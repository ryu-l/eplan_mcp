Dialog DT format

Dialog call:

  • You have opened a project. Options > Settings > Projects > "Project name" > Devices > Numbering (online). In the Settings: Numbering (online) dialog, click [...] next to the Numbering format field. In the DT tab, click [...].
  • Utilities > Change of standard. Make the necessary entries in the Project, Rotation / flipping, Master data, Symbols and Structure tabs and click [Next] each time. In the Numbering tab, next to the Device numbering field, click [...]. In the DT tab, click [...].

In this dialog, you select and edit the format elements for online numbering of general devices, terminal strips, plugs, black boxes, PLCs, cables, fluid devices, or fluid connection splicers and line connectors.

The following dialog elements are available:

Available format elements:

This field displays all available format elements. The format elements are either part of the format or define the manner in which numbering should occur. In order for a format element to be used for a format, you must select it and use (Move to the right) to include it in the Selected format elements field.

Format element

Preview

Meaning

Identifier

I

Defines the identifier for the device.

Counter

C

Defines the counter for the device.

Page

S

Defines the page name(s) of the page(s) where the device is located.

Column

P

Defines the column in which the device is located.

Row

R

Defines the row in which the device is located.

Separator

Separates format elements from one another. Separators can be inserted only behind the identifier and in front of the counter. If you use as separators a point, minus sign, or a preceding sign of structure identifiers, then round brackets will be inserted automatically around the format component between the identifier and counter. The display of brackets can be switched on or off using the Hide brackets in DT check box (Options > Settings > Projects > "Project name" > Devices > DT).

Example:

You have selected the following format elements for the online numbering format:

Page
Identifier
Separator
Column
Separator
Counter

The two separators are each a point. In the DT, the format component "Separator / Column / Separator" is placed in round brackets, for example, a fuse -2F(.4.)3.

Selected format elements:

This field displays all the format elements comprising the current format. The current format is shown in the Preview field.

Button

Meaning

(Edit)

Allows the selected format element to be edited.

(Delete)

Deletes the selected format element.

(Move up)

Moves the selected format element one line upwards. Specify the order of the format elements here.

(Move down)

Moves the selected format element one line downwards. Specify the order of the format elements here.

Preview:

This field displays a preview of the format. The format is composed from the format elements in the Selected format elements field.

Keep prefix:

The functionality applies to DTs containing a prefix. If the check box is selected, the prefix is retained in the DT. If the check box is deselected, the prefix is removed from the DT. This functionality allows you to (e.g.) decide whether the circuit number is to be retained in the DT for fluid devices.

Keep letter elements of counter:

This functionality applies to counters and designations containing letters. If the check box is selected, the numeric part is incremented and the letters remain unchanged.

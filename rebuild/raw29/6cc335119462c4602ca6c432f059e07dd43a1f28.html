Keeping Connection Point Logic when Changing the Function Definition

You edit the logic model of the function in the Connection point logic dialog. In the past if user-defined modifications were made for one or more connection points here, the settings were removed again as soon as another function definition was selected in the Symbol / function data tab. So that you can prevent this in the future, you have the new Keep connection point logic of the function check box in the Function definitions dialog. If this check box is activated, the connection point logic of the function is not changed when another function definition is selected. This way user-defined modifications in the Connection point logic dialog remain.

rowGroup

The element <rowGroup> groups rows, which are superordinate set to the same properties.

Attribute name Usage Attribute values Default value Description
height optional Absolute value in pixels Absolute value in pixels = height of the row in pixels, e.g. "150"
readonly optional true, false true = Row group is read-only.
false = Input can be written to the row group.
Allowed sub-elements Quantity
row any

Table with a configuration of column group and row:

The following table consists of 3 rows, whose heights are fixed by the configuration of the row group. The second row instead has another height and replaces the configuration in the row group.

Example code:

 

<table columns="2" boColor="0,0,0" border="2">
	<rowGroup height="50">
		<row/>
		<row height="100"/>
		<row/>
		</rowGroup>
		<td><label>Cell 1.1</label></td>
		<td><label>Cell 1.2</label></td>
		<td><label>Cell 2.1</label></td>
		<td><label>Cell 2.2</label></td>
		<td><label>Cell 3.1</label></td>
		<td><label>Cell 3.2</label></td>
</table>

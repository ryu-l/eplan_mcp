Numbering and Renaming Pages

The Number command allows you to subsequently renumber pages. In this manner, pages within a project can be renamed and thus moved.

For automated allocation of page names, EPLAN suggests the next available page name in the target project. Subpages are automatically incremented. For DIN projects, the suggestion is group referenced. You can either retain the suggested (start) page names, or change them. For several pages, you can also customize the increment defaults.

Precondition:

You have opened a project and selected one or more pages in the Pages - <Project name> navigator dialog.

  1. Page > Number
  2. In the Number pages dialog, enter a new starting number and the increment size (and if necessary, further page numbering entries).
  3. Click [OK].

    EPLAN renumbers the pages if no existing pages will be overwritten by this.

    If your choice of start number and increment means that page names will be overwritten, the Number pages: Preview of result dialog is opened.
  4. Change the corresponding page properties. Click [OK].

    The pages are renumbered.

Rename single pages

Precondition:

You have opened a project and selected a page in the tree view of the Pages - <Project name> navigator dialog.

  1. Page > Rename
  2. Enter the new page name and press the [Enter] key.

    The page is renamed but the page description remains unchanged.

Tips:

  • Some fields, such as the Page description and Drawing number field can be directly edited in the table in the page navigator list view.
  • In the tree view of the page navigator you can move and copy pages via Drag & Drop. Hold down the [Ctrl] key to copy pages.

Test 4 - Generate the current state of the ListOfComponents

This test shows that by determining the values for the plugs and sockets by way of the formulas, all sensors can initially be placed again. If the Testing function group is disabled, there must not be any gaps between the sensors

Generate the ECAD structure again.

The schematic consists of 2 pages that contain 8 and/or 2 sensors.

Open the schematic again.

The schematic consists of 2 pages where all sensors are available. The pages have names that are determined by the formula (=name).

Close P8 and disable again the Inspect function group by setting the Option_Inspect_available to false.

Generate the ECAD structure once again.

The schematic consists of the PLC_Sensors_1_8_Feeder page that contains 7 sensors, and the PLC_Sensors_9_16_Feeder page that does not contain any sensors.

Open the schematic again.

On the first page of the schematic, one can see that the PLC inputs are now assigned without any gaps. On the second page, all PLC inputs are unconnected. Thus, the second page is not required, and is to be disabled by means of a formula in the next step.

Upon closer inspection, one can see that the device tags and function texts are still represented by <null>. For these elements, too, formulas must still be entered.

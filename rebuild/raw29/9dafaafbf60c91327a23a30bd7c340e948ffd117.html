Preparatory steps in Pro Panel

Parts data that might not be available in your parts database is necessary for the tutorial. Therefore a parts database is provided which contains these parts data. Alternatively all used parts are provided as EDZ files so that they can be imported into other database types (for example SQL) as well.

Changing parts database

The parts database ESS_part001_Tutorial.mdb for this tutorial is stored in this folder:

<EEC installation folder>\install\Tutorial\ProPanel

This is how you change the parts database:

  1. Copy the parts database ESS_part001_Tutorial.mdb to the default folder for P8 parts databases (see Dialog Settings: Directories).
  2. Start EPLAN Pro Panel or EPLAN Electric P8 with the add-on for Pro Panel.
  3. Select Options > Settings... > User > Management > Parts.
  4. Click right of the option Access on [...].
  5. Select the parts database ESS_part001_Tutorial.mdb.
  6. Confirm with [Open].

The parts database is now entered for the Access option.

  1. Confirm with [OK].

Note:

Perform a synchronization of the parts database to make sure that the current data are used (see Master data: Managing parts data).

Then you can close EPLAN Pro Panel.

Importing parts data as EDZ files

The parts data for this tutorial are stored as EDZ files in this folder:

<EEC installation folder>\install\Tutorial\ProPanel

This is how you import the parts data into your database:

  1. Start EPLAN Pro Panel or EPLAN Electric P8 with the add-on for Pro Panel.
  2. Select Utilities > Part > Management.
  3. Click Extras.
  4. Select Import....
  5. For the File name field select the EDZ files from the folder specified above. To do this use the [...] button.
  6. Confirm with [Open].
  7. If necessary, mark the Only add new records option.
  8. Confirm with [OK].

Then you can close EPLAN Pro Panel.

Text generator

The text generator is used to create documents of the text and PLC disciplines.

The text generator is controlled by the following elements of the text generator language.

  • Control structures are used to conditional create text (see IF) and iterating over several objects (see LOOP). By means of control structures, for example, code fragments of a PLC program can be deleted or added.
  • Methods are used in particular by generators of the PLC discipline. They serve, for example, the creation of temporary variables, or the generation of block calls.
  • Formulas can be used to create variable text.
  • Replace parameters are used to exchange text according to the search-and-replace principle.

All elements of the text generator language (with the exception of the Replace parameters and Comments) begin with (*{ and end with }*), e. g. (*{CALL}*). The upper and lower case is important to note in the text generator language. The elements of the text generator language are removed from the template and replaced by the result text whilst generating. No line breaks, tabulators or others will be created, that means the formatting of the template remains in the generated text.

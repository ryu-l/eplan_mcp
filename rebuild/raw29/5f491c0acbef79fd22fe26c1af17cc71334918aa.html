Dialog Edit revision data

Dialog call:

You have generated a revision and have opened a revision project (file extension *.ell). You have made changes within the revision project. You have closed the pages. Utilities > Revision control > Change tracking > Edit revision data.

In this dialog, the revisions of a project and the modified pages in each revision are listed. You can change the revision information such as the comments, description, or the reason for the modifications here.

Overview of the main dialog elements:

In the table, the revisions of a project are shown first. Below the revisions, the modified pages are listed. The table contains the following columns:

  • Row: Contains a consecutive row number.
  • Revision name: Shows the name of the revision. You can change the revision name later. This field is grayed out for individual pages.
  • Defined working section: Shows the name of the defined working section to which the revision belongs.
  • Comment: Shows the comments you entered when creating the revision. You can change the comments for the revision. This field is grayed out for individual pages.
  • Index: Shows the revision index that you provided when describing the page modification. You can change the index for each page.
  • Description: Shows the description text that you provided when describing the page modification. You can change the description text for each page.
  • Reason for change: Shows the reason you provided when describing the page modification. You can change the reason for modification for each page.
  • Page / Layout space: Shows the complete name of the modified page / layout space. Unlike a complete page name, the name of a layout space is separated from the structure identifier not by the separator '/' but by a blank and a bracket (e.g. =EB3+ET1 (2)). This field cannot be modified.
  • User: Shows the user who described the page change. This field cannot be modified.
  • Date: Shows the exact date that the page modification was described. This field cannot be modified.
  • Code / Name / Phone / E-mail: Shows the data as specified under the Options > Settings > User > Display > User code / address menu items. These fields cannot be modified.
  • Approved by: Here you enter the user who approved the revision. This entry cannot be translated.
  • Approved date: Here you enter date and time when the revision was approved. Click into this field and then on the arrow button at the right margin to open the dialog for date selection and select the desired date.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

In addition, the following dialog-specific popup menu items are available:

Menu item

Meaning

Delete latest revision

Deletes the most recently created revision (i.e., with the most recent date). In the process, all revision information of such revision is deleted from the page properties. Modifications made on the project pages are retained. The revision markers remain unchanged as well.

Merge revisions

Merges the selected revisions. For this purpose, the Generate revision dialog is opened for you to enter a (new or already existing) revision name and a comment. The revision markers at the components are updated and the old revision name is replaced by the new one. The date of the merged revision is the date of the oldest revision which is merged.

Tip:

If necessary, you can remove the revision markers using the menu items Utilities > Revision control > Change tracking > Delete revision. However, this will delete all revision markers on the highlighted pages, regardless of the associated revision.

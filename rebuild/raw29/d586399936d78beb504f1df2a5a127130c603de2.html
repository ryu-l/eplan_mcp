P026073: Routing connection without part number, color / number and/or cross-section / diameter

Cause

When routing routing connections, a routing connection was found for which at least one of the following properties has not been defined:

  • Part number
  • Color / number
  • Cross-section / diameter.

Solution

  1. Locate the routing connection in the layout space using the function Go to (graphic) from the popup menu in the Message management dialog.
  2. In the layout space, double-click the routing connection highlighted in color.

    The Properties <...> dialog of the routing connection is opened.
  3. In the dialog, bring to front the Part tab, and check whether a part number is entered in the table.
  4. If not, select the first row, and open the part selection with [...].
  5. In the tree structure navigate to the required part, and select it by clicking [OK].
  6. Switch to the Connection tab.
  7. Check whether the fields Color / number and / or Cross-section / diameter each contain a value.
  8. If not, add the missing value(s).
  9. Close the Properties <...> dialog by clicking [OK].
  10. Then start a new check run, and route the connections again.

Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

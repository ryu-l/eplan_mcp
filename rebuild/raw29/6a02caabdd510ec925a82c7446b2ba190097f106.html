Using Graphical Macro Selection

Preconditions:

  • You have opened a project.
  • You have activated the Use graphical macro selection check box (Options > Settings > User > Graphical editing > Macros).
  1. Select one of the menu options Insert > Window macro / symbol macro or Page > Page macro > Insert.

    The Graphical macro selection dialog opens.
  2. Select the file path for which the macro directories are to be displayed.
  3. Select the Images popup menu item to display the directory images in another size.

    The size of the images is adjusted.
  4. Select the Filter: <Macro file type> popup menu item to filter for a specific macro type.

    The display of the files is adjusted in the File selection area.
  5. Click the plus sign in front of a macro name in the File selection area to find out the representation type of the macro and whether there are several variants.
  6. Click the required variant of a macro, followed by [OK], to select this macro. Or double-click a macro name to select and insert the first existing macro variant of this macro.

    The dialog is closed and the macro is inserted.

Note:

In contrast to the usual macro selection, you cannot execute any functions in the Graphical macro selection dialog that affect the directories or files. For example, you cannot create, rename or delete any directories or files in this dialog.

Creating and Editing Segment Templates

Segment templates are created and managed in the segment template navigator.

Create segment templates

  1. Project data > Pre-planning > Segment template navigator
  2. Select a segment definition and select the New segment template popup menu item.

    The dialog Properties <...> is opened.
  3. Enter an identifying name and an optional description for the new segment template in the Segment template tab in the dialog Properties <...>.
  4. If necessary, assign additional properties to the segment template in the other tabs. The tabs displayed depend on the segment definition.
  5. If necessary, enter a part in the Part tab. The function template of the part can be used later when the detail planning is created.
  6. If necessary, enter a macro in the Macro tab. This macro can be used later when creating the detail planning as described in the section Creating Detail Planning with Drag and Drop.
  7. Click [OK].

    A segment template with the appropriate properties is created.

Tip:

You can move segment templates via Drag & Drop to a different point within the same basic segment definition in the tree view of the segment template navigator, in as far as these segment templates are not yet used in the project. In the process the segment definition below which the segment template was moved is assigned automatically to it. If you keep the [Ctrl] key pressed while dragging, the marked segment templates are copied.

Creating a segment template from an existing segment

Preconditions:

  • You have opened a project that already contains segments.
  • You have opened the pre-planning navigator and the segment template navigator.
  1. Select a segment in the pre-planning navigator.
  2. Drag the segment into the segment template navigator.

    A segment template with the properties of the marked segment is created.

Note:

The segment template is not assigned to the segment from which it was created. If necessary, you have to carry out this assignment manually.

Edit the properties of segment templates

  1. Project data > Pre-planning > Segment template navigator
  2. Highlight a segment template and select the Properties popup menu item.
  3. Edit the display properties (Identifying name and Description) of the selected segment template in the Segment template tab of the dialog Properties <...>.
  4. If necessary, assign additional properties to the segment template in the other tabs or change the existing properties. The tabs displayed depend on the segment definition.
  5. Click [OK].

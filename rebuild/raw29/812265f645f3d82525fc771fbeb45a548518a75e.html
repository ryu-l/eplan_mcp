Lists of Results

For the searching and finding of project data, the Search results - <Project name> dialog provides two lists of results - the list of results and the Go to list.

List of results

If you carry out a search, the results are entered into the list of results. You can enter additional search results in the list of results and replace existing entries. You also have the option of jumping to the objects on the project pages. You can right-click to open the editing dialog of the corresponding objects for the selected entries in the list of results and make changes to the objects. This can also be performed for blocks of selected objects and texts. For texts, the language display can also be changed (All displayed languages, One language, etc.).

The menu item Find in the main menu of the graphical editor contains the following commands for the list of results:

Menu item

Meaning

Insert into list of results

If you have selected elements, they will be included into the list of results without opening the Search results - <Project name> dialog.

Next entry / Previous entry

Jumps to the next or previous placed element in the list of results. This enables you to jump from element to element. When performing this, the graphical sequence at the time of the search is maintained. Project data, page data, and unplaced object data are ignored.

Go to list

If you have selected objects in the graphical editor, the navigators, or list of results, then the menu items Go to (cross-referenced) and Go to (all representation types) are available in the popup menu (or the Find menu). This menu item will produce another list of results. In the Search results - <Project name> dialog the results are displayed on the Go to tab. Unlike the other list of results, this list is emptied each time before it is filled in. The popup menu provides you with all of the functions available for the list of results.

The menu item Find in the main menu of the graphical editor contains the following commands for the Go to list:

Menu item

Meaning

Go to > Cross-referenced function > List

Enters all cross-referenced functions for a selected function into the Go to list and opens the list. The Go to results list shows all objects cross-referenced to the source object, all object that it cross-references, and the object itself.
Objects on the "Schematic single-line", "Overview", and "Panel layout" page types are also shown in the list, as well as placeholder text on report pages.
In the case of interruption points not only pair cross-references but also all interconnected interruption points are entered.

Example:

If you call up the menu item Go to (cross-referenced) for a contact, not only the coil will be entered in the list, but also all of the other contacts as well as the original contact itself.

Go to > Cross-referenced function > Forward

Jumps forward in the Go to list and displays the relevant function in the graphical editor.

Go to > Cross-referenced function > Backward

Jumps back in the Go to list and displays the relevant function in the graphical editor.

Go to > All representation types

Enters all of the representation types of a function (e.g., on a schematic page, an overview page, and / or a report page) into the Go to list and opens it.

Example:

If you selected the Go to (all representation types) menu option for a contact, then all representation types for this contact (Single-line, Multi-line, Pair cross-reference, Overview etc.) are entered in the list.

Go to > Part assemblies

EPLAN enters all the locations at which the relevant parts are output in parts lists and summarized parts lists in the Go to list, and opens the list. The part number is displayed under "Name".

The menu items Go to (graphic) and Go to (counterpiece) that are available in the navigators or the graphical editor are used for navigation in the schematic and do not fill the list of results.

Menu item

Meaning

Go to > Counterpiece

Only available in the graphical editor! For pair cross-references (e.g PLCs, interruption points, etc.) this jumps to a counterpart and for auxiliary functions it jumps to the main function.

Example:

If you call up the menu item Go to (counterpiece) for a contact, then a jump occurs to the coil.

Go to > Graphic

This menu item is available in the navigators and the search results lists. Jumps to the first selected entry. For placed objects you will jump to the graphical editor. For unplaced objects you will remain where you are. When jumping to connections you will jump to the first graphical connection definition point. If there is no connection definition point you will jump to the source function.

On report pages, a jump occurs to the cross-referenced objects. This allows (e.g.) jumping from the table of contents to the relevant pages.

Jumps to reports

It is possible to jump to reports from the lists of results. Using the menu item Go to (cross-referenced) the placeholder text on the report pages is loaded into the list of results. If you select the menu item Go to (graphic) on an entry in this list, then the corresponding report page is opened in the graphical editor.

Conversely, you can select a placeholder text on a report page and use the Go to (cross-referenced) and Go to (all representation types) menu items to jump to the associated object in the list of results.

You can use the menu item Go to (graphic) to jump to the cross-referenced objects on report pages. If you keep the [Ctrl] key pressed down and move the cursor over an object that can be jumped from, the cursor changes into a hand. This allows (e.g.) jumping from the table of contents to the relevant pages.

It is also possible to jump from the report pages to the graphical editor if the data come from another project. If the schematic project (the source project) is not yet open, you will see a message with the option to open the project. Confirm this message with [Yes]; the schematic project is then opened automatically and you jump to the cross-reference object.

Dialog Multi-user conflict

Dialog call:

You are working with EPLAN in multi-user operation. All users have entered their respective user information under Options > Settings > User > Display > User code / address. You have opened a project in the "Default" processing mode and want to edit data which is already being processed by another user, or you want to open a project which is currently being edited project-wide by another user.

This dialog displays the users that are currently editing the same data or are editing the entire project.

Overview of the main dialog elements:

Table:

This table lists the users that are currently editing the same data in the selected project. If a project-wide revision is currently being made the user carrying it out will be displayed here.

The information in the Logon name, Name, Phone, and E-mail columns are stored in the user settings for the respective users. The computer name is also displayed in another column. This information allows you to recognize the computer in the network.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

In addition, the following dialog-specific popup menu items are available:

Menu item

Meaning

Copy

Use the Copy menu item to copy the contents of one or multiple selected cells (e.g. telephone number) into the Clipboard and make them available for other applications.

Send e-mail message

Opens the Message dialog where you can enter an e-mail message. The field for entering the e-mail address is automatically filled.

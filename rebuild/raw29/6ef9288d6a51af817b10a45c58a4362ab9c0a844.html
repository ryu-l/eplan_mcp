Tab Conditions

Dialog call:

You have opened a project and a dynamic form (via the Utilities > Master data > Form > Open > [Open] menu items, for example). Insert > Dynamic area > Conditional area. You have drawn the conditional area as a rectangle. Double-click in the rectangle and select the Conditions tab in the property dialog.

On this tab you can define the conditions under which specific areas are output in your reports. Graphical elements and placeholders can be used in conditional areas.

Overview of the main dialog elements:

If property is changed:

Click [...] in this field to move to the Change of the property dialog, where you can select the property that generates a report of the area when it is changed. For example, for a device tag list, you can specify that a thick line is drawn before the next DT, each time the DT (displayed) property is changed.

In the dynamic forms for the Connection list you are also offered the block properties for selection in the property selection for the Change of the property dialog. This way you can, for example, output a blank line in a connection list if the value of a specific block property changes.

When switching objects:

Select this check box to specify that the conditional area should be reported each time the object changes.

Example:

You have a terminal diagram in which the targets are listed for each terminal. A gray bar should be drawn before each reported object (so in this example, before each terminal). Draw the bar in your conditional area, and select this check box.

At first start of column / At every start of column / At every end of column / At last end of column:

Select this check box to specify that the graphic elements defined in the conditional area should only be inserted at the first start of column or at each start of column / at each end of column or only at the last end of column. In combined reports, the first start of column and the last end of column always refer to the object to be reported, e.g. a terminal strip.

After every n-th line:

In this field, enter the value of the line after which the graphical elements defined in the conditional area should be displayed.

Adjust height:

Select this check box if scaling for the conditional area should be based on the height of the previous row of data.

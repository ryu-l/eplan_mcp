Entries in the List of Results

From the navigators, or from a component in the graphical editor, the Go to (cross-referenced) or Go to (all representation types) menu items from the Find menu or the popup menu can be used to load data into the Go to list of results. To do this the Search results dialog does not need to be open. Texts can also be entered into the Go to list in this way.

The following information is entered:

Object

Value

Texts

With the first display language of the project

Functions

(Displayed) DT

Interruption points

(Displayed) DT (name)

Connection definition points

Connection designation

Potential definition points

Name of potential

Placeholder text in reports

Page type

The following objects are not entered into the list of results:

  • Structure boxes
  • Angles, T-nodes, jumpers, double junctions, etc.
  • Graphical elements (lines, circles, rectangles, etc.)
  • Connections
  • Mounting panels
  • Macro boxes
  • Placeholder objects.

A results list entry consists of the following information:

  • Index (the index defined the graphical sequence in the schematic. Unplaced functions are added to the end. The index is not displayed in the dialog.)
  • Object type (e.g. coil)
  • Object name, plus the first connection point designation (e.g. -K1:A1)
  • Property (e.g. function text)
  • Value (e.g. main drive)

Search results sequence

Results are first displayed according to their graphical sequence in the schematic. One line is entered for each language in which the result was found. Click the column headers to sort the entries in ascending or descending order.

  • Objects on page 1
  • Page 1
  • Objects on page 2
  • Page 2
  • ...
  • Unplaced functions
  • Project.

The full page name, position on the page, page type, and language of the first selected search entry are shown on the dialog status bar.

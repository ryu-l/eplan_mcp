Dialog DXF / DWG export

Dialog call:

You highlighted a project or at least a project page. Page > Export > DXF / DWG.

In this dialog you start the actual export process. When exporting an entire project or individual pages to DXF / DWG format, a separate file is generated for every selected page.

Overview of the main dialog elements:

Source:

This field displays the source of the export. For an entire project, this is the project name; for individual pages the full page names are displayed (including the page properties Functional assignment, Higher-level function, etc.). The entries can't be edited here.

Scheme:

Select a scheme to define the settings for the export of files from the drop-down list. Click [...] to open the settings dialog for the export. There you can define settings and save them as a scheme or Edit existing schemes.

Export medium:

Set the export medium for the export in this group box:

  • Storage medium: If this option is selected, the DXF / DWG file is output to a storage medium.
    Enter the storage location in the Output directory field. You can specify any drive and subdirectory as the target for the export.
  • E-mail: If this option is selected, the DXF / DWG file is sent as an e-mail. Once the function has been called up, the file is zipped using the internal zip program and your installed e-mail editor is started.
    From the Split size drop-down list select the maximum size for an individual e-mail file. The possible values are 1 MB to 10 MB in 1 MB increments, or you can select "Unlimited". EPLAN automatically creates the number of e-mail files required to send the whole project. All individual mails in the group will have this text in the subject line: "<File name> n/m". "n" is the number of the individual e-mail file and "m" is the overall quantity of the files.

Note:

A MAPI-based e-mail client must be installed and correctly set up on your computer in order to exchange e-mails. For this reason the e-mail app of Windows 8Â® cannot be used either.

File name:

When exporting a single page you can enter any desired file name here. You can use [...] to assign a new name or select the name of an existing file.

If no file name is specified, a name is assigned to the exported file on the basis of the Generate file names setting.

You can use the Insert path variable popup menu item to branch to the dialog Select path variable where you can select one of the available path variables.

Note:

When exporting multiple pages, the file name cannot be freely chosen. DXF- / DWG files are created as a consecutive number in the specified target directory, or from the page name, or from the properties; this depends on the settings of the selected scheme.

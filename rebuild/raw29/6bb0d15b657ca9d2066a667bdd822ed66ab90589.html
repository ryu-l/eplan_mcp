Predefining Connection Properties

Connections are given properties from the defaults in the project and the properties of the potential. All other properties are specified in the connection definition points.

You can specify certain properties for connections in the project settings that are then assigned to every connection generated.

The properties specified in the project are inherited by the potential. The potentials then pass on their properties to the signals and then the connections. You can manually change the data on the individual levels and define additional properties.

  1. Select the Options > Settings > Projects > "Project name" > Connections > Properties menu items.
  2. Select the desired tab, e.g. Electrical engineering, Hydraulics, or Process engineering.
  3. In the individual fields specify the default values for the connection properties.
  4. Confirm your entries.

    The default values are saved. When generating a connection it is automatically assigned the corresponding default values.

Tip:

For large projects, generating connections can take some time. If you don't have much time, select [No] when prompted. You have the option of generating the new connections at a later time by holding down the [Shift] + [Ctrl] keys when carrying out the action Project data > Connections > Update.

Protecting Devices

You can protect a complete device by means of the device protection. In addition, it is possible to protect only individual functions, connections or planning objects.

Protecting a complete device

Preconditions:

  • You have opened a project.
  • You have selected the function of a device in the graphical editor or in a navigator dialog.
  1. Select the Project data > Devices > Activate device protection menu items.

    The Device protection property is assigned to all the functions of the device. The parts assigned to the device can no longer be changed. This means that a device selection or part selection or actions such as "Exchange part", "Edit part" and "Add part" cannot be carried out.

    The device can no longer be deleted from the project.

Tips:

  • You can extend the device protection by specifying the "Prevent errors" type of check for specific test runs. In this way, you can prevent the over-allocation of a protected device, the addition of further functions, or the modification of data transferred to the functions from the parts.
  • If you have selected a hierarchy level in the device navigator, you can activate the device protection for all the devices below this hierarchy level simultaneously.

Protecting individual functions, connections or planning objects

Preconditions:

  • You have opened a project.
  • You have selected a function in the graphical editor or in a navigator dialog, or you have selected a connection in the connection navigator. You have selected a planning object in the preplanning navigator.
  1. Select the Edit > Other > Configure protection menu items.
  2. In the Configure protection dialog, select the check box Device protection.
  3. Click [OK].

    The parts assigned to the function, the connection or the planning object can no longer be changed. This means that a device selection or part selection or actions such as "Exchange part", "Edit part" and "Add part" cannot be carried out.

    The function, the connection, or the planning object can no longer be deleted from the project.

    However, it is still possible to change properties on the first tab of the properties dialog.

Deactivating the device protection

Preconditions:

  • You have opened a project.
  • You have selected the function of a device in the graphical editor or in a navigator dialog.
  1. Select the Project data > Devices > Deactivate device protection menu items.

    Device protection is canceled, so that the Device protection is deactivated for all the functions of the device.

Tip:

If you have selected a hierarchy level in the device navigator, you can deactivate the device protection for all the devices below this hierarchy level simultaneously.

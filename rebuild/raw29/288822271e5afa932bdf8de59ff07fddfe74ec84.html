Outputting Cable Parts in Reports

In the parts reports (parts lists and summarized parts list) you can decide whether cable parts (from the individual cables) and cable project parts should be output. Cable parts with the quantity "0" can be excluded from the output using a filter (Product group = "Cable" AND quantity = "0").

It may make sense to output the cable parts with quantities of "0": In this case, the accessory parts of cables as well as the premade cables that were not taken into consideration for the summation of cable lengths are also output. The parts with quantities of "0" then display which cable is used there, and the project parts specify what needs to be ordered.

Precondition:

You have opened a project.

  1. Utilities > Reports > Generate
  2. In the Reports dialog select [Settings] > Parts.
  3. In the Settings: Parts dialog select the Cable parts check box so that parts entered on cable definition lines or shields are also adopted in part assemblies.
  4. Activate the Cable project parts check box, so that cable project parts that are to be generated in the summation of cable lengths will be inserted into the parts reports.
  5. Activate the Connection parts check box so that parts entered on connection definition points or on nonplaced connections are also adopted in parts reports.
  6. Activate the Cable connection parts check box so that parts entered on cable connections are also adopted in parts reports.
  7. Click [OK].
  8. Select [Settings] > Display / output.
  9. In the Settings: Display / output dialog select the Restrict output of cables check box if you want to restrict output to cables that have a certain minimum number of cable connections.
  10. In the Output from number of connections field, enter a minimum number of cable connections.
  11. Click [OK].
  12. Click [New] to generate a new parts report, or select an existing parts report and update this by clicking [Update].

Predefine the cable parts output for the project

In the project settings you can predefine the output of cable parts for the project:

  1. Options > Settings > Projects > "Project name" > Reports > Part
  2. Select the Cable parts check box, the Cable project parts check box, the Connection parts check box, and / or the Cable connection parts check box in order to output the various parts in the parts reports.
  3. Click [OK].

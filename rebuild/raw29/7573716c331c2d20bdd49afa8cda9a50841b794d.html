Dialog Bundle connections: Preview of result

Dialog call:

Project data > Connections > Bundle. In the Bundle connections automatically dialog, the Preview of result check box is activated. Click [OK].

This dialog lists the connections to be modified. You can confirm the new bundle numbers with [OK] or modify the new bundle numbers manually.

The following dialog elements are available:

The table contains the following columns:

  • Row: Contains a consecutive line number.
  • Source: Source of the connection.
  • Target: Target of the connection.
  • Bundle: Bundle number that already existed at the connection prior to the automatic bundling.
  • New bundle: New bundle number of the connection assigned by automatic bundling; the number can be modified manually here in order to assign the connection to another bundle.

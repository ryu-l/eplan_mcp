Dialog Settings: Driver for SQL server

Dialog call:

Options > Settings > Workstation > Interfaces > Driver for SQL Server

When using SQL databases for parts management, the project management and the dictionary you can set up an alternative driver for the SQL Server in this dialog. This means that you can also use databases on SQL Servers, for which higher security requirements exist (for example encryption protocol with TLS 1.1 or TLS 1.2).

Overview of the main dialog elements:

Driver for SQL server:

Select the option Alternative driver if you want to select an alternative driver for the SQL Server from a drop-down list.

Note:

A selection possibility in the drop-down list is only available if corresponding drivers are installed on your computer. For questions about possible drivers please contact your SQL system administrator.

Dialog Number cables: Preview of result

Dialog call:

You have opened a project.

  • You have opened the Generate cables automatically dialog, e.g. via the Project data > Cables > Generate cables automatically menu items.
  • You have opened the Number cables dialog, for example via the Project data > Cables > Number menu items.

You have selected the Preview of result check box. Click [OK].

This dialog displays a preview of the DTs that are assigned to the cable definition lines, shields, and connection definition points in the numbering process. You can accept the new device tags, modify the device tags, or keep the old ones.

Overview of the main dialog elements:

The table displays old device tags on the left and new ones on the right for newly generated or existing (but unnamed) cable definition lines, shields, and connection definition points.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

In addition, the following dialog-specific popup menu items are available:

Menu item

Meaning

Use original DT

Accepts the old DT for the selected rows in the right column of the table.

The final device tags are generated in the subsequent numbering. The device tags that were previously identical are now renamed identically so that all assignments remain.

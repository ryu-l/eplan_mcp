unit

Allows reading of a property for a graphical object.

Attribute name Usage Attribute values Default value Description
name required Unit of the object
value required Value of the unit. The base unit must not be defined. If however, it is defined, the value is always indicated with 1.
Allowed sub-elements Quantity
none

Example code:

Units of time for the time line of a gantt diagram should be defined. Base unit is 1 s. All other units are derived from 1 s.

<figure-ganttContainer xmlns="http://www.mind8.com/Diagram/Gantt"
	figure="com.mind8.graph2d.figure.container.Gantt">
	<gantt:configuration>
		<ruler-config>
			<resolution>1000ms/10px</resolution>
			<units>
				<unit name="ms" value="0.001"/>
				<unit name="s" value="1"/>
				<unit name="min" value="60"/>
				<unit name="hour" value="3600"/>
			</units>
		</ruler-config>
	</gantt:configuration>
</figure-ganttContainer>

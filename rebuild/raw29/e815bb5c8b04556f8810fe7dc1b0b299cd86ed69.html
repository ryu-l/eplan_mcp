Dialog Number connecting points

Dialog call:

You have opened a project.

  • Utilities > Master data > Symbol > Open. You have opened a symbol library, selected the symbol to be edited, and added connecting points to the symbol. Utilities > Number connecting points.
  • Utilities > Master data > Symbol > New. You have selected the symbol variant to be generated, specified the Symbol number and Symbol name properties, and added connecting points in the symbol editor. Utilities > Number connecting points.

In this dialog you specify how the connecting points should be numbered.

Overview of the main dialog elements:

Sequence:

Use these options to specify whether the connection points should be numbered according to the "from top to bottom and left to right " method or the "from left to right and top to bottom" method.

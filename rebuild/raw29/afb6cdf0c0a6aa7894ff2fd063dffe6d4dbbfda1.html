Dialog Rights management: Users

Dialog call:

Utilities > Rights management > Users

In this dialog you can create and edit users.

Overview of the main dialog elements:

If you have selected the Users folder in the left-hand field then a list of all registered users is displayed in the right-hand field. Users created in EPLAN and imported from Windows are differentiated by means of the Icons.

[Change password]:

Opens the Change password dialog. You can change the password there that the associated user uses to log on to EPLAN. Changing the password is not possible for the pre-defined user "GUEST" as well as users imported from Windows.

The following dialog elements are available for individual users:

If you have opened the Users folder in the left-hand field and selected a single user, a list of user groups is displayed in the right-hand field. A checkmark in front of each user group shows whether the user is a member of this group and thus possesses the editing rights assigned to the group. Every user may belong to any number of groups.

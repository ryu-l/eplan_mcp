Creating a Function-related Report without a Template

EPLAN has report types for report overviews and for function-related reports. Function related reports, such as the terminal diagram, have a device in the header as standard, e.g., the terminal strip. The associated functions are in the data area, e.g., the terminals of the terminal strip. The way in which the report pages are sorted into the existing page structure depends on the Page sorting for reports defined in the report settings for the particular report type.

Preconditions:

  • You have opened a project.
  • You have assigned a form to the desired report type.
  1. Utilities > Reports > Generate
  2. In the Reports - <Project name> dialog, click [Settings] > Output to pages.
  3. Decide on a report type for function-related reports.
  4. In the Page sorting column click [...], and set up the page sorting in the following dialog.

    To generate comprehensive reports for the entire project, select the Total entry from the Sort by / into drop-down list.

    To generate structure identifier related reports, e.g. if the "Higher-level function" and "Mounting location" structure identifiers change, select the Higher-level function and Mounting location check box.
  5. Click [OK].

    The Page sorting dialog is closed.
  6. Click [OK] in the dialog Settings: Output to pages.
  7. In the Reports - <Project name> dialog, select the Reports tab and click (New).
  8. Choose the output format "Page" from the Output format drop-down list.
  9. Check whether the project that is the data source for the reports and templates has been entered into the Source project field.
  10. To select a different project click [...] in the Source project dialog, select the desired project and click [OK].
  11. Select a function-related report type on the Select report type field.

    If a function-related report type is selected, the Manual selection check box will be available.
  12. Select the Manual selection check box and click [OK].
  13. In the Available field, select the device that is to be included in the report and then click (Move to the right).

    The device is moved into the Selected field.
  14. Choose all the desired devices in the same manner.
  15. To alphabetically sort the devices for the report, click [Sort].
  16. Click [OK].
  17. In the Settings - <Report type> dialog, optionally select Schemes for filtering, sorting, and page breaks in reports, and click [OK].
  18. In the <Report type> dialog, enter the page name of the start page into the first structure identifier.
  19. If desired, enter an optional page description and sheet number and then click [OK].
  20. Define the properties of the start page for all other structure identifiers in the same manner. The structure identifiers that are available depend on the page sorting assigned to the report type in the Settings: Output to pages.
  21. To adopt the start page properties for all structure identifiers, select the check box Apply start to all structure identifiers.
  22. Click [OK]..

    The report pages are generated.

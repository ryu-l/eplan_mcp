Creating Your Own Identifier Sets

In EPLAN you can create your own sets of identifiers taking into consideration different standards, countries, and customers.

  1. Utilities > Master data > Identifier
  2. Select the New popup menu item.
  3. In the New identifier set dialog specify the designation for the identifier set and click [OK].

    A new column with the appropriate header is displayed.
  4. Enter the identifiers for the individual functions into the various cells. Identifiers can consist of multiple characters.
  5. Click [OK].

    The identifiers you entered are saved.

Note:

After each change, the changed identifier sets must be exported. If you receive a new function definition library in an update, you need to import your exported identifier sets into the new program version and add the new function definitions.

Select identifier sets

Warning:

Before selecting identifier sets it is essential to perform a project synchronization (Utilities > Master data), to ensure that newly created identifier sets are taken into account and offered for selection.

  1. Options > Settings > Projects > "Project name" > Devices > Numbering (online)
  2. In the Current identifier set box select the desired identifier set from the drop-down list.
  3. Select the desired subclass from the drop-down list in the Identifier subclasses field.
  4. Or click [...] in the Identifier subclasses field and define a new class in the Identifier subclasses dialog that opens.
  5. Click [OK].

    The corresponding identifier / subclass is used for creating a function.

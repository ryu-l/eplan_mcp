Deleting User-Defined Properties

Preconditions:

User-defined properties for the project:

  • You have opened a project.
  • You have selected the menu items Project data > Configure properties.

User-defined properties in parts management:

  • You have opened parts management. Utilities > Parts > Management.
  • You have selected the menu items [Extras] > Configure properties.
  1. Select the property that you want to delete in the dialog Configure properties.
  2. Activate the Do not use anymore check box.
  3. Click [Apply].

    After confirming the message the property is not displayed anymore in the project / in the parts management.
  4. Select the menu items [Extras] > Remove properties that will not be used anymore.

    After the message is confirmed, the user-defined properties that are marked as "not to be used anymore" are deleted.

    If a user-defined property is deleted in the parts management that is also available in the project via the assignment of a property, the Do not use anymore setting for this property is automatically activated during the synchronization of parts.

    During removal the used properties are removed as well. This is not possible though for user-defined properties in the project that are still used in the master data. This is logged in the system messages.

Notes:

  • In the project user-defined properties which are used in parts or other master data cannot be removed despite the activation of "Do not use anymore", until the value "0" is displayed in the Usage count column for these properties. To this purpose you must first cancel the usage (remove selected parts, forms, etc.) and remove the parts, forms, etc. no longer used by compressing the project. Only then can you delete the corresponding properties via the Remove properties that will not be used anymore menu item or a repeated compressing.
  • When inserting and copying macros, the user-defined properties stored in the macro are also inserted in the project. By means of the Do not use new property configurations from macros setting you can specify whether project-specific user-defined properties can be used or not. New user-defined properties can also be inserted via other master data such as forms, plot frames, etc. These properties are also taken into consideration through the setting.

Tips:

  • Before you delete user-defined properties, you can check beforehand whether the properties are used. Select the Check usage menu item below the [Extras] button. Subsequently the current numbers of the usage are displayed in the Usage count column of the list view. Properties not used have the entry "0".
    By means of the menu item Set unused properties to 'Do not use anymore' you first activate the Do not use anymore setting for the unused user-defined properties and then remove these properties via the menu item Remove properties that will not be used anymore.
  • To delete all user-defined properties that are no longer used anymore in the project you can also use the compressing of projects. To do this, activate the User-defined properties not to be used anymore check box in the Remove project data hierarchy level of the dialog Settings: Compression. The project is compressed. In the process the user-defined properties that are marked as "not to be used anymore" are deleted.

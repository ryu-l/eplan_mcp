Editing Plug Data

The properties of plugs and pins can be edited in different places:

  • In the Properties <...> dialog, you can edit the data for the selected plug definition or the selected pins.
  • The plug navigator (Plugs - <Project name> dialog) provides you with an overview of all the plugs and pins in the open project. Here, you can select one or more pins or plugs. You can use the popup menu to create plugs and pins, or to call up the corresponding dialogs for editing.
  • In the Edit plug dialog, all pins of a plug are shown, along with all targets and jumpers (male and female pin). Using the popup menu, you can call different edit functions, with which you can number or sort the pins.

If you place pins, it is not necessary to specially select their counterparts. The assignment of male and female pins is performed via identical DT and the pin designation.

When you place a male or female pin on a schematic page, EPLAN suggests a sensible DT and pin designation in the properties dialog. You can accept the suggested values or manually change them. Entry of a pin designation is absolutely required, however. The pin is uniquely identified in the plug using the pin designation. You also have the option in the properties dialog of removing a pin.

In the plug definition, you enter data on the type of plug, the number of pins, and so forth.

Cross-reference to counterpart

The property Cross-reference to plug counterpiece can be used to display a cross-reference to the counterpart (i.e., the corresponding plug definition representing the receptacle / coupling) on the plug definition. For a combined representation of male and female pins in one function, no cross-reference is displayed.

On the pins, this property can be used to display a cross-reference to a matching pin. If male and female pins have the same DT, only the position of the matching pin is displayed. For non-placed direct connections, the cross-reference shows the name and position of the connected counterpart.

Part

Parts are entered and managed at the plug definition. In addition, you can enter parts at the individual pins, which can then be output in reports or be used for manufacturing data export / labeling.

For fully configured plugs, you usually enter all parts (both the plug housing and the pins) on the plug definition.
For freely configurable plugs, you enter only the part for the plug housing on the plug definition. The parts for the pins are entered at the respective pin.

Parts at the pins (auxiliary functions) do not cause function templates to be displayed in the plug navigator. Pins only superimpose the function templates of the main function, i.e., the parts entered at the plug definition.

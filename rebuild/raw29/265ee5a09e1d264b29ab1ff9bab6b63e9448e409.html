Creating a local database

A local database is used in connection with a Stand-Alone installation. A new local database is created using the administration tool.

  1. When creating a local database, the check box Client Server Installation must not be enabled. The host pre-set for a local database is LOCAL, which cannot be edited.
  2. The database name can be any name (the default name is jazzDb).
  3. The [Create Database] button starts the wizard for creating the database, and for importing and updating model data.

The demo model Docu_UI_Configuration contains the elements which are described in the following. These can be easily transferred to an own project by copy and paste.

For the programming of user interfaces, the EEC provides an XML editor (see XML editor for Form-UIs and diagram definitions):

The Form-UIs can also be edited with Notepad from Windows or any editors of third-party distributors, e.g. XML-Spy, Liquid XML-Studio, Oxygen XML-Editor, etc.

Programmers of user interfaces which use third-party editors are provided with a XML-schema for validation. The schema file forms.xsd is provided in the folder ..\install\forms.

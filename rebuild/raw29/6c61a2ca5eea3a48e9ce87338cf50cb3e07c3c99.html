P004007: Rack '<x>' is mounted on itself

Cause

Identical designations were entered for a PLC box containing bus data in the Rack ID and PLC card is placed on rack ID fields, which means that the rack is mounted on itself.

Solution

  1. Open the Properties <...> dialog of the corresponding PLC box.
  2. In the first tab, enter different data into the Rack ID and PLC card is placed on rack ID fields.
  3. Then start a new check run.

Note:

This check run only checks PLC boxes at which a configuration project is entered.

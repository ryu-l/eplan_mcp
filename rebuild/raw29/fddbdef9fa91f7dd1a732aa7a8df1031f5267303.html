Detailed Setting Options for the Routing Track

In the Topology: Routing track property those topology routing paths are listed that run through a connection routed in the routing path network or a routed cable. Detailed setting options are now available for the routing track:

  • In the past unplaced routing paths were also displayed in the routing track. Unplaced topology routing paths arise, for example, during the Generation of topology functions at structure routing points. Now you have the possibility to hide unplaced routing paths in the routing track.
  • The lengths of topology routing points or structure routing points were also not considered in the routing track. You now have the option to output the topology routing points and structure routing points with their lengths in the routing track.

To this purpose the new Suppress unplaced topology routing paths in the routing track and Output topology routing points with length in the routing track check boxes are available in the project settings for the connections. The menu path for these settings is: Options > Settings > Projects > "Project name" > Connections > General.

Benefit:

  • With the new project setting Suppress unplaced topology routing paths in the routing track you have the possibility to only output the routing tracks placed on pages in the reports.
  • With the new Output topology routing points with length in the routing track project setting you have the option to output the length within the routing points in reports.

Suppress unplaced topology routing paths in the routing track:

If this check box is activated, unplaced topology routing tracks in the property Topology: Routing track (ID 20237) are hidden and are not output in the reports.

Output topology routing points with length in the routing track:

If this check box is activated, the topology routing points and structure routing points at which a length is entered are output in the Topology: Routing track (ID 20237) property.

If in addition the setting Suppress unplaced topology routing paths in the routing track is activated, only the placed topology routing points and structure routing points in the routing track are included in the output.

Dialog Dimensions

Dialog call:

You have opened a project. The layout space navigator is open and a layout space is open. Insert > Device.

Use this dialog to enter the values for width, height and depth of the part to be placed prior to the placing of electrical engineering, Fluid power, and certain mechanical parts. The dialog is displayed automatically if no dimensions have been defined on the part selected for placement, and if no graphical macro has been assigned. Such parts can be used, for example, as variable prototypes for placement in small series or for a batch production in the parts management, without having to create full master data in the form of complete part definitions.

Note:

Manual input of part dimensions is not possible for all other mechanical parts from the "Mechanics" generic product group or parts from the "Process engineering" generic product group.

Overview of the main dialog elements:

Width, Height, Depth:

These fields are used to enter or modify the device-specific dimensions in the displayed measuring unit specified as the user setting. If some partial part dimensions are already entered at the associated part, the corresponding fields are filled with these values.

Write back dimensions to part:

If this check box is activated, the values entered in this dialog for the Width, Height, Depth are stored in the mounting data of the part to be placed. When this part is placed the next time, the dimensions are thus defined completely and the dialog Dimensions is no longer displayed.

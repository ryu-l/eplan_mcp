P017013: Device occurs both with a higher-level identification structure in the project as well as without one

Cause

During project creation in EPLAN you can determine that certain device types (which include terminal strips, plugs, cables, and / or interruption points) can be optionally handled with an identifier structure (e.g. "Higher-level function" and "Mounting location") or as sequentially numbered devices. For this purpose, the Project properties dialog provides the Superior check boxes in its Structure tab for these special device types. Sequential numbering becomes effective if you activate the check box and additionally remove the preceding sign "-" from the displayed DT.

In the current EPLAN version you have opened such a project for which the structure setting Superior was used for terminal strips, plugs, cables, and / or interruption points. Since this setting is, however, not supported in future versions, the check run shows which devices have to be corrected to keep on getting an error-free schematic documentation. In particular, the message contains the information whether the devices would be combined or if they would be assigned to different devices if the Superior setting is deactivated.

Solution

Standardize the identifier structure for all device types of the project:

  1. Prefix all displayed DTs of the associated functions of the device with a "-" preceding sign and correct the displayed DTs by adapting the structure identifiers so that all functions again belong to the same DT.
  2. Then start a new check run.

Note:

The usage of sequentially numbered terminal strips, plugs, cables, and / or interruption points in a project with a determined identifier structure is not norm-compliant. The structure setting Superior will not be displayed any more in the project properties dialog for these device types in the future.

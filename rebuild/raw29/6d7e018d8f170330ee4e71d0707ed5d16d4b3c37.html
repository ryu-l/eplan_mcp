Dialog <Format element>

Dialog call:

You have opened a project. Options > Settings > Projects > "Project name" > Devices > Numbering (offline). You have selected a user-defined scheme in the dialog Settings: Numbering (offline). In the Available format elements or Selected format elements field double-click a format element for a property.

In this dialog, you can edit the selected format element.

Overview of the main dialog elements:

Minimum number of digits:

The value in this field defines the minimum number of digits to be used.

Filler character:

Missing positions are filled in with this filler character. The number of digits filled depends on the value you entered in the Minimum number of digits field.

Example:

If you entered a value of "4" in the Minimum number of digits field and the value "0" as the Filler character, then the numbering will appear as follows: "0001".

Counter is a subcounter:

This field is only available for format elements of the "Counter" type.

If this check box is selected, the counter always starts counting from the start value as soon as the other numbering changes.
If the check box is deactivated, the counter is incremented independently of the other characters.

Use alphanumeric counter:

This field is only available for format elements of the "Counter" type.

If this check box is selected the alphanumeric counter is used. If not, a numerical counter is used.

Alphanumeric counter:

This field is only available for format elements of the "Counter" type.

When using the alphanumeric counter specify the characters here that are allowed to be used by the counter. Only alphanumeric characters are allowed.

Alphanumeric counters are sorted by character from left to right (in the same manner as Excel columns). If you have specified, for example, the characters "AKS", counting proceeds as follows: A, K, S, AA, AK, AS, KA, ..., AAA, AAK, AAS, AKA ..., AAAA, AAAK, ...

New Dockable Dialog for Editing Properties

The EPLAN Platform has been extended with a dockable property dialog for this version. The so called Property overview behaves like a navigator and can be docked at the EPLAN main window at different positions. To open this dialog select the menu items Edit > Property overview.

Benefit:

The property overview can be used to rapidly edit the properties of different objects without having to open and close multiple property dialogs one after another. You can configure this dockable dialog so that only the important properties are displayed for you.

In this dialog you can edit the properties of one or more selected objects (texts, graphical elements, functions, segments). In order for the desired properties to be displayed for the selected objects, you must select or create a fitting scheme for a property configuration. You can, for example, use the included "Format graphic" scheme for graphical elements. Otherwise the "No data" entry is displayed for the properties in the Value column.

To create a scheme, branch into a follow-up dialog via [...]. The familiar Configure properties dialog is used for the configuration of the properties. In the respective property selection you can select properties for the four source objects "Text", "Component", "Segment" and "Graphical element".

Further information on property overview:

  • The buttons (tree view) and (list view) are available to switch between a tree and list view in the property overview. The properties are grouped according to their source objects in the tree view.
  • The Filter field is available above the property table in order to limit the number of properties. Both the names of the displayed properties as well as the values are searched.
  • If a property is selected, you are shown additional information on this property in the lower area of the dialog.
  • Multiple selection of the same or different objects is possible. At different values an entry <<...>> is displayed for a property.
  • In the course of this extension the two menu items Non-function-specific properties and Format graphic as well as the associated dialogs were removed from the Edit menu. Corresponding schemes with configurable properties are available in the property overview for these functionalities.

Note:

Global editing of distributed functions in the Property overview dialog is not possible for the activated Properties (global) mode.

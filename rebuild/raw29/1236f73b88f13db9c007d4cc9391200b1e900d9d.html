Master Data: Forms

This section provides information about the most important modifications for the forms.

A new form has been created for the device connection diagram:

  • F05_004.f05 (file type "Device connection diagram"; for embedded reports)

With the following forms for the Terminal diagram placeholder texts in the header and data area were updated:

  • F13_008.f13
  • F13_008_en_US.f13

Outdated placeholders with the designation "via form position" were replaced with the designation "external" or "internal" (for example, "cable chart header via form position [A] / DT (full)" with "Cable chart header external / DT (full)").

Two forms for outputting the revision overview have been corrected.

  • F17_002.f17
  • F17_002_en_US.f17

The Regenerate header after change property has been added to the form properties of these forms and a specific value assigned. When the Revision name (change tracking) [1] property is changed, a new header is generated during reporting. In addition, the placeholder text "Page / Revision name (change tracking) [1]" has been replaced by the placeholder text "Project /revision name (change tracking) [1]" in the forms.

With the following forms for the Piping overview, the alignment boxes in the column headers were optimized:

  • F37_003.f37 (file type "P&I diagram: Piping overview")
  • F37_003_en_US.f37

This means that languages with longer words also do not exceed column borders anymore.

We would like to learn from you. In order to improve the help system continuously, we are documenting your behavior with Google Analytics (Additional Information & Opt-out).

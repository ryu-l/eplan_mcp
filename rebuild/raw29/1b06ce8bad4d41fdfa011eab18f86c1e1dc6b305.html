Inserting Hyperlinks

You have the option of inserting a text which contains a link to a document or an internet page on any page.

Precondition:

You have opened a project page in the graphical editor.

  1. Select the following menu items: Insert > Graphic > Hyperlink
  2. In the Properties dialog, select the Hyperlink tab.
  3. There enter the file, Internet or mail address to be linked as well as the text that is to be displayed on the page.
  4. Click [OK].
  5. When you have selected a file, you can decide in the Copy hyperlink dialog whether the file is to be copied into the project directory (that is, into the external document directory of the project) or whether the source directory is retained. (When inserting a URL, this dialog is not shown, since URLs are always called from their original location.) When an email address is inserted, the email program installed will automatically start up with a new email to the address specified.
  6. Click [OK].
  7. Place the hyperlink on the page like a normal text.

Example:

You have defined a hyperlink in the schematic to a document containing the technical information for transformer "-T1". You have chosen "Info T1" as a designation.

Open hyperlinks

  1. Keep the [Ctrl] key pressed and move the cursor over the hyperlink.

    The shape of the cursor will change to a hand.
  2. Click the left mouse button.

    The linked document is opened.

    Executed hyperlinks will not change the display color.

Tip:

You can also first select a hyperlink and then call up the linked document using the menu item Edit > Other > Open hyperlink.

Copy hyperlinks

  1. Click the hyperlink, keep the [Ctrl] key pressed down, and drag the hyperlink to the desired position.
  2. Release the mouse button and the [Ctrl] key.

    The hyperlink is copied.

Automatic detection of hyperlinks

If a hyperlink is entered as a value of a property, this property text is automatically detected as a hyperlink during the placement of a page in the graphical editor. This also functions if the text of this property is output in reports by means of a placeholder text. In an exported PDF such texts are also treated as hyperlinks.

XML Export / Import: Overview of Function Definitions

To be able to import and export parts data in EPLAN, the XML file must include a <functiontemplate> tag. This tag includes the attributes "functiondefcategory" (function definition: Category), "functiondefgroup" (function definition: Group), and "functiondefid" (function definition: Function definition). These three attributes together make up the function definition of a part.

The internal values listed in the following function definition tables are relative to the attributes listed above. The order is Category.Group.Function definition.

Performing Settings for Contact Image Display

The contact image settings can be assigned project-specifically, but they can also be set individually for each device. The component settings have priority over the project settings.

Setting a contact image project-specifically

Precondition:

You have opened a project.

  1. Select the menu items Options > Settings > Projects > "Project name" > Cross-references / contact image.
  2. Select the settings section General.
  3. Enter the characters for the labeling of the contact image table in the Contact image table group box.
  4. Also enter the values for the Width and Height of the contact image table in this group box.
  5. Select the settings section Contact image on component.
  6. Specify the default settings here that are to be considered for the display of contact images at components.
  7. Activate the check box Show in tabular form if the page number and column designation are to be entered in tabular form: in the cross-reference; the table headers for NO and NC contacts are taken from the setting Contact image table: Labeling (Settings section General).
  8. Activate the Table cross with variable length check box if the table cross is to be automatically adjusted to the maximum size of the contact image entries; in this case the setting Contact image table: Width / height (settings section General) is not considered.
  9. If the contact image is to be displayed in a different angle as the default setting, select the desired value in the Rotation field.
  10. If the article and/or type number at the contact image of the component is to be displayed at different positions, select the corresponding entries from the drop-down lists Display the 1st / 2nd part number and Display the 1st / 2nd part type.
  11. Select the settings section Contact image in path.
  12. Specify the presettings here that are to be considered for the display of contact images in the path of the component. (The entry possibilities are identical to those of contact images on components.)
  13. Click [OK].

    The settings are applied.

Setting contact images on components

Preconditions:

  • You have opened a project and selected a schematic page for editing.
  • You have opened the property dialog of a component for which you can define a contact image (for example general devices, cables or shields) with a double-click.
  1. In the Display tab of the property dialog select the Contact image tab below the property arrangement.
  2. Click (New).
  3. Select the contact image alignment "In path" or "On component" in the dialog Generate contact image.
  4. Mark the selected contact image alignment in the Contact image tab.
  5. Activate the check box Align automatically in the Property / Assignment table of the Position hierarchy level, if EPLAN is to automatically position the contact image vertically below the associated main function.
  6. Deactivate the check box if you want to specify the contact image position itself and enter values by which the contact image is to be moved into the fields X coordinate and Y coordinate.
  7. Activate the User-defined check box in the Settings hierarchy level, if you do not want to apply the settings from the project settings.
  8. In the different settings of this hierarchy level specify how the contact image is to be displayed for the currently selected device.
  9. Click [OK].

    The contact image is placed in accordance with the settings at the component.

Note:

You can change the component-specific setting at any time by double-clicking the device and then either selecting another contact image alignment via (Edit) in the dialog Generate contact image, changing the settings for the Contact image tab in the table Property / Assignment or removing the contact image via (Delete).

Globally Changing the DT at Functions

You can change the DT of all functions and representations of a device in a single action. It is also possible to change the DT only in particular representations of a function, e.g., single-line, or only in the selected function.

Preconditions:

  • You have opened a project.
  • You have opened the graphical editor or the device navigator.

Change the device tag in all functions and representations of a device

If a device contains, for instance, main functions, auxiliary functions, and different representations of functions, then you can change the DT for all functions and representations at the same time.

  1. Activate the Properties (global) mode via the Options > Properties (global) menu items.
  2. Open the property dialog for a function of a device, for example via the Edit > Properties menu items.
  3. In the Properties (global): <...> dialog, select the <Function category> (Device) tab of the main function .

    The tab shows the properties of the device.
  4. Click [...] next to the Full DT field.
  5. Change the DT in the Full DT dialog.
  6. Confirm your entries.

    The DT will be changed in all functions and representations of the device.

    If functions are changed in a device-wide change, which are not identical with the selected function, then the warning dialog Save change to DT is shown. Click [Yes].

Tips:

  • You can also directly change the DT for all function representations of the device. Select a device in the device navigator and then select the Rename popup menu item. Directly enter the new DT.
  • Using the Properties (global) popup menu item, you can carry out device-wide modifications for the selected function without having to activate the Properties (global) mode previously.

Change device tags in all representations of a function

If a device contains, e.g., main functions, auxiliary functions, and different representations of the functions, then you can change the DT for all representations of one function at the same time.

  1. Activate the Properties (global) mode via the Options > Properties (global) menu items.
  2. Open the property dialog for a function of a device, for example via the Edit > Properties menu items.
  3. In the Properties (global): <...> dialog, select the <Function category> tab of the selected function.

    The tab shows the properties of the function.
  4. Click [...] next to the Full DT field.
  5. Change the DT in the Full DT dialog.
  6. Confirm your entries.

    The DT is changed in all representations of the selected function.

Change device tags in the selected function

If a device contains, for instance, main functions, auxiliary functions, and different representations of functions, then you can change the DT exclusively for the selected function.

  1. Deactivate the Properties (global) mode via the Options > Properties (global) menu items.
  2. Open the property dialog for a function of a device, for example via the Edit > Properties menu items.
  3. In the Properties (global): <...> dialog, select the <Function category> tab of the selected function.

    The tab shows the properties of the selected function.
  4. Click [...] next to the Full DT field.
  5. Change the DT in the Full DT dialog.
  6. Confirm your entries.

    The DT is changed in the selected function.

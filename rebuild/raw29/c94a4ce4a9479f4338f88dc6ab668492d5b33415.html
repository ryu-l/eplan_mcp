Extended Settings for the Connection Numbering

In the settings of the connection numbering you can specify which connections are to be numbered, how often the connection designations should be placed, and how the connection designations should be formatted. Save these settings in a scheme. A menu path to these settings is: Options > Settings > Projects > "Project name" > Connections > Connection numbering. You have the following extended possibilities when specifying the format for the connection designations:
- Using page properties for the connection numbering
- Suppressing the first counter.

Using page properties for the connection numbering

In the Designation tab of the Settings: Connection numbering dialog you specify the format for the connection designations. To this purpose you now have the possibility to select page properties of the source and target function for display in the connection designations.

Benefit:

By means of the new format elements "Data of the page of the source function" and "Data of the page of the target function", that you can use in the schemes for the connection numbering, you can have the page properties of the source and target function displayed in the connection designation.

To this purpose two new format elements are available in the Connection numbering: Formats dialog:

  • Data of the page of the source function: Outputs properties of the schematic page on which the connected source function is placed.
  • Data of the page of the target function: Outputs properties of the schematic page on which the connected target function is placed.

Suppressing the first counter

If you have selected a format element of the type "Counter" or "Subcounter" in the Connection numbering: Formats dialog for editing, you then subsequently specify the formatting for a counter or subcounter in the Format: Counter dialog.

With the Suppress first subcounter check box you could previously only suppress the first subcounter on the page, in the column, etc. Now this setting also acts on a counter. Therefore the check box has been renamed:

Old designation

New designation

Suppress first subcounter

Suppress first counter / subcounter

Including following separator

Including previous separator

As part of this extension the check box Including following separator has also been renamed. By activating this check box you can - together with the first counter or subcounter - also suppress the previous separator.

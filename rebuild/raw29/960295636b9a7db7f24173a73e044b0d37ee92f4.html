Placeholders in Forms and Plot Frames

The placeholders available are divided into the following different areas:

  • Form type-dependent placeholders: These placeholders are available only in certain form types. They are, for instance:
    Terminal diagram placeholders like saddle jumpers, wire jumpers, etc.
    Terminal connection diagram placeholders like shields, cable definition lines, etc.
    During the evaluation of the form, EPLAN automatically replaces these placeholder texts with the corresponding values of project objects on which the report is being run, such as devices, pages, symbols, etc.

    • Note:

    If the placeholder does not have an alignment box, or it has an alignment box and the Remove breaks check box is also selected (under the Border) property, line breaks are filtered out in the reports.

  • Special texts for forms and plot frames: A difference is made between project and page properties. These properties are filled with the appropriate data when inserted
  • Row and column texts for plot frames: These special texts can be inserted in order to display the numbers of the plot frame grid and thus arrange it more clearly.

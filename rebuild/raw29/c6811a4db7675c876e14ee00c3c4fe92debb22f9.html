Importing / Exporting Settings

In the Settings dialog, you can use a popup menu command to import, export, or export and add the tree view settings. The last option allows you to add extra settings areas to an already exported file. Exported settings are stored in an XML file that can be imported.

Note:

There is no other option for specifying more settings areas for project and company-specific settings.

Import settings

Precondition:

You have access to an import file *.xml.

  1. Select the following menu items: Options > Settings
  2. In the tree view of the Settings dialog, select the structure level into which you wish to import the settings.
  3. Click (Import).

    If you have selected one of the settings areas "User" or "Workstation", the Import settings dialog will open.

    If you have selected one of the settings areas "Projects" or "Company", the Import settings: <Hierarchy path dialog is opened. Here you can specify the source file.
  4. To import global settings, select the uppermost check box.
  5. To import further program settings and configurations, in the Other settings areas group box, select the check box for each desired settings area.
  6. Next to the Source file field, click [...], and select the *.xml import file.

    The settings are imported.

Export settings
  1. Select the following menu items: Options > Settings
  2. In the tree view of the Settings dialog, select the settings area that you wish to export.
  3. Click (Export).

    If you have selected one of the settings areas "User" or "Workstation", the Export settings dialog will open.

    If you have selected one of the settings areas "Projects" or "Company", the Export settings: <Hierarchy path dialog is opened. Here you can specify the target file.
  4. To export global settings for the selected settings area, select the uppermost check box.
  5. To export further program settings and configurations, in the Other settings areas group box, select the check box for each desired settings area.
  6. In the Target file field, check the file path and name, or use [...] to define a different file path and name.

    A file path and name reflecting the area selected in the tree view is already entered into the Target file field.

    Example:

    You have marked the area User > Display > General in the Settings dialog. The program suggests the name <User>+<Display>+<General>.xml.

  7. Click [OK].

    The settings are saved as an XML file under the specified name in the specified directory.

Note:

If you only select a single main category or sub-category in the tree view, all lower level settings areas are also included in the export.

Export and add settings

Preconditions:

  • You have opened a project.
  • You have access to an export file into which you wish to export further settings.
  1. Select the following menu items: Options > Settings
  2. In the tree view of the Settings dialog, select the desired main category, sub-category, or settings area that you wish to add to an already exported file.
  3. Select the Export (append data) popup menu item.

    If you have selected one of the settings areas "User" or "Workstation", the Export settings (append data) dialog is opened.

    If you have selected one of the settings areas "Projects" or "Company", the Export settings (append data): <Hierarchy path> dialog is opened. Here you can specify the target file.
  4. To export and add global settings for the selected settings area, select the uppermost check box.
  5. To export and add further program settings and configurations, in the Other settings areas group box, select the check box for each desired settings area.
  6. Select the existing export file in the Target file field.
  7. Click [OK].

    The settings are added to the selected export file.

Note:

When exporting and adding settings, the file name is not automatically expanded. For this reason, we recommend renaming the extended export file, or saving it in a separate directory.

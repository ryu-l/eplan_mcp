Extensions in Layer Management

The layer management has been restructured for this version into a dockable dialog. All modifications in the new layer management dialog are saved automatically. In addition the layer management has been extended with new functions such as the finding of layers and the changing of the layer allocation.

As part of this extension it is now also possible to specify the display and sequence of the columns in the dialog via the added popup menu item Configure representation.

Benefit:

Because the layer management now behaves analog to the navigators or the message management, you can place the layer management in such a way that for example the graphical editor is not covered and the modifications for the layers are visible immediately. The new functionalities in the layer management allow a specific and comfortable editing of layers and the objects that they are using.

Find layers

You can now find all objects in the layer management that have a specific layer assigned in a project or one of its sections. To this purpose the new button (Find) is available to you in the toolbar of the layer management. This way you can, for example, find and correct layers that were added to the project with a DXF / DWG import or that are used as user-defined layers in the project.

Before performing the search, first select the layer that you want to find in the layer management. Then select the project to be searched through in the page navigator. If you do not want to search the complete project, you can also restrict your search range.

All objects to which the searched layer is assigned are displayed in the Search results - <Project name> dialog.

Change layer assignment

Subsequently you can open the property dialog of a found object in the search results list and change the assignment of the searched layer manually there. Or click the new button (Change layer assignment) in the layer management and modify the assigned layers this way for one or more found objects.

With the new button you can also change the layer assignment for other selected objects (individual pages / layout spaces or objects on pages / in layout spaces).

In the following dialog you use the fields Source layer and Target layer to specify which source layers you want to replace through which target layers for the selected object(s).

User defined source layers to which no object is assigned any more can then be deleted.

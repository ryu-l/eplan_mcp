Tab Numbering (Changing Standards)

Dialog call:

You have opened a project. In the case of several opened projects: You have selected a project in the page navigator. Utilities > Change of standard. You have specified all of the settings in the Project tab. [Next]. You have specified all of the settings in the Rotation / flipping tab. [Next]. You selected the check box in the Master data tab in a symbol library row in the Individual assignment column. [Next]. You have specified all of the settings in the Symbols tab. [Next]. You have specified all of the settings in the Structure tab. [Next].

In this tab, you can specify that all devices of the target project should be renumbered. This is useful, for example, if the project structure of the source project does not match that of the target project.

Overview of the main dialog elements:

Renumber devices:

If this check box is selected, the devices are numbered.

Device numbering:

This drop-down list shows all user-defined and pre-defined schemes for online device numbering. User-defined and pre-defined schemes for device numbering are taken from the template that you specified when creating the target project. Use [...] to open the Settings: Numbering formats dialog where you manage and edit the schemes.

Data backup

While working with EEC, the following data are changed:

  • Database,
  • Resources,
  • User preferences (Workspace).

Particularly in the case of an update, the modified data must be applied.

Note:

If the database to be imported was created using an older version of EEC, you have to update the model first (see Updating a model).

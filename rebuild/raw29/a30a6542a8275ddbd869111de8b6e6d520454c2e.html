Function-related Reports

In contrast to Report overviews, function-related reports have a device in the header as standard, e.g., a terminal strip. The associated functions are in the data area, e.g., the terminals of a terminal strip.

Function-related reports can only occur once in the project.

Example:

A terminal diagram of terminal strip X1 may occur only once in the project.

The following tables show function-related reports.

Symbols from symbol libraries stored in the project.

Reporting behavior

Function-related report

Terminal line-up diagram (*. f12)

Enclosure information

Report type

Enclosure legend

Reporting behavior

Function-related report

Form

Enclosure legend (*. f18)

Description

Project data of part placements. Shows the relationship between the parts in the schematics, the part position in the bill of materials, and the graphical object or part placement on the mounting panel. All part placements are allocated a sequential number. The enclosure legends can be created as report pages or inserted as "Free placements" into a page of type "Panel layout".

(See also: Generating Enclosure Legends)

Other connection diagrams

The following table shows report types for function-related connection diagrams, following the targets of connection points over multiple devices.

Connection points by device

Report type

Device connection diagram

Reporting behavior

Function-related report

Form

Device connection diagram (*. f05)

Description

Lists the connection points of devices. Sorting by device.

Connection points by cable

Report type

Cable-connection diagram

Reporting behavior

Function-related report

Form

Cable connection diagram (*. f07)

Description

Lists the cable connections of the cables (as for a cable diagram, but with other forms and over several layers). Sorting by cable.

Connection points by terminal strip and terminal

Report type

Terminal-connection diagram

Reporting behavior

Function-related report

Form

Terminal-connection diagram (*. f11)

Description

Lists the terminals on the terminal strips (as with a terminal diagram, but with other forms and over several layers). Sorting corresponds to the order of the terminals on the terminal strip. Connected targets are displayed.

Connection points by plug and pin

Report type

Pin-connection diagram

Reporting behavior

Function-related report

Form

Pin-connection diagram (*. f21)

Description

Lists the pins (as in a plug diagram, but with other forms and over multiple layers). Sorting corresponds to the order of pins in plugs. Connected targets are displayed.

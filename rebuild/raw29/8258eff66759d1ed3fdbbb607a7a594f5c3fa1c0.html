Dialog Format: Separator

Dialog call (Online numbering):

You have opened a project. Options > Settings > Projects > "Project name" > Devices > Numbering (online). Click [...] next to the Numbering format field in the Settings: Numbering (online) dialog. Select a user defined scheme from the Numbering formats dialog. In the DT or Designations tab, click [...]. Double-click the "Separator" format element in the DT format dialog.

Dialog call (PLC address formats):

You have opened a project. You have opened the Settings: PLC dialog (for example via the Project data > PLC > Settings menu items). You clicked [...] next to the PLC-specific settings field in the Settings: PLC dialog. You have selected the Address formats tab and have clicked [...] next to the field for the desired address format in the Settings: PLC-specific dialog.

In the Format of PLC address dialog, in the Available format elements list, select a format element of the Separators type and click (Move to the right) (or double-click an already defined separator in the Selected format elements list).

In this dialog you specify the formatting for a separator in the format group.

Overview of the main dialog elements:

Blank:

If this option is activated, then a space is used as the separator. The number of spaces is entered in the field Number of characters.

Other characters:

If this option is activated, you can enter the required character combination to be used as the separator in the field below. Any digits, letters, and special characters can be used.

Number of characters:

This field is available if the option Blank is selected. The number in this field specifies the number of spaces to be displayed as separators in the numbering format. If you select Other characters, this field is grayed out and displays the specified number of characters.

Exporting a Copper Unfold

To transfer the fabrication information to bending machines and drilling / milling robots, the unfold of the copper item is evaluated. This also takes into consideration the information for edgewise bending. To allow for mechanized cutting of unbent copper rails, unbent copper rails with the "Busbar" function definition are included in the export.

Two export formats are available:

  • Export Copper DXF: Graphical export of the unfold in the DXF format
  • Export Copper NC: Export of the unfold in the XML format.

As an example, the Export Copper NC is described here.

Preconditions:

  • You have opened a project that contains layout spaces with placed copper items.
  • The bending table in the company settings is up-to-date.
  • Unfolds have been generated for the copper items.
  1. Select a copper item from which an unfold has been generated in the layout space navigator or in the 3D display area.
  2. Select the menu items Utilities > Manufacturing data > Machining > Copper NC.
  3. In the Export copper NC dialog, select a machine definition, an output directory, a target file, and a material.
  4. Click [OK].

    The target file is generated in the specified directory. It can now be transferred to the machine.

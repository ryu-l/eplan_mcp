Creating and Editing Pipe Classes and Substances

Pipe classes and substances are created and managed in the segment template navigator.

You edit the properties of a pipe class or of a substance in <Pipe class displayed name> or <Substance displayed name> tab of the property dialog.

Creating pipe classes

  1. Select the following menu items: Project data > Pre-planning > Segment template navigator.
  2. Mark a "segment definition" for the pipe class (for example "Pipe class general"), and select the New pipe class popup menu item.
  3. Enter the identifying name and an optional description for the new pipe class in the <Pipe class displayed name> tab in the dialog Properties <...>.
  4. If necessary, assign further properties to the pipe class. You have to assign the desired properties to the selected "segment definition" for the pipe class beforehand in the dialog Configure segment definitions so that user-defined properties are available for selection in the property selection for the Properties table.
  5. If necessary, enter a part in the Part tab. Only those parts that are assigned to a pipe class can be selected later on during a part selection at the segments.
  6. Click [OK].

    A pipe class with the appropriate properties is created.

The procedure for creating substances via the popup menu item New substance is analogous. In this case the assignment of parts is not possible.

The created pipe classes and substances are available in the project for selection at the segments of the pre-planning and at the piping definition points and piping connection points in the P&I diagram.

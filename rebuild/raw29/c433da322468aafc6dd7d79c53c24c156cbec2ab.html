Dialog Field assignment (importing devices / routing connections) / Dialog Settings: Import

Dialog call Field assignment dialog:

You have opened a project.

  • Project data > Devices > Import. In the Import device data dialog, click [...] next to the Field assignment field.
  • Project data > Connections > Import > Routing connections. In the Import connection data dialog, click [...] next to the Field assignment field.

Dialog call Dialog Settings: Import:

You have opened a project.

  • Options > Settings > Projects > "Project name" > Devices > Import
  • Options > Settings > Projects > "Project name" > Routing connections > Import

In the Settings: Import dialog, you create and edit the schemes with settings for the field assignment during the import of devices and routing connections. These settings are selected and applied in the dialog Field assignment.

The Field assignment dialog allows the assignment of an external data field from the data source to an EPLAN property. The assignments can also be selected, stored and edited as a scheme.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent toolbar for this purpose.

Table toolbar:

Button

Meaning

(New)

Generates a new line.

Only in the Field assignment dialog in lines with the status : Enables a data field designation that has not yet been assigned for editing.

(Delete)

Deletes a selected row.

Table:

The following columns are displayed in the table:

  • Status: The icon shows that the data field only exists in the scheme. These rows are not considered during the import and can be deleted by using the (Delete) button.
    Only in the Field assignment dialog: The icon indicates that the data field exists in the data source and could be identified.
  • Column number: For entering a column number that is used to select the data fields in the external data source from which the data are to be imported.
  • External data field name: This column displays the data field names of the external data source. If no row with data field names exists in the data source, nothing is displayed here.
  • Property: This column displays the EPLAN property that is assigned to the external data field. In order to assign a property, click a cell in the Property column. Use [...] to open the Property selection dialog and select a property.

Tip:

In the Field assignment dialog all the cells of a row have a gray background, when the data field name that was found in the external data source has not yet been assigned to an EPLAN property. In this case the data field has the status of (Data field does not exist in scheme).

For the field assignment click a cell in a row with a gray background and then click the (New) button in the toolbar of the table. The remaining cells of this row can then be accessed for entries.

Publishing Projects

You can publish a project by exporting it to a file of the EPDZ file type. Using a mobile application provided by EPLAN, the EPLAN View App, the project content can be displayed on mobile devices by means of the dropbox (for example iPad). The EPDZ file contains, in compressed form, the complete project structure (project properties, page properties, layout space properties, function properties). For each project page, a file with the 2D vector graphic (*.svg) and for each layout space, a file with the 3D graphical data (*.e3d) is included.

Precondition:

You have opened a project.

  1. Select the menu items Project > Publish.
  2. In the Publish dialog, select a scheme with the export settings. If no scheme exists yet, use the [...] button to call up the dialog Settings: Publish and there generate a new scheme.
  3. If you want to save the EPDZ file under a different name than the project name, enter a new file name in the EPDZ file field, or select an existing file name to overwrite via [...].
  4. In the Export medium group box select whether the EPDZ file is to be saved on a storage medium or sent as an e-mail.

    When publishing to storage media, you can save the EPDZ file to a USB device, or burn it directly to a CD / DVD.

    When publishing as an e-mail, you can send the EPDZ file directly to a mobile device.
  5. If you want to save the file to a storage medium, enter the storage location for the EPDZ file to be exported in the Publish dialog in the Output directory field.
  6. Click [OK].

    The exported project *.epdz is saved in the target directory or sent as an e-mail.

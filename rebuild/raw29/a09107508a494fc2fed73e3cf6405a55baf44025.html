Managing Multilingual Parts Data

If you want to use foreign-language designations, for instance for deliveries overseas, you can create and edit the parts master data in different languages. Multilingual entries can, e.g., be managed for the Designation 1 -3 and Description fields in the General tab or for the descriptive texts in the Free properties tab. A list of the possible multilingual properties for parts management can be found in the user-specific translation settings (Settings: Parts management dialog / Parts management tab).

Define translation settings

  1. Select the Utilities > Parts > Management > [Extras] > Translation > Settings menu items, and bring the Project-independent tab to the foreground.
  2. Select the translation languages, into which the part text is to be translated, from the Languages list: Use the buttons above the field to add or delete languages.
  3. In the Source language field you define the source language for the translation of non-project-specific texts. From the drop-down list you can select either the dialog language or a language that you have already set as translation language.

    When translating, EPLAN searches the dictionary for suitable keywords for this language and translates them into all the selected translation languages. If the ##_## (dialog language) option is selected, the source language is automatically matched to the dialog language currently set in EPLAN.
  4. Click [OK].

Translate text automatically

Preconditions:

  • You have opened parts management.
  • You have positioned the mouse cursor in one of the multilingual fields for one or more part(s) and entered the text in the source language.
  1. Select the Translate popup menu item.

    If there are already translations in the dictionary for the term you entered, the Found words dialog is opened, listing all the texts in the source language beginning with the letters entered.
  2. In the Found words dialog, select the matching translation text by double-clicking.
  3. Edit the translation text in the Translate dialog.

    If there are no translations in the dictionary, the Translate dialog is launched to enable you to enter a new translation text.
  4. Click [OK].

Example:

Enter the text "Tacho" into the "Designation 2" field. Select the Translate popup menu item. The Found words dialog lists the following entries:
DE: Tacho EN: Tachometer
DE: Tachogenerator EN: Tachometer generator
Double-click the entry you want. The Multilingual input dialog opens and you can edit the translation.

Enter translation texts

Preconditions:

  • You have opened parts management.
  • You have positioned the mouse cursor in one of the multilingual fields for one or more part(s) and entered the text in the source language.
  1. Select the Multilingual input popup menu item.
  2. Enter the translation text in the subsequent dialog.
  3. Click [OK].

Delete translation texts

Precondition:

  • You have opened parts management.
  • You have positioned the mouse cursor in one of the multilingual fields for one or more part(s) and entered the text in the source language.
  1. Select the Remove translations popup menu item.

    The translation texts of the currently selected field are deleted.

Import part texts

  1. Select the Utilities > Parts > Management > [Extras] > Translation > Import part texts menu items.
  2. In the Select languages dialog, select the languages whose texts are to be imported into the dictionary and click [OK].

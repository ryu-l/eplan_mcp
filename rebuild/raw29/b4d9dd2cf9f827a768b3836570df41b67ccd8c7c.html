Master Data: Schemes

This section provides information about the most important modifications for the schemes.

The following new schemes have been created for the filter in the Page navigator:

  • Automatic pages
  • Interactive pages
  • Plants
  • Document type
  • Mounting location

By means of the new filter scheme, you can filter the project pages both for pages of the respective page type (interactive or automatically generated report pages) or for structure identifiers for the identifier blocks "Higher-level function", "Mounting location" or "Document type".

PLC

The schemes for determining the Address formats of PLC addresses in the Settings: PLC-specific dialog have been revised and schemes no longer required have been deleted.

The following scheme was created for PLC addressing in the format for the Rockwell ControlLogix product family:

  • Allen-Bradley (ControlLogix)

In the course of this change, the project template and the basic project "Inch Template" were changed to the new scheme Allen-Bradley (ControlLogix) .

The schemes for address formats listed below have been deleted. These are schemes for systems, whose hardware is not available anymore or schemes for PLC configuration programs that cannot be run on current software anymore.

  • Allen Bradley PLC-5
  • BOSCH
  • ESS PC WORX
  • PL7
  • PS40
  • SIMATIC S5 (E/A)

Furthermore, the Rexroth scheme has been renamed to Bosch Rexroth.

Pre-planning

The following new scheme has been created for the export of manufacturing data / output of labeling in the Export manufacturing data / Output labeling dialog:

  • PCT loops VDI 3814

EPLAN Pro Panel

The following new scheme was created for the filter in the layout space navigator:

  • Mounting aids

By means of this new filter scheme, you can have the used mounting aids (mounting points, mounting lines, etc.) specifically displayed in a project.

Positioning and Formatting of Cable Properties

The properties of cables and shields (e.g. the DT) can be displayed on the symbol in the schematic, like with other devices. Four different angles can be specified when doing this.

Certain default configurations are delivered for the Property arrangement field, from which you can select the desired arrangement (in the Display tab of the property dialog). These arrangement configurations affect the placement of the DT and all additional property text docked on it.

If you have selected this type of default arrangement configuration, then the arrangement of the property text will remain, even after changing the extent of the cable definition line or shield. The position of the property text is also recalculated.

The text alignment is also dependent on those positions. This way the text will extend up and to the left in the case of "Upper left", for example.

However, you can also freely set the positioning and formatting of properties (user-defined property arrangement). In doing so the position is always specified relative to the insertion point. When moving the insertion point of the cable definition line (or the shield) the displayed properties move as well.

Example:

You have drawn a shield and opened the property dialog. Various default configurations are offered in the Property arrangement field of the Display tab. Select, for example, the configuration Shield designation, right top, 0Â°. The shield designation is then displayed at the top right, next to the shield.

Alternative cross-section / diameter

For cables and connections, an alternative cross-section / diameter can be specified, along with a corresponding alternative unit. These properties are independent of the parts management and must be manually filled and reported. These properties make it possible to define the connection cross-section / diameter in parallel in different units (e.g., AWG and mmÂ²). The properties are available in the property dialog for cables and connections, and can be used in reports.

For cables:

  • Cable / Conduit: Alternative cross-section / diameter
  • Cable / Conduit: Unit for alternative cross-section / diameter
  • Cable / Conduit: Alternative cross-section / diameter with unit.

For connections:

  • Alternative connection cross-section / diameter
  • Alternative connection cross-section / diameter with unit
  • Unit for alternative connection cross-section / diameter.

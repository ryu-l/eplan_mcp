Partial routing paths

User interface / operation

Partial routing paths are routing paths with the function definition "Topology partial routing path". They serve the distributed representation of a routing path and connect two routing points respectively on different topology pages with each other. Partial routing paths are used to connect routing path networks with each other that are located at different heights (for example on different floors of a building). You can have the height difference displayed at partial routing paths. This specifies the vertical distance between the routing path networks.

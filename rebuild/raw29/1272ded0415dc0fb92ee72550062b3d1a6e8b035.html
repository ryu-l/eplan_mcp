Editing Objects in Tables

Preconditions:

  • You have opened a project.
  • You have opened a navigator (page navigator, device navigator, etc.) or the graphical editor.
  1. Mark the desired objects on a project page on in a navigator, and select the menu items Edit > In table.

    The data of the marked objects are displayed in tabular form in the dialog Edit in table - <Project name>. If more than one object type is contained in the selection, separate tabs, such as Functions, Connections, etc. are displayed for the respective object types.
  2. For functions and connections, select a different scheme as needed to change the display of the columns.
  3. Change the desired properties in the corresponding fields.
  4. Close the dialog via , or click another (open) dialog.

    The changed data is adopted.

Notes:

  • If you modify the selection while the dialog is open, you must update the display in the dialog via the Edit in table popup menu item.
  • If you change the value of a connection property for Connections, this changed value will be transferred both to the connection and to all associated connection definition points at which the property was filled. Empty properties are not overwritten.
  • If a connection does not have connection definition points, and you modify the value of a property, a connection definition point will be placed automatically, and the property value will be entered there.

Example:

You would like to change the technical characteristics in all contactor coils on circuit diagram page "=AP+ST1/3". To do so, select a contactor coil, and select the Highlight objects of same type popup menu item. All contactor coils on the page are selected. Then, select the Edit in table popup menu item. The data from the contactor coils is displayed in the Edit in table - <Project name> dialog.

For the first contactor coil, enter the value "24-240V" in the Technical characteristics field. Then, copy the value via the popup menu, mark the cells in the Technical characteristics column for the remaining coils, and paste the value there using the popup menu. After this change is made, click on the graphical editor once with the mouse. The changed technical characteristics will immediately be shown on the coils.

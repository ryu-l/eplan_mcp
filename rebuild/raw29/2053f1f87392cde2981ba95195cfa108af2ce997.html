Icons in the Navigators

The following table lists the most important icons and their meaning that are used in several project data navigators.

If you position the cursor on an icon in the tree views of the project data navigators, you are seeing a short information text (tooltip) about this icon. If icons are combined (for example for a placed multi-line main function), a separate tooltip is displayed for each icon.

Specific icons are explained in the respective navigator dialogs.

Notes:

  • The icons for the various representation types and for the special functions (for example black boxes, cable definitions, etc.) are often used in combination with other icons. Thus the preceding icon means a main function (for example multi-line main function).
  • In the navigators for displaying devices all the devices that have only a device tag but no structure identifiers such as higher-level function, mounting location, etc. are sorted into the Without structure identifier tree structure level. All the devices that do not have a DT are sorted into the Without DT tree structure level.

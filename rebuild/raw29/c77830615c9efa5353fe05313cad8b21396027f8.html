Dialog Settings: Part selection (project)

Dialog call:

You have opened a project.

  • Options > Settings > Projects > "Project name" > Management > Part selection.
  • You have selected a main function in the graphical editor or in a navigator. Edit > Properties. Select the Parts tab. [Settings] > Part selection (project).

Use this dialog to determine for the entire project which data sources will be used for part selection.

Overview of the main dialog elements:

Part selection:

Select one of the following options:

  • User-defined: For parts selection, the user-defined settings you define under Options > Settings > User > Management > Part selection are used.
  • Project: For part selection, only those parts are offered which are stored in the project. These are stored in a project parts database which is generated from the stored parts. After changes to the parts data, you must regenerate the project parts database using [Update].
    Please take into account that all Microsoft Office applications have to be installed in the 64-bit version for this change!

[Update]:

Click this button to regenerate the project parts database from the stored parts.

Parts preselection:

Select an existing scheme (meaning a list of parts) from the drop-down list. Then, during part selection only those parts will be offered that appear in the selected list.

With [...] the Parts preselection dialog opens and you can create a new list of parts to save it as a scheme or change an existing list.

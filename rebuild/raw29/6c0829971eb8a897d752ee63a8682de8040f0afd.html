Dialog Copy external files to project

Dialog call:

You have opened a project.

  • Edit > Other > Links.
  • You have selected a project in the page navigator. Project > Back up > Project. Click [Links] in the Back up projects dialog.
  • Options > Settings > User > Data backup > Default settings > Projects. Click [Links] in the Settings: Projects dialog.

In this dialog you can copy image files and external documents referenced in the project or associated master data into the current project.

Overview of the main dialog elements:

File:

This column shows all external documents linked with the project as pages of page type "External document" or as hyperlinks. Image files referred to in the project or the master data (symbols, forms, plot frames) are also listed here.

Copy:

Select the check box(es) for the file(s) to be copied into the current project.

If the check box next to a file is deselected, then the file is not copied and remains as a reference link in the project.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

In addition, the following dialog-specific popup menu items are available:

Menu item

Meaning

Select all

Selects the check boxes for all listed documents.

Deselect

Deselects all check boxes.

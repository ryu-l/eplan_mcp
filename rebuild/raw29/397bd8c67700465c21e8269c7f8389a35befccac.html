Multi-user Monitor: Procedure

With the information from the multi-user monitor you can manage your work in such a way that obstacles in multi-user operation are minimized. To do this, you can get information from the dialog before starting an action or while executing it.

To open the multi-user monitor, select Project > Multi-user monitor. The Progress column shows the progress of the actions that have been started with a progress bar and a percentage figure.

Get information from the multi-user monitor before the action

In multi-user operation, you wish to start a lengthy action for an open project (e.g. a check run for an entire project, report on an entire project, etc.). For this purpose you first use the monitor to find out whether another user has also initiated a lengthy action for the current project.

If this is not the case, start the required action.

If a lengthy action is being executed for the current project, you have the following options:

  • You accept that execution will be lengthy and start your action nonetheless.
  • You can postpone your action to later.
  • You can contact the other user to discuss things. To do this you can, e.g., click the other user's user ID in the User column and send an e-mail.

Get information from the multi-user monitor during the action

You start a lengthy action. Because the action is taking longer than usual to execute, you open the multi-user monitor. Here you find out whether the delay is being caused by multi-user operation.

If it is, you have the following options:

  • You accept that execution will be lengthy and wait until your action is finished.
  • You stop your action by clicking [Cancel]. You can then - as stated previously - contact the other user to discuss things.

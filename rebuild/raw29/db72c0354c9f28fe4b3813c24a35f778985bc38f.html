Inserting Form Graphics

Certain placeholders can be replaced not by text during the evaluation run, but rather by graphical symbols, where the assignment to the respective graphic is defined in the Form properties - <Form name> dialog. The following placeholder texts are available:

  • Assignment: Index to graphic [1-100]: Replaces the placeholder with the symbol that was stored in the Assignment: Index to graphic dialog for the respective index.
    The index here is the index of the placeholder in graphic 1 to 100. In the form properties, you can assign a symbol to every index. If you then place the Assignment: Index to graphic [n] property in the form, the symbol assigned to index n is always placed here.
  • Assignment: Function definition to graphic: Replaces the placeholder with the symbol that was stored in the Assignment: Function definition to graphic dialog for the corresponding function definition.
    If you then place the Assignment: Function definition to graphic property in the form, a symbol is placed based on the function definition of the function to be output.
  • Assignment: Property / value to graphic [1-10]: Replaces the placeholder with the symbol that was stored in the Assignment: Property / value to graphic dialog for the corresponding property.
    If you then place the Assignment: Property / value to graphic [n] property in the form, a symbol is placed based on the value of the selected property of the function to be output. This can be the Graphical display in reports [1] and Graphical display in reports [2] properties for terminals, for instance, but any other properties can be used.

There are also special placeholders for generated graphics that are used in terminal diagrams, terminal bills of materials, and terminal connection diagrams as jumper graphics. For example, these include the placeholders "Graphic for saddle, insertable and wire jumpers", "Graphic for internal wire jumpers", "Graphic for saddle jumpers", etc.

Preconditions:

  • You have opened a project.
  • You have opened a suitable form in the form editor in which you want to replace placeholder texts with graphics (Utilities > Master data > Form > Open > [Open]).
  • You specified the assignments Index to graphic, Function definition to graphic and Property / value to graphic in the dialog Form properties - <Form name>.
  1. Insert > Placeholder text
  2. Click [...] in the Property field of the Placement tab on the Properties (placeholder text) dialog.
  3. Select the element (e.g. terminal properties) for which placeholder text is available for graphics in the Placeholder text - <Form type> dialog.
  4. Select the desired assignment type.
  5. Click [OK].

    The property is adopted in the Property field of the Placement tab.
  6. Click [OK].

    The element hangs on the cursor.
  7. Position the placeholder text on the form page.

    The element hangs on the cursor.
  8. Position the placeholder text a second, third ... time.
  9. Select the Cancel action popup menu item to exit the action.

    The placeholder text is placed on the form page and replaced with the graphic selected in the form properties in the appropriate report.

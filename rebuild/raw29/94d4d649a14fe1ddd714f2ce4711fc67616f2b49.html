Action: XGedStartInteractionAction


Parameter

Description

Name

Name of the interaction to be started. Possible interactions are:

  • XGedIaFormatDefPoints: Set the format of the connection graphic (connection definition point, potential definition point)
  • XGedIaFormatGraphic: Set the format of the graphical elements
  • XGedIaFormatSymbol: Set the format of the component
  • XGedIaFormatText: Set the text format
  • XMIaInsertMacro: Insert a macro into the current project.

In EPLAN you can create these interactions as actions on toolbar buttons. The parameters for the above interactions are listed below.

Example:

The following values are to be set for certain texts: Font size: 10 mm, Color: Green, Angle: -90Â°. In addition, an alignment box with a width of 45 and a height of 20 mm is to be shown. A possible entry in the command line in the Configure button dialog may look like this:

XGedStartInteractionAction /Name:XGedIaFormatText /height:10mm /color:3 /justification:? /angle:-90 /setframeactive:1 /showframe:1 /framewidth:45mm /frameheight:20mm

If a property should not be changed, then leave the corresponding question mark "?" on the command line alone. In the example, this is, for example, the Alignment property (Parameter: /justification:?). Parameters that are not needed, such as /bold:? can be deleted from the command line.

Parameters for the "XGedIaFormatDefPoints" interaction

Parameter

Description

Values

/width:?

Line thickness

Numeric values in "mm" or in "In" (Inch). With the value "-16002", the "From layer" setting will be applied.

/color:?

(Text or line) Color

The predefined values are:

  • 0 = black
  • 1 = red
  • 2 = yellow
  • 3 = green
  • 4 = cyan
  • 5 = blue
  • 6 = magenta
  • 7 = black
  • 8 = white
  • 9 = light gray
  • 252 = dark gray
  • 253 = gray
  • -16002 = from layer.

However, other values can also be specified in the Color selection dialog. Values from 0 to 256 are possible. The values of the colors are displayed in the color selection Tooltip.

/type:?

Line type

The following values are possible:

  • 0 = solid
  • 1 = dashed
  • 2 = dotted
  • 3 = dash-dot
  • 4 = dash-dot-dot
  • 5 = dash-2 short dashes
  • 26 = long dash-dot
  • -16002 = from layer.

/patternlength:?

Pattern length

Numeric values in "mm" or in "In" (Inch). With the value "-16002", the "From layer" setting will be applied.

  • 0 = graphical element is not filled

Transparency (specifies the transparency of a 3D object in the layout space)

Numerical values from 0.0 to 1.0. A value of 1.0 results in complete transparency (100% transparency). As an alternative you can also enter the value 'bylayer'. This will apply the transparency level as set for the layer.

/propertyId:?

Identifier of a component property to be defined (= Property number).

  • If this parameter is used, all format modifications are only performed for the property texts of the one specified property of the component.
  • If this parameter is not used, the format modifications are performed for the property texts of all placed properties.

5-digit number

/propertyIndex:?

The index, if the property has indices; usually 0

/linespacing:?

Row spacing

Numeric values. The value "1" corresponds, e.g., to single row spacing, value "2" is double spacing, etc.

/paragraphspacing:?

Paragraph spacing

Numeric values in "mm" or in "In" (Inch)

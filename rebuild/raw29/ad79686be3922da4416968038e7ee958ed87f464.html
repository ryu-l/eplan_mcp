Exporting / Importing Report Templates

Exporting and importing of Report templates allows report settings to be stored, passed on to others, and re-used in other projects. Exported report templates are stored in *.xml files.

Export report templates

Preconditions:

  • You have opened a project.
  • You have created report templates.
  1. Utilities > Reports > Generate
  2. Select the Templates tab.
  3. Select a report template.
  4. Select the Export popup menu item.

    The directory defined as the scheme directory in the settings is already loaded in the subsequent dialog.
  5. Enter a descriptive name into the File name field and click [OK].

Import report templates

Preconditions:

  • You have opened a project.
  • You have access to a *.xml report template file.
  1. Utilities > Reports > Generate
  2. Select the Templates tab.
  3. Select the Import popup menu item.

    The directory defined as the scheme directory in the settings is already loaded in the subsequent dialog.
  4. Switch to the directory containing the file, select the file and click [OK].

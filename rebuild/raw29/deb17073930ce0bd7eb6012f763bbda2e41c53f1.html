Opening Cross-references in a New Window

In the graphical editor it is possible to jump from the displayed cross-references to the cross referenced counterpieces (interruption points, main functions / auxiliary functions, etc.). During this action you can now also open a new window in the graphical editor provided that the respective cross referenced object is located on another project page. The new window opens by clicking the displayed cross-reference while simultaneously pressing the shortcut key [Ctrl] + [Shift].

Benefit:

When a cross-reference is opened in a new window, the project page with the first displayed cross-reference remains open. Tedious navigating to the original project page is superfluous.

Master Data: Basics

The system master data is not linked in the project, rather the master data is stored within the Project. A copy (e.g., of a symbol library) is generated in the project and is accessed during work. During the project you will always be working with the project-related copy. However, these are accessed by reference, so, for example, a symbol used several times in the project only exists once in the (project referenced) symbol library.

The project master data can be synchronized with the master data pool (and also the system master data) when opening the project as well as during backups / restores. The following project settings are available for this:

  • Synchronize project master data when opening: Under Options > Settings > Projects > "Project name" > Management > General: Select this check box when the master data stored in the current project should be synchronized with the master data pool every time the project is opened.
  • Synchronize plot frames: Under Options > Settings > Projects > "Project name" > Management > General: Select this check box when the plot frames stored in the current project should be synchronized with the master data pool every time the project is opened.
  • Standard plot frame: Under Options > Settings > Projects > "Project name" > Management > Pages: From the drop-down list or in the Select plot frame dialog select the default plot frame to be used.

Master data itself can only be edited in the master data pool (e.g., in the symbol editor).

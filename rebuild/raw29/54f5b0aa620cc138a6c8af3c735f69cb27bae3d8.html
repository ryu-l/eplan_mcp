Defining Net Extensions for Numbering with PLC Data

Typically a net ends at terminals, pins, or connection points of functions. You can use the net extension function to extend the net with terminals and pins, for example. To do this, specify in the net extension dialog which functions should not be treated as a boundary for the net. This setting affects the designation if the range is selected as "Net". The net extension for numbering with PLC data is independent of the Net-connecting property of the function concerned.

Precondition:

You have opened a project.

  1. Options > Settings > Projects > "Project name" > Devices > Number using PLC data
  2. Select a user-defined scheme from the drop-down list, or create a new scheme via (New) in the dialog Settings: Number using PLC data.
  3. Click [Net extension].
  4. In the Net extension dialog use the arrow button to move the desired functions from the Selection list into the Net extended with following objects list.

    The net then no longer ends at the selected functions; it is now extended beyond them.

    The net extension applies to all format groups with the scope "Net".
  5. Click [OK].

    The setting is saved in the selected scheme.

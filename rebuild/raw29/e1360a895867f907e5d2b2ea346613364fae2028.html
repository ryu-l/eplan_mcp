Tab Items (automatic dimensioning)

Dialog call:
  • You have opened a project.You have opened a project page in the graphical editor. You have inserted a model view (Insert > Graphic > Model view (<...>)) and placed it. Click [...] at the Model view: Scheme for automatic dimensioning property in the property dialog.
  • You have opened a project. Options > Settings > Projects > Graphical editing > Automatic dimensioning. Select the Items tab.

In this tab you select the items that are to be automatically dimensioned. You can specify the hierarchy level for each item type up to which it is to be included into automatic dimensioning. In addition you can specify for each item type where the measuring point is to be located at the item to be dimensioned.

Overview of the main dialog elements:

Toolbar:

Button

Meaning

(New)

Creates a new line in the table. Then double-click in the cells to select or enter the values for the items.

(Delete)

Deletes the selected rows.

Table:

The table contains the following columns:

  • Items to be dimensioned: Selection of the item type on the basis of its function definition.
  • Dimension up to level: Selection of the hierarchy level up to which the item is to be dimensioned automatically.
  • Measuring point at item: Selection of the point at the item at which the measuring point is to lie.

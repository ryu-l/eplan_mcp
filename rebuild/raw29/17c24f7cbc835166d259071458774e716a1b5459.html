Tab Display (outline definition point)

Dialog call:

You have opened a project. You have opened an "outline extrusion" outline type and inserted at least one logic element (Insert > Logic > "Logic element"). Mark a logic element. Edit > Properties. In the Outline definition point: <Logic element> dialog, select the Display tab.

In this tab, you can specify the display settings for the respective properties of the outline definition point. Individually placed properties can be docked with each other and made into a single block; when moving, this allows all the (desired) text to be moved at once and avoids overlapping of multi-line text with other text.

Overview of the main dialog elements:

Property arrangement:

In the drop-down list, different predefined assignment configurations are offered for selection. These configurations are stored at the outline definition point with their names.

From the drop-down list, select the desired property arrangement. It will specify the placed properties and their display settings. At the pre-defined arrangement configurations, there are already certain properties that have been selected for the display, and their values are specified in the right side of the dialog. Select "user-defined" if you want to specify your own arrangement.

If you have selected a property in the list below the toolbar, you can edit its display properties in the table on the right of the dialog.

Property / Assignment:

As soon as you have selected a property in the list, you can edit its display properties in the table on the right of the dialog. The hierarchy levels Format, Text box, Alignment box, Value / unit, and Position are available for this purpose. These can be opened by clicking the symbol. Concerning the display properties, the settings described in the following section are available:

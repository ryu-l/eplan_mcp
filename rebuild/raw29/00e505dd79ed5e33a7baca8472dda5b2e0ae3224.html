Working with Grids in the Layout Space

You can work with a grid also in the layout space to make the positioning of 3D part placements easier. The insertion and element points are then placed on the grid points. While working in the 3D layout space, a line grid is displayed during the placement of 3D part placements. In this case, the insertion points are on the points where the lines cross.

In the user settings you can determine five different grid sizes; using the to buttons in the View toolbar or via the Edit > Other > Grid A - E menu items, these can be selected in the layout space. This setting is possible separately for 2D and 3D.

Precondition:

You have opened a layout space.

Using Grid Snap

The use of grid snap is independent of the grid display options.

  1. Select the menu item Options > Snap to grid, to switch the grid snap on and off.

    If snap to grid is activated, then all of the subsequent actions are performed where the grid lines cross.

Align on grid

This function allows you to subsequently adjust 3D objects to the grid settings that were placed without the use of a grid. In this case, it does not matter whether snap to grid is on or off.

  1. Select the objects and then select the Edit > Other > Align on grid menu items.

    The selected objects are realigned (i.e., moved) so that all of their important points (such as handle, placement point, etc.) are on the grid.

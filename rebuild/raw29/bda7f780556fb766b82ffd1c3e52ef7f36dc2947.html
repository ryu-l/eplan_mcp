DXF / DWG Interface

EPLAN supports the import and export of data in DXF (Drawing eXchange Format) and in DWG format (DWG = DraWinG format) from the company Autodesk: These widely used formats allow data exchange between different CAD programs. Both formats were introduced with the AutoCAD program, and at this point in time, represent the industry standards.

With the help of DXF / DWG exports you can even deliver your project documentation to end customers that do not use EPLAN. EPLAN logic can't be transferred in this export. In EPLAN you have the option to export project pages or entire projects.

DXF / DWG imports are just one option in EPLAN for accessing design data on third-party systems and integrating them into your own projects. The following methods are available to you:

  • Import DXF / DWG files as graphics pages into the project layer
  • Insert DXF / DWG drawings into project pages
  • Create EPLAN window macros from DXF / DWG files.

Note:

EPLAN supports DXF / DWG formats of different AutoCAD format versions that you can view and predefine under Options > Settings > User > Interfaces > DXF / DWG export and import in the Export tab. If you use DXF / DWG files with elements that are not a part of these AutoCAD format versions, these elements will be ignored by EPLAN.

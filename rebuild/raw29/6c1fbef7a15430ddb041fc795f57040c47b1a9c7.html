Creating a library

A new library is created in the library catalog (see also Perspectives).

As a rule libraries contain specific objects, for example architecture components. Specific objects are derived from system objects. To this purpose the matching system library has to be imported into the newly created library (see also System libraries).

To create a new library:

  1. Click (New library).
  2. Enter a (unique) name for the new library.
  3. Enter a comment optionally.
  4. Open the editor page Imported libraries.

  1. Click (Import selected library).
  2. Select the Engineering library in the finder.
  3. Click [OK] in the finder.
  4. Save with [Ctrl] + [S] or .

The new library is subsequently listed in the library catalog.

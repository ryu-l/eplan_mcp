Changing the Page Description During the Copying of Pages

If you copy pages in a project or insert page macros in a project, you can use the familiar dialog Adapt structure to modify the structure identifiers and page numbers before inserting the pages. Now you can also change the page description for these actions.

Benefit:

When inserting copied pages you can now directly adapt the page descriptions. Subsequent processing of the pages is not required anymore.

To this purpose the Adapt structure dialog in the Pages tab was expanded by two columns Page description. In the Target table you can change the multilingual page descriptions of the inserted pages.

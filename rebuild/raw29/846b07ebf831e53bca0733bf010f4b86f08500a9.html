Bills of Materials: Export File Fields

When exporting a bill of materials, the parts data is output to an export file. Data exported in this manner can then be edited and re-imported. However, only the properties listed below are written back on import:

Export file field name

Property

P_ARTICLEREF_PARTNO

Part number

P_ARTICLEREF_VARIANT

Part variant, category Part reference data

P_ARTICLEREF_PARTTYPE

Record type, category Part reference data

P_ARTICLEREF_COUNT

Number of units / quantity

P_ARTICLEREF_FUNCTIONGROUP

Function group, category Part reference data

P_ARTICLEREF_PIECETYPE

Part group, category Part reference data

P_ARTICLEREF_ASSIGNMENT

Part allocation, category Part reference data

P_ARTICLEREF_ASSEMBLY

Assembly, category Part reference data

P_ARTICLEREF_POSNR

Item number, category Part reference data

P_ARTICLEREF_ADDITIONAL_TEXTFIELD

Supplementary field text, category Part reference data

P_ARTICLEREF_ADDITIONAL_BOOLFIELD

Supplementary field yes/no, category Part reference data

P_ARTICLE_EXTERNAL_PLACEMENT

External placement, category Part reference data

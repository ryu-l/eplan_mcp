Macros

Working with macros provides you with the following advantages:

  • You repeatedly want to use cut-outs of your schematic, including the graphics, but not always the same data and parts.
  • You want to save partial schematics under specific names in order to use them later.
  • You want to store records (variants i.e., value tables for technical data and parts) in the macros in order to avoid having to revise macros after inserting them in the schematic. To do this, placeholder objects can be defined for all kinds of data in a macro.
  • You can create macro projects and define macro boxes. The latter enable you to automatically generate window macros, for example.

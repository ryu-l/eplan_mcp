Extended Language Selection In The Block Properties

When formatting the properties in the Format: Block property dialog you can specify the language in which the texts of the property are displayed by means of the Language drop-down list. In this list new entries are also available for the displayed language, such as "Displayed language 1", "Displayed language 2", etc.

Benefit:

By means of the new entries in the language selection ("Displayed language 1", "Displayed language 2", etc.) it is possible that the texts of block properties and placeholder texts in the master data (macros, forms, plot frames, etc.) are always displayed in the current displayed language, even if this is changed in the translation settings.

During the selection of such an entry the texts of the property are displayed in the language that is specified in the translation settings as the first, second, etc. displayed language. Depending on the number of displayed languages in the translation settings up to five entries are possible here.

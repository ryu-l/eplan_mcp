Cross-references between Graphical Pre-planning / P&I Diagrams and Pre-planning Reports

Previously no cross-references to the reports of the pre-planning could be displayed for the placed segments in the graphical pre-planning or placed PCT loops in the P&I diagram. With the new version the cross-reference settings have been extended in such a way that cross-references between a segment placed on the respective logic page and the reports of this segment on the report pages are possible.

To this purpose the settings for the cross-reference display have been extended with the following page types:

  • Pre-planning: Planning object overview
  • Pre-planning: Planning object plan
  • Pre-planning: Structure segment overview
  • Pre-planning: Structure segment plan

This affects, on the one hand, the Display device cross-references table in the Settings: Display dialog and on the other hand the Page type / prefix table in the Settings: General dialog. The menu path for these settings is Options > Settings > Projects > "Project name" > Cross-references / contact image.

If you have selected such a pre-planning report for the Pre-planning column and / or for the P&I diagram column in the Display device cross-references table, cross-references to report pages are shown at the first placement of a segment on pre-planning reports and / or P&I diagram pages if such a pre-planning report exists for the segment. If the Auxiliary functions also refer to the device tag list setting is also activated, corresponding cross-references are also shown at the other placements of the segment.

Improved jumps in the exported PDF

During the PDF Export, jumps are now also output for the cross-references of the PCT loops to the corresponding pre-planning pages. This way you can for example jump in the PDF document from the PCT loops in the P&I diagram to the corresponding PCT loop data sheets.

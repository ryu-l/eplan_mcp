Changing the Rotation Angle when Inserting 3D Macros

When you insert a 3D macro, you can rotate the angle of the macro in 90Â° increments at the handle. Up to 40 different mounting positions can be implemented with a single 3D macro by changing the handles. These options also apply to devices whose parts have been assigned a 3D macro.

Preconditions:

  • You have opened a project.
  • The layout space navigator is open and a layout space is open.
  1. Select the Insert > Window macro / symbol macro menu items, and open a 3D macro for placement.
  2. Select the Options > Change rotation angle menu items.

    The position of the 3D macro will be rotated by 90Â° counter-clockwise.

    Each time the Options > Change rotation angle menu items are selected, the macro is rotated a further 90Â°.
  3. Click [A] to change the handle.
  4. At the changed handle, select the Options > Change rotation angle menu items again.

    You can set four different rotation angles at each available handle. This means that with nine default handles and one user-defined handle, as many as 40 possible positions can be implemented.

    5. Tip:

    You can also use the [Ctrl] + [Shift] + [R] shortcut key to change the rotation angle while inserting.

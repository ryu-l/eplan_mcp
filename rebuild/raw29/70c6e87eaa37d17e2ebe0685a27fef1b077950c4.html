Dialog Numbering formats

Dialog call:
  • You have opened a project. Options > Settings > Projects > "Project name" > Devices > Numbering (online). In the Settings: Numbering (online) dialog, click [...] next to the Numbering format field.
  • Utilities > Change of standard. Make the necessary entries in the Project, Rotation / flipping, Master data, Symbols and Structure tabs and click [Next] each time. In the Numbering tab, next to the Device numbering field, click [...].

Use this dialog to manage all numbering formats for online numbering of devices. You can create, edit, copy, delete, import, and export numbering formats. You can select these numbering formats for devices that you place on the schematic page using Insert > Symbol. You can also select these numbering formats for devices that you insert into the schematic page using macros or copy processes.

The following dialog elements are available:

Scheme:

This field contains the name under which you have saved the numbering format in the New scheme dialog in the Name field.

You can create new schemes, save any changes to a scheme, and copy or delete schemes via the adjacent Toolbar. Schemes can also be imported or exported.

Description:

In this field is the description you entered for the numbering format in the Description field of the New scheme dialog.

Tab DT

General devices ... Mechanical devices:

This field contains the DT format for the respective functions. Click [...] to open the DT format dialog, which is where you can edit the format. If the check box is activated, the functions are automatically numbered on insertion. If the check box is deactivated, the functions are not automatically numbered on insertion.

Number nested components:

If this check box is selected, then components allocated to a superior component are automatically numbered on insertion. If the check box is deselected, then these components are not automatically numbered on insertion.

Tab Designations

Terminals ... Busbar connection points:

If the check box is activated, the respective designations are automatically numbered on insertion. If the check box is deactivated, the designations are not automatically numbered on insertion. The format for the designations is shown in the field next to the check box. Click [...] to open the DT format dialog, which is where you can edit the format.

PLC addresses:

If the check box is selected, then PLC addresses are automatically numbered on insertion. If the check box is deselected, then PLC addresses are not automatically numbered on insertion.

Do not modify PE, N, and SH terminals:

If the check box is activated, PE / PEN, N, and SH terminals are not numbered. The designation of the PE, PEN, N, and SH terminals remains unchanged.

Do not modify PE, N, and SH pins:

If the check box is activated, PE / PEN, N, and SH pins are not numbered. The designation of the PE, PEN, N, and SH pins remains unchanged.

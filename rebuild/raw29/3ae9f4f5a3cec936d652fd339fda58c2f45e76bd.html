Automatic closing of editors

In the views Project Explorer and Project Libraries of the project perspective, the visible components of a project are displayed. Any number of editors can be opened for these components.

If in the Project Explorer view an alternative project is selected for the project perspective, this may cause editors for components from the old project to be opened, which are not visible in the new project.

For example, this is the case when editing or testing library components that are used in several projects. Most of the time, however, the user wants a behavior where all editors are closed automatically when switching between projects.

Dialog Settings: Parts pre-filtering

Dialog call:

Options > Settings > User > Management > Parts pre-filtering.

In this dialog you can pre-filter the parts management, the part master data navigator, the part selection and the device selection on the basis of specific properties.

Overview of the main dialog elements:

Filter:

This drop-down list contains all the filter schemes already defined. Through [...] you branch into the dialog Filter in which you can for example create a new scheme and assign filter criteria. To this purpose the dialog Criteria selection provides parts properties such as Discontinued part, ERP number etc.

Note:

If such a filter is active, a percentage sign "%" is displayed in the title bar of the dialogs listed above in front of the name of the parts database.

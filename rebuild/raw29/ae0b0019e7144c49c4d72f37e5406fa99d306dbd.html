Installing extension points into mechatronic components

You now have to install extensions points in all mechatronic components in which Word components have already been installed fixed.

This affects the following mechatronic components:

  • Feeder,
  • Cylinder,
  • Valve,
  • Positionsensor_Inductive,
  • Pressuresensor,
  • Positionsensor_optical.

Installing extension point for the main document
  1. Open the Feeder component.
  2. Click in the component editor to open the Finder dialog.
  3. Mark the Placeholder.
  4. Confirm with [Finish].
  5. Change the name from Placeholder to Bodies.
  6. Click [...] in the Type field to open the type finder.
  7. Enter the character I in the Name field.
  8. Click [Search].
  9. Select the IBody interface.
  10. Confirm with [OK].
  11. Enter the value 0..1 in the Number field.
  12. In the Selection formula field, enter the value =1.
  13. Mark the Extension point check box.
  14. Save the component.

In the future a component that implements the IBody interface is installed on the extension point. The quantity is limited to the value 1 and the selection formula only allows a single component. Later an instance of M_Body is placed on this extension point through the update of the extension point.

Installing extension point for two chapters

Two chapters are to be inserted into the Word document, one for the actuators and one for the sensors. Previously the discipline component Chapter was installed twice in the Feeder. At the same time a placeholder is now installed at the same place.

  1. Open the Feeder component.
  2. Click in the component editor to open the Finder dialog.
  3. Mark the Placeholder.
  4. Confirm with [Finish].
  5. Change the name from Placeholder to Chapters.
  6. Click [...] in the Type field to open the type finder.
  7. Enter the character I in the Name field.
  8. Click [Search].
  9. Select the IChapter interface.
  10. Confirm with [OK].
  11. Enter the value 0..2 in the Number field.
  12. In the Selection formula field, enter the value =2.
  13. Mark the Extension point check box.
  14. Save the component.

Installing an extension point for a row in all sensors and actuators
  1. Open the Positionsensor_inductive component.
  2. Click in the component editor to open the Finder dialog.
  3. Mark the Placeholder.
  4. Confirm with [Finish].
  5. Change the name from Placeholder to Rows.
  6. Click [...] in the Type field to open the type finder.
  7. Enter the character I in the Name field.
  8. Click [Search].
  9. Select the IRow interface.
  10. Confirm with [OK].
  11. Enter the value 0..1 in the Number field.
  12. In the Selection formula field, enter the value =1.
  13. Mark the Extension point check box.
  14. Save the component.
  15. Repeat Steps 1 to 14 for all other sensors and actuators.

Positioning goods that are sold by the meter on a mounting surface

To position objects that are sold by the meter and are cut to size prior to assembly, it is necessary to specify not only the coordinates, but also the length and orientation (angle).

Placement is determined via the Coordinate parameter, while length and orientation are specified via the Dimension parameter.

The coordinates are specified using the following syntax:

=List{<X-coordinate>,<Y-coordinate>}

The length and orientation are specified using the following syntax:

=List{<Length>,<angle>}

The following diagram shows the result of specifying =List{60.0,25.0} for the Coordinate parameter and =List{420.0,90} for the Dimension parameter in order to position a cable duct vertically on a mounting surface:

When calculating the position, it should be kept in mind that specifying an angle rotates the object counterclockwise around mounting point V1.

Determining the Format and Range for Numbering

Precondition:

You have opened a project.

  1. Options > Settings > Projects > "Project name" > Devices > Number using PLC data
  2. Select a user-defined scheme from the drop-down list, or create a new scheme via (New) in the dialog Settings: Number using PLC data.
  3. Click (New) via the Format groups field in the Settings: Number using PLC data dialog.
  4. Select the group of devices for which you want to determine the format from the Group drop-down list in the dialog Number using PLC data: Format. You can choose between terminals, pins, and devices.
  5. In the Extent drop-down list, select the scope of numbering for the selected group.

    Note:

    If you have selected the "Net" entry, then you can use the net extension to increase the area affected by the numbering scheme, as described in the section Defining Net Extensions.

  6. Mark a format element in the Available format elements field and use to move it to the right into the list of selected format elements.

    Different subsequent dialogs will appear, depending on the format element. Depending on the selected format element this can be one of the following dialogs: Format: PLC data, Format: Identifier, Format: Page / Column / Row or Format: Separator.
  7. Define the formatting in the subsequent dialog.

    A preview of the numbering format is displayed in the Preview field. The individual formatting elements are displayed in the connection designations in the same sequence as they currently exist in the list.
  8. If desired, you can change the sequence of the format elements using the arrow buttons.
  9. Click [OK].

    The values entered will be saved in the selected scheme.

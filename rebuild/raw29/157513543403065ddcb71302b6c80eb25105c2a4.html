P020016: <x> (no. of values) <y> -> <z>

Description

You have executed a project comparison in which the settings of the project to be checked (incoming project) are to be compared with those of the comparison project in order to determine any differences. In this message, <x> represents the path to the project setting where there are differences between the project to be checked and the comparison project. <y> and <z> indicate the number of values by which the setting in the project to be checked has changed.

Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

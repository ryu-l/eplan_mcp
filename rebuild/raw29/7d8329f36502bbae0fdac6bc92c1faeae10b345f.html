Create architecture components for the text discipline

As a rule concrete discipline components are derived from abstract discipline components (architecture components). For the ListOfComponents these are architecture components for Body, Chapter and Line.

Create the following architecture components in the Levelcomponents unit:

Architecture component Super class Image Image file Abstract Sublevels Component of the top level
Body ListOfComponentsComponent install/icon-collection/Rumpf.gif Yes Chapter Yes
Chapter ListOfComponentsComponent install/icon-collection/Abschnitt.gif Yes Line No
Line ListOfComponentsComponent install/icon-collection/Zeile.gif Yes - No

See Creating an architecture component.

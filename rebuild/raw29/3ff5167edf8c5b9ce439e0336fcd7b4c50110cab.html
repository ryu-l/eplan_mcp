Dialog Settings: Cable

Dialog call:

You have opened a project. Options > Settings > Projects > "Project name" > Devices > Cable.

In this dialog, you specify the default settings for the measuring unit for cable lengths and for the order in which the cable connections are to be assigned.

Overview of the main dialog elements:

Always sort cable connections according to plug sequence:

If the check box is selected, cable connections between terminals and plugs are always sorted according to the order of pin designations.

If the check box is not selected, terminals and plugs are treated equally and the cable connections are sorted according to the plug or terminal sequence at the source.

Ignore subordinate DTs for nested targets:

This setting affects both cable numbering and automatic generation of cables as well as the output of cables in reports.

If the check box is activated, the subordinate device tags are not output as cable targets in the case of nested devices. In this case the superior devices (for example the black boxes) are the targets. The representation of the targets of cable connections is not changed. The subordinate device tags are always output as targets here.

If the check box is deselected, the subordinate device tags are output as cable targets.

Example:

Two connections run between terminals of different terminals strips in two black boxes -U1 and -U2.

Case 1: The check box is deselected

In this case the terminal strips are the cable targets. In the case of automatic cable generation two cables are generated: One between the terminal strips -U1-X1 and -U2-X3 and one between the terminals strips -U1-X2 and -U2-X4.

Case 2: The check box is selected

In this case the black boxes are the cable targets. In the case of automatic cable generation only one cable is generated between the black boxes -U1 and -U2.

Measuring unit for cable length:

The measuring unit selected here will be used for outputting cable diagrams if you have not specified a measuring unit for the cable length in a manual cable definition in the schematic. In the schematic itself the cable definition remains as it was entered. An overview of the possible units can be found in the section "Connections: Units for Lengths and Cross-sections".

Cross-sections with blank character:

If this check box is activated, an empty space is placed between the value and the unit when you are outputting cross-section / diameter and unit together (e.g. via the Cable / Conduit: Cross-section / diameter with unit property or a similar one).

Lengths with blank character:

If this check box is activated, an empty space is placed between the value and the unit when you are outputting cable or connection lengths and unit together (e.g. via the Cable / Conduit: Length with unit property or a similar one).

Standard cable:

In this field, you can specify a cable to be used as the default for transmitting conductor properties to the connections. Click [...] to open the Part selection dialog and select an existing cable there. This cable is then automatically stored in the project.

If a standard cable is specified, the conductor properties will be transmitted to the connections when drawing a cable definition line. There are two possible cases:

  • If none of the connections intersecting the cable definition line belongs to a cable, then the cable connections of the standard cable will be assigned to the connections. This is done based on the identifying properties, which are also taken into consideration in the automatic assignment of suitable cable connections. Only the properties from the function templates are transferred to the connections. The cable does not adopt the part, cable type, or any other unassigned function templates from the standard cable.
  • If at least one of the connections intersected by the cable definition line belongs to a cable, then the cable definition line receives the first cable device tag that is found and the free cable connections of the existing cable are assigned to the newly added connections (if possible).

If no standard cable is specified, then cable connections are not assigned when drawing cable definition lines.

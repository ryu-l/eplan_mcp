Defining and Editing Background Images

Elements, such as image files, graphical elements or imported DXF / DWG files, can be used as background images. For this purpose the layer management comes with the Background setting. Elements on such a layer are always right at the bottom, i.e. also behind the autoconnect lines.

Preconditions:

  • You have opened a page, form, plot frame or symbol.
  • You have inserted an image file, a DXF / DWG file, graphical elements, etc.
  • In the layer management, you have activated the Background check box for specific layers.

Set elements as background image

  1. Double-click the required element to open the Properties dialog.
  2. In the properties dialog, select the Format tab.
  3. In the Layer field, select a layer for which the Background check box is activated in layer management (e.g., the EPLAN705, Graphic.Wallpaper layer).
  4. Click [OK].

    The element is placed in the background and can no longer be selected and edited.

Edit background image

  1. Select the menu items Options > Edit background.

    Elements on a layer for the Background setting has been activated can be selected and edited.
  2. Double-click the required element to open the properties dialog, and edit there the properties of the element.
  3. Select the Options > Edit background menu items to deactivate this option again.

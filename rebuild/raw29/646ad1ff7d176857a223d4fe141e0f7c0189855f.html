Placing Items Without Schematic

In order to support the various working methods of builders and engineers, it is also possible to create panel layouts without an existing schematic.

Preconditions:

  • You have opened a project.
  • You have opened the 2D panel layout - <Project name> dialog (Project data > Parts / Devices > 2D panel layout navigator).
  • You are in the graphical editor on a "Panel layout" page.
  • You have added a mounting panel.
  • In the dialog Settings: 2D panel layout (Popup menu > Settings) you have selected none of the Manual input <...> options.
  1. Popup menu > New device
  2. In the Part selection dialog select the desired part.
  3. Click [OK].

    The part symbol is scaled to the specified size (only values larger than 0.0 are accepted), and hangs on the cursor.
  4. Place the part on the mounting panel.

    The Properties <...>: Part placement dialog opens.
  5. In the Part placement tab allocate a device tag to the part.
  6. Edit the other properties of the part placement as required.
  7. Click [OK].
  8. Proceed in a similar manner for all the parts that you would like to place.

When the part is placed, a check is performed that the current page is of "Panel layout" type and that the part placement is within a mounting panel. If these conditions are not met, the part is not placed and an appropriate message is displayed.

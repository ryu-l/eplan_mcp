File Name Extensions and Icons for Projects

In the tree view of the Page navigator and Project management the following icons and file extensions illustrate the type of project you are dealing with:

Icon

File type

Meaning

File extension

EPLAN project

Standard EPLAN project that you can open and edit. If you work in the multi-user mode, such an opened project can be edited by several users simultaneously.

*.elk

Exclusively opened EPLAN project

EPLAN project which was opened exclusively. Only you can edit the project. If you work in the multi-user mode, other users cannot access such an opened project.

*.elk

Read-only EPLAN project

EPLAN project which was opened read-only. You can view, but not edit the project. If you are working in multi-user operation, other users can edit this project.

*.elk

Zipped EPLAN project

Zipped project. The project cannot be opened. The icon is only shown in Project management.

Is generated via: Project > Zip. The *.elk project becomes a *.elp project.

*.elp

Filed-off EPLAN project

For external editing of a filed-off project. You can open the project in EPLAN in read-only mode but cannot change or delete it.

Is generated via: Project > Back up > Project > Method "File off for external editing". The *.elk project becomes a *.els project in the same directory. A *.zw1 backup file is also created in the selected backup directory.

*.els

---

EPLAN data backup: Project

1) Backup file of a filed-off EPLAN project

or

2) Backup file of an archived EPLAN project

or

3) Backup file from another saved project. Is generated via: Project > Back up > Project > Method "Save additionally". The *.elk project remains in the same directory. A *.zw1 backup file is also created in the selected backup directory.

*.zw1

Filed-off, zipped EPLAN project

Filed-off and zipped project. This type of project has to first be zipped before it can be opened in read-only mode. The icon is only shown in Project management.

Is generated via: Project > Back up > Project > Method "File off for external editing". The filed-off project is zipped in project management via Popup menu > Zip. The *.elk project becomes a *.els project. The *.els project becomes a *.elx project.

*.elx

Archived EPLAN project

The project cannot be opened. The icon is only shown in Project management.
Is generated via: Project > Back up > Project > Method "Archive". The *.elk project becomes a *.ela project in the same directory. A *.zw1 backup file is also created in the selected backup directory.

*.ela

Completed EPLAN project

Completed project. You can open the project in EPLAN in read-only mode but cannot change or delete it.

Is generated via: Utilities > Revision control > Complete project. The *.elk project becomes a *.elr project.

*.elr

EPLAN reference project

Reference project. You can open the project in EPLAN in read-only mode but cannot change or delete it.

Is generated via: Utilities > Revision control > Property comparison of projects > Generate reference project. The *.elk project remains. A copy of the project is also created as a completed *.elr project.

REV*.elr

EPLAN revision project

Project with change tracking. You can open and edit the project.

Is generated via: Utilities > Revision control > Change tracking > Generate revision. The *.elk project becomes a *.ell project.

*.ell

Note:

Note that a different icon is used in the Open project dialog. The editable EPLAN projects are identified here with the symbol of their EPLAN application.

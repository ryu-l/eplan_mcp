Dialog Number items

Dialog call:

You have opened a project. Project data > Parts / Devices > Bill of materials navigator. In the Bill of materials - <Project name> navigator dialog, you have selected the desired records and selected Popup menu > Add item numbers in the tree or list view.

You can use this dialog to renumber the marked items in the bill of materials. The item numbers are a purely structural feature within the bill of materials.

Overview of the main dialog elements:

Sorting:

Select an existing sorting scheme from the drop-down list or click [...] to open the Sorting dialog. You can edit existing schemes or create new ones there.

A selected scheme is activated automatically. You can deactivate the selection of a scheme through the entry "-Not activated-".

New numbering at changed property:

Select an existing scheme from the drop-down list or use [...] to open the New numbering at changed property dialog. You can edit existing schemes or create new ones there. Such a scheme can be used to assign the item numbers structure- or page-specifically. To this purpose you can select, for example, the properties Higher-level function or Page name as criteria. If a value of the properties specified in the scheme changes (for example the structure identifiers for the higher-level function), numbering begins again with the starting value specified in the dialog.

A selected scheme is activated automatically. You can deactivate the selection of a scheme through the entry "-Not activated-".

Start value:

Enter the starting number for numbering here.

Increment:

Here, enter the increment by which the numbers are increased.

Field width:

In this field, determine the number of digits planned for the item numbers.

Same number for identical devices:

Select this check box, if devices with identical part numbers are to be given the same item numbers.
If the check box is deselected, the item numbers are assigned regardless of the device.

Please note that devices without assigned part number are treated like different devices, i.e., they always receive a new item number.

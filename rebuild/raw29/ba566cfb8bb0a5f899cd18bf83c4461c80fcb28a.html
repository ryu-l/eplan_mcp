Extended Settings for Internet Connections

There are different program components in the EPLAN Platform that establish a connection to the Internet by means of a browser window (for example EPLAN Data Portal, EPLAN Download Manager, etc.). In the settings for the Internet connections you can now delete the browsing data and specify that the proxy settings of the operating system are used.

Deleting browsing data of all EPLAN browser windows

In certain situations it can be necessary to delete the browsing data for these components. To this purpose, the previous Settings: Proxy server dialog has had the Browsing data tab added to it and has been renamed:

Old designation

New designation

Settings: Proxy server

Settings: Internet connection

(The menu path for the settings dialog is: Options > Settings > User > Management > Internet connections.)

In the Browsing data tab click the [Delete] button to delete the browsing data of all program components with a browser window. All previous entries that you have carried out for the confirmation or logon in a browser window are deleted.

You have to close and restart EPLAN so that this can become effective. You must then perform the confirmation or log on again when subsequently opening a browser window.

Importing settings for the proxy server from the operating system

If you use a proxy server for Internet connections, you have the possibility to import the proxy settings of the operating system. To this purpose the new setting Use proxy settings of the system is available to you on the Connection tab in the Settings: Internet connections dialog.

Benefit:

The new option for LAN settings means that you can import the proxy settings from the operating system and do not have to additionally enter the proxy login data manually in the EPLAN Platform.

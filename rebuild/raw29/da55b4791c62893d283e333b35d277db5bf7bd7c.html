Dialog Synchronize devices / Dialog Synchronize routing connections

Dialog call:

You have opened a project.

  • Project data > Devices > Import. You have carried out the required settings for the data source and field assignment in the dialog Import device data. Click [OK].
  • Project data > Connections > Import > Routing connections. You have carried out the required settings for the data source and field assignment in the dialog Import connection data. Click [OK].

This dialog displays the device data / connection data from the data source and the EPLAN project in a table. In the Data source table area the device data / connection data from the data source are displayed. In the EPLAN project table section the data from the EPLAN project. The displayed scope can be limited by using filters. Only the two columns Action and Part number in the EPLAN project table area have to be edited by the user.

Overview of the main dialog elements:

Filter:

Click [...] to open the Filter dialog. Here you can specify filter criteria for the devices and connections to be displayed.

Data source table area:

  • Row: Contains a consecutive row number.
  • Part number: Part number of the device / connection in the data source. Here, the name of the associated EPLAN property is displayed as a column heading.
  • Quantity, level, etc.: Further properties of the device / the connection in the data source are displayed as column header if they exist in the source. The extent of the displayed columns can be extended or reduced via the Configure representation popup menu item.

EPLAN project table area:

  • Status: This column displays whether devices / connections are not yet contained in the project, whether they already exist in the project, or whether the devices / connections in the data source and in the project have different editing states (for example other property values).

  • Action: Here you specify which action is to be carried out with the devices / routing connections depending on the displayed status:

    • Status

    Meaning

    Possible action

    New: The device / routing connection in the data source is not yet contained in the project.

    Import or None

    Identical: The device / routing connection in the data source is already contained in the project and will not be imported once more. All property values are identical.

    Note:

    If fields that have the status (Identical) have a dark gray background and if no action is available for them, the corresponding field in the source file contains several tabulators or blanks.

    None

    Additional: The device / routing connection is only contained in the project, but not in the data source.

    Delete or None

    Changed: The device / routing connection is contained in the data source and in the project. One or more property values differ, for example the part number.

    Note:

    Fields with changed property values have a dark-gray background. The Tooltip for such a field shows the respective value in the project.

    Change or None

    Invalid (only routing connections)

    None

  • DT (full): Full DT of the device / routing connection in the EPLAN project.
  • Part number: Part number of the device / routing connection in the EPLAN project.
  • Quantity, level, etc.: Further properties of the device / the connection in the EPLAN project can be displayed as column header. The extent of the displayed columns can be extended or reduced via the Configure representation popup menu item.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

In addition, the following dialog-specific popup menu items are available:

Menu item

Meaning

Assign parts

If part numbers from the data source do not exist in the EPLAN parts database, they are displayed in bold in the dialog. This popup menu searches in the parts database for other matching properties (for example order number, type number) of the devices / routing connections to be imported and uses them to assign a suitable part number from the parts database. If no automatic assignment is possible, click the [...] button in the Part number column to open the part selections and select a part there manually.

Filter (status):

Reduces the display of the devices to be imported in accordance with their status:

  • All (default setting)
  • Changed
  • Identical
  • New
  • Additional.

P001029: A connection definition point lies on a connection between distributed terminals

Cause

A connection definition point was placed on a drawn connection between saddle jumper connections of distributed terminals with different designations for activated jumper optimization.

Solution

Possibility 1

  1. Locate the connection definition point in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
  2. Delete the connection definition point on the connection between the saddle jumper connection points of the distributed terminals.
  3. Refresh the connections and then start a new check run.

Possibility 2

Or deselect the Jumper optimization property:

  1. Select the Options > Settings > Projects > "Project name" > Devices > Terminals (distributed terminals) menu items and deactivate the Jumper optimization check box.
  2. Refresh the connections and then start a new check run.

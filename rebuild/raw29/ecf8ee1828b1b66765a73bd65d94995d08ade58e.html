Changing Model Views

You can use the following actions to modify how the content of model views is displayed and arranged:

  • Update
  • Center contents
  • Move contents

Precondition:

You have opened a project. You have opened a project page in the graphical editor. The page must contain a model view.

Update model view

If the content of the layout space referenced by the model view was changed, the message "Model view not up to date" appears over the top of the model view when the page is opened. The model view must be updated to match the contents of the layout space and model view.

If the Model view: Frozen property has been activated for the model view, this must be deactivated prior to updating.

  1. Select the model view.
  2. Select the menu item Utilities > Reports > Update.

    The display in the model view is matched to the current status in the layout space. Any newly-added components are shown, while removed components are hidden.

Center contents

If the display in the model view was changed by modifying the frame size or by using the Move contents or Update action, you may find that the graphic no longer appears centered in the model view. You can run the Center contents action to return the graphic to the center of the model view.

  1. Select the model view.
  2. Select the Center contents popup menu item.

    The content of the model view is shown centered.

Move contents

This action moves the entire content of the model view. You can use this option to change the position of the graphic in the model view without having to create a new model view. The centered status can be restored with the Center contents action.

  1. Select the model view.
  2. Select the Move contents popup menu item.

    The content of the model view hangs centered on the crosshairs on the cursor.
  1. Use the cursor to move the graphic to its new position and click to place it. You can also use the input box to enter the placement point.

    The content of the model view is moved to the new position.

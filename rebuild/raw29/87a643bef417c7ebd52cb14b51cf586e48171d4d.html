P026091: Incomplete project properties for the air-conditioning calculation

Cause

No value was stored for at least one of the following project listed properties that are required for the air-conditioning calculation at the enclosure:

  • Thermal design: Simultaneity factor
  • Thermal design: Voltage
  • Thermal design: Frequency.

Solution

  1. Select the menu items Project > Properties and check in the Properties tab for which of the above listed projects the value is not entered.
  2. Add the missing value(s).
  3. Click [OK] to close the dialog of the project properties, and then start a new check run.

Synchronizing Pre-planning Parts with the Detailed Planning

It is possible that you may have to change the parts at the segments in the pre-planning although the associated main functions have already been placed in the detailed planning. In such a case you can synchronize the pre-planning parts with the parts in the detailed planning. In the process the part information at the main functions in the detailed planning is deleted and replaced by the part information of the assigned segments.

During synchronization a check is first carried out whether the parts defined in pre-planning already exist at the main function, irrespective of the order in which they are entered at the main function.

Parts that are entered at the main function but not at the assigned segment are deleted at the main function.

Parts that are entered at the segment but not at the main function are copied to the main function. The order of the parts is retained (as far as possible).

For parts that are entered at both the segment and the assigned main function the order of the parts at the main function is retained and the part reference data is transferred. The settings for the synchronization (under Options > Settings > Projects > "Project name" > Devices > General) are taken into consideration in this case.

Preconditions:

  • You have opened a project that contains the pre-planning data, and have the pre-planning navigator open.
  • You have stored parts at the segments.
  • You have assigned the segments to the corresponding functions in the detailed planning.
  1. Mark one or several segments in the pre-planning navigator.
  2. Select the Update detailed planning popup menu item.
  3. In the dialog that then opens Update detailed planning select the Synchronize parts check box.
  4. Click [OK].

    A message is displayed.
  5. Confirm the message by clicking [OK].

    The part information of the selected segments including all the subordinate segments is synchronized.

Note:

Part placements in the layout space are not synchronized and remain unchanged.

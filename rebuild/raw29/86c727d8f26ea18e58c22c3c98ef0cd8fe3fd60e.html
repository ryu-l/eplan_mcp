P001012: Incorrect saddle jumper formation

Cause

A wrongly-created saddle jumper was found in the schematic. This message may be output for several reasons, and the reason should be explained with reference to the following examples:

Possibility 1

In the schematic, you defined a connection between different levels of a multi-level terminal as a saddle jumper.

Example:

There is a connection defined as a saddle jumper between the two terminals -X1:1 and -X1:2. The two terminals are on different levels of a multi-level terminal. It is not possible to create a saddle jumper in this case.

Possibility 2

You have defined a connection between terminals in the schematic as a saddle jumper, but you have not entered a value for the number of saddle jumpers at one or both of the terminals.

Example:

There is a connection defined as a saddle jumper between the two terminals -X1:1 and -X1:2 (see illustration for the example under "Possibility 1"). Both terminals are "normal" feed-through terminals with two connection types. No value or 0 was entered at both terminals for the Number of saddle jumpers property in the Connection point logic dialog for the first function connection point.

Solution

Regarding option 1

  1. Double-click the connection definition point between the terminals in the schematic.
  2. In the Properties <...> dialog, select the Connection definition point tab.
  3. Next to the Function definition field click [...], and select the entry "Wire jumper" instead of "Saddle jumper" in the Function definitions dialog.
  4. Refresh the connections and then start a new check run.

Regarding option 2

  1. Open the Properties dialog for terminals that are connected to one another.
  2. Switch to the Symbol / function data tab, and click the [Logic] button to open the Connection point logic dialog.
  3. In the Number of saddle jumpers field for the relevant function connection points, enter a value greater than "0" (for the example under "Possibility 2", enter 1 at the first function connection point).
  4. Then start a new check run.

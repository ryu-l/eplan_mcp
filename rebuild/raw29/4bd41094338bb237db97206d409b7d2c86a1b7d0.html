Tab Connection point pattern

Dialog call:

Utilities > Parts > Management. In the tree or list, you have selected an object belonging to the Connection point pattern generic product group.

In this tab you define default values for connection points in a connection point pattern. In the Technical data tab of the part, you can then access the data entered here.

Overview of the main dialog elements:

Name:

When selecting a connection point pattern in the Technical data tab of a part, this name as well as an optional description will be shown in the selection dialog.

Group box Standard connection point

Connection category:

From this drop-down list select the default value that specifies the connection point type of the connections. Click [...] to define the desired values in the subsequent dialog and write them to the database. In the Connection points tab you can define individual connection points and determine deviating values.
In the Connection point pattern tab of part placements which use this connection point pattern, the default value defined here is accessed if no connection points are defined in the connection point pattern.

We recommend only using the connection categories corresponding to the eCl@ss classification when new connection point patterns are created.

Connection dimension:

In this field you can enter a default value for the dimension of the screw (e.g., "M6") or of the lug (e.g., "4.8 x 0.5") for screw connections, threads, nipples, and plug-in connections. In the Connection points tab you can define other values for individual connection points.

In the Connection point pattern tab of part placements which use this connection point pattern, the default values defined here are accessed if no connection points are defined in the connection point pattern.

Wire termination processing (EPLAN Cabinet):

This property is only required for reasons of compatibility with EPLAN Cabinet. Select the handling method for the end of the connection, e.g., "Strip" or "Crimp", from this drop-down list.

Additional length:

Here you enter the default value for the additional length of the connection point collection. In the Connection points tab you can define other values for individual connection points.

Routing direction:

Select the default routing direction from this drop-down list. In the Connection points tab you can define other values for individual connection points.

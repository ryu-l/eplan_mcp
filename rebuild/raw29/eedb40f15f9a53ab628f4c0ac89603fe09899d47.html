Improvements When Sorting Into the Existing Structure

When inserting macros or copies into a P&I diagram you can use the Select structure dialog to integrate PCT loops, PCT loop functions, planning objects etc. that are contained in the macro / copy into the existing structure of the pre-planning. In the current version the selection in this dialog has been simplified and improved at several points:

  • Simplified assignment of segments:
    To assign identical segments in the source and project to each other during selection of the structure you previously had to assign the segments individually. In the new version you can now also assign structures with several existing segments. To do so mark the respective node of an existing structure segment in the fields Source and Project, and click the button (Assign).
  • Improved user interface:
    New status icons then indicate in the Project field whether a segment already existed in a project (icon ) or whether it is a new segment (icon ).
  • Uniform numbering setting:
    The numbering setting in the dialog has been harmonized and now affects all segments in the source in the same way. As part of this extension the associated check box in Number segments has been renamed.
    If this check box is activated, the device tags and designations of the segments are numbered in accordance with the numbering settings in the configuration of the segment definitions.

Benefit:

When inserting macros or copies into a P&I diagram the segments already existing in a project can be assigned quicker, the tedious individual selection is superfluous.

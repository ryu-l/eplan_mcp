Moving Terminals

You can move terminals, in order to change their position on the terminal strip and reassign them. This is sometimes necessary in order to create a gap between terminals and to create space in the terminal strip for new terminals to be added.

Precondition:

You have selected a terminal or a terminal strip definition or in the terminal strip navigator, the device navigator or the graphical editor.

  1. Select the menu item Project data > Terminal strips > Edit.
  2. Select one or more terminals.
  3. Select the Move popup menu item.
  4. In the By how many field of the Move dialog, select the desired value or specify a value directly in the field.
  5. Click [OK].

    The terminal designations of the selected terminals as well as the other terminals all the way to the end of the terminal strip will be moved by the specified value.

Note:

Multi-level terminals are kept when they are moved. The properties of the lowest level of the multi-level terminal are relevant for the move. If you want to move the terminals without retaining the multi-level terminals, separate the multi-level terminals in advance in the Edit terminal strip dialog by selecting popup menu item Split.

Action: XPlaUpdateDetailAction


Parameters

Description

PROJECTNAME

Project name with complete file path.

UpdateMacros

1: The placements of the macros entered at the marked planning objects / PCT loops are deleted and these macros are placed again.

UpdateIdentifier

1: The devices tags of functions placed in the detailed planning, the structure identifiers and the symbolic addresses are updated.

UpdatePlaceholder

1: The modified data from the pre-planning is transferred to the placeholder objects placed in the detailed planning.

UpdatePipedata

1: The piping data is transferred from the piping planning objects to the associated pipings in the P&I diagram. In the process the pipe class, the associated properties and the substance are transferred to the placed piping definition points and connections. Only the pipe class and the associated properties are transferred at the functions in the pipings.

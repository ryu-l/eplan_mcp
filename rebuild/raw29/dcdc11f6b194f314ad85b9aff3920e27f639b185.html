    Color Eplan Color Value Defines the color of graphical placements Color stores either a) an colorId as reference into an internal color table (Default) OR ... b) the RGB values of the color OR ... c) a special color id ByLayer, that says: color is defined by layer usually the color is defined by color id. imported 3d graphics may store RGB values directly if the ColorId==ByLayer then the color must be taken from layer if the TransparencyDefinedByLayer is true, then the transparency must be taken from layer otherwise the transparency is stored in this object

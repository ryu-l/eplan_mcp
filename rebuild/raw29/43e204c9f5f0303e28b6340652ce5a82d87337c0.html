Tab Wire termination processing

Dialog call:

You have opened a project. Options > Settings > Projects > "Project name" > Routing connections > General. Select the Wire termination processing tab.

In this tab, you adjust project-wide settings for processing wire terminations of routing connections that are taken into account for the export of connections.

Overview of the main dialog elements:

Table Connection category - Wire termination processing:

In parts management, the Connection category property is defined at the individual connection points. In the transmission to the manufacturing machine, however, the information on wire termination processing is exported that is based on the Wire termination processing connection property. In this table, you assign each connection category a wire termination processing.

In the Connection category column, all entries are listed that have been defined in parts management. In the Wire termination processing column, you specify how the connection should be closed, e.g., with a conductor sleeve or a cable lug. The values entered here are carried over to the connection properties during routing and used subsequently in the export of connections.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

Wire termination processing (default):

The wire termination processing entered here is always used during routing if no connection category has been defined for the connection point in question.

Use of dual sleeves:

Here you specify the circumstances under which dual sleeves are to be used in the export of connections:

  • Always use: In the export of connections, dual sleeves are always used if two connections lead to the same connection point.
  • Use when prescribed: In the export of connections, dual sleeves are used if two connections lead to the same connection point and if the Dual sleeve prescribed property has been activated for the connection point in question in the connection point pattern (local connection point pattern or at the part).
  • Never use: Generally, no dual sleeves are used.

The Use when prescribed option is set by default.

Note:

For routing connections in a topology, the usage of dual sleeves is not considered.

Terminal Strip and Terminal Accessories

EPLAN makes a distinction between alignable and non-alignable accessories.

Non-alignable accessories

Non-alignable accessories belong to either a terminal or a terminal strip and are attached to it, e.g. terminal labels or strip labels. You enter these accessory parts at the terminal or terminal strip definition as a part. Non-alignable accessories are not shown in terminal-related reports (e.g., in the terminal diagram).

Non-alignable terminal accessories can be shown in the Preview accessories column in the dialog Edit terminal strip. The accessory is defined through the product subgroup in the parts management. To ensure that these parts are reported as non-alignable accessories, the Alignable check box in the Properties tab of the parts management must be deactivated.

The following non-alignable terminal accessories are displayed in the preview:

  • Cover
  • Terminal label
  • Cross-connector
  • Switching jumper
  • Switching lock
  • Attachment nut
  • Plug housing
  • Plug accessories
  • Test accessories
  • Partition
  • Other labels.

Alignable accessories

Alignable accessories are attached to the terminal strip. They can be sorted before or after a terminal. You enter these accessory parts at the relevant main terminal as a part. If you are not using main terminals, enter these accessory parts at the terminal strip definition as parts.

Possible parts for accessories

A part can be an alignable accessory if it belongs to one of the following product subgroups for terminals:

  • Cover
  • Terminator
  • General
  • End clamp
  • Terminal label
  • Strip label
  • Cross-connector
  • Rails
  • Plug housing
  • Plug accessories
  • Test accessories
  • Mounting rail
  • Partition
  • Undefined
  • Other labels
  • Tools.

To ensure that these parts are reported as alignable accessories, you must select the Alignable check box in the Properties tab in parts management. The check box is selected by default for the "Terminator", "End clamp" and "Partition" product subgroups; for all other product subgroups it is deselected by default. Terminals are always alignable, i.e., for the "Terminals" product subgroup the Alignable check box is selected and cannot be changed.

If the Display alignable accessories property is active in terminal-related reports, additional lines are generated for alignable accessories. In this case, the alignable accessories is not additionally displayed in the terminal's line. This behavior does, however, not apply when using product subgroup-specific placeholder texts ("Terminal part reference by product subgroups" etc.) - there, the alignable accessories are always included in the display of the terminal's line.

All non-alignable parts are simple parts of the terminal or terminal strip and are not shown as accessories in terminal-related reports (e.g., in the terminal diagram) or in the Edit terminal strip dialog.

A maximum of 50 parts references can be saved on each terminal / terminal strip definition. As one part reference is already occupied by the main part, this means that a maximum of 49 accessory parts can be assigned.

Note:

If you convert an older parts database (pre-version 2.0), the Alignable check box is selected for all parts in the "Terminals" product group which belong to one of the following product subgroups:

  • Cover
  • Terminator
  • End clamp
  • Terminal
  • Strip label
  • Rails
  • Plug accessories
  • Test accessories
  • Mounting rail
  • Partition
  • Other labels
  • Tools.

Creating a library for the Word discipline

Previously, the discipline components were inserted in the mechatronic modular system T_Mechatronic_ModularSystem below the Word_Components unit. The discipline components is now to be collected in their own library.

Creating a library for the Word
  1. In the Library Catalog click .
  2. Enter T_Office_Word in the Name field.

Import the libraries Word, T_Mechatronic_Architecture and T_Images and T_Interfaces:

  1. Open the editor page Imported libraries.
  2. Click the symbol [Add library].
  3. In the Library finder dialog click [Search].
  4. Mark the libraries Word, T_Mechatronic_Architecture, T_Images and T_Interfaces.
  5. Confirm with [OK].
  6. Save the library.

Removing discipline components

As long as instances of the discipline components are still installed in the mechatronic components, they cannot be moved into the new libraries T_Office_Word. Therefore all instances have to be removed first.

  1. Open the component Cylinder.
  2. Select the discipline component Row.
  3. Delete the discipline components with .
  4. Repeat Steps 1 to 3 for Valve, Posistionsensor_inductive, Positionsensor_optical and Pressuresensor.
  5. Repeat steps 1 to 3 for Feeder with the instances ListOfComponents, Actuators_Table and Sensors_Table.

Repeat Steps 1 to 3 for Valve, Posistionsensor_inductive, Positionsensor_optical and Pressuresensor.

Moving discipline components and parameters in the T_Office_Word library

Making the T_Office_Word library visible for T_Mechatronic_ModularSystem

  1. Open the T_Mechatronic_ModularSystem library.
  2. Open the editor page Imported libraries.
  3. Click the symbol [Add library].
  4. In the Library finder dialog click [Search].
  5. Select the T_Office_Word library.
  6. Confirm with [OK].
  7. Save the library.

The visibility is established.

Moving discipline components and parameters

  1. In the T_Mechatronic_ModularSystem library select the units Word, Word_Components and Parameter.
  2. Drag the units into the T_Office_Word library.

Cleaning up parameters

  1. Remove the Parameter unit of all parameters that are already available in the Word.Parameter unit.
  2. Move all other parameters into the unit Word.Parameter.
  3. Delete the Parameter unit.

Undoing visibility

  1. Open the T_Mechatronic_ModularSystem library.
  2. Open the editor page Imported libraries.
  3. Select the T_Office_Word library.
  4. Press the key [Del].
  5. Save the library.

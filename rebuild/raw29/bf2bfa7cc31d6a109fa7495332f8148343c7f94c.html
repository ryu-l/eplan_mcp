Dialog Settings: Numbering

Dialog call:

You have opened a project.

  • You have selected terminals in the graphical editor, the terminal strip navigator, or in the device navigator. You have selected pages or a project in the page navigator. Project data > Terminal strips > Number terminals. In the Number terminals dialog, click [...].
  • You have selected pins in the graphical editor, the plug navigator, or in the device navigator. You have selected pages or a project in the page navigator. Project data > Plugs > Number pins. In the Number pins dialog, click [...].

In this dialog you create a new numbering scheme or edit an existing user-defined scheme.

Use a numbering scheme to establish the method of numbering, whether it is for terminal or pin designation labeling, for example, the terminals / pins are to be alphanumerically or purely numerically numbered.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent toolbar for this purpose.

Default formats:

If this check box is selected, the standard format defined below will be used for numbering.

  • According to online numbering format: If this option is selected, the terminals / pins will be numbered according to the current settings of the online numbering format.
  • According to device definition: If this option is selected, the terminals / pins will be assigned the designations from the function templates.

If this check box is deselected, the terminals / pins will be assigned designations according to the table below.

Quantity:

Here you enter the quantity of terminals / pins that you wish to number. The corresponding number of lines will then be displayed in the table below.

In every row of the Designation column in the table specify the value that will be the designation for the nth terminal or the nth pin. When numbering, the designations that are entered here will be assigned later on to the terminals or pins in the series.

Tip:

If you wish to define a large number of terminal / pin designations (e.g., A001-A100), you can use Excel to create them and then transfer them into the numbering scheme via Clipboard. For this you select the required cells in Excel and copy them to Clipboard. In the Settings: Numbering dialog specify the required number of rows. Then position the cursor in the first row and insert the contents from the Clipboard using [Ctrl]+[V].

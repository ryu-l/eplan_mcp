Dialog Select fitting

Dialog call:

You have opened the Edit <...> dialog. Click [...] in the field Fitting left or Fitting right.

In this dialog select the fitting to be mounted on the left or right on the hose. If you have selected the DIN20066 2012-01 scheme preset by default in the settings, the type of construction and the series listed in DIN 20066 are presented with corresponding preview graphics for selection.

Overview of the main dialog elements:

Series:

You can limit the display of the type of construction according to the series in the drop-down list.

Preview:

In as far as available a preview window with a corresponding graphic of the type of construction is displayed in a 2 x 4 image matrix for each series.

A corresponding image file of the type "*.png" or "*.jpg" has to be stored in the settings so that a graphic of a type of construction can be displayed in a preview window. The graphics stored in the default setting are animated graphics of the type "*.png". If you move the cursor over one of the preview windows, or click the fitting, an animation of the displayed fitting is shown.

To select a fitting double-click the preview window with the desired type of construction.

Buttons:

If the selected series encompasses more than eight fittings, these are displayed on a new page of the dialog. The arrow button can be used to navigate through the selection pages.

The selection page on which you are located and the total number of selection pages available is displayed on the right next to the buttons.

Further navigation and selection options

The keyboard can also be used to navigate through the pages of the fitting selection and to select a fitting. You can use the cursor, page Up, Page Down and Enter keys to this purpose.

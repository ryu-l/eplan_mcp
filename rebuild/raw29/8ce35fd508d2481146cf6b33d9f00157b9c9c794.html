Creating an Export / Labeling Scheme

Export / labeling schemes / External report schemes allow the format elements and settings for manufacturing data report / labeling or external reports to be stored and re-used. This allows you to repeatedly output data using the same settings.

Precondition:

You have opened a project.

  1. Utilities > Manufacturing data > Export / labeling
  2. Click [...] next to the Settings field in the dialog Export manufacturing data / output labeling.
  3. In the dialog Settings: Manufacturing data export / labeling click (New).
  4. In the Report type dialog select a report type and click [OK].

    The report type specifies the group of similar information to be reported in the export / labeling file / external report file.
  5. Enter a name and description in the dialog New scheme and click [OK].

    The report type that you select here is displayed in the Report type field in the dialog Settings: Manufacturing data export / labeling.

    You can now Specify settings for *.txt output or Specify settings for Excel output.

Creating and Deleting Pages

Creating Pages

Precondition:

You have opened a project. You have opened the Pages - <Project name> navigator dialog.

  1. Select the menu items Page > New.

    The New page dialog is opened. If a page was selected in the Pages - <Project name> navigator dialog, its properties are loaded into the dialog. If a structure level was selected, the properties of the first page below this level are loaded. Only the grid defined in the plot frame is adopted.
  2. Click [Clear fields] if you want to clear the data fields in the currently-selected page, i.e. to delete their content.

    The content of the data fields is deleted. Only the page type of the currently selected page is retained. The automatically suggested page name is also retained. Scale and grid are taken from the plot frame and are also retained.
  3. If necessary, manually change the suggested page name in the Full page name field, or use [...] to open the Full page name dialog and edit the structure identifier and the page name. You can use [...] to select the structure identifiers (such as higher-level function and mounting location) from the existing values. You can also manually enter the identifiers and create new ones in the process.
  4. Assign an interactive page type to the page from the drop-down list in the Page type field, or use [...] to open the Add page type dialog and select an automatic page type.
  5. Enter a descriptive text into the Page description field; this is also displayed in the page navigator tree and list views.
  6. If necessary, enter further properties for the new page.
  7. If you would like to create several pages, then click [Apply] several times.

    With every click on [Apply], EPLAN generates a new page. Your user code is automatically entered into the Creator field.
  8. Click [OK].

    If you selected Project by project or Per structure identifier for the path numbering (Options > Settings > Projects > "Project name" > Management > Pages), a prompt is displayed, asking whether you want to automatically update the path designations.

    EPLAN checks if the page name that you have entered already exists and, if so, an appropriate message is displayed, in which you can choose another name.

    The (last) new page is then displayed in the graphical editor.

Tips:

  • You can use the button on the standard toolbar to create new pages.
  • You can create new pages in the Page navigator, by using the popup menu item New. Any page or structure level may be selected when you do this.

Delete pages

  1. Select the relevant pages in the Pages - <Project name> navigator dialog.
  2. Select the Delete popup menu item.

    After a confirmation prompt EPLAN deletes the selected pages from the project.

Note:

Positioned items are completely removed when the page is deleted.
Non-placed items are not removed, because they are not associated with the deleted pages.

Tip:

The page opened in the graphical editor can also be selected using the Edit > Select > Page menu item and then deleted using [Del]. The page navigator does not need to be open for this.

Deleting all pages in a project

  1. Select the name of the project in which you wish to delete all the pages in the Pages - <Project name> navigator dialog.
  2. Select the Delete popup menu item.

    After a confirmation prompt EPLAN deletes all the pages from the project.

Exporting Your Own Sets of Identifiers, Connection Point Designations, and Connection Point Descriptions

If you have created your own identifier sets, connection point designations, and connection point descriptions, you can export these into XML files. This file can be used, for instance, as a backup for the exchange of data.

Export identifier sets

  1. Utilities > Master data > Identifier
  2. Select the columns with the identifier sets you want to export.
  3. Select the Export popup menu item.
  4. In the Export dialog, switch to the desired directory and enter a file name.
  5. Click [Save].

    The selected identifier sets are saved in an XML file.

Export connection point designations and descriptions

  1. Utilities > Master data > Connection point designation / description
  2. Select the Connection point designations or Connection point descriptions tab.
  3. Select the Export popup menu item.
  4. In the Export dialog, switch to the desired directory and enter a file name.
  5. Click [Save].

    All sets of connection point designations and descriptions are saved in an XML file.

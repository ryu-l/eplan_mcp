Target information

Electrical engineering

The target information includes properties on target connection points, target items, target devices, and connections to the target and cables of the connections to the target. In the terminal-connection diagram, a distinction is made between internal and external targets. Only the first internal and the first external target of each connection point or terminal is considered. In the device-connection diagram, all targets are treated as external targets. In the cable connection diagram, the source is defined as end of the connection of the internal start connection point, and the target is the external starting connection point.

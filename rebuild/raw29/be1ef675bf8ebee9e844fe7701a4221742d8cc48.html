Dialog Back up <Master data>

Dialog call:

Project > Back up > "Master data"

In the Back up <Master data> dialog, you define how and where the selected master data are to be backed up. The dialogs have the same structure for all master data.

The following master data can be backed up from the dialog:

  • Basic projects
  • Project templates
  • Symbol libraries
  • Plot frames
  • Outlines
  • Forms
  • Macros
  • Parts data
  • Dictionaries
  • Project-independent settings.

Note:

Graphics in plot frames or forms are only backed up when they are stored in the plot frame or form. Referenced graphics cannot be saved and restored.

Overview of the main dialog elements:

Directory:

Select the directory where the backed up master data is located. The default master data directory is preset (as determined under the Options > Settings > User > Management > Directories menu path). Click [...] to open the Browse for Folder dialog and then navigate to the desired directory.

You can use the Insert path variable popup menu item to branch to the dialog Select path variable where you can select one of the available path variables.

Master data: <Master data>:

This table displays the master data in the selected directory. Click the column headers to sort the master data in ascending, descending, or original order. Select the master data you wish to back up. If nothing is selected, then all master data is backed up.

Back up subdirectories:

Select this check box if you want the master data in the subdirectories to be backed up as well.

Backup file name:

Enter the name of the file in which the selected master data is to be backed up. Click [...] to open the Select backup file dialog and then navigate to the desired directory, or create a new one.

Description:

In this field you can enter a text description (e.g. storage location) that is stored with the master data and which can be displayed from within EPLAN during backup and restore operations.

Backup medium:

Define whether the master data is to be backed up to a storage medium (hard disk, removable media, etc.) or sent via e-mail:

  • Storage medium: If this option is selected, the master data is backed up to a storage medium.
    Enter the storage location into the Target directory field. You can specify any drive and subdirectory as the target for the data backup.
    Click [...] to open the Select directory dialog and then navigate to the desired directory, or create a new one.
    You can use the Insert path variable popup menu item to branch to the dialog Select path variable where you can select one of the available path variables.
  • E-mail: If this option is selected, the master data is sent as an e-mail. Once the function has been called up, the master data are zipped using the internal zip program and your installed e-mail editor is started.
    From the Split size drop-down list select the maximum size for an individual e-mail file. The possible values are 1 MB to 10 MB in 1 MB increments, or you can select "Unlimited". EPLAN automatically creates the number of e-mail files required to send the whole project. All individual mails in the group will have this text in the subject line: "<Backup file name> n/m". "n" is the number of the individual e-mail file and "m" is the overall quantity of the files.

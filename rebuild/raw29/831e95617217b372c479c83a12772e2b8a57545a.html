Preparing an Excel Table for Import (Pre-planning)

In order to prepare an Excel table for the data import, it is necessary to define an area in the Excel table containing the data to be imported. The Excel table can, but does not have to, contain a column name.

Precondition:

You have access to an Excel table containing suitable data.

  1. Open the Excel table in Excel.
  2. In Excel select the menu item Formulas > Name manager.
  3. Click the [New] button.
  4. Enter a meaningful name for the import area in the New name dialog, in the Name field.
  5. Click the symbol next to the Applies to field, at the lower right.

    The dialog is minimized.
  6. Select the desired data area in the Excel table, including the column headers.

    The selected area is marked with a dotted line.
  7. Click the symbol next to the Applies to field once more.

    The dialog maximizes once more.
  8. Click [OK].

    The new name is entered into the list box of the name manager.
  9. Click [Close].

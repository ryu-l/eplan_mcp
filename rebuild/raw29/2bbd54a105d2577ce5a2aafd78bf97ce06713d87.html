The help system

The EPLAN help system contains conceptual information, instructions and dialog descriptions on most functions of the program. The help system is displayed on your computer in the default Internet browser. The help system can be used context-specifically via [F1] or context independently.

Reference.

In addition to the EPLAN help, the help system also includes the "EPLAN overviews". Here you receive additional information on special topics (for example EPLAN properties and placeholder elements). The icon is used for help pages that describe check run messages.

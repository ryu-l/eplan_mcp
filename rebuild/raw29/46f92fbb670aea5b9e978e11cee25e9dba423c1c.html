Duplicating Objects in the Layout Space

Using the Duplicate command, you can insert multiple copies of 3D objects and 3D macros in the layout space very easily at the same time. Duplication only works within the layout space, not across layout spaces.

Precondition:

You have opened a project. A layout space is open.

  1. Select the object, 3D macro, or group of objects to be duplicated by drawing a border around these objects, and select the Edit > Duplicate menu items.

    The objects hang on the top left handle on the cursor. Press [A] to change the handle.
  2. Select the Placement options popup menu item to open the Placement options dialog and set the rotation angle, handle and offset values. Click [OK].
  3. Place the first copy.
  4. In the Duplicate dialog, enter the total number of elements to be created.
  5. In the subsequent Insertion mode dialog determine how the structure identifiers of the duplicated objects are to be treated. Click [OK].

    EPLAN automatically generates the specified number of copies and places them at the distance selected for the first copy. In the layout space navigator the copies are entered in the hierarchy parallel to the source objects.

    Tips:

    • You can also generate a single copy by holding down the [Ctrl] key while clicking the object and then dragging the copy to its new position.
    • If you want to edit multiple 3D objects together in a layout space (duplicate, copy, move, cut, delete) you, after marking, combine these 3D objects to a group with the menu items Edit > Other > Group. You can subsequently undo the grouping again with Edit > Other > Ungroup.

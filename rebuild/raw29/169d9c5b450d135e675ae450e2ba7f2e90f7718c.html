Creating Check Run Schemes for Project Verification

You use check run schemes for the project verification in order to specify which runs EPLAN should execute.

Preconditions:

  • Select a project management database
  • Load directories and projects
  1. Project > Management
  2. Select a project.
  3. Select [Extras] > Verify project.
  4. Click [...] next to the Perform project checks field.
  5. Next to the Scheme field click (New).
  6. In the New scheme dialog, enter a recognizable name for the new scheme in the Name field and click [OK].
  7. Select a message class in the Class column.

    The table on the right side of the dialog shows the messages possible for this class.
  8. Use the drop-down list in the Category column to specify for each message whether the message should be displayed as an error, a warning, or a note.
  9. Use the drop-down list in the Type of check column to determine whether the check should be run both online and offline (setting "Online / offline") or only offline (setting "Offline"), or whether the corresponding check should not be run (setting "No").
  10. Click [Save] and then click OK.

Updating the Parts Database

If you work with several EPLAN versions (e.g., when switching to version 2.9) and have in version 2.9 an "older" parts database, you will be prompted upon opening parts management to update the parts database.

If you click [No], then the parts database is not updated. In this case the parts database is opened, but it cannot be edited, only viewed. However, part or device selection is possible.

Notes:

  • If you work with several EPLAN versions, you must always use the latest EPLAN version when editing and managing the parts database.
  • New and updated old parts databases can be opened and edited in the EPLAN versions 2.5, 2.6, 2.7 and 2.8. In older EPLAN versions (Version 2.4 or older) these parts databases can, for example, be opened for part or device selection, but cannot be edited.

Synchronizing Function Texts

The synchronizing function texts allows you to analyze various function texts of placed and unplaced functions in a device tag and thus harmonize different writing styles used in those texts.

Preconditions:

  • You have opened a project. You have opened a project page in the graphical editor.
  • You have selected a component.
  1. Select the Synchronize function texts popup menu item.
  2. In the dialog Synchronize function texts <DT> select the function definition whose function text is to be transferred to all other function definitions of the device.
  3. Enter the function text in the Function text column, if necessary, or revise the existing function text.
  4. Select the popup menu item Transfer function text in the row containing the function definition whose function text is to be transferred to all the other ones.
  5. Click [OK].

    The selected function text is transferred to the properties Function text and Function text (automatic)of all the function definitions, whereby the formatting and foreign language translation are also transferred. Existing function text is overwritten in the process.

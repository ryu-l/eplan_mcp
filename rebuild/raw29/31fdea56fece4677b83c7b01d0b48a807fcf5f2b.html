Creating Graphical Pre-planning

Structure segments are drawn on a pre-planning page like structure boxes, and planning objects like black boxes. But the symbols used differ. The segments located on a pre-planning page can be connected by means of connection planning objects. Connection planning objects are drawn as open polylines.

Insert new segments

Precondition:

You have opened a project, and you have opened a page of the "Pre-planning" page type.

  1. Select Insert > Box / connection point / mounting panel > Structure box to create a structure segment. Or select Insert > Box / connection point / mounting panel > Black box to create a planning object.
  2. Draw the rectangle representing the box.

    If there are several segment definitions in the project, the Select segment definition dialog opens.
  3. Select the desired segment definition and click [OK].
  4. Enter a designation for the structure segment or planning object in the Properties <...> dialog.
  5. Specify additional settings in the other tabs of the Properties <...> dialog.
  6. Click [OK].

    A structure segment or planning object is created with the corresponding properties.

Tip:

You can also draw structure segments and planning objects as polygons. In this context, the SPECIAL symbol library provides the special symbols SCSS2 (for structure segments) and DCPLO2 (for planning objects). Insert such a symbol via the symbol selection (Insert > Symbol), draw the polyline in the required form, and end the action via the popup menu item Complete polyline.

Inserting new connection planning objects

Precondition:

You have opened a project, and you have opened a page of the "Pre-planning" page type.

  1. Select the following menu items: Insert > Symbol.
  2. Select the PLINE symbol for a connection planning object as a polyline from the SPECIAL symbol library.
  3. Click in the box of a segment to specify the starting point of the polyline.

    The selected segment is entered in the properties of the connection planning object as the source segment.
  4. Specify the further points of the polyline consecutively.
  5. Click in the box of a further segment to specify the end point of the polyline.

    The selected segment is entered in the properties of the connection planning object as the target segment.
  6. Select the popup menu item Complete polyline to complete drawing of the polyline.
  7. Mark the desired segment definition in the Select segment definition dialog and click [OK].
  8. Enter a designation for the connection planning object in the Properties <...> dialog.
  9. Specify additional settings in the other tabs of the Properties <...> dialog.
  10. Click [OK].

    A connection planning object with the corresponding properties is created.

Place existing segments

Preconditions:

  • You have opened a project, and you have opened a page of the "Pre-planning" page type.
  • You have opened the pre-planning navigator.
  1. Highlight a structure segment or planning object in the pre-planning navigator.
  2. Select the Place popup menu item.

    The symbol for a box hangs on the cursor.
  3. Draw the rectangle representing the box.

    The properties of the segment are transferred to the box.

Tip:

You place a segment graphically multiple times. This way a segment can be displayed on multiple pre-planning pages.
In the process the further placements of a structure segment or planning object cannot be placed within another box, meaning below a different segment. In the tree view of the pre-planning navigator further placements of a segment are identified by the icon.

Placing existing connection planning objects

Preconditions:

  • You have opened a project, and you have opened a page of the "Pre-planning" page type.
  • You have opened the pre-planning navigator.
  1. Mark a connection planning object in the pre-planning navigator.
  2. Select the Place popup menu item.

    The symbol for polyline is attached to the cursor.
  3. Define the starting point of the polyline. If in the process you click in the drawn box of a segment, this segment is used as the source segment of the connection planning object.
  4. Specify the further points of the polyline consecutively. If in the process you position the last corner point in the drawn box of a segment, this segment is used as the target segment of the connection planning object.
  5. Select the popup menu item Complete polyline to complete drawing of the polyline.

    The properties of the connection planning object are transferred to the polyline.

Tip:

You can also place structure segments, planning objects and connection planning objects easily by using Drag & Drop by dragging a highlighted segment from the pre-planning navigator to your open pre-planning page in the graphical editor.

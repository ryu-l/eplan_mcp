Tab Label

Dialog call:
  • You have opened a project. Utilities > Manufacturing data > Export / labeling. Click [...] next to the Settings field in the dialog Export manufacturing data / output labeling. In the dialog Settings: Manufacturing data export / labeling select the Label tab.
  • Options > Settings > User > Interfaces > Manufacturing data export / labeling. In the dialog Settings: Manufacturing data export / labeling select the Label tab.

In this tab you can specify the format for the data to be output on the labels / exported.

Overview of the main dialog elements:

Available format elements:

The format elements available are in this field. The format elements available depend on the report type selected.

Selected format elements:

In this field are the format elements that make up the format for the data on the label.

Number of adjacent labels:

The number in this field specifies how many labels are output next to one another.

If the file type "Excel file (*.xls, *.xlsx, *.xlsm, *.xlsb)" is selected on the File tab, the properties are output in a corresponding number of columns if the setting Without template is selected, with all the properties of object 1 being reported, then all of object 2, etc. If the setting With template is selected-, the output is analogous, but a placeholder has to be defined for each column.

Example:

If you want to output three properties and three labels next to each other, nine columns with placeholders have to be defined in the template.

Separator for adjacent labels:

In this field, you can specify the separator to be placed between adjacent labels.

Example:

Input

Result

;

K1 ANL1;K2 ANL2

,

K1 ANL1,K2 ANL2

Rows of labels per page:

The number in this field specifies how many rows of labels are to be output on each page. If this value is "1", 1 page is output per part.

When the specified number is reached, a new sheet is started with the next row. (The maximum value possible is "1,048,500" rows.)

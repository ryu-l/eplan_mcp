Routing paths

User interface / operation

Segment of a routing path network. Routing paths are automatically or manually inserted sections along which connections can be routed. Routing paths can, but do not have to, consist of a material, and can have a part.

Layout space:
When generating the routing path network automatically, routing paths are generated automatically in wire ducts. Routing paths can also be generated manually in order to extend the routing path network outside of the wire ducts.
Graphically, the routing paths are displayed as blue lines with snap points at the starting/end points and the center.

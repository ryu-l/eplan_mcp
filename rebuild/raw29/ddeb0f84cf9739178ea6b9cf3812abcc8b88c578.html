Dialog Settings: Display / output

Dialog call:

You have opened a project.

  • Options > Settings > Projects > "Project name" > Reports > Display / output.
  • Utilities > Reports > Generate > [Settings] > Display / output.

In this dialog, you can specify display and output settings for report pages.

Overview of the main dialog elements:

Replace identical texts by:

During the display of reports it is possible that the repeating identical texts are output., for example function texts. Such identical texts can be replaced on the report pages by a replacement character. You specify this replacement character here.

You specify the texts that are to be replaced in the reports while editing the forms in the form editor while inserting or editing placeholder texts. For this reason the Replace identical text check box is available for placeholder texts on the Placement tab. If the check box is activated, repeated function texts placed below each other are replaced with the replacement character specified here.

Example:

You specify the repeat character " as the replacement character.

Main function

Position

Motor

=AP+0/1.2

"

=AP+ST1/2.15

=AP+0/1.1

Replace variable values with:

This functionality applies to the "Summarized parts list" report. If you link a placeholder object with a function then you can manage several value sets in the placeholder object and assign a current value set to the function. When reporting the function, the values of the currently assigned value set are output by default. This functionality allows you to replace the values of the currently assigned value set with fixed text when reporting functions of this type. To do this the Replace variable values with text form property in the summarized parts list form must be activated. You can also use the popup menu to enter multi-line text or manually translate the text.

Example:

If you enter the text See table into this field, then the text See table will be output at the position where EPLAN would otherwise display the values of the currently assigned value set. In this way you can (e.g.) refer to a table showing the values of all value sets.

Tip:

We recommend only activating the Replace variable values with text form property when it is actually required. If this form property is activated then the program searches all placeholder texts. Depending on the project size, this can take some time.

Start page offset for output group:

In this field you enter the number by which the start page names are increased from the second output group onwards. By this, space is retained between the reports so that all reports of one output group can follow behind each other.

This setting can only be used for numeric page names; in addition, the entry in the Fill identifier block with output group field must be set to "No".

Fill identifier block with output group:

Use this drop-down list to determine which identifier block in the start page specification of the report is to be overwritten with the value of the output group. Possible values are "No" or one of the identifier blocks from the project structure. For this identifier block, a structure identifier is generated for each value of the output group and the report sorted below this structure identifier in the page structure.

This setting is used if the "Output group" option has been selected in the Page sorting - <Report type> dialog in the Sort by / into field.

Example:

Your project structure has the identifier blocks "Higher-level function" and "Mounting location", and you select the "Mounting location" entry here. In the Output group property, you have entered the following values at different components: AB, CD, EF. During the evaluation, the name of the output group is entered as start page specification for the mounting location, and a separate report block is generated for each value of the output group. This will create the mounting locations AB, CD, EF and sort-in the reports there.

Restrict output of cables:

If this check box is deselected, then all of the cables are always output in report pages. If the check box is selected, then only those cables are output which contain a minimum number of cable connections. The minimum number is specified in the Output from number of connections field.

Determine source / target of cable connections via the cable connections:

If the check box is selected then source and target of the cable connections are not defined by the associated cable. If the check box is deselected, then source and target of the cable connections are defined by the associated cable.

Restrict output of terminal strips:

If this check box is deselected, then all terminal strips are always output in report pages. If the check box is selected, then only those terminal strips are output which contain a minimum number of terminals. The minimum number is specified in the Output when number of terminals reaches field.

Restrict output of plugs:

If this check box is deselected, then all of the plugs are always output in report pages. If the check box is selected, then only those plugs are output which contain a minimum number of pins. The minimum number is specified in the Output when number of male pins reaches field.

Use for individual connections:

If this check box is selected, then individual connections in the terminal diagram or plug diagram can be shown with a replacement character. The replacement character is entered in the Character for display in cable chart field. To allow individual connections to be displayed in the terminal or plug diagram, the Display all connections check box in the Placement tab of the Properties - Placeholder text dialog must be selected.

Use for cable connections:

If this check box is selected, then cable connections in the terminal diagram or plug diagram can be shown with a replacement character. The replacement character is entered in the Character for display in cable chart field.

Example:

If you enter X as the replacement character, then all cable connections in the data area of the cable chart are displayed with an X.

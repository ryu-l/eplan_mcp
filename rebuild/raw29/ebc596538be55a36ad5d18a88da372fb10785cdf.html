Dialog Graphical preview

Dialog call:

View > Graphical preview.

This dialog shows a preview of pages, symbols, image files, macros, forms, etc. The object currently selected in the selection dialog is displayed when the corresponding Preview check box is selected. This applies to (e.g.) macro and form selection, etc.

Overview of the main dialog elements:

The preview shows the page just as it appears in the graphical editor. All information on the page is displayed, even if it lies outside of the plot frame. The plot frame and page size are considered in the display.

  • If a page is highlighted in the Pages - <Project name> navigator dialog, then this page will be displayed in the graphical preview. If multiple pages are highlighted they will be shown below and next to each other in the preview.
  • If a function is highlighted in a navigator showing device data (e.g., Devices - <Project name>, Cables - <Project name>, ...), the graphical preview shows the page containing the function. The function's position is highlighted.
  • If you selected a message in the Message management - < Project name> dialog, the graphical preview displays the page to which the message relates, and the faulty function is highlighted.
  • If an entry is highlighted in the Device list dialog, the graphical preview shows the symbol or macro associated with the part. If you add a new part to the device list using the part selection tool, again, the symbol or macro associated with the part is shown.
  • If a part is highlighted when you select a device, the graphical preview shows the image file associated with the part.
  • If a macro file entry is selected in the Generate PLC schematic dialog then the macro variants contained in this macro file are shown in the graphical preview.
  • If in the Select macro, Select plot frame, Select form ... dialogs, the Preview check box is selected, then the corresponding object will be displayed in the graphical preview.
  • If, in the part master data navigator, you selected a part to which data for the device selection is assigned on the Function templates tab in parts management, the graphical preview will display the device that was placed in the graphical preview using drag&drop.
  • If a section has been selected in the Project options - <Project name> navigator dialog, the content of the section will be displayed in the graphical preview. If multiple sections have been selected, they will be shown below and next to each other in the preview.

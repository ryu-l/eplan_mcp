Dialog Settings: Pre-planning depth

Dialog call:

You have opened a project. Options > Settings > Projects > "Project name" > Pre-planning > Pre-planning depth.

Use this dialog to define the error checking for different types of segments. For this purpose, you specify mandatory properties, i.e., properties that these segments must have. Mandatory properties can be both EPLAN properties and user-defined properties.

The mandatory properties are checked to see whether a value has been entered, the property is enabled, or the "Undefined" entry has not been selected in connection with a drop-down list.

For error checking to take place, you must specify the type of check for the required error checking in your check run scheme.

The following dialog elements are available:

The following columns are displayed in the table:

  • Row: Consecutive row number.
  • Name: Here, you specify the name of the check run, for example, the required pre-planning level. This name is displayed in message management as a message text in the corresponding check run message.
  • Segment definition: In the drop-down list, you select the type of segment for which you want to define mandatory properties. By selecting an individual segment definition, you can check only identical segments (e.g., loops); by selecting a basic segment definition, you can check segments of a certain category (e.g., all PCT loops, which includes both loops and consumers); or you can check all segments via the "All" entry.
  • Mandatory property 1 ... 10: For each check run, you can specify up to ten mandatory properties. In a cell click [...], which opens the Property selection dialog, and then select the required property there.

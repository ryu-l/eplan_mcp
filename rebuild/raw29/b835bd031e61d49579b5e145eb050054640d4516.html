Dialog Description of page modification

Dialog call:

You have generated a revision and have opened a revision project (file extension *.ell).

  • Under the project settings in the Settings: Revision (change tracking) dialog, you have selected the Always prompt for description of page modification check box. You make changes to a page, such as generation, deletion, renaming (including renaming due to renumbering), import, generating reports, and so forth. In the Revision marker dialog, edit or accept the marker text and click [OK].
  • You have made changes to one or more pages. You have selected the affected pages in the page navigator. Utilities > Revision control > Change tracking > Complete pages.

In this dialog, you have the option of describing changes that you have made on a page in a revision project. The texts entered will be used for the printed and / or graphical output of the revision overview.

If you would like to revise the texts entered here, you can change them in the Edit revision data dialog.

The following dialog elements are available:

Revision index:

This field is provided for a text that can be used to identify the page modification. The revision index can consist of any arbitrary characters. Use [...] to open the Select revision index dialog. There you can select an already assigned revision index and change it if necessary.

If you have specified a numbering scheme in the Settings: Change tracking (numbering of the revision index) dialog, a new value is automatically determined for the revision index from the numbering scheme.

Description:

In this field, you can attach a comment to the page modification performed.

Reason for change:

This field is provided for the entry of the reasons for modification.

User:

In this field, the user is automatically provided who it is that described the page modification. It cannot be changed.

Defined working section:

This field displays the currently active defined working section. The entry cannot be modified.

Date:

The date on which the description was entered is automatically written to this field. It cannot be changed.

Generate report when completing pages:

If this check box is selected, the selected report pages such as the table of contents are updated when pages are completed. If generating a report produces a modification to a report page (for example, in the table of contents, in the revision overview, etc.), this page is completed with the same revision index, and the "Draft" identifier for this page will be removed. The selected report pages are updated even if they are not identified as a 'draft'.

If the check box is deselected then report pages are not updated.

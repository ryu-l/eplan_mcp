Action: search


Parameters

Description

TYPE

Describes the search range:
DEVICETAG: Search by device
ALLPROPERTIES: Search through all properties
TEXTS: Search text
PAGEDATA: Search page data
PROJECTDATA: Search project data

PROJECTNAME

Project name with complete file path (optional).
If nothing is entered, the selected project will be used if the action is to be run over the user interface (e.g. via script or the toolbar). When executing from the Windows command line, PROJECTNAME must be specified or ProjectAction has to be used before that. Otherwise a system message will appear.

SEARCHITEM 

Text you are searching for.

CASESENSITIVE 

Case-sensitive (optional, 0 = No, 1 = Yes).
Default value: most recently used value set up in the user interface.

WHOLETEXT 

Find whole texts only (optional, 0 = No, 1 = Yes).
Default value: most recently used value set up in the user interface.

LOGICPAGES 

Search logic pages (optional, 0 = No, 1 = Yes).
Default value: most recently used value set up in the user interface.

GRAPHICPAGES 

Search graphical pages (optional, 0 = No, 1 = Yes).
Default value: most recently used value set up in the user interface.

EVALUATIONPAGES 

Search report pages (optional, 0 = No, 1 = Yes).
Default value: most recently used value set up in the user interface.

NOTPLACEDFUNCTIONS 

Search unplaced functions (optional, 0 = No, 1 = Yes).
Default value: most recently used value set up in the user interface.

Note:

The result of the search is displayed in the list of the Search results dialog only if the project for which the search was carried out is currently open in EPLAN.

Example:

Search text: 

search 
/TYPE:TEXTS 
/PROJECTNAME:C:\Projects\EPLAN\ESS_Sample_Project.elk 
/SEARCHITEM:Hallo 
/CASESENSITIVE:1 
/WHOLETEXT:0 
/LOGICPAGES:1

Search page properties:

search 
/TYPE:PAGEDATA 
/PROJECTNAME:C:\Projects\EPLAN\ESS_Sample_Project.elk 
/SEARCHITEM:Drive 
/CASESENSITIVE:0 
/WHOLETEXT:0 
/LOGICPAGES:1 
/EVALUATIONPAGES:1 
/NOTPLACEDFUNCTIONS:1

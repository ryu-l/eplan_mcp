Page Types for EPLAN Fluid

"Fluid power schematic" page type

EPLAN Fluid provides you with a special interactive "Fluid power schematic" page type for schematic planning, which is displayed in the page navigator using the icon.

When using this page type the following special features should be noted:

  • Rotating and flipping this page type to change standards is not possible.
  • Schematic objects from an electrical engineering symbol library that are placed on a fluid page (e.g. symbols for electromagnetically operated valves) are automatically assigned the "pair cross-reference" representation type. This also applies to actuation elements from fluid power symbol libraries that have an electrical function definition.
  • If black boxes and / or device connections are inserted into a page of type "Fluid power schematic", the correct function definition is automatically assigned to these schematic objects, e.g. "Black box (fluid)" or "Device connection point (fluid)".

"Function overview (fluid power)" page type

For the simplified representation of complex of fluid power functions you can create special overview pages in EPLAN Fluid. To this purpose you can use the "Function overview (fluid power)" page type. The pages of this page type are marked by the icon in the tree of the page navigator.

In these function overviews for fluid power all cross-references to the functions in the Fluid schematic are shown. The pages of this type furthermore contain autoconnecting, connections and interruption points.

The representation type "Function overview (fluid power)" is available for functions, connections and macros that are inserted / placed on function overviews.

  • This representation type is taken into consideration for global editing and reporting of functions. In the order of the representation types for functions the representation type is positioned at the last position behind the "Functional" representation type.
  • The connections on the function overviews have the representation type "Function overview (fluid power)". Such connections are shown in the connection navigator but do not have counterparts on other page types. Therefore connections with this representation type are not taken into consideration for global editing.

Setting for the trade

When creating a page of the "Fluid power schematic" or "Function overview (fluid power)" page type, the Trade page property (ID 11037) will be displayed for you by default in the properties table.

Using this property, you can specify which trade is to be used for a fluid power page.

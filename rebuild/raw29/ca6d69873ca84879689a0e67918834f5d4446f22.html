Create placeholder objects for sensors

Analog to the schematic page a placeholder object has to be added for each sensor to equip the macros with variables.

  1. Select Insert > Placeholder object.
  2. Inside the Sensor_Inductive macro box, open a frame that includes all the elements.

The dialog Properties (components): Placeholder object opens.

  1. Open the popup menu of the table.
  2. Select Adopt variables.

The Variable column is then automatically filled with the name of the variables.

Note:

The variables for the socket and plug parameters must not be entered in the Variable column, so that no duplicate objects can be created during the automatic application of the parameters.

  1. From the Variable column remove the variable entry for the plug parameter (#<Plug:IP>).
  2. Open the Values tab.
  3. From the Variable column remove the variable entry for the plug parameter (#<Plug:IP>).
  4. Confirm with [OK].

Note:

Make sure that the anchors of the placeholder objects are inside the macro boxes; otherwise, the macros cannot be created correctly.

PDF Comments: Procedure

Redlining involves the exchange of a project between a project editor and a project redliner. The following procedure is possible:

  • Output pages as PDF Files: The project editor exports EPLAN pages to a PDF file.
  • Send PDF file for checking or Release PDF file for commenting: The project editor opens the generated PDF file in Acrobat Professional or Acrobat Standard and releases it for commenting in Acrobat Reader.
  • Add PDF comments to the PDF file: The project redliner adds PDF comments to the PDF file by inserting graphical and text comments into the PDF pages. The redliner then sends the commented PDF file back to the project editor.
  • Merge the PDF comments of the PDF files: The project editor opens the commented PDF file in Acrobat Professional or Acrobat Standard and merges the PDF comments.
  • Import the PDF comments into the EPLAN project: The project editor imports the merged PDF comments into the EPLAN project. After importing, the PDF comments are visible in the EPLAN pages.
  • Reading imported PDF comments in EPLAN: The project editor can read the imported PDF comments in EPLAN.
  • Delete the imported PDF comments from EPLAN: Once the project editor has read all the PDF comments, they can then be individually or collectively deleted from the project.

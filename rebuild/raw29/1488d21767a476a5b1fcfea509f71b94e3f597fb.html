Create macro box

Now create a macro box that combines all symbols of this page into a macro.

  1. Select Insert > Box / connection point > mounting panel > Macro box.
  2. Drag a frame around the power supply lines and PLC inputs.

  3. End the Macro box function using the ESC key.

Define the properties of the macro box.

  2. Select Edit > Properties.

    3. The Properties (components): Macro box (Properties (components): Macro box dialog opens.

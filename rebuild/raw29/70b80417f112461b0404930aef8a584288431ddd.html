Numbering the Devices Offline

You can number devices in the page navigator, the device navigator, or the graphical editor. Which option you choose depends on which scope of numbering you need.

Precondition:

You have opened a project.

  1. Select a project, pages, functions, or structure identifier layers.
  2. Select the following menu items: Project data > Devices > Number

    The Numbering (offline) dialog displays all the devices that are contained in the scope of numbering.
  3. If necessary limit the scope of numbering by selecting a filter.
  4. In the Format column of the Number (offline) dialog, select a numbering format.
  5. Select the Preview of result check box.
  6. Click [OK].

    In the Numbering (offline): Preview of result dialog, the devices are shown with the new numbering. In this dialog you can edit the DT numbering.

Edit device numbering

  1. Click in a field in the New DT column in the dialog Numbering (offline): Preview of results.
  2. Change the new DT and press [ENTER].

    The changed DT is highlighted.
  3. Select the popup menu item Use original DT if you do not want to use the new DT.

    The new DT is removed. The original DT is inserted into the row and highlighted.
  4. Click [OK].

    The new numbering is transferred to the devices in the schematic.

Tip:

For longer DTs with similar structure, there is the option of copying one or more DTs and inserting them in a different place.

Importing Project Texts into the Dictionary

It is possible for project texts to be imported into the dictionary. All texts that can be translated and that exist in the selected language in the project will be transferred as keywords into the dictionary. When importing project and parts texts the entire entry of a text box is always imported, even if the setting "Word" is selected in the Segment drop-down list. Texts marked "Do not translate" are also included, because otherwise the text would be incomplete and could not be translated with the dictionary.

Preconditions:

  • You have opened a project that contains project texts in one or more languages.
  1. Utilities > Translation > Edit dictionary
  2. Select the Management tab.
  3. Next to the Dictionary field click [...]; in the dialog that appears select the EPLAN dictionary into which you want to import, and click [Open].
  4. Click [Close].
  5. Select the menu items Options > Settings > Projects > "Project name" > Translation > General.
  6. In the Translate field next to the Languages field click (New), select each of the translation languages whose project texts you wish to import into the dictionary.
  7. Click [OK].
  8. Select the menu items Utilities > Translation > Import project texts.

    In the Select languages dialog you will see all of the selected translation languages.
  9. Select the languages you wish to import.

    If the selected languages are not selected as dictionary languages, the "Language not available" message will appear. Click [Yes].

    The project texts are imported.
  10. To check the import, select the menu items Utilities > Translation > Edit dictionary.
  11. In the Source language field in the Edit words tab select one of the languages you imported.

    In the Find field you will see all of the imported project texts of the selected language.

Extending Existing Pre-planning by Graphical Views and P&I Diagrams

So that you now extend an existing pre-planning with graphical views or P&I diagrams, you now have the option at all segments to store a window macro with graphical pre-planning or P&I diagram sections.

Benefit:

Through the new Macro for pre-planning and P&I diagram property you can extend an existing pre-planning with graphical views and P&I diagrams. This is, for example, of interest if imported pre-planning data contains different variants with the same part structure for which the same or similar window macros can be stored.

To this purpose the new property Macro for pre-planning and P&I diagram (ID 44084) is available on the first tab in the property dialog. If a window macro with the "Pre-planning" and / or "P&I diagram" representation type is selected for the property, you can place this segment with the cut-outs existing in the window macro via drag & drop on a project page of the corresponding page type.

Certain conditions must be met so that the structures in the macro can be assigned to structures existing in the project during such an action.

When placing a window macro with P&I diagrams the Select structure dialog is opened. If a corresponding segment exists for the segment to be placed in the structure of the window macro on the same hierarchy level (same basic segment definition) and if the subordinate part structures are the same, the structures from the macro are automatically sorted into the pre-planning structure of the project in the Project field.

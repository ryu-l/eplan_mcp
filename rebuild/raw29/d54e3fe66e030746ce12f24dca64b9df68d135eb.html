Dialog Connection numbering: Formats

Dialog call:

You have opened a project. You have opened the Settings: Connection numbering dialog, for example via the Options > Settings > Projects > "Project name" > Connections > Connection numbering menu items. Select a user-defined scheme in the dialog Settings: Connection numbering and select the Designation tab. Select an entry in the Format groups field and click (Edit), or click (New).

In this dialog you can change the format of an existing format group or define a new format.

Overview of the main dialog elements:

Connection group:

Select one of the default connection groups or specify a DT or a grouping as the connection group. The following connection groups among other things are pre-defined:

  • General connections (i.e. all desired connections)
  • Connections connected to PLC connection points (except card power supply and bus cable): Card power supplies and bus cables are considered separately and can therefore be numbered with the general connections.
  • Connections connected to "PLC connection points, I/O, 1 connection point" or "PLC connection point, variable": Connections connected to PLC connection points of the function group "PLC connection point, I/O, 1 connection point" or "PLC connection point, variable". Deactivated PLC connection points are not considered. Adjustable PLC connection points (function definition "PLC connection point, multi-function") are considered only if they are defined via the type of signal as input or output.
  • Device: In the Selection list dialog you can select one of the DTs in the project. When specifying a DT, the connection group will be defined by all of the connections attached to the corresponding functions.
  • Grouping: In the Selection list dialog, you can select one of the values that you specified for the Grouping property. The connection group is then defined for all connections that have the specified value for the grouping.

Extent:

Specify which connections have the same format for the connection designations.

Available format elements:

This list displays the elements that could be integral parts of the connection designation. To format a format element you have to move it to the list of selected format elements on the right. Multiple selections are not possible. When you move the format element, a dialog will open in which you can specify the formatting. This dialog is different depending on the format element.

Selected format elements:

This list displays the selected format elements in table form with their designation, symbolic representation (for the preview) and specified value.

Preview:

The preview of a connection format is displayed here. The individual formatting elements are displayed in the connection designations in the same sequence as they currently exist in the list. This field cannot be modified.

Overwrite terminal designations:

If this check box is selected, the designations for terminals will be overwritten with the connection designation. In the process, the designation of the first connection joined to the appropriate terminal is adopted.

Overwrite interruption point designations:

If this check box is selected, the designations for interruption points will be overwritten with the connection designation. In the process, the designation of the first connection joined to the appropriate interruption point is adopted.

Overwrite bundle connection point designations:

If this check box is selected, the designations for bundle connection points will be overwritten with the connection designation. In the process, the designation of the first connection joined to the appropriate bundle connection point is adopted.

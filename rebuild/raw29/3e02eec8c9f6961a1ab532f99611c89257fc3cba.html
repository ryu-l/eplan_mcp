Correcting Language-neutral Texts in the Parts Management

In the user settings for the translation you specify in the Settings: Parts management dialog which multilingual fields are to be translated in the parts management. You now have the option to convert texts that are excluded from the translation, but for which a translation text was accidentally entered, back into language-neutral texts. This way the texts are still displayed when the source language is changed. To this purpose the [Correction] button, known from the project settings has been integrated in the user settings for the translation. A menu path to this setting is: Options > Settings > User > Translation > Parts management.

Settings: Import and Export

All settings can be imported or exported. This allows an already defined working environment to be transferred to another computer that has EPLAN installed. On the other hand, it is possible to adopt the working environment of other EPLAN users, for example to continue a project under the same conditions. The following functions are available for importing and exporting settings:

Export

To define the settings to be exported, the desired area of the tree view in the Settings dialog must be selected. If a main category or sub-category is selected, such as Project or Devices, then the program also exports all lower level settings.

Note:

Exporting settings from several projects at once is not possible!

The settings are stored in an XML file. The program provides naming suggestions. By default, the export file receives a name reflecting the selected area in the tree view of the Settings dialog. The file name consists of the following elements: <Main category>+<Sub-category>+<Settings area>.xml. The advantage of this naming system is that the relevant areas are easier to find when importing settings. The suggested names can of course be changed and replaced with your own designations.

Extended export

You can add areas to an area that has already been exported. To do this, the appropriate export file must be opened and an additional area selected in the tree view of the Settings dialog.

Import

Importing loads the settings stored in the export files.

Go to default

To discard changes made after an export, the respective settings range can be reset to default values specified by the program. The settings that are reset depend on the selected area in the tree view of the Settings dialog. All lower-level settings are also reset, in the same way as with imports and exports, but the following special features must be taken into account:

  • The settings node for property configuration, dialog memory and tree and list configuration is deleted if the current selection is located on or below the "User" node and the Go to default action is opened.
  • The settings node for external programs is deleted if the marker is located on the "Workstation" node and the Go to default action is opened.

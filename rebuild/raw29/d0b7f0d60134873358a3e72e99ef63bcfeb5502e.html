Dialog Number Views

Dialog call:

You have opened a project that contains layout spaces. You have inserted views (model views, drilling views and / or copper unfolds) and placed these on project pages. Utilities > Reports > Number views.

In this dialog you can assign a sequential view name to all the views of a project.

It is to be expected that views have to be deleted during project editing. This results in gaps in the sequential numbering of the view names for the remaining views. This makes the renumbering of view names necessary.

The numbering begins at the view with the lowest value and renumbers the views in the existing order consecutively. Irrespective of the view type (model view, drilling view, copper unfolds) and irrespective of the selection made, all the views are renumbered in the complete project.

Overview of the main dialog elements:

Start value:

Enter the start value for numbering the view names here.

Number of digits:

In this field you define the number of characters to be used for numbering the view name. You can enter any number into this field, which will then define the minimum number of characters displayed. Smaller numbers are then padded with the appropriate number of zeros. Entering "0" suppresses the formatting, i.e. empty positions are not padded with zeros.

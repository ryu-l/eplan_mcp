Dialog Edit rack

Dialog call:

You have opened a project. Project data > PLC > Navigator. You have selected a rack in the rack-oriented view. Select the Edit popup menu item.

This dialog is used to define the order of the PLC cards on a rack. The PLC cards are normally sorted by the value of the Position (slot / module) property. If you change the order of the PLC cards in this dialog, the PLC cards are given a sort code (Sort code (for position in rack) property) and are sorted according to this sort code. This is particularly useful if the rack contains PLC cards for which the same values are entered in the Position (slot / module) property, or for which no values have been entered.

Overview of the main dialog elements:

The following columns are displayed in the table:

  • Row: Consecutive row number. One row is displayed for every PLC card on the rack.
  • Position (slot / module): Indicates the slot / position where this PLC card is plugged on the rack. The value can be changed here.
  • DT (identifying): Displays the identifying DT for the PLC card.
  • PLC type designation: Displays the PLC station type number or designation.
  • PLC card name: Displays the name of the PLC card. The value can be changed here.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

In addition, the following dialog-specific popup menu items are available:

Menu item

Meaning

Number "Position (slot / module)"

Provides the possibility to automatically assign the values of the Position (slot / module) property for the selected PLC cards or the entire rack. In the subsequent dialog you enter the start value and the increment for the numbering.

Tip:

Sort the PLC cards in the desired sequence via the arrow buttons and then use the popup menu item Number "Position (slot / module)", to renumber the values of the property Position (slot / module).

Further Optimizations for the EPLAN Platform and Its Products

The following further optimizations for the EPLAN Platform and its products have been realized in the current version:

EPLAN Platform

  • User interface: The Select scope of menu start dialog, that allows the extent of the displayed menu to be determined via a user mode, has been removed from the user interface. The scope of menu can still be restricted by means of the EPLAN rights management.
  • User interface: In the Property selection dialog (and similar dialogs) additional information for a selected property (the ID, the designation and the associated description of the property) is now also displayed in the lower area of the dialog.
  • User interface: To collapse all hierarchy levels again in an expanded tree of a tree view, you can use the [Ã·] key on your numeric keypad.
  • Data backup: When projects are restored the project description is now also shown. To this purpose the new column Project description has been added in the Projects field to the Restore project dialog. The display of this information makes it easier for you to select a backed up project.
  • Graphical preview: Double-clicking a page in the graphical preview opens this page in the graphical editor. To open a page displayed in the preview in a new window, keep the [Shift] key pressed while double-clicking.
  • Graphical preview: The graphical preview now also responds to the selection in the Sort interruption points dialog and shows the respective page with the marked interruption point.
  • Project data navigators: In the tree view of filtered navigators a marking now also remains if you deactivate the filter.
  • Settings: The color selected and activated for the Project groups in the Settings: Project groups (definition) dialog is now also displayed for the project-specific settings in the settings dialog. If a user has opened several projects, this allows them to recognize more easily for which project they are currently carrying out settings.
  • Settings: The user-specific setting Display scroll bars is now deactivated as a default. (Menu path: Options > Settings > User > Display > General). This way the scroll bars in the editors are not displayed as a default.
  • Settings: In the Settings: Languages dialog the superfluous group box Help system has been removed (Menu path: Options > Settings > User > Display > Languages). When called up the Help is opened via an Internet connection in the respective dialog language. It is possible for you to switch, via a button between all available languages within the help system.
  • Settings: If you open the Symbol selection dialog for a symbol that is already inserted from the Symbol / function data tab, to exchange the symbol, the Only exchange symbol setting is available in this dialog. This setting is now activated as a default to prevent the inadvertent changing of function definitions.
  • Connections: The Carry over connection designations dialog is now also opened when a connection designation is changed during direct editing or during tabular editing. Use this dialog to specify to which other connections a changed connection designation is to be carried over automatically. So that this dialog is opened, the Carry over connection designations to extent check box must be activated in the user settings in the Settings: Connection symbols dialog.
  • Revision control: If you now - after the generation of the fist revision - deactivate the display of the Revision markers for a project via the menu items View > Revision markers, this setting is contained during the generation of further revisions. The revision markers are only switched on automatically when the first revision is generated.
  • Form editor: In the dynamic forms for the Connection list the block properties are now also offered for selection in the property selection for the Change of the property dialog. This way you can, for example, output a blank line in a connection list if the value of a specific block property changes.

EPLAN Electric P8

  • Topology: The property Topology: Connection filter (ID 20247) can now be shown as a column in the list view of the topology navigator and for the tabular editing. This way you can identify more easily for which routing paths a connection filter was specified and edit it there.
  • Topology: The connection filters set at the routing paths are now also considered during the routing when the connection to be routed has a routing track specification (this means the property Topology: Routing track specification (ID 31119) is filled).

EPLAN Pro Panel

  • 3D mounting layout: When placing an extrusion outline as a user-defined rail in a layout space, the item description is now automatically generated from the description of the outline. In the outline properties enter this description in the property Description (form, plot frame, outline, form (copper)) (ID 18011).
  • 3D mounting layout: When inserting a mounting panel, the check box Integrate into enclosure hierarchy in the placement options is activated by default. This way mounting panels are now automatically integrated into the hierarchy below the enclosure during the insertion, without you having to open the Placement options dialog for this.
  • 3D mounting layout: The placement of electrical modules in the layout space and the subsequent routing of connections for these part placements has been improved.
  • 3D mounting layout: The accessories of length variable items can now also be inserted with variable length. This way it is now, for example, possible to select a cover via the accessory selection for the busbar system and place it with variable length on the busbar system.
  • Mounting aids: When moving a mounting aid (mounting point, mounting line, handle or base point) in a macro project from one mounting surface to another, the mounting aid is now placed directly below the new mounting surface, if the option Snap to mounting surface is activated.
  • Layout space navigator: In the layout space navigator it is now possible to specifically filter for the mounting aids (mounting points, mounting lines, etc.) that are used in a project. We have provided the pre-defined "Mounting aids" scheme for this purpose.
  • Layout space navigator: Placeholder objects are now always shown in the layout space navigator and can be deleted there as well - independently of the respective license.
  • Routing connections: The edges of routing connections are not shown in black anymore but in the respective connection color. This way the representation of connections in EPLAN Smart Wiring (with minimal zoom factor) has also been improved.
  • Master data for EPLAN Pro Panel: During the import of device data, devices (for example, mounting rails, wire ducts, etc.) can now also be imported with length specifications and then be inserted into the layout space with the respective length.
  • Master data for EPLAN Pro Panel: The outlines for the "NC record generation" now belong, like the extrusion outlines, to the project master data and are stored in the project during the placement in a layout space. These outlines are now also displayed in the Synchronize master data - <Project name> dialog and can be transfered together with the project.
  • Master data for EPLAN Pro Panel: You can now store up to 50 parts at a part placement in the layout space. This way during the import of devices all parts with identical DTs (for example, an enclosure and its accessories) are transfered to the same part placement.
  • Manufacturing data "Rittal - Perforex LC / Secarex": During the manufacturing data export"Rittal - Perforex LC / Secarex", the data is now generated for a component editing. This way removable enclosure parts (door, mounting panel, etc.) can be individually edited with the laser machining center.
  • Manufacturing data drilling template: During the manufacturing data export of drilling templates, the data is now output in the unit that is set as the display unit. This way an export with the unit "Inch" is possible.
  • Manufacturing data drilling template: During the manufacturing data export of drilling templates, you can now output the different cut-out types with different colors. The specification of the respective colors is made in the layer management by means of the four new layers "EPLAN691", "EPLAN692", "EPLAN693" and "EPLAN694" that are available to you in the layer management below the node "Graphic > Drilling template > Machining".
  • Manufacturing data "CadCabel": During the manufacturing data export of the wire fabrication data for "CadCabel" not only integer connection designations are supported but connection designations with decimal separators or other separators as well. (for example, "10.25" oder "10/25").
  • Message management: By means of the new check run 026105 from the message class 026 "3D mounting layout" you can check whether there are length-variable items within a project, a layout space etc. (wire ducts, mounting rails, busbars, C horizontal rails, user-defined rails) that have the same device tag.
  • Message management: By means of the 026017 check run, the identifier structure at the part placement is compared with the associated mounting surface. This check run now behaves according to the check run 012008. Not the entire identifier structure of a device but only the similarity of the individual identifier blocks is checked. Missing identifier blocks are ignored.
  • Message management For the manufacturing data export with the new interface to the fully automatic wire fabrication machine "Rittal - Wire Terminal WT" the check run 026072 has been extended by two further test criteria. Messages are now explicitly output for this new interface, if the connection color is missing or the minimum connection cross-section is smaller.

EPLAN Preplanning

  • Segment template navigator: In the tree of the segment template navigator the popup menu item Configure representation is now available. With the subsequent dialog by the same name you can change the tree view for segment templates, pipe classes and substances.
  • Checking the pre-planning: A check for multiple segments, structure identifiers or identifying designations through the check runs 28001, 28002, 28003 and 28018 was previously only possible if the check runs were applied to the complete project or a selection was made in the pre-planning navigator. A page is now also checked with this new version, if respective segments or objects linked with the pre-planning on the page were selected. This functions for pre-planning and P&I diagram pages and for linked objects for schematic pages or in the open layout space. In the course of this new feature the check runs 28001 and 28002 were expanded with the type of check "Prevent errors".
  • Creating the detail planning: When cutting and pasting components or cut-outs in the P&I diagram the links to the segments in the pre-planning remain. This also functions for the cutting and pasting in the layout space or on other schematic pages (page types "Schematic multi-line", "Schematic single-line", etc.).

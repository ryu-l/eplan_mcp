Templates and Defining Rotation / Flipping (Changing Standards)

Use a template to adjust designations and names to the target standard. The setting for rotation / flipping specifies, in combination with the selected symbol libraries, the location of the schematic elements in the schematic.

Preconditions:

  • You have opened a project.
  • In the case of several opened projects: You have selected a project in the page navigator.
  • You have a template containing country- or standards-specific settings.
  • You have set up a target project.
  1. Utilities > Change of standard
  2. To specify a template for the target project, use [...] on the Rotation / Flipping tab to select a project template *.ept.
  3. From the Rotation / flipping drop-down list, select the way in which you want to rotate and flip.
  4. Click [Next].

    Replacing Plot Frames, Forms and Function Definition Libraries

Tab Hyperlink

Dialog call:

You have opened a project page in the graphical editor.

  • Insert > Graphic > Hyperlink.
  • You have marked a hyperlink and selected the menu item Edit > Properties. In the Properties dialog, select the Hyperlink tab.

On this tab you can edit the display properties of a hyperlink.

The following dialog elements are available:

Document:

Enter the file or Internet page to be linked here. Using [...] you can call the file selection dialog where you can select the document to be linked. The name including the entire path designation is transferred into this field.

You can also enter a URL or the file name of a document (with file path) by using copy and paste. Or you enter an e-mail address, for example "mailto:info@eplan.de".

You can use the Insert path variable popup menu item to branch to the dialog Select path variable where you can select one of the available path variables.

Note:

Always start your hyperlinks with "http://" or "https://", to make sure that they always work in every environment on the Internet (during a PDF export, for example).

Text / designation:

The text entered here is displayed on the page. When selecting a file, the file name (without the file name extension) is automatically suggested. You can accept this text or change it manually. The text stored here is multilingual.

Description:

In this field, you can enter an optional descriptive text for the hyperlink.

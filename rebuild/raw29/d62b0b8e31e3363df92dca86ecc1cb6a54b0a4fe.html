Parts management: Assignment of eCl@ss properties to EPLAN part properties

eCl@ss characteristics can have a cardinality, for example the number of connection points of an item. This is used to define how often a block of eCl@ss properties occurs repeatedly. At the moment of definition of an assignment of eCl@ss data one only knows that a block can occur several times. But not however how often the block occurs during the actual import. This can differ at every imported object.

It must be possible to assign eCl@ss properties with cardinality to several EPLAN part properties. This is realized as follows:

  • The user can also select several EPLAN properties for each eCl@ss property that can occur several times due to the cardinality.
  • During importing these eCl@ss properties are assigned to these EPLAN properties in sequence.
  • User-defined properties and indexed EPLAN properties such as attributes and free properties can also be selected here.
  • The user selects all the indexes to be used explicitly in the process, for example "Attributes 10 to 20".
  • A dialog is available with one list each for the assignment of available properties and selected properties in which the sequence of the selected properties can be changed by means of buttons.
  • If an object to be imported contains more eCl@ss properties than were defined during the assignment of the cardinality, the superfluous properties are ignored.

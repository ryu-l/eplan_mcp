Exchanging Source and Target for Connection Planning Objects

With the new menu item Exchange source and target below the menu Project data > Connections you now have the possibility to exchange the source and target of connection planning objects. To do this the respective segments have to be selected in the pre-planning navigator.

The entries in the properties of the same name are exchanged in this way for piping planning objects in the fields Source segment and Target segment and for cable planning objects. The graphic on the pre-planning pages is modified accordingly.

For a piping definition point that is located in the tree of the navigator below such a piping planning object, the flow direction of the piping is adapted in the P&I diagram with the Exchange source and target function if source and target are specified at the linked piping planning object in the pre-planning. The source and target function of the piping in the P&I diagram must furthermore be linked with planning objects that correspond with the source and target segments at the piping planning object.

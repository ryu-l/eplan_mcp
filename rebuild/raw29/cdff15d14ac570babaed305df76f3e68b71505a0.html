Representation types

User interface / operation

Placed functions are differentiated into multi-line functions, single-line functions, graphical functions, external functions, pair cross-references, and overview functions. This differentiation is known as the representation type. In addition, for functions and macros to be placed in operational sequence sheets, the "Functional" representation type is available. For objects in the layout space, there is the "3D mounting layout" representation type, and for objects in the topology the "Topology" representation type.
A function can be used in the project in different representation types simultaneously, but each representation type may occur only once per function. The representation type has effects on the handling of the functions in reports.

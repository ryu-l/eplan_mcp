Tab Hose groups

Dialog call:

You have installed the hose line configurator as an add-on variant of EPLAN Fluid. You have started EPLAN Fluid and the hose line configurator.

  • Select the menu items Options > Settings > User > Add-ons > Hose line configurator in EPLAN Fluid and click in the Hose groups tab in the subsequent dialog.
  • Or select the menu items Extras > Settings in the Configure hose lines dialog of the hose line configurator and click in the Hose groups tab in the subsequent dialog.

Or you have installed the hose line configurator as a stand-alone variant and started the program.

  • Select the menu items Options > Settings > User > Add-ons > Hose line configurator in the hose line configurator and click in the Hose groups tab in the subsequent dialog.

You define the default data for hose groups in this tab. In the process you combine different hose types into hose groups and furthermore store the corresponding hose standard and part information for the selected hose types. The hose type standard assignments entered in the table are offered for selection when the hose lines are configured in the Edit <...> dialog.

Overview of the main dialog elements:

Group number (list):

Define the hose groups here by assigning a number to each hose group.

Use the buttons of the toolbar above the list to create new entries, edit existing ones and / or delete entries no longer required.

Note:

Each group number may only be used once. If an existing group number is assigned once more, a corresponding message is displayed.

Table:

In this table you assign the required hose types, standards and part numbers to the respective hose group.

If you use the hose line configurator as an add-on variant of EPLAN Fluid, you can use the [...] button available in the table cells of the Part column to access the parts management and there select the desired part.

Use the buttons of the toolbar above the table to create new entries and / or delete entries no longer required.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

Note:

If you select the default scheme DIN 20066__2012-01 the settings in this tab and in the Hose assignments tab have the effect that the hose types specified in accordance with the standard DIN 20066 are offered for selection in the Edit <...> dialog for each selected working pressure and for each selected nominal diameter of the hose.

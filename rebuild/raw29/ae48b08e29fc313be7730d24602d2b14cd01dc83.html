Dialog Parts preselection

Dialog call:

You have opened a project.

  • Options > Settings > Projects > "Project name" > Management > Part selection. Next to the Parts preselection field, click [...].
  • You have selected a main function in the graphical editor or in a navigator. Edit > Properties. Select the Parts tab. [Settings] > Part selection (project). Click [...] next to the Parts preselection field in the Settings: Part selection (project) dialog.

In this dialog, you can edit the lists for parts preselection, or create new lists.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to edit from the drop-down list. You can only edit user-defined schemes.

You can create new schemes, save any changes to a scheme, and copy or delete schemes via the adjacent Toolbar. Schemes can also be imported or exported.

Description:

This field displays the descriptive text that you entered into the Description field in the dialog New scheme when you created the scheme.

Toolbar:

You can use the following buttons in the toolbar:

Button

Meaning

(New)

Use this button to open the Parts selection dialog. It is there that you can select more parts to be added to the list in the parts preselection.

(Delete)

Use this button to delete the marked parts from the current list.

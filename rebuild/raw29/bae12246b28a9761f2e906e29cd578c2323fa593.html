Simplification for Bus Ports

With Version 2.9 only bus ports with the function definitions "Network / bus cable connection point, general" and "Network / bus cable connection point, switch connection" are stille used. The other function definitions for bus ports are still supported for reasons of compatibility but cannot be inserted into projects anymore.

Benefit:

Configuration of bus ports becomes more simple and clearer through the reduced function definitions. All bus systems can now be configured with the general network / bus cable connection points. Switch connection points are used at passive devices (for example terminals, pins, passive switches, bus repeaters).

The function definitions for bus ports not required anymore as of Version 2.9 have been marked with the supplement "do not use anymore":

  • "Network / bus cable connection point, input (do not use anymore)"
  • "Network / bus cable connection point, output (do not use anymore)"
  • "Network / bus cable connection point, source (do not use anymore)"
  • "Network / bus cable connection point, end (do not use anymore)"

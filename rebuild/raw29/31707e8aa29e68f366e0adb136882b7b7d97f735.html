Editing Outlines

Copying outlines

To copy an outline with all its contents, save it to another storage location and / or under a different name.

Precondition:

You have opened a project.

  1. Select the following menu items: Utilities > Master data > Outline (...) > Copy
  2. In the Copy outline dialog, select the drive and directory of the outline to be copied.
  3. Select the outline file to be copied. (Multiple selection is not possible here.)
  4. Click [Open].
  5. In the Create outline dialog, specify the storage location for the copy of the outline.
  6. In the File name field, enter a descriptive name for the new outline.
  7. Click [Save].

    The outline is copied and the copy is opened for editing.

Rotating outlines

Outlines can be rotated around a rotation point in any angle.

Precondition:

You have opened an outline or are creating a new outline.

Rotating without copy

  1. Select the following menu items: Edit > Rotate
  2. Select the objects to be rotated by enclosing them with a rectangle.
  3. Determine the point around which the rotation is to take place. This point can be either on the outline or outside the outline, for example on an auxiliary line.
  4. Enter the rotation angle.

    The outline is rotated around the specified rotation point with the specified angle.

Rotating with copy

  1. Select the following menu items: Edit > Rotate
  2. Select the objects to be rotated by enclosing them with a rectangle.
  3. Determine per mouse click the point around which the rotation is to take place. This point can be either on the outline or outside the outline, for example on an auxiliary line. A preview of the result to be expected is displayed.
  4. Enter the rotation angle. Use [Ctrl] + [Enter] to confirm the entry.
    Another possibility: Hold down the [Ctrl] key, and specify per mouse click the second point of the rotation angle.

    A copy of the outline is rotated around the specified rotation point with the specified angle.

Flipping outlines / Flipping with copy

Outlines can be flipped with or without copy around an axis to be specified.

Only use points that can be found on existing geometrical elements. To do this you can use an auxiliary line that you can delete again after the flipping.

Precondition:

You have opened an outline or are creating a new outline.

Flipping without copy

  1. Select the following menu items: Edit > Flip
  2. Select the objects to be flipped by enclosing them in a rectangle.
  3. Specify the starting point of the flipping axis. A preview of the result to be expected is displayed.
  4. Specify the end point of the flipping axis.

    The outline is flipped along the specified axis.

Flipping with copy

  1. Select the following menu items: Edit > Flip
  2. Select the objects to be flipped by enclosing them in a rectangle.
  3. Specify the starting point of the flipping axis. A preview of the result to be expected is displayed.
  4. Press the [Ctrl] key and enter the end point of the flipping axis.

    A copy of the outline is flipped along the specified axis.

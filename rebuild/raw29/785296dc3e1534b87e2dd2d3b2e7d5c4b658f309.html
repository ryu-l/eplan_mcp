Tab Conductor termination processing

Dialog call:
  • Options > Settings > Company > Wire fabrication > "Machine" > Conductor termination processing
  • Utilities > Manufacturing data > Wire fabrication > "Machine". Click [...] next to the Scheme field. Select the Conductor termination processing tab.

In this tab, the wire termination processing is assigned to the actual conductor termination processing by the machine.

Overview of the main dialog elements:

Wire termination processing:

From a drop-down list, you can select all definitions set in the project and company settings for the design of wire terminations.

Conductor termination processing single:

In this column, the preceding wire termination processing is assigned an equipment of conductor ends of single wires by sleeves. The selectable values for this dialog element are defined on the Machine command tab.

Conductor termination processing twin:

In this column, the preceding wire termination processing is assigned a processing of conductor ends of twin wires on the machine. The selectable values for this dialog element are defined on the Machine command tab.

Conductor termination processing twin center:

The setting in this column uses the double crimp module for Komax machines. If this module is activated on the Settings tab of the Settings: Komax dialog, a dual sleeve can be fabricated in the center of a pair of wires, with the beginning and the end of the pair only being stripped.

Creating Schemes for Automated Processing

The automated processing of projects is managed by means of EPLAN schemes. For this purpose, all actions that are to be run in an automated manner at once are stored in a user-specific scheme. Using this scheme, EPLAN automatically generates a script file (*.cs) that is stored by default in the directory <Program drive>:\<Program directory>\Scripts\<Company code>.

Precondition:

You have opened a project. You have selected project pages or the project in the page navigator.

Create a scheme

  1. Select the following menu items: Utilities > Automated processing
  2. Click [...] next to the Scheme field in the dialog Run: Automated processing.
  3. Click (New) next to the Scheme field in the Settings: Automated processing dialog.
  4. In the New scheme dialog, enter a meaningful name for the scheme in the Name field. You can enter additional describing text in the Description field.
  5. Click (Save).

Select actions

  1. Click [...] next to the Scheme field in the dialog Run: Automated processing.
  2. Select the scheme you want to edit from the Scheme drop-down list in the dialog Run: Automated processing.
  3. In the Available actions field, select an action and then click (Move to the right).
  4. Once EPLAN has opened a dialog, define the settings for the selected action and click [OK].

    The action is applied to the Selected actions field.
  5. Select all of the actions that you would like to automate, in the same manner.
  6. To define the sequence in which the actions are to be run, select an action in the Selected actions field and click (Move up) or (Move down), as many times as necessary until the entry is in the desired position.
  7. Click (Save).

    The scheme is saved and a script file (*.cs) is created automatically.
  8. Click [OK].

Tab Busbar

Dialog call:

You have opened a project.

  • The project contains at least one layout space. The layout space contains busbars (bending). You have opened the layout space navigator. Select a busbar in the navigator. Select the Properties popup menu item. In the Properties (components): Part placement (3D) dialog, select the Busbar tab.
  • While keeping the [Shift] key pressed, you have highlighted a busbar in the 3D display area. Edit > Properties. In the Properties <...> dialog, select the Busbar tab.

On this tab, you specify the properties for the highlighted busbar.

Overview of the main dialog elements:

Displayed DT:

The displayed DT is displayed in the graphical editor on the component. If you have defined in the project settings that devices are to be automatically numbered when symbols are inserted, then a DT is automatically suggested here. You can accept this DT or overwrite it manually.

In addition you can use the popup menu or the [...] button to create or select a DT.

Full DT:

This field displays the full DT (i.e. structure identifier of the current environment + displayed DT) of the component / item. Use the [...] button to open the Full DT dialog. You can edit the structure identifiers there and select, e.g., another mounting location.

Item:

In this field, the item definition is displayed; it is imported from the selected function definition and used for the display in the layout space navigator.

Function definition:

The function definition of the busbar displayed here is automatically assigned, depending on the function definition of the associated item. Click [...] to open the Function definitions dialog and select a different function definition if required.

Copper bundle:

This field specifies that a copper item belongs to a copper bundle. This relationship can be changed. Using the [...] button, you can display the 3D object selection dialog. All the copper bundles in the layout space are listed here. By moving the selection to another copper bundle, the copper item is assigned to this bundle. The selection is carried over to the property field via [OK].

P027021: The multi-line connection from <x> to <y> has not been routed

Cause

The project contains a multi-line connection that runs between the multi-line functions with the device tags <x> and <y>. In addition, the project contains two topology functions with the device tags <x> and <y>, but they have not yet been connected to each other by means of a routing connection.

Solution

  1. Select the Find menu item and find in the dialog of the same name the two device tags <x> and <y> in the project. Display the search result in the list of results.
  2. In the Search results - <Project name> dialog, locate the two topology functions <x> and <y> by selecting the Go to (graphic) function from the popup menu.
  3. Add routing paths and routing points to the two topology functions using the menu items Insert > Topology > Routing path and / or Insert > Topology > Routing point.
  4. Connect the two topology functions and routing points with the routing paths, and thus specify a routing track through the routing path network.
  5. Select the total routing path network, and select the menu items Project data > Topology > Route.

    A routing connection through the routing path network is generated between the two topology functions.
  6. Then start a new check run.

Note:

If there already exist a routing path network and a routing connection not routed yet between the two topology functions, check in the Properties <...> dialog, for each routing path of the connection, the value of the property Topology: Connection filter. Unify the value for all routing paths if there are differences. Then, re-route the connections, and start a new check run.

Importing Wire Harness Data

You have the possibility to import wire harness data from EPLAN Harness proD in order to configure wire harnesses in the EPLAN platform.

Synchronization with wire harness data (functions and connections) already existing in the project is carried out during importing. Functions and connections that are only contained in the project and not in the import file can be deleted from the project in the process. If the wire harness data do not yet exist in the project, these are imported as unplaced functions and connections in the project.

Preconditions:

  • You have opened a project.
  • Wire harness data are made available in the form of an hpdex file.
  1. Select the following menu items: Project data > Connections > Import > Wire harness data
  2. Select the desired file with wire harness data (*.hpdex) for the import in the dialog Wire harness data import.
  3. Click [Open].

    The wire harness data to be imported and those already existing in the project are displayed in the dialog Synchronize wire harness data.

    The Status column displays whether functions / connections are not yet contained in the project, whether they already exist in the project, or whether the functions / connections in the data source and in the project have different editing states (for example other property values). Fields with changed property values have a dark-gray background.
  4. Specify whether the respective functions / connections are to be imported, modified, or not imported in the Action column.
  5. Click [OK].

    The data are imported in accordance with the settings.

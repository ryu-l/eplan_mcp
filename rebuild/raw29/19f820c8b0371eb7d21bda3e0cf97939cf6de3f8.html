Deleting Stored Parts Properties

You can delete selected properties from the parts stored in the project. For instance, before providing the project to an end customer, you can remove the price information.

Precondition:

You highlighted a project or individual pages in the page navigator, or you highlighted components in the graphical editor.

  1. Select the following menu items: Utilities > Parts > Delete stored properties
  2. Select a scheme from the Settings drop-down list in the dialog Delete stored part properties or click [...] to open the subsequent dialog of the same name in which you can manage and edit the schemes.
  3. Click (New) and select the part properties to be deleted in the dialog Property selection. Multiple selection is possible.
  4. Click [OK].

    The selected part properties are deleted from the project.

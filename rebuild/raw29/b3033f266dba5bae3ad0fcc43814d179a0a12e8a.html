Outputting Pages as PDF Files

Regardless of the option selected (individual project pages or an entire project), only one PDF file is created.

Note:

When large pages are exported, you have to take into account that problems may occur in case of an export in the original size. Therefore you should first break up the imported DXF blocks so that scaling to the page size is possible. (This is done by using the menu items Edit > Other > Break up block.)

Precondition:

You have opened a project.

  1. In the page navigator, select the pages of a project (or the entire project) that you wish to export.
  2. Select the menu item Page > Export > PDF.

    EPLAN opens the PDF export dialog. The selected objects are displayed in the Source (page / 3D model) field.
  3. Select a suitable scheme from the Scheme drop-down list, or click [...] to open the Settings: PDF export dialog for creating or editing a scheme.
  4. In the PDF file field you enter the path and the name of the PDF file to be created, or select it interactively using [...]. The initial default is the documentation directory DOC and the name of the selected project (...\<Project.edb>\DOC\<Project>.PDF).
  5. In the Export medium group box specify the medium to which it is to be output.
  6. In the Output group box specify how it is to be output.
  7. Click [Settings] to view and, if necessary, modify the settings for the output languages, output size, and print margins.
  8. Click [OK].

    EPLAN generates the PDF file.

Note:

Adobe Acrobat Reader (minimum version 10.0) must be installed on your computer in order to read an exported PDF file.

Dialog Generate cables automatically

Dialog call:

You have opened a project.

  • You have selected components in the graphical editor.
  • Or you have selected cables or cable connections in the navigator dialog Cables - <Project name>.
  • Or you have selected connections in the navigator dialog Connections - <Project name>.
  • Or you have selected pages or a project in the Pages - <Project name> navigator dialog.

Project data > Cables > Generate cables automatically.

In this dialog you specify the settings according to which cables are automatically generated. After that you start generating the cables.

Overview of the main dialog elements:

Cable generation group box

Settings:

The scheme selected here specifies where the cable properties are positioned and which cable connections should be included when generating cables. Use [...] to open the Settings: Cable generation dialog where you manage and edit the schemes.

Cable numbering group box

Settings:

The scheme selected here specifies in which sequence cables are numbered, which properties are to be displayed in the cable DT and how they and formatted. Use [...] to open the Settings: Cable numbering dialog where you manage and edit the schemes.

Start value:

Enter the start value for the DT counter.

Increment:

Enter the value here to be used to increment the counter of the DT.

Keep existing cable DTs:

Select this check box if you would only like to renumber newly generated or copied cables. The DT of the already numbered cables is retained. The cables with "?" in the identifier will be numbered.

If the check box is deselected, all of the cable DTs are renumbered.

Automatic cable selection group box

Settings:

The scheme selected here specifies the criteria for automatic cable selection. Use [...] to open the Settings: Automatic cable selection dialog where you manage and edit the schemes.

Only automatically generated cables:

If this check box is selected, the cable selection is only performed for automatically generated cables. Manually generated cables are not taken into consideration.

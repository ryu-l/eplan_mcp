Creating a Form for Bent Copper Rails

The form of bent copper rails is the path along which a rectangular basic outline is moved in order to shape the bent copper rail. This path is created as a 2D line drawing in the outline editor.

In this example, the handle of the rail is to lie directly at the point of origin of the outline.

Precondition:

You have opened a project.

  1. Select the menu items Utilities > Master data > Form (copper) > New.
  2. In the Create form dialog, select in the Save as type field the directory to which the new form drawing is to be saved.
  3. In the File name field, enter a name for the new form drawing.
  4. The File type field contains the fixed entry Form copper (*.fp1); this entry cannot be modified.
  5. Click [Save].

    The Form properties - <File name> dialog is opened. The Grid property has already been entered and is preset at 4 mm.
  6. Add other properties, or apply the default setting unchanged.
  7. Click [OK].

    The form is opened in the outline editor. At the bottom on the left, the origin of the drawing is highlighted with a red circle. This is where the starting point of the first line should be, because the origin becomes the handle of the copper rail during the placement.
  8. Select one of the graphical elements "Line" or "Polyline".
  9. Place the starting point of the line into the red circle of the origin.
  10. Draw the intended form of the bent copper rail.
  11. Select the Utilities > Check form menu items to determine that the form is closed.
  12. Select the menu items Utilities > Master data > Form (copper) > Close.

    The form drawing is saved and closed. It can be used instantly for the placement of a copper rail.

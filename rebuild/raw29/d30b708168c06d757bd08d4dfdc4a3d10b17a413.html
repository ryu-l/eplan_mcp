Tab Settings

Dialog call:

Utilities > Parts > Management > [Extras] > Import. You have selected the entry eCl@ss version in the File type field. Click the [...] button next to the File type field and select the Settings tab.

Specific settings for the assignment of eCl@ss properties to the part properties of the parts management can be defined in this tab.

Overview of the main dialog elements:

Manufacturer (short name):

You should use this input box and enter the manufacturer abbreviation that precedes the actual part number so that the new EPLAN part numbers can be assigned uniquely. If, for example, you enter "ABC", a part number "4711" is then identified as "ABC.4711" after the import.
This string is also used at the generation of the names of connection point and drilling patterns as well as at the generation of specific customer-specific directories.

Note:

Please note that you have to use a three-character manufacturer abbreviation to allow future assignment to parts in the EPLAN Data Portal.

Generate connection point patterns / Generate drilling patterns:

Activate this check box if connection point patterns / drilling patterns are to be generated automatically when importing the eCl@ss data. The assignment of the corresponding properties is carried out automatically by the import scheme.

Note:

Please note that the manufacturer short name specified under Manufacturer (short name) is placed in front of the connection point name / drilling pattern name during the generation.

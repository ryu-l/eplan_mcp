Defining Multi-Line Connections on a Single-Line Connection Definition Point

In the property dialog for a single-line connection definition point you specify the connection points on the devices between which multi-line connections should be created. Jumpers (i.e. connections between the connection points on the same device) can also be generated and insulation inserted. You can also specify connection data for the multi-line connections that are defined in this way.

Preconditions:

  • You have created the multi-line functions of the device (e.g. the pins) in the project as unplaced functions.
  • The single-line function of the device (e.g. the plug) is a main function. The property Manage unplaced auxiliary functions at the main function should be activated for this function.
  • You have created single-line connections in the single-line representation.
  • You have inserted a connection definition point and assigned the representation type "Single-line" to it.
  1. Select the connection definition point, then select the menu items Edit > Properties (or double click on the connection definition point).
  2. In the Properties <...> dialog, select the Interconnect devices tab.

    The device which is the source of the single-line connection is automatically displayed in the Device source field. The connection points of the device are displayed in the Connection point column. In this case only connection points of unplaced multi-line functions are displayed.

    The device which is the target of the single-line connection is automatically displayed in the Device target field. The connection points of the device are displayed in the Connection point column. In this case only connection points of unplaced multi-line functions are displayed.
  3. Select the same number of connection points at the right and left of the dialog.

    If you have selected different numbers of connection points, then the smaller number of connections are created. If you have selected more connection points than available cable connections, the connection points are connected using only the cable connections available.
  4. Click [Generate connections].

    The multi-line connections are generated. Cable connections are generated if a cable is assigned to the single-line connection, otherwise conductor / wire connections are generated.
  5. If necessary, edit the connections. To do this, select the connection you want to edit and select Popup menu > Edit.
  6. In the Properties (components): Connection dialog, enter the desired data of the connection (e.g. connection color and connection designation), and click [OK].
  7. Click [OK].

    The multi-line connections and your connection data are saved at the connection definition point.

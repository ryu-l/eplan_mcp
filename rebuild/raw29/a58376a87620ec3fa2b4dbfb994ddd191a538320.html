Specifying the Default Positions for the Interruption Point Description

Precondition:

You have opened a project.You have opened a project page in the graphical editor.

  1. Open the properties dialog for an interruption point, for example by double-clicking the interruption point.
  2. Bring the Display tab of the Properties <...> dialog to the front.
  3. Click (New) in the properties area if necessary.
  4. In the Property selection dialog, select the "Interruption point: Description" property.
  5. Click [OK].
  6. In the Display tab, select one of the available default positions by changing the Docking, Alignment, and Angle settings.
  7. In the Symbol data tab, select a different variant from the Symbol variant drop-down list.
  8. Change back to the Display tab.

    The default positions in the above mentioned fields have been adapted to suit the new variant.
  9. Click (Save) above the Property arrangement field, in order to save the settings user defined.
  10. Enter a recognizable name for the property arrangement in the Save property arrangement dialog.
  11. If the newly established property arrangement is to be used as the default, select the Use as default check box and click [OK].
  12. Click [OK] in the properties dialog.

    The interruption point description displays according to the specified display settings.

    The next time an interruption point is inserted, the last symbol selected will be used as default, along with all specified settings, also relating to the text positioning.

Note:

As soon as you manually enter other values in the Display tab (e.g. for the X / Y position) or move the interruption point description with the mouse, the default values no longer apply, and the value in the Property arrangement field will be changed to "user defined". You can then save the settings as described above. Reselection of one of the default property arrangements will automatically set all values back to the selected default.

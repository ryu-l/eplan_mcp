Tab Designation

Dialog call:

You have opened a project.

  • Options > Settings > Projects > "Project name" > Connections > Connection numbering. Select the Designation tab in the dialog Settings: Connection numbering.
  • You have selected a connection in the graphical editor, or in the Connections - <Project name> navigator dialog. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog. Project data > Connections > Numbering > Place > [...]. Select the Designation tab in the dialog Settings: Connection numbering.

In this tab you specify a maximum of 20 format groups. You can compile different function definitions in a format group and format them in the same way. In the process you can also use wildcards (*). This allows groups of functions to be combined for which a common format can be defined.

Overview of the main dialog elements:

Format groups:

This list shows the connection groups selected for numbering, their extent, as well as a preview of the specified format.

Note:

The connections are numbered according to the sequence of the connection groups. Thus the "General Connections" group should be at the last position.

Example:

In the Format groups field, you have selected the following connection groups:

  • Connections attached to PLC connection points
  • Connections attached to terminals
  • General Connections.

In this case, the connections joined to PLC connection points are numbered first, whereby the numbering format defined for this group is used. After this, the connections joined to terminals are numbered (using the numbering format for the appropriate group). Finally, the remaining connections are numbered using the numbering format for the "General Connections" group.

If, however, the general connections are in the first position of the Format groups field, then all connections will be numbered using the "General Connections" numbering format. The formats for connections joined to PLC connection points and terminals are not used since the appropriate connections are already numbered.

[Net extension]:

Opens the Net extension dialog. In this dialog you can extend the definition of a net. This setting affects the designation if the range is selected as "Net".

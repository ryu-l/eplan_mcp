Deleting Automatically Generated Cables

The automatically generated cables and connection definition points can be deleted either for the entire project or for the selection.

Precondition:

You have opened a project.

  1. Select one or several cables in the graphical editor or the cable navigator. Or select in the page navigator one or several project pages or a project.
  2. Select the Project data > Cables > Delete automatically generated cables menu items.
  3. If necessary, select the Apply to entire project check box.
  4. Click [OK].

    All cable definition lines and connection definition points marked as automatically generated are deleted. Moreover, automatically assigned device tags on manually drawn cable definition lines or connection definition points are deleted. The manual cable definition lines and connection definition points remain untouched.

Dialog Customize

Dialog call:

Right-click on an area of the menu bar or a toolbar and select the Customize popup menu item.

In this dialog you can adjust the toolbars to your needs.

Commands tab

In this tab, select the button you want and "Drag & Drop" it onto a toolbar.

Overview of the main dialog elements:

Categories:

This list contains all program areas with toolbars. You can also access a number of actions and EPLAN menus here.

Commands:

Once you have selected a category, the associated buttons / commands are displayed in this list.

Note:

If you choose an Action or a Menu without an image file, you have to make other display settings before placing them on a toolbar.

Description:

Once you have marked an entry in the Commands list this field displays the associated description.

Tab Options

Overview of the main dialog elements:

Show tooltip on toolbars:

Activate this check box to show small descriptive text boxes on the toolbars.

Show shortcut keys in tooltip:

If this check box is activated, the shortcut keys are also displayed in addition to the descriptions.

Large images:

If this check box is active, the buttons in the toolbar are displayed as big buttons.

Toolbars tab

In this tab you select the toolbars to be displayed by selecting or deselecting the corresponding check boxes.

Overview of the main dialog elements:

[Reset] / [Reset all]:

Click this button if you wish to delete one particular or all user-defined buttons of default toolbars again.

[New]:

Click this button to create a new toolbar whose name you specify in the Toolbar name dialog.

[Rename] / [Delete]:

These buttons are only displayed if you have selected user-defined toolbars in the Toolbars list. Click the button in order to rename or delete a user-defined toolbar again.

Show text labels:

Check this check box if, in addition to the buttons of the toolbars, their names should also be displayed.

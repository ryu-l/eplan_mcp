Dialog Test input

Dialog call:

You have opened a project. Utilities > Translation > Test input.

If you want to test individual words and terms you have to first create a test project. In this dialog you can test translate texts and thus check your translation settings.

The following dialog elements are available:

Input field:

In this field you can input the project text to be translated. The list below it contains all of the translation languages that you selected in the Project tab in the Translation languages field.

[Translate]:

If you click this button the project text will be test translated. The project text must be in the dictionary as a keyword and there must be translation texts available for the desired languages.

Output list:

This list displays the translation texts that EPLAN found for the project text. This field contains all of the translation languages that you selected in the Project tab in the Translation languages field.

Dialog Assignment "Function definition to graphic"

Dialog call:

You have opened a project. Utilities > Master data > Form > Open > [Open]. You have opened the Form properties - <Form name> dialog (Popup menu > Properties on the form in the Pages - <Project name> navigator dialog) and have clicked [...] in the Value field of Assignment: Function definition to graphic property.

In this dialog you specify for which function definition a particular graphic should be shown in the data area. This property is needed so that a (predefined) graphic can be shown in the terminal diagram, for instance, for terminals of a particular terminal type (i.e., with a particular function definition).

If after defining the assignment in this dialog you place the Assignment: Function definition to graphic property in the form, then a symbol is placed based on the function definition of the function to be output.

Overview of the main dialog elements:

Category / Group / Description:

Once a function definition has been selected, the corresponding values are shown in these fields.

Example:

"Feed-through terminal, 4 targets, with saddle" is selected as function definition; the fields are then filled in as follows:
Category: Terminals
Group: Terminals (2 connection points)
Description: Feed-through terminal with four targets and saddle jumper option.

Function definition:

Click [...] in this field to open the Function definitions dialog to select a function definition. Multiple selection is not possible here.

Note:

Both the Attributes tab and the Connection point data tab of the selected function definition can not be edited here!

Symbol library:

Once a symbol is selected, the corresponding symbol library is shown in this field.

Symbol name:

In this field, the symbol is entered whose graphic should be assigned to the function definition: Click [...] to open the Symbol selection dialog and select a symbol. Multiple selection is not possible here.

Note:

Take care that only the symbols of the stored symbol libraries are displayed. If you use a form in a project that does not contain the appropriate symbol library, then the components will be missing from the report!

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

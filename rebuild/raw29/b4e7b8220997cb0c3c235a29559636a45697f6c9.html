New Menu Item for the Manufacturing Data Export

The new separate, menu item EPLAN Smart Wiring is now available in the Utilities > Manufacturing data menu item for the export of projects for EPLAN Smart Wiring in the EPLAN Platform. The dialog that then opens only contains the relevant setting options for the name and the output directory of the EPDZ file.

Extension of the export data with cable properties

The export data continue to be output in the EPDZ format. The values of the following cable properties are now also exported to enable the routing of cables in enclosures in EPLAN Smart Wiring:

  • DT (full) (ID 200006)
  • Cable / Conduit: Source: Stripping length (ID 20081)
  • Cable / Conduit: Target: Stripping length (ID 20082)
  • Cable / Conduit: Length (full) (ID 20257)
  • Cable / Conduit: Type (ID 20040)
  • Cable / Conduit: Number of connections (ID 20042)
  • Mounting location: Description (ID 1250)
  • Remark (ID 20045).

Note:

This new interface is licensed with an optional fee-based extension module. You can find specifications on this in the current performance description for EPLAN Pro Panel.

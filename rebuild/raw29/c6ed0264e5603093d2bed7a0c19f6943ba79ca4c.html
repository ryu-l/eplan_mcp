Dialog Settings - <Report type>

Dialog call:

You have opened a project. Utilities > Reports > Generate. Click (New). In the Select report dialog, select a report type for a report overview, e.g. a device tag list. Click [OK].

In this dialog, you can specify the sorting, filter, and page-break schemes for report overviews. The sorting, filter, and page-break schemes are stored per user and stored with the report when a report page is generated.

Overview of the main dialog elements:

Filter:

In this field, you select a scheme specifying the project or parts data to be output. Click [...] to open the Filter dialog, which you can use to define or edit a scheme.

Example:

You are in the process of defining a table of contents. Define the following filter:

Active

Negated

Criterion

Operator

Value

Higher-level function

=

FB3

Mounting location

=

FT1

EPLAN generates a table of contents exclusively for those project pages located in the =FB3+ET3 structure level.

Sorting:

In this field, you select a scheme specifying the sorting order of the project or parts data in the reports. Click [...] to open the Sorting dialog, which you can use to define or edit a scheme.

New page if property value has changed:

In this field, you can select a scheme which specifies when a new page is generated. A property is stored in the scheme, e.g., "higher-level function". Whenever the value of this property changes, a page break is inserted and a new page is generated. Click [...] to open the New page if property is changed dialog, which you can use to define or edit a scheme.

A selected scheme is activated automatically. You can deactivate the selection of a scheme through the entry "-Not activated-".

Form (deviating from settings):

To assign a form to the selected report type which deviates temporarily from the specification in the settings, you open this dropdown list and click on "Browse". The directory defined as the form directory in the settings is already loaded in the Select form dialog. In the File type field, the form type matching the report type is automatically displayed. Select the desired form and click [Open].

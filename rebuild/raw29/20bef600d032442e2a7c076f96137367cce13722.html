Editing Format Groups

Precondition:

You have opened a project.

  1. Options > Settings > Projects > "Project name" > Connections > Connection numbering
  2. Select the Designation tab in the dialog Settings: Connection numbering.
  3. In the Format groups field select a format group and click (Edit).
  4. Change if necessary, the range of connections that are to receive the same format for their connection designations in the Extent field of the Connection numbering: Formats dialog. Select an entry from the drop-down list.

    Note:

    If you have selected the "Net" entry, you can use the net extension to expand the area of influence for numbering.

  5. In the Selected format elements field select an entry and click (Edit) to change the formatting. Or, in the Available format elements field select a format element and move it over to the right using the arrow button into the list of selected format elements in order to define an additional format element.

    Different subsequent dialogs will appear, depending on the format element.
  6. Specify the formatting in the subsequent dialog (Format: Properties, Format: Counter, Format: Page / column / row or Format: Separator).

    A preview of the designation format is displayed in the Preview field. The individual format elements are displayed in the connection designations in the same sequence as they currently exist in the list.
  7. If desired, you can change the sequence of the format elements using the arrow buttons.
  8. Click [OK].

    The changed values entered will be saved in the selected scheme.

Deleting format groups

Precondition:

You have opened a project.

  1. Project data > Connections > Numbering > Settings
  2. Select the Designation tab in the dialog Settings: Connection numbering.
  3. In the Format groups field select a format group and click (Delete).

    The format group is deleted.

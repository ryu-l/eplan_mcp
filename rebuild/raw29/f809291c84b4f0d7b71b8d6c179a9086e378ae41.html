Dialog Select structure

Dialog call:

You have opened a project. You have opened a page of the "P&I diagram" type.

  • You insert a PCT loop or a PCT loop function via the symbol selection.
  • You insert a page section either as a copy from the Clipboard or as a macro. This section contains components that are linked with segments from the pre-planning (PCT loops, PCT loop functions, containers, planning objects, piping planning objects, etc.).

In this dialog you specify the location where a segment in the structure is placed in the structure of the pre-planning and whether a newly inserted segment is to be numbered in the process.

When macros or copies are inserted, other segments from the pre-planning in addition to PCT loops / PCT loop functions are also taken into consideration in this dialog (containers, planning objects, piping planning objects, etc.). When the terms "PCT loop / PCT loop function" are used in the subsequent text, this also applies correspondingly for these segments.

Overview of the main dialog elements:

Source:

In the Tree tab the superior structure of the PCT loops / PCT loop functions in which these are sorted in the source project or in the macro is displayed hierarchically.

The higher-level structures and the inserted PCT loops / PCT loop functions are displayed in a table in the List tab. The columns of this list correspond to the column configuration of the pre-planning navigator.

Sorting into the structure by means of multiple selection is only possible if the PCT loops / PCT loop functions are not marked simultaneously with their superior nodes.

Project:

This tree displays the structure of the target project in which the PCT loops / PCT loop functions are inserted. All placed and unplaced segments are displayed.

Arrow buttons:

Button

Meaning

(Insert)

Allows for the PCT loop / PCT loop function highlighted in the Source field to be inserted below the segment highlighted in the Project field. If a superior segment is highlighted in the Source field, the complete structure below this selection will be inserted into the target project. New segments in the Project field are identified by the icon .

(Assign)

Allows you to assign a segment marked in the Project field to the segment marked in the Source field if their basic segment definitions match. This way, you can place a PCT loop / PCT loop function that already existed in the pre-planning together with the inserted graphic. The assigned segment is then highlighted in bold in the Project field, and identified by a status icon . If, on such a segment in bold, you click the button, the assignment is undone.

(Undo)

This allows you to undo the insertion of a PCT loop / PCT loop function. The PCT loop / PCT loop function highlighted in the Project field is moved, together with its superior structure, back to the Source field.

Tip:

You can also assign structures with multiple existing segments. To do so mark the respective node of an existing structure segment in the fields Source and Project, and click the button (Assign).

Popup menu:

Through the popup menu in the Project field it is possible to immediately create new structures and to edit existing segments when inserting PCT loops / PCT loop functions into a P&I diagram.

Menu item

Meaning

New structure segment

The menu item is only available if a structure segment has been highlighted. Allows a structure segment to be created.

Properties

Opens the Properties (components): <...> dialog. Allows you to edit the properties of the segment.

Number segments:

If this check box is activated, the device tag and designations of the segments are saved locally. In the process the settings for numbering in the Numbering / Availability tab of the dialog Configure segment definitions are used.

If this check box is deselected, the segments are not numbered.

EPLAN Actions: Overview

The following EPLAN Actions are available:

Action name

Description

backup

Backs a project or master data up.

changelayer

Changes the graphical properties of layers.

check

Checks pages or the entire project.

compress

Compresses a project.

CopyToolBarAction

Copies the buttons of one toolbar to another.

devicelist

Imports, exports, or deletes a device list.

edit

Opens a page or a project.

EplApiModuleAction

Loads and registers an API module.

EsCorrectConnections

Combines identical connection definition points.

ExecuteScript

Runs a script.

export

Exports pages or projects in different formats.

export3D

Exports layout spaces into the STEP format.

exportNCData

Exports NC data for different machine formats.

exportProductionWiring

Exports wire fabrication data into different formats.

ExportSegmentsTemplate

Exports segment templates into a file.

exportToGraphics

Exports pages or projects in graphic format (TIF, GIF, PNG, JPG).

gedRedraw

Builds the image of the graphical editor anew.

generate

Generates connections or cables.

GenerateMacros

Generates macros from a project.

GraphicalLayerTable

Imports / exports layers.

import

Imports projects, macros, or drawings.

ImportPrePlanningData

Imports pre-planning data.

ImportSegmentsTemplate

Imports segment templates from a file into a project.

InsertModelViewAction

Inserts model views into a project.

label

Generates the export of the manufacturing data / the labeling for a project.

masterdata

Updates the master data of the current project.

MfExportToolbarAction

Exports one or more user-defined toolbars.

MfImportToolbarAction

Imports a toolbar from a file.

MfRemoveToolbarAction

Deletes a user-defined toolbar.

OpenWorkspaceAction

Opens an existing workspace.

partslist

Imports or exports a bill of materials.

plcservice

Imports or exports PLC data by means of the specified configuration program.

print

Prints a page or the whole project.

ProjectAction

Runs an action for a project and closes the project after this.

projectmanagement

Loads a file with project information into the project management.

ProjectOpen

Opens a project.

RegisterScript

Registers a script.

Renumber

Carries out renumbering.

reports

Generates project reports.

restore

Restores a project or master data from backup.

SaveWorkspaceAction

Saves the current user interface settings as workspace.

search

Searches for objects (devices, properties, texts, etc.) in a project.

selectionset

Retrieves values (name, file path, file name extension) from selected pages or a selected project.

SetProjectLanguage

Determines display languages for editable and read-only projects.

SpExportSubProject

Files off a project that has to be opened in the "Exclusive" editing mode.

SpImportSubProject

Imports a project that has to be opened exclusively.

SwitchProjectType

Switches the "Type of project" property.

synchronize

Synchronizes project data.

Topology

Routes topology connections or creates topology functions.

translate

Translates a project, deletes the translation from the project, or exports a missing word list.

UnregisterScript

Unregisters a script.

UpdateSegmentsFilling

Calculates the value of the property "Topology: Fill capacity" (ID 20332) of the manual routing paths project-wide and enters it at the respective routing paths, i.e. supplies a feedback about the space reserves in manual routing paths.

XAfActionSetting

Sets a user, station, or company setting to a certain value.

XAfActionSettingProject

Sets a project setting to a certain value.

XCMRemoveUnnecessaryNDPsAction

Removes superfluous net definition points from the current project. If necessary, connection definition points are placed on the connections of the net so that no properties are lost.

XCMUniteNetDefinitionPointsAction

Unites net definition points that are placed in the same net of the current project. If more than one net definition point is placed in the same net, these net definition points (i.e. their connections) are combined into a net definition point. After the execution of this action a maximum of one net definition point exists per net that contains all the net-based connections of the net.

XDLInsertDeviceAction

Inserts a device.

XEGActionInsertSymRef

Inserts a symbol.

XEsSetPagePropertyAction

Sets a page property for the currently selected page to a specific value.

XEsSetProjectPropertyAction

Sets a project property for the currently selected project to a specific value.

XEsSetPropertyAction

Sets a component property for the currently selected component to a specific value.

XEsUserPropertiesExportAction

Exports user-defined properties into a file.

XEsUserPropertiesImportAction

Imports user-defined properties from a file.

XGedClosePage

Closes all selected pages. This action has no parameters.

XGedStartInteractionAction

Starts an interaction in the graphical editor. Possible interactions are (e.g.) insertion of a macro or definition of the format settings for components, text, or similar elements.

XGedUpdateMacroAction

Updates macros.

XMActionDCCommonExport

Starts the export for the external editing.

XMActionDCImport

Imports a data configuration file of external editing into an existing EPLAN project.

XMDeleteReprTypeAction

Removes from selected macros a representation type and saves these macros in a directory.

XMExportConnectionsAction

Exports the connection properties of a project for external editing.

XMExportFunctionAction

Exports the function properties of a project for external editing.

XMExportPagesAction

Exports the page properties of a project for external editing.

XPamsDeviceSelectionAction

Carries our a device selection or updates device data.

XPamSelectPart

Starts the part selection.

XPlaUpdateDetailAction

Updates the detailed planning in the pre-planning navigator.

XPrjActionUpgradeProjects

Updates one or more projects to the current database scheme.

XSDPreviewAction

Opens or closes a page or macro preview window.

XSettingsExport

Exports user, workstation and company settings.

XSettingsImport

Imports user, workstation and company settings.

XSettingsRegisterAction

Allows registering of add-ons.

XSettingsUnregisterAction

Allows unregistering of add-ons.

XTranslateSourceLanguage

Allows translating of texts in a specific source language.

Warning:

Please note that the examples given for the individual actions in the help topics are separated by line breaks to make them easier to read. If you want to use the examples in the form illustrated, you MUST delete these line breaks. Please also make sure that, during input, action and parameter as well as the individual parameters are separated from each other by a blank space.

Defined Working Sections

Projects can be divided into defined working sections. This creates more transparency in project editing, and facilitates the simultaneous editing of projects by several users. The criteria for the division are saved to filter schemes.

For projects structured by identifier blocks, the division is realized on the basis of structure identifiers that exist in the project for the identifier blocks. You can filter by any combinations of these structure identifiers. In addition you can filter pages, layout spaces, functions, and connections for certain trades.

Sequentially numbered projects can be divided only into trades.

The following is possible:

  • Using the selection of a scheme, you can specify the defined working section to work in.
  • When you use the rights management of EPLAN, the defined working sections can be assigned centrally by a project administrator. Without usage of rights management each individual user can determine him-/herself in which defined working section he/she wants to work.
  • The project data navigators will display only the pages, devices, etc. corresponding to the criteria determined in the scheme. This makes the display of large projects more transparent and increases the editing speed.
  • Editing can be extended temporarily to the entire project.

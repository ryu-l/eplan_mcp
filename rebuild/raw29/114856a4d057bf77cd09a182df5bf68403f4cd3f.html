Zoom Functions

The zoom functions can be used to enlarge a screen segment in order to see detailed information better. The line width and line type are scaled when zooming.

The zoom functions can be called through the menu in the graphical editor, using the keyboard, or with the mouse wheel.

The zoom setting selected is retained when switching pages.

The user settings (Options > Settings > User > Display > General, Display scroll bars check box) let you activate or deactivate the scroll bars.

The following zoom functions are available:

  • Area zoom or window [Z]
    After you have pulled up a window, this area is shown maximized.
  • Entire page [Alt] + [3]
    The drawing area within the plot frame is fit to the graphical editor. Elements drawn outside the plot frame are not taken into account.

Move the visible area

The visible area can be moved using the arrow keys.

Key

Movement

Arrow key [left], [right], [up], [down]

If the cursor would leave the graphical editor, the visible area is moved one X increment in the corresponding direction. (The cursor never leaves the graphical area.)

[Shift] +arrow key

The visible area is moved in the corresponding direction. (The cursor position is retained until the cursor would leave the graphical editor. The cursor position is then always set to the edge of the dialog.)

Use the mouse

The zoom functions support the mouse wheel, whereby the current position of the cursor is taken into account.

The behavior when zooming with the mouse depends on the user settings (Options > Settings > User > Graphical editing > 2D). There you define whether the "scrolling behavior" reflects that of word processing or CAD programs.

In the following table, the behavior for the setting "As for word processing" is described; for the setting "As in CAD", the behaviors of scrolling and "[Ctrl] + scrolling" are exchanged.

Mouse wheel

Zoom function

Scroll up

Moves page downwards (the visible area is moved upwards)

Scroll down

Moves page upwards (the visible area is moved downwards)

[Ctrl] + scroll up

Zooms into the page (enlarges)

[Ctrl] + scroll down

Zooms out of the page (shrinks)

[Shift] + scroll up

Moves page rightwards (the visible area is moved to the left)

[Shift] + scroll down

Moves page leftwards (the visible section is moved to the right)

PAN function

When moving the cursor and holding the middle mouse button down, the page contents are moved in the direction of movement. The cursor changes into a hand for this operation.

Multi-line Representation of Network Structures

In the past bus systems and bus ports had to be in single-line representation so that the network structures were included during the PLC data exchange. The multi-line representation is now also supported for the PLC data exchange in the AutomationML format. The network structure to be replaced is determined from the single-line and multi-line bus ports connected to each other. For all other formats only the single-line representation is taken into consideration.

Benefit:

During the PLC data exchange in the AutomationML format, multi-line representations and bus ports connected to each other are also taken into consideration. This way you have the option of single-line and multi-line representation of the network structure.

For the sake of clarity, we recommend using the single-line representation. If bus ports are drawn both as single-line and multi-line, we recommend entering the bus data at the single-line bus ports.

In the course of this extension the respective project checks of the message class "PLC / bus" were also adjusted so that they now also consider multi-line bus ports.

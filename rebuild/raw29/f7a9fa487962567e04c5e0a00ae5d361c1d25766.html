Dialog Settings: Macros

Dialog call:

Options > Settings > User > Graphical editing > Macros

In this dialog you define the user-specific settings for graphical editing of macros.

Overview of the main dialog elements:

Use graphical macro selection:

If this check box is activated, the graphical macro selection is used at all positions in the EPLAN platform where macros are selected. This is true of the insertion of macros via the menu items Insert > Window macro / symbol macro and Page > Page macro > Insert, of the placing of macros in the project data navigators, and of the selection of macros in parts management. When graphical macro selection is activated, you "browse" in a special selection dialog on the basis of stored icons, symbols or other image files through the directory structure and thus find the required macro easily.

If the check box is deactivated, the selection dialog of the graphical macro selection does not open when inserting macros.

Include nested macro boxes when inserting:

This functionality is important in particular when you work with macros that have been combined in a superior macro box. These so-called "nested" macros are used mainly at the designing of fluid schematics.

If the check box is activated, the original path and file name of the macro in the Macro (ID 20468) property field is retained at all the functions of the subordinate macros that are combined in the superior macro box.

If the check box is deactivated, the name of the superior macro box is entered at all the functions of the subordinate macros in the Macro (ID 20468) property.

Example:

Two symbol macros from the master data directory for FESTO macros, a 5-/2-directional control valve with the file name P_V_0054.ems and a double-acting cylinder with the file name P_A_0017.EMS a combined in a common macro box with the file name V_Z_001.ema, so that a nested macro exists. The nested macro itself is also stored in the FESTO macro directory. The Macro property was selected for display at the functions of the subordinate macros as well as at the superior macro box.

The nested macro is now inserted twice consecutively on a fluid schematic page. The first time the check box Include nested macro boxes when inserting is activated. After the macro has been placed, the path and file names at the functions of the subordinate macros within the nested macro are retained (see the following figure on the left). Now the check box is deactivated and the nested macro is inserted once more. This time the path and the file name of the superior macro box V_Z_001.ema is entered at all the functions of the subordinate macros in the Macro property (see the following figure on the right).

Note:

You can carry out a part selection at the functions and use the name of the subordinate macro as an automatic filter in the process. To this purpose the corresponding file names of the macros have to be stored at the parts to be selected.

Group box "Open value set selection dialog for placeholder objects"

Placeholder objects that were inserted into macros can contain value sets. Here you determine whether the selection dialog for value sets is displayed during the insertion of such macros.

When inserting window macros:

If this check box is selected, the Select value set - <Placeholder name> dialog opens when window macros or symbol macros with placeholder objects are inserted.

Note:

If this setting is activated, the value set selection is also opened during the copying and pasting of placeholder objects as well as of window and symbol macros with placeholder objects.

When inserting page macros:

If this check box is selected, the Select value set - <Placeholder name> dialog opens when page macros with placeholder objects are inserted.

Note:

This setting has no effect on the copying and pasting of project pages with placeholder objects. During such an action the value selection is not opened.

Dialog Format: Page / Column / Row (Numbering with PLC Data)

Dialog call:

You have opened a project. You have opened the dialog Settings: Number using PLC data (for example with Options > Settings > Projects > "Project name" > Devices > Number using PLC data). You have selected a user-defined scheme in the dialog Settings: Number using PLC data. You have selected an entry in the Format groups field and clicked (Edit), or you have clicked (New).

Select a format element of the type "Page", "Column" or "Row" in the Available format elements list of the dialog Number using PLC data: Format and move it to the Selected format elements list by using the arrow button.

In this dialog, you specify the formatting for a page name, column or row number in the format group.

The following dialog elements are available:

From PLC connection point:

Select this option so that the page name, column, or row number of the PLC connection point is used for the format.

From target:

Select this option so that the page name, column, or row number of the target item is used for the format.

Minimum number of digits:

Here you define the minimum number of characters to be used for the property value. Longer values are displayed in their full length. Only positive numeric values are permitted. A value of zero means that the field width is variable.

Filler character:

The value is padded with this character if the Minimum number of digits is larger than the width of the value.

Dialog Assignment "Property / value to graphic"

Dialog call:

You have opened a project.

  • Utilities > Master data > Form > Open > [Open]. You have opened the Form properties - <Form name> dialog (Popup menu > Properties on the form in the Pages - <Project name> navigator dialog) and have clicked [...] in the Value field of Assignment: Property / value to graphic property.
  • Utilities > Master data > Plot frame > Open > [Open]. You have opened the Plot frame properties - <Plot frame name> dialog (Popup menu > Properties on the form in the Pages - <Project name> navigator dialog) and have clicked [...] in the Value field of Assignment: Property / value to graphic property.

In this dialog, you define the form or plot frame property with a particular value, for which a specified graphic should be shown in the data area. Ten properties are available here.

If after defining the assignment in this dialog you place the Assignment: Property / value to graphic [n] property in the form / plot frame, then a symbol is placed, based on the value of the selected property. With forms, this can be the Graphical display in reports [1] and Graphical display in reports [2] properties for terminals, for instance, but any other properties can be used. Or you could use the User supplementary field 1 page property, to display an electronic signature in the plot frame.

Overview of the main dialog elements:

Symbol library:

Once a symbol is selected, the corresponding symbol library is shown in this field.

Symbol name:

In this field, the symbol is entered whose graphic should be assigned to the property with the given value: Click [...] to open the Symbol selection dialog and select a symbol. Multiple selection is not possible here.

Note:

Take care that only the symbols of the stored symbol libraries are displayed. If you use a form / plot frame in a project that does not contain the appropriate symbol library, then the components / symbols will be missing from the report!

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

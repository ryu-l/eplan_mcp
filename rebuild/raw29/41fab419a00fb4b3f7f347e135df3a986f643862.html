Finding and Storing Missing Project Master Data, Updating Projects

Complete projects

By copying pages, for example, it can occur that new master data references to forms, plot frames, etc. will be inserted in the project. These do not necessarily have to be in the target project because referenced master data is not automatically embedded. Such projects can still be updated / completed, i.e., the used but unsaved master data is taken from the master data pool and copied into the project.

Preconditions:

  • You have opened the project whose master data is to be completed.
  • You have no editor open for working on master data (Plot frame editor, Form editor, etc.).
  1. Select Utilities > Master data > Complete current project.

    The project will search for the missing master data and, if it exists, it will be automatically stored.

Note:

The result of this action is logged in the system messages. This records, for example, when no data is in the master data pool for missing project master data or when an error occurs during completion. The relevant information can then be found under Utilities > System messages.

Update project

After editing forms, plot frames and / or symbols in the appropriate editor, the project does not contain the current data. If this data should be accepted in the project, the project must be updated as follows:

Preconditions:

  • You have opened the project whose master data is to be updated.
  • You have no editor open for working on master data (Plot frame editor, Form editor, etc.).
  1. Select Utilities > Master data > Update current project.

    The project is searched. If master data files more current than the corresponding project master data files are found, the newer files will be automatically saved, i.e., they will overwrite the project master data files.

Note:

The result of this action is logged in the system messages. This will record, for example, when no data in the master data pool is available for certain project master data. The relevant information can then be found under Utilities > System messages.

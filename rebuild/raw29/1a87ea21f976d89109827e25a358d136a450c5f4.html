Projects

In EPLAN, schematics and attached documents such as lists and overviews are created as pages within projects. Besides the project pages, a project contains all master data used in the project (symbols, plot frames, forms, parts data, etc.). The following is possible:

  • From the EPLAN main window, projects can be created, renamed, and deleted. Please note that deleting is carried out into the Windows-specific Recycle Bin. If required, such a deleted project can be restored from there.
  • Projects can be opened and closed from the EPLAN main window.
  • You can create project templates and basic projects, and use these for creating new projects.

Popup Menu Item for the Properties of the Assigned Segment

For functions in the schematic or for the piping definition points in the P&I diagram that are assigned to a segment in the pre-planning, the new popup menu item Properties (pre-planning) is available in the popup menu of the Graphical editor. The property dialog of the assigned segment is opened by means of this menu item.

Benefit:

You can directly edit the properties of the assigned segments from the graphical editor without having to use the pre-planning navigator by means of the popup menu item Properties (pre-planning).

If you select this popup menu item for a function linked with the pre-planning, for example on the schematic page, the property dialog of the assigned planning object is opened.

Dialog / Tab Parts data assignment

Dialog call Parts data assignment dialog:

You have opened a project. You have selected the desired elements or pages that are to be saved as a macro. Edit > Create window macro / symbol macro or Page > Page macro > Create. In the Save as dialog select [Extras] > Assign parts data.

Dialog call Parts data assignment tab:

You have inserted a macro box in a macro project (Insert > Box / connection point / mounting panel > Macro box), or you have double-clicked an existing macro box. Select the Parts data assignment tab.

When insertig devices (parts) with assigned macros, the part properties are copied from the EPLAN parts database to any properties of the objects which are inserted into the project from the macro. In this dialog / tab you can edit the properties of the objects inserted from the macro; the values from the part's free properties are also considered.

It is also possible here to enter a property in the Part number field. The part is then selected, and stored. The data from this type of part, however, is not transferred again to the function.

When using the part, this assignment is then used when transferring the parts data to the functions in the macro. This happens when you carry out the "Insert device" option and when selecting devices and parts.

Note:

If in the macro, parts data and the values of a placeholder object are assigned at the same time to the same property of an object, then the parts data assignment "trumps" when inserting a device with a corresponding stored macro.

Overview of the main dialog elements:

Category:

From the drop-down list, select the type of properties to be displayed in the table below.

Table:

This table shows all properties belonging to the objects of a macro and their current values. The properties displayed in the table depend on the selected category.

The table contains the following columns:

  • Property: The properties of the object are displayed as a tree structure here.
    If you open the tree by clicking , first the object names (e.g. symbol type) are displayed and then the properties of the placeholder object at the lowest level.
  • Current value: The current value of the respective property is displayed here.
  • Assignment: Here you store the new / changed value for the property.
    Click [...] to open the Format dialog and select the desired format elements from the list of available format elements.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

In addition, the following dialog-specific popup menu items are available:

Menu item

Meaning

Cut / Copy / Paste

Only in the Assignment column: Normal Windows functions for editing records apply. When pasting, EPLAN automatically checks whether the new entry is suitable for the corresponding property and cancels the action with a message if that is not the case.

Delete

Only in the Assignment column: Deletes the current entry.

Delete object

Only available when at least one row is selected: Deletes the entire selected object including all of its assigned properties as soon as you confirm with [Yes].

Only display properties with value in Assignment column:

This check box allows you to drastically reduce the number of displayed properties. If this check box is activated, then the table only shows the properties with an entry in the Assignment column.

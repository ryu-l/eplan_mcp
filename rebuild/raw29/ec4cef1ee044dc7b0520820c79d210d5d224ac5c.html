P004029: Object marked for deletion

Description

When importing PLC configuration files, PLC objects (PLC boxes, PLC connection points or addresses) are marked program-internally if they exist in the EPLAN project in the associated configuration project, but not in the import file.

After importing the PLC data, this marking is visible for the respective objects in the Addresses / assignment lists dialog (menu path Project data > PLC > Addresses / assignment lists) as activated check boxes in the Marked for deletion table column.

When importing in AutomationML format, PLC connection points are additionally marked for deletion if the symbolic address in the import file is empty, but the Symbolic address (automatic) property is filled at the associated PLC connection point in EPLAN. The existing symbolic address remains.

When carrying out the check run, all objects with this marking are searched for. A message is output in the message management for every PLC object found.

Note:

The marking is retained after the messages have been output.

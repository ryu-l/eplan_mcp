Selecting Fittings

The Select fitting dialog can be used to facilitate the selection of the fitting to be mounted at the left and right on the hose during the configuration of hose lines. This dialog makes it possible to select the desired fittings from those defined by you in the settings rapidly and easily. If an image file is stored in the settings, a corresponding graphic is displayed as a preview for each fitting, depending on the series.

Preconditions:

  • You have opened the Edit <...> dialog.
  • You have already selected or entered all the data in the Hose group box and in the Further specifications group box.
  1. Click [...] next to the field Fitting left or Fitting right.
  2. Decide which fittings are to be mounted in the fields of the Select fitting dialog.
  3. Double-click the selected fitting.

    The selected fitting is displayed in the preview window in the Edit <..> dialog.

    The designation of the type of construction is entered at the corresponding position in the Type code field.

2D Panel Layout: Legends

Legends gather and display information, or store information from the graphic in a free area. The enclosure legend is a function-specific report, i.e., the DT of the mounting panel must be unique.
Since a mounting panel is a graphically accurate representation of reality, a scale is used that can represent all elements of the mounting panel on an A3 / A4 page. This has the disadvantage that the part references can be very small and the labeling text can be difficult to read. The labeling text can therefore be reasonably stored as a legend. In this manner, instead of the identifying device tag, only a short unique item number is displayed that refers to the name of the device, as well as optionally further part properties (for example, type number, cross-reference, etc.), listed in the enclosure legend.

The Part number (ID 20100) property allows you to combine identical part numbers in a line when you output the enclosure legend; select this property from the Property selection dialog for the Combine in a line form property. You can also output the number of part placements combined in a line using the Total amount (number of units) (ID 20499) placeholder text.

Window legends

An independent list is created for every mounting panel, containing the name of the mounting area to which the legend applies. If the legends are created on the same page containing the mounting panel, then we talk of a Window legend. Window legends are freely positionable graphical objects and have an insertion point and symbol properties and / or a device tag.

Page legends

The legend can also be output as a separate form. In this case no legend is shown in the graphical editor on the panel layout page. However, items will display item numbers but no device tags. We call this type of legend a Page legend.

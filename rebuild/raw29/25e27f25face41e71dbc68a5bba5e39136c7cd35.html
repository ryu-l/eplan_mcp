P027030: Topology partial routing path does not exist in pairs

Cause

Two topology partial routing paths with the same DT form a routing path together, but not a partial routing path pair. The reason is that both topology partial routing path are either main or auxiliary functions.

Solution

  1. Locate the first topology partial routing path in the routing path network using the Go to (graphic) functionality from the popup menu in the Message management dialog.
  2. Open the property dialog of the topology function and check whether the Main function check box is activated in the Partial routing path tab.
  3. Repeat the process for the second topology partial routing path that is also displayed in the Message management dialog.
  4. Afterwards make one of the two topology partial routing paths the main function and the other one the auxiliary function, so that a topology partial routing path pair is created.
  5. Confirm the changes with [OK].
  6. Then start a new check run.

Tab Deletion marker

Dialog call:

You have opened a project containing deletion markers and are viewing a schematic page in the graphical editor. You have double-clicked a deletion marker (or selected the Properties popup menu item; in which case, several deletion markers may be selected). In the Properties <...> dialog, select the Deletion marker tab.

This tab displays the properties of a deleted object. Deletion markers are placed on the EPLAN576, Graphic.Deleted objects layer by default.

Overview of the main dialog elements:

Deleted object:

This field contains the name of the deleted object at the time it was deleted, e.g., the DT for a function or the page name for a page.

Type:

This field contains the type of deleted object, e.g., Function, Structure box, Page, etc.

User name:

This field contains the name of the user who deleted the object.

Delete date:

This field contains the time (date and time) at which the object was deleted.

Properties group box

Note:

There are special properties that help you to detect objects that were placed at the same point as the deletion marker and were also deleted. The properties of the other deleted objects can be displayed via the Deleted object (further): Name, Deleted object (further): Type, User name (further) and Delete date (further) properties. The individual objects are selected by index, i.e., index [1] displays the properties of the second deleted object, index [2] the properties of the third deleted object, etc. The object deleted first has the highest index value.

Example:

Three components were placed and deleted again in succession at the same point in the schematic. You can display the properties of all three objects at the deletion marker: The name of the last deleted object is displayed in the Deleted object field. The Deleted object (further): Name property together with index [1] outputs the name of the second deleted object, and with index [2] gives the name of the first deleted object.

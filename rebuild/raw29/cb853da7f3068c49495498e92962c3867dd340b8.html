New Project Property for the Display of the Highest Revision Index

If you use the revision control with change tracking, you assign a revision index when completing pages or layout spaces. This revision index is saved at the respective page / layout space in the property Revision index (change tracking) (ID 11071). You can now print the highest revision index in a project by using the new project property Highest revision index (change tracking) (ID 10098).

Benefit:

The new Highest revision index (change tracking) project property allows you to immediately see which highest revision index a project has.

The Highest revision index (change tracking) property supplies the highest revision index of all pages and layout spaces in the project. It can be placed as a special text on a project page and be printed this way. The property searches for the newest revision index. This must correspond to the format set in the Settings: Change tracking (numbering of the revision index) dialog and must not be changed subsequently.

P026100: Updating of the part placement is not possible: <x>

Cause

Several causes are possible. The placeholder <x> of the message specifies the cause which led to the message being output.

Solution

  1. Locate the part placement in the layout space using the Go to (graphic) function from the popup menu in the Message management dialog.
  2. Depending on the displayed placeholder carry out one of the following corrections:

    3. Placeholders

    Solution
    • Enclosure cannot be updated

    None - enclosures cannot be updated.
    • Part could not be found

    Create the desired part in the parts management.
    • The function definition of the part is not compatible with the part placement

    Check the function definition of the part and adapt it correspondingly.
    • Group of the function definitions of the part macro is not compatible with the part placement
    • Macro of the part contains more than one logic item
    • Macro contains more than one variant for representation type '3D mounting layout'

    Edit the macro so that the respective condition is not fulfilled.
  3. Start a check run (any check run scheme set) to delete the module-specific message from the dialog of the message management.
  4. Update the part placement again.

Drawing Circles, Arcs, and Ellipses

Precondition:

You have opened a page, form, plot frame or symbol.

Draw circles

Define circles through the center and the radius

  1. Select the following menu items: Insert > Graphic > Circle
  2. Define the center of the circle.
  3. Pull the circle out from the center, and click the left mouse button to define the radius.
  4. End the action via the Cancel action popup menu item or via the [Esc] button.

Define circles through three points on the circumference

  1. Select the following menu items: Insert > Graphic > Circle through 3 points
  2. Define the first, second and third point of the circumference consecutively.
  3. End the action via the Cancel action popup menu item or via the [Esc] button.

Draw arcs and sectors

Define arcs / sectors through the center and the radius

  1. Select the following menu items: Insert > Graphic > Arc through center or Insert > Graphic > Sector
  2. Define the center of the circle.
  3. Pull the circle out from the center, and click the left mouse button to define the radius.
  4. Define the first and second points of the arc or sector consecutively.
  5. End the action via the Cancel action popup menu item or via the [Esc] button.

Define arcs through three points on the circumference

  1. Select the following menu items: Insert > Graphic > Arc through 3 points
  2. Define the first and second points of the arc consecutively.
  3. Pull the circle out from the center, and click the left mouse button to define the arc.
  4. End the action via the Cancel action popup menu item or via the [Esc] button.

Draw ellipses

  1. Select the following menu items: Insert > Graphic > Ellipse
  2. Define the center of the ellipse.
  3. Pull the ellipse out from the center, and click the left mouse button to define the size of the ellipse.
  4. End the action via the Cancel action popup menu item or via the [Esc] button.

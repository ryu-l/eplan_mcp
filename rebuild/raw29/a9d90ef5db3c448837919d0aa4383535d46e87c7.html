Dialog Number (offline)

Dialog call:

You have opened a project.

  • Page > Navigator. One or more pages are selected.
  • Project data > Devices > Navigator. One or more devices are selected.

Project data > Devices > Number.

In this dialog, you can limit the numbering formats and the scope of numbering. The DTs of the main functions on the selected pages and also the DTs of all associated auxiliary functions are displayed. The DTs of the auxiliary functions that are unplaced or are on unselected pages are also displayed.

Overview of the main dialog elements:

Filter:

You can use the filter to limit the amount of devices that are to be numbered. You can only filter on main functions.

This drop-down list displays all the available filters. A chosen filter is activated automatically. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the Filter dialog. Here you can create, edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

  • Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
  • Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

Selected identifiers:

This table defines which devices should be numbered in what way.

  • Identifier: This column contains all the identifiers used in the selected devices.
  • Format: In this column you see the selected numbering format. You can assign a numbering format to each identifier. There is a standard numbering format. You can define additional numbering formats.
  • Number: If this check box is activated, all the devices with the identifier in the Identifier column are numbered. If this check box is deselected, these devices will not be numbered.
  • Only number marked ones: If this check box is activated, devices flagged with a "?" will automatically be renumbered.
  • Start value: Here you enter the value with which the device numbering should start. Allowed values are 0-X.
  • Increment The value in this field determines the increment between consecutive numbers when numbering. This allows you to reserve a number range. Allowed values are 1-X.
  • Group: If the check box is activated, the identifier in the Identifier column becomes a member of an identifier group. All devices beginning with this identifier (e.g., K in KT44) are numbered. If the check box is deselected, all devices containing only this identifier in the DT (e.g., K23) are numbered.

    Example:

    The schematic contains four coils with the device tags K1, K1, KT1 and KA1. You have selected a numbering format that outputs the identifier and the counter. You have defined a start value of 1 and an increment of 1.

    If the Group check box is selected in K identifier row, then the coils K1, K1, KT1 and KA1 are numbered because the DTs of the coils begin with the identifier K.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

Also number those controlled by PLC:

If this check box is selected, all devices whose DT is influenced by a PLC address are also numbered.

Also number cables whose DT contain source / target:

If this check box is checked, cables whose DT is composed of source and target are also numbered. If this check box is deselected, these cables will not be numbered.

Tab Format (device)

Dialog call:

You have opened a project.

  • You have inserted a symbol in the graphical editor containing formattable graphical components (e.g., a black box, a shield, or a cable definition line), or you have generated a corresponding function in a navigator. In the Properties dialog, select the Format tab.
  • You have selected a symbol in the graphical editor containing formattable graphical components (e.g., a black box, a shield, or a cable definition line), or you have generated a corresponding function in a navigator. Edit > Properties. In the Properties dialog, select the Format tab.
  • The layout space navigator is open and a layout space is open. You have inserted an auxiliary line or double-clicked an auxiliary line. In the Properties dialog, select the Format tab.

On this tab, you can edit the display properties of the graphical elements of a symbol, like the view of black boxes or PLC boxes, shields, cable definition lines, etc.

Overview of the main dialog elements:

Property / Assignment:

To this purpose the hierarchy levels <Graphical element> and Format are available. These can be opened by clicking the sign.

Note:

For editing the graphical data of connections, the Connection graphic tab is displayed instead of the Format tab; it provides the following setting possibilities:

  • Tab Connection graphic

For part placements in the layout space, only the Format hierarchy level is available; it contains the settings described in the following section:

  • Tab Format (3D part placement)

<Graphical element> hierarchy level

Here you determine specific settings for the graphical element such as, e.g., coordinate and length entries. Depending on the type of graphical element, one of the following hierarchy levels will be displayed here:

  • Line
  • Polyline
  • Rectangle
  • Shield

Format hierarchy level

Invisible:

Choose the entry "Yes" from the drop-down list if the element is not supposed to be visible on the schematic page. It is still present in the project, however. In the user settings, you define whether or not invisible elements are to be displayed and / or printed (in a different color).

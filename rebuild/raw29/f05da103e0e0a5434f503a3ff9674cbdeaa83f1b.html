Adding body and chapter to mechatronic components

In the first step, you need to link the Word components for the body and chapter of the ListOfComponents with the mechatronic components:

  1. Double-click to open the component Feeder in the T_Mechatronic_ModularSystem library in the Stations unit and move the Word component Body from Library Catalog to Components (editor panel).
  2. Move Chapter (twice) from Library Catalog to Components (editor panel).
  3. Rename the newly added components:

Body to ListOfComponents

Chapter to Actuators_Table

Chapter2 to Sensors_Table

Tip:

Switch to editor mode by clicking again on the selected component or by pressing [F2].

  1. Once again, click on ListOfComponents . The accompanying parameter table will now appear.
  2. Enter the following formula as a value in the table in the parameter line Logo:
=type('T_Mechatronic_ModularSystem.Images.Logo').image

This formula identifies the image that is saved in the image object T_Mechatronic_ModularSystem.Images.Logo.

  1. Enter the following formula as a value in the table in the parameter line Heading:
=this.name

This formula is used to determine the name of the current components (Feeder).

  1. Click and select Actuators_Table. The accompanying parameter table is now shown.
  2. Enter the value Actuators in the table in the parameter line Heading.
  3. Repeat the final two steps for Sensors_Table and the title parameter value Sensors.

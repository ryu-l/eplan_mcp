Test 3 - Generate the current state of the ListOfComponents

To create and view the components list, open the Mechatronic popup menu in the Project Catalog and select the SequenceSelectionAction Word > Generate and open Word document:

This operation again creates an error. The reason for this is that the component Image.Logo to be accessed in the model has not yet been created. The error message can be acknowledged by pressing [OK].

The created ListOfComponents looks as follows:

The logo on the cover sheet is, however, missing and the table of contents is not up-to-date, although the contents that are shown appear to be correct.

If the table of contents was updated before Chapter.docx was saved, the formula (*{LOOP:dos}*)(*{Content}*)(*{END_LOOP}*) is shown as chapter 1.1 as the chapter heading.

The table rows for actuators and sensors are now respectively contained in the correct chapter.

The images of the actuators and sensors are, however, still missing in the Symbol column.

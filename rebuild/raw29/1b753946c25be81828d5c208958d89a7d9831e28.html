Copying, Cutting, and Pasting Elements

EPLAN supports the familiar Windows commands for copying, cutting, and pasting of elements.

Precondition:

You have opened a page, form, plot frame or symbol.

  1. Select the desired elements and select either the menu items Edit > Copy, or Edit > Cut.
  2. If you work with multiple Clipboards (definable in the user settings), enter a description for the contents of the relevant Clipboard in the Clipboard dialog and click [OK].
  3. If necessary, open a different page where you want to insert the copied / cut elements.
  4. Select the menu items Edit > Paste.

    If you are working with multiple Clipboards, EPLAN opens the Paste dialog. Select the desired element and click [OK].
  5. Move the cursor to the position where you want to insert the elements and press [Enter].

    The contents of the Clipboard are pasted into the currently open page.

Notes:

  • Each call of the options Copy or Cut overwrites the current contents of the Clipboard, if you are only working with one Clipboard.
  • If you press [X] or [Y] when inserting, the elements will be positioned horizontally or vertically aligned with the original.

Copy elements using drag and drop

The copying of elements can also be performed using the Windows-compliant Drag & Drop technique.

  1. Select the elements to be copied.
  2. Hold down [Ctrl] and the left mouse button, pull the elements to the new position, and release the keys.

    A copy of the elements is inserted at the corresponding position.

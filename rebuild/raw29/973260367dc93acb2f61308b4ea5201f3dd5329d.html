Part / Device Selection

Parts can be assigned to a function using part or device selection. Selecting parts means you can choose parts using sales data. Devices are selected according to technical characteristics.

The technical characteristics normally originate from the internal parts database, while sales data can be retrieved from an external database. Technical data can also be extended using an external database. It is also possible to work only with the internal parts database, or additionally, to integrate an external database.

Device selection

Device selection is always performed using the internal EPLAN parts database. During device selection, therefore, only the data maintained within the internal parts database is available.

After a device selection, the part data can be completed, if necessary, using an external database. The following data sources are available for this:

  • API Interface
  • Access database
  • SQL server.

The data source for completion of part data can be set separately from the data source for part selection.

Completion of part data using the internal interface is also necessary after insertion of a macro, in order to fill the parts with data that are only present as references.

Part selection

Part selection can be performed using the internal EPLAN parts database or through an external database, as desired. The following data sources are available for this:

  • API Interface
  • Access database
  • SQL server.

The data source for part selection can be set independently from the data source for the completion of data after a device selection.

After a part selection, the part data can still be completed with technical data using the internal interface.

Defining the Search Direction for DT Adoption

By default, device tags are adopted corresponding to the plot frame orientation. However, you can change the search direction for any function in which DT adoption is possible.

Preconditions:

  • You have opened a project.
  • In the project settings, you have defined that devices and macros are to be numbered online on insertion (Options > Settings > Projects > "Project name" > Devices > Numbering (online)).
  1. Select a function in the graphical editor or in one of the navigators and select the Edit > Properties menu items.
  2. In the Properties <...> dialog, select the <Function category> tab.
  3. In the Properties table, select the DT adoption: Search direction property, and select one of the possible settings from the drop-down list in the Value column.

    If the search direction is "According to orientation of plot frame", then the DT is taken from the left in projects using the IEC standard, from above in projects using the NFPA standard, and from the right in projects using the GOST standard.

    If the search direction is "An alternative to orientation of plot frame", then the DT is taken from above in projects using the IEC standard, from the left in projects using the NFPA standard, and from below in projects using the GOST standard.

    If the search direction is "Only from boxes", then the DT is taken only from the box surrounding the function (Black box, PLC box). If the function is not located in a box, no DT can be adopted.
  4. Click [OK].

Notes:

  • To prevent DT adoption in general, deselect online numbering.
  • To prevent the DT adoption for individual pages, activate the DT adoption: Only from boxes property at the selected plot frames for the pages.
  • To prevent DT adoption for individual functions, set the search direction "Only from boxes" for those functions.

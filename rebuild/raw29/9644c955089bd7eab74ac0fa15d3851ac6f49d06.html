Structure Boxes

Structure boxes are not black boxes; only the graphical properties are the same in that the standard line type is the same as the standard for structure boxes. A structure box may possess a DT, but it is not a device. In addition to this, a structure box cannot have a part number.

All elements located within a structure box can be assigned to other structure identifiers than those given in the page properties. The components then have the same relationship to the structure box as they normally have to the page. A structure box thus does not represent a device but rather a group which merely shows the constructor that it belongs to a particular place in the schematic.

When determining the full DT, the components located in a structure box are treated in exactly the same way as those in a black box. That means that the project hierarchy of components located in a structure box is recalculated if the size of the structure box changes or if the component or the structure box is moved.

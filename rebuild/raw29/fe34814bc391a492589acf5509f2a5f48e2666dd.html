Migrating Parts

To migrate the Rittal baying system TS8 to the Rittal baying system VX25 in the existing EPLAN Pro Panel projects by using the Migrate part functionality the conditions and limits described in the "Migration of Enclosure Parts" section apply.

Note:

Please read the EPLAN Disclaimer of Liability Declaration first before you use the Migrate part functionality.

Preconditions:

  • You have opened at least one project.
  • The layout space navigator is open.

Migrating a part automatically

Depending on the selection in the layout space navigator, a project, the complete contents of a layout space or an individual enclosure is analyzed. You can find a list of the Rittal TS8 parts that can be automatically migrated here.

  1. In the layout space navigator, select a project, a layout space or an enclosure.
  2. Select the menu items Edit > Migrate part or the Migrate part popup menu item.

    The selected part is then analyzed to see whether the manufacturer name is "Rittal" and whether the order numbers of the parts represent TS8 parts.

If the enclosure cannot be fully migrated because of missing replacement parts, the Migrate part dialog is shown. In this dialog you can decide how you would like to proceed.

  1. Click [OK].

    The parts are migrated as far as possible.
  2. Click [Export].

    The required Rittal VX25 replacement parts that are not available are exported to the Parts.csv file. You can use this file to execute an automatic import of these parts to the shopping basket of the EPLAN Data Portal.

Migrate part manually

Migratable accessories that were determined after the automatic migration with the Check run 026104 can be migrated later manually if a replacement part is available.

You can find a list of the parts that can be manually migrated here.

Preconditions:

  • The migration of this enclosure was executed.
  • Check run 026104 is performed.
  1. Select a part reported by the check run in the layout space navigator or the layout space.
  2. Select the menu items Edit > Migrate part or the Migrate part popup menu item.

    The selected part is exchanged for a VX25 part.

    The replacement part hangs on the cursor.
  3. Place the part in a suitable location in the migrated enclosure.

Tip:

In the settings dialog you can decide under the menu items Options > Settings > User > Devices > Part migration which auxiliary elements are to be transferred during the part migration. No auxiliary elements are transferred as the default setting.

Correct enclosure distances in line ups

After the migration of TS8 enclosures within a line up, intersections arise because of the larger width of 2 mm of the VX25 enclosures. These are reported as collisions in the check run 026011. Such intersections can subsequently be corrected.

Preconditions:

  • The migration of this enclosure line up was executed.
  • Check run 026011 is performed.
  1. Select the menu items Edit > Correct enclosure distance.
  2. Enclose all VX25 enclosures of the line up with a rectangle.

    The VX25 enclosures are each moved by a width of 2 mm.

    The collision was corrected.

Dialog Model views - <Project name> / Dialog Copper unfolds - <Project name> / Dialog Drilling views - <Project name>

Dialog call:

You have opened a project.

  • In order to display the model views available in the project, select the menu items Utilities > Reports > Model views.
  • In order to display the copper unfolds available in the project, select the menu items Utilities > Reports > Copper unfolds.
  • In order to display the 2D drilling views available in the project, select the menu items Utilities > Reports > 2D drilling views.

Use this dialog to manage all model views, copper unfolds or 2D drilling views of the opened project via the Reports tab.

Overview of the main dialog elements:

Model views / copper unfolds / Drilling views:

In this tree structure, the top tree-structure level displayed is the "Model views", "Copper unfolds", or "Drilling views" report type to be managed. The second structure level shows the layout spaces contained in the project. Below each layout space node, the model views, copper unfolds, or 2D drilling views assigned to this layout space are displayed, and below that, the pages on which the report is placed.

Toolbar:

The following buttons are available on the toolbar above the tree structure:

Button

Meaning

(Update)

Modifications to the objects in the layout space are not represented in the report automatically. The Update function harmonizes the model view / copper unfold / drilling view with the current project data in the layout space and corrects the display if objects are changed.

(Delete)

Deletes all model views / copper unfolds / drilling views below the highlighted node.

Popup menu:

The popup menu of the tree view on the Reports tab contains the same menu items as the buttons on the toolbar plus one additional menu item:

Menu item

Meaning

Open page (only node model views / copper unfolds / drilling views)

Opens the currently highlighted page with the model view, copper unfold, or drilling view in the graphical editor. The Reports - <Project name> dialog closes automatically in the process.

Property name / Value:

In these columns, the properties and values of the selected reports are shown.

Model view: Frozen:

If the check box of this property is activated, the associated model view, copper unfold, or 2D drilling view will be locked for updates. The display remains unchanged even if the objects in the layout space have been modified. With this setting, you can document different edited versions in the reports.

Dialog Property overview - <Project name>

Dialog call:

You have opened a project. You have selected one or more objects (texts, components, segments, graphical elements) in the graphical editor, in the layout space or in a navigator. Edit > Property overview.

In this dialog you can edit the properties of one or more selected objects (texts, graphical elements, functions, segments).

In order for the desired properties to be displayed for the selected objects, you must select or create a fitting scheme for a property configuration. You can, for example, use the included "Format graphic" scheme for graphical elements. Otherwise the "No data" entry is displayed for the properties in the Value column.

Overview of the main dialog elements:

Select a scheme from the drop-down list for the display and editing of the properties. Use [...] to open the dialog for the property configuration. There you can determine which properties are to be displayed and in which sequence for a scheme.

Toolbar:

Button

Meaning

(Tree view)

Shows the properties of the property configuration grouped according to their source objects in a tree view.

(List view)

Shows the properties of the property configuration arranged one below the other in a list.

Filter:

Into this field enter the text for which the properties are to be filtered. Both the names of the displayed properties as well as the values are searched.

If you want to return to the original view of the properties, remove the search term from the entry field. Click (Delete) to do so.

Property / Value:

Shows the values of specific properties for the marked object or marked objects. Which values you can edit depends on the selected scheme.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

Note:

Global editing of distributed functions in the Property overview dialog is not possible for the activated Properties (global) mode.

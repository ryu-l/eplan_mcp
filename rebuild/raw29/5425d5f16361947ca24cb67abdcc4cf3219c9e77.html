Synchronize stored parts with the parts database

Stored part properties are a fixed component of the project, while non-stored properties must be accessed through parts management.

The configuration of commercial data for part selection also applies to device selection, i.e., there is only one common configuration.

Update parts in project

Utilities > Parts > Update current project


The parts stored in the project are updated with data from the internal parts database. In addition the newer device data is transfered to the main functions that are using these parts.

Any messages are written to message management.

Synchronizing parts

  1. Select the following menu items: Utilities > Parts > Synchronize current project

    The Synchronization of parts - <Project name> dialog is opened.
  2. Select the required filter from the Filter drop-down list. You can either display the parts that are different in the project and / or system master data or only the older project master data or only the older system master data.
  3. In the Stored parts list highlight the parts that you want to carry over to the system master data and click the arrow button.

    The parts stored in the projects are carried over to the internal parts database. During this process, the function templates of the stored parts are stored into the parts in the internal database.
  4. In the System parts list highlight the parts that you want to store in the project and click the arrow button.

    The selected parts are stored in the project. In addition the newer device data is transfered to the main functions that are using these parts.

Warning:

When carrying over the stored parts to the system master data, only the parts not yet available in the parts database are synchronized. Already existing parts are not updated.

Tip:

You can replace all of the out-of-date stored parts with newer system parts via [Extras] > Update current project.
You can complete all of the system master data stored in the project that are not yet available in the system via [Extras] > Complete current system.

EPLAN Fluid: Connection Symbols

EPLAN Fluid contains different connection symbols for creating fluid power schematics:

  • Purely graphical connection symbols
  • Connection symbols that represent functions and to which properties can be assigned
  • Connection symbols for the inside of valve blocks.

Purely graphical connection symbols

Purely graphical connection symbols are used in EPLAN Fluid to display direction changes and connection line junctions in the fluid power schematic: Properties such as device, symbol, function, and parts data can't be assigned to these schematic objects.

The following objects are purely graphical elements:

  • Angles
  • T-nodes
  • Double junctions
  • Diagonals.

Connection symbols that represent functions and to which properties can be assigned

In addition to purely graphical connection symbols, you can also use connection symbols that represent functions in EPLAN Fluid. Properties such as device, symbol, function, and parts data can't be assigned to these. The properties of these objects can be evaluated and e.g. output in connection lists and / or bills of materials.

The following connection symbols are functions:

  • Connection splicers (T-node, double junction)
  • Line connectors (angle, straight line)

Connection symbols for the inside of valve blocks

In EPLAN Fluid, valve blocks can be displayed using black boxes. Connection symbols inside valve blocks must be inserted as functions that have properties, namely connection splicers and line connectors. In EPLAN Fluid, it is important to assign the "Auxiliary function" property to these connection splicers and line connectors, as they are auxiliary functions of the block.

Connection symbols for the transition between blocks and external connections, and within blocks

For the transition between connections inside valve blocks and connections outside, and connections within blocks, the device connection point (two-sided) can be used in EPLAN Fluid. Alternatively, the line connector can be used.

configuration

The <configuration> element encloses a definition for a node, which is not covered by the available name space, for example it allows a name space extension for the presentation of an overlay tooltip (see Overlays).

The presentation of gradients for the background of a node is enclosed by the <configuration> element.

The <configuration> element itself has no attributes.

Allowed sub-elements Quantity
bGradient 0 or 1
editRequestHandler any
editRequestHandlerInfo any
ruler-config 0 or 1

Note:

Follow the sequence:

Within <figureBase>, <figureContainer>, <figureEllipse>, <figureImage>, <figureLabel> and <figurePolygon> first configure <configuration> and then <properties>.

Example code:

An overlay displays the content of a Form-UI as a tooltip for a node.

<node id="OnewayComponent"
	super="AbstractThermodynamicComponente"
	valid="isInstanceOf('Thermodynamic_ModularSystem.Base.OnewayComponent')">
	<figureImage>
		<configuration>
			<editRequestHandler xsi:type="formui:formui-handler" />
			<editRequestHandlerInfo xsi:type="formui:formui-handler-info" refId="TDD" />
		</configuration>
		<properties>
			<property id="img">
				<read value="=type('Thermodynamic_ModularSystem.Diagram_Configuration.Imageregister').image(this)"/>
			</property>
		</properties>
	</figureImage>
</node>

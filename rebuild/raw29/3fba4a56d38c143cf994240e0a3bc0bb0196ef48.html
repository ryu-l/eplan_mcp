Dialog Identifier subclasses

Dialog call:

You have opened a project. Options > Settings > Projects > "Project name" > Devices > Numbering (online). Next to the Identifier subclasses field, click [...].

In this dialog you define the identifiers and their subclasses, including a text description per subclass, on a project-specific basis. The descriptions are managed as multilingual text. In the Displayed DT field of the component properties dialog you can then use the popup menu to select the subclass from the corresponding selection list.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to edit from the drop-down list. You can only edit user-defined schemes.

You can create new schemes, save any changes to a scheme, and copy or delete schemes via the adjacent Toolbar. Schemes can also be imported or exported.

Description:

This field displays the descriptive text that you entered into the Description field in the New scheme dialog when you created the scheme.

Toolbar:

The Toolbar contains the following buttons:

Button

Meaning

(New)

Inserts a new row at the end of the table.

(Delete)

Deletes the current table row.

Subclass / Subclass task:

Enter the respective designation of the subclass into the Subclass field; these characters are then adopted in the Displayed DT field of the component properties dialog when you open the selection list there. Enter descriptive text into the Subclass task field. This can be translated.

Within a column, you can sort in ascending or descending order by double-clicking on the column heading. The direction is shown in the column header with a graphical icon.

Popup menu:

Menu item

Meaning

Freeze panes

Fixes all the rows of the table above the selected row, or all of the columns to the left of the selected column. The rows below, or the columns to the right of the selection, can still be moved by using the scroll bar.

Unfreeze panes

Removes the freezing so that all of the rows and columns can again be moved using the scroll bar.

Adjust column width

Adjusts the width of all table columns so that both the headings and column contents are fully legible.

Font size 100%

This menu item is only available if the font size has been changed in the table (via [Ctrl] + scrolling with the mouse wheel). Re-displays the text in the table in its original font size.

Configure representation

Opens the Configure representation dialog, where you can specify the order and number of the columns to be shown.

If you have double-clicked a cell for editing, then the following menu items are available:

Menu item

Meaning

Special characters

Opens the Special characters dialog, in which you can select the desired character and insert it at the current cursor position with [OK].

Line break

Inserts a line break at the current cursor position.

Multi-line input

Opens the Multi-line input dialog where you can enter the lines desired. A line break can be forced using [Ctrl]+[Enter].

Translate

Opens the Found words dialog if dictionary translation entries exist for the entered term. Select the suitable translation text. If there are no translations in the dictionary, the Translate dialog is launched to enable you to enter a new translation text.

Remove translations

Deletes all of the translated text.

Mark text as 'Excluded from translation'

Marks the selected text as "Excluded from translation". Texts marked in this way are excluded both from the translation and from being output into a missing-word file.

Remove marking

Removes the "Exclude from translation" marking for the selected text so that the particular text will be included in the translation again.

Multilingual input

Opens the Multilingual input dialog, in which you can enter the output text for the desired translation text.

Generating Mounting Panel Cross-references

At a part or device placed on a mounting panel, you can create a cross-reference pointing to the associated main function in the schematic. You can also do the reverse and create a cross-reference at the main function in the schematic that points to the placed part or device on the mounting panel.

Preconditions:

  • You have opened a project.
  • You have created a multi-line schematic page.
  • You have created a page of the type "Panel layout".
  • Under Options > Settings > Projects > "Project name" > Cross references / contact image > Display, in the Display device cross-references group box, you have specified that cross-references between multi-line schematic pages and pages of type "Panel layout" are to be displayed.
  1. Open the multi-line schematic page in the graphical editor and insert a symbol, for example, a contactor coil.
  2. In the Property <...> dialog, in the <Function category> tab, enter a Displayed DT for the contactor coil, for example, K1.
  3. If not already selected, select the Main function check box.
  4. Switch to the Part tab, and in the first free field under Part number click [...].
  5. Navigate through the Part selection tree view to the "Relays / contactors" product group.
  6. Select the appropriate part containing width and height information (Mounting data tab of the selected part).
  7. Click [OK].

    The part selection dialog is then closed and you are back in the properties dialog.
  8. Click [OK].
  9. Open the page of "Panel layout" type.
  10. Select the menu item Insert > Box / connection point / mounting panel > Mounting panel, and draw a rectangular mounting panel.
  11. In the Properties <...> dialog, in the Mounting panel tab, enter the Displayed DT of the mounting panel and click [OK].
  12. Select the menu item Project data > Parts / Devices > 2D panel layout navigator.
  13. In the tree view of the Panel layout - <Project Name> dialog, select the current project and navigate below the hierarchy level 'Unplaced' to the part number of the contactor.
  14. Select the part and then select Popup menu > Place on mounting panel.

    A rectangular graphic now hangs on the cursor whose dimension EPLAN has taken from the part information of the selected contactor.
  15. Move the graphic inside the mounting panel and place it there with a mouse click.

    A cross-reference is now created at the contactor coil in the schematic, pointing to the placed part on the 'Panel layout' page. Conversely, a cross-reference is created pointing to the contactor coil in the schematic on the "Panel layout".
  16. Open both pages in separate editors to observe the cross-reference display.

Mark mounting panel cross-references

To use a marking for highlighting mounting panel cross-references to main functions in the schematic, proceed as follows:

  1. Select the menu item Options > Settings > Projects > "Project Name" > Cross-references / contact image > General.
  2. In the Settings: General dialog, in the Marker for group box, enter any desired character into the Panel layout field.
  3. Click [OK].
  4. Update the display using the menu item View > Redraw.

Generating Reference Projects

Preconditions:

  • You have selected a project in the page navigator.
  • You dispose of the authorization to generate reference projects.
  1. Select the menu items Utilities > Revision control > Property comparison of projects > Generate reference project.
  2. Enter a name and optionally a brief description for the reference project in the corresponding fields in the Generate reference project dialog.
  3. Activate the Generate temporary reference project check box if you want to generate a temporary reference project.
  4. Click [OK].

    Depending on the setting for the Generate temporary reference project check box either a "normal" reference project is generated with the file extension *.elr or a temporary reference project with the file extension *.elt. You can also delete a temporary reference project in the project management if you do not dispose of the authorization to delete elr projects.

Display completed projects / reference projects

In order to display completed projects or reference projects in the page navigator, proceed as follows:

  1. Select the menu item Project > Open.
  2. In the Open project dialog in the File type field, select the entry "Completed EPLAN projects (*.elr)".
  3. Select the desired project (if necessary, switch to the corresponding directory) and click [Open].

    The project selected is displayed in the page navigator.

Defining Settings for External Editing

Before you can export data for external editing, you must first define the appropriate settings:

  1. Open the project for which you wish to define the settings for external editing.
  2. Select the menu items Options > Settings > User > Interfaces > External editing.
  3. In the Settings: External editing dialog, select a scheme from the Scheme drop-down list or click [...], to open a subsequent dialog where you can define the settings for a new user-defined scheme.
  4. In the File type drop-down list select the file type to be used when exporting.
  5. Click [Options] to define the settings for the selected file type, and click [OK].
  6. In the Target file field, define the drive, directory, and name of the target file to be created, or click [...] to interactively select the drive and directory.
  7. If you have selected the "Excel file (*.xls, *.xlsx, *.xlsm, *.xlsb)" entry from the File type drop-down list, you can enter the file path and the name of a template file in the Template field or select a file using [...]; this template then defines the format of the exported data.
  8. Select the Data tab.
  9. In the Available format elements list, select the object that must be accounted for on export; multiple selection is not possible here.
  10. Move the object using the (Move to the right) button in the Selected format elements list.
  11. Proceed in a similar manner for all format elements that are to taken into account when exporting.
  12. You can influence the sequence of the selected format elements by using the toolbar buttons.
  13. Click [OK].

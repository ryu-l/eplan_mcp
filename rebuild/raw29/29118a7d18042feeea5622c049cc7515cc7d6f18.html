Creating Allocation Schemes for Symbols (Changing Standards)

In the assignment scheme assign the symbols from the target symbol library to the symbols of the source symbol library. When changing standards the symbols of the source symbol library are replaced by the symbols of the target symbol library.

Preconditions:

  • You have opened a project.
  • In the case of several opened projects: You have selected a project in the page navigator.
  • You have set up a target project.
  • You have replaced the necessary forms and plot frames.
  • You have selected a target symbol library in the Master data tab and selected the Individual assignment check box.

Create a scheme

  1. Utilities > Change of standard > Project tab > [Next] > Rotation / flipping tab > [Next] > Master data tab > [Next]
  2. Click [Scheme] in the Symbols tab.
  3. In the Scheme field of the Settings: Symbol assignment dialog, select the scheme you want to edit or click (New) and create a scheme.

Select source and target symbol library

  1. Select [Extras] > Select source and target symbol library.
  2. In the Select source symbol library dialog select the symbol library you want to use for the assignment and click [OK].
  3. In the Select target symbol library dialog select the symbol library you want to use for the assignment and click [OK].

Enter and assign source and target symbols automatically

  1. Select [Extras] > Enter source symbols automatically.

    All symbols from the selected source symbol library are entered in the Assign symbols table.
  2. Select [Extras] > Suggest matching target symbols.

    The symbols from the selected target symbol library are entered in the Assign symbols table and assigned to source symbols.
  3. Check the symbol assignments.

    If EPLAN finds suitable symbols for the symbol exchange, then the status changes to "OK" .
  4. Click (Save) and then click [OK].

    The scheme is entered into the Symbols tab.
  5. Click [Next].

    Define the project structure.

Enter and assign source and target symbols manually

Precondition:

You have selected source and target libraries.

  1. Click (New) next to the Assign symbols field in the Settings: Symbol assignment dialog.

    In the Assign symbols table an empty row is inserted.
  2. In the Source area, click into the Symbol name column.

    The source symbol library opens in the Symbol selection dialog.
  3. Select a symbol and click [OK].
  4. Click in the Target section in the Symbol name column in the Settings: Symbol assignment dialog.

    The target symbol library opens in the Symbol selection dialog.
  5. Select a suitable symbol for the symbol exchange and click [OK].

    The assignment of symbols is checked.
  6. Assign other symbols in the same way.
  7. Click (Save) and then click [OK].

    The scheme is entered into the Symbols tab.
  8. Click [Next].

    Define the project structure.

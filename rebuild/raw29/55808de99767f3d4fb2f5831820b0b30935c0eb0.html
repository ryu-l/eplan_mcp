Dialog <Report type>

Dialog call:

You have opened a project.

  • Utilities > Reports > Generate. Click (New). In the Select report dialog, select a report type. Click [OK].
  • Utilities > Reports > Generate. Select the Templates tab. Next to the Start page of report block property, click in Value column and on [...].

In this dialog you define the start page for each report block. Whether a reports is generated in one or several report blocks depends on the type of Page sorting for reports that you have defined in the settings. When you generate a table of contents, then Total page sorting only generates a single report block, i.e. a table of contents for all the schematic documentation, whereas Higher-level function page sorting generates a report block for every higher-level function, i.e. a table of contents for each higher-level function. Either accept the start page EPLAN suggests for the report block, or specify a different start page. You define the start page by selecting existing structure identifiers of the page structure or by creating new structure identifiers.

Overview of the main dialog elements:

Structure identifiers:

In this table the structure identifiers are displayed and can be created or selected as the start page for the current report block. To create a structure identifier, directly enter the structure identifier. To assign a predefined structure identifier, click [...], and select a structure identifier from the subsequent dialog.

Page name:

In this field, the page name suggested by EPLAN for the report page is shown.

Append to the end:

This functionality affects the reports that you generate from report templates. The check box is available when you select a report template in the Reports dialog on the Templates tab and click on [...] in the Value column next to the Start page of report block property. If the check box is selected, the Page name field is cleared and grayed out. When the report is generated, the report pages are sorted into the specified structure identifiers. If there are already some report pages in the structure identifier level, all the new report pages will be sorted together behind the last existing page. Any page names that you may have left vacant between existing pages as spare pages, will not be used.

Supplementary field: Sheet no.:

In this field, the page number suggested by EPLAN for the report page is shown.

Automatic page description:

If this check box is selected, the format used for the page description is the one specified in the form for the Format for automatic page description property. If the check box is deselected, you can enter a page description in the Page description field.

Page description:

This field is available if the Automatic page description check box is deselected. In this field, you specify a short descriptive text for the page.

Page navigator:

In this field, the page structure is shown with all existing project pages. You can also define the start page of the report page in this way. If you select a page structure level, the structure identifier of the page structure level is automatically entered into the upper fields. The start page then begins at this page structure level.

Apply start to all structure identifiers:

This functionality is only available when you have generated a report in several Report blocks. You must define a start page for every report block. If this check box is selected then you do not need to define a start page for every report block or individually confirm every page suggested by EPLAN. The start page is automatically assigned by EPLAN for all further report blocks.

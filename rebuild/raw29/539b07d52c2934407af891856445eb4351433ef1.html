Tab Settings (Komax)

Dialog call:
  • Options > Settings > Company > Wire fabrication > Komax > Settings
  • Utilities > Manufacturing data > Wire fabrication > Komax. Click [...] next to the Scheme field. Select the Settings tab.

In this tab, information on the technical options of the machine to be used is stored. The individual settings are pre-set with appropriate values in a machine-specific manner, and can be modified here.

Overview of the main dialog elements:

Wire length minimum:

Minimum length the machine requires to handle the wire as defined (default value: 240 mm). Shorter wires are transferred to the machine with this minimum length.

Wire length maximum:

Wires that are longer than specified here cannot be processed by the machine (default value: 3,000 mm).

Conductor cross-section maximum:

Maximum cross-section of a wire that the machine can still process (default value: 6 mmÂ²).

Number of wires per bundle maximum:

Number of wires that the machine can combine into a bundle (default value: 50).

Total conductor cross-section maximum:

Limit value for the sum total of cross-sections of all wires (default value: 80 mmÂ²).

Continuous text from wire length:

Length from which wires are to be printed with endless text. If no value is entered, all wires will be printed with endless text.

Routing direction up / down / left / right:

Texts that are to be printed on the wire to indicate individual routing directions.

Maximum print font length:

Maximum number of characters that individual text can have (default value: 39).

Bundling at the machine:

This property controls how the machine is to bundle the generated wire bundles:

  • One end: The wire bundles are bundled at one end.
  • Both ends: The wire bundles are bundled at both ends.

Automatically rotate print texts:

The Komax export format offers the possibility to rotate a text if required.

If this check box is activated, the label texts of a wire to be fabricated for the identification of the connection side to the device are rotated by 180Â°.

Example:

The text at the left wire end is rotated by 180Â°. The mounting specialist can thus see that this wire end is to be connected at the left side of a device.

Double crimp module installed:

Using the double crimp module, fabrication of wires on dual sleeves is possible for various Komax machines.

If this check box is activated, the required information for the double crimp module is also exported during the KOMAX export.

Since a Komax part may consist of one or two pieces of wire, a different kind of processing is necessary for start and end (in the case of one piece of wire) and start, center, and end (in the case of two pieces of wire). If the contact lies in the center of a pair and if a machine command "TerminalKey" (AEH) has been defined for the "Crimp" conductor termination processing on the Machine command tab, the dual sleeve has to be fabricated in the center, with start and end of the pair only being stripped.

For this, the Conductor termination processing twin center setting is available on the Conductor termination processing tab.

Flex-bundling installed:

This setting influences the number of jobs (production units) that are generated in the export file for the Komax machine.

If this check box is activated, all the bundle processes are combined into one "lead job". This allows a flex-bundling module installed at the machine to execute this task, resulting in the acceleration of the bundle processing. The maximum number of wires in a bundle / lead job amounts to 99. When this number is exceeded, a further lead job is generated.

If this check box is deactivated, a separate job is generated in the export file for each bundle.

Note:

The Flex-bundling installed setting influences only the number of generated jobs in the export file. The extended functionalities of the flex-bundling are not supported by manufacturing data export of EPLAN Pro Panel. These functionalities have to be set directly at the machine.

Bundle type:

This setting determines whether either a Round bundle or a Sequence bundle is produced with the Komax wire fabrication machine. Prerequisite for the manufacturing of a sequence bundle is the existence of the machine option "Flex-bundling" at the Komax machine.

Dialog Prepare macros for automatic generation

Dialog call:

You have opened a macro project. You have selected the project, prepared page macros in the page navigator or prepared macros in the macro navigator or the graphical editor. Project data > Macros > Prepare macros for automatic generation.

In this dialog you specify which functionalities are carried out to prepare macros before automatic generation. This allows you to optimally prepare the macros before generation. By this means, for example the macros are detected more easily as a unit through the grouping after being inserted in the schematic. They can also not be separated unintentionally anymore.

Overview of the main dialog elements:

Group macro boxes and associated objects:

Activate this check box if the macro boxes and the associated objects are to be grouped for selected macros in the project.

The content of the macro box is checked. If the contents conform to the criteria of a device group, a device group is generated for the macro box with its associated objects.

Group page macros:

Select this check box if the selected page macros are to be grouped in the project.

Activate handles:

Select this check box if the respective handle is to be automatically activated for the selected macros with macro boxes. For macro boxes where this has not yet been the case the handles are set to their standard position as a result.

By activating the handle - both in the macro project and for the inserted macro in the schematic - you prevent that a change in the macro (e.g. the graphic) results in unwanted shifting of the macro and / or its elements after the update.

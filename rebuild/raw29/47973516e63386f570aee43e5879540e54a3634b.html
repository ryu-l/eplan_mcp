Dialog Select unplaced PLC connection points to place them blockwise

Dialog call:

You have opened a project. You have selected one or more PLC boxes and/or PLC connection points in the graphical editor, PLC navigator or device navigator. Or you have selected one or more pages or a project in the page navigator.

  • Project data > PLC > Use connection points blockwise.
  • You have opened the Use existing PLC connection points blockwise dialog. Click [...] on the toolbar.

In this dialog, you select unplaced PLC connection points for re-use. PLC boxes can also be selected for reuse.

Overview of the main dialog elements:

The PLC boxes and connection points in the project are displayed in the tree view and the list view. Here you select the PLC boxes and unplaced PLC connection points that you wish to reuse; multiple connection points can be selected. When you close the dialog, the selected PLC boxes and connection points are transferred to the Use existing PLC connection points blockwise dialog.

Filter:

This drop-down list displays all the available filters. A selected filter is automatically activated and is applied to both the tree and the list view. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the Filter dialog. Here you can create, edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

  • Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
  • Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

Value: <Property>:

Use this field, via Quick input, to adjust quickly the value of a filter criterion for a defined and activated filter.

Popup menu:

Menu item

Meaning

Configure representation

Opens the Configure representation dialog, where you define which properties are to be displayed in the list and tree view.

View (tree only)

Switches the display in the tree view:

  • DT-oriented: The PLC data is structured by their device tags according to the project structure.
  • Address-oriented: The PLC data is structured by addresses within the project structure.
  • Channel-oriented: The PLC data is structured by channels within the project structure. PLC connection points that do not have a channel designation are ordered by DT.
  • Rack-oriented: The PLC data is displayed in accordance with the assignment of the PLC cards to the racks. The functions contained by the PLC cards are displayed below these.

Dialog Settings: Directories

Dialog call:
  • Options > Settings > User > Management > Directories.
  • Utilities > Master data > Synchronize system master data. Click [...] in the Directories field.
  • Utilities > Master data > Synchronize current project. Click [...] in the Directories field.

The default settings for the directories used for master data selection and editing, and the paths to the required databases and files are defined or revised in this dialog. This information is used by certain program elements and functions when particular data is required. The settings are user dependent in order for you to manage and organize your own pool of master data.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent toolbar for this purpose.

Specify the drive and directory in which EPLAN is to manage your projects, templates, symbols, etc. in the input fields Projects, Templates, Symbols, etc. Click [...] to interactively select the desired storage location in the subsequent dialog. The default setting after installing EPLAN is <Drive_EPLAN>:\<Program directory>\Projects\<Company code>.

Notes:

  • For all input fields where you can define a directory, the following applies:
    You can use the Insert path variable popup menu item to branch to the dialog Select path variable where you can select one of the available path variables.
    Please note that less path variables are offered at this point because, after all, you define the values of the path variables MD_PROJECTS, MD_MACROS, etc. in the Settings: Directories dialog!
  • In all file selection dialogs where you select this type of data (for example in the Select macro dialog) you can specify the default directories defined here by using the Go to default popup menu item in the Path field.

Dialog Settings: 2D (User, Graphical Editing)

Dialog call:

Options > Settings > User > Graphical editing > 2D

In this dialog you can specify your personal settings for working with the graphical editor, like color settings, cursor form, or the display of invisible elements.

Overview of the main dialog elements:

Group box Color settings

Scheme:

Here, select the color scheme for the graphical editor. The names of the color schemes indicate the color of the screen background: You can select a white, black or gray background. The colors of the individual elements are adapted for each background.

Graphical symbol... Track potential:

You specify the colors for the representation of the following elements in the fields Graphical symbol to Track potential:

  • Symbols to which a function with the representation type Graphic, External or Pair cross-reference is assigned
  • Elements to which the Invisible property is assigned
  • Highlighting of connections that have the same potential, signal or net.

Use [...] to open the dialog Color selection at all the color settings. Select the desired color there.

Group box Cursor

Display:

From the drop-down list, select whether the cursor should be displayed as crosshairs or as a small cross.

Display crosshairs when placing symbols and macros:

If this check box is selected, the cursor will always take the form of crosshairs when you are placing symbols or macros, regardless of any other cursor representation.

Scroll behavior:

Here, specify how the mouse wheel should act during scrolling:

  • As for word processing: Scrolling moves the screen content up / down. [Ctrl] + scrolling enlarges / shrinks the image section.
  • As in CAD: Scrolling enlarges / shrinks the image section. [Ctrl] + scrolling moves the screen content up / down.

Minimum font size:

Independently of the currently defined font size, you can define a minimum font size for text to be displayed on the screen. However, this setting has no effect on the printed image.

If this check box is activated, all texts whose actual font size is smaller than the minimum font size determined in the adjacent field are displayed with the minimum font size.

If the check box is deactivated, the texts are displayed in the actually set font size.

Show invisible elements:

If this check box is selected, elements marked as "Invisible" are shown on the project pages. Invisible elements are displayed in a different color.

Print / Export invisible elements:

If this check box is selected, elements marked as "invisible" are printed and exported (e.g. to PDF and DXF).

If the check box is deselected, only visible elements will be printed / exported.

Show tooltip:

If this check box is selected, a short information text is displayed in the graphical editor (2D and 3D) when you move the cursor over a component.

Show property names:

If this check box is activated, then all property names are displayed for all placed properties in all projects and the assigned values are hidden.

If the check box is deactivated, the values of placed properties are displayed. This is the default setting.

Default grid sizes:

In the Grid size A through Grid size E fields, you have the option of specifying five different grid sizes. Choose the grid size in the graphical editor via the associated buttons to on the "View" toolbar.

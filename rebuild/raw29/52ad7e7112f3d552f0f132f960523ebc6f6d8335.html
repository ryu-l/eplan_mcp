Dialog Search results - <Project name>

Dialog call:

You have opened a project. Find > Show results.

The results of a search are shown in this dialog.

Overview of the main dialog elements:

The title bar of the dialog shows the project to which the search results belong.

Tabs List of results / Go to

In the tabs in the lower section of the dialog you can switch between the List of results and the Go to list.

The Go to list is filled using the Go to (cross-referenced) and Go to (all representation types) menu commands.

Popup menu:

Menu item

Meaning

Select all

Selects all of the list entries.

Adjust column width

Adjusts the width of all table columns so that both the headings and column contents are fully legible.

Font size 100%

This menu item is only available if the font size has been changed in the table (via [Ctrl] + scrolling with the mouse wheel). Re-displays the text in the table in its original font size.

Delete

Deletes the selected item(s) from the current list.

Delete all entries

Deletes all entries from the current list.

Find

Opens the Find dialog. You can enter a new search criteria and start a new search.

Replace

Opens the Replace dialog. You can replace existing values that were found with other values.

Go to (cross-referenced)

Enters cross-referenced functions into the Go to list and opens it.

Go to (all representation types)

Enters all of the representation types of a function (e.g., on a schematic page, an overview page, and / or a report page) into the Go to list and opens it.

Go to (graphic)

Jumps to the first selected entry. For placed objects you will jump to the graphical editor. For unplaced objects you will remain where you are. When jumping to connections you will jump to the first graphical connection definition point. If there is no connection definition point you will jump to the source function.

Edit in table

Opens tabular editing with the option of editing the properties of the pages and the devices on them.

Properties

Opens the Properties dialog for the selected list elements.

Properties (global)

Opens the respective "Global editing" dialog for the selected list elements. If the selected object is (e.g.) a function, then the Properties (global) dialog is opened. Allows the editing of the device properties.

Change of Standard

It is often required that a project be created and adjusted to a specific country for the international market. EPLAN offers you the option here of adjusting a project to the specifications of a different standard:

  • If you create a new project from an existing project and then adjust the new one to the specifications of a different standard, the original project remains unchanged.
  • You can adjust the project pages to a different plot frame. The project pages can thus be displayed in portrait and landscape format.
  • You can exchange the symbol libraries.
  • If you do not want to manage more than one symbol library, you can also exchange individual symbols.
  • You can exchange forms for reports.
  • You can adjust designations and names to the target standard by selecting a different template.
  • It is also possible to change the project structure by using a different template.
  • You can hide connection point designations.

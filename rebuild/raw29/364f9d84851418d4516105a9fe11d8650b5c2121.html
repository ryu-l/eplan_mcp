Locked Data in Multi-user Operation

If any property for an object has been changed, all of the properties are locked. In this case, "Lock" always means a change lock, but other users are still allowed to read the properties. After completing the work, the object is released again.

Editing pages and layout spaces

Only if a page or a layout space or an object on a page or in a layout space is being edited, is the page or layout space itself and all of the functions that are placed on that page, locked for a second user.

If a user is the second person in multi-user operation to open a page or a layout space that has already been opened, nothing happens. If a user is editing the page properties for a page or a layout space, for example, a second user can also open the page or layout space. Only if the second user tries to edit the properties of a device, for example, or the page or layout space properties does EPLAN open the Multi-user conflict dialog.

Editing functions in the navigators

If you change a function in a navigator, it will be locked during editing. If the function is placed, the page with all of the objects will also be locked. The higher-ranking and subordinate nodes for the function in the tree view are not locked, unless the corresponding functions are placed on the same page as the changed function.

Example:

In this way, a user can change the name of terminal strip definition X1 on page 8 to X5 in the device navigator, while another user edits a single terminal in this terminal strip that is on page 6. In this case, however, only the terminal strip definition and not all of the terminal strip functions can be renamed!

If, on the other hand, the entire terminal strip is to be renamed, the cursor must be positioned on the tree node that displays device X1. Then, in the Popup menu the user selects Rename and enters the new DT X5. During this procedure all of the functions with this DT are locked for other users.

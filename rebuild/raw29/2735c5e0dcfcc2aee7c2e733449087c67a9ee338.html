Adding Structure Boxes

Everything inside a structure box is allocated to a different identifier structure than that which is defined in the page properties. The components then have the same relationship to the structure box as they normally have to the page. This assumption of the DT also occurs if only identifier blocks like higher-level function and mounting location are entered in a component in the structure box.

Precondition:

You have opened a project and are viewing a schematic in the graphical editor.

  1. Insert > Box / connection point / mounting panel > Structure box
  2. Draw the rectangle representing the box.
  3. Enter the device data in the structure box-specific properties dialog.
  4. In the Identifier tab, click [...] in the Full DT field.
  5. Accept the default for the DT or make new entries for the identifier blocks if you would like to modify the structure.

    Note:

    If you enter new structure identifiers in the Full DT dialog, they are inserted according to the user settings for identifiers (option Enter new identifiers in alphabetical order or Add new identifiers to the end) in the table of identifiers. If necessary, you can also set another sorting of new structure identifiers in structure identifier management later on.

  6. Click [OK].

    The structure box is inserted into the project with all its properties.

Note:

If grid-snap is activated (Options > Snap to grid) a newly created structure box is exactly on the grid on which it is placed. If grid-snap is not active, the black box can be drawn at any desired position next to the grid.

Tips:

  • Structure boxes can also be drawn as polylines with the help of the SC2 symbol. To do so, select the symbol in the Symbol selection dialog and specify the starting point of the box by clicking the left mouse button inside the schematic. After you have specified all of the other points, complete the task via the Complete polyline popup menu item.
  • In the project settings you can determine that the upper left-hand corner of structure boxes can be spared and the device tag be placed there. To do this activate the Draw structure box with recess check box (under Options > Settings > Projects > "Project name" > Graphical editing > General).

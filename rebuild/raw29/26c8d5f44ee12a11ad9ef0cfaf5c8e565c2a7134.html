Dialog Field assignment (Pre-planning)

Dialog call:

You have opened a project, and have the pre-planning navigator open. Project data > Pre-planning > Import. In the Import pre-planning data - <Project name> dialog, select "Excel" or "Text" in the Type of data source field, and then click the [...] in the Field assignment field.

Use this dialog to create and edit the schemes that define the assignment of external data fields to the EPLAN properties.

The following dialog elements are available:

Scheme:

Select the scheme that you wish to edit from the drop-down list. You can only edit user-defined schemes.

You can create new schemes, save any changes to a scheme, and copy or delete schemes via the adjacent Toolbar. Schemes can also be imported or exported.

Description:

This field displays the descriptive text that you entered into the Description field in the New scheme dialog when you created the scheme.

Table

The following columns are displayed in the table:

Status:

A green icon indicates that this data field exists in the data source and could be identified. A yellow icon signals that the corresponding data fields do not exist. These rows are not considered during the import, and you can select and delete them as needed.

External field:

This column displays the data fields / properties of the selected table from an external data source.

Level:

The hierarchy level is displayed in the tree view here. Level "0" means that this row will not be imported.

Segment definition:

Here, you specify the type of segment to be generated from the record, e.g., a planning object or a structure segment.

Property:

This column displays the assigned EPLAN property. To assign a property, click in the column and then [...], and select a property from the dialog that opens.

Identifying:

Select this check box if the property is an identifying one for the assignment. Based on the properties marked as identifying, objects are identified and synchronized during the import. At least one external field must be identifying for every object type!

Filter:

Here you define a filter for the property. If you only enter one value, it is filtered for equality. However, you can also enter "> 100", for example.

Toolbar:

The following buttons are available on the toolbar above the table:

Button

Meaning

(New)

Creates a new line in the table. The new line is appended to the end of the table.

(Delete)

Deletes the selected row, with all of the contents. Multiple selection is possible.

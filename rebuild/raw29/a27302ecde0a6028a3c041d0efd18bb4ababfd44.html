Tab Item (Copper Export NC)

Dialog call:
  • Options > Settings > Company > Machining > Copper export NC. Select the Item tab.
  • Utilities > Manufacturing data > Machining > Copper NC. Click [...] next to the Machine field. Select the Item tab.

This tab contains information for the further processing NC machine.

Overview of the main dialog elements:

Material:

Information for the machine on the material to be machined. Here, you can enter any short text; the field can also be left empty. The default value is "Cu".

Generate item name for export:

This setting determines the composition of the unique name of the copper item. Under this name, the machining steps for the copper item are saved on the NC machine, and can be reproduced any number of times.

The following procedures are available:

  • From consecutive number: If you select this option, EPLAN assigns names to the XML files using the pattern Consecutive number.XML by default. If XML files already exist, EPLAN starts the numbering with the next available number.
  • From item designation: If you select this option, EPLAN assigns names to the XML files using the pattern <Item designation>.XML by default.
  • From properties: If you select this option, the file name is made up of the layout space, project, and device properties plus any freely-definable separators. Use the [..] button to open the Format: Property dialog to configure the file name.

Tool list:

The tool list is a file in the XML format. It contains information about which stamping tools are available on the machine and which tools are used to carry out the respective machining steps (punched holes with different diameters and different forms). The tool list is supplied by the machine manufacturer and adapted to the machine by the editor.

All machining for which the tool list does not contain any suitable tool is not exported.

Adoption of Connection Point Designations

Connection point designations can be assigned to a component in different ways:

  • By default, the connection point designations are adopted from the function definition. The function definitions contain a list of possible connection point designations; here, the first entry serves as the preset value. At the component, you can either select an entry from this list, or you can manually overwrite the connection point designations. Separators between the connection points can be typed using [Ctrl] + [Enter].
  • If you have defined devices and given them connection point designations, these connection point designations are assigned when the function is placed.
  • During device selection (or part selection), the connection point designations entered in the schematic are overwritten. If the Connection point designation check box is checked in the settings for device selection, connection point designations entered in the schematic are retained.
  • The connection point designation can â just as during DT adoption â be adopted from a function lying in the search direction. Prerequisite for this is that you have activated the Adopt connection point designation check box in the project settings (Options > Settings > Projects > "Project name" > Management > Compatibility).

Adoption from search direction

You not only can enter connection point designations in a function, but also all the connection point designations of the "subsequent components" which adopt the DT from this function and lie to the right (or below) this function in the schematic. You can enter the connection point designations for an entire series of components into a single component in this way. The possible connection point designations can be selected from a list in the subsequent components. The possible combinations of connection point designations are derived from the connection point designations entered during symbol creation.

Only if more connection point designations are entered than needed by the current component are the following components influenced.

In the properties dialog in the Connection point designation field, the current connection point designations are always listed as the first entries, after which the possible connection point designations of the following components are listed. For all empty connection point designations, there is a separator displayed so that you can see how many connection point designations are expected.

For the following functions, connection point designation adoption is not available:

  • Cables
  • Cable connections
  • Black boxes
  • Terminals
  • Pins.

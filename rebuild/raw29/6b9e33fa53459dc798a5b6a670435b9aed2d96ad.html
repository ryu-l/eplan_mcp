Regenerating Headings on Form Pages

You use the form property Generate data headers for the first x sorting properties (ID 13060) to create references to the sorting of the respective reports. This means that the form defines whether the sorting properties should be used for generating new headings.

The following values are possible for this property:

  1. "0": No new headings are generated.
  2. "1": The first sorting property is used for the new heading.
  3. "2": The first and second sorting properties are used for the new heading.
  4. "3": The first, second, and third sorting properties are used for the new heading.
  5. etc.

Preconditions:

  • You have opened a project.
  • You have opened the form whose properties you would like to edit in the form editor (Utilities > Master data > Form > Open > [Open]).
  • You have opened the Form properties - <Form name> dialog (Popup menu > Properties in the form in the navigator dialog Pages - <Project name>).
  1. In the Form properties - <Form name> dialog, click (New) above the Property name / Value list.
  2. In the Property selection dialog, select the Generate headings for the first x sorting properties property.
  3. Click [OK].

    The property is loaded into the list.
  4. Enter the number of sorting properties to be taken into account into the Value column.
  5. Edit other form properties as required.
  6. Click [OK].

    The defined properties are adopted for the form and the Form properties- <Form name> dialog closes.

Example:

In the Sorting dialog, you have selected the "Higher-level function + Mounting location + DT" scheme for outputting the device list. In the form for the device list, the Generate headings for the first x sorting properties has been given the value "1".

If you now generate the report pages for the device list, then a new heading is generated for every higher-level function, containing (e.g.) the higher-level function name. The data between the headings is still sorted by mounting location and DT.

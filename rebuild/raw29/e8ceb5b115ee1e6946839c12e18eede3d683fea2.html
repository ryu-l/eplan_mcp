Multi-user Operation

Multi-user operation means that projects can be edited simultaneously by multiple users from different workstations. All users working on one project have simultaneous access to project data. Work processes can thus be divided among multiple users.

You have the following options in multi-user operation in EPLAN:

  • Multiple users can work simultaneously on a project.
  • In project management you can display which other users are currently working with the selected project.
  • If multiple users would like to edit the same project data, EPLAN will inform you of this conflict.
  • If a conflict occurs you can inform the other users working on the same data via e-mail.

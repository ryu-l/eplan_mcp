Zipping and Unzipping a Project

Projects can be zipped either in the page navigator or in the project management. You can open a zipped project in the same way as any other project.

Zip projects in the page navigator

Precondition:

You have opened a project.

  1. Select the desired project in the page navigator.
  2. Select the menu item Project > Zip.
  3. Confirm your entries.

    The zipped project is stored in the project directory with the file name extension *.elp and closed in EPLAN.

Zip projects from the project management

Preconditions:

  • You have set up the project management.
  • In the tree structure of project management there is an imported directory with at least one project.
  1. Select the following menu items: Project > Management
  2. Select the desired projects from the tree structure in the Project management dialog.
  3. Select the Zip popup menu item.
  4. Confirm your entries.

    The zipped projects are stored in the project directory with an *.elp extension. Projects that were open during the packing process are closed.

Open a zipped project
  1. Select the following menu items: Project > Open
  2. Select the entry "Zipped EPLAN project (*.elp)" in the File type field of the Open project dialog.
  3. Switch to the directory where the project is stored and select the desired project.
  4. Click [Open].

    The project is unzipped and a progress bar is displayed with the option of canceling the process. If you have opened the page navigator, then the project is displayed there.

Tip:

You can also open a zipped project by double-clicking on a project with the *.elp file name extension. The project is automatically unzipped and opened.

Unzip projects

Precondition:

Zipped projects exist.

  1. Select the menu items Project > UnZip.

    The file type "Zipped EPLAN project (*.elp)" is preset in the Open project dialog so that the zipped projects are offered directly.
  2. Select the desired project in the Open project dialog. If appropriate, change to a different directory.
  3. Click [Open].

    The project is unzipped, but not opened.

Tip:

In the project management you can unzip a selected zipped project by using [Organize] > UnZip.

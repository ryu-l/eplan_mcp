Transferring Device Data from the Updated Parts into the Project

Parts and other master data are continuously updated and are, for example, made available via the EPLAN Data Portal. When in the past the data of the parts stored in the project changed in the parts management, these data were not transfered to the main functions during a parts data synchronization. We have now changed the behavior during the parts synchronization (and similar functionalities) so that the newest information is also transfered to the project. If the parts in the project are older than in the parts database, now not only the newer parts are stored in the project but also the newer device data is transfered to the main functions that these parts use.

Benefit:

The changed parts synchronization now allows you to transfer the device data from the updated parts to the main functions in the project.

This change of behavior affects the following functions:

  • Synchronize current project
  • Update current project
  • Complete current project
  • Synchronize stored parts when opening a project
  • Parts data synchronization after changing a project

During the update or completion of the project, the device data is updated for all parts used. During the parts synchronization only the device data of the selected part. In the process the respective part numbers and part reference data remain unchanged.

In the list for undoing, two editing steps are noted for these functionalities: "Parts data synchronization" and "Update device data". This way you can undo the modifications for the schematic again, if necessary.

Part and device selection of updated parts

Also during the part and device selection of a part that has an older state in the project than in the parts database, an update of the device data takes place at the affected main function. Since the device data is possibly not transfered to all usages of the part in the project (for example, for changed template data), a question is displayed in such cases. You can then decide whether you want to select this updated part or rather another part.

The new popup menu item Update device data is available to you in the bill of materials navigator in order to allow for updating of the device data at the functions in the project in such a case nevertheless.

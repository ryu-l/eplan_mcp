Distributing Elements Evenly

Using the Space evenly command, you can position multiple selected elements equal distances from one another in the horizontal or vertical direction. This only works for elements with insertion points (texts, symbols, placed functions, etc.). Simple graphical elements such as rectangles and lines are not taken into account as expected.

Precondition:

You have opened a page, form, plot frame or symbol.

  1. Select the respective elements and choose the Edit > Other > Space evenly (horizontal) or Edit > Other > Space evenly (vertical) menu items.

    EPLAN determines the distance between the first and last element and distributes all others evenly in between.

Note:

The grid is not taken into account when distributing elements; if necessary, use the Align on grid command to place the elements back onto the grid.

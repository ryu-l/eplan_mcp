Generating Pages with Views Using "Generate project reports"

When a project is reported via the menu items Utilities > Reports > Generate project reports, pages with views are now also generated (model view, 2D drilling view and / or copper unfold), if the respective report templates with page macros are available in the dialogs for the management of the views. All views that have already been generated are also updated.

Benefit:

Because the "Generate project reports" takes into consideration the templates for the views, you can generate the pages with the views more quickly. The separate reporting of the different views via different menu items is obsolete.

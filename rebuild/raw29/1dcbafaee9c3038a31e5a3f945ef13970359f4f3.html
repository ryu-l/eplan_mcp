Displaying or Hiding Revision Markers

The revision markers can be displayed or hidden as needed. This is irrespective of whether they were generated through change tracking or by a property comparison of projects.

  • After a property comparison, the revision markers are automatically displayed in the project.
  • The revision markers are activated automatically during the generation of the first revision of a project. If you subsequently deactivate the display of the revision markers by using the menu items View > Revision markers, this setting is retained during the generation of further revisions.

Precondition:

You have generated revision markers in the project.

  1. Select the menu item View > Revision markers.

    The revision markers are displayed in the project.
  2. Select the menu item View > Revision markers again.

    The revision markers are hidden.
  3. If necessary, update the display using the menu item View > Redraw.

Note:

If the View > Invisible elements option is activated, deletion markers remain visible when hiding the revision markers. This is because the deletion markers - contrary to "normal" revision markers - are hidden by setting their level to "invisible".

Find revision modifications in properties

Modified objects (even the objects to where their hidden properties have been changed) are shown on the page with a graphical marker.

If you move the mouse pointer over a changed object in a revision, then a tooltip is displayed containing information about the revision.

To find changes in the properties of objects, you can carry out a search:

  1. Select the following menu items: Find > Find
  2. In the Find dialog in the Find what field, enter the text that you provided for the identification of revision changes in the Compare properties of projects dialog.
  3. In the Search in group box, select the All properties of all components check box.
  4. In the Search location group box, determine whether the entire project or only the current page should be searched, and then select the Logic pages check box.
  5. Click [OK].

    The result of the search is shown in the dialog Search results.

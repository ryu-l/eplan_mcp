Drilling Patterns from Machine Data

In order to support the automation of manufacturing, machine manufacturers usually supply extensive libraries with item, part, drilling, cutting and milling information. This information allows the user, supported by the machine software, to create an enclosure layout and manufacture it correspondingly . As a rule, these libraries are extended over the years.

The information from these libraries can be used in EPLAN Pro Panel to supplement the EPLAN master data and to simplify the creation of master data overall.

In its current version EPLAN Pro Panel offers functionalities with which the drilling information which was previously exported from the machine software is imported into EPLAN and master data created from the imported data.

The following is possible:

  • Drilling patterns are generated from Rittal - Perforex / Secarex item files.
  • User-defined outlines that can be used to create drilling patterns in the parts management are created from Rittal - Perforex / Secarex outline files.
  • Graphical elements from DXF/DWG files (for example exported from Steinhauer eCAB or a CAD system) are combined into drilling patterns using the drilling pattern frames.
  • The drilling pattern originating from importing and graphical definition can be assigned to existing parts and thus be used for further engineering and machine manufacturing.
  • In addition, a purely graphical definition of drilling patterns by drawing items, drill holes and outlines is also possible.

P004089: PLC card name '<x>' assigned several times within a rack

Cause

At least two PLC boxes that are PLC cards of the same rack within a configuration project have the same PLC card name.

This check run only checks PLC boxes at which a configuration project is entered.

Solution

  1. Locate the PLC boxes in the schematic using the Go to (graphic) and Go to 2nd coordinate functionalities from the popup menu of the Message management dialog.
  2. Open the property dialog of each PLC box of the rack.
  3. Bring the first tab to the front.
  4. Modify the value of the PLC card name property in the property table. In the process ensure that each PLC box has a unique PLC card name.
  5. Click [OK].
  6. Then start a new check run.

Tip:

The Edit in table function can also be used for comfortable searching for errors in the project. Simply create a scheme that displays the PLC card name and the required PLC structure data in a clearly structured form.

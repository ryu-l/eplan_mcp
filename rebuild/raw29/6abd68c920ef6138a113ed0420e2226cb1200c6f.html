Nesting of mechatronic components

Generally, there are recurring configurations in a project. To minimize configuration efforts, closed units can be formed that contain recurring components. For example, the Axis of the tutorial includes the components Cylinder, Valve, and Position_1 to Position_4. Mechatronic components can be nested for this purpose.

Automatic Actions for Command Line Operation

When calling EPLAN from the command line, you have the option of using some automatic actions. Using these standard actions, you can execute complete program functions without needing to interact as a user.

The following automatic actions are available in EPLAN:

Action name

Description

backup

Backs a project or master data up.

changelayer

Changes the graphical properties of layers.

check

Checks pages or the entire project.

compress

Compresses a project.

CopyToolBarAction

Copies the buttons of one toolbar to another.

devicelist

Imports, exports, or deletes a device list.

edit

Opens a page or a project.

EplApiModuleAction

Loads and registers an API module.

EsCorrectConnections

Combines identical connection definition points.

ExecuteScript

Runs a script.

export

Exports pages or projects in different formats.

export3D

Exports layout spaces into the STEP format.

exportNCData

Exports NC data for the machine formats of Steinhauer, Rittal - Perforex / Secarex, DXF and the drilling template.

exportProductionWiring

Exports wire fabrication data into different formats.

exportToGraphics

Exports pages or projects in graphic format (TIF, GIF, PNG, JPG).

generate

Generates connections or cables.

GraphicalLayerTable

Imports / exports layers.

import

Imports projects, macros, or drawings.

label

Generates the export of the manufacturing data / the labeling for a project.

MfExportToolbarAction

Exports one or more user-defined toolbars.

MfImportToolbarAction

Imports a toolbar from a file.

MfRemoveToolbarAction

Deletes a user-defined toolbar.

OpenWorkspaceAction

Opens an existing workspace.

partslist

Imports or exports a bill of materials.

plcservice

Imports or exports PLC data by means of the specified configuration program.

print

Prints a page or the whole project.

ProjectAction

Runs an action for a project and closes the project after this.

projectmanagement

Loads a file with project information into the project management.

ProjectOpen

Opens a project.

RegisterScript

Registers a script.

Renumber

Carries out renumbering.

reports

Generates project reports.

restore

Restores a project or master data from backup.

SaveWorkspaceAction

Saves the current user interface settings as workspace.

search

Searches for objects (devices, properties, texts, etc.) in a project.

selectionset

Retrieves values (name, path, file extension) from selected pages or a selected project.

SetProjectLanguage

Determines display languages for editable and read-only projects.

synchronize

Synchronizes project data.

translate

Translates a project, deletes the translation from the project, or exports a missing word list.

UnregisterScript

Unregisters a script.

XEsUserPropertiesExportAction

Exports user-defined properties into a file.

XEsUserPropertiesImportAction

Imports user-defined properties from a file.

XDLInsertDeviceAction

Inserts a device.

XGedUpdateMacroAction

Updates macros.

XMActionDCImport

Imports a data configuration file of external editing into an existing EPLAN project.

XMDeleteReprTypeAction

Removes from selected macros a representation type and saves these macros in a directory.

XMExportConnectionsAction

Exports the connection properties of a project for external editing.

XMExportFunctionAction

Exports the function properties of a project for external editing.

XMExportPagesAction

Exports the page properties of a project for external editing.

XSDPreviewAction

Opens or closes a page or macro preview window.

XSettingsImport

Imports user, workstation and company settings.

If the parameter for the project name (/PROJECTNAME) is not given for an automatic action, the last project opened will be used.

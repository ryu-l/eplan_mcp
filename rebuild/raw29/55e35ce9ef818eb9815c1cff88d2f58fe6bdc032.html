Adding body and chapter to mechatronic components

In the first step, you need to link the text components for the body and chapter of the ListOfComponents with the mechatronic components:

  1. Double-click to open the component Feeder in the T_Mechatronic_ModularSystem library in the Stations unit and move the text component Sensors_Actuators_Body from Library Catalog view to the Components editor section.
  2. Move Sensors_Actuators_Chapter twice from Library Catalog view to Components editor panel.
  3. Rename Sensors_Actuators_Chapter as Actuators_Chapter (switch to editor mode by clicking again on the selected component or by pressing [F2]).
  4. Rename Sensors_Actuators_Chapter2 as Sensors_Chapter.

  1. Once again, select Actuators_Chapter. The accompanying parameter table will now appear.
  2. Enter the value Actuators in the table in the parameter line Heading.
  3. Repeat the final two steps for Sensors_Chapter and the heading parameter value Sensors.

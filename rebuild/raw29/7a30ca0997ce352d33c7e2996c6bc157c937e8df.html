Defining a User-defined Project Structure

As well as the pre-defined identifier schemes for the project structure, you can also create user-defined schemes and use them to define your own project structures. In addition to the "functional assignment", "higher-level function", "installation site", "higher-level function number" and "document type", the user-defined identifier structure also encompasses a user-defined identifier block for which you can freely define the preceding sign.

You can subsequently change a user-defined project structure, which consists of a user-defined page structure and a user-defined device structure, through the project properties dialog. The page structure can however only be changed later under specific conditions at a project with pages. The definition of all structures follows the same procedure.

Precondition:

You have created a project and selected it in the page navigator.

  1. Select the Project > Properties menu items and bring the Structure tab to the foreground.
  2. Click [...] next to the page structure field or next to one of the device fields.
  3. Use the drop-down lists to assign one of the three possible properties "Identifying", "Describing" or "Not available" to each identifier block in the dialog Page structure / dialog Device structure.
  4. If you want to change the identification order in the page structure, mark the identifier block in the Structure column of the dialog Page structure and move it to the desired position by using the arrow buttons.
  5. Click [OK].

Note:

Prefixes and separators for identifier blocks can only be selected or entered by the user when the respective identifier block was specified with the "Identifying" or "Describing" property when the new identifier scheme was created.

Proceed as follows:

Precondition:

You have created a new scheme for the page or device structure.

  1. Click [Other] in the Structure tab of the Project properties dialog.
  2. In the Extended project structures dialog, select a preceding sign for the functional assignment, higher-level function number, document type, and user-defined identifier blocks, or enter a preceding sign of your own choice where this is permitted.
  3. Proceed in the same manner for the separator for the sub-identifier.
  4. Click [OK].

Note:

The following preceding signs and separators may not be used for identifier blocks because they are already used for other purposes:

  • / Separator before page name
  • \ Directory structure
  • ? Placeholder for offline numbering
  • : Separator for connection point designation.

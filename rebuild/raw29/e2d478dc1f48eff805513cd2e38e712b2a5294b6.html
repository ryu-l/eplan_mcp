Dialog Use existing PLC addresses blockwise

Dialog call:

You have opened a project. You have selected several PLC connection points in the graphical editor, the PLC navigator, or in the device navigator. Or you have selected one or more pages or a project in the page navigator. Project data > PLC > Use existing addresses blockwise. In the Select dialog, select free or already used PLC addresses and click [OK].

In this dialog, you re-use the selected PLC connection point addresses that have not yet been used (in the overview or the schematic).

Overview of the main dialog elements:

To:

The selected, placed PLC connection points and the function templates are displayed in this table. The connection points are sorted in their graphical order in the schematic. It does not matter whether the connection points were selected in the graphical editor or in a navigator.

If addresses have been assigned to the function templates, then these become unplaced functions.

If placements of the same PLC connection point using different representation types (multi-line, single-line, etc.) are selected, then only one entry will appear in the table for this. If the addresses of these placements using different representation types are different, then the <<...>> character string is displayed in the table.

If PLC connection points occur multiple times in the project with the same representation type (with the same DT and connection point designation) then they are also listed multiple times in the table.

From:

The PLC addresses that you have selected for re-use are displayed in this table. The addresses are sorted by CPU and connection point designation. The table is empty when the dialog is first called up.

Toolbar:

Use the arrow keys to assign the existing project PLC connection points in the left-hand table to the PLC addresses that you selected for re-use. Only the entries in the right table change their order during this.

Button

Meaning

(Delete)

Deletes the contents of the selected lines. No lines are moved.

Opens the Select dialog for selecting PLC addresses. All free addresses are displayed here; multiple selection of addresses is possible. When you close the dialog, the selected PLC addresses are displayed in the right-hand table.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

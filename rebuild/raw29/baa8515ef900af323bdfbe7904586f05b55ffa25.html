Exporting Pages in DXF / DWG Format

When exporting individual project pages or an entire project in DXF / DWG format, a file is generated for every selected page. If you export a single page, then you can freely assign the file name. When exporting multiple pages, the file name cannot be freely chosen. The DXF / DWG files are created either as a consecutive number or from the page name or from configurable properties, depending on the settings of the selected scheme.

Precondition:

You have opened a project.

  1. In the page navigator, select the pages of a project (or the entire project) that you wish to export.
  2. Select the menu items Page > Export > DXF / DWG.
  3. In the Scheme field of the DXF / DWG export dialog, select an appropriate scheme from the drop-down list. Or click [...] to call up the dialog Settings: DXF / DWG export and import. You can view the settings here for the standard scheme, and also create and edit your own schemes. In the settings you also specify the file type (DXF or DWG) for the export.
  4. In the Export medium group box in the DXF / DWG export dialog select the medium for the export.
  5. When exporting a single page, enter the name of the file to be created into the File name field, or select it interactively using [...].
  6. Select the Apply to entire project check box if in the first step you selected individual pages of a project and would instead like to apply this selection to the entire project.
  7. Click [OK].

Display model view with black item edges

The new property Model view: Display item edges in black (ID 36526) is available in the property table in the View tab of the Model view dialog. If the check box of this property is activated, the visible edges of the items are not displayed in the color that is specified for the item in the layout space but consistently in black. This setting does not apply for the styles "Shading" and "Shading / Simplified representation" as well as for texts and dimensionings.

Editing Bill of Materials Parts

Preconditions:

  • You have opened a project.
  • You have opened the bill of materials navigator: Project data > Devices / Parts > Bill of materials navigator

Edit non-placed parts
  1. In the Bill of materials - <Project name> dialog, select the List tab.
  2. Select the Configure representation popup menu item.
  3. In the Configure representation dialog, activate the Placement check box and click [OK].

    The list view now has a new Placement column.
  4. Select Popup menu > Edit part for the non-placed part to be edited, i.e. for a part which has no entry in the Placement column. Multiple selection is possible.
  5. Click [...] in the Part number field of the Edit part dialog.
  6. In the Parts selection dialog, select a different part if necessary. Multiple selection is not possible. If several parts are marked, only the uppermost marked part is transferred.
  7. Click [OK].

    The part number is entered in the Part number field.
  8. Edit other properties as required.
  9. Click [OK].

    The parts data are transferred to the device.

Edit items with part placement

The term "Part Placement" describes a placed part on a panel layout page. One placement is possible per unit part. You can identify part placements from the "Panel layout" entry in the Representation type column of the list view in the bill of materials navigator.

  1. In the Bill of materials - <Project name> dialog, select the List tab.
  2. Select the Configure representation popup menu item.
  3. In the Configure representation dialog, activate the check boxes Placement and Representation type and click [OK].

    The list view now has new Placement and Representation type columns.
  4. Double-click the part to be edited that has already been placed and which has the "Panel layout" entry in the Representation type column.
    Or select the popup menu item Properties (in this case, multiple selection is possible.)
  5. Define the required settings for the Part placement, Display and Format tabs in the Properties <...>: Part placement dialog.
  6. Click [OK].

    The parts data are transferred to the device.

Edit project parts

Project parts are parts that are not assigned to any special device. In the list view of the bill of materials navigator you recognize a project part by the fact that it does not have an entry in the Device tag column or that it is identified as such in the Project part column.

  1. In the Bill of materials - <Project name> dialog, select the List tab.
  2. Select the Configure representation popup menu item.
  3. In the Configure representation dialog, activate the Project part check box and click [OK].

    The list view now has a new Project parts column.
  4. Double-click the project part that you wish to edit and assign it the appropriate data in the Edit part dialog.
  5. Click [OK].

Place parts
  1. In the Bill of materials - <Project name> dialog, select the List tab.
  2. Select the Configure representation popup menu item.
  3. In the Configure representation dialog, activate the Placement check box and click [OK].

    The list view now has a new Placement column.
  4. Select the popup menu item Place device for the non-placed part to be edited, i.e. for a part which has no entry in the Placement column. Multiple selection is not possible.
  5. Before actual placing press the [Backspace].

    The Insert device dialog opens.
  6. Select the Part macro option if at least one graphical macro and the values for width and height are defined in the parts data. In this case no further prompt is displayed and the part can be placed in the graphic as described in the next step.
    If you selected the Symbol selection option, select the symbol you would like to assign to the part from the Symbol selection dialog, then click [OK].
    If you selected the Individual functions option, select the function you would like to assign to the part from the Function definitions dialog, then click [OK].
    If you selected the Macro selection option, select the macro that you would like to assign to the part from the Select macro dialog, then click [OK].
  7. Place the part in the graphic.

Exchange parts

You can exchange parts by replacing existing parts in the bill of materials with others.

  1. Select the part to be replaced in the Bill of materials - <Project name> dialog.
  2. Select the Exchange part popup menu item.
  3. In the Parts selection dialog, select the parts to be exchanged. Multiple selection is not possible.
  4. Click [OK].

    The parts previously assigned to the device are replaced by the newly selected part. The quantity of the parts remains the same. Assemblies are not broken up.

Example:

Device with part reference -> Results after exchange
K1, 0815 replaced by 0915 -> K1, 0915
K1, 0815; K2, 0816 replaced by 0915 -> K1, 0915; K2, 0915

Delete parts
  1. Select the part to be deleted in the Bill of materials - <Project name> dialog.
  2. Select the Delete popup menu item.
  3. Answer the prompt.

    The selected part references are deleted according to how you answer the prompt. The corresponding part reference position in the device is empty after this action, and is unfilled.

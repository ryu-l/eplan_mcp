Tab General (Parts management)

Dialog call:

Utilities > Parts > Management. You have marked a part in the tree or list.

In this tab, you can enter general information which depends on the part type selected (component, cable, etc.). This data can be specified once per part.

The following dialog elements are available:

Generic product group / Product group / Product subgroup:

In these fields, you can select a group from preselected entries. Depending on the options selected under [Extras] > Settings for the tree configuration setting, the parts are sorted in the tree appropriately, once the product group has been changed.

Trade / subtrade:

In this field, click [...], so that in the subsequent dialog, you can define additional trades / subtrades, which should contain the part, by activating the respective check boxes.

Part number:

The part number identifies the part, that is, part numbers may only be used once per hierarchical level. In the case of part variants, the combination of part and variant number is the identifier. When saving the part or variant, this is automatically checked.
Part numbers may be up to 255 characters long.

When assigning part numbers, the organization of numbering should be chosen with great care.

Example:

Group_number.Manufacturer.Other_info.Serial_number, entry designation: KM22.KLM.0750.0001
Manufacturer.Group_no.Serial_number; entry designation: SIE.3TB.0001

Discontinued part:

Activate this check box if the part is to be characterized as "not used any more". With the configuration of list display in the parts and bill-of-materials navigators and with the field-based filter you can then have such parts displayed or filtered out.

ERP number:

Here you provide the part number of the external ERP system. Just like the part number, this number also has to be unique, and this is checked as well, when the part or variant is saved.
ERP numbers may be up to 50 characters long.

Type number:

In contrast to the part number, the type number, particularly for cables, is not unique. The entry here should correspond to data from the manufacturer catalog as much as possible.

Designation 1 / Designation 2 / Designation 3:

In these fields, additional specifications can be made for the part, for instance also corresponding to the data in the manufacturer's catalog. They are not subject to special processing, but they can be output in the bill of materials.

Manufacturer / Supplier:

In these fields, you can use [...] to select the corresponding short and long names. Direct entry of the short name is also possible, but the field for the long name cannot be edited.

If you enter a short name that does not yet exist into this field, then an appropriate empty customer / supplier record is automatically generated, which you must then fill with the desired data.

Order number:

Enter the order number of the part here, if possible, with the information of the data in the manufacturer's catalog.

Description:

This field can also be used for additional data about the part and could, for example, always be used for internal information.

P007004: Duplicate connection point designation: <x>

Cause

Possibility 1

You have inserted a device with distributed functions in the schematic or created the device in the device navigator. This means at least two function are using the same connection point designation.

Example:

You have inserted a contactor consisting of a contactor coil and two NO contacts into the schematic. The same connection point designation 13Â¶14 .was erroneously assigned to both NO contacts.

Possibility 2

You have placed a function in the schematic or created it in the device navigator and have assigned one or more identical connection point designations.

Example:

You have created a single-phase transformer with two windings in the device navigator. The connection point designation was accidentally changed from 1Â¶3Â¶2Â¶4 to 1Â¶3Â¶4Â¶4.

Solution

Regarding option 1

Starting from the Message management dialog use the menu items Go to (graphic) or Go to (cross-referenced) to locate the functions occurring distributed in the schematic or device navigator. For every found function call up the Properties <...> dialog and compare the values respectively entered in the Connection point designations field. Assign a unique connection point designation to every function.

In the case of bus ports the bus interface name is used for identification in addition to the plug designation.

Regarding option 2

Starting from the Message management dialog use the menu items Go to (graphic) or Go to (cross-referenced) to locate the functions in the schematic or device navigator. For the found function call up the Properties <...> dialog and note the entered values in the Connection point designations field. Assign a unique connection point designation to the function.

Then start a new check run.

Note:

In the case of bus ports the Plug designation and the Bus interface name are used for identification in addition to the connection point designation. A check is carried out whether this combination (Connection point designation + Plug designation + Bus interface name) is identical. If at least one of these partial designations shows a difference, the message is not output.

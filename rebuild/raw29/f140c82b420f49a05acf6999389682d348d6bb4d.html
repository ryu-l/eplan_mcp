Editing in Table

Using table editing, different objects on different project pages can be edited together in a single dialog. The following is possible:

  • The DT of the selected devices are shown in the convenient form of a table and can be edited in blocks, e.g. renamed or numbered.
  • Device tags can be subdivided into columns whose numbers and names you can determine yourself. In this way, for instance, structure fields can be edited in fluid power systems.
  • The properties of functions, connections, macros, interruption points, potentials, pipings and segments from the pre-planning are displayed in the form of a table and can be edited in a table. Separate tabs are only displayed for these different objects when the selection contains more than one object type.
  • The data of the objects can be copied into Excel with copy and paste, edited there, and then written back into EPLAN.

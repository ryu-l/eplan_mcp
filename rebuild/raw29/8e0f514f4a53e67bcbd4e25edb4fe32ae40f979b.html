Dialog Settings: User code / address

Dialog call:

Options > Settings > User > Display > User code / address

In this dialog you can enter user-specific data. Entering "user data" makes sense for multi-user licenses, for example, when multiple users from different workstations are simultaneously editing a project. If a multi-user conflict arises, for example when two users would like to edit the same data in EPLAN, EPLAN can access this data and send a message using the user information of the user, hindering the data editing process.

Overview of the main dialog elements:

Code / Name:

Enter user-specific data in these fields.

Logon name:

This field is automatically filled by EPLAN: If you are not using EPLAN rights management, the user name with which you logged onto the Windows operating system is entered. If on the other hand you are using rights management, the name with which you logged onto the rights management system is entered.
In either case the entry cannot be edited.

Phone / E-mail:

Enter your telephone number with prefix, and your e-mail address.

Customer number:

Enter your customer number here.

Use logon name for changes:

If this check box is selected, the Logon name is placed in automatically filled out properties such as "Creator" or "Last editor" for projects, pages, forms, plot frames, etc.

If the check box is not selected, the Logon name is not output, but rather the entries from the Code and Name fields are used. If the Code and Name fields are empty, a message is displayed and the check box is automatically activated, that is, the logon name is used.

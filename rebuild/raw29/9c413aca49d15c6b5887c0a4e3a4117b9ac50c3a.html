New Markers for Jump Targets in the PDF

In an exported PDF document the jump targets after the jump are now marked by a red, blinking frame. Possible jump targets are for example devices on the schematic pages, generated device pages etc. If the Archiving format PDF/A check box is activated in the settings for the PDF export, no red markers are generated. In addition further improvements for the PDF Export were implemented, such as changed default settings.

Benefit:

The new jump markers and modified default settings for the export make the orientations on the export pages easier for jumps in the PDF.

Changed default settings for the PDF export

In the course of this extension the default settings for the PDF export were also changed:

  • The user-specific setting Use zoom is now deactivated by default.
  • For the Zoom level setting the value was changed from "50.00 mm" / "1.9685 In" to "120.00 mm" / "4.7244 In".

(A possible menu path for the settings dialog is: Options > Settings > User > Interfaces > PDF export; General tab.)

Jumps between main and auxiliary functions of 2D mounting panels

Jumps between 2D mounting panels, that are placed as main and auxiliary functions on pages of the type "Panel layout", are now also possible in the PDF documents.

Display of property arrangements from the layout space in the 3D view

The property arrangements of the items in the layout space can now be recognized after the PDF export. The displayed properties of a 3D model in a PDF file are identical with the display in the layout space.

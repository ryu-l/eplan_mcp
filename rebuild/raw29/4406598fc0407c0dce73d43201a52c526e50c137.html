Tab Edit words / Select words

Dialog call (Edit words):

Utilities > Translation > Edit dictionary. Select the Edit words tab.

Dialog call (Select words):

You have opened the property dialog for a component, a text, a project page, etc. In a multilingual field select the popup menu item Multilingual input. Click the [Dictionary] button in the dialog Multilingual input.

In this tab you can add new keywords with translation texts to the dictionary as well as edit existing keywords and their translation texts. Dictionary keywords are case-sensitive.

Overview of the main dialog elements:

Full-text filter:

Enter the text to be found in this box, and click (Find). This way only entries that include the text searched for are displayed in the keyword list.
Click (Delete) to delete the search term and return to the full keywords display.

Note:

Do not use placeholder characters (such as "*", "?" or "_") for the full-text search as these will not be returned by the search. These restrictions are caused by the search mechanisms of the databases used. In addition no differentiation is made between upper- and lower-case letters and no AND / OR links are supported.

Source language:

Select one of the dictionary languages as the source language for the keyword that you would like to edit. The source language is the language in which the keyword is stored in the dictionary.

Find:

Use this field to search for all keywords already in the dictionary. When also using the full-text filter you can search for keywords within the filtered list.
To search for a keyword, enter it in the input field. To show all translation texts for a keyword, click on the desired keyword in the keyword list.

Keyword:

This field shows all of the translation texts for the selected keyword. One line is shown for each dictionary language. The keyword must have a translation text in the selected source language because the keyword is stored under this entry in the dictionary. You can enter a comment in the last line. A comment can be helpful if the keyword was stored twice but with different meanings. The comment is shown with the word suggestion in the Found words dialog.

Example:

The word Connector is stored twice in the en_US source language in the dictionary. It is translated differently in the fr_FR target language in each case.

fr_FR

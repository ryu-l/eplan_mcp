The Hose Line Configurator in Interaction with the Free Routing of Hose Lines in the Layout Space

Analog to hoses and piping parts hose lines or conduits can be routed freely as 3D objects in the layout space. For this case the hose line configurator offers support in the generation of the type code that contains the unique order information of a hose line.

The working principle is as follows:

  • You place a hose line in the Fluid schematic and assign the desired device tag in the properties.
  • You mark the hose line and start the hose line configurator.
  • In the editing dialog of the hose line configurator complete all the hose line information with the exception of the hose line length.
  • Confirm the configuration data and close the hose line configurator. The program transfers the type code with the missing length information to the hose line in the Fluid schematic. (The type code is saved in the table of the part properties in Row 4.)
  • In EPLAN Pro Panel select the menu items Project data > Connections > Free routing (layout space). In the process the hose line that was configured in the hose line configurator is routed automatically as a 3D object in the layout space between those fluid power items that were recognized as the source and as the target of the hose line. The hose line length determined through the routing process is entered automatically in the type code of the hose line in the Fluid schematic.
  • In order to ensure reliable functionality and proper installation subsequently adapt the routed hose line in its length and position to the 3D objects surrounding it by using the menu items Edit > Graphic > Change curve run. The hose line length that was changed in the layout space automatically results in an updating of the type code in the part properties of the hose line in the Fluid schematic. The hose line can now be ordered in its final length.

Notes:

  • In order to route hose lines in the layout space corresponding 3D graphical macros have to be stored in the parts management (Mounting data tab, Graphical macro field) for the fluid power parts and hose line fittings.
  • The standard scheme DIN 20066_2012-01 available in the hose line configurator provides preset configuration data that specifically reference the standard DIN 20066. If it is necessary to configure the hose lines differently than in this standard, the configuration data, such as the nominal diameter, fittings, hose groups and assignments, etc., have to be adapted to the respective normative requirements.

Assigning Segments / Objects

You can assign different segments and associated subordinate objects (function templates, PLC addresses) from the pre-planning navigator to the functions placed in the schematic. When assigning planning objects, function templates and PLC addresses, data can also be transferred to the components. Structure segments can only be assigned to structure boxes on the project pages.

It is also possible to assign segments to 3D part placements inserted in a layout space.

Through the assignment the functions or 3D part placements are linked with the segment from which they have been given the assignment.

Generally, protected functions cannot be the target of an assignment.

Assigning planning objects

The assigning is described here using the example of the planning objects. PCT loops, function templates and PLC addresses can be assigned as well in the same way.

Preconditions:

  • You have opened a project.
  • You have opened the pre-planning navigator.
  • You have opened a project page in the graphical editor.
  1. Select a planning object in the pre-planning navigator.
  2. Select the Assign popup menu item.

    The description of the selected planning object is hanging on the cursor.
  3. Move the cursor across the component to change the color of the component.
  4. Select the component.

    The data of the planning object are transferred to the component.

    The target functions are linked with the planning object from which they have been given the assignment.

There may be only one main function per planning object. If the target is a main function, the parts stored at the planning object will be carried over to the target function.

Notes:

  • When assigning Function templates, a multiple selection is possible. The data of the function template is transferred while assigning to the component, and the function of the component superimposes the function template.
  • The PLC address, symbolic address, function text, and data type are assigned to the PLC connection point during the assignment.

Tip:

If you want to edit the assigned segment from the pre-planning in the schematic for a function, select the popup menu item Properties (pre-planning) for the selected function. This way the property dialog of the associated segment is opened and you can directly edit the properties from the pre-planning without having to use the pre-planning navigator.

Assigning 3D part placements to segments

Preconditions:

  • You have opened a project.
  • You have opened the pre-planning navigator.
  • You have opened a layout space.
  • An enclosure or a mounting panel with 3D part placements has been placed.
  1. Select a segment in the pre-planning navigator.
  2. Select the Assign popup menu item.
  3. Move the cursor across the 3D part placement to change the color of the item.
  4. Click the 3D part placement.

    No data of the segment is transferred to the 3D part placements.

    The 3D part placements are linked with the segment from which they obtained the assignment.

Tip:

You can use this assigning, for example, in a macro project to link the items contained in a 3D macro with segments in the pre-planning. In the case of a corresponding assignment, the finished 3D macro contains complete part structures. If such a 3D macro is inserted in a schematic project, the part structures contained in the macro are sorted into the pre-planning structure of the project.

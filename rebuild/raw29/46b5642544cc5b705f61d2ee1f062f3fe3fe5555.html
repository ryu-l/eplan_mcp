Menu Items in the Main Menu of the Hose Line Configurator as a Separate Program (Stand-alone Variant)

The following menus are available in the main menu of the hose line configurator as a separate program (stand-alone variant):

Menu File

Menu item

Symbol

Meaning

New

Opens the New file dialog in as fas a you have opened the Configure hose lines dialog and at least one line with hose line data has been created. If you confirm the query whether you want to save the changes with [Yes], the Save as dialog is opened in which you can specify the name and the storage location where the hose line data are to be stored. The data are then stored in a tab-separated Unicode text file (*.txt) that can be exchanged with other applications (exchange file). If you answer [No] to the query in the New file dialog,the created hose line data are discarded.

Open

Opens the Open dialog for importing hose line data that were stored in an exchange file. In this dialog you specify the name and the location of the exchange file to be opened. Only tab-separated Unicode text files (*.txt) can be selected.

Save

Stores the edited hose line data in the exchange file specified by you beforehand by using the menu item Save as.

Save as

Opens the Save as dialog for the export of the hose line data into an exchange file that can be read in by a different application. In the dialog you specify the name and the storage location under which you wish to store the edited hose line data. The data are stored in a tab-separated Unicode text file (*.txt).

Configure hose lines

Opens the Configure hose lines dialog in which the read-in or edited hose line data are displayed.

Exit

Exits the program.

Menu Settings

Menu item

Symbol

Meaning

Options

Opens the Settings dialog.

Here you specify the properties and values for the configuration of the hose lines (categories User > Add-Ons > Hose line configurator) and save it as a scheme. Or you change the dialog language here (categories User > Display > Languages).

Menu Help

Menu item

Meaning

Contents

Calls up the help system with an opened Contents tab.

Customer-focused improvement program

Opens the Customer-focused improvement program dialog, where you can decide if you want to participate in this program.

About

Opens the About EPLAN dialog containing the following information:

  • Product
  • Licensed add-ons
  • Copyright / Trademark
  • System information

GRAPH2D

The system library Graph2D provides the definition of diagram configurations in project libraries.

The system library Graph2D must be imported into all project libraries, which are used to configure planning diagrams and or flow charts.

A new diagram definition is inserted with the action Diagram definition, which is found in the popup menu of a unit of the modular system library (New > Diagram definition).

The diagram definitions can also be edited with Notepad from Windows or any editors of third-party distributors, e.g. XML-Spy, Liquid XML-Studio, Oxygen XML-Editor, etc.

Programmers of diagram definitions which use third-party editors are provided with a XML-schema for validation. The schema file diagram.xsd is provided in the following folder:

<EEC-Installationsordner>\install\diagrams

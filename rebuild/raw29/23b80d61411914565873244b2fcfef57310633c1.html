Automatically Generated Cables

Cables can be generated / completed in an automatic run. In this case, the connections are first automatically updated. Automatic generation is in three steps: First, the cables are generated. Then, cable numbering and cable selection are performed for the newly generated cable in correspondence with the settings. This results in completely designated cables with parts. The cable numbering and the automatic cable selection can be called separately.

  • Cable generation
    EPLAN automatically places cable definition lines and connection definition points. Automatically generated cable definition lines are inserted on a separate layer in the schematic. Automatically generated cables and connection definition points are also marked (Automatically generated property). This makes it possible to restart the automatic run at any time (if necessary, with other settings).
  • Cable numbering
    For the numbering of cable DTs, additional special formatting options are available. This allows you to use (e.g.) the source and target data in the cable DT.
    At the connection definition point you can determine that the cable DT is manually set (via the Manually set property) and decide during numbering whether manual cable DTs are also to be renamed.
  • Automatic cable selection (device selection)
    When automatically selecting cables, EPLAN searches for the suitable cable in parts management. The voltage entered for the cable, the voltage of the cable connections (defined via the potentials), the number of connections present, and the number of spare cable connections are compared. In the settings for automatic cable selection, you can specify a preselection (e.g. a list) of cable types. Only the cables from this list will be used for automatic cable selection.

Note:

For a cable to be generated automatically, the Cable connection property has to be set to the "Cable" value for the connection. This can be set either in the properties dialog for the connection or through a connection definition point.

The connection point properties are also evaluated. In the connection point logic of a function, it is possible to assign the Cable connection point property to the connection points. If the graphically first connection point of a connection (according to the orientation of the plot frame) is a cable connection point, then a cable will be generated. It doesn't matter whether the second connection point is also a cable connection point or not. If, on the other hand, the first connection point is not a cable connection point, no cable will be generated.

Creating Basic Projects

Basic projects can be created via the project menu or the project management. You can use a basic project to create a project. If you create a basic project from an existing project, then the entire project is stored in the basic project.

Precondition:

You have selected a project.

Page navigator: Project > Organize > Create basic project.

Project management: [Extras] > Create basic project.

  1. Specify the storage location and the name for the basic project in the Create basic project dialog.

    EPLAN suggests the template directory that you specified in the user settings for master data in the Settings: Directories as the storage location.
  2. Click [Save].

    A *.zw9 basic project is created.

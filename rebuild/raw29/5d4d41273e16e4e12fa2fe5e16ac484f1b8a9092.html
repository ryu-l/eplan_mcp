Dialog Back up data

Dialog call:
  • You have opened a project. Utilities > Automated processing. Click [...] next to the Scheme field in the dialog Run: Automated processing. In the Settings: Automated processing dialog, in the Available actions field, select "Back up data" and click (Move to the right).
  • Project > Management. You have imported directories in the Project management dialog and selected at least one project. [Organize] > Automated processing. Click [...] next to the Scheme field in the dialog Run: Automated processing. Select the Scheme option and click [...] next to this field. In the Settings: Automated processing dialog, in the Available actions field, select "Back up data" and click (Move to the right).

In this dialog you define the settings for automated backup.

Overview of the main dialog elements:

Method:

This field defines the method that EPLAN uses for backing up data. For automated backups, the "Save additionally" method is available. Here, the data is compressed as a *.zw1 file and saved in the directory that you have selected in the Backup directory field. The source project remains unchanged.

Backup directory:

This field contains the directory to which the data is backed up. Use [...] to open the Browse for folder dialog. In this dialog you can choose another directory as the storage location. Any desired directory on any logical drive is a valid location.

You can use the Insert path variable popup menu item to branch to the dialog Select path variable where you can select one of the available path variables.

Options group box

Back up external documents:

If this check box is selected, all external documents in the $(EPLAN)\Projects\<...>\<Project name>\DOC directory are backed up with the project. $(EPLAN) is the main directory generated during installation.

Back up image files:

If this check box is selected, all image files in the $(EPLAN)\Projects\<...>\<Project name>\Images directory are backed up with the project. $(EPLAN) is the main directory generated during installation.

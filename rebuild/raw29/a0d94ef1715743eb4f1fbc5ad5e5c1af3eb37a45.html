Editing Sections

Sections can be modified subsequently and, for example, can be assigned to another project option or project options group. As well, sections can be extended subsequently to include other functions or pages, or the content of a section can be replaced entirely.

Preconditions:

  • You have opened a project.
  • You have opened the project options navigator: Project data > Project options > Navigator

Edit section properties
  1. Select a section in the Project options - <Project name> dialog.

    If you have activated the graphical preview (View > Graphical preview), the content of the highlighted section is displayed there.
  2. Select the menu item Edit > Properties.
  3. in the Section dialog, change the values in the Name and Description fields.
  4. If desired, select a different project options group and / or project option from the Name drop-down list (in the Project options group and Project option group boxes).
  5. Alternatively, you can manually enter a new project option group and / or project option.

    The Description fields of the project option group and / or project option are made editable.

    If you leave the Project options group field empty (or delete the entry) then the project option is not assigned to a project option group.
  6. If desired, enter a description into the Description field of the project options group and / or project option.
  7. Click [OK].

    If you entered a new name for the project option group and / or project option then this project option group and / or project option is generated.

    The associated project option is automatically switched on. Existing project options in the same project options group are switched off.

Modify sections

The content of a section can be extended subsequently to include other objects, or it can be replaced by new objects entirely. A section containing pages can be assigned only further pages (but not functions). A section containing functions can be assigned only further functions (but not pages).

  1. Select either a schematic section in the graphical editor, objects in a layout space, or functions in one of the project data navigators or pages in the page navigator.
  2. In the Project options - <Project name> dialog, select the section that you wish to modify.

    If you have activated the graphical preview (View > Graphical preview), the content of the highlighted section is displayed there.
  3. Select the Assign objects to the section popup menu item.

    If the selection contains objects that cannot be assigned to the section, a message will be displayed, and the action will be canceled after confirming the message.

    If the selection contains objects that can be assigned to the section, a prompt will be displayed asking whether objects not selected should be removed from the section.
  4. Click [Yes] in the prompt if you wish to replace the previous content of the section.

    The previous content of the section is deleted and replaced by the highlighted objects.
  5. Click [No] in the prompt if you wish to extend the section.

    The previous content of the section is retained and extended to include the highlighted objects.

Delete sections
  1. Select a section in the Project options - <Project name> dialog.

    If you have activated the graphical preview (View > Graphical preview), the content of the highlighted section is displayed there.
  2. Select the menu item Edit > Delete.
  3. Click [Yes] to confirm the safety prompt.

    The section is deleted. The objects are retained in the project when the associated project option is switched on; if the project option is switched off then the objects are deleted from the project.

Dialog Move

Dialog call:

You have opened a project.

  • You have selected a terminal strip definition or a terminal in the graphical editor. Project data > Terminal strips > Edit. Select the desired terminals. Popup menu > Move.
  • Project data > Terminal strips > Navigator. In the Terminal strips - <Project name> navigator dialog, select a terminal strip definition or a terminal. Popup menu > Edit. Select the desired terminals. Popup menu > Move.

This dialog allows you to move terminals by a specified number of positions on the terminal strip. This allows the creation (or removal) of gaps between the terminals. This changes the terminal designation(s) and also any existing sort code(s)

The selected and other terminals, up to the end of the terminal strip, are also moved by the same value on the terminal strip.

Overview of the main dialog elements:

By how many:

Enter a value specifying how far to move the selected terminals and all the subsequent terminals on the terminal strip. Negative values will move the terminals up (towards the back) and positive values will move them down (towards the front).

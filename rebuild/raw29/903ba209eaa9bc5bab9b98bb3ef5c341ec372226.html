Dialog Settings: PLC-specific

Dialog call:

You have opened a project. Options > Settings > Projects > "Project name" > Devices > PLC. In the Settings: PLC dialog, click beside the PLC-specific settings field on [...].

In this dialog, you defined the settings specific to each type of PLC, such as the format for PLC addresses, symbolic addresses, and assignment lists. These settings are stored as a scheme on a per project basis.

PLC processors can be freely configured in EPLAN. Thus, when you need to create an assignment list for which no EPLAN configuration exists, you can create your own configuration for your assignment list.

The following dialog elements are available:

Scheme:

Select a scheme that defines the PLC-specific settings from the drop-down list. The default setting for the scheme depends on the entry selected from the PLC-specific settings drop-down list (Settings: PLC dialog).
Using the neighboring Toolbar you can create new schemes, save changes to a scheme, and copy or delete a scheme. Schemes can also be imported or exported.

Description:

This field displays the descriptive text that you entered into the Description field in the New scheme dialog when you created the scheme.

Tabs:

The following tabs are available for entering the settings:

  • Addresses: In this tab you define the identifier and the data type for each of the inputs and outputs. You can also specify the data format for inputs and outputs.
  • Address formats: In this tab you define the format of the PLC addresses. Separate address formats are possible for digital and analog inputs and outputs.
  • Format of assignment list: In this tab you define the format of the assignment list.
  • Format of symbolic address: In this tab you define the criteria used for automatically creating symbolic addresses. You can also replace the special characters used by the structure identifiers in the assignment list with different characters.

Replacing Project Data

After the search, you can select project data and begin replacing the existing values with other ones.

  1. Select the following menu items: Find > Show results
  2. In the dialog Search results - <Project name> select the entry in the results list whose value you would like to replace in the list of results.Multiple selection is possible.
  3. Select the Replace popup menu item.

    The value of the (first) selected entry is displayed in the Find what field of the dialog Replace .
  4. In the Replace with field specify the value that you would like to use to replace the value shown in the Find what field.
  5. Use the check box to determine whether Upper-/lower-case letters will be taken into account during the search, and whether only entire texts (i.e. exactly as the text is entered into the input field) will be searched.
  6. Click [OK].

    The value is replaced in the selected entries.

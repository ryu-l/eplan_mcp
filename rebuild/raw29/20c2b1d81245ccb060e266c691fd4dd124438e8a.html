Generating Manufacturing Data for Machining

EPLAN Pro Panel allows for the output of item-specific drilling patterns in a ratio of 1:1 in PDF files. This template - printed on a plotter or large-format printer in the same size - serves as a template for the manual drilling of the mounting panel.

The NC interface modules transmit the coordinates and dimensions of drill holes, cut-outs, as well as other production data to edit mounting panels, doors, or side sections directly on NC drilling and milling robots. Restricted drilling areas are exported exclusively to Perforex machines. For the NC manufacture of user-defined outlines, outline records, adjusted for the machine in use, can be generated.

Interfaces for the export of manufacturing data are available for the following NC machines:

  • Rittal - Perforex BC / Secarex
  • Rittal - Perforex LC / Secarex (laser machining center)
  • Steinhauer
  • DXF.

Enclosure parts are thus prepared for mounting in a machine-based manner. The manufacturing time is reduced substantially as a result of the high automation level.

Note:

In order to adapt the creation of cut-outs through drilling patterns to length-variable items (mounting rails, wire ducts, etc.) to the operating method of the machine to be used, the dialog Settings: Zero position provides you with the possibility to set the zero position. The zero position designates that side of an item from which the drilling pattern is calculated on the item.

For all machining exports from EPLAN Pro Panel, the final message is contained in a dialog which lists specific information on the exported components or states reasons why certain components could not be exported. This dialog displays the following information:

  • Name of the exported format
  • Name of the used scheme and the set output path
  • Number of exported components
  • Alternative exports
  • List of all components which were not exported including the reasons why they were not exported
  • Reference to system messages if any have occurred.

Specifying the Representation of the Tree Structure in the Navigators

All the used structure identifiers of the identifier blocks that are identified in the project structure as "Identifying" are displayed by default in the tree views of the navigators (page navigator, device navigator, etc.).

In the project-specific settings you have the possibility to hide or display the structure identifiers of one or more identifier blocks and / or to have further properties (Page type, DT: Identifier, etc.) displayed in the tree representations. You can additionally change the order of the structure identifiers represented in the tree view by means of arrow buttons.

The following action is carried out using the page navigator as an example. Proceed analogously to specify the tree view in the other navigators.

Preconditions:

  • You have opened a project.
  • You have specified the project structure.
  • You have opened the page navigator.
  1. Decide which structure identifiers in an identifier block are to be displayed and which not.
  2. Select the menu items Options > Settings > Projects > "Project name" > Display > Tree structure (pages).
  3. To hide the structure identifiers for an identifier block, select the desired identifier block and deselect the check box in front of it.
  4. In order to display the page type in the page navigator activate the Page type check box.
  5. Click [OK].

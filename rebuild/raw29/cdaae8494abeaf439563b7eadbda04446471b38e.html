PDF File Export

In EPLAN, projects can be exported in PDF format (Portable Document File), which also takes into consideration the logical elements and links. This function allows high quality archiving of projects, since not only the graphical elements, but also a large part of the logical structure of the EPLAN project, is stored in the PDF file.

It is possible to navigate within the PDF: Jumps are available from the PDF bookmarks to the project pages, as well as jumps between linked elements within the pages.

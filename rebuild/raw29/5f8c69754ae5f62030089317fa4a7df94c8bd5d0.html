Dialog Select mounting panel

Dialog call:

You have opened a project. Utilities > Reports > Generate. Click (New). In the Select report dialog, select one of the "Device connection diagram (for wiring diagram)", "Terminal connection diagram (for wiring diagram)" or "Pin connection diagram (for wiring diagram)" reports. Choose the "Manual placement" entry from the Output format drop-down list, and select the Manual selection check box. Click [OK].

Notes:

  • If the "Manual placement" and / or Manual selection settings have not been selected, a corresponding message will be displayed. If you click [OK] in this message, the settings will change accordingly.
  • If there are no mounting panels in the project, the Select mounting panel dialog will not open.

In this dialog, you can select the mounting panel for which a connection diagram should be generated. A connection diagram shows the devices in the same sequence as on the mounting panel, and the exact coordinates and dimensions are irrelevant here.

Overview of the main dialog elements:

Mounting panel:

In this drop-down list, select the mounting panel for which the connection diagram is to be generated.

Hide devices already reported:

This check box is available if you have selected a mounting panel from the Mounting panel drop-down list, and a black box with the same DT exists.
Select this check box if the devices for which this report has already been generated, are no longer to be offered.

If this check box is not selected, all devices are offered for report generation.

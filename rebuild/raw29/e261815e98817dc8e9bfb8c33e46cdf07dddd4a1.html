Tabs Device properties / Part properties

Dialog call:
  • Page > Export > PDF. Click [...] in the Scheme field of the PDF export dialog. Select the Device properties or Part properties tab.
  • Options > Settings > User > Interfaces > PDF export. Select the Device properties or Part properties tab.

In the Device properties and Part properties tabs, specify which properties should be output in which order on PDF pages with device data.

Overview of the main dialog elements:

Table:

The Property column shows the properties that are output by default for the PDF file. Under Name, you will see the default names of these properties. You can also edit these multilingual texts.

Properties that are either "empty" in the properties dialog, have the value "0", or do not exist for a device (e.g. the Cable type property on a safety fuse) are not listed in the PDF.

Break up assemblies / modules:

Only for part properties!

If one of these check boxes is selected, assemblies / modules are broken apart, and the part numbers of the individual components of the assembly / module are assigned to the device.
If the check box is deselected, the part number of the assembly / module is assigned to the device.

The check box is deselected by default. You can then decide when creating reports whether assemblies modules should be broken down, and whether the bill of materials, for example, should show the part and order numbers of the assembly / module or of the individual parts.

Up to level:

If you selected the Break up assemblies and / or Break up modules check box, enter the number of hierarchical levels of assemblies that should be broken up.

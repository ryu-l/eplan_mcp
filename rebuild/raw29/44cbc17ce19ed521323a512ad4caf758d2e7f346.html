Action: reports


Parameter

Description

TYPE

Type of task to be carried out:
PROJECT: Update all project reports.
PAGES: Update all reports of the same type as the pages specified. Only the report type of the page is updated.
UPDATEMODELVIEWPAGES: Update model views on pages specified.
CREATEMODELVIEWS: Generate model views.
CREATECOPPERUNFOLDS: Generate copper unfolds.
CREATEDRILLINGVIEWS: Generate drilling views.

PROJECTNAME

Project name with complete file path (optional).
If nothing is entered, the selected project will be used if the action is to be run over the user interface (e.g. via script or the toolbar). When executing from the Windows command line, PROJECTNAME must be specified or ProjectAction has to be used before that.

PAGENAME 

Name of the page to be updated (optional).
If specified, only this report page is updated. This parameter has an effect only if the TYPE parameter has one of the following values: PAGES, UPDATEMODELVIEWPAGES.

USEPAGEFILTER

Determines whether only filtered pages or all project pages will be used (optional). Corresponds to the activation of the filter in the user interface. This parameter has an effect only if the TYPE parameter has one of the following values: PAGES, UPDATEMODELVIEWPAGES.
Default value: 0

PAGEFILTERNAME

Name of the page filter. Only reports on pages are updated that are filtered by the filter named PAGEFILTERNAME. This parameter has an effect only if the TYPE parameter has one of the following values: PAGES, UPDATEMODELVIEWPAGES.

PAGENAMEn

Names of pages for which a report update is to be run (optional). Here n is a number, for example /PAGENAME1:=EB3+ET1/2 /PAGENAME2:=EB3+ET1/4 /PAGENAME3:=EB3+ET1/7 etc. These parameters have an effect only if the TYPE parameter has one of the following values: PAGES, UPDATEMODELVIEWPAGES.

SELn

Object ID of pages for which a report update is to be run (optional). Here, n is a number, e.g., /SEL1:38/4/12/0. Alternative to PAGENAMEn. These parameters have an effect only if the TYPE parameter has one of the following values: PAGES, UPDATEMODELVIEWPAGES.

Example:

 
reports 
/TYPE:PROJECT 
/PROJECTNAME:C:\Projects\EPLAN\ESS_Sample_Project.elk

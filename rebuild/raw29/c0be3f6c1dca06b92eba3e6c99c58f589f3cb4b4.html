Updating Function Definitions

The function definition library is maintained and upgraded by EPLAN Software & Service. When you install a new version or an update that contains a new function definition library, you will have to reintegrate this library into the system. You must take the following steps to do this:

  • Export your own sets of identifiers, connection point designations, and connection point descriptions (if you have created any)
  • Synchronize the function definition library (by synchronizing the system master data with the EPLAN original master data)
  • Import your own identifier sets, connection point designations, and connection point descriptions (the EPLAN entries are overwritten during this import)
  • Add your own identifier sets, connection point designations, and connection point descriptions to the new function definitions.

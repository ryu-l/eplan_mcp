Tab Field description (Export Rittal - Perforex BC / Perforex LC / Secarex)

Dialog call:
  • Options > Settings > Company > Machining > Export Rittal - Perforex BC / Secarex. Select the Field description tab.
  • Options > Settings > Company > Machining > Export Rittal - Perforex LC / Secarex. Select the Field description tab.
  • Utilities > Manufacturing data > Machining > Rittal - Perforex BC / Secarex. Click [...] next to the Machine field. Select the Field description tab.
  • Utilities > Manufacturing data > Machining > Rittal - Perforex LC / Secarex. Click [...] next to the Machine field. Select the Field description tab.

On this tab field names for the export to Perforex machine software can be configured individually. To do this the property names in the Perforex software are assigned to selectable EPLAN properties in a table. After that the assigned Perforex field names are defined through the EPLAN properties. So for example the name of the current EPLAN project can be assigned to the Perforex field "Main program - Name" by assigning the EPLAN property "Project name" (P10000).

Overview of the main dialog elements:

Field:

Designation of the data field in the Perforex software.

Generate from:

In the drop-down list you can select how the field descriptions are to be defined in the Perforex software:

  • Automatic: The field descriptions are defined on the basis of the process of the previous EPLAN version 2.7.
  • Properties: The field descriptions are defined through EPLAN properties.

Formatting:

EPLAN properties that are assigned to field descriptions in the Perforex software.

As soon as the Formatting column is highlighted, the [...] button appears; click here to open the Select format elements dialog where you can configure the properties to be used.

Report Templates

Report templates allow the settings for reports to be saved and reused. You can generate reports based on report templates. All settings already specified in the report templates are used for the reports. Report templates can be imported and exported as *.xml files.

If you should regenerate an existing report from a template, the existing report will be deleted and a new one generated.

Tip:

It is possible to create several report templates for the same report type. If a report template (called 0001) already exists, when another template of this type is created, a prompt is displayed, querying whether or not the old template should be overwritten. If [No] is selected, two templates will be generated with the same name, which must then be changed.

Conditional reports

You can generate reports within the conditions of the project properties by using report templates. Define a project filter for this purpose and assign it to the template. During the reporting process, a report will only be generated from the template if the current project meets the filter criteria of the project filter.

Example:

This functionality is useful for instance when you are creating two projects (as common standard) from one basic project for differing project planning tasks:

Setting up a basic project

  • Use form A to create a report template in the basic project for a title page / cover sheet, designed for the first project EPLAN_Demo. This report template will be called Title_EPLAN_Demo.
  • Use form B to create a report template in the basic project for a title page / cover sheet, designed for the second project EPLAN_Test. This report template will be called Title_EPLAN_Test.
  • You define a project property as filter criterion in a project filter and assign the project filter to the report template Title_EPLAN_Demo.

Creating projects

  • The EPLAN_Demo project as well as the EPLAN_Testproject will be created from the basic project.
  • In order to be able to distinguish the two projects for reporting, assign the project properties you set up in the project filters as filter criterion to the first project EPLAN_Demo.

Generating project reports

  • When you use the reporting template to report on the EPLAN_Demo project, EPLAN uses the reporting template Title_EPLAN_Demo and generates a title page from form A.
  • When you generate reports on the EPLAN_Test project, EPLAN uses the reporting template Title_EPLAN_Test and generates a title page from form B.

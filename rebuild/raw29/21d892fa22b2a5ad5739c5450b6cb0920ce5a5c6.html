Dialog Synchronize wire harness data

Dialog call:

You have opened a project, and you have opened the wire harness navigator. Project data > Connections > Import > Wire harness data. You have selected a file (*.hpdex) with wire harness data in the Import wire harness data dialog. Click [Open].

In this dialog the wire harness data (functions, connections) to be imported from the source are displayed in a table respectively and are compared with the wire harness data already existing in the project. The displayed scope can be limited by using filters. Depending on the displayed status information you specify the action to be carried out with the wire harness data.

Overview of the main dialog elements:

The functions of the data source and project are synchronized in the Functions tab.

The connections of the data source and project are synchronized in the Connections tab.

Filter:

This drop-down list displays all the available filters. A chosen filter is activated automatically. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the Filter dialog. Here you can create, edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

  • Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
  • Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

Value:

Use this field, via Quick input, to adjust quickly the value of a filter criterion for a defined and activated filter.

Note:

Please note that an activated filter does not influence the import. The complete file is always imported on the basis of the set actions. It is therefore advisable to deactivate all the filters before the import and to check the actions specified in the table.

Table:

The contents of the selected import file are displayed in the table. The column headers correspond to the assigned EPLAN properties. The left-hand table section shows the wire harness data from the data source in addition to the fixed columns Status and Action. In the right-hand table section in addition to these columns the data from the EPLAN project. The following columns are always displayed:

  • Row: Contains a consecutive row number.
  • Status: This column indicates through an icon whether the wire harness data are not yet contained in the project, whether they already exist in the project, whether they have been deleted in the data source or whether the wire harness data in the project and in the data source have different editing states (for example other property values).
  • Action: Here you specify which action is to be carried out with the wire harness data depending on the displayed status.

    Status

    Meaning

    Possible action

    New: The function / connection in the data source is not yet contained in the project.

    Import or None

    Identical: The function / connection in the data source is already contained in the project and will not be imported once more. All property values are identical.

    None

    Changed: The function / connection is contained in the data source and in the project. One or more property values differ, for example the part number.

    Notes:

    • Fields with changed property values have a dark-gray background. The Tooltip for such a field shows the respective value in the project.
    • If the function / connection is "Marked for deletion", the Delete action is available additionally. The function / connection is deleted in the project by using this action.

    Change or None

    Invalid: The function / Connection cannot be assigned (because, for example, the source and target of a connection do not exist).

    None

Among other things the following columns can be displayed in addition to the columns Status and Action in the right-hand table section for the data from the EPLAN project:

  • Wire harness name: Shows the identifying name of the wire harness.
  • DT (full): Shows the full DT of the function / connection.
  • Marked for deletion: Shows whether the function / connection is marked for deletion.

The extent of the columns displayed here can be extended or reduced via the Configure representation popup menu item.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

Filter (status):

Here you can filter the wire harness data to be imported in accordance with their status information in addition to the filter set above. The following values are possible:

  • All: Displays all the wire harness data from the import file.
  • Changed: Displays the wire harness data that exist in both the data source and in the project and that differ.
  • Deleted: Displays the wire harness data that only exist in the project and have been deleted in the data source.
  • Identical: Displays the wire harness data that exist in both the data source and in the project and that are identical.
  • New: Displays only wire harness data that do not yet exist in the project.

Display only relevant columns:

This check box allows you to drastically reduce the number of displayed columns. If the respective check box is activated, only the most important columns (DT (full), Status, Action, columns with changed data, etc.) are displayed in the table for functions / connections.

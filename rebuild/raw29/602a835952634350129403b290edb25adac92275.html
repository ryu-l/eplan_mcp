Cables

The functionality of the cable in EPLAN is based on the connections. The following actions are possible for cables:

  • Cables can be edited in the navigator for cables or in the graphical editor.
  • Cable connections are defined using connection definition points.
  • Cables can also contain connections that are not conductors (hybrid cables).
  • Cables can be automatically completed and generated.
  • In parts selection, you can select a cable part for a cable defined in the project.
  • Cable parts are managed in the parts database. Cable information can be either manually entered or imported directly from the manufacturer using various import functions (e.g., ECAD, eCl@ss).
  • Cable connections are automatically assigned to connections of the cable part when cables are selected, and the connection point type is taken into consideration in the process. Manual assignment is another option.
  • Cables can be numbered. There are special formatting options for the numbering of cables.
  • Reserve cable connections can be managed.
  • Cables can be shielded, and multiple shields can be managed in the process.
  • Calculating the cable lengths generates project parts that reflect the actual requirements for cables. The cable lengths are added for each cable type.

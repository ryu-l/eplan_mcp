Tab Rotation / flipping (Changing Standards)

Dialog call:

You have opened a project. In the case of several opened projects: You have selected a project in the page navigator. Utilities > Change of standard. You have specified all of the settings in the Project tab. [Next].

Overview of the main dialog elements:

Template:

This field contains the template to be used for the target project. Use [...] to select a project template *.ept.

If you have activated the Apply project properties from the source project check box on the Project tab, the project properties are not taken from this template but rather from the source project.

You can use the Insert path variable popup menu item to branch to the dialog Select path variable where you can select one of the available path variables.

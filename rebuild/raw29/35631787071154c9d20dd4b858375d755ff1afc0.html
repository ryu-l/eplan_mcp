Dialog Print

Dialog call:

Project > Print.

In this dialog, you can select the printer and determine the pages that you would like to print.

The following dialog elements are available:

Printer:

In the drop-down list Name, all of the printers that are installed for your computer are displayed; select the one you would like. In the Status, Type, Where, and Comment fields, you can see the information stored for this printer in the Windows printer configuration.

[Properties]:

Use this button to open the Windows dialog for printer settings, which is where you can change the printer-specific settings. For more information, please see the help file for the printer in question.

Print to file:

Select this check box if you would like to print the selected pages into a file. EPLAN generates a *.PRN file which you can then print at a later date or use to create a PDF file.

Page range:

In this group box, you can determine which pages you would like to print. If you called up the Print dialog from the graphical editor, you can print either the page currently in the foreground or all of the project pages. If it was called up from the page navigator, you can either print the selected pages or all of the pages in the project.

  • Current page: The page in the foreground of the Graphical Editor is printed.
  • Selection: The pages selected in the page navigator are printed. If the project is selected in the page navigator and a page filter is activated at the same time, only the filtered project pages are printed.
  • Entire project: All the project pages are printed. Any activated page filter is ignored.

Copies:

In this group box, you determine the number of copies and their collation.

  • Quantity: You can determine how many copies of the selected pages will be printed here.
  • Collate: This check box can only be checked if you are printing multiple copies. If it is selected, the sets of selected pages will be printed one after the other. If it is not selected, all of the copies of each page will be printed together. A small graphic in the dialog makes the behavior clear.
  • Reverse print order: If this check box is selected, the pages will be printed in reverse order. If the check box is not selected, the pages will be printed in the order in which they appear in the project. A small graphic in the dialog makes the behavior clear.

Changed pages only:

Check this check box to have all pages printed which have been marked as "modified" since the last printout, that is, all pages for which the property "Modification date (automatic)" is more current than the last print date.

[Settings]:

Use this button to open the Settings: Print dialog. It is there that you can determine the scaling, print margins, and position on the page, as well as the settings for color or black and white.

[Print preview]:

Use this button to open the Print preview dialog.

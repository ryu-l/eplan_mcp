Coloring Components and Pipings in the P&I Diagram

In order to recognize in the P&I diagram which containers, PCT loops, pipings etc. are linked with segments in the pre-planning you can color these components and objects in the P&I diagram. To do so, select the new property Color for P&I diagram (ID 44086) in the pre-planning navigator in the property dialog and specify the desired color.

Benefit:

Through the new settings for coloring components and pipings in the P&I diagram and the new property Color in P&I diagram you can make the structures from the pre-planning that are placed in the P&I diagram visible.

In order for the linked objects in the P&I diagram to be displayed in the selected colors a setting still has to be carried out. To this purpose the general settings dialog for the pre-planning has been extended by the new group box Color components and pipings in P&I diagram with two check boxes (Menu path: Options > Settings > Projects > "Project name" > Pre-planning > General).

If you activate the new check box With assigned segment, all placed components and pipings whose link is located in the pre-planning navigator below a segment with selected color (Color for P&I diagram property), are colored with this color in the P&I diagram. The designation and description of such a segment is displayed in this color in the pre-planning navigator.

In addition the new In pipings (without assigned segment) check box is available in this settings dialog. If this check box is activated, the components that belong to the piping but are not linked with a segment in the pre-planning are colored additionally for colored pipings.

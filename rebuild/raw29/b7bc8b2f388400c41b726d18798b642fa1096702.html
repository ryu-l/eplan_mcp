Software requirements and approvals

In addition to the software approvals which are published in the EPLAN Information Portal, the following approvals apply.

EPLAN products

  • EPLAN Electric P8 (Professional and Select) versions* 2.7, 2.8, 2.9
  • EPLAN Pro Panel (Professional and Select) version* 2.7, 2.8, 2.9
  • EPLAN Fluid versions* 2.7, 2.8, 2.9

*) current Hotfix version

Java

For the installation variant Web EEC and the SCRIPTING module the installation of Java in the following versions is required.

  • JRE 8 64-Bit

Apache Tomcat Server

The installation of Apache Tomcat Server in the following version is approved for the Web EEC installation variant.

  • Apache Tomcat 9.0.48
  • Apache Tomcat 9.0.27
  • Apache Tomcat 9.0.24

The following approvals apply for older versions:

  • Apache Tomcat Version 7.0.91 for EEC Version 2.8.0, 2.8.1, 2.8.2.
  • Apache Tomcat Version 7.0.81 for EEC Version 2.7.2, 2.7.3, 2.7.4, 2.8.0.
  • Apache Tomcat Version 7.0.70 for EEC Version 2.7.1 and older.
  • Apache Tomcat Version 7.0.69 for EEC Version 2.7.1 and older.

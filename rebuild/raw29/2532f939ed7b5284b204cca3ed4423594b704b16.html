New Setting for New User-defined Properties from Macros

Previously new user-defined properties, that were for example inserted into the project by inserting and copying macros, automatically had the Do not use anymore setting assigned to them. These properties were then not visible at the assigned objects and were deleted when the project was compressed again. In the new version you can now decide whether the new user-defined properties are used in the current project or not.

To this purpose the new check box Do not use new property configurations from macros is now available in the project-specific settings for the graphical editing. (The menu path for this is Options > Settings > Projects > "Project name" > Graphical editing > General.)

This check box is deselected by default. In this case the new user-defined properties remain available in the project and are displayed at the assigned objects.

Activate the check box if the same behavior as before is desired for the new user-defined properties.

Benefit:

By means of the Do not use new property configurations from macros setting you can specify whether new user-defined properties from macros or other master data are used or not. When using the standard setting the new user-defined properties are directly visible in the project and this way can be found more easily in the project.

Note:

New user-defined properties can also be inserted via other master data such as forms, plot frames, etc. These properties are also taken into consideration through the setting.

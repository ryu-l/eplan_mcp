Dialog Device selection

Dialog call:

You have opened a project.

  • You have selected a main function in the graphical editor or in a navigator. Edit > Properties. Select the Parts tab and click [Device selection].
  • Project data > Parts / Devices > Bill of materials navigator. Select an entry. Popup menu > Device selection.

Select a device in this dialog. This means you assign one or more parts to a device using the technical data.

Note:

The data from the function definitions is assigned to the device. This data is entered in the parts management, in the function definitions table of the Function templates tab.

Overview of the main dialog elements:

Automatic filter:

You use [...] to open the dialog Automatic filter: Device selection. Here you set filter criteria for the parts which will then appear in the Main parts list.

Active:

Select this check box to use the defined filter criteria on the list.

Main parts:

This list contains all the parts from the parts management module that are suitable for the selected device and are not accessories (i.e. for which the Accessories check box on the Accessories tab is not selected). Part number, record type, and variant are always displayed; in addition, further columns can be shown depending on the respective item type (via the Configure representation popup menu item).

If you repeat the device selection, the last selected part is automatically selected in the list.

Note:

For devices with function definitions from the "Graphic" group, the device selection returns all the parts that have function templates with the "Graphic" function definition. In addition, all parts without function templates and accessory parts are displayed. This allows you to select parts from the "Mechanics" generic product group, for example.

Accessories:

If a part is selected in the Main parts list, the associated accessory is displayed here. The accessory parts must first have been assigned to the main part in the parts management module by entering them into the table on the Accessories tab.

An accessory part cannot be selected unless there is a part number entered in the Selection column:

  • For required accessories, the part number is automatically transferred from the Part number / Name column to the Selection column. Such an accessory part can thus be selected immediately.
    The part number is not automatically transferred for accessory lists. In the Selection column click [...] to open the Select accessories dialog. You can then select the required part from the accessory list.
  • The part number is not automatically transferred for optional accessories. You must first click in the Selection column and then click [...] to transfer the part number. You can then select the accessory.
    In this case, the Select accessories dialog is opened for accessory lists, and you can select the required part from the list there.

Note:

In the Select accessories dialog, the same columns are displayed that are also displayed in the Main part list.

Example:

The main part 001 (contactor + three power NO contacts) can be combined with auxiliary part 002 (two NC contacts) or with auxiliary part 003 (two NO contacts).

If you selected main part 001 in the Main parts list, auxiliary parts 002 and 003 will be suggested in the Accessories list. You can also select the following combinations:

  • 001 (contactor + three power NO contacts)
  • 001 + 002 (contactor + three power NO contacts + two NC contacts)
  • 001 + 003 (contactor + three power NO contacts + two NO contacts).

Selected parts: Functions / templates:

In this list both data of the function templates (such as Function definition) and important parts data (e.g. Part number) are displayed for the functions / templates. The columns with the template data are dynamically composed like in parts management. Which columns are displayed depends on the function definition of the main function, on the function definitions of the other functions of the device, and on the function templates of the selected part.

If the device has no part assigned to it, only the functions of the current device are shown here. An exclamation mark before the function indicates that the functions concerned are not yet overlaid by any function template of the part.

When you select a part in the Main parts field, you can see which device functions are overlaid by the function templates of the part and whether there are any empty function templates left. At first this is only a preview. The part isn't assigned yet. Preview rows are shown in italics.

If you use the arrow button to transfer the part into the Selected parts: Functions / templates list, the part is selected. This is indicated by the check symbol before the function templates of the part.

In every row, an icon is set to indicate whether the device function is overlaid by a suitable function template of the part:

Icon

Meaning

The device function is not yet assigned (i.e., you must select more parts to complete the device)

The device function has been assigned (the function is overlaid by a function template of the part)

The parts function template is still empty (i.e., the part contains more functions than are used by the device)

If the list shows several parts, the corresponding function templates are highlighted in alternating colors. This makes it easier to differentiate the parts. If you highlighted a row in the list, the entire part is highlighted along with it. To make this clear, all function templates that belong to the same part are highlighted in bold.

Note:

Parts that do not have a function template are also displayed here. These may be accessory parts or parts which have been assigned to the device using part selection, for example.

Tip:

All columns displaying data of function templates are summarized under the entry Template data in the column configuration of the list (via the popup menu Configure representation). Using this check box you can show / hide all columns with template data.

(Delete):

Deletes all function templates of the highlighted part from the Selected Parts: Functions / templates list.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

[Settings]:

Opens the dialog Settings: Device selection. Define which parts are to be taken into account when you select a device.

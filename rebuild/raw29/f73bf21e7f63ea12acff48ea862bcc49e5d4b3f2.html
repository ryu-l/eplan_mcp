Editing Modes when Opening Projects

You can open a project in miscellaneous processing modes:

  • Default: The project can be edited. If you work in the multi-user mode, such an opened project can be edited by several users simultaneously.
  • Exclusive: Only you can edit the project. If you work in the multi-user mode, other users cannot access such an opened project.
  • Read-only: You can view, but not edit the project. If you are working in multi-user operation, other users can edit this project.
    Read-only projects are identified in the tree and list representations of the navigators by a gray text background. In addition separate color settings for the display of opened write-protected pages and layout spaces are available.

Notes:

  • The edit mode is also shown in the list of recently used projects. When opening a project by selecting such a list entry, the project is opened in the last-used edit mode as indicated in the list.
  • If the Synchronize project master data when opening check box is activated in the project settings (Options > Settings > Projects > "Project name" > Management > General), the Project master data prompt is displayed when you open an "old" project. Click the [User-defined] button to branch to the dialog Synchronize master data - <Project name> where you can specifically accept individual master data. Click [Yes] to update the project master data automatically. If you click [No], the project master data is not updated, and you can synchronize the project master data later.

Tip:

You can open projects using drag and drop by dragging the selected *.elk project file from the Windows Explorer to the page navigator.

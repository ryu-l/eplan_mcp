properties

This element is a container, who encloses concrete properties, which will be specified with <property> elements.

Allowed sub-elements Quantity
property

Note:

Follow the sequence:

Within <figureBase>, <figureContainer>, <figureEllipse>, <figureImage>, <figureLabel> and <figurePolygon> first configure <configuration> and then <properties>.

Example code:

This example shows the definition for a node with the ID Component. All the nodes that are derived from this node, inherit these properties, but can override them.

<node id="Component">
	<figureContainer figure="com.mind8.graph2d.figure.Container">
		<properties>
			<property id="showLabel">
				<read value="false"/>
			</property>
			<property id="boColor">
				<read value="255,255,255"/>
			</property>
			<property id="fColor">
				<read value="50,50,50"/>
			</property>
			<property id="bColor">
				<read value="255,255,255"/>
			</property>
			<property id="selectedFColor">
				<read value="10,36,106"/>
			</property>
			<property id="selectedBoColor">
				<read value="10,36,106"/>
			</property>
			<property id="tooltip">
				<read value="=name"/>
			</property>
			<property id="boWidth">
				<read value="0"/>
			</property>
		</properties>
	</figureContainer>
</node>

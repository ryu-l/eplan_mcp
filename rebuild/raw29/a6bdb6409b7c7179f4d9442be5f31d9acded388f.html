Defining and Coloring Fluid Lines

In Fluid power, numerous line types are used for example pressure, control, drain, reservoir, and working lines, depending on the field of application and the task.

In EPLAN Fluid the various line types are represented in the schematic by means of fluid connections which are in turn based on autoconnecting lines. These lines are always automatically created between components if their connection points are positioned horizontally or vertically to each other.

In EPLAN Fluid a line type prescribed in accordance with the standard DIN ISO 1219-1 with the corresponding color assignment can be defined for a fluid connection. The following layers are available to this purpose. One layer is a type of slide on which the graphical connection properties of the autoconnecting line can be changed. The highlighting in color of the various line types serve the better orientation in the schematic during maintenance, servicing, repairing and modification of a fluid-specific system.

By default EPLAN Fluid assigns the line type "Pressure line" and the color "Orange" to all fluid connections. The corresponding layer is called EPLAN507, Symbol graphic.Connection symbols.Autoconnecting.Pressure lines.

Starting from the default setting the following section uses a concrete example to show you how you can change the line type and correspondingly the color at a fluid connection by assigning other connection point properties to the targets of the fluid connection.

Preconditions:

  • You have opened a project.
  • A fluid schematic page is opened on which you have placed a component for a hydraulic filter and a container return.
  • Both components are connected by an autoconnecting line which is displayed by default as a pressure line in orange.

  1. Double-click the filter component in the schematic, which is the first target of the connection.
  2. In the Properties <...> dialog of the filter bring the Symbol / function data tab to the front, and click the [Logic] button.
  3. Change the value "Undefined" to "Reservoir line" for the property Pressure / control port at the function connection point "2" in the dialog Connection point logic.
  4. Confirm your entries.
  5. Repeat the steps listed above for the container return, which is the second target of the connection. Also change the value "Pressure port" at the function connection point "1" to "Reservoir line" in the process.
  6. Update the schematic in the graphical editor by pressing the key [F5] (Redraw).

    Since the same line type "Reservoir line" has been set at both targets of the connection, EPLAN Fluid changes the default line type from "Pressure line" to "Reservoir line" at the connection. In the process the layer EPLAN521, Symbol graphic.Connection symbols.Autoconnecting.Reservoir line is assigned automatically to the fluid connection, with the result that the autoconnecting line color changes to "Light blue".

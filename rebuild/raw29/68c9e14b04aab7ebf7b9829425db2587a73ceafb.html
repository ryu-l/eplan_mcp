Sorting Terminals

In the Edit terminal strip dialog, you can change the order of the terminals within the terminal strip.

Precondition:

You have selected a terminal or a terminal strip definition in the terminal strip navigator, the device navigator or the graphical editor.

  1. Select the menu item Project data > Terminal strips > Edit.
  2. In the table in the Edit terminal strip dialog click the line number of the desired terminal in order to select the terminal.
  3. Hold down the [Ctrl] key and select any other terminals that you would like to move.
  4. Move the selected terminals with the arrow keys to the desired position on the terminal strip.

    The terminals are given a device position that is stored as a numerical value in the property Terminal: Device position.

    Within a terminal device (i.e. at related terminals with the same terminal position) a sort code is additionally assigned to the terminals that is stored as a numerical value in the Sort code (terminal / pin) property.
  5. Click [OK].

    The terminals are sorted according to the order of the sort code on the terminal strip. If several terminals have the same device position, these terminals are sorted according to the order of the sort codes. If multiple terminals have the same sort code or if the sort code is empty, these terminals are sorted according to the order of the terminal designation.

Tips:

  • The [Sort] button allows you to automatically sort all terminals in a terminal strip according to certain criteria.
  • Individual terminals can be sorted simply through Drag & Drop. To do so mark the row number of the desired terminal and move it to the correct position by dragging-&-dropping it. Multiple selection of terminals is also possible.

Note:

Multi-level terminals and other terminal devices are retained during sorting. To this purpose all the terminals of an independent area have the same device position assigned. If you want to sort the terminals without retaining the multi-level terminals, separate the multi-level terminals in advance in the Edit terminal strip dialog by selecting popup menu item Split.

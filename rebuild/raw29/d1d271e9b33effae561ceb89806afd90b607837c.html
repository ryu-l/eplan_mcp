Displaying Connection Points Graphically

Connection points at 3D part placements can be rendered visible in the layout space. This allows you to better estimate whether their position and connection point direction are suitable for existing routing paths and wire ducts, so that routing connections can find the connection points reliably. If this is not the case, you must modify either the connection point direction or the course of the routing paths.

In the graphical display, connection points cannot be deleted, moved or duplicated. Connection point data is modified in the property dialog of the part placement.

Display connection point designations

  1. Select the menu item View > Connection point designations.

    The connection points of the part placements are displayed as a red cuboid.

    The connection point designation is visible with a suitable 3D viewpoint and substantial enlargement of the section on the front of the red cuboid.



    The transparency of all part placements with connection points is set to 50%.

    If the cursor touches a connection point, a tooltip is displayed showing the plug designation and connection point designation.

Display connection point directions

  1. Select the menu item View > Connection point directions.

    The connection point direction is indicated by a red arrow.

Defining the Cursor Display

The cursor can either be shown as a crosshair or as "small cross". You define this in the User settings. In the "small cross" form, two short lines, at an angle of 45Â° to each other, are displayed. Regardless of the cursor display settings, the form of the cursor always represents the currently active action.

  1. Select the following menu items: Options > Settings > User > Graphical editing > 2D
  2. In the Display field, you define whether the cursor is displayed as crosshairs or as a "small cross".
  3. The Display crosshairs when placing macros and symbols check box allows you to define the type of cursor displayed when placing symbols and macros â regardless of the setting above.
  4. Click [OK].

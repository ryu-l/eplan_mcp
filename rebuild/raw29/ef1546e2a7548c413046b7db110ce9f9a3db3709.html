Dialog Settings: Internet connections

Dialog call:

Options > Settings > User > Management > Internet connections

In this dialog you specify whether a proxy server is used and in this case specify how it is addressed. The settings specified in this dialog are used for all the program components that establish a connection to the Internet. You can furthermore check the connection of the program components to the Internet and delete the saved browsing data for the program components.

Overview of the main dialog elements:

Tab Connection

LAN settings:

  • Without proxy server: Select this option if you are not using a proxy server.
  • Use proxy settings of the system: Select this option if you are using a proxy server and want to use the proxy settings from the operating system for EPLAN. In this case you do not need to make any adjustments in EPLAN if you change the proxy login data.
    If you want to use different login data for the proxy server in EPLAN despite using the proxy settings, you can make respective entries in the lower group box Proxy login data.
  • With proxy server: Select this option if you are using a proxy server. In this case, the bottom input fields are validated. Contact your administrator for the relevant settings.
    Specify here how the proxy server is addressed using the options Address and Configuration script (address). Under the Address option, you must enter the respective information on the actual address, port and the proxy login data; under the Configuration script (address) option, you specify the address of the script in the adjacent field and optionally enter the proxy login data.

Tab Connection test

The program components that establish a connection to the Internet as well as the associated URL are displayed In the table.

[Check]:

Click this button to check the connection of the program components to the Internet. If you use a proxy server there, the connection via the proxy server is tested. If the connection can be established, this is displayed in the table in the Status and Status message columns.

Tab Browsing data

[Delete]:

Click this button to delete the browsing data of all program components with browser windows. All previous entries that you have carried out for the confirmation or logon in a browser window are deleted.

You have to close and restart EPLAN so that this can become effective. You must then perform the confirmation or log on again when subsequently opening a browser window.

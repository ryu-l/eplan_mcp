Dividing Projects into Defined Working Sections

Preconditions:

  • You have opened a project.
  • You (or the project administrator) have created schemes which determine the criteria for the division into defined working sections.
  1. Select the menu items Project > Defined working sections > Define.

    In the Define working sections dialog, the schemes are displayed that were already created for the division in defined working sections.

    In the All editors column, you will also see the other editors who have selected a defined working section in the project.
  2. Select your defined working section by activating the check box for the desired scheme in the My defined working section column.
  3. If you want to edit the entire project temporarily, activate the Work temporarily in entire project check box.

    Editing is extended temporarily to the entire project. For example, this can be helpful in updating reports.
  4. Click [OK].
  5. Select the Project > Defined working sections > Activate selected defined working section menu items.

    Editing is now limited to only within the specified defined working sections. The project data navigators will then display only the pages, devices, etc. corresponding to the criteria determined in the scheme.

    If the selection of defined working sections has been activated for a project, a percentage symbol "%" is displayed in front of the project name in the title bar of the navigators (for example in the page navigator: Pages - %ESS_Sample_Project).

Notes:

  • Devices, terminal strips, etc. that have not been sorted into a defined project structure by means of structure identifiers are sorted into the tree structure level "Without structure identifier" of the device navigator. Such devices without structure identifier can be selected for editing by entering an empty structure identifier as filter criterion in the scheme for the defined working section.
  • If a user enters a new structure identifier during project processing, this will be available as filter criterion at once, it is, however, not automatically entered into the current scheme for the defined working section.

Tip:

To extend the defined working section temporarily to the entire project, select the menu items Project > Defined working sections > Entire project. Alternatively, in the Standard toolbar, you can also click the icon (Edit entire project). After you have completed the action, exit the temporary editing in the entire project and select the menu item again (or click the icon again).

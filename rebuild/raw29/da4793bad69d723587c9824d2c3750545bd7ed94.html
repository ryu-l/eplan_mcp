Adding up Cable Lengths

The cable lengths used in the project can be automatically totaled up for each cable type, in order to determine the number of cable drums needed. The same types of a cable will be combined into one cable project part and the lengths of the individual cables added together. The parts do not have to match, but the physical properties of the cables must match. To this purpose the complete cable type is reported.

You can only calculate the summation of cable lengths for the entire project.

Preconditions:

  • Cable lengths are entered for the cables.
  • A project is selected in the page navigator.
  1. Select the menu items Project data > Cables > Add up cable lengths.

    The cable types and their calculated lengths are displayed in the Add up cable lengths dialog. In addition, the length of the longest individual cable is displayed. In addition, the part assigned to the longest individual cable is displayed along with the cable's length. The required quantity of the part is also displayed.
  2. If necessary, change the value displayed in the Required quantity field. (This can be necessary if cutting problems arise: For three single lengths of 57 m, three 100 m drums will be needed, not two.)
  3. Select the Parts selection popup menu item if you want to select a new cable part.
  4. Select the Delete popup menu item in order to delete a part and thus exclude it from later reports.
  5. Click [OK].

    The old cable project parts are deleted and new ones are entered.

    The quantity of parts is reset to zero on the individual cables.

Note:

You can view, edit and delete the project parts in the Bill of materials - <Project name> navigator dialog. The changes, however, are overwritten in the next cable length calculation.

To display the project parts you have to select the Cable project parts check box in the Settings: Parts dialog (can be accessed in the bill of materials navigator via the menu items Popup menu > Settings). In the column configuration for the list view from the bill of materials navigator (via Popup menu > Configure representation) the Project part check box has to be activated in order to show the corresponding column.

Exclude cables from the addition of the cable lengths

You have the option of excluding prefabricated cables from the cable length addition.

  1. Double-click a cable definition line.
  2. In the Properties <...> dialog select the Cables tab.
  3. If the Do not use cable when adding up cable lengths property is not yet displayed in the table, go to (New) to add it.
  4. Select the check box for the Do not use cable when adding up cable lengths property.
  5. Click [OK].

    If the main part of the cable has a quantity of zero, a message will appear because this value may have been generated while adding up the cable lengths.

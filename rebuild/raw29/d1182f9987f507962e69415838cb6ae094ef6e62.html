P004045: Communication unit at the PLC box: '<x>'

...Bundle / Network ID =<x>, Bus master / bus coupler = <y>, To bus master / bus coupler ID = <z>, Bus system = <u>, Position / Bus ID = <v>, Data transfer rate = <w>, Subslot = <r>, DNS/PROFINET device name = <s>

Cause

Several causes are possible:

  • PLC boxes with communication units are still contained in your project.
  • Or you have imported an old project with PLC boxes that contain communication units.
  • Or you have imported old macros that contain PLC boxes with communication units.

Solution

You may handle the data as you wish:

  1. Create, for example, a new bus port or use an existing bus port and there enter the data found that are displayed in the placeholders of the message.
  2. Subsequently remove the existing communication units at the PLC boxes by means of the functionality Project > Organize > Compress.

Note:

This module-specific message is generated by the importing of PLC data. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

Exporting Bills of Materials

You can export all of the parts data from a bill of materials, regardless of the settings or active filters, that is, all of the parts and all of the data fields are output.

Precondition:

You have opened a project.

  1. Select the following menu items: Project data > Parts / Devices > Bill of materials navigator
  2. In the Bill of materials - <Project name> dialog, select the Export popup menu item.
  3. In the Export bill of materials dialog, select the drive and directory defining where the export file should be generated from the Save in drop-down list.
  4. In the File name field, enter the name for the export file to be generated.
  5. Select one of the entries defining the format for the export file to be generated, from the Save as type drop-down list.
  6. Click [Save].

    The bill of materials is exported to the specified directory under the specified name.

Data exported in this manner can then be edited and re-imported. However, only certain fields from the export file are written back during importing. An overview of the fields is provided in the section "Bills of Materials: Export File Fields".

Please note that export and import can only be carried out within the same project.

Tab Templates

Dialog call:

You have opened a project.

  • You have generated a planning object in the pre-planning navigator, or inserted one in the graphical editor. In the Properties <...> dialog, select the Templates tab.
  • You have highlighted a planning object in the pre-planning navigator or in the graphical editor. Edit > Properties (or Popup menu > Properties). Select the Templates tab.

Use this tab to assign function templates to a planning object. The planning object can also be assigned further function templates via the parts that are assigned to the planning object. Since each planning object may contain only one main function, we recommend that the function templates should be assigned either via the part only or via this tab only.

The following dialog elements are available:

Device selection (function templates):

This table displays the function templates assigned to the planning object. At the very top of the table, the function templates are displayed that are stored at the parts assigned to the planning object. These function templates and their sequence cannot be modified. The sequence is defined by the sequence of parts and by the sequence of function templates within each part.
If a part at the planning object is deleted or replaced, the associated function templates will also be deleted or replaced.

Below that, the function templates are displayed that are stored directly at the planning object. In a cell of the Function definition column, click [...] to open the Function definitions dialog: there, you can select the required function definition.

Tip:

If you want to hold off on a decision regarding a specific part until the detail planning, only enter function templates at the planning object, but no parts.

Toolbar:

Button

Meaning

(Find)

Opens the Part selection dialog and allows for function templates to be carried over from a part to the planning object. The part is not assigned to the planning object in the process.

(New)

Generates a new line. The new line will be appended to the end of the list.
The default setting for a new line is taken from the currently-selected line, i.e., its data are applied. If no entry is selected, an empty line is generated.

(Delete)

Deletes the line where the cursor is located, with all its contents, that is, including data, and if necessary renumbers the positions. Multiple selection is possible. Note that the changed data will only be written back to the database after you have clicked [Close] or [Apply].

/ (Move up / down)

Moves the selected row(s) one entry up or down, if possible.

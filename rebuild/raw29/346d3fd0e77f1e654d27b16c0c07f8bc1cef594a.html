Tab <Structure segment - displayed name>

Dialog call:

You have opened a project.

  • You have generated a structure segment in the pre-planning navigator, or inserted one in the graphical editor. In the dialog Properties <...> select the <Structure segment - displayed name> tab.
  • You have highlighted a structure segment in the pre-planning navigator or in the graphical editor. Edit > Properties (or Popup menu > Properties). Select the <Structure segment - displayed name> tab.
  • You have created a segment template for structure segments in the segment templates navigator. In the dialog Properties <...> select the <Structure segment - displayed name> tab.

On this tab, you specify the properties for the highlighted structure segment.

If the entries in the fields differ from the default values of the underlying segment template in the property dialog, these are highlighted by a yellow background.

Overview of the main dialog elements:

Designation:

Specify the name of the structure segment here. The designation entered here will be displayed in the pre-planning navigator at the structure segment by default.

Full designation:

This field displays the designation of the structure segment including the designations of the superior structure segments.

Description:

Enter description text for the structure segment here. This text is displayed in the pre-planning navigator together with the designation at the structure segment by default. If a structure identifier is entered for the structure segment, the description can be transferred later in the structure identifier management as structure descriptions of the assigned structure identifier.

Segment template:

This field displays the segment template which is assigned to the segment. Click [...] to open the Select segment template dialog for selecting a segment template. Only segment templates which are suitable for the segment definition of the current segment are displayed. When switching to another segment template, the property values of the new segment template are applied to the segment and are displayed in the property dialog of the segment. Manually changed values are retained.

Using (Delete), you can remove the reference to the segment template from the segment. The property values defined in the segment template will be deleted at the segment. Manually changed values are retained.

Structure identifiers:

Depending on the project structure the table displays the structure identifiers of the current structure segment which can be edited.

  • Structure: Lists the identifier blocks which correspond to the project structure. The adjacent column displays the associated preceding signs.
  • Visible: In these fields, the structure identifiers of the current structure segment can be edited. Enter a structure identifier in the proper field for this purpose, or click [...] to select a structure identifier using the <Structure identifier> (<Project name>) dialog.
  • Complete: These fields display the structure identifiers of the current structure segment including the superior structure segments. The superior structure segments cannot be edited here, they result from the hierarchical organization of the structure segment in the tree view of the pre-planning navigator.

Notes:

  • The preceding signs and separators between the individual structure identifiers can not be edited here. They originate from the settings of the Extended project structures dialog, which you open in the Structure tab of the project properties by clicking [Other].
  • Only enter one structure identifier each in such fields (without separators and sub-identifiers). Otherwise, it is impossible to generate a correct report for the structure. To create substructures, create a new structure segment.

Tips:

  • First, concentrate only on one identifier block (e.g., the plant), and do not attempt to pre-plan all identifier blocks at the same time.
  • You can also leave the fields for structure identifiers empty, and use such structure segments only for structuring in the pre-planning.

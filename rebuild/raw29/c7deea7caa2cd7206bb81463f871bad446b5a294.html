Display of Links to Connection Planning Objects and Other Objects in the Pre-planning Navigator

The pre-planning dependencies between the different segments are made visible by means of links. In order to detect whether segments are entered as source and target segments for cable and piping planning objects in the pre-planning navigator, you can have the links to the connection planning objects displayed by means of the new Tree view dialog.

To open this dialog select the popup menu item Tree view in the pre-planning navigator. Activate the check box Links to the cable and piping planning objects and close the dialog. Subsequently the links to the cable and piping planning objects are displayed in the tree view of the pre-planning navigator below the respective segments (icon: ).

Showing or hiding objects in the tree

The view of the tree view of the pre-planning navigator can possibly be unclear. For this reason you can use the respective check boxes to hide or display other objects displayed by default for the tree in the Tree view dialog, such as PLC addresses, structure boxes, functions. etc.

In accordance with your specification in this dialog other objects (PLC addresses, structure boxes, functions, etc.) are displayed below the segments or not.

Benefit:

Thanks to the new Tree view dialog you can individually specify which objects are to be displayed in the tree of the pre-planning navigator below the segments in the tree and in this way structure the tree in a manageable form. The new links show you where the segments are located that are entered as source and target segments at the connection planning objects.

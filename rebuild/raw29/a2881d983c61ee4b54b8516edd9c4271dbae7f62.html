Dialog Add up cable lengths

Dialog call:

You have selected a project in the Pages - <Project name> navigator dialog. You have entered cable lengths on the cables in the project. Project data > Cables > Add up cable lengths.

In this dialog, the number of cable drums needed is calculated. The same types of a cable will be combined into one cable project part and the lengths of the individual cables added together.

Overview of the main dialog elements:

Lengths in:

This field displays the measuring unit in which the cable lengths are output. You specify the measuring unit in the Settings: Cable dialog in the Measuring unit for cable length field.

Table

The following information is displayed in the table:

Complete cable type:

The complete cable type is displayed here. Multiple cables have the same complete cable type if the following properties of the cable are identical:

  • Cable / Conduit: Type (for example NYM)
  • Cable / Conduit: Number of connections (for example 3)
  • Cable / Conduit: Cross-section / diameter (for example 1.5)
  • Cable / Conduit: Unit for cross-section / diameter (for example mmÂ² or cm).

Calculated length:

The sum of the lengths of the individual cables is displayed here. The lengths are output in the default unit for cable lengths.

Longest single length:

The length of the longest individual cable is displayed here.

Part number:

The part number assigned to the longest individual cable is displayed here. Via the popup menu you can call the parts selection for the current cable type and select a different part (also one that is shorter than the longest individual length). After the selection the required quantity is automatically recalculated and updated in the row.

Part variant:

The part variant is shown here. Using the popup menu, you can call part selection for the current cable type and select a different part or variant.

Part length:

The length of the cable part assigned to the longest individual cable is displayed here.

Required quantity:

The required quantity is a result of the calculated lengths divided by the length of the cable part (in the Part length field). You can change the displayed value manually.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

In addition, the following dialog-specific popup menu items are available:

Menu item

Meaning

Part selection

Opens the parts selection.

Delete

Deletes the selected rows. The cable parts in question are deleted.

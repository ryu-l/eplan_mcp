Tab Part definition point

Dialog call:

You have opened a project.

  • You have selected a part definition point in the graphical editor. Edit > Properties. In the Properties <...> dialog, select the Part definition point tab.
  • Insert > Part definition point. In the Properties <...> dialog, select the Part definition point tab.

In this dialog, you can store parts on graphics in a schematic that are not assigned to a device. To each part definition point you can assign (like any main function) a maximum of 50 parts.

To output the parts stored at a part definition point in a parts list or summarized parts list in a structured manner, you can enter the properties Displayed DT and Full DT at a part definition point. This way, the parts can be assigned to a specific structure identifier. Still, the part definition points are not devices and, thus, are not shown in the device navigator or the device tag list.

Overview of the main dialog elements:

Displayed DT:

Enter the DT here which is to be displayed at the part definition point in the graphical editor. Once you change one of the identifier structures in the bottom part of the dialog, the changed entry is written into this field.

Full DT:

This field displays the full DT (i.e. structure identifier of the current environment + displayed DT) of the component / item. Use the [...] button to open the Full DT dialog. You can edit the structure identifiers there and select, e.g., another mounting location.

Structure identifiers:

For all structure identifiers used in the current project, you can click [...] here to open the <Structure identifier> (<Project name>) dialog and assign the part definition point a different structure identifier; the Full DT and Displayed DT fields are automatically adjusted, with the Displayed DT field being shown only for changed structure identifiers by default.

Note:

Depending on the settings under the Options > Settings > User > Display > Identifier menu items, new identifiers resulting from your entries in the Full DT and Displayed DT fields are automatically sorted in alphabetically or at the end.

Trade:

The trade is adopted from parts management, starting from the part number, and is prepopulated with the first placed trade setting of the part. If you need to, select another trade from the drop-down list.

Subtrade:

Here you enter the subtrade of the device if you need to. This information does not come from parts management and has to be separately entered.

User-Defined Properties

EPLAN offers you the possibility of creating additional user-defined properties. These properties extend the properties existing by default and are used for the entry and display of additional information.

The following is possible:

  • The properties are identified through a freely selectable unique identifying name.
  • Multilingual input is possible for the displayed name under which the property is displayed. The translated displayed names of the user-defined properties are displayed in the set dialog language.
  • You can specify the object (for example project, page, function, segment template) for which a property is to be available. In contrast to the configuration in the project, the user-defined properties created in the parts management can only be assigned to the object type "Part".
  • You can configure the properties freely and specify which type of input is possible, which default values are available in a selection list and in which category the property is displayed.
  • In pre-planning you can save user-defined properties in a segment template and also pre-assign values to them. These predefined properties are then available by default when creating new structure segments and planning objects.

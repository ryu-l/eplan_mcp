Reserved Special Characters in Keywords

The following table shows the meaning of reserved special characters in keywords.

Special characters

Meaning

%

Allows keywords with placeholders to be entered.

|

Allows you to enter a separator suggestion.

.(period)! (exclamation mark) ? (question mark) at the end of a keyword

Possible. Via the setting Options > Settings > User > Translation > Dictionary in the Remove end of sentence character field you can decide whether EPLAN searches for an appropriate keyword with or without end of sentence characters when translating in the dictionary.

.(period)! (exclamation mark) ? (question mark) within a keyword

Possible. In order for a punctuation mark not to be interpreted as a character for the sentence end during translation, select the Entire entry option in the Segment field under Options > Settings > User > Translation > General.

Â¶

Not possible. Reserved for the line break character in the graphical editor.

TAB

Not possible. Reserved as a separator for export files.

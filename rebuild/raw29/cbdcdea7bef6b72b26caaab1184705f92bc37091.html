Setting Toolbar Buttons for Actions or Menus

If you select an action or a menu without a pre-defined image file when modifying the toolbars, then you must specify further settings for the button in a subsequent dialog.

Precondition:

You have right-clicked on an area of the menu bar or a toolbar and selected the Customize popup menu item. You have extended a toolbar with a button corresponding to an Action or a Menu without an assigned image file.

  1. In the Configure button dialog enter the name of the image file to be assigned to the button in the Image file field. Or use [...] to open a selection dialog and select the desired image file. Only JPG and BMP are possible as image file formats.
  2. For a selected Action in the Tooltips field, enter the text that is to be displayed as Tooltip information.
  3. For a selected Action, adapt the sample entry in the Command line field to suit your requirements.
  4. Click [OK].

    The settings for the button are adopted. If you have not entered an image file in the Configure button dialog, a standard image file is displayed for the button.

Notes:

  • The settings for such a button can naturally be edited. Right-click the toolbar and select the Edit popup menu item, or double-click the button. You can then make your modifications in the Configure button dialog.
  • The popup menu for buttons offers some further functionalities: You can rapidly switch between the corresponding representation types via the Image, Text and Image and text options. And via the Button representation menu item you branch to the dialog of the same name in which you can further influence the representation of the button.
  • Once you have changed the button settings or changed toolbars in general, you must save the current user interface configuration as a new workspace or as a selected workspace (edit), so that the modified toolbars are permanently available for use (in the current workspace).

Editing Parts

Note:

You can also create or edit parts in the part selection from the components' property dialog. For this purpose the Modification allowed during selection check box must be activated in the settings (under Options > Settings > User > Management > Part selection). In this case open the part selection from the properties dialog not as read-only but rather create and / or edit parts.

Paste a part

Preconditions:

  • You have opened the parts management: Utilities > Parts > Management.
  • You have copied or cut a part into the Clipboard.
  1. Select the Insert popup menu item.

    EPLAN generates the new part in the current hierarchical level with the part number original_part_number_1.

    Example:

    Copies of the part SIE.ABC are named SIE.ABC_1, SIE.ABC_2, etc.

  2. Edit the copied data in the tabs on the right side of this dialog, or enter new data.

    During insertion, only the relevant data is used, i.e., copied data may not be inserted because the target part cannot store that data.

    Example:

    You copy the cable HELU.33 with order number ABC and a bending radius of 50 cm, and you insert this part as a general single component. As a result, you have the single part HELU.33_1 (in the "General" product group) with order number ABC. Since single components have no bending radius, the value of 50 cm is ignored.

Note:

The "Copy", "Paste", and "Cut" options are impossible for variants, since they always apply to the entire part. Therefore, if you call up one of these options on the hierarchy level of a variant designation, then the part to which the variant belongs to is cut or copied, and then pasted, along with all of its current variants.

Paste technical data

After copying a part, its technical data can be carried over to another part.

Precondition:

You have copied the part whose technical data should be copied to the Clipboard using the popup menu Copy or Cut and have selected the parts or variants into which the technical data should be copied.

  1. Select the Paste technical data popup menu item.

    The data is copied into the appropriate fields of the parts after any already existing data is first deleted. In the process variable data and the function templates are also taken into consideration. It is here too that only the relevant data is inserted, i.e., copied data possibly might not be inserted because the target part can't store that data.

Paste function templates

After copying a part, its function templates / function definition can be carried over to another part.

Precondition:

You have copied the part whose function templates / function definitions should be copied to the Clipboard using the popup menu Copy or Cut and have selected the parts or variants into which the function templates / function definition should be copied.

  1. Select the Paste function templates popup menu item.

    The data is copied into the corresponding fields of the parts. The data in the Function templates or Function definition tabs is taken into account. After a confirmation prompt, the existing function templates / function definitions are replaced by the templates / function definition being inserted.

Enter parts data

Precondition:

You have selected the desired part or variants.

  1. Use the tabs on the right-hand side of the dialog to enter data for the selected parts.

    If multiple parts are selected, then only data that is identical or undetermined (i.e., "empty") is displayed; this can be entered or changed globally for all selected parts. Compare the dialog-specific information with the fields in the individual tabs.

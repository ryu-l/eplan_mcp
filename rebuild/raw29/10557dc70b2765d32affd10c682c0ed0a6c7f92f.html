Generating Phase Busbar Connections

With this method the multi-line connections defined in the schematic are converted into phase busbar connections. This kind of connections will then no longer be considered when calculating the wiring and during wire fabrication.

If the phase busbar is to be configured in the mounting layout, it is possible to assign a DT and a part to the associated phase busbar connections. This turns the phase bus into a device so that it can be placed from the 3D mounting layout navigator.

Precondition:

A layout space is open.

  1. Select the menu items Project data > Connections > Generate phase busbar connections.

    You will be prompted to select the part placements that are to be converted to phase busbar connections.

    2. Note:

    The selection of the items takes into account only part placements with the following function definitions:

    • Part placement, normal item
    • Part placement, PLC card
    • Part placement, black box.
  2. Surround the desired items with a rectangle.

    The Generate phase busbar connections dialog lists all connections with the representation types "Multi-line" and "3D mounting layout" whose source and target are one of the items previously selected (e.g., connections with the "Conductor / wire" function definition).

Converting connections into phase busbar connections

  1. In the dialog Generate phase busbar connections mark all the connections that are to be converted into a phase busbar connection.
  2. Select the Generate phase busbar connection popup menu item.

    All connections with the check box enabled will be converted to phase busbar connections, and will be assigned the new "Phase busbar connection" function definition.

    All properties of these connections will be deleted.

    Connections of the "3D mounting layout" representation type produce non-routed connections.

    The resulting phase busbar connections are excepted from the calculation of the wiring and the wire fabrication.

Assign phase busbar

  1. In order to assign a part to a defined phase busbar connection select the Assign phase busbar popup menu item.
  2. Enter the DT for the phase bus bar connection in the DT field and select it from the drop-down list or by using the [...] button in the DT selection dialog.
  3. Use the [...] button in the Part field to open the part selection, in order to assign a part to a phase busbar connection and click [OK].

    The DT is displayed in the dialog Generate phase busbar connections.

    The phase busbar is displayed in the 3D mounting layout navigator as an unplaced device and can be placed from there into the layout space.

Deleting phase busbar connections

  1. In order the cancel the definition of phase busbar connections select the desired connections with the "Phase busbar connection" function definition in the dialog Generate phase busbar connections.
  2. Select the Delete phase busbar connection popup menu item.

    All properties entered at the phase busbar connection will be deleted.

    The connection is given the "Conductor / wire" function definition.
  3. Re-route the back-converted connections in the layout space.

Deleting non-routed connections

  1. Select the menu items Project data > Connections > Navigator.
  2. In the connection navigator, define a filter on the "Phase busbar connection" function definition.

    Only the remaining phase busbar connections and the non-routed connections created by the conversion to phase busbar connections are displayed.
  3. In the connection navigator, delete the non-routed connections created.

Tip:

In order to delete non-routed connections from the project, you can use the project compressing function. To do so, select the menu items Project > Organize > Compress. Activate the check box for the hierarchy level Remove unplaced connections in the dialog Settings: Compress.

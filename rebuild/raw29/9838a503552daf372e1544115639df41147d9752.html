Tab Text

Dialog call in the graphical editor:

You have opened a page in the graphical editor.

  • Insert > Graphic > Text.
  • Insert > Path function text.
  • You have selected a text or a path function text and the menu items Edit > Properties or have double-clicked a text or path function text.

Select the Text tab in the property dialog respectively.

Dialog call in the form editor:

You have opened a project. Utilities > Master data > Form > Open > [Open].

  • Insert > Graphic > Text.
  • You have double-clicked a text (or selected the Properties popup menu item, which allows also for multiple texts to be selected).

Select the Text tab in the property dialog respectively.

Dialog call in the plot frame editor:

You have opened a project. Utilities > Master data > Plot frame > Open > [Open].

  • Insert > Graphic > Text.
  • You have double-clicked a text (or selected the Properties popup menu item, which allows also for multiple texts to be selected).

Select the Text tab in the property dialog respectively.

Dialog call in the symbol editor:

You have opened a project. Utilities > Master data > Symbol > Open > [Open].

  • Insert > Graphic > Text.
  • You have double-clicked a text (or selected the Properties popup menu item, which allows also for multiple texts to be selected).

Select the Text tab in the property dialog respectively.

In this tab, you can enter a text or edit one later.

Note:

As soon as you have opened the dialog for entering and editing texts, the status bar shows the current data entry language.

Overview of the main dialog elements:

Text:

Enter the desired text in this field.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

Path function text:

Select / deselect this check box to assign the desired property to the text, regardless of whether you originally inserted text or path function text. The conversion also considers the layers, if you have used the default layers; i.e., Layer 108 (Graphic.Texts) is converted to Layer 110 (Graphic.Path function texts) and vice versa, but the other layers are disregarded.

Do not translate automatically:

Select this check box to prevent (online and offline) translation. Upon leaving the dialog by clicking [OK], the system checks whether the text is language-neutral. If this is not the case, you are asked whether the translation should be removed. If you click [Yes] here, text is created language-neutral. Existing translations are removed.

If the check box is deselected, then texts dependent on language are automatically translated.

Tab Identifier

Dialog call:

You have opened a project. You have opened a project page in the graphical editor.

  • Insert > Box / connection point / mounting panel > Structure box. You have placed the structure box. In the Properties <...> dialog, select the Identifier tab.
  • You have double-clicked a structure box (or selected the Properties popup menu item, which allows also for multiple structure boxes to be selected). In the Properties <...> dialog, select the Identifier tab.

In this dialog, you specify the identifier-specific properties for the selected structure boxes.

Overview of the main dialog elements:

Displayed DT:

Enter the DT here which is to be displayed at the structure box in the graphical editor. Once you change one of the identifier structures in the bottom part of the dialog, the changed entry is written into this field (see the example below).

Full DT:

This field displays the full DT (i.e. structure identifier of the current environment + displayed DT) of the component / item. Use the [...] button to open the Full DT dialog. You can edit the structure identifiers there and select, e.g., another mounting location.

Structure identifiers:

Depending on the project structure the table displays the structure identifiers of the current structure box which can be edited. EPLAN generally adopts the Device structure that you have defined in the project properties of the project.

  • Structure: Lists the identifier blocks which correspond to the device structure. The adjacent column displays the associated preceding signs.
  • Value / Visible: Without extended reference identification, the Value column is displayed. If you are using extended reference identification, the Visible column is displayed. In this column, the structure identifiers can be edited. Enter a structure identifier in the proper field for this purpose, or click [...] to select a structure identifier already defined in the project using the <Identifier block> (<Project name>) dialog. The fields Full DT and Displayed DT are immediately adapted automatically, whereby the Displayed DT field by default only displays the modified structure identifiers.
  • Complete: This column is displayed if you are using extended reference identification. It displays the structure identifier including all superior structure identifiers.

Example:

After insertion, the structure box has the full DT =AP+ST1.
Now you change the higher-level function to ANL2; the full DT is adjusted (=ANL2+ST1), and in the Displayed DT field only the newly assigned higher-level function =ANL2 is displayed.
On the other hand, if you change the mounting location +ST1 to +PT1 (and leave the higher-level function as =AP), then the full DT is changed to =AP+PT1, while the displayed DT is changed to +PT1.

Note:

Depending on the settings under the Options > Settings > User > Display > Identifier menu items, new identifiers resulting from your entries in the Full DT and Displayed DT fields are automatically sorted in alphabetically or at the end.

Starting and Exiting EPLAN

After installation, you can start EPLAN via the Windows Start menu.

Precondition:

You have the required software protection dongle for EPLAN and the required license.

  1. Click the Windows [Start] button and select All Programs.
  2. Open the EPLAN program group and click the icon for your EPLAN version.

    The EPLAN main window is started. If you have used an earlier version of EPLAN, the Import settings dialog opens.
  3. Select the check boxes for the settings areas that you want to import and click [OK].

    The settings for the areas selected are imported into the current version and relevant settings databases are generated. The settings for the areas Property configuration, Dialog memory, Tree and list configurations, and External programs are also imported.

Notes:

  • You can set up EPLAN such that after the program is started the most recently opened project, or the most recently opened page, appears. The settings for this can be changed via the menu items Options > Settings > User > Display > User interface.
  • If you use EPLAN Rights management you may (depending on the operating mode) have to log on via a Logon dialog before you can work in EPLAN.

Exit EPLAN

You can exit EPLAN at any time. All of the data and settings, including those relating to the user interface (i.e. open dialogs, displayed toolbars, etc.), are saved and used again when the program is restarted.

  1. Select the Project > Exit menu items or use the shortcut key combination [Alt] + [F4].

Check for a new EPLAN version

If a check is to be carried out whether a more recent version of the software is available when EPLAN is started, you can specify this in the settings:

  1. Select the following menu items: Options > Settings > Company > Management > Check EPLAN version
  2. Activate the check box Check for a new EPLAN version.

    During the next start of EPLAN a system message is displayed and the icon is displayed in the status bar. A double-click on this icon then opens the EPLAN Download Manager and you can install EPLAN in the most recent version.

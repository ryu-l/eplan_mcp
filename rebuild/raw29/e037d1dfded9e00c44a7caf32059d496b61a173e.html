Creating Detail Planning with Drag and Drop

If you have stored macros at planning objects, you can create the detail planning from them. To do so the macros have to be placed on project pages. A rapid and simple method for placing the macros is to drag & drop the planning objects from the tree view of the pre-planning navigator into the page navigator.

Preconditions:

  • You have opened a project.
  • You have created planning objects and stored macros at them.
  • You have opened the pre-planning navigator and the page navigator.

Placing a macro via drag & drop on a new page

Precondition:

The project setting Place several macros on one page is deactivated.

  1. Mark a planning object in the tree view of the pre-planning navigator.
  2. Drag the planning object into the page navigator.

    If a window macro with several representation types and / or variants are stored at the planning object, a selection dialog is opened. Through this dialog you can specify the representation type and variant of the macro to be placed.

    A page is generated. The name and the structure identifiers of the page is determined automatically from the structure identifiers of the planning object.

    The macro stored at the planning object is placed on the page.

    The Automatically generated property with the value "Import" is assigned to the automatically generated schematic page with the value "Pre-planning".

    The page is entered automatically in the list of the assigned pages at the planning object (Documents / Pages tab in the properties dialog).

In the case of a multiple selection of planning objects a new project page is created by default for each macro.

Tips:

  • You can also generate the schematic pages of the detailed planning from the list view of the pre-planning navigator. To do so, mark the desired segments with stored macro in the list and select the popup menu item Generate new pages from macro.
  • By using an activated filter you can carry out a rapid multiple selection of segments in the list view of the pre-planning navigator and thus generate several schematic pages specifically via the popup menu. In the tree view rapid and multiple selection of segments is not possible, because the superior segments are displayed here at an activated filter.

Placing a macro via drag & drop on an existing page

Preconditions:

  • The project setting Place several macros on one page is activated.
  • Place for the macro is available on then page onto which the planning object is dragged.
  1. Mark a planning object in the tree view of the pre-planning navigator.
  2. Drag the planning object to an existing page in the page navigator.

    If a window macro with several representation types and / or variants are stored at the planning object, a selection dialog is opened. Through this dialog you can specify the representation type and variant of the macro to be placed.

    The macro stored at the planning object is placed on the page.

    The page is entered automatically in the list of the assigned pages at the planning object (Documents / Pages tab in the properties dialog).

At a multiple selection of planning objects several macros are automatically placed on one page as long as there is enough space. Then a new page is generated and the next macros are placed there. If the planning objects are dragged onto a node in the page navigator, a new page is generated directly and several macros are placed as long as space is available.

Whether several macros are placed next to each other or below each other depends on the project setting Place macros below each other. By default this setting is deactivated and the macros are placed next to each other.

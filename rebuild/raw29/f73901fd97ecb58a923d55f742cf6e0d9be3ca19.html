Backing up Master Data

In EPLAN, you can backup not only complete projects, but also individual master data from the central master data pool. This includes basic projects, project templates, symbol libraries, plot frames, outlines, forms, macros, part information, dictionaries and project-independent settings.

In contrast to project data, individual master data cannot be filed off or archived. This means that a copy of the master data is always created and the original master data remains on the hard drive and can be further edited. Only when filing off or archiving of complete projects are the associated master data filed off or archived.

Data in subdirectories are included in the backup if the Back up subdirectories check box is selected.

Graphics in plot frames or forms are only backed up when they are stored in the plot frame or form. Referenced graphics cannot be saved and restored.

As in all list views, you can sort the master data displayed here in ascending or descending order by clicking the column headers.

  1. Select the following menu items: Project > Back up > "Master data"
  2. You define the settings for the master data to be backed up in the dialog Back up <Master data> dialog.
  3. Confirm your entries.

    The selected master data is backed up to the specified directory or e-mailed, according to the entries you have made.

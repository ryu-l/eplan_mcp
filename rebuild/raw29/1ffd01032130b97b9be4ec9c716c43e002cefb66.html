Saving Parts Reference Data to Function

Parts reference data are data stored at the function that reference a part entered at this function.

In the Parts tab of the Properties <...> dialog, you can assign part reference data to a function. The table within the tab serves for both the display of data that the part specifies as well as the entry of part reference data.

Preconditions:

  • You have double-clicked a component and in the Properties <...> dialog you have selected the Parts tab.
  • You have either entered a part number manually or have carried out a part selection or a device selection and subsequently used [Apply] to transfer the part data to the Parts tab.
  1. From the drop-down list Category, select the "Part reference data" entry.

    This table displays the corresponding values from the part. If you have manually entered a part number that is not defined in the parts management, the fields are empty.
  2. Change the existing values, or enter new ones.

    Values of part reference data that contain a value deviating from the part property are displayed with a yellow cell background.

    3. Note:

    If you delete the entry in a field and leave the field empty, this field is filled again with the corresponding value from the part as soon as you click [Apply] or [OK].

  3. Click [OK].

    The part reference data are stored at the function.

Tip:

If you want to delete the manually entered part reference data completely, mark all the values in the table (with the exception of the value for the part variant) and delete them. Then click [Apply] to fill the fields with values from the parts.

Deleting Parts at the Function

In the Parts tab of the Properties <...> dialog, you can delete part data assigned to a function.

Precondition:

You have double-clicked a component and in the Properties <...> dialog you have selected the Parts tab.

  1. Select the desired part numbers in the list and click (Delete).

    The respective parts are deleted at the function, but the parts remain stored in the project.

    The entered parts reference data are deleted completely.

Tip:

In order to delete stored parts no longer used from the project, you can use the project compressing function. To do so, activate the Unused parts check box in the dialog Settings: Compress in the Remove project data hierarchy level.

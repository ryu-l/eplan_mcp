Inserting a Wire Harness Definition

Wire harness definitions can be defined directly on insertion of the corresponding symbol into the schematic. In the wire harness navigator or the device navigator you can predefine wire harness definitions with specific properties. You can then place functions created in this manner in the schematic at a later time. Wire harness definitions must be placed if you want to copy these.

  1. Select the following menu items: Insert > Symbol.
  2. In the Symbol selection dialog, select the List tab.
  3. Enter the characters "HDEF" into the Direct entry field.
  4. Insert the wire harness definition on the schematic page.
  5. Enter the data for the wire harness definition in the Terminal strip definition tab of the Properties <...> dialog.
  6. Click [OK].

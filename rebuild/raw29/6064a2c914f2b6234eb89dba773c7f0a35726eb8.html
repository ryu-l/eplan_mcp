Dialog Settings: Symbol assignment (Changing Standards)

Dialog call:

You have opened a project. If multiple projects are open: You have selected a project in the page navigator. Utilities > Change of standard. You have specified all of the settings in the Project tab. [Next]. You have specified all of the settings in the Rotation / flipping tab. [Next]. You selected the check box in the Master data tab in a symbol library row in the Individual assignment column. [Next]. Click [Scheme] in the Symbols tab.

In this dialog, you can create and manage assignment schemes for assigning symbols from the source symbol library to symbols from the target symbol library. In assignment schemes, you use variants to specify whether the symbol should be rotated or flipped.

The following dialog elements are available:

Scheme:

Select the scheme that you wish to edit from the drop-down list. You can only edit user-defined schemes. You can create new schemes, save any changes to a scheme, and copy or delete schemes via the adjacent toolbar. Schemes can also be imported or exported.

Description:

This field displays the descriptive text that you entered into the Description field in the New scheme dialog when you created the scheme.

Assign symbols:

Button

Meaning

(New)

Creates a new assignment row. Allows symbols from the source and target symbol libraries, which you specified via [Extras] > Select source and target symbol library, to be individually selected and assigned.

(Delete)

Deletes a selected assignment row. The row must be selected in the Row column.

Source:

Shows the symbols from the source symbol library.

  • Symbol name: Displays the symbol name of the source symbol. [...] opens the specified source symbol library in the Symbol selection dialog. Makes it possible to display the selected symbol's properties or select another symbol.
  • Symbol number: Displays the symbol number of the source symbol.
  • Variant: Displays the source symbol variants used in the source project.
  • Description: Displays the symbol description of the source symbol.

Target:

Shows the symbols from the target symbol library.

  • Symbol name: Displays the symbol name of the target symbol. [...] opens the specified target symbol library in the Symbol selection dialog. Makes it possible to display the selected symbol's properties or select another symbol.
  • Symbol number: Displays the symbol number of the target symbol.
  • Variant: Displays the target symbol variant. The variant determines the rotation and flipping of the target symbol.
  • Description: Displays the symbol description of the target symbol.

Status:

The assignment of symbols is checked. This column displays the status of the check. The status is "OK" if the function definitions for the symbols match and the number of source symbol connection points is less or equal to the number of target symbol connection points.

[Extras]:

Menu item

Meaning

Select source and target symbol library

First opens the Select source symbol library dialog. Enables you to specify a source symbol library for the symbol assignment scheme. Then opens the Select target symbol library dialog. Enables you to specify a target symbol library for the symbol assignment scheme.

Enter source symbols automatically

Enters all of the symbols from the source symbol library, which you specified via [Extras] > Select source and target symbol library, into the various rows.

Suggest matching target symbols

Automatically assigns the symbols from the target symbol library, which you specified via [Extras] > Select source and target symbol library, to the symbols from the source symbol library.

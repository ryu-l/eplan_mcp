Improved Properties and Formatting for Date and Time

To be able to display individual components for the date and time in a better way, a project property was corrected, another one added and the formatting possibilities for these properties improved.

Benefit:

By means of the two project properties and the new format settings you can adjust the date and times specifications in the graphical editor and plot frames in accordance with your requirements.

Improved properties

The behavior of the Date (ID 10027) project property has been corrected. This property now only still shows the date in the project properties or as inserted special text in the graphical editor as well as in the plot frame. To have the current time shown in accordance with the set formatting in these locations, you now use the new project property Time (ID 10058).

By inserting the Time property in a plot frame, it is now also possible for project pages to document the time of a print order. All project pages that belong to a print order show the same time of the day.

Individual format settings

For the project properties placed as special text, new format settings are also available. To this purpose the Format tab below the new Date / time hierarchy level has been expanded by the two display properties Date format and Time format.

The default setting for these properties is "From project settings". In this case the format specified in the Project settings is used for a property for date and time display that is placed as special text. By using the respective drop-down list you can select an individual date or time format for the Date and Time project properties mentioned above, for example "YYYY" for a display "2018". In these lists further formats are available in comparison to the project settings.

Note:

The Display tab in the property dialog of the device has been expanded by the new hierarchy level Date / time. The date format can only be set here individually for a small number of properties for the date display.

Dialog Settings: Project groups (definition)

Dialog call:

Options > Settings > User > Display > Project groups (definition)

In this dialog you can create further project groups and can specify colors for the display in the project data navigators as well as additional project data navigators for the existing project groups.

Overview of the main dialog elements:

Project groups:

The table contains the following columns:

  • Row: Contains a consecutive row number.
  • Name: Here you can enter the names for up to three project groups. The names of the first two project groups, "Schematic projects" and "Macro projects" are predefined and cannot be modified.
  • Color: Here the color selected for a project group, which is used in the project data navigators as the colored edge for the projects of this project group, is displayed. Click in a line and then [...] to open the Color selection dialog and select a different color.
  • Color activated: Activate the respective check box if the selected color for the project group is to be displayed.

If a color is activated for a project with the project group assignment, the color set here is displayed as a colored edge in the project data navigators and in the project settings. If you open a page / layout space, etc. for such a project, the color is also used for coloring of the tab of the respective editor.

Additional navigators:

Up to ten additional navigators are possible. These navigators can be displayed and hidden in accordance with the sequence specified here by means of the menu path Project data > Additional navigators > â¦.

You can use additional navigators, for example, to have several differently filtered views displayed simultaneously for specific project data of a project (pages, devices, etc.).

The table contains the following columns:

  • Row: Contains a consecutive row number.
  • Type: Here select the type of project data navigator (for example page, device, etc.) is to be made available additionally.
  • Project group: Here select the name of the project group with the respective additional navigator.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

Managing Users

Rights management allows you to create users and assign them to particular user groups. You can also subsequently edit or delete users.

Note:

The users predefined by EPLAN, "ADMINISTRATOR" and "GUEST", cannot be edited or deleted.

Precondition:

You have opened the rights management: Utilities > Rights management

Create users
  1. To the left of the Rights management dialog, select the Users folder and click (New).
  2. In the User dialog, enter a name and short description of the new user.

    Note:

    Internally, the user name is always managed in upper-case characters in EPLAN (as it is under Windows). This means that, in EPLAN, the users "Paul Smith" and "PAUL SMITH" define the same person with the same rights.

  3. Click [OK].

    The user is displayed in the dialog Rights management, but still has no editing rights since they do not yet belong to a group.
  4. Assign the user to one or more groups as described in the section "Edit users".

    The user receives the corresponding editing rights.
  5. If necessary, assign the user a password as described in "Assign or change passwords".

Importing users from Windows
  1. Mark the Users folder on the left in the Rights management dialog, and click (Import users and groups from Windows).
  2. Select the desired Windows user or the Active Directory group in the subsequent dialog Select users or groups.
  3. Click [OK].

    The user is displayed in the dialog Rights management, but still has no editing rights since they do not yet belong to a group.

    Active Directory groups imported from Windows are displayed and managed like a user.
  4. Assign one or more EPLAN groups to the Windows user or the Active Directory group as described in the section "Edit users" .

    The user receives the corresponding editing rights. In an Active Directory group all the member of this group receive the corresponding rights without a separate user having to be created and edited for each group member.

Notes:

  • The logon is carried out using the Windows password at every user imported from Windows. The password cannot be changed here. Neither can the user name be changed.
  • If a user imported from Windows already exists as a user created in EPLAN, this user exists twice after the import. In such a case, however, only the Windows user is used and you should delete the EPLAN user who is not needed.

Edit user
  1. Mark the Users folder on the left in the Rights management dialog.
  2. Select a (self-defined) user name in the right-hand field and click (Edit).
  3. In the User dialog, change the name, and/or description and then click [OK].

    The dialog is closed and the changed data is displayed in the Rights management dialog.

Delete user
  1. Mark the Users folder on the left in the Rights management dialog.
  2. Select a (self-defined) user name in the right-hand field and click (Delete).

    After confirmation of the warning message, the user name is deleted.

Assign users to groups
  1. in the Rights management dialog, click the plus sign next to the User folder to open the folder and select a user name.

    The existing user groups are displayed at the right of the dialog.
  2. Select the check box corresponding to the user groups for which you wish the user to be a member of.

    The editing rights of the respective groups are assigned to the user. The assignments are stored as soon as you leave the dialog by clicking [OK].

Assign or change passwords
  1. Mark the Users folder on the left in the Rights management dialog.
  2. Select a user in the field at the right and click [Change password].
  3. In the Change password dialog, enter the (new) password into the New password field. To avoid typing errors on entry, you must enter the password a second time into the Confirm new password field.

    To ensure protection of your input, the password is not displayed in plain text but rather as * characters.
  4. Click [OK].

    The user is assigned the password entered here and, in the future, must enter this in the Log on to EPLAN dialog.

Data Transfer of EPLAN PPE Projects

EPLAN PPE projects from older EPLAN versions (Version 2.6 or older) are converted automatically into pre-planning projects during opening and the subsequent updating of the project databases. (In order for this to be possible, both the Microsoft operating system and the Microsoft Office applications (inter alia Microsoft Access) therefore have to be installed completely in the 64-bit version.)

In the process, segments are generated from the information contained in the PPE database. The old project is preserved under a modified name. If the EPLAN PPE project contains documents a message is displayed in which you can decide whether these documents are to be imported as graphical pages.

Note:

After the data import of an EPLAN PPE project further predefined planning objects (such as "Sensor", "Actuator", "Pick-up", etc.) and segment templates are available in the segment template navigator. These segment templates are based on the specifications from EPLAN PPE. During conversion the specification number in PPE becomes the identifying name of the segment template.

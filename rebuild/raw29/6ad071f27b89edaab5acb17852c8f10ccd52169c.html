P003002: It is not possible to make an automatic cable selection for this cable, because no corresponding filter criterion was found

Cause

You have generated a cable using the automatic cable selection. A manual cable definition does, however, exist for the cable with its properties, for example the properties Number of connections, Voltage, Cross-section, etc., being defaulted with certain values. One or several of these values do not match the cables you have determined in the Cable preselection table. This means, there is no suitable cable part for the manually defined cable.

Example:

You have defined a cable with a voltage value of 1.000 V. The table for cable preselection does, however, only contain cable parts with voltage values between 230 V and 400 V.

Solution

Adjust cable preselection to the manually defined voltage value.

Select the menu items Options > Settings, and, in the Settings <...> dialog, open the hierarchy levels Projects > "Project name" > Devices. Select the settings area Cable (automatic), and click [...] next to the Automatic cable selection field. In the Settings: Automatic cable selection dialog click (New) on the right above the Cable preselection table. In the tree view, switch to the Part selection dialog that opens for the Cables / connections product group and select a cable part with the corresponding property values. Click [OK] to transfer the part to the cable preselection table. If required, repeat the selection for additional cables. Close the dialog and generate the cable automatically once more.

Note:

This module-specific message is generated by the automatic cable selection. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

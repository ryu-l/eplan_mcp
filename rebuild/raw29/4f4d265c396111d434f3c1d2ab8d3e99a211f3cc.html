Operating EPLAN with the Keyboard

You can call up all menu items from the keyboard using the underlined identifier letters in the menu designations. Within the dialog elements, you can control the cursor using the keyboard and execute commands via key combinations.

Precondition:

You have opened the program.

Select elements within a dialog
  1. Press the [Tab] key as many times as necessary until you have selected the desired element.

Select tabs
  1. In the dialog, press the [Ctrl] + [Tab] keys together until you have selected the desired tab. "Paging" through the tabs takes place from left to right.
  2. Or press the [Ctrl] + [Shift] + [Tab] keys together until you have selected the desired tab. "Paging" through the tabs then takes place from right to left.

Open menus and popup menus
  1. In the dialog, press the [Tab] key until you have selected the desired menu button.
  2. Press [Space bar].

    The menu is opened.
  3. Use the arrow keys to reach the desired menu item.
  4. Press [Enter] to call up the menu item.

Open drop-down lists
  1. In the dialog, press the [Tab] key until you have selected the desired drop-down list.
  2. Press [Alt] +arrow key [down].

    The list is opened.
  3. Use the arrow keys to reach the desired entry.
  4. Press [Enter] to accept the value.

Use the keyboard in list or tree views
  1. Select the highest level in the tree structure, i.e. the project names for instance.
  2. Press [*] on your numeric keypad. (If your keyboard does not have a numeric keypad, e.g. a laptop keyboard, you can also use the shortcut key [Fn] combined with the computer- and country-specific key for "X".)

    The tree is opened.
  3. Switch between the tree and list views by pressing [Ctrl] + [Tab].
  4. Use the arrow keys to select the desired object within the list and tree structures.
  5. Press [Ã·] on your numeric keypad to collapse all hierarchy levels of the tree structure again.

Tip:

At any time you can press the [Ctrl] + [F12] keys to switch between the "dockable" dialogs, e.g., between the page navigator, message management, and a graphical editor.

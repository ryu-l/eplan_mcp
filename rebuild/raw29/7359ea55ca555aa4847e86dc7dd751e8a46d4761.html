Dialog Cables / Connections

Dialog call:

You have opened a project and are on a topology page. You have highlighted a routing path. Popup menu > Cables / Connections.

This dialog lists the connections running through the highlighted routing path. If a complete cable (i.e., all routing connections of the cable) runs through the routing path, the individual connections are not listed, but instead the DT of the cable is displayed.

The following dialog elements are available:

The table lists the cables / connections running through the routing path, together with their properties such as DT, Source, Target, and information regarding the routing track.

Popup menu:

Menu item

Meaning

Freeze panes

Fixes all the rows of the table above the selected row, or all of the columns to the left of the selected column. The rows below, or the columns to the right of the selection, can still be moved by using the scroll bar.

Unfreeze panes

Removes the freezing so that all of the rows and columns can again be moved using the scroll bar.

Adjust column width

Adjusts the width of all table columns so that both the headings and column contents are fully legible.

Font size 100%

This menu item is only available if the font size has been changed in the table (via [Ctrl] + scrolling with the mouse wheel). Re-displays the text in the table in its original font size.

Edit

Opens the Edit cable dialog where you can view and edit the assignment of cable connections to part connections. The menu item is only available when a cable has been highlighted.

Configure representation

Opens the Configure representation dialog in which you can determine the properties to be displayed in the list.

Properties

Opens the Properties (components): <...> dialog, which allows you to edit the function properties.

Properties (global)

Opens the Properties (global): <...> dialog, which allows you to edit the device properties.

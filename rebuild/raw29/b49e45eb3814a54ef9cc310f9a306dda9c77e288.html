Tab Settings (Schleuniger)

Dialog call:
  • Options > Settings > Company > Wire fabrication > Schleuniger > Settings
  • Utilities > Manufacturing data > Wire fabrication > Schleuniger. Click [...] next to the Scheme field. Select the Settings tab.

In this tab, information on the technical options of the machine to be used is stored. The individual settings are pre-set with appropriate values in a machine-specific manner, and can be modified here.

Overview of the main dialog elements:

Wire length minimum:

Minimum length the machine requires to handle the wire as defined (default value: 240 mm). Shorter wires are transferred to the machine with this minimum length.

Wire length maximum:

Wires that are longer than specified here cannot be processed by the machine (default value: 3,000 mm).

Conductor cross-section maximum:

Maximum cross-section of a wire that the machine can still process (default value: 6 mmÂ²).

Number of wires per bundle maximum:

Number of wires that the machine can combine into a bundle (default value: 1).

Total conductor cross-section maximum:

Limit value for the sum total of cross-sections of all wires (default value: 6 mmÂ²).

Routing direction up / down / left / right:

Texts that are to be printed on the wire to indicate individual routing directions.

Continuous text from wire length:

Length from which wires are to be printed with endless text. If no value is entered, all wires will be printed with endless text.

Maximum print font length:

Maximum number of characters that individual text can have (default value: 39).

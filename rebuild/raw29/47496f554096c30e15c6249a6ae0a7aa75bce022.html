Transferring Format Settings

The Copy format and Assign format functions allow the format and display settings to be transferred to other objects.

Precondition:

You have opened a page, form, plot frame or symbol.

  1. Select the object whose formatting settings you wish to adopt, and select the menu item Edit > Copy format (or click the appropriate toolbar button). If several objects are selected then the menu item and the button are grayed out.
  2. Click the objects to receive the new format, one after another. Or select them using an area selection.
  3. Select the menu item Edit > Assign format (or click the appropriate toolbar button).

    The format is transferred. If several different types of objects are selected, the format is only transferred to elements of the same object type as the original object.
  4. End the action via the Cancel action popup menu item or via the [Esc] button.

Transfer format settings of symbol macros / symbol groupings

The functionality "Copy and transfer format" may also be applied to grouped symbols and symbol macros. The following data of each symbol with multiple options and / or groupings will be stored:

  • Symbol number
  • Position within the symbols library
  • Graphical sequence (schematic path)
  • Type of object.

The following sequence is important when allocating information:

  • Type of object
  • Graphical sequence
  • Symbol number

If you should want to assign the properties of a multiple selection / grouping to a multiple selection / grouping, they will be assigned when the symbols of the source group are also present in the target group. If additional symbols are present there, a message will alert you, and no assignment will take place. If the source group contains more symbols than the target group they will be ignored. If the target group contains more identical symbols than the source group, they will be enumerated again from the beginning.

Example:

Source grouping: 3x NO contact (connection point designation "1,2; 3,4; 5,6")
End grouping: 5x NO contact (connection point designation "1,2; 3,4; 5,6; 1,2; 3,4")

In order to transfer the format of a multiple selection / grouping onto a single symbol, the corresponding symbol must be present in the grouping. If this is not the case, then an appropriate message is displayed. The option of separating the grouping with the [Shift] key is available here, the format will then be copied directly from the corresponding symbol.

In order to assign the format of a single symbol to a grouping, the symbol must also be present in the grouping. If this is not the case, then an appropriate message is displayed. The option of separating the grouping with the [Shift] key is also available here, the format will then be copied directly from the corresponding symbol.

P004057: Several parts with the same or suitable PLC type designation '<x>' found! A different part possibly has to be assigned to the function '<y>'

Cause

During the import of PLC data the PLC type designation is used to search for matching parts in the parts database. Possibly two or more parts having an identical type designation were found in the parts database. However, it is also possible that the PLC type designation contains placeholder characters. Then several parts are found, with the first found part being used.

The part found several times is displayed in the placeholder <x>, the DT of the respective part in the placeholder <y>.

Solution

  1. If several parts with an identical PLC type designation are found, correct the parts in the parts database. If a part with placeholder characters is found, check at the device whether right part is stored. If necessary, select a different part.
  2. Start a check run (any check run scheme set) to delete the module-specific message from the dialog of the message management.

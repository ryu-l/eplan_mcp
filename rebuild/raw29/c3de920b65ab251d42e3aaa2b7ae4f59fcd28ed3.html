Exchanging Symbols or Components

A symbol only serves to provide a graphical representation of a particular function, it does not contain any logic information. A component, however, is a symbol placed in the schematic to which a function (and thus logic) has been assigned. For this reason, the following distinction is made when swapping: If you swap a symbol, the logic (.e. the function) remains. Only the graphical representation changes. If, however, you swap a component then the function is also replaced. In both cases, the new symbol is selected using the symbol selection.

You can only swap symbols when the new symbol matches the function of the component. EPLAN checks the number of connecting points of the symbol to be replaced. In the symbol selection, you are only offered symbols having the same number, or fewer, connection points as the symbol you wish to replace. Symbols having more connection points than the symbol already in the schematic cannot be selected. For function definitions with a variable number of connection points, all symbols are offered. When swapping a symbol, the function definition remains unchanged.

Preconditions:

  • You have opened a project and at least one symbol library.
  • You have opened a project page in the graphical editor.
  1. Select the symbol to be swapped.
  2. Select the Properties popup menu item.
  3. In the Properties <...> dialog, select the Symbol / function data tab.
  4. Click [...] in the Number / name field.

    The Symbol selection dialog is opened. The symbol is selected in the tree or list and is displayed in the preview window.
  5. If you only wish to display symbols in the same function category, select the Only display symbols of the same symbol function category check box.
  6. If you only wish to swap the symbol while retaining the function definition, select the Only exchange symbol check box. (In this case, only symbols are offered which no longer have connection points as the current function definition.)
  7. Select the desired new symbol.
  8. Confirm your entries.

    The symbol is exchanged in the schematic.

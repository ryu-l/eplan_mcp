Tab Settings

Dialog call:
  • You have opened a project. Utilities > Manufacturing data > Export / labeling. Click [...] next to the Settings field in the dialog Export manufacturing data / output labeling. In the dialog Settings: Manufacturing data export / labeling select the Settings tab.
  • Options > Settings > User > Interfaces > Manufacturing data export / labeling. In the dialog Settings: Manufacturing data export / labeling select the Settings tab.

In this tab you define the project or parts data to be output with the export / labeling data.

Overview of the main dialog elements:

Part assemblies:

The settings in this group box only affect the parts list and summarized parts list:

  • Break up assemblies: Activate this check box if assemblies are to be broken down into their components, meaning their individual parts.
  • Break up modules: Activate this check box if modules are to be broken down into their components, meaning their individual parts.
  • Up to level: In this field enter the hierarchical level to which assemblies / modules are to be broken down. Entries are only possible if the Break up assemblies and / or Break up modules check box has been selected.
  • Combine parts of a device: Select this check box for a scheme of the "Parts list" report type if the parts at terminals are to be combined into terminal strips and the parts at cable connections are to be combined into cables in the parts list. If this check box is not selected then the parts are listed individually.

    Example:

    If the check box is selected, the parts list contains one item with 25 UK5 terminals and one item with 10 conductor sleeves; if the check box is not selected, the terminal UK5 is listed 25 times and the conductor sleeves are listed 5 times (conductor sleeves belong in pairs).

Setting / Value:

Project and function related filter and sorting settings can be defined in this table: In the Value column, click [...], select the desired project if necessary, and then define the appropriate criteria in the Filter or Sorting dialog.

The Value field for the "Action" setting displays the customer-specific extension currently assigned to the label by an action; click [...] to open the Enter name of the action dialog and, if necessary, replace the action with a different one.

Include parts:

Activate the check boxes at the parts whose data are to be output as well at the output for the "Parts list", "Summarized parts list" and "Manufacturer / Supplier list".

Notes:

  • The settings Devices without part number, Terminal strip parts, Terminal parts, Cable parts, Plug parts, Pin parts, Busbar parts, Busbar connection point parts also apply for the Device tag list report.
  • The Pre-planning part setting evaluates parts which have been entered solely at planning objects in pre-planning. If there already is a main function or a part placement for a planning object, this setting is not evaluated in the parts reports.

P028031: The part '<x>' entered at the segment is not contained in the pipe class '<y>'

Cause

In the pre-planning a part number is entered at a segment that does not match the part number that belongs to the selected pipe class.

Solution

Possibility 1

  1. Open the segment template navigator and call up the property dialog of the pipe class that is specified in the placeholder <y> of the message.
  2. Bring the Parts tab of the pipe class to the front.
  3. In the table supplement the part number <x> that is output in the message text of the segment.
  4. Then start a new check run.

Possibility 2

  1. Locate the segment on the pre-planning page by using the Go to (graphic) functionality from the popup menu in the Message management dialog. Or use the Synchronize selection functionality to jump to the segment in the pre-planning navigator.
  2. Call up the property dialog of the segment.
  3. On the first tab select a pipe class that contains the part number <x> which is output in the message text.
  4. Then start a new check run.

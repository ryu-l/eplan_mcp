Dialog Messages

Dialog call:

You have opened a project. You have selected several PLC connection points in the graphical editor, the PLC navigator, or in the device navigator. Or you have selected one or more pages or a project in the page navigator. Project data > PLC > Generate schematic. In the Generate PLC schematic dialog, you have selected the rows with the devices for which errors are to be displayed in the Status column. Select the Show messages popup menu item.

This dialog shows the errors that occurred when assigning macros to the PLC functions.

Overview of the main dialog elements:

The following columns are displayed in the table:

  • Object: This shows the DT of the PLC function that caused an error in the macro assignment.
  • Representation type: This shows the representation type where an error occurred.
  • Message text: This describes the error in more detail.

Example:

If (e.g.) the multi-line representation macro variant for a PLC box is missing, then the following information is displayed in the table:

Object: =EB3+EB1-A1
Representation type: Multi-line
Message text: The "Multi-line" representation type does not exist in the macro.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

Dialog Application class selection

Dialog call:

Utilities > Parts > Management > [Extras] > Import. You have selected the entry eCl@ss version in the File type field. Click the [...] button next to the File type field, select the Class structure assignment tab and click (New).

This dialog displays the complete eCl@ss class tree for the eCl@ss segments 19 ("Information, communication and media technology"), 23 ("Machine element, fixing, mounting"), 27 (" Electric engineering, automation, process control engineering ") and 37 ("Industrial piping").

Overview of the main dialog elements:

List:

The list contains all the classes for the corresponding eCl@ss segments in a structured tree view. Here you can carry out a free selection of segments, main groups, etc. for the assignment to EPLAN properties.

Note:

eCl@ss properties that are identified as "Deprecated" are not offered for the assignment.

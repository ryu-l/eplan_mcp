Dialog Select report

Dialog call:

You have opened a project. Utilities > Reports > Generate. Click (New).

This dialog lets you specify what report type should be generated and define the output format and source project.

Overview of the main dialog elements:

Output format:

In this field, you can specify the format in which the report will be generated.

  • Page: The report will be generated in the form of report pages and output in a project.
  • Manual placement: This option is only available when a project page is open in the graphical editor. The report will be generated in the form of an embedded report. You can manually place an embedded report in the currently open project page. This setting is useful when combined with the "Total" page sorting.

    Note:

    Although you may have selected (for example) the "Higher-level function and mounting location" page sorting (under the Options > Settings > Projects > "Project name" > Reports > Output to pages menu items in the Page sorting column), you can manually place only complete reports.

Source project:

In this field is the project that is the data source for the reports and templates. You can use [...] to open the source project dialog, where you can select a (different) project as the data source.

Select report type:

Reports are based on report types. This field displays all available report types. Select the report type for which a report is to be generated.

Current page:

Depending on the report type, this check box is only available for the "Manual placement" output form. Activate it to have only the data of the current page evaluated in the current report; this is, e.g., useful for embedded reports.

Manual selection:

This functionality is only available for function-related reports. If this check box is selected, then the Manual selection dialog opens before the report is generated. In this dialog, you can select the devices for the report individually.

Dialog Settings: Numbering (offline)

Dialog call:
  • You have opened a project. Page > Navigator. One or more pages are selected. Project data > Devices > Number > [Settings] > Numbering.
  • You have opened a project. Project data > Devices > Navigator. One or more devices are selected. Project data > Devices > Number > [Settings] > Numbering.
  • You have opened a project. Options > Settings > Projects > "Project name" > Devices > Numbering (offline).

In this dialog, you can create or edit a format for the offline device numbering.

Note:

The numbering formats that you create or edit here are different from the numbering formats used for online numbering.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent toolbar for this purpose.

Available format elements:

This field displays all available format elements. The format elements are either part of the format or define the manner in which numbering should occur. In order for a format element to be used for a format, you must select it and use (Move to the right) to include it in the Selected format elements field.

Format element

Preview

Meaning

Page

S

Defines the page name(s) of the page(s) where the device is located.

Column

P

Defines the column number in which the device is located.

Identifier

I

Defines the identifier for the device.

Counter, consecutive by rows

CL

Devices are numbered consecutively by row. The numbering proceeds over all pages.

Counter, consecutive by columns

CC

Devices are numbered consecutively by column. The numbering proceeds over all pages.

Page, counter consecutive by rows

SL

Devices are numbered consecutively by row. The counter begins with the start value on each page.

Page, counter consecutive by columns

Sc

Devices are numbered consecutively by column. The counter begins with the start value on each page.

Separator

Separates format elements from one another.

Line

R

Defines the line number in which the device is located.

Note:

Usually, the numbering is carried out in relation to the page sorting. 3D part placements that are placed exclusively in the layout space and do not have a counterpiece on a 2D page (e.g., wire duct, mounting panel) can be numbered correctly only with a numbering format that does not take the page sorting into account (e.g., "Default"). In the Selected format elements field of the numbering format that is used for the numbering of such devices, the "Page" format element must not be included.

Selected format elements:

This field displays all the format elements comprising the current format. The current format is shown in the Scheme field.

Keep prefix:

The functionality applies to DTs containing a prefix. If the check box is selected, the prefix is retained in the DT. If the check box is deselected, the prefix is removed from the DT. This functionality allows you to (e.g.) decide whether the circuit number is to be retained in the DT for fluid devices.

Keep counter:

If this check box is selected, the entire counter is kept with letters and digits, but without subcounters.

Keep letter elements of counter:

If this check box is selected, the letter part of the counter is retained.

Example:

The DT of the device contains a counter T3. The counter thus consists of a letter and a digit. After numbering, the letter T is retained.

Dialog Property selection

Dialog call:

You have opened a project.

  • You have selected one or more components in the graphical editor or one or more functions in a navigator. Edit > Properties. Click (New) in the <Function category> tab.
  • You have selected one or more segments in the pre-planning navigator or the graphical editor. Edit > Properties. Click (New) in the <Segment displayed name> tab.
  • In the page navigator you have marked a project, one or more pages, a symbol, a form or a plot frame. Edit > Properties. Click (New) in the property dialog / in the Properties tab.
  • You have opened a project and are now in the list view of a navigator, in the tree view of certain navigators, in the Symbol selection dialog, etc. Select the popup menu Configure representation. Click (New) in the settings dialog.

In this dialog you select the properties to which you want to assign values subsequently (in as far as these are properties that can be written to), or that are to be assigned in certain dialog elements (for example tree or list views).

Overview of the main dialog elements:

Filter:

Into this field enter the text for which the properties are to be filtered.

If you want to return to the original view of the properties, remove the search term from the entry field. Click (Delete) to do so.

List:

All the properties to be displayed are listed in the list. Which properties can be selected for additional display depends on the location from where you call up the dialog.

Select the desired properties; multiple selection is possible.

Notes:

  • If you call up the property selection for a specific object (for example in the properties table of the property dialog), the properties for the respective object are displayed as a table with the columns Property name and Value.
  • Please note that only texts and no specified values are found when filtering the properties.
  • Logic operators (AND / OR operation) and placeholders (such as * or ?) are not supported for filtering.

Tip:

Enter multiple letters one immediately after the other to search for a string and jump directly to the first entry that starts with the letters you entered. If you enter "sup", for example, the cursor will jump in the list of properties directly to the first entry that starts with "sup", for example "supplementary field".
If you pause too long between entering "s" and "u", the cursor will jump to the first entry that starts with "s", and then to the first entry that starts with "u".

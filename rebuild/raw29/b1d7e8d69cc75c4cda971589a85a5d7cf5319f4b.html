Notes

Using the editor for notes, notes can be assigned to objects that are available in the text format (*.txt) or OLE-compatible format (e.g., Word, Excel, PowerPoint).

In the notes editor, the icon Add opens a dialog for selecting a note resource. The search path for notes can be configured in the user preferences under Disciplines (see Menu Window).

The selected resource is then listed in the table of the editor (1). The content is displayed below the table in an editor window (2) for the respective format, where it can also be edited.

If an OLE-compatible format is used, the appropriate application (such as Excel) is displayed in the editor window.

This behavior with OLE-compatible formats suggests that the disk symbol (2) of the OLE application can be used to save changes to the note, but this has to be done always using the disk symbol (1) of EEC. Doing it differently will result in the loss of data. The key combination [Ctrl] + [S] does not have any effect either!

The behavior of OLE applications was modified by the move from Office 2003 to Office 2007 in such a way that an already opened file could be opened as read-only in Office 2003 application, but not in Office 2007/2010 applications.

If files are to be used for notes that the system will not recognize as being in the text format, you can add these to the content types in the text format under Window > Preferences > General > Content types > Text.

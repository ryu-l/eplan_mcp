P005046: Incomplete net

Cause

Possibility 1

Not all the connection points on a net were connected to one another.

Example:

A net N1 in the schematic apparently connects 5 fuses (-F1 to -F5) with the potential L1.

The net properties show, however, that connection point -F5:1 within the daisy chain is not connected.

Possibility 3

A connection was deleted within a net in the schematic. This creates a gap in the daisy chain. In this case, message P005047: Net definition point contains incomplete connections is also output.

Possibility 4

An additional connection that has not yet been assigned to a daisy chain was placed within a net in the schematic by copying. In this case, message P005050: Duplicate ID for net-based connections within a net (<x>) is also output.

Solution

Regarding option 1

Example:

For the example under "Possibility 1", the steps are as follows:

  1. Locate the relevant net definition point in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
  2. Open the Properties <...> dialog for net definition point N1.
  3. Bring the Net connections tab to the front.
  4. In the Connection points table, double-click connection point -F5:1.

    Connection point -F5:1 is copied to the Connections table and entered beneath the horizontal line of the first daisy chain. This starts a new daisy chain.
  5. Select connection point -F5:1 beneath the horizontal line, then click the (Move up) button to move it to the daisy chain already ended.
  6. Click [OK] to close the Properties <...> dialog for the net definition point, then start a new project check.

Regarding option 2

Connect the two separated daisy chains.

Example:

For the example under "Possibility 2", the steps are as follows:

  1. Locate the relevant net definition point in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
  2. Open the Properties <...> dialog for net definition point N1.
  3. Bring the Net connections tab to the front.
  4. In the Connection points table, double-click connection point -F4:1.

    Connection point -F4:1 is copied to the Connections table and entered beneath the horizontal line of the second daisy chain. This creates a new daisy chain.
  5. Click (End daisy chain) to complete the daisy chain.

    A horizontal line is created beneath connection point -F4:1 in the Connections table.
  6. Select connection point -F4:1 in the third daisy chain, then click the (Move up) button to move it to the second daisy chain.

    This breaks up the third daisy chain and connects connection point -F5:1 to connection point -F4:1.
  7. Click [OK] to close the Properties <...> dialog for the net definition point, then start a new project check.

Regarding option 3

You will find a detailed description in the Help under P005047: Net definition point contains incomplete connections.

Regarding option 4

You will find a detailed description in the Help under P005050: Duplicate ID for net-based connections within a net <x>.

Note:

EPLAN provides the possibility to automatically connect associated distributed terminals (menu items Options > Settings > Projects > "Project name" > Devices > Terminals > Settings (distributed terminals)), even if no drawn connections between the distributed terminals exist. However, this functionality is only effective if a net definition point determines the connections. At least one of the distributed terminal connection points occurring several times in the net so that the message "P005046: Incomplete net" is not output during configuring with distributed terminals.

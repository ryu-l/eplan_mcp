Tab Settings: Design space export

Dialog call:

Options > Settings > User > Interfaces > Design space import and export. Select the Export tab.

You define the settings for exporting XML and STEP files with design spaces in this tab.

One STEP file each is exported for each part placed with EPLAN Pro Panel during the data export. One XML file is created for each layout space during the data export. The XML file contains the data of all the objects in the layout space. These are the objects imported from the CAD system, the objects added using EPLAN Pro Panel, the cut-outs generated automatically through a part placement and manually inserted cut-outs.

The XML file contains a referencing to a concrete STEP file that has been exported together with the XML file for each part placed with EPLAN Pro Panel.

Overview of the main dialog elements:

Output directory:

In this case you specify the storage location for the XML and STEP files to be exported. You can specify any drive and subdirectory as the target for the export. The default directory is the directory for mechanical models $(MD_MECHANICALMODELS).

Click [...] to open the Select directory dialog and then navigate to the desired directory, or create a new one.

XML file group box

Generate file names:

When it comes to the file name settings for the XML file, you have the following options:

  • From consecutive number
  • From layout space name
  • From properties.

In the properties, you can access layout space properties, project properties, and separators.

3D mounting data:

If this check box is activated, the 3D mounting data are exported into the XML file.

NC data:

If this check box is activated, the NC data are exported into the XML file.

STEP file group box

Generate file names:

When it comes to the file name settings for the STEP file, you have the following options:

  • From consecutive number
  • From layout space name
  • From properties.

In the properties, you can access layout space properties, project properties, and separators.

Format version:

The following options are available for format versions:

  • STEP AP 203
  • STEP AP 214, CD version
  • STEP AP 214, DIS version
  • STEP AP 214, IS version.

Auxiliary elements:

If this check box is not activated, the following auxiliary elements are not exported:

  • Routing paths
  • Routing ranges
  • Wiring cut-outs
  • Restricted drilling areas
  • Restricted placing areas
  • Cut-outs.

Routing connections:

If this check box is activated, the routing connections existing in the layout space are also exported in STEP format. After the import of the resulting STEP file into an external CAD program, the routing connections can be displayed there.

Group box Simplified representation

In this group box you specify whether items - similar to the representation in the layout space - will be exported in a simplified manner:

  • Terminal strips (block definition): If this check box is activated, the terminal strips are exported as a simplified block.
  • 3D macros: If this check box is activated, the graphical macros, rails, and wire ducts are simplified into a cuboid.

Improvements in the Dialogs for the PLC Data Exchange

The PLC data edited in EPLAN can be exchanged with the PLC configuration programs of various manufacturers. To do so select the desired PLC configuration program and file format when exporting PLC data. This selection has now been structured more clearly.

Benefit:

Thanks to the new setting options for the PLC configuration program and the format of the export file, the desired file format can be selected more easily and more intuitively.

In the past all available combinations of PLC configuration programs and formats were displayed in the Format of export file field of the Export PLC data dialog. You reach this dialog via the menu path Project data > PLC > Export data. For certain formats you can branch into a subsequent dialog via the [Options] button and specify the export version or the output type there.

Now you select the desired PLC configuration program in the new PLC configuration program field. This drop-down list displays all available combinations of manufacturers and PLC configuration programs.

The supported formats are displayed in the drop-down list of the Format of export file field depending on the PLC configuration program selected in the PLC configuration program field. The selection of different export versions or output types is effected via separate list entries.

The [Options] button is active when an AutomationML format has been selected in the Format of export file field. In the Settings: AutomationML export dialog you specify the degree of detailing for an export file in the AutomationML format.

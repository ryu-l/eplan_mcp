Displaying / Filtering Frozen Report Pages

This functionality allows you to filter by Frozen report pages. You can also display the number of frozen report pages from the project statistics.

Preconditions:

  • You have opened a project.
  • You have frozen report pages.

Display the number of frozen report pages

  1. Select the following menu items: Page > Navigator
  2. Select a structure identifier layer.
  3. Select the menu items Project > Properties.
  4. In the Project properties - <Project name> dialog, select the Statistics tab.

    The number of frozen report pages for each page type is displayed in the Frozen pages column.

Filter frozen report pages

  1. Select the following menu items: Page > Navigator
  2. Click [...] next to the Filter field in the page navigator.
  3. Click (New) next to the Scheme field in the Filter dialog, and create a new scheme in the subsequent dialog.
  4. Click (New) in the toolbar for the filter criteria.
  5. Select the Frozen report page property in the Criteria selection dialog below the "Properties" hierarchical level.
  6. Activate the associated check box for this criterion in the Value column of the Filter dialog.
  7. Click [OK].

    The filter just created is entered automatically in the Filter field of the page navigator and activated.

    All non-frozen report pages are hidden. Only the frozen report pages are displayed.

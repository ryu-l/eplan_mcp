P005014: Connection and connecting point have differing connection point types

Cause

You entered the same connection point type of the function connection points of a connection's targets. You also gave the connection a connection definition point and a function definition which doesn't correspond to the connection point type of the targets.

Note:

This message is not output under the following conditions:

  • the connection is of type "Jumper"
  • the connection is of type "Saddle jumper"
  • the connection is of type "Wire jumper"
  • the connection is of type "Switching jumper"
  • the connection is of type "Internal jumper"
  • the connection is of type "Insertable jumper"
  • the connection is of type "Direct connection"
  • the connection is of type "Undefined"
  • the connection point is of type "Undefined".

Solution

Assign the same connection point type to the connection definition point and the connection targets.

Refresh the connections and then start a new check run.

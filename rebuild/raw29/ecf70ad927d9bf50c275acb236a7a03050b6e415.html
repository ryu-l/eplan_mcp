Creating Device Tag List Cross-references

For all main functions and auxiliary functions in the schematic, an extra cross-reference can be created and displayed that points to the device tag list containing the respective device. The cross-reference can be identified by marker text, a special character that allows it to be distinguished from other cross references.

Preconditions:

  • You have opened a project.
  • You have created a multi-line schematic page.
  • Under Options > Settings > Projects > "Project name" > Cross-references / contact image > Display in the Display device cross-references group box, you have specified that cross-references between multi-line schematic pages and pages of type "Device tag list" are to be displayed, and vice-versa.
  1. Open the multi-line schematic page in the graphical editor and insert a few symbols, e.g., a transformer, a fuse, and a signal lamp.
  2. In the Properties <...> dialog, in the <Function category> tab, enter the respective values for each of the components in the Displayed DT field, for example "-T1" for the transformer, "-F1" for the fuse, and "-H1" for the signal lamp.
  3. If not already selected, select the Main function check box for every component.
  4. For each component switch to the Parts tab, and use parts selection to assign a suitable part number to each component.
  5. Click [OK].
  6. Select the menu item Utilities > Reports > Generate.
  7. In the Reports - <Project name> dialog, click (New).
  8. In the Select report dialog, in the Select report type list, select the "Device tag list" entry and click [OK].
  9. In the Settings - Device tag list dialog, click [OK].
  10. In the Device tag list <...> dialog, enter the appropriate structure identifier for the classification of the device tag list in the project, define the page number and click [OK].

    The device tag list is created.

    Cross-reference information is now displayed at the main functions of the components in the schematic, which points to the appropriate components in the device tag list. Conversely, cross-reference information is now displayed in the device tag list, which points to the associated main functions of the components in the schematic.
  11. Close the Reports - <Project name> dialog.
  12. Open the schematic page and the device tag list in separate editors to observe the cross-reference display.

Example:

The transformer -T1, the fuse -F1, and the signal lamp -H1 in the schematic (left side of the illustration) point to the appropriate components in the device tag list (right side of the illustration). Conversely, the cross-references in the device tag list point to the appropriate components in the schematic.

Display device tag list cross-references to auxiliary functions

If you wish device cross-references from distributed displayed devices in the schematic also to be displayed at the auxiliary functions, then proceed as follows:

  1. Select the Options > Settings > Projects > "Project name" > Cross-references / contact image > General menu items, and activate the Auxiliary functions also refer to the device tag list check box.
  2. Click [OK].
  3. Update the display using the menu item View > Redraw.

Mark device tag list cross-references

To use a marking for highlighting device cross-references in the schematic, proceed as follows:

  1. Select the Options > Settings > Projects > "Project name" > Cross-references / contact image > General menu items and, in the Marker for group box, enter a marker text character in the Device tag list field.
  2. Click [OK].
  3. Update the display using the menu item View > Redraw.

# Inserting Connection Symbols

Connection symbols are managed in the SPECIAL.slk symbol library. They represent the flow of connections and have no function definitions.

### [ClosedInsert angles](javascript:void(0);)

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the Insert tab in the ribbon.
2. Select the button of the desired angle in the command group Symbols.
3. If required hold down the [Ctrl] key and move the mouse to page through the existing variants.
4. Place the angle on the page.
5. Proceed this way for all additional angles that you would like to insert on the page.
6. End the action via the Cancel action popup menu item or via the [Esc] button.

### [ClosedInsert T-nodes, double junctions, and jumpers](javascript:void(0);)

Preconditions:

- You have opened a project. You have opened a project page in the graphical editor.
- In the Settings: Connection symbols dialog you have selected the option With target specification or as point or if you select a different option, the check box Connection symbols with prompt is activated (command path: File > Settings > User > Graphical editing > Connection symbols).

1. Select the Insert tab in the ribbon.
2. Select the button of the desired connection symbol in the command group Symbols. With the button ![](../Pictures/Gui/ALL/ribbon_galleryfurther_as.png) (More) you can expand the field with the symbols and select the desired connection symbols below the Connector field.
3. In the subsequent dialog select the desired target-specific variant.
4. Select the Draw as point check box if you want the connection symbol to be drawn as a connection point.
5. Click [OK].
6. If required hold down the [Ctrl] key and move the mouse to page through the existing variants.
7. Place the connection symbol on the page.
8. Proceed this way for all additional connection symbols of this type that you would like to insert on the page.
9. End the action via the Cancel action popup menu item or via the [Esc] button.

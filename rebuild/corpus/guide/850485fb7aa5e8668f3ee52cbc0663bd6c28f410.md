# Creating and Editing Pins

You either create pins in the graphical editor, by placing a pin and specifying its properties in the properties dialog. The plug navigator and device navigator allow you to predefine pins with specific Properties which you can place at a later date.

When you create a pin, specify whether it's a male, a female, or a male/female combination, and then edit its properties. You can create a pin with predefined properties using the function definitions.

In the [Pin](devicetaggui_r_steckerkontakt.htm) tab of the property dialog, you can edit the properties of a plug.

### Create pins

1. Select the following commands: Tab Devices > Command group Plugs > Navigator.
2. Highlight a plug definition or a pin below a plug definition.
3. Select the Generate pin popup menu item and subsequently one of the subitems Male and female pin, Male pin, or Female pin.
4. In the Properties <...> dialog in the Pin tab, enter the data you want for the new pin.
5. Click [OK].

![](../Pictures/Gui/ALL/info.png)Tip:

The New functions popup menu item allows you to create several pins at the same time.

### Create pins with predefined properties

1. Select the following commands: Tab Devices > Command group Plugs > Navigator.
2. Select a DT or a plug definition, and select the New popup menu item.
3. In the Function definitions dialog in the Selection field, page through the tree structure and mark a pin.
4. Click [OK].
5. In the Properties <...> dialog, go to the Pin (or Male pin or Female pin) tab to enter the desired data for the new pin.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) A pin with the corresponding properties is created beneath the selected DT.

![](../Pictures/Gui/ALL/info.png)Tip:

You can copy and place pins using Drag & Drop, by dragging a highlighted pin from the navigator onto the open schematic page in the graphical editor.

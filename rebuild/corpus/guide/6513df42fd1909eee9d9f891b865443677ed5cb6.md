# Manually Updating a Report

When running manual updates, all selected reports belonging to a report block are always updated.

Preconditions:

- You have created report pages.
- You have opened the project with the report pages in the navigator dialog Pages - <Project name>.

### Update in the page navigator

1. Select a structure identifier layer from the Pages - <Project name> dialog.
2. Select the following commands: Tab Tools > Command group Reports > Update.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All report pages and all embedded reports below the structure identifier layer will be updated.

### Update in the report overview

1. Select the following commands: Tab Tools > Command group Reports > Generate.
2. Select the Reports tab, and select a report layer in the tree structure.
3. Click ![](../Pictures/Gui/ALL/all_update_as.png) (Update).  
     
   ![](../Pictures/Gui/ALL/arrow.png) All reports at the selected report level and all subordinated reports are updated.

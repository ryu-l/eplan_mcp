# P027026: Connection splicer <x> is missing in the topology representation

### Cause

The schematic contains a multi-line connection splicer whose counterpiece was deleted in the topology. Since the connection splicer is missing in the topology representation, the connections through the routing path network could not be routed or not routed completely.

### Solution

1. Locate the multi-line counterpiece of the connection splicer missing in the topology representation in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the dialog Properties <...> of the connection splicer and remember the displayed DT.
3. Place the missing connection splicer in the topology and insert it into the routing path network.
4. Assign the displayed DT of its counterpiece located in the multi-line representation to it.
5. Start a new check run after you have changed the device tags in order to delete the message.
6. Route the connections through the routing path network again.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

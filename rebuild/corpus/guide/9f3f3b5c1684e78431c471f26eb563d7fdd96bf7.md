# Dialog Sign in to Eplan

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You are using the "Sign in" operating mode. Start Eplan.

In this dialog you sign in using your user name and password. This dialog is automatically displayed when Eplan starts.

Overview of the main dialog elements:

Name:

Enter the user name here.

Password:

Enter your password here. To ensure protection of your input, the password is not displayed in plain text but rather as \* characters.

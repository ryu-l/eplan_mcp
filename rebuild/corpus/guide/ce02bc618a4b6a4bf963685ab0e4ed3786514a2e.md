# Dialog Results of property comparison - <Project name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have executed a property comparison of projects and opened a project. File > Revision control > Command group Project > Property comparison > Show results of the properties comparison.

This dialog displays the results of a property comparison of projects. The data is read from the revision results list in which the results of the property comparison were saved. (This list is stored in the project database of the current project.) To enable a quick overview of the results, not all entries from the revision results list are shown. Only the number of entries specified in the project settings under Maximum number of displayed results is shown.

Overview of the main dialog elements:

The following columns are shown in the table (can be set via the popup menu item Configure representation):

- Object type: Shows the object type, for example, Function, Image file, etc.
- DT / Name: Shows the complete DT of the function or the name of the object. For connections, the source and target are displayed; for projects, the project name is shown including file path; for image files, the file name is shown with file path; and for hyperlinks, the designation is shown.
- Page of the object: Shows the page where differences were found.
- Kind of change: Shows whether the object was changed, deleted, or newly inserted.
- Property: Shows the changed property.
- Previous value: Shows the value of the property in the reference project.
- New value: Shows the value of the property in the current project.
- Part number [1]: Shows the first part entered at the function.
- Name of potential: Shows the name of the potential for connections to which the connection is connected.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Select all | Selects all of the entries in the list. |
| Copy | Copies the content of the selected fields to the Clipboard. |
| Reset to old value | Resets the value of the marked property to the value of this property in the reference project. Multiple selection is possible. Only properties that can be written can be reset (for example Function text, Engraving text, Remark). Automatically determined properties (for example Function text (automatic)) cannot be reset. A corresponding note is displayed in this case. The changes are only visible at the object in the project, the display in the dialog is not changed. The revision marker of the objects also remains unchanged. In order to update the revision markers you have to delete them and then carry out a new project comparison. |
| Go to project (graphic) | Takes you to the associated placed object in the current project. |
| Go to reference project (graphic) | Takes you to the associated placed object in the reference project. |
| Synchronize selection | Marks the associated object in the opened navigators. |

![](../Pictures/Gui/ALL/info.png)Tip:

It is possible to carry out a synchronization in the Results of property comparison - <Project name> dialog for certain objects (functions, connections, potentials, PCT loops, PCT loop functions) having a revision marker in the graphical editor. To do this, mark the object and then select popup menu item Synchronize selection. The corresponding lines in the list of results will be marked.

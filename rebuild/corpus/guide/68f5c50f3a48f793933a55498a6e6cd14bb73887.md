# Tab Bending positions

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The project contains at least one layout space. The layout space contains placed busbars (bending). You have opened the layout space navigator. Select a busbar in the layout space navigator. Select the Properties popup menu item. In the Properties (components): Part placement (3D) dialog, select the Bending positions tab.

On this tab, you can modify the bending radii of the individual bending positions. The bending angle is also displayed for information purposes, but cannot be modified here.

Overview of the main dialog elements:

Bending positions:

The bending positions available on the item are listed.

Bending angle:

Display of the bending angle of the entry highlighted in the Bending positions field.

Bending radius:

The current bending radius of the entry highlighted in the Bending positions field is displayed and can be modified.

Status:

A comment text in this line displays whether the bending angle and / or bending radius is / are contained in the bending table in the Settings: Copper bending dialog. If the entries are missing from the bending table, the item cannot be unfolded.

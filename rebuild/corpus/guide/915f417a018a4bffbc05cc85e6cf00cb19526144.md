# P005075: Differing substances within a piping

### Cause

In the P&I diagram there are several piping definitions (piping connection points or piping definition points) which have contradictory values with regard to the Substance property at a connection.

### Solution

1. Locate the affected piping definitions by means of the functionalities Go to (graphic) or Go to (2nd coordinate), which the popup menu of the Message management dialog offers you.
2. Open the properties dialog for each piping definition and enter the same value in the Substance field.
3. If required, start a new check run.

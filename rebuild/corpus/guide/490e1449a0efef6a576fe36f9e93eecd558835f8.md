# Format Elements for Export / Labeling File / External Report File

You use format elements to define which export / labeling data / project data in export / labeling files / external report files is to be output.

You can also use format elements to define formatting properties, e.g., line breaks and page breaks. The following table shows some of the available format elements:

| Format element | Header | Label | Footer |
| --- | --- | --- | --- |
| Property: Specifies which project data to output to the export / labeling file / report file. | x | x | x |
| Separator: Inserts a separator after an export text / label text / report text. | x | x | x |
| Line break: Inserts a line break after an export text / label text / report text. Enables a multi-line text. | x | x | x |
| Page break: Generates a page break |  |  | x |
| Page break when change of DT: Generates a page break when the value of the device tag changes. |  |  | x |
| Calculation: Allows the creation of a calculation formula. |  | x |  |
| Action: Allows an action to be stored. |  | x |  |

# P005081: Unrealistic continuous connection at the connection splicer

### Cause

You have placed a connection splicer within a connection and have set the property "Continuous connection between the connection points" at the connection splicer for specific connection points. With regard to the function definition of the connection a continuous connection is not realistic for the specified connection points. The function definitions "Tube", "Pipe", and the function definitions for all types of jumpers are affected by this. The "Optical fiber" function definition is not checked.

### Solution

1. Locate the connection splicer in the project by using the Go to (graphic) functionality from the popup menu of the Message management dialog.
2. Call up the Properties <...> dialog of the distributor and change the connection point designations in the Continuous connection between the connection points field.  
     
   Or delete the placed connection splicer, or change the function definition of the connection on which the connection splicer was placed.
3. If required, start a new check run.

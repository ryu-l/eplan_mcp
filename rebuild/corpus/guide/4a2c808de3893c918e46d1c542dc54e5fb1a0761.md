# Configuring Wire Fabrication Machine

Representative for all wire fabrication interfaces, here the configuration of a machine for the "General wires parts list" format is described. The configuration of the machines of the other interfaces is done in the same manner, but differs in terms of the values to be entered in the settings dialog.

1. Select the following commands: File > Settings > Company > Wire fabrication > General wires parts list.
2. In the Settings: General wires parts list dialog, select the scheme of the required machine.
3. Modify the settings on the tabs as needed, or generate a new machine definition with the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The set machine data is available at the time of the export in the export dialog under the associated machine name.

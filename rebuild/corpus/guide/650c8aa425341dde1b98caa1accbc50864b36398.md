# Inserting Dynamic Connection Symbols

Dynamic connection symbols are managed in the SPECIAL.slk symbol library. Dynamic symbols are symbols without fixed graphics. These include:

- Dynamic symbols for diagonal connections
- Cable definitions
- Shields
- Connection definition points
- Potential definition points
- Potential connection points.

### Insert dynamic symbols for diagonal connections

It is often the case that a phase rotation must be generated over diagonal lines. Dynamic symbols are used to draw these connections over diagonal lines.

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the following commands: Tab Insert > Command group Symbols > ![](../Pictures/Gui/ALL/ribbon_diagonalconnection_as.png) (Diagonal connection).
2. If required, hold down the [Ctrl] key and move the mouse to change the direction of the connecting points.
3. Consecutively place the starting point and the end point of the diagonal connection line.
4. Proceed in a similar manner for all further diagonal connection lines.
5. End the action via the Cancel action popup menu item or via the [Esc] button.

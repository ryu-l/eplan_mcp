# Dialog Symbol properties - <Library name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Tab Master data > Command group Symbols > Drop-down button Symbol library > New. If multiple symbol libraries are open, select the symbol library in which you would like to create the symbol in the Symbol library selection dialog. Select the symbol variant to be generated.
- You have opened a project and you have opened a symbol from the symbol library that you would like to edit in the symbol editor. Select the popup menu item Properties for the symbol in the tree or list view of the Pages - <Project name> navigator dialog.

In this dialog you specify the properties for the newly created or the opened symbol.

Overview of the main dialog elements:

Symbol number:

The symbol number indicates the position of the symbol in the symbol library. This number is used by Eplan internally for report-related purposes and is unique to each symbol library. A new number from the drop-down list can be assigned to the symbol. The unallocated numbers are shown in the list.

Symbol name:

The symbol name usually starts with the device identifiers (default) and can contain be any number of characters. In this field you can make the appropriate entries or select the name from the drop-down list. All existing symbol names from the library are displayed.

Function definition:

If the symbol logic is to be changed, click [...] in this field to open the Function definitions dialog.

Connection points:

This field is available if you have selected a function definition with the supplement "variable" for a variable number of symbol connection points in the Function definition field.

[Logic]:

Opens the Connection point logic dialog. Displays the connection point data for the function definition that you assigned to the symbol in the Function definition field. Enables you to adapt the connection point data to the symbol. If you select a different function definition, the symbol-specific connection point data are replaced by the connection point data for the other function definition and can be symbol-specifically customized again. When inserting the symbol into the schematic the symbol-specific connection point data are used, if these deviate from the connection point data of the function definition at the function. This functionality can be useful, for example, if you need a special logic for specific symbols.

Property name / Value list:

The available properties are displayed depending on the selected category. Some of them, for example "Creator", "Last editor", and "Creation date" have already been assigned values that can't be changed. Others, for example "Symbol description" and "Version", can be assigned values or their existing values can be changed.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# P022004: Multiple connection points of the same direction or identical symbols have been placed on top of each other

### Cause

You have connected at least two symbols with connection points of the same connection point direction in the schematic in such a way that the connection point of a symbol overlaps the connection point of another symbol.

In rare cases the usage of a script via the Application Programming Interface may also cause that two identical symbols (same variant) were placed in a way that their insertion points lie on top of each other.

### Solution

1. Locate one of the symbols in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Move the symbol or both symbols in such a way that the autoconnecting line becomes visible between their connection points. If in rare cases the insertion points of identical symbols lie on top of each other, then move the symbols so that their connection points cannot influence each other.
3. If required, start a new check run.

# Updating Part Dimensions

The dimensioning of the parts can be subsequently changed, consequently necessitating an update.

Precondition:

You have opened a project.

1. Select the following commands: Tab Devices > Command group 2D panel layout > Navigator.
2. In the graphical editor, open the panel layout page for which the update is to be performed.
3. Select the Update part dimensions popup menu item in the navigator.
4. Click [Yes], to adopt the new part dimensions.
5. Click [Yes] for each further part.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The current part dimensions are added to the part placements. In the process, the current dimensions of the part are internally checked for every part and for every differing value, a message is displayed allowing you to accept or discard the update.

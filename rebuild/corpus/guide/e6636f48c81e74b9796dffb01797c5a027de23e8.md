# Tab Status

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Tab Home > Command group Page > Navigator. Select a project. Select the following commands: File > Information > Command group Project properties > Status.
- You have opened a project. Tab Home > Command group Page > Navigator. Select a project. Select the Properties popup menu item. In the Backstage view Information select the command Status.
- You have selected a project management database. You have loaded directories and projects. File > Project management. Select a project. Select the Status tab.

The last test runs are displayed in this dialog, with the status and number of generated messages.

![](../Pictures/Gui/ALL/note.png)Note:

If you have performed a test run and the information is not displayed in the project management or not updated, then click [Extras] > Update data.

Overview of the main dialog elements:

Project checks:

This column contains all available message classes of the check runs.

Date of project check:

This column shows the date on which each check run was last performed.

Version:

This column shows the program version of Eplan. The program version is shown in the Backstage view Help (File > Help > Command group Information > Product).

Build no.:

This column shows the build number of Eplan. The build number is shown in the Backstage view Help (File > Help > Command group Information > Product).

Test scheme:

This column shows the scheme used for the check run, for example "Offline" or "Interruption points".

Errors / Warnings / Notes:

These columns show the status and number of messages generated by a check run for every message category. The messages are generated when executing the error checking and are identical with the messages which are shown to you in the message management (Tab Tools > Command group Review > Messages).

Duration:

This column displays the total time in milliseconds that was required to execute the corresponding check runs for each message class.

Click [...] to open a subsequent dialog in which the individual times of the check runs performed are listed. Only values for check runs that were actually executed are displayed.

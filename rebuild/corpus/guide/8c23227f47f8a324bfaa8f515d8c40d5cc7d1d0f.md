# P033006: Cable unit assembly part does not match assembly elements

### Cause

Several causes are possible:

- A different part was entered at the cable unit component in the project than was defined in the cable unit assembly in the parts management.
- A cable unit component that is part of a cable unit assembly was deleted in the project.
- A part was added to the cable unit assembly in the parts management that was however not installed in the project as a cable unit component.
- One or more parts were selected / entered at the cable unit definition that do not suit the cable unit assembly parts defined in the parts management.

### Solution

1. Ensure whether the parts entered at the cable unit components in the project match the parts of the assembly components in the parts management.
2. If lengths are entered in the cable unit assembly, check whether these also exist in the schematic.
3. Also check whether the parts entered at the cable unit definition match the parts of the assembly components in the parts management. The cable unit definition can be located in the project by using the Go to (graphic) function from the popup menu of the Message management dialog.
4. In addition check whether the parts located in the cable unit assembly of the parts management are actually also installed in the project.
5. Adapt the parts to the cable unit components and the parts of the assembly components correspondingly and / or supplement or remove missing or superfluous cable unit components in the project.
6. If required, start a new check run.

# P005025: Too many connections at a connection point

### Cause

At least one of the function connection points of a component is connected with more components than specified.

### Solution

#### Possibility 1

1. Locate the connection definition point in the schematic by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. To do this, double-click the component and switch to the Symbol / function data tab in the Properties <...> dialog.
3. In the Function data (logic) group box click [Logic].
4. Check which values are stored for the function connection points of the component in the Number of targets line in the Connection point logic dialog.
5. Increase your requirements in accordance with the set value for the affected function connection points.

#### Possibility 2

1. Proceed as described under Possibility 1, Point 1 to Point 4.
2. Delete the superfluous components that are connected to the respective function connection point accordingly.

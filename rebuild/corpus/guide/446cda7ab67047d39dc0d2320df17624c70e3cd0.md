# Dialog Settings: Export NC - copper

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > Company > Machining > Export NC - copper
- File > Export > Command group Manufacturing data > Machining > NC - Copper. Click [...] next to the Machine field.

Use this dialog to specify the machine settings for the NC export of copper items.

Overview of the main dialog elements:

Machine:

The delivery scope includes the machine definition named "Default". If you have generated a different machine as a scheme, you can select and edit other machine definitions from the drop-down list.

You can create new schemes, save any changes to a scheme, and copy or delete schemes via the adjacent [Toolbar](schemeconfig_m_schemaschaltflaechen.htm). Schemes can also be imported or exported.

Description:

In this field is the description you entered for the machine in the Description field of the New scheme dialog.

Tabs:

You can use the following tabs to configure the NC export of copper items:

- [Tab General](ncgui_r_allgemeinkupferexportnc.htm)
- [Tab Item](ncgui_r_bauteilkupferexportnc.htm)

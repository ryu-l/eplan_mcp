# P004009: Slot (module) '<x>' of a rack '<y>' assigned several times

### Cause

At several PLC boxes with PLC structure data you also assigned the same slot positions /slots / modules for the same specification of the rack and configuration project.

### Solution

1. Open the Properties <...> dialog for the corresponding PLC boxes.
2. Bring the PLC structure data tab of the boxes to the front.
3. Enter different values in the respective Position (slot / module) fields.
4. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Notes:

- This check run only checks PLC boxes at which a configuration project is entered.
- During this check the property PLC card is placed on head station is also considered. This message is not output if of two PLC cards that have the same slot number one is placed on the rack and the other on the head station. The property PLC card is placed on rack ID means lateral extension, the property PLC card is placed on head station means upward extension.

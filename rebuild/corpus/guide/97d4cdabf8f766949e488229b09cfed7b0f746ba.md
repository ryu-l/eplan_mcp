# P003028: Cable does not use all the cable connections of the part

### Cause

You have placed a cable to which you have assigned a part with fixed function templates (device) in the schematic. When placing the cable you have however used less functions (cable connections) than the corresponding part has. For example, you have selected a part for the placed cable that contains 4 cable connections of which you only use 3 in the schematic.

### Solution

#### Possibility 1

Select a cable part with a suitable function template assignment (number of cable connections).

#### Possibility 2

Reduce the function template assignment (number of cable connections) for the selected part in the parts management.

1. Select the following commands: Tab Master data > Command group Parts > Management.
2. Bring the Function templates tab in the Parts management dialog to the foreground.
3. In the table, highlight the function templates you want to remove and click ![](../Pictures/Gui/ALL/all_delete_as.png) (delete).
4. Copy the changed setting into the parts management.
5. Then place the cable as a device once more in the schematic.
6. Update the connections.
7. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

The message is also output for cables that have not been placed yet.

# Synchronization and Correction Run

Synchronization and correction runs enable you to synchronize project-wide project data and thus remove inconsistencies and contradictions. Below we describe when synchronization and corrections are necessary:

- Devices with duplicate / surplus main functions: A device can only have one main function. To delete duplicate / surplus main functions from a device, you can convert all duplicate / surplus main functions into auxiliary functions with one action for the entire project.
- Redundant data for multiple and different representation types of a function: In Eplan you can distribute the representation of a function in the project, for example as a single-line function, multi-line function, overview function, pair cross-reference function, or P&I diagram function. A function can also multiply in a particular representation type, i.e., a PLC box that is displayed with two multi-line functions on two different pages. The properties of the function can be edited in every representation type. You can synchronize the functions in order to harmonize the properties of the functions that are displayed in a distributed manner.
- Auxiliary function should be a main function: You can convert an auxiliary function into a main function. The original main function becomes an auxiliary function.

# Dialog Paste data

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Master data > Command group Parts > Management. You have opened a parts database using [Extras] > Settings. You have marked the part to be copied in the tree view or in the list view and selected the popup menu item Copy. You have marked the target part(s) in the tree view or in the list view. Popup menu item Paste data.

In this dialog you specify which data of a copied source part is transferred to the target part(s). Data already existing is deleted at the target parts.

Overview of the main dialog elements:

Technical data:

If this check box is activated, the data of the hierarchy level Technical data is copied to the target part.

SPS data:

If this check box is activated, the data of the hierarchy level PLC data is copied to the target part.

Function templates:

Only available when function templates are available at the source part. If this check box is activated, the function templates of the Function templates tab is copied to the target part.

If the Keep existing function templates check box is furthermore activated, the existing function templates at the target parts are not deleted during pasting. In such a case the function templates of the source part are pasted below the existing function templates.

Safety-related values:

Only available when safety-related values exist at the source part. If this check box is activated, the data of the Safety-related values tab is copied to the target part.

User-defined properties:

Only available when user-defined properties exist at the source part. If this check box is activated, the user-defined properties stored in the User-defined properties tab are copied to the target part.

Accessories:

Only available when accessories are stored at the source part. If this check box is activated, the accessory parts and / or accessory lists stored in the Accessories tab are copied to the target part.

Modules:

Only available if both the source part and the target part are modules. If this check box is activated, the parts stored in the Module tab are copied to the target part.

Assemblies:

Only available when both the source part and the target part are assemblies. If this check box is activated, the parts stored in the Assembly tab are copied to the target part.

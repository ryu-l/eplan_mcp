# Inserting QR Codes

A QR code consists of a square formation of black and white squares. Such a code is, for example, used for a coded representation of Internet addresses, phone numbers, WLAN access data, etc. The tedious typing out of this data is no longer required thanks to photographing of the code with mobile devices and its interpretation via app.

In the graphical editor you have the possibility to generate a QR code by means of a menu item from a text, Internet address or properties, and have this displayed on a project page.

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the following commands: Tab Insert > Command group External > QR code.
2. Specify the first corner point of the QR code.
3. Drag the square of the QR code into any direction and define the end point.
4. In the Properties (QR code) dialog select the QR code tab.
5. Enter the text or the Internet address in the Block format field that is to be generated as a QR code and be shown on the project page. If a property is to be used for the QR code, use the [â¦] button to branch into the subsequent dialog Format to select the property and if required further format elements such as separators.   
     
   ![](../Pictures/Gui/ALL/arrow.png) If no entry is made in the Block format field, a QR code without contents is generated.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) When moving a cursor over the square of a QR code, the contents of the code is displayed as a tooltip.

![](../Pictures/Gui/ALL/note.png)Notes:

- Only the starting point or the size of a QR code square can be influenced via the Format tab. Further format settings are not possible.
- The "UTF-8" coding is used by default for the coding of texts in QR codes. However, the "Shift JIS" coding is required for Japanese characters.  
  The project setting [QR code coding](gedviewer_d_einstellungenprojektallgemein.htm#QRCodeCodierung) allows you to customize the coding of inserted QR codes in a project. With the drop-down list of this setting you can switch between the two codings "UTF-8" and "Shift JIS".
- A QR code cannot be edited by using the commands Rotate or Flip (tab Edit > Command group Graphic) since a change in the orientation of the QR code is prohibited during editing.
- To output QR code files on report pages, the Display drop-down list is available for placeholder texts in the Property (placeholder text) dialog on the Format tab below the "Alignment box" hierarchy level. If you select the "QR code" option, you can, for example, store hyperlinks to the manufacturer pages in the "Device tag list" report for the parts used in the project.

![](../Pictures/Gui/ALL/info.png)Tip:

If the generated QR code is an Internet or e-mail address, you can jump to the respective Internet page or start the e-mail program installed on your computer via the Open hyperlink popup menu item.

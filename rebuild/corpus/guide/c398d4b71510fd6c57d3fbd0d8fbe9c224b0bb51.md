# Creating and Deleting the Numbering Formats

If you don't want to use any existing numbering format, you can specify a new numbering format.

Preconditions:

- You have selected devices for numbering in the page navigator, the graphical editor, or in the device navigator.
- You have opened the Number dialog: Tab Devices > Command group Devices > Number.

### Creating numbering format

1. Select [Settings] > Numbering.
2. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the dialog Settings: Numbering (offline).
3. In the New scheme dialog, enter a name in the Name field and a description into the Description field for the numbering format.
4. Click [OK].
5. In the Available format elements field, select a "Page", "Column", or "Row" format element, and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).
6. Specify the number of digits to be displayed for the selected format element in the Minimum number of digits field of the <Format> dialog and click [OK].
7. To define the sequence of the format elements, select an element in the Selected format elements field and click ![](../Pictures/Gui/ALL/all_arrowup_as.png) (Move up) or ![](../Pictures/Gui/ALL/all_arrowdown_as.png) (Move down), as many times as necessary until the element is in the desired position.

### Deleting numbering format

1. Select the format that you want to delete in the Scheme field of the Settings: Numbering (offline) dialog .
2. Click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete).

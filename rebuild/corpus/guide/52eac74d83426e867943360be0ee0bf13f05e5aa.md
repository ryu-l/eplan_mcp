# P001036: Local function templates despite parts with function templates

### Cause

In Eplan the parts make the function templates available. Functions such as terminal strips can, however, also dispose of "local" function templates. Such local function templates at the terminal strip can, for example, be created in the Edit terminal strip dialog via the popup menu. If a part with function templates is now assigned to a terminal strip with local function templates, the local function templates are normally deleted.

The program behavior can be different if you use terminal strips from previous Eplan versions (prior to Version 2.4) in the current project: If such a terminal strip already disposes of local function templates and if a part with function templates is assigned to this terminal strip, it is possible that the local function templates are not deleted. It is also possible that Eplan permitted the generation of local function templates although the terminal strip from the previous version already had a part with function templates. One of these two cases has currently occurred and has resulted in the message being output.

### Solution

The local function templates at the terminal strip cannot be deleted directly.

We therefore recommend the following procedure:

1. First locate the relevant terminal strip in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Select the Properties popup menu item.
3. In the property dialog of the terminal strip bring the Parts tab to the front.
4. Increase the value entered for one of the parts used in the Number of units / quantity field. It is not relevant by which value you increase the number of units or quantity. It is only important that a change took place.
5. Close the properties dialog with [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The local function templates are deleted.
6. Open the property dialog again and correct the previously increased value in the Number of units / quantity field in the Part tab.
7. If required, start a new check run.

# P007034: Assignment of the connection point designations to the connection points does not correspond to the function template

### Cause

You have placed a device in the schematic that has several functions. Subsequently the connection point designations were changed or rotated at a function of the device, for example at an NO contact from "13Â¶14" to "14Â¶13". The connection point designations of the function thus no longer match the connection point designations at the associated function template of the selected part.

### Solution

1. Locate the function in the schematic by means of the Go to (graphic) functionality offered by the popup menu of the Message management dialog.
2. Launch the property dialog of the function.
3. Bring the Parts tab to the front.
4. Look at the connection point designations at the corresponding function template and remember the entered values.
5. Switch to the first tab of the property dialog.
6. Change the values in the field Connection point designation in accordance with the values at the associated function template of the part.
7. Click [OK].
8. If required, start a new check run.

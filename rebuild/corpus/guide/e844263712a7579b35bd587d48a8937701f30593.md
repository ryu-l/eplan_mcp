# Dialog Delete connection designations

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have selected a connection in the graphical editor, or in the Connections - <Project name> navigator dialog. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog. Tab Connections > Command group Connections > Drop-down button Enter designation > Delete designations.

In this dialog you specify whether just the connection designations should be deleted or the empty connection definition points as well.

Once you have called up the menu item, the connections are first automatically newly generated.

Overview of the main dialog elements:

Settings:

Select a scheme defining the settings for the connection numbering from the drop-down list. The filter settings defined in this scheme are taken into account when deleting the connection designations. You can use [...] to open the [Settings: Connection numbering](wirenumberinggui_d_verbnumeinstellungen.htm) dialog where you can edit the filter settings.

Only connection designations:

The designations of all the connection definition points are deleted. The definition points themselves remain.

Empty connection definition points:

All connection definition points that can possess one connection designation only (Valid data field in the properties dialog = "Only connection designation") and whose designation is empty or contains "????" are deleted.

Connection designations and empty connection definition points:

The designations of all the connection definition points are deleted. In addition, those connection definition points that can possess one connection designation only (Valid data field in the properties dialog = "Only connection designation") will also be deleted.

Retain 'manually set' numberings:

If this check box is selected, connection definition points whose connections have the Manually set property will not be deleted and will retain their designation.

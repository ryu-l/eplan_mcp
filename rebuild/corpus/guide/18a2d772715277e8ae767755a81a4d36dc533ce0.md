# Exporting Bills of Materials

You can export all of the parts data from a bill of materials, regardless of the settings or active filters, that is, all of the parts and all of the data fields are output.

Precondition:

You have opened a project.

1. Select the following commands: Tab Devices > Command group Devices > Bill of materials.
2. In the Bill of materials - <Project name> dialog, select the Export popup menu item.
3. In the Export bill of materials dialog select the drive and directory where the export file is to be generated. (To return to the default setting for a directory, click the Eplan icon in the left-hand navigation area and the directory listed below it.)
4. In the File name field, enter the name for the export file to be generated.
5. Select one of the entries defining the format for the export file to be generated, from the Save as type drop-down list.
6. Click [Save].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The bill of materials is exported to the specified directory under the specified name.

Data exported in this manner can then be edited and re-imported. However, only certain fields from the export file are written back during importing. An overview of the fields is provided in the section "[Bills of Materials: Export File Fields](partslistgui_k_felderexportdatei.htm)".

Please note that export and import can only be carried out within the same project.

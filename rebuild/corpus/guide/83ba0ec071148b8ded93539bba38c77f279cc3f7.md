# P033003: Wire harness assembly part does not match assembly elements

### Cause

Several causes are possible:

- A different part was entered at the wire harness component than was defined in the wire harness assembly in the parts management.
- A wire harness component that is part of a wire harness assembly was deleted in the project.
- A part was added to the wire harness assembly in the parts management that was however not installed in the project as a wire harness component.
- One or more parts were selected / entered at the wire harness definition that do not suit the wire harness assembly parts defined in the parts management.

### Solution

1. Ensure whether the parts entered at the wire harness components in the project match the parts of the assembly components in the parts management.
2. If lengths are entered in the wire harness assembly, check whether these also exist in the schematic.
3. Also check whether the parts entered at the wire harness definition match the parts of the assembly components in the parts management. The wire harness definition can be located in the project by using the Go to (graphic) function from the popup menu in the Message management dialog.
4. In addition check whether the parts located in the wire harness assembly of the parts management are actually also installed in the project.
5. Adapt the parts to the wire harness components and the parts of the assembly components correspondingly and / or supplement or remove missing or superfluous wire harness components in the project.
6. If required, start a new check run.

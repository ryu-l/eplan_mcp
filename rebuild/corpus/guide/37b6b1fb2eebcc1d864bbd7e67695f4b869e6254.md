# Copying Plot Frames

To copy a plot frame with all its content, save it to another location and / or under a different name.

Precondition:

You have opened a project.

1. Select the following commands: Tab Master data > Command group Plot frames / forms > Drop-down button Plot frame > Copy.
2. Select the drive and directory of the plot frame to be copied in the Copy plot frame dialog.
3. Select the desired plot frame file. (Multiple selection isn't possible here.)
4. Click [Open].
5. Specify the storage location for the copy of the plot frame in the Create plot frame dialog.
6. In the File name field, enter a descriptive name for the new plot frame.
7. Click [Save].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The plot frame is copied and the copy opened for editing.

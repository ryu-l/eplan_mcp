# Renaming, Deleting a Project (Project Management)

Precondition:

In the tree structure of project management, there is an imported directory with at least one project.

### Rename project

![](../Pictures/Gui/ALL/note.png)Note:

Filed off and archived projects cannot be renamed.

1. Select the following commands: File > Project management.
2. Select the project in the tree structure.
3. Select the Rename popup menu item.
4. Type the new project name.
5. Press [Enter].   
     
   ![](../Pictures/Gui/ALL/arrow.png) If you enter the name of an existing project here, a confirmation prompt appears then this project is overwritten and moved to the Windows-specific recycle bin.

### Delete project

1. Select the following commands: File > Project management.
2. Select the project in the tree structure.
3. Select the Delete popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project file and the project directory, and any data that it contains is deleted and copied to the Windows-specific recycle bin. If required, the project can be restored from there.

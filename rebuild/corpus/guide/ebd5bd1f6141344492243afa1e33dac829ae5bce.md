# Data of the Generated Macros

Macros created or automatically generated in Eplan contain the following data:

- Macro name
- Version
- Source project
- Description
- Source / reference.

In the Source project property, Eplan enters the project where the macro was originally created. The Version and Source / reference properties can only be edited in a macro project. These fields remain empty for macros created in a standard manner in a schematic project. When inserting macros this data is displayed for you in a comment field.

All macros also have page data. This allows you to insert a window or symbol macro as a page macro. If this macro is inserted as a cut-out of an existing page, the "page" in the macro is ignored.

Function definitions, symbols, parts, forms and plot frames are not stored in the macro. Only the sources and numbers / names are stored at the macro.

If you insert a macro and one of the data referenced in the macro (for example a symbol library) is not contained in the current project, this can result in the macro not being displayed. In such a case you have the possibility to synchronize and / or complete project master data in the Master data tab in the Part command group. In addition, you can synchronize and / or complete the project part data with the master data parts by using the following commands: Tab Master data > Command group Part > Synchronize.

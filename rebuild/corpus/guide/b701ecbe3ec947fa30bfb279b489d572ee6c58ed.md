# Dialog Settings: Identifier

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > User > Display > Identifier

In this dialog you can specify how new structure identifiers should be handled when created.

Overview of the main dialog elements:

Enter new identifiers in alphabetical order:

You can use this option to specify that all new structure identifiers should be sorted into the various identifier tables in alphabetical order.

Add new identifiers to the end:

You can use this option to specify that all new structure identifiers should always be added to the end of each identifier table.

![](../Pictures/Gui/ALL/info.png)Tip:

If necessary, you can also set another sorting of new structure identifiers in [structure identifier management](pleditorgui_d_kennzeichen.htm) later on.

# Tab Settings (Komax - Zeta)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > Company > Wire fabrication > Komax - Zeta > Tab Settings
- File > Export > Command group Manufacturing data > Wire fabrication > Komax - Zeta. Click [...] next to the Scheme field. Select the Settings tab.

In this tab, information on the technical options of the machine to be used is stored. The individual settings are pre-set with appropriate values in a machine-specific manner, and can be modified here.

![](../Pictures/Gui/ALL/note.png)Note:

If you do not enter a measuring unit, "mm" is assumed for the length specification and "mm²" for the cross-section specification. If you want to specify the connection length in "Inch" or the connection cross-section in "AWG", enter the respective measuring unit explicitly. During the export the conversion required for the machine from "Inch" to "mm" is then carried out, but "AWG" is not converted.

Overview of the main dialog elements:

Min. connection length:

Minimum length the machine requires to handle the wire as defined (default value: 240 mm). Shorter wires are transferred to the machine with this minimum length.

Max. connection length:

Wires that are longer than specified here cannot be processed by the machine (default value: 3,000 mm).

Min. connection cross-section:

Minimum cross-section of a wire that the machine can still process.

Max. connection cross-section:

Maximum cross-section of a wire that the machine can still process (default value: 6 mm²).

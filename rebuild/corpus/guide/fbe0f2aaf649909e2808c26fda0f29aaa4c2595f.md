# P008002: Text box is empty

### Cause

You have tried to translate the text in a text field for a graphical text or for a path function text without entered string.

### Solution

1. Have the affected text displayed in the project from the Message management dialog by means of the Go to (...) functionalities.
2. Open the property dialog of the text field.
3. Fill the affected text field with a text and translate it.

![](../Pictures/Gui/ALL/note.png)Note:

This module-specific message is output during the automatic translation of texts. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

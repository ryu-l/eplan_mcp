# XML Export / Import: Overview of Tags and Attributes

Parts data import and export is done using an XML file, which must be structured as follows:

![](../Pictures/Visualisation/ALL/xmlexport_example_av.png)

![](../Pictures/Gui/ALL/note.png)Notes:

- The <partsmanagement> tag may only be defined once! All other tags can be defined several times and can also be omitted, for instance, if you have defined a variant without function template or a drilling pattern without data.  
  Exception:  
  At least one variant (<variant> tag) must always be defined for a part (<part> tag)!
- The tag <variantx> below the tag <variant> has the properties (attributes), which before Version 2022 were only assigned to the part (tag <part>) and which are now variant-dependent. The <variantx> tag can only be used as of the second variant and contains differences from the first variant.  
  Exception:  
  The attribute P\_ARTICLE\_PARTNR (part number) must only be defined for the <part> tag.

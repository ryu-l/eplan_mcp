# Inserting Model Views

Model views are standardized 2D views of the 3D mounting layout, for example of equipped mounting surfaces.

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the following commands: Tab Insert > Command group View > Model view.
2. Press [Enter] or click to specify the first corner of the area for the model view at the current cursor position.
3. Open a frame by using the arrow buttons or by moving the mouse. You can open the frame in any direction.
4. End area selection with [Enter].
5. Define the data specific to the model view on the View tab of the Model view dialog.
6. On the Display tab, define the display settings for describing the model view, such as font size, alignment and width / height of the alignment box.
7. On the Format tab, define the graphical properties of the model view border, such as the starting point, end point, and width as well as further format properties.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Model view dialog closes and the model view is placed on the page according to the settings.

# Defining a Handle

A handle is used to place a 3D macro. In addition to the handles, which are generated automatically for 3D objects, there is a user-defined handle in the macro. When placing an item in the project, select this handle in the placement options in the Handle field under the name "Graphical macro".

Preconditions:

- You have opened a project.
- You have opened the layout space navigator and a layout space.
- The layout space contains imported 3D objects which are to be saved as a macro.
- Object snap is switched on.
- The Mounting aid button is activated for the view in the layout space.

1. Select the following commands: Tab Insert > Command group Mounting aids > Handle.
2. Move the cursor over the 3D geometry.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The 3D snap points of the object are displayed. These are the end or center points of an edge or the corner points of a cuboid surrounding the object.
3. Click the required point.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The handle is identified by an orange cuboid.
4. To move the handle to another location, execute the steps 1 to 3 again.
5. To define the extended handle logic, edit the properties of the handle.

![](../Pictures/Gui/ALL/info.png)Tip:

During the creation of macros (Tab Master data > Command group Macros > Create) you can change the handle in the dialog Save as by means of the menu item Define handle that is located below the button [Extras].

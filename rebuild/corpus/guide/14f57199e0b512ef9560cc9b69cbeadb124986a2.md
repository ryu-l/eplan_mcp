# Dialog Settings: Connection category

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > Company > Management > Connection category.

In this dialog you determine the connection categories which are offered and used as defaults when managing connection point patterns in parts management.

Overview of the main dialog elements:

Table:

The Number column displays the consecutive number which defaults the sequence in which the connection categories are displayed in the drop-down list in parts management. Under Connection category (default), you will see the default names of this data. Grayed-out entries are defaulted by Eplan and cannot be edited by you; all other designations for the connection categories can be assigned by you and be deleted again, if necessary.

The following connection categories correspond to the ECLASS classification and should be used when new connection point patterns are created:

- Screw connection
- Spring pulley connection
- Push-in connection
- Penetration connection
- Insulation-displacement connection
- Plug-in connection
- Push-wire connection
- Bolt connection
- Flat plug-in connector
- Crimp terminal
- Band connection
- Rail connection
- Soldering lug connection
- Wrap post

The following connection categories are still available for compatibility reasons but should not be used anymore in future when new connection point patterns are created:

- Screw clamp connection single (do not use anymore)
- Screw clamp connection double (do not use anymore)
- Cage clamp connection (do not use anymore)
- Screw-type connection (Ring or U cable lug), (do not use anymore)
- Ferrule connection (cable lug), (do not use anymore)
- Plug connection (do not use anymore)
- Conductor plate connection (do not use anymore)
- Plug-in connection (Fluid), (do not use anymore)
- Nipple (do not use anymore)
- Compression nut (do not use anymore)
- Compression fitting (do not use anymore)

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# Creating / Selecting a Project Management Database

Always begin project management in connection with a project management database. All information displayed in the project management is contained in this database. Project management can be based on an internal Eplan database or an SQL server database. The name of this database can be freely selected. An Eplan database with the name Projects.db is preset by default.

### [ClosedCreate a project management database](javascript:void(0);)

Precondition:

You have not yet created a project management database.

1. Select the following commands: File > Settings > User > Management > Project management database.
2. Use the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button in the dialog [Settings: Project management database](prjmanagementgui_d_prjverwaltungsdb.htm) to create an Eplan database or an SQL server database.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected the SQL server option, the [Generate SQL server database](modaldialogsdb_d_sqlserver.htm) dialog is opened to this purpose.
3. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The newly created database will then be entered in the settings as project management database and is therefore automatically selected.

![](../Pictures/Gui/ALL/note.png)Note:

A message is displayed if you open the project management without a project management database having being created and selected. When you confirm these, the Project management database dialog is opened where you can create or select the project management database.

### [ClosedSelect Eplan database](javascript:void(0);)

Precondition:

You have created an Eplan project management database or have access to an Eplan project management database.

1. Select the following commands: File > Settings > User > Management > Project management database.
2. Click [...] next to the Eplan field in the Settings: Project management database dialog.
3. In the file selection dialog, navigate to the directory where your project management database is stored. Select the desired file.
4. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The database is entered in the settings as project management database.

### [ClosedSelect SQL server database](javascript:void(0);)

Precondition:

You have created an SQL server database or have access to an SQL server database.

1. Select the following commands: File > Settings > User > Management > Project management database.
2. Select one of the last 15 SQL databases used from the SQL server drop-down list in the dialog Settings: Project management database. The databases used last are listed at the top.   
     
   ![](../Pictures/Gui/ALL/arrow.png) When a new database that is not yet contained in the list is opened / generated , the lowest database may be removed from the list.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The list can be emptied with the exception of the database currently being used via the popup menu item Delete entries.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The database is entered in the settings as project management database.

# External Editing: Functionality

During external editing only the data of a specific object are always output (for example devices, cables, pages, etc.). You specify the object that is to be exported in the settings during the creation of a scheme via the so-called [object type](macrosgui_d_pxfeinstellungenexport.htm#Objekttyp).

The data is always output without formatting. Only the column order of the editable data can be changed.

The data is sorted so that cross-referenced functions are output together, and pages are sorted in the same sequence as they are sorted in the project. Connection definition points without a DT cannot be output.

Imports and exports can also be carried out by means of [Eplan actions](availableactions_k_start.htm), by explicitly activating the action and running the associated program function automatically.

### [ClosedNon-importable data](javascript:void(0);)

Some types of data can be output for information but have to be ignored in the import. This applies to the following indirect data types:

For functions:

- Full DT
- Function type
- Position in schematic (page, path, row)
- Function definition (string)
- Symbol (string)
- Function text (automatic)
- Symbolic address (automatic)
- Symbolic address (determined).

For pages:

- Full page name
- Page type.

### [ClosedExternal editing: External Application](javascript:void(0);)

For external editing, the use of the external application is controlled by the field Output type of the Edit externally dialog. The following should be noted for the options in this group box:

- The setting Edit in external application and reload can only be selected if a target application is defined in the scheme or if Excel is defined as the file type .
- With the setting Edit in external application and reload Eplan automatically remains open in the background. If the external application is exited after modification of the data, then Eplan opens a dialog allowing you to choose whether or not you wish to re-import the changed data.
- With the setting Edit in external application and reload the Target file field is grayed-out and cleared. If a different setting is chosen then this field is again active.

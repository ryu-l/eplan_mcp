# P020018: <x> differs in <y> settings

### Description

You have executed a project comparison in which the settings of the project to be checked (incoming project) are to be compared with those of the comparison project in order to determine any differences. In this message, the <x> stands for the folder structure of the settings area in the project to be checked, just as it is displayed in the tree view of the Settings dialog (command path: File > Settings). <y> indicates the number of settings within the settings area of the project to be checked that deviate from the comparison project.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The numbering scheme has changed in the Numbering (offline) settings area of the project to be checked. Additional format elements have also been added in the process. The following message may appear during the project comparison:

"Devices+Numbering (offline)+Format elements differs in 5 settings".

![](../Pictures/Gui/ALL/note.png)Notes:

- This module-specific message is limited to the settings areas Number using PLC data and Numbering (offline).
- Using a new check run (any desired scheme) it can be deleted from the message management dialog.

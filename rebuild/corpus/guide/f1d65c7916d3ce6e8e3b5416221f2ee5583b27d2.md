# Moving Property Texts to Model Views

The Move property texts command activates the insertion points of the property texts of items in a model view and these are made visible by clicking on the individual components. The texts can then be moved using Drag & Drop.

Preconditions:

- You have opened a project.
- You have opened a page containing a model view.
- Displaying the item label is switched on.

1. Select the model view.
2. Select the Text > Move property text popup menu item.
3. Mark the property text you wish to move.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The element points of the property text are shown as small square frames.
4. Move the property text.

![](../Pictures/Gui/ALL/info.png)Tip:

If you hold the [Shift] key down while moving, the current grid snap is "divided by four". The insertion point can then be moved in steps of a one-fourth of the grid size.

### Reset moved property texts

With the Reset moved property text command all the moved property texts of the marked items are deleted. The property texts are shown again which are stored in the item. (Each item contains the information which property texts are displayed by default when inserting this item.)

1. Select the desired items and select the popup menu item Text > Reset moved property text.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The copied property texts of all items will be deleted, and the default property texts of the item will be displayed.

# Defining Block Properties as User-defined Properties

Block properties can be defined as project-specific, user-defined properties.

Preconditions:

- You have opened a project.
- You have selected the following commands: Tab Tools > Command group Management > Properties.

1. Click the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button in the Configure properties dialog.
2. Enter a unique identifying name in the dialog [New property](eservicesgui_d_konfigeigenschaften.htm#Name).   
     
   ![](../Pictures/Gui/ALL/arrow.png) The identifying name cannot be changed later on.
3. Enter the name under which the property is displayed in the project / parts management in the Displayed name field. Multi-lingual entry is possible.
4. If necessary enter a describing text in the Description field. This is then displayed in the dialogs for the property selection for this property.
5. In the Assignment drop-down list select the type of objects (function, project, etc.) at which the property is to be available.
6. Select the entry "Monolingual text" or "Value with unit" in the Field type drop-down list.
7. Switch to the Display tab.
8. Select the "Block property" entry from the Display type drop-down list.
9. In the Category drop-down list, select the category in which the property is displayed.
10. In the Block format field click the [...] button to specify a project-wide format for the block property.
11. In the Format dialog select a group of properties from the Available format elements list and click the ![](../Pictures/Gui/ALL/all_expand_hierarchy_as.png) sign to open the subordinate property groups.  
      
    ![](../Pictures/Gui/ALL/arrow.png) If you can access indirect properties of other objects from this object, the ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level) button will be active.
12. If you want to select indirect properties, click ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level).  
      
    ![](../Pictures/Gui/ALL/arrow.png) The original property grouping is displayed in the Available format elements field once more - these are now the (indirect) properties of the subsequent object, however.
13. Select the required format group and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).  
      
    ![](../Pictures/Gui/ALL/arrow.png) The ![](../Pictures/Gui/ALL/all_arrowright_as.png) button (move to the right) is only active if a format group can be selected.
14. In the Format: Block property dialog select a property and specify the formatting for it.
15. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The Format dialog displays the selected format elements in a table in the Selected format elements field. They are shown with their designation, symbolic representation (for the preview) and set value. The order in which the properties are listed determines the order in which the individual properties are displayed in the output of the block property.   
      
    ![](../Pictures/Gui/ALL/arrow.png) If you have selected indirect properties, the ![](../Pictures/Gui/ALL/all_stairdown_as.png) (Previous level) button is active. Use this button to return to the source object.
16. Repeat steps 8 to 12 in order to specify further format elements.
17. If necessary, you can change the sequence of the formatting elements using the arrow buttons on the toolbar.
18. Click [OK].
19. If you want to change the project-wide block format locally at an object later and output other values, activate the Block format at the object rewritable check box.  
      
    ![](../Pictures/Gui/ALL/arrow.png) This way a further block property with the same identifying name and the supplement "(local format)" is generated in the displayed name in addition to the user-defined block property. At the object itself you can then select the block property with the supplement "(local format)" in the respective property table in addition to the actual user-defined block property and define a local block format via the Format dialog.
20. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) A new user-defined block property is stored project-specifically and is available in the project at the respective object in accordance with the relevant assignment.

![](../Pictures/Gui/ALL/note.png)Notes:

- The "Block property" display type is not available for the "Part reference" assignment and in the parts management.
- If a user-defined property with the "Block property" display type was saved (or imported), this display type can no longer be changed.
- If one of the other display types was selected (and saved) once for a user-defined property with the field type "Monolingual text" or "Value with unit", the "Block property" option is no longer available when the property is selected again.
- A user-defined property with the assignment "Connection" is normally available for connections and for connection definition points, potential definition points and net definition points. If such a property is defined as a block property, it is only available for connections and connection definition points. This is due to the fact that potential definition points and net definition points have a different block format.

![](../Pictures/Gui/ALL/info.png)Tip:

In the Format dialog use the existing button ![](../Pictures/Gui/ALL/all_copy_as.png) (Copy) in the toolbar to copy existing format elements (such as "Calculation") and to modify them rapidly after pasting.

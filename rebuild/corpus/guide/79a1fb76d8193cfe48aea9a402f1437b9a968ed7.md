# Tab Device pages

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Export > Command group Project data > Project data > Command group Page > PDF. Click [...] in the Scheme field of the PDF export dialog. Select the Device pages tab.
- File > Settings > User > Interfaces > PDF export. Select the Device pages tab.

In this tab, you specify whether pages with device data should be output in the PDF. For these "Device pages", you can define the areas into which the device data is subdivided.

Overview of the main dialog elements:

Generate device pages:

Activate this check box if PDF pages with device data should be generated for the device. For every device then, the information from the properties dialog as well as reference information (representation types, reports, etc.) will be listed in the PDF below the header - the full DT of the related device.

If the check box is not activated, the devices in the device tree of the output PDF are only listed; the pages with the device data are not generated.

Device filter:

In this table you specify filter criteria for the object properties. The individual lines are AND-combined by default. This allows you, for example, to limit the PDF export to certain devices (e.g. cables) or reduce the PDF export by excluding devices from the export.

Areas:

The information output for a device is broken down by default into three areas: Device properties, Part properties, and References.

If a certain area does not show up in the PDF, deactivate the corresponding check box in the Areas table. Use ![](../Pictures/Gui/ALL/all_arrowup_as.png) (Move up) / ![](../Pictures/Gui/ALL/all_arrowdown_as.png) (Move down) in order to change the sequence of areas in the PDF.

Output references to function representations / Output references to reports:

If this check box is not activated, no references to the representation types for functions and no references to reporting pages will be listed for a device in the References area.

# Dialog Run: Automated processing

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have selected project pages or a project in the page navigator.

- Tab Tools > Command group Reports > Automated processing.
- File > Extras > Command group Extensions > Interfaces > Command group Automated processing > Automated processing.

In this dialog, you use the scheme to select the sequence of actions that are to be run in an automated manner.

Overview of the main dialog elements:

Scheme:

Choose the scheme that you would like to use from the drop-down list. Click [...] to open the Settings: Automated processing dialog.

Table:

The table contains the following columns:

- Actions in selected script: Shows the actions that are stored in the selected scheme.
- Description: Shows the describing text, that you have entered for a selected action in the dialog Settings: Automated processing in the Description field.

# Exporting Manufacturing Data for Eplan Smart Production

The manufacturing data of Eplan Smart Production are exported into an EPDZ file via a separate interface.

Preconditions:

- You have opened a project.
- You have opened the layout space navigator and a layout space.
- You have placed mounting rails, wire ducts and items.
- You have created routing connections.

1. Select the following commands: File > Export > Command group Manufacturing data > Manufacturing data > Smart Production.
2. In the Export Eplan Smart Production dialog select the file name and the output directory for the EPDZ file.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the set output directory, the EPDZ file is generated with the pre-selected name. You can then load this file into Eplan Smart Production.

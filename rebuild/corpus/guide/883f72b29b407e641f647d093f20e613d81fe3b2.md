# Creating Your Own Connection Point Designations and Descriptions

For each function definition, ten sets of connection designations and connection descriptions can be specified. These sets can then be selected later on from the function. We recommend that you create and maintain the sets of connection point designations and connection point descriptions in the basic project.

### Create connection point designations

Precondition:

You have opened a project.

1. Select the following commands: File > Settings > Projects > "Project name" > Devices > Numbering (online). Click the Connection point designations / descriptions button.
2. Select the Connection point designations tab.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Connection point designations tab lists the function definitions with their connection points. One line is shown for each connection point.
3. In the fields 1 - 10, enter up to 10 different connection point designations per connection point.
4. Click [OK].

### Create connection point descriptions

Precondition:

You have opened a project.

1. Select the following commands: File > Settings > Projects > "Project name" > Devices > Numbering (online). Click the Connection point designations / descriptions button.
2. Select the Connection point descriptions tab.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Connection point descriptions tab lists the function definitions with their connection points. One line is shown for each connection point.
3. In the fields 1 - 10, enter up to 10 different connection point descriptions per connection point.
4. Click [OK].

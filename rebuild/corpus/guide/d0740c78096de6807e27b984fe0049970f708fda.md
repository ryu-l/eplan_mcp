# Dialog Place device

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project and have opened a navigator. Mark a function and select the Place popup menu item. Move the mouse to the schematic page and press the [Backspace].

In this dialog you specify the placement options for the device.

Overview of the main dialog elements:

Part macro:

If a macro is assigned to the part in the parts management, you can select this option to place this macro.   
Otherwise this option is grayed out.

Individual functions:

Action "Place": Select this option if you want to place the actual function with all the function-specific data.

Action "Insert device": If function templates are assigned to the part in the parts management, you can select this option to insert these.   
Press the [N] button in order to page through the functions and select the desired one. Or use the [Spacebar] while placing the auxiliary functions if you want to interrupt the placement of the auxiliary functions and want to start again with the placement of the main function.

Macro selection:

Select this option if the Select macro dialog is to be opened after the confirmation with [OK] so that a (different) macro can be selected for the device. The macros and symbols stored at the part are not taken into consideration.

Representation type:

If you have selected one of the options Part macro or Individual functions, you can use this drop-down list to assign a (different) representation type to the functions.

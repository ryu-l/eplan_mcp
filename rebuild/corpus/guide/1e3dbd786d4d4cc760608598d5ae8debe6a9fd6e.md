# Determining the Fill Capacity (Topology)

After connections and cables have been routed, the program will know the routes through which these connections / cables run. If the cross-sections of the routing paths and the outside diameters of the connections / cables are known, the program can estimate whether the routing paths are dimensioned sufficiently large in order to accommodate all connections / cables.

The Determine fill capacity function provides feedback on the space reserves in manual routing paths. This way, you can see where you must modify specific routes in order to force routing through less crowded routing paths even if another path would be shorter, but would result in over-allocation.

Preconditions:

- You have opened a project.
- You have defined a routing path network and the cross-sections of the routing paths. To this purpose you must enter the routing path cross-section with unit in the Topology: Routing path cross-section property at the routing paths for which the fill capacity is to be calculated.
- The connections / cables passing through the routing paths are assigned parts with a defined outside diameter.
- You have routed connections / cables in the routing path network.

1. Select the following commands: Tab Connections > Command group Topology > Fill capacity.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The current fill capacity of the manual routing paths is calculated and entered in the property Topology: Fill capacity of the respective routing paths. Calculation of the fill capacity is carried out project-wide.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If no routing path cross-section is specified for a routing path, the Topology: Fill capacity property is deleted.

![](../Pictures/Gui/ALL/info.png)Tip:

To display the fill capacity on the schematic page add the property Topology: Fill capacity to the property arrangement of the routing paths. This property shows the fill capacity in percent.

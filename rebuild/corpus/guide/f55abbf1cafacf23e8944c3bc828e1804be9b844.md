# Installation Information

Preconditions

Before executing the setup program the following points must be executed or checked:

- For the duration of the installation deactivate your anti-virus software.
- Is the version of Java Script installed?
- Is [Microsoft .NET Framework](https://www.eplan.help/en-US/Infoportal/Content/htm/portal_software_approvals.htm) installed?
- Do the used versions for the operating system, MS Office, and SQL conform with the [current software releases](https://www.eplan.help/en-US/Infoportal/Content/htm/portal_software_approvals.htm)?
- In order to install an Eplan program variant you required local administrator rights and after installation the "Change" right in all Eplan directories (local and in the network).
- Please inform yourself about the hardware prerequisites and the software approvals of the Eplan Platform before installing Eplan products. This information is available in the Eplan performance descriptions of the respective products.

### Setting the target directories

We recommend the usage of UNC paths for data storage in the net.

Please ensure that no special characters (for example / : \* ? " < >) are used.

- Program directory:
    
  In this directory the required program components for Eplan are stored. To this purpose only use local drives (e.g. C: or D:), no network releases.
- Eplan original master data:
    
  This directory contains the Eplan original master data. These data serve as a backup of your system master data.
- System master data:
    
  This directory contains the customer-specific system master data. The directory selected for the system master data is stored in Eplan as the default directory for master data.

- Company code:
    
  Your company code is stored in this field. This code is used at some points as the directory name. We recommend that you select a short name.
- User settings:
    
  This directory contains the user-specific settings.
- Workstation settings:
    
  This directory contains the workstation-specific settings.
- Company settings:
    
  This directory contains the company-specific settings.

Installation in a network

The following configuration is recommended for a network installation:

- Local installation of the program data and settings databases (program directory, user settings and workstation settings)
- Installation of the master data (original Eplan master data and system master data) as well as the company settings in the network.

### Customized installation

Modifications in this field should only be carried out by experienced administrators since a faulty configuration can result in the Eplan installation not being executable.

![](../Pictures/Gui/ALL/note.png)Note:

If you want to install further user interface languages in addition to the language displayed in the Eplan Setup Manager, you have to carry out a customized installation and select the desired languages in the "Master data and languages" section.

Program components:

- Eplan License Client
    
  Required for local licensing with a dongle and for network licensing.
- Eplan Electric P8 (or Eplan Preplanning / Eplan Fluid / Eplan Pro Panel)   
  The required program components for Eplan Electric P8 (or Eplan Preplanning / Eplan Fluid / Eplan Pro Panel) are installed by activating the check box.
- Eplan Electric P8 Data (or Eplan Preplanning Data / Eplan Fluid Data / Eplan Pro Panel Data)  
  The required master data for Eplan Electric P8 (or Eplan Preplanning / Eplan Fluid) are installed by activating the check box.
- Eplan Platform
    
  The required program components of the Eplan Platform are installed by activating the check box.
- Eplan Platform Data
    
  The non-project-specific master data of the Eplan Platform (for example part master data) are installed by activating the check box.

Master data types:

Configure the master data to be installed by activating the respective check box.

Language modules:

Select the languages to be installed for Eplan.

Activated: The activated user interface language for the Eplan user interface is set during the first Eplan start.

### First start of Eplan

- When starting Eplan the first time do so with Administrator rights to ensure correct registration of components and the copying of the settings and master data databases.
- After the first start carry out the settings for the parts database, the dictionary and the project management database. Customize the settings to your company-specific requirements.

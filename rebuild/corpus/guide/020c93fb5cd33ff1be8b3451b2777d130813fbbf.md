# Tab Display (Connection Numbering)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- File > Settings > Projects > "Project name" > Connections > Connection numbering. Select the Display tab in the dialog Settings: Connection numbering.
- You have selected a connection in the graphical editor, or in the Connections - <Project name> navigator dialog. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog. Tab Connections > Command group Connections > Enter designation or Place definition points or Align and format. Click the [...] button in the subsequent dialog next to the Settings field. Select the Display tab in the dialog Settings: Connection numbering.

In this tab you specify the formatting for connection designations generated on the connection definition point.

Overview of the main dialog elements:

Property / Assignment:

To this purpose the hierarchy levels Distance and Format are available. These can be opened by clicking the ![](../Pictures/Gui/ALL/all_expand_hierarchy_as.png) sign.

---

Distance hierarchy level

Horizontal:

Specify the spacing of connection designations to vertical connection sections. The connection designation for vertical connection sections is fixed on the connection line. This setting allows you to move the position positively or negatively in a horizontal direction.

If the connection designation is docked to another property then the setting affects the entire block.

Vertical:

Specify the spacing of connection designations to horizontal connection sections.

---

Format hierarchy level

Alignment:

Select the desired text alignment from the drop-down list. The alignment defines where the insertion point relative to the text is located.

| 1: Upper left    2: Middle left    3: Basis left    4: Lower left |  | 9: Upper right    10: Middle right    11: Basis right    12: Lower right |
|  | 5: Upper center  6: Middle center  7: Basis center  8: Lower center |  |

---

Use default:

With this setting you can specify that the connection designations of the automatically placed connection definition points are formatted in the same way as manually inserted ones.

If this check box is activated, the connection definition points are assigned the property arrangement when running the commands Place definition points as well as Align and format. You defined the property arrangement as the default for the used symbol variant of the connection definition point (for example. in the dialog Save property arrangement). This makes it possible to format manually inserted and automatically placed connection definition points uniformly with a user-defined property arrangement. The settings in the table can then no longer be edited and are not used. If no property arrangement is specified as the default, the "Default value (connection)" property arrangement is assigned to the connection definition points.

If the check box is deactivated, the connection designations of the automatically placed connection definition points are formatted according to the settings in the table.

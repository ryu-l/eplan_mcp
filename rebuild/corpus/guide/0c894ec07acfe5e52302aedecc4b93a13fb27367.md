# Dialog Select configuration project

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Import > Command group Project data > Project data > Command group PLC > PLC data. You have selected an AutomationML AR APC format from the Format of import file field and then clicked [OK].

In this dialog you specify the configuration project into which the PLC data are to be imported from an import file in AutomationML AR APC format. The dialog is displayed when the configuration project entered in the import file does not exist in the Eplan project.

Overview of the main dialog elements:

Configuration project:

The configuration project from the import file and the configuration projects available in the project are displayed in the drop-down list. Select the configuration project into which the PLC data are to be imported.  
If you retain the configuration project from the import file, a new configuration project is created in the Eplan project and the PLC data are imported into it.

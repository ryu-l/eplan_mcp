# 2D Drilling View: Principle

2D drilling views show the NC and drill hole-relevant data, drilling patterns, as well as outlines of basic items and parts in a model view. 2D drilling views are project-internal documents which are permanently available during project processing in Eplan. You can use the drilling views to synchronize the output manufacturing data (for example generated with the following commands: File > Export > Command group Manufacturing data > Machining > Drilling template) prior to the production start with the current editing status in the Eplan project.

The items and drill holes can be assigned dimensioning in drilling views.

If the part placements in the project have been changed, the 2D drilling views can be updated at any time with the following commands: Tab Tools > Command group Reports > Update.

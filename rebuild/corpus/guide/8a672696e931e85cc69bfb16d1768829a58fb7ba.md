# Display Properties: Rectangle / Shield

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc. You have marked a rectangle and chosen the popup menu item Properties, or you have double-clicked a rectangle. In the table of the Properties (Rectangle) dialog, expand the hierarchy level Rectangle.
- You have opened a project. You have opened a project page in the graphical editor. You have inserted a rectangular structure, black, or PLC box, etc., or double-clicked a box. In the Properties <...> dialog select the Format tab and, in the table, expand the Rectangle hierarchy level.
- You have opened a project. And you are in the graphical editor of a page of the "Panel layout" type. You have inserted a mounting panel or double-clicked on a mounting panel. In the Properties <...> dialog select the Format tab and, in the table, expand the Rectangle hierarchy level.
- You have opened a project. And you are in a page within the graphical editor. You have inserted a shield or double-clicked on a shield. In the Properties <...> dialog select the Format tab and, in the table, expand the Shield hierarchy level.
- You have opened a project. You have opened a project page in the graphical editor. You have inserted a comment as a rectangle and selected the popup menu item Properties or double-clicked the rectangle of the comment. In the Properties dialog select the Format tab and, in the table, expand the Rectangle hierarchy level.

Below this hierarchy level, you can edit the specific settings of rectangles, mounting panels, rectangular structure, black, or PLC boxes, shields, comments with rectangles, etc.

Overview of the main dialog elements:

Starting point / End point:

In the fields below these hierarchy levels, the coordinates of the starting and end points of the rectangle are displayed. The direction in which the rectangle was opened is considered here.

Angle:

Enter an angle in order to rotate the rectangle relative to the X axis. The field is only available for "free rectangles", that is, not for rectangles representing mounting panels or structure, black, PLC boxes, etc.

# P502003: The document '<x>' entered at the part does not exist

### Cause

In the parts database to be checked a part was found where a document was entered which Eplan cannot find.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Properties tab to the front.
3. In the property table open the hierarchy levels Documents > External document: File / hyperlink to make the indexed properties visible.
4. Click [...] in the value field of the indexed property in which the document output by the message management is entered.
5. Select an existing document from the selection dialog opened.  
     
   Or alternatively to this, delete the entered document macro in the value field of the property.  
     
   Or store a new document in the desired document directory and select it again at the indexed property.
6. Click [Apply].
7. If required, start a new check run.
8. Close the parts management and perform a parts data synchronization.

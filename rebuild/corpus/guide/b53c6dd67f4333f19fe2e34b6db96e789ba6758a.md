# Popup Menu Items

In many dialogs in tables and fields a popup menu available. The menu items displayed, and / or which can be activated, depend on both the field type of the selected field or table cell, and also whether you have simply selected a table cell (single click) or selected a value for editing (double-click).

### [ClosedPopup menu items for the display of tables](javascript:void(0);)

The following listed menu items are used to influence the representation of the table.

| Menu item | Meaning |
| --- | --- |
| Freeze panes | Fixes all the rows of the table above the selected row, or all of the columns to the left of the selected column. The rows below, or the columns to the right of the selection, can still be moved by using the scroll bar. |
| Unfreeze panes | Removes the freezing so that all of the rows and columns can again be moved using the scroll bar. |
| Adjust column width | Adjusts the width of all table columns so that both the headings and column contents are fully legible. |
| Column width automatic | Customizes the width of the columns in such a way that the table is displayed within the overall available area. If the respective dialog is resized, the width of the table is automatically adjusted. After deactivating this option the last saved column width is displayed for all columns. |
| Font size 100% | This menu item is only available if the font size has been changed in the table (via [Ctrl] + scrolling with the mouse wheel). Re-displays the text in the table in its original font size. |
| Customize row | This menu item is available in some dialogs which have a table (for example in the property dialog). Opens the Customize row dialog in which you can specify the row height of the marked row. In addition you can emphasize the text of the marked line in bolt. |
| Expand all | This menu item is only available if tree views are displayed in a table column. Expands all trees in the table column at the same time. |
| Collapse all | This menu item is only available if tree views are displayed in a table column. Collapses all trees in the table column at the same time. |
| Configure | This menu item is only available in property dialogs. Opens the Configure properties dialog. There you select the default properties to be shown in the table for an object from this category. |
| Configure representation | This menu items is available in many dialogs that have a table or a tree and / or list view. Opens the Configure representation dialog in which you can determine the properties to be displayed in the table or in the tree or list. |

### [ClosedPopup menu items for the editing of values](javascript:void(0);)

The following listed menu items are used for the entry and editing of values in fields and tables. Also in many places - both for marked as well as for selected fields / spreadsheet cells - the familiar Windows functionalities, such as cutting, copying, inserting, deleting etc., are available.

Menu items for editing selected fields / table cells:

| Menu item | Meaning |
| --- | --- |
| Paste properties / values | Only in the property tables (property name / value). Allows for pasting one or several properties, including their values, that have been copied from another object. If the property already exists then only the values are inserted. If a property has not been displayed in the table yet, it - and the copied value - will be shown after pasting. |
| Special characters | Opens the Special characters dialog, in which you can select the desired character and insert it at the current cursor position with [OK]. |
| Line break | Inserts a line break at the current cursor position. |
| Multi-line input | Opens the Multi-line input dialog where you can enter the lines desired. A line break can be forced using [Ctrl] + [Enter]. |
| Update selection list | Only in fields containing a selection list. Supplements missing entries and deletes unused entries from the selection list: In the case of certain properties, the values entered there are written to a selection list and are then available for other objects of the same type. |

### [ClosedPopup menu items for multilingual texts](javascript:void(0);)

The following listed menu items are used for the entry and editing of multilingual texts in fields and tables.

| Menu item | Meaning |
| --- | --- |
| Translate | Opens the Found words dialog if dictionary translation entries exist for the entered term. Select the suitable translation text. If there are no translations in the dictionary, the Translate dialog is launched to enable you to enter a new translation text. |
| Remove translations | Removes all translation texts for the marked texts. In the process the marked texts become language-neutral texts. |
| Mark text as 'Excluded from translation' | Marks the selected text as "Excluded from translation". Texts marked in this way are excluded both from the translation and from being output into a missing-word file. |
| Remove marking | Removes the "Exclude from translation" marking for the selected text so that the particular text will be included in the translation again. |
| Multilingual input | Opens the Multilingual input dialog, in which you can enter the output text for the desired translation text. |

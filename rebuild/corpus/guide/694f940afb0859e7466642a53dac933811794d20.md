# P005074: Different connection point cross-section / diameter of connection and connecting point

### Cause

One or more connection points of functions are connected to a connection. The connection point or one of several connection points has a different value than the connected connection with regard to the connection point cross-section or diameter.

### Solution

1. Enter the same values for the connection point cross-section or diameter at both the connection points of all functions as well as at the connected connection point.
2. If required, start a new check run.

# Dialog Multi-user monitor

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The prerequisites for multi-user operation have been met. Eplan is connected to the monitor server. File > Collaboration > Command group Multi-user monitor > Multi-user monitor.

In this dialog the projects that are relevant for the multi-user operation are listed in two tables.

Overview of the main dialog elements:

Own opened projects in multi-user operation:

The left-hand table provides detailed information about the multi-user usage. It shows the projects that you and other users have open at the same time. The following data is listed for these projects:

- Project
- Users
- Area
- Product version
- Project action
- Progress.

If a user has started an action with respective runtime (error checking, reports etc.) for a project also opened by you, this is displayed in the Progress column through a progress bar.

In the User column click the user code designed as a hyperlink, then the e-mail program on your computer is started and you can send an e-mail to this user.

By clicking the ![](../Pictures/Gui/ALL/all_expand_hierarchy_as.png) icon before the respective project name, additional information about a user is displayed in both tables (name, phone, computer). As a prerequisite for this, the users working in multi-user operation must have their user data stored in the settings (File > Settings > User > Display > User code / address).

![](../Pictures/Gui/ALL/note.png)Notes:

- Projects that only you have open do not appear in the multi-user monitor.
- To send e-mails, an e-mail program has to be installed on your computer and be entered as the default e-mail app in the Windows settings.

Other open projects:

The table on the right of the dialog lists all the projects that have only been opened by other users. The following data is listed for these projects:

- Project
- User.

If more than one other user has a project open, the Users column displays more than one User code for the relevant project.

If you wish to email a user in this table, you first need to drop down the row of information below. Here, click the user name that has been set up as a hyperlink.

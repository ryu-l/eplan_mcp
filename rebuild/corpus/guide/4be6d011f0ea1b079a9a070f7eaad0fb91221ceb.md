You have opened a project. You have opened a project page in the graphical editor. You are in the information section of the dialog Insert center. Select the Configure representation popup menu item. In the dialog Configure representation click the ![](../Pictures/Gui/ALL/all_new_as_17x17.png) (New) button in the toolbar above the table of the configurations, or select the row of a configuration already defined and click the ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit) button.

In this dialog you specify which properties are to be displayed for the configuration with the name specified here. By means of a defined filter you can specify that these configured properties, for example in the parts management at parts, are only displayed at a very specific product group or in the property overview at functions only at a very specific function definition.

Overview of the main dialog elements:

Assignment:

From this drop-down list select the object (for example part, symbol, graphical element, etc.) to be used for a property configuration. The object which is available here depends on where the configuration is called up. This way a property configuration in the parts management can only be assigned to the "Part" object.

The object assigned here is displayed in the previous configuration dialog for the respective property configuration in the Assignment column.

Name:

Enter the name of the property configuration here as it is to be displayed in the configuration dialog.

Filter:

This field shows the filter you have defined via [...] in the Filter dialog.

Properties:

This list contains the properties assigned to the current property configuration. The properties are dependent on the object selected in the Assignment field.

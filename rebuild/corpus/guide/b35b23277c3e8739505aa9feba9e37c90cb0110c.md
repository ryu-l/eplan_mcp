# Importing Parts Data

Precondition:

In the Parts management dialog you have opened a parts database using [Extras] > Settings.

1. Select the following commands: Tab Master data > Command group Parts > Management.
2. Select the Import menu item in the dialog Parts management below the [Extras] button.
3. Select the desired file type from the File type drop-down list of the Import records dialog.   
     
   ![](../Pictures/Gui/ALL/arrow.png) Depending on the import format defined here, the [...] button becomes active and in the subsequent dialog you can specify the settings of the import behavior.
4. Enter the file names of the import files into the File name field or click ![](../Pictures/Gui/ALL/all_selectfile_as.png) to select the files interactively. Multiple selection is possible.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The file extension is automatically attached depending on the file type selected in the File type field.
5. In the Field assignment drop-down list, select the scheme to be used for the field assignment. Or click [...], to edit an existing scheme or create a new scheme using the Field assignment dialog.
6. Use the options to specify the treatment of new or existing records during import.
7. Click [OK].

# Automatic Assignment of Function Definitions and Items during Design Space Import

If the 3D model of an enclosure was imported from a CAD program via the design space import, several steps were required subsequently (defining mounting surfaces, setting function definitions, inserting placement area, etc.) in order to start with the 3D mounting layout. In order to reduce this required work during the creation of the 3D mounting layout for you, an automatic assignment of function definitions and items in Eplan to the imported 3D object is now possible in Eplan Pro Panel.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

The automatic assignment of function definitions and items to the imported 3D object during the design space import considerably reduces the work required during the creation of the 3D mounting layout. The work can be reduced even further by linking of designations from the CAD system and function definitions as well as items in Eplan.

You can specify the assignment of function definitions and items in the scheme for the design space import and export. To this purpose the new Function definitions (import) tab is available in the Settings: Design space import and export dialog (command path: File > Settings > User > Interfaces > Design space import and export).

This assignment is used during the design space import (command path: File > Import > Command group Project data > Layout space > Design space). During the import, the new Design space import - define items dialog is displayed. Here you can, if required, change the assignment to the function definitions and items in Eplan as well as specify the placement area for the enclosure (for the item designations of the imported 3D object used in the CAD system).

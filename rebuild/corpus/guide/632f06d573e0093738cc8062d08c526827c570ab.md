# Creating Plot Frames

When generating a plot frame, the Plot frame properties - <Plot frame name> dialog is opened in which you specify the most important properties of the new plot frame. (This dialog can also be called up for an opened plot frame after the event to allow you to change the properties at any time.)

Precondition:

You have opened a project.

1. Select the following commands: Tab Master data > Command group Plot frames / forms > Drop-down button Plot frame > New.
2. In the Create plot frame dialog, select the drive and directory, in which the new plot frame should be saved.
3. In the File name field, enter a descriptive name for the plot frame.
4. If you want to return to the default setting for the drive and directory, click the Eplan icon and the directory listed below this in the left-hand navigation area. (The default directory is either the program-specific default setting <Program drive>:\<Program directory>\Plot frames\<Company code> or the directory specified in the settings for plot frames: File > Settings > User > Management > Directories.)
5. Click [Save].
6. In the Plot frame properties - <Plot frame name> dialog, select the properties to be shown in the list from the Category drop-down list.
7. Specify the values for the properties, either by making or overwriting an entry or by selecting a preset value from a drop-down list.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new plot frame is saved according to your entries and displayed in the plot frame editor.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The point of origin if the plot frame is indicated by a red circle, analog to the outline editor and the symbol editor. The position of the point of origin is taken into consideration during zooming, but cannot be moved manually.

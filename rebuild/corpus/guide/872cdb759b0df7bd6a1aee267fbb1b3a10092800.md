# Outputting Hook-Ups for Planning Objects

Preconditions:

- You have opened a project that contains the pre-planning data, and have the pre-planning navigator open.
- You have created an assembly with the "Hook-up" product group in the parts management under the "Mechanics" generic product group. You have stored a macro for the assembly with the desired graphical display for the hook-up in the Schematic macro property (Tab Properties, Hierarchy level Data). The parts for the accessories of the hook-up are available for this assembly in the same generic product group under "Single component".

1. Select a planning object in the pre-planning navigator.
2. Select the Properties popup menu item.
3. In the Properties <â¦> dialog, select the Parts tab.
4. Click [...] in the Part number field in row 10.
5. In the Part selection dialog, navigate through the tree structure, and select the desired assembly part under "Mechanics > Hook-up > General".  
     
   ![](../Pictures/Gui/ALL/arrow.png) The part numbers are transferred to the properties dialog of the planning object.
6. Click [OK].
7. Select the following commands: Tab Tools > Command group Reports > Generate.
8. Select the Reports tab. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
9. In the Select report type field of the subsequent dialog, select the "Assembly/Module overview" entry. Click [OK].
10. In the Settings - <Report type> dialog, set a filter for the hook-ups options group in the Filter field. To this purpose select the "Mechanics: Hook-up" value for the "Product group" filter criterion in the subsequent dialog.
11. In the following dialog Assembly/Module overview you specify the start page. To this purpose select a page in the Page navigator field.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The hook-ups assigned to the planning objects are output as reports.

# Dialog Settings: Revision (property comparison of projects)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The project is not write-protected. File > Settings > Projects > "Project name" > Management > Revision (property comparison of projects).

In this dialog you can specify settings for the property comparison of projects.

Overview of the main dialog elements:

Place revision markers on each page at connections:

If this check box is selected, and a change has been made to a connection that exists on more than one page, this connection will be marked on all of those pages.

If the check box is deselected, the connection will only appear on the first page.

Maximum number of displayed results:

This field is where you specify the maximum number of messages to be shown in the Results of property comparison - <Project name> dialog. This setting helps speed up the display of the dialog and does not influence the execution of the property comparison. Regardless of the number specified here, all objects will be compared and all results will be written into the revision results list. (This list is stored in the project database of the current project.)

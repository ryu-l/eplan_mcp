# P012008: The structure identifier does not correspond to the mounting panel

### Cause

You created specific project structure and defined identifierblocks to which you assigned structure identifiers. Now there are conflicting structure identifiers for the placed part and for the corresponding mounting panel, in one of the identification blocks.

### Solution

1. Enter the same structure identifiers for the corresponding identifier blocks (for example for "Function designation" and / or "Location designation") at the part placement and at the corresponding mounting panel (respectively in the Displayed DT field of the Properties <...> dialog).
2. If required, start a new check run.

# Dialog Adapt structure

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have selected one or more layout spaces in the layout space navigator. Select the Copy or Cut popup menu item. In the layout space navigator, click the position where the copied layout spaces are to be inserted. Select the Insert popup menu item.

This dialog displays all names of the layout spaces to be copied in a table, where they can be changed.

Overview of the main dialog elements:

The table displays the names of the source layout spaces to be copied and the names of the target layout spaces to be inserted.

Source:

The names of the layout spaces to be copied are displayed. These names cannot be edited here.

Target:

The names of the layout spaces to be inserted are displayed. The names can be generated automatically or specified by input.

Overwrite:

Select this check box to specify whether an existing layout space of identical name should be overwritten or not when inserting the layout space.

Automatic layout space name:

Select this check box to determine the highest existing layout space number for the project, and to suggest the next highest number / numbers for the Layout space name column.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You have opened a project that contains three layout spaces with the names 1, 2, and 3. Select layout space 1 and copy it. After activating the Automatic layout space name check box, the layout space name of the target layout space to be inserted is changed to 4.

[Reset]:

Resets the setting of the layout space names to the original structure.

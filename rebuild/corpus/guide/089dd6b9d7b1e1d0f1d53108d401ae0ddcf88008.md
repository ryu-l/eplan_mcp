# Read Customer Data

You can load customer data such as address, company name, or telephone number from parts management into the project properties of the current project. This avoids having to enter the customer data twice. You can load address information for manufacturers / suppliers into the "Creator" property group and you can enter address information for customers into the "Customer" and "End customer" property groups. Existing property values are overwritten.

Preconditions:

- You have imported directories and projects into Project management.
- In the global settings you have defined a parts database that contains the appropriate customer, manufacturer, or supplier address data.

1. Select the following commands: File > Project management.
2. Select a project.
3. Select the button [Extras] > Read customer data > Creator to load the manufacturer / supplier data into the "Creator" property group.
4. Select the button [Extras] > Read customer data > Customer to read customer data into the "Customer" property group.
5. To read customer data into the "End customer" property group select the button [Extras] > Read customer data > End customer.
6. Select an entry in the subsequent property dialog.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The customer data is read into the project properties and is displayed in the Properties tab.

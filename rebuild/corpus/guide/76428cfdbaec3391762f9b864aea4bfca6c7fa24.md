# Creating and Placing Unplaced Comments

In the comments navigator you have the possibility to create unplaced textual comments.

![](../Pictures/Gui/ALL/note.png)Note:

Comments with a graphic (rectangle, polygon) can only be inserted as placed comments. Accordingly, it is not possible to delete only the placement for such comments. Graphical comments can only be deleted completely.

### [ClosedCreating unplaced comments](javascript:void(0);)

Precondition:

You have opened a project.

1. Select the following commands:  Tab Tools > Command group Comments > Navigator.
2. Select a comment or another hierarchy level in the tree and select the popup menu item New.
3. In the property dialog, select the Comments tab.
4. Enter a text in the Comment text field.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The unplaced comment is sorted into the tree view of the navigator below the "Unplaced" hierarchy level.

### [ClosedPlacing comments](javascript:void(0);)

You can place an unplaced comment on a project page.

Precondition:

You have opened a project.

1. Select the following commands: Tab Tools > Command group Comments > Navigator.
2. Below the "Unplaced" hierarchy level mark the unplaced comment that you want to place. Multiple selection is possible.
3. Select the Place popup menu item.
4. Place the comment text at the desired position on the project page.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The comment is displayed both on the project page and in the comments navigator, arranged below the respective project pages.

![](../Pictures/Gui/ALL/info.png)Tip:

You can also place an unplaced comment on a project page using Drag & Drop.

### [ClosedDeleting placement of comments](javascript:void(0);)

Preconditions:

- You have opened a project.
- You have opened a project page in the graphical editor. Or you have opened the comments navigator.

1. Select a text comment in the graphical editor or in the comments navigator.
2. Select the following commands:  Tab Home > Command group Clipboard > Drop-down button Delete > Placement.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The graphical representation of the comment in the schematic will be deleted. The comment is retained as an unplaced comment and can be placed again from the comments navigator.

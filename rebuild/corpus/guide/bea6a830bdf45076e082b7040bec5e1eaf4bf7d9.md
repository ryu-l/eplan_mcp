# Preventing a New Placement of a Symbol

If you wish to edit a symbol, you can prevent the symbol from being used while you are doing this. While the symbol is being edited, it can not be newly inserted into a project or edited by another user. Symbols already inserted into a project can still be used normally.   
Once you have finished editing the symbol you can then unlock it again. Only an unlocked symbol can be edited or inserted by another user.

Precondition:

You have opened a project. You have opened the Pages - <Project name> dialog.

1. Select the following commands: Tab Master data > Command group Symbols > Drop-down button Symbol > Open.
2. If you have not yet opened a symbol library, in the Open symbol library dialog, you first open the symbol library containing the symbol you wish to edit.
3. Select the symbol you would like to edit in the Symbol selection dialog and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol to be edited is opened in the symbol editor.
4. In the Pages - <Project name> dialog mark the opened symbol and select the Properties popup menu item.
5. In the Symbol properties - <Library name> dialog, activate the Prevent new placement check box in the property table. If this check box is not displayed, add this property of the table by using the Property selection dialog.
6. After you have closed the symbol and confirmed the subsequent dialog Synchronize master data with [Yes], the selected symbol is locked for the placement.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The locked symbol can neither be selected in the Insert center dialog for the placement nor in the Symbol selection dialog for exchanging the symbol.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The locked symbol can be edited in the symbol editor. When the editing is completed, deactivate the Prevent new placement check box again in the Symbol properties - <Library name> dialog.

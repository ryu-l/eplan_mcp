# Displaying the Eplan Data Portal in the Parts Management and for the Insert Center

The icon ![](../Pictures/Gui/ALL/userinterface_edpIcon_as.png) "Data Portal" is now displayed in the tree of the parts management and in the Insert center. In the tree and combination view of the parts management this icon is located above the node for the parts. In the Insert center this icon is displayed below the icon ![](../Pictures/Gui/ALL/insertergui_macro_as.png) "Window macros / symbol macros".

When you click the icon, the Eplan Data Portal is opened.

- Parts management: The Eplan Data Portal is displayed as a tab in a browser window in the right-hand section of the parts management.
- Insert center: A special window for the Eplan Data Portal is opened in the main window of the Eplan platform. Even if this window looks like a normal Data Portal window, this window is independent of the other Data Portal windows and is identified in the title bar by the text Data Portal (Insert center). If a Data Portal window has already been opened via the ribbon, the Data Portal window for the Insert center is opened nevertheless.

[![](../Pictures/Gui/Lang/articlesgui_dataportaltab_ls_thumb_0_60.png)](../Pictures/Gui/Lang/articlesgui_dataportaltab_ls.png)

![](../Pictures/Gui/ALL/benefit.png)Benefit:

By means of the "Data Portal" icon you now have direct access to the Eplan Data Portal in the parts management, in the part selection and in the Insert center. This saves time and makes access to master data much easier and quicker. Missing parts can be downloaded directly from the Eplan Data Portal without leaving the previous workflow.

By means of the new search filters in the Insert center you can decide specifically whether you want to "search all" (including the Eplan Data Portal) or want to carry out the search only in the devices of the parts management. This flexibility allows a search that matches the individual requirements of the respective work step and prevents superfluous results.

If no suitable part is found in the parts management or in the Insert center, the search is continued automatically in the Eplan Data Portal. This minimizes the effort since you do not have to switch manually to another system, but can automatically search through all available sources.

This makes working with parts in Eplan more efficient, more fluid and less error-prone - which increases productivity particularly in complex projects and a high number of parts.

In the new tab or the new window for the Data Portal you can select and download part master data as usual.

The "Data Portal" icon does not have a popup menu.

- Parts management: The icon can neither be configured via the Configure representation popup menu item nor via the tree configuration. The icon does not exist in the list view.
- Insert center: No properties are displayed in the information area for the "Data Portal" icon, and accordingly the information area cannot be configured for the icon either.

If nothing is found during the search in the parts management or in the Insert center, the search - if possible - is continued in the Eplan Data Portal. If the part is found there, it is displayed in the Eplan Data Portal. To this purpose, the Eplan Data Portal is opened, if necessary. During the search, the text that was entered in the Find field is also used for the search in the Eplan Data Portal.

You have to be signed in to the Eplan Cloud so that the icons for the Eplan Data Portal are displayed and you can use the Eplan Data Portal. Further information about the Eplan Cloud products can be found in the help of the [Eplan Cloud](../../../../Cloud/Content/htm/Cloud_k_home.htm).

### New search filters for the targeted search in the Insert center

During the search in the Insert center the Eplan Data Portal is now - if possible - also searched by default. To this purpose the search filter ![](../Pictures/Gui/ALL/insertergui_search_in_all_as.png) (Search all) has been extended with the search in the Eplan Data Portal. In addition the following new search filters are available:

| Button | Meaning |
| --- | --- |
| (Search all (except Data Portal)) | Searches for all object types. The search is only carried out in the Insert center and not in the Eplan Data Portal. |
| (Search in devices and Data Portal) | Searches only in the devices, meaning in the parts of the parts management and in the Eplan Data Portal. |

In order to search in the Insert center in the Eplan Data Portal, one of the search filters ![](../Pictures/Gui/ALL/insertergui_search_in_all_as.png) (Search all) or ![](../Pictures/Gui/ALL/insertergui_search_in_device_and_DP_as.png) (Search in devices and Data Portal) has to be activated before the Find field.

If the Eplan Data Portal is not to be included in the search, you have to press one of the other buttons (for example ![](../Pictures/Gui/ALL/insertergui_search_in_all_except_DP_as.png) (Search all (except Data Portal)).

### Displaying the Eplan Data Portal in the part selection

The Eplan Data Portal is now also displayed in the part selection. To this purpose the user-specific setting Modification allowed during selection has to be activated (command path for example File > Settings > User > Management > Part). The ![](../Pictures/Gui/ALL/userinterface_edpIcon_as.png) "Data Portal" icon is then displayed in the tree of the part selection and the Eplan Data Portal as a tab in the right-hand section of the part selection. Through this extension you can now also search for parts in the Eplan Data Portal during the part selection and download missing parts.

### No search in the Eplan Data Portal for parts pre-filtering

The parts displayed in the Parts management, Part master data navigator, Part selection, Device selection and Insert center dialogs can be limited to a few specific parts by means of a filter scheme. If a parts pre-filtering is set, the icon for the Eplan Data Portal is not displayed in the parts management, in the part selection and in the Insert center. A search in the Eplan Data Portal is then not possible.

#### Changed identification of the parts pre-filtering

In order to identify the set parts pre-filtering more clearly, the titles of the dialogs relevant for the part pre-filtering have been modified. In the case of a parts pre-filtering the database name is now preceded by the text "(Pre-filtering)" instead of the percentage sign "%" (for example Parts management - (Pre-filtering) <EPLAN\_parts>). This applies to all dialogs listed above with the exception of the Insert center. The text "(Pre-filtering)" is displayed behind the "Devices" folder in the Insert center. This identification is used both on the start page and during the search in the Insert center.

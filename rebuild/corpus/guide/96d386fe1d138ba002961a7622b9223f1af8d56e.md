# Opening a Project (Backstage View)

Within the Backstage view you can easily open projects. Projects that are already opened can be identified by the fact that the project names are shown in the title bar of the main window.

The number of projects that are shown in the Backstage view Open and the question whether Eplan has to start again automatically with the last project opened is defined in the user-specific settings for the user interface.

1. Select the following commands: File > Open.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the Last used area you are additionally shown a list of the recently opened projects.  
     
   ![](../Pictures/Gui/ALL/arrow.png) For each project the associated directory is displayed as well as the date and time at which the project was last opened and closed. If the project was opened exclusively or write-protected, the processing mode of the last project state is displayed.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the property preview you are shown - for the project marked in the list - values of some project properties such as Project description, Company name, Last editor, etc. Here the same information is displayed as in the preview window of the Windows Explorer.
2. Double-click the desired project in the Backstage view Open in the list of projects last opened.
3. Select the command Browse if the desired project is not contained in the list.
4. Navigate to the directory where the required project is located in the Open project dialog and select the project.
5. Click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Backstage view is closed, and the project is opened in the page navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project name is shown in bold text in the bar for fast access.

![](../Pictures/Gui/ALL/info.png)Tip:

Via a drop-down list in the Open project dialog you can set a specific processing mode for a project (Default, Exclusive, Read-only). This is, for example, important for working in multi-user operation.

### Pinning projects

You can pin regularly used projects using the icon ![](../Pictures/Gui/ALL/userinterface_unpin_as.png) (pin). These projects are then displayed in a second list above the most recently opened projects. If you do not need an entry pinned at the top anymore, you can remove it from the list of pinned projects by clicking the icon ![](../Pictures/Gui/ALL/userinterface_pin_as.png).

When the specified maximum number is reached in the list of pinned projects, further projects cannot be pinned anymore. You specify the maximum number in the user settings for the user interface.

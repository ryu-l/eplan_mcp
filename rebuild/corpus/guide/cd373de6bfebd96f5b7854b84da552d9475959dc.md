# Dialog Application class selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Master data > Command group Parts > Management. Button [Extras] > Import. You have selected the entry ECLASS version in the File type field. Click the [...] button next to the File type field, select the Class structure assignment tab and click ![](../Pictures/Gui/ALL/all_new_as.png) (New).

This dialog displays the complete ECLASS class tree for the ECLASS segments 19 ("Information, communication and media technology"), 23 ("Machine element, fixing, mounting"), 27 (" Electric engineering, automation, process control engineering ") and 37 ("Industrial piping").

Overview of the main dialog elements:

List:

The list contains all the classes for the corresponding ECLASS segments in a structured tree view. Here you can carry out a free selection of segments, main groups, etc. for the assignment to Eplan properties.

![](../Pictures/Gui/ALL/note.png)Note:

ECLASS properties that are identified as "Deprecated" are not offered for the assignment.

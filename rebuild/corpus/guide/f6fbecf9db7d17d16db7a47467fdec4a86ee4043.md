# Copying a Project (Project Management)

You can create a project by copying and adapting an existing project.

Precondition:

In the tree structure of project management, there is an imported directory with at least one project.

1. Select the following commands: File > Project management.
2. Select the project name in the tree structure.
3. Select the Copy popup menu item.
4. Select the scope of the project to be copied in the [Copy project](prjmanagementgui_d_projektkopieren.htm) dialog.
5. Next to the Target project field, click [...] and, in the Copy to dialog, enter the storage location and the name of the project copy.
6. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan copies the \*.elk project file and the associated \*.edb project directory to the target directory.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The copied project is automatically imported into project management.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The (last) copied project is opened automatically.

![](../Pictures/Gui/ALL/note.png)Note:

You can also select and copy several projects. In this case, the Copy project dialog opens several times, one after the other.

# Dialog Rights management

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Extras > Command group Extensions > Rights management > Rights management

In this dialog you manage users and user groups. To do this, you define the editing rights belonging to a user group. Users, passwords, and group membership as well as the assignment of the rights to the user groups are managed in a central file, the rights database.

If the rights database (via the operating system) was write-protected, then the Rights management dialog will also show "write-protected" in the heading line. If you carry out modifications in a write-protected rights database, these will not be saved, and a system message is generated.

![](../Pictures/Gui/ALL/note.png)Note:

Please note that administration of rights management is not multi-user-capable. Rights management should only be edited by one Eplan administrator at a certain time, otherwise, only the modifications of the Eplan administrator who closed rights management last will be saved.

Overview of the main dialog elements:

The following folders are displayed in the left-hand field:

- User: If you have selected this folder, the existing users are displayed in the right-hand side and you can then edit these or create new users. In addition, you can import the Windows users and groups from Active Directory. Once you have opened the folder, you can select individual users and define their group membership.
- Groups: If you have selected this folder, the existing user groups are displayed in the right-hand side and you can then edit these or create new user groups. Once you have opened the folder, you can select individual user groups and define their editing rights.
- Operating mode: Here you define whether Eplan is operated with or without rights management.

Users and user groups are differentiated by the following icons:

| Icon | Meaning |
| --- | --- |
|  | Users |
|  | Users imported from Windows |
|  | Active Directory group imported from Windows. Is displayed and managed in the rights management like a user |
|  | User group |

[Import]:

Allows for a rights database to be imported from a previous Eplan version into the rights management. Select the desired database file (\*.erm) in the subsequent dialog. This is an Eplan-internal file format which is used as of Version 2.3. An import of rights databases from older Eplan versions is not possible.

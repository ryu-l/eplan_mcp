# Dialog Settings: Parts pre-filtering

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > User > Management > Parts pre-filtering.

In this dialog you can pre-filter the parts management, the part master data navigator, the part selection, the device selection and the Insert center on the basis of specific properties.

Overview of the main dialog elements:

Filter:

This drop-down list contains all the filter schemes already defined. Through [...] you branch into the dialog [Filter](modaldialogsdb_d_filternnach.htm) in which you can for example create a new scheme and assign filter criteria. To this purpose the Criteria selection dialog offers part properties such as Discontinued part, ERP / PDM number, etc.

![](../Pictures/Gui/ALL/note.png)Notes:

- If a parts pre-filtering is set, the icon for the Eplan Data Portal is not displayed in the parts management, in the part selection and in the Insert center. A search in the Eplan Data Portal is then not possible.
- If such a filter is activated, the text "(Pre-filtering)" is displayed in front of the name of the parts database in the title bar of the dialogs listed above (for example Parts management - (Pre-filtering) <EPLAN\_parts>). This applies to all dialogs listed above with the exception of the Insert center. The text "(Pre-filtering)" is displayed behind the "Devices" folder in the Insert center. This identification is used both on the start page and during the search in the Insert center.
- The parts pre-filtering has an effect on the [Insert center](insertergui_k_start.htm). You can, for example, restrict the number of devices offered for insertion to a specific manufacturer by means of a corresponding scheme.

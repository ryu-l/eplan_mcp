# P004087: Missing start address

### Causes

- The required value is missing at the Start address of PLC card properties at a PLC box that only has inputs or outputs.
- In the case of a PLC box that disposes of inputs and outputs, the required value is missing at the Start address of PLC card and/or the Start address 2 of PLC card properties.
- The required value is missing at the PLC subdevice x: Start address (inputs) properties at a PLC box that disposes of inputs at the PLC subdevice x.
- The required value is missing at the PLC subdevice x: Start address (outputs) properties at a PLC box that disposes of outputs at the PLC subdevice x.   
  ("x" designates the number of the PLC subdevice 1 to 12. At the PLC connection points, the PLC subdevice: Index property specifies to which subdevice of the PLC box the PLC connection points belong.)

### Solution

1. Locate the PLC box in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Open the property dialog of the PLC box.
3. Bring the first tab to the front.
4. In the properties table fill in the value fields of the properties Start address of PLC card for inputs and Start address 2 of PLC card for outputs in accordance with the conditions described above under 'Cause'. Or fill in the value fields of the PLC subdevice x: Start address (inputs) or PLC subdevice x: Start address (outputs) properties.
5. Click [OK].
6. If required, start a new check run.

# Dialog Properties (Device list)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Tab Devices > Command group Devices > Drop-down button Navigator > Device list > Popup menu item New.
- You have opened an editor such as the graphical editor, the plot frame editor, etc. Tab View > Command group Navigators > Drop-down button Open > Device list. Select a part in the device list. Popup menu item Properties.

In this dialog you can enter a new part to be monitored as well as view and edit the properties of an existing part.

Overview of the main dialog elements:

Part number:

Manually enter a part number here, or click [...] to open [part selection](partselectiongui_d_artikelauswahl.htm) and select a part there.

During entry as many characters as you wish are possible for the part number, but only the first 96 characters in the UTF-8 format are identifying.

Variant:

The variant is adopted from the parts management based on the part number.

ERP number:

The ERP number is adopted from parts management based on the part number.

Type number:

The type number is adopted from the parts management based on the part number.

Order number:

The order number is adopted from the parts management based on the part number.

Trade:

The trade is adopted from parts management, starting from the part number, and is prepopulated with the first placed trade setting of the part. If you need to, select another trade from the drop-down list. When placing a device from the device list, the trade and the subtrade will be adopted in the component.

Subtrade:

Here you enter the subtrade of the device if you need to. This information does not come from parts management and has to be separately entered.

Designation 1 - 3:

The designations are adopted from the parts management based on the part number.

Manufacturer:

The manufacturer is adopted from the parts management based on the part number.

Macro:

If a macro is assigned to the part, the macro name is displayed here.

Number allowed:

Enter the number of units of the current part that can be used in the project.

Total number allowed:

In this field is the sum of all Number allowed field values for all parts with the same part number.

Used unit quantity:

Indicates how often a part was actually used in the project. (The part references are counted for this.) Deviations from the allowed quantity are permitted and will be reported in the test run.

System part:

Here you enter the name of the system part into which the device is to be installed (for example "Conveyor element 15"). This information does not come from parts management and has to be separately entered.

Device description:

Enter a description of the functionality of the device. This information does not come from parts management and has to be separately entered. A part may occur multiply in the device list under different device descriptions.

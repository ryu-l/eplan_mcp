# Copying, Cutting, and Pasting Elements

Eplan supports the familiar Windows commands for copying, cutting, and pasting of elements.

Precondition:

You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc.

1. Select the desired elements and select either the popup menu item Copy, or Cut.
2. If you work with multiple clipboards (definable in the user settings), then enter a description for the contents of the relevant clipboard in the [Clipboard](macrosgui_d_zwischenablage.htm) dialog, and click [OK].
3. If necessary, open a different page where you want to insert the copied / cut elements.
4. Select the Insert popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you are working with multiple Clipboards, the [Paste](macrosgui_d_einfuegen.htm) dialog opens. Select the desired element and click [OK].
5. Move the cursor to the position where you want to insert the elements and press [Enter].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The contents of the Clipboard are pasted into the currently open page.

![](../Pictures/Gui/ALL/note.png)Notes:

- Each call of the commands Copy or Cut overwrites the current contents of the Clipboard, if you are only working with one Clipboard.
- If you press [X] or [Y] when inserting, the elements will be positioned horizontally or vertically aligned with the original.
- When copying table cells from property tables the contents of the clipboard for copying & pasting in Excel is saved in the HTML format. This way the column header is also always inserted by default when a copied table cell is inserted in Excel. If only the text of the table cell is to be inserted, you have to insert the contents of the clipboard via "Insert contents" as text without formatting when inserting into Excel.

### Copy elements using drag and drop

The copying of elements can also be performed using the Windows-compliant Drag & Drop technique.

1. Select the elements to be copied.
2. Hold down [Ctrl] and the left mouse button, pull the elements to the new position, and release the keys.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A copy of the elements is inserted at the corresponding position.

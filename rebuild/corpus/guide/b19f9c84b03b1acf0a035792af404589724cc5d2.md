# P004121: 'Symbolic address: UDT (data type)' is not unique

### Cause

Within a CPU there are several PLC connection points where the same value is entered in the Symbolic address: UDT (name) property. At one or more of these PLC connection points there are contradictory values with regard to the Symbolic address: UDT (data type) property.

### Solution

1. Locate the PLC connection point in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Open the property dialog of the PLC connection point.
3. In the property table enter a unique value in the field Symbolic address: UDT (data type). This value must be the same at all PLC connection points within the CPU where the property Symbolic address: UDT (name) has an identical value.
4. Click [OK].
5. If required, start a new check run.

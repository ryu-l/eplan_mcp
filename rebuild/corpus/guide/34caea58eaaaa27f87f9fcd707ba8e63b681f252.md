# Editing Symbols

Precondition:

You have opened a project and at least one symbol library.

1. Select the following commands: Tab Master data > Command group Symbols > Drop-down button Symbol > Open.
2. In the Symbol selection dialog select the symbols you would like to edit.
3. For faster selection, click [...] in the Filter field if necessary, and then select the filter criteria or create new ones.
4. Or enter a character string in the Direct entry field in the list view.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The cursor jumps to the first symbol matching your entry as soon as you enter a single character, and selects it.
5. Select the popup menu item Function-oriented in the tree view if the hierarchical display of the symbols should not be carried out according to the symbol library, but according to their functional Category (such as "Coils and contacts", "Signal devices", etc.).
6. In the list view select the popup menu item Configure representation if you would like to change the display and / or the order of the symbol properties in the list.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Every selected symbol is displayed in a separate window of the symbol editor, showing the first available symbol variant. Use the Clipboard to exchange data between multiple open symbols.
8. Edit the graphics of the symbols, i.e. by adding connection points and changing and / or adding the property placements.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The default settings for line properties (type, thickness, color, etc.) as well as the display-specific properties of the connection point designation and the connection point description are taken from the corresponding layers (Tab Tools > Command group Management > Layers. Node "Symbol graphic" or "Property placement").

![](../Pictures/Gui/ALL/note.png)Notes:

- The grid used is saved in the symbol library properties and applies to all symbols in this library.
- The insertion point for a symbol can be moved but not deleted because it marks the location where the symbol hangs on the cursor when being placed. The insertion point is also decisive for the symbol position and therefore also for the cross-reference.

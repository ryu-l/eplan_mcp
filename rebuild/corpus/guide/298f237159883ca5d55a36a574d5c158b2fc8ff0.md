# Tab Thread (Settings: Export NC - DXF / Settings: Export DXF - copper)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Export NC - DXF:

- File > Settings > Company > Machining > Export NC - DXF. Select the Thread tab.
- File > Export > Command group Manufacturing data > Machining > NC - DXF. Click [...] next to the Machine field. Select the Thread tab.

Export DXF - copper:

- File > Settings > Company > Machining > Export DXF - copper. Select the Thread tab.
- File > Export > Command group Manufacturing data > Machining > DXF - Copper. Click [...] next to the Machine field. Select the Thread tab.

In this tab, you specify the settings on visibility as well as layers and colors of threads.

Overview of the main dialog elements:

Group box Format for thread

Export as circle:

During the DXF export, threads are represented as geometric shapes and assigned to specific layers and colors. If the check box is activated, the thread will be generated as the DXF element "circle with center".

Layer:

Default name of the layer where the thread is stored in the DXF file.

Color:

Default color that is assigned to the thread in the DXF file.

Export as text:

Alternatively, or in addition to the representation of a thread as a circle, you can specify text with a prefix to output the thread. If the check box is activated, the thread is characterized with the diameter. In addition, the text can be preceded by a prefix.

Layer:

Default name of the layer where the text is stored in the DXF file.

Color:

Default color that is assigned to the text in the DXF file.

Prefix:

Here you enter the string that precedes the text at the thread.

Export with:

Here you specify whether the Core hole diameter or the Nominal diameter is to be exported for threaded holes for the Export NC - DXF. Your selection depends on the machine or application for which you are exporting data.

![](../Pictures/Gui/ALL/note.png)Note:

The values according to DIN 13-1 are exported for the core hole diameter.

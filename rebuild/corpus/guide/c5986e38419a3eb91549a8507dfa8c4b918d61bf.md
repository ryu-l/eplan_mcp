# Dialog Attribute definition

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > User > Interfaces > DXF / DWG export and import. Select the Block attribute tab. Select an entry from the Available properties list and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).
- File > Export > Command group Project data > Project data > Command group Page > DXF / DWG. Click [...] next to the Scheme field. Select the Block attribute tab. Select an entry from the Available properties list and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).

In this dialog you specify the assignments of the Eplan properties to the AutoCAD attributes.

Overview of the main dialog elements:

Category:

From the drop-down list, select the category whose properties should be displayed in the list below. The properties for each element selected from Available properties are displayed.

Attribute designation:

Enter the designation under which the selected element is to be applied in AutoCAD.

Command prompt:

Enter an input prompt for the selected property here.

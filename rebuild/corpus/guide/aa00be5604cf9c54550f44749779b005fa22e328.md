# Scaling and Stretching Elements

Precondition:

You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc.

### Scaling elements

1. Mark the desired elements, and select the following commands: Tab Edit > Command group Graphic > Scale.
2. Specify the origin point for the scaling.
3. In the Scale dialog, indicate the Scaling factor, and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The elements will then be enlarged or shrunk relative to the point of origin. Texts can also be scaled; in this case, the font size is also changed.

### Stretching elements

You use the Stretch command to move one or more selected points of graphical elements, thereby stretching them. Points of rectangles, lines, and polylines can be moved. All graphical elements that are completely selected are moved.   
 If this is a dimensioned point then the dimensioning is also changed.

![](../Pictures/Gui/ALL/note.png)Note:

Only graphical elements, not components, may be stretched.

1. Select the following commands: Tab Edit > Command group Graphic > Stretch.
2. Open a frame around the desired element points in order to select them.
3. Move the marked element points to the desired position.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The line is extended or shortened to this point.

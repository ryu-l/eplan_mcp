# Dialog Settings: Hose line configurator

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > User > Add-ons > Hose line configurator
- You have opened a project. You have opened the [Configure hose lines](fluidhoseconfiggui_d_schlauchleitungen.htm) dialog. Select the Extras > Settings menu items.

In this dialog you define the properties and values for the configuration of the hose lines and save them as a scheme. The information stored here is offered for selection when the hose lines are configured in the Edit <...> dialog.

![](../Pictures/Gui/ALL/note.png)Note:

The scheme DIN 20066\_2012-01 is preset by default. It allows you to configure hose lines conforming to the specifications of the standard DIN 20066.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Tabs:

In the tabs specify the settings for the configuration data:

- [Tab General](fluidhoseconfiggui_r_nummerierung.htm)
- [Tab Nominal diameter](fluidhoseconfiggui_r_nenndurchmesser.htm)
- [Tab Manufacturer](fluidhoseconfiggui_r_hersteller.htm)
- [Tab Fittings](fluidhoseconfiggui_r_armaturen.htm)
- [Tab Hose groups](fluidhoseconfiggui_r_schlauchgruppen.htm)
- [Tab Hose assignments](fluidhoseconfiggui_r_schlauchzuordnungen.htm)
- [Tab Further properties](fluidhoseconfiggui_r_weitereeigenschaften.htm)

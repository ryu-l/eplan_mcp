# Multi-user Monitor: Principle

The monitor for multi-user operation was implemented as a client-server solution.

The server application is installed on the required computer by the Eplan installation wizard. This may also be a "normal" Eplan workstation. The server application is then available as a service in the server-computer's Control Panel. This Eplan Multiuser Monitor service starts automatically.

For the other Eplan workstations to be able to log onto this "monitor server" when the program is started, a further setting has to be carried out in Eplan on the relevant client computers (File > Settings > User > Management > Multi-user monitor).

When the service and the client-server connection have been set up, the monitor server receives the information about actions that have been carried out, collates it, and redistributes it to the Eplan workstations.

![](../Pictures/Gui/ALL/note.png)Note:

We recommend that a system administrator sets up the multi-user monitor and makes the necessary settings on the Eplan workstations.

# Adding up Cable Lengths

The cable lengths used in the project can be automatically totaled up for each cable type, in order to determine the number of cable drums needed. The same types of a cable will be combined into one cable project part and the lengths of the individual cables added together. The parts do not have to match, but the physical properties of the cables must match. To this purpose the [complete cable type](cablegui_d_kabelmengenberechnung.htm#VollstaendigerKabeltyp) is reported.

You can only calculate the summation of cable lengths for the entire project.

Preconditions:

- Cable lengths are entered for the cables.
- A project is selected in the page navigator.
- Information from which the part length is determined is stored at the parts in the parts management. To this purpose the following properties of the "Prices" hierarchy level are used: Quantity/packaging (ID 22122), Price unit (ID 22043), Quantity unit (ID 22042).

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

For a specific cable type, the manufacturer sells the cables in 4 rolls of 25 m each for a total of 200.00 euros. The minimum order amount is thus 100 m of cable. The price unit is "25", the quantity unit "m", and the quantity per packaging "4".

Then enter the following values for the properties of the cable part in the parts management:

Price unit: 25  
Quantity unit: m  
Quantity/packaging: 4

1. Select the following commands: Tab Connections > Command group Cables > Drop-down button Edit > Add up cable lengths.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The cable types and their calculated lengths are displayed in the Add up cable lengths dialog. In addition, the length of the longest individual cable is displayed. In addition, the part assigned to the longest individual cable is displayed along with the cable's length. The required quantity of the part is also displayed.
2. If necessary, change the value displayed in the Required quantity field. (This can be necessary if cutting problems arise: For three single lengths of 57 m, three 100 m drums will be needed, not two.)
3. Select the Parts selection popup menu item if you want to select a new cable part.
4. Select the Delete popup menu item in order to delete a part and thus exclude it from later reports.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The old cable project parts are deleted and new ones are entered.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The quantity of parts is reset to zero on the individual cables.

![](../Pictures/Gui/ALL/note.png)Note:

You can view, edit and delete the project parts in the Bill of materials - <Project name> navigator dialog. The changes, however, are overwritten in the next cable length calculation.

To display the project parts you have to activate the Cable project parts check box in the dialog Settings: Parts (can be accessed in the bill of materials navigator via the popup menu item Settings). The Project part check box has to be activated in the column configuration for the list view of the bill of materials navigator (via the Configure representation popup menu item) to show the corresponding column.

### Exclude cables from the addition of the cable lengths

You have the option of excluding cables from the cable length summation.

Prefabricated cables (these are cable parts of the product grouping "Electrical engineering > Cables > Prefabricated") are always excluded from the summation.

1. Double-click a cable definition line.
2. In the Properties <...> dialog select the Cables tab.
3. If the Do not use cable when adding up cable lengths property is not yet displayed in the table, go to ![](../Pictures/Gui/ALL/all_new_as.png) (New) to add it.
4. Select the check box for the Do not use cable when adding up cable lengths property.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the main part of the cable has a quantity of zero, a message will appear because this value may have been generated while adding up the cable lengths.

# P027028: The length of the routing path is greater than the delivery length of the part

### Cause

A part with a specific delivery length was assigned to a placed routing in the routing path network. However, the length of the routing path is greater than the delivery length entered at the part.

### Solution

1. Locate the routing path in your routing path network using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Reduce the length of the routing path at least to the dimension of the delivery length or make the routing path smaller. Or alternatively select a part that has a delivery length that is greater than the length of the routing path.
3. If required, start a new check run.

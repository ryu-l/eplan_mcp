# Exporting NC Data

Representative for all the NC interfaces, the NC export for the "Rittal - Perforex BC / Secarex" format is described here. The NC export of the other interfaces is done in the same manner, but differs in terms of the values to be entered in the export dialog and of the file formats generated.

Preconditions:

- You have opened a project.
- An NC machine of the required type is defined in the company settings.
- You have opened the layout space navigator and a layout space.
- You have selected a mounting panel / or construction items in the navigator or the layout space.

1. Select the following commands: File > Export > Command group Manufacturing data > Machining > Rittal - Perforex BC.
2. In the Export Rittal - Perforex BC / Secarex dialog select the required machine, material and the output directory or leave use the default settings unchanged.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the set output directory, several files are generated that contain the names of the exported items and the coordinates of the NC drill holes and milling cuts. This data is transferred to the software of the NC machine and controls the manufacture.

# P015003: The jumper '<x>' could not be output

### Cause

The number of set jumper levels is set too low.

### Solution

1. Locate the relevant jumper in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Increase the number of jumper levels or set the number of jumper levels to "0" in order to output all the jumpers as targets.
3. Subsequently start a new check run and a new report.

![](../Pictures/Gui/ALL/note.png) Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

# Icons in the Navigators

The following table lists the most important icons and their meaning that are used in several project data navigators.

If you position the cursor on an icon in the tree views of the project data navigators, you are seeing a short information text (tooltip) about this icon. If icons are combined (for example ![](../Pictures/Gui/ALL/navigatorgui_mainfunctionpart_as.png)![](../Pictures/Gui/ALL/navigatorgui_function_as.png) for a placed multi-line main function), a separate tooltip is displayed for each icon.

Specific icons are explained in the respective navigator dialogs.

![](../Pictures/Gui/ALL/note.png)Notes:

- The icons for the various representation types and for the special functions (for example black boxes, cable definitions, etc.) are often used in combination with other icons. Thus the preceding icon ![](../Pictures/Gui/ALL/navigatorgui_mainfunctionpart_as.png) means a main function (for example ![](../Pictures/Gui/ALL/navigatorgui_mainfunctionpart_as.png)![](../Pictures/Gui/ALL/navigatorgui_function_as.png) multi-line main function).
- In the navigators for displaying devices all the devices that have only a device tag but no structure identifiers such as function designation, location designation, etc. are sorted into the ![](../Pictures/Gui/ALL/navigatorgui_device_as.png) Without structure identifier tree structure level. All the devices that do not have a DT are sorted into the ![](../Pictures/Gui/ALL/navigatorgui_device_as.png) Without DT tree structure level.

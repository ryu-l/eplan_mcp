# Closing Symbol Libraries

Precondition:

You have opened a project and at least one symbol library.

1. Select the following commands: Tab Master data > Command group Symbols > Drop-down button Symbol library > Close.
2. If several symbol libraries are open, select the ones you would like to close in the Symbol library selection dialog and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) If only one symbol library is open, this one will be closed without any further prompting.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If changes have been made to a symbol and would be lost if the library is closed, you are prompted whether to save the page or not.

![](../Pictures/Gui/ALL/note.png)Note:

If the Close / Save action is canceled for a symbol, the symbol library will also not be closed.

# Dialog Export Address space assignment

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Tab Devices > Command group PLC > Assignment list > Button [Extras] > Export address space assignment.

In this dialog you export the address space assignment of a CPU. A language independent list is exported that specifies which addresses are occupied by which PLC card. Only PLC cards are exported at which the [Address range](devicetaggui_r_spskarte.htm#Eigenschaften) is specified by entering a start address and the associated data length.

The address space assignment list is structured as follows:

- Structure of a line: "Byte number", "DT (input card)", "DT (output card)"  
  Example (separate PLC cards for inputs and outputs): "0","=A1+O1-K1","=A1+O1-K2"  
  Example (PLC card has both inputs and outputs): "0","=A1+O1-K1","=A1+O1-K1"
- The line is repeated if a PLC card occupies multiple bytes.
- If a byte is not occupied, the entry for the DT remains empty.
- The output of the list ends with the last occupied byte.

![](../Pictures/Gui/ALL/note.png)Note:

You can export only one separate list each for each processor (CPU). Therefore set the filter in the dialog Addresses / assignment lists so that the PLC addresses of only one CPU are displayed.

Overview of the main dialog elements:

PLC-specific settings:

The scheme which defines the format of the PLC addresses is displayed in this field. The scheme is determined on the basis of the CPU that is contained in the selection and cannot be changed here. If no scheme is assigned to the CPU, the scheme specified in the project settings is used. The configuration project and the workstation name to which the CPU is assigned are further displayed via the field.

File name:

In this field, you enter the name of the file where the address space assignment list is saved. Click ![](../Pictures/Gui/ALL/all_selectfile_as.png) to open the file selection dialog where you can select an address space assignment list that you wish to overwrite or whose name you wish to change. You can save the list as a CSV file or as a TXT file.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

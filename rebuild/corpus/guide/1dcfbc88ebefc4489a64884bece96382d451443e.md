# Import Design Space

Eplan Design Space Exchange is used in 3 working steps:

- The import of design spaces as STEP files from 3D CAD programs
- The creation of a mounting layout in Eplan Pro Panel
- The export of the design space with added mounting layout and NC data to a 3D CAD program.

The following section describes the first working step, the import of STEP files.

The settings for the STEP import can be adjusted in the user-specific settings (File > Settings > User > Interfaces > Design space import and export).

Precondition:

You have opened a project. The layout space navigator is open.

1. Select the following commands: File > Import > Command group Project data > Layout space > Design space.
2. In the Open open a STEP file that was generated by a 3D CAD program.
3. In the Design space import dialog select a scheme with settings for the import of the selected source file or use [...] to open the settings dialog and change the settings.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Design space import - define items dialog is opened.
5. If required, overwrite the settings from the import scheme and specify a placement area.

![](../Pictures/Gui/ALL/warning.png)Caution:

Mounting surfaces and field sizes are generated automatically during the import, whereby the field sizes correspond to the external dimensions of the mounting surfaces. When selecting the placement area ensure that the enclosure stands upright and points with the doors forward. Otherwise mounting surfaces may not be generated automatically.

6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The 3D graphic data from the STEP file are imported into a separate layout space. In the layout space navigator, an enclosure node is created under which all the items are arranged without nesting.

![](../Pictures/Gui/ALL/note.png)Note:

The imported geometry is partially protected against changes. Properties of items can be changed, but items cannot be deleted or moved.

7. Create the mounting layout in the imported design space using the functionality of Eplan Pro Panel. Depending on the settings in the import scheme you may only have to carry out customizations.

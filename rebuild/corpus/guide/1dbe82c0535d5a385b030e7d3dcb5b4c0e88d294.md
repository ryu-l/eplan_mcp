# P502036: The part property 'ERP / PDM number <x>' is not identical at all variants of the part.

### Cause

In the parts database to be checked a part was found which has different variants. A different value was entered respectively at the ERP / PDM number <x> part property at the variants of the part. This may have been caused by editing via the Eplan API.

(The variable <x> can assume values from 1 to 10. Up to ten ERP / PDM numbers can be stored at a part variant in the ERP / PDM number 1 to ERP / PDM number 10 properties.)

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Properties tab for all variants of the part to the foreground.
3. In the property table open the respective hierarchy level General.
4. Enter identical values for the ERP / PDM number <x> property at all variants.
5. Click [Apply].
6. If required, start a new check run.
7. Close the parts management and perform a parts data synchronization.

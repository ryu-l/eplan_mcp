# Tab Connection filter

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Settings > Projects > "Project name" > Routing connections > General. Select the Connection filter tab.

In this tab, you can define a filter for the generation of routing path networks. This filter is used for routing path networks in the layout space and the topology.

In the Layout space, the filter criteria defined here are available later in the project for selection at channels, routing paths and routing ranges in the property Layout space: Connection filter (ID 36026). The connection filter is used for routing to control which connections may be routed through which routing tracks (channel, manual routing path, routing range, wiring cut-out). Connection filters are taken into account only if the Layout space: Routing track specification (ID 31094) property is not filled.

In the Topology, the filter criteria defined here are available later in the project for selection at the routing paths in the property Topology: Connection filter (ID 20247). The connection filter is used during routing to control which connections may be routed through which routing track (routing paths and routing points).

Overview of the main dialog elements:

Selected connection property:

Using [...], open the Criteria selection dialog and select there one of the connection properties provided.

In the table, you can enter up to 100 values as criteria for the selected connection property.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

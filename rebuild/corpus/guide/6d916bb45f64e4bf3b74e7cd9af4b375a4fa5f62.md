# P004110: Physical network without name

### Cause

Several interconnected bus ports are combined into a physical network. In the concrete case no name was assigned to the physical network.

### Solution

1. Locate the network via the Go to (graphic) functionality, that is contained in the popup menu of the dialog Message management to jump to the first network / bus cable connection point of the network.
2. Call up the property dialog of the network / bus cable connection point and enter a value in the Bus data tab in the Physical network: Name field. Alternatively to this you can also enter the name into another network / bus cable connection point that is connected to the physical network. It is sufficient if the name of the physical network is entered at least in one of the network / bus cable connection points that are interconnected.
3. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

This check run is "project-specific". This means that the check run is only performed if you have marked the project name in the page navigator or have selected the Apply to entire project check box in the Run check dialog.

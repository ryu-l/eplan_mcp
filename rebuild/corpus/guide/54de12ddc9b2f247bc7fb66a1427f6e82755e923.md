# Dialog "Undo in project <Project name>" / Dialog "Redo in project <Project name>"

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Calling up Undo in the project <Project name> dialog:](javascript:void(0);)

You have opened a project. You have carried out one or more modifications to the project. Quick access toolbar: Undo list.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Calling up Redo in project <Project name> dialog:](javascript:void(0);)

You have opened a project. You have undone one or more modifications to the project. Quick access toolbar: Redo list.

The last (up to 50) editing steps that you have made / undone since opening the current project are listed in this dialog. The list with the editing steps is only retained until you close the project again. The redo list is deleted as soon as you perform a new action in the project.

Overview of the main dialog elements:

Action:

The actions that you can undo / redo are listed in this column. If you select a line in the list, all lines above this are also selected automatically. This means that the steps can only be undone or redone together and that the currently selected step is included in this.

![](../Pictures/Gui/ALL/note.png) Note:

Please note that the "Eplan print job" action is also listed here, if you have printed a project or a page - but of course, this is an action that cannot be undone or redone. But this is necessary internally, as printing writes information about page printing to the page.

Page:

This column shows the pages where the actions occurred. No pages are displayed for actions that cannot be clearly assigned to a page (e.g. for tabular editing).

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Select all | Selects all of the elements in the list. |

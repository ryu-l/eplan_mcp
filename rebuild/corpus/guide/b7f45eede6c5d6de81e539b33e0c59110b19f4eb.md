# Editing Form Properties

The Form properties - <Form name> dialog is automatically opened when creating a form. However, it can also be called up for an opened form after the event.

Preconditions:

- You have opened a project.
- You have opened a form in the form editor (Tab Master data > Command group Plot frames / forms > Drop-down button Form > Open > Button [Open]).

1. Select the form whose properties you would like to view and edit in the Pages - <Project name> navigator dialog.
2. Select the Properties popup menu item.
3. Select a different form type from the drop-down list in the Form properties - <Form name> dialog, if necessary.
4. Specify the values for the properties by either entering or overwriting an entry or selecting a template value from a drop-down list, or jump to a special dialog in which you can enter additional data.
5. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) on the toolbar above the table Property name / value.
6. In the Property selection dialog, select a new property that you would like to assign to the form.
7. Click [OK].
8. Assign the property a value.
9. Proceed in a similar manner for all of the other properties.
10. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The form is displayed with changed / new data in the form editor.

![](../Pictures/Gui/ALL/note.png)Note:

Usually all form properties are available, but these should be selected depending on the Form handling property. For example, dynamic form properties (such as the Adapt row height dynamically property) are meaningless for static forms.

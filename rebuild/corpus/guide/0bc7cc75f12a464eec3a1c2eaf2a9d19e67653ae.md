# Assigning a Part to a Device

Parts can only be assigned to the main function of a device. Eplan accesses the master data stored in parts management, making it possible to select the correct data for the current device with a parts selection dialog.

Preconditions:

- You have opened a project.
- You have opened the property dialog for a component / function, for example via the Properties popup menu item.
- The Main function check box on the <Function category> tab (or the Symbol / function data tab) is selected.

1. In the Properties <â¦> dialog, select the Parts tab.
2. Click [...] in the Part number field.
3. In the Part selection dialog select the desired parts. Multiple selection is possible.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The data are adopted in the corresponding fields of the Parts tab, whereby the Number of units / quantity field is preset to "1".
5. If necessary, edit the properties of the part in the right-hand side of the dialog.
6. Click [OK].

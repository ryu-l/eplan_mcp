# Dialog Settings: Default symbols

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.File > Settings > Projects > "Project name" > Connections > Default symbols. Select the Multi-line, Single-line or General tab.

In this dialog you specify the default symbols for connection definition points, potential definition points, and net definition points project-specifically. These default symbols are used when manually placing connection definition points, potential definition points, and net definition points. These symbols are also used when the properties of a connection are changed (for example in the connection navigator) and a connection definition point is placed automatically as a result. This setting, however, does not apply to connection definition points that are placed by the connection numbering. For such connection definition points you specify the symbol in the settings for connection numbering.

Overview of the main dialog elements:

The dialog contains the following tabs:

- Multi-line: Here you define the default symbols for connection definition points that are placed on multi-line pages.
- Single-line: Here you define the default symbols for connection definition points that are placed on single-line pages.
- General: Here you define the default symbols for potential definition points and net definition points. The symbols defined here are placed independently of the representation type.

Each tab contains the following fields:

Number / name:

To specify the default symbols, the Number / Name field is available in each tab. These fields are initially empty. By clicking [...], you open the Symbol selection dialog where you can select the desired symbol. Subsequently the symbol number and the name of the current symbol are displayed here. If available, a preview of the symbol is shown in the adjacent field.

If the symbol has several variants, you can select a different symbol variant in the Variant field by using the drop-down list.

Use the ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) button to remove the selected default symbol. If no standard symbol is specified, the most recently used symbol from the dialog memory is inserted when a connection definition point, potential definition point or net definition point is placed.

![](../Pictures/Gui/ALL/info.png)Tips:

- The set symbol variant is always used for manually placed connection definition points, etc. To select a different variant press the [Tab] key or keep the [Ctrl] key pressed and move the mouse around the symbol. For automatically placed connection definition points, etc., a symbol variant matching the direction of the autoconnecting line is automatically placed.
- If you want to use a different symbol deviating from the specified standard symbol, you can press the [Backspace] key before inserting and select the desired symbol via the symbol selection. (In the process the symbol is stored in the dialog memory.) In addition it is also possible to select a different symbol subsequently in the property dialog of the connection definition points, potential definition points and net definition points.

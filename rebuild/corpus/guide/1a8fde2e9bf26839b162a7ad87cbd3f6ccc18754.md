# Dialog Rights management: Operating mode

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Extras > Command group Extensions > Rights management > Rights management > Folder Operating mode

In this field you specify the operating mode.

Overview of the main dialog elements:

If you have selected the Operating mode folder in the left-hand field, then you can set the desired operating mode in the right-hand field:

Sign in:

Eplan operates using a rights management system. Every user must sign in using their user name. The current Windows user name is entered as a default value in the Eplan sign-in dialog. The user must then only enter their password (which was specified in the rights management).

Signing in of users who were imported from Windows is not supported in this operating mode since a password check is not carried out in Eplan in the Active Directory.

Sign in with Windows user name:

Eplan operates using a rights management system. The user can directly sign in to Eplan using their Windows user name and password. If the (locally) signed-in Windows user is registered as an Eplan user, then the sign-in occurs automatically and the user does not need to enter their user name and password into Eplan.

This operating mode also allows the automatic sign-in of users who were imported from Windows (as Active Directory users or groups).

Without rights management:

Eplan is operated without rights management, i.e., Eplan uses the Windows sign-in name without a password and assigned administrator rights to all Eplan users.

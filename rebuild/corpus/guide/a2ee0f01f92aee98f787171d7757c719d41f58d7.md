# Editing Deletion Markers in Revision Projects

If you have generated a revision of a project, deleted objects on the project pages of the revision project are identified by a revision marker and a deletion marker if the project setting While deleting create deletion markers and list deleted pages is activated. The properties of the deleted object are stored at the deletion marker and can be viewed there.

Precondition:

You have opened a revision project (file name extension \*.ell) containing deletion markers and are viewing a schematic page in the graphical editor.

### [ClosedMove deletion marker](javascript:void(0);)

1. Highlight a deletion marker and move it in the graphical editor.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The deletion marker is given a new revision marker. The color for changed objects alerts the user to the fact that this object has been moved. In addition the marker text is re-generated and updated if necessary.

### [ClosedEdit revision marker texts](javascript:void(0);)

By default, a tooltip with the automatically generated revision marker text is also shown for a deletion marker. This text can be edited later.

1. Select a deletion marker and select the popup menu item Edit revision marker.
2. Change the revision marker text in the [Edit revision marker](revisionlogmgtgui_d_markierungstexte.htm) dialog.
3. Click [OK].

### [ClosedDelete deleted objects permanently](javascript:void(0);)

1. Select a deletion marker and select the popup menu item Delete permanently.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The information relating to the deleted object is permanently deleted from the project.

![](../Pictures/Gui/ALL/note.png)Note:

If the revision marker and the deletion marker of a deleted object are conventionally deleted in the graphical editor (using the popup menu item Delete, for example), then the deleted objects will be replaced by identical, new objects.

![](../Pictures/Gui/ALL/info.png)Tip:

You also have the opportunity to remove all the revision markers and deletion markers in the project that were produced by change tracking. To this purpose select File > Revision control > Command group Modifications > Change tracking > Delete revision.

In a revision with change tracking, deleted pages count as data. To delete them, in the Delete revision dialog, select the Revision data from change tracking check box.

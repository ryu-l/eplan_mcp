# Customizing the Quick Access Toolbar

The quick access toolbar is available above or below the ribbon to allow quick access to commands that are used often. Here you can store such commands that you require frequently as buttons, independently of the placement in the ribbon.

Specific commands which appear multiple times in the ribbon (depending on the context in different tabs and/or command groups) cannot be inserted in the quick access toolbar. This affects, for example, the commands Image file, DXF / DWG, Hyperlink, QR code from the tab Insert which can be assigned to different command groups depending on the context (depending on the editor opened). The commands of the Eplan Cloud products can also not be inserted into the quick access toolbar.

### [ClosedAdd further commands](javascript:void(0);)

1. In the title bar of the Eplan main window click the icon ![](../Pictures/Gui/ALL/all_quickaccess_as.png) (Customize quick access toolbar).
2. Select the command Further commands.
3. In the Customize dialog, switch to the Add quick access tab.
4. In the drop-down list Tabs, select the tab from which you want to select the commands for quick access.
5. In the Commands field mark the desired command and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) to add this command to the quick access toolbar.
6. Click the ![](../Pictures/Gui/ALL/all_arrowup_as.png) and ![](../Pictures/Gui/ALL/all_arrowdown_as.png) buttons to change the sequence of the commands in the toolbar.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected commands are displayed in the title bar as icons in the quick access toolbar and also remain in the toolbar after completion of the program.

### [ClosedAdding commands from the ribbon to quick access](javascript:void(0);)

You can also customize your toolbar via the ribbon.

1. Right-click a command in the ribbon.
2. Select the popup menu item Add to quick access toolbar.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected command is displayed as a button in the quick access toolbar. The associated standard image is always displayed there for the commands from the main tabs or commands of the "Further commands" category.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If no icon is stored in the program for the selected command, a colored dot is shown instead in the toolbar.

### [ClosedDeleting commands from the ribbon for quick access](javascript:void(0);)

1. Right-click a command in the quick access toolbar.
2. Select the popup menu item Remove from quick access toolbar.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The button of the selected command is removed from the quick access toolbar.

### [ClosedResetting the quick access toolbar](javascript:void(0);)

1. Right-click the quick access toolbar.
2. From the popup menu item select the Customize quick access toolbar.
3. In the Customize dialog, switch to the Add quick access tab.
4. Click the [Reset] button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) After confirming a prompt, the quick access toolbar is reset to the default state again.

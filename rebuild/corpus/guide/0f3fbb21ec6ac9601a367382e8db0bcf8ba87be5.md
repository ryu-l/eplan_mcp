# P026053: Connection point '<x>' does not exist and cannot be created

### Cause

Several part placements have the same DT but the required connection point designation <x> does not exist in the connection point patterns that are assigned to the respective parts.

### Solution

1. Add the missing connection point designation in one of the assigned connection point patterns.
2. Route the connections again.

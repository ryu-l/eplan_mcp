# Page Types

Every page is allocated to a particular page type. The page types help to structure a project and accelerate the reporting processes, since non-relevant pages can be skipped. All page types behave the same way in the page navigator.

The page type is assigned when a page is created, but can be subsequently changed. When a page type is changed, all other page properties remain unchanged, the page is just analyzed and reported differently.

![](../Pictures/Gui/ALL/note.png)Note:

The External document page type is an exception to this rule and once created can't be changed later on.

### Logic and graphical pages

Pages are basically either logic pages or graphical pages:

- On Logic pages the device data is analyzed and reported, and autoconnecting lines are automatically generated. (Exception: Auto-connecting does not occur on pages of the type "Panel layout", "Overview" and "Pre-planning".)
- This does not occur with Graphical pages; these are only used for displaying data or for drawing graphics (but not schematics).

The page types are displayed alphabetically sorted in the dialogs (e.g. Page properties). Also displayed is whether they are "Interactive" or "Automatic" (e.g. "Schematic multi-line (I)", "Parts list (A)"). You can generate and edit interactive pages yourself (e.g. schematic or graphical pages), automatic pages are generated automatically as reports and filled with data by Eplan (e.g. terminal or cable diagrams).

![](../Pictures/Gui/ALL/info.png)Tip:

If you position the cursor on an icon in the tree view of the page navigator, a short information text (Tooltip) about this icon is displayed. This way you can quickly notice which type of page this is.

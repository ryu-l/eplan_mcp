# Path Function Texts

Path function texts ease documentation because you don't have to enter a function text for each component. These texts can be positioned arbitrarily within a path and are reported when generating PLC cross-references, in terminal diagrams, and in bills of materials.

If no other function text is entered for a component, the function text from the schematic path will be used for reports.

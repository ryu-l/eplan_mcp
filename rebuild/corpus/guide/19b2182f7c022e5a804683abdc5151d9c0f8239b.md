# Importing Projects

You can import projects that were previously exported in XML format with the epj file suffix.

Backstage view: File > Import > Command group Project data > Project data > Command group Project > Project .

Project management: [Organize] > Import.

1. Select the desired project in the Import project dialog.
2. Click [Open].
3. Check that you have selected the correct project file in the XML file field of the XML project dialog and, if necessary, click [...] to open a different project for the import.
4. Select the Synchronize parts check box if automatic parts synchronization should be performed during the import.
5. If necessary, enter another name in the Target project field for the project to be imported.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project is imported and a progress bar shows the progress. If you have selected the Synchronize parts check box then, after the import, a progress bar shows the progress of the synchronization.

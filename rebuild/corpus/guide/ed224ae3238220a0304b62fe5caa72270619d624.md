# Inserting a Routing Connection

In addition to the automatic routing of connections, there is also a function for the manual definition of routing connections. In this context, routing connections are generated, then routed automatically, and shown in the layout space. After calling up the function, the view of the connection points is activated. All defined connection points of the part placements shown in the layout space are thus visible. The preview of connections should be enabled, too, in order to rule out that duplicate routing connections are generated.

![](../Pictures/Gui/ALL/note.png)Note:

By manually inserting a routing connection, a counterpiece is not automatically generated in the multi-line planning. The check run 005067 checks whether a routing connection generated in this way has a counterpiece in the multi-line schematic. If this is not the case, the missing source and / or missing target should be added to the schematic with the corresponding parts data (device) and connected via an autoconnecting line.

Precondition:

You have opened a project. A layout space is open. The routing path network is generated.

1. Select the following commands: Tab Edit > Command group Routing connections > Drop-down list Route > Routing connection.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection point view is enabled.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the status bar, you are prompted to select the source of the connection.
2. Select as the source one of the connection points of a part placement shown in the layout space, or select a part placement, followed by a connection point from the list of connection points of such a part placement.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the status bar, you are prompted to select the target of the connection.
3. Select as the target one of the connection points of a part placement shown in the layout space, or select a part placement, followed by a connection point from the list of connection points of such a part placement.
4. In the Routing connection dialog select if the connection is to be routed in the routing path network or freely. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Between the selected connection points of the source and target, a routing connection is generated, routed, and displayed in the preview of connections.

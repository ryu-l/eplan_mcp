# Routing Pipings Freely

Pipings that were designed as multi-line connections between fluid power items or screw connections on a fluid power schematic page can be routed freely in the layout space.

Precondition:

You have opened a project. The project contains [pipings to be routed freely in the fluid planning](ftechnic_h_paketedefinieren.htm). You have opened a layout space.

1. Select the following commands: Tab Edit > Command group Routing connections > Drop-down button Route > Free routing. Or you select the Free routing (layout space) popup menu item in the connections navigator.
2. Enter the two corner points of a rectangle that comprises the part placements and connections to be routed.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The curve for the form of the routing connection is calculated.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The routing connections are generated and assigned the specific properties.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The routing connections are displayed as pipes in the 3D representation.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The following figure shows a model with a freely routed piping.

![](../Pictures/Visualisation/ALL/piping_freeroutedpipes_as.png)

3. To change the route for the freely routed connection, select the following commands: Tab Edit > Command group Graphic > Change bending positions or New bending position or Delete bending position.

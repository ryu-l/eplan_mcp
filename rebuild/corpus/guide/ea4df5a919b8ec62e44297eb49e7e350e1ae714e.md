# P008005: Text in project not translated: '<x>'

### Cause

A project text was not translated into one or more languages.

### Solution

1. Have the affected text (text, path function text, property of a function, etc.) displayed in the project from the Message management dialog by means of the Go to (...) functionalities.
2. Open the property dialog of the text or of the function.
3. Mark the field that contains the text that was not translated.
4. Select the Translate popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the dialog Translate the program displays the corresponding translation as it is stored as a keyword in the dictionary for the selected translation languages.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The texts are translated into all the translation languages.
6. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Notes:

If the translation is missing for one or more translation language in the list in the dialog Translate, it has to be added in the corresponding languages in the dictionary.

The message is not output under the following conditions:

- The Do not translate automatically check box was activated for text (Text tab) in the dialog Properties.
- Or a text was marked (completely) as "Excluded from translation'" (popup menu in the dialog Properties for devices or for text (tab Text), menu item Mark text as 'Excluded from translation').
- Or a word was specified as a word not to be translated in the dialog Dictionary (tab Do not translate).

Ensure furthermore that the corresponding check boxes are activated in the settings under File > Settings > Projects > "Project name" > Translation > Extent for describing properties and under File > Settings > Projects > "Project name" > Translation > Translatable pages for page types.

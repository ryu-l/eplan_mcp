# Managing User Groups

The rights management allows you to create user groups and assign particular editing rights to them. You can also subsequently edit or delete user groups.

![](../Pictures/Gui/ALL/note.png)Note:

The user groups predefined by Eplan - "Administrators" and "Guests" - cannot be edited or deleted.

Precondition:

You have opened the rights management: File > Extras > Command group Extensions > Rights management > Rights management

### [ClosedCreate user groups](javascript:void(0);)

1. To the left of the Rights management dialog, select the Groups folder, and click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
2. In the Group dialog, enter a name and short description of the allowed editing rights of the new user group. In contrast to the user names, a distinction is made between upper and lower case in the group names, i.e., a group "QS" and a group "Qs" are different groups.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The group is created, but editing rights have not yet been assigned.
4. Assign editing rights to the group as described under "Assign rights to groups".

### [ClosedCopy user group](javascript:void(0);)

1. To the left of the Rights management dialog, select the Groups folder.
2. Select a user group in the field on the right and click ![](../Pictures/Gui/ALL/all_copy_as.png) (Copy).
3. In the Group dialog, enter a name and short description of the allowed editing rights of the new user group. In contrast to the user names, a distinction is made between upper and lower case in the group names, i.e., a group "QS" and a group "Qs" are different groups.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The group is created and possesses the editing rights of the previously selected user group.
5. Modify, if required, the editing rights as described under "Assign rights to groups".

### [ClosedEdit user groups](javascript:void(0);)

1. To the left of the Rights management dialog, select the Groups folder.
2. Select a (self-defined) user group in the right-hand field and click ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit).
3. In the Group dialog, change the name or description.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The dialog is closed and the changed data is displayed in the Rights management dialog.

### [ClosedDelete user groups](javascript:void(0);)

1. To the left of the Rights management dialog, select the Groups folder.
2. Select a (self-defined) user group in the right-hand field and click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete).  
     
   ![](../Pictures/Gui/ALL/arrow.png) After confirmation of the warning message, the group name is deleted.

### [ClosedAssign rights to groups](javascript:void(0);)

1. In the Rights management dialog, click the ![](../Pictures/Gui/ALL/all_expand_hierarchy_as.png) sign next to the Groups folder to open the folder and select a user group.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The available rights are displayed on the right and are grouped according to topic area.
2. Click the plus sign to open the subordinate rights in front of a topic area.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The rights are divided into editing rights for menu items, dialogs, and API actions. The rights for dialogs are also identified by "[Dialog]". The rights for API actions are also identified by "[Interface]".
3. Select the check boxes in front of the rights the user groups are to possess and deactivate those that are to be revoked.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The activated rights will be assigned to the user group.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If all subordinate rights are deselected for a topic area, then the check box for the topic area is displayed in gray.

![](../Pictures/Gui/ALL/info.png)Tip:

You can assign or revoke all of the rights for a particular topic area by selecting or deselecting the check box in front of the topic area.

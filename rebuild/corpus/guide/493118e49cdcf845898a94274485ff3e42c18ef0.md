# Exchanging Connection Symbols

Connection symbols can be exchanged using the "Draw over" function.

Preconditions:

- You have opened a project. You have opened a project page in the graphical editor.
- The page contains connection symbols.
- You have activated the Connection symbols with prompt check box in the user settings (command path: File > Settings > User > Graphical editing > Connection symbols).

1. Select the Insert tab in the ribbon.
2. Select the button of the desired connection symbol in the command group Symbols. With the button ![](../Pictures/Gui/ALL/ribbon_galleryfurther_as.png) (More) you can expand the field with the symbols and select the desired connection symbols below the Connector field.
3. In the subsequent dialog select the desired target-specific variants for T-nodes, double junctions, and jumpers.
4. Select the Draw as point check box if you want the connection symbol to be drawn as a connection point.
5. Click [OK].
6. If required hold down the [Ctrl] key and move the mouse to page through the existing variants.
7. With the left mouse button click the insertion point of an existing connection symbol in order to place the new connection symbol on this location.
8. Proceed in a similar manner for all additional connection symbols.
9. End the action via the Cancel action popup menu item or via the [Esc] button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The original connection symbol is replaced by the new one. The following restriction applies to interruption points: An interruption point can draw over an angle (a T-node) but not vice-versa.

![](../Pictures/Gui/ALL/note.png) Note:

As soon as you double-click the connection symbol with the left mouse button, a dialog containing the list of variants for the selected connection symbol opens. Select a variant to replace the current variant. This does not apply to angles.

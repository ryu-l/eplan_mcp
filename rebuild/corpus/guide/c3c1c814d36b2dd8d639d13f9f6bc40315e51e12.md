# P022027: Text is too small

### Cause

A text was found on a project page whose font size is smaller than the minimum font size defined in the project-specific settings.

### Solution

1. First locate the text in the project by using the Go to (graphic) functionality from the popup menu of the Message management dialog.
2. Open the Properties <...> dialog of the text, bring the Format tab to the foreground and specify the set value in the Font size field.
3. Select the following commands: File > Settings > Project > "Project name" > Graphical editing > General and determine the set value in the Min. font size for test field.
4. Either increase the value of the font size of the text so that the set minimum font size is exceeded. Or reduce the value for the project-specific setting in the field Min. font size for test so that the font size currently used for the text becomes valid and an error is no longer reported.
5. If required, start a new check run.

# P002004: Plug without pins

### Cause

You have created a plug definition in the plug navigator that has no pins assigned yet or you have placed a plug definition without pins in the schematic.

### Solution

#### Possibility 1

1. Create at least one pin in the plug navigator by using the popup menu New, or place at least one pin in the schematic via the Symbols object type of the Insert center.
2. Assign the DT of the plug definition to the pin and give it a designation.

#### Possibility 2

1. Select the plug definition in the plug navigator.
2. Select the Generate pin popup menu item, and branch to the submenu Male and female pin, Male pin, or Female pin.
3. Click [OK] in the property dialog that is opened.

If required, start a new check run.

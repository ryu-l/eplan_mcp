# P011007: Branch before a star source

### Cause

A branch (for example a T-node) is located before the arrow head or behind the arrow stub of an interruption point that has the property Star source. This means that the arrow head or arrow stub of the star source leads to two targets. Interruption points that are designated as a star source only allow one target.

### Solution

#### Possibility 1

1. Locate the interruption point that is defined as a star source in the schematic by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Delete the branch (the T-node) before the arrow head or behind the arrow stub of the interruption point so that only one connection to the star source is retained.
3. Update the connections.
4. If required, start a new check run.

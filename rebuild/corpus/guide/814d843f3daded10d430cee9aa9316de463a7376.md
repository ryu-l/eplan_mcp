# Distributing Elements Evenly in the Layout Space

Several marked 3D part placements can be arranged in the same distance from each other in horizontal or vertical direction ("distribute evenly"). For this purpose, the 3D objects to be distributed must be on a common mounting surface or mounting rail. The even distribution of objects on different mounting surfaces is not meaningful. Therefore, distribution is not available when objects have been highlighted that are not positioned on a common mounting surface or mounting rail.

Precondition:

You have opened a layout space. You have selected the "Front" 3D viewpoint.

### [ClosedSpacing general 3D objects evenly](javascript:void(0);)

1. Mark the corresponding 3D objects.
2. Select the following commands: Tab Edit > Command group Arrange > Space horizontally.  
   Or select: Tab Edit > Command group Arrange > Drop-down button Space horizontally > Space vertically.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan determines the distance between the first and last 3D object, and distributes all others evenly in between.  
   ![](../Pictures/Visualisation/ALL/cabinetgui_deployparts_as.png)

### [ClosedSpacing wire ducts evenly](javascript:void(0);)

During the even spacing of wire ducts the spacings are calculated referenced to the center axis not to the space distance. The reason is that differently sized spaces result when wire ducts with different widths are used.

1. Mark the respective wire ducts.
2. Select the following commands: Tab Edit > Command group Arrange > Space horizontally.  
   Or select: Tab Edit > Command group Arrange > Drop-down button Space horizontally > Space vertically.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan determines the distance between the center axes of the first wire duct and of the last one and distributes all others evenly in between.  
   ![](../Pictures/Visualisation/ALL/cabinetgui_distributeducts_as.png)

![](../Pictures/Gui/ALL/note.png)Note:

The grid is not taken into account when distributing 3D objects; if necessary, use the Align on grid command to place the elements back onto the grid.

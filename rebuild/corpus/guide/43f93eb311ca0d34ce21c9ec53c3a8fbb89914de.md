# Automated Processing of Projects

The Automated processing functionality allows you to automate certain areas of project processing using a user-specific scheme.

- Eplan helps you create schemes with pre-defined actions. Programming knowledge is not required for this.
- Eplan generates a script file automatically from the sequence of actions stored in the scheme. By default, the scripts are saved in the directory <Program drive>:\<Program directory>\Scripts\<Company code>.
- You can automatically process one or multiple projects.

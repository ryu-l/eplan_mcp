# Dialog Settings: Automated processing

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Tab Tools > Command group Reports > Automated processing. Click [...] next to the Scheme field in the dialog Run: Automated processing.
- You have opened a project. File > Extras > Command group Extensions > Interfaces > Command group Automated processing > Automated processing. Click [...] next to the Scheme field in the dialog Run: Automated processing.
- File > Project management. You have imported directories in the Project management dialog and selected at least one project. [Organize] > Automated processing. Click [...] next to the Scheme field in the dialog Run: Automated processing.

In this dialog, you define a sequence of actions that are to be run in an automated manner. This sequence of actions is saved in a scheme in a user-specific manner, and thus, for example, can be copied, exported, and imported.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Available actions:

This field contains all of the [Actions](autoprocgui_k_automprojektaktionen.htm) that can be selected for automated processing. In order for an action to be included in the scheme, you must use ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right) to transfer it to the Selected actions field.

Table:

The table contains the following columns:

- Row: Contains a consecutive row number.
- Selected actions: Shows all the [actions](autoprocgui_k_automprojektaktionen.htm) contained in the selected scheme.
- Description: Enter a meaningful text here, for example, to be able to differentiate between actions with the same name.

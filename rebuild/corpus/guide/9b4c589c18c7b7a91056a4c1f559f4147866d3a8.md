# Dimensions

You can enter as many project pages as you would like, for example for the panel layout structure or dimension information.

Eplan offers the following dimension types:

- Linear dimension
- Aligned dimension
- Continued dimension
- Incremental dimension
- Baseline dimension
- Angular dimension
- Radius dimension.

The dimensioning functions via the object snap and is not grid-dependent. Dimension results can be changed retroactively. A prefix and a suffix can be (pre)defined for dimensions.

Different views for arrows and dimension help lines can be selected in order to customize the dimensions for specific countries and standards.

# Dialog Settings: 3D import

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > Projects > "Project name" > Management > 3D import

In this dialog define the settings for importing STEP or JT files.

![](../Pictures/Gui/ALL/note.png)Note:

Eplan supports solely the import of STEP files that have been generated with the application protocol AP 203 or AP 214.

Overview of the main dialog elements:

Automatically assigned function definition after import:

Function definition receiving imported 3D objects from the STEP or JT file; set to "Part placement, normal item". Use the [...] button to select other function definitions.

Degree of detailing:

To adjust the data volume upon import of STEP or JT files, you can pre-select the degree of detailing with a slide control. There are five settings between the following values:

- Low
- Medium
- High.

A low degree of detailing accelerates the import of large STEP or JT files, but does result in a rougher representation of roundings. A high degree of detailing improves the representation of roundings, but also increases the data volume and time required for the import.

Separate items:

The behavior during importing depends on the form in which the STEP or JT data were exported from the CAD system. Prior to the import the STEP or JT file is analyzed and it is determined which organizational structure it has.

- Possibility 1: The STEP or JT file contains several objects which were not combined during the generation as assembly. In this case, this check box controls whether several or only one logic item are generated from it.
- Possibility 2: The STEP or JT file contains several objects which were combined during the generation as an assembly. In this case, the check box is ignored and several logic items are always generated.

If, during STEP or JT import, this check box is activated, several logic items are generated if several individual objects / surfaces can be found in the imported STEP or JT file which were not combined organizationally by the generating CAD system.

If the check box is deactivated, the individual objects / surfaces are no longer separated in the STEP or JT file into several logic items; instead, one logic item is generated.

If the STEP or JT file contains assemblies whose objects were combined into one unit by the generating CAD system, all combined objects are generally separated - independent of the setting of this check box.

![](../Pictures/Gui/ALL/info.png)Tip:

The following command can be used to subsequently combine several individual objects: Tab Edit > Command group Graphic > Unite.

Correcting normal vectors and orientation:

The normal vector of a surface determines whether the surface faces the viewer or is turned away from him / her. STEP or JT files can contain surfaces whose normal vectors point inwards. Such surfaces are then interpreted as transparent.

If this check box is activated, the respective surfaces are generated during the import so that they are not transparent from both sides.

![](../Pictures/Gui/ALL/note.png)Note:

Correction of the normal vectors can only be carried out at complete closed objects. The Separate items has to be deactivated in order to activate correction. Both settings cannot be used together.

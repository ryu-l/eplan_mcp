# Editing Legend Items

In the case of changes to the equipping of a mounting panel it may become necessary to renumber the legend items.

Preconditions:

- You have opened a project.
- You have opened the 2D panel layout - <Project name> dialog.
- In the Tree tab you have selected the mounting panel whose legend items are to be updated. (Multiple selection isn't possible here.)

1. In the 2D Panel Layout - <Project name> dialog select the Edit legend item popup menu item.
2. In the Edit legend item dialog use the buttons ![](../Pictures/Gui/ALL/all_arrowtop_as.png), ![](../Pictures/Gui/ALL/all_arrowup_as.png), ![](../Pictures/Gui/ALL/all_arrowdown_as.png), and ![](../Pictures/Gui/ALL/all_arrowbottom_as.png) to move the legend items upwards or downwards or to the beginning / end of the list.
3. Click the [Number] button.
4. In the Number dialog, define the numbering settings.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The entries in the Legend item column are adjusted.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The legend items are updated.

The updated entries can be displayed in the List tab. To do this you may have to customize the column configuration of the list by using the popup menu item Configure representation and select the Legend item property for the configuration.

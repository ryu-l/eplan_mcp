# Parts Management: Importing Parts Data to the ECLASS Standard

ECLASS is a standardized, cross-trade classification system for product groups, product characteristics and services with the aim of simplifying electronic trading of classified products.

During the import of parts data in the parts management according to the ECLASS standard, the XML-based "BMEcat" format is used. The supported version "BMEcat 2005.1" allows, among other things, for the import of multilingual data.

In order to import data according to ECLASS classification, the Import records dialog in the File type field comes with entries for the different supported ECLASS versions.

Importing is carried out by means of a scheme that you select in the subsequent dialog. The assignment of ECLASS groups and ECLASS properties to product groups and part properties of the Eplan parts management are configured in this scheme.

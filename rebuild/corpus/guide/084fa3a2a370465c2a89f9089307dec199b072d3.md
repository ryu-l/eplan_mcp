# Action: compress

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| PROJECTNAME | Project name with complete file path (optional). If nothing is entered, the selected project will be used if the action is to be run over the user interface (e.g. via the script or ribbon). When executing from the Windows command line, PROJECTNAME must be specified or ProjectAction has to be used before that. Otherwise a system message will appear. |
| CONFIGSCHEME | Configuration scheme for project compression (optional). Default value: last configuration scheme. When transferring an empty string the most recently used scheme is used. |
| FILTERSCHEME | Filter scheme for project compression (optional). Default value: most recently used filter scheme. When transferring an empty string the most recently used scheme is used. |
| USEFILTER | Uses the filter scheme that is specified in the FILTERSCHEME parameter. Default value: 1 |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Compress project:

```
compress 
/PROJECTNAME:C:\Projects\EPLAN\EPLAN_Sample_Project.elk 
/CONFIGSCHEME:config_scheme 
/FILTERSCHEME:filter_scheme
```

Usage of the last configuration scheme: The CONFIGSCHEME parameter is not specified.

```
compress 
/PROJECTNAME:C:\Projects\EPLAN\EPLAN_Sample_Project.elk 
/FILTERSCHEME:filter_scheme
```

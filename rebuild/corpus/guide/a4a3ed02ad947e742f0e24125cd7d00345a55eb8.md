# P011001: Interruption point without device tag

### Cause

The specification of the device tag is missing at an interruption point.

### Solution

1. Locate the interruption point in the schematic by using the Go to (graphic) functionality from the popup menu of the Message management dialog.
2. Open the Properties <...> dialog of the interruption point and enter a value in the Displayed DT field.
3. Click [OK].
4. If required, start a new check run.

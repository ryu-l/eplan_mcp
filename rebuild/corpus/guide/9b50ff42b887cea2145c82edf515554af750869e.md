# P026038: Routing path network no longer up-to-date

### Cause

Graphical objects that affect the connections to be routed in the layout space are part of what is known as the routing path network. This includes, for example, routing paths, curves, routing ranges, wire ducts or also wiring cut-outs. Each time such a routing path network object is placed in the layout space, positioned differently or deleted, the routing path network is modified, resulting in the output of the message "Routing path network no longer up-to-date".

### Solution

Update the routing path network.

1. Select the following commands: Tab Edit > Command group Routing connections > Generate routing path network.
2. Update the connections.
3. If required, start a new check run.

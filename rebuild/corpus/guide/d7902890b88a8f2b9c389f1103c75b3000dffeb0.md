# Inserting Interruption Points

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the following commands: Tab Insert > Command group Symbols > ![](../Pictures/Gui/ALL/ribbon_interruptionpoint_as.png) (Interruption point).
2. If required hold down the [Ctrl] key and move the mouse to page through the existing variants.
3. Click the left mouse button to place the interruption point symbol on the page.
4. Enter the device tag that is to be displayed with the interruption point in the graphical editor in the Displayed DT field of the [Interruption point](devicetaggui_r_abbruchstelle.htm) tab in the dialog Properties <...>, or click [...] to open the dialog Place existing interruption point and there select an existing interruption point name.
5. If required, enter further properties in the Interruption point tab and in the other tabs.
6. Confirm your entries.
7. Proceed in a similar manner for all additional interruption points that you would like to insert.
8. End the action via the Cancel action popup menu item or via the [Esc] button.

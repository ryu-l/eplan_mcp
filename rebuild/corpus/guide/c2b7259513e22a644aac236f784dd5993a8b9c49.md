# Assigning a Value Set to a Placeholder Object

If a placeholder object has different value sets then, when editing the placeholder object later, you can switch between the different value sets. When doing this, the properties to which a variable has been assigned will receive the values of the new value set.

Precondition:

You have inserted a placeholder object with multiple value sets on a page or in a layout space.

1. Position the cursor over the "anchor" symbol of a placeholder object.
2. Select the Assign value set popup menu item.
3. Select the name of the desired value set in the Value set field of the dialog Select value set.
4. If appropriate, change the value of the selected value set in the table. For this to be possible a variable in the property dialog of the placeholder object have to be set as modifiable.   
     
   ![](../Pictures/Gui/ALL/arrow.png) This means that a further user-defined value set is created and the prefix "user-defined" is placed in front of the name of the originally selected value set. The User-defined value set is removed again when the original value set is selected again.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The properties assigned a variable in the Assignment tab receive the values defined for the selected value set.

![](../Pictures/Gui/ALL/info.png)Tip:

A value set can also be assigned from the Properties <...>: Placeholder object dialog. To do this, select the column of the desired value set in the Values tab and then select the popup menu Assign value set. The objects to whose properties a variable has been assigned in the Assignment tab contain the appropriate values.

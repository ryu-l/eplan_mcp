# Generating Enclosure Legends

Legends gather and display information, or store information from the graphic in a free area. The enclosure legend is a function-specific report, i.e., the DT of the mounting panel must be unique.

If the legends are created on the same page where the mounting panel is located, then we speak of a Window legend; Window legends are freely positionable graphical objects, and have an insertion point and symbol properties, and / or a device tag.

The legend can also be output as a separate form. In this case no legend is shown in the graphical editor on the panel layout page. However, items will display item numbers but no device tags. We call this type of legend a Page legend.

### Create page legends

Precondition:

You have opened a project that contains mounting panels.

1. Select the following commands: Tab Tools > Command group Reports > Generate.
2. If the enclosure legend is not yet contained in the Pages hierarchy level in the Reports - <Project name> dialog, select [Settings] > Output to pages.
3. In the dialog Settings: Output to pages select a form for the Enclosure legend report type and if necessary, specify any additional settings.
4. Click [OK].
5. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the dialog Reports - <Project name>.
6. In the Select report dialog, define the Output format and Source project.
7. Select Enclosure legend from the list of available report types.
8. Select the Manual selection check box if you would like to select the mounting panels for which a legend is to be generated.
9. Click [OK].
10. In the Manual selection dialog, select the mounting panels for which a legend is to be generated.
11. Click [OK].
12. In the Enclosure legend <...> dialog, define the structure identifier and designation of the pages on which the legends are to be generated.
13. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The page legends are generated.
14. Click [Close] in the dialog Reports - <Project name>.

![](../Pictures/Gui/ALL/info.png)Tip:

You can specify before the generation of the enclosure legend that assemblies and modules are to be broken down into their individual parts. To this purpose select the Part menu item in the Reports - <Project name> dialog under the [Settings] button. Activate the check boxes Break up assemblies and Break up modules in the Settings: Parts dialog.

### Create window legends

Window legends are directly placed on creation of the Enclosure legend report type, by defining the following entries in the Select report dialog:

Preconditions:

- You have opened a project that contains mounting panels.
- You are in the graphical editor on a "Panel layout" page.
- The Suppress generation of the enclosure legend check box (Category "Settings") in the Mounting panel tab is not selected.

1. Select the following commands: Tab Tools > Command group Reports > Generate.
2. If the enclosure legend is not yet contained in the Embedded reports hierarchy level in the Reports - <Project name> dialog, select [Settings] > Output to pages.
3. In the dialog Settings: Output to pages select a form for the Enclosure legend report type and if necessary, specify any additional settings.
4. Click [OK].
5. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
6. Select the Manual placement entry from the Output format list in the Select report dialog.
7. Select Enclosure legend from the list of available reports.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The legend is hanging on the cursor.
9. Place the legend on the panel layout page.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The program checks which items are on the page and creates a provisional bill of materials with all of the part data for the items positioned on the mounting panel.

### Prevent window legends

For every mounting panel, a Window legend is generated as the standard. To prevent this, proceed as follows:

Preconditions:

- You have opened a project.
- You are in the graphical editor on a "Panel layout" page.
- You have inserted a mounting panel, or have double-clicked a mounting panel (or selected the popup menu item Properties; in this way, multiple mounting panels can be selected).

1. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) on the toolbar above the property list on the Mounting panel tab of the dialog Properties <...>.
2. In the Property selection dialog, select the Suppress generation of the enclosure legend property.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property is appended to the end of the list in the Property name column.
4. Select the check box in the Value column of the Suppress generation of the enclosure legend property.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The legend is not generated.

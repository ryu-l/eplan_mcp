# Printing Attached Documents

Attached documents can be separately printed in Eplan. These are external documents inserted into schematic pages via hyperlinks or entered into the parts used on the page. In order for attached documents to be printed, the files must be located on a local drive or a network drive to which you have access.

Preconditions:

- You have selected a project or pages in the page navigator.
- You have inserted external documents via hyperlinks or have entered them at parts.

1. Select the following commands: File > Print.
2. Select the option Only attached documents or Project / page and attached documents in the group box Scope of printing of the Print backstage view.
3. Click [Select attached documents].  
     
   ![](../Pictures/Gui/ALL/arrow.png) All attached documents linked in the project are listed in the Select attached documents dialog. As standard, all documents to be printed are selected in the Print column.
4. Deactivate the check box for all documents that you do not wish to print in the Print column of the Select attached documents dialog.
5. Click [OK].
6. Select the desired printer from the drop-down list in the Printer group box of the Print backstage view.
7. You specify the number of copies to be printed in the Copies group box in the Number field.
8. Click ![](../Pictures/Gui/ALL/btn_print_as.png) (Print).  
     
   ![](../Pictures/Gui/ALL/arrow.png) Printing begins.

# Dialog NC outline record

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened an outline of the type "Outline NC record generation" in the outline editor (for example via the commands: Tab Master data > Command group Outline / form > Drop-down button Outline (NC data) > Open). The outline drawing contains only a single closed outline that does not intersect itself. Tab Edit > Command group NC record > Drop-down button Generate > Rittal - Perforex BC / Secarex or Rittal - Perforex LC / Secarex or Steinhauer.

In this dialog, you specify the machine-related data relevant to the outline drawing. This data is stored to the outline.

![](../Pictures/Gui/ALL/note.png)Note:

Note that there can be several machine configurations per outline. But only one NC record is permitted per machine.

Overview of the main dialog elements:

Machine:

From this drop-down list select the machine for which you want to create the NC record.

Description:

This field can be used for additional record information.

Milling cutter:

(only for Rittal - Perforex BC / Secarex and NC Steinhauer)

Select the milling tool from this drop-down list.

---

Group box Approach process

Using the options of this group box, specify the approach path:

- Tangential (arc): Choose this option if the approach path is to be tangential, that is, in parallel to the rotational axis.
- Vertical (straight): Choose this option if the approach path is to be vertical, that is, from the top or from the bottom, and then enter the distance in the Distance field.

# P502043: The upper- and lower-case characters of the specified file name for the property '<x>' do not match the upper- and lower-case characters in the file system

### Cause

In the parts database to be checked a part was determined at which a file is specified for a property, at which the upper- and lower-case letters of the file name or the file path do not match the upper- and lower-case letters of the file name or the file path of the file physically stored in the file system.

Inconsistent spelling (due to different upper-/lower-case letters) can result in identical files (images, documents, etc.) being saved several times in an EDZ file during the data exchange in the EDZ format.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Properties tab to the front.
3. Click the ![](../Pictures/Gui/ALL/all_selectfile_as.png) button in the value field of the affected property to call up the Windows Explorer.
4. Double-click the affected file in the Windows Explorer.  
   ![](../Pictures/Gui/ALL/arrow.png) The file name and file path are inserted with the correct spelling in the value field of the affected property.
5. Click [Apply].
6. If required, start a new check run.
7. Close the parts management and perform a parts data synchronization.

![](../Pictures/Gui/ALL/note.png)Note:

This check run is not activated by default and can only be performed offline.

# Action: XPamSelectPart

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| DatabaseId | ID of the database. |
| SelectedPartsCount | Supplies the quantity of selected parts. |
| PartNo(no) | Supplies the part number of the selected parts, where "no" = 1, 2, ... |
| Variant(no) | Supplies the part variant of the selected parts, where "no" = 1, 2, ... |
| PartType(no) | Supplies the part type of the selected parts, where "no" = 1, 2, ... |

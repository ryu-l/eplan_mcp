# Action: XAfActionSetting

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| set | Name of setting to be configured. |
| Index | Index of setting (optional). If no index is specified, 0 is used. |
| value | New value of the setting. |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
XAfActionSetting 
/set:USER.SYSTEM.GUI.SHOW_PROPERTY_NR 
/value:1
```

In this example, the user-specific Display identifying numbers user interface setting is activated.

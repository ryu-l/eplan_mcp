# Dialog Settings: Part selection (project)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- File > Settings > Projects > "Project name" > Management > Part.
- You have selected a main function in the graphical editor or in a navigator. Popup menu item Properties. Select the Parts tab. Button [Settings] > Part selection (project).

Use this dialog to determine for the entire project which data sources will be used for part selection.

Overview of the main dialog elements:

Part selection:

Select one of the following options:

- User-defined: The user-defined settings you define under File > Settings > User > Management > Part selection are used for part selection.
- Project: For part selection, only those parts are offered which are stored in the project. This part selection is filled with data via a synchronization of parts between the parts management and project.

Parts preselection:

Select an existing scheme (meaning a list of parts) from the drop-down list. Then, during part selection only those parts will be offered that appear in the selected list.

With [...] the Parts preselection dialog opens and you can create a new list of parts to save it as a scheme or change an existing list.

![](../Pictures/Gui/ALL/note.png)Note:

The parts preselection has an effect on the [Insert center](insertergui_k_start.htm). You can, for example, restrict the number of devices offered for insertion to specific parts by means of a corresponding scheme.

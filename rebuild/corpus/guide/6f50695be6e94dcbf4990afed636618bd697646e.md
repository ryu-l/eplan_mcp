# Dialog Upload parts data

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Master data > Command group Parts > Management. You have opened a parts database using [Extras] > Settings. In the tree or in the list of the parts management you have selected one or more parts and selected the popup menu item Upload in eStock.

In this dialog you specify whether the selected parts are added to an eStock collection or not during the upload to the central database eStock of the Eplan Cloud.

Overview of the main dialog elements:

The following settings are available:

- Parts: If this option is selected, the selected parts of the central database eStock are added. However, they are not part of an eStock collection.
- New collection: If this option is selected, the selected parts are added to a new eStock collection. To do this, enter the name of the new collection in the field below.
- Existing collection: If this option is selected, the selected parts are added to an existing eStock collection. Select the desired name of the collection in the field below.

# Dialog Store image file

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a symbol. Tab Insert > Command group Image > Image file. In the Select image file dialog, select the desired image file and click [Open].

Image files in the GIF, JPG, BMP, ICO, PNG, or TIFF formats can be inserted in Eplan. In this dialog, you can specify whether the image file is to be stored in the symbol library or referenced from the source directory.

Overview of the main dialog elements:

Keep source directory:

A reference to the image file is inserted in the symbol. If the image file is changed, it is automatically updated as soon as you open the symbol. During the data backup, a setting allows referenced files to be taken into consideration.

Transfer back:

The image file is stored as a copy in the symbol and thus becomes part of the symbol library. An image file transferred like this is retained after synchronization of the master data, the forwarding of symbol libraries, or a symbol import or export. When changing the image file it is, however, not automatically updated.

# Dialog Settings: Cable generation

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- File > Settings > Projects > "Project name" > Devices > Cable (automatic). Next to the Cable generation field, click [...].
- Tab Connections > Command group Cables > Drop-down button Reassign all > Generate cables automatically. In the Generate cables automatically dialog, click [...] in the Cable generation group box next to the Settings field.

In this dialog you specify the objects on which cable properties are to be placed and which objects are to be taken into consideration when generating cables.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

---

Group box Place properties

At cable definition line:

If this check box is selected, the cable properties are placed on the cable definition line when generating a cable.

If the check box is not selected, only the cable definition lines are drawn but no properties are displayed.

At connection definition point:

If this check box is selected, the cable properties are displayed on the connection definition points when generating a cable.

If the check box is not selected, no cable properties are displayed on the connection definition points.

---

Only complete existing cables:

If this check box is selected, the existing cables (placed or unplaced) are completed. To do this, the cable connections running between the same targets for the selected cables are grouped together. If only part of the project is selected (schematic extract or single pages), only the cable connections in this selection are taken into account. New cables are not generated.

If the check box is deselected, existing cables are completed and new cables are generated, if necessary. To do this, all cable connections (contained in the selection) running between the same targets are grouped together.

Combine main functions between identical targets:

If this check box is selected, multiple main functions between identical targets are combined to a single main function. This is the default setting.

If the check box is not selected, one cable is generated for each main function.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Let's assume you have drawn one cable definition line each for two different connections (between identical targets). Each of these cable definition lines is a main function.

If the check box is selected, the first graphic cable definition line becomes the main function and the second becomes the auxiliary function. Eplan then generates a cable with the data from the first cable definition line. In the reports only the data from the main function is taken into consideration.

If the check box is not selected, two cables are generated.

# Using the Design Mode

The design mode assists you in placing graphical elements at specific points and at specific coordinates.

If the ![](../Pictures/Gui/ALL/statusbar_constructionmode_as.png) (Design mode on/off) button is activated in the status bar, do not use area selection for editing operations (such as Move, Delete, Duplicate, etc.) on the elements to be changed, but rather mark an element by clicking it. To edit the element, define both the starting and target points for the action.

Precondition:

You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc.

1. Click the button ![](../Pictures/Gui/ALL/statusbar_constructionmode_as.png) (Design mode on / off) in the status bar to activate the design mode or deactivate it again.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Moving elements with the design mode switched on

Assuming you would like to place the middle point of the rectangle on the starting point of the line. To find the middle point, draw two auxiliary diagonal lines within the rectangle.

![](../Pictures/Visualisation/ALL/gededitgui_constructmode1_av.png)

You then select the menu item Edit > Move, and then select the rectangle.

![](../Pictures/Visualisation/ALL/gededitgui_constructmode2_av.png)

Now select the starting point for moving by positioning the crosshairs on the intersection of the diagonals and clicking.

![](../Pictures/Visualisation/ALL/gededitgui_constructmode3_av.png)

Finally, select the target point by positioning the crosshairs on the desired point and by clicking. The rectangle is moved to the desired position and the middle point is on the starting point of the line.

![](../Pictures/Visualisation/ALL/gededitgui_constructmode4_av.png)

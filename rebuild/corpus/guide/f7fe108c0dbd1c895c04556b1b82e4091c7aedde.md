# P027014: Topology - Routing paths lie over each other

### Cause

Within the topology, routing paths have been drawn on top of each other in the routing path network. The routing paths on top of each other can be of differing lengths.

### Solution

1. Locate the routing paths lying on top of each other in the routing path network by using the functionalities Go to (graphic) and Go to (2nd coordinate), which the popup menu of the Message management dialog offers you.
2. Delete the surplus routing paths.
3. Update the connections.
4. If required, start a new check run.

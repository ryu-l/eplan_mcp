# Defining and Using a Mounting Grid

Mounting grids are assigned to individual areas of a 3D part placement, and during the placement of other components are displayed on these areas. Thus, placement is only possible on the intersections of the grid lines. Using the mounting grid, it is possible to represent a manufacturer and type-specific hole pattern, for example, on enclosure profiles, within which screw connections are set during the mounting. The properties of the placed mounting grid can be modified subsequently.

Preconditions:

- You have opened a project.
- You have opened the layout space navigator and a layout space.
- The layout space contains imported 3D objects which are to be saved as an enclosure or accessory part.

1. Select the following commands: Tab Insert > Command group Mounting aids > Mounting grid.
2. In the Mounting grid dialog enter suitable values for the grid increments and grid rows in the X and Y direction.
3. Click [OK].
4. Move the cursor over the surfaces of the 3D geometry.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The surface beneath the cursor is highlighted in color.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The point of origin of the surface to which the grid points defined in the Mounting grid dialog refer is displayed in a coordinate system.  
     
   ![](../Pictures/Visualisation/ALL/cabinetgui_mountinggrid_select_as.png)
5. Click the desired surface.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The mounting grid is displayed at the cursor as freely movable.  
     
   ![](../Pictures/Gui/ALL/arrow.png) On the clicked surface, snap points are displayed and handles are displayed on the mounting grid to be placed.
6. If necessary, switch the handle during the placement with key [A] or use the popup menu Placement options to determine via the dialog of the same name a handle as well as an offset for the selected handle to the cursor position.
7. Place the mounting grid by clicking at the desired position on the selected surface.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The mounting grid is saved at the part placement and is displayed in the layout space on the selected surface. The function remains active, and you can put mounting grids on additional surfaces.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Small cross lines are displayed for single-row mounting grids.  
     
   ![](../Pictures/Visualisation/ALL/cabinetgui_mountinggrid_as.png)
8. End the action via the Cancel action popup menu item or via the [Esc] button.
9. Double-click the placed mounting grid and in the first tab of the Properties: Mounting grid dialog store a speaking name and a description.
10. If you want to subsequently change the grid increment and/or the number of grid columns in X and Y direction, enter the desired value into the Format tab of the dialog.
11. Click [OK].

### [ClosedUsing mounting grids](javascript:void(0);)

To use a mounting grid defined on a mounting surface or on a profile when placing an item, the snap to mounting grid function can be activated and deactivated during the placement procedure via the popup menu.

Precondition:

A mounting grid was defined on a mounting surface or on a profile.

1. During the item placement select the popup menu item Snap to mounting grid.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The item can be placed preferably on the intersections of the lines of the mounting grid.
2. If instead of using the mounting grid you want to place freely again on the complete mounting surface, select the popup menu item Snap to mounting surface.

# Dialog Select source / target symbol library (Changing Standards)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. In the case of several opened projects: You have selected a project in the page navigator. Tab Tools > Command group Standards > Exchange. You have specified all of the settings in the Project tab. [Next]. You have specified all of the settings in the Rotation / flipping tab. [Next]. You selected the check box in the Master data tab in a symbol library row in the Individual assignment column. [Next]. Click [Scheme] in the Symbols tab. Select [Extras] > Select source and target symbol library.

Overview of the main dialog elements:

Project master data:

Displays all source and target symbol libraries for which the Individual assignment check box is selected in the Master data tab.

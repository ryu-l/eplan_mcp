# Updating the Part Placement

When the part number is replaced in a part placement in a layout space, it is necessary to update the part dimensions or the display of the part by a macro:

- When the part dimensions change
- When the macro name was changed
- When the image file name has changed
- When the macro itself was changed graphically, for example by the insertion of an additional mounting point, base point or a mounting surface.

It is possible to update the part placement at devices, mounting rails and wire ducts on mounting surfaces, and for individually inserted mounting panels and free mounting panels.

Preconditions:

- You have opened a project. You have opened a layout space.
- You have exchanged the part number in one or more part placements in the layout space.
- You have changed the part macro graphically.

1. Select one or more nodes in the layout space navigator.
2. Select the Update part placement popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected element and all elements below the marked element are updated in tree view. The graphic is adjusted to the dimensions of the new part, provided the requisite part properties Width, Height, and Depth are available for it or a macro is stored at the part.

![](../Pictures/Gui/ALL/note.png)Note:

Each update must first be confirmed by the user. The complete device tag and the part number of the elements to be updated are displayed in the Update part placement dialog for this. If you click the Do not show this dialog again check box in the dialog, confirmation is suppressed, and the update is performed immediately.

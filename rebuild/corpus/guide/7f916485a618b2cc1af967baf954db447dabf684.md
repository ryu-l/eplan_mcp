# Editing Project Properties (Project Management)

If you edit a project without a project management database, you can insert and delete the project properties from within the page navigator via the Properties popup menu item.

If you work with a project management database then you can also insert and delete project properties from the page navigator. The changes are adopted in the project management database and can be further edited in the project management.

Preconditions:

- You have selected a project management database.
- You have loaded directories and projects.

### Activate edit mode

1. Select the following commands: File > Project management.
2. Select the desired project from the tree structure in the Project management dialog and select the Properties tab.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The contents are displayed in display mode.
3. To switch to editing mode, click [Edit].

### Insert project properties

1. To reduce the quantity of displayed and selectable properties, in the Properties tab, select an entry from the Category drop-down list.
2. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
3. Select one or more properties from the Property selection dialog.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The properties are transferred onto the Properties tab. Properties whose values contain automatically generated entries are displayed in gray and cannot be changed from this location.
5. To edit the value of a property, click the Value column and enter the value.
6. Click [Save].

### Delete project properties

1. Select the Properties tab.
2. In the Property name column, select one or more properties.
3. Click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete).
4. Click [Save].

# Project Structure

To allow you to structure your project in a manageable form, you can structure all objects in your project:

- You can select an identifier structure for pages and devices from the default schemes (= project structure) or define your own (user-defined) structures.
- You can assign the Identifying, Describing, or Not available properties to the identifier blocks required for defining the project structure.
- You can export project structures from one project and import them into another project.
- The extended reference identification allows for working with a device structure in compliance with the EN 81346 standard. In the process the product aspect is available as an additional identifier block.
- In addition an identification of the pages in accordance with the standard DIN EN 61355-1 is possible. In this kind of identification a so-called "object identifier" is used for structuring.

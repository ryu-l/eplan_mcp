# Tab Labeling (Export Drilling Template)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > Company > Machining > Export drilling template. Select the Labeling tab.
- File > Export > Command group Manufacturing data > Machining > Drilling template. Click [...] next to the Machine field. Select the Labeling tab.

In this tab, you specify the strings to be used in the textual identification of the dimensioning in drilling templates.

Overview of the main dialog elements:

Group box Textual identification

The default characters are partially language-specific, and can be replaced by any random characters:

- Drill hole diameter: D
- Thread diameter: M
- Width: W
- Height: H
- Chamfer: X
- Fillet radius: R
- Edge length hexagon: a
- Edge length octagon: a.

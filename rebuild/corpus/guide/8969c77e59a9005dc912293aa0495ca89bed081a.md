# P012009: The part of the part placement is not available in sufficient numbers at the main function

### Cause

#### Possibility 1

A part placement on a page of the "Panel layout" type disposes of a specific part number and variant. By contrast, no part number, a different part number or a different variant was assigned to the associated main function on the schematic page corresponding to the part placement.

#### Possibility 2

A part placement that disposes of a specific part number and variant was inserted several times on a page of the "Panel layout" type. The associated main function on the schematic page corresponding to the part placement disposes of the same part number and variant. However, it has a lower value with the Number of units / quantity property at the part than the number of part placements inserted on the page of the "Panel layout" type.

### Solution

#### Regarding option 1

Enter the same part number and variant at the part placement of the page of the "Panel layout" type and at the main function in the schematic.

#### Regarding option 2

Adapt the entered value for the Number of units / quantity property in the part properties of the main function in the schematic to the number of the part placements inserted on the page of the "Panel layout" type. This means, either increase the value for the Number of units / quantity property at the main function, or delete the surplus part placements.

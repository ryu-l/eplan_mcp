# Master Data

Managing master data is especially important for supplier relationships and data exchanges. It is therefore possible to group all of the master data by way of the end customer in turn making it easier to sort through the information.

The term "Master data" here includes all "auxiliary data" generated outside of the project for use within the project.

In Eplan the following data belong to the master data:

- Symbols
- Plot frames
- Reporting forms
- Macros
- Basic projects
- Foreign language database
- Parts data, including device definitions etc.
- Function definitions
- Image files
- DXF / DWG files
- Eplan-specific rights database.

This data is managed in specific directories that you can predefine in the user settings (command path: File > Settings > User > Management > Directories).

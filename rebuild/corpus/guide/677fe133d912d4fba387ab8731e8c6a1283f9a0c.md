# Data Backup

The data backup and forwarding of projects and master data are important components of the configuration. With the data backup you can back up and restore all data you generated. Use cases for the data backup are:

- External data backup
- Long-term data archiving

Amongst other the following actions are possible via the data backup:

- Back up one or more projects with all the associated master data. A descriptive text can be assigned to the backed up project, for example the specification of the storage location.
- Backup of individual master data (symbol libraries, plot frames, forms, macros, templates, parts data, dictionaries).
- Restoring the backed up projects. In the process a check is carried out whether the project settings have changed and whether data are already available and can be overwritten.
- Unpacking of projects in the project directory. Projects packed in the project directory are unpacked during the call up.
- Archiving of projects.
- Filing off of projects.
- Viewing messages that were generated during the backup or restoration of a project.

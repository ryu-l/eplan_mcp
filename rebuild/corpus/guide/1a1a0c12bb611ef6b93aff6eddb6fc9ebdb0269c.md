# Dialog Settings: Clean up

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Extras > Command group Organize > Project > Command group Optimize > Clean up project. Click [...] next to the Settings field in the Clean up project dialog.
- File > Settings > Projects > "Project name" > Management > Clean up.

In this dialog you can specify which project data are to be corrected automatically by means of a correction run. These settings must be saved as a scheme.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Extent:

In this field you specify the scope of the correction with the corresponding check boxes.

- [Terminals](ProjectCorrectionGui_k_korrekturdaten.htm#I_Klemmen)
- [Plugs](ProjectCorrectionGui_k_korrekturdaten.htm#I_Stecker)
- [Connections](ProjectCorrectionGui_k_korrekturdaten.htm#I_Verbindungen)
- [PLC](ProjectCorrectionGui_k_korrekturdaten.htm#I_SPS).

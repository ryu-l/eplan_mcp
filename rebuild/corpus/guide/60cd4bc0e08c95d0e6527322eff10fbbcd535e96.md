# P022062: Object has user-defined property arrangement

### Description

If you place objects in the schematic or layout space or create objects in a project data navigator, a specified property arrangement called "Default value" is automatically assigned to these objects in the property dialog on the Display tab. As soon as, for example, you change the assigned value at a property, the name of the property arrangement changes to "User-defined". This can result in many different "User-defined" property arrangements at objects in a project.

This check run can be used to determine which objects in the project have a property arrangement called "User-defined". You can then save a standardized property arrangement under a freely selectable name for these objects. You then select the property arrangement defined in this way for one or more objects in the property dialog.

The objects listed in the message management dialog can be located in the schematic or layout space by using the Go to (graphic) functionality in the popup menu of the dialog. In this dialog you determine unplaced objects in project data navigators by using the popup menu item Synchronize selection.

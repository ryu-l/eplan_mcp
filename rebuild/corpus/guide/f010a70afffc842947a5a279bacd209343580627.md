# Dialog Design space import - define items

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Import > Command group Project data > Layout space > Design space

You have selected a STEP file to be imported. You have selected a scheme in the Design space import dialog and clicked [OK].

In this dialog you specify which function definitions and items are to be assigned to the imported 3D objects in Eplan during the import of STEP files with design spaces.

![](../Pictures/Gui/ALL/note.png)Notes:

- Eplan supports solely the import of STEP files that have been generated with the application protocol AP 203 or AP 214.
- The function definitions and items specified in the import scheme are used by default. You can overwrite these settings if required.

Overview of the main dialog elements:

Perform the assignment settings in the following fields:

- Preview: Shows a preview for the imported 3D object with the settings made.
- Item description: Shows the internal item designation that is used in the exporting CAD system for the 3D object.
- Function definition: Select a function definition that is to be assigned to the 3D object exported from the CAD system during importing into Eplan, for example "Panel". Click [...] to open the Function definitions dialog.
- Item: Select an item matching the function definition that is to be assigned to the 3D object exported from the CAD system during importing into Eplan, for example "Side panel right".

![](../Pictures/Gui/ALL/note.png)Note:

The "Enclosure" function definition is automatically assigned to the geometry model contained in the STEP file during importing.

- Select placement area for enclosure: Click an icon to define the placement area for the enclosure. The preview image of the enclosure as well as the preview images of the items adapt automatically to this setting.

![](../Pictures/Gui/ALL/warning.png)Caution:

Mounting surfaces and field sizes are generated automatically during the import, whereby the field sizes correspond to the external dimensions of the mounting surfaces. When selecting the placement area ensure that the enclosure stands upright and points with the doors forward. Otherwise mounting surfaces may not be generated automatically.

# Exporting Wire Harness Data

During the export of wire harness data the cable units selected in the project are also taken into consideration and corresponding data are output for these objects.

Preconditions:

- You have opened a project.
- You have opened the wire harness navigator.

1. Select one or more wire harness definitions and/or cable unit definitions in the graphical editor or in the wire harness navigator.
2. Select the following commands: File > Export > Command group Project data > Project data > Command group Devices > Wire harness data.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Export wire harness data dialog is opened. The selected wire harnesses and/or cable units are displayed in the Source field.
3. Enter a name under which the export file is stored via ![](../Pictures/Gui/ALL/all_selectfile_as.png) in the File name field or select it interactively.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A query is displayed when you export into an existing file. There decide whether you want to supplement or overwrite the file.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The file with the wire harness data (\*.hpdex) is generated. If cable units were selected, the data of these objects are also contained in the export file.

![](../Pictures/Gui/ALL/note.png)Note:

If you activate the Apply to entire project check box when exporting wire harness data, not only all the predefined wire harnesses and/or predefined cable units and their associated components are exported, but rather the entire project with all the project data. In such a case the names of the wire harnesses and cable units of the entire project are not listed in the Source field. Instead the field remains empty.

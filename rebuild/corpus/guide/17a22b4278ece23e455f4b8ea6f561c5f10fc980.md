# Inserting and Editing Path Function Texts

Path function texts are inserted in the same way as graphical texts. The only differences are that the title bar of the input dialog in the first tab shows a different title, and that the path function texts are stored in a different layer from the other texts (EPLAN110, Graphic.Path function texts).

### Insert a path function text

Precondition:

You have opened a project. You have opened a schematic page with a multi-line or a single-line representation.

1. Select the following commands: Tab Insert > Command group Text > Path function text.
2. In the Text tab of the property dialog, enter the desired text.  
     
   ![](../Pictures/Gui/ALL/arrow.png) As soon as you have opened the dialog for entering and editing texts, the status bar shows the current data entry language.

![](../Pictures/Gui/ALL/info.png)Tip:

The popup menu provides you with the possibility to further edit the text. You can, for example, enter special characters and line breaks. Line breaks can be entered using [Ctrl]+[Enter].

3. In the Format tab, specify the format properties, such as size, color and alignment, as well as the border properties, such as whether the text is placed within an alignment box and how it is adapted into the alignment box.
4. Click [OK].
5. Place the text in the desired path. Be sure that the insertion point of the text is aligned with the insertion point of the component which should receive the path function text.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If no separate function text is entered at the component, the path function text is entered in the Function text (automatic) property.

### Edit path function text

1. Double-click a path function text.
2. You edit the text and its properties in the Properties (path function text) dialog. Use the Text and Format tabs, as described under "Inserting a path function text".
3. Click [OK].

![](../Pictures/Gui/ALL/info.png)Tip:

To convert the path function text into "normal" text, deactivate the Path function text check box.

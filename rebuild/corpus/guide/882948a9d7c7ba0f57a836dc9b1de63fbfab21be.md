# Dialog Address PLC connection points

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have selected several PLC connection points in the graphical editor, the PLC navigator, or in the device navigator. Or you have selected one or more pages or a project in the page navigator. Tab Devices > Command group PLC > Address.

In this dialog it is possible to address entire or partial areas of PLC connection points within a PLC controller (several PLC connection points, one or more PLC cards).

![](../Pictures/Gui/ALL/note.png)Notes:

- Only the PLC connection points of one CPU can be addressed respectively. If you have selected PLC connection points belonging to different CPUs, a selection dialog is displayed prior to the opening of the Address PLC connection points dialog, and you have to select a CPU.
- Only the marked PLC connection points are addressed. If the PLC connection points are selected in both the schematic and the overview page, the new address is transferred to both placements. Otherwise the addresses in the schematic and the overview page are different.

Overview of the main dialog elements:

PLC-specific settings:

In this drop-down list you select the scheme that specifies the format of the PLC addresses. The addressing scheme can be selected independently of the CPU and is not written back to the CPU.

The scheme that was determined on the basis of the CPU belonging to the PLC connection points is displayed as the default setting. If no scheme is assigned to the CPU, the scheme specified in the project settings is displayed as the default setting. The configuration project, the station ID and the CPU to which the PLC connection points are assigned are furthermore displayed via the field.

Digital connection points:  
Analog connection points:

Activate the respective check boxes so that digital and/or analog PLC connection points are addressed. If the check box is activated, the associated input fields Inputs and Outputs are available for the start value of the addressing.

If the check box is deactivated, no values are displayed in the Inputs and Outputs fields, and no entry is possible in these fields.

Inputs:  
Outputs:

In the group boxes Digital start address and Analog start address the fields Inputs and Outputs are available. Enter the start value in each of these fields with which the addressing of the digital or analog PLC connection points begins. An example address is displayed in the fields as an aid. This example address is determined depending on the selected addressing scheme and is displayed including the associated identifier. The entry of the identifier is optional.

The input fields for the start value of the addressing are only available (i.e. not grayed out) if no [Configuration value](plcprocessorgui_k_adressformate.htm#I_Konfigurationswert) is set for at least one of the counters used in the associated address format. If all counters of an address format use a configuration value, the associated input field is grayed out.

Sorting:

In addition to the start address, you define here the order in which addresses are to be assigned. The PLC connection points are sorted by the DT of the card. In addition, sorting can be carried out by the graphical order of the placements in the schematic, by the order of channel designations or by the order of the connection point designations.

- By card DT and placement (graphical): The PLC connection points are addressed per card according to their graphical order in the schematic. This option only makes sense if all PLC connection points have been placed.
- By card DT and channel designation: The PLC connection points are addressed per card according to the order of their channel designation. This option is only sensible when the channel designations are entered.
- By card DT and connection point designation: The PLC connection points are addressed per card according to the order of their channel designation. The plug designation is taken into account and sorted in front of the connection point, i.e. the connection point "-A1-X1:2" comes before the connection point "-A1-X2:1".

Apply to entire CPU:

Select this check box in order to expand the addressing to the entire CPU. In this case no function templates for PLC connection points that were selected in the PLC or device navigator are addressed. If the check box is deactivated, selected function templates for PLC connection points are taken into consideration during addressing.

# Dialog Number items: Preview of result

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Tab Devices > Command group Devices > Bill of materials. In the tree or list view of the navigator dialog Bill of materials - <Project name>, you have selected the popup menu item Add item numbers, you have activated the Preview of result check box in the Number items dialog, and have clicked [OK] to confirm your numbering settings.

If you would like to renumber the particular items or all of the items in your bill of materials, you can display a preview after setting up the numbering settings, which is where you can still make changes.

Overview of the main dialog elements:

Original:

Under this heading, the parts data Device tag, Part number, and Item number are displayed as they appear in the current bill of materials; this data can't be edited here.

Target:

Since the part data Device tag and Part number may also not be changed in the case of a renumbering, only the new Item number (corresponding to the information entered in the Number items dialog) is displayed; this can be edited here.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

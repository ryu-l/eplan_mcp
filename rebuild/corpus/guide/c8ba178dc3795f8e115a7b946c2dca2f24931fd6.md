# Placing Length-variable Items

Length-variable items are

- Mounting rails
- Wire ducts
- C horizontal rails
- User-defined rails.

Length-variable items are normally placed on mounting panels or on the mounting surfaces of enclosure profiles. If a corresponding drilling pattern is stored at the part, cut-outs are automatically generated while placing length variable items. If one of those cut-outs is completely or partially on a restricted cut-out area due to the settings in the drilling pattern, an alternative cut-out is generated outside the restricted cut-out area.

The [automatic activation](cabinetgui_h_aktivierenautomatisch.htm) or [direct activation](cabinetgui_h_aktivierenautomatisch.htm#I_GezieltAktivieren) options help with accurate placement. The handle of the length-variable item can be changed before placement. Length-variable items can be inserted in one of two ways, which differ in the method by which the length is entered:

- Placement by entering the start and end point; here the length is defined by the distance between the two points.
- Adoption of the length of an already placed item; here the length-variable item is placed by entering a single point.

With the second method the length-variable item can also be automatically positioned centrally between two already placed items.

### [ClosedVariable-length placement of item](javascript:void(0);)

Preconditions:

- You have opened a project.
- You have opened the layout space navigator and a layout space.

1. Select one of the following commands: Tab Insert > Command group Devices > ![](../Pictures/Gui/ALL/ribbon_mountingrail_as.png) (Mounting rail) or ![](../Pictures/Gui/ALL/ribbon_wireduct_as.png) (Wire duct) or ![](../Pictures/Gui/ALL/ribbon_chorizontalrail_as.png) (C horizontal rail) or ![](../Pictures/Gui/ALL/ribbon_userdefinedrail_as.png) (User-defined rail).
2. Select the desired item part in the Part selection dialog.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The length-variable item hangs on the cursor as a transparent preview with the height defined for the part but with no defined length. The currently selected handle is displayed in red, and is also identified by a red square as a snap point.
4. Press [A] to change the handle.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Each time you press [A], the handle changes from the "Center" position to "Top", and "Bottom".  
     
   ![](../Pictures/Visualisation/ALL/cabinetgui_toggleappendpointrail_as.png)
5. Select the Placement options popup menu item to call up the [Placement options](cabinetgui_d_platzieroptionen.htm) dialog. Here you can choose the handle and enter an offset.
6. Enter the starting point of the length-variable item at the desired position.
7. Move the cursor to the right or left, up or down, and draw the length-variable item to the desired length like a line.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The item is displayed transparently at its current length up to the cursor position.
8. Enter the end point of the item at the desired position.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The item is inserted. The selected part remains at the cursor and can be placed again.

![](../Pictures/Gui/ALL/info.png)Tip:

If you keep the [Ctrl] key pressed while clicking two random and consecutive geometric points, a handle, mounting starting point or end point will be placed in the center between the geometric points. This input method can be used, for example, to place the point in the center of a drill hole.

### [ClosedItem placement with length adoption](javascript:void(0);)

Precondition:

There is at least one length-variable item on the same mounting surface on which you wish to place.

1. Select one of the following commands: Tab Insert > Command group Devices > ![](../Pictures/Gui/ALL/ribbon_mountingrail_as.png) (Mounting rail) or ![](../Pictures/Gui/ALL/ribbon_wireduct_as.png) Wire duct) or ![](../Pictures/Gui/ALL/ribbon_chorizontalrail_as.png) (C horizontal rail) or ![](../Pictures/Gui/ALL/ribbon_userdefinedrail_as.png) (User-defined rail).
2. Select the desired item part in the Part selection dialog. Click [OK].
3. Change the handle in the same way as for variable-length placement.
4. Select the Adopt length popup menu item.
5. Click an already placed length-variable item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new item to be placed adopts the length of the placed item you clicked and hangs on the cursor. The item to be placed can only be moved with the cursor parallel to the clicked item.
6. Move the item to the desired position parallel to the clicked item and click to place it.

### [ClosedCentered item placement with length adoption](javascript:void(0);)

Precondition:

There are at least two length-variable items on the same mounting surface on which you wish to place.

1. Select one of the following commands: Tab Insert > Command group Devices > ![](../Pictures/Gui/ALL/ribbon_mountingrail_as.png) (Mounting rail) or ![](../Pictures/Gui/ALL/ribbon_wireduct_as.png) Wire duct) or ![](../Pictures/Gui/ALL/ribbon_chorizontalrail_as.png) (C horizontal rail) or ![](../Pictures/Gui/ALL/ribbon_userdefinedrail_as.png) (User-defined rail).
2. Select the desired item part in the Part selection dialog. Click [OK].
3. Select the Adopt length popup menu item.
4. Click an already placed length-variable item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new item to be placed adopts the length of the placed item you clicked and hangs on the cursor.
5. Select the Place centered popup menu item.
6. Use the left-hand mouse button to click on a second placed item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new item to be placed is placed centrally between the two selected components.

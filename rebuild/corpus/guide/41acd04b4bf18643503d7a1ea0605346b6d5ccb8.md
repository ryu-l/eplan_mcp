# Tab Accessories

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Master data > Command group Parts > Management. You have marked a part in the tree or list. Select the Accessories tab.

This tab is used to define the selected part as an accessory part or to assign accessories to it.

Overview of the main dialog elements:

Part is accessory:

Select this check box if the part is an accessory part. In this case it will be detected as an accessory when you select the device, and will appear in the Accessories list in the Device selection dialog. You will then also not be able to assign accessory parts and accessory lists to it.   
If the check box is deactivated, the part is listed as a "normal" part (Main part list in the Device selection dialog). Accessory parts and accessory lists can be assigned to such main parts.

Table:

The following columns are displayed in the table amongst others:

- Required: Activate this check box if the part is to be a mandatory accessory part.
- Part number / name: Click [...] in this column to select an accessory part / the variant of accessory part or an accessory list from the part selection. (Multiple selection isn't possible here.)
- Variant: Shows the corresponding variant designation of the accessory part. You can overwrite this entry if required.
- Record type: Shows the record type of the accessory ("Component", "Assembly", "Module" or "Accessory list"). This column is filled automatically and cannot be changed.
- Accessory placement: In this column click [...], and select the accessory placement that is to be assigned to the respective component from the Select accessory placement dialog. For this purpose, the corresponding accessory placements must have been generated previously in the "Accessory placement" hierarchy level.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Clear contents | Deletes the contents of the currently selected cells. |
| Go to | Only available for the columns Part number / name and Accessory placement. Jumps to the part / accessory list / accessory placement that is entered in the currently selected cell. |

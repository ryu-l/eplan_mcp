# Defining Favorites in the Insert Center

Objects such as symbols, devices or macros that you need time and again and have to place frequently can be defined as non-project-specific favorites in the Insert center.

Preconditions:

- You have opened a project.
- You have opened a project page in the graphical editor. Or you have opened a layout space.
- You have opened the Insert center.

1. Navigate via the folders of the object types Symbol, Device or Window macro / symbol macro and the corresponding subfolders to the object that you want to define as a favorite.
2. In the preview tile of the object click the icon with the asterisk (![](../Pictures/Gui/ALL/insertergui_no_favorite_tile_as.png))   
     
   ![](../Pictures/Gui/ALL/arrow.png) The icon is now displayed filled (![](../Pictures/Gui/ALL/insertergui_favorite_tile_as.png)), which identifies the object as a favorite.
3. In the breadcrumb trail select the navigation path Home > Favorites.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The object is available as a preview tile in the folder Favorites and can now be inserted repeatedly.

![](../Pictures/Gui/ALL/info.png)Tip:

Alternatively to clicking the icon ![](../Pictures/Gui/ALL/insertergui_favorite_tile_as.png), the object marked in the preview tile can also be defined as a favorite by using the [F] key.

![](../Pictures/Gui/ALL/note.png)Notes:

- If symbols, devices or macros have variants, only the first variant shown in the preview tile can be defined as a favorite. If a different variant of the object identified as a favorite is required for inserting, the favorite can be marked and dragged from the Insert center into the graphical editor and placed there in the desired variant by means of the shortcut keys [Tab] or [Ctrl] + mouse rotation.
- If you have defined favorites for different objects, the corresponding properties of the objects are available object type-specifically in the tabs Symbols, Devices and/or Window macros / symbol macros in the table in the information area.

### Deleting favorites

1. If not already set, open the preview of the favorites using the breadcrumb trail by selecting Home > Favorites.
2. In the preview tile of the object whose definition you want to delete as a favorite, click the icon with the filled asterisk (![](../Pictures/Gui/ALL/insertergui_favorite_tile_as.png)).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The icon is displayed unfilled again (![](../Pictures/Gui/ALL/insertergui_no_favorite_tile_as.png)). The definition is now no longer a favorite.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The object is removed from the folder Favorites and not offered for preview anymore.

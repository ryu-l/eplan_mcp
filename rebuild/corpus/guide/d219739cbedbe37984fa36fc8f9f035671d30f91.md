# Dialog Select data source (Pre-planning, Excel import)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project, and have the pre-planning navigator open. Tab Pre-planning > Command group General > Import. In the Import pre-planning data - <Project name> dialog, select the "Excel" entry in the Type of data source field and then click the [...] in the Data source field.

You select the data source for the import of an Excel file from this dialog.

Overview of the main dialog elements:

File:

In this field you select the Excel file: Click [...] to navigate through the directory structure in the subsequent dialog, and select the required file.

Table:

All the worksheets and named data areas available in the selected Excel file are displayed in this drop-down list.

In the case of an Excel file with a set filter you are shown a special entry that has the term "Filter" in its name. After such an entry has been selected, only the filtered values of the Excel file are offered for import in the Synchronize pre-planning data dialog.

Column names in the header row:

If this check box is selected, the column names from the data table are output in the External field column of the assignment table. If it is not selected, the import ignores the column names.

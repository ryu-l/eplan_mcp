# P003022: Invalid cable length

### Cause

At a cable definition a negative value for the cable length was entered.

### Solution

1. Locate the cable definition line in the schematic by using the Go to (graphic) functionality from the popup menu of the Message management dialog.
2. Open the property dialog.
3. Enter a positive value in the Length field.
4. Click [OK].
5. Update the connections.
6. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

Other invalid values, for example letters, are not accepted. Invalid values that include interpretable units, are automatically corrected. For example the input 2M turns into length 2 m.

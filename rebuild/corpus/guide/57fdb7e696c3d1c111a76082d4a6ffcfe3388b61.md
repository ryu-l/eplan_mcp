# Dialog Insert center

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a project page in the graphical editor.Or you have opened a layout space.

After the installation the Insert center presents itself as a size-adjusting flyout. With the buttons ![](../Pictures/Gui/ALL/userinterface_pin_as.png) (Pin) and ![](../Pictures/Gui/ALL/userinterface_unpin_as.png) (Unpin) you can determine whether the flyout remains pinned or can be unpinned. In the unpinned state, the Insert center is hidden and only visible as a vertically positioned Insert center tab. Clicking the tab or pressing the [Ins] key displays the Insert center again. If the Insert center is pinned and if it was set to a specific size, the dialog memory saves this information after exiting the program and opens them the next time you start them in the previous state.

In the start view of the Insert center the folders for the quick access Last used, Tags and Favorites as well as for the object types Symbols, Devices and Window macros / symbol macros are shown. Depending on the object type you branch to folders below, which display the hierarchy levels of the used symbol libraries, system or project parts or the macro directories.

If you click a folder which contains objects, a preview of the objects in the form of tiles is shown. To insert mark the objects shown in the preview and drag them into the graphical editor.

Which object types you can insert depends on whether a project page or a layout space is opened. In project pages you can insert symbols, window macros / symbol macros or devices, in the layout space only window macros / symbol macros or devices.

If different representation types are saved in a window and / or symbol macro and if you have opened a specific page type in the graphical editor which matches one of the representation types available in the macro, the window or symbol macro is inserted in the corresponding representation type using the Insert center.

In the project-specific settings you can specify which [Company standards and standards](macrosgui_k_standards.htm) are to be taken into consideration when inserting macros or devices. If you configure the schematics with these settings, the selected company standard and/or the standard in the title bar of the Insert center are displayed.

If you have signed in to the Eplan Cloud, the ![](../Pictures/Gui/ALL/userinterface_edpIcon_as.png) "[Data Portal](#DataPortal)" icon is displayed in addition to the various folders in the home view of the Insert center.

Overview of the main dialog elements:

### [ClosedFind](javascript:void(0);)

Enter the text that is to be found into this field and confirm with [Enter].

You can influence the search by using the following buttons:

| Button | Meaning |
| --- | --- |
| (Search all) | Searches for all object types. The search is carried out both in the Insert center and in the Eplan Data Portal. |
| (Search all (except Data Portal)) | Searches for all object types. The search is only carried out in the Insert center and not in the Eplan Data Portal. |
| (Search in symbols) | Searches only in the symbols. |
| (Search in devices) | Searches only in the devices, meaning in the parts of the parts management. |
| (Search in devices and Data Portal) | Searches only in the devices, meaning in the parts of the parts management and in the Eplan Data Portal. |
| (Search in window macros / symbol macros) | Searches only in the window macros / symbol macros. |
| [...] | Opens the [Configure search](modaldialogsdb_d_suchekonfigurieren.htm) dialog. There you can use a scheme to specify the properties and the order in which the search is to be carried out. |

Logical operators (AND / OR operation) and placeholders (such as \* or ?) are supported in the search. For further information on this topic please refer to the section "[Search in the Insert center and in the parts management"](insertergui_k_suchen.htm) .

If one of the search filters ![](../Pictures/Gui/ALL/insertergui_search_in_all_as_14x14.png) (Search all) or ![](../Pictures/Gui/ALL/insertergui_search_in_device_and_DP_as.png) (Search in devices and Data Portal) is activated for the search, the search - if possible - is also carried out in the Eplan Data Portal. If nothing is found during the search in the Insert center, but the part exists in the Eplan Data Portal, it is displayed in the Eplan Data Portal. To this purpose, the Eplan Data Portal is opened, if necessary.  
During the search in the Eplan Data Portal, operators, placeholders and the properties specified during the configuration of the search are not taken into consideration.

If the Eplan Data Portal is not to be included in the search, you have to press one of the other buttons (for example ![](../Pictures/Gui/ALL/insertergui_search_in_all_except_DP_as.png) (Search all (except Data Portal)).

### [ClosedBreadcrumb trail](javascript:void(0);)

The breadcrumb trail indicates in which folder structure of the Insert center you are located. In addition, different buttons are available in the breadcrumb trail to switch the currently set folder and to move to the desired objects.

| Button | Meaning |
|  | Opens a menu from where - depending on the currently selected folder - you can switch to a folder of the same, higher or lower hierarchy level. |
|  | Makes it possible to return immediately to the standard view of the Insert center, which is also possible via the Home entry. |
|  | Makes it possible to navigate one hierarchy level up in the folder structure. |
|  | Makes it possible to select other folders or return to the standard view. Shows at the same time that the folder structure shown in the breadcrumb trail cannot be displayed fully anymore because of its length. To make the entire folder structure visible you can further extend the dialog of the Insert center. |

### [ClosedFolders for the quick access](javascript:void(0);)

Recent ![](../Pictures/Gui/ALL/insertergui_last_used_as.png):

This provides you with a preview of the most recently inserted objects. The number of displayed objects encompasses a maximum of 20 entries that can be assigned to different object types. The most recently inserted object is always positioned as a tile at the top in the first position in the preview area.

![](../Pictures/Gui/ALL/note.png)Note:

In the preview you are also shown the most recently used symbol and macro variant for the most recently used objects.

Favorites ![](../Pictures/Gui/ALL/insertergui_favorite_as.png):

You can define objects as favorites which you require repeatedly for insertion. This folder provides you with a preview of all objects identified as favorites. You will see an object identified as favorite in the preview tile at the filled icon ![](../Pictures/Gui/ALL/insertergui_favorite_tile_as.png). Favorites are saved in the user-specific settings and can be exported and imported. Furthermore favorites are available non-project-specifically for insertion. A maximum of 5000 favorites can be defined.

![](../Pictures/Gui/ALL/note.png)Note:

Only the first variant of an object displayed in the preview tile can be defined as a favorite.

Tags ![](../Pictures/Gui/ALL/insertergui_tag_as.png):

An object can be assigned to one or more randomly selected tags. With this folder you branch to further folders that are named after tags assigned by you. For each tag the number of objects assigned by you is displayed next to the folder. A mouse click on the tag opens the preview and the objects contained in it. That fact that a tag is assigned to an object is indicated by the filled icon ![](../Pictures/Gui/ALL/insertergui_tag_tile_as.png) in the preview tile. Tags are saved in the company-specific settings and can be exported and imported. A maximum of 5000 tags can be assigned to an object.

If you have assigned multiple tags to an object, all further tag folders are displayed above the preview tiles and offered for selection after a tag folder has been selected.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The tags 001, 002 and 003 have been assigned to a motor symbol from the symbol library IEC\_Symbol with the symbol name M6. After selecting the commands Home > Tags in the breadcrumb trail, 3 tags appear accordingly as folder 001, 002 and 003.

![](../Pictures/Visualisation/ALL/insertergui_3_tag_directories_as.png)

If you now click tag folder 001, you are also shown the tag folders 002 and 003 above the preview tile.

![](../Pictures/Visualisation/ALL/insertergui_tag_directories_with_preview_as.png)

![](../Pictures/Gui/ALL/note.png)Note:

A tag can only be identified at the first variant of an object displayed in the preview tile.

### [ClosedFolders for object types](javascript:void(0);)

Symbols ![](../Pictures/Gui/ALL/insertergui_2D_symbol_as.png):

With this you branch to the symbol libraries stored in the currently open project including the contained symbols. Depending on the currently selected folder, all symbols of the folders located in the hierarchy levels below are displayed in the preview. Which variant of the symbol is displayed as the default variant in the preview tile, depends on which setting was made at the individual symbol and for the entire symbol library. By preference the default variant set at the symbol is displayed.

Devices ![](../Pictures/Gui/ALL/insertergui_device_as.png):

With this you access the devices available in the part selection. Different contents can be shown in the preview tile for devices: If you have opened a project page and if the corresponding information is stored at the part, either an image of the part, a macro (variant "A"), a graphical macro (variant "A") or the function template (variant "A") are displayed. If you have opened a layout space and if the information is available at the part, either an image of the part, a graphical macro (variant "A") or a macro (variant "A") is displayed. If none of this information is stored at the part, a camera symbol for the missing graphic is shown instead in both cases.

![](../Pictures/Gui/ALL/note.png)Notes:

- Eplan offers the possibility to use the parts database set in the parts management or the parts (project parts) stored in the project when inserting devices. This can be specified via the command path File > Settings > Project > "Project name" > Management > Part selection.
- Eplan allows restricting parts in the part selection via the [Parts pre-filtering](partsextensiongui_d_artikelvorfilterung.htm) and / or [Parts preselection](partselectiongui_h_artikelvorauswahl.htm). This restriction also affects the Insert center with regard to the selection possibility of devices. If one or both restrictions were made in the settings provided, this is shown in the Insert center with the ![](../Pictures/Gui/ALL/insertergui_device_limited_part_selection_as.png) icon and a corresponding Tooltip text.
- With the user settings you can configure the [tree view](partsmanagementgui_d_baumkonfiguration.htm) for the parts management. The configuration also affects the display in the part selection and thus also the Insert center with regard to the display of the folders for devices.

Window macros / symbol macros ![](../Pictures/Gui/ALL/insertergui_macro_as.png):

With this you branch to the window and symbol macros in the set macro directory. Depending on the currently opened page type or layout space - if available - the macro graphic of variant "A" matching the representation type is automatically displayed in the preview tile.

![](../Pictures/Gui/ALL/note.png)Note:

For the Insert center Eplan does not directly use the macro directory for window and symbol macros but a [macro collection](insertergui_k_makrosammlung.htm) which is generated from this directory.

### [ClosedData Portal](javascript:void(0);)

If you click the icon ![](../Pictures/Gui/ALL/userinterface_edpIcon_as.png) "Data Portal", a special window for the Eplan Data Portal is opened outside the Insert center in the main window of the Eplan platform. Here you can select and import part master data.

Even if this window looks like a normal Eplan Data Portal window, this window is independent of the other Data Portal windows and is identified in the title bar by the text Data Portal (Insert center). If a Data Portal window has already been opened via the ribbon, the Data Portal window for the Insert center is opened nevertheless.

The "Data Portal" icon does not have a popup menu. No properties are displayed in the information area, and the information area can accordingly not be configured for the icon.

If a parts pre-filtering is set, a search in the Eplan Data Portal is not possible and the icon ![](../Pictures/Gui/ALL/userinterface_edpIcon_as.png) "Data Portal" is not displayed. Further information about the search in the Insert center can be found in the section ["Find"](#Suchen).

Further information on the Eplan Data Portal can be found [here](../../../../EDP_Cloud/Content/htm/DataPortalCS_k_home.htm).

### [ClosedPreview](javascript:void(0);)

If you click a folder which contains objects, a preview of the objects in the form of tiles is shown. The visualized contents of a preview tile depend on the selected object type:

A symbol or macro graphic is always displayed for a symbol or a macro.

For a device the preview depends on the information stored at the part. The following sequence applies:

- If an image file is stored at the part, it is displayed. If a macro is stored, the macro graphic is displayed.
- If a symbol is assigned to a function template, the symbol graphic is displayed.
- If neither an image file nor a macro or symbol graphic is available for the device, a camera symbol is displayed.

Within the preview tiles different icons are available which allow you to define favorites, assign tags to objects or select the variants of an object. The icons have the following meaning:

| Icon | Meaning |
|  | Object identified as favorite |
|  | Object not identified as favorite |
|  | Object to which a tag is assigned |
|  | Object to which no tag is assigned |
|  | Number of available variants of an object |
|  | Variant name (A - H) |

In addition, the symbol name (for symbols), the part number (for devices) or the macro name (for window and symbol macros) is displayed in the preview tile as identification of the object. Part numbers which are wider than the preview tile due their length are wrapped and displayed in two line.

### [ClosedInfo area](javascript:void(0);)

Below the preview the most important properties for all preview tiles available in the preview are displayed in a configured table. Depending on the object type in the selected preview tile the table columns show different properties.

When you select a preview tile, the row with the associated properties of this object is marked in the table. Conversely the associated preview tile is marked when you click a table row. Double-click one of the column headers in the table and with that perform an alphanumerically ascending or descending sorting of the property values. This way the display of the tiles in the preview changes as well.

From the table it is possible with a double click on the table cell to insert the corresponding object into the schematic.

If you have defined Favorites for more than one object type when selecting the quick access folder Favorites, the properties of the objects are displayed in corresponding tabs of the table which are named in accordance with the corresponding object types.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Configure representation | Opens the [Configure representation](modaldialogsdb_d_eigenschaftskonfiguration.htm) dialog in which you can determine the properties to be displayed in the table. |
| Open hyperlink | Only available for devices. Allows opening of external documents or an image file, as long as this is assigned to the associated part in the parts management. |
| Assign | Only available for devices. Allows you to assign a selected part to a specific function in the schematic. |

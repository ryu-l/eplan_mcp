# P028001: Structure segment occurring multiple times

### Cause

A structure segment occurs more than once in the project with the same designation.

### Solution

1. Locate the structure segment that occurs several times by using the functionalities Go to (graphic), Go to (2nd coordinate) or Synchronize selection, which the popup menu of the Message management dialog offers you.
2. Call up the Properties <...> dialog of the structure segment and bring the <Structure segment - displayed name> tab to the front.
3. In the Designation field, change the character string, so that a unique structure segment is stored in the project.
4. Click [OK].
5. If required, start a new check run.

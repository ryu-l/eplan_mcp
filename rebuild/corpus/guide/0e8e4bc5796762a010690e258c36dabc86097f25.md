# P032002: The drilling pattern name <x> is repeated

### Cause

The same drilling pattern name was assigned to several drilling patterns. The placeholder <x> in the message specifies the drilling pattern name that exists several times.

### Solution

1. Locate the drilling pattern name existing several times in the project using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Change the names one after the other in the dialog Properties <...> of the associated drilling pattern names so that each name occurs only once in the project.
3. Click [OK] to apply the change respectively.
4. Subsequently generate the drilling pattern again via the following command path: Tab Master data > Command group Drilling pattern / outline > Drop-down button Generate > From macro project (automatically).

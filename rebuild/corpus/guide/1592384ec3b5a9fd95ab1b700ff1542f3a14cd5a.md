# Projects: Principle

In Eplan, schematics and attached documents such as lists and overviews are created as pages within projects. A project is a database in which, besides the project pages, all master data used in the project (symbols, plot frames, forms, parts data, etc.) is stored.

Thus the project file (\*.elk) belongs to a project, as well as the directory where the database and the project-related master data are stored. The project file represents the project; using this file you select (e.g.) a project to open or unzip. It contains the reference to the associated directory containing the project data.

Project files can have different file suffixes, e.g.:

\*.elk: Standard project

\*.elp: Zipped project

\*.elr: Completed project / reference project.

In the ..\Projects\EPLAN directory is the EPLAN\_Sample\_Project.elk project file. This contains the reference to the EPLAN\_Sample\_Project.edb directory. In the ..\Projects\EPLAN\EPLAN\_Sample\_Project.edb subdirectory is the associated project data. If you wish to open a project using File > Open > Command group Open > Browse, the EPLAN\_Sample\_Project.elk file is offered in the file selection dialog.

# Enclosure Legends of Model Views

Enclosure legends are not generated from a layout space but rather from the model views derived from the layout space. In this way a project page may have several model views which each show a particular area of the layout space that was defined in the Model view dialog by the selection in the Basic items field. This may be, for example, a mounting panel, a populated mounting rail or a complete enclosure. The number of objects contained in the model view can be modified additionally using the [Toggle] button.

If you create an enclosure legend on a project page that contains several model views a separate enclosure legend is generated for each model view. Each separate enclosure legend contains components that have been preselected for the associated model view.

In order to generate an enclosure legend for the complete content of a layout space, you must therefore first insert a model view without restricting the basic items.

### Suppress generation of the enclosure legend

In order to exclude a model view from generating an enclosure legend, open the Model view dialog. In the Properties group box (category: "Settings"), add the Suppress generation of the enclosure legend property, and activate the check box. Then no enclosure legend is generated for this model view. This model view is also not considered during the output of the labeling for the report type "Enclosure legend".

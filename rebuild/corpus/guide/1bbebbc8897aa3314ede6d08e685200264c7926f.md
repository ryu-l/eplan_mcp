# Dialog Delete stored part properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Master data > Command group Parts > Drop-down button Synchronize > Delete stored part properties.

In these dialogs you can delete the properties of parts stored in the project. User-defined properties are also taken into consideration in the process. This request can apply to the entire project, marked pages, or marked elements in the graphical editor.

Overview of the main dialog elements:

Settings:

This drop-down list shows all of the user-defined and pre-defined schemes. Select a scheme to determine the settings for the deleting of the stored properties. Use [...] to open the subsequent dialog of the same name where you manage and edit the schemes.

### Subsequent dialog: Delete stored part properties

In the subsequent dialog you define the settings for the deleting and save this as a scheme.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Part property:

The part properties that are to be deleted are listed in this column.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

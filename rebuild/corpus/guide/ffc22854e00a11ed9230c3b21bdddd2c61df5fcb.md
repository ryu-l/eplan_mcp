# Dialog Settings: External editing

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call up (for project data):](javascript:void(0);)

- You have opened a project. File > Export > Command group Project data > Project data > Command group External editing > Properties. Click [...] next to the Settings field in the Edit externally dialog.
- File > Settings > User > Interfaces > External editing.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call up (for parts data):](javascript:void(0);)

Tab Master data > Command group Parts > Management. In the Parts management dialog you have opened a parts database using [Extras] > Settings. Button [Extras] > Edit properties externally > Export data. Click [...] next to the Settings field in the dialog Edit externally.

In this dialog, you can manage and edit schemes for external editing. Settings for the export of data for external editing are specified in a scheme.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Object type:

A scheme for external editing is always generated for a specific object type. In this field the object type is displayed that you have selected while creating the current scheme via the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button in the Object type dialog. Subsequent changes can then not be made to the object type!

Different object types are possible depending from where you call up the settings. In the parts management you have object types available such as parts, addresses, drilling patterns. etc. In the Backstage view during export of project data these are object types such as devices, cables, path function texts, etc.

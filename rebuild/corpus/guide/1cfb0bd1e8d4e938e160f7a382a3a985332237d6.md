# Dialog Settings: Property dialogs

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > User > Graphical editing > Property dialogs

Use this dialog to specify whether the property dialog is to be displayed or not when inserting specific objects.

Overview of the main dialog elements:

When inserting connection splicers:

If this check box is selected, the Properties <...> dialog is displayed when connection splicers or line connectors are inserted. There, you can immediately enter the device properties of the connection splicer or line connector.

When inserting shields:

If this check box is selected, the Properties <...> dialog is always displayed when shields are inserted. You can then immediately enter the device properties of the shield.

While inserting routing points and routing paths (topology):

If this check box is activated, the Properties <...> dialog will be displayed when inserting routing points and routing paths in the topology. There, you can enter immediately the device properties of the routing point or of the routing path.

# Tab History

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. This project contains either comments from an imported PDF file or comments that were inserted directly into Eplan.

- You have marked a comment on a project page. Select the Properties popup menu item. In the dialog Properties, switch to the History tab.
- Tab Tools > Command group Comments > Navigator. Mark a comment and select the Properties popup menu item. In the dialog Properties, switch to the History tab.

In this tab you can view the editing history of the comment. The most recent modifications are at the top of the tab, the oldest at the bottom.

Overview of the main dialog elements:

Status:

Icons in this column show whether property values have been deleted, edited or added for the comment.

| Status | Meaning |
|  | New: A new value has been added for a property (for example a reply text). |
|  | Deleted: The value of a property has been deleted. |
|  | Changed: The value of a property has been changed (for example the comment text). |

User name:

Shows the Windows sign-in name of the person who edited the comment.

Modification date:

Shows when the comment was edited.

Modification: Property:

Shows the property of the comment that was edited.

Modification: Previous value:

Shows the previous property value before editing.

Modification: New value:

Shows the new property value after editing.

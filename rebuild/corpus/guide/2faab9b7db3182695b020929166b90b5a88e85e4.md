# Displaying Message Text in the Graphical Editor

You can also display message text from message management messages directly at components in the graphical editor. When the check runs are appropriately configured, project errors can be immediately seen in the schematic when they occur (i.e. "online") and can be immediately corrected.

Precondition:

- You have opened a project page in the graphical editor.
- You have configured the check runs so that the checks are performed both online and offline (Type of check "Online / offline").

1. Select the following commands: Tab Tools > Command group Management > Layers.
2. For the EPLAN520 layer ("Property placement.Message text"), select the Visible check box.
3. Click [OK].
4. Select the desired component in the graphical editor.
5. Select the Properties popup menu item.
6. In the properties dialog, select the Display tab.
7. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) on the toolbar above the property list.
8. In the Property selection dialog, select the "Message text" property.
9. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The "User-defined" entry is now displayed in the Property arrangement drop-down list of the property dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new property "Message text" has been added to the list of display properties.
10. Edit the display settings of this new property as desired.
11. Click ![](../Pictures/Gui/ALL/all_save_as.png) (Save) in the toolbar above the Property arrangement drop-down list if you wish to also use this user-defined arrangement for other components with the same symbol variants.
12. Enter a descriptive name for the property arrangement in the Save property arrangement dialog and select the Use as default check box.
13. Confirm your entries.  
      
    ![](../Pictures/Gui/ALL/arrow.png) In the case of faulty data entered at the component or an incorrect action, the message text is now displayed online in the graphical editor.

![](../Pictures/Gui/ALL/note.png)Note:

Once you have corrected an error, the corresponding message text at the component is not automatically deleted but must be removed via a check run (i.e. offline), similar to processed messages in the message management.

# P004120: 'Symbolic address: UDT (data type)' is empty even though 'Symbolic address: UDT (name)' exists

### Cause

A PLC connection point with incomplete UDT data was determined within a CPU. In this concrete case a value is entered at the PLC connection point in the Symbolic address: UDT (name) property. However, the value of the data type is missing for the Symbolic address: UDT (Data type) property.

### Solution

1. Locate the PLC connection point in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Open the property dialog of the PLC connection point.
3. In the property table enter the data type in the field Symbolic address: UDT (data type). This value must be the same at all PLC connection points within the CPU where the property Symbolic address: UDT (name) has an identical value.
4. Click [OK].
5. If required, start a new check run.

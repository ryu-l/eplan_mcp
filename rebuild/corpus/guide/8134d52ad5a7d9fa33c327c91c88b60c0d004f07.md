# Cleaning up a Project

Precondition:

You have opened and selected a project in the Page navigator.

1. Select the following commands: File > Extras > Command group Organize > Project > Command group Optimize > Clean up project.
2. Click [...] next to the Settings field in the Clean up project dialog.
3. If you have already stored the scope of correction as a scheme, select the existing scheme from the drop-down list in the dialog Settings: Clean up. Otherwise click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
4. In the New scheme dialog, in the Name field, enter a name for your new scheme. In the Description field, enter a descriptive text for the scheme, then click [OK].
5. To select the project data for the [Correction settings](ProjectCorrectionGui_k_korrekturdaten.htm) activate the corresponding check boxes of in the Scope field in the dialog Settings: Clean up.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have activated the check box for a node, the subordinate check boxes are automatically selected, too.
6. Click ![](../Pictures/Gui/ALL/all_save_as.png) (Save).
7. Click [OK].

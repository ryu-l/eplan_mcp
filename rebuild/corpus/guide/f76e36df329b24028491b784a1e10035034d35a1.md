# P502028: 'Plug designation' property at the bus port is empty

### Cause

In the parts database to be checked a part was found at which a function template is defined with the "Network / bus cable connection point" function definition. No value is stored for the Plug designation property at this function template.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Function templates tab with the Device selection (function templates) table to the foreground.
3. Enter a value in the Plug designation field for the bus port at the function template.
4. Click [Apply].
5. If required, start a new check run.
6. Close the parts management and perform a parts data synchronization.

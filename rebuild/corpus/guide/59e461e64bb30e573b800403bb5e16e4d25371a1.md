# Tab Format of symbolic address

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Settings > Projects > "Project name" > Devices > PLC. Click [...] next to the PLC-specific settings field in the Settings: PLC dialog. Select the Format of symbolic address tab in the Settings: PLC-specific dialog.

In this tab you define the criteria used for automatically creating symbolic addresses. You can also replace the preceding signs used by the identifier blocks in the assignment list with different characters. This is necessary if you want to use the DT as automatically entered symbolic address, but special characters in the symbolic address are not allowed for the used PLC controller.

Overview of the main dialog elements:

Generate symbolic addresses automatically using:

If this check box is activated, you can use the check boxes in the Active column in the table to specify the identifier blocks that make up automatically generated symbolic addresses.

If this check box is deselected, then symbolic addresses are not automatically created. The fields of the table cannot be edited.

Table:

The identifier blocks with their preceding signs and the associated substructures with their separators are displayed in the table. Here you specify which identifier blocks are a component of the symbolic address. You can use the arrow buttons above the table to specify the sequence of the identifier blocks within the symbolic address. The rows Device tag, Plug designation and Connection point designation cannot be moved and are always displayed at the end of the page.

The following columns are displayed in the table:

- Active: If this check box is activated, the associated identifier block in the Structure column is a component of the symbolic address.
- Structure: The identifier blocks are displayed in this column.
- Preceding sign: The preceding sign defined in the project structure is displayed for each identifier block. To replace this preceding sign in the assignment list by a different character, you can overwrite this default by any desired character. It is also possible to replace all preceding signs with the same character, since the preceding sign does not have an identifying role in the assignment list.
- Substructure: If this check box is selected, sub-identifiers of the respective identifier block are included in the symbolic address. If the check box is deselected then sub-identifiers are not accounted for.
- Separator: The separator defined in the project structure is displayed for the respective sub-identifier. To replace this separator in the assignment list by a different character, you can overwrite this default by any desired character.

Special features for the device tag, the plug designation and the connection point designation

The Device tag and the Subcounter of a device tag are always included in the automatically generated symbolic address. The associated check boxes in the Active and Substructure columns are therefore always activated and cannot be deactivated. You can specify a different preceding sign and a different separator for the assignment list.

The Plug designation of the device connection point is an optional component of the symbolic address. You have the option of specifying a different preceding sign for the assignment list.

The Connection point designations of the function are an optional component of the symbolic address. The preceding sign defined here is displayed before the connection point designation as well as before the terminal designation. The terminal designation is always part of the symbolic address, when the PLC connection point is connected to a terminal.

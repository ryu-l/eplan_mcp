# Undoing and Redoing Actions

Using the Undo and Redo commands, you can undo or redo your last changes during project editing. To this purpose corresponding buttons are available in the quick access toolbar and commands by the same name in the dialog for customizing the ribbon.

When undoing an action, Eplan returns to its previous state. For instance, a page which has just been deleted can be restored by using the button ![](../Pictures/Gui/ALL/all_quickaccess_undo_as.png) (Undo).

Undoing and redoing have a linear structure. This means that you always undo your work steps one after the other in reverse order. Thus you first undo the last action, then the next-to-last, and so on. Eplan saves the work steps performed for each project and user.

By using the Redo command, you can activate work steps again in their original sequence . Redoing can be seen as "undoing" the Undo. You can only perform the Redo command if you have previously called Undo at least once.

If an undo will take some time (for instance, if undoing a change in the structure identifier manager) then the progress of the undo action is shown with a progress bar.

### Undo and redo list

In addition to linear, step-by-step undo and redo operations, you can also use the commands Undo list and Redo list. In the list you can see the last (up to 50) steps that you have carried out in the current project and search for a particular working step up to the point where you wish to undo / redo. The undo steps are listed with the most recently performed step at the top; the redo steps have the most recently undone step at the top.   
If you select a line in the list, all lines above this are also selected automatically. This means that the steps can only be undone or redone together and that the currently selected step is included in this.

The project-specific list of editing steps is only temporarily stored. Closing the project deletes the list.

![](../Pictures/Gui/ALL/note.png)Notes:

- Please note that the "Eplan print job" action is also listed here, if you have printed a project or a page - but of course, this is an action that cannot be undone or redone. But this is necessary internally, as printing writes information about page printing to the page.
- If you run an action that cannot be undone (e.g., parts data synchronization), the list will be deleted. This means that the previous work steps cannot be undone anymore either.

### Undo and redo views

Using the Back and Forward commands, you can undo or redo your last changes of the view. This affects zoom settings and changes of page. (To this purpose you first have to [Customize the ribbon](userinterface_h_menuebandanpassen.htm) and then assign the desired command to a user-defined command group.)

Like the undoing / redoing of actions, the undoing / redoing of views has a linear structure. The page changes and zoom settings made are thus run through in their original order.

# Report Pages

Report pages represent the results of reports in their own pages. Reports are divided into [report types](formgeneratorgui_k_auswertungstypen.htm). This allows groups of similar types of information to be reported. Report types are assigned forms in order to clearly structure and format project data in the report pages. The forms contain placeholders that are filled with project data during reporting.

When generating reports you can decide whether you wish to generate report pages or an [Embedded report](formgeneratorgui_k_ausgabeformen.htm). Project data is output in report pages when you select the "Page" output format when generating the reports. Eplan sorts the generated report pages into the page structure of the existing project pages. You can recognize a report page from the page type, for example "Terminal diagram (A)". You use [page sorting for reports](formgeneratorgui_k_seitensortierung.htm) to define whether a report is generated in one or several [report blocks](formgeneratorgui_k_auswertungsbloecke.htm).

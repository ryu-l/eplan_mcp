# P012004: The dimensions of the part placement do not correspond to the dimensions of the part

### Cause

The values of the fields X- / Y-extension of a part placement were changed subsequently and now differ from the property Width / Height of the part being used.

If the part property Width / Height of the part has been changed in the parts management and the values of the fields X- / Y-extension of the corresponding part placement are the same, this message also appears.

### Solution

1. Check the values in the fields X- and Y-extension of the part placement.
2. Also check the dimensions of the part in the fields Width and Height of the parts management. X-extension and width as well as Y-extension and height must match.
3. If the values do not match, adjust them.
4. If required, start a new check run.

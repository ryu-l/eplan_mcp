# Symbol Exchange

When changing standards, symbols of one standard can be exchanged with symbols of another standard. Symbols can only be exchanged for symbols with the same structure and size. The function definitions of the symbols must therefore match. The target symbol can possess an equal or greater number of connection points as the source symbol. The direction of the connection points must match the rotation of the project.

![](../Pictures/Gui/ALL/note.png)Notes:

- Symbols with symbol numbers > 3000 are no longer used in Eplan projects. So it is basically not possible to change standards for these symbols. However, you have the option of manually adjusting or exchanging such symbols.
- Please note that symbols of the symbol library IEC\_single\_Symbol can only be replaced to a limited extent by symbols of the symbol library NFPA\_single\_Symbol. Therefore manual correction of the replaced symbols is required after the change of standard.

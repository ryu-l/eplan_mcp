# P017004: Error in DT: <x>

### Cause

You used one or more characters in the device identifier which are not permitted characters.

### Solution

#### Possibility 1

Remove the incorrect character(s) and replace them with permitted characters.

#### Possibility 2

1. Select the following commands: File > Settings > Projects > "Project name" > Devices > DT syntax check.
2. If you want to use the characters "+", "-", "\_", "\*" and "?", activate the Valid special characters check box in the Device tag group box of the Electrical engineering or Fluid power tab.
3. Select the Special text characters check box as well, if you want to allow special characters, such as umlauts, in the device tag.
4. Copy the characters defined as allowed into the neighboring field without adding any dividers.

---

  

If required, start a new check run.

# Dialog Edit block reference properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a project page in the graphical editor. You have combined several elements to a block and selected this block. Popup menu item Properties.

This dialog displays the properties of a block reference.

Overview of the main dialog elements:

Number of objects:

This field shows the number of objects contained in the block.

Number of references:

This field shows how many references to this block are placed in the project. (At present only one reference is possible.)

Name of referenced block:

Provide a name for the block here. In a DXF / DWG export, this name is stored in the exported file.

[Break up block]:

Breaks up the block into its individual elements. The individual objects can then be individually edited.

# P027018: Connection point <x> does not exist and cannot be created

### Cause

On the topology function, the named connection point <x> does not exist in the connection point pattern, and cannot be generated during the route either.

The message occurs in connection with terminal strips displayed multiple times.

### Solution

1. Locate the topology functions in your routing path network by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Call up the Properties <...> dialog of the topology function, and switch to the Connection point pattern tab.
3. Select the table, and select from the popup menu the Update menu item.
4. Delete all connection points from the table that are not to be connected to this display of the terminal strip. (For example, these can be connection points that are connected with targets in another routing path network.)
5. Click [OK].
6. Route the connections again.

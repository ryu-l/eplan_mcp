# P007006: Function without connection point designation

### Cause

There is at least one connection name missing from the function placed in the schematic. Or no name is entered at a shield.

### Solution

1. Double-click the component and enter the missing different connection point designation(s) in the Properties <...> dialog. Or enter the missing name of the shield.
2. Click [OK].
3. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

Connection points without connection point designation are not reported if the connection point type "Internal", "Direct connection point" or "Saddle jumper" is assigned to them.

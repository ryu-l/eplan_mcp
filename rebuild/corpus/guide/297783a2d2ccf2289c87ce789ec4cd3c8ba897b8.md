# Tab Dimensioning

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a project page in the graphical editor. You have marked a dimension and selected the popup menu item Properties. In the Properties dialog select the Dimensioning tab.

In this tab you edit the display properties and, if necessary, dimension values.

Overview of the main dialog elements:

Group box Display

Segments:

This field displays the individual sections of continued dimensions, incremental dimensions, and baseline dimensions. For all other dimensions this field is not displayed. Select the segments whose properties you would like to view and change. (You can select several segments by holding down the [Ctrl] key and then clicking the desired segments.)

Prefix:

The prefix is placed in front of the dimension value. Select an entry from the drop-down list or enter a value manually. All characters are allowed.

Dimension value:

By default, this field is write-protected and serves to display the automatically calculated dimension value. Deselect the Automatic check box if you would like to change the dimension value manually. You can also dimension unscaled lengths this way.

![](../Pictures/Gui/ALL/warning.png)Warning:

If you change the Unit property or the Precision property for manually-entered dimension values, the specified value may be lost, depending on the setting. For example, if you entered the dimension value of "1,234 mm" for a precision of "0.000", the value will change to "0.001 m" if you change the unit to "m". If you then change the unit back to "mm", the dimension value will change to "1.000 mm".

Suffix:

The suffix is attached to the end of the dimension value. Select an entry from the drop-down list or enter a value manually. All characters are allowed.

---

Group box Dimension value

Distance to dimension line:

Here you specify the desired distance from the dimension value to the dimension line. The value from the project settings is used as the default.

Center dimension value:

If this check box is selected, the dimension value is displayed in the middle of the dimension or the section in question. This setting also affects the angle and alignment of the dimension value. These are grayed out on the Format tab and cannot be changed when the Center dimension value setting is activated.

![](../Pictures/Gui/ALL/note.png)Note:

If you move the dimension value with the mouse, it is moved accordingly and the Center dimension value check box is deactivated and the value of the Distance to dimension line field is deleted in the Dimensioning tab. The affected dimension value is moved exactly back as soon as you reselect the check box and enter the original distance value.

Unit:

Select the dimensioning unit from the drop-down list. The value from the project settings is used as the default.

Display units:

If this check box is selected, the unit will be displayed with the dimension value on the dimension line.

If the check box is deselected, only the dimension value is displayed.

Display two units:

If this check box is selected, the dimension value is displayed both in a metric unit (mm, cm, etc) and in inches.

The dimension value with the second unit (thus the one that is not set in the Unit field) is displayed immediately after the first dimension value with the first unit in square brackets (e.g. 88 mm[3.46"]). The dimension value in the second unit is shown with the same accuracy as the first dimension value, although the decimal places are limited to two.

If the check box is not selected, the dimension value is displayed with the unit specified in the Unit field only.

![](../Pictures/Gui/ALL/note.png)Note:

It is not possible to display two units for the angular dimension. In this case, the Display two units check box in the properties dialog is grayed out.

Precision:

From the drop-down list, select the desired number of decimal places to be displayed for the dimension value. The value from the project settings is used as the default.

Suppress zero:

If this check box is selected, non-significant zeros will not be shown.

Display dimension value as fraction:

If this check box is selected, decimal numbers such as "0.5", "0.25", "0.125", "0.0625" or multiples thereof are displayed as fractions. The possible fractions are "1/2", "1/4", "1/8", "1/16" and multiples thereof. No other decimal numbers are displayed as fractions.

Horizontal dimension value:

If this check box is selected, the dimension value is always shown horizontally, regardless of the dimensioning direction.

If this check box is deselected, the dimension value is always shown in the dimensioning direction.

Dimension value centered in dimension line:

If this check box is selected, the dimension value is positioned in the center of the dimension line, thus interrupting the line. The dimension value is always displayed horizontally and centered. In this case, the Horizontal dimension value and Center dimension value check boxes are grayed out. This setting also affects the angle and alignment of the dimension value; these are grayed out on the Format tab and cannot be changed.

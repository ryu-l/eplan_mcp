# Dialog Settings: Languages

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > User > Display > Languages

This dialog is used to define the settings for the languages of the user interface.

Overview of the main dialog elements:

Dialog language:

Different languages for the user interface are offered for selection in this drop-down list.

![](../Pictures/Gui/ALL/note.png)Notes:

- You can only select other languages from the Dialog language list if these languages have also been installed on your system.
- After selecting a different dialog language, you must restart Eplan before the new language is displayed in the user interface.

Alternative language:

In this drop-down list, Eplan offers different languages to be used as the alternative language. You can use an alternative language if the project language is not available as a dictionary language.

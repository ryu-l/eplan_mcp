# Dialog Format: Property (calculation properties)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the dialog [Format: Calculation](eservicesgui_d_formatberechnung.htm) (for example, when creating a user-defined block property).

- In the Available format elements list, select a format element of the Property type and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).
- In the Selected format elements list, select a format element of the type Property and click ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit).

In this dialog you select a property to be used in the calculation formula.

Overview of the main dialog elements:

Available format elements:

This field displays the available format elements. The format elements can be used partially for navigation and partially for property selection. Which actions are possible is indicated by a preceding icon.

| Icon | Meaning |
| --- | --- |
|  | You can select a property by double-clicking the format element. |
|  | Using the button  (Next level), it is possible to go from the starting object to other objects connected to it and select indirect properties there. |
|  | You can select a property (by double-clicking) or navigate to other objects (via  (Next level)). |
|  | Group of properties |

The grouping of the properties corresponds to the grouping in the dialog [Format](eservicesgui_d_format.htm#Gruppierung).

Click the ![](../Pictures/Gui/ALL/all_expand_hierarchy_as.png) sign to open the subordinate property groups. If you can access indirect properties of other objects from this object, the ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level) button above the Navigation field is active. If you click this, the original property grouping is displayed once more â but these are now the (indirect) properties of the subsequent object!

If you select a multilingual property, the Source language is always used in the calculation formula and not the displayed language.

Navigation:

This field displays the path leading to the selected property. The steps are displayed in the individual rows through the available format elements. This way you can recognize more easily from which object the property is determined.

Toolbar:

Using the buttons above the Navigation field, you can follow the path to indirectly referenced objects and back again.

| Button | Meaning |
| --- | --- |
| (Next level) | Allows continuing from a starting object, going to objects connected to this object and examining the indirect properties there. |
| (Previous level) | Allows returning from an indirectly referenced object back to the starting object. |

Category:

The category allows you to limit the display of the properties possible for the marked format element to a subset.

Find:

Into this field enter the text for which the properties are to be filtered. Both property names and set values are found when the properties are filtered. Logic operators (AND / OR operation) and placeholders (such as \* or ?) are not supported for filtering.

If you want to return to the original view of the properties, remove the search term from the entry field. Click ![](../Pictures/Gui/ALL/all_delete_input_as.png) (Delete) to do so.

Table:

All properties available for the relevant format element are displayed sorted by name in the Property name column of the table. The associated property values (where available) are displayed in the Value column. Double-click a column header to sort the properties by the respective column.

Select the desired property and click [OK] to open the property in the dialog Format: Calculation.

Replacement text:

From the drop-down list select the table of replacement texts to be used. The values of the selected property are then compared to the texts defined in the table and replaced accordingly.

- Select the "Use local table" entry if the table with the replacement texts is to be saved directly in block format. To do so, click the [...] button and define a local table with replacement texts in the Replacement texts dialog.
- Select the "Use table [n]" entry if you want to use a table predefined in the project properties or in the form properties. Click the [...] button to inform yourself in the subsequent dialog Replacement texts whether a table was defined for the respective entry. If so, you can view the defined replacement texts there, but not edit them.
- If you select "Do not use", the values of the selected property will not be replaced.

![](../Pictures/Gui/ALL/note.png)Note:

The tables predefined in the project properties or in the form properties are displayed via the project properties Block property: Replacement text [n] and via the form properties Properties formatted: Replacement text [n]. Using the index [n], you can define up to 100 tables for project properties and up to ten tables for form properties.

- The tables defined in the project property are used for the block format of Block properties at the various objects (project, page, function, etc.).
- The tables defined in the form property are used primarily for the block format of Placeholder texts with formatted properties in the forms. If the selected table is not defined in the form property, the table of the same name will instead be used from the project property.

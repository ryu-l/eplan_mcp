# Dialog Settings: Parts management

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a parts database. Tab Master data > Command group Parts > Management. Button [Extras] > Settings. Button [Other].
- You have opened a project and selected a main function in the graphical editor or in a navigator. Popup menu item Properties. Select the Parts tab and click [...] next to the Data source field.
- File > Settings > User > Management > Part. Button [Other].

In the Settings: Parts (user) dialog, click [Other].

In this dialog, you can specify certain default settings for your work with parts management.

Overview of the main dialog elements:

Measuring unit - import / export:

In parts management, units are always saved in "mm" / "kg". If you import or export Eplan data, you can use these options to decide which unit system should be used.

Currency 1 / Currency 2:

In these two fields you specify the two currency units which are to be used for the selected parts database.

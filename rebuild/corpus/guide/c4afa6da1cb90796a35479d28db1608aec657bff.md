# Finding Objects in the Insert Center

You can use the full-text search in the Find field to search for one or more specific objects in the Insert center. Information about the different options during the search can be found in the section ["Searching in the Insert center and in the parts management"](insertergui_k_suchen.htm).

Preconditions:

- You have opened a project.
- You have opened a project page in the graphical editor. Or you have opened a layout space in the graphical editor.
- You have opened the Insert center.

### Searching across all object types

By default, the ![](../Pictures/Gui/ALL/insertergui_search_in_all_as.png) (Search all) button is activated for the search in the Find field. In this case the search is carried out over all object types. If possible, the search is also carried out in the Eplan Data Portal. If the search is to be carried out without taking the Eplan Data Portal into consideration, you have to click the ![](../Pictures/Gui/ALL/insertergui_search_in_all_except_DP_as.png) (Search all (except Data Portal)) button.

1. Enter the desired search term in the Find (![](../Pictures/Gui/ALL/insertergui_start_searching_as.png)) field.
2. Press the [Enter] key.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The entry Home > Search results is displayed in the breadcrumb trail.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The search result is displayed - grouped by object types - below the breadcrumb trail in the form of drop-down folders next to which the number of found hits is noted. The number of search hits is also displayed for the Eplan Data Portal.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If a part is not found in the Insert center during the search, but instead in the Eplan Data Portal, it is also displayed there. To this purpose, the Eplan Data Portal is opened, if necessary.
3. To display a concrete search result, click the down arrow button next to the folder of the desired object type. To have the search result displayed in the Eplan Data Portal, click the icon ![](../Pictures/Gui/ALL/userinterface_edpIcon_as.png) Data Portal.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The preview tiles of the determined objects are displayed below the object type. The objects can be inserted directly.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the Eplan Data Portal has not yet been displayed, it is opened. The search text that was entered in the Find field is also used for the search in the Eplan Data Portal. You can select and download parts in the Eplan Data Portal.
4. If necessary, switch to the search result of another object type by opening the corresponding folder.
5. To return to the standard view, click Home in the breadcrumb trail.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The term entered in the Find field and the Search results folder are retained.

### Searching in a specific object type

1. Click the button ![](../Pictures/Gui/ALL/insertergui_search_in_all_as_21x20.png) (Search all).
2. Select the desired option from the menu that opens (for example ![](../Pictures/Gui/ALL/insertergui_search_only_device_as.png) Search in devices).
3. Enter the desired search term in the Find (![](../Pictures/Gui/ALL/insertergui_start_searching_as.png)) field.
4. Press the [Enter] key.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The entry Home > Search results is displayed in the breadcrumb trail.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The folder of this object type in the search results is opened directly, and the preview tiles of the determined objects are displayed. The objects can be inserted directly.
5. To return to the standard view, click Home in the breadcrumb trail.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The term entered in the Find field and the Search results folder are retained.

![](../Pictures/Gui/ALL/note.png)Note:

In the search result only the default variant of an object type is always displayed in the preview tile.

![](../Pictures/Gui/ALL/info.png)Tip:

By default, the search is carried out via specific properties of an object type. Use the [...] button to branch to the subsequent Configure search dialog. There you can use a scheme to specify the properties of an object type and the sequence in which the search is to be carried out.

### Deleting the search result

Preconditions:

You have entered a search term in the Find field, started a search and obtained a search result.

1. Click the icon ![](../Pictures/Gui/ALL/all_delete_input_as.png) next to the entered search term.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The field Find is emptied and the search result is deleted.  
     
   ![](../Pictures/Gui/ALL/arrow.png) You return to the standard view of the Insert center.

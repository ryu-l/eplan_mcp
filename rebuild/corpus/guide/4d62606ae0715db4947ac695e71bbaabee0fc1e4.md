# Dialog Select data source (Pre-planning, Text file import)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project, and have the pre-planning navigator open. Tab Pre-planning > Command group General > Import. In the Import pre-planning data - <Project name> dialog, select the "Text" entry in the Type of data source field and then click the [...] in the Data source field.

You select the data source for the import of a text file from this dialog.

Overview of the main dialog elements:

Text file:

In this field you select the text file: Click [...] to navigate through the directory structure in the subsequent dialog, and select the required file.

Column names in the header row:

Column names are mandatory in a text file so that the data can be assigned to the Eplan properties. Therefore this field is always activated and grayed out for text files.

Separator:

Specify here the separator to be used in the text file in order to separate the columns. The following values are possible:

- Blank
- Tabulator
- Other characters: After selecting this option, enter the desired character in the input field below. Any digits, letters, and special characters can be used.

# P001034: Old manual saddle jumper setting: '<x>'

### Cause

A terminal strip with a manually generated saddle jumper that was configured using Eplan Version 2.4 or a previous version was inserted in the project (for example via a macro ) on a schematic page. Eplan lists all the terminals in the dialog of the message management that are involved in the generation of this saddle jumper. The placeholder <x> of the message provides information about which saddle jumper setting was used beforehand, for example "Start of jumper".

![](../Pictures/Gui/ALL/note.png)Note:

Since working with manual saddle jumpers has been changed since Version 2.5, this check run allows you to determine whether manual saddle jumpers exist in your current project that were configured with previous Eplan versions.

### Solution

1. First locate the relevant terminal in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Select the Properties popup menu item.
3. Bring the first tab to the front in the property dialog of the terminal .
4. Change the setting "[No value set]" in the Saddle jumper field that as of Version 2.5 can only still be used for the generation of automatic saddle jumpers. Select the setting "Automatic" for example.
5. Click [OK].
6. Also repeat the change of this setting for all other jumpered terminals in the terminal strip.
7. Generate the desired manual saddle jumper again in the Edit terminal strip dialog (Tab Devices > Command group Terminals > Terminal strip).
8. If required, start a new check run.

# Dialog Settings: Print margins

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Export > Command group Project data > Project data > Group box Page > PDF > Button [Settings] > Print margins.

The PDF export print settings are displayed and can be edited in this dialog. Modifications made here are also adopted in the current print settings (File > Print > Group box Pages > [Settings]).

Overview of the main dialog elements:

Left / Right / Top / Bottom:

Here, you can determine the area for all four page margins that should not be printed. The units are taken from the project settings and displayed here. Input is possible in mm and in inches.

Print position:

Here, you define how a PDF page will be positioned on the sheet of paper. The print margins specified are taken into account. Select the desired position from the drop-down list.

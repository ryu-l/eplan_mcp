# Update of the Insert Center

The Insert center updates automatically after the following events:

- Adding or removing symbol libraries
- Generating, updating and deleting the [macro collection](insertergui_k_makrosammlung.htm)
- Changing of parts data in the parts database
- Import of favorites or tags

![](../Pictures/Gui/ALL/note.png)Note:

If the macro collection has to be updated, this is indicated by means of the ![](../Pictures/Gui/ALL/warningicon_systemmessages.png) icon in the status bar. Simultaneously a corresponding warning message is issued. If you click the icon, the system message dialog is shown in which the message is listed. Click [Close] to close the dialog and delete the icon with the warning message in the status bar.

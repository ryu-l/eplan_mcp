# Designate connections

Connection designations are assigned using connection definition points. A connection can only be designated if the source and target of the connection are selected. (If a page is open in the graphical editor you can select the connections manually. Otherwise they are selected via the page or project selection.)

Both the scope and the subscope are taken into account when renumbering connections. For the connections in the selection, the associated scope is identified automatically and the connection designation is adopted from the scope, according to the settings.

Precondition:

You have selected a connection in the graphical editor, or in the Connections - <Project name> navigator dialog. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog.

1. Select the following commands: Tab Connections > Command group Connections > Enter designation.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Once you have called up the command, the connections are first automatically generated new.
2. In the Settings field of the Designate connections dialog select a scheme from the drop-down list that specifies the settings for connection numbering. Use [...] to open the [Settings: Connection numbering](wirenumberinggui_d_verbnumeinstellungen.htm) dialog. Define the numbering settings here and store them in a scheme.
3. In the table specify the start value and the increment for numbering each displayed connection group. If the start value and increment are the same for all the counters in a group, also select the Group check box.
4. Select the Mark as 'manually set' check box to assign the Manually set property to all connection definition points for which a connection designation is set during this numbering process.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have activated the Preview of result check box, the dialog Designate connections: Preview of result is first displayed. Here you can check the new connection designations and change them manually if required.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection designations are displayed at the connections that are selected for numbering, as long as connection definition points have already been placed there.

# Action: XMActionDCImport

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| ProjectLink | Project name with complete file path. |
| DataConfigurationFile | File path of the data configuration file (\*.edc). |
| ProgressTitle | Specifies the title of the progress bar (optional). |

![](../Pictures/Gui/ALL/note.png)Note:

This action makes it possible to modify the properties of functions, pages and / or connections by way of an import. A data configuration file \*.edc can, for example, be generated using File > Export > Command group Project data > Project data > Command group External editing > Properties.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
XMActionDCImport 
/ProjectLink:C:\Projects\EPLAN\test.elk 
/DataConfigurationFile:C:\EPLAN\DataCfgFile.edc
```

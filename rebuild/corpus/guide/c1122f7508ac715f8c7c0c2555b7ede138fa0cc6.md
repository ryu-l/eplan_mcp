# Synchronizing Connections Displayed in a Distributed Manner

A connection can occur in the schematic multiple times in a distributed manner in the representation types "Multi-line", "Single-line", "Topology" or "3D mounting layout". If you have not activated the Properties (global) processing mode, you can edit the properties of the distributed connections independently of each other. This can create differences between the properties of the connections. If you wish to fix the differences, synchronize the properties of the distributed connections throughout the project.

Preconditions:

- You have opened a project.
- You have further multi-line, single-line and / or routing connections of at least one identical connection.
- You have specified in the project settings how empty properties are to be handled during synchronizing (File > Settings > Projects > "Project name" > Devices > General, [Synchronization](xessettingsgui_d_betriebsmittelallgemein.htm) group box).

1. Select a project, page, or connection.
2. Select the following commands: Tab Tools > Command group Synchronization > Drop-down button Connections > "Representation type" --> All representation types  
     
   ![](../Pictures/Gui/ALL/arrow.png) After you have confirmed the prompt, the property values of the selected connections are transferred to the corresponding connections of the other representation types.

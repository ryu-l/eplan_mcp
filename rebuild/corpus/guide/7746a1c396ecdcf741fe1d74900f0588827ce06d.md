# Defining Device Numbering (Changing Standards)

User-defined and pre-defined schemes for device numbering are taken from the basic project that you specified when creating the target project.

Preconditions:

- You have opened a project.
- In the case of several opened projects: You have selected a project in the page navigator.
- You have set up a target project.
- You have defined a basic project and the rotation / flipping.
- You have replaced the necessary plot frames, forms, symbol libraries, and symbols.
- You have specified the project structure.

1. Select the following commands: Tab Tools > Command group Standards > Exchange > Tab Project > Button [Next] > Tab Rotation / flipping > Button [Next] > Tab Master data > Button [Next] > Tab Structure > Button [Next].
2. In the Numbering tab select the Renumber devices check box.
3. Select a numbering format from the Device numbering drop-down list.
4. Click [Finish].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The target project is displayed in the page navigator.

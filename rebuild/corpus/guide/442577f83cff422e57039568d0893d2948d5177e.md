# P002005: Only male pin end available

![](../Pictures/Gui/ALL/note.png)Note:

The counterpiece of a male pin is either the female pin with the same DT and the same pin designation or a female pin that is connected with the male pin via direct connection points.

### Cause

A plug definition was created in the plug navigator or placed in the schematic. The function definition "Plug definition for male pins" is set at this plug definition. This setting makes the program search for a corresponding item, namely the female pin end. This counterpiece, however, is missing in the plug navigator or in the schematic.

### Solution

#### Possibility 1

1. Place a further plug definition in the schematic and enter "Plug definition for female pins" for the function definition.
2. In addition, for the plug definition, enter the same DT as you did for the male pins at the plug definition.

#### Possibility 2

1. Select the plug definition for male pins in the plug navigator.
2. Select the Generate plug definition popup menu item and branch to the submenu Only female pins.
3. Click [OK] in the property dialog that is opened.

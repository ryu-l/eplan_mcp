# P030008: The unplaced connection does not fit into the defined working section of the subproject.

### Description

In a filed-off subproject an unplaced connection was created that does not fulfill the filter criteria agreed in the defined working section. For example the unplaced connection was integrated into the identification structure that does not exist in the defined working section of the subproject.

Make sure whether the creation of this unplaced connection is permissible in the subproject with regard to the storage of the subproject in the original project.

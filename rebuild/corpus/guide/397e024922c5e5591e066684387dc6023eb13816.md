# Dialog Settings: Input box

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > User > Graphical editing > Input box

This dialog is used to determine the settings for the input box for entering values via keyboard.

Overview of the main dialog elements:

Always show input box (2D) / Always show input box (3D):

Activate this check box if you want the input box to always be displayed in the 2D or 3D editor.

![](../Pictures/Gui/ALL/note.png)Note:

The input box can be shown or hidden either here in the settings or in the editors by using the Input box command in the ribbon. The setting will then be synchronized accordingly, meaning that if you activate the input box in the settings and then deactivate it in, for example, the graphical editor, it will also be deactivated in the settings.

Transparency level (without focus) / Transparency level (with focus):

Enter the transparency level with or without focus as a "%"; the maximum value for the transparency level is "85%".

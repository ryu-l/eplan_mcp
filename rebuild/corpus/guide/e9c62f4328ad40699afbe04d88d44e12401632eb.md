# Tab Hose assignments

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > User > Add-ons > Hose line configurator. Click the Hose assignments tab.
- You have opened a project. You have opened the [Configure hose lines](fluidhoseconfiggui_d_schlauchleitungen.htm) dialog. Select the Extras > Settings menu items. In the subsequent dialog click the Hose assignments tab.

You define the default data for hose assignments in this tab. In the process you assign different hose groups to a specific working pressure and furthermore store the desired maximum and minimum permissible hose diameters for the selected hose groups. The working pressures entered in the table are offered for selection when the hose lines are configured in the Edit <...> dialog.

Use the buttons of the toolbar above the list to create new entries, edit existing ones and / or delete entries no longer required.

Overview of the main dialog elements:

Working pressure (list):

Determine the maximum permissible dynamic working pressure of the hose lines here. The values reference the unit "bar".

Use the buttons of the toolbar above the list to create new entries, edit existing ones and / or delete entries no longer required.

![](../Pictures/Gui/ALL/note.png)Note:

Different working pressures can be assigned in accordance with different hose groups.

Table:

In this table you assign the required hose groups as well as the minimum and maximum permissible nominal diameters of the hoses to the respective working pressure.

Use the buttons of the toolbar above the table to create new entries and / or delete entries no longer required.

![](../Pictures/Gui/ALL/note.png)Note:

If you select the default scheme DIN 20066\_2012-01 the settings in this tab and in the [Hose groups](fluidhoseconfiggui_r_schlauchgruppen.htm) tab have the effect that the hose types specified in accordance with the standard DIN 20066 are offered for selection in the Edit <...> dialog for each selected working pressure and for each selected nominal diameter of the hose.

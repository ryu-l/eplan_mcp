# P003011: Too many cable connections

### Cause

The value entered in the field Number of connections of the cable connection property dialog is smaller than the actually existing number of cable connections of the cable.

![](../Pictures/Gui/ALL/note.png)Note:

Shields and free templates are not taken into consideration!

### Solution

#### Possibility 1

Increase the value in the field Number of connections of the cable connection property dialog so that it matches the number of cable connections actually existing.

#### Possibility 2

In the cable connection property dialog click [...] next to the Type field and use the part selection to enter a suitable cable with the corresponding number of connections.

#### Possibility 3

With the Part tab of the cable connection property dialog take advantage of the possibility of the Device selection that is available to you via the button by the same name.

---

Update the connections.

If required, start a new check run.

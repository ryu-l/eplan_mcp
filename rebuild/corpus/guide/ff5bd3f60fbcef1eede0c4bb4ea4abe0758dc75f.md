# Exporting Manufacturing Data for Machining Enclosures to Rittal - RiPanel Processing Center

Eplan Pro Panel allows the manufacturing data to be provided for machining of enclosures in the form of an AML file for Rittal - RiPanel Processing Center. To this purpose an interface for the export of data is available in the Backstage view.

Precondition:

- You have opened a project.
- The project contains at least one layout space with a 3D mounting layout.

1. Select the project in the page navigator.
2. Select the following commands: File > Export > Command group Manufacturing data > Machining > Rittal - RiPanel Processing Center.
3. Select a suitable scheme from the drop-down list in the Scheme field of the Export: Rittal - RiPanel Processing Center dialog. Or click [...] to specify the settings for a new user-defined scheme in the subsequent dialog.
4. Select the storage location for the data to be exported in the Output directory field.
5. Enter a name under which the export file is saved in the Target file field. Or select the name interactively via ![](../Pictures/Gui/ALL/all_selectfile_as.png).  
     
   ![](../Pictures/Gui/ALL/arrow.png) A query is displayed when you select an existing file. There decide whether you want to overwrite the file.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png)The data are written to the export file.

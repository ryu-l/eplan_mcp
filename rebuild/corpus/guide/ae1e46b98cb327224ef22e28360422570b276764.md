# P011005: Arrowheads at cross-referenced interruption points do not match

### Cause

The arrowheads of two interruption points cross-referencing each other point towards each other. Interruption points must be placed in such a way that the arrowhead of the one interruption point points towards the arrow stub of the other one.

### Solution

1. Locate the interruption points in the schematic by using the functionalities Go to (graphic) and Go to (2nd coordinate), which the popup menu of the Message management dialog offers you.
2. To do this, double click the interruption point to be changed and bring the Symbol data tab to the foreground in the Properties <...> dialog.
3. Depending on the alignment of the interruption point, rotate the arrow symbol by 180° by means of the Variant drop-down list. To do this, select, for example, only variant C for preset variant A.
4. If required, start a new check run.

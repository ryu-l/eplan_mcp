# P016001: Component within two black boxes which are not nested

### Cause

There is a component between two overlapping but unnested black boxes. This is preventing the component from being clearly assigned to one of the black boxes.

### Solution

Check which device identifier the component belongs to and which black box it is assigned to. For more information on the nesting of devices with black boxes, see the section [Black Boxes. Basics for nesting](blackbox_k_schachteln.htm).

# P005088: Individual connection with DT

### Cause

At a multi-line or single-line connection the value "Individual connection" was assigned to the Connection: Association property. In addition this connection disposes of a device tag.

### Solution

1. Locate the connection definition point of the connection in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the property dialog of the connection definition point.
3. Delete the device tag of the connection or assign a different value to the Connection: Association property.
4. Click [OK].
5. If required, start a new check run.

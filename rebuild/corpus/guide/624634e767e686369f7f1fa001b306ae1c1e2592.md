# Copper Parts: Principle

Parts for bent busbars can be found in parts management under the parent group Mechanics, subgroup Component, Busbars, Rail. When placing a "Busbar (bending)", a filter is used for the selection of the part number, and the suitable position in parts management is opened immediately.

Values are entered for the rail part on the Properties tab in the Width and Depth fields in the Mounting data hierarchy level. These values form the rectangular cross-section outline of the copper rail. They are read out during the placement and assigned to a form. The form is the path along which a rectangular basic outline is moved in order to shape the bent copper rail.

If an Outline (extrusion) with the file extension \*.fp1 (to create a user-defined rail) is assigned to the part instead of the values in the Width and Depth fields, this part cannot be used for a bent copper rail. An error message is displayed during the placement.

At the rail part a value is entered for the Delivery length property in the Technical data hierarchy level on the Properties tab for purchased rail parts. This value is taken into account during the placement of the rail, so that the rail can be shaped only up to this value along the form. When the delivery length is reached, a message is shown; in the design, another rail must be connected here.

### Unchangeable copper items

The length, angle and bending positions of a placed copper item are generally changeable. In practice, however, there is the requirement that copper items are to be standardized or purchased in a fixed set form. Such parts, which are not variable, should not be possible to be modified after placement.

This behavior can be controlled using the Prefabricated (ID 36011) property that can be activated on the item, e.g., in a macro. Once this property exists and has been activated, the copper item can no longer be modified after placement. If this property is deactivated, the functions for editing copper items can be applied again.

# Creating / Selecting a Dictionary

You can create and manage multiple dictionaries. Select the appropriate dictionary for each of your projects.

### Create Dictionary

1. Select the following commands: Tab Tools > Command group Translation > Dictionary.
2. In the Dictionary dialog click ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the Management tab to create a new dictionary as an Eplan database or as an SQL server database.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected the SQL server option, the Generate SQL server database dialog is opened to this purpose.
3. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The newly created database will then be entered in the settings as a Dictionary and is therefore automatically selected.

### Select the dictionary

Precondition:

You have created a database for the Dictionary or have access to such a database.

1. Select the following commands: Tab Tools > Command group Translation > Dictionary.
2. In the Management tab click ![](../Pictures/Gui/ALL/all_selectfile_as.png) next to the Eplan option and select the desired database file \*.db using the file selection dialog.  
   Or click the SQL server option and then select one of the last 15 SQL databases used from the drop-down list. The databases used last are listed at the top.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The database is entered in the settings as the Dictionary.

### Add a dictionary language

1. In the Management tab, use [...] to select the dictionary to which you wish to add a dictionary language.
2. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) next to the Dictionary languages field.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan displays all of the languages that can be accepted into the dictionary.
3. One after the other, select all of the languages that should be available in the dictionary.

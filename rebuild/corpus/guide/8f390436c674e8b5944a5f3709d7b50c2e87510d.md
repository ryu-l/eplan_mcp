# P027002: The topology function is not connected to a routing path

### Cause

Within the routing path network, a topology function or routing point was determined that is not connected to a routing path. Thus, there is no routing path on the graphical connection point of the topology function or on the insertion point of the routing point.

### Solution

1. Locate the topology function or the routing point in the project by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Connect the topology function and / or routing point to a routing path.
3. Update the connections.
4. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

It is not absolutely necessary for topology functions that an automatic routing path to the nearest routing point is generated during the route.

# Specifying Local Formats for User-defined Block Properties

At functions and certain other objects it is now possible to specify a separate block format locally for a user-defined property that is defined as a block property. To this purpose the Configure properties dialog in the Display tab contains the new Block format at the object rewritable check box.

[![](../Pictures/Gui/Lang/eservicesgui_userpropertiesdialog_localformat_ls_thumb_0_60.png)](../Pictures/Gui/Lang/eservicesgui_userpropertiesdialog_localformat_ls.png)

This setting is only available for the "Block property" display type. If this check box is activated, a further block property with the same identifying name is generated in addition to the user-defined block property. This second property differs from the actual user-defined block property by the supplement "(local format)" in the displayed name and can be edited. This block property serves to define a local block format and can also be selected at the object to which the user-defined property has been assigned (for example function).

A local block format is possible for the following objects:

- Interruption points
- Function
- Page
- Connection
- Segments (pre-planning)

To specify a local block format at an object, select the block property for the local format in the property table. You can use the [...] button in the Value column to branch to the Format dialog and define a local format there. The value specified here is then also displayed for the associated user-defined block property with the same identifying name.

# Scaling Symbols

Precondition:

You have opened a project and at least one symbol library.

1. Select the following commands: Tab Master data > Command group Symbols > Drop-down button Symbol > Open.
2. In the Symbol selection dialog select the symbols you would like to edit.
3. Click [OK].
4. Select the following commands: Tab Edit > Command group Graphic > Scale.
5. Click once with the left mouse button in the editing window to specify the starting point for the frame around the elements to be scaled.
6. Move the cursor in the direction you would like to stretch the frame around the elements to be scaled.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The rectangle lines "move" with the mouse.
7. Click a second time to specify the end point of the rectangle.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected symbol parts will be colored.
8. Click in the symbol editor.
9. Enter the desired value into the Scaling factor field of the Scale dialog.
10. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The symbol is scaled to the specified value.

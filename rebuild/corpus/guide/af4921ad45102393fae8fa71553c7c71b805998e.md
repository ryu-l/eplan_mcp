# P024008: Differing conduit data: <x>

### Cause

You treated a conduit that was shown as distributed In the schematic as if it were separate conduits and assigned contradictory data to the main function and auxiliary functions. These data include the properties Type, Number of connections and / or Cross-section / diameter that are output in the placeholder <x> of the message.

### Solution

1. Locate the main function of the conduit in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Open the main function of the popup menu and use the menu item Go to (counterpiece) to jump to the auxiliary function of the conduit.
3. Open each property dialog at the main and auxiliary functions of the conduit and standardize all the values in the fields of the respective properties.
4. If required, start a new check run.

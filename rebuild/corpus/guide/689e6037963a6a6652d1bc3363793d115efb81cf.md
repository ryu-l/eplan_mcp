# P030001: Original project contains changes in the defined working section of the subproject '<x>'

### Cause

In the original project, for example, pages, layout spaces or pre-planning segments were created in the defined working section in which you want to embed the subproject.

![](../Pictures/Gui/ALL/note.png)Note:

This message is only output in the original project.

### Solution

1. Delete the pages, layout spaces or pre-planning segments from the respective defined working section of the original project or move them to other defined working sections of the original project.
2. Then embed the subproject again into the desired working section of the original project.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

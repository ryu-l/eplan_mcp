# P001026: Unconnected distributed terminals with same designation

### Cause

The schematic contains distributed terminals that are not connected with each other although they have the same designation. The Connect associated distributed terminals automatically project-specific setting may not be activated.

### Solution

1. Select the commands File > Settings and in the tree view of the dialog Settings track the device in the Projects > "Project name" > Devices folder structure.
2. Click on the setting area Terminals (distributed terminals), and activate the Connect associated distributed terminals automatically check box.
3. Click [OK] in the dialog.
4. Update the connections.
5. If required, start a new check run.

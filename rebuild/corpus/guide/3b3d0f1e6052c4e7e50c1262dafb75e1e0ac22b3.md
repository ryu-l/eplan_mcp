# P011004: Connection via interruption points on the same page

### Cause

Two or more interruption points cross-referenced to each other with the same DT are located on the same schematic page. Only one interruption point with the same DT must be located on a schematic page.

### Solution

1. One after another locate the interruption points in the schematic by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Place all the surplus interruption points with the same DT on different schematic pages.
3. Update the connections.
4. If required, start a new check run.

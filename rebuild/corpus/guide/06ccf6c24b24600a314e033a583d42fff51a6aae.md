# Cross-referencing DTs

In Eplan, components with differing device tags can be cross-referenced to a new device by assigning a unified DT to the components.

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the components to be cross-referenced (at least two).
2. Select the following commands: Tab Home > Command group Edit > Property overview.
3. In the dialog Property overview click in the Value column of the properties table for the Name (full) property, and then the button [...].  
   If the Name (full) property is not displayed in the properties table, you must select a scheme with a suitable property configuration in the drop-down list for the schemes.
4. Enter the DT that is to be assigned to all the marked components as the common one in the dialog Full DT.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The DT is assigned to all the marked components. Device cross-references are then automatically displayed at the components.

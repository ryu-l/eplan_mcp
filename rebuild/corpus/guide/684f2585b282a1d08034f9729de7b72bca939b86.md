# P028029: The pipe class '<x>' entered does not exist as a template in the project

### Cause

A pipe class that is not defined as a template in the project was determined at a piping planning object, a piping or connection definition or a process engineering function.

### Solution

1. Locate the piping planning object in the pre-planning navigator using the Synchronize selection function offered by the popup menu in the Message management dialog. Or use the Go to (graphic) functionality of the popup menu to jump to the piping or connection definition point or to the process engineering function in the P&I diagram.
2. Open the property dialog of the corresponding object and bring the first tab to the front.
3. Click [...] in the property table of the piping planning object for the Pipe class property. Or in the case of a piping or connection definition point or the process engineering function click [...] next to the Pipe class field.
4. Mark a name listed in the Select pipe class dialog.
5. Click [OK].
6. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

If the desired substance is not available in the Select pipe class dialog, you have to define it as a new template in the Segment template navigator.

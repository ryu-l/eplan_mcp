# Dialog Output project information

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have selected a project management database. You have loaded directories and projects. File > Project management. Select a project. Button [Extras] > Output project information.

In this dialog you define the range of project-specific information to be output. The information is subsequently displayed in the Internet Explorer and is saved to this purpose in the local \tmp directory in an HTML file PrjInfo.htm.

Overview of the main dialog elements:

Condensed overview:

If you select this option, the following project information is output: Storage location of the project, project name, project description, job number, supplementary fields.

Complete overview:

If you have selected this option, then all project-specific information is output.

Complete overview with updating:

When you select this option, the project-specific information is updated and then a complete overview created. Depending on the size of the project database this process can take some time.

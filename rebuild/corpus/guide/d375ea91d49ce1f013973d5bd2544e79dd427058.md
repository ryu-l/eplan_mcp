# Plotting Locked Areas

Areas on the mounting panel can be locked for placement so that no part placement can occur on these areas. Locked areas are independent objects drawn as rectangles.

Precondition:

You have opened a project.

1. Select the following commands: Tab Devices > Command group 2D panel layout > Navigator.
2. In the graphical editor, select the panel layout page where you would like to draw a locked area.
3. Select the following commands: Tab Insert > Command group 2D panel layout > Drop-down button Mounting panel (2D) > Generate locked area.
4. In the graphical editor draw the rectangle that represents the locked area.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The locked area is drawn.

![](../Pictures/Gui/ALL/note.png)Note:

As soon as part placement is attempted in a locked area, the placement is prevented, and a corresponding message is displayed.

# P004117: Incorrect DT during AutomationML AR APC import

### Cause

An incorrect DT was determined at a PLC card or a bus-capable device during the PLC data import in the AutomationML AR APC format. The incorrect DT arose through missing preceding sign specifications (=, +, -, ...) at the identifier blocks of the reference identifier in the AML file.

### Solution

1. Please contact the creator of the AML file and have the missing preceding signs added in the PLC configuration program with which the AML file was generated.
2. Import the AML file again.

# Tab Hyperlink

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a project page in the graphical editor.

- Tab Insert > Command group External > Drop-down button QR code > Hyperlink.
- You have marked a hyperlink and selected the popup menu item Properties. In the Properties dialog, select the Hyperlink tab.

On this tab you can edit the display properties of a hyperlink.

Overview of the main dialog elements:

Document:

Enter the file or Internet page to be linked here. Using ![](../Pictures/Gui/ALL/all_selectfile_as.png) you can call the file selection dialog where you can select the document to be linked. The name including the entire path designation is transferred into this field.

You can also enter a URL or the file name of a document (with file path) by using copy and paste. Or you enter an e-mail address, for example "mailto:info@eplan.de".

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

![](../Pictures/Gui/ALL/note.png) Note:

Always start your hyperlinks with "http://" or "https://", to make sure that they always work in every environment on the Internet (during a PDF export, for example).

Text / designation:

The text entered here is displayed on the page. When selecting a file, the file name (without the file name extension) is automatically suggested. You can accept this text or change it manually. The text stored here is multilingual.

Description:

In this field, you can enter an optional descriptive text for the hyperlink.

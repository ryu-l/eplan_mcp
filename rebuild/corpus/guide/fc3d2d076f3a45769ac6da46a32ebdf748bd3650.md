# P020037: The project structure for '<x>: <y>' was changed from '<z>' to '<u>'

### Description

You have run a project comparison, checking the structure of the test project (incoming project) against that of the comparison project and differences were found.

This message occurs when a difference in the page or device structure was found in the test project. The changed structure element (<x>), the changed identifier block (<y>), the previous setting (<z>) and the new setting (<u>) are output. You can call up or set the page and device structure as follows: Mark the project in the page navigator, select the popup menu item Properties, select the Structure command in the Information Backstage view.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

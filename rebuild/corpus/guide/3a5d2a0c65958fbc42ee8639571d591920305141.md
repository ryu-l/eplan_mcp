# P026081: Error while placing a fitting: <x>

### Cause

A fitting could not be placed while routing a hose line.

Several causes are possible. The placeholder <x> of the message specifies the cause which led to the message being output.

### Solution

1. Locate the source of the routing connection in the layout space using the Go to (graphic) function provided by the popup menu in the Message management dialog.
2. Use the popup menu item Go to (counterpiece) to jump to the source in the schematic.
3. Determine the hose line connected to the source in the schematic.
4. Call the property dialog of the hose line and bring the Parts tab to the front.
5. Depending on the displayed placeholder carry out one of the following corrections:

   | Placeholders | Solution |
   | - No part number defined - Parts data could not be determined | Assign a suitable part or check the existing parts data for completeness and supplement if required. |
   | - No connection point defined - Connection point cannot be determined | No connection point pattern was stored for a part or no connection points were defined in the connection point pattern.  1. Select the following commands: Tab Master data > Command group Parts > Management , and bring the Properties tab to the foreground for the part in the parts management. 2. In the Mounting data hierarchy level click the [...] button in the Connection point pattern value field to call up the Connection point pattern selection dialog. 3. Either select a suitable connection point pattern or bring the Connection points tab to the foreground for an existing connection point pattern to define the connection points. 4. Click [OK]. 5. Click [Apply]. 6. Close the parts management and perform a parts data synchronization. Note:  If no suitable connection point pattern is available, you must first create a connection point pattern. To this purpose select the Connection point pattern hierarchy level in the tree view of the Parts management, and select the New popup menu item. |
   | - Fitting cannot be generated - No macro defined | 1. Make sure that a correct graphical macro is stored respectively for both fittings of the hose line. 2. If this is not the case, call up the parts management: Tab Master data > Command group Parts > Management. Select the correct graphical macro for the affected part on the Properties tab (Mounting data hierarchy level) in the Graphical macro field. Note:  If no graphical macro is available in the macro directory for the part, you must first store a graphical macro in the macro directory. |
6. Carry out a check run (any check run scheme set) to delete the module-specific message from the dialog of the message management.
7. Route the hose line again.

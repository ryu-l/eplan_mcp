# P001011: Terminal strip without terminals

### Cause

You created a terminal strip definition without a terminal in the terminal strip Navigator or placed it in the schematic.

### Solution

#### Possibility 1

1. Create at least one terminal in the terminal strip navigator using the New popup menu item.   
   Or place at least one terminal in the schematic using the Symbols object type of the Insert center.
2. Assign the DT terminal strip definition to the terminal and give it a designation.

#### Possibility 2

1. Select the terminal strip definition in the terminal strip navigator.
2. Select the Generate terminal popup menu item.
3. In the property dialog of the terminals enter the DT of the terminal and the connection point designation.
4. Click [OK].

---

  

If required, start a new check run.

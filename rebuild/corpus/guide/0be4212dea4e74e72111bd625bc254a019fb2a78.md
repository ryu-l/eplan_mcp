# Tab BMEcat Data Field Assignment

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Master data > Command group Parts > Management. Button [Extras] > Import. You have selected the entry ECLASS version in the File type field. Click the [...] button next to the File type field and select the BMEcat data field assignment tab.

Here you can assign some fixed BMEcat fields for which an ECLASS property does not exist or that are normally saved separately in a BMEcat field to the part properties of the parts management. User-defined properties and free properties are not available for selection because no (multilingual) ECLASS property name exists. To allow the importing of such data a special treatment for some fixed BMEcat fields is available here.

Overview of the main dialog elements:

BMEcat field:

The contents of these fields are taken from the BMEcat file and cannot be changed.

Part property:

Click the [...] button in these fields and select the property that you want to assign to the BMEcat field in the Property selection dialog.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# Generating Project Reports

For "Generate project reports" the entire project is reported. In the process reports are generated from all the existing [Report templates](formgeneratorgui_k_auswertungsvorlagen.htm). All reports that have already been generated are also updated.

Preconditions:

- You have opened a project.
- You have already generated reports and / or created report templates.
- You have opened the page navigator.

1. Select the project in the Pages - <Project name> dialog.
2. Select the following commands: Tab Tools > Command group Reports > Generate project reports.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If a report template is not found, a message is displayed informing you of this and enabling the report to be deleted.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Reports are generated from all the existing report templates. All existing reports are updated. The reports are displayed in the Reports tab and the page navigator.

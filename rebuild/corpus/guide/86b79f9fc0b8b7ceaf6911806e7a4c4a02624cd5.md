# Dialog Page selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have generated a planning object in the pre-planning navigator, or inserted one in the graphical editor. You have selected the Documents / Pages tab in the Properties <...> dialog. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) above the Pages table.
- You have highlighted a planning object in the pre-planning navigator or in the graphical editor. Popup menu item Properties. You have selected the Documents / Pages tab. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) above the Pages table.

You select the pages that are assigned to a planning object in this dialog.

Overview of the main dialog elements:

Tree tab:

In the tree view, the pages are displayed hierarchically nested by page type and structure identifier (if used).

List tab:

In the list view, all of the pages are displayed vertically in a customizable table format. The displayed properties and the sorting of the pages depend on the column configuration selected in the Configure representation dialog.

Multiple selection of pages is possible in the tree and list views.

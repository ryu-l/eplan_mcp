# Automatically Processing Multiple Projects

It is possible to use project management to automate actions for multiple projects.

Preconditions:

- You have imported directories and projects into the Project management dialog.
- You have created a scheme that contains a sequence of automatable actions.

1. Select the following commands: File > Project management.
2. To select several projects, hold down the [Ctrl] key and select the desired projects in the project management tree.
3. Select the Automated processing popup menu item.
4. In the Run: Automated processing dialog in the Scheme field, select the scheme with the automatable actions.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The sequence of actions stored in the scheme is displayed in the Actions list.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The projects are automatically processed, one after the other.

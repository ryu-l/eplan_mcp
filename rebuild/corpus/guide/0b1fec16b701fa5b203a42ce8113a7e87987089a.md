# Tab Class structure assignment

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Master data > Command group Parts > Management. Button [Extras] > Import. You have selected the entry ECLASS version in the File type field. Click the [...] button next to the File type field and select the Class structure assignment tab.

The ECLASS segments can be assigned to the product groups of the Eplan parts management in this tab.

Overview of the main dialog elements:

ECLASS segment / ECLASS main group / ECLASS group / ECLASS subgroup:

In these fields you specify the part properties to which the hierarchical BMEcat class levels are to be assigned by clicking [...] and selecting the respective property in the Property selection dialog. ("Attributes [1]" to "Attributes [4]" are preassigned.)

Toolbar:

| Button | Meaning |
| --- | --- |
| (New) | Opens the Application class selection dialog. Allows any application classes to be selected for the assignment to Eplan properties for the ECLASS segments 19 ("Information, communication and media technology"), 23 ("Machine element, fixing, mounting"), 27 (" Electric engineering, automation, process control engineering ") and 37 ("Industrial piping"). |
| (Import) | Opens a file selection dialog and allows a file in xml format to be selected so that the classes in the scheme can be supplemented by ECLASS data. |
| (Delete) | Allows one or more classes to be deleted from the scheme. All the characteristics that belong to this class are also deleted. |

Table:

The table located in the lower area contains the following columns:

- Class ID: Contains the 8-character ECLASS ID of the class.
- Class name: Contains the name of the class in the (default) language of the xml file. The language of the xml file is specified in the header of this file. If ECLASS does not exist in this language, the source language is used.
- Generic product group: Drop-down list for the selection of the generic product group of the Eplan parts management. The default is "Electrical engineering".
- Product group: Drop-down list for the selection of the product group of the Eplan parts management. The default is "General".
- Product subgroup: Drop-down list for the selection of the product subgroup of the Eplan parts management. The default is "undefined".

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# The Eplan Message Management

While editing a project, there can be (intentional or unintentional) inconsistencies, electrical or logical errors. This sort of project error can result in incorrect or incomplete reports. Eplan offers you the option of performing logic checks on the schematic pages, which support you when creating electrical drawings. The problems discovered in the checks are displayed in message management. The checks help you work with the program quickly, surely, and effectively in all areas of schematic creation.

Message management offers you the following options:

- All messages generated during check runs are displayed in an easily understood form in the Message management - <Project name> dialog.
- You can determine which criteria should be selected and how the corresponding messages are categorized.
- You can allow every project step to be automatically checked (Online checking). Or you define a Check run according to particular criteria and start it at any desired time (Offline check run).
- Check runs can be carried out at an online check for the entire project, for any components of the project structure or for any pages.
- Project data that were generated or modified by actions of specific modules, for example during the automatic cable selection, are also checked. These are so-called module-specific checks.
- You can specify for Eplan that certain checks are not to be carried out by selecting the type of check "No".
- An intelligent jump function makes it possible to navigate to the "location" in the project where the message was generated.
- You can carry out special check runs for part master data in the parts management. The associated messages are displayed in the parts management.
- Extensive descriptions and correction suggestions are available in the help system for all check run messages.

# Editing Legend Items

The 3D mounting layout also has the option of editing legend items and changing numbering.

Preconditions:

- You have opened a project.
- You have opened the layout space navigator and a layout space.

1. In the layout space navigator, select a layout space with legend items to be edited.
2. Select the Edit legend item popup menu item.
3. In the Edit legend item dialog, change the entries in the Legend item column manually, or use [Number] to open the Number dialog. There you can change the numbering settings and renumber the legend items.
4. Confirm your entries.

# Editing Connection Points

Precondition:

You have opened a project.

1. Select the following commands: Tab Master data > Command group Symbols > Drop-down button Symbol > Open.
2. If not open yet, select the desired symbol library in which the symbol with the connection points to be edited is located in the subsequent dialog.
3. Select the symbol in the Symbol selection dialog. Use the filter functionality or direct entry to move to the symbol quicker.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol to is opened in the symbol editor.
5. Double-click each of the connecting points.
6. In the Connecting point dialog define the properties of the connecting point such as Connection point number, Connection point designation and / or Connection point description.
7. Click [OK].
8. Select the following commands: Tab Master data > Command group Symbols > Drop-down button Connecting points > Number.
9. In the Sequence group box in the Number connecting points dialog specify whether the connecting points should be numbered according to the "from top to bottom and left to right" (option Horizontal / vertical) method or the "from left to right and top to bottom" (option Vertical / horizontal) method.
10. Click [OK].
11. Close the symbol editor.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The symbol is checked and the data is updated.

![](../Pictures/Gui/ALL/warning.png)Warning:

Multiple symbol connection points can't be located on top of another.

Connection point data will be applied according to your settings for the symbol. The graphic for the connection point will indicate the connection point direction explicitly, but later on it is not an integral element of the symbol.

![](../Pictures/Gui/ALL/note.png)Notes:

- After closing the symbol editor the connection numbers are automatically renumbered in sequential ascending order beginning with "1". Possibly assigned connection numbers which are higher than the number of placed connecting points are overwritten in the process.
- With the Properties as numbers command you can switch the display of the property texts (device tags, function text, etc.) to make the display clearer (command path: Tab Edit > Command group Symbol > Properties as numbers). If you print the current page with this setting or export it as a PDF, the numbers, not the property texts, are output in the print-out / PDF export file.
- To display and toggle the property sets Connection point designation / Connection point description use the following commands: Tab View > Command group General > Drop-down button Connection point designations > Non-rotated or Rotated.

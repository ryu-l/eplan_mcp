# Tab Block definition

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > User > Interfaces > DXF / DWG export and import. Select the Block definition tab.
- File > Export > Command group Project data > Project data > Command group Page > DXF / DWG. Click [...] next to the Scheme field. Select the Block definition tab.

In this tab you define which block are to be taken into consideration for the export.

Overview of the main dialog elements:

Group box Dynamic reports

For exports to DXF / DWG format the dynamic and conditional areas of the forms are combined into blocks and transferred. Specify the prefixes of the designations for each area here, for example "HEADER" for the header area.

---

Group box Block properties

In this group box you can specify the following settings:

- Export invisible attributes: Select this check box if all AutoCAD-specific attributes for an item should be exported, including the invisible ones.
- Generate one block per symbol: Select this check box if an AutoCAD block should be generated for every placed Eplan symbol. If the check box is deselected, no blocks will be generated and the pages will be exported as pure graphics.
- Generate a block for plot frames: Select this check box if AutoCAD blocks should be generated for all Eplan plot frames. If the check box is deselected, no blocks will be generated and the plot frames will be exported as pure graphics.
- Generate a block for standard forms: Activate this check box if AutoCAD blocks should be generated for all Eplan standard forms. If the check box is deselected, no blocks will be generated and the forms will be exported as pure graphics.

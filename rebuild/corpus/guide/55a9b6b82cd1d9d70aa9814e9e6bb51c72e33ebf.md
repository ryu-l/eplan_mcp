# Symbol Editor: Functionality

The symbol editor is a robust tool that simplifies the process of working with symbol libraries and symbols. As soon as you have opened a project, you can open the symbol editor via the following commands and edit the data: Tab Master data > Command group Symbols > Symbol library or Symbol.

It has to be taken into account that symbols and symbol libraries are part of the master data whose editing is controlled via the rights management (File > Extras > Command group Extensions > Rights management).

![](../Pictures/Gui/ALL/note.png)Note:

The reason a project must be opened before you can work with symbols is that several symbol and symbol library properties come from project settings.

# P001037: Main terminals existing several times

### Cause

#### Possibility 1

You use one and the same main terminal several times in different representation types of your schematic. For example the main terminal in the schematic exists in the representation type "Multi-line" and in the representation type "Overview".

#### Possibility 2

Or you have activated the main terminal setting at several distributed terminals of a terminal displayed as distributed.

### Solution

#### Regarding option 1

1. Locate the relevant main terminal in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Launch the property dialog of the main terminal.
3. Change the main terminal into an auxiliary terminal by deactivating the Main terminal check box on the first tab or rename the main terminal.
4. Click [OK].

#### Regarding option 2

1. Locate the relevant distributed terminal that is also a main terminal in the schematic by using the Go to (graphic) functionality from the popup menu in the Message management dialog. Or select the Synchronize selection functionality from the popup menu if the distributed terminal was created in the terminal or device navigator and is not placed yet.
2. Launch the property dialog of the distributed terminal.
3. Deactivate the Main terminal check box on the first tab.
4. Click [OK].
5. Repeat this procedure for all but one distributed terminal that is to be the main terminal. At this terminal the check boxes Main terminal and Distributed terminal must be activated.

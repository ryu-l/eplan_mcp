# Replacing Plot Frames, Forms, and Function Definition Libraries (Changing Standards)

To adjust a project to a different standard you can replace existing plot frames and forms with different ones.

Preconditions:

- You have opened a project.
- In the case of several opened projects: You have selected a project in the page navigator.
- You have set up a target project.
- You have defined a basic project and the rotation / flipping.

1. Select the following commands: Tab Tools > Command group Standards > Exchange > Tab Project > Button [Next] > Tab Rotation / flipping > Button [Next].
2. In the Master data tab in the Name column, select a form, a plot frame, or a function definition library to be replaced.
3. Within the same row, click [...] in the New name column.
4. In the following dialog select the form, the plot frame, or the function definition library to be used for the target project and click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected file is entered in the New name column.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Next, you can [replace symbol libraries and symbols](changestandardsgui_h_symboletauschen.htm).

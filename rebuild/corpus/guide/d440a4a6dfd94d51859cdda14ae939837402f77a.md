# Dynamically Placing Graphics

To create header, data areas, and footers within a page, there is the concept of dynamic forms. Since the positions of these areas are dynamic and they should normally stand out in the table graphic, each line generated in a report is able to draw a border in a dynamic form.

Header areas are normally only used for forms from which function related reports such as terminal diagrams are generated. The header area is irrelevant for overviews, such as parts lists, for example.

![](../Pictures/Gui/ALL/note.png)Note:

Dynamic forms can be identified by the "Dynamic" entry in the drop-down list for the Form handling form property.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

A device tag list should be created with the following dynamic areas:  
Device tag list (page header)  
DT / Quantity / Designation  
Manufacturer: H1 (group header)  
K1 / 10 / Designation 1  
K2 / 5 / Designation 2  
Kn / 99 / Designation n  
Manufacturer: H2 (group header)  
K1 / 10 / Designation 1  
K2 / 5 / Designation 2  
Kn / 99 / Designation n

This information is drawn in the form editor as graphical row frames and written with each generated row in a report page. In addition, it is also possible to define graphic or text objects as header, data, or footer elements, i.e. not only placeholder texts.

Preconditions:

- You have opened a project.
- You have opened the dynamic form you want to edit in the form editor (Tab Master data > Command group Plot frames / forms > Drop-down button Form > Open > Button [Open]).

1. Select the following commands: Tab Insert > Command group Text > Drop-down button Forms.
2. Here select the type of Dynamic area you want to define by using the commands Header, Data header area (for the data area), Data area, Data footer area, or Footer.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The rectangle representing the area hangs on the cursor.
3. Click with the mouse to place the starting point of the rectangle to be drawn.
4. Click to specify the end position of the rectangle.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The rectangle representing the particular area is drawn; in addition, information about which type of area it is (header/data area or footer, data footer or data header area) is displayed on the upper left.
5. Select the newly defined rectangle.
6. Select the following commands: Tab Insert > Command group Text > Drop-down button Forms > Placeholder text.
7. Click [...] in the Property field of the Placement tab on the Properties (placeholder text) dialog.
8. Select the property that you want to define as a placeholder for the respective area in the Placeholder texts - <Form type> dialog.
9. Click [OK].
10. Confirm your entries.

![](../Pictures/Gui/ALL/info.png)Tip:

As an alternative you can also edit placeholder texts that were assigned to an area by double-clicking on the graphics of the dynamic area. The subsequently opened dialog Dynamic area lists all placeholder texts in a clearly structured table in the [Placeholder texts](formeditorgui_r_platzhaltertexte.htm) tab.

The Form orientation property specifies the sequence in which the various defined ranges are composed. If the form orientation is by row, the defined ranges are composed from "bottom left" to "top left":

![](../Pictures/Visualisation/ALL/formgeneratorgui_grafikendynamischplatzieren1_AV.png)

If the form orientation is by column, the defined ranges are combined from "lower right" to "lower left":

![](../Pictures/Visualisation/ALL/formgeneratorgui_grafikendynamischplatzieren2_AV.png)

(In both illustrations:  
1 = Header  
2 = Data area  
3 = Footer)

![](../Pictures/Gui/ALL/note.png)Notes:

- If several of the same defined ranges (e.g. several data areas) are placed, only one is taken into consideration for the reports.
- Additional marking commands are available as an optical checking function for dynamic forms (Tab Edit > Command group Form > Mark) that each display all elements of the header, footer, data area, data footer or data header area. In general, it is a normal selection, i.e., all marked elements can be deleted, copied, moved, etc.
- Like all other forms, dynamic forms can also be automatically checked during editing (Tab Edit > Command group Form > Drop-down button Other > Check form), for example for the correct usage of the defined ranges.

### Assigning an area to externally located placeholder text

In dynamic forms it is also possible to assign the areas for placeholder text lying outside the area.

Preconditions:

- You have opened a project.
- You have opened the dynamic form you want to edit in the form editor (Tab Master data > Command group Plot frames / forms > Drop-down button Form > Open > Button [Open]).
- You have specified an area (Tab Insert > Command group Text > Drop-down button Forms.> "Dynamic area") and inserted placeholder texts.

1. Select the placeholder text that should belong to the area.
2. Click the desired area and select the popup menu item Assign objects to area.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The objects are assigned to the area. You can check the assignment by selecting the Select associated objects popup menu item for the respective area.

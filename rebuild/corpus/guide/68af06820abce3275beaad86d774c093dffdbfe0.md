# Creating a Project (Project Management)

You can create projects via the project management, or you can create them directly. In the process the project is created based on a basic project. As an alternative to basic projects (\*.zw9) you can also select backed up Eplan projects (\*.zw1) as project templates when creating projects. If you have not yet created any basic projects, you can use the Eplan [Sample templates](projects_k_basisprojekteerweitert.htm#Beispielvorlagen). The following section describes how you create a project via the project management.

Preconditions:

- You have access to [Basic Projects](projects_k_basisprojekteerweitert.htm).
- You have created a project management database.

1. Select the following commands: File > Project management > Button [Organize] > New.
2. Enter the project name and the storage location in the dialog [Create project](prjmanagementgui_d_projekterstellen.htm).
3. Select the desired basic project or the desired backed-up Eplan project for the project.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new project \*.elk is created in the target directory.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new project is automatically imported into the project management.
5. Check all the entries in the dialog Project properties: <Project name> and customize them if necessary.

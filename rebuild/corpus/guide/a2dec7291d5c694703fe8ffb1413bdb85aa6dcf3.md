# Selecting Fluid DTs (ISO 1219-2)

In the case of a Fluid device already placed you have the possibility of selecting the next free device tag program-supported. In the case of fluid devices identified to ISO 1219-2 you can define during the selection whether the next free circuit number or the item number is to be determined.

Preconditions

- You have opened a project.
- The project was created by using the FL\_1219-2\_bas001.zw9 basic project. This basic project has the effect that fluid device tags are structured to ISO 1219-2 with a trade-specific Media code, a Circuit number and an Item number.
- You have created a page of the type "Fluid power schematic" and have opened the page in the graphical editor.
- At least one fluid device is placed on the schematic page.

### Display identifier structure for DT selection

1. Select the following commands: File > Settings > Projects > "Project name" > Display > Tree structure (navigators).
2. Activate the check boxes DT: Prefix, DT: Identifier, DT: Counter and DT: Subcounter in the dialog Settings: Project structure (navigators).   
     
   ![](../Pictures/Gui/ALL/arrow.png) This setting causes the individual structure components of the DTs of placed Fluid functions to be displayed separately in the tree view of the DT selection dialog, each with its own icon.
3. Click [OK].

### Select the circuit number with program support

1. Double-click a Fluid device in the schematic.
2. Click [...] next to the Displayed DT field in the properties dialog.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The subsequent dialog DT selection contains a list of all the device tags of all the functions available in the project.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The DT of the selected Fluid function is already marked in the list.
3. To have the individual identifier elements of the DT of the selected Fluid function displayed by means of icons select the tab Tree.
4. In the opened tree view click on the value behind the icon ![](../Pictures/Gui/ALL/all_countericon_projectstructure.png).
5. Click [Next].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The DT selection is closed. Eplan Fluid enters the next available circuit number into the Displayed DT field of the Properties <...> dialog.
6. Click [OK].

### Select the item number with program support

1. Repeat Steps 1 to 3 described in the previous section.
2. In the tree view click the desired value behind the icon ![](../Pictures/Gui/ALL/navigatorgui_subcounter_as.png).
3. Click [Next].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The DT selection is closed. Eplan enters the next available item number into the Displayed DT field of the Properties <...> dialog.
4. Click [OK].

The following 3 fluid devices are located in a project:  
H1.1, H3.7 and H4.5

In the first case the next free circuit number is assigned to the DT H3.7.  
The new DT is then H5.7.

In the second case the next free item number is assigned to the DT H3.7.  
The new DT is then H3.8.

# Dialog Settings: Cable (automatic)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Settings > Projects > "Project name" > Devices > Cable (automatic).

In this dialog you specify defaults to be used for automatically generated cables.

Overview of the main dialog elements:

Cable generation:

The scheme selected here specifies where the cable properties are positioned and which cable connections should be included when generating cables. Use [...] to open the [Settings: Cable generation](cablegui_d_einstellungenkabelerzeugen.htm) dialog where you manage and edit the schemes.

Cable numbering:

The scheme selected here specifies in which sequence cables are numbered, which properties are to be displayed in the cable DT and how they and formatted. Use [...] to open the [Settings: Cable numbering](cablegui_d_einstellungenkabelnummerierung.htm) dialog where you manage and edit the schemes.

Automatic cable selection:

The scheme selected here specifies the criteria for automatic cable selection. Use [...] to open the [Settings: Automatic cable selection](cablegui_d_einstellungenautomatischekabelauswahl.htm) dialog where you manage and edit the schemes.

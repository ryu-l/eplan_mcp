# Specifying Settings for Displaying the Connection Symbols

The general project-specific settings for graphical editing include various areas that influence the work in the graphical editor.

Precondition:

You have opened a project.

1. Select the following commands: File > Settings > Projects > "Project name" > Graphical editing > General.
2. In the Display connection junctions as group box specify how connection symbols are to be displayed in the graphical editor.
3. Specify other general settings by selecting / deselecting the check boxes.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection symbols are displayed accordingly.

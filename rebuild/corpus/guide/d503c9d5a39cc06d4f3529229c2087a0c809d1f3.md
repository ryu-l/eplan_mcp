# Dialog "Configure properties" / Dialog "Configure representation"

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call dialog Configure properties:](javascript:void(0);)

You have opened a project.

- You have selected one or more objects (texts, components, segments, graphical elements) in the graphical editor, in the layout space or in a navigator. Tab Home > Command group Edit > Property overview. In the property overview click next to the drop-down list on [...].

You have opened parts management. You have opened a parts database using [Extras] > Settings.

- You have marked a part in the tree or list. You have selected the Overview tab. In the View field click next to the drop-down list on [...].
- You have marked a part in the tree or list. You have selected the Properties tab. Next to the drop-down list, click [...].

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call for dialog Configure representation:](javascript:void(0);)

You have opened a project. You have opened a project page in the graphical editor. You are in the information section of the dialog Insert center. Select the Configure representation popup menu item.

In this dialog you manage and edit the schemes for property configuration. As a rule, several configurations are stored in such a scheme. The assignment to a desired object (part, function, etc.) and the definition of filters make it possible to always display the suitable properties for a selected object.

Such property configurations are used for the display in the tabs Overview and Properties of the parts management, for the display in the property overview and for the column configuration in the information area of the Insert center. Different schemes are used for each of these applications.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Configurations:

This table contains the property configurations of the selected scheme. The assigned object, the name and - if existing - the filter defined for the property configuration are displayed.

To add a new configuration, click the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button. To edit a configuration, select the corresponding line in the list and click the ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit) button. You can then, for example, add or remove properties from the respective configuration in the [subsequent dialog](modaldialogsdb_d_eigenschaftskonfigurationhauptknoten.htm).

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# P026033: Bundle distributed in several bundle groups

### Cause

A connection has been assigned to a bundle which has already been assigned to another bundle group.

### Solution

1. Locate the connection in the layout space by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Double-click the displayed connection to open the Properties dialog.
3. Assign the connection to the correct bundle and the correct bundle group by entering valid designations in the Bundle and Bundle group fields of the Properties group box. When assigning the designations make sure that the same bundle group may be contained in different bundles, but the same bundle may not be part of several bundle groups.
4. If necessary repeat the bundle and bundle group designation for further connections.
5. If required, start a new check run.

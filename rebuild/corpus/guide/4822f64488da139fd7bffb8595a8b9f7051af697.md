# Realigning and Formatting Connection Designations

Use the Align and format command to reset the original positions of any connection definition points that were already set but were later moved / reformatted. In doing so, the original formatting specified in the settings will be restored for the selected connection definition points.

Precondition:

You have selected a connection in the graphical editor, or in the Connections - <Project name> navigator dialog. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog.

1. Select the following commands: Tab Connections > Command group Connections > Align and format.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Once you have called up the command, the connections are first automatically generated new.
2. In the Settings field of the Align and Format Connection Designations dialog select a scheme from the drop-down list that will specify the settings for connection numbering. Use [...] to open the Settings: Connection numbering dialog. Define the numbering settings here and store them in a scheme.
3. In the Connection definition points group box specify which connection definition points should be realigned and formatted.
4. Activate the Retain "manually set" numberings check box to retain the alignment and formatting for connection definition points with the Manually set property.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection definition points are realigned and formatted.

# P502038: The value of the part property '<x>' does not lie within the value range that is defined in the Eplan Data Standard

### Cause

In the parts database to be checked, a cable duct or mounting rail part was determined at which a value that does not conform to the Eplan Data Standard is stored for the property Height, Width or Depth (displayed in the placeholder '<x>'). For example an impermissible negative value was imported into the parts database for one of these part properties through a parts data import from Eplan Data Portal.

### Solution

1. Check the web page of the Eplan Support for information about the [Eplan Data Standard](https://www.eplan.com/en/support/data-standard.html) and which value range is permissible for the reported part property.
2. Adapt the value of the part property in the parts management correspondingly, so that it lies within the permissible value range.
3. If required, start a new check run.

# Bills of materials

The bill of materials is not a part of the parts management in Eplan, but rather belongs to the project-specific data.

When opening the bill of materials navigator, the current data from the current project is always read in. In the list / tree view, all of the device tags with parts, device tags without parts, parts in part definition points, and project parts are displayed.

Using this navigator, you can edit the parts data of a project centrally in one place in the system. The following is possible:

- The tree view is parts-oriented, i.e., only the device tags that already have a part are shown.
- The list view is device-oriented and can display different information for the individual DTs. The displayed information can be configured via the Configure representation popup menu item.
- In both representations you can use the Settings popup menu item to define which (further) parts should be taken into account in the display.
- In this navigator dialog, you can manually enter or change a part number. It is also possible to change the quantity and perform a parts selection.
- Moreover, device selection is possible within the bill of materials navigator.

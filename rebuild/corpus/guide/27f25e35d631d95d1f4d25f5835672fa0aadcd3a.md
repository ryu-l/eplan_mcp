# Defining the Translation and Display Languages

Translation and display languages allow you define the languages into which the project is to be translated, and also the languages that are visible.

Precondition:

You have opened a project.

### Specify translation languages

The translation languages determine the languages in which the text is translated. All translated texts are stored in the project and can be removed from the project via the following commands: Tab Tools > Command group Translation > Remove translation.

1. Select the following commands: File > Settings > Projects > "Project name" > Translation > General.
2. In the Translation group box next to the Languages field click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
3. From the drop-down list select all of the languages into which the project should be translated.

### Specify source language

The source language is the language in which you enter your project texts. You also use the source language to specify the language in which translatable project texts are displayed in dialogs.

1. Select an entry from the Source language drop-down list.

### Select and position the display languages

The display languages, determine which of the translation languages will be displayed in the project pages. The display language position allows you to define the sequence in which the display languages are shown in the translated project.

1. In the Display group box next to the Languages field click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
2. From the drop-down list select all of the languages in which the project pages should be displayed.

# Tab Settings

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. File > Export > Command group Manufacturing data > Manufacturing data > Labeling. Click [...] next to the Settings field in the dialog Export manufacturing data / output labeling. In the dialog Settings: Manufacturing data export / labeling select the Settings tab.
- File > Settings > User > Interfaces > Manufacturing data export / Labeling. In the dialog Settings: Manufacturing data export / labeling select the Settings tab.

In this tab you define the project or parts data to be output with the export / labeling data.

Overview of the main dialog elements:

Part assemblies:

The settings in this group box only affect the parts list and summarized parts list:

- Break up assemblies: Activate this check box if assemblies are to be broken up into their components, meaning their individual parts.  
  In addition activate the subsequent Include supplemental parts (assemblies) check box if the supplemental parts are to be taken into consideration when breaking up the assemblies. This means that the supplemental parts contained in an assembly are also output when manufacturing / labeling data are exported.
- Break up modules: Activate this check box if modules are to be broken up into their components, meaning their individual parts.  
  In addition activate the subsequent Include supplemental parts (modules) check box if the supplemental parts are to be taken into consideration when breaking up the modules. This means that the supplemental parts contained in a module are also output when manufacturing / labeling data are exported.
- Up to level: In this field enter the hierarchical level to which assemblies / modules are to be broken up. Values can only be entered if the Break up assemblies and / or Break up modules check box has been selected.
- Combine parts of a device: Select this check box for a scheme of the "Parts list" report type if the parts at terminals are to be combined into terminal strips and the parts at cable connections are to be combined into cables in the parts list. If this check box is not selected then the parts are listed individually.

  ![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

  If the check box is selected, the parts list contains one item with 25 UK5 terminals and one item with 10 conductor sleeves; if the check box is not selected, the terminal UK5 is listed 25 times and the conductor sleeves are listed 5 times (conductor sleeves belong in pairs).

![](../Pictures/Gui/ALL/note.png)Note:

In the parts management you can specify individually for individual assemblies or modules whether these are to be broken up in the summarized parts list and / or in the parts list or not ("Yes" or "No"). This individual setting takes priority over the setting defined here in the settings dialog. For general information on breaking up modules and assemblies, please refer to the section "[Breaking up Modules and Assemblies](articlesgui_k_module.htm#ModuleAufloesen)".

Setting / Value:

Project and function related filter and sorting settings can be defined in this table: In the Value column, click [...], select the desired project if necessary, and then define the appropriate criteria in the Filter or Sorting dialog.

The Value field for the "Action" setting displays the customer-specific extension currently assigned to the label by an action; click [...] to open the Enter name of the action dialog and, if necessary, replace the action with a different one.

Include parts:

Activate the check boxes at the parts whose data are to be output as well at the output for the "Parts list", "Summarized parts list" and "Manufacturer / Supplier list".

![](../Pictures/Gui/ALL/note.png)Notes:

- The settings Devices without part number, Terminal strip parts, Terminal parts, Cable parts, Plug parts, Pin parts, Busbar parts, Busbar connection point parts also apply for the Device tag list report.
- The Pre-planning part setting evaluates parts which have been entered solely at planning objects in pre-planning. If there already is a main function or a part placement for a planning object, this setting is not evaluated in the parts reports.

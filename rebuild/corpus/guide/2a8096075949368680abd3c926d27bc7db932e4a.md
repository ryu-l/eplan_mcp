# Displaying External Targets

The External targets button in the View tab option makes it easier to find external targets: If this button is activated, the external connection points of functions are marked with an arrow. This makes (e.g.) target tracking for terminals easier. This allows you recognize the page of a terminal diagram where a target is output.

You set the Internal / External property in the [Connection point logic](xfctdefbrowsergui_d_anschlusslogik.htm) dialog, which you call up from the Symbol / function data tab of the property dialog, via [Logic].

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Activate the button External targets in the View tab in the command group General.  
     
   ![](../Pictures/Gui/ALL/arrow.png) External connection points of functions are marked with a small arrow.
2. Deactivate the External targets button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The arrows marking external connection points are hidden once more.

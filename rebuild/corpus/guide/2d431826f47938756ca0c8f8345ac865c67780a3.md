# Sending an E-mail if a Conflict Occurs

Preconditions:

- To send e-mails, an e-mail program has to be installed on your computer and be entered as the default e-mail app in the Windows settings.
- For multi-user operation, you have opened a project in the "Default" processing mode. In addition, the users working in multi-user operation must have their user data stored in the settings (File > Settings > User > Display > User code / address).

In multi-user operation, the Multi-user conflict dialog will appear if a conflict arises. Use the dialog to send an e-mail to other users that are currently working on the same project data.

### Send an e-mail to another user

1. Select the line with the desired user in the Multi-user conflict dialog.
2. Select the Send e-mail message popup menu item.
3. If you haven't run your e-mail editor yet, you must first select a profile for the information service from a subsequent dialog. The e-mail editor will only start after you have done this.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The e-mail program installed on your computer is started. The e-mail address field is already automatically filled in and the subject line is filled in with "Multi-user conflict".
4. Enter your text and send the e-mail to the other user by clicking [Send].

### Send an e-mail to all of the users simultaneously

If multiple users are listed in the Multi-user conflict dialog, you can send an e-mail to all other users at the same time.

1. To perform this, select the entire E-mail column.
2. Select the Send e-mail message popup menu item.
3. If you haven't run your e-mail editor yet, you must first select a profile for the information service from a subsequent dialog. The e-mail editor will only start after you have done this.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The e-mail program installed on your computer is started. All selected e-mail addresses will already be in the address field and the subject field will be filled in with "Multi-user conflict".
4. Enter your text and send the mail by clicking [Send] to all of the other users.

# P033004: Function has an invalid cable unit name

### Cause

A function was found in the schematic to which a cable unit name has been assigned, but for which no cable unit definition with the same cable unit name exists. Possibly the function was copied from the schematic of a different project and inserted into the project currently opened, or cable unit names of cable unit definitions were renamed subsequently.

### Solution

If the function is not assigned to a cable unit definition, delete the cable unit name at the function. Or assign an existing cable unit name that is stored at a cable unit definition to the function.

1. Locate the function in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Open the property dialog of the function.
3. Delete the value of the Cable unit name property in the properties table of the first tab. Or use the [...] button in the value field of the property to select an existing cable unit name of a cable unit definition.
4. Click [OK].
5. If required, start a new check run.

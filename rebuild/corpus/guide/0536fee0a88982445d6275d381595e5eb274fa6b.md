# Assigning the PCT Type of a PCT Loop / PCT Loop Function

You use the PCT type to define which symbol is placed in the P&I diagram for the PCT loop / PCT loop function.

Preconditions:

- You have opened a project containing pre-planning data.
- You have created a PCT loop / PCT loop function.

1. Select the following commands: Tab Pre-planning > Command group General > Navigator.
2. Select a PCT loop / PCT loop function.
3. Select the Properties popup menu item.
4. Select the <PCT loop> / <PCT loop function> tab in the property dialog.
5. In the Properties table, select the desired option from the drop-down list for the PCT type property.  
     
   ![](../Pictures/Gui/ALL/arrow.png) When you place the PCT loop / PCT loop function, a suitable symbol from the symbol library is automatically assigned.

![](../Pictures/Gui/ALL/note.png)Note:

For a placed PCT loop / PCT loop function, the PCT type property cannot be changed any more in the drop-down list. You can, however, change the Implementation and Activation site options in the Symbol data tab and thus change the P&I symbol and the PCT type.

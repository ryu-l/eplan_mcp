# Base Points: Principle

Base points are components of the device logic that are used in working with enclosure accessories. Base points are fixed defined mounting points in a layout space. You can use base points to install enclosure items (e.g., side panels, base) at a fixed defined location in the accessories management. These items cannot be moved subsequently anymore.

A distinction is made between automatically generated base points and user-defined base points. You can use automatic base points to place enclosures and matching accessories from accessories management, without having to generate detailed macros for this purpose. But there is also the option to store user-defined base points in a macro and to use them in accessories management as the property of an accessory placement.

### Automatic base points

Automatic base points are generated for all enclosures that are generated directly without macro from the parts database (product group "Enclosure", product subgroups "Component" and "Body"). The automatic base points are used only for the automatic placement of the accessories and are not calculated in the event of a manual placement.

Automatic base points are generated at the following part placements:

Frame profile horizontal floor

- Frame profile down: Left front
- Frame profile down: Left rear
- Frame profile down: Right front
- Frame profile down: Right rear.

Frame profile horizontal cover

- Frame profile up: Left front
- Frame profile up: Left rear
- Frame profile up: Right front
- Frame profile up: Right rear.

Housings

- Housing exterior: Up left front
- Housing exterior: Up left rear
- Housing exterior: Up right front
- Housing exterior: Up right rear
- Housing exterior: Down left front
- Housing exterior: Down left rear
- Housing exterior: Down right front
- Housing exterior: Down right rear
- Housing interior: Up left front
- Housing interior: Up left rear
- Housing interior: Up right front
- Housing interior: Up right rear
- Housing interior: Down left front
- Housing interior: Down left rear
- Housing interior: Down right front
- Housing interior: Down right rear.

### User-defined base points

User-defined base points are mounting points with predefined properties that are manually placed in a macro by the user. They can be inserted with the command Base point (command path: Tab Insert > Command group Mounting aids > Base point).

Similar to the definition of mounting points, a point is selected in the layout space at which the base point is to be defined. Placement options can be used for this. In the subsequent property dialog, all base points are shown as available that are also generated as automatic base points.

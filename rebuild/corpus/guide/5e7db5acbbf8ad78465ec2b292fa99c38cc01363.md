# Tab Rotation / flipping (Changing Standards)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. In the case of several opened projects: You have selected a project in the page navigator. Tab Tools > Command group Standards > Exchange. You have specified all of the settings in the Project tab. Button [Next].

Overview of the main dialog elements:

Basic project:

This field contains the basic project to be used as the template for the target project. Use ![](../Pictures/Gui/ALL/all_selectfile_as.png) to select a basic project \*.zw9 or a backed up Eplan project \*.zw1.

If you have activated the Apply project properties from the source project check box on the Project tab, the project properties are not taken from the basic project but rather from the source project.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

Rotation / flipping:

Select the manner of rotation and flipping from this drop-down list.

- 0°: The schematic elements are not rotated.
- 90°: Rotates graphical elements like lines, texts, hyperlinks counter-clockwise by 90°. Sets the insertion point of symbols counter-clockwise by 90°. You can specify the rotation / flipping of symbols using the variants selected in the Symbols tab in the assignment diagram. For special symbols, a suitable symbol library is automatically preset in the Master data tab. The Individual assignment check box is automatically selected. In the Symbols tab, the Special IEC NFPA IEC scheme is automatically available. Use this setting to switch from IEC standard to NFPA standard.
- 270°: Rotates graphical elements like lines, texts, hyperlinks counter-clockwise by 270° or clockwise by 90°. Moves the insertion point of symbols counter-clockwise 270° or clockwise 90°. You can specify the rotation / flipping of symbols using the variants selected in the Symbols tab in the assignment diagram. For special symbols, a suitable symbol library is automatically preset in the Master data tab. The Individual assignment check box is automatically selected. In the Symbols tab, the Special IEC NFPA IEC scheme is automatically available. Use this setting to switch from NFPA standard to IEC standard.

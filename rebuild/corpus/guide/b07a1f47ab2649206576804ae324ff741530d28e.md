# P004112: Incorrect data type '<x>' or incorrect data length of the channel

### Cause

The data type of the symbolic address of the PLC connection point deviates from the data length of the channel.

### Solution

1. Please check the data in the PLC configuration program which was used to generate the AML file.
2. Import the PLC data again.

# P002008: Number of female pins and male pins in the plug do not match

### Cause

You created a plug connection with separate male and female pins in the Plug Navigator or placed it in the schematic. The plug has two plug definitions with the same DT, but different function definitions ("Plug definition for male pins" / "Plug definition for female pins"). There are more pins on the male pin side of the plug than on the female pin side or vice versa.

### Solution

1. Add the corresponding pins to the male or female end of the plug, so that there is a corresponding number of male and female pins on each side.
2. If required, start a new check run.

# Dialog Mounting point / Dialog Mounting line

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a layout space. The layout space contains 3D objects. A mounting point or a mounting line has been defined at a 3D object. Select the mounting point or the mounting line and then select the popup menu item Properties. Or double-click the mounting point or the mounting line.

In this dialog you set the properties of a mounting point / mounting line.

Overview of the main dialog elements:

Name:

Enter the name of the mounting point / mounting line here. Or alternatively click the [...] button to select the name and the description of a mounting point already assigned or a mounting line already assigned in the following dialog.

Description:

Enter a description text for the mounting point / mounting line here.

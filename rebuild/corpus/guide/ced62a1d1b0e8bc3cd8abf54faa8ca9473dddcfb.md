# Overview Reports

In contrast to [function-related reports](formgeneratorgui_k_funktionsbezogen.htm), report overviews provide an overview of several devices as standard, e.g., all terminal strips used in the project.

Report overviews may occur multiple times in the project.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You have generated two parts lists in the same project. In the first parts list, the item is output with the Manufacturer A filter setting. In the second parts list, the identical item is output with the Manufacturer B filter setting.

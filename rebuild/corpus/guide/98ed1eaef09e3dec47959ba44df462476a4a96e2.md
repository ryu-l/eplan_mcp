# Determining the Format and Range for Numbering

Precondition:

You have opened a project.

1. Select the following commands: File > Settings > Projects > "Project name" > Device > Number using PLC data.
2. Select a user-defined scheme from the drop-down list, or create a new scheme via ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the dialog Settings: Number using PLC data.
3. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) via the Format groups field in the Settings: Number using PLC data dialog.
4. Select the group of devices for which you want to determine the format from the Group drop-down list in the dialog Number using PLC data: Format. You can choose between terminals, pins, and devices.
5. In the Extent drop-down list, select the scope of numbering for the selected group.

   ![](../Pictures/Gui/ALL/note.png)Note:

   If you have selected the "Net" entry, then you can use the net extension to increase the area affected by the numbering scheme, as described in the section [Defining Net Extensions](offlinenumerationplcgui_h_netzerweiterung.htm).
6. Mark a format element in the Available format elements field and use ![](../Pictures/Gui/ALL/all_arrowright_as.png) to move it to the right into the list of selected format elements.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Different subsequent dialogs will appear, depending on the format element. Depending on the selected format element this can be one of the following dialogs: [Format: PLC data](offlinenumerationplcgui_d_formateigenschaften.htm), [Format: Identifier](offlinenumerationplcgui_d_formatkennbuchstabe.htm), [Format: Page / Column / Row](offlinenumerationplcgui_d_formatseite.htm) or [Format: Separator](offlinenumerationplcgui_d_formattrennzeichen.htm).
7. Define the formatting in the subsequent dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A preview of the numbering format is displayed in the Preview field. The individual formatting elements are displayed in the connection designations in the same sequence as they currently exist in the list.
8. If desired, you can change the sequence of the format elements using the arrow buttons.
9. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The values entered will be saved in the selected scheme.

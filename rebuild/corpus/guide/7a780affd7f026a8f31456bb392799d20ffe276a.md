# P020045: Hyperlink  <x> (x Pos <y> : y Pos <z>) : <u>

### Description

You have run a project comparison, checking the Properties of the test project (incoming project) against those of the comparison project and differences were found.

This message occurs when a difference concerning an inserted hyperlink was found by the project comparison. <x> displays the path of the document linked with the hyperlink, or of the internet address linked with the hyperlink. The hyperlinks in the schematic are output with <y> for the X position and with <z> for the Y position. <u> indicates whether the hyperlink has been deleted or added, or if one of its properties has been changed.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

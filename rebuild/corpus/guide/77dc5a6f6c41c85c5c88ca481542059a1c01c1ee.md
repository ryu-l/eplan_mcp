# Dialog Automatic filter: Device selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have selected a main function in the graphical editor or in a navigator. Popup menu item Properties. Select the Parts tab and click [Device selection]. Click [...] next to the Automatic filter field.
- Tab Devices > Command group Devices > Bill of materials. Select an entry. Popup menu item Device selection. Click [...] next to the Automatic filter field.

In this dialog, you determine the filter settings for device selection. The filter settings relate only to the main parts shown in the Parts list in the Device selection dialog, and not to the Accessories list. The accessories are oriented to the selected main part. The number of accessories matching each main part is normally relatively low, so that filtration is normally not required here.

Overview of the main dialog elements:

Property:

The properties suggested in the filter settings depend on the item type and are those properties that can also be displayed in the columns of the Main parts list in the Device selection dialog.

Value:

In this field, the values entered into the component as presets are displayed. Spaces at the beginning and end, such as line breaks, are removed for display, but are not actually discarded.

Enter a value (for an empty field) or overwrite the preset value; the corresponding part properties will then be synchronized from this value (as long as the Active check box is selected). You can use [placeholders](searchandreplacegui_k_platzhalter.htm) (such as "\*" or "?").

Apply:

Select this check box if you want to use the filter settings in the Main parts list in the Device selection dialog.

The filter settings are always filled with the properties of the current component when the dialog starts. For each item type, Eplan remembers if the Apply setting is selected or not. (So, for instance, if you have selected this setting for a coil, it is automatically activated for all of the other coils in device selection).

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

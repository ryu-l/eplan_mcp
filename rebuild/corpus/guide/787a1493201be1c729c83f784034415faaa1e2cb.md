# Distributing Elements Evenly

You can use the Space horizontally and Space vertically commands to assign several marked elements at equal distances from one another in the horizontal or vertical direction. This only works for elements with insertion points (texts, symbols, placed functions, etc.). Simple graphical elements such as rectangles and lines are not taken into account as expected.

Precondition:

You have opened an editor such as the graphical editor, the plot frame editor, etc.

1. Mark the respective elements.
2. Select the following commands: Tab Edit > Command group Arrange > Space horizontally or drop-down button Space horizontally > Space vertically.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan determines the distance between the first and last element and distributes all others evenly in between.

![](../Pictures/Gui/ALL/note.png)Note:

The grid is not taken into account when distributing elements; if necessary, use the Align on grid command to place the elements back onto the grid.

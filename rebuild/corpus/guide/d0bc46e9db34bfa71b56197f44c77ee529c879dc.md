# P028012: There is more than one graphical placement for the structure segment

### Cause

There is more than one graphical placement of a structure segment on one or several pre-planning pages of your project.

### Solution

1. Locate the structure segment placed graphically multiple times by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Delete the excess graphical placement.
3. Repeat the deletion process for any further excess placements.
4. If required, start a new check run.

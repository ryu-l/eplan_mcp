# Dialog Net extension (Connection Numbering)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the [Settings: Connection numbering](wirenumberinggui_d_verbnumeinstellungen.htm) dialog (for example by using File > Settings > Projects > "Project name" > Connections > Connection numbering). Select a user-defined scheme in the dialog Settings: Connection numbering and select the Designation tab. Click [Net extension].

In this dialog you extend the definition of the net. This setting affects the designation if the range is selected as "Net". The net extension for connection numbering is independent of the Net-connecting property of the function concerned.

Overview of the main dialog elements:

Selection:

All functions are displayed in a tree view. Use the arrow button to move a selected entry from the list on the left to the list on the right. It is also possible to select a category and move all of the functions within the category.

Net extended with following objects:

The list displays all of the functions that you have moved from the selection list. The net will then no longer end at the selected functions, but rather it will be extended by them.

![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) allows you to remove a selected function from the list.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Select all (list only) | Selects all of the entries in the list. |

# Aligning Elements Horizontally / Vertically

By means of the Align horizontally and Align vertically commands you can position several marked elements on a horizontal or vertical line. This only works with elements that have a single insertion point. The line is formed from the midpoint of the two elements with the greatest distance between them.

Precondition:

You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc.

1. Mark the respective elements.
2. Select the following commands: Tab Edit > Command group Arrange > Align horizontally or drop-down button Align horizontally > Align vertically.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan determines the midpoint of the two elements with the greatest distance between them and aligns all elements to this line.

![](../Pictures/Gui/ALL/note.png)Note:

Note that you must run the Align on grid command after performing alignment in order to reposition the insertion points on the grid.

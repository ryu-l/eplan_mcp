# Dialog Generate phase busbar connections

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a layout space. The connections navigator is open. Tab Edit > Command group Phase busbar connection > Generate.

This dialog lists all connections with the representations types "Multi-line" and "3D mounting layout" whose source and target are one of the items, respectively, which you have selected to generate a phase busbar connection. For example, these can be connections with the "Conductor / Wire" function definition.

In addition the DT of the connection with which the phase busbar can be used for grouping of connections is displayed.

Creation and deleting of phase busbar connections as well as the assignment of parts is possible with menu items in the popup menu.

Overview of the main dialog elements:

The table contains the following columns:

DT (identifying):

DT of the connection.

Function definition:

For connections that are not phase busbar connections the "Conductor / wire" function definition is displayed in this column. After the conversion into a phase busbar connection the displayed function definition is changed into "Phase bus bar connection". When the phase busbar connection is deleted, the entry in this column is reset to "Conductor / Wire".

Source:

Source of the connection.

Target:

Target of the connection.

---

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Generate phase busbar connection | This popup menu converts a connection in the marked line into a phase busbar connection with the function definition "Phase busbar connection". All properties of this connection are deleted.  If one of the connections has the "3D mounting layout" representation type, this will create a non-routed connection. Subsequently, delete the non-routed connections created in the connection navigator. |
| Delete phase busbar connection | With popup menu is used to remove a phase busbar connection already defined. The function definition is changed back to "Conductor / wire". This will delete all properties entered at the phase busbar connection.  The connection with the "Conductor / wire" function definition has to be re-routed in the layout space. |
| Assign phase busbar | Opens the dialog Assign phase busbar in which you can assign a part to a phase busbar connection. In addition, you can enter or select the DT for the phase busbar connection. |
| Select all | Selects all of the entries in the table. |
| Adjust column width | Adjusts the width of all table columns so that both the headings and column contents are fully legible. |
| Configure representation | Opens the Configure representation dialog in which you can determine the properties to be displayed in the table. This way, for example, you can display further connection properties in the table. |

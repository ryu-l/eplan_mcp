# Block Properties

Block properties are used to format and display several direct and/or indirect properties together. The following is possible by means of the block properties:

- You can access indirect properties of an object via block properties.
- You can enter block properties at any component and display the property values in the schematic.
- Block properties can be output in reports.
- Block properties can be defined as user-defined properties.
- In addition, indexed block properties are available.
- Indexed block properties can be predefined for symbols and projects.
- Calculation formulas can be entered in block properties and this way calculation properties defined.

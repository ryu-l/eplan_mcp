# Placing Connected Functions

Connected functions are all functions that are directly connected to a device via connections. When you place a device, you can use the Connected functions command to automatically place all connections and functions that are directly connected to an already placed function.

Preconditions:

- You have created at least 2 unplaced devices that have connection points.
- You have [generated unplaced connections](planningconnections_h_createconnections.htm) between the devices.
- You have opened a project page in the graphical editor.

1. Select the following commands: Tab Devices > Command group Devices > Navigator.
2. Select a device that has connections for connected functions.
3. Use drag & drop to pull the device onto the project page.
4. Select the placed device.
5. Select the following commands: Tab Insert > Command group Devices > Connected functions.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All directly connected, unplaced connections and functions are placed.
6. Press [F5] to update.

# Dialog Carry over connection designations

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have activated the Carry over connection designations to extent check box in the dialog [Settings: Connection symbols](gedviewer_d_einstellungenverbindungssymbole.htm). You have opened the property dialog for a connection (e.g., for a highlighted connection in the connection navigator or for a connection definition point in the graphical editor). Enter a new designation in the Connection designation field and click [OK].

Use this dialog to specify to which other connections a changed connection designation is to be carried over automatically.

Overview of the main dialog elements:

You can carry over the connection designation to the following connections:

- To no other connections: The connection designation is changed only at the highlighted connection.
- To all connections of the potential: The connection designation is assigned automatically to all connections within the potential.
- To all connections of the signal: The connection designation is assigned automatically to all connections within the signal.
- To all connections of the net: The connection designation is assigned automatically to all connections within the net.

![](../Pictures/Gui/ALL/note.png)Notes:

- When carrying over connection designations, the filter is taken into account that you have defined for the connection numbering. You specify this filter in the Filter tab of the dialog Settings: Connection numbering (command path: File > Settings > Projects > "Project name" > Connections > Connection numbering).
- The Carry over connection designations to extent setting does not have any effect when the connection designations are changed via the connection numbering.

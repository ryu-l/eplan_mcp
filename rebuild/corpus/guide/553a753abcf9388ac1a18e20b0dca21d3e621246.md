# Exporting Data for External Editing

The output of data for external editing depends on the selected object type which you can specify by means of the scheme. Different object types are possible depending from where you call up the export. In the parts management you have object types available such as parts, addresses, drilling patterns. etc. In the Backstage view during export of project data these are object types such as devices, cables, path function texts, etc.

Accordingly, you are always only offered schemes for selection for the respective relevant object during the respective export. If necessary, you also have to create schemes for other, desired object types.

### [ClosedExporting project data for external editing](javascript:void(0);)

Preconditions:

- You have opened a project.
- You have opened a navigator and the project in the tree view or list view, and have selected one or more pages or one or more records.

1. Select the following commands: File > Export > Command group Project data > Project data > Command group External editing > Properties.
2. In the dialog Edit externally select a scheme from the Settings drop-down list or click [...] to define the settings for a new user-defined scheme in the Settings: External editing dialog.
3. In the Language drop-down list, select the language to be used for the export.
4. In the Target file field, enter the file name including file path of the target file to be created, or click ![](../Pictures/Gui/ALL/all_selectfile_as.png) to interactively select the directory and the file name.
5. In the Output type group box, select one of the available output options.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The data of the specified object type is exported and a progress bar shows the progress.
7. Depending on the export-specific settings and the output type settings, you may have to finish your external editing before you can continue working in Eplan.

### [ClosedExporting parts data for external editing](javascript:void(0);)

You have the following possibilities during the export of data from the parts management for external editing:

- Export all data of an object type (part, accessory list, etc.)
- Export selected data of an object type

You specify the type of data (parts data, data of the accessory list, etc.) which is exported via the object type in the scheme for the export.

Precondition:

In the Parts management dialog you have opened a parts database using [Extras] > Settings.

#### Export all data of an object type

1. Select the following commands: Tab Master data > Command group Parts > Management.
2. Select the menu items Edit properties externally > Export data in the dialog Parts management below the button [Extras].
3. In the dialog Edit externally select a scheme from the Settings drop-down list or click [...] to define the settings for a new user-defined scheme in the Settings: External editing dialog.
4. In the Language drop-down list, select the language to be used for the export.
5. In the Target file field, enter the file name including file path of the target file to be created, or click ![](../Pictures/Gui/ALL/all_selectfile_as.png) to interactively select the directory and the file name.
6. In the Output type group box, select one of the available output options.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The data of the specified object type is exported and a progress bar shows the progress.
8. Depending on the export-specific settings and the output type settings, you may have to finish your external editing before you can continue working in Eplan.

#### Export selected data of an object type

1. Select the following commands: Tab Master data > Command group Parts > Management.
2. Mark one or more parts or other records in the tree view or in the list view.
3. Select the Export data popup menu item.
4. Continue in the dialog Edit externally as described above.

![](../Pictures/Gui/ALL/note.png)Note:

If the current selection in the tree view contains nodes, all the records under those nodes are taken into account.

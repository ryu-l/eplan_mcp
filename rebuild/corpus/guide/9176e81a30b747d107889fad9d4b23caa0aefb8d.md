# Dialog Properties (components): Layout space

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the layout space navigator. The project contains at least one layout space. You have selected a layout space in the layout space navigator. Select the Properties popup menu item.

In this dialog, you can view and change the properties of layout spaces.

Overview of the main dialog elements:

Name:

When creating a layout space, Eplan automatically suggests a name that comprises a number. The number in the automatically suggested name is incremented by one digit for each new layout space. You can accept this suggested name or extend and change it manually.

Structure identifiers:

You can use [...] to open the Structure identifier of layout space dialog where you can edit the structure identifiers.

Description:

Enter a descriptive text for the layout space here. This text is also displayed in the tree view of the layout space navigator.

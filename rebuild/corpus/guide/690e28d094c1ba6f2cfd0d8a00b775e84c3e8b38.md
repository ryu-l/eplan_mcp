# Automatable Actions

You can automate the following actions without programming knowledge:

| Action | Functionality |
| --- | --- |
| Update parts in project | Updates outdated parts data in the project. This will replace outdated stored parts in the project by newer system parts (i.e. newer parts in the parts database). |
| Complete parts in project | Searches in the project for missing parts; if they are found, they are automatically stored. Missing parts can occur if parts have first been entered at the main function in the project and only afterwards have been created in the parts database. |
| Complete parts in system | Supplements the system (i.e., the parts database) with parts that were present in the project, but not in the system. |
| Update reports | Updates all reports that are contained in the selection or in the entire project. |
| Update / generate reports | Updates / generates all reports that are contained in the selection or in the entire project. |
| DXF / DWG | Outputs the entire project or selected project pages as a DXF / DWG file. |
| Back up data | Saves the project as an \*.zw1 file in the selected backup directory. Depending on the selected backup method, the source project is retained, filed off, and remains write-protected or is deleted. |
| Print | Prints the selected project pages or the entire project. |
| Delete stored part properties | Deletes the properties of parts stored in the project. |
| Export manufacturing data / Labeling | Outputs project data for the manufacturing data / labeling. |
| Komax - Zeta: Export manufacturing data | Outputs the wire data of the project for the wire fabrication machines "Komax - Zeta". |
| Update model views | Updates all model views that are contained in the selection or in the entire project. |
| NC DXF | Outputs the manufacturing data of the project for the machining at NC machines. |
| Export PDF | Outputs the entire project or selected project pages as a PDF file. |
| Compress project | Removes any unnecessary project data. |
| Optimize project database | Optimizes the project database. (This is necessary before "old" projects can be edited in the current version.) |
| Perform project checks | Performs the selected project checks. The messages generated are stored in the message management. |
| Rittal - Perforex BC: Export manufacturing data | Outputs the coordinates of drill holes as control data for a Rittal - Perforex BC / Secarex system. |
| Rittal - Perforex LC: Export manufacturing data | Outputs the coordinates of drill holes as control data for a Rittal - Perforex LC / Secarex system. |
| Generate topology functions | Automatically generates topology functions and inserts them into the routing path network. |
| Update connections | Generates or updates connections. |
| Route (topology) | Routes connections in the topology. |
| Translate | Translates the project into the desired languages. |
| Remove translations | Removes translation text in one or more languages from the project. |

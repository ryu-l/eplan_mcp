# Creating Macro Projects

You can use macro projects to manage your macros and automatically create macros.

Precondition:

You have created a basic project \*.zw9.

1. Select the following commands: File > New.
2. In the Create project dialog create a new project as described in [Creating a Project](projects_h_projekteerstellen.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan opens the Project properties: <Project name> dialog.
3. Select the "Settings" Category in the Properties tab.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Only the Type of project property is still displayed.
4. Click here in the Value column on the associated field and select the "Macro project" setting from the drop-down list.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new macro project is created and can be edited like a "normal" project.

![](../Pictures/Gui/ALL/info.png)Tip:

Creating a new project is not the only way to create macro projects. You can also first create a schematic project, prepare corresponding schematics cut-outs for the macros to be generated, and then convert to a macro project by changing the project properties. To do this you only have to change the project setting Type of project to "Macro project" as described in Step 3.

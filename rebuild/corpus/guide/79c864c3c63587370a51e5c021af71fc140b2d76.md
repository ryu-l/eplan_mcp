# P502004: The function definition '<x>' entered at the part is obsolete

### Cause

In the parts database to be checked a part was found where a function definition was entered which is obsolete and therefore no longer permissible.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Function templates tab to the front.
3. In the Device selection (function templates) table click the entry in the Function definition column that contains the obsolete no longer permissible function definition and click [...].
4. Select an up-to-date function definition from the Function definitions dialog that is opened.
5. Click [Apply].
6. If required, start a new check run.
7. Close the parts management and perform a parts data synchronization.

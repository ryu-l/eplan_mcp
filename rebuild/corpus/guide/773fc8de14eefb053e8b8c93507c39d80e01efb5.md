# PLC Address Formats

Eplan supports you in the assignment of PLC addresses. The following editing options are available:

- You can define a desired format for PLC addresses.
- You can use separate addressing formats for digital and analog PLC addresses.
- Symbolic addresses can be automatically created according to specific criteria.
- You can define different formats for assignment lists.

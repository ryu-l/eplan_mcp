# Importing PDF Comments

You can export selected project pages or an entire project as a PDF file and add comments in Adobe Acrobat. The comments from this PDF file can then be imported into the associated Eplan project again.

Preconditions:

- You have exported an Eplan project as a PDF file.
- The project redliner has inserted comments into the PDF file via Adobe Acrobat.
- You have opened the Eplan project again.

1. Select the following commands: Tab Tools > Command group Comments > Import.
2. In the dialog Open, select the PDF file with the comments to be imported and click Open.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The import is started. If necessary, a message is displayed and you have to confirm the addition or overwriting of comments.

![](../Pictures/Gui/ALL/info.png)Tip:

You can also import PDF comments using the following commands: File > Import > Command group Project data > Project data > Command group Comments > PDF comments.

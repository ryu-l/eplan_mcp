# Dialog Number cables

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have selected components in the graphical editor.
- Or you have selected cables or cable connections in the navigator dialog Cables - <Project name>.
- Or you have selected connections in the navigator dialog Connections - <Project name>.
- Or you have selected pages or a project in the Pages - <Project name> navigator dialog.

Tab Connections > Command group Cables > Number.

In this dialog you specify the settings for numbering cable device tags and then you execute the numbering.

![](../Pictures/Gui/ALL/note.png)Note:

Ensure that nested DTs are excluded from numbering.

Overview of the main dialog elements:

Settings:

The scheme selected here specifies in which sequence cables are numbered, which properties are to be displayed in the cable DT and how they and formatted. Use [...] to open the [Settings: Cable numbering](cablegui_d_einstellungenkabelnummerierung.htm) dialog where you manage and edit the schemes.

Start value:

Enter the start value for the DT counter.

Increment:

Enter the value here to be used to increment the counter of the DT.

Keep existing cable DTs:

Select this check box if you would only like to renumber newly generated or copied cables. The DT of the already numbered cables is retained. The cables with "?" in the identifier will be numbered.

If the check box is deselected, all of the cable DTs are renumbered.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

In the following example, start value and increment are set to 1.

Before numbering: W2 ?W W3 W5  
Activated check box: W2 W1 W3 W5  
Deactivated check box: W1 W2 W3 W4

Keep identifier:

Activate this check box if you want to renumber existing cables and only want to reassign the counters. The identifier of the already numbered cables remains. Question marks at the beginning of the identifier are not retained.

If the check box is deactivated, the identifiers of the cables are overwritten with the identifier from the identifier set that is used during numbering.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

In the following example, start value and increment are set to 1.

Before numbering: WB2 WB3 WD3 ?WD3 WD5  
Check box activated: WB1 WB2 WD1 WD2 WD3  
Check box deactivated: W1 W2 W3 W4 W5

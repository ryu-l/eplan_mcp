# P027009: Topology - The routing path has at least one open end

### Cause

The routing path in the routing path network is connected only with one end or with no end at all to a topology function, a topology interruption point or a routing point.

### Solution

1. Locate the routing path in your routing path network using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. According the number of open ends of the routing path, place a topology function, a topology interruption point or a routing point in the routing path network.
3. Position the routing path network objects on the routing path in such a way that the respective connection point or insertion point docks to the routing path. Check this by moving the routing path network objects at the end of the routing path. The routing path has to move along.
4. Update the connections.
5. If required, start a new check run.

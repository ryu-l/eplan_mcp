# P004115: Address range of the subdevice '<x>' overlaps with the address range of the subdevice '<y>' of the PLC card '<z>'

### Cause

The address areas of two subdevices of a PLC card are defined in such a way that their address areas overlap.

### Solution

1. Locate the PLC box of the PLC card in the schematic via the popup menu of the Message management dialog.
2. Call up the property dialog of the PLC box and bring the first tab to the front.
3. In the properties table modify the values in the fields PLC subdevice x: Start address (...) and PLC subdevice x: Data length (...) in such a way that an overlap of the address areas is impossible.
4. Confirm your entries.
5. If required, start a new check run.

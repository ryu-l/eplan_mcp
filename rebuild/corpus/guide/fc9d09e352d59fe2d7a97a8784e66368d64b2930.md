# Manufacturing Data for Eplan Smart Production

Eplan Pro Panel allows the export of manufacturing data for Eplan Smart Production. Eplan Smart Production is a web application that supports you in the context of enclosure production during the mounting of mounting rails, wire ducts and during the installation of connections. The export file from Eplan Pro Panel is output in the "EPDZ" format. This file contains the properties of all layout spaces and schematic pages of a project as well as the information contained of all routed connections. In addition an AML file with the data of all part placements as well as an E3D file with the 3D graphic data is embedded in the EPDZ file for each layout space.

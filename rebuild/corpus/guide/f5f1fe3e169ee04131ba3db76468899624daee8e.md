# Assigning a Segment Template

Preconditions:

- You have opened a project that already contains segments.
- You have opened the pre-planning navigator or the graphical editor.

### Assigning a segment template to a segment

1. Select a segment in the pre-planning navigator or in the graphical editor, and select the Properties popup menu item.
2. Select the <Segment - displayed name> tab in the dialog Properties <...>.
3. Click [...] next to the Segment template field.
4. Select the desired segment template in the Select segment template dialog.
5. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property values defined in the segment template are transferred to the segment.

![](../Pictures/Gui/ALL/note.png)Note:

During the selection of a segment template with subordinate segment templates only the segment template with your predefined data is transferred. The subordinate segment templates are ignored. This is the case both when assigning in the property dialog as well during the import of pre-planning data and for external editing.

![](../Pictures/Gui/ALL/info.png)Tip:

In the segment template navigator you can use the Assign popup menu item to assign the marked segment template to a segment placed in the graphical editor.

### Generating segments via drag & drop or assigning segment templates

1. Select the following commands: Tab Pre-planning > Command group General > Segment templates.
2. Select a segment template in the segment template navigator.
3. Drag the segment template into the pre-planning navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A new segment to which the segment template is assigned is created.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property values defined in the segment template are transferred to the segment.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A nested segment with subordinate segments is generated from a segment template with subordinate segment templates. A segment template is assigned to each individual segment.
4. Or drag the segment template on a segment in the pre-planning navigator and while dragging press the [Ctrl] + [Shift] keys. After pressing the shortcut key, first release the mouse button and then the keys.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The segment template is assigned to the existing template (if both have the same segment definition).  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the segment template has subordinate segment templates, subordinate segments are generated for the existing segment.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property values defined in the segment template are transferred to the segment. Values that were changed manually beforehand at the segment are retained.
5. If you also want to replace the manually changed property values of the segment by the corresponding values from the segment template, mark the segment in the segment template navigator and select the popup menu item Reset to segment template.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All the property values of the segment are replaced by the corresponding values from tjhe segment template.

![](../Pictures/Gui/ALL/info.png)Tip:

You can also drag-and-drop a segment template into the graphical editor (on a pre-planning page). In the process a new segment to which the segment template is assigned is created and placed.

### Remove the assigned segment template from the segment

1. Select a segment in the pre-planning navigator or in the graphical editor, and select the Properties popup menu item.
2. Select the <Segment - displayed name> tab in the dialog Properties <...>.
3. Click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) next to the Segment template field.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The reference to the segment template is deleted from the segment.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property values defined in the segment template will be deleted at the segment. Manually changed values are retained.

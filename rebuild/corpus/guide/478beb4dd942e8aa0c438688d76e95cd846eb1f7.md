# Generating Mounting Panel Cross-references

At a part or device placed on a mounting panel, you can create a cross-reference pointing to the associated main function in the schematic. You can also do the reverse and create a cross-reference at the main function in the schematic that points to the placed part or device on the mounting panel.

Preconditions:

- You have opened a project.
- You have created a multi-line schematic page.
- You have created a page of the type "Panel layout".
- In the Display device cross-references group box, you have specified under File > Settings > Projects > "Project name" > Cross-references / contact image > Display that cross-references between multi-line schematic pages and pages of type "Panel layout" and vice-versa are to be displayed.

1. Open the multi-line schematic page in the graphical editor and insert a symbol, for example, a contactor coil.
2. In the <Function category> tab of the dialog Properties <...> enter a Displayed DT for the contactor coil, for example, K1.
3. If not already selected, select the Main function check box.
4. Switch to the Part tab, and in the first free field under Part number click [...].
5. Navigate through the tree view of the dialog Part selection to the "Relays / contactors" product group.
6. Select the appropriate part containing the width and height information (hierarchy level Mounting data on the Properties tab of the selected part).
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The part selection dialog is then closed and you are back in the properties dialog.
8. Click [OK].
9. Open the page of "Panel layout" type.
10. Select the following commands: Tab Insert > Command group 2D panel layout > Mounting panel (2D). Draw the mounting panel as a rectangle.
11. In the Mounting panel tab of the dialog Properties <...> enter the Displayed DT of the mounting panel and click [OK].
12. Select the following commands: Tab Devices > Command group 2D panel layout > Navigator.
13. In the tree view of the dialog Panel layout - <Project name> select the current project and navigate below the hierarchy level "Unplaced" to the part number of the contactor.
14. Select the part and then select the popup menu item Place on mounting panel.  
      
    ![](../Pictures/Gui/ALL/arrow.png) A rectangular graphic now hangs on the cursor whose dimension Eplan has taken from the part information of the selected contactor.
15. Move the graphic into the inside of the mounting panel and place it there with a mouse click.  
      
    ![](../Pictures/Gui/ALL/arrow.png) A cross-reference is now created at the contactor coil in the schematic, pointing to the placed part on the 'Panel layout' page. Conversely, a cross-reference is created pointing to the contactor coil in the schematic on the "Panel layout".
16. Open both pages in separate editors to observe the cross-reference display.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The contactor -K1 in the schematic (left side of the illustration) points within the panel layout (right side of the illustration) to the part 001ART placed inside the mounting panel U1 and vice-versa.

![](../Pictures/Visualisation/ALL/xessettingsgui_MontageQVWerzeugen_av.png)

### Mark mounting panel cross-references

To use a marking for highlighting mounting panel cross-references to main functions in the schematic, proceed as follows:

1. Select the following commands: File > Settings > Projects > "Project name" > Cross-references / contact image > General.
2. In the Marker for group box of the dialog Settings: General enter any desired character in the Panel layout field.
3. Click [OK].
4. Press [F5] to update the schematic representation.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You have entered the "%" character as marker text for cross-references to the mounting panel (panel layout). In the schematic, this setting is displayed at the main function as follows:

# Dialog Settings: 3D

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > User > Graphical editing > 3D

Use this dialog to enter your own user settings for graphical editing in the 3D view.

Overview of the main dialog elements:

Group box Color settings

Use [...] to open the dialog [Color selection](mf_d_farbauswahl.htm) at all the color settings. Select the desired color there.

Shading - background 1 / Shading - background 2:

Enter the background colors for the shading in the 3D view.

Collision indication:

Enter the background colors for collisions between components during placement and when making changes in the 3D view.

Active mounting surface:

Enter the color for the active mounting surface in the 3D view.

Active copper bundle:

Enter the color for the active copper bundle in the 3D view.

---

Default grid sizes group box

You can specify five different default grid sizes in the Grid size A to Grid size E fields. In an opened layout space choose the grid size by using the drop-down button ![](../Pictures/Gui/ALL/all_gridactive_as.png) (Grid) in the status bar.

---

Apply simplified representation to group box

Use this group box to specify which items in the layout space are to be reduced in size in the detail in the graphic by the Simplified representation functionality:

- Terminal strips (block definition): If this check box is activated (default setting), the terminal strips will be displayed as a simplified block.
- 3D macros: If this check box is activated (default setting), the graphical macros, rails, and wire ducts are simplified into a cuboid.

You activate the representation specified here for an opened layout space by using the button Simplified representation (Tab View > Command group Layout space > Simplified representation). Or select the Simplified representation popup menu item in the layout space navigator.

---

Group box Middle mouse button

Here you use the middle mouse button to specify whether you want to rotate or move the 3D model in the layout space.

- Rotate, and to move also use [Shift]: If this option is selected and you press the middle mouse button, you change the viewing angle of the 3D model in the layout space by moving the mouse. The display in the layout space follows the movement of the mouse, and rotates in the corresponding direction. This functionality corresponds to the command Rotate viewing angle ![](../Pictures/Gui/ALL/statusbar_viewpoint_as.png) in the status bar of the graphical editor. While rotating, also press the [Shift] key and keep it pressed, the rotation is interrupted and the 3D model is moved in the layout space in the direction of the mouse movement.
- Move and rotate with [Shift]: If this option (default setting) is selected, and you also hold down the [Shift] key while moving, moving is interrupted and the 3D model in the layout space is rotated in the direction of the mouse movement.

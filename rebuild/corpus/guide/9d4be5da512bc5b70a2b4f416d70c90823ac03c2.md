# P024009: Conduit connection without conduit / line

### Cause

The connection definition point of a conduit connection no longer lies on the interface of the conduit definition line anymore. Eplan can therefore not assign the connection definition point to a conduit.

### Solution

1. Locate the connection definition point in the schematic by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Move the connection definition point to the interface of the conduit definition line with the conduit connection or redraw the conduit definition line.
3. Update the connections.
4. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

If the moved connection definition point of a conduit connection has the same DT as the conduit definition, the connection is assignable to the conduit. Accordingly the message is not output.

# Dialog Print

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Print.

In this dialog, you can select the printer and determine the pages that you would like to print.

Overview of the main dialog elements:

Printer group box

In the drop-down list Name, all of the printers that are installed for your computer are displayed; select the one you would like. In the Status, Type, Where, and Comment fields, you can see the information stored for this printer in the Windows printer configuration.

[Properties]:

Use this button to open the Windows dialog for printer settings, which is where you can change the printer-specific settings. For more information, please see the help file for the printer in question.

---

Pages group box

In this group box, you can determine which pages you would like to print. If you called up the Print dialog from the graphical editor, you can print either the page currently in the foreground or all of the project pages. If it was called up from the page navigator, you can either print the selected pages or all of the pages in the project.

- Current page: The page in the foreground of the Graphical Editor is printed.
- Marker: The pages marked in the page navigator are printed. If the project is selected in the page navigator and a page filter is activated at the same time, only the filtered project pages are printed.
- Entire project: The entire project pages are printed. Any activated page filter is ignored.
- Changed pages only: Activate this check box to have all pages printed which have been marked as "modified" since the last printout, that is, all pages for which the property "Modification date (automatic)" is more current than the last print date.

[Settings]:

This button opens the [Settings: Print](printgui_d_druckoptionen.htm) dialog. It is there that you can determine the scaling, print margins, and position on the page, as well as the settings for color or black and white.

---

Copies group box

In this group box, you determine the number of copies and their collation.

- Quantity: You can determine how many copies of the selected pages will be printed here.
- Collate: This check box can only be checked if you are printing multiple copies. If this check box is selected, the sets of selected pages will be printed one after the other. If it is not selected, all of the copies of each page will be printed together. A small graphic in the dialog makes the behavior clear.
- Reverse print order: If this check box is selected, the pages will be printed in reverse order. If the check box is not selected, the pages will be printed in the order in which they appear in the project. A small graphic in the dialog makes the behavior clear.
- Print to file: Select this check box if you would like to print the selected pages into a file. Eplan generates a \*.PRN file which you can then print at a later date or use to create a PDF file.

---

Scope of printing group box

In this group box you determine whether only project pages are to be printed or the attached documents as well.

- Only project / page: The project pages selected in the Pages group box are printed.
- Only attached documents: Only those attached documents are printed which are linked on the pages selected for printing.
- Project / page and attached documents: The project pages selected in the Pages group box are printed as well as the attached documents linked on these pages.

[Select attached documents]:

This button opens the [Print attached documents](printgui_d_begleitdokumente.htm) dialog. There you select those attached documents linked in the project that are to be printed.

---

Print preview

The right-hand side of the dialog shows a print preview of the selected pages. The display corresponds to the output on the printer, including the position on the paper. For color printing, all of the elements are displayed using the "Colored on white" color scheme; for black and white printing, all of the elements (except image files) are shown in black, on a white background.

Below the preview the total number of the pages to be printed as well as the name of the page displayed in the preview is shown. Through the entry field you can browse through the pages or jump to the desired page.

Only those pages are displayed in the print preview which are also printed. If in the Pages group box you have selected the Changed pages only option, the selection may contain pages that have not changed since the last printout and these will therefore not be printed. These pages are not displayed in the print preview.

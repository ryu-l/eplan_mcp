# P024004: Connection between different subtrades

### Cause

The target functions of a connection have a conflicting entry for the Subtrade property. This can occur when, for example, a connection exists between functions belonging to the subtrades "Water cooling" and "Oil cooling".

### Solution

1. Assign matching Subtrade property data to the connection targets. The subtrade can be set for each function in the Properties <...> dialog on the first tab.
2. Update the connections.
3. If required, start a new check run.

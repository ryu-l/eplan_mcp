# P004113: Symbolic address (automatic) contains a blank, a tabulator or a line break

### Cause

A value that contains a blank, a tabulator or a line break was entered at a PLC connection point (at an input or output) in the Symbolic address (automatic) field. According to standard IEC 61131-3 these characters are not permitted in a symbolic address.

### Solution

1. Locate the PLC connection point in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Call up the property dialog of the PLC connection point and manually correct the value in the Symbolic address field. If the error occurred due to an import from an assignment list, correct the symbolic address in the assignment list and import it again.
3. If required, start a new check run.

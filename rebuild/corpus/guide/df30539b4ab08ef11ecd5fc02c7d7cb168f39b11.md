# P020032: Connection from <x> to <y>: <z>

### Description

You have run a project comparison, checking the Properties of the test project (incoming project) against those of the comparison project and differences were found.

This message occurs when a difference in the properties of a connection was found. The DTs of the connected source and connected target are output as <x> and <y>, respectively. <z> indicates whether the connection has been deleted or added, or one of its properties has been changed. The check of the properties of connections extends to the non-placed connections and routing connections (layout space and topology).

If you have adjusted the corresponding properties in the incoming project to the properties of the comparison project, update the connections in the incoming project subsequently.

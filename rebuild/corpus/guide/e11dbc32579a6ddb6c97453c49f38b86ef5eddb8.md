# Dialog Settings: 3D navigation cube

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > User > Graphical editing > 3D navigation cube

In this dialog you specify the user settings for the navigation cube in the layout space.

Overview of the main dialog elements:

Navigation cube visible:

This allows you to specify whether the navigation cube in the layout space is to be shown or hidden. This check box is selected by default.

Home view for navigation cube:

Use this drop-down list to specify the viewpoint of the view in the layout space when you click the button ![](../Pictures/Gui/ALL/cabinetgui_navigationcubehome_as.png) below the navigation cube. You can choose between six orthogonal and four isometric home views.

Navigation cube size:

Use this drop-down list to select the size of the navigation cube in the layout space. You can set up five different sizes, from "Very small" to "Very large". Together with the size of the navigation cube, all the buttons used to control the navigation cube change as well.

Rotate when changing the viewpoints:

This check box can be used to activate and deactivate the animated rotation when changing the viewpoints in the layout space. In accordance with the setting, the rotation of the navigation cube is also animated or not animated during viewpoint changes. The animation is activated by default. The setting also applies to the commands for rotating the viewing angles in the status bar and to the possibilities of changing the viewpoint by means of the shortcut keys provided for this purpose.

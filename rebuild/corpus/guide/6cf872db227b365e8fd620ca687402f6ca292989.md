# Defining Tags in the Insert Center

With a "Tag" you can link objects such as symbols, devices as well as window and symbol macros, in the Insert center with any keyword. By assigning tags you can, for example, assign objects to a manufacturer, a customer name or a plant part. Tags also make it easier to find objects again that you might need for insertion at a later point.

Preconditions:

- You have opened a project.
- You have opened a project page in the graphical editor. Or you have opened a layout space.
- You have opened the Insert center.

1. Navigate via the folder of the object types Symbol, Device or Window macro / symbol macro and the corresponding subfolders to the object that you want to assign a tag to.
2. In the preview tile of the object click the icon ![](../Pictures/Gui/ALL/insertergui_no_tag_tile as.png) (Tag).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The icon is now displayed filled (![](../Pictures/Gui/ALL/insertergui_tag_tile_as.png)).
3. In the dialog Manage tags: <Object name> enter the desired tag in the field New tag. Or select a tag from the list that opens.  
     
   ![](../Pictures/Gui/ALL/arrow.png) As soon as you click in this field, a list of the existing tags to which the object is not yet assigned is displayed.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The tag is displayed in the Tags list.
5. If required, enter further tags or delete tags that are not required by using the ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) button.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The object is linked with the tags contained in the Tags list.
7. In the breadcrumb trail select the breadcrumb trail Home > Tags.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The tag created is displayed as a new folder below the breadcrumb trail.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Next to the folder a "1" is shown as the number of objects assigned to the tag. The number increases accordingly when you assign the tag to further objects.
8. Click the folder of the tag.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The object or objects linked to the tag are now available to you as preview tiles and can be inserted immediately.

![](../Pictures/Gui/ALL/info.png)Tip:

Alternatively to clicking the icon ![](../Pictures/Gui/ALL/insertergui_tag_tile_as.png), the object marked in the preview tile can also be linked with a tag by using the [T] key.

![](../Pictures/Gui/ALL/note.png)Notes:

- It is not possible to define multilingual tags.
- The tags can consist of any string, including special characters.
- Eplan remembers all keywords assigned as a tag. If you want to assign an existing keyword to an object in the dialog for tag editing, it is sufficient to simply enter the first character of the keyword in the New tag field (case sensitivity is not considered). All tags already assigned that begin with the entered characters are offered for selection below the field. You assign the desired keyword to the object via a mouse click on the desired tag and with [OK].
- One and the same object can be assigned to different tags.

### Delete a tag assignment

1. In the breadcrumb trail select Home > Tags > "Name" and use this to switch to the preview of the objects listed under the tag name.
2. In the preview tile, select the icon (![](../Pictures/Gui/ALL/insertergui_tag_tile_as.png)) at the object whose tag assignment you want to delete.  
     
   ![](../Pictures/Gui/ALL/arrow_11x11.png) The Manage tags: <Object name> dialog is opened and shows the names of the tags which have the object assigned.
3. In the list mark the tag to which the object is no longer to be assigned.
4. Click the ![](../Pictures/Gui/ALL/all_delete_as.png) button.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow_11x11.png) The preview tile of the object is deleted.  
     
   ![](../Pictures/Gui/ALL/arrow_11x11.png) The display of the number of objects assigned in the tag next to the corresponding folder has been reduced by the value "1". If only one object was assigned to the tag, the tag is deleted completely.

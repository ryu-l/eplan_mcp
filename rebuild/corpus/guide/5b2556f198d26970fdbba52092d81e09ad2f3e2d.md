# P502035: The user-defined property '<x>' with the value '<y>' is not defined in the 'Configure properties' dialog.

### Cause

In the parts database to be checked a part with the user-defined property '<x>' and the value '<y>' has been determined. However, the user-defined property is not defined in the Configure properties dialog. This case can occur when you import parts from Eplan Version 2.9 with assigned user-defined properties for parts or schemes for the user-defined properties.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the User-defined properties tab to the foreground.
3. Select the Configure properties popup menu item.
4. In the Configure properties dialog carry out the desired configuration and close the dialog.
5. Edit the user-defined property in the tab which is still open.
6. Click [Apply].
7. If required, start a new check run.
8. Close the parts management and perform a parts data synchronization.

# Inserting Net Definition Points

With a net definition point you specify the properties of a net, for example the net name. You can also define the net-based connections here.

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the following commands: Tab Insert > Command group Cables / connections > Drop-down button Connection > Net definition point.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol for the net definition point is attached to the cursor.
2. To place the net definition point, click into the schematic.
3. In the Properties <...> dialog, enter the properties of the network in the Net definition tab.
4. In the Net connections tab specify the connections within the network.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The properties are assigned to the connections defined with the net definition point.

![](../Pictures/Gui/ALL/info.png)Tips:

- With the user setting (File > Settings > User > Graphical editing > Connection symbols), you can specify that the Specify targets property at the connection symbols of the associated net is automatically deactivated when inserting a net definition point.
- You can insert multiple net definition points at the same time by holding the left mouse button down and pulling the cursor over multiple autoconnect lines. A net definition point is then placed on each autoconnect line that is intersected.

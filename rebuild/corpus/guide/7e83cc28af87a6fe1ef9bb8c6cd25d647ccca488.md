# Defined Working Sections

Projects can be divided into defined working sections. This creates more transparency in project editing, and facilitates the simultaneous editing of projects by several users. The criteria for the division are saved in filter schemes.

For projects that are structured by identifier blocks, the division is based on the structure identifiers available for the identifier blocks in the project. You can filter by any combination of these structure identifiers. In addition, you can filter pages, layout spaces, functions and connections by specific trades.

For sequentially numbered projects only a division by trades is possible.

The following is possible:

- You can specify in which defined working section you want to work by selecting a scheme.
- When you use the rights management of Eplan, the defined working sections can be assigned centrally by a project administrator. Without the usage of the rights management, each individual user can specify in which defined working section they want to work.
- The project data navigators will then display only the pages, devices, etc. corresponding to the criteria determined in the scheme. This makes the display of large projects more transparent and increases the editing speed.
- Editing can be extended temporarily to the entire project.

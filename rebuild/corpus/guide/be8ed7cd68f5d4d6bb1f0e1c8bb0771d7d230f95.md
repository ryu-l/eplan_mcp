# P502033: The identifying connection point information of the function templates does not match the connection point data at the connection point pattern

### Cause

In the parts database to be checked a part was determined at which the identifying connection point information of the function templates do not match the connection point data at the connection point pattern.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Function templates tab to the front.
3. Remember the values entered in the Device selection (function templates) table in the Connection point designations column.
4. Bring the Properties tab to the front.
5. In the property table in the Data hierarchy level remember the connection point pattern in the value field of the Connection point pattern property.
6. Click [...] in the value field.
7. In the Connection point pattern selection dialog change to the Connection points tab and compare the stored connection point designations with the connection point designations at the function templates of the part.
8. Correct the connection point designations in the connection point pattern. In the process ensure that - in contrast to the function templates - every single connection value has to be located in a separate row in the connection point pattern.
9. Click [Apply].
10. If required, start a new check run.
11. Close the parts management and perform a parts data synchronization.

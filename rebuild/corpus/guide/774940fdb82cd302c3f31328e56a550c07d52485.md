# Using and Returning Existing PLC Addresses

If your project contains free PLC addresses, you can use these existing ones and assign them to the PLC connection points existing in the project.

At a single PLC connection point, you can use the Properties <...> dialog to use an existing address and to 'return' it ('returning' only deletes the graphical representation of a function from the schematic). In the Use existing PLC addresses blockwise dialog, you can use several addresses at the same time (also for different PLC connection point placements).

### Re-use single PLC addresses

Precondition:

You have opened the Properties <...> dialog for a single PLC connection point.

1. Select the <Function category> tab and click [...] next to the Address field.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Select for use dialog shows all PLC addresses in the project.
2. Select the desired PLC address from the table.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The PLC address is inserted in the Properties <...> dialog.

![](../Pictures/Gui/ALL/info.png)Tip:

By means of a filter you have the possibility to limit the display of the PLC addresses to one (or several) CPU. The filter is activated automatically as soon as you select it in the Filter drop-down list.

### Return single PLC addresses

Preconditions:

- You have opened the Properties <...> dialog for a single PLC connection point.
- The selected PLC connection point address is not entered for any other connection point representation.

1. Select the <Function category> tab and click ![](../Pictures/Gui/ALL/all_rebook_as.png) next to the Address field.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The address is removed from the field and added as a free address to the current assignment list, whereby the Function text (automatic) and Symbolic address (automatic) are retained.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Manual function texts and symbolic addresses are deleted.
2. Next to the Address filed, click [...] to use a new address, or leave the field empty and fill it with an address at a later time.
3. Click [OK].

![](../Pictures/Gui/ALL/info.png)Tip:

In the Properties (global) editing mode the address of all connection points is returned collectively. Empty spaces in the addresses are not taken into account, i.e., the addresses "E0.0" and "E 0.0" are regarded as identical.

### Use existing PLC addresses blockwise

Precondition:

You have selected several PLC connection points in the graphical editor, the PLC navigator, or in the device navigator.

1. Select the following commands: Tab Devices > Command group PLC > Addresses.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Use existing PLC addresses blockwise and Select for use dialogs open automatically, whereby the second dialog is in the foreground and can be directly edited.
2. Select the PLC addresses that you wish to use and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Use existing PLC addresses blockwise dialog shows the selected PLC addresses in the From table.
3. Use the arrow keys to move the PLC addresses in the right-hand table and assign them to the existing PLC connection points in the left-hand table To.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Entries can only be moved to another free position; no changes are made to the unselected, occupied positions.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the selected quantities are different, then this is balanced by appended empty lines.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The PLC addresses are re-used and assigned to the PLC connection points.  
     
   ![](../Pictures/Gui/ALL/arrow.png) At power supply connection points, the address, the symbolic address, and the function text are only transferred if these properties already contained values.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have also selected the associated power supply connection points and representations on the overview pages for a PLC connection point, then the address is re-used for all representations.

![](../Pictures/Gui/ALL/info.png)Tip:

By means of a filter you have the possibility to limit the display of the PLC addresses to one (or several) CPU. The filter is activated automatically as soon as you select it in the Filter drop-down list.

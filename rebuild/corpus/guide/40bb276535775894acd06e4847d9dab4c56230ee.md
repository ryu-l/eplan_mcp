In this dialog you select the properties that are displayed at the respective object (function, pre-planning placement, connection definition point, etc.) or in tabs or that are used in a scheme for the property configuration of the property overview or in which the search for the search term takes place.

Overview of the main dialog elements:

Source object:

This field is only available if multiple sources are possible for the properties.

This field lists the possible sources for a property. If you select a source object, the right part of the dialog displays a tab of the same name with the available properties of this source object.

Category:

The category allows you to limit the display of the properties possible for the marked source object to a subset.

This field is irrelevant for the property configuration of the property overview and for the property configuration in the parts management at the record types such as accessory list, drilling pattern, etc.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example (categories for the display):](javascript:void(0);)

In the "Devices" category device properties are available, for example components of the DT; elements of the DT, structure identifiers.

The "Data" category makes properties available for which the entry of data values is possible, e.g., function texts, technical characteristics, user supplementary fields, block properties.

In the "Settings" category properties are available that are set using check boxes or drop-down lists, e.g., "Suppress in device tag list", "Cross-reference display: Display".

Find:

Into this field enter the text for which the properties are to be filtered. Both property names and set values are found when the properties are filtered. Logic operators (AND / OR operation) and placeholders (such as \* or ?) are not supported for filtering.

If you want to return to the original view of the properties, remove the search term from the entry field. Click ![](../Pictures/Gui/ALL/all_delete_input_as.png) (Delete) to do so.

![](../Pictures/Gui/ALL/info.png)Tip:

Enter multiple letters one immediately after the other to search for a string and jump directly to the first entry that starts with the letters you entered. If you enter "sup", for example, the cursor will jump in the list of properties directly to the first entry that starts with "sup", for example "supplementary field".  
If you pause too long between entering "s" and "u", the cursor will jump to the first entry that starts with "s", and then to the first entry that starts with "u".

Table:

All properties available for the relevant object are displayed sorted by name in the Property name column of the table. The associated property values (where available) are displayed in the Value column. Double-click a column header to sort the properties by the respective column.

# P026076: Cable / tubing protection or cable / tubing tie is not located on a routing path / curve

### Cause

A cable / tubing protection or cable / tubing tie was moved in the layout space, so that it can no longer be assigned to a routing path or curve.

### Solution

1. Locate the cable / tubing protection or cable / tubing tie in the layout space using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Delete the moved cable / tubing protection or cable / tubing tie.
3. Route the connections again.
4. If required, start a new check run.

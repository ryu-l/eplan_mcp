# Dialog Project options group

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Tab Devices > Command group Project options > Navigator.

- Select the New > Project options group popup menu items.
- You have selected a project options group. Select the Properties popup menu item.

In this dialog you create a new project options group or edit an existing one.

Overview of the main dialog elements:

Name:

Enter a name for the project options group here, or change the existing name.

Description:

Enter a description text for the project options group here. The description is a multi-language text and is displayed by default in the tree view next to the name, separated by a blank and within round brackets.

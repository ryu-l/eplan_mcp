# Marking and Editing the Piping Route

In order to obtain a rapid overview of the extension of a piping in the P&I diagram a piping can be highlighted temporarily in color. The piping route can be edited by adding / removing autoconnect lines.

The currently selected piping is then colored according to the color you have defined for the potential tracking in the user settings. Autoconnect lines, which you can add to a piping, are colored in the color set for external symbols.

Preconditions:

- You have opened a project containing pre-planning data.
- You have opened a page of the "P&I diagram" type.
- You have defined a piping in the P&I diagram by means of a piping definition point.

1. Select the following commands: Tab Pre-planning > Command group Piping > Highlight piping route.
2. Select a piping definition point.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The autoconnect lines belonging to a piping are colored. Autoconnect lines which you can add to a piping are highlighted in a different color.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The direction of flow is indicated by means of the arrowheads on the autoconnecting lines of the piping.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Icons at the cursor show you if an autoconnect line can be added to or removed from a piping by a click:

| Cursor | Meaning |
| --- | --- |
|  | Piping route is activated |
|  | The following three icons are displayed when the cursor is located exactly over an autoconnect line: |
|  | Add autoconnect line of a piping |
|  | Adding / removing an autoconnect line not allowed |
|  | Remove autoconnect line from a piping |

3. Click an autoconnect line to add this connection to the piping or to remove it from the piping - depending on the displayed cursor.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection point logic of the associated connection point is adapted automatically.
4. If you want to extend the piping route manually beyond the component at which no suitable potential transfer is set in the connection point logic by default, press [Shift] and keep the key pressed.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Further autoconnect lines are highlighted in color at the corresponding components that limit the piping.
5. Select the desired autoconnect lines. By the addition of further autoconnect lines you can extend the piping route step-by-step to all the accessible connection points on the P&I diagram page.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection point logic of the associated connection points is adapted automatically in the process.
6. Exit the action by using the popup menu item Complete action / Complete the piping route or the [Blank] key.

![](../Pictures/Gui/ALL/info.png)Tips:

- It is also possible to first select a piping definition point (or an object that is assigned to a piping definition) in the graphical editor or in a navigator (pre-planning, piping navigator, etc.) and then to carry out a Highlight piping route command. The piping route is highlighted and the corresponding page is opened, if appropriate.
- You can still change the flow direction of a piping in the P&I diagram with the property Piping: Exchange source and target or with the command Source and target. You can find detailed information in the section "[Route and source / target of a piping](planningri_k_rdp.htm#Quelle_Ziel)".
- Use the special symbols AR1 or AR2 to permanently display the flow direction of a piping route. To do this select one of these symbols in the Insert center dialog in the SPECIAL symbol library and place it on the autoconnecting line of the desired piping. To ensure that the direction arrow points in the correct direction, the selected variant of the symbol may have to be adjusted by means of the Update detailed planning or Highlight piping route functionalities.

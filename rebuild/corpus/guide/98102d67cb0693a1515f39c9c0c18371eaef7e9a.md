# Dialog Clean up project

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Extras > Command group Organize > Project > Command group Optimize > Clean up project

In this dialog you can specify a scheme for the scope of correction. The last settings used are saved for each project.

Overview of the main dialog elements:

Settings:

In this field, you can select a scheme containing the desired correction settings. Click [...] to open the dialog Settings: Clean up. Here you can edit existing schemes or create a new scheme.

# Dialog 3D mounting layout navigator - <Project name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have opened a layout space. Tab Insert > Command group 3D mounting layout > Navigator.
- You have opened an editor such as the graphical editor, the plot frame editor, etc. Tab View > Command group Navigators > Drop-down button Open > 3D mounting layout

In this dialog, the devices present in the project that have a part assigned, are listed and offered for placement in a layout space.

Overview of the main dialog elements:

Filter:

This drop-down list displays all the available filters. A selected filter is automatically activated and is applied to both the tree and the list view. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the [Filter](modaldialogsdb_d_filternnach.htm) dialog. Here you can create, edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

- Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
- Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

Value: <Property>:

Use this field, via [Quick input](modaldialogsdb_k_filter.htm#I_Schnelleingabe), to adjust quickly the value of a filter criterion for a defined and activated filter.

Tree:

Shows all the electrical and fluid power devices available in the open project, whether or not they are already placed in a layout space. The view is identifier-based. Parts without a device tag are grouped in a separate node. Devices that have already been placed are identified by an additional ![](../Pictures/Gui/ALL/all_statusok_as.png) icon. Devices placed in the layout space, but not included in the schematic project, are marked by the ![](../Pictures/Gui/ALL/cabinetgui_placednotinproject_as.png) icon.

(An overview on the most important icons for project data can be found in the [Icons in the Navigators](userinterface_k_iconsnavigatoren.htm) topic.)

List:

Shows all the devices in the open project. The view and sorting of the devices depends on the column configuration selected in the Configure representation dialog.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| New device | Opens the Part selection dialog. Here a part can be selected and placed in the layout space, which is not contained in the project structure. |
| Delete | This menu item is available only if a part placement exists for the function / part. Deletes the selected part placements after a confirmation warning. The parts and functions are preserved. |
| Place | Allows placement of a part which is in the project structure, but not yet in a layout space. It is also possible to select several entries and use Drag & Drop to drag them from the navigator to the layout space. These selected devices can then be simultaneously placed. It is also possible to select a node in the tree view. All devices that are affected by this selection are placed together.  The [connection preview](cabinetgui_h_verbindungsvorschau.htm) can also be used during placement. |
| Go to (graphic) | Shows the selected object in the graphical editor. If an item is now called for placement, a suitable area is automatically selected for it, if the cursor rests on it for 1 second without moving. This is recognizable from the change in color and the appearance of 3D snap points. |
| List with preselection (tree only) | Reduces the number of elements displayed in order to allow for a faster orientation in the list view. If this option is activated, the list view is called up with an automatic filter (preselection) containing the elements that are currently selected. |
| Select in tree (list only) | Displays the marked object in the Tree tab. |
| Configure representation | Opens the Configure representation dialog, where you define which properties are to be displayed in the list and tree view. |

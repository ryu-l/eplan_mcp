# Displaying Fluid Device Tags in the Schematic

The fluid power standard ISO 1219-2 stipulates that DT must have a rectangular frame in the schematic. Eplan Fluid allows you to show and hide this text box. The Draw text box property is available to this purpose in the Display tab in the Properties <...> dialog. In addition to the rectangle, an ellipse or an oval can be used as the box frame. However, this is not norm-compliant.

![](../Pictures/Visualisation/ALL/ftechnic_bmk_mitrahmen_new_AV.png)

![](../Pictures/Gui/ALL/note.png)Note:

Please note that you can also use layer management to add borders to device tags (or to general text on a special layer). To this purpose select the relevant setting for the Text box field for the desired layers in the layer management (command path: Tab Tools > Command group Management > Layers).

# Views in PLC Navigator

The tree view of the navigator dialog PLC - <project name> allows you to choose different views for the display of PLC data.

All PLC data present in the project is displayed in all views, i.e. PLC boxes, all PLC connection points, and function templates. Empty PLC boxes are also displayed, as are PLC boxes containing only function templates.

The following views are available via the popup menu item View:

- DT-oriented: The PLC data is structured by their device tags according to the project structure.
- Address-oriented: The PLC data is structured by addresses within the project structure. This means that the I / O connection points are shown below the PLC address. The associated power supplies are also displayed below the PLC address if the corresponding PLC address is entered at the power supply. A preset icon ![](../Pictures/Gui/ALL/navigatorgui_nonplaced_as.png) indicates whether unplaced I/O connection points are located below the address. In addition, the PLC boxes and connection points are grouped under the relevant CPU if this property is entered at the associated PLC box.
- Channel-oriented: The PLC data is structured by channels within the project structure. That is, the I/O connection points and associated power supplies are displayed under the channel designation. The ![](../Pictures/Gui/ALL/plcgui_plcchannelwithsafty_as.png) icon for the channel shows whether there is a safety-relevant connection point below. In addition, the preceding ![](../Pictures/Gui/ALL/navigatorgui_nonplaced_as.png) icon indicates whether the channel contains unplaced I/O connection points. PLC connection points which do not have a channel designation which has been either determined automatically or entered manually will be arranged according to their DT.
- Rack-oriented: The PLC data is displayed in accordance with the assignment of the PLC cards to the racks. Racks are marked with a preceding ![](../Pictures/Gui/ALL/navplc_rack_as.png) icon, with the PLC cards (![](../Pictures/Gui/ALL/navplc_moduleonrack_as.png) icon) and their bus IDs listed below. The sequence reflects the item numbers of the slots / modules. The functions contained by the PLC cards are displayed below these.  
  PLC cards that are placed on a head station or are integrated into it, are marked with the icon ![](../Pictures/Gui/ALL/navplc_moduleonheadmodule_as.png). PLC cards that are adjoined next to the head station are marked with the icon ![](../Pictures/Gui/ALL/navplc_moduleonrack_as.png). A head station is also always a rack and is therefore marked with the preceding icon ![](../Pictures/Gui/ALL/navplc_rack_as.png). Below a rack first the PLC cards placed on the head station are shown, followed by all further PLC cards.  
  In the case of devices that are located on a sub-slot this is indicated by the fact that the sub-slot is displayed behind the slot number, separated by a decimal point, for example 2.1:=EB3+ET1-A99.
- Drive-oriented: The PLC data is structured by drives within the project structure. Drives are identified by the preceding icon ![](../Pictures/Gui/ALL/navplc_drive_as.png). The functions are displayed below the hierarchy levels "Configuration project", "Drive" and "Station ID". Functions that are not assigned to any drive are also displayed here. Prerequisite for this is that the functions are assigned to a configuration project and / or a station.

With the popup menu item Configure representation you can determine which properties in a tree view of a specific view are displayed.

![](../Pictures/Gui/ALL/info.png)Tip:

In the rack-oriented view you can additionally display the function text of the PLC box at the rack. To this purpose the "Function: PLC box (rack-oriented view)" object is now available in the Configure representation dialog. For this object click [...] in the Block format field to specify the desired format and, if necessary, a separator. In the Format dialog, double-click in the list of available format elements on the entry "General function" and select the "Function text (automatic)" entry in the subsequent dialog Format: Block property.

If you wish to limit the display to certain data, you can use a filter.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

In the address-oriented view, if you wish to view only PLC connection points which have a PLC address, filter by the property PLC address with the value blank. To do this, go to the PLC - <project name> dialog, click [...] next to the Filter field, and specify the following settings in the Filter dialog:

| Active | Negated | Criterion | Operator | Value |
| --- | --- | --- | --- | --- |
|  |  | PLC address | <> |  |

To view only I / O connection points in the address-oriented view, filter by the function group PLC connection point, I/O, 1 connection point. To do this, go to the PLC - <project name> dialog, click [...] next to the Filter field, and specify the following settings in the Filter dialog:

| Active | Negated | Criterion | Operator | Value |
| --- | --- | --- | --- | --- |
|  |  | Function group | = | PLC connection point, I/O, 1 connection point |

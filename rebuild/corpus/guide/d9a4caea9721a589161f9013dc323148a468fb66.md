# Creating User-Defined Property Configurations

Wherever the properties of an object are listed in a table (project, page, device properties, etc.), you have the opportunity to create separate property configurations. Properties from different groups can be combined in this way and saved in a user-defined property configuration.

Precondition:

You have opened the properties for an object, for example the Properties tab of the project properties in the Backstage view.

1. Select the "User-defined" entry from the Category drop-down list.
2. Select the Configure popup menu item.
3. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) next to the drop-drop-down list Scheme in the Configure properties dialog.
4. Create a new scheme and click [OK].
5. Edit the properties, i.e. add further properties or delete any properties that are not required.
6. Use the arrow buttons to change the order of the properties when they are displayed.
7. Click ![](../Pictures/Gui/ALL/all_save_as.png) (Save) to save the properties selected under the scheme name. Or click ![](../Pictures/Gui/ALL/all_export_as.png) (Export) to export the property configuration and make it available to other users.
8. Click [OK].

The schemes for user-defined property configurations created by you are project-dependent, meaning that they are also saved at the project.

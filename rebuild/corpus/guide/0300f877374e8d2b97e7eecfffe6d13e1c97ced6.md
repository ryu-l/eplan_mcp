# Optimizing Nets Automatically

With automatic optimization, the connections of the net / daisy chains are redesigned in such a way that the following conditions are met:

- All connection points continue to be connected.
- A routing track is determined for which the sum of the wires to be routed is as short as possible.
- No more than two connections terminate in a connection point.
- A daisy chain is always generated.

During automatic optimization the properties (among others the function definition) of the first connection are assigned to all the connections of the net. Fixed connections (jumpers, direct connections, internal connections) remain in place and cannot be optimized.

Precondition:

You have created routing connections. In the layout space navigator or connections navigator, a component is highlighted that contains routing connections (layout spaces, enclosures, mounting surfaces, 3D part placements, connections).

1. Select the following commands: Tab Edit > Command group Optimize nets > Automatic.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the selection does not contain a net, or contains an incomplete net, an error message will be displayed. In this case, repeat and modify your selection.
2. In the Optimize nets automatically dialog, select the settings for net optimization.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The nets are analyzed.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Optimize nets automatically: Preview of result dialog is displayed. The dialog shows the results of the analysis. [OK] will automatically re-route the connections determined by the optimization.
4. In the Optimize nets automatically: Preview of result dialog, click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connections classified as status = "New" are routed in the new routing tracks.

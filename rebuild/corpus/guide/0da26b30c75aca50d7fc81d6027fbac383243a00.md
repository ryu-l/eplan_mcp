# Dialog Bundle connections: Preview of result

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Edit > Command group Routing connections > Bundle. In the dialog Bundle routing connections you have selected the Preview of result check box. Click [OK].

This dialog lists the connections to be modified. You can confirm the new bundle numbers with [OK] or modify the new bundle numbers manually.

Overview of the main dialog elements:

The table contains the following columns:

- Row: Contains a consecutive row number.
- Source: Source of the connection.
- Target: Target of the connection.
- Bundle: Bundle number that already existed at the connection prior to the automatic bundling.
- New: New bundle number of the connection assigned by automatic bundling. The number can be modified manually here in order to assign the connection to another bundle.

# Calculating the Total Weight of Enclosures

Eplan Pro Panel allows the calculation of the total weight of each enclosure placed in a layout space project-wide. The total weight of an enclosure consists of the weight of the enclosure as well as the weights of all "normal" parts, all length-adjustable items (for example, mounting rails) and connections.

### Adding weight specifications at parts

For correct calculation of the total weight of an enclosure, corresponding weight specifications must be entered at the parts to be placed. Check this in the parts management.

1. Select the following commands: (Tab Master data > Command group Parts > Management).
2. Bring the Properties tab to the front.
3. Check whether values are entered in the part property Weight (full) (ID 22233) at all the parts to be placed such as enclosures, terminals, contactors, etc. and at length-variable items such as mounting rails and wire ducts.
4. Add missing weight specifications for the parts in the part property Weight (ID 22046). (The value assigned in this property is entered automatically into the Weight (full) (ID 22233) property required for the total weight calculation after the parts data have been saved.)
5. Also check whether values are entered in the Weight / length (ID 22067) part property at the connection parts to be placed and supplement this information if they are missing.
6. Close the parts management.
7. In the subsequent dialog answer the question whether you want to perform a parts data synchronization of the parts database with [Yes].

### Performing a calculation

Preconditions:

- You have opened a project.
- You have opened the layout space navigator and a layout space.

1. Use the Insert center to place all parts with weight specifications in the layout space.
2. Mark the layout space in the layout space navigator and route all routing connections.
3. Select the following commands: Tab Tools > Command group Reports > Drop-down button [Generate project reports] > Calculate total enclosure weight.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The total weight of each enclosure in the project is calculated on the basis of the entered values and is output in the Total weight (ID 36108) property of the part placement of the enclosure.

# Drawing Potential Definition Points or Connection Points

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the following commands: Tab Insert > Command group Cables / connections > Drop-down button Connection > Potential definition point or Potential connection point.
2. Place the potential definition point or connection point in the schematic.
3. In the properties dialog, in the Potential definition tab, enter the potential properties (and other properties in the other tabs if required).
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The properties are assigned to the connections running through the potential definition point or the connection joined to the potential connection point.

![](../Pictures/Gui/ALL/info.png)Tip:

You can insert multiple potential definition points at the same time by holding the left mouse button down and pulling the cursor over multiple autoconnect lines. At each autoconnect line intersected, a potential definition point is then placed.

# Creating planning objects as devices

1. Select the following commands: Tab Pre-planning > Command group General > Navigator.
2. Highlight the project, a structure segment or an existing planning object, and select the popup menu item New device (planning object).
3. Select a part from the Part selection dialog.
4. Select the desired segment definition in the dialog Select segment definition. This dialog is opened if a structure segment is marked and several segment definitions for planning objects exist in the project.
5. Enter the desired data for the new planning object in the Properties <...> dialog.  
     
   ![](../Pictures/Gui/ALL/arrow_14x14.png) The part number is displayed in the Part tab and the function templates of the part in the Templates tab.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) A planning object is created with the corresponding properties.

### Creating planning objects via Drag & Drop of parts

Preconditions:

- You have opened the part master data navigator or device list.
- You have opened the pre-planning navigator.

1. Highlight a part in the part master data navigator or in the device list.
2. Drag the part with the mouse to the pre-planning navigator, and drop the part on a structure segment or planning object.
3. Select the desired segment definition in the dialog Select segment definition. This dialog is opened if a structure segment is marked and several segment definitions for planning objects exist in the project.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Properties <...> dialog opens, and the part number is carried over to the Part tab.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The function templates of the part are displayed in the Templates tab.
4. Enter the desired data for the new planning object in the Properties <...> dialog.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Below the highlighted structure segment or planning object, a planning object with the corresponding properties is created.

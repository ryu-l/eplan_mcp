# Creating Your Own Identifier Sets

In Eplan you can create your own sets of identifiers taking into consideration different standards, countries, and customers. We recommend that you create and maintain the identifier sets in the basic project.

Precondition:

You have opened a project.

1. Select the following commands: File > Settings > Projects > "Project name" > Devices > Numbering (online). Click [...] next to the Identifiers field.
2. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the Identifier dialog next to the Scheme field.
3. In the New scheme dialog, enter a meaningful name for the new scheme in the Name field and click [OK].
4. Enter the identifiers for the individual functions in the Identifier column in the individual cells. Identifiers can consist of multiple characters.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The identifiers you entered are saved.

### Select identifier sets

Precondition:

You have opened a project.

1. Select the following commands: File > Settings > Projects > "Project name" > Devices > Numbering (online).
2. In the Identifiers field select the desired identifier set from the drop-down list.
3. Select the desired subclass from the drop-down list in the Identifier subclasses field.
4. Or click [...] in the Identifier subclasses field and define a new class in the Identifier subclasses dialog that opens.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The corresponding identifier / subclass is used for creating a function.

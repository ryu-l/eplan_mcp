# Tab Potential definition

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have selected a potential definition point in the graphical editor. Popup menu item Properties. In the Properties <...> dialog, select the Potential definition tab.
- Tab Insert > Command group Cables / connections > Drop-down button Connection > Potential definition point. In the Properties <...> dialog, select the Potential definition tab.

In this tab, you can set the properties for a potential definition point.

Overview of the main dialog elements:

Name of potential:  
Signal name:

Enter the name for the potential / signal here. Click [...] in order to open the Select potential / signal dialog. The potential names and the associated signal names existing in the project are presented here for selection.

If the Name of potential field is empty, then the signal entered under Signal name is itself a potential. If both fields are filled in, then this is a signal. If a potential is entered in the Name of potential field which doesn't exist or is a signal, an error message is displayed and the project settings are used.

Cross-section / diameter:  
Cross-section / diameter unit:

The connection cross-section or diameter is adopted from the parts management and can be used as filter criteria when selecting devices. Click [...] to open the Cross-sections / diameters dialog and select a cross-section / diameter (with the associated unit) from the list.

If you selected a predefined cross-section / diameter from the Cross-section / Diameter field, the associated unit is automatically transferred to the Cross-section / diameter unit field. Use the drop-down list to select another unit. An overview of the possible units can be found in the section "[Connections: Units for Lengths and Cross-sections](connectionbrowsergui_k_einheitenverbindungen.htm)".

Color / number:

Here you enter the color or number of the connection; this property identifies the connection. Click [...] to launch the Connection colors dialog and select a color from the list.

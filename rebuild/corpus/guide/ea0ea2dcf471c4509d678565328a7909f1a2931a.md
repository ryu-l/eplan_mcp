# P026077: Bundle diameter too great; connections cannot be bundled with the selected part

### Cause

The total diameter of all routing connections that are to be bundled using the placed cable / tubing protection or cable / tubing tie is greater than the maximum bundle diameter of the cable / tubing protection or cable / tubing tie used.

### Solution

1. Locate the cable / tubing protection or cable / tubing tie in the layout space using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Call the property dialog of the cable / tubing protection or cable / tubing tie, and bring to front the Part tab.
3. Via the parts used, navigate to the part selection, and bring to front the Routing accessories data tab.
4. Check at the part used the value set in the Maximum bundle diameter field.
5. Select a cable / tubing protection or cable / tubing tie whose maximum bundle diameter is greater than the total diameter of all routing connections in the bundle.
6. Close the part selection and the property dialog by clicking [OK] respectively.
7. If required, start a new check run.

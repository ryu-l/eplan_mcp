# Dialog Select revision index

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have generated a revision and have opened a revision project (file extension \*.ell). You have made modifications to a page and opened the Description of page modification dialog. Click [...] next to the Revision index field.

In this dialog you select an existing revision index for the page description.

Overview of the main dialog elements:

The revision statuses already present in the project are presented here in the table for selection.

Select a revision index and exit the dialog by clicking [OK]. The revision name as well as the associated entries for description and reason for change are then transferred to the Description of page modification dialog, where you can change this data.

# P003023: Mismatch between quantity of parts and setting for adding up cable lengths

### Cause

The property Do not use cable when adding up cable lengths is activated at the cable, and additionally the value "0" is entered in the Number of units / quantity field in the Parts tab of the Cable properties dialog.

### Solution

#### Possibility 1

1. Double-click the cable definition line and select the Cable tab in the Properties <...> dialog.
2. Under Properties deselect the check box Do not use cable when adding up cable lengths.

#### Possibility 2

1. Double-click on the cable definition line and select the Parts tab in the Properties <...> dialog.
2. In the Number of units / quantity field enter a value higher than "0" for the cable.

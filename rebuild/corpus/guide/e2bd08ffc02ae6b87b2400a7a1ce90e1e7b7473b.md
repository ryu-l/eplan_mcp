# Generally Translating / Not Translating Texts and Properties

If you do not want to translate all of the texts and properties in the project, you can generally exclude texts and properties from the translation. These settings are stored on a per project basis.

Precondition:

You have opened a project.

1. Select the following commands: File > Settings > Projects > "Project name" > Translation > Extent.
2. To select text elements for translation, select the Free texts check box. (Such "Free texts" are inserted in the schematic by using the following command path: Tab Insert > Command group Text > Text.)
3. To select path function texts for translation, select the Path function texts check box.
4. From the Extent drop-down list select an extent so that the texts whose contents are generated from describing properties of the respective extent are translated.
5. To select a property for the translation, select the check box in front of the desired property.

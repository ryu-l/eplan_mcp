# P004010: Rack '<x>' is unknown

### Cause

A non-existent rack name was entered for a slot.

### Solution

#### Possibility 1

Create a new rack with a suitable designation.

#### Possibility 2

Enter an existing rack name.

---

  

If required, start a new check run.

# Action: XCabCalculateEnclosureTotalWeightAction

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| ProjectName | Project name with complete file path (optional). If the specified project is not open, it is automatically opened when this action is performed and closed again when the action is complete.  Without valid specification the currently open project is used. |
| DatabaseId | Project ID of a project (optional).  If this parameter is used, the project must be opened in Eplan Electric P8 before the action is executed.  Without valid specification the currently open project is used.  If the ProjectName parameter is specified, the DatabaseID parameter is ignored. |
| CabinetTotalWeight | Total weight of an individual enclosure. |

# P020039: The DT format for '<x>' was changed

### Description

You have run a project comparison, checking the structure of the test project (incoming project) against that of the comparison project and differences were found.

This message occurs when the DT format of a particular device type has changed in the project to be checked. (Mark the project in the page navigator, select the popup menu item Properties, select the command Structure in the Information Backstage view.) The device type whose DT format has changed is output as <x>.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

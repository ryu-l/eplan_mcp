# P001010: Terminal strip definition missing

### Cause

You created a terminal without terminal strip definition in the terminal strip navigator or placed it in the schematic.

### Solution

#### Possibility 1

1. Select the terminal in the terminal strip navigator.
2. Select the New popup menu item.
3. Branch to the function definition Terminal strip definition in the tree view of the subsequent dialog (via the nodes Electrical engineering > Terminals and plugs > Terminal strip definition > Terminal strip definition).
4. Click [OK].
5. Assign the DT to the terminal in the terminal strip definition in the Displayed DT field in the dialog Properties <...>.

#### Possibility 2

1. Place a terminal strip definition in the schematic by using the Symbols object type of the Insert center.
2. Assign the DT to the terminal in the terminal strip definition in the Displayed DT field in the dialog Properties <...>.
3. Click [OK].

#### Possibility 3

1. Select the terminal in the terminal strip navigator.
2. Select the Generate terminal strip definition popup menu item.
3. Click [OK] in the property dialog that is opened.

#### Possibility 4

Use the cleaning up of projects.

1. Select the following commands: File > Extras > Command group Organize > Project > Command group Optimize > Clean up project
2. In the Clean up project dialog select the [...] button next to the Settings field.
3. In the following dialog click the Terminals node in the list of the data to be corrected and activate the Add missing terminal strip definitions check box.
4. Confirm your entries.

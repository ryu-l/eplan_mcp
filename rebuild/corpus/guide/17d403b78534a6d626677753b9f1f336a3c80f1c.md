# Tab Labeling

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > Company > Wire fabrication > "Machine" > Tab Labeling
- File > Export > Command group Manufacturing data > Wire fabrication > "Machine". Click [...] next to the Scheme field. Select the Labeling tab.

In this tab you specify the labeling information for the single conductors to be manufactured on the wire fabrication machines Schleuniger Easy ProductionServer, Rittal - Wire Terminal WT and Komax - Zeta. Here, you define the spacing and positions of the texts to be printed, select the text contents required for identifying the single conductors and specify the desired formatting of the texts. Up to three different texts for labeling the wires are transferred to all three machines, whereby individual positions can also remain empty. All distances or length values can be specified in the units mm or inch.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Overview of the most important dialog elements for Schleuniger - EASY ProductionServer:](javascript:void(0);)

Labeling connection start:

Text at the connection start of the wire.

Labeling connection end:

Text at the connection end of the wire.

Labeling continuous text:

Text that is printed constantly and repeatedly at a specified distance.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Overview of the main dialog elements for Rittal - Wire Terminal WT:](javascript:void(0);)

Print text Source:

Text at the first end of the wire that is connected to the source item.

Print text Target:

Text at the second end of the wire that is connected to the target item.

Print text Center:

Text that can be output in the center of the wire.

Hierarchy level "Single conductor":

Settings for direct printing of single conductors are available in this hierarchy level:

![](../Pictures/Visualisation/ALL/productionwiringgui_wireprintingexample_as.png)

|  |  |
| --- | --- |
| A | Connection start |
| B | Connection end |
| C1, C2, C3 | Text 1, Text 2, Text 3 |
| D1, D2, D3 | Distance text 1, Distance text 2, Distance text 3 |
| E | Section Continuous text |
| F | Continuous text |
| G | Text spacing |

![](../Pictures/Gui/ALL/note.png)Note:

If you do not enter a measuring unit, "mm" is assumed. If you want to specify the length in "Inch", enter the measuring unit explicitly. During the export the conversion into "mm" required for the machine is then carried out.

Print labeling: Select this check box if the texts are to be printed directly on the single conductors.

Connection start / Connection end:

- Text 1 to Text 3: Use the dialog Select format elements to select the property values to be used for printing the three possible texts at the connection start and connection end of the single conductors and additionally specify the format of the texts.
- Distance text 1 to Distance text 3: Here, you determine the spacing for the three possible print texts in relation to the connection start and the connection end of the single conductors.

Print continuous text: If you want to print a text on the single conductors that repeats itself constantly at a specified interval (continuous text), select this check box.

Continuous text: Use the dialog Select format elements in the value field to define which property value is to be printed as continuous text and in which format this text is to be printed on the single conductors. A maximum of 100 characters can be output. The default value is 39 characters.

Text spacing: If the labeling is printed on the wire as continuous text, you must enter the distance between the individual blocks of text here.

From connection length: Enter the length from which the continuous text is to be printed on the single conductors.

"Marker tube" hierarchy level:

In this hierarchy level, settings are available for the printing of marker tubes that are moved by the machine over the single conductors at the connection start and / or connection end:

![](../Pictures/Visualisation/ALL/productionwiringgui_tubemarking_as.png)

Print and push on: Activate this check box if a printed marker tube is to be pushed on respectively at the connection start and/or connection end of the single conductors.

Connection start / Connection end:

- Text line 1 / Text line 2: Use the dialog Select format elements to select the property values to be used as text for the two-line possible printing of the marker tubes at the connection start and connection end of the single conductors and additionally specify the format of the texts.

Hose length: Specify the length of the marking hose that - shaped into a label - is pushed over the single conductors at the connection start and connection end.

"General" hierarchy level:

General settings for printing single conductors are available in this hierarchy level:

Routing direction up to Routing direction right: Fields for texts that are to be printed on the single conductors in order to specify the individual routing directions.

Maximum number of characters: Enter the maximum number of the characters that a single text can have here. The default value is 39 characters.

Invert rotation of the text: The print text on the single conductors is always automatically rotated so that it can be read horizontally or from the right. This depends on the rotation of the item and on the direction from which the single conductors are connected to the item (from the left, from the right, from above or from below). Depending on the machine, it may be necessary to reverse this rotation. In this case, activate the check box.

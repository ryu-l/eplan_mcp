# Deleting Connection Designations

Precondition:

You have selected a connection in the graphical editor, or in the Connections - <Project name> navigator dialog. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog.

1. Select the following commands: Tab Connections > Command group Connections > Drop-down button Enter designation > Delete designations.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Once you have called up the command, the connections are first automatically generated new.
2. Select a scheme from the drop-down list in the Settings field of the Delete connection designations dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The filter settings defined in this scheme are taken into account when deleting the connection designations.
3. If you wish to change the filter settings, click [...] next to the Settings field.
4. Carry out the desired filter settings in the "Filter" tab in the dialog Settings: Connection numbering. Select the appropriate check boxes for the desired connection types and click [OK].
5. In the Delete connection designations dialog use the radio buttons to specify whether you only want to delete the connection designations or also the empty connection definition points.
6. Activate the Retain "manually set" check box to retain the alignment and formatting for connection definition points with the Manually set property to not delete them, and to retain their designation.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) In accordance with the settings the connection designations and â if selected â the empty connection definition points are deleted from the project.

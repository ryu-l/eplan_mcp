# XML Export / Import: Tags and Associated Attributes

The following tables list the tags used for export and import, their attributes, and additional information. Here, the data types in the "Type" column have the following meanings:

Bool

"0" or " " mean "no", "false", or "off", "1" means "yes", "true", or "on".

Integer / Long

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

"", "0", "1", "2", or "-5"

"" means the same as "0".

For attributes of a selection list, only certain values may be used which can be selected in parts management. An overview of the valid values can be found in the section [Overview of Selection Lists](xmlexport_o_sellists.htm).

Double / Currency

The decimal separator is the period.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

"1.99" or "2.5"

"" means the same as "0".

Text

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

"This is a text" or "".

Multilingual text

Language parts in a multilingual text are defined starting with the language code and ending with a semicolon. Between the language code and the text there must be an "@".

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

de\_DE@Schütz; en\_US@Contactor;nl\_NL@Relais;

### <partsmanagement>

| No. | Attribute | Type | Property | Remark |
| 1 | count | Long | Number of parts |  |
| 2 | length-unit | Text | Unit length | Unit in which lengths are imported, for instance "mm" or "inch". Optional, default "mm". |
| 3 | weight-unit | Text | Unit weight |  |
| 4 | type | Text | Type | Type of parts management. Currently the only supported value is "Eplan.PartsManagement". Optional. |
| 5 | build | Text | Build number | Build number at the time of export. Optional. |
| 6 | version | Text | Program build number |  |

### Part properties <part> / <variantx>

![](../Pictures/Gui/ALL/note.png)Notes:

- The attribute P\_ARTICLE\_PARTNR must only be defined for the <part> tag.
- The P\_ARTICLE\_PARTTYPE attribute must be set to the value "1" ("Component"), "4" ("Assembly") or "5" ("Module").
- Attribute P\_ARTICLE\_SUBCRAFT\_ELECTRICAL\_#index: Multilingual; if you yourself have created a subtrade under a trade, this is output in the form P\_ARTICLE\_SUBCRAFT\_<Trade>-1="??\_??@<Subtrade name>;" (for example P\_ARTICLE\_SUBCRAFT\_ELECTRICAL-1="??\_??@test;" for the first subtrade under "Electrical engineering" with the name "test"). As the properties are indexed, the index is output with a "minus".

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

P\_ARTICLE\_GROUPSYMBOLMACRO   
Example: "C:\macro.ema" or "$(MD\_MACROS)\Macro.ema"

P\_ARTICLE\_ECABINET\_MACRO   
Example: "C:\texture.jpg" or "$(MD\_IMAGES)\texture.jpg"

# Dialog Settings: Contact image on component / Contact image in path

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Settings > Projects > "Project name" > Cross-references / contact image > Contact image on component and Contact image in path.

In this dialog you define the defaults for displaying contact images on the component / in the component path. These settings are normal for motor overload switches and contactors, for example.

Overview of the main dialog elements:

Display own cross-reference:

If this check box is selected, then the cross-reference of the current component is also displayed in the contact image.

Display as symbol image:

If this check box is selected, then a symbol contact image symbol is displayed at the component. In this representation type, all of the components are displayed, only the main function is suppressed by default.

Default:

Select this option if you want to define the defaults for displaying contact images on the component or for displaying contact images in the schematic path of the component. All the settings between this option and the Embedded form option are then activated for selection / activation.

Arrange vertically:

If this check box is selected, the contact image is arranged vertically.

Display cross-reference texts vertically:

If this check box is selected, the cross-references are displayed vertically.

Underline cross-reference texts of NC and change-over contacts:

If this check box is selected, the cross-references of NC contacts and change-over contacts are highlighted with underlining.

Decrease cross-reference texts and connection point designations:

If this check box is selected, the cross-reference texts and connection point designations are shrunk; this makes the display easier to read.

Show symbols:

If this check box is selected, then symbols, instead of the entries, are displayed in the contact image.

Show cross-references on the left:

If this check box is selected, then the cross-reference is shown to the left of the symbol.

Hide left-hand / right-hand connection point designation:

If this check box is selected, then the left or right connection point designation is not displayed; this can also improve the readability of the display.

Show in tabular form:

If this check box is activated, the page number and column designation are displayed in the cross-reference in tabular form where the layout is influenced by the Arrange vertically setting; the table headings for NC contacts and NO and contacts are then taken from the setting Contact image table: Labeling (command path: File > Settings > Projects > "Project name" > Cross-references / contact image > General).

Table cross with variable length:

If this check box is activated, the table cross is automatically adjusted to the maximum size of the contact image entries. In this case the setting Contact image table: Width / height is not taken into consideration (command path: File > Settings > Projects > "Project name" > Cross-references / contact image > General).

Rotation:

The contact image is normally located vertically beneath the appropriate device. If desired, select the angle by which the contact image should be rotated from the drop-down list.

Display of 1st / 2nd Part number:

Select from this drop-down list whether, and at what position, each part number is to be displayed in the cross-reference / contact image. (The setting always follows the alignment of the contact image, and the part numbers are displayed centered in multi-line format.)

Display of 1st / 2nd part type:

Select from this drop-down list whether, and at what position, each part type is to be displayed in the cross-reference / contact image. (The setting always follows the alignment of the contact image, and the part types are displayed centered in multi-line format.)

Embedded form:

Select this option if you want to create contact images with the use of embedded forms. All the settings between this option and the Default option are grayed out and can no longer be activated.

Form:

From this drop-down list select the embedded form for creating form-based contact images.

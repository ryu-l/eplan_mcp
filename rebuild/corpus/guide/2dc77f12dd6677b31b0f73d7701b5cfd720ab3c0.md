# Dialog "Settings: Date / time / numbers"

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Settings > Projects > "Project name" > Display > Date / time / numbers.

In addition to accepting the operating system time and date formats, this dialog allows you to define the format on a project-specific basis. For example, this can be useful in cross-border projects; in this case, a standardized date format can then be used.

Overview of the main dialog elements:

Operating system format:

Select this option when the time and date format of the operating system is to be used. A preview of the format is shown in the Preview field below.

Project-specific format:

Select this option when the time and date format deviates from that of the operating system. You define the details in the fields below, whereby the Preview field shows an updated preview of the currently defined format. The following settings are available:

- Date format: Select the desired date format from the drop-down list, e.g., "DDMMYYYY" to display "05.01.2007", or the entry "DMYY" to display "5.1.07".
- First date separator / Second date separator: Select one of the possible separators from the drop-down list, i.e., ".", "/" or "-".
- Time format: Select the desired time format from the drop-down list, e.g., "HHMMSS" to display "07:05:51", or the entry "HMM" to display "7:05". A small "h" represents the time in 12 hour format, i.e., "1:05" for "13.05" and "1:05".
- Time separator: Select one of the desired separators from the drop-down list, i.e. "<space>" or ":".
- AM symbol / PM symbol: Select one of the possible symbols for morning and afternoon from this drop-down list, for example AM and PM.

For numbers output unit with blanks:

Select this check box if you want numbers that are output with a unit, such as kg, to have a blank before the unit. If this check box is deselected, no blank is inserted between the number and the unit.

# Macro Collection for the Insert center

For an optimized workflow with macros the Insert center works with a macro collection, which stores all the currently set window and symbol macros in a type of Clipboard.

### Automatic generation of the macro collection

The following cases are automatically generated in the macro collection:

- When opening a page or a layout space when the Insert center dialog is shown and no macro collection exists in the set macro directory
- When switching between directories for macros in the user-specific settings, if no macro collection exists in the new directory

### Updating the macro collection

The following cases are automatically updated in the macro collection:

- When window or symbol macros are created
- When macros are generated in macro projects
- When macros are generated from DXF / DWG files or from 3D files
- When macros are imported, for example from the Eplan Data Portal

The macro collection can be manually updated at any time. The following command is available to this purpose: Tab Master data > Command group Macros > Macro collection.

During the update of the macro collection the message "The macro collection is updated" is shown in the lower right-hand section of the status bar.

### Deactivating automatic checking of the macro directories

By default, the macro directory is automatically checked for changes. If the macro directory is located in a network, this can result in a high utilization of the network. In such a case you can deactivate the automatic check.

To activate or deactivate the check, the setting Automatically check macro directory for changes is available in the Settings: Macro collection dialog (command path: File > Settings > User > Management > Macro collection). The check box is activated by default.

If the check box is deactivated, the macro directories in a network are no longer automatically checked for changes. Changes carried out by other users or changes carried out outside of Eplan in the file directories are then no longer recorded. If a manual change is carried out within Eplan (for example creation of a macro), the macro collection is nevertheless updated automatically.

![](../Pictures/Gui/ALL/note.png)Note:

In the project-specific settings you can specify which [Company standards and standards](macrosgui_k_standards.htm) are to be considered when inserting schematic macros or devices. If you have made one or both settings, a corresponding message is received. The macro collection is updated after confirming the message.

![](../Pictures/Gui/ALL/info.png)Tips:

- For the optimum interaction with the Insert center and the macro collection we recommend observing the following steps after the installation of Eplan:  
  1. First install all the required Eplan add-ons.  
  2. Update the master data.  
  3. Open a project page or a layout space. The macro collection is automatically generated in the process.
- If a network directory that several users can access is specified for the macro directory, the search for macros in the Insert center can take a relatively long time. By specifying a local directory for the macro collection that deviates from the specified macro directory, you can ensure that the search for macros in the Insert center takes place quicker. You can set such a directory in the Settings: Macro collection dialog in the Database directory field.

### Exceptions for macro directories that are not included in the macro collection

Exceptions can be defined for window macro and / or symbol macro directories which are not to be included in the macro collection. This affects, for example, macro directories for the software product Eplan Engineering Configuration (EEC). The macros included in this are not intended for manual insertion. To exclude these macro directories, the Settings: Macro collection dialog provides the setting Exceptions (command path: File > Settings > User > Management > Macro collection).

A macro directory that is not included in the macro collection is specified in a row of the Directory column. Click ![](../Pictures/Gui/ALL/all_selectdirectory_as.png) to open the dialog for choosing a directory and then navigate to the desired directory. After clicking a cell in the Directory column, you can also manually enter the directory path for a macro directory. You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

The macro directories specified in this settings dialog are then not displayed as folders in the Insert center.

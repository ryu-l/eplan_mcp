# P004085: Missing data type

### Cause

The value of the Data type property is empty at a PLC connection point that is an analog or digital input or output.

### Solution

#### Possibility 1

1. Locate the PLC connection point in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Open the property dialog of the PLC connection point.
3. Bring the first tab to the front.
4. In the properties table click the value field of the Data type property.
5. Use the [...] button to select the required data type.
6. Click [OK].

#### Possibility 2

Use the cleaning up of projects.

1. Select the following commands: File > Extras > Command group Organize > Project > Command group Optimize > Clean up project.
2. In the Clean up project dialog select the [...] button next to the Settings field.
3. In the following dialog click the PLC node in the list of the data to be corrected and activate the Set data types check box.
4. Confirm your entries.

![](../Pictures/Gui/ALL/note.png)Notes:

- PLC connection points with the function definition PLC connection point, multi-function are also taken into consideration during this check run in as far as the type of signal in the connection point logic is set correspondingly to Digital input or Digital output or Analog input or Analog output.
- PLC connection points with the function definition PLC connection point, general and PLC connection point, variable are not taken into consideration during this check run.

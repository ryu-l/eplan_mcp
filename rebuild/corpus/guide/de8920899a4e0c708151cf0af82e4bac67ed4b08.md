# Dialog Format: Separator (offline numbering)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- File > Settings > Projects > "Project name" > Devices > Numbering (offline)
- You have selected one or more pages in the page navigator. Or you have selected one or more devices in the Device navigator. Tab Devices > Command group Devices > Number > Button [Settings] > Numbering.

You have selected a user-defined scheme in the dialog Settings: Numbering (offline). In the Available format elements or Selected format elements field double-click the format element "Separator".

In this dialog, you define the "Separator" format element for device numbering.

Overview of the main dialog elements:

Blank:

If this option is activated, then a space is used as the separator. The number of spaces is entered in the field Number of characters.

Other characters:

If this option is activated, you can enter the required character combination to be used as the separator in the field below. Any digits, letters, and special characters can be used.

Number of characters:

This field is available if the option Blank is selected. The number in this field specifies the number of spaces to be displayed as separators in the numbering format. If you select Other characters, this field is grayed out and displays the specified number of characters.

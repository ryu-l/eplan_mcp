# P005092: The part '<x>' entered at the connection is not contained in the pipe class '<y>'

### Cause

In the P&I diagram a part number is entered at a connection that does not match the part number that belongs to the selected pipe class.

### Solution

#### Possibility 1

1. Select the following commands: Tab Pre-planning > Command group General > Segment templates.
2. In the segment template navigator call up the property dialog of the pipe class that is specified in the placeholder <y> of the message.
3. Bring the Parts tab of the pipe class to the front.
4. In the left-hand table supplement the part number <x> that is output in the message text of the connection.
5. If required, start a new check run.

#### Possibility 2

1. Locate the connection in the P&I diagram using the Go to (graphic) button that is provided in the popup menu of the Message management dialog.
2. Launch the property dialog of the connection.
3. On the first tab select a pipe class that contains the part number <x> which is output in the message text.
4. If required, start a new check run.

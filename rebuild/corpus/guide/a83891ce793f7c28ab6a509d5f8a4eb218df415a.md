# Globally Editing the Properties for all Representations of a Main Function

A main function can be represented more than once in the project, as a distributed single-line, multi-line, overview, pair cross-reference function, and / or a P&I diagram function. The "Properties (global)" feature allows you to change the common properties for all function representations of one main function at the same time, for example the function text of all function representations of a coil.

![](../Pictures/Gui/ALL/note.png)Note:

This procedure does not apply to the Displayed DT property. If you are using the Properties (global) editing mode and change the Displayed DT of the main function then the DT is changed for all function representations of the device.

Preconditions:

- You have opened a project.
- You have opened the graphical editor or the device navigator.

1. Mark the function representation of a main function in the device navigator or in the graphical editor, and select the Properties (global) popup menu item.  
   If you have activated the Properties (Global) Mode (command path: Tab Edit > Command group Options > Global), double-click the function representation of a main function.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the Properties (global): <...> dialog, the <Function category> (device) tab is labeled with the respective function category of the corresponding function definition, for example "Coil" and the additional "(device)" for devices.
2. Change the desired properties of the main function.
3. Click [OK].
4. Press [F5] to update.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The properties are changed at all associated function representations of the selected main function.

![](../Pictures/Gui/ALL/note.png)Note:

No global properties are displayed in the Display, Symbol / function data and Format tabs. In these tabs you can only edit the selected function representation of the main function. All other associated function representations are not changed.

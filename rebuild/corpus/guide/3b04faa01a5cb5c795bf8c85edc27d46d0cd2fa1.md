# Reporting on Project Options and Placeholder Objects

Project options and placeholder objects can be output to reports and output at manufacturing data export / labeling.

In the Project options overview all project options available in the project can be output. You can also use a filter to output only the active project options.

Project options objects have the following properties:

- Project option group: Name
- Project option group: Description
- Project option: Name
- Project option: Description
- Project option active (Yes / No)
- Project option section: Name (indexed)
- Project option section: Description (indexed)
- Placeholder object name (indexed)
- Placeholder object: Last selected value set (indexed)
- Placeholder object: Placement (indexed).

In the Placeholder object overview all placeholder objects available in the project can be output. Placeholder objects belonging to a section can be filtered out.

Placeholder objects have the following properties:

- Placeholder object name
- Last selected value set
- Placement.

If you have generated a report of project options or placeholder objects, and then remove the project options and placeholder objects from the project (e.g. through compression), do not subsequently update the reports.

The reports will no longer be automatically updated when no project options or placeholder objects exist in the project.

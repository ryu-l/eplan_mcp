# Creating an Identifier when Inserting New Pages, Device Tags, and Macros

If the creation of new pages or devices or the insertion of pages and macros adds new structure identifiers to the project, the new structure identifiers are inserted in the table of identifiers according to the user settings for identifiers (option Enter new identifiers in alphabetical order or Add new identifiers to the end). In structure identifier management, you can subsequently access the identifier data of the selected identifier blocks, and, for example, modify their sorting.

![](../Pictures/Gui/ALL/note.png)Note:

The project setting Conversion to upper-case (command path: File > Settings > Projects > "Project name" > Device > General) is used when generating new identifiers.

### [ClosedCreate identifiers during page processing](javascript:void(0);)

When creating a new page or when renaming / moving an existing page, you can specify a new structure identifier which does not yet exist in the database. How the new structure identifier is sorted in the list by default (alphabetically or at the end of the list) depends on the identifier settings which have been made. Existing structure identifiers cannot be changed here.

Precondition:

You have opened a project in which identifier blocks are used in the project structure, for instance "Function designation" and "Location designation".

1. Select the following commands: Tab Home > Command group Page > New.
2. If you would like to obtain an overview of the existing structure identifiers, click [...] next to the Full page name field of the New page dialog.
3. In the Full page name dialog, click [...] next to the corresponding box for the identifier block.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The <Identifier block> dialog lists all existing structure identifiers. In the List tab, the field contents Complete structure identifier and Structure description are displayed.
4. Click [Cancel] to close the list.
5. In the Full page name dialog, enter a new structure identifier into one of the fields for the identifier block.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the New page dialog, the full page name is correspondingly updated.

### [ClosedCreate identifiers during device processing](javascript:void(0);)

When creating a new device, cable, etc. or when renaming / moving an existing one, you can provide a new structure identifier which does not yet exist in the database. How the new structure identifier is sorted in the list by default (alphabetically or at the end of the list) depends on the identifier settings which have been made. Existing structure identifiers cannot be changed here.

Preconditions:

- You have opened a project in which identifier blocks are used in the project structure, for instance "Function designation" and "Location designation".
- You have opened a schematic page.

1. Select the following commands: Insert center > Breadcrumb trail Home > Symbols. Using the folder structure navigate to the desired symbol and select it by clicking the preview tile.
2. Position the symbol using the mouse.
3. In the Full DT field of the component-specific Properties <...> dialog, click [...].
4. If you would like to obtain an overview of the existing structure identifiers, click [...] next to the appropriate field for the identifier block.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The <Identifier block> dialog lists all existing structure identifiers.
5. Click [Cancel].
6. In the Full DT dialog, enter a new structure identifier into one of the fields for the identifier block.

### [ClosedCreate identifiers during macro processing](javascript:void(0);)

When adding macros with devices with identifier blocks you can also enter a new structure identifier which does not yet exist in the database. How the new structure identifier is sorted in the list by default (alphabetically or at the end of the list) depends on the identifier settings which have been made. Existing structure identifiers cannot be changed here.

Precondition:

You have opened a project in which identifier blocks are used in the project structure, for instance "Function designation" and "Location designation".

1. Select the following commands: Tab Home > Command group Page > Drop-down button Page macro > Insert.
2. In the subsequent dialog, select the macro to be inserted and click [Open].
3. In the Adapt structure dialog, specify the handling of page names for the target macro.
4. If you would like to obtain an overview of the existing identifiers, click [...] next to the respective block for the target identifier block.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The <Identifier block> dialog lists all existing identifiers.
5. Click [Cancel].
6. In the Adapt structure dialog, enter a new structure identifier into one of the boxes for the target identifier block (for example for "Function designation" or "Location designation").

# Dialog "Settings: Export NC - DXF" / Dialog "Settings: Export DXF - Copper"

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Export NC - DXF:

- File > Settings > Company > Machining > Export NC - DXF
- File > Export > Command group Manufacturing data > Machining > NC - DXF. Click [...] next to the Machine field.

Export DXF - copper:

- File > Settings > Company > Machining > Export DXF - copper
- File > Export > Command group Manufacturing data > Machining > DXF - Copper. Click [...] next to the Machine field.

In this dialog define the settings for the NC export and copper export in the DXF format.

Overview of the main dialog elements:

Machine:

The delivery scope includes the machine definition named "Default". If you have generated a different machine as a scheme, you can select and edit other machine definitions from the drop-down list.

You can create new schemes, save any changes to a scheme, and copy or delete schemes via the adjacent [Toolbar](schemeconfig_m_schemaschaltflaechen.htm). Schemes can also be imported or exported.

Description:

In this field is the description you entered for the machine in the Description field of the New scheme dialog.

Tabs:

To configure the NC export in the DXF format, you can use the following tabs:

- [Tab DXF general](ncgui_r_dxfallgemein.htm)
- [Tab Items](ncgui_r_dxfbauteile.htm)
- [Tab Drill holes](ncgui_r_dxfbohrungen.htm)
- [Tab Thread](ncgui_r_dxfgewinde.htm)
- [Tab Outlines](ncgui_r_dxfkonturen.htm)
- [Tab Drill exceptions](ncgui_r_bohrausnahmen.htm)

You can use the following tabs to configure the DXF export of copper items:

- [Tab DXF general](ncgui_r_dxfallgemein.htm)
- [Tab Items](ncgui_r_dxfbauteile.htm)
- [Tab Drill holes](ncgui_r_dxfbohrungen.htm)
- [Tab Thread](ncgui_r_dxfgewinde.htm)
- [Tab Outlines](ncgui_r_dxfkonturen.htm)

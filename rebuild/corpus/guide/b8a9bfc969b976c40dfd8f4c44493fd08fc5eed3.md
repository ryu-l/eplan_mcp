# Dialog DT syntax check

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The check is activated in the DT syntax check settings. In the Properties <...> dialog, specify an invalid character as the identifier element and click [OK].

After specifying the device tag properties, Eplan then checks whether the syntax for the specified device tag identifier is correct. If this is not the case, this dialog appears.

![](../Pictures/Gui/ALL/note.png)Notes:

- You specify which characters are permitted in the settings for the DT syntax check.
- A syntax check also takes place when entering the identifier in Structure identifier management.

Overview of the main dialog elements:

Message:

This field, which cannot be changed, shows the identifier and highlights the incorrect elements.

Description:

A descriptive text for the error that occurred is displayed here.

[Settings]:

Opens the dialog Settings: DT syntax check. There you can check, and if necessary, correct your syntax settings.

[<<] / [>>]:

If you click one of these buttons, the next (or previous) incorrect component of the identifier is highlighted. If only one character is invalid, these buttons are grayed out.

[Ignore]:

Ignores all errors, closes the message dialog, and inserts the rejected identifier.

[Cancel]:

Closes the dialog. You return to the property dialog and can correct your entry there.

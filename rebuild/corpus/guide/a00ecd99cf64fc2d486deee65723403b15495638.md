# P020033: Potential <x>: <y>

### Description

You have run a project comparison, checking the Properties of the test project (incoming project) against those of the comparison project and differences were found.

This message occurs when a difference in the properties of a potential (potential definition or potential connection point) was found. The name of the potential is shown as <x>, and >y< indicates whether the potential has been deleted or added, or one of the properties of the potential has been changed.

If you have adjusted the corresponding properties in the incoming project to the properties of the comparison project, update the connections in the incoming project subsequently.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

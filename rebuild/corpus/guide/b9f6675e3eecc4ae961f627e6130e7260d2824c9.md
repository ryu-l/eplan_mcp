# Dialog Settings: Zero Position

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Settings > Projects > "Project name" > Machining > Zero position.

In this dialog you specify the settings for the zero position at the calculation of drilling patterns on length-variable items. These settings are applied during the export of manufacturing data for NC machines. This allows a notably wider spectrum of machines to be controlled sensibly for manufacturing automation.

The zero position designates that side of an item from which the drilling pattern is calculated on the item. Different machines expect this starting point at different points. Therefore this setting has to be customized project-specifically to the machine to be used. Separate settings for horizontal and vertical placement are possible. The settings do not apply for items that are placed at different angles than horizontal or vertical.

Overview of the main dialog elements:

Zero position at horizontal item placement:

- Left: The drilling pattern is calculated starting from the left-hand side (default) of the item.

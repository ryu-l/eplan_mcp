# Inserting Radius Dimensions

To dimension a radius, first select the circle and then specify the position of the dimension line (and the dimension value). The dimension value can be written in any angle on the circle. Regardless of the end point position, the dimension value is always the radius.

![](../Pictures/Visualisation/ALL/gededitgui_dimcircle_av.png)

Preconditions:

- You have opened a project.
- You have opened a project page in the graphical editor.

1. Select the following commands: Tab Insert > Command group Dimensioning > Drop-down list Linear dimension > Radius dimension.
2. Select a circle.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The center of the circle is automatically selected as the dimension starting point.
3. Define the end point of the dimension line and click the left mouse button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the end point is within the circle, a small arrow on the inner edge of the circle will be drawn as the dimension line. If the end point is outside, the dimension line is drawn from the end point to the outer edge of the circle.

![](../Pictures/Gui/ALL/note.png)Note:

Arcs can also be dimensioned in the same manner.

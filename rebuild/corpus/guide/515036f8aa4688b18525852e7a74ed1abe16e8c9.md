# P001028: Distributed terminals have different function definitions

### Cause

In the project there are distributed terminals with different function definitions.

### Solution

1. Locate the relevant terminals in the schematic or device navigator by using the Go to (...) function from the popup menu in the Message management dialog.
2. Call up the dialog Properties for each distributed terminal and there the Symbol / function data tab.
3. In the Function data (logic) group box, click the [...] button next to the Definition field and select the desired function definition for the distributed terminal.
4. Repeat the process for all other distributed terminals and ensure that all the function definitions are the same.
5. If required, start a new check run.

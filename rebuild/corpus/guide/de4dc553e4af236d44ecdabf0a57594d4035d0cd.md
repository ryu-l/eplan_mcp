# P022060: The user-defined property '<x>' (input aid '<z>') contains an invalid value '<y>'

### Cause

You use user-defined properties in the project at objects (pages, macros, functions, etc.) and use a selection list for the assignment of the default values. A default value '<y>' that is not configured in the selection list was assigned to the user-defined property '<x>' by using the input aid '<z>' through a copying action from another project or by inserting a macro.

### Solution

1. Locate the object in the schematic by using the functionality Go to (graphic) provided in the popup menu of the dialog Message management or, if the object is a page, mark the page number displayed in the dialog in the page navigator.
2. Call up the property dialog of the object.
3. Select a valid default value '<y>' from the selection list for the property '<x>' by using the input aid '<z>'.
4. Click [OK].
5. If required, start a new check run.

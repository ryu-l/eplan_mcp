# P008001: The text '<x>' cannot be translated into the <y> language

### Cause

The required entries (keywords) in the respective dictionary language are missing.

### Solution

1. Select the following commands: Tab Tools > Command group Translation > Dictionary.
2. In the Dictionary dialog check the dictionary languages used. If the desired dictionary language is missing in the list of the Management tab, add it by means of ![](../Pictures/Gui/ALL/all_new_as.png) (New).
3. Subsequently select the Edit words tab and select the desired language from the Source language drop-down list.
4. In the Find field select the respective keywords and check whether the respective translation texts are available in the desired dictionary language.
5. If not, create or add the missing keywords in the source language and the associated translation texts in the desired dictionary language by using ![](../Pictures/Gui/ALL/all_new_as.png) (New).
6. Close the Dictionary dialog and translate the texts.

![](../Pictures/Gui/ALL/note.png)Note:

This module-specific message is output during the automatic translation of texts. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

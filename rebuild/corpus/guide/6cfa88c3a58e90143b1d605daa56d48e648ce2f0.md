# Print

Project pages can be printed from the Print backstage view. To this purpose a project has to be opened and project pages have to be marked in the page navigator or in the graphical editor. You can use the print settings to adapt the output of pages to different printers. The following is possible:

- You can print out any selected pages or all of the pages from the chosen project.
- Besides project pages, you can also print symbol libraries, macro projects, plot frames, and forms.
- The print can be in black and white, color, or in gray scales, and can either be sent to a printer or to a file.
- You have the option of changing the output of the project pages by using different settings.
- In the print preview, you can check the effects of your settings before printing. This saves you a lot of paper and time, since no unnecessary test printouts must be made.
- Attached documents can be separately printed. These are external documents inserted into schematic pages via hyperlinks or entered into the parts used on the page.

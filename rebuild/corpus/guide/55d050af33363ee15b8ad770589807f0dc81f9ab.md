# P005061: More than one multi-line connection definition at a single-line connection

### Cause

A single-line connection has multiple connection definition points that contain connection multi-line definition points. This means that connections are defined on the Interconnect devices tab in the property dialog of both single-line connection definition points.

### Solution

1. Enter the multi-line connection definitions only at one connection definition point.
2. Delete the multi-line connection definitions at the other connection definition points.
3. If required, start a new check run.

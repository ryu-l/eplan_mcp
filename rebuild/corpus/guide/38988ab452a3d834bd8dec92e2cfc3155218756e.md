# Generating Macros from DXF / DWG Files

1. Select the following commands: Tab Master data > Command group Macros > Drop-down button Generate automatically > From DXF / DWG files.
2. In the DXF / DWG file selection dialog select the desired macros.
3. Click [Open].
4. In the DXF / DWG import dialog select the desired scheme and specify the target directory.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected files are saved in the specified directory (default is <Drive\_EPLAN>:<Program directory>\Macros\<Company code>) as window macros <original\_name>.ema and can be inserted like "normal" window macros in Eplan. When inserting the resulting window macros, a "DXF" is displayed for macros from DXF files and a "DWG" is displayed for macros from DWG files.

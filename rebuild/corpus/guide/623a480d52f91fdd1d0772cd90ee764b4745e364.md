# Generating a Cut-out Legend for the 2D Drilling View

It is possible to generate reports for the cut-outs displayed in the 2D drilling views. The most important data of these manually inserted cut-outs or cut-outs imported from drilling patterns can be displayed structured in a table.

The report type "Cut-out legend" is available to this purpose in the dialog Select report. Analog to the enclosure legend a cut-out legend can be output as a new report page or be placed manually as an embedded report in an existing project page.

In the reports of this type the most important data of the cut-outs are listed in a table (for example item designations such as the respective drilling type "Drill hole", "Rectangle", "Slotted hole" etc., X , Y coordinates of handles, size of the cut-out, etc.).

Preconditions:

- You have opened a project.
- The project contains NC-relevant cut-outs.
- You have opened a project page in the graphical editor. The page contains a 2D drilling view.
- The Suppress generation of the enclosure legend property is not activated in the property dialog of the 2D drilling view.
- You have specified a form for the Cut-out legend report type with the file type "Cut-out legend (\*.f47)" in the dialog Settings: Output to pages.

1. Select the following commands: Tab Tools > Command group Reports > Generate.
2. In the Reports - <Project name> dialog, click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
3. Select the Manual placement entry in the Output format drop-down list of the Select report dialog.
4. Select the Cut-out legend report type from the list of available reports. Click [OK].
5. If required, carry out further filter settings in the dialog Settings - cut-out legend. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The legend is hanging on the cursor.
6. Place the legend on the page in the graphical editor.

# Drawing Lines and Rectangles

Lines, polylines, and rectangles consist of line segments. To draw lines only in the horizontal or vertical direction, use the [Orthogonal function](gededitgui_h_orthogonalfunktion.htm) as a drawing aid.

Precondition:

You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc.

### Drawing Lines

1. Select the following commands: Tab Insert > Command group Graphic > ![](../Pictures/Gui/ALL/ribbon_graphic_line_as.png) (Line).
2. Define the starting point of the line.
3. Define the end point of the line.
4. End the action via the Cancel action popup menu item or via the [Esc] button.

![](../Pictures/Gui/ALL/info.png)Tip:

Lines can be drawn with a projection, which is useful, for instance, when drawing center lines. Double-click the line, choose the Format tab in the Properties dialog and select the Projection check box. The projection is automatically calculated from the line thickness. The EPLAN105, Graphic.Center lines layer is provided for center lines: Select this from the drop-down list in the Layer field.

### Draw polylines

1. Select the following commands: Tab Insert > Command group Graphic > ![](../Pictures/Gui/ALL/ribbon_graphic_polyline_as.png) (Polyline) or ![](../Pictures/Gui/ALL/ribbon_graphic_polygon_as.png) (Polygon).
2. Define the starting point of the polyline.
3. Specify the further points of the polyline consecutively.  
     
   ![](../Pictures/Gui/ALL/arrow.png) With a polygons, a connection is automatically drawn between the first and last point in each case.
4. Exit the action using the [Space bar] or the Complete polyline popup menu item.

#### Increasing the number of polyline segments

1. Select the polyline you wish to edit.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The corner points and centers of the polyline segments are displayed by squares.
2. Keep the left mouse button pressed and drag one of the centers to a different position.  
     
   ![](../Pictures/Gui/ALL/arrow.png) This increases the number of segments by 1.

### Draw rectangles

Define rectangles through the starting point and end point

1. Select the following commands: Tab Insert > Command group Graphic > ![](../Pictures/Gui/ALL/ribbon_graphic_rectangle_as.png) (Rectangle).
2. Define the starting point of the rectangle.
3. Drag the rectangle into any direction and define the end point.
4. End the action via the Cancel action popup menu item or via the [Esc] button.

Define rectangles through the center and a corner

1. Select the following commands: Tab Insert > Command group Graphic > ![](../Pictures/Gui/ALL/ribbon_graphic_rectanglecenter_as.png) (Rectangle through center).
2. Define the center of the rectangle.
3. Drag the rectangle out from the center and define the corner point of the rectangle.
4. End the action via the Cancel action popup menu item or via the [Esc] button.

# Inserting Devices in Macros / Copies with Unchanged DT

On insertion of macros and cut or copied devices, you can decide if these schematic elements should be online numbered or not.

Precondition:

You have opened a project.

### Specify numbering behavior before insertion

1. Select the following commands: File > Settings > Projects > "Project name" > Devices > Numbering (online).
2. In the On insertion of macros and copies group box, select the Do not modify option.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) All the devices that you insert into the schematic via macros or copies are inserted unchanged. The original DTs are retained.

### Specify numbering behavior on insertion

If you activate the numbering behavior prompt in the global settings, you can specify a different numbering behavior for devices in macros or copies at each insertion.

1. Select the following commands: File > Settings > Projects > "Project name" > Devices > Numbering (online).
2. In the On insertion of macros and copies group box, select the With prompt option.
3. Click [OK].
4. Paste your copy from the Clipboard into the schematic page. Select the following commands: Tab Home > Command group Clipboard > Insert.
5. Or insert a macro. Select the following commands: Insert center > Breadcrumb trail Home > Window macros / symbol macros. Using the folder structure navigate to the desired window macro / symbol macro and select it by clicking the preview tile.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The macro / copy hangs on the cursor.
6. Move the cursor to the desired location on the schematic page.
7. Click the page to place the copy / macro.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Insertion mode dialog opens.
8. Select the Do not modify option.
9. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The macro / the copy is placed. The DT is retained unchanged.

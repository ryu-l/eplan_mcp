# Tab Mounting panel (panel layout)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a page of the "Panel layout" type.

- Tab Insert > Command group 2D panel layout > Mounting panel (2D). Draw the mounting panel. In the Properties <...> dialog, select the Mounting panel tab.
- You have double-clicked a mounting panel (or selected the Properties popup menu item; in this way, multiple mounting panels can be selected). In the Properties <...> dialog, select the Mounting panel tab.

In this dialog, you specify the properties for the selected mounting panel.

Overview of the main dialog elements:

Displayed DT:

The displayed DT is displayed in the graphical editor on the component. If you have defined in the project settings that devices are to be automatically numbered when symbols are inserted, then a DT is automatically suggested here. You can accept this DT or overwrite it manually.

In addition you can use the [popup menu or the [...] button](devicetaggui_r_feldsichtbaresbmk.htm) to create or select a DT.

Full DT:

This field displays the full DT (i.e. structure identifier of the current environment + displayed DT) of the component / item. Use the [...] button to open the Full DT dialog. You can edit the structure identifiers there and select, e.g., another mounting location.

Main function:

Select this check box if the current function is a main function.   
If the mounting panel is not a main function, the display of the Parts tab is suppressed.

# Dialog Edit cable

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have selected a cable definition line or a shield in the graphical editor. Or you have selected a connection or a connection definition point, at which the "Cable" value is set for the Connection: Association property. Tab Connections > Command group Cables > Edit.
- You have opened the cable navigator, for example via the following commands: Tab Connections > Command group Cables > Navigator. In the Cables - <Project name> dialog select a cable definition and select the Edit popup menu item.

In this dialog you can view and edit the device-specific properties of the marked cable and the properties of the cable connections. The full DT for the cable is displayed in the title bar. You can also view and edit the assignment of the cable connections to the function templates of the cable part. When the dialog is opened, the connections are automatically updated.

Cables with the representation types "External" or "Graphic" are not displayed here.

Overview of the main dialog elements:

Table Cable information

In the table the device-specific properties of the cable, such the assigned part or the length of the cable, are displayed in one row. Further columns, for example with information on the source and target of the cable, can be shown as required by using the popup menu item Configure representation. Properties which cannot be changed are grayed out. The following columns can, amongst others, be displayed:

Part number [1]:

Shows the first part assigned to the cable definition. If necessary, you can show additional columns for further parts via the popup menu item Configure representation. In the columns for the part numbers you can call the part selection by using the [...] button and select a different part there.

After the selection of a new part the associated function templates are displayed immediately in the table Connections.

If a cell of the Cable information table is selected, the image of this part is displayed in the graphical preview - provided a part is entered at the cable. The image is updated when another part is selected.

Cable / Conduit: Length with unit:

Shows the length of the cable including unit. This corresponds to the value available in the Length field in the first tab of the property dialog.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Device selection | Opens the dialog Device selection. Allows selecting a suitable cable part as the device on the basis of the connection properties. |
| Properties (global) | Opens the Properties (global): <...> dialog. Allows the editing of the device properties. |

Table Connections

The cable connections defined for the cable in the project are displayed in the table with their targets as well as the function templates of the cable parts assigned to the cable. Properties of function templates cannot be changed.

The sequence corresponds to the display in the tree view of the cable navigator.

- If a part is assigned to the cable, the part specifies the fixed sequence of the cable connections. The function templates of the part represent the connections of the cable part. Cable connections which override the function templates receive their sequence from them.
- If the cable does not have a part, or if no matching function template can be found, the cable connections are output sorted alphanumerically by name (property Connection color / number) behind the function templates. The named cable connections are listed first, then the unnamed cable connections.
- Unnamed cable connections are shown in graphical sequence (corresponding to the orientation of the plot frame).

If a cell of the Connections table is marked, the page on which the connection is located is displayed in the graphical preview. The position of the corresponding connection is highlighted by a marker in the preview.

Some of the columns listed here can be displayed additionally by using the dialog Configure representation. Properties which cannot be changed are grayed out. The following columns can, amongst others, be displayed:

Status:

Shows with an icon whether a cable connection overlaps a function template or not, or whether it is a free function template.

Connection color / number:

Shows the color code, color name or the color number of the connection. With the [...] button you can open the dialog Connection colors and there select a color defined in the project settings.

Color (graphic):

Shows through a graphic the color of the connection which corresponds to the color code entered in the Connection color / number property. If a color code is entered in this property that is not defined in the project settings (dialog Settings: Connection colors) or a different value, for example a color name or a connection number, a black, labeled graphic is displayed.

Indicates through a graphic whether the connection is shielded and visualizes the extent of the shield. The connection point of the shield is represented by a point. If the shielded connections are arranged in sequence, an oval graphic similar to that in the schematic is displayed. Otherwise the graphic is interrupted.

If several shields are available, they are displayed next to each other.

Pair index (graphic):

Shows through a graphic (small point) whether a pair index is entered at the connection and visualizes which cable connections are paired and belong to each other. If the pair index contains a point as a separator, only the component before the dot is considered for the association. This means that connections with the pair indexes "2", "2.1" and "2.2" belong together.

Connection: Association:

With this property you can specify the association of the connections to the cable. This is useful, for example, if you have added possible cable connections to the cable using the Collect cable connections action. In this way, connections which were assigned the Cable connection point property through their connection points can easily be added to the cable. The collected cable connections are not assigned directly, but rather extend the list in the lower area.

If the property has the value "Cable", the connection becomes a cable connection of the cable and adopts the cable DT.

If the property has the value "Individual connection", the cable DT is removed from this cable connection. If the associated connection definition point (because of a [DT adoption](devicetaggui_k_bmkuebernahme.htm)) inherits the cable DT to further connection definition points, the next connection definition point now receives the cable DT.

Cable connections defined by a cable definition line or a shield cannot be removed from the cable. The property is then grayed out.

For existing cable connections which are not influenced by a cable definition line or shield, the property can be changed.

Arrow buttons:

Use the arrow buttons to change the assignment of cable connections to the connections of the cable part (function templates). The buttons are only active if it is possible to move the selected connections.

Connections can only be moved to available function template positions. The data on the connections (connection definition points) are correspondingly exchanged. If a connection to which a shield is connected is moved, the shielded cable connections are also moved.

The potential type is taken into consideration in this case. This way, PE / PEN or SH conductors, for example, can't be moved to function template positions with other potential types. Nor is it possible to move them to a position with a different shield. Connections without shields, however, can be assigned to a function template with shielding.

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| --- | --- |

| Delete cable connections | Deletes the selected unplaced connections. Placed connections can't be deleted. |

| Assign cable connections | Resorts the sequence of connections for the selected cable. In doing so, it takes into consideration the rules for determining the source and target of the cable or â for terminals â the sequence of the terminals on the terminal strip. The assignment only occurs when all properties of the cable connections match those of the connection of the cable part.

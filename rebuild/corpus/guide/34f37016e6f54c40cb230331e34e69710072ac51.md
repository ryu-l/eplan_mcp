# Drawing and Changing Restricted Placing Areas

Mounting surfaces on components in the layout space (mounting panels, enclosure profiles, walls, doors) can be locked for positioning so that part placements cannot occur on them. This may be necessary if holes are to be subsequently drilled at these points or if the space is needed for devices that are mounted from other sides. These can include top-mounted cooling units, which project from above into the enclosure, or monitors and control elements on a door which have a relatively large mounting depth. Locked areas are independent 3D objects drawn as rectangles.

Restricted placing areas are displayed in the layout space navigator for each mounting surface under the Locked areas hierarchy level.

Precondition:

You have opened a project. You have opened a layout space. An enclosure or a mounting panel has been placed.

1. Select the following commands: Tab Insert > Command group Locked areas > Placement.
2. Move the cursor to the area to be locked to activate it automatically, or activate a mounting surface directly in the layout space navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The automatically or directly activated mounting surface is identified in color. Input is now only possible on this area.
3. Draw the rectangle that represents the restricted placing area.

![](../Pictures/Gui/ALL/info.png)Tip:

Use the popup menu item [Placement options](cabinetgui_d_platzieroptionen.htm) during insertion. In the subsequent dialog by the same name you can directly determine the distance between the cursor and the placement point for the start and end point of the restricted placing area in the Offset X and Offset Y fields.

![](../Pictures/Gui/ALL/note.png)Note:

As soon as a part placement is attempted in a locked area, the placement is prevented, and an [appropriate message](messages_p_026012.htm#P026012) is displayed. If the initiating check run P026012 has the setting "Prevent errors", then placement is prevented automatically on confirmation of the message.

### Modifying the size of restricted placing areas

The size of restricted placing areas can only be changed in two ways:

- Changing the format properties in the property dialog: Enter changed values for the Width and Height fields on the tab of the Format property dialog. The change is made referenced to the bottom left-hand corner.
- Graphical change: Mark the object. Direction arrows appear at the corners and in the middle of the sideline, in whose displayed direction you can pull apart and pull together the object. While moving along the direction arrow, handles that you can use for exact positioning are displayed at neighboring 3D objects.

# P002001: A pin connection point has too many targets: <x>. Maximum number of targets allowed: <y>

### Cause

You connected at least one of the two pin function connection points to more components than the specified number.

### Solution

#### Possibility 1

1. Double-click the pin in the schematic and select the Symbol / function data tab in the Properties <...> dialog.
2. In the Function data (logic) group box click [Logic].
3. In the Connection point logic dialog, check which values are set in the Number of targets row for both function connection points of the pin.
4. Increase the defined value for one or both function connection points based on your requirements.

#### Possibility 2

1. Double-click the pin in the schematic and select the Symbol / function data tab in the Properties <...> dialog.
2. In the Function data (logic) group box click [Logic].
3. In the Connection point logic dialog, check which values are set in the Number of targets row for both function connection points of the pin.
4. Delete the excess components placed for each pin function connection point in the schematic.

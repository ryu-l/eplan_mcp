# Form and Plot Frame Editor

Forms display information or results of report runs in graphical form. Using forms, you can determine which properties to output in which order and which layout. A form defines a list of fields with positioning information on one page and the number of records to be output per page. The position and formatting of information is determined using predefined placeholders. The (numerical or alphanumeric) IDs of the placeholders are unique and divided into functional areas.

The following Form types can be created in the form editor:

- Function related output lists (e.g. terminal diagram, cable diagram)
- Overviews (e.g. bill of materials, table of contents)
- Connection diagrams (e.g. terminal connection diagram).

In contrast to forms, plot frames define the logical structure of the schematic, that is, the assignment of a plot frame to a page determines the header, page size, and the division into rows and columns.

Forms and plot frames are individual files on the hard drive. If they are to be changed or created, the project must first be opened. Only then can forms and plot frames be selected for editing and opened in the appropriate editor.

![](../Pictures/Gui/ALL/note.png)Note:

The edited forms and plot frames are not stored locally in the opened project. The editing of master data is always done in the master data pool.

For each open form / plot frame, a temporary page in the project is created and opened in the corresponding editor. If the form / plot frame editor is closed, then the form / plot frame is stored, closed, and the temporary page deleted.

# P024011: Conduit target with incomplete DT

### Cause

The full DT is missing for one or several connections of a conduit at the connected source or target function.

### Solution

1. Locate the conduit definition line in the schematic by using the Go to (graphic) functionality from the popup menu of the Message management dialog.
2. At all connection definition points of the conduit track the respective connection of the connected source or target function.
3. Open the property dialog for every source or target function.
4. Add the full DT wherever none is entered.
5. Confirm your entries.
6. Update the connections.
7. If required, start a new check run.

# P005073: Different connection point cross-section / diameter of targets

### Cause

A cross-section or diameter can be specified for each connection point at a function by means of the indexed property Connection point cross-section / diameter (all, depending on DT adoption).

In this case the connection points of the targets (target functions) connected with a function have different cross-sections or diameters.

### Solution

1. Enter the same value for the connection point cross-section or diameter at the targets (target functions).
2. If required, start a new check run.

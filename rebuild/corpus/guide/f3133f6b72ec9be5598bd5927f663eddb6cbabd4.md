# P007013: Part '<x>' is stored, but the variant '<y>' is not. There is the variant '<z>'

### Cause

You placed a device and manually selected a part variable that is not included in the part master data. In this case the part variable is not loaded into the project.

### Solution

1. Create a new part variant for the selected device in the parts management.
2. Place the device with this variable.
3. If required, start a new check run.

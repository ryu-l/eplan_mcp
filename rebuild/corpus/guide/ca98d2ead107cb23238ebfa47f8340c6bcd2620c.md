# Wire Harnesses

Eplan supports you in the planning and management of wire harnesses, cable units and their components. By using an import functionality you can import wire harnesses, cable units and the associated components designed in Eplan Harness proD into Eplan projects, and edit and report them there. You can subsequently export the wire harnesses, cable units and their components for renewed editing in Eplan Harness proD.

The following is possible:

- You can import the wire harnesses designed with Eplan Harness proD into a project of the Eplan platform.
- You can generate wire harnesses and cable units with pre-defined properties or insert them as symbols in the schematic.
- You can assign further functions, connections or parts to a wire harness or a cable unit, or remove existing assignments again.
- The parts entered at the wire harness definitions cable unit definitions their components can be output into reports or be used for the manufacturing data export / labeling.
- You can export the wire harnesses and cable units for further editing into Eplan Harness proD.

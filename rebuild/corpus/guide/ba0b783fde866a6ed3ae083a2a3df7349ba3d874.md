# Updating the Parts Database

If you work with several Eplan versions (e.g., when switching to version 2026) and have in version 2026 an "older" parts database, you will be prompted upon opening parts management to update the parts database. If you answer this prompt with [Yes], the parts database is updated.

If you click [No], the parts database is not updated. In this case the parts database is opened, but it cannot be edited, only viewed. However, part or device selection is possible.

![](../Pictures/Gui/ALL/note.png)Notes:

- If you work with several Eplan versions, you must always use the latest Eplan version when editing and managing the parts database.
- New and updated old parts databases can be opened but not edited in the Eplan versions 2022 (as of Update3), 2023, 2024 and 2025. This allows you to select a part or device. In Eplan 2022 before Update3 an empty dialog is shown for a new or updated old parts database in the parts management.
- For Version 2022 the parts management has been changed to a different database technology. Parts databases of Version 2.9 (or older) can therefore no longer be updated in newer Eplan versions (2022, 2023, etc.). It is possible to transfer such parts databases into new databases.

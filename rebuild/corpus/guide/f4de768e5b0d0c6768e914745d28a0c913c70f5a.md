# P004080: Missing configuration project

### Cause

The specification of the configuration project is missing at a PLC box or a bus port. This information is required for a correct PLC data export from Eplan.

### Solution

1. Locate the PLC box or the bus port in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the property dialog for the PLC box or the bus port.
3. In the case of the PLC box bring the PLC structure data tab to the foreground. In the case of the bus port bring the Bus data tab to the foreground.
4. Assign a corresponding name for the PLC box in the Configuration project field or select an entry from the drop-down list.   
   For a bus port show the Configuration project (at PLC boxes and bus ports) property in the group box Properties of the network interface and enter the name there.
5. Click [OK].
6. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

The bus port inherits the Configuration project property from the main function, the PLC box. Therefore the specification of the configuration project is required at the bus port if none is entered at the PLC box.

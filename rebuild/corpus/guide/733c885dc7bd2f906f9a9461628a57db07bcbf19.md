# P005049: Different net definition points within a net

### Cause

A net contains more than one net definition point.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

A net in a schematic contains two net definition points (see circles in the following figure).

![](../Pictures/Visualisation/ALL/messages_005049_bsp_av.png)

### Solution

A net must contain only one net definition point. Superfluous net definition points have to be deleted. Proceed as follows:

1. Locate the first net definition point of the net in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Search for further net definition points that are placed multiple times in the net by using the functionality Go to (2nd coordinate) of the popup menu.
3. In the schematic delete the net definition points placed multiple times in the net.
4. If required, start a new check run.

# Tab Format (mounting grid)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a layout space. The layout space contains 3D objects. A mounting grid has been defined on a 3D object. You have marked the mounting grid and selected the popup menu item Properties. In the Properties <...> dialog, select the Format tab.

On this tab you can edit the display properties of a mounting grid.

Overview of the main dialog elements:

Property / Assignment:

The hierarchy level Mounting grid is available in the table. It can be opened by clicking the ![](../Pictures/Gui/ALL/all_expand_hierarchy_as.png) sign.

X direction / Y direction:

The grid increment and the number of the grid lines in the X and in Y direction are specified here.

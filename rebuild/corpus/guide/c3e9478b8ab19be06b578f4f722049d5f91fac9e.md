# Dialog Migrate free properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Master data > Command group Parts > Management. You have opened a parts database using [Extras] > Settings. Button [Extras] > Migrate free properties.

This dialog displays the outdated, free properties that exist in the set parts database. You can decide whether you want to migrate a free property into a user-defined property, delete the free property or leave it in the parts database.

You are supported during the migration, for example, by being able to select existing user-defined properties. This is advantageous in case you have prepared user-defined properties with the desired displayed names and configurations and only want to change the assignment at the part. During the migration the user-defined property is assigned to the part and the value of the free property is entered there.

Overview of the main dialog elements:

All available free properties are displayed in the upper table. Information about the respective free property such as the displayed name is displayed in the left-hand table area Free properties. The identifying name and other information about the respective user-defined property to be generated or already existing are displayed in the right-hand table section User-defined properties.

Table section for free properties:

- Displayed name: Displays the displayed names of the free properties.
- Position of the property: Shows the positions of the free properties in the Free properties dialog.
- Values: Displays the values of the free properties.
- Unit: Displays the units for the values of the free properties.

Action:

In this column you specify which action is to be carried out for the respective free property:

- None: The free property remains unchanged in the parts database. Select this option if you do not want to migrate or delete the free property for the time being.
- Delete: The free property is deleted at the affected parts. The deleted free properties no longer exist the next time you start the dialog.
- Migrate: The free property is migrated to a user-defined property. You can either create a new user-defined property or select an existing one. To this purpose the field in the Identifying name column is enabled and you can enter a new identifying name or select the name of an existing property via a selection dialog.  
  A free property is not deleted by the "Migrate" action and continues to exist.

Table section for user-defined properties:

If the entries "None" or "Delete" are selected as the action, the fields in the subsequent columns for the respective free property are grayed out and cannot be changed.

- Identifying name: Displays the identifying name of a user-defined property. If the "Migrate" action is selected, you can enter a new name here in accordance with the format for identifying names ("Name\_range.name").   
  Or click the [...] button in the cell for the identifying name to branch to the Select properties dialog and there select the name of a user-defined property that already exists.
- Field type: Displays the field type of a user-defined property. Only available if a new identifying name is entered in the Identifying name column.
- Unit group: Displays the unit group of a user-defined property. Only available if a new identifying name is entered in the Identifying name column and if the "Value with unit" entry has been selected as the field type.
- Display type: Displays the display type of a user-defined property. Only available if a new identifying name is entered in the Identifying name column.

Usage table:

When a free property is selected in the upper table, the parts that use the free property (meaning to which the free property has been assigned) are displayed here. This makes it easier to assess the impact of the migration.

- Part number: Displays the part number of the parts to which the selected free property has been assigned.
- Variant: Displays the variant of the parts.
- Position of the property: Shows the positions of the free properties in the Free properties dialog.
- Values: Displays the values of the free properties.
- Unit: Displays the units for the values of the free properties.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Carrying out migration

If the migration dialog is closed with [OK], a migration is carried out for the free properties with the selected action "Migrate". When creating a new user-defined property, the displayed name of the free property becomes the displayed name of the new user-defined property.

Irrespective of whether a new user-defined property was created during the migration or an existing one was used, data is transferred to the parts that use the free property. The respective user-defined property is assigned to these parts and the value of the free property is entered at the user-defined property.

A free property is not deleted during the migration and continues to be displayed in the Migrate free properties dialog. To delete a free property, either select the "Delete" action for the selected free property in the migration dialog or remove it manually at all the respective parts in the Free properties dialog.

# Using Connection Preview

The connection preview is useful when placing devices on the 3D mounting layout navigator. A blue line shows which device, already placed, is electrically connected to the device that is about to be placed in the project plan. The connection preview makes it easier to group associated devices and helps avoid unnecessarily long wiring.

Preconditions:

- You have opened a project.
- You have opened the layout space navigator and a layout space.
- The layout space contains part placements.
- The 3D mounting layout navigator is open.

1. Select a device in the 3D mounting layout navigator.
2. Select the Place popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The part that is to be placed hangs movably from the cursor as a preview.
3. Activate the button Connection preview in the command group Routing connections of the View tab.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A blue line appears between the part to be placed and the device with which it is electrically connected.
4. Place the part in a suitable location.

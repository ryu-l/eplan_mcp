# Moving Elements

Precondition:

You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc.

1. Select the desired elements and select the popup menu item Move.
2. Move the cursor to the position where you want to place the elements and press [Enter].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The elements are inserted at the relevant point and deleted at their original position.

### Move elements using drag and drop

The moving of elements can also be performed using the Windows-compliant Drag and Drop technique.

1. Select the elements to be moved.
2. Hold down the left mouse button, drag the elements to the new position, and release the mouse button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The elements are inserted at the relevant point and deleted at their original position.

![](../Pictures/Gui/ALL/note.png) Note:

If you use drag and drop in combination with [Ctrl], the selected elements are not simply moved, but copied. When using the Input box for your entry, it is enough to hold down the [Ctrl] key during confirmation of the last input.

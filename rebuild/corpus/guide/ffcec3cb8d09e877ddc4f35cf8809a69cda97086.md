# P005056: Conflict between net and potential or signal

### Cause

The properties of a net definition point, to which a name of potential (and a signal name) was assigned, deviate from the properties of a potential definition defined in the schematic, which are components of a network and have the same potential name (and signal name). The potential type, the potential value or the frequency data can be contradictory.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The name of potential P200 was specified at the net definition point N1 in the schematic and a potential value of 100 V was defined. The net is connected with a potential definition which was placed as a potential connection point. The potential connection point has the same potential as the potential of the network. However, a potential value of 24 V was defined here.

![](../Pictures/Visualisation/ALL/messages_005056_bsp_av.png)

### Solution

1. Locate the net definition point in the schematic by using the Go to (graphic) functionality from the popup menu in the Message management dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The net definition point is marked accordingly in the schematic.
2. Call up the property dialog of the net definition point and notate the values in the property fields Potential type, Potential value and Frequency.
3. Close the property dialog.
4. Jump from the dialog of the message management via the popup menu item Go to (2nd coordinate) to the connected potential definition (potential definition point or potential connection point) which has the same potential name (and signal name) as the net definition point.
5. Call up the property dialog here as well and compare the properties listed above with those of the net definition point.
6. Either standardize the property values at the net definition point or at the potential definition.
7. Confirm your entries.
8. If required, start a new check run.

# Tab Pages

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have selected one or more pages in the page navigator. Popup menu item Copy. In the page navigator, click the position where the copied pages are to be inserted. Popup menu item Insert. Select the Pages tab.
- Tab Home > Command group Page > Drop-down button Page macro > Insert. In the selection dialog, select a page macro and click [Open]. Select the Pages tab.

All the structure identifiers for the pages and elements in the page are displayed in a table on the pages and can be edited on this tab.

Overview of the main dialog elements:

In the table, the structure identifiers defined for each project structure as well as the page numbers, sheet numbers and page descriptions are displayed for the source (i.e. the source project or source macro) and the target project.

Source:

The respective data of the source project or macro is displayed in the fields for the structure identifiers (such as "=" for function designation or "+" for location designation), page number, supplementary field sheet number and page description. These cannot be edited here.

Target:

The data of the source project or macro are used as defaults in the target project fields and can be changed as desired: In the fields for the individual structure identifiers, you can use [...] to open a dialog offering the existing structure identifiers in the target project for selection. Page number, supplementary field sheet number and page description can be overwritten manually. Table cells with new structure identifiers, page names, etc. that deviate from the current value are highlighted by a yellow background.

Overwrite:

Selecting this check box defines whether an existing page is to be overwritten when a page or page macro is inserted.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Automatic page name:

Select this check box to determine the highest existing page number for the structure, and to suggest the next highest number / numbers for the Page name column.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You have opened the EPLAN\_Sample\_Project sample project, and selected the page =GB1+A1&EFS1/1 with the page description 400/230 V feed-in in the page navigator. You then insert a single-page macro. The page name of the created page macro is initially the default setting in the Adapt structure dialog on the Pages tab (e.g. 5). Select the Automatic page name check box so that the page name changes to 2 since the highest assigned page number in the substructure is 1.

[Number]:

Opens the [Number pages](pagebrowsergui_d_seitennummerierung.htm) dialog. Define how the pages are to be numbered before they are inserted.

[Reset]:

Resets the pages to the original structure. This can be useful if you want to insert multiple-page macros into a project, and want them to retain their original structure identifiers.

[Extras]:

| Menu item | Meaning |
| --- | --- |
| Edit structures | Opens the Edit structures dialog. Allows you to specify / edit the main identifiers and up to 9 sub-identifiers each for the individual identifier blocks. |

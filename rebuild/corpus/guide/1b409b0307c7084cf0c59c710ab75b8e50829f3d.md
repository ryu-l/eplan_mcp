# P003013: Several PE conductors intersected

### Cause

You specified in the Cable Properties dialog that only one PE / PEN conductor is permitted in the cable. The cable actually has several PE / PEN conductors, however.

### Solution

#### Possibility 1

Change the potential type at the connection points of the functions that lead to PE or PEN conductors appearing multiple times in the cable.

1. Call up the respective property dialog of the functions that are the source and / or target of the cable.
2. For each function bring the Symbol / function data tab to the front, and click the [Logic] button.
3. In the Connection point logic dialog at the function connection points check the value in the Potential type field.
4. Then select a different potential type, for example "Undefined", at the function connection points with the value "PE" or "PEN" assigned several times.
5. Confirm your entries.

#### Possibility 2

You allow multiple PE or PEN conductors in the cable.

1. Double-click the cable definition line in the schematic.
2. Activate the Allow multiple PE conductors check box in the property dialog of the cable.

---

Update the connections.

If required, start a new check run.

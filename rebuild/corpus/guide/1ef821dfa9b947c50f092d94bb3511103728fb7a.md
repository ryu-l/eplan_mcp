# Dialog Customize

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Click in the title bar of the Eplan main window on the ![](../Pictures/Gui/ALL/all_quickaccess_as.png) icon (Customize quick access toolbar) and select the command Further commands.
- Right-click the ribbon and select the Customize ribbon command.

In this dialog you can adapt the quick access toolbar and the ribbon to your requirements.

![](../Pictures/Gui/ALL/note.png)Notes:

- Once you have customized the quick access toolbar and / or the ribbon, you must save the current user interface configuration as a new workspace or as a selected workspace (via the command Edit workspace), so that the modifications are permanently available for use (in the current workspace).
- In the Ribbon tab the displayed name is always displayed for each command, which also appears under the configured button. This means that identical texts are displayed for some commands in the Select commands drop-down list. To distinguish them, the Tooltip can be shown by moving the mouse pointer over the corresponding entry.
- The tooltip also displays for each command the category to which this command is assigned. This also applies to commands that are not displayed in the ribbon by default.

---

### "Quick access" tab

In this tab you select your desired commands that are to be available to you as an icon in the quick access toolbar.

Overview of the main dialog elements:

Tabs:

All tabs of the ribbon are displayed in this list. In addition, the "All commands" entry is also available in this toolbar. When this entry is selected, all commands of the ribbon which are available for quick access are displayed in the field below.

Commands:

Once you have selected an entry in the Tabs field, the associated commands are displayed in this list. With the button ![](../Pictures/Gui/ALL/all_arrowright_as.png) you can add a highlighted command to the quick access toolbar. The associated icon of the command is displayed in the quick access.

(Selected commands:)

The selected commands are displayed in the field on the right-hand side. You can use the buttons ![](../Pictures/Gui/ALL/all_arrowup_as.png) and ![](../Pictures/Gui/ALL/all_arrowdown_as.png) to change the sequence of the commands in the quick access toolbar.

Show below the ribbon:

If this check box is activated, the quick access toolbar is displayed below the ribbon.

[Reset]:

Click this button if you want to reset the quick access toolbar to the default state.

---

### "Ribbon" tab

In this tab you adjust the ribbon in accordance with your requirements. Selected commands can only be assigned to a user-defined command group.

Overview of the main dialog elements:

Select commands:

In the drop-down list select the desired category from which you want to select a command. All commands of this category are displayed in the field located below.

With the ![](../Pictures/Gui/ALL/all_arrowright_as.png) button you can assign a marked command to a user-defined command group.

Customize ribbon:

In the drop-down list select the desired category of tabs that you want to customize for the ribbon.

Main tabs:

Shows the available main tabs of the ribbon on the highest hierarchy level (for example Home). Deactivate the check box directly before it, if the respective tab in the ribbon is to be hidden in the ribbon.

The command groups and on the lowest level the commands are displayed below the tabs. Both the predefined as well as the user-defined tabs and command groups can be renamed via the popup menu or the [Edit] button. The deletion of command groups and user-defined tabs is only possible in the popup menu by using the command Delete.

[New tab]:

Click this button to create a new user-defined tab below the currently selected tab.

[Edit]:

Opens a dialog by the same name with whose help you can rename tabs, command groups as well as commands that are assigned to user-defined command groups. The commands listed in the standard tabs cannot be renamed.

[New command group]:

Click this button to create a new user-defined command group for the currently selected tab.

[Reset]:

Click this button if you want to reset all customizations for the ribbon to the default state again.

Shortcut keys:

With the [Customize] button you branch into the Customize shortcut keys dialog in which you can customize the shortcut keys for the individual commands.

# Behavior of the Program when Copying Between Different Project Structures

In Eplan, it is possible to copy pages and devices from one project to another, even if the source and target projects have a different project structure.

Eplan exhibits the following behavior when doing this:

### Behavior when copying pages

If you copy pages from a project into a project with a smaller structure:

- Identifier blocks are retained if they are defined as describing in the target project.
- Identifier blocks are deleted if they are defined as not available in the target project.

### Behavior when copying devices

If you copy general or other devices, such as cables, interruption points, black and structure boxes from a project into a project with a lower structure:

- The displayed device tag is always retained.
- In the identifying identifier block, only the identifier blocks conforming to the target project structure are adopted.

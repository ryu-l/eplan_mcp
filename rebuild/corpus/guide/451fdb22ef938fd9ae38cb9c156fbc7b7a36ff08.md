# Updating Symbols

A symbol library stored within a project can be modified outside the project at any time. In this case, the old symbol library stored in the project can be replaced with the modified one. Only the graphic is changed by this, the function remains unchanged.

Precondition:

You have opened a project.

1. Select the following commands: Tab Master data > Command group Synchronization > Synchronize project.
2. Select the symbol libraries that have been changed outside the project in the System master data field of the Synchronization of master data - <Project name> dialog. Multiple selection is possible.
3. Click ![](../Pictures/Gui/ALL/all_arrowleft_as.png) (Copy to the left).  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan compares the libraries with each other and displays a message with the results.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project master data are updated, i.e. overwritten by the system master data.

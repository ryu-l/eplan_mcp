# Inserting Angular Dimensions

To dimension an angle, first specify the angle middle point and then the starting and end points. The offset of the dimension line from the angle midpoint is defined by the starting point.

![](../Pictures/Visualisation/ALL/gededitgui_dimangle_av.png)

Preconditions:

- You have opened a project.
- You have opened a project page in the graphical editor.

1. Select the following commands: Tab Insert > Command group Dimensioning > Drop-down list Linear dimension > Angular dimension.
2. Specify the angle middle point by clicking it with the left mouse button.
3. Specify the starting point of the angle.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The distance from the starting point to the angle middle point defines the height of the dimension line.
4. Drag the angle counter-clockwise and define the end point.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The dimension value is centered on the dimension line by default.
5. End the action via the Cancel action popup menu item or via the [Esc] button.

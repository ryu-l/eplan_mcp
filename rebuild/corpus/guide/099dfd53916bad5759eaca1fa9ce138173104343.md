# Exporting Parts Data

When exporting part data, there is a difference noted between:

- The export of subsets of the database
- The export of selected records.

Precondition:

In the Parts management dialog you have opened a parts database using [Extras] > Settings.

### Export subsets of the database

1. Select the following commands: Tab Master data > Command group Parts > Management.
2. Select the Export menu item in the Parts management dialog below the [Extras] button.
3. Select the desired file type from the File type drop-down list in the Export records dialog.
4. Click [...] to specify how the data are to be exported for the Eplan Data Portal exchange format (EDZ): Activate the check box Export referenced data completely if subassemblies, submodules, etc. are to be included in the export in the case of assemblies, modules, etc.
5. Select if export is to be made to one file (Entire file option) or to an individual file for each record (Individual files option); depending on your selection you must either enter the file name for the export file (File name field) or specify the export directory.
6. In the Record type group box, select the check boxes of the data that you would like to export.
7. In the Trade group box, select the check boxes of the trades that you would like to export.
8. Change the scope of the fluid data to be exported by selecting / deselecting the check box.
9. Click [OK].

### Export selected records

1. Select the following commands: Tab Master data > Command group Parts > Management.
2. Mark the records to be exported in the tree or the list of the Parts management dialog.
3. Select the Export popup menu item.
4. Continue as described above.

![](../Pictures/Gui/ALL/note.png)Note:

If the current selection contains nodes (in the tree view) then all the records under those nodes will be exported.

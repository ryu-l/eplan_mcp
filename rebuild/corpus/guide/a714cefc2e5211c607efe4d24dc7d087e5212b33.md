# Project Backup

While saving projects you differentiate between the possibilities Save additionally, File off for external editing and Archive.

### Save additionally

During a data backup a copy of the project is saved on another storage medium. More than one project can be selected. They will be saved in sequence. A multiple selection of projects is made via the project management. There a multiple selection is possible in the tree.

### Filing off

If a project is transferred to subcontractors, end customers or other companies for temporary editing, you can file it off.

A copy of the project is saved on a different storage medium and the source project becomes write-protected. This ensures that modifications cannot be made to the project in the meantime that would be lost when the project is returned. All data from the filed-off project remains in the original location.

If another user should try to edit a filed-off project, they receive the message that the project is filed-off and locked for editing.

### Archive

Completed projects can be archived to create space again and a better overview on the storage medium. A copy of the project is saved onto a different storage medium and, apart from a single information file, the source project is deleted completely from the hard disk.

# Tab Settings: Design space - function definitions (import)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > User > Interfaces > Design space import and export. Select the Function definitions (import) tab.

In this tab you specify which function definitions and items are to be assigned automatically to the imported 3D objects in Eplan during the import of STEP files with design spaces.

![](../Pictures/Gui/ALL/note.png)Note:

Eplan supports solely the import of STEP files that have been generated with the application protocol AP 203 or AP 214.

Overview of the main dialog elements:

Specify an assignment scheme in the following fields:

- Designation in CAD: Enter the internal company item designation that is used in the exporting CAD system for a 3D object.
- Function definition in Eplan: Select a function definition that is to be assigned automatically to the 3D object exported from the CAD system during importing into Eplan, for example "Panel". Click [...] to open the Function definitions dialog.
- Item in Eplan: Select an item matching the function definition that is to be assigned automatically to the 3D object exported from the CAD system during importing into Eplan, for example "Side panel right".

![](../Pictures/Gui/ALL/note.png)Note:

The "Enclosure" function definition is automatically assigned to the geometry model contained in the STEP file during importing.

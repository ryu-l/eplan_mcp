# Tabs Header / Footer

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. File > Export > Command group Manufacturing data > Manufacturing data > Labeling. Click [...] next to the Settings field in the dialog Export manufacturing data / output labeling. In the dialog Settings: Labeling select the Header tab or Footer tab.
- File > Settings > User > Interfaces > Manufacturing data export / Labeling. In the dialog Settings: Manufacturing data export / labeling select the Header tab or Footer tab.

In these tabs you can specify the layout of the header and footer of the export / labeling page.

Overview of the main dialog elements:

Available format elements:

The format elements available are in this field. The format elements available depend on the report type selected

Selected format elements:

In this field are the format elements that make up the format for the header or footer.

- Format element: This column displays the name of the format element.
- Symbol: This column displays the abbreviation of the format element. The abbreviations of the selected format elements are shown together in the Preview field.
- Settings: This column contains the abbreviations and values for the settings of a format element.

Use header for all pages / Use footer for all pages:

If the check box is selected, the header / footer will be repeated on every page of the export / labeling file. If the check box is deactivated, the respective area is only output on the first page.

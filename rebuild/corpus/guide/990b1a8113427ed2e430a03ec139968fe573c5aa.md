# P007029: The DT ID '<x>' of the auxiliary function differs from that of the main function ('<y>')

### Cause

The DT ID that was entered at an auxiliary function that is a component of a macro for a module differs from the entered DT ID of the associated main function in the macro.

### Solution

1. Locate the auxiliary function in the schematic by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Launch the property dialog of the auxiliary function.
3. Enter the DT ID of the main function that is displayed in the message into the DT ID property of the auxiliary function so that both properties match.
4. Click [OK].
5. If required, start a new check run.

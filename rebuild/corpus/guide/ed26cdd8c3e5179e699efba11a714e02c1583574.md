# Dialog Project options - <Project name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Tab Devices > Command group Project options > Navigator
- You have opened an editor such as the graphical editor, the plot frame editor, etc. Tab View > Command group Navigators > Drop-down button Open > Project options

In this dialog, you create and edit the project options (via the popup menu); the ![](../Pictures/Gui/ALL/all_statusok_as.png) icon next to the project option indicates if it is activated. If particular customer requirements mean that you do not require part of a machine for which a project option has been defined, then deactivate the project option. The schematic and reports are then automatically adjusted.

Overview of the main dialog elements:

The project options groups are displayed in the tree tab sorted hierarchically according to project options groups, project options and sections. The respective description of the project options groups, project options and sections is a multi-language text and is displayed by default in the tree view next to the name, separated by a blank and within round brackets.

In the List tab, the names and descriptions of the project options groups, project options, and sections are displayed as standard, and also whether the option is active (i.e., switched on). The displayed properties can be configured using the popup menu.

Filter:

This drop-down list displays all the available filters. A selected filter is automatically activated and is applied to both the tree and the list view. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the [Filter](modaldialogsdb_d_filternnach.htm) dialog. Here you can create, edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

- Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
- Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

Value: <Property>:

Use this field, via [Quick input](modaldialogsdb_k_filter.htm#I_Schnelleingabe), to adjust quickly the value of a filter criterion for a defined and activated filter.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Select all (list only) | Selects all of the entries in the list. |
| Adjust column width (list only) | Adjusts the width of all table columns so that both the headings and column contents are fully legible. |
| New > Project options group | Generates a project options group. |
| New > Project option | Generates a project option. |
| New > Section | Creates a section. |
| Delete (tree only) | Deletes the selected element. |
| Assign value set (tree only) | Only when placeholder objects are selected: Opens the dialog Select value set - <Placeholder name> allowing you to assign a value set to the selected placeholder objects. |
| Select associated objects | Selects all objects belonging to the current section, placeholder object, or current project option in the graphical editor. |
| Assign objects to the section | Allows for the content of the current section to be extended or replaced by the selected objects. A section containing pages can be assigned only further pages (but not functions). A section containing functions can be assigned only further functions (but not pages). |
| Toggle | Toggles the selected project option. |
| Make transparent (On/Off) | Displays deactivated project options transparently or hides them completely again. This function allows you to check the location of deactivated project options in the schematic. The components of the transparently displayed project options appear somewhat lighter than the other components. |
| Edit revision marker | This menu item allows you to edit the revision marker texts and their format. This menu item is only available when a changed object in a revision is selected. |
| Delete revision marker | This menu item allows you to delete the revision marker texts. This menu item is only available when a changed object in a revision is selected. |
| Go to (graphic) | Shows the selected section or placeholder object in the graphical editor. |
| List with preselection (tree only) | Reduces the number of elements displayed in order to allow for a faster orientation in the list view. If this option is activated, the list view is called up with an automatic filter (preselection) containing the elements that are currently selected. |
| Select in tree (list only) | Displays the marked object in the Tree tab. |
| Configure representation | Opens the Configure representation dialog, where you define which properties are to be displayed in the list and tree view. |
| Edit in table | Opens the tabular editing allowing editing of the properties of the functions contained in the project option or section. |
| Properties | Depending on the selection, opens the appropriate dialog for editing the project option, section, etc. |

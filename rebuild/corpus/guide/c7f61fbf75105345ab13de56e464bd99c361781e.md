# P026108: The item for the mechanical feedthrough does not have a suitable connection point pattern

### Cause

You have placed a part placement for a mechanical feedthrough, for example an insert or bar-type current transformer, in the layout space. During the routing of the connections it was determined that no matching connection point pattern is stored at the part. For example, the connection points in the connection point pattern of the part placement have different connection point designations than in the connection point pattern that is stored at the part.

### Solution

1. Locate the part placement of the current transformer in the layout space by means of the Go to (graphic) function from the popup menu in the Message management dialog.
2. Launch the property dialog of the part placement.
3. Bring the Connection point pattern tab to the foreground and note all the connection points.
4. Switch to the Parts tab and remember the part entered at the part placement.
5. Call up the parts management and check the connection point pattern entered at the part. Compare the connection point designations entered in the connection point pattern of the part with those that are entered in the connection point pattern of the part placement in the layout space.
6. Correct the connection point designations in the connection point pattern of the part placement in accordance with the connection point designations that are defined in the connection point pattern of the part.
7. Then route the connections again.

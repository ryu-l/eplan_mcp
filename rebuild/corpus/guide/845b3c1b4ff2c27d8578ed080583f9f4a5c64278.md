# Editing Page Properties

You can view and edit the properties of pages in the Pages - <Project Name> navigator dialog.

Precondition:

You have opened a project. You have opened the Pages - <Project name> navigator dialog.

1. Select the desired page in the tree or list view. Multiple selection is possible.
2. Select the Properties popup menu item.
3. Use the [Page properties](pagebrowsergui_d_seiteneigenschaften.htm) dialog to change the desired properties.
4. Click [OK].

![](../Pictures/Gui/ALL/note.png)Note:

When identifying page properties, such as the function designation, are changed, all the DTs on the page with the same function designation are renamed.

![](../Pictures/Gui/ALL/info.png)Tip:

Some fields, such as the Page description and Drawing number field can be directly edited in the table in the page navigator list view.

# Copying Forms

To copy a form with all its content, save it to another location and / or under a different name.

Precondition:

You have opened a project.

1. Select the following commands: Tab Master data > Command group Plot frames / forms > Drop-down button Form > Copy.
2. Select the drive and directory of the form to be copied in the Copy form dialog.
3. Select the form file to be copied. (Multiple selection is not possible here.)
4. Click [Open].
5. Specify the storage location for the copy of the form in the Create form dialog.
6. In the File name field, enter a descriptive name for the new form.
7. Click [Save].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The form is copied and the copy opened for editing.

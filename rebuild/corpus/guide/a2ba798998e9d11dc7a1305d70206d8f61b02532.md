# Dialog Connection point designations and descriptions

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.File > Settings > Projects > "Project name" > Devices > Numbering (online). Click the [Connection point designations / descriptions] button.

In this dialog, you have the option of storing 10 sets of connection point designations and descriptions for each function definition. These sets can then be selected later on from the function. The settings made here are stored project-specifically.

Overview of the main dialog elements:

Find:

Enter the text for which the function definitions are to be filtered into this field. In the process the texts of the columns Trade, Category, Group and Function definition are searched.

If you want to return to the original view of the function definitions, remove the search term from the entry field. Click ![](../Pictures/Gui/ALL/all_delete_input_as.png) (Delete) to do so.

Table:

Both the Connection point designations tab and the Connection point descriptions tab list the connection points of the function definitions in a table (including the potential type). Only columns 1 - 10 for the connection point designations and connection point descriptions can be edited.

- Trade: The trade of the function definition is displayed here.
- Category: The category of the function definition is displayed here.
- Group: The group of the function definition is displayed here.
- Function definition: The function definition is displayed here.
- Connection point: The connection points of the function definition are each displayed in a separate row. Either the connection point number is specified or "n" (for a variable number of connection points) or "z" (for the last connection point if the number of connection points is variable).
- Potential type: The potential type of the connection point is displayed here.
- 1 -10: In the Connection point designations tab you can specify 10 different connection point designation recommendations for each connection point. The connection point designation identifies the connection point.  
  In the Connection point descriptions tab you can specify 10 different connection point description recommendations for each connection point. The connection point description is an additional, non-identifying entry.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

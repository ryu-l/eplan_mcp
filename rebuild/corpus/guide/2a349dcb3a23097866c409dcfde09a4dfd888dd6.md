# Dialog Free properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Master data > Command group Parts > Management. You have marked a part in the tree or list. You have clicked the [Free properties] button in the User-defined properties tab.

In this dialog, you can enter additional text information which is independent of the product group selected (cables, terminals, etc.). These properties are only assigned to the respectively selected variant of a part.

![](../Pictures/Gui/ALL/note.png)Notes:

- We recommend using the user-defined properties for the entry and display of additional information in the parts management. These offer you more setting options during the configuration than the free properties and behave in a way analogous to the user-defined properties for the project. The free properties only exist for reasons of compatibility.
- Eplan supports you in converting the outdated, free properties into user-defined properties or also deleting them. To this purpose the [Migrate free properties](articlesgui_d_migrationfreieeigenschaften.htm) dialog is available in the parts management.

Overview of the main dialog elements:

Scheme:

Choose the scheme that you would like to use from the drop-down list. Or click [...], to edit an existing scheme or create a new scheme using the Configure free properties dialog.

The schemes for assigning free properties are saved user-specifically.

[Assign scheme]:

Click this button to assign the scheme selected in the drop-down list.

![](../Pictures/Gui/ALL/note.png)Note:

Take into account that only filled cells can be overwritten by data from the scheme. Empty contents are ignored.

Table:

In the "Displayed name", "Value" and "Unit" cells you enter additional text information that you wish to use for particular parts irrespective of the part type.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

![](../Pictures/Gui/ALL/note.png)Note:

Each field of each free property can be used for filtering with the filter.

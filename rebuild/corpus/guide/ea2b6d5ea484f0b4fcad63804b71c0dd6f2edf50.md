# Creating an Accessory List and Assigning a Main Part

Parts management provides "accessory lists" as a simple means of managing alternative accessory parts. They allow you to select a part from a list of possible alternatives. The accessory lists in the parts management represent their own record type and are displayed in the tree view below the separate hierarchy level "Accessory list".

Once you have created accessory lists, they may be assigned to a main part of a part type in the Parts management module.

Precondition:

You have opened the Parts management dialog (Tab Master data > Command group Parts > Management).

### [ClosedCreating an accessory list](javascript:void(0);)

1. Select the Accessory list hierarchy level in the tree.
2. Select the New popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan automatically generates a new accessory list with the name New(<Sequential\_number>). If you have marked an existing accessory list, this name of this accessory list is used and extended by a sequential number.
3. In the right-hand section of the dialog change to the Properties tab.
4. Change the automatically assigned entry for the Name (accessory list) property in the Data hierarchy level.   
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan automatically fills the properties Creation date and Modification date (in the hierarchy level Revision) with the corresponding data. These cannot be changed.
5. Bring the Parts tab to the front.
6. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) to generate a line in the accessory list.
7. Click [...] in the Part number column.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Part selection dialog opens. Only the previously defined accessory parts are displayed here.
8. Select the desired accessory parts in the tree and click [OK].
9. Repeat the selection if you want to add a further accessory part.
10. Close the parts management and save the modified data.
11. Click [Yes] in the subsequent dialog to perform a parts data synchronization.

### [ClosedAssigning an accessory list to a main part](javascript:void(0);)

1. Mark the desired main part in the tree or in the list.
2. In the right-hand section of the dialog change to the Accessories tab.
3. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) to generate a line in the list of the accessory parts.
4. Click [...] in the Part number / name column.
5. In the Part selection dialog in the tree structure mark the newly created accessory list in the Accessory list hierarchy level.
6. Click [OK].
7. Close the parts management and save the modified data.
8. Click [Yes] in the subsequent dialog to perform a parts data synchronization.

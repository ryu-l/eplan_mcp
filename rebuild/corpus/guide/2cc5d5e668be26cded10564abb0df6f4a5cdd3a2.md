# Moving Elements into the Foreground / Background

To influence the arrangement of elements on the screen as well as the sequence of accessing, you can move elements to the foreground or into the background. For instance, if multiple elements are on top of one another, then normally the element added last is on top.

Precondition:

You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc.

1. Select an element and then select the following commands: Tab Edit > Command group Arrange > Foreground or Background.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The element will now be shown as the topmost or bottommost element of the stack.

If you edit one of the elements you have moved to the back, press [F5] to update the view and to reactivate the defined front/back properties.

# P001035: Several distributed terminal connection points with the same designation: <x>

### Cause

The same connection point designation was assigned to several connection points of a distributed terminal in the project.

### Solution

1. Locate the affected distributed terminal in the project by using the Go to (graphic) functionalities from the popup menu in the Message management dialog.
2. In the popup menu call up the property dialog of the distributed terminal and assign unique connection point designations for all connection points in the first tab in the Connection point designation field.
3. If required, start a new check run.

# Tab Outlines (Settings: Export NC - DXF / Settings: Export DXF - copper)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Export NC - DXF:

- File > Settings > Company > Machining > Export NC - DXF. Select the Outlines tab.
- File > Export > Command group Manufacturing data > Machining > NC - DXF. Click [...] next to the Machine field. Select the Outlines tab.

Export DXF - copper:

- File > Settings > Company > Machining > Export DXF - copper. Select the Outlines tab.
- File > Export > Command group Manufacturing data > Machining > DXF - Copper. Click [...] next to the Machine field. Select the Outlines tab.

In this tab, you specify the settings on visibility as well as layers and colors of outlines.

Overview of the main dialog elements:

Group box Formats for outlines

Export outlines:

If the check box is activated, milling outlines will be generated on a separate layer in the DXF file.

Layer:

Default name of the layer where the outline is stored in the DXF file.

Color:

Default color that is assigned to the outline in the DXF file.

# Dialog Parts preselection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- File > Settings > Projects > "Project name" > Management > Part selection. Next to the Parts preselection field, click [...].
- You have selected a main function in the graphical editor or in a navigator. Popup menu item Properties. Select the Parts tab. Button [Settings] > Part selection (project). Click [...] next to the Parts preselection field in the Settings: Part selection (project) dialog.

In this dialog, you can edit the lists for parts preselection, or create new lists.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Description:

This field displays the descriptive text that you entered into the Description field in the dialog New scheme when you created the scheme.

Toolbar:

You can use the following buttons in the toolbar:

| Button | Meaning |
| --- | --- |
| (New) | Use this button to open the Part selection dialog. It is there that you can select more parts to be added to the list in the parts preselection. |
| (Delete) | Use this button to delete the marked parts from the current list. |

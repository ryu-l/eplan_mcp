# P502029: The part '<z>', variant '<u>', entered at the module '<x>', variant '<y>', has neither a DT nor a DT ID

### Cause

In the parts database to be checked a module was determined at which a subpart (so-called module position) is entered without DT and DT ID. The part number of the module is output in the placeholder <x>, the variant of the module in the placeholder <y>, the part number in the placeholder <z>, and the variant of the entered subpart <u> in the placeholder <u>.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The respective variant of the subpart entered at the module is marked in the tree of the parts management.
2. Bring the Module tab to the foreground.
3. Select a corresponding value in the property table in the DT column and / or in the DT ID column.
4. Click [Apply].
5. If required, start a new check run.
6. Close the parts management and perform a parts data synchronization.

# P027017: Topology - No connection point pattern defined

### Cause

No connection point pattern has been defined at a topology function.

That is, there exists neither a local connection point pattern, nor a connection point pattern that has been stored on the part used.

### Solution

1. Locate the topology function in the project by using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the Properties <...> dialog of the topology function.
3. Bring to front the Part tab, and check first whether a part has been stored for the topology function, and whether a connection point pattern has been entered for it. If this is not the case, and you want to use for the route the connection point pattern defined on the part for the topology function, proceed as described below under "Possibility 1".
4. If no part has been stored on the topology function, check in the Connection point pattern tab whether connection point designations have been entered in the table that are derived either from the function connection points or are freely defined and not yet carried over to the local connection point pattern. If this is not the case, and you want to use for the route the local connection point pattern of the topology function, proceed as described below under "Possibility 2".

#### Possibility 1

For the route, the connection point pattern defined on the part is to be used for the topology function. To do so, select in parts management a part on which a connection point pattern has been stored. Proceed as follows:

1. Close, if still open, the property dialog of the topology function.
2. Select the following commands: Tab Master data > Command group Parts > Management.
3. Branch in the tree view of the Parts management dialog to the part that you want to assign to the topology function.
4. Bring the Properties tab to the front.
5. In the property table click [...] in the Data hierarchy level in the value field of the Connection point pattern property.
6. Select the name of the required connection point pattern in the Connection point pattern selection - <Project name> dialog that opens and click [OK]  
     
   ![](../Pictures/Gui/ALL/arrow.png) The name is transferred to the Connection point pattern field of the Properties tab, and the connection point pattern is assigned to the topology function.
7. Close parts management, save the modified data, and update the parts database.
8. Open the Properties <...> dialog of the topology function again.
9. Bring to front the Part tab, and assign to the topology function the required part with the connection point pattern from parts management.
10. Switch to the Connection point pattern tab and select the Update connection point pattern menu item from the popup menu.   
      
    ![](../Pictures/Gui/ALL/arrow.png) The connection point pattern is read from the part.  
      
    ![](../Pictures/Gui/ALL/arrow.png) If the topology function comes with connection points, they will be listed in the table and identified by the ![](../Pictures/Gui/ALL/erroricon_error_systemmessages.png) icon.  
      
    ![](../Pictures/Gui/ALL/arrow.png) If the connection point designations of the imported connection point pattern stored on the part deviate from those of the topology function, they will be identified in the table by the ![](../Pictures/Gui/ALL/all_statusnotok_as.png) icon.
11. Delete in the connection point pattern of the topology function all connection points that do not belong to the connection point of the part, and click [OK].
12. Transfer the connection point designations to the local connection point pattern of the topology function by activating the Local connection point pattern check box.  
      
    ![](../Pictures/Gui/ALL/arrow.png) In the "Status" column, the connection point designations are identified by the ![](../Pictures/Gui/ALL/all_statusok_as.png) icon.
13. Click [OK].

![](../Pictures/Gui/ALL/note.png)Note:

If no connection point pattern has been stored in parts management, it will have to be created subsequently. Proceed as follows:

1. Select in the tree view of parts management the Connection point pattern hierarchy level, and select the New popup menu item.
2. Define the required connection point data on the tabs Properties and Connection points, enter a name for the connection point pattern, and click [Apply].
3. Select in the parts tree the part, and assign to it the connection point pattern - as described above.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The assignment is then also implemented for the part placement in the layout space.

#### Possibility 2

During the route, the connection point pattern entered locally on the topology function is to be used. Proceed as follows:

1. Bring to front the Connection point pattern tab.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the topology function comes with connection points, they will be listed in the table and identified by the ![](../Pictures/Gui/ALL/erroricon_error_systemmessages.png) icon.
2. Transfer the connection point designations to the local connection point pattern of the topology function by activating the Local connection point pattern check box.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the "Status" column, the connection point designations are identified by the ![](../Pictures/Gui/ALL/all_statusok_as.png) icon.
3. Click [OK]..

---

  

If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

You can also use freely defined connection point designations in the connection point pattern. Proceed as follows:

1. Add to the table new rows corresponding to the number of connection points.
2. Enter the required connection point designations.
3. Delete all connection point designations no longer needed, and carry over the data to the local connection point pattern via the check box.

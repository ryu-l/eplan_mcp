# Generating Start Addresses of the PLC Cards

The start addresses of the PLC box can be automatically generated by means of the data length entered there. The start addresses generated in this way can then be used for subsequent addressing of the I/O connection points.

Preconditions:

- The data length for inputs and / or outputs is entered at the PLC cards (properties PLC device: Data length (inputs), PLC device: Data length (outputs) or the corresponding properties for PLC subdevices).
- In the PLC-specific settings the configuration value "Start address of PLC card" is used for the counter in the format of the PLC address.

1. Select one or several PLC cards in one of the navigators or the graphical editor. Or select one or several pages that contain PLC cards or the project in the page navigator.
2. Select the following commands: Tab Devices > Command group PLC > Start addresses  
     
   ![](../Pictures/Gui/ALL/arrow.png) A selection dialog is displayed if you have selected PLC cards that belong to different CPUs. Select the desired CPU.
3. Enter the respective desired start addresses for the first PLC card in the Generate start addresses of the PLC cards dialog in the fields Start value for inputs and Start value for outputs.
4. If applicable, activate the check box Apply to entire CPU to generate the start addresses for all PLC cards of the CPU.
5. If applicable, activate the check box Preview of result to have a preview of the generated start addresses displayed. If applicable, you can manually change the generated start addresses in the preview dialog.   
     
   ![](../Pictures/Gui/ALL/arrow.png) If conflicts occur, the affected cells are marked in red in the preview dialog. Conflicts can arise through manual editing or can be found during the comparison with the start addresses of the other PLC cards of the same CPU that are not contained in the selection. The values can nevertheless be written back into the project.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The start addresses are written to the PLC cards in the project. Existing start addresses are overwritten in the process.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The sequence in which the start addresses are generated for the PLC cards corresponds with the sequence of the PLC cards in the rack-oriented view of the PLC navigator.

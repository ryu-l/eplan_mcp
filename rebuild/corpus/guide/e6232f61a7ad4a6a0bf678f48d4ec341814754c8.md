# Checking Symbols

The following problems can occur when editing symbols:

- Double connection point numbers: are automatically corrected by the system during editing
- Gaps in the connection point numbers: are automatically removed by the system during verification
- Differing number of connection points in the variants: is documented in the message management
- Differing number of connection points in the symbol and the function definition: is documented in the message management
- Overlapping connection points: are automatically corrected by the system during editing
- Referencing symbols are not broken up: are automatically broken up by the system during verification
- User-defined layers in the symbol: automatically converted during verification to the "EPLAN300" layer.

You can also start the check function manually in order to verify the quality of a certain symbol. Proceed as follows:

Preconditions:

- You have opened a project and at least one symbol library.
- You have opened the symbol to be checked in the symbol editor.

1. Select the following commands: Tab Edit > Command group Symbol > Drop-down button Other > Check symbol.
2. Confirm the prompt regarding the quality of the symbol.

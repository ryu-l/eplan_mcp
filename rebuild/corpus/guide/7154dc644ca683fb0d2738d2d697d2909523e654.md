# Identifier Sets, Connection Point Designations and Descriptions Moved to the Project Settings

In order to improve the standardization, user-friendliness and data consistency in projects, customizations were also carried out at the function definition library in the new version. For example, the identifier sets and the connection point designations and descriptions are now no longer stored in the function definition library, but rather integrated directly into the project settings.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

Saving of the identifier sets and the connection point designations and descriptions directly in the project settings avoids user-specific differences of the function definition libraries and ensures consistency. A central management in the project settings reduces complexity and ensures intuitive operation.

Project-specific schemes and export / import options offer flexibility, while new search fields and a clearly structured user interface simplify work and save time.

The definition of identifier sets and connection point designations and descriptions is now no longer carried out in the Master data tab of the ribbon but in the Settings: Numbering (online) dialog (command path: File > Settings > Projects > "Project name" > Devices > Numbering (online)).

[![](../Pictures/Gui/Lang/numerationgui_identifierset_ls_thumb_0_60.png)](../Pictures/Gui/Lang/numerationgui_identifierset_ls.png)

### New dialog for identifier sets

In the course of these modifications the drop-down list Current identifier set has been renamed to Identifiers and the [...] button has been added.

- New dialog: With the [...] button you branch to the new Identifiers dialog and can use the scheme technique here to create and edit an identifier set as a scheme.  
  Each identifier set is stored project-specifically in a separate scheme. In contrast to the previous dialog for the definition of identifier sets, only the identifiers of a set are displayed here in the Identifier column.
- Predefined schemes: Frequently used standards are provided as schemes. (The outdated identifier set "IEC" is applied when used in an older project, but cannot be edited anymore.)
- Export and import functionalities: The schemes for the identifier sets can be exported and imported. The exported file can be used, for instance, as a data backup or for the exchange of data.

### Moved dialog for connection point designations and descriptions

The connection point designations and descriptions have now also been moved from the ribbon into the project settings.

- New button: The Settings: Numbering (online) dialog has been extended with the new button [Connection point designations and descriptions]. When this button is activated, the familiar Connection point designations and descriptions dialog is opened.
- Export and import functionalities: The connection point designations and descriptions can be exported and imported together with the project settings of the Settings: Numbering (online) dialog. The assignments to the function definitions are retained during exporting and importing.

### Extension with search fields

A search field has been added to both the new Identifiers dialog as well as the Connection point designations and descriptions dialog. This way you can filter the displayed data specifically by function definitions and reduce the data volume rapidly.

### Importing of older projects

When projects from older versions are imported, the identifier sets and connection point designations / descriptions stored in the function definition libraries are transferred automatically to the settings of the respective project.   
The outdated identifier sets "IEC" and "IEC 61346" are only transferred if they were used in the project.

### Simplified user interface

Some elements in the user interface have been removed in the context of the conversion of the function definition libraries:

- In the Master data tab of the ribbon, the Connection point designation and Identifier sets commands no longer required anymore have been removed.
- In the Function definitions dialog, the Identifier field has been removed since the identifier displayed there originated from the outdated identifier set "IEC".

# Automatically Numbering New Devices

New devices / functions which you insert by means of the insert center into the schematic pages or create in a navigator without placement, can be numbered automatically on insertion or creation. A DT is determined and automatically assigned online for every new device / function, depending on the online numbering format selected. If the online numbering format contains a counter, the DT's counter is incremented.

![](../Pictures/Gui/ALL/note.png)Note:

Only the device groups that you have selected in the online numbering format are numbered.

Preconditions:

- You have opened a project.
- You have opened a schematic page.

1. Select the following commands: File > Settings > Projects > "Project name" > Devices > Numbering (online).
2. Under On symbol insertion, select the Number option.
3. If you want to create or edit an online numbering format, click [...] next to the Numbering format field.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Numbering formats dialog opens. Here you can define an [Online numbering format](numerationgui_h_onlineformat.htm). Click [OK].
4. If you want to use an existing online numbering format, select an online numbering format from the Numbering format drop-down list under On symbol insertion.
5. Click [OK].

### Insert and number a device / function via a symbol

1. Select the following commands: Insert center > Breadcrumb trail Home > Symbols. Using the folder structure navigate to the desired symbol and select it by clicking the preview tile.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol hangs on the cursor.
2. Move the cursor to the desired location on the schematic page.
3. Click the page to place the symbol.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Properties (components): <...> dialog opens.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Displayed DT field proposes the displayed device tag for the new device / function according to the online numbering format.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol is placed and the DT is displayed in the schematic.

### Create and number a device / function without placement

1. Select the following commands: Tab Devices > Command group Devices > Navigator.
2. Select the Tree tab.
3. Select the project level or a structure identifier.
4. Select the New popup menu item.
5. Select a function definition in the Selection field of the Function definitions dialog and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Properties (components): <...> dialog opens.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have previously selected a project level, the Displayed DT field suggests the displayed device tag for the new device / function without a structure identifier, depending on the online numbering format selected.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have previously selected a structure identifier, the Displayed DT field proposes the displayed device tag for the new device / function with a structure identifier, according to the online numbering format selected.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The device / function is created in the device navigator.

# Dialog Numbering formats

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. File > Settings > Projects > "Project name" > Devices > Numbering (online). Click [...] next to the Numbering format field in the Settings: Numbering (online) dialog.
- Tab Tools > Command group Standards > Exchange. Make the necessary entries in the Project, Rotation / flipping, Master data, Symbols and Structure tabs and click [Next] each time. In the Numbering tab, next to the Device numbering field, click [...].

Use this dialog to manage all numbering formats for online numbering of devices. You can create, edit, copy, delete, import, and export numbering formats. You can select these numbering formats for devices that you place on the schematic page using the Insert center (Insert center > Breadcrumb trail Home > Symbols). You can also select these numbering formats for devices that you insert into the schematic page using macros or copy processes.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

---

Tab DT

General devices ... Mechanical devices:

This field contains the DT format for the respective functions. Click [...] to open the DT format dialog, which is where you can edit the format. If the check box is activated, the functions are automatically numbered on insertion. If the check box is deactivated, the functions are not automatically numbered on insertion.

Number nested components:

If this check box is selected, then components allocated to a superior component are automatically numbered on insertion. If the check box is deselected, then these components are not automatically numbered on insertion.

---

Tab Designations

Terminals ... Busbar connection points:

If the check box is activated, the respective designations are automatically numbered on insertion. If the check box is deactivated, the designations are not automatically numbered on insertion. The format for the designations is shown in the field next to the check box. Click [...] to open the DT format dialog, which is where you can edit the format.

PLC addresses:

If the check box is selected, then PLC addresses are automatically numbered on insertion. If the check box is deselected, then PLC addresses are not automatically numbered on insertion.

Terminal sort codes:

This setting only affects existing terminal sort codes on insertion of macros and copies.

If the check box is selected, then existing sort codes are automatically numbered on insertion. The highest sort code in the terminal strip is identified and incremented by one. Therefore, the newly inserted terminals are always sorted at the end of the terminal strip. If several terminals have a sort code, their sequence is retained by ascending sort code values. The numbering does not separate consecutive terminals. If at least one terminal in the macro or copy has a sort code, all the other terminals inserted, except the graphically sorted terminals, are given a sort code.

If the check box is deactivated, the sort codes of the inserted terminals are not changed. The terminals are then sorted between the existing terminals according to their sort code or terminal designation. This can mean that terminals that were previously consecutive (e.g. multi-level terminals) can be separated.

Do not modify PE, N, and SH terminals:

If the check box is activated, PE / PEN, N, and SH terminals are not numbered. The designation of the PE, PEN, N, and SH terminals remains unchanged.

Do not modify PE, N, and SH pins:

If the check box is activated, PE / PEN, N, and SH pins are not numbered. The designation of the PE, PEN, N, and SH pins remains unchanged.

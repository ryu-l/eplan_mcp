# Tab Tool Selection (NC Export All Machines)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > Company > Machining > "NC export". Select the Tool selection tab.
- File > Export > Command group Manufacturing data > Machining > "NC export". Click [...] next to the Machine field. Select the Tool selection tab.

In this tab, you specify the export behavior in the event of a missing suitable tool at the machine.

The behavior in case of a missing drill or thread cutter is defined separately.

Furthermore, a definition is made here as to the diameter size from which a round section is no longer drilled, but milled.

Overview of the main dialog elements:

Group box Drill holes (not for Rittal - Perforex LC)

Use a different drill (if a suitable tool is not available):

If no suitable tool is available for the required drilling diameter at the machine, another drill can be used.

If this check box is activated, another tool will be used in the event of a missing suitable tool. Via the Drill to be selected drop-down list, you specify whether the next smaller or next bigger tool is to be used for drilling.

Mill larger drill holes:

If a machine can drill and mill, you can enter a drilling diameter from which no tool is available for drilling and from which another technology is to be used instead.

If this check box is activated, drill holes exceeding the defined value will be milled. In the Diameter limit value field, you enter the drilling diameter from which to switch to the alternative technology.

---

Group box Thread (if a suitable tool is not available)

If no tap suitable for the required thread diameter has been defined at the machine for manufacturing threaded holes, there are 2 alternatives how the machine should react.

Drill only core hole:

With this setting, no threaded holes are drilled. If this option is activated, only the thread core hole will be drilled with the tool set aside for this task, and the thread will be post-processed manually later on.

Use different thread cutter:

As an alternative to working without thread cutting, another thread cutter can be used.

If this option is activated, another tool will be used in the event of a missing suitable tool. Via the Thread cutter to be selected drop-down list, you specify whether the next smaller or next bigger tool is to be used for thread cutting.

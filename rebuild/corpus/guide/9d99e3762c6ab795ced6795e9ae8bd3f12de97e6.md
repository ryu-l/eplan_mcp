# Backstage View: Command Area

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File

All the functionalities for the management and transfer of your projects are available in the Backstage view of Eplan. Depending on the command (left) selected in the command area, further commands and / or dialog elements are shown in the displayed area (right).

Overview of the main dialog elements:

|  |  |
| --- | --- |
| Command | Meaning |
| Information | Branches in the Backstage view Information. With the tabs [Properties](prjmanagementgui_r_eigenschaften.htm), [Statistics](prjmanagementgui_r_statisitk.htm), [Structure](prjmanagementgui_r_struktur.htm) and [Status](prjmanagementgui_r_status.htm) you can have information on the active project displayed and edit the project properties as well as the structure. |
| New | Opens the [Create project](prjmanagementgui_d_projekterstellen.htm) dialog and allows you to create a new project by means of a basic project. |
| Open | Branches to the Backstage view Open and allows you to [Open a project](prjmanagementgui_h_backstageprojektoeffnen.htm). You can access the projects used most recently via the tab Last used. The Browse command opens the Open project dialog for the selection of any project. |
| Back up | Opens the [Back up projects](bakbackupdlggui_d_projektesichern.htm) dialog and allows you to back up, archive or file off projects. |
| Copy | Opens the [Copy project](prjmanagementgui_d_projektkopieren.htm) dialog and allows you to copy the active project. |
| Delete | Deletes the active project |
| Close | Closes the active project. |
| Project management | Opens the Project management dialog. The project management allows you to manage all aspects of your projects. |
| Revision control | Branches into the Backstage view Revision control. Here you have the option of working with change tracking or using the property comparison of projects. |
| Print | Branches in the Backstage view Print. Here you can specify the settings for the printing of the active project and [print](printgui_h_drucken.htm) it. |
| Collaboration | Branches in the backstage view Collaboration. Here you can define the [Defined working sections](/eservicesgui_d_bearbeitungsbereichdefinieren.htm), store and file off [Subprojects](subprojectservicesgui_k_grundlagen.htm) and open the [Multi-user monitor](eplan.eplcoreaddin.multiusermonitor_k_vorgehensweise.htm). |
| Import | Branches into the Backstage view Import. Here different import functionalities are available for project data, master data and manufacturing data. |
| Export | Branches into the Backstage view Export. Here different export functionalities are available for project data, master data and manufacturing data. |
| Extras | Branches into the Backstage view Extras.  In the command group Organize you can [compress](projectcleangui_h_projektsaeubern.htm), [correct](ProjectCorrectionGui_h_projektkorrigieren.htm) and [synchronize](projects_h_projekteabgleichen.htm) projects as well as create a basic project from the current project. You also have the possibility to back up and restore master data.  In the command group System you can access system messages.  In the command group Extensions you can edit projects automated, and manage scripts, add-ons and add-ins. You also have the possibility to use the rights management. |
| Settings | Opens the Settings dialog. In this dialog you can make all project-specific, user-specific, workstation-specific, and company-specific settings. |
| Help | Branches into the Backstage view Help. Here you find information among other things on Eplan products and on your Eplan version. You can also create a support request or obtain program components via the Eplan Download Manager. |
| Exit | Closes the current Eplan application. |

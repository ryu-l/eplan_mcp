# P028025: Macro at the planning object is placed several times in a representation type

### Cause

A macro stored at a planning object was placed more than once in the same representation type.

### Solution

1. Locate the macro placed several times with the same representation type via the functionality Go to (2nd coordinate), which the popup menu of the Message management dialog offers you.
2. Delete the superfluous macro placements in the respective representation type.
3. If required, start a new check run.

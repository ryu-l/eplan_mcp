# Tab DXF general Settings: Export NC - DXF / Settings: Export DXF - copper)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Export NC - DXF:

- File > Export > Command group Manufacturing data > Machining > NC - DXF. Click [...] next to the Machine field. Select the DXF general tab.
- File > Settings > Company > Machining > Export NC - DXF. Select the DXF general tab.

Export DXF - copper:

- File > Export > Command group Manufacturing data > Machining > DXF - Copper. Click [...] next to the Machine field. Select the DXF general tab.
- File > Settings > Company > Machining > Export DXF - copper. Select the DXF general tab.

In this tab, you specify the general settings of the NC export in the DXF format used by many machines.

Overview of the main dialog elements:

Group box Format

AutoCAD version:

Here you select the format of the AutoCAD version in which the DXF data is to be exported.

Code page:

Setting as to the character set that is to be used. The default is the Windows character set CP\_ANSI\_1252.

---

Output directory:

In this field, you set the storage location for the DXF file to be generated. You can specify any drive and subdirectory as the target for the export.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

Generate file names:

In this drop-down list you specify the default method for allocating file names during the DXF export:

- From consecutive number: If you select this option, Eplan assigns names to the DXF files using the pattern <Consecutive number>.DXF by default. If DXF files already exist, Eplan starts the numbering with the next available number.
- From item designation: If you select this option, Eplan assigns names to the DXF files using the pattern <Item designation>.DXF by default.
- From properties: If you select this option, the file name is made up of the layout space, project, and device properties plus any freely-definable separators. Use the [...] button to open the Format: Property dialog to configure the file name.

Generate subdirectories:

In this drop-down list you specify the default method for generating subdirectories during the DXF export:

- None: If you select this option, no subdirectories are generated during the export.
- From project structure: If you select this option, subdirectories that reflect the project structure are automatically generated during the export.
- From properties: If you select this option, the substructure name is compiled from the layout space, project and device properties as well as freely-definable separators or directory separators. Use the [...] button to open the Format: Property dialog to configure the directory name. Here you can use the "directory separator" format element, for example, to generate a directory structure with multiple subdirectories arranged one below the other.

# P003009: Differing cable data: <x>

### Cause

At the main and auxiliary functions you are using contradictory cable data at a distributed cable displayed in the schematic with regard to the properties Type, Number of connections and / or Connection: Cross-section / diameter. The applicable properties are output in the placeholder '<x>'.

### Solution

#### Possibility 1

1. Locate the functions of the cable displayed as distributed using the Go to (cross-referenced) functionalities from the popup menu in the Message management dialog.
2. In the Search results <Project name> dialog double-click the entered cable definition of the main and auxiliary functions and call up the property dialog of the respective cable definition.
3. Assign identical cable data to the main and auxiliary functions of the cable.
4. Confirm your entries.

#### Possibility 2

Use the synchronizing of functions.

1. In the schematic select the cable definition line of the main or an auxiliary function of the cable displayed as distributed, whose cable data you want to transfer to all functions of the cable.
2. Select the following commands: Tab Tools > Command group Synchronization > Drop-down button Functions.
3. Decide, depending on the Representation type, which type of synchronization you want to perform. Use, for example, the command Multi-line --> All representation types if you have configured the selected cable definition line whose data you want to transfer as multi-line.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The cable data of all functions of the cable displayed as distributed are synchronized correspondingly to each other.

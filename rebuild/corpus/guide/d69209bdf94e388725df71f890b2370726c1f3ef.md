# P004007: Rack '<x>' is mounted on itself

### Cause

Identical designations were entered at a PLC box that contains PLC structure data in the Rack ID and PLC card is placed on rack ID fields, which means that the rack is mounted on itself.

### Solution

1. Open the Properties <...> dialog of the corresponding PLC box.
2. Bring the PLC structure data tab to the front.
3. In the first tab, enter different data into the Rack ID and PLC card is placed on rack ID fields.
4. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

This check run only checks PLC boxes at which a configuration project is entered.

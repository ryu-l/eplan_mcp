# Tab Data (Settings: External Editing)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call up (for project data):](javascript:void(0);)

- You have opened a project. File > Export > Command group Project data > Project data > Command group External editing > Properties. Click [...] next to the Settings field in the Edit externally dialog. Select the Data tab.
- File > Settings > User > Interfaces > External editing. Select the Data tab.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call up (for parts data):](javascript:void(0);)

Tab Master data > Command group Parts > Management. In the Parts management dialog you have opened a parts database using [Extras] > Settings. Button [Extras] > Edit properties externally > Export data. Click [...] next to the Settings field in the dialog Edit externally. Select the Data tab.

On this tab, you can specify the data to be considered during external editing.

Overview of the main dialog elements:

Category:

Only available for export of project data. From this drop-down list, select the type of properties to be displayed in the list.

Find:

Only available for export of project data. Into this field enter the text for which the properties are to be filtered.

If you want to return to the original view of the properties, remove the search term from the entry field. Click ![](../Pictures/Gui/ALL/all_delete_input_as.png) (Delete) to do so.

Available format elements:

Only available for export of project data. Depending on the category selected, the possible format elements are displayed in the list.

To export a format element, you have to move it to the right into the list of the selected format elements by using the button ![](../Pictures/Gui/ALL/all_arrowright_as.png). Multiple selection is not possible.

Source object:

Only available for export of parts data. Depending on the selected object type, possible source objects for a property from the parts management are displayed in the list. For a specific object type (e.g. part), not only the own data but also the data of associated other objects (e.g. function templates, drilling patterns, accessories, etc.) is output. In order to output data for such an associated object (e.g. for the fourth function template), click the respective node and select the subordinate source object in the list with the associated index (e.g. "Function template [4]").

To export a property you have to select the associated source object and move it to the right using the ![](../Pictures/Gui/ALL/all_arrowright_as.png) button. In the subsequent dialog Property selection, the available properties of this source object are displayed and you can select the desired property there. Multiple selection is possible.

Selected format elements:

In this list, the selected format elements are shown in tabular form with their designations and the information "Changeable" = "Yes" / "No". Using the buttons above the list, you can delete format elements or change their order.

| Button | Meaning |
| --- | --- |
| (Delete) | Deletes the selected format element. |
| (Move to the beginning) /  (Move to the end) | Moves a selected entry to the respective first or last position of the list. |
| (Move up) /  (Move down) | Moves an entry up / down in the list. |
| (Exchange) | Swaps the positions of two selected entries. |

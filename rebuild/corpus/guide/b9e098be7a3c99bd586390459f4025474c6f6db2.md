# Configuring the Display of Placeholder and Special Texts

To arrange form and plot frame editing more clearly, so that inserting graphical elements like lines and graphics is easier, there are the options described in the following.

Preconditions:

- You have opened a project.
- You have opened the form you want to edit in the form editor (Tab Master data > Command group Plot frames / forms > Drop-down button Form > Open > Button [Open]). Or you have opened the plot frame that you want to edit in the plot frame editor (Tab Master data > Command group Plot frames / forms > Drop-down button Plot frame > Open > Button [Open]).

### Hide placeholder texts

You can temporarily hide the placeholder text.

1. Activate the button Hide placeholders in the command group General in the View tab.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The placeholder texts are hidden.
2. Edit the graphical elements of the form.
3. Deactivate the Hide placeholders button to display the placeholder texts again.

### Display / output properties as numbers

The property texts are displayed as texts by default. However, this can be bothersome if there are several entries in a row, for example.

1. Select the following commands: Tab Edit > Command group Form / Plot frame > Drop-down button Other > Properties as numbers.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property texts are replaced by their internal ID numbers.
2. Edit the form / plot frame as desired.
3. Print the form / plot frame with this setting, to also include the numbers in the printout.
4. Export the form / plot frame with this setting as a PDF file, to also include the numbers in the created PDF file.
5. Select the Properties as numbers command to display the property texts as texts again.

### Display path divisions

It can be helpful to display paths if you want to make sure that you are placing a particular object in a particular path.

1. In the View tab in the command group Layout General activate the button Schematic paths.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The path division is displayed in the form / plot frame using lines.
2. Edit the form / plot frame as desired.
3. Deactivate the Schematic paths button to return to the display without schematic paths.

# Comments

In a project you have the possibility to store comments on the project pages. These comments are visible for other users working on the project.

Comments can be managed in Eplan in a navigator dialog and exchanged between a project editor and a project redliner either directly in Eplan or via a PDF file.

The following is possible:

- You can insert comments on project pages in Eplan. You can insert the comments not only as text, but also as a rectangle or as a polygon.
- You can import PDF comments that were stored in an Eplan project as a PDF file back into the Eplan project.
- You can create unplaced textual comments in the comments navigator and place them on the project pages later.
- You can edit the properties of comments and thus, for example, change the comment text, the status or possible replies. The comment text and the reply texts are multilingual and can be translated. (You have to activate the Free texts setting in the Settings: Extent dialog so that such texts are taken into consideration during the translation by a translation run.)
- By default, the comments inserted in Eplan are displayed on the layer "EPLAN109, Graphic.Comment texts" and the imported PDF comments on the layer "EPLAN519, Graphic.Comments". You can, for example, use the layer management to specify whether these layers and thus the comments are to be displayed and/or printed.
- You can delete individual selected comments or all comments of a project.
- You can track in the History tab who made which modifications to a comment and when.

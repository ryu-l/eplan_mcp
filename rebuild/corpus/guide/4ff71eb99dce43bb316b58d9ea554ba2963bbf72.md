# P007026: The logic model of the function deviates from the function definition

### Description

A value deviating from the function definition was found in the dialog Connection point logic of the function. For example the connection point type, the number of targets and / or the symbol connection point has been changed. Fields whose values deviate from the default setting are highlighted in this dialog by a yellow background.

The dialog Connection point logic is called up by clicking the [Logic] button on the Symbol / function data tab in the property dialog of the function.

The function can be located in the schematic by using the Go to (graphic) function from the popup menu in the Message management dialog.

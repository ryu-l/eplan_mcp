# Dialog Select identifier subclasses

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have inserted a symbol in the graphical editor or generated a new function in a navigator. You have selected the <Function category> tab In the Properties <...> dialog. In the Displayed DT field, select the popup menu item Identifier subclasses.
- You have selected a component in the graphical editor or a function in a navigator. Popup menu item Properties. You have selected the <Function category> tab. In the Displayed DT field, select the popup menu item Identifier subclasses.
- You have marked a planning object in the graphical editor or in the pre-planning navigator. Popup menu item Properties. You have selected the <Planning object displayed name> tab in the Properties <...> dialog. In the Product aspect field select the popup menu item Identifier subclasses.

In this dialog you select an identifier subclass, to be used for generating a new DT, from a selection list. The selected subclass is used at planning objects to generate a new product aspect. The identifier subclasses are stored in the project settings (command path: File > Settings > Projects > "Project name" > Devices > Numbering (online)).

Overview of the main dialog elements:

Filter:

Enter a string of characters into this field. As soon as you enter the first character, the cursor jumps to the first entry in the Subclass column that begins with that character and marks it. If this character / entry is not found in the Subclass column, the search is carried out in the columns Subclass task, Purpose or task of the object, Examples for products and Comments. If existing, the identifier subclass in which the string occurs for the first time is then selected.

Table:

In the Subclass column, select the desired designation of the identifier subclass and click [OK]. These characters are then adopted in the Displayed DT field in the component properties dialog. This generates a new DT and any existing identifiers are discarded.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Transfer subclass task to function text:

Not available for planning objects! If this check box is activated, the text from the Subclass task column is transferred to the function text, if the function is a main function. Existing function texts are overwritten in the process. Multilingual texts are transferred into all languages. No text is transferred for auxiliary functions.

# Dialog Settings: Manufacturing data export / labeling

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. File > Export > Command group Manufacturing data > Manufacturing data > Labeling. Click [...] next to the Settings field in the dialog Export manufacturing data / output labeling.
- File > Settings > User > Interfaces > Manufacturing data export / Labeling.

In this dialog, you can manage and edit schemes for the manufacturing data export / labeling. Corresponding settings are specified in a scheme.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Report type:

An export / labeling scheme is always created together with a report type. In this field, the report type is displayed that you selected for the current scheme.

# Dialog "STEP export" / Dialog "VRML export" / Dialog "IFC export" / Dialog "JT export"

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have selected a layout space in the layout space navigator. File > Export > Command group Project data > Layout space > STEP, VRML, IFC or JT.

In this dialog you specify the settings for the export of the 3D graphic data to the STEP, VRML, IFC or JT format.

Overview of the main dialog elements:

Source:

This field displays the source of the export. In the case of an entire project, this is the project name; for individual layout spaces the full layout space names are displayed (including the structure identifiers Functional assignment, Function designation, etc.). The entries in this field cannot be modified.

Scheme:

Select a scheme to define the settings for the STEP, VRML, IFC or JT export from the drop-down list.

The button [...] opens the dialog Settings: STEP export, dialog Settings: VRML export, dialog Settings: IFC export or dialog Settings: JT export. In this dialog you define the settings for exporting STEP, VRML, IFC or JT files and save them as a scheme.

Output directory:

The storage location is specified here. The directory that is defined for the STEP, VRML, IFC or JT export in the user settings is pre-selected. The ![](../Pictures/Gui/ALL/all_selectdirectory_as.png) button opens the Select folder dialog in order to select any directory of your choice for the export.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

File name:

When exporting a single layout space, you have the option of entering any random file name. You can use the ![](../Pictures/Gui/ALL/all_selectfile_as_20x15.png) button to assign a file name or select the name of an existing file.

If no file name is specified, a name is assigned to the exported file on the basis of the [Generate file names](gededit3dgui_d_einstellungenstepexport.htm#Dateinamenerzeugen) setting.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

When exporting multiple layout spaces, the file name cannot be freely chosen. STEP, VRML, IFC and JT files are created in the specified target directory either as a consecutive number, or from the layout space name, or from the properties - this depends on the settings of the selected scheme.

If a layout space is selected which contains several enclosures and, in the dialog Settings: STEP export the Separate export per enclosure setting has been activated, it is impossible to enter the file name. The File name field is deactivated in this case.

Apply to entire project:

If you activate this check box, the currently selected layout space is extended to all layout spaces of the project.

If this check box is deselected, then only the selected layout spaces are exported.

If you have already selected a single project (and not set any filters), then this check box is grayed-out. You can then no longer change the relevant settings.

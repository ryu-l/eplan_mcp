# Dialog Edit cable (compatibility)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have selected a cable definition line or a shield in the graphical editor. Or you have selected a connection or a connection definition point, at which the "Cable" value is set for the Connection: Association property. Select the command Edit cable (compatibility). (To this purpose you first have to [Customize the ribbon](userinterface_h_menuebandanpassen.htm) and then assign the desired command to a user-defined command group.)
- You have opened the cable navigator, for example via the following commands: Tab Connections > Command group Cables > Navigator. In the Cables - <Project name> dialog mark a cable definition and select the command Edit cable (compatibility). (To this purpose you first have to [Customize the ribbon](userinterface_h_menuebandanpassen.htm) and then assign the desired command to a user-defined command group.)

In this dialog, you can view and edit the assignment of the cable connections to the part connections for a cable. connections for a cable part can be assigned to the Connections of the cable defined in the schematic. The full DT for the cable is displayed in the title bar.

Cables with the representation types "External" or "Graphic" are not displayed here.

Use the popup menu to update connections and delete unplaced connections as well as edit connection properties.

Overview of the main dialog elements:

Function templates:

The cable connections defined in the cable definition are displayed in the table (the connections of the cable part).

---

Connections:

The cable connections defined for the cable in the project are displayed in the table with their targets. First the cable connections are shown whose function templates are assigned, then the cable connections for which no templates could be found. The named cable connections are listed first, then the unnamed cable connections:

- If a part is assigned to the cable, the part specifies the fixed sequence of the cable connections. The function templates of the part represent the connections of the cable part. Cable connections which override the function templates receive their sequence from them.
- If the cable has no part, or if no matching function template can be found, then the cable connections are output at the function templates, sorted alphanumerically by name.
- Unnamed cable connections are shown in graphical sequence (corresponding to the orientation of the plot frame).

The values shown in the columns of the table provide information and cannot be modified here, except for the Connection of this cable column.

Connection of this cable:

If this check box is checked, the connection becomes a cable connection of the cable. It adopts the name of the cable, and the "Cable" value is assigned to it for the Connection: Association property.

If the check box is not checked, the cable DT is removed from this cable connection. If the associated connection definition point has dependent connection definition points (due to a [DT adoption](devicetaggui_k_bmkuebernahme.htm)), then the dependent connection definition point adopts the DT.

Cable connections defined by a cable definition line or a shield cannot be removed from the cable. The check box is checked and grayed out in this case.

For existing cable connections which are not influenced by a cable definition line or shield, the check box is activated by default, but can be changed.

For cable connections added to the cable using the Collect cable connections action, the check box can be changed. The check box is activated if the value "Cable" has been assigned to the connections for the property Connection: Association. It is not checked if the connections are not identified as a cable connection. In this way, connections which were assigned the Cable connection point property through their connection points can easily be added to the cable. The collected cable connections are not assigned directly, but rather extend the list in the lower area.

Arrow buttons:

Use the arrow buttons to change the assignment of cable connections to the connections of the cable part (function templates). The buttons are only active if it is possible to move the selected connections. Moving or exchanging connections are displayed in the changes on the right side of the dialog. The function templates on the left side remain in the sort order they are in.

Connections can only be moved to available function template positions. No change to the connections is made when they are moved. The data on the connections (connection definition points) are correspondingly exchanged.

The potential type is taken into consideration in this case. This way, PE / PEN or SH conductors, for example, can't be moved to function template positions with other potential types. Nor is it possible to move them to a position with a different shield. Connections without shields, however, can be assigned to a function template with shielding.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| New | Generates a new connection. |
| Delete | Deletes the selected unplaced connections. Placed connections can't be deleted. |
| Collect cable connections | Searches all other connections that run between the same sources and targets of the cable and are not allocated to any other cable and puts these into the Connections table. |
| Assign cable connections | Resorts the sequence of connections for the selected cable. In doing so, it takes into consideration the rules for determining the source and target of the cable or â for terminals â the sequence of the terminals on the terminal strip.  The Keep existing properties option will retain existing connection properties without changing them. The assignment only occurs when all properties of the cable connections match those of the connection of the cable part.  The Reassign all option overwrites all cable connection properties with the connection properties from the part. |
| Properties (global) | Opens the Properties (global): <...> dialog. Allows the editing of the device properties. |

# Dialog Configure property arrangements - <Project name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Tab Tools > Command group Management > Property arrangements

You create user-defined property arrangements in this dialog. These arrangements are stored project-specifically and can be used at 3D part placements or components within a project.

Overview of the main dialog elements:

The user-defined property arrangements that exist in the current project are displayed on the left-hand side in the dialog in a tree and list view.

Property arrangements for 3D part placements already exist in a new project through the used basic projects. The property arrangements are only displayed for the component if a user-defined property arrangement was saved under a name here in the dialog or at the component.

While the user-defined property arrangements of the 3D part placements in the layout space are assigned to a function definition, the property arrangements for components are saved for a symbol variant.

Find:

Enter the text for which the property arrangements are to be filtered into this field. To this purpose the property arrangements are searched for both the identifying name as well as the displayed name.

If you want to return to the original view of the property arrangements, remove the text from the entry field. Click ![](../Pictures/Gui/ALL/all_delete_input_as.png) (Delete) to do so.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Library-oriented (tree only) | Only available at the property arrangements for components. Shows the symbol libraries in the highest node below the "Component" folder. Under them are the function definitions. |
| Function-oriented (tree only) | Only available at the property arrangements for components. Shows the functional category (such as "Coils and contacts" and "Signal devices") in the upper node below the "Component" folder. |
| New | Allows creating a new user-defined property arrangement. Depending on the marker in the tree or list the Function definitions or Symbol selection dialog is first opened and after the selection of a function definition or a symbol the dialog New property arrangement. |
| Insert into list of search results | Checks the usage of the marked structure property arrangements in the project and enters the found objects into the search results list. This way you can search via the popup menu item Go to (graphic) in the graphic for the used property arrangements of objects such as components, part placements, etc. |

---

New property arrangement

The marked hierarchy level is used as a filter when creating new property arrangements.

If you have selected a symbol variant or the component arrangement of a symbol variant, the New property arrangement dialog for entry of an identifying name is opened and then a property arrangement is created for components. If you have selected a function definition or the property arrangement of a function definition, a property arrangement for a function definition is created.

If you have selected a higher hierarchy level in the tree, the marked position is used as a filter for the subsequently opened dialog Function definitions or Symbol selection. Then, enter a unique identifying name for the property arrangement in the New property arrangement dialog.

![](../Pictures/Gui/ALL/note.png)Note:

Within a project, the identifying name must be unique and cannot be subsequently changed any more.

Multiple selection of property arrangements

A multiple selection of property arrangements or list structure levels is possible here. The following points are to be considered:

- If you have selected the property arrangements of different symbol variants or function definitions, a shared displayed name can be assigned for these property arrangements.
- For the same configuration (same properties, order of the properties and docking settings) you can directly edit the property arrangements in the tabs 3D functions or Components etc.
- For a different configuration you are shown the ![](../Pictures/Gui/ALL/eservicesgui_multipleselection_as.png) entry in the tabs 3D functions or Components. To still be able to configure the property arrangements together, you must mark the entry and then remove all previously selected properties via the button ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete). This way all selected property arrangements receive a completely new configuration!

After the shared editing the selected property placements and changed display settings are available at all selected property arrangements.

---

Identifying name:

Here, the unique name is displayed that you specified when you created the property arrangement. The property arrangement is managed in Eplan under this name.

Displayed name:

Here, enter the name under which the property arrangement is displayed in the project. Multi-lingual entry is possible.

Default:

If this check box is activated, the property arrangement is used as a default for all additional usages of the 3D part placement / symbol variant.

Default for cable connections:

Only available for connection definition points. If this check box is activated and this symbol variant is used for cable connections, this property arrangement is used as the default. You specify which symbol variant is used during placing of connection definition points for cable connections in the [Project settings](cablegui_r_allpoligeinpolig.htm). Connection definition points for cable connections are placed in the graphical editor when drawing cables / shields or during Drag & Drop from the cable navigator or connection navigator.

---

Configuration of the properties and display settings

The actual configuration of the properties with the associated display settings is effected for 3D part placements in the 3D functions tab and for components in the Component tab as well as in the tabs Connection points and Contact image. To this purpose the same setting options are available as in the [Display](devicetaggui_r_anzeige.htm) tab of the property dialog.

[Extras]:

| Menu item | Meaning |
| --- | --- |
| Check usage | Fills the Usage count column in the list view with the current numbers of how frequently the respective property arrangement is used in the project. Property arrangements not used receive the entry "0". |
| Remove unused property arrangements | Deletes user-defined property arrangements that are not used in the project. Fixed specified property arrangements (such as "Default value" or "Upper left, outside, 90°" at the boxes) are not removed. |

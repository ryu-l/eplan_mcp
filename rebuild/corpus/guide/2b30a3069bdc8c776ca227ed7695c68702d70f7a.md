# P026080: Could not create export data

### Cause

While data of the design space were being exported, it was established either that no 3D mounting layout is available or that the existing 3D mounting layout did not contain any cut-outs.

### Solution

1. Locate the design space using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Complete the 3D model imported from the M-CAD system by adding a 3D mounting layout, by cut-outs and / or corresponding elements that contain drill holes or cut-outs (such as mounting rails).
3. Export the data again.

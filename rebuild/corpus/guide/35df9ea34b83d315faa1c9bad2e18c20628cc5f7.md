# P003007: Multiple cable targets

### Cause

You have numbered a cable that has more than one cable target. In the process a numbering format is selected that outputs the device tag of the target as a counter in the device tag of the cable, for example -W(=ANL+EBO-X5/=ANL+EBO-H3). A conflict occurred since more than one cable target is available but only one target designation can be output.

![](../Pictures/Gui/ALL/note.png)Note:

You access the numbering settings for cables by first selecting the cable in the schematic and then selecting the following commands: Tab Connections > Command group Cables > Number. Then click [...] in the Settings field of the Number cables dialog. Open the Format drop-down list of the first tab in the Settings: Cable numbering dialog.

### Solution

1. Only assign one cable target to the cable.
2. Update the connections.
3. Subsequently number the cable again by using one of the following formats:

- According to source
- According to target
- According to source and target
- According to target and source

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any set desired check scheme) this module-specific message can be deleted from the message management dialog.

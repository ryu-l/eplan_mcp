# Action: OpenWorkspaceAction

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| Workspacename | Name of the workspace to be opened (a string). |
| Silent | Set or reset quiet mode (Boolean expression). In the "quiet" mode, all dialogs (e.g. error dialogs) are suppressed. |

OpenWorkspaceAction

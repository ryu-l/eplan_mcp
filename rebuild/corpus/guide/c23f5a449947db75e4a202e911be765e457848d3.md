# Aligning Elements Horizontally / Vertically in the Layout Space

The Align horizontally and Align vertically commands allow you to position several highlighted 3D part placements on a horizontal or vertical line. For this purpose, the 3D objects to be aligned must be on a common mounting surface or mounting rail. The line is formed from the midpoint of the two elements with the greatest distance between them. The even alignment of objects on different mounting surfaces is not meaningful. Therefore, alignment is not available when objects have been highlighted that are not positioned on a common mounting surface or mounting rail.

![](../Pictures/Gui/ALL/note.png)Note:

Note that you must run the Align on grid command after performing this action in order to reposition the insertion points on the grid.

Precondition:

You have opened a layout space. You have selected the "Front" 3D viewpoint.

1. Mark the corresponding 3D objects.
2. Select the following commands: Tab Edit > Command group Arrange > Align horizontally.  
   Or select: Tab Edit > Command group Arrange > Drop-down button Align horizontally > Align vertically.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan determines the centers of the two 3D objects with the greatest distance between them and aligns all elements to this line.

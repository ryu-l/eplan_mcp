# P004021: Address has been assigned more than once within a CPU

### Cause

An address was assigned multiple times within a CPU.

### Solution

1. Change the addresses of the affected PLC connection points by means of the Properties <...> dialog so that each address within a CPU is uniquely addressed. (Assign the CPUs to a PLC box by setting the CPU and CPU: Name properties).
2. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Notes:

- This check run is also output when multiple addressed PLC connection points are not assigned to any CPU.
- The check run also checks PLC connection points without DT. If multiple addressed PLC connection points without DT were determined, delete the PLC address at these connection points.

# Cross-references

The division of a selected plot frame in a page into line and column sections is the basis for forming cross-references in a project. In this procedure, a line represents a horizontal section and a column represents a vertical section of the plot frame. The numbering sequence of the sections can be alphabetic or numeric. It is also possible to use different numbering sequences (numeric / alphabetic) for the horizontal or vertical divisions of the sections.

The cross-reference itself makes it possible to easily find a particular component or specific information in a multitude of pages. For this reason it contains at least the required page designation. In addition, it may also contain the column and line information for orientation within the page.

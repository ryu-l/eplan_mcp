# Dialog Settings: Fonts

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > Company > Graphical editing > Fonts
- You have opened a project. File > Settings > Projects > "Project name" > Graphical editing > Fonts.

In this dialog, you specify the fonts which may be used for editing in Eplan. The fonts defined in the project settings have priority over the fonts defined in the company settings.

If a font entered in the project settings is not available on the computer, the appropriate font will be taken from the company settings. In copying actions (e.g. inserting a macro) the target project settings are used.

Overview of the main dialog elements:

Font 1 through Font 10:

In these 10 fields, you can select one font apiece from the drop-down list. Fonts which are installed on your computer are offered here. OTF fonts (Open Type Fonts) are not supported.

![](../Pictures/Gui/ALL/note.png)Note:

Fonts selected here must be installed on every computer on which they should later be used.

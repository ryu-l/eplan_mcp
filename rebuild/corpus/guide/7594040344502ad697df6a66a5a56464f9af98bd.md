# P004088: The PLC card name '<x>' is already being used at a rack or a CPU

### Cause

Within a configuration project a PLC card name that already exists at a different PLC card that is also a rack or a CPU was entered at a PLC card which represents a rack or a CPU.

This check run only checks PLC boxes at which a configuration project is entered.

### Solution

1. Use the search function to locate the PLC boxes in the schematic: To this purpose enter the PLC card name that is output in the placeholder '<x>' as the search text.
2. Navigate to the respective PLC box via the displayed search result by using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog, and open it.
3. Bring the first tab to the front.
4. Change the value of the PLC card name property in the property table. In the process ensure that a PLC card name is assigned to each rack or each CPU.
5. Click [OK].
6. If required, start a new check run.

![](../Pictures/Gui/ALL/info.png)Tip:

The [Edit in table](functiondatagridgui_k_start.htm) function can also be used for comfortable searching for errors in the project. Simply create a scheme that displays the PLC card name and the required PLC structure data in a clearly structured form.

# Dialog: Settings: Settings comparison of projects

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have selected a project management database. You have loaded directories and projects. File > Project management. Select the input project with the advanced project status. [Extras] > Verify project. Click [...] next to the Compare settings field.

In this dialog, you can manage and edit schemes for comparing settings. This type of scheme stores the information defining the settings to be compared between the input project and a comparison project during project comparison.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Settings to be compared:

Shows all project-related settings that Eplan can compare when performing project comparisons. These settings correspond to the settings under File > Settings > Projects > "Project name". If the check box in front of an entry is selected then a check is made to see if this setting and all subordinate settings are the same for the [comparison project and incoming project](processreceiptcontrol_k_projekte.htm).

# Dialog Format: Page / column / row (Connection Numbering)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the [Settings: Connection numbering](wirenumberinggui_d_verbnumeinstellungen.htm) dialog (for example by using File > Settings > Projects > "Project name" > Connections > Connection numbering). You have selected a user-defined scheme in the dialog Settings: Connection numbering and have selected the Designation tab. You have selected an entry in the Format groups field and clicked ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit), or you have clicked ![](../Pictures/Gui/ALL/all_new_as.png) (New).

Select a format element of the type "Page", "Column" or "Row" in the Available format elements list of the dialog Connection numbering: Formats and move it to the Selected format elements list by using the arrow button.

In this dialog, you specify the formatting for a page name, column or row number in the format group.

Overview of the main dialog elements:

From source:

Select this option so that the page name, column, or row number of the source item is used for the format.

From target:

Select this option so that the page name, column, or row number of the target item is used for the format.

Minimum number of digits:

Here you define the minimum number of characters to be used for the property value. Longer values are displayed in their full length. Only positive numeric values are permitted. A value of zero means that the field width is variable.

Filler character:

The value is padded with this character if the minimum number of digits is larger than the width of the value. A padding character cannot be entered for a variable number of digits (entry of "0" in the Minimum number of digits field).

Show data of individual connections:

If this check box is activated, the chosen property for each connection is displayed. The connection designations can then differ within the extent.

If this check box is deactivated, the value of the property is displayed for the first connection in the extent. This value will then be the same for the entire extent (e.g., the net).

![](../Pictures/Gui/ALL/note.png)Note:

If you want to apply existing connection designations from the extent during the repetition of numbering, the check box Show data of individual connections must be deactivated. The application of existing connection designations is not supported at an activated setting since different connection point designations can be located within the scope.

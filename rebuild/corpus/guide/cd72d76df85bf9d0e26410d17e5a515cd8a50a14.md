# Graphical Reports

Graphical reports provide a clear overview of the process of a plant, a machine or a device. In Eplan, you can create for example simple text-based functional diagrams with placed property texts and symbol-based functional diagrams with inserted device symbols.

Graphical reports can occur several times in the project.

The following table shows graphical reports.

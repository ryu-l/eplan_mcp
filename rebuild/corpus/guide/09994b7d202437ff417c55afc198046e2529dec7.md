# Managing Multilingual Parts Data

If you want to use foreign-language designations, for instance for deliveries overseas, you can create and edit the parts master data in different languages. Multilingual entries for parts are possible in the Properties tab e.g. for the Part: Designation [1 - 3] and Description properties. By default, multi-lingual, editable input fields are identified as well in the parts management with a preset icon. A list of the possible multilingual properties for parts management can be found in the user-specific translation settings (Settings: Parts management dialog / Parts management tab).

### Define translation settings

1. Select the following commands: Tab Master data > Command group Parts > Management.
2. Select the Translation > Settings menu items in the Parts management dialog below the [Extras] button.
3. Switch to the Project-independent tab in the Settings: Translation dialog.
4. Select the translation languages, into which the part text is to be translated, from the Languages list: Use the buttons above the field to add or delete languages.
5. In the Source language field you define the source language for the translation of non-project-specific texts. From the drop-down list you can select either the dialog language or a language that you have already set as the translation language.  
     
   ![](../Pictures/Gui/ALL/arrow.png) When translating, Eplan searches the dictionary for suitable keywords for this language and translates them into all the selected translation languages. If the ##\_## (dialog language) option is selected, the source language is automatically matched to the dialog language currently set in Eplan.
6. Click [OK].

### [ClosedTranslate texts manually](javascript:void(0);)

Preconditions:

- You have opened the Parts management dialog (Tab Master data > Command group Parts > Management).
- You have entered a text in the source language for the multilingual property of a part and positioned the cursor in the respective field.

1. Select the Translate popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If there are already translations in the dictionary for the term you entered, the Found words dialog is opened, listing all the texts in the source language beginning with the letters entered.
2. In the Found words dialog, select the matching translation text by double-clicking.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If there are no translations in the dictionary, the Translate dialog is launched to enable you to enter a new translation text.
3. If necessary, edit the translation text in the Translate dialog, or enter a new translation text.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The text is translated. The preset icon ![](../Pictures/Gui/ALL/navigatorgui_globecolor_as.png) identifies the text as language-dependent.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Enter the text "Tacho" for the Part: Designation 2 property in the Value column. Select the Translate popup menu item. The Found words dialog lists the following entries:  
DE: Tacho EN: Tachometer  
DE: Tachogenerator EN: Tachometer generator

Double-click the entry you want. The Multilingual input dialog opens and you can edit the translation.

### [ClosedEnter translation texts](javascript:void(0);)

Preconditions:

- You have opened the Parts management dialog (Tab Master data > Command group Parts > Management).
- You have entered a text in the source language for the multilingual property of a part and positioned the cursor in the respective field.

1. Select the Multilingual input popup menu item.
2. In the Multilingual input dialog, enter the translation text.
3. Click [OK].

### [ClosedDelete translation texts](javascript:void(0);)

Preconditions:

- You have opened the Parts management dialog (Tab Master data > Command group Parts > Management).
- You have translated a text for the multilingual property of a part or have stored a translation text.

1. Position the cursor in the respective field.
2. Select the Remove translations popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The translation texts of the currently selected property are deleted. The preset icon ![](../Pictures/Gui/ALL/navigatorgui_globegrey_as.png) identifies the text as language-neutral.

### [ClosedImport part texts](javascript:void(0);)

1. Select the following commands: Tab Master data > Command group Parts > Management.
2. Select the Translation > Import part texts menu items in the Parts management dialog below the [Extras] button.
3. In the Select languages dialog, select the languages whose texts are to be imported into the dictionary and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts texts are imported.

# P005031: A connection designation is added to the connection definition point (<y>) located on a section of the connection (<x>)

### Description

A connection definition point that has the property No connection designation (drop-down list Valid data in the dialog Properties <...>) has been centered on the section of a connection. During the placement of further connection definition points the connection definition point that was previously inserted centered is prepared for the connection designation. The value of the property in the drop-down list Valid data changes automatically to "All data".

![](../Pictures/Gui/ALL/note.png)Note:

This module-specific message is output during the numbering of connections. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

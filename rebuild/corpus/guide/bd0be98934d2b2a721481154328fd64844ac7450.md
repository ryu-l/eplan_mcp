# P001038: Multiple main terminals with same device position

### Cause

Multiple main terminals with same device position (property Terminal: Device position) are defined for a terminal device.

The following applies with regard to the usage of main terminals:

- Only one main terminal may exist per terminal device.
- Two terminal devices must not have the same device position.

This means: Only one main terminal may exist per device position.

### Solution

1. Locate the relevant main terminals in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Deactivate the Main terminal check box for all main terminals apart from one in the property dialog.   
   Or enter different values for the Terminal: Device position property for all main terminals apart from one in the property dialog.
3. Confirm your entries.
4. If required, start a new check run.

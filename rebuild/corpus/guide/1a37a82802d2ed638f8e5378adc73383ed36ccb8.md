# Notes on the Scope of Service

This documentation describes the entire scope of service of the software. This service scope is available to you if you have licensed all of the products and modules. Insofar as this is not the case, this documentation is extended beyond the scope of the current software procured by you, that is, functions may be described which you do not have access to.

The scope of service of the software you have purchased is determined exclusively by the service description of the software you have licensed. Thus, this documentation has solely informational character for any additional services as well as scope of the service that you can also purchase.

Information about the software you have currently licensed can be found in the Backstage view Help (command path: File > Help > Command group Information > Licensed add-ons).

# P001029: A connection definition point lies on a connection between distributed terminals when the jumper optimization is activated

### Cause

A connection definition point was placed on a connection between two distributed terminal connection points. At a later time the Jumper optimization project setting was activated. When the jumper optimization is activated, the graphically drawn connections are not used for jumper creation. The connection definition point placed on the schematic page can therefore not be assigned to the logical connections arising during the jumper optimization and cannot transfer any data to the logical connection.

### Solution

#### Possibility 1

1. Locate the connection definition point in the schematic by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Delete the connection definition point on the connection between the distributed terminal connection points.
3. Update the connections.
4. If required, start a new check run.

#### Possibility 2

Deactivate the Jumper optimization project setting in the Settings: Distributed terminals dialog (command path: File > Settings > Projects > "Project name" > Device > Terminals (distributed terminals)).

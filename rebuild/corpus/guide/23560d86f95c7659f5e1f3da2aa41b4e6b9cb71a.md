# P028006: The full DT of the function does not match the pre-planning

### Cause

The full DT of the function does not match the defined identifier structure of the planning object. It is checked whether parts of the full device tag specified by the planning object (and the structure in which the planning object is embedded) match those of the function. For example, if only the function designation was defined in the pre-planning, only the function designation of the function will be compared.

### Solution

1. Locate the function in the pre-planning navigator using the Synchronize selection function offered by the popup menu in the Message management dialog.
2. Rename the DT of the function, or assign it to the function again, or re-number the DT taking into account the defined pre-planning structure.
3. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

If the "Product" identifier block is used in the pre-planning, and if the structure identifier used in it contains a question mark, the identifier, too, will be checked by means of this check run.

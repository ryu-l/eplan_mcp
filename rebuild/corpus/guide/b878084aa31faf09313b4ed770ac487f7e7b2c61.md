# Inserting Comments

You can insert comments directly into Eplan on project pages, either as text or as a rectangle or polygon. It is also possible to import comments from the PDF file of an Eplan project or to create unplaced comments in the comments navigator.

Preconditions:

- You have opened a project.
- You have opened a project page in the graphical editor.
- You have opened the comments navigator.

### [ClosedInserting comment as text](javascript:void(0);)

1. Select the following commands: Tab Insert > Command group Text > Comment.
2. In the Comment tab of the property dialog, enter a text into the Comment text field.
3. To format the comment, change to the Format tab and make the desired settings there.
4. Click [OK].
5. Place the comment at the desired position on the project page.
6. End the action via the Cancel action popup menu item or via the [Esc] button.

### [ClosedInserting a comment as a rectangle](javascript:void(0);)

1. Select the following commands: Tab Insert > Command group Text > Drop-down button Comment > Rectangle.
2. Define the starting point of the rectangle.
3. Drag the rectangle into any direction and define the end point.
4. In the Comment tab of the property dialog, enter a text into the Comment text field.
5. To format the comment, change to the Format tab and make the desired settings there.
6. Click [OK].
7. End the action via the Cancel action popup menu item or via the [Esc] button.

### [ClosedInserting a comment as a polygon](javascript:void(0);)

1. Select the following commands: Tab Insert > Command group Text > Drop-down button Comment > Polygon.
2. Define the starting point of the polygon.
3. Specify the further points of the polygon consecutively.
4. Exit the action using the [Space bar] or the Complete polyline popup menu item.
5. In the Comment tab of the property dialog, enter a text into the Comment text field.
6. To format the comment, change to the Format tab and make the desired settings there.
7. Click [OK].
8. End the action via the Cancel action popup menu item or via the [Esc] button.

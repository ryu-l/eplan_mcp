# P005085: Connection is marked for deletion

### Cause

A connection definition point was determined in the project at which the property Marked for deletion is activated. The property is always set by the program when you have imported a connection definition point by means of an external program that was deleted in the external program.

### Solution

1. Locate the connection definition point in the project by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Call up the properties dialog of the connection definition point and deactivate the Connection is marked for deletion check box. Or delete the connection definition point.
3. If required, start a new check run.

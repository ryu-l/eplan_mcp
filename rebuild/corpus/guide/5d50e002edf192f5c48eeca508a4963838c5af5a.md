# Dialog Coordinate input

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a project page in the graphical editor. Tab Edit > Command group Options > Coordinate input.

In this dialog, enter the target coordinates where the cursor is to be positioned. Entry is relative to the point of origin of the coordinate system used.

Overview of the main dialog elements:

Current cursor position:

When the dialog is called up, the current position of the cursor is displayed. Enter the target coordinates in the X and Y fields.

Coordinate system:

In this group box, the coordinate system assigned via the page type is selected by default. You can temporarily switch coordinate systems, which influences the position of the base point (coordinate origin).

- Graphic: The graphical coordinate system has its origin on the lower left. Coordinate values are entered in the unit "mm".
- Electrical engineering: The electrical engineering coordinate system has its origin in the upper left-hand corner of the drawing area. Coordinate values are entered in grid increments.
- Fluid power: The fluid power coordinate system has its origin at the lower left. Coordinate values are entered in grid increments.
- Process engineering: The process-specific coordinate system has its origin at the lower left. Coordinate values are entered in grid increments.

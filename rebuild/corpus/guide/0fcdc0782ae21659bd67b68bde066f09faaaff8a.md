# Dialog Symbol library properties - <Library name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Tab Master data > Command group Symbols > Drop-down button Symbol library > New. Select the [Save] button in the subsequent dialog.
- You have opened a project and at least one symbol library. Tab Master data > Command group Symbols > Drop-down button Symbol library > Properties. If multiple symbol libraries are open, select the one you would like to edit in the Symbol library selection dialog.

In this dialog you specify the properties for the newly created or the selected symbol library.

Overview of the main dialog elements:

Property name / Value list:

The available properties are displayed depending on the selected category. Some of them, for example "Creator", "Number of symbols," and "Creation date" have already been assigned values that cannot be changed. Others, such as "Symbol library description" and "Version", can be assigned values or their existing values can be changed.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# P013050: Project part cannot be added

### Cause

The project part required could not be added when importing the bill of materials because the maximum possible number was exceeded.

![](../Pictures/Gui/ALL/note.png)Note:

In Eplan the number of importable project parts is restricted to a maximum of 1,000.

### Solution

1. Open the import file with a text or XML editor and delete the surplus project parts.
2. Save the file, then import the bill of materials again.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

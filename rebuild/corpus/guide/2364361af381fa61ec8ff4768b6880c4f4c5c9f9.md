# P003025: Number of connections not specified

### Cause

The number of connections is not specified for the cable's main function.

### Solution

1. Locate the cable's main function in the schematic from the Message management dialog using the Go to (graphic) functionality.
2. There double-click the marked cable definition line and call up the Properties <...> dialog for the cable.
3. If not already set by default, switch to the Cable tab and enter a value in the Number of connections field. Alternatively you can carry out a part selection and assign a suitable type to the cable. To do this, click [...] beside the Type field and select the cable with the required properties from the part selection dialog.
4. Click [OK].
5. If required, start a new check run.

# Tab Bundle connection point

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a project page in the graphical editor.

- Tab Insert > Command group Symbols > "Bundle connection point type" (for example ![](../Pictures/Gui/ALL/ribbon_straightline_as.png) Bundle connection point: Straight line). You have placed the connection symbol. In the Properties<...> dialog, select the Bundle connection point tab.
- You have double-clicked a bundle connection point (or have selected the Properties popup menu item. In this case several bundle connection points can also be marked). In the Properties<...> dialog, select the Bundle connection point tab.

Bundle connection points allow the switch from multi-line to single-line representation. These symbols are used to combine individual connections into a bundle or to separate a bundle into individual connections.

Overview of the main dialog elements:

Bundle: Connection point designation:

Specify the bundle connection point designation here. It identifies a connection within a bundle and occurs in pairs (but not more often) for each bundle: At the connection point entering the bundle and at the connection point leaving the bundle.

You can separate multiple connection point designations using a slash ("/") or a comma (",").

Bundle: Connection point description:

Specify the bundle connection point description here.

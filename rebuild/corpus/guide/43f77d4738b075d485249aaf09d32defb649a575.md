# Exchanging Devices

When two devices are changed, all the functions of the respective devices are exchanged. The DT is exchanged.

Preconditions:

- You have opened a project.
- You have opened a project page in the graphical editor, or you have opened a project data navigator.

1. Select any component / function of the two devices you wish to exchange.
2. Select the following commands: Tab Devices > Command group Devices > Drop-down button Extras > Exchange DT.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All the functions of the two selected devices have the DT of the respective other device assigned to them..

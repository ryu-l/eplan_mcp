# Drawing and changing restricted cut-out areas

Restricted cut-out areas exclude the affected area from the calculation of drilling coordinates. Two situations are differentiated here:

- Placement of cut-outs or items with drilling patterns via an already defined restricted cut-out area: Placement of cut-outs is not possible. Items with drilling patterns can be placed, the drilling patterns will, however, not be displayed in the drilling view and will not be exported as NC data.
- Placement of a restricted cut-out area via already existing cut-outs or items with drilling patterns: Already existing drill holes from drilling patterns which are contained in this area are not displayed in the drilling view and are not exported. Already existing cut-outs are still displayed and exported as NC data even though a restricted cut-out area was placed over them.

Restricted cut-out areas are placed in the same way as restricted placing areas. In contrast to restricted placing areas, however, the restricted cut-out areas penetrate the entire item and are also visible and effective on the opposite side.

Restricted cut-out areas are displayed in the layout space navigator for each mounting surface under the Locked areas hierarchy level.

Precondition:

You have opened a project. You have opened a layout space. An enclosure or a mounting panel has been placed.

1. Select the following commands: Tab Insert > Command group Locked areas > Cut-out.
2. Move the cursor to the area to be locked to activate it automatically, or activate a mounting surface directly in the layout space navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The automatically or directly activated mounting surface is identified in color. Input is now only possible on this area.
3. Draw the rectangle that represents the restricted cut-out area.

![](../Pictures/Gui/ALL/info.png)Tip:

Use the popup menu item [Placement options](cabinetgui_d_platzieroptionen.htm) during insertion. In the subsequent dialog by the same name you can directly determine the distance between the cursor and the placement point for the start and end point of the restricted cut-out area in the Offset X and Offset Y fields.

### Changing the size of restricted cut-out areas

The size of restricted cut-out areas can only be changed in two ways:

- Changing the format properties in the property dialog: Enter changed values for the Width and Height fields on the tab of the Format property dialog. The change is made referenced to the bottom left-hand corner.
- Graphical change: Mark the object. Direction arrows appear at the corners and in the middle of the sideline, in whose displayed direction you can pull apart and pull together the object. While moving along the direction arrow, handles that you can use for exact positioning are displayed at neighboring 3D objects.

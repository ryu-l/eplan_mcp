# Transfer of Configuration Data to Eplan Fluid

In order to output your plant or machine documentation in the parts lists and / or conduit / line plans, the configuration data created in the hose line configurator have to be written back to the hose lines placed in Eplan Fluid.

Prerequisite for correct data transfer is that the configuration data of the hose lines in the hose line configurator and the hose lines placed in Eplan Fluid in the schematic dispose of the same (full) DT.

If you have generated the configuration data by using the hose line configurator, the data are transferred simply by a mouse click or key to the project currently opened in Eplan Fluid and there entered and stored as corresponding properties at the hose lines marked in the schematic.

During the data transfer the following device properties are displayed in the Conduit / line tab and filled with values from the configuration at the hose lines marked in the project in Eplan Fluid:

- Type (the respective hose type is entered here)
- Cross-section / diameter (the respective nominal diameter is entered here)
- Hose line length
- Hose line identification
- Manufacturing date
- Torsion angle
- Working pressure

In addition the following information is entered at the part properties of the hose lines:

- Type of construction of the fitting left  (at part position 1)
- Type of construction of the fitting right (at part position 2)
- Hose type (at part position 3)
- Type code (at part position 4).

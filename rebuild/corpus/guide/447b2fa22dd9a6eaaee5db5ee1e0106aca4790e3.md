# Specifying Settings for Connection Numbering

Settings for connection numbering are saved in schemes. This way you can access previously specified settings at any time and even change them, if necessary.

Precondition:

You have opened a project.

1. Select the following commands: File > Settings > Projects > "Project name" > Connections > Connection numbering.
2. Select a user-defined scheme from the drop-down list, or create a new scheme via ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the dialog Settings: Connection numbering.
3. In the [Filter](wirenumberinggui_r_filter.htm) tab select the check boxes for the trades and the function definitions you want to number.  
   If necessary, deactivate the check boxes for the potential types which you want to exclude from the connection numbering (for example PE or SH).
4. In the [Placement](wirenumberinggui_r_platzierung.htm) tab select where and how often you want to place the connection definition points on the connections.
5. In the [Designation](wirenumberinggui_r_bezeichnung.htm) tab, define the format groups that are to be formatted together.
6. Define the formatting that is assigned to the generated connection designations at the connection definition point in the [Display](wirenumberinggui_r_anzeige.htm) tab. Among these formatting options are, for example, horizontal and vertical increments of the connection designation from the connection line, as well as text color, size, etc.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The scheme is now set up and will be used when you are numbering connections.

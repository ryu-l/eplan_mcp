# Specifying Default Symbols for Connection Definition Points Project-specifically

In the project properties the symbols for connection definition points, potential definition points and net definition points can now be predefined for the entire project. The new Settings: Default symbols dialog is available in the project settings for connections to this purpose. The command path to this dialog is: File > Settings > Projects > "Project name" > Connections > Default symbols.

Benefit:

You can now specify default symbols for connection definition points, potential definition points and net definition points independently of the user. This allows uniform and consistent usage of these symbols within a project.

[![](../Pictures/Gui/Lang/connections_defaultsymbol_ls_thumb_0_60.png)](../Pictures/Gui/Lang/connections_defaultsymbol_ls.png)

The default symbols specified in this dialog are used when manually placing connection definition points, potential definition points and net definition points. These symbols are also used when the properties of a connection are changed (for example in the connection navigator) and a connection definition point is placed automatically as a result. This setting, however, does not apply to connection definition points that are placed by the connection numbering. For such connection definition points you specify the symbol in the settings for connection numbering.

The dialog contains the following tabs:

- Multi-line: Here you define the default symbols for connection definition points that are placed on multi-line pages.
- Single-line: Here you define the default symbols for connection definition points that are placed on single-line pages.
- General: Here you define the default symbols for potential definition points and net definition points. The symbols defined here are placed independently of the representation type.

To specify the default symbols, the Number / Name field is available in each tab. These fields are initially empty. By clicking [...], you open the Symbol selection dialog where you can select the desired symbol. If the symbol has several variants, you can select a different symbol variant in the Variant field by using the drop-down list.

Use the ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) button to remove the selected default symbol. If no standard symbol is specified, the most recently used symbol from the dialog memory is inserted when a connection definition point, potential definition point or net definition point is placed.

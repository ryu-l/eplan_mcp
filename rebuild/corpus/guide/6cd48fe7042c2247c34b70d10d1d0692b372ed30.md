# Dialog Paste

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have deactivated the Use one Clipboard only check box in the user settings (Command path: File > Settings > User > Display > General). You have opened a project. You have copied at least two schematics projects or two pages to the Clipboard. Tab Edit > Command group Clipboard > Paste. Or select the Insert popup menu item.

This dialog displays all objects (or pages) in the Clipboard. Select an object here that you want to insert or select the page.

![](../Pictures/Gui/ALL/note.png)Note:

There are different Clipboards for copying and pasting objects and pages. If your cursor is in the page navigator, Eplan opens a dialog with copied pages if you are pasting. If, on the other hand, your cursor is in a project page, you can use the Paste dialog to paste copied schematics objects.

Overview of the main dialog elements:

Table:

This field displays all objects saved in the Clipboard when copying or cutting.

- Description: This column contains the description you entered in the Clipboard dialog.
- Type: This column displays the object type.
- Date / time: This column contains the date and time the object was saved to the Clipboard.
- ![](../Pictures/Gui/ALL/all_delete_as.png): This allows you to delete a marked object from the clipboard.

Preview:

If this check box is selected, a preview is displayed in the field below for the object selected in the table.

# P026103: Incorrect part placement

### Cause

As a result of a part placement or a part migration, the placement of a part on a mounting surface is not possible anymore since the mounting surface no longer exists.

### Solution

1. Locate the part placement in the layout space by means of the Go to (graphic) function from the popup menu in the Message management dialog.
2. Place the part on an existing mounting surface.
3. If required, start a new check run.

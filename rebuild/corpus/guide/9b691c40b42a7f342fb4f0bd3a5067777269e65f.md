# Specifying the Macro Variant for the Creation of the Detailed Planning at Planning Objects

If a macro is stored at a planning object, the detailed planning can be created by placing the macro. If more than one variant is available at a stored window macro, the placeholder objects of all variants are displayed at the planning object in the Macro tab. This means that the display can quickly become confusing. When planning objects with such macros are dragged into the page navigator using Drag & Drop, a selection dialog for selecting the representation type and the variant of the macro is also displayed.

If the concrete variant of a window macro is to be used immediately during the Drag & Drop, you can now specify this at the planning object in the Macro tab. To this purpose the new Variant drop-down list is available next to the Macro field. By default, no variant is selected, and an empty entry is displayed accordingly.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

The selection of a macro variant makes the Macro tab clearer. The property values in the placeholder objects can be adapted specifically.

The fact that the selection dialog is no longer required for the Drag & Drop of planning objects into the page navigator means that placement is faster. This is particularly advantageous in the case of a multiple selection of planning objects.

[![](../Pictures/Gui/Lang/planninggui_macrovariantselection_ls_thumb_0_60.png)](../Pictures/Gui/Lang/planninggui_macrovariantselection_ls.png)

If you select the desired variant of a window macro in the Variant field, only the placeholder objects, variables and values of this variant are still displayed in the Properties group box. If the macro variant has only one representation type, the selection dialog is no longer required when generating schematic pages via Drag & Drop of the planning object into the page navigator.

If the macro originates from the assigned segment template, the macro name displayed in the Macro field cannot be changed. However, the selection of a different variant is possible in such a case.

If a macro has already been placed and a different variant of the macro is selected at the planning object, the placed macro can be updated via the Update detailed planning popup menu item. To do so select the Place macros again option in the [Update detailed planning](planninggui_d_detailplanungaktualisieren.htm) dialog.

The preset variant of a macro is also taken into consideration during the export and import of pre-planning data for external editing as well as during the pre-planning import. The new Macro variant (ID 44093) property is now available to also specify the macro variant during the pre-planning import in the Excel format for planning objects.

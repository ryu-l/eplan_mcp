# Overview of the Transferred Part Data

By means of part selection, you assign one or more parts to a device. In the process the data listed below of the first part contained in the selection are assigned to the function / component.

| Connection point cross-section | 22036 | Connection point cross-section | 20057 |
| Plugs: Number of pins | 22035 | Plugs: Number of pins | 20056 |

In addition, the following values are transferred:

- All properties of the "main template". The main template is the first function template in the Function templates tab of the parts management whose function definition is set to "Main function".
- Part assignments set in the macro box (If a macro is entered at the part and part assignments are configured there).
- The value for the Technical characteristics property in the Properties tab is only transferred during the part selection if no value is entered for this property at the "main template", or if there are no function templates.

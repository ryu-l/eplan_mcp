# Exchanging the Settings

You can pass project-specific settings to other projects. To do this, you must save the source project settings, together with the project as a basic project and then create the new project from the basic project.

### Save the project as a basic project

Preconditions:

- You have opened the project management: File > Project management
- In the tree structure of project management, there is an imported directory with at least one project.

1. Select your source project in the Project management dialog.
2. Select [Extras] > Create basic project.
3. Select the storage location and the name for the basic project.
4. Click [Save].  
     
   ![](../Pictures/Gui/ALL/arrow.png) A basic project is created.

### Create a project from a basic project

1. Select the following commands: File > New.
2. Assign a name to the new project in the Create project dialog.
3. Click [...] next to the Basic project field.
4. Select the desired basic project in the Select basic project dialog and click [Open].
5. Select a storage location for the project.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) A project is created on the basis of the basic project.

# Inserting Black Boxes

A black box represents a physical item composed of several graphical elements, all of which are within the black box rectangle. When a black box is created, Eplan allocates a DT to it.

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the following commands: Tab Insert > Command group Devices > ![](../Pictures/Gui/ALL/ribbon_blackbox_as.png) Black box.
2. Draw the rectangle that represents the box.
3. Enter the item data in the black box specific Properties dialog.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The black box is inserted into the project with all its properties.

![](../Pictures/Gui/ALL/note.png)Note:

If Snap to grid is activated (Button ![](../Pictures/Gui/ALL/statusbar_snaptogrid_as.png) (Snap to grid on / off) in the status bar), a newly created black box will be exactly on the grid on which it is placed. If snap to grid is not active, the black box can be drawn at any desired position next to the grid.

![](../Pictures/Gui/ALL/info.png)Tip:

With the help of the symbols DC2 or DCF2, black boxes can also be drawn as polylines. To do so, select the symbol in the Symbol selection dialog and specify the starting point of the box by clicking the left mouse button inside the schematic. After you have specified all of the other points, complete the task via the Complete polyline popup menu item.

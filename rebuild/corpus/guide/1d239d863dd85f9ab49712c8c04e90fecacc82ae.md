# Checking Part Master Data

In the parts management you have the possibility to check the part master data directly. To this purpose you can perform the check runs for the part master data in the parts management, and the resulting messages are not displayed in the message management but rather directly in the parts management.

Preconditions:

- You have opened the Parts management dialog (Tab Master data > Command group Parts > Management).
- You have opened a parts database using [Extras] > Settings.

1. Select the parts to be checked in the tree view of the parts management.
2. Select the Run check popup menu item.
3. In the Run check dialog select a scheme from the Settings drop-down list or click [...] to specify the settings for a new check run scheme for the part master data in the Settings: Messages and checks dialog.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected parts are checked on the basis of the settings specified in the scheme. The results of the check run are written to the parts database. The results of any previous check run are removed.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A message with the number of generated check run messages is displayed. Subsequently the Messages tab with the output messages is opened. You can jump from a message to the respective part by means of the Go to popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Parts with faulty or incomplete information are identified in the tree view of the parts management by a red exclamation mark. To do this at least one check run message has to exist with regard to this part. The Check run messages available property can be used to create a filter with which you can have only those parts displayed in the parts management that are identified with the red exclamation mark.

# Dialog Settings: Export pipe bending

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > Company > Machining > Export pipe bending
- File > Export > Command group Manufacturing data > Machining > Pipe bending. Click [...] next to the Machine field.

Use this dialog to specify the settings for the export of data for the control software for controlling pipe bending machines.

Overview of the main dialog elements:

Output directory:

The pipe bending export is generated as an XML file. Enter the storage location in this field. You can specify any drive and subdirectory as the target for the export. The default setting is the directory $(EPLAN\_DATA)\Export\XML.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

Generate file names:

In this drop-down list you specify the default method for allocating file names during the export:

- From consecutive number: If you select this option, Eplan assigns names to the XML files using the pattern Consecutive number.XML by default. If XML files already exist, Eplan starts the numbering with the next available number.
- From item designation: If you select this option, Eplan assigns names to the XML files using the pattern <Item designation>.XML by default.
- From properties: If you select this option, the file name is made up of the layout space, connection or project properties plus any freely-definable separators. Use the [...] button to open the Format: Property dialog to configure the file name.

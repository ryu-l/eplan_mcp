# Restoring the Settings to Default Values

In the settings dialog, you can use a command in the popup menu to return the individual settings to standard starting values defined by Eplan. In the process you can set either individual fields or - by selecting in the tree view - complete settings areas to the default values.

Precondition:

You have opened a project.

1. Select the following commands: File > Settings.
2. Navigate through the tree structure in the Settings dialog until you have reached the desired sub-category.
3. To reset this settings area to default values mark the desired settings area in the tree.
4. To reset an individual field back to the default value click on the right in the settings dialog in the desired field or check box.
5. Select the popup menu item Go to default.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected settings (meaning the field or the area) are reset to the default values.

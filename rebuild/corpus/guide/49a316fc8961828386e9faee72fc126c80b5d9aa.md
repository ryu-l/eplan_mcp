# P001016: Terminal without targets

### Cause

You placed a terminal in the schematic without connecting it to a component.

### Solution

1. Connect at least one of the symbol connection points of the placed terminal to a component.
2. Update the connections.
3. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

Note that unplaced terminals are not captured by this check run!

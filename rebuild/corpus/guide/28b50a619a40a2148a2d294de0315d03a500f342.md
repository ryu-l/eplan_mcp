# P011003: Interruption point without target

### Cause

An interruption point is without a target.

### Solution

1. Locate the interruption point in the schematic by means of the Go to (graphic) functionality offered by the popup menu in the Message management dialog.
2. Connect at least one connection point of the interruption point with another component so that an autoconnecting line is formed.
3. Update the connections.
4. If required, start a new check run.

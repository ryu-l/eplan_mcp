# Action: XEsUserPropertiesImportAction

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| XMLFile | Name of the XML file from which the export is to be carried out, including the complete path (optional). If not specified, a file selection dialog is opened. |
| Project | Complete name of the project into which the user-defined properties are to be imported (optional). If not specified, the current project is used or a file selection dialog is opened. |
 Overwrite | If the value is 0, user-defined properties of the same name are overwritten during importing (optional). Default value: 1 (Query dialog is opened). |

XEsUserPropertiesImportAction

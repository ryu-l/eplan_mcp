# Connections: Units for Lengths and Cross-sections

The lengths and cross-sections / diameters of electrical engineering or fluid power connections, cables or conduits can be entered and displayed in various units. In the project settings, the defaults for the lengths, cross-sections / diameters and their units can be determined.

### Possible display units for the connection lengths

| Unit | Meaning |
| --- | --- |
| mm | Millimeters (0.001 m) |
| cm | Centimeters (0.01 m) |
| dm | Decimeters (0.1 m) |
| m | Meters |
| km | Kilometers (1000 m) |
| ft; feet; foot | Feet / foot = 1/3 yard (0.305 m) |
| yd; yard | Yard (0.914 m) |
| "; inch; In | Inch (25.4 mm) |
| mil | 1/1000 inch |

# Tab General (User, PDF Export)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Export > Command group Project data > Project data > Command group Page > PDF. Click [...] in the Scheme field of the PDF export dialog. Select the General tab.
- File > Settings > User > Interfaces > PDF export. Select the General tab.

In this tab, you define the general company-specific settings for exporting PDF files.

Overview of the main dialog elements:

Use zoom:

Select this check box when a zoom window is to be used when jumping to components in the PDF file. The components are then displayed centered within the zoom window. If you select this check box, then the Zoom level field below this check box also becomes available.

If this check box is deselected then the entire page is displayed when jumping to a component.

Zoom level:

If the check box Use zoom is activated, enter the desired zoom level in "mm". The value entered reflects the height of the screen section that is to be displayed magnified after the jump. A small value (e.g. 20 mm) thus leads to a greatly magnified display of the respective component on the screen.

Simplified jump function:

If this check box is selected then the created PDF file offers only "simple" jump functions.   
If this check box is deselected then "three-way" jumps are available for all components in the PDF.

Use of the Simplified jump function setting also allows the size of the PDF file to be reduced.

Quick Web display:

If this check box is selected, the PDF file is optimized for display in the Internet. In this case the first page of the PDF file is displayed while the rest of the file is still being loaded.

If the check box is deselected, then the file will only be displayed once it has been completely loaded.

Read-only:

Select this check box if you wish to create a read-only PDF on export. A PDF document created with this option selected can no longer be changed using Adobe Acrobat.

With an activated check box, jump targets in the PDF file are not identified through a red frame.

Copy externally linked documents automatically to output directory:

Select this check box so that external documents / linked documents that are neither stored in the project nor contained in the default directory for documents can also be copied to the target directory with the output.

If the check box is deactivated, all documents are ignored which are not stored in the project and are not contained in the default directory for documents.

Archiving format PDF/A:

You can archive the PDF files to ensure that the documentation remains available for long periods: o do this, select this check box to save the data in PDF/A-1b format. Note that models and linked documents in this format will be ignored.

In PDF files with the PDF/A format the identification of a jump target by a red frame is not possible.

Page tree sorted by:

In this group box you define the page tree display for the PDF document output.

- Structure identifier: If this option is selected, the page tree pages in the PDF file are sorted by structure identifiers.
- Page type: If this option is selected, the page tree pages in the PDF file are sorted by page types.

Texts in PDF file:

This table shows properties that occur in the PDF file as bookmarks and other fixed terms (e.g. names of page types, names of output areas). The default names of these properties can be edited in the Name column.

When exporting PDFs, the texts are output in the specified PDF output language (File > Settings > Projects > "Project name" > Management > PDF output languages). If these texts are not found in the specified language, the texts will be output in the first language available.

# P005054: Different nets with identical net name (<x>)

### Cause

Different nets were determined that have the same net name.

#### Possibility 1

The nets are not connected to each other but each have a net definition point with the same net name.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Two nets are not connected to each other but have the same net name N1 (see circles in the following figure).

![](../Pictures/Visualisation/ALL/messages_005054_bsp1_av.png)

#### Possibility 2

Two nets with the same net name each have a potential connection point. The potential connection points have different potential names.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Two nets have the same net name N1 and are both connected with a potential connection point. The potential connection point at the first net (top) has the potential name L1, the potential connection point at the second net (below) L2 (see circles in the following figure).

![](../Pictures/Visualisation/ALL/messages_005054_bsp2_av.png)

### Solution

#### Regarding option 1

1. Connect both nets via connection symbols, for example with T-nodes.
2. Delete one of the net definition points.
3. Organize the connection points in the Properties <...> dialog of the remaining net definition point (Net connections tab) in the desired sequence into a daisy chain.
4. Close the properties dialog with [OK].

#### Regarding option 2

1. Assign the same potential name to both potential connection points.
2. Delete one of the net definition points.
3. Organize the connection points in the Properties <...> dialog of the remaining net definition point (Net connections tab) in the desired sequence into a daisy chain.
4. Close the properties dialog with [OK].

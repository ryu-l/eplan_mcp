# Tab Segment templates

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have created a segment template in the segment templates navigator. In the Properties <...> dialog, select the Segment template tab.
- You have selected a segment template in the segment template navigator. Popup menu item Properties. Select the Segment template tab.

In this tab you specify the identifying name and the description for the segment template.

Overview of the main dialog elements:

Identifying name:

Enter a unique name for the segment template here. The segment template is managed in Eplan under this name.

Description:

Here, enter the name under which the segment template is displayed in the project. Multi-lingual entry is possible.

Subordinate segment templates:

In this table you specify the segment templates that are subordinate to the current segment template. To do this, use the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button in the Select segment template dialog. The available matching segment templates are displayed in the left-hand section of this dialog. You can narrow the number of displayed segment templates by using the Find field here. Both the names of the displayed templates as well as the description are searched. Select the desired segment templates. Multiple selection is possible. Move the selected segment templates to the Subordinate segment templates field by using the button ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).

The segment templates which are available to you in the Select segment template dialog depends on the configuration of the segment definitions. Templates for measuring functions are for example available as a default for loop templates.

The sequence of the subordinate segments is specified with the sequence of the subordinate segment template. These arise when a segment is generated by means of the current segment template. You can change the sequence using the arrow buttons on the toolbar.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

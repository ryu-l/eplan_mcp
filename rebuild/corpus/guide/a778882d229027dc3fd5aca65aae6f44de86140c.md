# P005016: Connection and connecting point have differing potential types

### Cause

You have set the same potential type at the function connection points of the targets of a connection. In addition you have assigned a potential definition point to the connection and have assigned a potential type to it that does not match the targets. Or you have set different potential types at the function connection points of the targets of the connection.

### Solution

1. Select the following commands: Tab Connections > Command group Connections > Navigator.
2. Locate the connection in the connection navigator using the Synchronize selection function offered by the popup menu in the Message management dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection is marked in the connections navigator.
3. Jump from the selected connection via the popup menu items Go to (graphic, source) and / or Go to (graphic, target) to the targets in the schematic between which the graphical connection runs as an autoconnecting line.
4. Call up the property dialog respectively of the target functions.
5. Bring the Symbol / function data tab to the front.
6. Select the [Logic] button and check the potential type set at the function connection points of the target functions.
7. If the settings of the potential type deviate from each other at the target functions, modify the values to suit each other.
8. If a potential definition point is located additionally on the graphical connection, delete it or assign the same potential type to it that is also entered at the function connection types of the target functions.
9. If the connection point type at the target functions deviates from the function definition of the connection definition point, modify the values to suit each other.
10. Confirm your entries.
11. If required, start a new check run.

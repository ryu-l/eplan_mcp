# Dialog Structure identifier of layout space

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have generated a layout space. Popup menu item Properties. Click [...] in the Structure identifier field In the Properties (components): Layout space dialog.

In this dialog you can edit the structure identifiers of the layout space.

Overview of the main dialog elements:

Structure identifier:

The table displays the device structure of the part placements in the layout space. Eplan generally adopts the Structure for mechanical devices that you have defined in the project properties of the project. Thus, in the fields you see the structure identifiers of the layout space where the part placement is located.

- Structure: Lists the identifier blocks which correspond to the project structure. The adjacent column displays the associated preceding signs.
- Value / Visible: Without extended reference identification, the Value column is displayed. If you are using extended reference identification, the Visible column is displayed. In this column, the structure identifiers can be edited. Enter a structure identifier in the proper field for this purpose, or click [...] to select a structure identifier already defined in the project using the <Identifier block> (<Project name>) dialog.
- Complete: This column is displayed if you are using extended reference identification. It displays the structure identifier including all superior structure identifiers.

![](../Pictures/Gui/ALL/note.png)Note:

The preceding signs and separators between the individual structure identifiers can not be edited here. They originate from the settings of the Extended project structures dialog, which you open in the Structure tab of the project properties by clicking [Other].

# P007009: Coil without matching contacts

### Cause

A contactor coil in the schematic is missing at least one suitable contact in the schematic. Here, the program checks the Contact / coil index property for the coil and for the contacts assigned to it (via the DT).

This message is displayed if the coil has a value in this field, but the contacts assigned to the coil do not. This message also appears if a coil has been inserted into the schematic but a value has not been assigned to it in the Contact / coil index field and a contact has not been assigned to it.

### Solution

#### Possibility 1

Enter the same value in the property field for the Contact / coil index and at least one of the contacts assigned to it.

#### Possibility 2

If it is not necessary to specify the contact / coil index, for both the coil and the contacts, delete the value in the Contact / coil index property field.

#### Possibility 3

Add at least one contact with the same DT to an individually placed coil in the schematic, and enter the same value for both the coil and the contact in the Contact / coil index property field, or leave the field for this property empty for both the coil and the contact.

---

  

If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

If you predefine a contactor in the device navigator by means of device or part selection, the mere presence of the function templates for the associated contacts means that the message is not displayed during a check run.

# P004055: More than one rack was found during importing. Ensure that you use the right hardware for connecting

### Cause

You use the PLC import interface Schneider Schneider Unity Pro: In the case of the M340 product line the PLC boxes for connecting the racks with each other are not contained in the import file.

### Solution

1. Ensure that existing rack extensions are configured with the right hardware.
2. Import the PLC data again.

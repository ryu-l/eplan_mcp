# Access to Eplan Cloud Products

You can access the Eplan Cloud products available to you in a separate tab in the ribbon. Which products these are depends on the organization to which you are signed in.

Buttons for the corresponding applications are displayed in the Eplan products command group. Some applications are opened in the internal browser window of the platform. Other applications are opened in the Internet browser set by default on your computer.

If you are signed in with your Eplan ID and click the Eplan Cloud Dashboard button, the dashboard is shown as an additional window. The command groups and commands displayed in the tab are synchronized with the dashboard.

You can find further information on Eplan Cloud products in the [Eplan Information Portal](../../../../htm/portal_home.htm).

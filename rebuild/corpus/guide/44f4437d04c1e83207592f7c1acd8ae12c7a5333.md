# Tabular Editing of Fluid DTs Identified to ISO 1219-2

Eplan Fluid allows you to edit the function data of various devices of your fluid power project together in one dialog. The respective function data are represented in a table. The table column display can be freely defined and saved as a scheme. If you have structured the fluid DTs of your project according to the ISO 1219-2 standard and have selected a suitable column scheme, the identifier block "Higher-level function number" and the identifier parts "Circuit number", "Item number", and "Media code" can be easily edited in a table in a single step.

# Dialog Select report

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Tab Tools > Command group Reports > Generate. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New).

This dialog lets you specify what report type should be generated and define the output format and source project.

Overview of the main dialog elements:

Output format:

In this field, you can specify the format in which the report will be generated.

- Page: The report will be generated in the form of [report pages](formgeneratorgui_k_auswertungsseiten.htm) and output in a project.
- Manual placement: This option is only available when a project page is open in the graphical editor. The report will be generated in the form of an [embedded report](formgeneratorgui_k_ausgabeformen.htm). You can manually place an embedded report in the currently open project page. This setting is useful when combined with the "Total" page sorting.

  ![](../Pictures/Gui/ALL/note.png)Note:

  Although you may have selected, for example, the "Function designation and location designation" page sorting for your report by means of the commands File > Settings > Projects > "Project name" > Reports > Output to pages in the Page sorting column, you can only place a comprehensive report manually.

Source project:

In this field is the project that is the data source for the reports and templates. You can use [...] to open the source project dialog, where you can select a (different) project as the data source.

Select report type:

Reports are based on [report types](formgeneratorgui_k_auswertungstypen.htm). This field displays all available report types. Select the report type for which a report is to be generated.

Current page:

Depending on the report type, this check box is only available for the "Manual placement" output form. Activate it to have only the data of the current page reported in the current report; this is, e.g., useful for embedded reports.

Manual selection:

This functionality is only available for [function-related reports](formgeneratorgui_k_funktionsbezogen.htm). If this check box is selected, then the Manual selection dialog opens before the report is generated. In this dialog, you can select the devices for the report individually.

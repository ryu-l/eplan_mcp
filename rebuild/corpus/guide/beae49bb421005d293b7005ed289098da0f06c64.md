# Dialog "Connection colors" / Dialog "Settings: Connection colors"

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- File > Settings > Projects > "Project name" > Connections > Connection colors
- You have opened the Property dialog for a connection, connection definition point or potential definition point (e.g., by double-clicking a connection definition point in the graphical editor). Select the Connection tab, Connection definition point tab or Potential definition tab and click [...] beside the Color / number field.

This dialog displays the color codes opposite the color names in the source language. This table is used to fill out the Connection color (multilingual) property. It can also be translated automatically.  
In addition, the color codes can be assigned the colors in which routing connections in the layout space are displayed.

Overview of the main dialog elements:

Color code:

This field displays the color codes according to IEC 60757.

Color name:

The color names in the source language are displayed in this field. In the Settings: Connection colors dialog you can change these manually or translate them into another language. It is only possible to select an existing connection color in the Connection colors dialog.

Color in layout space:

The color in which a routing connection is displayed in the layout space is determined from the color code that has been entered in the Color / number connection property.

In this field, you assign each color code the color in which the routing connection is displayed in the layout space. Click a cell and then [...] to open the [Color selection](mf_d_farbauswahl.htm) dialog, and you can select a different color.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

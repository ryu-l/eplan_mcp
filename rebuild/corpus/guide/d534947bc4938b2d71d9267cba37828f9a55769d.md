# Dialog Project option

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Tab Devices > Command group Project options > Navigator.

- Select the New > Project option popup menu items.
- You have selected a project option. Select the Properties popup menu item.

In this dialog you create a new project option or edit an existing one.

Overview of the main dialog elements:

Project options group:

In this group box you select the project options group to which the project option is to be assigned.

- Name: Select an existing project options group from the drop-down list or enter an new name. If you leave this field empty (or delete the entry), the project option is not assigned to a project options group.
- Description: This field displays the description text of the selected project option group. When a new project options group is entered, this field is editable and you can enter a description.

Name:

Enter a name for the project option here, or change the existing name.

Description:

Enter description text for the project options group here. The description is a multi-language text and is displayed by default in the tree view next to the name, separated by a blank and within round brackets.

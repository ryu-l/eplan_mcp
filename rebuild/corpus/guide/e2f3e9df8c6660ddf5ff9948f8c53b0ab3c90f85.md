# P017002: Unnumbered DT

### Cause

You asked Eplan to automatically flag a device tag when inserting symbols and this function should be no exception. As a result, Eplan cannot identify the function.

### Solution

#### Possibility 1

Correct the device tag by removing the flag and then start a new check run.

#### Possibility 2

Use the numbering functionality.

1. First highlight the function in the schematic.
2. Select the following commands: Tab Devices > Command group Devices > Number. In the Number (offline) dialog, make sure that the "Identifier + counter" format is set and the Only number marked ones check box is selected.

#### Possibility 3

Deactivate the functionality of automatically numbering with a flag.

1. Select the following commands: File > Settings > Projects > "Project name" > Devices > Numbering (online).
2. In the On symbol insertion group box, deselect the Number with flag "?" option by selecting the Number option.

---

  

If required, start a new check run.

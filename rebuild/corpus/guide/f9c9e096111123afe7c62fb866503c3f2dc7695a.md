# New Dialog for Managing Layout Space Views

In Eplan Pro Panel orthogonal and isometric layout space views that were, for example, generated by means of the navigation cube can now be managed in a dialog. The Layout space views dialog is displayed next to the Insert center dialog as a flyout and can be pinned or detached. The dialog contains tiles on which generated layout space views can be saved. Saved views are displayed on the tiles as preview images.

The following is possible:

- Up to 10 views per layout space can be saved.
- Saved views can be retrieved and applied again to the layout space, both via a popup menu and via self-assigned shortcut keys.
- Views can also be used without the set viewing angle.
- Views can also be used with the items and connections hidden in the saved view or without the items and connections shown in the saved view.
- Saved views can be renamed, deleted or overwritten.
- Layout space views are stored project-specifically per layout space and are also retained when copying a project (via File > Copy), but not when copying individual layout spaces within a project or between projects.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

The new Layout space views dialog allows designers to generate and store several views of, for example, an enclosure. If routing is then carried out later, these views do not have to be generated again, but can be retrieved again rapidly. This means a saving in time and working more comfortably for all designers involved.

# Outputting Pages as Image Files

Project pages can be output in the following image file formats: BMP, GIF, JPG, PNG and TIFF.

If you export a single page, then you can freely assign the file name. When exporting multiple pages, the file name cannot be freely chosen. In this case, the image files are named with the complete page name.

Precondition:

You have opened a project.

1. Select the following commands: Tab Home > Command group Page > Navigator.
2. In the page navigator, select the pages of a project (or the entire project) that you wish to export.
3. Select the following commands: File > Export > Command group Project data > Project data > Command group Page > Image file.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan opens the Image file export dialog. The chosen files are displayed in the Source field.
4. In the Scheme field, select an appropriate scheme for the image file export.
5. If required, change the specified target directory and define all of the project pages, or only the marked pages that are to be exported.
6. When exporting a single page, enter the name of the file to be created into the File name field, or select it interactively by using ![](../Pictures/Gui/ALL/all_selectfile_as.png).
7. Check the Black-and-white output check box to print all elements on the project pages in black on a white background.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Every page is saved as a separate image file in the specified target directory.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If an entire project is selected, a subdirectory with the name of the project is generated in the target directory and the image files are stored in this subdirectory.

![](../Pictures/Gui/ALL/info.png)Tip:

If the cursor is positioned on a page in the graphical editor, you can export the currently open page via the following commands: File > Export > Command group Project data > Project data > Command group Page > Image file.

The subdirectory EPLAN\_Sample\_Project is generated in the target directory. All pages in the project are saved as TIFF files in this subdirectory.

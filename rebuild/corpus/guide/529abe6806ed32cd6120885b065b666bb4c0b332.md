# Spare Items: Basics

### Function pool

Each item can contain any number of functions. Devices thus consist of a function pool. For example, a contactor can consist of the functions "Coil" and "NO contact".

Components are required in order to place functions. A 1:1 relationship exists between functions and components.

A function pool can be generated either via a device selection or through "unplaced" functions.

### Terminal pool

Any number of terminals can be assigned to each terminal strip.

Terminals that are not drawn in are "unplaced" terminals. They can be wired to define jumpers or to place free cable connections, and individual connections (pre-wirings) can also be placed.

The terminal itself can be composed from different functions (multi-level terminal).

### Cable connection pool

Often not all cable connections of a cable are required in the schematic. Such cable connections that remain free are "unplaced" or "free" cable connections.

Cable connections can be placed on unplaced or placed connection points. This way all cable connections of a master cable can be placed completely on a terminal strip without all cable connections and all terminals having to be drawn.

Unplaced cable connections can be wired in the terminal and cable dialogs, with the following wiring combinations possible:

| Case | Device 1 | Device 2 | Cable connection |
| --- | --- | --- | --- |
| 1 | Placed connection point | Placed connection point | Placed cable connection or unplaced cable connection |
| 2 | Unplaced connection point | Unplaced connection point | Unplaced cable connection |
| 3 | Placed connection point | Unplaced connection point | Unplaced cable connection |

### Wiring

Unplaced connection points can be connected via unplaced wirings. For example, jumpers can be created on unplaced terminals.

The following wiring combinations are possible:

| Device 1 | Device 2 | Wiring |
| --- | --- | --- |
| Placed connection point | Placed connection point | Placed wiring or unplaced wiring |
| Unplaced connection point | Unplaced connection point | Unplaced wiring |
| Placed connection point | Unplaced connection point | Unplaced wiring |

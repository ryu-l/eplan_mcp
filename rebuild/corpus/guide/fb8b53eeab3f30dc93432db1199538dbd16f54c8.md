# Dialog Placeholder texts - <Form type>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Tab Master data > Command group Plot frames / forms > Drop-down button Form > Open > Button [Open].

- Tab Insert > Command group Text > Drop-down button Forms > Placeholder text. Click [...] in the Property field in the Placement tab.
- You have double-clicked a placeholder text (or selected the popup menu Properties; in which case multiple placeholder texts may also be selected) and have clicked [...] in the Property field in the Placement tab of the Properties (placeholder text) dialog.

In this dialog, you can select the form type-specific placeholder text, which should be inserted into the form. During the evaluation of the form, Eplan automatically replaces these placeholders with the corresponding values of project objects on which the report is being run, such as items, pages, symbols, etc.

Overview of the main dialog elements:

Element:

Depending on the current form type, all elements are shown here for which a placeholder can be defined. In forms for function-related reports, the available elements are divided into the two lists "Header object" and "Data object". Select an entry in order to have the corresponding list of properties displayed in the right side.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

For instance, if you select the Page properties element ("Table of contents" form type), the subproperties Function designation, Page number, Suppl. field: Page, etc. in the right-hand list.

![](../Pictures/Gui/ALL/note.png)Note:

An index is possible for some elements, such as Part (source), and in this case, a ![](../Pictures/Gui/ALL/all_expand_hierarchy_as.png) sign is shown next to the element. If you click on that symbol, the list of possible indexed properties is expanded in the tree view, and you can select the desired property. Please note that this index does not necessarily reflect the index in the Part tab of the property dialog. If, for example, a part is entered in line 1 and line 20, you obtain the data of the second part in the report via index 2 (and not via index 20).

Category:

You can limit the display of subproperties by selecting an entry from this drop-down list.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

For instance, if you select the Page properties element ("Table of contents" form type) and choose the "Revision" category, then in the right-hand list you will only see the revision-specific subproperties Created by, Creation date, Last editor, etc.

Find:

Into this field enter the text for which the properties are to be filtered. Both property names and set values are found when the properties are filtered. Logic operators (AND / OR operation) and placeholders (such as \* or ?) are not supported for filtering.

If you want to return to the original view of the properties, remove the search term from the entry field. Click ![](../Pictures/Gui/ALL/all_delete_input_as.png) (Delete) to do so.

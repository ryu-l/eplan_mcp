# Working with Symbol Variants

A symbol can have up to eight variants with names from A to H, a contact image variant, and a variant for representation as a connection point whereby all variants of a symbol have common properties. They also behave identically, and have the same function. This way they always have the same number of connection points and are only different in their graphical configuration of the connection points.

### [ClosedGenerate symbol variants](javascript:void(0);)

Precondition:

You have opened a project and are editing a symbol in which all of the variants do not exist yet.

1. Select the following commands: Tab Edit > Command group Symbol > New variant.
2. In the Create variant dialog select the target variant that you would like to generate from the list of variants that are not available yet.
3. In the subsequent Create variant dialog select the variant that is to be used as the Source variant. In this dialog only the already available variants will be listed as possible source variants.
4. In the Rotate by field select how many degrees the source variant should be rotated in order to generate the new variant.
5. Select the Flip graphic across Y-axis check box if the graphic for the symbol should be flipped across the Y-axis (through the point of origin).
6. Select the Rotate connection point designation check box if the text for the connection point designation should be rotated.
7. Select the Rotate placed properties check box if placed properties should be rotated.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The variant is generated and displayed on a new page <Symbol library>;<Symbol name>:<Symbol number>;<Variant designation> (for example new.test:1;A for Variant A of the test symbol with the internal symbol number 1 in the symbol library new.slk). On the Symbol editor toolbar the button for the new variant will be switched on so that it is easy to move back and forth between the variants of a given symbol.

![](../Pictures/Gui/ALL/note.png) Note:

If all variants have been generated, the New variant command is inactive.

### [ClosedDelete symbol variants](javascript:void(0);)

Precondition:

You are editing a symbol for which at least one variant exists, in which you have activated the graphical view of the variant to be deleted.

1. Select the following commands: Tab Edit > Command group Symbol > Drop-down button Other > Delete variant.
2. Answer the prompt.

### [ClosedToggle symbol variants](javascript:void(0);)

To toggle between graphical views of symbol variants, proceed as follows:

Precondition:

You are editing a symbol for which at least one variant exists.

1. By default, the button Variant A is activated in the command group View of the Edit tab.
2. Now click the button of the variant (e.g. Variant B) whose graphical view you would like to have displayed.
3. If necessary, answer the prompt if changes were made on the current page that have not yet been saved.

![](../Pictures/Gui/ALL/note.png)Note:

When paging through the symbols in the symbol editor, the same variant of the symbol is always shown. If this variant does not exist for a certain symbol, an empty page will be shown in the editor with the note that this "Variant does not exist".

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Symbol 1 has the variants A, B, C and D, symbol 2 has the variants A, B and D, and symbol 3 has the variants A, C and D.  
Now, if variant C is specified for symbol 1, and you page through the three symbols in the symbol editor, you will be informed that this variant is not available for symbol 2. Variant C is displayed for symbol 3, as specified.

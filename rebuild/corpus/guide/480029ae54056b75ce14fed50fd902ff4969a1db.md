# P502008: The connection point pattern '<x>' entered at the part does not exist

### Cause

In the parts database to be checked a part was found where a connection point pattern was entered which Eplan cannot find.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Properties tab to the front.
3. In the property table click [...] in the Data hierarchy level in the value field of the Connection point pattern property.
4. Select the required connection point pattern from the selection dialog opened.
5. Click [OK].
6. Click [Apply].
7. If required, start a new check run.
8. Close the parts management and perform a parts data synchronization.

# P005079: Differing states within a piping

### Cause

In the P&I diagram there are several piping definitions (piping connection points or piping definition points) which have contradictory values with regard to the State (substance) property at a connection.

### Solution

1. Locate the piping definitions in the P&I diagram using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the property dialog of each piping definition and enter the same value in the State (substance) field.
3. If required, start a new check run.

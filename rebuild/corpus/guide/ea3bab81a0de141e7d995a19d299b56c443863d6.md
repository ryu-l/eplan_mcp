# P028003: Structure identifier occurring multiple times in structure segments (<x> = Structure identifier)

### Cause

The structure identifier output with <x> in the Message management dialog exists more than once in several structure segments of the project.

### Solution

1. Locate the structure identifier that occurs several times by using the functionalities Go to (graphic), Go to (2nd coordinate) or Synchronize selection, which the popup menu of the Message management dialog offers you.
2. Call up the Properties <...> dialog of the structure segment and bring the <Structure segment - displayed name> tab to the front.
3. Change the structure identifier in question in the respective identifier block of the structure segment, so that a unique structure identifier is stored in the project.
4. Click [OK].
5. If required, start a new check run.

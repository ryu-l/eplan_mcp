# Creating Check Run Schemes for Project Verification

In a check run scheme for the project verification you determine which error checkings are performed by Eplan.

Preconditions:

- You have selected a project management database.
- In project management, you have loaded directories and projects.

1. Select the following commands: File > Project management.
2. Select a project.
3. Select [Extras] > Verify project.
4. Click [...] next to the Perform project checks check box.
5. Next to the Scheme field click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
6. In the New scheme dialog, enter a meaningful name for the new scheme in the Name field and click [OK].
7. Select a message class in the Class column.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The available messages of the selected class are displayed in the table on the right-hand section of the dialog.
8. Use the drop-down list in the Category column to determine for each message whether the message should be displayed as an error, a warning, or a note.
9. Use the drop-down list in the Type of check column to determine whether the check is to take place online as well as offline ("Online / offline" setting) or only offline ("Offline" setting) or whether the corresponding check is not to be performed (setting "No").
10. Click [Save] and then click [OK].

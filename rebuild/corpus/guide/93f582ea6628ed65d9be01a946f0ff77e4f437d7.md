# Dialog "Workspace" / Dialog "Settings: Workspace"

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Click in the top right in the ribbon on the button ![](../Pictures/Gui/ALL/all_workspace_as.png) (Workspace) and in the opened list select the command Edit workspace.
- File > Settings > User > Display > Workspace

In this dialog you manage and edit the schemes for workspaces. This type of scheme saves an interface configuration which has been configured to personal settings or tasks.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

The ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit) button is also available in this toolbar. With this button you branch to the dialog Edit workspace in which you can select another workspace as the template for the current workspace. In this case the settings of the scheme being edited are overwritten by the settings of the chosen template scheme.

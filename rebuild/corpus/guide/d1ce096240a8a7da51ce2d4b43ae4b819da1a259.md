# Tab Manufacturing

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Master data > Command group Parts > Management. You have marked a part in the tree or list. Select the Manufacturing tab.

In this tab you assign one or more drilling patterns to a part for manufacturing. This data can be specified individually for each part variant.

![](../Pictures/Gui/ALL/note.png)Notes:

- Take note that a drilling pattern is not a part, but simply serves to assign additional structural information to a part.
- Devices with miscellaneous assembly variants must have a suitable drilling pattern defined for each variant. When [placing](cabinetgui_h_geraetplatzieren.htm) such a part, a dialog is displayed in which you can select the drilling pattern to be used.

Overview of the main dialog elements:

Name (drilling pattern):

Click in this column for a row and then click [...]. In the Drilling pattern selection dialog select a drilling pattern that is to be assigned to the part. Any number of drilling patterns can be assigned to each part variant.

Offset X direction (drilling pattern) / Offset Y direction (drilling pattern):

In these columns, you specify a move in the X and Y direction for the respective drilling pattern. This allows you to use identical drilling patterns for parts of different sizes.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Clear contents | Deletes the contents of the currently selected cells. |
| Go to | Only available for the column Name (drilling pattern). Jumps to the drilling pattern that is entered in the currently selected cell. |

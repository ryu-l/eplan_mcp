# Dialog Start pages

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have selected several PLC connection points in the graphical editor, the PLC navigator, or in the device navigator. Or you have selected one or more pages or a project in the page navigator. Select the command Generate schematic. (To this purpose you first have to [Customize the ribbon](userinterface_h_menuebandanpassen.htm) and then assign the desired command to a user-defined command group.) In the Generate PLC schematic dialog, you have selected the rows with the devices for which you wish to generate schematic pages. Select the Calculate pages popup menu item.

In this dialog, you enter the page name of the first page for every required representation type.

Overview of the main dialog elements:

You can use [...] to open the [Full page name](pagebrowsergui_d_seitenname.htm) dialog where you can edit the structure identifier and the page name. You can use [...] to select the structure identifiers (such as function designation and location designation) from the existing ones. You can also manually enter the identifiers and create new ones in the process.

# Compressing the Project

In the course of project planning, project data is often generated which is no longer used in the project when planning is finished. You can remove this data from the project by compressing the project.

- You can reduce the size of a project by removing unused project data.
- You can decide what project data should be removed.
- Project data is compressed for the entire project. You can define a filter to exclude project data from the compression or to compress only selected levels of the hierarchy.
- The result of the compression is output as a system message.

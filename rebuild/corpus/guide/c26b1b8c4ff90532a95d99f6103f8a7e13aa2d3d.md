# P502026: The bus port '<x>' entered in the function templates of the part was not found in single-line representation in the macro '<y>'. The message applies to the part property '<z>'

### Cause

In the parts database to be checked, a part was found at which a function template of a bus port '<x>' is defined. The bus port is missing in the single-line representation in the associated macro '<y>' that is stored in the Data hierarchy level of the parts management at the '<z>' part property.

### Solution

1. Add the bus port in the macro in the single-line representation.
2. Save the change in the macro.
3. In the parts management store the macro again at the part property.
4. Click [Apply].
5. If required, start a new check run.
6. Close the parts management and perform a parts data synchronization.

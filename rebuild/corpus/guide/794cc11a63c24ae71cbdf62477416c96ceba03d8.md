# Dialog Routing connection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Edit > Command group Routing connections > Drop-down list Route > Routing connection. You have selected the source and target of the routing connection to be inserted.

Use this dialog to specify whether the routing connection to be inserted is to be routed in the routing path network or freely.

Overview of the main dialog elements:

Route connection in the routing path network:

The existing routing path network is used for routing the connection. This is the default setting.

Route connection freely:

The connection is routed freely in the room outside the routing path network. The form of the freely routed connection can be changed using the commands New control point, Change curve run and Align curve run tangentially menu items and adapted to the spatial conditions in the mounting layout (tab Edit > Command group Routing connections).

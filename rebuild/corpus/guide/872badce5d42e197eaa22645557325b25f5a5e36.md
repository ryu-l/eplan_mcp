# Creating Configurations for the Tree View

You can configure the structure of the tree view that displays the data in a hierarchical structure to suit your needs. This is done in the user-specific settings that can be accessed from the parts management.

A configuration defines so-called "main nodes" that are displayed as the uppermost hierarchy in the tree structure. All properties in the parts management can be used as structure nodes for grouping purposes. This allows parts data to be prepared to suit different customers and different planning methods.

Precondition:

You have opened the Parts management dialog (Tab Master data > Command group Parts > Management).

1. Select the Settings popup menu item below the [Extras] button.
2. Click [...] in the Tree configuration field of the Settings: Parts (user) dialog.
3. In the Tree configuration dialog, select a scheme from the Scheme drop-down list or create a new one.
4. Click the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button next to the Main nodes field in the toolbar.
5. In the Tree configuration - main node dialog, in the Name field, enter the name of the main node as it is to be displayed in the parts management tree view.
6. If necessary, click [...] in the Filter field to define a filter in the subsequent Filter dialog.
7. Click the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button in the toolbar next to the Properties field.
8. In the Criteria selection dialog select the desired entry from the properties list (e.g. "Manufacturer") and click [OK].
9. Repeat these steps to determine further criteria / create additional main nodes.
10. Click [OK] until you have returned to the Parts management dialog.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The tree view is adjusted.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Enter the "Cables" value for the main node in the Name field of the Tree configuration - main node dialog. Click [...] in the Filter field and define the filter "Product group" = "Electrical engineering: Cables". Then select the properties "Manufacturer", "Connection: Cross-section / diameter" and "Number of connections" (in this order). Confirm all dialogs by clicking [OK].   
The parts management tree view then appears as follows:

| Structure | Meaning |
| --- | --- |
| Cables  RITTAL  10 mm²  4 conductors  RIT.CAB1 4X10RE   5 conductors  RIT.CAB2 1123 (5G10) | Main nodes Subnode "Manufacturer" Subnode "Connection cross-section" Subnode "Number of connections" "Part number" Next subnode "Number of connections" "Part number" |

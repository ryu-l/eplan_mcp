# P005093: The connection diameter '<x>' does not lie within the permissible range of the terminal part

### Cause

A connection to which a terminal is connected was determined in the project whose parts data with regard to the permissible range of the connection cross-section data do not match the value entered at the Cross-section / diameter property. A permissible range of 1 to 10 mm² was, for example, defined for the connection cross-section at the terminal part while a value of 16 mm² was entered at the connection definition point of the connection.

### Solution

Modify either the value for the cross-section at the connection definition point or the corresponding part properties at the terminal:

1. Locate the connection definition point in the project by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Call up the property dialog of the connection definition point and check the value entered in the Cross-section / diameter property on the first tab.
3. Close the property dialog and jump from the popup menu of the message management via the functionality Go to (2nd coordinate) to the connected terminal at which the part is stored.
4. Call up the property dialog at the terminal and select the Parts tab.
5. Branch into the Part selection at the part entered there.
6. Select the Properties tab in the part selection and in the table at the Terminal data tree structure check the values entered in the property fields Terminals: Cross-section from and Terminals: Cross-section to or Terminals: AWG from and Terminals: AWG to.
7. Now either change the cross-section at the connection definition point or the cross-section data at the terminal part in the parts management. In the process ensure that the specified cross-section of the connection definition point is exactly in the range of the cross-section specifications at the terminal part.
8. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Notes:

- The check only takes place if the cross-section was entered at the connection definition point and in the property fields Terminals: Cross-section from and Terminals: Cross-section to or Terminals: AWG from and Terminals: AWG to of the terminal part.
- The units "mm²" are checked against "mm²", "AWG" against "AWG" as well as "sqmm" versus "mm²".
- Not checked are connections with the following connection definition:  
  - Saddle jumper
  - Direct connection
  - Internal
  - Transmission path

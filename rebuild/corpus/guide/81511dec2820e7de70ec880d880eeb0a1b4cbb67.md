# Dialog Import settings

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have performed a version update and started the program for the first time.

In this dialog you specify whether and which settings should be applied from the previous version. Eplan recognizes if the settings databases do not exist yet and need to be generated. The previous version is determined from the registry entries generated during setup.

Overview of the main dialog elements:

User / Workstation / Company:

Select the check box for the settings area whose settings you wish to import into the current version. The following settings are also applied:

- Property arrangement
- Dialog memory
- Tree and list configurations

If the settings database for a settings area (e.g. company settings) already exists, the check box is deselected and grayed out, i.e. no settings can be applied from the previous version.

![](../Pictures/Gui/ALL/note.png)Note:

If the new Eplan version is started by means of the W3u.exe file using the run parameter /Quiet, the Import settings dialog is suppressed. In a case like this, the settings are not applied.

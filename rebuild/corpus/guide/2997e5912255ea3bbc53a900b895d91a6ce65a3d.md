# Action: import3d

|  |  |
| --- | --- |
| **Parameter** | **Description** |
| TYPE | Type of task that the action is to perform: STEP: Importing of 3D graphic data in STEP format DESIGNSPACE: Importing of design spaces (as a STEP file) JT: Importing of 3D graphic data in JT format |
| PROJECTNAME | Project name with complete file path. If nothing is entered, the selected project will be used if the action is to be run over the user interface (e.g. via the script or ribbon). When executing from the Windows command line, PROJECTNAME must be specified or ProjectAction has to be used before that. Otherwise a system message will appear. |
| IMPORTFILE | File path and name. |
| SCHEME | Import scheme (optional). If this parameter is not available or empty (""), then the most recently used scheme is used. |

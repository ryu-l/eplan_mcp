# Dialog Number

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Tab Devices > Command group 2D panel layout > Navigator. In the tree view you have selected the mounting panel whose enclosure legend is to be updated. Popup menu item Edit legend item. Select the [Number] button in the subsequent dialog.
- You are in the graphical editor on a "Panel layout" page and have selected the mounting panel whose enclosure legend is to be updated. Tab Devices > Command group 2D panel layout > Navigator. Popup menu item Edit legend item. Select the [Number] button in the subsequent dialog.

In this dialog you define the numbering settings for the legend items.

Overview of the main dialog elements:

Start value:

Enter the start value for numbering the items here.

Increment:

Here, enter the increment by which the numbers are increased.

Numbering direction:

In this group box you define the direction of numbering:

- Given sequence: With this setting, the sequence of the legend items displayed in the 2D panel layout - <project name> dialog is used. Select this option when you would like to renumber existing positions but would like to retain the existing sequence of numbering.
- Horizontal / Vertical: The numbering takes place here based on the placement on the mounting panel, where the position of the handle of the part placements is decisive for the legend numbers.
- Automatic (only Eplan Pro Panel): The assignment of the item classes in the sorting sequence is based on a two-level hierarchy. Items are first sorted according to their hierarchy and subhierarchy; only items in the same hierarchy and subhierarchy are sorted geometrically.

![](../Pictures/Gui/ALL/note.png)Note:

Please note that the Horizontal and Vertical options are available only in the 2D panel layout navigator and not in the 3D layout space!

Same number for identical devices:

Select this check box, if identical devices are to be given the same legend item. This is particularly important for the GOST standard.  
If the check box is deselected, the legend numbers are assigned regardless of the device.

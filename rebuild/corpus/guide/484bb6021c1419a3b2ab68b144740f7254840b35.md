# P026055: Connection point '<x>' exists more than once

### Cause

Several part placements have the same DT and an identical connection point designation <x> exists in the connection point patterns that are assigned to the parts. As a result the system does not know where it should route the connection.

### Solution

1. Check the connection point patterns of the parts and ensure that there are no identical connection point designations in the connection point patterns.
2. Route the connections again.

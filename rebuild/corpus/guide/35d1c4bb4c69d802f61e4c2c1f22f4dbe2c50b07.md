# P502030: The drilling pattern <x> entered at the part is incomplete. The outline '<y>' does not exist

### Cause

In the parts database to be checked a part was found where a drilling pattern is stored for which an outline was entered which Eplan cannot find.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Manufacturing tab to the front.
3. In the property table in the Name (drilling pattern) column click the table entry and then click [...].
4. In the subsequent dialog open the list of available drilling patterns and mark the desired drilling pattern.
5. Bring the Cut-outs tab to the foreground in the right-hand section of the dialog.
6. In the Outline name column of the table enter an existing outline, or click [...] and select the outline in the subsequent dialog.
7. Click [OK].
8. Click [Apply].
9. If required, start a new check run.
10. Close the parts management and perform a parts data synchronization.

# Activating AutoCorrect for Project Texts

The "AutoCorrect" function allows you to replace project texts with replacement texts during the input. This setting depends on the user. You specify in the dictionary which keywords should be automatically replaced by which replacement texts.

Precondition:

You have selected a dictionary with keywords for AutoCorrect.

1. Select the following commands: File > Settings > User > Translation > Dictionary.
2. Activate the AutoCorrect check box and click [OK].
3. To check the automatic replacement, open a schematic page and select the following commands: Tab Insert > Command group Text > Text.
4. Enter a text from the keyword list for AutoCorrect and select the popup menu item Translate.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The keyword is automatically replaced in the source language, and if a translation text is available for the new text, it is also translated.

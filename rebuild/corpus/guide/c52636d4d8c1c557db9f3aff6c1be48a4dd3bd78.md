# Dialog Format: Address / text

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the [Settings: PLC](plcgui_d_allgemeinespseinstellungen.htm) dialog (for example via File > Settings > Projects > "Project name" > Device > PLC). You clicked [...] next to the PLC-specific settings field in the Settings: PLC dialog. You selected the Format of assignment list tab and clicked [...] next to the Format of assignment list row or Format of assignment list address fields in the dialog [Settings: PLC-specific](plcprocessorgui_d_spsspezifischeeinstellungen.htm).

In the Format of rows in the assignment list (or Format of address in the assignment list) dialog , in the Available format elements list, select any format element except "Separator" and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (or double-click an already defined format element in the Selected format elements list).

In this dialog you specify the formatting for addresses, function text, identifiers or data types in the format group.

Overview of the main dialog elements:

Length:

In this group box you define a limit for the length of the format element:

- Infinitely variable: The number of characters is not defined. You can enter as many characters as you wish.
- Limited variable: The number of characters can be freely chosen up to a particular limit. You define the maximum value in the Number of characters field.
- Fixed: The number of characters is defined as a fixed value in the Number of characters field. If the number of characters lies below the defined value, the format element is padded with spaces.

Number of characters:

For the Limited variable and Fixed options, you enter the maximum permitted number or characters here.

Output right-aligned:

If you have chosen the Fixed option, you can use this check box to specify that the text is to be right-aligned.

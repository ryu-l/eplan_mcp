# Report Blocks

Report blocks are logically coherent groups of [report pages](formgeneratorgui_k_auswertungsseiten.htm). You use [page sorting for reports](formgeneratorgui_k_seitensortierung.htm) to define whether a report is generated in one or several report blocks. If you wish to (e.g.) generate a table of contents for the entire project, i.e., for all structure identifier levels together, then a single report block is generated in the report. If you output a separate table of contents for every structure identifier level then the report is generated using several report blocks. A report block exists for every structure identifier level. When updating reports, all report pages belonging to a report block are taken into account. A report setting always applies for a report block.

When generating reports, Eplan suggests start pages within the page structure. You can accept these start pages or specify different start pages. In this way you define the page structure level where the report block begins. The first report page of the report block is also the start page of the report block.

If you have specified a start page, but this start page is already assigned, Eplan finds the next available page for the report page.

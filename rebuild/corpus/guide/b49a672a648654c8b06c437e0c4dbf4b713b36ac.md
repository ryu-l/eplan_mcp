# Displaying Empty Texts

Precondition:

You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc.

### Finding empty texts

If you accidentally placed empty texts when inserting texts, you can quickly find and remove them.

1. Activate the button Empty texts in the View tab in the command group General.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The empty texts are indicated by the "Empty text" string.
2. Select the respective empty texts and select the popup menu item Delete.

![](../Pictures/Gui/ALL/note.png)Note:

Note that empty special texts on the "normal pages", meaning (still) empty project or page properties, cannot be made visible via the button Empty texts but only via the insertion points. The special texts can only be removed individually by clicking and calling up the delete function.

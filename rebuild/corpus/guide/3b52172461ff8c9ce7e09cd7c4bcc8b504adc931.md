# P002006: Only female pin end available

![](../Pictures/Gui/ALL/note.png)Note:

The counterpiece of a male pin is either the female pin with the same DT and the same pin designation or a female pin that is connected with the male pin via direct connection points.

### Cause

A plug definition was created in the plug navigator or placed in the schematic. The function definition "Plug definition for female pins" is set at this plug definition. This setting makes the program search for a corresponding item, namely the male pin side. This counterpiece, however, is missing in the plug navigator or in the schematic.

### Solution

#### Possibility 1

1. Place a further plug definition in the schematic and enter "Plug definition for male pins" for the function definition.
2. In addition, for the plug definition, enter the same DT as you did for the female pins at the plug definition.

#### Possibility 2

1. Select the plug definition for female pins in the plug navigator.
2. Select the Generate plug definition popup menu item and branch to the submenu Only male pins.
3. Click [OK] in the property dialog that is opened.

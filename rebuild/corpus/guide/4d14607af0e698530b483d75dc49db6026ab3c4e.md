# Adding Parts

In contrast to the adding of project parts, you use this menu item to assign one (or more) parts to the current device.

Precondition:

You have opened a project.

1. Select the following commands: Tab Devices > Command group Devices > Bill of materials.
2. In the Bill of materials - <Project name> dialog, select the devices that are to be assigned further parts.
3. Select the Add part popup menu item.
4. In the Part selection dialog select the parts to be added. Multiple selection is possible.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new parts are assigned to the devices.

![](../Pictures/Gui/ALL/note.png)Note:

All functions of the Part selection can be used, and the parts-specific presettings will be taken into account.

# Tab Format (Cable Numbering)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the [Settings: Cable numbering](cablegui_d_einstellungenkabelnummerierung.htm) dialog, for example via the commands File > Settings > Projects > "Project name" > Device > Cable (automatic). Select the Format tab in the Settings: Cable numbering dialog.

In this tab you specify which properties are to be displayed in the cable DT and how they are to be formatted.

Overview of the main dialog elements:

Format:

Here you specify which properties are to be shown in the cable DT.

- From project structure: The device structure for cables specified in the project structure is used. With this setting, the Sequence tab is also displayed. There, specify the order in which cables should be numbered.
- According to source: e.g. -W=A1+O1-X1
- According to target: e.g. -W=A1+O1-M1
- According to source and target: e.g. -W=A1+O1-X1/=A1+O1-M1
- According to target and source: e.g. -W=A1+O1-M1/=A1+O1-X1

![](../Pictures/Gui/ALL/note.png)Notes:

- If a cable at a PLC connection point is numbered using a format that contains the source and / or target, the associated plug designation of the PLC connection point is taken into account and is shown as a property in the cable DT after numbering. At bus ports the bus interface name of the bus port is displayed in addition to the plug designation.
- In projects with complex identifier structures (functional assignment, function designation, installation site, etc.), the cable identifier can become very long when numbering using the "According to source and target" format (or a similar format) is used. If the identifier structure of a cable now contains the same identifier as the source and / or target, then this identifier can be suppressed in the counter of the cable DT. The device structure is listed in the Full DT field of the cable.

Separator between source and target:

Specify here the separator to be set between the two target designations. All characters are allowed. For DIN projects the standard is the forward slash "/".

Create subcable:

If the check box is selected, subcable DTs are generated for multiple cables between two targets. This is the default setting for all formats for which source and / or target is displayed in the DT. In this case, multiple cables between the same targets can only be differentiated by a subcable.

If the check box is not selected, no subcables are generated and the "normal" counter in the DT continues. (This is only possible for the "From project structure" format.)

Source and target in brackets:

Source and target are set in either square brackets or parentheses in the cable DT.

The display of brackets can be activated and deactivated in the project settings via the check box Hide brackets in DT (command path: File > Settings > Projects > "Project name" > Devices > DT).

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Examples of cable DTs with source and target

| Option | Cable DT |
| --- | --- |
| Round brackets | -W(-X1/-M1).1 (here, M1 is the target),  -W(-X1/-M1.1), -W(-X1/-M1.1).1 (here, M1.1 is the target) |
| Square brackets | -W[-X1/-M1].1 (here, M1 is the target),  -W[-X1/-M1.1], -W[-X1/-M1.1].1 (here, M1.1 is the target) |
| Brackets display switched off | -W-X1/-M1.1.1, -W-X1/-M1.1 (without brackets it is not clear whether M1 or M1.1 is the target) |

The DT components in brackets are considered to be associated in the DT subdivision and therefore not divided up any further. A component of this type - depending on where it is in the DT - can be interpreted as a prefix, counter, or subcounter.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Examples of cable DTs with DT components set in brackets

| Cable DT | Meaning |
| --- | --- |
| -W(=A+O-X1).1 | (=A+O-X1) is interpreted as a counter. |
| =A+O-W(=A-X1/=B-X2) | (=A-X1/=B-X2) is interpreted as a counter. |
| =A+O-(=A-X1/=B-X2)W1 | (=A-X1/=B-X2) is interpreted as a prefix. |

---

Group box Add connection point designation

At source designation:  
At target designation:

If this check box is selected, the first graphic connection point designation is attached to the DT of the cable source / cable target. The separator character specified in the Separator field is inserted in between.

The check box is grayed out for the Format = "From project structure" setting.

Separator:

Specify here the separator to be set between the DT of the cable source / cable target and the attached connection point designation. Any character can be used except "?", ":", and ".". Default is the comma ",".

The field is grayed out for the Format = "From project structure" setting.

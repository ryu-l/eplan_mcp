# Defining and Changing Placement Areas

In order to be placed correctly on other 3D objects, 3D macros require information about the area with which they are placed and the direction in which they may have to be turned. This information is stored in the 3D macro by the definition of a placement area. The position of the placement area also determines the mounting depth to which the 3D object is positioned on a mounting surface. Nine handles are then automatically generated on the placement surface. You can use these for positioning. In addition you can use the command Handle to define a further handle (command path: Tab Insert > Command group Mounting aids > Handle). This handle is always projected onto the defined placement area when placing it.

![](../Pictures/Gui/ALL/note.png)Note:

Please use the functionalities for creating and modifying placement areas only for self-made enclosures that you have imported as a design space or for macros of a macro project. Enclosures that you download via the Data Portal already have placement areas that you must not change. Otherwise the enclosures are no longer compatible with the foreseen accessories and the enclosure configuration is made more difficult.

Preconditions:

- You have opened a schematic project or a macro project.
- You have opened the layout space navigator and a layout space.
- The layout space contains imported 3D objects which are to be saved as a macro.

### [ClosedDefine placement area](javascript:void(0);)

1. Select the following commands: Tab Insert > Command group Placement area > Define.
2. Move the cursor over the surfaces of the 3D object.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The surface beneath the cursor is automatically highlighted in color.
3. When you reach the surface you want, click it.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected area is defined as the placement area. Any area that projects beyond the limits of the selected area will appear transparent. Handles are created at the corners and centers of the limiting edges.

![](../Pictures/Gui/ALL/note.png)Note:

The area that is to be defined as the placement area has to be limited by points that lie geometrically in a common level. Depending on the quality of the imported 3D data, surfaces may be generated which do not meet this condition. Placement areas cannot be defined on such surfaces.

The illustration shows a 3D macro with a placement area beneath the base plate. The handles are at the corners and centers of the edges.

![](../Pictures/Visualisation/ALL/cabinetgui_placementarea_as.png)

### [ClosedTurn around placement area](javascript:void(0);)

The Turn around command rotates the placement area by 180° horizontally.

1. Select the following commands: Tab Insert > Command group Placement area > ![](../Pictures/Gui/ALL/ribbon_placementarea_turnaround_as.png) Turn around.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The placement area and the 3D object are rotated by 180°.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

3D macro with a turned-around placement area

![](../Pictures/Visualisation/ALL/cabinetgui_placementareainvert_as.png)

### [ClosedMove placement area](javascript:void(0);)

The Move command moves the position of the placement area in the Z direction. This allows the mounting depth of the 3D macro to be varied.

1. Select the following commands: Tab Insert > Command group Placement area > ![](../Pictures/Gui/ALL/ribbon_placementarea_move_as.png) Move.
2. Enter the value of the displacement.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If a positive number or a number without prefix is entered, the placement area is moved upwards.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If a negative number with a preceding "-" is entered, the placement area is moved downwards.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The figure shows a 3D macro with a placement area moved by 100 mm.

![](../Pictures/Visualisation/ALL/cabinetgui_placementareadeplace_as.png)

### [ClosedRotate placement area](javascript:void(0);)

The Rotate command rotates the placement area vertically around its center. This allows rotated placement of the 3D macro.

1. Select the following commands: Tab Insert > Command group Placement area > ![](../Pictures/Gui/ALL/ribbon_placementarea_rotate_as.png) Rotate.
2. Specify the angle of the rotation.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If a positive number or a number without prefix is entered, the 3D object is moved counter-clockwise on the placement area.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If a negative number with a preceding "-" is entered, the 3D object is moved clockwise on the placement area.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The figure shows a 3D macro with a placement area rotated by -15°. The handles remain unchanged on the base area.

![](../Pictures/Visualisation/ALL/cabinetgui_placementarearotate_as.png)

# Dialog Settings: Displayed units of measure

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > User > Display > Displayed units of measure

In this dialog, you determine the settings for displayed units of measure.

Overview of the main dialog elements:

Displayed unit of length:

You use these option fields to define whether length information should be displayed in mm or inches. The changed display measuring unit is immediately displayed in the status bar in the lower edge of the screen.

Displayed unit of weight:

You use these option fields to decide whether the weight of a part is reported in "kg" or "lb" (pounds) in parts management. This means that an existing weight will be converted in accordance with the displayed unit of measure.

Decimal places:

In this group box you specify the number of decimal places. The settings apply both for the specified displayed unit of length and for the displayed unit of weight. For both settings "0" can be selected as the minimum value and "8" as the maximum value.

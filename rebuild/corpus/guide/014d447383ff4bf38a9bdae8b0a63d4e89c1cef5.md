# Dialog Configure search

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You are in the parts management, in the part selection, in the part master data navigator or in the Insert center. Click [...] next to the Find field.

In this dialog, you can specify the properties in which the search term is to be searched for.

In the process the properties are saved as schemes so they can be used again at any time. Different schemes are used for the search in the parts management and for the search in the Insert center.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Configuration:

In this field, you can specify through which properties the search is performed. By using ![](../Pictures/Gui/ALL/all_new_as.png) (New) you can select further properties and insert them into the list. The arrow buttons can be used to change the order of the properties.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Select all | Selects all of the entries in the list. |

![](../Pictures/Gui/ALL/note.png)Note:

If the search is to be carried out across all the properties, you have to use an "empty" scheme, meaning a scheme without selected properties. Alternatively you can create a scheme with all properties.

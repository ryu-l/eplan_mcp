# P007033: Manual function text at a function that has a block format for the calculation of the automatic function text

### Cause

You have defined a block property for the automatic function text at a function. The automatic function text defined as a block property has been disabled though by an import, a "global editing" or by a manual input of a function text.

### Solution

1. Locate the function in the schematic by means of the Go to (graphic) functionality offered by the popup menu of the Message management dialog.
2. Launch the property dialog of the function.
3. Delete the manually entered function text at the function, if the defined block property is to be effective for the automatic function text. If you want the manually entered function text "to win", either make no change or delete the block property for the automatic function text from the property list.
4. Confirm your entries.
5. If required, start a new check run.

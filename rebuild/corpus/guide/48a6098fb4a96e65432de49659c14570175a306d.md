# P502032: The channel designation entered in the function templates of the part is invalid

### Cause

In the parts database to be checked a PLC part was found where an incorrect channel designation is entered.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Function templates tab to the front.
3. Change the value or values entered in the column Channel designation in the Device selection (function templates) table at the function definitions that represent connection points for signal, network, bus cable and / or supply connection points. Use purely numeric values. Ensure that no blank space is entered before or after the value. Also there may not be any blank space between two numeric values.
4. Click [OK].
5. Click [Apply].
6. If required, start a new check run.
7. Close the parts management and perform a parts data synchronization.

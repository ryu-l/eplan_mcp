# P007012: Part '<x>,' variant '<y>' is not stored

### Cause

You placed a device and then manually changed the part number and / or part variable. The part and / or the part variable are not loaded into the project in this case.

### Solution

1. In the parts management, create a new device with the relevant part number and / or a corresponding part variant.
2. Place the device.
3. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

This check run is only carried out correctly if it is applied to the entire project!

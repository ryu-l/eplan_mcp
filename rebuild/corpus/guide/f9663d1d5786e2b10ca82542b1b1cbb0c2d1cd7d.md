# Viewing and Changing the Settings

In the Settings dialog, you can view and edit all settings for the Project, User, Workstation, or Company categories.

Precondition:

You have opened a project.

1. Select the following commands: File > Settings.
2. Navigate through the tree structure in the Settings dialog until you have reached the desired setting area.
3. Change the desired settings on the right in the Settings dialog.
4. Click [OK].

![](../Pictures/Gui/ALL/info.png)Tip:

Use the Find input box to find a specific setting faster. As soon as entering the first character, the list below the entry field displays all matches.

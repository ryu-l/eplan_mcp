# P004020: More than one I/O connection point with the same representation type at a channel

### Cause

More than one I/ connection point with the same address and the same representation type was defined within a channel.

### Solution

1. Select the message in the Message management dialog and locate occurrences of the I/O connection point in the schematic using the Go to (cross-referenced) functionality.
2. To do this double-click in the Search results - <Project name> dialog on a function of the I/O connection point that is available more than once in a representation type.
3. In the property dialog opening bring the Symbol and function data tab to the front and in the drop-down list Representation type change the set value in such a way that it only occurs once per channel.
4. Repeat the correction for other I/O connection points reported as faulty as well.
5. Update the connections.
6. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Notes:

- The usage of several I/O connection points within a channel is permissible if only one of these was defined as an activated connection point. All the other I/O connection points within the channel must be marked as deactivated connection points by assigning the property Deactivated I/O connection point to them.
- Please use the [P004097](messages_p_004097.htm) check run, if you use PLC cards at which an input and an output are assigned to the same channel.

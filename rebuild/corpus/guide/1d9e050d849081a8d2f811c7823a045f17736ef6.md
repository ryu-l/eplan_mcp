# Tab Image file

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc. You have marked an image file and chosen the popup menu item Properties, or you have double-clicked an image file. In the Properties dialog, select the Image file tab.

On this tab you can edit the display properties of an image file.

Overview of the main dialog elements:

File:

The file name and the source directory of the image file are displayed here. Whether this image file is referenced or was copied into the project directory depends on the setting you selected in the Copy image file dialog when inserting the image file:

- Keep source directory: If this option is selected, the image is a referenced image, i.e. only a reference to the image is inserted. It is not copied into the project directory.
- Copy: If this option is selected, the image is copied into the image directory specified in the settings.

This is indicated by the tooltip for this image file. In the case of a referenced image file only the file name with the source directory is displayed in the tooltip. In the case of an image file stored in the project the type of storage ("Manually copied" or "Automatically copied") and the storage location are additionally displayed.

Display size:

Here you can specify the size at which the image will be displayed. Entry can optionally be either in coordinate values or in percentages of the original size.

Keep aspect ratio:

Select this check box, so that the original ratio between height and width will be preserved on changes to the display size of the image.

Angle:

Enter an angle in order to rotate the image relative to the X axis.

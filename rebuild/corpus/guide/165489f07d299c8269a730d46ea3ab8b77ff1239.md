# P502015: Part property 'Product group' is undefined

### Cause

In the parts database to be checked a part was found where no information for the Product group property is entered.

![](../Pictures/Gui/ALL/note.png)Note:

The three part properties Generic product group, Product group and Product subgroup are summarized in the Product grouping part property and displayed next to each other in the value field.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Properties tab to the foreground and open the Product grouping hierarchy level.
3. Click the [...] button in the value field of the Product grouping property.
4. In the part tree opening select a product grouping in which a concrete value is defined for all three part properties.
5. Click [Apply].
6. If required, start a new check run.
7. Close the parts management and perform a parts data synchronization.

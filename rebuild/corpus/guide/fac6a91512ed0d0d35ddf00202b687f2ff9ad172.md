# Specifying Entry Point into Routing Path Network

The routing track of a connection can be defined by specifying the point at which the routing connection is to enter into the routing path network. This specification can be applied to routed and non-routed connections.

- With this, non-routed connections are routed in pre-selected routing paths.
- The routing track of already routed connections is modified according to the specifications; the connections are re-routed in the pre-selected routing paths.

Precondition:

You have created connections or routing connections. The routing path view is switched on. The routing connections are shown. The routing connection highlighted in red in the figure is to enter into the routing path network not in the center, but left wire duct.

![](../Pictures/Visualisation/ALL/routing_entrynet1_as.png)

1. Select the following commands: Tab Edit > Command group Routing connections > Entry point into routing path network.  
     
   ![](../Pictures/Gui/ALL/arrow.png) You will be prompted to select the sources / targets of the routing connections.
2. Enter the two corner points of a rectangle that encompasses the required objects.  
     
   ![](../Pictures/Visualisation/ALL/routing_entrynet1b_as.png)  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected sources / targets are highlighted in color.  
     
   ![](../Pictures/Gui/ALL/arrow.png) You will be prompted to select a wire duct or a routing path at which the connection is to enter into the routing path network.
3. Select a wire duct or a routing path at which the connection is to enter into the routing path network. In this example it is the wire duct on the left.  
   ![](../Pictures/Visualisation/ALL/routing_entrynet2_as.png)  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Connections dialog is displayed, which lists all the connections contained in the selected source. The connections captured in the selection of the source and target are already highlighted in the dialog.
4. Activate the check box in the Selection column for the connections that are to be re-routed in the selected target routing path.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected connections enter into the routing path network at the selected entry point, and are re-routed.  
     
   ![](../Pictures/Visualisation/ALL/routing_entrynet3_as.png)

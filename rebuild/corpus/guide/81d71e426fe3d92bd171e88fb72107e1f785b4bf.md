# P027010: Topology - The routing track at the connection from <x> to <y> has an invalid routing path

### Cause

A routing path has been deleted within the routing path network through which the routing connection runs from <x> to <y>. Moreover, the connection has not been re-routed yet.

### Solution

1. Locate the source of the topology function in the routing path network by using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Trace the routing track in the routing path network back to the gap that was created by the missing routing path.
3. Add the missing routing path to the routing path network by means of the following commands: Tab Insert > Command group Topology > Routing path.
4. Position the new routing path between routing path networks objects that are no longer connected so that the two ends of the routing path dock to the connection point of a topology function or to the insertion point of a routing point.
5. Re-route the connection by selecting the total routing path network, and the following commands: Tab Connections > Command group Topology > Route.
6. Update the connections.
7. If required, start a new check run.

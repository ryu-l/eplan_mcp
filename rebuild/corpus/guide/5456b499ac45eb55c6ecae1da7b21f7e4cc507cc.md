# Report page sorting

Project pages are managed in the page structure of the project using structure identifier levels. When generating reports, Eplan analyzes the project data and displays it in [report pages](formgeneratorgui_k_auswertungsseiten.htm). These pages are sorted into the page structure of the project.

You use the page sorting to define which structure identifiers generate their own [report blocks](formgeneratorgui_k_auswertungsbloecke.htm). When generating a table of contents for instance, the "Total" page sorting generates a comprehensive table of contents for the complete schematic documentation, whereas the page sorting "Function designation" generates a separate table of contents for each function designation. For instance, the following functions are possible:

- You can create a comprehensive reporting block for the entire project.
- You can create a separate reporting block for each structure identifier level of an identifier block.
- You can create a separate reporting block for each structure identifier level of several identifier blocks.

  ![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

  You have specified Function designation + location designation page sorting for the "Table of contents" report type by means of the commands File > Settings > Projects > "Project name" > Reports > Output to pages. Eplan uses this setting to create the following report blocks:

  - A separate table of contents for each structure identifier level of the Function designation identifier block. Therefore, this happens every time the function designation changes.
  - A separate table of contents for each structure identifier level of the Location designation identifier block. Therefore, this happens every time the location designation changes.
- You can create one comprehensive reporting block for the complete project, and additionally, one or more identifier blocks for each structure identifier level.

  ![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

  You have specified the page sorting Total + Function designation + Location designation for the "Table of contents" report type by means of the commands File > Settings > Projects > "Project name" > Reports > Output to pages. Eplan uses this setting to create the following report blocks:

  - A comprehensive table of contents for the total project.
  - A separate table of contents for each structure identifier level of the Function designation and Location designation identifier blocks. Therefore, this happens every time the function designation and location designation change.
- You can create a separate reporting block every time the component property "Output group" changes.

![](../Pictures/Gui/ALL/note.png) Note:

Which types of page sorting are available depends on the report type. For the "Forms documentation" report type, only (e.g.) the "Total" page sorting option is available.

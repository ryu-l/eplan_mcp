# Action: XEsGetPropertyAction

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| PropertyId | Identifier of the property to be defined (= Property number) |
| PropertyIdentName | Identifier of the user-defined property as it was assigned by the user |
| PropertyIndex | Index of the property (usually 0) |
| PropertyValue | Determined value of the property |

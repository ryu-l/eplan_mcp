# P022025: The text angle is not equal to 0 or 90 degrees

### Cause

A text was found in the schematic whose text angle is not equal to 0° or 90°.

### Solution

1. Locate the text in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Call up the Properties <...> dialog of the text and bring the Format tab to the foreground.
3. Assign the value 0,00° or 90,00° to the Angle property.
4. Close the Properties <...> dialog by clicking [OK].
5. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Notes:

- The check run is carried out for text on the following page types:

- Schematic multi-line  
- Schematic single-line  
- Fluid power schematic  
- Overview.

- In the case of docked property texts, only the text of the main property is checked.
- The check does not include texts of dimensions, texts within blocks, and texts within embedded reports.

# Selecting Objects for Block Editing

There are several methods available for the selection of objects for block editing.

### Select objects directly

Objects like projects, pages, project data, and components can be selected for block editing by using direct selection via a mouse click.

### Highlight objects of the same type

Preconditions:

- You have opened a project. You have opened a project page in the graphical editor.
- Multiple objects are not selected on the page.

1. Move the mouse pointer over the desired object.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The object is shown in a different color.
2. Select the popup menu item Highlight objects of same type.   
     
   ![](../Pictures/Gui/ALL/arrow.png)All the objects of the selected types are marked in color on the currently open page and shown with their insertion points.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Your schematic page includes cables -W20, -W21, and -W22. To perform a block edit on these cables, you use the option of selecting objects of the same type.

Use the mouse to move the crosshair onto the definition line of -W20. Cable -W20 is marked in color.

![](../Pictures/Visualisation/ALL/multipleselection_kabelobjekt1_av.png)

You subsequently select the popup menu item Highlight objects of same type. Cables -W20, -W21, and -W22 are marked in color and shown with their insertion points. Now you can change the properties of these cables in one step using block editing.

### Select objects within an area

Eplan also offers the option of selecting objects for block editing within an arbitrary page area. To this purpose hold the left mouse button down and move the mouse pointer to draw a frame around the desired objects in the graphical editor.

#### Highlight objects of the same type in an area

Within the area you have defined with a frame, it is also possible to select objects of the same type. Also use the popup menu item Highlight objects of same type here.

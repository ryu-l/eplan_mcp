# Exporting 3D Graphic Data

3D graphic data can be exported from Eplan Pro Panel for further usage in other CAD programs into the formats STEP, VRML, JT and in the open data standard IFC.

Precondition:

You have opened a project. You have opened a layout space.

1. In the layout space navigator, select the project or the layout spaces whose contents are to be exported.
2. Select the following commands: File > Export > Command group Project data > Layout space > Command group Layout space > STEP or VRML or IFC or JT.
3. In the scheme field of the dialog STEP export, VRML export, IFC export or JT export, select the desired export scheme from the Scheme drop-down list. Or click [...] to create the settings for a new user-defined scheme in the subsequent dialog.
4. In the Output directory field, enter the storage location of the export file to be generated, or use the button ![](../Pictures/Gui/ALL/all_selectdirectory_as.png) to open the dialog Select folder to select any desired directory for the export.
5. Enter a name under which the export file is saved in the File name field. Or select the name interactively via ![](../Pictures/Gui/ALL/all_selectfile_as.png).  
     
   ![](../Pictures/Gui/ALL/arrow.png) A query is displayed when you select an existing file. There decide whether you want to overwrite the file.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The data are written to the export file.

# Displaying Part Properties as QR Codes or as Images at a Device

At a component in the schematic you have the possibility to have the data of a part stored at the device displayed as property placements. To do so add the desired properties to a property arrangement. For the part properties Image file and External document: File / hyperlink [1-20] the image file of an assigned part and/or the hyperlink of an external document at the assigned part can be displayed as a QR code via the display property Display at the component in the graphical editor.

If you use these part properties in a property arrangement, a different image or a different QR code with a different hyperlink can be displayed at the device when the part is replaced.

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select a component in the graphical editor.
2. Select the Properties popup menu item.
3. In the Properties <â¦> dialog, select the Display tab.
4. From the Property arrangement list select a property arrangement with the desired part property, or use the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button to add the part property Image file and/or External document: File / hyperlink [1-20] to a property arrangement.
5. Select one of these part properties from the Property arrangement list.
6. In the right-hand section of the tab in the Property / assignment table open the Alignment box hierarchy level and activate the check box for the Activate alignment box property.
7. Select the entry "QR code" or "Image file" from the Display drop-down list.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The QR code or the image file is displayed at the component. If a desired representation (for example "Image file") is not possible for a property of the property arrangement, nothing is displayed.

The size of the alignment box determines the size of the image or of the QR code in the graphical editor.

For "normal" texts, function texts, special texts and placeholder texts, the "Text" value for the Display display property cannot be changed.

![](../Pictures/Gui/ALL/note.png)Notes:

- If you have added one or both part properties to a property arrangement, this property arrangement is set to "User-defined". Save the property arrangement via the button ![](../Pictures/Gui/ALL/all_save_as.png) (Save) if this property arrangement is also to be available for other functions with the same symbol variant.
- The "UTF-8" coding is used by default for the coding of texts in QR codes. However, the "Shift JIS" coding is required for Japanese characters.  
  The project setting [QR code coding](gedviewer_d_einstellungenprojektallgemein.htm#QRCodeCodierung) allows you to customize the coding of inserted QR codes in a project. With the drop-down list of this setting you can switch between the two codings "UTF-8" and "Shift JIS".

![](../Pictures/Gui/ALL/info.png)Tip:

Different functionalities can be executed for the images or QR codes displayed as property placements:

- If a QR code is a link to an external document, you can, for example, use the [Ctrl] key to turn the cursor into a hand and open the hyperlink with a click.
- Like other property texts, the images or QR codes can also be moved in the graphical editor by using the popup menu items Text > Move property text. In order for an image or a QR code to be moved independently of the other property placements, the respective properties in the property arrangement must not be docked to other properties.

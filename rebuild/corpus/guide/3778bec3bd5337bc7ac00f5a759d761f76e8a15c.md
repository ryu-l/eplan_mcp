# Tab Copper bundle

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The project contains at least one layout space. The layout space contains a copper bundle. You have opened the layout space navigator. Select a copper bundle in the layout space navigator or 3D display area. Select the Properties popup menu item.

On this tab, you specify the properties for the highlighted copper bundle.

Overview of the main dialog elements:

Name:

The name entered here is displayed in the layout space navigator.

Structure identifiers:

The full DT of the copper bundle (i.e., structure identifier of the current environment + displayed DT) is displayed in this field. Click [...] to open the Structure identifier of the copper bundle dialog and, for example, enter a different location designation.

Description:

In this field, a describing text can be assigned to the copper bundle, e.g., which is output in reports.

# Export Design Space

The following section describes the third working step when using Eplan Design Space Exchange:

- The export of the design space with added mounting layout and NC data to a 3D CAD program.

The settings for the export of design spaces can be adjusted in the user-specific settings (File > Settings > User > Interfaces > Design space import and export).

Precondition:

You have opened a project. The layout space navigator is open. You have created a mounting layout in the previously imported design space.

1. In the layout space navigator, select the design space that is to be exported.
2. Select the following commands: File > Export > Command group Project data > Layout space > Design space.
3. In the Design space export dialog select a scheme with settings for the export of the selected design space or use [...] to open the settings dialog and change the settings.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) One STEP file each is exported for each part placed with Eplan Pro Panel during the data export.  
     
   ![](../Pictures/Gui/ALL/arrow.png) During data export one XML file with the data of all the objects in the layout space (the objects imported from the CAD system, the objects added using Eplan Pro Panel, the cut-outs generated automatically through a part placement and manually inserted cut-outs) is created for each layout space.
5. Use the [CAD Add-ins](xdesignspaceimportgui_k_prinzip.htm#CADAddIn) to import the generated STEP files back into the 3D model in the 3D CAD program.

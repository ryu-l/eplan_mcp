# Reports

Reports represent queries of the project data. They allow the targeted output of project data. These are automatically generated and can be written directly to report pages or to external files, e.g., for printing item labels. It is also possible to manually place reports into an existing project page as an embedded report, e.g., for enclosure legends. Reports are divided into [report types](formgeneratorgui_k_auswertungstypen.htm).

![](../Pictures/Gui/ALL/note.png)Note:

If the project does not contain any objects that are required for the respective report or if no suitable objects were found due to the set filters, a report page is generated.

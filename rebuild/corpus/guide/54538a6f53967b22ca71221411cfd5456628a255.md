# Inserting Wire Harness Definitions or Cable Unit Definitions

Wire harness definitions and cable unit definitions can be defined directly while inserting the corresponding symbol into the schematic. In the wire harness navigator or the device navigator you can predefine wire harness definitions or cable unit definitions with specific properties. You can then place functions created in this manner in the schematic at a later time. Wire harness definitions or cable unit definitions must be placed if you want to copy these.

Preconditions:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the following commands: Insert center > Breadcrumb trail Home > Symbols.
2. Enter the character string "HDEF" for wire harness definitions and the character string "CUDEF" for cable unit definitions in the Find field.
3. Below the Symbols folder click the tile of the symbol displayed in the preview.
4. Insert the wire harness definition or the cable unit definition on the schematic page.
5. Enter the data for the wire harness definition in the dialog Properties <...> in the Wire harness tab or the data for the cable unit definition in the Cable unit tab.
6. Click [OK].

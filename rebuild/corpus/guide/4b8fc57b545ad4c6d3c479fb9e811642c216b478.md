# Dialog Settings: DXF / DWG export and import

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > User > Interfaces > DXF / DWG export and import
- File > Export > Command group Project data > Project data > Command group Page > DXF / DWG. Click [...] next to the Scheme field.

In this dialog specify the settings for DXF / DWG file imports and exports and save them as a scheme.

The settings in the Layers, Colors, Fonts and Line types tabs apply to exports and imports. Special settings such as the output or initial directory, which only affect import or export, can be specified in the Export and Import tabs. The data in the Block definition and Block attribute tabs is only evaluated on export.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

# P005047: Net definition point contains incomplete connections

### Cause

One or more connections were deleted within a net in the schematic. This creates a gap in the daisy chain. A connection gap is indicated in the property dialog of a net definition point (tab Net connections, Connections table) by a small warning triangle in the Connection points column. In this case the [P005046: Incomplete net](messages_p_005046.htm) message is output as well.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

A net N1 in the schematic connects 5 fuses (-F1 to -F5) with the potential L1. The connection points form the following daisy chain:

| Connection point | Source | Target |
| --- | --- | --- |
| L1 | L1 | -F1:1 |
| -F1:1 | -F1:1 | -F2:1 |
| -F2:1 | -F2:1 | -F3:1 |
| -F3:1 | -F3:1 | -F4:1 |
| -F4:1 | -F4:1 | -F5:1 |
| -F5:1 |  |  |

The fuse -F4 and the associated T-node is deleted in the schematic.

![](../Pictures/Visualisation/ALL/messages_005046_bsp1.3_av.png)

After deleting -F4 and the T-node, a gap arises in the daisy chain:

| Connection point | Source | Target |
| --- | --- | --- |
| L1 | L1 | -F1:1 |
| -F1:1 | -F1:1 | -F2:1 |
| -F2:1 | -F2:1 | -F3:1 |
| -F3:1 | -F3:1 |  |
|  |  | -F5:1 |
| -F5:1 |  |  |

### Solution

Complete the net by reintegrating the deleted connection into the net and closing the gap in the daisy chain.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Proceed as follows with regard to the example listed above:

1. Locate the relevant net definition point in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the Properties <...> dialog of the net definition point.
3. Bring the Net connections tab to the front.
4. In the Connections table determine the missing connection point that is indicated by a warning triangle - in this case the -F4:1 fuse is missing.
5. Close the property dialog and insert a fuse again with the DT -F4.
6. Use a T-node to connect the connection point of the fuse -F4:1 to the net.
7. Call up the Properties <...> dialog of the net definition point N1 again and bring the Net connections tab to the front.
8. Click ![](../Pictures/Gui/ALL/all_startdaisy_as.png) (Create daisy chain).
9. In the Connection points table select the connection point -F4:1 with the target number "0".  
     
   ![](../Pictures/Gui/ALL/arrow.png) Connection point -F4:1 is copied to the Connections table and entered beneath the horizontal line of the daisy chain. This creates a new daisy chain.
10. Click ![](../Pictures/Gui/ALL/all_enddaisy_as.png) (End daisy chain) to complete the daisy chain.  
      
    ![](../Pictures/Gui/ALL/arrow.png) A horizontal line is created beneath connection point -F4:1 in the Connections table.
11. Select the connection point -F4:1 in the new daisy chain, then click the ![](../Pictures/Gui/ALL/all_arrowup_as.png) (Move up) button to move it to the second daisy chain.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The second daisy chain is deleted in the process.
12. Position the -F5:1 connection point directly under the warning triangle.
13. Select the entry with the warning triangle and delete it with ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete).
14. Close the Properties <...> dialog of the net definition point by clicking [OK].
15. If required, start a new check run.

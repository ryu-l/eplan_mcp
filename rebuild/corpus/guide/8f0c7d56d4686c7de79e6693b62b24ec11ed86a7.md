# P028008: The planning object has a function template for which there is no function

### Cause

The planning object has at least one free function template for which there is no assigned detail planning. The function template assigned to the planning object, thus, has not been placed in the schematic as a function yet.

### Solution

Create the detail planning:

1. Locate the function template and associated planning object in the pre-planning navigator using the Synchronize selection function offered by the popup menu in the Message management dialog.
2. Highlight the function template in the pre-planning navigator, and place it on a schematic page using the Place popup menu item.
3. If required, start a new check run.

# Dialog Number pages

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened the page navigator and opened (at least) one project.

- You have selected one or more pages in the page navigator. Tab Home > Command group Page > Number.
- You have copied and inserted the pages. Click [Number] in the Adapt structure dialog.

In this dialog you can automatically allocate page names.

Overview of the main dialog elements:

Structure-oriented numbering:

In DIN projects activate this check box to provide numbering per structure identifier. If deactivated, then pages are continuously numbered without accounting for the structure identifiers.   
For sequentially numbered projects, this option is inactive.

Starting number:

Here you enter the page number from which the numbering is to begin.

Increment:

Here you enter the increment value for the separation between the page numbers.

Keep interval:

In combination with the definition of the start page, this check box retains the increments between the selected pages for the target pages. In this way you can move any desired number of selected pages by a specified increment. Entering the increment size is not possible in this case.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Assume that you want to move the pages 1, 2, 3, and 8 and choose a starting number of "2". After renumbering, the page names 2, 3, 4, and 9 will be displayed in the list.

Keep text:

Activate this check box when the alphabetic part of the page name should not be overwritten. This option is also available for subpages. If the check box is deactivated then the text part is deleted.

Subpages:

In the drop-down list, you select how subpages are to be handled when copying:

- Retain: Existing subpages are adopted unchanged into the target pages.
- Consecutive numbering: Existing subpages are renumbered using the starting value "1" and an increment of "1". At every change of the main page, the subpage numbering begins again from "1".  
   The subpage numbering depends on the Subpage character project setting (command path: File > Settings > Projects > "Project name" > Management > Pages).
- Convert into main pages: Subpages are converted into main pages and renumbered.

# Dialog New bundle if property value has changed

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have created routing connections. Routing connections are highlighted in the connections navigator. Tab Edit > Command group Routing connections > Bundle. In the dialog Bundle routing connections click the [...] button in a line under Bundling scheme in the table. In the Settings: Bundle dialog click the [...] button in the New bundle if property value has changed field.

Use this dialog to define schemes with an arrangement of properties. Whenever the value for one of the properties changes, a new bundle with a new bundle number is created. The structure and functionality of this dialog corresponds to that of the dialog Sorting (bundles).

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Category / property:

This list shows the criteria in accordance with which bundles are created when the value of one of these properties changes. To define the rules for the generation of the new bundles, several criteria can be combined with each other.

When the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button is clicked, the dialog Criteria selection is displayed in which you can select properties from the source, target and connection sections whose change is to initiate sorting into new bundles.

By connection point position:

Devices whose connection points are located on two or more connection point layers over each other are wired during manufacturing from bottom to top. To this purpose it should be possible to combine the wires per connection point layers in a bundle. The following check boxes are available as sorting and bundling settings in order to ensure this requirement:

- Source X, Target X
- Source Y, Target Y
- Source Z, Target Z.

These settings take into consideration the position specifications X-position, Y-position and Z-position in a global or local connection point pattern of a part placement. When these check boxes are activated, wires from and to connection points with the same position specification are sorted correspondingly into common bundles.

# P004200: Siemens: Incorrect PLC card assignment: <x>

### Cause

Eplan has determined an incorrect assignment of a PLC card with regard to the used rack. Which PLC card is affected and how the assignment has to be corrected is specified in the placeholder '<x>' of the message.

### Solution

1. Locate the PLC box representing the PLC card in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Open the property dialog of the PLC box.
3. Bring the PLC structure data tab to the front.
4. Correct the value or the setting of the property specified in the message text in accordance with the default (for example for the property Rack, PLC card is placed on rack ID, Position (slot / module) or CPU).
5. Click [OK].
6. If required, start a new check run.

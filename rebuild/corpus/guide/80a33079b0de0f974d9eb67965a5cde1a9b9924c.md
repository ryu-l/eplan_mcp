# P026023: The length of the part placement is greater than the delivery length of the part

### Cause

Part placements which are mounting rails or cable ducts can be inserted on a mounting surface in variable lengths. The value of the Length property changes automatically. In the parts management, the Delivery length property is available for the selected mounting rail or cable duct part. In a specific case, the length of the mounting rail or cable duct placed exceeds the delivery length value specified in the parts management.

### Solution

1. In the parts management, check the value entered in the Delivery length property for the mounting rail or cable duct used.
2. Either reduce the length of the mounting rail or the associated part placement on the mounting surface (command path: Tab Edit > Command group Rail / wire duct > Change length), or increase the value in the Delivery length property in the parts management accordingly.
3. If required, start a new check run.

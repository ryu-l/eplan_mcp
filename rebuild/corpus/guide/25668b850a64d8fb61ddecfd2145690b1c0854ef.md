# P026093: Missing environmental conditions for air-conditioning calculation at the enclosure

### Cause

Properties that are required for the air-conditioning calculation are missing at the enclosure.

The following properties have to be defined and have values assigned to them at the enclosure for air-conditioning calculation to be carried out:

- Power dissipation: Installation situation
- Power dissipation: Maximum external temperature
- Power dissipation: Minimum external temperature
- Power dissipation: Maximum internal temperature
- Power dissipation: Minimum internal temperature.

### Solution

1. Locate the enclosure in the layout space using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Call up the properties dialog of the enclosure and check on the first tab whether all the properties listed above are entered in the properties table and / or have values assigned to them.
3. If not, add the properties and / or missing value(s).
4. If required, start a new check run.

# P003002: It is not possible to make an automatic cable selection for this cable, because no corresponding filter criterion was found

### Cause

You have generated a cable by means of the automatic cable selection. However, there is already a manual cable definition for the cable that has specific default values with regard to its properties, for example the properties Number of connections, Voltage, Cross-section etc. One or more of these values do not match the cables that you have stored in the Cable preselection table for the automatic cable selection. Therefore no suitable cable part exists for the manually defined cable.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You have defined a cable with a voltage value of 1000 V. However, in the table for the cable preselection there are only cable parts with voltage specifications between 230 V and 400 V.

### Solution

Modify the cable preselection to the manually defined property values.

1. Select the following commands:  File > Settings > Projects > "Project name" > Devices > Cable (automatic).
2. Click [...] next to the Automatic cable selection field.
3. In the dialog Settings: Automatic cable selection click ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the toolbar of the Cable preselection table.
4. In the tree view of the part selection that opens, branch via the hierarchy levels Part > Electrical engineering > Component to the product group Cables and select a cable part with the corresponding property values.
5. Confirm your entries.
6. Regenerate the cable automatically again.

![](../Pictures/Gui/ALL/note.png)Note:

This module-specific message is output by the automatic cable selection. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

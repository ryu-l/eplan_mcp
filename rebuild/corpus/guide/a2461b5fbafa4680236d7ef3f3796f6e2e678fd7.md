# Dialog Optimize net manually

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have created routing connections. A net is highlighted in the layout space navigator or in the layout space. Tab Edit > Command group Optimize nets > Drop-down button Automatic > Manual.

In this dialog, you can set options for the manual optimization of nets and the connections routed in them.

Overview of the main dialog elements:

Close last daisy chains into a ring:

If this check box is activated, an additional connection from the first to the last connection point of the chain is generated.

Route connections:

If this check box is activated, all connections generated in the newly defined routing tracks will be routed as routing connections.

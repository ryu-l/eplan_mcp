# Displaying Block Properties

Block properties can be displayed in the schematic and output in forms. This applies equally to user-defined block properties and indexed block properties.

### Display block properties in schematic

Preconditions:

- You have opened a project.
- You have opened the properties dialog for a function (e.g. by double-clicking on a component in the graphical editor).

1. In the Properties <...> dialog, select the <Function category> tab.
2. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) on the toolbar above the Properties field.
3. In the dialog Property selection select a block property and click [OK]. This can be a user-defined block property or an indexed block property for which a format property is already defined.

   ![](../Pictures/Gui/ALL/info.png)Tip:

   To select multiple properties at once, hold down the [Ctrl] key and click different properties.
4. Select the Display tab and change the display settings for the block property, if necessary.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The block property is displayed according to the settings in the schematic and contains the values of the properties defined in the associated format or in the associated format property.

![](../Pictures/Gui/ALL/note.png)Note:

So that block properties are shown on the project pages in a macro project, you have to set a corresponding display mode in the [Settings: Representation in macro projects](settingsmastergui_d_darstellungmakroprojekten.htm) dialog.

### Output block properties in forms

Preconditions:

- You have opened a project.
- You have opened a form in the forms editor.
- You have already defined block properties for the functions to be included in the report of the form, or the corresponding block properties on the symbol or project are predefined.

1. Select the following commands: Tab Insert > Command group Text > Drop-down button Forms > Placeholder text
2. In the Properties - Placeholder text dialog in the Placement tab click [...].
3. In the dialog Placeholder texts - <Form type> select the desired block property and click [OK]. This can be a user-defined block property or an indexed block property for which a format property is already defined.
4. In the Properties - Placeholder text dialog, click [OK].
5. Place the property in the form.
6. Repeat the steps above in order to place any additional placeholders for block properties in the form.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the form is used for a report, the placeholders for the block properties are filled with the values of the properties defined in the associated formats or in the associated format properties.

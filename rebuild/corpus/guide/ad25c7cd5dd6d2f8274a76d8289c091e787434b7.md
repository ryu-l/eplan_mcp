# Creating Properties Comparison Schemes

In a project comparison scheme you specify which properties are compared to each other during the project comparison of the project verification.

Preconditions:

- You have selected a project management database.
- In project management, you have loaded directories and projects.

1. Select the following commands: File > Project management.
2. Select a project.
3. Select [Extras] > Verify project.
4. Click [...] next to the Compare properties check box.
5. Next to the Scheme field click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
6. In the New scheme dialog, enter a meaningful name for the new scheme in the Name field and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The properties of the project data groups "Device", "Connections", "Graphic", "Pages", "Potentials" and "Project" are displayed in the tabs.
7. Select a project data group in the tab.
8. To select properties for the property comparison, select one or more properties in the Do not compare field and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).
9. Click [Save] and then click [OK].

# Dialog Edit revision marker

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have generated a revision and have opened a revision project (file extension \*.ell). You have marked a changed object and selected the popup menu item Edit revision marker.

In this dialog you specify the settings for the automatically generated revision marker text or you can change it manually.

Overview of the main dialog elements:

Marker text format:

This field displays the set format for the automatic marker text. This consists of different properties, such as revision name, edited by, modification date. Use [...] to open the Format dialog, where you can determine the properties and their formatting.

Marker text:

This field displays the automatically generated marker text, meaning the values of the properties specified above. You can manually supplement or overwrite this text.

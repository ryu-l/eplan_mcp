# Tab Plug definition

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have selected a plug definition in the graphical editor. Popup menu item Properties. In the Properties <...> dialog, select the Plug definition tab.
- You have selected a plug definition in the plug navigator or device navigator. Popup menu item Properties or Properties (global). In the Properties <...> dialog, select the Plug definition tab.
- You create a plug definition in the plug navigator via the Generate plug definition popup menu item.

In this tab, you can specify or modify the properties of a plug. The plug can either consist only of male pins, only of female pins, or of a mixture of male and female pins.

In the Properties (global) processing mode, you edit the properties of all representations of the function jointly; in this case, the tab shows the supplement "(Device)".

Overview of the main dialog elements:

Displayed DT:

The displayed DT is displayed in the graphical editor on the component. If you have defined in the project settings that devices are to be automatically numbered when symbols are inserted, then a DT is automatically suggested here. You can accept this DT or overwrite it manually.

In addition you can use the [popup menu or the [...] button](devicetaggui_r_feldsichtbaresbmk.htm) to create or select a DT.

Full DT:

This field displays the full DT (i.e. structure identifier of the current environment + displayed DT) of the component / item. Use the [...] button to open the Full DT dialog. You can edit the structure identifiers there and select, e.g., another mounting location.

Plug diagram form:

The form defined here is used when creating plug diagrams. It has priority over the form that you have selected in the report settings.

Select a form from the drop-down list. Selecting the "Browse" entry opens the file selection dialog where you can select a form from any desired directory.

Function text:

Here you enter the function text for the function / device.

Aside from the manually entered function text, there are other (automatically determined) function texts that you will find in the table of properties:

- Function text (automatic): Displays the content of the manually entered function text or, if it is empty, the path function text. If you edit this function text in the Properties (global) processing mode, the content is returned to the function where the function text was entered originally. When this property is displayed on a project page, the line breaks are removed.
- Function text (common): Displays the function text (automatic) of the function or, if it is empty, the function text (automatic) of the associated main function.

Connection point diagram form:

The form defined here is used when creating connection-point diagrams. It has priority over the form that you have selected in the report settings.

Select a form from the drop-down list. Selecting the "Browse" entry opens the file selection dialog where you can select a form from any desired directory.

Mounting site (describing):

Here you enter the descriptive mounting site for the plug, or select an entry from the drop-down list. The list shows all values that you have previously entered for the same type of function at other places in the project.

Main function:

Select this check box if the current function is a main function.   
When using a DT for which there is already a main function, when using a placed main function, or when placing an already placed main function, this property will automatically be switched off at the target function, that is, the check box is deactivated.

![](../Pictures/Gui/ALL/note.png)Note:

The setting is automatically compared to the check box of the same name in the Symbol / function data tab.

Function definition:

Click [...] to open the Function definitions dialog. The function definitions are already filtered here, and only plug definitions are offered. Select the desired plug definition.

This field is synchronized with the Definition field in the Symbol / function data tab.

[Properties group box](devicetaggui_r_gruppenfeldeigenschaften.htm)

You can use the following properties in the "Settings" category to specify whether plug definitions should be output in plug diagrams, plug connection diagrams, or plug overviews:

- No output to terminal / plug diagram
- No output to terminal-connection / pin-connection diagram
- No output to terminal-strip / plug overview.

# Dialog Export settings (append data)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings. Select one of the settings areas "User" or "Workstation" and click the popup menu item Export (append data).

This dialog allows you to add the data from further settings areas to an existing export file.

Overview of the main dialog elements:

<Hierarchy path>:

The text next to the check box shows which settings area is selected in the tree view of the Settings dialog. If the check box is selected, the selected settings area and all subordinate areas are exported and added to the existing export file.

Other settings areas:

Here you define which other program settings and configurations are to be exported. If a check box is selected, this is exported. The check boxes available depend on the settings area selected in the tree view of the Settings dialog.

![](../Pictures/Gui/ALL/note.png)Note:

These other settings are only available for the setting areas "User" and "Workstation".

- Property configuration: Exports the property configurations for devices, pages, etc. that you have defined in the Properties <...> dialog, via the Configure popup menu item.
- Dialog memory: Exports, for example, the size, position on the screen, screen resolution, "minimized" / "maximized" status of dialogs and for the tables in dialogs the settings of the column widths, the row height and whether the text is highlighted in bold.

  ![](../Pictures/Gui/ALL/note.png)Note:

  When importing / exporting the settings for the dialog memory, it is a good idea to set the same resolution on all the different workstations. Different screen resolutions can result in dialogs no longer being displayed in the visible area of the screen.
- Tree and list configurations: Exports all configurations for the tree and list views of the navigators which have been determined via the popup menu item Configure representation.
- Filter: Exports all the user-defined filter settings.
- Shortcut keys: Exports all specified shortcut keys.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Target file:

In this field you enter the name of the existing export file to which you wish to add the extra settings area data. By default, the export file receives a name reflecting the selected area in the tree view of the Settings dialog. The file name consists of the following elements: <Main category>+<Sub-category>+<Settings area>.xml. Using ![](../Pictures/Gui/ALL/all_selectfile_as.png) you can enter a file name and file path for the export file.

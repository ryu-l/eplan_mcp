# P004099: PLC card with the device identification '<x>' is not placed on a head station

### Cause

At a PLC card with the device identification '<x>' which is placed on a specific rack the active property PLC card is placed on head station documents that the rack is a head station. However, the PLC card which represents the rack is not a head station. A head station is identified by being a rack and either has the Bus coupler / head station check box or the CPU check box selected in the PLC structure data.

### Solution

1. Locate the PLC card placed on the rack in the schematic by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. In the popup menu select the menu item Go to (2nd coordinate) and this way jump to the PLC box that represents the rack.
3. Open the property dialog of the PLC box.
4. Bring the PLC structure data tab to the front.
5. In the property table activate the check box of the property Bus coupler / head station and / or CPU.
6. Click [OK].
7. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

It is not possible to jump to the rack if such had not been defined. In this case select or create a PLC card which is to serve as a rack. Assign the value to the rack (second tab, field Rack) that you have assigned to the PLC card (second tab, field PLC card is placed on rack ID) that is to be placed on the rack. Do not forget to additionally declare the rack defined that way as a bus coupler / head station and / or CPU.

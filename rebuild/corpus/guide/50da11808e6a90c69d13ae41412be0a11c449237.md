# Dialog Optimize nets automatically: Preview of result

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have created routing connections. In the layout space navigator or in the layout space a component has been highlighted that contains routing connections. Tab Edit > Command group Optimize nets > Automatic. In the Optimize nets automatically dialog, click [OK].

In this dialog, the result of the analysis of nets and routing connections is displayed. The data of the first connection is transferred to all connections of the net following optimization.

Overview of the main dialog elements:

The properties of the connections are displayed in the table. The table contains the following columns:

- Row: Contains a consecutive row number.
- Status: Indicates whether the connection can be optimized.   
  "New" = connections that receive a new routing track through optimization.  
  "Cannot be optimized" = connections that are not complete or that were previously routed optimally.
- Source
- Target
- Connection designation
- DT (full)
- Connection color / number
- Connection: Cross-section / diameter with unit
- Part number [1]: Shows the part number of the first part entered at the connection.

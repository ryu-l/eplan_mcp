# Parts Management

Managing master data is especially important for supplier relationships and data exchanges. For this reason, Eplan provides a dialog with the parts management which supports the following actions:

- You can store the most important part-specific and supplier-specific information and combine this with the project currently being edited.
- You can assign required or optional accessories to the part and manage these accessories.
- A collection of parts which belong to a device can be combined into an assembly.
- Multilingual information and different currencies can be managed in the parts management.
- You can structure the parts according to your individual requirements.
- You can import and export the data of specific manufacturers.
- The data of parts, addresses, drilling patterns, etc. can be exported and reimported after external editing (for example in Microsoft Excel).

The respective data sources are stored in an internal Eplan database or in an SQL Server database and the currently selected database is displayed in the title bar of the Parts management dialog.

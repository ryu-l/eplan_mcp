# Automatic / Manual Translation

In Eplan, you can translate an entire project or just selected project texts. You can also translate project-independent data such as parts data in Eplan.

### Automatic Translation

In automatic translation the translated text is automatically assigned to the project or selected project data. Eplan used the translation text in the dictionary for this. To start the automatic translation, enter the text and select a project or project data and perform a translation run. You can also specify that individual text is to be translated on input.

### Manual Translation

In manual translation you manually assign translation text when inputting each individual piece of text. You can select existing translation text from the dictionary or enter new translation text when doing this.

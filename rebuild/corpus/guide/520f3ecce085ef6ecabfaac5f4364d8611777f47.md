# P011006: Ring connection for interruption point

### Cause

The arrowhead of the counterpiece of two interruption points that are cross-referenced with each other are connected to the arrow stub of the first interruption point. A ring connection arises.

### Solution

1. Locate the interruption points in the schematic by using the Go to (graphic) functionalities from the popup menu in the Message management dialog.
2. Disconnect the connection between the interruption points cross-referenced to each other.
3. Update the connections.
4. If required, start a new check run.

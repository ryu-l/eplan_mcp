# Outline Editor

The outline editor is opened in the ribbon via the Master data tab, in the same way as plot frames and forms. The functionality of the outline editor depends on the outline type ("Outline extrusion" or "Outline NC record generation") to be created and thus on the selected file type (\*.fc2 or \*fc1):

- The outline editor for "NC record generation" is used to manage 2D outlines from which NC records can be generated (\*fc1).
- The 2D outlines managed in the outline editor for "extrusions" can later be used to model a 3D object by extrusion (\*fc2).

![](../Pictures/Gui/ALL/note.png)Note:

Please note that subsequent changes to the Outline type property are not possible.

A created / drawn outline is always saved as an independent file in the format of the relevant master data type, in the special <Program Drive>: \<Program Directory>\Macros\<Company Code> directory.   
Sometimes it is also necessary to save additional data such as machine-based information for NC programs or logics, as well as saving the actual outline drawing.

The general outline drawings created for customized mounting rails, etc., can include several outlines that do not intersect. By contrast, an outline drawing from which NC records are to be generated must contain only a single closed outline.

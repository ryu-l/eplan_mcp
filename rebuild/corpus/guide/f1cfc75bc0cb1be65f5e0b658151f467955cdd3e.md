# P024012: Too many conduit connections

### Cause

The value entered in the field Number of connections of the conduit property dialog is smaller than the actually existing number of conduit connections of the conduit.

![](../Pictures/Gui/ALL/note.png)Note:

Free templates are not taken into consideration!

### Solution

1. Locate the conduit definition line in the schematic by using the Go to (graphic) functionality from the popup menu of the Message management dialog.
2. Open the property dialog of the conduit.
3. Increase the value in the field Number of connections so that it matches the number of conduit connections actually existing.   
     
   Or click [...] next to the Type field and use the part selection to enter a suitable conduit with the respective number of connections.
4. Click [OK].
5. Update the connections.
6. If required, start a new check run.

# P502018: The dimensions 'Width' and 'Height' stored at the part do not agree with the dimensions of the macro '<x>' ('<y>' / '<z>') (tolerance <u> percent)

### Cause

In the parts database to be checked a part was found at which a 2D window macro is stored whose dimensions deviate by a fixed specified maximum tolerance from the values of the parts properties Height and Width entered at the part. Eplan specifies the name of the macro in the placeholder '<x>', the representation type in the placeholder '<y>', the variant in the placeholder '<z>' and the used tolerance in the placeholder '<u>'.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Properties tab to the front.
3. In the property table expand the following hierarchies: Mounting data > Dimensions.
4. Note the values in of the properties Width and Height.
5. Switch to the hierarchy level Data.
6. Remember the macro name entered in the Schematic macro property.
7. Close the parts management.
8. Now place the macro of the schematic page of a project and call the properties of the macro.
9. Remember the assigned values of the properties Width and Height in the Format tab.
10. Compare these values with the values already noted from the parts management.
11. Close the property dialog.
12. Mark the line with the message in the message management dialog and open the parts management by means of the Properties popup menu item.
13. Change for the part marked there into the Properties tab and open the hierarchy levels Mounting data > Dimensions once more in the properties table.
14. Enter the dimensions from the macro in the value fields of the properties Height and Width.
15. Click [Apply].
16. If required, start a new check run.
17. Close the parts management and perform a parts data synchronization.

![](../Pictures/Gui/ALL/note.png)Note:

Note that only the variant "A" is checked with regard to the dimensions in 2D macros.

# P004029: Object marked for deletion

### Description

When importing PLC configuration files, PLC objects (PLC boxes, PLC connection points or addresses) are marked program-internally if they exist in the Eplan project in the associated configuration project, but not in the import file.

After importing the PLC data, this marking is displayed as an activated check box for the respective objects in the Addresses / assignment lists dialog (Tab Devices > Command group PLC > Assignment list) in the Marked for deletion table column.

When importing in AutomationML AR APC format, PLC connection points are additionally marked for deletion if the symbolic address in the import file is empty, but the Symbolic address (automatic) property is filled at the associated PLC connection point in Eplan. The existing symbolic address remains.

When carrying out the check run, all objects with this marking are searched for. A message is output in the message management for every object found.

# Opening a Project (Project Management)

You can open normal and zipped projects from within the project management. Already opened projects have a project name shown in bold text.

Preconditions:

- You have set up the project management.
- In the tree structure of project management there is an imported directory with at least one project.

### Open projects and close project management

With this procedure, one or more projects can be opened simultaneously and edited directly in the page navigator. Project management closes automatically after the projects have been opened.

1. Select the following commands: File > Project management.
2. Mark the desired project in the tree structure in the Project management dialog.
3. Click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project management is closed, and the project is opened in the page navigator.

### Open projects without closing project management

In this procedure, one or more projects can be opened simultaneously and edited directly in project management.

1. Select the following commands: File > Project management.
2. Mark one or more projects in the tree structure in the Project management dialog.
3. Select [Organize] > Open.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The marked projects are opened in the page navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project names of the projects opened are shown in bold text in the project management dialog.

![](../Pictures/Gui/ALL/info.png)Tips:

- You can open projects using drag & drop by dragging the selected \*.elk project file from Windows Explorer to the page navigator.
- Projects that you have imported into project management can also be opened outside project management. When you open project management again, these projects are automatically opened in project management.

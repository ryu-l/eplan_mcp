# P005065: Connections have conflicting data at the '<x>' property

### Cause

A connection that exists in the project in multiple representation types has conflicting data regarding the <x> property. For example, the connection in the multi-line representation has the connection color "RD" for "red"; in the single-line representation, however, the connection color "BU" for "blue".

### Solution

1. Locate the connection in the respective representation type by using the functionalities Go to (graphic) and Go to (2nd coordinate), which the popup menu of the Message management dialog offers you.
2. Call up the Properties <...> dialog of the connection in each representation type and streamline the value in each case of the <x> property that was indicated in the message.
3. If required, start a new check run.

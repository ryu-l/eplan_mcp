# Dialog New identifier

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project in which identifier blocks are used in the project structure, for instance "Function designation" and "Location designation". Tab Tools > Command group Management > Structure identifiers. Select the Tree tab, highlight the structure identifier below which you want to generate a new identifier, and click ![](../Pictures/Gui/ALL/all_new_as.png) (New).

In this dialog, you can generate a new structure identifier within an identifier block and determine its properties.

Overview of the main dialog elements:

Designation:

Enter the designation here under which the structure identifier is to be managed.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

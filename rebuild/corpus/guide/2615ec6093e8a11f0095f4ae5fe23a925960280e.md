# P004027: Missing or incorrect channel designation

### Cause

A missing or incorrect channel designation was found at a PLC connection point that is an input or output.

The message is output when one of the following conditions is fulfilled for the Channel designation property of the PLC connection point:

- No channel designation was assigned.
- The channel designation consists of an alphanumerical string.
- A numerical string whose value is less than zero was entered as the channel designation.

![](../Pictures/Gui/ALL/note.png)Note:

Other PLC connection points, for example connection points for the card power supply are not checked.

### Solution

1. Locate the relevant PLC connection point in the schematic or in the overview by using the Go to (graphic) function from the popup menu in the Message management dialog.  
     
   If you have created the PLC connection point as a new function via one of the project navigators (for example PLC or device navigator) and not placed it yet, select the Synchronize selection functionality from the popup menu.
2. Open the property dialog of the PLC connection point.
3. Enter a value that consists of a numerical string and that is greater than zero in the Channel designation field of the PLC connection point tab.
4. If required, start a new check run.

# Copper Rail: Changing the Angle

Each angle of a placed copper rail can be modified directly on the item.

Preconditions:

- You have opened a project. You have opened a layout space.
- The layout space contains placed busbars (bending).

1. Select the following commands: Tab Edit > Command group Graphic > Change angle.
2. To modify the angle of a leg on a bent copper rail, move the cursor over the item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Bending positions where the angle can be changed are marked with a green point.
3. Select the green point at the required bending position.
4. You can then rotate the end point of the selected leg, or you enter a new angle value on the keyboard.

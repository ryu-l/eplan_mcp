# P028010: The data of the PLC connection point differ from the data of the PLC address in the pre-planning

### Cause

Identification occurs via the CPU name and the symbolic address. The address, function text, data type, and direction can deviate. The direction of the connection point is determined from the function definition.

### Solution

1. Synchronize the data of the PLC connection point with the data of the PLC address in the pre-planning, or assign the data of the PLC address to the PLC connection point in the detail planning.
2. If required, start a new check run.

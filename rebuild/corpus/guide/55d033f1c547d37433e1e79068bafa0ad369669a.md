# Dialog Settings: DT (projects, devices)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Settings > Projects > "Project name" > Devices > DT.

In this dialog you determine project-specific general settings for the identifiers of devices, such as whether device tags are to be converted to upper-case letters.

Overview of the main dialog elements:

Conversion to upper-case:

If this check box is activated, the texts for the following properties are converted to upper-case letters:

- Displayed DT
- Full DT
- Connection designation and color / number (for connections and connection definition points)
- Terminal designation
- Plug designation, channel designation and address (for PLC connection points)
- Structure identifiers.

Terminal connection point designations are not converted.

![](../Pictures/Gui/ALL/note.png)Note:

Please note that existing values are not converted automatically. If, for example, a check run is carried out after the page properties has been changed, a message is output if there are lower-case characters.

Hide brackets in DT:

If this check box is selected, the brackets used to structure the DT are removed from display in the graphical editor, in the block properties, in the reports as well as manufacturing data export so that, for example, WX1/X2 is displayed there instead of W(X1/X2) for a cable designation.

If multiple pairs of brackets are used, only the outermost pair is removed so that, for example, W(X1)/(X2) is displayed there instead of W((X1)/(X2)).

In direct editing, in the properties dialog and in dialog title bars the brackets are always displayed.

![](../Pictures/Gui/ALL/note.png)Note:

Note that this setting also influences the Symbolic address (automatic) and Symbolic address (determined) properties.

Set preceding sign:

In this group box, you specify the device groups for which the preceding sign should be automatically set in the displayed DT. If this check box is activated for a device group then the displayed DT will be visible with the preceding sign for devices from this group, for example -M1. If the check box is deactivated, the displayed DT will be displayed without a preceding sign, for example M1.

Fluid power: Use trade identifier as identifier (media code):

If this check box is activated, an identifier structure according to the ISO 1219-2 standard is supported for fluid devices. For fluid functions, the value of the Trade property (ID 20466) is then queried and the associated trade identifier is transferred into the property DT: Identifier (ID 20013). This property corresponds to the media code. No special settings are required in Eplan Fluid for the identifier elements "Circuit number", "Item number", and "Accessories". The appropriate data entries are automatically recognized by the program.

This behavior applies both to the inserting of macros and the inserting of symbols. In the case of symbols, the last-used trade is set by default. In the case of macros, the trade is stored at the associaated functions.

In addition, this setting has the following effects on program behavior:

- The Prefix project setting (under File > Settings > Projects > "Project name" > Devices > DT syntax check) is automatically set to "Prohibit" and grayed out.
- In the Full DT dialog, the edit fields for the DTs of fluid power functions are shown in a table and the designations according to the standard DIN ISO 1219-2 used for column headers. For this, the prefix in the DT of fluid power functions must be empty.
- In the Insertion mode dialog, the Number circuit number if existing field is displayed for fluid power functions instead of the Number prefix if existing field.

Fluid power: Hide identifier (media code) in the graphic:

If this check box is activated, the media code is hidden in the placed property text for the displayed DT., i.e., it is not displayed on the schematic page. In the properties dialog, the media code continues, however, to be displayed in the displayed DT and in the full DT.

If the check box is deactivated, the media code is displayed both in the properties dialog and on the schematic page.

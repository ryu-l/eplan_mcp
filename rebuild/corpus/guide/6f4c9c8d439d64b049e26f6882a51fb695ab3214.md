# P028024: The pre-planning assigned to the object has been deleted

### Cause

A segment was deleted in the pre-planning. The objects that are no longer assigned (functions, macros or pages, etc.) still exist in the schematic and have to be checked.

A segment was deleted in the pre-planning. The objects that are no longer assigned (functions, macros or pages, etc.) still exist in the schematic and have to be checked.

### Solution

1. Locate the objects that are no longer assigned in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Check the objects and assign them, if required, to the corresponding pre-planning.
3. If required, start a new check run.

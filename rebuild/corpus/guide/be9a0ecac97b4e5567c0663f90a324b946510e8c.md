# Dialog Copy hyperlink

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a project page in the graphical editor.. Tab Insert > Command group External > Drop-down button QR code > Hyperlink. In the Properties dialog, select the document to be linked in the Hyperlink tab and click [OK].

In this dialog, you can specify whether the document is to be copied into the project directory or referenced from the source directory.

Overview of the main dialog elements:

Keep source directory:

A reference to the document is inserted in the project and the document from the original directory is displayed. If the document is changed, it is automatically updated as soon as you open the page. During the data backup, a setting allows documents that are located in external directories and to which references are made, to be taken into consideration.

Copy:

The document is copied to the project directory (this means into the DOC subdirectory of the project) and the copied document from the project directory is displayed. The document is not stored directly in the DOC subdirectory but in a further separate subdirectory. The name of this subdirectory is derived from the source directory name.   
All files in the project subdirectories are also included in backups.

Overwrite with prompt:

Select this check box to have a confirmation displayed for the Copy option if the document is already present in the project directory. You can then decide whether it should be overwritten or not.

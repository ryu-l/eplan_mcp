# Filleting / Chamfering Corners

Filleting / chamfering is available for the following elements in Eplan:

- The corner of two radiating lines
- The corner between a line and a polyline
- The corner between two polylines
- The corners of polylines (open and closed)
- Rectangles.

Precondition:

You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc.

### Fillet corners

Use the Fillet command to fillet enclosed angles of less than 180°. Angles between open lines cannot be filleted i.e. lines cannot be connected via the filleting function.

1. Select the following commands: Tab Edit > Command group Graphic > Fillet.
2. Click on the corner to be filleted.
3. Specify the fillet radius by moving the mouse and left-clicking as soon as the required value is reached.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The corner is correspondingly filleted.
4. Click on the next corner to be filleted with the same fillet radius.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The corner is automatically filleted with the previously defined fillet radius.
5. End the action via the Cancel action popup menu item or via the [Esc] button.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

A corner of a rectangle is filleted with a radius of 16 mm.

![](../Pictures/Visualisation/ALL/gededitgui_roundingexample1_as.png)

### Chamfer corners

You can use the Chamfer command to chamfer the corners of different elements symmetrically. This functionality can be used on enclosed angles which are less than 180°. In this case the original lines are shortened symmetrically by a value (the so-called chamfer width) which is measured from the angle point.

1. Select the following commands: Tab Edit > Command group Graphic > Chamfer.
2. Click on the corner to be chamfered.
3. Specify the chamfer width by moving the mouse and left-clicking as soon as the required value is reached.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The corner is correspondingly chamfered.
4. Click on the next corner to be chamfered with the same chamfer width.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The corner is automatically chamfered with the previously defined chamfer width.
5. End the action via the Cancel action popup menu item or via the [Esc] button.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

A corner of a rectangle is chamfered with a chamfer width of 16 mm.

![](../Pictures/Visualisation/ALL/gededitgui_faseexample1_as.png)

![](../Pictures/Gui/ALL/note.png) Note:

You can also fillet or chamfer corners of single elements in a group of elements.

![](../Pictures/Gui/ALL/info.png)Tip:

You can also use the input box to specify the fillet radius or the chamfer width, for filleting and chamfering.

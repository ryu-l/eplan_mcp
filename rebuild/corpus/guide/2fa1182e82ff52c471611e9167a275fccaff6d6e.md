# P004057: Several parts with the same or suitable device identification '<x>' found. A different part possibly has to be assigned to the function '<y>'

### Cause

During the import of PLC data a search is carried out for a matching part in the parts database on the basis of the device identification. It can consist of the specification of the PLC type designation or the device description file. Possibly two or more parts having an identical device identification were found in the parts database. However, it is also possible that the PLC type designation that is always searched for first contains placeholder characters. Then several parts are found, with the first found part being used.

The device identification is displayed in the placeholder '<x>' of the message, the DT of the respective part in the placeholder '<y>'.

### Solution

1. If several parts with an identical device identification are found, correct the parts in the parts database. If a part with placeholder characters is found in the PLC type designation, check at the device whether the right part is stored. If necessary, select a different part.
2. Import the PLC data again.

# P027024: The function definition of the topology function is not suitable for the main function

### Cause

Within the routing path network, a topology function has been found that is not a main function and whose function definition does not match the associated multi-line main function in the schematic.

### Solution

1. Locate the topology functions in your routing path network by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Select the popup menu item Go to (2nd coordinate).  
     
   ![](../Pictures/Gui/ALL/arrow.png) A jump is made to the multi-line counterpiece â the main function.
3. Call up the Properties <...> dialog of the main function, and switch to the Symbol / function data tab.
4. Remember the entry in the Definition field under the Function data (logic) group box.
5. Close the Properties <...> dialog of the main function using [Cancel].
6. On the insertion point of the main function, open the popup menu, and select the Go to (counterpiece) menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A jump is made to the topology function.
7. Call up the Properties <...> dialog of the topology function, and, here too, switch to the Symbol / function data tab.
8. In the Function data (logic) group box in the Definition field, click [...], and set the same function definition at the topology function that is also set on the main function.
9. Click [OK].
10. If required, start a new check run.

# P005063: Connection point is not contained in the multi-line connection definition

### Cause

Not all connection points of devices that are displayed in the Interconnect devices tab of the property dialog of a single-line connection definition point have had a target assigned to them.

### Solution

1. Either interconnect all the connection points or no connection point on the Interconnect devices tab of the single-line connection definition point.
2. If required, start a new check run.

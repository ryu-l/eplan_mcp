# Inserting and Changing Wiring Cut-Outs

Wiring cut-outs are used to steer connections during routing to the back of mounting panels, partitions, or other enclosure items. During routing automatic routing paths are used that arise during the creation of the routing path network between the part placements and the wiring cut-out.

- The placement of wiring cut-outs is similar to that of locked areas.
- Wiring cut-outs are inserted in the layout space as cuboids.
- Wiring cut-outs have the Extra length property. If the value of this property is empty at the wiring cut-out, the value from the Extra length wiring cut-outs project setting (command path: File > Settings > "Project name" > Routing connections > General, tab Route) is used. During routing, the extra length is added once to each connection that passes through.
- A wiring cut-out contains only a routing path. As a result, it can only receive connections from one direction.
- The edges of a wiring cut-out can be used as starting or end point of a line or curve. In this case, connections are also routed through the wiring cut-out. This allows routing through the wiring cut-out to be implemented by the specification of manual routing tracks.

1. Select the following commands: Tab Insert > Command group Routing aids > Wiring cut-out.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The status bar shows a prompt "Starting point of the wiring cut-out".  
     
   ![](../Pictures/Gui/ALL/arrow.png) When determining the starting and end point, you can use the Placement options popup menu item, and use the relative coordinate input.
2. Place the starting point of the wiring cut-out on an activated area of a mounting panel.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The status bar shows a prompt "End point of the wiring cut-out".
3. Pull the wiring cut-out apart in the desired direction like a rectangle.
4. Place the end point freely, or capture another point.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The wiring cut-out is inserted in the item as a cuboid.  
     
   ![](../Pictures/Visualisation/ALL/routing_cutout_as.png)

### Modifying the size of wiring cut-outs

The size of wiring cut-outs can only be changed in two ways:

- Changing the format properties in the property dialog: Enter changed values for the Width and Height fields on the tab of the Format property dialog. The change is made referenced to the bottom left-hand corner.
- Graphical change: Mark the object. Direction arrows appear at the corners and in the middle of the sideline, in whose displayed direction you can pull apart and pull together the object. While moving along the direction arrow, handles that you can use for exact positioning are displayed at neighboring 3D objects.

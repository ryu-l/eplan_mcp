# Dialog Back up master data

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Extras > Command group Organize > Master data > Command group Back up > Back up master data

In this dialog, define how and where the selected master data are to be backed up.

The following master data can be backed up from the dialog:

- Parts data
- Basic projects
- Forms
- Outlines
- Plot frames
- Macros
- Project-independent settings.
- Symbol libraries
- Dictionaries

![](../Pictures/Gui/ALL/note.png)Note:

Graphics in plot frames or forms are only backed up when they are stored in the plot frame or form. Referenced graphics cannot be saved and restored.

Overview of the main dialog elements:

Master data type:

Select the master data type here that you want to back up.

Directory:

Select the directory where the backed up master data is located. The default master data directory is preset (as determined under the command path File > Settings > User > Management > Directories). Click ![](../Pictures/Gui/ALL/all_selectdirectory_as.png) to open the dialog for choosing a directory and then navigate to the desired directory.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

Master data: <Master data type>:

This table displays the master data in the selected directory. Click the column headers to sort the master data in ascending, descending, or original order. Select the master data you wish to back up.

Back up subdirectories:

Select this check box if you want the master data in the subdirectories to be backed up as well.

File name:

Enter the name of the file in which the selected master data is to be backed up. Click ![](../Pictures/Gui/ALL/all_selectfile_as.png) to open the Select backup file dialog and then navigate to the desired directory, or create a new one.

Description:

In this field you can enter a text description (e.g. storage location) that is stored with the master data and which can be displayed from within Eplan during backup and restore operations.

Target directory:

Enter the storage location here. You can specify any drive and subdirectory as the target for the data backup. Click ![](../Pictures/Gui/ALL/all_selectdirectory_as.png) to open the dialog for choosing a directory and then navigate to the desired directory, or create a new one.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

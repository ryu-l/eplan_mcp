# Defining a Handle for Grouped 3D Objects

If you have grouped 3D objects in the layout space, you can define a superior handle for this group. This handle can be used to move the entire group. After the group has been broken up, the superior handle is removed automatically, and the handles of the individual 3D objects take effect again.

Preconditions:

- You have opened a project.
- You have opened a layout space.
- The layout space contains 3D objects that you have inserted, for example, as devices or window macros / symbol macros.
- Object snap is switched on.
- The grouping for 3D objects is selected (Tab Edit > Command group Group > Button Grouping).
- The Mounting aid button is activated for the view in the layout space.

1. Hold down the left mouse button and drag a frame around the 3D objects that you want to move as a group.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The 3D objects are highlighted in color.
2. Select the following commands: Tab Edit > Command group Group > Group.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The 3D objects are combined into a group.
3. Now insert a handle that you define as the superior handle of the group. To do so, select the following commands: Tab Insert > Command group Mounting aids > Handle.
4. Move the cursor over the 3D objects.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The 3D snap points of the object are displayed. These are the end or center points of an edge or the corner points of a cuboid surrounding the object.
5. Click the desired 3D snap point.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The handle is identified by an orange cuboid.
6. Now click one of the grouped 3D objects.
7. Press the [V] key to move the group by means of the handle.
8. Move the cursor to the desired position and click the left mouse button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The grouped 3D objects are placed at the new position.
9. If you want to ungroup the grouping, draw a frame around the group again.
10. Select the following commands: Tab Edit > Command group Group > Ungroup.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The superior handle is deleted.
11. Deactivate the grouping for 3D objects. (Tab Edit > Command group Group > Button Grouping)  
      
    ![](../Pictures/Gui/ALL/arrow.png) The handles of all individual 3D objects are now effective again.

# Duplicating Objects in the Layout Space

Using the Duplicate command, you can insert multiple copies of 3D objects and 3D macros in the layout space very easily at the same time. Duplication only works within the layout space, not across layout spaces.

Precondition:

You have opened a project. You have opened a layout space.

1. Mark the object, 3D macro, or group of objects to be duplicated by drawing a border around these objects.
2. Select the following commands: Tab Edit > Command group Graphic > Duplicate.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The objects hang on the top left handle on the cursor. Press [A] to change the handle.
3. Select the Placement options popup menu item to open the [Placement options](cabinetgui_d_platzieroptionen.htm) dialog and set the rotation angle, handle and offset values. Click [OK].
4. Place the first copy.
5. In the Duplicate dialog, enter the total number of elements to be created.
6. In the subsequent Insertion mode dialog determine how the structure identifiers of the duplicated objects are to be treated. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan automatically generates the specified number of copies and places them at the distance selected for the first copy. In the layout space navigator the copies are entered in the hierarchy parallel to the source objects.

![](../Pictures/Gui/ALL/info.png)Tips:

- You can also generate a single copy by holding down the [Ctrl] key while clicking the object and then dragging the copy to its new position.
- If you want to edit multiple 3D objects together in a layout space (duplicate, copy, move, cut, delete) you, after marking them, combine these 3D objects into a [group](gededitgui_h_elementegruppieren.htm) by using the command Group. You can subsequently ungroup the grouping by using the command Ungroup (Tab Edit > Command group Group).

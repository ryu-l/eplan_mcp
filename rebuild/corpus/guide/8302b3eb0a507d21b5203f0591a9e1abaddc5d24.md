# Tabs "Device properties" / "Part properties"

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Export > Command group Project data > Project data > Command group Page > PDF. Click [...] in the Scheme field of the PDF export dialog. Select the Device properties or Part properties tab.
- File > Settings > User > Interfaces > PDF export. Select the Device properties or Part properties tab.

Only available if the Generate device pages check box is selected in the Device pages tab. In the Device properties and Part properties tabs, specify which properties should be output in which order on PDF pages with device data.

Overview of the main dialog elements:

Table:

The Property column shows the properties that are output by default for the PDF file. Under Name, you will see the default names of these properties. You can also edit these multilingual texts.

Properties that are either "empty" in the properties dialog, have the value "0", or do not exist for a device (e.g. the Cable type property on a safety fuse) are not listed in the PDF.

Break up assemblies:  
Break up modules:

Only for part properties!

Activate these check boxes if assemblies and/or modules are to be broken up into their components, meaning the individual parts, during the PDF export. This way the components of an assembly or a module are listed on the exported device pages.

In addition activate the adjacent Include supplemental parts check boxes if the supplemental parts are to be taken into consideration when breaking up the assemblies and/or modules. This means that the supplemental parts contained in an assembly and/or module are also listed on the device pages.

Up to level:

If you selected the Break up assemblies and / or Break up modules check box, enter the number of hierarchical levels of assemblies that should be broken up.

# P003008: Cable connection without cable

### Cause

- Case 1: The connection definition point of a cable connection no longer exists on the intersection with the cable definition line. This is preventing Eplan from assigning the connection definition point to a cable.
- Case 2: The connection definition point of a shield is no longer located within its own area of influence. This is preventing Eplan from assigning the connection definition point to a shielding conductor.

### Solution

#### Possibility 1

Move the connection definition point to the intersection of the cable definition line with the cable connection or to within reach of the shield.

#### Possibility 2

Draw the cable definition line or the shielding conductor again.

Update the connections.

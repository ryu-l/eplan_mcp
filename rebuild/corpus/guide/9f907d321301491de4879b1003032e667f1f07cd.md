# P013045: The import file contains an invalid part

### Cause

In the import file (XML format) for the import of bills of material the field name P\_ARTICLEREF\_IDENTNAME within the tag <device\_P\_ARTICLEREF\_IDENTNAME> has been changed.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The tag <device ARTICLEREF\_TEST\_IDENTNAME> has been renamed.

### Solution

1. During the output of the message check in the Message management dialog whether the message [P013048: A field named <x> does not exist and is therefore ignored](messages_p_013048.htm) was output as well. The message also shows the incorrect field name instead of the placeholder <x>.
2. Open the import file used in a text or XML editor.
3. Find the field name given in message P013048 within the "device" tag and correct it as described in the "Cause" section.
4. Save the import file and import it again.

![](../Pictures/Gui/ALL/note.png)Notes:

- Further information appears in the Help under [Importing bills of materials](partslistgui_h_stuecklistenimportieren.htm).
- Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

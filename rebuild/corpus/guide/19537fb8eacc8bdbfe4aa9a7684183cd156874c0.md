# P026027: Cut-out is not completely on a mounting surface

### Cause

A cut-out was not fully placed on the mounting surface, or a length-variable item was shortened by using the command Change length, so that a cut-out no longer lies completely on the mounting surface. "Not complete" means that the cut-out with its handles is either only partially or completely outside the mounting surface.

### Solution

1. Locate the cut-out in the layout space using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Move the cut-out to the desired mounting surface so that its handles lie completely within the mounting surface.
3. If required, start a new check run.

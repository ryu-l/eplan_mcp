# Creating Symbols

Precondition:

You have opened a project and at least one symbol library.

1. Select the following commands: Tab Master data > Command group Symbols > Drop-down button Symbol > New.
2. If multiple symbol libraries are open, select the symbol library in which you would like to create the new symbol in the Symbol library selection dialog.
3. Click [OK].
4. In the Create variant dialog select which symbol variant you would like to create.
5. Click [OK].
6. In the Symbol properties - <Library name> dialog specify the data for the symbol to be generated. The next available number will be assigned as the Symbol number.
7. In the Function definition field click [...] in order to specify the symbol logic in the Function definitions dialog.
8. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol editor is opened.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A circle is displayed in the symbol editor which has been moved but cannot be deleted. This circle represents the future insertion point of the symbol.
9. Design the desired symbol: Insert graphical elements such as lines, rectangles and / or circles and arrange the insertion point and the graphical elements according to your wishes.
10. At the desired places place the connecting points that are to represent the connection points of the symbol. Select the following commands: Tab Insert > Command group Logic > Drop-down button Symbol connection points > Connection point top, ...bottom, ...right or ...left.
11. In the Connecting point dialog define the properties of the connecting points such as Connection point number, Connection point description and / or Connection point designation.
12. Confirm your entries.
13. Select the following commands: Tab Edit > Command group Symbol > Drop-down button Other > Placed properties.
14. In the Property placement dialog specify the properties displayed as default of the symbol.
15. Click [OK].
16. Close the symbol editor and confirm the message that follows by clicking [Yes].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The new symbol is generated in the selected symbol library.

![](../Pictures/Gui/ALL/info.png)Tip:

When placing connecting points press [Ctrl] and move the mouse to switch back and forth between the connection point directions. Or press the [TAB] button to rotate the connection point counter-clockwise through the possible directions.

![](../Pictures/Gui/ALL/note.png)Notes:

- The symbol number "0" is offered as the starting value in an empty symbol library.
- Negative values and values that exceed the maximum number of 32,000 are not allowed as symbol numbers.

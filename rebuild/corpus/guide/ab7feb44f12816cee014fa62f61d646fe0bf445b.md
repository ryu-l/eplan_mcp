# Defining Settings for External Editing

When exporting for the external editing, prepared schemes are not available for each object type. If you want to export the data of such an object, it is therefore recommended to determine a scheme with corresponding settings.

Preconditions:

Exporting project data for external editing:

- You have selected the following commands: File > Settings > User > Interfaces > External editing.

Exporting parts data for external editing:

- You have opened the dialog Parts management (Tab Master data > Command group Parts > Management).
- In the dialog Parts management below the button [Extras] you have the selected the menu items Edit properties externally > Export data.
- You have clicked [...] next to the Settings field in the dialog Edit externally.

1. Select a scheme whose settings you want to edit in the dialog Settings: External editing from the drop-down list Scheme or click ![](../Pictures/Gui/ALL/all_new_as.png) (New) to select an object type for a new user-defined scheme in the subsequent dialog.
2. In the File type drop-down list, select the desired file type to be generated when exporting.
3. Click [Options] to specify the export settings for the selected file type and click [OK].
4. In the Target file field, specify the drive, directory and name of the target file to be created, or click ![](../Pictures/Gui/ALL/all_selectfile_as.png) to interactively select the drive and directory.
5. If you have selected an Excel file for the file type, enter the file path and name of a template file in the Template field or select the template via ![](../Pictures/Gui/ALL/all_selectfile_as.png). This template then determines the format of the data during the export.
6. Select the Data tab.
7. In the list Available format elements / Source object select the object which is to be considered during the export. Multiple selection is not possible.
8. Move the object by means of the button ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right) into the Selected format elements list. When selecting a source object in the parts management this results in opening the dialog Property selection which allows you to select the properties to be exported for the selected source object. Multiple selection is possible.
9. Proceed similarly for all additional format elements to be considered during the export.
10. Influence the sequence of the selected format elements / source objects by using the buttons of the toolbar.
11. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The applied settings are stored in the selected scheme.

# Manufacturing Data Export / Labeling: Procedure

The manufacturing data export / item labeling consists of the following steps:

- [Creating an export / labeling scheme](labelgui_h_beschriftungsschema.htm): If you do not use a pre-defined scheme, create a user-defined scheme.
- [Defining header, label and footer](labelgui_h_formatelemfestlegen.htm): You decide which properties are output and how the texts are formatted.
- [Specify settings for \*.txt output](labelgui_h_textausgabe.htm) or [Specify settings for Excel output](labelgui_h_exceldatei.htm): You decide whether the export / labeling is output into a \*.txt file or into an MS Excel file and specify the settings required.
- [Output manufacturing data / labeling](labelgui_h_beschriftungausgeben.htm): You define the range in which the labeling data will be output and in what order they will be displayed.

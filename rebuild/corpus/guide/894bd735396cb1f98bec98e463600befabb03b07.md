# P026113: Wire length is too short. The bending radius of the routing connection may be too large.

### Cause

Too small a wire length was determined for the routing connection between two control points. Possibly an excessively large bending radius was entered for the connection part in the parts management or the bending radius was specified without measuring unit.

### Solution

1. Locate the routing connection in the layout space using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Select the following commands: Tab Connections > Command group Connections > Navigator.
3. Right-click the routing connection in the layout space and select the Synchronize selection popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The routing connection is marked in the connections navigator.
4. Open the property dialog of the associated 2D connection.
5. Look up the part in question and close the dialog.
6. Select the following commands: Tab Master data > Command group Parts > Management.
7. In the dialog Parts management search for the determined part and bring the Properties tab to the foreground.
8. Correct the value of the Min. bending radius property in the properties table and carry out a parts data synchronization.
9. Route the connections again.
10. If required, start a new check run.

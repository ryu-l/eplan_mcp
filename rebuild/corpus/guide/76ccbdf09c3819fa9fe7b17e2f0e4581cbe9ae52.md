# Exchanging Symbol Libraries

The symbol libraries used in the project are entered into the project-specific settings and can be exchanged for other libraries.

Preconditions:

- You have opened the project whose symbol libraries are to be exchanged.
- The symbols and variants used in the project must exist in both libraries. The decisive factor here is the position of the symbols in the library, i.e. the symbol number.

1. Select the following commands: File > Settings > Projects > "Project name" > Management > Symbol libraries.
2. Click [...] in the field for the desired symbol library in the Settings: Symbol libraries dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Select symbol library dialog is opened. If the symbol library should not be removed, then a message is displayed.
3. Select the desired symbol library.
4. Click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The two symbol libraries are compared. If differences are found that prevent the libraries from being exchanged, then an appropriate message is displayed.
5. If the two symbol libraries are compatible, click [Yes] in the Exchange symbol libraries dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol library in the project is replaced with the new symbol library.

# Eplan Fluid: Default Fluid Connection Properties

Values can be pre-assigned to the connection properties at fluid connections. In the project settings these default values are possible for the trades "Hydraulics", "Pneumatics", "Cooling", "Lubrication", "Cooling lubricant" and "Gas engineering" (command path: File > Settings > Projects > "Project name" > Connections > Properties).

By default, the values these properties are assigned to all connections in the project. If you specify a connection definition point for a connection, the values of its properties overwrite the default for the connection.

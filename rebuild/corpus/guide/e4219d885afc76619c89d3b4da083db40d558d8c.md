# Automatic Generation of Views

It is possible to automatically generate pages with model views, 2D drilling views and copper unfolds in projects with mechanical components in layout spaces. The basis for these automatic reports are report templates with specifications for the pages to be created. These templates are created and reported in the dialog Model views â <Project name> on the Templates tab.

How the views are displayed is specified by means of macros that are created individually and assigned to the report templates. Filter settings in the templates are used to configure the basic items (enclosures, mounting panels, etc.) of which views are created in the layout spaces.

The automatic generation of pages with views on the basis of templates can be used for the standardized representation of views. Through this automated reporting the work required is reduced to a fraction of the time required for manual creation. For you this means a considerable reduction in time for the creation of documentation ready for manufacturing.

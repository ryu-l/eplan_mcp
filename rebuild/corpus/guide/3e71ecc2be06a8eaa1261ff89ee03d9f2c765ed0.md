# Your Own Connection Point Designations and Identifiers

In the project settings you have the possibility to define own connection point designations and identifiers for each function definition.

- Using your own identifier sets you can take different standards, countries, and customers into consideration.
- The identifier sets are stored project-specifically as schemes. The schemes for the identifier sets can be exported and imported. The exported file can be used, for instance, as a data backup or for the exchange of data.
- For each function definition, ten sets of connection designations and connection descriptions can be specified. These sets can then be selected later on from the function.
- The sets of connection point designations and connection point descriptions are stored in the project settings and are also exported and imported during the export and import of project settings.

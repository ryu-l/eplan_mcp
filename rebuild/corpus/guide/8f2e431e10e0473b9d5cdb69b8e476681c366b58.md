# P026036: Part placement lies in a routing range

### Cause

A part placement was placed on a mounting surface within a routing range.

### Solution

1. Locate the part placement in the layout space using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Move the part placement from the routing range, or remove it. Or modify the routing range on the mounting surface.
3. If required, start a new check run.

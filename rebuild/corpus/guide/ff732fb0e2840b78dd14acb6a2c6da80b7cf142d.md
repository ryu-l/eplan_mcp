# Cleaning up Outlines

The Clean up command removes all the unacceptable elements from the outline. These include ellipses, splines, and 3D elements. Blocks are automatically broken up.

Preconditions:

- You have opened a project.
- You have opened an outline that you want to edit in the outline editor (Tab Master data > Command group Outline / form > Drop-down button Outline (...) > Open > Button [Open]).

1. Select the following commands: Tab Edit > Command group Outline > Clean up.
2. Confirm the prompt in the Clean up dialog by clicking [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Elements reported as "unacceptable" are removed and the blocks are broken up.

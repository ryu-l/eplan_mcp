# Dialog Part selection: Select data source

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Tab Master data > Command group Part > Drop-down button Management > Settings. Select the Part selection with scheme selection check box and click [OK].

- You have selected a main function in the graphical editor or in a navigator. Popup menu item Properties. Select the Parts tab and click [...] in the Part number field.
- Tab Devices > Command group Devices > Navigator. Select an entry. Popup menu item New device.
- Tab Devices > Command group Devices > Bill of materials. Select an entry. Popup menu item Add part or Exchange part.
- Tab Devices > Command group Devices > Drop-down button Navigator > Device list. Select an entry. Popup menu item Add part.

In this dialog, select a scheme for the data source for the part selection. This is used to determine which data source is used for the part selection.

Overview of the main dialog elements:

Data source:

Select a scheme from the drop-down list which determines the user-specific default settings for part selection. Click [...] to open the [Settings: Parts (user)](partselectiongui_d_datenauswahlbenutzer.htm) dialog, in which you can change these default settings.

Always use this data source:

If this check box is selected, the selected data source will be used for all further actions which open the part selection. The Part Selection: Select data source dialog is no longer displayed. You can reactivate the Part selection: Select data source dialog by reactivating the setting Part selection with scheme selection (command path: Tab Master data > Command group Part > Drop-down button Management > Settings).

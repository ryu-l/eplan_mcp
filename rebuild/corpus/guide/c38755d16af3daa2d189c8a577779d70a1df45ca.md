# Inserting a Window Macro with P&I Diagram Data

If you want to reuse page sections that contain P&I diagram data several times, you store these in a window macro. In addition to the usual symbols from process engineering, such a window macro can also contain components that are linked with segments from the pre-planning (PCT loops, PCT loop functions, containers, planning objects, piping planning objects, etc.). When inserting the window macro on a P&I diagram page of a different project, the contained segments are taken into consideration and can be transferred into a current project.

Preconditions:

- You have opened a project.
- You have opened a page of the "P&I diagram" type.

1. Select the following commands: Insert center > Breadcrumb trail Home > Window macros / symbol macros.
2. Using the folder structure navigate to the desired window macro with the "P&I diagram" representation type.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the preview tile of a macro is marked, the representation type of the macro is displayed in the information area below the preview tiles in the Macro: Representation type property.
3. Click the tile of the required macro.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The macro is attached to the cursor and can be positioned wherever you want (single click).  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the window macro contains devices with structure identifiers that are not yet included in the project, they are inserted according to the user settings for identifiers (option Enter new identifiers in alphabetical order or Add new identifiers to the end) in the table of identifiers.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Select structure dialog is opened and allows for sorting all PCT loops / PCT loop functions / containers, etc. of the window macro into the existing structure.
4. Select a segment in the Source field.
5. In the Project field, select the segment below which the segment from the source is to be sorted in.
6. Move the segment using the arrow button or per Drag & Drop from the Source field into the Project field.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the window macro contains devices and if the With prompt option is selected in the settings for the online numbering (File > Settings > Projects > "Project name" > Device > Numbering (online)), the Insertion mode dialog is displayed.
8. To optionally number devices, select a numbering setting in the Insertion mode dialog.
9. Click [OK].

# P001008: A terminal connection point has too many targets: <x>. Maximum number of targets allowed: <y>

### Cause

You have connected at least one of the function connection points of the terminal with more components than specified.

### Solution

#### Possibility 1

1. Double-click the terminal in the schematic and select the Symbol / function data tab in the Properties <...> dialog.
2. In the Function data group box click [Logic].
3. Check which values are set for the function connection points of the terminal in the Number of targets line in the Connection point logic dialog.
4. Increase your requirements in accordance with the set values for the function connection points.

#### Possibility 2

1. Double-click the terminal in the schematic and select the Symbol / function data tab in the Properties <...> dialog.
2. In the Function data group box click [Logic].
3. Check which values are set for the function connection points of the terminal in the Number of targets line in the Connection point logic dialog.
4. Accordingly, delete the excess placed components at the respective function connection points of the terminal in the schematic.

Update the connections.

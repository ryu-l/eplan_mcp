# Dialog Field assignment (Pre-planning)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project, and have the pre-planning navigator open. Tab Pre-planning > Command group General > Import. In the Import pre-planning data - <Project name> dialog, select "Excel" or "Text" in the Type of data source field, and then click the [...] in the Field assignment field.

Use this dialog to create and edit the schemes that define the assignment of external data fields to the Eplan properties.

Rows without assigned property are ignored during importing. If properties are assigned to the external fields of a level, a property must be identified as identifying.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to edit from the drop-down list. You can only edit user-defined schemes.

You can create new schemes, save any changes to a scheme, and copy or delete schemes via the adjacent [Toolbar](schemeconfig_m_schemaschaltflaechen.htm). Schemes can also be imported or exported.

Description:

This field displays the descriptive text that you entered into the Description field in the New scheme dialog when you created the scheme.

---

Table

The following columns are displayed in the table:

Status:

A green icon ![](../Pictures/Gui/ALL/all_statusok_as.png) indicates that this data field exists in the data source and could be identified. A yellow icon ![](../Pictures/Gui/ALL/all_statusnotok_as.png) signals that the corresponding data fields do not exist. These rows are not considered during the import, and you can select and delete them as needed.

External field:

This column displays the data fields / properties of the selected table from an external data source.

Level:

Here you specify the hierarchy level in the tree view of the segment to be generated or updated. All rows with the same level belong to a segment.

Segment definition:

Here, you specify the type of segment to be generated from the record, e.g., a planning object or a structure segment.

Property:

This column displays the assigned Eplan property. To assign a property, click in the column and then [...], and select a property from the dialog that opens.

Identifying:

Select this check box if the property is an identifying one for the assignment. Based on the properties marked as identifying, objects are identified and synchronized during the import. At least one external field must be identifying for every object type!

Filter:

Here you define a filter for the property. If you only enter one value, it is filtered for equality. You could also enter "> 100".

Toolbar:

The following buttons are available on the toolbar above the table:

| Button | Meaning |
| --- | --- |
| (New) | Creates a new line in the table. The new line is appended to the end of the table. |
| (Delete) | Deletes the selected row, with all of the contents. Multiple selection is possible. |

![](../Pictures/Gui/ALL/info.png)Tip:

The identification of objects can also be carried out via the Object identification property instead of by means of properties such as Designation, Measurand, and Number. This identification via the object ID is suitable for updating existing segments.

In such a case the level here in the dialog does not refer to a hierarchy level in the tree view of the pre-planning navigator, but to the object identified respectively via the ID. The value in the Level column can therefore remain at "0". If subordinate objects are to be added to an existing segment or subordinate objects of a segment are to be edited, you have to specify the levels "1", "2", etc. for such objects in the field assignment. Subordinate objects are identified via the designation as in the past.

The respective object IDs can also be output during the export of pre-planning data via the output of manufacturing data for the labeling. To this purpose you then have to adapt the settings for the export scheme correspondingly.

# Activating Object Snap

Object snap makes it easier to construct graphical objects.

Precondition:

You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc.

1. Click the ![](../Pictures/Gui/ALL/statusbar_objectsnap_as.png) (Object snap on / off) button in the status bar to activate the object snap.  
     
   ![](../Pictures/Gui/ALL/arrow.png) When drawing graphical objects, these are automatically connected to the possible handles. These include, for example, the insertion points of logical objects and texts, as well as the element points, perpendicular and tangent points of graphical elements.
2. Click the ![](../Pictures/Gui/ALL/statusbar_objectsnap_as.png) (Object snap on / off) button to deactivate the object snap again.

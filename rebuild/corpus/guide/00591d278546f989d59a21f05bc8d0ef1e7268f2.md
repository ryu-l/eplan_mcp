# P020048: <x> (x Pos <y> : y Pos <z>) : <u>

### Description

You have run a project comparison, checking the Properties of the test project (incoming project) against those of the comparison project and differences were found.

This message displays when a difference concerning a text or path function text was detected by the project comparison. <x> designates the text type (text or path function text), <y> the X position and <z> the Y position of the text or path function text in the schematic output. <u> indicates whether text or path function text has been deleted or added, or if one of its properties has been changed.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

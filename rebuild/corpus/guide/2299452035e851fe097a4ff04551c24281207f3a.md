# P022063: The property '<x>' (value with unit '<z>') does not contain a unit: '<y>'

### Cause

The project contains an object (page, macro, function, etc.) with a property of the "Value with unit" field type for which a unit group is defined. However, no unit was specified for the property value of the object.

### Solution

1. Locate the object in the project by using the Go to (graphic) functionality from the popup menu in the dialog Message management.
2. Call up the property dialog of the object.
3. Enter a unit for the value of the affected property.
4. Click [OK].
5. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

This check run is not activated by default and can only be performed offline.

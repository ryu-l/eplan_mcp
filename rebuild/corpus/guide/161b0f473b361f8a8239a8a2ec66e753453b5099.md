# P005091: Connection and function have differing pipe classes

### Cause

The value for the Pipe class property entered at a connection in the P&I diagram does not agree with the value that is entered at the property having the same name of the function that is the source or target of this connection.

### Solution

1. Locate the function using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Use the Go to (2nd coordinate) option of the popup menu to jump to the connection definition point of the connection.
3. Determine the value entered in the Pipe class field in the respective property dialog.
4. Standardize the two values.
5. If required, start a new check run.

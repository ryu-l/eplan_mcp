# Tab Overview

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Master data > Command group Parts > Management. You have opened a parts database using [Extras] > Settings. You have marked a part in the tree or list. Select the Overview tab.

This tab shows the most important properties such as - if existing - a preview image of the part. An editing of properties is not possible here.

If the desired properties are not displayed here, you must select or create a scheme with fitting property configuration in the View field.

Overview of the main dialog elements:

View:

Select a scheme from the drop-down list for the display of the properties. Click [...] to open the dialog [Configure properties](modaldialogsdb_d_eigenschaftskonfiguration.htm). There you can use a scheme with several property configurations to specify which properties are to be displayed in the Overview tab and in which sequence.

![](../Pictures/Gui/ALL/note.png)Note:

The schemes created in this tab are not available to you in the Properties tab.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Preview:

All images and macros for one or more selected parts that are linked to these parts are displayed in the preview. For example, an image file for a part is stored in the Image file property and a 3D macro for the 3D mounting layout is stored in the Graphical macro property.

Without an opened project, only the image file of the part and the graphical macro (3D macro) are displayed in the preview. If a project is open, three tiles with images are displayed for a part with assigned macro (for example the image file, the multi-line schematic macro and the graphical macro).

If there are more than three images available for one or more selected parts, the images can be selected via a scroll bar. If available, the following sequence applies to the display of the images:

- Image file
- 2D schematic macro in all representation types and in all variants
- Graphical macro (3D macro)

If several parts are selected in the tree or list view, all representation types and variants per part are always displayed consecutively in the tiles. Images of the other parts are displayed without interruption directly behind it.

# P022015: The pages combined with ''Number of pages / Page name per property' are not consecutive. Property value: '<x>' Pages: '<y>'

### Cause

Non-consecutive pages were identified when calculating identical values for page properties Number of pages per property and Page names per property.

### Solution

1. In the Message management dialog, look at the list of page ranges in this message.
2. Open the page navigator and expand all the pages in the tree view.
3. In the tree view, select the entire range for all the non-consecutive pages reported.
4. Select the popup menu Number and number the pages with a start number and increment value of "1". (When using a page structure on the basis of "Function designation" and "Location designation", also add structure-oriented numbering.)
5. After numbering, select the command Number of pages / page name per property. (To this purpose you first have to [Customize the ribbon](userinterface_h_menuebandanpassen.htm) and then assign the desired command to a user-defined command group.)
6. If required, start a new check run.

# Editing Comments

You can edit comments imported or created in Eplan.

Preconditions:

- You have opened a project. This project contains comments.
- You have opened a project page in the graphical editor.
- You have opened the comments navigator.

1. Select a comment on the project page or in the comments navigator.
2. Select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Comment tab is displayed.
3. Change the comment text, add a reply, or assign a different status to the comment.
4. If required, switch to the Format tab to format a comment placed on the project page.
5. Click [OK].

![](../Pictures/Gui/ALL/info.png)Tip:

Comments with a closed graphic (rectangle, polyline) and also graphics with line segments can be drawn in the form of a cloud. To this purpose select the display property Line type in the property dialog of the comments on the Format tab below the hierarchy level "Format" and there set the cloud-shaped line type with the identifying number "56".

# P028035: The segment has no assigned function of the representation type 'Multi-line'

### Cause

With this check run you can determine whether placed functions exist in the detailed planning (in the P&I diagram or in the schematic) for segments (PCT loops or planning objects) created in the pre-planning navigator. In the concrete case there is no function of the "Multi-line" representation type in the detailed planning for the segment existing in the pre-planning.

### Solution

#### Possibility 1

1. Locate the corresponding segment in the pre-planning navigator using the Synchronize selection function offered by the popup menu in the Message management dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The respective segment is marked in the pre-planning navigator.
2. Place the segment on a page of the type "P&I diagram" or on a schematic page.

#### Possibility 2

Exclude the segments that do not have to be placed from the check. Define corresponding filters to this purpose.

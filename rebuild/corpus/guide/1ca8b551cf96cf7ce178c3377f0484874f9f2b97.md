# Dialog Settings: Driver for SQL server

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > Workstation > Interfaces > Driver for SQL Server

When SQL databases are used for the parts management, the project management and the dictionary, the Eplan platform requires a Microsoft ODBC driver for the connection to an SQL server. In this dialog you can select the desired driver if several versions of the ODBC driver are installed.

Overview of the main dialog elements:

Driver for SQL server:

If an ODBC driver is installed, it is displayed here. If several drivers are installed, you can select the desired driver for SQL server from the drop-down list.

![](../Pictures/Gui/ALL/note.png)Note:

A selection possibility in the drop-down list is only available if corresponding drivers are installed on your computer. For questions about possible drivers please contact your SQL system administrator.

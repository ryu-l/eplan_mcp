# Importing Device Data and Devices

Device data is imported from files with the file extension TXT, CSV, ASC and from MS Excel files (\*.XLSX, \*.XLSM) into an Eplan project that is open or is selected in the page navigator.

Preconditions:

- You have opened a project.
- Device data from an external program are available in the form of a text or an MS-Excel file.

1. Select the following commands: File > Import > Command group Project data > Project data > Command group Devices > Devices.
2. Select the file type ("Text" or "Excel") from which you want to import device data in the Type of data source field of the dialog Import device data.
3. Click [...] next to the Data source field.
4. In the dialog [Select data source](projectprocessinggui_d_datenquelleauswaehlen.htm) select the file from which importing is to be carried out and carry out the required settings.
5. Click [OK].
6. In the Import device data dialog, click [...] next to the Field assignment field.
7. Specify in the Property column of the dialog Field assignment which Eplan properties are to be assigned to the designations of the external data fields that are listed in the External data field name column.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The dialog Synchronize devices displays the device data from the data source and their assignment to devices in the Eplan project. In the process an analysis is carried out and the Status column then displays whether devices are not yet contained in the project, whether they already exist in the project or whether the devices in the data source and in the project have different editing states (for example other property values). Fields with changed property values have a dark-gray background.
9. Specify in the Action column in the dialog Synchronize devices what is to happen with the devices, depending on the displayed status:

| Status | | Action |
| --- | --- | --- |
|  | New | Import or None |
|  | Identical | None |
|  | Additional | Delete or None |
|  | Changed | Apply change or None |

10. You can set a trade-specific filter in the Filter field in order to reduce the scope of display in the dialog Synchronize devices to the desired devices.
11. In order to display the devices to be imported in accordance with their current status select a status from the drop-down box in the Filter (status) field.
12. In a marked row in the dialog Synchronize devices select the popup menu item Assign part to automatically assign an existing suitable part number from the parts database to the devices to be imported.
13. If no automatic assignment is possible, click the [...] button in the Part number column to open the part selections and select a part there manually.
14. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The import or the selected actions are carried out.

| Status | | Action | Result |
| --- | --- | --- | --- |
|  | New | Import | Devices are imported |
|  | Identical | None | Device remains in the project |
|  | Additional | Delete | Device is deleted from the project |
| None | Device remains in the project |
|  | Changed | Apply changes | Changed property values are applied |
| None | Changed property values are not applied |

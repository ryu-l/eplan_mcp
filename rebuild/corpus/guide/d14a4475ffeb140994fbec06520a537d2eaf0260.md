# Dialog Settings: AutomationML AR APC export

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Export > Command group Project data > Project data > Command group PLC > PLC data. You have selected an AutomationML AR APC export format from the Format of export file field and then clicked [Options].

In this dialog you specify the degree of detailing for an export file in the AutomationML AR APC format.

Overview of the main dialog elements:

Export port-specific interconnection:

This setting is only relevant for the following bus systems:

- [Ethernet-based bus systems](plcgui_k_spsanschluesse.htm#I_Netzwerkanschluesse)
- DRIVE-CLiQ
- IO-Link
- PortToPort
- ET-Connection
- Local-Bus: Extension

If this check box is activated, the interconnection of the bus ports is output in detail in the export file. In addition to the information about which PLC boxes are connected together, the information which bus port at the first box is connected with which bus port at the second box is output.

If the check box is deactivated, only the information which PLC boxes are connected together is output. The information which bus port is connected with which other one is not output. Connections between a rack and the associated extension racks are also not exported in this case.

Export accessories:

If this check box is activated, the accessory parts are output as well in the export file. All parts that are entered at the positions 2 to 50 on the Parts tab in the property dialog of a main function are considered to be accessories.

![](../Pictures/Gui/ALL/note.png)Note:

A PLC type designation must be entered for these parts in the parts management to allow export of the accessory parts.

If the check box is deactivated, accessory parts are ignored.

Exporting device-specific configuration values:

This setting is only available as of the export format "AutomationML AR APC V1.1.0." If this check box is activated, the [device-specific configuration values](plcgui_k_geraetebezkonfigwerte.htm) are output as well in the export file.

If the check box is deselected or grayed out, the device-specific configuration values are ignored during the PLC data exchange.

Export drives:

This setting is only available as of the format "AutomationML AR APC V1.2.0". If this check box is activated, drives and drive components are output as well in the export file.

If the check box is deselected or grayed out, drives and drive components are ignored during the PLC data exchange.

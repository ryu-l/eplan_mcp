# Creating and Deleting Pages

### Creating Pages

Precondition:

You have opened a project. You have opened the Pages - <Project name> navigator dialog.

1. Select the following commands: Tab Home > Command group Page > New.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The New page dialog is opened. If a page was selected in the Pages - <Project name> navigator dialog, its properties are loaded into the dialog. If a structure level was selected, the properties of the first page below this level are loaded. Only the grid defined in the plot frame is adopted.
2. Click [Clear fields] if you want to clear the data fields in the currently-selected page, i.e. to delete their content.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The content of the data fields is deleted. Only the page type of the currently selected page is retained. The automatically suggested page name is also retained. Scale and grid are taken from the plot frame and are also retained.
3. If necessary, manually change the suggested page name in the Full page name field, or use [...] to open the Full page name dialog and edit the structure identifier and the page name. You can use [...] to select the structure identifiers (such as function designation and location designation) from the existing ones. You can also manually enter the identifiers and create new ones in the process.
4. Assign an interactive page type to the page from the drop-down list in the Page type field, or use [...] to open the Add page type dialog and select an automatic page type.
5. Enter a descriptive text into the Page description field; this is also displayed in the page navigator tree and list views.
6. If necessary, enter further properties for the new page.
7. If you would like to create several pages, then click [Apply] several times.  
     
   ![](../Pictures/Gui/ALL/arrow.png) With every click on [Apply], Eplan generates a new page. Your user code is automatically entered into the Creator field.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you selected one of the settings Project by project or Per structure identifier for the path numbering (File > Settings > Projects > "Project name" > Management > Pages), a prompt is displayed, asking whether you want to automatically update the path designations.   
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan checks if the page name that you have entered already exists and, if so, an appropriate message is displayed, in which you can choose another name.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The (last) new page is then displayed in the graphical editor.

![](../Pictures/Gui/ALL/info.png)Tip:

You can create new pages in the Page navigator, by using the popup menu item New. Any page or structure level may be selected when you do this.

### Delete pages

1. Select the relevant pages in the Pages - <Project name> navigator dialog.
2. Select the Delete popup menu item.   
     
   ![](../Pictures/Gui/ALL/arrow.png) After a confirmation prompt Eplan deletes the selected pages from the project.

![](../Pictures/Gui/ALL/note.png)Note:

Positioned items are completely removed when the page is deleted.   
 Non-placed items are not removed, because they are not associated with the deleted pages.

![](../Pictures/Gui/ALL/info.png)Tip:

The page opened in the graphical editor can also be marked by using the shortcut key Ctrl + [M] and then deleted using [Del]. The page navigator does not need to be open for this.

### Deleting all pages in a project

1. Select the name of the project in which you wish to delete all the pages in the Pages - <Project name> navigator dialog.
2. Select the Delete popup menu item.   
     
   ![](../Pictures/Gui/ALL/arrow.png) After a confirmation prompt Eplan deletes all the pages from the project.

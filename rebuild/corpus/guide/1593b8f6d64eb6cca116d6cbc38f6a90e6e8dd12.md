# P002007: Several non-associated plug definitions exist

### Cause

You configure with plugs and manage female pins and male pins separately. Now the function definitions of two plug definitions corresponding with each other, that have the same DT, do not match. The formation of the pairs between male pin and female pin ends therefore does not exist.

### Solution

1. Check at the plug definition for the female pin and male pin ends whether the correct function definition is set.
2. To do this, call up the Properties <...> dialog and in the Plug definition tab look at the settings in the Function definition field. The function definition for the plug definition of the female pin end must be set to "Plug definition for female pins". The function definition for the plug definition of the male pin end must be set to "Plug definition for male pins".
3. Change the deviating settings in accordance with these specifications.
4. If required, start a new check run..

# P004118: Missing CPU name at a PLC card in the configuration project '<x>' with multiple CPUs

### Cause

Within a configuration project that contains multiple CPUs, a PLC card exists with a start address that cannot be assigned to any of the CPUs since no CPU name was assigned.

### Solution

1. Locate the PLC box of the PLC card in the schematic by using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Call up the property dialog of the PLC box and bring the Structure data tab to the front.
3. In the property table for the CPU: Name [1] property select the name of the CPU in the configuration project to which you want to assign the PLC card.
4. Click [OK].
5. If required, start a new check run.

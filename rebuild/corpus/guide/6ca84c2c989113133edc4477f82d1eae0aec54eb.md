# P021005: Placeholder objects of the same name with different variables

### Cause

The macro project contains macros with placeholder objects that have the same name but for which different variants were defined. This results in error messages when the project is opened in Eplan Engineering Configuration One (EEC One).

### Solution

1. Locate the placeholder objects by means of the functionality Go to (graphic) or Go to (2nd coordinate), which the popup menu of the Message management dialog offers you.
2. Rename the placeholder objects existing several times or use the same variables for the placeholder objects.
3. If required, start a new check run.

# Extensions for Automated Processing

For this version the following extensions have been realized for the automated processing of projects:   
- Archiving projects by means of automated processing   
- Automated processing extended with manufacturing data export in the "Komax - Zeta" format   
- New action "Update reports" for automated processing

### Archiving projects by means of automated processing

Previously you could only back up projects via automated processing. Archiving was not possible. If you start automated processing from the project management, you now also have the possibility to archive several projects. To this purpose the Back up data dialog has been extended with the "Archive" entry in the drop-down list Method. In the drop-down list, the same backup methods are now available as in the Back up projects dialog. This means that you can now also additionally select the entry "File off for external editing".

### Automated processing extended by several actions for the manufacturing data export

The automated processing has now been extended by several actions for the export of manufacturing data. To this purpose the following new actions are available in the Settings: Automated processing dialog when creating a scheme for automated processing:

- Komax - Zeta: Export manufacturing data
- Rittal - Perforex BC: Export manufacturing data
- Rittal - Perforex LC: Export manufacturing data

You can access this dialog, for example, via the following command path: Tab Tools > Command group Reports > Automated processing. Then click [...] next to the Scheme field in the dialog Run: Automated processing.

### New action "Update reports" for automated processing

In the past it was only possible under very specific conditions to update only the report pages and not to generate new reports during the execution of the action "Update / generate reports" during automated processing. For this reason the new action "Update reports" is now available in the dialog Settings: Automated processing. If this action and not the action "Update / generate reports" is available in the scheme for automated processing, only the existing report pages are updated.

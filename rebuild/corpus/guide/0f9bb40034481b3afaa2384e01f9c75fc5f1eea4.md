# Cross-references in the Graphical Pre-planning and in the P&I Diagram

Cross-references can be shown at the segments on the pre-planning pages, if corresponding "counterpieces" exist for the segments, which are placed in the detailed planning (P&I diagram, multi-line schematic) or the pre-planning pages as well.

At the first placement of a segment (for example, on a pre-planning page or a P&I diagram) additional cross-references to report pages can be displayed if such a pre-planning report exists for the segment. If the Auxiliary functions also refer to the device tag list setting is also activated, corresponding cross-references are also shown at the other placements of the segment.

The following is possible for example:

- Cross-reference between a segment placed on a pre-planning page (for example "Main placement" of a structure segment) and further placements on other pre-planning pages
- Cross-reference between a PCT loop placed on a pre-planning page and placements of the PCT loop on P&I diagrams
- Cross-reference between a planning object placed on a pre-planning page and a linked main function that is for example placed on multi-line schematic pages
- Cross-reference between a segment placed on a pre-planning page and the report of this segment on a report page
- Cross-reference between a PCT loop placed on a P&I diagram segment and the report of this PCT loop on a report page.

### Settings for cross-references

The page type "Pre-planning" in the dialog [Settings: Display](xessettingsgui_d_einstellungenprojektqvwanzeige.htm) in the Display device cross-references table has to be selected so that cross-references are shown on the pre-planning pages or on the segments on the pre-planning pages. The "P&I diagram" page type has to be selected in the table for the display of cross-references on P&I diagram pages or to the segments on these pages.

If additional cross-references for pre-planning reports are required on the pre-planning pages and / or P&I diagram pages, a corresponding entry (such as "Pre-planning: Planning object overview") must be selected in the same table for the Pre-planning and / or P&I diagram column.

If the cross-references to the segments on the pre-planning pages or P&I diagram pages are highlighted by a prefix, you have to specify this in the dialog [Settings: General](xessettingsgui_d_einstellungenprojektqvwallgemein.htm) in the table Page type / prefix.

### Jump function to the counterpiece

You can select the popup menu item Go to (counterpiece) to jump from one segment to the cross-referencing counterpiece in the graphical editor. In this case a jump from one segment on a pre-planning page to a linked main function in the detailed planning only takes place if there are no further placements for the segment on the pre-planning pages.

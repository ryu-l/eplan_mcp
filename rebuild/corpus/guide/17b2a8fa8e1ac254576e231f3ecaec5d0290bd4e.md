# P502005: The layer '<u>' assigned to the macro '<x>' ('<y>' / '<z>') is user-defined. The message applies to the part property '<w>'

### Cause

In the parts database to be checked a part was found where a macro with a user-defined layer is entered. In the placeholder '<x>' of the message, the path and name of the macro are output, in the placeholders '<y>' and '<z>' the representation type of the macro and the macro variant, in the placeholder '<u>' the name of the layer and in the placeholder '<w>' the part property to which you want to transfer the macro.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Properties tab to the front.
3. In the tree view of the property table open the hierarchy level Data or Mounting data - depending on whether a schematic macro or a graphical macro was named in the message.
4. Click [...] in the value field of the part property named in the check run message for the macro.
5. In the selection dialog that opens select a macro file that contains a macro with an assigned layer which is Eplan-specific.  
     
   Or alternatively to this, delete the entered schematic macro in the value field of the property.  
     
   Or create a new macro with an Eplan-specific layer, store it in the desired macro directory and select it again at the property.
6. Click [Apply].
7. If required, start a new check run.
8. Close the parts management and perform a parts data synchronization.

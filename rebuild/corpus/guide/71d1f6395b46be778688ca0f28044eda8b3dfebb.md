# Dialog Configure properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Project dialog call:](javascript:void(0);)

You have opened a project. You have opened a dialog in which you can assign properties to an object (such as a project, page, form, etc.) properties via a table. Select the Configure popup menu item.

In this dialog select the properties and their sequence, to be shown by default in the table with each object in the relevant function category.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Parts management dialog call:](javascript:void(0);)

You have opened parts management. You have opened a parts database using [Extras] > Settings. You have selected an accessory list, accessory placement, etc. in the tree. You have selected the Properties tab. Next to the drop-down list, click [...].

In this dialog you select the properties and their sequence that are to be displayed to you in the Properties tab of the parts management for the record types such as accessory list, drilling pattern, etc.

In the process the properties are saved as schemes so they can be used again at any time.

Overview of the main dialog elements:

![](../Pictures/Gui/ALL/note.png)Note:

The fields Scheme and Description are only available in the parts management during the configuration of the Properties tab for the record types such as accessory list, drilling pattern, etc.

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

List / configuration:

In this field, you can determine which properties are displayed. By using ![](../Pictures/Gui/ALL/all_new_as.png) (New) you can select further properties and insert them into the list. The arrow buttons can be used to change the order of the properties.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Select all | Selects all of the entries in the list. |

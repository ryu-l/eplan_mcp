# Dialog Settings: Bundle

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have created routing connections. Routing connections are highlighted in the connections navigator. Tab Edit > Command group Routing connections > Bundle. In the dialog Bundle routing connections click the [...] button in a line under Bundling scheme in the table.

In this dialog you define the detailed settings for the selected bundling scheme.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Filter:

Select a scheme for filtering the routing connections from the drop-down list. When the [...] button is clicked, the dialog Filter is displayed in which you can create new filtering schemes and edit existing filters.

Sorting:

Select a scheme with bundling criteria for sorting the routing connections from the drop-down list. When the [...] button is clicked, the dialog Sorting is displayed in which you can create new sorting schemes and edit existing schemes.

New bundle if property value has changed:

Select a scheme with bundling criteria whose change is to result in new bundles being created from the drop-down list. When the [...] button is clicked, the dialog New bundle if property value has changed is displayed in which you can create new schemes with bundling criteria and edit existing schemes.

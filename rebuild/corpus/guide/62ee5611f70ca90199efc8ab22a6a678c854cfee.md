# Notes for the Reader

Before using the help system, please note the following points:

![](../Pictures/Gui/ALL/warning.png)Warning:

Text preceded by this symbol contains a warning; you should be absolutely sure to read this warning before proceeding!

Examples are highlighted by this graphical symbol and can be expanded. Click the plus sign to expand and display the sample text.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The example text is shown here. Click the minus sign to collapse and hide the sample text.

![](../Pictures/Gui/ALL/note.png)Note:

After this image, extra comments to facilitate your interaction with the program are presented.

![](../Pictures/Gui/ALL/info.png)Tip:

After this graphic, you'll find useful tips and alternative commands.

- User interface elements are marked in blue so they can immediately be located in the text.
- Bold text provides particularly important information that you should definitely pay attention to.
- Code examples, directory names, and direct input (among others) are displayed in a non-proportional font.
- To make it easier for you to find particular program options, some help topics provide a pre-defined "Command path". Select the commands and options marked in blue in order to navigate from the ribbon menu to the desired option. With the following command path you, for example, call up the Eplan help system: File > Help > Command group Support > Contents > Help system.
- The operating information provides step-by-step instructions for reaching specific targets, and in many places, after the right-arrow symbol ![](../Pictures/Gui/ALL/arrow.png) you'll also find the reaction of the program to your action.
- Hyperlinks to related pages are located below the See also line. This allows you to (e.g.) use the following hyperlink to reach the "Using the help system" section, containing further information on how to use the online help system.

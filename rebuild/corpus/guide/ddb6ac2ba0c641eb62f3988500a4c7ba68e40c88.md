# Routing Connections Freely

The free routing of connections generates curved electrical engineering or Fluid power routing connections outside of a routing path network. Such connections are needed when the use of wire ducts is impossible or not customary:

- For routing wires with large cross-sections
- When routing, e.g., Ethernet cables
- For the definition of routing tracks in complex housing situations
- For the flexible direct connection of electrical devices, e.g., devices mounted on a swivelable door
- For the connection of Fluid power devices to hose lines outside of a routing path network.

Freely routed connections are often mounted or bundled with routing accessories (cable / tubing clamp, cable / tubing tie, cable / tubing protection).

A freely routed connection is generated along a defined spatial curve between the source and target devices. No routing path network is expected or needed. Following the exit from the connection point, the connection is first aligned at the curve run tangentially to the connection point direction, and runs again tangentially at the target in the direction of the target connection point.

The curve run of a freely routed connection can be modified subsequently. As such, the position of control points can be changed, or new control points can be inserted. After modifying the curve run, the connection is re-routed.

Precondition:

You have opened a project. A layout space is open that contains connections to be routed freely.

![](../Pictures/Gui/ALL/note.png)Note:

You can select the connections to be routed freely before or after the function call. The possibilities for the selection of connections to be routed freely are the same as those for routing in a routing path network.

You can specifically route multi-line connections outside the routing path network by using the Free routing (layout space) popup menu item in the connections navigator or by using the Free routing popup menu item in the [wiring manager](routinggui_d_verdrahtungsmanager.htm).

1. Select the following commands: Tab Edit > Command group Routing connections > Drop-down button Route > Free routing. Or you select the Free routing (layout space) popup menu item in the connections navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the status bar, you are prompted to select the connections to be routed.
2. Enter the two corner points of a rectangle that comprises the part placements and connections to be routed.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The curve for the form of the routing connection is calculated.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The routing connections are generated and assigned the specific properties.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The routing connections are displayed in 3D representation.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Freely routed spatial routing connections outside of the routing path network

3. To change the route for freely routed connections, select the following commands: Tab Edit > Command group Routing connections > Change curve run and New control point.

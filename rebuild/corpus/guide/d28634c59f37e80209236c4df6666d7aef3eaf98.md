# P001022: Saddle jumpers are on top of each other

### Cause

You have defined more than one saddle jumper for a terminal strip in the schematic that consists of simple terminals. The saddle jumper formation can, however, not be realized because of the selected sequence of terminals since the saddle jumpers would - on the basis of the wiring-specific information - lie on top of each other.

### Solution

#### Possibility 1

1. Select the terminal strip definition in the terminal strip navigator or in the schematic. Select the following commands: Tab Devices > Command group Terminals > Terminal strip.
2. In the Edit terminal strip dialog, examine the graphical view of the connections in the Saddle jumpers column. Parallel connections are displayed.
3. Change the sequence of the terminals in the toolbar by means of the arrow buttons. Ensure that the saddle jumper graphics are not arranged in parallel but in succession.
4. Accept the changed terminal strip sequence in the Edit terminal strip dialog by clicking [OK].

#### Possibility 2

1. Repeat steps 1 and 2 as described under "Possibility 1".
2. In the Edit terminal strip dialog select the terminals that contributed to the generation of one of the saddle jumpers that are on top of each other.
3. Click the ![](../Pictures/Gui/ALL/terminalgui_deletesaddlejumpext_as.png) button in the toolbar of the dialog to delete this saddle jumper.
4. Accept the change and close the dialog Properties <...> with [OK].

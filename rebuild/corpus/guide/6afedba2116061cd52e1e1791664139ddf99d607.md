# Dialog Extend parts data

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a parts database. Tab Master data > Command group Parts > Drop-down button Management > Settings. In the dialog Settings: Parts (user), click [...] in the Extend parts data using field.
- You have opened a project. You have selected a main function in the graphical editor or in a navigator. Popup menu item Properties. Select the Parts tab and click [...] next to the Data source field. In the dialog Settings: Parts (user), click [...] in the Extend parts data using field.

In this dialog you determine which Eplan-specific technical parts data is to be extended by commercial data from linked systems such as PMS.

Overview of the main dialog elements:

Extend parts data using:

If the Eplan-specific technical parts data is to be extended by commercial data from linked systems such as PMS you can use this table to do so. When you select a scheme for part selection, you can not only determine a data source (Scheme field in the dialog Settings: Parts (user)), but you can also select other data sources that must also be defined as schemes. The assignment is made in this field:

First click ![](../Pictures/Gui/ALL/all_new_as.png) (New) to generate a line in the list of assignments. This button is only active if you have defined at least one scheme for the part selection in the user-specific settings. Then select the scheme which is to be evaluated for extending the data from the Scheme name drop-down list and activate the check box in the Generate part if not found column. In addition to part number and variant, each of which receives the value New\_<sequential\_number> when a new record is created, the Function group property (in the Data hierarchy level of the Properties tab) receives the value "New", making it easy to find parts generated via the part selection process.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You have selected the "Default" setting in the Scheme field of the Settings: Parts (user) dialog, and the settings you made in this scheme are included in the part selection. In the Scheme name drop-down list of the Extend parts data using field you have selected the two schemes "CustomerA\_SQL" and "CustomerA\_API". If you have selected the check boxes under Generate part if not found, the corresponding parts will be generated in parts management.

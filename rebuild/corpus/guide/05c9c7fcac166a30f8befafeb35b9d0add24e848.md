# Editing Text Properties

Precondition:

You have opened an editor such as the graphical editor, the plot frame editor, etc.

1. Double-click a text.
2. In the Properties (text) dialog, edit the text and its properties. Use the [Text](gededitgui_r_text.htm)and [Format](gededitgui_r_format.htm) tabs, as described under "Inserting texts".
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The changes are adopted and are immediately visible on the page.

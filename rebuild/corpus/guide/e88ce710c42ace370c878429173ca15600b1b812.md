# Dialog Create project

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > New.
- You have selected a project management database. You have loaded directories and projects. File > Project management > Button [Organize] > New.

In this dialog you create a new project using a basic project.

Overview of the main dialog elements:

Project name:

Enter the project name without file extension in this field. The project name can contain special characters and umlauts.

Storage location:

This field contains the directory where the new project is to be saved. Use ![](../Pictures/Gui/ALL/all_selectdirectory_as.png) to open the directory selection dialog. In this dialog you can choose another directory as the storage location for the project. Any desired directory on any logical drive is a valid location.

Basic project:

The template for the new project is displayed here. Click ![](../Pictures/Gui/ALL/all_selectfile_as.png) in order to open the Select basic project dialog. In this dialog you can select a basic project \*.zw9 or a backed up Eplan project \*.zw1 from any desired directory.

Specify creation date:

If this check box is selected, then you can specify a different creation date for the new project in the field below. The current date will be displayed here to begin with. You can change this date if necessary.

If the check box is not selected, the creation date of the selected template is used.

Specify creator:

If this check box is selected, your sign-in name or user code will automatically be entered in the field below, depending on the settings under User > Display > User code / address. If you do not wish to use your sign-in name or user code, you can enter a different name.

If the check box is not selected, the name of the person who created the template is displayed. If this field is blank, no creator was specified for the template.

![](../Pictures/Gui/ALL/info.png)Tip:

You can use the functionalities described above - the Specify creation date and Specify creator check boxes - to enter and, if necessary, change the current creator and current creation date for new projects.

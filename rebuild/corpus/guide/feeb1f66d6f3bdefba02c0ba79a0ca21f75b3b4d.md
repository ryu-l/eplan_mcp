# PCT Loops / PCT Loop Functions in P&I Diagrams

PCT loops and PCT loop functions are represented using P&I symbols in the P&I diagram. These P&I symbols are located in the Special.slk symbol library.

### PCT Types

There are different PCT types for PCT loops and PCT loop functions. Different P&I symbols must be used, depending on the PCT type.

The following table shows a selection of possible PCT types and the relationships between location and P&I symbol.

| Activation site / Implementation |  | On-site | Measuring station | Control room | Measuring station (not visible) | Control room (not visible) |

| PCS | 2 |  |  |  |  |  |

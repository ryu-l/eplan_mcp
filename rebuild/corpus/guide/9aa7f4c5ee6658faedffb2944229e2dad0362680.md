# P026109: The item for the mechanical feedthrough was not found in the layout space

### Cause

You have inserted an item with a mechanical feedthrough in the schematic, e.g. an insert or bar-type current transformer, and then routed connections in the layout space. However, the item through which the connection runs as a mechanical feedthrough in the schematic could not be determined in the layout space. Possibly the item was not inserted, or it was deleted before the routing.

### Solution

1. Locate the item with mechanical feedthrough in the schematic using the Go to (graphic) function from the popup menu in the dialog Message management.
2. Call up the property dialog of the item.
3. Bring the Part tab to the foreground and note the part number.
4. Use the Insert center to place the item as a device in the layout space and assign the same device tag to it as in the schematic. In the process ensure that the connection points of the mechanical feedthrough of the device find access to the routing path network.
5. Then route the connections again.

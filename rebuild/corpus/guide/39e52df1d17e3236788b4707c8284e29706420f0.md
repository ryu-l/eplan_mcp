# Dialog Settings: Directories

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > User > Management > Directories
- Tab Master data > Command group Synchronization > Synchronize system master data. Click [...] in the Directories field.
- Tab Master data > Command group Synchronization > Synchronize project. Click [...] in the Directories field.

The default settings for the directories used for master data selection and editing, and the paths to the required databases and files are defined or revised in this dialog. This information is used by certain program elements and functions when particular data is required. The settings are user dependent in order for you to manage and organize your own pool of master data.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Specify the drive and directory in which Eplan is to manage your projects, templates, symbols, etc. in the input fields Projects, Templates, Symbols, etc. Click [...] to interactively select the desired storage location in the subsequent dialog. The default setting after installing Eplan is <Drive\_EPLAN>:\<Program directory>\Projects\<Company code>.

![](../Pictures/Gui/ALL/note.png)Notes:

- For all input fields where you can define a directory, the following applies:   
  You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.  
  Please note that less path variables are offered at this point because, after all, you define the values of the path variables MD\_PROJECTS, MD\_MACROS, etc. in the Settings: Directories dialog!
- You can return to the directories set by default here in all the dialogs where you select this type of data (for example in the dialog Open project). To do so, click the Eplan icon and the directory listed below it in the left-hand navigation area.

# P021004: Placeholder object contains invalid variable assignment

### Cause

The program checks whether the variable assignment fits in the Variable column of the assignment table of the selected object's relevant property. In this case the variable assignment and the object property are not correctly assigned. For example, you may have a property which can only accept yes or no states, and a variable containing text as the value set assigned to it.

### Solution

1. Assign a variable with a suitable value to the affected object property.
2. If required, start a new check run.

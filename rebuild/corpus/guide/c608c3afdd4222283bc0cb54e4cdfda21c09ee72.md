# Block Editing

When editing a project with Eplan it is often necessary to change the properties of multiple objects in a single step. For instance, you copy an existing project and adapt it to new requirements by changing the device tags. You want to rename a certain number of pages, renumber them, or reconcile texts with different content. There is significant risk here of missing some objects and thus leaving them unchanged.

Eplan makes it possible to change the properties of multiple objects simultaneously. This kind of editing is called block editing.

- You can edit the properties of multiple open projects in a single step.
- The properties of selected pages of the currently opened project can be changed at one time.
- Block editing also enables the quick adaptation of properties of components on the currently open schematic page.
- Many of the so-called navigators can be used to change the properties of functions or even project data for the entire project.

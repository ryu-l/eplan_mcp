# Eplan Fluid: Trades

In Eplan Fluid, it is possible to generate reports, and filter and sort them by trades. Eplan Fluid differentiates between the following trades:

- Electrical engineering
- Hydraulics
- Pneumatics
- Cooling
- Lubrication
- Cooling lubricant
- Gas technology
- Fluid power (undefined).

For example, separate connection lists and / or bills of materials can be output for hydraulic and pneumatic components by specifying the trade.

You specify the trade either when creating a new function in the navigator or when placing a function in the schematic. You specify the setting in the Properties <...> dialog of the respective function. The Properties table in the <Function category> tab can be extended to include the Trade drop-down list for this purpose.

Eplan Fluid automatically uses the last trade setting selected as the default for a newly created or newly placed function.

If you assign a new definition that you select from the general functions area to a placed function, the page type determines the default trade for the function. On a "fluid power schematic"-type page, the fluid power-specific trades are then automatically selectable, while on a "schematic multi-line"-type page, the "Electrical engineering" trade is the default.

![](../Pictures/Gui/ALL/note.png)Note:

In the fluid schematic, if you place symbols from the fluid power symbol libraries for electromagnetic actuation of valves (solenoids), then the function definition is used to automatically set the trade to "electrical engineering".

The trade can also be configured for project parts and mounting panels.

Conversely, connection definition points of the trade can't be configured. This property is automatically copied from the connected functions, i.e. the targets of the connection.

### Subtrades

In addition to trade settings, "subtrades" can be defined for functions in Eplan Fluid. For instance, you can assign the "Water cooling" and "Oil cooling" subtrades to functions of the "Cooling" trade. The definition of subtrades allows you to use very detailed sorting and filter criteria for reports.

Subtrades are also specified in the Properties <...> dialog. The Properties table in the <Function category> tab can be extended to include the Subtrade drop-down list for this purpose. You can choose any designations for the subtrade.

### Insert devices with undefined Fluid power trade

In parts management it is possible to assign more than one trade to a part. If you insert a part with such a multiple assignment as a device into the schematic (for example, via the [Insert center](insertergui_k_start.htm)), the Select trade dialog is opened. This dialog offers all fluid power trades assigned to the part as well as the additional "Fluid power (undefined)" trade for selection. You must select one of these trades. This trade will then be assigned to the functions of the device.

In the device navigator, e.g., you have the possibility to filter by the "Fluid power (undefined)" trade and then apply a special trade to the corresponding functions.

In tabular editing (command path: Tab Home > Command group Edit > In table) you have the additional possibility to assign a specific trade to the functions of devices to which the "Fluid power (undefined)" trade has been assigned in a single step.

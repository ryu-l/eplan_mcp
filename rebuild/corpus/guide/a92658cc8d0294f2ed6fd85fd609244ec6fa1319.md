# Tab Symbol data

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have selected an object which does not contain function data (such as, e.g., an interruption point or a structure box) in the graphical editor or in a navigator.
- You have selected a placeholder object in the graphical editor or in a navigator.
- You have selected a segment placed on a pre-planning page or selected such a segment in the pre-planning navigator.

Popup menu item Properties. Select the Symbol data tab in the Properties <... > dialog.

Use this tab to edit the graphical properties of the component. Here you can assign the component a different symbol variant or a different symbol.

Overview of the main dialog elements:

Number / name:

This field displays the name of the current symbol; click [...] to open the [Symbol selection](xsbgui_d_symbolauswahl.htm) dialog and to select, if necessary, another symbol.

If available, a preview of the symbol is shown in the adjacent field.

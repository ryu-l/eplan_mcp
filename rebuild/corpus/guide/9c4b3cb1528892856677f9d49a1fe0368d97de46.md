# Dialog Output: Removal list

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Export > Command group Manufacturing data > Wire fabrication > Removal list

Use this dialog to specify the settings for the output of the removal list.

The removal list is a list of all fabricated connections that have been deleted in the course of project editing, however. Accordingly, these connections were once part of the project, but were then exported and subsequently removed again from the project. A tab-delimited list is generated.

Precondition:

The connections must have been exported.

Overview of the main dialog elements:

Target file:

Input box for the name of the file to be generated with the removal list. With the button ![](../Pictures/Gui/ALL/all_selectfile_as.png) you open the Open dialog where you select an existing file of the Tab-delimited Unicode file (\*.txt) file type or enter a new name.

Only deleted connections:

It is also possible that connections, following export to a machine, may not have been deleted, but may have been changed in terms of length. If this check box is activated, only actually deleted connections will be output in the removal list. Connections whose length was changed will be suppressed.

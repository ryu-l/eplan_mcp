# P027007: More than one topology function available in the device <x>

### Cause

In the routing path network, the <x> device has been assigned more than one topology function with the same device tag. But each topology function may exist in the routing path network only once with the "Topology" representation type.

![](../Pictures/Gui/ALL/note.png)Notes:

1. The message is also output if several routing points or routing paths have been placed with the same device tag.
2. Terminal strip definitions are an exception. They may occur several times, and are not checked in case of multiple placement!

### Solution

1. Locate the topology functions occurring several times of the device in your routing path network by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Rename the multiple topology functions of the device, or delete them, so that only one topology function with a unique device tag remains.
3. If required, start a new check run.

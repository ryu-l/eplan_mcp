# P004056: Part not found: PLC type designation '<x>' or device description file '<y>' / Index '<z>'! Import of '<u>' may be faulty

### Cause

When importing PLC configuration files main functions arise at which a part is entered, in as far as a suitable part exists in the parts management. In this specific case, a suitable part cannot be determined in the parts management.

A part is then suitable if the PLC type designation property (it is checked first) in the configuration file matches the property of the same name at the part. If no PLC type designation is specified, the Device description: File name property in the configuration file is compared to the property of the same name at the part. If a device description file is specified, the Device description: Index in file property is also compared for the AutomationML AR APC formats. The values of these properties are output in the placeholders '<x>' to '<z>' of the message in as far as these are entered in the configuration file. The displayed DT of the PLC box is output in the placeholder '<u>'.

### Solution

1. Create a corresponding part in the parts management. Ensure that either the Device description: File name property and the Device description: Index in file property or the PLC type designation property is filled with the value as it is entered in the configuration file to be imported at this part.
2. Import PLC data again.

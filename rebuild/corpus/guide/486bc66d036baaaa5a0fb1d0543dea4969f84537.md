# Action: CleanWorkspaceAction

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| Workspacename | Name of the workspace to be deleted (a string). If no name of a workspace is specified, the workspace last used is deleted. |
| Silent | Set or reset quiet mode (Boolean expression). In the "quiet" mode, all dialogs (e.g. error dialogs) are suppressed. |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
CleanWorkspaceAction 
/Workspacename:"?"
```

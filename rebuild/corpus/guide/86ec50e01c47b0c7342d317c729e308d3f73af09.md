# Tab Info

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Master data > Command group Parts > Management. You have opened a parts database using [Extras] > Settings. You have marked a main node (part, accessory list, etc.) in the tree.

In this tab information such as the name and version of the currently used parts database, the number of contained parts, the number of parts variants, the number of accessory lists, drilling patterns, etc. is displayed. With multiple properties such as the property Name of the configured tree node [1-n] statistical information is provided here on the respective main node (name, type, number).

The content of the tab is automatically updated during opening. However, it can be updated at any time manually by using [F5].

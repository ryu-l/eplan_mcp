# Tab Master data (Changing Standards)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. In the case of several opened projects: You have selected a project in the page navigator. Tab Tools > Command group Standards > Exchange. You have specified all of the settings in the Project tab. Button [Next]. You have specified all of the settings in the Rotation / flipping tab. Button [Next].

This tab lists all master data that is used in the project and that can be exchanged. Forms, plot frames, function definition libraries, and symbol libraries belong here.

Overview of the main dialog elements:

Project master data:

One row shows the assignment of master data from the source library to the master data of the target library.

- Name: This column lists all the master data used in the project. The name of the master data is displayed.
- Type: This column contains a description of the master data type. Master data types that can be exchanged in this dialog include symbol libraries, function definition libraries, forms, and plot frames.
- Modification date: This column displays the date of the last changes to the master data of the source project.
- New name: You can exchange master data by using this column. Click in a field and then click [...] to select the master data for the target project. If the fields are empty, the master data from the source project is copied to the target project.
- Individual assignment: This check box is only available for symbol libraries. If it is selected, symbols from the source and target symbol libraries can be individually assigned to one another. If the check box is deselected, the entire symbol library is assigned.

# Creating Projects

Projects can be created via the Backstage view or the project management. In both methods the project is created based on a basic project. The following section describes how you create a project via the Backstage view. If you have not yet created any basic projects, you can use the Eplan [Sample templates](projects_k_basisprojekteerweitert.htm#Beispielvorlagen).

Precondition:

You have access to [Basic projects](projects_k_basisprojekteerweitert.htm).

1. Select the following commands: File > New.
2. Specify a project name without a file suffix in the Project name field of the dialog Create project.
3. Click ![](../Pictures/Gui/ALL/all_selectdirectory_as.png) in the Storage location field and specify the directory where the project is to be stored in the subsequent dialog.
4. Click ![](../Pictures/Gui/ALL/all_selectfile_as.png) in the Basic project field and switch to the directory where the template is located in the Select basic project dialog.
5. Select the desired basic project and click [Open].
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new project \*.elk is created in the target directory.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you are working with project management, the new project is automatically loaded in the project management module.

![](../Pictures/Gui/ALL/info.png)Tip:

In the project properties, you can display the basic project from which a project comes:   
Mark your project in the page navigator and select the popup menu Properties. Add the project property Project: Template in the Backstage view Information in the tab Properties. The property displays the template (basic project, or, for a copied project, the source project) from which the project was created. To differentiate, the file extension is displayed in addition to the file name.

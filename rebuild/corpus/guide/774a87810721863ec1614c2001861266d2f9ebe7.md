# Inserting Linear / Aligned Dimensions

A linear dimension can only be drawn horizontally or vertically. An aligned dimension, on the other hand, can be drawn at every angle. The dimension line will thus run parallel to the dimension starting and end point.

![](../Pictures/Visualisation/ALL/gededitgui_dimfree_av.png)

Preconditions:

- You have opened a project.
- You have opened a project page in the graphical editor.

1. Select the following commands: Tab Insert > Command group Dimensioning > Linear dimension or Drop-down list Linear dimension > Aligned dimension.
2. Specify the starting dimensioning point by clicking it with the left mouse button.
3. Specify the end dimensioning point.

![](../Pictures/Gui/ALL/note.png)Tip:

When you keep the [Ctrl] key pressed while entering the two measuring points, the center between the two points will be determined. The dimension starting point is then set to this calculated center. You then enter the dimension end point without pressing the [Ctrl] key. This mode of input is possible for inserting dimensioning in model views.

1. Define the offset of the dimensions to the object being dimensioned. To do this, move the mouse in the vertical direction until the desired spacing is reached and click with the left mouse button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The dimension help lines are drawn with the corresponding height.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The dimension value is centered on the dimension line by default.
2. End the action via the Cancel action popup menu item or via the [Esc] button.

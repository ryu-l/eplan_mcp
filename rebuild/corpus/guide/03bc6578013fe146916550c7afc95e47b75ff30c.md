# Starting and Exiting Eplan

After installation, you can start Eplan via the Windows Start menu.

Preconditions:

- You have the required Eplan license.
- You have an Eplan ID and are a member of a company organization (this is a company-specific, protected cloud workspace).

1. Click the Windows [Start] button and select All Programs.
2. Open the Eplan program group and click the icon for your Eplan version.
3. In the sign-in dialog, enter your e-mail address and the password you specified when creating the Eplan ID.
4. Click [Sign in].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Eplan main window is started. If you have used an earlier version of Eplan, the Import settings dialog opens.
5. Select the check boxes for the settings areas that you want to import and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The settings for the areas selected are imported into the current version and relevant settings databases are generated. The settings for the areas Property configuration, Dialog memory and Tree and list configurations are also applied.

![](../Pictures/Gui/ALL/note.png)Notes:

- You can set up Eplan such that after the program is started the most recently opened project, or the most recently opened page, appears. The settings for this can be changed in the user settings: File > Settings > User > Display > User interface.
- If you use Eplan Rights management you may (depending on the operating mode) have to sign in via a sign-in dialog before you can work in Eplan.

### Exit Eplan

You can exit Eplan at any time. All of the data and settings, including those relating to the user interface (i.e. opened dialogs, hidden tabs in the ribbon, etc.), are saved and used again when the program is restarted.

1. Select the following commands: File > Exit. Or you use the shortcut key [Alt] + [F4].

### Check for a new Eplan version

If a check is to be carried out whether a more recent version of the software is available when Eplan is started, you can specify this in the settings:

1. Select the following commands: File > Settings > Company > Management > Check Eplan version.
2. Activate the check box Check for a new Eplan version.  
     
   ![](../Pictures/Gui/ALL/arrow.png) During the next start of Eplan a system message is displayed and the ![](../Pictures/Gui/ALL/modaldialogsgui_update_available.png) icon is displayed in the status bar. A click on this icon then opens the Eplan Download Manager and you can install the most recent version of Eplan.

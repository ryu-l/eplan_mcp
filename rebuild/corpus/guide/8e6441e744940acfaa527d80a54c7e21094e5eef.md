# Dialog Sort interruption points

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have opened a project page in the graphical editor. You have marked at least one interruption point (and with that one interruption point name). Tab Connections > Command group Interruption points > Drop-down button Navigator > Sort interruption points.
- You are located in the navigator dialog Interruption points - <Project name> (Tab Connections > Command group Interruption points > Navigator) and have marked at least one interruption point (and thus an interruption point name). Select the Sort interruption points popup menu item.

In this dialog you can sort the interruption points.

Overview of the main dialog elements:

Position:

This column shows the position of the interruption point in the schematic.

Type:

This column shows the type of the interruption point (source or target).

Connection:

This column shows the connection of the interruption point in graphical form.

Sort code:

The sort code defines the sequence in which the interruption points are sorted. It is automatically allocated by Eplan and defined by the sequence of the interruption points in the Interruption points dialog. The default sort code is 100. This means that the sorting is carried out only by page, row and column and the rising numerical value of the sort code. A "0" in this field defines the interruption point as a source. With identical sort codes, the interruption points are sorted in the order in which they appear in the schematic.

Toolbar:

You can use the arrow buttons in the toolbar to change the sequence of the interruption points. This influences the sequence of formation of the pairs in chain interruption points.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Sort graphically | Sets all sort codes to 100. |
| Properties | Opens the Properties <...>: Interruption point dialog, in which the existing or new properties of the selected interruption points can be edited. |
| Properties (global) | Opens the Properties (global): <...> dialog. Allows the editing of the device properties. |

![](../Pictures/Gui/ALL/note.png)Note:

As soon as you change the current sorting options in the Sort interruption points dialog, the Connection and Sort code columns show the situation to be created by clicking [OK].

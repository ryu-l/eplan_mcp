# P005087: Direct connection: Different connection dimension '<x>' / '<y>'

### Cause

The connection dimension of the functions connected to a direct connection does not agree. Placeholder <x> outputs the connection dimension of the connected function that is the source of the direct connection. Placeholder <y> outputs the connection dimension of the connection function that is the target of the direct connection. The connection dimension of both functions are compared directly with each other in this check.

### Solution

1. Locate the functions connected to the direct connection in the schematic by using the functionalities Go to (graphic) and Go to (2nd coordinate), which the popup menu of the Message management dialog offers you.
2. Open the property dialog of both functions one after the other.
3. Unitize the values of the Connection dimension (all) property at both functions. Ensure that the upper-case / lower-case spelling is the same.
4. If you have transferred the connection dimensions via a part selection to the function, select corresponding parts with suitable values.
5. If required, start a new check run.

# P005060: Connection point has a multi-line connection in both single-line and multi-line display

### Cause

The connection point of a device that has been interconnected on the Interconnect devices tab of the property dialog of a single-line connection definition point already has a multi-line connection.

### Solution

1. Delete one of the connections.
2. If required, start a new check run.

# P028023: PCT loop or PCT loop function is not placed in representation type 'P&I diagram'

### Cause

A PCT loop or PCT loop function created in the pre-planning navigator has not yet been placed in the "P&I diagram" representation type.

### Solution

1. Open the page of the "P&I diagram" type on which the PCT loop or the PCT loop function is to be placed.
2. Open the pre-planning navigator (command path: Tab Pre-planning > Command group General > Navigator).
3. Mark the message in the Message management dialog and select the popup menu item Synchronize selection.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The respective PCT loop or PCT loop function is marked in the pre-planning navigator.
4. Select the Place popup menu item in the pre-planning navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A symbol for a P&I diagram is shown at the cursor.
5. Click the left mouse button.
6. Use the cursor to determine the size of the symbol that represents the PCT loop or the PCT loop function.
7. Click the left mouse button again.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The PCT loop or the PCT loop function is placed on the page.
8. If required, start a new check run.

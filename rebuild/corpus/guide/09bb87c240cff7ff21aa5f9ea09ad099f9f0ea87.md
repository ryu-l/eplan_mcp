# Dialog Settings: Project master data (Changing Standards)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > User > Change of standard > Project master data.

This dialog lists all previous cross-project and user-defined assignments of source project master data to target project master data. You can delete any assignments that are no longer necessary. If you use an assignment for the change of standard, the source project master data is replaced by the target project master data.

Overview of the main dialog elements:

Toolbar:

| Button | Meaning |
| --- | --- |
| (Delete) | Deletes a selected row. The deleted assignment is then no longer available in any project. |

Project master data:

A row contains an assignment of source project master data to target project master data. Forms, plot frames, function definition libraries, and symbol libraries are included in the master data that you can assign here.

- Name: Displays the file names of the source project master data.
- Type: Shows the master data type. Plot frames, form / report type names, symbol and function definition libraries are all allowed.
- Modification date: This column displays the date of the last changes to the master data of the source project.
- New name: Displays the file names of the target project master data.
- Individual assignment: This column is only available for symbol libraries. If the check box is selected, the individual symbols can be assigned to one another. If the check box is deselected, the entire source symbol library is assigned to the target symbol library.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

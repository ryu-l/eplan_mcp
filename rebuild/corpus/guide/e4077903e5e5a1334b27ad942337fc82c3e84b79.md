# Tab Fittings

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > User > Add-ons > Hose line configurator. Click the Fittings tab.
- You have opened a project. You have opened the [Configure hose lines](fluidhoseconfiggui_d_schlauchleitungen.htm) dialog. Select the Extras > Settings menu items. In the subsequent dialog click the Fittings tab.

You manage the data of the fittings for hose lines in this tab. The entered values are offered during the fitting selection when the hose lines are configured in the Edit <...> dialog.

Overview of the main dialog elements:

Table:

In this table you define the types of construction, series, part numbers and image files of the fittings.

Use the [...] button in the table cells of the Part number column to access the parts management and select the desired part there.

You can store a path to an image file for each fitting in the Image file column. The image file is displayed in a preview window during the selection of the fittings.   
The [...] button available in the table cells can be used to specify the respective image file by means of a selection dialog. The possible image file types are \*. gif and \*.jpg.

Use the buttons of the toolbar above the table to create new entries and / or delete entries no longer required.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

![](../Pictures/Gui/ALL/note.png)Note:

If you select the default scheme DIN 20066\_2012-01, the table is filled with preset values from the standard DIN 20066. The following types of construction and series are available:

- Types of construction: D, N, N45, N90, R, R45, R90, E, P, P45, P90, S, S45 and S90
- Series: "L" (for "metric light") and "S" (for "metric heavy").

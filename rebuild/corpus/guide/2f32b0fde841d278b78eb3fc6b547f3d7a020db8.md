# Adding Structure Boxes

Everything inside a structure box is allocated to a different identifier structure than that which is defined in the page properties. The components then have the same relationship to the structure box as they normally have to the page. This transfer of the DT also occurs if only identifier blocks such as the function designation and location designation are entered in a component in the structure box.

Precondition:

You have opened a project and are viewing a schematic in the graphical editor.

1. Select the following commands: Tab Insert > Command group Devices > Structure box.
2. Draw the rectangle representing the box.
3. Enter the device data in the structure box-specific properties dialog.
4. In the Identifier tab, click [...] in the Full DT field.
5. Accept the default for the DT or make new entries for the identifier blocks if you would like to modify the structure.

   ![](../Pictures/Gui/ALL/note.png)Note:

   If you enter new structure identifiers in the Full DT dialog, they are inserted according to the user settings for identifiers (option Enter new identifiers in alphabetical order or Add new identifiers to the end) in the table of identifiers. If necessary, you can also set another sorting of new structure identifiers in structure identifier management later on.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The structure box is inserted into the project with all its properties.

![](../Pictures/Gui/ALL/note.png)Note:

If snap to grid is activated (button ![](../Pictures/Gui/ALL/statusbar_snaptogrid_as.png) (Snap to grid on / off) in the status bar), a newly created structure box will be exactly on the grid on which it is placed. If snap to grid is not active, the box can be drawn at any desired position next to the grid.

![](../Pictures/Gui/ALL/info.png)Tips:

- Structure boxes can also be drawn as polylines with the help of the SC2 symbol. To do so, select the symbol in the Insert center and specify the starting point of the box by clicking the left mouse button inside the schematic. After you have specified all of the other points, complete the task via the Complete polyline popup menu item.
- In the project settings you can determine that the upper left-hand corner of structure boxes can be spared and the device tag be placed there. To do this activate the Draw structure box with recess check box (command path: File > Settings > Projects > "Project name" > Graphical editing > General).

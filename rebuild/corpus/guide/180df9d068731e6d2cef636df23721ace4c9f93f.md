# P022017: The project contains excessive field length values in the database: <x>

### Cause

A number of identifiers, numbers, and designations in Eplan projects, such as the device tag, are managed by different databases. In individual cases, the input of very long sequences of letters and / or numbers can result in a cap on information in one of the databases and thus produce incorrect results.

### Solution

Reorganize the project.

1. Select the following commands: File > Extras > Command group Organize > Project > Command group Optimize > Compress project.
2. Click [...] next to the Settings field in the Compress project dialog.
3. In the Settings: Compression dialog, select the scheme you want to edit or create a new one.
4. In the field Data to be compressed select the check box Advanced mode below the check box Reorganize project.
5. Click ![](../Pictures/Gui/ALL/all_save_as.png) (Save).
6. Click [OK].
7. Wait until the reorganization procedure is completed and subsequently start a new check run for the entire project.

![](../Pictures/Gui/ALL/note.png)Note:

The default field lengths of the identifying components of the device tag are often asked for.

Note that Eplan supports the following number of characters:

- 16 characters for the prefix
- 16 characters for the identifier
- 64 characters for the counter
- 16 characters for the subcounter.

Keep the device tags as short as possible for the sake of an easy overview and to prevent errors.

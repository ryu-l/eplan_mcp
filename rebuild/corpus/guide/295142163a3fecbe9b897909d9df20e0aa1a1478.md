# Copying Parts and Pasting Data

### Paste a part

By copying and pasting parts you can rapidly create new parts with existing data.

Preconditions:

- You have opened the Parts management dialog (Tab Master data > Command group Parts > Management).
- You have marked and copied a part or several variants in the tree.

1. Mark the position in the tree at which the part is to be inserted.
2. Select the Insert popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan generates the new part with the part number <Original\_Part\_Number>(1) in the current hierarchy level.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have marked the hierarchy level of the part before copying, the new parts has all variants of the copied part. If you have marked one or more variants of a part, the new part is generated exactly with these variants.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The ERP / PDM numbers of a part are not copied as well during copying in order to avoid duplicate ERP / PDM numbers.
3. Edit the copied data on the right-hand side of the parts management in the tabs or enter new data.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the product group of the selected target does not match the product group of the source part, data of properties can also be transferred which are normally not displayed for the product group of the target.
4. Click [Apply] to save the entries and modifications without leaving parts management.

### [ClosedPaste data](javascript:void(0);)

After copying a part or a variant, its data (technical data, function templates, user-defined properties, etc.) can be transferred to other parts or variants.

Precondition:

- You have opened the Parts management dialog (Tab Master data > Command group Parts > Management).
- In the tree view or in the list view you have copied a part or a variant into the Clipboard by using the popup menu item Copy.

1. In the tree view or in the list view select the part or the variant into which the data of the source part are to be copied. Multiple selection is possible.
2. Select the Paste data popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A prompt is displayed if the product group of the selected target parts does not match the product group of the source part. If you confirm this prompt with [Yes], the copied data will still be inserted. In such a case, data can also be copied from properties which are normally not displayed for the product group. If you click [No], no data is copied and the action is terminated.
3. Activate the check box for the data which is to be inserted in the subsequent dialog Paste data.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If data for a specific area is not available (e.g. safety-related values, modules, etc.), the associated check box is grayed out.
4. If applicable, activate the check box Keep existing function templates if you want to insert copied function templates and in the process keep existing function templates.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The data is written into the corresponding properties of the parts / variants after any data already existing is first deleted.
6. Close the parts management and save the modified data.
7. Click [Yes] in the subsequent dialog to perform a parts data synchronization.

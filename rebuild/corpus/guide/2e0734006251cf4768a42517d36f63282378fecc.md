# Dialog Settings: Project group (assignment)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Settings > Projects > "Project name" > Display > Project group (assignment).

In this dialog, you assign a project group to a project. This activates the settings for the project (color in project data navigators, provision of additional project data navigators), that you specified for the project group in the dialog Settings: Project groups (definition).

Overview of the main dialog elements:

Project group assignment:

Select the desired project group from the drop-down list.

![](../Pictures/Gui/ALL/note.png)Note:

Two of the possible five project groups are predefined ("Project group 1: Schematic projects", "Project group 2: Macro projects"). The names of these project groups cannot be modified. If a name is also to be displayed for the project groups 3-5 behind the designation "Project group <3-5>:", you have to specify it in the user-specific settings during the definition.

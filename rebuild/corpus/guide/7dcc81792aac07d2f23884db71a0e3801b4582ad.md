# File Name Extensions and Icons for Projects

In the tree view of the Page navigator and Project management the following icons and file extensions illustrate the type of project you are dealing with:

| Icon | File type | Meaning | File extension |
| --- | --- | --- | --- |
|  | Eplan project | Standard Eplan project that you can open and edit. If you work in the multi-user mode, such an opened project can be edited by several users simultaneously. | \*.elk |
|  | Exclusively opened Eplan project | Eplan project which was opened exclusively. Only you can edit the project. If you work in the multi-user mode, other users cannot access such an opened project. | \*.elk |
|  | Read-only Eplan project | Eplan project which was opened read-only. You can view, but not edit the project. If you are working in multi-user operation, other users can edit this project. | \*.elk |
|  | Packed Eplan project | Packed project. The icon is only shown in Project management. | \*.elp |
|  | Filed-off Eplan project | For external editing of a filed-off project. You can open the project in Eplan in read-only mode but cannot change or delete it.  Is generated via: File > Back up with the method "File off for external editing". The \*.elk project becomes a \*.els project in the same directory. A \*.zw1 backup file is also created in the selected backup directory. | \*.els |
| --- | Eplan data backup: Project | 1) Backup file of a [filed-off Eplan project](#Ausgelagertes)  or  2) Backup file of an [archived Eplan project](#Archiviertes)  or  3) Backup file from another saved project. Is generated via: File > Back up with the method "Save additionally". The \*.elk project remains in the same directory. A \*.zw1 backup file is also created in the selected backup directory. | \*.zw1 |
|  | Filed-off, packed Eplan project | Such a project could occur in previous Eplan versions via the packing of filed-off projects. The project first has to be unpacked before it can be opened in write-protected mode. The icon is only shown in Project management. | \*.elx |
|  | Archived Eplan project | The project cannot be opened. The icon is only shown in Project management. Is generated via: File > Back up with the method "Archive". The \*.elk project becomes a \*.ela project in the same directory. A \*.zw1 backup file is also created in the selected backup directory. | \*.ela |
|  | Completed Eplan project | Completed project. You can open the project in Eplan in read-only mode but cannot change or delete it.  Is generated via: File > Revision control > Command group Project > Complete > Complete project / section. The \*.elk project becomes a \*.elr project. | \*.elr |
|  | Eplan reference project | Reference project. You can open the project in Eplan in read-only mode but cannot change or delete it.  Is generated via: File > Revision control > Command group Project > Property comparison > Generate reference project. The \*.elk project remains. A copy of the project is also created as a completed \*.elr project. | REV\*.elr |
|  | Eplan revision project | Project with change tracking. You can open and edit the project.  Is generated via: File > Revision control > Command group Modifications > Change tracking > Generate revision. The \*.elk project becomes a \*.ell project. | \*.ell |

![](../Pictures/Gui/ALL/note.png)Note:

Note that a different icon is used in the Open project dialog. The editable Eplan projects are identified here with the symbol of their Eplan application.

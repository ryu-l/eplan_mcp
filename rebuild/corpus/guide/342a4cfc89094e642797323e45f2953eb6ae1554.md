# Tab Lines

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a project page in the graphical editor. You have marked a dimension and selected the popup menu item Properties. In the Properties dialog, select the Lines tab.

You can edit the display properties of the dimension lines and dimension help lines on this tab.

Overview of the main dialog elements:

Group box Dimension help line

Extension:

Here you specify how far the dimension help line should extend past the dimension line.

Distance 1st dimension help line / Distance 2nd dimension help line:

These fields are used to change the distance between the measuring point and the start of the dimension help line. The dimension help line is shortened for positive values and extended for negative values.

Suppress first / Suppress second:

If this check box is activated, the first / second dimension help line is not displayed.

---

Dimension line termination:

From the drop-down list, select how the ends of the dimension lines should be displayed, for example with arrows.

Suppress dimension line:

If this check box is selected, only the dimension value is shown but not the dimension line.

Dimension line interrupted by dimension value:

If this check box is selected, the dimension line is interrupted when the dimension value intersects it.

If this check box is deselected, the dimension line is never interrupted, regardless of the position of the dimension value.

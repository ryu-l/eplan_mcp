# Specifying Comparison Settings

You have the option of determining in detail which properties should be compared with one another in the Settings: Property comparison of projects dialog. The settings are stored in a scheme. You can create different schemes for different tasks, and retrieve settings together whenever needed.

1. Select the following commands: File > Revision control > Command group Project > Property comparison > Compare projects.
2. In the Compare projects dialog, click [...] beside the Settings for property comparison field.
3. From the drop-down list in the Settings: Property comparison of projects dialog, select a user-defined scheme that you would like to change, or use ![](../Pictures/Gui/ALL/all_new_as.png) (New) to create a new [scheme](schemeconfig_h_schematabearbeiten.htm).
4. From the drop-down list Category, select the object type for which you would like to specify properties for comparison.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Depending on your selection, the field Do not compare will show all properties that come into question for a comparison of the selected object type.
5. In the field Do not compare, select the desired properties, and move them using the arrow button into the Compare field.
6. To undo the selection, if necessary, use the second arrow button to move the property selected in the Compare field back into the Do not compare field.
7. Activate the check box Include deleted and new objects if deleted and new objects of the respective object type should also be dealt with as changes.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Your settings are saved in the scheme selected, and then you are returned to the Compare projects dialog.

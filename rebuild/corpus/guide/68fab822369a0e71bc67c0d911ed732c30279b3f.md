# Dialog Busbar (bending)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the layout space navigator and a layout space. Tab Insert > Command group Devices > ![](../Pictures/Gui/ALL/ribbon_busbarbending_as.png) (Busbar (bending)).

Use this dialog to define the part number of the busbar, the copper form and the bending radius of the busbar to be placed. All three fields must have an entry.

Overview of the main dialog elements:

Part number:

The [...] button opens the Part selection dialog of the hierarchy level generic product group "Mechanics", product group "Busbars", product subgroup "Rail".

If the selected part has an assigned macro with the "3D mounting layout" representation type, this macro will be used for the definition of the dimensions width and depth. If no macro is assigned, the values of the properties Width and Depth of the part are used (on the Properties tab in the hierarchy level Mounting data).

Copper rails which are planned for bending always have a rectangular cross-section. If the selected part has already been assigned an outline (extrusion) (to create a user-defined rail), this part cannot be bent. Such a part cannot be used for a bent copper rail.

Form:

If the selected part has an assigned macro with the "3D mounting layout" representation type, this macro will be used for the definition of the form and bending radius. If no macro has been assigned, a form drawing must be entered in this field.

The [...] button opens the Select form dialog where you can select a file with the file extension \*.fp1.

Bending radius:

Enter here the required bending radius for the bending positions of the copper rail. The entries in this field are entered in a drop-down list from which you can also select values.

Flat bending

With this setting, the busbar is bent around the edge which is defined in the "Width" value of parts management.

![](../Pictures/Visualisation/ALL/cabinetgui_copperbarflatbending_as.png)

Edgewise bending

With this setting, the busbar is bent around the edge which is defined in the "Depth" value of parts management. For an edgewise bending a far larger bending radius is required than for a flat bending.

![](../Pictures/Visualisation/ALL/cabinetgui_copperbaruprightbending_as.png)

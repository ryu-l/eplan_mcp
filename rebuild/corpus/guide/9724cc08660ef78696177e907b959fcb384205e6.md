# Creating and Editing Structure Segments

Structure segments are created and managed in the pre-planning navigator.

You edit the properties of a structure segment in the tabs <Structure segment - displayed name> and Documents / Pages of the property dialog.

![](../Pictures/Gui/ALL/note.png)Note:

Structure segments cannot be created below planning objects, nor can they be moved there.

1. Select the following commands: Tab Pre-planning > Command group General > Navigator.
2. Highlight either the project or an existing structure segment, and select the New structure segment popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If there are several segment definitions in the project, the Select segment definition dialog opens.
3. Select the desired segment definition and click [OK].
4. Enter the desired data for the new structure segment in the <Structure segment - displayed name> tab in the Properties <...> dialog.
5. If necessary, assign to the structure segment external documents and / or project pages on the Documents / Pages tab.
6. Click [OK].

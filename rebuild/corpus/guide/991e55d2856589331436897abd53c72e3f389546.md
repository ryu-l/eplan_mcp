# P026107: New calculation of the total weight for enclosure '<x>' required

### Cause

The value of the total weight for the enclosure '<x>' has changed. Therefore the total weight for this enclosure has to be recalculated.

![](../Pictures/Gui/ALL/note.png)Note:

The check run message is also output if the total weight for the enclosure has not yet been calculated.

### Solution

1. Select the following commands: Tab Tools > Command group Reports > Drop-down button [Generate project reports] > Calculate total enclosure weight.
2. Then start the check run again.

# Copper Rail: Adding a New Bending Position

Additional bending positions can be added to a placed copper rail; these positions are not defined in terms of the form. This way, the number of bending positions, including for already placed and modified copper items, can be extended, without having to draw a new form and placing a new copper item.

A new bending position can be inserted on all straight segments of a busbar.

- If a flat bending is to be inserted, all entries have to be made in an isometric 3D viewpoint on the surfaces of the top or bottom side of the rail segment.
- If an upright bending is to be inserted, all entries have to be made on the lateral surfaces of the rail segment.
- Flat and upright bendings can be inserted together at one individual busbar; this way, the item can be defined as bent by different axes in the space.

Preconditions:

- You have opened a project. You have opened a layout space.
- The layout space contains placed busbars (bending).

1. Select the following commands: Tab Edit > Command group Graphic > New bending position.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A cuboid is displayed on the cursor. This cuboid can be placed on all mounting surfaces of straight segments of the copper item and on snap points. If the cuboid touches a mounting surface, a blue line is displayed on it. Placement options can be used for the placement.
2. Click the unchangeable end of the copper item to be modified.
3. Click the desired position where the new bending position is to be added.
4. Use the keyboard to enter the bending angle.
5. Enter the bending radius via keyboard and press [Enter].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new bending position is inserted.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The function remains active, and you can insert other bending positions on the same item.

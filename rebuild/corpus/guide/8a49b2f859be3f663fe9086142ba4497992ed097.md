# Inserting Hyperlinks

You have the option of inserting a text which contains a link to a document or an internet page on any page.

Precondition:

You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc.

1. Select the following commands: Tab Insert > Command group External > Drop-down button QR code > Hyperlink.
2. In the Properties dialog, select the [Hyperlink](gededitgui_r_hyperlink.htm) tab.
3. In the Document field enter the file, Internet page or mail address to be linked as well as the text that is to be displayed on the page.
4. Click [OK].
5. If you have selected a file, you decide in the dialog [Copy hyperlink](gededitgui_d_hyperlinkkopieren.htm) whether the source directory is to be kept for the file or whether the file is to be copied into the project directory. (When inserting a URL or an e-mail address, this dialog is not displayed. URLs are always called up at their original location.)
6. Click [OK].
7. Place the hyperlink on the page like a normal text.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected a file and selected the Copy hyperlink option in the dialog Copy, the file is copied to the DOC subdirectory of the project. There the file is not stored directly, but in a further separate subdirectory. The name of this subdirectory is derived from the source directory name.

The hyperlink will be displayed in the schematic as shown:

When an email address inserted as a hyperlink is opened, the email program installed will automatically start up with a new email to the address specified.

### Open hyperlinks

1. Keep the [Ctrl] key pressed and move the cursor over the hyperlink.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The shape of the cursor will change to a hand.
2. Click the left mouse button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The linked document is opened.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Executed hyperlinks will not change the display color.

![](../Pictures/Gui/ALL/info.png)Tip:

You can also first select a hyperlink and then call up the linked document by using Open hyperlink. (To this purpose you first have to [Customize the ribbon](userinterface_h_menuebandanpassen.htm) and then assign the desired command to a user-defined command group.)

### Copy hyperlinks

1. Click the hyperlink, keep the [Ctrl] key pressed down, and drag the hyperlink to the desired position.
2. Release the mouse button and the [Ctrl] key.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The hyperlink is copied.

### Automatic detection of hyperlinks

If a hyperlink is entered as a value of a property, this property text is automatically detected as a hyperlink during the placement of a page in the graphical editor. This also functions if the text of this property is output in reports by means of a placeholder text. In an exported PDF such texts are also treated as hyperlinks.

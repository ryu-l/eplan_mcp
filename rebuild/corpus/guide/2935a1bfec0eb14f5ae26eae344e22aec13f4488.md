# P004023: Address is missing

### Cause

No address was specified at a PLC connection point that is an input or output.

![](../Pictures/Gui/ALL/note.png)Note:

Other PLC connection points, for example connection points for the card power supply are not checked.

### Solution

1. In the Properties <...> dialog of the PLC connection point, enter the address in the field by the same name.
2. If required, start a new check run.

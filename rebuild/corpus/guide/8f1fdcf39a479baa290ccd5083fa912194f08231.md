# P004119: Multiple assignment of safety address: Source '<x>'

### Cause

One and the same value was entered at the Safety address: Source property at at least two PLC boxes that are safety-relevant in the project.

### Solution

1. Locate the PLC boxes in the schematic by using the functionalities Go to (graphic) and Go to (2nd coordinate), which the popup menu of the Message management dialog offers you.
2. Open the property dialog of each PLC box one after the other.
3. Bring the first tab to the front.
4. Enter a unique value in the table of properties in the Safety address: Source field.
5. Click [OK].
6. If required, start a new check run.

# P005001: Potential connection point or definition point without specification of potential

### Cause

You have inserted a potential connection point or definition point in the schematic at which no name has been assigned yet.

### Solution

1. Locate the potential connection point or definition point in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Call up the property dialog of this component and add the missing information in the Name of potential field.
3. Click [OK].
4. If required, start a new check run.

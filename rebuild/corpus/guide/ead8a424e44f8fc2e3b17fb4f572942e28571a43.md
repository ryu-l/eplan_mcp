# Determining the Order Length

The total length of all the routing connections, cables, tubes etc. with the same part could be calculated and output in summarized parts lists. The total length is calculated from the lengths of the routing paths and routing points through which the connection runs.

In addition the required order lengths of materials can also be calculated and output in the summarized parts list. This allows you, for example to calculate the order lengths of materials that are required to realize the routing paths of a routing path network. Routing paths can consist of materials such as cable ducts, conduits, platforms, etc. and have a part. The total lengths of these materials and the required order lengths can be calculated on the basis of the properties of the parts entered at the routing paths. You can output the order length in meters or as a number of units.

A routing path network contains several routing paths that represent cable ducts. To this purpose the same cable duct part is assigned respectively to these routing paths. The delivery length of the part amounts to 2000 mm, meaning that the cable ducts are supplied as units with 2 m length. If the total routing length of the routing paths amounts to 10.5 m, an order length of 12 m corresponding to 6 units is required. This order length can be calculated by entering a formula in the form for the summarized parts list.

You have to enter the delivery length (in the unit mm) in the parts management for parts of the generic product group "Mechanics", product group "Routing path (topology)" as the basis for the calculation. During a part selection or a device selection the value is transferred to the part property Delivery length (ID 22058). This property is displayed in the property dialog of the routing path in the Parts tab ("Parts data" category).

The used lengths of the materials are determined from the part reference property Subset / Length (ID 31008). This property is filled with the value of the property Topology Routing length (automatic) (ID 20250) as soon as a part has been selected. When changes take place, these properties are synchronized. A manual entry at the part reference is thus automatically copied into the manual routing length.

#### Output of the order length

You have to enter a corresponding calculation formula in the form for the summarized parts list to calculate the order length. To this purpose enter a placeholder text with the option Properties formatted / calculated. The part reference property Total length with unit of the project (ID 20513) is available when selecting the format elements for the calculation. This property totals up the lengths of all the functions (for example connections, routing paths, busbars, etc.) having the same part. The unit of length is specified in the project settings for cables. Only at connections does the unit come from the project settings for connections.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

To calculate the number of units the total length of all the functions with the same part is divided by the value of the delivery length from the parts management. If required, you can add a reserve value in units to round up. In order to create the calculation formula select the following formatting elements in the dialog Format: Calculation:

| Format element | Value | Meaning |
| Placeholder text | Part reference (total length with unit of the project) | Total of the lengths of all the functions with the same part, for example the total of the routing lengths of all the topology routing paths with the same part |
| / | / | Division |
| Placeholder text | Part (delivery length) | Delivery length of the part (from the parts management) |
| \* | \* | Multiplication |
| Number | 1000 | Conversion to meters (necessary because the value is entered in mm in the parts management) |
| + | + | Addition |
| Number | 0.4999 | Reserve for rounding up |

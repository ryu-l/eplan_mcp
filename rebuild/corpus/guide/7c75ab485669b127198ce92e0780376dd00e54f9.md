# Backstage View

If you click the File tab in the ribbon of the main window, the new Backstage view of the Eplan Platform is displayed. Here you can find all the commands and information around your projects. In this view you perform commands with projects. The editing within a project - on the pages, in the layout spaces or in project data - takes place in the main window, in the navigators or the different editors.

The command area is located in the left-hand area of the Backstage view. This is where different commands for the management and transfer of your projects are available to you. Depending on the command selected in the command area further commands and/or dialog elements in the displayed area (right) are shown. In most cases the displayed area is split into two parts and contains a second, context-dependent list with commands. Depending on the command selected, the associated dialog elements, for example buttons with commands or dialog fields are then displayed on the right.

### Shortcut keys for the Backstage view

The following shortcut keys are available for the Backstage view:

| Key combination | Meaning |
| --- | --- |
| [Alt] + [D] | Opens the Backstage view from the main window and shows colored characters. With the colored characters you can select the commands in the command area. |
| [Shift] + [Tab] | Jumps from the first operating element of a dialog displayed in the display area to the list of commands in the middle column of the Backstage view. If there is no middle column, you jump directly to the command area.  Jumps from the List of commands in the middle column to the command area. |
| Arrow button [Up] / Arrow button [Down] | Jumps to the previous / next command. The selected command can be selected with [Input] or [Spacebar].  This functions both within the command area as well as within the list of commands in the middle column. |

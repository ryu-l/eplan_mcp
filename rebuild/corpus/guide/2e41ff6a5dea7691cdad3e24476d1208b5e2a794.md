# Defining Indexed Block Properties

Indexed block properties can be predefined for a function, but also at symbols, and at a project. Below is the definition of block properties for a function. The predefinition of block properties for symbols and projects is done in exactly the same way. For projects the only difference is that each different function category has one (indexed) format property Block property: Format: (<Function category>) [n].

Preconditions:

- You have opened a project.
- You have opened the properties dialog for a function (e.g. by double-clicking on a component in the graphical editor).

1. In the Properties <...> dialog, select the <Function category> tab.
2. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) on the toolbar above the Properties field.
3. In the Property selection dialog select a format property and click [OK].

   ![](../Pictures/Gui/ALL/info.png)Tip:

   You can simultaneously select the associated block property for the graphical editor display. To do this, hold down the [Ctrl] key and click different properties.
4. On the <Function category > tab in the property dialog select the Block property: Format [n] property and click [...] in the Value column.
5. In the Format dialog select a group of properties from the Available format elements list and click the ![](../Pictures/Gui/ALL/all_expand_hierarchy_as.png) sign to open the subordinate property groups.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you can access indirect properties of other objects from this object, the ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level) button will be active.
6. If you want to select indirect properties, click ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The original property grouping is displayed in the Available format elements field once more - these are now the (indirect) properties of the subsequent object, however.
7. Select the required format group and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The ![](../Pictures/Gui/ALL/all_arrowright_as.png) button (move to the right) is only active if a format group can be selected.
8. In the Format: Block Property dialog select a property and specify the formatting for it.
9. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Format dialog displays the selected format elements in a table in the Selected format elements field. They are shown with their designation, symbolic representation (for the preview) and set value. The order in which the properties are listed determines the order in which the individual properties are displayed in the output of the block property.   
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected indirect properties, the ![](../Pictures/Gui/ALL/all_stairdown_as.png) (Previous level) button is active. Use this button to return to the source object.
10. Repeat steps 5 to 7 in order to specify further format elements.
11. If necessary, you can change the sequence of the formatting elements using the arrow buttons on the toolbar.
12. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The block property is then defined. In the Properties dialog the Value field for the corresponding format property will be filled with the preview of the specified format.

![](../Pictures/Gui/ALL/info.png)Tip:

Select Copy & Paste to transfer the specified format to additional format properties.

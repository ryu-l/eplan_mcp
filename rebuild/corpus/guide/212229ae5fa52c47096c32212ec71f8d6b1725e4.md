# Replacing Symbol Libraries and Symbols (Changing Standards)

You can replace symbol libraries and individual symbols.

Preconditions:

- You have opened a project.
- In the case of several opened projects: You have selected a project in the page navigator.
- You have set up a target project.
- You have defined a basic project and the rotation / flipping.

### Assign target symbol libraries

1. Select the following commands: Tab Tools > Command group Standards > Exchange > Tab Project > Button [Next] > Tab Rotation / flipping > Button [Next].
2. In the Master data tab in the Name column select the symbol library to be replaced.
3. Within the same row, click [...] in the New name column.
4. In the Symbol library selection dialog, select the symbol library to be used for the target project and click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol library is entered in the New name column.
5. To assign the entire symbol library, click [Next] on the Master data tab, and do the same in the Symbols tab.  
     
   ![](../Pictures/Gui/ALL/arrow.png) [Define the project structure](changestandardsgui_h_projektstrukturanpassen.htm).
6. To assign the source symbol library symbols to the target symbol library symbols, select the Individual assignment check box in the Master data tab and click [Next].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The source and target symbol libraries are entered in the Symbols tab.
7. In the Symbols tab in the Scheme column select an assignment scheme.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you do not want to use an existing assignment scheme, click [Scheme] and create your own assignment scheme.  
     
   ![](../Pictures/Gui/ALL/arrow.png) [Create assignment scheme for symbols](changestandardsgui_h_stammdatenersetzen.htm)
8. Click [Next].  
     
   ![](../Pictures/Gui/ALL/arrow.png) [Define the project structure](changestandardsgui_h_projektstrukturanpassen.htm).

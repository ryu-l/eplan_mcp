# P027015: Topology - Routing path network no longer up-to-date

### Cause

Graphical objects that influence the connections to be routed in the topology are part of what is known as the routing path network. This includes, for example, routing paths, routing points and interruption points. Each time such a routing path network object is placed in the topology, positioned differently or deleted, the routing path network is modified, resulting in the output of the message "Routing path network no longer up-to-date".

### Solution

1. Re-route the connections throughout the project in order to update the routing path network.
2. Update the connections.
3. If required, start a new check run.

# Templates for Pipe Classes and Substances

The data that describe a piping include the pipe class as well as the substance that is transported through the respective piping (for example "water", "oil", "oxygen"). In the segment template navigator you can predefine the pipe classes and substances that are required in a project with all the relevant data as templates. This means that you do not have to enter the relevant data time and again, but can rather use these templates repeatedly when creating new segments in the pre-planning or when defining pipings in the P&I diagram. The pipe class templates and substance templates can be made available to other users via the popup menu items Export and Import in the segment template navigator.

### Creating pipe classes and substances

The templates for pipe classes and substances are managed in the segment template navigator below the hierarchy level "Other templates". In contrast to the segment templates, the templates for the pipe classes / substances can only be created via the corresponding popup menu items (New pipe class, New substance).

In addition to the identifying name and the description, properties such as the Nominal pressure level, Material and Standard can furthermore be specified at a pipe class template. Initially no further properties for the entry of data are available at a substance template. You can make further properties for the selection and entry of data available for pipe classes and substances through the configuration of user-defined properties.

### Selection of the templates

The created pipe classes and substances are available for selection at the segments in the pre-planning. In the P&I diagram you can select the pipe classes and substances at the piping definition points and piping connection points.

### Assigned parts as filters for the part and device selection

You can additionally store further parts in the Parts tab for a pipe class template. Only those parts that are assigned to a pipe class can be selected later on during a part selection at the segments.

If you have selected a pipe class for a device in the P&I diagram or for a connection, only those parts that are stored at the pipe class are taken into consideration during the device selection - at a corresponding setting of the selection criteria.

### Check runs

You are supported in the configuration of the pipe classes and substances by various check runs. You can use the check runs 028028 and 028029 to check whether the substance entered at an object or the entered pipe class exists as a template in the project.

You can use the check run messages 005092, 007031 and 028031 in order to determine whether parts that are entered at connections / functions / segments do not match the selected pipe class.

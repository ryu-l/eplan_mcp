# Setting the Navigation Cube

Various user-specific settings are available for the navigation cube displayed in the layout space. With these settings you can show and hide the navigation cube, select a home view of the viewpoint, specify the size of the navigation cube and activate and deactivate the animated rotation of the view when the viewpoint changes in the layout space:

1. Select the following commands: File > Settings > User > Graphical editing > 3D navigation cube.
2. Activate or deactivate the Navigation cube visible check box in the Settings: 3D navigation cube dialog to show or hide the navigation cube in the layout space.
3. Use the drop-down list Home view for navigation cube to specify the viewpoint on the 3D object in the layout space that is to be used when the button ![](../Pictures/Gui/ALL/cabinetgui_navigationcubehome_as.png) is clicked. You can select your preferred viewpoint as the home view from six orthogonal and four isometric viewpoints.  

   ![](../Pictures/Gui/ALL/note.png)Note:

   The home view can also be defined by using the shortcut key [Ctrl] + [Alt] + [5]. In addition the button ![](../Pictures/Gui/ALL/ribbon_setstartview_as.png) (Set as home view) is available to this purpose in the ribbon in the View tab in the command group 3D viewpoint.
4. Use the drop-down list Navigation cube size to select the size of the navigation cube to be displayed in the layout space. You can set up five different sizes, from "Very small" to "Very large". Together with the size of the navigation cube, all the buttons used to control the navigation cube change as well.
5. If you want to activate or deactivate the animated rotation when changing the viewpoints in the layout space, activate or deactivate the check box Rotate when changing the viewpoints. In accordance with the setting, the rotation of the navigation cube is also animated or not animated during viewpoint changes.

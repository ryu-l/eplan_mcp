# Placing Items Without Schematic

In order to support the various working methods of builders and engineers, it is also possible to create panel layouts without an existing schematic.

Preconditions:

- You have opened a project.
- You have opened a project page of the "Panel layout" type in the graphical editor.
- You have added a mounting panel.
- You have opened the 2D panel layout - <Project name> dialog (Tab Devices > Command group 2D panel layout > Navigator).
- In the dialog [Settings: 2D panel layout](panellayoutgui_d_schaltschrankaufbaueinstellungen.htm) you have selected none of the Manual input <...> options.

1. In the 2D panel layout - <Project name> dialog select the New device popup menu item.
2. Select the desired part in the Part selection dialog.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The part symbol is scaled to the specified size (only values larger than 0.0 are accepted), and hangs on the cursor.
4. Place the part on the mounting panel.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Properties <...>: Part placement dialog opens.
5. In the Part placement tab allocate a device tag to the part.
6. Edit the other properties of the part placement as required.
7. Click [OK].
8. Proceed in a similar manner for all the parts that you would like to place.

When the part is placed, a check is performed that the current page is of "Panel layout" type and that the part placement is within a mounting panel. If these conditions are not met, the part is not placed and an appropriate message is displayed.

When generating part placements, the function definition is derived from the part master data in the following manner:

| Product group | Product subgroup | Function definition |
| --- | --- | --- |
| Terminals | Mounting rail | Part placement terminal strip |
| Terminals | (no preference) | Part placement terminal |
| Plugs | (no preference) | Part placement plug (male pin / female pin) |
| PLC | (no preference) | Part placement PLC card |
| (all product groups except terminals / plugs / PLC) | (no preference) | Part placement normal item |

![](../Pictures/Gui/ALL/note.png) Note:

If you have selected one of the Manual input <...> options in the Settings: 2D panel layout dialog, you must first specify its dimensions in the Extension and distance dialog prior to placing the device.

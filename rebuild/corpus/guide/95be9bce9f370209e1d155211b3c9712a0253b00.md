# P005082: Cable connection without color / number

### Cause

You have not stored a color or a number at a cable connection.

### Solution

1. Locate the connection definition point of the cable in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Call up the Properties <...> dialog of the connection definition point and enter a value into the Color / number field.
3. If required, start a new check run.

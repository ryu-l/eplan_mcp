# Bundling Connections

The option of organizing and combining wires routed consecutively or in parallel into bundles and of making them available as labeled bundles for wiring accelerates the wiring process and streamlines further the entire enclosure manufacture.

There are two methods for bundling routing connections:

- In the case of Automatic bundling, bundle numbers are determined by the program and written into the Bundle property of the routing connections.
- In the case of Manual bundling, bundle numbers are entered by the user manually in the Bundle property of the routing connections.

Using the interfaces for wire fabrication, you can evaluate this information and transfer to the manufacturing robots that produce the appropriate combined and labeled bundles.

### Bundle connections automatically

Precondition:

You have opened a project. You have created routing connections. Routing connections are highlighted in the connections navigator.

1. Select the following commands: Tab Edit > Command group Routing connections > Bundle.
2. In the Settings field of the Bundle routing connections dialog, select a bundling scheme with settings for bundling, or create a new scheme.
3. When you create a new scheme click the [...] button in the table under Bundling scheme in the cell with the new scheme name.
4. In the Settings: Bundle dialog define one scheme each for the filtering and the sorting of routing connections as well as for the creation of new bundles at a changed property value.
5. Click [OK].
6. Enter the suitable values and settings in the dialog [Bundle routing connections](routinggui_d_autobuendeln.htm#Startwert) in the fields under the table with the bundle schemes.
7. Select the Apply to entire project check box if you wish to bundle all connections in the project.
8. Activate the Preview of result check box if you want to check the bundles to be generated beforehand and sort connections manually into other bundles.
9. Start automatic bundling using [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Bundle connections: Preview of result dialog is displayed.
10. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The connections are assigned to the bundles determined. The bundle number is entered in the Bundle property of each connection.

# Deleting Stored Parts Properties

You can delete the properties of parts stored in the project. User-defined properties are also taken into consideration in the process. For instance, before providing the project to an end customer, you can remove the price information.

Precondition:

You highlighted a project or individual pages in the page navigator, or you highlighted components in the graphical editor.

1. Select the following commands: Tab Master data > Command group Parts > Drop-down button Synchronize > Delete stored part properties.
2. Select a scheme from the Settings drop-down list in the dialog Delete stored part properties or click [...] to open the subsequent dialog of the same name in which you can manage and edit the schemes.
3. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) and select the part properties to be deleted in the dialog Property selection. Multiple selection is possible.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected part properties are deleted from the project.

![](../Pictures/Gui/ALL/benefit.png)Note:

If you delete stored part properties, only the data that is stored at parts is deleted from the project. Part reference data are retained.

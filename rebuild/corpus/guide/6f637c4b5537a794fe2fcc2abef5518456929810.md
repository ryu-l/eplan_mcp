# P026044: No connection point pattern defined.

### Cause

No connection point pattern has been defined at the part placement in the layout space.

### Solution

Store a connection point pattern on the part placement.

#### Possibility 1

1. Locate the part placement in the layout space using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the Properties <...> dialog of the part placement.
3. Bring the Part tab to the front, remember the part number assigned there, and close the property dialog.
4. Select the following commands: Tab Master data > Command group Parts > Management.
5. Branch in the tree view of the Parts management dialog to the part that you have remembered.
6. Bring the Properties tab to the front.
7. In the property table click [...] in the Data hierarchy level in the value field of the Connection point pattern property.
8. Select the name of the required connection point pattern in the Connection point pattern selection - <Project name> dialog that opens and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The name is transferred to the Connection point pattern field of the Properties tab, and the connection point pattern is assigned to the part placement in the layout space.
9. Close parts management, save the modified data, and update the parts database.

![](../Pictures/Gui/ALL/note.png)Note:

If no connection point pattern has been stored in parts management, it will have to be created subsequently. Proceed as follows:

1. Select in the tree view of parts management the Connection point pattern hierarchy level, and select the New popup menu item.
2. Define the required connection point data on the tabs Properties and Connection points, enter a name for the connection point pattern, and click [Apply].
3. Select in the parts tree the part, and assign to it the connection point pattern - as described above.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The assignment is then also implemented for the part placement in the layout space.

#### Possibility 2

1. Open the Properties <...> dialog of the part placement.
2. Bring to front the Connection point pattern tab.
3. Activate the Local connection point pattern check box.
4. Enter the required connection point designations in the table together with other connection point data.
5. Close the Properties <...> dialog by clicking [OK].

# P004025: Slot / module is missing

### Cause

In a PLC box, a rack name was entered under PLC card is placed on rack ID but not the slot position.

### Solution

1. Open the Properties <...> dialog for the corresponding PLC box.
2. In the PLC structure data tab, enter the missing slot position into the Position (slot / module) field.
3. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

This check run only checks PLC boxes at which a configuration project is entered.

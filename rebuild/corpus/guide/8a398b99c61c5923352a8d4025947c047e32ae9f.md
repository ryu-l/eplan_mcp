# Dialog Format: Constant

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the dialog [Format: Calculation](eservicesgui_d_formatberechnung.htm) (for example, when creating a user-defined block property). Select a format element of the Constant type from the Available format elements list and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right) (or double-click an already defined constant in the Selected format elements list).

In this dialog you enter a constant number or a constant text for the calculation formula.

Overview of the main dialog elements:

You can enter the following characters:

- Number: Select this option to enter a constant number in the associated input field in the calculation formula.
- Text: Select this option to enter a fixed text in the associated input field. Any digits, letters, and special characters can be used. The text entered here is regarded as a fixed character combination and cannot be translated.
- Constant Ï: Select this option to enter the circle constant Ï into the calculation formula.

# Showing a Graphical View of the Placed Function

You can display the position of a placed function in the graphical preview. If a device is marked in the device navigator, the graphical preview shows all the components that belong to this device. If the functions are placed in several pages, Eplan displays all associated pages in nested form.

Precondition:

You have placed a function in the schematic.

### Activate graphical preview

1. Select the following commands: Tab Devices > Command group Devices > Navigator.
2. Select a device.
3. Select the following commands: Tab Home > Command group Graphical preview > Open.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan displays the schematic pages on which the associated functions of the device are placed in the Graphical preview dialog.

### Jump to component

In the device navigator you can jump straight to the placed function in the schematic.

1. Select a device.
2. Select the Go to (graphic) popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan opens the schematic page in the graphical editor and positions the cursor on the component.

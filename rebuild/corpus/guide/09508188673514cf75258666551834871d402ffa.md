# Frozen Report Pages

You can freeze report pages. This means that the associated pages are no longer updated. The report block is deleted. However, the frozen report pages remain in the page navigator. [Embedded reports](formgeneratorgui_k_ausgabeformen.htm) cannot be frozen.

Non-frozen report pages are still updated.

| Icon in the Page Navigator | Meaning |
| --- | --- |
|  | Report page |
|  | Frozen report page |

![](../Pictures/Gui/ALL/info.png)Tip:

To regenerate frozen report pages, you must first manually delete the existing report pages and then generate them as new pages. If you do not delete the report pages then additional report pages are generated.

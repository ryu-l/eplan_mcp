# Find and Replace

When planning a project and comparing revisions it is often necessary to find specific information within a project in order to make further changes. The following is possible:

- You can search for text, device tags, symbols, cables, cable connections, potentials, macros, master data, page header data, project header data, properties (format data), etc. in the entire project or on specific pages.
- Placeholders can be used within searches.
- Structure identifiers are also included within searches.
- Invisible objects and layers are also taken into consideration within searches.
- The results of a search are written to lists of results. The following actions are possible based on these lists: As a result, for example, the Properties dialog for a selected object can be open and its properties edited.
- You can synchronize the displays of open navigators.

# Creating Basic Projects

[Basic projects](projects_k_basisprojekteerweitert.htm) can be created via the Backstage view or the project management. You can use a basic project to create a project. If you create a basic project from an existing project, then the entire project is stored in the basic project.

Precondition:

You have selected a project.

Backstage view: File > Extras > Command group Organize > Project > Command group Back up > Create basic project.

Project management: [Extras] > Create basic project.

1. Specify your settings in the dialog Create basic project. The "Generate basic project" method is preset and cannot be changed by you.
2. In the Backup file name field, enter the name of the basic project.
3. In the Backup directory field, specify the directory where the basic file is to be saved.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan suggests the template directory that you specified in the user settings in the dialog Settings: Directories as the storage location.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) A \*.zw9 basic project is created.

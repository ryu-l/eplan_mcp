# Filtering Updated Changed Report Pages

On updating, the modification date of reports only changes when the report has actually changed. A report changes when (e.g.) project data or a form changes. If you update all the reports by using the Generate project reports functionality, you can use the Modification date property to filter for all the report pages that have actually changed.

Preconditions:

- You have opened a project.
- You have updated reports.

1. Select the following menu items: Tab Home > Command group Page > Navigator.
2. Click [...] next to the Filter field in the page navigator.
3. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) next to the Scheme field in the Filter dialog, and create a new scheme in the subsequent dialog.
4. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the toolbar for the filter criteria.
5. Select the Modification date (automatic) property in the Criteria selection dialog below the "Properties" hierarchical level.
6. Select the >= entry in the Operator column of the Filter dialog.
7. Double-click the Value column and select a date for the modification date.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The name of the new filter scheme is entered automatically in the Filter list and activated.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan shows all report pages that have changed on or after the selected modification date.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All report pages that have not changed on or after the selected modification date are hidden.

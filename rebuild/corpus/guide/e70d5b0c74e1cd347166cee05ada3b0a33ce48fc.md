# P004035: Bus ID '<x>' within a logical network '<y>' assigned several times (bus port in the bus system: <z>')

### Cause

The same bus IDs were assigned at one or more bus ports within a logical network of the bus system. The check considers both the entered value of the Physical network: Bus ID / item number property and the value of the Physical network: Bus ID / item number 2 property in the Bus data tab.

The use of this check run makes sense if multiple bus IDs within the physical network are permitted and the uniqueness is only required within the logical network.

![](../Pictures/Gui/ALL/note.png)Notes:

- This check run only checks bus ports at which the Configuration project (automatic, at bus ports) property is filled.
- For bus ports with the function definition "Network / bus cable connection point, general" the following applies: All bus ports of a device with the same bus interface name are combined and must have a common bus address.

### Solution

1. Open the Properties <...> dialog for the corresponding bus port or bus ports. Enter differing values in the Bus data tab in the fields Physical network: Bus ID / item number and / or Physical network: Bus ID / item number 2.
2. Update the connections.
3. If required, start a new check run.

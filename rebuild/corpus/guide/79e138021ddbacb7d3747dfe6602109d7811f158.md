# Dialog Export: NC - copper

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have selected in the layout space or layout space navigator copper items for which an NC export is to be carried out. File > Export > Command group Manufacturing data > Machining > NC - Copper.

Use this dialog to specify the settings for the export of manufacturing data for machining of copper items. The transfer file to the machines has the "XML" format. The following data is transferred:

- Notes on the software version
- Project information
- Material
- Rail dimensions
- Bendings
- Punched holes.

Overview of the main dialog elements:

Machine:

The delivery scope includes the machine definition named "Default". If you have defined other schemes in the company settings, you can select other machine definitions from the drop-down list.

The [...] button opens the Export settings: NC - copper dialog where you can modify the settings for the scheme or define a new scheme.

Output directory:

This field displays the storage location. The directory that is defined for the copper export NC in the company settings is pre-selected here.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

Target file:

This field is active only if the selection contains copper items that can be exported. Here, you can enter the name of the NC file to be generated, or use ![](../Pictures/Gui/ALL/all_selectfile_as.png) in the Open dialog to select a file of the Copper NC (\*. xml) file type. If this results in several files, the field is deactivated, and the conditions apply that are defined in the scheme for generating the file name and the subdirectories.

Material:

Information for the machine on the material to be machined. Here, you can enter any short text; the field can also be left empty. The default value is "Cu".

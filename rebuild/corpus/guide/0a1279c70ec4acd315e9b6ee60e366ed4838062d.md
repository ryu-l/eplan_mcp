# Tab Items (Settings: Export NC - DXF / Settings: Export DXF - copper)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Export NC - DXF:

- File > Settings > Company > Machining > Export NC - DXF. Select the Items tab.
- File > Export > Command group Manufacturing data > Machining > NC - DXF. Click [...] next to the Machine field. Select the Items tab.

Export DXF - copper:

- File > Settings > Company > Machining > Export DXF - copper. Select the Items tab.
- File > Export > Command group Manufacturing data > Machining > DXF - Copper. Click [...] next to the Machine field. Select the Items tab.

In this tab, you specify the settings on visibility as well as layers and colors of item silhouettes and the exported fields.

Overview of the main dialog elements:

Group box Format for field

Display field:

Fields on mounting panels and other items are represented in the DXF file as geometric shapes and assigned to specific layers and colors. If the check box is activated, a defined field for NC machining on a mounting panel or another item is displayed as a rectangle in the DXF file.

If the check box is deactivated, the fields will not be identified in the DXF file. However, the content of the fields will still be exported.

Layer:

Default name of the layer where the field is stored in the DXF file.

Color:

Default color that is assigned to the field in the DXF file.

---

Group box Format for item silhouettes

Generate item silhouettes:

Silhouettes of 3D items display their spatial limitation in addition to the basic outlines and extrusion paths. If the check box is activated, item silhouettes will be generated in the DXF file. In the DXF file, they can be output on separate layers and be assigned colors.

If the check box is deselected, no item silhouettes are generated. This reduces the data volume.

Layer:

Default name of the layer where the item silhouettes are stored in the DXF file.

Color:

Default color that is assigned to the item silhouettes in the DXF file.

---

Group box format for bending information (only available for the Export DXF - copper)

Export bending lines:

If the check box is activated, the bending lines will be generated from the unfold in the DXF file.

Layer:

Default name for the layer on which bending lines are stored in the DXF file.

Color:

Default color given to the bending lines in the DXF file.

Export bending extents:

If the check box is activated, the bending extents will be generated from the unfold in the DXF file.

Layer:

Default name for the layer on which bending extents are stored in the DXF file.

Color:

Default color given to the bending extents in the DXF file.

Export bending notes:

If the check box is activated, the bending notes will be generated as text from the unfold in the DXF file.

Layer:

Default name for the layer on which bending notes are stored in the DXF file.

Color:

Default color given to the bending notes in the DXF file.

# Action: GraphicalLayerTable

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| TYPE | Type of task that the action is to perform: IMPORT: Importing layers EXPORT: Exporting layers. |
| PROJECTNAME | Project name with complete file path (optional). If nothing is entered, the selected project will be used if the action is to be run over the user interface (e.g. via the script or ribbon). When executing from the Windows command line, PROJECTNAME must be specified or ProjectAction has to be used before that. Otherwise a system message will appear. |
| IMPORTFILE | Directory and name of the layer configuration file for the import. |
| EXPORTFILE | Directory and name of the layer configuration file for the export. |

GraphicalLayerTable 
/TYPE:IMPORT 
/PROJECTNAME:C:\Projects\EPLAN\DEMO2_D.elk
/IMPORTFILE:C:\EPLAN\EPLAN_Sample_Project.elc

# P003027: Cable: 'Function text (automatic)' different (in language '<x>')

### Cause

For a cable placed in a distributed manner in the schematic, the Function text (automatic) property is different in the selected displayed language at one or several placements of the cable.

### Solution

#### Possibility 1

1. Locate the functions of the cable displayed as distributed using the Go to (cross-referenced) functionalities from the popup menu in the Message management dialog.
2. In the Search results <Project name> dialog double-click the entered cable definition of the main and auxiliary functions and call up the property dialog of the respective cable definition.
3. Standardize the Function text (automatic) property in the selected displayed language for all placements of the cable.
4. Confirm your entries.

#### Possibility 2

Use the synchronization functionality.

1. Select one of the cable definition lines of the cable displayed as distributed whose automatic function text is to be transferred to the other functions of the cable.
2. Select the following commands: Tab Tools > Command group Synchronization > Drop-down button Functions and decide which type of synchronization you want to perform depending on the representation type. Use, for example, the command Multi-line --> All representation types if you have configured the selected cable definition line whose data you want to transfer as multi-line.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The automatic function texts of the cable displayed as distributed are synchronized correspondingly to each other.

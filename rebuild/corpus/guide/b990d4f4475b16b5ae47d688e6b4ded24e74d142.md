# Creating Symbol Libraries

Precondition:

You have opened a project.

1. Select the following commands: Tab Master data > Command group Symbols > Drop-down button Symbol library > New.
2. In the Create symbol library dialog select the drive and directory where the new symbol library is to be saved. (To return to the default setting for a directory, click the Eplan icon in the left-hand navigation area and the directory listed below it.)
3. Overwrite the preset file name <New symbol library.slk> with a name of your choice.
4. Click [Save].  
     
   ![](../Pictures/Gui/ALL/arrow.png) If a symbol library with that name already exists in the selected drive and directory, reply to the prompt regarding overwriting the file.
5. In the Symbol library properties - <Library name> dialog you assign values to the desired properties.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new symbol library is created, transferred to the list of opened symbol libraries, and can be edited. Eplan then extracts the company code, workstation number, and the short name of the employee from the system and user settings and stores this data in the symbol library.

![](../Pictures/Gui/ALL/note.png)Note:

A project configuration (File > Settings > Projects > "Project name" > Management > Symbol libraries) can be used to assign any number of symbol libraries to a project. The symbol libraries selected are then stored in the project.

# Dialog Settings: Message management

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Settings > Projects > "Project name" > Management > Message management.

In this dialog, you can specify which type of messages will be displayed.

Overview of the main dialog elements:

Check-related settings:

From the drop-down list, select a scheme for the display of messages. Click [...] to open the Settings: Messages and checks dialog. For the different messages, here you can define whether they should be displayed as an error, a warning, or a note, and whether they should be checked online or offline. Save your settings in a scheme.

Max. number of check run messages:

In this field, enter the number of offline check run messages that are to be considered.

![](../Pictures/Gui/ALL/note.png)Note:

Internally, the number of messages is limited to a maximum of 10,000. If no value is entered in the Max. number of check run messages field, you will be shown a corresponding message. Only once you have entered a valid value (1-10,000) will you be able to exit the Settings with [OK].

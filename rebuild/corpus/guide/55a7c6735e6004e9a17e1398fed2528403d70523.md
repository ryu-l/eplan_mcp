# Selecting Elements

An element in the graphical editor is selected when you click it. In the case of filled graphical elements you can also click anywhere within the filled area.

Precondition:

You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc.

### Select multiple elements individually

1. Press [Ctrl] while selecting the individual elements.   
     
   ![](../Pictures/Gui/ALL/arrow.png) Selected elements are displayed in a different color.

![](../Pictures/Gui/ALL/info.png)Tip:

Use [Ctrl] + [Spacebar] to select several single elements via the keyboard.

### Select an area of elements

1. If you want to select multiple elements which lie next to one another, open a frame around the desired group with the mouse.   
     
   ![](../Pictures/Gui/ALL/arrow.png) All the elements within this frame are selected.

   ![](../Pictures/Gui/ALL/note.png)Note:

   If you open the frame from left to right, only those elements are selected which lie completely within the frame. But if you open the frame from right to left, "partial" elements are also selected, which only partially lie within the frame.
2. To remove a single element from this selected group, press [Ctrl] and click the element at the same time.

### Select an area via the ribbon

1. Select the command Highlight area. (To this purpose you first have to [Customize the ribbon](userinterface_h_menuebandanpassen.htm) and then assign the desired command to a user-defined command group.)
2. Specify the first corner of the area to be selected using [Enter].
3. Open a frame using the arrow keys. You can open the frame in any direction.
4. You can use [Tab] to switch the cursor between the lower right corner and the upper left corner, in order to stretch the area in all directions.
5. End area selection with [Enter].   
     
   ![](../Pictures/Gui/ALL/arrow.png) All the elements within this area selection are selected.

### Select all elements

1. Press [Ctrl] + A, to select all elements on the current page, the current form, etc.

### Remove element selection

1. Press [Esc] to remove the selection from the elements.

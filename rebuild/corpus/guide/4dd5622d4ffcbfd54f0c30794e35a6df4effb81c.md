# Creating Parts

Preconditions:

- You have opened the dialog Parts management (Tab Master data > Command group Parts > Management).
- You have marked an entry in the tree view below the "Parts" hierarchy level.

1. Select the New popup menu item in the tree.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have highlighted the hierarchy level "Component" or a product group below it, Eplan generates a new part with the part number New(<Consecutive\_Number>).  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have marked a part, Eplan generates a new part with the part number Original\_part\_number(<Consecutive\_Number>).
2. In the right-hand section of the dialog change to the Properties tab.
3. Change the automatically assigned entry for the Part number property in the General hierarchy level.
4. Change the product grouping for the part, if hierarchy levels with the "Undefined" designation have occurred. This is the case, for example, when you have selected the "Component" hierarchy level.
5. To this purpose click in the Value column for the Product grouping property and then click [...]. From the drop-down list with the product groups double-click to select the desired product subgroup (e.g. "General").  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected product grouping is displayed in the Product grouping property. After application of the modifications the product grouping is also displayed for the hierarchy levels in the tree.
6. Enter the further data of the part (e.g. manufacturer) in the Properties tab.
7. Click [Apply] to save the entries and modifications without leaving parts management.

![](../Pictures/Gui/ALL/note.png)Note:

If no "Component" hierarchy level is available for a generic product group (e.g. fluid power), you create a component via the popup menu items New > Component.

### [ClosedCreating variants](javascript:void(0);)

Preconditions:

- You have opened the dialog Parts management (Tab Master data > Command group Parts > Management).
- You have created a part.

1. Mark the desired part in the tree view or in the list view.
2. Select the New variant popup menu item.
3. In the subsequent dialog enter the designation for the new variant of the current part. Up to 3 characters are possible.

![](../Pictures/Gui/ALL/note.png)Note:

Part number and a variant designation must be unique. If you accidentally enter a designation which already exists, Eplan warns you as soon as you click [Apply] or [Close]. The record can only be saved after you have assigned a new part number.

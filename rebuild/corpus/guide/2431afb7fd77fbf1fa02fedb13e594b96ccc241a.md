# P011008: Several star sources with the same device tag

### Cause

Multiple interruption points that are star sources and have the same device tag exist in the project.

### Solution

#### Possibility 1

1. Locate the interruption points defined as star sources in the schematic by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Delete the superfluous interruption points that are star sources so that only one star source is retained.

#### Possibility 2

Assign different device tags for the interruption points occurring multiple times that are star sources.

#### Possibility 3

Double-click the superfluous interruption points that are star sources and deactivate the Star source check box in the respective Properties <...> dialog.

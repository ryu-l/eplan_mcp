# Dialog Page properties / New page

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened the page navigator and opened (at least) one project.

- You have selected one or more pages in the page navigator. Popup menu item Properties.
- Tab Home > Command group Page > New.

In the Page properties dialog you can view and change the properties of pages.

When creating pages, in the New page dialog you define the properties of the new pages. If a page was selected in the page navigator, Eplan takes on its properties; otherwise the property values are empty.

Overview of the main dialog elements:

Full page name:

When creating a page, Eplan automatically suggests a name. You can accept this or change it manually. You can use [...] to open the [Full page name](pagebrowsergui_d_seitenname.htm) dialog where you can edit the structure identifier and the page name.

Page type:

Assign an interactive page type to the page from the drop-down list, or use [...] in the Add page type dialog to select an automatic page type. When changing the page type all of the other page properties are retained.

Page description:

You enter description text for the page here. This text is also displayed in the tree view or list view of the page navigator.

---

[Properties group box](devicetaggui_r_gruppenfeldeigenschaften.htm)

The properties for the current page are displayed in the table and can be edited.

---

[Clear fields]:

This button is only available when creating pages. It deletes the content of all data fields in the currently chosen page. Only the page type of the currently selected page is retained.

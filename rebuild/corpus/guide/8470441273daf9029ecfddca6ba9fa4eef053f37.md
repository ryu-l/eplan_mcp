# Placing Connection Definition Points

Precondition:

You have selected a connection in the graphical editor, or in the Connections - <Project name> navigator dialog. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog.

1. Select the following commands: Tab Connections > Command group Connections > Place definition points.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Once you have called up the command, the connections are first automatically generated new.
2. In the Settings field of the Place connection definition points dialog select a scheme from the drop-down list that will specify the settings for connection numbering. Use [...] to open the Settings: Connection numbering dialog. Define the numbering settings here and store them in a scheme.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection definition points are placed on the schematic pages. They receive "????" as a designation if the associated connection still has no designation.

![](../Pictures/Gui/ALL/note.png)Note:

For the connection definition points placed by means of the connection numbering, all properties are cleared and reset to undefined values, so that these connection definition points are neutral.

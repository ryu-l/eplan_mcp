# Defining Pipings in a P&I Diagram

You can predefine pipings with specific properties in the pre-planning navigator. You can then place piping planning objects created in this manner in the P&I diagram at a later time. The result is a piping definition point with a reference to the piping planning object. However, piping definition points can also be insert directly via a symbol in the P&I diagram â without assignment to a planning object.

Preconditions:

- You have opened a project containing pre-planning data.
- You have opened a page of the "P&I diagram" type.
- You have placed process engineering symbols that are connected via autoconnect lines on this page.

### Placing piping planning objects as piping definition points

1. Select the following commands: Tab Pre-planning > Command group General > Navigator.
2. Select the piping planning object that you wish to place.
3. Select the Place popup menu item.
4. Place the piping definition point on an autoconnect line.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The data of the piping planning object are assigned to the piping definition point.

If you want to modify the assigned data, open the property dialog for the piping definition point (for example by a double-click) and enter other properties for the piping in the Piping definition tab.

![](../Pictures/Gui/ALL/info.png)Tip:

You can also place piping definition points simply with drag & drop, by dragging a marked piping planning object from the pre-planning navigator onto an autoconnect line of your opened P&I diagram page in the graphical editor.

### Drawing piping definition points

1. Select the following commands: Tab Pre-planning > Command group P&I diagram > Piping definition point.
2. Place the piping definition point on an autoconnect line.
3. In the Properties <...> dialog specify the piping properties in the Piping definition tab (and other properties in the other tabs, if necessary).
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The properties are assigned to the piping defined by the piping definition point.

![](../Pictures/Gui/ALL/info.png)Tip:

You can insert multiple piping definition points at the same time by holding the left mouse button down and pulling the cursor over multiple autoconnect lines. A piping definition point is then placed on each autoconnect line that is intersected.

A piping planning object can be assigned to an inserted piping definition point from the pre-planning navigator by using the popup menu item Assign. This links the piping definition point with the piping planning object. The data of the piping planning object are carried over to the piping definition point.

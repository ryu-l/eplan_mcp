# Tab Single conductors (Komax - Zeta)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > Company > Wire fabrication > Komax - Zeta > Tab Single conductors
- File > Export > Command group Manufacturing data > Wire fabrication > Komax - Zeta. Click [...] next to the Scheme field. Select the Single conductors tab.

In this tab, you specify the data for the processing of single conductors on the "Komax - Zeta" machine.

Overview of the main dialog elements:

Toolbar:

| Button | Meaning |
| --- | --- |
| (New) | Generates a new line. The new line is appended to the end of the list. |
| (Move up) /  (Move down) | Moves the selected lines up or down by one position, if possible. |
| (Update) | Reloads the part numbers, connection colors, and connection cross-sections of the connections routed in the layout space from the project. |
| (Delete) | Deletes a selected row. |

Table:

Part number:

The fields of this column display the part numbers of the single conductors to be processed. You can change the part numbers manually or use the [...] button to branch to the part selection in order to interactively select the desired single-conductor part. If you have selected a single-conductor part, the fields below for Connection color and Connection cross-section are automatically filled with corresponding values.

Connection color:

Enter the identifier for the color of each single conductor here, for example BK = black. The fields are automatically filled with a value when you select the single conductor parts via the part selection.

Connection cross-section:

Enter the cross-section of each single conductor here, for example 2.5 = 2.5 mm. The fields are automatically filled with a value when you select the single conductor parts via the part selection.

![](../Pictures/Gui/ALL/note.png)Note:

If you do not enter a measuring unit, "mm²" is assumed. If you want to specify the connection cross-section in "AWG", enter the measuring unit explicitly.

Single conductor: WireKey:

Enter the "WireKey" for each single conductor here, for example H07V-K-BK-1.50. This is a text that is defined as a parameter set in the software settings of the Komax machine and has to be taken from there. The "WireKey" contains information about the part, the connection color and the connection cross-section of the single conductors. The maximum text length of this parameter set is 25 characters.

Labeling: FontKey:

Enter the "FontKey" for each single conductor here. The "FontKey" is required for the direct labeling of the single conductors. This is a text that is defined as a parameter set in the software settings of the Komax machine and has to be taken from there. The "FontKey" contains information about the text formatting such as font, font size and font color. The maximum text length of this parameter set is 25 characters.

Marker tube: TubeKey:

Enter the "TubeKey" here. This is a text that is defined as a parameter set in the software settings of the Komax machine and has to be taken from there. If a marker tube is used for the labeling of the single conductors, the "TubeKey" provides information about the used part, the diameter and the color of the marker tube. The maximum text length of this parameter set is 25 characters.

Marker tube: Text size:

Here you specify the size of the font for the marker tube to be printed, if one is provided for labeling the single conductors. You can choose from 10 different font sizes. (Default value: 2).

Marker tube: Layout:

Enter the "Layout" for each single conductor here. The "layout" is required for the labeling of the marker tubes. This is a text that is defined as a parameter set in the software settings of the Komax machine and has to be taken from there. The "Layout" contains information about the text formatting such as font, font size and font color. The maximum text length of this parameter set is 25 characters.

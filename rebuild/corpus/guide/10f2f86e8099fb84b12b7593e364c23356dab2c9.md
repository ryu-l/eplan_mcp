# Adjusting the Layout Space Structure

When copying layout spaces, you can change the layout space numbers prior to pasting the layout spaces.

Precondition:

You have selected one or more layout spaces in the layout space navigator.

1. Select the Copy popup menu item.
2. In the layout space navigator, click the position where the copied layout spaces are to be inserted, and select the popup menu item Insert.
3. In the Adapt structure dialog, change the name of the target layout space to be inserted. The Automatic layout space name check box also allows you to determine the next highest layout space number (in relation to the structure).
4. Click [Reset] if you want to retain the original structure identifiers when you insert several layout spaces, for example.
5. Select the Overwrite check box if layout spaces of the same name in the target project are to be overwritten.

![](../Pictures/Gui/ALL/note.png)Note:

If you selected the With prompt option in the project settings (File > Settings > Projects > "Project name" > Devices > Numbering (online)), the dialog Insertion mode is displayed. You specify here as to how the DT should be numbered in the copied layout spaces.

If you select in this dialog the Number option, both the device tags of the items and the grouping signs for item designations will be renumbered.

8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The layout spaces are inserted into the target project, and the structure identifiers and DT are changed according to the input.

# Deleting Placements and Returning Placed Functions

The Return mode allows the removal of a component for a placed function in the schematic while leaving the data contained in the then unplaced function in the database. The representation type of the function is retained when the function is returned.

The following placement types can be returned:

- Schematic (single-line and multi-line)
- Overview
- Pair cross-reference
- P&I diagram.

The following placement types cannot be returned:

- Graphical placements
- External placements
- Part placements
- All elements that are not functions or that cannot exist "unplaced" (angle, T-node, interruption points, ...).

Precondition:

- You are in a schematic project.
- You have opened a page in the graphical editor, or you have opened a project data navigator (e.g., the device navigator).

1. Select the components in the graphical editor or the placed functions in the navigator that you want to return.
2. Select the following commands: Tab Home > Command group Clipboard > Drop-down button Delete > Placement.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected functions that can be returned are converted into unplaced functions (and deleted from the page).

![](../Pictures/Gui/ALL/note.png)Notes:

- If a single object is selected that cannot be returned, then the menu item is grayed-out.

- If multiple objects are selected that cannot be returned, then the menu item is also grayed-out.

- Otherwise, if multiple objects are selected, then only the returnable functions are considered and all other functions in the selection remain unchanged.

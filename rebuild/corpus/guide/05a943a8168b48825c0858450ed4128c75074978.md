# P502023: The function templates of the assembly / module '<x>', variant '<y>' are not up-to-date

### Cause

An assembly / module '<x>' in the variant '<y>' whose function templates are no longer up-to-date was found in the parts database to be checked.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Select the [Extras] > Summarize function templates menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The function templates located at the assemblies / modules are combined and updated.
3. If required, start a new check run.

# Action: XGedStartInteractionAction

| Parameter | Description |
| --- | --- |
| Name | Name of the interaction to be started. Possible interactions are:   - [XGedIaFormatDefPoints](#XGedIaFormatDefPoints): Set the format of the connection graphic (connection definition point, potential definition point) - [XGedIaFormatGraphic](#XGedIaFormatGraphic): Set the format of the graphical elements - [XGedIaFormatSymbol](#XGedIaFormatSymbol): Set the format of the component - [XGedIaFormatText](#XGedIaFormatText): Set the text format - [XMIaInsertMacro](#XMIaInsertMacro): Insert a macro into the current project. |

Using this interaction you have the option of setting the formatting settings of components, texts, graphical elements, or connection and potential definition points to exactly specified values. The available settings are the same as those that can be made in the user interface in the individual property dialogs on the Display, Format and Connection graphic tabs.

In Eplan, for example, you can assign these interactions in the ribbon of a [user-defined command group as commands](userinterface_h_menuebandanpassen.htm). The parameters for the above interactions are listed below.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The following values are to be set for certain texts: Font size: 10 mm, Color: Green, Angle: -90°. In addition, an alignment box with a width of 45 and a height of 20 mm is to be shown. A possible entry in the command line in the Rename dialog may look like this:

XGedStartInteractionAction /Name:XGedIaFormatText /height:10mm /color:3 /justification:? /angle:-90 /setframeactive:1 /showframe:1 /framewidth:45mm /frameheight:20mm

If a property should not be changed, then leave the corresponding question mark "?" on the command line alone. In the example, this is, for example, the Alignment property (Parameter: /justification:?). Parameters that are not needed, such as /bold:? can be deleted from the command line.

### Parameters for the "XGedIaFormatDefPoints" interaction

| Parameter | Description | Values |
| /width:? | Line thickness | Numeric values in "mm" or in "In" (Inch). With the value "-16002", the "From layer" setting will be applied. |
| /color:? | (Text or line) Color | The predefined values are:   - 0 = black - 1 = red - 2 = yellow - 3 = green - 4 = cyan - 5 = blue - 6 = magenta - 7 = black - 8 = white - 9 = light gray - 252 = dark gray - 253 = gray - -16002 = from layer.   However, other values can also be specified in the [Color selection](mf_d_farbauswahl.htm) dialog. Values from 0 to 256 are possible. The values of the colors are displayed in the color selection Tooltip. |
| /type:? | Line type | The following values are possible:   - 0 = solid - 1 = dashed - 2 = dotted - 3 = dash-dot - 4 = dash-dot-dot - 5 = dash-2 short dashes - 26 = long dash-dot - -16002 = from layer. |
| /patternlength:? | Pattern length | Numeric values in "mm" or in "In" (Inch). With the value "-16002", the "From layer" setting will be applied. |

| /patternlength:? | Pattern length | Numeric values in "mm" or in "In" (Inch). With the value "-16002", the "From layer" setting will be applied. |
| /lineendstyle:? | Line end style | The following values are possible:   - 0 = round - 1 = rectangular - 2 = flat - 32 = from layer. |
| /visible:? | Invisible (text or line invisible / visible) | The following values are possible:   - 0 = invisible - 1 = visible. - 2 = from layer. |

| /transparency:? | Transparency (specifies the transparency of a 3D object in the layout space) | Numerical values from 0.0 to 1.0. A value of 1.0 results in complete transparency (100% transparency). As an alternative you can also enter the value 'bylayer'. This will apply the transparency level as set for the layer. |

For certain graphical elements, the line thickness should be set to 5.5 mm and the graphic filled with cyan. The graphical elements should always be visible. The entry in the command line can look as follows:

XGedStartInteractionAction /Name:XGedIaFormatGraphic /width:5,5mm /color:4 /visible:1

XGedStartInteractionAction /Name:XGedIaFormatSymbol /language:fr\_FR

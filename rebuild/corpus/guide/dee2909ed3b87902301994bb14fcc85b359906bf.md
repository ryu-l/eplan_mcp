# P004093: The PLC connection point references an invalid subdevice with the property 'PLC subdevice: Index'

### Cause

An invalid reference to a PLC subdevice was determined at a PLC connection point or a bus port. The reference to a PLC subdevice is invalid if no value was entered at the associated PLC box for the property PLC subdevice x: Name and / or PLC subdevice x: Position (slot / module). This also applies for the properties PLC subdevice x: Start address (outputs) or PLC subdevice x: Start address (inputs) .

### Solution

#### Possibility 1

1. Locate the PLC connection point / bus port in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Open the property dialog of the PLC connection point / bus port.
3. Bring the first tab to the front.
4. Determine the value entered in the properties table for the number of the subdevice in the field PLC subdevice: Index.
5. Jump from the PLC connection point / bus port - for example by using the popup menu item Go to (counterpiece) - to the associated PLC box.
6. Here too bring the first tab to the front.
7. Check in the properties table whether values are entered in the properties listed in the "Cause" section for the associated PLC subdevice.
8. If necessary, enter corresponding values in the empty property fields.
9. Click [OK].
10. If required, start a new check run.

#### Possibility 2

1. Repeat Steps 1 to 4 described in "Option 1".
2. Change the value entered in the PLC subdevice: Index field in order to assign the PLC connection point / bus port to the correct PLC subdevice.
3. If required, start a new check run.

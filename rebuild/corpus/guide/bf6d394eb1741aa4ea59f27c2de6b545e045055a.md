# Backstage View: Help

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Help

The following commands are available in the Help Backstage view:

| Command | Meaning |
| --- | --- |
| Contents | Here you find information on the Eplan products.   - Information Portal: Starts an Eplan website with information about the Eplan products (help systems, TechTips, release notes, etc.). Here you have the possibility to search globally for terms in all the stored technical publications via a full-text search. - Help system: Calls up the help of your Eplan version. |
| Support & Updates | - Support: Starts an Eplan website with a form for a support request. - Download Manager: Starts the Eplan Download Manager and offers the possibility to install the program components for Eplan. |
| Information command group | Here you can find the following information on your Eplan version:   - Product - Licensed add-ons - Copyright / Trademark - System information |

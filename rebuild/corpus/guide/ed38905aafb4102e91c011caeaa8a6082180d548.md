# P005089: Connection definition point lies on a bundle

### Cause

A connection definition point or a cable definition line was inserted on a bundle drawn in the schematic.

### Solution

1. Locate the connection definition point or the cable definition line in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Delete the connection definition point or the cable definition line from the bundle.
3. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

We recommend that you insert connection definition points or cable definition lines as far as possible on multi-line connections entering or exiting on the bundle in order to obtain unique connection information in the reports, for example in the cable diagram.

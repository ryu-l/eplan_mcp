# Tab Symbols (Changing Standards)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. In the case of several opened projects: You have selected a project in the page navigator. Tab Tools > Command group Standards > Exchange. You have specified all of the settings in the Project tab. Button [Next]. You have specified all of the settings in the Rotation / flipping tab. Button [Next]. You selected the check box in the Master data tab in a symbol library row in the Individual assignment column. Button [Next].

In this tab, you can select assignment schemes for assigning symbols from the source symbol library to symbols from the target symbol library.

Overview of the main dialog elements:

Assign symbols:

A row contains an assignment of source library symbols to target library symbols. It displays only the assignment pairs from the symbol libraries for which the Individual assignment check box is selected in the Master data tab.

- Source: Symbol library: Displays the file name of the source project symbol library without a file extension.
- Target: Symbol library: Displays the file name of the target project symbol library without a file extension.
- Scheme: In this column you can select a scheme. This scheme contains information about which symbols can be assigned to one another. Click [Scheme] button to create or edit a scheme.
- Status: If a scheme is selected in the Scheme column, the assignment of the symbols is checked. This column displays the status of the check. The status is "OK" if the function definitions for the symbols match and the number of source symbol connection points are less or equal to the number of target symbol connection points.

[Scheme]:

Opens the dialog Settings: Symbol assignment. Enables you to assign symbols from the source library to symbols from the target library.

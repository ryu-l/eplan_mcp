# Tab Nominal diameter

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > User > Add-ons > Hose line configurator. Click the Nominal diameter tab.
- You have opened a project. You have opened the [Configure hose lines](fluidhoseconfiggui_d_schlauchleitungen.htm) dialog. Select the Extras > Settings menu items. In the subsequent dialog click the Nominal diameter tab.

In this tab define the default values for the nominal diameter of the used hoses. The values entered in the table are offered for selection when the hose lines are configured in the Edit <...> dialog.

Overview of the main dialog elements:

List:

The values of the nominal diameter always reference the unit "mm". They can therefore be entered without a unit.

Use the buttons of the toolbar above the list to create new entries and / or delete entries no longer required and / or edit existing ones.

![](../Pictures/Gui/ALL/note.png)Note:

If you select the default scheme DIN 20066\_2012-01, the table is filled with preset values from the standard DIN 20066 that are assigned to the hose nominal diameter "d1".

# Tab Drill holes (Settings: Export NC - DXF / Settings: Export DXF - copper)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Export NC - DXF:

- File > Settings > Company > Machining > Export NC - DXF. Select the Drill holes tab.
- File > Export > Command group Manufacturing data > Machining > NC - DXF. Click [...] next to the Machine field. Select the Drill holes tab.

Export DXF - copper:

- File > Settings > Company > Machining > Export DXF - copper. Select the Drill holes tab.
- File > Export > Command group Manufacturing data > Machining > DXF - Copper. Click [...] next to the Machine field. Select the Drill holes tab.

In this tab, you specify the settings on visibility as well as layers and colors of drill holes. In addition, you specify whether and at what point round sections are to be transferred as outlines.

Overview of the main dialog elements:

Group box Format for drill holes

Export as circle:

During the DXF export, drill holes are represented as geometric shapes and assigned to specific layers and colors. If the check box is activated, the drill hole will be generated as the DXF element "circle with center".

Layer:

Default name of the layer where the circle is stored in the DXF file.

Color:

Default color that is assigned to the circle in the DXF file.

Export as text:

Alternatively, or in addition to the representation of a drill hole as a circle, you can specify text with a prefix to output the drill hole. If the check box is activated, the drill hole is characterized with the diameter. In addition, the text can be preceded by a prefix.

Layer:

Default name of the layer where the text is stored in the DXF file.

Color:

Default color that is assigned to the text in the DXF file.

Prefix:

Here you enter the string that precedes the text at the drill hole.

---

Group box Export

Always export holes as hole:

If this option is selected, the drill hole will be generated as the DXF element "circle with center". The machine finds the position of the drill holes by way of the center of the drill circle in the DXF file. The information on the diameter for the hole in this location is contained in the description placed at the center of the drill circle.

Always export holes as outline:

If this option is selected, the drill hole will be generated as an outline description.

Export small holes as holes and large ones as outline:

If this option is selected, the drill holes will be output as holes up to the value set in the Diameter limit value field. If the diameter of a drill hole exceeds the limit value, the drill hole will be generated as an outline description.

Diameter limit value:

In this field, you specify the drill hole diameter up to which drill holes are exported as holes if the Export small holes as hole and larger ones as outline option is selected.

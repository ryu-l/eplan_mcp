# 2D Panel Layout

The program allows you to design panel layouts and mounting panels, as well as simply creating schematics with the associated charts and lists. Mounting panels can only be created on project pages of type "Panel layout".

Graphical objects or "Composite macros" are used to symbolize the items on a mounting panel. You must store the composite macros in the part management master data.

In addition to mounting panels, you can also create item legends that can be bound to the project in a number of different ways.

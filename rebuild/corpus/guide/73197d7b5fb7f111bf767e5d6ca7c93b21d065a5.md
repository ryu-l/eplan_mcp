# P007021: The device contains both protected and unprotected functions

### Cause

A device has both protected and unprotected functions.

### Solution

1. Use the Go to functionalities to locate the device in the project.
2. Open the properties of all functions of the device in turn and check the status of the Device protection check box.
3. For all functions (main and auxiliary functions) of the device, activate or deactivate the device.
4. If required, start a new check run.

# Synchronizing Project Data

The data that is saved in a project includes data such as layers, user-defined properties, property arrangements etc., but also project settings, check run schemes and report templates. You can use the project data synchronization to easily transfer data from one source project (for example a basic project) to another project.

Precondition:

You have opened the project whose project data is to be synchronized.

### Synchronizing individual project data

1. Select the following commands: File > Extras > Command group Organize > Project > Command group Optimize > Synchronize project data.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the Synchronize project data - <Project name> dialog, the source and target projects are displayed in two lists. In the left-hand list Target project data the project data of the project currently opened and selected in the page navigator is displayed. This is the project into which the data is copied.
2. In the Source project field select the project from which you want to import the project data.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The source project last selected is pre-selected when the synchronization dialog is opened the next time.
3. For the Source project click the column headers in order to sort the data alphanumerically in either ascending or descending order by column. For example, if you click the Type column, all entries will be sorted and displayed according to the project data type.
4. Select an entry below the Target project list in the drop-down list Type in order to reduce the amount of displayed and selectable project data.
5. In the Source project list select the project data that you would like to transfer to the target project. Multiple selection is possible.
6. Click ![](../Pictures/Gui/ALL/all_arrowleft_as.png) (Copy to the left).
7. Click [Close].

### Synchronizing all project data

1. Select the following commands: File > Extras > Command group Organize > Project > Command group Optimize > Synchronize project data.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the Synchronize project data - <Project name> dialog, the source and target projects are displayed in two lists. In the left-hand list Target project data the project data of the project currently opened and selected in the page navigator is displayed. This is the project into which the data is copied.
2. In the Source project field select the project from which you want to import the project data.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The source project last selected is pre-selected when the synchronization dialog is opened the next time.
3. Select [Update] > Update project to replace all outdated or different project data of the target project with the project data of the source project.
4. Select [Update] > Complete project to complete the project data of the target project with the data from the source project.
5. Click [Close].

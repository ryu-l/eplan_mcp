# Defining Translation Fonts

If you wish to translate a project into a language whose characters are not contained in the standard fonts on your computer, then you must install an appropriate font containing these characters on your computer. You must select this font in the Eplan settings.

Precondition:

You have installed a font containing the desired characters.

1. Select the following commands: File > Settings > Company > Graphical editing > Fonts.
2. In the Font drop-down list, select the font containing the desired characters.

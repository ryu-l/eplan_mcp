# Comment: Procedure

A project is exchanged between a project editor and a project redliner for commenting. Different procedures are possible here, depending on whether comments are inserted into a PDF file or directly into Eplan. In the course of the editing of the comments, further comments and replies can be added in Eplan, the status can be assigned and a history can be viewed.

### [ClosedPDF comments](javascript:void(0);)

Precondition:

The project editor has created a project and would like to have it checked and commented by a project redliner without an Eplan license.

- The project editor exports their Eplan project as a PDF file.
- The project editor sends the PDF file to the project redliner for review.
- The project redliner opens the PDF file in Adobe Acrobat (full version or Reader) and inserts comments.
- The project redliner sends the commented PDF back to the project editor.
- The project editor imports the PDF comments into their Eplan project.
- The project editor processes the comments successively and marks the comments accordingly.
- When the project is complete, the project editor deletes all comments from the project.

### [ClosedEplan comments](javascript:void(0);)

Precondition:

The project editor has created a project in Eplan and would like to have it checked and commented by a project redliner with an Eplan license.

- The project editor saves their Eplan project and sends it to the project redliner for review.
- The project redliner opens the project in Eplan and adds comments directly in Eplan.
- The project redliner saves the commented project and sends it back again to the project editor.
- The project editor opens the commented project in Eplan.
- The project editor processes the comments successively and marks the comments accordingly.
- When the project is complete, the project editor deletes all comments from the project.

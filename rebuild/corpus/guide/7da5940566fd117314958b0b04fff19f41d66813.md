# P007008: The part '<x>,' which had been predefined in the device list, was used <y> times too often

### Cause

A part in the device list was used more often than allowed.

### Solution

#### Possibility 1

Delete the part in the schematic. Refer to the value entered in the parts column Number allowed.

#### Possibility 2

Increase the number of allowed pieces for the part in the device list.

1. To do this, highlight the part in the device list.
2. Then select the Properties popup menu item.
3. Increase the value in the Number allowed field in the Properties <...> dialog.
4. Click [OK].

---

  

If required, start a new check run.

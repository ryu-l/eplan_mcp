# Checking Project Data Online

In contrast to the offline check, project data are checked directly during the processing of a project in the online checking mode.

Preconditions:

- You have opened a project.
- You have opened a schematic page in the graphical editor.
- You have created schemes for check runs that contain checks which you wish to carry out online and whose type of check is set correspondingly to "online".

1. Select the following commands: Tab Tools > Command group Review > Messages.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Any messages stored in the message database are displayed in the Message management - <Project name> dialog.
2. Execute the processing steps in the project. Copy or move for example devices or change the properties of devices.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan checks the processing steps in accordance with the set test criteria. If inconsistencies or errors are found, the corresponding messages are written immediately into the message database and are displayed in the dialog Message management - <Project name>.

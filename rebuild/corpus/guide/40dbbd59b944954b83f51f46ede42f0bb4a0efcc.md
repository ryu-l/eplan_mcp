# P026111: No order number assigned to the part of the device

### Cause

During the export of the AML file a device was determined in the layout space at whose part no information for the property Order number is stored. The device could therefore not be exported.

### Solution

1. Locate the part placement in the layout space using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Double-click the part placement in the layout space and in the dialog Properties bring the Parts tab to the foreground.
3. Look up the part in question and close the dialog.
4. Select the following commands: Tab Master data > Command group Parts > Management.
5. In the dialog Parts management search for the determined part and bring the Properties tab to the foreground.
6. Enter the required information in the property table in the value field of the property Order number.
7. Click [Close].
8. Save the modified data, and carry out a parts synchronization.
9. Repeat the export.

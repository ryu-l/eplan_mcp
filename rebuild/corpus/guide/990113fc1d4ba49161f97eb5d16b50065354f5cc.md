# Displaying Cable Connection Points

The Cable connections button in the View tab makes it easier to find automatically generated cables and connections used during the automatic generation of cables. When this button is activated, connection points of functions having an active Cable connection point property are marked with an arrow. (Automatic generation of cables only accounts for connections to functions with at least one cable connection point or which are defined as cable connections.)

You set the Cable connection point property in the [Connection point logic](xfctdefbrowsergui_d_anschlusslogik.htm) dialog, which you call up from the Symbol / function data tab, via the [Logic] button.

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the button Cable connections in the command group General in the View tab.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Connection points of functions with the Cable connection point property are marked with a small arrow.
2. Deactivate the Cable connections button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The arrows marking cable connection points are hidden again.

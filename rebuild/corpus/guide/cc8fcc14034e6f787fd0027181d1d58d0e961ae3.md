# P002003: Plug definition is missing

### Cause

You created a pin without plug definition in the plug navigator or placed it in the schematic.

### Solution

#### Possibility 1

1. Select the pin in the plug navigator.
2. Select the New popup menu item in the plug navigator.
3. Branch to the desired function definition (Plug definition for female pins, Male pins or Male and female pins) in the tree view of the subsequent dialog (via the nodes Electrical engineering > Terminals and plugs > Plug definition > Plug definition).
4. Click [OK].
5. Assign the DT of the pin to the plug definition in the Displayed DT field of the dialog Properties <...>.

#### Possibility 2

1. Place a plug definition in the schematic using the Symbols object type of the Insert center.
2. Assign the DT of the pin to the plug definition in the Displayed DT field in the dialog Properties <...>.
3. Click [OK].

#### Possibility 3

1. Select the pin in the plug navigator.
2. Select the Generate plug definition popup menu item.
3. Click [OK] in the property dialog that is opened.

#### Possibility 4

Use the cleaning up of projects.

1. Select the following commands: File > Extras > Command group Organize > Project > Command group Optimize > Clean up project
2. In the Clean up project dialog select the [...] button next to the Settings field.
3. In the subsequent dialog click the node Plugs in the list of the data to be tidied up and activate the check box Add missing plug definition.
4. Confirm your entries.

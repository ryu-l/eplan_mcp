# P004006: PLC box without conn. point

### Cause

#### Possibility 1

You have drawn a PLC box in the schematic that does not contain PLC connection points.

#### Possibility 2

You have created a non-placed PLC box with symbol data in a project navigator (for example in the PLC or in the device navigator) to which no PLC connection points are assigned.

### Solution

#### Regarding Possibility 1:

1. Locate the PLC box in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Insert at least one PLC connection point into the drawn PLC box.

![](../Pictures/Gui/ALL/note.png)Note:

Missing PLC connection points are determined both on schematic pages as well as on overview pages.

#### Regarding Possibility 2:

1. Locate the PLC box in the PLC or device navigator using the Synchronize selection function offered by the popup menu in the Message management dialog.
2. Create at least one PLC connection point with symbol data in the PLC or device navigator for the PLC box that is not placed yet.

# Using Direct Editing

Using direct editing you can activate an editing mode that allows you to directly modify individual text. This can be property text or graphical text.

![](../Pictures/Gui/ALL/note.png)Note:

When you have switched on the direct editing mode, double-clicking an object with text does not open the properties dialog but rather an editing frame.

Precondition:

You have opened a page, form, plot frame, or symbol. Or you have opened a layout space.

1. Activate the button ![](../Pictures/Gui/ALL/ribbon_directediting_as.png) Direct editing in the command group Options of the Edit tab.  
   Or if you have opened a layout space: Select the button ![](../Pictures/Gui/ALL/ribbon_directediting_as.png) Direct editing in the Insert tab in the command group Options.
2. Double-click the text that you would like to edit.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The text is displayed in an editing frame.
3. Edit the text as desired. Make special use of the popup menu (click within the editing frame with the right mouse button), to (e.g.) change special text or line-breaks.
4. Press [Enter] to save the changes and close the editing field, press [Esc] to discard the changes. Clicking outside the editing frame also saves the changed text.
5. If you no longer wish to use direct editing, deactivate the button Direct editing.

![](../Pictures/Gui/ALL/info.png)Tips:

- When you directly edit the placed properties of a component, you can use [Tab] to jump from one property to the next. When jumping, the changed text is saved and the next property text is automatically opened in an editing frame.
- You can select direct editing even if editing mode is not switched on. Select the text / component, or placed the cursor exactly over the text, then simply press the [F2] key and edit the displayed text. Pressing [Enter] accepts the changes and the editing frame closes. The system behaves in a similar manner to MS Excel.
- You can also select direct editing using the mouse. This functions in a similar manner to renaming files in the Windows Explorer. First select the text or component on your page and then leave the cursor over the text to be edited. To open the editing frame, briefly hold down the left mouse button and then release it.

# Defining Net Extensions for Connection Numbering

In Eplan, a net is a subset of a signal. Typically a net ends at terminals, pins, or connection points of functions. You can use the net extension function to extend the net within the limits of the signal, e.g. with terminals and pins. To do this, specify in the net extension dialog which functions should not be treated as a boundary for the net. This setting affects the designation if the range is selected as "Net". The net extension for connection numbering is independent of the Net-connecting property of the function concerned.

Precondition:

You have opened a project.

1. Select the following commands: File > Settings > Projects > "Project name" > Connections > Connection numbering.
2. Select a user-defined scheme from the drop-down list, or create a new scheme via ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the dialog Settings: Connection numbering.
3. Select the Designation tab and click [Net extension].
4. In the dialog Net extension, mark the required functions from the Selection list and use the arrow button to move these into the Net extended with following objects list.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The net then no longer ends at the selected functions; it is now extended beyond them.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The net extension applies to all format groups with the scope "Net".
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The setting is saved in the selected scheme.

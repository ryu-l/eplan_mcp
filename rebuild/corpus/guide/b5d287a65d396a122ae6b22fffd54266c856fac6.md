# Dialog Settings: Item selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a project page in the graphical editor. You have inserted a model view (Tab Insert > Command group View > Model view) and placed it. In the Model view dialog, select the View tab and click [...] for the property Model view: Selection scheme in the column Value.

You use this dialog to create and manage schemes for displaying item types in the model view.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Table:

This part of the dialog is used to specify the criteria for automatic item selection.

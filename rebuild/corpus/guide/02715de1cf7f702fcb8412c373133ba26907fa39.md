# Dialog Settings: Copper bending (Company)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > Company > Machining > Copper bending

Use this dialog to define schemes with settings for the mechanical bending of copper components. Each material thickness used is assigned a bending table that contains correction values for the bending radii for each planned bending angle. These values are taken into account during the unfold of the copper component.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Material thickness:

The Material thickness field initially contains only the value 10.00 mm. A minimum bending table exists for this value. Initially, it consists of a column for the bending radius (1.00 mm) and a row for the bending angle. It is there that an adjustment factor of 0.00 mm has already been entered.

Other material thicknesses can be defined. For each new material thickness, a new bending table is defined automatically, which must then be built up and filled with data by the user. When selecting a material thickness, the associated bending table is displayed.

Toolbar (material thickness):

| Button | Meaning |
| --- | --- |
| (Edit) | Allows for the value of a material thickness to be modified. The Change material thickness dialog is displayed where the new value for the material thickness must be entered. |
| (New) | Creates a new entry in the Material thickness field. The New material thickness dialog is displayed where the required value for the material thickness must be entered. This allows for positive values greater than 0. |
| (Delete) | Deletes a selected material thickness. The associated bending table is also deleted. |

Bending table:

The bending table contains for each material thickness used a matrix with adjustment values for the bending radius that are to apply to the individual bending angles. These adjustment values equalize the changes in length at the copper items that are caused during bending by the different extension and compression of the material.

It is the responsibility of the user to insert a new column for each required bending radius and a new row for each required bending angle. The resulting matrix must then be filled with adjustment values. The functions required for this are included in the popup menu of the bending table.

![](../Pictures/Gui/ALL/info.png)Tip:

You can determine the bending angles and bending radii of the copper items to be unfolded from the properties of the copper items. If, in the layout space, you double-click a busbar with pressed-down [Shift] key, then its properties dialog is displayed. On the Bending positions tab, all bending positions are contained including bending angle and bending radius and the information if this data is already contained in the bending table. Paste the missing values into the bending table.

![](../Pictures/Gui/ALL/note.png)Note:

After a modification to the bending table, the copper items are recalculated for the export. The display of the copper items in the layout space, in model views, and copper unfolds is subsequently not adapted to the export result automatically. Therefore, the display must be updated.

- Layout space: Select the Update part placement popup menu item.
- Model views: Tab Tools > Command group Reports > Model views. In the Reports tab, select the popup menu item Update.
- Copper unfolds: Tab Tools > Command group Reports > Drop-down button Model views > Copper unfolds. In the Reports tab, select the popup menu item Update.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| New bending radius | Creates a new column with a bending radius. The New bending radius dialog is displayed where the required value for the bending radius must be entered. This allows for positive values greater than 0. |
| Change bending radius | Allows for the value of a bending radius to be modified. The Change bending radius dialog is displayed where the new value for the bending radius must be entered. |
| Delete bending radius | Removes the entire column with the selected bending radius. |
| New bending angle | Creates a new row with a bending angle. The New bending angle dialog is displayed where the required value for the bending angle must be entered. This allows for positive values greater than 0. The new bending angle is used to generate automatic entries in the columns of the existing bending radii that are preset to the value 0.00 mm. The required adjustment values can be set here. |
| Change bending angle | Allows for the value of a bending angle to be modified. The Change bending angle dialog is displayed where the new value for the bending angle must be entered. |
| Delete bending angle | Removes the entire row with the selected bending angle and the bending radii assigned. |

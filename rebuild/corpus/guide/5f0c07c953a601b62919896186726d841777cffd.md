# Copying Pages within the Same Project

Within the same project, you can copy pages using either the page navigator or the graphical editor. In the page navigator it is possible to copy individual pages or entire blocks of pages. In the graphical editor you copy the currently open page.

Precondition:

You have selected at least one page in the Pages - <Project name> navigator dialog.

1. Select the following commands: Tab Home > Command group Clipboard > Copy. Or select the Copy popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected pages are copied to the clipboard.
2. If you work with multiple clipboards (definable in the user settings), then in the [Clipboard](macrosgui_d_zwischenablage.htm) dialog, enter a description for the content of the relevant clipboard and click [OK].
3. Select the following commands: Tab Home > Command group Clipboard > Insert. Or select the Insert popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you are working with multiple clipboards, the [Paste](macrosgui_d_einfuegen.htm) dialog opens. Select the desired page and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the Adapt structure dialog, the page numbers, the page descriptions, and the structure identifiers of the source and target pages are listed on the [Pages](pagebrowsergui_r_seitenstruktur.htm) tab.
4. Change the page number and / or the structure identifier if you would not like to overwrite the existing pages, and deselect the Overwrite check box.
5. Select [Number] to open the [Number pages](pagebrowsergui_d_seitennummerierung.htm) dialog and renumber the copied pages.
6. If the copied DTs contain structure identifiers, you can change the visible DTs in the [DT](pagebrowsergui_r_ortkaestenstruktur.htm) tab.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the Overwrite check box is selected, a prompt is displayed if there are already pages with the same name that would be overwritten. Click [Yes] to overwrite the pages. Click [No] to return to the Adapt structure dialog and change your settings.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you selected the With prompt option by means of the commands File > Settings > Projects > "Project name" > Device > Numbering (online), the Insertion mode dialog is displayed. You specify here as to how device tags should be numbered on the copied pages.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The pages are inserted into the project, and the structure identifiers of the pages and of the DTs are modified in accordance with the entries.

![](../Pictures/Gui/ALL/info.png)Tips:

- The page opened in the graphical editor can also be selected by using the shortcut key Ctrl + [M]. The page navigator does not need to be open for this.
- In the page navigator, you can move and copy pages via Drag & Drop. Hold down the [Ctrl] key to copy pages.

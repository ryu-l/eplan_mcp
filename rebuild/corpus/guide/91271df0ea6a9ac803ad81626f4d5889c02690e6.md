# Display Properties: Tab Polyline / Polygon

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc. You have marked a polyline or a polygon and selected the menu item Properties. Or you have double-clicked on a polyline or polygon. In the table of the Properties (Polyline) dialog, expand the hierarchy level Polyline.
- You have opened a project. You have opened a project page in the graphical editor. You have drawn a structure, black box or PLC box as a polyline, or double-clicked on such a box. In the Properties <...> dialog select the Format tab and, in the table, expand the Polyline hierarchy level.
- You have opened a project. You have opened a project page in the graphical editor. You have inserted a comment as a polygon or double-clicked the polygon of the comment. In the Properties dialog select the Format tab and, in the table, expand the Polyline hierarchy level.

Below this hierarchy level you can edit the specific settings of open polylines or polygons or comments with polygons.

Overview of the main dialog elements:

Segments:

Below the Segments hierarchy level, the individual line segments of the polyline are displayed. Use the ![](../Pictures/Gui/ALL/all_new_as.png) (New) and ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) buttons above the table to add a new line segment or delete the selected one.

The following properties are available for each segment:

Starting point / End point:

In the fields below these hierarchy levels, the coordinates of the starting and end points of the currently selected line segments are displayed.

Angle:

The selected line segment will be drawn at this angle to the X axis.

Length:

Here, the length of the selected line segment is displayed and can be altered.

Radius:

Here, the radius of the selected line segment is displayed and can be altered. The field is only available for "free polylines", that is, not for polygons representing structure, black, or PLC boxes.

---

Closed:

This check box is selected if you have drawn a polygon.   
If you activate it later for an open polyline, a connection is drawn from the first to the last point of the line.  
If you deselect it later for a polygon, the line between the first and last points is deleted.

The check box is only available for "free polylines", that is, not for polygons representing structure, black, or PLC boxes.

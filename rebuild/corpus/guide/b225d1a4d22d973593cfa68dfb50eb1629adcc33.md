# P027020: Connection point <x> exists more than once

### Cause

On the topology function, the named connection point <x> exists in the connection point pattern multiple times.

The message occurs in connection with terminal strips displayed multiple times.

### Solution

1. Locate the topology functions in your routing path network by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Call up the Properties <...> dialog of the topology function, and switch to the Connection point pattern tab.
3. Mark the table and select the popup menu item Update.
4. Delete all connection points from the table that are not to be connected to this display of the terminal strip. (For example, these can be connection points that are connected with targets in another routing path network.) Or rename the connection point designations that occur multiple times.
5. Click [OK].
6. Route the connections again.

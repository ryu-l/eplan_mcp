# Dialog Segment templates - <Project name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Tab Pre-planning > Command group General > Segment templates
- You have opened an editor such as the graphical editor, the plot frame editor, etc. Tab View > Command group Navigators > Drop-down button Open > Segment templates.

This dialog is used to display the segment templates and templates for pipe classes and substances defined in the project either in the tree or list view and to edit them.

Overview of the main dialog elements:

In the Tree tab, the segment templates are displayed in their hierarchical structure. The top hierarchy level is the project. Below that the segment templates of a project are structured in the following hierarchy levels:

- Basic segment definitions (for example "Structure segment", "Planning object", "PCT loop", etc.).
- Segment definitions (for example "Structure segment general", "Planning object general", "Loop", etc.).
- Segment templates: User-defined segment templates are identified by the preceding icon ![](../Pictures/Gui/ALL/all_segtemplate_as.png). The icon ![](../Pictures/Gui/ALL/all_segtemplatedouble_as.png) is displayed for segment templates with subordinate segment templates.
- Subordinate segment templates: The segment templates that are subordinate to the current segment template are displayed on the lowest hierarchy level. Subordinate segment templates are additionally identified by the preceding icon ![](../Pictures/Gui/ALL/planninggui_link_as.png) (for example ![](../Pictures/Gui/ALL/planninggui_link_as.png)![](../Pictures/Gui/ALL/all_segtemplate_as.png) Voltage measuring function).

Otherwise, the same icons are displayed for the basic segment and the segment definitions as in the pre-planning navigator. In addition to the segment templates, the templates existing in the project for pipe classes (icon ![](../Pictures/Gui/ALL/navigatorgui_pipingtemplate_as.png)) and substances (icon ![](../Pictures/Gui/ALL/navigatorgui_substancetemplate_as.png)) are displayed in the tree below the hierarchical level Other templates (icon ![](../Pictures/Gui/ALL/navigatorgui_othertemplates_as.png)).

In the List tab, the segment template name, the segment template description, the segment definition name, the designation and the description of the segment, as well as structure identifiers for the identifier blocks "Function designation" and "Location designation" are displayed by default. The names and descriptions of the "other templates" (pipe classes, substances) are also displayed in the columns Segment template: Name (identifying) and Segment template: Description.

In addition, structure identifiers for further identifier blocks, as well as other properties of the structure segments and planning objects can be displayed (e.g., the properties Technical description, Power consumption or user-defined properties). The values of the properties can be edited directly in the list view.

![](../Pictures/Gui/ALL/info.png)Tip:

Press [F5] to update the view in the segment template navigator.

Filter:

This drop-down list displays all the available filters. A selected filter is automatically activated and is applied to both the tree and the list view. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the [Filter](modaldialogsdb_d_filternnach.htm) dialog. Here you can create, edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

- Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
- Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

Value: <Property>:

Use this field, via [Quick input](modaldialogsdb_k_filter.htm#I_Schnelleingabe), to adjust quickly the value of a filter criterion for a defined and activated filter.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| New segment template | This menu item is available when a segment definition is selected. Allows you to create a segment template. |
| New pipe class | This menu item is available when a "segment definition" for pipe classes is marked. Allows you to create a pipe class. |
| New substance | This menu item is available when a "segment definition" for substances is marked. Allows you to create a substance. |
| Copy / Paste | Reflects the Windows functions for editing data. Allows you to copy and paste segment templates within the segment template navigator. The copied segment templates are numbered automatically. When segment definitions or basic segment definitions are copied, the complete subordinate structure is copied as well. |
| Duplicate | Duplicates the selected segment template. The identifying name is incremented automatically. |
| Export | Allows you to export segment templates to a file in XML format. |
| Import | Allows you to import segment templates from a file in XML format. |
| Delete | Deletes all the selected segment templates or - in the tree view - all segment templates below the selected tree structure level. (Multiple selection of segment templates or tree structure levels is possible here.) Only segment templates which are not used in the project can be deleted. |
| Rename (tree only) | Use this menu item to rename the identifying name of the selected segment template. |
|  | Note:  The popup menu items Rename, Update segments, Assign and Change segment definition are not available at templates for pipe classes and substances! |
| Update segments | Updates the data of the PLC addresses and / or parts at the segments (planning objects, PCT loops, etc.) to which the marked segment templates were assigned. This is necessary after the changes in the tabs PLC and / or Parts of a segment template so that the current data of the segment template can also be displayed at the segments and subsequently in the PLC assignment list and / or in the reports (for example parts list). An update is only possible if no PLC addresses and / or parts were assigned manually to the segments! |
| Assign | This menu item is available when a project page (pre-planning page, P&I diagram) is opened. Assigns the marked segment template to the selected segment on the project page. The property values defined in the segment template are transferred to the segment. Values that were changed manually beforehand at the segment are retained. |
| Update placeholder data | Updates the data of the placeholder objects for selected segment templates. In the process the changed placeholder data is transfered from the macros already assigned to the segment templates for PCT loops, planning objects, etc. This way you do not have to individually open the segment templates with stored macros to update the data. |
| Change segment definition | Opens the dialog Select segment definition and allows you to assign a different segment definition to the segment template (in as far as the segment template is not used in the project). |
| List with preselection (tree only) | Reduces the number of elements displayed in order to allow for a faster orientation in the list view. If this option is activated, the list view is called up with an automatic filter (preselection) containing the elements that are currently selected. |
| Select in tree (list only) | Displays the marked object in the Tree tab. |
| Properties | Opens the Properties (components): <...> dialog. Allows you to edit the properties of the segment or function. |
| Properties (global) | Opens the Properties (global): <...> dialog. Allows the editing of the device properties. |

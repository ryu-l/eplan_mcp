# Searching / Filtering a Project

You can search for a project using a filter. In the filter definition you can enter properties as filter criteria. You can also specify a search directory where Eplan is to search for the project. Other directories documents are not included in the search.

Precondition:

In project management, you have loaded directories and projects.

1. Select the following commands: File > Project management.
2. In the Project management dialog, next to the Filter field, click [...].
3. Select a scheme in the Scheme field or use the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button to create a new scheme in the dialog [Filter](modaldialogsdb_d_filternnach.htm).
4. In the Filter dialog, to the right above the table, click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
5. To determine a search directory, select the "Directory" entry in the Criteria selection dialog and click [OK].
6. Click [...] in the Value column.
7. Select a directory from the Select folder dialog and click [OK].
8. If required, specify additional properties as criteria.
9. Click [OK].
10. In the Project management dialog, select the desired filter from the Filter field.  
      
    ![](../Pictures/Gui/ALL/arrow.png) Eplan displays all projects satisfying the filter criteria in the tree structure.

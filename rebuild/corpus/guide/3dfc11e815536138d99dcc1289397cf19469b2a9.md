# P005037: Conflicting intrinsic safety of connection points

### Cause

The target functions of a connection have a conflicting entry for the Intrinsically safe property. For example the Intrinsically safe check box was activated in the function settings of the one target and in addition the Intrinsic safety possible setting was specified at the function connections. On the other hand, the other target of the connection was not made intrinsically safe.

### Solution

#### Possibility 1

If the connection has to be intrinsically safe, make all targets of the connection intrinsically safe.

1. To do this, activate the respective Intrinsically safe check box in the Properties <...> dialog, group box Function data (logic).
2. In addition activate the respective check boxes Intrinsic safety possible in the Connection point logic dialog at the corresponding function connections.

#### Possibility 2

If the connection does not have to be intrinsically safe, deactivate the respective Intrinsically safe check box at all targets in the Properties <...> dialog, group box Function data (logic).

---

  

If required, start a new check run.

# Identifier Blocks for Pages and Devices

For the definition of project structure by Eplan, the following identifier blocks are used for the hierarchy of pages and objects included in the schematic:

| Identifier block | Preceding sign |
| --- | --- |
| Functional assignment | == or # or â |
| Function designation | = |
| Installation site | ++ |
| Location designation | + |
| Document type | & or space |
| User-defined | Arbitrary |

All identifier blocks named are available for page numbering and, with the exception of the identifier block "Document type", for the device numbering. The identifier blocks to be used for the project hierarchy are determined when creating a project.

All identifier blocks can be combined arbitrarily. Except for the identifier block "Document type" and the free hierarchy, there are no dependencies or exclusion criteria between the settings for the page formats and the settings for devices.

Identifier blocks must not necessarily be filled with structure identifiers, even if they are specified in the project properties. This means that empty structure identifiers which are then listed in the structure identifier management can occur. In addition, global changes (find, replace, sort, etc.) can conveniently be performed on structure identifiers.

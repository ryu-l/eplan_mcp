# Signing in or Changing Users

Precondition:

You are using the "Sign-in" operating mode.

### Sign in users

The Sign in to Eplan dialog is automatically displayed when Eplan starts.

1. Enter the user name and password and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan checks if the user is correctly set up and the password is correct. If this is the case then you are signed in under the specified user name.

### Switch users

1. Close Eplan via File > Exit.
2. Restart Eplan.
3. Enter the user name and password into the Sign in to Eplan dialog and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan checks if the user is correctly set up and the password is correct. If this is the case then you are signed in under the specified user name.

![](../Pictures/Gui/ALL/info.png)Tip:

In the user settings (command path: File > Settings > User > Display > User code / address) you can see which user you are signed in as in the Sign-in name field.

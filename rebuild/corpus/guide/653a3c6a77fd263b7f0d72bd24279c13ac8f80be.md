# Using Jump Functions

Jump functions allow jumping to all cross-referenced "Parts" of a particular item, where the main function is always jumped to.

Preconditions:

- You have opened a project.
- You have opened the 2D panel layout - <Project name> dialog.
- You have inserted mounting panels and part placements.

1. In the tree or in the list of the 2D panel layout - <Project name> dialog, select the item to whose graphical representation in the graphical editor you would like to jump to.
2. Select the Go to (graphic) popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the device is not yet placed on the mounting panel, the graphical editor branches to the page where the main function is located. The main function is highlighted in the process.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the device has been placed, the graphical editor jumps to the macro placed on the mounting panel.

# Finding and Storing Missing Project Master Data, Updating Projects

Preconditions:

- You have opened the project whose master data is to be completed.
- You have no editor open for working on master data (Plot frame editor, Form editor, etc.).

### Completing projects

By copying pages, for example, it can occur that new master data references to forms, plot frames, etc. will be inserted in the project. These do not necessarily have to be in the target project because referenced master data is not automatically embedded. Such projects can still be updated / completed, i.e., the used but unsaved master data are copied from the master data pool into the project.

1. Select the following commands: Tab Master data > Command group Synchronization > Complete project.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The missing master data are searched for in the project and, if they exist, they are stored automatically.

![](../Pictures/Gui/ALL/note.png)Note:

The result of this action is logged in the system messages. This records, for example, when no data is in the master data pool for missing project master data or when an error occurs during completion. The corresponding information can be viewed in the system messages (command path: File > Extras > Command group System > System messages > System messages).

### Updating a project

After editing forms, plot frames and / or symbols in the appropriate editor, the project does not contain the current data. If the edited master data are to be transferred into the project, the project can be updated as follows:

1. Select the following commands: Tab Master data > Command group Synchronization > Update project.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project is searched. If master data files more current than the corresponding project master data files are found, the newer files will be automatically saved, i.e., they will overwrite the project master data files.

![](../Pictures/Gui/ALL/note.png)Note:

The result of this action is logged in the system messages. This will record, for example, when no data in the master data pool is available for certain project master data. The corresponding information can be viewed in the system messages (command path: File > Extras > Command group System > System messages > System messages).

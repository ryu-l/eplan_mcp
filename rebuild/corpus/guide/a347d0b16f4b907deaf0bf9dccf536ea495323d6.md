# Dialog Generate reference project

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Revision control > Command group Project > Property comparison > Generate reference project.

In this dialog you can generate a reference project from the current project.

Overview of the main dialog elements:

Project name:

Provide a name for the reference project here. Eplan automatically suggests a name based on the current project name, as well as the number of reference projects already generated for this project.  
Use ![](../Pictures/Gui/ALL/all_selectfile_as.png) to open the dialog for file selection. Select a project name already in use and then change it.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

User:

This field cannot be changed and shows the user who generated the reference project.

Date:

This field cannot be changed and shows the date on which the reference project was generated.

Generate temporary reference project:

If this check box is activated, a temporary reference project with the file name extension \*.elt is generated. You can also delete a temporary reference project in the project management if you do not dispose of the authorization to delete elr projects.

If the check box is deactivated, a "normal" reference project with the file name extension \*.elr is generated. Such a project can only be deleted in the project management by users with the authorization to delete elr projects.

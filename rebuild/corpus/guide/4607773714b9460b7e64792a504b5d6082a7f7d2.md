# P004036: Unknown logical network '<x>' (bus port in the bus system: <y>')

### Cause

At a bus port that is the slave within a bus system the name of a logical network was entered, for which no bus port was found that is identified as a master.

![](../Pictures/Gui/ALL/note.png)Note:

This check run only checks bus ports at which the Configuration project (automatic, at bus ports) property is filled.

### Solution

1. Create a bus port as a master with a corresponding logical net name or specify a logical net name that already exists at the bus port.
2. Update the connections.
3. If required, start a new check run.

# Creating Settings Comparison Schemes

In a settings comparison scheme you specify which settings are compared to each other during the project comparison of the project verification. With this scheme Eplan can compare all settings with each other that you can specify for the respective project in the project settings (command path: File > Settings > Projects > "Project name").

Preconditions:

- You have selected a project management database.
- In project management, you have loaded directories and projects.

1. Select the following commands: File > Project management.
2. Select a project.
3. Select [Extras] > Verify project.
4. Click [...] next to the Compare settings check box.
5. Next to the Scheme field click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
6. In the New scheme dialog, enter a meaningful name for the new scheme in the Name field and click [OK].
7. To select the setting for the settings comparison, activate the check box before a setting in the Settings to be compared field.
8. To exclude a setting for the settings comparison, deactivate the check box before a setting in the Settings to be compared field.
9. Click [Save] and then click [OK].

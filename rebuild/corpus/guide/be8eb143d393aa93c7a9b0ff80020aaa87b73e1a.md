# P005033: Designation process of format group no. <x>: First assigned connection designation '<y>', last assigned connection designation '<z>' within the format group

### Description

This message is output as confirmation after each designation run of the connection definition points. You receive information about the number (position) of the format group specified in the table of the Settings: Connection numbering dialog as well as about the first assigned and the last assigned connection designation or the first assigned and last assigned name within the format group.

![](../Pictures/Gui/ALL/note.png)Note:

This module-specific message is output during the numbering of connections. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

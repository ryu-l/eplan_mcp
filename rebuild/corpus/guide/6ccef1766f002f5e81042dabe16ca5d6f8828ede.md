# P026039: Connection runs through invalid routing paths

### Cause

After the routing of a connection, a routing path network object was subsequently deleted, for example a wire duct, a routing path or a curve, through which the connection passed previously.

### Solution

Update the routing path network.

1. Select the following commands: Tab Edit > Command group Routing connections > Generate routing path network.
2. Route the connections again.
3. If required, start a new check run.

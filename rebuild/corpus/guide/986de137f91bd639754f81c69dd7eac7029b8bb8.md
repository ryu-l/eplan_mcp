# P502007: The height, width and / or depth is not specified at the part: Height = <x>, Width = <y>, Depth = <z>

### Cause

In the parts database to be checked a part was found where the mounting information about the Height, Width and / or the Depth is missing.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Properties tab to the front.
3. In the property table expand the following hierarchies: Mounting data > Dimensions.
4. Insert the missing values in the Width, Height and / or Depth properties.
5. Click [Apply].
6. If required, start a new check run.
7. Close the parts management and perform a parts data synchronization.

![](../Pictures/Gui/ALL/note.png)Note:

So that the message is not output anymore at least two of the mounting data listed above need to have values at the part. The exception are parts at which a 3D macro is stored. In this case the values of all these mounting data have to be available.

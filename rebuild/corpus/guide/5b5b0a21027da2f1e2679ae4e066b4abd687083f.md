# P005042: The value of the 'Color / Number' property is a color code or color name that is not contained in the project settings under 'Connection colors'

### Cause

Color codes or color names can be predefined project-specifically in the dialog Settings: Connection colors (command path: File > Settings > Projects > "Project name" > Connections > Connection colors). The value selected by you for the Color / number property is a color code or color name that is not listed in the Connection colors table.

### Solution

#### Possibility 1

Select a color code or color name that is defined in the table of the connection colors:

1. Open the Properties <...> dialog for the corresponding connection or the corresponding connection definition point.
2. Click [...] next to the Color / number field.
3. Select the name of the predefined color codes or color names in the Connection colors dialog that opens and click [OK].

#### Possibility 2

Extend the project-specific connection colors by the color code or color name that you want to use:

1. Select the following commands: File > Settings > Projects > "Project name" > Connections > Connection colors.
2. In the Settings: Connection colors dialog, click ![](../Pictures/Gui/ALL/all_new_as.png) (New) and enter the desired value in the new table row under Color code or Color name.

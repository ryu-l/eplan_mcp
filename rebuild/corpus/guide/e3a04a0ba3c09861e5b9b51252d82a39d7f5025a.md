# P020041: Different layers: Symbol <x> : Property placement <y> : Layer <z> - <u>

### Cause

You have run a project comparison, checking the layers of the test project (incoming project) against those of the comparison project and differences were found.

This message is output when the property placement of a symbol placed in the schematic has a different layer setting to that defined for the same symbol in the symbol library. <x> stands for the name of the symbol, <y> for the name of the property placement, <z> for the layer of the property placement in the symbol library and <u> for the layer of the property placement of the symbol in the schematic.

### Solution

Change the layer of the property placement for the symbol located in the schematic and synchronize the layer of the property placement in the symbol library.

Then start a project comparison or new check run.

# P020035: Terminal  <x> (x Pos <y> : y Pos <z>) : <u>

### Description

You have run a project comparison, checking the Properties of the test project (incoming project) against those of the comparison project and differences were found.

This message occurs when a difference in the properties of a terminal was found. <x> designates the full DT of the terminal concerned, <y> the X position and <z> the Y position in the schematic. <u> indicates whether the terminal has been deleted or added, or if one if its properties has been changed. Testing of the properties of terminals includes both the device and the terminal strip navigator as well as the schematic. If a property of a terminal which has been created in the device or terminal strip navigator but not yet placed in the schematic has changed in the test project, the values for the X and Y position are shown as "0" in the message text.

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

# P024006: Media code does not suit the trade

### Cause

The media code used in the device tag of the fluid device does not suit the selected trade and thus does not conform to the current version of the standard ISO 1219-2. For example, a control valve in a pneumatic circuit is designated with the media code "H" for "Hydraulics", but not with the correct media code "P" for "Pneumatics".

### Solution

1. Locate the fluid device in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Adapt the media code in the device tag of the fluid device norm-compliant to the trade by using the right letter.  
     
   The standard requires the following media codes for the different trades:  
     
   - H for hydraulics  
   - P for pneumatics  
   - C for cooling  
   - K for cooling lubricant  
   - L for lubrication  
   - G for gas engineering.
3. If required, start a new check run.

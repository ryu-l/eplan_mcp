# P007035: No valid counterpiece or number of targets unequal to 1: Connection point '<x>' (Mechanical feedthrough)

### Cause

You have placed a plug-in or bar current transformer in the schematic and to this purpose use one of the symbols "LSW1A", "LSW2A" or "LSW3A" with the function definition "Current transformer, inductive". With regard to the connection point logic, the function connection points "1" and "2" of these functions have a continuous connection that is defined as the connection point type "Mechanical feedthrough".

In the specific case the Connection point type property deviates from the value "Mechanical feedthrough" at least at one of the function connection points so that no valid counterpiece exists. Or the Transfer potential to setting at one of the function connection points has a value that makes the transfer of the potential impossible. The message is also output if a value that does not correspond to "1" has been selected for the property Number of targets.

### Solution

1. Locate the function in the schematic by means of the Go to (graphic) functionality offered by the popup menu of the Message management dialog.
2. Launch the property dialog of the function.
3. Bring the Symbol / function data tab to the front.
4. Click the [Logic] button.
5. In the dialog Connection point logic check and change the values of the following properties at the function connection points "1" and "2":  
   - Connection point type: Select the "Mechanical feedthrough" entry for both function connection points.  
   - Transfer potential to: Enter a "2" at the function connection point "1" and a "1" at the function connection point "2".  
   - Number of targets: Set the value "1" at both function connection points.
6. Click [OK].
7. If required, start a new check run.

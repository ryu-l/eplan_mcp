# Dialog Test input

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Tab Tools > Command group Translation > Test input.

If you want to test individual words and terms you have to first create a test project. In this dialog you can test translate texts and thus check your translation settings.

Overview of the main dialog elements:

Input field:

In this field you can input the project text to be translated. The list below it contains all of the translation languages that you selected in the [Project](translategui_r_einstellungprojekt.htm#Uebersetzungssprachen) tab in the Translation languages field.

[Translate]:

If you click this button the project text will be test translated. The project text must be in the dictionary as a keyword and there must be translation texts available for the desired languages.

Output list:

This list displays the translation texts that Eplan found for the project text. This field contains all of the translation languages that you selected in the [Project tab](translategui_r_einstellungprojekt.htm#Uebersetzungssprachen) in the Translation languages field.

| Result | Check | Change |
| --- | --- | --- |
| No translation text was output for one translation language. | The correct dictionary is selected in the [User](translategui_r_einstellungbenutzer.htm#Woerterbuch) tab. | Select the desired dictionary in the [User](translategui_r_einstellungbenutzer.htm#Woerterbuch) tab. |
|  | The translation language is in the selected dictionary as a dictionary language ([User](translategui_r_einstellungbenutzer.htm#Woerterbuchsprachen) tab). | [Select dictionary language](translatedbgui_h_woerterbuchanlegen.htm) |
|  | The project text that you want to test is entered in the dictionary as a keyword. | Find a keyword  [Create a keyword](translatedbgui_h_stichwortanlegen.htm) |
|  | The correct translation texts are assigned to the keyword in the dictionary. |  |

[Settings]:

This button takes you to the project- and user-specific translation settings.

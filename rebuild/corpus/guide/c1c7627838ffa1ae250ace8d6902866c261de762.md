# P020017: <x> (value <y>) <z> -> <u>

### Description

You have executed a project comparison in which the settings of the project to be checked (incoming project) are to be compared with those of the comparison project in order to determine any differences. In this message, <x> represents the file path to the project setting where there are differences between the project to be checked and the comparison project. <y> shows the value number or value position of the respective setting. <z> shows the value of the setting in the comparison project, <u> the value in the project to be checked.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

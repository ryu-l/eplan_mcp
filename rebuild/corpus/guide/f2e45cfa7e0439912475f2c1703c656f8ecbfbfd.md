# Automatically Assigning Cable Connections

Two different possibilities are available in the Connections tab of the ribbon for automatically assigning the connections of a cable part to cable connections:

- The Reassign all command overwrites all connection properties with the properties from the part. Only the potential type is compared.
- The command Keep existing properties leaves existing connection properties unchanged. The assignment only occurs when all identifying properties of the cable connections match those of the part connection.

The sequence of the cable connections for the selected cables is resorted during this. The [Sorting of cable connections](cablegui_k_quellezielermittlung.htm#I_Sortierung) defines the sequence in which the cable connections are assigned. The sorting depends on the source of the cable. This means that the devices of the source are decisive for the order of the cable connections. If the device is a terminal strip, the order of the connections is determined according to the order of the terminals on the terminal strip.

![](../Pictures/Gui/ALL/info.png)Tip:

In the navigator dialog Cables- <Project name> and in the Edit cable dialog the commands Reassign all and Keep existing properties are additionally available below the popup menu item Assign cable connections.

Preconditions:

- You have selected a cable definition line in the graphical editor or a cable definition in the Cables - <Project name> navigator dialog.
- The cable is already assigned a part.

### Reassign all cable connections

1. Select the following commands: Tab Connections > Command group Cables > Reassign all.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connections of the cable part are assigned to the cable connections, if the potential type matches. Existing properties of the cable connections are overwritten by the part properties.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The data at the connection definition points are correspondingly updated. Existing data are overwritten. New data are only written to the connection definition points if these are not yet entered at the associated cable definition line / shield.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The organization of shields is retained, but the shield designations can change.

### Assign cable connections with suitable properties

Identifying properties for the assignment:

- Function definition
- Shield designation (shielded by)
- Pair index
- Potential type
- Color / number
- Cross-section / diameter.

Rules for the assignment:

- If a property of the part connection is filled in, the cable connection must have the same value.
- Blank properties of the part connection match any value on the cable connection.
- Shielded conductors also match non-shielded connections; however, if a matching shielded connection has already been found, it will be assigned preferentially.

1. Select the following commands: Tab Connections > Command group Cables > Drop-down button Reassign all > Keep existing properties.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connections of the cable part are assigned to the cable connections if their identifying properties match.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Existing properties of cable connections are retained, additional properties of the cable part are supplemented.

# Dialog Export Eplan Smart Production

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Export > Command group Manufacturing data > Manufacturing data > Smart Production.

In this dialog you can specify the settings for the export of a project to the "EPDZ" format for reading into the application Eplan Smart Production.

Overview of the main dialog elements:

Source:

This field displays the project name of the project to be exported. The entry in this field cannot be edited.

EPDZ file:

Enter the file name into this field or click ![](../Pictures/Gui/ALL/all_selectfile_as.png) to interactively select the file name and overwrite it, if necessary.

Output directory:

Enter a storage location in this field. The ![](../Pictures/Gui/ALL/all_selectdirectory_as.png) button opens the dialog Select folder in order to select any directory of your choice for the storage location.

# Synchronizing Stored Parts with the Parts Database

Stored part properties are a fixed component of the project, while non-stored properties must be accessed through parts management.

The configuration of commercial data for part selection also applies to device selection, i.e., there is only one common configuration.

### Update parts in project

  

Select the following commands: Tab Master data > Command group Parts > Update.

![](../Pictures/Gui/ALL/arrow.png) The parts stored in the project are updated with data from the internal parts database.   
  
![](../Pictures/Gui/ALL/arrow.png) If the setting [Update device data after the storing of parts](partselectiongui_d_datenauswahlbenutzer.htm#GeraetedatenAktualisieren) is activated, the newer device data from the Function templates is additionally transferred to the main functions that use these parts.  
  
![](../Pictures/Gui/ALL/arrow.png) Any messages are written to message management.

### Synchronizing parts

1. Select the following commands: Tab Master data > Command group Parts > Synchronize.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The [Synchronization of parts - <Project name>](partsextensiongui_d_artikelabgleich.htm) dialog is opened.
2. Select the required filter from the Filter drop-down list. You can either display the parts that are different in the project and / or system master data or only the older project master data or only the older system master data.
3. In the Stored parts list highlight the parts that you want to carry over to the system master data and click the arrow button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts stored in the projects are carried over to the internal parts database. During this process, the function templates of the stored parts are stored into the parts in the internal database.
4. In the System parts list highlight the parts that you want to store in the project and click the arrow button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected parts are stored in the project.   
     
   ![](../Pictures/Gui/ALL/arrow.png) If the setting [Update device data after the storing of parts](partselectiongui_d_datenauswahlbenutzer.htm#GeraetedatenAktualisieren) is activated, the newer device data from the Function templates is additionally transferred to the main functions that use these parts.

![](../Pictures/Gui/ALL/warning.png)Warning:

When carrying over the stored parts to the system master data, only the parts not yet available in the parts database are synchronized. Already existing parts are not updated.

![](../Pictures/Gui/ALL/info.png)Tip:

You can replace all of the out-of-date stored parts with newer system parts via [Extras] > Update current project.  
You can use [Extras] > Complete current system to complete the system master data by all the parts stored in the project that do not yet exist in the system.

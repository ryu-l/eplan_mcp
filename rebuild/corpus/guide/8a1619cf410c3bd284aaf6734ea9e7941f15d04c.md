# P008004: The text '<x>' cannot be translated

### Cause

The keywords for the text '<x>' that are required for the translation are not available in the dictionary.

### Solution

1. Add the missing texts as new [Keywords](translatedbgui_h_stichwortanlegen.htm) in the dictionary. Take the [project-specific settings](translategui_r_einstellungprojekt.htm) for the type of segmentation into account for the translation.
2. If required, start a new check run.

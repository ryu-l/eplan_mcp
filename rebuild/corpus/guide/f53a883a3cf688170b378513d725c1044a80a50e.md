# Notes for the Reader

Important information:

- Before installing the version, please note the information on the software requirements and hardware requirements in the Eplan Information Portal:   
  <https://www.eplan.help/en-us/infoportal/content/swreqs/Content/htm/SwReqs_k_home.htm>
- If you want to use old projects that were created with previous Eplan versions in Eplan Version 2026, these projects have to be updated. For further information read the section [Updating the Project Databases](news_p_projekte_datenbankaktualisieren_504102.htm).
- If you want to use an "older" parts database, you will first have to update such a parts database. For further information read the section [Updating the Parts Database](news_p_artikelverwaltung_datenbankaktualisieren_504217.htm).
- We used "Eplan Electric P8" when creating the images for the news. If you use a different program of the Eplan Platform, a different program icon will be displayed in the dialog of your program.

Before you begin reading, please note the following symbols and styles used in the news:

![](../Pictures/Gui/ALL/warning.png)Warning:

Text preceded by this symbol contains a warning; you should be absolutely sure to read this warning before proceeding!

![](../Pictures/Gui/ALL/note.png)Note:

Text preceded by this image contains extra notes.

![](../Pictures/Gui/ALL/info.png)Tip:

Useful tips to facilitate your interaction with the program are presented after this image.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Examples are highlighted by this symbol.

- User interface elements are marked in bold (and blue) so they can immediately be located in the text.
- bold text provides particularly important information that you should definitely pay attention to.
- Code examples, directory names, and direct input (among others) are displayed in a non-proportional font.
- Function keys, keyboard keys, and buttons within the program are shown in square brackets (e.g., [F1] for the "F1" function key).

- To improve the flow of the text, we often use "command paths" in the news (for example File > Help > Command group Support > Contents > Help system). In order to find a particular program function, the commands and options shown in the command path must be selected in the specified sequence. For example, the command path mentioned above calls up the Eplan help system.
- In combination with settings or fields (e.g., check boxes) which can only be switched on or off, we often use the term "activate" (after which the setting is active ![](../Pictures/Gui/ALL/all_checkon_as.png)) and "deactivate" (after which the setting is inactive ![](../Pictures/Gui/ALL/all_checkoff_as.png)). in the news.

# P007025: The DT ID '<x>' has been assigned several times

### Cause

A DT ID which has already been assigned was determined at a function which is a component of a macro for a module.

### Solution

1. Locate the function in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Launch the property dialog of the function.
3. Change the value of the DT ID property In the properties table. Enter a value which has not been assigned yet.
4. If required, start a new check run.

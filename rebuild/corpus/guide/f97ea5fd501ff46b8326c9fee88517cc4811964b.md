# Exchange of Hose Line Data

Hose line data can be imported and exported by means of the hose line configurator.

The data exchange is carried out by means of a tab-separated Unicode text file (\*.txt). This exchange file can also be opened in other applications such as Excel, if necessary revised, stored and read back into the hose line configurator.

# Showing Property Names

If you have placed certain properties on a project page, by default the values of these properties are displayed. The user setting Show property names is available to make the property names visible instead of the values (such as DT (displayed), Connection: Cross-section / diameter with unit) and to allow individual placement: If this setting is activated, then all property names are displayed for all placed properties in all projects and the assigned values are hidden. This is especially useful when editing the properties of macros on a mounting panel.

1. Select the following commands: File > Settings > User > Graphical editing > 2D.
2. Activate the Show property names check box.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property names are displayed in all projects instead of the property values.

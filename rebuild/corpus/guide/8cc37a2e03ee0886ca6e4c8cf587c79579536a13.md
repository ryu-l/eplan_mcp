# P004058: Accessory part '<x>' at function '<y>' is only available in the project

### Cause

When importing an AML file it was determined in the project that an accessory part '<x>' exists at the function '<y>' that does not exist in the import file.

### Solution

1. Locate the function in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Check whether the accessory part is still required.
3. If not, delete it at the function.
4. Import the AML file again.

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

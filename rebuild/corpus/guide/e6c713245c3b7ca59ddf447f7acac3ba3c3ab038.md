# Network Structures

The use of bus systems for measurement, regulation and controlling technology is an essential part of modern plant construction.

In Eplan, the most diverse range of network structures can be easily shown using PLC boxes, bus ports, connection symbols and cable definitions, which you insert on schematic pages in single-line or multi-line representation.

Often, standard cables for connections are used between individual bus participants which, for reasons of simplicity, are displayed only in single-line form and often with bundle connection points. The detailed structure of such cables, including the required terminal wiring (e.g. plugs), is displayed by so-called [Cable assignment diagrams](cablegui_k_kabeldarstellungsplan.htm), which you can also generate using Eplan. In addition to the cable graphics, these plans also contain tabular overviews in which you can store information about the usage of cables in project, part, and manufacturing data (e.g. cable type and length specifications).

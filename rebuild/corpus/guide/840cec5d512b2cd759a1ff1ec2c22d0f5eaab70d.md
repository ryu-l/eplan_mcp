# Dialog Select increment

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a project page in the graphical editor. Tab Edit > Command group Options > Increment.

The increment defines how far the cursor jumps in a particular direction when the arrow key is pressed. It is set and activated from the current cursor position.

Overview of the main dialog elements:

Current increment:

When the dialog is called up, the current increment is displayed. Enter the desired increment in the X and Y fields.

Use graphical coordinates:

Select this check box to display the increments for Graphical coordinates in the list fields. These increments are specified in drawing units (mm or inch).  
Deactivate the check box to display the increments for logic coordinates. These increments are entered in grid increments.

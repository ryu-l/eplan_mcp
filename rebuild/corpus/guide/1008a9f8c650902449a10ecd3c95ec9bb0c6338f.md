# Report Templates

Report templates allow settings for reports to be saved and used again. You can generate reports on the basis of report templates. All settings already specified in the report templates are used for these reports. Report templates can be imported and exported as \*.xml files.

If you generate an existing report again from a report template, the existing report is deleted and a new report is generated.

![](../Pictures/Gui/ALL/info.png)Tip:

It is possible to create several report templates for the same report type. If an existing report template (with the name 0001) already exists, a prompt is displayed when another template of this type is created, asking whether the old template should be overwritten or not. If you select [No], two templates with the same name are generated whose names still have to be changed.

### Conditional reports

Report templates can be used to generate reports depending on project properties. To this purpose you define a project filter and assign it to the report template. When reporting only one report is generated from the report template if the current project fulfills the filter criteria of the project filter.

![](../Pictures/Gui/ALL/example.png) [![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

This functionality is useful, for example, if you create two projects for different project planning tasks from a basic project (as a common standard):

Setting up a basic project

- For the first project EPLAN\_Demo you create a report template for a title page / cover sheet with form A in the basic project. This report template is called Title\_EPLAN\_Demo.
- For the second project EPLAN\_Test you create a report template for a title page / cover sheet with form B in the basic project. This report template is called Title\_EPLAN\_Test.
- In a project filter you define a project property as a filter condition and assign the project filter to the Title\_EPLAN\_Demo report template.

Creating projects

- You create both the EPLAN\_Demo project and the EPLAN\_Test project from the basic project.
- In order to differentiate between the two projects during reporting, assign the project property that you specified as a filter condition in the project filter to the first project EPLAN\_Demo.

Generating project reports

- If you generate a report for the EPLAN\_Demo project on the basis of the report templates, Eplan uses the report template Title\_EPLAN\_Demo and generates a title page from form A.
- When you generate a report for the EPLAN\_Test project, Eplan uses the report template Title\_EPLAN\_Test and generates a title page from form B.

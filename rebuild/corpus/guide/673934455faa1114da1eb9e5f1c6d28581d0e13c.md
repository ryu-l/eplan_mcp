# Action: RegisterScript

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| ScriptFile | File name of the script with complete file path. Two types of script can be used: C# (\*.cs) and VB.NET (\*.vb). |
| RegisterAgain | Allows the script to be registered again (optional, 0 = No, 1 = Yes). |
| ShowDecider | Displays a query as to whether the script is to be registered again (optional, 0 = No, 1 = Yes). This parameter is ignored, when the "RegisterAgain" parameter has the value "1". |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
RegisterScript 
/ScriptFile:"C:\myScript.cs"
```

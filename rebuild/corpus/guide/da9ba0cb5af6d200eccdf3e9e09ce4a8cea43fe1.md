# Display Properties: Line

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc. You have marked a line and selected the popup menu item Properties, or you have double-clicked a line. In the table of the Properties (Line) dialog expand the hierarchy level Line.
- You have opened a project. You have opened a project page in the graphical editor. You have inserted a cable definition line or double-clicked on a cable definition line. In the Properties <...> dialog select the Format tab and, in the table, expand the Line hierarchy level.

Below this hierarchy level you can edit the settings specific to lines and cable definition lines.

Overview of the main dialog elements:

Starting point / End point:

The fields below these hierarchy levels display the coordinates of the starting and end points of the line and let you determine whether the line has arrows on its ends or not.

Angle:

The line will be drawn at this angle to the X axis.

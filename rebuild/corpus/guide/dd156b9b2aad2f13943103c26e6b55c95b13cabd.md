# P013046: Unknown DT '<x>'

### Cause

You have imported a bill of materials into your project. A device tag that is specified in the imported bill of materials could not be found in the project.

### Solution

1. Open the import file used in a text or XML editor.
2. Compare the device tags specified in the import file within the XML tag "<device\_P\_ARTICLEREF\_IDENTNAME>" with the device tags that appear in the schematic for your project.
3. When you have identified the discrepancy, change the device tag in the schematic to match the device tag in the import file.
4. Save the file, then import the bill of materials again.

# Functions

In Eplan, the logical and graphical data are managed separately. Logical data is stored in the function definitions, graphical data in the symbols. This separation is significant when working with an engineering approach and offers a number of additional advantages for a modern CAE product (such as standards independence).

Eplan supports both a symbol-oriented drawing approach (copy pages, add macros, place symbols, etc.) as well as a device-oriented approach based on an engineering approach (working with devices, predefined listed, navigators, "use existing", etc.).

If you work according to the symbol-based approach, you do not need to worry about functions and function definitions. Function definitions are already assigned to the symbols in the standard symbol libraries. You simply place a symbol or a macro and the default assigned function definitions are automatically added.

If you work according to the device-oriented engineering approach or want to modify reports, numbering, etc., however, it is necessary to understand the concept of functions.

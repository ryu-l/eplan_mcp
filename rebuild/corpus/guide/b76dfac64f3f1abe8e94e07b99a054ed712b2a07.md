# Dialog Tree configuration - main node

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Tab Master data > Command group Parts > Management. Button [Extras] > Settings.
- File > Settings > User > Management > Part.

Click [...] in the Tree configuration field. In the dialog Tree configuration click the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button in the toolbar above the list of main nodes, or select the row of an already defined main node and click the ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit) button.

In this dialog you define the configuration of individual main nodes in the parts management tree view.

Overview of the main dialog elements:

Record type:

Select from this drop-down list the type of cross-part data (such as customer, drilling patterns, etc.) to be used for a main node of the tree view. The respective record type for which a main node has been created is displayed in the Tree configuration dialog in the Record type column.

Name:

Enter the name of the main node here, as it is to be displayed in the parts management tree view.

Filter:

This field shows the filter you have defined via [...] in the Filter dialog.

Properties:

This list contains the properties assigned to the current main node. The properties are dependent on the record type selected in the Record type field.

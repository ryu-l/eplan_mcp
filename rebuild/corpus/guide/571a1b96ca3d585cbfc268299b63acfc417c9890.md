# Tab "Handle" / Tab "Mounting grid"

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a layout space. The layout space contains 3D objects. A handle or a mounting grid has been defined on a 3D object. Select the handle or the mounting grid and then select the popup menu item Properties. Or double-click the handle or the mounting grid.

In this tab you set the properties of a handle / mounting grid.

Overview of the main dialog elements:

Name:

Enter the name of the handle / mounting grid here.

Description:

Enter a description text for the handle / mounting grid here.

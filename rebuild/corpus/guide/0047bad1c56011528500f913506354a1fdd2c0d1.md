# Dialog Change of the property

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have opened a dynamic form (for example via the following commands: Tab Master data > Command group Plot frames / forms > Drop-down button Form > Open > [Open]). Tab Insert > Command group Text > Drop-down button Forms > Conditional area. You have drawn the conditional area as a rectangle. Double-click in the rectangle and select the Conditions tab in the properties dialog. In the If property is changed field, click [...].
- Tab Master data > Command group Plot frames / forms > Drop-down button Form > Open > Button [Open]. You have marked the form in the page navigator and opened the Form properties <Form name> dialog via the popup menu item Properties. You have clicked [...] for the property Regenerate header after change in the Value field.

In this dialog, you select the properties for which the conditional area / data header area is reported when they are changed.

Overview of the main dialog elements:

Property:

Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the toolbar above the list to open the Property selection dialog and select the properties for which the area/data header area is reported when they are changed. For example, for a device tag list, you can specify that a thick line is drawn before the next DT, or a new main header is generated, each time the DT (displayed) property is changed.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

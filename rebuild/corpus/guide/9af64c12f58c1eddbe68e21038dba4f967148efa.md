# Verifying a Project

During the project verification compare the settings and properties of the comparison project and incoming project to each other. Similarly, check runs are carried specifically for the incoming project.

Preconditions:

- You have selected a project management database.
- In project management, you have loaded directories and projects.
- The loaded directory contains the returned incoming project.
- You have access to the original project that you want to use as the comparison project.

1. Select the following commands: File > Project management.
2. In the project management mark the project that contains the advanced project status.
3. Select [Extras] > Verify project.
4. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) next to the Select comparison project field.
5. In the subsequent dialog select the original project which is the comparison project and click [Open].
6. To perform a project-specific settings comparison during the project verification, activate the check box Compare settings and select an existing comparison scheme from the Scheme drop-down list below.  
     
   ![](../Pictures/Gui/ALL/arrow.png) You can [Create a settings comparison scheme](processreceiptcontrol_h_vergleichsschema.htm) via [...].
7. To perform a property comparison during the project verification, activate the check box Compare properties and select an existing comparison scheme from the Scheme drop-down list below.  
     
   ![](../Pictures/Gui/ALL/arrow.png) You can [Create a property comparison scheme](processreceiptcontrol_h_eigenschaftenvergleich.htm) via [...].
8. To perform project checks during the project verification, activate the Perform project checks check box and select an existing check run scheme from the Scheme drop-down list below.  
     
   ![](../Pictures/Gui/ALL/arrow.png) You can create a new [Error check scheme for project verification](processreceiptcontrol_h_pruefschema.htm) via [...].
9. To compare the project structures of the two projects to each other, activate the check box Compare project structures.
10. To stop the project comparison when the first difference is found, activate the check box Stop comparison when first difference is found.
11. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The projects are compared to each other and the specified error checkings are performed.  
      
    ![](../Pictures/Gui/ALL/arrow.png) In the Project verification: Results dialog, Eplan automatically displays the overall result of the project verification.  
      
    ![](../Pictures/Gui/ALL/arrow.png) Detailed results are listed in the message management (command path: Tab Tools > Command group Verify > Messages).

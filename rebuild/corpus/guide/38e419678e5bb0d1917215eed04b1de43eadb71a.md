# Placing mounting panels (2D)

When placing mounting panels on a "Panel layout" type page, a distinction is made between placing a device via the Insert center and "free" placement using the property dialog.

### Placing mounting panels as devices via the Insert center

Preconditions:

- You have opened a project.
- You are in the graphical editor on a "Panel layout" page.

1. Select the following commands: Insert center > Breadcrumb trail Home > Devices.
2. Further navigate via the folders Mechanics > Component > Housing > Mounting panels to the desired mounting panel manufacturer.
3. Select the desired mounting panel in the preview tile.
4. Move the cursor into the project page and click the left mouse button briefly at the position where you want to place the mounting panel.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The properties dialog is opened.
5. Enter a device tag in the Displayed DT field on the Mounting panel tab.
6. If necessary, assign further properties to the mounting panel.
7. Click [OK].

### Placing free mounting panels

Preconditions:

- You have opened a project.
- You are in the graphical editor on a "Panel layout" page.

1. Select the following commands: Tab Insert > Command group 2D panel layout > Mounting panel (2D).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The box symbol that displays the mounting panel is hanging on the cursor.
2. Drag open a rectangle that represents the mounting panel at the desired position.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Properties <...>: Mounting panel dialog opens.
3. Click the left mouse button briefly.
4. Enter a device tag in the Displayed DT field on the Mounting panel tab.
5. If necessary, assign further properties to the mounting panel.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The mounting panel is created.

# Dialog Calculate power dissipation

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the layout space navigator and a layout space. The layout space contains at least one enclosure or a mounting panel that has the Power dissipation: Air-conditioning field property. Tab Tools > Command group Reports > Drop-down button Generate project reports > Calculate total power dissipation.

In this dialog you can select the air-conditioning fields in the project for which the total power dissipation of all the devices and busbars contained in it and can start the calculation.

Overview of the main dialog elements:

Display all the air-conditioning fields existing in the project:

After the call-up only those air-conditioning fields that are contained in the opened layout space are listed. If this check box is active, all the air-conditioning fields contained in the other layout spaces of the project are displayed in the list positioned below.

Air-conditioning field:

The air-conditioning fields of the opened layout space or of the entire project are displayed in this field. If the check box before an air-conditioning field name is deactivated, this air-conditioning field is excepted from the calculation of the total power dissipation.

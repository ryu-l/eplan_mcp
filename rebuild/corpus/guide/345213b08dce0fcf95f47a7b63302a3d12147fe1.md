# P026020: The function definition of the part placement does not suit the part

### Cause

The function definition selected for the part placement in the layout space and for the selected part (in the function template of the main function) in the schematic are different.

### Solution

1. Select the message in the Message management dialog and locate occurrences of the device in the project using the Go to (cross-referenced) or Go to (all representation types) functionality.
2. The Search results - <Project name> dialog opens. In the Object column of the table, check the texts displayed that correspond to the function definitions.
3. Standardize the function definition texts, by changing either the function definition of the part placement in the layout space or the part placed in the schematic. To do this, double click the desired entry in the Search results - <Project name> dialog; and modify the function definition accordingly in the Properties <...> dialog.
4. Click [OK].
5. If required, start a new check run.

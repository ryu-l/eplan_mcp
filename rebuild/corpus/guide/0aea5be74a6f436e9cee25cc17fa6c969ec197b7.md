# P022026: Text is displayed truncated

### Cause

A text that is displayed truncated with an activated alignment box was found on a project page.

### Solution

First locate the text in the project by using the Go to (graphic) functionality from the popup menu of the Message management dialog.

Several solution options are available. These are described below:

#### Possibility 1

You enlarge the alignment box.

1. Mark the text on the project page so that the element points of the alignment box become visible.
2. Position the cursor on one of the element points, press the left-hand mouse button and drag the alignment box in the desired direction until the text lies completely within the alignment box.

Alternatively you can also change the size of the alignment box by using the Width and Height format properties in the dialog Properties <...> of the text.

#### Possibility 2

You reduce the font size of the text.

1. Call up the Properties <...> dialog of the text and bring the Format tab to the foreground.
2. Reduce the value entered in the Font size field until the text fits in the alignment box.
3. Close the Properties <...> dialog by clicking [OK].

#### Possibility 3

Fit the text in the alignment box.

1. Call up the Properties <...> dialog of the text and bring the Format tab to the foreground.
2. Activate the Text fitting permitted check box.
3. Close the Properties <...> dialog by clicking [OK].
4. If the text is located on a schematic page, select the command Fit texts in alignment boxes. (To this purpose you first have to [Customize the ribbon](userinterface_h_menuebandanpassen.htm) and then assign the desired command to a user-defined command group.)  
   If the text is located on a report page, generate the report again.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The size of the text is adapted automatically to the size of the alignment box.

If required, start a new check run.

# P005013: Targets have differing connection point types

### Cause

Targets of a connection have different connection point types for their function connections. For example, one target has the connection point type "Conductor / wire" while the other target is equipped with the connection point type "Optical fiber".

### Solution

1. Enter the same connection point type for all function connections that are targets of the connection.
2. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

The connection point type "Undefined" can be used for all connection points.

# Dialog Configure hose lines

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have marked hose lines on a fluid power schematic page. Select the command Hose lines. (To this purpose you first have to [Customize the ribbon](userinterface_h_menuebandanpassen.htm) and then assign the desired command to a user-defined command group.)

This dialog contains an overview in table form of the read-in or edited hose line data.

The following is possible:

- You can use this dialog to create new hose lines. In addition you can copy the technical data of a hose line already configured and assign it to a newly created hose line.
- It is possible to mark several table cells at the same time and thus configure several hose lines simultaneously in the editing dialog.
- In addition it is possible to import hose line data from other applications, for example Excel, and to store the changed data back in an exchange file or to export it.
- You can furthermore use the dialog to call up the settings for the hose line configurator.

Overview of the main dialog elements:

Table:

The table displays the configuration data of the hose lines. These consist of the technical, identification-specific and part-specific information including the type code. The displayed data of a hose line can be edited by using the popup menu or by double-clicking a table row. The table furthermore offers the possibility to modify several marked hose lines simultaneously (block editing).

---

[Extras]:

| Menu item | Meaning |
| --- | --- |
| Import | Opens the Open dialog for the import of hose line data that were stored in an exchange file. In this dialog you specify the name and the location of the exchange file to be opened. Only tab-separated Unicode text files (\*.txt) can be selected. |
| Export | Opens the Save as dialog for the export of the hose line data into an exchange file that can be read in by a different application. In the dialog you specify the name and the storage location under which you wish to store the edited hose line data. The data are stored in a tab-separated Unicode text file (\*.txt). |
| Settings | Opens the dialog Settings: Hose line configurator in which you can save the properties and values for the configuration of the hose lines and save them as a scheme. |

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Select all | Selects all of the entries in the table. |
| Adjust column width | Adjusts the width of all table columns so that both the headings and column contents are fully legible. |
| Copy | Copies all the hose lines into the Clipboard in order to also make the data available to other applications. |
| Paste technical data | Pastes the technical data of the previously copied hose into a new row.  Notes:   - If the selected row already contains data of a hose line, this information is overwritten without any query with the exception of the full DT. - This menu item is only available if exactly one hose line was copied before using the Copy menu item. |
| Edit | Opens the Edit dialog in which you can configure one or more marked hose lines. |
| New | Creates a new table cell for a hose line through which you can configure a new hose line. |
| Update | Recalculates the type code and the hose line identification for all the marked hose lines. Execute this menu item whenever you have modified type-code-relevant properties, for example the hose line length, or identification-relevant properties, for example the value for the working pressure, at one or more hose lines in the schematic. |
| Delete | Deletes the marked hose lines without prompt. |

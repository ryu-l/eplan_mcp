# P502027: Connection point data at the bus port are filled

### Cause

In the parts database to be checked a part was found at which a function template is defined with the "Network / bus cable connection point" function definition. At this function template values are assigned to the connection point data (connection point designations, connection point descriptions, connection point cross-section and / or connection dimension).

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Function templates tab with the Device selection (function templates) table to the foreground.
3. Delete the values in the Connection point designations, Connection point descriptions, Connection point cross-section and Connection dimension columns at the function template of the bus port.
4. Click [Apply].
5. If required, start a new check run.
6. Close the parts management and perform a parts data synchronization.

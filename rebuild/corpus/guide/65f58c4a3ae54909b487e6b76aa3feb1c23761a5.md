# Cleaning up projects

In the course of project planning, project data are often generated which have to be corrected when planning is finished. Therefore you can start correction runs that automatically correct specific errors at specific data (terminals, plugs, etc.). Only multi-line functions are taken into account here.

- You can decide what project data should be corrected.
- Project data are compressed for the entire project. You can define a filter to exclude project data from the correct or to correct only selected hierarchy levels.
- The settings for the scope of correction are stored in schemes. This allows you to save the settings you use most often for easy reuse.

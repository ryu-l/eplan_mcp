# Dialog Place connection definition points

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have selected a connection in the graphical editor, or in the Connections - <Project name> navigator dialog. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog. Tab Connections > Command group Connections > Place definition points.

In this dialog you begin the connection numbering for the selected connections, pages, or the entire project.

Once you have called up the menu item, the connections are first automatically newly generated.

Overview of the main dialog elements:

Settings:

Select a scheme defining the settings for the connection numbering from the drop-down list. Use [...] to open the Settings: Connection numbering dialog. Define the numbering settings and store them in a scheme.

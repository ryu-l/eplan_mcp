# Tab Settings (CadCabel)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > Company > Wire fabrication > CadCabel > Tab Settings
- File > Export > Command group Manufacturing data > Wire fabrication > CadCabel. Click [...] next to the Scheme field. Select the Settings tab.

In this tab, information on the technical options of the machine to be used is stored. The individual settings are pre-set with appropriate values in a machine-specific manner, and can be modified here.

Overview of the main dialog elements:

Wire length minimum:

Minimum length the machine requires to handle the wire as defined (default value: 230 mm). Shorter wires are transferred to the machine with this minimum length.

Wire length maximum:

Wires that are longer than specified here cannot be processed by the machine (default value: 15,000 mm).

Conductor cross-section maximum:

Maximum cross-section of a wire that the machine can still process (default value: 16 mm²).

Number of wires per bundle maximum:

Number of wires that the machine can combine into a bundle (default value: 32).

Total conductor cross-section maximum:

Limit value for the sum total of cross-sections of all wires (default value: 80 mm²).

Continuous text from wire length:

Length from which wires are to be printed with endless text. If no value is entered, all wires will be printed with endless text.

Routing direction up / down / left / right:

Texts that are to be printed on the wire to indicate individual routing directions.

# Action: generatemacros

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| PROJECTNAME | Project name with complete file path (optional). If nothing is entered, the selected project will be used if the action is to be run over the user interface (e.g. via the script or ribbon). When executing from the Windows command line, PROJECTNAME must be specified or ProjectAction has to be used before that. Otherwise a system message will appear. |
| PAGENAMEn | Names of the pages to be considered (optional). Here, n is a number (for example /PAGENAME1:=AP+ST1/2 /PAGENAME2:=AP+ST1/4 /PAGENAME3:=AP+ST1/7, etc.). |
| INSTALLATIONSPACENAMEn | Names of the layout spaces to be considered (optional). Here, n is a number (for example /INSTALLATIONSPACENAME1:BR1 /INSTALLATIONSPACENAME2:BR2 /INSTALLATIONSPACENAME3:BR3, etc.). |
| STRUCTUREn | Structure identifier of the layout spaces to be considered (optional). Here, n is a number (e.g.  /INSTALLATIONSPACENAME1:BR1  /STRUCTURE1:=EB3+ET1 /INSTALLATIONSPACENAME2:BR2 /STRUCTURE2:=EB3+ET2 etc.). |
| WINDOWMACRODIR | Directory for window macros (optional). |
| PAGEMACRODIR | Directory for page macros (optional). |
| FILTERSCHEME | Filter scheme (optional). Default value: most recently used filter scheme. When transferring an empty string the most recently used scheme is used. |
| OVERWRITE | Overwrite mode (optional). |

![](../Pictures/Gui/ALL/note.png)Note:

Only such projects where the Type of project property is set to "Macro project" are taken into consideration.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Generate macros:

```
generatemacros 
/PROJECTNAME:C:\Projects\EPLAN\EPLAN_Sample_Project.elk
```

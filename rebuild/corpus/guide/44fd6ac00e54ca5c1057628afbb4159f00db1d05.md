# P017009: DT customization due to updated DT calculation, old DT: <x>, new DT: <y>

### Description

During planning, it may happen that two black boxes, a black box and a PLC box or a black box and a "normal" component are positioned in the schematic in such a way that the insertion point of the second black box or the PLC box or the "normal" component comes to rest exactly on one of the border lines of the (first-placed) black box.

In Eplan version 2.1 and earlier Eplan versions, such a component positioning, in a black box type-dependent manner ("DC2 /46 /Polyline" or "DC /0"), led to deviating display results regarding the complete device tag, which was due to the different behavior in the nesting of the two black box types.

The program behavior was changed only to the extent that, when opening such a project, the complete device tags with black boxes of nested black boxes or PLC boxes or "normal" components were automatically determined as new and changed. If the program has done a DT customization, this is documented in the message management, with the old and new DTs being named.

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

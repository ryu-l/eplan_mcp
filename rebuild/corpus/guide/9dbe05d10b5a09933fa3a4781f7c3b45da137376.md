# Tab Fins (Export Rittal - Perforex LC / Secarex)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > Company > Machining > Export Rittal - Perforex LC / Secarex. Select the Fins tab.
- File > Export > Command group Manufacturing data > Machining > Rittal - Perforex LC. Click [...] next to the Machine field. Select the Fins tab.

In order to prevent damage arising when large milled rectangular surfaces fall down, such surfaces can be divided by fins. This creates smaller milling areas. The resulting fins are broken out during the mounting. All settings regarding fin generation are specified in this tab.

Overview of the main dialog elements:

Group box Settings for default outlines

Use the default settings or change the values for the individual settings in accordance with your requirements.

Fin width:

A fin width of 0.1 mm is set as standard.

Fin height:

A fin height of 2 mm is set as standard.

Generate one fin if edge length exceeds:

By default, a fin is inserted from a milling length of 100 mm.

Generate two fins if edge length exceeds:

By default, two fins are inserted from a milling length of 250 mm.

Generate three fins if edge length exceeds:

By default, three fins are inserted from a milling length of 500 mm.

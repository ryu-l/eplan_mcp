# P502009: The drilling pattern '<x>' entered at the part does not exist

### Cause

In the parts database to be checked a part was found where a drilling pattern was entered which Eplan cannot find.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Manufacturing tab to the front.
3. Click [...] in the Name (drilling pattern) table column.
4. Select the required drilling pattern from the selection dialog opened.
5. Click [Apply].
6. If required, start a new check run.
7. Close the parts management and perform a parts data synchronization.

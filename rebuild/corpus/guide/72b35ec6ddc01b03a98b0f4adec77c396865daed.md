# Symbols: Procedure

To use symbols for creating and editing schematics, the following steps must be performed:

- Load the symbol library into a project: If you wish to use symbols from a symbol library in a project, then you must first load the symbol library into the project. This links the corresponding symbol library in this project with the master data: File > Settings > Projects > "Project name" > Management > Symbol libraries.
- Select symbols: In the Insert center dialog you can select a symbol by means of different possibilities (e.g. via the search or via defined tags or favorites).
- Place symbols: Once you have selected the desired symbol using the Insert center dialog, you then use the graphical editor to place the symbol on the page. The connection of the newly placed symbol to the other symbols in the schematic occurs automatically via autoconnection.
- Define the properties of the component: Once the symbol has been placed on the page, you use the Properties <...> dialog to define the component-specific properties (for device tag, function text, etc).

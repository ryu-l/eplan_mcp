# Dialog Settings: Conduit

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Settings > Projects > "Project name" > Devices > Conduit.

Use this dialog for the default settings of the symbol that is displayed on the connection definition points for conduit definitions. By default, a symbol without graphic is set, so that the connection definition points placed automatically during the conduit definition are visible only by the insertion points in the graphical editor.

Overview of the main dialog elements:

Number / name:

This field displays the name and number of the current symbol. Click [...] to open the [Symbol selection](xsbgui_d_symbolauswahl.htm) dialog and select a different symbol if necessary.

# Dialog Select trade

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. In parts management (Tab Master data > Command group Parts > Management), there is at least one part with more than one trade assignment. Insert center > Breadcrumb trail Home > Device. In the Insert center dialog, select a part with more than one trade assignment, and place the device.

In this dialog you select the trade the device is to have from the list of trades stored for the part.

Overview of the main dialog elements:

Trade:

This list offers all fluid power trades assigned to the part as well as the additional "Fluid (undefined)" trade for selection.   
 Click on the option of the trade to be assigned to the functions of the device.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

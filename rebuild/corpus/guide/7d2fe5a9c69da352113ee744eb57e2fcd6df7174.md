# Working with Grids in the Layout Space

You can work with a grid also in the layout space to make the positioning of 3D part placements easier. The insertion and element points are then placed on the grid points. While working in the 3D layout space, a line grid is displayed during the placement of 3D part placements. In this case, the insertion points are on the points where the lines cross.

You can store up to five different grid sizes in the user settings. These can then be selected in the layout space by using the drop-down button ![](../Pictures/Gui/ALL/all_gridactive_as.png) (Grid) in the status bar. This setting is possible separately for 2D and 3D.

Precondition:

You have opened a layout space.

### Using Grid Snap

The use of grid snap is independent of the grid display options.

1. In the status bar of the graphical editor select the button ![](../Pictures/Gui/ALL/statusbar_snaptogrid_as.png) (Snap to grid on/off) to activate or deactivate the usage of the snap to grid on/off function.   
     
   ![](../Pictures/Gui/ALL/arrow.png) If snap to grid is activated, then all of the subsequent actions are performed where the grid lines cross.  
     
   ![](../Pictures/Visualisation/ALL/cabinetgui_usegrid_as.png)

### Align on grid

This function allows you to subsequently adjust 3D objects to the grid settings that were placed without the use of a grid. In this case, it does not matter whether snap to grid is on or off.

1. Select the objects and then select the following commands: Tab Edit > Command group Arrange > Align on grid.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected objects are realigned (i.e., moved) so that all of their important points (such as handle, placement point, etc.) are on the grid.  
     
   ![](../Pictures/Visualisation/ALL/cabinetgui_alignongrid_as.png)

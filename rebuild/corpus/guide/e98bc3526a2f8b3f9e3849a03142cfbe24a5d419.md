# Dialog Connecting point

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Tab Master data > Command group Symbols > Drop-down button Symbol > Open. You have opened the symbol library, selected the symbol to be edited and added a connecting point to the symbol in the symbol editor: Tab Insert > Command group Logic > Drop-down button Symbol connection points > Connection point "Direction". Or you have double-clicked an existing connecting point.
- Tab Master data > Command group Symbols > Drop-down button Symbol > New. You have selected the symbol variant to be generated, specified the Symbol number and Symbol name properties, and added a connecting point in the symbol editor: Tab Insert > Command group Logic > Drop-down button Symbol connection points > Connection point "Direction".

In this dialog you specify or edit the properties of the new connecting point.

Overview of the main dialog elements:

Symbol: Connection point designation / Symbol: Connection point description:

From this list select one or more entries for the connection point property placements (multiple and block selection is possible):

- Non-rotated connection point designation / connection point description
- Rotated connection point designation / connection point description (relevant for the new DIN).

![](../Pictures/Gui/ALL/note.png)Note:

To display and toggle use the following commands: Tab View > Command group General > Drop-down button Connection point designations > Non-rotated or Rotated.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Property / Assignment:

If you have selected a property, you can edit its display properties in the table in the right-hand section of the dialog. The hierarchy levels Format, Text box, Alignment box, Value / unit, and Position are available to this purpose. These can be opened by clicking the ![](../Pictures/Gui/ALL/all_expand_hierarchy_as.png) symbol. Concerning the display properties, the settings described in the following section are available:

- [Display Properties: Placed Property](devicetaggui_r_anzeigeeigenschaften.htm)

![](../Pictures/Gui/ALL/info.png)Tip:

With the Properties as numbers command you can switch the display of the property texts (device tags, function text, etc.) to make the display clearer (command path: Tab Edit > Command group Symbol > Properties as numbers). The property specified is also reported in the print-out and in the output as a PDF file.

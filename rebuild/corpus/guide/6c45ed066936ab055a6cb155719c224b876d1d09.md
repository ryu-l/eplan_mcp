# P021003: Placeholder object contains invalid object references

### Cause

A component which is part of a placeholder object was deleted in the schematic.

### Solution

#### Possibility 1

Double-click the placeholder object and close the subsequent Placeholder object dialog that appears by clicking [OK] or [Cancel]. The object references are then updated.

#### Possibility 2

Undo the deletion or add the delete object again.

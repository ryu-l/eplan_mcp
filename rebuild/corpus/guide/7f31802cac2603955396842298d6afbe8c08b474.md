# Creating and Editing PLC Cards and Connection Points

PLC cards and PLC connection points can be created in different ways:

- In the graphical editor (drawn, as described in "Inserting PLC Cards and Connection Points")
- In the navigator dialogs PLC - <Project name> or Device - <Project name> (here you can also create and re-use unplaced connection points).

You edit the properties of a PLC card in the tabs [PLC box](devicetaggui_r_spskarte.htm) and [PLC structure data](devicetaggui_r_spsstruktur.htm) of the property dialog.

You edit the properties of a PLC connection point in the [PLC connection point](devicetaggui_r_spsanschluss.htm) tab of the properties dialog. The [Bus data](devicetaggui_r_busdaten.htm) tab is additionally available for network / bus cable connection points.

![](../Pictures/Gui/ALL/note.png)Note:

If you want to use the PLC data exchange, a single-line representation of the [PLC configuration](plcgui_k_prinzip.htm#I_SPSKonfigurationen) is required. A multi-line representation is not needed but is additionally optionally possible. In this case enter the bus data at the single-line network / bus cable connection points.

During the PLC data exchange in the AutomationML AR APC format, the multi-line representation is reported in addition to the single-line representation in determining the network structures. If a multi-line representation of the PLC configuration is available, a single-line representation is not necessarily required anymore.

Precondition:

You have opened the PLC navigator: Tab Devices > Command group PLC > Navigator.

### [ClosedCreate PLC boxes or PLC connection points](javascript:void(0);)

1. In the PLC - <Project name> dialog, select the New popup menu item.
2. In the Function definitions dialog, select a PLC box or a PLC connection point and click [OK].
3. In the Properties <...> dialog, edit the properties of the PLC box or the PLC connection point. For example, enter a new DT for the PLC box.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new (unplaced) PLC box or PLC connection point is displayed in the tree or the list.

### [ClosedPlace PLC boxes or PLC connection points](javascript:void(0);)

1. In PLC navigator mark a PLC box or connection point and select the Place popup menu item.
2. Before actual placing press the [Backspace].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The dialog Place device is opened. If a macro is defined at the part, the Part macro option is set as the default.
3. From the Representation type drop-down list select the entry "Multi-line" and click [OK] in order to place the function on a multi-line schematic page. (Select "single-line" or "overview" to place the function on a single-line or overview page.)
4. Press the keys [Shift] + [Tab] to browse through the representation types of the macro. With [Tab] alone you can browse through the macro variants.  
   Or press the [N] button in order to page through the functions and select the desired one. Or use the [Spacebar] while placing the auxiliary functions if you want to interrupt the placement of the auxiliary functions and want to start again with the placement of the main function.
5. If you have selected a PLC box, then you draw this as a rectangle.  
   If you have selected a PLC connection point, place the symbol in the schematic.

![](../Pictures/Gui/ALL/info.png)Tip:

Assigning PLC structure data in the tabular editing

Through the tabular editing you can rapidly and easily assign the PLC structure data for a rack. To this purpose first place the PLC items in the single-line representation or in the overview display. Then mark all the items of the rack and call up tabular editing (command path: Tab Home > Command group Edit > In table). Use a scheme in which the properties Main function, Placement, Rack, PLC card is placed on rack ID and Position (slot / module) are displayed.

Double-click the column heading Placement and then twice on the column heading Main function. This results in the items (main functions) being sorted after their placement at the beginning of the table.

Enter the desired value for the Rack property at the rack. Copy this value for all the associated PLC cards in the PLC card is placed on rack ID column. Subsequently enter the desired value in the column Position (slot / module).

The rack is now configured completely. On the basis of these data Eplan assumes that the items are connected by a backplane.

# Tab Comment

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. This project contains either comments from an imported PDF file or comments that were inserted directly into Eplan.

- You have marked a comment on a project page. Select the Properties popup menu item.
- Tab Tools > Command group Comments > Navigator. Mark a comment and select the Properties popup menu item.

In this tab you can view and change the properties of the comment or create a new comment.

Overview of the main dialog elements:

Author:

Shows the Windows sign-in name of the person who originally created the comment.

Creation date:

Shows when the comment was created by the author.

Modification date:

Shows when the comment was last modified by the author.

Comment text:

Shows the comment text that the author has inserted either in the imported PDF file or directly in Eplan. You can modify this comment text or create a new comment.

Status:

Shows the comment status that was assigned either in the imported PDF file or directly in Eplan. You can change this status.

Replies:

Shows the comment replies including the author and the modification date that were added either in the imported PDF file or directly in Eplan. You can modify replies or add new replies via the property Reply text.

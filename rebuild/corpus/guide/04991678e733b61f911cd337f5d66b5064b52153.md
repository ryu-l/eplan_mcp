# Drawing Boxes as Polylines

Structure boxes, black boxes, PLC boxes, macro boxes and drilling pattern frames can also be drawn as polygons. The SPECIAL symbol library contains the following symbols for this purpose:

- DC2: Black box as a polyline
- DCF2: Fluid black box as a polyline
- PLCC3: PLC box as a polyline
- SC2: Structure box as a polyline
- MC2: Macro box as polyline
- BB2: Drilling pattern frame as polyline.

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the following commands: Insert center > Breadcrumb trail Home > Symbols.
2. Select the symbol for a box as polyline from the SPECIAL symbol library, such as DC2 for a black box.
3. Specify the starting point of the polyline and click the left mouse button.
4. Specify the next points of the polyline, and click with the left mouse button each of the points to place.
5. Select the Complete polyline popup menu item to finish drawing the box.
6. Enter the box-specific device data in the Properties <...> dialog.
7. Click [OK].

![](../Pictures/Gui/ALL/info.png)Tip:

You can rapidly select the symbol for drawing a box as a polyline by selecting the respective commands for inserting a box (for example Tab Insert > Command group Devices > ![](../Pictures/Gui/ALL/ribbon_blackbox_as.png) Black box) and subsequently pressing the [Backspace]. In the Symbol selection dialog the symbols are already filtered and only symbols with the same function category are displayed.

![](../Pictures/Gui/ALL/note.png)Notes:

- If Snap to grid is activated (button ![](../Pictures/Gui/ALL/statusbar_snaptogrid_as.png) (Snap to grid on / off) in the status bar), a newly created box will be exactly on the grid on which it is placed. If Snap to grid is not active, the box can be drawn at any desired position next to the grid.
- In contrast to rectangular boxes, boxes as polylines have only one property arrangement which relates to the insertion point. The corner point furthest to the left is selected as the insertion point when positioning the polyline. If multiple points are overlaid, the topmost point is used as the insertion point.
- The drawing of macro boxes and drilling pattern frames is only possible in macro projects.

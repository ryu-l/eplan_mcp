# Action: SetProjectLanguage

|  |  |
| --- | --- |
| **Parameter** | **Description** |
| PROJECTNAME | Full project name. The project must be open.  When calling from the Windows command line, ProjectAction has to be used beforehand. |
| DISPLAY | Displayed language (for example "en\_US"). When several languages are specified, the individual language identifiers are separated by a semicolon (";"). |
| VARIABLE | Monolingual (variable) displayed language. Can be set via the language code (for example, "de\_DE" for German) or via the index for the displayed language (for example "03\_03" for "Displayed language 3"). The method described last only functions for the first five displayed languages ("05\_05" is therefore the maximal value). |
| SOURCE | Source language. |

![](../Pictures/Gui/ALL/note.png)Notes:

- SetProjectLanguage does not translate the project texts, but only changes the display settings. The action sets the languages in which the translated project text is displayed in the project pages.
- For write-protected projects the displayed language is only changed temporarily through SetProjectLanguage. This setting is not saved in the project.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
SetProjectLanguage 
/DISPLAY:en_US;de_DE 
/VARIABLE:en_US
```

Sets the displayed language to the value "Displayed language 4" (which is set to French here):

```
SetProjectLanguage 
/DISPLAY:en_US;de_DE;pl_PL;fr_FR 
/VARIABLE:04_04
```

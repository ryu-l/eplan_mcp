# Dialog Extension and distance

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Tab Devices > Command group 2D panel layout > Navigator. In the 2D panel layout - <Project name> dialog, you have used the popup menu item Settings to select one of the Manual input <...> options from the Apply group box. You are in the graphical editor on a "Panel layout" page. Select the popup menu item Place on mounting panel on an unplaced part.

This dialog allows you to manually define the dimensions of non-placed parts when placing them on the mounting panel.

Overview of the main dialog elements:

Extension group box

Enter the corresponding values of the part to be inserted in the fields Width and Height.

Distance group box

In the fields Horizontal and Vertical, enter the values for the horizontal and vertical clearance of the part to be inserted to any neighboring part.

# Dialog Criteria selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened the Filter dialog. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the toolbar for the filter criteria or [...] in the Criterion field.

In this dialog you select the property for which you wish to define a filter criterion.

Overview of the main dialog elements:

Find:

Into this field enter the text for which the properties / criteria are to be filtered.

If you want to return to the original view of the criteria selection, remove the search term from the entry field. Click ![](../Pictures/Gui/ALL/all_delete_input_as.png) (Delete) to do so.

Criteria:

The possible criteria are displayed in a tree structure. Depending on the context in which you called up the dialog Filter (in a project data navigator, when generating reports, when defining defined working sections, etc.) only the criteria making sense there are offered.

(...):

This entry places brackets around all subsequent filter criteria and groups them. This allows you to define the hierarchy and importance of filter criteria.

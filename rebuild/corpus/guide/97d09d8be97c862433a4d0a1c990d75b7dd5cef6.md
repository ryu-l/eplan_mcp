# P005040: Bundle connection point is not in pairs

### Cause

The connection is only routed through one part of a bundle connection point. The counterpiece on the connection is missing.

### Solution

1. Locate the bundle connection point in the schematic by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. In the schematic place the counterpiece on the connection so that a bundle connection point pair is formed. Enter the respective designation at the bundle connection points.
3. If required, start a new check run.

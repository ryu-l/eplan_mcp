# Changing the Target Order of Net-Based Connections

The target order of net-based connections can be retrospectively changed in the Property dialog of the associated net definition point.

Preconditions:

- You have opened a project. You have opened a project page in the graphical editor.
- You have inserted a net definition point.

1. Select the net definition point in the graphical editor and then select the popup menu item Properties.
2. In the Properties <...> dialog, select the Net connections tab.
3. Select a connection point in the Connection points table.
4. Select the Change target order popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Change target order dialog shows all the targets of the connection point that are connected through net-based connections.
5. Use the arrow buttons to move the targets to the required positions.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The changed target order is saved.

# Dialog Property arrangement (symbol editor)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have either opened or created a symbol in the symbol editor (Tab Master data > Command group Symbols > Drop-down button Symbol > [Open] or New).

- Tab View > Command group General > Property arrangement.
- Select the Properties popup menu item on the symbol name in the page navigator. Select the "Settings" entry from the Category drop-down list in the Symbol properties - <Symbol name> dialog. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New), and in the Property selection dialog, select one of the "Default property arrangement for variant x" entries. [OK]. Click [...] in the Value cell of the "Default property arrangement for variant x" property.

In this dialog, you select the arrangement set for the property to be currently displayed in the symbol editor. The currently defined arrangement set is displayed after the symbol information in the title bar and can be individually defined for each variant.

Overview of the main dialog elements:

Property arrangement:

This drop-down list shows all created and default property arrangement sets.

# Specifying the Parts Preselection

The parts preselection is a list of parts that you create yourself and save under a specific name. It can be used as a filter during part selection and device selection. The parts preselection is saved specifically for a project.

Precondition:

You have double-clicked a component and in the Properties <...> dialog you have selected the Parts tab.

1. Select the Device selection menu item below the [Settings] button.
2. Click [...] next to the Selection list field in the Settings: Device selection dialog.
3. From the drop-down list select a user defined scheme that you want to change or create a new [scheme](schemeconfig_h_schematabearbeiten.htm) by using ![](../Pictures/Gui/ALL/all_new_as.png) (New).  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the parts preselection already contains parts, these will be displayed in the list.
4. Use ![](../Pictures/Gui/ALL/all_new_as.png) (New) above the parts list to open the Part selection dialog.
5. Page through the tree structure, and mark the parts that you would like to place in the parts preselection.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts are included in the list.
7. In the Parts preselection dialog, click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The scheme for the parts preselection is saved in the Settings: Device selection dialog and displayed in the drop-down list Selection list.
8. Close the Settings: Device selection dialog by clicking [OK].

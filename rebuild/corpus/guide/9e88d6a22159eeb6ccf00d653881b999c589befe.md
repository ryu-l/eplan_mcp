# P001015: Too many wire jumper levels

### Cause

The terminal diagram report cannot display the number of overlapping wire jumpers in the selected form. The value entered for the wire jumper levels is too low in the terminal diagram form. Please note that this project check is only carried out if the number of levels in the associated form is greater than "0".

### Solution

1. Select the following commands: Tab Master data > Command group Plot frames / forms > Drop-down button Form > Open.
2. In the Open forms dialog, select the file type "Terminal diagram (\*.f13)" in the File type field.
3. Click the desired form and open it.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The form is displayed in the page navigator.
4. Mark the form in the page navigator and select the popup menu Properties. Enter a higher value under the property Jumpers: Number of levels in the table for form properties.
5. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png) Note:

- The check run takes both external and internal wire jumpers into consideration.
- Only terminal strips for which a terminal strip definition exists are checked.

# Dialog Settings: PDF output languages

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > Projects > "Project name" > Management > PDF output languages.
- File > Export > Command group Project data > Project data > Command group Page > PDF. [Settings] > Output languages.

In this dialog you define the language to be used in the PDF output.

Overview of the main dialog elements:

Project languages:

In this setting the Display languages set for the project are output to the PDF file.

Alternative languages:

With this setting, alternative, non-displayed languages are output. Specify the desired languages in the Languages field underneath.

Languages:

This list is only available when you have selected the Alternative languages option. In this field you define the alternative languages used to display the translated text in the PDF file. You can select these from the list of Translation languages defined for the project. The PDF export uses only these languages, the display language settings are ignored.

![](../Pictures/Gui/ALL/note.png)Note:

If the Languages list has no entries when the Alternative languages option is set, then the PDF file will be generated in the project display language. An "empty" language list can occur when (e.g.) a translation language previously defined as the PDF output language is removed from the project.

Toolbar:

The toolbar above the Languages list is only available when you have selected the Alternative languages option above; the following buttons are available here:

| Button | Meaning |
| --- | --- |
| (New) | Generates a new line at the end of the Languages list and opens the drop-down list for selection of one of the possible alternative languages. |
| (Delete) | Deletes the selected languages from the list. |
| (Move up) | Moves the selected language one line upwards. This allows you to specify the order of the output languages. |
| (Move down) | Moves the selected language one line down. This allows you to specify the order of the output languages. |

# Configuring Hose Lines

The hose line data read into the Configure hose lines dialog as a rule only contain the complete DT of the hose lines. In order to generate norm-compliant Hose line identification and a norm-compliant Type code for each hose line, further properties have to be added to the incomplete hose line information and values assigned to these, i.e. configured. The Edit <...> dialog is available to this purpose. During editing you access the properties and values set in the selected scheme. The Block editing function allows you to edit the data of several hose lines simultaneously in this dialog.

Preconditions:

- You have opened the [Configure hose lines](fluidhoseconfiggui_d_schlauchleitungen.htm) dialog.
- You have read in hose line data - either directly from the schematic page of an opened project or by using an exchange file. The hose line data contain the complete device tags of the hose lines as the minimum information and are displayed in the table of the Configure hose lines dialog.

1. In the Configure hose lines dialog select the Extras > Settings menu items.
2. In the Settings: Hose line configurator dialog you select the desired scheme, for example the default preset scheme DIN 20066\_2012\_01 with which you can generate the hose line identification and the type code in accordance with the specifications of the standard DIN 20066.
3. Click [OK].
4. Double-click a row with a complete DT in the Configure hose lines dialog.
5. Carry out the desired entries in the fields of the Edit <...> dialog.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The edited hose line data are entered in the table of the Configure hose lines dialog.
7. Close the dialog by clicking [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) After editing the hose line data are written back into the project and saved at the marked hose lines. (This is only possible if you have read in the hose line data from an opened schematic page of a project before editing and the respective hose lines are still marked in the schematic.)

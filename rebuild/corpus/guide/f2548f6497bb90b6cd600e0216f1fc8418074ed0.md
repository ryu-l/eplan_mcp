# Displaying the Project Information

In the project management you can display project-specific and non-project-specific information.

1. Select the following commands: File > Project management.
2. Mark the desired project in the tree structure in the Project management dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Project properties, statistical project information, project status, and the structure of devices and pages are displayed in the tabs.

# P027004: Topology - The connection from <x> to <y> does not run through a routing path / has not been routed yet

### Cause

The routing path network contains the topology functions <x> and <y> that are connected graphically by a so-called not routed routing connection. This connection is displayed in the routing path network by a graphical line that displays that no routing track could be determined through a routing path or routing path network. Accordingly, the value of the Topology: Routing track property of this connection remains empty.

### Solution

1. Locate the source of the topology function, and based on this, the routing connection not routed in the topology using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Add routing paths and routing points to the routing path network by means of the following commands: Tab Insert > Command group Topology > Routing path and Routing point.
3. Connect the topology functions <x> and <y>, and the routing points with the routing paths, and thus specify a routing track through the routing path network.
4. Mark the total routing path network, and select the following commands: Tab Connections > Command group Topology > Route.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A routing connection is generated through the routing path network.
5. Update the connections.
6. If required, start a new check run.

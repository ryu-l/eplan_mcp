# P014003: The version specified at the referencing macro box does not agree with the version (<x>) in the macro file

### Cause

The version specified at the referencing macro box does not agree with that (<x>) in the macro file.

### Solution

1. Locate the macro box in the project using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Select the insertion point of the macro box.
3. Select the Update macro popup menu item.
4. In the subsequent dialog select the desired scheme with which you specify the manner in which the macro is to be updated.
5. Click [OK].
6. If required, start a new check run.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The macro box and macro file now are of the same version.

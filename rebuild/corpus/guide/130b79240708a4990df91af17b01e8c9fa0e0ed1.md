# Tab Format (3D part placement)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have opened the layout space navigator and a layout space. The layout space contains part placements (3D). Select a part placement in the navigator. Select the Properties popup menu item. In the Properties <...> dialog, select the Format tab.
- You have selected a device in the 3D display area. Popup menu item Properties. In the Properties <...> dialog, select the Format tab.

In this tab you can edit the display properties of the graphical display of 3D components such as enclosures, mounting panels, mounting rails, etc.

Overview of the main dialog elements:

Property / Assignment:

The hierarchy level Format is available in the table. This can be opened by clicking the ![](../Pictures/Gui/ALL/all_expand_hierarchy_as.png) sign.

Transparency:

Select a transparency level from the drop-down list or enter a value manually. With a value of 100% the component is completely transparent.

![](../Pictures/Gui/ALL/note.png)Notes:

- The color of a 3D object cannot be changed if a surface color or an object color already exists. The color of an individual surface cannot be changed if there is a corresponding layer for the entire object. That is the case with a 3D enclosure, for example.
- A surface or an object color is created if a STEP file is imported in which the colors have been defined. If no surface colors or object colors have been defined, then they can be set with this dialog element.
- These restrictions also apply for the working method of the functionalities Copy format and Assign format in combination with 3D objects (Tab Home > Command group Clipboard > Copy format or Assign format).

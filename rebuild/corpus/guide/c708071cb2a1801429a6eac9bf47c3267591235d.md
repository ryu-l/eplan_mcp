# Dialog Settings: API part selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- File > Settings > User > Management > Part. Select a user-defined Scheme from the drop-down list in the Settings: Parts dialog. Select the API option and click [...].
- You have selected a main function in the graphical editor or in a navigator. Popup menu item Properties. You clicked [...] in the Parts tab next to the Data source field. Select a user-defined Scheme from the drop-down list in the Settings: Parts (user) dialog. Select the API option and click [...].

In this dialog you determine which parts properties to load with the API interface.

Selecting parts via API is a purely functional interface. How the selection option is structured and how the selection dialog appears depends on the implementation of the corresponding API program.

Overview of the main dialog elements:

Name of action:

Enter the action to be started when you select a part with the API interface. This action is prepared with an API program.

# P012005: The mounting panel and the main function have differing mounting sites (describing)

### Cause

#### Possibility 1

Differing texts were entered in the property fields under Mounting site (describing) for the main function and at the mounting panel for the corresponding part placement.

#### Possibility 2

You want to display the text of the Mounting site (describing) field in several languages for both the main function and the mounting panel for the corresponding part placement. The text is available in the dictionary in the languages you want, but you have only translated it for the Mounting site (describing) field for the main function, and not for the mounting panel.

#### Possibility 3

In the Mounting site (describing) field, you have marked a ready-translated text, which is available in the dictionary in the languages you want, as Do not translate for the main function. However, at the mounting panel for the corresponding part placement, you can display the translated text in the languages you want.

### Solution

#### Regarding option 1

Enter the same texts in the Mounting site (describing) field for both the main function and the mounting panel for the corresponding part placement.

#### Regarding option 2

Translate the text in the Mounting site (describing) field into all languages for both the main function and the mounting panel for the corresponding part placement.

#### Regarding option 3

For the main function, in the Mounting site (describing) field, select the popup menu item Remove marking.

If required, start a new check run.

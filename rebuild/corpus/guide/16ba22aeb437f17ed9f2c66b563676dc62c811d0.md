# Tab Documents / Pages

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have generated a segment in the pre-planning navigator, or inserted one in the graphical editor. Select the Documents / Pages tab in the Properties <...> dialog.
- You have highlighted a segment in the pre-planning navigator or in the graphical editor. Popup menu item Properties. Select the Documents / Pages tab.

Use this tab to assign external documents and / or project pages to a segment. By means of the assignment of pages you can easily see at the segment on which pages there are associated data.

Overview of the main dialog elements:

Table Documents

The following columns are displayed in the table:

- File / hyperlink: Here you can specify any documents, which can be output as hyperlinks in reports. Using [...] you can call the file selection dialog where you can select the document to be linked. The name, including file path, is carried over to this field.
- Designation: Here you can enter a description text for the linked document. This text is displayed when placing the hyperlink.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Open document | Provides the possibility to open stored documents or Internet addresses in the File / Hyperlink column. |

---

Table Pages

The following columns are displayed in the table:

- Row: Consecutive row number.
- Page name (full): Full page name. Contains page names and the identifying and describing identifier blocks.
- Page type: Defines the page type, i.e. whether it is a page for schematics, mounting panels, terminal diagrams, etc.
- Page description: Descriptive text for the page, is displayed for example in the tree view of the page navigator or in reports.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Open | Opens the selected page in the graphical editor. |
| Open in new window | Opens the marked page in another graphical editor window. This is displayed using an additional tab. |

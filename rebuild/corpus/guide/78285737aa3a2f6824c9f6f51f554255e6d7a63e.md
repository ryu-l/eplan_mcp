# P502001: The macro '<x>' entered at the part does not exist. The message applies to the part property '<y>'

### Cause

In the parts database to be checked a part was found where a macro was entered which Eplan cannot find. In the placeholder '<x>' of the message, the path and name of the macro are output, in the placeholder '<y>' the part property at which the macro is entered.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Properties tab to the front.
3. In the tree view of the property table open the hierarchy level Data or Mounting data - depending on whether a schematic macro or a graphical macro was named in the message.
4. Click [...] in the value field of the part property named in the check run message for the macro.
5. In the selection dialog that is opened select an existing macro from one of the directories on offer.  
     
   Or alternatively to this, delete the entered schematic macro and/or graphical macro in the value field of the respective part property.  
     
   Or create a new schematic and/or graphical macro, store it in the desired macro directory and select it again at the respective part property.
6. Click [Apply].
7. If required, start a new check run.
8. Close the parts management and perform a parts data synchronization.

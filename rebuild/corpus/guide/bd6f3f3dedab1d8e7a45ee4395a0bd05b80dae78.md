# Dialog Generate drilling patterns / outlines

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a macro project. Tab Master data > Command group Drilling pattern / outline > Drop-down button Generate > From Rittal - Perforex / Secarex files. In the file selection dialog select the Rittal - Perforex / Secarex NC files to be imported and click Open.

In this dialog set the directory in which the user-defined outlines that are created together with the drilling pattern are to be stored.

In addition select a scheme with a Rittal - Perforex / Secarex machine definition from which further information can be used for the drilling pattern to be created.

Overview of the main dialog elements:

Machine:

Selection option for a scheme with a Rittal - Perforex / Secarex machine definition as it is defined in the settings for the Rittal - Perforex / Secarex NC export. The drill type and diameter of the drill holes in the drilling pattern to be created are determined from the settings in this scheme.

Directory for outlines (NC data):

Storage location for \*.fc1 files (outline NC data) that are created automatically during the creation of a drilling pattern. The default directory is the directory for macros ($MD\_MACROS).

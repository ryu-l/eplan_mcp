# P004053: Too many differences were found between the network structure in the import file and in the project! Please check all network structures

### Cause

During the last import of PLC data a connection was found that contradicts the connection currently existing in the project. The faulty connection could not be determined due to the complex contradiction. Possibly the imported file was intended for a different project.

### Solution

1. Check all the bus ports whether they are connected with the correct physical network.
2. Import the PLC data again.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

# P004052: Connection to the wrong physical network! '<x>' has to be connected to the physical network '<y>'

### Cause

During the last import of PLC data, a device was determined that is connected with the wrong physical network.

### Solution

1. Check the Physical network: Name property at the reported connection point of the device.
2. Import the PLC data again.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

# Importing / Exporting Symbols

You can export symbols in order to import them into other symbol libraries.

Precondition:

You have opened a project and at least one symbol library.

### [ClosedImport symbols](javascript:void(0);)

1. Select the following commands: Tab Master data > Command group Symbols > Drop-down button Symbol > Import.
2. If multiple symbol libraries are open, select the symbol library to which you would like to import the new symbol in the Symbol library selection dialog.
3. Click [OK].
4. In the Import symbol dialog select the desired symbol (\*.esl) from the list. Multiple selection is not possible.
5. Click [Open].
6. In the Symbol properties - <Library name> dialog you specify data about the symbol that is to be imported and the following defaults will be shown:  
   Symbol number: next available number  
   Symbol name: "<name of the original>" if this is not already available in the current symbol library, otherwise "<Name of the original> (copy)"  
   Function definition: function definition of the original.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol is imported and can now be edited in the current project.

### [ClosedExport symbols](javascript:void(0);)

1. Select the following commands: Tab Master data > Command group Symbols > Drop-down button Symbol > Export.
2. In the Symbol selection dialog select the symbols to be exported. Multiple selection is possible.
3. Click [OK].
4. In the Create export file dialog, choose the target directory where you would like to export the symbols.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The export files will be generated in the drive and directory selected.

![](../Pictures/Gui/ALL/note.png) Note:

During the export all existing variants of the symbol are also taken into consideration.

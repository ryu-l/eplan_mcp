# Dialog Property overview - <Project name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Tab Home > Command group Edit > Property overview.

In this dialog you can edit the properties of one or more selected objects (texts, graphical elements, functions, segments).

In order for the desired properties to be displayed for the selected objects, you must select or create a fitting scheme for a property configuration. In the supplied "Default" scheme we provide a scheme with property configurations for all important objects.

Overview of the main dialog elements:

Toolbar:

You can specify the display of the properties by means of the following buttons:

| Button | Meaning |
| --- | --- |
| (Tree view) | Shows the properties in a tree view. |
| (List view) | Shows the properties arranged one below the other in a list. |
| (All properties) | Shows all properties. |
| (Filled properties) | Only shows the properties for which a value is available. |
| (From scheme) | Shows the configured properties from the scheme. |

If the button ![](../Pictures/Gui/ALL/all_fromscheme_as.png) (From scheme) is activated, you can select a scheme for display and editing of the properties from the drop-down list. Click [...] to open the [Configure properties](modaldialogsdb_d_eigenschaftskonfiguration.htm) dialog . There you can use a scheme with several property configurations to specify which properties are to be displayed in the property overview and in which sequence.

If one of the buttons ![](../Pictures/Gui/ALL/all_allproperties_as.png) (All properties), ![](../Pictures/Gui/ALL/all_filledproperties_as.png) (Filled properties) or ![](../Pictures/Gui/ALL/all_fromscheme_as.png) (From scheme) is activated, you can switch between tree view and list view via the buttons ![](../Pictures/Gui/ALL/all_treeview_as.png) (Tree view) and ![](../Pictures/Gui/ALL/all_listview_as.png) (List view).

In the respective tree view the selected source objects (function, text, component, etc.) are displayed as a hierarchy level.

Find:

Into this field enter the text for which the properties are to be filtered. Both the names of the displayed properties as well as the values are searched.

If you want to return to the original view of the properties, remove the search term from the entry field. Click ![](../Pictures/Gui/ALL/all_delete_input_as.png) (Delete) to do so.

Property / Value:

Shows the values of specific properties for the marked object or marked objects. Which values you can edit depends on the selected scheme.

The values of specific properties that contain a value deviating from the specification at the part, in the logic model or from the segment template are displayed with a yellow cell background. This is the case for part reference properties, properties of the connection point logic or pre-planning properties.

Additional information is displayed in the information area below the properties table. For a property selected in the Property / Value table these are, for example, the ID, the designation and the description of the property.

[Load all objects]:

If more than 100 objects are selected in the selection in the graphical editor, in a navigator, etc., a text is shown in the information area that not all objects are displayed. Click this button to reload all the objects and display them in the property overview. This procedure may take some time.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

![](../Pictures/Gui/ALL/note.png)Note:

Global editing of distributed functions in the Property overview dialog is not possible for the activated Properties (global) mode.

# Defining Daisy Chains

The connections within a net can be defined on the net definition point. The net will not be complete until all connection points have been connected. If a net has more than one daisy chain, these must also be interconnected in order to create a complete net.

Preconditions:

- You have opened a project. You have opened a project page in the graphical editor.
- You have inserted a net definition point.

1. Select the net definition point in the graphical editor and then select the popup menu item Properties.
2. In the Properties <...> dialog, select the Net connections tab.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The Connection points table displays all the connection points in the net.
3. Select the Create daisy chain popup menu item.
4. Click the connection point at which the daisy chain is to begin.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection point is shown in the Connections table.
5. Click in sequence on the other connection points that are to be included in the daisy chain.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection points in the daisy chain are shown in the Connections table.
6. Select the End daisy chain popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A horizontal line is added to the Connections table to indicate that the daisy chain is complete.
7. Select the Create daisy chain popup menu item again to define a further daisy chain.
8. Consecutively click the starting connection point and then the other connection points that are to be included in the daisy chain.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connections are displayed in the Connections table.
9. Select the End daisy chain popup menu item.
10. Click [Apply] to save the defined daisy chains.

![](../Pictures/Gui/ALL/info.png)Tip:

You can create a new daisy chain by double-clicking a connection point in the Connection points table in the Net connections tab. This also ends an already started daisy chain.

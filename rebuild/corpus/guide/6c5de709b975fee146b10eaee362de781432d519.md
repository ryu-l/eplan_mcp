# Dialog Copy image file

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc. Tab Insert > Command group External > Image file. In the Select image file dialog, select the desired image file and click [Open].

Image files in the GIF, JPG, BMP, ICO, PNG, or TIFF formats can be inserted in Eplan. In this dialog, you can specify whether the image file is to be copied into the project directory or referenced from the source directory.

Overview of the main dialog elements:

Keep source directory:

A reference to the image file is inserted in the project. If the image file is changed, it is automatically updated as soon as you open the page. During the data backup, a setting allows referenced files to be taken into consideration.

Copy:

The file is copied into the project directory (that is, into the Images subdirectory of the project). There the image file is not stored directly, but in a further separate subdirectory. The name of this subdirectory is derived from the source directory name.   
All files in the project subdirectories are also included in backups.

Overwrite with prompt:

Select this check box to have a confirmation displayed for the Copy option if the image is already present in the project directory. You can then decide whether this image should be overwritten or not.

# Checking Device Tags

The DT syntax check supports you in checking the length and validity of the characters at the entries for the device tags.

Precondition:

You have opened a project.

1. Select the following commands: File > Settings > Projects > "Project name" > Devices > DT syntax check.
2. In the dialog Settings: DT syntax check on the Electrical engineering and / or Fluid tab, activate the Enable check check box.
3. In the Device tag and Count numbers group boxes, specify the scope of the check for the device tag components of the full DT.
4. In the Identifier blocks group box on the Structure identifier tab, specify the scope of the check for the identifier blocks within the full DT.
5. Click [OK].

After the entry of the device data in the Properties <...> dialog, Eplan checks whether the syntax of the specified device tag is correct. The entire device tag string is always checked (i.e. the full DT). The settings on the Structure identifier tab are used for the identifier blocks, even if the check box is deselected on that tab.

![](../Pictures/Gui/ALL/note.png)Note:

The Enable check check box on the Structure identifier tab only has to be selected if you want to check other structure identifiers, in addition to the electrical engineering or fluid power DTs (pages, for example).

If the syntax does not meet the defined criteria, Eplan opens a message dialog in which the incorrect elements are displayed. You can branch from this message dialog to the settings for the DT syntax check by means of the [Settings] button. There you can check, and if necessary, correct your syntax settings. If the "error" is an intentional deviation from the syntax, you can exit the message box by means of the [Ignore] button and apply your entry without having to change the settings.

# Managing Master Data

Master data files to be edited or stored in the project can be opened in the standard dialog, which is in a default directory. This directory is set for the individual master data types via the commands File > Settings > User > Management > Directories.

Actual storage and management depends on the type of master data in question, in which the program distinguishes between the management of:

- [Parts data](xmasterdatasettingsgui_h_artikeldatenverwalten.htm)
- Forms
- Plot frames
- [Macros](xmasterdatasettingsgui_h_makrosverwalten.htm)
- Symbol libraries.

If the specified form / plot frame, etc. does not exist in the master data pool, it can be found by using the Complete project command and can, if appropriate, be automatically stored. If missing master data can't be found in the master data pool, a message is displayed.

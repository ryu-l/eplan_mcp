# GOST-compliant Path Numbering

The GOST standard requires horizontal, numeric path numbering from right to left and optional, vertical, alphanumeric item numbering from bottom to top. "Project by project" path numbering across more than one page is also supported: Here only the vertical path numbering is numbered consecutively, and the alphanumeric items start again on each page with the set start value.

The following properties are available to set path numbering for the GOST standard:

- Inverse column numbering (ID 12035): This property sets column numbering from right to left, for projects that comply with the GOST standard.
- Inverse row numbering (ID 12036): This property sets row numbering from bottom to top, for projects that comply with the GOST standard.

Both settings for the Reporting direction (ID 12103) must be "vertical" for this.

As well as the special property DT adoption: Search direction conforming to GOST standard (ID 12104), the Row numbering format (ID 12009) and the Column numbering format (ID 12011) values must be set to "Numeric" or "Alphanumeric".

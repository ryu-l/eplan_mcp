# Tab Symbol data (PCT Loops / PCT Loop Functions)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have generated a PCT loop or PCT loop function in the pre-planning navigator, and placed it on a page of the "P&I diagram" type. Select the Symbol data tab in the Properties <...> dialog.
- You have highlighted a PCT loop or PCT loop function in the pre-planning navigator or in a P&I diagram in the graphical editor. Popup menu item Properties. Select the Symbol data tab.

In this tab, you can configure the settings for the graphical display of the PCT loop or PCT loop function in the P&I diagram.

Overview of the main dialog elements:

Symbol (graphic) group box

Use this group box to edit the graphical properties of the component. Here, you can assign to the PCT loop / PCT loop function another symbol variant or another symbol. Depending on the symbol selected, the associated options in the group boxes Implementation and Activation site are also modified.

Number / name:

This field displays the name of the current symbol; click [...] to open the [Symbol selection](xsbgui_d_symbolauswahl.htm) dialog and to select, if necessary, another symbol.

If available, a preview of the symbol is shown in the adjacent field.

---

Group boxes Implementation / Activation site

Select an option from each group box to determine the P&I symbol for the graphical display of the PCT loop or the PCT loop function in the P&I diagram. Depending on the options selected, the associated symbol is displayed in the preview in the upper area of the tab.

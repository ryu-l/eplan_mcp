# Export / Labeling File / External Report File

Project data for manufacturing data, labelings or external reports are output in external export files / labeling files or report files. An export / labeling file represents one or more pages of labels. A page contains a header, a label area, and a footer.

### Header

The header is at the top of the page. It can output a single time on the first page or be repeated on each page.

### Label area

The label area contains one or more rows of labels. One label row consists of one or more labels next to one another.

### Footer

The footer is at the bottom of the page. It can output a single time on the first page or be repeated on each page.

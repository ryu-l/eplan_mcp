# Placing Items on the Mounting Rail

The items can be placed on mounting rails as an alternative to the equipment of mounting panels. An "Auxiliary function" for performing this is available, with which you must define the position of the items: A mounting rail can currently be represented on a "Line", a "Polyline", a "Polygon", a "Rectangle" or a "Spline". Not allowed are "Circle", "Ellipse", etc.  
The insertion point of the part placement is then placed on the selected object. The clearances defined in the parts management are also accounted for here when placing.

Preconditions:

- You have opened a project.
- You have opened a project page of the "Panel layout" type in the graphical editor.
- You have added a mounting panel.
- You have opened the 2D panel layout - <Project name> dialog (Tab Devices > Command group 2D panel layout > Navigator).
- The List tab contains parts with the "Unplaced" part status (Number of units / quantity (unplaced) property).
- If you have specified the dimensions and / or macros in the parts management, specify one of the options <...> from parts master data in the dialog [Settings: 2D panel layout](panellayoutgui_d_schaltschrankaufbaueinstellungen.htm). Otherwise select Manual input <...>.

1. In the Tree tab of the 2D panel layout - <Project name> dialog select the items that have not yet been placed. Multiple selection is possible.
2. Select the popup menu item Place on mounting rail.
3. Select the object on which the part placement is to be positioned.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The first part placement hangs on the cursor.
4. Define the dimensions of the part placement using the Extension and distance dialog.
5. Click [OK].
6. Move the cursor along the object to move the part placement.
7. Confirm the position with a mouse click.
8. Proceed in this way for all additional part placements selected in the tree.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The newly-placed parts are removed from the "Unplaced" hierarchy level, and moved to the hierarchy level of the populated mounting rail. If parts have already been placed on the mounting rail, new placements can only occur in the free area.

![](../Pictures/Gui/ALL/note.png)Note:

Even if you do not move the cursor during placement, the symbols will be placed from left to right. If a symbol extends over the edge of the mounting panel, an error message will inform you of this.

# Checking Part Placements

When part placements are placed, the part placement assumes the location designation of the mounting panel. In the process, a check is performed to see if the part placement has been performed on the correct mounting panel, based on the structure identifier blocks of the mounting panel and the placed device. In addition to this, you can compare the Mounting site (describing) property of the mounting panel with the main function.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

| Mounting panel | Device | Status |
| --- | --- | --- |
| =A1+O1-MP1 | =A1+O1-K1 | Correct |
| =A1+O1-MP1 | =A1+O2-K1 | Error |
| MP1 (location designation =O1) | K1 (location designation =O1) | Correct |
| MP1 (location designation =O1) | K1 (location designation =O2) | Error |

Preconditions:

- You have opened a project.
- You have selected the commands File > Settings > Projects > "Project name" > Management > Message management and clicked [...] in the Check-related settings field in the Settings: Message management dialog.

1. If required, select a scheme for the settings or generate a new one in the Settings: Messages and checks dialog.
2. Select the Class "2D panel layout".
3. Define the Category and the Type of check for the individual errors and messages in the table on the right-hand side of the dialog by selecting an entry from the drop-down list for each one in the table cells by the same name.
4. Click [OK].

Once you have performed this, when making part placements on the mounting panel, these are then checked according to the settings; if disagreement is found, then a suitable message is displayed.

# P004084: The MasterSystemID is faulty

### Cause

An invalid MasterSystemID was entered at a bus port that is assigned to the bus system "PROFIBUS" or an Ethernet-based bus system.

This check run only checks bus ports at which a configuration project is entered.

### Solution

1. Locate bus port in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Open the property dialog of the bus port.
3. Bring the Bus data tab to the front.
4. If the "PROFIBUS" bus system is set, enter a value between 1 and 99 in the MasterSystemID property of the Properties of the network interface group box. If an Ethernet-based bus system is set, enter a value equal to or greater than 100 in the value field of this property.
5. Click [OK].
6. If required, start a new check run.

# P024002: Connection between different trades

### Cause

The target functions of a connection have a conflicting entry for the property Trade. This can occur when, for example, a connection exists between functions belonging to the trades "Pneumatics " and "Hydraulics".

### Solution

1. Assign data to the connection targets that agrees with the Trade property. The trade can be set for each function in the Properties <...> dialog on the first tab.
2. Update the connections.
3. If required, start a new check run.

# Dialog Settings: Graphical memory requirements

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > Workstation > Graphical editing > Graphical memory requirements

In this dialog you can specify the degree of multisampling for rendering graphics in order to optimize the graphical memory requirements.

Multisampling is a method of reducing aliasing effects in rendered graphics. In this method, each pixel is broken down into several sampling points. The higher the number of sampling points (= sample count), the smaller the aliasing effects in the rendered graphics. However, this also increases the graphical memory requirement.

Overview of the main dialog elements:

Multisampling:

With this slide control you specify the degree of multisampling and thus the graphical memory requirement. Four settings are available:

- Low: With this setting, multisampling is carried out with a sample count of 1 and leads to a low graphical memory requirement.
- Medium: With this setting, multisampling is carried out with a sample count of 2 and leads to an average graphical memory requirement.
- High: With this setting, multisampling is carried out with a sample count of 4 and leads to a high memory requirement.
- Very high: With this setting, multisampling is carried out with a sample count of 8 and leads to a very high graphical memory requirement.

![](../Pictures/Gui/ALL/note.png)Note:

You have to reopen the layout space after carrying out the setting, so that the changed multisampling setting acts on a layout space.

# Inserting Interruptions for Pipings

Preconditions:

- You have opened a project containing pre-planning data.
- You have opened a page of the "P&I diagram" type.
- You have defined a piping in the P&I diagram by means of a piping definition point.

1. Select the following commands: Insert center > Breadcrumb trail Home > Symbols.
2. From the symbol library SPECIAL select the symbol PBR for a piping interruption.
3. In the preview select the corresponding variant of the interruption symbol for a vertical or horizontal piping section.
4. For the desired piping click the positions between which the interruption is to be inserted.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The piping is not deleted between these two positions but only graphically interrupted.
5. Proceed in a similar way for all additional pipings that are to be interrupted.
6. End the action via the Cancel action popup menu item or via the [Esc] button.

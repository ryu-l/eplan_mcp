# Reporting and Outputting Piping and Tubing Lists

In fluid power, fluid connections are generally documented using so-called piping lists and tubing lists. A piping or tubing list is a special connection list for fluid power. It shows if a fluid power connection between two fluid functions is a pipe or a tube. It also lists the devices (DT of the targets) and gives information about cross-section and / or length of the corresponding connection. In Eplan Fluid it is possible to report on such connections and to output the result as piping and tubing lists as pages in the project.

The connection type "Pipe" or "Tube" of a fluid connection can be determined either by means of defaults in the settings or with the help of a connection definition point with "Pipe" or "Tube" as set function definition.

When reporting on piping and tubing lists, the program proceeds as follows:

If fluid connections don't have any connection definition points, the program determines the function definition from the settings for the connection properties.

For connections that have connection definition points, the function definition of the connection definition point determines whether the connection is a "pipe" or a "tube".

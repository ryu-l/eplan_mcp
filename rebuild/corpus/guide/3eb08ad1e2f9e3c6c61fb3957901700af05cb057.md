# P002009: Dual entry in form position

### Cause

There are at least two form positions by the same name for one or more targets at the first and / or second function connection point of the pin that was either generated in the plug navigator or placed in the schematic.

### Solution

1. Double-click in the plug navigator or in the schematic on the pin and select the Connections tab in the Properties <...> dialog.
2. Name the form positions by the same name for the targets at the first and / or the second function connection point of the pin.
3. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

The Connections tab is only available if you have activated the Use 'Connections' tab at terminals and pins setting. You access this setting with the following commands: File > Settings > Projects > "Project name" > Management > Compatibility.

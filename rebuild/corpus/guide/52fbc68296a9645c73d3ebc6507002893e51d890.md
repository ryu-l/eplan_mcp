# Dialog Layout space views

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a layout space.

The Layout space views dialog is used to manage layout space views and is displayed next to the Insert center dialog as a flyout. With the buttons ![](../Pictures/Gui/ALL/userinterface_pin_as.png) (Pin) and ![](../Pictures/Gui/ALL/userinterface_unpin_as.png) (Unpin) you can determine whether the flyout remains pinned or can be unpinned. In the released state the Layout space views dialog is hidden and only visible as a vertically arranged tab Layout space views. Clicking the tab redisplays the Layout space views dialog.

Overview of the main dialog elements:

Layout space-specific views

This area contains 10 tiles on which you can save orthogonal and isometric views in order to reuse them later. You previously generated the views for a layout space, for example by means of the navigation cube. A preview image of the saved view is displayed on each tile.

Toolbar

The icons above the tiles allow you to perform the following actions:

| Icon | Meaning |
|  | Add current view |
|  | Delete view |

Tile icons

The following icons can be located on a tile:

| Icon | Meaning |
|  | Indicates that the viewing angle set in the saved view is also used when retrieving the view. |
|  | Indicates that the items and connections shown or hidden in the saved view are also shown or hidden when the view is retrieved. |

Popup Menu

A popup menu is available for each tile:

| Menu item | Meaning |
| Viewing angle on / off | Specifies before retrieving the view whether the viewing angle set in the saved view should also be used after the view has been retrieved. The  icon is displayed or hidden accordingly. |
| Visibility on / off | Specifies before retrieving the view whether the items and connections that are shown or hidden in the saved view should also be shown or hidden after the view has been retrieved. The  icon is displayed or hidden accordingly. |
| Use view | Applies the view saved on the tile to the layout space. |
| Rename view | Allows renaming of the view. |
| Add current view | Saves the view currently generated in the layout space on the tile. |
| Delete view | Deletes the view stored on the tile. |

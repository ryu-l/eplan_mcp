# Dialog Save property arrangement

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have inserted a symbol in the graphical editor or generated a new function in a navigator.
- You have selected a function in the graphical editor or in a navigator. Popup menu item Properties.

In the Properties <...> dialog, select the Display tab. From the Property arrangement list select the "User-defined" option, edit the property arrangement and click ![](../Pictures/Gui/ALL/all_save_as.png) (Save) in the toolbar above the drop-down list.

In this dialog you save a user-defined property arrangement under a language-neutral name.

Overview of the main dialog elements:

Property arrangement:

In this field, enter a descriptive name for the property arrangement. If you have already saved a user-defined property arrangement, then you can select an existing name from the drop-down list and overwrite the old property arrangement.

![](../Pictures/Gui/ALL/note.png)Note:

If you overwrite a user-defined property arrangement, the modified display settings are transferred to all the components that use this property arrangement.

Use as default:

This check box is only available if the symbols / functions have no connection definition points!

Select this check box if this saved property arrangement is to be used as a default for all additional usages of these symbol variants. This will result in all previously saved property arrangements for this symbol variant being ignored.

Use as default for connections / Use as default for cable connections:

These check boxes are only available if the symbols / functions have no connection definition points!

Select the check box Use as default for connections if this saved property arrangement is to be used as a default for "normal" connection definition points at all additional usages of these symbol variants. This property arrangement is also used for connection definition points that arise during connection numbering. To this purpose the Use default check box must be activated in the Display tab in the settings for connection numbering.

Activate the check box Use as default for cable connections if this saved property arrangement is to be used as a default for connection definition points of cable connections at all additional usages of the symbol variant. Connection definition points for cable connections are placed in the graphical editor when drawing cables / shields or during Drag & Drop from the cable navigator or connection navigator.

The settings carried out here are also displayed in the dialog Configure property arrangements - <Project name>. There you can edit all the property arrangements at a central point.

# Creating GRAFCET Diagrams

GRAFCET diagrams can be created on an existing page or on a new page. This section describes how a GRAFCET diagram can be created on a new page. The procedure for creating GRAFCET diagrams on existing pages is similar.

Preconditions:

- You have opened a project.
- You have added the symbol library OS\_SYM\_ESS.slk to the project. (This setting is carried out via the following commands: File > Settings > Projects > "Project name" > Management > Symbol libraries.)
- In the project settings you have specified the special symbol that is used for the placing of the property texts in operational sequence sheets (e.g., OS3 for GRAFCET diagrams).
- You have inserted functions or devices in the project and have entered on those the required values for the properties Function text, State [1] to State [10], etc.

![](../Pictures/Gui/ALL/note.png)Notes:

- If you create a GRAFCET diagram, the Functional placing with symbol graphic project setting must be deactivated.
- The State [10] property has been set aside, by default, for the input of variables for GRAFCET diagrams. If you use the special symbol OS3, the value of the State [10] property is placed as the variable text.

### [ClosedCreate project page for the GRAFCET diagram](javascript:void(0);)

1. Create a new project page. Select the following commands: Tab Home > Command group Page > New.
2. Select the entry "Overview (I)" in the New page dialog in the Page type field, and enter a descriptive text for the project page in the Page description field.
3. In the table in the Grid field, enter the value "3 mm".
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) A new project page is generated. If the grid settings and the form used match, the grid points will be in the center of the table rows defined in the form. This facilitates the correct placing of devices and process sequences.

### [ClosedCreate table of variables](javascript:void(0);)

The table header of the table of variables is created by means of a macro. You can insert a single table row by placing the property texts from the device navigator.

1. Open the project page for the operational sequence sheet, e.g., by double-clicking the project page in the page navigator.
2. Select the following commands: Insert center > Breadcrumb trail Home > Window macros / symbol macros.
3. Using the folder structure navigate to the macro directory OS\_ESS and there select the Table\_GRAFCET.ema by clicking a preview tile.
4. Then place the macro with the table row at the required position in the diagram.
5. Select the following commands: Tab Devices > Command group Devices > Navigator.
6. Mark a function in the device navigator and select the Place functional > With symbol graphic popup menu items.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The special symbol defined in the project settings hangs on the cursor. If you use the special symbol OS3, a table row with the property texts of the function will be displayed (i.e., the value of the State [10] property).
7. Place the graphic (the table row) at the required position in the diagram.
8. Repeat the above steps for the other devices that you want to place in the table of variables.

### [ClosedDraw process sequences](javascript:void(0);)

You use graphical elements (e.g., polylines) to draw process sequences. Eplan provides support to enable you to insert some special elements of operational sequence sheets faster. Arrows, signal points, AND and OR conditions, GRAFCET steps, GRAFCET actions, and GRAFCET transitions can be drawn into the respective operational sequence sheet by means of the corresponding commands. (To this purpose you first have to [Customize the ribbon](userinterface_h_menuebandanpassen.htm) and then assign the desired command to a user-defined command group.)

1. If you want to draw a polyline, select the following commands: Tab Insert > Command group Graphic > Button ![](../Pictures/Gui/ALL/ribbon_graphic_polyline_as.png) (Polyline). (You can draw rectangles, circles, etc. using the other buttons.)
2. Specify the points of the polyline consecutively, and click with the left mouse button each of the points to place them.
3. Exit the action using the [Space bar] or the Complete polyline popup menu item.
4. Select the Step command to insert a step. (To this purpose you first have to [Customize the ribbon](userinterface_h_menuebandanpassen.htm) and then assign the desired command to a user-defined command group.) In the same way you can insert other GRAFCET elements using the commands Step with transition, Action, Action with connection, and Transition.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The step is hanging on the cursor.
5. Select the desired variant of the step, such as a starting step, by pressing the [Tab] key several times.
6. Place the step in the operational sequence sheet.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Then the symbol hangs again on the cursor, and you can place another step.
7. End the action via the Cancel action popup menu item or via the [Esc] button.
8. Repeat the above steps for the other GRAFCET elements that you want to place in the operational sequence sheet.

![](../Pictures/Gui/ALL/info.png)Tips:

- You can insert special elements for operational sequence sheets (e.g., a forward slash, miscellaneous signaling elements, etc.) as window macros from the macro directory OS\_ESS. In addition, using the Arrows.ema macro you can also insert prefabricated arrows in a GRAFCET diagram.
- The asterisk (\*) in the GRAFCET elements inserted shows you that you can enter in this space texts such as step names, transition names or conditions or an action identifier. The different objects of a GRAFCET element are combined into a group. In order to enter a single text directly without undoing the grouping, keep the [SHIFT] key pressed and then open the Properties - Text dialog by clicking the respective asterisk.
- Using the C variant of the special symbol OS3, you can place only the displayed DT of the selected device. The D variant allows you to place only the variable of the highlighted device. This way you can insert the device tags or variables also as texts in the sequential control of a GRAFCET diagram.

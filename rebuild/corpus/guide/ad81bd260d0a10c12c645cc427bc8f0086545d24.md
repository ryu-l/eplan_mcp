# Activating the Properties (global) Mode

The Properties (global) editing mode allows global editing of the common properties of distributed functions in a single step.

Precondition:

You have opened a project.

1. Activate the button Global in the command group Options of the Edit tab.  
     
   ![](../Pictures/Gui/ALL/arrow.png) When you double-click a function, the properties of the function are automatically opened in the Properties (global): <...> dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) [Globally Editing the Properties for all Representations of a Main Function](reverseengineering_h_alledarstellungenbm.htm)  
     
   ![](../Pictures/Gui/ALL/arrow.png) [Globally Editing the Properties for all Representations of an Auxiliary Function](reverseengineering_h_alledarstellungenfunktion.htm)  
     
   ![](../Pictures/Gui/ALL/arrow.png) [Globally Changing the DT at Functions](devicetaggui_h_bmkaendern.htm)

![](../Pictures/Gui/ALL/info.png)Tip:

If the Properties (global) editing mode is selected, you can still edit the properties of distributed functions independently from each other. Highlight a function and select the Properties popup menu item.

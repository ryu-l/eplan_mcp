# Loading Directories and Projects

To access existing projects from the project management, you must load the project directory containing the project into the project management. You can only load directories that contain Eplan projects into project management.

Precondition:

There must be projects present in the directory that you would like to load.

1. Select the following commands: File > Project management.
2. In the Project management dialog, select the menu item [Extras] > Load directory.
3. Select a directory level from the Select initial directory dialog as an initial directory, and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan searches all subdirectories for projects and loads these, with the directory structure, into the project management.

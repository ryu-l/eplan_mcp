# The Help System

The Eplan help system contains conceptual information, usage instructions, and dialog descriptions of most of the program functions. The help is opened online via an Internet connection. The help system is displayed in the Internet browser that is set as the default on your computer. The help system can be used context-sensitive via [F1] or context-independent.

Most chapters are split into the following subchapters:

- Basics
- Proceed as Follows
- Reference

In addition to the Eplan Help, the help system also contains the "Eplan Overviews". You can find further information on special topics (e.g. Eplan properties and placeholder elements) here.

# Adjusting the Page Structure

When you copy pages or insert page macros, you can modify the structure identifier, page numbers and page descriptions before insertion.

The procedure for copying pages is described below. When inserting page macros, you can customize the page structure in the same manner.

Precondition:

You have selected one or more pages in the Pages - <Project name> navigator dialog.

1. Select the Copy popup menu item.
2. In the Pages - <Project name> navigator dialog, click the position where the copied pages are to be inserted and select the popup menu item Paste.
3. Change the page number, the page description, and / or the structure identifier on the Pages tab of the Adapt structure dialog. You can either enter the page number manually, or renumber by selecting [Number]. The Automatic page name check box also allows you to determine the next highest page number (in relation to the structure).
4. Click [Reset] if you want to retain the original structure identifiers when you insert multiple-page macros, for example.
5. To change the structure identifiers, click the appropriate field in the table. You can either manually enter (new) identifiers or open a selection dialog using [...]. The selection dialog contains all the identifiers that exist in the target project.
6. In order to modify structure identifiers extensively (for example to rename the main identifiers of several pages or DTs), select [Extras] > Edit structures. In the subsequent dialog Edit structures you can then specify / edit the main identifiers and up to 9 sub-identifiers respectively for the individual identifier blocks.
7. Select the Overwrite check box if pages of the same name in the target project are to be overwritten.
8. Select the DT tab if the copied DTs contain structure identifiers.
9. Change the visible DTs on the DT tab, if necessary.
10. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) If you have not made any changes, Eplan creates the structure identifiers for the source pages in the target project.  
      
    ![](../Pictures/Gui/ALL/arrow.png) A prompt appears if the target project contains pages with the same name that would be overwritten. If you click [Yes] the pages in the target project will be overwritten. Click [No] to return to the Adapt structure dialog and change your settings.  
      
    ![](../Pictures/Gui/ALL/arrow.png) If you selected the With prompt option by means of the commands File > Settings > Projects > "Project name" > Devices > Numbering (online), the Insertion mode dialog is displayed. You specify here as to how device tags should be numbered on the copied pages.
11. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The pages are inserted into the target project, and the structure identifiers and DT are changed accordingly.

### Behavior of the structure identifiers when copying

When copying pages from one project into another project with a smaller project structure, all structure identifiers defined as "Not available" in the target project are removed. Structure identifiers defined as "Describing" in the target project are retained.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

When copying pages from a project containing "Function designation" and "Location designation" identifier blocks into a project having sequential numbering, the structure identifiers are deleted from the page properties.

When copying pages from a project containing"Function designation" and "Location designation" identifier blocks into a project in which only the "Function designation" identifier block (no descriptive location designation) is used, the location designation is deleted from the page properties.

When pages are copied from a project containing structure identifiers (for example with "Function designation" and "Location designation" identifier blocks) into a project having a page structure using the "Function designation identifying" and "Location designation descriptive" identifier scheme, you have the possibility to renumber the pages. Without renumbering, the page names may no longer be unique since the identification part is lost.

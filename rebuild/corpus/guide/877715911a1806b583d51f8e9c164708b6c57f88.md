# P003003: Mismatch between connection DT and cable DT

### Cause

A connection definition point, situated within reach of a cable definition line or a shielding conductor, uses its own device designation. The cable or shielding conductor DT and the connection definition point DT do not correspond.

### Solution

1. Double-click the connection definition point in the schematic, and delete the displayed device tag of the connection definition point in the Properties <...> dialog.
2. Update the connections.
3. If required, start a new check run.

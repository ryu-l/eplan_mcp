# P024005: Undefined connection point (pressure / control line) connected with defined connection point (pressure / control line)

### Cause

A connection's functions conflict with the function connection points in terms of the entries for the Pressure line / control line property. For example, "Pressure line" was set as the value at the source of the connection, but "Undefined" was set at the target.

### Solution

1. Enter matching data for the Pressure line / control line property for both the source and target of the connection at the function connection points. You set this property in the Connection point logic dialog of the respective function (call up the Properties <...> dialog, select the Symbol / function data tab and click [Logic]).
2. Update the connections.
3. If required, start a new check run.

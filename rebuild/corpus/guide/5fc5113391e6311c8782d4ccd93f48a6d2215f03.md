# Deleting Column and Row Numbers and Placing Them Again

This functionality supports you in the labeling of column and row areas, in that all placed column and row numbers are deleted and automatically reset. An automatic placing function sets the column and row placeholder texts exactly on the edges of the defined columns and rows.

Preconditions:

- You have opened a project.
- You have opened a plot frame in the plot frame editor.
- You have placed column or row texts in the plot frame (Tab Edit > Command group Plot frame > Drop-down button Other > Insert column text or Insert row text).

1. Select the following commands: Tab Edit > Command group Plot frame > Drop-down button Other > Place column and row text again.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The column and row numbers are deleted and placed again. During the generation of special texts, the formatting last used is selected.

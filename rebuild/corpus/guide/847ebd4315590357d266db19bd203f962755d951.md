# P004016: Rack '<x>' is not unique

### Cause

A rack name is used more than once.

### Solution

1. In the Properties <...> dialog at the affected PLC boxes change the rack designation in the PLC structure data tab in such a way that the entered values differ.
2. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

This check run only checks PLC boxes at which a configuration project is entered.

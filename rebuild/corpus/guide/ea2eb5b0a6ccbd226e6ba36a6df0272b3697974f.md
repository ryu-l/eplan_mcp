# Inserting Objects via the Insert Center

The Insert center offers the possibility to insert different object types such as symbols, devices, window and/or symbol macros from a central dialog with drag & drop onto project pages or in layout spaces.

Preconditions:

- You have opened a project.
- You have opened a project page in the graphical editor. Or you have opened a layout space.

1. If the Insert center is not opened yet and is displayed as a reduced flyout, move the cursor on the vertically arranged Insert center tab at the right-hand margin of the graphical editor.  
     
    The Insert center is shown.
2. If you want an Insert center to be shown continuously for the period of the configuration, pin it in the title bar by clicking the ![](../Pictures/Gui/ALL/userinterface_unpin_as.png) icon.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The icon changes (![](../Pictures/Gui/ALL/userinterface_pin_as.png)) and the Insert center remains visible when you move the cursor back into the opened project page or into the layout space.
3. Depending on the desired object in the Insert center, click the folder Symbols, Devices or Window macros / symbol macros, or click the folder Recent, Favorites or Tags, if you want to insert objects using the quick access options. Alternatively, you can also use the [breadcrumb trail](insertergui_d_einfuegezentrum.htm#Navigationszeile) to switch between the different folders. Or use the comprehensive possibilities of [Find](insertergui_h_suchen.htm) to find the desired object more quickly.
4. Navigate through the folder structure until the corresponding objects are shown as tiles in the preview of the Insert center.
5. If you want detailed information on an object, mark the associated preview tile.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The preview tile is framed in blue.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the table of the information area the row with the most important properties of the object is marked.
6. If you want to insert a variant of an object, click the icon with the entered number in the preview tile of the object. (For example, the ![](../Pictures/Gui/ALL/insertergui_variants_tile_as.png) icon is displayed when eight variants of the object are available.)  
     
   ![](../Pictures/Gui/ALL/arrow.png) According to the number all available variants of the object are displayed as tiles in the preview. The variant name is displayed with one character (e.g. ![](../Pictures/Gui/ALL/insertergui_variant_name_tile_as.png) for the first variant).
7. Mark the tile with the desired object variant and keep the left mouse button pressed.
8. Drag the object from the Insert center into the opened project page or into the layout space.
9. Click the left mouse button briefly to place the object hanging on the cursor at the desired position.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Depending on the inserted object, the property dialog, the dialog Insert device, the dialog Insertion mode or the subsequent dialog is displayed.
10. Enter the desired property values or specify the required settings.
11. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The object still hangs on the cursor and can be placed again.
12. End the action via the Cancel action popup menu item or via the [Esc] button.

![](../Pictures/Gui/ALL/info.png)Tips:

- Alternatively to the drag & drop method, an object in a preview tile can also be inserted into the project page or the layout space by double-clicking and dragging or through marking and pressing the [Input] key.
- To insert variants of an object, the first variant of the object shown in the preview tile can be dragged from the Insert center into the graphical editor and can be placed in the desired variant by means of the key [Tab] or shortcut key [Ctrl] + mouse rotation.

![](../Pictures/Gui/ALL/note.png)Notes

- A [macro collection](insertergui_k_makrosammlung.htm) is required for the insertion of window and symbol macros.
- Which objects can be inserted and are shown in the Insert center depends on whether a project page or a layout space is currently opened. For example, no symbols are offered when a layout space is open.

# Changing Piping Elbows

In order to adapt the form of a piping to the installation situation the piping elbows contained in it can be modified, inserted additionally and deleted.

Preconditions:

- You have opened a project. You have opened a layout space.
- The layout space contains freely routed pipings.

### [ClosedMoving a piping elbow / bending position](javascript:void(0);)

1. Select the following commands: Tab Edit > Command group Graphic > Change bending positions.
2. To change the position of a bending position at a piping move the cursor over the piping elbow.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The segment is highlighted in color.
3. Click the piping elbow.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Two arrows are displayed in the axial directions of the two adjacent piping segments and a third arrow to changes the bending radius.
4. Select the direction in which you want to move the piping elbow by clicking the green arrow.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The segment can be moved in the selected arrow direction.
5. Click the desired end point for the move or enter an angle in the input box.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The piping elbow is moved to the selected position. The adjacent segments and the angles of the piping elbows involved are adapted correspondingly.  
     
   ![](../Pictures/Visualisation/ALL/piping_movebending_as.png)

### [ClosedChange bending radius](javascript:void(0);)

1. Select the following commands: Tab Edit > Command group Graphic > Change bending positions.
2. To change the radius of a bending position at a piping move the cursor over the piping elbow.
3. Click the piping elbow.
4. Click the green arrow that points inward at the angle or the piping elbow.  
     
   ![](../Pictures/Visualisation/ALL/piping_changebendingradius_as.png)  
     
   ![](../Pictures/Gui/ALL/arrow.png) The radius of the piping elbow can be enlarged or reduced by moving the cursor.
5. Click the desired end point for the change to the radius or enter a new value in the input box.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The radius of the piping elbow is modified, the adjacent segment are adjusted accordingly.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the radius is smaller than the minimum bending radius defined in the part, the piping elbow is displayed in bright blue.  
     
   ![](../Pictures/Visualisation/ALL/piping_bendingradiuschanged_as.png)

### [ClosedInserting an additional piping elbow](javascript:void(0);)

1. Select the following commands: Tab Edit > Command group Graphic > New bending position.
2. To insert a new bending position in a straight segment of a piping move the cursor over the segment.
3. Click the segment.
4. Select the direction in which you want to move the new bending position by clicking the green arrow.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The segment is divided into three parts. the middle third can be moved in the selected arrow direction.
5. Click the desired end point for the move or enter a distance value in the input box.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The middle third of the segment is moved to the selected position.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Four new piping elbows are inserted that connect the partial segment with the piping.  
     
   ![](../Pictures/Visualisation/ALL/piping_additionalbending_as.png)

### [ClosedDeleting a piping elbow / bending position](javascript:void(0);)

1. Select the following commands: Tab Edit > Command group Graphic > Delete bending position.
2. Click the bending position to be deleted.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The piping elbow is deleted and is replaced by a straight segment. The adjacent segments and piping elbows are adapted accordingly.

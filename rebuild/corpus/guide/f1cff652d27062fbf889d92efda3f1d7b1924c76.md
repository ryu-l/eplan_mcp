# Dialog DXF / DWG export

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You highlighted a project or at least a project page. File > Export > Command group Project data > Project data > Command group Page > DXF / DWG.

In this dialog you start the actual export process. When exporting an entire project or individual pages to DXF / DWG format, a separate file is generated for every selected page.

Overview of the main dialog elements:

Source:

This field displays the source of the export. For an entire project, this is the project name; for individual pages the full page names are displayed (including the page properties Functional assignment, Function designation, etc.). The entries can't be edited here.

Scheme:

Select a scheme to define the settings for the export of files from the drop-down list. Click [...] to open the settings dialog for the export. There you can define settings and save them as a scheme or [Edit existing schemes](schemeconfig_h_schematabearbeiten.htm).

Output directory:

Enter the storage location here. You can specify any drive and subdirectory as the target for the export. Click ![](../Pictures/Gui/ALL/all_selectdirectory_as.png) to open the Select folder dialog and then navigate to the desired directory, or create a new one.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

File name:

When exporting a single page you can enter any desired file name here. You can use ![](../Pictures/Gui/ALL/all_selectfile_as.png) to assign a new file name or select the name of an existing file.

If no file name is specified, a name is assigned to the exported file on the basis of the Generate file names setting.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

![](../Pictures/Gui/ALL/note.png)Note:

When exporting multiple pages, the file name cannot be freely chosen. DXF- / DWG files are created as a consecutive number in the specified target directory, or from the page name, or from the properties; this depends on the settings of the selected scheme.

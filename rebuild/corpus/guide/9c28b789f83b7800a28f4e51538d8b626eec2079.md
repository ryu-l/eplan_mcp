# Master Data: Managing Parts Data

In addition to the general parts database there is an internal project parts database, in which the parts data used in the project are stored. Data for a part is transferred from the parts database into the project for each part selection, even if only the part number is stored on the component in the graphical editing at the time the part is selected.

Project data can be synchronized later with the system master data for the entire project using the Update current project menu item. Alternatively you can selectively update individual parts in the project using the Synchronization of parts - <project name> dialog. In this dialog, you also have the opportunity to complete the system (i.e. the parts database). Parts which were previously only present in the project are transferred into the parts database. Furthermore, certain stored parts properties can be removed from the project.

Precondition:

You have selected a parts database in the dialog Settings: Parts (user).

### Update current project

1. Open the project whose parts are to be synchronized.
2. Select the following commands: Tab Master data > Command group Parts > Update.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The current project is searched for obsolete parts data. If parts data that is more up-to-date is found in the system (i.e. in the parts database) for the parts in the project, the data from the parts database is transferred into the project, i.e. it overwrites the parts stored in the project.

### Update individual parts in the project

1. Open the project whose parts are to be synchronized.
2. Select the following commands: Tab Master data > Command group Parts > Synchronize.
3. In the System parts list of the Synchronization of parts - <Project name> dialog, select the parts you wish to update in the project. Multiple selection is possible.
4. Click ![](../Pictures/Gui/ALL/all_arrowleft_as.png).
5. Click [Close].  
     
   ![](../Pictures/Gui/ALL/arrow.png) For the selected parts the data is transferred from the parts database and updated in the project.

![](../Pictures/Gui/ALL/note.png)Note:

In order to protect the data in the parts database, you cannot update the system data via this dialog. For that reason parts which have a 'newer' status in the project than in the system parts cannot transfer data into the system. The ![](../Pictures/Gui/ALL/all_arrowright_as.png) button for the corresponding parts in the Stored parts list is therefore grayed out.

### Complete current system

1. Open the project whose parts are to be synchronized.
2. Select the following commands: Tab Master data > Command group Part > Synchronize.
3. Select [Extras] > Complete current system in the dialog Synchronization of parts - <Project name>.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Parts which are in the project but not in the system are created in the parts database.

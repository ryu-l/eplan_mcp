# P013047: Part with index '<x>' has already been imported

### Cause

A part index that is used more than once was found when importing the bill of materials. The values in the field name 'REFERENCE\_POS' in the import file may have been changed manually for several parts with the result that several identical part indexes may have been assigned.

![](../Pictures/Gui/ALL/note.png)Note:

In Eplan a maximum of 50 parts can be assigned to a device. The part index defines the order in which the parts are entered in the Property <...> dialog on the Parts tab.

### Solution

1. Open the import file with a text or XML editor, and find the index specified in the message management dialog under message '013047', e.g. by entering the search entry REFERENCE\_POS="<Index>".
2. Correct the indexes if you find a multiple assignation.
3. Save the file, then import the bill of materials again.

![](../Pictures/Gui/ALL/note.png)Notes:

- Further information appears in the Help under [Importing bills of materials](partslistgui_h_stuecklistenimportieren.htm).
- Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

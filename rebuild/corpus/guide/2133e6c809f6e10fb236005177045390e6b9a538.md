# Dialog Settings: Numbering (online)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Settings > Projects > "Project name" > Devices > Numbering (online).

In this dialog, you determine the settings for online numbering project-specifically. This includes the online numbering format and the specifications of how devices are numbered when being copied and pasted into the schematic.

Overview of the main dialog elements:

Identifiers:

Select the scheme for identifiers from this drop-down list. In such a scheme, an identifier set is defined that specifies the assignment of identifiers and functions. Or click [...] to edit an existing scheme or create a new scheme using the [Identifiers](numerationgui_d_kennbuchstaben.htm) dialog.

Identifier subclasses:

Select the scheme for identifier subclasses from this drop-down list. Or click [...] to edit an existing scheme or create a new scheme using the [Identifier subclasses](numerationgui_d_kennbuchstabenunterklassen.htm) dialog.

---

Group box On symbol insertion

In this group box you specify the automatic numbering behavior for new devices. This applies, for example, to devices that you place in the schematic using Insert > Symbol or create in the device navigator.

Empty field:

The device is not automatically numbered during insertion. No visible DT is assigned to the device.

Number:

The device is automatically numbered during insertion. A visible and a full DT is assigned to the device.

Number with flag "?":

The device is automatically numbered during insertion. A visible and a full DT is assigned to the device. A question mark is also inserted as a tag before the identifier. All devices that contain an identifier in the DT can be renumbered independent of other devices.

Numbering format:

This numbering format affects all the devices that you place on the schematic page via the Insert center (Insert center > Breadcrumb trail Home > Symbols) or, for example, newly create in the device navigator. In numbering formats, you specify which format elements are to be used and which device types are to be taken into consideration during numbering. The drop-down list displays all the available online numbering formats. You can use [...] to create, edit, copy, delete, import, and export numbering formats.

---

Group box On insertion of macros and copies

In this group box you indicate whether the original numbering is kept for devices that you insert into the schematic from the Clipboard, or whether the devices are renumbered automatically during insertion.

Do not modify:

If this option is selected, the devices are inserted unchanged. The numbering of the devices is retained. Structure identifiers are defined by the page.

Number:

If this option is selected, then the inserted devices are automatically renumbered during insertion. The specified numbering format is taken into consideration here.

Number with flag "?":

If this option is selected, the inserted devices are automatically renumbered on insertion and tagged with a question mark. The specified numbering format is taken into consideration here.

With prompt:

If this option is selected, the Insertion mode dialog opens during the insertion of devices. Here you can indicate whether the numbering of the devices is kept or whether the devices are renumbered and identified with an identifier.

Numbering format:

This numbering format affects all the devices that you insert from the Clipboard into the schematic via the macros and / or by copying from the Clipboard. In numbering formats, you specify which format elements are to be used and which device types are to be taken into consideration during numbering. The drop-down list displays all the available online numbering formats. You can use [...] to create, edit, copy, delete, import, and export numbering formats.

Number prefix if existing:

This field is available if the Number option is selected. This setting allows numbering of the prefix of the DTs of inserted device copies or inserted devices in macros. This functionality only affects device groups for which the Keep prefix numbering format setting in the DT format dialog that you can access in the project settings is activated (command path: File > Settings > Projects > "Project name" > Device > Numbering (online)).

[Connection point designations / descriptions]:

With this button you open the [Connection point designations and descriptions](numerationgui_d_anschlussbezeichnungen.htm) dialog. In this dialog, you have the option of storing 10 sets of connection point designations and descriptions for each function definition.

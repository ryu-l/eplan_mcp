# P004102: The bus port in the station '<x>' is connected by a bus extension cable with the bus port in the station '<y>'

### Cause

Within a configuration project two bus ports that are located on racks of different workstations are connected by a bus extension cable. This means that the bus system setting "Local-Bus: Extension" is assigned to the bus ports connected to each other. This setting is invalid when the racks are assigned to different workstations.

### Solution

#### Possibility 1

1. Locate the bus port of the workstation '<x>' in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Call up the property dialog of the bus port.
3. Bring the Bus data tab to the front.
4. From the drop-down list Bus system change the specified value "Local-Bus: Extension", and instead select the required bus system.
5. Click [OK].
6. Locate the bus port of workstation '<y>' in the schematic, by selecting the function Go to (2nd coordinate) from the popup menu of the message management.
7. Repeat the settings described under Point 2 to Point 5 for the second bus port as well.
8. Update the connections.
9. If required, start a new check run.

#### Possibility 2

1. Open the property dialogs of the corresponding PLC boxes for both bus ports, and remember the workstation name entered in the tab PLC structure data.
2. Then standardize the workstation names of both PLC boxes.
3. Click [OK].
4. Update the connections.
5. If required, start a new check run.

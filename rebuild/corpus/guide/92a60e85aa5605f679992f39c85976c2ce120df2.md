# Creating Segment Templates

Segment templates are created and managed in the segment template navigator.

### Creating segment templates

1. Select the following commands: Tab Pre-planning > Command group General > Segment templates.
2. In the tree mark a segment definition (such as a loop) and select the popup menu item New segment template.
3. Enter the identifying name and an optional description for the new segment template in the Segment templates tab in the Properties <...> dialog.
4. If required, assign subordinate segment templates to the segment template via the table Subordinate segment templates. To do this click ![](../Pictures/Gui/ALL/all_new_as.png) (New), and select the desired segment template in the subsequent Select segment template dialog. Multiple selection is possible. If required, enter a text for which the segment templates are to be filtered in the Find field.
5. If required, assign further properties to the segment template in other tabs. Which tabs are displayed depends on the segment definition.
6. If necessary, enter a part in the Part tab. The function templates of the part can later be used to create the detail planning.
7. If necessary, enter a macro in the Macro tab. You can later use this macro for [Creation of the Detail Planning](planninggui_h_makrosdragdrop.htm).
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) A segment template with the appropriate properties is created.

![](../Pictures/Gui/ALL/info.png)Tips:

- In the tree view of the segment template navigator you can move the segment templates via drag & drop to another part within the same basic segment definition, if these segment templates are not used yet in the project. In the process the segment definition is automatically assigned to the segment template below which it was moved. While dragging, keep the [Ctrl] key pressed to copy the highlighted segment templates.
- You can select several segment templates simultaneously in the segment template navigator. If you have now selected segment templates that have the same subordinate segment templates, you can use Block editing, for example, to select subordinate segment templates simultaneously for all selected segment templates or delete selected subordinate segment templates again. To do so, select these segment templates in the segment template navigator and select the Properties popup menu item.

### Creating segment template from an existing segment

Preconditions:

- You have opened a project that already contains segments.
- You have opened the pre-planning navigator and the segment template navigator.

1. Select a segment in the pre-planning navigator.
2. Drag the segment in the segment template navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A segment template with the properties of the marked segment is created.

![](../Pictures/Gui/ALL/note.png)Notes:

- The segment template is not assigned to the segment from which it was generated. You must carry out this assignment manually if you need to.
- Segment templates with subordinate segment templates can not be created this way.

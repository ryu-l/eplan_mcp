# Dialog Plot frame properties - <Plot frame name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Tab Master data > Command group Plot frames / forms > Drop-down button Plot frame > New > [Save].
- Tab Master data > Command group Plot frames / forms > Drop-down button Form > Open > Button [Open]. Select the Properties popup menu item on the plot frame in the Pages <Project name> navigator dialog.

In this dialog, you specify the properties for the newly created or opened plot frame.

Overview of the main dialog elements:

Property name / Value:

The available properties are displayed depending on the selected category. Some of them, for example Company code and Modification date have already been assigned values that can't be changed. Others, such as the Description and Version properties, can be assigned values or their existing values can be changed.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# P502034: The PLC device identification is not unique

### Cause

In the parts database to be checked a PLC part was determined where a non-unique device identification is assigned.

Identification of the devices in Eplan is effected either by means of the PLC type designation or by specifying a device description file. In the concrete case the same PLC type designation or the same device description data was assigned to several PLC parts.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Properties tab to the front.
3. In the property table open the hierarchy level PLC data.
4. Correct the entry either in the value field of the PLC type designation property or the Device description: File name property.
5. Click [OK].
6. Click [Apply].
7. If required, start a new check run.
8. Close the parts management and perform a parts data synchronization.

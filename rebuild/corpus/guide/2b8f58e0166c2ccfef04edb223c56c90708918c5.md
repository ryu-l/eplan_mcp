# Overview of Actions for the Ribbon

The following Actions can be inserted as commands when customizing the ribbons:

| Action | Meaning |
| --- | --- |
| Define setting | Sets a user, station, or company setting to a certain value. |
| Import settings | Imports the settings for property arrangement, dialog memory and tree and list configurations. |
| Run external program | Allows the execution of an external program that can be called up from Eplan. |
| Export manufacturing data / Output labeling | Outputs the manufacturing data / labeling for a project. |
| Set format of graphical elements | Sets one or more formatting settings of selected graphical elements to specific value(s). If you have not yet selected a graphical element then, after clicking the button, the cursor symbol changes and you can select a desired area containing the graphical elements. Further information on the format settings is available [here](availableactions_o_xgedstartinteractionaction.htm). |
| Export functions | Exports the function properties of the current project for external editing. |
| Insert device | Allows placing of a pre-defined device without calling up a dialog. |
| Insert macro | Allows insertion of a particular variant of a pre-defined macro without calling up a dialog. If the variant does not exist in the macro then a message is displayed. |
| Export to Rittal - Athex | Exports the manufacturing data of terminal strips and alignable terminal accessories for controlling the automatic Rittal - Athex equipment system. |
| Manage project | Runs an action for the project management or for projects. It is possible, among other things, to reorganize a project. Further information about the possible settings is available [here](availableactions_o_projectmanagement.htm). |
| Set project property | Sets a project property for a selected project to a specific value. |
| Define project setting | Sets a project setting to a certain value. |
| Set component property | Sets a component property for a selected component to a specific value. |
| Set component format | Sets one or more formatting properties for all property texts of selected components to specific value(s). If you have not yet selected a component then, after clicking the button, the cursor symbol changes and you can select a desired area containing the components. Further information on the format settings is available [here](availableactions_o_xgedstartinteractionaction.htm). |
| Export pages | Exports the page properties of the current project for external editing. |
| Set page property | Sets a page property for a selected page to a specific value. |
| Insert symbol | Allows insertion of a pre-defined symbol without calling up a dialog. If the "?" placeholders in the command line are not replaced with sensible values, then the Symbol selection dialog is opened. |
| Insert symbol with function definition | Allows insertion of symbols with the same function definition. |
| Set text format | Sets one or more formatting settings of selected text elements to specific value(s). If you have not yet selected a text element then, after clicking the button, the cursor symbol changes and you can select a desired area containing the components. Further information on the format settings is available [here](availableactions_o_xgedstartinteractionaction.htm). |
| Export connections | Exports the connection properties of the current project for external editing. |
| Set graphical format of connections (connection definition point, potential definition point) | Sets one or more formatting settings of selected connection and / or potential definition points to specific value(s). If you have not yet selected a definition point then, after clicking the button, the cursor symbol changes and you can select a desired area containing the definition points. Further information on the format settings is available [here](availableactions_o_xgedstartinteractionaction.htm). |

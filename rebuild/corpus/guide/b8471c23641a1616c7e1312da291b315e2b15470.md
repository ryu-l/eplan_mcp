# Dialog Settings: Add-ons

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > Company > Management > Add-ons

In this dialog you define the directory path for the automatic registration of add-ons.

Overview of the main dialog elements:

File path for automatic add-on registration:

In this field you specify the directory path on a server directory where the install.xml file for automatic registration of add-ons is located. By default, you or your administrator saves an add-on and its associated file install.xml in a central server directory. When starting Eplan, this server directory is searched. Add-ons and more current versions of add-ons are automatically registered.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

# P003019: Subcable generated

### Description

A cable with subcables was created. This is the case when you select a cable part which provides fewer cable connections than you require.

If required, select a different cable part with a fitting number of cable connections if you do not want to use a subcable.

![](../Pictures/Gui/ALL/note.png)Note:

This module-related message is shown when cables are created automatically. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

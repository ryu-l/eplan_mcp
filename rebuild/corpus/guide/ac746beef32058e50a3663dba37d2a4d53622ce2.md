# Tab Settings (placeholder object)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project page in the graphical editor. Or you have opened a layout space.

- Tab Master data > Command group Macros > Drop-down button Navigator > Insert placeholder object. Select an area with objects that should belong to the placeholder object. In the Properties <...> dialog, select the Settings tab.
- Double-click the "anchor" symbol of an already created placeholder object. In the Properties <...> dialog, select the Settings tab.
- Tab Devices > Command group Project options > Placeholder objects. In the Placeholder objects - <Project name> dialog mark a placeholder object and select the Properties popup menu item. In the Properties <...> dialog, select the Settings tab.

In this tab you specify the settings for the usage of placeholder objects. In Eplan applications Eplan eBuild and Eplan Cogineer and in the pre-planning, placeholder objects in the macros are used to vary the data during the generation of schematics or on the generated schematic pages.

Overview of the main dialog elements:

Use placeholder object in Eplan eBuild and Eplan Cogineer:

If this check box is activated, the placeholder object is available after adding the macro in Eplan eBuild / Eplan Cogineer and is taken into consideration during the schematic generation in the respective Eplan application. In this case values assigned in Eplan eBuild / Eplan Cogineer are displayed at the placeholder object on the generated schematic page.

If the check box is deactivated, the placeholder object in Eplan eBuild / Eplan Cogineer is not available. In this case the placeholder object is displayed unchanged on the generated schematic page. Subsequently a value set can be assigned on the schematic page.

Remove placeholder object after generation:

This check box is only available if the setting Use placeholder object in Eplan eBuild and Eplan Cogineer has been activated.

If this check box is activated, the placeholder object is deleted from the schematic after the generation of the schematic with the respective Eplan application.

Consider placeholder object in the pre-planning:

If this check box is activated, the placeholder object is displayed after assigning the macros at the planning object in the Macro tab. The values of the placeholder object can be edited in the pre-planning. After creating the detail planning, the values changed in the pre-planning are displayed at the placeholder object on the generated schematic page.

If the check box is deactivated, the placeholder object at the planning object is not displayed in the Macro tab anymore. The values of the placeholder object can therefore not be edited in the pre-planning. After creation of the detail planning the placeholder object is displayed unchanged on the schematic page.

After generating the schematic, the placeholder object - independent of this setting - is available on the generated schematic page and other values can be assigned via the assignment of a value set.

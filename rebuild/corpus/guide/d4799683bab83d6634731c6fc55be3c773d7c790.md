# Action: XSDPreviewAction

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| PROJECTNAME | Name of project. If the file path is missing, the default value is used (see $(MD\_PROJECTS)). |
| PAGENAME | Name of a page as string |
| MACRONAME | Complete file path to a window or page macro (with file name extension). If the file path is missing, the default value is used (see $(MD\_MACROS)). |
| SHOW | 1: The preview of the page / macro is opened;  0: The graphical preview closes. |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Preview of a page:

```
XSDPreviewAction 
/PROJECTNAME:EPLAN_Sample_Project 
/PAGENAME:=CA1+EAA/1
```

```
XSDPreviewAction 
/PROJECTNAME:"C:\...\EPLAN\Electric P8\Projects\...\EPLAN_Sample_Project" 
/PAGENAME:=CA1+EAA/2
```

Preview of a page macro:

```
XSDPreviewAction 
/PROJECTNAME:EPLAN_Sample_Project 
/MACRONAME:Macro_0001.ema
```

```
XSDPreviewAction 
/PROJECTNAME:$(MD_PROJECTS)\EPLAN_Sample_Project 
/MACRONAME:$(MD_MACROS)\Macro_0001.ema
```

# Dialog Update detailed planning

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Tab Pre-planning > Command group General > Navigator. You have selected one or more segments in the pre-planning navigator. Popup menu item Update detailed planning.

In this dialog you specify the updating scope for the detailed planning.

Overview of the main dialog elements:

Place macros again:

If this check box is activated, the placements of the macros entered at the marked planning objects / PCT loops are deleted and these macros are placed again. During this process, all objects are exchanged which are inside a macro box.

Update device tags and symbolic addresses:

If this check box is activated, the device tags of the functions and structure segments placed in the detailed planning are updated. In addition the symbolic addresses at the subordinate segments (planning objects, PCT loops) in the pre-planning navigator and at the placed PLC connection points are updated in the schematic. This is for example relevant when the structure identifiers and / or individual components of the symbolic address of superior segments have been modified in the pre-planning navigator.

Update value sets of placeholder objects:

If this check box is activated, you can transfer the modified data from the pre-planning to the placeholder objects placed in the detailed planning. As the prerequisite macros have to be entered at one or more planning objects or PCT loops and these macros have to be placed in the detailed planning. Possible changes in the pre-planning are, for example, the selection of other value sets for the placeholder objects in the macros.

Update piping data:

If this check box is activated, the piping data are transferred from the piping planning objects to the defined pipings in the P&I diagram. In the process the pipe class, the associated properties and the substance are transferred to the placed piping definition points and connections. Only the pipe class and the associated properties are transferred at the functions in the pipings.

If a check box is deactivated, the respective objects are not updated in the detailed planning.

Synchronize parts:

If this check box is selected, the pre-planning parts are synchronized with parts in the detailed planning. In the process the part information at the main functions in the detailed planning is deleted and replaced by the part information of the assigned segments.

# P022020: The '<x>/<y>' symbol from the '<z>' symbol library was created during the data transfer of an EPLAN 5 or EPLAN 21 project

### Description

In the project an obsolete symbol with the symbol number > 3000 has been found, which was created during the data transfer of an EPLAN 5 or EPLAN 21 project. If possible, the symbol should not be used anymore.

Meaning of the placeholders in the message text:

- <x> indicates the symbol number.
- <y> indicates the symbol name.
- <z> indicates the name of the symbol library.

By means of the functionality Go to (graphic), which is offered to you by the popup menu of the dialog Message management, it is possible to locate the respective symbol in the schematic from the message management.

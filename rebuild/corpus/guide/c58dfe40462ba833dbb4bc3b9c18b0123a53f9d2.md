# Managing Layout Space Views

Preconditions:

- You have opened a project.
- You have opened the layout space navigator and a layout space.
- The layout space contains a 3D object (or a 3D mounting layout).
- You have specified a home view for the navigation cube, for example the view "SE Isometric", in the user-specific settings.
- You have opened the Layout space views dialog.

### [ClosedSaving a layout space view](javascript:void(0);)

1. Generate a view for your layout space, for example by means of the navigation cube.
2. Select a tile in the Layout space views dialog.
3. Click the ![](../Pictures/Gui/ALL/all_new_as.png) icon (Add current view), or select the Add current view menu item in the popup menu of the tile.  
   ![](../Pictures/Gui/ALL/arrow.png) A preview image of the saved view is displayed on the tile.

### [ClosedRetrieving and reusing the layout space view](javascript:void(0);)

1. Select a tile in the Layout space views dialog.
2. Select the Use view menu item in the popup menu of the tile or double-click the tile.  
   ![](../Pictures/Gui/ALL/arrow.png) The view stored on the tile is applied to your layout space.

![](../Pictures/Gui/ALL/info.png)Tips:

- You can also use a view without the set viewing angle, with the items and connections hidden in the saved view or without the items and connections shown in the saved view. To do so, select the Viewing angle on / off or Visibility on / off popup menu item before retrieving the view. The corresponding tile icon ![](../Pictures/Gui/ALL/views_viewing_angle_as.png) or ![](../Pictures/Gui/ALL/views_visibility_as.png) is then hidden.
- You can also retrieve views by using shortcut keys. In the Customize shortcut keys dialog you can assign a shortcut key to each tile. To this purpose the Activate layout space view 1 to Activate layout space view 10 commands are available in the Customize shortcut keys dialog if you select the All commands entry in the Tabs field.

### [ClosedRenaming a layout space view](javascript:void(0);)

By default, the layout space views are named View 1 to View 10. You can change the name of a view.

1. Select a tile in the Layout space views dialog.
2. Select the Rename view menu item in the popup menu of the tile.  
   ![](../Pictures/Gui/ALL/arrow.png) The Renaming a layout space view dialog is displayed.
3. Please enter a new name for the view.
4. Click [OK].  
   ![](../Pictures/Gui/ALL/arrow.png) The new name of the view is displayed on the tile.

### [ClosedDeleting a layout space view](javascript:void(0);)

1. Select a tile in the Layout space views dialog.
2. Click the ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete view) icon, or select the Delete view menu item in the popup menu of the tile.
3. Click [Yes] to confirm the subsequent prompt.  
   ![](../Pictures/Gui/ALL/arrow.png) The preview image of the deleted view is no longer displayed on the tile.

### [ClosedOverwriting a layout space view](javascript:void(0);)

1. Generate a view for your layout space, for example by means of the navigation cube.
2. In the Layout space views dialog, select a tile on which a view is already saved.
3. Click the ![](../Pictures/Gui/ALL/all_new_as.png) icon (Add current view), or select the Add current view menu item in the popup menu of the tile.
4. Click [Yes] to confirm the subsequent prompt.  
   ![](../Pictures/Gui/ALL/arrow.png) A preview image of the newly saved view is displayed on the tile.

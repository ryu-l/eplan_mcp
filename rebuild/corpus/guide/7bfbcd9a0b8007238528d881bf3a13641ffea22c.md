# Action: XEsUserPropertiesExportAction

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| XMLFile | Name of the XML file to which the export is to be carried out, including the complete path |
| Project | Complete name of the project whose user-defined properties are to be exported |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
XEsUserPropertiesExportAction 
/XMLFile:c:\my_user.xml 
/Project:c:\...\EPLAN_Sample_Project.elk
```

# Specifying a Separate Directory for the Macro Collection

By default the macro directory specified in the settings for the directories is used for the storage of the macro collection. If required, you can now specify a deviating directory for the macro collection.

This can be useful, for example, if a network directory which several users can access has been specified for the macro directory. In such a case the search for macros in the Insert center can take a relatively long time. By specifying a local directory that deviates from the specified macro directory, you can ensure that the search for macros in the Insert center takes place quicker.

To specify a separate directory for the macro collection the Settings: Exceptions dialog in Settings: Macro collection has been renamed, moved to the user settings and extended with the new Database directory setting. The command path to this dialog is: File > Settings > User > Management > Macro collection. This new feature is available as of Version 2025 Update1.

### Extensions to the exceptions for the macro collection

In addition the setting for exceptions at the macro directories has been moved from the company settings into the user-specific settings dialog. All settings relating to files and directories are usually saved in the user settings. This new feature is available as of Version 2025 Update1.

In the Settings: Exceptions dialog you could previously only select directories but not manually enter a directory path or use path variables. In the new dialog Settings: Macro collection this is now possible for the exceptions in the Directory column. The specified macro directories are then not displayed as folders in the Insert center.

### Deactivating automatic checking of the macro directories

By default, the macro directory is automatically checked for changes. If the macro directory is located in a network, this can result in a high utilization of the network. In such a case you can now deactivate automatic checking.

To activate or deactivate checking you can use the new Automatically check macro directory for changes setting in the Settings: Macro collection dialog. The check box is activated by default.

If the check box is deactivated, the macro directories in a network are no longer automatically checked for changes. Changes carried out by other users or changes carried out outside of Eplan in the file directories are then no longer recorded. If a manual change is carried out within Eplan (for example creation of a macro), the macro collection is nevertheless updated automatically.

This new feature is available as of Version 2025 Update3.

### Renamed file extensions of the macro collection

The file extensions of the macro collection have now been renamed from \*.mdb and \*.mlk to \*.emdb and \*.emlk in order to avoid confusion with Microsoft Access files. Since Version 2025 the name of the macro collection is furthermore supplemented by the version number (for example "Macros\_2026.emlk").

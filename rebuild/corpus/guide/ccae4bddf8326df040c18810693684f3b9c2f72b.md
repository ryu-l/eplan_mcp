# Tab Messages

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Master data > Command group Parts > Management. You have opened a parts database using [Extras] > Settings. You have selected the "Parts" main node in the parts management tree.

The check run messages for part master data (message class 502) are displayed in this tab.

Overview of the main dialog elements:

Table:

- Status: Shows the message category assigned to the message in the form of an icon.
- Category: Displays the message category assigned to the message.
- Number: Each message is identified by a unique number. In addition, the message number provides information about the message class, i.e. the area where the message occurred.
- Part number: Shows the part with missing or impermissible data.
- Part variant: Shows the part variant with missing or impermissible data.
- Message text: This describes the error in more detail.
- Completed: Select this check box if you have corrected an error. You have the option to check only the corrected messages in a subsequent check run. This way you can check whether your corrections in the parts management have been successful.
- Generated by: Shows who defined the message. In most cases, the messages are defined by Eplan. Using the API interface, however, you have the option of defining your own messages.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Go to | Shows the selected part in the tree view of the parts management. |

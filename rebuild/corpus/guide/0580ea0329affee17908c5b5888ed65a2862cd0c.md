# Editing the Properties of the Selected Function Representation

A function can be represented more than once in the project, as a distributed single-line, multi-line, overview, pair cross-reference function, and / or a P&I diagram function. You can edit the properties of the distributed function representations independently from each other.

Preconditions:

- You have opened a project.
- You have opened the graphical editor or the device navigator.

1. Deactivate the Global button in the command group Options of the Edit tab.
2. In the function representation, double-click a main function or auxiliary function.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The properties of the selected function representation are displayed in the Properties (components): <...> dialog.
3. Change the desired properties and click [OK].
4. Press [F5] to update.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The properties are only changed at the selected function representation.

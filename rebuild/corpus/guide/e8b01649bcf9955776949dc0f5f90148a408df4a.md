# P005066: Connection (multi-line) does not have a counterpiece (3D mounting layout)

### Cause

There exists a connection of the "Multi-line" representation type in the schematic, whose corresponding connection of the "3D mounting layout" representation type does not exist in the layout space. Thus, the connection between the source and target was not routed in the layout space, or the routing connection between the source and target was deleted subsequently.

### Solution

1. Locate the multi-line connection in the schematic using the functionality Go to (graphic) from the popup menu in the Message management dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the connection has a connection definition point, a jump to it in the schematic is made. If there is no connection definition point, a jump is made to the source of the connection.
2. Follow the connection in the multi-line representation both up to the connected source and the connected target.
3. Highlight the source and target in each case.
4. Use the Go to (counterpiece) functionality from the popup menu to determine whether the source and target exist in the layout space as counterpiece (part placement) of the "3D mounting layout" representation type.
5. Using the mouse, define in the layout space a selection area that includes the source and target determined.
6. Generate routing connections between the source and target by means of the following commands: Tab Edit > Command group Routing connections > Route.
7. If required, start a new check run.

# Data from Unplaced Functions

It is possible to create functions without having to place them in the schematic or mounting plan. All data in these "unplaced" functions can be changed or adapted. The creation of connections between unplaced and placed functions, and between unplaced and unplaced functions is also possible.

The creation of functions is realized using so-called device definitions (types). Device definitions contain function templates, where function templates contain the minimum identifying properties which are used to create functions (placed or unplaced).

In unplaced functions, no data relating to the graphic can be stored, i.e., no symbols, line data, position of property placements etc. This data is defined by the user during placement.

# P004086: Missing PLC type designation or device description file

### Cause

No device identification could be determined at a PLC box that is assigned to a configuration project. Either the value of the property PLC type designation (it is first checked) or the property Device description: File name (it is checked subsequently) is empty. Or no value is stored at both properties.

This check run only checks PLC boxes at which a configuration project is entered.

### Solution

1. Locate the PLC box in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Open the property dialog of the PLC box.
3. Bring the first tab to the front.
4. In the properties table fill the required information either into the value field of the PLC type designation property or into the value field of the Device description: File name property.
5. Click [OK].
6. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

If the Integrated module property in the PLC structure data tab is activated, the PLC type designation and Device description: File name properties in the first tab may remain empty.

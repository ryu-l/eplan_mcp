# Dialog Pre-planning - <Project name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Tab Pre-planning > Command group General > Navigator
- You have opened an editor such as the graphical editor, the plot frame editor, etc. Tab View > Command group Navigators > Drop-down button Open > Pre-planning.

Use this dialog to display the structure segments and planning objects defined in the project either in the tree or list view and to edit them.

Overview of the main dialog elements:

In the Tree tab, the structure segments and planning objects are displayed in their hierarchical structure. The top hierarchy level is the project; below that, structure segments and planning objects can be created. Structure segments cannot be sorted below planning objects.

Below planning objects, their PLC addresses and function templates are displayed. A preceding status icon indicates whether a macro has been stored at the planning object. Such a macro can be placed in the graphical editor using Drag & Drop. The representation type that fits the page type is offered for placement.

The segments are sorted by default first by their basic definition and then by their designation. The sequence of the basic definitions is:

- Structure segments
- Containers
- PCT loops
- PCT loop functions
- Planning objects
- Connection planning objects (piping planning objects, cable planning objects).

In the case of PCT loops only the identifying components of the designation are taken into account for sorting, and not the full designation. You specify the properties that are identifying in addition to the number in the dialog Settings: Numbering / PCT loops. Using the arrow buttons, you can modify the sorting of the segments below a node in the tree structure. This manual sorting takes precedence.

![](../Pictures/Gui/ALL/info.png)Tip:

Non-assigned objects from the detailed planning whose associated segments have been deleted do not have properties. Through the popup menu item Go to (graphic) you have the possibility to branch to the schematic and there to edit the detailed planning. The popup menu items Disconnect and Delete can furthermore be used to remove the assignment to the pre-planning or to completely delete the object no longer assigned.

In the List tab, the segment definition name, designation and description, as well as structure identifiers for the identifier blocks "Function designation" and "Location designation" are displayed by default. In addition, structure identifiers for further identifier blocks, as well as other properties of the structure segments and planning objects can be displayed (e.g., the properties Technical description, Power consumption or user-defined properties). The values of the properties can be edited directly in the list view.

Filter:

This drop-down list displays all the available filters. A selected filter is automatically activated and is applied to both the tree and the list view. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the [Filter](modaldialogsdb_d_filternnach.htm) dialog. Here you can create, edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

- Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
- Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

If a structure segment or planning object is hidden via a filter in the tree view, the subordinate structure segments and planning objects will be hidden, too. In the list view, subordinate structure segments and planning objects are not hidden.

Value: <Property>:

Use this field, via [Quick input](modaldialogsdb_k_filter.htm#I_Schnelleingabe), to adjust quickly the value of a filter criterion for a defined and activated filter.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| New structure segment | Allows a structure segment to be created. If there are several segment definitions in the project, the Select segment definition dialog opens first to select the required segment definition. Subsequently the Properties (components): Structure segment dialog opens. This allows for the properties of the new structure segment to be edited. |
| New planning object | Allows a planning object to be created. If there are several segment definitions in the project, the Select segment definition dialog opens first to select the required segment definition. Subsequently the Properties (components): Planning object dialog opens. This allows for the properties of the new planning object to be edited. |
| New device (planning object) | Opens the Part selection dialog. Allows a planning object with a part to be created. If there are several segment definitions in the project, the Select segment definition dialog subsequently opens to select the required segment definition. |
| Copy / Paste | Reflects the Windows functions for editing data. Allows for structure segments and planning objects to be copied within the pre-planning navigator. When copying structure segments, the complete subordinate structure is copied as well. |
| Insert link (only tree) | Inserts a copied segment as a link. Links can be used to reference existing segments in other structures. |
| Duplicate | Duplicates the structure below the highlighted structure segment or planning object. The designation and structure identifiers are incremented automatically in the process. |
| Delete | Deletes all selected segments or - in the tree view - all segments below the selected tree structure level. (Multiple selection of segments or tree structure levels is possible here.) |
| Rename (tree only) | Use this menu item to rename the designation of the highlighted segment. After renaming, the tree structure is updated. |
| Place | Places the appropriate functions in the schematic for the highlighted planning object or highlighted template. Or places the segment itself on a pre-planning page or the macro / part macro entered at the segment on a project page.  Before the actual placing press [Shift] in order to start the placement action in the mode "Individual functions". Press [Backspace] to open the dialog Place device and, if required, for example open the macro selection or change the representation type.  Notes:   - So that a segment with entered macro / part macro can be placed on a project page, the representation type matching the project page must be available in the macro. - When placing macros, the macro boxes are generally placed, too. The functions, placeholder objects, etc. contained therein are identified on the basis of the macro box and can be updated in detailed planning, if required. |
| Place (device) | This action is available only for planning objects at which no part has been stored. If the planning object has templates, the device selection will be called. If the planning object does not have any templates, the part selection will be called. The functions of the selected part can then be placed. The part is assigned to the main function, and is not stored at the planning object. |
| Place functional | Searches for the part macro in the "Functional" representation type and places it as a symbol or macro graphic in the schematic via the subsequent menu. Before the actual placement press the [Backspace] to open the symbol or macro selection and select a different symbol / macro. |
| Generate new page from macro (only list) | This menu item is available if a macro is entered at the marked planning object. Generates a new schematic page. In the process the macro stored at the planning object is placed on the page. The name of the page is determined automatically from the structure identifiers of the planning object. Multiple selection is possible. |
| Update placeholder data | Updates the data of the placeholder objects for selected planning objects. In the process the changed placeholder data is transferred from the macros already assigned to the segments. This way you do not have to individually open the segments with stored macros to update the data. |
| Update detailed planning | Transfers the modified data from the pre-planning to the objects in the detailed planning that are linked to the segments marked here. This takes into account the highlighted segment and all subordinate segments. Multiple selection of segments is also possible.  You specify the updating scope in the subsequent dialog [Update detailed planning](planninggui_d_detailplanungaktualisieren.htm). |
| Assign | Assigns the selected segment of a function on a project page or a 3D part placement in a layout space.  [Assigning segments / objects](planninggui_h_objektezuweisen.htm) |
| Split | Separates a function or a 3D part placement from the linked segment. |
| Number PCT loops | Renumbers the PCT loops selected in the navigator . In the process the settings for numbering in the Numbering / Availability tab of the dialog [Configure segment definitions](planninggui_d_konfigsegmentdef.htm#RegisterkarteVerfuegbarkeit) are used. |
| Reset to segment template | Resets the modified values of the marked segments to the values predefined in the segment template. |
| Change segment definition | Opens the Select segment definition dialog, and allows for the segment to be assigned another segment definition. (A multiple selection is possible for segments with the same basic definition.) |
| Create pre-planning macro | Creates a pre-planning macro that contains the highlighted structure segment or planning object, and the structure below it. |
| Insert pre-planning macro | Opens the Select pre-planning macro dialog, and inserts the selected macro below the highlighted structure segment or planning object. No macros containing structure segments can be inserted below planning objects. |
| Go to (cross-referenced) | Enters cross-referenced segments and functions into the Go to list and opens it. All placements of the segment, the linked functions and associated entries are output in the pre-planning reports. |
| Go to (all representation types) | Enters all of the representation types of the segment or function (e.g., on a pre-planning page and report page) into the Go to list and opens it. |
| Go to (graphic) | Displays the placement of the highlighted segment or highlighted function in the graphical editor. |
| Tree view (tree only) | Opens the [Tree view](planninggui_h_verknuepfungenanzeigen.htm) dialog in which you specify which objects and links are displayed in the tree view below the segments. |
| List with preselection (tree only) | Reduces the number of elements displayed in order to allow for a faster orientation in the list view. If this option is activated, the list view is called up with an automatic filter (preselection) containing the elements that are currently selected. |
| Select in tree (list only) | Displays the marked object in the Tree tab. |
| Configure representation | Opens the Configure representation dialog, where you define which properties are to be displayed in the list and tree view.  Note:  Please note that during the configuration of the tree view in the dialog Configure representation you do not configure the representation of the segments, but can only specify which properties are to be displayed for the other objects (projects, functions, structure boxes, piping definitions, etc.) in the tree. The representation of the segments in the tree of the pre-planning navigator is specified via the Display format navigator field in the dialog [Configure segment definitions](planninggui_d_konfigsegmentdef.htm). |
| Edit in table | Opens tabular editing, with the possibility of editing the properties of the selected objects. |
| Properties | Opens the Properties (components): <...> dialog. Allows you to edit the properties of the segment or function. |
| Properties (global) | Opens the Properties (global): <...> dialog. Allows the editing of the device properties. |

# P007022: The symbol has more connection points than the function definition

### Cause

The currently edited project was created with an earlier Eplan version. In earlier Eplan versions, it was still possible, when creating devices, to select symbols and function definitions with a different number of connection points.

### Solution

1. Use the Go to (graphic) function to locate the device in the project.
2. Open the Properties <...> dialog of the device.
3. Bring the Symbol / function data tab to the front.
4. Adjust the symbol data to the function data regarding the number of connection points, or vice-versa. Modify either the symbol or the function definition.
5. If required, start a new check run.

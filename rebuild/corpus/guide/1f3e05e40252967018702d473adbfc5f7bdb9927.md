# Interface to Rittal - RiPanel Processing Center

To ensure a continuous workflow in engineering with the Rittal - RiPanel Processing Center production planning and control program, Eplan Pro Panel disposes of an interface that allows data export via an AML file.

The interface allows the export of manufacturing data for the machining of enclosures from Eplan Pro Panel to Rittal - RiPanel Processing Center.

![](../Pictures/Gui/ALL/note.png)Note:

Please note that parts at which the value "Undefined" or "Process engineering" is stored for the Generic product group property are generally not exported.

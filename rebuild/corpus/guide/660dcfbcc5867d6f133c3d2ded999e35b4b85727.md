# Dialog "Outline properties - <Outline name>" / Dialog "Form properties (copper) - <Form name>"

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Tab Master data > Command group Outline / form > Drop-down button Outline (NC data) > New > Button [Save].
- Tab Master data > Command group Outline / form > Drop-down button Outline (NC data) > Open. In the navigator dialog Pages - <Project name> select the popup menu item Properties on the outline.
- Tab Master data > Command group Outline / form > Drop-down button Form (Copper) > New > Button [Save].
- Tab Master data > Command group Outline / form > Drop-down button Form (copper) > Open. In the navigator dialog Pages - <Project name> select the popup menu item Properties on the form.

In this dialog, you specify the properties for a generated or opened outline or a form (copper).

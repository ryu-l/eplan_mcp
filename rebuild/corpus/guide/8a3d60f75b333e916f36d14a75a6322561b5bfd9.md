# Dialog 3D object selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. You have opened a project page in the graphical editor. You have inserted a model view (Tab Insert > Command group View > Model view) and placed it. In the Model view dialog, select the View tab and click [...] in the Basic items field.
- You have opened a project. You have opened a project page in the graphical editor. You have double-clicked a model view. In the Model view dialog, select the View tab and click [...] in the Basic items field.

In this dialog, select the 3D objects to be displayed in the model view.

Overview of the main dialog elements:

Tab Tree:

In the tree view the information about the 3D objects is displayed in a hierarchical structure with the individual items below it.

Tab List:

The 3D objects are displayed in the list view with their item designations and names.

Filter:

This drop-down list displays all the available filters. A selected filter is automatically activated and is applied to both the tree and the list view. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the [Filter](modaldialogsdb_d_filternnach.htm) dialog. Here you can create, edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

- Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
- Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Select all (list only) | Selects all of the entries in the list. |
| Adjust column width (list only) | Adjusts the width of all table columns so that both the headings and column contents are fully legible. |
| Configure representation | Defines how the layout spaces and the components in the layout spaces are represented in the navigator's tree view. The individual options can also be used in combination. A check mark in front of the option indicates whether it is selected:   - Item designation: Displays the item designation with the grouping sign, which is the default setting. - Item description - DT - Part number - Item number.   If no check box is activated in the Configure representation dialog, the tree and the list of the layout space navigator only display the item designation without grouping sign.    With the configurable tree view for 3D object selection, the identifying of identically named 3D objects (e.g., logic items) is facilitated by the display of additional information (such as the item description). |

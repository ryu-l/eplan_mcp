# Dialog Select data source

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Import > Command group Project data > Project data > Command group Devices > Devices. In the Import device data dialog, click [...] next to the data source field.
- File > Import > Command group Project data > Project data > Command group Routing connections > Routing connections. In the Import connection data dialog, click [...] next to the Data source field.

This dialog contains settings for controlling the import of devices and routing connections from the text or MS-Excel file that is to be imported. You also define the row from which the import is to be triggered.

Overview of the main dialog elements:

File:

This field displays the file name of the text and MS-Excel files to be imported. Use [...] to open the Open dialog to select the file to be imported.

Table:

This field is only available for MS-Excel files. Select the name of the table within the MS Excel file from the drop-down list.

Number of headers:

Defines the row in the text file to be imported from which the import is to be started. The set number of headers is ignored during the import.

Data field name in row:

Defines from which row of the data source the data field name is to be taken for the "External data field" column in the assignment table.

Separator:

This field is only available for text files. The individual columns in the text file to be imported are separated by a separator at the time of the import. You can specify the following characters as separators:

- Blank
- Tabulator
- Other characters: After selecting this option, enter the desired character combination in the input field below. Any digits, letters, and special characters can be used.

# P022016: The page name of page '<x>' contains letters

### Cause

The page name of a page contains one or more letters.

### Solution

1. In the Message management dialog, double click on the message to locate the relevant page in the tree view in the page navigator.
2. Use the popup menu to open the Page properties dialog, and in the Full page name field change the letter(s) after the separator "/" to numbers.
3. If required, start a new check run.

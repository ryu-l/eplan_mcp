# Creating a Report Overview without a Template

Eplan has report types for [report overviews](formgeneratorgui_k_auswertungsuebersicht.htm) and for function-related reports. As standard, report overviews provide an overview of several devices, e.g. "Terminal-strip overview". The way in which the report pages are sorted into the existing page structure depends on the [Page sorting for reports](formgeneratorgui_k_seitensortierung.htm) defined in the report settings for the particular report type.

Preconditions:

- You have opened a project.
- You have assigned a form to the desired report type.
- You have specified all the desired settings in the dialog Settings: Output to pages.

1. Select the following commands: Tab Tools > Command group Reports > Generate.
2. In the Reports - <Project name> dialog, click [Settings] > Output to pages.
3. Decide on a report type for report overviews.
4. In the Page sorting column click [...], and set up the page sorting in the following dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) To generate comprehensive reports for the entire project, select the Total entry from the Sort by / into drop-down list.  
     
   ![](../Pictures/Gui/ALL/arrow.png) To generate structure identifier-related reports, for example when the "Function designation" and "Location designation" structure identifiers change, activate the Function designation and Location designation check boxes.
5. Click [OK].
6. Click [OK] in the dialog Settings: Output to pages.
7. In the Reports - <Project name> dialog, select the Reports tab and click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
8. Select the output format "Page" from the Output format drop-down list of the Select report dialog.
9. Check whether the project that is the data source for the reports and templates has been entered into the Source project field.
10. To select a different project click [...] in the Source project dialog, select the desired project and click [OK].
11. Select a report overview in the Select report type field.  
      
    ![](../Pictures/Gui/ALL/arrow.png) If a report overview is selected, then the Manual selection check box will not be not available.
12. Click [OK].
13. In the Settings - <Report type> dialog, optionally select [Schemes](schemeconfig_k_start.htm) for filtering, sorting, and page breaks in reports, and click [OK].
14. In the <Report type> dialog, enter the page name of the start page into the first structure identifier.
15. If desired, enter an optional page description and sheet number and then click [OK].
16. Define the properties of the start page for all other structure identifiers in the same manner. The structure identifiers that are available depend on the page sorting assigned to the report type in the Settings: Output to pages.
17. To adopt the start page properties for all structure identifiers, select the check box Apply start to all structure identifiers.
18. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The report pages are generated.

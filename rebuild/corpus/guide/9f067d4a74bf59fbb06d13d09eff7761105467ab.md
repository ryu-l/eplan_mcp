# Changing the 3D View of the Layout Space

Various functionalities can be used to change the view of an opened layout space.

Preconditions:

- You have opened a project.
- You have opened the layout space navigator and a layout space.

### [ClosedMove a 3D model in the layout space](javascript:void(0);)

This functionality allows you to move the 3D model in the 3D view of the layout space.

1. Hold down the middle mouse button and move the cursor in the desired direction.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The 3D model is shifted in the direction of the mouse movement.
2. If you additionally hold down the [Shift] key while shifting, shifting is interrupted and the 3D model is rotated in the layout space in the direction of the mouse movement.

![](../Pictures/Gui/ALL/note.png)Note:

The user setting [Middle mouse button](gedviewer_d_einstellungenbenutzerallgemein3d.htm#MittlereMaustaste) is used to specify whether the 3D model in the layout space is moved or rotated with the middle mouse button. The Move and rotate with [Shift] option is the default setting.

### [ClosedChange the zoom](javascript:void(0);)

You can use this functionality to zoom in or out, the layout space shown in the 3D view or a separately displayed component (mounting panel, mounting rail, etc.).

1. Select the commands Zoom in or Zoom out. (To this purpose you first have to [Customize the ribbon](userinterface_h_menuebandanpassen.htm) and then assign the desired command to a user-defined command group.)  
     
   ![](../Pictures/Gui/ALL/arrow.png) The view zooms in or out, step by step, starting from the position of the coordinate system.
2. Hold the cursor over the 3D view and turn the mouse wheel forward or backward.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The view zooms in or out, step by step, starting from the cursor position.

### [ClosedChange the viewpoint](javascript:void(0);)

This functionality generates different orthogonal (top, bottom, left, right, front, rear) or [isometric views](gededit3dgui_k_start.htm#IsometrischeAnsichten) (south-west, south-east, north-east, north-west) of your layout space. The designations of the four isometric viewpoints determine the orientation from which the model is viewed. Additionally, the viewpoint is rotated 60° downwards.

1. Either use the [Navigation cube](cabinetgui_k_navigationswuerfel.htm) at the top right in the layout space to rotate the viewpoints. Or select the following commands: Tab View > Command group 3D viewpoint > "3D viewpoint" (e.g. ![](../Pictures/Gui/ALL/ribbon_viewpointfront_as.png) "3D viewpoint, front").

![](../Pictures/Gui/ALL/note.png)Note:

When switching the 3D viewpoint, the view becomes animated and is rotated into the new position. Using the user setting [Rotate when changing the viewpoints](gedviewer_d_einstellungennavigationswuerfel3d.htm#DrehenWechselBlickpunkte), this animation can be switched off, so that the viewpoint is changed without rotation.

![](../Pictures/Gui/ALL/info.png)Tip:

You can also use [shortcut keys](gededitgui_k_tastaturbefehle.htm) to change the 3D viewpoint. You can furthermore assign these shortcut keys to the function keys of a 3D mouse.

### [ClosedRotate the viewing angle](javascript:void(0);)

With this functionality, you can change the viewing angle of the graphic by moving the mouse.

1. Select the following commands: Tab View > Command group Viewing angle > Rotate.  
   Or click the button ![](../Pictures/Gui/ALL/statusbar_viewpoint_as.png) (Rotate viewing angle) in the status bar.
2. Click in the 3D view and keep the left mouse button pressed.
3. Holding the button down, move the mouse in the direction in which the viewing angle is to be changed.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The display in the layout space follows the movement of the mouse, and rotates in the corresponding direction.

### [ClosedSimplified representation](javascript:void(0);)

With this functionality, you can reduce the detail shown in the graphic of the parts placed in the layout space. You can set which items are to be shown in a simplified representation in the [Settings: 3D](gedviewer_d_einstellungenbenutzerallgemein3d.htm#VereinfachteDarstellung) dialog:

- Terminal strips (block definition)
- 3D macros.

These settings apply to all items already placed and to all subsequently placed items.

1. Select the Simplified representation popup menu item in the layout space navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) 3D macros are replaced by cuboids in the dimensions of the items previously used. Terminal strips are combined into a block; the individual terminals are no longer displayed. The labeling of the terminal strip is displayed instead of the labeling for the individual terminals. The position of the components placed on the items does not change.

### [ClosedChange the background colors for the 3D view](javascript:void(0);)

The default colors for the background to the 3D view can be set individually. You can specify a single color or two colors, between which a horizontal color gradient is generated.

1. Select the following commands: File > Settings > User > Graphical editing > 3D.
2. Open the dialog [Color settings](mf_d_farbauswahl.htm) by using [...] in the Shading - Background 1 and Shading - Background 2 fields In the Color selection group box.
3. Select the desired colors.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected two different colors, the background will be drawn with a color gradient. The first color defines the starting color in the upper window pane and the second color stands for the end color in the lower window pane.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected two identical colors, the background will be drawn with one single color.

### [ClosedDisplay and hide the drilling view](javascript:void(0);)

Drilling view refers to the display of all mechanical working steps (designs). This does not concern manually placed cut-outs.

1. In the command group Layout space in the View tab select the button Drilling view.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The transparency of all part placements is set to 50%. All drilling patterns stored on the parts are displayed on the mounting surfaces where they have been placed. The visualized drilling patterns fully penetrate the components below to be drilled, which becomes clear in the side view.  
     
   ![](../Pictures/Visualisation/ALL/cabinetgui_drillview_as.png)
2. Deactivate the Drilling view button to hide the drilling view.

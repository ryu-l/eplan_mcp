# Inserting PLC Cards and Connection Points

You can insert PLC cards and connection points on schematic pages and also on pages of type "Overview". Synchronization occurs between the overview pages and the schematic pages. All of the PLC connection point data can be entered in both the overview and in the schematic.

![](../Pictures/Gui/ALL/info.png)Tip:

If you already know during project planning which PLC parts are to be used, you can insert the PLC cards and connection points directly as a device via the Insert center. This way you can place the individual I/O connections, card power supplies, bus ports, etc. comfortably one after another. The function definition and, at bus ports, additionally the plug designation, is displayed as a placement aid. You can use the [N] key to "browse" through the functions.

### PLC card overview

A PLC card is represented in the schematic by one or more PLC boxes. To insert a PLC box, proceed as follows:

1. Select the following commands: Tab Insert > Command group Devices > PLC box.
2. Draw the PLC box as a rectangle.
3. In the Properties <...> dialog enter the device data of the PLC card.

![](../Pictures/Gui/ALL/info.png)Tip:

PLC boxes can also be drawn as polylines with the help of the PLCC2 symbol. To do so, select the symbol in the Insert center and specify the starting point of the box by clicking the left mouse button in the schematic. After you have specified all of the other points, complete the task via the Complete polyline popup menu item.

### Insert PLC connection points

You normally place PLC connection points inside the associated PLC box. It is however possible to place PLC connection points outside a PLC box.

1. Select the following commands: Tab Insert > Command group Devices > Drop-down button PLC connection points > "PLC connection point".
2. Place the PLC connection point in the PLC box.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The PLC connection point adopts the DT of the PLC box. A number of additional properties are also displayed, but these are not editable.
3. In the Properties <...> dialog, enter the connection point data of the PLC connection point.

![](../Pictures/Gui/ALL/note.png)Note:

Before inserting or copying PLC connection points, make sure that the PLC-specific settings are correct. Otherwise, wrongly formatted addresses may be suggested by the program when performing automatic addressing.

If you work in multi-user operation, we recommend disabling automatic addressing of PLC addresses.

# P027012: Several routing tracks are filled (topology, Pro Panel) at the connection from <x> to <y>

### Cause

There are separate routing track properties on the connections for the modules Eplan FieldSys and Eplan Pro Panel. Possibly, you plan with both modules, and one and the same connection or one and the same cable was routed in the topology and layout space. In the process, the length and connection point values (e.g., in connection with wire termination processing, etc.) of the last route were overwritten.

### Solution

1. Remove the targets from one of the representation types (topology, 3D part placement).
2. Also remove the corresponding routing track on the connection / cable.
3. Update the connections.
4. If required, start a new check run.

# Action: subprojects

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| TYPE | Type of task to be carried out: FILEOFF: Filing off of subprojects STORE: Storing of subprojects. |
| PROJECTNAME | Project name with complete file path (optional). If nothing is entered, the selected project will be used if the action is to be run over the user interface (e.g. via the script or ribbon). When calling up in the Windows command line, the PROJECTNAME must be specified.  The project must be opened for filing off or storing subprojects in the exclusive processing mode. |
| DESTINATIONPATH | Target directory (optional). Default value is $(MD\_PROJECTS) |
| SPNR | Subproject number. |
| EXPANDONLY | Only expand subproject (optional). Standard value is "No". |

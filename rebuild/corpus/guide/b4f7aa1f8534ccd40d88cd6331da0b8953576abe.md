# Tab Conductor termination processing

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > Company > Wire fabrication > "Machine" > Tab Conductor termination processing
- File > Export > Command group Manufacturing data > Wire fabrication > "Machine". Click [...] next to the Scheme field. Select the Conductor termination processing tab.

In this tab, the wire termination processing is assigned to the actual conductor termination processing by the machine.

Overview of the main dialog elements:

Wire termination processing:

From a drop-down list, you can select all definitions set in the project and company settings for the design of wire terminations.

Conductor termination processing single:

In this column, the preceding wire termination processing is assigned an equipment of conductor ends of single wires by sleeves. The selectable values for this dialog element are defined on the [Machine command](productionwiringgui_r_maschinenbefehl.htm) tab.

Conductor termination processing twin:

In this column, the preceding wire termination processing is assigned a processing of conductor ends of twin wires on the machine. The selectable values for this dialog element are defined on the [Machine command](productionwiringgui_r_maschinenbefehl.htm) tab.

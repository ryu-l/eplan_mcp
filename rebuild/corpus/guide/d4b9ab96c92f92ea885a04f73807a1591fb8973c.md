# P502021: Part property 'ERP / PDM number <x>' is not unique

### Cause

In the parts database to be checked, a part was found at which a value was entered for the ERP / PDM number <x> property which already exists for the same property at another part. This may have been caused by editing via the Eplan API.

(The variable <x> can assume values from 1 to 10. Up to ten ERP / PDM numbers can be stored at a part in the ERP / PDM number 1 to ERP / PDM number 10 properties.)

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Properties tab to the front.
3. In the property table open the hierarchy level General.
4. Remember the entered value for the ERP / PDM number <x> property.
5. Repeat this at all other parts for which the message was output.
6. Enter different values for the ERP / PDM number <x> property at all parts.
7. Click [Apply].
8. If required, start a new check run.
9. Close the parts management and perform a parts data synchronization.

# Exporting Projects

Projects can be exported via the Backstage view or the project management. Exported projects are XML-compatible and can be edited using an external application (e.g. text editor) before being reimported into Eplan.

Precondition:

You have selected a project. When exporting from the Backstage view, it is sufficient if you have marked a project page in the Pages - <Project name> dialog or have opened a project page in the graphical editor.

Backstage view: File > Export > Command group Project data > Project data > Command group Project > Project.

Project management: [Organize] > Export.

1. In the Export project to dialog, enter the storage location for the project to be exported. You can create a new directory if required by using the New > Folder popup menu item.
2. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project is exported, and a progress bar shows the progress. The exported project \*.epj is stored in the target directory in XML format.

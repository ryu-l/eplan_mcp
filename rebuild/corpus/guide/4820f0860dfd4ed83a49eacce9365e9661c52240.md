# Configuring Project Checks

Precondition:

You have opened a project.

1. Select the following commands: Tab Tools > Command group Review > Check.
2. Click [...] beside the Settings field of the Run check dialog.
3. Messages and checks, Select a user-defined scheme from the drop-down list in the dialog Settings: Messages and checks, or create one using the [toolbar](schemeconfig_m_schemaschaltflaechen.htm).
4. Select a message class on the left in the list.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The possible messages for this class are displayed in the table on the right of the dialog.
5. Use the drop-down list in the Category field to determine whether the message should be displayed as an error, a warning, or a note.
6. Select one of the available [types of check](msgmanagementgui_k_prueflaufprinzip.htm#I_OnlineOffline) from the drop-down list in the Type of check field.
7. In the Filter field, click [...], and specify the trades to which the check should be extended in the Filter dialog. You have the option of selecting an existing filter scheme for trades, or defining your own.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The settings will be saved in the selected scheme.

![](../Pictures/Gui/ALL/note.png)Notes:

- Please note that you cannot select all of the types of check listed above for every check; only certain types are available to you.
- Some useful schemes with specific check run configurations are offered by default after Eplan has been installed.

# Highlighting Routing Path Networks

Routing path networks can be temporarily highlighted in color to verify if an unbroken routing path network is available for the laying of connections in the layout space.

Precondition:

You have opened a project. You have opened a layout space. The layout space contains one or more routing path networks.

1. Select the button Routing path network tracking in the command group Routing connections in the View tab.
2. Click the object (wire duct, routing path, curve) with a partial routing path of the routing path network.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All paths of the routing path network that are connected with the routing path of the clicked object are highlighted in color.
3. Click another routing path.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The highlighting of the first routing path network is terminated and the routing path network belonging to this routing path is colored.

![](../Pictures/Gui/ALL/note.png)Note:

Connection filters that were specified for routing paths, wire ducts, etc. are taken into consideration when the routing path network is tracked.

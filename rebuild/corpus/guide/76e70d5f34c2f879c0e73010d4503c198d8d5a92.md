# P502039: The reference '<x>' in the function template for the placement of the conductor is not valid

### Cause

In the parts database to be checked, a prefabricated cable was determined for which a value that does not reference a valid plug function template is stored for the property Conductor start or Conductor end of a conductor.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Function templates tab to the front.
3. Enter a valid value for the affected property.
4. Click [Apply].
5. If required, start a new check run.
6. Close the parts management and perform a parts data synchronization.

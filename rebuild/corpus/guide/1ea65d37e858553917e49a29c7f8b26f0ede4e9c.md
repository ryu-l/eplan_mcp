# P026042: No entry point to routing path network found for connection point <x>

### Cause

The connection point of a part placement does not find any access to the routing path network.

A virtual level that is formed from the specified routing direction and the Z vector of the part placement is generated in the connecting point of the part placement. This level does not intersect any of the following routing path network objects on the mounting panel in the routing direction:

- Routing path (placed manually or in the cable duct)
- Routing range
- Routing cut-out.

In addition the mounting surface is not located in the item hierarchy of the part placement.

### Solution

1. Locate the part placement in the layout space using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Check the settings for the routing direction in the connection point pattern of the part placement and the surroundings of the part placement on the mounting surface. Move the routing path network object (routing path, routing range or routing cut-out) on the mounting surface so that it intersects the virtual level that is formed from the specified routing direction and the Z vector of the part placement.  
     
   And / or you ensure that the mounting panel belongs to the item hierarchy of the part placement.
3. Route the connections again.

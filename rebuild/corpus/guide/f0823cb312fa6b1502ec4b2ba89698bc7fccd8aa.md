# Tab Global extra length

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Settings > Projects > "Project name" > Routing connections > General. Select the Global extra length tab.

You define the global extra length for routing connections on this tab. This extra length is added to each connection when calculating the length of a connection.

Overview of the main dialog elements:

Separate settings are possible for connections of different trades.

- Absolute: Here you can enter a fixed length for the measuring unit (mm, inch) defined for the project. The value can have two decimal places. Negative values are possible.
- In percentage: Extra length as a percentage of the length of the connection. The value can range from 0 to 100, without decimal places. Negative values are only possible for electrical engineering.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

| Menu item | Meaning |
| --- | --- |
| Go to default | Restores the default settings of all fields. |

# Dialog "Settings: Translatable pages" / Tab "Translatable pages"

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. File > Settings > Projects > "Project name" > Translation > Translatable pages.
- Tab Tools > Command group Translation > Drop-down button Translate > Settings. Select the tab Translatable pages.

In this dialog or in this tab you use the page type to specify which pages are to be translated. This settings are stored on a project-specific basis.

Overview of the main dialog elements:

Page types:

This field displays all of the available page types in Eplan. If the check box in front of the page type is selected, all pages of this type are translated.

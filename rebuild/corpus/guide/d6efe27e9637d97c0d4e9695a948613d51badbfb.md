# Display Properties: Ellipse

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened an editor such as the graphical editor, the plot frame editor, etc. You have marked an ellipse and chosen the popup menu item Properties, or you have double-clicked an ellipse. In the table of the Properties (Ellipse) dialog, expand the hierarchy level Ellipse.

Below this hierarchy level you can edit the ellipse-specific settings.

Overview of the main dialog elements:

Center:

In the fields below this hierarchy level, the coordinates of the ellipse's center are displayed and can be modified.

Semi-axis:

The lengths of the larger and smaller semi-axes of the ellipse are shown in the fields below this hierarchy level and can be altered.

Angle:

Enter an angle in order to rotate the ellipse relative to the X axis.

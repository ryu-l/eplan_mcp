# Importing and Exporting Favorites and Tags (Insert Center)

Favorites and tags that were defined by you in the insert center are saved in the settings - favorites in the User settings, tags in the Company settings. From the respective settings dialog it possible to exchange favorites and tags with other workstations and users.

Preconditions:

You have defined favorites and / or tags in the insert center.

1. Select the following commands: File > Settings > User for favorites, or File > Settings > Company for tags to navigate to the respective settings dialogs.
2. In the respective settings dialog select the popup menu item Import or Export.
3. In the subsequent dialog deactivate the check box User or Company.
4. In the table under Other settings areas activate the check box Insert center favorites or the check box Insert center tags.
5. For the import select the source directory and for the export the desired target directory.
6. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The favorites and / or tags are imported as a file in the \*.xml format from the set source directory or exported into the set target directory.

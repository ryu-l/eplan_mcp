# Parts Management: Accessories Management

### Definition of accessories and main parts

Whether a part (of the part type "Component", "Assembly" or "Module") is a main part or an accessory part is specified in the parts management in the Accessories tab by means of the setting Part is accessory.

- Definition of a main part:  
  A main part is a part for which the Part is accessory check box is deselected. These parts may be assigned accessory parts (accessory parts and accessory lists) on the Accessories tab.
- Definition of an accessory part:  
  Selecting the Part is accessory check box turns a main part into an accessory part. If the check box is selected, it is not possible to assign accessory parts or accessory lists to the part. The table of accessory parts is grayed out as the part is now an accessory part itself.

When the accessory parts are assigned to the main part, the need for the accessory part must be specified. The available options are "Necessary" (check box in the Necessary column is activated) and "Optional" (check box in the Necessary column is deactivated). This setting is taken into account in the device selection: Here the main parts list displays all the parts from the parts management module that are suitable for the selected device and for which the Part is accessory check box in the Accessories tab is deactivated. When a decision is taken for a main part, the accessory must be determined in the accessories list, which displays all the suitable accessory parts for the selected main part.

It is essentially possible to assign both individual accessory parts and accessory lists to a main part.

### Definition of accessory lists

Parts management provides "accessory lists" as a simple means of managing alternative accessory parts. They allow you to select a part from a list of possible alternatives. The accessory lists in the parts management represent their own record type and are displayed in the tree view below the separate hierarchy level "Accessory list".

An accessory list is defined in the Properties and Parts tabs. You must enter a unique name in the Properties tab. (By contrast, the description of the list is optional.)

A part can be selected in the Part number field on the Parts tab. In the process access to the "Electrical engineering", "Fluid power", "Mechanics" and "Process engineering" generic product groups is possible, although only previously defined accessory parts are displayed. A given part may be selected multiple times.

Once you have created accessory lists, they may be assigned to a main part of a part type in the Parts management module.

#### Insert accessory lists completely

In certain applications it is desirable that no selection be made when using an accessory list, but rather that all parts of an accessory list be inserted. To this purpose the property "Insert accessory list completely" (ID 22987) is available in the parts management at an accessory list in the Properties tab of the Insert complete accessory list property.

If the check box for an accessory list is activated, all parts of this accessory list are selected completely, for example during an accessory selection in the device selection. In the process all accessory parts are transferred immediately (required accessories) or when the selection is called up (optional accessories) automatically into the Selected parts: Functions / templates field.

The entire accessory list can also be inserted when inserting or placing the part as a device. To this purpose the Add required accessories automatically project setting has to be activated and the accessory list for the part has to be marked as "required".

# P005022: Connection definition point is located on more than one connection

### Cause

The connection above and below the connection definition point branches at a T-node or a connection definition point is located on two crossing connections.

### Solution

#### Possibility 1

Delete the target direction in accordance with the connection definition point before or after the T-node. Specify separate connection definition points for the branching connections.

#### Possibility 2

Move one of the connections from the intersection with the connection definition point.

#### Possibility 3

Move the connection definition point to one of the connections so that an intersection of both connections with the connection definition point is not possible anymore.

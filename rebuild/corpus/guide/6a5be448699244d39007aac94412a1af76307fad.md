# Action: ExportNCData

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| MachineType | Integer value, has to be specified. The following values are possible:   - 1 = NC-Steinhauer - 2 = Rittal - Perforex BC - 3 = NC-DXF - 4= Drilling template - 5 = Rittal - Perforex LC - 6 = Copper NC - 7 = Copper DXF - 8 = Pipe bending |
| MachineName | String, has to be specified. Name of the machine as specified in the settings. |
| PROJECTNAME | Project name with complete file path (optional). If nothing is entered, the selected project will be used if the action is to be run over the user interface (e.g. via the script or ribbon). When executing from the Windows command line, PROJECTNAME must be specified or ProjectAction has to be used before that. Otherwise a system message will appear. |
| USESELECTION | Specifies whether the current selection in the user interface is to be taken into account in connection with the output of the NC data (optional, 0 = No, 1 = Yes). Default value: 0. Can only be used if the parameter PROJECTNAME is not used. |
| TargetDirectory | Target directory (optional). If the parameter is set, an output directory specified in the settings is overwritten. |
| MaterialName | Only available for Rittal - Perforex machines and copper NC. If set, the corresponding material is taken from the machine settings and used for the export. |

```
ExportNCData 
/MACHINETYPE:2 
/MACHINENAME:Standard
/TARGETDIRECTORY:D:export
/MATERIALNAME:Steel
```

# P005051: Connector with unconnected connection point

### Cause

A connection symbol with at least one non-connected connection point was found in the schematic. Connection symbols in accordance of this message are the following:

- Angle
- T-node
- Jumper
- Double junction
- Diagonal connection
- Junction, angled connection (process engineering)
- Connection crossing with recess (process engineering)
- Gap for connection crossing
- Semicircle for connection crossing
- Piping interruption

### Solution

1. Locate the relevant connection symbol in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Connect the open connection point or connection points of the connection symbol with a component so that autoconnect lines are formed.
3. Delete the connection symbol if it is not required anymore.
4. If required, start a new check run.

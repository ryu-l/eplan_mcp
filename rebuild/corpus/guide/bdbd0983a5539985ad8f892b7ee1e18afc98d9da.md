# P005069: Same connection designation within different nets

### Cause

A connection designation that already exists was assigned within different nets.

### Solution

1. Locate the connection definition point in the schematic by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Delete the connection designation or rename it.
3. If required, start a new check run.

![](../Pictures/Gui/ALL/info.png)Tip:

Use the connection numbering functionality to automatically assign connection designations.

# Importing Devices and Routing Connections into a Project

Devices and routing connections can be imported in the form of data from external programs (other CAE systems, ERP systems, MS Excel, etc.) into an Eplan project in order to create a complete panel layout on the basis of these data and subsequently route connections in this layout.

The following are imported:

- Device tag / terminal lists and wiring lists with the file extensions TXT and CSV
- Text files with the file extension ASC
- MS Excel files with the file extensions XLSX, XLSM.

Synchronization with devices and routing connections already existing in the project can be carried out during importing. It is furthermore possible to delete devices and routing connections already existing in the project by carrying out synchronization. As a result of importing unplaced devices and unrouted routing connections are imported into the project. These devices can subsequently be placed in the layout space and the unrouted routing connections can be rerouted.

# Dialog Format: Counter (connection numbering)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the [Settings: Connection numbering](wirenumberinggui_d_verbnumeinstellungen.htm) dialog (for example by using File > Settings > Projects > "Project name" > Connections > Connection numbering). You have selected a user-defined scheme in the dialog Settings: Connection numbering and have selected the Designation tab. You have selected an entry in the Format groups field and clicked ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit), or you have clicked ![](../Pictures/Gui/ALL/all_new_as.png) (New).

Select a format element of the type "Counter" in the Available format elements list of the dialog Connection numbering: Formats dialog and move it to the Selected format elements list by using the arrow button.

In this dialog, you specify the formatting for a counter or a subcounter in the format group.

Overview of the main dialog elements:

Reserved numbers/page:

One spare value can be specified per page for the counter numbers. Positive numeric values are permitted. Zero means that no counter numbers are reserved.

Based on the last count number on the page, the count numbers are reserved up to the next multiple of the spare value entered. On the next page the counter numbers begin with the correspondingly increased value. Thus, the spare value determines the maximum number of reserved count numbers.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Reserved numbers/page: 100   
The last counter number on a page is: 230  
The starting number on the following page is: 300

Reserved numbers/page: 50   
The last counter number on a page is: 230  
The starting number on the following page is: 250

Minimum number of digits:

Here you define the minimum number of characters to be used for the property value. Longer values are displayed in their full length. Only positive numeric values are permitted. A value of zero means that the field width is variable.

Filler character:

The value is padded with this character if the minimum number of digits is larger than the width of the value. A padding character cannot be entered for a variable number of digits (entry of "0" in the Minimum number of digits field).

Direction:

Specify the direction in which connections are numbered. Possible values are:

- By row: Numbering goes from left to right within the row.
- By column: Numbering goes from top to bottom within the column.
- According to plot frame logic: The plot frame determines whether numbering is performed by row or column.

![](../Pictures/Gui/ALL/note.png)Note:

During connection numbering, all connections are initially sorted graphically together, regardless of the format group. The direction of the first counter or subcounter of the first format group is used (in accordance with the sequence in the Designation tab of the dialog Settings: connection numbering) that contains a counter or subcounter. The direction of the other counters or subcounters is not evaluated.

Number by devices:

If this check box is selected, connections between two components are numbered in the order they appear in the schematic instead of the order in which they are specified under Direction. Connections between different components having the same identifying DT, but no displayed DT, are also taken into account. This thus affects components receiving an identical DT via [DT adoption](devicetaggui_k_bmkuebernahme.htm).

![](../Pictures/Gui/ALL/note.png)Note:

The setting Number by devices only makes sense if the scope "Individual connections" is selected for the numbering. At a larger numbering scope additional rules for the connection numbering (for example for networks or potentials) are taken into consideration. This can result in a changed sequence.

Use alphanumeric counter:

If this check box is selected the alphanumeric counter is used. If not, a numerical counter is used.

Alphanumeric counter:

When using the alphanumeric counter specify the characters here that are allowed to be used by the counter. Only alphanumeric characters are allowed.

Alphanumeric counters are sorted by character from left to right (in the same manner as Excel columns). If you have specified, for example, the characters "AKS", counting proceeds as follows: A, K, S, AA, AK, AS, KA, ..., AAA, AAK, AAS, AKA ..., AAAA, AAAK, ...

Reset per structure / page:

If this check box is selected, the counter starts again with the start value if the page or a structure identifier, for example, has changed. From [Settings], open the [Settings: Counter reset range](wirenumberinggui_d_zaehlerruecksetzbereich.htm) dialog where you define the criteria for resetting the counter. This allows you, for example, to begin with the start value respective per page or per function designation. Resetting the counter only makes sense if the connection designations would otherwise not be the same (for example differ in their page number or the structure identifier for function designation). In order to differentiate between connections that would otherwise have the same name use a subcounter.

If the check box is deactivated, the connections selected for numbering are numbered consecutively.

Counter is a subcounter:

Select this check box to define a subcounter. The settings available for the subcounter depend on this setting. The subcounter ensures that connections that would otherwise have the same designation can differ.

If the check box is deselected the settings for the subcounter are grayed out.

Suppress first counter / subcounter:

If this check box is activated, the first counter or - if the Counter is a subcounter check box is activated - subcounter is suppressed.

For a subcounter, depending on the selected scope, the respective first subcounter is suppressed. For example no subcounter is displayed for the first respective connection per potential.

For a counter - if no counter reset range is specified - only the first counter in the project is suppressed. If the Reset per structure / page check box is additionally activated for a counter, the first counter is suppressed each time a criterion is fulfilled for the reset (e.g. per page or per function designation).

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You want to assign one connection designation per potential. You therefore have selected the "Potential / piping" entry in the Extent field for the affected connection group (e.g. "General connections") in the Connection numbering: Formats dialog. In addition each individual connection in the potential is to receive a subcounter. To do this you have specified a format group in the Selected formats field that consists of a counter, a separator and a subcounter.

For the subcounter select the "Individual connection" setting in the Range of the subcounter field. Also activate the check box Suppress first counter / subcounter.

The subcounter is then not displayed at the respective first connection per potential. So, for example, the connection designations "1. / 1.2 / 1.3" and "2. / 2.2 / 2.3" instead of "1.1 / 1.2 / 1.3" and "2.1 / 2.2 / 2.3" are displayed.

If the Including previous separator check box is additionally activated for the subcounter, the connection designations are, for example, "1 / 1.2 / 1.3" and "2 / 2.2 / 2.3".

Including previous separator:

Select this check box so that, together with the first counter or subcounter, the previous separator is also hidden.

Range of the subcounter:

Specify the range of the connections for which a subcounter is allocated.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

If you want to allocate one designation per potential, and within this potential one subcounter is to be allocated per net, select the "Net" setting here.   
If every individual connection in the potential has one subcounter, select the "Individual connection" setting.

# Dialog Copy referenced files manually into the project

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Tab Master data > Command group Synchronization > Store documents.
- You have selected a project in the page navigator. File > Back up. Click [Links] in the Back up projects dialog.

In this dialog you can manually copy files (external documents, image files, etc.) that are referenced in the project or in the associated master data into the current project. You can also change the type of storage of automatically stored files to "Manually copied" and update manually stored files.

Overview of the main dialog elements:

File:

This column shows all external documents linked with the project as pages of page type "External document" or as hyperlinks. Image files referred to in the project or the master data (symbols, forms, plot frames) are also listed here.

Reference type:

The reference type shows you how the respective file is referenced in the project. This way you can recognize into which subdirectories the files are copied (reference type "Document" in ...\<Project name>\DOC\, reference type "Image file" in ...\<Project name>\Images\).

Modification date (reference) / Modification date (stored):

You can check whether the stored or referenced file has a more recent modification date by comparing these columns. The value in the Modification date (stored) column remains empty if the file has not yet been stored.

Type of storage:

In this column you are shown whether the respective referenced file was copied into the project or not. The possible entries "Not stored", "Manually copied" or "Automatically copied" cannot be directly changed by you.

Copy:

Select the check box(es) for the file(s) to be copied into the current project.

- If this is done for files of the "Automatically copied" or "Not stored" type, these files are then copied manually into the project. This changes the storage type to "Manually copied".
- If this is the case for files with the "Manually copied" type of storage, a prompt is displayed with which you can overwrite the files. This way you can update manually stored files as required.

If the check box for a file is deactivated, the file is not copied into the project.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Select all | Selects the check boxes for all listed documents. |
| Deselect | Deselects all check boxes. |

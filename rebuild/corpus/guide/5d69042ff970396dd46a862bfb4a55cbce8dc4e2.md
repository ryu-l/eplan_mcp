# P007018: A required accessory part is missing for the part <x>

### Cause

You have created a device in the device navigator or placed a device in the schematic for which at least one 'required' accessory part has been defined in the parts management.

However, after creating or placing the device, the accessory part marked as 'required' was not entered on the Parts tab in the property dialog in addition to the main part.

### Solution

1. Use the Go to functionalities to locate the device in the project.
2. Open the properties for the main function of the device and bring the Parts tab to the front.
3. Open part selection for the main part by clicking [...].
4. In part selection, bring the Accessories tab to the front.
5. Note the required part number of the accessory part, or copy it to the clipboard.
6. Close part selection.
7. In the Parts tab for the device, which is still open, add the missing part number for the accessory part.
8. Click [OK].
9. If required, start a new check run.

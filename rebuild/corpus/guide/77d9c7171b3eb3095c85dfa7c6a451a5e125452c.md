# P001012: Incorrect saddle jumper formation

### Cause

A wrongly formed saddle jumper was found in the project. This message may be triggered by several causes. These are explained below with reference to the following examples:

#### Possibility 1

In the schematic you have defined a connection between different levels of a multi-level terminal as a saddle jumper.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

A connection defined as a saddle jumper exists between the two terminals -X1:1 and -X1:2. Both terminals are located on different levels of a multi-level terminal. The formation of a saddle jumper is not possible in this case.

![](../Pictures/Visualisation/ALL/messages_001012_bsp1_av.png)

#### Possibility 2

You have defined a connection between terminals as a saddle jumper in the schematic or in the dialog Edit terminal strip. However, no value for the number of saddle jumpers is entered at one or both terminals.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

A connection defined as a saddle jumper exists between the two terminals -X1:1 and -X1:2. Both terminals are "normal" feed-through terminals with two connection types. In the Connection point logic dialog no value or 0 was entered for the respective first function connection point at both terminals for the property Number of saddle jumpers.

#### Possibility 3

In the Edit terminal strip dialog you have manually created a saddle jumper between the levels of a multi-level terminal.

### Solution

#### Regarding option 1

1. Double-click in the schematic on the connection definition point between the terminals.
2. In the Properties <...> dialog, select the Connection definition point tab.
3. Click [...] next to the Function definition field and select the entry "Wire jumper" instead of "Saddle jumper" in the Function definitions dialog.

#### Regarding option 2

1. Call up the dialog Properties for the terminals respectively.
2. Switch to the Symbol / function data tab and open the Connection point logic dialog by clicking the [Logic] button.
3. In the Number of saddle jumpers field, enter a value for the respective fields that is larger than "0" (with regard to the example under "Possibility 2", respectively a 1 at the first function connection point).

#### Regarding option 3

In the Edit terminal strip dialog, delete the multi-level terminal manually created between the levels of the saddle jumper.

# P004051: Connection missing! <x> is not connected to the physical network '<y>'

### Cause

In accordance with the import file the '<x>' device is connected with a physical network '<y>'. However, no corresponding connection was determined in the project.

### Solution

1. Create the connection between the device and the physical network by means of a bus port.
2. Import the PLC data again.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

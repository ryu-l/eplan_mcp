# Inserting Busbars

The busbar symbol is stored in the SPECIAL.slk symbol library. It has four variants and the text positions are managed like device connection points.

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the following commands: Tab Insert > Command group Devices > Busbar connection point.
2. If required hold down the [Ctrl] key and move the mouse to page through the existing variants.
3. Place the symbol on the side.
4. Specify the busbar connection point properties in the Properties <...> dialog.
5. Click [OK].
6. Proceed in a similar manner for all of the other busbar connection points.
7. End the action via the Cancel action popup menu item or via the [Esc] button.

# P001021: Terminal is not included in terminal strip definition

### Cause

You have generated a function template for a terminal strip in the terminal strip navigator or in the schematic. In addition you have created a terminal in the terminal strip navigator or placed it in the schematic that is not part of the function template.

### Solution

1. Select the terminal strip definition in the terminal strip navigator or in the schematic.
2. Select the following commands: Tab Devices > Command group Terminals > Terminal strip.
3. Select the popup menu item Generate function templates in the Edit terminal strip dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All terminals now become a component of the function template.

![](../Pictures/Gui/ALL/note.png)Note:

Note that the functionality Generate function templates is only available when the Do not use main terminals check box is activated for the terminal strip definition.

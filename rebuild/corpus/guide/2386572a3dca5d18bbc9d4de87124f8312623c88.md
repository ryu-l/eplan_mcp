# Examples of the Design of Structure Identifiers

All objects in a project (pages, devices and functions) must be identified and placed in a hierarchical structure within the project.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Structure identifier for a page: =AP+ST1/6.

| Identifier | Meaning |
| --- | --- |
| = | Preceding sign of the following structure identifier for the identifier block "Function designation" |
| AP | Structure identifier for the identifier block "Function designation" |
| + | Preceding sign of the following structure identifier for the identifier block "Location designation" |
| ST1 | Structure identifier for the identifier block "Location designation" |
| / | Separator before the page name |
| 6 | Page name |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Structure identifier for a device: =AP+ST1-F6.

| Identifier | Meaning |
| --- | --- |
| = | Preceding sign of the following structure identifier for the identifier block "Function designation" |
| AP | Structure identifier for the identifier block "Function designation" |
| + | Preceding sign of the following structure identifier for the identifier block "Location designation" |
| ST1 | Structure identifier for the identifier block "Location designation" |
| - | Preceding sign for the identifier block "Device" |
| F6 | Structure identifier for the identifier block "Device" |

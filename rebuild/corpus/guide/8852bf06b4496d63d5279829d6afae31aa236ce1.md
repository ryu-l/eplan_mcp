# Dialog Change routing direction

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The layout space navigator is open and a layout space is open. The layout space contains 3D part placements with defined connection points. Tab Edit > Command group Routing connections > Change route.

Use this dialog to change the routing direction for one or several highlighted devices in a layout space. This way, you specify a direction for the connection point in which the routing connection connected to it is to search for the entry into the routing path network if the connection point direction specified in the connection point pattern deviates from it.

Overview of the main dialog elements:

Routing direction:

This drop-down list contains the same direction designations that are also available for the creation of a connection point pattern:

- Automatic
- Left
- Move up
- Right
- Down.

The following rule applies to the "Automatic" setting:

If the connection points are terminal connection points, the routing direction for internal connection points, points upwards and for external connection points downwards. If the connection points are connection points of other devices, the last character of the connection point description decides on the routing direction. If the last character of the connection point description is numerical and odd, the routing direction points upwards. If, on the other hand, the last character of the connection point description is numerical and straight, the routing direction points downwards.

# P004054: Connection only in project! The connection to '<x>' only exists in the project

### Cause

A network connection was found in the project that was not contained during the last import of the PLC data. Possibly it is an intended extension of the project.

### Solution

1. Check the network connection of the device '<x>' specified in the message.
2. Import the PLC data again.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

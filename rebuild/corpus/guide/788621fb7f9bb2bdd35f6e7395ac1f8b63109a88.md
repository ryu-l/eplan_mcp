# P002014: Pin of the same name used multiple times

### Cause

A pin is used multiple times with the same full DT on the project schematic pages.

### Solution

1. Locate the multiple pins in the schematic using the Go to menu options or double-click the output messages in the Message management dialog.
2. Call up the Properties <...> dialog for each of the found pins and compare respectively with the full DT.
3. Assign each of the multiple pins to another full DT by assigning unique pin designations.
4. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

Female and male pin pages can be represented separately from plug-in connectors in Eplan. There are special pin symbols for female and male pins provided for this purpose. Male and female pins may have the same pin designations if they belong to the same plug-in connector, i.e., are counterparts. On the other hand, pins of the same type at the male and female ends of a plug must have different designations.

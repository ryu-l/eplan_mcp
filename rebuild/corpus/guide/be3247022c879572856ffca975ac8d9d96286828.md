# Tab Result (Project Verification)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have selected a project management database. You have loaded directories and projects. File > Project management. Select the input project with the advanced project status. Select [Extras] > Verify project. Select a comparison project. Select the Compare settings check box. Click [OK]. Select the Result tab.

This tab displays a short overview of results from the project verification.

Overview of the main dialog elements:

Description:

This column displays which comparisons and check runs were carried out during the project verification process and which were not. The overall result of the project verification are also displayed. If you select a line, the Message description field (below the table) will show a text description. You can see the detailed results of the project verification in the message management (Tab Tools > Command group Review > Messages).

- Comparison of settings: This line displays the result of the settings comparison.
- Comparison of properties: This line displays the result of the properties comparison.
- Comparison of project structures: This line displays the result of the project structure comparison.
- Comparison of layers: This line displays the result of the layer comparison.
- Project checks: Displays the result of the check run. The [Status tab](prjmanagementgui_r_status.htm) also shows additional statistics of the check runs, for example the number of errors and the check run scheme used.

Status:

Shows the overall results of the project verification.

- ![](../Pictures/Gui/ALL/all_statusok_as.png): Everything correct! There are no setting / property differences between the comparison and incoming project. The check run generated no check run messages.
- ![](../Pictures/Gui/ALL/erroricon_error_systemmessages.png): Warning! Setting / property differences were found between the comparison and incoming project. The check run generated check run messages.
- ![](../Pictures/Gui/ALL/all_statusnotok_as.png): Warning! The comparison / check was not completed. Possible causes: You did not select the comparison / check run for the project verification. You selected the setting Stop comparison when first difference is found and Eplan discovered a difference that stopped the comparison / check run.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# Tab Wires (CadCabel)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > Company > Wire fabrication > CadCabel > Tab Wires
- File > Export > Command group Manufacturing data > Wire fabrication > CadCabel. Click [...] next to the Scheme field. Select the Wires tab.

In this tab, you specify the wire master data for the processing of wires on the CadCabel machine.

Overview of the main dialog elements:

Toolbar:

| Button | Meaning |
| --- | --- |
| (Update) | Imports the wires and wire parts from the project again. |
| (Delete) | Deletes a selected row. |

Color:

Color of the wire.

Cross-section:

Cross-section of the wire.

Part number:

Part number of the wire part.

CadCabel wire type:

In the CadCabel order, each wire must correspond to a wire type set by CadCabel. In this table field, you assign to the wires in the project the appropriate CadCabel wire types. CadCabel supplies an Excel table from which you can import the appropriate wire types.

CadCabel cable code:

In the CadCabel order, each wire must be designated with a cable code set by CadCabel. In this table field, you assign to the wires in the project the appropriate CadCabel parts codes. CadCabel supplies an Excel table from which you can import the appropriate cable codes.

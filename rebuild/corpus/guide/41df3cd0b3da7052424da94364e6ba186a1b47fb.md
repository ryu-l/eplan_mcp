# Importing Parts Texts into the Dictionary

It is possible to import parts texts from parts management into the dictionary. All texts that can be translated and that exist in the selected language in parts management will be transferred as keywords into the dictionary.

Preconditions:

- You have selected a parts database in the user settings (command path: File > Settings > User > Management > Parts management).
- Parts management contains parts texts in one or more languages.

1. Select the following commands: Tab Tools > Command group Translation > Dictionary.
2. Select the Management tab.
3. Click [...] next to the Dictionary field. In the dialog that appears select the Eplan dictionary into which you want to import.
4. Confirm your entries.
5. Select the following commands: Tab Master data > Command group Parts > Management.
6. Select [Extras] > Translation > Settings.
7. In the Translate field next to the Languages field click ![](../Pictures/Gui/ALL/all_new_as.png) (New), select each of the translation languages whose parts texts you wish to import into the dictionary and click [OK].
8. Select [Extras] > Translation > Import part texts.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All the selected translation languages are listed in the Select languages dialog.
9. Select the languages you wish to import.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the selected languages are not selected as dictionary languages, the "Language not available" message will appear.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts texts will be imported into the dictionary.
10. Click [Close].
11. To check the import open the dictionary via the following commands: Tab Tools > Command group Translation > Dictionary.
12. Select one of the languages you imported in the Source language field in the Edit words tab.  
      
    ![](../Pictures/Gui/ALL/arrow.png) In the Find field you will see all of the imported parts texts of the selected language.

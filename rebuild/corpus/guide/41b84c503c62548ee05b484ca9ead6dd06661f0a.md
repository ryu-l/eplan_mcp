# Tab Electrical engineering

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Settings > Projects > "Project name" > Connections > Properties. Select the Electrical engineering tab.

In this tab, you can specify project-wide default settings for the properties of electrical engineering connections. By default, these properties are assigned to all connections in the project. However, they can be overwritten on the individual connections.

![](../Pictures/Gui/ALL/note.png)Note:

The settings in this tab only work on individual connections (the value "Individual connection" is set for the Connection: Association property at the connection) but not on cable connections. The default values for cable connections (e.g. Cross-section) come from the cable part.

Overview of the main dialog elements:

Group box Cross-section / diameter

Value:  
Unit:

Specify a default value for the cross-section or diameter of the connections and a default value for the associated unit.

An overview of the possible units can be found in the section "[Connections: Units for Lengths and Cross-sections](connectionbrowsergui_k_einheitenverbindungen.htm)".

Alternative value:  
Alternative unit:

Here, an alternative cross-section / diameter can be specified, along with a corresponding alternative unit.

The alternative properties are independent of the parts management and must be manually filled and reported. These properties make it possible to define the connection cross-section / diameter in parallel in different units (e.g., AWG and mm²). The properties are available in the connections property dialog and can be used in reports.

---

Length:

Enter a default value for the connection length in m here.

Unit of length:

This drop-down list shows the display units you can select for the connection length. An overview of the possible units can be found in the section "[Connections: Units for Lengths and Cross-sections](connectionbrowsergui_k_einheitenverbindungen.htm)".

Type designation:

Enter here the type designation of the connection part (e.g., the type number of the wire type). The value is transferred into the Connection: Type designation property and serves as default for new connections.  
During a part selection, the value entered in parts management in the Properties tab below the Connection data node is transferred into this property and overwrites the default value.

Wire termination processing source:  
Wire termination processing target:

Here you specify how the connection should be closed, e.g. with a conductor sleeve or a cable lug. This property is required for the transfer to packaging machines.

Source: Sleeve cross-section:  
Target: Sleeve cross-section:

If the connection is closed with a conductor sleeve, specify the cross-section of the sleeve here. This property is required for the transfer to packaging machines.

Stripping length source:  
Stripping length target:

Here you specify the length of the insulation distance. This property is required for the transfer to packaging machines.

Part number:

Enter the part number of the connection part here, or click [...] to open part selection and select a part there. The part number is transferred into the Part tab of the property dialog of connections and is used as the default value for new connections. We recommend using a part without length and price specifications. To calculate the fill capacity during routing, an outside diameter must be entered at the part.

# P028028: The substance '<x>' entered does not exist as a template in the project

### Cause

A substance that is not defined as a template in the project was determined at a piping planning object or a piping or connection definition.

### Solution

1. Locate the piping planning object in the pre-planning navigator using the Synchronize selection function offered by the popup menu in the Message management dialog. Or use the Go to (graphic) functionality of the popup menu to jump to the piping or connection definition point in the P&I diagram.
2. Open the property dialog of the piping planning object or of the piping or connection definition point and bring the first tab to the front.
3. Click [...] in the property table of the piping planning object for the Substance property. Or in the case of a piping or connection definition point click [...] next to the Substance field.
4. Mark a name listed in the Select substance dialog.
5. Click [OK].
6. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

If the desired substance is not available in the Select substance dialog, you have to define it as a new template in the Segment template navigator.

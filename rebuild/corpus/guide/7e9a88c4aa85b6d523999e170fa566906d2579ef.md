# Reading in Hose Line Data

Before you can configure hose lines, you have to read the hose line data, that as a rule only consist of the full DT of the hose lines, from Eplan Fluid into the hose line configurator.

### Reading in hose line data directly from the fluid schematic

Preconditions:

- You have opened a project.
- In this project you have created one or more fluid schematic pages that contain hose lines which you have inserted by means of the Hose.ems symbol macro.
- You have assigned a DT to the hose lines as minimum information.

1. In the project mark the hose lines that you want to configure.
2. Select the command Hose lines.(To this purpose you first have to [Customize the ribbon](userinterface_h_menuebandanpassen.htm) and then assign the desired command to a user-defined command group.)  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Configure hose lines dialog is opened.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All the hose lines marked in the project are automatically displayed with the full DT and offered for editing in the table of this dialog.

### Importing hose line data through an exchange file

Preconditions:

- You have opened the [Configure hose lines](fluidhoseconfiggui_d_schlauchleitungen.htm) dialog.
- You have received an exchange file as a tab-separated Unicode text file with incomplete hose line data from, for example, the design department.

1. In the Configure hose lines dialog select the menu items Extras > Import.
2. In the subsequent dialog select the storage location and the name of the exchange file and click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The imported hose line data are displayed in the Configure hose lines dialog and can now be edited.

# P005046: Incomplete net

### Cause

#### Possibility 1

Not all the connection points on a net were connected to one another.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

A net N1 in the schematic apparently connects 5 fuses (-F1 to -F5) with the potential L1.

![](../Pictures/Visualisation/ALL/messages_005046_bsp1.1_av.png)

The net properties show, however, that connection point -F5:1 within the daisy chain is not connected.

Daisy chain

| Connection point | Source | Target |
| --- | --- | --- |
| L1 | L1 | -F1:1 |
| -F1:1 | -F1:1 | -F2:1 |
| -F2:1 | -F2:1 | -F3:1 |
| -F3:1 | -F3:1 | -F4:1 |
| -F4:1 |  |  |

#### Possibility 2

Two daisy chains of a net are not connected to one another.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

A net N1 in the schematic apparently connects 5 fuses (-F1 to -F5) with the potential L1.

![](../Pictures/Visualisation/ALL/messages_005046_bsp1.1_av.png)

The net properties show, however, that the connection points are in two separate daisy chains:

Daisy chain 1

| Connection point | Source | Target |
| --- | --- | --- |
| -F4:1 | -F4:1 | -F3:1 |
| -F3:1 | -F3:1 | -F2:1 |
| -F2:1 | -F2:1 | -F1:1 |
| -F1:1 |  |  |

Daisy chain 2

| Connection point | Source | Target |
| --- | --- | --- |
| L1 | L1 | -F5:1 |
| -F5:1 |  |  |

If the connection points on the net were replaced by connectors with target specification, the picture would be as follows:

![](../Pictures/Visualisation/ALL/messages_005046_bsp1.2_av.png)

#### Possibility 3

A connection was deleted within a net in the schematic. This creates a gap in the daisy chain. In this case, message [P005047: Net definition point contains incomplete connections](messages_p_005047.htm) is also output.

#### Possibility 4

An additional connection that has not yet been assigned to a daisy chain was placed within a net in the schematic by copying. In this case the message [P005050: Duplicate ID for net-based connections within a net (<x>)](messages_p_005050.htm) is also output.

### Solution

#### Regarding option 1

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

For the example under "Possibility 1", the steps are as follows:

1. Locate the relevant net definition point in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the Properties <...> dialog for net definition point N1.
3. Bring the Net connections tab to the front.
4. In the Connection points table, double-click connection point -F5:1.   
     
   ![](../Pictures/Gui/ALL/arrow.png) Connection point -F5:1 is copied to the Connections table and entered beneath the horizontal line of the first daisy chain. This starts a new daisy chain.
5. Select connection point -F5:1 beneath the horizontal line, then click the ![](../Pictures/Gui/ALL/all_arrowup_as.png) (Move up) button to move it to the daisy chain already ended.
6. Close the Properties <...> dialog of the net definition point by clicking [OK].
7. If required, start a new check run.

#### Regarding option 2

Connect the two separated daisy chains.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

For the example under "Possibility 2", the steps are as follows:

1. Locate the relevant net definition point in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the Properties <...> dialog for net definition point N1.
3. Bring the Net connections tab to the front.
4. In the Connection points table, double-click connection point -F4:1.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Connection point -F4:1 is copied to the Connections table and entered beneath the horizontal line of the second daisy chain. This creates a new daisy chain.
5. Click ![](../Pictures/Gui/ALL/all_enddaisy_as.png) (End daisy chain) to complete the daisy chain.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A horizontal line is created beneath connection point -F4:1 in the Connections table.
6. Select connection point -F4:1 in the third daisy chain, then click the ![](../Pictures/Gui/ALL/all_arrowup_as.png) (Move up) button to move it to the second daisy chain.  
     
   ![](../Pictures/Gui/ALL/arrow.png) This breaks up the third daisy chain and connects the connection point -F5:1 to connection point -F4:1.
7. Close the Properties <...> dialog of the net definition point by clicking [OK].
8. If required, start a new check run.

#### Regarding option 3

You will find a detailed description in the Help under [P005047: Net definition point contains incomplete connections](messages_p_005047.htm).

#### Regarding option 4

You will find a detailed description in the Help under [P005050: Duplicate ID for net-based connections within a net <x>](messages_p_005050.htm).

---

![](../Pictures/Gui/ALL/note.png)Note:

Eplan provides the possibility to automatically connect associated distributed terminals (Command path: File > Settings > Projects > "Project name" > Devices > Terminals > Settings (distributed terminals) > Check box Connect associated distributed terminals automatically), even if no drawn connections between the distributed terminals exist. However, this functionality is only effective if a net definition point determines the connections. At least one of the distributed terminal connection points occurring several times in the net so that the message "P005046: Incomplete net" is not output during configuring with distributed terminals.

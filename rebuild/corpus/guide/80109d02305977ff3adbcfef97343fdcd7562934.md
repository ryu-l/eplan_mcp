# Lists of Results

For the searching and finding of project data, the Search results - <Project name> dialog provides two lists of results - the list of results and the Go to list.

### List of results

If you carry out a search, the results are entered into the list of results. You can enter additional search results in the list of results and replace existing entries. You also have the option of jumping to the objects on the project pages. You can right-click to open the editing dialog of the corresponding objects for the selected entries in the list of results and make changes to the objects. This can also be performed for blocks of selected objects and texts. For texts, the language display can also be changed (All displayed languages, One language, etc.).

If you have selected objects in the graphical editor or in the navigators, the Insert into list of search results menu item is available in the popup menu. When this menu item is used, the corresponding objects are included in the list of results.

In addition, the drop-down button Find in the ribbon (Tab Home > Command group Find) includes the following commands for the list of results:

| Command | Meaning |
| --- | --- |
| Insert into list | If you have marked objects, they will be included into the list of results without opening the Search results - <Project name> dialog. |
| Previous entry / Next entry | Jumps to the previous or next placed object in the list of results. This enables you to jump from object to object. When performing this, the graphical sequence at the time of the search is maintained. Project data, page data, and unplaced object data are ignored. |

### Go to list

If you have selected objects in the graphical editor, the navigators, or list of results, the menu items Go to (cross-referenced) and Go to (all representation types) are available in the popup menu. (Instead of the previously named menu item, the popup menu item Cross-referenced function is available in the graphical editor.) This menu item will produce another list of results. In the Search results - <Project name> dialog the results are displayed on the Go to tab. Unlike the other list of results, this list is emptied each time before it is filled in. The popup menu provides you with all of the functions available for the list of results.

In addition, the drop-down button Synchronize selection in the ribbon (Tab Home > Command group Find) includes the following commands for the list of results:

| Command | Meaning |
| --- | --- |
| Cross-referenced function --> list | Enters all cross-referenced functions for a selected function into the Go to list and opens the list. The Go to results list shows all objects cross-referenced to the source object, all object that it cross-references, and the object itself.  Objects on the page types "Schematic single-line", "Overview" and "Panel layout" as well as placeholder texts on report pages, 3D part placements in the layout space and cross-referenced model views are also entered in the list. In the case of interruption points not only pair cross-references but also all interconnected interruption points are entered.  [ClosedExample:](javascript:void(0);)  If you call up the command Cross-referenced function --> List for a contact, not only the coil will be entered in the list, but also all of the other contacts as well as the original contact itself. |
| Cross-referenced function --> Forward | Jumps forward in the Go to list and displays the relevant function in the graphical editor. |
| Cross-referenced function --> Backward | Jumps back in the Go to list and displays the relevant function in the graphical editor. |
| All representations | Enters all of the representation types of a function (e.g., on a schematic page, an overview page, and / or a report page) into the Go to list and opens it.  [ClosedExample:](javascript:void(0);)  If you selected the All representations command for a contact, then all representation types for this contact (Single-line, Multi-line, Pair cross-reference, Overview, etc.) are entered in the list. |
| Part assemblies | Eplan enters all the locations at which the relevant parts are output in parts lists and summarized parts lists in the Go to list, and opens the list. The part number is displayed under "Name". |

The popup menu items Go to (graphic) and Go to (counterpiece) that are available in the navigators or the graphical editor are used for navigation in the schematic and do not fill the list of results.

In addition, the drop-down button Synchronize selection in the ribbon (Tab Home > Command group Find) includes the following commands for the navigation:

| Command | Meaning |
| --- | --- |
| Counterpiece | Only available in the graphical editor! For pair cross-references (e.g PLCs, interruption points, etc.) this jumps to a counterpart and for auxiliary functions it jumps to the main function.  [ClosedExample:](javascript:void(0);)  If you call up the command Counterpiece for a contact, a jump takes place to the coil. |
| Graphic | This command is available in the navigators and the search results lists. Jumps to the first selected entry. For placed objects you will jump to the graphical editor. For unplaced objects you will remain where you are. When jumping to connections you will jump to the first graphical connection definition point. If there is no connection definition point you will jump to the source function.  On report pages, a jump occurs to the cross-referenced objects. This allows (e.g.) jumping from the table of contents to the relevant pages. |

### Jumps to reports

It is possible to jump to reports from the lists of results. Using the popup menu item Go to (cross-referenced) the placeholder texts on the report pages is loaded into the list of results. If you select the popup menu item Go to (graphic) on an entry in this list, then the corresponding report page is opened in the graphical editor.

Conversely, you can mark a placeholder text on a report page and use the Go to (cross-referenced) and Go to (all representation types) popup menu items to jump to the associated objects in the list of results.

You can use the popup item Go to (graphic) to jump to the cross-referenced objects on report pages. If you keep the [Ctrl] key pressed down and move the cursor over an object that can be jumped from, the cursor changes into a hand. This allows (e.g.) jumping from the table of contents to the relevant pages.

It is also possible to jump from the report pages to the graphical editor if the data come from another project. If the schematic project (the source project) is not yet open, you will see a message with the option to open the project. Confirm this message with [Yes]; the schematic project is then opened automatically and you jump to the cross-reference object.

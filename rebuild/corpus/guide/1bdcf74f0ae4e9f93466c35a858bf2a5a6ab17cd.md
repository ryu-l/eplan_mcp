# Dialog Settings: Export of text files

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call up (for project data):](javascript:void(0);)

- You have opened a project.File > Export > Command group Project data > Project data > Command group External editing > Properties. Click [...] next to the Settings field in the dialog Edit externally. Select the General tab in the subsequent dialog. In the File type drop-down list, select one of the "Tab-delimited text", "Tab-delimited Unicode file (\*.txt)", or "XML file (\*.edc)" entries and click [Options].
- File > Settings > User > Interfaces > External editing. Select the General tab. In the File type drop-down list, select one of the "Tab-delimited text", "Tab-delimited Unicode file (\*.txt)", or "XML file (\*.edc)" entries and click [Options].

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call up (for parts data):](javascript:void(0);)

Tab Master data > Command group Parts > Management. In the Parts management dialog you have opened a parts database using [Extras] > Settings. Button [Extras] > Edit properties externally > Export data. Click [...] next to the Settings field in the dialog Edit externally. Select the General tab. In the File type drop-down list, select one of the "Tab-delimited text", "Tab-delimited Unicode file (\*.txt)", or "XML file (\*.edc)" entries and click [Options].

In this dialog, you can specify the settings for external editing of pages, functions, or connections in a text editor.

Overview of the main dialog elements:

Application:

Enter the name (including the drive and directory) here for the format of the application to be used, or click ![](../Pictures/Gui/ALL/all_selectfile_as.png) to select the program interactively.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

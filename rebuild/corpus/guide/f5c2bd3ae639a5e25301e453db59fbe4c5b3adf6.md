# P026029: The part placement does not have a valid drilling pattern

### Cause

#### Possibility 1

A part placement was placed on the mounting surface with the activated property Item requires holes in mounting surface. But the part placement does not have a drilling pattern name and drilling pattern data.

#### Possibility 2

A part placement was placed on a mounting surface with a drilling pattern assignment. The drilling pattern name, under which the drilling pattern is defined, however, no longer exists in parts management.

### Solution

1. Locate the part placement in the layout space using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Select a valid drilling pattern (see note below) for the part placement.
3. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png) Note:

A valid drilling pattern consists of a record of drilling pattern data and must be stored in parts management. The drilling pattern data contains information on the name as well as position and dimensions. The drilling pattern must be assigned to the part placement in parts management. You do the assignment via the Manufacturing tab, which allows you to select the drilling pattern via the drilling pattern name.

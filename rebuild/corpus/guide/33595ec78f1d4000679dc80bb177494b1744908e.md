# Dialog Connections

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Tab Master data > Command group Plot frames / forms > Drop-down button Form > Open > Button [Open] For a form of the type "Cable assignment diagram". You have marked the form in the page navigator and opened the Form properties <Form name> dialog via the popup menu item Properties. You have clicked [...] in the Value field for the Connections property.

In this dialog, you control the assignment of connections to connection points in cable diagram forms.

Overview of the main dialog elements:

Source (designation) / Target (designation):

The designations of the connection source and target are stored in this table.

Connection (color / number):

You can store the color or number of the connection here.

The assignment of a connection to two connection points is thus shown as a "three-tuple"; multiple connection assignments are each separated by a "pipe" character.  
("Tuple" is a mathematical term representing an ordered combination of objects whose elements have a fixed sequence.)

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

For a cable, the entry 1;2:red|2;3;|;3;4;blue means:   
The red conductor of the cable type connects connection point 1 with connection point 2. The second conductor of the cable type connects connection point 2 with connection point 3, and the blue conductor of the cable type connects connection point 3 with connection point 4.

Popup menu:

# Outputting Pages as PDF Files

Regardless of the option selected (individual project pages or an entire project), only one PDF file is created.

![](../Pictures/Gui/ALL/note.png)Note:

When large pages are exported, you have to take into account that problems may occur in case of an export in the original size. Therefore you should first break up the imported DXF blocks so that scaling to the page size is possible. (This takes place via the following commands: Tab Edit > Command group Block > Break up.)

Precondition:

You have opened a project.

1. In the page navigator, select the pages of a project (or the entire project) that you wish to export.
2. Select the following commands: File > Export > Command group Project data > Project data > Command group Page > PDF.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan opens the PDF export dialog. The selected objects are displayed in the Source (page / 3D model) field.
3. Select a suitable scheme from the Scheme drop-down list, or click [...] to open the Settings: PDF export dialog for creating or editing a scheme.
4. In the PDF file field you enter the target directory and the name of the PDF file to be created, or select it interactively by using ![](../Pictures/Gui/ALL/all_selectfile_as.png). The initial default is the documentation directory DOC and the name of the selected project (...\<Project.edb>\DOC\<Project>.PDF).
5. In the Output directory field select the storage location in which the output is to take place.
6. In the Output group box specify how it is to be output.
7. Activate the Use print margins check box if the print margins specified in the print settings are to be considered as well for the PDF export.
8. You use the check box Output 3D model / Output pages with model views to specify if the project contains 3D models and / or pages with model views of these models that are to be output.
9. If you want to extend the current selection to the entire project, activate the Apply to entire project check box.
10. Click [Settings] to view and, if necessary, modify the settings for the output languages, output size, and print margins.
11. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) Eplan generates the PDF file.

![](../Pictures/Gui/ALL/note.png)Note:

Adobe Acrobat Reader (minimum version 10.0) must be installed on your computer in order to read an exported PDF file.

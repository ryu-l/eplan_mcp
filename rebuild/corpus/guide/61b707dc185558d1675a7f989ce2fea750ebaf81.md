# Dialog Back up data

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Tab Tools > Command group Reports > Automated processing. Click [...] next to the Scheme field in the dialog Run: Automated processing. Mark the action "Back up data" in the dialog Settings: Automated processing in the Available actions field, and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).
- You have opened a project. File > Extras > Command group Extensions > Interfaces > Command group Automated processing > Automated processing. Click [...] next to the Scheme field in the dialog Run: Automated processing. Mark the action "Back up data" in the dialog Settings: Automated processing in the Available actions field, and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).
- File > Project management. You have imported directories in the Project management dialog and selected at least one project. [Organize] > Automated processing. Click [...] next to the Scheme field in the dialog Run: Automated processing. Select the Scheme option and click [...] next to this field. Mark the action "Back up data" in the dialog Settings: Automated processing in the Available actions field, and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).

In this dialog you define the settings for automated backup.

Overview of the main dialog elements:

Method:

Define the manner in which the project is to be backed up:

- Save additionally: The project is compressed as a \*.zw1 file and saved in the directory that you have selected in the Backup directory field. The source project remains unchanged.
- File off for external editing: The project is saved on a different storage medium and the source project becomes write-protected. All data from the filed-off project remains in the original location. The \*.elk project becomes an \*.els project in the same directory. A \*.zw1 backup file is also created in the selected backup directory.
- Archive: The project is saved onto a different storage medium and, apart from a single information file, the source project is completely deleted from the hard drive. The \*.elk project becomes an \*.ela project in the same directory. A \*.zw1 backup file is also created in the selected backup directory.

Backup file name:

This is where you enter the name of the backup file. The project name is used by default. With ![](../Pictures/Gui/ALL/all_selectfile_as.png) you open a file selection dialog and can select the name of an existing backup file there.

Backup directory:

This field contains the directory to which the data is backed up. Use ![](../Pictures/Gui/ALL/all_selectdirectory_as.png) to open the directory selection dialog. In this dialog you can choose another directory as the storage location. Any desired directory on any logical drive is a valid location.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

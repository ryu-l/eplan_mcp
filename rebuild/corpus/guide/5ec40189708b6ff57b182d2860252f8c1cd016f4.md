# P502042: The file '<x>' is not located in the master data directory '<z>' foreseen for the property '<y>'

### Cause

In the parts database to be checked a part was determined for which a file that is not located in the set directory for the respective master data (for example an image file that is saved outside the set directory for images) is specified for a property. Files that are not located in the specified directories cannot be output during the parts data export in the EDZ format.

### Solution

1. In the parts management mark the line with the message in the Messages tab and select the Go to popup menu item for this line.  
   ![](../Pictures/Gui/ALL/arrow.png) The respective part is marked in the tree view of the parts management.
2. Bring the Properties tab to the front.
3. Click the ![](../Pictures/Gui/ALL/all_selectfile_as.png) button in the value field of the affected property to call up the Windows Explorer.
4. Move the respective file into the correct master data directory.
5. Double-click the newly stored file in the Windows Explorer.  
   ![](../Pictures/Gui/ALL/arrow.png) The file is inserted with the correct file path into the value field of the affected property.
6. Click [Apply].
7. If required, start a new check run.
8. Close the parts management and perform a parts data synchronization.

![](../Pictures/Gui/ALL/note.png)Note:

This check run is not activated by default and can only be performed offline.

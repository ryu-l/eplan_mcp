# Dialog Image file export

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You highlighted a project or at least a project page. File > Export > Command group Project data > Project data > Command group Page > Image file.

In this dialog you start the actual export process. When you export an entire project or individual pages in an image file format, a separate file is generated for every selected page.

Overview of the main dialog elements:

Source:

This field displays the source of the export. For an entire project, this is the project name; for individual pages the full page names are displayed (including the page properties Functional assignment, Function designation, etc.). The entries can't be edited here.

Scheme:

Select a scheme to define the settings for the export of graphics files from the drop-down list. Click [...] to open the settings dialog for the export. There you can define settings and save them as a scheme or [Edit existing schemes](schemeconfig_h_schematabearbeiten.htm).

Target directory:

Here you specify the default target directory for the files to be generated, or click ![](../Pictures/Gui/ALL/all_selectdirectory_as.png) to select it. The default is the directory that is set as the target directory in the selected scheme.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

File name:

When exporting a single page you can enter any desired file name here. You can use ![](../Pictures/Gui/ALL/all_selectfile_as.png) to assign a new file name or select the name of an existing file. The directory selected is loaded into the Target directory field.

If you do not enter a specific file name, the exported file will be named after the page (e.g., =EB3+ET1/1.bmp). To prevent files from different projects becoming mixed up, a subdirectory with the same name as the project is generated in the specified directory, and the files are exported to it.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

![](../Pictures/Gui/ALL/note.png)Note:

When you export multiple pages, you cannot select the file name yourself; the image files are generated from the page names.

Black-and-white output:

If this check box is selected, all of the elements on the project pages (except image files) will be printed in black on a white background. Image files are always output in their original colors.

![](../Pictures/Gui/ALL/note.png) Note:

If you want to print the "color" image files on the exported pages in gray scale, set the printer driver of your color printer to black and white or use a black and white printer.

If the check box is not selected, all elements will be printed in the colors that correspond to the color scheme "Color on white".

Invert white graphical elements:

This check box is available if the Black-and-white output setting is activated. If this check box is selected, graphical elements which have been assigned the Eplan color numbers 8, 255, 263, 264 and 266 are output in black.

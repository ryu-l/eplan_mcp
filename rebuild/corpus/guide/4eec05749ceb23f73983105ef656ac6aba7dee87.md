# Dialog Export assignment list (entire CPU)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Tab Devices > Command group PLC > Assignment list > Button [Extras] > Export assignment list (entire CPU)
- File > Export > Command group Project data > Project data > Command group PLC > Assignment list > Button [Extras] > Export assignment list (entire CPU)

In this dialog, you export the assignment lists that you have either created or edited.

![](../Pictures/Gui/ALL/note.png)Notes:

- You can export only one separate list each for each processor (CPU). Therefore set the filter in the dialog Addresses / assignment lists so that the PLC addresses of only one CPU are displayed.
- When exporting an assignment list, all PLC I/O connection points of the CPU are always exported. A filter set in the dialog Addresses / assignment lists only affects the display.

Overview of the main dialog elements:

PLC-specific settings:

The scheme which defines the format of the PLC addresses is displayed in this field. The scheme is determined on the basis of the CPU that is contained in the selection and cannot be changed here. If no scheme is assigned to the CPU, the scheme specified in the project settings is used. The configuration project and the workstation name to which the CPU is assigned are further displayed via the field.

Language:

All languages defined in the translation settings for the project are displayed in the drop-down list. Select the language in which the assignment list is to be exported. The "All displayed languages" entry is used to export the assignment list in all the displayed languages that are selected in the translation settings. Detailed information is available in the section "[Export and import of multilingual function texts in the assignment list](plcgui_k_zuordnungslisten.htm#I_MehrsprachigeFunktionstexte)".

![](../Pictures/Gui/ALL/note.png)Note:

Before you can export the assignment list in Unicode languages such as Chinese and Russian, you must have selected the "UNICODE" entry from the Character set drop-down list on the Format of assignment list tab in the Settings: PLC-specific dialog.

File name:

In this field, you enter the name of the file where the assignment list is to be saved. Click ![](../Pictures/Gui/ALL/all_selectfile_as.png) to open the file selection dialog where you can select an assignment list that you wish to overwrite or whose name you wish to change.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

![](../Pictures/Gui/ALL/note.png)Note:

The file types available in the file selection dialog depend on the scheme selected in the dialog Settings: PLC.

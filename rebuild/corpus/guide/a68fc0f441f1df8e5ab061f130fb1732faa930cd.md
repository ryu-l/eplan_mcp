# Managing Symbols

Symbols are standardized graphics for representing functions. The logic for the symbol is stored in the function definition which the symbol refers to.

Symbols are managed in symbol libraries, which can contain any number of symbols. You can use the symbols stored in symbol libraries in different projects by loading the symbol library into the current project. At the same time, this means that the basic function definitions, i.e. the logical data, are used in all projects in a unified manner.

Standardized symbol libraries contain the most frequently used symbols for the following areas:

- General system electronics
- Mounting panel construction drawings
- Measurement and control technology
- Single-line Representation
- Hydraulics
- Pneumatics
- Electronics
- Process diagrams.

![](../Pictures/Gui/ALL/note.png)Note:

Symbol libraries with special symbols (such as black boxes, PLC boxes, structure boxes, shields, etc.) can only be edited and extended by EPLAN GmbH & Co. KG, that is, they are locked for you. When you try to open such a symbol library, a message will appear and the action is canceled.  
When creating a project, these symbol libraries are automatically stored in the project.

Symbols are edited and created in a special editor, the "Symbol editor". This is also where symbol libraries are created and edited. During schematic creation in the graphical editor you can only access symbol data and insert them via the Insert center dialog.

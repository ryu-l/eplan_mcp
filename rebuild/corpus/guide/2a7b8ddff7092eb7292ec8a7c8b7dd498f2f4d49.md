# P005036: The minimum number of digits for the format (<x>) was exceeded

### Cause

The minimum number of digits for a format element of the connection numbering is longer than has been agreed in the settings.

### Solution

If you do not want this message to be output anymore, please increase the minimum number of digits for the corresponding format element.

The setting can be accessed as follows:

1. Select the following commands: Tab Connections > Command group Connections > Enter designation.
2. Click [...] next to the Settings field in the dialog Designate connections.
3. Bring the Designation tab in the Settings: Connection numbering - <Project name> dialog to the foreground.
4. Select the desired connection group in the Format groups list, and click ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit).
5. In the dialog Connection numbering: Formats, select the desired format element in the Selected format elements list and click ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Format: <Format element> dialog opens that offers you the Minimum number of digits field for the setting.

![](../Pictures/Gui/ALL/note.png)Note:

This module-specific message is output during the numbering of connections. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

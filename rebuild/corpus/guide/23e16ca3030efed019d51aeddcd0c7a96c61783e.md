# Extension for Fluid Functionalities

All module packages of Eplan Electric P8 have been extended with the Eplan Fluid functionalities for Version 2026. This means that all functionalities of Eplan Fluid are now an integral part of Eplan Electric P8.

Therefore installing Eplan Fluid as an independent program is no longer required and is no longer available. An installation of the original master data of Eplan Fluid as an add-on is still possible. The extensive master data for Eplan Fluid are not installed by default during an Eplan Electric P8 installation. When selecting the program components in the Eplan Setup Manager, however, you have the option of activating the installation of these data.

# Regenerating Headings on Form Pages

You use the form property Generate data headers for the first x sorting properties (ID 13060) to create references to the sorting of the respective reports. This means that the form defines whether the sorting properties should be used for generating new headings.

The following values are possible for this property:

| Value | Meaning |
| --- | --- |
| 0 | No new headings are generated. |
| 1 | The first sorting property is used for the new heading. |
| 2 | The first and second sorting properties are used for the new heading. |
| 3 | The first, second, and third sorting properties are used for the new heading. |
| x | The first, second, etc. to x sorting properties are used for the new heading. Whereby "x" is any integer. |

Preconditions:

- You have opened a project.
- You have opened the form whose properties you want to edit in the form editor (Tab Master data > Command group Plot frames / forms > Drop-down button Form > Open > Button [Open]).
- You have marked the form in the page navigator and opened the Form properties <Form name> dialog via the popup menu item Properties.

1. In the Form properties - <Form name> dialog, click ![](../Pictures/Gui/ALL/all_new_as.png) (New) above the Property name / Value list.
2. In the Property selection dialog, select the Generate headings for the first x sorting properties property.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property is loaded into the list.
4. Enter the number of sorting properties to be taken into account into the Value column.
5. Edit other form properties as required.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The defined properties are adopted for the form and the Form properties- <Form name> dialog closes.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

In the Sorting dialog, you have selected the "Function designation + Location designation + DT" scheme for outputting the device tag list. In the form for the device list, the Generate headings for the first x sorting properties has been given the value "1".

If you now generate the report pages for the device tag list, a new heading is generated for each new function designation. The data between the headings is still sorted by location designation and DT.

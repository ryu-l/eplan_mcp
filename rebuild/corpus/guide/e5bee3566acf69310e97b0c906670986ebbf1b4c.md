# Deleting Report Pages

When deleting report pages, all report pages belonging to a [Report block](formgeneratorgui_k_auswertungsbloecke.htm) are deleted.

Precondition:

You have opened a project.

1. Select the following commands: Tab Tools > Command group Reports > Generate.
2. In the Reports - <Project name> dialog, select the Reports tab.
3. Select a report block.
4. Select the Delete report block popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All report pages belonging to this report block are deleted.

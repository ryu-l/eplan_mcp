# P008003: The language '<x>' does not exist in the dictionary

### Cause

The source language '<x>' selected in the project-specific settings for project texts exists as a translation language, but not as a dictionary language.

### Solution

Add the missing language that you have defined in the settings as a translation language and have selected as a source language to the dictionary.

1. Select the following commands: Tab Tools > Command group Translation > Dictionary.
2. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the Dictionary dialog in the Management tab.
3. Select the desired language in the list that opens.
4. Close the dialog.
5. Translate the desired text.

![](../Pictures/Gui/ALL/note.png)Note:

This module-specific message is output during the automatic translation of texts. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

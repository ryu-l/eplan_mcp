# P024013: Conduit: 'Function text (automatic)' different (in language '<x>')

### Cause

For a conduit placed in a distributed manner in the schematic, the Function text (automatic) property is different in the selected display language at one or several placements of the conduit.

### Solution

1. Locate the main function of the conduit in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Open the main function of the popup menu and use the menu item Go to (counterpiece) to jump to the auxiliary function of the conduit.
3. Open each property dialog at the main and auxiliary functions of the conduit and standardize the Function text (automatic) property in the selected displayed language.
4. Confirm your entries.
5. If required, start a new check run.

# Basic Project and Defining Rotation / Flipping (Change of Standard)

Use a basic project to customize designations and names to the target standard. The setting for rotation / flipping specifies, in combination with the selected symbol libraries, the location of the schematic elements in the schematic.

Preconditions:

- You have opened a project.
- In the case of several opened projects: You have selected a project in the page navigator.
- You have a basic project containing country- or standards-specific settings.
- You have set up a target project.

1. Select the following commands: Tab Tools > Command group Standards > Exchange.
2. Open a file selection dialog via ![](../Pictures/Gui/ALL/all_selectfile_as.png) in the Basic project field of the Rotation / flipping tab and there select the desired basic project \*.zw9 or the desired backed up Eplan project \*.zw1.
3. From the Rotation / flipping drop-down list, select the way in which you want to rotate and flip.
4. Click [Next].

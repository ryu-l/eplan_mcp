# P007032: For a function with DT ID the superior function with DT ID is missing

### Cause

In a macro project a function with a nested device tag (for example "-A1-B1") exists within in a macro. This function has a DT ID. However, either a function which has the superior device tag assigned (in the example"-A1") is missing in the macro or this function exists but has no DT ID assigned.

### Solution

#### Possibility 1

1. If a function which has the superior device tag assigned exists in the macro, enter the appropriate DT ID there.

#### Possibility 2

1. Draw a black box around the functions whose visible device tags are nested.
2. Assign the outer component of the nested tag to this black box.
3. Remove the outer (front) component of the nested device tag at the functions which are now located in the black box. (The outer device tag is now "inherited" by the black box).
4. Then enter the DT ID at the newly drawn black box.

#### Possibility 3

1. Draw a black box next to the items.
2. Assign the outer (front) component of the nested device tag to this black box.
3. Then enter the outer DT ID at all the functions.

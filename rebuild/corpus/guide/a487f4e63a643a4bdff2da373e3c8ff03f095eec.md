# P028032: The subordinate segments do not match the subordinate segment templates

### Cause

It is possible with segment templates to create nested structures with planning objects, PCT loops, PCT loop functions etc. as a template and to reference them.

A subordinate segment in contrast to the segment template was deleted within such a nestled structure. Or a subordinate segment template was removed or added in the segment template without the segments being subsequently updated.

### Solution

1. First locate the affected segment in the pre-planning navigator using the Synchronize selection function offered by the popup menu in the Message management dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The respective segment is marked in the pre-planning navigator.
2. To correct the substructure of an individual segment, select the popup menu item Reset to segment template for the segment selected in the pre-planning navigator.  
   To correct all segments or a segment template, select the popup menu item Update segments for the segment template selected in segment template navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In both cases the structure in the pre-planning navigator is modified accordingly after the correction.
3. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

Note that after the menu item Reset to segment template has been selected, other data of the segment is also reset, for example properties.

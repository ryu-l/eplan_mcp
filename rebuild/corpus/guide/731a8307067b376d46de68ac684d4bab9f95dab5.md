# Exporting Wire Fabrication

Representative for all wire fabrication interfaces, here the export for the "General wires parts list" format is described. The export of the other interfaces is done in the same manner, but differs in terms of the values to be entered in the export dialog and the file formats generated.

Preconditions:

- You have opened a project.
- A machine of the required type is defined in the company settings.
- You have opened the layout space navigator and a layout space.
- The connections navigator is open.
- You have created routing connections.
- You have highlighted connections in the connections navigator or in the [wiring manager](routinggui_d_verdrahtungsmanager.htm), or you have selected the area to be exported in the layout space or layout space navigator.

1. Select the following commands: File > Export > Command group Manufacturing data > Wire fabrication > Wires parts list.
2. In the dialog Wire fabrication: General wires parts list, select the scheme of the required machine, the language and the output directory, or import the default settings.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the set output directory, the wires parts list file is generated with the pre-selected name. In the export of machine-specific interfaces, depending on the manufacturer, several files are generated with set file names and file name extensions. This data is transferred to the software of the wire fabrication machine.

![](../Pictures/Gui/ALL/note.png)Note:

Please note that sorting of the wires parts list is carried out text-oriented by the bundle number, so that the output is "1, 10, 2, ...". To avoid this use leading zeros.

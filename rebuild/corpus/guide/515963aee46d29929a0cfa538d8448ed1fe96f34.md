# P005015: Targets have differing potential types

### Cause

Targets of a connection have different potential types for their function connections. For example, one target has the potential type "L" while the other has the potential type "PE / PEN".

### Solution

1. Enter the same potential type for all function connections that are targets of the connection.
2. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

The potential type "undefined" can be used for all connection points.

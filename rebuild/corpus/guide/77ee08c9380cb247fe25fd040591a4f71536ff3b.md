# Inserting New Devices Without a DT

New devices / functions can be placed in the schematic during the Insert > Symbol procedure without automatic DT assignment . In this case, the entries for the displayed and full DT remain empty.

Precondition:

You have opened a project.

1. Select the following commands: File > Settings > Projects > "Project name" > Devices > Numbering (online).
2. Under On symbol insertion, select the Empty field option.
3. Click [OK].

### Insert a device / function via a symbol without DT

1. Select the following commands: Insert center > Breadcrumb trail Home > Symbols. Using the folder structure navigate to the desired symbol and select it by clicking the preview tile.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol hangs on the cursor.
2. Move the cursor to the desired location on the schematic page.
3. Click the page to place the symbol.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Properties (components): <...> dialog opens. There is no DT entry in the Displayed DT field.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol is placed without DT.

### Create a device / function without placement and without DT

1. Select the following commands: Tab Devices > Command group Devices > Navigator.
2. Select the Tree tab.
3. Select the project level.
4. Select the New popup menu item.
5. Select a function definition in the Selection field of the Function definitions dialog and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Properties (components): <...> dialog opens. There is no DT entry in the Displayed DT field.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The device / function is sorted into the tree structure level without DT.

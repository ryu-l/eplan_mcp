# Scheme Toolbar

In the toolbar to the right of the Scheme field, the following buttons can be available:

| Button | Meaning |
| --- | --- |
| (Edit) | Opens a dialog allowing editing of the selected scheme. |
| (New) | Opens the New scheme dialog. This enables you to create a scheme. |
| (Save) | Saves a scheme. |
| (Copy) | Opens the Copy scheme dialog. This enables you to copy an existing scheme. |
| (Delete) | Deletes a scheme. |
| (Export) | Opens the Select export file dialog. This enables you to export a scheme. Multiple selection is not possible. |
| (Import) | Opens the Select import file dialog. This enables you to import one or more schemes. Multiple selection is possible. |

![](../Pictures/Gui/ALL/note.png)Notes:

- To access old schemes, these must first be exported in the previous version. This can be done either for all schemes of a settings section via the ![](../Pictures/Gui/ALL/all_export_as.png) (Export) button in the left-hand area of the settings dialog (toolbar above the tree structure of the settings sections) or for an individual scheme via the ![](../Pictures/Gui/ALL/all_export_as.png) (Export) button in the right-hand area of the settings dialog (toolbar next to the Scheme field).  
    
  After the import, the schemes will then be converted into the new format via the corresponding ![](../Pictures/Gui/ALL/all_import_as.png) (Import) button.
- For both imports and exports, unique file names following the pattern "Action.Schema name.xml" are suggested, for example "CBcr.Standard.xml" for exporting the "Default" scheme for cable generation ("CBcr" = CABLE create). This makes it easier to keep an overview of existing schemes.

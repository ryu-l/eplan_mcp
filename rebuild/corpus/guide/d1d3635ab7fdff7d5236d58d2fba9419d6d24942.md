# Dividing Projects into Defined Working Sections

Preconditions:

- You have opened a project.
- You (or the project administrator) have created schemes which determine the criteria for the division into defined working sections.

1. Select the following commands: File > Collaboration > Command group Defined working sections > Define > Define.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the Define working sections dialog, the schemes are displayed that were already created for the division in defined working sections.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the All editors column, you will also see the other editors who have selected a defined working section in the project.
2. Select your defined working section by activating the check box for the desired scheme in the My defined working section column.
3. If you want to edit the entire project temporarily, activate the Work temporarily in entire project check box.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Editing is extended temporarily to the entire project. For example, this can be helpful in updating reports.
4. Click [OK].
5. Select the following commands: File > Collaboration > Command group Defined working sections > Activate. Activate the Activate selected defined working sections check box.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Editing is now limited to only within the specified defined working sections. The project data navigators will then display only the pages, devices, etc. corresponding to the criteria determined in the scheme.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the selection of defined working sections has been activated for a project, a percentage symbol "%" is displayed in front of the project name in the title bar of the navigators (for example in the page navigator: Pages - %EPLAN\_Sample\_Project).

![](../Pictures/Gui/ALL/note.png)Notes:

- Devices, terminal strips, etc. that have not been sorted into a defined project structure by means of structure identifiers are sorted into the tree structure level "Without structure identifier" of the device navigator. Such devices without structure identifier can be selected for editing by entering an empty structure identifier as filter criterion in the scheme for the defined working section.
- If a user enters a new structure identifier during project processing, this will be available as filter criterion at once, it is, however, not automatically entered into the current scheme for the defined working section.

![](../Pictures/Gui/ALL/info.png)Tip:

To temporarily extend the defined working section to the entire project select the commands File > Collaboration > Command group Defined working sections > Activate and activate the check box Entire project. After you have completed the action, exit the temporary editing in the entire project by selecting the command again and deactivate the check box.

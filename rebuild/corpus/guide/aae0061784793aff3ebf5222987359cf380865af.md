# Dialog Settings: Check Eplan version

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Settings > Company > Management > Check Eplan version

In this dialog you specify whether a check is to be carried out for possible updates when Eplan is started.

Overview of the main dialog elements:

Check for a new Eplan version:

If this check box is activated, a check is carried out for a more recent version of the software when Eplan is started. In this case a system message is displayed and the ![](../Pictures/Gui/ALL/modaldialogsgui_update_available.png) icon is displayed in the status bar. A click on this icon then opens the Eplan Download Manager and you can install the most recent version of Eplan.

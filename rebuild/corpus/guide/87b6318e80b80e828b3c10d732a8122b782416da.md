# Parts management: Assignment of ECLASS properties to Eplan part properties

ECLASS properties can have a cardinality, for example the number of connection points of an item. This is used to define how often a block of ECLASS properties occurs repeatedly. At the moment of definition of an assignment of ECLASS data one only knows that a block can occur several times. But not how often the block occurs during the actual import. This can differ at every imported object.

It must be possible to assign ECLASS properties with cardinality to several Eplan part properties. This is realized as follows:

- The user can also select several Eplan properties for each ECLASS property that can occur several times due to the cardinality.
- During the import these ECLASS properties are assigned to these Eplan properties in sequence.
- User-defined properties and indexed Eplan properties such as attributes and free properties can also be selected here.
- The user selects all the indexes to be used explicitly in the process, for example "Attributes 10 to 20".
- A dialog is available with one list each for the assignment of available properties and selected properties in which the sequence of the selected properties can be changed by means of buttons.
- If an object to be imported contains more ECLASS properties than were defined during the assignment of the cardinality, the superfluous properties are ignored.

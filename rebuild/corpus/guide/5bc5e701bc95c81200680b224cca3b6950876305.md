# Tab Further properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > User > Add-ons > Hose line configurator. Click the Further properties tab.
- You have opened a project. You have opened the [Configure hose lines](fluidhoseconfiggui_d_schlauchleitungen.htm) dialog. Select the Extras > Settings menu items. In the subsequent dialog click the Further properties tab.

In this tab you can specify up to 200 additional properties and assign a specific value to each property. You can use these properties to extend the type code required for ordering hose lines and thus adapt them individually to the order specifications of different manufacturers. The properties are defined as so-called "free properties" meaning that you can define their names and values freely.

For example some manufacturers offer hose lines with a tubing protection. In the order information you then have to carry out specifications for the tubing protection, such as the tubing protection type and the tubing protection length, in addition to the type code to DIN 20066.

![](../Pictures/Gui/ALL/note.png)Note:

The free properties defined in this tab cannot be implemented in the type code until you have also correspondingly extended the format of the type code in the General tab.

Overview of the main dialog elements:

Property (list):

You define the free properties in this list.

Use the buttons of the toolbar above the list to create new entries, edit existing ones and / or delete entries no longer required.

Table:

You can assign a value to the respective property in this table.

Use the buttons of the toolbar above the table to create new entries and / or delete entries no longer required.

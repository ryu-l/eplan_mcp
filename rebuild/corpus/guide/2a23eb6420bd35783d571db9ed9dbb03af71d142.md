# Backing up Projects

Projects can be backed up from the Backstage view and from the project management.

### [ClosedBack up projects from the Backstage view](javascript:void(0);)

Precondition:

You have selected a project in the page navigator.

1. Select the following commands: File > Back up.
2. In the [Back up projects](bakbackupdlggui_d_projektesichern.htm) dialog, define the settings for the backup.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project is backed up to the specified directory according to the entries you have made.

![](../Pictures/Gui/ALL/note.png) Note:

Eplan notes these settings for each project and offers them again during later backups.

### [ClosedBack up projects from the project management](javascript:void(0);)

Preconditions:

- You have set up the project management.
- In the tree structure of project management there is an imported directory with at least one project.

1. Select the following commands: File > Project management.
2. Select the desired projects from the tree structure in the Project management dialog.
3. Select the Back up popup menu item.
4. In the [Back up projects](bakbackupdlggui_d_projektesichern.htm) dialog, define the settings for the backup.
5. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The projects are compressed one after another, and backed up to the specified directory.

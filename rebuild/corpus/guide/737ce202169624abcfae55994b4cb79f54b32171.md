# Inserting and Editing Special Text

Preconditions:

- You have opened a project.
- You have opened the form in which you want to define special texts in the form editor (Tab Master data > Command group Plot frames / forms > Drop-down button Form > Open > Button [Open]). Or you have opened the plot frame in which you want to define special texts in the plot frame editor (Tab Master data > Command group Plot frames / forms > Drop-down button Plot frame > Open > Button [Open]).

### Insert project and page properties in forms and plot frames

The special project and page properties available for forms and plot frames are placeholders that are automatically replaced with the corresponding properties by Eplan.

1. Select the following commands: Tab Insert > Command group Text > Drop-down button Text > Project properties or Page properties.
2. Click [...] in the Property field of the Placement tab on the Special text <...> dialog.
3. In the Property selection dialog, select the page or project property that should be inserted in the plot frame / form.
4. If needed, limit the display of possible properties by selecting an entry from the Category drop-down list.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected property is adopted in the Property field.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The element hangs on the cursor.
7. Position the special text on the plot frame / form page.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The element hangs on the cursor.
8. Position the special text a second or third time.
9. Select the Cancel action popup menu item to exit the action.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The special text is inserted on the plot frame / form page and can be revised by double-clicking it.

![](../Pictures/Gui/ALL/note.png) Note:

Eplan internally notes the last selected property and suggests it again when next inserting. All settings made during the placement are also used.

### Insert form and plot frame properties in forms and plot frames

The form and plot frame properties available for forms and plot frames are property placements that can be formatted as desired. Only the properties permissible for the respective form / plot frame type are available for selection.

The insertion of these special texts takes place in accordance with the special texts page and project properties described above â however, via the following commands: Tab Edit > Command group Form / Plot frame > Special text.

### Insert column and row texts in plot frames

There are also column and row texts available for plot frames in addition to the project and page properties.

1. Select the following commands: Tab Edit > Command group Plot frame > Drop-down button More > Insert column text or Insert row text.
2. Specify the formatting settings for the row and column text in the Format tab of the Special text <... > dialog.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The element hangs on the cursor.
4. Position the special text on the plot frame page.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The element hangs on the cursor.
5. Position the special text a second or third time.
6. Select the Cancel action popup menu item to exit the action.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The special text is inserted on the plot frame page and can be revised by double-clicking it.

![](../Pictures/Gui/ALL/note.png) Note:

With the command Place column and row text again these special texts can be deleted and automatically placed on the edge areas of the defined columns and rows (Tab Edit > Command group Plot frame > Drop-down button Other > Place column and row text again).

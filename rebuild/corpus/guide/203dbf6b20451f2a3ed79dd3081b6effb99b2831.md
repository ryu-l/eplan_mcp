# P007010: Functions have conflicting data at the '<x>' property

### Cause

With cross-referencing functions, the data of a specific property of a main and an auxiliary function do not match.

### Solution

1. Enter the same property for the main and sub-function.
2. If required, start a new check run.

![](../Pictures/Gui/ALL/info.png)Tip:

Use the block editing or the table editing tool. You can change the properties of multiple function in one go with both editing tools.

# P004050: Connection from '<x>' to '<y>' missing

### Cause

During the PLC data import an individual connection from '<x>' to '<y>' was determined that was currently not found in the project. In the placeholders '<x>' and '<y>' the respective bus port is output with its identifying DT.

### Solution

1. Create the connection between the devices by means of bus ports.
2. Import the PLC data again.

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

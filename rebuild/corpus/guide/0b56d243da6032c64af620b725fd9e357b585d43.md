# P017012: The preceding sign is missing at the displayed DT

### Cause

You have placed a device in the schematic at which the preceding sign is missing at the displayed DT.

![](../Pictures/Gui/ALL/note.png)Note:

Note that this check run takes into consideration the settings specified under the following command path: File > Settings > Projects > "Project name" > Devices > DT.

### Solution

1. Locate the device in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Call up the dialog Properties <...> of the device and enter the preceding sign "-" (minus) before the identifier of the DT in the Displayed DT field.
3. Click [OK].
4. If required, start a new check run.

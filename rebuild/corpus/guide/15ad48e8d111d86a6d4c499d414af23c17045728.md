# Changing the Rotation Angle when Inserting 3D Macros

When you insert a 3D macro, you can rotate the angle of the macro in 90° increments at the handle. Up to 40 different mounting positions can be implemented with a single 3D macro by changing the handles. These options also apply to devices whose parts have been assigned a 3D macro.

Preconditions:

- You have opened a project.
- You have opened the layout space navigator and a layout space.

1. Select the following commands: Insert center > Breadcrumb trail Home > Window macros / symbol macros. Select a 3D macro for placement.
2. Select the following commands: Tab Insert > Command group Options > Change rotation angle.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The position of the 3D macro is rotated by 90° counter-clockwise.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Each time the Change rotation angle command is selected, the macro is rotated a further 90°.
3. Click [A] to change the handle.
4. At the changed handle, select the Change rotation angle command again.  
     
   ![](../Pictures/Gui/ALL/arrow.png) You can set four different rotation angles at each available handle. This means that with nine default handles and one user-defined handle, as many as 40 possible positions can be implemented.

![](../Pictures/Gui/ALL/info.png)Tip:

You can also use the [Ctrl] + [Shift] + [R] shortcut key to change the rotation angle while inserting.

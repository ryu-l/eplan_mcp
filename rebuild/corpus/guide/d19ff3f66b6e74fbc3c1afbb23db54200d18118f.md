# P005034: An identified connection definition point is located on multiple connections

### Description

This message is output when one of the connection definition points is located on several connections during the designation of the connection definition points.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The connection definition point 001 was placed on an autoconnecting line that leads from a T-node from the terminal -XD1 and back. The function connection point 1 of the terminal is therefore connected with more than one connection. This results in a contradiction when numbering the connection.

![](../Pictures/Visualisation/ALL/messages_005035_bsp_av.png)

Whether an identified connection definition point is located on several connections can be seen in the Tooltip text, if you move the cursor over the autoconnecting line with the connection definition point.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

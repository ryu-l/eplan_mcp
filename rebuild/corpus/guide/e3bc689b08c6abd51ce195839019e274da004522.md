# P001039: Saddle jumper at terminal without saddle jumper connection point

### Cause

A wrongly formed saddle jumper was found in the project. You have defined a connection between terminals as a saddle jumper in the schematic or in the dialog Edit terminal strip. However, no value for the number of saddle jumpers is entered at one or both terminals.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

A connection defined as a saddle jumper exists between the two terminals -X1:1 and -X1:2. Both terminals are "normal" feed-through terminals with two connection types. In the Connection point logic dialog no value or 0 was entered for the respective first function connection point at both terminals for the property Number of saddle jumpers.

![](../Pictures/Visualisation/ALL/messages_001012_bsp1_av.png)

### Solution

1. Call up the dialog Properties for the terminals respectively.
2. Switch to the Symbol / function data tab and open the Connection point logic dialog by clicking the [Logic] button.
3. In the Number of saddle jumpers field, enter a value for the respective function connection points that is greater than "0" (with regard to the example a 1 each at the first function connection point).

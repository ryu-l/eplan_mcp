# Selecting Parts in the Navigators or the Device List

In the device navigator, the bill of materials navigator and the device list you can open the parts selection tool via the context menu.

### Create devices in the device navigator

You can create devices in the device navigator with the parts selection tool.

1. Select the following commands: Tab Devices > Command group Devices > Navigator.
2. Mark an element and select the popup menu item New device.
3. In the Part selection dialog search through the tree structure and select one or more desired parts.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) A new device is created. The device is sorted into the project structure according to the marked element.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts data are stored at the device. In this way, a new device is created through part selection.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Let us assume that you have marked an arbitrary device under the location designation PT1. Now open part selection through the New device function, and select a conctactor. Under PT1, the device K1 is created with all the functions of a contactor.

### Select parts from the Bill of materials navigator

1. Select the following commands: Tab Devices > Command group Devices > Bill of materials.
2. Mark an entry and select the popup menu item Add part or Exchange part.
3. In the Part selection dialog search through the tree structure and select one or more desired parts.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new part is assigned to the marked device. In Exchange part, the old part is replaced, while in Add part existing part references are retained.

### Select parts from the device list

1. Select the following commands: Tab Devices > Command group Devices > Drop-down button Navigator > Device list.
2. Select the Add part popup menu item.
3. In the Part selection dialog search through the tree structure and select one or more desired parts.
4. Click [OK].
5. You store the part-specific data in the dialog Properties.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts data are written into the Device list. A new entry is created for the part to be monitored.

# Registering Add-ons Manually / Automatically

### Register add-on manually

Add-ons are typically registered manually if you have saved an add-on and the appropriate install.xml file in a local directory on your system.

1. Select the following commands: File > Extras > Command group Extensions > Interfaces > Command group Add-ons > Manage.
2. In the Add-ons dialog, click the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button on the toolbar.
3. In the next dialog select the associated install.xml file and click [Open].
4. In the Add-ons dialog select the Registered check box.
5. Confirm your entries.

### Set up automatic add-on registration

You have the option of setting up the automatic registration of add-ons if your administrator has stored an add-on and the appropriate install.xml file in a server directory.

1. Select the following commands: File > Settings > Company > Management > Add-ons.
2. Click ![](../Pictures/Gui/ALL/all_selectdirectory_as.png) next to the File path for automatic add-on registration field.
3. In the Select folder dialog, select the directory where the install.xml is located.
4. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The add-on is registered automatically the next time you start Eplan.

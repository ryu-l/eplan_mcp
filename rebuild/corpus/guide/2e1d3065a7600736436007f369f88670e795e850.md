# Numbering and Functions

The following functions are influenced by device numbering:

- Overview placements
- Functions with single-line representation
- Part placement
- Terminal strips
- Plugs
- Cables.

The following functions are not influenced by device numbering:

- Potentials
- Interruption points
- Connections
- Cable connections
- Automatically generated cables
- Graphical functions
- External functions.

Functions with representation type "Graphic" are not numbered, since they contain no logic or logical information cannot be taken into account. Functions with representation type "External" are never numbered, since they are not taken into account during automatic runs. They are counted as targets, however. If the main function is a function of representation type "Graphic" or "External", the entire device will not be numbered.

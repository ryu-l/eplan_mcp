# Shortcut Keys in the Insert Center

Apart from pure use of the mouse, the Insert center also allows numerous navigation possibilities via the keyboard. The following shortcut keys are available to this purpose:

Navigation in the folder structure:

| Key combination | Meaning |
| --- | --- |
| Arrow key [left] | Switches to the folder of next lower hierarchy level. |
| Arrow key [right] | Switches to the folder of next higher hierarchy level. |
| Arrow key [up] | Switches upwards to the next folder within the same hierarchy level. |
| Arrow key [down] | Switches downwards to the next folder within the same hierarchy level. |
| [Enter] | Switches to the folder of next lower hierarchy level. |

Navigation in the preview:

| Key combination | Meaning |
| --- | --- |
| [Page up] | Jumps in the visible preview area to the next preview tile and selects it. |
| [Page down] | Jumps in the visible preview area to the last preview tile and selects it. |
| [Ctrl] + [Home] | Jumps to the first preview tile in the selected folder and selects it. |
| [Ctrl] + [End] | Jumps to the last preview tile in the selected folder and selects it. |
| Arrow key [left] | Jumps to the preview tile on the left and selects it. |
| Arrow key [right] | Jumps to the preview tile on the right and selects it. |
| Arrow key [up] | Jumps to the preview tile upward and selects it. |
| Arrow key [down] | Jumps to the preview tile downward and selects it. |
| [F] | Defines the object in the selected preview tile as a favorite. |
| [T] | Assigns a tag to the object in the selected preview tile. |
| [V] | Displays the variants of the selected object. |

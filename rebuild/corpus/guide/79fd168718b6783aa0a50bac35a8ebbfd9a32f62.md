# P003012: Color / number assigned twice (for same shields / indexes)

### Cause

#### Possibility 1

You have assigned the same color or number to two cable connections when entering connection colors or numbers.

#### Possibility 2

In the cable you are using shielded connection pairs with identical connection colors, the shields of which have the same name.

#### Possibility 3

The cable contains paired connections, at least two pairs of which are assigned the same color or number and the same index.

### Solution

#### Regarding option 1

Change the duplicated connection colors or numbers. Make sure each cable connection has a clear value assigned to it.

#### Regarding option 2

If you are using shielded connection pairs with identical connection colors in the cable, then assign a unique name for every shield.

#### Regarding option 3

If you are using paired connections in the cable, and you have allocated the same color or number and the same index to at least two connection pairs, then assign unique colors or numbers to every connection pair in the cable, or assign a unique index to every connection pair.

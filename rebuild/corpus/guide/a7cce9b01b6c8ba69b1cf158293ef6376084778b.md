# Dialog Settings: Cable numbering

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- File > Settings > Projects > "Project name" > Devices > Cable (automatic). Next to the Cable numbering field, click [...].
- Tab Connections > Command group Cables > Drop-down button Reassign all > Generate cables automatically. In the Generate cables automatically dialog, click [...] in the Cable numbering group box next to the Settings field.
- You have opened the cable navigator, for example via the following commands: Tab Connections > Command group Cables > Navigator. Select multiple entries with cables and select the Number cable DTs popup menu item. Click [...] in the Settings field of the Number cables dialog.

In this dialog you can change the settings for numbering cables.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

# Dialog Design space export

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

File > Export > Command group Project data > Layout space > Design space

In this dialog you carry out the export of design spaces processed in Eplan Pro Panel to external CAD programs.

Overview of the main dialog elements:

Source:

This field displays the source of the data export. In the case of a complete project this is the project name, in the case of individual layout spaces the complete layout space names are displayed. The entries in this field cannot be modified.

Scheme:

Selection of a scheme or the possibility to edit or create a scheme. The [...] button opens the settings dialog for the STEP export.

Output directory:

This field displays the storage location. The directory is pre-selected that is defined for the data export in the user settings.

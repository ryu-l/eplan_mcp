# Action: ProjectOpen

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| Project | Used project. |
| OpenMode | Determines the editing mode when opening projects (optional). Possible values are: STANDARD: A project opened in this mode can be edited. In multi-user operation, the project can be simultaneously edited by several users. READONLY: Opens the project read-only. EXCLUSIVE: Opens the project only for you. In multi-user operation, other users cannot access such an opened project. |

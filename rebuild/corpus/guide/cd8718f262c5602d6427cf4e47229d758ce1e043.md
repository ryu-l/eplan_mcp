# Interrupting Connections

Autoconnecting can sometimes create unwanted connections in the schematic (e.g., to motor overload switch auxiliary contacts). You can interrupt these connections by inserting a break point between the connection points. A break point is an invisible symbol without connection points that prevents autoconnecting or that interrupts an existing autoconnect line.

Preconditions:

- You have opened a project. You have opened a project page in the graphical editor.
- The page contains autoconnect lines.

1. Select the Insert tab in the ribbon.
2. In the command group Symbols click the ![](../Pictures/Gui/ALL/ribbon_galleryfurther_as.png) (Other) button and below the Connectors field select the button ![](../Pictures/Gui/ALL/ribbon_breakpoint_as.png)(Interrupt connection).
3. Click between the two connection points on the autoconnect line to be interrupted.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The autoconnect line is interrupted, i.e., the connection is deleted.
4. Proceed in a similar way for all additional autoconnect lines that are to be interrupted.
5. End the action via the Cancel action popup menu item or via the [Esc] button.

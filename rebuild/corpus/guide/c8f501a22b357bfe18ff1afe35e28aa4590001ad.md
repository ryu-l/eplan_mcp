# Form Functions

In addition to the text, there are two types of graphics in the report lists:

- Generated graphics
- Symbol graphics.

### Generated graphics

Generated graphics only occur as jumper graphics in the following reports:

- Terminal diagram
- Terminal line-up diagram
- Terminal connection diagram.

The graphics in the connection diagram are generated in the following manner: In the form, particular placeholder texts are placed at the positions where the base of the "jumper legs" should be located. In these placeholder texts the properties Graphic for saddle jumpers, Graphic for external saddle jumpers, etc. are selected for the placeholder element "Terminal". During the report run, special terminal properties are placed at these points, which contain the jumper information among other values. In a subsequent run, exactly this text is replaced by the suitable jumper graphic. The exact representation of the graphic is determined by the properties in the placeholder texts and some form properties.

For the output of Saddle jumper slots the properties Graphic for saddle jumper slot 3 to Graphic for saddle jumper slot 5 are available in the respective forms for the placeholder element "Terminal". For saddle jumper slot 1, the property Graphic for internal saddle jumpers is used and for saddle jumper slot 2 the property Graphic for external saddle jumpers.

### Symbol graphics

Symbol graphics can be used in any diagram, whereby particular placeholders are not replaced with text during the report run, but rather with symbol graphics in the form of graphical symbols or item references (Symbol graphic property, (ID 13049)). The symbol graphic is always obtained from the indirectly referenced object, i.e. exactly the same graphic as in the item is used.

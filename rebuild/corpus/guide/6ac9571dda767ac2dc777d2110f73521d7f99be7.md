# Exporting Piping

After the free routing and customizing of a piping the next step is to transfer this piping to the manufacturing and to bend it with a pipe bending machine. Eplan generates an XML file with the required data per piping for the transfer to the software of the pipe bending machine.

The sawing length and the bending data of a pipe are calculated with the software of the pipe bending machine. Subsequently the manufacturing data for pipe bending are transferred from the software to a pipe bending machine.

Precondition:

You have opened a project that contains layout spaces with freely routed pipings.

1. Mark one or more pipings for which manufacturing data are to be generated in the connections navigator or in the layout space.
2. Select the following commands: File > Export > Command group Manufacturing data > Machining >   
   Pipe bending.
3. In the Export pipe bending dialog, select a machine definition, an output directory, and a target file.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The target file is generated in the specified directory. The file can now be transferred to the machine.

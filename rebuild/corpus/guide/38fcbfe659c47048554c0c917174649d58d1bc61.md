# Extensions for Subordinate Segment Templates

The segment templates defined in the project are displayed in the segment template navigator and can be edited. The Subordinate segment templates table in the Segment templates tab of the property dialog of segment templates is available for the creation of nested segment templates - i.e. segment templates with subordinate segment templates. The following extensions have been implemented for subordinate segment templates:

For this version the following extensions have been realized for the automated processing of projects:   
- Multiple selection in the "Select segment templates" dialog  
- Search field for the selection of subordinate segment templates  
- Configure representation of the tables for subordinate segment templates  
- Assign subordinate segment templates to several segment templates simultaneously

### Multiple selection in the "Select segment templates" dialog

If subordinate segment templates are assigned for a segment template in the Segment templates tab, multiple selection of these subordinate segment templates is now possible in the subsequent dialog Select segment template during the selection.

### Search field for the selection of subordinate segment templates

The available matching segment templates are displayed in the left-hand section of the Select segment template dialog. In order to maintain an overview even in the case extensive selection lists (for example in building automation), you can now limit the number of the segment templates displayed here by using the newly added field Find. Both the names of the displayed templates as well as the description are searched.

### Configure representation of the tables for subordinate segment templates

In the dialogs for segment templates the tables for subordinate segment templates now include the Configure representation popup menu item. This applies both for the table in the property dialog of a segment template in the Segment templates tab and for the table in the Select segment templates dialog. This allows you to add further columns for relevant properties to the tables and customize the order of the columns as you wish. Different configurations can be selected for the two dialogs in the process.

### Assign subordinate segment templates to several segment templates simultaneously

You can select several segment templates simultaneously in the segment template navigator. If the property dialog is then opened (for example for PCT loops), it was previously not possible to carry out a change for the Subordinate segment templates table in the case of multiple selection. If you have now selected segment templates that have the same subordinate segment templates, you can, for example, use Block editing to select subordinate segment templates simultaneously for all selected segment templates or delete selected subordinate segment templates again.

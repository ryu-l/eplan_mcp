# Tab Properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Tab Home > Command group Page > Navigator. Select a project. Select the following commands: File > Information > Command group Project properties > Properties.
- You have opened a project. Tab Home > Command group Page > Navigator. Select a project. Select the Properties popup menu item. In the Backstage view Information select the command Properties.
- You have selected a project management database. You have loaded directories and projects. File > Project management. Select a project. Select the Properties tab.

The current project properties of the selected project are displayed in this tab.

Overview of the main dialog elements:

The project name of the current project is displayed on top and the associated storage location is displayed below. The ![](../Pictures/Gui/ALL/prjmanagementgui_rename_as.png) (Rename project) button offers you the option of renaming the project.

The ![](../Pictures/Gui/ALL/all_copy_as.png) (Copy) button next to the project name and the storage location allows you to copy the project name or the file path of the storage location to the clipboard. And the ![](../Pictures/Gui/ALL/all_fileopen_as.png) (Open) button allows you to open the file path of the storage location in Windows Explorer.

Category:

The view of the properties in the Property name column is filtered according to the category set in this drop-down list. The view of the properties is also filtered, which you can select using ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the Property selection dialog.

Toolbar:

| Button | Meaning |
| --- | --- |
| (New) | Opens the Property selection dialog. Allows a property to be selected. |
| (Delete) | Deletes one or more selected properties. |

Property name:

The project properties of the selected project are displayed in this column.

Value:

The values of these project properties are displayed and can be edited in this column. To do this you must first use the [Edit] button to activate the edit mode within the project management.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# Tabs Multi-line / Single-line (Settings: Cable (Cable connections))

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. File > Settings > Projects > "Project name" > Devices > Cable (Cable connections). Select the Multi-line or Single-line tab.

In the tabs, you specify the default settings for the symbols that are to be shown on the connection definition points for cable definition lines and shields. These settings can be made separately for multi-line and single-line representation types.

Overview of the main dialog elements:

Group boxes Symbol (graphic) for connection definition points on cable definition line / in shield

The symbol defined in the Symbol (graphic) for connection definition points on cable definition line group box is used for connection definition points that are placed when drawing cable definition lines or during automatic cable generation.

The symbol defined in the Symbol (graphic) for connection definition points in shield group box is used for connection definition points that are placed when drawing shields.

Number / name:

This field displays the name and number of the current symbol. Click [...] to open the [Symbol selection](xsbgui_d_symbolauswahl.htm) dialog and select a different symbol if necessary.

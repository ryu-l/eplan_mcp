# Restoring Deleted Revision Markers

Preconditions:

- You have already executed a comparison run, so that changed information is present in the revision results list.
- You have deleted revision markers from the project.
- The project into which you would like to write the revision markers is open.

1. Select the following commands: File > Revision control > Command group Project > Property comparison > Add revision markers.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan writes the revision markers into the project.

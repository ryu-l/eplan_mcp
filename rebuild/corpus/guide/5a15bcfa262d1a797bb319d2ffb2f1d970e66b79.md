# Printing pages

You can print single pages or all pages of a project. You have the option of changing the output of the project pages by using the print settings.

Preconditions:

- You have selected the desired number of pages (or the project) in the page navigator in the tree or list view.
- You have opened a page in the graphical editor.

1. Select the following commands: File > Print.
2. Select the desired printer from the drop-down list in the Printer group box of the Print backstage view.
3. In the Pages group box, you can determine whether you would like to print the currently selected pages or all of the pages in the current project.   
   If you have opened a page in the graphical editor and if it has the focus, you can print either the page currently in the foreground or all of the project pages.
4. Use [Settings] to open the Settings: Print dialog in order to change the other settings there.
5. In the Copies group box enter the number of copies and the collating order.
6. In the print preview you have the option of checking the results of your settings before printing. Browse through the pages selected for printing by means of the entry field below the print preview.
7. Click ![](../Pictures/Gui/ALL/btn_print_as.png) (Print).  
     
   ![](../Pictures/Gui/ALL/arrow.png) Printing begins.

![](../Pictures/Gui/ALL/note.png)Note:

You can work on a different project while printing is going on in the background. Just start multiple copies of Eplan.

![](../Pictures/Gui/ALL/info.png)Tip:

When printing pages, if you wish to output only the current pages of an active page filter, select the project in the page navigator and in the Print dialog activate the Selection option.

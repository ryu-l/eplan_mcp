# Dialog Clipboard

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have deactivated the Do not show description dialog check box in the user settings (command path: File > Settings > User > Display > General). You have opened a project. In addition, you have selected at least one object on a project page or at least one page in the page navigator.

- Tab Home > Command group Clipboard > Copy. The Clipboard dialog can also be called for selected objects via the following commands: Tab Edit > Command group Clipboard > Cut.
- Popup menu item Copy.

In this dialog you enter a description for the element to be copied.

Overview of the main dialog elements:

Description:

In this field you enter a description for the object or page you want to save in the Clipboard. If you want to insert the object or page, this description is displayed in the Paste dialog in the Description column.

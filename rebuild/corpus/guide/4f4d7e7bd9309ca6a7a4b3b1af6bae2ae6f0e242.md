# Tab AutoCorrect

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Tools > Command group Translation > Dictionary. Select the AutoCorrect tab.

In this tab you can manage a list of words that are not to be used in project pages and are automatically replaced. Enter a replacement text for each word that is not to be used. This makes it possible to guarantee the uniform usage of words.

If the User tab in the translation settings has the AutoCorrect check box selected, the unwanted words of the source language are replaced with the replacement texts during entry. The unwanted words for the other display languages are not replaced.

Overview of the main dialog elements:

Find:

Use this field to search for all of the keywords that have already been added to the list of words that are to be used in the AutoCorrect. To search for a keyword, enter it in the input field. To show all replacement texts for a keyword, select the desired keyword in the keyword list. The keyword is displayed in the Replace field. The replacement text is displayed in the By field.

Replace:

In this field you edit the keyword that you would like to replace. Use the toolbar to create, save, copy and delete a keyword for the AutoCorrect function.

# Generating Revisions

Preconditions:

- You have opened a standard project (file extension \*.elk) or a revision project (file extension \*.ell).
- You have completed all pages of the revision project.

1. Select the following commands: File > Revision control > Command group Modifications > Change tracking > Generate revision.
2. Enter a name and optionally a comment text for the revision in the corresponding fields in the [Generate revision](revisionlogmgtgui_d_revisionerzeugen.htm) dialog.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan generates the revision under the specified name.   
     
   ![](../Pictures/Gui/ALL/arrow.png) If you generate a revision for a standard project, the project becomes a revision project, that is, the file extension changes from \*.elk to\*.ell.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If a page is then modified, it is marked as a "draft".

![](../Pictures/Gui/ALL/info.png)Tip:

If you have selected the Generate reference project when new revision of completed project is created check box in the project settings (File > Settings > Projects > "Project name" > Management > Revision (change tracking)), a reference project (i.e. a write-protected copy of the project) is also generated when you generate a new revision of a completed project.

### Generating a revision for a defined working section

![](../Pictures/Gui/ALL/note.png)Note:

In order for a revision to be generated for a defined working section the project itself may not be revisioned. However, it is conversely possible to generate a project-wide revision if the project already contains revisioned defined working sections.

Preconditions:

- You have opened a standard project (file extension \*.elk).
- You have selected and activated a defined working section that does not overlap another defined working section.
- You have completed a defined working section.

1. Select the following commands: File > Revision control > Command group Modifications > Change tracking > Generate revision.
2. Enter a name and optionally a comment text for the revision in the corresponding fields in the [Generate revision](revisionlogmgtgui_d_revisionerzeugen.htm) dialog.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan generates the revision under the specified name.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The revision is assigned to the current defined working section.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project becomes a revision project, meaning that the file extension is changed from \*.elk to \*.ell.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If a page is then modified, it is marked as a "draft".

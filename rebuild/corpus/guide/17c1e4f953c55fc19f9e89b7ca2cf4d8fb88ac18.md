# Dialog Numbering (offline): Preview of result

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have selected one or more pages in the page navigator. Or you have selected one or more devices in the Device navigator. Tab Devices > Command group Devices > Number. In the [Number (offline)](offlinenumerationgui_d_nummerieren.htm) dialog, select the Preview of result check box. Click [OK].

In this dialog, a preview of the numbering results is provided. All numbered main and auxiliary functions are displayed which contain a displayed DT. Functions that contain no displayed DT, but rather accept one from elsewhere, are not listed here. You can manually change the device numbering here. If you assign a different DT to a numbering function, you can also change the cross-reference.

Overview of the main dialog elements:

Preview of result:

In this table, there is a row for each numbered function. The following columns are fixed:

- Error: If an error occurs in the device numbering, a cell in this column is highlighted in red. If the field is selected, the error status is printed in the Message description field.
- Name (identifying): Provides the identifying name of the function.
- All connection point designations: Shows the connection point designations of the function.
- New DT: Shows how the DT looks after numbering. You can change the DT in this column. New DTs that deviate from the current value are highlighted by a yellow background.
- Function text (automatic): Outputs the function text.
- Placement: Specifies the page on which the function is placed.

Other columns can be added in the popup menu with Configure representation.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Use original DT | Assigns a device its original identifier again after renumbering. |

Message description:

A message is printed for each selected line in which an error occurred. You can ignore the error or correct it.

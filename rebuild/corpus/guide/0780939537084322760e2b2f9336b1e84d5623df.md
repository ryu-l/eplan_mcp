# Dialog "<Identifier block> (<Project name>)" / Dialog "Object identifier"

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call <Identifier block> (<Project name>):](javascript:void(0);)

You have opened a project.

- You have opened the property dialog for a function. You have clicked [...] in the Full DT field of the <Function category> tab. You have clicked [...] in a field of the Visible column of the Structure identifier table in the dialog Full DT.
- You have opened the Page properties dialog for a page. You have clicked [...] in the Full page name field, and in the subsequent dialog have clicked [...] in the Value field of a structure identifier.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call Object identifier:](javascript:void(0);)

You have opened a project for which the object identifier for structuring the pages was selected (dialog Page structure in the project properties). You have opened the Page properties dialog for a page. You have clicked [...] in the Full page name field, and in the subsequent dialog have clicked [...] in the Value field of the "Object identifier" structure identifier.

In this dialog you select a structure identifier that has already been defined for the respective identifier block in the project, or you select the structure identifier that is to be used as the object identifier.

Overview of the main dialog elements:

The structure identifiers with their structure description which were already defined in the project for the respective identifier block are displayed in the tree and in the list views. In the dialog Object identifier the identifier blocks already existing in the project are furthermore displayed in the left-hand section of the dialog.

Filter:

This drop-down list displays all the available filters. A selected filter is automatically activated and is applied to both the tree and the list view. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the [Filter](modaldialogsdb_d_filternnach.htm) dialog. Here you can create, edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

- Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
- Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

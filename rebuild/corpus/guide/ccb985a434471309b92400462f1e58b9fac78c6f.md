# Tab Manufacturer

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > User > Add-ons > Hose line configurator. Click the Manufacturer tab.
- You have opened a project. You have opened the [Configure hose lines](fluidhoseconfiggui_d_schlauchleitungen.htm) dialog. Select the Extras > Settings menu items. Click the Manufacturer tab in the subsequent dialog.

You manage the names of hose line manufacturers in this tab. The information entered in the table is offered for selection when the hose lines are configured in the Edit <...> dialog.

Overview of the main dialog elements:

Table:

The table offers the possibility to enter the manufacturer names in the form of a short name and a long name.

In both columns you can use the [...] buttons available in the table cells to access the manufacturer names stored in the parts management.

Use the buttons of the toolbar above the table to create new entries and / or delete entries no longer required.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

![](../Pictures/Gui/ALL/note.png)Note:

If you select the default scheme DIN 20066\_2012-01, the list is filled with the names of renowned hose line manufacturers.

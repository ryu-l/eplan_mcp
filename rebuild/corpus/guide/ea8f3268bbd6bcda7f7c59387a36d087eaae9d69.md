# Management of Routing Connections

The Wiring manager dialog allows you to manage routing connections. This dialog is the central point for retaining an overview of the connections within a layout space and for routing these connections and exporting them for wire fabrication. For the sake of clarity, saddle jumpers and other connection types that are not relevant for routing in the layout space are deliberately not displayed. In addition, no distinction is made between the representation types of the connections for better clarity. This way only the connections relevant for routing and wiring are displayed in the dialog.

The following is possible:

Display in dialog

- The dialog reacts to the selection in the layout space navigator, in the 3D mounting layout navigator, in the connections navigator, etc. For example, if you select a layout space and start the Wiring manager dialog, all connections running within the layout space are displayed.
- All connections whose function definitions are taken into consideration during routing and whose source and target are located as part placements in the same layout space are displayed.
- No connections across layout spaces are displayed.
- The routing- and wiring-relevant status is displayed for each connection. Possible values are "Not routed", "Routed", "Non-routable", "Protected", "Exported", and "Non-exportable". The list of connections can be filtered by the status.
- The dialog can also be used to display the connection properties and the current status of the connections. Every change to the connection outside the dialog is displayed directly in the dialog.

Editing the connections

- The connection properties can be changed for all selected connections in the Properties (global) mode.
- The different representation types in the navigators can be marked for the selected connections by using the Synchronize selection command of the ribbon (tab Home > Command group Find).
- It is possible to jump to the 2D and 3D representation types of the connection or source and target for the selected connections.

Routing the connections

- The connections selected in the dialog can be routed directly from the dialog.
- If a connection could not be routed, the message text of the first message occurring for the connection is displayed.
- The routing connections (3D connections) selected in the dialog can be deleted directly from the dialog.
- You can edit the filtered list of connections that can be routed (but have not yet been routed) until all the relevant connections have been routed and the list is therefore empty.

Exporting for wire fabrication

- The connections marked in the dialog can be exported for the wire fabrication (command path: File > Export > Command group Manufacturing data > Wire fabrication). After the export the status for the connections is updated and displayed in the dialog.
- The list of connections can be filtered by layout space and enclosure via the selection in the layout space navigator. This way you can edit each enclosure individually and already enter the wiring data into the manufacturing process while you are editing the next enclosures. You can carry out this procedure consecutively for all layout spaces located in the project.
- If messages have occurred during the export, the message text of the first message occurring for the connection is displayed. The check run P026072 must be activated so that the required settings for wire fabrication data are checked during the export and the associated messages are displayed in the wiring manager.

# Tab User-defined properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Tab Master data > Command group Parts > Management. You have marked a part in the tree or list. Select the User-defined properties tab.

In this tab you assign user-defined properties that you previously created and configured for the parts management in the [Configuration dialog](eservicesgui_d_konfigeigenschaften.htm) to a part. These properties are only assigned to the respectively selected variant of a part.

Overview of the main dialog elements:

Scheme:

Choose the scheme that you would like to use from the drop-down list. Or click [...] to edit an existing scheme or create a scheme using the Configure properties dialog.

![](../Pictures/Gui/ALL/note.png)Note:

The schemes for assigning user-defined properties are managed user-specifically. This has the effect that in multi-user operation - meaning when several users access the same parts database - the modifications to such a scheme are not automatically synchronized, i.e. displayed to another user. In multi-user operation we recommend managing these schemes centrally and making the schemes available to other users by exporting and importing in the dialog Configure properties. The same behavior also applies analogously for the schemes for assigning free properties.

[Assign scheme]:

With this button the user-defined properties stored in the scheme are entered into the tab. If properties were already assigned, the user-defined properties from the scheme are attached. If a property was already selected and is available in the scheme, its values are not changed during assignment.

If a previously assigned scheme is deleted, the user-defined properties of this scheme remain assigned to the part.

Table

The user-defined properties that are assigned to a part are displayed in the table.

You can freely select individual user-defined properties for a part via ![](../Pictures/Gui/ALL/all_new_as.png) (New) or assign a predefined set of user-defined properties via [Assign scheme].

During a later part or device selection these user-defined properties are transferred with the values to the respective main function.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Configure properties | Only available for user-defined properties without definition. Such a case can, for example, occur when you import parts from Version 2.9 with assigned user-defined properties or schemes for the user-defined properties.  The popup menu item offers the possibility to branch to the Configure properties dialog and configure this property there. This dialog is directly preset with sensible values. Subsequently you can edit the user-defined property in the User-defined properties tab. |

![](../Pictures/Gui/ALL/info.png)Tip:

The check run 502035 in the message class 502 "Part master data" is available to find parts in the parts management that have user-defined properties without an assigned definition.

[Free properties]:

Click this button to open the dialog [Free properties](articlesgui_d_freieeigenschaften.htm).

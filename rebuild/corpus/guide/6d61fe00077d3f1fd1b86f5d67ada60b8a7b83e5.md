# P025001: The value of the 'Grid' page property (Page <x>) does not match the 'Grid for page type' project setting

### Cause

The Grid page property value of the named page differs from the Grid for page type project setting. For instance, a grid of 4 mm was set for all electrical engineering schematic pages in your project ("Schematic multi-line" and "Schematic single-line"). However, the Grid page property value was changed to 2 mm subsequently for the specified schematic page.

### Solution

1. Adapt the value of the Grid page property for the specified page to the Grid for page type project setting, or vice versa.
2. If required, start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

The Grid page property is called up by marking the page in the page navigator and selecting the Properties popup menu. The Grid for page type project setting is accessed by selecting the commands: File > Settings > Projects > "Project name" > Management > Pages.

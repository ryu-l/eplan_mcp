# P026078: Bundle diameter too small; connections cannot be bundled with the selected part

### Cause

The total diameter of all routing connections that are to be bundled using the placed cable / tubing protection or cable / tubing tie is smaller than the minimum bundle diameter of the cable / tubing protection or cable / tubing tie used.

### Solution

1. Locate the cable / tubing protection or cable / tubing tie in the layout space using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Call the property dialog of the cable / tubing protection or cable / tubing tie, and bring to front the Part tab.
3. Via the parts used, navigate to the part selection, and bring to front the Routing accessories data tab.
4. Check at the part used the value set in the Minimum bundle diameter field.
5. Select a cable / tubing protection or cable / tubing tie whose minimum bundle diameter is smaller than the total diameter of all routing connections in the bundle.
6. Close the part selection and the property dialog by clicking [OK] respectively.
7. If required, start a new check run.

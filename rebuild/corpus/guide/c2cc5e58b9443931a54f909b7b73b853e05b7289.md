# Editing Dimensions

Preconditions:

- You have opened a project.
- You have opened a project page in the graphical editor.
- You have added a dimension.

1. Double-click the dimension or mark the dimension and select the popup menu item Properties.
2. In the Properties dialog select the Dimensioning tab and edit the display properties and dimension values, if necessary.
3. Select the Format tab and edit the dimension value display properties.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The settings are saved and the dimension is displayed correspondingly.

### Move dimensions / dimension elements

1. Click a dimension, for example on the dimension line.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The elements associated with the dimension (the dimension values, dimension lines, etc.) are highlighted.
2. Move the dimension with the mouse.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All the elements are moved together.
3. Select the insertion point of a dimension value and move it with the mouse.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Only the dimension value is moved.
4. Select the outer handle of a dimension help line and move it with the mouse.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The dimension is shrunk or expanded and the dimension value is updated.
5. Select the inner handle of a dimension help line and move it with the mouse.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The length of the dimension help line changes.

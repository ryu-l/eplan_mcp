# Tab File

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. File > Export > Command group Manufacturing data > Manufacturing data > Labeling. Click [...] next to the Settings field in the dialog Export manufacturing data / output labeling. In the dialog Settings: Manufacturing data export / labeling select the File tab.
- File > Settings > User > Interfaces > Manufacturing data export / Labeling. In the dialog Settings: Manufacturing data export / labeling select the File tab.

In this tab you can specify the settings for the file formats in which the export / labeling file can be output.

Overview of the main dialog elements:

File type:

This field contains the file type in which the data are output.

- Text file (\*.txt): The data are output as a txt file.
- Excel file (\*.xlsx, \*.xlsm): The data are output as an MS Excel file in the following format:   
  \*.xlsx: Format for Microsoft Excel without macros  
  \*.xlsm: Format for Microsoft Excel with macros   
  In the Template field, you can specify an Excel form.
- XML file (\*.xml): The data are output as an xml file.

Target file:

Enter the file path for the storage location and the file name of the export / labeling file.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

Template:

If you have selected an Excel file as the export / labeling file in the File type field , enter an [Excel form as a template](labelgui_k_excelexportvorlagen.htm) in this field. The data are output in this form.

[Options]:

Depending on the file type selected, use this button to open the dialog Settings: Text export or the dialog Settings: Excel export.

# Creating Links in Pre-Planning

Links can be used in the tree of the pre-planning navigator to reference existing segments in other structures.

Precondition:

You have opened a project with existing structure segments and planning objects.

1. Select the following commands: Tab Pre-planning > Command group General > Navigator.
2. Mark the segment that you want to link in the tree of the pre-planning navigator and select the popup menu item Copy.
3. Mark the segment for which you want to insert a link in the tree and select the popup menu item Insert link.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The link inserted below the marked segment is identified by a blue arrow (icon: ![](../Pictures/Gui/ALL/planninggui_link_as.png)).

Multiple selection is possible when copying and pasting links.

![](../Pictures/Gui/ALL/info.png)Tip:

You can also create links to segments simply by means of Drag & Drop by dragging one or more marked segments to a desired position and by pressing the shortcut key [Ctrl] + [Shift] while dragging.

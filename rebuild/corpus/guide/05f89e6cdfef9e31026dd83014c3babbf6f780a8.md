# Dialog Settings: PDF output size

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have selected a project or at least one project page. File > Export > Command group Project data > Project data > Command group Page > PDF. Click the [Settings] button and select the menu item Output size.
- File > Settings > Workstation > Graphical editing > PDF output size.

In this dialog, you specify the output size for the project pages output to the PDF file.

Overview of the main dialog elements:

Original size:

If this option has been selected, the project pages are output in the paper format that has been set via the plot frame in use. This is the default setting.

Scale to page:

If this option has been selected, the project pages are scaled to the selected paper format and output to the PDF file. The page aspect ratios are retained during scaling. The project pages are not rotated.

The dimensions of the selected paper format are displayed in the Width and Height fields. Whether the dimensions are displayed in mm or inches depends on the displayed unit of length set in the user settings. You can overwrite these values manually. Using the [...] button next to the Width field, open the [Select paper format](pdfexportgui_d_auswahlausgabeformat.htm) dialog; here then you can select another paper format from the drop-down list.

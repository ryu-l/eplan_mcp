# Tab General (Export Drilling Template)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- File > Settings > Company > Machining > Export drilling template. Select the General tab.
- File > Export > Command group Manufacturing data > Machining > Drilling template. Click [...] next to the Machine field. Select the General tab.

In this tab you define the general settings for the export of drilling templates.

Overview of the main dialog elements:

Group box Edges

In this group box, you set the minimum distance of the drilling pattern geometry from the edge of the template surface in the fields Top / Left / Right / Bottom.

---

Output directory:

The drilling template is generated as a PDF file. Enter the storage location in this field. You can specify any drive and subdirectory as the target for the export.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

Generate file names:

In this drop-down list you specify the default method for allocating names when exporting PDF files:

- From consecutive number: If you select this option, Eplan assigns names to the PDF files using the pattern <Consecutive number>.PDF by default. If PDF files already exist, Eplan starts the numbering with the next available number.
- From item designation: If you select this option, Eplan assigns names to the PDF files using the pattern <Item designation>.PDF by default.
- From properties: If you select this option, the file name is made up of the layout space, project, and device properties plus any freely-definable separators. Use the [...] button to open the Format: Property dialog to configure the file name.

Generate subdirectories:

In this drop-down list you specify the default method for generating subdirectories when exporting PDF files:

- None: If you select this option, no subdirectories are generated during the export.
- From project structure: If you select this option, subdirectories that reflect the project structure are automatically generated during the export.
- From properties: If you select this option, the substructure name is compiled from the layout space, project and device properties as well as freely-definable separators or directory separators. Use the [...] button to open the Format: Property dialog to configure the directory name. Here you can use the "directory separator" format element, for example, to generate a directory structure with multiple subdirectories arranged one below the other.

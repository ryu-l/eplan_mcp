# Dialog Export property arrangements

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have inserted a symbol in the graphical editor or generated a new function in a navigator.
- You have selected a function in the graphical editor or in a navigator. Popup menu item Properties.

In the Properties <...> dialog, select the Display tab. You have created at least one user-defined property arrangement and saved it under a specific name. Click ![](../Pictures/Gui/ALL/all_export_as.png) (Export) in the toolbar above the drop-down list.

In this dialog, you export the saved, user-defined property arrangements for a specific symbol variant.

Overview of the main dialog elements:

Available property arrangements:

In this field, you will see the saved, user-defined property arrangements of the symbol variants selected in the Properties <...> dialog. Select the check boxes for the property arrangements you would like to export.

Target file:

In this field, enter the file path and the file name of the export file. The export file has the file extension \*.emc.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

![](../Pictures/Gui/ALL/note.png)Note:

When exporting user-defined property arrangements for a specific symbol variant, and when executing a project-wide export of user-defined property arrangements via the dialog [Configure property arrangements](eservicesgui_d_konfigeigenschaftsanordnungen.htm), the export files are saved by default in the same directory ($(EPLAN\_DATA)\Xml\<Company code>) with the file extension \*.emc. Use different file names in order to differentiate between the generated files.

# Defining Multi-level Terminals

### Defining multi-level terminals with program support

Preconditions:

- You have selected a terminal or a terminal strip definition in the terminal strip navigator, the device navigator or the graphical editor.
- You have opened the Edit terminal strip dialog (command path: Tab Devices > Command group Terminals > Terminal strip).

#### Generate individual multi-level terminal

1. Mark the desired terminals in the Edit terminal strip dialog.
2. Select the button ![](../Pictures/Gui/ALL/terminalgui_createmulti_as.png) (Generate multi-level terminal).  
     
   ![](../Pictures/Gui/ALL/arrow.png) All selected terminals are combined to a single multi-level terminal.

#### Generating multiple multi-level terminals

1. Mark the desired terminals in the Edit terminal strip dialog.
2. Select the button ![](../Pictures/Gui/ALL/terminalgui_createmulti2_as.png) (Generate multi-level terminals).
3. Specify the number of levels in the subsequent dialog.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The marked terminals are each combined to multi-level terminals with a fixed number of levels.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You have marked eight terminals in the Edit terminal strip dialog.

Case 1: You select the button ![](../Pictures/Gui/ALL/terminalgui_createmulti_as.png). A multi-level terminal with eight levels is generated.

Case 2: You select the button ![](../Pictures/Gui/ALL/terminalgui_createmulti2_as.png). In the subsequent dialog you enter the value 3 for the number of levels. Two multi-level terminals with three levels each are generated. Two terminals remain and are not combined.

For every generated multi-level terminal, the levels are assigned automatically in descending order. The terminal with the highest level becomes the main terminal, all other terminals become auxiliary terminals.

If the main terminal of a generated multi-level terminal was already a main terminal before the merger and has a part, the function templates of the part are overlapped by the terminals. The assignment of the individual levels results from the function templates.

![](../Pictures/Gui/ALL/info.png)Tips:

- You can use the ![](../Pictures/Gui/ALL/terminalgui_separatemulti_as.png) (Disconnect multi-level terminals) button to remove one or more marked terminals from the multi-level terminal.
- You can also combine selected terminals into a multi-level terminal in the graphical editor or the terminal strip navigator. To do this select the following commands: Tab Devices > Command group Terminals > Drop-down button Extras > Generate multi-level terminal. The graphically first terminal (in accordance with the sequence in the schematic or in the terminal strip navigator) becomes the main terminal.

### Defining multi-level terminals manually

Precondition:

You have selected one terminal in the terminal strip navigator, the device navigator, or the graphical editor.

1. Select the Properties popup menu item.
2. In the Properties <...> dialog, select the Terminal tab.
3. Enter the desired value in the Level field.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A value > 0 defines the terminal as a multi-level terminal; the value "0" defines the terminal as a "simple" terminal. The levels can be sorted in ascending or descending order. In the case of ascending order the lowest level in the terminal housing is level number "1".
4. Enter a value in the Terminal: Device position property. All the terminals that belong to the same multi-level terminal, must also have the same value for the device position.
5. Use the Sort code (terminal / pin) property to specify the sequence within the multi-level terminal.
6. Deselect the Main terminal check box if you want the terminal to be managed as a secondary terminal. (The main terminal can be the terminal with the lowest or the highest level.)
7. Click [OK].
8. Repeat the previous steps for the further terminals that are to become part of the multi-level terminal.

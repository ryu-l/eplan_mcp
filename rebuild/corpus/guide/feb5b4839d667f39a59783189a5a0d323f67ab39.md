# Reporting of Device Connection Points

As with all "normal" functions, device connection points also have a DT, a connection point designation, connection point description, and other properties. As with all other (normal) functions, it is also possible to enter the connection point designation into the Displayed DT field of the Properties dialog for device connection points.

If, for example, you enter -H4 here, the program interprets this entry as a device tag without connection point designation. However, if you change your entry to -H4:1, the string behind the (first) ":"-character (in the example 1) is transferred to the Connection point designation field.

![](../Pictures/Gui/ALL/note.png)Note:

The full DT contains no connection point designation.

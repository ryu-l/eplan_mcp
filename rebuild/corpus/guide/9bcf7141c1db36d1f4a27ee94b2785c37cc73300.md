# Adopting the Connection Colors/Numbers of Cable Connections as Bundle Connection Point Designations

By means of the Overwrite bundle connection points menu item you can overwrite the bundle connection point designations of cable connections with the connection colors or numbers of the cable. For very long bundles, which often lead over several pages via interruption points, this allows the connection designations to be read at the bundle entry and exit points of the cable. When searching for errors in the schematic, this makes it much easier to follow a bundled cable connection between the cable target and the cable source.

Preconditions:

- You have opened a project.
- The project contains a multi-line schematic page with a cable connection represented as a bundle - as shown in the following example. In the multi-line representation area, the cable definition lines run between the cable source and the bundle connection point symbols at the entry to the bundle. The connection definition points of the cable show color or number information.
- The schematic page is opened in the graphical editor.  
    
  ![](../Pictures/Visualisation/ALL/singlepole_stranganschluss_kabel1_av.png)

1. Select the cable definition line.
2. Select the following commands: Tab Connections > Command group Cables > Drop-down button Edit > Overwrite bundle connection points.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The bundle connection point designations 1, 2, 3 and 4 at both ends of the bundle are replaced with the connection colors BK, BU, BN and GNYE of the cable.  
     
   ![](../Pictures/Visualisation/ALL/singlepole_stranganschluss_kabel2_av.png)

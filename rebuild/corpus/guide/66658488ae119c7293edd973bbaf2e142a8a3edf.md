# Updating Connections

The properties of connections are defined at various locations: in the project settings, at potential connections, potential definition points and connection definition points. Connection data is not immediately automatically updated after changes. You can manually update them if you need to.

![](../Pictures/Gui/ALL/note.png)Note:

Whether the connections are up to date can be checked at the right-hand corner of the status bar: If a "#" sign is displayed there, the project contains out-of-date connections. If the "\*" sign is displayed, the open page has out-of-date connections.

By default the check box Update connections when switching pages is activated in the user settings (File > Settings > User > Display > General). This means that the connections are updated automatically during editing in the graphical editor. The connections are updated within the edited page after every editing step. During a page change the connections are updated both on the opened pages and on those pages to which the connections lead through interruption points.

### Update connections manually

The behavior when manually updating the connections is controlled by a user setting: By default the check box Update connections throughout the project (manually) is activated in the user settings (File > Settings > User > Display > General). This will update the connections throughout the entire project, independent of the current selection.

If the check box is deactivated, the connections will be updated only for the current selection. If you selected one or more pages, only the connections on those pages will be updated. If you selected functions in the graphical editor (or in a navigator), the connection update will take place only for those pages that contain functions for the associated devices, as well as unplaced connections of the device.

Precondition:

You have opened a page in the graphical editor or have selected pages or a project in the page navigator. You have selected functions in the graphical editor or in one of the navigators.

1. Select the following commands: Tab Connections > Command group Connections > Update  
     
   ![](../Pictures/Gui/ALL/arrow.png) Eplan updates the connections either in the entire project or in the current selection, depending on the user setting. This means that new connections are generated, if required, and changes of existing connections are updated.

![](../Pictures/Gui/ALL/info.png)Tip:

If you hold down [Shift] while carrying out the Update command all the connections of the project are generated again. In doing so, changes to the connection properties defined in the project settings are also adopted. This process can take some time for larger projects.

### Delete connections

Connections are automatically deleted if you move a component in the schematic and its connection points can no longer find its counterpart. Any existing connection definition points remain.

Unplaced connections can be deleted in the Connections - <Project name> dialog:

1. Select the following commands: Tab Connections > Command group Connections > Navigator.
2. In the Connections - <Project name> dialog, select the unplaced connections you want to delete.
3. Select the Delete popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) After a confirmation prompt, the connections in question are deleted.

# P026040: Connection / Cable without valid diameter (<x>)

### Cause

During the calculation of the fill capacity for wire ducts Eplan determined that there is a missing diameter entry for a used individual connection or a used cable.

The diameter is invalid if there is either no diameter entry at all or if the value for the diameter is outside an area between 0 and 500 mm.

### Solution

1. Enter a valid diameter for the individual connection or cable.
2. Update the fill capacity again. (Command path: Tab Edit > Command group Routing connections > Drop-down button Generate routing path network > Update fill capacity.)

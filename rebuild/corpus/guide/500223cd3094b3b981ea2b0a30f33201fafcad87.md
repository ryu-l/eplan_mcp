# Extensions for Reports for the Building Automation

The following extensions have been realized for this version for the reports for building automation:   
- Planning object overview extended by the "Cable planning object" format element  
- Output segments in accordance with the sorting in the pre-planning navigator in function lists

### Planning object overview extended by the "Cable planning object" format element

The Settings: Manufacturing data export / labeling dialog in the Label tab has been extended by the available format element "Cable planning object" for the output of the labeling for the report type "Pre-planning: Planning object overview".

![](../Pictures/Gui/ALL/benefit.png)Benefit:

This extension offers users a number of advantages in the context of the VDI 3814 (Building Automation). The new format element now allows the properties of a cable planning object to be accessed in the planning object overview. This makes it possible, for example, to output "mixed" lists. As a result the data of a cable planning object (for example cable lengths) can be output for a planning object (such as a motor).

### Segments output in accordance with the sorting in the pre-planning navigator in function lists

Previously PCT loop functions that are subordinate to a PCT loop were output in the reports in alphabetical order and not in the order in which they are displayed in the tree of the pre-planning navigator. The different sequence in the pre-planning navigator and in the reports (such as in function lists for building automation according to VDI 3814) caused interpretation difficulties and misinterpretations for the users.

The new Sort code (segments) (ID 44092) property is now available to output the segments in the same sequence as in the pre-planning navigator. You have to select this property as the "Category / property" in the sorting settings in the Sorting dialog so that the same sorting takes place in the reports as in the pre-planning navigator. This applies both for reports of the type "Pre-planning: Planning object overview" (function lists for building automation to VDI 3814) and for the export of manufacturing data / labeling data.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

The retention of the same sequence in the pre-planning navigator and in the reports offers a consistent user experience. Users do not have to switch between different views or hierarchies - which improves the user-friendliness. Users can also switch rapidly between different views to check information and create plans without having to worry about inconsistencies in the hierarchy. This allows more efficient planning and reporting.

The uniform hierarchy and sequence simplifies the interpretation of the function lists for the building automation. Users can understand more intuitively how the various PCT loop functions are logically connected to one another and which functions are subordinate. This way misinterpretations are avoided.

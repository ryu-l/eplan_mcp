#### Parameters

*strFullLinkFileName*
:   Full link file name of the project, into which the parts (Articles) will be imported.

*strImportFilePath*
:   Full file name of the parts list file to import.

*strConverter*
:   Converter long name [XPamImport](XPamImport.html) converters

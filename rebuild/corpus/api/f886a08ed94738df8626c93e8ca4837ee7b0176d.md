# Transaction Class

Transaction Class

Class representing DataModel's transaction. It implements the [IDisposable](#) interface. Must be disposed immediately after the end of the transaction.

Example

Transaction usage - only inside "using".

- [c#](#i-tab-content-3da430ea-702b-4645-83e9-fcb8700a11fe)

```
using (Transaction txn = new TransactionManager().CreateTransaction())
{
    Function f;
    f.Name = "F1";
    txn.Commit();
}
```

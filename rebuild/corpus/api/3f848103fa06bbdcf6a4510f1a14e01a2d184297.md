Remarks

Represents relative transformation including the macro transformation.  
Calculated in relation to origin of parent placement coordinate system.  
For more information, please refer to the "[API Pro Panel](API_Pro_Panel.html)" chapter.  
Currently, scaling 3D objects in P8 is not supported, therefore setting the cell `M33` to a value different than `1` may cause incorrect result.

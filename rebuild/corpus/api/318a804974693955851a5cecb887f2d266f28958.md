#### Parameters

*pFilter*
:   Object used to customize the results. If `NULL` then all segment placements for the current project are returned.

#### Return Value

Array of [PlanningSegment](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.Planning.PlanningSegment.html)s matching the filter

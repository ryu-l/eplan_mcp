#### Property Value

Returns property value of type System.Int64.

Remarks

Specifies the specific method or technology with which an item is installed or fastened at a foreseen position. The following values are possible:

0 = Undefined

1 = Roof mounted

2 = Free-standing

3 = Integrated

4 = Wall-mounted

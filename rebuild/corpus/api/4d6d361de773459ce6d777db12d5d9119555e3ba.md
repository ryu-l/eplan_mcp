# GetExpandedStringSetting Method (ISettings)

GetExpandedStringSetting Method (ISettings)

Reads value from settings. Substitutes path fragments (like $Eplan).

Syntax

- [C#](#i-syntax-CS)
- [C++/CLI](#i-syntax-CPP2005)


   string strSettingPath,
   int nIdx
)

   int nIdx

#### Parameters

*strSettingPath*
:   Path to settings

*nIdx*
:   0-based index.

#### Return Value

value read from settings

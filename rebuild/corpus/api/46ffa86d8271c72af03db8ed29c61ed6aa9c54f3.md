# DMPLAOBJECT_PLCADDRESS_SYMBOLICADDRESS Property (SegmentTemplatePropertyList)

DMPLAOBJECT\_PLCADDRESS\_SYMBOLICADDRESS Property (SegmentTemplatePropertyList)

Overload List

| Overload | Description |
| --- | --- |
| [DMPLAOBJECT\_PLCADDRESS\_SYMBOLICADDRESS](topic1084.html) | PLC address: Symbolic address # 44024. |

Remarks

Property is indexed. Possible indexes are from 1 to 50.

PLC inputs and outputs that are required for controlling can be defined at a planning object. Enter here the symbolic address. The individual PLC inputs and outputs are differentiated via the index, with a maximum of 50.

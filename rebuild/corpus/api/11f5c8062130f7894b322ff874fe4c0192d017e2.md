# MfImportRibbonBarAction

MfImportRibbonBarAction

```
 Imports main ribbon bar customizing from XML file.
```

  

| Parameter | Description |
| --- | --- |
| ``` FileName ``` | ``` Path to the ribbon bar file that will be imported. ``` |

**Example**

```
 MfImportRibbonBarAction /FileName:"?"
```

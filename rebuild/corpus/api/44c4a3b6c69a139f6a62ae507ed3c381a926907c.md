# LockingStepCount Property

LockingStepCount Property

Returns the number of active LockingSteps. This is not the length of the vector, because the locking-operations are stored(represented) there (not the LockingSteps).

Syntax

- [C#](#i-syntax-CS)
- [C++/CLI](#i-syntax-CPP2005)

public int LockingStepCount {get;}
```
```

```
```

   int get();
}
```
```

#### Property Value

Returns the number of started LockingStep objects (and not ended).

Remarks

If you experience locking problems when trying to execute (internal) actions from the ribbon via API, this can be caused by autolocking. In this case, please use the [SafetyPoint](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.SafetyPoint.html) class.

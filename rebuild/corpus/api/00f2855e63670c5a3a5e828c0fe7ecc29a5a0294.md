#### Parameters

*page*
:   The [Page](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.Page.html) where the DimensionCircle will be placed on

*circle*
:   The [Graphics.Arc](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.Graphics.Arc.html) where DimensionCircle will be created

*vertex*
:   End point of DimensionCircle

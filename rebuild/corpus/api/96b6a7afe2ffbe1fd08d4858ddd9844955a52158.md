Replace Method

Replaces text in a searched objects.


#### Parameters

*oObjectsInSearchResults*
:   Objects found by a Search class for which we are replacing text.

*strTextToFind*
:   Text that we want to find.

*strReplaceWith*
:   Text that we want to replace with.

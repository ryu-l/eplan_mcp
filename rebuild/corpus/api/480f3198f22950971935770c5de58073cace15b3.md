OnSelect Method

#### Parameters

*arrSelectedObjects*
:   Array containing the selected placements.

*oContext*
:   Information about the selection operation.

Default [RequestCode](Eplan.EplApi.EServicesu~Eplan.EplApi.EServices.Ged.RequestCode.html) for this function is `Success`.

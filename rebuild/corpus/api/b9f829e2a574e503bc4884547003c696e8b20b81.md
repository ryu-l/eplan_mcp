# RemoveLayer Method

RemoveLayer Method

Removes specified layer from the table. Note 1: Only custom layer can be removed. Note 2: When the bSkipCheck parameter is TRUE, the layer will be removed without checking whether it is used. This may lead to inconsistence in the database. USE THIS METHOD WITH CARE!

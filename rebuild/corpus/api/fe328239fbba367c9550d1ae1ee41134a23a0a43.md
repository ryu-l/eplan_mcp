#### Parameters

*bSuccess*
:   if bSuccess == false, dragging was aborted by user

*oPosition*
:   Current position of cad cursor.

Default [RequestCode](Eplan.EplApi.EServicesu~Eplan.EplApi.EServices.Ged.RequestCode.html) for this function is `Nothing`.

Example

UndoStep usage - only inside "using".

- [C#](#i-tab-content-7c29c95e-5701-4404-9710-f271ba028fec)

```
using (UndoStep undo = new UndoManager().CreateUndoStep())
{
	using(Transaction txn = new TransactionManager().CreateTransaction())
	{
		Function f;
		f.Name = "F1";
		txn.Commit();
	}
    undo.DoUndo();
}
```

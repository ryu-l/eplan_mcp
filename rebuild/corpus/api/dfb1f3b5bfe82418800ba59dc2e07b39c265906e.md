Remarks

Start address for the outputs of the PLC subdevice 1 (for PLC data exchange in AutomationML AR APC format). Can be used in the addressing format. PLC devices exist that consist of several integrated modules and that have several start addresses. Such a device can consist, for example, of an internal CPU module, an internal input-output module as well as internal counter module - however with only one part number. Such integrated modules within a PLC device can be displayed in Eplan with PLC subdevices. To this purpose up to twelve PLC subdevices are available.

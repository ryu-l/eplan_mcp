#### Parameters

*elementsToCheck*
:   Array of [Eplan.EplApi.DataModel.StorableObject](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.StorableObject.html) which should be checked.

*oLayer*
:   Layer to check.

# HasBox Property

HasBox Property

Returns true if the Text has an alignment box. In GUI it's 'Activate alignment box' checkbox.

- [C#](#i-syntax-CS)
- [C++/CLI](#i-syntax-CPP2005)

```
```

   bool get();
   void set (    bool value);

```
```

#### Property Value

true : Text has a box

false : Text does not have a box

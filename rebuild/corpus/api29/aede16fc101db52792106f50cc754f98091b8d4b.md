# AllowSpecialCharacters Property

AllowSpecialCharacters Property

Representation of XDtcDeviceTagCheck.Hierarchy.AllowSpecialCharacters setting value. In P8-GUI it can be found in the menu:Options/Settings:Projects/<project>/Devices/DT syntax check:Structure identifier/Valid special characters. It provides possibility to use special characters in DeviceTag. Special characters are: `\_' `?' `\*' `,' . It might be changed by dynamic configuration. To make it work [EnableSyntaxCheck](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.Project+DeviceTagSettings~EnableSyntaxCheck.html) must be `true`.

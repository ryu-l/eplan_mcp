# XPamImportXml

XPamImportXml

```
Imports article data from a XML ("*.xml") file to system article database.
```

  

Remarks

```
No options used
```

```
This converter was designed to work on System Article Database (It is used in EPLAN P8 GUI in Utilities/Parts/Management Import dialog).
```

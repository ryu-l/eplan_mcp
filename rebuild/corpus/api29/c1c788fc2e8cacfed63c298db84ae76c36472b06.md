# GetBoundingBox Method (Group)

GetBoundingBox Method (Group)

Placement bounding box. Bounding box is a rectangle which contain this placement. It can be also used to determine placement size.

Syntax

- [C#](#i-syntax-CS)
- [C++/CLI](#i-syntax-CPP2005)

```
```
public override PointD[] GetBoundingBox()
```
```

```
```
public:
array<PointD>^ GetBoundingBox(); override
```
```

#### Return Value

Two points are always returned. First one is a lower-left corner and second is upper-right corner of bounding box.

Exceptions

| Exception | Description |
| --- | --- |
| [Eplan.EplApi.Base.BaseException](Eplan.EplApi.Baseu~Eplan.EplApi.Base.BaseException.html) | Thrown when something went wrong in internal function. |
| [System.InvalidOperationException](#) | Thrown when bounding box cannot be calculated. |

Remarks

In order to use function `GetBoundingBox` property [Placement.Page](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.Placement~Page.html) can't be null. For classes [Eplan.EplApi.DataModel.Graphics.DimensionItem](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.Graphics.DimensionItem.html), [Eplan.EplApi.DataModel.Graphics.DimensionCircle](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.Graphics.DimensionCircle.html) and [Eplan.EplApi.DataModel.Graphics.PlaceHolder](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.Graphics.PlaceHolder.html) this method will throw an exception `InvalidOperationException`. If `GetBoundingBox` is called on [Eplan.EplApi.DataModel.Graphics.Text](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.Graphics.Text.html) which length is zero an exception `InvalidOperationException` is thrown. Exception is also thrown for objects of type [Function](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.Function.html) when property Eplan.EplApi.DataModel.Function.Enums.Category is set to `Shielding`.

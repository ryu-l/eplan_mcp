Example

Following example shows how to use Backup class.

- [C#](#i-tab-content-cd65c11c-2612-4c8d-b223-39f1901e0d77)

```
Backup oBackup = new Backup();
oBackup.Project(
 "$(MD_PROJECTS)\\ESS_Sample_Project.elk",
  "Project backup - test comment",
  "$(MD_PROJECTS)",
  "ESS_Sample_Project.zw1",
  Backup.Type.MakeBackup,
  Backup.Medium.Disk,
  0.0 /*do not split*/,
  Backup.Amount.All,
  false,
  false,
  false,
  false);
Console.Out.WriteLine("Backup of project was created !");
```

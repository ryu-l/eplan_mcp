# GetNumericDefault Method

GetNumericDefault Method

Returns default numeric value of a setting. The index starts at 0.

- [C++/CLI](#i-syntax-CPP2005)

#### Parameters

*strSettingPath*
:   Indicates the path of the setting.

*nIdx*
:   Indicates the index.

#### Return Value

Default numeric value

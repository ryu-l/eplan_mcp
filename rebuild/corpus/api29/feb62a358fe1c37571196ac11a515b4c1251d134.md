# XPamSelectPart

XPamSelectPart

```
 starts the part selection (using the configured database)
```

  

| Parameter | Description |
| --- | --- |
| DatabaseId | ``` id of the database ``` |
| SelectedPartsCount | ``` result: number of the selected parts ``` |
| PartNr(nr) | ``` result: partnr of the selected part (nr = 1,2,...) ``` |
| Variant(nr) | ``` result: variant of the selected part (nr = 1,2,...) ``` |
| PartType(nr) | ``` result: parttype of the selected part (nr = 1,2,...) ``` |

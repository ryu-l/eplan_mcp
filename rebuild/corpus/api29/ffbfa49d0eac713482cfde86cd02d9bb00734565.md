# IXPartsImportExportEdz

IXPartsImportExportEdz

```
Exports parts data from system article database to a EDZ ("*.edz") file.
```

  

Remarks

```
No options used
```

```
This converter was designed to work on System Article Database (It is used in EPLAN P8 GUI in Utilities/Parts/Management Export dialog).
```

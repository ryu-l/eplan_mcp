# GetPersistentMenuId(String) Method

GetPersistentMenuId(String) Method

#### Parameters

*strText*
:   the name (caption) of the menu

#### Return Value

the command id (menu id)

Remarks

The id will never change. With this method, you cannot retrieve command (menu) ids of custom menu items, eg. menu items created by API. To get custom menu ids, please use the [GetCustomMenuId](Eplan.EplApi.Guiu~Eplan.EplApi.Gui.Menu~GetCustomMenuId.html) method.

# AllowedLetters Property

AllowedLetters Property

Representation of XDtcDeviceTagCheck.Hierarchy.AllowedLetters setting value. In P8-GUI it can be found in the menu:Options/Settings:Projects/<project>/Devices/DT syntax check:Structure identifier/All upper-case letters and numbers. It provides possibility to use letters in DeviceTag. To make it work [EnableSyntaxCheck](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.Project+DeviceTagSettings~EnableSyntaxCheck.html) must be `true`.

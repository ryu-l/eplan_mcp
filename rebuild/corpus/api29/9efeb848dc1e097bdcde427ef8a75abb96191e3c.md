# AddMenuItem(MultiLangString,String) Method

AddMenuItem(MultiLangString,String) Method

Adds a new menu item to the end of the utilities menu

- [C++/CLI](#i-syntax-CPP2005)

#### Parameters

*oText*
:   Multilanguage Text of the new menu item.

*strActionName*
:   Name of the [Eplan.EplApi.ApplicationFramework.Action](Eplan.EplApi.AFu~Eplan.EplApi.ApplicationFramework.Action.html) to be performed when the menu item is selected. Also its parameters can be passed here. Must be unique within menu.

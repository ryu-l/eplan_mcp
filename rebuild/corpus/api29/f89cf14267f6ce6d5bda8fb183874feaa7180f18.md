# GetNodeHandle Method

GetNodeHandle Method

Returns the [SettingNode](Eplan.EplApi.Baseu~Eplan.EplApi.Base.SettingNode.html) of the data node of the current setting. The individual settings can now be accessed via the functions of the [SettingNode](Eplan.EplApi.Baseu~Eplan.EplApi.Base.SettingNode.html).

#### Return Value

The [SettingNode](Eplan.EplApi.Baseu~Eplan.EplApi.Base.SettingNode.html) of the data node of the current scheme.

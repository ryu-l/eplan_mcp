# UpdateSegmentsFilling

UpdateSegmentsFilling

```
Calculates and sets value of property CABLINGSEGMENT_FILLING for all segments in project.
```

  

| Parameter | Description |
| --- | --- |
| PROJECTNAME | ``` Project name with full path (optional). If not entered, the selected project is used when the action is called from GUI (like from a script or button bar).  If called from the windows command line, PROJECTNAME must be set or the  must be used first, otherwise an  exception is thrown. ``` |

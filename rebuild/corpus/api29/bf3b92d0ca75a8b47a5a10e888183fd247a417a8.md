# Paths Property

Paths Property

Returns [PathInfo](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.PathInfo.html) object. It is intended to provide information about default Eplan P8 paths.

- [C#](#i-syntax-CS)
- [C++/CLI](#i-syntax-CPP2005)

```
```
public PathInfo Paths {get;}
```
```


   PathInfo^ get();
}
```
```

#### Property Value

New [PathInfo](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.PathInfo.html) object.

Example

- [C#](#i-tab-content-470c7c23-b032-46f9-a4db-3c12a189fa53)

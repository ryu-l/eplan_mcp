# RemoveMenuItem(String,String) Method

RemoveMenuItem(String,String) Method

Removes a new menu item (which was added with add(Popup)MenuItem. When it was a popup, the complete popup menu is removed, including its separators

Syntax

- [C#](#i-syntax-CS)
- [C++/CLI](#i-syntax-CPP2005)

```
```
public void RemoveMenuItem( 
   string strText,
   string strActionName
)
```
```


   String^ strText,
   String^ strActionName

```
```

#### Parameters

*strText*
:   Text of the new menu item.

*strActionName*
:   Name of the [Eplan.EplApi.ApplicationFramework.Action](Eplan.EplApi.AFu~Eplan.EplApi.ApplicationFramework.Action.html) to be performed when the menu item is selected. Also its parameters can be passed here.

# OpenWorkspaceAction

OpenWorkspaceAction

```
 opens an existing workspace
```

  

| Parameter | Description |
| --- | --- |
| Workspacename | ``` name of the workspace which should be opened (a string) ``` |
| Silent | ``` set or reset the silent mode (a bool term); in silent mode all dialogs will be suppressed (e.g. error dialogs) ``` |

Remarks

```
 This action needs a mainframe.
```

```
action name = OpenWorkspaceAction
```

Example

```
 OpenWorkspaceAction /Workspacename:"?"
```

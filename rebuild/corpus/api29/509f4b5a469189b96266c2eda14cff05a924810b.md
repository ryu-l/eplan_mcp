# ResetPositions3D(Int32) Method

ResetPositions3D(Int32) Method

#### Parameters

*nIndex*
:   Index of .TopLevelObjects3D from a macro 3d

Remarks

After calling the method, each 3d object is transformed by inverted transformation of .TopLevelObjects3D[nIndex]

Remarks

Type of placement of a function (normally contains the page type where the function has been placed). Possible values are:

1 = Multi-line

3 = Overview

-2 = Pair cross-reference

2 = Single-line

38 = P&I diagram

43 = Topology

8 = Panel layout

-6 = Detailed panel layout

-8 = 3D mounting layout

-12 = Functional

-3 = External

7 = Graphic.

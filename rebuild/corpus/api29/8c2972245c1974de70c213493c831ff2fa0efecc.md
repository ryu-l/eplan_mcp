# StartPin Property

StartPin Property

Returns the start [Pin](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.Pin.html) of this connection, if such exists (i.e. if the connection is connected on the source side). Otherwise, NULL is returned.

Remarks

Specifies at a connection splicer the connection points between which a continuous connection can run. Possible values are:

0 = None

1 = 1;2

2 = 1;3

3 = 1;4

4 = 2;3

5 = 2;4

6 = 3;4

7 = 1;2 / 3;4

8 = 1;3 / 2;4

9 = 1;4 / 2;3

# Menu Class

Menu Class

Class for modifying menu items. Add-ins can add new menu items to the EPLAN menu. A menu item is connected to an [Eplan.EplApi.ApplicationFramework.Action](Eplan.EplApi.AFu~Eplan.EplApi.ApplicationFramework.Action.html).

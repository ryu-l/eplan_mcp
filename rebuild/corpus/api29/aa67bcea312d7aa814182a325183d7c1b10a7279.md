# AllowUserCharacters Property

AllowUserCharacters Property

Representation of XDtcDeviceTagCheck.Hierarchy.AllowUserCharacters setting value. In P8-GUI it can be found in the menu:Oprions/Settings:Projects/<project>/Devices/DT syntax check:Structure identifier/Special text characters. When this option is enabled, all characters in [UserCharacters](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.Project+DeviceTagSettings~UserCharacters.html) string are possible to be used in DeviceTags. To make it work [EnableSyntaxCheck](Eplan.EplApi.DataModelu~Eplan.EplApi.DataModel.Project+DeviceTagSettings~EnableSyntaxCheck.html) must be `true`.

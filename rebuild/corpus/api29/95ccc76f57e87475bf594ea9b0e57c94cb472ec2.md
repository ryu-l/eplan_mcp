# TrackSignal Method

TrackSignal Method

Finds all connections on the same schema as `oSourceConnection` which transmit the same signal.

Syntax

- [C#](#i-syntax-CS)
- [C++/CLI](#i-syntax-CPP2005)

```
```
public void TrackSignal( 
   Connection oSourceConnection,
   List<Connection> foundConnectionList
)
```
```

```
```
public:
void TrackSignal( 
   Connection^ oSourceConnection,
   List<Connection^>^ foundConnectionList
)
```
```

#### Parameters

*oSourceConnection*
:   Connection from which tracking signal is started.

*foundConnectionList*
:   List of connections that transmits the same signal as `oSourceConnection` and are on the same schema.

Exceptions

| Exception | Description |
| --- | --- |
| [System.ArgumentNullException](#) | Thrown if parameter `oSourceConnection` or `foundConnectionList` is `null` value. |
| [System.ArgumentException](#) | Throw if parameter `oSourceConnection` is invalid. |

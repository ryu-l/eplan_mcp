# UpdatePartDimensions(Page) Method

UpdatePartDimensions(Page) Method

Transfers dimensions from articles to article placements. Corresponds to the 'Project data -> Parts / Devices -> 2D panel layout -> Update part dimensions' menu item.

#### Parameters

*page*
:   A panel layout page to update article placements from.

#### Return Value

An array of modified article placements.

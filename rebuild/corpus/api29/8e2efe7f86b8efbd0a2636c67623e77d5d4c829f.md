# MaxIndex Property (PropertyDefinition)

MaxIndex Property (PropertyDefinition)

Allows to check maximal index of a given property.

Syntax

- [C#](#i-syntax-CS)
- [C++/CLI](#i-syntax-CPP2005)

```
```
public int MaxIndex {get;}
```
```

```
```
public:
property int MaxIndex {
   int get();
}
```
```

#### Property Value

Maximal index of a given property.

Exceptions

| Exception | Description |
| --- | --- |
| [Eplan.EplApi.Base.BaseException](Eplan.EplApi.Baseu~Eplan.EplApi.Base.BaseException.html) | Thrown when called for PropertyValue created as a conversion from other type. |

Remarks

Can be called only after retrieving form given API class property list.

Example

- [C#](#i-tab-content-51fec1b8-1b6c-4a34-8cb9-6623851266ff)

```
Article article; //a valid article object

int i = article.Properties[Properties.Article.ARTICLE_HEIGHT].MaxIndex;

PropertyValue pv = 2;
int ii = pv.MaxIndex;
```

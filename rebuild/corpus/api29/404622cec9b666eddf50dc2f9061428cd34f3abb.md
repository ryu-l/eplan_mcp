# StyleId Property

StyleId Property

Line style identifier (0-6) Please use -16002 as "From layer" value.

Predefined line type index values are:

0 = continous: ------

1 = dash: - - - - -

2 = dot: .......

3 = dashdot: \_.\_.\_.\_

4 = dashdotdot: \_..\_..\_

5 = dash: \_ \_

6 = dashlongdot: \_\_ \_

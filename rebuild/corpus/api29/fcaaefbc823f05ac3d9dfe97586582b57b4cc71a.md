#### Parameters

*arrTemplates*
:   Array of segment template to export. Can't be `null`.

*strFileName*
:   Full file name of target file. Can't be `null` or `empty`.

*mlsDescription*
:   Description which is contained in exported file.

#### Return Value

Returns `true` if export is successful.

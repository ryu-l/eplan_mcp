# ECAD.UpdateEcadPagesCommand

Generates a project with specific pages of an EPLAN Electric P8 project. A list with pages and/or fragments which are located within the discipline structure is handed over as the argument of the command. The generated project only contains those pages that contain the listed fragments and the directly specified pages. All other pages are not considered during generation.

| Argument | Type | Description |
| --- | --- | --- |
| pages | List | Schematic pages and fragments within the discipline structure that are to contain the generated project. |

```
ECAD.UpdateEcadPagesCommand(=List{mos('WiringDiagram').first.derived.dos('T_Mechatronic_ModularSystem.ECAD.Page.Page')})
```

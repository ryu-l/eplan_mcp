# isExtension()

Returns true if the placeholder is an extension point.

| isExtension() | | | |
| --- | --- | --- | --- |
| Argument |  |  |  |
| Return value | [Boolean](glossary_o_boolean.htm) | | true or false |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code in Groovy:](javascript:void(0);)

```
placeholders = component.getPlaceholders();
for (iter = placeholders.iterator();
iter.hasNext(); )
{
	placeholder = iter.next();
	if (placeholder.isExtension())
	{
	// do something
	}
}
```

# Editions

Two editions of EEC are available for developing modular systems:

- Desktop edition:

The Desktop edition makes it possible for only one developer to edit a modular system at any one time. Several developers can work on the modular system, but not at the same time. The controls and functions of the Desktop edition correspond to Microsoft Excel.

This proven, sequential approach to development is fully adequate, especially for models of limited complexity.

- Enterprise edition:

In the case of complex models, particularly those involving multiple mechatronic disciplines (mechanic, fluidics, electric, software, etc.), it is necessary for several developers to work on a modular system at the same time. The Enterprise edition provides the features required to do this.

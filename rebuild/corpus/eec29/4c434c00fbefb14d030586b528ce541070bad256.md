# isInstanceOf(String typeName)

Returns true if for the project component either the library component <typeName>, the library component <typeName> is a superclass of the library component, or <typeName> is an interface associated with the library component.

| **isInstanceOf([String](glossary_o_string.htm) typeName)** | | | | |
| --- | --- | --- | --- | --- |
| Argument | String | typeName | Name of the library component May be assigned as name or absolute name (always the absolute name should be used, because it identifies the library component unique) | |
| Return value | [Boolean](glossary_o_boolean.htm) | |  | |

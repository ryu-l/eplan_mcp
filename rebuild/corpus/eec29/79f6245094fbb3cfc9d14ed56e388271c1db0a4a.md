# Creating new fragments FR_SymbolTable and FR_SymbolsGeneral

The FR\_SymbolTable and FR\_SymbolsGeneral fragments will provide the required contents at a later time when the symbol table is created. First the fragments are created and then installed and parameterized in the actuators and sensors in additional steps.

Create the fragment FR\_SymbolTable in unit Step7:

1. Select the Step7 unit.
2. From the popup menu, select New > Step7 > Source > Fragment.
3. In the Resource location panel, click Import.
4. Select the file FR\_SymbolTable.sdf in the following dialog.
5. Confirm with [Open].

Create the fragment FR\_SymbolsGeneral in unit Step7:

1. Select the Step7 unit.
2. From the popup menu, select New > Step7 > Source > Fragment.
3. In the Resource location panel, click Import.
4. Select the file FR\_SymbolsGeneral.sdf in the following dialog.
5. Confirm with [Open].

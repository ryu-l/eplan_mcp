# Task: Creating an enclosure for Feeder with EPLAN Pro Panel

The task is to create an enclosure with EPLAN Pro Panel from the Feeder functional, mechatronic configuration.

![](../Pictures/tutorial_pp_aufgabenstellung.png)

To accomplish this, the T\_Mechatronic\_ModularSystem will be expanded to include the pre-built Pro Panel library. Next, the Pro Panel components will be assigned to the components of the functional, mechatronic configuration. Finally, we will show how to create the enclosure.

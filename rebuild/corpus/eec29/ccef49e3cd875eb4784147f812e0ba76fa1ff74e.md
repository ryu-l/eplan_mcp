# Create new project

Use the project wizard to create a new project.

![](../Pictures/Komposition_1.png)

1. Click ![](../Pictures/new_project.png)in the Project Catalog view.

![](../Pictures/Komposition_2.png)

1. Enter the name Feeder
2. Click [Next >].

![](../Pictures/Komposition_2b.png)

1. Select the check box for the library to be imported, T\_Mechatronic\_ModularSystem.

(Manually selected libraries are identified by a check mark. Libraries imported due to dependencies are marked with a square)

1. Click [Next >].

![](../Pictures/projektassistent_ebenenkomponenten.png)

1. Highlight the Feeder level component.
2. Close the project wizard by clicking [Finish].

The result of the project wizard is as follows:

![](../Pictures/Komposition_2c.png)

![](../Pictures/Gui/ALL/note.png)Note:

So far, you have only worked with libraries. Libraries, object-oriented terms, contain Classes. Symbols of objects of the class level (libraries, units, etc.) are shown in blue. The newly created project, in object-oriented terms, is located at the instance level. Objects of this level are shown in orange.

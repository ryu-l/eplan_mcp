# com.mind8.global.resourcePath

The EEC argument must be transferred with the following syntax:

```
-D<Argument>=<Value>
```

| EEC argument | Usage |
| --- | --- |
| -Dcom.mind8.global.resourcePath=<File name> | Optional |
| **Annotation** | |
| Specifies a resource path from which relative paths can be set for the individual disciplines in the user preferences.  Example:   ``` -Dcom.mind8.global.resourcePath=C:\Users\Public\EPLAN\EngineeringConfiguration\PB23_20120814_1536\resources ```   In the user preferences, the resource path can be entered for each discipline, starting from this folder, e.g., \ECAD. | |

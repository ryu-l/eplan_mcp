# Move objects

Using the move method of the MoveHelper, it is possible to move instances of objects from one placeholder to another.

| MoveHelper.move(IUnitOfWork uow, [String](glossary_o_string.htm) sourceAbsoluteName, String targetPlaceholderAbsoluteName) | | |
| --- | --- | --- |
| Argument | IUnitOfWork uow | The UnitOfWork of the script |
| String sourceAbsoluteName | Absolute name of the source object |
| String targetPlaceholderAbsoluteName | Absolute name of the placeholder on which the source object is inserted. |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code:](javascript:void(0);)

```
import com.mind8.moving.helper.MoveHelper;
import org.foederal.eobroker.core.IUnitOfWork;

uow = self.getUnitOfWork();
source = "Feeder.Mechatronic.Feeder.Insert"; // Absolute name of source object
target = "T_Mechatronic_ModularSystem.Stations.Feeder.Functiongroups"; // Absolute name of target placeholder
MoveHelper.move(uow, source, target);
uow.saveChanges();
```

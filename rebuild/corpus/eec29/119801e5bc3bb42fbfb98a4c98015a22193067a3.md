# Conversions

Basic types are converted automatically according to the type hierarchy integer->double->string. That is to say an integer can be converted to double and a double can be converted to string.

| Conversion | Example | Result |
| --- | --- | --- |
| [Integer](glossary_o_integer.htm) to [String](glossary_o_string.htm) | 'a'+1 | a1 |
| [Double](glossary_o_double.htm) to String | 'a'+1.0 | a1.0 |
| Integer to Double | 1.2+1 | 2.2 |

Besides the automatically conversions the following methods may be used to convert basic types.

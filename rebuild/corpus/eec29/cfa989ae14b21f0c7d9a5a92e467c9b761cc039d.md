# Query the global resource path in scripts

To query the global resource path, which is set in the .ini file for starting EEC, the following script code may be used:

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code in Groovy:](javascript:void(0);)

```
globalResourcePath = System.getProperty("com.mind8.global.resourcePath");
if (globalResourcePath == null)
{
	// Set message or default
}
```

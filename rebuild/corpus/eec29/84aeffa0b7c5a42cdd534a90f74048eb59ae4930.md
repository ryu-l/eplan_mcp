# Installing and configuring the fragment FR_SymbolsGeneral in the Feeder Station

Analogous to the "Installing the configuring the fragment FR\_SymbolTable in actuators and sensors" section, the fragment FR\_SymbolsGeneral is now installed into the Feeder Station and the parameters are provided with values.

1. Open the Feeder station.
2. Drag the fragment FR\_SymbolsGeneral from the Step7 unit into the component editor.
3. Select the installed fragment FR\_SymbolsGeneral.
4. Enter the following formulas and values for the parameters:

| [Parameter](glossary_o_parameter.htm) | Value |
| --- | --- |
| Bit0 | =mc.$Bit0\_IX |
| Bit1 | =mc.$Bit1\_IX |
| Bit2 | =mc.$Bit2\_IX |
| Bit3 | =mc.$Bit3\_IX |
| Bit4 | =mc.$Bit4\_IX |
| Bit5 | =mc.$Bit5\_IX |
| Bit6 | =mc.$Bit6\_IX |
| Bit7 | =mc.$Bit7\_IX |
| Bit8 | =mc.$Bit8\_IX |

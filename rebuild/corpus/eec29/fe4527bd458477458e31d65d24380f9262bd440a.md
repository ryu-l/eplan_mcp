# Importing a library for interfaces in the modular system

Analog to the architecture model, the T\_Interfaces library is imported into the mechatronic modular system.

1. Open the T\_Mechatronic\_ModularSystem library.
2. Switch to the editor page Imported libraries.
3. Click ![](../Pictures/button_finder.png) to open the Finder dialog.
4. Click [Search] in the Finder dialog.
5. Select the T\_Interfaces library.
6. Confirm with [OK].
7. Save the T\_Mechatronic\_ModularSystem library.

The interfaces of T\_Interfaces can now be applied in the T\_Mechatronic\_ModularSystem.

# addToPlaceholderObjects(MechatronicObject mo, Placeholder placeholder, int index)

Places the mechatronic object mo on the placeholder placeholder on the index index in this mechatronic component.

| addToPlaceholderObjects(MechatronicObject mo, [Placeholder](glossary_o_placeholder.htm) placeholder, int index) | | | |
| --- | --- | --- | --- |
| Argument | MechatronicObject | mo | A mechatronic object to place. |
| Placeholder | placeholder | A placeholder of the component. |
| [Integer](glossary_o_integer.htm) | index | A valid index within the already existing objects on the placeholder |
| Return value |  | |  |
| Exceptions | Throws an IndexOutOfBoundsException if the specified index is out of bounds:  -1 < index < getPlaceholderObjects(placeholder).size() | | |

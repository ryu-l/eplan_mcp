# Use of Maps: Page Numbering Example

The aim is to calculate the page number (parameter page number) for wiring diagram macros. The following rules apply:

- All page objects are assigned a chapter (parameter chapter).
- Within each chapter the page numbering should begin again with "1".

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

| ECAD.ChapterItems | Chapter | page number to calculate |
| --- | --- | --- |
| PageA | 1 | 1 |
| PageB | 2 | 1 |
| PageC | 1 | 2 |
| PageD | 3 | 1 |
| PageE | 2 | 2 |
| PageF | 1 | 3 |

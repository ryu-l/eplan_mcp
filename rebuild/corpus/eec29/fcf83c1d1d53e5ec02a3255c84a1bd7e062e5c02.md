# Task 1 - Creating the Step 7 program for Feeder

The task is to create a STEP 7 program based on the functional, mechatronic configuration Feeder.

**![](../Pictures/2009030501.svg)**

As shown in the following figure, the plug-socket principle will be used to insert the FB\_Insert, FB\_Move, and FB\_Inspect function blocks into the FB\_Sequence function block. The socket parameter for the STEP 7 discipline is always assigned the name Caller. The parameter value is the same as the name of the block where the socket is located, i.e., FB\_Sequence for purposes of this tutorial.

Because the optional Inspect function group is installed in the mechatronic, two different programs should be created.

- With FB\_Inspect
- Without FB\_Inspect

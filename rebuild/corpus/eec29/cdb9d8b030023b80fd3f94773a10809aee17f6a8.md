# Adding the program blocks and preassembled symbol table

You need to create components for the symbol table and program blocks. The files supplied are to be used for this purpose.

Create the OB\_Cycle program block.

1. Select the Step7 unit.
2. From the popup menu, select New > Step7 > Source > Program.
3. In the Resource location panel, click Import.

The Open dialog now appears.

![](../Pictures/tutorial_s7_programm1.png)

1. Select the file OB\_Cycle.AWL.
2. Confirm with [Open].

![](../Pictures/tutorial_s7_programm2.png)

The OB\_Cycle name is automatically imported. The Step7-LD language of the block is also automatically detected.

1. Select the Parameters editor.

![](../Pictures/tutorial_s7_ob_cycle_parameter_number.png)

The Number parameter has already been entered.

1. Enter the number 1 in the Value column.
2. Repeat steps 1 and 7 for the following symbol table and blocks. Use the specified values for the Number parameter:

New > Step7 > Source > Function:

FC\_Org\_Functions.AWL, Number = 1

New > Step7 > Source > Function:

FC\_ASI\_CopyInputs.AWL, Number = 2

New > Step7 > Source > Function block:

FB\_Sequence.AWL, Number = 1

New > Step7 > Source > Function block:

FB\_Insert.AWL, Number = 20

New > Step7 > Source > Function block:

FB\_Move.AWL, Number = 21

New > Step7 > Source > Function block:

FB\_Inspect.AWL, Number = 22

New > Step7 > Source > Symbol table:

Symboltable.SDF

The results should look as follows:

![](../Pictures/tutorial_s7_bausteine.png)

The parameters of the imported blocks are listed in the Parameter unit that is automatically created.

# Import of SAP libraries

The SAP libraries provide the required library components and commands for using the SAP interface.

The libraries are provided for importing in the [EOX](glossary_o_eox.htm) file in the folder <EEC installation folder>\install\sap. The file name has the following syntax: sap\_<Version number>.eox.

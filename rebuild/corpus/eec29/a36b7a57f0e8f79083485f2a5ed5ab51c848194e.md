# Creating a library for the discipline ECAD P8

Previously, the discipline components were inserted in the mechatronic modular system T\_Mechatronic\_ModularSystem below the ECAD unit. The discipline components is now to be collected in their own library.

### [ClosedCreating a library for ECAD P8:](javascript:void(0);)

1. In the Library Catalog click ![](../Pictures/button_new_library.png).
2. Enter T\_ECAD\_P8 in the Name field.

Import the libraries ECAD, T\_Mechatronic\_Architecture and T\_Interfaces:

1. Open the editor page Imported libraries.
2. Click the symbol [Add library].
3. In the Library finder dialog click [Search].
4. Mark the libraries ECAD, T\_Mechatronic\_Architecture and T\_Interfaces.
5. Confirm with [OK].
6. Save the library.

### [ClosedMoving discipline components into the library T\_ECAD\_P8:](javascript:void(0);)

Making the T\_ECAD\_P8 library visible for T\_Mechatronic\_ModularSystem

1. Select the T\_Mechatronic\_ModularSystem library.
2. Open the editor page Imported libraries.
3. Click the symbol [Add library].
4. In the Library finder dialog click [Search].
5. Select the T\_ECAD\_P8 library.
6. Confirm with [OK].
7. Save the library.

The visibility is established.

Moving discipline components

1. Mark the ECAD unit in the T\_Mechatronic\_ModularSystem library.
2. Drag the unit into the T\_ECAD\_P8 library.

Undoing visibility

1. Open the T\_Mechatronic\_ModularSystem library.
2. Open the editor page Imported libraries.
3. Select the T\_ECAD\_P8 library.
4. Press the key [Del].
5. Save the library.

# write

Allows reading of a property for a graphical object.

| Attribute name | Usage | Attribute values | Default value | Description |
| --- | --- | --- | --- | --- |
| key | required |  |  | Property of the object, which is to change |
| receiver | optional |  |  | Formula to the object |
| value | required |  |  | Write-value of a constant or formula |

| Allowed sub-elements | Quantity |
| --- | --- |
| none |  |

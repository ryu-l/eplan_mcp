# includingAll(Collection coll)

Adds the objects of the collection coll to the Collection.

| includingAll(Collection coll) | | | |
| --- | --- | --- | --- |
| Argument | Collection | coll | Collection with the objects to be added |
| Return value | Collection |  | |

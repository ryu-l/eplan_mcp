# isMinValue()

Delivers true if the integer matches the smallest possible integer. The minimum integer value is -231.

| **isMinValue()** | | | | |
| --- | --- | --- | --- | --- |
| Argument |  |  |  | |
| Return value | [Boolean](glossary_o_boolean.htm) | |  | |

| --- | --- |

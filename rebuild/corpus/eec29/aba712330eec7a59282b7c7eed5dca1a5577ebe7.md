# instantiate(instantiationTarget, MechatronicObjectClass classToInstantiate, String instanceName, boolean instantiateExtensions, IMechatronicInstantiationContext context)

Similar to instantiate(instantiationTarget,TypeClass classToInstantiate, String instanceName, boolean instantiateExtensions), but a reusable context can be added. This is useful when multiple instantiations are processed within a script in order to achieve optimal performance.

It is important to strictly follow the application of pattern in the example, otherwise may not be saved.

| instantiate(instantiationTarget, MechatronicObjectClass classToInstantiate, [String](glossary_o_string.htm) instanceName, boolean instantiateExtensions, IMechatronicInstantiationContext context) throws NoMatchingPlaceholderException | | | |
| --- | --- | --- | --- |
| Argument |  | instantiationTarget | A mechatronic component or mechatronic root, under which the new object is placed |
| MechatronicObjectClass | classToInstantiate | The class to instantiate |
| String | instanceName | The name of the object. If null is returned, the object gets the name of the class. |
| [Boolean](glossary_o_boolean.htm) | instantiateExtensions | If the return value is true, internal extension points are calculated during instantiation, if the return value is false no calculation is done. |
| IMechatronicInstantiationContext | context | A reusable context for instantiation. |
| Return value | [Component](glossary_o_component.htm) | | The instantiated object |

```
import com.mind8.mechatronic.skill.api.IMechatronicInstantiationAPI;
import com.mind8.mechatronic.skill.api.NoMatchingPlaceholderException;
import com.mind8.mechatronic.skill.eos.TypeClass;
import java.util.ArrayList;

instantiationTarget = obj; // Argument in command
absLibComp = "T_Mechatronic_ModularSystem.Functiongroups.Insert"; // Absolute name of library component to instantiate
instanceName = "Insert"; // Name of new instance
context = IMechatronicInstantiationAPI.DEFAULT.createInstantiationContext(instantiationTarget);
aList = new ArrayList();
try
{
	instance = IMechatronicInstantiationAPI.DEFAULT.instantiate(instantiationTarget, absLibComp, instanceNam, true, context);
	aList.add(instance);
	instance = IMechatronicInstantiationAPI.DEFAULT.instantiate(instantiationTarget, absLibComp, instanceNam, true, context);
	aList.add(instance);
}
catch (NoMatchingPlaceholderException nmpe)
{
	// error handling
}
finally
{
	context.deleteUnusedInstances();
}
return aList;
```

# Java Virtual Machine Arguments (VMArgs)

A list of all possible Java VM arguments can be called up via the command java-?. Non-standardized options of a VM are displayed via the command java-X. The VM arguments relevant to the operation of the EEC are shown in the following table.

All arguments for the Java Virtual Machine should be executed below the entry -vmargs in the initialization file (e.g. ec.ini).

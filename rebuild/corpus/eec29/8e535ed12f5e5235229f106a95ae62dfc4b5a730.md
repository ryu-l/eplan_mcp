# addToPlaceholderObjects(MechatronicObject mo, String placeholderName, int index)

Places the mechatronic object mo on the placeholder with the name placeholderName on the index index in this mechatronic component.

| addToPlaceholderObjects(MechatronicObject mo, [String](glossary_o_string.htm) placeholderName, int index) | | | |
| --- | --- | --- | --- |
| Argument | MechatronicObject | mo | A mechatronic object to place. |
| String | placeholderName | The name of the placeholder of the component. |
| [Integer](glossary_o_integer.htm) | index | A valid index within the already existing objects on the placeholder |
| Return value |  | |  |
| Exceptions | Throws a PlaceholderNotExistingException, if no placeholder with the specified name exists. Throws an IndexOutOfBoundsException if the specified index is out of bounds:  -1 < index < getPlaceholderObjects(placeholder).size(). | | |

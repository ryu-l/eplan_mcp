# Adding body and chapter to mechatronic components

In the first step, you need to link the text components for the body and chapter of the ListOfComponents with the mechatronic components:

![](../Pictures/Komponentenliste_16.png)

1. [Double](glossary_o_double.htm)-click to open the component Feeder in the T\_Mechatronic\_ModularSystem library in the Stations unit and move the text component Sensors\_Actuators\_Body from Library Catalog view to the Components editor section.
2. Move Sensors\_Actuators\_Chapter twice from Library Catalog view to Components editor panel.
3. Rename Sensors\_Actuators\_Chapter as Actuators\_Chapter (switch to editor mode by clicking again on the selected component or by pressing [F2]).
4. Rename Sensors\_Actuators\_Chapter2 as Sensors\_Chapter.

![](../Pictures/Komponentenliste_17.png)

1. Once again, select Actuators\_Chapter. The accompanying parameter table will now appear.
2. Enter the value Actuators in the table in the parameter line Heading.
3. Repeat the final two steps for Sensors\_Chapter and the heading parameter value Sensors.

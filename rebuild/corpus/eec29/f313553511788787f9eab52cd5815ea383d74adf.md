# union(Collection coll)

Adds the objects of the Collection coll to a Collection. In contrast to including, the argument has to be a Collection.

| union(Collection coll) | | | |
| --- | --- | --- | --- |
| Argument | Collection | coll |  |
| Return value | Collection |  | |

| --- | --- |

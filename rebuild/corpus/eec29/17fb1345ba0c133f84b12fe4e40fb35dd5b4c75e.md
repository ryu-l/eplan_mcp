# de.eplan.eec.datasource.defaultTable

The EEC argument must be transferred with the following syntax:

```
-D<Argument>=<Value>
```

| EEC argument | Usage |
| --- | --- |
| -Dde.eplan.eec.datasource.<absolute path to datasource object>.defaultTable=<default table> | Optional |
| **Annotation** | |
| By means of EEC arguments for the runtime environment the entries Connection URL, User, Password and Default table for a database component of the DatabaseDataSource type could be overruled.  By means of the EEC argument de.eplan.eec.datasource.<absolute path to datasource object>.defaultTable the name of the default table is given.  Example:  A different table name for the datasource component Databases.SQL.PartsDB should be used.   ``` -Dde.eplan.eec.datasource.Databases.SQL.PartsDB.defaultTable=Parts ``` | |

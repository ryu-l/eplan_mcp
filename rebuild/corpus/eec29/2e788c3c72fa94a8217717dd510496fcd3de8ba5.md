# Downloading the created files

The list of created files of the Job can be sampled by the downloads link contained in the Job status. The individual file is then downloaded through the included file link. The files have to be made known to the Job Server during the Job execution by means of the MarkFileForDownloadCommand.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example GET to the download URI:](javascript:void(0);)

|  |  |
| --- | --- |
| Request | GET /api/jobs/<jobId>/downloads |
| Accept | application/json |
| Accept-Encoding | gzip, deflate |
| Pragma | no-cache |
| Body | ``` [ 	{ "title": "proj.px", 		"links":{ 			"file": { 				"href": "http://aliasurl/api/jobs/<jobId>/downloads/proj.px" 			} 		} 	}, 	{ "title": "proj1.px", 		"links":{ 			"file": { 				"href": "http://aliasurl/api/jobs/<jobId>/downloads/proj1.px" 			} 		} 	} ] ``` |

# Job Server Worker installation

The installation of the Worker is based on the Stand-Alone installation with [EOX](glossary_o_eox.htm) data storage (see [Stand-Alone installation](admin_h_installation_stand_alone.htm)).

The optional function (Optional Feature) has to be installed for the Job Server Worker:

1. Start EEC
2. Open Help > Install new software....
3. In the Use field select the --All available sites-- or de.eplan.eec.install.optfeatures entry from the drop-down list.
4. Expand the EC Optional Features path.
5. Select the Job Server Worker Feature entry.
6. Click [Next >].

The function to be installed is only listed so that the selection can be checked.

1. Click [Next >].
2. Accept the license terms.
3. Click [Finish].

![](../Pictures/Gui/ALL/note.png)Note:

At the moment the Worker cannot be operated headless. Dialogs possibly occurring would lead to the stop of the Worker.

Further Worker settings can be made in the preferences:

- If the Worker should start automatically after EEC has been started.
- A directory ([UNC path](glossary_o_unc.htm) is possible), where the job definitions for the Worker are stored.
- The maximum number of parallel jobs.
- E-mail preferences, to send e-mails to particular addresses in case of successful or failed jobs.

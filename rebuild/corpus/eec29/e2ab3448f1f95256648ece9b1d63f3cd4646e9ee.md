# getEngineeringObject(IEngineeringObject eo)

Is used to exchange IEngineeringObjects between several IUnitOfWork. Only already stored EOs can be exchanged between several IUnitOfWork.

| getEngineeringObject(IEngineeringObject eo) | | | |
| --- | --- | --- | --- |
| Argument | IEngineeringObject | eo | An IEngineeringObject from another IUnitOfWork |
| Return value | IEngineeringObject | | Reference on the IEngineeringObject eo of this IUnitOfWork |

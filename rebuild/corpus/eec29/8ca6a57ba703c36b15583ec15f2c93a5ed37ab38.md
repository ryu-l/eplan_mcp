# de.eplan.eec.formui.renderer

The EEC argument must be transferred with the following syntax:

```
-D<Argument>=<Value>
```

| EEC argument | Usage |
| --- | --- |
| -Dde.eplan.eec.formui.renderer=<Renderer type> | Optional |
| **Annotation** | |
| Specifies the renderer with which Form-UIs are represented.  Permitted values for the renderer type are:   - swing: Form-UIs are rendered with SWING; no other renderer can be selected. - swt: Form-UIs are rendered with SWT; no other renderer can be selected. - all: Form-UIs are rendered either with SWING or SWT; a menu is used for the selection. - No value: Form-UIs are rendered with SWT by default.   Example:   ``` -Dde.eplan.eec.formui.renderer=SWING ``` | |

# case

A condition is formulated with every <case> sub-element. If the condition is fulfilled, the assigned sub-element (<input> or <label>) is displayed in the column of the pureTable.

| Attribute name | Usage | Attribute values | Default value | Description |
| --- | --- | --- | --- | --- |
| on | required |  |  | Formula of the condition |

| Allowed sub-elements | Quantity |
| --- | --- |
| [input](refformui_r_input.htm) | 0..1 |
| [label](refformui_r_label.htm) | 0..1 |

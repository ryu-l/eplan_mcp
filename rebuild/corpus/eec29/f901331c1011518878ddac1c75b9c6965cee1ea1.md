# p8dbquery(String Partnumber, String Variant, Integer Id)

Returns the value of the specified identifying number for the specified part of the specified variant. If the part cannot be found in the parts database, the method returns an error.

| p8dbquery([String](glossary_o_string.htm) Partnumber, String Variant, [Integer](glossary_o_integer.htm) Id) | | | |
| --- | --- | --- | --- |
| Arguments | String | Partnumber | Part number |
| String | Variant | Part variant | |
| Integer | Id | Identifying number of the property | |
| Return value |  |  | |

| --- | --- |
| =p8dbquery('TS 8886.500','1',22014) | 597.0 |

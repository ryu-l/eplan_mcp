# Parameterizing encapsulating mechatronic components

All formulas have been lost due to the encapsulation of the discipline components and the usage of interface parameters. In addition all values can now be determined in the mechatronic structure!

### [ClosedParameterizing M\_Body](javascript:void(0);)

1. Open the component M\_Body.
2. Switch to the Parameter editor page.
3. Enter the following formula for the Heading parameter:

```
=mc.name
```

1. Enter the following formula for the Logo parameter:

```
=type('T_Images.Logo').image
```

1. Enter the following value for the Socket parameter:

```
Chapter
```

1. Save the component.

### [ClosedParameterizing M\_Chapter](javascript:void(0);)

1. Open the component M\_Chapter.
2. Switch to the Parameter editor page.
3. Enter the following formula for the Heading parameter:

```
=switch mc.mos('T_Office_Word.Wrapper.M_Chapter').indexOf(this)
{
	case 0 : 'Actuators'
	case 1 : 'Sensors'
	else : 'Not defined'
}
```

1. Enter the following value for the Plug parameter:

```
Chapter
```

1. Enter the following formula for the Socket parameter:

```
=$Heading
```

1. Save the component.

### [ClosedParameterizing M\_Row](javascript:void(0);)

1. Open the component M\_Row.
2. Switch to the Parameter editor page.
3. Enter the following value for the Descriptor parameter:

```
=mroot.name + mc.absoluteName.substring(mroot.absoluteName.size, mc.absoluteName.size - 1)
```

1. Enter the following value for the Icon parameter:

```
=type('T_Images.Actuators_Sensors_Imageregister').image(mc.type)
```

1. Enter the following formula for the Plug parameter:

```
=switch mc.isInstanceOf('T_Mechatronic_Architecture.Levelcomponents.Actuator')
{
	case true : 'Actuators'
	case false : 'Sensors'
	else: 'Not defined'
}
```

1. Enter the following formula for the Socket parameter:

```
=mroot.rmos.indexOf(this) + 1
```

1. Save the component.

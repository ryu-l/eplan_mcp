# ECAD.GenerateMacroAndEdzForEcadProjectCommand

By using the command data are packed into an EDZ file whose contents represent a part for the P8 parts database. To this purpose a macro is created and packed together with further information and files into an EDZ file.

Requirements:

- EPLAN Electric P8 Version 2.6 and above.
- The basic project template IEC\_bas001.zw9is available in the current P8 version.
- The enveloping macro has a placeholder object with special properties (see [Variable\_Placeholder\_Object](#Variablen_Platzhalterobjekt)).
- The executable file or EPLAN Electric P8 (W3u.exe) is entered in the EEC preferences.
- Either the option Keep macro boxes in window macros or Keep macro boxes in symbol macros is activated in the EEC preferences. In the case of the generation of an EDZ file these options are mutually exclusive! For information on creating macros see [EPLAN Electric P8](admin_r_prefs_ecad_p8.htm).
- The current configuration already contains a valid ECAD structure.
- The specified C# script contains an EcExportMacroAction in order to create a macro and an EcCleanProjectAction in order to remove the temporarily created projects.

The following method creates an EDZ file from a schematic page that contains a macro already created. If the schematic contains more than page, an error message is output. The name of the created EDZ file is returned.

| Argument | Type | Description |
| --- | --- | --- |
| wiringDiagram | WiringDiagam | Project component of the WiringDiagram type whose subcomponents are collected. |
| targetFolderName | String | Name of the target directory, where the created EDZ file is stored. The EDZ file is stored with the specified part number as the file name. When a relative path is specified, the created EDZ file is stored in the project directory. Alternatively an absolute path can be specified. |

The following method creates an EDZ file from a schematic page that contains a macro already created. If the schematic contains more than page, an error message is output. The name of the created EDZ file is returned.

| Argument | Type | Description |

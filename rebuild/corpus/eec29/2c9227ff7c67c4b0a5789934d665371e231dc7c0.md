# Creating a database on a server

A server-based database is used in connection with a client-server installation. A new database on a server is created using the administration tool.

![](../Pictures/ec_admin_erstelle_server_datenbank.png)

1. The check box Client server installation must be enabled to create a database on a server.
2. The host must be the available server in the corresponding notation.

Upon entry of the host name and / or port number, their availability will be checked immediately (4). If the port number is entered slowly, the availability check will be carried out character by character, which causes a delay. Using [F5], the availability check can be executed on the entire entry, thus accelerating the process.

3. The database name can be any name (the default name is jazzDb).
4. The [Create Database] button starts the wizard for creating the database, and for importing and updating model data.

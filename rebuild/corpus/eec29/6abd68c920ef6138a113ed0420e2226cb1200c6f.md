# Nesting of mechatronic components

Generally, there are recurring configurations in a project. To minimize configuration efforts, closed units can be formed that contain recurring components. For example, the Axis of the tutorial includes the components Cylinder, Valve, and Position\_1 to Position\_4. Mechatronic components can be nested for this purpose.

The components Finder is launched via the Add components dialog. This dialog can be used to add mechatronic components. Functional structures can be realized by nesting mechatronic components.

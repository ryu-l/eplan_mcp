# Creating a library for the Word discipline

Previously, the discipline components were inserted in the mechatronic modular system T\_Mechatronic\_ModularSystem below the Word\_Components unit. The discipline components is now to be collected in their own library.

### [ClosedCreating a library for the Word](javascript:void(0);)

1. In the Library Catalog click ![](../Pictures/button_new_library.png).
2. Enter T\_Office\_Word in the Name field.

Import the libraries Word, T\_Mechatronic\_Architecture and T\_Images and T\_Interfaces:

1. Open the editor page Imported libraries.
2. Click the symbol [Add library].
3. In the Library finder dialog click [Search].
4. Mark the libraries Word, T\_Mechatronic\_Architecture, T\_Images and T\_Interfaces.
5. Confirm with [OK].
6. Save the library.

### [ClosedRemoving discipline components](javascript:void(0);)

As long as instances of the discipline components are still installed in the mechatronic components, they cannot be moved into the new libraries T\_Office\_Word. Therefore all instances have to be removed first.

1. Open the component Cylinder.
2. Select the discipline component Row.
3. Delete the discipline components with ![](../Pictures/delete.png).
4. Repeat Steps 1 to 3 for Valve, Posistionsensor\_inductive, Positionsensor\_optical and Pressuresensor.
5. Repeat steps 1 to 3 for Feeder with the instances ListOfComponents, Actuators\_Table and Sensors\_Table.

Repeat Steps 1 to 3 for Valve, Posistionsensor\_inductive, Positionsensor\_optical and Pressuresensor.

### [ClosedMoving discipline components and parameters in the T\_Office\_Word library](javascript:void(0);)

Making the T\_Office\_Word library visible for T\_Mechatronic\_ModularSystem

1. Open the T\_Mechatronic\_ModularSystem library.
2. Open the editor page Imported libraries.
3. Click the symbol [Add library].
4. In the Library finder dialog click [Search].
5. Select the T\_Office\_Word library.
6. Confirm with [OK].
7. Save the library.

The visibility is established.

Moving discipline components and parameters

1. In the T\_Mechatronic\_ModularSystem library select the units Word, Word\_Components and Parameter.
2. Drag the units into the T\_Office\_Word library.

Cleaning up parameters

1. Remove the Parameter unit of all parameters that are already available in the Word.Parameter unit.
2. Move all other parameters into the unit Word.Parameter.
3. Delete the Parameter unit.

Undoing visibility

1. Open the T\_Mechatronic\_ModularSystem library.
2. Open the editor page Imported libraries.
3. Select the T\_Office\_Word library.
4. Press the key [Del].
5. Save the library.

# Specify level configuration

In the next step, the composition rules are defined, that is, which subcomponents and/or sublevels are permitted in a component (see [Architecture model](tutorial_k_example_feeder_architecture.htm)). The result of the definition of permitted sublevels are hierarchy levels:

![](../Pictures/Mechatronik_Architektur_10.png)

1. In T\_Mechatronic\_Architecture, in the Levelcomponents unit, open the Station component, and switch to the Level configuration editor page.
2. Click ![](../Pictures/new.png) to open the Finder dialog; there, select Functiongroup.
3. Repeat Steps 1 and 2 for Functiongroup with Functionunit sublevel.
4. Repeat Steps 1 and 2 for Functionunit, and assign the two sublevels Actuator and Sensor to this component (also possible in a single step via multiple selection in Finder!).
5. Repeat Steps 1 and 2 for Actuator and assign the Actuator sublevel to this component.

# Create macro boxes for sensors

Now, a fragment is prepared as a macro from each single sensor together with the associated plug.

1. Select Insert > Box / connection point / mounting panel > Macro box.
2. Drag a macro box around each sensor together with the plug. The elements framed by the macro box may have to be moved first to a free position on the page. Make sure that the sensor and plug maintain their positions to each other.

![](../Pictures/tutorial_p8_makrokasten_sensor_induktiv.png)

1. Highlight the macro box.
2. Select Edit > Properties.

The dialog Properties (components): Macro box opens.

1. In the Name field, enter the text PLC\_Inputs\Sensor\_Inductive.

![](../Pictures/Gui/ALL/note.png)Note:

1. Open the Display tab.
2. Click [New].

The Property selection dialog opens:

1. Select Macro: Name.
2. Confirm with [OK].

You return to the Properties (components) macro box dialog.

1. Confirm with [OK].
2. Repeat steps 1 to 10 for the other two sensors. As the name of the other sensors, enter the texts PLC\_Inputs\Sensor\_Pressure and PLC\_Inputs\Sensor\_optical.

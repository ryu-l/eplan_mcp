# Support for placeholders with value sets

If a parameter has been to the name field of a placeholder added (see the following figure), a parameter of the same name will be created when the resource is imported. The variables, then, will not be considered. During generation of the schematics the value set whose name equals the value of the parameter is assigned.

![](../Pictures/p8_platzhalter_variable.png)

If the assigned value set is missing, or EEC does not find the value set due to differing uppercase / lowercase spelling, an error message appears and the generation process is aborted.

Also during the generation process, the portion #<> of the parameter definition from the placeholder name is replaced. For example, the name #<Model> selection becomes the new name Model selection.

![](../Pictures/Gui/ALL/note.png)Note:

No more than one parameter definition may be entered in the name of the placeholder.

In the user preferences, it is possible to define that the macro boxes are retained so that the user has the macro-specific popup menu items (Update macros... etc.) available at the macro box. This option can be set separately for window macros and symbol macros. Both options are disabled by default.

Similarly you can specify the removal of placeholders created in the schematics in the user preferences.

# Tooltips

Tooltips, which appear, if the mouse cursor is positioned over a graphical object, can be specified for the components that are inserted as graphical objects in a GRAPH2D diagram (see the following figure).

![](../Pictures/graph2d_tooltip_text.png)

The element <property id="tooltip"> is used to configure a tooltip. The content of the tooltip is specified in the enclosing element <read value="Formula to text">.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code:](javascript:void(0);)

The following example code creates the tooltip, which is shown in the above figure.

```
<node id="Component">
	<figureImage figure="com.mind8.graph2d.figure.Image">
	<properties>
	<property id="tooltip">
	<read value="=name"/>
	</property>
	</properties>
	..</figureImage>
</node>
```

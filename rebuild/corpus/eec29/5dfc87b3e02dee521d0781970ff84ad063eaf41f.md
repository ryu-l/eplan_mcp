# Adding plugs and sockets to Text discipline components

Using the corresponding sockets for chapters and plugs for lines, it is now possible to assign the lines to the correct chapters:

![](../Pictures/tutorial_plug_socket_3.png)

1. Open the text component Sensors\_Actuators\_Chapter in the ListOfComponents unit.
2. Switch to the Parameters editor page.
3. Click on the Add parameter symbol and select the Socket parameter in the finder. Alternatively, you can also use drag & drop to add the Socket parameter.
4. Add the Plug parameter to the text component Sensors\_Actuators\_Line by repeating steps 1 to 3.

![](../Pictures/tutorial_plug_socket_4.png)

1. [Double](glossary_o_double.htm)-click to open the component Feeder in the T\_Mechatronic\_ModularSystem library in the Stations unit.
2. Click to select the Actuators\_Chapter component. The corresponding parameter table now opens.
3. Enter Actuators as the value for the Socket parameter.
4. Repeat the previous two steps to add the Sensors value to the Sensors\_Chapter at the Feeder component.

![](../Pictures/tutorial_text_plug_aktoren.png)

1. To enter the Actuators plug parameter value to the two actuators Valve and Cylinder (both in the Actuators subunit in the Mechatronic unit) in the component Sensors\_Actuators\_Line, perform steps 5 to 7.

![](../Pictures/tutorial_text_plug_sensoren.png)

1. Repeat steps 5 to 7 for the non-abstract sensors (in the Sensors subunit in the Mechatronic unit) as well and enter the Sensors plug parameter value in the component Sensors\_Actuators\_Line.

- Pressuresensor
- Positionsensor\_inductive
- Positionsensor\_optical

# relRef(String relativeName)

References the project components relativeName. Project components which are disabled cannot be referenced (see [Navigation methods for project components](refformulas_r_project_components_navigation.htm)).

| **relRef([String](glossary_o_string.htm) relativeName)** | | | |
| --- | --- | --- | --- |
| Arguments | String | relativeName | Relative path to a project component |
| Return value | Project component |  | The referenced project component |

# Generating all macros

All preparations for the macros are completed.

Now all macros will be generated together:

1. Select Project data > Macros > Generate automatically.
2. Mark the Overwrite existing macros option.
3. Mark the Apply to entire project option.
4. Close P8.

The macros will be stored in the following directories:

```
<EEC installation folder>\resources\Tutorial\P8\Page
<EEC installation folder>\resources\Tutorial\P8\PLC_Inputs
```

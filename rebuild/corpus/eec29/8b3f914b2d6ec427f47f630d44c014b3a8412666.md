# Xrunjdwp:transport

| EEC argument | Usage |
| --- | --- |
| -Xrunjdwp:transport=dt\_socket, server=y, suspend=n, address=<port number> | Only for eeLide |
| **Annotation** | |
| To create a channel from the EEC runtime environment back to the EEC development environment for debugging purposes.  Example:   ``` -Xrunjdwp:transport=dt_socket, server=y, suspend=n, address=5005 ``` | |

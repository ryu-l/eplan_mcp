# Calling script in scripts

Scripts can be called in other scripts. The following fragment can be used to call a script:

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code in Groovy:](javascript:void(0);)

```
import com.mind8.mechatronic.skill.eos.TypeClass;
TypeClass.findType(self.getUnitOfWork(),<AbsoluteName>).perform(
<MethodName>,<Argument1>,<Argument2>,...);
```

This runs with up to 10 arguments, beyond that an array has to be used (the array can also be used with less than 10 arguments).

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code in Groovy:](javascript:void(0);)

```
import com.mind8.mechatronic.skill.eos.TypeClass;
argumens=new Object[]{<Argument1>,<Argument2>,...,<Argument23>};
TypeClass.findType(self.getUnitOfWork(),<AbsolutName>).perform(
<MethodName>,arguments);
```

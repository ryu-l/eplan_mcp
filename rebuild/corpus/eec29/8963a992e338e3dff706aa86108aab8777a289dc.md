# pathLocation

The element <pathLocation> encompasses the definition of the file extensions permissible for the file selection.

| Attribute name | Usage | Attribute values | Default value | Description |
| --- | --- | --- | --- | --- |
| text | required |  |  | Directory path that is opened upon starting the file selection window. |

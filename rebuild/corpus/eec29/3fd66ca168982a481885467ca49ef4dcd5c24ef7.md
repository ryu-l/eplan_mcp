# Import T_ListOfComponents_Architecture

To add a ListOfComponents to T\_Mechatronic\_ModularSystem, the T\_ListOfComponents\_Architecture library has to be imported:

![](../Pictures/Komponentenliste_11.png)

1. [Double](glossary_o_double.htm)-click to open the T\_Mechatronic\_ModularSystem library.
2. Click on Imported Libraries to switch to the corresponding editor page.
3. Move the T\_ListOfComponents\_Architecture library to the Imported libraries diagram.

# com.mind8.script.debug.modus.enable

The EEC argument must be transferred with the following syntax:

```
-D<Argument>=<Value>
```

| EEC argument | Usage |
| --- | --- |
| -Dcom.mind8.script.debug.modus.enable=<true/false> | Optional |
| **Annotation** | |
| The script debug mode is enabled via this value.  Possible values are true and false, i.e.,   ``` -Dcom.mind8.script.debug.modus.enable=true ```   or   ``` -Dcom.mind8.script.debug.modus.enable=false ``` | |

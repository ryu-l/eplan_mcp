# prependAll(Collection coll)

Inserts all objects of the Collection coll at the beginning of the list.

| prependAll(Collection coll) | | | |
| --- | --- | --- | --- |
| Argument | Collection | coll | Collection to be inserted. |
| Return value | List |  | |

# deleteAllInstanceParameters

Deletes all parameters of the project component with the absolute path.

| deleteAllInstanceParameters(String instanceAbsPath) | | | |
| --- | --- | --- | --- |
| Argument | [String](glossary_o_string.htm) | instanceAbsPath | Absolute path to the project component. |
| Return value | [Boolean](glossary_o_boolean.htm) | true = all parameters have been deleted successfully. false = no parameter has been deleted. | |

# nodeCreation

If the project structure contains instances that still have to be inserted in the diagram, they can be collected in the palette by means of an appropriate configuration and can then be inserted from the palette into the diagram. The new <nodeCreation> tag creates a palette entry for each project component, which can be determined by the formula of the attribute entries. By marking the palette entry the node is attached to the mouse cursor and can be placed in the diagram by a single click.

If a node, which is determined by a formula of the attribute entries is deleted from the diagram, it is put back to the palette.

| Attribute name | Usage | Attribute values | Default value | Description |
| --- | --- | --- | --- | --- |
| entries | required |  |  | Formula to determine project components to be collected in the palette. |

| Allowed sub-elements | Quantity |
| --- | --- |
| none |  |

The example identifies all nodes of the BodyShellWork\_Architecture.LevelComponents.SafetyCircuit project components and adds those that are inserted in the BodyShellWork diagram to the palette.

```
<paletteEntry id="SafetyCircuitCreation" group="Components" text="=$Designation"
	smallIcon="=type('BodyShellWork_ModularSystem.Diagram_Configuration.Planning_Diagram.
	Palette_SafetyCircuit_ObjectCreation').getImage"
	largeIcon="=type('BodyShellWork_ModularSystem.Diagram_Configuration.Planning_Diagram.
	Palette_SafetyCircuit_ObjectCreation_24').getImage">
	<nodeCreation entries="=rmos('BodyShellWork_Architecture.LevelComponents.SafetyCircuit')"/>
</paletteEntry>
```

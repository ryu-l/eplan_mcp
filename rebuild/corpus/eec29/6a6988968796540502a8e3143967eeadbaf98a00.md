# com.mind8.formui.perspective.object

Das EEC-Argument muss mit der folgenden Syntax übergeben werden:

```
-D<Argument>=<Value>
```

| EEC-Argument | Verwendung |
| --- | --- |
| -Dcom.mind8.formui.perspective.object=absolutePath | Optional |
| **Erläuterung** | |
| Startet EEC mit einem bestimmten Form-UI im Form-UI-Editor.  absolutePath referenziert die Projektkomponente, die das anzuzeigende Form-UI enthält.  Beispiel:   ``` -Dcom.mind8.formui.perspective.editor=Feeder.Mechatronic.Feeder ``` | |

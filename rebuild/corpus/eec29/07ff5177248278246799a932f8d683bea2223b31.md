# Comments

For very large Form-UIs it is a good help to comment parts of it.

Comments always start with <!-- and end with -->. In between may lie a few comments, but also entire program sections.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code for a comment line:](javascript:void(0);)

```
<!-- Dies ist eine Kommentarzeile -->
```

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code for a commented program block:](javascript:void(0);)

```
<!-- Die folgende Tabelle ist auskommentiert
<table columns="2"
..<td> ? </td>
..<td> ? </td>
..<td> ? </td>
..<td> ? </td>
</table>
-->
```

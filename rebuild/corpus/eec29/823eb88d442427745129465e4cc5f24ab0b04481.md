# Navigation methods for root objects

The following methods of mechatronic components are available in the scripts also for mechatronic root objects (not discipline root objects):

- mos
- rmos

These methods are available for mechatronic and discipline root objects:

- existsRelRef
- relRef

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code determines the project and the mechatronic root object:](javascript:void(0);)

```
import org.foederal.apache.log4j.SpaceLogger;
SpaceLogger logger = SpaceLogger.getSpaceLogger("Test project, getProject and mroot");
//arg0 is an object of MechatronicComponent
logger.info(arg0);
//returns the project
pro = arg0.project();
logger.info(pro);
//returns the project
getPro = arg0.getProject();
logger.info(getPro);
//returns the mechatronic root object
getmroot = arg0.mroot();
logger.info(getmroot);
return null;
```

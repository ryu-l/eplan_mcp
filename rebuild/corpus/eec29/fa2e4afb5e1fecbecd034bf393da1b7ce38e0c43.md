# Parameter name for the prefix

Path to model variable:

Disciplines > ECAD > EPLAN Electric P8

Specify the name of a parameter. Add this parameter to the P8 discipline components. The value of the parameter in the discipline components defines the prefix for the identifier of the device tag.

# notEmpty()

Returns true if the map includes key-value pairs.

| notEmpty() | | | |
| --- | --- | --- | --- |
| Argument |  |  |  |
| Return value | [Boolean](glossary_o_boolean.htm) | true for a filled map false for an empty map | |

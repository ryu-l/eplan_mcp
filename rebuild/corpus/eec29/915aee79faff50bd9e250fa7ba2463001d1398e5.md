# Roots

When creating a project configuration or creating a structure, roots are created automatically below which the objects of the model will be inserted.

![](../Pictures/wurzelobjekte.png)

These roots are now defined as objects in the system libraries, so that they can be assigned actions.

- DisciplineRoot
- AutomationWorXRoot
- CoDeSysRoot
- EcadRoot
- PowerpointRoot
- Step7Root
- TextDisciplineRoot
- WordRoot
- MechatronicRoot

# The help system

The EPLAN help system contains conceptual information, instructions and dialog descriptions on most functions of the program. The help system is displayed on your computer in the default Internet browser. The help system can be used context-specifically via [F1] or context independently.

Most chapters are split into the following subchapters:

![](../Pictures/Gui/ALL/helpsystem_info_as.png) Basics

![](../Pictures/Gui/ALL/helpsystem_action_as.png) How it works

![](../Pictures/Gui/ALL/helpsystem_reference_as.png) Reference.

In addition to the EPLAN help, the help system also includes the ![](../Pictures/Gui/ALL/helpsystem_overview_as.png) "EPLAN overviews". Here you receive additional information on special topics (for example EPLAN properties and placeholder elements). The ![](../Pictures/Gui/ALL/helpsystem_message_as.png) icon is used for help pages that describe check run messages.

# Preparatory steps in EEC

The following steps are required to prepare the tutorial.

### [ClosedImport EOX files for Word tutorial](javascript:void(0);)

Before the Word discipline can be edited, the T\_Mechatronic\_Architecture and T\_Mechatronic\_ModularSystem libraries created in the chapter [Mechatronic](tutmechatronic_h_mechatronic.htm) have to be available.

If the T\_Mechatronic\_Architecture and T\_Mechatronic\_ModularSystem are not available, please import the following [EOX](glossary_o_eox.htm) file:

```
<EEC-Installationsordner>\install\Tutorial\Mechatronic\Mechatronic.eox.
```

Predefined SequenceSelectionActions used to create and open the discipline structure, the code, and the PDF file can be found in this EOX file:

```
<EEC-Installationsordner>\install\Tutorial\Word\Word_Ui.eox.
```

See also:

[Importing libraries/projects as an EOX file](eecbase_k_eox_exchange_library_import.htm)

### [ClosedCustomizing a model variable](javascript:void(0);)

Various model variables can be customized for Word. Only the Name for Unit for Word Parameter model variable has to be changed in order to create a connection to the existing parameters when importing the Word resources and to ensure that parameters of the same name are not created in a new unit.

1. Select Model > Model variables.
2. Navigate to Disciplines > Office > Word.
3. Enter the value true for the model variable Create Parameters On Demand.
4. Enter the value true for the model variable Create Parameter Units On Demand.

### [ClosedImporting libraries](javascript:void(0);)

To use the Word function in the T\_Mechatronic\_ModularSystem library, it is necessary to import the Word system library. Likewise, the Word\_Ui and Word\_Customizing libraries must be imported to use predefined SequenceSelectionActions. First, import the MediaSource library. This will allow you to insert image objects in the Word file.

![](../Pictures/tutorial_word_bibliothek_importieren.png)

1. Open the Imported libraries editor.
2. Click ![](../Pictures/button_finder.png) to open the library finder dialog. Select the Word and Word\_Ui libraries here. The Word\_Customizing library is already contained in the Word\_Uilibrary.
3. Confirm with [OK].
4. Repeat steps 1 to 3 for the MediaSource library.

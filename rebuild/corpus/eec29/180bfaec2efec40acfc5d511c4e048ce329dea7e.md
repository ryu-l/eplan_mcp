# Importing project changes

The following sequence describes how to import project changes from a \*.px file. The successful import of project changes requires that there is no project of the same name.

1. Click File > Import.

![](../Pictures/eec_datei_importieren.png)

The Import dialog opens:

![](../Pictures/projectexchange_import_auswaehlen.png)

2. Highlight Model > Project Exchange Format (PX format).
3. Click [Next >].

The Import project changes dialog opens:

![](../Pictures/projectexchange_import_project.png)

4. Select the PX file to be imported.
5. Highlight the project whose changes you wish to import.
6. Click Finish.

The imported project is then listed in the project catalog (see the following figure).

![](../Pictures/projectexchange_import_projectexplorer.png)

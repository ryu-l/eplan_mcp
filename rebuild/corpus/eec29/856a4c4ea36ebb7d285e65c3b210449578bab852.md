# existsRelRef(String relativeName)

Determines if the project component given by relativeName is referencable. Project components which are disabled cannot be referenced.

| existsRelRef([String](glossary_o_string.htm) relativeName) | | | |
| --- | --- | --- | --- |
| Arguments | String | relativeName | Relative path to a project component |
| Return value | [Boolean](glossary_o_boolean.htm) |  | |

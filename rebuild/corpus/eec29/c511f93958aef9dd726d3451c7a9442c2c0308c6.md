# com.mind8.formui.perspective.editor

The EEC argument must be transferred with the following syntax:

```
-D<Argument>=<Value>
```

| EEC argument | Usage |
| --- | --- |
| -Dcom.mind8.formui.perspective.editor=absolutePath#Page:Form-UI-ID | Optional |
| **Annotation** | |
| Starts EEC with a specific Form-UI in the Form-UI Editor.  absolutePath references the project component that contains the Form-UI to be displayed.  Form-UI-ID references the Form-UI of the project component  Example:   ``` -Dcom.mind8.formui.perspective.editor=Dokumentation_UI_Konfiguration. Mechatronik.Dokumentation#Page:start ``` | |

# Side-by-side mounting of devices with mounting parts

When mounting devices with (asymmetrical) mounting parts side-by-side on a mounting rail, handle M4 cannot be placed directly on handle M2. Prior to positioning, it is necessary to determine the widths of all of the mounting parts available between the already-mounted devices and the devices to be mounted. These widths should then be used as an offset (dx).

This specification is made using the following syntax:

```
=List{'M4','M2',<dx>}
```

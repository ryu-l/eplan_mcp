# appendAll(Collection coll)

Inserts all objects of the Collection coll at the end of the list.

| appendAll(Collection coll) | | | |
| --- | --- | --- | --- |
| Argument | Collection | coll | Collection to be inserted. |
| Return value | List |  | |

# Duplicating an installation with FastObjects DBMS for the data maintenance

Before an installation is duplicated the database model and the user preferences should be exported  (see [Exporting the current information model](admin_h_backup_export_current_model.htm)).

Stand-alone installation:

When installing using the setup program, a different target folder and a different path must be specified for the start menu entry.

After the installation import the previously exported database model and the user preferences (see [Importing model data](admin_h_maintenance_model_import.htm)).

Client-Server installation:

Generally, the same applies to the Client-Server installation as for the Stand-Alone installation.

After the installation, the ec.ini file also needs to be adjusted in such a way to ensure that the correct folders Workspace and Configuration are referenced.

# Navigation

The usual navigation with link attributes, as known for websites, is created with the element <open>. Furthermore it is possible to provide the elements <label> and <input> with links, which, however, are not be represented in the usual formatting and equipped with the usual behavior (see [label](refformui_r_label.htm) and [input](refformui_r_input.htm)).

Editable and controllable items in Form-UIs can be accessed by the tab key. In this case the items are accessed in the order upper left to lower right. The order is reversed if the Shift key is pressed.

# defaultValue()

The defaultValue method returns the expression for the default value of a parameter. Returns an empty string if no default value is set.

| defaultValue() | | | |
| --- | --- | --- | --- |
| Argument |  |  |  |
| Return value |  | The expression for the default value of a parameter | |

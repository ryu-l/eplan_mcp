# Using values for plugs and sockets

Thus far, only discipline components with an abstract and a concrete derivation have been assigned parameters and parameter values.

There are still no parameters or parameter values for the following discipline components, which are also installed in the Feeder station.

- WiringDiagram
- LayoutSpace
- MountingPanel
- Plane

We begin by assigning parameters to the discipline components:

1. Open the WiringDiagram component in the ProPanel unit.
2. Open the Parameter editor.
3. Drag the Socket parameter from the Parameter unit in the editor.
4. Repeat steps 1 to 3 for the LayoutSpace component and the Plug and Socket parameters.
5. Repeat steps 1 to 3 for the MountingPanel and Plane components and the Id, Plug and Socketparameters.
6. The next step is to assign values to the parameters.
7. Open the Feeder component.

![](../Pictures/tutorial_pp_plug_socket_angeben.png)

1. Select the installed WiringDiagram component.
2. For the Socket parameter, enter the value LayoutSpace.
3. Repeat steps 8 and 9 for the following components with the parameter values from the following table:

| [Component](glossary_o_component.htm) | [Parameter](glossary_o_parameter.htm) | Value |
| --- | --- | --- |
| LayoutSpace | [Plug](glossary_o_plug.htm) | LayoutSpace |
| [Socket](glossary_o_socket.htm) | Enclosure |
| AE1050\_500 | Plug | Enclosure |
| Socket | EnclosureMounted |
| MountingPanel | Plug | EnclosureMounted |
| Socket | MP\_Plane |
| Plane | Plug | MP\_Plane |
| Socket | PlaneMounted |

The hierarchy of Pro Panel components can be recognized by the values for Plug and Socket.

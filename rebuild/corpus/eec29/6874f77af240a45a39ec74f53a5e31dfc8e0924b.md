# rmos(String typeName, Integer depth)

rmos(typeName, depth) returns all children of the mechatronic component to the depthlevel, which correspond to the type typeName.

| **rmos([String](glossary_o_string.htm) typeName, [Integer](glossary_o_integer.htm) depth)** | | | |
| --- | --- | --- | --- |
| Arguments | String | typeName | Type of the components to be determined |
| Integer | depth | Subordinate hierarchy level in which mechatronic components are determined |
| Return value | List |  | |

# getOutputDirectoryForProjectName(String projectName, Boolean createFolder)

Determines the output folder for the created files for the specified project name. If no folder exists, it can be created if required. The output folder is session-specific for the Job Server and Web EEC, meaning that it contains the session ID.

| getOutputDirectoryForProjectName([String](glossary_o_string.htm) projectName, [Boolean](glossary_o_boolean.htm) createFolder) | | | |
| --- | --- | --- | --- |
| Argument | String | projectName | Project name |
| Boolean | createFolder | true = output folder is created false = output folder is not created |
| Return value | String | | Absolute path of the output folder |

Requirements:

For this example an action for OpenResourceCommand is to be created in the library with the name Customizing\_Engineering. This library is to be imported into the library with the Form-UI.

```
<action type="link" name="Customizing_Engineering.OpenResourceCommand"
arguments="List{mroot.project,
type('Customizing_Engineering.UtilAPI').getOutputDirectoryForProjectName(mroot.project.name, true)}">
Download file
</action>
```

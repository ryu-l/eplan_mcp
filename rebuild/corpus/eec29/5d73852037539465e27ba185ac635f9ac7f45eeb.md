# left(Integer x)

Delivers the first x characters of the character string starting on the left.

| **left([Integer](glossary_o_integer.htm) x)** | | | | |
| --- | --- | --- | --- | --- |
| Argument | Integer | x | Number of characters starting on the left. | |
| Return value | [String](glossary_o_string.htm) | | New character string with the first x characters starting on the left. | |

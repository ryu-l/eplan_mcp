# Enclosing discipline components in mechatronic components

In the course of the tutorial discipline components were created once through a mass import. Then formulas (for example to calculate a plug) were entered for the parameter values.

If a macro was changed, for example another parameter added and the discipline component synchronized with the changed macro, the parameter values were lost.

For this reason each discipline component is enclosed (encapsulated) in a mechatronic component. In the mechatronic component the same parameters are created and the formulas inserted. The parameters of the discipline components then always reference the parameters (interface parameters) of the same name of the encapsulating mechatronic components. After a synchronization you then only have to insert the references on the interface parameter again.

### [ClosedCreating a unit for mechatronic components](javascript:void(0);)

The encapsulating mechatronic components are to be created in a unit parallel to Word\_Components.

1. Select the T\_Office\_Word library.
2. Select New > Unit in the shortcut menu.
3. Specify the Wrapper name.
4. Save the unit.

### [ClosedCreating mechatronic components](javascript:void(0);)

For each mechatronic component an encapsulating mechatronic component now has to be created.

Creating encapsulation for the discipline components

1. Select the new Wrapper unit.
2. From the popup menu select New > Mechatronic > Function.
3. Specify the M\_Body name.
4. Switch to the Interfaces editor page.
5. Click ![](../Pictures/button_finder.png) to open the Finder dialog.
6. Click [Search].
7. Select the IBody.
8. Confirm with [OK].
9. Drag the Body discipline component into the component editor.
10. Select the installed discipline component Body.
11. Mark all parameters.
12. Select Add interface temperature from the popup menu.
13. Save the component.
14. Repeat steps 1 to 13 with the names M\_Chapter with the interface IChapter and the discipline component Chapter.
15. Repeat steps 1 to 13 with the names M\_Row with the interface IRow and the discipline component Row.

A reference to the parameter of the superior component (capsule) by the same name is now entered as the value. These parameters were inserted into the capsule during the same step. The parameter values are entered at a later step.

### [ClosedAdding plugs and sockets to discipline components](javascript:void(0);)

To generate the Word discipline structure independent of the structure of the mechatronics, the discipline components have to be extended with plugs and sockets.

This takes place in two steps:

1. Extend the discipline components with the parameters [Plug](glossary_o_plug.htm) and [Socket](glossary_o_socket.htm).
2. Extend the encapsulating mechatronic components.

Extending Plugs and Sockets to discipline components:

1. Open the component Body.
2. Open the Parameters editor page.
3. Drag the Socket parameter from the Word.Parameter unit in the editor.
4. Repeat steps 1 to 3 for the Chapter component with the Plug and Socket parameters.
5. Repeat steps 1 to 3 for the Row with the parameter Plug.

Extending encapsulating mechatronic components:

1. Open the component M\_Body.
2. Select the installed Body discipline component.
3. In the editor open the popup menu of the Socket parameter.
4. Select Adding interface temperature.
5. Save the editor.
6. Repeat steps 1 to 5 for the M\_Chapter and M\_Row components with the newly added Plug and Socket parameters.

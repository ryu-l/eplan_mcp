# Navigating from a macro in P8 to a macro in EEC

During the development phase the possibility is helpful to navigate from a macro in the generated schematic to the macro in the mechatronic modular system.

Requirements:

- An action for P8 is set up.
- The optional P8 Integration Service Feature function is installed.
- The option Delete placeholders after generation is deactivated in the user specifications.

### [ClosedSetting up Action for P8](javascript:void(0);)

EEC makes the XML file EEC\_P8\_Kopplung\_Symbolleiste.xml available that is to be imported from EPLAN Electric P8. The XML file is located in the following folder:

<EEC installation folder>\install\eplanP8

1. Open EPLAN Electric P8.
2. Open the popup menu of the toolbar.
3. Click Import....
4. Select the EEC\_P8\_Kopplung\_Symbolleiste.xml XML file.
5. Click [Open].

Then a floating toolbar with the name EEC is available. This toolbar contains the icon ![](../Pictures/icon_opencorrespondingmacro.png) (Open corresponding macro) to start the action for P8.

### [ClosedInstalling an optional function](javascript:void(0);)

The optional function P8 Integration Service Feature has to be installed to be able to use the navigation from P8 to EEC:

1. Start EEC
2. Open Help > Install new software....
3. In the Use field select the --All available sites-- or de.eplan.eec.install.optfeatures entry from the drop-down list.
4. Expand the EC Optional Features path.
5. Select the P8 Integration Service Feature entry.
6. Click [Next >].

The function to be installed is only listed so that the selection can be checked.

1. Click [Next >].
2. Accept the license terms.
3. Click [Finish].

If a schematic has been generated successfully, you can navigate from each macro of the schematic to the corresponding discipline component in the configuration.

1. Select a macro in the schematic.
2. Click ![](../Pictures/icon_opencorrespondingmacro.png) (Open corresponding macro) in the EEC toolbar.

The corresponding discipline component opens in EEC.

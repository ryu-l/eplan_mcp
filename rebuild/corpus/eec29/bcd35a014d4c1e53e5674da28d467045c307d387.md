# Coupler

A coupler can represent junctions between all kinds of communication channels. The point here is not logs, but the logical allocation of hardware. Bus couplers and communication modules, for example, can be represented in this way. From the perspective of control technology, it may sometimes seem advantageous to subdivide the same channel. In this way, for example, signals belonging to different emergency-off areas can be consolidated into separate logical channels that nevertheless physically constitute a single bus. The Coupler object must be equipped with the parameters for structure formation and must implement the ICoupler interface if the IO generator is to be used for address calculation.

# Create copies of pages

Create the first copy of the 1 Sensors page for the window macro:

1. If necessary, open the Macro\_Project project again.
2. Highlight the 1 Sensors page.
3. Select Edit > Copy.
4. Select Edit > Insert.

The Adapt structure dialog opens.

1. Enter 1a in the Page name field.
2. Confirm with [OK].

The Insertion mode dialog opens:

1. Select the Do not modify option.
2. Confirm with [OK].

Change the description of the 1a Sensors page in the page properties:

1. Highlight the 1a Sensors page.
2. Select Edit > Properties.

The Page properties dialog opens.

1. Enter Page in the Page description field.
2. Confirm with [OK].

You must also create a copy of the 1 Sensors page for the fragments of the sensors:

1. Copy the 1 Sensors page.
2. Enter 1b in the Page name field.
3. In the Insertion mode dialog select the Do not modify option.
4. Confirm with [OK].

Now the Macro\_Project project should contain the following pages:

- 1 Sensors
- 1a Page
- 1b Sensors
- 2 Sensors

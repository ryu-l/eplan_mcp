# hasRole(String role)

Delivers true if the authorized EEC user has the assigned user role, otherwise false is delivered.

| **hasRole([String](glossary_o_string.htm) role)** | | | | |
| --- | --- | --- | --- | --- |
| Argument | String | role | User role | |
| Return value | [Boolean](glossary_o_boolean.htm) | | true = user has the assigned user role false = user has another user role | |

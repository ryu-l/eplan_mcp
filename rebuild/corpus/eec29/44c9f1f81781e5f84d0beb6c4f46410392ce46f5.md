# Changing the EOX back-end

After the first start with selection of a [EOX](glossary_o_eox.htm) file for data management, EEC always starts with this EOX file.

Via the menu File > Switch back-end the dialog for selecting a EOX file as well as a previously used EOX file can be selected.

![](../Pictures/eox_choose_backend.png)

1. Click on File > Switch back-end.
2. Mark a previously selected EOX file.

The data model is immediately changed to the selected EOX file.

3. Click Choose.

The dialog Choose new backend opens.

![](../Pictures/eox_select_backend_1.png)

4. Select a EOX file
5. Confirm your selection with [OK].

The selected file appears in the list of previously selected EOX files at the next time the data basis should be switched.

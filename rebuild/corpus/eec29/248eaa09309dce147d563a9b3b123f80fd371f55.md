# Formulas

Formulas are enclosed in (\*{ and }\*) in the text generator language. Any formulas described in the [Formula language](JavaScript:TL_1902662.HHClick()) can be used. this, by default, is for formulas, the object for that the text is generated In LOOP elements without variable, this is the object, that is to be iterated over.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
(*{1+1}*)
```

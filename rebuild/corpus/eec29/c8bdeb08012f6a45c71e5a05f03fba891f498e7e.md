# -xmx

| EEC argument | Usage |
| --- | --- |
| -Xmx<value>m | Optional |
| **Annotation** | |
| Maximum RAM that is made available to the application by the operating system.  It is measured in megabytes (m).  The value set should not exceed 50% of the physically available memory.  For example, 256 or 1024  Standard setting for Stand-alone and Worker installation:   ``` -Xmx1536m ```   Standard setting for Job Server installation:   ``` -Xmx1792m ``` | |

# property(String key)

The property method allows accessing to the values of the parameters that were passed in the call of the WebEEC page.

This way you can pass the available data of a superior system to the EEC model.

Syntax:

```
http://<host>:<port>?<parameter name 1>=<value>&<parameter name x>=<value>
```

| **property([String](glossary_o_string.htm) key)** | | | | |
| --- | --- | --- | --- | --- |
| Argument | String | key | Key, whose value should be returned. | |
| Return value | String | | The value of the key | |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Examples](javascript:void(0);)

```
http://xxx.xxx.xxx.xxx:xxxx?orderno=996633&type=N36M45
```

The values of the parameters with the following formulas are considered in the EEC model:

Formula for orderno: =type('Engineering.System').property('orderno')

Formula for type: =type('Engineering.System').property('type')

For the model development you can simulate web calls by means of entries in the initialization file (ec.ini).

The parameter passing follows in the initialization file of this syntax:

-Dcom.mind8.rap.<parameter name>=<value>

To simulate the parameter passing of the example above the names of entries in the initialization file are as follows:

```
-Dcom.mind8.rap.orderno=996633
-Dcom.mind8.rap.type=N36M45
```

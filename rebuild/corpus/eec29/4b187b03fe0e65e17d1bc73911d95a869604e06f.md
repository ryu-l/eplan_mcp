# performEvent

Defines the action to be performed. The name of the action and a list of arguments for the run method are supplied as arguments.

| Attribute name | Usage | Attribute values | Default value | Description |
| --- | --- | --- | --- | --- |
| name | required | any |  | Absolute name of the action |
| arguments | required | List |  | List of arguments which are passed to the run method of the action |

| Allowed sub-elements | Quantity |
| --- | --- |
| none |  |

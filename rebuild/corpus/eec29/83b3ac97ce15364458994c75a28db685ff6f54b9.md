# <xsl:attribute> with value

The following rule creates an attribute name in the target document with the value of the attribute NAME in the original document.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code:](javascript:void(0);)

```
<xsl:attribute name="name">
	<xsl:value-of select="NAME">
</xsl:attribute>
```

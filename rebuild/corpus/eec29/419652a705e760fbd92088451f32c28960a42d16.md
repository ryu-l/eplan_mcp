# Replace parameters

Replace parameters are used to replace parts of the template whilst generating. The opening and closing tokens are specified in the text discipline configuration resp. in the user configurations for the PLC disciplines (e.g. opening token = âM8B\_â closing token = â\_M8Eâ). The tokens must be defined in a way, that no conflicts with existing names in the text, which is to generate, appear (e.g. < as the opening token in XML documents). The text between the tokens appears in the interface as parameter. The parameter for the PLC disciplines is declared by the variable type REPLACE.

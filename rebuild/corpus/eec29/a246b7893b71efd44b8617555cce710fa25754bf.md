# CoordinateMap

By specifying the CoordinateMap parameter, objects are positioned in a map via the X and Y coordinates.

The coordinates are specified using the following syntax:

```
=Map{Pair{'x',<X-coordinate>}, Pair{'y',<Y-coordinate>}}
```

When freely positioning, for example, a wire duct on a mounting plate, the X and Y coordinates of handle V1 on the mounting plate refer to the V1 mounting point on the wire duct.

When positioning a device on a mounting rail, the X position of handle M4 on the mounting rail refers to the M2 mounting point on the device. The Y-coordinate specification is ignored in this case.

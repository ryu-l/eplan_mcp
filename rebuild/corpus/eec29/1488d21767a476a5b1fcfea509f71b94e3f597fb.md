# Create macro box

Now create a macro box that combines all symbols of this page into a macro.

1. Select Insert > Box / connection point > mounting panel > Macro box.
2. Drag a frame around the power supply lines and PLC inputs.

![](../Pictures/tutorial_p8_makrokasten.png)

3. End the Macro box function using the ESC key.

Define the properties of the macro box.

1. Highlight the macro box.
2. Select Edit > Properties.

The Properties (components): Macro box (Properties (components): Macro box dialog opens.

![](../Pictures/tutorial_p8_makrokasten_eigenschaften1.png)

3. In the Name field, enter the file name Page\Page.

![](../Pictures/Gui/ALL/note.png)Note:

For the input of the name, German umlauts (Ã, Ã, Ã, ä, ö, ü) are not permitted, because the default EPLAN settings are used.

4. Open the Display tab.
5. Click on [New].

The Property selection dialog opens:

![](../Pictures/tutorial_p8_makrokasten_eigenschaften2.png)

6. Select from the list Macro: Name (Macro: Name).
7. Confirm with [OK].

You return to the dialog Properties (components): Macro box (Properties (components): Macro box).

![](../Pictures/tutorial_p8_makrokasten_eigenschaften3.png)

8. Confirm with [OK].

# existsRef(String absoluteName)

Determines if the project component given by absoluteName is referencable. Project components which are disabled cannot be referenced.

| **existsRef([String](glossary_o_string.htm) absoluteName)** | | | | |
| --- | --- | --- | --- | --- |
| Arguments | String | absoluteName | The path to a project component | |
| Return value | [Boolean](glossary_o_boolean.htm) | |  | |

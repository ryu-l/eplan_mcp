# WatchDogCommand

Cancels the generation of a documentation after a specified time and issues a corresponding error message. With WatchDogCommand you can currently monitor the generation of EPLAN Electric P8 schematics and WORD documents.

| Argument | Type | Description |
| --- | --- | --- |
| timeout | [Integer](glossary_o_integer.htm) | Number of seconds after whose expiration a cancellation takes place. |
| commandName | [String](glossary_o_string.htm) | Name of the command to be executed. |
| commandObj | Object | The marked object. |
| killProcessName | String | Name of the process to be canceled.  Possible processes:  WINWORD.EXE  W3U.EXE |

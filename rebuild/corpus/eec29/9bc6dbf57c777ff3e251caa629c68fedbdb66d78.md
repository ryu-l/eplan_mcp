# getOutputDirectory(IProject project)

Returns a string that contains the path to the output directory in the workspace. In the event of an error, an exception is thrown.

| getOutputDirectory(IProject project) throws CoreException | | | |
| --- | --- | --- | --- |
| Argument | IProject | project | Project object |
| Return value | [String](glossary_o_string.htm) | | Path to the project folder in the workspace. |

The path to the project folder in the workspace. This path differs depending on whether a desktop or job server installation has been performed.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code:](javascript:void(0);)

```
import com.mind8.mechatronic.skill.AbsoluteNameUtil
proj=AbsoluteNameUtil.getObjectByAbsolutePath("Feeder ", UnitOfWork)
path = IUtilAPI.DEFAULT.getOutputDirectory(proj)
// This method returns e.g. the path "WS\Feeder\" within the regular context.
// This method returns e.g. the path "WS\Feeder\-etsehvxndtqz\" within the Job Server context.
```

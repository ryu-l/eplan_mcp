# connectionCreation

Indicates, that the palette element creates a connection.

Further elements, which are required for specifying of connections:

- [router](refgraph2d_r_router.htm)
- [connection](refgraph2d_r_connection.htm)
- [reference](refgraph2d_r_reference.htm)

| Attribute name | Usage | Attribute values | Default value | Description |
| --- | --- | --- | --- | --- |
| connection | required |  |  | Reference to the connection element |

| Allowed sub-elements | Quantity |
| --- | --- |
| none |  |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code:](javascript:void(0);)

The following example configures the entry for the order connection in the palette. The connection attribute specifies the corresponding configuration for the appearance of the connection.

```
<connection id="Order" reference="OrderReference" width="3" color="17,240,70" sourceDeco="empty" targetDeco="filled-arrow"/>
	<paletteEntry
	id="OrderConnection"
	group="Connections"
	text="Order"
	smallIcon="=type('BodyShellWork_ModularSystem.Diagram_Configuration.Planning_Diagram.
	Palette_Order_Connection').getImage"
	largeicon="=type('BodyShellWork_ModularSystem.Diagram_Configuration.Planning_Diagram.
	Palette_Order_Connection_24').getImage">
	<connectionCreation connection="Order"/>
</paletteEntry>
```

Result:

The order is displayed in the palette of the planning diagram with a small icon and the text Order.

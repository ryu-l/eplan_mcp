# Exporting authorization data

If authorization is used in projects, user data can be exchanged between models via export and import.

User data are exported via the administration tool.

![](../Pictures/ec_admin_menu_exportiere_benutzerdaten.png)

1. Export Authorization Data is called via the menu of the administrator view.
2. The Export Authorization Data dialog opens.

![](../Pictures/ec_admin_exportiere_benutzerdaten.png)

3. Any file name can be entered in the Export zip file name field.

The file system can be searched for a suitable file via [Browse...].

4. [Finish] starts the export of authorization data.

# Engineering.ExportPXCommand

Exports changes to the project to a PX file.

| Argument | Type | Description |
| --- | --- | --- |
| projectName | [String](glossary_o_string.htm) | Name of the project to export |
| absolutePXFilePath | String | Absolute name of the PX file to export to |
| withExtensions | [Boolean](glossary_o_boolean.htm) | Option indicating whether objects positioned on extension points should also be exported:  true = export objects that are positioned on extension points  false = do not export objects that are positioned on extension points |

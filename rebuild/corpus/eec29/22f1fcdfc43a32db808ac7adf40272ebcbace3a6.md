# Specify subcomponents of function units

Like the Functiongroups, the Functionunits, too, must be supplemented to include Actuators and Sensors.

1. Assign to Axis the following components:

- Cylinder
- Valve
- Rename Positionsensor\_inductive to Position\_1
- Rename Positionsensor\_inductive to Position\_2
- Rename Positionsensor\_inductive to Position\_3
- Rename Positionsensor\_inductive to Position\_4

2. Assign to Gripper the following components:

- Valve
- Pressuresensor

3. Assign to Orientationinspector and Stack each the Positionsensor\_optical component.
4. Assign to Separator the following components:

- Cylinder
- Valve
- Rename Positionsensor\_inductive to Position\_1
- Rename Positionsensor\_inductive to Position\_2

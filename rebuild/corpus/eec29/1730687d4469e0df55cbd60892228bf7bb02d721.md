# name

The parameter.name or Parameter().name method delivers the name of the parameter object whose formula is executed.

| name | | | |
| --- | --- | --- | --- |
| Argument |  |  |  |
| Return value | [String](glossary_o_string.htm) |  |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example](javascript:void(0);)

Given:

| [Parameter](glossary_o_parameter.htm) name | Value |
| --- | --- |
| Data | =Map{Pair{'Example1','A'},Pair{'Example2','B'},Pair{'Example3','C'}} |

With the following formula a value can then be determined from the map whose key corresponds to the name of the parameter:

| Formula | Result |
| --- | --- |
| Example3= if $Data.containsKey(parameter.name) then $Data.value(parameter.name) else '' | C |

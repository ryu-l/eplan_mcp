# Preparatory steps in EPLAN Electric P8

To prepare the creation of macros, copies of the compressed project file Tutorial\_P8.zw1 are created and variously re-saved.

The first copy (Template\_Project.elk) is saved as an empty template. When the structure is generated, the macros of the page and sensors are inserted in this file.

The second copy (Macro\_Project.elk) is saved as a macro project. This is used to create the macros for the page and the sensors:

![](../Pictures/2009022001.svg)

Create path for macros:

1. Start EPLAN Electric P8.
2. Select Options > Settings.
3. Navigate to User > Management > Directories.
4. Specify the <EEC installation folder>\resources\ECAD\Tutorial folder for the Templates.
5. Specify the <EEC installation folder>\resources\ECAD\Tutorial folder for the Macros.

Enter the folder where EEC is installed instead of EEC installation Folder. The EPLAN Electric P8 projects are stored in the default folder.

6. Confirm with [OK].

Restoring the project Tutorial\_P8.zw1:

1. Select Project > Restore > Project....
2. Select in the field Backup directory:

```
<EEC installation folder>\install\Tutorial\P8\Tutorial_P8.zw1
```

The file Tutorial\_P8.zw1 is automatically entered into the field Projects .

1. Enter into the field Project name the text Feeder.
2. Confirm with [OK].

Create the first copy of the Feeder project:

1. Select the Feeder project.
2. Select Project > Copy.

The Copy project dialog opens.

1. Select the Only header data option.
2. In the Target project field, enter the file name:

```
Template_Project.elk
```

1. Confirm with [OK].

Back up the Template\_Project project:

1. Select the Template\_Project project.
2. Select Project > Back up > Project...

The Back up projects dialog opens.

1. Select in the field Backup directory:

```
<EEC installation folder>\resources\ECAD\Tutorial
```

This directory should correspond to the path variable $(MD\_MACROS).

1. Confirm with [OK].

Create another copy of the Feeder project:

1. Select the Feeder project.
2. Select Project > Copy.

The Copy project dialog opens.

1. If necessary, highlight the Entirely incl. report option.
2. In the Target project field, enter the file name:

```
Macro_Project.elk
```

1. Confirm with [OK].

Change the settings of the Macro\_Project project:

1. Highlight the Macro\_Project project.
2. Select Project > Properties...

The Project properties dialog opens.

1. If required, open the Properties tab.
2. For the Type of project in the Value column, select Macro project.
3. Confirm with [OK].

Create the macro template as the basic project:

1. Highlight the Macro\_Project project.
2. Select Project > Organize > Create basic project.

The Create basic project dialog opens.

1. Navigate to the following folder: <EEC installation folder>\resources\ECAD\Tutorial.
2. Enter Macro\_Template.zw9 in the File name field.
3. Confirm with [Save].

Close the Feeder project:

1. Select the Feeder project.
2. Select Project > Close.

This completes all preparatory work.

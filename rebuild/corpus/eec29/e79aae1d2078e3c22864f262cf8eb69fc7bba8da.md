# de.eplan.eec.datasource.password

The EEC argument must be transferred with the following syntax:

```
-D<Argument>=<Value>
```

| EEC argument | Usage |
| --- | --- |
| -Dde.eplan.eec.datasource.<absolute path to datasource object>.password=<password> | Optional |
| **Annotation** | |
| By means of EEC arguments for the runtime environment the entries Connection URL, User, Password and Default table for a database component of the DatabaseDataSource type could be overruled.  The user password for the database is specified by the EEC argument de.eplan.eec.datasource.<absolute path to datasource object>.password.  Example:  The password to access the database of the datasource component Databases.SQL.PartsDB should be altered.   ``` -Dde.eplan.eec.datasource.Databases.SQL.PartsDB.password=xvfs45hj2N_7d ``` | |

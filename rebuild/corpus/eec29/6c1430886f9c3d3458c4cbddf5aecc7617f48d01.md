# Validation and error messages

During the input and prior to the saving of editors, a validation process takes place that checks the input value for plausibility and / or determines the validity of formulas.

All changes in the editor are calculated in two steps.

- The first step refers to the edited object in the open editor.
- If these changes where successful than in the second step the effects to the model are calculated and the feasibility and the model validity is checked.

This is all done in the background and for small changes and for small models it is quickly completed. The results of these changes are represented on the new editor page Validation (see the following figure).

![](../Pictures/editor_validierung.png)

For quickly identifying of the validation state the icon of the validation page (1) matches the status and the result of the validation process. The table of the editor contains the changes in sequence (2). If the effects to the model are calculated without errors and if the model is valid after the changes is shown underneath (3).

If validation produces an error, an error dialog opens up (see the following figure).

![](../Pictures/editor_validierung_fehlermeldung.png)

Using [Details >>], the dialog is expanded and shows the details of the error, for example, also the absolute name of the faulty component.

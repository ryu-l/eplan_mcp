# Parameter name for the sub-page number

Path to model variable:

Disciplines > ECAD > EPLAN Electric P8

Specify the name of a parameter. Add this parameter to the P8 discipline components. The value of the parameter in the discipline components defines the identifier Sub-Page Number.

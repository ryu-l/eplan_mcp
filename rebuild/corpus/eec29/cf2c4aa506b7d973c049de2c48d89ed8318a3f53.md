# Web EEC installation and configuration

Before the Web EEC is installed and configured, you must stop the service of the Tomcat web server:

1. Right-click the symbol of the Tomcat Monitor on the taskbar.
2. Select Stop service from the context menu.

The Web EEC is provided as a web archive with the file extension .war. This file format represents a JAR and / or ZIP archive, and can be opened and edited using a compression program, for example, 7-ZIP.

3. Extract the file webec.war to a folder of the same name.
4. Open the file \webec\WEB-INF\web.xml in an editor.
5. Change the following configuration parameters:

| Configuration parameter | Description |
| --- | --- |
| com.mind8.formui.eox | Name of the model [EOX](glossary_o_eox.htm) file without file extension. This information must match the information in the file ec.ini of the EEC Server. |
| com.mind8.formui.perspective.object | Path to the project component that contains the Form-UI to be displayed initially. |
| com.mind8.formui.perspective.form-id | The ID of the Form-UI to be displayed initially. |
| com.mind8.formui.host | Host of the EEC Server. |
| com.mind8.formui.port | Port of the EEC Server. This information must match the information in the file ec.ini of the EEC Server. |
| com.mind8.formui.timeout | Waiting time until a session-timeout is triggered after inactivity (in seconds). |

![](../Pictures/Gui/ALL/note.png)Note:

[Parameter](glossary_o_parameter.htm) values to be entered by the user are identified by a comment:

<!-- TODO: Comment text -->.

The complete comment, including <!-- and --> has to be replaced by a parameter value.

Example for a parameter value before the change by the user:

<param-value><!-- TODO: ExampleEOX (without file type .eox) --></param-value>

Example for a parameter value after the changes by the user:

<param-value>TutorialModel</param-value>

![](../Pictures/Gui/ALL/example.png)Example of configuration:

```
<web-app id="WebApp">
...
	<context-param>
		<param-name>com.mind8.formui.eox</param-name>
		<param-value>Tutorial_model</param-value>	
	</context-param>
	<context-param>
	<param-name>com.mind8.formui.perspective.object</param-name>
	<param-value>Feeder.Feeder</param-value>
	</context-param>
	<context-param>
		<param-name>com.mind8.formui.perspective.form-id</param-name>
		<param-value>feeder</param-value>
	</context-param>
	<context-param>
		<param-name>com.mind8.formui.host</param-name>
		<param-value>localhost</param-value>
	</context-param>
	<context-param>
		<param-name>com.mind8.formui.port</param-name>
		<param-value>7171</param-value>
	</context-param>
...
</web-app>
```

6. Copy the folder \webec to the folder C:\Program Files\Apache Software Foundation\Tomcat <Tomcat version>\webapps.
7. Delete the content of the folder C:\Program Files\Apache Software Foundation\Tomcat 7.0<Tomcat version>\work.
8. Right-click the symbol of the Tomcat Monitor on the taskbar.
9. Select Start service from the context menu. Check the Tomcat log files for any error messages.

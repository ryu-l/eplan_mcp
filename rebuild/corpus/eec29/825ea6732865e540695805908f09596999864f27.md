# sum()

Returns the sum of all objects in the Collection. The included objects have to support the + operator.

| sum() | | | |
| --- | --- | --- | --- |
| Argument |  |  |  |
| Return value | [String](glossary_o_string.htm), [Integer](glossary_o_integer.htm) or [Double](glossary_o_double.htm) | Sum of the included objects | |

# Modifying formulas

All formulas will fail due to the encapsulation of the discipline components and the usage of interface parameters.

### [ClosedModifying formulas for the component M\_WiringDiagram](javascript:void(0);)

1. Open the component M\_WiringDiagram.
2. Switch to the Parameter editor page.
3. For the Plant parameter, enter the following value:

```
=mc.$Plant
```

1. Save the component.

The formula =mc.$Plant requires that a Plant parameter exists in the higher-level component, meaning the Feeder component and that it supplies a suitable value. This parameter must still be inserted in the Feeder and have a value assigned to it.

### [ClosedCreating a plant parameter and inserting it into Feeder](javascript:void(0);)

1. Select the Parameter unit.
2. Select New > Parameter in the shortcut menu.
3. Specify the Plant name.
4. Specify the String type.
5. Save the parameter.

Insert the Plant parameter into the Feeder component.

1. Open the Feeder component.
2. Open the Parameters editor page.
3. Drag the Plant parameter from the Parameter unit into the editor page.
4. Enter the ='Feederâ formula as the value.
5. Save the component.

# Template for all elements of the node (Root Template)

The following rule has the effect that the current element is called up. It is used, for example, to call up the root node of the XML.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code:](javascript:void(0);)

```
<xsl:template match="/">
	<!-- Content -->
</xsl:template>
```

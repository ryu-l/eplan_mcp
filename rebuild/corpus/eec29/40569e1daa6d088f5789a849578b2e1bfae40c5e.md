# Create parameter

Since the function groups Inspect and Discard, and the position sensors Position\_2, Position\_3, and Position\_4 are to be either available or not, parameters of the Boolean type will be enough.

Create the parameters of the following table in the Parameter unit.

| [Parameter](glossary_o_parameter.htm) name | Type | Formula |
| --- | --- | --- |
| Option\_Inspect\_available | [Boolean](glossary_o_boolean.htm) | false |
| Sensor\_2\_available | Boolean |  |
| Sensor\_3\_available | Boolean |  |
| Sensor\_4\_available | Boolean |  |
| Option\_Two\_Valves | Boolean |  |

See [Create parameter](eecbase_k_create_parameter.htm).

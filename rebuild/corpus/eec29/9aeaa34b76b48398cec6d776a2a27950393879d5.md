# Line break

To insert a line break into the text, the corresponding ASCII-sign as a decimal value is inserted in the following manner:

&#10;

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code:](javascript:void(0);)

```
<label>
	Text&#10;Text
</label>
```

Result:

Text

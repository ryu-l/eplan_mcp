# com.mind8.project.exchange.model.ProjectExchangeModel.modelKitVersionHolderPath

The EEC argument must be transferred with the following syntax:

```
-D<Argument>=<Value>
```

| EEC argument | Usage |
| --- | --- |
| -Dcom.mind8.project.exchange.model.ProjectExchangeModel.modelKitVersionHolderPath=<absolutePath>.<VersionParameter> | Optional |
| **Annotation** | |
| Absolute name to the parameter, which contains the modular system version number. Only then is it possible to run PX updates automatically.  absolutePath references the project component that contains the parameter for the model version.  VersionParameter indicates the name of the parameter that stores the model version  Example:   ``` -Dcom.mind8.project.exchange.model.ProjectExchangeModel. modelKitVersionHolderPath=Bib.Komponenten.Basis.modellversion ``` | |

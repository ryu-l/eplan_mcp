# Set device tag

Insert a device tag to identify the sensors:

1. Mark all the sensors on the 1b Sensors page.
2. Select Edit > Properties.

The Properties (components): General devices opens.

1. If required, open the Function tab.
2. In the Displayed DT field, enter the text <DT>.
3. Confirm with [OK].

The message window Settings: DT syntax check opens.

1. Click [Ignore].

The message window is displayed for each sensor and has to be closed correspondingly often by using [Ignore].

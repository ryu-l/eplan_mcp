# mos(Boolean alsoDisabled)

mos(alsoDisabled) corresponds to the method mos for alsoDisabled=false. If the return value is alsoDisabled=true also the disabled children of the mechatronic component are returned.

| **mos([Boolean](glossary_o_boolean.htm) alsoDisabled)** | | | |
| --- | --- | --- | --- |
| Argument | Boolean | alsoDisabled | true = deactivated project components are also taken into consideration  false = deactivated project components are not taken into consideration |
| Return value | List |  | |

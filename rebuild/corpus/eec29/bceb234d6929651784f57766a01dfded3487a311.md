# Header

The header indicates which XML version and character set was used in creating the job definition and which should be used in interpreting it. The file must include a header.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code:](javascript:void(0);)

```
<?xml version="1.0" encoding="UTF-8"?>
```

# Creating a library

A new library is created in the library catalog (see also [Perspectives](eecbase_k_perspectives.htm)).

As a rule libraries contain specific objects, for example architecture components. Specific objects are derived from system objects. To this purpose the matching system library has to be imported into the newly created library (see also [System libraries](eecbase_k_methodology_system_libraries.htm)).

To create a new library:

![Create library step 1](../Pictures/createLibrary_1.png)

1. Click ![New library](../Pictures/new_library.png) (New library).
2. Enter a (unique) name for the new library.
3. Enter a comment optionally.
4. Open the editor page Imported libraries.

![Create architecture library step 2](../Pictures/createArchitectureLibrary_2.png)

1. Click ![Import selected library](../Pictures/new.png) (Import selected library).
2. Select the Engineering library in the finder.
3. Click [OK] in the finder.
4. Save with [Ctrl] + [S] or ![](../Pictures/speichern.png).

The new library is subsequently listed in the library catalog.

![Create library result](../Pictures/createLibrary_3.png)

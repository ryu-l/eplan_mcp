# Create Parameters On Demand

Path to model variable:

Disciplines > ECAD

Select a [Boolean](glossary_o_boolean.htm) value. The value determines whether parameters that are not available yet in the unit for global parameters, are automatically created when ECAD resources are added.

Valid values are true and false.

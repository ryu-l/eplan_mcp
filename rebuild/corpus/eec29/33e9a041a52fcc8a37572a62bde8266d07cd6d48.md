# Exporting the current information model

The entire information model is exported to an XML file, and subsequently imported into an empty database of the new installation (note: The XML format is database-neutral and allows for the switch between different database products and versions).

The entire information model is exported to an [EOX](glossary_o_eox.htm) file, and subsequently imported into an empty database of the new installation.

1. Click File > Export....

![](../Pictures/eec_datei_exportieren.png)

The Export dialog opens:

![](../Pictures/eec_exportieren_mindxml.png)

2. Navigate to Other > Mind XML Export.
3. Click [Next >].

The Export dialog opens:

![](../Pictures/eec_exportieren_mindxml_dialog.png)

4. Enter a file name and storage location for the export file.
5. Using rootUnit, select the entire model and / or select subunits that are not to be exported.
6. Click [Finish].

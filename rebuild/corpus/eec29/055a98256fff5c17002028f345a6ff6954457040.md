# Creating the Simatic project in the project explorer

The Simatic Manager is required to create the Simatic project in the project explorer.

1. Open the project explorer view (Window > Show view > Project explorer).

![](../Pictures/tutorial_s7_test5_simatic_projekt_erzeugen.png)

1. Select the Feeder.
2. Select Create Simatic Project in the shortcut menu.

![](../Pictures/Gui/ALL/note.png)Note:

In order to be able to create the Simatic project, the option Simatic project in one source has to be disabled (see [SIMATIC](admin_r_prefs_plc_s7simatic.htm)).

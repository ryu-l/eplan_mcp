EEC provides an XML editor for the creation of configurations (see [XML editor for Form-UIs and diagram definitions](eecbase_k_editors_xml_editor_for_formui_and_diagramdefinitions.htm)):

![](../Pictures/xml-editor_xdd_source.png)

The Graph2D diagram configurations can also be edited with Notepad from Windows or any editors of third-party distributors, e.g. [XML-Spy](http://www.altova.com), [Liquid XML-Studio](http://www.liquid-technologies.com), [Oxygen XML-Editor](http://www.oxygenxml.com), etc.

Programmers of user interfaces which use third-party editors are provided with a XML-schema for validation. The schema file diagram.xsd is provided in the folder ..\install\diagrams.

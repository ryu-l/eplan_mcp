# isExtensionPlaced()

Returns true, if the object is placed on a extension point.

| isExtensionPlaced() | | | |
| --- | --- | --- | --- |
| Argument |  |  |  |
| Return value | [Boolean](glossary_o_boolean.htm) | | true or false |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code in Groovy:](javascript:void(0);)

```
objects = component.getMos();
for (iter = objects.iterator();
iter.hasNext(); )
{
	object = iter.next();
	if (object.isExtensionPlaced())
	{
		// do something
	}
}
```

# <parameterName>

The tag <parameterName> defines the alias for the absolute name of a parameter.

The tag has no sub-elements.

| Attribute name | Usage | Attribute values | Default value | Description |
| --- | --- | --- | --- | --- |
| alias | required |  |  | Alias name of a parameter. |
| realName | required |  |  | Absolute name of a parameter. |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code:](javascript:void(0);)

```
<mapping>
	<parameterName alias="Plug" realName="T_Mechatronic_ModularSystem.Parameter.Plug"/>
	<parameterName alias="Socket" realName="T_Mechatronic_ModularSystem.Parameter.Socket"/>
</mapping>
```

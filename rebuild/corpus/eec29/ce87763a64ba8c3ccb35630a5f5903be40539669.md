# Stand-Alone installation

The installation is carried out as follows:

1. Start the installation file.
2. Select the language of the installation wizard.
3. Click [OK].
4. Acknowledge the following information page with [Next >].
5. Accept the license agreement.
6. Click [Next >].
7. Select the installation variant Stand-alone installation.
8. Click [Next >].
9. Enter the target folder for the installation.
10. Click [Next >].
11. Indicate whether an entry is to be created in the start menu and/or desktop symbol.
12. Click [Next >].
13. Complete the installation overview with [Install].

Additional installation steps for FastObjects-DBMS as back-end:

After the installation, the following change has to be made to the initialization file ec.ini so that a FastObjects DBMS is accessed as a back-end rather than the default [EOX](glossary_o_eox.htm) file:

1. Open the file <Installation folder>/ec.ini with any editor (e.g., Notepad).
2. Change the following entry in the ec.ini file to start EEC with a designated FastObjects database:

before: -Dorg.foederal.sn.connectionURL=proxy://any

after: -Dorg.foederal.sn.connectionURL=fastobjects://LOCAL/db

Afterwards EEC has to be licensed, bevore it can start (see [Licensing](admin_h_installation_lincensing.htm) and [Starting](admin_h_installation_stand_alone_start.htm)).

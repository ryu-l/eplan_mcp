# Installing extension points into mechatronic components

You now have to install extensions points in all mechatronic components in which EPLAN Electric P8 components have already been installed fixed.

This affects the following mechatronic components:

- Feeder,
- Positionsensor\_Inductive,
- Pressuresensor,
- Positionsensor\_optical.

### [ClosedCreating an extension point for the schematic:](javascript:void(0);)

1. Open the Feeder component.
2. Delete the installed components WiringDiagram\_Feeder, PLC-Sensors\_1\_8 and PLC\_Sensors\_9\_16.
3. Click ![](../Pictures/button_finder.png) to open the Finder dialog.
4. Mark the Placeholder.
5. Confirm with [Finish].
6. Change the name from Placeholder to WiringDiagram.
7. Click [...] in the Type field to open the type finder.
8. Enter the character I in the Name field.
9. Click [Search].
10. Select the IWiringDiagram interface.
11. Confirm with [OK].
12. Enter the value 0..1 in the Number field.
13. In the Selection formula field, enter the value =1.
14. Mark the Extension point check box.
15. Save the component.

In the future a component that implements the IWiringDiagram interface is installed on the extension point. The quantity is limited to the value 1 and the selection formula only allows a single component.

### [ClosedCreating an extension point for schematic pages whose quantity is calculated:](javascript:void(0);)

The number of installed sensors is evaluated for the extension point on which the schematic pages are to be installed. To simplify the formula for the evaluation a parameter is required that saves the number of installed sensors.

Creating the Sensors parameter:

1. Mark the Parameter unit in the T\_Mechatronic\_ModularSystem library.
2. Select New > Parameter in the shortcut menu.
3. Specify the Sensors name.
4. Specify the Collection type.
5. Save the parameter.

Inserting the Sensors parameter in Feeder:

1. Open the Feeder component.
2. Switch to the Parameter editor page.
3. Drag the Sensors parameter from the Parameter unit into the editor page.
4. Enter the following formula as the value:

```
=rmos('IMechSensor')
```

1. Save the Feeder component.

Creating the extension point for schematic pages:

1. Repeat Steps 2 to 10 of the previous extension point creation, in the process rename the placeholder to SchematicPages and mark the ISchematicPage interface.
2. Leave the asterisk in the Number field.
3. Enter the following formula as the value in the Selection formula field:

```
=if (mroot.$Sensors.size.mod(8) > 0) then (mroot.$Sensors.size / 8 + 1) else (mroot.$Sensors.size / 8) endif
```

1. Mark the Extension point check box.
2. Save the component.

![](../Pictures/Gui/ALL/note.png)Note on the number and selection formula:

The value in the number field specifies the overall number of insertable components. The number of components of an insertable type is specified in the selection formula field. Here the overall number is not restricted. The number of insertable components (schematic pages) is calculated. On one page 8 sensors can be placed. Therefore the overall number modulo 8 is calculated. If a rest remains, the sensors have to be placed on an additional page, so that a 1 has to be added to the result.

### [ClosedCreating extension points for sensors](javascript:void(0);)

1. Open the Positionsensor\_inductive component.
2. Delete the installed Sensor\_Inductive component.
3. Save the component Positionsensor\_inductive.
4. Click ![](../Pictures/button_finder.png) to open the Finder dialog.
5. Mark the Placeholder.
6. Confirm with [Finish].
7. Change the name from Placeholder to Sensor\_inductive.
8. Click [...] in the Type field to open the type finder.
9. Enter the character I in the Name field.
10. Click [Search].
11. Select the ISensorInductive interface.
12. Confirm with [OK].
13. Enter the value 0..1 in the Number field.
14. In the Target project field, enter the value 1.
15. Mark the Extension point check box.
16. Save the component.
17. Repeat Steps 1 to 16 with the Positionsensor\_optical component, in the process rename the placeholder to Sensor\_optical and mark the ISensorOptical interface.
18. Repeat Steps 1 to 16 with the Pressuresensor component, in the process rename the placeholder to Sensor\_Pressure and mark the ISensorPressure interface.

Through the transition to extension points, the parameters of the sensors are applied to encapsulating mechatronic components and are not part of the T\_Mechatronic\_ModularSystem anymore.

The parameters have to be removed in the abstract Positionsensor sensor.

1. Open the component Positionsensor.
2. Switch to the Parameter editor page.
3. Mark all parameters.
4. Click ![](../Pictures/button_delete.png) to delete the parameter.
5. Save the component.

The number of pages in the projects orientates itself towards the number of sensors that implement the IMechSensor interface.

Implementing IMechSensor in the sensors interface:

1. Open the Positionsensor\_inductive component.
2. Switch to the Interfaces editor page.
3. Click ![](../Pictures/button_finder.png) to open the Finder dialog.
4. Click [Search].
5. Mark the IMechSensor.
6. Confirm with [Finish].
7. Save the component.
8. Repeat Steps 1 to 7 for the Positionsensor\_optical and Pressuresensor components.

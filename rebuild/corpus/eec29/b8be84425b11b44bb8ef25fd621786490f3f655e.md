# Preferences

Path to the preferences:

Menu Window > Preferences

Dialog Preferences

User preferences are used to control the appearance and behavior of the user interface. All settings are default settings that apply to most users.

Using the [Restore default values] button, the preferences of the category displayed are reset to the default values.

The modifications become active immediately when the [Apply] button is clicked.

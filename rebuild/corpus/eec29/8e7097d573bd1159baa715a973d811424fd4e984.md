# Insert sensor macros in mechatronic components

Add as components via Drag & Drop the P8 components Sensor\_Pressure, Sensor\_Inductive, and Sensor\_Optical to all non-abstract sensors that are not in the T\_Mechatronic\_ModularSystem library Sensors subunit:

- Pressuresensor
- Positionsensor\_inductive
- Positionsensor\_optical

Then create the ECAD structure again. An error message will appear, because components cannot be assigned according to the plug-socket principle.

# rmos(String typeName, Boolean alsoDisabled)

rmos(typeName, alsoDisabled) corresponds to the method rmos(String typeName) for alsoDisabled=false. If the return value is alsoDisabled=true also the disabled children of the mechatronic component are returned.

| **rmos([String](glossary_o_string.htm) typeName, [Boolean](glossary_o_boolean.htm) alsoDisabled)** | | | |
| --- | --- | --- | --- |
| Arguments | String | typeName | Type of the components to be determined |
| Boolean | alsoDisabled | true = deactivated project components are also taken into consideration  false = deactivated project components are not taken into consideration |
| Return value | List |  | |

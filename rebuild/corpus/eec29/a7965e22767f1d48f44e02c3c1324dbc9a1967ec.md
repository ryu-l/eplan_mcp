# includes(Object obj)

Returns true if the assigned object obj is included in the Collection.

| includes(Object obj) | | | |
| --- | --- | --- | --- |
| Argument | Object | obj | Object which has to be included in the collection. |
| Return value | [Boolean](glossary_o_boolean.htm) |  | |

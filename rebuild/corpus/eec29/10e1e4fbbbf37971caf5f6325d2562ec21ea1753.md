# Components for placement

In the level structure, the Device object is also inserted as a placeholder for various placeable components. The following table lists the most common special characters:

| [Component](glossary_o_component.htm) | Description |
| --- | --- |
| WireDuct | Wire duct |
| MountingRail | Mounting rail |
| BusBarSystem | Busbar system |
| Device | Component, e.g. terminal clamp |
| CutOut | Cutout in a mounting surface |
| Area | Barred area on a mounting surface |
| EnclosurePart | Switching cabinet part, e.g. door |

# Web EEC

The installation variant Web EEC can optionally be installed and distributed on different servers, or just on a single computer.

After the installation of the application as a stand-alone installation on the EEC Server, further manual installation steps are required (see [Installation of EEC Server](admin_h_installation_web_eec_eec_server.htm)).

On the page of the EEC Server, the file ec.ini must be adjusted in such a way that the data of the user interface of a model provided can be sent to the Web EEC Server on the basis of an [EOX](glossary_o_eox.htm) file. In addition to the EOX file used, one must specify read-only or also write access. For communications, the host of the EEC Server, the port, and waiting time must be defined. The identical port number must be stated in the file web.xml of the Tomcat Server. The port must be different from the port for the communication between the clients and the Web EEC Server if the Web EEC Server and the EEC Server have been set up on the same computer.

On the page of the Web EEC Server, at first, a Tomcat web server must be installed (see [Web EEC installation and configuration](admin_h_installation_web_eec_configuration.htm)).

Then, the port for client communications must be configured, and Java options set up.

# Specify component of the top level

In the last step of creating the architecture modular system, you must specify the levels of the hierarchy that are permitted to be the top component of a configuration. This is to be possible only for Stations:

![](../Pictures/Mechatronik_Architektur_11.png)

1. In T\_Mechatronic\_Architecture, in the Levelcomponents unit, open the Station component, and switch to the Level configuration editor page.
2. Activate the Top-level element check box.

In the above figure, the level components are shown sorted in alphabetical order. [Level components](glossary_o_levelcomponent.htm) and units can also be sorted by hierarchy (see [Preferences for Unit Explorer](admin_r_prefs_unit_explorer.htm)).

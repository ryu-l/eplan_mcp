# Setting up a FastObjects database server

Installing the FastObjects DB server software:

The files of the FastObjects DB server are located as zipped files in the subfolder install\other\dbserver of the EEC installation folder. To use the DB server, the files have to be unzipped to the target folder on the DB server computer, e.g., to C:\Program Files\fastobjects.

How the DB server can be entered as a Windows service is explained in the section [Setting up a FastObjects database server as service](admin_h_installation_fastobjects_database_as_service.htm).

After the files have been unzipped, the DB server still does not have a database. To add a database to the configuration, please follow the instructions in the section [Adding a database to the DB server configuration](admin_h_installation_fastobjects_add_database_to_db_server.htm).

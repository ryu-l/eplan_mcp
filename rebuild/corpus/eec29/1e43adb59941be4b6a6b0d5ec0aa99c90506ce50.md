# Insert schematic and page into mechatronic components

In the first step, components for the schematic and pages must be linked with the mechatronic component Feeder:

1. In T\_Mechatronic\_ModularSystem, open the Feeder component.

![](../Pictures/tutorial_p8_plan_seiten_einbauen1.png)

1. Using Drag & Drop, drag the WiringDiagram component once, and the Page component twice, into the component panel of the editor.
2. Rename WiringDiagram to WiringDiagram\_Feeder.
3. Rename Page and Page2 to PLC\_Sensors\_1\_8 and PLC\_Sensors\_9\_16.

The result should look as follows:

![](../Pictures/tutorial_p8_komponenten_plan_seiten_eingebaut.png)

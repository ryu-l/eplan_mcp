# com.mind8.ecserver.baseEOXPath

The EEC argument must be transferred with the following syntax:

```
-D<Argument>=<Value>
```

| EEC argument | Usage |
| --- | --- |
| -Dcom.mind8.ecserver.baseEOXPath=<absolute path to base models folder> | Only for Web EEC: |
| **Annotation** | |
| Specifies an absolute path to a folder in which the result of a configuration is stored as a session model.  Example:   ``` -Dcom.mind8.ecserver.baseEOXPath=C:\base\EOX ``` | |

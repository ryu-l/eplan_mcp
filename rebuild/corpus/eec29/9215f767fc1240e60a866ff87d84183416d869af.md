# Filter

To improve clarity in case of larger models, it helps to filter certain objects from a variety of objects and hide the ones that are not needed. For this purpose, filters can be set up for views. This way, various objects can be hidden. The Filter dialog is opened via the ![](../Pictures/Gui/filter.png) symbol of the view-specific toolbar. Filters are always subtractive.

A number of objects can be selected to be hidden in the Filter dialog.

![](../Pictures/projektkatalog_filter.png)

Filters can be enabled and / or disabled for any view. This can be done using ![](../Pictures/Gui/filteronoff.png) of the view-specific toolbar.

The view is updated after the settings have been confirmed. For details, see subsequent chapters.

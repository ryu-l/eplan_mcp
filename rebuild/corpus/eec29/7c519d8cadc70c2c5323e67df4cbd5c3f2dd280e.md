# Adding plugs and sockets to Word components

Using the corresponding sockets for chapters and plugs for rows, it is now possible to assign the rows to the correct chapters:

![](../Pictures/tutorial_word_socket_parameter_einfuegen.png)

1. [Double](glossary_o_double.htm)-click to open the Word component Chapter in the Word\_Components unit.
2. Switch to the Parameters editor page.
3. Click on the Add parameter symbol and select the Socket parameter in the finder.
4. Add the Plug parameter to the Word component Row by repeating steps 1 to 3.

![](../Pictures/tutorial_word_socket_wert.png)

1. Double-click to open the component Feeder in the T\_Mechatronic\_ModularSystem library in the Stations unit.
2. Click to select the Actuators\_Table component. The corresponding parameter table now opens.
3. Enter Actuators as the value for the Socket parameter.
4. Repeat the previous two steps to add the Sensors value to the Sensors\_Table feeder component.

![](../Pictures/tutorial_word_plug_wert_aktoren.png)

1. To enter the Actuators plug parameter value to the two actuators Valve and Cylinder (both in the Actuators subunit in the Mechatronic unit) in the Row component, perform steps 5 to 7.

![](../Pictures/tutorial_word_plug_wert_sensoren.png)

1. Repeat steps 5 to 7 for the non-abstract sensors (in the Sensors subunit in the Mechatronic unit) as well and enter the Sensors plug parameter value in the Row component.

- Pressuresensor
- Positionsensor\_inductive
- Positionsensor\_optical

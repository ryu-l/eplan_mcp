# isEmpty()

Returns true if the map does not include any key-value pairs.

| isEmpty() | | | |
| --- | --- | --- | --- |
| Argument |  |  |  |
| Return value | [Boolean](glossary_o_boolean.htm) | true for an empty map false for a filled map | |

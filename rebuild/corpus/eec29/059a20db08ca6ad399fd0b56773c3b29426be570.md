# Calculating formulas for components

With the method evaluate formulas for mechatronic objects are calculated. The return value is the result of the formula.

[Integer](glossary_o_integer.htm) and [Double](glossary_o_double.htm) results are returned as object and not als simple type (e.g. java.lang.Double and not double):

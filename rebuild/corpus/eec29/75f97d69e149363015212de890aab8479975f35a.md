# asInteger(Integer radix)

Generates an integer, the character string is therefore interpreted as a number to the base <radix>. asInteger() equates to asInteger(10).

| --- | --- | --- | --- | --- |
| Arguments | Integer | radix |  | |
| Return value | Integer | |  | |

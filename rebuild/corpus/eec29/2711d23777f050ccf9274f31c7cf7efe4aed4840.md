# Restoring preferences

Proceed as follows to restore preferences:

1. Start EEC

![](../Pictures/eec_datei_importieren.png)

2. Click File > Import....

The Import dialog opens:

![](../Pictures/eec_importieren_benutzervorgaben.png)

3. Navigate to General > Preferences.
4. Click Next >.

The Import Preferences dialog opens:

![](../Pictures/eec_importieren_benutzervorgaben_dialog.png)

5. Select the preference file previously exported.
6. Select the check box Import all.
7. Click Finish.

Then, the user preferences of the previous installation are available again.

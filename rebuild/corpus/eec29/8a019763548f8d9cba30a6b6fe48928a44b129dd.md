# de.eplan.eec.rest.service.projectsfolder

The following EEC argument must be transferred with the following syntax:

```
-D<Argument>=<Value>
```

| EEC argument | Usage |
| --- | --- |
| -Dde.eplan.eec.rest.service.projectsfolder=<Path to projects folder> | Only for eeLide |
| **Annotation** | |
| Specifies the temporary folder for storing the configuration on the server's file system.  Example:   ``` -Dde.eplan.eec.rest.service.projectsfolder=C:\TEMP\MyProjects ``` | |

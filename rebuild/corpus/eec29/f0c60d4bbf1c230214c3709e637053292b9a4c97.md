# Template for elements and the document root

The following rule has the effect that all child notes of the current element are called up. If the style sheet is empty, this causes the source document to be traversed from the root to the leaves.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code:](javascript:void(0);)

```
<xsl:template match="*|/">
	<!-- Content -->
</xsl:template>
```

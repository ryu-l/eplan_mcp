# Nested structures

Control structures can be nested as in a programming language.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
(*{LOOP:dos}*)
	(*{IF $Group="Cyclic"}*)
		//True
	(*{ELSE}*)
		//False
	(*{END_IF}*)
(*{END_LOOP}*)
```

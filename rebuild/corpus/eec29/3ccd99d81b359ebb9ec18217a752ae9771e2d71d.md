# Adding ImageObjects to the mechatronic model

On the cover sheet below the title the EPLAN logo and in the tables of the actuators and sensors in the first column the symbols of the components are to be displayed. Instead of permanently installing these figures they are to be referenced by means of a formula.

The GIF file Logo.gif (![EPLAN-Logo](../Pictures/Logo_20x21.gif)) that is directly referenced serves as an image object for the EPLAN logo.

The images Actuator.gif(![](../Pictures/aktor.png)) and Sensor.gif (![](../Pictures/sensor.png)) previously specified should be used as the image objects for actuators and sensors. The image objects are assigned to the relevant type of the components in the image register. A formula can access this image register and determine the matching image.

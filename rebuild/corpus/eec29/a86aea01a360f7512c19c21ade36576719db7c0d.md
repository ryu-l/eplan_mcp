# Updating extension points

Analog to the calls of UpdateExtensionsCommand and RemoveExtensionsCommand also an API is used to update extension points in scripts directly. Compared to the commands, there is also the possibility to reuse an instantiation context and to update the extensions for only one level. The API for IMechatronicExtensionsAPI.DEFAULT is shown in the following.

# -perspective

| Eclipse argument | Values | Usage |
| --- | --- | --- |
| -perspective | perspective identifier | Optional |
| **Annotation** | | |
| At the launch the perspective is opened by default that was open the last time the EEC was closed. Using the argument -perspective, EEC can be controlled in such a way that always a specific perspective is opened, regardless of the last state.

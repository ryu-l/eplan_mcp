# removeExtensions(Object obj)

Deletes all objects placed on extension points under the specified object. This can be a mechatronic component, Engineering.MechatronicRoot or a placeholder.

| removeExtensions(Object obj) | | | |
| --- | --- | --- | --- |
| Argument | Object | obj | A mechatronic component, MechatronicRoot or placeholder, for which the extension points should be updated. |
| Return value |  | |  |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code in Groovy:](javascript:void(0);)

```
import com.mind8.mechatronic.skill.api.IMechatronicExtensionsAPI;
// obj is script argument
IMechatronicExtensionsAPI.DEFAULT.removeExtensions (obj);
```

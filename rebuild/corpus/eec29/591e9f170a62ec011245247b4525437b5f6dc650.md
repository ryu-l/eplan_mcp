# Calling the Web EEC

The Web EEC is called in a browser with the following syntax:

```
http://<Hostname>:<Portnummer>/webec/main
```

Example of a URL for the Web EEC if, as described before, it was installed in the folder webapps\webec of a Tomcat server that accepts http requests at http://(localhost:8181:

<http://localhost:8181/webec/main>

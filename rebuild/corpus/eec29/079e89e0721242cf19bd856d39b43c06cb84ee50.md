# Create macro box

Now create a macro box that combines all symbols of this page into a macro.

1. Select Insert > Box / connection point / mounting panel > Macro box.
2. Drag a frame around the power supply lines and PLC inputs.

![](../Pictures/tutorial_p8_makrokasten.png)

1. End the Macro box function using the [ESC] key.

Define the properties of the macro box.

1. Highlight the macro box.
2. Select Edit > Properties.

The Properties (components): Macro box opens.

1. In the Name field, enter the file name Page\Page.

![](../Pictures/note.png) Note:

1. Open the Display tab.
2. Click [New].

The Property selection dialog opens.

1. Select from the list Macro: Name.
2. Confirm with [OK].

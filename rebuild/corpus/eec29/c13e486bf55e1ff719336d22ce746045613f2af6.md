# Testing upgrade

The test of the upgrade is intended to show that the configuration can be first performed without the participation of discipline components. After the configuration a discipline can be added by importing a library. It consists of the following steps:

### [ClosedCreating a project](javascript:void(0);)

1. In the Project Catalog click ![](../Pictures/button_new_project.png).
2. Specify Feeder1 as the name.
3. Click [Next >].
4. Select the T\_Mechatronic\_ModularSystem library. The T\_Office\_Word and T\_Images libraries are not automatically marked and should also not be!
5. Click [Next >].
6. The Feeder level component is automatically marked.
7. Confirm with [Finish].

The Feeder1 project now exists in the Project catalog.

1. Select the Feeder1 project.
2. Select Expand all from the popup menu.

Depending on the filter settings all project components and the extension points are now shown in the tree view. For this tutorial we recommend the following objects per filter setting:

- Non-active objects
- Categories
- AutomationWorX
- CoDeSys
- ECAD
- STEP 7

### [ClosedConfiguring a project without the option "Add workpiece inspection"](javascript:void(0);)

Now open the Form-UI to configure the project.

1. Select the Feeder component.
2. Select Form-UIs > Feeder from the popup menu.

As a default the value of the parameter Option\_Inspect\_available is false and the Add Workpiece Inspection check box is not activated. Since all required components are already installed according to the maximum principle, another configuration is not possible in this case.

### [ClosedImporting a discipline library](javascript:void(0);)

Which libraries are involved in the Feeder1 project shall be checked before and after the import.

Before:

1. Open the Feeder1 library.
2. Change to the Imported libraries editor.

Imported libraries:

![](../Pictures/tutorial_word_expert_test1.png)

Import a discipline library per Form-UI:

1. Select the Feeder component.
2. Select Form-UIs > Feeder from the popup menu.
3. Click the button [Import Word Discipline].
4. Save the Form-UI.

After:

1. Open the Feeder1 library.
2. Change to the Imported libraries editor.

Imported libraries:

![](../Pictures/tutorial_word_expert_test2.png)

After the import the discipline components of the T\_ECAD\_P8 library are available.

### [ClosedUpdating extension points](javascript:void(0);)

In the tree view of the project catalog you can see that no discipline components are inserted on the extension points.

![](../Pictures/tutorial_word_expert_test3.png)

1. Select the Feeder component.
2. Select Form-UIs > Feeder from the popup menu.
3. Click the [Update Extensions] button.
4. Save the Form-UI.

In the tree view of the project catalog you now can see that discipline components are inserted on all extension points.

![](../Pictures/tutorial_word_expert_test4.png)

![](../Pictures/Gui/ALL/note.png)Note:

Discipline components are also inserted on the hidden extension points, but are not considered during the generation of the discipline components.

### [ClosedGenerating discipline documents](javascript:void(0);)

A Word document is generated from the existing discipline components with the following steps.

1. Select the component Mechatronic.
2. Select Word > Generate Word document from the popup menu.

Subsequently the structure of the Word components is created in the project catalog. It consists of the discipline components Body, two chapters with eight rows each.

1. Select the component Mechatronic.
2. Select from the popup menu Word > Generate and open Word document.

Microsoft Word is opened and the generated document is displayed. The document contains a cover sheet, a table of contents and a page with tables of the actuators and sensors. Only the table of contents does not correspond to the current content. The table of contents for the field must be updated to this purpose.

1. Close the Word document and exit Word.
2. Select the component Mechatronic.
3. Select Word > Update Word document fields from the popup menu.

Microsoft Word is opened and the generated document is displayed. The table of contents now corresponds to the current content.

### [ClosedRe-generating a discipline component](javascript:void(0);)

A Word document is re-generated with the added discipline components with the following steps.

1. Select the component Mechatronic.
2. Select Word > Generate Word document from the popup menu.

Subsequently the structure of the Word components is recreated in the project catalog. It consists of the discipline components body, two chapters, eight rows below chapter and 11 rows below the second chapter.

1. Select the component Mechatronic.
2. Select from the popup menu Word > Generate and open Word document.

Microsoft Word is opened and the generated document is displayed. The document contains a cover sheet, a table of contents and a page with tables of the actuators and sensors. Only the table of contents does not correspond to the current content. The table of contents for the field must be updated to this purpose.

1. Close the Word document and exit Word.
2. Select the component Mechatronic.
3. Select Word > Update Word document fields from the popup menu.

Microsoft Word is opened and the generated document is displayed. The table of contents now corresponds to the current content.

### [ClosedSummary](javascript:void(0);)

The advantage that extension points entail have no effect for smaller models in connection with an individual discipline.

The bigger the model becomes and the more disciplines are added, the bigger the advantage of extension points becomes. The mechatronic modular system remains slim and clear. Discipline libraries can be changed and extended independently of each other.

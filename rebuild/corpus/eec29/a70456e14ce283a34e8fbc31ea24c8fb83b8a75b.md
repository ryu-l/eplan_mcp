# isPlaceholderPlaced()

Returns true, if the object is placed on a placeholder (also extension point).

![](../Pictures/Gui/ALL/note.png)Note:

To distinguish between pure placeholders and extension points, additionally isExtensionPlaced() has to be used.

| isPlaceholderPlaced() | | | |
| --- | --- | --- | --- |
| Argument |  |  |  |
| Return value | [Boolean](glossary_o_boolean.htm) | | true or false |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code in Groovy:](javascript:void(0);)

```
objects = component.getMos();
for (iter = objects.iterator();
iter.hasNext(); )
{
	object = iter.next();
	if (object.isPlaceholderPlaced())
	{
		if (object.isExtensionPlaced())
		{
			// do something with extensions
		}
		else
		{
			// do something with pure placeholder placed objects
		}
	}
}
```

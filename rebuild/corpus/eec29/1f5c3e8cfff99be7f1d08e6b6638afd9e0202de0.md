# getImportedLibraryNames

Delivers a list of strings with the names of the directly imported libraries.

| getImportedLibraryNames | | | |
| --- | --- | --- | --- |
| Argument | [String](glossary_o_string.htm) | projectName | Name of the project |
| Return value | List | List with the names of the imported libraries | |

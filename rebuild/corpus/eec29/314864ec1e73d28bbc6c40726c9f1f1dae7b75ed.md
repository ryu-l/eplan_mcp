# Creating a discipline component

Discipline components as a rule are mechatronic components to which a resource, e.g. a macro file, is assigned. No resources are assigned to abstract discipline components. They are only used to define superclasses from which concrete discipline components are subsequently derived.

To create concrete discipline components:

![Create discipline component step 1](../Pictures/DisziplinkomponenteErstellen_1.png)

1. Call up the popup menu of a library or a unit and select New > Discipline name > Discipline component here.

![Create discipline component step 2](../Pictures/DisziplinkomponenteErstellen_2.png)

1. Click [Import...] and select a resource file to import it.

![Create discipline component step 3](../Pictures/DisziplinkomponenteErstellen_3.png)

The creation of the discipline components is accelerated by applying the name of the resource.

1. Enter a comment optionally.
2. Save with [Ctrl] + [S] or ![](../Pictures/speichern.png).

The subsequent saving of the editor results in the component being created. A name must be unique within a unit.

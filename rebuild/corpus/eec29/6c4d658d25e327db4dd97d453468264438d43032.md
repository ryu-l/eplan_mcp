# absRef(String absoluteName)

References the project component absoluteName. Project components which are disabled cannot be referenced.

This method is only applicable in JMX files for the Job Server environment.

| **sabsRef([String](glossary_o_string.htm) absoluteName)** | | | |
| --- | --- | --- | --- |
| Arguments | String | absoluteName | Absolute path to the project component. |
| Return value | Project component |  | The referenced project component |

# Creating the basic structure

A number of objects are required to define a text discipline. They contain, for example, specifications on how parameters can be identified in text files or define how files are created. These required text discipline objects can be generated quickly by using the wizard:

![Create text discipline library step 2](../Pictures/tuttextCreateDisciplineArchitectureLibrary_2.png)

1. Call up the popup menu of the T\_ListOfComponents\_Architecture and select New > Text discipline....

![Create text discipline library step 3](../Pictures/tuttextCreateDisciplineArchitectureLibrary_3.png)

1. Enter the ListOfComponents name into the Text discipline name field.
2. Click [Finish].

# Engineering.ForcefulEOXImportCommand

Imports an [EOX](glossary_o_eox.htm) file.

The EOX file contains all information necessary for the project import.

| Argument | Type | Description |
| --- | --- | --- |
| pathToEOX | [String](glossary_o_string.htm) | Path to the EOX file. |

The EOX file contains all the information necessary for the project import but not the object on which the import has to be performed.

| Argument | Type | Description |
| --- | --- | --- |
| object | Object | Project or project component. |
| pathToEOX | String | Path to the EOX file. |

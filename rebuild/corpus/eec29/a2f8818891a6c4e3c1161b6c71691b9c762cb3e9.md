# SIMATIC Step 7

Basic knowledge of Step 7 is necessary to complete this section of the tutorial.

Several source files are required for this discipline. Information on the name of these files and how they are provided will be described in the [Tutorial](tutorial_k_tutorial.htm) section.

This SIMATIC Step 7 tutorial is divided into four sections:

1. Creating the Step 7 program for Feeder.
2. Creating addresses for the inputs and outputs.
3. Creating the symbol table.
4. Integrating interrupt messages.

After a section of the discipline model has been created, the result can be compared with the sample solution (see [Comparison with sample solution](tutorial_h_compare_with_example_solution.htm)).

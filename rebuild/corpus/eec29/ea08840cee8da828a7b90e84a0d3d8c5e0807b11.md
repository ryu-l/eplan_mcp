# Creating actions for the import of the discipline library into the modular system

The upgrade to extension points has the advantage that during the configuration of a machine or plant only mechatronic components are involved and the data model therefore remains smaller. Only when the documents of a discipline have to be created for the completely configured machine or plant, are the discipline components installed per import of the discipline library and update of the extension points.

Both the import as well as the update are to be triggered through actions by means of buttons of a user interface. The actions are based on a command and a SequenceSelectionAction that are created in the following steps.

### [ClosedCreating a command for the import of a library](javascript:void(0);)

1. Select the T\_Mechatronic\_ModularSystem library.
2. Select New > Unit in the shortcut menu.
3. Specify the Actions name.
4. Select the new Actions unit.
5. Select New > Object... from the popup menu.
6. Click Object > Command.
7. Confirm with [Finish].
8. Specify the ImportLibCommand name.
9. Switch to the Methods editor page.
10. Click ![](../Pictures/button_finder.png).

The New Name has to be entered in the table and the Name field.

1. Specify execute as the name.
2. In the drop-down list select LanguageSequence.
3. In the Arguments area click on ![](../Pictures/button_finder.png).
4. The New Argument with the Engineering.Object type is entered in the table of the arguments.
5. Enter root as the name.
6. Enter Engineering.Root as the type.
7. Repeat Steps 12 to 15 with the name libNames and the type Engineering.List.

The new arguments are entered as values for the signature of the method. It is now an execute method that requires the root node of the mechatronic and the list of the libraries to be imported as arguments.

Below a table is shown with the specification of type names, method names and method arguments.

1. Click ![](../Pictures/button_finder.png) above the table.
2. In the Select method dialog, click Object > Command > FrameworkCommand > ImportLibrariesCommand.
3. Confirm with [Finish].
4. Repeat Steps 18 to 20 with Object > Command > FrameworkCommand > SaveObjectCommand.
5. Save the command.

This concludes the creation of the command for the import of a library. With this command the framework commands for the import of libraries and the subsequent saving are performed.

### [ClosedCreating SequenceSelectionAction for the update of extension points](javascript:void(0);)

1. Select the Actions unit.
2. Select New > Object from the popup menu.
3. Click Object > Action > SelectionAction > SequenceSelectionAction.
4. Confirm with [Finish].
5. Specify the UpdateExtensionPointsAction name.
6. Specify Update Extension Points in the Displayed Name field.
7. Switch to the Methods editor page.
8. Click ![](../Pictures/button_finder.png).
9. Click Object > Command > FrameworkCommand > StartFormulaCacheCommand.
10. Confirm with [Finish].
11. Repeat Steps 8 to 10 with Object > Command > FrameworkCommand > UpdateExtensionsCommand.
12. Repeat Steps 8 to 10 with Object > Command > FrameworkCommand > StopFormulaCacheCommand.
13. Repeat Steps 8 to 10 with Object > Command > FrameworkCommand > SaveObjectCommand.
14. Switch to the Attributes editor page.
15. Specify Component in the Selected object field.
16. Save the SequenceSelectionAction.

This completes the creation of the SequenceSelectionAction for updating the extension points. With this SequenceSelectionAction the framework commands for starting the formula cache, the update of extension points, stopping the formula cache and the subsequent saving are performed consecutively.

The created actions are then linked with interfaces in a small user interface. The user interface (Form-UI) is created for the component Feeder and therefore is available directly after the creation of a project.

### [ClosedCreating Form-UI for Feeder](javascript:void(0);)

With the user interface you can not only set up the interfaces for the import of the library but you can also make the option for checking workpiece available for selection.

1. Open the Feeder component.
2. Change to the UI configuration editor page.
3. Change to the Source tab.

1. In the <form> tag specify the Feeder title and the ID feeder.
2. Insert the following lines after the opening tag <form>:

```
<line>
	<label font="Arial-20-bold">Feeder configuration</label>
</line>
<line>
	<gap hSizePx="10"/>
</line>
<line>
	<input receiver="=parameter('Option_Inspect_available')" type="check" ></input>
	<label font="Arial-12">Add workpiece inspection</label>
</line>
<line>
	<gap hSizePx="10"/>
</line>
<action name="T_Mechatronic_ModularSystem.Actions.ImportLibCommand" 
	arguments="=List{this.mroot.parent, List{'T_Office_Word'}}" 
	type="button" 
	text="Import Word Discipline">
</action>
<action name="T_Mechatronic_ModularSystem.Actions.UpdateExtensionPointsAction" 
	arguments="=mroot" 
	type="button" 
	text="Update extensions">
</action>
```

Through the first three rows the user interface receives the Feeder configuration header.

The header is followed by three rows to create space.

Below that is a row with a check box, followed by a text. The check box influences the Option\_Inspect\_available parameter that amongst others is used for the Disabler of the function groups Inspect and Discard.

Three further lines follow to create space to the buttons.

This is followed by two buttons that can each perform actions.

The first button triggers the action to import the library T\_Office\_Word.

With the second button the action for updating the extension points is performed.

### [ClosedSetting the default value for the Option\_Inspect\_available parameter](javascript:void(0);)

The check box for the Option\_Inspect\_available parameter in the user interface should always have a defined state at the beginning of the configuration. In this case the check box should not be selected, so that the value is false.

1. Open the Option\_Inspect\_available parameter.
2. Switch to the Formula editor page.
3. Enter false in the Value field.
4. Save the parameter.

This value is now specified as the default value. As a result the Add workpiece inspection option will not be selected when opening the user interface for the first time.

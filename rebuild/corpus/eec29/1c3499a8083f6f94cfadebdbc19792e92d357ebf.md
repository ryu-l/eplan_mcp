# Using parameters in mechatronic components

The corresponding parameters have to be assigned to the respective components. This is done via the Parameters editor page of a mechatronic component.

The following editor page shows the parameters of the discipline component Page:

![](../Pictures/editor_parameter.png)

A new parameter can be assigned in two ways:

- Drag & Drop.
- ![](../Pictures/Gui/button_finder.png) (Add parameter).

# ref(String absoluteName)

References the project components absoluteName. Project components which are disabled cannot be referenced (see [Navigation methods for project components](refformulas_r_project_components_navigation.htm)).

| **ref([String](glossary_o_string.htm) absoluteName)** | | | | |
| --- | --- | --- | --- | --- |
| Arguments | String | absoluteName | The path to a project component | |
| Return value | Project component | | The referenced project component | |

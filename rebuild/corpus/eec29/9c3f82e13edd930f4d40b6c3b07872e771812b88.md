# Upgrading mechatronic model to extension points

The upgrade of the model to extension points is targeted towards experienced users who are already familiar with the basic functions.

The currently structured model serves as the starting point. If the model has not been elaborated, the P8.eox sample file has to be imported and the EEX user settings and model variables as well as the P8 settings have to be adapted.

The concept of extension points is based on the idea that only such components are installed on an extension point that import an interface by the same name and that are visible for the project. Those discipline components are visible whose libraries have been imported into the project. The number of components to be inserted is specified separately for each extension point or is controlled by formulas. The insertion of components is triggered by updating the extension points.

# Setting preferences for the Step7 discipline

In order for the EC to access the blocks that were unzipped and modified in the previous step, it is necessary to first enter the path of these files under preferences.

1. Select Window > Preferences.

The Preferences window now appears.

![](../Pictures/tutorial_s7_benutzervorgaben.png)

1. Select Disciplines > PLC > Step7 in the tree structure.
2. Enter the path of the blocks that you want to unzip in the Source folder field.

```
\resources\Tutorial\Step7
```

1. Confirm with [OK].

![](../Pictures/Gui/ALL/note.png)Note:

Because this path has been changed, the Step7 discipline no longer works in the demo model!

To work with the demo model, press Restore default values to restore the previous path.

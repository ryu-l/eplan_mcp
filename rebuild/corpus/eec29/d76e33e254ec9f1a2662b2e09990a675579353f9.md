# Connection Type BendpointFix

The new router BendpointFix can be used for connections between two elements of a Graph-UI. The new router is specified in the diagram definition as follows:

```
<router id="BendpointFix" class="com.mind8.graph2d.router.BendpointFix" />
```

The following figure shows the connection of two elements with the new BendpointFix router before the right element is moved.

![](../Pictures/verbindung_bendpointfix.png)

After the moving, the polyline of the connection remains except the directly to the right element connected segment, as shown by the following figure.

![](../Pictures/verbindung_bendpointfix_moved.png)

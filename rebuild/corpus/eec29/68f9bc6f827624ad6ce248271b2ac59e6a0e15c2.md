# Insert sockets in page

You must insert Sockets to ensure that the sensors can be placed by EEC when generating the page. Each socket defines a place on which a sensor (with plug) can be positioned. A macro can contain several sockets, but no more than one plug.

1. Select Insert > Graphic > Text....
2. Enter the following text for the socket:

```
#<Socket:Input1>
```

1. Confirm with [OK].
2. Position the text on the right above the PLC input, as shown in the following figure:

![](../Pictures/tutorial_p8_position_socket.png)

1. Repeat the steps 1 o 5 for each further PLC input, and use ascending numbers for the socket (<Socket:Input2>, <Socket:Input3>, etc.). As an alternative you can copy the existing text several times by using Edit > Duplicate and adapting the texts.

![](../Pictures/tutorial_p8_funktionstexte_socket.png)

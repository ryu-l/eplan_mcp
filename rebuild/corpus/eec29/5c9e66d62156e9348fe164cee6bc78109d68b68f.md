# getPlaceholders()

Returns a list of names of all placeholders in this mechatronic component.

| getPlaceholders() | | | |
| --- | --- | --- | --- |
| Argument |  |  |  |
| Return value | List | | List of placeholders |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code in Groovy:](javascript:void(0);)

```
placeholders = component.getPlaceholders();
```

Result:

```
[<<Placeholder1>>,<<Placeholder2>>]
```

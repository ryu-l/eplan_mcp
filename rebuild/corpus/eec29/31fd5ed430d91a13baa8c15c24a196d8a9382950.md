# isUser(String name)

Delivers true if the authorized EEC user is equal to the assigned user, otherwise false is delivered.

| **isUser([String](glossary_o_string.htm) name)** | | | | |
| --- | --- | --- | --- | --- |
| Argument | String | name | User name | |
| Return value | [Boolean](glossary_o_boolean.htm) | | true = user has the assigned name false = user has another name | |

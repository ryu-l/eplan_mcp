# Parameter

The interface of a component is defined by **parameters**. Each parameter has a name, a type, a value, and a comment.

Examples of different types of parameters:

| Name | Value | Type | Comment |
| --- | --- | --- | --- |
| ToolchangerAvailable | true | [Boolean](glossary_o_boolean.htm) | Toolchanger available? |
| AmountGripper | 5 | [Integer](glossary_o_integer.htm) | Number of built-in grippers |
| Safety factor | 1:50 AM | Real | Safety factor protecting against disconnection |
| [DT](glossary_o_bmk.htm) | =ZS+S1-M01 | [String](glossary_o_string.htm) | Device tag |

# Test 2 - Generate the current state of the enclosure

Generate the (still incomplete) enclosure

1. Switch to the Project perspective.
2. In the Project Explorer select the Feeder project.

![](../Pictures/tutorial_pp_test2_struktur_generieren.png)

1. In the Project Explorer, select Mechatronic.
2. In the context menu, select ECAD > Generate EPLAN Pro Panel Structure.

The following structure should have been created in the Project Explorer:

![](../Pictures/tutorial_pp_test2_struktur.png)

1. In the Project Explorer select the WiringDiagram\_Feeder component.
2. In the context menu, select Generate and Open EPLAN Pro Panel.

The EPLAN Electric P8 application opens.

1. [Double](glossary_o_double.htm)-click the LayoutSpace\_Feeder element to open it in the layout space.

The created enclosure is displayed in the editor area.

![](../Pictures/tutorial_pp_test2_ergebnis.png)

All of the discipline components installed in the Feeder station are available and properly arranged. Terminal clamps for the sensors are still missing from the lower mounting rail between the two endblocks on the right.

1. Close EPLAN Electric P8.

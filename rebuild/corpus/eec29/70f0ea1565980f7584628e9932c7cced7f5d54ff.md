# Installation of the FastObjects server

A client-server installation supports the installation of a FastObjects database both on the same file server, on which the application runs, and on a separate database server (see chapter [Client-Server-Installation](admin_h_installation_client_server.htm)). The following sections describe the setup of the FastObjects database management system on a separate database server.

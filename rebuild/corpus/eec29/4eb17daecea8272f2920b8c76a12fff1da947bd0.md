# Engineering.NewProjectCommand

Creates a new project.

| Argument | Type | Description |
| --- | --- | --- |
| eo | Object | Engineering object |
| projectName | [String](glossary_o_string.htm) | Name of the new project |
| librariesToImport | List | Libraries, which are selected for the new project. |
| objectsToInstantiate | List | Components, which are instantiated in the new project. |

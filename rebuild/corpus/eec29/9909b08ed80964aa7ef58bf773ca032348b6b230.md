# Name of the macro project template

Path to model variable:

Disciplines > ECAD > EPLAN Electric P8 >Eplan Data Zip (.edz) generation

The model variable Macro project template specifies the name of the macro project template. The macro project template is only required for the EDZ+ generation. Since a macro project template hosted by EPLAN is used, the specification of a customer-specific macro project template is not possible.

Default is IEC\_bas001.zw9.

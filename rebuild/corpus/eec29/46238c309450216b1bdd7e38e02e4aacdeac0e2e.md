# getPlaceholderNames(String absoluteTypeName)

Returns a list of names of all placeholders in this mechatronic component, where classes of the specified type can be placed.

| getPlaceholderNames([String](glossary_o_string.htm) absoluteTypeName) | | | |
| --- | --- | --- | --- |
| Argument | String | absoluteTypeName | Absolute name of the limited type |
| Return value | List | | List of placeholder names |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code in Groovy:](javascript:void(0);)

```
placeholders = component.getPlaceholderNames("T_Interfaces.ISchematicPage");
```

Result:

```
["SchematicPages"]
```

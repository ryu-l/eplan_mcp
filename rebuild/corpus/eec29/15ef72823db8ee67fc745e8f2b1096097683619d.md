# containsKey(Object key)

Validates whether key is included in the map as key.

| containsKey(Object key) | | | |
| --- | --- | --- | --- |
| Argument | Object | key | Key to be inspected |
| Return value | [Boolean](glossary_o_boolean.htm) | true if the key key is included. | |

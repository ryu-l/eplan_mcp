# Test 4 - Creating the Step7 program

This test is designed to show how to create the Step7 program on the basis of the created structure.

Before you start, reset the Option\_Inspect\_available parameter to true.

1. Generate the Step7 structure again.
2. Select the Step7 root component.
3. Select Step7 > Generate Code in the popup menu.

![](../Pictures/tutorial_s7_test4_step7_code_erzeugen.png)

The created files are stored in the following folder:

```
EC-Installationsordner\workspace\Feeder\Step7\SiemensCPU
```

1. Use the navigator view to view the folder contents:
2. Open the navigator view.

![](../Pictures/tutorial_s7_test4_ergebnis_mit_pruefen.png)

The symbol table and AWL files of all blocks have been created.

The test with the Option\_Inspect\_available parameter set to false creates the following results:

![](../Pictures/tutorial_s7_test4_ergebnis_ohne_pruefen.png)

The file FB\_Inspect.AWL is no longer available.

[Double](glossary_o_double.htm)-click on an AWL file to open this in an internal EC editor.

![](../Pictures/tutorial_s7_test4_ergebnis_navigator_awl.png)

In the figure, you can see the created calls that have been inserted for the FB\_Insert and FB\_Move function blocks.

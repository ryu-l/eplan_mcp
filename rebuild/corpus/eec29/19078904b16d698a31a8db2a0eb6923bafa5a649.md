# Importing libraries

Libraries can import further libraries. This way, the necessary libraries for a modular system can be selected according to the task at hand. To do this, open the library and, using the ![](../Pictures/Gui/import_lib_in_lib.png) button, open the Imported Libraries editor page.

The icon ![](../Pictures/Gui/new.png) (Add library) is used to start the Library finder dialog. The libraries to be integrated can now be selected. Once the selection is complete, the relations between the libraries are represented graphically.

In the following example, a new library with the name T\_Mechatronic\_ModularSystem is created, and the libraries T\_Mechatronic\_Architecture and T\_Step7\_Ui are imported:

![](../Pictures/tutorial_s7_bibliothek_importieren3.png)

The ![](../Pictures/Gui/hide_lib.png) (Hiding assemblies which are not directly imported) icon allows you to only show the directly imported assemblies.

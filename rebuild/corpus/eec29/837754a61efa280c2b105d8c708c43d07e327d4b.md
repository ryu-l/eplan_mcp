# Internal structure of editors

The following figure shows the internal structure of an editor. It consists of the areas Editor menu (1) and Editor pages (2):

![](../Pictures/editor.png)

The editor menu contains different menu items that open an editor page. By default, only one editor page is visible. But several editors can be opened by pinning individual editors, that is, you keep them open.

This is done using the icon Pin ![](../Pictures/Gui/pin.png):

![](../Pictures/editor_pinnen.png)

If a further editor is selected, it will be displayed directly below the existing editor.

![](../Pictures/editor_pinnen_2.png)

Below the pinned editor Parameter (1), one can now also see the editor Notes (2).

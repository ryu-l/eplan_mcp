# com.mind8.export.zip

The EEC argument must be transferred with the following syntax:

```
-D<Argument>=<Value>
```

| EEC argument | Usage |
| --- | --- |
| -Dcom.mind8.export.zip=<File name> | Optional |
| **Annotation** | |
| Through this argument, the XMLExportApplication learns the path and name of the file to which the model must be exported.  Example:   ``` -Dcom.mind8.export.zip=exportedDB.zip ``` | |

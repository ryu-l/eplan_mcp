# Task: Generate ListOfComponents

The task is to create a ListOfComponents with the following structure based on the functional, mechatronic of a plant.

![](../Pictures/tutorial_word_aufgabenstellung.png)

To achieve this goal, this chapter will begin by describing how to create a modular system from a reusable main document and a reusable fragment document on the basis of the Office discipline. It then goes on to show how to check the modular system components of the list of components by way of a test configuration.

The relationship of this new discipline to the mechatronic model will then be examined.

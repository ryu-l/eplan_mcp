# Removing a local database

A local database is used in connection with a Stand-Alone installation. A local database is removed using the administration tool.

![](../Pictures/ec_admin_entferne_lokale_datenbank.png)

1. When removing a local database, the check box Client-Server Installation must not be enabled. The host pre-set for a local database is LOCAL, which cannot be edited.
2. The name of the database to be removed must be entered in the Databasename field.
3. The database is removed via [Remove Database].

# Creating parameters for model variables

Parameters must now be created for model variables for the parameters names defined in the [Defining parameter names for model variables](tutstep7_h_task2_define_parametername.htm) section:

1. Select the Parameter unit.
2. Select New > Parameter in the shortcut menu.
3. In the Name field, enter the text IO\_BitRange. The preset type String is set.
4. Save the parameter.
5. Repeat steps 3 and 4 for the following parameters (all with type String):

| [Parameter](glossary_o_parameter.htm) name |
| --- |
| IO\_IncomingBus |
| IO\_InputBlockSize |
| IO\_InputStartAddressFormat |
| IO\_InputStartAddress |
| IO\_OutgoingBus |
| IO\_OutputBlockSize |
| IO\_OutputStartAddressFormat |
| IO\_OutputStartAddress |
| IO\_Place |
| IO\_Places |

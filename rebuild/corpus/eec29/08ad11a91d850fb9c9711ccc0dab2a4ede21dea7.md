# deleteParameter

Deletes the parameter with the stated absolute path.

| deleteParameter(String parameterAbsPath) | | | |
| --- | --- | --- | --- |
| Argument | [String](glossary_o_string.htm) | parameterAbsPath | Absolute path of the parameter to be deleted. |
| Return value | [Boolean](glossary_o_boolean.htm) | true = the parameter has been deleted successfully. false = no parameter value has been deleted. | |

# Assign fixed values for plugs and sockets to EPLAN Electric P8 components

For the discipline-specific ECAD structure to be created, values has to be assigned to the parameters Plug and Socket.

In the following steps the parameters of the plugs for all sensors occurring in the mechatronics structure are numbered beginning at I0.0 (notation for STEP 7).

1. In the Project Catalog, open the Mechatronics tree.

![](../Pictures/Gui/ALL/info.png)Tip:

If the tree structure does not indicate the sensors as in the below illustration, please check the settings for the filter. Uncheck the box for the ECAD option, if necessary.

1. Open Sensor\_Optical.
2. Click Parameters in the editor.

![](../Pictures/tutorial_p8_sensor_parameter_ep_e00.png)

1. For the IP parameter, enter the value I0.0.
2. Repeat Steps 2 to 4 for all further sensors and enter I0.1 to I0.7, I1.0 and I1.1 in the process.

Then enter the values I0.0 to I0.7 and I1.0 to I1.7 for the socket parameters of the pages.

1. Open the PLC\_Sensors\_1\_8 page.
2. Click Parameters in the editor.

![](../Pictures/tutorial_p8_seite_parameter_ep_e00.png)

1. For the parameters Input1 to Input8, enter the values I0.0 to I0.7.
2. Repeat steps 1 to 3 for the PLC\_Sensors\_9\_16 page, and enter the values I1.0 to I1.7.

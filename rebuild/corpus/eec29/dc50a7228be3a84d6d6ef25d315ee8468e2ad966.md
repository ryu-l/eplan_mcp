# P8 project filepath

Path to model variable:

Disciplines > ECAD > EPLAN Electric P8 >Eplan Data Zip (.edz) generation

The model variable P8 project file path specifies the path to the P8 project filename. If the project has to exist before generation, it is created. Depending on the installation variant write rights are assigned.

Default value is $(TMP)\P8Project.elk.

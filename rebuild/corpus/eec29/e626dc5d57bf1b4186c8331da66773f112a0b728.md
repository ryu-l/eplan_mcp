# notNULL()

Delivers true if the received object is not <<null>>.

| **notNULL()** | | | | |
| --- | --- | --- | --- | --- |
| Argument | Object | obj |  | |
| Return value | [Boolean](glossary_o_boolean.htm) | |  | |

| Formula | Result |
| --- | --- |
| =notNULL(true) | true |
| =notNULL(null) | false |

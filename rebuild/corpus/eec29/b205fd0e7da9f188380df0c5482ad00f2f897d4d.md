# updateParameterValue

Updates the value of the parameter with the stated absolute path in all existing projects.

| updateParameterValue(String parameterAbsPath, Object parameterValue) | | | |
| --- | --- | --- | --- |
| Argument | [String](glossary_o_string.htm) | instanceAbsPath | Absolute path to the project component. |
| Object | parameterValue | New value of the parameter. |
| Return value | [Boolean](glossary_o_boolean.htm) | true = at least one parameter value has been updated. false = no parameter value has been updated. | |

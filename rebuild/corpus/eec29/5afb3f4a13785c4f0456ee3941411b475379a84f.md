# com.mind8.remote.server.repository.file

The EEC argument must be transferred with the following syntax:

```
-D<Argument>=<Value>
```

| EEC argument | Usage |
| --- | --- |
| -Dcom.mind8.remote.server.repository.file=<absolute path to session models folder> | Only for Web EEC: |
| **Annotation** | |
| Specifies an absolute path to a folder in which the [EOX](glossary_o_eox.htm) files of the sessions are stored.  Example:   ``` -Dcom.mind8.remote.server.repository.file=C:\SessionModels ``` | |

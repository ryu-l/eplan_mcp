# Test 2 - Generate the current state of the ListOfComponents

To create and view the (not yet completed) ListOfComponents, open the Mechatronic popup menu in the Project Catalog and select the SequenceSelectionAction Word > Generate and open Word document:

This operation creates an error. The reason for this is that the component Image.Logo to be accessed in the model has not yet been created. The error message can be acknowledged by pressing [OK].

Parallel to Mechatronic, a structure consisting of a body and two chapters is created in the project tree.

![](../Pictures/tutorial_word_test2_erzeugte_struktur.png)

The created ListOfComponents is saved to the wordspace folder Word\Word and looks as follows:

![](../Pictures/tutorial_word_test2_komponentenliste.png)

In the ListOfComponents, the parameter values #{Heading} are replaced with their values and the chapters for actuators and sensors are added. The logo on the cover sheet is, however, missing and the table of contents is not up-to-date, although the contents that are shown appear to be correct.

If the table of contents was updated before Chapter.docx was saved, the formula (\*{LOOP:dos}\*)(\*{Content}\*)(\*{END\_LOOP}\*) is shown as chapter 1.1 as the chapter heading.

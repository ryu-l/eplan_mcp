# indexOf(String sub)

Delivers the position of the first occurrence of the character string sub in the original. If the character string sub is not contained in the original the return value is: -1.

| **indexOf([String](glossary_o_string.htm) sub)** | | | | |
| --- | --- | --- | --- | --- |
| Argument | String | sub |  | |
| Return value | [Integer](glossary_o_integer.htm) | | New position of the first occurrence of the character string sub in the original. If the character string sub is not contained in the original the return value is: -1. | |

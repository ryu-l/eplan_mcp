# Header

The header contains the declaration, which XML version and which character set is used for creating the Form-UI, resp. which is to be used to interpret the Form-UI.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code:](javascript:void(0);)

```
<?xml version="1.0" encoding="UTF-8"?>
```

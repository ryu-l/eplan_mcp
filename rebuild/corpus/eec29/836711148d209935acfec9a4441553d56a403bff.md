# com.mind8.formui.perspective.form-id

Das EEC-Argument muss mit der folgenden Syntax übergeben werden:

```
-D<Argument>=<Value>
```

| EEC-Argument | Verwendung |
| --- | --- |
| -Dcom.mind8.formui.perspective.form-id=Form-UI-ID | Optional |
| **Erläuterung** | |
| Startet EEC mit einem bestimmten Form-UI im Form-UI-Editor.  Form-UI-ID referenziert das Form-UI der Projektkomponente  Beispiel:   ``` -Dcom.mind8.formui.perspective.form-id=start ``` | |

# Creating plug and socket parameters

Before the plugs and sockets can be assigned to the Word components, these must first be created as parameters:

![](../Pictures/tutorial_word_plug_parameter_anlegen.png)

1. Select the Parameter unit in T\_Mechatronic\_ModularSystem.
2. Right-click and select New > Parameter in the shortcut menu.
3. Enter Plug in the Name field.
4. Enter Plug as the Type. The type can either be found by using the Finder ![](../Pictures/button_finder.png) or be entered directly.
5. Repeat steps 1 to 4 for the parameter with Socket as the name and type.

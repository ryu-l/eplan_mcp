# Notes on using the document

Before using the help system, please note the following points:

Examples are highlighted by this graphical symbol and can be expanded. Click the arrow to expand and display the sample text.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The example text is shown here. Click the arrow to collapse and hide the sample text.

![](../Pictures/Gui/ALL/note.png)Note:

After this image, extra comments to facilitate your interaction with the program are presented.

![](../Pictures/Gui/ALL/info.png)Tip:

After this graphic, you'll find useful tips and alternative commands.

- User interface elements are marked in blue so they can immediately be located in the text.
- Bold text provides particularly important information that you should definitely pay attention to.
- Code examples, directory names, and direct input (among others) are displayed in a non-proportional font.
- To make it easier for you to find particular program options, some help topics provide pre-defined menu paths. Select the menus and menu items marked in blue, in order to navigate from the main menu to the desired option.
- The operating information provides step-by-step instructions for reaching specific targets, and in many places, after the right-arrow symbol ![](../Pictures/Gui/ALL/arrow.png) you'll also find the reaction of the program to your action.
- Below, the More or See also comments are hyperlinks to related pages.

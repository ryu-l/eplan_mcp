# Plug-Socket concept for Pro Panel

The conceptual approach of the [Plug](glossary_o_plug.htm)-[Socket](glossary_o_socket.htm) concept is explained in the section [Plug-Socket concept](concept_k_plug_socket_concept.htm). The following section explains how to use the concept with Pro Panel.

The **Plug-Socket concept** describes a discipline-specific structure (logical placement) that can differ from the mechatronic structure. The logical link between the objects is established by means of the Plug-Socket concept. For example, if a mounting rail has a socket, then different plugs within a project can reference it. This results in a logical, discipline-specific project structure. When the Pro Panel structure is created, the Pro Panel objects are placed logically.

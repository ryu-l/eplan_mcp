# Test 1 - Instantiate EPLAN Pro Panel discipline components

As with the mechatronic components, the EPLAN Pro Panel components can also be instantiated. This is done by dragging and dropping them from the library catalog view into the project tree, where they will appear under the ECAD discipline root node:

![](../Pictures/tutorial_pp_test1.png)

1. Switch to the Project perspective.
2. Open the Feeder project.
3. Drag and drop the WiringDiagram library component into the Project Explorer.

If you place the component somewhere other than the permitted position, the cursor will change to a stop sign to indicate this.

1. Drag the LayoutSpace library component onto the WiringDiagram project component.
2. Drag the Enclosure, MountingPanel, Plane, WireDuct, MountingRail and Device library components into the Project Explorer.

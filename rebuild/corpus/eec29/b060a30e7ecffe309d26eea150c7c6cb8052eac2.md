# getPlaceholders(String absoluteTypeName)

Returns a list of all placeholders in this mechatronic component, where classes of the specified type can be placed.

| getPlaceholders([String](glossary_o_string.htm) absoluteTypeName) | | | |
| --- | --- | --- | --- |
| Argument | String | absoluteTypeName | Absolute name of the limited type |
| Return value | List | | List of placeholders |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code in Groovy:](javascript:void(0);)

```
placeholders = component.getPlaceholders("T_Interfaces.ISchematicPage");
```

Result:

```
[<<SchematicPages>>]
```

# Databases

EEC can be installed as a database-based application. The following database product is used:

| [Product](glossary_o_product.htm) | Type of database | Licensing | Description |
| --- | --- | --- | --- |
| [FastObjects](http://www.fastobjects.com/) | OODBMS | commercial | Existing installations are based on FastObjects from the company Versant. FastObjects is supplied as part of the EEC platform. |

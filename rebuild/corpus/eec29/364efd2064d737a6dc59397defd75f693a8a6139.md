# fileTrigger

The <fileTrigger> tag brackets the definitions for the folder specifications and the file filter. This tag has no attribute.

| Allowed sub-elements | Quantity |
| --- | --- |
| [incomingFolder](refjobserver_r_incomingfolder.htm) | 1 |
| [outputFolder](refjobserver_r_outputfolder.htm) | 0..1 |
| [failedFolder](refjobserver_r_failedfolder.htm) | 0..1 |
| [filter](refjobserver_r_filter.htm) | 1 |

# Deleting objects in scripts

Objects are deleted with the method delete of UnitOfWork.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example code in native Java:](javascript:void(0);)

```
//UOW besorgen
IUnitOfWork uow=self.getUnitOfWork();
// Delete first object of selection
// Keep in mind that the mechatronic objects are only deleted
// if isPlaceholderPlaced() returns true
MechatronicObject mo= (MechatronicObject) selectedEOs.get(0);
if (mo.isPlaceholderPlaced())
uow.delete(mo);
```

# Database selection for EOX data management

If the initialization file, e.g. ec.ini contains the entry -Dorg.foederal.sn.connectionURL=proxy://any for the data management instead of the FastObjects database entry, then an [EOX](glossary_o_eox.htm) file has to be selected on the first start (see the following figure).

![](../Pictures/eox_select_backend_1.png)

Select the EOX file which contains the data model for your current work. If the data model should not be changed by the new work, then the check box Open read-only must be marked. In this case all changes to the data model are lost when ending EEC. To save the changes you have to export the data model to a EOX file (see [Exporting libraries/projects as an EOX file](eecbase_k_eox_exchange_library_export.htm)).

At the next start the selected EOX file is automatically used again.

# version()

Returns the version of the executable file of the EPLAN Electric P8 installation (w3u.exe), which is specified in the preferences.

| version() | | | |
| --- | --- | --- | --- |
| Argument |  |  |  |
| Return value | [String](glossary_o_string.htm) | Version number of the currently selected executable file of the P8 installation. If no executable file of P8 (w3u.exe) is specified, Version 0.0.0 is returned. | |

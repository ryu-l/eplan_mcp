# Installation of the SAP plug-in

The SAP plug-in is required for operating the SAP interface. The installation of the plug-in is not part of the Stand-Alone installation and must be installed manually.

Here are the steps to install the plug-in:

1. Open Windows Explorer.
2. Navigate to the following folder: <EEC installation folder>\install\sap.
3. Open the file sap\_<Build-Name>.zip, for example sap\_2\_4\_20141009\_0818.zip, with a suitable file archiver, for example, 7-Zip.
4. Unpack the \sap directory contained in it into the <EEC installation folder>\dropins directory.

The following plug-ins are included:

- SAP API
- SAP plug-in
- SAP Business-API

The plug-ins will be automatically installed at the next startup.

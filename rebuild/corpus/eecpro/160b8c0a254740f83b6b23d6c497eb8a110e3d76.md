# Import EOX files for EPLAN Electric P8

The T\_Ecad\_Ui discipline library, as well as the T\_Mechatronic\_Architecture and T\_Mechatronic\_ModularSystem libraries created in the chapter âMechatronic,â must be available before the P8 macros are imported into EEC.

Based on the initial situation, various EOX files that contain the corresponding libraries must be imported:

- The model is empty, i.e., only the system libraries are available (also see [Filter](eecbase_k_filter.htm)). Import the following EOX files:

```
<EEC-Installationsordner>\install\Tutorial\Mechatronic\Mechatronic.eox
<EEC-Installationsordner>\install\Tutorial\P8\Ecad_Ui.eox
```

- The model contains T\_Mechatronic\_Architecture and T\_Mechatronic\_ModularSystem but not T\_Ecad\_Ui. Import the following EOX file:

```
<EEC-Installationsordner>\install\Tutorial\P8\Ecad_Ui.eox
```

- The model contains T\_Ecad\_Ui but not T\_Mechatronic\_Architecture and T\_Mechatronic\_ModularSystem. Import the following EOX file:

```
<EEC-Installationsordner>\install\Tutorial\Mechatronic\Mechatronic.eox.
```

Proceed as follows to import the required EOX files:

1. Start EEC
2. Select File > Import....

The import wizard opens with the Import dialog:

![](../Pictures/import_eox.png)

1. Select Model > Import wizard for model files in Engineering Object Format (EOX Format).
2. Press [Next >] to confirm.

![](../Pictures/tutorial_p8_t_ecad_ui_eox_importieren2.png)

1. Select Add in the Mode panel.
2. Select the required EOX file in the Source section.
3. Select the required libraries.
4. Press [Finish] to confirm.

![](../Pictures/tutorial_p8_t_ecad_ui_eox_importieren3.png)

1. Use ![](../Pictures/button_accept_incoming_changes.png) to apply all incoming changes in the Synchronization view.
2. If necessary, repeat Steps 2 to 9 and select the next EOX file that you need.

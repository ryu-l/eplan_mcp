# fileButtonArea

The element <fileButtonArea> encloses the definition of the buttons for a file selection window.

Only the buttons cancelButton and okButton can be used in a fileSelectionForm.

| Attribute name | Usage | Attribute values | Default value | Description |
| --- | --- | --- | --- | --- |
| none |  |  |  |  |

| Allowed sub-elements | Quantity |
| --- | --- |
| [cancelButton](refformui_r_cancelbutton.htm) | 0..1 |
| [okButton](refformui_r_okbutton.htm) | 0..1 |

# inputValidators

The element <inputValidators> encompasses the specific elements <numberRangeValidator>,  <contentValidator> or <keyValidator> for validation of the input in a text box or a drop-down listbox. It has no attributes.

| Attribute name | Usage | Attribute values | Default value | Description |
| --- | --- | --- | --- | --- |
| none |  |  |  |  |

| Allowed sub-elements | Quantity |
| --- | --- |
| [numberRangeValidator](refformui_r_numberrangevalidator.htm) | 0..1 |
| [contentValidator](refformui_r_contentvalidator.htm) | 0..1 |
| [keyValidator](refformui_r_keyvalidator.htm) | 0..1 |

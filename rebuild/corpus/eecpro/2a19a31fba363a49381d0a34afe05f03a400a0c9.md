# Create macro box

Now create a macro box that combines all symbols of this page into a macro.

1. Select Insert > Box / connection point > mounting panel > Macro box.
2. Drag a frame around the power supply lines and PLC inputs.

![](../Pictures/tutorial_p8_makrokasten.png)

3. End the Macro box function using the ESC key.
4. Define the properties of the macro box.
5. Highlight the macro box.
6. Select Edit > Properties.
7. The Properties (components): Macro box (Properties (components): Macro box dialog opens.

![](../Pictures/tutorial_p8_makrokasten_eigenschaften1.png)

8. In the Name field, enter the file name Page\Page.

### Note

9. Open the Display tab.
10. Click on [New].
11. The Property selection dialog opens:

![](../Pictures/tutorial_p8_makrokasten_eigenschaften2.png)

12. Select from the list Macro: Name (Macro: Name).
13. Confirm with [OK].
14. You return to the dialog Properties (components): Macro box (Properties (components): Macro box).

![](../Pictures/tutorial_p8_makrokasten_eigenschaften3.png)

15. Confirm with [OK].

# Set preferences in EEC

Path specifications have to be defined and options to be activated in the preferences for the discipline ECAD P8.

Path to the preferences:

Menu Window > Preferences

- The Path to ECAD macros specifies which folder is initially searched for EPLAN Electric P8 macros. Relative path specifications consist of the Root folder for notes and this specification.
- Macro project template specifies the name of a macro project template (\*.zw9 file) for generation of schematics. The macro project template must be specified, if EEC is used to create only EDZ files.
- EPLAN Electric P8 executable specifies the executable file of the EPLAN Electric P8 application (W3u.exe). The executable file must not be specified, if EEC is used to create only EDZ files.
- Automatically start API in background starts the Eplan API on start of EEC in background. This option can only be used if valid specifications are contained n the fields EPLAN Electric P8 executable and Macro project template.
- Keep plug/socket text objects avoids deletion of function text for Plugs and Sockets in the generated schematics.
- Keep macro boxes in window macros avoids deletion of macro boxes of window macros in generated schematics.
- Keep macro boxes in symbol macros avoids deletion of macro boxes of symbol macros in generated schematics.
- Reuse existing project for schematic generation accelerates the renewed generation of the same project. The creating and deleting of P8 projects using API takes considerable time. Schematic generation has therefore been optimized so that a project already generated is kept during repeated generating. If the project already exists when a new schematic is to be generated, EEC checks whether the project template for the project has remained the same. If yes, EEC deleted only existing pages and leaves the project. As a secondary effect an error message is no longer generated if the project is still opened in a P8. This is particularly useful, if only individual pages are to be checked in a schematic.
- Convert macros into groups during schematic generation groups all macros, which are located in a generated schematic.

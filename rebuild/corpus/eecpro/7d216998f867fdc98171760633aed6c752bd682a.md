# Create architecture components

Create the following abstract architecture components in the Levelcomponents unit:

| Architecture component | Image | Image file | Top-level component | Sub components |
| --- | --- | --- | --- | --- |
| Station | Level 2 | install/icon-collection/Level2.gif | Yes | Functiongroup |
| Functiongroup | Level 3 | install/icon-collection/Level3.gif | No | Functionunit |
| Functionunit | Level 4 | install/icon-collection/Level4.gif | No | Actuator, Sensor |
| Actuator | Actuator | install/icon-collection/Aktor.gif | No | Actuator |
| Sensor | Sensor | install/icon-collection/Sensor.gif | No |  |

See [Create architecture components](eecbase_k_create_architecture_component.htm).

Result:

![Creation result of architecture components](../Pictures/tutmechatronic_ArchitectureResult.png)

### Tip

The decorators can be enabled and disabled under Window > Settings > General > Representation > Label Decorations.

### Tip

In the above figure, the level components are shown sorted in alphabetical order. But level components can also be sorted by hierarchy. See [Preferences for Unit Explorer](admin_r_prefs_unit_explorer.htm).

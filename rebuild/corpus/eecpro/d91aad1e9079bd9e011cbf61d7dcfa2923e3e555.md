# hash()

String methods

Returns a hash value of a string as a 32-character hex string. The hash value will be created out of the UTF-8-coded character string.

| --- | --- | --- | --- | --- |
| Argument |  |  |  | |
| Return value | 32-character hex string | | Character string of the hash value | |

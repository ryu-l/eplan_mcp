# Importing T_IOGenerator_Ui library into mechatronic modules

To add the functions for the IO\_Generator to the T\_Mechatronic\_ModularSystem model, you will need to import the T\_IOGenerator\_Ui library.

1. Double-click to open the T\_Mechatronic\_ModularSystem library.
2. Select the Imported libraries editor.
3. Click ![](../Pictures/button_finder.png).

The library finder now appears:

![](../Pictures/tutorial_s7_bibliothek_importieren4.png)

1. Click [Search].
2. Select the T\_IOGenerator\_Ui library.
3. Confirm with [OK].

![](../Pictures/tutorial_s7_bibliothek_importieren3.png)

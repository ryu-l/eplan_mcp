# Parameter Name For The Higher-level Function Number

Path to model variable:

Disciplines > ECAD > Eplan Electric P8

Specify the name of a parameter. Add this parameter to the P8 discipline components. The value of the parameter in the discipline components defines the mounting location of a device for the device tag.

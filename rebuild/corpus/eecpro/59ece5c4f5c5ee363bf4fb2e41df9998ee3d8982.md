# value(Object key)

Methods For Map

Returns the value for the key. The result is <<null>> if the key is not included.

| value(Object key) | | | |
| --- | --- | --- | --- |
| Argument | Object | key | Key for which the value is sought. |
| Return value | Object | Value for the key. | |

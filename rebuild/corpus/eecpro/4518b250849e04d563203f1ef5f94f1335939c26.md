# perform(String MethodName, Arguments)

Calls a command or another script.

| perform(String MethodName, Arguments) | | | |
| --- | --- | --- | --- |
| Argument | String | MethodName | The name of the scripting method to be executed. For commands to be executed the method run or execute has to be specified. |
|  | Arguments | Up to 10 arguments can be specified directly. In addition, an array of arguments is to be used as the second argument. |
| Return value | String |  | Path to the global resources. |
| Exception error |  |  |
| Plug-in | com.mind8.mechatronic.skill.eos.TypeClass | | |

### [ClosedExample code](javascript:void(0);)

#### Requirements:

- The model data of install\scripting\scripting.eox have been imported.

The following script example (ScriptingExamples.exportEOX) executes the command Engineering.ExportEOXCommand.

The method ((CommandClass) TypeClass.findType(uow, "Engineering.ExportEOXCommand")) specifies the command to be executed.

This is followed by the method .perform("execute", ".\\workspace\\test.eox",["T\_Mechatronic\_ModularSystem","Feeder\_Extended1"]) with the specifications of the method and the arguments that are required of the command to be executed (see row 11).

Information and possible errors are output in the message log (see rows 7, 16, 20 and 26).

```
import org.foederal.util.ui.messages.UserMessageCollector;
import com.mind8.mechatronic.skill.eos.CommandClass;
import com.mind8.mechatronic.skill.eos.TypeClass;

String scriptName = "exportEOX";
String info = "### Start of script '" + scriptName + "' ###";
UserMessageCollector.addInfo(LIBRARY,'self',null,"Scripting",info);

uow = self.getUnitOfWork();

((CommandClass) TypeClass.findType(uow, "Engineering.ExportEOXCommand")).perform("execute", ".\\workspace\\test.eox",["T_Mechatronic_ModularSystem","Feeder_Extended1"]);

errorStatus = UserMessageCollector.getErrorStatus();
if(errorStatus.isOK() != true){
	info = errorStatus.getMessage();
	UserMessageCollector.addError(LIBRARY,'self',null,"Scripting",info);
}
else{
	info = "Exporting assemblies successful.";
	UserMessageCollector.addInfo(LIBRARY,'self',null,"Scripting",info);
}

self.getUnitOfWork().saveChanges();

info = "### End of script '" + scriptName + "' ###";
UserMessageCollector.addInfo(LIBRARY,'self',null,"Scripting",info);
```

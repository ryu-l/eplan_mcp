# default()

Methods for Parameters

The default method returns the (calculated) default value of a parameter. Returns <null> if no default value is set.

| default() | | | |
| --- | --- | --- | --- |
| Argument |  |  |  |
| Return value |  | The (calculated) default value of a parameter | |

| Parameter name | Value | Standard |
| --- | --- | --- |
| TotalLength | 1000 | = Length1 + Length2 |
| Length1 | 500 |  |
| Length2 | 300 |  |

| Formula | Result |
| --- | --- |

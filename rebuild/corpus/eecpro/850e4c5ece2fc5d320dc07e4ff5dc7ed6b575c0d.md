# Installing discipline components for sensors

All of the terminal clamps that can be assigned to a sensor are installed in the respective sensor.

1. Change to the Engineering perspective.
2. Open the Positionsensor\_inductive component.
3. Drag the Terminal\_PxC\_3031212 component from the ECAD > ProPanel unit to the component editor three times.
4. Name the installed components as follows:

| Old name | New name |
| --- | --- |
| Terminal\_PxC\_3031212 | X1L+ |
| Terminal\_PxC\_30312122 | X1M1 |
| Terminal\_PxC\_30312123 | Input |

1. For the Position parameter of the installed components, enter the value 300.
2. Repeat steps 2 to 5 for the Positionsensor\_optical component.
3. Open the Pressuresensor component.
4. Drag the Terminal\_PxC\_3031212 component from the ECAD > ProPanel unit to the component editor two times.
5. Name the installed components as follows:

| Old name | New name |
| --- | --- |
| Terminal\_PxC\_3031212 | X1L+ |
| Terminal\_PxC\_30312122 | Input |

1. For the Position parameter of the installed components, enter the value 300.

# messageForm

A <messageForm> is a message window that is displayed as a pop-up.

![](../Pictures/form-ui_messageForm1.png)

The message window is defined by the title (1), the icon (2), the message text (3) and the buttons (4).

The popupForm is called by means of the [open](refformui_r_open.htm) element from within another Form-UI or from a Graph2D diagram.

| Attribute name | Usage | Attribute values | Default value | Description |
| --- | --- | --- | --- | --- |
| id | required | any |  | Unique ID, which is referred to as reference |
| title | required | any |  | Name of the Form-UI |

| Allowed sub-elements | Quantity |
| --- | --- |
| [messageIcon](refformui_r_messageicon.htm) | 0..1 |
| [messageText](refformui_r_messagetext.htm) | 0..1 |
| [formButtonArea](refformui_r_formbuttonarea.htm) | 0..1 |

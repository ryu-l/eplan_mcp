# Engineering.RemoveLibrariesCommand

Removes the libraries from the project, which are passed by the list.

An assigned library, which is not imported, will be ignored. Returns an error if the assigned library does not exist.

| Argument | Type | Description |
| --- | --- | --- |
| root | Root | Root object of the mechatronic structure or of a discipline structure |
| libNames | List | Libraries to import |

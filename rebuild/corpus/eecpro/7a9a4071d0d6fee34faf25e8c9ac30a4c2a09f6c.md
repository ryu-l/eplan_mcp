# Preparatory steps in EEC

An adapted mechatronics modular system and various import files are made available for this tutorial. The files first have to be unzipped and stored into specific directories.

Requirements:

- EEC as a Job Server with Worker installation Version 2.9 or higher.

Carry out the following steps to prepare the tutorial:

1. Import the file <EEC installation folder>\install\Tutorial\SAP\Result-to\_SAP-sample.eox.
2. Import the file <EEC installation folder>\install\Tutorial\SAP\SAPToolkitSample.eox.
3. The libraries SAPArchitecture, SAPToolkitSample, T\_Mechatronic\_Architecture, T\_Mechatronic\_ModularSystem, Word\_Customizing and Word-Ui have been added to the Library Catalog.
4. The Feeder library has been added to the Project catalog.

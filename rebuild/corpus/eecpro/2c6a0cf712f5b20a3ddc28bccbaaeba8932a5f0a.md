# IDs

IDs are always used where a mounting surface is to be referenced, since the respective object offers several mounting surfaces. For example, a mounting panel has a front and a rear on which items can be placed.

IDs of a mounting panel:

```
Mounting panel: '15100.3.1;0;0'
```

```
Mounting panel rear: '16000.1.2;10003;0'
```

```
Mounting panel front: '16000.1.2;10002;0'
```

Proceed as follows to determine the ID of a part in Pro Panel:

1. Start Pro Panel.
2. Navigate to the desired part in the layout space. Alternatively insert the desired part in the layout space.
3. Open the properties of the part by double-clicking.
4. If required, open the Part placement tab.
5. If appropriate, add the property name Item ID (relative to macro, EEC).
6. The ID of the part is displayed in the Value column.

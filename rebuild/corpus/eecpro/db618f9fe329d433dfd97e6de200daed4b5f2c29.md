# Test 3 - Konfiguration mit aktualisierten Erweiterungspunkten erstellen

Voraussetzungen:

- EEC als Job Server mit Worker-Installation der Version 2.5.1 oder höher.
- Job Server ist gestartet.
- Perspektive Job Server ist geöffnet.

Der dritte Test soll zeigen, dass die Jobdefinition korrekt erstellt ist und ein Job ausgelöst werden kann. Damit soll eine Konfiguration erzeugt werden, in der die Komponente Inspect auf den passenden Einfügeplatz platziert ist und alle Erweiterungspunkte aktualisiert sind.

Da sich an der Jobdefinition für den Worker nichts geändert hat, können die Schritte für die Kontrolle entfallen.

Stoppen Sie den Worker:

1. Stoppen Sie mit ![](../Pictures/Gui/ALL/button_jobserver_stop.png) den Worker.

Um den Test durchzuführen, ist die IMX-Datei T3\_Project.IMX in den Ordner zu kopieren, der in der Jobdefinition mit dem Tag <incomingFolder> angegeben ist und der Worker zu starten.

Starten Sie den Worker:

1. Kopieren Sie die Datei <Job Server installation path>\resources\JobServer\IMX\T3\_Project.imx in den Ordner <Job Server installation path>\resources\JobServer\input.
2. Starten Sie mit ![](../Pictures/Gui/ALL/button_jobserver_start.png) den Worker.

Der Job wird sofort ausgeführt.

Der Status des Jobs kann auf der Seite Jobs kontrolliert werden:

1. Ãffnen Sie die Seite Jobs.

![](../Pictures/tutjobs_test3_jobs.png)

Hier werden alle Jobs mit ihrem Namen aufgelistet. Der Status des erfolgreich abgeschlossenen Jobs wird mit einem grünen Haken gekennzeichnet. In der Spalte Worker wird die Adresse des Workers gelistet, der diesen Job abgearbeitet hat. Durch einen Klick auf das Symbol ![](../Pictures/Gui/ALL/button_open_jobstatus.png) in der Spalte Actions werden weitere Informationen zu diesem Job in einem externen Browser angezeigt:

![](../Pictures/tutjobs_test3_actions.png)

1. Ãffnen Sie den Windows-Explorer.
2. Navigieren Sie zum Verzeichnis c:\temp.

Ergebnis:

Der Job ist erfolgreich abgearbeitet worden. Das Ergebnis ist als Datei Feeder.eox im Verzeichnis c:\temp abgespeichert. Der Inhalt von Feeder.eox kann mit einer Stand-Alone-Installation des EECs kontrolliert werden:

1. Starten Sie EEC.
2. Wählen Sie als Datenbasis die Datei c:\temp\Feeder.eox.
3. Markieren Sie gegebenenfalls die Option Nur-lesend öffnen.
4. Klappen Sie im Projekt-Katalog das Projekt Feeder auf:

![](../Pictures/tutjobs_test3_feeder.png)

Das Projekt Feeder ist durch den Import erfolgreich erzeugt worden. Auf dem Einfügeplatz Placeholder\_Inspect ist die Projektkomponente Inspect platziert.

Auf dem Erweiterungspunkt ExtensionPoint\_Orientationinspector ist die Komponente Orientationinspector platziert und auf dem Erweiterungspunkt ExtensionPoint\_Positionsensor\_optical die Komponente Positionsensor\_optical.

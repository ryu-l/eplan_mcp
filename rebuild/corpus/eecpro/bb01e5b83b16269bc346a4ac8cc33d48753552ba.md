# MateMap

In order to place an object on an object that is already placed, for example a cutout on a mounting surface, the position and alignment can be specified by the MateMap parameter. A MateMarker can be used to specify the surface.

Syntax with angle specification for rotation around the X-axis:

```
=Map{Pair{'dest','<plane>:<mate of plane>'},Pair{'src','<handle>'},Pair{'angle',<value>},Pair{'dx',<value>},Pair{'dy',<value>},Pair{'dz',<value>}}
```

Syntax with angle specification for rotation around all axes:

```
=Map{Pair{'dest','<plane>:<mate of plane>'},Pair{'src','<handle>'},Pair{'angleX',<value>},Pair{'angleY',<value>},Pair{'angleZ',<value>},Pair{'dx',<value>},Pair{'dy',<value>},Pair{'dz',<value>}}
```

### [ClosedExample](javascript:void(0);)

```
=Map{
	Pair{'dest','MateMarker:V1'},
	Pair{'src','C'},
	Pair{'dx','120'},
	Pair{'dy','90'},
	Pair{'angle','45'}
}
```

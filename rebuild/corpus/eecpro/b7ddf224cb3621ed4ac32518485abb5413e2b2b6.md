# Nesting elements and attributes

XSLT

The following rule creates two elements, one with a name attribute with the value ' Hello\_World'in the target document.

### [ClosedExample code](javascript:void(0);)

```
<xsl:element name="mo">
	<xsl:element name="mo2">
		<xsl:attribute name="name">
			<xsl:value-of select="'Hello_World'" />
		</xsl:attribute>
	</xsl:element>
</xsl:element>
```

Result of example code in IMX format:

```
<mo>
	<mo2 name='Hello_World' />
</mo>
```

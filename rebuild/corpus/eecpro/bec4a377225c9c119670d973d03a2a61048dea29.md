# isAvailable()

Data source objects

Returns true, if a connection to a data source has been successfully established.

| **isAvailable()** | | | | |
| --- | --- | --- | --- | --- |
| Argument |  |  |  | |
| Return value | Boolean | | true = connection to the data source is successfully established  false = no connection to the data source possible | |

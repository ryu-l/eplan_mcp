# Comments

GRAPH2D

For very large diagram configurations it is a good help to comment parts of it.

Comments always start with <!-- and end with -->. In between may lie a few comments, but also entire sections.

### [ClosedExample code for a comment line](javascript:void(0);)

```
<!-- Dies ist eine Kommentarzeile -->
```

### [ClosedExample code for a commented-out section](javascript:void(0);)

```
<!-- Die folgende Routerkonfiguration ist auskommentiert
<router id="LayoutComponentRouter"
	class="com.mind8.graph2d.router.BendpointShortestPathRouter"
	distance="5">
</router>
-->
```

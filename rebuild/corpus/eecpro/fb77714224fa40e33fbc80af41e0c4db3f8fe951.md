# Navigation from Form-UI to configuration file

The modular system developer can access the definition of an element in the configuration file directly from the Form-UI.

In the Form-UI window, an arrow is first displayed on each Form-UI element with the key combination [Ctrl] + [Alt]. The arrows are hidden by pressing the key combination again.

![](../Pictures/form-ui_navigation_zu_xml.png)

By clicking on an arrow, the XML file of the Form-UI is opened in a new Editor and the cursor is placed on the relevant element.

### Note

This function is currently only available for displaying Form-UIs with SWT.

# Adding discipline components to mechatronic components

The FB\_Insert, FB\_Inspect, and FB\_Move function blocks still have to be inserted into the corresponding mechatronic components.

![](../Pictures/tutorial_s7_komponenten_eingebaut2.png)

1. Open the Insert function group in T\_Mechatronic\_ModularSystem.
2. Insert the FB\_Sequence function block.
3. Open the Inspect function group.
4. Insert the FB\_Inspect function block.
5. Open the Move function group.
6. Insert the FB\_Move function block.

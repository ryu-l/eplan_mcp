# name

Methods for Parameters

The parameter.name or Parameter().name method delivers the name of the parameter object whose formula is executed.

| name | | | |
| --- | --- | --- | --- |
| Argument |  |  |  |
| Return value | String |  |

Given:

| Parameter name | Value |
| --- | --- |
| Data | =Map{Pair{'Example1','A'},Pair{'Example2','B'},Pair{'Example3','C'}} |

| Formula | Result |
| --- | --- |

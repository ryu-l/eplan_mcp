# Creating parameters for input and output addresses

Parameters of type IX and OX must be created for the input and output addresses.

1. Select the Parameter unit.
2. Select New > Parameter in the shortcut menu.
3. In the Name field, enter the text Bit0\_IX.
4. In the Type field, enter the text IX.
5. Save the parameter.
6. Repeat steps 2 to 5 for the parameters with names Bit1\_IX to Bit23\_IX (all with type IX).
7. Repeat steps 2 to 5 for the parameters with names Bit0\_QX to Bit15\_QX and enter the type QX for these parameters.

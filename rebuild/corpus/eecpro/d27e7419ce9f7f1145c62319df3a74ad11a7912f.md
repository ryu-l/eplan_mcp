# <imx>

The <imx> tag is the top-level element. All following tags are wrapped by this element.

| Attribute name | Usage | Attribute values | Default value | Description |
| --- | --- | --- | --- | --- |
| version | required |  |  | Specifies the version of the IMX file. |
| xmlns | optional |  |  | Specifies the namespace of the IMX tags. |

| Allowed sub-elements | Quantity |
| --- | --- |
| [<mapping>](refimx_r_mapping.htm) | 1 |
| [<project>](refimx_r_project.htm) | any |

### [ClosedExample code](javascript:void(0);)

```
<imx version="1.0">
```

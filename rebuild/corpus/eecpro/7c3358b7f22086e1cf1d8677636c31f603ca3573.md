# Create architecture components for the text discipline

As a rule concrete discipline components are derived from abstract discipline components (architecture components). For the ListOfComponents these are architecture components for Body, Chapter and Line.

Create the following architecture components in the Levelcomponents unit:

| Architecture component | Super class | Image | Image file | Abstract | Component of the top level | Output type | Sublevels |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Body | ListOfComponentsComponents | Icon for Body component | install/icon-collection/Rumpf.gif | Yes | Yes | Template file | Chapter |
| Chapter | ListOfComponentsComponents | Icon for Chapter component | install/icon-collection/Abschnitt.gif | Yes | No | Fragment | Line |
| Line | ListOfComponentsComponents | Icon for Line component | install/icon-collection/Zeile.gif | Yes | No | Fragment | - |

See [Create architecture components](eecbase_k_create_architecture_component.htm).

# Parameter Name For The Installation Site

Path to model variable:

Disciplines > ECAD > Eplan Electric P8

Specify the name of a parameter. Add this parameter to the P8 discipline components. The value of the parameter in the discipline components defines the installation site of the device for the device tag.

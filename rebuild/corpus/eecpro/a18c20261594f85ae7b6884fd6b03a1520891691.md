# link

The <link> element opens a Form-UI page. The element is configured as a sub-element, whose attributes are the designated Form-UI and its ID.

| Attribute name | Usage | Attribute values | Default value | Description |
| --- | --- | --- | --- | --- |
| receiver | required |  |  | Formula to the object |
| ref | required | Form-UI ID, URL |  | shows the Form-UI page whose ID or the website whose URL is specified |

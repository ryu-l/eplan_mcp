# Importing the library for interfaces into the modular system

To be able to use the interfaces in the modular system, the T\_Interfaces library has to be imported to the mechatronic modular system.

1. Open the T\_Mechatronic\_ModularSystem library.
2. Change to the Imported libraries editor page.
3. Click ![](../Pictures/button_finder.png) to open the Finder dialog.
4. Click [Search] in the Finder dialog.
5. Select the T\_Interfaces library.
6. Confirm with [OK].
7. Save the T\_Mechatronic\_ModularSystem library.
8. The interfaces of T\_Interfaces can now be applied in the T\_Mechatronic\_ModularSystem.

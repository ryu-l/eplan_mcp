# File System Name Check

Path to model variable:

Validation > File System Name Check

The model variable File System Name Check regulates the name check for newly created libraries and projects when the FiBa-Backend is used. The following values can be selected:

Ignore: Errors occurring during the name check are ignored.

Warning: Errors occurring during the name check are issued as warnings.

Error: Errors occurring during the name check are issued as errors.

# Adjoining devices with add-ons

Devices with (asymmetrical) attachments on a mounting rail cannot be placed directly with the handles M4 on the handles M2. Prior to positioning, you have to determine the widths of all of the mounting parts existing between the already-mounted device and the device to be mounted. These widths should then be used as the space (dx).

This specification is made using the following syntax:

```
=List{'M4','M2',<dx>}
```

# ecAction

Specifies the action,which is called by means of a command. For each parameter of the action one sub-element <param> must be configured.

| Attribute name | Usage | Attribute values | Default value | Description |
| --- | --- | --- | --- | --- |
| name | required |  |  | The absolute name of the invoked action |

| Allowed sub-elements | Quantity |
| --- | --- |

# de.eplan.eec.jobserver.disablehttps

The EEC argument must be transferred with the following syntax:

```
-D<Argument>=<Value>
```

| EEC argument | Usage |
| --- | --- |
| -Dde.eplan.eec.jobserver.disablehttps=<true/false> | Only for Job Server |
| **Annotation** | |
| Activates/deactivates support of the https protocol for the project.  Possible values are true and false.   ``` -Dde.eplan.eec.jobserver.disablehttps=true ```   Deactivates the support of the https protocol, the http protocol is used.   ``` -Dde.eplan.eec.jobserver.disablehttps=false ```   Activates support for the https protocol. | |

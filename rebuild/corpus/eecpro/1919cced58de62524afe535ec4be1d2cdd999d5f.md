# default

With the sub-element <default>, a sub-element (<input> or <label>) must be specified, which is displayed in the column of the pureTable if the previous conditions are not satisfied.

| Attribute name | Usage | Attribute values | Default value | Description |
| --- | --- | --- | --- | --- |
| on | required |  |  | Formula to the object |
| variable | optional |  |  | Name of the variable |

| Allowed sub-elements | Quantity |
| --- | --- |
| [input](refformui_r_input.htm) | 0..1 |
| [label](refformui_r_label.htm) | 0..1 |

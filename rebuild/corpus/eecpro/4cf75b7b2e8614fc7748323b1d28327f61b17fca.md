# mosWithPlaceholders(String typeName)

Navigation methods for mechatronic components

All active children and placeholders of the mechatronic component which are an instance of typeName or, for placeholders, whose type can be assigned to typeName (see [isInstanceOf(String typeName)](refformulas_r_project_components_isinstanceof.htm)).

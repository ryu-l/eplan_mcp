# Import ECAD libraries into T_Mechatronic_ModularSystem

To add the functions for the ECAD discipline to the T\_Mechatronic\_ModularSystem model, you will need to import the T\_Ecad\_Ui library.

1. Double-click to open the T\_Mechatronic\_ModularSystem library.
2. Select the Imported libraries editor.
3. Click ![](../Pictures/button_finder.png).

The library finder now appears:

![](../Pictures/tutorial_p8_bibliothek_importieren2.png)

1. Click [Search].
2. Select the T\_Ecad\_Ui library.
3. Confirm with [OK].

![](../Pictures/tutorial_p8_bibliothek_importieren3.png)

1. The modifications can be adopted by clicking the disk icon at the top left (or using [Ctrl] + [S]).

In the following, it is assumed that you save your modifications by the time you open the next object (disk icon top left or using the shortcut key [Ctrl] + [S]), and if not, by the time you see the prompt and click [Yes].

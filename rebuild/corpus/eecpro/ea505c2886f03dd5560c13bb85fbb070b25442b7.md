# Enter values for the DBNumber parameter

The task is to assign a value for the DBNumber parameter:

1. Open the FB\_Sequence function block.
2. Select the Parameters editor.
3. Enter 1 as the value for the DBNumber parameter.
4. Repeat steps 1 and 3 for the FB\_Insert, FB\_Move and FB\_Inspect function blocks. Enter the values from the following table for the DBNumber parameter.

| Function block | DBNumber | Comment |
| --- | --- | --- |
| FB\_Sequence | 1 |  |
| FB\_Insert | 9999 | Multi-instance |
| FB\_Move | 9999 | Multi-instance |
| FB\_Inspect | 9999 | Multi-instance |

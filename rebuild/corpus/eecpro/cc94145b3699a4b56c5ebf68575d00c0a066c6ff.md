# Generating the current status of the schematic

Generate the current status of the schematic.

![](../Pictures/tutp8_generateSchematic_1.png)

1. In the Project Explorer select the Mechatronic component.
2. In the shortcut menu, select ECAD > Generate\_structure.

![](../Pictures/tutp8_generateSchematicResult_1.png)

3. In parallel to Mechatronic, a structure consisting of the discipline root node ECAD, a schematic (Schematic\_Feeder), and two pages (PLC\_Sensors\_1\_8\_Feeder and PLC\_Sensors\_9\_16\_Feeder) has been created.

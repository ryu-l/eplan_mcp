# Import text discipline library

The ListOfComponents is a Text discipline that is defined by importing the TextDiscipline system library.

![](../Pictures/Komponentenliste_3.png)

1. Click on Imported Libraries to switch to the corresponding editor page.
2. Click on Import selected library to assembly to open the Library finder. Select the TextDiscipline library here.
3. Confirm with [OK].
4. The modifications can be adopted by clicking the disk icon at the top left (or using the shortcut key [Ctrl] + [S]).

In the following, it is assumed that you save your modifications by the time you open the next object (disk icon top left or using the shortcut key [Ctrl] + [S]), and if not, by the time you see the prompt and click Yes.

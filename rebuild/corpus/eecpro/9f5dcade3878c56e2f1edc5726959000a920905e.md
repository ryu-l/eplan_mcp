# Important Characters in Regular Expressions

| Characters | Meaning | Example | Result |
| --- | --- | --- | --- |
| X | Character X | 'X'.matches('X') 'Y'.matches('X') | true false |
| \\ | Backslash character | '\' matches('\\\\') '/'.matches('\\\\') | true false |
| \t | Tabulator character | ' '.matches('\\t') ' '.matches('\\t') | true false |
| \n | Line feed character | '\n'.matches('\\n') '\\n'.matches('\\n') | true false |

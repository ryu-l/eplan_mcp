# Comparison with sample solution

To compare the results achieved with the sample solution, the following EOX file is imported:

```
<EEC-Installationsordner>\install\Tutorial\Word\Word.eox.
```

Importing the EOX file:

1. Select File > Import... (File > Import...).

The import wizard opens with the Import dialog:

![](../Pictures/import_eox.png)

2. Select Model > Engineering Object Exchange Format (EOX Format).
3. Press Next > to confirm.

![](../Pictures/tutorial_word_eox_importieren.png)

4. Select Add in the Mode panel.
5. Select the file Word.eox in the Source panel.
6. Select the Feeder library.
7. Press Finish to confirm.

![](../Pictures/tutorial_word_eox_importieren2.png)

The following symbols appear in the figure above of the synchronization view:

| Symbol | Meaning |
| --- | --- |
|  | The incoming changes shown with a plus sign (+) indicate that a component is missing in your solution. |
|  | The incoming changes shown with a minus sign (-) indicate that there is one more component in your solution than in the sample solution. |
|  | The incoming changes shown with the red double arrow indicate that action is required on the part of the user. |

Incoming changes generally indicate that your solution differs from the sample solution. Double-click on the incoming change to view further information on the component.

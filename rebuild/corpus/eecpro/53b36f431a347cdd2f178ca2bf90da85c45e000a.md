# matches(String regEx)

String methods

Delivers true if the character string matches the regular expression regEx.

| matches(String regEx) | | | | |
| --- | --- | --- | --- | --- |
| Argument | String | regEx |  | |
| Return value | Boolean | |  | |

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Examples](javascript:void(0);)

| Formula | Result |
| --- | --- |
| ='abcaaefgaac'.matches('[a]{2}') | false |
| ='abcaaefgaac'.matches('\\w\*') | true |
| ='abcaaefgaac'.matches('abc.\*') | true |
| ='abcaaefgaac'.matches('.\*gaac') | true |
| ='abcaaefgaac'.matches('.\*efg.\*') | true |

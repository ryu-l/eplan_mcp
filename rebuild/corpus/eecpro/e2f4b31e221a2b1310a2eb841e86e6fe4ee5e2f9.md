# Insert sensor macros in mechatronic components

Add as components via Drag & Drop the discipline components Sensor\_Pressure, Sensor\_Inductive and Sensor\_Optical to all non-abstract sensors that are under T\_Mechatronic\_ModularSystem.Sensors:

- Pressuresensor contains Sensor\_Pressure
- Positionsensor\_inductive contains Sensor\_Optical
- Positionsensor\_optical contains Sensor\_Inductive

Then create the ECAD structure again. An error message will appear, because components cannot be assigned according to the plug-socket principle.

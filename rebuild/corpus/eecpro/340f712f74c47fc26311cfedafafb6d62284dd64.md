# Internal structure of editors

The following figure shows the internal structure of an editor. It consists of the areas Editor menu (A) and Editor page (B):

![](../Pictures/gui_editorinternalstructure.png)

1. The editor menu contains different menu items that open an editor page.
2. If a further editor is selected, it is displayed directly below the existing editor.
3. By default only one editor page is visible. However, several editors can be opened by pinning individual editors by using the icon ![](../Pictures/Gui/pin.png).

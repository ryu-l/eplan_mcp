# Creating components

### [ClosedCreate architecture components](javascript:void(0);)

Architecture components are abstract mechatronic components of the MechatronicComponent type with a functional construction hierarchy.

To create an architecture component:

![Create architecture component step 1](../Pictures/createMechatronicComponent_1.png)

1. Call up the popup menu of a library or a unit and select New > Engineering > MechatronicComponent here.

The editor of a new component is opened via the Attributes editor page.

![Create architecture component step 2](../Pictures/createMechatronicComponent_2.png)

1. Enter a name for the new component.
2. Select an optional image with ![](../Pictures/button_set_image.png).
3. Select the Abstract check box.
4. Optionally enter a comment for the component.
5. Switch to the Level configuration editor page.

![Create architecture component step 3](../Pictures/createMechatronicComponent_3.png)

1. If necessary, select the Top-level element check box.
2. Start the finder for subordinate components ![](../Pictures/Gui/ALL/new.png) and select one or more components from the search result.
3. The selected components are applied in the list of the subordinate components.
4. Save with [Ctrl] + [S] or ![](../Pictures/speichern.png).

The component is created as a result of the assignment of a name and subsequently the saving of the editor. Without a valid name the name field is highlighted in red. A name must be unique within a unit.

### [ClosedCreating mechatronic components](javascript:void(0);)

Mechatronic components are objects of the type MechatronicComponent. Mechatronic components are either derived from architecture components or created directly. During derivation of an architecture or other mechatronic components all attributes are inherited, for example the image and the level configuration, so that they do not have to be specified anymore.

To create mechatronic components directly:

![Create mechatronic component step 1](../Pictures/createMechatronicComponent_4.png)

1. Call up the popup menu of a library or a unit and select New > Engineering > MechatronicComponent here.

![Create mechatronic component step 2](../Pictures/createMechatronicComponent_5.png)

1. Enter a name for the new component.
2. Select an optional image with ![](../Pictures/button_set_image.png).
3. Select the Abstract check box optionally.
4. Optionally enter a comment for the component.
5. Switch to the Level configuration editor page.

![Create mechatronic component step 3](../Pictures/createMechatronicComponent_6.png)

1. Optionally select the Top-level element check box.
2. Start the finder for subordinate components ![](../Pictures/Gui/ALL/new.png) and select one or more components from the search result.
3. The selected components are applied in the list of the subordinate components.
4. Save with [Ctrl] + [S] or ![](../Pictures/speichern.png).

The component is created as a result of the assignment of a name and subsequently the saving of the editor. Without a valid name the name field is highlighted in red. A name must be unique within a unit.

This way you derive a mechatronic component from an architecture component or another mechatronic component:

![Derive mechatronic component step 1](../Pictures/MechatronikkomponenteAbleiten_1.png)

1. Call up the popup menu of a library or a unit and select New > Mechatronic > Name of the component here.

![Derive mechatronic component step 2](../Pictures/MechatronikkomponenteAbleiten_2.png)

1. Enter a name for the new component.
2. Select the Abstract check box optionally.
3. Optionally enter a comment for the component.
4. Save with [Ctrl] + [S] or ![](../Pictures/speichern.png).

The component is created as a result of the assignment of a name and subsequently the saving of the editor. Without a valid name the name field is highlighted in red. A name must be unique within a unit.

### [ClosedCreating discipline components](javascript:void(0);)

Discipline components are mechatronic components to which, as a rule, a resource, e.g. a macro file, is assigned. No resources are assigned to abstract discipline components. They are only used to define superclasses from which concrete discipline components are subsequently derived.

To create concrete discipline components:

![Create discipline component step 1](../Pictures/DisziplinkomponenteErstellen_1.png)

1. Call up the popup menu of a library or a unit and select New > Discipline name > Discipline component here.

![Create discipline component step 2](../Pictures/DisziplinkomponenteErstellen_2.png)

1. Click [Import...] and select a resource file to import it.

![Create discipline component step 3](../Pictures/DisziplinkomponenteErstellen_3.png)

The name of the resource is applied as a name for the discipline component.

1. Optionally enter a comment for the component.
2. Save with [Ctrl] + [S] or ![](../Pictures/speichern.png).

The component is created as a result of the assignment of a name and subsequently the saving of the editor. Without a valid name the name field is highlighted in red. A name must be unique within a unit.

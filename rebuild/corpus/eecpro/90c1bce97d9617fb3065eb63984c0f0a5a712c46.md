# FORM-UI

The Form-UI is a XML-defined user interface that is used to define user-specific views on the mechatronic model.

![](../Pictures/2009021201.svg)

The user interface is displayed in EEC independent of the UI technology and by means of appropriate adapters displayed in a web browser, a swing client or a rich client or directly in EEC.

![](../Pictures/2011041301.svg)

The reference chapter contains a description of the possible structure elements of a Form-UI.

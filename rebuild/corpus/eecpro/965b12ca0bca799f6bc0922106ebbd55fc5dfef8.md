# Use the method of the new plug-in in EEC

The method of the new plug-in must be used in the same class (library component), as already specified in the section on [Creating a class for the extension](eecscripting_k_implement_create_class_for_extension.htm) (1). In the editor for the library component (e.g. MyClass).

![](../Pictures/java_ec_methode_1.png)

In the Methods editor view (2), make the following entries:

- Click Add to add a new method to the list of methods (3).
- Enter the name of the method (4).
- Select the return type (5).
- For the language type select Native (6).
- Add the arguments that are to be passed to the method and declare them with the appropriate type (7).

# filter

The <filter> tag defines which files from the Worker should be reacted to when executing this Job definition in the incoming folder.

| Attribute | Usage | Values | Default value | Description |
| --- | --- | --- | --- | --- |
| value | required | \*.xls, \*.xlsx, \*.imx |  | Specifies which files the Job Server should react to when executing the Job definition. Multiple entries should be separated by the pipe symbol, e.g. \*.xls|\*.xslx. |

### [ClosedExample of a file specification that permits all Excel formats.](javascript:void(0);)

```
<filter value="*.xlsx|*.xls" />
```

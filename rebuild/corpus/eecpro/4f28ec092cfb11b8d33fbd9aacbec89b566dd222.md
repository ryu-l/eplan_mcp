# rdc(String typeName)

Navigation methods for discipline-specific components

Determines all superordinate discipline-specific components which are an instance of the type typeName (see [isInstanceOf(String typeName)](refformulas_r_project_components_isinstanceof.htm)) (see [Project component navigation methods](refformulas_r_project_components_navigation.htm)).

| Argument | String | typeName | Type of the components to be determined |

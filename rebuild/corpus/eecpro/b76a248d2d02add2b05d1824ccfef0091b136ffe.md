# Block, expression, condition

A block is a group of instructions (expressions) or conditions (conditions).

An instruction (expression) is any construct of the formula language.

### [ClosedExample for the sortedBy(Block expression) method:](javascript:void(0);)

| Formula | Result |
| --- | --- |
| =List{'abc','c','bf'}.sortedBy(x|x.size) | [c, bf, abc] |
| =List{'abc','c','bf'}.sortedBy(x|x.$Name) | [abc,bf,c] |

A condition (Condition) is a formula that must return a Boolean-type value.

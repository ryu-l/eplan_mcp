# com.mind8.formui.aliasUrl

The EEC argument must be transferred with the following syntax:

```
-D<Argument>=<Value>
```

| EEC argument | Usage |
| --- | --- |
| -Dcom.mind8.formui.aliasUrl=<URL> | Only for Web EEC |
| **Annotation** | |
| Replaces the URL for the download of generated documents.  Example:   ``` -Dcom.mind8.formui.aliasUrl=https:\\www.downloads.MyCompany.com ```   URL for downloads without specification for com.mind8.formui.aliasUrl:   ``` http:\\MyCompany.com ```   URL for downloads with specification for com.mind8.formui.aliasUrl:   ``` https:\\www.downloads.MyCompany.com ``` | |

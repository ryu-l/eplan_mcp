# Generation of variants via disabler

First, using the maximum principle, all possible components are created in the library. To create variants, the components that are not to be included will be excluded (disabled) by the composition. In this tutorial, we do not want to use in the Feeder component the function groups Inspect and Discard. For this purpose, we disable the installed components Inspect and Discard.

![](../Pictures/tutmechatronic_InspectDisablerTrue.png)

1. Open the Feeder component.
2. Click the installed component Inspect.
3. In the Disabled field, enter = true.
4. Repeat the steps 2 to 3 for the Discard component.

The effect is visible in the project without updating via [F5]:

![](../Pictures/tutmechatronic_resultWithoutInspect.png)

In the Feeder project component, only the components Store, Insert, and Move remain.

### Note

As long as the filter is not enabled, the disabled components will be displayed as well.

The filter is enabled in the toolbar of the Project Catalog.

1. Enable the filter by clicking ![](../Pictures/filteronoff.png).
2. Open the filter dialog by clicking ![](../Pictures/filter.png).

You set the options in the filter dialog.

![](../Pictures/tutorial_mechatronik_filter_settings.png)

1. Highlight the Disabled Components option.

# Task: Generate a ListOfComponents

The task is to create a ListOfComponents with the following structure based on the functional, mechatronic of a plant.

![](../Pictures/Komponentenliste_1.png)

To achieve this goal, this chapter will begin by describing how to create a new ListOfComponents discipline on the basis of the Text discipline. It then goes on to show how to create a reusable text block and how to check the modular system components of the list of components using a test configuration.

The connection of this new discipline to the mechatronic model will be examined in the next chapter.

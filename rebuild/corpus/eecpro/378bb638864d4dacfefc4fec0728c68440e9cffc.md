# excludes(Object obj)

General methods for Collections

Delivers true if the assigned object is not included in the collection.

| excludes(Object obj) | | | |
| --- | --- | --- | --- |
| Argument | Object | obj | Object which should not be included in the collection. |
| Return value | Boolean |  | |

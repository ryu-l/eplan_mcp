# Insert schematic and page into mechatronic components

In the first step, discipline components for the schematic and page must be linked with the mechatronic component Feeder:

![](../Pictures/tutp8_importDisciplineSubcomponents_1.png)

1. Open the Feeder component.
2. Using Drag & Drop, drag the Schematic component once, and the Page component twice into the component panel of the editor.
3. Name Page and Page2 to PLC\_Sensors\_1\_8 and PLC\_Sensors\_9\_16.

The result should look as follows:

![](../Pictures/tutp8_importDisciplineSubcomponentsResult.png)

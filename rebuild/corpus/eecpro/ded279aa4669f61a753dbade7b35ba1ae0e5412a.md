# delete(IEngineeringObject eo)

The delete method of the UnitOfWork deletes the specified object.

### [ClosedExample code](javascript:void(0);)

#### Requirements:

- The model data of install\scripting\scripting.eox have been imported.
- The Move.Axes placeholder contains at least one instance of Axis.

The following script example (ScriptingExamples.deleteObject) removes an Axis project component from the Move.Axes placeholder.

For the example the SelectionAction deleteObject has to be executed on the Move project component.

The name of the placeholder is specified directly as a string (see row 14).

To delete only the last project component on the placeholder, the method obj.sortPlaceholderObjects(placeholderName,"x | x.name") first sorts all instances on the specified placeholder (see row 20).

The obj.getPlaceholderObjects(placeholderName) method finds all instances on the specified placeholder (see row 23).

The last() method finds the most recently installed project component from the list of installed instances (see row 28).

The query whether the determined project component is installed on a placeholder is carried out with the method if(moToDelete.isPlaceholderPlaced()) (see row 33).

If the result of the query is true, the uow.delete method deletes the project component found.

The uow.saveChanges() method (see row 39) is used to make the change effective in the Unit-Of-Work in the project.

The output of information and possible errors is carried out in the message log (see rows 9, 16, 25, 30, 36, 40, 44, 47 and 51).

```
import org.foederal.util.ui.messages.UserMessageCollector;
import org.foederal.eobroker.core.IUnitOfWork;
import com.mind8.mechatronic.skill.api.PlaceholderNotExistingException;
import com.mind8.expressionparser.EvaluationException;
import org.foederal.eobroker.core.IEngineeringObject;

String scriptName = "deleteObject";
String info = "### Start of script '" + scriptName + "' ###";
UserMessageCollector.addInfo(LIBRARY,'self',null,"Scripting",info);

// determine the UnitOfWork
uow = self.getUnitOfWork();

String placeholderName = "Axes";
info = "placeholderName: " + placeholderName;
UserMessageCollector.addInfo(LIBRARY,'self',null,"Scripting",info);

try{
	// Sort Objects on placeholder
	obj.sortPlaceholderObjects(placeholderName,"x | x.name");
	
	// Absolute name of object to delete
	mosOnPlaceholder = obj.getPlaceholderObjects(placeholderName);
	info = "mosOnPlaceholder: " + mosOnPlaceholder;
	UserMessageCollector.addInfo(LIBRARY,'self',null,"Scripting",info);
	
	// Determine last object on placeholder
	moToDelete = mosOnPlaceholder.last();
	info = "moToDelete: " + moToDelete;
	UserMessageCollector.addInfo(LIBRARY,'self',null,"Scripting",info);
	
	// Delete object if placed on placeholder
	if(moToDelete.isPlaceholderPlaced()){
		uow.delete(moToDelete);
		info = "Object is deleted";
		UserMessageCollector.addInfo(LIBRARY,'self',null,"Scripting",info);
		
		// save the change
		uow.saveChanges();
		UserMessageCollector.addInfo(LIBRARY,'self',null,"Scripting","UOW saved");
	}
}
catch (EvaluationException ex){
	UserMessageCollector.addError(LIBRARY,'self',null,"Scripting",ex);
}
catch (PlaceholderNotExistingException ex){
	UserMessageCollector.addError(LIBRARY,'self',null,"Scripting",ex);
}

info = "### End of script '" + scriptName + "' ###";
UserMessageCollector.addInfo(LIBRARY,'self',null,"Scripting",info);
```

### Result:

Applied to the project component Feeder\_Extended1.Mechatronic.Feeder.Move of the tutorial, the SelectionAction removes the last installed instance of Axis on the placeholder Axes.

# Path to the project template

Path to model variable:

Disciplines > ECAD > Eplan Electric P8 > Eplan Data Zip (.edz) generation

The model variable Path to the project template specifies the name of the parameter, which specifies the path to the project template.

The default value is template\$(Eplan\_VERSION\_SHORT).

The entire path to the project template results from the composition of these module variables and the model variables [Macro project template](admin_r_modelvar_p8edzmacroprojecttemplate.htm).

### Example

Path to the project template = template\$(Eplan\_VERSION\_SHORT)\

Macro project template = Template\_Project-zw1

Result:

```
template\$(Eplan_VERSION_SHORT)\Template_Project.zw1
```

# globalResourcePath()

System methods

Determines the EEC global resource folder in Windows notation, that means with backslashes as separators and a final backslash. This folder can also be explicit assigned in the initial file (e.g. ec.ini), for example

-Dde.eplan.eec.global.resourcePath=E:\Users\Public\EPLAN\EngineeringConfiguration\2022\_1\resources

| **globalResourcePath()** | | | | |
| --- | --- | --- | --- | --- |
| Argument |  |  |  | |
| Return value | String | | The EEC resource folder | |

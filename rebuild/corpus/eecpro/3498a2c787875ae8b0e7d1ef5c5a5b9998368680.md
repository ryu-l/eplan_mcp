# Supplementing Eclipse initialization file

The initialization file of the installed Eclipse (eclipse.ini) has to be supplemented with the following row below the -vm row:

```
<path to jdk>/bin/javaw.exe
```

Replace <path to jdk> with the current path to the installed JDK.

Once the initialization file has been modified, EEC has to be restarted.

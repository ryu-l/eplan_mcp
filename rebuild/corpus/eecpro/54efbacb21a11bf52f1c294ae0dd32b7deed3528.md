# derived()

Navigation methods for discipline-specific components

Is used in the mechatronic structure to access the corresponding object in the discipline-specific structure (see [Project component navigation methods](refformulas_r_project_components_navigation.htm)).

The result is <null> if the discipline-specific structure is not created, yet.

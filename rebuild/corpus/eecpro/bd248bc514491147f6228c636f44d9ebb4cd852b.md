# Views

The user interface consists of different views of the model. The following figure illustrates the understanding of views:

![](../Pictures/2007010301.svg)

Views generally show a section of the overall model: Views serve to represent objects of the model in a suitable structure based on a selection that is meaningful in terms of the task at hand. As a result of the modular combination of different views, a number of workflows can be supported.

An object of the model can be displayed in several views at the same time. Modifications to a view are imported into the model, and other views are updated.

Views can be selected via the menu Window > Show view. In the following figure different views are identified through a yellow framing.

![](../Pictures/eecbase_view.png)

1. Views can be moved in any manner as well as arranged side-by-side or on top of each other within the window by grabbing them with a left mouse click. Alternatively, views can also be stacked.
2. Views are closed by using the small x in the title bar.
3. The familiar Windows mechanisms can be used to change the size of the respective view: Touching the border of the window allows for its size to be modified. Minimizing and maximizing are possible via the two icons at the top right-hand border of each view window. Alternatively, double-clicking the title bar will maximize and minimize a view.

# sum()

General methods for Collections

Returns the sum of all objects in the Collection. The included objects have to support the + operator.

| sum() | | | |
| --- | --- | --- | --- |
| Argument |  |  |  |
| Return value | String, Integer or Double | Sum of the included objects | |

# Importing Pro Panel libraries into T_Mechatronic_ModularSystem

To add the functions for the Pro Panel discipline to the T\_Mechatronic\_ModularSystem model, you will need to import the T\_Pro Panel\_Ui library.

1. Double-click to open the T\_Mechatronic\_ModularSystem library.
2. Select the Imported libraries editor.
3. Click the Add library button.

The library finder now appears:

![](../Pictures/tutorial_pp_bibliothek_importieren2.png)

4. Click Search.
5. Select the T\_Pro Panel\_Ui library.
6. Confirm with OK.

![](../Pictures/tutorial_pp_bibliothek_importieren3.png)

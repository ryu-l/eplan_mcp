# Create specific mechatronic components

Through the derivation of abstract architecture components create concrete, meaning instantiatable, mechatronic components.

| Mechatronic component | Derived from architecture component | Unit |
| --- | --- | --- |
| Feeder | Station | Stations |
| Discard  Insert  Inspect  Move  Store | Functiongroup | Functiongroups |
| Axis  Gripper  Orientationinspector  Separator  Stack | Functionunit | Functionunits |
| Cylinder  Valve | Actuator | Actuators |
| Positionsensor  Pressuresensor | Sensor | Sensors |

See [Creating a mechatronic component](eecbase_k_create_mechatronic_component.htm).

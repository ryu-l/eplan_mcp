# Menu Help

The Help menu contains the following menu items:

| Menu item | Meaning |
| --- | --- |
| Content | Calls up the help with open Content tab. |
| Eplan tips | Shows a page with tips for the started program variant serve to facilitate your start with new functionalities and working methods. |
| Create Eplan support request | Starts an Eplan Internet page with a form for a support request. |
| Eplan Download Manager | Starts the Eplan Download Manager and offers the possibility to install the Help system in various languages. |
| Customer-focused improvement program | Opens the Customer-focused improvement program dialog, where you can decide if you want to participate in this program. |
| About | Opens the About Eplan dialog containing the following information:   - Product - License extent - Copyright / Trademark - System information |

# getPlaceholderNames

Returns a list of names of all placeholders in this mechatronic component.

The method is executed directly on the component.

| getPlaceholderNames() | | | |
| --- | --- | --- | --- |
| Argument |  |  |  |
| Return value | List | | List of placeholder names |

### [ClosedExample code](javascript:void(0);)

#### Requirements:

- The model data of install\scripting\scripting.eox have been imported.

The following script example (ScriptingExamples.getPlaceholderNames1) determines the names of all placeholders of a project component.

For the example the SelectionAction getPlaceholderNames1 has to be executed on the project component Feeder or Move.

The getPlaceholderNames() method provides a list of all names of the placeholders under the current project component (see row 9).

```
import org.foederal.apache.log4j.SpaceLogger;

SpaceLogger logger = SpaceLogger.getSpaceLogger("My logger");

String scriptName = "getPlaceholderNames1";
logger.info("### Start of script '" + scriptName + "' ###");

// Determine placeholder names for selected object
placeholderNames = obj.getPlaceholderNames();
logger.info("placeholderNames: " +  placeholderNames);

logger.info("### End of script '" + scriptName + "' ###");
```

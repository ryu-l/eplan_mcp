# Creating a unit structure

The discipline components and their parameters should be created in a single structure. The structure is built of hierarchically ordered units. In the T\_Mechatronic\_ModularSystem library create the ECAD unit, and in it, the ProPanel subunit:

1. Select the T\_Mechatronic\_ModularSystem library.
2. Select New > Engineering > Unit in the popup menu.
3. In the Name field, enter the text ECAD.
4. Save the unit with [Ctrl] + [S].
5. Select the ECAD unit.
6. Repeat steps 2 to 4. Enter the unit name ProPanel in the process.

### Note

When following instructions that describe how to create or modify something, always press [Ctrl] + [S] at the end. In the following instructions, this mandatory step is no longer carried out explicitly.

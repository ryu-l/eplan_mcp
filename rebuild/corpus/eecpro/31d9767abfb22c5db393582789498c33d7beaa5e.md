# paletteEntry

With the element <paletteEntry> all objects are defined to be represented in the palette on the edge of the graphical editor. This can be connections, as well as engineering objects.

| Attribute name | Usage | Attribute values | Default value | Description |
| --- | --- | --- | --- | --- |
| group | optional |  |  | Groups the enclosed palette elements |
| id | required |  |  | A unique ID for the element of the palette |
| largeIcon | required |  |  | Path to an icon in the resource folder of the diagram (size is 24 x 24 pixels) |
| smallIcon | required |  |  | Path to an icon in the resource folder of the diagram (size is 16 x 16 pixels) |
| text | required |  |  | Label of the palette element |
| visible | optional | true, false | true | Visibility true = visible false = hidden |

| Allowed sub-elements | Quantity |
| --- | --- |
| [connectionCreation](refgraph2d_r_connectioncreation.htm) | any |
| [eoCreation](refgraph2d_r_eocreation.htm) | any |
| [nodeCreation](refgraph2d_r_nodecreation.htm) | any |

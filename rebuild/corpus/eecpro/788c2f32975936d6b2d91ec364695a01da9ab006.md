# project()

Navigation methods for project components

Determines the project which contains the project component. If there is a unit incorporated within a project, the unit is returned.

| **project()** | | | | |
| --- | --- | --- | --- | --- |
| Argument |  |  |  | |
| Return value | Project | | The project of the project component | |

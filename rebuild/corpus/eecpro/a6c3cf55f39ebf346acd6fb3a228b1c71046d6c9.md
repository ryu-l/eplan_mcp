# Selecting an EOX file during the start

Requirements:

- The preparatory steps on the file level have been carried out.
- EEC has not yet been started after the installation.

The EOX file that was copied into the \eox folder during the preparatory steps is to serve as the data basis for this tutorial. This contains the mechatronical modular system with the required extensions for this tutorial.

Proceed as follows to select the data basis for this tutorial when starting EEC:

1. Start EEC

![](../Pictures/tutimp_choose_eox.png)

1. Select the following EOX file:

```
<EEC installation path>\eox\Tutorial_Import.eox
```

1. Remove the marking of the Open read-only option.
2. Confirm with [OK].

### Note

This selection is only displayed during the first start. To call up this selection again open the menu File > Switch back-end > Select.

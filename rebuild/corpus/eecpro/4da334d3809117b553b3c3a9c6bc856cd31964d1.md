# Create a mechatronic library

Create the T\_Mechatronic\_ModularSystem library for the mechatronics modular system of the tutorial.

The mechatronic components of the modular system are derived from the existing created abstract architecture components. Import the architecture library T\_Mechatronic\_Architecture to this purpose.

See [Creating libraries](eecbase_k_libraries.htm).

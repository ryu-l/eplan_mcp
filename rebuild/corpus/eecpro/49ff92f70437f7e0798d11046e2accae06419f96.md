# Using the help system

### [ClosedDialog call](javascript:void(0);)

Help > Contents

If you have opened a dialog, you can also activate the context help ([F1]).

You can directly select a help topic from the contents menu. The help system also provides you with a number of different search alternatives. You can navigate via the index or the full-text search. The glossary is available for definitions of terms.

The syntax which is used for searching orients itself towards the syntax of well-known Internet search machines.

### Note

The text search allows a search for synonyms: A suitable search result is shown in many cases even when you enter similar or incorrect search terms or ones no longer used.

### [ClosedUsing a search filter](javascript:void(0);)

The text search in the help can be restricted by means of a search filter to specific categories. Possible categories are Eplan product variants (such as "Eplan Electric P8") and the page types of the help system (for example "operating information", "check run messages"). The search filter can be set before the search is started or be activated in the search result.

1. Click the [Search in] button on the right next to the input field of the text search.
2. Select a category from the drop-down list.
3. Enter a search term and start the search with the ![](../Pictures/Gui/ALL/helpsystem_startsearch_as.png) button.  
     
   ![](../CSS/arrow.png) Only the find locations from the selected category are displayed in the search result.
4. Select a different category from the drop-down list.  
     
   ![](../CSS/arrow.png) Only the find locations from the new category are displayed in the search result.

### [ClosedAutoComplete for search terms](javascript:void(0);)

In the online version search terms are completed automatically while being entered in the input field of the text search. The suggested terms are contained in the help system index.

Automatic search suggestions can also be combined with search filters.

### [ClosedSetting the start language for the help](javascript:void(0);)

In the settings you can specify the language in which the help system is to be started. This setting applies for the locally installed help system and for the online version via the Internet connection.

1. Select the following menu items: Options > Settings > User > Display > Languages
2. In the Settings: Languages dialog select the Language field in the Help system group box.
3. Select the desired language from the drop-down list and confirm.

### Notes

- If you are using the locally installed help system: You can only select another language for the help system if extra languages were installed when the system was initially installed.
- Your can download further help languages available for local installation by using the menu items Help > Eplan Download Manager and install them on your computer. (If you need help during the installation press [F1] in the Eplan Download Manager.)

### [ClosedSwitching the help language](javascript:void(0);)

The online version of the help allows you to switch between all the available languages.

1. Click the button in which the current help language is displayed in the toolbar of the help.
2. Select the language to which you want to switch from this drop-down list.  
     
   ![](../CSS/arrow.png) The help system shows the current page in the selected language.

# Toolbar with tools to create new instances

One part of the graph-UI palette is the Components section (see following figure). It contains tools for instantiating components within the diagram.

![](../Pictures/diagram_eo_erzeugungswerkzeuge.png)

In order to instantiate a component, the according tool of the component is selected in the palette. Left-clicking the mouse on the diagram editor creates an instance of the comonent.

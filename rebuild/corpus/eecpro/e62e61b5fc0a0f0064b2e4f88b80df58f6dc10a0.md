# Plus operator for string

String operator

The operator + (plus) hangs strings together (concatenate strings).

| <Character string1> + <Character string2> | | | |
| --- | --- | --- | --- |
| Expressions | String | String1 | Arithmetic operator |
| String | String2 | Arithmetic operator |
| Return value | String |  | |

# Adding a controller

A controller is first needed as the root element. This must be created in the new Step7 unit.

1. Select the Step7 unit.

![](../Pictures/tutorial_s7_steuerung1.png)

1. From the popup menu, select New > STEP 7 > Control Device > Controller.
2. In the Name field, enter the text SiemensCPU.
3. Save the controller ([Ctrl] + [S]).

### Note

When following instructions that describe how to create or modify something, always press [Ctrl] + [S] at the end. In the following instructions, this mandatory step is no longer carried out explicitly.

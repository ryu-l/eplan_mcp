# Set preferences in EEC

The cabinet is generated using IEC\_bas001.zw9, the default macro-project template delivered with EPLAN Pro Panel.

1. Select Disciplines > ECAD > EPLAN Electric P8.

![](../Pictures/tutorial_pp_benutzervorgaben2.png)

2. In the Macro project template field, enter the path to the file IEC\_bas001.zw9.
3. Confirm with OK.

EPLAN Electric P8 is launched by EEC to generate the wiring diagrams. For this purpose, the path for the executable file W3u.exe must be made known to EEC:

1. Select Disciplines > ECAD > EPLAN Electric P8.

![](../Pictures/tutorial_pp_benutzervorgaben3.png)

2. In the EPLAN Electric P8 executable field, enter the path for the file W3u.exe.

The field is already pre-filled with a path, but that path may be different from the one in the version that you use.

![](../Pictures/Gui/ALL/note.png)Note:

The versions of EEC and EPLAN Pro Panel have to have the same version!

If a different path is shown, you must do a restart after confirming.

3. Confirm with OK.

# de.eplan.eec.jobserver.worker.autostart

The EEC argument must be transferred with the following syntax:

```
-D<Argument>=<Value>
```

| EEC argument | Usage |
| --- | --- |
| -Dde.eplan.eec.jobserver.worker.autostart=<true/false> | Only for Worker |
| **Annotation** | |
| If the value is true (case insensitive) the Worker starts automatically on start and opens the Job Server perspective. If all conditions for execution of a job are met, the job execution starts immediately.  Example:   ``` -Dde.eplan.eec.jobserver.worker.autostart=true ``` | |

# Placing 3D Macros

A 3D-Macro can be placed directly instead of a part.

The discipline component must dispose of the type Macro3D via the parameter Macro3D.

The absolute path to the 3D-Macro is specified as the parameter value.

Example:

```
=type('Engineering.System').globalResourcePath()+'ECAD3D\\faz 6-1pol_3D.ema'
```

# Importing an architecture library

To add a discipline component for the ListOfComponents for the mechatronic modular system T\_Mechatronic\_ModularSystem, the T\_ListOfComponents\_Architecture library has to be imported:

![](../Pictures/tuttext_importArchitectureLibrary.png)

1. Double-click to open the T\_Mechatronic\_ModularSystem library.
2. Click Imported Libraries to switch to the corresponding editor page.
3. Move the T\_ListOfComponents\_Architecture library to the Imported libraries diagram.

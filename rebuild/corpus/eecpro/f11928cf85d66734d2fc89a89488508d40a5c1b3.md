# formButtonArea

The <formButtonArea> element encloses the definition of the buttons for popup windows of the type <messageForm>.

A messageForm can contain any buttons, but only in the combinations cancelButton with okButton **or** yesButton with noButton.

| Attribute name | Usage | Attribute values | Default value | Description |
| --- | --- | --- | --- | --- |
| none |  |  |  |  |

| Allowed sub-elements | Quantity |
| --- | --- |
| [cancelButton](refformui_r_cancelbutton.htm) | 0..1 |
| [noButton](refformui_r_nobutton.htm) | 0..1 |
| [okButton](refformui_r_okbutton.htm) | 0..1 |
| [yesButton](refformui_r_yesbutton.htm) | 0..1 |

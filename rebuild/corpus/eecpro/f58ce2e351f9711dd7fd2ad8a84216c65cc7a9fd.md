# uis

The Form-UI element <uis> is the top-level element. All following Form-UI elements are wrapped by this element. The element does not have any attributes.

| Allowed sub-elements | Quantity |
| --- | --- |
| [form](refformui_r_form.htm) | any |

### [ClosedExample code](javascript:void(0);)

```
<uis>
	<form title="Formular 1" id="fm1" >
		<label>Formular 1</label>
	</form>
	<form title="Formular 2" id="fm2" >
		<label>Formular 2</label>
	</form>
</uis>
```

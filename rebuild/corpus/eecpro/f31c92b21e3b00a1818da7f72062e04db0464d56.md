# Import EOX files for EPLAN Pro Panel

The T\_Pro Panel\_Ui discipline library, as well as the T\_Mechatronic\_Architecture and T\_Mechatronic\_ModularSystem libraries created in the âMechatronicsâ section, must be available before the Pro Panel discipline components are imported.

Based on the initial situation, various EOX files that contain the corresponding libraries must be imported:

- The model is empty, i.e., only the system libraries are available (also see [Filter](eecbase_k_filter.htm)). Import the following EOX files:

```
<EEC-Installationsordner>\install\Tutorial\Mechatronic\Mechatronic.eox
<EEC-Installationsordner>\install\Tutorial\ProPanel\ProPanel_Ui.eox
```

- The model contains T\_Mechatronic\_Architecture and T\_Mechatronic\_ModularSystem but not T\_Pro Panel\_Ui. Import the following EOX file:

```
<EEC-Installationsordner>\install\Tutorial\ProPanel\ProPanel_Ui.eox
```

- The model contains T\_Pro Panel\_Ui but not T\_Mechatronic\_Architecture and T\_Mechatronic\_ModularSystem. Import the following EOX file:

```
<EEC-Installationsordner>\install\Tutorial\Mechatronic\Mechatronic.eox
```

Proceed as follows to import the required EOX files:

1. Start EEC
2. Select File > Import... (File > Import...).

The import wizard opens with the Import dialog:

![](../Pictures/import_eox.png)

3. Select Model > Import wizard for model files in Engineering Object Format (EOX Format).
4. Press Next > to confirm.

![](../Pictures/tutorial_pp_eox_importieren2.png)

5. Select Add in the Mode panel.
6. Select the required EOX file in the Source panel.
7. Select the required libraries.
8. Press Finish to confirm.

![](../Pictures/tutorial_pp_eox_importieren3.png)

9. Use the ![](../Pictures/button_accept_incoming_changes.png) button to apply all incoming changes in the Synchronization view.
10. If necessary, repeat steps 2 to 9 and select the next EOX file that you need.

# mos(Integer depth)

Navigation methods for mechatronic components

mos(depth) returns the children of the depth level below the mechatronic component.

| **mos(Integer depth)** | | | | |
| --- | --- | --- | --- | --- |
| Argument | Integer | depth | Subordinate hierarchy level in which mechatronic components are determined | |
| Return value | List | |  | |

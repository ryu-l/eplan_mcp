# Modifying the formulas

New formulas are necessary due to the encapsulation of the discipline components and the usage of interface parameters.

### [ClosedThe formulas for component M\_Schematic](javascript:void(0);)

1. Open the component M\_Schematic.
2. Switch to the Parameter editor page.
3. Enter the following value for the FunctionDesignation parameter:

```
=mc.$FunctionDesignation
```

1. Save the component.

The formula =mc.$FunctionDesignation requires that a FunctionDesignation parameter exists in the higher-level component, meaning the Feeder component and that it supplies a suitable value. This parameter must still be inserted in the Feeder and have a value assigned to it.

### [ClosedCreating the FunctionDesignation parameter and inserting it into Feeder](javascript:void(0);)

1. Mark the Mechatronic.Parameter unit in the T\_Mechatronic\_ModularSystem library.
2. Select New > Engineering > Parameter.
3. Specify the FunctionDesignation name.
4. Specify the String type.
5. Save the parameter.

Insert the FunctionDesignation parameter into the Feeder component.

1. Open the Feeder component.
2. Open the Parameters editor page.
3. Drag the Plant parameter from the Parameter unit into the editor page.
4. Enter the ='Feederâ formula as the value.
5. Save the component.

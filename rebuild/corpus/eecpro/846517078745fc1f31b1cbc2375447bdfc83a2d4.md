# ifNull(Block expression)

The condition ifNull returns the block expression, if the receiving object is <null>, otherwise the receiving object is returned as the result.

| **ifNull(Block expression)** | | | | |
| --- | --- | --- | --- | --- |
| Argument | Block | expression | Expression to be returned if the object is <null> | |
| Return value | Result or block expression | | | |

### [ClosedExamples](javascript:void(0);)

| Formula | Result |
| --- | --- |
| =null.ifNull('Object is <null>') | Object is <null> |

# Allocating the parameters of the S7_313C component

For creating the input and output addresses (IO\_Generation), the S7\_313C component must first allocate the following parameters:

1. Open the S7\_313C component.
2. Open the Parameter editor.
3. Drag the following parameters from the Parameter unit into the editor.

- IO\_BitRange
- IO\_InputBlockSize
- IO\_InputStartAddress
- IO\_InputStartAddressFormat
- IO\_OutgoingBus
- IO\_OutputBlockSize
- IO\_OutputStartAddress
- IO\_OutputStartAddressFormat
- IO\_Place
- IO\_Places
- Bit0\_IX to Bit23\_IX
- Bit0\_QX to Bit15\_QX

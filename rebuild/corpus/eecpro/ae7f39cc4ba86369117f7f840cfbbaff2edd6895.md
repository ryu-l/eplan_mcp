# aliasURL

The <aliasURL> tag specifies a URL for links that are returned to the client when it is an alias. An alias is a replacement of the machine name in the network in the form of a URL. For example, the Job Server is installed on the machine SRV\_101 and can be addressed via Port 8070. An alias jobserver.corporation.lan with Port 80 through which the queries are placed at the Job Server is defined in the network. The URL http://jobserver.corporation.lan must therefore be entered in the <aliasURL> tag.

| Attribute | Usage | Values | Default value | Description |
| --- | --- | --- | --- | --- |
| value | required |  |  | URL that is to be used to call the Job Server (for example call a Job status). |

# Logging

EEC stores log files that save all program messages and alerts that occur. Scripts, too, can create messages and store them in the logging system. In the event of a support request, all logs are attached to the request, and are thus available to Support. Good logging facilitates the error search, and can help locate the problem quickly.

To record entries in the log file, an object of the SpaceLogger type is required. The following example shows how such an object is created and used.

### [ClosedExample code in Groovy](javascript:void(0);)

```
import org.foederal.apache.log4j.SpaceLogger;
SpaceLogger logger = SpaceLogger.getLogger(this);
logger.info(this,?An info log entry?);
```

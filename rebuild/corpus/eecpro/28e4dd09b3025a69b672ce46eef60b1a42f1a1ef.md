# Test 4 - Generate the current state of the enclosure

1. Switch to the Project perspective.
2. Open the Feeder project component in the Project Explorer.
3. Open the Parameter editor.
4. Set the value of the Option\_Inspect\_available parameter to false.
5. Generate the ECAD structure again.

In the structure, all of the terminals for the Inspect function group and the PxC\_IL\_DI5 input card are now hidden.

![](../Pictures/tutorial_pp_test4_struktur.png)

1. Generate the enclosure.

![](../Pictures/tutorial_pp_test4_ergebnis.png)

The enclosure is now created without the terminal clamps for the optical sensor and has one less input card installed.

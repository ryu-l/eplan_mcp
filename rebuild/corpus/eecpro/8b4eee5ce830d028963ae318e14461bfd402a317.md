# rmos(String typeName)

Navigation methods for mechatronic components

rmos(typeName) returns all not disabled children of the mechatronic component which are an instance of typeName (see [isInstanceOf(String typeName)](refformulas_r_project_components_isinstanceof.htm)). The argument can be declared with and without unit path.

| **rmos(String typeName)** | | | |
| --- | --- | --- | --- |
| Argument | String | typeName | Type of the components to be determined |
| Return value | List |  | |

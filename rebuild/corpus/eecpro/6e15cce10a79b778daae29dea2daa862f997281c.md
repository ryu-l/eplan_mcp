# Division operator for integer

Integer operator

Integer division

It is frequently expected that the result of the division of two integers is a floating point number. To achieve this result either the dividend or the divisor is to be converted to a double (see [asDouble()](refformulas_r_conversion_asdouble.htm)).

| <Integer1> / <Integer2> | | | |
| --- | --- | --- | --- |
| Expressions | Integer | Integer1 | Arithmetic operator |
| Integer | Integer2 | Arithmetic operator |
| Return value | Integer |  | |

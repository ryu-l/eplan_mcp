# Coordinate

By specifying the Coordinate parameter, objects are positioned in a list via the X and Y coordinates.

The coordinates are specified using the following syntax:

```
=List{<X-coordinate>,<Y-coordinate>}
```

When positioning on a mounting surface, e.g. when placing a wire duct on a mounting panel, the X and Y coordinates of handle V1 on the mounting panel refer to the V1 mounting point on the wire duct.

When positioning a device on a mounting rail, the X coordinate of handle M4 on the mounting rail refers to the M2 mounting point on the device. The Y-coordinate specification is ignored in this case.

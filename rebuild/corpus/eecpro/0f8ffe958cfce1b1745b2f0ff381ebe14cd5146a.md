# Specifying the runtime environment for the plug-in

To avoid incompatible runtime environments, only the generally defined runtime environment should be specified for the newly developed plug-in. The general runtime environment to be used is defined in the initialization file (ec.ini). Other runtime environments could be entered in the MANIFEST.MF file and should be removed.

1. Open the MANIFEST.MF file of the new plug-in.
2. Open the Overview tab.
3. Remove all entries in the Execution Environments list.

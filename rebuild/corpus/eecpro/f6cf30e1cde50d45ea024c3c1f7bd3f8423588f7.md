# getProperty(String property)

Determines the value of an EEC setting.

| getProperty(String property) | | | |
| --- | --- | --- | --- |
| Argument | String | property | Setting |
| Return value | String | | Value of the setting |
| Exception error |  | |  |  |
| Plug-in | com.mind8.mechatronic.skill.api.IUtilAPI | | |

The global resource path can be queried in scripts with two methods.

1. In a local EEC environment the method System.getProperty("en.eplan.eec.global.resourcePath") is used.
2. In a Job Server environment, the IUtilAPI.DEFAULT.getGlobalResourcePath() method is applied.

### [ClosedExample code for local EEC environment](javascript:void(0);)

```
import org.foederal.util.ui.messages.UserMessageCollector;

String scriptName = "getGlobalResourcePath";
String info = "### Start of script '" + scriptName + "' ###";
UserMessageCollector.addInfo(PROJECT,'self',null,"Scripting",info);

String globalResourcePath = System.getProperty("de.eplan.eec.global.resourcePath");

if (globalResourcePath == null){
	info = "Global resource path not set.";
	UserMessageCollector.addInfo(PROJECT,'self',null,"Scripting",info);
}
else{
	info = "globalResourcePath: " + globalResourcePath;
	UserMessageCollector.addInfo(PROJECT,'self',null,"Scripting",info);
}

info = "### End of script '" + scriptName + "' ###";
UserMessageCollector.addInfo(PROJECT,'self',null,"Scripting",info);
```

### Result:

Applied to the project component Feeder\_Extended1.Mechatronic.Feeder of the tutorial the SelectionAction determines the value of the property de.eplan.eec.global.resourcePath.

```

globalResourcePath: ../_resources/ecad/tutorial/p8
### End of script 'getGlobalResourcePath1' ###
```

### [ClosedSample code for Job Server environment](javascript:void(0);)

```
import org.foederal.util.ui.messages.UserMessageCollector;
import com.mind8.mechatronic.skill.api.IUtilAPI;

String scriptName = "getGlobalResourcePath2";
String info = "### Start of script '" + scriptName + "' ###";
UserMessageCollector.addInfo(PROJECT,'self',null,"Scripting",info);

String globalResourcePath = IUtilAPI.DEFAULT.getGlobalResourcePath();
info = "globalResourcePath: " + globalResourcePath;
UserMessageCollector.addInfo(PROJECT,'self',null,"Scripting",info);

info = "### End of script '" + scriptName + "' ###";
UserMessageCollector.addInfo(PROJECT,'self',null,"Scripting",info);
```

Applied to the project component Feeder\_Extended1.Mechatronic.Feeder of the tutorial the SelectionAction determines the value of the property de.eplan.eec.global.resourcePath.

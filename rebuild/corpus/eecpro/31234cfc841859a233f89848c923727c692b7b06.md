# <libraries>

IMX

The tag <libraries> encloses the details which libraries are imported into the project.

The tag has no attributes.

| Allowed sub-elements | Quantity |
| --- | --- |
| [<add>](refimx_r_add.htm) | 1..n |

### [ClosedExample code](javascript:void(0);)

```
<libraries>
	<add type="String" value="T_Mechatronic_ModularSystem"/>
</libraries>
```

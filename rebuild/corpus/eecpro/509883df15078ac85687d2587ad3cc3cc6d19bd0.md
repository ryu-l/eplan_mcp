# <arrayList>

IMX

The < arrayList > tag surrounds one or more <add> tags, in order to write one or more values in a list.

The tag has no attributes.

| Allowed sub-elements | Quantity |
| --- | --- |
| [<add>](refimx_r_add.htm) | 1..n |

### [ClosedExample code](javascript:void(0);)

```
<project name="Feeder" save="true">
```

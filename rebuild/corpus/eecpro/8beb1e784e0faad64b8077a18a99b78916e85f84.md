# Entering formulas for the parameters of the S7_313C component

The parameters of the S7\_313C component require fixed values and formulas, with whose help the parameter values of the project components are determined.

1. Open the S7\_313C component.
2. Open the Parameter editor.
3. Enter the following formula for the Bit0\_IX parameter:

```
='I' + $IO_InputStartAddress
```

1. Repeat step 3 for the parameters Bit1\_IX to Bit23\_IX with the following formula (the bit address must be increased by 1 each time):

```
='I' + $IO_InputStartAddress.addressAdd(1, 0, 8)
...
='I' + $IO_InputStartAddress.addressAdd(23, 0, 8)
```

1. Repeat step 3 for the parameter Bit0\_QX with the following formula:

```
='O' + $IO_OutputStartAddress
```

1. Repeat step 3 for the parameters Bit1\_QX to Bit15\_QX with the following formula (the bit address must be increased by 1 each time):

```
='O' + $IO_OutputStartAddress.addressAdd(1, 0, 8)
...
='O' + $IO_OutputStartAddress.addressAdd(15, 0, 8)
```

1. Enter these fixed values for the following parameters:

| Parameter name | Value |
| --- | --- |
| IO\_BitRange | 8 |
| IO\_InputBlockSize | 24 |
| IO\_InputStartAddress | 0.0 |
| IO\_InputStartAddressFormat | x.0 |
| IO\_OutgoingBus | IO |
| IO\_OutputBlockSize | 16 |
| IO\_OutputStartAddress | 0.0 |
| IO\_OutputStartAddressFormat | x.0 |
| IO\_Place | PLC |
| IO\_Places | PLC |

# ref(String absoluteName)

Navigation methods for project components

References the project component absoluteName. Project components which are disabled cannot be referenced (see [Project component navigation methods](refformulas_r_project_components_navigation.htm)).

| **ref(String absoluteName)** | | | | |
| --- | --- | --- | --- | --- |
| Arguments | String | absoluteName | The path to a project component | |
| Return value | Project component | | The referenced project component | |

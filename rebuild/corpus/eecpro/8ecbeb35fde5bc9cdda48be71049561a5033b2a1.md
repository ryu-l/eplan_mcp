# Create level components

Preconditions:

- A library must be available which imports at least the Engineering system library.

Level components form the functional construction hierarchy of a model. At least one level component must be specified as a component of the top level. All others form the underlying structure.

This is how you create level components:

1. In the popup menu of the library select New > Object.
2. Navigate to Object > Component > MechatronicComponent.
3. Confirm with [Finish].

The editor for the level component opens with the Attributes editor area.

1. Enter a name for the level component in the Name field.
2. Switch to the Level configuration editor area.
3. Mark the Component of the top level check box, if it is the level component for which all following level components are sublevels.
4. Click ![Zulässige untergeordnete Ebene hinzufügen](../Pictures/button_finder.png) (Add valid subordinate level), to select level components which are to be located below this level component.

The Mechatronic components - Finder opens.

1. Enter a name or part of a name in the Name field to filter the desired ones from a large amount of level components.
2. Click [Search].
3. Mark the desired level components in the list.
4. Confirm with [OK].

You return to the editor for level components.

The selected level components are entered in the list of sublevels.

1. Save the level component.

# Placement

Correct placement of the objects in relation to each other is accomplished with the aid of a diverse range of parameters (graphical placement). In order to position objects correctly in relation to each other in the switching cabinet, the model variable for sort order is used along with the following parameters: Coordinate, CoordinateMap, Dimension, DimensionMap, MateMarker, Mate, MateMap, SuplementaryMap, and BusBarId.

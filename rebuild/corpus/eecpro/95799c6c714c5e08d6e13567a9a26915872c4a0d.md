# Defining the level configuration for the Text discipline

![](../Pictures/Komponentenliste_10a.png)

1. Open the component Line.
2. Select the editor page Level Configuration here.
3. Select the type Fragment in the Output type field.

![](../Pictures/Komponentenliste_10b.png)

1. Repeat steps 1 and 3 for the component Chapter.
2. Click the Add valid sublevel component icon to open the Finder dialog to open the finder dialog.
3. Select the component Line.

In addition you have to specify for the Body component that it is the Top-level element.

![](../Pictures/Komponentenliste_10c.png)

1. Open the component Body.
2. Select the editor page Level Configuration here.
3. Activate the check box for the Top-level element option.
4. Select the type Template File in the Output type field.
5. Click the Add valid sublevel component icon to open the Finder dialog to open the finder dialog.
6. Select the component Chapter.

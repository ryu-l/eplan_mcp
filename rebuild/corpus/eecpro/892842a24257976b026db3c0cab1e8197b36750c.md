# hasParameter(String name)

General methods for project components

Delivers true if the component has a parameter with the name <name>.

| **hasParameter(String name)** | | | | |
| --- | --- | --- | --- | --- |
| Argument | String | name | Name of the wanted parameter. | |
| Return value | Boolean | |  | |

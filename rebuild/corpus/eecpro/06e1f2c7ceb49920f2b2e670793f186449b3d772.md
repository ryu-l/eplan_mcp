# Configuring a text discipline

We will now create the ListOfComponents in a single text file. This will be built from chapters that in turn consist of lines. To specify that all text blocks should be generated in one file, the text discipline has to be configured accordingly:

![Configure text discipline step 1](../Pictures/tuttext_configureTextDiscipline_1.png)

1. Double-click to open the ListOfComponents text discipline configuration you just created.
2. Select the image ![ListOfComponents icon](../Pictures/komponentenliste.gif) (<EEC installation folder>\install\icon-collection\komponentenliste.GIF) with ![](../Pictures/button_set_image.png).
3. Enter an optional comment for the text discipline.
4. Open the Configuration editor page.

![Configure text discipline step 2](../Pictures/tuttext_configureTextDiscipline_2.png)

1. Enter the path resources\Tutorial\ListOfComponents in the field Resource storage location.
2. Save with [Ctrl] + [S] or ![](../Pictures/speichern.png).

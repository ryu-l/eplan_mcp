# Predefined Character Classes in Regular Expressions

| Characters | Meaning | Example | Result |
| --- | --- | --- | --- |
| . | any character except the line terminator | 'a'.matches('.') 'b'.matches('.') '\n'.matches('.') | true true false |
| \d | any digit matching [0-9] | 'a'.matches('\\d') '8'.matches('\\d') | false true |
| \D | no digit matching [^0-9] | 'a'.matches('\\D') '8'.matches('\\D') | true false |
| \s | any whitespace character (\n,\t etc.) |  |  |
| \S | nor "whitespace" character |  |  |
| \w | any word character matching [a-zA-Z\_0-9] |  |  |
| \W | no word character is matching [^a-zA-Z\_0-9] |  |  |

# Task: Creating a project documentation with the Job Server

Prolonged concurrent processes are executed by means of the Job Server. This tutorial shows how the Job Server can be used after successful completion of the generation Jobs to link the project documents with a Job position in the SAP system and save the documents in the SAP system.

The following steps are necessary to achieve the Job definition:

- Part 1: Adjust the Job Server model.
- Part 2: Create a new Job definition with webserviceTrigger for the Job Server.
- Part 3: Adjust the modular system in EEC and expand the existing configuration.
- Part 4: Generate documents with Job Server and upload these to the SAP system.

# Discipline-specific components

Discipline-specific components represent the objects as they are defined by integrated systems, for example, an ECAD macro in EPLAN Electric P8 or a PLC function block in STEP 7.

In order to fill discipline-specific components with discipline-specific data, one needs Resources. Resources contain the discipline-specific information as text blocks or text-based exchange formats. The original formats of the integrated systems are used.

The functional principle of the discipline-specific components is shown on the basis of the components list of the tutorial model ListOfComponents.

It consists of several entries. Apart from a header (document body), it contains one line per paragraph for actuators and sensors, as well as one entry per actuator and/or sensor.

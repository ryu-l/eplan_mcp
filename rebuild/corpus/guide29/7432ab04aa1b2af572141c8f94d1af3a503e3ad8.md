# Product aspect: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_produktkennzeichen.htm)

### Product aspect

User interface / operation

The product aspect corresponds to the identifier block of the device (preceding sign "-"); it can be used in the project structure (see [Project structure](Glossary_o_projektstruktur.htm)) additionally as a structuring element.

# Exporting Image Files

Project pages can be exported in various graphics [formats](Glossary_o_formate.htm), such as BMP, JPG, TIFF and GIF. You can use the image file export for archiving purposes and much more.

One image file per page is generated during the export. Each export file receives the full page name as a file name. If an entire project is output, a subdirectory (with the name of the project) is generated in the target directory. Existing files are overwritten without confirmation.

# Dialog Optimize net manually

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have created [routing connections](Glossary_o_verlegeverbindungen.htm). A net is highlighted in the [layout space](Glossary_o_bauraum.htm) navigator or in the layout space. Project data > Connections > Optimize net manually.

In this dialog, you can set options for the manual optimization of [nets](Glossary_o_netze.htm) and the [connections](Glossary_o_verbindungen.htm) routed in them.

The following dialog elements are available:

Close last daisy chains into a ring:

If this check box is activated, an additional connection from the first to the last connection point of the chain is generated.

Route connections:

If this check box is activated, all connections generated in the newly defined [routing tracks](Glossary_o_verlegewege.htm) will be routed as routing connections.

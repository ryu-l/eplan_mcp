# P012008: The structure identifier does not correspond to the mounting panel

### Cause

You created specific [project structure](Glossary_o_projektstruktur.htm) and defined identification [blocks](Glossary_o_bloecke.htm) to which you assigned [structure identifiers](Glossary_o_strukturkennzeichen.htm). Now there are conflicting structure identifiers for the placed [part](Glossary_o_artikel.htm) and for the corresponding mounting panel, in one of the identification blocks.

### Solution

Enter the same structure identifiers in the identification blocks for the placed part and the corresponding mounting panel (in the Properties<...> dialog under Displayed DT) (e.g. for "Higher-level function" and / or "Mounting location").

Start a new check run.

# Preventing a Search for the Channel Designation and Plug Designation

The channel designation and the plug designation can be manually entered or automatically assigned at the [PLC connection points](Glossary_o_sps_anschluesse.htm). During automatic assignment the corresponding values are determined from the graphical arrangement of the PLC [connection points](Glossary_o_anschluesse.htm). If an automatic assignment of a channel designation and / or plug designation is not desired for certain PLC connection points, you can prevent this by using the new [properties](Glossary_o_eigenschaften.htm) Channel designation (automatic): Suppress search ([ID](Glossary_o_id.htm) 20578) and Plug designation (automatic): Suppress search (ID 20579).

![](../Pictures/Gui/ALL/benefit.png)Benefit:

By using the new properties for PLC connection points you can prevent the automatic assignment of a channel designation and / or plug designation.

If the Channel designation (automatic): Suppress search property is activated at a PLC connection point, the Channel designation (automatic) property remains empty if no manual value for the channel designation was entered.  
The same behavior applies for the properties Plug designation (automatic): Suppress search and Plug designation (automatic).

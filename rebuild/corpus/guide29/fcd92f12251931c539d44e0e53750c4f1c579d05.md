# Dialog New identifier

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project in which [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) are used in the [project structure](Glossary_o_projektstruktur.htm), for instance "Higher-level function" and "Mounting location". Project data > Structure identifier management. Select the Tree tab, highlight the structure identifier below which you want to [generate](Glossary_o_erzeugen.htm) a new identifier, and click ![](../Pictures/Gui/ALL/all_new_as.png) (New).

In this dialog, you can generate a new structure identifier within an identifier block and determine its [properties](Glossary_o_eigenschaften.htm).

Overview of the main dialog elements:

Designation:

Enter the designation here under which the structure identifier is to be managed.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

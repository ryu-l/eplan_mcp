# Inserting Dynamic Connection Symbols

Dynamic [connection symbols](Glossary_o_verbindungssymbole.htm) are managed in the SPECIAL.slk symbol library. Dynamic [symbols](Glossary_o_symbole.htm) are symbols without [fixed graphics](Glossary_o_festegrafiken.htm). These include:

- Dynamic symbols for diagonal [connections](Glossary_o_verbindungen.htm)
- Cable definitions
- Shields
- Connection definition points
- Potential definition points
- Potential [connection points](Glossary_o_anschluesse.htm).

### Insert dynamic symbols for diagonal connections

It is often the case that a phase rotation must be generated over diagonal [lines](Glossary_o_leitungen.htm). Dynamic symbols are used to draw these connections over diagonal lines.

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the menu [items](Glossary_o_bauteile.htm) Insert > Connection symbol > Diagonal connection.
2. If required, hold down the [Ctrl] key and move the mouse to change the direction of the connection points.
3. Consecutively place the starting point and the end point of the diagonal connection line.
4. Proceed in a similar manner for all further diagonal connection lines.
5. End the action via the Cancel action popup menu item or via the [Esc] button.

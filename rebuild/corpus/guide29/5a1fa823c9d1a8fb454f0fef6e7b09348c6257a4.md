# Checking Identifiers

### Check usage

The option of usage checking checks whether the currently displayed [structure identifiers](Glossary_o_strukturkennzeichen.htm) are actually used in the project and, if so, how often.

Precondition:

You have opened a project in which [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) are used in the [project structure](Glossary_o_projektstruktur.htm), for instance "Higher-level function" and "Mounting location".

1. Project data > Structure identifier management
2. In the dialog Structure identifier management - <Project name>, select [Extras] > Check usage.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Usage column of the List tab is filled with the number of times each structure identifier appears in the schematic, or with the text "No" if the identifier is not (or is no longer) used in the schematic. If the structure identifier is not used, but a sub-identifier exists, then the entry "\*" is displayed.
3. Edit the structure identifiers as usual.

Since the values in the Usage column are not stored, there is always a "?" value in the column when [structure identifier management](Glossary_o_strukturkennzeichen_verwaltung.htm) is opened, until you call up the command (or call it up again).

![](../Pictures/Gui/ALL/note.png)Note:

During this check, [graphical pages](Glossary_o_grafikseiten.htm) are also processed to which a structure identifier has been assigned, or on which [objects](Glossary_o_objekte.htm) with structure identifiers are located.

### Check syntax

The structure identifiers used are subject to a suppressible test for legal characters.

Precondition:

You have opened a project in which identifier [blocks](Glossary_o_bloecke.htm) are used in the project structure, for instance "Higher-level function" and "Mounting location".

1. Options > Settings > Projects > "Project name" > Devices > DT syntax check
2. In the  DT syntax checkdialog, select the Enable check check box, if the syntax of device tags is to checked during entry.
3. In the group boxes Identifier blocks, Device tags, and Count numbers, specify the scope of the test for the components of the DT.
4. Click [OK].
5. Select the menu [items](Glossary_o_bauteile.htm) Project data > Structure identifier management.
6. Edit the structure identifiers as usual.
7. Click [Apply] or [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) If an illegal character is found, the DT syntax check dialog is opened with the corresponding identifier highlighted.

# Views in PLC Navigator

The tree view of the navigator dialog PLC - <project name> allows you to choose different views for the display of PLC data.

All PLC data present in the project is displayed in all views, i.e. [PLC boxes](Glossary_o_sps_kaesten.htm), all [PLC connection points](Glossary_o_sps_anschluesse.htm), and [function templates](Glossary_o_funktionsschablonen.htm). Empty PLC boxes are also displayed, as are PLC boxes containing only function templates.

The following views are available via the popup menu item View:

- DT-oriented: The PLC data is structured by their device tags according to the [project structure](Glossary_o_projektstruktur.htm).
- Address-oriented: The PLC data is structured by addresses within the project structure. This means that the I / O [connection points](Glossary_o_anschluesse.htm) are shown below the PLC address. The associated [power supplies](Glossary_o_anschlussversorgungen.htm) are also displayed below the PLC address if the corresponding PLC address is entered at the power supply. In addition, the PLC boxes and connection points are grouped under the relevant CPU if this property is entered at the associated PLC box.
- Channel-oriented: The PLC data is structured by [channels](Glossary_o_kanaele.htm) within the project structure. That is, the I/O connection points and associated power supplies are displayed under the channel designation. The ![](../Pictures/Gui/ALL/plcgui_plcchannelwithsafty_as.png) icon for the channel shows whether there is a safety-relevant connection point below. In addition, the preceding ![](../Pictures/Gui/ALL/navigatorgui_nonplaced_as.png) icon indicates whether the channel contains unplaced I/O connection points. PLC connection points which do not have a channel designation which has been either determined automatically or entered manually will be arranged according to their DT.
- Rack-oriented: The PLC data is displayed in accordance with the assignment of the [PLC cards](Glossary_o_sps_karten.htm) to the racks. Racks are marked with a preceding ![](../Pictures/Gui/ALL/navplc_rack_as.png) icon, with the PLC cards (![](../Pictures/Gui/ALL/navplc_moduleonrack_as.png) icon) and their bus IDs listed below. The sequence reflects the item numbers of the [slots / modules](Glossary_o_steckplaetze.htm). The [functions](Glossary_o_funktionen.htm) contained by the PLC cards are displayed below these.  
  PLC cards that are placed on a head station or are integrated into it, are marked with the icon ![](../Pictures/Gui/ALL/navplc_moduleonheadmodule_as.png). PLC cards that are adjoined next to the head station are marked with the icon ![](../Pictures/Gui/ALL/navplc_moduleonrack_as.png). A head station is also always a [rack](Glossary_o_baugruppentraeger.htm) and is therefore marked with the preceding icon ![](../Pictures/Gui/ALL/navplc_rack_as.png). Below a rack first the PLC cards placed on the head station are shown, followed by all further PLC cards.  
  In the case of [devices](Glossary_o_betriebsmittel.htm) that are located on a sub-slot this is indicated by the fact that the sub-slot is displayed behind the slot number, separated by a decimal point, for example 2.1:=EB3+ET1-A99.
- Drive-oriented: The PLC data is structured by drives within the project structure. Drives are identified by the preceding icon ![](../Pictures/Gui/ALL/navplc_drive_as.png). The functions are displayed below the hierarchy [levels](Glossary_o_etagen.htm) "Configuration project", "Drive" and "Station [ID](Glossary_o_id.htm)". Functions that are not assigned to any drive are also displayed here. Prerequisite for this is that the functions are assigned to a configuration project and / or a station.

If you wish to limit the display to certain data, you can use a filter.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

In the address-oriented view, if you wish to view only PLC connection points which have a PLC address, filter by the property PLC address with the value blank. To do this, go to the PLC - <project name> dialog, click [...] next to the Filter field, and specify the following [settings](Glossary_o_einstellungen.htm) in the Filter dialog:

| Active | Negated | Criterion | Operator | Value |
| --- | --- | --- | --- | --- |
|  |  | PLC address | <> |  |

To view only I / O connection points in the address-oriented view, filter by the function group PLC connection point, I/O, 1 connection point. To do this, go to the PLC - <project name> dialog, click [...] next to the Filter field, and specify the following settings in the Filter dialog:

| Active | Negated | Criterion | Operator | Value |
| --- | --- | --- | --- | --- |
|  |  | Function group | = | PLC connection point, I/O, 1 connection point |

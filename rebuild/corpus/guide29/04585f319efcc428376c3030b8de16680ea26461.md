# P026053: Connection point '<x>' does not exist and cannot be created

### Cause

Several [part placements](Glossary_o_artikelplatzierungen.htm) have the same DT but the required connection point designation <x> does not exist in the [connection point patterns](Glossary_o_anschlussbilder.htm) that are assigned to the respective parts.

### Solution

1. Add the missing connection point designation in one of the assigned connection point patterns.
2. Then start a new check run.

![](../Pictures/Gui/ALL/note.png) Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

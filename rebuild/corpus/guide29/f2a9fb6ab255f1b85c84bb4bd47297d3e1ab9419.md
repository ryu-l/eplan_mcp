# Excluding the PLC Connection Points from Numbering

When numbering with PLC data, all [devices](Glossary_o_betriebsmittel.htm) connected to [PLC connection points](Glossary_o_sps_anschluesse.htm) are numbered by default if they are included in the scope. However, you can exclude certain PLC [connection points](Glossary_o_anschluesse.htm) from the numbering.

Precondition:

You have selected a PLC connection point in the graphical editor or in a navigator.

1. Edit > Properties
2. Activate the "Prevent numbering with PLC data" property in the PLC connection point tab in the Properties <...> dialog.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) When numbering with PLC data, devices connected to this function will not be numbered.

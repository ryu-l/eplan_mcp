# Report page sorting

Project pages are managed in the page structure of the project using structure identifier [levels](Glossary_o_etagen.htm). When generating [reports](Glossary_o_auswertungen.htm), EPLAN analyzes the [project data](Glossary_o_projektdaten.htm) and displays it in [report pages](formgeneratorgui_k_auswertungsseiten.htm). These pages are sorted into the page structure of the project.

You use the [page sorting](Glossary_o_seitensortierung.htm) to define which [structure identifiers](Glossary_o_strukturkennzeichen.htm) [generate](Glossary_o_erzeugen.htm) their own [report blocks](formgeneratorgui_k_auswertungsbloecke.htm). When generating a table of contents for instance, the "Total" page sorting generates a comprehensive table of contents for the complete schematic documentation, whereas the page sorting "Higher level function" generates a separate table of contents for each higher level function. For instance, the following [functions](Glossary_o_funktionen.htm) are possible:

- You can [create](Glossary_o_erstellen.htm) a comprehensive reporting block for the entire project.
- You can create a separate reporting block for each structure identifier level of an identifier block.
- You can create a separate reporting block for each structure identifier level of several [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm).

  ![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

  You have specified Higher-level function + Mounting location page sorting for the "Table of contents" report type under the menu item Options > Settings > Projects > "Project name" > Reports > Output to pages. EPLAN uses this setting to create the following [report blocks](Glossary_o_auswertungsbloecke.htm):

  - A separate table of contents for each structure identifier level of the Higher-level function identifier block. Therefore, this will take place every time the higher level function changes.
  - A separate table of contents for each structure identifier level of the Mounting location identifier block. Therefore, this will take place every time a [mounting location](Glossary_o_einbauort.htm) changes.
- You can create one comprehensive reporting block for the complete project, and additionally, one or more identifier [blocks](Glossary_o_bloecke.htm) for each structure identifier level.

  ![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

  You have specified Total + Higher-level function + Mounting location page sorting for the "Table of contents" report type under the menu item Options > Settings > Projects > "Project name" > Reports > Output to pages. EPLAN uses this setting to create the following report blocks:

  - A comprehensive table of contents for the total project.
  - A separate table of contents for each structure identifier level of the Higher-level function and Mounting location identifier blocks. Therefore, this will take place every time the higher level function and mounting location change.
- You can create a separate reporting block every time the [component](Glossary_o_schaltzeichen.htm) property "Output group" changes.

![](../Pictures/Gui/ALL/note.png) Note:

Which types of page sorting are available depends on the report type. For the "Forms documentation" report type, only (e.g.) the "Total" page sorting option is available.

# Extending Existing Pre-planning by Graphical Views and P&I Diagrams

So that you now extend an existing pre-planning with graphical views or P&I diagrams, you now have the option at all [segments](Glossary_o_segmente.htm) to store a window macro with graphical pre-planning or [P&I diagram](Glossary_o_ri_fliessbild.htm) sections.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

Through the new Macro for pre-planning and P&I diagram property you can extend an existing pre-planning with graphical views and P&I diagrams. This is, for example, of interest if imported pre-planning data contains different [variants](Glossary_o_varianten.htm) with the same [part](Glossary_o_artikel.htm) structure for which the same or similar [window macros](Glossary_o_fenstermakros.htm) can be stored.

To this purpose the new property Macro for pre-planning and P&I diagram ([ID](Glossary_o_id.htm) 44084) is available on the first tab in the [property dialog](Glossary_o_eigenschaftendialog.htm). If a window macro with the "Pre-planning" and / or "P&I diagram" representation type is selected for the property, you can place this segment with the [cut-outs](Glossary_o_durchbrueche.htm) existing in the window macro via drag & drop on a project page of the corresponding page type.

[![](../Pictures/Gui/Lang/planninggui_segmentwithwindowmarco_ls_thumb_0_60.png)](../Pictures/Gui/Lang/planninggui_segmentwithwindowmarco_ls.png)

Certain [conditions](planninggui_k_vorplanungerweitern.htm) must be met so that the structures in the macro can be assigned to structures existing in the project during such an action.

When [placing](Glossary_o_auflegen.htm) a window macro with P&I diagrams the Select structure dialog is opened. If a corresponding segment exists for the segment to be placed in the structure of the window macro on the same hierarchy level (same basic segment definition) and if the subordinate part structures are the same, the structures from the macro are automatically sorted into the pre-planning structure of the project in the Project field.

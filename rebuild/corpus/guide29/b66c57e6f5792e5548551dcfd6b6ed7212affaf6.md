# Tab Drilling pattern

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have selected an object in the tree that belongs to the Drilling pattern hierarchy level.

In this tab you define an arrangement (i.e., a group) of [cut-outs](Glossary_o_durchbrueche.htm). Take note that a drilling pattern is not a [part](Glossary_o_artikel.htm), but simply serves to assign additional structural information to a part. Any part can contain such drilling pattern information; the corresponding reference is created in the Manufacturing tab of the part in the Drilling pattern field.

Overview of the main dialog elements:

Name:

When selecting [drilling patterns](Glossary_o_bohrbilder.htm) in the Manufacturing tab of a part, this name as well as its optional description will be shown in the selection dialog.

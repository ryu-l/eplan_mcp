# P005069: Same connection designation on different nets

### Cause

An existing connection designation was assigned to different [nets](Glossary_o_netze.htm).

### Solution

1. Locate the connection definition point in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Delete the connection designation, or change its name.
3. Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

![](../Pictures/Gui/ALL/info.png)Tip:

Use the function of [connection numbering](Glossary_o_verbindungsnummerierung.htm) in order to assign [connection designations](Glossary_o_verbindungsbezeichnungen.htm) automatically.

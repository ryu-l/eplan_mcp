# P011003: Interruption point without target

### Cause

One interruption point has no target.

### Solution

Link at least one interruption point connection to another [component](Glossary_o_schaltzeichen.htm) so as to [form](Glossary_o_verlauf.htm) an autoconnect line.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

# Dialog Check project (Consistency Check when Opening Projects)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You open a project that has not been closed properly. You have confirmed the prompt whether the data is to be checked with [Yes].

In this dialog, you can check and correct a project. If a project was not closed properly - e.g., due to power loss - this can result in incomplete entries in the database.

The following dialog elements are available:

Check project:

The project will be checked if this option has been selected. If no incomplete data is found, the project will then be opened. Otherwise, a message will be displayed, and you will be able to correct the project.

Check and correct project:

If this option has been selected, the project will be checked and - if possible - also corrected in the process. The project will then be opened.

A message will be displayed if the project could not be corrected. In the event, contact EPLAN Support.

Zip and back up project:

This check box can be activated only if the Check and correct project option has been selected.  
If the check box is activated, a back-up copy of the project will be created and zipped prior to the correction. This is the default setting, and we recommend that you do not change it.

If the check box is deactivated, no back-up copy of the project will be created.

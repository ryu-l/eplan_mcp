# Checking Forms

A special function is available to check at any time during [form](Glossary_o_verlauf.htm) editing whether your form is correct or there are errors.

Preconditions:

- You have opened a project.
- You have opened the form that you would like to edit in the form editor (Utilities > Master data > Form > Open > [Open]).

1. Utilities > Check form
2. Confirm the prompt in the Check form dialog.
3. Click [Save] in the System messages dialog.
4. Specify drive and directory in which the log file should be saved using the Open dialog.
5. In the File name field, enter a descriptive name for the log file.
6. Click [Open].
7. Click [Close] in the System messages dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The [system messages](Glossary_o_systemmeldungen.htm) that apply to the current form are saved in the corresponding file and can be printed as needed.

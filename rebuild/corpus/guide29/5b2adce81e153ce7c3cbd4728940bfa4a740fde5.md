# Tab Wires (Schleuniger)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Wire fabrication > Schleuniger > Wires
- Utilities > Manufacturing data > Wire fabrication > Schleuniger. Click [...] next to the Scheme field. Select the Wires tab.

In this tab, you specify the wire [master data](Glossary_o_stammdaten.htm) for the processing of [wires](Glossary_o_draehte.htm) on the Schleuniger machine.

Overview of the main dialog elements:

Toolbar:

| Button | Meaning |
| --- | --- |
| (Update) | Imports the wires and wire parts from the project again. |
| (Delete) | Deletes a selected row. |

Color:

Color of the wire.

Cross-section:

Cross-section of the wire.

Part number:

Part number of the wire [part](Glossary_o_artikel.htm).

Schleuniger part number:

For production on the Schleuniger machine, each wire must be designated with a part number set by Schleuniger. In this table field, you assign the appropriate Schleuniger part numbers to the wires in the project. Information on the required part numbers can be obtained from the manufacturer.

Distance 1st / side Distance 2nd side:

Distance at which the labeling is printed from either end of the wire.

Distance continuous text:

Distance between individual [blocks](Glossary_o_bloecke.htm) of text.

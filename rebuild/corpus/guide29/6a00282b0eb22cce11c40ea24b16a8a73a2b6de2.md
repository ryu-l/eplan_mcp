# Changing the 3D Viewpoint of the Layout Space by Means of Shortcut Keys

You can now also use shortcut keys to change the 3D viewpoint. As a default the following shortcut keys are available for the menu [items](Glossary_o_bauteile.htm) below the menu path View > 3D viewpoint:

| Command | Key combination |
| --- | --- |
| 3D viewpoint top | [Ctrl] + [Alt] + [T] |
| 3D viewpoint bottom | [Ctrl] + [Alt] + [D] |
| 3D viewpoint left | [Ctrl] + [Alt] + [L] |
| 3D viewpoint right | [Ctrl] + [Alt] + [R] |
| 3D viewpoint front | [Ctrl] + [Alt] + [F] |
| 3D viewpoint back | [Ctrl] + [Alt] + [B] |
| 3D viewpoint SW Isometric | [Ctrl] + [Alt] + [1] |
| 3D viewpoint SE Isometric | [Ctrl] + [Alt] + [2] |
| 3D viewpoint NE Isometric | [Ctrl] + [Alt] + [3] |
| 3D viewpoint NW Isometric | [Ctrl] + [Alt] + [4] |

You can also assign these shortcut keys to the function keys of a SpaceMouse.

# Display Properties: Ellipse

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a page, [form](Glossary_o_verlauf.htm), plot frame, or symbol. You have marked an ellipse and selected the menu [items](Glossary_o_bauteile.htm) Edit > Properties, or you have double-clicked on an ellipse. In the table of the Properties (Ellipse) dialog, expand the hierarchy level Ellipse.

Below this hierarchy level you can edit the ellipse-specific [settings](Glossary_o_einstellungen.htm).

The following dialog elements are available:

Center:

In the fields below this hierarchy level, the coordinates of the ellipse's center are displayed and can be modified.

Semi-axis:

The lengths of the larger and smaller semi-axes of the ellipse are shown in the fields below this hierarchy level and can be altered.

Angle:

Enter an angle in order to rotate the ellipse relative to the X axis.

# Report Templates

Report templates allow the [settings](Glossary_o_einstellungen.htm) for [reports](Glossary_o_auswertungen.htm) to be saved and reused. You can [generate](Glossary_o_erzeugen.htm) reports based on report templates. All settings already specified in the report templates are used for the reports. Report templates can be imported and exported as \*.xml files.

If you should regenerate an existing report from a template, the existing report will be deleted and a new one generated.

![](../Pictures/Gui/ALL/info.png)Tip:

It is possible to [create](Glossary_o_erstellen.htm) several report templates for the same report type. If a report template (called 0001) already exists, when another template of this type is created, a prompt is displayed, querying whether or not the old template should be overwritten. If [No] is selected, two templates will be generated with the same name, which must then be changed.

### Conditional reports

You can generate reports within the conditions of the [project properties](Glossary_o_projekteigenschaften.htm) by using report templates. Define a project filter for this purpose and assign it to the template. During the reporting process, a report will only be generated from the template if the current project meets the filter criteria of the project filter.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

This functionality is useful for instance when you are creating two [projects](Glossary_o_projekte.htm) (as common standard) from one basic project for differing project planning tasks:

Setting up a basic project

- Use [form](Glossary_o_verlauf.htm) A to create a report template in the basic project for a title page / cover sheet, designed for the first project EPLAN\_Demo. This report template will be called Title\_EPLAN\_Demo.
- Use form B to create a report template in the basic project for a title page / cover sheet, designed for the second project EPLAN\_Test. This report template will be called Title\_EPLAN\_Test.
- You define a project property as filter criterion in a project filter and assign the project filter to the report template Title\_EPLAN\_Demo.

Creating projects

- The EPLAN\_Demo project as well as the EPLAN\_Testproject will be created from the basic project.
- In order to be able to distinguish the two projects for reporting, assign the project [properties](Glossary_o_eigenschaften.htm) you set up in the project [filters](Glossary_o_filter.htm) as filter criterion to the first project EPLAN\_Demo.

Generating project reports

- When you use the reporting template to report on the EPLAN\_Demo project, EPLAN uses the reporting template Title\_EPLAN\_Demo and generates a title page from form A.
- When you generate reports on the EPLAN\_Test project, EPLAN uses the reporting template Title\_EPLAN\_Test and generates a title page from form B.

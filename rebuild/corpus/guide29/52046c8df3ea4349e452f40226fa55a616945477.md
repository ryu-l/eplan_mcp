# Generating and Editing NC Outline Records

Preconditions:

- You have opened a project.
- You have opened an outline of the type "Outline NC record generation" in the Outline editor (for example via the Utilities > Master data > Outline (NC data) > Open menu [items](Glossary_o_bauteile.htm)). The outline drawing contains only a single closed outline that does not intersect itself.

1. Select the menu items Utilities > Master data > Outline (NC data) > Generate record > Rittal - Perforex BC / Secarex (or ... > Rittal - Perforex LC / Secarex or ... > NC Steinhauer).
2. In the NC outline record <...> dialog, specify the record-specific [properties](Glossary_o_eigenschaften.htm) Manufacturer, Machine, Approach process, etc.
3. Click [OK].
4. Select a starting point on the outline. The starting point should be located on a straight line and not in a corner, so that the outline can be approached correctly.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The milling path is drawn as a graphical representation of the NC program via the outline. Each end point of a program step (straight or arc travel) is indicated by a circle. The milling path is represented by parallel [lines](Glossary_o_leitungen.htm), arcs or circle [segments](Glossary_o_segmente.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The record is generated.

![](../Pictures/Gui/ALL/note.png)Note:

The system prevents that a starting point is placed too closely to arcs, to a rounding or a corner point of a rectangle. Such an input is ignored. The status bar indicates the incorrect position, and you are prompted to define another starting point.

5. Repeat these steps to [generate](Glossary_o_erzeugen.htm) other [NC records](Glossary_o_nc_datensaetze.htm). (Note, however, that per machine only one NC record is permitted.)
6. Select the Utilities > Master data > Outline (NC data) > Edit record > Generate drill hole menu items and ... > Generate fin to generate [drill holes](Glossary_o_bohrungen.htm) and fins.
7. To render visible the NC records stored in an open outline, use the View > Next NC record and View > Previous NC record [functions](Glossary_o_funktionen.htm).

![](../Pictures/Gui/ALL/note.png)Note:

To minimize the danger of damage to the workpieces and tools caused by erroneous NC exports, you should carry out an optical check of the defined NC outline record before closing the NC outline. Make sure to pay attention to, e.g., excessive milling cutter diameters for roundings and corners.

In many cases it is easier and safer to use the default [outlines](Glossary_o_konturen.htm) (circle, rectangle chamfered / rounded, slotted hole, hexagon, octagon), if possible.

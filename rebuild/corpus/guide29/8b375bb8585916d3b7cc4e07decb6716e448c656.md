# P004099: PLC card with the PLC type designation '<x>' is not placed on a head station

### Cause

At a PLC card with the PLC type designation <x>, which is placed on a specific [rack](Glossary_o_baugruppentraeger.htm), the active property PLC card is placed on head station documents that the rack is a head station. However, the PLC card which represents the rack is not a head station since certain information is missing. It is also possible that no head station was defined.

### Solution

1. Locate the PLC card placed on the rack in the schematic by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. In the popup menu, select the Go to 2nd coordinate menu item, and this way jump to the PLC box that represents the rack.
3. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the PLC box.
4. Bring the PLC structure data tab to the front.
5. In the property list activate the check box of the property Bus coupler / head station and / or CPU.
6. Click [OK].
7. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

It is not possible to jump to the rack if such had not been defined. In this case select or [create](Glossary_o_erstellen.htm) a PLC card which is to serve as a rack. Assign the value to the rack (second tab, field Rack) that you have assigned to the PLC card (second tab, field PLC card is placed on rack [ID](Glossary_o_id.htm)) that is to be placed on the rack. Do not forget to additionally declare the rack defined that way as a bus coupler / head station and / or CPU.

# Tab Curve

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open. You have selected a curve and chosen the menu [items](Glossary_o_bauteile.htm) Edit > Properties, or you have double-clicked a curve. In the Properties dialog, select the Curve tab.

On this tab you can edit the display [properties](Glossary_o_eigenschaften.htm) of curves.

Overview of the main dialog elements:

Segment points:

The characteristic points of a curve are displayed here: Starting point, end point and at least one control point.

Click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) in order to delete all control points of the curve except one. When there is (only) one control point, the button will be grayed out.

Position:

The X, Y and Z-coordinates of the selected segment point are displayed here and may be altered. Note that the input of alphanumeric values, letters or special characters is not permitted here.

Gradient:

The X, Y and Z-coordinates of the gradient of the selected segment point are displayed here and may be altered. Note that the input of alphanumeric values, letters or special characters is not permitted here.

Bending factor:

Here, the bending factor of the selected segment point is displayed and can be altered. Note that the input of negative numbers, alphanumeric values, letters or special characters is not permitted here.

# P005036: The minimum number of digits for the format (<x>) was exceeded

### Cause

The minimum number of characters of a format element in the [connection numbering](Glossary_o_verbindungsnummerierung.htm) is longer than that defined in the [settings](Glossary_o_einstellungen.htm).

### Solution

If this message should no longer be output, please increase the minimum number of digits for the relevant format element.

To make the setting, do the following:

1. Select the menu [items](Glossary_o_bauteile.htm) Project data > Connections > Numbering > Settings.
2. In the Settings: Connection numbering - <Project name> bring the Designation tab to the foreground.
3. Highlight the desired connection group in the Format groups list and click on ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit).
4. In the Connection numbering: Formats dialog select the desired format element in the Selected [format elements](Glossary_o_formatelemente.htm) list, and click ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Format: <Format element> dialog is opened and it offers you the Minimum number of digits field.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

# Dialog Copy image file

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a page, a [form](Glossary_o_verlauf.htm), or a plot frame. Insert > Graphic > Image file. In the Select image file dialog, select the desired image file and click [Open].

Image files in the GIF, JPG, BMP, ICO, PNG, or TIFF [formats](Glossary_o_formate.htm) can be inserted in EPLAN. In this dialog, you can specify whether the image file is to be copied into the project directory or referenced from the source directory.

The following dialog elements are available:

Keep source directory:

A reference to the image file is inserted in the project. If the image file is changed, it is automatically updated as soon as you open the page. However, referenced files are not included in backups.

Copy:

The file is copied into the project directory (that is, into the Images subdirectory of the project). Image files in this directory are also taken into consideration during data backup.

Overwrite with prompt:

Select this check box to have a confirmation displayed for the Copy option if the image is already present in the project directory. You can then decide whether this image should be overwritten or not.

# Tab Addresses (PLC address formats)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Options > Settings > Projects > "Project name" > Devices > PLC. Click [...] next to the PLC-specific settings field in the Settings: PLC dialog. Select the Addresses tab in the Settings: PLC-specific dialog.

In this tab you define the identifier and the data type for each of the inputs and outputs. You also specify the signal type of the inputs and outputs. EPLAN then searches the schematic for data corresponding to the entered identifier and data type and creates the assignment list based on the affected definition.

Overview of the main dialog elements:

Addressing:

Inputs and outputs can be addressed in the following manner:

- Bitwise
- Bytewise (8 bit)
- Wordwise (2 Byte or 16 bit)
- Double wordwise (4 byte or 32 bit)
- Long wordwise (8 byte or 64 bit).

Separate [settings](Glossary_o_einstellungen.htm) are possible for each of these addressing types.

Code:

Here you define a code for the data type. The code may consist of one or more letters and/or numbers. EPLAN uses the code to identify the PLC inputs and outputs in the schematic. The code is also used for filtering entries when importing [assignment lists](Glossary_o_zuordnungslisten.htm).

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Assignment of codes:

| Code consists of | PLC input | PLC output |
| --- | --- | --- |
| Identifiers | E 3.1 | A 4.5 |
| Numbers | 1 3.1 | 2 4.5 |

Data type:

Here you assign particular data types to the address type. The entry can be made manually or from the drop-down list. Sensible entries are:

- BOOL
- BYTE
- WORD
- DWORD
- LWORD.

In addition the entries INT, DINT, LINT are possible, these correspond to WORD, DWORD, LWORD and are supported for the PLC [data exchange](Glossary_o_datenaustausch.htm) in the AutomationML format.

Type of signal:

Select whether it is a digital or analog, input or output from the drop-down list.

Increment:

Here you enter the increment used for each step when numbering the [PLC addresses](Glossary_o_sps_adressen.htm).

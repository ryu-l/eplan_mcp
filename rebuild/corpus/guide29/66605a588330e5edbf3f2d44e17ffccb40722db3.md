In this tab, you can specify that all [devices](Glossary_o_betriebsmittel.htm) of the target project should be renumbered. This is useful, for example, if the [project structure](Glossary_o_projektstruktur.htm) of the source project does not match that of the target project.

Overview of the main dialog elements:

Renumber devices:

If this check box is selected, the devices are numbered.

Device numbering:

This drop-down list shows all [user-defined](Glossary_o_benutzerdefiniert.htm) and pre-defined [schemes](Glossary_o_schemata.htm) for online device numbering. User-defined and pre-defined schemes for device numbering are taken from the template that you specified when creating the target project. Use [...] to open the Settings: Numbering formats dialog where you manage and edit the schemes.

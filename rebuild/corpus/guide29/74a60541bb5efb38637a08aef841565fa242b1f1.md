# Deleting Column and Row Numbers and Placing Them Again

This functionality supports you in the labeling of column and row areas, in that all placed column and row numbers are deleted and automatically reset. An automatic [placing](Glossary_o_auflegen.htm) function sets the column and row [placeholder texts](Glossary_o_platzhaltertexte.htm) exactly on the edges of the defined columns and rows.

Preconditions:

- You have opened a project.
- You have opened a plot frame in the plot frame editor.
- You have placed column or row texts in the plot frame (Insert > Special text > Column text or Insert > Special text > Row text).

1. Select Utilities > Place column and row text again.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The column and row numbers are deleted and placed again. During the generation of [special texts](Glossary_o_sondertexte.htm), the formatting last used is selected.

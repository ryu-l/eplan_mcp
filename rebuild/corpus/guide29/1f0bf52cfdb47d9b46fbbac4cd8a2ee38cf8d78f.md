# Specifying the Representation of the Tree Structure in the Navigators

All the used [structure identifiers](Glossary_o_strukturkennzeichen.htm) of the [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) that are identified in the [project structure](Glossary_o_projektstruktur.htm) as "Identifying" are displayed by default in the tree views of the [navigators](Glossary_o_navigatoren.htm) (page navigator, device navigator, etc.).

In the [project-specific settings](Glossary_o_projektbezogeneeinstellungen.htm) you have the possibility to hide or display the structure identifiers of one or more identifier [blocks](Glossary_o_bloecke.htm) and / or to have further [properties](Glossary_o_eigenschaften.htm) (Page type, DT: Identifier, etc.) displayed in the tree representations. You can additionally change the order of the structure identifiers represented in the tree view by means of arrow buttons.

The following action is carried out using the page navigator as an example. Proceed analogously to specify the tree view in the other navigators.

Preconditions:

- You have opened a project.
- You have specified the project structure.
- You have opened the page navigator.

1. Decide which structure identifiers in an identifier block are to be displayed and which not.
2. Select the menu [items](Glossary_o_bauteile.htm) Options > Settings > Projects > "Project name" > Display > Tree structure (pages).
3. To hide the structure identifiers for an identifier block, select the desired identifier block and deselect the check box in front of it.
4. In order to display the page type in the page navigator activate the Page type check box.
5. Click [OK].

# P007014: 'Function text (automatic)' different for different representation types (in language '<x>')

### Cause

The schematic has a placed function that exists in different [representation types](Glossary_o_darstellungsarten.htm) (e.g. multi-line, single-line, or overview function). For that function, the entry in the Function text (automatic) field deviates for one or more of the representation types in the selected display language.

### Solution

Standardize the entry in the Function text (automatic) field in the selected language for all representation types of that function.

1. Double-click the line with the message 007014 in the Message management dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The main function is selected in the graphical editor.
2. Right-click and select Properties (global) in the popup menu.
3. In the Properties (global): <...> dialog select the <Function category> (Device) tab and go to the Function text field where you open the popup menu with the right mouse button.
4. Select the Translate menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Translate dialog opens and shows you all the available translations of the text in the dictionary in all languages.
5. Click [OK] and then close the Properties (global): <...> dialog with [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The text is now consistent in the selected display language for all representation types of the function in the schematic.
6. Then start a new check run.

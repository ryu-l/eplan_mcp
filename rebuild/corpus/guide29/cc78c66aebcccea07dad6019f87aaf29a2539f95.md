# Dialog Attribute definition

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > User > Interfaces > DXF / DWG export and import. Select the Block attribute tab. Select an entry from the Available properties list and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).
- Page > Export > DXF / DWG. Next to the Scheme field, click [...]. Select the Block attribute tab. Select an entry from the Available properties list and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).

In this dialog you define the assignment of the EPLAN [properties](Glossary_o_eigenschaften.htm) to the [ACAD](Glossary_o_acad.htm) attributes.

The following dialog elements are available:

Category:

From the drop-down list, select the category whose properties should be displayed in the list below. The properties for each element selected from Available properties are displayed.

Attribute designation:

Enter a designation to be used in ACAD for the selected element.

Command prompt:

Enter an input prompt for the selected property here.

# Editing Search Entries

Precondition:

You have performed a search and the dialog Search results - <project name> is open.

1. Select an entry in the list of search results and select the popup menu Properties.  
    You can also select multiple entries. In this case only the [properties](Glossary_o_eigenschaften.htm) common to all of the [objects](Glossary_o_objekte.htm) are displayed.
2. In the Properties dialog make the desired changes to the object properties.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Properties dialog will close and you will be returned to the search results list.

Edit schematic objects, project, and page data

Page data, [project data](Glossary_o_projektdaten.htm), and schematic objects can only be separately edited, not mixed.  
If you have selected a mix of entries a message will appear prompting you to change your selection.

Multi-user Operation

All objects to be edited are locked when you select the Properties menu command in [multi-user operation](Glossary_o_multiuser_betrieb.htm). If all of the objects can't be locked, these objects also can't be edited, in which a message to that effect will appear. Change your selection if this is the case.

# Path Function Texts: Principle

If no other function text is entered for a [component](Glossary_o_schaltzeichen.htm), the function text generated automatically from the path will be used for [reports](Glossary_o_auswertungen.htm). The search direction depends on the plot frame used.  
To decide whether a function text on a component has been entered or is an automatically generated function text, each function has the [properties](Glossary_o_eigenschaften.htm) Function text and Function text (automatic).

- The Function text property contains the manually entered function text.
- The Function text (automatic) property is automatically determined and cannot be changed manually. It contains the manually entered function text if that property is not empty. Otherwise the relevant path function text in the schematic is entered here.

![](../Pictures/Gui/ALL/note.png)Note:

The path function text is only correctly adopted in the Function text (automatic) property as standard, when the insertion point of the component and the insertion point of the path function text lie directly above/below each other.

It is possible to extend the search for path function text to the entire schematic path. The project setting Extend path function text on the schematic path (under Options > Settings > Projects > "Project name" > Graphical editing > General) must be selected. In this case, a path function text is carried over into the Function text (automatic) property of a component if it is located anywhere within the same path. However, the insertion point of the path function text does not need to be located immediately above / below the insertion point of the component in question. If there are multiple [path function texts](Glossary_o_pfad_funktionstexte.htm) in the path, the first path found is transferred to the component. For this, the schematic path - identical for all [functions](Glossary_o_funktionen.htm) - is searched from left to right and from bottom to top.

![](../Pictures/Gui/ALL/example.png) [![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Correct positioning of the path function text in a line above the component. The path function text can be reported here and adopted in the Function text (automatic) property.

![](../Pictures/Gui/ALL/gededitgui_pathfunctiontext1_as.png)

Incorrect positioning of the path function text, displaced below the component. The path function text cannot be reported here and the Function text (automatic) property remains empty.

![](../Pictures/Gui/ALL/gededitgui_pathfunctiontext2_as.png)

But if the Extend path function text on the schematic path project setting is selected, the path function text is also transferred to the Function text (automatic) property here.

![](../Pictures/Gui/ALL/note.png)Note:

The path function text is only transferred within the complete schematic path if the plot [form](Glossary_o_verlauf.htm) either only contains columns or only [lines](Glossary_o_leitungen.htm). If the plot frame contains columns and lines, the path function text is only transferred to the components that are in the same "Field" (defined by the column and line number) as the path function text.

When displaying the Function text (automatic) property on a project page, the line breaks of the path function text or of the manually entered function text are removed. These line breaks are not required for display on PLC overview pages or in the [report pages](Glossary_o_auswertungsseiten.htm) and would even cause problems.

The path function text basically behaves like a graphical text and has the same orientation options.

### Behavior of the path function text for removal and return of functions

If a function is taken from a navigator and placed, it automatically takes the path function text from the path, if that exists. If a function is returned from the schematic to the navigator, the function text of the returned function is changed if it was taken from the path, but not entered directly in the component.

If a component is cut and reinserted in a different place in the project or in a different project, then the function text in the newly generated function is changed if it was derived from the path function text in the original function.

# Importing Devices and Routing Connections into a Project

Devices and [routing connections](Glossary_o_verlegeverbindungen.htm) can be imported in the [form](Glossary_o_verlauf.htm) of data from external programs (other CAE systems, ERP systems, MS Excel, etc.) into an EPLAN project in order to [create](Glossary_o_erstellen.htm) a complete [panel layout](Glossary_o_schaltschrankaufbau.htm) on the basis of these data and subsequently [route](Glossary_o_verlegen.htm) [connections](Glossary_o_verbindungen.htm) in this layout.

The following are imported:

- Device tag / terminal lists and [wiring](Glossary_o_verdrahtungen.htm) lists with the file extensions TXT and CSV
- Text files with the file extension ASC
- MS Excel files with the file extensions XLS, XLSX, XLSB, XLSM.

Synchronization with [devices](Glossary_o_betriebsmittel.htm) and routing connections already existing in the project can be carried out during importing. It is furthermore possible to delete devices and routing connections already existing in the project by carrying out synchronization. As a result of importing unplaced devices and unrouted routing connections are imported into the project. These devices can subsequently be placed in the [layout space](Glossary_o_bauraum.htm) and the unrouted routing connections can be rerouted.

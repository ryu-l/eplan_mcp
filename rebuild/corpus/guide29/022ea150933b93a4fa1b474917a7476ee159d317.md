# Exchanging Projects via E-mail

![](../Pictures/Gui/ALL/warning.png)Warning:

A MAPI-based e-mail editor is installed and configured on your computer to exchange e-mails. For this reason the e-mail app of Windows 8Â® cannot be used either.

You can only send one project at a time via e-mail. When a project is sent, the [project properties](Glossary_o_projekteigenschaften.htm) remain unchanged; the write-protection of a project is also retained. The information that this is a filed off project is also sent.

You can send a project via e-mail from the page navigator or from the project management.

### [ClosedSend projects from the page navigator](javascript:void(0);)

Preconditions:

- You have selected the desired project in the page navigator.
- You have configured the default [settings](Glossary_o_einstellungen.htm) for the Backup medium "E-mail" under Options > Settings > User > Data backup > Settings > Default settings.

1. Select the menu item Project > Send by e-mail.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project is split according to the settings into zipped files of the specified size, your installed e-mail editor is opened, and the appropriate number of e-mails is created.
2. Select the recipient and enter an accompanying text, if necessary.
3. Click [Send] for each generated e-mail.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project is sent as an attachment - split into several e-mails, if necessary.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The split backup files are differentiated by the addition of ".000" up to maximally ".999" in the file names.

### [ClosedSend projects from the project management](javascript:void(0);)

Preconditions:

- You have opened the project management (Project > Management) and selected the desired [projects](Glossary_o_projekte.htm).
- You have configured the default settings for the Backup medium "E-mail" under Options > Settings > User > Data backup > Settings > Default settings.

1. Select the Send by e-mail popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The first selected project is split according to the settings into zipped files of the specified size, your installed e-mail editor is opened, and the appropriate number of e-mails is created.
2. Select the recipient and enter an accompanying text, if necessary.
3. Click [Send] for each generated e-mail.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project is sent and the next selected project is split according to the settings into zipped files of the specified size, your installed e-mail editor is opened, and the appropriate number of e-mails is created.
4. Proceed in a similar way for all additional selected projects.

### [ClosedRestore projects sent as e-mail](javascript:void(0);)

Precondition:

If the project is split into several e-mails, then the files must all be stored in a common directory.

1. Double-click the backup file (\*.zw1 or \*.000.zw1 in the case of split backup files).  
     
   ![](../Pictures/Gui/ALL/arrow.png) EPLAN is started (if necessary), and the Restore project dialog is opened.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Projects field displays the backup file \*.zw1. If the directory contains split backup files, only the \*.000.zw1 file is displayed, the other backup files belonging to the same project (\*.001.zw1, \*.002.zw1, etc.) are not shown.
2. Define whether the project is to be restored to the project directory under its original name or using a new name.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the project is split into several parts, EPLAN recognizes this and automatically combines the files.

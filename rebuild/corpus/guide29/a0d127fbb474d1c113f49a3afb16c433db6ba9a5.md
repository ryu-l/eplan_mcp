# Project Management

Project management always occurs in connection with a project management database. You can read centralized and decentralized directories and the [projects](Glossary_o_projekte.htm) they contain into the project management. EPLAN searches through the directories and displays all of the existing projects in a tree view.

All directories and projects that have been read are simultaneously displayed in the project management. This allows you direct access to the distributed projects.

The project management allows you to manage all aspects of your projects.

- You can edit and [generate](Glossary_o_erzeugen.htm) [reports](Glossary_o_auswertungen.htm) on a project specific basis or over multiple projects.
- You can organize many projects and subprojects from within the project management.
- You can access projects with several users. The project management shows which projects are currently being edited.
- You can allocate access rights for editing the project management.
- You can backup, file off, and archive projects.

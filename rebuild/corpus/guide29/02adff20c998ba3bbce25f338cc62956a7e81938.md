# P016001: Component within two black boxes which are not nested

### Cause

There is a [component](Glossary_o_schaltzeichen.htm) between two overlapping but unnested [black boxes](Glossary_o_geraetekaesten.htm). This is preventing the component from being clearly assigned to one of the black boxes.

### Solution

Check which device identifier the component belongs to and which black box it is assigned to. For more information on the nesting of [devices](Glossary_o_betriebsmittel.htm) with black boxes, see the section [Black Boxes. Basics for nesting](blackbox_k_schachteln.htm).

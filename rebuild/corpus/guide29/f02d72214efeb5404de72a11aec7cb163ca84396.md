# Tab General (Export Rittal - Perforex LC / Secarex)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Machining > Export Rittal - Perforex LC / Secarex. Select the General tab.
- Utilities > Manufacturing data > Machining > Rittal - Perforex LC / Secarex. Click [...] next to the Machine field. Select the General tab.

In this tab, you specify the general [settings](Glossary_o_einstellungen.htm) of the NC export to Perforex LC / Secarex laser machining center of the manufacturer Rittal.

Overview of the main dialog elements:

Distance start hole:

Distance of the insertion hole of the laser beam to the inside to the machining edge of the cut-out outline. The laser begins the milling process in the start hole and then enters the outline. Then it moves through the outline and returns to the start hole in order to complete the process there.

The default value is 1.5 mm.

Prefix:

Here you can specify a character or string that precedes the entries for the generation of a Perforex outline name in the exported NC file. The default setting is "LC\_".

The prefix for [outlines](Glossary_o_konturen.htm) is also effective for the field identifier Part / Variable component part - Name on the [Field identifier](ncgui_r_feldbezeichner.htm) tab, if the corresponding setting for the generation is set to "Automatic".

Output directory:

Select the directory where the export files are to be saved. The workstation in the workshop at the machine must have access to this directory.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).

Generate file names:

Through the "From [properties](Glossary_o_eigenschaften.htm)" entry the file name is made up solely from [layout space](Glossary_o_bauraum.htm) and [project properties](Glossary_o_projekteigenschaften.htm) as well as freely definable separators during the NC export. Use the [...] button to open the Format: Property dialog to configure the file name.

Generate subdirectories:

In this drop-down list you specify the default method for generating subdirectories during the CNC export:

- None: If you select this option, no subdirectories are generated during the export.
- From properties: If you select this option, the substructure name is compiled from the layout space and project properties as well as freely-definable separators or directory separators. Use the [...] button to open the Format: Property dialog to configure the directory name. Here you can use the "directory [separator](Glossary_o_trennzeichen.htm)" format element, for example, to [generate](Glossary_o_erzeugen.htm) a directory structure with multiple subdirectories arranged one below the other.

---

Material number table

Up to 10 different material numbers that you can assign to the materials to be worked are available during the Rittal Perforex LC / Secarex export. You can also allocate all the assigned materials to individual tools on the Tools tab. The corresponding material number is entered.

During the export, this number is then selected and transferred to the machine. These settings must be synchronized with those at the machine. The first three material numbers are preset as follows:

- Material number 1: Steel
- Material number 2: Stainless steel
- Material number 3: Aluminum.

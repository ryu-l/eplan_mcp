# Change of Standard

It is often required that a project be created and adjusted to a specific country for the international market. EPLAN offers you the option here of adjusting a project to the specifications of a different standard:

- If you [create](Glossary_o_erstellen.htm) a new project from an existing project and then adjust the new one to the specifications of a different standard, the original project remains unchanged.
- You can adjust the project pages to a different plot frame. The project pages can thus be displayed in portrait and landscape format.
- You can exchange the [symbol libraries](Glossary_o_symbolbibliotheken.htm).
- If you do not want to manage more than one symbol library, you can also exchange individual [symbols](Glossary_o_symbole.htm).
- You can exchange [forms](Glossary_o_formulare.htm) for [reports](Glossary_o_auswertungen.htm).
- You can adjust [designations](Glossary_o_bezeichnungen.htm) and names to the target standard by selecting a different template.
- It is also possible to change the [project structure](Glossary_o_projektstruktur.htm) by using a different template.
- You can hide [connection point designations](Glossary_o_anschlussbezeichnungen.htm).

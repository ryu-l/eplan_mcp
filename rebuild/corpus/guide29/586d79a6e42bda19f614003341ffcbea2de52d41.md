# Tab Manufacturing

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have marked a [part](Glossary_o_artikel.htm) in the tree, list or combined view.

In this tab, you can enter production information which is independent of the selected part type and product group ([component](Glossary_o_schaltzeichen.htm), [cable](Glossary_o_kabel.htm), etc.). This data can be specified once per part.  
Take note that a drilling pattern is not a part, but simply serves to assign additional structural information to a part. Each part can contain any quantity of such drilling pattern information.

Overview of the main dialog elements:

Drilling pattern:

Here click [...] and select from the Select drilling pattern dialog the drilling pattern(s) to be assigned to the part.

Devices with miscellaneous assembly [variants](Glossary_o_varianten.htm) must have a suitable drilling pattern defined for each variant. When [placing](Glossary_o_auflegen.htm) such a part, a dialog is displayed in which you can select the drilling pattern to be used. If the Select drilling pattern selection dialog is no longer to be displayed, you can deactivate it using the Do not show this dialog again check box. In this case, the first drilling pattern entered at the part will always be used.

The drilling pattern selected during placement is entered in the [properties](Glossary_o_eigenschaften.htm) of the part placement on the Parts tab in the Part reference data category in the Used drilling pattern field. The drilling pattern can be subsequently modified here. For this, all [drilling patterns](Glossary_o_bohrbilder.htm) assigned to the part are offered for selection in a drop-down list.

Offset in X-direction / Offset in Y-direction:

In these fields, you specify a move in the X and Y direction for the respective drilling pattern. This allows you to use identical drilling patterns for parts of different sizes.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# Dialog Settings: Compression

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Project > Organize > Compress. Click [...] next to the Settings field in the Compress project dialog.
- Options > Settings > Projects > "Project name" > Management > Compress.

In this dialog you can specify the scope in which the project should be compressed. These [settings](Glossary_o_einstellungen.htm) must be saved as a scheme.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Data to be compressed:

In this field, you can specify the compression settings. This determines which [project data](Glossary_o_projektdaten.htm) will be removed or reorganized. If a check box is selected, that data is eligible for compression.

- [Remove project data](projectcleangui_k_komprimierungsdaten.htm#I_ProjektdatenEntfernen)
- [Revise devices](projectcleangui_k_komprimierungsdaten.htm#I_BetriebsmittelUeberarbeiten)
- [Remove unplaced functions](projectcleangui_k_komprimierungsdaten.htm#I_NichtPlatzFunktionenEntfernen)
- [Remove unplaced connections](projectcleangui_k_komprimierungsdaten.htm#I_NichtPlatzVerbindEntfernen)
- [Remove placed functions](projectcleangui_k_komprimierungsdaten.htm#I_PlatzFunktionenEntfernen)
- [Reorganize project](projectcleangui_k_komprimierungsdaten.htm#I_DatenbankNeuAufbauen)
- [Remove completely unplaced devices](projectcleangui_k_komprimierungsdaten.htm#I_VollstNichtPlatzDT)
- [Remove unplaced functions without main functions](projectcleangui_k_komprimierungsdaten.htm#I_NichtPlatzFunktionenOhneHauptfkt)
- [Symbols](projectcleangui_k_komprimierungsdaten.htm#I_Symbole)
- [Comments](projectcleangui_k_komprimierungsdaten.htm#I_Kommentare)
- [Net definition points](projectcleangui_k_komprimierungsdaten.htm#I_NDPs)
- [Revision control](projectcleangui_k_komprimierungsdaten.htm#I_Revision)
- [Remove 3D data](projectcleangui_k_komprimierungsdaten.htm#I_3DDaten)

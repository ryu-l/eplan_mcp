# P014002: The macro name '<x>' defined at the layout space exists several times

### Cause

While [macros](Glossary_o_makros.htm) were being generated from a macro project a macro name was defined at a [layout space](Glossary_o_bauraum.htm) that is already assigned to a different layout space. Or several identical macro names have been stored in the macro definition for one and the same layout space. The corresponding layout space and the multiple defined macro name <x> are displayed in the Layout space and Message text columns in the Message management dialog.

### Solution

1. Open the layout space navigator.
2. Locate the layout space in the project using the Synchronize selection function offered by the popup menu in the Message management dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The layout space is marked in the layout space navigator.
3. Use the popup menu of the layout space navigator to open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the layout space.
4. Bring the Layout space tab to the front.
5. Change the macro name in the Macro: Name field of the [properties](Glossary_o_eigenschaften.htm) table. Select a name that has not yet been assigned to a different layout space.
6. Change to the Macro definition tab and check whether further [lines](Glossary_o_leitungen.htm) with identical macro names exist below the Line 1 in the table column Macro: Name.
7. If so, delete the macro names occurring several times or replace them by unique macro names.
8. Close the properties dialog with [OK].
9. Start a new check run.
10. Repeat Steps 2 to 9 for further layout spaces displayed in the Message management dialog.

# P005026: Connection point is not connected

### Cause

At least one [component](Glossary_o_schaltzeichen.htm) connection is not linked to another component. This means there is no structure for the connection.

### Solution

Link the component connection to the connection of another component so that an autoconnect line can be made with targets.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

# Importing Externally Edited Properties

Precondition:

You have opened a project, and have exported data using the Utilities > Edit properties externally > Export data menu [items](Glossary_o_bauteile.htm) and under Output type you have not selected the Edit in external application and reload option. You have edited the data in the chosen external application and saved the file. In EPLAN, open the project where the data is to be imported.

1. Select the menu items Utilities > Edit properties externally > Import data.
2. In the Open dialog, select the directory where the file to be imported is located, then select the file and click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The data is imported.

![](../Pictures/Gui/ALL/note.png)Note:

Please note the following points about the import: If you add a new object (new function, new page, etc.) to the exported file before the import, you must enter this new line in the Excel file in the "EPL\_VALUES" name definition too. To do this, open the Define name dialog in Excel, using the shortcut key [Ctrl] + [F3] for example. Now modify the data area of the "EPL\_VALUES" variable in the Applies to field so that the new object is included in the import.

### Creating new functions when importing from Excel

Precondition:

You have opened a project.

1. Select the following menu items: Utilities > Edit
   properties externally > Export data
2. Click [...] in the Settings field of the Edit externally dialog.
3. In the Settings: External editing dialog select a different scheme if necessary, or [create](Glossary_o_erstellen.htm) a new scheme. Regardless of which scheme is selected, ensure that the object type is set to All functions.
4. Click [OK].
5. Select the Edit in external application and reload option in the Edit externally dialog.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The data are exported to Excel.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Excel is opened with the exported function [properties](Glossary_o_eigenschaften.htm).  
     

   ![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

   ![](../Pictures/Visualisation/ALL/pxfinterface_createnewfunktions1_av.png)
7. To create new [functions](Glossary_o_funktionen.htm), copy the [lines](Glossary_o_leitungen.htm) from existing functions, for example, and then edit the entries for DT (full) and DT (displayed). (These entries are highlighted with a frame on the right-hand side of the illustration below.)
8. Lastly, change the entry in the first column of each function by setting the number after the slash ("/") to zero.  
     

   ![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

   ![](../Pictures/Visualisation/ALL/pxfinterface_createnewfunktions2_av.png)
9. To make the new functions available for the EPLAN project, you must extend the range of the EPLAN values in Excel. To do this, press [Ctrl] + [F3].   
     
   ![](../Pictures/Gui/ALL/arrow.png) The Define name dialog opens.
10. Click the name "EPL\_VALUES" and change the entry in the Applies to field to the current bottom right cell ("=EplSheet!$A$3$L$7" in the example above).
11. Click [OK].
12. Save the table, and close Excel.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The data are exported.  
      
    ![](../Pictures/Gui/ALL/arrow.png) EPLAN opens a dialog asking whether you wish to import the data.
13. Click [Yes].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The functions created in Excel are imported and inserted in the device navigator as [unplaced functions](Glossary_o_nicht_platziertefunktionen.htm).

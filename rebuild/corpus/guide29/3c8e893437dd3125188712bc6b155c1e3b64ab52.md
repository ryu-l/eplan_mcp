# Menu Help

The Help menu contains the following menu [items](Glossary_o_bauteile.htm):

| Menu item | Meaning |
| --- | --- |
| Contents | Calls up the help system with an opened Contents tab. |
| EPLAN Information Portal | Starts an EPLAN website with information about the EPLAN products (help systems, tutorials, etc.). Here you have the possibility to search globally for terms in all the stored technical publications via a full-text search. |
| Create EPLAN support request | Starts an EPLAN Internet page with a [form](Glossary_o_verlauf.htm) for a support request. |
| EPLAN Download Manager | Starts the EPLAN Download Manager and offers the possibility to install the program components for EPLAN. |
| Customer-focused improvement program | Opens the Customer-focused improvement program dialog, where you can decide if you want to participate in this program. |
| About | Opens the About EPLAN dialog containing the following information:   - Product - Licensed add-ons - Copyright / Trademark - System information |

### Project groups

User interface / operation

Project groups are used to make working easier at simultaneous working with several projects. Through the assignment of a project to a specific project group you can stipulate that this project is marked by a colored margin in the project data navigators in order to facilitate differentiation. In addition you can have further additional navigators, such as a second page navigator, displayed for the projects of a project group.

# Dialog Settings: General (user, display)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > User > Display > General

In this dialog, you define the general user [settings](Glossary_o_einstellungen.htm) for the display.

Overview of the main dialog elements:

Use one Clipboard only:

If this check box is selected, only one Clipboard is used for cut and copied [objects](Glossary_o_objekte.htm) and copied pages.

If this check box is deselected, multiple Clipboards are used for cut and copied objects and copied pages. If in such a case you copy two or more objects (or pages), EPLAN opens the Paste dialog when you are pasting. In this dialog you then select which copied object (or page) you want to paste.

Do not show description dialog:

If this check box is selected, the cut or copied object (or a copied page) is stored in the Clipboard without description.

If this check box is deselected, the Clipboard dialog opens when copying an object or page. Here you can enter a description for the object. This description is displayed in order to assist you with selection in the Paste dialog.

Update reports when opening pages:

If this check box is selected, existing [report pages](Glossary_o_auswertungsseiten.htm) are automatically updated when they are opened.

If this check box is deselected, existing report pages are not automatically updated when they are opened.

Update reports when printing and exporting:

If this check box is selected, existing report pages are automatically updated before being printed or exported. If a template exists in the [reports](Glossary_o_auswertungen.htm), it is also generated.

If this check box is deselected, existing report pages are not automatically updated before being printed or exported.

Update connections when switching pages:

If this check box is selected, then the [connections](Glossary_o_verbindungen.htm) are automatically updated when changing pages (opening, closing, scrolling across pages, etc.). The connections are updated both on the opened pages and on those pages to which the connections lead through [interruption points](Glossary_o_abbruchstellen.htm). In addition, connections within the edited page (i.e., those that do not end at an interruption point) are updated after every editing step. Project-wide updating does not take place.

If the check box is deactivated, automatic updating does not take place during editing in the graphical editor and when changing pages.

Update connections during routing:

If this check box is activated, the connections are updated automatically in the [layout space](Glossary_o_bauraum.htm) or in the [topology](Glossary_o_topologie.htm) before the generation of [routing connections](Glossary_o_verlegeverbindungen.htm).

If the check box is deactivated, the connections are not updated automatically during routing.

Update connections throughout the project (manually):

This setting only has an effect on the manual connection updating.  
If this check box is activated, connections are updated as if the entire project has been selected.

If the check box is not activated, updating is only carried for the current selection (of pages, [functions](Glossary_o_funktionen.htm), etc.).

Always update cross-references:

If this check box is selected, then the graphical editor view is rebuilt after every editing step. This always automatically updates the [interruption point cross-references](Glossary_o_abbruchstellenquerverweise.htm) on the page.

If this check box is deselected, then automatic updating does not occur. In this case you can update the interruption point [cross-references](Glossary_o_querverweise.htm) via View > Redraw or by pressing the [F5] key.

Display scroll bars:

If this check box is activated, scroll bars are displayed on the right and / or bottom margin of the [editors](Glossary_o_editoren.htm) (Graphical editor, Symbol editor, Form editor, etc.) with which you can move the displayed section.

If the check box is deactivated, the scroll bars in the editors are hidden.

Synchronize navigators upon opening:

Objects selected in the graphical editor, in message management, or in the Search results dialog can be automatically synchronized when opening the [project data](Glossary_o_projektdaten.htm) [navigators](Glossary_o_navigatoren.htm) without having to activate the Synchronize selection popup menu item.

If this check box is activated and you have, e.g., selected one or several objects on an opened page, the selection is synchronized as soon as you open a project data navigator. For quickly opening click on the desired button of a navigator in the Navigators toolbar. The selected objects are also highlighted in the opened navigator if this contains the objects.

Retain revision data and revision markers during inserting:

If this check box is activated, the revision data from the source project are inserted into the target project when copied pages or [page macros](Glossary_o_seitenmakros.htm) are inserted. In addition, the [revision markers](Glossary_o_revisionsmarkierungen.htm) are copied as well and inserted into the target project during the copying and inserting of schematic sections, pages or layout spaces as well as during the insertion of [macros](Glossary_o_makros.htm).

If the check box is deactivated, no revision data and no revision markers are inserted into the target project.

![](../Pictures/Gui/ALL/note.png)Notes:

- The revision data are only visible in the target project, if a revision with the same internal "Revision number" exists (in accordance with the sequence of creation). This means that the revision data of the second revision of the source project are sorted into the second revision of the target project, irrespective of the revision names and revision indexes in the two [projects](Glossary_o_projekte.htm). The revision data are also inserted into non-revisioned projects. However, they are not visible there until after the generation of a suitable revision.
- The revision markers are only visible in the target project if the View > Revision markers option is activated.

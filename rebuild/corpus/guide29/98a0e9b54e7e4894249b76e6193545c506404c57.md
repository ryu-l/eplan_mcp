# P004050: Connection from '<x>' to '<y>' missing

### Cause

During the PLC data import an individual connection from device <x> to device <y> was determined that was currently not found in the project.

### Solution

Create the connection between the [devices](Glossary_o_betriebsmittel.htm) by means of [bus ports](Glossary_o_sps_busanschluesse.htm).

![](../Pictures/Gui/ALL/note.png)Note:

This module-specific message is generated by the importing of PLC data. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

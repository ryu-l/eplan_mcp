# Improved Detection of User-Defined Layers

The "501005" check message from the 501 "[part](Glossary_o_artikel.htm) [master data](Glossary_o_stammdaten.htm)" message class has been revised. This allows [user-defined](Glossary_o_benutzerdefiniert.htm) [layers](Glossary_o_ebenen.htm) in [macros](Glossary_o_makros.htm) that were stored at parts to be found more easily. As a consequence significantly more check messages are now generated for user-defined layers than before the revision.

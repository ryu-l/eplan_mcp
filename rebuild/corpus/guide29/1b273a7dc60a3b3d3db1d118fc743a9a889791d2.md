# Determining Search Terms

Search terms in EPLAN are sought in the following locations:

- In all [objects](Glossary_o_objekte.htm) that can be placed on a page
- In all objects that can be placed in layout spaces
- In the [properties](Glossary_o_eigenschaften.htm) of all placed and unplaced objects
- In the page data (except the page name)
- In the [layout space](Glossary_o_bauraum.htm) data (except the layout space name)
- in the [project data](Glossary_o_projektdaten.htm) (except the project name).

The search can be defined for the entire project, or just for specific pages. In addition, you can specify the project in which a search term is sought.

The results of a search are written to a list of results.

All character strings are allowed in searches, in which they can also contain [placeholders](searchandreplacegui_k_platzhalter.htm) (such as "\*" and "?"). It is also possible to search for multiple related terms. However, you cannot search for multiple independent phrases.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

If you search for an "Enclosure control system" only those texts with the individual words in the correct order will be found. The phrases "System for enclosure control" or "Control system in enclosure" will not be found.

### Take structural elements into consideration for searches

If the DT / designation check box is selected in the Search in group box of the Find dialog, the search term will be searched for in the full DT. Structural elements are not taken into consideration for this.   
  
 Only if the DT is entered as a search term along with its structure will the structure be used! It is here that a complete partial structure of the [project structure](Glossary_o_projektstruktur.htm) must be entered from the DT to the left. Additionally, the [preceding sign](Glossary_o_vorzeichen.htm) (=, +, etc.) must also be entered. No placeholders are allowed in the structural elements.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

It is assumed that the project structure consists of a [functional assignment](Glossary_o_funktionalezuordnung.htm), [higher-level function](Glossary_o_anlage.htm), [installation site](Glossary_o_aufstellungsort.htm), and [mounting location](Glossary_o_einbauort.htm).

Permitted search terms are (e.g.) ==AA=A++OO+O-K1 or =A++OO+O-K1 or ++OO+O-K1 or +O-K1,  
 but not =A-K1 (the device structure is incomplete because the installation site and mounting location are unspecified)  
 or =A++O\*+O-K1 (the placeholder symbol "\*" is not allowed).

The "Displayed DT" is shown as a search result. Use the Replace function to change only the displayed DT and, within that, only the elements without structural elements. If no DT is displayed at the [component](Glossary_o_schaltzeichen.htm), i.e., [DT adoption](devicetaggui_k_bmkuebernahme.htm) exists, then nothing will be replaced.

![](../Pictures/Gui/ALL/note.png)Note:

When adopting DTs, the displayed DT is empty and no DT will be found in the search.

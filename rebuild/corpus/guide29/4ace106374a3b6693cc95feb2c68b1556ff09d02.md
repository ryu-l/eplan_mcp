# Reports

Reports represent queries of the [project data](Glossary_o_projektdaten.htm). They allow the targeted output of project data. These are automatically generated and can be written directly to [report pages](Glossary_o_auswertungsseiten.htm) or to external files, e.g., for printing item labels. It is also possible to manually place [reports](Glossary_o_auswertungen.htm) into an existing project page as an embedded report, e.g., for [enclosure legends](Glossary_o_schaltschranklegenden.htm). Reports are divided into [report types](formgeneratorgui_k_auswertungstypen.htm).

![](../Pictures/Gui/ALL/note.png)Note:

If the project does not contain any [objects](Glossary_o_objekte.htm) that are required for the respective report or if no suitable objects were found due to the set [filters](Glossary_o_filter.htm), a report page is generated.

# Tab Dimension (mounting panel)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- The project contains at least one [layout space](Glossary_o_bauraum.htm). The layout space contains at least one placed mounting panel. You have opened the layout space navigator. Select a mounting panel in the navigator. Select the Properties popup menu item. In the Properties <...> dialog, select the Dimension tab.
- You have selected a mounting panel in the 3D display area. Edit > Properties (or Popup menu > Properties). In the Properties <...> dialog, select the Dimension tab.

The dimensions of a 3D mounting panel are shown in this tab. Display of the width, height, and depth of the mounting panel can be in mm or inch. The value cannot be edited in this dialog. With a free mounting panel, a change may be made.

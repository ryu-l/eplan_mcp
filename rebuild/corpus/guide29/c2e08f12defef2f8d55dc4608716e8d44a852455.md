# Creating Device Definitions

A device definition is composed of a set of x [function templates](Glossary_o_funktionsschablonen.htm). You define these templates in the parts management.

1. Utilities > Parts > Management
2. Browse the tree structure and select a [part](Glossary_o_artikel.htm).
3. In the Function templates tab define a function template for every function in the device: To do so click ![](../Pictures/Gui/ALL/all_new_as.png) (New).  
     
   ![](../Pictures/Gui/ALL/arrow.png) A new row is created in the table.
4. In the first cell, use [...] to open the function selection and select a function definition.
5. Click [OK].
6. Enter the technical data of the function in the other cells of the Function templates. A symbol can be assigned to the part by means of the Symbol field.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol is placed when no function templates exist, i.e. the table is empty.   
     
   ![](../Pictures/Gui/ALL/arrow.png) If function templates exist, the data entered here is not taken into consideration, but you can still use this for filtering.
7. Click [Apply].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The device definition is stored in the part.

# PCT Loops / PCT Loop Functions in P&I Diagrams

[PCT loops](Glossary_o_plt_stellen.htm) and [PCT loop functions](Glossary_o_plt_stellenfunktionen.htm) are represented using P&I [symbols](Glossary_o_symbole.htm) in the [P&I diagram](Glossary_o_ri_fliessbild.htm). These P&I symbols are located in the Special.slk symbol library.

### PCT Types

There are different PCT types for PCT [loops](Glossary_o_messstellen.htm) and PCT loop [functions](Glossary_o_funktionen.htm). Different P&I symbols must be used, depending on the PCT type.

The following table shows a selection of possible PCT types and the relationships between location and P&I symbol.

| Activation site / Implementation |  | On-site | Measuring station | Control room | Measuring station (not visible) | Control room (not visible) |
| --- | --- | --- | --- | --- | --- | --- |

| General | 1 |  |  |  |  |  |
| PCS | 2 |  |  |  |  |  |
| Process computer | 3 |  |  |  |  |  |
| PLC | 4 |  |  |  |  |  |

# Documenting Forms and Plot Frames

It is possible to manage and output [forms](Glossary_o_formulare.htm) and [plot frames](Glossary_o_normblaetter.htm) in a special report, where a table of contents is generated and change information can be entered. The report on forms / plot frames can be a project into which the forms / plot frames are read: There are specific [reports](Glossary_o_auswertungen.htm) for this purpose Forms documentation and plot frame documentation. Form / plot frame documentation are overviews of all documents / plot frames used in a project.

Precondition:

You have selected a [form](Glossary_o_verlauf.htm) via the menu [items](Glossary_o_bauteile.htm) Options > Settings > Projects > "Project name" > Reports > Output to pages for the "Forms documentation" or "Plot frame documentation" [report types](Glossary_o_auswertungstypen.htm) and have specified the [settings](Glossary_o_einstellungen.htm) for the pages to be generated.

1. Utilities > Reports > Generate
2. If the forms documentation / plot frame documentation is not listed under the reports, click [New].
3. In the Select report dialog, select the Forms documentation or the Plot frame documentation option.
4. If necessary, change the setting for the source project field.
5. Click [OK].
6. In the Forms documentation (Total) (or Plot frame documentation (Total)) dialog specify the settings for the pages to be generated.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The documentation is generated, the process perhaps taking some time, depending on the amount and complexity of the data.
8. Click [Close].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The newly generated pages are generated in the target project specified in the settings. In the list of reports, the level Forms documentation or Plot frame documentation is inserted, and the list of pages contained in the documentation appears there.

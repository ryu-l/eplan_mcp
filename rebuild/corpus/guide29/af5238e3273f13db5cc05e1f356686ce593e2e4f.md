# P021005: Placeholder objects of the same name with different variables

### Cause

The macro project contains [macros](Glossary_o_makros.htm) with [placeholder objects](Glossary_o_platzhalterobjekte.htm) that have the same name but for which different [variants](Glossary_o_varianten.htm) were defined. This results in error messages when the project is opened in EPLAN Engineering Configuration One (EEC One).

### Solution

1. Locate the placeholder [objects](Glossary_o_objekte.htm) by using the Go to (graphic) or Go to 2nd coordinate functionality from the popup menu in the Message management dialog.
2. Rename the placeholder objects existing several times or use the same variables for the placeholder objects.
3. Then start a new check run.

# Dialog Settings: Publish

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Project > Publish. Click [...] in the Scheme field of the Publish dialog.
- Options > Settings > User > Interfaces > Publish.

In this dialog, you can specify the [settings](Glossary_o_einstellungen.htm) for the export of a project to the EPDZ format. The EPDZ format can be read via the dropbox on mobile [devices](Glossary_o_betriebsmittel.htm) (for example iPad) by means of the EPLAN View App.

Tabs:

The following tabs are available for entering the settings:

[Tab Export](edaexportgui_r_export.htm)

[Tab Project properties](edaexportgui_r_eigenschaften.htm)

[Tab Page properties](edaexportgui_r_seiteneigenschaften.htm)

[Tab Layout space properties](edaexportgui_r_bauraumeigenschaften.htm)

[Tab Function properties](edaexportgui_r_funktionseigenschaften.htm)

[Tab Interruption point properties](edaexportgui_r_abrstleigenschaften.htm)

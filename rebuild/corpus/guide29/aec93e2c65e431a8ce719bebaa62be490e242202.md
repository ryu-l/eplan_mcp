# P005027: Ring connection

### Cause

There is an error in the link. It leads back to the same target without getting to another target. This can happen if you link a function to the first target of a T node and link the second target of the T node to the same connection.

### Solution

If you interrupt the ring connection by breaking the connection or adding a function as the second target in the ring.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

# Installing Program Features Using the EPLAN Download Manager

The EPLAN Download Manager helps you to [load](Glossary_o_laden.htm) and install program features with corrections and enhancements in the software (such as hotfixes) from the EPLAN download area.

You start the EPLAN Download Manager by using the menu [items](Glossary_o_bauteile.htm) Help > EPLAN Download Manager.

The following dialog elements are available:

[Download from EPLAN download area and install](#LadenInstallieren)

[Download from EPLAN download area](#LadenausDownload)

[Install from folder](#LadenausOrdner)

[List of the program features installed and available for downloading](#Liste)

[Start download / installation](#Start)

### Specify from where you want to get the program features

You can download and / or install the EPLAN components from various sources.

Download from EPLAN download area and install: The simplest option is to download and install the help systems and program features directly via the Internet from the EPLAN download area. The files with the program features are copied to the download directory of your computer and installed in the EPLAN program directory. This option is suitable for users installing directly from the Internet. At this option only those program features are displayed that match the products already installed.

Download from EPLAN download area: The files with the program features are only copied into the download directory or into a different customizable directory and are not installed in the EPLAN program directory. This option is suitable for an administrator who copies the program features to a folder in the company network from where they are then available for installation by the users. At this option all the program features are displayed that match the version number of the installed EPLAN version and of the Download Manager.

Install from folder: If the user's access to the Internet is deactivated or limited by a firewall, the system administrator can download the installation packages with the program features and copy them to a folder in the company network. From there you install the program features even without Internet access. Enter the file path in which the installation packages are stored in your network into the field next to this option. At this option only those program features are displayed that match the products already installed.

### List of the program features installed and available for downloading

In the middle of the dialog the EPLAN Download Manager lists all the installation packages available in the EPLAN download area or in a set folder. The list of packages that are available in the selected area is updated automatically after every change in the download area.

The following information about the installation of the program features is displayed on your computer:

- The version number of the installation packages already installed
- The status of the installation packages: downloaded / not downloaded / installed / not installed
- The file size of the installation packages.

### Start download / installation

After you have carried out all the [settings](Glossary_o_einstellungen.htm) as desired, click [Start]. The program features are downloaded and installed.

# Changed Publishing of Projects

With the menu [items](Glossary_o_bauteile.htm) Project > Publish only data for the EPLAN View App is exported. As of Version 2.9, [projects](Glossary_o_projekte.htm) for EPLAN Smart Wiring are exported via a separate menu item.

# Generate project reports

For "Generate project [reports](Glossary_o_auswertungen.htm)" the entire project is reported. In the process reports are generated from all the existing [Report templates](formgeneratorgui_k_auswertungsvorlagen.htm). All reports that have already been generated are also updated.

Preconditions:

- You have opened a project.
- You have already generated reports and / or created report templates.

1. Select the menu item Utilities > Reports > Generate project reports.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If a report template is not found, a message is displayed informing you of this and enabling the report to be deleted.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Reports are generated from all the existing report templates. All existing reports are updated. The reports are displayed in the Reports tab and the page navigator.

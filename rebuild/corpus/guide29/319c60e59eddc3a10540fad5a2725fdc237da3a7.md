# Using Connection Filters

Wire ducts, [routing paths](Glossary_o_strecken.htm), [routing ranges](Glossary_o_verlegebereiche.htm), and [wiring cut-outs](Glossary_o_verdrahtungsdurchbrueche.htm) have the property Layout space: Connection filter. The connection filter is used for routing to control which [connections](Glossary_o_verbindungen.htm) may be routed through the routing track. The values of such criteria can be color assignments of [wires](Glossary_o_draehte.htm) or voltage values.

The assignment of values to the connections to be routed is purely textual. Free text is used to define the values, but it must also be added to the connection parts.

### Set project settings for connection filters

The values that can be activated or deactivated in the Connection filter dialog are set in the project [settings](Glossary_o_einstellungen.htm).

1. To call up the settings of the connection filter, select the menu [items](Glossary_o_bauteile.htm) Options > Settings > Projects > "Project name" > Routing connections > General.
2. Select the Connection filter tab in the Settings: General dialog.
3. Click the [...] button.
4. From the Criteria selection dialog select a connection property for which the values are to be displayed in the connection filter, e.g. the property Connection color / number, and click [OK].
5. In the table in the Value column, enter text that describes the filter criterion, e.g., "Blue", "Red", "Black", "Yellow". You can use 15 [lines](Glossary_o_leitungen.htm) for this.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The set values are stored and displayed there when opening the Connection filter dialog.

### Apply connection filter

Apply the values defined in the connection filter to the [objects](Glossary_o_objekte.htm) that are involved in the routing process.

1. In the [layout space](Glossary_o_bauraum.htm) select one or several [wire ducts](Glossary_o_verdrahtungskanaele.htm) or routing paths, and select the popup menu item  Properties.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Properties (components): Part placement (3D) dialog is opened.
2. Select the Connection filter property, and click [...] in the Value column.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The Connection filter dialog is displayed. The table displays the values that you defined in the project settings.
3. Activate the Active check box above the table in order to enable the connection filter generally.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Now the individual values in the table can be activated or deactivated.
4. Activate the Active check box in the table in front of each value that is to be applied to this connection.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Properties (components): Part placement (3D) dialog displays in the Value field of the Layout space: Connection filter property all values that you have activated in the connection filter.  
     
   ![](../Pictures/Gui/ALL/arrow.png) During routing, only the connections are routed through the edited routing path that correspond to the set values.

# P004016: Rack '<x>' is not unique

### Cause

A [rack](Glossary_o_baugruppentraeger.htm) name is used more than once.

### Solution

1. In the Properties <...> dialog at the affected [PLC boxes](Glossary_o_sps_kaesten.htm) change the rack designation in the PLC structure data tab in such a way that the entered values differ.
2. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

This check run only checks PLC boxes at which a configuration project is entered.

# Dialog Design space import

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Layout space > Design space > Import

In this dialog you carry out the import of design spaces (STEP files from external 3D CAD programs).

![](../Pictures/Gui/ALL/note.png)Note:

EPLAN supports solely the import of STEP files that have been generated with the application protocol AP 203 or AP 214.

Overview of the main dialog elements:

Source:

This field displays the names of the STEP files to be exported. The entries in this field cannot be modified.

Scheme:

Selection of a scheme or the possibility to edit or [create](Glossary_o_erstellen.htm) a scheme. The [...] button opens the [settings](Glossary_o_einstellungen.htm) dialog for the STEP import.

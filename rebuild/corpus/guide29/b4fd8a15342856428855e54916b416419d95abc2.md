# P008004: The text '<x>' cannot be translated

### Cause

The [keywords](Glossary_o_stichworte.htm) for the text '<x>' that are required for the translation are not available in the dictionary.

### Solution

1. Add the missing texts as new [Keywords](translatedbgui_h_stichwortanlegen.htm) in the dictionary. For the translation take the [project-specific settings](translategui_r_einstellungprojekt.htm) for the segmentation into account.
2. Then start a new check run.

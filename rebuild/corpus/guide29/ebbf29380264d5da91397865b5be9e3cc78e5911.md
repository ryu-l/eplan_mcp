# P012010: Item exists on the mounting panel without representation in the schematic

### Cause

The main function of an item located on a mounting panel is missing in the schematic.

### Solution

Place the missing main function of the item located on the mounting panel in the schematic.

Then start a new check run.

![](../Pictures/Gui/ALL/note.png) Note:

The page types "Schematic multi-line", "Schematic single-line", and "Overview" are checked.

# Dialog Generate reference project

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Revision control > Property comparison of projects > Generate reference project.

In this dialog you can [generate](Glossary_o_erzeugen.htm) a reference project from the current project.

Overview of the main dialog elements:

Project name:

Provide a name for the reference project here. EPLAN automatically suggests a name based on the current project name, as well as the number of [reference projects](Glossary_o_referenzprojekte.htm) already generated for this project.  
Use [...] to open the dialog for file selection. Select a project name already in use and then change it.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).

User:

This field cannot be changed and shows the user who generated the reference project.

Date:

This field cannot be changed and shows the date on which the reference project was generated.

Generate temporary reference project:

If this check box is activated, a temporary reference project with the file name extension \*.elt is generated. You can also delete a temporary reference project in the project management if you do not dispose of the authorization to delete elr [projects](Glossary_o_projekte.htm).

If the check box is deactivated, a "normal" reference project with the file name extension \*.elr is generated. Such a project can only be deleted in the project management by users with the authorization to delete elr projects.

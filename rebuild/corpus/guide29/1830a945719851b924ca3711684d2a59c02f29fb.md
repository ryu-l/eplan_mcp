# Tab / Dialog Select languages

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Utilities > Translation > Remove translation from project.
- Utilities > Translation > Import project texts.
- You have selected a project or pages. Utilities > Translation > Export missing-word list.

In this dialog you can choose one or more of the displayed languages.

The following dialog elements are available:

Language:

To select a language, mark it. To select more than one language, hold down the [Ctrl] key and select the desired languages.

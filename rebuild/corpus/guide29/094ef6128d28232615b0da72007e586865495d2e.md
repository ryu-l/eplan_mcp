# P022061: The user-defined property '<x>' (input aid '<z>') contains a non-specified value '<y>'

### Cause

You are using a [user-defined](Glossary_o_benutzerdefiniert.htm) property '<x>' in the project at [objects](Glossary_o_objekte.htm) (pages, [macros](Glossary_o_makros.htm), [functions](Glossary_o_funktionen.htm), etc.) for which certain default values <y>' were defined in a selection list by using the input aid '<z>' in the dialog Configure [properties](Glossary_o_eigenschaften.htm).

In the concrete case a value was used that was not a [component](Glossary_o_schaltzeichen.htm) of the selection list specified in the configuration dialog and is therefore reported as invalid.

### Solution

#### Possibility 1

1. Locate the object in the project by means of the Find menu item. Or use the Go to (graphic) functionality from the popup menu of the dialog Message management to find the object on a schematic page.
2. Call up the [property dialog](Glossary_o_eigenschaftendialog.htm) of the object.
3. Select a valid default value '<y>' in the property list for the user-defined property '<x>' via the [...] button.
4. Click [OK].
5. Then start a new check run.

#### Possibility 2

1. Select the menu [items](Glossary_o_bauteile.htm) Project data > Configure properties.
2. In the dialog Configure properties add the manually added value '<y>' to the selection list of the user-defined property '<x>' by using the input aid '<z>'.
3. Click [OK].
4. Then start a new check run.

# P003001: The automatic cable selection is being canceled, because no cable could be preselected

### Cause

You have generated a [cable](Glossary_o_kabel.htm) using the automatic cable selection. EPLAN has not found any cable parts in the cable preselection, however, so the automatic selection is canceled.

### Solution

Select the Options > Settings > Projects > "Project name" > Devices > Cable (automatic) menu option. Click [...] beside the Automatic cable selection field. In the Settings: Automatic cable selection dialog click ![](../Pictures/Gui/ALL/all_new_as.png) (New) on the right above the Cable preselection table. In the tree view, switch to the Part selection that opens for the Cables / [connections](Glossary_o_verbindungen.htm) product group and select the most suitable [cable part](Glossary_o_kabelartikel.htm) for the connections. Click [OK] to transfer the [part](Glossary_o_artikel.htm) to the cable preselection table. Repeat the selection for additional cables. Close the dialog and [generate](Glossary_o_erzeugen.htm) the cable automatically once more.

![](../Pictures/Gui/ALL/note.png) Note:

This module-specific message is generated by the automatic cable selection. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

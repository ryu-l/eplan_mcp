# P020038: The 'Edit DT in individual fields' setting was changed from '<x>' to '<y>'

### Description

You have run a project comparison, checking the structure of the test project (incoming project) against that of the comparison project and differences were found.

This message occurs when the Edit DT in individual fields setting (Project management dialog, DT structure tab) has changed in the project to be checked. The state of the setting before the change (<x>) and after the change (<y>) are output.

![](../Pictures/Gui/ALL/note.png)Notes:

- This message is only displayed in conjunction with a certain, customer-specific version of EPLAN.
- A new check run (any desired scheme) will delete this module-specific message from the message management dialog.

# Protecting Devices

You can protect a complete device by means of the device protection. In addition, it is possible to protect only individual [functions](Glossary_o_funktionen.htm), [connections](Glossary_o_verbindungen.htm) or [planning objects](Glossary_o_planungsobjekte.htm).

### [ClosedProtecting a complete device](javascript:void(0);)

Preconditions:

- You have opened a project.
- You have selected the function of a device in the graphical editor or in a navigator dialog.

1. Select the Project data > Devices > Activate device protection menu [items](Glossary_o_bauteile.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Device protection property is assigned to all the functions of the device. The parts assigned to the device can no longer be changed. This means that a device selection or [part](Glossary_o_artikel.htm) selection or [actions](Glossary_o_aktionen.htm) such as "Exchange part", "Edit part" and "Add part" cannot be carried out.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The device can no longer be deleted from the project.

![](../Pictures/Gui/ALL/info.png)Tips:

- You can extend the device protection by specifying the "Prevent errors" type of check for specific test runs. In this way, you can prevent the over-allocation of a protected device, the addition of further functions, or the modification of data transferred to the functions from the parts.
- If you have selected a hierarchy level in the device navigator, you can activate the device protection for all the [devices](Glossary_o_betriebsmittel.htm) below this hierarchy level simultaneously.

### [ClosedProtecting individual functions, connections or planning objects](javascript:void(0);)

Preconditions:

- You have opened a project.
- You have selected a function in the graphical editor or in a navigator dialog, or you have selected a connection in the connection navigator. You have selected a planning object in the preplanning navigator.

1. Select the Edit > Other > Configure protection menu items.
2. In the Configure protection dialog, select the check box Device protection.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts assigned to the function, the connection or the planning object can no longer be changed. This means that a device selection or part selection or actions such as "Exchange part", "Edit part" and "Add part" cannot be carried out.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The function, the connection, or the planning object can no longer be deleted from the project.  
     
   ![](../Pictures/Gui/ALL/arrow.png) However, it is still possible to change [properties](Glossary_o_eigenschaften.htm) on the first tab of the properties dialog.

### [ClosedDeactivating the device protection](javascript:void(0);)

Preconditions:

- You have opened a project.
- You have selected the function of a device in the graphical editor or in a navigator dialog.

1. Select the Project data > Devices > Deactivate device protection menu items.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Device protection is canceled, so that the Device protection is deactivated for all the functions of the device.

![](../Pictures/Gui/ALL/info.png)Tip:

If you have selected a hierarchy level in the device navigator, you can deactivate the device protection for all the devices below this hierarchy level simultaneously.

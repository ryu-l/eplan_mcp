# Transfer of Configuration Data to EPLAN Fluid

In order to output your plant or machine documentation in the parts lists and / or conduit / line plans, the configuration data created in the hose line configurator have to be written back to the [hose lines](Glossary_o_schlauchleitungen.htm) placed in EPLAN Fluid.

Prerequisite for correct data transfer is that the configuration data of the hose [lines](Glossary_o_leitungen.htm) in the hose line configurator and the hose lines placed in EPLAN Fluid in the schematic dispose of the same (full) DT.

If you have generated the configuration data by using the add-on variant of the hose line configurator, the data are transferred simply by a mouse click or key to the project currently opened in EPLAN Fluid and there entered and stored as corresponding [properties](Glossary_o_eigenschaften.htm) at the hose lines marked in the schematic.

If you have generated the configuration data by means of the stand-alone variant of the hose line configurator, you first have to store the data in an exchange file. You then send the exchange file to the recipient, for example the designer, who edits the hose line data further with EPLAN Fluid and has therefore installed the hose line configurator as an add-on variant of EPLAN Fluid. The recipient imports the exchange file and transfer the configuration data - as already described - to the hose lines located in the opened project.

During the data transfer the following device properties are displayed in the Conduit / line tab and filled with values from the configuration at the hose lines marked in the project in EPLAN Fluid:

- Type (the respective hose type is entered here)
- Cross-section / diameter (the respective nominal diameter is entered here)
- Hose line length
- Hose line identification
- Manufacturing date
- Torsion angle
- Working pressure

In addition the following information is entered at the [part](Glossary_o_artikel.htm) properties of the hose lines:

- Type of construction of the fitting left  (at part position 1)
- Type of construction of the fitting right (at part position 2)
- Hose type (at part position 3)
- Type code (at part position 4).

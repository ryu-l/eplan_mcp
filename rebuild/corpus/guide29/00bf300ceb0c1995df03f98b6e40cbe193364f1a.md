# Property overview

The so called Property overview behaves like a navigator and can be docked at the EPLAN [main window](Glossary_o_hauptfenster.htm) at different positions. The dockable dialog can be used to rapidly edit the [properties](Glossary_o_eigenschaften.htm) of different [objects](Glossary_o_objekte.htm) without having to open and close multiple property dialogs one after another. You can configure this dockable dialog so that only the important properties are displayed for you.

In the property overview you can simultaneously edit the properties of an individual object or the properties of multiple selected objects. Since in [part](Glossary_o_artikel.htm) there are properties with the same name for the objects (texts, graphical elements, components, [segments](Glossary_o_segmente.htm)), the properties are grouped in the tree view in accordance with their source objects.

### Formatting Several Graphical Elements Simultaneously

You can, for example use the property overview to select multiple graphical elements (rectangles, line, etc.) together and format them at the same time as well. To format graphical elements, you have the "Format graphic" scheme available in the property overview. In the common formatting you can change properties such as the Line thickness, Color, Line type, etc.

### Editing non-function-specific properties of components

The property overview also gives you the option of a special [form](Glossary_o_verlauf.htm) of [block editing](Glossary_o_blockbearbeitung.htm). In the process, the properties that all different components have together are displayed and edited. This is designated as [non-function-specific block editing](multipleselection_k_prinzip.htm#I_BlockbearbSchaltzeichen). The property overview of the scheme "Non-function-specific properties" is available for this purpose.

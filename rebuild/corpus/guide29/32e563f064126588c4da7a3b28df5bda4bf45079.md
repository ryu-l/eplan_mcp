# P005020: Conflict between identical potential definitions

### Cause

Two or more of a connection's potential definitions (potential [connections](Glossary_o_verbindungen.htm) or [potential definition points](Glossary_o_potenzialdefinitionspunkte.htm)) which use the same potential name, have conflicting [properties](Glossary_o_eigenschaften.htm), for example the potential type or value.

### Solution

Enter the same properties for all a connection's potential definition points and / or potential connections.

Refresh the connections and then start a new check run.

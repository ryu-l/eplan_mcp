# Improved Properties and Formatting for Date and Time

To be able to display individual components for the date and time in a better way, a project property was corrected, another one added and the formatting possibilities for these [properties](Glossary_o_eigenschaften.htm) improved.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

By means of the two [project properties](Glossary_o_projekteigenschaften.htm) and the new format [settings](Glossary_o_einstellungen.htm) you can adjust the date and times specifications in the graphical editor and [plot frames](Glossary_o_normblaetter.htm) in accordance with your requirements.

### Improved properties

The behavior of the Date ([ID](Glossary_o_id.htm) 10027) project property has been corrected. This property now only still shows the date in the project properties or as inserted special text in the graphical editor as well as in the plot frame. To have the current time shown in accordance with the set formatting in these locations, you now use the new project property Time (ID 10058).

By inserting the Time property in a plot frame, it is now also possible for project pages to document the time of a print order. All project pages that belong to a print order show the same time of the day.

### Individual format settings

For the project properties placed as special text, new format settings are also available. To this purpose the Format tab below the new Date / time hierarchy level has been expanded by the two display properties Date format and Time format.

[![](../Pictures/Gui/Lang/gededitgui_datetimeformat_ls_thumb_0_60.png)](../Pictures/Gui/Lang/gededitgui_datetimeformat_ls.png)

The default setting for these properties is "From project settings". In this case the format specified in the [Project settings](xessettingsgui_d_einstellungenprojektdatum.htm) is used for a property for date and time display that is placed as special text. By using the respective drop-down list you can select an individual date or time format for the Date and Time project properties mentioned above, for example "YYYY" for a display "2018". In these lists further [formats](Glossary_o_formate.htm) are available in comparison to the project settings.

![](../Pictures/Gui/ALL/note.png)Note:

The Display tab in the [property dialog](Glossary_o_eigenschaftendialog.htm) of the device has been expanded by the new hierarchy level Date / time. The date format can only be set here individually for a small number of properties for the date display.

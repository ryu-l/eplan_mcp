# P026092: New air-conditioning calculation required for air-conditioning field <x>

### Cause

The value of the power dissipation in the air-conditioning field <x> has changed. Therefore a new air-conditioning calculation is required for this air-conditioning field.

![](../Pictures/Gui/ALL/note.png)Note:

The comparison criterion for this check run is the power dissipation occurring in the respective air-conditioning field. The current power dissipation is compared with the power dissipation of the last air-conditioning calculation. This check can be carried out for a maximum of 100 air-conditioning fields.

Depending on the air-conditioning field that was selected all the power dissipations are added under consideration of the [simultaneity factor](Glossary_o_gleichzeitigkeitsfaktor.htm) for all the [items](Glossary_o_bauteile.htm) of the air-conditioning field in accordance with the following formula:

Total power dissipation per air-conditioning field = Total (Power dissipation x Simultaneity factor) + Total (Busbars)

This calculated value is compared with the values of the [project properties](Glossary_o_projekteigenschaften.htm) Thermal design: Total power dissipation for air-conditioning field [1] to Thermal design: Total power dissipation for air-conditioning field [100].

If the currently calculated value does not agree with the values stored in the project [properties](Glossary_o_eigenschaften.htm), the check run message is issued.

In addition the check run message is issued when a total power dissipation is issued for a air-conditioning field that does not exist / no longer exists in the project properties.

### Solution

1. Note the number of the air-conditioning field that was output in the message.
2. Select the menu item Utilities > Reports > Calculate total power dissipation.
3. Activate the Display all the air-conditioning fields existing in the project check box in the Calculate power dissipation dialog.
4. Activate the corresponding check box of the reported air-conditioning field and start the calculation with [OK].
5. Also check in the project properties whether an air-conditioning field is entered that does not exist / no longer exists at the enclosure and delete this entry.
6. Then start a new check run.

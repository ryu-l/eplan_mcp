# Defined devices: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_geraete.htm)

### Defined devices

User interface / operation

A defined device is defined by one (or more) parts. The part provides the defined device with the data for its functions. Ultimately, a defined device is then a pre-defined collection of functions (with particular pre-defined fixed (identifying) properties and freely definable properties).

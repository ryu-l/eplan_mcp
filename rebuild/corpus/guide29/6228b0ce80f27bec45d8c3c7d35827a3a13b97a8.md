# Defining the Cursor Display

The cursor can either be shown as a crosshair or as "small cross". You define this in the [User settings](gedviewer_d_einstellungenbenutzerallgemein.htm#Fadenkreuzdarstellung). In the "small cross" [form](Glossary_o_verlauf.htm), two short [lines](Glossary_o_leitungen.htm), at an angle of 45° to each other, are displayed. Regardless of the cursor display [settings](Glossary_o_einstellungen.htm), the form of the cursor always represents the currently active action.

1. Select the following menu [items](Glossary_o_bauteile.htm): Options > Settings > User > Graphical editing > 2D
2. In the Display field, you define whether the cursor is displayed as crosshairs or as a "small cross".
3. The Display crosshairs when placing macros and symbols check box allows you to define the type of cursor displayed when [placing](Glossary_o_auflegen.htm) [symbols](Glossary_o_symbole.htm) and [macros](Glossary_o_makros.htm) â regardless of the setting above.
4. Click [OK].

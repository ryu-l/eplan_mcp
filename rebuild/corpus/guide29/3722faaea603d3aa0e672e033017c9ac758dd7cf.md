# Managing Symbols

Symbols are standardized graphics for representing [functions](Glossary_o_funktionen.htm). The logic for the symbol is stored in the function definition which the symbol refers to.

Symbols are managed in [symbol libraries](Glossary_o_symbolbibliotheken.htm), which can contain any number of [symbols](Glossary_o_symbole.htm). You can use the symbols stored in symbol libraries in different [projects](Glossary_o_projekte.htm) by loading the symbol library into the current project. At the same time, this means that the basic [function definitions](Glossary_o_funktionsdefinitionen.htm), i.e. the logical data, are used in all projects in a unified manner.

Standardized symbol libraries contain the most frequently used symbols for the following areas:

- General system electronics
- Mounting panel construction drawings
- Measurement and control technology
- Single-line Representation
- Hydraulics
- Pneumatics
- Electronics
- Process diagrams.

![](../Pictures/Gui/ALL/note.png)Note:

Symbol libraries with special symbols (such as [devices](Glossary_o_betriebsmittel.htm), PLCs, [structure boxes](Glossary_o_strukturkaesten.htm), [shields](Glossary_o_abschirmungen.htm), etc.) can only be edited and extended by EPLAN Software & Service GmbH Co. KG, that is, they are locked for you. When you try to open such a symbol library, a message will appear and the action is canceled.  
When creating a project, these symbol libraries are automatically stored in the project.

Symbols are edited and created in a special editor, the "Symbol editor". This is also where symbol libraries are created and edited. During schematic creation in the graphical editor you can only access symbols and insert them, with the Symbol selection dialog providing a range of different search possibilities.

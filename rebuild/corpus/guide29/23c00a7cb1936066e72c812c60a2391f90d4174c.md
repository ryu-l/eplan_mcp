# P027027: Connection splicer <x> is not located on the routing track of the connection

### Cause

The schematic contains a multi-line connection splicer that also has a corresponding counterpiece in the [topology](Glossary_o_topologie.htm). However, the connection splicer was not found while routing the [connections](Glossary_o_verbindungen.htm) through the routing path network, because a routing point through which the connection splicer was already connected to the routing track was deleted.

### Solution

1. Locate the placed connection splicer with the "Topology" representation type using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Reroute the connection so that the connection passes a routing point to which the connection splicer is connected.  
     
   Or connect the connection splicer to a routing point that lies on the routing track.
3. Start a new check run after you have changed the device tags in order to delete the message.
4. Route the connections through the routing path network again.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

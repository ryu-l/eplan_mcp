# Tab Data (Settings: External Editing)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Utilities > Edit properties externally > Export data. Click [...] next to the Settings field in the Edit externally dialog. Select the Data tab.

- Options > Settings > User > Interfaces > External editing. Select the Data tab.

On this tab, you can specify the data to be considered during external editing.

Overview of the main dialog elements:

Category:

From this drop-down list, select the type of [properties](Glossary_o_eigenschaften.htm) to be displayed in the list.

Filter:

Into this field enter the text for which the properties are to be filtered.

If you want to [return](Glossary_o_zurueckbuchen.htm) to the original view of the properties, remove the search term from the entry field. Click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) to do so.

Available format elements:

Depending on the category selected, the possible [format elements](Glossary_o_formatelemente.htm) are displayed in the list.

To export a format element you have to move it to the list of selected format elements on the right. Multiple selections are not possible.

Selected format elements:

In this list, the selected format elements are shown in tabular [form](Glossary_o_verlauf.htm) with their [designations](Glossary_o_bezeichnungen.htm) and the information "Changeable" = "Yes" / "No". Using the buttons above the list, you can delete format elements or change their order.

| Button | Meaning |
| --- | --- |
| (Delete) | Deletes the selected format element. |
| (Move up) /  (Move down) | Moves an entry up / down in the list. |

# Tab Comment

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project that contains imported PDF [comments](Glossary_o_kommentare.htm).

- Page > Navigator. Select a page and then select the menu item Page > Open. Double-click a comment on the page.
- Page > Comments navigator. Select a comment. Popup menu > Go to (graphic). Double-click a comment on the page or select the comment, and then select Popup menu > Properties.

This tab shows the [properties](Glossary_o_eigenschaften.htm) of the current comment, e.g., the comment text and status.

The following dialog elements are available:

Author:

Shows the Windows logon name of the person who originally created the PDF comment.

Creation date:

Shows when the PDF comment was created by the author.

Modification date:

Shows when the PDF comment was last changed by the author.

Comment text:

Shows the comment text that the author entered into the comment field of the PDF file.

Status:

Shows the comment status that the author assigned to the comment field of the PDF file via Options > Status. You can change this status.

Reply:

Shows the comment responses that the author entered into one or more response fields of the comment field in the PDF file via Options > Reply.

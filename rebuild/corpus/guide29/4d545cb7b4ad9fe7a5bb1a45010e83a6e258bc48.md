# Tooltips for Icons in the Navigators

If you position the cursor on an icon in the tree views of the [project data](Glossary_o_projektdaten.htm) [navigators](Glossary_o_navigatoren.htm), a short information text (tooltip) about this icon is then displayed. If [icons](Glossary_o_icons.htm) are combined (for example ![](../Pictures/Gui/ALL/navigatorgui_mainfunctionpart_as.png)![](../Pictures/Gui/ALL/navigatorgui_function_as.png) for a placed multi-line main function), a separate tooltip is displayed for each icon. No additional information is displayed for icons in other tree views (for example in the project management, in the [part](Glossary_o_artikel.htm) [master data](Glossary_o_stammdaten.htm) navigator, etc.).

![](../Pictures/Gui/ALL/benefit.png)Benefit:

The [tooltips](Glossary_o_quickinfos.htm) allow you to understand the meaning of the icons in the project data navigators faster.

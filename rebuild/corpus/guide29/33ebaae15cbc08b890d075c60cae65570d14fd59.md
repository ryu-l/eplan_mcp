# P032001: Drilling pattern could not (or not completely) be created. <x>

### Cause

Several causes are possible. These are output in the placeholder <x> of the message:

- No drilling pattern name available.
- Block not broken up.
- Outline not closed.
- No cut-out identified.

### Solution

Depending on the respective cause the following solutions are possible:

1. First locate the drilling pattern frame in the project using the Go to (graphic) function from the popup menu in the Message management dialog.  
     
   - Enter a name in the dialog Properties <...> of the drilling pattern frame.  
     
   - Or break up the block into individual elements.  
     
   - Or close the outline.  
     
   - Or check the layer allocation of the [objects](Glossary_o_objekte.htm) belonging to the drilling pattern frame.
2. Subsequently start any check run in order to delete the module-specific message.
3. Create the drilling pattern again by using the menu [items](Glossary_o_bauteile.htm) Utilities > Generate [drilling patterns](Glossary_o_bohrbilder.htm) / [outlines](Glossary_o_konturen.htm) > Automatically from macro project.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

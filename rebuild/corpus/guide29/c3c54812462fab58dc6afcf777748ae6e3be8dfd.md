# P007019: Over-allocation of a protected main function or main terminal

### Cause

You have added an additional function to a protected main function or main terminal that you have placed as a [part](Glossary_o_artikel.htm) with defined [function templates](Glossary_o_funktionsschablonen.htm) (device), or you have changed a property of a function of the part. The part does not make this additional function available or does not use the retrospective change to a property of the part.

### Solution

#### Possibility 1

1. Select a part with suitable function templates for the protected main function or main terminal.
2. Then start a new check run.

#### Possibility 2

1. In the schematic, delete the function that was added to the part retrospectively, or undo the change to the function for the part.
2. Then start a new check run.

#### Possibility 3

Extend the function template [settings](Glossary_o_einstellungen.htm) for the selected part in the parts management. Proceed as follows:

1. Select the menu [items](Glossary_o_bauteile.htm) Utilities > Parts > Management.
2. Select the function or terminal in the tree or the list in the Parts management dialog.
3. Bring the Function templates tab to the front.
4. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) above the Device selection (function templates)table.  
     
    ![](../Pictures/Gui/ALL/arrow.png) A new row is added.
5. Click in the cell in the first column and then click [...].
6. In the Function definitions dialog select the function you want, to extend the part.
7. Click [OK], and apply the changed setting to parts management.
8. Then place the device in the schematic again and start a new check run.

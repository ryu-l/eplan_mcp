# Migration of Enclosure Parts

The Migrate part functionality is a conversion aid for Rittal TS8-based [projects](Glossary_o_projekte.htm) to migrate existing individual parts from the Rittal baying system TS8 to the Rittal baying system VX25.

![](../Pictures/Gui/ALL/note.png)Note:

Please read the EPLAN [Disclaimer of Liability Declaration](license_k_start.htm#Haftungsausschluss) first before you use the Migrate part functionality.

The following conditions and limits apply:

- The menu [items](Glossary_o_bauteile.htm) Migrate part and Correct enclosure distance are not available in the optionally available EPLAN Pro Panel Add-on.
- A migration is only possible for the Rittal TS8 system.
- All parts must have been placed with a 3D macro.
- Special parts that are not contained in the Rittal catalog and not in the EPLAN Data Portal are not migrated.
- Article placements with automatic and manual protection are not migrated. Therefore every protection has to be removed before migration.
- Enclosures that were created with the RICS Configurator are not migrated, since they are subject to automatic protection.
- Enclosures that were created in external systems and integrated via a STEP import, cannot be migrated.
- The required VX25 replacement parts must be contained in the parts database used. Missing replacement parts are determined and can be exported to a CSV file and obtained via the shopping basket of the EPLAN Data Portal. It is advisable to obtain missing replacement parts only from the EPLAN Data Portal.
- The [Check run 026104](messages_p_026104.htm) determines migratable Rittal TS8 parts which have not been migrated yet.
- The [Check run 026102](messages_p_026102.htm) determines Rittal TS8 parts that cannot be migrated. These are discontinued parts.
- The [Check run 026103](messages_p_026103.htm) determines the [part placements](Glossary_o_artikelplatzierungen.htm) whose mounting surface does not exist in the migrated enclosure. These [objects](Glossary_o_objekte.htm) are displayed in the [layout space](Glossary_o_bauraum.htm) navigator under the hierarchy level "Incorrectly placed". For the correction incorrectly placed [part](Glossary_o_artikel.htm) placements must be placed manually on the existing [mounting surfaces](Glossary_o_montageflaechen.htm).
- All part placements are copied geometrically unchanged onto the mounting surface of the same name into the migrated enclosure from the origin in the same X/Y position.
- You can assign a new 3D macro to Rittal TS8 parts that exist in modified [form](Glossary_o_verlauf.htm) (for example hole with [slotted holes](Glossary_o_langloecher.htm) instead of round holes) by using the menu item Update part placement.
- Part placements for which no mounting surface of the same name is found in the target enclosure are displayed in the layout space navigator under the hierarchy level "Incorrectly placed". At these part placements a manual re-placement is required.

### Automatic migration

Depending on the selection in the layout space navigator, a project, the complete contents of a layout space or an individual enclosure is analyzed and migrated on the part level. The following parts can be automatically migrated:

- Enclosure
- Base
- Doors
- Panels, for example side panels, partitions
- Cover with door
- TS disconnect switch cover
- Roof plate
- Top module.

![](../Pictures/Gui/ALL/note.png)Note:

A peculiarity applies for bases / top [modules](Glossary_o_module.htm): The migration generates a completely closed base with covers.

### Manual migration

Non automatically migratable part placements can be migrated manually, for example:

- Adjoining parts
- Pivoting frames
- Rails
- Chassis
- Partial mounting panel
- Partial doors
- Floor sheet
- Lock system
- Adapter profile
- Wire duct
- Hinge.

### Required check and post-processing after the migration

After the migration an exact check of the results should be carried out. Perform the following updates and checks at the migrated enclosure:

- Checking all part placements for the correct position
- Renumbering DT
- Renumbering legend item
- Updating views ([model views](Glossary_o_modell_ansichten.htm), 2D [drilling views](Glossary_o_bohransichten.htm), copper unfolds)
- Updating [reports](Glossary_o_auswertungen.htm) ([bills of materials](Glossary_o_stuecklisten.htm), enclosure legend)
- Checking and correcting routing path network
- Routing [connections](Glossary_o_verbindungen.htm).

### Correction of the enclosure distance for line ups

Since a VX25 enclosure is 2 mm wider than a TS8 enclosure, an intersection of the migrated VX25 enclosures occurs after the migration of an enclosure line up. The check run P026011 reports this as a collision.

To correct the distance within the line up, select the menu item Edit > Correct enclosure distance.

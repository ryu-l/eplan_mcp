# Tab Busbar system

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have selected a [part](Glossary_o_artikel.htm) in the tree or list, from the Generic product group "Mechanics", Product group "Busbars", Product subgroup "System".

In this tab, you define the specific data for busbar systems, i.e., for parts from the Generic product group "Mechanics", Product group "Busbars", Product subgroup "System". The data can be specified more than once per part, namely once per variant. Busbar systems are used for the secure and rational connection of distributor [devices](Glossary_o_betriebsmittel.htm) such as miniature circuit-breakers, modular installation devices, etc.

Overview of the main dialog elements:

Profile geometry D x H:

Enter the appropriate values here, e.g. "35x12x20x5".

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

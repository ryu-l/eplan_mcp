### Main terminals

Electrical engineering

The main terminal represents a terminal device on a terminal strip. A device can contain any number of main terminals but only one main function. Therefore the terminal strip is defined as a main function and all the terminals as main terminals. If a terminal is defined as a main terminal, then it behaves in a similar manner to a main function. For example, for a main terminal the function templates are displayed in the terminal strip navigator, and a device selection can be performed.

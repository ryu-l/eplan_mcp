# Print attached documents

Attached documents can be separately printed in EPLAN. These are [external documents](Glossary_o_fremddokumente.htm) inserted into schematic pages via hyperlinks or entered into the parts used on the page. In order for [attached documents](Glossary_o_begleitdokumente.htm) to be printed, the files must be located on a local drive or a network drive to which you have access.

Preconditions:

- You have selected a project or pages in the page navigator.
- You have inserted external documents via hyperlinks or have entered them at parts.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project > Print attached documents  
     
   ![](../Pictures/Gui/ALL/arrow.png) All attached documents linked in the project are listed in the Print attached documents dialog. As standard, all documents to be printed are selected in the Print column.
2. In the Print attached documents dialog, in the Print column, deselect the check box for all documents that you do not wish to print.
3. Click [OK].
4. In the Print dialog, in the Printer group box, select the desired printer from the drop-down list.
5. You specify the number of copies to be printed in the Number field.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The [Settings] and [Print preview] buttons and the fields for defining the page range and print order are grayed out, since these [settings](Glossary_o_einstellungen.htm) cannot be made for attached documents.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Printing begins.

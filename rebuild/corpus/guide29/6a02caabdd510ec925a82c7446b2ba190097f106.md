# Using Graphical Macro Selection

Preconditions:

- You have opened a project.
- You have activated the Use graphical macro selection check box (Options > Settings > User > Graphical editing > Macros).

1. Select one of the menu options Insert > Window macro / symbol macro or Page > Page macro > Insert.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Graphical macro selection dialog opens.
2. Select the file path for which the macro directories are to be displayed.
3. Select the Images popup menu item to display the directory images in another size.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The size of the images is adjusted.
4. Select the Filter: <Macro file type> popup menu item to filter for a specific macro type.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The display of the files is adjusted in the File selection area.
5. Click the plus sign in front of a macro name in the File selection area to find out the representation type of the macro and whether there are several [variants](Glossary_o_varianten.htm).
6. Click the required variant of a macro, followed by [OK], to select this macro. Or double-click a macro name to select and insert the first existing macro variant of this macro.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The dialog is closed and the macro is inserted.

![](../Pictures/Gui/ALL/note.png)Note:

In contrast to the usual macro selection, you cannot execute any [functions](Glossary_o_funktionen.htm) in the Graphical macro selection dialog that affect the directories or files. For example, you cannot [create](Glossary_o_erstellen.htm), rename or delete any directories or files in this dialog.

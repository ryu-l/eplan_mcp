# Defining the Project Structure (Changing Standards)

User-defined and pre-defined [schemes](Glossary_o_schemata.htm) for page and device structure are taken from the template that you specified when creating the target project.

Preconditions:

- You have opened a project.
- In the case of several opened [projects](Glossary_o_projekte.htm): You have selected a project in the page navigator.
- You have set up a target project.
- You have defined a template and the rotation / flipping.
- You have replaced the necessary plot frame, [forms](Glossary_o_formulare.htm), [symbol libraries](Glossary_o_symbolbibliotheken.htm), and [symbols](Glossary_o_symbole.htm).

1. Utilities > Change of standard > Project tab > [Next] > Rotation / flipping tab > [Next] > Master data tab > [Next]
2. To change the page structure, select an identifier scheme for the page structure from the Pages drop-down list in the Structure tab.
3. To change separators click [Other] and specify the desired [separator](Glossary_o_trennzeichen.htm) in the Extended project structures dialog.
4. To change the identifier schema for [devices](Glossary_o_betriebsmittel.htm), select an identifier scheme in the corresponding drop-down list.
5. Click [Next].

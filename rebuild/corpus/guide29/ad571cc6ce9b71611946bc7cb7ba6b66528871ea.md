# Action: XEGActionInsertSymRef

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| SymbolLibName | Name of the symbol library that contains the symbol. |
| SymbolId | Number of the symbol to be inserted. |
| VariantId | Number of the variant if the symbol has [variants](Glossary_o_varianten.htm) |
| FctDefTag | Identifier of the function definition to search for the symbol to be inserted |
| Placementmode | Identifier of the representation type to search for the symbol to be inserted. String which defines the representation type of the symbol. Possible values are:   - all: Multi-line - single: Single-line - paircrossreference: Pair cross-reference - overview: Overview - graphics: Graphic - processandinstdiagram: [P&I diagram](Glossary_o_ri_fliessbild.htm) - cabling: Topology - functional: Functional. |
| SymbolType | Identifier of the symbol type to search for the symbol to be inserted |
| CustomSymbols | Name of the project-related setting for loading a customer-specific symbol to be inserted. |

![](../Pictures/Gui/ALL/note.png)Note:

This action requires a [main window](Glossary_o_hauptfenster.htm). If the stated symbol is not found, the Symbol selection dialog will be opened.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
XEGActionInsertSymRef 
/SymbolLibName:IEC_symbol 
/SymbolId:55 
/VariantId:0
```

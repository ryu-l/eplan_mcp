# P028024: The pre-planning assigned to the object has been deleted

### Cause

A segment was deleted in the pre-planning. The [objects](Glossary_o_objekte.htm) that are no longer assigned ([functions](Glossary_o_funktionen.htm), [macros](Glossary_o_makros.htm) or pages, etc.) still exist in the schematic and have to be checked.

### Solution

Locate the objects that are no longer assigned in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.

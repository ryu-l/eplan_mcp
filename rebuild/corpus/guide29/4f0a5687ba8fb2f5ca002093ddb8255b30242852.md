# Display Properties: Spline

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a page, [form](Glossary_o_verlauf.htm), plot frame, or symbol. You have marked a spline and selected the menu [items](Glossary_o_bauteile.htm) Edit > Properties, or you have double-clicked on a spline. In the table of the Properties (Spline) dialog, expand the hierarchy level Spline.

Below this hierarchy level you can edit the spline-specific [settings](Glossary_o_einstellungen.htm).

The following dialog elements are available:

Starting point / End point / Control point 1 / Control point 2:

In the fields below these hierarchy [levels](Glossary_o_etagen.htm), the coordinates of the four characteristic points of the spline are displayed and can be modified.

# Generating Parts Based on Schematic Data

In EPLAN, a [part](Glossary_o_artikel.htm) can be generated from the data stored at a [component](Glossary_o_schaltzeichen.htm). Among other data, the part and device-specific data (function definition, connection point designation, etc.) is transferred to the parts database. A part generated in this way contains [function templates](Glossary_o_funktionsschablonen.htm) for all device [functions](Glossary_o_funktionen.htm) and is stored as a part in the project.

Preconditions:

- You have marked a component that represents a main function.
- Exactly one parts reference is entered in the DT.

1. Select the Generate part popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog opens. The new part is sorted into the product group structure of the parts management module with reference to the function definition for the component, and is preset.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If a part already exists in the project, a query is displayed that you have to confirm to overwrite. If the part does not exist yet in the parts database, the parts management is subsequently opened, and the new part is pre-selected.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If a part already exists in the parts database, a further security prompt is displayed. If you confirm this prompt with [Yes], the device-specific data (such as the function templates) are updated at the parts already existing in the parts database. In this case the parts management is opened and the part is pre-selected. If you click [No], the parts existing in the project are overwritten. However, the part in the parts database is not updated.
2. If necessary, you can edit the data of the new part on the tabs on the right.
3. Click [Close].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Exits the Parts management dialog.   
     
   ![](../Pictures/Gui/ALL/arrow.png) If data that may have been changed is not saved via [Apply] then an additional confirmation prompt is displayed. A message is also displayed allowing you to decide whether an automatic "Parts database -> Project" parts data synchronization should be performed.

![](../Pictures/Gui/ALL/note.png)Note:

Parts generated in this way are given the value "NEW" under Function group on the Technical data tab. This allows you to specifically filter for such parts.

# Action: XMDeleteReprTypeAction

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| RepresentationType | Representation type to be removed from the selected [macros](Glossary_o_makros.htm). The following values are permitted:   - 0 = Neutral - 1 = Multi-line - 2 = Single-line - 3 = Pair cross-reference - 4 = Overview - 5 = Graphic - 6 = Panel layout - 7 = [P&I diagram](Glossary_o_ri_fliessbild.htm) - 8 = Multi-line Fluid - 9 = Topology - 10 = 3D mounting layout - 11 = Functional. |
| Source | Specifies the files to be modified. You must enter a file name with or without complete file path. When entering the file name extension, you can also use placeholders. |
| Destination | Target directory |

![](../Pictures/Gui/ALL/note.png)Note:

If when calling the action only the RepresentationType parameter is specified, first a dialog for selecting macros will open, followed by a dialog where you can select the target directory for the macros to be saved.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
XMDeleteReprTypeAction 
/RepresentationType:0 
/Source:C:\macros\*.ema 
/Destination:C:\dest
```

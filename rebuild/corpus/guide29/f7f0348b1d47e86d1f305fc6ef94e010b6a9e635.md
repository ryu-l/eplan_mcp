# Dialog Log on to EPLAN

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You are using the "Logon" operating mode. Start EPLAN.

In this dialog you logon using your user name and password. The Logon dialog is automatically displayed when EPLAN starts.

Overview of the main dialog elements:

Name:

Enter the user name here.

Password:

Enter your password here. To ensure protection of your input, the password is not displayed in plain text but rather as \* characters.

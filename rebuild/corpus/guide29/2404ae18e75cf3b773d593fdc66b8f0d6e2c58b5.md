# EPLAN Fluid: Special Features when Working with Macros in Mixed Projects

Macros can be used to store any schematic sections for further use and thus accelerate the schematic planning notably.

In mixed [projects](Glossary_o_projekte.htm) it is often necessary to document the documentation of machines or plants containing both [fluid power](Glossary_o_fluidtechnik.htm) and electrical engineering schematic pages. Macros can also be used in interdisciplinary project planning. Even when [macros](Glossary_o_makros.htm) are first created it is possible to manage sections of both schematic types with the same macro file. (This is only possible with window and [symbol macros](Glossary_o_symbolmakros.htm).)

A precondition is that the Representation type property of the macros differs. Within the macro file, the section from the fluid schematic must therefore be saved with the "Multi-line Fluid" representation type and the section from the electrical engineering schematic must be saved with the "Multi-line" representation type.

When inserting window or symbol macros into a schematic page, the program automatically recognizes the page type for the correct placement of the respective section from the representation type.

This also applies to the placement of parts via "Drag & Drop" from the device list or from the bill of materials navigator, that have been assigned a macro file with sections from both disciplines.

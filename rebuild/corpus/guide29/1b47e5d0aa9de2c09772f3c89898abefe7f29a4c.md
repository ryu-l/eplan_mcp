# Action: EsCorrectConnections

This action combines the graphical [properties](Glossary_o_eigenschaften.htm) (color, line type, etc.) of [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) into one potential definition point per signal if these graphical properties are identical for the entire signal.

![](../Pictures/Gui/ALL/note.png)Note:

The combination of connection definition points can be useful, for example, after an EPLAN 5 data import that has created many connection definition points with identical graphical properties. The generated [potential definition points](Glossary_o_potenzialdefinitionspunkte.htm) are automatically incremented and receive the signal names "correction-1", "correction-2", etc. "Empty" connection definition points are deleted.

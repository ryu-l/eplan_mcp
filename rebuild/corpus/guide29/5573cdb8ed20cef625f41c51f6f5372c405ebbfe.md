# Dialog Settings: Edit in table

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have highlighted [functions](Glossary_o_funktionen.htm) or a schematic section in the graphical editor. Edit > In table. In the Functions or Connections tab, click [...] next to the Scheme field.
- You have highlighted functions or [connections](Glossary_o_verbindungen.htm) in one of the [navigators](Glossary_o_navigatoren.htm). Popup menu > Edit in table. In the Functions or Connections tab, click [...] next to the Scheme field.

In this dialog, you can specify which columns will be displayed for editing in tables of functions or connections.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

![](../Pictures/Gui/ALL/note.png)Note:

The [schemes](Glossary_o_schemata.htm) are saved by user. If, for instance, an electrical engineer and a fluid engineer are working together on a project, each of them can use specific [settings](Glossary_o_einstellungen.htm) for editing in tables. To include a scheme together with the project, you must export the scheme and pass it on separately.

Distribute DT into columns:

If this check box is checked, the device tag is subdivided in a group of columns. The columns are specified in the Column headers field.

If the check box is not checked, the standard subdivision of the DT is used, that is, "partial DT1, partial DT2, prefix, identifier, counter, subcounter".

Column headers:

In this field, you can specify the number of columns for the DT subdivision and their headings. By default, five columns are shown with the headings "Section 1" through "Section 5". You can rename them, delete them, or add more columns.

If the Distribute DT into columns check box is activated, these columns are shown in the Edit in table - <Project name> dialog. The DTs are analyzed and the components distributed between columns.

![](../Pictures/Gui/ALL/example.png) [![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You specify three columns with the headings "Circuit number", "Component code", and "Item number". A DT "1V2" is then subdivided as follows:

| Circuit number | Component code | Item number |
| --- | --- | --- |
| 1 | V | 2 |

Column configuration:

In this field, you can specify which columns are shown in the table in the Edit in table - <Project name> dialog. Check the corresponding check boxes. Use the arrow buttons to change the order of the columns.

The DT subdivision check box cannot be deactivated, since the table columns dependent on the DT subdivision are changeable.

Popup menu:

A popup menu is available in the Column headers and Column configuration fields:

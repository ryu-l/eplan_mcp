# Backing up Master Data

In EPLAN, you can backup not only complete [projects](Glossary_o_projekte.htm), but also individual [master data](Glossary_o_stammdaten.htm) from the central master data pool. This includes [basic projects](Glossary_o_basisprojekte.htm), [project templates](Glossary_o_projektvorlagen.htm), [symbol libraries](Glossary_o_symbolbibliotheken.htm), [plot frames](Glossary_o_normblaetter.htm), [outlines](Glossary_o_konturen.htm), [forms](Glossary_o_formulare.htm), [macros](Glossary_o_makros.htm), [part](Glossary_o_artikel.htm) information, [dictionaries](Glossary_o_woerterbuecher.htm) and project-independent [settings](Glossary_o_einstellungen.htm).

In contrast to [project data](Glossary_o_projektdaten.htm), individual master data cannot be filed off or archived. This means that a copy of the master data is always created and the original master data remains on the hard drive and can be further edited. Only when filing off or archiving of complete projects are the associated master data filed off or archived.

Data in subdirectories are included in the backup if the Back up subdirectories check box is selected.

Graphics in plot frames or forms are only backed up when they are stored in the plot frame or [form](Glossary_o_verlauf.htm). Referenced graphics cannot be saved and restored.

As in all list views, you can sort the master data displayed here in ascending or descending order by clicking the column headers.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project > Back up > "Master data"
2. You define the settings for the master data to be backed up in the dialog [Back up <Master data>](bakbackupmdatadlggui_d_stammdatensichern.htm) dialog.
3. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected master data is backed up to the specified directory or e-mailed, according to the entries you have made.

### Placeholder texts

User interface / operation

Placeholder text can be compared with special text, but is used in forms to define the position and formatting of the appropriate properties. During the evaluation of the form, they are automatically replaced with the corresponding values of project objects on which the report is being run, such as devices, pages, symbols, etc.

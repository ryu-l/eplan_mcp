# User Interface Elements

When started, EPLAN begins with a pre-configured user interface. You can adapt this standard view to suit your personal working habits. Many dialogs, such as the page navigator dialog, which you often use for editing data, can be permanently positioned on your screen while working with EPLAN and undocked from the EPLAN [main window](Glossary_o_hauptfenster.htm) in the same way as independent windows.

You can position any of these "Windows" (in an undocked state), and every other dialog, by pulling the title bar of the dialog to the desired position while holding down the left mouse button.

If you have customized the EPLAN user interface for a special design task, then you can define this configuration (position, size, [settings](Glossary_o_einstellungen.htm) for dockable dialogs and [toolbars](Glossary_o_symbolleisten.htm)) as a workspace and re-select it at any time.

You can control EPLAN using both the mouse and the keyboard. You can use the predefined shortcut keys when working with the keyboard, or customize these to suit your requirements.

The standard user interface contains the following elements:

Title bar

The uppermost line of a Windows application is the title bar. It contains the system menu, information about the program scope, the name of the current project including file path, information as to whether the project has been opened with write-protection, the name of the currently open page / open symbol, etc., as well as buttons for controlling the window size.

The name of the currently open page is displayed in square brackets in the title bar (e.g. [=EB3+ET1/1]). If there is no page open in the graphical editor, no page name will be displayed.

If you have opened a page in the graphical editor and you then select a page of a different project in the page navigator, the project name of the second project is displayed in addition to the page name of the open page. This is because EPLAN always tries to display the current project in the title bar.

Menu bar

The menu bar is located below the title bar. It contains the most important commands and dialog calls.

Toolbars

The toolbars are located below the menu bar and consist of buttons allowing you to directly call up the most important [functions](Glossary_o_funktionen.htm) in the program. All toolbars, and their appearance, are freely configurable and you can also [create](Glossary_o_erstellen.htm) [user-defined](Glossary_o_benutzerdefiniert.htm) toolbars.

Status Bar

The status bar is located at the lower edge of the window. When you point the mouse at a menu item, or a button in a toolbar, then brief informative text relating to the function called by this command is displayed here. Otherwise, the status bar displays the information on [grid](Glossary_o_raster.htm) and logic status.

Window Size Adjustment

The ability to modify the size of the EPLAN main window (and also other dialogs) is indicated by three diagonal [lines](Glossary_o_leitungen.htm) in the lower right-hand corner of the window.

You can change the window size by positioning the cursor in the frame at the edge of the window, and then pulling the window frame left / right or up / down while holding down the left mouse button.

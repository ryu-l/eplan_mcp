# Dialog Workspace / Settings: Workspace

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- View > Workspace.
- Options > Settings > User > Display > Workspace.

In this dialog you manage and edit the [schemes](Glossary_o_schemata.htm) for [workspaces](Glossary_o_arbeitsbereiche.htm). This type of scheme saves an interface configuration which has been configured to personal [settings](Glossary_o_einstellungen.htm) or tasks.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

The ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit) button is also available in this toolbar. This button opens the Edit workspace dialog where you can save the current workspace if the interface has been changed, or update it with the contents of another workspace.

![](../Pictures/Gui/ALL/note.png)Note:

When you delete a current user-defined workspace using ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete), EPLAN switches to the "Default" workspace.

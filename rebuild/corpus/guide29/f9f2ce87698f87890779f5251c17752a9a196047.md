# Routing Connections

Routing generates [routing connections](Glossary_o_verlegeverbindungen.htm) between the 3D [part placements](Glossary_o_artikelplatzierungen.htm) that follow the real course of the [wires](Glossary_o_draehte.htm) and cables in the routing path network. If there are no [connection points](Glossary_o_anschluesse.htm) defined for a [part](Glossary_o_artikel.htm) placement, they will be generated prior to the routing.

Apart from the routing track, the length of wires is also determined. All information thus determined can be used as [wiring](Glossary_o_verdrahtungen.htm) instructions or to control [wire fabrication](Glossary_o_drahtkonfektionierung.htm) machines.

Precondition:

You have opened a project. A [layout space](Glossary_o_bauraum.htm) is open. The routing path network is generated.

1. Select the menu [items](Glossary_o_bauteile.htm) Project data > Connections > Route (layout space).  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the status bar, you are prompted to select the [connections](Glossary_o_verbindungen.htm) to be routed.
2. Enter the two corner points of a rectangle that comprises the part placements and connections to be routed.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The most efficient routing track is calculated. The routing connections are displayed in 3D representation.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The routing connections are assigned the [properties](Glossary_o_eigenschaften.htm) Length, Routing track, Routing track specification, Connection dimension, Routing direction, Wire termination processing, and Dual sleeve prescribed.

# Tab Further properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have installed the hose line configurator as an add-on variant of EPLAN Fluid. You have started EPLAN Fluid and the hose line configurator.

- Select the menu [items](Glossary_o_bauteile.htm) Options > Settings > User > Add-ons > Hose line configurator in EPLAN Fluid and click in the Further properties tab in the subsequent dialog.
- Or select the menu items Extras > Settings in the Configure hose lines dialog of the hose line configurator and click in the Further properties tab in the subsequent dialog.

Or you have installed the hose line configurator as a stand-alone variant and started the program.

- Select the menu items Options > Settings > User > Add-ons > Hose line configurator in the hose line configurator and click in the Further properties tab in the subsequent dialog.

In this tab you can specify up to 200 additional [properties](Glossary_o_eigenschaften.htm) and assign a specific value to each property. You can use these properties to extend the [type code](Glossary_o_typencode.htm) required for ordering [hose lines](Glossary_o_schlauchleitungen.htm) and thus adapt them individually to the order specifications of different manufacturers. The properties are defined as so-called "free properties" meaning that you can define their names and values freely.

For example some manufacturers offer hose [lines](Glossary_o_leitungen.htm) with a tubing protection. In the order information you then have to carry out specifications for the tubing protection, such as the tubing protection type and the tubing protection length, in addition to the type code to DIN 20066.

![](../Pictures/Gui/ALL/note.png)Note:

The free properties defined in this tab cannot be implemented in the type code until you have also correspondingly extended the format of the type code in the General tab.

Overview of the main dialog elements:

Property (list):

You define the free properties in this list.

Use the buttons of the toolbar above the list to [create](Glossary_o_erstellen.htm) new entries, edit existing ones and / or delete entries no longer required.

Table:

You can assign a value to the respective property in this table.

Use the buttons of the toolbar above the table to create new entries and / or delete entries no longer required.

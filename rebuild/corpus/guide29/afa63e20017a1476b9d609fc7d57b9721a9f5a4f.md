# Using Existing Cables, Cable Connections, and Shields

The use of existing cables and [cable connections](Glossary_o_kabelverbindungen.htm) is carried out via DT selection. In this case, the respective [functions](Glossary_o_funktionen.htm) must match or the DT selection is not possible. It is thus only possible to [use existing](Glossary_o_abbuchen.htm) [cable definition lines](Glossary_o_kabeldefinitionslinien.htm) on [cable](Glossary_o_kabel.htm) definition [lines](Glossary_o_leitungen.htm), and only [connections](Glossary_o_verbindungen.htm) on connections.

The "Cable" value must be assigned to the Connection: Association property at [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) or connections. In this case, the DT selection dialog is opened for the use of existing cables, otherwise the Use existing connections dialog is opened.

### Use existing cables or shields

When manually defining cables you can select an existing DT, [generate](Glossary_o_erzeugen.htm) a new DT, or generate a new cable definition for an existing DT. If you use an existing unplaced cable definition line, then it will be deleted from the list and all data for this function is transferred to the cable definition line in the schematic.

If you select a shield connection (the connection to which the shield is assigned, not the cable definition of the shield), then the shield DT and designation are adopted. The shield connection can be placed or unplaced. It is not deleted because the actual connection is not used here.

1. Select a cable definition line, a shield, or a connection definition point in the graphical editor.
2. Select the menu item Edit > Properties.
3. In the Properties <...> dialog, select the Cable or Shield tab.
4. Or select the Connection definition point tab and select the "Cable" value from the drop-down list for the Connection: Association property.
5. Click [...] next to the Displayed DT field.
6. From the DT selection dialog, select one of the cable DTs existing in the project. or - depending on the selection - [create](Glossary_o_erstellen.htm) a new DT using [Next].
7. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The DT is adopted in the Properties <...> dialog, and the connection is assigned to the cable.

![](../Pictures/Gui/ALL/note.png)Note:

The following behavior applies when generating a new DT using [Next]:

- If a DT is selected, a new DT is generated with the next available counter.
- If a cable definition is selected, another cable definition is generated for the same DT.
- If a cable connection is selected, another cable definition is generated for the same DT.

### Use existing cable connections

1. Select a connection definition point in the graphical editor.
2. Select the menu item Edit > Properties.
3. In the Properties <...> dialog select the Connection definition point tab and select the "Cable" value from the drop-down list for the Connection: Association property.
4. Click [...] next to the Displayed DT field.
5. Select a connection in the DT selection dialog.
6. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The DT is adopted in the Properties <...> dialog, and the connection is assigned to the cable.

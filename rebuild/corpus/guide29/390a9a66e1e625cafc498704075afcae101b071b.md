# Tab Display (model view)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project.You have opened a project page in the graphical editor. You have inserted a model view (Insert > Graphic > Model view (<...>)) and placed it. In the Model view dialog, select the Display tab.
- You have opened a project.You have opened a project page in the graphical editor. You have double-clicked a model view. In the Model view dialog, select the Display tab.

This tab is used to define the display [settings](Glossary_o_einstellungen.htm) for the Labeling field of the model view. Individually placed [properties](Glossary_o_eigenschaften.htm) can be docked with each other and made into a single block; when moving, this allows all the (desired) text to be moved at once and avoids overlapping of multi-line text with other text.

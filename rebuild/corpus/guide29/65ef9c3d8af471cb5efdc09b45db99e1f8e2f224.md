# Tooltips with Project Values during Data Import

If differences between the values in the data source and the values in the project occur during the import of pre-planning, device, connection and wire harness data, these fields have a dark-gray background in the respective synchronization dialog (for example Synchronize pre-planning data). In order to recognize the difference between the data source and the project more easily, the current property values in the project are now displayed for such fields in the Tooltips.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

Through the display of the deviating project values in the Tooltip you do not have to scroll back and forth to compare such values in the divided synchronization dialogs. Displaying columns for the project to be able to see and compare the project values is no longer required.

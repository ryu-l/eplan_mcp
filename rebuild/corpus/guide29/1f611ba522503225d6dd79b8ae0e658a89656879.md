# Tab Settings (General Wires Parts List)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Wire fabrication > General wires parts list > Settings
- Utilities > Manufacturing data > Wire fabrication > General wires parts list. Click [...] next to the Scheme field. Select the Settings tab.

In this tab, information on the technical options of the machine to be used is stored. The individual [settings](Glossary_o_einstellungen.htm) are pre-set with appropriate values in a machine-specific manner, and can be modified here.

Overview of the main dialog elements:

Wire length minimum:

Minimum length the machine requires to handle the wire as defined (default value: 1mm). Shorter [wires](Glossary_o_draehte.htm) are transferred to the machine with this minimum length.

Wire length maximum:

Wires that are longer than specified here cannot be processed by the machine (default value: 150,000 mm).

Conductor cross-section maximum:

Maximum cross-section of a wire that the machine can still process (default value: 50 mm²).

Number of wires per bundle maximum:

Number of wires that the machine can combine into a [bundle](Glossary_o_buendel.htm) (default value: 10,000).

Total conductor cross-section maximum:

Limit value for the sum total of cross-sections of all wires (default value: 10,000 mm²).

Continuous text from wire length:

Length from which wires are to be printed with endless text. If no value is entered, all wires will be printed with endless text.

Routing direction up / down / left / right:

Texts that are to be printed on the wire to indicate individual [routing directions](Glossary_o_verlegerichtungen.htm).

Do not convert connection cross-section into mm²:

During the manufacturing data export General wires parts list [connections](Glossary_o_verbindungen.htm) whose cross-sections have the unit "AWG" are to be exported with he actual value, for example "18AWG". Activate this setting to prevent the AWG value from being converted automatically into mm².

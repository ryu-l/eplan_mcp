# Using the Orthogonal Function

The orthogonal function enables movement of the cursor in only the horizontal or vertical direction. In the process, the cursor assumes a special [form](Glossary_o_verlauf.htm), known as the Orthogonal cursor. The functionality can be used when all insertion points are to be oriented either horizontally or vertically to each other upon symbol insertion.

Precondition:

You have opened a page, form, plot frame or symbol.

1. Press [Shift] + [<] to activate the orthogonal function.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The cursor can only be moved in the horizontal and vertical directions. The cursor assumes the form of four arrows, indicating the set mode.
2. Press [<] to deactivate the orthogonal function.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The cursor can be moved again in all directions.

### Activate the orthogonal function for the horizontal or vertical direction only

1. Press [<], to activate the orthogonal function in a horizontal direction.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The cursor can only be moved in the horizontal direction. The cursor assumes the form of two arrows, indicating the direction setting.
2. Press [<], a second time to activate the orthogonal function in a vertical direction.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The cursor can only be moved in the vertical direction. The cursor assumes the form of two arrows, indicating the direction setting.
3. Press [<] once more to deactivate the orthogonal function.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The cursor can be moved again in all directions.

The cursor can assume the following shapes:

| Cursor | Meaning |
|  | Movement possible in the horizontal and vertical directions. |
|  | Movement only possible in the horizontal direction. |
|  | Movement only possible in the vertical direction. |

![](../Pictures/Gui/ALL/info.png)Tip:

While drawing graphical elements, once you have defined the starting point, you can also call the orthogonal function with the [X] or [Y] keys. Use [<] to deactivate the orthogonal function.

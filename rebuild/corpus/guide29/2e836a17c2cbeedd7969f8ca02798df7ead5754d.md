# Dialog Configure representation (tree)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project and are in the tree view of specific [navigators](Glossary_o_navigatoren.htm). Select the Configure representation popup menu item.

In this dialog you can define the display and sort order of the data so that only the information relevant to you is displayed.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Configuration:

The Object column lists those [objects](Glossary_o_objekte.htm) ([projects](Glossary_o_projekte.htm), pages, [devices](Glossary_o_betriebsmittel.htm), [functions](Glossary_o_funktionen.htm), [structure identifiers](Glossary_o_strukturkennzeichen.htm), etc.) that can be displayed in the respective tree.

The Block format column displays whether a formatting exists for an object. The formatting is used to specify the [properties](Glossary_o_eigenschaften.htm) that are displayed for an object. [â¦] can be used to select further [format elements](Glossary_o_formatelemente.htm) (properties, separators) and to determine their sequence.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

![](../Pictures/Gui/ALL/note.png)Note:

Certain properties are always displayed. For example, the Project name property is displayed in the tree view even if no format is specified for the Block format column.

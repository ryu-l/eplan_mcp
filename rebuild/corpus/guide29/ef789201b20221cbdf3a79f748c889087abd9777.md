# Converting Surplus Main Functions

Devices that contain multiple [main functions](Glossary_o_hauptfunktionen.htm) may be created during project planning. In order to achieve a logically correct project, a device can only contain one main function. Use the correction run to convert all surplus main [functions](Glossary_o_funktionen.htm) in the entire project to [auxiliary functions](Glossary_o_nebenfunktionen.htm). When doing this you can decide whether the single-line, multi-line, or overview functions should be kept as main functions.

Surplus [main terminals](Glossary_o_hauptklemmen.htm) are also corrected in the process. If the same terminal occurs in different [representation types](Glossary_o_darstellungsarten.htm), only one may be the main terminal. The surplus main terminals are converted into auxiliary terminals.

Preconditions:

You have opened a project.

1. Select the following menu [items](Glossary_o_bauteile.htm): Utilities > Synchronize > Functions > Correct main functions
2. In the Main function with priority group box of the Correct main functions dialog, select the desired representation type. To keep, e.g., all multi-line main functions, select the Multi-line option.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) All surplus main functions are converted into auxiliary functions.

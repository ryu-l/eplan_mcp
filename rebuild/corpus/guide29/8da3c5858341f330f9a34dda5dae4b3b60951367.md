# P024003: Electrical function with a fluid character is not present as a pair cross-reference representation

### Cause

This message is displayed if an electrical function with a [fluid power](Glossary_o_fluidtechnik.htm) character does not have the representation type "Pair cross-reference". For example, a solenoid was inserted on a fluid power schematic page as the operating element of a valve and the automatically assigned representation type "Pair cross-reference" was changed manually.

The electrical [functions](Glossary_o_funktionen.htm) with a fluid character which are covered by the check include all electrical functions in the "valves" function category and all electrical functions in the "analog sensors" function category that are assigned the physical dimensions "pressure", "flow", "level" and "temperature".

### Solution

In the Representation type field assign the "pair cross-reference" entry to the function. The representation type can be set in the Symbol / function data tab of the Properties <...> dialog.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

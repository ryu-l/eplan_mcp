# Dialog Settings: General (projects, management)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Options > Settings > Projects > "Project name" > Management > General.

In this dialog you specify the general [master data](Glossary_o_stammdaten.htm)-specific [settings](Glossary_o_einstellungen.htm).

Overview of the main dialog elements:

Synchronize project master data when opening:

Select this check box if the master data used in the project should be synchronized with the master data pool as soon as the project is opened, saved, or restored.

Symbol libraries and [forms](Glossary_o_formulare.htm), however, are only synchronized when the Synchronize check box is also selected for the individual [symbol libraries](Glossary_o_symbolbibliotheken.htm) and forms. You define the symbol libraries and forms to be synchronized in the following areas:

- Symbol libraries: Dialog Settings: Symbol libraries (Options > Settings > Projects > "Project name" > Management > Symbol libraries)
- Forms: Dialog Settings: Output to pages (Options > Settings > Projects > "Project name" > Reports > Output to pages)

If the check box is deactivated, the master data is not synchronized when the project is opened, even if the Synchronize check box is selected for the individual symbol libraries and forms.

Synchronize plot frames:

If this check box is selected, the [plot frames](Glossary_o_normblaetter.htm) used in the project are synchronized with the master data pool as soon as the respective project is opened, saved, or restored. A precondition is that the Synchronize project master data when opening check box is selected.

Synchronize stored parts when opening:

If this check box is selected, the parts used in the project are synchronized with the parts in the parts database when the project is opened. If the project parts are obsolete, a prompt opens.

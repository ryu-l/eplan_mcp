# P004040: Contradictory specifications at the associated bus port were found for the bus port at '<x>'

### Cause

Network / bus [cable](Glossary_o_kabel.htm) [connection points](Glossary_o_anschluesse.htm) of the type "Network / bus cable connection point, general" are considered as belonging together and are automatically connected to each through an internal connection if they have the same DT, belong to the same bus system and have the same bus interface name.

In the concrete case contradictory specifications were determined at one of the internally interconnected [bus ports](Glossary_o_sps_busanschluesse.htm), because one or more values of the [properties](Glossary_o_eigenschaften.htm) listed below differ:

- Physical network: Name
- Logical network: Name
- Logical network: Bus port is master
- Physical network: Bus [ID](Glossary_o_id.htm) / item number
- Physical network: Bus ID / item number 2
- DNS/PROFINET device name
- Data transfer rate
- Integrated module
- MasterSystemID
- Subnet mask
- Subslot
- Marked for deletion.

The full DT of the respective bus port is output in the placeholder <x> of the message.

### Solution

1. Locate the bus ports in the schematic by using the functionalities Go to graphic and Go to 2nd coordinate, which the popup menu of the Message management dialog offers you.
2. Call up the [property dialog](Glossary_o_eigenschaftendialog.htm) of the bus ports respectively and compare the entered properties in the tab Bus data in accordance with the above list.
3. Enter clear and unique values at the respective properties.
4. Click [OK].
5. Start a new check run.

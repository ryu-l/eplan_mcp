# P028016: Segment is subordinated to a '<x>' segment definition that is not permitted

### Cause

A segment has been subordinated to an invalid segment definition <x> to which it must not be subordinated.

### Solution

1. Locate the segment definition in the pre-planning navigator using the Synchronize selection function offered by the popup menu in the Message management dialog.
2. Select another segment definition for the segment, or adjust the segment definition.
3. Then start a new check run.

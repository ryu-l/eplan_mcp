# Inserting New Devices Without a DT

New [devices](Glossary_o_betriebsmittel.htm) / [functions](Glossary_o_funktionen.htm) can be placed in the schematic during the Insert > Symbol procedure without automatic DT assignment . In this case, the entries for the displayed and full DT remain empty.

Precondition:

You have opened a project.

1. Options > Settings > Projects > "Project name" > Devices > Numbering (online)
2. Under On symbol insertion, select the Empty field option.
3. Click [OK].

### Insert a device / function via a symbol without DT

1. Select the menu item Insert > Symbol.
2. Select a symbol in the Symbol selection dialog and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol hangs on the cursor.
3. Move the cursor to the desired location on the schematic page.
4. Click the page to place the symbol.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The dialog Properties (components): <...> dialog opens. There is no DT entry in the Displayed DT field.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol is placed without DT.

### Create a device / function without placement and without DT

1. Select the menu item Project data > Devices > Navigator.
2. Select the Tree tab.
3. Select the project level.
4. Select Popup menu > New.
5. In the Function definitions dialog, under Selection, select a function definition and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The dialog Properties (components): <...> dialog opens. There is no DT entry in the Displayed DT field.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The device / function is sorted into the tree structure level without DT.

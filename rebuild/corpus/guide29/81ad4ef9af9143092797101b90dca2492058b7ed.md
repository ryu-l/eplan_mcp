# 2D Panel Layout

The program allows you to design panel layouts and [mounting panels](Glossary_o_montageplatten.htm), as well as simply creating schematics with the associated charts and lists. Mounting panels can only be created on project pages of type "Panel layout".

Graphical [objects](Glossary_o_objekte.htm) or "Composite [macros](Glossary_o_makros.htm)" are used to symbolize the [items](Glossary_o_bauteile.htm) on a mounting panel. You must store the composite macros in the [part](Glossary_o_artikel.htm) management [master data](Glossary_o_stammdaten.htm).

In addition to mounting panels, you can also [create](Glossary_o_erstellen.htm) item legends that can be bound to the project in a number of different ways.

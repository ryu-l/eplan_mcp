# Master Data: Forms

This section provides information about the most important modifications for the [forms](Glossary_o_formulare.htm).

A new [form](Glossary_o_verlauf.htm) has been created for the device connection diagram:

- F05\_004.f05 (file type "Device connection diagram"; for [embedded reports](Glossary_o_eingebetteteauswertungen.htm))

With the following forms for the Terminal diagram [placeholder texts](Glossary_o_platzhaltertexte.htm) in the header and data area were updated:

- F13\_008.f13
- F13\_008\_en\_US.f13

Outdated placeholders with the designation "via form position" were replaced with the designation "external" or "internal" (for example, "[cable](Glossary_o_kabel.htm) chart header via form position [A] / DT (full)" with "Cable chart header external / DT (full)").

Two forms for outputting the revision overview have been corrected.

- F17\_002.f17
- F17\_002\_en\_US.f17

The Regenerate header after change property has been added to the form [properties](Glossary_o_eigenschaften.htm) of these forms and a specific value assigned. When the Revision name (change tracking) [1] property is changed, a new header is generated during reporting. In addition, the placeholder text "Page / Revision name ([change tracking](Glossary_o_aenderungsverfolgung.htm)) [1]" has been replaced by the placeholder text "Project /revision name (change tracking) [1]" in the forms.

With the following forms for the Piping overview, the alignment boxes in the column headers were optimized:

- F37\_003.f37 (file type "[P&I diagram](Glossary_o_ri_fliessbild.htm): Piping overview")
- F37\_003\_en\_US.f37

This means that languages with longer words also do not exceed column borders anymore.

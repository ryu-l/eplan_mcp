# Dialog Settings: General (workstation, display)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > Workstation > Display > General.

When using EPLAN via terminal server or remote desktop, specify the [settings](Glossary_o_einstellungen.htm) for the terminal server in this dialog. This speeds up the update of the view if interface changes have been made.

Overview of the main dialog elements:

Optimize terminal server:

If this check box is activated, the background bitmap is no longer represented when EPLAN is started. In addition, the [tooltips](Glossary_o_quickinfos.htm) at [symbols](Glossary_o_symbole.htm) are also not displayed in the graphical editor.

![](../Pictures/Gui/ALL/note.png)Note:

Note that your settings for showing or hiding the background bitmap will not be activated until you restart the program.

Group box graphical editor

If you have selected the check box Optimize terminal server, you can specify additional optimization settings in this group box.

Bitmap caching:

If this check box is selected, the bitmap files are cached. The image display will be calmer but the update of the view will take longer.

If the check box is deactivated (default setting), the character mode is optimized for the terminal server so that the transfer quantity between terminal and server is as small as possible. This can lead to a flickering display though.

Hide mouse pointer:

If this check box is activated, the mouse pointer in the graphical editor is hidden.

# EPLAN Fluid: Device Structure

In EPLAN, "device structure" means the combination of all device identifier structures used in the project.

In EPLAN Fluid , the term "fluid device" covers the following device types:

- General fluid devices (e.g., valves, [filters](Glossary_o_filter.htm), cylinders, etc.)
- Fluid connection splicer and line connector.

The identifier structures for both types of [devices](Glossary_o_betriebsmittel.htm) can be defined independently of each other.

In EPLAN Fluid the following preceding signs and [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) are available, and allow you to [create](Glossary_o_erstellen.htm) standard-conformant, hierarchically structured device tags:

| Preceding sign | Identifier block |
| --- | --- |
| == | Functional assignment |
| = | Higher-level function |
| ++ | Installation site |
| + | Mounting location |
|  | Higher-level function number |
| # | User-defined structure |
| - | Device (consists of the identifier components "Prefix", "Identifier", "Counter", "Separator" and "Subcounter") |

These identifier [blocks](Glossary_o_bloecke.htm) allow numerous structuring possibilities in EPLAN Fluid. For example, you can structure the DTs standard-compliant to [EN 81436](projectstructure_k_referenzkennzeichnung.htm) or also to DIN ISO 1219-2.

### Device tags conformant to fluid power standard DIN ISO 1219-2

DIN ISO 1219-2 stipulates the following [ID](Glossary_o_id.htm) code for [fluid power](Glossary_o_fluidtechnik.htm) [items](Glossary_o_bauteile.htm):

- Plant designation
- - ([separator](Glossary_o_trennzeichen.htm))
- Media code
- Circuit number
- . (separator)
- Item number

Instead of the Plant designation identification specified by the standard, the program makes the identification block Higher-level function number available. Since EPLAN Fluid does not have any special identifier blocks for the structure elements required by the standard, namely "Media code", Circuit number" and "Item number", these components of the ID code can be created by using the project setting Fluid power: Use trade identifier as identifier (media code). This setting can be accessed under Options > Settings > Projects > "Project name" > Devices > DT.

The identifier components required in accordance with DIN ISO 1219-2, namely "Media code", Circuit number" and "Item number" are assigned automatically in EPLAN Fluid to the components of the "Device" identifier block, i.e. the "normal" DT components (see following table).

| Structure elements according to DIN ISO 1219-2 | Identifier components in EPLAN Fluid |
| --- | --- |
| Plant designation | Corresponds to the Higher-level function number identifier block . The [higher-level function number](Glossary_o_anlagennummer.htm) is entered without a prefix. |
| - | Separator (fixed pre-defined) |
| Media code | Corresponds to the Trade identifier. Is assigned to the DT [part](Glossary_o_artikel.htm) Identifier. |
| Circuit number | Is assigned to the DT part Counter. |
| . | Separator (fixed pre-defined) |
| Item number | Consecutive number. Is assigned to the DT part Subcounter. |

The assignment of the structure elements can be seen in the table structure of the Full DT dialog. To do this, call up the Properties <...> dialog for a fluid device identified according to DIN ISO 1219-2, and click [...] next to the Full DT field.

![](../Pictures/Gui/ALL/note.png) Notes:

- In accordance with DIN ISO 1219-2 the plant designation (in EPLAN the "Higher-level function number") can be omitted if the fluid circuit consists of only one [higher-level function](Glossary_o_anlage.htm).
- In addition, the media code (in EPLAN the "Trade identifier") can also be omitted in accordance with this standard if only one medium is used in the higher-level function. This requirement is met in EPLAN Fluid by means of the project setting Fluid power: Hide identifier (media code) in the graphics (menu items Options > Settings > Projects > "Project name" > Device > DT). To this purpose the check box has to be deactivated. However, the trade identifier is only no longer displayed graphically in the displayed DT of a fluid function, it remains in the visible and complete DT of the [property dialog](Glossary_o_eigenschaftendialog.htm) with this setting.

![](../Pictures/Gui/ALL/info.png)Tip:

EPLAN Fluid supports you in planning according to the standard DIN ISO 1219-2. To this purpose the project template FL\_1219-2\_tpl001.ept is available after the installation of the program. If you use this template, the correct [settings](Glossary_o_einstellungen.htm) for standard-compliant device identification are offered automatically for fluid devices as well as for fluid [connection splicers](Glossary_o_leitungsverteiler.htm) and [line connectors](Glossary_o_leitungsverbinder.htm).

# Inserting PLC Cards and Connection Points

You can insert [PLC cards](Glossary_o_sps_karten.htm) and [connection points](Glossary_o_anschluesse.htm) on schematic pages and also on pages of type "Overview". Synchronization occurs between the overview pages and the schematic pages. All of the PLC connection point data can be entered in both the overview and in the schematic.

![](../Pictures/Gui/ALL/info.png)Tip:

If you already know during project planning which PLC parts are to be used, you can insert the PLC cards and connection points directly as a device (menu [items](Glossary_o_bauteile.htm): Insert > Device). This way you can place the individual I/O [connections](Glossary_o_verbindungen.htm), card [power supplies](Glossary_o_anschlussversorgungen.htm), [bus ports](Glossary_o_sps_busanschluesse.htm), etc. comfortably one after another. The function definition and, at bus ports, additionally the plug designation, is displayed as a placement aid. You can use the [N] key to "browse" through the [functions](Glossary_o_funktionen.htm).

### PLC card overview

A PLC card is represented in the schematic by one or more [PLC boxes](Glossary_o_sps_kaesten.htm). To insert a PLC box, proceed as follows:

1. Select the menu item Insert > Box / connection point / mounting panel > PLC box.
2. Draw the PLC box as a rectangle.
3. In the Properties <...> dialog enter the device data of the PLC card.

![](../Pictures/Gui/ALL/info.png)Tip:

PLC boxes can also be drawn as [polylines](Glossary_o_polylinien.htm) with the help of the PLCC2 symbol. To do so, select the symbol in the Symbol selection and specify the starting point of the box by clicking the left mouse button inside the schematic. After you have specified all of the other points, complete the task via the Popup menu > Complete polyline.

### Insert PLC connection points

You normally place [PLC connection points](Glossary_o_sps_anschluesse.htm) inside the associated PLC box. It is however possible to place PLC connection points outside a PLC box.

1. Select the menu item Insert > Box / connection point / mounting panel > PLC connection point <...>.
2. Place the PLC connection point in the PLC box.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The PLC connection point adopts the DT of the PLC box. A number of additional [properties](Glossary_o_eigenschaften.htm) are also displayed, but these are not editable.
3. In the Properties <...> dialog, enter the connection point data of the PLC connection point.

![](../Pictures/Gui/ALL/note.png)Note:

Before inserting or copying PLC connection points, make sure that the PLC-specific [settings](Glossary_o_einstellungen.htm) are correct. Otherwise, wrongly formatted addresses may be suggested by the program when performing automatic addressing.

If you work in [multi-user operation](Glossary_o_multiuser_betrieb.htm), we recommend disabling automatic addressing of [PLC addresses](Glossary_o_sps_adressen.htm).

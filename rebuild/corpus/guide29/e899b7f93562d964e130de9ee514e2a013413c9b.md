# Tab Rotation / flipping (Changing Standards)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. In the case of several opened [projects](Glossary_o_projekte.htm): You have selected a project in the page navigator. Utilities > Change of standard. You have specified all of the [settings](Glossary_o_einstellungen.htm) in the Project tab. [Next].

Overview of the main dialog elements:

Template:

This field contains the template to be used for the target project. Use [...] to select a project template \*.ept.

If you have activated the Apply project properties from the source project check box on the Project tab, the [project properties](Glossary_o_projekteigenschaften.htm) are not taken from this template but rather from the source project.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).

Rotation / flipping:

Select the manner of rotation and flipping from this drop-down list.

- 0°: The schematic elements are not rotated.
- 90°: Rotates graphical elements like [lines](Glossary_o_leitungen.htm), texts, hyperlinks counter-clockwise by 90°. Sets the insertion point of [symbols](Glossary_o_symbole.htm) counter-clockwise by 90°. You can specify the rotation / flipping of symbols using the [variants](Glossary_o_varianten.htm) selected in the Symbols tab in the assignment diagram. For special symbols, a suitable symbol library is automatically preset in the Master data tab. The Individual assignment check box is automatically selected. In the Symbols tab, the Special IEC NFPA IEC scheme is automatically available. Use this setting to switch from IEC standard to [NFPA standard](Glossary_o_nfpa_norm.htm).
- 270°: Rotates graphical elements like lines, texts, hyperlinks counter-clockwise by 270° or clockwise by 90°. Moves the insertion point of symbols counter-clockwise 270° or clockwise 90°. You can specify the rotation / flipping of symbols using the variants selected in the Symbols tab in the assignment diagram. For special symbols, a suitable symbol library is automatically preset in the Master data tab. The Individual assignment check box is automatically selected. In the Symbols tab, the Special IEC NFPA IEC scheme is automatically available. Use this setting to switch from NFPA standard to IEC standard.

# Page Filter

In the page navigator, you can define a filter for displaying the pages. This is especially useful in larger [projects](Glossary_o_projekte.htm) for limiting the number of displayed pages to those being currently edited. A filter can be useful in the following situations, among others:

- Displaying pages in the page navigator
    
  As soon as you have set a filter, only the selected pages are displayed in the page navigator. If all pages are filtered out for an individual tree node (e.g. "[higher-level function](Glossary_o_anlage.htm)"), then the tree node is also not displayed, even in the tree.
- Changing pages 
    
  You can filter pages when you would like to edit only specific pages in a project. During graphical editing you can then use [Page up] / [Page down] to switch between the pages selected in this way, without having to page through the intermediate pages.
- Editing [properties](Glossary_o_eigenschaften.htm)
    
  It is also possible to edit the properties of several selected pages, and to assign a single plot frame to all schematic pages, for example.
- Print
    
  A filter allows you to print only specific pages (such as all pages of the "Overview" page type), or to prevent these pages from being printed.
- Exporting
    
  It is also possible to export only specific pages, or to exclude these pages from being exported.

![](../Pictures/Gui/ALL/info.png)Tip:

When you print / export pages, if you only want to output the current pages of an active page filter, select the Selection option from the Print dialog, and do not select the Apply to entire project check box in the export dialogs.

A page filter is a field-based filter that you, as is usual in EPLAN, specify in the Filter dialog and save in a scheme. As filter criteria you can use different page properties and / or properties and [function definitions](Glossary_o_funktionsdefinitionen.htm) of [functions](Glossary_o_funktionen.htm) that are placed on pages. This means that you have the following options:

- Using a search results list for the page filter   
  The pages contained in the search results list can be taken into consideration when pages are filtered by using the Contains results in the search results list ([ID](Glossary_o_id.htm) 11045) property.
- Using properties and function definitions of functions for the page filter   
  The pages can be filtered via the functions placed on them by using the Function on page filter criteria. Properties for the [structure identifiers](Glossary_o_strukturkennzeichen.htm), the Representation type, the Trade or the Function definition are available as criteria here. As the result of such a page filter only those pages are then displayed on which the functions are placed whose property values or function definitions match the set criteria.

Filter for functions on pages: Function definition

You have opened the project ESS\_Sample\_Project. In the Filter dialog you [create](Glossary_o_erstellen.htm) a scheme for PE terminals and select the entry "Function on page: Function definition" in the criteria selection to this purpose. In the table with the filter criteria specify the following:

| Active | Negated | Criterion | Operator | Value |
| --- | --- | --- | --- | --- |
|  |  | Function on page / Function definition | = | PE terminal with rail contact, 2 [connection points](Glossary_o_anschluesse.htm) |

Close the Filter dialog with [OK]. This way the filter scheme is saved and the set filter is automatically activated. In the page navigator only schematic pages are shown in which PE terminals with the function definition specified above occur. In this example these are for example pages like "=GB1+A1&EFS1/1", "=GD1+A2&EFS1/1" etc.

Filter for functions on pages: Structure identifier

You have opened the project ESS\_Sample\_Project. In the Filter dialog you create a scheme. To do so, select the Mounting location property in the criteria selection in the hierarchy level "Function on page". In the table with the filter criteria specify the following:

| Active | Negated | Criterion | Operator | Value |
| --- | --- | --- | --- | --- |
|  |  | Function on page / Mounting location | = | B4 |

Close the Filter dialog with [OK]. This way the filter scheme is saved and the set filter is automatically activated. The page navigator only shows pages in which functions with the specified structure identifier occur. In this example this is the page "=VN01&PFB/1" with the description "Paint workpiece" on which "Analog sensors" are placed as the functions with the [mounting location](Glossary_o_einbauort.htm) "B4".

![](../Pictures/Gui/ALL/note.png)Note:

The page property Contains results in the search results list as well as the criteria for the functions on pages are available to you only for the criteria selection of the page filter.

The filter is simultaneously activated for all open projects via the selection of the filter scheme in the page navigator. It is therefore possible that when the filter is changed all the pages of a project are hidden completely from the page navigator because no page matches the filter criteria. If pages are generated for the selected filter, these will be displayed if they match the filter criteria. It makes no difference whether the pages are created using the New, Copy, [DXF](Glossary_o_dxf.htm) / [DWG](Glossary_o_dwg.htm) import commands, or via the API. If there is no filter in the project, all the pages will be displayed.

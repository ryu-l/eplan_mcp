# Identifier Blocks for Pages and Devices

For the definition of [project structure](Glossary_o_projektstruktur.htm) by EPLAN, the following [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) are used for the hierarchy of pages and [objects](Glossary_o_objekte.htm) included in the schematic:

| Identifier block | Preceding signs |
| --- | --- |
| Functional assignment | == or # or â |
| Higher-level function | = |
| Installation site | ++ |
| Mounting location | + |
| Document type | & or space |
| User-defined | Arbitrary |

All identifier [blocks](Glossary_o_bloecke.htm) named are available for page numbering and, with the exception of the identifier block "Document type", for the device numbering. The identifier blocks to be used for the project hierarchy are determined when creating a project.

All identifier blocks can be combined arbitrarily. Except for the identifier block "Document type" and the free hierarchy, there are no dependencies or exclusion criteria between the [settings](Glossary_o_einstellungen.htm) for the page [formats](Glossary_o_formate.htm) and the settings for [devices](Glossary_o_betriebsmittel.htm).

Identifier blocks must not necessarily be filled with [structure identifiers](Glossary_o_strukturkennzeichen.htm), even if they are specified in the [project properties](Glossary_o_projekteigenschaften.htm). This means that empty structure identifiers which are then listed in the [structure identifier management](Glossary_o_strukturkennzeichen_verwaltung.htm) can occur. In addition, global changes (find, replace, sort, etc.) can conveniently be performed on structure identifiers.

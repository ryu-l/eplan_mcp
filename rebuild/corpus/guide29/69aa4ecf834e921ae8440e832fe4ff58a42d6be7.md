# Working with Nested Structure Boxes

If the Structure box check box is selected in the Nesting group box of the Inheritance tab in the Extended project structures dialog, then [structure boxes](Glossary_o_strukturkaesten.htm) can be nested. In this case, the display (the entry) of the point is omitted in the innermost identifier in the schematic.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

![](../Pictures/Visualisation/ALL/dinkasten_schachteln_av.png)

If you have the multiply nested structure boxes =A2+O2, =A3+O3, and =A4+O4, and have activated the Structure box check box (left [part](Glossary_o_artikel.htm) of the illustration), then the fuse receives the DT =A2.A3.A4+O2.O3.O4-F3; if the Structure box check box is deactivated (right side), then the fuse is called =A4+O4-F3.

When this setting is changed, all components located in structure boxes must therefore be edited.

The view is always from outside inwards, i.e., in the outermost structure box the missing parts are taken from the page. A box located within this box then completes its missing parts from the box outside it, and so on. Finally, the components fill in their missing parts from the innermost box. That means that missing or incomplete identifiers in the Displayed DT entry are completed from the superordinate unit, where a superordinate unit can be a page, a structure box, or a black box.

Precondition:

You have opened a project.

1. In the tree view of the page navigator, select the Project > Properties popup menu item.
2. Please select the Structure tab in the Project properties dialog.
3. Click [Other].
4. In the Extended project structures dialog, select the Structure boxes check box in the Nesting group box of the Inheritance tab.
5. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project structures will be changed and the device tags will be adapted.
6. Switch to a schematic page.
7. Insert multiple nested structure boxes.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Full DT field displays the nesting for each interior black box using the nested device tags.

![](../Pictures/Gui/ALL/note.png)Note:

In the case of nested structure boxes, identifiers in the displayed DT of the structure box will always be interpreted as [sub-identifiers](Glossary_o_unterkennzeichen.htm), regardless of whether the [separator](Glossary_o_trennzeichen.htm) for sub-identifiers (period) was entered or not.

![](../Pictures/Gui/ALL/info.png)Tip:

If you hold down the [Shift] key while moving an element from the box, the original nested DT will be maintained.

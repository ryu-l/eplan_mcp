# Polylines: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_polylinien.htm)

### Polylines

User interface / operation

A "polyline" is a connected sequence of line segments. If the starting and end points of the polyline are connected with each other, we call it a polygon. A polyline is created and treated as a single object in EPLAN.

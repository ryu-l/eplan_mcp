# Calculating the Total Power Dissipation of Switch Gears

To ensure correct calculation of the total power dissipation, the components involved have to be prepared by setting specific [properties](Glossary_o_eigenschaften.htm):

- The general conditions have to be defined as properties of the project and at the enclosure.
- The parts data are to be defined as properties per device and / or busbar. Suitable values are to be taken from the data sheets supplied by the manufacturer.

Preconditions:

- You have opened a project.
- The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open.

1. Enter the values for the following properties in the properties of the project.

| Property name | Example value |
| --- | --- |
| Thermal design: Voltage | 230 V |
| Thermal design: Frequency | 50 Hz |
| Thermal design: Simultaneity factor | 0.75 |

2. Enter the values for the general conditions of the power dissipation calculation in the properties of the enclosures (= air-conditioning fields to be calculated).

| Property name | Example value |
| --- | --- |
| Thermal design: Air-conditioning field | 1 |
| Thermal design: Max. external temperature | 50° |
| Thermal design: Max. internal temperature | 65° |
| Thermal design: Min. external temperature | 0° |
| Thermal design: Min. internal temperature | 0° |
| Thermal design: Installation situation | Single housing free-standing |

3. Enter a value for the power dissipation in the parts data on the Properties tab of each device [part](Glossary_o_artikel.htm) for devices.
4. If you want to specify a value deviating from the global project property Thermal design: Simultaneity factor for devices, enter a value for the property [Thermal design: Simultaneity factor (device)](cabinetgui_k_verlustleistungprinzip.htm#Gleichzeitigkeitsfaktor) in the properties of the [part placements](Glossary_o_artikelplatzierungen.htm).
5. Enter the values for the following part properties in the parts data of each busbar part on the Properties tab for busbars. Some values are filled out automatically by the program depending on the selected material.

| Property name | Example value |
| --- | --- |
| Delivery length | 900 mm |
| Rail cross-section | 40 mm² |
| Rail material | Copper Cu-ETP CW004A |
| Conductivity (at +20 °C) | 57 MS/m (= MegaSiemens per meter) |
| Temperature coefficient | 0.004 1/K |

6. Enter a value for the property Thermal design: Operating current, for example "800 A", at Current-carrying busbars at the part placement.
7. In the layout space navigator, select a layout space whose total power dissipation is to be calculated.
8. Select the menu item Utilities > Reports > Calculate total power dissipation.
9. Select the air-conditioning fields to be reported in the dialog Calculate power dissipation.
10. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The total power dissipation is calculated on the basis of the entered values and entered in the Thermal design: Total power dissipation for air-conditioning field [n] property project.

![](../Pictures/Gui/ALL/note.png)Note:

Carry out all the entries for the power dissipation in the following [form](Glossary_o_verlauf.htm): Value and unit in Watt, for example "10 W".

The specification of the unit is mandatory. The usage of blanks is possible, for example "10 W".

# Dialog Settings: Shortcut keys

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > User > Management > Shortcut keys.

In this dialog, you can edit and [create](Glossary_o_erstellen.htm) key combinations to control certain menu commands.

Overview of the main dialog elements:

Select command:

This list contains all menu commands. Select the desired ones.

Description:

This field displays a short description of the selected menu command.

Assigned shortcut keys:

The shortcut assigned to the selected menu command is displayed here (if available). Multiple shortcuts can be assigned to one menu command.

[Create]:

This button opens the Create shortcut key dialog. You can enter your own shortcut for the menu command there.

[Remove]:

Use this button to delete the shortcut selected in the Assigned shortcut keys field.

[Reset all]:

Use this button to delete all [user-defined](Glossary_o_benutzerdefiniert.htm) shortcuts. The default configuration is reassigned.

### Dialog Create shortcut key

Options > Settings > User > Management > Shortcut keys. Click [Create].

In this dialog, you can define your own shortcuts in order to more quickly access certain program [functions](Glossary_o_funktionen.htm).

New shortcut keys:

Enter the desired shortcut here. The [Alt], [Ctrl], etc., keys are entered by simply pressing that particular key.

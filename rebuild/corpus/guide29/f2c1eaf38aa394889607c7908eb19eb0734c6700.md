# Dialog Form properties - <Form name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Utilities > Master data > Form > New > [Save].
- Utilities > Master data > Form > Open. Select the Properties popup menu item on the [form](Glossary_o_verlauf.htm) in the Pages -<Project name> navigator dialog.

In this dialog, you specify the [properties](Glossary_o_eigenschaften.htm) for the newly created or the opened form.

Overview of the main dialog elements:

Form type:

Select the desired form type from the drop-down list (such as "Terminal connection diagram", "Table of contents", "Order list", etc.).  
This property defines the type of form. Each form type is assigned a particular [ID](Glossary_o_id.htm). This ID is used internally to [generate](Glossary_o_erzeugen.htm) the list of properties available ([placeholder texts](Glossary_o_platzhaltertexte.htm)) that can be used during the editing of the form. Thus each form has a specific list of available fields. The form type ID is also used to generate the list of [forms](Glossary_o_formulare.htm) which are available in the Reports dialog for a particular document. For instance, if you want to generate a device tag list, only the forms present which are designated as device tag list forms are offered for selection.

Property name / Value:

The available properties are displayed depending on the selected category. Some of them, for example Company code and Modification date have already been assigned values that can't be changed. Others, such as the Description and Version properties, can be assigned values or their existing values can be changed.

![](../Pictures/Gui/ALL/note.png)Note:

Usually all form properties are available, but these should be selected depending on the Form handling property. For example, dynamic form properties (such as the Adapt row height dynamically property) are meaningless for [static forms](Glossary_o_statischeformulare.htm).

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# Display Properties: Line

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a page, [form](Glossary_o_verlauf.htm), plot frame, or symbol. You have marked a line and selected the menu [items](Glossary_o_bauteile.htm) Edit > Properties or you have double-clicked on a line. In the table of the Properties (Line) dialog expand the hierarchy level Line.
- You have opened a project and are viewing a page in the graphical editor. You have inserted a [cable](Glossary_o_kabel.htm) definition line or double-clicked on a cable definition line. In the Properties <...> dialog select the Format tab and, in the table, expand the Line hierarchy level.

Below this hierarchy level you can edit the [settings](Glossary_o_einstellungen.htm) specific to [lines](Glossary_o_leitungen.htm) and [cable definition lines](Glossary_o_kabeldefinitionslinien.htm).

Overview of the main dialog elements:

Starting point / End point:

The fields below these hierarchy [levels](Glossary_o_etagen.htm) display the coordinates of the starting and end points of the line and let you determine whether the line has arrows on its ends or not.

Angle:

The line will be drawn at this angle to the X axis.

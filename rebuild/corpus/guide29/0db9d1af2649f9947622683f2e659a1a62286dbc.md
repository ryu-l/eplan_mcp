# Dialog Select configuration project

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Project data > PLC > Import data. You have selected an AutomationML format from the Format of import file field and then clicked [OK].

In this dialog you specify the configuration project into which the PLC data are to be imported from an import file in AutomationML format. The dialog is displayed when the configuration project entered in the import file does not exist in the EPLAN project.

Overview of the main dialog elements:

Configuration project:

The configuration project from the import file and the [configuration projects](Glossary_o_konfigurationsprojekte.htm) available in the project are displayed in the drop-down list. Select the configuration project into which the PLC data are to be imported.  
If you retain the configuration project from the import file, a new configuration project is created in the EPLAN project and the PLC data are imported into it.

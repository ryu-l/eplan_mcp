# Placing Functions of Devices

It is also possible to place [functions](Glossary_o_funktionen.htm) / [devices](Glossary_o_betriebsmittel.htm) in the graphical editor from those [navigators](Glossary_o_navigatoren.htm) that display functions. In the process the function's representation type is determined automatically depending on the page type of the opened page. If necessary, you can, however, specify a representation type deviating from it during placement. When you are [placing](Glossary_o_auflegen.htm), the first suitable symbol from the symbol library is used, or the symbol that you have allocated to the function.

The following section describes the placement of functions / [function templates](Glossary_o_funktionsschablonen.htm) in the multi-line schematic.

Preconditions:

- You have opened a navigator that displays functions, for example Project data > Cables > Navigator or Project data > Terminal strips > Navigator.
- You have opened a project page in the graphical editor.

1. Mark one or more functions / function templates that are not placed multi-line in the navigator. In the simplest case you mark a device node in the tree view.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The system tries to first place those functions / function templates of this device that are not placed multi-line.
2. Select the Place popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The macro assigned to the [part](Glossary_o_artikel.htm) or the individual function is attached to the cursor.
3. If you want to use a different representation type or a different macro or symbol, press the [Backspace] key before the actual placing.
     
     
   ![](../Pictures/Gui/ALL/arrow.png) The [Place device](egedgui_d_platzieren.htm) dialog is opened.
4. Specify the insertion options in this dialog. If, for example, a macro is defined at the part, you have to select the option Individual functions.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Depending on the selected option a subsequent dialog is opened. If you have for example selected the option Macro selection, the Select macro dialog is opened.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The assigned or selected macro / symbol hangs on the cursor.
6. Place the macro / symbol in the schematic.
7. Place the additional functions of the selection, or cancel the process via the menu [items](Glossary_o_bauteile.htm) Edit > Cancel action.

![](../Pictures/Gui/ALL/info.png)Tips:

- Press the [N] button in order to page through the functions and select the desired one. Or use the [Spacebar] while placing the [auxiliary functions](Glossary_o_nebenfunktionen.htm) if you want to interrupt the placement of the auxiliary functions and want to start again with the placement of the main function.  
  When inserting a macro, [Shift] + [Tab] is used to browse through the [representation types](Glossary_o_darstellungsarten.htm). Use [Tab] to browse through the macro [variants](Glossary_o_varianten.htm) of a representation type.
- You can also insert devices using drag and drop, by dragging a selected device from the navigators onto your opened page in the graphical editor. The behavior is identical with the steps described above.

### Deleting a placement

Precondition:

- You are in a schematic project.
- You have opened a page in the graphical editor, or you have opened a [project data](Glossary_o_projektdaten.htm) navigator (e.g., the device navigator).

1. Select a [component](Glossary_o_schaltzeichen.htm) in the graphical editor or a placed function in the navigator, and select the menu items Edit > Delete placement.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The graphical representation of the function in the schematic will be deleted. The function is retained as an unplaced function with the original representation type and can, for instance, be placed again from the device navigator.

![](../Pictures/Gui/ALL/note.png)Note:

For functions with the following representation types the placement can not be deleted:

- External
- Graphic
- Panel layout, detailed [panel layout](Glossary_o_schaltschrankaufbau.htm) (these are representation types for [part placements](Glossary_o_artikelplatzierungen.htm) for the 2D panel layout).

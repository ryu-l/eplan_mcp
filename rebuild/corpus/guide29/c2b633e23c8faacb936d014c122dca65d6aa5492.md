# Dialog Settings: Bundle

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have created [routing connections](Glossary_o_verlegeverbindungen.htm). Routing [connections](Glossary_o_verbindungen.htm) are highlighted in the connections navigator. Select the menu [items](Glossary_o_bauteile.htm) Project data > Connections > Bundle. In the dialog Bundle routing connections click the [...] button in a line under Bundling scheme in the table.

In this dialog you define the detailed [settings](Glossary_o_einstellungen.htm) for the selected bundling scheme.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Filter:

Select a scheme for filtering the routing connections from the drop-down list. When the [...] button is clicked, the dialog Filter is displayed in which you can [create](Glossary_o_erstellen.htm) new filtering [schemes](Glossary_o_schemata.htm) and edit existing [filters](Glossary_o_filter.htm).

Sorting:

Select a scheme with bundling criteria for sorting the routing connections from the drop-down list. When the [...] button is clicked, the dialog Sorting is displayed in which you can create new sorting schemes and edit existing schemes.

New bundle if property value has changed:

Select a scheme with bundling criteria whose change is to result in new [bundles](Glossary_o_straenge.htm) being created from the drop-down list. When the [...] button is clicked, the dialog New bundle if property value has changed is displayed in which you can create new schemes with bundling criteria and edit existing schemes.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Go to default | Returns all settings of the selected area back to their default values. |

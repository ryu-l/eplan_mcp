# Connection Definition Point Placement

The [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) placed automatically by [connection numbering](Glossary_o_verbindungsnummerierung.htm) are usually placed on a section of the connection in a centered manner. Exception: If the connection definition points are placed at the start and end of a connection, they are placed near the source or target function.

No connection definition points are placed on sections through which several [connections](Glossary_o_verbindungen.htm) pass. The connections still have a designation. (You can manually place a connection definition point on a section with multiple connections and display a connection designation there.)

The sequence in which the sections of a connection are passed through for the purpose of [placing](Glossary_o_auflegen.htm) the connection definition points is taken from the reporting direction of the plot frame and is independent of source and target.

### Display of the connection designation

In the [property dialog](Glossary_o_eigenschaftendialog.htm) of a connection definition point, you can use the Valid data property to specify whether the connection definition point can carry a connection designation or not, and whether other [properties](Glossary_o_eigenschaften.htm) may be entered there as well.

Automatically placed connection definition points are set up to where they can only contain one connection designation (and no other properties).

Automatically placed connection definition points receive "????" as a designation if the associated connection still has no designation. If the connection already has a designation, then this is displayed at the connection definition point.

The placed property Connection designation is formatted as defined in the Settings: Connection numbering - <Project name> dialog (Display tab).

### Taking into account existing (manually set) connection definition points

If a section already has a connection definition point that can carry a connection designation, no further connection definition point will be placed on this section. This point will be used for connection numbering and has "????" as a designation. If the connection already has a designation, then this is displayed at the connection definition point.

If there is already a connection definition point that cannot carry a connection designation located in the exact position (centered in the section) where a connection definition point is to be placed, the existing definition point will be changed so that it can carry data. This way the connection definition point can be used for a later designation operation. It will also retain all other existing properties. A message will also be written in message management.

![](../Pictures/Gui/ALL/note.png)Note:

If you manually place a connection definition point and assign the Manually set property to it, the Manually set property will be applied for the entire connection. However, the remaining connection properties, i.e., the connection designation, will be assigned to the connection from the graphically first connection definition point.

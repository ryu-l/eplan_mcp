# Placing PCT Loops / PCT Loop Functions

The PCT loop / PCT loop function is automatically assigned a P&I symbol when placed on the [P&I diagram](Glossary_o_ri_fliessbild.htm). It is possible to place a PCT loop / PCT loop function several times, e.g., on different pages. From the pre-planning navigator, you can use the Go to (graphic) popup menu item to jump to the placed PCT loop / PCT loop function.

Preconditions:

- You have opened a project containing pre-planning data.
- You have assigned a PCT type to the PCT loop / PCT loop function.
- You have opened a page of the "P&I diagram" type in the graphical editor.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project > Pre-planning > Navigator
2. Select a PCT loop / PCT loop function.
3. Drag the PCT loop / PCT loop function per Drag & Drop onto the page.
4. Click at the desired position on the page and pull the symbol to the desired size.
5. Click the page to place the symbol.
6. To select a different symbol, press the backspace key before [placing](Glossary_o_auflegen.htm) the symbol and select a different symbol from the Symbol selection dialog.

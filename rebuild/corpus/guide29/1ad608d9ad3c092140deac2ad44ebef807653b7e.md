# Tab Statistics

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Page > Navigator. Select a project. Select the Properties popup menu item. Select the Statistics tab.
- You have selected a project management database. You have loaded directories and [projects](Glossary_o_projekte.htm). Project > Management. Select a project. Select the Statistics tab.

The number of pages of each type of page contained in the project are displayed in this tab.

Overview of the main dialog elements:

Table

Page type:

Displays all [page types](pagebrowsergui_k_seitentypen.htm) available in EPLAN.

Quantity:

Displays the number of pages of one page type in the project.

Last change:

The date on which the number of pages of this page type was changed is displayed here.

Frozen pages:

Shows the number of [frozen report pages](formgeneratorgui_k_eingefrorseiten.htm) for each page type. You can use the page navigator to filter the frozen [report pages](Glossary_o_auswertungsseiten.htm).

---

Created pages:

Shows the number of pages that you have created in the project.

Generated report pages:

Shows the number of pages generated during reporting and contained in the project.

Total no. of pages:

Shows all pages contained in the project.

Number of layout spaces:

Shows the number of layout spaces contained in the project.

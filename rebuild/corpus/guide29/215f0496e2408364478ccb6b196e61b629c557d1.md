# Cable connections: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_kabelverbindungen.htm)

### Cable connections

Electrical engineering

Connection that can be part of a cable. That is, either a conductor or - for hybrid cables - an optical fiber, hose, etc.  
For a connection to be assigned to a cable in EPLAN, this connection must have the "Cable" value assigned to the Connection: Association property.

# P005040: Bundle connection point is not in pairs

### Cause

You only placed a [bundle](Glossary_o_buendel.htm) connection point once in the schematic.

### Solution

Place the bundle connection point twice within a bundle in the schematic so that a bundle connection point pair is shown. Give the bundle [connection points](Glossary_o_anschluesse.htm) the same name.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

# Spare Items: Basics

### Function pool

Every item can have any number of [functions](Glossary_o_funktionen.htm). Devices thus consist of a function pool. A contactor can (e.g.) consist of the functions "coil" and "NO contact"

Components are required in order to place functions. A 1:1 relationship exists between functions and components.

A function pool can be created either using device selection or via "unplaced" functions.

### Terminal pool

Every terminal strip can be assigned any number of terminals.

Terminals that are not drawn are "unplaced" terminals; they can be wired to [create](Glossary_o_erstellen.htm) jumpers or add free [cable connections](Glossary_o_kabelverbindungen.htm), and single [connections](Glossary_o_verbindungen.htm) (pre-[wiring](Glossary_o_verdrahtungen.htm)) can also be added.

The terminal itself can be composed of different functions (multi-level terminal).

### Cable connection pool

Very often, not all [cable](Glossary_o_kabel.htm) connections in a cable are needed in the schematic. Such free cable connections are "unplaced" or "free" cable connections.

Cable connections can be added to placed or unplaced [connection points](Glossary_o_anschluesse.htm). This allows all cable connections of a master cable to be completely added to a terminal strip, without having to draw all cable connections and all terminals.

Unplaced cable connections can be wired in the terminal and cable dialogs, where the following wiring combinations are possible:

| Case | Device 1 | Device 2 | Cable connection |
| --- | --- | --- | --- |
| 1 | Placed connection point | Placed connection point | Placed cable connection or unplaced cable connection |
| 2 | Unplaced connection point | Unplaced connection point | Unplaced cable connection |
| 3 | Placed connection point | Unplaced connection point | Unplaced cable connection |

### Wiring

Unplaced connection points can be joined using unplaced wiring. This allows (e.g.) creation of jumpers on unplaced terminals.

The following wiring combinations are possible:

| Device 1 | Device 2 | Wiring |
| --- | --- | --- |
| Placed connection point | Placed connection point | Placed wiring or unplaced wiring |
| Unplaced connection point | Unplaced connection point | Unplaced wiring |
| Placed connection point | Unplaced connection point | Unplaced wiring |

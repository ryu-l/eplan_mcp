### Base point shift

User interface / operation

The Move base point function allows you to define an optional coordinate base point. The new base point is displayed with a small coordinate cross. In the status bar, the display of the coordinates changes from X / Y to DX / DY (graphical coordinate system) or from RX / RY to DRX / DRY (logical coordinate system), and the values are displayed relative to the new base point.

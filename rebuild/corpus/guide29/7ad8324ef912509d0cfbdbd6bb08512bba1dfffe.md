# Dialog Settings: Export drilling template

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Machining > Export drilling template
- Utilities > Manufacturing data > Machining > Drilling template. Click [...] next to the Machine field.

In this dialog you define the [settings](Glossary_o_einstellungen.htm) for NC export of [drilling templates](Glossary_o_bohrschablonen.htm).

Overview of the main dialog elements:

Machine:

The delivery scope includes the machine definition named "Default". If you have generated a different machine as a scheme, you can select and edit other machine definitions from the drop-down list.

You can [create](Glossary_o_erstellen.htm) new [schemes](Glossary_o_schemata.htm), save any changes to a scheme, and copy or delete schemes via the adjacent [Toolbar](schemeconfig_m_schemaschaltflaechen.htm). Schemes can also be imported or exported.

Description:

In this field is the description you entered for the machine in the Description field of the New scheme dialog.

Tabs:

To configure the export of drilling templates, you can use the following tabs:

- [Tab General](ncgui_r_allgemeinbohrschablone.htm)
- [Tab Labeling](ncgui_r_beschriftungbohrschablone.htm)
- [Tab Drill exceptions](ncgui_r_bohrausnahmen.htm)

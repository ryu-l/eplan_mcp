### Routing path networks

User interface / operation

Layout space:  
A routing path network consists of interconnected routing paths, curves, wiring cut-outs, and routing ranges. Cables and connections are routed in the routing path network.  
  
![](../Pictures/Visualisation/ALL/routing_routingpathnet_as.png)  
  
Topology:  
A routing path network consists of interconnected routing paths, routing points, and topology functions. Cables, tubes, pipes, and connections are routed in the routing path network.

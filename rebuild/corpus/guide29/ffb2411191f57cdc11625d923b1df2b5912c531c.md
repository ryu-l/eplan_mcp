# Preventing a New Placement of a Symbol

If you wish to edit a symbol, you can prevent the symbol from being used while you are doing this. While the symbol is being edited, it can't then be newly inserted into a project or edited by another user. Symbols already inserted into a project can still be used normally.   
Once you have finished editing the symbol you can then unlock it again. Only an unlocked symbol can be edited or inserted by another user.

Precondition:

You have opened a project and at least one symbol library.

1. Select the following menu [items](Glossary_o_bauteile.htm): Utilities > Master data > Symbol > Open
2. If you have not yet opened a symbol library, in the Open symbol library dialog, you first open the symbol library containing the symbol you wish to edit.
3. In the Symbol selection dialog select the symbol(s) you would like to edit.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The preview on the right side of the dialog shows the [symbols](Glossary_o_symbole.htm) that have been selected. For instance, if you have selected a node in the tree view, then all of the elements under it are shown graphically. (For space reasons, the display of the available [variants](Glossary_o_varianten.htm) is omitted in this case.)
4. Change to the List tab.
5. Select the Configure representation popup menu item.
6. In the Configure representation dialog, select the Prevent new placement check box.
7. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected symbols are now locked and can be edited in the [symbol editor](Glossary_o_symboleditor.htm).

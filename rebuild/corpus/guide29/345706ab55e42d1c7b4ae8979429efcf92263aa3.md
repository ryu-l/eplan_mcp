# Extension modules: Definition of Terms

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_erweiterungsmodule.htm)

### Extension modules

User interface / operation

Extension modules are modules which extend the standard scope of delivery of an EPLAN product variant, and must be licensed separately. Such a module cannot be used on its own without an existing product variant. If you have licensed all the extension modules available for an EPLAN product variant, this corresponds to the maximum possible functional scope of this product variant.

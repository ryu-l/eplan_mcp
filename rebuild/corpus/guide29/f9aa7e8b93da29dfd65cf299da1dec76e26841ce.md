# P003009: Differing cable data: <x>

### Cause

In the schematic, for display purposes you treated a [cable](Glossary_o_kabel.htm) that was split as two separate cables and assigned different cable data to the main and subfunctions, e.g., different [cable types](Glossary_o_kabeltypen.htm), numbers of [connections](Glossary_o_verbindungen.htm), and connection cross-sections / diameters.

### Solution

Assign the cable's main and subfunctions identical cable data.

Refresh the connections and then start a new check run.

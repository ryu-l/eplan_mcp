# Adopting the Connection Colors/Numbers of Cable Connections as Bundle Connection Point Designations

By means of the Overwrite bundle connection points menu item you can overwrite the [bundle connection point designations](Glossary_o_stranganschlussbezeichnungen.htm) of [cable connections](Glossary_o_kabelverbindungen.htm) with the connection colors or numbers of the [cable](Glossary_o_kabel.htm). For very long [bundles](Glossary_o_straenge.htm), which often lead over several pages via [interruption points](Glossary_o_abbruchstellen.htm), this allows the [connection designations](Glossary_o_verbindungsbezeichnungen.htm) to be read at the [bundle](Glossary_o_buendel.htm) entry and exit points of the cable. When searching for errors in the schematic, this makes it much easier to follow a bundled cable connection between the cable target and the cable source.

Preconditions:

- You have opened a project.
- The project contains a multi-line schematic page with a cable connection represented as a bundle - as shown in the following example. In the multi-line representation area, the [cable definition lines](Glossary_o_kabeldefinitionslinien.htm) run between the cable source and the [bundle connection point symbols](Glossary_o_stranganschlusssymbole.htm) at the entry to the bundle. The [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) of the cable show color or number information.
- The schematic page is opened in the graphical editor.  
    
  ![](../Pictures/Visualisation/ALL/singlepole_stranganschluss_kabel1_av.png)

1. Select the cable definition line.
2. Select the Project data > Cables > Overwrite bundle connection points menu [items](Glossary_o_bauteile.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The bundle [connection point designations](Glossary_o_anschlussbezeichnungen.htm) 1, 2, 3 and 4 at both ends of the bundle are replaced with the connection colors BK, BU, BN and GNYE of the cable.  
     
   ![](../Pictures/Visualisation/ALL/singlepole_stranganschluss_kabel2_av.png)

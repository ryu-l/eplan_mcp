# P002001: A pin connection point has too many targets: <x>. Maximum number of targets allowed: <y>

### Cause

You connected at least one of the two pin function [connection points](Glossary_o_anschluesse.htm) to more components than the specified number.

### Solution

#### Possibility 1

Double-click the pin in the schematic and in the Properties <...> dialog select the Symbol / function data tab. In the Function data (logic) group box, click [Logic]. In the Connection point logic dialog, check which values are set in the Number of targets row for both function connection points of the pin. Increase the defined value for one or both function connection points based on your requirements.

#### Possibility 2

Double-click the pin in the schematic and in the Properties <...> dialog select the Symbol / function data tab. In the Function data (logic) group box, click [Logic]. In the Connection point logic dialog, check which values are set in the Number of targets row for both function connection points of the pin. Delete the excess components placed for each pin function connection point in the schematic.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

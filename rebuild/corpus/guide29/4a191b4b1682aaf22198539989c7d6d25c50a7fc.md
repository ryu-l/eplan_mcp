# Translation of the Layer Description of User-Defined Layers

Layers have a layer description from which the hierarchical structure of the tree view is generated in the Layer management - <Project name> dialog. Previously the layer description was not considered for the translation. Now you have the possibility to also translate the descriptions of the user-defined [layers](Glossary_o_ebenen.htm) during the translation of the project.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

With the new property Layer: Description multilingual input is now possible for the layer description. The layer description can be translated and is displayed in the selected displayed language.

The new Layer: Description ([ID](Glossary_o_id.htm) 19380) property is available to this purpose. You can select this property in the project [settings](Glossary_o_einstellungen.htm) for the translation. The menu path for the project setting is: Options > Settings > Projects > "Project name" > Translation > Extent. Select the "Project" entry in the Extent field and activate the check box for the Layer: Description property.

The names and descriptions of the standard EPLAN layers cannot be changed and cannot be translated.

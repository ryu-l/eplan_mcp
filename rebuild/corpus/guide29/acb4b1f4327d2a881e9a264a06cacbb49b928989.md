# Creating and Editing PLC Cards and Connection Points

[PLC cards](Glossary_o_sps_karten.htm) and [connection points](Glossary_o_anschluesse.htm) can be created in different ways:

- In the graphical editor (drawn, as described in "Inserting PLC Cards and Connection Points")
- In the navigator dialogs PLC - <Project name> or Device - <Project name> (here you can also [create](Glossary_o_erstellen.htm) and re-use unplaced connection points).

You edit the [properties](Glossary_o_eigenschaften.htm) of a PLC card in the tabs [PLC box](devicetaggui_r_spskarte.htm) and [PLC structure data](devicetaggui_r_spsstruktur.htm) of the [property dialog](Glossary_o_eigenschaftendialog.htm).

You edit the properties of a PLC connection point in the [PLC connection point](devicetaggui_r_spsanschluss.htm) tab of the properties dialog. The [Bus data](devicetaggui_r_busdaten.htm) tab is additionally available for network / bus [cable](Glossary_o_kabel.htm) connection points.

![](../Pictures/Gui/ALL/note.png)Note:

If you want to use the PLC [data exchange](Glossary_o_datenaustausch.htm), a single-line representation of the [PLC configuration](plcgui_k_prinzip.htm#I_SPSKonfigurationen) is required. A multi-line representation is not needed but is additionally optionally possible. In this case enter the bus data at the single-line network / bus cable connection points.

During the PLC data exchange in the AutomationML format, the multi-line representation is reported in addition to the single-line representation in determining the [network structures](Glossary_o_netzwerkstrukturen.htm). If a multi-line representation of the PLC configuration is available, a single-line representation is not necessarily required anymore.

### [ClosedCreate PLC boxes or PLC connection points](javascript:void(0);)

1. Select the following menu [items](Glossary_o_bauteile.htm): Project data > PLC > Navigator
2. In the PLC - <Project name> dialog, select the New popup menu item.
3. In the Function definitions dialog, select a PLC box or a PLC connection point and click [OK].
4. In the Properties <...> dialog, edit the properties of the PLC box or the PLC connection point. For example, enter a new DT for the PLC box.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new (unplaced) PLC box or PLC connection point is displayed in the tree or the list.

### [ClosedPlace PLC boxes or PLC connection points](javascript:void(0);)

1. Select the following menu items: Project data > PLC > Navigator
2. Mark a PLC box or connection point and select the Place popup menu item.
3. Before actual [placing](Glossary_o_auflegen.htm) press the [Backspace].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The dialog Place device is opened. If a macro is defined at the [part](Glossary_o_artikel.htm), the Part macro option is set as the default.
4. From the Representation type drop-down list select the entry "Multi-line" and click [OK] in order to place the function on a multi-line schematic page. (Select "single-line" or "overview" to place the function on a single-line or overview page.)
5. Press the keys [Shift] + [Tab] to browse through the [representation types](Glossary_o_darstellungsarten.htm) of the macro. With [Tab] alone you can browse through the macro [variants](Glossary_o_varianten.htm).  
   Or press the [N] button in order to page through the [functions](Glossary_o_funktionen.htm) and select the desired one. Or use the [Spacebar] while placing the [auxiliary functions](Glossary_o_nebenfunktionen.htm) if you want to interrupt the placement of the auxiliary functions and want to start again with the placement of the main function.
6. If you have selected a PLC box, then you draw this as a rectangle.  
   If you have selected a PLC connection point, place the symbol in the schematic.

![](../Pictures/Gui/ALL/info.png)Tip:

Assigning PLC structure data in the tabular editing

Through the tabular editing you can rapidly and easily assign the PLC structure data for a [rack](Glossary_o_baugruppentraeger.htm). To this purpose first place the PLC items in the single-line representation or in the overview display. Them mark all the items of the rack and call up tabular editing (menu items: Edit > In table). Use a scheme in which the properties Main function, Placement, Rack, PLC card is placed on rack ID and Position (slot / module) are displayed.

Double-click the column heading Placement and then twice on the column heading Main function. This results in the items ([main functions](Glossary_o_hauptfunktionen.htm)) being sorted after their placement at the beginning of the table.

Enter the desired value for the Rack property at the rack. Copy this value for all the associated PLC cards in the PLC card is placed on rack ID column. Subsequently enter the desired value in the column Position (slot / module).

The rack is now configured completely. On the basis of these data EPLAN assumes that the items are connected by a backplane.

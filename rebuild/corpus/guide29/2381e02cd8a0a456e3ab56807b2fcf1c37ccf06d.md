# P017007: DTs are not cross-referenced

### Cause

You entered the device identifiers of both function in different ways:

When you added it to the schematic, you entered the device identifier in the "normal" way under Displayed DT in the Properties dialog. The same device identifier for the other [functions](Glossary_o_funktionen.htm) were entered in the Full DT dialog which gave the identifier character as well as the counter together in the Characters field.

![](../Pictures/Gui/ALL/note.png)Note:

You can access the Full DT dialog by clicking [...] in the Properties <...> dialog next to the Full DT field.

### Solution

Change the device identifier which you entered in the Full DT dialog. Enter the identifier character and the counter separately in their own fields.

Then start a new check run.

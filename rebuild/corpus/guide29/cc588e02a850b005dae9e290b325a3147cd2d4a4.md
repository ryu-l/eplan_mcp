# Assigning Segments to the 3D Part Placement in the Layout Space

From the pre-planning navigator, the [segments](Glossary_o_segmente.htm) from the pre-planning can now be assigned to 3D [part placements](Glossary_o_artikelplatzierungen.htm) in the [layout space](Glossary_o_bauraum.htm) via the popup menu item Assign.

This way you can, for example, in a macro project link the 3D [part](Glossary_o_artikel.htm) placements contained in a 3D macro with segments in the pre-planning. In the case of a corresponding assignment, the finished 3D macro contains complete part structures. If such a 3D macro is inserted in a schematic project, the part structures contained in the macro are sorted into the pre-planning structure of the project.

If the pre-planning contained in the 3D macro does not match the superior segment, a corresponding message is issued. The 3D macro is inserted. However, the pre-planning structure is not transfered.

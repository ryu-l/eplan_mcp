# Creating a Project (Project Management)

You can [create](Glossary_o_erstellen.htm) [projects](Glossary_o_projekte.htm) via the project management, or you can create them directly. In the process the project is created based on a project template or a basic project. If you have not yet created any [project templates](Glossary_o_projektvorlagen.htm) or [basic projects](Glossary_o_basisprojekte.htm), you can use the EPLAN [Sample templates](projects_k_basisprojekt.htm#Beispielvorlagen). The following section describes how you create a project via the project management.

Preconditions:

- You have access to [Project templates](projects_k_projektvorlagen.htm) or [Basic projects](projects_k_basisprojekteerweitert.htm).
- You have created a project management database.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project > Management
2. Select [Organize] > New.
3. Enter the project name and the storage location in the dialog [Create project](prjmanagementgui_d_projekterstellen.htm) and select the desired template for the project.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new project \*.elk is created in the target directory.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new project is automatically imported into the project management.
5. Check all the entries in the dialog Project properties: <Project name> and customize them if necessary.

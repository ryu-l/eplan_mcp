# P004097: More than one I/O connection point at a channel within a type of signal in a subdevice

### Cause

More than one I/O connection point was defined for a channel within a type of signal in a PLC subdevice.

This check run checks in particular [PLC cards](Glossary_o_sps_karten.htm) that dispose of both inputs and outputs that can be managed as subdevices. At such cards the following channel assignment is, for example, allowed:

I1 => Channel 1, I2 => Channel 2, etc.

O1 => Channel 1, O2 => Channel 2, etc.

Check criterion is the type of signal (digital / analog PLC input / output) and the index on the subdevice.

At multi-function [connections](Glossary_o_verbindungen.htm) the type of signal stored in the connection point logic is taken into consideration.

[PLC connection points](Glossary_o_sps_anschluesse.htm) with the "PLC connection point, internal, general" function definition are not checked before this check run since they are only used for the display of free [symbolic addresses](Glossary_o_symbolischeadressen.htm).

### Solution

Assign only one I/O connection point per subdevice to each channel. In addition enter a unique channel designation for each I/O connection point in the Properties <...> dialog.

Then start a new check run.

# Dialog Busbar (bending)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open. Insert > Busbar (bending).

Use this dialog to define the [part](Glossary_o_artikel.htm) number of the busbar, the copper [form](Glossary_o_verlauf.htm) and the bending radius of the busbar to be placed. All three fields must have an entry.

Overview of the main dialog elements:

Part number:

The [...] button opens the Part selection dialog of the hierarchy level generic product group "Mechanics", product group "Busbars", product subgroup "Rail".

If the selected part has an assigned macro with the "3D mounting layout" representation type, this macro will be used for the definition of the dimensions width and depth. If no macro has been assigned, the entries Width and Depth from the fields on the Mounting data tab of the part will be used.

Copper rails which are planned for bending always have a rectangular cross-section. If the selected part has already been assigned an outline (extrusion) (to [create](Glossary_o_erstellen.htm) a [user-defined](Glossary_o_benutzerdefiniert.htm) rail), this part cannot be bent. Such a part cannot be used for a bent copper rail.

Form:

If the selected part has an assigned macro with the "3D mounting layout" representation type, this macro will be used for the definition of the form and bending radius. If no macro has been assigned, a form drawing must be entered in this field.

The [...] button opens the Select form dialog where you can select a file with the file extension \*.fp1.

Bending radius:

Enter here the required bending radius for the bending positions of the copper rail. The entries in this field are entered in a drop-down list from which you can also select values.

Flat bending

With this setting, the busbar is bent around the edge which is defined in the "Width" value of parts management.

![](../Pictures/Visualisation/ALL/cabinetgui_copperbarflatbending_as.png)

Edgewise bending

With this setting, the busbar is bent around the edge which is defined in the "Depth" value of parts management. For an [edgewise bending](Glossary_o_hochkantbiegung.htm) a far larger bending radius is required than for a [flat bending](Glossary_o_flachkantbiegung.htm).

![](../Pictures/Visualisation/ALL/cabinetgui_copperbaruprightbending_as.png)

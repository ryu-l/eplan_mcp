# Tab <PCT loop> / Tab <PCT loop function>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have generated a planning object with the segment definition "Loop", "Consumer", "Measuring function", or "Consumer function" in the pre-planning navigator, or inserted one in the graphical editor. In the Properties <...> dialog, select the PCT loop or PCT loop function tab.
- You have highlighted a PCT loop or PCT loop function in the pre-planning navigator or in the graphical editor. Edit > Properties (or Popup menu > Properties). Select the <PCT loop> or <PCT loop function> tab.

In this tab, you can specify the [properties](Glossary_o_eigenschaften.htm) of the selected PCT loop or PCT loop function.

If the entries in the fields differ from the default values of the underlying segment template in the [property dialog](Glossary_o_eigenschaftendialog.htm), these are highlighted by a [yellow background](planninggui_k_segmentvorlagen.htm#GelberHintergrund).

Overview of the main dialog elements:

Group box designation

In these fields, enter all properties for the PCT loop number of the new PCT loop / PCT loop function. The PCT loop number is compiled automatically from these properties and displayed in the Full designation field.

Technical facility:

In this field, you can specify an identifier for the technical facility if required.

Measurand:

In this field you enter an identifier for the measurand. Click [...] to select a specified identifier for a measurand.

Processing function:

In this field you enter an identifier for the processing function. Click [...] to select a predefined processing function identifier. (The identifiers for [processing functions](Glossary_o_verarbeitungsfunktionen.htm) can be predefined in the [Settings: Processing function](planninggui_d_einstellverarbeitfunktion.htm) dialog.)

Number:

You can enter a counter in this field.

Full designation:

This field displays the PCT loop number including the [designations](Glossary_o_bezeichnungen.htm) of the superior [segments](Glossary_o_segmente.htm).

---

Description:

Enter description text for the planning object here. This text is displayed in the pre-planning navigator together with the designation at the planning object by default.

Segment template:

This field displays the segment template which is assigned to the segment. Click [...] to open the Select segment template dialog for selecting a segment template. Only [segment templates](Glossary_o_segmentvorlagen.htm) which are suitable for the segment definition of the current segment are displayed. When switching to another segment template, the property values of the new segment template are applied to the segment and are displayed in the property dialog of the segment. Manually changed values are retained.

Using ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete), you can remove the reference to the segment template from the segment. The property values defined in the segment template will be deleted at the segment. Manually changed values are retained.

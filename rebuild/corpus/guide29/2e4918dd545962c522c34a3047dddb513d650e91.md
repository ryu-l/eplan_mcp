# Cross-referencing DTs

In EPLAN, components with differing device tags can be cross-referenced to a new device by assigning a unified DT to the components.

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the components to be cross-referenced (at least two).
2. Select the menu [items](Glossary_o_bauteile.htm) Edit > Property overview.
3. In the drop-down list of the Property overview dialog select the entry "Non-function-specific [properties](Glossary_o_eigenschaften.htm)".
4. In the property table for the property Name (full), click in the column Value and then the button [...].
5. Enter the DT that is to be assigned to all the marked components as the common one in the dialog Full DT.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The DT is assigned to all the marked components. Device [cross-references](Glossary_o_querverweise.htm) are then automatically displayed at the components.

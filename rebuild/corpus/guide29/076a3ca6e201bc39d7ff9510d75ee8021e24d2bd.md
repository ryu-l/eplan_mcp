# Tab Do not translate

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Translation > Edit dictionary. Select the Do not translate tab.

In this tab you have the option of entering words that should not be translated and thus are always the same in every language. These words will be ignored during the translation process. The setting is only valid for word-by-word translation.

The following dialog elements are available:

Find:

Use this field to search for all of the words that have already been added to the list of words that are not to be translated. To search for a word, enter it in the input field.

Word not to be translated:

In this field you can edit the word that is not to be translated.

Toolbar:

| Button | Meaning |
| --- | --- |
| (New) | Creates a word. |
| (Save) | Saves a word in the list of words not to be translated. |
| (Copy) | Copies a word. The copy obtains the addition "(Copy)". |
| (Delete) | Deletes a word from the list of words not to be translated. |

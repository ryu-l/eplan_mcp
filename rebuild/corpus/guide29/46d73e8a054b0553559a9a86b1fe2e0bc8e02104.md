# Deleting Imported PDF Comments from EPLAN

PDF [comments](Glossary_o_kommentare.htm) existing in the project via importing of PDF comments can be manually deleted from the project, either sequentially or together.

Precondition:

- Open project containing PDF comments.

1. Project > Organize > Compress
2. Click [...] next to the Settings field in the Compress project dialog.
3. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the dialog Settings: Compress, enter a descriptive name into the Name field and click [OK].
4. Select the Comments check box, click ![](../Pictures/Gui/ALL/all_save_as.png) (Save) and then click [OK].
5. In the Compress project dialog click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The comments are removed from the project.

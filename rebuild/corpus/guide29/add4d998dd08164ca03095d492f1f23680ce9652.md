# P008005: Text in project not translated: '<x>'

### Cause

A project text has not been translated into one or more [translation languages](Glossary_o_uebersetzungssprachen.htm).

### Solution

1. From the Message management dialog, use the Go to functionalities to display the relevant text (text, path function text, property of a function, etc.) in the project.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) for the text or function.
3. Select the field that contains the untranslated text.
4. Select the menu item Popup menu > Translate.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the Translate dialog, the program displays the corresponding translation, as specified as a keyword in the dictionary, for the translation languages selected.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The texts are translated into all the translation languages.
6. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Notes:

If the translation for one or more of the translation languages is missing from the list in the Translate dialog, it must be added to the dictionary in the relevant languages.

This message is not output under the following conditions:

- The Do not translate automatically check box was activated in the Properties dialog for text (Text tab).
- Or a text was marked (completely) as "text not to be translated" (popup menu in the Properties dialog for [devices](Glossary_o_betriebsmittel.htm) or for text (Text tab), menu option Mark text as 'Excluded from translation').
- Or a word has been stated in the Dictionary dialog (Do not translate tab) as a word that is not to be translated.

# Tab Info

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > User > Management > Data Portal. Select the Info tab.

This tab contains information about the add-on.

Overview of the main dialog elements:

Version:

This shows the version number of the add-on.

Status:

This shows the status of the add-on.

[Check]:

Click this button to check the [settings](Glossary_o_einstellungen.htm) on the other tab: If a connection to the portal exists, the version number of the set portal is displayed, and a message appears in the Status field.

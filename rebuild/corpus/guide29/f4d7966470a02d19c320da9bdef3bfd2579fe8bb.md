# P001021: Terminal is not included in terminal strip definition

### Cause

You created a terminal strip in the terminal strip Navigator or a function template in the schematic. You also created a terminal in the terminal strip Navigator or placed one in the schematic which is not a [component](Glossary_o_schaltzeichen.htm) of the function template.

### Solution

Highlight the terminal strip definition in the terminal strip navigator or in the schematic. Go to Project data > Terminal strips > Edit. In the Edit terminal strip dialog go to the Popup menu and select the menu option Generate function template.

![](../Pictures/Gui/ALL/arrow.png) Now all terminals are components in the function template.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

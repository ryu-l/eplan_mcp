# Dialog Reassign PLC addresses

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Project data > PLC > Addresses / assignment lists. You have selected [PLC addresses](Glossary_o_sps_adressen.htm) in the table. Select the Address popup menu item.

In this dialog you reassign the PLC addresses in an assignment list. Both free and used addresses are re-addressed. The new addresses are written back to the appropriate [functions](Glossary_o_funktionen.htm) in the project.

![](../Pictures/Gui/ALL/note.png)Note:

Only the PLC addresses of one CPU can be addressed respectively. If in the assignment list you have selected PLC addresses belonging to different CPUs, a selection dialog is displayed prior to the opening of the Reassign PLC addresses dialog, and you have to decide for a CPU.

Overview of the main dialog elements:

PLC-specific settings:

The scheme which defines the format of the PLC addresses is displayed in this field. The scheme is determined on the basis of the CPU that is contained in the selection and cannot be changed here. If no scheme is assigned to the CPU, the scheme specified in the project [settings](Glossary_o_einstellungen.htm) is used. The configuration project, the station [ID](Glossary_o_id.htm) and the CPU to which the PLC addresses are assigned are furthermore displayed via the field.

Addressing:

The drop-down list offers all addressing that was defined in the Addresses tab in the dialog Settings: PLC-specific.

The Input bit and Output bit settings cause the digital [connection points](Glossary_o_anschluesse.htm) to be re-addressed, all other settings cause the analog connection points to be re-addressed.

Start address:

Here you define the address from which the addressing is to begin. The currently defined addressing format is displayed as an aid above the list; this depends on the addressing selected in the options above.

![](../Pictures/Gui/ALL/note.png)Note:

Please note that a configuration value in the address format will not be used for addressing within the assignment list. The assignment list only accesses the data for the [PLC connection points](Glossary_o_sps_anschluesse.htm), and not the data for [PLC boxes](Glossary_o_sps_kaesten.htm).

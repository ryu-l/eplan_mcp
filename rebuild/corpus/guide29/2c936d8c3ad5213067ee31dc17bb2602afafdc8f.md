# Dialog Settings: Property dialogs

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > User > Graphical editing > Property dialogs

Use this dialog to specify whether the [property dialog](Glossary_o_eigenschaftendialog.htm) is to be displayed or not when inserting specific [objects](Glossary_o_objekte.htm).

Overview of the main dialog elements:

When inserting connection splicers:

If this check box is selected, the Properties <...> dialog is displayed when [connection splicers](Glossary_o_leitungsverteiler.htm) or [line connectors](Glossary_o_leitungsverbinder.htm) are inserted. There, you can immediately enter the device [properties](Glossary_o_eigenschaften.htm) of the connection splicer or line connector.

When inserting shields:

If this check box is selected, the Properties <...> dialog is always displayed when [shields](Glossary_o_abschirmungen.htm) are inserted. You can then immediately enter the device properties of the shield.

While inserting routing points and routing paths (topology):

If this check box is activated, the Properties <...> dialog will be displayed when inserting [routing points](Glossary_o_verlegepunkte.htm) and [routing paths](Glossary_o_strecken.htm) in the [topology](Glossary_o_topologie.htm). There, you can enter immediately the device properties of the routing point or of the routing path.

# Dialog Insertion point of next form

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Utilities > Master data > Form > Open. In the Open forms dialog, select a [form](Glossary_o_verlauf.htm) and click [Open]. Insert > Insertion point of next form.
- Utilities > Master data > Form > New. In the Create form dialog, select the appropriate file type, enter the file name, and then click [Save]. In the Form properties - <Form name> dialog click [OK]. Insert > Insertion point of next form.

In this dialog you determine the report type and the form of the next form. In addition you have the possibility to determine filter and sorting criteria for the extent and the sorting of the report.

Overview of the main dialog elements:

Report type:

Select the report type for the next form from this drop-down list. Depending on the form type of the opened main form, different entries are available for selection here. For most [form types](Glossary_o_formulartypen.htm), the "Summarized parts list" and the "Parts list" are available.

If you change the report type here, the [settings](Glossary_o_einstellungen.htm) made for the Form, Filter, Sorting, and New page [properties](Glossary_o_eigenschaften.htm) are removed again.

---

Property / value table:

Use this table to determine additional settings for the next form.

Form:

Here you determine the form of the next form, i.e., you select a second form for the report. In the Value column you can select a suitable form from the drop-down list or branch to [forms](Glossary_o_formulare.htm) selection by means of the "Browse" entry. If, e.g., you [generate](Glossary_o_erzeugen.htm) a [cable](Glossary_o_kabel.htm) assignment diagram, you can output the cable data on the main form and the associated parts can be output in the next form which is entered in this field.

Filter:

Use the [...] button in the Value column to branch to the Filter dialog.

Sorting:

Use the [...] button in the Value column to branch to the Sorting dialog.

![](../Pictures/Gui/ALL/note.png)Note:

Concerning [filters](Glossary_o_filter.htm) and sorting, the same [schemes](Glossary_o_schemata.htm) and filter criteria are available as for the generation of a report of the respective report type. In the case of function-related [report types](Glossary_o_auswertungstypen.htm) (such as, e.g., terminal diagram, plug diagram, etc.), the filter and sorting criteria apply to the [functions](Glossary_o_funktionen.htm).

New page:

If this check box is selected, first the report is generated from the main form and then the report for the next form starts on the next page.

If the check box is not selected, the second report would be inserted directly on the first page of the insertion point of next form.

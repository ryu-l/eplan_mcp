# P020034: Device <x> (x Pos <y> : y Pos <z>) : <u>

### Description

You have run a project comparison, checking the Properties of the test project (incoming project) against those of the comparison project and differences were found.

This message occurs when a difference in the [properties](Glossary_o_eigenschaften.htm) of a function was found. <x> designates the full DT in question, <y> the X position and <z> the Y position in the schematic. <u> indicates whether the function in the project has been deleted or added, or if one if its properties has been changed. Testing of the properties of [functions](Glossary_o_funktionen.htm) includes both the device navigator and the schematic. If a property of a function which has been created in the device navigator but not yet placed in the schematic has changed in the test project, the values for the X and Y position are shown as "0" in the message text.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

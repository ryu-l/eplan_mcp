# Viewing and Editing the Check Run Messages

In the Message management - Project name dialog, the messages of the currently selected project are listed. The project name is displayed in the title bar of the dialog. If the dialog is opened and you select a different project in the page navigator, the display of messages is updated.

The different [message categories](Glossary_o_meldungskategorien.htm) are marked with appropriate [icons](Glossary_o_icons.htm). Critical messages can therefore be identified immediately, even if the messages in the table are not sorted or filtered.

### View check run messages

Precondition:

You have opened a project.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Messages > Management.
2. Double-click the column headers in the dialog Message management - <Project name> to sort the messages. By clicking multiple times, you can switch between ascending and descending sort orders.

![](../Pictures/Gui/ALL/note.png)Note:

Use the [F1] key to call up comprehensive help for each message, including correction suggestions.

### Filter check run messages

Preconditions:

- You have opened a project.
- You have opened the message management dialog.

1. Click [...] next to the Filter field.
2. In the dialog Filter: Messages define the [message classes](Glossary_o_meldungsklassen.htm) in the table for which messages should be displayed, e.g. terminals, [plugs](Glossary_o_stecker.htm), cables, etc. Select the appropriate check box in the Selection column for this.
3. Using the check boxes below the table, specify the [trades](Glossary_o_gewerke.htm) from which messages should be displayed (Electrical engineering, Fluid power, and General).
4. Specify the categories (error, warning, note) to be displayed. Check the corresponding check boxes.
5. Select the Completed messages check box if you also would like to display messages already flagged as resolved.
6. Click [OK].
7. Activate the Active check box in the message management dialog so that only those messages are displayed which correspond to the filter.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The last filter criteria selected also remain in effect after the dialog is closed, and are again active when the dialog is reopened.

![](../Pictures/Gui/ALL/note.png)Note:

When opening a project or switching [projects](Glossary_o_projekte.htm), the current state of project-wide messages is always displayed when message management is called up. However, the existing [filters](Glossary_o_filter.htm) can influence this display.

### Edit check run messages

Preconditions:

- You have opened the message management dialog.
- Messages are displayed in the dialog.

1. Mark the message and select the menu item Go to (graphic) from the popup menu. (Or double-click the message.)   
     
   ![](../Pictures/Gui/ALL/arrow.png) The erroneous object is selected in the graphical editor and the cursor is placed on the insertion point of the object.
2. Double-click the selected object in the graphical editor.
3. Change the data which caused the error in the [property dialog](Glossary_o_eigenschaftendialog.htm) and click [OK].
4. Use Project data > Messages > Check project to start a new check run to check whether the error has been resolved.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The message display is updated in the Message management - <Project name> dialog.

![](../Pictures/Gui/ALL/note.png)Notes:

- For processed messages, you can select the Completed check box and filter on this property in order to hide them.
- If you want to remove processed messages from the dialog of the message management, activate the check box Check only completed messages when carrying out a check run.

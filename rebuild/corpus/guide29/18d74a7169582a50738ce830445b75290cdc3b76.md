# Displaying Empty Text and Small Font Text

Precondition:

You have opened a page, [form](Glossary_o_verlauf.htm), plot frame, or symbol.

### Find empty texts

If you accidentally enter empty texts while inserting text, then you can find and remove them easily.

1. Select the menu [items](Glossary_o_bauteile.htm) View > Empty text boxes in order to enable the display of empty texts.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The empty texts are displayed using the "Empty text" string.
2. Select the desired empty texts and select the menu items Edit > Delete.

![](../Pictures/Gui/ALL/note.png)Note:

Note that empty [special texts](Glossary_o_sondertexte.htm) on "normal pages", i.e. (as yet) empty project or page [properties](Glossary_o_eigenschaften.htm), can not be made visible via the View > Empty text boxes menu items, but only by means of their insertion points. And they can only be deleted individually by clicking and calling up the Delete function.

### Display texts in the minimum font size

Independently of the currently defined font size, you can define a minimum font size for text to be displayed on the screen. However, this setting has no effect on the printed image.

1. Options > Settings > User > Graphical editing > 2D
2. Activate the Minimum font size check box.
3. Enter the desired font size into the adjacent field.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) All texts whose actual font size is smaller than the minimum font size will be displayed in the minimum font size in the graphical, the symbol, form and plot frame editor.

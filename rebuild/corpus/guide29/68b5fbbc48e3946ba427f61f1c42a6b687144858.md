# P002003: Plug definition is missing

### Cause

You created a pin without a plug definition in the Plug Navigator or placed it in the schematic.

### Solution

#### Possibility 1

Select Popup menu > New in the plug navigator.

In the expanded Selection tree of the subsequent dialog (via Electrical engineering > Terminals and [plugs](Glossary_o_stecker.htm) > Plug definition > Plug definition ) navigate to the desired function definition (Plug definition for [female pins](Glossary_o_steckerbuchsen.htm), Pins or Male and female [pins](Glossary_o_steckerkontakte.htm)). Click [OK], and assign the displayed DT or the plug to the plug definition in the Properties <...> dialog.

#### Possibility 2

Under Insert > Plug definition place a plug definition in the schematic and assign the displayed pin DT to it.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

# P024010: Invalid conduit length

### Cause

At a conduit definition a negative value for the conduit length was entered.

### Solution

1. Locate the conduit definition line in the schematic by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the conduit definition line.
3. Enter a positive value in the Length field.
4. Click [OK].
5. Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

Other invalid values, for example letters, are not accepted. Invalid values that include interpretable units, are automatically corrected. For example the input 2M turns into length 2 m.

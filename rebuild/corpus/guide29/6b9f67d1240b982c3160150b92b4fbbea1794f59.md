# P005017: Target does not exist

### Cause

At an unplaced connection the specification of the function which is the source and / or target of the connection is missing.

### Solution

#### Possibility 1

1. Open the [connections](Glossary_o_verbindungen.htm) navigator via the menu [items](Glossary_o_bauteile.htm) Project data > Connections > Navigator.
2. To locate the faulty connection, click the message in the dialog of the message management and select the menu item Synchronize selection from the popup menu.
3. The connection is marked in the connections navigator.
4. Call up the [property dialog](Glossary_o_eigenschaftendialog.htm) of the connection. Then add the device tag of a function existing in the project in the [properties](Glossary_o_eigenschaften.htm) list at the property Source and / or at the property Target.
5. Click [OK].
6. Then start a new check run.

#### Possibility 2

1. Select the menu items Project > Organize > Compress to remove data that is no longer needed from your project.
2. In the compression [settings](Glossary_o_einstellungen.htm) activate the check box Remove unplaced connection.
3. Then start a new check run.

# Dialog Settings: Multi-user monitor

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > User > Management > Multi-user monitor

In this dialog, specify the computer on which the monitor server service has been set up.

![](../Pictures/Gui/ALL/note.png)Note:

If you have any questions about the [settings](Glossary_o_einstellungen.htm), please contact your system administrator.

The following dialog elements are available:

Server name:

In this field, enter the name of the computer on which the server application for the multi-user monitor has been installed.

Port:

In this field, enter the port number of the server application.

Active:

Check this check box to establish the connection with the server.

Status:

This field displays the status of the connection.

[Check]:

Click this button to check the settings. If there is a connection to the server computer, a corresponding message is displayed in the Status field.

# Connection Cross-section / Diameter for Piping Planning Objects

Analog to the piping definition points the property Connection: Cross-section / diameter ([ID](Glossary_o_id.htm) 44085) is now also available for the piping [planning objects](Glossary_o_planungsobjekte.htm).

![](../Pictures/Gui/ALL/benefit.png)Benefit:

By means of the new property at the piping planning [objects](Glossary_o_objekte.htm) you can already specify the connection cross-section / diameter in the pre-planning and inherit it to the [pipings](Glossary_o_rohrleitungen.htm) in the [P&I diagram](Glossary_o_ri_fliessbild.htm). This avoids redundant data entry.

If you have entered a value for this property, this value is transferred when [placing](Glossary_o_auflegen.htm) the piping planning object in the P&I diagram or during the assignment of the piping definition point. Modified values at the piping planning object can be transferred to the placed piping definition points via the popup menu item Update detailed planning.

The unit of the connection cross-section / diameter is adopted from the project-wide default [settings](Glossary_o_einstellungen.htm) for [process engineering](Glossary_o_verfahrenstechnik.htm) [connections](Glossary_o_verbindungen.htm) (menu path: Options > Settings > Projects > "Project name" > Connections > Properties; Process engineering tab). To have values shown together with the unit at the piping definition points, you can use the familiar property Connection: Cross-section / diameter with unit (ID 31007).

# Functions: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_funktionen.htm)

### Functions

User interface / operation

A function is an object to which a function definition (see [Function definitions](Glossary_o_funktionsdefinitionen.htm)) is assigned. Once the function has been placed in the schematic (represented by a symbol on a schematic page), this will be hereafter be known as a "component". Each device can have one or more functions. For example, a contactor consists of a coil and several contacts.

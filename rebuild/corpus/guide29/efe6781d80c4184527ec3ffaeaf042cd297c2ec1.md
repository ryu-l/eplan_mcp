# Printing pages

You can print single pages or all pages of a project. You have the option of changing the output of the project pages by using the print [settings](Glossary_o_einstellungen.htm).

Preconditions:

- You have selected the desired number of pages (or the project) in the page navigator in the tree or list view.
- You have opened a page in the graphical editor.

1. Project > Print
2. In the Print dialog, in the Printer group box, select the desired printer from the drop-down list.
3. In the Page range group box, you can determine whether you would like to print the currently selected pages or all of the pages in the current project.   
    If you called up the Print dialog from the graphical editor, you can print either the page currently in the foreground or all of the project pages.
4. Enter the number of copies and the collating order.
5. Use [Settings] to open the Settings: Print dialog to perform further settings.
6. With [Print preview] you have the option of checking the results of your settings before printing. You can use [Back] and [Next] to page through the pages selected for printing.
7. Start the print process using [OK] in the Print dialog or with [Print] in the Print preview dialog.

![](../Pictures/Gui/ALL/note.png) Note:

You can work on a different project while printing is going on in the background. Just start multiple copies of EPLAN.

![](../Pictures/Gui/ALL/info.png)Tip:

When printing pages, if you wish to output only the current pages of an active page filter, select the project in the page navigator and in the Print dialog activate the Selection option.

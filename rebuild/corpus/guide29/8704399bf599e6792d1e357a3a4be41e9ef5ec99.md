# Report Types

Report types specify which group of related information should be reported. Report types are predefined and cannot be user-created. In order to output [report pages](formgeneratorgui_k_auswertungsseiten.htm) and [embedded reports](formgeneratorgui_k_ausgabeformen.htm) in a formatted and structured manner, you must assign a [form](Glossary_o_verlauf.htm) to the report type before generating the report. In EPLAN, a distinction is made between [report types](Glossary_o_auswertungstypen.htm) for function-related [reports](Glossary_o_auswertungen.htm), report types for report overviews, and graphical reports.

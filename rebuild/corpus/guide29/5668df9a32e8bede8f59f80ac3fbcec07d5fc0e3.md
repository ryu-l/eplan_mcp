# Dialog Settings: Contact image on component / Contact image in path

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Options > Settings > Projects > "Project name" > Cross-references / contact image > Contact image on component / Contact image in path.

In this dialog you define the defaults for displaying contact images on the [component](Glossary_o_schaltzeichen.htm) / in the component path. These [settings](Glossary_o_einstellungen.htm) are normal for motor overload switches and contactors, for example.

The following dialog elements are available:

Display own cross-reference:

If this check box is selected, then the cross-reference of the current component is also displayed in the [contact image](Glossary_o_kontaktspiegel.htm).

Display as symbol image:

If this check box is selected, then a symbol contact image symbol is displayed at the component. In this representation type, all of the components are displayed, only the main function is suppressed by default.

Default:

Select this option if you want to define the defaults for displaying contact images on the component or for displaying contact images in the schematic path of the component. All the settings between this option and the Embedded form option are then activated for selection / activation.

Arrange vertically:

If this check box is selected, the contact image is arranged vertically.

Display cross-reference texts vertically:

If this check box is selected, the [cross-references](Glossary_o_querverweise.htm) are displayed vertically.

Underline cross-reference texts of NC and change-over contacts:

If this check box is selected, the cross-references of NC contacts and change-over contacts are highlighted with underlining.

Decrease cross-reference texts and connection point designations:

If this check box is selected, the cross-reference texts and [connection point designations](Glossary_o_anschlussbezeichnungen.htm) are shrunk; this makes the display easier to read.

Show symbols:

If this check box is selected, then [symbols](Glossary_o_symbole.htm), instead of the entries, are displayed in the contact image.

Show cross-references on the left:

If this check box is selected, then the cross-reference is shown to the left of the symbol.

Hide left-hand / right-hand connection point designation:

If this check box is selected, then the left or right connection point designation is not displayed; this can also improve the readability of the display.

Show in tabular form:

If this check box is selected, then the page number and column designation is displayed in the cross-reference in tabular [form](Glossary_o_verlauf.htm). The arrangement is affected by the Arrange vertically setting, and the table headings for NC and NO contacts are taken from the setting Contact image table: Labeling (under Options > Settings > Projects > "Project name" > Cross-references / contact image > General).

Table cross with variable length:

If this check box is selected, then the table cross is automatically adjusted to fit the maximum size of the contact image entries; In this case, the setting Contact image table: Width / height (under Options > Settings > Projects > "Project name" > Cross-references / contact image > General) are not taken into account.

Rotation:

The contact image is normally located vertically beneath the appropriate device. If desired, select the angle by which the contact image should be rotated from the drop-down list.

Display of 1st / 2nd part number:

Select from this drop-down list whether, and at what position, each [part](Glossary_o_artikel.htm) number is to be displayed in the cross-reference / contact image. (The setting always follows the alignment of the contact image, and the part numbers are displayed centered in multi-line format.)

Display of 1st / 2nd part type:

Select from this drop-down list whether, and at what position, each part type is to be displayed in the cross-reference / contact image. (The setting always follows the alignment of the contact image, and the [part types](Glossary_o_artikeltypen.htm) are displayed centered in multi-line format.)

Embedded form:

Select this option if you want to [create](Glossary_o_erstellen.htm) contact images with the use of embedded [forms](Glossary_o_formulare.htm). All the settings between this option and the Default option are grayed out and can no longer be activated.

Form:

From this drop-down list select the embedded form for creating form-based contact images.

# Add-ons: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_add_ons.htm)

### Add-ons

User interface / operation

Add-ons are function or data packages that add additional functionalities beyond an EPLAN product variant to this variant or that make additional data available. These can be both add-ons supplied by EPLAN and add-ons created by the user. In many cases the function packages of the EPLAN add-ons are also available as independent stand-alone versions. Thus, for example, EPLAN Fluid is available as a stand-alone version, but it can also be purchased as an add-on for EPLAN Electric P8 Professional.

### Device positions

Electrical engineering

The device position specifies the position of the terminal device within the terminal strip to which the terminal belongs. All the terminals of a terminal device have the same device position. The sort code (see [Sort codes](Glossary_o_sortierkennungen.htm)) also specifies the order of the terminals within a terminal device.

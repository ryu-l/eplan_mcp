# P026089: The routing connection <x> collides with <y>

### Cause

A routing connection was routed in the [layout space](Glossary_o_bauraum.htm) in such a manner that it penetrates another routing connection or a [part](Glossary_o_artikel.htm) placement. This situation can arise in particular at freely routed [routing connections](Glossary_o_verlegeverbindungen.htm).

The displayed DT and the connection point designation of the part placement are output in the placeholder <x>. This part placement is the source of the routing connection that caused the collision. The following information is output in the placeholder <y> depending on the situation:

- The item designation and the displayed DT of the part placement with which the collision has occurred. This is the case when the routing connection collides with a part placement.
- The text "Routing connection" followed by the displayed DT and the connection point designation of the part placement that is the source of the routing connection with which the collision took place. This is the case when the routing connection collides with another routing connection.

### Solution

1. Locate the routing connection that causes the collision in the layout space by using the Go to (graphic) functionality from the popup menu in the Message management dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The corresponding connection is highlighted in color.
2. Position the part placement with which the collision took place at a different location in the layout space and reroute the routing connection. Or - if the collision took place with a routing connection - change the routing for one or both of the routing [connections](Glossary_o_verbindungen.htm) involved in the collision.
3. Then start a new check run.

# P004051: Connection missing! <x> is not connected to the physical network '<y>'

### Cause

During the PLC data import a connection between the device <x> and the physical network <y> was determined that was currently not found in the project.

### Solution

Create the connection between the device and the physical network by means of a bus port.

![](../Pictures/Gui/ALL/note.png)Note:

This module-specific message is generated by the importing of PLC data. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

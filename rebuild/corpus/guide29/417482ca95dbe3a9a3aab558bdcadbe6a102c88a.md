# Tab Connection filter

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Options > Settings > Projects > "Project name" > Routing connections > General. Select the Connection filter tab.

In this tab, you can define a filter for the generation of [routing path networks](Glossary_o_streckennetze.htm). This filter is used for routing path networks in the [layout space](Glossary_o_bauraum.htm) and the [topology](Glossary_o_topologie.htm).

In the Layout space, the filter criteria defined here are available later in the project for selection at [channels](Glossary_o_kanaele.htm), [routing paths](Glossary_o_strecken.htm) and [routing ranges](Glossary_o_verlegebereiche.htm) in the property Layout space: Connection filter ([ID](Glossary_o_id.htm) 36026). The connection filter is used for routing to control which [connections](Glossary_o_verbindungen.htm) may be routed through which [routing tracks](Glossary_o_verlegewege.htm) (channel, manual routing path, routing range, [wiring](Glossary_o_verdrahtungen.htm) cut-out). Connection [filters](Glossary_o_filter.htm) are taken into account only if the Layout space: Routing track specification (ID 31094) property is not filled.

In the Topology, the filter criteria defined here are available later in the project for selection at the routing paths in the property Topology: Connection filter (ID 20247). The connection filter is used during routing to control which connections may be routed through which routing track (routing paths and [routing points](Glossary_o_verlegepunkte.htm)).

Overview of the main dialog elements:

Selected connection property:

Using [...], open the Criteria selection dialog and select there one of the connection [properties](Glossary_o_eigenschaften.htm) provided.

In the table, you can enter up to 15 values as criteria for the selected connection property.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

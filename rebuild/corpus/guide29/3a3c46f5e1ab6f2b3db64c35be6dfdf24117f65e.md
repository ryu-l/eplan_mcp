# P004018: No actuator at output

### Cause

No actuator can be determined at the PLC output during [target tracking](Glossary_o_zielverfolgung.htm). The reason for this can be an incorrect type of signal at the PLC output and/or at the actuator. The target tracking definition might also be missing at a terminal or plug switched to the actuator.

### Solution

1. Double-click the PLC output and select the Symbol / function data tab in the Properties <...> dialog.
2. Click [Logic].
3. Check the Type of signal property for the PLC output in the Connection point logic dialog. This property must match the function definition! If, for example, you entered a PLC connection point with the function definition "PLC connection point, DO" or "PLC connection point (fluid), DO", the Type of signal field must be set as a "Digital output"!
4. Also check whether the Type of signal property on the actuator is set to "actuator".
5. If a terminal or a plug is located between the actuator and the PLC output, also check the [settings](Glossary_o_einstellungen.htm) in the field Target tracking (PLC) to for this object. A "2" must be entered for the function connection point 1 and a "1" for function connection point 2.
6. Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

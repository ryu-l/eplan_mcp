# P501022: The connection dimensions of the function templates do not match the connection dimensions at the connection point pattern

### Cause

In the parts database to be checked [function templates](Glossary_o_funktionsschablonen.htm) with connection dimensions were defined at the [part](Glossary_o_artikel.htm) that do not agree with the connection dimensions of the connection point pattern selected at the part.

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective part is already marked.
2. Bring the Function templates tab to the front.
3. Note the connection dimensions entered in the table for the [connection points](Glossary_o_anschluesse.htm).
4. Change to the Technical data tab.
5. Note the names stored in the Connection point pattern group box.
6. Close the parts management.
7. Open the parts management again, this time by using the menu [items](Glossary_o_bauteile.htm) Utilities > Parts > Management.
8. In the tree view mark the connection point pattern whose name you have noted.
9. Switch to the Connection points tab.
10. Transfer the connection dimensions of the connection points from the function templates that you noted beforehand into the table, so that the connection point pattern and the function templates have identical values.
11. Close the parts management, save the modified data, and carry out a parts synchronization.
12. Then start a new check run.

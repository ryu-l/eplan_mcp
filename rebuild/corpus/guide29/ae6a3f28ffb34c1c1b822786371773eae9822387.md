# P004070: No matching bus port (output) at the predecessor address '<y>' was found for the bus port (input) at '<x>'

### Cause

You use the PLC import interface Beckhoff TwinCat: No bus port (output) was found for a bus port (input) at the device <x> named in the message during importing. The matching bus port (output) is always searched for at the predecessor address <y>.

### Solution

Check whether a bus port (output) exists for the bus port (input) of the device <x> named in the message at the predecessor address <y>.

![](../Pictures/Gui/ALL/note.png)Note:

This module-specific message is generated by the importing of PLC data. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

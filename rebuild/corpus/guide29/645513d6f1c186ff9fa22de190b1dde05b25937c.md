# Dialog Rights management

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Rights management

In this dialog you manage users and [user groups](Glossary_o_benutzergruppen.htm). To do this, you define the editing rights belonging to a user group. Users, passwords, and group membership as well as the assignment of the rights to the user groups are managed in a central file, the rights database.

If the rights database (via the operating system) was write-protected, then the Rights management dialog will also show "write-protected" in the heading line. If you carry out modifications in a write-protected rights database, these will not be saved, and a system message is generated.

![](../Pictures/Gui/ALL/note.png)Note:

Please note that administration of [rights management](Glossary_o_rechteverwaltung.htm) is not multi-user-capable. Rights management should only be edited by one EPLAN administrator at a certain time, otherwise, only the modifications of the EPLAN administrator who closed rights management last will be saved.

Overview of the main dialog elements:

The following folders are displayed in the left-hand field:

- User: If you have selected this folder, the existing users are displayed in the right-hand side and you can then edit these or [create](Glossary_o_erstellen.htm) new users. In addition, you can import the Windows users and groups from Active Directory. Once you have opened the folder, you can select individual users and define their group membership.
- Groups: If you have selected this folder, the existing user groups are displayed in the right-hand side and you can then edit these or create new user groups. Once you have opened the folder, you can select individual user groups and define their editing rights.
- Operating mode: Here you define whether EPLAN is operated with or without rights management.

Users and user groups are differentiated by the following [icons](Glossary_o_icons.htm):

| Icon | Meaning |
| --- | --- |
|  | Users |
|  | Users imported from Windows |
|  | Active Directory group imported from Windows. Is displayed and managed in the rights management like a user |
|  | User group |

[Import]:

Allows for a rights database to be imported from a previous EPLAN version into the rights management. Select the desired database file in the subsequent dialog. Possible file types are "Rights database in EPLAN format (\*.erm)" and "Rights database in Access format (\*.mdb)". Up to EPLAN version 2.2, the users and user groups were stored in an Access database, from version 2.3 onwards, an EPLAN-internal file format is used. An import of Access databases (\*.mdb) into an EPLAN 64 Bit system is not possible.

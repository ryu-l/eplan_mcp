# Parts databases: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_artikeldatenbanken.htm)

### Parts databases

User interface / operation

Database with technical and sales data for parts. EPLAN differentiates between the internal (EPLAN-specific) parts database which can be edited using parts management, and external parts databases. External databases can also be used. An example is the PMS application, which is implemented via an interface.

# P027029: Connection point <x> exists more than once in the topology function

### Cause

The connection point <x> exists several times in the connection point pattern of a [topology](Glossary_o_topologie.htm) function.

### Solution

1. Locate the respective topology function in the routing path network using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the topology function and bring the Connection point pattern tab to the front.
3. In the table search for the connection point designation specified in the message and change it. Ensure that you assign unique [connection point designations](Glossary_o_anschlussbezeichnungen.htm).
4. Confirm the change with [OK].
5. Then start a new check run.

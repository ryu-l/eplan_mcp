# Festo Product Catalog

If you have installed the Festo product catalog, then you can import parts data from this and use them in EPLAN. The following is possible:

- Parts from the Festo product catalog can be imported into the EPLAN parts management.
- Alternatively, you can use the API interface to directly access the Festo product catalog and select parts from this.
- The Festo parts can be assigned to an EPLAN macro on import.
- The import [settings](Glossary_o_einstellungen.htm) are configurable, i.e., you can customize the assignment of [part](Glossary_o_artikel.htm) data to suit your particular requirements.
- The device list can be filled or expanded with data from the Festo product catalog.
- The imported Festo parts can be used in EPLAN by [placing](Glossary_o_auflegen.htm) [macros](Glossary_o_makros.htm) or when working with [devices](Glossary_o_betriebsmittel.htm).
- Hyperlinks in the parts data provide access to the Festo website, which contains current documentation and technical data of the parts. When a part number is changed, this allows the associated documentation and technical data to be automatically adjusted.

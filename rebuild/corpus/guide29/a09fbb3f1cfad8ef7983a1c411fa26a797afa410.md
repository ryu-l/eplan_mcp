# Creating and Editing Project Options Groups

Project options groups are stored in the project. For this reason, they must be created in the project where they will be later used.

Preconditions:

- You have opened a project.
- You have opened the [project options](Glossary_o_projektoptionen.htm) navigator: Project data > Project options > Navigator

### [ClosedCreate project options groups](javascript:void(0);)

1. Select the New > Project option group popup menu item.
2. In the Project options group dialog, specify a name for the project options group in the Name field.
3. If desired, enter a description text into the Description field.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The description is a multi-language text and is displayed by default in the tree view next to the name, separated by a blank and within round brackets.
4. Click [OK].

### [ClosedEdit project options groups](javascript:void(0);)

1. Select a project option group in the Project options - <Project name> dialog.
2. Select the menu item Edit > Properties.
3. In the Project options group dialog, change the values in the Name and Description fields.
4. Click [OK].

### [ClosedDelete project options groups](javascript:void(0);)

1. Select a project option group in the Project options - <Project name> dialog.
2. Select the menu item Edit > Delete.
3. Click [Yes] to confirm the safety prompt.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project options group and all of the project options and sections it contains are deleted. When doing this, the [objects](Glossary_o_objekte.htm) of the project options that are switched on in the project are retained; objects of the project options that are switched off in the project are deleted.

# Displaying Mounting Aids

Mounting aids like handles, [mounting points](Glossary_o_montagepunkte.htm), [mounting surfaces](Glossary_o_montageflaechen.htm) etc. are elements of the device logic. These elements are visible in a schematic project only if they are in use, that is, during the placement in a [layout space](Glossary_o_bauraum.htm). Sometimes you may want to render mounting aids visible even outside of placement [actions](Glossary_o_aktionen.htm), so that they can be edited. You can control the visibility of mounting aids in the schematic project as needed by using the View > Mounting aids menu [items](Glossary_o_bauteile.htm).

![](../Pictures/Gui/ALL/info.png)Tip:

When a device is placed, it is possible that different mounting aids can lie at the same position over each other and that they can be used with equal rights for placement. In such a situation the found interactive points and surfaces are offered for selection in a selection list after being clicked. You can select the individual entries in the list by clicking on them or by using the cursor keys. The respective associated point or associated area is highlighted and a preview of the placement to be expected at this point is displayed.

Preconditions:

- You have opened a project.
- The layout space navigator is open and a layout space is open.
- The layout space contains 3D [part placements](Glossary_o_artikelplatzierungen.htm).

1. Select the View > Mounting aids menu items.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All existing mounting aids are displayed, and can be selected as well as edited.
2. Reselect the View > Mounting aids menu items.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All displayed mounting aids are hidden.

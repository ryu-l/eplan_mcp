# Tab Format (mounting grid)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The project contains at least one [layout space](Glossary_o_bauraum.htm). The layout space contains 3D [objects](Glossary_o_objekte.htm). A [mounting grid](Glossary_o_montageraster.htm) has been defined on a 3D object. You have marked the mounting [grid](Glossary_o_raster.htm) and selected the menu [items](Glossary_o_bauteile.htm) Popup menu > Properties. In the Properties dialog, select the Format tab.

On this tab you can edit the display [properties](Glossary_o_eigenschaften.htm) of a mounting grid.

Overview of the main dialog elements:

Property / Assignment:

The hierarchy level Mounting grid is available in the table. It can be opened by clicking the ![](../Pictures/Gui/ALL/all_plussign_as.png) sign.

X direction / Y direction:

The grid increment and the number of the grid [lines](Glossary_o_leitungen.htm) in the X and in Y direction are specified here.

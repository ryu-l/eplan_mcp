# P004103: Bus slave and bus master differ in the property 'Physical network: Name'

### Cause

Within a configuration project a bus slave and bus master that belong to the same logical network differ in regards to the Physical network: Name property.

### Solution

1. Locate the [bus ports](Glossary_o_sps_busanschluesse.htm) of the bus slave and of the bus master in the schematic by using the functionalities Go to (graphic) and Go to 2nd coordinate, which the popup menu of the Message management dialog offers you.
2. Call up the [property dialog](Glossary_o_eigenschaftendialog.htm) of the bus ports and in the Bus data tab check the value entered respectively in the Physical network: Name field.
3. Copy the value from the Physical network: Name field at the bus port of the master, insert it into the field by the same name at the bus ports of the slaves and confirm the entries.  
   Or alternatively for a manual change use the project correction with the setting Synchronize names of physical networks.
4. Then start a new check run.

# Coloring Components and Pipings with Linked Segments in the P&I Diagram

In order to recognize in the [P&I diagram](Glossary_o_ri_fliessbild.htm) which containers, [PCT loops](Glossary_o_plt_stellen.htm), [pipings](Glossary_o_rohrleitungen.htm) etc. are linked with [segments](Glossary_o_segmente.htm) in the pre-planning you can color these components and [objects](Glossary_o_objekte.htm) in the P&I diagram. This way these associated structures are detected in the diagram and possible corrections can be identified more easily.

Preconditions:

- You have opened a project containing pre-planning data.
- You have opened a page of the "P&I diagram" type.
- You have placed [process engineering](Glossary_o_verfahrenstechnik.htm) [symbols](Glossary_o_symbole.htm) that are connected via autoconnect [lines](Glossary_o_leitungen.htm) on this page.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Pre-planning > Navigator
2. Mark the segment whose subordinate structures you want to make visible in the P&I diagram.
3. Select the Properties popup menu item.
4. In the [property dialog](Glossary_o_eigenschaftendialog.htm) of the segment in the property table select the property Color for P&I diagram.
5. Open the [Color selection](mf_d_farbauswahl.htm) dialog with [...] and select the desired color there.
6. Select the following menu items: Options > Settings > Projects > "Project name" > Pre-planning > General
7. Activate the With assigned segment check box in the Color components and pipings in P&I diagrams group box in the Settings: General dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) After you have closed the [settings](Glossary_o_einstellungen.htm) dialog with [OK], the objects with linked segments are displayed in the selected color.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The [designations](Glossary_o_bezeichnungen.htm) and descriptions of the segments for which a color was specified with the Color for P&I diagram property, are displayed in the selected color in the pre-planning navigator.

![](../Pictures/Gui/ALL/info.png)Tip:

Activate the In pipings (without assigned segment) check box to additionally color the components that belong to such a piping but are without an assigned segment in the pre-planning.

![](../Pictures/Gui/ALL/note.png)Note:

If the check box With assigned segment is deactivated, neither the objects with linked segments nor the additional components in the pipings without link to the pre-planning are colored.

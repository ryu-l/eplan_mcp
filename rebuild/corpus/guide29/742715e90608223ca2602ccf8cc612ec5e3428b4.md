# Grouping Symbolic Addresses

The new Symbolic address: Group ([ID](Glossary_o_id.htm) 20610) property is available for [PLC connection points](Glossary_o_sps_anschluesse.htm). With this property you can group areas of [symbolic addresses](Glossary_o_symbolischeadressen.htm) in the assignment list, for example inputs, outputs, safety addresses, etc. To this purpose, this property can be shown as a column in the assignment list (menu [items](Glossary_o_bauteile.htm) Project data > PLC Addresses / assignment lists) and entered as a freely selectable designation.

The property is used during the PLC [data exchange](Glossary_o_datenaustausch.htm) in AutomationML format. This property is also available as a format element in the Row formatting in assignment list dialog.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

With this grouping of symbolic addresses, specific areas in the assignment list, for example safety addresses, can be grouped during the PLC data exchange in the AutomationML format.

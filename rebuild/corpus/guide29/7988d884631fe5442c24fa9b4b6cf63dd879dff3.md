# Graphical Macro Selection

You can use a graphical selection dialog for inserting [macros](Glossary_o_makros.htm). In this selection dialog, you can "browse" through the directory structure on the basis of stored [icons](Glossary_o_icons.htm), [symbols](Glossary_o_symbole.htm) or other image files and thus find the required macro easily. The graphical macro selection makes finding and selecting macros in a complex directory structure easier. Through a specific configuration in the company [settings](Glossary_o_einstellungen.htm), the graphical macro selection can be adapted directly to the special features of a company.

The use of the graphical macro selection is shown or hidden via the new [user-specific](Glossary_o_benutzerbezogen.htm) Use graphical macro selection setting. This setting can be found below the menu [items](Glossary_o_bauteile.htm) Options > Settings > User > Graphical editing > Macros.

If the check box is activated, the graphical macro selection is used at all positions in the EPLAN platform where macros are selected. This is true of the following [actions](Glossary_o_aktionen.htm):

- Insert macro (Insert > Window macro / symbol macro and Page > Page macro > Insert)
- Place macro in the [project data](Glossary_o_projektdaten.htm) [navigators](Glossary_o_navigatoren.htm) (via the popup menu item Place)
- Select macro in parts management.

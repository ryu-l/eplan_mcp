# Dialog Settings: Graphical macro selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > Company > Display > Graphical macro selection.

In this dialog you define the [settings](Glossary_o_einstellungen.htm) for the graphical macro selection.

Overview of the main dialog elements:

Toolbar:

The following buttons are available on the toolbar above the list:

| Button | Meaning |
| --- | --- |
| (New) | Creates a new empty row in the table. |
| (Delete) | Removes the currently selected row from the table. |

Directory:

Use this field to define the directory name that is to be replaced by the text in the adjacent field during the graphical macro selection. Click [...] to browse the directory tree in the Select directory dialog, and then select a directory.

Text:

In this field, store the text that is to replace the directory shown in the adjacent Directory field during the graphical macro selection.

Image:

Use this field to set the image that is to be displayed for the directory. Click [...] to open the Select image dialog and select another image.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

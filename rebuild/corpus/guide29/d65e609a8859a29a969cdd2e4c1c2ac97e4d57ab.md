# Dialog Update detailed planning

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Project data > Pre-planning > Navigator. You have selected one or more [segments](Glossary_o_segmente.htm) in the pre-planning navigator. Popup menu item Update detailed planning.

In this dialog you specify the updating scope for the detailed planning.

Overview of the main dialog elements:

Place [macros](Glossary_o_makros.htm) again:

If this check box is activated, the placements of the macros entered at the marked [planning objects](Glossary_o_planungsobjekte.htm) / [PCT loops](Glossary_o_plt_stellen.htm) are deleted and these macros are placed again. During this process, all [objects](Glossary_o_objekte.htm) are exchanged which are inside a macro box.

Update device tags and [symbolic addresses](Glossary_o_symbolischeadressen.htm):

If this check box is activated, the device tags of the [functions](Glossary_o_funktionen.htm) and [structure segments](Glossary_o_struktursegmente.htm) placed in the detailed planning are updated. In addition the symbolic addresses at the subordinate segments (planning objects, PCT [loops](Glossary_o_messstellen.htm)) in the pre-planning navigator and at the placed [PLC connection points](Glossary_o_sps_anschluesse.htm) are updated in the schematic. This is for example relevant when the [structure identifiers](Glossary_o_strukturkennzeichen.htm) and / or individual components of the symbolic address of higher-level segments have been modified in the pre-planning navigator.

Update value sets of [placeholder objects](Glossary_o_platzhalterobjekte.htm):

If this check box is activated, you can transfer the modified data from the pre-planning to the placeholder objects placed in the detailed planning. As the prerequisite macros have to be entered at one or more planning objects or PCT loops and these macros have to be placed in the detailed planning. Possible changes in the pre-planning are, for example, the selection of other value sets for the placeholder objects in the macros.

Update piping data:

If this check box is activated, the piping data are transferred from the piping planning objects to the defined [pipings](Glossary_o_rohrleitungen.htm) in the [P&I diagram](Glossary_o_ri_fliessbild.htm). In the process the pipe class, the associated [properties](Glossary_o_eigenschaften.htm) and the substance are transferred to the placed piping definition points and [connections](Glossary_o_verbindungen.htm). Only the pipe class and the associated properties are transferred at the functions in the pipings.

If a check box is deactivated, the respective objects are not updated in the detailed planning.

Synchronize parts:

If this check box is selected, the pre-planning parts are synchronized with parts in the detailed planning. In the process the [part](Glossary_o_artikel.htm) information at the [main functions](Glossary_o_hauptfunktionen.htm) in the detailed planning is deleted and replaced by the part information of the assigned segments.

# Piping Definitions in the P&I Diagram

A piping definition can be used to specify that a specific sequence of components, [connection symbols](Glossary_o_verbindungssymbole.htm) and [autoconnecting](Glossary_o_autoconnecting.htm) [lines](Glossary_o_leitungen.htm) in a [P&I diagram](Glossary_o_ri_fliessbild.htm) belong to a piping.

### Inserting piping definition points in the P&I diagram

For the definition of [pipings](Glossary_o_rohrleitungen.htm) you can on the one hand use the piping [planning objects](Glossary_o_planungsobjekte.htm) from the pre-planning. These are then placed from the pre-planning navigator in the P&I diagram. The result is a piping definition point with a reference to the piping planning object. The data of the piping planning object are assigned to the piping definition point.

On the other hand piping definition points can also be inserted directly - without assignment to a planning object, meaning without pre-planning - on a P&I diagram page. In this case an assignment to a planning object does not exist initially. However, a piping planning object can be assigned later on to a piping definition point.

Use a piping connection point to place the piping definition at the beginning of an autoconnecting line. It is possible to also subsequently assign a piping planning object to a piping connection point.

### Procedure

To define a piping place a piping definition point on an autoconnect line in the P&I diagram. If an assigned planning object does not exist, specify the piping name, the pipe class as well as the substance that is transported through this piping in the [property dialog](Glossary_o_eigenschaftendialog.htm) of this piping definition point. By means of this piping definition point you can have the piping [route](Glossary_o_verlegen.htm) displayed in the diagram and can edit its route.

If [devices](Glossary_o_betriebsmittel.htm) exist in the P&I diagrams (heat exchangers, shut-off control valves, etc.) at which the state of the substance changes, you can use further piping definition points to define these states. To this purpose you place additional piping definition points with the data of the respective piping (same piping name, pipe class, etc.) on the autoconnect lines before and after the respective device and enter the desired state.

### Route and source / target of a piping

The route of a piping, meaning which [connections](Glossary_o_verbindungen.htm) belong to a piping, is determined automatically and set by the potential transfer. In the process the piping route goes beyond a [component](Glossary_o_schaltzeichen.htm) if a suitable potential transfer is set in the connection point logic of the function.

The source and target of a defined piping are determined in accordance with the same rules as at connections. To exchange source and target of a piping you have the following possibilities:

- At the linked piping planning object in the pre-planning navigator via the menu [items](Glossary_o_bauteile.htm) Project data > Connections > Exchange source and target:   
  For a piping definition point that is located in the tree of the navigator below such a piping planning object the flow direction of the piping is adapted in the P&I diagram, if the source and target are specified at the linked piping planning object in the pre-planning. The source and target function of the piping in the P&I diagram must furthermore be linked with planning [objects](Glossary_o_objekte.htm) that correspond with the source and target [segments](Glossary_o_segmente.htm) at the piping planning object.
- At a piping definition point in the pre-planning navigator or in the P&I diagram via the property Piping: Exchange source and target ([ID](Glossary_o_id.htm) 33301):  
  However, this is only possible if the source and target at the linked piping planning object were not specified completely in the pre-planning.

If the source and / or the target in the P&I diagram do not match the source and / or target of the assigned piping from the pre-planning, this can be checked by using the check run "028027".

### Marking and editing the piping route

You can use the menu items Project data > Connections > Piping route to temporarily highlight the specified pipings in the P&I diagram and, if necessary, also edit the route of pipings.

The direction of flow of the piping is determined via source and target at the piping definition point when you have selected a piping definition point by means of the menu item Piping route. Wherever the source and target at the connection segments do not match the direction of flow of the piping, [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) are placed automatically for which the property Exchange source and target is activated. Through this the direction of flow is transferred to the complete piping.

The flow directions of the pipings can be permanently displayed by means of two special [symbols](Glossary_o_symbole.htm) from the SPECIAL symbol library. For further information please refer to the tips of the section "[Marking and Editing the Piping Route](planningri_h_rohrleitungmarkieren.htm#Tipps)".

### Piping interruptions

Pipings are displayed with interruptions in the P&I diagram in accordance with the standard DIN 28000-4:2014-07 if the piping course overlaps with another symbol (for example a [container](Glossary_o_behaelter.htm)) or another piping. To insert such interruptions in the P&I diagram, the PBR connection symbol is available in the SPECIAL symbol library.

### Reports for pipings in a P&I diagram

You can output the pipings defined for a project in the P&I diagram as a list by using the report type "P&I diagram: Piping overview".

All pipings, substances and pipe classes which are on a P&I diagram can be manually placed in certain [report types](Glossary_o_auswertungstypen.htm) as [embedded reports](Glossary_o_eingebetteteauswertungen.htm) in the respective P&I diagram. This has been enabled for the following report types:

- P&I diagram: Piping overview
- Preplanning: Pipe class overview
- Preplanning: Substance overview.

So that only the data of the current P&I diagram page is considered for such a report, you have to activate the Current page setting in the Select report dialog for the "Manual placement" output format.

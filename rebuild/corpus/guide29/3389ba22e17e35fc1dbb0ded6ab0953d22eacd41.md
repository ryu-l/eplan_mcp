# PLC

EPLAN supports you in planning and managing PLC control systems and bus systems. Data exchange with different [PLC configuration programs](Glossary_o_sps_konfigurationsprogramme.htm) is possible. The following editing options are available:

- All PLC information in a project can be displayed and edited in a single dialog.
- PLC information can be displayed on overview pages.
- PLC data can be edited on the schematic page, on the overview page, in the PLC navigator, or in the device navigator.
- You can readdress the [PLC connection points](Glossary_o_sps_anschluesse.htm).
- You can separately manage several PLC controllers.
- You can exchange PLC data ([assignment lists](Glossary_o_zuordnungslisten.htm)) with different PLC configuration programs using the export and import [functions](Glossary_o_funktionen.htm).
- The configuration data of the PLC controllers of bus systems can be exchanged with different PLC configuration programs.

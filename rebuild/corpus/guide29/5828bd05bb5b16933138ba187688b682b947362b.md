# Tab Master data (Changing Standards)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. If multiple [projects](Glossary_o_projekte.htm) are open: You have selected a project in the page navigator. Utilities > Change of standard. You have specified all of the [settings](Glossary_o_einstellungen.htm) in the Project tab. [Next]. You have specified all of the settings in the Rotation / flipping tab. [Next].

This tab lists all [master data](Glossary_o_stammdaten.htm) that is used in the project and that can be exchanged. Forms, [plot frames](Glossary_o_normblaetter.htm), [function definition libraries](Glossary_o_funktionsdefinitionsbibliotheken.htm), and [symbol libraries](Glossary_o_symbolbibliotheken.htm) belong here.

The following dialog elements are available:

Project master data:

One row shows the assignment of master data from the source library to the master data of the target library.

- Name: This column shows the master data used in the project. The name of the master data is displayed.
- Type: This column contains a description of the master data type. Master data types that can be exchanged in this dialog include symbol libraries, function definition libraries, [forms](Glossary_o_formulare.htm), and plot frames.
- Modification date: This column displays the date of the last changes to the master data of the source project.
- New name: In this column you can exchange master data. Click in a field and then click [...] to select the master data for the target project. If the fields are empty, the master data from the source project is copied to the target project.
- Individual assignment: This check box is only available for symbol libraries. If it is selected, [symbols](Glossary_o_symbole.htm) from the source and target symbol libraries can be individually assigned to one another. If the check box is deselected, the entire symbol library is assigned.

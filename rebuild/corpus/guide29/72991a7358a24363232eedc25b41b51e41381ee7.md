# Mechanical Modules for the 3D Mounting Layout

In the parts management it is now also possible to [create](Glossary_o_erstellen.htm) [modules](Glossary_o_module.htm) for the parts from the mechanics field. After you have marked the "Mechanics" generic product group, this is done as usual by using the menu [items](Glossary_o_bauteile.htm) New > Module. In contrast to other modules, mechanical modules may only contain parts and no other [assemblies](Glossary_o_baugruppen.htm) or modules.

The procedure for the mechanical modules correspondents more or less to the procedure for the other modules. You can find further information on this in the section "[Parts Management: Modules](partsmanagementgui_k_module.htm)".

A mechanical module for the 3D mounting layout stands for a standard item that has been delivered as a whole to a manufacturer by another manufacturer (for example, an enclosure socket that consists of different elements such as socket corner piece, socket orifice, [cable](Glossary_o_kabel.htm) rail, etc.).

When [placing](Glossary_o_auflegen.htm) mechanical modules in a [layout space](Glossary_o_bauraum.htm), the length of the length-variable items are determined from the stored macro and the [part](Glossary_o_artikel.htm) reference data is entered in the property Subset / length ([ID](Glossary_o_id.htm) 31008). Snap points are displayed for a mechanical module during the placement so that a module can be adjoined multiple times.

# Selecting Devices

In device selection, you assign one device to another device; the assigned device may contain one or more parts. The data from the [function definitions](Glossary_o_funktionsdefinitionen.htm) is assigned to the device. This data is entered in the parts management, in the function definitions table of the Function templates tab.

Device selection can be called up from different places:

- From the Properties <...> dialog
- From the Bill of materials navigator.

### Select devices in the Properties <...> dialog

Precondition:

You have opened the Properties <...> dialog for a [component](Glossary_o_schaltzeichen.htm) and have selected the Parts tab.

1. Click [Device selection].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Main parts list contains all the parts from the parts management module that are suitable for the selected device and for which the Accessories check box on the Accessories tab is not selected.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Selected parts: Functions / templates list displays the [functions](Glossary_o_funktionen.htm) of the current device.
2. If you want to, for example, change the selection criteria for the device selection, click [Settings].
3. In the Settings: Device selection dialog, edit the [settings](Glossary_o_einstellungen.htm) and click [OK].
4. If you want to enter additional functions, click [...] next to Automatic filter field.
5. In the Automatic filter: Device selection dialog carry out the filter settings for the technical values of the parts and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Main parts list shows the filtered parts.
6. Highlight a [part](Glossary_o_artikel.htm) in the Main parts list.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Accessories list shows the [accessories](Glossary_o_zubehoer.htm) of the highlighted part (if applicable).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Selected parts: Functions / templates list shows - in a preview - the device functions to which a function template of the part is assigned and whether there are any remaining empty [function templates](Glossary_o_funktionsschablonen.htm).
7. Select the part you want from the Main parts list (or an accessory part from the Accessories list), and click ![](../Pictures/Gui/ALL/all_arrowdown_as.png) beneath the list. (If you highlighted an accessory part, you can transfer the accessory and the associated part by using ![](../Pictures/Gui/ALL/all_arrowdowndouble_as.png).)  
     
   ![](../Pictures/Gui/ALL/arrow.png) You have completed the part selection. This is clarified in the list Selected parts: Functions / templates with an additional icon (a check mark) before the function templates of the part.
8. If function templates are not yet assigned to all the functions of the device, select a further part from the Main parts or Accessories lists.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the Selected parts: Functions / templates list the associated function templates of the parts are shown in alternating colors. Preview rows are shown in italics.
9. Click ![](../Pictures/Gui/ALL/all_arrowdown_as.png) below the list to transfer the part into the Selected parts: Functions / templates list. If necessary, select more parts until all the device functions are overlaid by suitable part function templates.
10. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The part numbers are transferred to the Properties <...> dialog.
11. Exit the Properties <...> dialog by clicking [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) All the part numbers entered in the Properties <...> dialog are searched for in the parts database and the associated parts are stored in the project. In the process, the relevant data source for each part is also read, according to the parts data. The function templates of the part are also stored.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The part [properties](Glossary_o_eigenschaften.htm) of the first selected part are written to the current device (for example Cable type, Connection: Cross-section / diameter, Connection point designation, Technical characteristics, etc.).  
      
    ![](../Pictures/Gui/ALL/arrow.png) The data from the function templates of the [stored parts](Glossary_o_eingelagerteartikel.htm) is written to the current device (main function) and its [auxiliary functions](Glossary_o_nebenfunktionen.htm).  
      
    ![](../Pictures/Gui/ALL/arrow.png) If a part was already assigned to a device, its data will be overwritten without further warning by the data of the first selected part. A conflict dialog as in the part selection is not displayed at the device selection.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The data entered for the component (e.g., [connection point designations](Glossary_o_anschlussbezeichnungen.htm)) is retained and will not be overwritten by data from the parts management dialog. These deviations are flagged during a project check.

### Select devices in the bill of materials navigator

1. Project data > Parts / Devices > Bill of materials navigator
2. Highlight a part reference and go to Popup menu > Device selection.
3. In the Device selection dialog, select the part(s) you want as described above.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts data is transferred to the Bill of materials - <Project name> dialog, meaning that the [part references](Glossary_o_artikelreferenzen.htm) are updated.

![](../Pictures/Gui/ALL/note.png)Note:

During the selection of a part, that has an older state in the project than in the parts database, a prompt is shown. You can then decide whether you want to select this updated part or rather another part. In specific cases (for example, in the case of changed template data) the device data for the updated parts are possibly not transfered to all usages of the part in the project.  
The popup menu item Update device data is available to you in the bill of materials navigator to allow for updating the device data at the functions in the project in such a case nevertheless.

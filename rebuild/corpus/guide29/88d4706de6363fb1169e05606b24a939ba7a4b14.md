# Creating Plot Frames

When generating a plot frame, the Plot frame properties - <Plot frame name> dialog is opened in which you specify the most important [properties](Glossary_o_eigenschaften.htm) of the new plot frame. (This dialog can also be called up for an opened plot frame after the event to allow you to change the properties at any time.)

Precondition:

You have opened a project.

1. Utilities > Master data > Plot frame > New
2. In the
   Create plot frame dialog, select the drive
   and directory, in which the new plot frame should be saved.
3. In the
   File name field, enter a descriptive name
   for the plot frame.
4. In the
   Path field, select the Go to default popup menu item if you would like
   to [return](Glossary_o_zurueckbuchen.htm) to the default [settings](Glossary_o_einstellungen.htm) for drive and directory. (The default directory
   is either the program-specific default setting <Program Drive>:
   \<Program Directory>\Plot frames\<Company Code> or
   the setting specified under the
   Options > Settings > User > Management > Directories menu [items](Glossary_o_bauteile.htm).)
5. Click [Save].
6. In the
   Plot frame properties - <Plot frame name> dialog, select the properties to be shown in the list
   from the Category drop-down list.
7. Specify
   the values for the properties, either by making or overwriting an entry
   or by selecting a preset value from a drop-down list.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new plot frame is saved according to your entries
   and displayed in the plot frame editor.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The point of origin if the plot frame is indicated by a red circle, analog to the outline editor and the [symbol editor](Glossary_o_symboleditor.htm). The position of the point of origin is taken into consideration during zooming, but cannot be moved manually.

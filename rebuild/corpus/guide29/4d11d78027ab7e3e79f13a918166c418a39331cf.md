# Creating Parts

In the Parts management dialog, you can [create](Glossary_o_erstellen.htm), edit, and organize your [master data](Glossary_o_stammdaten.htm). Using [Extras] > Settings select the database that you want to edit.

In the left area of the dialog, the data to be managed is displayed in a tree or list, where the hierarchical structure of the tree contains the following [levels](Glossary_o_etagen.htm):

- Part; configuration of the displayed hierarchy is possible via the [Tree configuration](partsmanagementgui_d_baumkonfiguration.htm)
- Accessory list
- Accessory placement
- Drilling pattern
- Connection point pattern
- Customer
- Manufacturer / supplier

Within a trade, the parts are divided into "Components", "Assemblies", and "Modules". Cables and housings are included in the components group.

For parts which cannot be clearly categorized as electrical components or fluid technology components, the trade "Mechanics" is available. This contains general and mechanical data (e.g. from EPLAN Pro Panel).

### Creating Parts

Preconditions:

- You have opened the parts management: Utilities > Parts > Management.
- You have marked an entry in the tree or in the list.

1. Select the New popup menu item and, depending on the current selection, select one of the Component, Assembly, or Module entries from the subsequent menu.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have highlighted the hierarchy level of the [product groups](Glossary_o_produktgruppen.htm), EPLAN automatically generates a new [part](Glossary_o_artikel.htm) with the part number New\_<consecutive\_number>.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have highlighted the hierarchy level of the part number, EPLAN automatically generates a new part with the part number <original\_part number>\_<consecutive\_number>.
2. Enter the data for the part into the tabs on the right side of the dialog.

### Creating variants

Precondition:

In the Tree or in List, you have highlighted a Part number.

1. Select the New variant popup menu item.
2. Provide the designation for the new variant of the current part in the subsequent dialog. Valid [designations](Glossary_o_bezeichnungen.htm) are 0 through 9 and A through Z.

![](../Pictures/Gui/ALL/note.png)Note:

Part and variant numbers must be unique. If you accidentally enter a designation which already exists, EPLAN warns you as soon as you click [Apply] or [Close]. The record can only be saved after you have assigned a new part number.

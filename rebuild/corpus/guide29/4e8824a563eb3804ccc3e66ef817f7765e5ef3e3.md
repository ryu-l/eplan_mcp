# P501029: The part <z>, variant <u>, entered at the module <x>, variant <y>, has neither a DT nor a DT ID

### Cause

In the parts database to be checked a module was determined at which a subpart (so-called module position) is entered without DT and DT [ID](Glossary_o_id.htm). The [part](Glossary_o_artikel.htm) number of the module is output in the placeholder <x>, the variant of the module in the placeholder <y>, the part number in the placeholder <z>, and the variant of the entered subpart <u> in the placeholder <u>.

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective variant of the subpart entered at the module is already marked in it.
2. Bring the Module tab to the foreground.
3. Assign a corresponding value in the DT field and / or in the DT ID field.
4. Close the parts management, save the modified data, and carry out a parts synchronization.
5. Then start a new check run.

# P020040: The sequence of the project structures for pages was changed from '<x>' to '<y>'

### Description

You have run a project comparison, checking the structure of the test project (incoming project) against that of the comparison project and differences were found.

This message shows if, in the project to be checked, changes were made to the logical order of the [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) in the Page structure dialog. In the message in the <x> placeholder the order of the identifier [blocks](Glossary_o_bloecke.htm) of the comparison project is output and in the <y> placeholder the identifier blocks of the incoming project.

![](../Pictures/Gui/ALL/note.png) Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

# Inserting Net Definition Points

With a net definition point you specify the [properties](Glossary_o_eigenschaften.htm) of a net, for example the net name. You can also define the [net-based connections](Glossary_o_netzbasierteverbindungen.htm) here.

Precondition:

You have opened a project. You are in a page within the graphical editor.

1. Select the Insert > Net definition point menu [items](Glossary_o_bauteile.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol for the net definition point is attached to the cursor.
2. To place the net definition point, click into the schematic.
3. In the Properties <...> dialog, enter the properties of the network in the Net definition tab.
4. In the Net connections tab specify the [connections](Glossary_o_verbindungen.htm) within the network.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The properties are assigned to the connections defined with the net definition point.

![](../Pictures/Gui/ALL/info.png)Tips:

- With the user setting (Options > Settings > User > Graphical editing > Connection symbols), you can specify that the Specify targets property at the [connection symbols](Glossary_o_verbindungssymbole.htm) of the associated net is automatically deactivated when inserting a net definition point.
- You can insert multiple [net definition points](Glossary_o_netzdefinitionspunkte.htm) at the same time by holding the left mouse button down and pulling the cursor over multiple autoconnect [lines](Glossary_o_leitungen.htm). A net definition point is then placed on each autoconnect line that is intersected.

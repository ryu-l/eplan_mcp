# Cross-references: Basics

It is often necessary to represent the same device several times. The relationship of the appropriate components to this device is recognized by the program by the fact that all these components have the same device tag and are identified by the appropriate function definition. The cross-reference then shows where each other [part](Glossary_o_artikel.htm) of the device is to be found in the schematic. The following variations are possible for this:

- Device [cross-references](Glossary_o_querverweise.htm) between general components (in this way, [functions](Glossary_o_funktionen.htm) displayed in a distributed manner are identified as "connected")
- Contact cross-references in the [contact image](Glossary_o_kontaktspiegel.htm) (cross-references between the complete display of contactor or motor overload switch contacts, and the individual contacts of this device that are displayed distributed over the schematic)
- Interruption point cross-references between [interruption points](Glossary_o_abbruchstellen.htm)
- Pair cross-references (cross-references between the complete display of motor overload switch, or [load](Glossary_o_laden.htm) circuit breaker, contacts and the individual contacts of this device that are displayed distributed over the schematic).

EPLAN automatically (online) inserts device, contact, and [interruption point cross-references](Glossary_o_abbruchstellenquerverweise.htm) into the [project data](Glossary_o_projektdaten.htm) while the schematic is being edited. For [pair cross-references](Glossary_o_paarquerverweise.htm), this automation only occurs if the affected [component](Glossary_o_schaltzeichen.htm) of a device is made cross-reference capable via a specific setting.

The cross-reference display depends on the following factors:

- Structure and layout of the plot frame
- The [settings](Glossary_o_einstellungen.htm) for the cross-references; these are taken either from the project settings or from the respective device.

![](../Pictures/Gui/ALL/note.png)Note:

Note especially in connection with the [properties](Glossary_o_eigenschaften.htm) of the components the Cross-reference display ([ID](Glossary_o_id.htm) 20021) property; this property can assume the following values:   
0 = Automatic display: Cross-references are displayed only if the displayed DT is not empty.  
1 = Never display: Cross-references are never displayed.  
2 = Always display: Cross-references are always displayed, regardless of whether the displayed DT is empty or not.

With respect to the plot frame being used, the following should be noted for the display of cross-references: In contrast to components placed within the plot frame, cross-references for components inserted outside the plot frame do not contain a column designation. Inversely, a complete cross-reference with page and column [designations](Glossary_o_bezeichnungen.htm) is created from the component within the plot frame to the component outside the plot frame.

A cross-reference with page and column designations is created at an interruption point outside the plot frame, pointing to an interruption point inside the plot frame. However, the interruption point placed outside the plot frame can't [create](Glossary_o_erstellen.htm) a valid column designation in the cross reference of the interruption point inside the plot frame.

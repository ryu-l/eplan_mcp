# Tab DXF General (NC Export DXF / Copper Export DXF)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Machining > NC export DXF. Select the General tab.
- Utilities > Manufacturing data > Machining > NC DXF. Click [...] next to the Machine field. Select the General tab.

In this tab, you specify the general [settings](Glossary_o_einstellungen.htm) of the NC export in the DXF format used by many machines.

Overview of the main dialog elements:

Group box Format

AutoCAD version:

Here in the AutoCAD version you select the format in which the [DXF](Glossary_o_dxf.htm) data is to be exported:

- AutoCAD 2013/2014/2015/2016/2017
- AutoCAD 2018/2019.

Code page:

Setting as to the character set that is to be used. The default is the Windows character set CP\_ANSI\_1252.

---

Output directory:

In this field, you set the storage location for the DXF file to be generated. You can specify any drive and subdirectory as the target for the export.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).

Generate file names:

In this drop-down list you specify the default method for allocating file names during the DXF export:

- From consecutive number: If you select this option, EPLAN assigns names to the DXF files using the pattern <Consecutive number>.DXF by default. If DXF files already exist, EPLAN starts the numbering with the next available number.
- From item designation: If you select this option, EPLAN assigns names to the DXF files using the pattern <Item designation>.DXF by default.
- From properties: If you select this option, the file name is made up of the [layout space](Glossary_o_bauraum.htm), project, and device [properties](Glossary_o_eigenschaften.htm) plus any freely-definable separators. Use the [...] button to open the Format: Property dialog to configure the file name.

Generate subdirectories:

In this drop-down list you specify the default method for generating subdirectories during the DXF export:

- None: If you select this option, no subdirectories are generated during the export.
- From project structure: If you select this option, subdirectories that reflect the [project structure](Glossary_o_projektstruktur.htm) are automatically generated during the export.
- From properties: If you select this option, the subdirectory name is made up of the layout space, project, and device properties plus any freely-definable separators. Use the [...] button to open the Format: Property dialog to configure the file name. Here you can, for instance, use the "Directory [separator](Glossary_o_trennzeichen.htm)" format element to [generate](Glossary_o_erzeugen.htm) a directory structure with several subdirectories arranged one below the other.

# P028007: Differing parts or number / quantity of parts between main function and associated planning object

### Cause

In the Parts tab of the main function belonging to a planning object and in the tab of the same name of the planning object (Properties <...> dialog), different parts entries and / or numbers of units / quantities were specified.

### Solution

1. Locate the main function and associated planning object in the pre-planning navigator using the Synchronize selection function offered by the popup menu in the Message management dialog.
2. Open the Properties <...> dialog of the main function and the associated planning object, and, for both [objects](Glossary_o_objekte.htm), respectively, bring to the front the Parts tab.
3. Compare the entries in the columns Part number and / or Number of units / quantity at the main function and the associated planning object.
4. Standardize the entries for both objects if there is a discrepancy regarding the [properties](Glossary_o_eigenschaften.htm) Part number and / or Number of units / quantity, and save the modified data.
5. Then start a new check run.

# Tab Machine (Automatic Equipment Rittal - Athex)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Automatic equipment > Rittal - Athex. Select the Machine tab.
- Utilities > Manufacturing data > Automatic equipment Rittal - Athex. Click [...] next to the Machine field. Select the Machine tab.

In this tab you define the machine [settings](Glossary_o_einstellungen.htm) for the automatic equipment system Rittal - Athex.

Overview of the main dialog elements:

Maximum rail length:

In this field you enter the maximum length of the mounting rail that the machine is to equip. The machine can process rail lengths of 150 mm to 1200 mm. Mounting rails that are longer than the value specified here are not exported.

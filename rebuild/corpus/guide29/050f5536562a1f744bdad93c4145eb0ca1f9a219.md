# New Connection Categories for Connection Point Patterns

In the Settings: Connection category dialog you determine the [connection categories](Glossary_o_anschlussausfuehrungen.htm) which are offered and used as defaults when managing [connection point patterns](Glossary_o_anschlussbilder.htm) in parts management. New pre-defined connection categories in accordance with the [eCl@ss](Glossary_o_eclass.htm) classification are now available in this dialog. We recommend only using the new connection categories for the creation of new connection point patterns.

This dialog can be accessed by selecting the Options > Settings > Company > Management > Connection category menu path.

The following connection categories are new and conform to the eCl@ss classification:

- Screw connection
- Spring-cage connection
- Push-in connection
- Penetration connection
- Plug-in connection
- Plug-in terminal connection
- Bolt connection
- Flat connector
- Crimp terminal
- Ribbon connection
- Rail connection
- Solder tail connection
- Wrap connection

![](../Pictures/Gui/ALL/benefit.png)Benefit:

During the creation of connection point patterns you can now use connection categories conforming to the eCl@ss classification.

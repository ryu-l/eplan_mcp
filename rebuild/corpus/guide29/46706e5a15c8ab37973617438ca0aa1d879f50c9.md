# Dialog Format: Property

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call (in the form editor):](javascript:void(0);)

You have opened a project. Utilities > Master data > Form > Open > [Open].

- Insert > Placeholder text. Select the Placement tab in the subsequent dialog and click [...] next to the Properties formatted / calculated field.
- You have double-clicked a placeholder text (or have selected the Properties popup menu item. In this case several texts can also be marked). Select the Placement tab in the subsequent dialog and click [...] next to the Properties formatted / calculated field.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call (generate DXF / DWG file name):](javascript:void(0);)

Options > Settings > User > Interfaces > DXF / DWG export and import. Select the Export tab, select the entry "From [properties](Glossary_o_eigenschaften.htm)" in the Generate file names field, and click [...].

In this dialog you can specify [format elements](Glossary_o_formatelemente.htm) and / or a calculation formula for the placeholder text or you specify the properties that are to be used for the generation of the [DXF](Glossary_o_dxf.htm) / [DWG](Glossary_o_dwg.htm) file name.

Overview of the main dialog elements:

Available format elements:

This field shows all format elements that can be selected and formatted for the placeholder text. The format elements that are available depend on the selected [form](Glossary_o_verlauf.htm) type.

Selected format elements:

This field displays all format elements that you have selected. To select a format element, select a format element from the Available format elements field and then click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).

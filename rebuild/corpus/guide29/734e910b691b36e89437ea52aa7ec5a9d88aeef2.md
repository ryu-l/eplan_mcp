# Dialog Sorting (bundles)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have created [routing connections](Glossary_o_verlegeverbindungen.htm). Routing [connections](Glossary_o_verbindungen.htm) are highlighted in the connections navigator. Select the menu [items](Glossary_o_bauteile.htm) Project data > Connections > Bundle. In the dialog Bundle routing connections click the [...] button in a line under Bundling scheme in the table. In the Settings: Bundle dialog click the [...] button in the Sorting field.

In this dialog you define [schemes](Glossary_o_schemata.htm) and criteria in accordance with which routing connections are sorted into [bundles](Glossary_o_straenge.htm).

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Category / property:

This list displays the criteria that are used to [generate](Glossary_o_erzeugen.htm) bundles. All connections in a [bundle](Glossary_o_buendel.htm) are assigned the same bundle number. To define the rules for the generation of the bundles, several criteria can be combined with each other. In this case, the [wires](Glossary_o_draehte.htm) are combined into a bundle where all criteria are met. Thus, when combining the source and target, both are taken into account.

When the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button is clicked, the dialog Criteria selection is displayed in which you can select [properties](Glossary_o_eigenschaften.htm) from the source, target and connection sections by which the connections are to be sorted into new bundles.

The following table shows examples for possible sorting criteria:

| Criterion | Meaning |
| --- | --- |
| Grouping sign for item designation (automatic) | Through the use of this property a sorting criterion the bundling for each enclosure or mounting panel is done separately. First, the first enclosure from the first [layout space](Glossary_o_bauraum.htm) is bundled, then the second enclosure from the first layout space, then the other enclosures from the first layout space, then all enclosures from the second layout space, etc. If there are only [mounting panels](Glossary_o_montageplatten.htm) in the layout spaces, they will be treated as enclosures and evaluated in the same sequence. If there are enclosures and mounting panels in the layout spaces, the enclosures will be evaluated first, followed by the mounting panels.  The program numbers the bundles in a graphically sorted manner in the following sequence:   - Targets of the connections are sorted. - Connections are sorted based on the first target of each connection. In case of several identical positions, the sorting will be determined by the position of the respective graphically last target of the connection. - Then, the connections are sorted in bundles consecutively. - The bundles are numbered in the sequence in which they were created. |
| DT source | All wires with the same DT of the source are combined into one bundle. |
| DT target | All wires with the same DT of the target are combined into one bundle. |
| Net | All connections of a net are given the same bundle number. Under the term "net", we include all [connection points](Glossary_o_anschluesse.htm) of [devices](Glossary_o_betriebsmittel.htm) that are connected to each other by means of electrical connections.  The use of this setting alone does not optimize the [wiring](Glossary_o_verdrahtungen.htm) during automatic bundling. The source and target of the connection are not exchanged. |
| Color / number | All wires with the same Color number connection property are combined into one bundle. |
| Cross-section / diameter | All wires with the same Cross-section or Diameter connection property are combined into one bundle. |
| Bundle group | All wires with the same Bundle group connection property are combined into one bundle. |
| Connection: Type designation | All wires with the same Type designation connection property are combined into one bundle. |
| Part number (1st main part) | All wires with the same Part number connection property are combined into one bundle. |
| Mounting surface | All wires on [mounting surfaces](Glossary_o_montageflaechen.htm) that contain the connected [functions](Glossary_o_funktionen.htm) are combined into one bundle. |
| Connection point designation | All wires with the same connection point designation at the functions connected by the connection are combined into one bundle. |
| Connection point description | All wires with the same connection point description at the functions connected by the connection are combined into one bundle. |
| Terminal / pin description | All wires with the same terminal / pin description at the functions connected by the connection are combined into one bundle. |

Toolbar:

The following buttons are available on the toolbar above the list:

| Button | Meaning |
| --- | --- |
| (New) | Opens the Criteria selection dialog for selecting sorting criteria. |
| (Delete) | Deletes the selected sorting criterion from the list. |
| (Move up) | Moves the selected sorting criterion one line upwards. This allows you to specify the order of the display. |
| (Move down) | Moves the selected sorting criterion one line downwards. This allows you to specify the order of the display. |

By connection point position

Devices whose connection points are located on two or more connection point [layers](Glossary_o_ebenen.htm) over each other are wired during manufacturing from bottom to top. To this purpose it should be possible to combine the wires per connection point layers in a bundle. The following check boxes are available as sorting and bundling [settings](Glossary_o_einstellungen.htm) in order to ensure this requirement:

- Source X, Target X
- Source Y, Target Y
- Source Z, Target Z.

These settings take into consideration the position specifications X-position, Y-position and Z-position in a global or local connection point pattern of a [part](Glossary_o_artikel.htm) placement. When these check boxes are activated, wires from and to connection points with the same position specification are sorted correspondingly into common bundles.

# Tab Format (device)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have inserted a symbol in the graphical editor containing formattable graphical components (e.g., a black box, a shield, or a [cable](Glossary_o_kabel.htm) definition line), or you have generated a corresponding function in a navigator. In the Properties dialog, select the Format tab.
- You have selected a symbol in the graphical editor containing formattable graphical components (e.g., a black box, a shield, or a cable definition line), or you have generated a corresponding function in a navigator. Edit > Properties. In the Properties dialog, select the Format tab.
- The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open. You have inserted an auxiliary line or double-clicked an auxiliary line. In the Properties dialog, select the Format tab.

On this tab, you can edit the display [properties](Glossary_o_eigenschaften.htm) of the graphical elements of a symbol, like the view of [black boxes](Glossary_o_geraetekaesten.htm) or [PLC boxes](Glossary_o_sps_kaesten.htm), [shields](Glossary_o_abschirmungen.htm), [cable definition lines](Glossary_o_kabeldefinitionslinien.htm), etc.

Overview of the main dialog elements:

Property / Assignment:

To this purpose the hierarchy [levels](Glossary_o_etagen.htm) <Graphical element> and Format are available. These can be opened by clicking the ![](../Pictures/Gui/ALL/all_plussign_as.png) sign.

![](../Pictures/Gui/ALL/note.png)Note:

For editing the graphical data of connections, the Connection graphic tab is displayed instead of the Format tab; it provides the following setting possibilities:

- [Tab Connection graphic](devicetaggui_r_verbindungsgrafik.htm)

For part placements in the layout space, only the Format hierarchy level is available; it contains the [settings](Glossary_o_einstellungen.htm) described in the following section:

- [Tab Format (3D part placement)](devicetaggui_r_format3d.htm)

---

<Graphical element> hierarchy level

Here you determine specific settings for the graphical element such as, e.g., coordinate and length entries. Depending on the type of graphical element, one of the following hierarchy levels will be displayed here:

- [Line](gededitgui_r_linie.htm)
- [Polyline](gededitgui_r_polylinie.htm)
- [Rectangle](gededitgui_r_rechteck.htm)
- [Shield](gededitgui_r_rechteck.htm)

---

Format hierarchy level

Invisible:

Choose the entry "Yes" from the drop-down list if the element is not supposed to be visible on the schematic page. It is still present in the project, however. In the [user settings](gedviewer_d_einstellungenbenutzerallgemein.htm), you define whether or not invisible elements are to be displayed and / or printed (in a different color).

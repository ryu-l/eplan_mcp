# Tab General (Settings: Cable (Cable connections))

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Options > Settings > Projects > "Project name" > Devices > Cable (Cable connections). Select the General tab.

This tab is used to define whether [autoconnecting](Glossary_o_autoconnecting.htm) [lines](Glossary_o_leitungen.htm) are colored by potential or by [cable](Glossary_o_kabel.htm).

Overview of the main dialog elements:

Representation of the autoconnecting line:

Select the Cable-oriented option if you want the autoconnecting lines to be colored by cable, or the Potential-oriented option if you want them to be colored by potential.

# Generating Macros from a Macro Project

You can [generate](Glossary_o_erzeugen.htm) [macros](Glossary_o_makros.htm) automatically in [macro projects](Glossary_o_makroprojekte.htm).

![](../Pictures/Gui/ALL/info.png)Tip:

You can automatically group the macros in the macro project before generation and / or automatically activate the handles. To this purpose select the menu [items](Glossary_o_bauteile.htm) Project data > Macros > [Prepare macros for automatic generation](macrosgui_d_makrosvorbereiten.htm).

### Generating window or symbol macros automatically

Preconditions:

- You are in a macro project.
- You have opened a page that contains [objects](Glossary_o_objekte.htm) (such as schematic [cut-outs](Glossary_o_durchbrueche.htm), graphics, etc.), from which macros are to be generated automatically.

1. Select Insert > Box / connection point / mounting panel > Macro box.
2. Use the mouse to drag the frame around the desired objects.
3. Repeat these steps until all the [macro boxes](Glossary_o_makrokaesten.htm) are defined.
4. End the action via the Cancel action popup menu item or via the [Esc] button.
5. Double-click a macro box.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The entry "Defining" is preset for the Type of usage drop-down list in the [Macro box](macrosgui_r_makrokasten.htm) tab of the [property dialog](Glossary_o_eigenschaftendialog.htm). This has the effect that the "Referencing" type of usage is assigned to the automatically generated macros when being inserted into a schematic and / or macro project, meaning that they can be updated if required.
6. Enter the data for the macro to be generated in this tab. In order for a macro to be generated you have to specify at least one macro name in the Name field. If you do not specify a file extension, a window macro (\*.ema) is generated from the respective macro box. To generate [symbol macros](Glossary_o_symbolmakros.htm) enter the macro name including the file extension (\*.ems).
7. Click [OK].
8. Repeat Steps 5 - 7 for all further macro boxes.
9. Select the menu items Project data > Macros > Generate automatically.
10. Activate the Overwrite existing macros check box in the Generate macros automatically dialog if you want to overwrite existing macros during generation in the specified macro directory
11. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The areas identified above the macro boxes are stored as window and / or symbol macros into the specified macro directory. When doing this the necessary data is taken from the macro box [properties](Glossary_o_eigenschaften.htm).  
      
    ![](../Pictures/Gui/ALL/arrow.png) The result of the automatic generation is displayed in the System messages dialog.

![](../Pictures/Gui/ALL/info.png)Tip:

Macro boxes can also be drawn as [polylines](Glossary_o_polylinien.htm) by using the MC2 symbol. To do so, select the symbol in the Symbol selection dialog and specify the starting point of the box by clicking the left mouse button inside the schematic. After you have specified all of the other points, complete the task via the Complete polyline popup menu item.

### Generating page macros automatically

Preconditions:

- You are in a macro project.
- You have inserted objects on at least one page (e.g., schematic cut-outs, graphics, etc.), from which macros are to be automatically generated.

1. Mark one or more pages in the page navigator.
2. Select the Properties popup menu item.
3. Specify the data for the macro to be generated in the Page tab of the Page properties dialog. In order to [create](Glossary_o_erstellen.htm) a page macro, you have to specify at least one macro name in the Macro: Name property. In order to generate multi-page [page macros](Glossary_o_seitenmakros.htm) enter the same macro name into the page properties of several pages in the respective tab Page.
4. Enter any further data for the macro (such as Macro: Version) in the properties table on the Page tab.
5. Click [OK].
6. Repeat Steps 1 - 4 for all further page for which you want to generate page macros.
7. Select the menu items Project data > Macros > Generate automatically.
8. Activate the Overwrite existing macros check box in the Generate macros automatically dialog if you want to overwrite existing macros during generation in the specified macro directory.
9. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The page macros (\*.emp) are stored in the specified macro directory. When doing this the necessary data are taken from the page properties.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The result of the automatic generation is displayed in the System messages dialog.

![](../Pictures/Gui/ALL/info.png)Tip:

If you want to assign a prepared macro box or a prepared page to several macros, use the Macro definition tab. Enter the respective name and the description of the macros to be generated in the [lines](Glossary_o_leitungen.htm) of this tab. During automatic generation the same content (same macro box or same page) is stored in several macros.

# P501027: Connection point data at the bus port are filled

### Cause

In the parts database to be checked a [part](Glossary_o_artikel.htm) was found at which a function template is defined with the "Network / bus [cable](Glossary_o_kabel.htm) connection point" function definition. At this function template values are assigned to the connection point data ([connection point designations](Glossary_o_anschlussbezeichnungen.htm), [connection point descriptions](Glossary_o_anschlussbeschreibungen.htm), connection point cross-section and / or [connection dimension](Glossary_o_anschlussmass.htm)).

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective part is already marked in it.
2. Bring the Function templates tab to the front.
3. Delete the values in the Connection point [designations](Glossary_o_bezeichnungen.htm), Connection point descriptions, Connection point cross-section and Connection dimension fields at the function template.
4. Close the parts management, save the modified data, and carry out a parts synchronization.
5. Then start a new check run.

# P027025: Terminal strip definition exists several times in the same routing path network

### Cause

A terminal strip definition with the same DT was placed several times within the routing path network.

![](../Pictures/Gui/ALL/note.png)Note:

A terminal strip definition with the "Topology" representation type may occur several times in the project, but only once in a routing path network.

### Solution

1. In the routing path network locate the [terminal strip definitions](Glossary_o_klemmenleistendefinitionen.htm) occurring several times in the routing path network using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the dialog Properties <...> for each of these terminal strip definitions respectively and assign a unique device tag in the Displayed DT field.
3. Start a new check run after you have changed the device tags.

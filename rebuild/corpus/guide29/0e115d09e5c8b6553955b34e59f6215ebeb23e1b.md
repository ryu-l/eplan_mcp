# Tab AutoCorrect

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Translation > Edit dictionary. Select the AutoCorrect tab.

In this tab you can manage a list of words that are not to be used in project pages and are automatically replaced. This makes it possible to guarantee the uniform usage of words.

Enter a replacement text for each word that is not to be used. The unwanted words will then be replaced during translation. Only the words in the source language are automatically replaced. The unwanted words for the other [display languages](Glossary_o_anzeigesprachen.htm) are not replaced. In the User tab of the translation [settings](Glossary_o_einstellungen.htm), the AutoCorrect check box must be selected.

Overview of the main dialog elements:

Dictionary language:

Select the dictionary language.

Find:

Use this field to search for all of the [keywords](Glossary_o_stichworte.htm) that have already been added to the list of words that are to be used in the AutoCorrect. To search for a keyword, enter it in the input field. To show all replacement texts for a keyword, select the desired keyword in the keyword list. The keyword is displayed in the Replace field. The replacement text is displayed in the With field.

Replace:

In this field you edit the keyword that you would like to replace. Use the toolbar to [create](Glossary_o_erstellen.htm), save, copy and delete a keyword for the AutoCorrect function.

With:

Enter a replacement text in this field. When translating, and when the "AutoCorrect" function is activated, the keyword in the Replace field is replaced by this replacement text.

Toolbar:

| Button | Meaning |
| --- | --- |
| (New) | Creates an empty keyword in the chosen source language. |
| (Save) | Saves the change or a new word pair. |
| (Copy) | Copies a word. The copy obtains the addition "(Copy)". |
| (Delete) | Deletes a word from the list of blocked terms. |

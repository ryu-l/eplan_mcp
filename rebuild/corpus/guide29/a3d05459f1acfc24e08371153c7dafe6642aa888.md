# Creating Settings Comparison Schemes

In a [settings](Glossary_o_einstellungen.htm) comparison scheme you specify which settings should be compared with each other in the project comparison operation of the project verification. EPLAN can use this scheme to compare all settings that you have specified for the corresponding project via Options > Settings > Projects > "Project name".

Preconditions:

- [Select a project management database](prjmanagementgui_h_projekteverwalten.htm)
- [Load directories and projects](prjmanagementgui_h_verzeichniseinlesen.htm)

1. Project > Management
2. Select a project.
3. Select [Extras] > Verify project.
4. Click [...] next to the Compare settings check box.
5. Next to the Scheme field click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
6. In the New scheme dialog, enter a recognizable name for the new scheme in the Name field and click [OK].
7. To select a setting for the settings comparison, select the check box in front of a setting in the Settings to be compared field.
8. To exclude a setting from the settings comparison, deselect the check box in front of a setting in the Settings to be compared field.
9. Click  [Save] and then click OK.

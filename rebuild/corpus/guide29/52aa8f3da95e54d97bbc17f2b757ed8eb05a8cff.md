# Dialog Object selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You highlighted different types of object on one page. Edit > Properties.

In this dialog you select the object type whose [properties](Glossary_o_eigenschaften.htm) you want to edit as a block.

The following object types can be listed:

- General [devices](Glossary_o_betriebsmittel.htm) (e.g. lamps, fuses, contactors, resistors)
- Connection definition point
- Potential definition point
- Interruption point
- Terminal definition
- Terminal
- Plug definition
- Pin
- [PLC connection points](Glossary_o_sps_anschluesse.htm) and [bus ports](Glossary_o_sps_busanschluesse.htm)
- Cable
- Shield
- Black box
- PLC box
- Structure box
- Macro box
- T-node
- Bundle connection point symbol
- Placeholder object for [macros](Glossary_o_makros.htm)
- Part placement
- Part placement (3D)
- Layout space
- Mounting panel
- Line
- Arc, sector, or circle
- Ellipse
- Rectangle
- Polyline
- Spline
- Dimensioning
- Path function text
- Text
- Placeholder text

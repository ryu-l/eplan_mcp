# Assigning Outlines via the "Graphical macro" Field

In the parts management, [outlines](Glossary_o_konturen.htm) of the "Outline extrusion" type can now also be entered on the Mounting data tab in the Graphical macro field. The subsequent dialog for the file selection has been extended with the file type "Outline extrusion" (\*.fc2). An outline stored in the Graphical macro field is preferably used in contrast to an outline drawing in the Technical data tab.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

The [macros](Glossary_o_makros.htm) and outlines relevant for the 3D mounting layout can now be stored uniformly at the [part](Glossary_o_artikel.htm) in the Mounting data tab. This way you also enter a 2D macro into the Technical data tab at the same time.

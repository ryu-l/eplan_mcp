# P501002: The image file <x> entered at the part does not exist

### Cause

In the parts database to be checked a [part](Glossary_o_artikel.htm) was found where an image file was entered which EPLAN cannot find.

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective part is already marked in it.
2. Bring the Mounting data  tab to the front.
3. Click [...] next to the Image file field and select the required image file from one of the offered image directories in the selection dialog that is opened.  
     
   Or alternatively delete the entry in the Image file field.  
     
   Or [create](Glossary_o_erstellen.htm) a new image, store it in the desired image directory and select it in the Image file field.
4. Close the parts management, save the modified data, and carry out a parts synchronization.
5. Then start a new check run.

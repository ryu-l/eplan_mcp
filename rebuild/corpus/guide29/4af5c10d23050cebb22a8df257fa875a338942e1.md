# Placing Items on the Mounting Panel

When [placing](Glossary_o_auflegen.htm) [items](Glossary_o_bauteile.htm) on the mounting panel, a distinction is made between single placement, multiple placement, and the placement of locked areas. For this the installation spacing for every item / device must be stored in the parts data to where the device walls are not on top of each other, but rather next to each other. For multiple placements, the clearances are automatically accounted for, otherwise the single placement and multiple placement interactions are identical.

Preconditions:

- You have opened a project.
- You have opened the 2D panel layout - <Project name> dialog.
- You are in the graphical editor on a "Panel layout" page.
- You have added a mounting panel.
- The List display type contains parts with the "Unplaced" [part](Glossary_o_artikel.htm) status (Number of units / quantity (unplaced) property).
- In the dialog Settings: 2D panel layout (Popup menu > Settings) you have selected none of the Manual input <...> options.

1. Select the items in the list tab that have not yet been placed. (Multiple selection is possible.)
2. Select Popup menu > Place on mounting panel.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The first part placement hangs on the cursor.
3. Position the part placement on the mounting panel with a mouse click.
4. Proceed in this way for all additional [part placements](Glossary_o_artikelplatzierungen.htm) selected in the tree.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Number of units / quantity (unplaced) property of the newly placed parts is reduced correspondingly. In tree view, the parts are integrated into the mounting panel's hierarchy level, and the check mark shows that the parts have been placed.

![](../Pictures/Gui/ALL/note.png)Notes:

- If you are placing unplaced parts on a terminal strip then, provided that no parts have yet been placed on this terminal strip, a prompt appears, asking you to decide whether the complete terminal strip should be placed. If you answer [Yes] to this prompt, you can then place the complete terminal strip, and all the terminals on the strip will be identified as placed by a green tick in the tree in the [panel layout](Glossary_o_schaltschrankaufbau.htm) navigator. The terminal widths stored in the parts management module are added together to determine the dimensions of the terminal strip on the mounting panel. The maximum height stored for the terminal parts is used as the height of the new part placement.   
  If you answer [No] to the prompt, you can then place the terminals individually.
- Even if you do not move the cursor during placement, the [symbols](Glossary_o_symbole.htm) will be placed from left to right. If a symbol extends over the edge of the mounting panel, an error message will inform you of this.
- If you have selected one of the options Manual input <...> in the Settings: 2D panel layout dialog (Popup menu > Settings), you must first specify its dimensions in the Extension and distance dialog prior to placing the device.

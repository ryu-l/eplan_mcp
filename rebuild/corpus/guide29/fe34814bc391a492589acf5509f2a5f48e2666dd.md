# Migrating Parts

To migrate the Rittal baying system TS8 to the Rittal baying system VX25 in the existing EPLAN Pro Panel [projects](Glossary_o_projekte.htm) by using the Migrate part functionality the conditions and limits described in the "[Migration of Enclosure Parts](cabinetgui_k_artikelmigrieren.htm)" section apply.

![](../Pictures/Gui/ALL/note.png)Note:

Please read the EPLAN [Disclaimer of Liability Declaration](license_k_start.htm#Haftungsausschluss) first before you use the Migrate part functionality.

Preconditions:

- You have opened at least one project.
- The [layout space](Glossary_o_bauraum.htm) navigator is open.

### [ClosedMigrating a part automatically](javascript:void(0);)

Depending on the selection in the layout space navigator, a project, the complete contents of a layout space or an individual enclosure is analyzed. You can find a list of the Rittal TS8 parts that can be automatically migrated [here](cabinetgui_k_artikelmigrieren.htm#AutomatischesMigrieren).

1. In the layout space navigator, select a project, a layout space or an enclosure.
2. Select the menu [items](Glossary_o_bauteile.htm) Edit > Migrate part or the Migrate part popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected [part](Glossary_o_artikel.htm) is then analyzed to see whether the manufacturer name is "Rittal" and whether the order numbers of the parts represent TS8 parts.

If the enclosure cannot be fully migrated because of missing replacement parts, the Migrate part dialog is shown. In this dialog you can decide how you would like to proceed.

1. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts are migrated as far as possible.
2. Click [Export].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The required Rittal VX25 replacement parts that are not available are exported to the Parts.csv file. You can use this file to execute an automatic import of these parts to the shopping basket of the EPLAN Data Portal.

### [ClosedMigrate part manually](javascript:void(0);)

Migratable [accessories](Glossary_o_zubehoer.htm) that were determined after the automatic migration with the [Check run 026104](messages_p_026104.htm) can be migrated later manually if a replacement part is available.

You can find a list of the parts that can be manually migrated [here](cabinetgui_k_artikelmigrieren.htm#ManuellesMigrieren).

Preconditions:

- The migration of this enclosure was executed.
- Check run 026104 is performed.

1. Select a part reported by the check run in the layout space navigator or the layout space.
2. Select the menu items Edit > Migrate part or the Migrate part popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected part is exchanged for a VX25 part.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The replacement part hangs on the cursor.
3. Place the part in a suitable location in the migrated enclosure.

![](../Pictures/Gui/ALL/info.png)Tip:

In the [settings](Glossary_o_einstellungen.htm) dialog you can decide under the menu items Options > Settings > User > Devices > Part migration which auxiliary elements are to be transferred during the part migration. No auxiliary elements are transferred as the default setting.

### [ClosedCorrect enclosure distances in line ups](javascript:void(0);)

After the migration of TS8 enclosures within a line up, intersections arise because of the larger width of 2 mm of the VX25 enclosures. These are reported as collisions in the check run 026011. Such intersections can subsequently be corrected.

Preconditions:

- The migration of this enclosure line up was executed.
- Check run 026011 is performed.

1. Select the menu items Edit > Correct enclosure distance.
2. Enclose all VX25 enclosures of the line up with a rectangle.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The VX25 enclosures are each moved by a width of 2 mm.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The collision was corrected.

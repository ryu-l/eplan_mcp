# Deleting Embedded Reports

[Embedded reports](formgeneratorgui_k_ausgabeformen.htm) can only be directly deleted from the project page where they are placed.

Precondition:

You have opened a project.

1. Page > Navigator
2. Select the project page on which the embedded report is placed and select the menu item Page > Open.
3. Select the embedded report and select the menu item Edit > Delete.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The report block is deleted. The [report pages](Glossary_o_auswertungsseiten.htm) remain intact.

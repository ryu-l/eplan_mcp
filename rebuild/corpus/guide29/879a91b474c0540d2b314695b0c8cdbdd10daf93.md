# Routing Paths (Topology)

In EPLAN, [topology](Glossary_o_topologie.htm) refers to an area within the two-dimensional schematic editing where [routing path networks](Glossary_o_streckennetze.htm) are planned and [connections](Glossary_o_verbindungen.htm) are routed. This allows for any connections, cables, tubes or pipes to be routed. For these connections, in the topology you define [routing tracks](Glossary_o_verlegewege.htm) through which the connections are to run.

The following [actions](Glossary_o_aktionen.htm) are possible:

- A routing path network can be created independently of other displays in the project. The structuring of a routing path network is done via the identifier structure (for pages, [devices](Glossary_o_betriebsmittel.htm), etc.).
- A routing path network can be designed as placed or unplaced. The "Topology" page type is available for placement.
- There is an additional "Topology" representation type for [functions](Glossary_o_funktionen.htm) and connections. Connections with this representation type are taken into account for the purposes of synchronizing.
- Use a connection filter to control which connections may be routed through a routing track.
- When routing, the length of the routed [cable](Glossary_o_kabel.htm) or connection is determined.
- On the basis of the routing path networks and the generated [routing connections](Glossary_o_verlegeverbindungen.htm), [reports](Glossary_o_auswertungen.htm) can be generated which output, for example, the routing tracks, the [routing paths](Glossary_o_strecken.htm), or the cables and connections passing through the routing paths.

# Parts Management: Importing Parts Data to the eCl@ss Standard

[eCl@ss](Glossary_o_eclass.htm) is a standardized, cross-trade classification system for [product groups](Glossary_o_produktgruppen.htm), product characteristics and services with the aim of simplifying electronic trading of classified products.

During the import of parts data in the parts management according to the eCl@ss standard, the XML-based "[BMEcat](Glossary_o_bmecat.htm)" format is used. The supported version "BMEcat 2005.1" allows, for example, importing of multilanguage data.

In order to import data according to the eCl@ss classification, the Import records dialog in the File type field comes with entries for the different supported eCl@ss versions.

Importing is carried out by means of a scheme that you select in the subsequent dialog. The assignment of eCl@ss groups and eCl@ss [properties](Glossary_o_eigenschaften.htm) to product groups and [part](Glossary_o_artikel.htm) properties of the EPLAN parts management are configured in this scheme.

# Exchanging Symbol Libraries

The [symbol libraries](Glossary_o_symbolbibliotheken.htm) used in the project are entered into the [project-specific settings](Glossary_o_projektbezogeneeinstellungen.htm) and can be exchanged for other libraries.

Preconditions:

- You have opened the project whose symbol library/libraries is/are to be exchanged.
- The [symbols](Glossary_o_symbole.htm) and [variants](Glossary_o_varianten.htm) used in the project must exist in both libraries. The decisive factor here is the position of the symbols in the library, i.e. the symbol number.

1. Options > Settings > Projects > "Project name" > Management > Symbol libraries
2. In the Settings: Symbol libraries dialog, in the field for the desired symbol library, click [...].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The Select symbol library dialog is opened. If the symbol library should not be removed, then a message is displayed.
3. Select the desired symbol library.
4. Click [Open]  
      
    ![](../Pictures/Gui/ALL/arrow.png) The two symbol libraries are compared. If differences are found that prevent the libraries from being exchanged, then an appropriate message is displayed.
5. If the two symbol libraries are compatible, in the Exchange symbol libraries dialog, click [Yes].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The symbol library in the project is replaced with the new symbol library.

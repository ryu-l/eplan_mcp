# P020042: The <x> settings in the <y> layer differ: Previous value: <z> - New value: <u>

### Description

You have run a project comparison, checking the [layers](Glossary_o_ebenen.htm) of the test project (incoming project) against those of the comparison project and differences were found.

This message occurs when a layer setting has changed in the test project. <x> indicates the name of the setting and <y> the description of the layer. <z> shows the previous value of the layer and <u> the new value of the layer.

![](../Pictures/Gui/ALL/note.png) Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

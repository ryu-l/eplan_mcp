# P007002: The device uses fewer functions than provided by the associated part

### Cause

You added a device which you defined as a [part](Glossary_o_artikel.htm) with defined [function templates](Glossary_o_funktionsschablonen.htm) (device). In doing so, you place less [functions](Glossary_o_funktionen.htm) than the corresponding part has.

### Solution

#### Possibility 1

Select a part with the corresponding function template entries.

#### Possibility 2

Reduce function template [settings](Glossary_o_einstellungen.htm) for the selected part in the parts management. To do so select the menu [items](Glossary_o_bauteile.htm) Utilities > Parts > Management, and select the Function templates tab in the Parts management dialog. In the table, highlight the function templates you want to remove and click ![](../Pictures/Gui/ALL/all_delete_as.png) (delete). Copy the changed setting into the parts management. Then place the device in the schematic once again.

Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

Whether this message is issued depends on the Minimize unused functions and Number of unused functions settings. You move to the settings by firstly opening the Properties dialog of the device, bringing the Part tab to the front and clicking the [Device selection] button. Subsequently click [Settings] in the Device selection dialog and use it to open the Settings: Device selection dialog with the setting options previously stated. Using the Number of unused functions setting you set the number of functions not used in the device (reserve functions) that the part should provide. The number can only be set if you have selected the Minimize unused functions check box setting.   
If the Number of unused functions setting is set to "0", all the unused templates are identified as error(s).

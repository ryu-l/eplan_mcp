# Dialog Settings: eCl@ss import

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management > [Extras] > Import. You have selected the entry [eCl@ss](Glossary_o_eclass.htm) version in the File type field. Click [...] next to the File type field.

In this dialog you define the [settings](Glossary_o_einstellungen.htm) for importing eCl@ss data.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

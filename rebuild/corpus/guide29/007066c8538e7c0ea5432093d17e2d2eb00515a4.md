# Measuring in the Layout Space

The Measuring functionality is available for checking the equipment of the [mounting panels](Glossary_o_montageplatten.htm) and enclosures in the [layout space](Glossary_o_bauraum.htm). The distance from points and edges can be measured, and the measurement result is displayed in a dialog. This contains the coordinates of both the measured elements, the distances of the measured points and the shortest distance between the two measured elements.

The measured points and [lines](Glossary_o_leitungen.htm) are projected onto a mounting surface and correlated with each other there, i.e., the projected points on this mounting surface are then also visible during the measurement. If the measured points are not on a common mounting surface, the measured values are relative to the origin of the layout space.

Color display of measuring points:

1. Red: first measured point
2. Yellow: second measured point
3. Green: points on the mounting surface to which the measurement is projected.

Preconditions:

- You have opened a project.
- The layout space navigator is open and a layout space is open.
- The layout space contains [part placements](Glossary_o_artikelplatzierungen.htm).

1. Select the Layout space > Measuring menu [items](Glossary_o_bauteile.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Measuring result dialog is displayed. You are prompted to select the first point or the first edge.
2. Move the cursor over the [objects](Glossary_o_objekte.htm) in the layout space.  
     
   ![](../Pictures/Gui/ALL/arrow.png) When the cursor touches a measurable edge, it is highlighted in yellow. If the cursor touches a measurable point, it is displayed as a yellow highlighted square.

![](../Pictures/Gui/ALL/info.png)Tip:

If you want to measure points or edges on an enclosure, then press the [Shift] key, to display the grouped elements individually.

3. Click to select the desired first point or the first edge.
4. Click to select the desired second point or the second edge.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Measuring result dialog displays the measured coordinates and length values. The measured points and the end points of measured edges are displayed in the layout space. A connecting line is drawn between the measured points.

# P003023: Mismatch between quantity of parts and setting for adding up cable lengths

### Cause

The property Do not take the [cable](Glossary_o_kabel.htm) into account when calculating the cable length is selected, and the value 0 is entered for Number of units / quantity in the Parts tab of the Cable Properties dialog.

### Solution

#### Possibility 1

To do this, double-click on the cable definition line and switch to the Cable tab in the Properties <...> dialog. Under Properties deselect the check box Do not use cable when adding up cable lengths.

#### Possibility 2

To do this, double-click on the cable definition line and switch to the Parts tab in the Properties <...> dialog. Under Number of units / quantity enter a higher value than 0.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

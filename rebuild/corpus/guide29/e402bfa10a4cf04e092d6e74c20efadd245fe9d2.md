# Importing Pre-planning Data

In order to [create](Glossary_o_erstellen.htm) the pre-planning, you can import lists with pre-planning data that were created in external applications. Possible data sources are MS Excel files and text files.

Preconditions:

- You have opened a project.
- You have prepared the data source for importing. In order to prepare an Excel table for the data import, it is necessary to define an area containing the data to be imported. In order to import a text file specify the [separator](Glossary_o_trennzeichen.htm) and column headers.

Importing is described below using the "Excel" data source type as an example.

1. Select the menu [items](Glossary_o_bauteile.htm) Project data > Pre-planning > Import.
2. Select the entry "Excel" in the Type of data source field of the [Import pre-planning data - <Project name>](planninggui_d_importvorplanung.htm) dialog.
3. Click [...] next to the Data source field.
4. In the [Select data source](planninggui_d_datenquelleexcel.htm) dialog select the desired Excel file for the import.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All the worksheets and named areas that are located in the Excel file are listed in the Table field.
5. Select the name of an area that you specified for the import when preparing the Excel file in the Table field.
6. If the Excel file contains column headers, activate the Column names in the header row check box.
7. Click [OK].
8. Specify the scheme for the assignment of the external fields to the EPLAN [properties](Glossary_o_eigenschaften.htm) in the Field assignment field. If you have already created a scheme for the field assignment, you can select it from the drop-down list. Click [...] in order to create a new scheme or edit an existing one.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The column names from the Excel file are displayed in the External field column in the Field assignment dialog. If the file does not contain column names, the fields are numbered sequentially.
9. Specify the assignment of the external fields to the EPLAN properties in the table of the [Field assignment](planninggui_d_feldzuordnung.htm) dialog and save this assignment as a scheme.
10. Click [OK].
11. Use the check boxes in the lower section of the Import pre-planning data - <Project name> dialog to specify whether the data of existing [planning objects](Glossary_o_planungsobjekte.htm) are to be overwritten and whether new [segments](Glossary_o_segmente.htm) are to be generated during importing. Depending on these [settings](Glossary_o_einstellungen.htm) the value in the Action column is preassigned in the Synchronize pre-planning data dialog.
12. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The data to be imported from the Excel file are displayed in the [Synchronize pre-planning data](planninggui_d_importabgleich.htm) dialog.
13. Specify whether the respective segments are to be imported, modified, or not imported in the Action column.
14. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The data are imported in accordance with the settings.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The Automatically generated property with the value "Import" is assigned to the automatically generated segments in the pre-planning navigator.

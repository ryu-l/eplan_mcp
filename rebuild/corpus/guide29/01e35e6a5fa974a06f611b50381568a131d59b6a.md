# Dialog Report type

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Manufacturing data > Export / labeling. Click [...] next to the Settings field in the dialog Export manufacturing data / output labeling. In the dialog Settings: Manufacturing data export / labeling click ![](../Pictures/Gui/ALL/all_new_as.png) (New).

In this dialog you select a report type for the scheme of the exported manufacturing data / labeling. Such a scheme applies only to one report type.

![](../Pictures/Gui/ALL/warning.png)Caution:

You cannot change the report type later.

Overview of the main dialog elements:

Available report types:

This field displays all available [report types](Glossary_o_auswertungstypen.htm). The report types correspond to [form types](Glossary_o_formulartypen.htm). The report type that you select here is displayed in the Report type field in the dialog Settings: Manufacturing data export / labeling.

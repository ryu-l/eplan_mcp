# New Tabular List View for Navigators

For Version 2.8 the list view of the macro navigator was already converted into a table with cells that can in [part](Glossary_o_artikel.htm) be edited. For the current version this modification has also been realized for the following [navigators](Glossary_o_navigatoren.htm):

- Layout space navigator
- Device navigator
- Terminal strip navigator
- Plug navigator
- PLC navigator
- Cable navigator
- Topology navigator
- Connections navigator
- Potential navigator
- Piping navigator
- Wire harness navigator
- Interruption point navigator
- Bill of materials navigator.

In the new lists some of the displayed [properties](Glossary_o_eigenschaften.htm) can be edited directly. Direct [block editing](Glossary_o_blockbearbeitung.htm) of properties is also possible.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

In the new list view of the navigators you can now directly change the values of editable properties.

### Usage of selected data in table editing

The [objects](Glossary_o_objekte.htm) selected in a tabular list view can be transferred by means of the Edit in table popup menu item into the dialog of the editing in tables function. You can now also edit [macros](Glossary_o_makros.htm), [interruption points](Glossary_o_abbruchstellen.htm), [potentials](Glossary_o_potenziale.htm), [pipings](Glossary_o_rohrleitungen.htm) for the [P&I diagram](Glossary_o_ri_fliessbild.htm) as well as [segments](Glossary_o_segmente.htm) of the pre-planning in this dialog, in addition to [functions](Glossary_o_funktionen.htm) and [connections](Glossary_o_verbindungen.htm).

![](../Pictures/Gui/ALL/benefit.png)Benefit:

In the table editing function you can now also edit [project data](Glossary_o_projektdaten.htm) such as macros, interruption points, potentials, pipings and segments, in addition to the functions and connections. Through the transfer of marked objects from a list view into the editing in tables you obtain a better overview of the selected data and can edit these directly.

In the editing in tables dialog, the tabs Functions, Connections, Interruption points are only displayed when the corresponding [object types](Glossary_o_objekttypen.htm) are contained in the selection. In the context of these extensions the dialog for editing in tables has been renamed:

| Old designation | New designation |
| --- | --- |
| Edit function data | Edit in table |

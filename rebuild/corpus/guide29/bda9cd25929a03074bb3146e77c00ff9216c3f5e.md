# Dialog Number using PLC data: Format

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the dialog Settings: Number using PLC data (for example with Options > Settings > Projects > "Project name" > Devices > Number using PLC data). Select a [user-defined](Glossary_o_benutzerdefiniert.htm) scheme or [create](Glossary_o_erstellen.htm) one in the dialog Settings: Number using PLC data. Select an entry in the Format groups field and click ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit), or click ![](../Pictures/Gui/ALL/all_new_as.png) (New).

In this dialog, you can change the format of an existing format group or define a new format.

Overview of the main dialog elements:

Group:

The numbering range for numbering with PLC data is separately set for each group of [devices](Glossary_o_betriebsmittel.htm). In the drop-down list, the following groups of devices are offered:

- Terminals: The terminal designation is changed.
- Pins: The pin designation is changed.
- Device: Only the DT is changed for general [functions](Glossary_o_funktionen.htm). The device tags of boxes, [device connection points](Glossary_o_geraeteanschluesse.htm), [PLC connection points](Glossary_o_sps_anschluesse.htm), [busbars](Glossary_o_sammelschienen.htm), cables, [plugs](Glossary_o_stecker.htm), and terminal strips are unchanged.

If a format is already specified for a group, this group is no longer offered in the list.

Extent:

Specify the numbering range for the selected group.

- Directly connected first target: Only the first target is searched for, e.g. the pin on a PLC connection point.

  ![](../Pictures/Gui/ALL/example.png) [![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

  On PLC connection point E1.0, the direct target is terminal X10; this is designated with PLC data. The second terminal connected to the PLC connection point is not designated.

  ![](../Pictures/Visualisation/ALL/offlinenumerationplcgui_directtarget_LV.png)
- Net: The ends of all common [connections](Glossary_o_verbindungen.htm) are taken into account, plus net extensions (terminals, plugs, etc.).

  ![](../Pictures/Gui/ALL/example.png) [![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

  Here, all devices connected to PLC connection point E1.0 are numbered, i.e. both terminals and sensor PLC3.

  ![](../Pictures/Visualisation/ALL/offlinenumerationplcgui_net_LV.png)
- Up to first sensor / actuator: The first target from which the automatic symbolic address is taken is searched for.

  ![](../Pictures/Gui/ALL/example.png) [![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

  Here, all devices located on the direct path to the first sensor are numbered, i.e. the first terminal and sensor PLC3.

  ![](../Pictures/Visualisation/ALL/offlinenumerationplcgui_firstsensor_LV.png)
- Up to each sensor / actuator (net): In the entire net, the search is carried out to the respective sensor / actuator. Sensors are searched for when starting from an input and actuators are searched for when starting from an output. The others are numbered (using DT numbering) if they are [main functions](Glossary_o_hauptfunktionen.htm). Terminals and [pins](Glossary_o_steckerkontakte.htm) are also numbered.

  ![](../Pictures/Gui/ALL/example.png) [![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

  In the illustration, the "Continue numbering with PLC data beyond this function" property is set on the [component](Glossary_o_schaltzeichen.htm) in the black box. Terminals in between are also numbered. Additional [nets](Glossary_o_netze.htm) - if present - would also be completely incorporated. On the second PLC connection point, the "Prevent numbering with PLC data" property is activated.

  ![](../Pictures/Visualisation/ALL/offlinenumerationplcgui_allsensor_LV.png)

Available [format elements](Glossary_o_formatelemente.htm):

This list displays the elements that could be integral parts of the address [formats](Glossary_o_formate.htm). To format a format element you have to move it to the list of selected format elements on the right. Multiple selections are not possible. When you move the format element, a dialog will open in which you can specify the formatting. This dialog is different depending on the format element.

The following format elements are possible for terminals and pins:

| Format element | Preview | Meaning |
| --- | --- | --- |
| Data of PLC connection point | T | Outputs the [properties](Glossary_o_eigenschaften.htm) of the PLC connection point. |
| Data of PLC address | A | Outputs the properties of the PLC address. |
| Separator |  | Separates format elements from one another. |

The following format elements are possible for [general devices](Glossary_o_allgemeinebetriebsmittel.htm):

| Format element | Preview | Meaning |
| --- | --- | --- |
| Identifier | I | Defines the identifier for the device. (only allowed once in a format.) |
| Data of PLC connection point | T | Outputs the properties of the PLC connection point. |
| Data of PLC address | A | Outputs the properties of the PLC address. |
| Page | S | Defines the page name(s) of the page(s) where the device is located. A page subcounter is not output. (only allowed once in a format.) |
| Column | P | Defines the column number in which the device is located. (only allowed once in a format.) |
| Line | R | Defines the line number in which the device is located. (only allowed once in a format.) |
| Separator |  | Separates format elements from one another. |

![](../Pictures/Gui/ALL/note.png) Note:

The complete PLC address can be found under "Data of PLC connection point"; individual components of the PLC address can be selected under "PLC address data". The bit corresponds to the first level and the byte the second level in the address.

Selected format elements:

This list shows which format elements you have set for the selected group. The selected format elements are shown in tabular [form](Glossary_o_verlauf.htm) with their designation, symbolic representation (for the preview) and specified value. Use the toolbar buttons above the list to change the format element formatting retroactively, delete format elements, and change their order.

Preview:

The preview of a numbering format is displayed here. The individual formatting elements are displayed in the [connection designations](Glossary_o_verbindungsbezeichnungen.htm) in the same sequence as they currently exist in the list. This field cannot be modified.

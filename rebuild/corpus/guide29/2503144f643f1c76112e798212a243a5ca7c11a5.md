# Configuring Property Arrangements

A new configuration dialog is now available in the EPLAN platform for improved management and editing of the [user-defined](Glossary_o_benutzerdefiniert.htm) property arrangements for 3D [part placements](Glossary_o_artikelplatzierungen.htm) and components existing in a project.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

The new configuration dialog provides an overview of all property arrangements available in the project. The exporting and importing of property arrangements for multiple different [part](Glossary_o_artikel.htm) placements or components as well as simultaneous editing of multiple property arrangements is now also possible. In addition, you can now also translate the names with which the property arrangements in the project are displayed.

[![](../Pictures/Gui/Lang/eservicesgui_configpropertyarrangement_ls_thumb_0_60.png)](../Pictures/Gui/Lang/eservicesgui_configpropertyarrangement_ls.png)

Select the Project data > Configure property arrangements menu path to open the Configure property arrangements dialog. This dialog is similar in its structure to the familiar dialog for the configuration of the [properties](Glossary_o_eigenschaften.htm).

### Tree and list view of the property arrangements

The user-defined property arrangements existing in the current project are displayed in a tree and list view in the left-hand section of the dialog.

The Filter field is available above the tree and list view in order to limit the number of displayed property arrangements. To this purpose the property arrangements are searched for both the identifying name as well as the displayed name.

### Editing a user-defined property arrangement

The buttons above the tree and list view allow you to [create](Glossary_o_erstellen.htm), delete, export and import user-defined property arrangements from another project into the current project.

Depending on the selected hierarchy level the Function definitions or Symbol selection dialog is first opened during the creation of new property arrangements. In the process the marked hierarchy level is used as a filter.

In the right-hand section of the dialog you specify the identifying name and the displayed name for a new user-defined property arrangement. A multilingual input is possible here for the displayed name, in contrast to the creation of a property arrangement in the [layout space](Glossary_o_bauraum.htm) or schematic.

The actual configuration of the properties with the associated display [settings](Glossary_o_einstellungen.htm) is effected for 3D part placements in the 3D functions tab and for components in the Component tab as well as in the tabs Connection points and Contact image. To this purpose the same setting options are available as in the [Display](devicetaggui_r_anzeige.htm) tab of the [property dialog](Glossary_o_eigenschaftendialog.htm).

### Checking the usage of a property arrangement and removing it

During the configuration you have the option to check the usage of the user-defined property arrangements and remove property arrangements not used.

To this purpose the menu [items](Glossary_o_bauteile.htm) Check usage and Remove unused property arrangements are available below the [Extras] button. The Check usage menu item fills the Usage count column in the list view with the current numbers of how frequently the respective property arrangement was used in the project. Fixed specified property arrangements are not removed during the removal.

To be able to find used user-defined property arrangements you have the Insert into list of search results menu item available in the popup menu of the tree and list view. This menu item checks the usage of the marked property arrangements in the project and enters the found [objects](Glossary_o_objekte.htm) into the search results list. This way you can search via the popup menu item Go to (graphic) in the graphic for the used property arrangements of objects such as components, part placements, etc.

### Changed settings for the contact image

The settings for the [contact image](Glossary_o_kontaktspiegel.htm) belong to a property arrangement. The property dialogs for the [devices](Glossary_o_betriebsmittel.htm) in this section were restructured so that the contact image displays can also be configured.

In addition to the tabs Components and Connection points the new tab Contact image is also available in the Display tab. This replaces the existing drop-down list Contact image as well as the tab Contact image setting.

To have a contact image displayed for a function, click the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button in this tab and specify the alignment of the contact image ("In path", "On [component](Glossary_o_schaltzeichen.htm)") in the subsequent dialog. If you have selected a contact image alignment, you can edit the familiar settings for the contact image in the Property / Assignment: table in the right-hand section.

[![](../Pictures/Gui/Lang/devicetaggui_contactimage_ls_thumb_0_60.png)](../Pictures/Gui/Lang/devicetaggui_contactimage_ls.png)

![](../Pictures/Gui/ALL/note.png)Notes:

- A contact image can only be specified for components but not for part placements. Accordingly the Contact image tab is not available for these objects.
- To specify the contact image position when creating and editing [symbols](Glossary_o_symbole.htm) in the [symbol editor](Glossary_o_symboleditor.htm), the new Contact image tab is available in the Property placement dialog as well.

# P027015: Topology - Routing path network no longer up-to-date

### Cause

Graphical [objects](Glossary_o_objekte.htm) that affect the [connections](Glossary_o_verbindungen.htm) to be routed in the [topology](Glossary_o_topologie.htm) are [part](Glossary_o_artikel.htm) of the so-called routing path network. These include, for example, [routing paths](Glossary_o_strecken.htm), [routing points](Glossary_o_verlegepunkte.htm), and [interruption points](Glossary_o_abbruchstellen.htm). Each time such a routing path network object is placed in the topology, positioned differently or deleted, the routing path network is modified, resulting in the output of the message "Routing path network no longer up-to-date".

### Solution

1. Re-[route](Glossary_o_verlegen.htm) the connections throughout the project in order to update the routing path network.
2. Then start a new check run.

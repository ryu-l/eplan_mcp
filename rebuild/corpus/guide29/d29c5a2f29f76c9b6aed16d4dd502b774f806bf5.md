# P026034: NC mounting surface without valid field size

### Cause

There is a [part](Glossary_o_artikel.htm) placement in the [layout space](Glossary_o_bauraum.htm) that contains an NC-specific mounting surface without a valid field size. Most likely, a 3D macro was created for the part with an NC-specific mounting surface that lacks the field size information.

### Solution

1. Locate the part placement in the layout space using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the layout space navigator and navigate in the tree view to the NC-specific mounting surface that is displayed in the layout space.
3. Select in the tree view the mounting surface and select from the popup menu the Field size menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the layout space you will see along the edges of the mounting surface 2 vertical and 2 horizontal [lines](Glossary_o_leitungen.htm) that delimit the field size.
4. Switch to the layout space and select one of the lines on the mounting surface, which then changes its color.
5. Click the line with the left mouse button, and move it to the desired position.
6. Exit the move mode with another left click.
7. Repeat these work steps - if necessary - for the other lines of the NC-specific mounting surface.
8. Then start a new check run.

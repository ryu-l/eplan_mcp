# User-Defined Properties: Principle

User-defined [properties](Glossary_o_eigenschaften.htm) can be created for the project as well as in the parts management. The [user-defined](Glossary_o_benutzerdefiniert.htm) properties for the project are stored project-specifically and transmitted together with the project. In analogy to this, the user-defined properties for the parts are stored in the parts database.

The creation and management of user-defined properties is carried out by means of a [Configuration dialog](eservicesgui_d_konfigeigenschaften.htm). In the process, the project-specific user-defined properties are only displayed during the configuration for the project. After user-defined properties for a [part](Glossary_o_artikel.htm) are stored in the project with a part and / or device selection, these user-defined properties for parts are also displayed in the configuration for the project.

### Consideration for the automatic translation

You can specify whether the value of a user-defined, multi-language property is considered for the automatic translation of the project or the automatic translation in the parts management by using the respective setting Translate property value in the configuration dialog.

For the translation of the displayed name and the default values of selection lists there are both [project-specific settings](Glossary_o_projektbezogeneeinstellungen.htm) as well as corresponding [settings](Glossary_o_einstellungen.htm) in the settings for the parts management. To this purpose the settings User-defined properties: Displayed name, User-defined properties: Description and User-defined properties: Default values selection list are available respectively in the dialog [Settings: Extent](translategui_r_einstellungumfang.htm) and in the dialog [Settings: Parts management](translategui_r_artikelverwaltung.htm).

### User-defined properties for the parts management

The configuration of user-defined properties is carried out in the parts management via [Extras] > Configure properties. You can assign these configured properties to a part by means of the User-defined properties tab.

The user-defined properties for the parts provide you with, among others, the following options:

- The identifying names and the values of the user-defined properties can be used as full-text [filters](Glossary_o_filter.htm) for search terms and filter criteria for filtering in the parts management.
- During a later part or device selection the user-defined properties are transferred with the values to the respective main function.
- The user-defined properties for the parts are considered during the parts synchronization between the parts management and the project.
- The user-defined properties are also considered while exporting and importing parts data with the file types "EDZ" and "XML".   
  If you export the entire parts database or a subset, meaning that you open the export dialog via [Extras] > Export, the record type "Property configuration" is available in the Export records dialog. If you export individual, selected parts, the assigned user-defined properties are also exported when the listed file types are used.

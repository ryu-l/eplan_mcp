# Dialog Filter: Messages

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Project data > Messages > Management. Click [...] next to the Filter field.

In this dialog you can specify the [message classes](Glossary_o_meldungsklassen.htm) for which messages should be displayed, e.g. errors for terminals, [plugs](Glossary_o_stecker.htm), cables, etc. or also for parts [master data](Glossary_o_stammdaten.htm).

The last filter criteria selected also remain in effect after the display is closed, and are again active when the dialog is reopened.

Overview of the main dialog elements:

The table contains the following [properties](Glossary_o_eigenschaften.htm):

Selection:

Select the check box to select the message classes for display. If a check box is deselected, then messages in the corresponding class are not displayed.

ID:

The number identifying a message within the message class is displayed here. These are the last three digits of the message number.

Class:

Here is where the message class is displayed, e.g. terminals, plugs, cables, etc.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Electrical engineering / Process engineering / Fluid power / Mechanics:

If the corresponding check box is activated, only those messages are displayed that are assigned to the selected trade.

General:

If this check box is selected, all the messages that are not assigned to a trade are displayed. These include messages from the area of translation or parts management.

Errors / Warnings / Notes:

You can use these check boxes to specify the categories to be displayed. The [settings](Glossary_o_einstellungen.htm) specified here overwrite the project settings.

Completed messages:

If this check box is selected, then messages will be displayed that have already been flagged as resolved. If this check box is deselected, then resolved messages are hidden.

# P003014: Two / several N conductors intersected

### Cause

The [cable](Glossary_o_kabel.htm) uses two or more N [conductors](Glossary_o_adern.htm).

### Solution

Change the potential type on one of the duplicated conductors.  
 To do this, double-click on the cable source [component](Glossary_o_schaltzeichen.htm) and switch to the Symbol / function data tab in the Properties <...> dialog. Click [Logic]. In the Connection point logic dialog, assign the function connection point 2 under Potential type a new value (e.g.) "undefined".

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

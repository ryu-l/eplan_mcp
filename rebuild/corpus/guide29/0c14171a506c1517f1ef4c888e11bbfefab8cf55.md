# Tab Handle / Tab Mounting grid

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The project contains at least one [layout space](Glossary_o_bauraum.htm). The layout space contains 3D [objects](Glossary_o_objekte.htm). A handle or a [mounting grid](Glossary_o_montageraster.htm) has been defined on a 3D object. Select the handle or the mounting [grid](Glossary_o_raster.htm) and then select the menu [items](Glossary_o_bauteile.htm) Popup menu > Properties. Or double-click the handle or the mounting grid.

In this tab you set the [properties](Glossary_o_eigenschaften.htm) of a handle / mounting grid.

Overview of the main dialog elements:

Name:

Enter the name of the handle / mounting grid here.

Description:

Enter a description text for the handle / mounting grid here.

# Inserting Connection Symbols

Connection [symbols](Glossary_o_symbole.htm) are managed in the SPECIAL.slk symbol library. They represent the flow of [connections](Glossary_o_verbindungen.htm) and have no [function definitions](Glossary_o_funktionsdefinitionen.htm).

### [ClosedInsert angles](javascript:void(0);)

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the following menu [items](Glossary_o_bauteile.htm): Insert > Connection symbol
2. From the submenu select the angle you would like to insert.
3. If required hold down the [Ctrl] key and move the mouse to page through the existing [variants](Glossary_o_varianten.htm).
4. Place the angle on the page.
5. Proceed this way for all additional angles that you would like to insert on the page.
6. End the action via the Cancel action popup menu item or via the [Esc] button.

### [ClosedInsert T-nodes, double junctions, and jumpers](javascript:void(0);)

Preconditions:

- You have opened a project. You have opened a project page in the graphical editor.
- Under Options > Settings > User > Graphical editing > Connection symbols you selected the With target specification or as point option, or you selected the Connection symbols with prompt check box when you selected another option.

1. Select the following menu items: Insert > Connection symbol
2. From the submenu select the connection symbol you would like to insert.
3. In the subsequent dialog select the desired target-specific variant.
4. Select the Draw as point check box if you want the connection symbol to be drawn as a connection point.
5. Click [OK].
6. If required hold down the [Ctrl] key and move the mouse to page through the existing variants.
7. Place the connection symbol on the page.
8. Proceed this way for all additional [connection symbols](Glossary_o_verbindungssymbole.htm) of this type that you would like to insert on the page.
9. End the action via the Cancel action popup menu item or via the [Esc] button.

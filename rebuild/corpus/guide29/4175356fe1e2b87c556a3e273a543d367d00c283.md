# Dialog Settings: General (users, devices)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > User > Device > General

In this dialog you specify the [user-specific](Glossary_o_benutzerbezogen.htm) [settings](Glossary_o_einstellungen.htm) for [devices](Glossary_o_betriebsmittel.htm).

Overview of the main dialog elements:

Take the connection point designations into account during the device assignment:

![](../Pictures/Gui/ALL/note.png)Note:

This setting only has an effect if during the preparation of the [macros](Glossary_o_makros.htm), the option "from user settings" was selected for the setting [Take connection point designations into account](macrosgui_r_makrokasteneinstellungen.htm#AnschlussbezeichnungenBeruecksichtigen) in the macro project at the respective macro box.

During the device assignment, those [functions](Glossary_o_funktionen.htm) are searched for that match best. This is normally carried out on the basis of the [function definitions](Glossary_o_funktionsdefinitionen.htm) and the template [properties](Glossary_o_eigenschaften.htm).

Select this check box if, in addition the [connection point designations](Glossary_o_anschlussbezeichnungen.htm) have to be identical, so that when assigning functions or [placing](Glossary_o_auflegen.htm) complex devices, the matching functions can be assigned or associated from the stored macro.

This setting is also used when updating macros. If this check box is activated, the connection point [designations](Glossary_o_bezeichnungen.htm) are transferred during the update from the macro file to the inserted macros in the schematic.

Retain symbol / macro variant when placing device:

When inserting or placing devices you have the possibility "to browse" through the symbol / macro [variants](Glossary_o_varianten.htm) of the symbol / symbol macro that is entered in the respective function template with the [Tab] key.

If this check box is activated, the selected variant is retained.

- When a device is placed from the device navigator, the symbol variant of a function is retained if the subsequent functions belong to the same function category.
- When a device is inserted repeatedly, the first symbol of the device which was used for this device during the last insert is used for the variant.  
  During inserting the same applies for other [symbols](Glossary_o_symbole.htm) of the device as for placing - a selected variant is retained for this inserting as long as the function category does not change.

![](../Pictures/Gui/ALL/note.png)Note:

This setting only applies for those devices that are defined via [function templates](Glossary_o_funktionsschablonen.htm). When inserting devices that are defined via a macro, only the variant of the first symbol is retained.

Delete manual saddle jumpers during copying:

This setting controls the behavior of manual saddle jumpers during the copying and pasting of terminals in the graphical editor.

If this check box is activated, manual saddle jumpers are deleted during copying and pasting. The values of the properties Manual saddle jumpers (internal) ([ID](Glossary_o_id.htm) 20350) and Manual saddle jumpers (external) (ID 20351) are then empty.

This setting does not have any effect on copying [actions](Glossary_o_aktionen.htm) in the page navigator or the insertion of macros. In these cases the jumper information is always retained.

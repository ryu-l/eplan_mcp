# P026038: Routing path network no longer up-to-date

### Cause

Graphical [objects](Glossary_o_objekte.htm) that affect the [connections](Glossary_o_verbindungen.htm) to be routed in the [layout space](Glossary_o_bauraum.htm) are [part](Glossary_o_artikel.htm) of what is known as the routing path network. This includes, for example, [routing paths](Glossary_o_strecken.htm), curves, [routing ranges](Glossary_o_verlegebereiche.htm), [wire ducts](Glossary_o_verdrahtungskanaele.htm) or also [wiring cut-outs](Glossary_o_verdrahtungsdurchbrueche.htm). Each time such a routing path network object is placed in the layout space, positioned differently or deleted, the routing path network is modified, resulting in the output of the message "Routing path network no longer up-to-date".

### Solution

1. Select the Layout space > Route connections > Generate routing path network menu [items](Glossary_o_bauteile.htm) to update the routing path network.
2. Then start a new check run.

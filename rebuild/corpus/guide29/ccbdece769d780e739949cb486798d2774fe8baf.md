# Dialog Export Copper NC

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have selected in the [layout space](Glossary_o_bauraum.htm) or layout space navigator copper [items](Glossary_o_bauteile.htm) for which an NC export is to be carried out. Utilities > Manufacturing data > Machining > Copper NC.

Use this dialog to specify the [settings](Glossary_o_einstellungen.htm) for the export of manufacturing data for machining of copper items. The transfer file to the machines has the "XML" format. The following data is transferred:

- Notes on the software version
- Project information
- Material
- Rail dimensions
- Bendings
- Punched holes.

Overview of the main dialog elements:

Machine:

The delivery scope includes the machine definition named "Default". If you have defined other [schemes](Glossary_o_schemata.htm) in the company settings, you can select other machine definitions from the drop-down list.

The [...] button opens the Settings: Copper export NC dialog where you can modify the settings for the scheme or define a new scheme.

Output directory:

This field displays the storage location. Here, the directory is pre-selected that is specified under Settings > Company > Machining for the copper export NC.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).

Target file:

This field is active only if the selection contains copper items that can be exported. Here, you can enter the name of the NC file to be generated, or use [...] in the Open dialog to select a file of the Copper NC (\*.xml) file type. If this results in several files, the field is deactivated, and the conditions apply that are defined in the scheme for generating the file name and the subdirectories.

Material:

Information for the machine on the material to be machined. Here, you can enter any short text; the field can also be left empty. The default value is "Cu".

Apply to entire project:

If this check box is activated, the current selection will be extended to all copper items of the project.

If the check box is deactivated, only highlighted copper items will be exported.

If you have already selected a single project (and not set any [filters](Glossary_o_filter.htm)), then this check box is automatically activated and grayed-out. You can then no longer change this setting.

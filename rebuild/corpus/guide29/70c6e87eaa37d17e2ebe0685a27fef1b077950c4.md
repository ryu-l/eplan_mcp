# Dialog Numbering formats

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Options > Settings > Projects > "Project name" > Devices > Numbering (online). In the Settings: Numbering (online) dialog, click [...] next to the Numbering format field.
- Utilities > Change of standard. Make the necessary entries in the Project, Rotation / flipping, Master data, Symbols and Structure tabs and click [Next] each time. In the Numbering tab, next to the Device numbering field, click [...].

Use this dialog to manage all [numbering formats](Glossary_o_nummerierungsformate.htm) for [online numbering](Glossary_o_onlinenummerieren.htm) of [devices](Glossary_o_betriebsmittel.htm). You can [create](Glossary_o_erstellen.htm), edit, copy, delete, import, and export numbering [formats](Glossary_o_formate.htm). You can select these numbering formats for devices that you place on the schematic page using Insert > Symbol. You can also select these numbering formats for devices that you insert into the schematic page using [macros](Glossary_o_makros.htm) or copy processes.

The following dialog elements are available:

Scheme:

This field contains the name under which you have saved the numbering format in the New scheme dialog in the Name field.

You can create new [schemes](Glossary_o_schemata.htm), save any changes to a scheme, and copy or delete schemes via the adjacent [Toolbar](schemeconfig_m_schemaschaltflaechen.htm). Schemes can also be imported or exported.

Description:

In this field is the description you entered for the numbering format in the Description field of the New scheme dialog.

---

Tab DT

General devices ... Mechanical devices:

This field contains the DT format for the respective [functions](Glossary_o_funktionen.htm). Click [...] to open the DT format dialog, which is where you can edit the format. If the check box is activated, the functions are automatically numbered on insertion. If the check box is deactivated, the functions are not automatically numbered on insertion.

Number nested components:

If this check box is selected, then components allocated to a superior [component](Glossary_o_schaltzeichen.htm) are automatically numbered on insertion. If the check box is deselected, then these components are not automatically numbered on insertion.

---

Tab Designations

Terminals ... Busbar connection points:

If the check box is activated, the respective [designations](Glossary_o_bezeichnungen.htm) are automatically numbered on insertion. If the check box is deactivated, the designations are not automatically numbered on insertion. The format for the designations is shown in the field next to the check box. Click [...] to open the DT format dialog, which is where you can edit the format.

PLC addresses:

If the check box is selected, then [PLC addresses](Glossary_o_sps_adressen.htm) are automatically numbered on insertion. If the check box is deselected, then PLC addresses are not automatically numbered on insertion.

Do not modify PE, N, and SH terminals:

If the check box is activated, PE / PEN, N, and SH terminals are not numbered. The designation of the PE, PEN, N, and SH terminals remains unchanged.

Do not modify PE, N, and SH pins:

If the check box is activated, PE / PEN, N, and SH [pins](Glossary_o_steckerkontakte.htm) are not numbered. The designation of the PE, PEN, N, and SH pins remains unchanged.

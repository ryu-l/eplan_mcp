# P501019: Symbol library <x> was not found in the project (<y>)

### Cause

In the parts database to be checked a [part](Glossary_o_artikel.htm) was found where a symbol macro is entered that consists of [symbols](Glossary_o_symbole.htm) from a symbol library that does not exist in the test project. This may be a symbol library that is not an EPLAN default symbol library. EPLAN states the name of the symbol library in the placeholder <x> and the macro name in the placeholder <y>.

### Solution

1. Create the macro using symbols that are part of an EPLAN default symbol library. Or copy the symbol library used for the creation of the macro â if available â- into the desired [system master data](Glossary_o_systemstammdaten.htm) directory for symbols and include it into the test project.
2. Then start a new check run.

# Dialog Delete connection designations

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have selected a connection in the graphical editor, or in the Connections - <Project name> navigator dialog. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog. Project data > Connections > Numbering > Delete.

In this dialog you specify whether just the [connection designations](Glossary_o_verbindungsbezeichnungen.htm) should be deleted or the empty [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) as well.

Once you have called up the menu item, the [connections](Glossary_o_verbindungen.htm) are first automatically newly generated.

Overview of the main dialog elements:

Settings:

Select a scheme defining the [settings](Glossary_o_einstellungen.htm) for the [connection numbering](Glossary_o_verbindungsnummerierung.htm) from the drop-down list. The filter settings defined in this scheme are taken into account when deleting the connection [designations](Glossary_o_bezeichnungen.htm). You can use [...] to open the [Settings: Connection numbering](wirenumberinggui_d_verbnumeinstellungen.htm) dialog where you can edit the filter settings.

Only connection designations:

The designations of all the connection definition points are deleted. The definition points themselves remain.

Empty connection definition points:

All connection definition points that can possess one connection designation only (Valid data field in the [properties](Glossary_o_eigenschaften.htm) dialog = "Only connection designation") and whose designation is empty or contains "????" are deleted.

Connection designations and empty connection definition points:

The designations of all the connection definition points are deleted. In addition, those connection definition points that can possess one connection designation only (Valid data field in the properties dialog = "Only connection designation") will also be deleted.

Retain 'manually set' numberings:

If this check box is selected, connection definition points whose connections have the Manually set property will not be deleted and will retain their designation.

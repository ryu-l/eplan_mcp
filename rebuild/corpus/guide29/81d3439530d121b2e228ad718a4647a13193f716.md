# Dialog New CPU

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Project data > PLC > Addresses / assignment lists. In the Addresses / assignment lists dialog select [Extras] > Import assignment list > New CPU.

In this dialog you [create](Glossary_o_erstellen.htm) a new CPU.

Overview of the main dialog elements:

Configuration project:  
Station ID:  
CPU identifier:

Enter the name of the configuration project, the station name, and the CPU identifier here, or select an entry from the drop-down lists in these fields. The CPU name is made up of these entries.

![](../Pictures/Gui/ALL/note.png)Note:

Since the point is used as a [separator](Glossary_o_trennzeichen.htm) in the complete CPU name, the values for the configuration project, the station name and the CPU identifier must not contain a point.

PLC-specific settings:

Here you define the PLC type-specific [settings](Glossary_o_einstellungen.htm). Select an existing scheme from the drop-down list. Click [...] to open the Settings: PLC-specific dialog.

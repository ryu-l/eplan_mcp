# Dialog Application class selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management > [Extras] > Import. You have selected the entry [eCl@ss](Glossary_o_eclass.htm) version in the File type field. Click the [...] button next to the File type field, select the Class structure assignment tab and click ![](../Pictures/Gui/ALL/all_new_as.png) (New).

This dialog displays the complete eCl@ss class tree for the eCl@ss [segments](Glossary_o_segmente.htm) 19 ("Information, communication and media technology"), 23 ("Machine element, fixing, mounting"), 27 (" Electric engineering, automation, process control engineering ") and 37 ("Industrial piping").

Overview of the main dialog elements:

List:

The list contains all the classes for the corresponding eCl@ss segments in a structured tree view. Here you can carry out a free selection of segments, main groups, etc. for the assignment to EPLAN [properties](Glossary_o_eigenschaften.htm).

![](../Pictures/Gui/ALL/note.png)Note:

eCl@ss properties that are identified as "Deprecated" are not offered for the assignment.

# Revision markers: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_revisionsmarkierungen.htm)

### Revision markers

User interface / operation

If you have changed an object in a revision, then this is displayed with a graphical marker in the schematic. Changes in properties are also designated with a marker text entered into the "Revision marker (change tracking)" or "Revision marker (from property comparison)" properties (see [Revision marker texts](Glossary_o_revisionsmarkierungstexte.htm)). Both the graphical markers in the schematic and the text markers in the properties are described as revision markers.

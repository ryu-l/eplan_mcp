# Dialog Settings: Correct

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Project > Organize > Correct. Click [...] next to the Settings field in the Correct project dialog.
- Options > Settings > Projects > "Project name" > Management > Correct.

In this dialog you can specify which [project data](Glossary_o_projektdaten.htm) are to be corrected automatically by means of a correction run. These [settings](Glossary_o_einstellungen.htm) must be saved as a scheme.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Data to be corrected:

In this field you specify the correction settings by means of check boxes.

- [Terminals](ProjectCorrectionGui_k_korrekturdaten.htm#I_Klemmen)
- [Plugs](ProjectCorrectionGui_k_korrekturdaten.htm#I_Stecker)
- [Cables](ProjectCorrectionGui_k_korrekturdaten.htm#I_Kabel)
- [Connections](ProjectCorrectionGui_k_korrekturdaten.htm#I_Verbindungen)
- [PLC](ProjectCorrectionGui_k_korrekturdaten.htm#I_SPS).

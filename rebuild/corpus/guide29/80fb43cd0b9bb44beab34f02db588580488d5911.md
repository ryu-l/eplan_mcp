# Automatically Processing a Project

If you apply [actions](Glossary_o_aktionen.htm) to a project in an automated manner, you can choose whether to run these actions for the whole project or only for the current selection in the page navigator.

Preconditions:

- You have opened a project.
- You have created a scheme that contains a sequence of automatable actions.

1. Select the menu item Page > Navigator.
2. Select in the page navigator one or several project pages or a project.
3. Select the menu [items](Glossary_o_bauteile.htm) Utilities > Automated processing.
4. In the Run: Automated processing dialog in the Scheme field, select the scheme with the automatable actions.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The sequence of actions stored in the scheme is displayed in the Actions list.
5. Activate the Apply to entire project check box to process the whole project in an automated manner.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The actions are executed.

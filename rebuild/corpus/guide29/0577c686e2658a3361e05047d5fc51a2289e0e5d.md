# Dialog Rename project

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have selected a project in the page navigator. Project > Rename.

In this dialog, you can give an existing project a different project name.

Overview of the main dialog elements:

Old project name:

This field contains the project name of the existing project.

New project name:

Enter the new project name in this field.

# DXF: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_dxf.htm)

### DXF

User interface / operation

Stands for "Data eXchange Format". Refers to an ASCII or binary file format from Autodesk for an AutoCAD drawing file used to export AutoCAD drawings to other applications or import drawings from other applications. Today it is the standard for exchanging data in mechanical design.

# Dialog Properties (special text): Project properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Master data > Plot frame / Form > Open > [Open].

- Insert > Special text > Project properties.
- You have double-clicked a project property (or selected the  Properties popup menu.In this case, several [project properties](Glossary_o_projekteigenschaften.htm) can also be selected).

In this dialog, you can select the project property which should be inserted into the [form](Glossary_o_verlauf.htm) / plot frame, and specify its [properties](Glossary_o_eigenschaften.htm) for format, language, and frame. These [special texts](Glossary_o_sondertexte.htm) are then filled in corresponding to the data entered from the program.

# P004085: Missing data type

### Cause

The value of the Data type property is empty at a PLC connection point that is an analog or digital input or output.

### Solution

1. Locate the PLC connection point in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the PLC connection point.
3. Bring the first tab to the front.
4. In the [properties](Glossary_o_eigenschaften.htm) table click the value field of the Data type property.
5. Use the [...] button to select the required data type.
6. Click [OK].
7. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Notes:

- [PLC connection points](Glossary_o_sps_anschluesse.htm) with the function definition PLC connection point, multi-function are also taken into consideration during this check run in as far as the type of signal in the connection point logic is set correspondingly to Digital input or Digital output or Analog input or Analog output.
- PLC [connection points](Glossary_o_anschluesse.htm) with the function definition PLC connection point, general and PLC connection point, variable are not taken into consideration during this check run.

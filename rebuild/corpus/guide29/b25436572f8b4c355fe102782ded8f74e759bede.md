# Create: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_erstellen.htm)

### Create

User interface / operation

If new objects (e.g., projects pages, etc.) are created manually, we speak of "creating". There is a menu entry "New" for this purpose. Even if objects are generated on the basis of something already in existence, we speak of "creating", e.g., if project templates are created based on an existing project.

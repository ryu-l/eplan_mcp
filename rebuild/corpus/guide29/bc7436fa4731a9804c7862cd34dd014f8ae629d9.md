# P026017: The structure identifier does not correspond to the mounting surface

### Cause

You created specific [project structure](Glossary_o_projektstruktur.htm) and defined identifierblocks to which you assigned [structure identifiers](Glossary_o_strukturkennzeichen.htm). Now there are conflicting structure identifiers for the placed [part](Glossary_o_artikel.htm) and for the corresponding mounting surface, in one of the [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm).

### Solution

1. Enter the same structure identifiers for the relevant identifier [blocks](Glossary_o_bloecke.htm) (e.g. for "Higher-level function" and / or "Mounting location") for the placed part and the corresponding mounting surface (in the Properties <...> dialog under Displayed DT).
2. Then start a new check run.

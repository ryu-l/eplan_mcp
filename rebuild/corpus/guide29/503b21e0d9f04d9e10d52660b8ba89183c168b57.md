# Copper Bundles in Mounting Lists

For the 3D [part placements](Glossary_o_artikelplatzierungen.htm) of a [layout space](Glossary_o_bauraum.htm), [reports](Glossary_o_auswertungen.htm) of the Mounting list type can be output in EPLAN Pro Panel. Mounting lists are used to map in a report the hierarchical structure of a mounting layout in the layout space. This report can also be generated for copper [bundles](Glossary_o_straenge.htm) and copper [items](Glossary_o_bauteile.htm).

In such a function-based report, the copper bundles are evaluated for which the Create mounting list ([ID](Glossary_o_id.htm) 36032) property has been activated in the [property dialog](Glossary_o_eigenschaftendialog.htm). This property can be selected via property selection for all 3D [objects](Glossary_o_objekte.htm) (except for [mounting surfaces](Glossary_o_montageflaechen.htm)). For a [copper bundle](Glossary_o_kupferstrang.htm) with the activated property, the output mounting list will show all copper items contained therein. The listed objects are sorted by legend item by default.

### Forms for mounting lists

In creating the mounting list, the [form](Glossary_o_verlauf.htm) is used that was specified in the project-specific Settings: Output to pages dialog for the "Mounting list (\*.f32)" form type. You can select [placeholder texts](Glossary_o_platzhaltertexte.htm) for the [forms](Glossary_o_formulare.htm) of this type in the Placeholder texts - Mounting list dialog. The same placeholder texts are available for selection in both the header and data area.

### Filtering in the layout space navigator

If you want to know which [devices](Glossary_o_betriebsmittel.htm) have been set aside for the generation of the mounting list, [create](Glossary_o_erstellen.htm) a new filter for the layout space navigator and select for such filter the Create mounting list property as a filter criterion.

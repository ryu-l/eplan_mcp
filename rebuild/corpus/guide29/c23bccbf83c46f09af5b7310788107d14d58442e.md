# Editing a Device List

Precondition:

You have opened a project page.

### Create entries

You have two ways of inserting parts into the device list: Either insert a [part](Glossary_o_artikel.htm) using the part selection, or [create](Glossary_o_erstellen.htm) a new part directly in the device list.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Parts / Devices > Device list
2. Select the Add part popup menu item.
3. In the Part selection dialog select the desired part.
4. Click [OK].
5. You store the part-specific data in the dialog Properties.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The part is inserted into the device list with the permitted quantity of "1".
6. Select the New popup menu item.
7. Assign a part number in the dialog Properties <...>. Click [...] to open the part selection and select an existing part.
8. In the Number allowed field enter the number of these parts that may be used in the project.
9. In the fields Part section and Device description enter the name of the part section in which the device is mounted (for example "Conveyor element 15") as well as a description of the functionality for the part. The device list can be sorted according to these descriptions by clicking the column headers.
10. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The part is inserted into the device list with the specified permitted quantity.

### Edit entries

1. Select the desired part in the device list.
2. Select the Properties popup menu item.
3. If required, change the values in the Part number, Number allowed as well as Part section, and Device description fields in the dialog Properties <...>.   
     
   ![](../Pictures/Gui/ALL/arrow.png) All other fields are filled automatically and cannot be changed.
4. Click [OK].

### Delete entries

1. Select one or more parts in the device list.
2. Select the Delete popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected parts are deleted from the device list. This has no effect on the placement of the relevant part. It merely means that the relevant part is no longer monitored.

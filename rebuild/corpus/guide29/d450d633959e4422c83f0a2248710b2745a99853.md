# Tab Wires (Komax)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Wire fabrication > Komax > Wires
- Utilities > Manufacturing data > Wire fabrication > Komax. Click [...] next to the Scheme field. Select the Wires tab.

In this tab, you specify the wire [master data](Glossary_o_stammdaten.htm) for the processing of [wires](Glossary_o_draehte.htm) on the Komax machine.

Overview of the main dialog elements:

Toolbar:

| Button | Meaning |
| --- | --- |
| (Update) | Imports the wires and wire parts from the project again. |
| (Delete) | Deletes a selected row. |

Color:

Identifier for the color of wire, e.g., Blk = black.

Cross-section:

Identifier for the cross-section of wire, e.g., 2.5 = 2.5 mm.

Part number:

Part number of the wire [part](Glossary_o_artikel.htm).

Komax WireKey:

Wire key; identifier for cross-section and color of wire, e.g., 2.5 blk = 2.5 mm black.

Komax FontKey:

Identifier for transfer to font definition in the machine. The default is the value of the wire key (Komax WireKey). Font, font size and font color with which the wire is actually to be printed via this identifier are defined under the same designation at the Komax machine as the parameter set.

Distance 1st side / Distance 2nd side:

Distance at which the labeling is printed from either end of the wire.

Distance continuous text:

If the labeling is printed on the wire as endless text, you must enter here the distance between the individual [blocks](Glossary_o_bloecke.htm) of text.

Stripping length:

Length in mm on which the machine is to cut off the insulation.

![](../Pictures/Visualisation/ALL/productionwiringgui_cutofflength_as.png)

Pull-off length:

Length in mm on which the machine is to remove the cut-off insulation from the wire.

In the case of completely stripping the wire end there is the danger, especially for stranded wires, that the open ends splice during further machining and the wire cannot be led through the machine any more.

![](../Pictures/Visualisation/ALL/productionwiringgui_splicedends_as.png)

To prevent this, the cut-off end is withdrawn just a tiny bit from the wire. The removed piece is retained on the wire as a protection of the wire end and is removed during [wiring](Glossary_o_verdrahtungen.htm). Depending on the machine, this value is valid for both wire ends.

![](../Pictures/Visualisation/ALL/productionwiringgui_stripofflength_as.png)

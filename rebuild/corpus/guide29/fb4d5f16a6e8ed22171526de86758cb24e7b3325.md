# Moving Property Texts to Model Views

The Move property texts command activates the insertion points of the [property texts](Glossary_o_eigenschaftstexte.htm) of [items](Glossary_o_bauteile.htm) in a model view and these are made visible by clicking on the individual components. The text can then be moved using Drag & Drop.

Preconditions:

- You have opened a page containing a model view.
- Displaying the item label is switched on.

1. Select the model view.
2. Select the Move property text popup menu item.
3. Select the property text you wish to move.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The element points of the property text are shown as small square frames.
4. Move the property text. Make sure that any leader line that may have been set is moved as well. (Leader [lines](Glossary_o_leitungen.htm) are defined in the Display tab under Border.)

![](../Pictures/Gui/ALL/info.png)Tip:

If you hold the [Shift] key down while moving, the current [grid](Glossary_o_raster.htm) snap is "divided by four". The insertion point can then be moved in steps of a one-fourth of the grid size.

### Reset moved property texts

You can use the Reset moved property texts option to delete all moved (thus copied) property texts of selected items. The property texts are shown again which are stored in the item. (Each item contains the information which property texts are displayed by default when inserting this item.)

1. Select the desired items and choose the menu items Edit > Text > Reset moved property text.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The copied property texts of all items will be deleted, and the default property texts of the item will be displayed.

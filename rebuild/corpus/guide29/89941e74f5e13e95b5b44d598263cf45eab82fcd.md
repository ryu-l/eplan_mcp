# Exporting Manufacturing Data for EPLAN Smart Wiring

The manufacturing data of EPLAN Smart Wiring are exported into an EPDZ file via a separate interface. The EPDZ file contains the [project properties](Glossary_o_projekteigenschaften.htm), page [properties](Glossary_o_eigenschaften.htm), and [layout space](Glossary_o_bauraum.htm) properties, and thus also the complete [project structure](Glossary_o_projektstruktur.htm) as well as the connection data and [cable properties](Glossary_o_kabeleigenschaften.htm) for the [routing connections](Glossary_o_verlegeverbindungen.htm). The EPDZ file also contains an E3D file with the 3D graphic data for each layout space.

Preconditions:

- You have opened a project.
- The layout space navigator is open and a layout space is open.
- You have created routing [connections](Glossary_o_verbindungen.htm).

1. Select the menu [items](Glossary_o_bauteile.htm) Utilities > Manufacturing data > EPLAN Smart Wiring.
2. In the EPLAN Smart Wiring dialog select the file name and the output directory for the EPDZ file.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the set output directory, the EPDZ file is generated with the pre-selected name. This file is read in in EPLAN Smart Wiring.

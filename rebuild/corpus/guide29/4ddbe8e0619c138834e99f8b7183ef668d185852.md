# P005049: More than one net definition point on a net

### Cause

A net contains more than one net definition point.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

A net in the schematic contains two [net definition points](Glossary_o_netzdefinitionspunkte.htm) (see circles in the following figure).

![](../Pictures/Visualisation/ALL/messages_005049_bsp_av.png)

### Solution

A net must not contain more than one net definition point. Any superfluous net definition points should be deleted. Proceed as follows:

1. Locate the first net definition point of the net in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Use the Go to 2nd coordinate function from the popup menu to search for other net definition points that have been placed multiple times in the net.
3. Delete the net definition points that have been placed multiple times from the schematic.
4. Then start a new check run.

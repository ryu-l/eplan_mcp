### Placeholder objects

User interface / operation

A placeholder object can be assigned to one or more objects. Variables can be assigned to the properties of these objects. A placeholder object is represented in EPLAN with a special "anchor" symbol and stored in the separate EPLAN322 layer, "Symbol graphic.Macro.Placeholder object".

# P026033: Bundle distributed in several bundle groups

### Cause

A connection has been assigned to a [bundle](Glossary_o_buendel.htm) which has already been assigned to another bundle group.

### Solution

1. Locate the connection in the [layout space](Glossary_o_bauraum.htm) using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Double-click the displayed connection to open the Properties dialog.
3. Assign the connection to the correct bundle and the correct bundle group by entering valid [designations](Glossary_o_bezeichnungen.htm) in the Bundle and Bundle group fields of the Properties group box. When assigning the designations make sure that the same bundle group may be contained in different [bundles](Glossary_o_straenge.htm), but the same bundle may not be [part](Glossary_o_artikel.htm) of several bundle groups.
4. If necessary repeat the bundle and bundle group designation for further [connections](Glossary_o_verbindungen.htm).
5. Then start a new check run.

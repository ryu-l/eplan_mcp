# Subprojects

Extensive [projects](Glossary_o_projekte.htm) are often edited by a team consisting of several [editors](Glossary_o_editoren.htm). For this use case you can divide the projects in the EPLAN Platform into so-called "[defined working sections](workingsection_k_start.htm)". This makes the display of large projects more transparent and increases the editing speed. Such a procedure only makes sense, however, if the team only consists of internal persons and a powerful network is available.

If external persons who do not have access to the company network are to be used for editing extensive projects, or if editing is to be carried out independently of a network connection, you can use the Subprojects functionality to divide these projects into subprojects. After the division the created subprojects can be stored on local workstations by means of a backup or sent to external editors for further editing.

The following [actions](Glossary_o_aktionen.htm) are possible:

- The dialog Subprojects that can only be used at exclusively opened projects lists all the defined working sections specified in the project. Each defined working section represents a possible subproject.

  ![](../Pictures/Gui/ALL/note.png)Note:

  When you select the menu [items](Glossary_o_bauteile.htm) Project > Subprojects, an internal check is carried out whether the project is opened exclusively. If this is not the case, the project is closed and automatically opened exclusively. If this is not possible, a message is displayed that [exclusive access](Glossary_o_exklusiverzugriff.htm) is not possible and the action is aborted.
- The creation and filing off of subprojects allows extensive projects to be divided so that they can also be edited by external persons (with installed EPLAN program [variants](Glossary_o_varianten.htm)) .
- Filing a subproject off to a local data medium allows a defined [part](Glossary_o_artikel.htm) of a project to be edited - even when a permanent network connection to the original project is not available.

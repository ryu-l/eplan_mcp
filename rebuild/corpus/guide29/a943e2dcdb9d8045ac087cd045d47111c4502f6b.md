# Dialog Export settings

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings. Select one of the [settings](Glossary_o_einstellungen.htm) areas "User" or "Workstation" and click ![](../Pictures/Gui/ALL/all_export_as.png) (Export).

In this dialog you define the target file where the selected settings area is to be exported to.

Overview of the main dialog elements:

<Hierarchy path>:

The text next to the check box shows which settings area is selected in the tree view of the Settings dialog. If the check box is selected, the selected settings area and all subordinate areas are exported.

Other settings areas:

Here you define which other program settings and [configurations](Glossary_o_konfigurationen.htm) are to be exported. If a check box is selected, this is exported. The available check boxes depend on the settings area selected in the tree view of the Settings dialog.

![](../Pictures/Gui/ALL/note.png)Note:

These other settings are only available for the settings areas "User", "Workstation", and "Company". For project settings, therefore, the check boxes described below are grayed out and cannot be activated.

- Property configuration Exports the property configurations for [devices](Glossary_o_betriebsmittel.htm), pages, etc. that you have defined in the Properties <...> dialog, via the Configure popup menu item.
- Dialog memory: Exports, for example, the size, position on the screen, screen resolution, "minimized" / "maximized" status, and the column widths of the dialogs.

  ![](../Pictures/Gui/ALL/note.png)Note:

  When importing / exporting the settings for the dialog memory, it is a good idea to set the same resolution on all the different workstations. Different screen resolutions can result in dialogs no longer being displayed in the visible area of the screen.
- Tree and list configurations: Exports all configurations for the tree and list views of the [navigators](Glossary_o_navigatoren.htm) which have been determined via the popup menu item Configure representation.
- External programs: Exports the lists for fast access to external programs that you defined using the Options > External programs menu [items](Glossary_o_bauteile.htm).
- Filter: Exports all the user-defined filter settings.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Target file:

A file path and name for the export file are suggested in this field. By default, the export file receives a name reflecting the selected area in the tree view of the Settings dialog. The file name consists of the following elements: <Main category>+<Sub-category>+<Settings area>.xml. Using [...] you can enter a file name and directory path for the export file.

# P501001: The macro <x> <y> entered at the part does not exist

### Cause

In the parts database to be checked a [part](Glossary_o_artikel.htm) was found where a macro, a graphical macro or a symbol macro was entered which EPLAN cannot find. The path and name of the macro are output in the placeholder <x>, the macro type in the placeholder <y>.

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective part is already marked in it.
2. Depending on the macro type output in the message bring the Technical data tag ("Macro" macro type), the Mounting data tab ("Graphical macro" macro type) and / or the Function templates tab ("Symbol macro" macro type) to the foreground.
3. In the corresponding tab click [...] next to the field Macro and / or Graphical macro and / or Symbol macro and from the selection dialog that is opened select the required macro from one of the directories offered.  
     
   Or alternatively delete the entered macro in the field Macro, Graphical macro and / or Symbol macro.  
     
   Or [create](Glossary_o_erstellen.htm) a new macro, graphical macro and / symbol macro, and save it in the desired macro directory. Then select it again in the Macro field, Graphical macro field and / or Symbol macro field.
4. Close the parts management, save the modified data, and carry out a parts synchronization.
5. Then start a new check run.

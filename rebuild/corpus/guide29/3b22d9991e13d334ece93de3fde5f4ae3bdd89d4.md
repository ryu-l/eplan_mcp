# P001011: Terminal strip without terminals

### Cause

You created a terminal strip definition without a terminal in the terminal strip Navigator or placed it in the schematic.

### Solution

Create at least one terminal in the terminal strip navigator by using the popup menu New, or place at least one terminal in the schematic via Insert > Symbol. Assign the DT terminal strip definition to the terminal and give it a designation.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

# P028030: The pipe class entered at the piping definition point does not correspond to the pipe class '<x>' of the linked piping planning object

### Cause

A different pipe class is entered at a piping definition point placed in a [P&I diagram](Glossary_o_ri_fliessbild.htm) that is linked with a piping planning object in the pre-planning than at a linked piping planning object.

### Solution

1. Locate the piping planning object in the pre-planning navigator using the Synchronize selection function offered by the popup menu in the Message management dialog.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the piping planning object and bring the first tab to the front.
3. In the Pipe class field select the pipe class designation <x> that is output in the message text or enter it manually.
4. Click [OK].
5. Then start a new check run.

# P004081: Missing station ID

### Cause

The specification of the station name is missing at a PLC box. This information is required for a correct PLC data export from EPLAN.

This check run only checks [PLC boxes](Glossary_o_sps_kaesten.htm) which are [main functions](Glossary_o_hauptfunktionen.htm) and at which a configuration project is entered.

### Solution

1. Locate the PLC box in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the PLC box.
3. Bring the PLC structure data tab to the front.
4. Assign a corresponding name in the Station [ID](Glossary_o_id.htm) field or select an entry from the drop-down list.
5. Click [OK].
6. Then start a new check run.

# P002010: Incorrect saddle jumper formation

### Cause

#### Option 1

You bridged two plug [pins](Glossary_o_steckerkontakte.htm) by using brackets in the schematic. The existing connection between the two pins also has a connection definition point whose function definition is set to "saddle jumper". In the connection point logic [properties](Glossary_o_eigenschaften.htm) of the contacts, the Number of saddle jumpers field is set to "0" for all function [connection points](Glossary_o_anschluesse.htm). This creates a conflict relating to the saddle jumper formation.

#### Option 2

You bridged two plug pins without using brackets. You created the jumper with the property Saddle jumper, by selecting the setting "Start of jumper" for the first pin and "End of jumper" for the second pin. In the connection point logic properties of the contacts, the Number of saddle jumpers field is set to "0" for all function connection points. This creates a conflict relating to the saddle jumper formation.

### Solution

#### Regarding option 1

Increase the value for the number of saddle jumpers on both plug pins [connections](Glossary_o_verbindungen.htm). Double-click the pin in the schematic and in the Properties <...> dialog select the Symbol / function data tab. In the Function data group box, click [Logic]. Increase the value of the property for one or both function connections Number of saddle jumpers to at least "1".

Or change the function definition at the connection definition point. (e.g. choose the setting "Connection general".)

#### Regarding option 2

Increase the value for the number of saddle jumpers on both plug pin connections (see option 1).

Refresh the connections and then start a new check run.

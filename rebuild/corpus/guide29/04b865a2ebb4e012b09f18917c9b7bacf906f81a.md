# Defining Unique PCT Loop Numbers

You can specify whether [PCT loop numbers](Glossary_o_plt_stellennummern.htm) have to be unique within a project or whether they may occur several times up to a specified hierarchy level. If (e.g.) you have defined that a PCT loop number may only occur once in the project, then it is not possible to [create](Glossary_o_erstellen.htm) two [PCT loops](Glossary_o_plt_stellen.htm) with the same PCT loop number in the project.

Precondition:

You have opened a project.

1. Options > Settings > Projects > "Project name" > Pre-planning > Numbering / PCT loops
2. To define that a PCT loop number may only occur once in the project, select the option "No" in the Allow PCT loops of identical designation field.
3. To define that a PCT loop number may occur several times in the project, select the option "Up to level in tree" in the Allow PCT loops of identical designation field.
4. Subsequently enter the desired hierarchy level in the In miscellaneous segments up to level in tree field.   
     
   ![](../Pictures/Gui/ALL/arrow.png) Within the determined hierarchy level and in the superior hierarchy [levels](Glossary_o_etagen.htm), PCT loop [designations](Glossary_o_bezeichnungen.htm) may occur several times, but only in different branches. Within the same branch, PCT loop designations must always be unique.
5. Click [OK].

# P026101: Automatic wiring not possible: <x>

An error occurred during the automatic [wiring](Glossary_o_verdrahtungen.htm) process with the Rittal - Averex wiring robot. The text with the error cause is output in the placeholder <x> of the message. In some messages the connection point designation is output additionally. The placeholder <y> is used to this purpose.

| Cause | Additional information | Solution |
| --- | --- | --- |
| Connection category for connection point <y> not configured | The Rittal Averex wiring robot currently supports only the [connection categories](Glossary_o_anschlussausfuehrungen.htm) Screw connection and Push-in connection. | Check the configuration of the connection categories in the [settings](Glossary_o_einstellungen.htm) of the "Averex Center" software and correct the configuration if required.  Or replace the item temporarily by a placeholder item for the automatic wiring. |
| Number of [connections](Glossary_o_verbindungen.htm) at connection point <y> too high | Two or more connections are to be connected to the same connection point. Currently only one connection to one connection point can be realized for the automatic wiring with the Rittal Averex wiring robot. | Replace the item temporarily by a placeholder item for the automatic wiring. |
| Impermissible wire cross-section | The wire cross-section of the connection is either smaller than or greater than the cross-section range that is configured in the settings of the "Averex Center". | Check the configuration of the wire cross-sections in the settings of the "Averex Center" software and correct the configuration if required. |
| Conductor end sleeve not configured | The required conductor end sleeve does not exist physically and / or is not configured in the "Averex Center" settings. | Check the configuration of the conductor end sleeves in the settings of the "Averex Center" software and correct the configuration if required. |
| Connection too short | The connection is too short. Therefore automatic wiring is not possible. | Check the value for the minimum length in the settings of the "Averex Center" software and correct it if required. |
| Tool for connection point <y> not configured | A tool with the required socket size does not exist physically and / or is not configured in the "Averex Center" settings. | Check the value for the socket size in the EPLAN connection point pattern and correct it if required.  Or check the configuration of the conductor end sleeves in the settings of the "Averex Center" software and correct the configuration if required. |
| Clamping space [offset](Glossary_o_offset.htm) at connection point <y> too large | The clamping space offset is greater than the maximum gripper offset. The clamping space offset is set in the EPLAN connection point pattern and specifies how far the clamping space of a connection point is offset from the item outer edge into the item inside. The maximum gripper offset is defined in the settings of the "Averex Center" software and specifies how far - offset from the conductor end depending on the conductor cross-section - the conductor can still be held by the gripper without bending through due to gravity. | Check the value for the clamping space offset in the EPLAN connection point pattern and correct it if required.  Or check the value for the maximum gripper offset in the settings of the "Averex Center" software and correct it if required. |
| Gripper / tool offset at connection point <y> too large | The offset between the gripper (holding of the conductor) and tool (connecting of the conductor) is too large. | Check the value for the maximum permissible offset between the gripper and tool in the settings of the "Averex Center" software and correct it if required. |
| Mounting panel too large | The dimensions (width / height) of the mounting panel are too large. | Due to its dimensions the mounting panel cannot be wired automatically. The maximum permissible dimensions are specified in the documentation of the Rittal Averex wiring robot. |
| Warning limit for the maximum height exceeded | The total height of the mounting panel with all the mounted parts is greater than the warning limit. | Check the value for the warning limit in the settings of the "Averex Center" software and correct it if required.  Or replace the item temporarily by a placeholder item for the automatic wiring.  Or exclude the item from the automatic wiring and remove it temporarily from the mounting panel. |
| Information limit for the maximum height exceeded | The total height of the mounting panel with all the mounted parts is greater than the information limit. | Check the value for the information limit in the settings of the "Averex Center" software and correct it if required.  Or replace the item temporarily by a placeholder item for the automatic wiring.  Or exclude the item from the automatic wiring and remove it temporarily from the mounting panel. |
| Distance from connection point <y> to wire duct too small | The distance between the [part](Glossary_o_artikel.htm) placement and a wire duct is smaller than the total of the maximum gripper offset plus the gripper depth. | Check the value for the maximum gripper offset in the settings of the "Averex Center" software and correct it if required.  Or check the value for the gripper depth in the settings of the "Averex Center" software and correct it if required. |
| Impermissible connection point direction at connection point <y> | The connection point direction is impermissible if it is not equal to 0° at a screw connection and is not equal to 90° at a push-in connection - in relation to the mounting panel. | Check the value - depending on the connection category - for the permissible connection point direction in the settings of the "Averex Center" software and correct it if required. |
| Impermissible tool operating direction at connection point <y> | The tool operating direction describes the direction of a tool (for example of a screwdriver) that is necessary to tighten the terminal screw for the connection point.  The tool operating direction is impermissible if it is not equal to 90° at a push-in connection - in relation to the mounting panel. | Check the value for the tool operating direction in the EPLAN connection point pattern (X / Y / Z direction: Tool [properties](Glossary_o_eigenschaften.htm)), and correct it if required.  Or check the value for the tool operation direction in the settings of the "Averex Center" software and correct it if required. |
| Wire duct data do not exist | The parts data for a wire duct are incomplete. | Complete the parts data for the wire duct in the EPLAN parts management.  The following parts data are required additionally for an automatic wiring:   - Finger width - Slot width - Distance of the pinch point. |
| Several [connection points](Glossary_o_anschluesse.htm) with identical tool operation | Only one tool operation is required for the wiring of connections to connection points that are different but have identical [designations](Glossary_o_bezeichnungen.htm). | Check the values for the socket size in the EPLAN connection point pattern and correct them if required.  The tool operation is defined by means of the following connecting point pattern properties:   - X position: Tool - Y position: Tool - Z position: Tool - X direction: Tool - Y direction: Tool - Z direction: Tool. |
| Max. number of conductor end sleeves exceeded | The Rittal - Averex wiring robot can maintain a maximum of only four different conductor end sleeves for the automatic wiring. | Change the connection definition so that an automatic wiring is possible with one of the four conductor end sleeves is possible. |
| Max. number of [conductors](Glossary_o_adern.htm) exceeded | The Rittal - Averex wiring robot can maintain a maximum of sixteen different conductors. | Change the connection definition so that an automatic wiring is possible with one of the sixteen conductors is possible. |
| Max. number of tools exceeded | The Rittal - Averex wiring robot can maintain a maximum of six different tools. | Change the socket size in the connection point pattern so that an automatic wiring is possible with one of the six tools. |
| Max. gripper offset not configured |  | Check the value for the maximum gripper offset in the settings of the "Averex Center" software and correct it if required. |
| Impermissible connection category at connection point <y> | The connection category at the connection point is then impermissible if it is not a screw connection or push-in connection point. | Set the permissible connection categories in the settings of the "Averex Center" software. |
| Impermissible item inclination | An impermissible item inclination exists when the item is placed on a mounting rail that was mounted on an inclined bracket. The item is then inclined toward the mounting panel. | Change the item inclination or exclude the item from the automatic wiring. |
| Wire duct too narrow | The wire duct is too narrow for automatic wiring. This means that a wire duct has been placed with a low width either horizontally or vertically directly at the mounting panel edge and that the mounting panel size is furthermore either equal to or almost as large as the maximum permissible mounting panel size. | Replace the wire duct that is too narrow by a wider one. |
| Collision at the connection point <y> with the part placement | During the check of the wiring data it was determined that the Rittal - Averex wiring robot collides with the part placement during the automatic wiring. | Ensure that enough place is available for automatic wiring at the part placement by selecting a different part. |
| Collision at the connection point <y> with an adjacent part placement | During the check of the wiring data it was determined that the Rittal - Averex wiring robot collides with a neighboring part placement during the automatic wiring. | Change the 3D mounting layout so that sufficient space is available for automatic wiring between the [part placements](Glossary_o_artikelplatzierungen.htm). |
| Collision at connection point <y> with a lateral wire duct | During the check of the wiring data it was determined that the Rittal - Averex wiring robot collides with a neighboring part placement during the automatic wiring. | Change the 3D mounting layout so that sufficient space is available for automatic wiring between the part placement and the lateral wire duct. |
| Gripper / tool offset in Y direction at connection point <y> too large | During the check of the wiring data it was determined that the Y distance between the gripper (holding of the conductor) and tool (connecting of the conductor) is too large. | Specify the maximum distance between the gripper and the tool in the settings of the "Averex Center" software. |

After the data have been corrected, export the data for controlling the Rittal Averex wiring robot again.

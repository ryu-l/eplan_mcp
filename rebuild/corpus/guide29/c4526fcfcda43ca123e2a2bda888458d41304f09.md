# Automatically Generating Functions Using a Numbering Pattern

In EPLAN you can automatically [generate](Glossary_o_erzeugen.htm) several [unplaced functions](Glossary_o_nicht_platziertefunktionen.htm) by specifying a numbering pattern. The functionality can be used with the following [functions](Glossary_o_funktionen.htm):

- Terminals
- Pins
- Contactor contacts, relay coil contacts (NO, changer, NC)
- Device and PLC [connections](Glossary_o_verbindungen.htm)
- Busbars.

Depending on the selected function definition, the numbering pattern defines the number of new functions and the terminal, plug or [connection point designations](Glossary_o_anschlussbezeichnungen.htm). Using the numbering pattern 1a,1b,2a-8b you can (e.g.) [create](Glossary_o_erstellen.htm) 16 functions with the [designations](Glossary_o_bezeichnungen.htm) 1a,1b,2a,2b,3a,3b,4a,4b,5a,5b,6a,6b,7a,7b,8a,8b.

Precondition:

You have opened a project.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Devices > Navigator
2. Select an existing DT.
3. Select the New functions popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The full DT is entered into the Generate functions dialog. If you wish to generate a new DT, then enter a new full DT into the Generate functions dialog, in the Full DT field.
4. Click [...] next to the Function definition field and select a function definition from the subsequent dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The number of [connection points](Glossary_o_anschluesse.htm) of the selected function definition is entered into the Number of connection points field.
5. Enter the connection point designations to be used for the new functions into the Numbering pattern field.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Depending on the numbering pattern chosen, the number of functions that will be created is displayed in the Number of new functions field.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The functions are created in the device navigator.

![](../Pictures/Gui/ALL/info.png)Tip:

You can also create functions in the same manner in the PLC navigator, the terminal strip navigator and the plug navigator.

# Action: SetProjectLanguage

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| PROJECTNAME | Complete project name. The project must be open.  When executing from the Windows command line, ProjectAction must be used first. |
| DISPLAY | Displayed language (e.g., ). When specifying several languages, the individual language codes are separated by a semicolon (";"). |
| VARIABLE | One language (variable) displayed language. |
| SOURCE | Source language. |

![](../Pictures/Gui/ALL/note.png)Notes:

- SetProjectLanguage does not translate the project texts, but only modifies the display [settings](Glossary_o_einstellungen.htm). The action sets the languages in which the translated project text is displayed in the project pages.
- In case of read-only [projects](Glossary_o_projekte.htm), the displayed language is modified by SetProjectLanguage only temporarily; this setting is not stored in the project.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
SetProjectLanguage 
/DISPLAY:;de_DE 
/VARIABLE:
```

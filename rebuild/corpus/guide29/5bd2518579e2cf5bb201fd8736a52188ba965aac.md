# Dialog Settings: Connection numbering

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Options > Settings > Projects > "Project name" > Connections > Connection numbering
- You have selected a connection in the graphical editor, or in the Connections - <Project name> navigator dialog. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog. Project data > Connections > Numbering > Place > [...].

In this dialog you specify which [function definitions](Glossary_o_funktionsdefinitionen.htm) of [connections](Glossary_o_verbindungen.htm) are to be numbered, how often the [connection designations](Glossary_o_verbindungsbezeichnungen.htm) should be placed, and how the connection [designations](Glossary_o_bezeichnungen.htm) should be formatted. Save these [settings](Glossary_o_einstellungen.htm) in a scheme.

Overview of the main dialog elements:

The project for which you are defining the settings is displayed in the title bar.

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

In the tab specify the settings for [connection numbering](Glossary_o_verbindungsnummerierung.htm):

- [Tab Filter](wirenumberinggui_r_filter.htm)
- [Tab Placement](wirenumberinggui_r_platzierung.htm)
- [Tab Designation](wirenumberinggui_r_bezeichnung.htm)
- [Tab Display](wirenumberinggui_r_anzeige.htm).

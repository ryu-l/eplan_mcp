# Placing Function Templates and PLC Addresses of Planning Objects

From within the pre-planning navigator, you can place [function templates](Glossary_o_funktionsschablonen.htm) and [PLC addresses](Glossary_o_sps_adressen.htm) assigned to a planning object on a project page as many times as you want. In the process, it does not matter if these [objects](Glossary_o_objekte.htm) have already been placed, are unplaced, or are of a different representation type. Specify the representation type when you place a function. The generated representation type does not depend on the type of page on which the object is placed.

In the event of a multiple selection, placement is possible only if identical objects are highlighted.

Preconditions:

- You have opened a project.
- You have opened the pre-planning navigator.
- You have opened a project page.

The following describes placement with the "Multi-line" representation type. Placement in the other [representation types](Glossary_o_darstellungsarten.htm) works the same way.

### Placing function templates

During the placement of [planning objects](Glossary_o_planungsobjekte.htm), all function templates stored at the planning objects are placed. These templates can be entered directly at the planning object, or they can originate from a [part](Glossary_o_artikel.htm) stored there.

During the placement of individual function templates, the suitable [functions](Glossary_o_funktionen.htm) are determined and placed.

1. Highlight a planning object or individual function template in the pre-planning navigator.
2. Select the Place popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The functions found for the templates hang on the cursor, and can be placed one by one.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If no function has been found for a template, the symbol selection opens.
3. Place the functions one by one in the schematic.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The functions created during the placement are linked with the planning object from which they were placed.

### Placing PLC addresses

During the placement of PLC addresses, the associated function definition is determined from the [properties](Glossary_o_eigenschaften.htm) Data type and Direction. The PLC connection point [symbols](Glossary_o_symbole.htm) that go with the [function definitions](Glossary_o_funktionsdefinitionen.htm) are placed. The function definitions with one connection point are used here.

1. Highlight one or several PLC addresses in the pre-planning navigator.
2. Select the Place popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The functions found for the PLC addresses hang on the cursor, and can be placed one by one.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If no function has been found for a PLC address, the symbol selection opens.
3. Place the functions one by one in the schematic.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The functions created during the placement are linked with the planning object from which they were placed.

![](../Pictures/Gui/ALL/info.png)Tip:

You can place planning objects, function templates, and PLC addresses using Drag & Drop by dragging a highlighted object from the navigator to your open page in the graphical editor. The function's representation type is automatically chosen independent of the page type.

### Placing macros

During the placement of [macros](Glossary_o_makros.htm), the part macro of the selected representation type is found and placed.

1. Select a planning object in the pre-planning navigator.
2. Select the Place popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The dialog Place device is opened. The Part macro option is preset.
3. From the Representation type drop-down list select the entry "Multi-line" and click [OK] in order to place the macro on a multi-line schematic page.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol of the part macro stored at the planning object hangs on the cursor.
4. Place the macro in the schematic.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The functions created during the placement are linked with the planning object from which they were placed.

# P501004: The function definition <x> entered at the part is obsolete

### Cause

In the parts database to be checked a [part](Glossary_o_artikel.htm) was found where a function definition was entered which is obsolete and therefore no longer permissible.

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective part is already marked in it.
2. Bring the Function templates tab to the front.
3. In the Device selection ([function templates](Glossary_o_funktionsschablonen.htm)) table click the entry in the Function definition column that contains the obsolete no longer permissible function definition and click [...].
4. Select an up-to-date function definition from the Function definitions dialog that is opened.
5. Close the parts management, save the modified data, and carry out a parts synchronization.
6. Then start a new check run.

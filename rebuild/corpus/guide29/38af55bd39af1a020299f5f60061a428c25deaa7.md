# P001031: The distributed terminal could not be included in optimization. <x>

### Cause

If a distributed terminal can not be considered for optimization this may be due to the following reasons:

- The distributed terminal uses unknown [connection point designations](Glossary_o_anschlussbezeichnungen.htm). For example, the distributed terminal to be optimized has certain connection point [designations](Glossary_o_bezeichnungen.htm) that you also want to retain after optimization. For this you have activated the Keep existing connection point designations check box in the Optimize [distributed terminals](Glossary_o_teilklemmen.htm) dialog, but later selected a terminal item for optimization that provides additional connection point designations via its function definition.
- The distributed terminal has more [connection points](Glossary_o_anschluesse.htm) than the function definition of the newly selected terminal [part](Glossary_o_artikel.htm). For example, a part was chosen for optimization and its function definition has fewer connection points than the distributed terminal that is to be optimized.
- The new function definition is invalid. For example, a non-terminal part was selected for optimizing the relevant distributed terminal.

The various causes are output in the message text with the placeholder <x>.

### Solution

1. Locate the distributed terminal in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. For all three cases select a terminal part with an appropriate function definition and matching connection point designations.

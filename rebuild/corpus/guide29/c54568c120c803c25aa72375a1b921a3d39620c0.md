[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_makrokaesten.htm)

### Macro boxes

User interface / operation

An aid for creating and editing macros in macro projects as well as revising macros in schematic projects. Full macro box functionality is only available in macro projects: The outlines and the data from macros to be generated automatically are determined with the help of macro boxes.

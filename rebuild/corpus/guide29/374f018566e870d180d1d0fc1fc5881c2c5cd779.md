# Editing Legend Items

The 3D mounting layout also has the option of editing legend [items](Glossary_o_bauteile.htm) and changing numbering.

Preconditions:

- You have opened a project.
- The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open.

1. In the layout space navigator, select a layout space with legend items to be edited.
2. Select the Edit legend item popup menu item.
3. In the Edit legend item dialog, change the entries in the Legend item column manually, or use [Number] to open the Number dialog. There you can change the numbering [settings](Glossary_o_einstellungen.htm) and renumber the legend items.
4. Confirm your entries.

# General requirements

The Microsoft .NET framework 4.7.2 is required to operate the EPLAN platform. Further information and the current version of this Microsoft [component](Glossary_o_schaltzeichen.htm) are available for download from the Microsoft website.

You can find further information on the supported operating systems and software approvals under:

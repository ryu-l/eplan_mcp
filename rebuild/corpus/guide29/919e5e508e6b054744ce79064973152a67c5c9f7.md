# Dialog Page sorting <Report type>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Options > Settings > Projects > "Project name" > Reports > Output to pages. Click the [...] in the column Page sorting, e.g. in the summarized parts list line.
- Utilities > Reports > Generate > [Settings] > Output to pages. Click the [...] in the column Page sorting, e.g. in the summarized parts list line.
- Utilities > Reports > Generate. Select the Templates tab. Select a report template, click next to the Page sorting field in the Value column and select [...].

You define the [Page sorting for reporting](formgeneratorgui_k_seitensortierung.htm) in this dialog. The [page sorting](Glossary_o_seitensortierung.htm) specifies for which structure identifier [levels](Glossary_o_etagen.htm) of the page structure [report blocks](Glossary_o_auswertungsbloecke.htm) are to be generated. It is also possible to [generate](Glossary_o_erzeugen.htm) report [blocks](Glossary_o_bloecke.htm) dependent on the Output group [component](Glossary_o_schaltzeichen.htm) property.

![](../Pictures/Gui/ALL/note.png)Note:

Which types of page sorting are available depends on the report type. Total page sorting is the only option available for the "Forms documentation" report type, for example.

Overview of the main dialog elements:

Sort by / into:

Use the drop-down list to define the type of page sorting.

- From settings: (Not available in the Settings dialog.) If this option is activated, the [settings](Glossary_o_einstellungen.htm) specified in the project settings are used.
- Structure identifier: If this option is active, then use the check boxes in the lower [part](Glossary_o_artikel.htm) of the dialog to determine which [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) are to be evaluated in the report. At least one check box must be activated. If you have selected several identifier blocks, a report block is generated for each combination of [structure identifiers](Glossary_o_strukturkennzeichen.htm). The report blocks are sorted into the page structure according to their structure identifiers.
- Total: The Total page sorting generates a comprehensive report for the entire project. If this option is selected, all structure identifier levels will be allocated a reporting block. Depending on the amount of [project data](Glossary_o_projektdaten.htm), this report block may contain one or several [report pages](Glossary_o_auswertungsseiten.htm).   
  If you have selected additional identifier blocks, separate report blocks are generated for each combination of structure identifiers in addition to the total evaluation and sorted into the page structure at the corresponding locations. The settings for the identifier blocks are not available for function-related [reports](Glossary_o_auswertungen.htm).
- Output group: If this option is selected, a report block is generated every time the Output group component property changes. This setting cannot be combined with the other settings in the current dialog.
- Object identifier: If this option is activated, only the Document type check box is activated. When this is activated, the pages can be structured in accordance with the standard DIN EN 61355-1. In doing so, the object identifier assigns a document (i.e. a project page) to a certain object (e.g. a function, a location, or a product).

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You have exclusively selected the Total option for the report type "Table of contents". EPLAN generates a table of contents and thus a report block for the entire project. In this example, the report block contains 9 report pages.

![](../Pictures/Gui/ALL/formgeneratorgui_total_as.png)

If you have activated the Structure identifier option and additionally the Higher-level function and Mounting location check boxes, a separate table of contents is generated for each combination of [higher-level function](Glossary_o_anlage.htm) and [mounting location](Glossary_o_einbauort.htm), for example for =GB1+A1, =GD1+A2, =GL1+B2.Y1 etc. The tables of contents are sorted into the page structure, meaning that the table of contents for =GB1+A1 is sorted below A1, the table of contents for =GL1+B2.Y1 is sorted below Y1, etc.

![](../Pictures/Gui/ALL/formgeneratorgui_tocinstructure_as.png)

Structure / value table:

If the check box is activated in one of the fields "Functional assignment", "Higher-level function", etc., an individual reporting block will be generated for each structure identifier level of each identifier block (e.g. [functional assignment](Glossary_o_funktionalezuordnung.htm)). In this case the structure depth can be specified by using the drop-down list of the Value column: Here the entries "Full" and, if they exist, "Main identifier" and "Sub-identifier" are available. This setting cannot be combined with the Output group setting. Additionally, the Total setting will not be available for function related reports.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You have exclusively selected the check box Higher level function for the report type "Table of contents" and set the structure depth "Full". EPLAN generates a table of contents for every structure identifier level of the "Higher-level function" identifier block. for example =GB1, =GD1, =GD2 etc. This generates the report in several report blocks. The tables of contents are sorted into the page structure below the respective higher-level function.

![](../Pictures/Gui/ALL/formgeneratorgui_higherlevelfunction_as.png)

Use source / target:

This check box can only be activated for [cable](Glossary_o_kabel.htm) diagrams, cable overviews, cable-[connection diagrams](Glossary_o_anschlussplaene.htm) and connection lists.  
If the check box is selected, it is not the device tags of the cables that are used for page sorting, but those of the sources and targets. Cables with different structure identifiers for their source and target (such as mounting locations, for example), will be output in multiple structure identifiers.

Use placement:

If this check box is selected, when reporting [devices](Glossary_o_betriebsmittel.htm) into different project structures, it is not the structure identifiers of the devices that are considered, but the structure identifiers of the page on which they are placed.

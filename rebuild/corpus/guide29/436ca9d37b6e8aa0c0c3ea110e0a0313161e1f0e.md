# Tab Filter

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Options > Settings > Projects > "Project name" > Connections > Connection numbering. Select the Filter tab in the dialog Settings: Connection numbering.
- You have selected a connection in the graphical editor, or in the Connections - <Project name> navigator dialog. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog. Project data > Connections > Numbering > Place > [...]. Select the Filter tab in the dialog Settings: Connection numbering.

In this tab you can limit the [connections](Glossary_o_verbindungen.htm) to be numbered to specific [trades](Glossary_o_gewerke.htm) and connection types. This setting applies to the placement of [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) as well as [connection numbering](Glossary_o_verbindungsnummerierung.htm). Connection numbering places new connection definition points and writes [connection designations](Glossary_o_verbindungsbezeichnungen.htm) to existing definition points that the user has already placed in the schematic.

Overview of the main dialog elements:

Trade:

Select the appropriate check boxes in order to specify the trades whose connections should be numbered.

Function definition:

All available [function definitions](Glossary_o_funktionsdefinitionen.htm) for connections are listed in this field. Select the appropriate check boxes to specify which of these connections should be numbered.

The "Conductor / wire" function definition that can be set at the connection is divided here over several check boxes. This enables the connections of the "Conductor/ wire" type that are to be numbered to be set in greater detail. A distinction is made between single-line and multi-line connections and connections that are inside or outside a [cable](Glossary_o_kabel.htm).

- Conductor: Multi-line connection with the "Conductor / wire" function definition that is found inside a cable.
- Cable: Single-line connection with the "Conductor / wire" function definition that is found inside a cable.
- Wire: Multi-line connection with the "Conductor / wire" function definition that is found outside a cable.
- Wire bundle: Single-line connection with the "Conductor / wire" function definition that is found outside a cable.

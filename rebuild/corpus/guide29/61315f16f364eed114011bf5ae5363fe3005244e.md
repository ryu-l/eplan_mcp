[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_aktionen.htm)

### Actions

User interface / operation

An action is a program function that the "EPLAN" program executes and that has visible effects for the user. Some actions can be inserted as buttons in toolbars, other actions can be executed automatically via the "Automated processing" function, and some actions can be used when calling up EPLAN via a command line.

# P001035: Several distributed terminal connection points with the same designation: <x>

### Cause

The same connection point designation was assigned to several [distributed terminals](Glossary_o_teilklemmen.htm) in the project.

### Solution

1. Locate the corresponding distributed terminals in the project using the Go to (cross-referenced) or Go to (all [representation types](Glossary_o_darstellungsarten.htm)) functionalities offered by the popup menu of the Message management dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The distributed terminals are listed in the dialog Search results - <Project name> in the Go to tab.
2. Use the popup menu to call up the [property dialog](Glossary_o_eigenschaftendialog.htm) for each of the distributed terminals and assign a unique value to each distributed terminal in the Connection point designation field (Terminal tab).
3. Then start a new check run.

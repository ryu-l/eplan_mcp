# Tab Accessories

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have marked a [part](Glossary_o_artikel.htm) in the tree or list.

This tab is used to define the selected part as an accessory part or to assign [accessories](Glossary_o_zubehoer.htm) to it.

Overview of the main dialog elements:

Part is accessory:

Select this check box if the part is an accessory part. In this case it will be detected as an accessory when you select the device, and will appear in the Accessories list in the Device selection dialog. You will then also not be able to assign accessory parts and accessory lists to it.   
If the check box is not activated, the part is listed as a "normal" part (Main parts list in the Device selection dialog). Accessory parts and accessory lists can be assigned to such main parts.

Table:

Select the Required check box if the part is to contain a mandatory accessory part. Click [...] in the Part number / Name field to select a part / part variant or an accessory list from the part selection. (Multiple selection isn't possible here.) The relevant variant number of the part is then displayed in the Variant field. You can overwrite this entry if required.

The Record type field ("Component" or "Accessory list") is filled automatically. The field is for displaying information only and is grayed out.

In the Accessory placement field click [...], and select from the Select accessory placement dialog the accessory placement that is to be assigned to the respective [component](Glossary_o_schaltzeichen.htm). For this purpose, the corresponding accessory placements must have been generated previously in the "Accessory placement" hierarchy level.  
Note that the Accessory placement property is not available for accessory lists!

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

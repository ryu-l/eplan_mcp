# Dialog Settings: Fonts

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Graphical editing > Fonts.
- You have opened a project. Options > Settings > Projects > "Project name" > Graphical editing > Fonts.

In this dialog, you specify the fonts which may be used for editing in EPLAN. The fonts defined in the project [settings](Glossary_o_einstellungen.htm) have priority over the fonts defined in the company settings.

If a font that does not exist on the computer is specified in the project settings, then the appropriate font from the company settings is used. In copying [actions](Glossary_o_aktionen.htm) (e.g. inserting a macro) the target project settings are used.

The following dialog elements are available:

Font 1 through Font 10:

In these 10 fields, you can select one font apiece from the drop-down list. All fonts which are installed on your computer are offered.

![](../Pictures/Gui/ALL/note.png) Note:

Fonts selected here must be installed on every computer on which they should later be used.

# Editing Interruption Points

Precondition:

You have opened a project.You have opened a project page in the graphical editor.

1. Open the [properties](Glossary_o_eigenschaften.htm) dialog for an interruption point, for example by double-clicking the interruption point.
2. Enter the device tag that is to be displayed with the interruption point in the graphical editor in the Displayed DT field of the [Interruption point](devicetaggui_r_abbruchstelle.htm) tab in the dialog Properties <...>, or click [...] to open the dialog Place existing interruption point and there select an existing interruption point name.
3. If required, in the Full DT  field, click [...] to open the Full DT dialog and make changes to the full DT.
4. If required, enter further properties in the Interruption point tab and in the other tabs.
5. Click [OK].

![](../Pictures/Gui/ALL/info.png)Tip:

By default a subordinate DT cannot be entered at [interruption points](Glossary_o_abbruchstellen.htm). You can make this possible by changing the [project structure](Glossary_o_projektstruktur.htm) for the entire project in the [project properties](Glossary_o_projekteigenschaften.htm) and activating the [Extended reference identification](projectstructure_k_referenzkennzeichnung.htm). To do so activate the Extended reference identification check box in the [Structure](prjmanagementgui_r_struktur.htm) tab. Subsequently the edit fields for the DT are displayed in a table in the Full DT dialog. The DT and the subordinate DT are entered in separate [lines](Glossary_o_leitungen.htm) there.

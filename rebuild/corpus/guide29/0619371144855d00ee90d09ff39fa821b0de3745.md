# Inserting Busbars

The busbar symbol is stored in the SPECIAL.slk symbol library. It has four [variants](Glossary_o_varianten.htm) and the text positions are managed like [device connection points](Glossary_o_geraeteanschluesse.htm).

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the menu [items](Glossary_o_bauteile.htm) Insert > Box / connection point / mounting panel > Busbar connection point.
2. If required hold down the [Ctrl] key and move the mouse to page through the previous variants.
3. Place the symbol on the side.
4. Specify the busbar connection point [properties](Glossary_o_eigenschaften.htm) in the Properties <...> dialog.
5. Click [OK].
6. Proceed in a similar manner for all of the other busbar [connection points](Glossary_o_anschluesse.htm).
7. End the action via the Cancel action popup menu item or via the [Esc] button.

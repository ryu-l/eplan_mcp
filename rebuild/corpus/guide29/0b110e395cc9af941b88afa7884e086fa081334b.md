# P028004: The planning object has several parts with potential main functions

### Cause

Several parts have been assigned to one planning object. As a result, there are also several potential [main functions](Glossary_o_hauptfunktionen.htm) under the [function templates](Glossary_o_funktionsschablonen.htm). Potential main [functions](Glossary_o_funktionen.htm) are main functions whose [function definitions](Glossary_o_funktionsdefinitionen.htm) are preset with the "Main function" attribute. This preset attribute cannot be changed.

A planning object can have only one potential main function.

### Solution

1. Locate the planning object in question in the project using the Synchronize selection function offered by the popup menu in the Message management dialog.
2. In the pre-planning navigator, open the Properties <...> dialog of the planning object, and bring to front the Part tab.
3. Delete all unnecessary parts, so that at the planning object only one [part](Glossary_o_artikel.htm) with a unique potential main function remains.
4. Click [OK] to close the Property dialog, then start a new project check.

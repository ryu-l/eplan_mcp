# Updating Part Dimensions

The dimensioning of the parts can be subsequently changed, consequently necessitating an update.

Precondition:

You have opened a project.

1. Project data > Parts / Devices > 2D panel layout navigator
2. In the graphical editor, open the [panel layout](Glossary_o_schaltschrankaufbau.htm) page for which the update is to be performed.
3. Select Popup menu > Update part dimensions.
4. Click [Yes], to adopt the new [part](Glossary_o_artikel.htm) dimensions.
5. Click [Yes] for each further part.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The current part dimensions are added to the [part placements](Glossary_o_artikelplatzierungen.htm). In the process, the current dimensions of the part are internally checked for every part and for every differing value, a message is displayed allowing you to accept or discard the update.

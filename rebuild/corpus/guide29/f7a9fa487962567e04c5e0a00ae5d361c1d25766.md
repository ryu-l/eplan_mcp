# Dialog Settings: Macros

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > User > Graphical editing > Macros

In this dialog you define the [user-specific](Glossary_o_benutzerbezogen.htm) [settings](Glossary_o_einstellungen.htm) for graphical editing of [macros](Glossary_o_makros.htm).

Overview of the main dialog elements:

Use graphical macro selection:

If this check box is activated, the graphical macro selection is used at all positions in the EPLAN platform where macros are selected. This is true of the insertion of macros via the menu [items](Glossary_o_bauteile.htm) Insert > Window macro / symbol macro and Page > Page macro > Insert, of the [placing](Glossary_o_auflegen.htm) of macros in the [project data](Glossary_o_projektdaten.htm) [navigators](Glossary_o_navigatoren.htm), and of the selection of macros in parts management. When graphical macro selection is activated, you "browse" in a special selection dialog on the basis of stored [icons](Glossary_o_icons.htm), [symbols](Glossary_o_symbole.htm) or other image files through the directory structure and thus find the required macro easily.

If the check box is deactivated, the selection dialog of the graphical macro selection does not open when inserting macros.

Include nested macro boxes when inserting:

This functionality is important in particular when you work with macros that have been combined in a superior macro box. These so-called "nested" macros are used mainly at the designing of fluid schematics.

If the check box is activated, the original path and file name of the macro in the Macro ([ID](Glossary_o_id.htm) 20468) property field is retained at all the [functions](Glossary_o_funktionen.htm) of the subordinate macros that are combined in the superior macro box.

If the check box is deactivated, the name of the superior macro box is entered at all the functions of the subordinate macros in the Macro (ID 20468) property.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Two [symbol macros](Glossary_o_symbolmakros.htm) from the [master data](Glossary_o_stammdaten.htm) directory for FESTO macros, a 5-/2-directional control valve with the file name P\_V\_0054.ems and a double-acting cylinder with the file name P\_A\_0017.EMS a combined in a common macro box with the file name V\_Z\_001.ema, so that a nested macro exists. The nested macro itself is also stored in the FESTO macro directory. The Macro property was selected for display at the functions of the subordinate macros as well as at the superior macro box.

The nested macro is now inserted twice consecutively on a fluid schematic page. The first time the check box Include nested macro boxes when inserting is activated. After the macro has been placed, the path and file names at the functions of the subordinate macros within the nested macro are retained (see the following figure on the left). Now the check box is deactivated and the nested macro is inserted once more. This time the path and the file name of the superior macro box V\_Z\_001.ema is entered at all the functions of the subordinate macros in the Macro property (see the following figure on the right).

![](../Pictures/Visualisation/ALL/macrosgui_considernestedmacroboxes_av.png)

![](../Pictures/Gui/ALL/note.png)Note:

You can carry out a [part](Glossary_o_artikel.htm) selection at the functions and use the name of the subordinate macro as an automatic filter in the process. To this purpose the corresponding file names of the macros have to be stored at the parts to be selected.

Group box "Open value set selection dialog for placeholder objects"

Placeholder [objects](Glossary_o_objekte.htm) that were inserted into macros can contain value sets. Here you determine whether the selection dialog for value sets is displayed during the insertion of such macros.

When inserting window macros:

If this check box is selected, the Select value set - <Placeholder name> dialog opens when [window macros](Glossary_o_fenstermakros.htm) or symbol macros with [placeholder objects](Glossary_o_platzhalterobjekte.htm) are inserted.

![](../Pictures/Gui/ALL/note.png)Note:

If this setting is activated, the value set selection is also opened during the copying and pasting of placeholder objects as well as of window and symbol macros with placeholder objects.

When inserting page macros:

If this check box is selected, the Select value set - <Placeholder name> dialog opens when [page macros](Glossary_o_seitenmakros.htm) with placeholder objects are inserted.

![](../Pictures/Gui/ALL/note.png)Note:

This setting has no effect on the copying and pasting of project pages with placeholder objects. During such an action the value selection is not opened.

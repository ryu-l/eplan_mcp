# Extending Placeholder Objects

### Assigning additional objects to the placeholder object

In order to expand [placeholder objects](Glossary_o_platzhalterobjekte.htm), select other [objects](Glossary_o_objekte.htm) that should also belong to the placeholder object.

Precondition:

You have inserted a placeholder object on a page and in the process marked an area with objects that are to belong to the placeholder object.

1. Select the desired placeholder object in the graphical editor.
2. Select the Select associated objects popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The schematic elements belonging to the current placeholder object are marked.
3. Select other objects to be assigned by holding the [Ctrl] key.
4. Select the Assign objects to placeholder object popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected objects are (re-)assigned to the placeholder object.

### Assigning all the objects of a macro to the placeholder object

If not all objects of the macro are included in the selection during the preparation of [macros](Glossary_o_makros.htm) when inserting a placeholder object, you can correct this later on by means of a popup menu item.

Preconditions:

- You are in a macro project.
- You have inserted one or more objects in a project page, from which a macro is to be automatically generated, and you have defined the plan of the macro to be created, using a macro box.
- During the insertion of the placeholder object you have marked an area with objects that belong to a defining macro box or you have inserted a placeholder object on a page that belongs to a prepared page macro.

1. Select the desired placeholder object in the graphical editor.
2. Select the Select associated objects popup menu item.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The schematic elements belonging to the current placeholder object are marked.
3. Select the Assign all the objects of the macro to the placeholder object popup menu item.   
     
   ![](../Pictures/Gui/ALL/arrow.png) All the objects that clearly belong to the same prepared macro are assigned to the corresponding placeholder object.   
     
   ![](../Pictures/Gui/ALL/arrow.png) A corresponding message is displayed if the program cannot determine an associated macro box with the "Defining" type of usage or an associated page macro.

A placeholder object can also be inserted on the pages of a prepared page macro. You can assign all the pages of the page macro as well as the objects located on the pages to such a placeholder object by means of the popup menu item Assign all the objects of the macro to the placeholder object.

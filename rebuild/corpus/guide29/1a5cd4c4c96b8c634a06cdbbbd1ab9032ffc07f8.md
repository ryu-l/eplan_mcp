# P024016: Contradiction between connection DT and conduit DT

### Cause

A connection definition point, situated within reach of a conduit definition line, disposes of its own device tag. The conduit DT and the connection definition point DT do not correspond.

### Solution

Double-click the connection definition point in the schematic, and delete the displayed device tag of the connection definition point in the Properties <...> dialog.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

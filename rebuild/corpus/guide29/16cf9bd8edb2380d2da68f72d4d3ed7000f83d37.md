# Dialog Verify project

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have selected a project management database. You have read in directories and [projects](Glossary_o_projekte.htm). Project > Management. Select the input project with the advanced project status. Select [Extras] > Verify project.

In this dialog you specify which [actions](Glossary_o_aktionen.htm) are to be carried out by EPLAN during the project verification. When verifying projects, the [settings](Glossary_o_einstellungen.htm) and [properties](Glossary_o_eigenschaften.htm) of a comparison project are compared with those of an incoming project. Likewise, targeted [check runs](Glossary_o_prueflaeufe.htm) are carried out on the incoming project.

The following dialog elements are available:

Select comparison project:

Select the comparison project in this field. The comparison project is the original project to be compared to the incoming project. If the field does not contain a suitable comparison project, click ![](../Pictures/Gui/ALL/all_new_as.png) (New) and select a project in the subsequent dialog.

Compare settings:

If the check box is selected, all project-related settings from the comparison and incoming projects - which you selected in the Scheme field in the comparison scheme for the operation - will be compared with each other.

- Scheme: Select a comparison scheme for the settings comparison from this drop-down list. With this scheme, you check whether the project-related settings of the comparison and incoming projects match. You can use [...] to [create](Glossary_o_erstellen.htm) a new comparison scheme or edit an existing one. The comparison scheme is taken into consideration in the project comparison, as [part](Glossary_o_artikel.htm) of the project verification, if the Compare settings check box is selected.

![](../Pictures/Gui/ALL/info.png)Tip:

If you only want to compare the projects only with regard to the settings, the easiest way to do so is by using the search function within the settings: There simply enter the corresponding search term. This directly creates a type of filter, and the hierarchical tree structure is displayed for all the opened projects on the same tree structure.

Compare properties:

If the check box is selected, all properties from the comparison and incoming projects - which you selected in the Scheme field in the comparison scheme for the operation - will be compared with each other.

- Scheme: Select a comparison scheme for the properties comparison from this drop-down list. With this scheme you check whether the [project data](Glossary_o_projektdaten.htm) properties of the comparison and incoming projects match. You can use [...] to create a new comparison scheme or edit an existing one. The comparison scheme is taken into consideration in the project comparison, as part of the project verification, if the Compare properties check box is selected.

Perform project checks:

If the check box is selected, all project checks selected in the Scheme field in the check run scheme will be carried out during the project comparison as part of the project verification.

- Scheme: From this drop-down list select a check run scheme for the project comparison operation of the project verification. You can use [...] to create a new check run scheme or edit an existing one. The check run scheme is taken into consideration in the project comparison, as part of the project verification, if the Perform project checks check box is selected.

Compare project structures:

If the check box is selected, all project structures of the comparison and incoming projects will be compared during the project comparison operation of the project verification. All settings that you specified under Project > Properties in the Structure tab are compared.

Compare layers:

If the check box is selected, all layer settings of the comparison and incoming projects will be compared with each other during the project comparison operation of the project verification.

- Report new layers: This functionality is available if the Compare layers check box is selected. If the check box is selected, EPLAN [reports](Glossary_o_auswertungen.htm) the newly created [layers](Glossary_o_ebenen.htm). New layers can, for example, be created by a [DXF](Glossary_o_dxf.htm) / [DWG](Glossary_o_dwg.htm) import.

Stop comparison when first difference is found:

If the check box is selected, EPLAN interrupts all selected comparisons and check runs of the project verification as soon as a difference is found between relevant settings or properties of the comparison and incoming projects. The Project verification: Results dialog opens and EPLAN displays which actions can no longer be carried out.

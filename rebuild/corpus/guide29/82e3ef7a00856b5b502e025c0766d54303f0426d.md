# Project Options

EPLAN allows the creation of a starting project containing all the possible options of a machine, which is practical for (e.g.) series production of machines. These [project options](Glossary_o_projektoptionen.htm) are machine [variants](Glossary_o_varianten.htm), e.g. whether a machine is delivered with or without a suction unit. Dimension can also be performed. A project can be created for a concrete job by simply switching the various project options on and off.

The following editing options are available:

- You can define areas of a plant and selectively display or hide them. Hidden areas are not included in [reports](Glossary_o_auswertungen.htm).
- Project options can be given names and descriptions.
- Sections can contain [placeholder objects](Glossary_o_platzhalterobjekte.htm) in which different sets of values are stored.

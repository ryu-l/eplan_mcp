# Defining Net Extensions for Connection Numbering

In EPLAN, a net is a subset of a signal. Typically a net ends at terminals, [pins](Glossary_o_steckerkontakte.htm), or [connection points](Glossary_o_anschluesse.htm) of [functions](Glossary_o_funktionen.htm). You can use the net extension function to extend the net within the limits of the signal, e.g. with terminals and pins. To do this, specify in the net extension dialog which functions should not be treated as a boundary for the net. This setting affects the designation if the range is selected as "Net". The net extension for [connection numbering](Glossary_o_verbindungsnummerierung.htm) is independent of the Net-connecting property of the function concerned.

Precondition:

You have opened a project.

1. Options > Settings > Projects > "Project name" > Connections > Connection numbering
2. Select a [user-defined](Glossary_o_benutzerdefiniert.htm) scheme from the drop-down list, or [create](Glossary_o_erstellen.htm) a new scheme via ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the dialog Settings: Connection numbering.
3. Select the Designation tab and click [Net extension].
4. In the Net extension dialog, select the functions you require from the Selection list and use the arrow button to move them into the Net extended with following objects list.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The net then no longer ends at the selected functions; it is now extended beyond them.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The net extension applies to all format groups with the scope "Net".
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The setting is saved in the selected scheme.

# Selecting Symbol Variants

A symbol can have up to eight [variants](Glossary_o_varianten.htm) with names from A to H and a [contact image](Glossary_o_kontaktspiegel.htm) variant. Alll variants for a symbol have common [properties](Glossary_o_eigenschaften.htm). They also behave identically, and have the same function. This way they always have the same number of [connection points](Glossary_o_anschluesse.htm) and are only different in their graphical configuration of the connection points.

You can select a different variant of a symbol by rotating the mouse pointer before [placing](Glossary_o_auflegen.htm) it. The default setting for the initial variant is taken from the "Default variant" symbol property that can be set per symbol library in the dialog Settings: Symbol libraries (Options > Settings > Projects > "Project name" > Management > Symbol libraries).

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the following menu [items](Glossary_o_bauteile.htm): Insert > Symbol
2. Select the desired symbol in the Symbol selection dialog.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The dialog is closed and the symbol hangs on the mouse pointer, whereby the current variant used is the first variant (standard variant).
4. Move the cursor to the desired location in the graphical editor.
5. Press the [Ctrl] key and move the mouse around the symbol to switch between all [symbol variants](Glossary_o_symbolvarianten.htm).  
    Or press the [TAB] button to rotate the connection point counter-clockwise through the possible directions.
6. Place the desired symbol variant in the schematic (simple click).
7. Enter the desired data for the device in the Properties <...> dialog.
8. Click [OK].
9. Proceed in a similar manner for all further insertions of the selected symbol.
10. End the action via the Cancel action popup menu item or via the [Esc] button.

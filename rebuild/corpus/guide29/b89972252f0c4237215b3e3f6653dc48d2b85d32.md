# EPLAN Fluid: Complex Devices

### Black Boxes and Device Connection Points

In [fluid power](Glossary_o_fluidtechnik.htm), complex [devices](Glossary_o_betriebsmittel.htm) such as valve [blocks](Glossary_o_bloecke.htm) or power units with internal [connection points](Glossary_o_anschluesse.htm) are often used. In fluid power schematics, such devices are normally displayed graphically within rectangles. EPLAN Fluid supports this display method and provides relevant [functions](Glossary_o_funktionen.htm) for implementing [black boxes](Glossary_o_geraetekaesten.htm) and [device connection points](Glossary_o_geraeteanschluesse.htm).

If you insert a black box or device connection point in the schematic, the program checks which page type this happens on. If it is "fluid power schematic"-type page, the corresponding function definition is automatically configured, and you insert a "black box (fluid)" or "device connection point (fluid)".

### Device groups

Complex fluid power devices with electrical engineering components can be implemented with the help of a device group. Functions from different [trades](Glossary_o_gewerke.htm) and devices tags can be grouped graphically and logically into one device.

The functions combined as a device group are as a rule saved as a macro. The creation of a device group is therefore only possible in a macro project. To group devices, you must first select the functions to be grouped in the schematic; then select the menu [items](Glossary_o_bauteile.htm) Edit > Other > Group device. If the criteria for the creation of a device group have been met, the functions will be grouped.

### Routing connections

User interface / operation

Routing connections are connections of the "3D mounting layout" representation type that are routed in the layout space, or connections of the "Topology" representation type that are routed in the topology. A routing connection has all the properties that a multi-line connection also has, but it also additionally contains information about its routing track.

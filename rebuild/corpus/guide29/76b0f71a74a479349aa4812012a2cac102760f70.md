# Exporting Data for External Editing

Before you can export data for external editing, you must first define [settings](Glossary_o_einstellungen.htm) for external editing of data: Options > Settings > User > Interfaces > External editing. After this, you then define how and where the selected data is to be exported. Note that output depends on the selected object type as determined in the scheme.

1. Select the menu [items](Glossary_o_bauteile.htm) Utilities > Edit properties externally > Export data.
2. In the Edit externally dialog select a scheme from the Settings drop-down list or click [...] to define the settings for a new [user-defined](Glossary_o_benutzerdefiniert.htm) scheme in the Settings: External editing dialog.
3. In the Language drop-down list, select the language to be used for the export.
4. In the Target file field, enter the path and name of the target file to be created, or click [...] to interactively select the path and directory.
5. In the Output type group box, select one of the available output options.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The data is exported and a progress bar shows the process.
7. Depending on the export-specific settings and the output type settings, you may have to finish your external editing before you can continue working in EPLAN.

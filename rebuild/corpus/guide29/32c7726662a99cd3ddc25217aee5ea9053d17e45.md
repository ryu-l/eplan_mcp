# Tab Format of symbolic address

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Options > Settings > Projects > "Project name" > Devices > PLC. Click [...] next to the PLC-specific settings field in the Settings: PLC dialog. Select the Format of symbolic address tab in the Settings: PLC-specific dialog.

In this tab you define the criteria used for automatically creating [symbolic addresses](Glossary_o_symbolischeadressen.htm). You can also replace the preceding signs used by the [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) in the assignment list with different characters. This is necessary if you want to use the DT as automatically entered symbolic address, but special characters in the symbolic address are not allowed for the used PLC controller.

Overview of the main dialog elements:

Generate symbolic addresses automatically using:

If this check box is selected, then you can use the following check boxes to define which identifier [blocks](Glossary_o_bloecke.htm) are used to automatically [create](Glossary_o_erstellen.htm) symbolic addresses.

If this check box is deselected, then symbolic addresses are not automatically created. All other check boxes are then grayed-out.

Functional assignment ... User-defined:

If one of these check boxes is selected, then the respective identifier block is [part](Glossary_o_artikel.htm) of the symbolic address.

For every identifier block, the [preceding sign](Glossary_o_vorzeichen.htm) defined in the [project structure](Glossary_o_projektstruktur.htm) is used; in a second field you can enter a desired character that replaces this preceding sign in the assignment list. It is also possible to replace all preceding signs with the same character, since the preceding sign does not have an identifying role in the assignment list.

Sub-identifiers:

If this check box is selected, then [sub-identifiers](Glossary_o_unterkennzeichen.htm) of the respective identifier block are included in the symbolic address. If the check box is deselected then sub-identifiers are not accounted for.

Device tag:

The device tag is always included in automatically created symbolic addresses. You have the option of specifying a different preceding sign for the assignment list.

Subcounter:

The subcounter of a device tag is also always included in automatically created symbolic addresses. You have the option of specifying a different preceding sign for the assignment list.

Plug designation:

If this check box is activated, the plug designation of the device connection point is a [component](Glossary_o_schaltzeichen.htm) of the symbolic address. You have the option of specifying a different preceding sign for the assignment list.

Connection point designation:

If this check box is selected then the [connection point designations](Glossary_o_anschlussbezeichnungen.htm) of the function are part of the symbolic address.

The preceding sign defined here is displayed before the connection point designation as well as before the terminal designation. The terminal designation is always part of the symbolic address, when the PLC connection point is connected to a terminal.

# P501030: The drilling pattern <x> entered at the part is incomplete. The outline '<y>' does not exist

### Cause

In the parts database to be checked a [part](Glossary_o_artikel.htm) was found where a drilling pattern is stored for which an outline was entered which EPLAN cannot find.

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective part is already marked in it.
2. Bring the Manufacturing tab to the front.
3. In the Drilling pattern column click the table entry and then click [...].
4. In the part selection that is opened bring the Cut-outs tab to the front.
5. In the Outline name column of the table enter an existing outline, or click [...] and select the outline in the subsequent dialog.
6. Click [OK].
7. Close the parts management, save the modified data, and carry out a parts synchronization.
8. Then start a new check run.

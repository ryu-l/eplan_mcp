# Action: MfExportToolbarAction

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| File | The XML file to be exported including file path. |
| ToolbarName | The name of the first user toolbar to be exported. |
| 0 | The name of the next user toolbar to be exported. |
| 1 | The name of the next user toolbar to be exported. |

![](../Pictures/Gui/ALL/note.png)Note:

This action requires a [main window](Glossary_o_hauptfenster.htm).

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
MfExportToolbarAction 
/File:"?" 
/ToolbarName:"?"
```

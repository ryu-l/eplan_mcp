# P026070: Bent busbar with invalid total length

### Cause

The total length could not be calculated correctly. No valid adjustment factor was available in the current bending table at the time the item was placed.

### Solution

1. Locate the bent busbar in the [layout space](Glossary_o_bauraum.htm) using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Complete your bending table.
3. After carrying out this correction select the popup menu item Update [part](Glossary_o_artikel.htm) placement to update the [items](Glossary_o_bauteile.htm) already placed.

# Dialog Addresses / assignment lists

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Project data > PLC > Addresses / assignment lists.

In this dialog, all inputs and outputs for the PLC controllers in the project are managed. To distinguish between several PLC controllers within a project, the addresses must be assigned to a processor (i.e., a CPU). The list then shows which CPU a connection point belongs to. A CPU is identified by the specification of the CPU name. The full CPU name is composed of the contents of the [properties](Glossary_o_eigenschaften.htm) Configuration project and Station ID and a CPU identifier in the [form](Glossary_o_verlauf.htm) of [Configuration project].[Station ID].[CPU identifier].

- You can define new addresses by inserting an empty line and then filling it with data.
- You can define new [symbolic addresses](Glossary_o_symbolischeadressen.htm) by inserting an empty row and then filling it with data. To do this at least one data type must be filled additionally.
- Data can be exchanged with an Excel table using Copy & Paste.
- In addition to this, you can import [assignment lists](Glossary_o_zuordnungslisten.htm) and synchronize them with the schematic, and also [create](Glossary_o_erstellen.htm) new assignment lists.

Overview of the main dialog elements:

Filter:

This drop-down list displays all the available [filters](Glossary_o_filter.htm). A chosen filter is activated automatically. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the [Filter](modaldialogsdb_d_filternnach.htm) dialog. Here you can create, edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

- Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
- Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

By means of the filter you have the possibility to limit the display of the [PLC addresses](Glossary_o_sps_adressen.htm) to one (or several) specific CPU(s).

![](../Pictures/Gui/ALL/info.png)Tip:

Using the Create filter for CPU popup menu item in the table you can automatically [generate](Glossary_o_erzeugen.htm) a filter for the display of the PLC addresses based on the data of the highlighted row. The values of the Configuration project (indirect), PLC station ID (indirect), and CPU (indirect) properties are used as filter criteria here.

---

Table area PLC data from schematic

The table displays all the addresses of the selected filter with information on the following properties in the PLC data from schematic section:

- Configuration project (indirect): Shows the configuration project to which the connection point is assigned. This column can be displayed additionally by using the dialog Configure representation.
- PLC station ID (indirect): Shows the station to which the connection point is assigned. This column can be displayed additionally by using the dialog Configure representation.
- CPU (indirect): The processor that the connection point is allocated to is displayed here (if a CPU has been specified in the PLC box).
- PLC address: The address of the PLC connection point is displayed here.
- Data type: The data type is shown here.
- Symbolic address: Shows the symbolic address that was manually entered at the PLC connection point (if existing).
- Symbolic address (automatic): Shows the content of the manually entered symbolic address or, when that is empty, the automatically determined symbolic address.
- Symbolic address (determined): This shows the symbolic addresses determined through the [target tracking](Glossary_o_zielverfolgung.htm).
- Symbolic address: Group: Shows the assignment of the symbolic address to a group. With this group you can group areas of symbolic addresses in the assignment list, for example inputs, outputs, safety addresses, etc.
- Function text: Shows the function text that was manually entered at the PLC connection point (if existing).
- Function text (automatic): Shows the automatic function text. If there is no manually entered function text, the function text determined by target tracking is displayed here.
- DT (identifying): Shows the identifying device tag for the PLC connection point. This field is automatically filled when a connection point is placed.
- Connection point designation (with plug designation (automatic)): A composite property formed from the plug designation (automatic) and the connection point designation of the PLC connection point. This field is automatically filled when a connection point is placed.
- Direction: Specifies the direction of the address (input, output, undefined).
- Marked for deletion: This column can be additionally displayed via the Configure representation dialog and shows if an address is identified for deletion.
- Name (identifying): Identifying name of the function, is made up of the identifying device tag and, in the case of [connection points](Glossary_o_anschluesse.htm), the additional connection point designation.
- Pre-planning: Outputs the planning object to which this PLC address is assigned. This column can be displayed additionally by using the dialog Configure representation.
- Channel designation: Shows the channel designation of the PLC channel to which the PLC connection point is assigned. This column can be displayed additionally by using the dialog Configure representation. Through the display of the channel designation you can recognize the assignment of the [function texts](Glossary_o_funktionstexte.htm) to the channel.

---

Table area New PLC data / From assignment list

In the New PLC data / From assignment list area you have the option of changing certain PLC data. If you have imported an assignment list, the imported data is shown in the table, and you can accept it or change it. If there are differences between the old and new values, then the corresponding [lines](Glossary_o_leitungen.htm) are highlighted in color. The new values are identified by a yellow background and the old values by a gray background. The following properties can be changed:

- PLC address: The address of the PLC connection point is displayed here. You can change the address manually or by re-addressing.
- Data type: The data type is displayed here; you can select a different entry from the drop-down list or overwrite the entry.
- Symbolic address: The automatic symbolic address is displayed here. You can overwrite the entry; the changes are then transferred into the manual symbolic address.
- Symbolic address: Group: With this property you can group areas of symbolic addresses in the assignment list, for example inputs, outputs, safety addresses, etc. To do this enter a freely selectable designation. The property is used during the PLC [data exchange](Glossary_o_datenaustausch.htm) in AutomationML format.
- Function text: The automatic function text is displayed here. You can overwrite the entry; the changes are then transferred in the manual function text. If the function text is determined from the path function text, or from the function text of a sensor or actuator, then the changes are written back to the path function text or the sensor / actuator.
- Marked for deletion: This column can be additionally displayed via the Configure representation dialog and shows if an address is identified for deletion. You can remove this identification by deselecting the check box.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Add row | Inserts a new line before the selected line. |
| Delete row | Deletes the selected rows. Addresses built into the project cannot be deleted. |
| Addressing | Opens the Reassign PLC addresses dialog. |
| Generate with device | Generates [unplaced functions](Glossary_o_nicht_platziertefunktionen.htm) for the selected addresses, with the aid of the device selection. |
| Use original value | Adopts the old value when the contents of a cell are changed. |
| Keep line breaks in the project | Transfers the old function text with existing line breaks into the field for the new function text if the function texts are identical except for the line breaks and blanks. This allows line breaks which were removed to be recaptured when an assignment list was imported. Any translations existing in the project are also kept. |
| Create filter for CPU | Based on the data of the highlighted row, an automatic filter is generated for the display of the PLC addresses. The values of the Configuration project (indirect), Station ID (indirect), and CPU (indirect) properties are used as filter criteria here. |

[Extras]:

| Menu item | Meaning |
| --- | --- |
| Import assignment list | Imports an assignment list. You specify via the submenu items whether the PLC addresses are to be imported into the CPU currently displayed or into a new CPU:   - Displayed CPU: Opens the dialog Import / synchronize assignment list. - New CPU: Opens the New CPU dialog, and allows you to create a new CPU. Subsequently the dialog Import / synchronize assignment list is opened. |
| Export assignment list | Opens the Export assignment list dialog. |
| Exporting the [address space assignment](Glossary_o_adressraumbelegung.htm) | Opens the dialog Export address space assignment and makes it possible to export the address space assignment of a CPU as a list into a file. |
| Settings | Opens the dialog Settings: PLC. |

![](../Pictures/Gui/ALL/note.png)Note:

You can export or import only one separate list each for each processor (CPU). Therefore set the filter so that the PLC addresses of only one CPU are displayed.

### Configuration projects

Electrical engineering

Configuration projects are subsets of PLC devices within an EPLAN project. The property of the same name is available at PLC boxes and bus ports for the definition of configuration projects. All objects to which the same configuration project is assigned belong together and represent the PLC configuration. The data of the resulting specified set of devices can be exchanged with the PLC configuration programs of various PLC manufacturers.

# P020049: Pre-planning segment <x>: <y>

### Description

You have run a project comparison, checking the Properties of the test project (input project) against those of the comparison project and differences were found.

This message occurs when a difference concerning an pre-planning segment () was found. The designation of the pre-planning segment is shown as <x>, and >y< indicates whether the designation has been deleted or added, or one of the [properties](Glossary_o_eigenschaften.htm) of the pre-planning segment has been changed.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

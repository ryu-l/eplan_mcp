# P007031: The part '<x>' entered at the function is not contained in the pipe class '<y>'

### Cause

In the [P&I diagram](Glossary_o_ri_fliessbild.htm) a [part](Glossary_o_artikel.htm) number is entered at a [process engineering](Glossary_o_verfahrenstechnik.htm) function that does not match the part number that belongs to the selected pipe class.

### Solution

#### Possibility 1

1. Open the segment template navigator and call up the [property dialog](Glossary_o_eigenschaftendialog.htm) of the pipe class that is specified in the placeholder <y> of the message.
2. Bring the Parts tab of the pipe class to the front.
3. In the left-hand table supplement the part number <x> that is output in the message text of the process engineering function.
4. Then start a new check run.

#### Possibility 2

1. Locate the process engineering function in the P&I diagram using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Launch the property dialog of the function.
3. On the first tab select a pipe class that contains the part number <x> which is output in the message text.
4. Then start a new check run.

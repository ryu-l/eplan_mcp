# P005055: Several signal definitions on one signal

### Cause

You have placed multiple signal definitions or [net definition points](Glossary_o_netzdefinitionspunkte.htm) with different signal names on a signal.

### Solution

#### Possibility 1

Reduce the number of signal definitions and/or net definition points with specified signal names, leaving only one valid signal definition.

#### Possibility 2

Enter the same signal name for all signal definitions.

Then start a new check run.

![](../Pictures/Gui/ALL/info.png)Tip:

You can highlight the signal curve in color under View > Signal tracking.

# P004071: Bus interface '<x>': 'Bus interface: Main bus port' property activated more than once or not activated

### Cause

Within a PLC card one or more [bus ports](Glossary_o_sps_busanschluesse.htm) were assigned to a specific bus interface through the entry of a uniform designation at the Bus interface: Name property. This means that either it was forgotten to activate the Bus interface: Main bus port property, or this property was activated several times.

This check run only checks bus ports at which a configuration project is entered.

### Solution

1. Locate the bus port or bus ports in the schematic using the Go to (graphic) and Go to 2nd coordinate functionalities from the popup menu of the Message management dialog.
2. Open the Properties <...> dialog for the corresponding bus port or bus ports.
3. Bring the Bus data tab to the front.
4. If only one bus port exists with a bus interface name, activate the Bus interface: Main bus port property for this bus port. If several bus ports exist with the same bus interface name, activate the Bus interface: Main bus port property for only one of these bus ports.
5. Click [OK].
6. Then start a new check run.

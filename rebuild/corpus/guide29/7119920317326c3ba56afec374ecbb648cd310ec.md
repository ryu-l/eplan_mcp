# Dialog External programs

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > External programs.

Use this dialog to make [settings](Glossary_o_einstellungen.htm) for external programs you want to access from EPLAN.

The following dialog elements are available:

Menu contents:

This list shows the menu texts as they were specified for each of the external programs in the Menu text field.

Menu text:

Enter the text you want to see for the relevant program under Options. A number is automatically inserted in the menu before the text, which is used as a "Hotkey" (this means it is underlined and can be activated with the keyboard).

![](../Pictures/Gui/ALL/example.png) [![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

For example, if you enter "Excel", the entry "1 Excel" is displayed in the menu. By entering "1", you can open Excel.

Command:

Enter the call-up sequence for the relevant program; click [...], to see all the drives and directories and to apply the call-up command.

Arguments:

In this field enter the arguments to be taken over with the relevant program. If you want to start a program with a certain file, for example, enter the name of the file.

Initial directory:

Specify in which directory you want to start the program (this does not have to be the same as the one you specified under Command); click [...], to see all the drives and directories and select the directory.

Toolbar:

In the Toolbar next to the external program settings you can use the following buttons:

| Button | Meaning |
| --- | --- |
| [Insert] | Inserts a new entry in the list under Menu contents and in the row Menu Text |
| [Delete] | Deletes the highlighted entry from the list under Menu contents. Multiple selection is impossible here. |
| [Up] / [Down] | Allows you to shift the highlighted entry in the list under Menu contents up or down and with it change the order of the external programs shown under Options. |

# P501028: 'Plug designation' property at the bus port is empty

### Cause

In the parts database to be checked a [part](Glossary_o_artikel.htm) was found at which a function template is defined with the "Network / bus [cable](Glossary_o_kabel.htm) connection point" function definition. No value is stored for the Plug designation property at this function template.

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective part is already marked in it.
2. Bring the Function templates tab to the front.
3. Enter a value in the Plug designation field at the function template.
4. Close the parts management, save the modified data, and carry out a parts synchronization.
5. Then start a new check run.

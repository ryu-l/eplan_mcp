# Dialog Settings - <Report type>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Reports > Generate. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New). In the Select report dialog, select a [report type](formgeneratorgui_k_auswertungstypen.htm#I_Auswertungsuebersicht) for a report overview, e.g. a device tag list. Click [OK].

In this dialog, you can specify the sorting, filter, and page-break [schemes](Glossary_o_schemata.htm) for [report overviews](formgeneratorgui_k_auswertungsuebersicht.htm). The sorting, filter, and page-break schemes are stored per user and stored with the report when a report page is generated.

Overview of the main dialog elements:

Filter:

In this field, you select a scheme specifying the project or parts data to be output. Click [...] to open the Filter dialog, which you can use to define or edit a scheme.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You are in the process of defining a table of contents. Define the following filter:

| Active | Negated | Criterion | Operator | Value |
| --- | --- | --- | --- | --- |
|  |  | Higher-level function | = | FB3 |
|  |  | Mounting location | = | FT1 |

EPLAN generates a table of contents exclusively for those project pages located in the =FB3+ET3 structure level.

Sorting:

In this field, you select a scheme specifying the sorting order of the project or parts data in the [reports](Glossary_o_auswertungen.htm). Click [...] to open the Sorting dialog, which you can use to define or edit a scheme.

New page if property value has changed:

In this field, you can select a scheme which specifies when a new page is generated. A property is stored in the scheme, e.g., "[higher-level function](Glossary_o_anlage.htm)". Whenever the value of this property changes, a page break is inserted and a new page is generated. Click [...] to open the New page if property is changed dialog, which you can use to define or edit a scheme.

A selected scheme is activated automatically. You can deactivate the selection of a scheme through the entry "-Not activated-".

Form (deviating from settings):

To assign a [form](Glossary_o_verlauf.htm) to the selected report type which deviates temporarily from the specification in the [settings](Glossary_o_einstellungen.htm), you open this dropdown list and click on "Browse". The directory defined as the form directory in the settings is already loaded in the Select form dialog. In the File type field, the form type matching the report type is automatically displayed. Select the desired form and click [Open].

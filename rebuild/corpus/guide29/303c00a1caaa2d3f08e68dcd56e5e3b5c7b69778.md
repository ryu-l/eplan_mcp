# Action: search

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| TYPE | Describes the search range: DEVICETAG: Search by device ALLPROPERTIES: Search through all [properties](Glossary_o_eigenschaften.htm) TEXTS: Search text PAGEDATA: Search page data PROJECTDATA: Search [project data](Glossary_o_projektdaten.htm) |
| PROJECTNAME | Project name with complete file path (optional). If nothing is entered, the selected project will be used if the action is to be run over the user interface (e.g. via script or the toolbar). When executing from the Windows command line, PROJECTNAME must be specified or ProjectAction has to be used before that. Otherwise a system message will appear. |
| SEARCHITEM | Text you are searching for. |
| CASESENSITIVE | Case-sensitive (optional, 0 = No, 1 = Yes). Default value: most recently used value set up in the user interface. |
| WHOLETEXT | Find whole texts only (optional, 0 = No, 1 = Yes). Default value: most recently used value set up in the user interface. |
| LOGICPAGES | Search [logic pages](Glossary_o_logikseiten.htm) (optional, 0 = No, 1 = Yes). Default value: most recently used value set up in the user interface. |
| GRAPHICPAGES | Search [graphical pages](Glossary_o_grafikseiten.htm) (optional, 0 = No, 1 = Yes). Default value: most recently used value set up in the user interface. |
| EVALUATIONPAGES | Search [report pages](Glossary_o_auswertungsseiten.htm) (optional, 0 = No, 1 = Yes). Default value: most recently used value set up in the user interface. |
| NOTPLACEDFUNCTIONS | Search [unplaced functions](Glossary_o_nicht_platziertefunktionen.htm) (optional, 0 = No, 1 = Yes). Default value: most recently used value set up in the user interface. |

![](../Pictures/Gui/ALL/note.png)Note:

The result of the search is displayed in the list of the Search results dialog only if the project for which the search was carried out is currently open in EPLAN.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Search text:

```
search 
/TYPE:TEXTS 
/PROJECTNAME:C:\Projects\EPLAN\ESS_Sample_Project.elk 
/SEARCHITEM:Hallo 
/CASESENSITIVE:1 
/WHOLETEXT:0 
/LOGICPAGES:1
```

Search page properties:

```
search 
/TYPE:PAGEDATA 
/PROJECTNAME:C:\Projects\EPLAN\ESS_Sample_Project.elk 
/SEARCHITEM:Drive 
/CASESENSITIVE:0 
/WHOLETEXT:0 
/LOGICPAGES:1 
/EVALUATIONPAGES:1 
/NOTPLACEDFUNCTIONS:1
```

# Dialog Settings: Property comparison of projects

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have generated a reference project.

- Utilities > Revision control > Property comparison of projects > Compare projects. In the Compare properties of projects dialog, click [...] beside the Settings for property comparison field.
- Options > Settings > Company > Management > Property comparison of projects.
- You have opened project management and selected a project. [Extras] > Verify project. Click [...] next to the Compare properties field in the Verify project dialog.

In this dialog, you define the [properties](Glossary_o_eigenschaften.htm) to be compared for each object type. By default, the "Graphical placement" of [object types](Glossary_o_objekttypen.htm) is usually compared, i.e., the position of the respective [objects](Glossary_o_objekte.htm) on the page. Save these [settings](Glossary_o_einstellungen.htm) in a scheme.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Category:

From this drop-down list, select the object type for which you would like to specify properties for comparison. Depending on your selection ([devices](Glossary_o_betriebsmittel.htm), [connections](Glossary_o_verbindungen.htm), etc.), the different properties will be listed in the fields Do not compare and Compare.

Then, in the field Do not compare, select the desired properties, and move them using the arrow button into the Compare field. You can move unwanted properties back into the field Do not compare. The settings can be made separately for each object type and are saved together in the scheme selected above.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Assume that you wish to find devices whose function text has changed. Then open the tree view for the Device object type in the Do not compare field below the 'Data' level. Highlight the Function text and Function text (automatic) properties and move them to the Compare field using the arrow buttons.

![](../Pictures/Gui/ALL/note.png)Notes:

- The more properties you select for the comparison, the more time the comparison will take.
- During the properties comparison with alternative identification, only placed connections are compared. Properties of [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) are captured indirectly, because they transferred their properties to the connections.  
  During the "normal" properties comparison of [projects](Glossary_o_projekte.htm), only unplaced connections are compared. In addition, placed connections can be compared via the properties of the connection definition points.
- If you carry out a properties comparison for pre-planning [segments](Glossary_o_segmente.htm), a change marker is added both to the segment in the pre-planning navigator and to the placement in the graphical editor in the case of changes in the properties of a segment.  
  If, however, only the graphical placement of the segment is modified (e.g. the segment is moved on the page), then neither the associated segment of the pre-planning navigator nor the placement is marked in the case of a properties comparison with identical setting.

Include deleted and new objects:

If this check box is selected, then deleted and new objects of the object type shown in the Category field are regarded as changes. The objects are still compared when no property for the comparison is selected (i.e. the Compare field is empty). Deleted objects are entered into the revision results list, but not visualized by a revision marker in the schematic.

If the check box is deselected, then deleted and new objects of this object type are ignored. This increases the speed of the property comparison.

![](../Pictures/Gui/ALL/info.png)Tip:

To speed up the property comparison of projects, we recommend only comparing the truly necessary object types. You should completely exclude all other object types from the comparison. To do this, no properties should be selected for comparison for these object types and the Include deleted and new objects check box must also be deselected.

# Dialog Contents of backup file

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have performed a backup (project or [master data](Glossary_o_stammdaten.htm)) and have selected a backup file from the Restore project or Restore <Master data> dialog. [Show contents].

This dialog displays the contents of the backup file for a selected project or master data file.

The following dialog elements are available:

The backup directory and the name of the current backup file are displayed above the list.

List:

All backed up elements are displayed in the list. If no directory is specified, then the data is located in the project / master data directory, otherwise the subdirectory path is also displayed.

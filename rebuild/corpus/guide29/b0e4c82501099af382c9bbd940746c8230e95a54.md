# Tab Fittings

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have installed the hose line configurator as an add-on variant of EPLAN Fluid. You have started EPLAN Fluid and the hose line configurator.

- Select the menu [items](Glossary_o_bauteile.htm) Options > Settings > User > Add-ons > Hose line configurator in EPLAN Fluid and click in the Fittings tab in the subsequent dialog.
- Or select the menu items Extras > Settings in the Configure hose lines dialog of the hose line configurator and click in the Fittings tab in the subsequent dialog.

Or you have installed the hose line configurator as a stand-alone variant and started the program.

- Select the menu items Options > Settings > User > Add-ons > Hose line configurator in the menu of the hose line configurator and click in the Fittings tab in the subsequent dialog.

You manage the data of the fittings for [hose lines](Glossary_o_schlauchleitungen.htm) in this tab. The entered values are offered during the fitting selection when the hose [lines](Glossary_o_leitungen.htm) are configured in the Edit <...> dialog.

Overview of the main dialog elements:

Table:

In this table you define the types of construction, series, [part](Glossary_o_artikel.htm) numbers and image files of the fittings.

If you use the hose line configurator as an add-on variant of EPLAN Fluid, you can use the [...] button available in the table cells of the Part number column to access the parts management and there select the desired part.

You can store a path to an image file for each fitting in the Image file column. The image file is displayed in a preview window during the selection of the fittings.   
The [...] button available in the table cells can be used to specify the respective image file by means of a selection dialog. The possible image file types are \*. gif and \*.jpg.

Use the buttons of the toolbar above the table to [create](Glossary_o_erstellen.htm) new entries and / or delete entries no longer required.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

![](../Pictures/Gui/ALL/note.png)Note:

If you select the default scheme DIN 20066\_2012-01, the table is filled with preset values from the standard DIN 20066. The following types of construction and series are available:

- Types of construction: D, N, N45, N90, R, R45, R90, E, P, P45, P90, S, S45 and S90
- Series: "L" (for "metric light") and "S" (for "metric heavy").

# P026028: Part placement lies completely within a cut-out.

### Cause

A [part](Glossary_o_artikel.htm) placement was placed completely within a cut-out and has no more contact with the mounting surface.

### Solution

1. Locate the part placement in the [layout space](Glossary_o_bauraum.htm) using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Move the part placement in such a way that its outline still has contact with the mounting surface.
3. Then start a new check run.

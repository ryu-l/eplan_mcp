# P011008: Several star sources with the same device tag

### Cause

There are several [interruption points](Glossary_o_abbruchstellen.htm) in the project which are star sources and the have the same device identifiers.

### Solution

#### Possibility 1

Delete the redundant interruption points which are star sources.

#### Possibility 2

For the interruption points that appear more than once, enter different device identifiers.

#### Possibility 3

Double-click the redundant interruption points which are star sources and, in each case, deselect the check box Star source in the Properties <...>  dialog.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

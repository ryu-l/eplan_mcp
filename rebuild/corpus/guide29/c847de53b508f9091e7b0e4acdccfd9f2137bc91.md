# Automatically Assigning Cable Connections

Using the Assign cable connections menu [items](Glossary_o_bauteile.htm) you have two different possibilities to automatically assign the [connections](Glossary_o_verbindungen.htm) of a [cable part](Glossary_o_kabelartikel.htm) to [cable connections](Glossary_o_kabelverbindungen.htm):

- The Reassign all option overwrites all connection [properties](Glossary_o_eigenschaften.htm) with the properties from the [part](Glossary_o_artikel.htm). Only the potential type is compared.
- The Keep existing properties option will retain existing connection properties without changing them. The assignment only occurs when all identifying properties of the [cable](Glossary_o_kabel.htm) connections match those of the part connection.

The sequence of the cable connections for the selected cables is resorted during this. The sequence of the connections is determined according to the rules for determining source and target of the cable or, in the case of terminals, according to the sequence of the terminals on the terminal strip.

Preconditions:

- You have selected a cable definition line in the graphical editor or a cable definition in the Cables - <Project name> navigator dialog.
- The cable is already assigned a part.

### Reassign all cable connections

1. Select the Project data > Cables > Assign cable connections > Reassign all menu items.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connections of the cable part are assigned to the cable connections, if the potential type matches. Existing properties of the cable connections are overwritten by the part properties.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The data at the [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) are correspondingly updated. Existing data are overwritten. New data are only written to the connection definition points if these are not yet entered at the associated cable definition line / shield.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The organization of [shields](Glossary_o_abschirmungen.htm) is retained, but the shield [designations](Glossary_o_bezeichnungen.htm) can change.

![](../Pictures/Gui/ALL/info.png)Tip:

The Assign cable connections menu item can also be found in the popup menu of the navigator dialog Cables - <Project name> and of the Edit cable dialog.

### Assign cable connections with suitable properties

Identifying properties for the assignment:

- Function definition
- Shield designation (shielded by)
- Pair index
- Potential type
- Color / number
- Cross-section / diameter.

Rules for the assignment:

- If a property of the part connection is filled in, the cable connection must have the same value.
- Blank properties of the part connection match any value on the cable connection.
- Shielded [conductors](Glossary_o_adern.htm) also match non-shielded connections; however, if a matching shielded connection has already been found, it will be assigned preferentially.

1. Select the Project data > Cables > Assign cable connections > Keep existing properties menu items.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connections of the cable part are assigned to the cable connections if their identifying properties match.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Existing properties of cable connections are retained, additional properties of the cable part are supplemented.

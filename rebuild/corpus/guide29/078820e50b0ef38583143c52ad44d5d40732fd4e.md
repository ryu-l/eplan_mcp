# Dialog Settings: Part migration

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > User > Devices > Part migration

In this dialog you can set up which auxiliary elements are to be transferred during the [part](Glossary_o_artikel.htm) migration:

- Routing path
- Curve
- Routing range
- Wiring cut-out
- Restricted [placing](Glossary_o_auflegen.htm) area
- Restricted drilling area
- Line.

![](../Pictures/Gui/ALL/note.png)Note:

The following [object types](Glossary_o_objekttypen.htm) are generally not transferred during the migration:

- Mounting surface
- Handle
- Mounting point
- Mounting line
- Mounting [grid](Glossary_o_raster.htm)
- Placement area
- Base point.

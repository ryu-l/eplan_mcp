# Adding Parts

In contrast to the adding of project parts, you use this menu item to assign one (or more) parts to the current device.

Precondition:

You have opened a project.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Parts / Devices > Bill of materials navigator
2. In the Bill of materials - <Project name> dialog, select the device(s) that are to be assigned further [part](Glossary_o_artikel.htm)(s).
3. Select the Add part popup menu item.
4. In the Part selection dialog, select the part or parts to be added. Multiple selection is possible.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new parts are assigned to the [devices](Glossary_o_betriebsmittel.htm).

![](../Pictures/Gui/ALL/note.png)Note:

All [functions](Glossary_o_funktionen.htm) of the Part selection can be used, and the parts-specific presettings will be taken into account.

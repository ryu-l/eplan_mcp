# Dialog Settings: Display

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Options > Settings > Projects > "Project name" > Cross-references / contact image > Display.

For each of the different page types, in this dialog you define which [cross-references](Glossary_o_querverweise.htm) to other page types are to be displayed and in what order.

Overview of the main dialog elements:

Display device cross-references:

Here you select the page types for which cross-references to the main function are to be possible for each different page type by clicking ![](../Pictures/Gui/ALL/all_arrowdropdown_as.png) in the individual columns and selecting an entry from the drop-down list.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The "Panel layout" setting allows cross-references between [main functions](Glossary_o_hauptfunktionen.htm) in the schematic and placed parts on a Mounting panel to be created. The "Device tag list" setting creates cross-references between main [functions](Glossary_o_funktionen.htm) in the schematic and the respective [devices](Glossary_o_betriebsmittel.htm) in the Device tag list.

Only show first cross-reference of each representation type:

Select this check box if the cross-references for the individual [representation types](Glossary_o_darstellungsarten.htm) should not be displayed in the [form](Glossary_o_verlauf.htm) of a list but only the cross-reference of the first entered [part](Glossary_o_artikel.htm). If the check box is deselected, then the lists are displayed.

Display overview cross-references:

In this group box you can specify the following [settings](Glossary_o_einstellungen.htm):

- From overview to schematic: Select this check box if cross-references from overviews to schematic pages are to be possible.
- From schematic to overview: Select this check box if cross-references from schematics to overview pages are to be possible.
- At supply connection points: Select this check box if cross-references at supply [connection points](Glossary_o_anschluesse.htm) are to be possible as well.

You use these settings, for instance, to display [PLC cross-references](Glossary_o_sps_querverweise.htm) between [PLC connection points](Glossary_o_sps_anschluesse.htm) in the schematic and overview.

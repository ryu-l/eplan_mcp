# Dialog Calculate prices

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have opened a parts database in the Parts management dialog using [Extras] > Settings, defined the currency units and conversion factors for both price units under [Extras] > Currencies, and selected the parts for which prices should be calculated. [Extras] > Prices

In this dialog, you can convert prices for selected parts.

The following dialog elements are available:

Currency 1 (<Name>) group box / Currency 2 (<Name>) group box:

Specify for both currencies which purchase price EPLAN should calculate. You can only select one option at a time for a currency, i.e., you can calculate either the "Purchase price/price unit" or the "Purchase price/packaging".

The corresponding prices are recalculated for the selected parts.

![](../Pictures/Gui/ALL/note.png) Note:

The value is rounded to 2 digits after the decimal point.

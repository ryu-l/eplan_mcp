# Dialog Format: Properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the [Settings: Connection numbering](wirenumberinggui_d_verbnumeinstellungen.htm) dialog (for example via the Options > Settings > Projects > "Project name" > Connections > Connection numbering menu [items](Glossary_o_bauteile.htm)). You have selected a [user-defined](Glossary_o_benutzerdefiniert.htm) scheme in the dialog Settings: Connection numbering and have selected the Designation tab. You have selected an entry in the Format groups field and clicked ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit), or you have clicked ![](../Pictures/Gui/ALL/all_new_as.png) (New).

Select a format element of the type "Data" in the Available format elements list of the dialog Connection numbering: Formats dialog and move it to the Selected format elements list by using the arrow button.

In this dialog you specify the formatting for a property in the format group.

Overview of the main dialog elements:

Category:

From the drop-down list select the [properties](Glossary_o_eigenschaften.htm) that should be displayed in the list below, for example "All", "Data" or "Settings". The list displays all properties of the selected type that have not yet been assigned a formatting.

Filter:

Into this field enter the text for which the properties are to be filtered.

If you want to [return](Glossary_o_zurueckbuchen.htm) to the original view of the properties, remove the search term from the entry field. Click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) to do so.

Minimum number of digits:

Here you define the minimum number of characters to be used for the property value. Longer values are displayed in their full length. Only positive numeric values are permitted. A value of zero means that the field width is variable.

Filler character:

The value is padded with this character if the minimum number of digits is larger than the width of the value. A padding character cannot be entered for a variable number of digits (entry of "0" in the Minimum number of digits field).

Suppress empty properties:

Select this check box so that properties that are not set will not be displayed. In addition to this, the Including preceding separator and Including following separator check boxes enable the suppression of the separators before and after the property.

Suppress properties equaling zero:

Select this check box so that numerical properties equal to zero will not be displayed. In addition to this, the Including preceding separator and Including following separator check boxes enable the suppression of the separators before and after the property.

Language:

For multilingual properties you can specify the output language using the drop-down list.

Show data of individual connections:

If this check box is activated, the chosen property for each connection is displayed.

If this check box is deactivated, the value of the property is displayed for the first connection in the extent. This value will then be the same for the entire extent (e.g., the net).

# Inserting Routing Paths (Topology)

Routing paths are automatically or manually inserted sections along which [connections](Glossary_o_verbindungen.htm) can be routed.

Precondition:

You have opened a [topology](Glossary_o_topologie.htm) page in the graphical editor.

1. Select the menu [items](Glossary_o_bauteile.htm) Insert > Topology > Routing path.
2. Move the cursor close to an existing topology function, a routing point, or a topology interruption point.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The existing point is highlighted.
3. Click the highlighted object to place the starting point. Or click free space to place the starting point freely.
4. Specify the next points of the routing path, and click with the left mouse button each of the points to place.
5. Place the end point by clicking another topology function, routing point, or topology interruption point.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Properties <...> dialog opens (if in the Property dialogs category, the While inserting routing points and routing paths (topology) check box has been activated in the user [settings](Glossary_o_einstellungen.htm) for graphical editing).
6. Enter the data for the routing path in the [Routing path](devicetaggui_r_cablingstrecke.htm) tab.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) For an uneven number of sections, the [properties](Glossary_o_eigenschaften.htm) of the routing path are displayed at the middle section, and in the case of an even number of sections at the section in front of the center.
8. End the action via the Cancel action popup menu item or via the [Esc] button.

![](../Pictures/Gui/ALL/info.png)Tips:

- Use the Complete routing path popup menu item or [Spacebar] to freely place the end point of a routing path.
- You can use the Generate routing path popup menu item to [generate](Glossary_o_erzeugen.htm) unplaced [routing paths](Glossary_o_strecken.htm) in the topology navigator.

# Tab Labeling

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Wire fabrication > "Machine" > Labeling
- Utilities > Manufacturing data > Wire fabrication > "Machine". Click [...] next to the Scheme field. Select the Labeling tab.

Up to three different texts for the labeling of [wires](Glossary_o_draehte.htm) are transferred to the Komax, Schleuniger and Rittal - Wire Terminal WT machines; individual positions can be left empty.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Overview of the main dialog elements for Komax and Schleuniger:](javascript:void(0);)

Labeling 1. Page:

Text at the first end of the wire.

Labeling 2. Page:

Text at the second end of the wire.

Labeling endless text:

Text that is printed constantly and repeatedly at a specified distance.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Overview of the main dialog elements for Rittal - Wire Terminal WT:](javascript:void(0);)

Print text source:

Text at the first end of the wire that is connected to the source item.

Print text target:

Text at the second end of the wire that is connected to the target item.

Print text center:

Text that can be output in the center of the wire.

![](../Pictures/Gui/ALL/note.png)Note:

As soon as the Value column is highlighted, the [...] button appears; click here to open the Select format elements dialog where you can configure the text to be displayed.

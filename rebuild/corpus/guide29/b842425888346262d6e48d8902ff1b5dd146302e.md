# Dialog Export settings <...>: <Hierarchy path>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings. Mark one of the [settings](Glossary_o_einstellungen.htm) areas "Projects" or "Company" and click ![](../Pictures/Gui/ALL/all_export_as.png) (Export).

In this dialog you define the target file where the selected settings area is to be exported to.

Overview of the main dialog elements:

Target file:

A file path and name for the export file are suggested in this field. By default, the export file receives a name reflecting the selected area in the tree view of the Settings dialog. The file name consists of the following elements: <Main category>+<Sub-category>+<Settings area>.xml. Using [...] you can enter a file name and directory path for the export file.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).

# P028022: Planning object is not placed in the representation type 'Pre-planning'

### Cause

A planning object created in the pre-planning navigator has not yet been placed in the "Pre-planning" representation type.

### Solution

1. Open the page of the "Pre-planning" type on which the planning object is to be placed.
2. Open the pre-planning navigator (menu [items](Glossary_o_bauteile.htm) Project data > Pre-planning > Navigator).
3. Mark the message in the Message management dialog and select the popup menu item Synchronize selection.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The respective planning object is marked in the pre-planning navigator.
4. Select the Place popup menu item in the pre-planning navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A symbol for a black box is shown at the cursor.
5. Click the left mouse button.
6. Drag open a rectangle that represents that box as a planning object.
7. Click the left mouse button again.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The planning object is placed.
8. Then start a new check run.

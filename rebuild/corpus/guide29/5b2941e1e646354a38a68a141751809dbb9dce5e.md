# P005016: Connection and connecting point have differing potential types

### Cause

You entered the same potential type of the function [connections](Glossary_o_verbindungen.htm) of a connection's targets. You also gave the connection a potential definition point and a potential type which doesn't correspond the that of the targets.

### Solution

Give the potential definition point and the connection targets the same potential type.

Refresh the connections and then start a new check run.

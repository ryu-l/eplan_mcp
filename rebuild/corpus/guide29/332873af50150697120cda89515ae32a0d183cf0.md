# P024004: Connection between different subtrades

### Cause

The target [functions](Glossary_o_funktionen.htm) of a connection have a conflicting entry for the Subtrade property. This can occur when, for example, a connection exists between functions belonging to the [subtrades](Glossary_o_untergewerke.htm) "Water [cooling](Glossary_o_kuehlung.htm)" and "Oil cooling".

### Solution

Assign matching Subtrade property data to the connection targets. The subtrade can be set for each function in the Properties <...> dialog on the first tab.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

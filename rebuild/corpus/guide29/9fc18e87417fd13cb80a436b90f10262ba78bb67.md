# Pre-planning: Links

Through the use of links you can define dependencies between different [segments](Glossary_o_segmente.htm) (for example [PCT loops](Glossary_o_plt_stellen.htm), [PCT loop functions](Glossary_o_plt_stellenfunktionen.htm), etc.) in the pre-planning, have them displayed in the project and in the schematic, and output in [reports](Glossary_o_auswertungen.htm).

### Editing links and linked segments

Actions that you carry out at a link are carried out for the linked segment. For example you open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the linked segment by using the popup menu item Properties. Please also note the following points:

- No other object (segment or link) can be inserted below a link.
- The deleting of a link deletes only the link and not the linked segment. If a segment is deleted, the associated links are also deleted.
- In order to jump from the link to the linked segment (and back) in the pre-planning navigator select the popup menu item Go to (cross-referenced) at the selected link.
- A link itself cannot be copied. In order to copy a segment with its link you have to mark both the segment as well as the structure below which the link is located. By using this method you can, for example, insert a segment including its links into another project.
- Links are taken into consideration when creating and inserting [pre-planning macros](Glossary_o_vorplanungsmakros.htm). In order to save a link in a pre-planning macro the same requirements apply as for copying.

### Displaying the linked segments

The indexed property Linked segments: Name [1-10] ([ID](Glossary_o_id.htm) 44063) is available in the property dialog of the segments in order to have those segments that are linked to a particular segment displayed at the segment. The complete designation of a linked segment is displayed as a value.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Below the PCT loop TICA+ 1000 there are links to the loop LIRA+ 3000 and to the structure segment FW01 U1.

![](../Pictures/Visualisation/ALL/planninggui_linkedsegmentsexample_av.png)

The following values are displayed in the property dialog of the PCT loop.

| Property name | Value | Linked segment |
| Linked segments: Name [2] | GW02 LIRA+ 3000 | Loop LIRA+ 3000 |
| Linked segments: Name [1] | FW01 U1 | Structure segment FW01 U1 |

The loop LIRA+ 3000 is located below the structure segment GW02. Therefore the complete designation is GW02 LIRA+ 3000.

At a corresponding configuration of the property arrangements this information is also displayed at the placed segments in the schematic.

### Consideration in reports

The links and the segments for which the links were created can be output in the pre-planning reports through the placement of corresponding [placeholder texts](Glossary_o_platzhaltertexte.htm) in the pre-planning [forms](Glossary_o_formulare.htm).

The following elements are available for the forms of the pre-planning reports in the Placeholder texts - <Form type> dialog:

- Linked segments:   
  Through this element you can list all the segments that were inserted as a link below a specific segment. You can then see which other segments are linked to this segment through a link.
- Linked with higher-level segments:   
  Through this element you can list all the segments below which a specific link was inserted. This enables you to display in the reports the structures in which a segment was stored as a link.

### Links to the connection planning objects

The dependencies between the segments that are entered as source and target segments at the connection [planning objects](Glossary_o_planungsobjekte.htm) and the connection planning [objects](Glossary_o_objekte.htm) can be made visible by means of links in the tree of the pre-planning navigator. In contrast to the manually inserted links, these "automatic" links can not be deleted. With the popup menu item Go to (cross-referenced) you can jump from the link in the pre-planning navigator to the linked connection planning object.

# Dialog Settings: NC export DXF / Dialog Settings: Copper export DXF

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Machining > NC export DXF
- Options > Settings > Company > Machining > Copper export DXF
- Utilities > Manufacturing data > Machining > NC DXF. Click [...] next to the Machine field.
- Utilities > Manufacturing data > Machining > Copper DXF. Click [...] next to the Machine field.

In this dialog define the [settings](Glossary_o_einstellungen.htm) for the NC export and copper export in the [DXF](Glossary_o_dxf.htm) format.

Overview of the main dialog elements:

Machine:

The delivery scope includes the machine definition named "Default". If you have generated a different machine as a scheme, you can select and edit other machine definitions from the drop-down list.

You can [create](Glossary_o_erstellen.htm) new [schemes](Glossary_o_schemata.htm), save any changes to a scheme, and copy or delete schemes via the adjacent [Toolbar](schemeconfig_m_schemaschaltflaechen.htm). Schemes can also be imported or exported.

Description:

In this field is the description you entered for the machine in the Description field of the New scheme dialog.

Tabs:

To configure the NC export in the DXF format, you can use the following tabs:

- [Tab DXF general](ncgui_r_dxfallgemein.htm)
- [Tab Items](ncgui_r_dxfbauteile.htm)
- [Tab Drill holes](ncgui_r_dxfbohrungen.htm)
- [Tab Thread](ncgui_r_dxfgewinde.htm)
- [Tab Outlines](ncgui_r_dxfkonturen.htm)
- [Tab Drill exceptions](ncgui_r_bohrausnahmen.htm)

You can use the following tabs to configure the DXF export of copper [items](Glossary_o_bauteile.htm):

- [Tab DXF general](ncgui_r_dxfallgemein.htm)
- [Tab Items](ncgui_r_kupferdxfbauteile.htm)
- [Tab Drill holes](ncgui_r_dxfbohrungen.htm)
- [Tab Thread](ncgui_r_dxfgewinde.htm)
- [Tab Outlines](ncgui_r_dxfkonturen.htm)

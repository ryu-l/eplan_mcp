# Dialog Format: Identifier

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the dialog [Settings: Number using PLC data](offlinenumerationplcgui_d_einstellungen.htm) (for example with Options > Settings > Projects > "Project name" > Devices > Number using PLC data). You have selected a [user-defined](Glossary_o_benutzerdefiniert.htm) scheme in the dialog Settings: Number using PLC data. You have selected an entry in the Format groups field and clicked ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit), or you have clicked ![](../Pictures/Gui/ALL/all_new_as.png) (New).

Select a format element of the type "Identifier" in the Available format elements list of the dialog Number using PLC data: Format and move it to the Selected format elements list by using the arrow button.

In this dialog you specify the formatting for an identifier in the format group.

Overview of the main dialog elements:

Minimum number of digits:

Here you define the minimum number of characters to be used for the value of the identifier. Longer values are displayed in their full length. Only positive numeric values are permitted. A value of zero means that the field width is variable.

Filler character:

The identifier is padded with this filler character if the Minimum number of digits is larger than the width of the value.

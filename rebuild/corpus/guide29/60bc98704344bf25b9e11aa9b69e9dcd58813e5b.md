# Adjusting the Layout Space Structure

When copying layout spaces, you can change the page numbers prior to pasting the layout spaces.

Precondition:

You have selected one or more layout spaces in the [layout space](Glossary_o_bauraum.htm) navigator.

1. Select the menu item Edit > Copy.
2. In the layout space navigator, click the position where the copied layout spaces are to be inserted, and select the menu [items](Glossary_o_bauteile.htm) Edit > Insert.
3. In the Adapt structure dialog, change the name of the target layout space to be inserted. The Automatic layout space name check box also allows you to determine the next highest layout space number (in relation to the structure).
4. Click [Reset] if you want to retain the original [structure identifiers](Glossary_o_strukturkennzeichen.htm) when you insert several layout spaces, for example.
5. Select the Overwrite check box if layout spaces of the same name in the target project are to be overwritten.

![](../Pictures/Gui/ALL/note.png)Note:

If you selected the With prompt option under the Options > Settings > Projects > "Project name" > Devices > Numbering (online) menu items, the Insertion mode dialog is displayed. You specify here as to how the DT should be numbered in the copied layout spaces.

If you select in this dialog the Number option, both the device tags of the items and the grouping signs for item [designations](Glossary_o_bezeichnungen.htm) will be renumbered.

8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The layout spaces are inserted into the target project, and the structure identifiers and DT are changed according to the input.

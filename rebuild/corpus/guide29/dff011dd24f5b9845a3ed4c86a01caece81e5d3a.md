# Dialog Select value set

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project page in the graphical editor. Or you have opened a [layout space](Glossary_o_bauraum.htm). You have marked a placeholder object with value sets and have selected the popup menu item Assign value set.

In this dialog you select a value set of a placeholder object. As a result the values of the value set are assigned to the [properties](Glossary_o_eigenschaften.htm) to which a variable has been assigned.

If the Modifiable check box is activated for a variable in the Values tab, you can still adjust the value in the selected value set for this variable.

Overview of the main dialog elements:

Filter:

Enter the text for which the value sets are to be filtered into this field. As a result only those value sets are displayed in the Value set drop-down list, whose value set name or an associated value contains the entered text.

If you want to [return](Glossary_o_zurueckbuchen.htm) to the original selection, remove the text in the entry field. Click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) to do so.

Value set:

Here you select the name of a value set for the placeholder object.

Table:

Table cells with values can only be edited at modifiable variables.

The table contains the following columns:

- Row: Contains a consecutive row number.
- Variable: Here the existing variables are displayed.
- <Value set>: Here the values of the selected value set are displayed. Values of variables that are set in the [property dialog](Glossary_o_eigenschaftendialog.htm) of the placeholder object as modifiable can be changed here.   
  This means that a further [user-defined](Glossary_o_benutzerdefiniert.htm) value set is created and the prefix "User-defined" is placed in front of the name of the originally selected value set. The user-defined value set is removed again when the original value set is selected again.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Show variables for project and page properties:

This check box is only available if a variable is entered in the placeholder object for at least one project or page property.

If this check box is activated, the variables for project and / or page properties are displayed and the values for the selected value set are transferred to the project and / or to the respective pages for these variables.

Enlarge section:

The preview displays the page / layout space on which the placeholder object has been inserted. If this check box is activated, the section with the selected placeholder object and the associated [objects](Glossary_o_objekte.htm) is displayed larger.

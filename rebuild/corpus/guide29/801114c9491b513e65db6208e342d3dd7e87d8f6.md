# Action: XAfActionSettingProject

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| Project | Name of the target project (optional). If no project is specified, the currently selected project is used. |
| set | Name of project setting to be configured. |
| Index | Index of project setting (optional). If no index is specified, 0 is used. |
| value | New value of the project setting. |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
XAfActionSettingProject 
/set:MacrosGui.InsertMacrobox 
/value:1
```

In this example, the project-specific setting for the graphical editing Also insert macro boxes is activated.

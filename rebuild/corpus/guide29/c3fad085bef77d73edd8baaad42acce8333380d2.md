# Action: ExecuteScript

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| ScriptFile | Script file to be executed. |

![](../Pictures/Gui/ALL/note.png)Note:

Only [scripts](Glossary_o_scripte.htm) with the [Start] attribute can be executed.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
W3u.exe ExecuteScript 
/ScriptFile:"C:\...\EPLAN\Electric P8\...\Scripts\...\SimpleScriptWithParameters.cs" 
/Param1:Hello 
/Param2:EPLAN 
/Param3:" API developer!"
```

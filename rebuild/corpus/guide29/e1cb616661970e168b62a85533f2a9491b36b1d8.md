# Dialog Designate connections: Preview of result

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have selected a connection in the graphical editor, or in the Connections - <Project name> navigator dialog. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog. Project data > Connections > Numbering > Enter designation. In the Designate connections dialog you have selected the Preview of result check box. Click [OK].

This dialog lists the [connections](Glossary_o_verbindungen.htm) whose [designations](Glossary_o_bezeichnungen.htm) will be changed. You can accept the [connection designations](Glossary_o_verbindungsbezeichnungen.htm) or change them manually.

Overview of the main dialog elements:

The table lists all connections whose designations are to be changed during [connection numbering](Glossary_o_verbindungsnummerierung.htm). The following is displayed:

- Source (full DT and connection point designation)
- Target (full DT and connection point designation)
- Current connection designation
- New connection designation.

Only the new connection designation can be changed.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Keep old connection designations | Accepts the old connection designation for the connections selected in the New connection designation field. |

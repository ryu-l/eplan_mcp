# Action: ImportPrePlanningData

|  |  |
| --- | --- |
| **Parameter** | **Description** |
| PROJECTNAME | Project name with complete file path (optional). If nothing is entered, the selected project will be used if the action is to be run over the user interface (e.g. via script or the toolbar). When executing from the Windows command line, PROJECTNAME must be specified or ProjectAction has to be used before that. Otherwise a system message will appear. |
| FILENAME | Full path and name of the file to be imported. |
| SCHEMENAME | Name of the scheme that defines the assignment of the external data fields to the EPLAN [properties](Glossary_o_eigenschaften.htm). Has to be specified. |
| TABLENAME | If importing is carried from an MS Excel file, this parameter is used to specify the name of the spreadsheet or of the data area of the data source to be imported. |
| DELIMITER | If the import is carried out from a text file, this parameter is used to define the [separator](Glossary_o_trennzeichen.htm) that is used in the text file to separate the columns. |
| HEADER | Output column [designations](Glossary_o_bezeichnungen.htm) (optional). Only relevant for importing from MS Excel. 1: Column designations of the data spreadsheet are output in the "External field" column of the assignment table. 0: Column designations are not output. Default value: 0. |
| TARGETNAME | Name of the object ("Designation (full)"property [ID](Glossary_o_id.htm) 44009) below which the imported data are to be inserted. If the parameter is empty, the data are inserted below the project name. |
| SKIPERRORS | If the value is 1, importing is not aborted when faults and messages occur (optional). Default value: 1. |
| OVERWRITE | If the value is 1, pre-planning data of the same name are overwritten during importing (optional). Default value: 1. |
| UPDATEONLY | If the value is 1, only the data of existing [structure segments](Glossary_o_struktursegmente.htm) and planning data are updated (optional). Default value: 0. |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Importing pre-planning data from MS Excel:

```
ImportPrePlanningData 
/PROJECTNAME:C:\Projects\ESS_Sample_Project.elk 
/FILENAME:C:\Projects\EPLAN\preplanning.xls
/SCHEMENAME:config_scheme
/Header:1
/UPDATEONLY:1
```

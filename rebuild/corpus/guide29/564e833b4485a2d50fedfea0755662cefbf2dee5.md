# P004080: Missing configuration project

### Cause

The specification of the configuration project is missing at a PLC box or a bus port. This information is required for a correct PLC data export from EPLAN.

### Solution

1. Locate the PLC box or the bus port in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) for the PLC box or the bus port.
3. In the case of the PLC box bring the PLC structure data tab to the foreground. In the case of the bus port bring the Bus data tab to the foreground.
4. Assign a corresponding name in the Configuration project field or select an entry from the drop-down list.
5. Click [OK].
6. Then start a new check run.

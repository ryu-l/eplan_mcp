# P004021: Address has been assigned more than once within a CPU

### Cause

An address was assigned multiple times within a PLC.

### Solution

1. Change the addresses of the affected [PLC connection points](Glossary_o_sps_anschluesse.htm) by means of the Properties <...> dialog so that each address within a CPU is uniquely addressed. (Assign the CPUs to a PLC box by setting the CPU and CPU: Name [properties](Glossary_o_eigenschaften.htm)).
2. Then start a new check run.

# P026104: The <x> part has not been migrated yet.

![](../Pictures/Gui/ALL/note.png)Note:

This check run message occurs during migration of the Rittal baying system TS 8 to the Rittal baying system VX 25.

### Cause

The Rittal TS8 [part](Glossary_o_artikel.htm) has not been migrated to a corresponding Rittal VX25 part yet.

### Solution

Perform a manual migration for this Rittal VX25 part.

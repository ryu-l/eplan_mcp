# Tab Display (Extended project structures)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Page > Navigator. Select a project. Select the Properties popup menu item. Select the Structure tab. Click [Other]. In the Extended project structures dialog, select the Display tab.
- You have selected a project management database. You have loaded directories and [projects](Glossary_o_projekte.htm). Project > Management. Select a project. Select the Structure tab. Click [Other]. In the Extended project structures dialog, select the Display tab.

In this tab you define the preceding signs for the [structure identifiers](Glossary_o_strukturkennzeichen.htm) and the separators for [sub-identifiers](Glossary_o_unterkennzeichen.htm) of the [project structure](Glossary_o_projektstruktur.htm).

Higher-level function number:

In this field you enter the [preceding sign](Glossary_o_vorzeichen.htm) for the "[higher-level function number](Glossary_o_anlagennummer.htm)". When characters are entered that are not permitted (blank, -, etc.) a corresponding Tooltip is displayed.

Document type:

In this field you enter the preceding sign for the "[document type](Glossary_o_dokumentenart.htm)". Default is the preceding sign "&". In place of "&", a space can also be selected in EPLAN.

User-defined:

In these fields you enter the preceding sign and [separator](Glossary_o_trennzeichen.htm) for a freely [user-defined](Glossary_o_benutzerdefiniert.htm) structure identifier. When characters are entered that are not permitted (blank, -, etc.) a corresponding Tooltip is displayed.

Automatic separation when number is followed by letter:

If this check box is selected then the substructures are separated by a change from numeral to letter. I.e., EPLAN interprets a change from numeral to letter within a structure identifier as a sub-structure.

If the check box is deactivated, sub-structures are displayed by means of the separators determined for sub-identifiers.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

If the check box is activated, an identifier =A1.A2.A3 is displayed and evaluated as =A1A2A3.

Group box Product aspect

![](../Pictures/Gui/ALL/note.png)Note:

The [settings](Glossary_o_einstellungen.htm) for the [product aspect](Glossary_o_produktkennzeichen.htm) are only available if the Extended reference identification check box has been activated in the Structure tab of the [project properties](Glossary_o_projekteigenschaften.htm).

In this group box you determine whether the product aspect is used as a structuring element and how the sub-structures of the product aspect are displayed. For optimum product support we recommend to assign an identifying product aspect ("-") to all [devices](Glossary_o_betriebsmittel.htm). Additional describing structuring criteria (aspects) can enhance structuring, if required. By structuring projects with product aspect identifiers, the designed machines can be completely structured by their mechanical structure.

Use for structuring:

If this check box is activated, the product aspect - i.e., the identifier block for the device (preceding sign "-") - is used as additional structuring element. The setting has the following effect:

- The preceding sign "-" is always displayed in the full DT, even if no other [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) are used.
- The table for the DT is hidden in the Full DT dialog and the product aspect displayed in the Structure identifiers table.
- The product aspect is displayed in [structure identifier management](Glossary_o_strukturkennzeichen_verwaltung.htm).
- Product aspects are nested at [interruption points](Glossary_o_abbruchstellen.htm), too.
- You can use the product aspect for [structure segments](Glossary_o_struktursegmente.htm) in pre-planning. Concerning [planning objects](Glossary_o_planungsobjekte.htm), you can use the product aspect even if the check box is deactivated.

If this check box is deactivated, then the product aspect is not used as a structuring element.

Preceding signs and separators:

These fields contain the preceding signs and separators for the "product aspect". The fields are available if the Use for structuring check box is active. The following table shows the possible characters.

| Preceding sign | Separator for sub-identifiers |
| --- | --- |
| - | - |
|  | . |

![](../Pictures/Gui/ALL/note.png)Note:

If the full-stop is selected as separator for the product aspect, some functionalities of the EPLAN platform are no longer usable completely since they are contrary to the usage of the full-stop as separator. Among others this includes functionalities which use subcounters and full-stop-separated fluid [designations](Glossary_o_bezeichnungen.htm).

Automatic separation when number is followed by letter:

If this check box is selected then the substructures of the product aspect are separated by a change from numeral to letter. I.e., EPLAN interprets a change from numeral to letter within a structure identifier as a sub-structure.

If the check box is deactivated, sub-structures are displayed by means of the separators determined for sub-identifiers.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

If the check box is activated, the DT -K01Q04S01 is internally broken down into the sub-structures -K01, Q04, and S01. With deactivated check box, this DT is displayed and evaluated as -K01.Q04.S01.

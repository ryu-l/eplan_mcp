# P002005: Only male pin end available

![](../Pictures/Gui/ALL/note.png)Note:

The counterpiece of a male pin is either the female pin with the same DT and the same pin designation or a female pin that is connected with the male pin via direct [connection points](Glossary_o_anschluesse.htm).

### Cause

A plug definition was placed in the schematic for which "Plug definition for [male pins](Glossary_o_steckerstifte.htm)" was entered for the function definition. This setting makes the program search for a corresponding item, namely the female pin side. However, this counterpiece is missing in the schematic.

### Solution

Add another plug definition to the schematic and enter "Plug definition for [female pins](Glossary_o_steckerbuchsen.htm)" for the function definition. For the plug definition, enter the same DT as you did for the male plug definition.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

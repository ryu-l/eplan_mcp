# Creating an Identifier when Inserting New Pages, Device Tags, and Macros

If the creation of new pages or [devices](Glossary_o_betriebsmittel.htm) or the insertion of pages and [macros](Glossary_o_makros.htm) adds new [structure identifiers](Glossary_o_strukturkennzeichen.htm) to the project, the new structure identifiers are inserted in the table of identifiers according to the user [settings](Glossary_o_einstellungen.htm) for identifiers (option Enter new identifiers in alphabetical order or Add new identifiers to the end). In [structure identifier management](Glossary_o_strukturkennzeichen_verwaltung.htm), you can subsequently access the identifier data of the selected [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm), and, for example, modify their sorting.

![](../Pictures/Gui/ALL/note.png)Note:

The project setting Conversion to upper-case (under Options > Settings > Projects > "Project name" > Devices > General) is used when creating new identifiers.

### Create identifiers during page processing

When creating a new page or when renaming / moving an existing page, you can specify a new structure identifier which does not yet exist in the database. How the new structure identifier is sorted in the list by default (alphabetically or at the end of the list) depends on the identifier settings which have been made. Existing structure identifiers cannot be changed here.

Precondition:

You have opened a project in which identifier [blocks](Glossary_o_bloecke.htm) are used in the [project structure](Glossary_o_projektstruktur.htm), for instance "Higher-level function" and "Mounting location".

1. Select the menu [items](Glossary_o_bauteile.htm) Page > New.
2. If you would like to obtain an overview of the existing structure identifiers, click [...] next to the Full page name box of the New page dialog.
3. In the Full page name dialog, click [...] next to the corresponding box for the identifier block.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The <Identifier block> dialog lists all existing structure identifiers. In the List tab, the field contents Complete structure identifier and Structure description are displayed.
4. Click [Cancel] to close the list.
5. In the Full page name dialog, enter a new structure identifier into one of the fields for the identifier block.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the New page dialog, the full page name is correspondingly updated.

### Create identifiers during device processing

When creating a new device, [cable](Glossary_o_kabel.htm), etc. or when renaming / moving an existing one, you can provide a new structure identifier which does not yet exist in the database. How the new structure identifier is sorted in the list by default (alphabetically or at the end of the list) depends on the identifier settings which have been made. Existing structure identifiers cannot be changed here.

Preconditions:

- You have opened a project in which identifier blocks are used in the project structure, for instance "Higher-level function" and "Mounting location".
- You have opened a schematic page.

1. Select the menu item Insert > Symbol.
2. Select the desired symbol from the Symbol selection dialog and click [OK].
3. Position the symbol using the mouse.
4. In the Full DT field of the [component](Glossary_o_schaltzeichen.htm)-specific Properties <...> dialog, click [...].
5. If you would like to obtain an overview of the existing structure identifiers, click [...] next to the appropriate field for the identifier block.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The <Identifier block> dialog lists all existing structure identifiers.
6. Click [Cancel].
7. In the Full DT dialog, enter a new structure identifier into one of the fields for the identifier block.

### Create identifiers during macro processing

When adding macros with devices with identifier blocks you can also enter a new structure identifier which does not yet exist in the database. How the new structure identifier is sorted in the list by default (alphabetically or at the end of the list) depends on the identifier settings which have been made. Existing structure identifiers cannot be changed here.

Precondition:

You have opened a project in which identifier blocks are used in the project structure, for instance "Higher-level function" and "Mounting location".

1. Select the menu item Page > Page macro > Insert.
2. In the subsequent dialog, select the macro to be inserted and click [Open].
3. In the Adapt structure dialog, specify the handling of page names for the target macro.
4. If you would like to obtain an overview of the existing identifiers, click [...] next to the respective block for the target identifier block.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The <Identifier block> dialog lists all existing identifiers.
5. Click [Cancel].
6. In the Adapt structure dialog, enter a new structure identifier into one of the boxes for the target identifier block (e.g. for "Higher-level function" or "Mounting location").

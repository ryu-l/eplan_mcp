# Action: exportProductionWiring

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| MachineType | Integer value, has to be specified. The following values are possible:   - 1 = Komax - 2 = CadCabel - 3 = Schleuniger - 4 = Steinhauer PWA - 5 = Metzner - 7 = General [wires](Glossary_o_draehte.htm) parts list |
| MachineName | String, has to be specified. Name of the machine as specified in the [settings](Glossary_o_einstellungen.htm). |
| PROJECTNAME | Project name with complete file path (optional). If nothing is entered, the selected project will be used if the action is to be run over the user interface (e.g. via script or the toolbar). When executing from the Windows command line, PROJECTNAME must be specified or ProjectAction has to be used before that. Otherwise a system message will appear. |
| USESELECTION | Specifies whether the current selection in the user interface is to be taken into account in connection with the output of the wire data (optional, 0 = No, 1 = Yes). Default value: 0. Can only be used if the parameter PROJECTNAME is not used. |
| TargetDirectory | Target directory (optional). If the parameter is set, a file path specified in the settings is overwritten. |
| FileName | File name (optional). If the parameter is set, a file name specified in the settings is overwritten. |
| LANGUAGE | Language (for example en\_US), optional. |
| MultipleConnections | If the value = 1, wires that have already been exported are exported again. If the value = 0, only wires that have not yet been exported are exported. Default setting: 0. |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
ExportProductionWiring 
/MACHINETYPE:5 
/MACHINENAME:Metzner
/TARGETDIRECTORY:D:export
/MultipleConnections:1
/UseSelection:0
```

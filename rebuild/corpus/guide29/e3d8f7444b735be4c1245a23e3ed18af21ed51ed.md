# Functions

In EPLAN, the logical and graphical data are managed separately. Logical data is stored in the [function definitions](Glossary_o_funktionsdefinitionen.htm), graphical data in the [symbols](Glossary_o_symbole.htm). This separation is significant when working with an engineering approach and offers a number of additional advantages for a modern CAE product (such as standards independence).

EPLAN supports both a graphics-oriented drawing interface (copy pages, add [macros](Glossary_o_makros.htm), place symbols, etc.) as well as a logic-oriented interface based on an engineering approach (working with [devices](Glossary_o_betriebsmittel.htm), predefined listed, [navigators](Glossary_o_navigatoren.htm), "[use existing](Glossary_o_abbuchen.htm)", etc.).

If you work with the graphics-based interface you don't need to worry about [functions](Glossary_o_funktionen.htm) or function definitions. Function definitions are already assigned to the symbols in the standard [symbol libraries](Glossary_o_symbolbibliotheken.htm). You simply place a symbol or a macro and the default assigned function definitions are automatically added.

If you work with the engineering interface or want to adapt [reports](Glossary_o_auswertungen.htm), numbering, etc., however, it is necessary to understand the concept of functions.

# Dialog Select revision

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Revision control > Change tracking > Generate revision. In the Generate revision dialog, click [...] next to the Revision name field.

In this dialog, you can select an existing revision name.

The following dialog elements are available:

The revision names already present in the project are presented here in the table for selection.

Select a revision name and exit the dialog by clicking [OK]. The revision name and the associated [comments](Glossary_o_kommentare.htm) are then entered into the Generate revision dialog where you can then edit them.

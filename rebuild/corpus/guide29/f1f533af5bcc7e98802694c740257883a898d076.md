# Dialog Relative coordinate input

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a page in the graphical editor. Options > Relative coordinate input.

In this dialog, enter the target coordinates where the cursor is to be positioned. Entry is relative to the current position of the cursor. You have two options here: Either enter the target coordinates relative to the current cursor position in the Distance field. Or you can enter the target coordinates using an angle and the length of the [offset](Glossary_o_offset.htm) from the current cursor position.

![](../Pictures/Gui/ALL/note.png)Note:

Please note that the results of jumping to the target coordinates are not exact, but are oriented to the [grid](Glossary_o_raster.htm), when you make length entries and the grid is enabled.

The following dialog elements are available:

Distance (<coordinate system>):

When the dialog is called up, the set coordinate system and the current position of the cursor are displayed here. Enter the values into the fields for X and Y by which the end point should be moved, from the coordinates of the starting point, in the X and Y directions. Positive or negative values may be entered. The values in the fields Angle and Length are automatically changed.

Angle:

Specify the direction in which the cursor should be moved by entering the angle from the current cursor position.

Length:

Enter the length here by which the cursor should be moved in the direction of the given angle. The values for X and Y in the Distance field will automatically be changed.

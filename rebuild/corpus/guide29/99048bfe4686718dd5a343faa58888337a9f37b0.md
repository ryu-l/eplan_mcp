# Activating Object Snap

Object snap makes it easier to construct graphical [objects](Glossary_o_objekte.htm).

Precondition:

You have opened a page, [form](Glossary_o_verlauf.htm), plot frame or symbol.

1. Select the Options > Object snap menu [items](Glossary_o_bauteile.htm) to activate this option.  
     
   ![](../Pictures/Gui/ALL/arrow.png) When drawing graphical objects, these are automatically connected to the possible handles. These include, for example, the insertion points of logical objects and texts, as well as the element points, perpendicular and tangent points of graphical elements.
2. Select the Options > Object snap menu items to deactivate this option.

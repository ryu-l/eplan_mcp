# Activating AutoCorrect for Project Texts

The "AutoCorrect" function allows you to replace project texts with replacement texts before the translation. This setting depends on the user. You specify in the dictionary which [keywords](Glossary_o_stichworte.htm) should be automatically replaced by which replacement texts.

Precondition:

You have selected a dictionary with keywords for AutoCorrect.

1. Options > Settings > User > Translation > Dictionary
2. Activate the AutoCorrect check box and click [OK].
3. To check the automatic replacement, open a schematic page and select the menu [items](Glossary_o_bauteile.htm) Insert > Graphic > Text.
4. Enter a text from the keyword list for AutoCorrect and select Popup menu > Translate.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The keyword is automatically replaced and if a translation text exists, it was will also be replaced.

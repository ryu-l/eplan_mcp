# Tab Outlines (NC Export DXF / Copper Export DXF)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Machining > NC export DXF. Select the Outlines tab.
- Utilities > Manufacturing data > Machining > NC DXF. Click [...] next to the Machine field. Select the Outlines tab.

In this tab, you specify the [settings](Glossary_o_einstellungen.htm) on visibility as well as [layers](Glossary_o_ebenen.htm) and colors of [outlines](Glossary_o_konturen.htm).

Overview of the main dialog elements:

Group box Formats for outlines

Export outlines:

If the check box is activated, milling outlines will be generated on a separate layer in the [DXF](Glossary_o_dxf.htm) file.

Layer:

Default name of the layer where the outline is stored in the DXF file.

Color:

Default color that is assigned to the outline in the DXF file.

# Replacing Plot Frames, Forms, and Function Definition Libraries (Changing Standards)

To adjust a project to a different standard you can replace existing [plot frames](Glossary_o_normblaetter.htm) and [forms](Glossary_o_formulare.htm) with different ones.

Preconditions:

- You have opened a project.
- If multiple [projects](Glossary_o_projekte.htm) are open: You have selected a project in the page navigator.
- You have set up a target project.
- You have defined a template and the rotation / flipping.

1. Utilities > Change of standard > Project tab > [Next] > Rotation / flipping tab > [Next]
2. In the Master data tab in the Name column, select a [form](Glossary_o_verlauf.htm), a plot frame, or a function definition library to be replaced.
3. Within the same row, click [...] in the New name column.
4. In the following dialog select the form, the plot frame, or the function definition library to be used for the target project and click [Open].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The selected file is entered in the New name column.  
      
    ![](../Pictures/Gui/ALL/arrow.png) Next, you can [replace symbol libraries and symbols](changestandardsgui_h_symboletauschen.htm).

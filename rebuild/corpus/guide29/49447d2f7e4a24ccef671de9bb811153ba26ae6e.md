# Displaying Bus Ports in Multi-line

For the PLC [data exchange](Glossary_o_datenaustausch.htm) in the AutomationML format the network structure to be replaced is determined from the single-line or multi-line [bus ports](Glossary_o_sps_busanschluesse.htm) connected to each other. For all other [formats](Glossary_o_formate.htm) only the single-line representation is considered.

Multi-line representation of the bus is not required. Detailed [multi-line representations](Glossary_o_allpoligedarstellungen.htm) of standard bus cables can be implemented by means of a [cable](Glossary_o_kabel.htm) assignment diagram.

In the parts management the network / bus cable-[connection points](Glossary_o_anschluesse.htm) (in brief: bus ports) and the [PLC connection points](Glossary_o_sps_anschluesse.htm) of a PLC card are represented as [function templates](Glossary_o_funktionsschablonen.htm). A bus port represents a plug and is represented by only one function template. If you want to place the bus ports in single-line and the remaining PLC connection points in multi-line, this can be achieved by using [part macros](Glossary_o_artikelmakros.htm) that contain a single-line and a multi-line variant.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The single-line variant of a [part](Glossary_o_artikel.htm) macro is shown on the left and the multi-line variant on the right.

![](../Pictures/Visualisation/ALL/plcgui_busmacro_av.png)

Either a plug designation (and in addition, if necessary, the bus interface name) or a connection point designation must be entered at the single-line bus port so that the function templates in the PLC navigator are overlapped correctly.

If required, you can place the single-line bus port additionally with the "Multi-line" representation type.

### Multi-line representation all the contacts of a bus port

If a bus cable is to be represented with all the individual contacts in multi-line, you can increase the number of connection points at the bus port and place a symbol suitable for the set number of connection points.

Preconditions:

- You have opened a project page in the graphical editor.
- You have opened the PLC navigator.

1. Select the following menu [items](Glossary_o_bauteile.htm): Insert > Box / connection point / mounting panel > Bus port
2. Place the bus port on the project page.
3. Check that the bus port has the representation type "single-line" in the Symbol / function data of the [property dialog](Glossary_o_eigenschaftendialog.htm).
4. Enter the number of connection points, meaning the number of contacts of the network / bus cable-connection point, in the Connection points field.
5. Click [OK].
6. Mark the bus port in the PLC navigator and select the popup menu Place.
7. Press the [Backspace] and select a symbol for the bus port with the corresponding number of connection points.
8. Confirm your entries.
9. Place the symbol on the project side. If applicable change the representation type to "Multi-line".  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the PLC navigator a multi-line and a single-line bus port is displayed, whose data are synchronized with each other and that consequently overlap the function template together.

![](../Pictures/Gui/ALL/note.png)Note:

The multi-line bus port may only be placed once with all its contacts in a symbol. This is the only means of ensuring complete editing and correct overlapping of the function templates.

# Placing Connection Definition Points

Precondition:

You have selected a connection in the graphical editor, or in the Connections - <Project name> navigator dialog. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Connections > Numbering > Place  
     
   ![](../Pictures/Gui/ALL/arrow.png) Once you have called up the menu item, the [connections](Glossary_o_verbindungen.htm) are first automatically newly generated.
2. In the Settings field of the Place connection definition points dialog select a scheme from the drop-down list that will specify the [settings](Glossary_o_einstellungen.htm) for [connection numbering](Glossary_o_verbindungsnummerierung.htm). Use [...] to open the Settings: Connection numbering dialog. Define the numbering settings here and store them in a scheme.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) are placed on the schematic pages. They receive "????" as a designation if the associated connection still has no designation.

![](../Pictures/Gui/ALL/note.png)Note:

For the connection definition points placed by means of the connection numbering, all [properties](Glossary_o_eigenschaften.htm) are cleared and reset to undefined values, so that these connection definition points are neutral.

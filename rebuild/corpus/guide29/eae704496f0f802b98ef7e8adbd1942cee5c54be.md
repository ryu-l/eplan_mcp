# P005025: Too many connections at a connection point

### Cause

At least one of the function [connections](Glossary_o_verbindungen.htm) of a [component](Glossary_o_schaltzeichen.htm) is liked to more components than was defined.

### Solution

#### Possibility 1

Double-click the component in the schematic and then, in the Properties <...> dialog, bring the Symbol / function data tab to the front. In the Function data (logic) group box, click [Logic...]. In the Connection point logicdialog, check which values are set in the Number of targets row for both function [connection points](Glossary_o_anschluesse.htm). Increase your requirements on the defined value for one or both function connection points.

#### Possibility 2

Double-click the component in the schematic and then, in the Properties <...> dialog, bring the Symbol / function data tab to the front. In the Function data (logic) group box, click [Logic...]. In the Connection point logic dialog, check which values are set in the Number of targets row for both function connection points of the terminal. Delete the excess components placed in each of the component's function connections.

Refresh the connections and then start a new check run.

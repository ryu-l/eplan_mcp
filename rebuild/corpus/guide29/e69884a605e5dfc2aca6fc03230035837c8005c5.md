# Editing Outline Definition Point Properties

The logic of [outlines](Glossary_o_konturen.htm) is defined by means of "[outline definition points](Glossary_o_konturdefinitionspunkte.htm)" and is available only for outlines of the type "Outline extrusion". Special menu [items](Glossary_o_bauteile.htm) are available for this in the Outline editor under the Insert > Logic > "Logic element" menu items, and they each start an interaction for [placing](Glossary_o_auflegen.htm) and numbering an outline definition point.

When outline definition points are inserted, they are numbered according to their type, and given a unique counter. Outline definition points for the logical elements Guide rail, Guide rail with alignment Mounting surface, Mounting surface NC and Field size may only occur in pairs and have an additional subcounter, to ensure their uniqueness, in combination with the counter. The subcounter can only have the value "1" or "2" (e.g. counter = 1, subcounters = 1.1 and 1.2).

Preconditions:

- You have opened a project.
- You have opened the outline that you want to edit in outline editor (Utilities > Master data > Outline (extrusion) > Open > [Open]) and have inserted at least one outline definition point.

1. Double-click the logic element.
2. In the Outline definition point: <...> dialog, select the Data tab, if you want to edit the counters and / or subcounters of the logic element.
3. Select the Display tab, to edit the logic element display [settings](Glossary_o_einstellungen.htm) (such as Font size, Font, etc.).
4. Click [OK].

# Data Transfer of EPLAN PPE Projects: Properties

During the data transfer of [projects](Glossary_o_projekte.htm) with PPE database the [properties](Glossary_o_eigenschaften.htm) from EPLAN PPE are converted into [user-defined](Glossary_o_benutzerdefiniert.htm) properties for the pre-planning. These properties are displayed below the nodes EPLAN and PPE in the tree of the configuration dialog Configure properties.

A property can be assigned to different property groups in EPLAN PPE. Since a property has to be unique in the EPLAN Platform, the property groups are mapped as additional nodes in internal identifying property names (GROUP1 â GROUP8) during the data transfer and used as [part](Glossary_o_artikel.htm) of the displayed name. The displayed name can be changed later.

After the data transfer the following two user-defined properties result for the PPE property State of aggregation that was used in the "Measured medium data" and "Regulating substance data" property groups:

- Identifying name: Eplan.PPE.GROUP2.STATE OF AGGREGATION  
  Displayed name: Measured medium data: State of aggregation.
- Identifying name: Eplan.PPE.GROUP5.STATE OF AGGREGATION  
  Displayed name: Regulating substance data: State of aggregation.

These properties that were previously used in a property group are assigned by default to the categories "Pre-planning 1" to "Pre-planning 8" for the display in the program. The use of these categories allows the properties to be displayed better structured for example in the [property dialog](Glossary_o_eigenschaftendialog.htm) of the [segments](Glossary_o_segmente.htm). However, grouping of the properties into the categories is not mandatory.

All other transferred PPE properties have the category "Data" assigned by default.

| Property group (PPE) | Node | Category |
| General [loops](Glossary_o_messstellen.htm) / General [consumers](Glossary_o_verbraucherstellen.htm) | GROUP1 | Pre-planning 1 |
| Measured medium data / Type of consumer | GROUP2 | Pre-planning 2 |
| Measuring-point data / Electr. consumer data | GROUP3 | Pre-planning 3 |
| Instrumentation data / Mechanical consumer data | GROUP4 | Pre-planning 4 |
| Regulating substance data / Control | GROUP5 | Pre-planning 5 |
| Control point data / Starting behavior, motor | GROUP6 | Pre-planning 6 |
| Actuator data / Design | GROUP7 | Pre-planning 7 |
| Other loops / Other consumers | GROUP8 | Pre-planning 8 |

# Dialog Properties (special text): Page properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Master data > Plot frame / Form > Open > [Open].

- Insert > Special text > Page properties.
- You have double-clicked a page property (or selected the  Properties popup menu. In this case, several page [properties](Glossary_o_eigenschaften.htm) can be selected).

In this dialog, you can select the page property which should be inserted into the plot frame / [form](Glossary_o_verlauf.htm), and specify its properties for format, language, and border. These [special texts](Glossary_o_sondertexte.htm) are then filled in corresponding to the data entered from the program.

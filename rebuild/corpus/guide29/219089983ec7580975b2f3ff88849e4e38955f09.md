# Dialog Start pages

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have selected several [PLC connection points](Glossary_o_sps_anschluesse.htm) in the graphical editor, the PLC navigator, or in the device navigator. Or you have selected one or more pages or a project in the page navigator. Project data > PLC > Generate schematic. In the Generate PLC schematic dialog, you have selected the rows with the [devices](Glossary_o_betriebsmittel.htm) for which you wish to [generate](Glossary_o_erzeugen.htm) schematic pages. Select the Calculate pages popup menu item.

In this dialog, you enter the page name of the first page for every required representation type.

Overview of the main dialog elements:

You can use [...] to open the [Full page name](pagebrowsergui_d_seitenname.htm) dialog where you can edit the structure identifier and the page name. You can use [...] to select the [structure identifiers](Glossary_o_strukturkennzeichen.htm) (such as [higher-level function](Glossary_o_anlage.htm) and [mounting location](Glossary_o_einbauort.htm)) from the existing values. You can also manually enter the identifiers and [create](Glossary_o_erstellen.htm) new ones in the process.

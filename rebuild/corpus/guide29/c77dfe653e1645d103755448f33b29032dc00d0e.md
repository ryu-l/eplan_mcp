# P004038: A data transfer rate is defined for the bus slave '<x>' at the bus port in the bus system '<y>'

### Cause

A data transfer rate has been defined as a property and a value assigned to it for the bus slave of the specified bus port in the bus system.

Note that a data transfer rate may be defined only for the master of a bus system, but not for the bus slave! The master is defined via the Logical network: Bus port is master property.

This check run only checks [bus ports](Glossary_o_sps_busanschluesse.htm) at which a configuration project is entered.

### Solution

1. Locate the bus slave in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Call up the Properties <...> dialog again for the bus port of the bus slave and bring the Bus data tab to the foreground.
3. Delete the Data transfer rate property from the table in the Properties of the network interface group box and close the Properties <...> dialog with [OK].
4. Then start a new check run.

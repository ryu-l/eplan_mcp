# Settings for Update

On program update, you have a number of different options available for the way in which [settings](Glossary_o_einstellungen.htm) are adopted.

When updating to a newer program version, all settings are adopted. A prompt asks you to decide which settings you wish to adopt (user, workstation, company). You can also [return](Glossary_o_zurueckbuchen.htm) all settings to their program default values.

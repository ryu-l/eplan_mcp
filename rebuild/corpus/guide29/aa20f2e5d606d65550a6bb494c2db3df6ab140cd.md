# Uniting Objects in the Layout Space

A 3D macro (in other words a [layout space](Glossary_o_bauraum.htm) in a macro project) can contain several individual bodies if there were several bodies included in the imported source file. Although a geometrical addition of bodies is not possible, there is a function available which merges all components of the layout space in such a way that a 3D macro is treated like one item. This function is only available in layout spaces and is intentionally differentiated from grouping in the 2D [panel layout](Glossary_o_schaltschrankaufbau.htm).

![](../Pictures/Gui/ALL/note.png)Note:

The uniting of 3D bodies is not suited to reduce the amount of data in the macro to be generated. If the imported STEP file contains several identical and very detailed parts, this may lead to an increase of the amount of data after uniting. This directly influences the size of the macro files since [macros](Glossary_o_makros.htm) cannot be compressed due to the system's way of operation.

To reach an acceptable size of the macro file you should thus refrain from uniting imported common parts and [generate](Glossary_o_erzeugen.htm) the macro with the imported single parts.

Preconditions:

- You have opened a project.
- The layout space navigator is open and a layout space is open.
- The layout space contains imported 3D bodies or a 3D macro open for editing.

1. Select the Edit > Graphic > Unite menu [items](Glossary_o_bauteile.htm).
2. Surround the desired [objects](Glossary_o_objekte.htm) with a rectangle. If you have already selected objects before calling the function, there is no need to draw a frame.
3. Move the cursor over the selected objects and click the snap point you wish to use as the handle for the newly united item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected handle is stored in a new object. If you generate a 3D macro from this object, then it is moved to this point on the cursor and placed.

![](../Pictures/Gui/ALL/note.png)Note:

For technical reasons united items can only be separated again immediately after executing the action, using the Undo option. Once this option is no longer available, the bodies cannot be separated.

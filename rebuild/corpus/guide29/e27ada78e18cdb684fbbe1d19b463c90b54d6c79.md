# P026102: The <x> part cannot be migrated.

![](../Pictures/Gui/ALL/note.png)Note:

This check run message occurs during migration of the Rittal baying system TS 8 to the Rittal baying system VX 25.

### Cause

The Rittal TS8 [part](Glossary_o_artikel.htm) output in the placeholder <x> cannot be migrated because it is a [discontinued part](Glossary_o_auslaufartikel.htm).

### Solution

Place an alternative Rittal VX25 part in its place.

# P005082: Cable connection without color / number

### Cause

You have not assigned a color or a number at a [cable](Glossary_o_kabel.htm) connection.

### Solution

1. Locate the connection definition point of the cable in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Call up the dialog Properties <...> of the connection definition point and enter a value in the Color / Number field.
3. Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

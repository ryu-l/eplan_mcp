# Transferring a Local Connection Point Pattern to Parts Management

The local connection point data of the [part](Glossary_o_artikel.htm) placement can also be used in parts management in order to define [connection point patterns](Glossary_o_anschlussbilder.htm) as defaults for other [part placements](Glossary_o_artikelplatzierungen.htm). For this, a local connection point pattern which has been, e.g., individually extended by graphically defined [connection points](Glossary_o_anschluesse.htm), can be directly transferred to parts management.

1. In the [layout space](Glossary_o_bauraum.htm), select an item with connection point pattern.
2. Select the Generate connection point pattern popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In parts management, a new connection point pattern is generated with the automatic name New\_<consecutive number> (e.g. New\_1) below the hierarchy level "Connection point pattern".  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog opens.
3. Modify the automatically generated name of the connection point pattern in the opened parts management.
4. If necessary you can assign the connection point pattern with its new name to a part.

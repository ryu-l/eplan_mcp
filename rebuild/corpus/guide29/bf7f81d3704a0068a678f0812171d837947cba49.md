### Message numbers

User interface / operation

In EPLAN, every message is identified by a unique number. The system message numbers are prefixed with the "S" identifier. The numbers for check run messages are displayed without identifiers in the program user interface, but the numbers are preceded by a "P" in the help system. All message numbers consist of a 6-digit sequence: The first three digits specify the module for system messages or the class for check run messages (e.g., cables, terminals, etc.). The last three digits identify the message within a module / class.

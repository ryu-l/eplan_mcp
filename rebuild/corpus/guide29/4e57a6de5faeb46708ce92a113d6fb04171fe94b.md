# P026045: Routing connection does not end graphically at the targets

### Cause

A [part](Glossary_o_artikel.htm) placement that is the target of a routing connection was moved in the [layout space](Glossary_o_bauraum.htm), so that the routing connection virtually ends up "hanging in the air" at one end.

### Solution

#### Possibility 1

1. Locate the moved part placement in the layout space using the Go to (graphic) function from the popup menu in the Message management dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The routing connection in question is highlighted in color in the layout space.
2. Route the [connections](Glossary_o_verbindungen.htm) again.
3. Then start a new check run.

#### Possibility 2

1. Locate the moved part placement in the layout space using the Go to 2nd coordinate functionality from the popup menu in the Message management dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The part placement is highlighted in the layout space.
2. Move it back to the old position, so that it becomes the target of the routing connection again.
3. Then start a new check run.

# Parts References from the Mounting Panel

The mounting panel uses [part references](Glossary_o_artikelreferenzen.htm), since a [part](Glossary_o_artikel.htm) placement on a mounting panel is only used for visualization of a part.

Part placements on a mounting panel already define a device, even if no main function has been placed yet. In this case, you must ensure that a part is only added once to the bill of materials, even if it appears in the project through a main function as well as through a part placement.

For [devices](Glossary_o_betriebsmittel.htm) consisting of only a part placement (i.e. no main function), no device selection can be performed, nor can new part references be added.

The following combinations of part references and [part placements](Glossary_o_artikelplatzierungen.htm) can occur:

| --- | --- | --- | --- |
| 0815; 0915 | Not available | No error | 0815; 0915 |
| 0815; 0915 | 0815 | No error | 0815; 0915 |
| 0815; 0915 | 0915 | No error | 0815; 0915 |
| 0815; 0915 | AP1: 0815; AP2: 0915 | No error | 0815; 0915 |
| Main function does not exist | 0715 | No error | 0715 |
| Does not contain parts | 0715 | Errors | 0715 |
| 0815; 0915 | 0715 | Errors | 0815; 0915, 0715 |
| 0815; 0915 | AP1: 0715; AP2: 0815 | Errors | 0815; 0915, 0715 |

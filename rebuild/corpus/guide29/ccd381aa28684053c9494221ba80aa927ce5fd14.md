# Tab Module

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have selected a module [part](Glossary_o_artikel.htm) in the tree or in the list.

In this tab you can assign the positions for the selected module, that is, the parts it should contain (so-called module items).

Overview of the main dialog elements:

DT:

Enter the subordinate device tag of a device that belongs to this module.

DT ID:

Enter the DT [ID](Glossary_o_id.htm) for the function template of a device that belongs to this module. The entries 1 to 4 are possible.

You have to define the DT ID both at the main and the [auxiliary functions](Glossary_o_nebenfunktionen.htm) so that [modules](Glossary_o_module.htm) are also taken into consideration during the device selection.

![](../Pictures/Gui/ALL/note.png)Notes:

- The device has to be part of the macro that was assigned to the module. The part entered in this line is assigned to this device when inserting the module.
- Either the subordinate DT of the device or the DT ID entered at the device is used to identify a device assigned in the macro. Correspondingly either an entry in the DT column or in the DT ID column is possible per row (meaning for a module position). A corresponding check is then carried out during storing. If both fields are empty, a message is output.

Length:

Input in this column is only possible for parts with length specifications (for example cables, [connections](Glossary_o_verbindungen.htm), [lines](Glossary_o_leitungen.htm) / [conduits](Glossary_o_pakete.htm), hoses), but not for parts from the "Mechanics" generic product group.

For such a part, for example a [cable](Glossary_o_kabel.htm), you can enter a part of the length here that you have stored at the part itself. If the assembly is inserted as a device into the schematic or is broken up during the part selection, the length entered here for the individual part is transferred into the part reference property Subset / length of the corresponding function and can be output in [reports](Glossary_o_auswertungen.htm). The transfer, however, only [functions](Glossary_o_funktionen.htm) for those functions that, because of their function definition, also have their own length field in addition to the part reference [properties](Glossary_o_eigenschaften.htm). These are, for example, [cable definition lines](Glossary_o_kabeldefinitionslinien.htm) and [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm).

![](../Pictures/Gui/ALL/note.png)Note:

If the lengths of the individual parts of the modules used in the schematic are to be output in the part [assemblies](Glossary_o_baugruppen.htm) (for example parts list), you have to break the modules up for these reports. To this purpose you have to activate the Break up modules check box in the [settings for part assemblies](partslistgui_d_paramartikelauswertung.htm).

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Clear contents | Deletes the contents of the currently selected cells. |
| Go to | This menu item is only available for the column Part number. Jumps to the part that is entered in the currently selected cell. |

Break up in summarized parts list:

By means of the setting from this drop-down list you specify whether modules are to be broken up in the summarized parts list. The default value is the entry "From [settings](Glossary_o_einstellungen.htm)", meaning that the setting is taken from the [Settings: Parts](partslistgui_d_paramartikelauswertung.htm) dialog. If you select a different setting here, it overwrites those specified in the settings.

Distributed placement of module:

By means of the setting from this drop-down list you specify how a module is to be placed in the 3D mounting layout. In accordance with the selection made here, the respective module part and / or its elements (meaning the parts that are contained in a module) are displayed in the 3D mounting layout navigator, if they are assigned to a device and can be placed in the [layout space](Glossary_o_bauraum.htm).

Note that the setting does not affect the reports and the behavior in the 2D [panel layout](Glossary_o_schaltschrankaufbau.htm).

![](../Pictures/Gui/ALL/note.png)Note:

Mechanical modules can only be placed as a unit. Accordingly the Distributed placement of module setting for modules from the "Mechanics" generic product group is preset to the option "Place module parts and its components" and cannot be changed either.

# Behavior of the Program when Copying Between Different Project Structures

In EPLAN, it is possible to copy pages and [devices](Glossary_o_betriebsmittel.htm) from one project to another, even if the source and target [projects](Glossary_o_projekte.htm) have a different [project structure](Glossary_o_projektstruktur.htm).

EPLAN exhibits the following behavior when doing this:

### Behavior when copying pages

If you copy pages from a project into a project with a smaller structure:

- Identifier [blocks](Glossary_o_bloecke.htm) are retained if they are defined as describing in the target project.
- Identifier blocks are deleted if they are defined as not available in the target project.

### Behavior when copying devices

If you copy general or other devices, such as cables, [interruption points](Glossary_o_abbruchstellen.htm), black and [structure boxes](Glossary_o_strukturkaesten.htm) from a project into a project with a lower structure:

- The displayed device tag is always retained.
- In the identifying identifier block, only the [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) conforming to the target project structure are adopted.

# Dialog DT selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call of <Function category> tab:](javascript:void(0);)

You have opened a project.

- You have inserted a symbol in the graphical editor or generated a new function in a navigator. You have selected the <Function category> tab In the Properties <...> dialog. Click [...] next to the Displayed DT field.
- You have selected a [component](Glossary_o_schaltzeichen.htm) in the graphical editor or a function in a navigator. Edit > Properties (or Popup menu > Properties). You have selected the <Function category> tab. Click [...] next to the Displayed DT field.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call of <Function category> (device) tab:](javascript:void(0);)

You have opened a project.

- In the Options menu, you have selected the menu item Properties (global). You have selected a function. Double-click the function or select the Edit > Properties menu [items](Glossary_o_bauteile.htm). Click [...] next to the Displayed DT field.
- You have selected a function. Popup menu > Properties (global). Click [...] next to the Displayed DT field.

In this dialog you can use an existing function, select an existing DT, or [generate](Glossary_o_erzeugen.htm) a new DT.

Overview of the main dialog elements:

Tree and list view display the [functions](Glossary_o_funktionen.htm) existing in the project in accordance with the display in the [project data](Glossary_o_projektdaten.htm) [navigators](Glossary_o_navigatoren.htm).

If in tree view you have selected a node for device tags (e.g. "F4"), the marked DT can be selected or the next free DT with the same identifier be determined by means of the [Next] button. When selecting an existing DT, the current function is assigned this DT; no data is, however, transferred to the function.

If, in tree or list view, you have selected a function or a function template, you can use it. Here, the data of the selected function or function template is transferred to the current function. In accordance with the behavior when swapping [function definitions](Glossary_o_funktionsdefinitionen.htm), only functions with a matching number of [connection points](Glossary_o_anschluesse.htm) can be used. The number of connection points of the new function must be the same or greater than those of the selected function. It is thus possible to (e.g.) use an NO contact at an NC contact or change-over contact. Functions with an incorrect number of connection points cannot be used and the [OK] button is then not active.

Filter:

This drop-down list displays all the available [filters](Glossary_o_filter.htm). A selected filter is automatically activated and is applied to both the tree and the list view. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the [Filter](modaldialogsdb_d_filternnach.htm) dialog. Here you can [create](Glossary_o_erstellen.htm), edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

- Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
- Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

[Next]:

Generates a new DT depending on the selection. This button is only active when a node for device tags (e.g. "F4") is selected in the tree.

# Placing 3D Macros

3D [macros](Glossary_o_makros.htm) are placed in the [layout space](Glossary_o_bauraum.htm) in the same way as [devices](Glossary_o_betriebsmittel.htm).

Preconditions:

- You have opened a project.
- The layout space navigator is open and a layout space is open.

1. Select the Insert / Window macro / symbol macro menu item.
2. In the Select macro dialog, select the \*.ema file that you would like to place in the layout space. Click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The 3D macro hangs on the cursor. The handle defined in the 3D macro file is displayed as an orange cuboid.
3. Press [A] to change the handle.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Each time pushbutton [A] is actuated, the handle changes from the original position to one of the other possible handles. The handle currently selected is colored red.
4. Move the 3D macro close to a mounting panel or another object.  
     
   ![](../Pictures/Gui/ALL/arrow.png) As when [placing](Glossary_o_auflegen.htm) devices, the mounting surface or mounting rail under the cursor is automatically activated. 3D snap points are also displayed.
5. Click at the required position to place the 3D macro.
6. Set the desired numbering options in the Insertion mode dialog. Click [OK].

![](../Pictures/Gui/ALL/note.png)Note:

As well as the [part](Glossary_o_artikel.htm) [properties](Glossary_o_eigenschaften.htm) Width, Height, and Depth, EPLAN Pro Panel also provides the option of displaying devices and [items](Glossary_o_bauteile.htm) using qualified 3D graphical macros.

In order to [create](Glossary_o_erstellen.htm) own devices, items and 3D graphics macros, 3D model data in STEP format can be imported into EPLAN Pro Panel. This data, normally provided by [component](Glossary_o_schaltzeichen.htm) manufacturers, is usually based on the component manufacturer's CAD design data, and is often complex and detailed.

Using complex, detailed 3D models as the basis for EPLAN 3D graphical macros is correspondingly RAM-intensive and can have a negative impact on the program's performance when editing [projects](Glossary_o_projekte.htm) in EPLAN.

To obtain further information about this topic as well recommendations please contact the EPLAN Support.

# Defining and Formatting Device Tags

The device tag identifies a device, and can be structured according to different standards. You can use DIN-compliant [structure identifiers](Glossary_o_strukturkennzeichen.htm) or [user-defined](Glossary_o_benutzerdefiniert.htm) structures.

Preconditions:

- You have opened a project.
- In the Settings: General dialog (under the Options > Settings > Projects > "Project name" > Devices > General menu [items](Glossary_o_bauteile.htm)), you have specified how upper- and lower-case letters and the assignment of preceding signs should be handled for particular [devices](Glossary_o_betriebsmittel.htm).

1. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) for a function of a device, for example via the Edit > Properties menu items.
2. In the Properties <...> dialog, select the <Function category> tab.
3. In the Displayed DT field, enter the DT which should be displayed in the graphical editor.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The entry in the Full DT field is automatically updated.
4. Click [...] in the Full DT field.
5. In the Full DT dialog, edit the components of the device tag and click [OK].
6. Select the Display tab.
7. Select the DT (displayed) property in the list of [properties](Glossary_o_eigenschaften.htm) on the left side of the dialog.
8. Change the display and docking [settings](Glossary_o_einstellungen.htm) from the "default setting".  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Property arrangement drop-down list is automatically changed to "User-defined".
9. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The device tag is displayed in the graphical editor according to your settings.

![](../Pictures/Gui/ALL/info.png)Tip:

In the Displayed DT field, you can use the Find new DT popup menu item or the [Ctrl] + [N] key combination to [generate](Glossary_o_erzeugen.htm) a new DT with the next free counter.

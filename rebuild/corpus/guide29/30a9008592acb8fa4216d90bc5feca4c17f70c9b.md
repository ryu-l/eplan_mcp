# Compressing a Project

During compression, EPLAN checks which [project data](Glossary_o_projektdaten.htm) is used in the project and whether the project data is consistent. All of the project data that is not used and is [part](Glossary_o_artikel.htm) of the scope of the compression is deleted. The [settings](Glossary_o_einstellungen.htm) for the scope of compression are stored in [schemes](Glossary_o_schemata.htm). This allows you to save the settings you use most often for easy reuse.

If you have already stored the scope of compression as a scheme, you only need to select the existing scheme. To exclude [layers](Glossary_o_ebenen.htm) of the [project structure](Glossary_o_projektstruktur.htm) from compression, you need to define a filter.

### Determine scope of compression

Precondition:

You have opened and selected a project in the Page navigator.

1. Select the Project > Organize > Compress menu [items](Glossary_o_bauteile.htm).
2. Click [...] next to the Settings field in the Compress project dialog.
3. In the Settings: Compression dialog, select the scheme you want to edit or [create](Glossary_o_erstellen.htm) a new one.
4. In the Data to be compressed field, select the check box for the data to be compressed.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have activated the check box for a node, all subnodes are automatically selected, too.
5. Click ![](../Pictures/Gui/ALL/all_save_as.png) (Save).
6. Click [OK].

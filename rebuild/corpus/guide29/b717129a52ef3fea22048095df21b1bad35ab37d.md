# Interpreting and Transferring Logic of 3D Macros

The Automatic interpretation function is used to transfer the existing logic of any 3D macro (enclosure, enclosure components, components, contactor, etc.) to another 3D macro newly to be defined of the same or similar design. This way you can, for example, substantially simplify and speed up the work steps to [create](Glossary_o_erstellen.htm) own enclosure series.

Preconditions:

- You have opened a project.
- The project contains a completely defined enclosure.
- The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open.
- The layout space contains imported 3D bodies which are to be saved as an enclosure.
- The imported 3D bodies were arranged in the correct mounting position in the X/Y alignment using the [functions](Glossary_o_funktionen.htm) Edit > Device logic > Placement area > Define and Edit > Device logic > Placement area > Rotate.

1. Select the Edit > Device logic > Automatic interpretation menu [items](Glossary_o_bauteile.htm).
2. Surround the 3D [objects](Glossary_o_objekte.htm) for a new enclosure with a rectangle.
3. In the tree view of the Select interpretation template dialog, select a layout space and, inside of it, an enclosure whose [properties](Glossary_o_eigenschaften.htm) you want to apply to the 3D geometry.
4. If you select several different template objects and click [OK], similarity checking starts and determines which items are most suited as template objects.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The results are displayed in the Matching results dialog, including the percentage of similarity.
5. Select the most suitable item from the list of matching results. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected item is applied to the Select interpretation template dialog.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The 3D geometry is combined in the navigator under the "Enclosure" node.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The item definitions of the sample enclosure are applied to the new enclosure.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The logic elements of the sample enclosure are generated on all item definitions (handles, [mounting surfaces](Glossary_o_montageflaechen.htm), [mounting points](Glossary_o_montagepunkte.htm)).
7. Create a [3D macro](cabinetgui_h_3dmakroerstellen.htm) from the new enclosure that you can assign to a corresponding [part](Glossary_o_artikel.htm) in parts management.

![](../Pictures/Gui/ALL/info.png)Tip:

You can also first select the objects and then start the Automatic interpretation function.

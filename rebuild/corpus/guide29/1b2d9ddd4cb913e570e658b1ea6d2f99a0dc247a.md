# P005081: Unrealistic continuous connection at the connection splicer

### Cause

You have placed a connection splicer within a connection and have set the "Continuous connection between the [connection points](Glossary_o_anschluesse.htm)" property at it for specific connection points. A continuous connection is unrealistic for the specified connection points in view of the function definition of the connection. This applies to the [function definitions](Glossary_o_funktionsdefinitionen.htm) "Tube", "Optical fiber" and the function definitions for all types of jumpers.

### Solution

1. Locate the connection splicer in the project using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Call up the dialog Properties <...> of the splicer and change the [connection point designations](Glossary_o_anschlussbezeichnungen.htm) in the Continuous connection between the connection points field.  
     
   Or delete the placed connection splicer, or change the function definition of the connection on which the connection splicer was placed.
3. Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

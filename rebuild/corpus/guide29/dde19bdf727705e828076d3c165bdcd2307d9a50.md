# Dialog Conflict

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened the Properties <...> dialog for a device in the graphical editor, and have selected the Parts tab. Click [...] in the Part number field. If a [part](Glossary_o_artikel.htm) or technical [properties](Glossary_o_eigenschaften.htm) (such as technical characteristics, [connection point designations](Glossary_o_anschlussbezeichnungen.htm), [cable](Glossary_o_kabel.htm) type, etc) were already assigned to the device and these differ from those of the part selection, this dialog is displayed.

This dialog shows an overview of the old and new part properties of a function. The new properties are taken from the part just selected or entered. Here, you can decide whether to retain the old entries or overwrite them with the new ones.

Overview of the main dialog elements:

Table:

The following columns are displayed in the table:

- Status: In this column an icon indicates whether differences exist between the data of the part and the data of the function.
- Property: This lists all the properties of the function that have a value.   
   If you move the cursor over a cell here, a tooltip with the assigned part property is displayed here.
- Option: Select whether the old values should be retained, overwritten, or attached.
- Result: This field shows the value assigned to the function, depending on the selected option. If the option is not set to "Retain", the value in this cell is furthermore displayed with a yellow background.  
  All the values in the Result cell can also be edited directly.
- Part: Here the value entered for the part is displayed.
- Function: Here the value entered for the function is displayed.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Do not show this dialog again:

If this check box is selected, the Conflict dialog will no longer be displayed for the next conflict situation and you will automatically see the new part properties.

You can re-activate display of the conflict dialog by using the Reactivate suppressed messages check box (Options > Settings > User > Display > User interface menu items).

# Viewing and Editing the Connection Properties

The [properties](Glossary_o_eigenschaften.htm) of a connection can be viewed and edited in the Connections - <Project name> dialog.

1. Select the menu [items](Glossary_o_bauteile.htm) Project data > Connections > Navigator.
2. In the Connections - <Project name> dialog mark the desired [connections](Glossary_o_verbindungen.htm) and select the Properties popup menu item.
3. In the Properties <...> dialog change the connection properties in the [Connection](devicetaggui_r_verbindung.htm) tab and the graphical properties of the connecting [lines](Glossary_o_leitungen.htm) in the [Connection graphic](devicetaggui_r_verbindungsgrafik.htm) tab.
4. Click [OK].

![](../Pictures/Gui/ALL/note.png)Note:

Connections can be assigned additional properties via Connection definition points. Edit these properties at the connection definition point.

![](../Pictures/Gui/ALL/info.png)Tip:

In the Connection tab you can automatically determine the next free connection designation in the Connection designation field. For this, use the Determine new designation popup menu item or the [Ctrl] + [N] key combination.

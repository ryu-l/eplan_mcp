# Docking / Undocking Control Elements

Different user interface control elements such as the menu bar, the [toolbars](Glossary_o_symbolleisten.htm) or the "dockable" dialogs (e.g. page navigator) can be positioned inside or outside the EPLAN [main window](Glossary_o_hauptfenster.htm). You can [dock](Glossary_o_andocken.htm) these elements to the frame of the EPLAN main window or "couple" them to an already docked element.

When the program is exited, EPLAN saves the last [settings](Glossary_o_einstellungen.htm) of these elements (docked, undocked, size, position) and restores them the next time the program is started. If a particular configuration of dockable elements is to be permanently retained, i.e. when changing [workspaces](Glossary_o_arbeitsbereiche.htm), then these settings must be saved as a new workspace or saved under the existing workspace.

The windows of open pages are also "dockable and undockable". However, the settings of these [editors](Glossary_o_editoren.htm) cannot be saved with a workspace.

### [ClosedUndock the menu bar, toolbars, and dockable dialogs](javascript:void(0);)

Precondition:

You have selected a workspace with docked control elements.

1. Using the left mouse button, click a "free" area within the menu bar, within a toolbar, or in the title bar of a dockable dialog and keep the mouse button pressed.
2. Press the [Ctrl] key to avoid docking and pull the docked element to the desired position.   
     
   ![](../Pictures/Gui/ALL/arrow.png) If the borders of the respective control element are displayed with a thick line, EPLAN positions the control element as an independent, undocked element on the Windows desktop.

![](../Pictures/Gui/ALL/info.png)Tip:

Alternatively you can right-click the title bar of a docked dialog or the tab of a dialog grouped in a window and select the popup menu item Undock.

### [ClosedDock the menu bar, toolbars, and dockable dialogs](javascript:void(0);)

Precondition:

You have selected a workspace with undocked control elements.

1. Click the title bar of the desired undocked control element with the left mouse button and keep the button pressed.
2. Pull the element to the desired position in the EPLAN main window.  
     
   ![](../Pictures/Gui/ALL/arrow.png) When moving docked windows multiple [Dock elements](userinterface_k_dialoge.htm#I_Andockelemente) are displayed as positioning aids. If you move a window onto a docking element in the case of moving, the pre-selected position is highlighted in color (blue).

![](../Pictures/Gui/ALL/info.png)Tip:

Alternatively you can right-click the title bar of an undocked dialog and select the popup menu item Dock.

### [ClosedGrouping navigators, pages, etc. in a window](javascript:void(0);)

Precondition:

You have selected a workspace with undocked control elements.

1. Click the title bar of the desired undocked window with the left mouse button and keep the button pressed.
2. Drag the element to an already open window.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The window is displayed as an additional tab within the other window.

![](../Pictures/Gui/ALL/info.png)Tip:

By using the shortcut key [Ctrl] + [F7] you can switch between the tabs arranged on top of each other in a window, and bring a different tab to the front.

### [ClosedDisplaying navigators such as project pages as tabs](javascript:void(0);)

Precondition:

You have opened a page in an editor (graphical editor, [symbol editor](Glossary_o_symboleditor.htm), [form](Glossary_o_verlauf.htm) editor, etc.). You have opened at least one additional dialog (for example one of the [project data](Glossary_o_projektdaten.htm) [navigators](Glossary_o_navigatoren.htm)).

1. Right-click the title bar of the respective window and select the popup menu item Dock as tab. Alternatively you can position the window in the center of the cross-shaped docking element.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The window is displayed as additional tab. Multiple windows arranged as tabs on top of each other form an optical unit - a so-called Tab group.
2. To display the tab again as an independent window select the popup menu item Dock as tab again.

![](../Pictures/Gui/ALL/info.png)Tips:

- By using the shortcut key [Ctrl] + [F6] you can switch between the tabs of a group and bring a different window to the front.
- If multiple docked windows with tabs exist, you can arrange these windows in different tab groups. To do so click a tab and select the popup menu [items](Glossary_o_bauteile.htm) New tab group > Horizontal or New tab group > Vertical.

### [ClosedArranging a window as a flyout](javascript:void(0);)

The windows of navigators, pages, etc. can be pinned as flyouts at the right, top and lower margin of the main window. The window is then hidden and is only visible as a tab at the margin. When you move the cursor onto this tab, the "hidden" window appears again and you can carry out a selection. If the cursor is located outside the window, the flyout disappears again.

1. Click the ![](../Pictures/Gui/ALL/userinterface_pin_as.png) (Pin) button in the title bar of a docked window and select the Flyout popup menu item.
2. To dock the window again click the ![](../Pictures/Gui/ALL/userinterface_unpin_as.png) (Unpin) button in the visible state or select the popup menu item Flyout again.

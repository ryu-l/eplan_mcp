# Improvements in the Dialog for Editing the Rack

In the Edit rack dialog, you define the sequence of the [PLC cards](Glossary_o_sps_karten.htm) on a [rack](Glossary_o_baugruppentraeger.htm). This dialog has been extended with the possibility to edit the PLC card name as well as automatically assign the values for the property Position (slot / module). The PLC cards are positioned on the rack on the basis of this property.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

The new editing possibilities mean that you can comfortably edit the assignment of the PLC cards on a rack.

[![](../Pictures/Gui/Lang/plcgui_editrack_ls_thumb_0_60.png)](../Pictures/Gui/Lang/plcgui_editrack_ls.png)

To open the editing dialog, select a rack in the rack-oriented view of the PLC navigator and select the popup menu item Edit.

- In the PLC card name column you can now manually change the displayed value.
- With the new popup menu item Number "Position (slot / module)" you have the possibility to automatically assign the Position (slot / module) values of the property for the selected PLC cards or the entire rack. In the subsequent dialog you enter the start value and the increment for the numbering.

### Sort codes

User interface / operation

Sort codes exist for interruption points, for pins and for terminals. For interruption points, the sort code determines the order in which they are sorted within the project. They are automatically assigned by EPLAN and determined by the order of interruption points in the sorting dialog for interruption points, but they can also be changed manually. The default sort code is 100, i.e., the sorting occurs by page, row, and column. A "0" in this field defines the interruption point as a source. With identical sort codes, the interruption points are sorted in the order in which they appear in the schematic.   
For pins the sort code specifies the order of the pins within the plug.  
For terminals the sort code specifies the order of the terminals within a terminal device. The order of the terminal devices within the terminal strip is specified through the device position (see [Device positions](Glossary_o_geraetepositionen.htm)).

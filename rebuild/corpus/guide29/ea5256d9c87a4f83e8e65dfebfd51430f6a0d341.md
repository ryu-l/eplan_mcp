# Tab Class structure assignment

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management > [Extras] > Import. You have selected the entry for an [eCl@ss](Glossary_o_eclass.htm) version in the File type field and select an XML file with the parts records in the File name field and clicked [OK]. In the eCl@ss import dialog click the [...] button next to the Settings field and select the Class structure assignment tab.

The eCl@ss [segments](Glossary_o_segmente.htm) can be assigned to the [product groups](Glossary_o_produktgruppen.htm) of the EPLAN parts management in this tab.

Overview of the main dialog elements:

eCl@ss segment / eCl@ss main group / eCl@ss group / eCl@ss subgroup:

In these fields you specify the [part](Glossary_o_artikel.htm) [properties](Glossary_o_eigenschaften.htm) to which the hierarchical [BMEcat](Glossary_o_bmecat.htm) class [levels](Glossary_o_etagen.htm) are to be assigned by clicking [...] and selecting the respective property in the Property selection dialog. ("Attributes [1]" to "Attributes [4]" are preassigned.)

Toolbar:

| Button | Meaning |
| --- | --- |
| (New) | Opens the Application class selection dialog. Allows any application classes to be selected for the assignment to EPLAN properties for the eCl@ss segments 19 ("Information, communication and media technology"), 23 ("Machine element, fixing, mounting"), 27 (" Electric engineering, automation, process control engineering ") and 37 ("Industrial piping"). |
| (Import) | Opens a file selection dialog and allows a file in xml format to be selected so that the classes in the scheme can be supplemented by eCl@ss data. |
| (Delete) | Allows one or more classes to be deleted from the scheme. All the characteristics that belong to this class are also deleted. |

Table:

The table located in the lower area contains the following columns:

- Class ID: Contains the 8-character eCl@ss [ID](Glossary_o_id.htm) of the class.
- Class name: Contains the name of the class in the (default) language of the xml file. The language of the xml file is specified in the header of this file. If eCl@ss does not exist in this language, the source language is used.
- Generic product group: Drop-down list for the selection of the generic product group of the EPLAN parts management. The default is "Electrical engineering".
- Product group: Drop-down list for the selection of the product group of the EPLAN parts management. The default is "General".
- Product subgroup: Drop-down list for the selection of the product subgroup of the EPLAN parts management. The default is "undefined".

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

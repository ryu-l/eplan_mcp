# Working with Assemblies

An assembly is a collection of parts belonging to one device (e.g., a pushbutton with an NO contact, the appropriate bracket, and the pushbutton head). The assembly has its own [part](Glossary_o_artikel.htm) number and can contain subassemblies. The parts contained in [assemblies](Glossary_o_baugruppen.htm) also contain information about part [variants](Glossary_o_varianten.htm). Specially for device selection and for [reports](Glossary_o_auswertungen.htm), then, the technical data for variants will also be taken into account.

### Assign assembly positions

Preconditions:

- You have opened the parts management: Utilities > Parts > Management.
- You have selected an assembly and opened the Assembly tab.

1. Click on ![](../Pictures/Gui/ALL/all_new_as.png) (New) to [generate](Glossary_o_erzeugen.htm) a line in the list of assembly positions.
2. Select the desired part from the tree or list structure of parts selection.  
    Multiple selection is not possible here, i.e., the uppermost selected part is always used.
3. Click [OK].
4. Repeat these steps for each additional assignment.
5. If you want a distributed placement of the assembly in the 3D mounting layout, activate the Distributed placement of assembly check box.
6. Click [Apply] to write the entries and changes to the database without leaving parts management.

![](../Pictures/Gui/ALL/note.png)Note:

The default setting for a new line is taken from the line currently selected, i.e., its data on number and part number is used. If no entry is marked, then an empty line (with a default Quantity = "1") will be generated.

# P003007: Multiple cable targets

### Cause

You have numbered a [cable](Glossary_o_kabel.htm) that has more than one cable target. When doing this, the "According to source and target" numbering format is selected, which outputs the device tag of the target as a counter in the device tag of the cable, e.g., -W(=ANL+EBO-X5/=ANL+EBO-H3). A conflict occurs because more than one cable target exists but only one target designation can be output.

![](../Pictures/Gui/ALL/note.png) Note:

You reach the "According to source and target" numbering setting as follows:

Select the cable in the schematic.

Select the menu [items](Glossary_o_bauteile.htm) Project data > Cables > Numbering.

Click [...] next to the Settings field of the Number cables dialog.

In the Settings: Cable numbering dialog, open the Format drop-down list.

### Solution

Assign only one cable target to the cable. Then number the cable anew using the "According to source and target" format.

![](../Pictures/Gui/ALL/note.png) Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

# Displaying Routing Path View

Routing path view is defined as the highlighting of the currently valid routing path network. The routing path view can be displayed in full or filtered through the respective valid connection filter.

1. Select the menu [items](Glossary_o_bauteile.htm) View > Connections > Routing path view.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The routing path view is displayed. All [channels](Glossary_o_kanaele.htm), [routing tracks](Glossary_o_verlegewege.htm), [wiring cut-outs](Glossary_o_verdrahtungsdurchbrueche.htm), and [routing paths](Glossary_o_strecken.htm) through which a connection can run are highlighted.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The transparency of all [part placements](Glossary_o_artikelplatzierungen.htm) in the [layout space](Glossary_o_bauraum.htm) is set to 50%. The [wire ducts](Glossary_o_verdrahtungskanaele.htm) and [routing ranges](Glossary_o_verlegebereiche.htm) involved in the currently valid routing path network are excluded from the transparency highlighting to make them more clearly visible. Automatic routing paths are not highlighted.  
   ![](../Pictures/Visualisation/ALL/routing_routingpathview_as.png)

### Connection filter for routing path view

In connection with the display of the routing path view, you can set in the connection filter the criteria to be considered for the routing path view. Routing ranges that correspond to the activated criteria are highlighted. Routing ranges that correspond to the non-activated criteria are displayed as transparent.

1. Select the menu items View > Connections > Filter.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Connection filter dialog is displayed.
2. Activate or deactivate the required criteria.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) All ducts, routing tracks, [wiring](Glossary_o_verdrahtungen.htm) [cut-outs](Glossary_o_durchbrueche.htm) and routing paths through which a connection can run are highlighted if they meet at least one of the activated criteria. Tracks for which no criterion has been activated are represented as transparent.

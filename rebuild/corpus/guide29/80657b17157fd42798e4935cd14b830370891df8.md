# P011006: Ring connection for interruption point

### Cause

The arrow head of one counterpart of two cross-referencing [interruption points](Glossary_o_abbruchstellen.htm) is linked to the arrow stump of the first interruption point. A ring connection is made.

### Solution

Stop the connection between the two cross-referencing interruption points.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

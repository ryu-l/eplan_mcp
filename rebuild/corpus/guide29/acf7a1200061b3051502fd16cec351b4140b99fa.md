### Navigators

User interface / operation

The navigators offer a special view of the project data, showing all corresponding open project data, e.g., an overview of all cables, all plugs, or all connections. These dialogs are dockable and can remain open while the project is being edited. For editing specific project data, an editing dialog can be called up from the navigators (usually via the popup menu).

# Dialog Settings

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings

In this dialog you can make all project-specific, [user-specific](Glossary_o_benutzerbezogen.htm), workstation-specific, and company-specific [settings](Glossary_o_einstellungen.htm).

Overview of the main dialog elements:

The settings are divided into four main categories Project, User, Workstation and Company, which are themselves divided into further sub-categories. Main and sub-categories are presented as folders / subfolders in the tree view of the settings dialog. At the lowest level of this hierarchically arranged structure are the [settings dialogs](Glossary_o_einstellungsdialoge.htm), which appear as little dialog [icons](Glossary_o_icons.htm) in the tree view. When you click an icon, EPLAN shows the settings for the appropriate area on the right side of the settings dialog.

Find:

Into this field enter the text for which the search is to be carried out in the settings. You start actual search with the [Enter] key. If you have not entered a search term, the field is characterized with the gray text "Find".

As soon as entering the first character, the list below the entry field displays all matches. If the entered text is not found in the settings, no matching results are displayed.

If you select an entry in the list of matching results by mouse-click, then this term is applied to the entry field and search started. Tree view will then be reduced to the dialogs containing the search term.

If you want to [return](Glossary_o_zurueckbuchen.htm) to the original view of tree display, remove the search term from the entry field. Click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) to do so. This will also restore the originally made selection in tree view if, during search, you have not selected another settings area.

During search, each word in tree view and the user interface texts of the settings dialogs is evaluated. Note that you do not have to worry about case-sensitivity when entering a search term. The program only searches for texts in the determined [dialog language](Glossary_o_dialogsprache.htm). Matches will include words in which the entered search term is simply a [part](Glossary_o_artikel.htm) of the word. Thus, in the case of an English user interface, a search term "Space" will also find the setting "Workspace".

![](../Pictures/Gui/ALL/note.png)Notes:

- Please note that only texts and no specified values are found when searching in the settings.
- Logical operators (AND / OR operation) and placeholders (such as \* or ?) are not supported in this search.
- If settings dialogs are not displayed to a user on account of the current license or the rights assigned in [rights management](Glossary_o_rechteverwaltung.htm), the settings of these dialogs are not found during a search.
- When searching in the settings, user interface texts of subsequent dialogs are also browsed and found. Thus, for a search for the term "[cable](Glossary_o_kabel.htm) definition line", the dialog Settings: Cable (automatic) is listed. The actual match, however â the setting At cable definition line â is located in the subsequent dialog Settings: Cable generation. This subsequent dialog is reached by clicking [...] in the previous settings dialog for the Cable generation field.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Export | Exports the currently selected settings to an xml file, whose location you specify in a subsequent dialog. |
| Export (append data) | Exports the currently selected settings to an xml file, whose location you specify in a subsequent dialog. In contrast to exporting using the Export menu item, newly added settings (e.g. in a new version) are added to an already exported (backed-up) file. Old settings are not overwritten by this. |
| Import | Imports a previously exported xml file or settings database, which you specify in a subsequent dialog. |
| Go to default | Returns all settings of the selected area back to their default values. |

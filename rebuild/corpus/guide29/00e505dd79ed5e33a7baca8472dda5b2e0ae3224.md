# Working with Grids in the Layout Space

You can work with a [grid](Glossary_o_raster.htm) also in the [layout space](Glossary_o_bauraum.htm) to make the positioning of 3D [part placements](Glossary_o_artikelplatzierungen.htm) easier. The insertion and element points are then placed on the grid points. While working in the 3D layout space, a line grid is displayed during the placement of 3D [part](Glossary_o_artikel.htm) placements. In this case, the insertion points are on the points where the [lines](Glossary_o_leitungen.htm) cross.

In the user [settings](Glossary_o_einstellungen.htm) you can determine five different grid sizes; using the ![](../Pictures/Gui/ALL/gededitgui_grida.png) to ![](../Pictures/Gui/ALL/gededitgui_gride.png) buttons in the View toolbar or via the Edit > Other > Grid A - E menu [items](Glossary_o_bauteile.htm), these can be selected in the layout space. This setting is possible separately for 2D and 3D.

Precondition:

You have opened a layout space.

### Using Grid Snap

The use of grid snap is independent of the grid display options.

1. Select the menu item Options > Snap to grid, to switch the grid snap on and off.   
     
   ![](../Pictures/Gui/ALL/arrow.png) If snap to grid is activated, then all of the subsequent [actions](Glossary_o_aktionen.htm) are performed where the grid lines cross.  
     
   ![](../Pictures/Visualisation/ALL/cabinetgui_usegrid_as.png)

### Align on grid

This function allows you to subsequently adjust 3D [objects](Glossary_o_objekte.htm) to the grid settings that were placed without the use of a grid. In this case, it does not matter whether snap to grid is on or off.

1. Select the objects and then select the Edit > Other > Align on grid menu items.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected objects are realigned (i.e., moved) so that all of their important points (such as handle, placement point, etc.) are on the grid.  
     
   ![](../Pictures/Visualisation/ALL/cabinetgui_alignongrid_as.png)

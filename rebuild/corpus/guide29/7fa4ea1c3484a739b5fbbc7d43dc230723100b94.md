# Positioning and Formatting of Cable Properties

The [properties](Glossary_o_eigenschaften.htm) of cables and [shields](Glossary_o_abschirmungen.htm) (e.g. the DT) can be displayed on the symbol in the schematic, like with other [devices](Glossary_o_betriebsmittel.htm). Four different angles can be specified when doing this.

Certain default [configurations](Glossary_o_konfigurationen.htm) are delivered for the Property arrangement field, from which you can select the desired arrangement (in the Display tab of the [property dialog](Glossary_o_eigenschaftendialog.htm)). These arrangement configurations affect the placement of the DT and all additional property text docked on it.

If you have selected this type of default arrangement configuration, then the arrangement of the property text will remain, even after changing the extent of the [cable](Glossary_o_kabel.htm) definition line or shield. The position of the property text is also recalculated.

The text alignment is also dependent on those positions. This way the text will extend up and to the left in the case of "Upper left", for example.

However, you can also freely set the positioning and formatting of properties ([user-defined](Glossary_o_benutzerdefiniert.htm) property arrangement). In doing so the position is always specified relative to the insertion point. When moving the insertion point of the cable definition line (or the shield) the displayed properties move as well.

### Alternative cross-section / diameter

For cables and [connections](Glossary_o_verbindungen.htm), an alternative cross-section / diameter can be specified, along with a corresponding alternative unit. These properties are independent of the parts management and must be manually filled and reported. These properties make it possible to define the connection cross-section / diameter in parallel in different units (e.g., AWG and mm²). The properties are available in the property dialog for cables and connections, and can be used in [reports](Glossary_o_auswertungen.htm).

For cables:

- Cable / Conduit: Alternative cross-section / diameter
- Cable / Conduit: Unit for alternative cross-section / diameter
- Cable / Conduit: Alternative cross-section / diameter with unit.

For connections:

- Alternative connection cross-section / diameter
- Alternative connection cross-section / diameter with unit
- Unit for alternative connection cross-section / diameter.

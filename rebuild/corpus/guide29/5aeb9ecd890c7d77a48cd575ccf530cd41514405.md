# Dialog Settings - <Report type> (Function-related)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Reports > Generate. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New). In the Select report dialog, select a function-related [report type](formgeneratorgui_k_auswertungstypen.htm#I_Funktionsbezogene), e.g., a terminal diagram. Click [OK].

In this dialog, you can specify the sorting, filter, and page break [schemes](Glossary_o_schemata.htm) for [function-related](formgeneratorgui_k_funktionsbezogen.htm) [reports](Glossary_o_auswertungen.htm). Function related reports have a device in the header as standard, e.g., terminal strip. The associated [functions](Glossary_o_funktionen.htm) are in the data area, e.g., the terminals of the terminal strip. The sorting and filter schemes are stored per user and stored with the report when a report page is generated.

Overview of the main dialog elements:

Device:

This group box is only available when the Manual selection check box in the Select report dialog is deselected. Here you define the filter and sorting criteria for the device. For "Terminal diagram" reports these are the terminal strips. For "Symbol overview" reports, these are the [symbol libraries](Glossary_o_symbolbibliotheken.htm).

- Filter: In this field, select a scheme defining which [devices](Glossary_o_betriebsmittel.htm) / symbol libraries are to be output. Click [...] to open the Filter dialog, which you can use to define or edit a scheme. Possible filter criteria are (e.g.) the [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) of the [project structure](Glossary_o_projektstruktur.htm).

  ![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

  You [generate](Glossary_o_erzeugen.htm) a terminal diagram. Define the following filter:

  | Active | Negated | Criterion | Operator | Value |
  | --- | --- | --- | --- | --- |
  |  |  | Higher-level function | = | HF1 |

  All terminal strips of the HF1 [higher-level function](Glossary_o_anlage.htm) are reported.
- Sorting: In this field, select a scheme defining how the report for devices / symbol libraries is to be sorted. Click [...] to open the Sorting dialog, which you can use to define or edit a scheme.

  ![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

  You generate a terminal diagram and have selected the Higher-level function HF1 filter. Select the predefined sorting scheme Mounting location.

  All filtered terminal strips are sorted by [mounting location](Glossary_o_einbauort.htm) in the report.

A selected scheme is activated automatically. You can deactivate the selection of a scheme through the entry "- Not activated -".

Functions:

Here you define the filter and sorting criteria for the functions. For "Terminal diagram" reports these are the associated terminals of a terminal strip. For "Symbol overview" reports, these are the [symbols](Glossary_o_symbole.htm).

- Filter: In this field select a scheme defining which functions / symbols are to be output. Click [...] to open the Filter dialog, which you can use to define or edit a scheme.

  ![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

  Manual selection is deactivated:

  You are creating a terminal diagram and have already selected the Higher-level function HF1 filter in the Devices group box for terminal strips. Define the following filter:

  | Active | Negated | Criterion | Operator | Value |
  | --- | --- | --- | --- | --- |
  |  |  | Function definition | = | PE- / PEN terminal, 4 targets |

  Only the PE / PEN terminals with 4 targets are reported from all the filtered terminal strips.

  Manual selection is activated:

  You generate a terminal diagram. Define the following filter:

  | Active | Negated | Criterion | Operator | Value |
  | --- | --- | --- | --- | --- |
  |  |  | Function definition | = | PE- / PEN terminal, 4 targets |

  Only the PE / PEN terminals with 4 targets are reported from all the manually selected terminal strips.
- Sorting: In this field, you can select a scheme specifying the sort order of the functions / symbols. Click [...] to open the Sorting dialog, which you can use to define or edit a scheme.

  ![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

  You generate a terminal diagram. Select the predefined sorting scheme Mounting site. All filtered terminals are sorted by mounting site in the report.
- New page if property value has changed: In this field, you can select a scheme which specifies when a new page is generated. Click [...] to open the New page if property is changed dialog, which you can use to define or edit a scheme.

A selected scheme is activated automatically. You can deactivate the selection of a scheme through the entry "-Not activated-".

Form (deviating from settings):

To assign a [form](Glossary_o_verlauf.htm) to the selected report type which deviates temporarily from the specification in the [settings](Glossary_o_einstellungen.htm), you open this dropdown list and click on "Browse". The directory defined as the form directory in the settings is already loaded in the Select form dialog. In the File type field, the form type matching the report type is automatically displayed. Select the desired form and click [Open].

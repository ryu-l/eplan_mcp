# Popup Menu Item for the Properties of the Assigned Segment

For [functions](Glossary_o_funktionen.htm) in the schematic or for the piping definition points in the [P&I diagram](Glossary_o_ri_fliessbild.htm) that are assigned to a segment in the pre-planning, the new popup menu item Properties (pre-planning) is available in the popup menu of the Graphical editor. The [property dialog](Glossary_o_eigenschaftendialog.htm) of the assigned segment is opened by means of this menu item.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

You can directly edit the [properties](Glossary_o_eigenschaften.htm) of the assigned [segments](Glossary_o_segmente.htm) from the graphical editor without having to use the pre-planning navigator by means of the popup menu item Properties (pre-planning).

If you select this popup menu item for a function linked with the pre-planning, for example on the schematic page, the property dialog of the assigned planning object is opened.

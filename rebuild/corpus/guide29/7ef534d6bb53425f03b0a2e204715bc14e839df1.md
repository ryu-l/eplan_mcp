# P501017: No trade is selected at the part

### Cause

In the parts database to be checked a [part](Glossary_o_artikel.htm) was found where no trade is entered.

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective part is already marked in it.
2. Bring the General tab to the front.
3. Click [...] next to the Trade / Subtrade field.
4. In the Trade /Subtrade dialog activate corresponding check box(es) in the Use column for the desired trade and / or subtrade and click [OK].
5. Close the parts management, save the modified data, and carry out a parts synchronization.
6. Then start a new check run.

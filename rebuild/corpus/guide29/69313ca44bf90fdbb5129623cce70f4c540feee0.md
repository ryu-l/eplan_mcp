# Outline Editor: Basics

As soon as you have opened the outline you want to edit in the outline editor, you can edit its components.

The first editing step is to draw the 2D geometry of the outline you have created. All the graphical elements and editing [functions](Glossary_o_funktionen.htm) that are allowed for [outlines](Glossary_o_konturen.htm) are available to you.

The following conditions apply:

- Draw on a 1:1 scale.
- Use the line, polyline, rectangle, circle, and arc graphical elements.
- Make sure that the elements making up the outline are closed at all the transition points.

The further procedure depends on the outline type: The logic for outlines of the Outline extrusion type is defined as "[outline definition points](Glossary_o_konturdefinitionspunkte.htm)". The following menu [items](Glossary_o_bauteile.htm) are available for this in the outline editor under Insert > Logic, and they each start a special interaction for [placing](Glossary_o_auflegen.htm) and numbering an outline definition point:

- Guide rails: can be placed any number of times
- Guide rail with alignment: can be placed any number of times
- Mounting surfaces: can be placed clockwise (outer outline) / counter-clockwise (inner outline) in pairs, on a straight outline segment
- Mounting surfaces NC: can be placed clockwise (outer outline) / counter-clockwise (inner outline) in pairs, on a straight outline segment
- Field size: can be placed clockwise in pairs, relating to the outer outline.

For outlines of the Outline NC record generation type, there is a special dialog available, the [NC outline record](contoureditorgui_d_ncdatensatz.htm) dialog; in this dialog, you specify the machine-based data relevant to the outline drawing. This information is stored to the outline.

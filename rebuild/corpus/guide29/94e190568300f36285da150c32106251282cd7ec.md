# Creating an Unplaced Function in the Device Navigator

In the device navigator you can [create](Glossary_o_erstellen.htm) a function with a new device or a function for an existing device - by selecting a function definition. The new function is not placed in the schematic.

Unplaced [functions](Glossary_o_funktionen.htm) can be deleted only in the [project data](Glossary_o_projektdaten.htm) [navigators](Glossary_o_navigatoren.htm) (e.g., the device navigator).

Precondition:

You have opened a project.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Devices > Navigator
2. Mark a device and select the New popup menu item.
3. Select a function definition in the Selection field of the Function definitions dialog.
4. Click [OK].
5. In the Properties <...> dialog, select the <Function category> tab.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The displayed device tag of the selected device is shown in the Displayed DT field.
6. Enter a new visible DT in order to create a function with a new device. Leave the DT unchanged in order to create a function for the marked existing device.
7. Click [OK].
8. Press [F5] to update the view.

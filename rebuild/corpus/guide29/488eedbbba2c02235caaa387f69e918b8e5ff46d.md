# P007025: The DT ID '<x>' has been assigned several times

### Cause

A DT [ID](Glossary_o_id.htm) which has already been assigned was determined at a function which is a [component](Glossary_o_schaltzeichen.htm) of a macro for a module.

### Solution

1. Locate the function in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Launch the [property dialog](Glossary_o_eigenschaftendialog.htm) of the function.
3. In the [properties](Glossary_o_eigenschaften.htm) list, change the value of the DT ID property. Enter a value which has not been assigned yet.
4. Then start a new check run.

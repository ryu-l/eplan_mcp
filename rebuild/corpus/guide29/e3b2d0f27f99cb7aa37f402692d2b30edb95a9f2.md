# P014001: The macro name '<x>' is repeated

### Cause

While [macros](Glossary_o_makros.htm) were being generated from a macro project a macro name was defined at a macro box that is already assigned to a different macro box. Or several identical macro names have been stored in the macro definition for one and the same macro box.

### Solution

1. Locate the macro box in the macro project using the Go to (graphic) functionality from the popup menu in the Message management dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The macro box is marked on the project page.
2. Use the popup menu to open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the macro box.
3. Bring the Macro box tab to the front.
4. Change the macro name in the Name field. Select a name that has not yet been assigned to a different macro box.
5. Change to the Macro definition tab and check whether further [lines](Glossary_o_leitungen.htm) with identical macro names exist below the 1st line in the table column Macro: Name.
6. If so, delete the macro names occurring several times or replace them by unique macro names.
7. Close the [properties](Glossary_o_eigenschaften.htm) dialog with [OK].
8. Start a new check run.
9. Repeat Steps 1 to 9 for further [macro boxes](Glossary_o_makrokaesten.htm) displayed in the Message management dialog.

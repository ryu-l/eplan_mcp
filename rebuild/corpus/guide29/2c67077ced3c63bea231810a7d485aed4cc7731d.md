# P014005: No macro name defined at the layout space

### Cause

At least one macro name has to be specified at the [layout space](Glossary_o_bauraum.htm) for the automatic generation of [macros](Glossary_o_makros.htm) from a macro project. This has to be defined as a property both in the Layout space tab and in the Macro definition tab. In this case the entry is missing in both tabs.

### Solution

1. Open the layout space navigator.
2. Locate the layout space in the macro project using the Synchronize selection function offered by the popup menu in the Message management dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The layout space is marked in the layout space navigator.
3. Use the popup menu of the layout space navigator to open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the layout space.
4. Bring the Macro definition tab to the front.
5. Enter the desired macro name in the first line of the table in the Macro: Name column or select it interactively by using [...]. (Use the further [lines](Glossary_o_leitungen.htm) of the table to define further macro names.)
6. If required, store a description of the macro in the Macro: Description column.
7. Close the [properties](Glossary_o_eigenschaften.htm) dialog with [OK].
8. Then start a new check run.

![](../Pictures/Gui/ALL/note.png) Note:

If you have entered a macro name in the first line of the Macro definition tab, this is entered automatically in the properties table of the Layout space tab and displayed there as the Macro: Name property. Similarly a macro name defined in the Layout space tab for the Macro: Name property is entered automatically into the first line of the Macro definition tab and there displayed in the Macro: Name column.

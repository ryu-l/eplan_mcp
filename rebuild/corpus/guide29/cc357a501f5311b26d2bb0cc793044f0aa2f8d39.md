# P005071: Different connection designations in a signal

### Cause

Within a signal, there are [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) with different [connection designations](Glossary_o_verbindungsbezeichnungen.htm).

### Solution

1. Locate the connection definition point in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Delete the connection designation, or change its name, so that all connection [designations](Glossary_o_bezeichnungen.htm) within the signal are identical.
3. Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

![](../Pictures/Gui/ALL/info.png)Tip:

Use the function of [connection numbering](Glossary_o_verbindungsnummerierung.htm) in order to assign connection designations automatically.

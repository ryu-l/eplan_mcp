# P024017: Function of the representation type 'Function overview (fluid power)' has no correspondence in the schematic

### Cause

On a page of the "Function overview ([fluid power](Glossary_o_fluidtechnik.htm))" type a function is placed that has the representation type "Function overview (fluid power)". This function has no corresponding counterpiece of the "Multi-line" representation type on the associated multi-line schematic page.

### Solution

1. Starting from the Message management dialog use the Go to (graphic) functionality to locate the function of the page of the "Function overview (fluid power)" type in the schematic.
2. Call up the Properties <...> dialog of the function and first ensure that the function is not a main function.
3. Copy the function and change to the associated page of the type "Schematic (fluid power)".
4. Insert the function on this page as a main function, assign the same DT and assign the representation type "Multi-line" to the function on the Symbol / function data tab.
5. Confirm your entries.
6. Then start a new check run.

# Symbols: Procedure

To use [symbols](Glossary_o_symbole.htm) for creating and editing schematics, the following steps must be performed:

- Load the symbol library into a project: If you wish to use symbols from a symbol library in a project, then you must first [load](Glossary_o_laden.htm) the symbol library into the project. This links the appropriate symbol library in this project with the [master data](Glossary_o_stammdaten.htm): Options > Settings > Projects > "Project name" > Management > Symbol libraries.
- Select the symbols: Insert > Symbol opens the Symbol selection dialog, where you can select a symbol with the help of various search alternatives.
- Place the symbols: Once you have selected the desired symbol using the Symbol selection dialog, you then use the graphical editor to place the symbol on the page. The connection of the newly placed symbol to the other symbols in the schematic occurs automatically via autoconnection.
- Define the [properties](Glossary_o_eigenschaften.htm) of the [component](Glossary_o_schaltzeichen.htm): Once the symbol has been placed on the page, you use the Properties <...> dialog to define the component-specific properties (for device tag, function text, etc).

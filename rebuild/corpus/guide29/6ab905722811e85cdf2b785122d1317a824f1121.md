# Mounting panels: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_montageplatten.htm)

### Mounting panels

Electrical engineering

2D: Logical area on a "Panel layout" graphical page, defined by a graphically modifiable schematic object with a number of similar characteristics to a black box.  
  
3D: 3D part placement in the layout space. The mounting panel has mounting surfaces on which other 3D part placements can be placed. If the Machining property is activated for a mounting surface, the objects placed on it will generate machining (drill holes) that can be transferred to NC machines for manufacturing.

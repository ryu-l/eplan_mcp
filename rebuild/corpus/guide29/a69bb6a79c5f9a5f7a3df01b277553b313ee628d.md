# Drawing Connection Symbols With Target Specification or as Point

For [connection symbols](Glossary_o_verbindungssymbole.htm) there is a series of [user-specific](Glossary_o_benutzerbezogen.htm) [settings](Glossary_o_einstellungen.htm) regarding the drawing of [symbols](Glossary_o_symbole.htm). Under the menu [items](Glossary_o_bauteile.htm) Options > Settings > Projects > "Project name" > Graphical editing > General there are also additional project-related settings which influence the display of connection symbols.

1. Options > Settings > User > Graphical editing > Connection symbols
2. In the Draw connection junctions as group box in the Settings: Connection symbols dialog specify how the connection symbols should be drawn in the graphical editor.
3. Select the Connection symbols with prompt check box if you always want to display a prompt dialog when drawing connection symbols. (If you selected the With target specification or as point option in the Draw connection junctions as group box, this check box is automatically selected and grayed out.)
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection symbols are populated accordingly when they are drawn.

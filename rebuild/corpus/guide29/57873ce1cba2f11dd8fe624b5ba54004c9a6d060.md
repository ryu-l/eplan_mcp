# Use cases: Definition of term

### Use cases

User interface / operation

The usage of a device is known as a so-called "use case". Each use case has its own set of safety-related values (see [Safety-related values](Glossary_o_sicherheitskennwerte.htm)). This means that, depending on how a device is used, differing safety-related values must be used. Differing uses cases may arise, for example, from the differing use of a device. Thus, for example, a drive can be operated with or without brakes, which in turn means differing safety-related values.

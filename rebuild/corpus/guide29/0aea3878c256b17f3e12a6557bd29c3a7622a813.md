# P026076: Cable / tubing protection or cable / tubing tie is not located on a routing path / curve

### Cause

A [cable / tubing protection](Glossary_o_kabel_schlauchschutz.htm) or [cable](Glossary_o_kabel.htm) / tubing tie was moved in the [layout space](Glossary_o_bauraum.htm), so that it can no longer be assigned to a routing path or curve.

### Solution

1. Locate the cable / tubing protection or cable / tubing tie in the layout space using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Delete the moved cable / tubing protection or cable / tubing tie.
3. Route the [connections](Glossary_o_verbindungen.htm) again, then start a new check run.

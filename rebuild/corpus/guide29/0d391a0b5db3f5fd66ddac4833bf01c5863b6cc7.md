### PLC data types

Electrical engineering

Some controllers specify a data type for every I/O connection point. This data type is automatically accounted for by EPLAN, and in addition to the address and connection point designation, is regarded as an identifying property. The most frequently used data types are BOOL, BYTE, WORD, and DWORD.

# P004096: Safety address '<x>' assigned several times

### Cause

One and the same value was entered at the Safety address property at at least two [PLC boxes](Glossary_o_sps_kaesten.htm) that are safety-relevant in the project.

### Solution

1. Locate the PLC boxes in the schematic using the Go to (graphic) and Go to 2nd coordinate functionalities from the popup menu of the Message management dialog.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) of each PLC box one after the other.
3. Bring the first tab to the front.
4. Enter a unique value in the list of [properties](Glossary_o_eigenschaften.htm) in the Safety address field.
5. Click [OK].
6. Then start a new check run.

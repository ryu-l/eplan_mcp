# XML Export / Import: Tags and Associated Attributes

The following tables list the tags used for export and import, their attributes, and additional information. Here, the data types in the "Type" column have the following meanings:

Bool

"0" or " " mean "no", "false", or "off", "1" means "yes", "true", or "on".

Integer / Long

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

"", "0", "1", "2", or "-5"

"" means the same as "0".

For attributes of a selection list, only certain values may be used which can be selected in parts management. An overview of the valid values can be found in the section [Overview of Selection Lists](xmlexport_o_sellists.htm).

Double / Currency

The decimal [separator](Glossary_o_trennzeichen.htm) is the period.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

"1.99" or "2.5"

"" means the same as "0".

Text / memo

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

"This is a text" or "".

Multilingual text

Language parts in a multilingual text are defined starting with the language code and ending with a semicolon. Between the language code and the text there must be an "@".

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

de\_DE@Schütz; en\_US@Contactor;nl\_NL@Relais;

### <partsmanagement>

| Attribute | Field name | Remark |
| --- | --- | --- |
| length-unit | Unit of length | Unit in which lengths are imported, for instance "mm" or "inch". Optional, default "mm". |
| type | Type | Type of parts management. Currently the only supported value is "EPLAN.PartsManagement". Optional. |
| build | Build number | Build number at the time of export. Optional. |

# Tab Options

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > User > Management > Data Portal. Select the Options tab.

In this tab you specify the security [settings](Glossary_o_einstellungen.htm) for the import from the Data Portal.

Overview of the main dialog elements:

Check downloaded files:

If this check box is activated, a check is carried out whether the downloaded supplementary documents were changed by third parties compared to their state on the server.

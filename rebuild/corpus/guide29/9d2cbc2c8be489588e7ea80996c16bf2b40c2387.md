# Reporting and Outputting Piping and Tubing Lists

In [fluid power](Glossary_o_fluidtechnik.htm), fluid [connections](Glossary_o_verbindungen.htm) are generally documented using so-called piping and tubing lists. A piping or tubing list is a special connection list for fluid power. It shows if a fluid power connection between two fluid [functions](Glossary_o_funktionen.htm) is a pipe or a tube. It also lists the [devices](Glossary_o_betriebsmittel.htm) (DT of the target) and gives information about cross-section and / or length of the corresponding connection. In EPLAN Fluid it is possible to report on such connections and to output the result as piping and tubing lists as pages in the project.

The connection type "Pipe" or "Tube" of a fluid connection can be determined either by means of defaults in the [settings](Glossary_o_einstellungen.htm) or with the help of a connection definition point with "Pipe" or "Tube" as set function definition.

When reporting on piping and tubing lists, the program proceeds as follows:

If fluid connections don't have any [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm), the program determines the function definition from the settings for the connection [properties](Glossary_o_eigenschaften.htm).

For connections that have connection definition points, the function definition of the connection definition point determines whether the connection is a "pipe" or a "tube".

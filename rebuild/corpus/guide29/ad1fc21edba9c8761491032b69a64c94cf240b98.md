# Generating PLC Schematics

EPLAN allows unplaced PLC [functions](Glossary_o_funktionen.htm) (or those that are unplaced in particular representations) to be automatically placed, thus allowing PLC schematics with different overview pages to be generated. You can first [create](Glossary_o_erstellen.htm) the unplaced PLC functions in the PLC navigator, import from a PLC configuration file, or import addresses from an assignment list and use the device selection to [generate](Glossary_o_erzeugen.htm) PLC functions for these. If you have already generated a PLC schematic then the automatically placed PLC functions can be deleted and placed again.

Preconditions:

- You have opened a project.
- You have created unplaced PLC functions or imported them from a PLC configuration file.
- Or you have imported [PLC addresses](Glossary_o_sps_adressen.htm) from an assignment list and then used the Generate with device popup menu option to generate unplaced PLC functions for these addresses.
- Or you have already generated a PLC schematic, so that the project contains automatically placed PLC functions.
- You have selected a project or project pages in the page navigator. You have selected PLC functions in one of the [navigators](Glossary_o_navigatoren.htm). You have selected PLC components in the graphical editor.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project data > PLC > Generate schematic  
     
   ![](../Pictures/Gui/ALL/arrow.png) Those PLC [devices](Glossary_o_betriebsmittel.htm) that are completely or partially included in the marking are shown in the Objects column in the dialog Generate PLC schematic.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the functions are already placed in particular representations, then the corresponding page names are shown in the Page, single-line, Page, multi-line, Page, overview, and Page, rack layout columns.
2. Assign a suitable macro in the Macro file column to the [PLC boxes](Glossary_o_sps_kaesten.htm) if no macro was entered at the [part](Glossary_o_artikel.htm), or change the automatically assigned macro (via the part) if necessary. To do this, click [...] in the cell and select the desired macro in the Select macro dialog.
3. Assign suitable [wiring](Glossary_o_verdrahtungen.htm) [macros](Glossary_o_makros.htm) to the [PLC connection points](Glossary_o_sps_anschluesse.htm) in the Macro file column. To do this, click [...] in the cell and select the desired macro in the Select macro dialog.
4. If the assigned macros contain variables then, if necessary, select different value sets in the columns with variable names. You can also manually enter values.
5. Activate the check boxes for the representations that you want to generate: Generate single-line representations, Generate multi-line representations, Generate overviews, or Generate rack overviews.
6. Select the rows with the devices for which you wish to generate schematic pages.
7. Select the Calculate pages popup menu item.
8. In the Start pages dialog enter the page names for the first start page of every required representation type, or click [...] and use the Full page name dialog to edit the structure identifier and the page names. You can use [...] to select the [structure identifiers](Glossary_o_strukturkennzeichen.htm) (such as [higher-level function](Glossary_o_anlage.htm) and [mounting location](Glossary_o_einbauort.htm)) from the existing values. You can also manually enter the identifiers and create new ones in the process.
9. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Based on the name specified for the first start page, EPLAN calculates the start pages for all other devices and enters these into the table.
10. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The pages are generated according to the [settings](Glossary_o_einstellungen.htm) and the specified macros are placed on them. The macros are inserted at their original positions. If several macros fit on a page, these are inserted next to each other or below each other (depending on the plot frame).  
      
    ![](../Pictures/Gui/ALL/arrow.png) The automatically generated pages are assigned the Automatically generated property, whereby the value in the drop-down list shows the representation type.

![](../Pictures/Gui/ALL/info.png)Tips:

- In the Generate PLC schematic dialog, you can use ![](../Pictures/Gui/ALL/all_new_as.png) (New) to insert further PLC devices from the project into the table. You can select, for example, only those functions that are unplaced in one or more particular [representation types](Glossary_o_darstellungsarten.htm). You can (e.g.) first generate only the multi-line schematic pages and then generate the overview pages in a second step.
- Via ![](../Pictures/Gui/ALL/all_export_as.png) (Export) and ![](../Pictures/Gui/ALL/all_import_as.png) (Import) you can save the configuration (i.e. all settings you have made in the Generate PLC schematic dialog) and use them later.

![](../Pictures/Gui/ALL/note.png)Note:

You can subsequently manually edit automatically generated pages. However, when these pages are re-generated they are overwritten and the manual changes are lost. If you do not wish this to happen, change the value of the Automatically generated page property to "No".

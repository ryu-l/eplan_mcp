# Displaying, Adding or Deleting Alignable Accessories

In the Edit terminal strip dialog you can assign alignable [accessories](Glossary_o_zubehoer.htm) such as [mounting rails](Glossary_o_tragschienen.htm), partition plates, end clamps, etc. to a terminal strip. The accessory is saved as a parts entry at the [main terminals](Glossary_o_hauptklemmen.htm), or in the terminal strip definition if you are not using main terminals. To ensure that this accessory is displayed in the dialog, you must select the Alignable accessories visible option.

Preconditions:

- Appropriate [accessories](terminalgui_k_klemmenzubehoer.htm) are available in parts management.
- You have selected a terminal or a terminal strip definition in the terminal strip navigator, the device navigator or the graphical editor. You have used the menu [items](Glossary_o_bauteile.htm) Project data > Terminal strips > Edit to open the Edit terminal strip dialog.

### [ClosedDisplay alignable accessories](javascript:void(0);)

1. Select the popup menu item Alignable accessories visible.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The alignable accessory is displayed in the dialog in a separate line. In the Preview column a schematic preview of the accessory is shown.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the accessory is already assigned to a terminal, the terminal and accessory are displayed as a block. In the "line" column, the line numbers are grouped in one field.

### [ClosedAdd alignable accessories](javascript:void(0);)

1. In the Edit terminal strip dialog click the field with the line number of the desired terminal.
2. Select the popup menu item Add alignable accessories.
3. In the Part selection dialog scroll through the tree structure and select the alignable accessory required. Multiple selection is possible.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The alignable accessory is inserted into the Edit terminal strip dialog below the current cursor position as a separate, shaded line. You can move every row as you wish. In the "Row" column, a small arrow indicates the direction in which the accessory is sorted before or after a terminal.
5. Select the popup menu item Alignable accessories following to sort the alignable accessory before or after the terminal.
6. Click [Apply].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The alignable accessory is assigned to the terminal and the parts are entered at the terminal. The terminal and accessory are combined into a block which can be moved as one unit. In the "line" column, the line numbers are grouped in one field.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the Do not use main terminals property is selected for the terminal strip, the parts are entered at the terminal strip definition. The [lines](Glossary_o_leitungen.htm) for the alignable accessory and the direction arrow for sorting are retained.  
     
   ![](../Pictures/Gui/ALL/arrow.png) When moving alignable accessories, the sequence of the parts on the terminal strip is stored in a sort code. The value is entered into the Sorting of part on terminal strip property which is either visible at the associated main terminal or at the terminal strip definition in case you do not use main terminals.

![](../Pictures/Gui/ALL/info.png)Tip:

You can also perform the Add alignable accessories action for several marked terminals. The alignable accessories selected in the subsequent dialog are then entered at the marked main terminals or multi-level terminals.

### [ClosedDelete alignable accessories](javascript:void(0);)

1. In the Edit terminal strip dialog, click in the line in question with the line number field in order to select the block formed from a terminal and an alignable accessory.
2. Click the ![](../Pictures/Gui/ALL/terminalgui_separatemulti_as.png) (Split) button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The alignable accessory is displayed as a separate line.
3. In the Edit terminal strip dialog, click in the line in question with the line number field in order to select the alignable accessory.
4. Select the popup menu item Delete alignable accessories.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected accessory is deleted, i.e. the parts entry at the main terminal / in the terminal strip definition is removed.

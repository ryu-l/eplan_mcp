# Dialog Optimize nets automatically

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have created [routing connections](Glossary_o_verlegeverbindungen.htm). In the [layout space](Glossary_o_bauraum.htm) navigator or in the layout space a [component](Glossary_o_schaltzeichen.htm) has been highlighted that contains routing [connections](Glossary_o_verbindungen.htm). Project data > Connections > Optimize [nets](Glossary_o_netze.htm) automatically.

In this dialog, you can set options for the automatic optimization of nets and the connections routed in them. With automatic optimization, the connections of the net / [daisy chains](Glossary_o_verbindungsketten.htm) are redesigned in such a way that the following conditions are met:

- All [connection points](Glossary_o_anschluesse.htm) continue to be connected.
- The sum of the [wires](Glossary_o_draehte.htm) to be routed is a short as possible.
- No more than two connections terminate in a connection point.
- A daisy chain is always generated.

Overview of the main dialog elements:

Apply to nets from number of connections:

Prior to optimization, you can specify the number of connections per net that is to trigger optimization. The minimum number is 2.

Apply to nets to number of connections:

In the case of large nets with many connections the optimization can take some time. To limit the time required you can apply the optimization exclusively to nets that do not contain more than the number of connections specified here. Larger nets are not optimized. The maximal value is 2000. If a net was not optimized, this is logged in the [system messages](Glossary_o_systemmeldungen.htm).

Also optimize nets that are only selected partially:

All nets included in the selection completely or partially are optimized.

Close daisy chains into a ring:

If this check box is activated, an additional connection from the first to the last connection point of the chain is generated.

Apply to entire project:

If this check box is activated, all nets are optimized for which targets have been placed in all the layout spaces of the project.

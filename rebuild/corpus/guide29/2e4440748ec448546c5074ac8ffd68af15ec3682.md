# Creating / Selecting a Project Management Database

Always begin project management in connection with a project management database. All information displayed in the project management is contained in this database. Project management can be based on an Access database or an [SQL server](Glossary_o_sql_server.htm) database. The name of this database can be freely selected. In previous EPLAN versions (version 2.3 or older), project management was based on an Access database with the unchangeable default name Projects.mdb.

### [ClosedCreating a Project Management Database](javascript:void(0);)

Precondition:

You have not yet created a project management database.

1. Select the following menu [items](Glossary_o_bauteile.htm): Options > Settings > User > Management > Project Management Database
2. Use the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button in the dialog [Settings: Project management database](prjmanagementgui_d_prjverwaltungsdb.htm) to [create](Glossary_o_erstellen.htm) an Access database or an SQL server database.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected the SQL server option, the [Generate SQL server database](modaldialogs_d_sqlserver.htm) dialog is opened to this purpose.
3. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The newly created database will then be entered in the [settings](Glossary_o_einstellungen.htm) as project management database and is therefore automatically selected.

![](../Pictures/Gui/ALL/note.png)Note:

A message is displayed if you open the project management without a project management database having being created and selected. If you confirm this message, the dialog for creating / selecting a project management database is opened.

### [ClosedSelect Access database](javascript:void(0);)

Precondition:

You have created an Access project management database or have access to an Access project management database.

1. Select the following menu items: Options > Settings > User > Management > Project Management Database
2. Click [...] next to the Filter field in the Settings: Project management database dialog.
3. In the file selection dialog, navigate to the directory where your project management database is stored. Select the desired file.
4. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The database is entered in the settings as project management database.

### [ClosedSelect SQL server database](javascript:void(0);)

Precondition:

You have created an SQL server database or have access to an SQL server database.

1. Select the following menu items: Options > Settings > User > Management > Project Management Database
2. Select one of the last 15 SQL databases used from the SQL server drop-down list in the dialog Settings: Project management database. The databases used last are listed at the top.   
     
   ![](../Pictures/Gui/ALL/arrow.png) When a new database that is not yet contained in the list is opened / generated , the lowest database may be removed from the list.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The list can be emptied with the exception of the database currently being used via the popup menu item Delete entries.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The database is entered in the settings as project management database.

# Tab Items (Copper Export DXF)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Machining > Copper export DXF. Select the Items tab.
- Utilities > Manufacturing data > Machining > Copper DXF. Click [...] next to the Machine field. Select the Items tab.

Use this tab to specify [settings](Glossary_o_einstellungen.htm) for visibility and [layers](Glossary_o_ebenen.htm) as well as colors of item silhouettes and exported bending information.

Overview of the main dialog elements:

Group box Format for item silhouettes

Generate item silhouettes:

Silhouettes of 3D [items](Glossary_o_bauteile.htm) display their spatial limitation in addition to the basic [outlines](Glossary_o_konturen.htm) and extrusion paths. If the check box is activated, item silhouettes will be generated in the [DXF](Glossary_o_dxf.htm) file. In the DXF file, they can be output on separate layers and be assigned colors.

If the check box is deselected, no item silhouettes are generated. This reduces the data volume.

Layer:

Default name of the layer where the item silhouettes are stored in the DXF file.

Color:

Default color that is assigned to the item silhouettes in the DXF file.

Group box Format for bending information

Export bending lines:

If the check box is activated, the bending [lines](Glossary_o_leitungen.htm) will be generated from the [unfold](Glossary_o_abwicklung.htm) in the DXF file.

Layer:

Default name for the layer on which bending lines are stored in the DXF file.

Color:

Default color given to the bending lines in the DXF file.

Export bending extents:

If the check box is activated, the bending extents will be generated from the unfold in the DXF file.

Layer:

Default name for the layer on which bending extents are stored in the DXF file.

Color:

Default color given to the bending extents in the DXF file.

Export bending notes:

If the check box is activated, the bending notes will be generated as text from the unfold in the DXF file.

Layer:

Default name for the layer on which bending notes are stored in the DXF file.

Color:

Default color given to the bending notes in the DXF file.

# Reading Imported PDF Comments in EPLAN

You can import an EPLAN project, which you have issued as a PDF file and which has been commented in Acrobat Reader 8.0, into an EPLAN project and read the PDF [comments](Glossary_o_kommentare.htm) in EPLAN. When importing, the associated EPLAN project must be located in the same directory as when the PDF file was generated.

Preconditions:

- You are a [Project editor](redlining_k_projektkommentator.htm#Projektbearbeiter).
- [Output pages as PDF files](pdfexportgui_h_seitenexportieren.htm)
- [Send PDF file for checking](redlining_h_permailversenden.htm) or [Release PDF file for commenting](redlining_h_freigabe.htm)
- You have received a PDF file containing PDF comments from a project redliner.
- [Combine the PDF comments in the PDF files](redlining_h_zusammenfuehren.htm)
- [Import the PDF comments into the EPLAN project](redlining_h_pdfkommentareeinlesen.htm)

1. Project > Open
2. Select the project containing the imported PDF comments and click [OK].
3. Select the menu item Page > Comments navigator.
4. Select a comment.
5. Select Popup menu > Go to (graphic).  
     
   ![](../Pictures/Gui/ALL/arrow.png) EPLAN opens the related schematic page in the graphical editor and positions the cursor on the comment.

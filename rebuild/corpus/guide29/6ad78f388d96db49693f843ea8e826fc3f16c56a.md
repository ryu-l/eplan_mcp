# Changing the Rotation Angle when Inserting 3D Macros

When you insert a 3D macro, you can rotate the angle of the macro in 90° increments at the handle. Up to 40 different mounting positions can be implemented with a single 3D macro by changing the handles. These options also apply to [devices](Glossary_o_betriebsmittel.htm) whose parts have been assigned a 3D macro.

Preconditions:

- You have opened a project.
- The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open.

1. Select the Insert > Window macro / symbol macro menu [items](Glossary_o_bauteile.htm), and open a 3D macro for placement.
2. Select the Options > Change rotation angle menu items.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The position of the 3D macro will be rotated by 90° counter-clockwise.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Each time the Options > Change rotation angle menu items are selected, the macro is rotated a further 90°.
3. Click [A] to change the handle.
4. At the changed handle, select the Options > Change rotation angle menu items again.  
     
   ![](../Pictures/Gui/ALL/arrow.png) You can set four different rotation angles at each available handle. This means that with nine default handles and one [user-defined](Glossary_o_benutzerdefiniert.htm) handle, as many as 40 possible positions can be implemented.

![](../Pictures/Gui/ALL/info.png)Tip:

You can also use the [Ctrl] + [Shift] + [R] shortcut key to change the rotation angle while inserting.

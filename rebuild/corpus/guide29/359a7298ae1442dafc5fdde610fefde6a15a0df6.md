# Tab Part placement (3D)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open. The layout space contains [part placements](Glossary_o_artikelplatzierungen.htm) (3D). You have double-clicked a [part](Glossary_o_artikel.htm) placement or selected the menu [items](Glossary_o_bauteile.htm) Edit > Properties. In the Properties <components>: Part placement (3D) dialog, select the Part placement tab.

In this dialog you specify the [properties](Glossary_o_eigenschaften.htm) for the item placed on the mounting panel.

Overview of the main dialog elements:

Displayed DT:

The displayed DT is displayed in the graphical editor on the [component](Glossary_o_schaltzeichen.htm). If you have defined in the project [settings](Glossary_o_einstellungen.htm) that [devices](Glossary_o_betriebsmittel.htm) are to be automatically numbered when [symbols](Glossary_o_symbole.htm) are inserted, then a DT is automatically suggested here. You can accept this DT or overwrite it manually.

In addition you can use the [popup menu or the [...] button](devicetaggui_r_feldsichtbaresbmk.htm) to [create](Glossary_o_erstellen.htm) or select a DT.

Full DT:

This field displays the full DT (i.e. structure identifier of the current environment + displayed DT) of the component / item. Use the [...] button to open the Full DT dialog. You can edit the [structure identifiers](Glossary_o_strukturkennzeichen.htm) there and select, e.g., another [mounting location](Glossary_o_einbauort.htm).

Designation:

The designation already assigned to terminals is displayed here and can be changed. This field has no significance for all other [functions](Glossary_o_funktionen.htm).

Function definition:

The function definition of the part placement displayed here is automatically assigned, depending on the function definition of the associated item. Click [...] to open the Function definitions dialog and select a different function definition if required.

Item:

Product group within the generic product group Mechanics in parts management which is especially assigned to the function definition of mechanics items.

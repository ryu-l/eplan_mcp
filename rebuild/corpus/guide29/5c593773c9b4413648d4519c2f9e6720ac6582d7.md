# Dialog Rights management: Groups

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Rights management > Groups

In this dialog you can [create](Glossary_o_erstellen.htm) [user groups](Glossary_o_benutzergruppen.htm) and assign editing rights to them.

Overview of the main dialog elements:

If you have selected the Groups folder in the field on the left then a list of all existing user groups is displayed in the field on the right.

The following predefined user groups are delivered with EPLAN:

| User group | Rights |
| --- | --- |
| Administrators | Have all rights. This user group can't be edited or deleted. |
| Guests | Have restricted permission to work with the program. This user group can't be edited or deleted. |
| Master data [editors](Glossary_o_editoren.htm) | May edit [master data](Glossary_o_stammdaten.htm) such as [symbols](Glossary_o_symbole.htm), [forms](Glossary_o_formulare.htm), etc. This user group can be edited or deleted, i.e., it serves as an sample user group. |
| Schematic editors | Have full rights except for editing master data. This user group can be edited or deleted - an example user group. |

![](../Pictures/Gui/ALL/warning.png)Warning:

The names of the user groups supplied will be translated when using another [dialog language](Glossary_o_dialogsprache.htm). Do not change the names of these user groups since otherwise translatability is lost. Names that have been changed once will not be translated again even if you restore the original designation.

The following dialog elements are available for one individual group:

Rights:

If you have opened the Groups folder in the left field and selected a single user group, then a list of the possible rights is displayed in this field. The rights are divided into editing rights for menu [items](Glossary_o_bauteile.htm), dialogs, and API [actions](Glossary_o_aktionen.htm). The rights for dialogs are identified by the additional symbol "[dialog]"; rights for API actions are identified by the additional symbol "[interface]". An icon in front of each entry indicates whether the group members have the right or rights below the topic area.

| Icon | Meaning |
| --- | --- |
|  | In front of an individual right: The right is assigned. In front of a topic area: All rights below the topic area are assigned. |
|  | In front of a topic area: The rights below the topic area are only assigned partially. |
|  | In front of an individual right: The right is not assigned. In front of a topic area: All rights below the topic area are not assigned. |
|  | For write-protected user groups. In front of an individual right: The right is assigned. In front of a topic area: All rights below the topic area are assigned. |
|  | For write-protected user groups. In front of a topic area: The rights below the topic area are only assigned partially. |
|  | For write-protected user groups. In front of an individual right: The right is not assigned. In front of a topic area: All rights below the topic area are not assigned. |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Below the "Page management" topic area, the "Copy from / to", "New page" and "Number pages" rights enable you to access the menu items of the same name, which are located in the Page menu, and to carry out the corresponding actions. The "Edit page [properties](Glossary_o_eigenschaften.htm)" right enables you to access the Page properties dialog by double clicking the page in the page navigator or via Edit > Properties, and to edit the page properties in this dialog.

The "Page navigator [dialog]" right enables you to access the Pages - <Project name> dialog and edit data in it.

The "Edit page properties [interface]" right enables you to edit page properties via the application programming interface.

If certain editing rights are revoked from a user group, the associated menu items will be grayed out. If a dialog is blocked for a particular user group, the group members can open the dialog but cannot edit any data or documents. The [settings dialogs](Glossary_o_einstellungsdialoge.htm) are an exception: These are hidden if they are blocked for a user group.

If a user group does not have the right for a certain API action, the group members cannot use the associated command in the command line when editing.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You have revoked all page management rights from a user group, including the "Page navigator (dialog)" right. A user belonging to this group can still page through the page navigator and project pages. But the user can no longer make any changes (e.g. numbering or deletions). The corresponding menu items (e.g. Number) are hidden. Only menu items that are used in other locations (such as Copy or Delete) are still displayed. If the user calls up these actions, a message is displayed that the editing is not possible due to [settings](Glossary_o_einstellungen.htm) in [rights management](Glossary_o_rechteverwaltung.htm).

![](../Pictures/Gui/ALL/note.png)Note:

If you have added rights for a user group, the relevant [icons](Glossary_o_icons.htm) are not shown on the [toolbars](Glossary_o_symbolleisten.htm) until you have reloaded the workspace using View > Workspace. The corresponding menu items are not updated until the program has been restarted.

Group members:

If you have selected a user group in the left-hand side of the dialog, then all users who are members of this group are displayed here. The user name and associated description text for each user are displayed.

# Dialog Align and format connection designations

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have selected a connection in the graphical editor, or in the Connections - <Project name> navigator dialog. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog. Project data > Connections > Numbering > Realign and reformat.

In this dialog you reset the original positions of any [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) that had already been set but were later moved / reformatted. In addition to this, the original formatting specified in the [settings](Glossary_o_einstellungen.htm) for [connection numbering](Glossary_o_verbindungsnummerierung.htm) will be restored.

Once you have called up the menu item, the [connections](Glossary_o_verbindungen.htm) are first automatically newly generated.

Overview of the main dialog elements:

Settings:

Select a scheme defining the settings for the connection numbering from the drop-down list. Click [...] to open the [Settings: Connection numbering](wirenumberinggui_d_verbnumeinstellungen.htm) dialog. Define the numbering settings here and store them in a scheme.

Connection definition points:

In this group box you specify which connection definition points should be realigned and formatted:

- All: All connection definition points will be realigned and formatted regardless of the data they can possess.
- With only the connection designation allowed: Those connection definition points that can only possess a connection designation (and no other data) will be realigned and formatted.
- With a connection designation allowed: Those connection definition points that can possess either all data or only one connection designation (and no other data) will be realigned and formatted. Connection definition points that cannot possess a connection designation will not be taken into consideration.

![](../Pictures/Gui/ALL/note.png) Note:

The setting in the Valid data field on a connection definition point decides the type of data that can be specified on the connection definition point: "All data", "Only connection designation", or "No connection designation".

Retain 'manually set' numberings:

If this check box is selected, connection definition points whose connections have the Manually set setting will keep their alignment and formatting.

# P026062: The multi-line connection was not routed

### Cause

Either a multi-line connection does not have an associated routing connection, meaning that either it has not yet been routed or the Layout space: Routing track property of a routing connection is empty- This means that it is regard as "not routed".

### Solution

1. Route the [connections](Glossary_o_verbindungen.htm) again.
2. Then start a new check run.

# Dialog Settings: STEP export / VRML export

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > User > Interfaces > STEP export / VRML export.

In this dialog you define the [settings](Glossary_o_einstellungen.htm) for exporting STEP or VRML files and save them as a scheme. The [schemes](Glossary_o_schemata.htm) for STEP / VRML file export are saved in a [user-specific](Glossary_o_benutzerbezogen.htm) manner. You can copy and edit an existing scheme or [create](Glossary_o_erstellen.htm) a new scheme.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

---

Group box Export medium

Set the export medium for the export in this group box:

- Storage medium: If this option is selected, the STEP / VRML file is output to a storage medium. Each [layout space](Glossary_o_bauraum.htm) is saved as a separate STEP file.  
  Enter the storage location in the Output directory field. You can specify any drive and subdirectory as the target for the export.  
   Click [...] to open the Select directory dialog and then navigate to the desired directory, or create a new one.  
  You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).
- E-mail: If this option is selected, the STEP / VRML file is sent as an e-mail. Once the function has been called up, the file is zipped using the internal zip program and your installed e-mail editor is started.  
   Select the maximum size of an individual mail file from the Split size drop-down list. The possible values are 1 MB to 10 MB in 1 MB increments, or you can select "Unlimited". EPLAN automatically generates the number of mail files required to send the whole project. All individual mails in the group will have this text in the subject line: "<File name> n/m". "n" is the number of the individual e-mail file and "m" is the overall quantity of the files.

Generate file names:

When it comes to the file name settings, you have the following options:

- From consecutive number
- From layout space name
- From [properties](Glossary_o_eigenschaften.htm).

In the properties, you can access layout space properties, [project properties](Glossary_o_projekteigenschaften.htm), and separators.

Format version: (STEP)

The following options are available for format versions:

- STEP AP 203
- STEP AP 214, CD version
- STEP AP 214, DIS version
- STEP AP 214, IS version.

Only external representation of the enclosure: (STEP)

If this check box is activated (default setting), an enclosure is exported with all [items](Glossary_o_bauteile.htm) that can be seen from the outside when the enclosure is closed. This also applies to a freely placed mounting panel that is not [part](Glossary_o_artikel.htm) of an enclosure.

All [part placements](Glossary_o_artikelplatzierungen.htm) are exported with the items arranged below that in the hierarchy are one step below the enclosure or the mounting panel.

Separate export per enclosure: (STEP)

If this check box is activated (default setting), a separate STEP file is generated for each enclosure and for each detached mounting panel. If you want to use the From layout space name setting to [generate](Glossary_o_erzeugen.htm) the file name, the name of the enclosure is added to the file name.

Export auxiliary elements: (STEP)

If this check box is not activated (default setting), the following auxiliary elements are not exported:

- Routing paths
- Routing ranges
- Wiring [cut-outs](Glossary_o_durchbrueche.htm)
- Restricted drilling areas
- Restricted [placing](Glossary_o_auflegen.htm) areas
- Cut-outs.

Export routing connections: (STEP)

If this check box is activated, the [routing connections](Glossary_o_verlegeverbindungen.htm) existing in the layout space are also exported in STEP format. After the import of the resulting STEP file into an external CAD program, the routing [connections](Glossary_o_verbindungen.htm) can be displayed there.

---

Group box Simplified representation (STEP)

In this group box you specify whether items - similar to the representation in the layout space - will be exported in a simplified manner:

- Terminal strips (block definition): If this check box is activated (default setting), the terminal strips will be exported as a simplified block.
- 3D macros: If this check box is activated (default setting), the graphical [macros](Glossary_o_makros.htm), rails, and [wire ducts](Glossary_o_verdrahtungskanaele.htm) are simplified into a cuboid.

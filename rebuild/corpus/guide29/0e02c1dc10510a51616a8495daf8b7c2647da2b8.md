# P021003: Placeholder object contains invalid object references

### Cause

A [component](Glossary_o_schaltzeichen.htm) was deleted in the schematic which is [part](Glossary_o_artikel.htm) of a placeholder object.

### Solution

#### Possibility 1

Double-click the placeholder object and close the Placeholder Objectdialog that appears by clicking [OK] or [Cancel]. The object references are then updated.

#### Possibility 2

Undo the deletion or add the delete object again.

Then start a new check run.

# Tab Connected structures

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have inserted a structure routing point in the graphical editor or generated one in the [topology](Glossary_o_topologie.htm) navigator. In the Properties <...> dialog, select the Connected structures tab.
- You have marked a structure routing point in the graphical editor or in the topology navigator. Edit > Properties. Select the Connected structures tab.

In this tab you specify a filter that is used during the automatic generation of topology [functions](Glossary_o_funktionen.htm). The filter acts on the current [structure routing points](Glossary_o_strukturverlegepunkte.htm) as well as on those connected to it. For the generation of the topology functions a search is carried out in the multi-line or single-line schematic for those functions that correspond to the identification structure of the marked structure routing point or of the structure [routing points](Glossary_o_verlegepunkte.htm) connected to it and that additionally fulfill the specified filter criteria.

Overview of the main dialog elements:

Selection criteria:

In this table you specify filter criteria. The individual [lines](Glossary_o_leitungen.htm) are AND-combined by default.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You have inserted three structure routing points on a topology page and have assigned the device tags =A1+O1-U1, =A1+O2-U2 and =A1+O3-U3 to them. The corresponding [structure boxes](Glossary_o_strukturkaesten.htm) with the same name, which contain different [devices](Glossary_o_betriebsmittel.htm), exist in the multi-line schematic for these DTs. The three structure routing points are interconnected by means of [routing paths](Glossary_o_strecken.htm).

Now you wish to [route](Glossary_o_verlegen.htm) [connections](Glossary_o_verbindungen.htm) only between the identification structures =A1+O1-U1 and =A1+O2-U2. To do so, open the [property dialog](Glossary_o_eigenschaftendialog.htm) for the structure routing point =A1+O1-U1 and specify a filter for the topology functions to be generated automatically. In this example select the criterion Mounting location with the operator "=" and the value O2.

| Active | Negated | Criterion | Operator | Value |
| --- | --- | --- | --- | --- |
|  |  | Mounting location | = | O2 |

When you subsequently use the menu [items](Glossary_o_bauteile.htm) Project data > Topology > Generate topology functions > Automatic to automatically [generate](Glossary_o_erzeugen.htm) the topology functions and then route the connections, [routing connections](Glossary_o_verlegeverbindungen.htm) only arise between the identification structures =A1+O1-U1 and =A1+O2-U2. Without the filter routing connections would also be generated between the identification structures =A1+O1-U1 and =A1+O3-U3 and between =A1+O2-U2 and =A1+O3-U3.

# Automated Processing of Projects

The "Automated processing" functionality allows you automate certain areas of project processing using a [user-specific](Glossary_o_benutzerbezogen.htm) script.

- EPLAN helps you [create](Glossary_o_erstellen.htm) [schemes](Glossary_o_schemata.htm) with pre-defined [actions](Glossary_o_aktionen.htm). Programming knowledge is not required for this.
- EPLAN generates a script file automatically from the sequence of actions stored in the scheme. By default, the [scripts](Glossary_o_scripte.htm) are saved in the directory <Program drive>:\<Program directory>\Scripts\<Company code.
- You can automatically process one or multiple [projects](Glossary_o_projekte.htm).

# P026079: Export Rittal - Athex:  <x>

### Cause

During the export of mounting rail data for the "Rittal - Athex" terminal strip assembly machine, an impermissible setting and / or an impermissible state has been determined.

This setting and / or state is identified by the placeholder <x> in the message. The following placeholder is output:

- Mounting rail not exported due to overlength.  
    
  In this case, an attempt was made to export a mounting rail whose length exceeds the maximum rail length defined in the company-specific [settings](Glossary_o_einstellungen.htm) for the Athex terminal strip assembly machine.

### Solution

Shorten mounting rail

1. Select the Options > Settings > Company > Automatic equipment > Rittal - Athex menu [items](Glossary_o_bauteile.htm), and first determine the maximum mounting rail length that has been defined for the terminal strip assembly machine.
2. For this purpose bring the Machine tab in the Settings: Rittal -Athex dialog to the front, and remember the value stored in the Maximum rail length field.
3. Switch to the User > Graphical editing > input box settings section and select the Always show input box (3D) check box in the dialog Settings: Input box in order to modify the length of the mounting rail via the input box.
4. Close the Settings: Input box dialog by clicking [OK].
5. Locate the mounting rail in the [layout space](Glossary_o_bauraum.htm) using the Go to (graphic) function from the popup menu in the Message management dialog.
6. Double-click to bring up the Properties <...> dialog of the mounting rail, bring the Part tab to the front and remember the value entered in the Subset / length field of the [part](Glossary_o_artikel.htm) reference data.
7. Close the Properties <...> dialog of the mounting rail using [Cancel].
8. Select the Edit > Graphic > Change length menu item, and briefly click the required end of the mounting rail in the layout space that you wish to shorten.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A red handle appears on the cursor at the selected end of the mounting rail.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The previously enabled input box is displayed below the handle.
9. Shorten the mounting rail by using the mouse to move the handle in the direction of the other end of the mounting rail. In the process, watch the value displayed in the input box.
10. Left-click once the value in the input box matches the value of the company-specific setting for the Athex terminal strip assembly machine (or is smaller than it).
11. End the length changing of the mounting rail by way of the Cancel action popup menu item.
12. Then start a new check run, and export the mounting rail data again.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

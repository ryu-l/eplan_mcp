# EPLAN Fluid: Generation of Interruption Points to DIN ISO 1219-2

If the fluid schematic consists of more than one page and if fluid [symbols](Glossary_o_symbole.htm) on different pages are connected with each other, the standard DIN ISO 1219-2 specifies that a reference has to be declared at the [interruption points](Glossary_o_abbruchstellen.htm) of the [connections](Glossary_o_verbindungen.htm) ([lines](Glossary_o_leitungen.htm)). The reference declaration has to be the same on both sides, it has to contain a hyphen as the [separator](Glossary_o_trennzeichen.htm), and it must state the number of the page on which the connection (line) is continued. The type of schematic (pneumatic, hydraulic, etc.) with specification of the schematic path can optionally be added to the connection reference.

Such interruption points corresponding to the standard can be created automatically in EPLAN Fluid on [fluid power](Glossary_o_fluidtechnik.htm) schematic pages during the inserting and cutting of schematic [objects](Glossary_o_objekte.htm). Prerequisite for this is that you have selected the FL\_1219-2\_tpl001 project template for the project and that you have activated the so-called [Smart connect](connectionbrowsergui_h_smartconnecting.htm) (menu [items](Glossary_o_bauteile.htm) Options > Smart connect).

The following data are then displayed in a rectangular text box:

- Displayed DT of the interruption point
- Separator
- Identifier for the trade of the schematic page on which the counterpiece of the interruption point is placed
- Page name (number) on which the counterpiece of the interruption point is placed
- Separator
- Designation or number of the line on the schematic page on which the counterpiece of the interruption point is placed
- Separator
- Number of the column on the schematic page on which the counterpiece of the interruption point is placed.

The last two data refer to the positions of the interruption points that are cross-referenced with each other on the respective schematic page. For example the interruption point 001-P4-B/2 located on the schematic page 3, in row A and in column 4 (see upper schematic section) points to its counterpart 001-P3-A/4 that is placed on page 4 in row B and in column 2 (see lower schematic section). Vice versa the counterpiece points to the interruption point in row A and in column 4 on page 3.

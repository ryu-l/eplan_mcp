# Tab Properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have marked a [part](Glossary_o_artikel.htm) in the tree or list.

In this tab the product-group-specific [properties](Glossary_o_eigenschaften.htm) are displayed in a table and can be edited by you depending on the product group selected for a part.

Overview of the main dialog elements:

Table:

The table as a tree structure where the usually uppermost nodes correspond to the [designations](Glossary_o_bezeichnungen.htm) of the previous tabs that were available until Version 2.6. During the first start of the parts management all the nodes are folded open by default. If you change this, for example by collapsing the Creation / Modification data node, this setting applies for all the parts, irrespective of the product group.

![](../Pictures/Gui/ALL/info.png)Tip:

Properties with a gray background indicate that something is wrong with the corresponding part. If you have, for example assigned the Plugs: Pin type property to a relay (by temporarily changing the product group), the dark-gray color indicates that a property was assigned here that is not provided for the corresponding product group. Such properties can be removed from the table by using the Delete popup menu item. This popup menu item is only available at properties with a dark gray background.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Go to | Only available for properties that reference a different part (for example the property Part number of busbar support for parts of the "Busbars" product group). Jumps directly to the specified part within the parts management. |

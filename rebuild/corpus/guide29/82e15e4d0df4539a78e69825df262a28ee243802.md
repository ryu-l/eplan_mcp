# Managing Terminal Strips

Terminal strips are managed via the terminal strip definition. The terminal strip definition identifies the terminal strip and contains all the relevant data for the terminal strip as well as the terminal strip [part](Glossary_o_artikel.htm) information.

To copy a terminal strip definition it must be placed on a page. You can also [create](Glossary_o_erstellen.htm) a terminal strip definition as an unplaced function. Use the "normal" DT numbering to number terminal strips.

### Reports

For each terminal strip you can specify a [form](Glossary_o_verlauf.htm) in the terminal strip definition that will be used when outputting this terminal strip in terminal diagrams and terminal [connection diagrams](Glossary_o_anschlussplaene.htm). Individual terminal strips can be hidden when outputting terminal plans.

### Terminal strip structure

The terminal parts of the terminals lined up on the terminal strip can be stored at the individual terminals. To do this, the terminals in question must have been defined as [main terminals](Glossary_o_hauptklemmen.htm). In this case, the terminal strip is divided into "independent areas", with each main terminal defining an independent area.

You specify [device definitions](Glossary_o_geraetedefinitionen.htm), i.e the structure of the individual terminals, in parts management. To do this, enter the [function templates](Glossary_o_funktionsschablonen.htm) for the main terminal and the auxiliary terminals at the terminal parts. The function template for the main terminal should be at the top.

#### Terminal strip structure as in previous versions

If the entire terminal strip is defined via the terminal strip definition alone - as in the versions before EPLAN 2.0 - the terminal strip must consist of just one independent area. The terminal strip structure is then defined via a device definition which is saved in the terminal strip definition.

![](../Pictures/Gui/ALL/note.png)Note:

This procedure is only supported by the program for compatibility reasons. We recommend that parts should be managed at the main terminals.

However, a terminal strip structure by means of a device definition can only be defined if the terminal strip does not contain any main terminals or the property Do not use main terminals has been selected for the terminal strip.

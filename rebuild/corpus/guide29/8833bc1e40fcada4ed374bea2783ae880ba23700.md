# Dialog Assignment VDMA 66413

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have opened a parts database using [Extras] > Settings. [Extras] > Import. In the File type field, select the entry "VDMA 66413", and click the [...] button next to it.

Use this dialog to specify the identifying property in the XML file that corresponds to the unique [part](Glossary_o_artikel.htm) property in your parts database.

The following dialog elements are available:

VDMA property:

Choose the desired identifying property from the drop-down list:

- Identifier: Manufacturer-specific, unique identifier for a device
- PartNumber: Manufacturer-specific part or order number.

Part property:

From the drop-down list, choose the EPLAN property (Part number, ERP number, Order number, etc.) that corresponds to this VDMA property. If the assignment is unique, the data with the [safety-related values](Glossary_o_sicherheitskennwerte.htm) will be carried over.

![](../Pictures/Gui/ALL/note.png)Note:

If, during the import of parts data with the "VDMA 66413" file type, an assignment to the EPLAN property Part number occurs, then it is also possible to [create](Glossary_o_erstellen.htm) new parts during such an import. This requires that you select for this import the Update existing records and add new ones option. However, if you want to add to existing parts, select in the Import dialog the Update existing records only option.

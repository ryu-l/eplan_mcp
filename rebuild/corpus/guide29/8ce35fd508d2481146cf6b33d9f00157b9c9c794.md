# Creating an Export / Labeling Scheme

Export / labeling [schemes](Glossary_o_schemata.htm) / External report schemes allow the [format elements](Glossary_o_formatelemente.htm) and [settings](Glossary_o_einstellungen.htm) for manufacturing data report / labeling or external [reports](Glossary_o_auswertungen.htm) to be stored and re-used. This allows you to repeatedly output data using the same settings.

Precondition:

You have opened a project.

1. Utilities > Manufacturing data > Export / labeling
2. Click [...] next to the Settings field in the dialog Export manufacturing data / output labeling.
3. In the dialog Settings: Manufacturing data export / labeling click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
4. In the Report type dialog select a report type and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The report type specifies the group of similar information to be reported in the export / labeling file / external report file.
5. Enter a name and description in the dialog New scheme and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The report type that you select here is displayed in the Report type field in the dialog Settings: Manufacturing data export / labeling.  
     
   ![](../Pictures/Gui/ALL/arrow.png) You can now [Specify settings for \*.txt output](labelgui_h_textausgabe.htm) or [Specify settings for Excel output](labelgui_h_exceldatei.htm).

# Tab Function properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Project > Publish. Click [...] in the Scheme field of the Publish dialog. Select the Function properties tab.
- Options > Settings > User > Interfaces > Publish. Select the Function properties tab.

On the Function properties tab, you can view and add to, but not change, the [properties](Glossary_o_eigenschaften.htm) of the [functions](Glossary_o_funktionen.htm) of a project to be exported.

Overview of the main dialog elements:

Property name:

The function properties to be exported of the selected project are displayed in this column.

[Toolbar](edaexportgui_r_eigenschaften.htm#Symbolleiste):

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

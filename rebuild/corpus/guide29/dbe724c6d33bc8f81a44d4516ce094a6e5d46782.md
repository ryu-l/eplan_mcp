### Transfer back

User interface / operation

During project editing, once a form, plot frame, etc. is selected, opened, or created, which has not yet been used in the project, it is stored locally; that is, a copy is created in the project which is accessed during further work. Master data is also stored on a project-related basis and can be synchronized with the master data pool when opening, backing up, or restoring the project, independently of project settings. If certain master data needed for project editing is not present in the master data pool, it can be found using the option "Complete project", and automatically stored locally if necessary. If missing master data can't be found in the master data pool, a message is displayed.

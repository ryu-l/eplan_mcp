# Dialog Edit revision marker

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have generated a revision and have opened a revision project (file extension \*.ell). You have selected a changed object. Popup menu > Edit revision marker.

In this dialog you define the [settings](Glossary_o_einstellungen.htm) for automatically created revision marker text or you can manually change this.

The following dialog elements are available:

Marker text format:

The format defined for automatic marker text is shown in this field. This is composed of a number of different [properties](Glossary_o_eigenschaften.htm), such as, for example, revision name, editor, and modification date. Use [...] to open the Format dialog, where you can determine the properties and their formatting.

Marker text:

The automatically generated marker text is displayed in this field, i.e., the values of the properties defined above. You can manually overwrite or enhance this text.

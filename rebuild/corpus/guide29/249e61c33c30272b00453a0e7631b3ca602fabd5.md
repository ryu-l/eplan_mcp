# Plant Overviews

Plant overviews are created on pages of type "Schematic single-line". Plant overviews are used to show structured overview plans of an installation with all [structure identifiers](Glossary_o_strukturkennzeichen.htm) and matching [cable connections](Glossary_o_kabelverbindungen.htm). You can define the structure identifiers using [structure boxes](Glossary_o_strukturkaesten.htm) and connect them with [cable definition lines](Glossary_o_kabeldefinitionslinien.htm).

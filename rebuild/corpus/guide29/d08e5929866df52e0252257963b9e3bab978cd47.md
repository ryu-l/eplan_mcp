# Activating the Properties (Global) Mode

The Properties (global) editing mode allows global editing of the common [properties](Glossary_o_eigenschaften.htm) of distributed [functions](Glossary_o_funktionen.htm) in a single step.

Precondition:

You have opened a project.

1. Select the Options menu.
2. Select the Properties (global) menu item.  
      
   ![](../Pictures/Gui/ALL/arrow.png) A check mark is displayed in front of the menu item. When you double-click a function, then the properties of the function are automatically opened in the Properties (global): <...> dialog.  
      
   ![](../Pictures/Gui/ALL/arrow.png) [Globally editing the properties for all representations of a main function](reverseengineering_h_alledarstellungenbm.htm)  
      
   ![](../Pictures/Gui/ALL/arrow.png) [Globally editing the properties for all representations of an auxiliary function](reverseengineering_h_alledarstellungenfunktion.htm)  
      
   ![](../Pictures/Gui/ALL/arrow.png) [Globally changing the DT at functions](devicetaggui_h_bmkaendern.htm)

![](../Pictures/Gui/ALL/info.png)Tip:

If the Properties (global) editing mode is selected in the Options menu then you can still edit the properties of distributed functions independently from each other. Select a function and select Popup menu > Properties.

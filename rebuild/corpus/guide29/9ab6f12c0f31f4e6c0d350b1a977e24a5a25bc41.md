# P004020: More than one I/O connection point at a channel

### Cause

More than one I/O connection point was defined within a channel. The I/O [connections](Glossary_o_verbindungen.htm) now have the same channel name.

### Solution

1. Assign just one I/O connection to each channel.
2. In addition enter a unique channel designation for each I/O connection point in the Properties <...> dialog.
3. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Notes:

- The usage of several I/O [connection points](Glossary_o_anschluesse.htm) within a channel is permissible if only one of these was defined as an activated connection point. All the other I/O connection points within the channel must be marked as deactivated connection points by assigning the property Deactivated I/O connection point to them.
- Please use the [P004097](messages_p_004097.htm) check run, if you use [PLC cards](Glossary_o_sps_karten.htm) at which an input and an output are assigned to the same channel.

# Data Transfer of EPLAN PPE Projects: Device Groups

During data importing from PPE [projects](Glossary_o_projekte.htm) the following segment definitions are automatically created from the device groups of the PCT loop elements:

- Sensor
- Actuator
- Pick-ups
- Converter
- Function device
- Switching device
- Evaluation / signal device
- Automatization
- Software function
- Protection device
- Heating / light
- Other [devices](Glossary_o_betriebsmittel.htm)
- Apparatus
- Control valve
- Machine.

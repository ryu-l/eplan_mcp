# P501026: The bus port '<x>' entered in the function templates of the part was not found in single-line representation in the macro '<y>'

### Cause

In the parts database to be checked, a [part](Glossary_o_artikel.htm) was found at which a function template of a bus port is defined. In the associated macro that is stored in the Technical data tab of the parts management, different values are entered with regard to one or more of the [properties](Glossary_o_eigenschaften.htm) listed below:

- Bus interface: Name
- Bus system
- Function definition
- Plug designation.

### Solution

#### Possibility 1

1. Move the value of the determined property from the function template of the part to the property of the same name of the reported macro.
2. Save the change in the macro.
3. Then start a new check run.

#### Possibility 2

1. Move the value of the determined property from the macro to the part.
2. Save the change in the parts management.
3. Then start a new check run.

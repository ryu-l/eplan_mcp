# Connections: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_verbindungen.htm)

### Connections

User interface / operation

A connection is a line that is used to transmit information, electric power, liquids, or air (pressure) from a source to a target. A connection exists between two connection points. There can be multiple connections between two targets (e.g., cross-section doubling).

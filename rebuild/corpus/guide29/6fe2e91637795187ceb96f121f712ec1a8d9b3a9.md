# PDF Comments

PDF [comments](Glossary_o_kommentare.htm) make the redlining process possible. Redlining means that a project editor passes a schematic on to a project redliner. The project redliner checks and comments the schematic. Comments are created in the schematic during this process. The project redliner then returns the commented schematic to the project editor. The editor then revises the schematic based on the comments. PDF comments include:

- Drawn comments
- Comment texts
- Comment responses
- Comment status information

# Creating Configurations for the Tree View

You can configure the structure of the tree view that displays the data in a hierarchical structure to suit your needs. This is done in the [user-specific](Glossary_o_benutzerbezogen.htm) [settings](Glossary_o_einstellungen.htm) that can be accessed from the parts management.

A configuration defines so-called "main nodes" that are displayed as the uppermost hierarchy in the tree structure. All fields in the parts management can be used as structure nodes for grouping purposes. This allows parts data to be prepared to suit different customers and different planning methods.

Precondition:

You have opened the Parts management dialog (Utilities > Parts > Management).

1. [Extras] > Settings
2. Click [...] in the Tree configuration field of the subsequent dialog.
3. In the next dialog, select a scheme from the Scheme drop-down list or [create](Glossary_o_erstellen.htm) a new one.
4. Click the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button next to the Main nodes field in the toolbar.
5. In the Tree configuration - main node dialog, in the Name field, enter the name of the main node as it is to be displayed in the parts management tree view.
6. If necessary, click [...] in the Filter field to define a filter in the subsequent Filter dialog.
7. Click the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button in the toolbar next to the Properties field.
8. Select the desired entry from the Properties list (e.g. "Manufacturer") and click [OK].
9. Repeat these steps to determine further criteria / create additional main nodes.
10. Click [OK] until you have returned to the Parts management dialog.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The tree view is adjusted.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

In the Name field, enter "Cable" for the main node in the Tree configuration - main node. Click [...] in the Filter field and define the filter "Product group" = "Electrical engineering: Cables". Then select the structure [properties](Glossary_o_eigenschaften.htm) "Manufacturer", "Connection cross-section / diameter" and "Number of [connections](Glossary_o_verbindungen.htm)" (in this order). Confirm all dialogs by clicking [OK].   
 The parts management tree view then appears as follows:

| Structure | Meaning |
| --- | --- |
| Cable  RITTAL  10 mm²  4 [conductors](Glossary_o_adern.htm)  RIT.CAB1 4X10RE   5 conductors  RIT.CAB2 1123 (5G10) | Main nodes Subnode "Manufacturer" Subnode "Connection cross-section" Subnode "Number of connections" "Part number" Subnode "Number of connections" "Part number" |

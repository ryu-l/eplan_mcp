# PLC Schematic Generation

EPLAN allows a schematic to be automatically generated from, for example, a PLC configuration. Unplaced PLC [functions](Glossary_o_funktionen.htm) (or those that are unplaced in particular representations) are automatically placed, thus allowing PLC schematics with different overview pages to be generated. The following editing options are available:

- Schematic pages with different [representation types](Glossary_o_darstellungsarten.htm) can be generated.
- The PLC functions allow [macros](Glossary_o_makros.htm) to be automatically assigned (from the [part](Glossary_o_artikel.htm)) or manually assigned.
- Value sets can be selected for variables in the macros contained by [placeholder objects](Glossary_o_platzhalterobjekte.htm), or values can be manually entered.
- Wiring macros allow the [wiring](Glossary_o_verdrahtungen.htm) of the [connection points](Glossary_o_anschluesse.htm) to be displayed.
- The PLC configuration can be created using external [PLC configuration programs](Glossary_o_sps_konfigurationsprogramme.htm) and then importing the data into EPLAN and using them to [generate](Glossary_o_erzeugen.htm) a schematic.
- Objects subsequently entered into the PLC configuration can also be automatically inserted into the schematic. You can generate new pages for the newly added [objects](Glossary_o_objekte.htm), or regenerate a range of pages, or regenerate the entire PLC schematic.
- [PLC addresses](Glossary_o_sps_adressen.htm) can be imported from an assignment list and the device selection can then be used to generate unplaced PLC functions for these addresses. These functions can be automatically placed by the PLC schematic generation.
- The configuration defined in the Generate PLC schematic dialog can be saved, imported, and exported. You can interrupt your schematic planning and resume it at a later date.
- Automatically [placed functions](Glossary_o_platziertefunktionen.htm) generated by the PLC schematic generation can be deleted and placed again.
- The [properties](Glossary_o_eigenschaften.htm) dialog can be called up in the "Global" mode and you can then use this to edit the device properties.

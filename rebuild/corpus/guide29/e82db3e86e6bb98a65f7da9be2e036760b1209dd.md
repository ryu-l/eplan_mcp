# Tab Export

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Project > Publish. Click [...] in the Scheme field of the Publish dialog.
- Options > Settings > User > Interfaces > Publish.

In this tab, specify the [settings](Glossary_o_einstellungen.htm) for the export of a project to the EPDZ format. The EPDZ format can be read by mobile applications on mobile [devices](Glossary_o_betriebsmittel.htm).

Overview of the main dialog elements:

Group box Export medium

Storage medium:

If this export medium is selected, the EPDZ file is output to a storage medium.  
  
The storage location can be entered in the Output directory field.

The [...] button opens the Select directory dialog in order to select any directory of your choice for the export.

E-mail:

If this export medium is selected, the EPDZ file is sent as an e-mail.

![](../Pictures/Gui/ALL/note.png)Note:

Mobile devices cannot read split files. This is why the file cannot be split into several, smaller parts when sending an EPDZ file by e-mail.

Group box Output

Source language:

If this check box is enabled, the texts will be output in the EPDZ file in the source language set for the project to be exported. If the ##\_## (dialog language) option is selected for the source language, the source language automatically becomes the [dialog language](Glossary_o_dialogsprache.htm) currently set in EPLAN.

Alternative language:

If this check box is enabled, you can select the alternative language in which to display the translated texts in the EPDZ file. You can select these from the list of [translation languages](Glossary_o_uebersetzungssprachen.htm) defined for the project. The EPDZ export uses only this language, the displayed language settings are ignored.

Copy externally linked documents to output directory:

Select this check box so that [external documents](Glossary_o_fremddokumente.htm) / linked documents that are neither stored in the project nor contained in the default directory for documents can also be copied to the target directory of the EPDZ file with the output. The following are externally linked documents:

- Pages of the type "External document"
- Hyperlinks that are linked to documents in file [form](Glossary_o_verlauf.htm)
- Links to documents in file form in texts and property values.

If the check box is deactivated, only the internally linked documents are stored in the EPDZ file. All documents which are not stored in the project and are not contained in the default directory for documents are ignored.

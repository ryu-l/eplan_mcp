# Piping Interruptions for the P&I Diagram

Pipings are displayed with interruptions in the [P&I diagram](Glossary_o_ri_fliessbild.htm) in accordance with the standard DIN 28000-4:2014-07 if the piping course overlaps with another symbol (for example [container](Glossary_o_behaelter.htm)) or another piping. To insert such interruptions in the P&I diagram, the PBR connection symbol is now available in the SPECIAL symbol library.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

By means of the new symbol for piping interruptions you can display the interruptions in the P&I diagram.

In the preview in the Symbol selection dialog select the fitting variant of the interruption symbol for a vertical or horizontal piping section. For the desired piping click the positions between which the interruption is to be inserted. The piping is not deleted between these two positions but only graphically interrupted.

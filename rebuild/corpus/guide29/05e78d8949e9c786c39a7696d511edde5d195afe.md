# P004052: Connection to the wrong physical network! '<x>' has to be connected to the physical network '<y>'

### Cause

During the last import of PLC data a connection was found that contradicts the connection currently existing in the project. The faulty connection could be determined.

### Solution

Replace the connection in the project by means of the connection <x> specified in the message and connect it to the physical network <y>.

![](../Pictures/Gui/ALL/note.png)Note:

This module-specific message is generated by the importing of PLC data. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

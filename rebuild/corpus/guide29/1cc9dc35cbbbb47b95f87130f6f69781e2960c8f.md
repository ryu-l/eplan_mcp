# Rotating and Flipping

In EPLAN, you can rotate and flip both graphical elements and [symbols](Glossary_o_symbole.htm) as well as [macros](Glossary_o_makros.htm). Graphical elements can be rotated and flipped by any rotation angle and mirror axis. Symbols and macros, however, can be rotated and flipped only in 90° increments, because these [actions](Glossary_o_aktionen.htm) are based on the exchange of symbol or macro [variants](Glossary_o_varianten.htm).

By rotating and flipping symbols and macros, you can [create](Glossary_o_erstellen.htm) [master data](Glossary_o_stammdaten.htm) and partial schematics easily and quickly.

### Rotate and flipping symbols

When rotating and flipping symbols, there is an internal exchange of [symbol variants](Glossary_o_symbolvarianten.htm). The property arrangement of the placed [property texts](Glossary_o_eigenschaftstexte.htm) (Displayed DT, Cross-references, etc.) is rotated or flipped as well.

This means that symbols can be rotated or flipped only in 90° steps. To ensure that the result of the rotation or flipping meets your expectations, the symbol variants must be set up accordingly in the master data. When you rotate, the variants A to D are taken into account.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

In the following figure, the symbol variant A of a cylinder (symbol 675 / Z\_ZUB\_38 from symbol library HYD2ESS) is rotated in three 90° increments. In this example, the coordinate cross is the point around which the rotation is carried out.

![](../Pictures/Visualisation/ALL/gededitgui_rotatelogicalsymbols_as.png)

When rotating the symbol variant A by 90°, the symbol variant B is used; when rotating by 180°, the symbol variant C and when rotating by 270°, the symbol variant D.

The flipped variants E-H are used for the symbol variants A-D for the purposes of flipping. The variant selected is always the one that is located on the other side of the mirror axis.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

When flipping a cylinder (symbol variant A) across the mirror axis 1, a cylinder is created with the symbol variant E. But if the flipping is done across axis 2, the cylinder will have the symbol variant G.

![](../Pictures/Visualisation/ALL/gededitgui_mirrorlogicalsymbols_as.png)

### Rotate and flip macros

Macros (symbol (\*.ems) or [window macros](Glossary_o_fenstermakros.htm) (\*.ema)) are rotated and flipped on the basis of macro variants. In the process, all [objects](Glossary_o_objekte.htm) within a macro box are identified internally. In the respective action, the logical information (e.g., displayed DT, [connection point designations](Glossary_o_anschlussbezeichnungen.htm), etc.) is preserved; all graphical information (e.g., position of the symbol graphic and property texts as well as the symbol variant) is imported from the respective macro variant.

If a necessary macro variant is not available for the respective macro box, the objects will be transformed (rotated/flipped) on the basis of existing symbols. In such a case (or when other inconsistencies occur), you will receive relevant information in the [system messages](Glossary_o_systemmeldungen.htm).

![](../Pictures/Gui/ALL/note.png)Note:

If macros are to be rotated and flipped only on the basis of symbols, press the [Shift] key when executing the respective action. If you use the shortcut key [Ctrl] + [Shift], the action will be executed on the basis of symbols, while preserving the original macro.

### Transformation point for symbol variants

The base point for rotating and flipping is generally the first connection point of a symbol. In the [symbol editor](Glossary_o_symboleditor.htm) you can define a different base point â the so-called "transformation point" â for a symbol variant.

This will be of interest if, while executing one of these actions, you notice that a symbol variant has been set up inconsistently (e.g., the symbol graphic is [offset](Glossary_o_offset.htm) against the [connection points](Glossary_o_anschluesse.htm)) or if you receive a corresponding system message (e.g., object in the wrong position) for a macro.

To define a transformation point for a symbol variant in the symbol editor, add to the symbol [properties](Glossary_o_eigenschaften.htm) of such variant the Transformation point property ([ID](Glossary_o_id.htm) 16045) via the property selection.

Each symbol variant can have its own transformation point; symbol variants are distinguished via the index. The transformation point is entered as a coordinate, e.g., "2.0/2.0". The entry refers to the insertion point of the respective symbol variant.

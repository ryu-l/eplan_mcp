# Inserting Routing Points (Topology)

Routing points are required to build up a routing path network. For example as a jump-in position for the connection to a target, as a position for a junction to other [routing paths](Glossary_o_strecken.htm) or for connecting routing paths.

Structure [routing points](Glossary_o_verlegepunkte.htm) represent a specific identification structure. Through these special routing points it is possible to [route](Glossary_o_verlegen.htm) [connections](Glossary_o_verbindungen.htm) between different identification structures without the connected [topology](Glossary_o_topologie.htm) [functions](Glossary_o_funktionen.htm) having to be placed.

Precondition:

You have opened a topology page in the graphical editor.

1. Select the menu [items](Glossary_o_bauteile.htm) Insert > Topology > Routing point.
2. Click the graphical editor to place the routing point.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Properties <...> dialog opens (if in the Property dialogs category, the While inserting routing points and routing paths (topology) check box has been activated in the user [settings](Glossary_o_einstellungen.htm) for graphical editing).
3. Enter the data for the routing point in the [Routing point](devicetaggui_r_cablingstrecke.htm) tab.
4. If you want to insert a structure routing point, click [...] next to the Function definition field. Select the "Topology structure routing point" in the subsequent dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The additional tab Connected structures is displayed for [structure routing points](Glossary_o_strukturverlegepunkte.htm). There you can specify a filter that is used during the automatic generation of topology functions.
5. Click [OK].
6. End the action via the Cancel action popup menu item or via the [Esc] button.

![](../Pictures/Gui/ALL/info.png)Tip:

You can use the Generate routing point popup menu item to [generate](Glossary_o_erzeugen.htm) unplaced routing points in the topology navigator.

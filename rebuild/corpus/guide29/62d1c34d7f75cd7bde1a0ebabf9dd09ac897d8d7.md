# P007012: Part '<x>,' variant '<y>' is not stored

### Cause

You placed a device and then manually changed the [part](Glossary_o_artikel.htm) number and / or part variant. The part and / or the part variant are not loaded into the project in this case.

### Solution

In the parts management, [create](Glossary_o_erstellen.htm) a new device with the relevant part number and / or a corresponding part variant. Place the device.

Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

This check run is only carried out correctly if it is applied to the entire project!

### Connection definition points

Electrical engineering

The connection definition point is used to assign properties to one or more connections running below it. The properties specified here have priority over the connection properties predefined for the potential or in the project settings. Using the connection definition point, all of the information that a connection can have can be specified (including the graphical representation of the connection).

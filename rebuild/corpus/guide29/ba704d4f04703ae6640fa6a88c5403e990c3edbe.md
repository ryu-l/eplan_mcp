# P005075: Differing substances within a piping

### Cause

In the [P&I diagram](Glossary_o_ri_fliessbild.htm) there are several piping definitions (piping [connection points](Glossary_o_anschluesse.htm) or piping definition points) which have contradictory values with regard to the Substance property at a connection.

### Solution

1. Locate the respective piping definitions using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the [properties](Glossary_o_eigenschaften.htm) dialog for each piping definition and enter the same value in the Substance field.
3. Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

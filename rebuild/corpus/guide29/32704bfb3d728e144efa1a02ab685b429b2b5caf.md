# P027014: Topology - Routing paths lie over each other

### Cause

Within the [topology](Glossary_o_topologie.htm), [routing paths](Glossary_o_strecken.htm) have been drawn on top of each other in the routing path network. The routing paths on top of each other can be of differing lengths.

### Solution

1. Locate the routing paths on top of each other in the routing path network using the Go to (graphic) and Go to 2nd coordinate [functions](Glossary_o_funktionen.htm) from the popup menu of the Message management dialog.
2. Delete the surplus routing paths.
3. Then start a new check run.

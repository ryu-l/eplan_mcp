# Dialog Structure identifier of layout space

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have generated a [layout space](Glossary_o_bauraum.htm). Click [...] in the Structure identifier field In the Properties (components): Layout space dialog.

In this dialog you can edit the [structure identifiers](Glossary_o_strukturkennzeichen.htm) of the layout space.

Overview of the main dialog elements:

Structure identifier:

The table displays the device structure of the [part placements](Glossary_o_artikelplatzierungen.htm) in the layout space. EPLAN generally adopts the Structure for mechanical [devices](Glossary_o_betriebsmittel.htm) that you have defined in the [project properties](Glossary_o_projekteigenschaften.htm) of the project. Thus, in the fields you see the structure identifiers of the layout space where the [part](Glossary_o_artikel.htm) placement is located.

- Structure: Lists the [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) which correspond to the [project structure](Glossary_o_projektstruktur.htm). The adjacent column displays the associated preceding signs.
- Value / Visible: Without extended reference identification, the Value column is displayed. If you are using extended reference identification, the Visible column is displayed. In this column, the structure identifiers can be edited. Enter a structure identifier in the proper field for this purpose, or click [...] to select a structure identifier already defined in the project using the <Identifier block> (<Project name>) dialog.
- Complete: This column is displayed if you are using extended reference identification. It displays the structure identifier including all superior structure identifiers.

![](../Pictures/Gui/ALL/note.png)Note:

The preceding signs and separators between the individual structure identifiers can not be edited here. They originate from the [settings](Glossary_o_einstellungen.htm) of the Extended project structures dialog, which you open in the Structure tab of the project [properties](Glossary_o_eigenschaften.htm) by clicking [Other].

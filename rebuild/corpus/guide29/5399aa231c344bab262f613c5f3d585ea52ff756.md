# Sending the PDF File for Checking

In order to comment an EPLAN project that you have issued as a PDF file in Acrobat Reader, it must be released for commenting via Acrobat Professional. To do this, you can send the PDF file to a third party via e-mail from within Acrobat. The PDF file is automatically released for commenting.

Preconditions:

- You are a [Project editor](redlining_k_projektkommentator.htm#Projektbearbeiter).
- You have Acrobat Professional 7.0 / Acrobat Standard 7.0 installed and open.
- [Output pages as PDF file](pdfexportgui_h_seitenexportieren.htm)

1. File > Send for review
2. Select the menu item for sending the file via e-mail for reviewing.
3. In the subsequent dialog, select the PDF file containing EPLAN pages and click [Next].
4. Enter the e-mail address of the recipient in the subsequent dialog and then click the button to send the invitation.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The PDF file is sent. The recipient can use Acrobat Reader to [Create PDF comments in the PDF file](redlining_h_pdfkommentare.htm).

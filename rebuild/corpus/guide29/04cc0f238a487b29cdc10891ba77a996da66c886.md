# Tab Machine command

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Wire fabrication > "Machine" > Machine command
- Utilities > Manufacturing data > Wire fabrication > "Machine". Click [...] next to the Scheme field. Select the Machine command tab.

In this tab, you enter the machine-specific commands and assign them to [conductor termination processing](Glossary_o_aderendbehandlung.htm).

Overview of the main dialog elements:

Conductor termination processing:

The values from the Conductor termination processing column are available as values to be selected from the Conductor termination processing tab.

To cross-section:

The To cross-section column allows you to specify the cross-section up to which the instructions entered in the Machine command field are applied.

Machine command:

In this column, you enter the instructions in the language of the respective machine software that are to be executed for the selected conductor termination processing.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example: Komax machine commands](javascript:void(0);)

AEH1-n = TerminalKey (use end sleeve with suitable cross-section)

$strip$ = Stripping

$ultrasonic,xx$ = Ultrasonic welding (xx = length of ultrasonic welding in mm)

Information on machine commands can be obtained from the manufacturers of machines.

Stripping Lengths for Dual Sleeves on Komax Machines

If you use the Komax machine-specific command $strip$, the value from the Stripping length column of the Wires tab is accessed. In the case of dual sleeves you do, however, need other stripping lengths than in the case of single sleeves.

To be able to control the differing [stripping length](Glossary_o_absetzlaenge.htm) for dual sleeves, the $strip$ machine command was extended by the parameters a (stripping length) and b (pull-off length). The format of the machine command to be used is: $strip,a,b$. If the machine command is specified in the $strip,a,b$ manner, the values entered for a and b for stripping length and pull-off length are used; entries on the Wires tab are ignored in this case.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

| Conductor termination processing | To cross-section | Machine command |
| Strip Double | 6.0 | $strip,10,5$ |
| Result:  Stripping length = 10 mm, Pull-off length= 5 mm | | |

If no value has been specified for parameter b ($strip,a$), the pull-off length is calculated on the basis of stripping length/2.

If no value has been specified for parameter a ($strip,,b$), the value for the stripping length is taken from the Stripping length column of the Wires tab.

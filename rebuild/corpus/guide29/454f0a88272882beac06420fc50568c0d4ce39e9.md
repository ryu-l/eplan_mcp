# P028009: Not all functions / representation types of the device reference the same planning object

### Cause

Not all [functions](Glossary_o_funktionen.htm) or [representation types](Glossary_o_darstellungsarten.htm) of a device assigned to a planning object have been placed or assigned from within the pre-planning navigator. Instead, other functions or representation types of the device were inserted as [symbols](Glossary_o_symbole.htm) or [macros](Glossary_o_makros.htm), and they were assigned manually the device tag of the function from the pre-planning.

For example, from the pre-planning navigator you have placed the function template of a contactor coil assigned to a planning object on a multi-line schematic page. However, you have inserted the contacts of the contactor coil in the multi-line schematic as a window macro, named after the device tag of the placed function from the pre-planning.

### Solution

1. Locate the planning object in the pre-planning navigator using the Synchronize selection function offered by the popup menu in the Message management dialog.
2. Select the menu item Update detailed planning from the popup menu of the pre-planning navigator and in the subsequent dialog activate the check box Update device tags and [symbolic addresses](Glossary_o_symbolischeadressen.htm).  
     
   Or alternatively number the [devices](Glossary_o_betriebsmittel.htm) offline. As a result, all functions and representations of the device not yet assigned are assigned.  
     
   Or, in the pre-planning navigator, highlight the planning object, select from the popup menu the Assign menu item, and then click the function not yet assigned.
3. Then start a new check run.

# P004082: Configuration project '<x>' does not contain a CPU

### Cause

The information that a PLC box is a CPU is missing at the PLC box. This information is required for a correct PLC data export from EPLAN.

This check run only checks [PLC boxes](Glossary_o_sps_kaesten.htm) which are [main functions](Glossary_o_hauptfunktionen.htm) and at which a configuration project is entered.

### Solution

1. Locate the PLC box in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the PLC box.
3. Bring the PLC structure data tab to the front.
4. Activate the CPU check box in the [properties](Glossary_o_eigenschaften.htm) list.
5. Ensure that a configuration project and a station [ID](Glossary_o_id.htm) are entered at the PLC box.
6. Click [OK].
7. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

Take into account that a CPU does not have to exist at every workstation. It is sufficient if at least one CPU exists under all workstations that are assigned to a configuration project.

# Master Data: Symbols

This section provides information about the new [symbols](Glossary_o_symbole.htm) that are available to you in the [master data](Glossary_o_stammdaten.htm) as of the current version.

![](../Pictures/Gui/ALL/note.png)Notes:

- The following pages show a number of illustrations of new symbols from different [symbol libraries](Glossary_o_symbolbibliotheken.htm). The illustrations show variant "A" of the respective symbols in multi-line or single-line representation. The name and number of the symbol are shown underneath the symbol.
- Several symbols dispose of the same symbol graphic. These symbols do, however, differ with regard to usage in the [trades](Glossary_o_gewerke.htm), the [function definitions](Glossary_o_funktionsdefinitionen.htm), the symbol [properties](Glossary_o_eigenschaften.htm) and their positions. New symbols that have the same symbol graphic are displayed together.

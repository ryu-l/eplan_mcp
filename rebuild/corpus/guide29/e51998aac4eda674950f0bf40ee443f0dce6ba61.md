# Spare Items: Deletion Modes for Functions

Functions can be deleted in different "user interfaces":

| "User interface" | Deleteable [functions](Glossary_o_funktionen.htm) |
| --- | --- |
| Device navigator | Placed, unplaced |
| Schematic | Placed |
| Compress | Unplaced |

Functions are always completely deleted, but the following cases differ:

- Deletion of placed functions: In a placed function is deleted, then it is completely deleted, i.e. the placement and the function are deleted. If the placed function was a device function, then this remains in the [device definitions](Glossary_o_geraetedefinitionen.htm). All extra data entered for this function is lost on deletion. The deletion of a main function also deletes the device definition (i.e. the device).
- Deletion of unplaced functions: Unplaced functions can only be deleted from the device navigator or when compressing the project. Apart from this, they behave in the same way as [placed functions](Glossary_o_platziertefunktionen.htm).
- Deletion of function templates: Function templates can either be deleted from the device selection or by deleting the main function or the device definition (the type). Deleting a device definition does not affect placed or [unplaced functions](Glossary_o_nicht_platziertefunktionen.htm).  
   If a placed or unplaced function is deleted for which a function template exists, the [function templates](Glossary_o_funktionsschablonen.htm) are not modified, i.e., the function templates are retained.

![](../Pictures/Gui/ALL/note.png)Note:

On deletion of a function that is not contained in the device definition, then the function is deleted with all additional data; the Return mode offers the possibility of removing the [component](Glossary_o_schaltzeichen.htm) from the plan while leaving the data contained in the unplaced function in the database (menu item Edit > Delete placement).

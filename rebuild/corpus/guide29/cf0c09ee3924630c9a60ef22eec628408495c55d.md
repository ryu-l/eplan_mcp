# Creating Symbols

Precondition:

You have opened a project and at least one symbol library.

1. Select the following menu [items](Glossary_o_bauteile.htm): Utilities > Master data > Symbol > New
2. If multiple [symbol libraries](Glossary_o_symbolbibliotheken.htm) are open, select the symbol library in which you would like to [create](Glossary_o_erstellen.htm) the new symbol in the Symbol library selection dialog.
3. Click [OK].
4. In the Create variant dialog select which symbol variant you would like to create.
5. Click [OK].
6. In the Symbol properties - <Library name> dialog specify the data for the symbol to be generated. The next available number will be assigned as the Symbol number.
7. In the Function definition field click [...] in order to specify the symbol logic in the Function definitions dialog.
8. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol is created and opened in a separate graphical editor so it can be edited directly. Please note that the insertion point can only be moved, and can't be deleted.

![](../Pictures/Gui/ALL/note.png)Notes:

- The symbol number "0" is offered as the starting value in an empty symbol library.
- Negative values and values that exceed the maximum number of 32,000 are not allowed as [symbol numbers](Glossary_o_symbolnummern.htm).

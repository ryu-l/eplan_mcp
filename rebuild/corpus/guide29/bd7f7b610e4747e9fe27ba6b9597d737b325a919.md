### Fixed graphics

User interface / operation

There are connection diagrams in which a fixed "screw graphic" is shown for each terminal. Here, it is possible to replace a placeholder with an arbitrary but fixed graphic. For instance, the grid divisions on a form can also be automatically generated in this way.

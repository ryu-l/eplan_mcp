# Create Dictionary

You can [create](Glossary_o_erstellen.htm) and manage multiple [dictionaries](Glossary_o_woerterbuecher.htm). Select the appropriate dictionary for each of your [projects](Glossary_o_projekte.htm).

1. Select the following menu [items](Glossary_o_bauteile.htm): Utilities > Translation > Edit dictionary
2. Select the Access option in the Management tab in order to then interactively select the \*.mdb database file via [...].  
   Or select the SQL server option and then one of the last 15 SQL databases used from the drop-down list. The databases used last are listed at the top.
3. To [generate](Glossary_o_erzeugen.htm) a new database for the dictionary click ![](../Pictures/Gui/ALL/all_new_as.png) (New ) next to the fields Access / SQL Server.
4. Click [Save].

### Adding a Dictionary Language

1. In the Management tab, use [...] to select the dictionary to which you wish to add a dictionary language.
2. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) next to the Dictionary languages field.  
     
   ![](../Pictures/Gui/ALL/arrow.png) EPLAN displays all of the languages that can be accepted into the dictionary.
3. One after the other, select all of the languages that should be available in the dictionary.

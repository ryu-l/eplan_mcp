# P020032: Connection from <x> to <y>: <z>

### Description

You have run a project comparison, checking the Properties of the test project (incoming project) against those of the comparison project and differences were found.

This message occurs when a difference in the [properties](Glossary_o_eigenschaften.htm) of a connection was found. The DTs of the connected source and connected target are output as <x> and <y>, respectively. <z> indicates whether the connection has been deleted or added, or one of its properties has been changed. Testing of the properties of [connections](Glossary_o_verbindungen.htm) includes both the connections navigator and the schematic. If the property of a connection in the test project that has been created in the connections navigator but not yet placed in the schematic has changed, the device tags of the source and target are not output.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

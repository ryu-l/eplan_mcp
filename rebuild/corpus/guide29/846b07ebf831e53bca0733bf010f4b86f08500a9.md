# Bills of Materials: Export File Fields

When exporting a bill of materials, the parts data is output to an export file. Data exported in this manner can then be edited and re-imported. However, only the [properties](Glossary_o_eigenschaften.htm) listed below are written back on import:

| Export file field name | Property |
| --- | --- |
| P\_ARTICLEREF\_PARTNO | Part number |
| P\_ARTICLEREF\_VARIANT | Part variant, category Part reference data |
| P\_ARTICLEREF\_PARTTYPE | Record type, category Part reference data |
| P\_ARTICLEREF\_COUNT | Number of units / quantity |
| P\_ARTICLEREF\_FUNCTIONGROUP | Function group, category Part reference data |
| P\_ARTICLEREF\_PIECETYPE | Part group, category Part reference data |
| P\_ARTICLEREF\_ASSIGNMENT | Part allocation, category Part reference data |
| P\_ARTICLEREF\_ASSEMBLY | Assembly, category Part reference data |
| P\_ARTICLEREF\_POSNR | Item number, category Part reference data |
| P\_ARTICLEREF\_ADDITIONAL\_TEXTFIELD | Supplementary field text, category Part reference data |
| P\_ARTICLEREF\_ADDITIONAL\_BOOLFIELD | Supplementary field yes/no, category Part reference data |
| P\_ARTICLE\_EXTERNAL\_PLACEMENT | External placement, category Part reference data |

# Correcting a Project

Precondition:

You have opened and selected a project in the Page navigator.

### Determining the scope of correction

1. Select the following menu [items](Glossary_o_bauteile.htm): Project > Organize > Correct
2. Click [...] next to the Settings field in the Correct project dialog.
3. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the Settings: Correct dialog.
4. In the New Scheme dialog, in the Name field, enter a name for your new scheme. In the Description field, enter a descriptive text for the scheme, then click [OK].
5. To select the [project data](Glossary_o_projektdaten.htm) for the [Correction settings](ProjectCorrectionGui_k_korrekturdaten.htm) activate the check box of a level in the Data to be corrected field in the Settings: Correct dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the level has sublevels, they will automatically be selected as well.
6. Click ![](../Pictures/Gui/ALL/all_save_as.png) (Save).
7. Click [OK].

### Selecting the correction scheme and filters

If you have already stored the scope of correction as a scheme, you only need to select the existing scheme. To exclude [layers](Glossary_o_ebenen.htm) of the [project structure](Glossary_o_projektstruktur.htm) from correction, you need to define a filter.

1. Select a scheme for the scope of correction in the Correct project dialog in the Settings field.
2. To exclude project data from correction, select a filter from the Filter field.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The results of the correction are displayed in the System messages dialog.

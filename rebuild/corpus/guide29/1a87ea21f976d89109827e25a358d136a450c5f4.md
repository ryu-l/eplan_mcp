# Projects

In EPLAN, schematics and [attached documents](Glossary_o_begleitdokumente.htm) such as lists and overviews are created as pages within [projects](Glossary_o_projekte.htm). Besides the project pages, a project contains all [master data](Glossary_o_stammdaten.htm) used in the project ([symbols](Glossary_o_symbole.htm), [plot frames](Glossary_o_normblaetter.htm), [forms](Glossary_o_formulare.htm), parts data, etc.). The following is possible:

- From the EPLAN [main window](Glossary_o_hauptfenster.htm), projects can be created, renamed, and deleted. Please note that deleting is carried out into the Windows-specific Recycle Bin. If required, such a deleted project can be restored from there.
- Projects can be opened and closed from the EPLAN main window.
- You can [create](Glossary_o_erstellen.htm) [project templates](Glossary_o_projektvorlagen.htm) and [basic projects](Glossary_o_basisprojekte.htm), and use these for creating new projects.

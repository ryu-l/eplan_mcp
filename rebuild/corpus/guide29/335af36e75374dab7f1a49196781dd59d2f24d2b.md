# Templates for New Projects

Templates allow [projects](Glossary_o_projekte.htm) to be created based on existing data. If you [create](Glossary_o_erstellen.htm) projects using the project management or the project wizards, then you must always use a template. Templates for new projects are:

- [Project templates](projects_k_projektvorlagen.htm)
- [Basic projects](projects_k_basisprojekteerweitert.htm).

You can create your own templates from projects and store and manage them in any directory on any available drive.

### Sample templates

After a standard EPLAN installation the ..\Templates\EPLAN and ..\Templates\<Company code> directories contain (e.g.) the following [project templates](Glossary_o_projektvorlagen.htm) and [basic projects](Glossary_o_basisprojekte.htm).

| File name | Meaning |
| --- | --- |
| IEC\_tpl001.ept | Project template: IEC identifier structure is pre-defined |
| Num\_tpl001.ept | Project template: Sequential numbering is pre-defined |
| GOST\_tpl001.ept | Project template: Suitable for creating projects conforming to the [GOST standard](Glossary_o_gost_norm.htm) |
| IEC\_bas001.zw9 | Basic project: IEC identifier structure is pre-defined. Contains [master data](Glossary_o_stammdaten.htm) such as [symbol libraries](Glossary_o_symbolbibliotheken.htm), [forms](Glossary_o_formulare.htm), plot frame. |
| Num\_bas001.zw9 | Basic project: Sequential numbering is pre-defined. Contains master data such as symbol libraries, forms, plot frame. |
| GOST\_bas001.zw9 | Basic project: Suitable for creating projects conforming to the GOST standard. Contains master data such as symbol libraries, forms, plot frame. |

# Dialog Part master data

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Part master data navigator

This dialog provides you with an overview of the existing parts [master data](Glossary_o_stammdaten.htm). Parts / [devices](Glossary_o_betriebsmittel.htm) can be placed in a schematic page from here using Drag&Drop, and then subsequently edited.

Overview of the main dialog elements:

Field-based filter:

This drop-down list displays all the available [filters](Glossary_o_filter.htm). A selected filter is automatically activated and is applied to both the tree and the list view. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the [Filter](modaldialogsdb_d_filternnach.htm) dialog. Here you can [create](Glossary_o_erstellen.htm), edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

- Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
- Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

Full-text filter:

Enter the text to be found in this box, and click ![](../Pictures/Gui/ALL/all_search_as.png) (Find). The text is then searched for in all data records; in tree view, this search also includes the main nodes "Accessory list", "Accessory placement", "Drilling pattern", and "Connection point pattern".  
If you are using this search for the first time, you must click [OK] to [generate](Glossary_o_erzeugen.htm) the search index. Otherwise the search index can be updated at any time by using [Extras] > Update search index.   
Click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) to delete the search term and [return](Glossary_o_zurueckbuchen.htm) to the full parts display.

Rules for the syntax of the search item can be found [here](partsmanagementgui_d_artverw.htm#VolltextFilter).

Tree:

The [part types](Glossary_o_artikeltypen.htm) can be displayed in a hierarchical tree structure below these filter fields, where the individual [part](Glossary_o_artikel.htm) numbers are displayed at the lowest level. Use the Configure representation popup menu item to show or hide the additional display of the part designation.

List:

As an alternative to the tree, you can also display the data in a list, where the scope of the display is set using the Configure representation popup menu item. Here, the list shows all parts, but only those [properties](Glossary_o_eigenschaften.htm) possessed by all parts are shown (e.g. part number, product group, etc.).

Combination:

This tab contains a combined view of the parts tree and list. It provides a clear view of the selection for [placing](Glossary_o_auflegen.htm) parts / devices on schematic pages using the Drag & Drop.   
You can preselect parts in the tree view in the upper area of the tab. When you select a node such as the "Cables" product group in the tree, the associated parts are displayed in the list below.  
The scope of the display can also be specified here using the popup menu item Configure representation options.

The tabs displayed in the dialog on the right-hand side relate to the selection made in the tree, list or combined view. When selecting a customer, the detailed view for this customer is displayed, while for cables the [cable](Glossary_o_kabel.htm)-specific tabs are shown.

Info:

In this tab information such as the name and type of the currently used parts database, the number of contained parts, the number of manufacturers / suppliers, [drilling patterns](Glossary_o_bohrbilder.htm), accessory lists, etc. is displayed. The content of the tab is automatically updated during opening. However, it can be updated at any time manually by using [F5].

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Adjust column width (list only and combination) | Adjusts the width of all table columns so that both the headings and column contents are fully legible. |
| List with preselection (tree only) | Reduces the number of elements displayed in order to allow for a faster orientation in the list view. If this option is activated, the list view is called up with an automatic filter (preselection) containing the elements that are currently selected. |
| Configure representation | Opens the Configure representation dialog, where you define which properties are to be displayed in the list and tree view. |
| Open hyperlink | Allows opening of [external documents](Glossary_o_fremddokumente.htm) or an image file, as long as this is assigned to the part in the parts management. |
| Insert device | Inserts the marked device. Before the actual placing press the [Backspace] in order to open the dialog Insert device and, if required, for example open the macro selection or change the representation type. |
| Assign | This menu option is used to assign a part previously selected in the navigator to a certain function on the schematic. When you select this option, the part hangs on the cursor. Position the cursor on the required [component](Glossary_o_schaltzeichen.htm) in the graphical editor, and left-click to assign the part. The part can be assigned several times; it remains on the cursor until you cancel the action. |

![](../Pictures/Gui/ALL/info.png)Tip:

You can add parts to a device placed in the graphical editor using Drag&Drop. To do this, select the desired part in the Part master data navigator, press the [Ctrl] + [Shift] key combination, and pull the part onto the component. If the device already has one or more parts, then a query is displayed asking whether the existing parts should be enhanced or replaced.

# Setting up the Target Project (Changing Standards)

When changing standards, a source project is transformed. The transformed source project is saved in a target project. The source project remains unchanged.

![](../Pictures/Gui/ALL/note.png)Note:

Please note that only those [objects](Glossary_o_objekte.htm) that are within the reporting range of the plot frame (thus the range defined by the rows and columns) are copied to the target project.

Preconditions:

- You have opened a project.
- If multiple [projects](Glossary_o_projekte.htm) are open: You have selected a project in the page navigator.
- You have a template containing country- or standards-specific [settings](Glossary_o_einstellungen.htm).

1. Utilities > Change of standard
2. Specify a recognizable project name without file name extension in the Target project name field of the Project tab.
3. Click [...] next to the Storage location field to select a location for the project.
4. In the Select directory dialog select the directory where you want to save the new project and click [OK].
5. Click [Next].

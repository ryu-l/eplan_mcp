# Dialog Connection numbering: Formats

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the [Settings: Connection numbering](wirenumberinggui_d_verbnumeinstellungen.htm) dialog, for example via the Options > Settings > Projects > "Project name" > Connections > Connection numbering menu [items](Glossary_o_bauteile.htm). Select a [user-defined](Glossary_o_benutzerdefiniert.htm) scheme in the dialog Settings: Connection numbering and select the Designation tab. Select an entry in the Format groups field and click ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit), or click ![](../Pictures/Gui/ALL/all_new_as.png) (New).

In this dialog you can change the format of an existing format group or define a new format.

Overview of the main dialog elements:

Connection group:

Select one of the default [connection groups](Glossary_o_verbindungsgruppen.htm) or specify a DT or a grouping as the connection group. The following connection groups among other things are pre-defined:

- General connections (i.e. all desired [connections](Glossary_o_verbindungen.htm))
- Connections connected to PLC connection points (except card power supply and bus cable): Card [power supplies](Glossary_o_anschlussversorgungen.htm) and bus cables are considered separately and can therefore be numbered with the general connections.
- Connections connected to "PLC connection points, I/O, 1 connection point" or "PLC connection point, variable": Connections connected to [PLC connection points](Glossary_o_sps_anschluesse.htm) of the function group "PLC connection point, I/O, 1 connection point" or "PLC connection point, variable". Deactivated PLC [connection points](Glossary_o_anschluesse.htm) are not considered. Adjustable PLC connection points (function definition "PLC connection point, multi-function") are considered only if they are defined via the type of signal as input or output.
- Device: In the [Selection list](wirenumberinggui_d_betriebsmittelliste.htm) dialog you can select one of the DTs in the project. When specifying a DT, the connection group will be defined by all of the connections attached to the corresponding [functions](Glossary_o_funktionen.htm).
- Grouping: In the [Selection list](wirenumberinggui_d_betriebsmittelliste.htm) dialog, you can select one of the values that you specified for the Grouping property. The connection group is then defined for all connections that have the specified value for the grouping.

Extent:

Specify which connections have the same format for the [connection designations](Glossary_o_verbindungsbezeichnungen.htm).

Available format elements:

This list displays the elements that could be integral parts of the connection designation. To format a format element you have to move it to the list of selected [format elements](Glossary_o_formatelemente.htm) on the right. Multiple selections are not possible. When you move the format element, a dialog will open in which you can specify the formatting. This dialog is different depending on the format element.

| Format element | Preview | Meaning |
| --- | --- | --- |
| Piping data | V | Outputs [properties](Glossary_o_eigenschaften.htm) of the piping in the [P&I diagram](Glossary_o_ri_fliessbild.htm). |
| Data of the page of the source function | Pb | Outputs properties of the schematic page on which the connected source function is placed. |
| Data of the page of the target function | Pe | Outputs properties of the schematic page on which the connected target function is placed. |
| Data of the connection | W | Displays the connection properties. |
| Data of the connected source function | B | Displays the properties of the connected source function. |
| Data of the connected target function | E | Displays the properties of the connected target function. |
| Data of the object on which the connection group is based | O | Displays the properties of the object on which the connection group is based. |
| Data of the potential | V | Displays the potential properties. |
| Page | S | Displays the names of the page where the device (source or target as desired) is located. A page subcounter is not output. |
| Column | P | Displays the number of the column where the device (source or target as desired) is located. |
| Separator |  | Separates format elements from one another. |
| Subcounter | Cs | Inserts a subcounter. |
| Line | R | Displays the number of the row where the device (source or target as desired) is located. |
| Counter | C | Inserts a counter. |

Selected format elements:

This list displays the selected format elements in table [form](Glossary_o_verlauf.htm) with their designation, symbolic representation (for the preview) and specified value.

Preview:

The preview of a connection format is displayed here. The individual formatting elements are displayed in the connection [designations](Glossary_o_bezeichnungen.htm) in the same sequence as they currently exist in the list. This field cannot be modified.

Overwrite terminal designations:

If this check box is selected, the designations for terminals will be overwritten with the connection designation. In the process, the designation of the first connection joined to the appropriate terminal is adopted.

Overwrite interruption point designations:

If this check box is selected, the designations for [interruption points](Glossary_o_abbruchstellen.htm) will be overwritten with the connection designation. In the process, the designation of the first connection joined to the appropriate interruption point is adopted.

Overwrite bundle connection point designations:

If this check box is selected, the designations for [bundle](Glossary_o_buendel.htm) connection points will be overwritten with the connection designation. In the process, the designation of the first connection joined to the appropriate bundle connection point is adopted.

# P024008: Differing conduit data: <x>

### Cause

You treated a conduit that was shown as distributed In the schematic as if it were separate [conduits](Glossary_o_pakete.htm) and assigned contradictory data to the main function and [auxiliary functions](Glossary_o_nebenfunktionen.htm). These data include the [properties](Glossary_o_eigenschaften.htm) Type, Number of [connections](Glossary_o_verbindungen.htm) and / or Cross-section / diameter that are output in the placeholder <x> of the message.

### Solution

1. Locate the main function of the conduit in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Open the main function of the popup menu and use the menu item Go to (counterpiece) to jump to the auxiliary function of the conduit.
3. Open each [property dialog](Glossary_o_eigenschaftendialog.htm) at the main and auxiliary [functions](Glossary_o_funktionen.htm) of the conduit and standardize all the values in the fields of the respective properties.
4. Refresh the connections and then start a new check run.

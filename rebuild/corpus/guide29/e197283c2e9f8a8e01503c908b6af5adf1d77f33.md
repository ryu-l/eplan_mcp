# Inserting QR Codes

A QR code consists of a square formation of black and white squares. Such a code is, for example, used for a coded representation of Internet addresses, phone numbers, WLAN access data, etc. The tedious typing out of this data is no longer required thanks to photographing of the code with mobile [devices](Glossary_o_betriebsmittel.htm) and its interpretation via app.

In the graphical editor you have the possibility to [generate](Glossary_o_erzeugen.htm) a QR code by means of a menu item from a text, Internet address or [properties](Glossary_o_eigenschaften.htm), and have this displayed on a project page.

Precondition:

You have opened a project page in the graphical editor.

1. Select the following menu [items](Glossary_o_bauteile.htm): Insert > Graphic > QR code
2. Specify the first corner point of the QR code.
3. Drag the square of the QR code into any direction and define the end point.
4. In the Properties (QR code) dialog select the QR code tab.
5. Enter the text or the Internet address in the Block format field that is to be generated as a QR code and be shown on the project page. If a property is to be used for the QR code, use the [â¦] button to branch into the subsequent dialog Format to select the property and if required further [format elements](Glossary_o_formatelemente.htm) such as separators.   
     
   ![](../Pictures/Gui/ALL/arrow.png) If no entry is made in the Block format field, a QR code without contents is generated.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) When moving a cursor over the square of a QR code, the contents of the code is displayed as a tooltip.

![](../Pictures/Gui/ALL/note.png)Notes:

- Only the starting point or the size of a QR code square can be influenced via the Format tab. Further format [settings](Glossary_o_einstellungen.htm) are not possible.
- A QR code cannot be edited by using Edit > Rotate or Edit > Flip since a change in the orientation of the QR code is prohibited during editing.
- You can output QR codes on [report pages](Glossary_o_auswertungsseiten.htm). To this purpose the [Show as QR code](formeditorgui_r_platzierung.htm#QRCode) check box is available for [placeholder texts](Glossary_o_platzhaltertexte.htm) in the Property (placeholder text) dialog on the Placement tab. This way you can, for example, store hyperlinks to the manufacturer pages for the parts used in the project in the "Device tag list" report.

![](../Pictures/Gui/ALL/info.png)Tip:

If the generated QR code is an Internet or e-mail address, you can jump to the respective Internet page or start the e-mail program installed on your computer via the Open hyperlink popup menu item.

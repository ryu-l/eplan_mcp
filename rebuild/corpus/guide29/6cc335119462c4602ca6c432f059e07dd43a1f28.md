# Keeping Connection Point Logic when Changing the Function Definition

You edit the logic model of the function in the Connection point logic dialog. In the past if [user-defined](Glossary_o_benutzerdefiniert.htm) modifications were made for one or more [connection points](Glossary_o_anschluesse.htm) here, the [settings](Glossary_o_einstellungen.htm) were removed again as soon as another function definition was selected in the Symbol / function data tab. So that you can prevent this in the future, you have the new Keep connection point logic of the function check box in the Function definitions dialog. If this check box is activated, the connection point logic of the function is not changed when another function definition is selected. This way user-defined modifications in the Connection point logic dialog remain.

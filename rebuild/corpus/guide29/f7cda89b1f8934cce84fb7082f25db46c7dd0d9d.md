# P005051: Connector with unconnected connection point

### Cause

A connector with at least one unconnected connection point was found in the schematic. For the purposes of this message, a connector is an angle, T-node, jumper, double junction or diagonal connection.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

A T-node in the schematic has an unconnected connection point (see circle in the following figure).

![](../Pictures/Visualisation/ALL/messages_005051_bsp_av.png)

### Solution

1. Locate the relevant connector in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Connect the open connection point(s) of the connector with a [component](Glossary_o_schaltzeichen.htm) so as to [form](Glossary_o_verlauf.htm) [autoconnecting](Glossary_o_autoconnecting.htm) [lines](Glossary_o_leitungen.htm).
3. Delete the connector if it is no longer required.
4. Then start a new check run.

# Direct Editing

Using direct editing you can activate an editing mode that allows you to directly modify individual graphical texts and [property texts](Glossary_o_eigenschaftstexte.htm) of components.

As well as switching this editing mode on and off via the Options menu, you can also temporarily activate the direct editing mode via the mouse or keyboard. To do this, first select the text or [component](Glossary_o_schaltzeichen.htm) and then briefly hold down and release the left mouse button or press the [F2] key.

### Direct editing of graphical texts

"Graphical texts" means any placement of free texts and [path function texts](Glossary_o_pfad_funktionstexte.htm). These can be placed on schematic pages, [graphical pages](Glossary_o_grafikseiten.htm), in [reports](Glossary_o_auswertungen.htm), or in [master data](Glossary_o_stammdaten.htm) (such as [forms](Glossary_o_formulare.htm) or [plot frames](Glossary_o_normblaetter.htm)).

### Direct editing of property texts

Certain property placements of components, for example the [properties](Glossary_o_eigenschaften.htm) Displayed DT or Technical characteristics, can also be edited directly in the graphical editor. An overview of the "directly" editable properties can be found under "[Properties for Direct Editing](inplaceeditinggui_k_eigenschaften.htm)". However, direct editing is only possible for [functions](Glossary_o_funktionen.htm), for example not for [interruption points](Glossary_o_abbruchstellen.htm) and [structure boxes](Glossary_o_strukturkaesten.htm).

As soon as you have switched to the direct editing mode, you can jump between the individually editable texts of a component using the [Tab] key. When jumping, the changes to the current text are saved and an editing frame for the next text is opened.

To jump, first graphically determine a sequence of the main properties (from top left to bottom right). Then a jump is made to the first main property, and subsequently to its docked placements. After this, the system jumps to the second main property with its docked placements, etc. Empty or hidden properties are ignored.

### Special considerations for direct editing

In contrast to entering and editing texts via the properties dialog, the following special conditions must be considered for direct editing:

- It is not possible to format texts in this mode.
- Direct editing does not support multiple selections. If several texts or components are marked, the editing frame is only opened for the text currently in question (clicked on).
- Special texts cannot be directly edited. This applies to project and page properties, property texts in the [symbol editor](Glossary_o_symboleditor.htm), column and line texts in the plot frame editor, [placeholder texts](Glossary_o_platzhaltertexte.htm) in the [form](Glossary_o_verlauf.htm) editor, etc.

# Tab Status

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Page > Navigator. Select a project. Select the Properties popup menu item. Select the Status tab.
- You have selected a project management database. You have loaded directories and [projects](Glossary_o_projekte.htm). Project > Management. Select a project. Select the Status tab.

The last test runs are displayed in this dialog, with the status and number of generated messages.

![](../Pictures/Gui/ALL/note.png) Note:

If you have performed a test run and the information is not displayed or not updated, then click [Extras] > Update data.

Overview of the main dialog elements:

Project checks:

All available test runs are shown in this column.

Date of project check:

This column shows the date on which each check run was last performed.

Version:

This column shows the program version of EPLAN. The program version is displayed using the menu item Help > About.

Build no.:

This column shows the build number of EPLAN. The build number is displayed using the menu item Help > About.

Test scheme:

This column shows the scheme used for the check run, for example "Offline" or "Interruption points".

Errors / Warnings / Notes:

These columns show the status and number of messages generated by a check run for every message category. The messages are created when the test is run and are identical to the messages that can be displayed using the menu item Project data > Messages > Management.

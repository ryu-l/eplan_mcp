# Inserting and Outputting QR Code

A QR code consists of a square formation of black and white squares. Such a code is, for example, used for a coded representation of Internet addresses, phone numbers, WLAN access data, etc. The tedious typing out of this data is no longer required thanks to photographing of the code with mobile [devices](Glossary_o_betriebsmittel.htm) and its interpretation via app. In the graphical editor you have the possibility to [generate](Glossary_o_erzeugen.htm) a QR code by means of the new menu item Insert > Graphic > QR code from a text, Internet address or [properties](Glossary_o_eigenschaften.htm), and have it displayed on a project page.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

You can use the QR code to store hyperlinks in your documentation that in printed [form](Glossary_o_verlauf.htm) can be read by mobile devices and be opened on these devices.

After you have determined the position and size of the square for the QR code with two clicks, the new Properties (QR code) dialog opens.

Enter the text or the Internet address, that is to be generated as the QR code on the project page, on the QR code tab in the Block format field. If a property is to be used for the QR code, use the [â¦] button to branch into the subsequent dialog Format to select the property and if required further [format elements](Glossary_o_formatelemente.htm) such as separators.

### Editing QR code

Only the starting point or the size of a QR code square can be influenced via the Format tab. Further format [settings](Glossary_o_einstellungen.htm) are not possible.

A QR code cannot be edited by using Edit > Rotate or Edit > Flip since a change in the orientation of the QR code is prohibited during editing.

### Jump function for the QR code

If the generated QR code is an Internet or e-mail address, you can jump to the respective Internet page or start the e-mail program installed on your computer via the Open hyperlink popup menu item.

You can also activate the jump function by pressing the [Ctrl] key. The cursor changes into a hand for this operation.

### QR code on report pages

You can output QR codes on [report pages](Glossary_o_auswertungsseiten.htm). To this purpose the new check box [Show as QR code](formeditorgui_r_platzierung.htm#QRCode) is available for [placeholder texts](Glossary_o_platzhaltertexte.htm) in the Properties (placeholder text) dialog on the Placement tab. If this check box is activated, QR codes are generated for the previous, selected property during reporting on the basis of the determined values and are output on the output report pages.

This way you can, for example, store hyperlinks to the manufacturer pages for the parts used in the project in the "Device tag list" report.

# Dialog Select manufacturer

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened the [Edit <...>](fluidhoseconfiggui_d_schlauchleitungenbearbeiten.htm) dialog. In the Further specifications group box click [...] next to the Manufacturer field.

Select the desired hose line manufacturer in this dialog. This information is required for the output of the [hose line identification](Glossary_o_schlauchleitungskennzeichnung.htm).

Overview of the main dialog elements:

Table:

The table allows you to manage the manufacturer information as short names and as long names. If you have selected the default preset scheme DIN 20066\_2012-01 in the [settings](Glossary_o_einstellungen.htm), numerous well-known hose manufacturers are already offered for selection in the table.

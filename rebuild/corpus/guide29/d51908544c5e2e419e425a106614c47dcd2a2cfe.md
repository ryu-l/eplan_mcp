# Dialog Format: Separator

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call (Formats for block properties):](javascript:void(0);)

You have opened a project. You have opened the [properties](Glossary_o_eigenschaften.htm) dialog for a function, a symbol, or a project. In the Properties field, you have selected the Block property: Format [n] property and clicked [...] in the Value column.

- Select the Separator format element in the Available format elements list of the Format dialog, and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).
- Select an existing format element of the Separator type in the Selected format elements list of the Format dialog, and click ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit).

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call (PLC address formats):](javascript:void(0);)

You have opened a project. You have opened the [Settings: PLC](plcgui_d_allgemeinespseinstellungen.htm) dialog, for example via the Options > Settings > Projects > "Project name" > Devices > PLC menu [items](Glossary_o_bauteile.htm). You clicked [...] next to the PLC-specific settings field in the Settings: PLC dialog. You selected the Format of assignment list tab and clicked [...] next to the Format of assignment list row or Format of assignment list address fields in the dialog [Settings: PLC-specific](plcprocessorgui_d_spsspezifischeeinstellungen.htm).

In the subsequent dialog, select a format element of the Separator type from the Available format elements list and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right) (or double-click an already defined [separator](Glossary_o_trennzeichen.htm) in the Selected format elements list).

In this dialog you specify the formatting for a separator in the format group.

Overview of the main dialog elements:

You can specify the following characters as separators:

- Blank
- Tabulator
- Line break
- Other characters: After selecting this option, enter the desired character combination in the input field below. Any digits, letters, and special characters can be used.

![](../Pictures/Gui/ALL/note.png)Notes:

- For all PLC formats, the line break is not available as a separator. The tabulator is also not available as a separator for the address format of digital or analog inputs or outputs.
- For Block properties, the tabulator is not available as a separator.

Number of characters:

If you have selected a space, tabulator, or line break as a separator, you can specify the number of characters here. The separator can consist of multiple spaces, tabulators, or line breaks. If you select Other characters, this field is grayed out and displays the specified number of characters.

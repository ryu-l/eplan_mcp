# Defining Block Properties for PCT Loops / PCT Loop Functions

Block [properties](Glossary_o_eigenschaften.htm) allow the format information of multiple properties to be managed in a single property. Each Block property [n] has a Block property: Format [n]. Every Block property [1] has for example the Block property: Format [1] property. You define the format specifications for several properties in the Block property: Format [1] property. Block property [1] shows the concrete data based on these formatting specifications.

Preconditions:

- You have opened a project containing pre-planning data.
- You have opened a project page in the graphical editor.
- You have not yet defined the Block property: Format [1] property.

1. Select a PCT loop / PCT loop function.
2. Select the following menu [items](Glossary_o_bauteile.htm): Edit > Properties
3. In the dialog Properties <...>: PCT loop or Properties <...>: PCT loop function select the <PCT loop> / <PCT loop function>.
4. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) above the Properties table.
5. In the Property selection dialog, select the Block property: Format [1] property and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property is shown in the Property name column.
6. Click the Value column next to this and then click [...].
7. Mark the PCT loop or PCT loop function property in the Format dialog, in the Available format elements field, and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Format: Block property dialog shows all properties available for [PCT loops](Glossary_o_plt_stellen.htm) or [PCT loop functions](Glossary_o_plt_stellenfunktionen.htm).
8. Select an entry in the list below the Category field.
9. To define the number of positions and the filler character for empty spaces in the property text, enter the desired values into the Minimum number of digits and Filler character fields.
10. To define when the property is to be hidden, define the conditions in the Hide property if group box.
11. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The format information of the property is displayed in the Selected format elements field.
12. Define further format information in the same manner.
13. Once you have defined the block property, click [OK] in the Format dialog.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The format specifications of the Block property: Format [1] property are shown in the Value column.
14. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
15. In the Property selection dialog, in the Block property group box, select the Block property [1] property and click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The concrete values of the property are displayed next to Block property [1]. If the property has not been updated, you must close the dialog and re-open it.

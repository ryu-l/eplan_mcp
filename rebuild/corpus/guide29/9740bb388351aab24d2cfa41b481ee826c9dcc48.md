# P002007: Several non-associated plug definitions exist

### Cause

You design with [plugs](Glossary_o_stecker.htm) and manage female and [male pins](Glossary_o_steckerstifte.htm) separately. The [function definitions](Glossary_o_funktionsdefinitionen.htm) of two corresponding [plug definitions](Glossary_o_steckerdefinitionen.htm) with the same DT do not match. The pair relationship between plug and socket is not defined by this.

### Solution

Check that the correct function definition is set in the plug definition for the female and male sides. To do this, call up the Properties <...> dialog and, in the Plug definition tab, examine the [settings](Glossary_o_einstellungen.htm) in the Function definition field.

For the plug definition on the female side, the function definition must be set to "Plug definition for [female pins](Glossary_o_steckerbuchsen.htm)". For the plug definition on the male side, the function definition must be set to "Plug definition for male [pins](Glossary_o_steckerkontakte.htm)".

Change the incorrect settings according to these instructions and then begin a new project check.

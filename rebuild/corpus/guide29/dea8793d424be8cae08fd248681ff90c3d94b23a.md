# Dialog Settings: Connection category

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > Company > Management > Connection category.

In this dialog you determine the [connection categories](Glossary_o_anschlussausfuehrungen.htm) which are offered and used as defaults when managing [connection point patterns](Glossary_o_anschlussbilder.htm) in parts management.

Overview of the main dialog elements:

Table:

The Number column displays the consecutive number which defaults the sequence in which the connection categories are displayed in the drop-down list in parts management. Under Connection category (default), you will see the [default names](Glossary_o_vorgabenamen.htm) of this data. Grayed-out entries are defaulted by EPLAN and cannot be edited by you; all other [designations](Glossary_o_bezeichnungen.htm) for the connection categories can be assigned by you and be deleted again, if necessary.

The following connection categories correspond to the eCl@ass classification and should be used when new connection point patterns are created:

- Screw connection
- Spring pulley connection
- Push-in connection
- Penetration connection
- Insulation-displacement connection
- Plug-in connection
- Push-wire connection
- Bolt connection
- Flat plug-in connector
- Crimp connection
- Band connection
- Rail connection
- Soldering lug connection
- Wrap post

The following connection categories are still available for compatibility reasons but should not be used anymore in future when new connection point patterns are created:

- Screw clamp connection single
- Screw clamp connection double
- Cage clamp connection
- Screw-type connection (ring or u [cable](Glossary_o_kabel.htm) lug)
- Ferrule connection (cable lug)
- Plug connection
- Conductor plate connection
- Plug-in connection (Fluid)
- Nipple
- Compression nut
- Compression fitting

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# Creating Format Groups

Precondition:

You have opened a project.

1. Options > Settings > Projects > "Project name" > Connections > Connection numbering
2. Select a [user-defined](Glossary_o_benutzerdefiniert.htm) scheme from the drop-down list, or [create](Glossary_o_erstellen.htm) a new scheme via ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the dialog Settings: Connection numbering.
3. Move the Designation tab to the foreground and above the Format groups field click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
4. Select one of the predefined [connection groups](Glossary_o_verbindungsgruppen.htm) or select the entry "Device..." or "Grouping..." in the Connection group field in the dialog Connection numbering: Formats.
5. If you selected "Device..." or "Grouping..." to get to the Selection list dialog, select one of the DTs in the project or a value for the grouping and click [OK].
6. In the Extent field specify the range of [connections](Glossary_o_verbindungen.htm) that are to receive the same format for their [connection designations](Glossary_o_verbindungsbezeichnungen.htm). Select an entry from the drop-down list.

   ![](../Pictures/Gui/ALL/note.png) Note:

   If you have selected the "Net" entry, you can use the net extension to expand the area of influence for numbering.
7. In the Available format elements field select a format element and move it over to the right using the arrow button into the list of selected [format elements](Glossary_o_formatelemente.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) Different subsequent dialogs will appear, depending on the format element. Depending on the selected format element this can be one of the following dialogs: [Format: Properties](wirenumberinggui_d_formateigenschaften.htm), [Format: Counter](wirenumberinggui_d_formatzaehler.htm), [Format: Page / column / row](wirenumberinggui_d_formatseite.htm) or [Format: Separator](wirenumberinggui_d_formattrennzeichen.htm).
8. Define the formatting in the subsequent dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A preview of the designation format is displayed in the Preview field. The individual format elements are displayed in the connection [designations](Glossary_o_bezeichnungen.htm) in the same sequence as they currently exist in the list.
9. If desired, you can change the sequence of the format elements using the arrow buttons.
10. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The values entered will be saved in the selected scheme.

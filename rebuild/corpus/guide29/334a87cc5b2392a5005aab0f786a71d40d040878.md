# Tab Terminal strip definition

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have selected a terminal strip definition in the graphical editor. Edit > Properties. In the Properties <...> dialog, select the Terminal strip definition tab.
- You have selected a terminal strip definition in the terminal strip navigator or device navigator. Popup menu item Properties or Properties (global). In the Properties <...> dialog, select the Terminal strip definition tab.
- You [generate](Glossary_o_erzeugen.htm) a terminal strip definition in the terminal strip navigator via the Generate terminal strip definition popup menu item.

In this tab, you can specify or modify the [properties](Glossary_o_eigenschaften.htm) of terminal strips.

In the Properties (global) processing mode, you edit the properties of all representations of the function jointly; in this case, the tab shows the supplement "(Device)".

Overview of the main dialog elements:

Displayed DT:

The displayed DT is displayed in the graphical editor on the [component](Glossary_o_schaltzeichen.htm). If you have defined in the project [settings](Glossary_o_einstellungen.htm) that [devices](Glossary_o_betriebsmittel.htm) are to be automatically numbered when [symbols](Glossary_o_symbole.htm) are inserted, then a DT is automatically suggested here. You can accept this DT or overwrite it manually.

In addition you can use the [popup menu or the [...] button](devicetaggui_r_feldsichtbaresbmk.htm) to [create](Glossary_o_erstellen.htm) or select a DT.

Full DT:

This field displays the full DT (i.e. structure identifier of the current environment + displayed DT) of the component / item. Use the [...] button to open the Full DT dialog. You can edit the [structure identifiers](Glossary_o_strukturkennzeichen.htm) there and select, e.g., another [mounting location](Glossary_o_einbauort.htm).

Terminal diagram form:

The [form](Glossary_o_verlauf.htm) defined here is used when creating terminal diagrams. It has priority over the form that you have selected in the report settings.

Select a form from the drop-down list. Selecting the "Browse" entry opens the file selection dialog where you can select a form from any desired directory.

Function text:

Here you enter the function text for the function / device.

Aside from the manually entered function text, there are other (automatically determined) [function texts](Glossary_o_funktionstexte.htm) that you will find in the table of properties:

- Function text (automatic): Displays the contents of the manually entered function text. If you edit this function text in the Properties (global) processing mode, the content is returned to the function where the function text was entered originally. When this property is displayed on a project page, the line breaks are removed.
- Function text (common): Displays the function text (automatic) of the function.

Connection point diagram form:

The form defined here is used when creating connection-point diagrams. It has priority over the form that you have selected in the report settings.

Select a form from the drop-down list. Selecting the "Browse..." entry opens the file selection dialog where you can select a form from any desired directory.

Mounting site (describing):

Enter the descriptive mounting site for the terminal strip here, or select an entry from the drop-down list. The list shows all values that you have previously entered for the same type of function at other places in the project.

Main function:

Select this check box if the current function is a main function.   
When using a DT for which there is already a main function, when using a placed main function, or when [placing](Glossary_o_auflegen.htm) an already placed main function, this property will automatically be switched off at the target function, that is, the check box is deactivated.

![](../Pictures/Gui/ALL/note.png)Note:

The setting is automatically compared to the check box of the same name in the Symbol / function data tab.

[Properties group box](devicetaggui_r_gruppenfeldeigenschaften.htm)

You can use the Do not use main terminals property to specify that a terminal strip should not be divided into independent areas and should only be defined via the terminal strip definition. Main terminals are then treated in the same way as auxiliary terminals.

You can use the following properties in the "Settings" category to specify whether [terminal strip definitions](Glossary_o_klemmenleistendefinitionen.htm) should be output in terminal diagrams, terminal [connection diagrams](Glossary_o_anschlussplaene.htm), or terminal overviews:

- No output to terminal / plug diagram
- No output to terminal-connection / pin-connection diagram
- No output to terminal-strip / plug overview
- No output to terminal line-up diagram.

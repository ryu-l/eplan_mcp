# P020041: Different layers: Symbol <x> : Property placement <y> : Layer <z> - <u>

### Cause

The project comparison has discovered that a property placement of a symbol placed in the schematic has a different layer setting as that defined for the same symbol in the symbol library. This message shows the name of the symbol (<x>), the name of the property placement (<y>), the layer of the property placement in the symbol library (<z>), and the layer of the property placement of the placed symbol (<u>).

### Solution

Change the layer of the property placement for the placed symbol to the same value as the symbol library and then start a new check run.

# Cables

The functionality of the [cable](Glossary_o_kabel.htm) in EPLAN is based on the [connections](Glossary_o_verbindungen.htm). The following [actions](Glossary_o_aktionen.htm) are possible for cables:

- Cables can be edited in the navigator for cables or in the graphical editor.
- Cable connections are defined using [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm).
- Cables can also contain connections that are not [conductors](Glossary_o_adern.htm) (hybrid cables).
- Cables can be automatically completed and generated.
- In parts selection, you can select a [cable part](Glossary_o_kabelartikel.htm) for a cable defined in the project.
- Cable parts are managed in the parts database. Cable information can be either manually entered or imported directly from the manufacturer using various import [functions](Glossary_o_funktionen.htm) (e.g., ECAD, [eCl@ss](Glossary_o_eclass.htm)).
- Cable connections are automatically assigned to connections of the cable [part](Glossary_o_artikel.htm) when cables are selected, and the connection point type is taken into consideration in the process. Manual assignment is another option.
- Cables can be numbered. There are special formatting options for the numbering of cables.
- Reserve [cable connections](Glossary_o_kabelverbindungen.htm) can be managed.
- Cables can be shielded, and multiple [shields](Glossary_o_abschirmungen.htm) can be managed in the process.
- Calculating the cable lengths generates project parts that reflect the actual requirements for cables. The cable lengths are added for each cable type.

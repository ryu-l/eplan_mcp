# Tab Cable / shield

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have selected a [cable](Glossary_o_kabel.htm) definition line or a shield in the graphical editor. Edit > Properties. In the Properties <...> dialog, select the Cable / Shield tab.
- You have selected a cable definition or a shield in the cable navigator or in the device navigator. Popup menu item Properties or Properties (global).In the Properties <...> dialog, select the Cable / Shield tab.

In this tab, you can edit the [properties](Glossary_o_eigenschaften.htm) of a cable or a shield.

In the Properties (global) processing mode, you edit the properties of all representations of the function jointly; in this case, the tab shows the supplement "(Device)".

Overview of the main dialog elements:

Displayed DT:

The displayed DT is displayed in the graphical editor on the [component](Glossary_o_schaltzeichen.htm). If you have defined in the project [settings](Glossary_o_einstellungen.htm) that [devices](Glossary_o_betriebsmittel.htm) are to be automatically numbered when [symbols](Glossary_o_symbole.htm) are inserted, then a DT is automatically suggested here. You can accept this DT or overwrite it manually.

In addition you can use the [popup menu or the [...] button](devicetaggui_r_feldsichtbaresbmk.htm) to [create](Glossary_o_erstellen.htm) or select a DT.

When inserting shields, the displayed DT remains empty. If necessary, however, you can enter a DT manually or assign it via the device numbering.

Full DT:

This field displays the full DT (i.e. structure identifier of the current environment + displayed DT) of the component / item. Use the [...] button to open the Full DT dialog. You can edit the [structure identifiers](Glossary_o_strukturkennzeichen.htm) there and select, e.g., another [mounting location](Glossary_o_einbauort.htm).

Type:

Enter a cable type in this field. Click [...] to open the Part selection dialog. There, you can select a [cable part](Glossary_o_kabelartikel.htm) and assign its technical data to the current cable.

The parts data is updated â just like with a new [part](Glossary_o_artikel.htm) selection. In contrast to a regular part selection, however, no conflict dialog is displayed here with the old and new data, but the old data is overwritten without any further prompt.

Function text:

Here you enter the function text for the function / device.

Aside from the manually entered function text, there are other (automatically determined) [function texts](Glossary_o_funktionstexte.htm) that you will find in the table of properties:

- Function text (automatic): Displays the content of the manually entered function text or, if it is empty, the path function text. If you edit this function text in the Properties (global) processing mode, the content is returned to the function where the function text was entered originally. When this property is displayed on a project page, the line breaks are removed.
- Function text (common): Displays the function text (automatic) of the function or, if it is empty, the function text (automatic) of the associated main function.

Number of connections:

The number of [connections](Glossary_o_verbindungen.htm) is adopted from parts management and can be used as filter criteria when selecting devices.

You can enter a value manually; entries such as "9PE" or "3x3" are possible. In case of the automatic cable selection, the number of connections is determined from the value:

- For a combination of a number and "PE", "PEN" or "N", EPLAN considers them as PE, PEN or N [conductors](Glossary_o_adern.htm) included in the whole number (e.g., 4PE => four [cable connections](Glossary_o_kabelverbindungen.htm) total, of which one is a PE conductor).
- For a combination of a number and letters, only the number is evaluated (e.g., "4G" or "4X" => four cable connections).
- For a combination <number> letter <number> (except for the "+" character) the numbers are multiplied (e.g., 3x3 or 3a3 => nine cable connections).
- For a combination <number> + <number> the numbers are added (e.g., 3+3 => six cable connections).

Length:

Enter the length of the cable here (including the unit). If you do not enter a unit, the unit specified in the project settings will be used. An overview of the possible units can be found in the section "[Connections: Units for Lengths and Cross-sections](connectionbrowsergui_k_einheitenverbindungen.htm)".

Connection: Cross-section / diameter:  
Unit:

The connection cross-section or diameter is adopted from the parts management and can be used as filter criteria when selecting devices. Click [...] to open the Cross-sections / diameters dialog and select a cross-section / diameter (with the associated unit) from the list.

If you selected a predefined cross-section / diameter from the Connection: Cross-section / diameter field, the associated unit is automatically transferred to the Unit field. Use the drop-down list to select another unit. An overview of the possible units can be found in the section "[Connections: Units for Lengths and Cross-sections](connectionbrowsergui_k_einheitenverbindungen.htm)".

Voltage:

Enter the voltage of the cable here (including the unit of measure). This field is automatically filled during part selection.

Name of shield:

This field is only available for [shields](Glossary_o_abschirmungen.htm). Specify the name of the shield here. When you use the existing device tags, this field is filled automatically if an existing function of the "Shield" type is used (no connection, but a shield symbol).

Main function:

Select this check box if the current function is a main function.   
When using a DT for which there is already a main function, when using a placed main function, or when [placing](Glossary_o_auflegen.htm) an already placed main function, this property will automatically be switched off at the target function, that is, the check box is deactivated.

![](../Pictures/Gui/ALL/note.png)Note:

The setting is automatically compared to the check box of the same name in the Symbol / function data tab.

[Properties group box](devicetaggui_r_gruppenfeldeigenschaften.htm)

For use in reports (e.g., in the cable diagram), there are preformatted properties that collect specific combinations of the properties entered above:

- Cable / Conduit: Cross-section / diameter with unit (e.g.: 1.5 mm²)
- Cable / Conduit: Number of connections and cross-section / diameter (e.g.: 4x1.5)
- Cable / Conduit: Number of connections, cross-section / diameter with unit (e.g.: 4x1.5 mm²)
- Cable / Conduit: Number of connections, cross-section / diameter with unit, length with unit (e.g.: 4x1.5 mm² 50 m)
- Cable / Conduit: Type, number of connections, cross-section / diameter with unit (e.g.: NYY-J 4x1.5 mm²)
- Cable / Conduit: Type, number of connections, cross-section / diameter with unit, length with unit (e.g.: NYY-J 4x1.5 mm² 20 m).

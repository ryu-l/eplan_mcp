# Dialog Add-ons

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Add-ons

In this dialog, you manually register [add-ons](Glossary_o_add_ons.htm) or delete the registration of add-ons.

Overview of the main dialog elements:

All the installed add-ons are displayed in the table. These can be both add-ons supplied by EPLAN and add-ons created by the user. An add-on extends the default scope of delivery of an EPLAN product variant with additional functionalities or makes additional data available. The EPLAN add-ons are normally registered automatically. You register own add-ons manually if these are stored in a local directory. To do this, select the add-on by clicking ![](../Pictures/Gui/ALL/all_new_as.png) (New) and then select the Registered check box.

![](../Pictures/Gui/ALL/note.png) Note:

Add-ons can be registered automatically if these are located on a server directory. To this purpose the associated file install.xml has to lie in the directory path that you specified in the dialog Settings: Add-ons.

Toolbar:

| Button | Meaning |
| --- | --- |
| (New) | Opens the Select add-on dialog, in which you can select the install.xml file of the respective add-on. |
| (Delete) | Deletes the add-on from the table. For this to be possible the add-on may not be registered. EPLAN add-ons cannot be deleted. |

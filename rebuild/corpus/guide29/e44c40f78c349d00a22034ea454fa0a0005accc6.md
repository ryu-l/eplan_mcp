# Planning objects: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_planungsobjekte.htm)

### Planning objects

Pre-planning

Planning objects define part of a machine / plant in the pre-planning; they each describe a device and reference the functions of a device. In this, the device represents the functionality of a machine / plant (e.g., motor for a conveyor belt).

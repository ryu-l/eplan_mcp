# P004101: The rack '<x>' is not connected by a bus extension cable with all other racks of the station '<y>'

### Causes

#### Possibility 1

Within a configuration project a [rack](Glossary_o_baugruppentraeger.htm) is not connected to the racks of the same workstation.

#### Possibility 2

Within a configuration project a rack is connected to the other racks of the same workstation with a different connection than a bus extension [cable](Glossary_o_kabel.htm). This means that at least one of the [bus ports](Glossary_o_sps_busanschluesse.htm) connected to each other is not assigned to the bus system setting "Local-Bus: Extension". This setting is required when the racks are assigned to the same station.

### Solution

#### Possibility 1

1. Locate the PLC box of the rack '<x>' in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Connect a bus port of this rack with a bus port of a different rack within the same workstation, so as to [form](Glossary_o_verlauf.htm) [autoconnecting](Glossary_o_autoconnecting.htm) [lines](Glossary_o_leitungen.htm).
3. Call up the [property dialog](Glossary_o_eigenschaftendialog.htm) of the first bus port.
4. Bring the Bus data tab to the front.
5. Select the "Local-Bus: Extension" entry from the Bus system drop-down list.
6. Click [OK].
7. Repeat the [settings](Glossary_o_einstellungen.htm) described under Point 3 to Point 6 for the second bus port.
8. Then start a new check run.

#### Possibility 2

1. Locate the PLC box of the rack '<x>' in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Call up the [properties](Glossary_o_eigenschaften.htm) dialog of the bus port that is connected to the bus port of another rack within the same workstation.
3. Bring the Bus data tab to the front.
4. Select the "Local-Bus: Extension" entry from the Bus system drop-down list.
5. Click [OK].
6. Locate the bus port connected to the first bus port in the schematic by selecting the function Go to 2nd coordinate from the popup menu of the message management.
7. Repeat the settings described under Point 2 to Point 5 for the second bus port as well.
8. Then start a new check run.

#### Possibility 3

1. Open the property dialog of the PLC box for one of the two racks.
2. Bring the PLC structure data tab to the front.
3. Change the workstation name.
4. Click [OK].
5. Then start a new check run.

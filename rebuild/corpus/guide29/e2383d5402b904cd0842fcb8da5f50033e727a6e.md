# Renumbering Items

Precondition:

You have opened a project. The project contains [devices](Glossary_o_betriebsmittel.htm) to which parts are assigned.

1. Select the menu item Project data > Parts / Devices > Bill of materials navigator.
2. Select the [items](Glossary_o_bauteile.htm) to be numbered in the Bill of materials - <Project name> dialog.
3. Select the Add item numbers popup menu item.
4. In the [Number items](partslistgui_d_positionsnummerierung.htm) dialog, specify the criteria for the assignment of the item numbers.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the Preview of result check box is not activated, the new numbering is written directly to the bill of materials. Otherwise the Number items: Preview of result dialog is opened.
6. Edit the desired item numbers in the Target column of the Number items: Preview of result dialog.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new numbering is written to the bill of materials.

![](../Pictures/Gui/ALL/note.png)Note:

If several parts are assigned to one function, the Item number list ([ID](Glossary_o_id.htm) 20346) property displays the item numbers of all the parts separated by commas. This property allows you to display the item numbers of the parts at the [functions](Glossary_o_funktionen.htm) in the graphical editor or output them in [reports](Glossary_o_auswertungen.htm).

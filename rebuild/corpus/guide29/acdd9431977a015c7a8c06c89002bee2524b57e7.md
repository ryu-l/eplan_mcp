# Dialog Run: Automated processing

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have selected project pages or a project in the page navigator. Utilities > Automated processing.

In this dialog, you use the scheme to select the sequence of [actions](Glossary_o_aktionen.htm) that are to be run in an automated manner.

Overview of the main dialog elements:

Scheme:

Choose the scheme that you would like to use from the drop-down list. Click [...] to open the Settings: Automated processing dialog.

Actions:

The list shows the actions that are stored in the selected scheme.

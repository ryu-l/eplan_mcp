# Drawing Splines

Splines are defined using the two end points of a curve and the tangents through two control points.

Precondition:

You have opened a page, [form](Glossary_o_verlauf.htm), plot frame or symbol.

1. Select the following menu [items](Glossary_o_bauteile.htm): Insert > Graphic > Spline
2. Specify the starting point, the end point and the first and second control points of the spline.
3. End the action via the Cancel action popup menu item or via the [Esc] button.

# Dialog Configure properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have opened a dialog in which you can use a table to assign [properties](Glossary_o_eigenschaften.htm) to an object (such as a project, a page, a [form](Glossary_o_verlauf.htm), ...). Select the Configure popup menu item.
- You have selected one or more [objects](Glossary_o_objekte.htm) (texts, components, [segments](Glossary_o_segmente.htm), graphical elements) in the graphical editor, in the [layout space](Glossary_o_bauraum.htm) or in a navigator. Edit > Property overview. In the property overview click next to the drop-down list on [...].

Property dialogs: In this dialog select the properties and their sequence, to be shown by default in the table with each object in the relevant function category.

Property overview: In this dialog select the properties and their sequence, to be shown in the property table of the property overview.

Overview of the main dialog elements:

![](../Pictures/Gui/ALL/note.png)Note:

The fields Scheme and Description are only available to you for the property configuration of the property overview and for [user-defined](Glossary_o_benutzerdefiniert.htm) property [configurations](Glossary_o_konfigurationen.htm).

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

List:

The list contains the currently selected properties. By using ![](../Pictures/Gui/ALL/all_new_as.png) (New) you can select further properties and transfer them to the list. The arrow buttons can be used to change the order of the properties.

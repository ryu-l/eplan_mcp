# Creating Sections

Sections are always assigned to a project option and are stored in the project. For this reason, sections must be created in the project where they will be later used.

Precondition:

You have opened a project. You have selected a schematic section in the graphical editor, or you have selected pages in the page navigator or [functions](Glossary_o_funktionen.htm) in one of the [project data](Glossary_o_projektdaten.htm) [navigators](Glossary_o_navigatoren.htm). Or you have selected [objects](Glossary_o_objekte.htm) in a [layout space](Glossary_o_bauraum.htm).

1. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Project options > Create section
2. In the
   Section dialog, in the
   Project options group and Project option group boxes, select the [project options](Glossary_o_projektoptionen.htm) group and the project option that the section is to be
   assigned to from the Name drop-down list.
3. Alternatively,
   you can manually enter a new project options group and / or project option.
     
     
   ![](../Pictures/Gui/ALL/arrow.png) The Description fields of the project
   options group and / or project option are
   made editable.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you leave the Project options group field empty (or delete the entry) then the project option is not assigned to a
   project options group.
4. If desired,
   enter a description into the Description field of the project options group
   and / or project option.
5. Enter
   a name for the section in the
   Name field.
6. If desired,
   enter a description text into the Description
   field.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The description is a multi-language text and is displayed by default in the tree view next to the name, separated by a blank and within round brackets.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you entered a new name for the project options group
   and / or project option then this project options group and / or project option
   is generated.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The section is assigned to the (already existing
   or new) project option and this project option is switched on.

![](../Pictures/Gui/ALL/info.png)Tips:

- Sections can also be created using the popup menu in the project options navigator. Once you have selected the desired objects (schematic section, pages, functions), select a project option or a section in the Project options - <Project name> dialog and then select the New > Section popup menu items. In the Section dialog, the named of the current project options group and project option are already set, and you can accept these or overwrite them. The section is stored as soon as you close the dialog by clicking [OK].
- As with most editing operations in the graphical editor, the reverse method is also supported (first call up the command and then select the elements).

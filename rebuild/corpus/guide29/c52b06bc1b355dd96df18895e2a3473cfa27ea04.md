# P004004: Missing bus port on overview

### Description

You cannot make a cross-reference between a bus port in the schematic and a bus port on the overview page.

### Cause

A bus port in the schematic cannot be cross-referenced with the corresponding bus port because of a missing device tag in the PLC box in the overview.

### Solution

Enter the same DT at the bus port in the schematic and in the overview, and start a new check run.

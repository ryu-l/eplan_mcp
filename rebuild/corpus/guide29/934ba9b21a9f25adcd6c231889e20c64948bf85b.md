# P501023: The function templates of the assembly / module <x>, variant <y> are not up-to-date

### Cause

An assembly / module <x> in the variant <y> whose [function templates](Glossary_o_funktionsschablonen.htm) are no longer up-to-date was found in the parts database to be checked.

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective [part](Glossary_o_artikel.htm) is already marked in it.
2. Select the [Extras] > Sum up function templates menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The function templates located at the [assemblies](Glossary_o_baugruppen.htm) / [modules](Glossary_o_module.htm) are summed up and updated.
3. Then start a new check run.

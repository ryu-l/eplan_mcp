# P005089: Connection definition point lies on a bundle

### Cause

A connection definition point or a [cable](Glossary_o_kabel.htm) definition line was inserted on a [bundle](Glossary_o_buendel.htm) drawn in the schematic.

### Solution

1. Locate the connection definition point or the cable definition line in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Delete the connection definition point or the cable definition line from the bundle.
3. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

We recommend that you insert [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) or [cable definition lines](Glossary_o_kabeldefinitionslinien.htm) as far as possible on multi-line [connections](Glossary_o_verbindungen.htm) entering or exiting on the bundle in order to obtain unique connection information in the [reports](Glossary_o_auswertungen.htm), for example in the cable diagram.

# Dialog Import device data

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Project data > Devices > Import

In this dialog, you execute the import of data from external programs (other CAE systems, ERP systems, Excel, etc.) into an EPLAN project in order to [create](Glossary_o_erstellen.htm) a complete [panel layout](Glossary_o_schaltschrankaufbau.htm) including [routing connections](Glossary_o_verlegeverbindungen.htm) on the basis of such data. Device tag / terminal strip lists with the file extensions TXT and CSV as well as text files with the file extension ASC are imported.

Overview of the main dialog elements:

Type of data source:

The following file types are available from the drop-down list:

- Text (\*.txt, comma-delimited Unicode file (\*.csv), ASCII file (\*.asc))
- MS Excel (\*.xls, \*.xlsx, \*.xlsb, \*.xlsm).

Data source:

This field displays the file name of the device tag lists to be imported.

Field assignment:

Here you select the import scheme for the data to be imported. A scheme by the name "Default" has been predefined. Click [...] to open the Field assignment dialog. This dialog allows the assignment of an external data field from the data source to an EPLAN property.

Popup menu:

From within the Data source field you can open a popup menu that makes the following menu [items](Glossary_o_bauteile.htm) available:

- Popup Menu Items for the Editing of Values

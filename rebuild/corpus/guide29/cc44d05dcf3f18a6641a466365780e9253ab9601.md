# Tab Part placement

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Project data > Parts / Devices > 2D panel layout navigator. You have double-clicked on an item placed on the mounting panel (or selected the Properties popup menu item; in this way, multiple [items](Glossary_o_bauteile.htm) can be selected). In the Properties <...> dialog, select the Part placement tab.

In this dialog you specify the [properties](Glossary_o_eigenschaften.htm) for the item placed on the mounting panel.

Overview of the main dialog elements:

Displayed DT:

The displayed DT is displayed in the graphical editor on the [component](Glossary_o_schaltzeichen.htm). If you have defined in the project [settings](Glossary_o_einstellungen.htm) that [devices](Glossary_o_betriebsmittel.htm) are to be automatically numbered when [symbols](Glossary_o_symbole.htm) are inserted, then a DT is automatically suggested here. You can accept this DT or overwrite it manually.

In addition you can use the [popup menu or the [...] button](devicetaggui_r_feldsichtbaresbmk.htm) to [create](Glossary_o_erstellen.htm) or select a DT.

Full DT:

This field displays the full DT (i.e. structure identifier of the current environment + displayed DT) of the component / item. Use the [...] button to open the Full DT dialog. You can edit the [structure identifiers](Glossary_o_strukturkennzeichen.htm) there and select, e.g., another [mounting location](Glossary_o_einbauort.htm).

Designation:

The designation already assigned to terminals is displayed here and can be changed. This field has no significance for all other [functions](Glossary_o_funktionen.htm).

Function definition:

The function definition of the [part](Glossary_o_artikel.htm) placement displayed here is automatically assigned, depending on the function definition of the associated item. Click [...] to open the Function definitions dialog and select a different function definition if required.

Part:

This field displays the part number already assigned. Click [...] to open the Part selection dialog and select a different part if necessary.

Representation type:

Select the desired representation type from the drop-down list. This is used to set the type of placement. Placements of the representation type "Detailed [panel layout](Glossary_o_schaltschrankaufbau.htm)" can only be used once per part placement. In addition, placements of the representation type "Detailed panel layout" are not taken into account in the bill of materials area.

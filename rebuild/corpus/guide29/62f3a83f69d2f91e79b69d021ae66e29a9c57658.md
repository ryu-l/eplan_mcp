# Reading in Hose Line Data

Before you can configure [hose lines](Glossary_o_schlauchleitungen.htm), you have to read the hose line data, that as a rule only consist of the full DT of the hose [lines](Glossary_o_leitungen.htm), from EPLAN Fluid into the hose line configurator.

### [ClosedReading in hose line data by means of the add-on variant](javascript:void(0);)

#### Reading in hose line data directly from the fluid schematic

Preconditions:

- You have installed the hose line configurator as an add-on variant of EPLAN Fluid.
- You have started EPLAN Fluid and opened a project.
- In this project you have created one or more fluid schematic pages that contain hose lines which you have inserted by means of the Hose.ems symbol macro.
- You have assigned a DT to the hose lines as minimum information.

1. In the project mark the hose lines that you want to configure.
2. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Connections > Configure hose lines  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Configure hose lines dialog is opened.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All the hose lines marked in the project are automatically displayed with the full DT and offered for editing in the table of this dialog.

#### Importing hose line data through an exchange file

Preconditions:

- You have installed and started the hose line configurator as an add-on variant of EPLAN Fluid.
- You have received an exchange file as a tab-separated Unicode text file with incomplete hose line data from, for example, the design department.

1. In the Configure hose lines dialog select the menu items Extras > Import.
2. In the subsequent dialog select the storage location and the name of the exchange file and click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The imported hose line data are displayed in the Configure hose lines dialog and can now be edited.

### [ClosedReading in hose line data by means of the stand-alone variant](javascript:void(0);)

Preconditions:

- You have installed the hose line configurator as a stand-alone variant.
- You have received an exchange file as a tab-separated Unicode text file with incomplete hose line data from, for example, the design department.

1. Start the hose line configurator by double-clicking the program icon with the hose line on the Windows Desktop.
2. Select the menu items File > Configure hose lines.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Configure hose lines dialog is opened.
3. Select the menu items File > Open.
4. In the subsequent dialog select the storage location and the name of the exchange file and click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The imported hose line data are displayed in the Configure hose lines dialog and can now be edited.

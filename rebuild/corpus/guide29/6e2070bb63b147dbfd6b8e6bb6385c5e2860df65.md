# Copying Symbols

When copying [symbols](Glossary_o_symbole.htm) an exact copy of the original symbol is created and it is possible to transfer symbols from one symbol library to another.

Precondition:

You have opened a project and at least one symbol library.

1. Select the following menu [items](Glossary_o_bauteile.htm): Utilities > Master data > Symbol > Copy
2. In the Symbol selection dialog, select the symbol(s) you would like to copy. Multiple selection is possible here.
3. Click [OK].
4. Select the symbol library to which you would like to copy the symbols under Target in the Copy symbols dialog: Open the drop-down list in the Symbol library field.
5. In the Number field overwrite the default or open the drop-down list of unallocated numbers.
6. In the Name field enter the symbol name by overwriting the default <(Original name (copy)> for copies in [symbol libraries](Glossary_o_symbolbibliotheken.htm) where this name already exists or <Original name> if no symbol exists with this name).
7. In the Description field enter a descriptive text for the symbol.
8. Select the check box in the With variants field if the symbol should be copied together with its existing [variants](Glossary_o_varianten.htm). If the check box is deselected, then only the first existing variant will be copied.
9. Click [OK].

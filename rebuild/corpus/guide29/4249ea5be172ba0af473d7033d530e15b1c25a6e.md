# Creating 3D Macros

3D [macros](Glossary_o_makros.htm) can be created as follows:

- Manually by saving selected [objects](Glossary_o_objekte.htm) from a [layout space](Glossary_o_bauraum.htm)
- Manually or automatically from imported STEP files (\*.ema only)
- Manually or automatically from a macro project.

### [ClosedCreate a 3D macro by saving selected objects](javascript:void(0);)

Precondition:

You have opened a project. A layout space is open. The layout space contains 3D [part placements](Glossary_o_artikelplatzierungen.htm) or objects that have been loaded via Layout space > Import (3D graphic).

1. Select the menu item Edit > Create window macro / symbol macro.
2. Draw a border around the objects that should belong to the macro.
3. In the Save as dialog, enter an identifying name and optionally a description text for the 3D macro.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the Representation type field, the entry "3D mounting layout" is displayed, which cannot be modified.
4. From the Variant field select the required variant for the macro.  
     
   ![](../Pictures/Gui/ALL/arrow.png) "Variant A" is the default setting. You can [generate](Glossary_o_erzeugen.htm) further [variants](Glossary_o_varianten.htm) by rotating the macro geometry, or by changing the handle and saving the 3D macro under the same name, but as a different variant.
5. Click [OK].
6. Select the Edit > Device logic > Handle menu [items](Glossary_o_bauteile.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The cursor will be surrounded by a square, that you can set to 3D snap points on the geometry, to define the handle. Once the handle is placed, the Save as dialog reappears. The defined handle is always projected onto the placement area.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The 3D macro is saved to the set directory. It can then be called up for placement.

### [ClosedCreate a 3D macro from an imported 3D graphic](javascript:void(0);)

3D graphic files can be imported in STEP format. You can generate files of this type with a 3D CAD system, or obtain them from the storage mediums of various manufacturers. After importing the original position of the graphic can be influenced by defining and rotating a placement area so that the desired areas are always rotated to the placement position when the macro is placed as a window macro and as a device.

Precondition:

You have opened a project. A layout space is open.

1. Select the menu items Layout space
   > Import (3D graphic).
2. In
   the Open dialog, select a directory and in this, select a file containing the 3D graphic in STEP format to be imported, and click [Open].   
     
   ![](../Pictures/Gui/ALL/arrow.png) The 3D graphic from the STEP file is loaded in the layout space and displayed as a 3D object.
3. Depending on the quality of the source data, the 3D graphic may have to be edited, before it can be saved as a 3D macro. In order to achieve uniform behavior when [placing](Glossary_o_auflegen.htm) a macro that contains rotated graphics, select the menu items Edit > Device logic > Placement area > Define and Edit > Device logic > Placement area > Rotate.
4. Irrespective of the placement position you can use Edit > Graphic > Unite to combine all the items of the layout space so that a 3D macro is handled like one item when used.

![](../Pictures/Gui/ALL/note.png)Note:

The uniting of 3D bodies is not suited to reduce the amount of data in the macro to be generated. If the imported STEP file contains several identical and very detailed parts, this may lead to an increase of the amount of data after uniting. This directly influences the size of the macro files since macros cannot be compressed due to the system's way of operation.

To reach an acceptable size of the macro file you should thus refrain from uniting imported common parts and generate the macro with the imported single parts.

5. Save the 3D macro via the Edit > Create window macro / symbol macro menu items.

### [ClosedGenerate a 3D macro from 3D files](javascript:void(0);)

This function works in the same way as [Generating Macros from DXF / DWG Files](macrosgui_h_makrosausdxf.htm).

1. Select Utilities > Generate macros > From 3D files.  
     
   ![](../Pictures/Gui/ALL/arrow.png) 3D [window macros](Glossary_o_fenstermakros.htm) (\*.ema) are generated directly from single or multiple STEP files, without being loaded into a layout space and edited before saving.

### [ClosedGenerate a 3D macro from a macro project](javascript:void(0);)

In the same way as 2D macros, 3D macros can be generated [automatically from macro projects](macrosgui_h_makrosausmakroprojekt.htm).

1. Select the menu items Project data > Macros > Generate automatically.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All 3D macros or each individually selected one are saved from the macro project layout spaces as \*.ema or \*.ems files.

![](../Pictures/Gui/ALL/note.png)Note:

Please note our [Recommendations for working with 2D and 3D macros](cabinetgui_k_3dmakros.htm#EmpfehlungenMakros).

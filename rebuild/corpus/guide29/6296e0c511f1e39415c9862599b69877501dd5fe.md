# Creating User-Defined Property Configurations

Wherever the [properties](Glossary_o_eigenschaften.htm) of an object are listed in a table (project, page, device properties, etc.), you have the opportunity to [create](Glossary_o_erstellen.htm) separate property [configurations](Glossary_o_konfigurationen.htm). Properties from different groups can be combined in this way and saved in a [user-defined](Glossary_o_benutzerdefiniert.htm) property configuration.

Precondition:

You have opened the [property dialog](Glossary_o_eigenschaftendialog.htm) for an object, e.g. the Project properties dialog.

1. Select the "User-defined" entry from the Category drop-down list.
2. Select the Configure popup menu item.
3. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) next to the Scheme drop-down list of the Configure properties dialog.
4. Create a new scheme and click [OK].
5. Edit the properties, i.e. add further properties or delete any properties that are not required.
6. Use the arrow buttons to change the order of the properties when they are displayed.
7. Click ![](../Pictures/Gui/ALL/all_save_as.png) (Save) to save the properties selected under the scheme name. Or click ![](../Pictures/Gui/ALL/all_export_as.png) (Export) to export the property configuration and make it available to other users.
8. Click [OK].

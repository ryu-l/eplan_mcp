# Tab Free properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have marked a [part](Glossary_o_artikel.htm) in the tree or list.

In this tab, you can enter additional text information which is independent of the part type selected ([component](Glossary_o_schaltzeichen.htm), [cable](Glossary_o_kabel.htm), etc.) These [properties](Glossary_o_eigenschaften.htm) are then identical for all [variants](Glossary_o_varianten.htm) of a part.

![](../Pictures/Gui/ALL/note.png)Note:

We recommend using the user-defined properties for the entry and display of additional information in the parts management. These offer you more setting options during the configuration than the free properties and behave in a way analogous to the [user-defined](Glossary_o_benutzerdefiniert.htm) properties for the project. The free properties only exist for reasons of compatibility.

Overview of the main dialog elements:

Scheme:

Choose the scheme that you would like to use from the drop-down list. Or click [...], to edit an existing scheme or [create](Glossary_o_erstellen.htm) a new scheme using the Configure free properties dialog.

[Assign scheme]:

Click this button to assign the scheme selected in the drop-down list.

![](../Pictures/Gui/ALL/note.png)Note:

Take into account that only filled cells can be overwritten by data from the scheme. Empty contents are ignored.

Table:

In the "Description", "Value" and "Unit" cells you enter additional text that you wish to use for particular parts irrespective of the part type.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

![](../Pictures/Gui/ALL/note.png)Note:

Each field of each free property can be used for filtering with the field-based filter.

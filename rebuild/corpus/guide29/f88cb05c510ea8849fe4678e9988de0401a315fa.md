# Generating Macros from DXF / DWG Files

1. Utilities > Generate macros > From DXF / DWG files
2. In the DXF / DWG file selection dialog select the desired macro(s).
3. Click [Open].
4. In the DXF / DWG import dialog select the desired scheme and specify the target directory.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected files are saved in the specified directory (default is <Drive\_EPLAN>:<Program directory>\Macros\<Company code) as [window macros](Glossary_o_fenstermakros.htm) <original\_name>.ema and can be inserted like "normal" window [macros](Glossary_o_makros.htm) in EPLAN. When inserting the resulting window macros, a "[DXF](Glossary_o_dxf.htm)" is displayed for macros from DXF files and a "[DWG](Glossary_o_dwg.htm)" is displayed for macros from DWG files.

# Dialog Format: Comment

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the [properties](Glossary_o_eigenschaften.htm) dialog for a function, a symbol, or a project. In the Properties field, you have selected the Block property: Format [n] property and clicked [...] in the Value column.

- In the Format dialog, in the Available format elements list, select the Comment format element and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).
- In the Format dialog, in the Selected format elements list, select an existing format element of the Comment type, and click ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit).

In this dialog, you enter a comment within the format group, which you can use to document your format [settings](Glossary_o_einstellungen.htm). The comment can only be entered once for each property, and is always sorted to the end. It is not output in the results.

Overview of the main dialog elements:

Comment:

Enter any desired text here. As with all format strings, the comment is language-neutral.

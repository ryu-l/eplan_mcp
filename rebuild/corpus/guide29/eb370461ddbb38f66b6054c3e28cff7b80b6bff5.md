# Graphical Editor Control Elements

For the control elements in EPLAN's graphical editor, the following applies:

### Visible page area

The [visible page area](Glossary_o_sichtbarerseitenbereich.htm) is shown in the graphical editor and output when printing or when the page is output as PDF. It is determined depending on whether a page is assigned a plot frame:

- If a page has no plot frame, then all elements located on the page [form](Glossary_o_verlauf.htm) the visible page area.
- If a page has a plot frame, then only those graphical elements within the plot frame constitute the visible area. Elements outside the plot frame are ignored. Texts are always ignored, since they may extend over the edges of the plot frame.

### Status bar

In the status bar of the graphical editor, the following information is shown:

- Cursor position (depending on the coordinate system in X / Y or RX / RY coordinates)
- Grid size and display (on/off)
- Page report (logic or graphic) and the current data entry language, if text is input
- Page scale
- Status of [connections](Glossary_o_verbindungen.htm): If the # sign is displayed, the project has out-of-date connections. If the character \* is additionally displayed, the opened page contains out-of-date connections.  
  The \* character is also displayed if, prior to the backup of [wire ducts](Glossary_o_verdrahtungskanaele.htm), [routing ranges](Glossary_o_verlegebereiche.htm), [wiring cut-outs](Glossary_o_verdrahtungsdurchbrueche.htm) and manual [routing paths](Glossary_o_strecken.htm), the program has determined that the routing path network of the [layout space](Glossary_o_bauraum.htm) is not up-to-date.
- The character ~ indicates that the routing path network is not up-to-date in a layout space of the project. If the routing path network has changed in a layout space, the character ~ is displayed until routing was successful in the project.  
  When editing [routing path networks](Glossary_o_streckennetze.htm) in the [topology](Glossary_o_topologie.htm), it is assumed that the [route](Glossary_o_verlegen.htm) is not up-to-date any more when routing paths, [routing points](Glossary_o_verlegepunkte.htm), topology [interruption points](Glossary_o_abbruchstellen.htm), or topology targets are saved. This state of the route not being up-to-date is also indicated by the character ~ in the status bar. The character is displayed until routing has been successfully performed in the project.

- Error icon ![](../Pictures/Gui/ALL/erroricon_error_systemmessages.png) : If a new error occurs after the [system messages](Glossary_o_systemmeldungen.htm) dialog was last opened, then this icon is displayed at the right edge of the status bar. Double-clicking this icon leads you to the system messages dialog. Once you have viewed the system message and closed the dialog, the icon is removed.
- "+" character: If you have activated "advanced" support log mode (using the "ELogFileConfigToolu.exe" logging program), this is indicated by this sign, drawing your attention, if necessary, to the reason why EPLAN has slowed down. In this case, you can deactivate "advanced" mode.

If you are on a schematic page, then the status bar may look like the following:

|  |  |  |  |
| --- | --- | --- | --- |
| RX: 42.00 RY: 30,00 | ON: 4.00 mm | Logic 1:1 | #\* |

The cursor is located in position RX=42.00 and RY=30.00, with the units being stated in [grid](Glossary_o_raster.htm) increments.  
The grid is turned on, and the grid size is 4.00 mm.  
The page is a logic page with a scale of 1:1.  
The connections on the page are not current.

#### Use the keyboard

The cursor can be controlled with the keyboard; the grid is taken into account when doing this. The increment can be set to several [levels](Glossary_o_etagen.htm).

### Tooltip

If you move the cursor over an object in the graphical editor (2D or 3D), the object is displayed in a different color. If the cursor hovers above the object, a tooltip displays information on the object. For a [component](Glossary_o_schaltzeichen.htm), for instance, the DT and the function definition are displayed.

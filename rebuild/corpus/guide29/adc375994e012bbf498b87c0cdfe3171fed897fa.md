# P001008: A terminal connection point has too many targets: <x>. Maximum number of targets allowed: <y>

### Cause

You connected at least one of the two terminal function [connections](Glossary_o_verbindungen.htm) with more components than the specified number.

### Solution

#### Possibility 1

Double-click the terminal in the schematic and in the Properties <...> dialog select the Symbol / function data tab. In the Function data group box, click [Logic]. In the Connection point logic dialog, make sure of which values are set in the Number of targets row for both function [connection points](Glossary_o_anschluesse.htm) of the terminal. Increase your requirements on the defined value for one or both function connection points.

#### Possibility 2

Double-click the terminal in the schematic and in the Properties <...> dialog select the Symbol / function data tab. In the Function data group box, click [Logic]. In the Connection point logic dialog, make sure of which values are set in the Number of targets row for both function connection points of the terminal. Delete the excess components placed in each terminal function connection in the schematic.

Refresh the connections and then start a new check run.

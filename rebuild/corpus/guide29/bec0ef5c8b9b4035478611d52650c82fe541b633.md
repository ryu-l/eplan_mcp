# Loading Directories and Projects

To access existing [projects](Glossary_o_projekte.htm) from the project management, you must [load](Glossary_o_laden.htm) the project directory containing the project into the project management. You can only load directories that contain EPLAN projects into project management.

Precondition:

There must be projects present in the directory that you would like to load.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project > Management
2. In the Project management dialog, select the menu item [Extras] > Load directory.
3. Select a directory level from the Select directory dialog as a starting directory, and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) EPLAN searches all subdirectories for projects and loads these, with the directory structure, into the project management.

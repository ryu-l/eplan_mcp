# Tab Property assignment

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management > [Extras] > Import. You have selected the entry for an [eCl@ss](Glossary_o_eclass.htm) version in the File type field and select an XML file with the parts records in the File name field and clicked [OK]. In the eCl@ss import dialog click the [...] button next to the Settings field and select the Property assignment tab.

The eCl@ss [properties](Glossary_o_eigenschaften.htm) can be assigned to the [part](Glossary_o_artikel.htm) properties of the parts management in this tab.

![](../Pictures/Gui/ALL/note.png)Note:

The eCl@ss classes must have been selected beforehand on the Class structure assignment tab.

Overview of the main dialog elements:

Toolbar:

| Button | Meaning |
| --- | --- |
| (New) | Opens the Property selection dialog. Allows you to select one or more eCl@ss characteristics. In this case you can select from the eCl@ss properties drop-down list whether you want to use eCl@ss properties of the "Advanced" type (default setting) or the "Basic" type. "Advanced" designates a structured properties tree, whereas "Basic" represents a flat properties list.  With the filter you can limit the number of displayed properties. In the Filter field enter the text to be found and click  (Find). Both the names of the properties as well their description are searched. |
| (Delete) | Allows one or more property assignments to be deleted from the scheme. |

Table

To assign a part property or a [user-defined](Glossary_o_benutzerdefiniert.htm) property to a selected eCl@ss property, click the [...] button in the Part property or User-defined property column. This opens the Property selection dialog in which you can select the desired property from the list of available properties. If a part property is already assigned, no user-defined property can be assigned and vice versa.

Whether you assign one or more part properties or user-defined properties depends on the cardinality of the eCl@ss property. For further information refer to the topic [Parts management: Assignment of eCl@ss Properties to EPLAN Part Properties](partsimportbmecatgui_k_mappingdetails.htm).

In the Condition column you can specify filter criteria by clicking the [...] button in a field and selecting the criteria in the subsequent dialog Filter. In the process ![](../Pictures/Gui/ALL/all_new_as.png) (New) is used to open the Characteristic selection dialog. Select the eCl@ss property for which the filter is to be defined and specify the condition (meaning operator and value) in the Filter dialog.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Let us assume that you always want to import the file paths from documents of the type "2D graphic" at the same point, for example in the part property External document: File / hyperlink 1, irrespective of the sequence of the properties in the import file. Then you specify the part property External document: File / hyperlink 1 for the characteristic "Source as path specification" and [create](Glossary_o_erstellen.htm) the condition "Document type = 2D graphic". (The two properties "Source as path specification" and "Document type" can be accessed in the Characteristic selection dialog below the folder Supplementary documentation > Supplementary documentation.)

![](../Pictures/Gui/ALL/note.png)Notes:

- The eCl@ss properties cannot be assigned to different EPLAN properties depending on the class. This is also not necessary since the eCl@ss properties are described uniquely through the [ID](Glossary_o_id.htm) and definition.
- Is it possible to assign several eCl@ss properties to one EPLAN part property. In this case conflicts can occur during importing if a part has both eCl@ss properties. A system message is output and the first imported property "wins".
- Values and eCl@ss properties that are imported in multi-language fields are imported in the languages of the [BMEcat](Glossary_o_bmecat.htm) catalog, in as far as they exist.
- The unit of the values is appended, except when importing is carried out into the free properties. In this case it is transferred to the Unit field of the Free properties tab. If applicable, conversion has to be carried out for fields of the parts database with a fixed unit.
- The Part number property always has to be filled so that a part can be imported.

# Connections

A connection is a line between two [connection points](Glossary_o_anschluesse.htm) that is used to transmit information, electric power, liquids, or air (pressure) from a source to a target. Because [connections](Glossary_o_verbindungen.htm) can stretch over many pages, they are not updated online in EPLAN, but rather generated offline. The following editing options are available:

- Components are automatically connected if their connection points are precisely opposite ([autoconnecting](Glossary_o_autoconnecting.htm)). When inserting and moving [symbols](Glossary_o_symbole.htm), a preview of the autoconnecting [lines](Glossary_o_leitungen.htm) is shown.
- Connection junctions can be represented either as simple points or with target specification. In the latter case, the connection sequence is directly visible and is determined by the internal logic of the connection symbol.
- There are a wide variety of connection types that can be displayed and differentiated, for example hydraulic, pneumatic, electrical, cables, tubes, pipes, [wires](Glossary_o_draehte.htm), intrinsically safe, etc.
- You can specify defaults for electrical or fluid connection [properties](Glossary_o_eigenschaften.htm) on a project-wide basis.
- Using [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm), information can be assigned to each connection, e.g. [connection point designations](Glossary_o_anschlussbezeichnungen.htm), cross-section / diameter, connection color / number, connection designation, etc. This connection data can be reported and output in [forms](Glossary_o_formulare.htm).
- Cable definition lines are used to represent complete cables (e.g., bus cables) or multiple wires of a [wiring](Glossary_o_verdrahtungen.htm) system that connect two [items](Glossary_o_bauteile.htm).
- You can define the order of the targets within a net. To do this, all the connections that are directly linked to one another are displayed in a dialog and can be assigned from there.
- Connections can be automatically designated. You can then specify the criteria to be used and the connections to be made in this designation.
- The connection color can be saved as a multilingual text. You can specify which color name is assigned to a color code and have the color name automatically translated.

# Dialog Rights management: Operating mode

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Rights management > Operating mode

In this field you specify the operating mode.

Overview of the main dialog elements:

If you have selected the Operating mode folder in the left-hand field, then you can set the desired operating mode in the right-hand field:

Log on:

EPLAN operates using a [rights management](Glossary_o_rechteverwaltung.htm) system. Every user must log on using their user name. The current Windows user name is entered as a default value in the EPLAN logon dialog. The user must then only enter their password (which was specified in the rights management).

Logging on of users who were imported from Windows is not supported in this operating mode since a password check is not carried out in EPLAN in the Active Directory.

Log on with Windows user name:

EPLAN operates using a rights management system. The user can directly log on to EPLAN using their Windows user name and password. If the (locally) logged on Windows user is registered as an EPLAN user, then the logon occurs automatically and the user does not need to enter their user name and password into EPLAN.

This operating mode also allows the automatic logon of users who were imported from Windows (as Active Directory users or groups).

Without rights management:

EPLAN is operated without rights management, i.e., EPLAN uses the Windows logon name without a password and assigned administrator rights to all EPLAN users.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call (for the property overview):](javascript:void(0);)

You have opened a project. You have selected one or more [objects](Glossary_o_objekte.htm) (texts, components, segments, graphical elements) in the graphical editor, in the [layout space](Glossary_o_bauraum.htm) or in a navigator. Edit > Property overview. In the property overview click next to the drop-down list on [...]. In the Configure properties dialog for the Configuration click ![](../Pictures/Gui/ALL/all_new_as.png) (New).

In this dialog you select the [properties](Glossary_o_eigenschaften.htm) to be displayed at the respective object (function, pre-planning placement, connection definition point, etc.) or that are used in a scheme for the property configuration of the property overview.

Overview of the main dialog elements:

Source object:

This field is only available if multiple sources are possible for the properties.

This field lists the possible sources for a property. If you select a source object, the right [part](Glossary_o_artikel.htm) of the dialog displays a tab of the same name with the available properties of this source object.

Available if a graphically placed segment or a function or function template linked to a planning object has been selected. The index passes through the hierarchy [levels](Glossary_o_etagen.htm) in accordance with the tree structure in the pre-planning navigator. This is done starting from the current segment of the tree from the bottom upward. |
| Structure segment hierarchical | Properties of the superior structure segment. Available if a graphically placed segment or a function or function template linked to a planning object has been selected. The index passes through the hierarchy levels in accordance with the tree structure in the pre-planning navigator. This is done starting from the highest node in the tree to the last structure segment above the current segment. |
| PCT loop | Properties of the superior PCT loop. Available if a graphically placed segment or a function or function template linked to a planning object has been selected. |
| PCT loop function | Properties of the superior PCT loop function. Available if a graphically placed segment or a function or function template linked to a planning object has been selected. |
| Part reference | Properties of the part that can be changed at the device, and calculated properties. Available when a main function is marked and parts are assigned to it. The index passes through the parts in accordance with their sequence in the Parts tab of the [property dialog](Glossary_o_eigenschaftendialog.htm). |

The index passes through the parts in accordance with their sequence in the Parts tab of the property dialog. |
| Segment: Part | Properties of the part that is assigned to the planning object. Available when a function of a pre-planning placement is marked to which a planning object is assigned and parts are entered at the planning object. The index passes through the parts in accordance with their sequence in the Parts tab of the property dialog. |
| Placement | Properties of the graphical placement of the segment. Available if a graphically placed segment has been selected. |
| Connection definition point | Properties of the connection definition point. Available if a connection definition point has been selected. |
| Connection | Properties which are available for the connections that run under the connection definition point. Available if a connection definition point has been selected. |
| Piping definition | Properties of the piping definition point. Available if a piping definition point has been selected. |

Category:

The category allows you to limit the display of the properties possible for the marked source object to a subset.

This field is without meaning for the property configuration of the property overview.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

In the "Devices" category device properties are available, for example components of the DT; elements of the DT, [structure identifiers](Glossary_o_strukturkennzeichen.htm).

The "Data" category makes properties available for which the entry of data values is possible, e.g., [function texts](Glossary_o_funktionstexte.htm), technical characteristics, user supplementary fields, [block properties](Glossary_o_blockeigenschaften.htm).

In the "Settings" category properties are available that are set using check boxes or drop-down lists, e.g., "Suppress in device tag list", "Cross-reference display: Display".

Filter:

Into this field enter the text for which the properties are to be filtered.

If you want to [return](Glossary_o_zurueckbuchen.htm) to the original view of the properties, remove the search term from the entry field. Click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) to do so.

![](../Pictures/Gui/ALL/note.png)Notes:

- Please note that only texts and no specified values are found when filtering the properties.
- Logic operators (AND / OR operation) and placeholders (such as \* or ?) are not supported for filtering.

All properties available for the relevant object are displayed sorted by name in the Property name column of the table. The associated property values (where available) are displayed in the Value column. Click on a column header to sort the properties by the respective column.

![](../Pictures/Gui/ALL/info.png)Tip:

Enter multiple letters one immediately after the other to search for a string and jump directly to the first entry that starts with the letters you entered. If you enter "sup", for example, the cursor will jump in the list of properties directly to the first entry that starts with "sup", for example "supplementary field".  
If you pause too long between entering "s" and "u", the cursor will jump to the first entry that starts with "s", and then to the first entry that starts with "u".

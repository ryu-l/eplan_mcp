# Copying Pages between Different Projects

Pages can be copied within a project as well as between different [projects](Glossary_o_projekte.htm). It is possible to copy individual pages or entire [blocks](Glossary_o_bloecke.htm) of pages.

Precondition:

You have selected at least one page in the Pages - <Project name> navigator dialog.

1. Select the menu item Page > Copy from / to.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the Copy pages dialog, the source and target projects are displayed in two tree views. The project where the data is to be copied to is shown in the right field Current project. This project is currently open and selected in the page navigator. Initially, the current project is displayed in both fields, since copy operations most often take place within the same project.
2. In the left field Selected project select the source project where the data is to be copied from. This can be an already open project or one that has not yet been opened. Using [...] you can open the project selection dialog; click ![](../Pictures/Gui/ALL/all_fileopen_as.png) (Open) to choose any desired project from any directory.
3. If necessary, set a [Filter](modaldialogsdb_d_filternnach.htm) for the source project to display only specific project pages.
4. In the Selected project field at the left, select the pages that you wish to copy. You can also select a structure level, which selects all pages below the structure level.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The [properties](Glossary_o_eigenschaften.htm) of the (first) selected page are displayed in the Properties table.
5. Use the arrow keys to copy the selected pages into the target project in the Current project field to the right.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the Adapt structure dialog, the page numbers, the page descriptions, and the [structure identifiers](Glossary_o_strukturkennzeichen.htm) of the source and target pages are listed on the [Pages](pagebrowsergui_r_seitenstruktur.htm) tab.  
     
   You can either retain the page numbers, page descriptions and structure identifiers, or change them. If the pages already exist in the target project, then the Overwrite check box is automatically selected. Deselect this if you do not want to overwrite the pages, and change the page properties.
6. Select [Number] to open the [Number pages](pagebrowsergui_d_seitennummerierung.htm) dialog and renumber the copied pages.
7. If the copied DTs contain structure identifiers, you can change the visible DTs in the [DT](pagebrowsergui_r_ortkaestenstruktur.htm) tab.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) A prompt appears if the target project contains pages with the same name that would be overwritten. If you click [Yes] the pages in the target project will be overwritten. Click [No] to [return](Glossary_o_zurueckbuchen.htm) to the Adapt structure dialog and change your [settings](Glossary_o_einstellungen.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you selected the With prompt option under the Options > Settings > Projects > "Project name" > Devices > Numbering (online) menu [items](Glossary_o_bauteile.htm), the Insertion mode dialog is displayed. You specify here as to how device tags should be numbered on the copied pages.
9. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The pages are inserted into the target project, and the structure identifiers and DT are changed accordingly.

![](../Pictures/Gui/ALL/info.png)Tip:

In the page navigator, you can move and copy pages via Drag & Drop. Hold down the [Ctrl] key to copy pages.

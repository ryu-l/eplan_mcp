# P022050: GUID (AutomationML) '<x>' not unique

### Cause

A GUID with the same value <x> exists at more than one main function in the project. Each main function must have a unique GUID to allow the project export to AutomationML.

### Solution

1. Locate the [main functions](Glossary_o_hauptfunktionen.htm) that have the GUID that has been assigned several times in the project by using the Go to (graphic) or Synchronize selection [functions](Glossary_o_funktionen.htm) offered by the popup menu of the Message management dialog.
2. Call up the [property dialog](Glossary_o_eigenschaftendialog.htm) respectively for each main function.
3. Assign a unique value in the [properties](Glossary_o_eigenschaften.htm) table in the GUID (AutomationML) field.
4. Click [OK].
5. Then start a new check run.

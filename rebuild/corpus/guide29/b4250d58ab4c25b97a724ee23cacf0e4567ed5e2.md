# P003011: Too many cable connections

### Cause

The value entered in the Number of [connections](Glossary_o_verbindungen.htm) field of the Cable [properties](Glossary_o_eigenschaften.htm) dialog is smaller than the actual number of [cable connections](Glossary_o_kabelverbindungen.htm) of the [cable](Glossary_o_kabel.htm).

![](../Pictures/Gui/ALL/note.png)Note:

Shields and free templates are not taken into account!

### Solution

#### Possibility 1

Increase the value entered in the Number of connections field in the Cable Properties dialog so that it corresponds to the actual number of connections of the cable.

#### Possibility 2

In the Cable properties dialog next to the Type field, click [...], and when selecting parts, enter a suitable cable with the corresponding number of connections.

Refresh the connections and then start a new check run.

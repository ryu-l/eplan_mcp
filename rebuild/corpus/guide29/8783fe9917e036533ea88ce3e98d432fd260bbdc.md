# P026040: Connection / Cable without valid diameter (<x>)

### Cause

During the calculation of the fill capacity for [wire ducts](Glossary_o_verdrahtungskanaele.htm) EPLAN determined that there is a missing diameter entry for a used individual connection or a used [cable](Glossary_o_kabel.htm).

The diameter is invalid if there is either no diameter entry at all or if the value for the diameter is outside an area between 0 and 500 mm.

### Solution

1. Enter a valid diameter for the individual connection or cable.
2. Then start a new check run and update the fill capacity again (menu [items](Glossary_o_bauteile.htm) Project data > Connections > Update fill capacity).

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

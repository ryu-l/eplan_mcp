# Dialog New bundle if property value has changed

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have created [routing connections](Glossary_o_verlegeverbindungen.htm). Routing [connections](Glossary_o_verbindungen.htm) are highlighted in the connections navigator. Select the menu [items](Glossary_o_bauteile.htm) Project data > Connections > Bundle. In the dialog Bundle routing connections click the [...] button in a line under Bundling scheme in the table. In the Settings: Bundle dialog click the [...] button in the New bundle if property value has changed field.

Use this dialog to define [schemes](Glossary_o_schemata.htm) with an arrangement of [properties](Glossary_o_eigenschaften.htm). Whenever the value for one of the properties changes, a new [bundle](Glossary_o_buendel.htm) with a new bundle number is created. The structure and functionality of this dialog corresponds to that of the dialog Sorting (bundles).

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Category / property:

This list shows the criteria in accordance with which [bundles](Glossary_o_straenge.htm) are created when the value of one of these properties changes. To define the rules for the generation of the new bundles, several criteria can be combined with each other.

When the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button is clicked, the dialog Criteria selection is displayed in which you can select properties from the source, target and connection sections whose change is to initiate sorting into new bundles.

Toolbar:

The following buttons are available on the toolbar above the list:

| Button | Meaning |
| --- | --- |
| (New) | Opens the Criteria selection dialog for selecting sorting criteria. |
| (Delete) | Deletes the selected sorting criterion from the list. |
| (Move up) | Moves the selected sorting criterion one line upwards. This allows you to specify the order of the display. |
| (Move down) | Moves the selected sorting criterion one line downwards. This allows you to specify the order of the display. |

By connection point position

Devices whose [connection points](Glossary_o_anschluesse.htm) are located on two or more connection point [layers](Glossary_o_ebenen.htm) over each other are wired during manufacturing from bottom to top. To this purpose it should be possible to combine the [wires](Glossary_o_draehte.htm) per connection point layers in a bundle. The following check boxes are available as sorting and bundling [settings](Glossary_o_einstellungen.htm) in order to ensure this requirement:

- Source X, Target X
- Source Y, Target Y
- Source Z, Target Z.

These settings take into consideration the position specifications X-position, Y-position and Z-position in a global or local connection point pattern of a [part](Glossary_o_artikel.htm) placement. When these check boxes are activated, wires from and to connection points with the same position specification are sorted correspondingly into common bundles.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Go to default | Returns all settings of the selected area back to their default values. |

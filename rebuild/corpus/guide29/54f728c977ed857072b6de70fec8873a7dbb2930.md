# P017005: DT exists more than once, too many main functions

### Cause

You assigned the same device tag to two or more [main functions](Glossary_o_hauptfunktionen.htm) in the schematic.

### Solution

#### Possibility 1

Assign different device tags to the main [functions](Glossary_o_funktionen.htm).

#### Possibility 2

If you meant to assign the device tag several times, make one of the functions the main function and all the other functions [auxiliary functions](Glossary_o_nebenfunktionen.htm) in the [property dialog](Glossary_o_eigenschaftendialog.htm). To this purpose the property dialog of the respective function contains the Main function check box in the Symbol / function data tab that you have to activate or deactivate correspondingly.

Then start a new check run.

![](../Pictures/Gui/ALL/info.png)Tip:

Use automatic numbering when inserting [symbols](Glossary_o_symbole.htm). Select the menu item Options > Settings > Projects > "Project name" > Devices > Numbering (online). Under On symbol insertion, select the option Number.

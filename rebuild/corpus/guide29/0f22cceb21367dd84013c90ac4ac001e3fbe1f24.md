# Connection forks: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_verbindungsgabeln.htm)

### Connection forks

User interface / operation

Connections from one level of the connection point diagram to the next are shown using lines. Multiple lines next to one another are a comb. A comb is combined into a fork if all the lines of the comb belong to the same cable and all lines of the comb originate from the same device or the same terminal strip, or enter the same device or the same terminal strip.

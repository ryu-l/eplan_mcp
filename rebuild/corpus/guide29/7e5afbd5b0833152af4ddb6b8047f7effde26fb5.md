# Dialog Deleted pages

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have generated a revision and have opened a revision project (file extension \*.ell). You have selected the project setting While deleting create deletion markers and list deleted pages. Utilities > Revision control > Change tracking > Deleted pages.

The deleted pages of a revision project are displayed in this dialog. Some of the [properties](Glossary_o_eigenschaften.htm) displayed here are for information only and cannot be changed. You can describe your changes in the Index, Description, and Reason for change fields.

The following dialog elements are available:

The deleted pages are listed in the table together with the following information:

- Row: Consecutive row number.
- Page: Full page name of the deleted page.
- Defined working section: Shows the name of the defined working section to which the page belongs.
- Index: This field is provided for a text that can be used to identify the page modification. The index can consist of any arbitrary characters.
- Description: In this field, you can attach a comment to the page modification performed. 'Page deleted' is entered here automatically as a suggestion.
- Reason for change: This field is provided for the entry of the reasons for modification.
- Project revision: Name of the project revision in which the page was included at the time of the deletion.
- User: Name of the user who deleted the page.
- Date: Time at which the page was deleted. The date and time are specified.

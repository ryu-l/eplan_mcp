# Importing / Exporting Settings

In the Settings dialog, you can use a popup menu command to import, export, or export and add the tree view [settings](Glossary_o_einstellungen.htm). The last option allows you to add extra settings areas to an already exported file. Exported settings are stored in an XML file that can be imported.

![](../Pictures/Gui/ALL/note.png) Note:

There is no other option for specifying more settings areas for project and company-specific settings.

### [ClosedImport settings](javascript:void(0);)

Precondition:

You have access to an import file \*.xml.

1. Select the following menu [items](Glossary_o_bauteile.htm): Options > Settings
2. In the tree view of the Settings dialog, select the structure level into which you wish to import the settings.
3. Click ![](../Pictures/Gui/ALL/all_import_as.png) (Import).  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected one of the settings areas "User" or "Workstation", the Import settings dialog will open.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected one of the settings areas "Projects" or "Company", the Import settings: <Hierarchy path dialog is opened. Here you can specify the source file.
4. To import global settings, select the uppermost check box.
5. To import further program settings and [configurations](Glossary_o_konfigurationen.htm), in the Other settings areas group box, select the check box for each desired settings area.
6. Next to the Source file field, click [...], and select the \*.xml import file.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The settings are imported.

### [ClosedExport settings](javascript:void(0);)

1. Select the following menu items: Options > Settings
2. In the tree view of the Settings dialog, select the settings area that you wish to export.
3. Click ![](../Pictures/Gui/ALL/all_export_as.png) (Export).  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected one of the settings areas "User" or "Workstation", the Export settings dialog will open.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected one of the settings areas "Projects" or "Company", the Export settings: <Hierarchy path dialog is opened. Here you can specify the target file.
4. To export global settings for the selected settings area, select the uppermost check box.
5. To export further program settings and configurations, in the Other settings areas group box, select the check box for each desired settings area.
6. In the Target file field, check the file path and name, or use [...] to define a different file path and name.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A file path and name reflecting the area selected in the tree view is already entered into the Target file field.

   ![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

   You have marked the area User > Display > General in the Settings dialog. The program suggests the name <User>+<Display>+<General>.xml.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The settings are saved as an XML file under the specified name in the specified directory.

![](../Pictures/Gui/ALL/note.png)Note:

If you only select a single main category or sub-category in the tree view, all lower level settings areas are also included in the export.

### [ClosedExport and add settings](javascript:void(0);)

Preconditions:

- You have opened a project.
- You have access to an export file into which you wish to export further settings.

1. Select the following menu items: Options > Settings
2. In the tree view of the Settings dialog, select the desired main category, sub-category, or settings area that you wish to add to an already exported file.
3. Select the Export (append data) popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected one of the settings areas "User" or "Workstation", the Export settings (append data) dialog is opened.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected one of the settings areas "Projects" or "Company", the Export settings (append data): <Hierarchy path> dialog is opened. Here you can specify the target file.
4. To export and add global settings for the selected settings area, select the uppermost check box.
5. To export and add further program settings and configurations, in the Other settings areas group box, select the check box for each desired settings area.
6. Select the existing export file in the Target file field.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The settings are added to the selected export file.

![](../Pictures/Gui/ALL/note.png)Note:

When exporting and adding settings, the file name is not automatically expanded. For this reason, we recommend renaming the extended export file, or saving it in a separate directory.

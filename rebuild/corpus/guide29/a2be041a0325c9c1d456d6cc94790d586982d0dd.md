# Dialog Create project

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Project > New.
- You have selected a project management database. You have loaded directories and [projects](Glossary_o_projekte.htm). Project > Management. Select a directory in the tree structure. Select the New popup menu item.

In this dialog you [create](Glossary_o_erstellen.htm) a new project using a project template / basic project.

Overview of the main dialog elements:

Project name:

Enter the project name without file extension in this field. The project name can contain special characters and umlauts.

Storage location:

This field contains the directory where the new project is to be saved. Use [...] to open the Browse for folder dialog. In this dialog you can choose another directory as the storage location for the project. Any desired directory on any logical drive is a valid location.

Template:

The template used to create the new project is displayed here. You can select [project templates](Glossary_o_projektvorlagen.htm) or [basic projects](Glossary_o_basisprojekte.htm) as the template. Click [...] to open the Select project template / basic project dialog. You can select a template in this dialog.

Specify creation date:

If this check box is selected, then you can specify a different creation date for the new project in the field below. The current date will be displayed here to begin with. You can change this date if necessary.

If the check box is not selected, the creation date of the selected template is used.

Specify creator:

If this check box is selected, your logon name or user code will automatically be entered in the field below, depending on the [settings](Glossary_o_einstellungen.htm) under User > Display > User code / address. If you do not wish to use your logon name or user code, you can enter a different name.

If the check box is not selected, the name of the person who created the template is displayed. If this field is blank, no creator was specified for the template.

![](../Pictures/Gui/ALL/info.png) Tip:

You can use the functionalities described above - the Specify creation date and Specify creator check boxes - to enter and, if necessary, change the current creator and current creation date for new projects.

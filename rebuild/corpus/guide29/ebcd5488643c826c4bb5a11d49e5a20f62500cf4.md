# Tab <Cut-out>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open. The layout space contains a cut-out. You have double-clicked a cut-out or selected the menu [items](Glossary_o_bauteile.htm) Edit > Properties. In the Properties <...> dialog, select the <Cut-out> tab.

In this tab, you specify the [properties](Glossary_o_eigenschaften.htm) for the placed cut-out. The units are imported from the project [settings](Glossary_o_einstellungen.htm) or converted to mm in case of input in inches.

Overview of the main dialog elements:

Tab Drill hole

Diameter:

Input field for the drill hole diameter. The drop-down list shows the most recently used drill hole diameter.

---

Tab Threaded hole

Nominal diameter:

Input field for the threaded hole-specific nominal diameter. The drop-down list shows typical thread thicknesses with metric ISO thread and the recently used thread nominal diameter.

---

Tab Outline

Outline:

This field contains the file name of a [user-defined](Glossary_o_benutzerdefiniert.htm) outline file \*.fc1. Using the [...] button, you can select the file from the directory for [macros](Glossary_o_makros.htm) and [outlines](Glossary_o_konturen.htm) defined in the user settings.

---

Tab Slotted hole

Length:  
Height:

Input fields for the length and height of the slotted hole. The value for the length entered must exceed the value for the height.

---

Tab Rectangle

Type:

From the drop-down list, you can choose from the entries "Square", "Rounded", and "Chamfered".

Radius / Chamfer distance:

This input field is available only if the type "Rounded" or "Chamfered" has been selected. Here, depending on the select type, you can enter or select the value for the radius of the rounded rectangle or for the [chamfer](Glossary_o_fasen.htm) distance of the chamfered rectangle.

---

Tab Hexagon

Edge length:

Input field for the edge length of the hexagon.

---

Tab Octagon

Edge length:

Input field for the edge length of the octagon.

---

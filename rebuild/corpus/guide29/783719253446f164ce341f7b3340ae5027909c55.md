# Dialog Settings: Symbol scheme (Changing Standards)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > User > Change of standard > Symbol scheme.

This dialog lists all previous cross-project and [user-defined](Glossary_o_benutzerdefiniert.htm) assignment [schemes](Glossary_o_schemata.htm) of source project [symbols](Glossary_o_symbole.htm) to target project symbols. You can delete any assignment schemes that are no longer needed. If you use an assignment scheme for the [change of standard](Glossary_o_normentausch.htm), the source project symbols are replaced by the target project symbols.

The following dialog elements are available:

Toolbar:

| Button | Meaning |
| --- | --- |
| (Delete) | Deletes a selected row. The deleted assignment is then no longer available in any project. |

Assign symbols:

Every row contains an assignment of source library symbols to target library symbols.

- Source: Symbol library: Displays the source project symbol library file name without a file extension.
- Target: Symbol library: Displays the target project symbol library file name without a file extension.
- Scheme: This drop-down list displays all previously specified assignment schemes for assigning symbols. The schemes selected here are transferred to the project.
- Status: If a scheme is selected in the Scheme column, the assignment of the symbols is checked. This column displays the status of the check. The status is "OK" if the [function definitions](Glossary_o_funktionsdefinitionen.htm) for the symbols match and the number of source symbol [connection points](Glossary_o_anschluesse.htm) are less or equal to the number of target symbol connection points.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Freeze panes | Fixes all the rows of the table above the selected row, or all of the columns to the left of the selected column. The rows below, or the columns to the right of the selection, can still be moved by using the scroll bar. |
| Unfreeze panes | Removes the freezing so that all of the rows and columns can again be moved using the scroll bar. |
| Adjust column width | Adjusts the width of all table columns so that both the headings and column contents are fully legible. |
| Font size 100% | This menu item is only available if the font size has been changed in the table (via [Ctrl] + scrolling with the mouse wheel). Re-displays the text in the table in its original font size. |

# Action: MfImportToolbarAction

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| File | XML file to be imported including file path. |
| Replace | Existing [toolbars](Glossary_o_symbolleisten.htm) with the same name are replaced. |

![](../Pictures/Gui/ALL/note.png)Note:

This action requires a [main window](Glossary_o_hauptfenster.htm).

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
MfImportToolbarAction 
/File:"?" 
/Replace:Yes
```

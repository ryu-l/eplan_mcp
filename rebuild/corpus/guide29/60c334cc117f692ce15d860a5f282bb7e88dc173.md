# Defining a Mounting Surface

### [ClosedDefining mounting surfaces individually](javascript:void(0);)

Surfaces of bodies imported as 3D data can be defined as mounting surfaces. There are three possibilities:

- Individual surfaces can be defined as separate [mounting surfaces](Glossary_o_montageflaechen.htm).
- During a [part](Glossary_o_artikel.htm) placement a mounting surface can be defined on any surface, provided that no other mounting surface exists yet.
- Several surfaces within one shared space level can be combined into one common mounting surface.

Mounting surfaces are surfaces of an item on which other components can be placed. They are used for capturing the handles of rails, [channels](Glossary_o_kanaele.htm) and components that are to be placed on them. The mounting surfaces can be activated automatically by touching them with the cursor or selectively from the popup menu of the [layout space](Glossary_o_bauraum.htm) navigator. Mounting surfaces can be deleted in the layout space navigator.

Preconditions:

- You have opened a project.
- The layout space navigator is open and a layout space is open.
- The layout space contains imported 3D bodies which are to be saved as a macro.

1. Select the Edit > Device logic > Mounting surface.
2. Move the cursor over the surfaces of the 3D body.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The surface beneath the cursor is automatically highlighted in color.
3. When you reach the surface you want, click it.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If, in addition to the selected surface, other surfaces are found in the same space level, a message is displayed.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The surfaces found additionally on the same space level are displayed within yellow frames.
4. If you want to combine all surfaces found in the same space level to one common mounting surface, click [Yes] in the message.  
   ![](../Pictures/Visualisation/ALL/cabinetgui_mountingsurfacecommon_as.png)
5. If you want to define only the surface selected previously as mounting surface, click [No] in the message.  
   ![](../Pictures/Visualisation/ALL/cabinetgui_mountingsurfacesingle_as.png)  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected surface is defined as a mounting surface. In the layout space navigator a Mounting surface entry is generated under the corresponding item node.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Properties dialog of this mounting surface is displayed and you can enter the item description and select other [properties](Glossary_o_eigenschaften.htm).

### [ClosedDefining mounting surfaces during the placement of a part](javascript:void(0);)

Part placements without 3D graphics [macros](Glossary_o_makros.htm) that were generated as cuboids from the part dimensions or 3D solids imported as STEP data do not have any mounting surfaces. If you want to place a part on such a 3D solid, you can [generate](Glossary_o_erzeugen.htm) the missing mounting surfaces during the placement.

1. Select a menu item for inserting a part, for example Insert > Mounting panel, Insert > Device.
2. Move the cursor over the surfaces of the 3D body.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The surface lying under the cursor is not marked in color, if no mounting surface is defined on it.
3. Select the Edit > Device logic > Mounting surface.
4. Define the mounting surface as described in the previous section.
5. When the mounting surface is defined, continue the part placement.

### [ClosedGenerate type-specific mounting surfaces from function definition](javascript:void(0);)

A part placement or a 3D body imported as 3D graphic that does not yet have any mounting surfaces can be given mounting surfaces automatically that are generated as matching the set function definition. This is possible with the following [function definitions](Glossary_o_funktionsdefinitionen.htm) from the areas "Enclosure systems" and "System [accessories](Glossary_o_zubehoer.htm)":

- Body, general
- Mounting panel, general
- Door, general
- Panel, general
- Partition, general
- Floor sheet, general
- Flange plate.

1. Select a logic item in the layout space navigator.
2. Select the Properties popup menu item.
3. Click the [...] button in the Function definition field.
4. In the Function definitions dialog, select one of the suitable function definitions from the areas "Enclosure systems" and "System accessories".
5. Click [OK].
6. Select the Generate mounting surfaces popup menu item in the layout space navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Matching the selected function definition, all mounting surfaces are generated on the item and entered in the layout space navigator with the corresponding item [designations](Glossary_o_bezeichnungen.htm).

![](../Pictures/Gui/ALL/note.png)Notes:

- Prior to creating mounting surfaces, you have to rotate the object into the correct position.
- The surface that is to be defined as a mounting surface must be limited by points which are geometrically in the same plane. Depending on the quality of the imported 3D data, surfaces may be generated which do not meet this condition. Mounting surfaces cannot be defined on such surfaces.
- The point of origin of the mounting surface is usually on the bottom left. When surfaces are not perpendicular, the mounting surface also has to [form](Glossary_o_verlauf.htm) a surrounding rectangle with a point of origin on the bottom left. If - because the item has special shapes - the automatic alignment of the mounting surface fails, the [Adjust X-axis](cabinetgui_d_navigator.htm#XAchseUmbenennen) and [Adjust Y-axis](cabinetgui_d_navigator.htm#XAchseUmbenennen) functionalities can be used to correct the state.
- If several 3D [objects](Glossary_o_objekte.htm) are combined into an item in imported STEP data (e.g., mounting panel and support), the origin of the mounting surface can be outside the area set aside for the placement. To prevent errors in the placement of a device relative to the origin of the mounting surface, the size of the area set aside for the placement can be changed, and the position of the origin can be adjusted. To do so, use the [Change size](cabinetgui_d_navigator.htm#GroesseMontageflaeche) function in the popup menu of the layout space navigator.
- When creating macros with NC-relevant mounting surfaces, the field size is not entered automatically but must be defined manually. To do so, use the [Field size](cabinetgui_d_navigator.htm#Feldgroesse) function in the popup menu of the layout space navigator.
- Generally, the [field sizes](Glossary_o_feldgroessen.htm) are automatically assigned to the mounting surfaces to be normally edited: mounting panel front, door outside, panel outside, flange plate inside, etc.

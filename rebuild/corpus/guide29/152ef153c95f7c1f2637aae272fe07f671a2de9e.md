# Dialog Use existing PLC connection points blockwise

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have selected one or more [PLC boxes](Glossary_o_sps_kaesten.htm) and/or [PLC connection points](Glossary_o_sps_anschluesse.htm) in the graphical editor, PLC navigator or device navigator. Or you have selected one or more pages or a project in the page navigator. Project data > PLC > Use connection points blockwise. In the Select unplaced PLC connection points to place them blockwise dialog, open the tree or list view, select the desired PLC boxes and [connection points](Glossary_o_anschluesse.htm) and click [OK].

In this dialog, you re-use the unplaced PLC connection points that exist in the project, at the selected PLC connection points.

![](../Pictures/Gui/ALL/note.png)Note:

If you have selected PLC connection points that are in a PLC box, these will be assigned the selected connection points when you use the existing DT. This does not change the DT of the PLC box and, as a result, the assignment of the PLC connection points to the PLC box is lost. If you want to retain the assignment of the PLC connection points to the PLC box, you should again use the existing PLC box.

Overview of the main dialog elements:

To:

The selected, placed PLC boxes and connection points are displayed in this table. Other [objects](Glossary_o_objekte.htm) and unplaced PLC [functions](Glossary_o_funktionen.htm) are not displayed. The connection points are sorted in their graphical order in the schematic. It does not matter whether the connection points were selected in the graphical editor or in a navigator.

If placements of the same PLC connection point using different [representation types](Glossary_o_darstellungsarten.htm) (multi-line, single-line, etc.) are selected, then only one entry will appear in the table for this. If the addresses of these placements using different representation types are different, then the <<...>> character string is displayed in the table.

If PLC connection points occur multiple times in the project with the same representation type (with the same DT and connection point designation) then they are also listed multiple times in the table.

From:

The PLC boxes and connection points that you selected for re-use are displayed in this table. The table is empty when the dialog is first called up.

Status:

This column shows whether the PLC box or connection point selected for reuse can be assigned to the PLC box or connection point available in the project in the left-hand table. The [icons](Glossary_o_icons.htm) have the following meaning:

| Button | Meaning |
| --- | --- |
|  | Category and group of the PLC [function definitions](Glossary_o_funktionsdefinitionen.htm) match. It can be used. |
|  | Warning: The category of the PLC function definitions match, but the group does not. It can be used, but this could lead to incorrect results. |
|  | Error: The category of the PLC function definitions do not match. It cannot be used. |

Toolbar:

Use the arrow keys to assign the PLC boxes and connection points selected for use to the existing PLC boxes and connection points available in the project. Only the entries in the right table change their order during this. The assignment of the PLC functions cannot be transferred until the Status column contains no more red error icons.

| Button | Meaning |
| --- | --- |
| (Delete) | Deletes the contents of the selected [lines](Glossary_o_leitungen.htm). No lines are moved. |
|  | Opens the Select unplaced PLC connection points to place them blockwise dialog for selection of unplaced PLC connection points. This displays all the functions that are also displayed in the PLC - <Project name> navigator dialog. Multiple functions can be selected here. When you close the dialog, the selected PLC functions are transferred to the right-hand table of the Select unplaced PLC connection points to place them blockwise dialog. The connection points are sorted in the order in which they appear in the Select unplaced PLC connection points to place them blockwise dialog. |

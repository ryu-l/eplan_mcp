# Dialog Number using PLC data: Preview of result

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have selected [devices](Glossary_o_betriebsmittel.htm) in the graphical editor or a navigator, or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog. Project data > Devices > Number using PLC data. In the Number using PLC data dialog, you have selected the Preview of result check box. Click [OK].

In this dialog, a preview of the numbering results is provided. The [designations](Glossary_o_bezeichnungen.htm) of terminals and [pins](Glossary_o_steckerkontakte.htm) and the device tags of [general devices](Glossary_o_allgemeinebetriebsmittel.htm) will be shown in two separate tabs.

Overview of the main dialog elements:

Tab Terminal and pin designations / Tab Devices:

In the Terminal and pin designations tab, the designations of terminals and pins are shown before and after the numbering.

In the Devices tab, all numbered main and [auxiliary functions](Glossary_o_nebenfunktionen.htm) are displayed which contain a displayed DT. Functions that contain no displayed DT, but rather accept one from elsewhere, are not listed here. You can manually change the device numbering here. If you assign a different DT to a numbering function, you can also change the cross-reference.

The table contains a row for each numbered function. The following columns are always displayed:

- Error: If an error occurs during numbering with PLC data, a cell in this column will be highlighted in red. If the field is selected, the error status is printed in the Message description field.
- Name (identifying): Provides the identifying name of the function.
- Terminal / Pin designation: Shows the designation before numbering (only for terminals and pins).
- Connection point designations (all): Shows the [connection point designations](Glossary_o_anschlussbezeichnungen.htm) of [functions](Glossary_o_funktionen.htm) (only for general devices).
- New designation / New DT: Shows how the designation / DT looks after numbering. You can change the designation / DT in this column.
- Function text (automatic): Outputs the function text.
- Placement: Specifies the page on which the function is placed.

Other columns can be added in the popup menu with Configure representation.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Use original designation / DT | Here you can reassign the original designation or DT to a terminal or pin or device after numbering. |

Message description:

A message is printed for each selected line in which an error occurred. You can ignore the error or correct it.

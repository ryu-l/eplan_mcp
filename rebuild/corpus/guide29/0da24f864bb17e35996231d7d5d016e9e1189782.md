# Creating Functional Diagrams

Functional diagrams can be created on an existing page or on a separate new page. This section describes how a functional diagram can be created on a new page. The procedure for creating [functional diagrams](Glossary_o_funktionsdiagramme.htm) on existing pages is similar.

Preconditions:

- You have opened a project.
- You have added the symbol library OS\_SYM\_ESS.slk to the project. (This setting is carried out this via the Options > Settings > Projects > "Project name" > Management > Symbol libraries menu [items](Glossary_o_bauteile.htm).)
- In the project [settings](Glossary_o_einstellungen.htm) you have set the special symbol that is used for the [placing](Glossary_o_auflegen.htm) of the [property texts](Glossary_o_eigenschaftstexte.htm) in [operational sequence sheets](Glossary_o_ablaufdiagramme.htm) (e.g., OS1 for a text-based functional diagram or OS2 for a symbol-based functional diagram).
- You have inserted [functions](Glossary_o_funktionen.htm) or [devices](Glossary_o_betriebsmittel.htm) in the project and have entered on those the required values for the [properties](Glossary_o_eigenschaften.htm) Function text, State [1] to State [10], etc.

![](../Pictures/Gui/ALL/note.png)Notes:

- If you [create](Glossary_o_erstellen.htm) a symbol-based function diagram, the Functional placing with symbol graphic project setting must be activated. This setting must be deactivated for a text-based functional diagram.
- The State [10] property has been set aside, by default, for the input of variables for [GRAFCET](Glossary_o_grafcet.htm) diagrams.

### [ClosedCreate project page for the operational sequence sheet](javascript:void(0);)

1. Create a new project page using the Page > New menu items.
2. In the New page dialog in the Page type field, select the entry "Overview (I)", and enter a descriptive text for the project page in the Page description field.
3. In the table select from the Form name field the [form](Glossary_o_verlauf.htm) to be used, e.g., F28\_001.f28 for a text-based functional diagram or F28\_002.f28 for a symbol-based functional diagram.
4. In the table in the Grid field, enter the value "3 mm".
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) A project page is created that contains the selected form for an operational sequence sheet.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the [grid](Glossary_o_raster.htm) settings and the form used match, the grid points will be in the center of the table rows defined in the form. This facilitates the correct placing of devices and process sequences.

### [ClosedPlace devices in the operational sequence sheet](javascript:void(0);)

1. Open the project page for the operational sequence sheet, e.g., by double-clicking the project page in the page navigator.
2. Select the menu item Project data > Devices > Navigator.
3. Mark a function in the device navigator and select the popup menu Place functional and select the With symbol graphic menu item in the subsequent menu.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The special symbol defined in the project settings hangs on the cursor. When creating a text-based functional diagram, only the property texts of the function are displayed. When creating a symbol-based functional diagram, the symbol of the function is displayed in addition.
4. Or select the subsequent menu item With macro graphic if you want to place the graphic of a [part](Glossary_o_artikel.htm) macro in the functional diagram when creating symbol-based functional diagrams. If no part macro is stored for the selected device, you can, after a corresponding query, open the macro selection and select a macro.
5. Place the graphic on the project page. The insertion point of this symbol should be positioned in the top left corner of a table row in the diagram.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property texts are placed in the diagram. In the case of symbol-based functional diagrams, the symbol graphic of the function is also placed.
6. Or place the macro in the functional diagram.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The grouped graphic of the macro and the property texts of the main function are placed at the selected position on the page.
7. Repeat the above steps for the other devices that you want to place in the operational sequence sheet.

![](../Pictures/Gui/ALL/info.png)Tip:

During placing, you can use the [Tab] key to "leaf through" the [variants](Glossary_o_varianten.htm) of the symbol/macro. Using the [SHIFT] + [Tab] shortcut key, you can "leaf through" the [representation types](Glossary_o_darstellungsarten.htm) while placing [macros](Glossary_o_makros.htm).

### [ClosedDraw process sequences](javascript:void(0);)

You use graphical elements (e.g., [polylines](Glossary_o_polylinien.htm)) to draw process sequences. EPLAN provides support to enable you to insert some typical elements of functional diagrams faster. Arrows, signal points, AND and OR operations can be drawn in the respective functional diagram by means of the corresponding menu items via the Insert > Operational sequence sheet menu path.

1. If you want to draw a polyline, select the Insert > Graphic > Polyline menu items. (You can draw rectangles, circles, etc. using the other submenu items in the Graphic menu.)
2. Specify the points of the polyline consecutively, and click with the left mouse button each of the points to place them.
3. Exit the action using the [Space bar] or the Complete polyline popup menu item.
4. If you want to insert an arrow, select the Insert > Operational sequence sheet > Arrow menu items. (You can insert other elements for operational sequence sheets using the submenu items Signal point, AND condition, and OR condition.)  
     
   ![](../Pictures/Gui/ALL/arrow.png) The arrow is hanging on the cursor.
5. Select the desired variant of the arrow by pressing the [Tab] key several times.
6. Place the arrow in the functional diagram.

![](../Pictures/Gui/ALL/info.png)Tip:

You can insert special elements for operational sequence sheets (e.g., a forward slash, miscellaneous signaling elements, etc.) as [window macros](Glossary_o_fenstermakros.htm) from the macro directory OS\_ESS.

# Drag & Drop

Drag & drop is a method of moving data between computer programs using the mouse.

If you click with the mouse button on the graphical representation of a drag & drop source and then move the mouse while holding down the mouse button, then the cursor will change its shape, and you can then see if you have dragged it onto a target object that is drag & drop capable. When you then release the mouse button, depending on the source and target programs, the data associated with the source object is copied, moved or linked to the target program.

As for drag & drop in the EPLAN platform, you are shown an additional information text in the status bar as soon as the action is permitted. This way, you can see when the action is possible and which action you are currently executing in connection with drag & drop (move pages, place function, insert external file, etc.).

More complex [actions](Glossary_o_aktionen.htm) are also possible. For instance, you can directly open a file once you have dragged and dropped it.

#### [ClosedFrom an EPLAN navigator into the graphical editor](javascript:void(0);)

From the navigator, you can place every function on a page as many times as you like. In the process, it does not matter if the function has already been placed, is unplaced, or is of a different representation type. The created representation type depends on the page type where the function is placed.

Special feature of Drag & Drop: When the mouse button is released, the function hangs on the cursor. When you have selected the desired position, insert the function with a click.

In the [navigators](Glossary_o_navigatoren.htm) from within which you can place [functions](Glossary_o_funktionen.htm) (e.g., device navigator), it is also possible to make a multiple selection and to place the selected functions on a page one by one via drag & drop.

| Device navigator | Places / assigns. |
| PLC navigator | Places / assigns. |
| Cable navigator | Places / assigns. |
| Plug navigator | Places / assigns. |
| Terminal strip navigator | Places / assigns. |

Please note that when using multiple selections in a navigator's tree view, the selection made is only retained if you draw the most recently selected function. The function that was selected last is marked by a broken border line. Click on another function of the selected block; this removes the original selection and selects the new function.

If you have selected a DT in a navigator and you drag it to a schematic page using drag & drop, all the functions of this device are offered for placement one after the other. In this context, you can "browse" the functions using the [N] key and select the required one. You can use [Tab] to "page" through the available [symbol variants](Glossary_o_symbolvarianten.htm) for each function.

Alternatively to deciding, prior to the drag & drop in the device navigator (or other [project data](Glossary_o_projektdaten.htm) navigators), whether you want to place or assign the function, you can now do this while executing the action: You now decide to assign the function while executing the drag & drop, simply press the [Ctrl] + [Shift] shortcut keys while performing the dragging action. When you let go of the left mouse button, the function description of the highlighted function will hang on the cursor. Move the cursor to a suitable [component](Glossary_o_schaltzeichen.htm), and with one click you can apply the data of the function to the component. A function cannot be assigned directly via drag & drop.

#### [ClosedFrom an EPLAN navigator into a device's property dialog](javascript:void(0);)

From some navigators you can add parts to the main function of a device placed in the graphical editor using drag & drop. To do this, select the desired [part](Glossary_o_artikel.htm), e.g. in the Part master data navigator, press the [Ctrl] + [Shift] key combination, and pull the part onto the component. You thus have the opportunity to select a part using drag & drop.

If the device already has one or more parts, then a query is displayed asking whether the existing parts should be enhanced or replaced.

| Drag & drop source | Reaction |
| --- | --- |
| Part master data navigator | Inserts the part. |
| Device list | Inserts the part. |

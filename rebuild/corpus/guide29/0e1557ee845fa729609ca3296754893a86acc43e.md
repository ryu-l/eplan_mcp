# Exchanging Connection Symbols

Connection [symbols](Glossary_o_symbole.htm) can be exchanged using the "Draw over" function.

Preconditions:

- You have opened a project.You have opened a project page in the graphical editor.
- The page contains [connection symbols](Glossary_o_verbindungssymbole.htm).
- You selected the Connection symbols with prompt check box in the user [settings](Glossary_o_einstellungen.htm) (Options > Settings > User > Graphical editing > Connection symbols).

1. Select the menu [items](Glossary_o_bauteile.htm) Insert > Connection symbol.
2. Select the connection symbol you would like to insert from the menu that opens.
3. In the subsequent dialog select the desired target-specific [variants](Glossary_o_varianten.htm) for T-nodes, double junctions, and jumpers.
4. Select the Draw as point check box if you want the connection symbol to be drawn as a connection point.
5. Click [OK].
6. If required, hold down the [Ctrl] key and move the mouse to page through the previous variants.
7. With the left mouse button click the insertion point of an existing connection symbol in order to place the new connection symbol on this location.
8. Proceed in a similar manner for all additional connection symbols.
9. End the action via the Cancel action popup menu item or via the [Esc] button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The original connection symbol is replaced by the new one. The following restriction applies to [interruption points](Glossary_o_abbruchstellen.htm): An interruption point can draw over an angle (a T-node) but not vice-versa.

![](../Pictures/Gui/ALL/note.png) Note:

As soon as you double-click the connection symbol with the left mouse button, a dialog containing the list of variants for the selected connection symbol opens. Select a variant to replace the current variant. This does not apply to angles.

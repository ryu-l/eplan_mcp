# P026037: Routing paths lie over each other

### Cause

Two [routing paths](Glossary_o_strecken.htm) were placed on a mounting surface in such a way that they are tiled horizontally in [part](Glossary_o_artikel.htm) or completely.

![](../Pictures/Gui/ALL/note.png)Note:

The cause of this message applies not only to a routing path but also analogously also to a curve.

### Solution

1. Locate the routing path placed most recently in the [layout space](Glossary_o_bauraum.htm) using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Select the routing path and move it so that no segment of the routing path overlaps the previously drawn routing path anymore, or delete the routing path in question.
3. Then start a new check run.

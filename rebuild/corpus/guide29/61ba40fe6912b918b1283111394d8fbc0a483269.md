# Cleaning up Outlines

The "clean up" action removes all the unacceptable elements from the outline. These include ellipses, [splines](Glossary_o_bezierkurven.htm), and 3D elements. Blocks are automatically broken up.

Preconditions:

- You have opened a project.
- You have opened the outline that you want to edit in the outline editor (Utilities > Master data > Outline (...) > Open > [Open]).

1. Select the Utilities > Clean up menu [items](Glossary_o_bauteile.htm).
2. Confirm the prompt in the Clean up dialog by clicking [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Elements reported as "unacceptable" are removed and the [blocks](Glossary_o_bloecke.htm) are broken up.

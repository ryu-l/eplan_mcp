### PLC configurations

Electrical engineering

The PLC configuration is the totality of all the data of an exchange file (PLC configuration file) from a PLC configuration program. The PLC configuration provides information as to which network components are connected to each other, which PLC cards (type) are located in which slots, and which addresses are on which PLC cards.

# Dialog Extend parts data

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a parts database. Utilities > Parts > Management > [Extras] > Settings. In the Settings: Parts (user) dialog, click [...] in the Extend parts data using field.
- You have opened a project and selected a main function in the graphical editor or in a navigator. Edit > Properties. Select the Parts tab and click [...] next to the Data source field. In the Settings: Parts (user) dialog, click [...] in the Extend parts data using field.

In this dialog you determine which EPLAN-specific technical parts data is to be extended by commercial data from linked systems such as PMS.

Overview of the main dialog elements:

Extend parts data using:

If the EPLAN-specific technical parts data is to be extended by commercial data from linked systems such as PMS, you can use this table to do so. During the selection of a scheme for parts selection you can not only determine one data source (Scheme field of the Settings: Parts (user) dialog), but select additional data sources which have to be defined as [schemes](Glossary_o_schemata.htm), too. The assignment is made in this field:

First click ![](../Pictures/Gui/ALL/all_new_as.png) (New) to [generate](Glossary_o_erzeugen.htm) a line in the list of assignments. Then select the scheme which is to be evaluated for extending the data from the Scheme name drop-down list and activate the check box in the Generate part if not found column. In addition to [part](Glossary_o_artikel.htm) number and variant, each of which receives the value New\_<consecutive\_number> when creating a new dataset, the Function group property (in the Technical data tab) receives the value "New", making it easy to find parts generated via the parts selection process.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

In the Scheme field of the Settings: Parts (user) dialog, you selected the "Default" setting, and the [settings](Glossary_o_einstellungen.htm) you made in this scheme are included in part selection. In the Scheme name drop-down list of the Extend parts data using field you have selected the two schemes "CustomerA\_SQL" and "CustomerA\_API". If you have selected the check boxes under Generate part if not found, the corresponding parts will be generated in parts management.

# Displaying External Targets

The View > External targets option makes it easier to find external targets: If this option is activated, the external [connection points](Glossary_o_anschluesse.htm) of [functions](Glossary_o_funktionen.htm) are marked with an arrow. This makes (e.g.) [target tracking](Glossary_o_zielverfolgung.htm) for terminals easier. This allows you recognize the page of a terminal diagram where a target is output.

You set the Internal / External property in the [Connection point logic](xfctdefbrowsergui_d_anschlusslogik.htm) dialog, which you call up from the Symbol / function data tab of the [property dialog](Glossary_o_eigenschaftendialog.htm), via [Logic].

Precondition:

You have opened a project page in the graphical editor.

1. Select the menu item View > External targets.  
     
   ![](../Pictures/Gui/ALL/arrow.png) External connection points of functions are marked with a small arrow.
2. Select the menu item View > External targets again.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The arrows marking external connection points are hidden once more.

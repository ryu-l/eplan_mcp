# Plotting Locked Areas

Areas on the mounting panel can be locked for placement so that no [part](Glossary_o_artikel.htm) placement can occur on these areas. Locked areas are independent [objects](Glossary_o_objekte.htm) drawn as rectangles.

Precondition:

You have opened a project.

1. Project data > Parts / Devices > 2D panel layout navigator
2. In the graphical editor, select the [panel layout](Glossary_o_schaltschrankaufbau.htm) page where you would like to draw a locked area.
3. Select Popup menu > Locked area.
4. Draw the rectangle that represents the locked area.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The locked area is drawn.

![](../Pictures/Gui/ALL/note.png) Note:

As soon as part placement is attempted in a locked area, the placement is prevented, and an appropriate message is displayed.

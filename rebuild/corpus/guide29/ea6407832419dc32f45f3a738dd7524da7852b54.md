# Predefining Identifiers for Processing Functions

You can predefine multiple processing function identifiers. You can then access these predefined identifiers when creating [PCT loops](Glossary_o_plt_stellen.htm). If no identifiers are predefined, then you can directly enter an identifier when creating the PCT loop.

Precondition:

You have opened a project.

1. Options > Settings > Projects > "Project name"
   > Pre-planning > Processing functions
2. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the right-hand section of the Settings: Processing functions dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A new row is inserted in the Identifier and Description columns.
3. Enter a letter into the Identifier column and a descriptive text into the Description column.
4. Click [OK].

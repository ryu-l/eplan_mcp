# Tab Fins (Export Rittal - Perforex BC / Secarex)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Machining > Export Rittal - Perforex BC / Secarex. Select the Fins tab.
- Utilities > Manufacturing data > Machining > Rittal - Perforex BC / Secarex. Click [...] next to the Machine field. Select the Fins tab.

To prevent damage to the milling tool in the case of rectangular surfaces to be milled that are too big, such surfaces can be divided by fins. This creates smaller milling areas. The resulting fins are broken out during the mounting. All [settings](Glossary_o_einstellungen.htm) regarding automatic fin processing are specified in this tab.

![](../Pictures/Gui/ALL/note.png)Notes:

- To prevent the destruction of the outline during the approach of the milling tool, the following condition applies to [outlines](Glossary_o_konturen.htm) of small height: Fins are finished in connection with rectangles only if the smaller side is at least 20 mm long.

The following rules apply to chamfered / rounded rectangles:

- If the setting on this tab says that on the entire side length (side width or height) three fins are to be generated, and the available length is sufficient for only two fins due to the [chamfer](Glossary_o_fasen.htm) / rounding, then two fins will be fabricated.
- If the setting on this tab says that on the entire side length (side width or height) two fins are to be generated, and the available length is sufficient for only one fin due to the chamfer / rounding, then one fin will be fabricated.
- These rules are applied if the side length minus chamfer distance / fillet radius is greater than the fin width plus double the milling diameter / drill hole diameter.

Post-processing:

- To prevent the protrusion of the milled [part](Glossary_o_artikel.htm) from the material, the following correction is applied: If the setting on this tab says that on both parallel sides one fin is to be generated per side length, and no fins are fabricated on the other sides, two fins will in fact be generated.

Overview of the main dialog elements:

Group box Settings for default outlines

Use the default settings or change the values for the individual settings in accordance with your requirements.

Fin width:

A fin width of 1 mm is set as standard.

Generate one fin if edge length exceeds:

By default, a fin is inserted from a milling length of 100 mm.

Generate two fins if edge length exceeds:

By default, two fins are inserted from a milling length of 250 mm.

Generate three fins if edge length exceeds:

By default, three fins are inserted from a milling length of 500 mm.

Rework fins:

Since the operator removes the fins manually at the Perforex machine by means of pliers after the manufacturing, unclean surfaces are created that must be processed manually (e.g., by sanding them down). The Perforex machine can carry out this post-processing of fins automatically.

The post-processing of fins is only possible for rectangular outlines; fins in [user-defined](Glossary_o_benutzerdefiniert.htm) outlines cannot be post-processed automatically.

If the check box is activated, for all fields on which outlines with fins are processed, two [drilling patterns](Glossary_o_bohrbilder.htm) are sent to the processing machine.

The first drilling pattern contains information on processing with fins, with the outlines being reduced by the set thickness value for post-processing. In the second drilling pattern, another processing step is transferred for the outlines with fins. This then involves the precise outer outline without fins. Post-processing occurs only in locations where a fin remained after the first work step. The milling cutter leaves the workpiece between the fin locations, and moves in rapid traverse to the next fin, without performing a milling action.

The second drilling pattern can also be used for post-processing after the manual clipping off of the fins through finish-grinding of the breaking points.

Reworking thickness:

If the Rework fins check box is activated, you specify here the value by which the fin outline is extended following the clipping off of the fins. The default setting is 0.00 mm.

Suffix for rework programs:

The character string entered here is attached during the generation of the name of a Perforex rework program and the name of a Perforex rework contour. The default setting is \_NA.

If the suffix is set additionally in the Perforex software, ensure that both settings match.

---

The two subsequent check boxes are available if the format "Windows as of 1.9x" is set for the Perforex machine software, the Rework fins setting is activated and the value 0 mm is entered for the Reworking thickness field on the General tab.

M50 function:

If this check box is enabled, the M50 function of the Perforex machine is used. This function works fin residues in rectangular milling outlines in the middle of each edge automatically and without breaks for checking or changing of the milling tool. To this purpose the working point is approached outside the milling outline diagonally in rapid traverse.

![](../Pictures/Gui/ALL/note.png)Note:

To be able to use the M50 function, the value of the Z high setting on the Tools tab has to be at least 6 mm.

Do not generate rework program:

If this check box is activated, no additional NC program is generated for reworking in the Perforex software. Reworking is integrated in the milling program.

A rework program does not have to be generated for fin reworking if a Perforex workshop programming as of Version 1.9.2.74 is installed.

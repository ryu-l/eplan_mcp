# Dialog Automatic filter: Device selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have selected a main function in the graphical editor or in a navigator. Edit > Properties. Select the Parts tab and click [Device selection]. Click [...] next to the Automatic filter field.
- Project data > Parts / Devices > Bill of materials navigator. Select an entry. Popup menu > Device selection. Click [...] next to the Automatic filter field.

In this dialog, you determine the filter [settings](Glossary_o_einstellungen.htm) for device selection. The filter settings relate only to the main parts shown in the Parts list in the Device selection dialog, and not to the Accessories list. The [accessories](Glossary_o_zubehoer.htm) are oriented to the selected [main part](Glossary_o_hauptartikel.htm). The number of accessories matching each main [part](Glossary_o_artikel.htm) is normally relatively low, so that filtration is normally not required here.

Overview of the main dialog elements:

Property:

The [properties](Glossary_o_eigenschaften.htm) suggested in the filter settings depend on the item type and are those properties that can also be displayed in the columns of the Main parts list in the Device selection dialog.

Value:

In this field, the values entered into the [component](Glossary_o_schaltzeichen.htm) as presets are displayed. Spaces at the beginning and end, such as line breaks, are removed for display, but are not actually discarded.

Enter a value (for an empty field) or overwrite the preset value; the corresponding part properties will then be synchronized from this value (as long as the Active check box is selected). You can use [placeholders](searchandreplacegui_k_platzhalter.htm) (such as "\*" or "?").

Apply:

Select this check box if you want to use the filter settings in the Main parts list in the Device selection dialog.

The filter settings are always filled with the properties of the current component when the dialog starts. For each item type, EPLAN remembers if the Apply setting is selected or not. (So, for instance, if you have selected this setting for a coil, it is automatically activated for all of the other coils in device selection).

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Freeze panes | Fixes all the rows of the table above the selected row, or all of the columns to the left of the selected column. The rows below, or the columns to the right of the selection, can still be moved by using the scroll bar. |
| Unfreeze panes | Removes the freezing so that all of the rows and columns can again be moved using the scroll bar. |
| Adjust column width | Adjusts the width of all table columns so that both the headings and column contents are fully legible. |
| Font size 100% | This menu item is only available if the font size has been changed in the table (via [Ctrl] + scrolling with the mouse wheel). Re-displays the text in the table in its original font size. |

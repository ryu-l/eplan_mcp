# Dialog Settings: AutomationML export

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Project data > PLC > Export data. You have selected an AutomationML export format from the Format of export file field and then clicked [Options].

In this dialog you specify the degree of detailing for an export file in the AutomationML format.

Overview of the main dialog elements:

Export port-specific interconnection:

This setting is only relevant for the following bus systems:

- [Ethernet-based bus systems](plcgui_k_spsanschluesse.htm#I_Netzwerkanschluesse)
- DRIVE-CLiQ
- PortToPort
- ET-Connection
- Local-Bus: Extension

If this check box is activated, the interconnection of the [bus ports](Glossary_o_sps_busanschluesse.htm) is output in detail in the export file. In addition to the information about which [PLC boxes](Glossary_o_sps_kaesten.htm) are connected together, the information which bus port at the first box is connected with which bus port at the second box is output.

If the check box is deactivated, only the information which PLC boxes are connected together is output. The information which bus port is connected with which other one is not output. Connections between a [rack](Glossary_o_baugruppentraeger.htm) and the associated extension racks are also not exported in this case.

Export accessories:

If this check box is activated, the accessory parts are output as well in the export file. All parts that are entered at the positions 2 to 50 on the Parts tab in the [property dialog](Glossary_o_eigenschaftendialog.htm) of a main function are considered to be [accessories](Glossary_o_zubehoer.htm).

![](../Pictures/Gui/ALL/note.png)Note:

A PLC type designation must be entered for these parts in the parts management to allow export of the accessory parts.

If the check box is deactivated, accessory parts are ignored.

Exporting device-specific configuration values:

This setting is only possible as of the AutomationML export format V1.1.0. If this check box is activated, the device-specific configuration values are output as well in the export file.

If the check box is deselected or grayed out, the device-specific configuration values are ignored during the PLC [data exchange](Glossary_o_datenaustausch.htm).

![](../Pictures/Gui/ALL/note.png)Note:

The device-specific configuration values are defined in the parts management as [user-defined](Glossary_o_benutzerdefiniert.htm) [properties](Glossary_o_eigenschaften.htm) via the [Configure properties](eservicesgui_d_konfigeigenschaften.htm) dialog. So that these properties can be considered during the PLC data exchange in the AutomationML format, you must enter the value "PLC data" in the Category field and the value "Part" in the Assignment field and in addition activate the check box Also validate for part references. The prefix (character string until the first point) in the identifying name of these properties is deleted during the export and is added during the import from the data of the associated [part](Glossary_o_artikel.htm).

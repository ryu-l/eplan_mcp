# Dialog Settings: Check EPLAN version

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > Company > Management > Check EPLAN version.

In this dialog you specify whether a check is to be carried out for possible updates when EPLAN is started.

Overview of the main dialog elements:

Check for a new EPLAN version:

If this check box is activated, a check is carried out for a more recent version of the software when EPLAN is started. In this case a system message is displayed and the ![](../Pictures/Gui/ALL/modaldialogsgui_update_available.png) icon is displayed in the status bar. A double-click on this icon then opens the EPLAN Download Manager and you can install EPLAN in the most recent version.

### Line connectors

User interface / operation

Connections can be connected with each other through line connectors. In fluid power line connectors are used to adapt different connection types (tube / pipe transitions, cross-section reductions) in a fluid power system. In EPLAN line connectors are represented graphically by logical connection symbols and are managed like general devices. Meaning that line connectors can have device, symbol and function as well as parts data assigned to them.

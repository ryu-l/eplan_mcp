# Basic Projects

Basic [projects](Glossary_o_projekte.htm) are templates from which you can [create](Glossary_o_erstellen.htm) new projects. When doing this, all data of the basic project is adopted in the new project.

| File type | Meaning |
| --- | --- |
| EPLAN basic project (\*.zw9) | Basic project / \*.zw9 file: You can create new projects from a \*.zw9 file and save EPLAN projects as \*.zw9 files. |

A basic project can contain (e.g.) the following project [settings](Glossary_o_einstellungen.htm), [project data](Glossary_o_projektdaten.htm), and [master data](Glossary_o_stammdaten.htm).

- All project settings: Project settings are the settings under Options > Settings > Projects > "Project name". This includes the [schemes](Glossary_o_schemata.htm) for pages and device structure.
- All project data: Project data are for example unplaced [devices](Glossary_o_betriebsmittel.htm) and devices placed on pages.
- All pages: All pages that are located in the basic project are adopted.
- Master data: Master data stored in the project, such as [forms](Glossary_o_formulare.htm) and [symbols](Glossary_o_symbole.htm).
- Stored external documents and image files: Stored [external documents](Glossary_o_fremddokumente.htm) and image files are data that you have directly linked into the project or which you have subsequently copied into the project via Edit > Other > Links.
- Referenced data: When a basic project is created, all referenced data is stored in the project. Referenced data is data that is linked with the project (e.g.) via a hyperlink, but which is not contained in the project. This includes external documents, [attached documents](Glossary_o_begleitdokumente.htm), and image files. In order for this data to be stored in a basic project, these files must be located on a local drive or a network drive to which you have access permission. Data linked via the HTTP protocol is not stored in a basic project.

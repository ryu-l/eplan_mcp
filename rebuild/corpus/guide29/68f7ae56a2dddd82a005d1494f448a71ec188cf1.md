# Extensions in eCl@ss Import

Since Version 2.6 the EPLAN platform supports the importing of parts data into the parts management in accordance with the [eCl@ss](Glossary_o_eclass.htm) Version 9.0. With EPLAN 2.9 the eCl@ss Version 10.0.1 is now also supported. The XML-based format "[BMEcat](Glossary_o_bmecat.htm)" is used for the import for both versions.

Accordingly, the new entry "eCl@ss 10.0.1 (BMEcat 2005.1)" is available in the Import records dialog for the File type field. In the course of the extensions listed here, the superfluous file type "BMEcat (1.2)" has been removed.

### Filter for the Property Selection during eCl@ss Importing

In the [settings](Glossary_o_einstellungen.htm) for the eCl@ss import a filter option is now available at the property assignment for the selection of characteristics. The Property filter field has been included into the Property selection dialog to this purpose. (You open this selection dialog by, for example, clicking the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button in the Property assignment tab.)

Enter the text that is to be found into this field and click ![](../Pictures/Gui/ALL/all_search_as.png) (Find). Both the names of the [properties](Glossary_o_eigenschaften.htm) as well their description are searched. Subsequently only those entries that include the text searched for are displayed in the list of properties.

### User-defined properties for the property assignment

During the property assignment you can now assign a [user-defined](Glossary_o_benutzerdefiniert.htm) property instead of an EPLAN [part](Glossary_o_artikel.htm) property for a selected eCl@ss property. To this purpose a new User-defined property column is also available in the Property assignment tab. If a part property is already assigned, no user-defined property can be assigned and vice versa. Whether you can assign one or several user-defined properties depends on the cardinality of the eCl@ss property.

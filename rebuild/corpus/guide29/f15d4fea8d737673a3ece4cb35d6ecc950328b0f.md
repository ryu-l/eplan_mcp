# Details on the Use of Cables in the Single-line Representation

When you draw [cable definition lines](Glossary_o_kabeldefinitionslinien.htm) on schematic pages in EPLAN, the representation type property of the [cable](Glossary_o_kabel.htm) is automatically set to match the page type. On a single-line schematic page, the representation type of the cable becomes "single-line" and on multi-line schematic pages it becomes "multi-line". The cable property Number of connections used (single-line cable) is available to allow the number of [connections](Glossary_o_verbindungen.htm) of cables in single-line representation to be output in [reports](Glossary_o_auswertungen.htm).

### Shields

It is normal to also use [shields](Glossary_o_abschirmungen.htm) in [plant overviews](Glossary_o_anlagenuebersichten.htm) or single-line schematic pages. EPLAN allows shields to be drawn in single-line schematic pages. However, in this case they are only used as [cable definitions](Glossary_o_kabeldefinitionen.htm).

### Connection definition points

Connection definition points that are inserted into a single-line schematic page together with a cable definition line automatically make the connection into a cable connection. The Connection: Association property is correspondingly set to the "Cable" value in the Properties <...> dialog of the connection definition point.

The Number of functions property can be used to specify the number of connections at [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) (and also at [functions](Glossary_o_funktionen.htm)). The entered value is placed in the schematic together with the connection definition point - usually represented as a forward slash. Values such as "3+PE" are permitted.

### Bundles

To draw [cable connections](Glossary_o_kabelverbindungen.htm) in a clearer, more space-saving manner in multi-line schematics, it is often normal to represent cables as single-line [objects](Glossary_o_objekte.htm). To do this, the cable connections are bundled behind the source, e.g. a terminal strip, and fed into a [bundle](Glossary_o_buendel.htm) consisting of a single thick connection line. Before the target the bundle is split apart and the cable connections are then again represented in multi-line [form](Glossary_o_verlauf.htm). To implement the transition of connections of cables from multi to single-line representation, and vice-versa, so-called "bundle [connection points](Glossary_o_anschluesse.htm)" are used. EPLAN offers the appropriate schematic objects when you select the menu [items](Glossary_o_bauteile.htm) Insert > Bundle connection point.

# Showing the Graphical Preview

The graphical preview allows you see a preview of pages. If you have selected multiple pages, or multiple [objects](Glossary_o_objekte.htm) on different pages, these are tiled in the preview.

![](../Pictures/Gui/ALL/note.png)Note:

The object currently selected in the selection dialog is displayed in the graphical preview when the corresponding Preview check box is selected. This applies to macro and [form](Glossary_o_verlauf.htm) selection, etc.

1. Select the menu item View > Graphical preview.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A check mark next to the menu item shows whether this is active.

### Open pages from the graphical preview

Preconditions:

- You have opened the graphical preview.
- You have opened the Pages - <Project name> navigator dialog.
- You have opened a project and selected the project or individual pages in the Pages - <Project name> navigator dialog.

1. Double-click a page in the graphical preview.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The page is then opened in the graphical editor and the page preview also remains open.

![](../Pictures/Gui/ALL/info.png)Tip:

To open a page displayed in the preview in a new window, keep the [Shift] key pressed while double-clicking.

### Close graphical preview

Precondition:

The graphical preview is open.

1. Select the menu [items](Glossary_o_bauteile.htm) View > Graphical preview a second time, or click ![](../Pictures/Gui/ALL/all_shut_as.png) in the graphical preview.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The graphical preview closes.

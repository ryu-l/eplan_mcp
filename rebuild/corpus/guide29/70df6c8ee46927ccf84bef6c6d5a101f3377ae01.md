# P027018: Connection point <x> does not exist and cannot be created

### Cause

On the [topology](Glossary_o_topologie.htm) function, the named connection point <x> does not exist in the connection point pattern, and cannot be generated during the [route](Glossary_o_verlegen.htm) either.

The message occurs in connection with terminal strips displayed multiple times.

### Solution

1. Locate the topology [functions](Glossary_o_funktionen.htm) in your routing path network using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Call up the Properties <...> dialog of the topology function, and switch to the Connection point pattern tab.
3. Select the table, and select from the popup menu the Update menu item.
4. Delete all [connection points](Glossary_o_anschluesse.htm) from the table that are not to be connected to this display of the terminal strip. (For example, these can be connection points that are connected with targets in another routing path network.)
5. Close the Properties <...> dialog by clicking [OK], then re-route the [connections](Glossary_o_verbindungen.htm).
6. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

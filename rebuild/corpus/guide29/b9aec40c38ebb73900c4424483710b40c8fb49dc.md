[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_indirekteeigenschaften.htm)

### Indirect properties

User interface / operation

Properties of an object that is connected to the source object. Using block properties (see [Block properties](Glossary_o_blockeigenschaften.htm)) you can use one object (the starting object) to query the properties of another object connected to it.

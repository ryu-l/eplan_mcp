# Compressible Project Data

EPLAN can remove, reorganize, or rework the following [project data](Glossary_o_projektdaten.htm).

### General project data

The following general project data can be removed during project data compression:

| Remove project data | Meaning |
| --- | --- |
| Clear list of search results | The entries under Find > Show results > Tab List of results are deleted. |
| Clear message management | The entries under Project data > Messages > Management are deleted. |
| Unused stored [external documents](Glossary_o_fremddokumente.htm) and bitmaps | All external documents and bitmaps which are no longer used in the project are deleted. |
| Unused [structure identifiers](Glossary_o_strukturkennzeichen.htm) | Structure identifiers (such as [higher-level function](Glossary_o_anlage.htm), [installation site](Glossary_o_aufstellungsort.htm)) which do not contain project data are deleted. |
| Unused [layers](Glossary_o_ebenen.htm) | Layers which do not contain project data are deleted. |
| Unused [symbol libraries](Glossary_o_symbolbibliotheken.htm) | Symbol libraries which are not used in the project are deleted. This setting is always applied to the entire project. |
| Unused [forms](Glossary_o_formulare.htm) | Forms which are not used in the project are deleted. |
| Unused [plot frames](Glossary_o_normblaetter.htm) | Plot frames which are not used in the project are deleted. |
| Unused parts | Parts not used in the project are deleted. |
| Remove languages that are not [translation languages](Glossary_o_uebersetzungssprachen.htm) from multi-lingual texts | Languages which are not translation languages are removed from multilingual texts. |
| Project options | Deletes all [project options](Glossary_o_projektoptionen.htm) that you have set under Project data > Project options. |
| Remove element groups | Removes the grouping at all the element groups. The graphical elements of these groups remain. |
| Remove 'Macro' property from components | Deletes the content of the property "Macro" (<20468>) on all components. |
| Saved data backup directories | Deletes all data backup directories that have been saved. |
| Output data of manufactured [connections](Glossary_o_verbindungen.htm) | Deletes all output data of manufactured connections. |
| Unused [part](Glossary_o_artikel.htm) reference data | Deletes all unused part reference data. |
| Reset "Automatically generated" property on all pages | Deletes the value of the "Automatically generated" property on all pages. |
| Connections not belonging to the routing path network ([topology](Glossary_o_topologie.htm)) | Deletes all [routing connections](Glossary_o_verlegeverbindungen.htm) which do not belong to the routing path network in the topology. |
| User-defined entries in selection lists | Deletes all unused entries from the selection lists for certain [properties](Glossary_o_eigenschaften.htm) (such as Engraving text, Mounting site (describing)). Note that only [user-defined](Glossary_o_benutzerdefiniert.htm) entries are deleted. An update of missing entries does not occur. |
| User-defined properties not to be used anymore | User-defined properties identified as "Do not use anymore" will be deleted. |
| User-defined [segment definitions](Glossary_o_segmentdefinitionen.htm) not to be used anymore | User-defined segment definitions for pre-planning which are characterized as "not to be used anymore" and are, in fact, not used within the project are deleted. |
| Properties no longer defined from [segments](Glossary_o_segmente.htm) | At segments deletes the values of user-defined properties that are no longer configured at the segment definitions. In such a case the segment properties are no longer available at the segments. However, values previously entered continue to exist at the segments and are displayed, for example, as a placed property. |
| Unused and unnamed user supplementary fields | Deletes all user-defined supplementary fields for which no values have been entered or for which no names have been determined in the [settings](Glossary_o_einstellungen.htm). Such supplementary fields can exist in [projects](Glossary_o_projekte.htm) that were created by means of previous EPLAN versions (version 2.3 or older). |
| Remove communication units at [PLC boxes](Glossary_o_sps_kaesten.htm) | Deletes the communication units entered at PLC boxes. Such communication units can exist in projects that were created by means of previous EPLAN versions (version 2.3 or older). |
| Remove PLC structure data at PLC [auxiliary functions](Glossary_o_nebenfunktionen.htm) | Deletes PLC structure data that are entered at PLC auxiliary [functions](Glossary_o_funktionen.htm). Such data can exist in projects that were created by means of previous EPLAN versions (Version 2.3 or older). As of Version 2.4 Plc structure data are only entered at PLC [main functions](Glossary_o_hauptfunktionen.htm) in the PLC structure data tab. |
| Invalid pre-planning links | Deletes invalid links from segments in the pre-planning. |
| Property arrangements not used | Deletes user-defined property arrangements that are not used in the project. Fixed specified property arrangements (such as "Default value" or "Top left, outside, 90°" at the boxes) are not removed during compressing. |
| AutomationML GUIDs | Deletes all AutomationML GUIDs. Such GUIDs are, for example, generated or imported during [data exchange](Glossary_o_datenaustausch.htm) of PLC configuration files in AutomationML-Format. |
| Bus data at non-single-line [bus ports](Glossary_o_sps_busanschluesse.htm) | Deletes the bus data at all bus ports that have a different representation type than "single-line". Only the data at the single-line bus ports remains. The Bus interface: Name property is retained at all [representation types](Glossary_o_darstellungsarten.htm). |
| Remove protected groups | Removes the grouping at all protected groups. The [macros](Glossary_o_makros.htm) inserted into the schematic and their components remain. |
| Connection definition points without connections | Deletes [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) that have no connections assigned. Connection definition points on connections without target (this means the connection ends for example at an angle or T-node) are also deleted. |

### Devices

The following [devices](Glossary_o_betriebsmittel.htm) and functions that can be revised during project data compression:

| Revise devices | Meaning |
| --- | --- |
| Remove spare devices | Removes spare devices. All functions in spare devices are completely unplaced. |
| Remove unplaced duplicate functions | Removes unplaced duplicated functions. An unplaced function is duplicated if a second placed or unplaced function has the same identifying properties. You can only remove the unplaced function. |
| Remove unplaced surplus device functions | Removes unplaced surplus device functions. Unplaced surplus device functions are functions that are not overlapped by device templates. Devices without device definition / without function template are not affected. |

### Unplaced functions

The following [unplaced functions](Glossary_o_nicht_platziertefunktionen.htm) can be removed during project data compression:

| Remove unplaced functions | Meaning |
| --- | --- |
| Cable / shield definition | Removes unplaced [cable](Glossary_o_kabel.htm) / shield definitions. |
| Black boxes | Removes unplaced [black boxes](Glossary_o_geraetekaesten.htm). |
| Device [connection points](Glossary_o_anschluesse.htm) | Removes unplaced [device connection points](Glossary_o_geraeteanschluesse.htm). |
| PLC boxes | Removes unplaced PLC boxes. |
| PLC terminals | Removes unplaced PLC terminals. |
| Terminals | Removes unplaced terminals. |
| Plugs | Removes unplaced [plugs](Glossary_o_stecker.htm). |
| Terminal strip definitions | Removes unplaced [terminal strip definitions](Glossary_o_klemmenleistendefinitionen.htm) which contain terminals. The terminals themselves are not deleted. |
| Plug definitions | Removes unplaced [plug definitions](Glossary_o_steckerdefinitionen.htm) which contain [pins](Glossary_o_steckerkontakte.htm). The pins themselves are not deleted. |
| Single-line functions | Removes unplaced functions with the representation type "Single-line". |
| External functions | All unplaced functions with the representation type "External" are deleted. |
| All other functions | All other unplaced functions are deleted. |
| Terminal strip definition without terminals | Removes unplaced terminal strip definitions which do not contain terminals. |
| Plug definition without pins | Removes unplaced plug definitions which do not contain pins. "Plug definition for male and [female pins](Glossary_o_steckerbuchsen.htm)" without pins removes male and female pins. "Plug definition for [male pins](Glossary_o_steckerstifte.htm)" without pins removes male pins. "Plug definition for female pins" without pins removes female pins. |

### Unplaced connections

The following unplaced connections can be removed during project data compression:

| Remove unplaced connections | Meaning |
| --- | --- |
| Incorrect | Removes unplaced connections with errors. Connections have errors if they are not completely connected or are only partially connected. The targets of the connections are missing. |
| Duplicate | Removes duplicated unplaced connections. An unplaced connection is duplicated if a second placed connection has identical [target information](Glossary_o_zielinformationen.htm). |
| All other connections | Removes all unplaced connections which are not erroneous or duplicated. |

### Placed functions

The following [placed functions](Glossary_o_platziertefunktionen.htm) can be removed during project data compression:

| Remove placed functions | Meaning |
| --- | --- |
| Placeholder [objects](Glossary_o_objekte.htm) | Removes placed [placeholder objects](Glossary_o_platzhalterobjekte.htm). |
| Macro boxes | Removes placed [macro boxes](Glossary_o_makrokaesten.htm). |
| Terminal strip definition without terminals | Removes placed terminal strip definitions which do not contain terminals. |
| Plug definition without pins | Removes placed plug definitions which do not contain pins. "Plug definition for male and female pins" without pins removes male and female pins. "Plug definition for male pins" without pins removes male pins. "Plug definition for female pins" without pins removes female pins. |

| Reorganize project | Meaning |
| --- | --- |
| Reorganize project | Deleted data is permanently deleted from the project database. The database is reduced in size. |

| Plugs | Completely removes unplaced plugs. |

### Nonplaced functions without main functions

| Remove unplaced functions without main functions | Meaning |
| --- | --- |

| Terminal strips / terminals | Removes unplaced terminal strips and terminals without main functions. |
| Plugs / pins | Removes unplaced plugs and pins without main functions. |
| PLC / connection points | Removes unplaced PLC devices and connection points without main functions. |

### Symbols

| Symbols | Meaning |
| --- | --- |
| Remove unused alternative [symbol variants](Glossary_o_symbolvarianten.htm) | Removes all unused rotated and/or flipped symbol [variants](Glossary_o_varianten.htm), i.e., variants E to H. |
| Remove unused symbol variants and [symbols](Glossary_o_symbole.htm) | Removes all unused symbols without variants as well as the symbol variants. |

### Comments

| Comments | Meaning |
| --- | --- |
| Remove [comments](Glossary_o_kommentare.htm) | Removes all comments. |

### Net definition points

| Net definition points | Meaning |
| --- | --- |
| Remove invalid connections | Removes all invalid connections at [net definition points](Glossary_o_netzdefinitionspunkte.htm). |
| Merge net definition points | If this check box is activated, a number of net definition points within a network are combined to [form](Glossary_o_verlauf.htm) a single net definition point. The remaining net definition point contains all the connections and properties that were defined in the other net definition points. In the event of a conflict, the first graphical net definition point "wins". |
| Remove superfluous net definition points | Removes all the net definition points that are not required to specify the connections. This will be the case, for instance, if the connections of the net are defined using connectors with target specification. If additional properties are stored in the net definition point, a connection definition point with identical properties is placed here instead of the net definition point. |
| Remove all net definition points and correct [connection symbols](Glossary_o_verbindungssymbole.htm) | Removes all the net definition points and simultaneously corrects the connection symbols. This can for example make sense when a customer - after having carried out optimization of the [nets](Glossary_o_netze.htm) - wants to recognize the target [wiring](Glossary_o_verdrahtungen.htm) at the t-nodes. |

### Revision control

| Revision control | Meaning |
| --- | --- |
| Remove the results of the property comparison | Deletes the content of the internal [list of revision results](Glossary_o_revisionsergebnisliste.htm) which is filled during the property comparison of projects. In addition those MS Access databases are deleted that were created during the property comparison of projects with previous EPLAN versions (Version 2.3 or previous). These databases contain the comparison results and are automatically stored in the project directory. |

### 3D data

| Remove 3D data | Meaning |
| --- | --- |
| Part placements without main function | Removes all [part placements](Glossary_o_artikelplatzierungen.htm) without main function on the 3D data. |
| Unused connection points at the part placement that are not in the connection point pattern | Removes all connection points not in use at the part placement that are not included in the connection point pattern. |
| Routing connections that have become invalid through optimization | Removes all routing connections that have become invalid. |
| Unplaced functions | Removes all unplaced functions. |

### Protection

| Remove protection | Meaning |
| --- | --- |
| Device protection | Removes the device protection at all the objects. |
| Manual change protection | Removes the manually assigned change protection at all the objects. |
| Automatic change protection: File off subprojects | Removes the automatic change protection from all objects that was assigned during the filing off of subprojects. |
| Automatic change protection: Creation of pages (pre-planning) | Removes the automatic change protection from all objects that was assigned during pre-planning during the creation of pages from macros. |
| Automatic change protection: Import of design spaces (Pro Panel) | Removes the automatic change protection from all objects that was assigned in EPLAN Pro Panel during the import of 3D models. |

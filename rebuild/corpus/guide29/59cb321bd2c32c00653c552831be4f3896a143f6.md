# Dialog Full page name

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened the page navigator and opened (at least) one project.

- You have selected one or more pages in the page navigator. Edit > Properties. Click [...] next to the Full page name field.
- Page > New. Click [...] next to the Full page name field.

In this dialog you can edit the structure identifier and the page name. After modification, the page is resorted into the appropriate position in the project.

The following dialog elements are available:

Structure identifier:

Depending on the [project structure](Glossary_o_projektstruktur.htm) the table displays the [structure identifiers](Glossary_o_strukturkennzeichen.htm) of the page which can be edited. EPLAN generally adopts the Page structure that you have defined in the [project properties](Glossary_o_projekteigenschaften.htm) when creating the project.

- Structure: Lists the [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) which correspond to the page structure. The adjacent column displays the associated preceding signs.
- Value: In this column, the structure identifiers can be edited. Enter a structure identifier in the proper field for this purpose, or click [...] to select a structure identifier already defined in the project using the [<Identifier block> (<Project name>)](pleditorgui_d_kennzeichnungsblock.htm) dialog.

Page name:

This field displays the page name. You can accept this or change it manually.

The page name that EPLAN suggests for a new page depends on the currently selected page. If no pages exist in the project, then EPLAN suggests the page name "1". Otherwise the next available free page name is used. In DIN [projects](Glossary_o_projekte.htm), EPLAN allocates the page names on a group basis.

For DIN and JIC a subnumber is accounted for if the current page contains a subnumber. The suggested page names are independent of the Subpage character project setting (Options > Settings > Projects > "Project name" > Management > Pages) and the current page.

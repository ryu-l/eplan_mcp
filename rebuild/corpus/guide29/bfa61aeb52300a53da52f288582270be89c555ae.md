# P007010: Functions have conflicting data at the '<x>' property

### Cause

With cross-referencing [functions](Glossary_o_funktionen.htm), the data of a specific property of a main and a sub-function do not match.

### Solution

Enter the same property for the main and sub-function.

Then start a new check run.

![](../Pictures/Gui/ALL/info.png) Tip:

Use the [block editing](Glossary_o_blockbearbeitung.htm) or the table editing tool. You can change the [properties](Glossary_o_eigenschaften.htm) of multiple function in one go with both editing tools.

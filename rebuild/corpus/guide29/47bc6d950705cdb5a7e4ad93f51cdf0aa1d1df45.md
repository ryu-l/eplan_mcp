# Dialog Found words

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a page in the graphical editor. Or you have opened a project and an editor ([form](Glossary_o_verlauf.htm) editor, [symbol editor](Glossary_o_symboleditor.htm), etc.).

- Insert > Graphic > Text / Insert > Path function text. Select the Text tab. Enter a word with multiple meanings. Select the Translate popup menu item.
- You have selected a text or a path function text and the menu [items](Glossary_o_bauteile.htm) Edit > Properties or have double-clicked a text or path function text. Select the Text tab. Enter a word with multiple meanings. Select the Translate popup menu item.

This dialog displays word suggestions for the specified word. To do this, EPLAN searches for suitable [keywords](Glossary_o_stichworte.htm) in the dictionary.

Overview of the main dialog elements:

Context information:

This is only available if a word with multiple meanings is found during the automatic translation. To this purpose the Manual selection for terms with multiple meanings check box has to be activated. For the translation of project data this setting is located in the project-specific translation [settings](Glossary_o_einstellungen.htm). For the translation of parts data the [user-specific](Glossary_o_benutzerbezogen.htm) setting of the same name is located in the Project-independent tab.   
In this dialog section information about the context of the respectively marked word is displayed. The Context line contains the text type (for example "free text") or the function category, the DT as well as the property in which the word occurs. The second line shows the entire text that contains the word.

![](../Pictures/Gui/ALL/info.png)Tip:

If the text has already been translated before, you can branch to the dialog of the same name via the popup menu item Multilingual input for the Full text field and there have a look at which translation has already been used in the project / parts management. This information can help you further in the selection of a word suggestion. Entries in the dialog are not possible during this action.

Word suggestions:

If you translate during input, EPLAN makes word suggestions for the word you enter when the word has multiple meanings in the dictionary and it makes word suggestions for words that start with the word you enter.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Word with multiple meanings

You have selected en\_US as the source language. You enter the word "Connector". The word exists twice as a keyword in the dictionary, but is differently translated in the fr\_FR target language.

| en\_US | fr\_FR | Comment |
| --- | --- | --- |
| Connector | Connecteur | Function definition |
| Connector | Symbole de connexion | Symbol |

Words that begin with the word

You enter the word "Coil". EPLAN suggests all words from the dictionary that begin with "Coil".

| en\_US | fr\_FR |
| --- | --- |
| Coil | Bobine |
| coil current | courant de bobine |
| coil voltage | tension de bobine |
| Coil, AC | Bobine, courant alternatif |

# Dialog Settings: Print

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Project > Print > [Settings].
- Options > Settings > Workstation > Graphical editing > Print.

In this dialog, among other things, you can determine the print size, print margin, and position on the page.

Overview of the main dialog elements:

Group box Print size

In this group box, you can determine whether the selected pages should be printed at 1:1 scale or at a different scale.

Print to scale (1:1):

If this option is selected, the pages will be printed at the scale as indicated for the plot frame. If a page is too large for the sheet of paper used, it will not be printed completely, that is, the areas which do not fit on the paper will be cut off.

To page scale:

If you selected the Print to scale (1:1) option, this check box can be used. If the check box is selected, printing takes account of the page scale, and several pages with different scales can be printed without needing to change the [settings](Glossary_o_einstellungen.htm) individually.

Horizontal adjustment factor / Vertical adjustment factor:

If you selected the Print to scale (1:1) option, you can use these fields to specify a horizontal and a vertical adjustment factor for printing to scale. This can be necessary when (e.g.) different printers give different results when doing scaled printing. Enter the desired value here, the default is "1".

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

On a graphical page with a scale of 1:10 you have drawn a vertical straight line with a length of 2,000.00 mm.

When printing with the Print to scale option enabled, the line should be 200 mm long on the printed paper but the printer only prints a line that is 199 mm long.   
After calculating the ratio of target-to-actual value, the result is the adjustment factor (200/199=1.00502). Enter this factor 1.00502 in the Vertical adjustment factor field to correct the inaccuracy.

Scale to page:

If this option is selected, the pages will be enlarged or reduced so that they fill the paper as completely as possible. The format to be scaled to is the page output format that is set for the printer.

Keep aspect ratio:

If you selected the Scale to page option, this check box can be used. If the check box is selected, the height and width will be scaled in the same amount, and no distortions will be introduced. If the check box is deselected, the drawing is scaled to cover the entire page; in this case, distortions are allowed.

---

Group box Print margins

In this group box, you can determine the area that should not be printed.

Left / Right / Top / Bottom:

Here you determine the area that should not be printed for the Left, Right, Top and Bottom page margins. The units are taken from the project settings and displayed here. Input is possible in mm and in inches.

![](../Pictures/Gui/ALL/note.png)Note:

The print margins provided here only apply to the printable area of the printer! The gap between the printable area and the edge of the paper depends on the printer and is not taken into account.

Print position:

You can determine how the print image will be positioned on the page here. The print margins specified are taken into account. Select the desired position from the drop-down list.

---

Print in black and white:

If this check box is selected (default setting), all of the elements (except image files) will be printed in black, on a white background, on a color printer. Image files are always output in their original colors. They are only printed in gray [levels](Glossary_o_etagen.htm) when the printer driver of the color printer is set to black and white, or if you are using a black and white printer.

If the check box is not selected, then all of the elements will be printed in the colors corresponding to the color scheme "Color on white".

![](../Pictures/Gui/ALL/note.png)Note:

If the Print in black and white check box is deselected and the project is printed on a black and white printer, then all color information is converted into gray scales by the printer. This can result in, for instance, a yellow line being printed only as a light dotted line.

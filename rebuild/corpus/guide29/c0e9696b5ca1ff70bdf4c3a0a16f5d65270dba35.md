# Action: partslist

|  |  |
| --- | --- |
| **Parameter** | **Description** |
| TYPE | Type of task to be carried out: IMPORT: Import [bills of materials](Glossary_o_stuecklisten.htm) EXPORT: Export bills of materials IMPORTTOSYSTEM: Import into the parts management EXPORTFROMSYSTEM: Export from the parts management DELETESTOREDPROPERTIES: Delete saved [properties](Glossary_o_eigenschaften.htm) from the project |
| PROJECTNAME | Project name with complete file path (optional). If nothing is entered, the selected project will be used if the action is to be run over the user interface (e.g. via script or the toolbar). When executing from the Windows command line, PROJECTNAME must be specified or ProjectAction has to be used before that. Otherwise a system message will appear. |
| IMPORTFILE | The directory and the name of the file to be imported must be specified here. Applies only for IMPORT. |
| EXPORTFILE | The directory and the name of the file to be exported must be specified here. The system adds a file name extension automatically. Applies only to EXPORT. |
| FORMAT | Optional:  File [formats](Glossary_o_formate.htm) for the import (TYPE:IMPORT) / export (TYPE:EXPORT) of bills of materials:   - XPalXmlExporter - or XPalCSVConverter   Default value: XPalXmlExporter    File format for importing into the parts management (IMPORTTOSYSTEM):   - IXPamImportE21 - IXPamImportE5 - IXPamImportText - IXPamImportCSV - IXPamImportEcad - IXPamImportCSVAddresses - XPamImportXml   Default value: XPamImportXml    File format for exporting from the parts management (EXPORTFROMSYSTEM):   - IXPamImportText - IXPamImportCSV - IXPamImportCSVAddresses - XPamExportXml   Default value: XPamExportXml |
| SQLFILTERPART | Optional: SQL filter for advanced users. Default value: 1 = 1 |
| SQLFILTERADDRESS | Optional: SQL filter for advanced users (is used with the format "IXPamImportCSVAddresses"). Is used for the export of addresses. Default value: 1 = 1 |
| SQLFILTERCONSTRUCTION | Optional: SQL filter for advanced users. Is used for the export of [drilling patterns](Glossary_o_bohrbilder.htm).  Default value: 1 = 0 |
| SQLFILTERTERMINAL | Optional: SQL filter for advanced users. Is used for the export of [connection point patterns](Glossary_o_anschlussbilder.htm).  Default value: 1 = 0 |
| SQLFILTERACCESSORYLIST | Optional: SQL filter for advanced users. Is used for the export of accessory lists.  Default value: 1 = 0 |
| SQLFILTERACCESSORYPLACEMENT | Optional: SQL filter for advanced users. Is used for the export of accessory placements.  Default value: 1 = 0 |
| CFGFILE | Optional: Directory and file name of the configuration file. Default value: currently used configuration file. |
| FIELDASSIGNMENTSCHEME | Optional: Name of the scheme of the field assignment for importing parts. |
| MODE | Optional: Import mode. Supported modes are:   - 0: Add new records only (default value) - 1: Update existing records only - 2: Update existing records and add new ones   When specifying an invalid value, the default value 0 will be used. |
| ADDITIONAL\_LANGUAGE | Optional. Only applies if TYPE = IMPORTTOSYSTEM. If the value of this parameter is 1, the multilingual properties will be updated with other language values. If the parameter is left out, the file content will replace the values of multilingual properties. |
| CONFIGSCHEME | Configuration scheme for the deletion of saved properties (optional). Default value: most recently used configuration scheme. |

![](../Pictures/Gui/ALL/note.png)Note:

If the action partslist is to enable the complete export of all [record types](Glossary_o_datensatztypen.htm) from parts management (TYPE=EXPORTFROMSYSTEM), the parameters SQLFILTERCONSTRUCTION, SQLFILTERTERMINAL, SQLFILTERACCESSORYLIST, and SQLFILTERACCESSORYPLACEMENT must be transferred with the value 1=1 in addition to the parameters SQLFILTERPART and SQLFILTERADDRESS.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Export:

```
partslist 
/TYPE:EXPORT 
/PROJECTNAME:C:\Projects\EPLAN\ESS_Sample_Project.elk 
/FORMAT:XPalCSVConverter 
/EXPORTFILE:d:\temp\PartsList.csv
```

Import:

```
partslist 
/TYPE:IMPORT 
/PROJECTNAME:C:\Projects\EPLAN\ESS_Sample_Project.elk 
/FORMAT:XPalCSVConverter 
/IMPORTFILE:d:\temp\PartsList.csv
```

Delete saved properties from the project:

```
partslist 
/TYPE:DELETESTOREDPROPERTIES 
/PROJECTNAME:C:\Projects\EPLAN\ESS_Sample_Project.elk 
/CONFIGSCHEME:config_scheme
```

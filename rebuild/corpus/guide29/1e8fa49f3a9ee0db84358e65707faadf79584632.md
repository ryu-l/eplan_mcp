# Deleting Revisions

You can remove [revision markers](Glossary_o_revisionsmarkierungen.htm) and revision data created via [change tracking](Glossary_o_aenderungsverfolgung.htm) or a property comparison of [projects](Glossary_o_projekte.htm) from the project separately.

### Delete revisions (change tracking)

Precondition:

You have opened a project containing revision markers. You have selected one or several pages or a project in the page navigator or selected one or several layout spaces or a project in the [layout space](Glossary_o_bauraum.htm) navigator.

1. Utilities > Revision control > Change tracking > Delete revision
2. In the Delete revision dialog select the Revision markers check box and / or the Revision data from change tracking check box.
3. Select the Apply to entire project check box if you wish to delete all revision markers / revision data in the project. Otherwise, this information is only deleted for the selected pages or layout spaces.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The revision markers and / or revision data are deleted from the current revision project.

![](../Pictures/Gui/ALL/info.png)Tip:

In the graphical editor and in the [project data](Glossary_o_projektdaten.htm) [navigators](Glossary_o_navigatoren.htm) you have the possibility to delete revision markers for individual selected [objects](Glossary_o_objekte.htm) via the Delete revision marker popup menu item. This action deletes both the revision marker text and the graphical marker.

![](../Pictures/Gui/ALL/note.png)Notes:

- In the case of a project-wide revision the revisioning is deleted completely, if you activate the Revision data from change tracking check box and apply deleting to the entire project. No changes are logged subsequently in the project. The defined working sections must have been deactivated beforehand in order to delete the [revisions](Glossary_o_revisionen.htm) completely at revisioning of defined working sections.
- If a defined working section is active, the revision data of the pages of the project cannot be deleted. In order to delete the revision data of individual pages the defined working sections must have been deactivated beforehand.

### Delete revisions (property comparison)

Precondition:

You have opened a project containing revision markers.

1. Utilities > Revision control > Property comparison of projects > Delete revision
2. In the Delete revision dialog select the Revision markers check box and / or the Revision data of property comparison check box.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The revision markers and / or revision data are deleted from the current project.

![](../Pictures/Gui/ALL/info.png)Tip:

You can delete the revision markers for individual objects by deleting the values of the Revision marker (from property comparison) and  Revision change marker (from property comparison) [properties](Glossary_o_eigenschaften.htm) in the properties dialog. This also deletes the graphical marker.

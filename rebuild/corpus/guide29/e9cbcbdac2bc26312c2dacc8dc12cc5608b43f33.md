# Device boxes: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_bm_kaesten.htm)

### Device boxes

User interface / operation

A rectangle is drawn around the graphical view of items in connection diagrams. If all components of a device lie next to one another, then instead of multiple boxes only one box is drawn, which is then correspondingly larger. The connection points on the box are graphically delimited by a line.

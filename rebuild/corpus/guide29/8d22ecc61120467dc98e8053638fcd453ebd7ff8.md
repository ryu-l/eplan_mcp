# Action: XMActionDCImport

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| ProjectLink | Project name with complete file path. |
| DataConfigurationFile | File path of the data configuration file (\*.edc). |
| ProgressTitle | Specifies the title of the progress bar (optional). |

![](../Pictures/Gui/ALL/note.png)Note:

This action makes it possible to modify the [properties](Glossary_o_eigenschaften.htm) of [functions](Glossary_o_funktionen.htm), pages and / or [connections](Glossary_o_verbindungen.htm) by way of an import. A data configuration file \*edc, for example, can be generated via the menu path Utilities > Edit properties externally > Export functions.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
XMActionDCImport 
/ProjectLink:C:\Projects\EPLAN\test.elk 
/DataConfigurationFile:C:\EPLAN\DataCfgFile.edc
```

# Placing Enclosures

Enclosures are placed in a [layout space](Glossary_o_bauraum.htm) in the 3D mounting layout. The parts management dialog contains various predefined series of enclosures; you can select enclosures from them to be placed. There are two different enclosure types, which are defined in parts management in separate product subgroups. With both enclosure types, the elements are grouped and fixed to the enclosure by the Item is fastened unmovably to the superior item property.

- Body type: The enclosure consists of several 3D [objects](Glossary_o_objekte.htm) (housing, door, mounting panel). The housing is a single 3D object. The individual elements can be deleted in the layout space navigator. AE and CM series enclosures are body-type enclosures.
- Component type: The enclosure consists of several 3D objects (profiles, walls, doors, mounting panel). All the elements of the enclosure can be individually deleted in the layout space navigator. TS 8 series enclosures are [component](Glossary_o_schaltzeichen.htm)-type enclosures.

Preconditions:

- You have opened a project.
- The layout space navigator is open and a layout space is open.

1. Select the menu item Insert > Enclosure.
2. Select the desired enclosure [part](Glossary_o_artikel.htm) in the Part selection dialog.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The enclosure hangs on the cursor as a detailed preview with the height, width and depth defined for the part. The currently selected handle is displayed in red, and is also identified by a red square as a snap point.
4. Press [A] to change the handle.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Every time you click the [A] button, the handle changes clockwise from the "Back left" position to "Back right", "Front right", "Front left".  
     
   ![](../Pictures/Visualisation/ALL/cabinetgui_toggleappendpointenclosure_as.png)
5. Select the Placement options popup menu item to call up the [Placement options](cabinetgui_d_platzieroptionen.htm) dialog. Here you can define an [offset](Glossary_o_offset.htm) between the handle and the cursor position as well as use all the setting options for the multiple placement of enclosures.  
     
   ![](../Pictures/Visualisation/ALL/cabinetgui_offsetappendpointenclosure_as.png)
6. Click to place the enclosure at the desired position.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The enclosure is inserted. The grouping identifier 'S<Enclosure number>' is automatically entered in the navigator and is carried over to all components of the enclosure and to all components placed in the enclosure. All enclosure add-on parts placed with the enclosure are grouped logically. When you move an enclosure or an enclosure item, all the components placed on it are moved as well. The selected part remains at the cursor and can be placed again.

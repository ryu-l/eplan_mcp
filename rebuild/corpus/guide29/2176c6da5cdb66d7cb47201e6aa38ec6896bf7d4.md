# P007021: The device contains both protected and unprotected functions

### Cause

A device has both protected and unprotected [functions](Glossary_o_funktionen.htm).

### Solution

1. Use the Go to functionalities to locate the device in the project.
2. Open the [properties](Glossary_o_eigenschaften.htm) of all functions of the device in turn and check the status of the Protected function check box.
3. For all functions (main and [auxiliary functions](Glossary_o_nebenfunktionen.htm)) of the device, select or deselect the Protected function check box.
4. Then start a new check run.

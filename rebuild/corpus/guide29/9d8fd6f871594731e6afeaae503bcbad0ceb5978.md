# Dialog Configure representation (list)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project and are now in the list view of a navigator, in the list view of the Symbol selection dialog, etc. Select the popup menu Configure representation.

In this dialog you can define the display and sort order of the data so that only the information relevant to you is displayed.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Configuration:

In this field, you can determine which [properties](Glossary_o_eigenschaften.htm) are displayed. By using ![](../Pictures/Gui/ALL/all_new_as.png) (New) you can select further properties and transfer them to the list. The arrow buttons can be used to change the order of the properties.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Select all | Selects all of the entries in the list. |

![](../Pictures/Gui/ALL/note.png)Note:

Certain properties are always displayed. Such properties can not be deleted from the list in the Configuration field. For example the Project name property is always displayed in the list view as a column, in as far as more than one project or no project is opened.

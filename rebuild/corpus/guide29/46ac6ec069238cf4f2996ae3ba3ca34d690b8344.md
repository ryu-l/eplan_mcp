# Managing Wire Harnesses

Wire harnesses can be managed via the wire harness definition. The wire harness definition identifies the wire harness and contains all the relevant data of the wire harness as well as the parts of the wire harness.

### Editing wire harness data

You can edit wire harness [properties](Glossary_o_eigenschaften.htm) at a variety of locations:

- In the dialog Properties <...> you edit the data for the marked wire harness. The most important properties are entered in the fields in the upper section of the Wire harness tab (for example the wire harness name or the DT). In addition to the device tag a wire harness is identified by the wire harness name.
- The wire harness navigator (Wire harness - <Project name> dialog) provides you with an overview of all the [wire harnesses](Glossary_o_kabelbaeume.htm) of open project. Here you can select single or multiple wire harnesses or the components contained in the wire harness. Through the popup menu you can [generate](Glossary_o_erzeugen.htm) wire harnesses or call up the appropriate dialogs for editing them.

### Assigning functions and connections to a wire harness

The assignment of [functions](Glossary_o_funktionen.htm) and [connections](Glossary_o_verbindungen.htm) to a specific wire harness is carried out via the property Wire harness name ([ID](Glossary_o_id.htm) 31143). In the properties table of the [objects](Glossary_o_objekte.htm) you enter the respective wire harness name for this property. In the [navigators](Glossary_o_navigatoren.htm) that display the wire harness data you can use the Wire harness name property as a filter criterion or display it in the list view as a column.

Through editing in tables you can assign or change a wire harness name rapidly and easily for selected functions and / or connections.

### Part

The [part](Glossary_o_artikel.htm) of a wire harness assembly can be entered at the wire harness definition in the first line of the Part tab. The further [lines](Glossary_o_leitungen.htm) of this tab are provided for parts (up to a maximum of 999) for which no corresponding EPLAN functions are available by default.

It is not absolutely necessary to [create](Glossary_o_erstellen.htm) a wire harness assembly in the parts management. It is also possible to store parts only at the individual components of a wire harness (connections, cables, [pins](Glossary_o_steckerkontakte.htm), etc.) during designing.

### Reports

The parts data of the wire harnesses contained in a project can be listed in the bill of materials are be output in the corresponding [reports](Glossary_o_auswertungen.htm) (for example parts list, summarized parts list, etc.). You can specify in the dialog Settings: Parts whether only the wire harness assembly parts or / and the parts of the wire harness components are to be taken into consideration.

The following points are to be considered:

- The Wire harness assembly parts setting takes into consideration those parts that are entered in the [property dialog](Glossary_o_eigenschaftendialog.htm) of a wire harness definition in the first line of the Part tab. This can be an assembly part in the parts management, but does not have to be.
- The Wire harness component part setting takes the parts of the wire harness components into consideration. These are, on the one hand, parts at [main functions](Glossary_o_hauptfunktionen.htm) at which an existing wire harness name is entered for the Wire harness name (ID 31143) property in the property dialog. And on the other hand further parts at the wire harness definition (in the property dialog in Lines 2-1000).
- In the dialog Settings: Parts the [settings](Glossary_o_einstellungen.htm) for the wire harnesses are logically AND-combined with the other settings options. For example in order to output a [cable](Glossary_o_kabel.htm) as a [component](Glossary_o_schaltzeichen.htm) of a wire harness you have to activate the Wire harness component part check box as well as the Cable part check box.

The parts data of the wire harnesses can also be taken into consideration at the output of manufacturing data / labeling. Analog setting options as for the parts reports are available in the Settings tab of the dialog Settings: Manufacturing data export / labeling.

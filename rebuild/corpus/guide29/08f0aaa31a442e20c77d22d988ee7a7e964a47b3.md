# Function templates: Definition of term

### Function templates

User interface / operation

Function templates provide templates for the functions to be used in the project. The templates are not actually used in the project, and have no graphical representation in the schematic. No additional information may be added to a function template. Information can only be added to the function or component. Function templates are defined by the device data (part). They are therefore not a part of the project but rather belong to the part.

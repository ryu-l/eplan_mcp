# PLC Address Formats

EPLAN supports you in the assignment of [PLC addresses](Glossary_o_sps_adressen.htm). The following editing options are available:

- You can define a desired format for PLC addresses.
- You can use separate addressing [formats](Glossary_o_formate.htm) for digital and analog PLC addresses.
- Symbolic addresses can be automatically created according to specific criteria.
- You can define different formats for [assignment lists](Glossary_o_zuordnungslisten.htm).

# Configuring the Display of Placeholder and Special Texts

To arrange [form](Glossary_o_verlauf.htm) and plot frame editing more clearly, so that inserting graphical elements like [lines](Glossary_o_leitungen.htm) and graphics is easier, there are the options described in the following.

Preconditions:

- You have opened a project.
- You have opened the form that you would like to edit in the form editor (Utilities > Master data > Form > Open > [Open]). Or you have opened the plot frame that you would like to edit in the plot frame editor (Utilities > Master data > Plot frame > Open > [Open]).

### Hide placeholder texts

You can temporarily hide the placeholder text.

1. Select the menu [items](Glossary_o_bauteile.htm) View > Hide placeholders.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The [placeholder texts](Glossary_o_platzhaltertexte.htm) are hidden.
2. Edit the graphical elements of the form.
3. Select View > Hide placeholders to display the placeholder texts again.

### Display / output properties as numbers

The [property texts](Glossary_o_eigenschaftstexte.htm) are displayed as texts by default. However, this can be bothersome if there are several entries in a row, for example.

1. Select View > Properties as numbers.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property texts are replaced by their internal [ID](Glossary_o_id.htm) numbers.
2. Edit the form / plot frame as desired.
3. Print the form / plot frame with this setting, to also include the numbers in the printout.
4. Export the form / plot frame with this setting as a PDF file, to also include the numbers in the created PDF file.
5. Select View > Properties as numbers to display the property texts as texts again.

### Display path divisions

It can be helpful to display paths if you want to make sure that you are [placing](Glossary_o_auflegen.htm) a particular object in a particular path.

1. Select the menu items View > Paths.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The path division is displayed in the form / plot frame using lines.
2. Edit the form / plot frame as desired.
3. Select View > Paths to [return](Glossary_o_zurueckbuchen.htm) to the display without paths.

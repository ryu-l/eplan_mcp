# Toggling Project Options

The [project options](Glossary_o_projektoptionen.htm) can be switched on and off, which means that they are selectively included in [reports](Glossary_o_auswertungen.htm) or not. All areas of a project option can only be switched on and off together. Only one project option at a time can be switched on in a project option group. However, It is possible to switch all project options off.

Precondition:

You have opened a project. You have created at least one project option.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Project options > Navigator
2. Select a project option (or a section assigned to a project option) in the Project options - <Project name> dialog.
3. Select the Toggle popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project option is switched on if it was previously switched off. The associated [objects](Glossary_o_objekte.htm) are reported in the project. Existing project options in the same project options group are automatically switched off.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project option is switched off if it was previously switched on. The associated objects are no longer reported in the project.

![](../Pictures/Gui/ALL/note.png)Notes:

- If when a project option is switched on EPLAN reports that the page on which a section is to be shown does not exist, you may have deleted the page on which the section was placed. As the page has been deleted, the project option can no longer be switched on.
- If a page on which a section is to be displayed has been hidden by another project option, a corresponding message will be displayed. First, enable the project option mentioned in the message that contains the page. Then, you can display the section.

![](../Pictures/Gui/ALL/info.png)Tip:

You can also click the icon in front of a project option to switch it on or off. A green check mark indicated that the project option is switched on.

### Transparently display or hide project options

Project options that have been switched off can be displayed transparently or completely hidden. This setting is used as a construction aid when creating several project options at the same place in the schematic and has no effect on the object reporting. Entire pages and [unplaced functions](Glossary_o_nicht_platziertefunktionen.htm) can only be completely hidden and cannot be displayed transparently.

Precondition:

You have opened a project. You have created at least one project option.

1. Select the following menu items: Project data > Project options > Navigator
2. Select a project option (or a section assigned to a project option) in the Project options - <Project name> dialog.
3. Select the Make transparent (On/Off) popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Deactivated project options are displayed transparently when they were previously completely hidden.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Deactivated project options are completely hidden when they were previously displayed transparently.

# Creating Properties Comparison Schemes

In a [properties](Glossary_o_eigenschaften.htm) comparison scheme, you specify which properties should be compared with each other in the project comparison operation of the project verification.

Preconditions:

- [Select a project management database](prjmanagementgui_h_projekteverwalten.htm)
- [Load directories with projects](prjmanagementgui_h_verzeichniseinlesen.htm)

1. Project > Management
2. Select a project.
3. Select [Extras] > Verify project.
4. Click [...] next to the Compare properties check box.
5. Next to the Scheme field click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
6. In the New scheme dialog enter a recognizable name for the new scheme in the Name field and click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) Properties from the [project data](Glossary_o_projektdaten.htm) groups "Devices", "Connections", "Graphic", "Pages", "Potentials", and "Project" are shown in the tabs.
7. Select one of product data group tabs.
8. To select properties for the properties comparison, select one or more properties in the Do not compare field and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).
9. Click  [Save] and then click OK.  
      
    ![](../Pictures/Gui/ALL/arrow.png) [Verify project](processreceiptcontrol_h_eingangskontrolvorber.htm)

# P026054: Connections of the cable are not defined uniquely

### Causes

The following causes are possible:

- No [connections](Glossary_o_verbindungen.htm) are assigned to the [cable](Glossary_o_kabel.htm) (cable without connections).
- Not all the connections of the cable can be routed. This may have the following causes:   
    
  - Source and / or target of a cable connection are not placed.  
    
  - Source and target of a cable connection are placed in different layout spaces.  
    
  - There are several [part placements](Glossary_o_artikelplatzierungen.htm) with an identical DT for the source or the target, and the searched connection point designation does not exist in any connection point pattern.  
    
  - There are several [part](Glossary_o_artikel.htm) placements with an identical DT for the source or the target, and the searched connection point designation exists several times in all the [connection point patterns](Glossary_o_anschlussbilder.htm).

### Solutions

You have the following solutions:

- Place the source and / or the target of the corresponding cable connection.
- Place the source and target of the corresponding cable connection in the same [layout space](Glossary_o_bauraum.htm).
- Add the missing [connection point designations](Glossary_o_anschlussbezeichnungen.htm) in a connection point patterns.
- Check the connection point patterns on several occurring connection point [designations](Glossary_o_bezeichnungen.htm).

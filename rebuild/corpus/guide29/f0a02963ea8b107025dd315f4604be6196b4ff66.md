# Importing Connection Data and Routing Connections

Routing data are imported from files with the file extension TXT, CSV, ASC and from MS Excel files (\*.XLS, \*.XLSX, \*.XLSB, \*.XLSM) into an EPLAN project that is open or is marked in the page navigator.

Preconditions:

- You have opened a project.
- Connection data from an external program are available in the [form](Glossary_o_verlauf.htm) of a text or an MS-Excel file.

1. Select the menu [items](Glossary_o_bauteile.htm) Project data > Connections > Import > Routing connections.
2. Select the file type ("Text" or "Excel") from which you want to import connection data in the Type of data source field of the dialog Import device data.
3. Click [...] next to the Data source field.
4. In the dialog [Select data source](projectprocessinggui_d_datenquelleauswaehlen.htm) select the file from which importing is to be carried out and carry out the required [settings](Glossary_o_einstellungen.htm).
5. Click [OK].
6. Enter a text with which the position of the respective wire connection of terminals is to be identified in the Designation for internal / external fields in the dialog Import connection data.
7. In the Import connection data dialog, click [...] next to the Field assignment field.
8. Specify in the Property column of the dialog Field assignment which EPLAN [properties](Glossary_o_eigenschaften.htm) are to be assigned to the [designations](Glossary_o_bezeichnungen.htm) of the external data fields that are listed in the External data field name column.
9. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The dialog Synchronize routing connections displays the connection data from the data source and their assignment to [routing connections](Glossary_o_verlegeverbindungen.htm) in the EPLAN project. In the process an analysis is carried out and the Status column then displays whether [connections](Glossary_o_verbindungen.htm) are already contained in the project or not.
10. Specify in the Action column in the dialog Synchronize routing connections what is to happen with the connections depending on the displayed status:

| Status | | Action |
| --- | --- | --- |
|  | New | Import or None |
|  | Identical | None |
|  | Additional | Delete or None |
|  | Changed | Apply change or None |
|  | Invalid | None |

11. You can set a trade-specific filter in the Filter field in order to reduce the scope of display in the dialog Synchronize routing connections to the EPLAN properties of one routing connection.
12. In a marked row in the dialog Synchronize routing connections select the popup menu item Assign part to automatically assign a suitable [part](Glossary_o_artikel.htm) number existing in the parts database to the routing connections to be imported.
13. If no automatic assignment is possible, click the [...] button in the Part number column to open the part selections and select a part there manually.
14. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The import or the selected [actions](Glossary_o_aktionen.htm) are carried out.

| Status | | Action | Result |
| --- | --- | --- | --- |
|  | New | Import | Routing connections are imported |
|  | Identical | None | Routing connection remains in the project |
|  | Additional | Delete | Routing connection is deleted from the project |
| None | Routing connection remains in the project |
|  | Changed | Apply changes | Changed property values are applied |
| None | Changed property values are not applied |
|  | Invalid | None | Routing connection is not imported |

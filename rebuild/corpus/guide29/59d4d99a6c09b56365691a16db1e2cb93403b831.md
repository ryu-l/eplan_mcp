# Dialog Sorting / Dialog New page if property is changed / Dialog New numbering at changed property

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Sorting dialog call:](javascript:void(0);)

You have opened a project. Utilities > Reports > Generate. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New). In the Select report dialog, select a [report type](formgeneratorgui_k_auswertungstypen.htm).Click [OK]. In the Settings - <Report type> dialog click [...] next to the Sorting field.

This dialog is used to [create](Glossary_o_erstellen.htm), edit, and administer sorting [schemes](Glossary_o_schemata.htm) for [reports](Glossary_o_auswertungen.htm). In sorting schemes for reports you define sorting criteria specifying the sorting order of project and parts data in reports.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)New page if property is changed dialog call:](javascript:void(0);)

You have opened a project. Utilities > Reports > Generate. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New). In the Select report dialog, select a [report type](formgeneratorgui_k_auswertungstypen.htm).Click [OK]. In the Settings - <Report type> dialog click [...] next to the New page if property value has changed field.

This dialog is used to create, edit, and administer page-break schemes for reports. In page break schemes you define page break criteria defining when page breaks are to be inserted in [report pages](Glossary_o_auswertungsseiten.htm).

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call: New numbering at changed property:](javascript:void(0);)

You have opened a project. You have opened the bill of materials navigator, marked several positions there and have selected the Add item numbers popup menu item. In the Number items dialog click [...] next to the New numbering at changed property field.

This dialog is used to create, edit, and administer numbering schemes for the assignment of item numbers. Such a scheme can be used to assign the item numbers structure- or page-specifically. To this purpose you define criteria that specify when numbering begins again with the starting value.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Category / property:

Depending on the dialog, you define the sorting criteria, the page break criteria or the numbering criteria in this field.

To define sorting criteria, click ![](../Pictures/Gui/ALL/all_new_as.png) (New) and select all the desired [properties](Glossary_o_eigenschaften.htm) in the subsequent dialog.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Select the following properties, one after another:

- Higher-level function
- DT: Identifier
- Mounting location.

Save the scheme. If you now [generate](Glossary_o_erzeugen.htm) a report, then the project or parts data in the output are first sorted by [higher-level function](Glossary_o_anlage.htm), then by DT identifier, and finally, by [mounting location](Glossary_o_einbauort.htm).

![](../Pictures/Gui/ALL/note.png)Note:

Please note that the Function definition ([ID](Glossary_o_id.htm) 20026) property is available as a sorting criterion for the non function-related reports parts list, summarized parts list and device tag list, so that [functions](Glossary_o_funktionen.htm) can also be sorted alphabetically.

To define page break criteria, click ![](../Pictures/Gui/ALL/all_new_as.png) (New) and select the desired property whose property value defines a page break in the subsequent dialog. When the report is generated, a new page is generated whenever the property value of the selected property changes.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You wish to generate a device tag list. Your project contains two [structure identifiers](Glossary_o_strukturkennzeichen.htm) for the "Higher-level function" identifier block:

EB1
  
FB1.

If you now select the Higher-level function property for the page break, when the report pages are generated, a page break is inserted after the last device assigned to the EB1 higher-level function. The first device of the FB1 higher-level function is then output on a new report page, because the higher-level function has changed.

To define numbering criteria for the assignment of item numbers, click ![](../Pictures/Gui/ALL/all_new_as.png) (New) and select all the desired properties in the subsequent dialog.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Select the property Higher-level function as the criterion. Save the scheme. When you now number the [items](Glossary_o_bauteile.htm), numbering restarts from the starting value as soon as the structure identifier for the higher-level function changes.

# Creating and Editing Terminal Strips

Terminal strips are managed via the terminal strip definition and can be created in the terminal strip navigator, the device navigator, and when inserted into the schematic.

If you would like to [create](Glossary_o_erstellen.htm) a terminal strip with predefined [properties](Glossary_o_eigenschaften.htm), you first have to create a terminal strip definition. In doing so, you can specify the terminal strip construction.

If you would like to just create a new terminal strip (without other properties), simply enter the DT for the terminal strip in the Properties <...> dialog when you insert the terminal. A non-default terminal strip will be generated that has no terminal strip definition. A non-default terminal strip of this sort is visible in [reports](Glossary_o_auswertungen.htm) but you cannot assign properties to it (this is only possible via the terminal strip definition).

Initially, you can create non-default terminal strips and then edit their properties later on. However, you can also specify [settings](Glossary_o_einstellungen.htm) for the terminal strips upon creation. You can use the function definition to [generate](Glossary_o_erzeugen.htm) a terminal strip with default properties.

In the [Terminal strip definition](devicetaggui_r_klemmenleisten.htm) tab of the [property dialog](Glossary_o_eigenschaftendialog.htm) you can edit the properties of a terminal strip.

### Create terminal strips

1. Select the Project data > Terminal strips > Navigator menu [items](Glossary_o_bauteile.htm).
2. Select the Generate terminal strip definition popup menu item.
3. In the Properties <...> dialog, in the Terminal strip definition tab, enter the desired data for the new terminal strip.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) A terminal strip definition with the appropriate properties will be created. If you do not enter any data, a non-default terminal strip will be created. You can then define this at a later time.

### Generate terminal strips with default properties

1. Select the Project data > Terminal strips > Navigator menu items.
2. Select a DT and select the New popup menu item.
3. In the Function definitions dialog select the lowest possible level "Terminal strip definition" in the tree view.
4. Click [OK].
5. In the Properties <...> dialog, in the Terminal strip definition tab, enter the desired data for the new terminal strip.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Below the selected DT, a terminal strip definition with the appropriate properties will be created. If you do not enter any data, a non-default terminal strip will be created. You can then define this at a later time.

![](../Pictures/Gui/ALL/info.png)Tip:

You can copy and place terminal strips using Drag & Drop, by dragging a highlighted terminal strip from the navigator onto the open schematic page in the graphical editor.

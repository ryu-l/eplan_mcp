# Dialog Parts management

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have opened a parts database using [Extras] > Settings.

In this dialog, you manage the [master data](Glossary_o_stammdaten.htm) of your parts and people databases (for customers and manufacturers / suppliers); parts management contains both technical and sales data.

Overview of the main dialog elements:

Field-based filter:

This drop-down list displays all the available [filters](Glossary_o_filter.htm). A selected filter is automatically activated and is applied to both the tree and the list view. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the [Filter](modaldialogsdb_d_filternnach.htm) dialog. Here you can [create](Glossary_o_erstellen.htm), edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

- Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
- Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

Full-text filter:

Enter the text to be found in this box, and click ![](../Pictures/Gui/ALL/all_search_as.png) (Find). The text is then searched for in all data records; in tree view, this search also includes the main nodes "Accessory list", "Accessory placement", "Drilling pattern", and "Connection point pattern". The main nodes "Customer" and "Manufacturer / supplier" are not considered here!   
If you are using this search for the first time, you must click [OK] to [generate](Glossary_o_erzeugen.htm) the search index. Otherwise the search index can be updated at any time by using [Extras] > Update search index.  
Click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) to delete the search term and [return](Glossary_o_zurueckbuchen.htm) to the full parts display.

The following rules apply to the search term syntax:

| Input | Found terms | Example |
| Single word, e.g., search text terminal | A [part](Glossary_o_artikel.htm) is found containing the text terminal in at least one text field. This text can be part of a word. The search is not case-sensitive. | Parts are found with: Type number: Terminal or Type number: Terminal red or Designation 1: Terminal block or Attributes, value in Row 3: Feed-through terminals. |
| Single word, e.g., search text "Isolating terminal with fuse" | This search will find those parts that contain exactly this string. The search is not case-sensitive. |  |
| OR operation, e.g., search text terminal motor | The parts found are those containing the text terminal or motor in the text boxes. There may be different text boxes for the individual parts. | Parts are found with: Type number: Terminal or  Designation 1: 3-phase motor 10 kW or  Attributes, value in Row 3: Feed-through terminals. |
| AND operation, e.g., search text terminal +motor or +terminal + motor | For this AND operation, a space must be entered between the first search term and the plus sign. The parts found are those containing the text terminal and motor in the text boxes. The two texts may both be contained within a text field (such as the text entry motor protection terminal) or may appear in different fields. | Parts are found with: Type number: Terminal for miniature motor or  Designation 1: 3~motor 10 kW and Description: Connection point via terminals or  Attributes, value in Row 2: Motor overload, value in Row 3: Terminal box.  Note:  This AND operation can then only be used if a [SQL server](Glossary_o_sql_server.htm) is used as the parts database. If Access databases are used, the search term Terminal +motor would have the same effect as Terminal motor; thus it would be treated as an OR operation. |
| Spaces in the search text, e.g., search text = "OPC 53" | A part is found containing the text OPC 53 in at least one text field. Omitting the " character at the start and end of the search text would return parts that contain "OPC" or "53". | This search alternative can be combined with AND and OR: A search text: "OPC 53" Festo finds all parts which contain the character string "OPC 53" or Festo. |

![](../Pictures/Gui/ALL/note.png)Note:

Do not use placeholder characters (such as "\*", "?" or "\_") for the full-text search as these will not be returned by the search. These restrictions are caused by the search mechanisms of the databases used.

Tree:

In this tab the [part types](Glossary_o_artikeltypen.htm) as well as customers and manufacturers / suppliers can be displayed in a hierarchical tree structure, where the individual part numbers or, if present, part [variants](Glossary_o_varianten.htm) can be entered as last hierarchy [levels](Glossary_o_etagen.htm).  
The display can be configured as required for parts via [Extras] > Settings.

List:

As an alternative to the tree, you can also display the data in a list, where the scope of the display is set using the Configure representation popup menu item. Here, the list shows all parts, but no manufacturers, suppliers, or customers, and only those [properties](Glossary_o_eigenschaften.htm) are shown which all parts have (such as for example, part number, product group, and so on).

Combination:

This tab contains a combined view of the parts tree and list: You can preselect parts in the tree view in the top part of the tab. When you select a node such as the "Cables" product group in the tree, the associated parts are displayed in the list below.  
The scope of the display can also be specified here using the popup menu item Configure representation options.

The tabs displayed in the dialog on the right-hand side relate to the selection made in the tree, list or combined view. When selecting a customer, the detailed view for this customer is displayed, while for cables the [cable](Glossary_o_kabel.htm)-specific tabs are shown.

Info:

In this tab information such as the name and Version of the currently used parts database, the number of contained parts, the number of manufacturers / suppliers, [drilling patterns](Glossary_o_bohrbilder.htm), accessory lists, etc. is displayed. The content of the tab is automatically updated during opening. However, it can be updated at any time manually by using [F5].

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Adjust column width (list only) | Adjusts the width of all table columns so that both the headings and column contents are fully legible. |
| New | On the hierarchy level of part types or, for the components, on the hierarchy level of the [product groups](Glossary_o_produktgruppen.htm): generates a new part of the desired type ([component](Glossary_o_schaltzeichen.htm), housing, etc.) or of the current generic product group / product subgroup / product group, where the name is defaulted with New\_<consecutive\_number> (selection of a hierarchy level) or <original\_part\_number>\_<consecutive\_number> (selection of a part).  On the hierarchy level of the master person data groups: generates a new customer or manufacturer / supplier, where the name is also defaulted with New\_<consecutive\_number> (selection of the hierarchy level) or <original\_part\_number>\_<consecutive\_number> (selection of a customer or manufacturer / supplier).  In the list: Creates a new part of the respective type (component, housing, etc.) or of the current generic product group / product subgroup / product group, where the name is defaulted with <original\_part\_number>\_<consecutive\_number>. |
| Paste technical data | After copying one part its variable data and the [function templates](Glossary_o_funktionsschablonen.htm) are inserted. This data is copied into the currently selected record, and any data already present is deleted first. |
| Paste function templates | After copying one part, inserts its function templates / [function definitions](Glossary_o_funktionsdefinitionen.htm), i.e., the data in the Function templates and Function definition tabs. This data is copied into the selected records. After a confirmation prompt, the existing function templates / function definitions are replaced by the templates / function definition being inserted. |
| Paste [safety-related values](Glossary_o_sicherheitskennwerte.htm) | After copying one part, inserts its safety-related values, i.e. the data on the Safety-related values tab. This data is copied into the selected records. After a confirmation prompt, the existing safety-related values are replaced by the values being inserted. |
| List with preselection (tree only) | Reduces the number of elements displayed in order to allow for a faster orientation in the list view. If this option is activated, the list view is called up with an automatic filter (preselection) containing the elements that are currently selected. |
| Configure representation | Opens the Configure representation dialog. There you can display or hide the additional display of the part designation for the tree view or specify the display of columns for the list view. |
| Export | Opens the Export records dialog for the selected records, where you can determine the name and type of export file. If the current selection contains nodes (in the tree view) then all the records under those nodes will be taken into account. |
| Assign function templates | Allows you to generate still missing function templates automatically from the stored [macros](Glossary_o_makros.htm) for the highlighted records. Note that the Undo action is not available for this functionality! Therefore back up the parts data before major changes. |
| Update via Data Portal | Updates the marked parts by means of the EPLAN Data Portal.  Note:  This is only possible if you are logged in at the EPLAN Data Portal and if you additionally have an EPLAN Data Portal Professional license. |

Both "normal" insertion and insertion of technical data always apply only to the relevant data, i.e., copied data might not be inserted if the target part cannot store this data.

Copying the cable HELU.33 with order number ABC and bending radius 50 cm. Insertion of this part as a single component, resulting in: A component HELU.33 with order number ABC. Since single components have no bending radius, the value of 50 cm is ignored.

[Extras]:

| Menu item | Meaning |
| --- | --- |
| Import | Opens the Import records dialog, in which you can specify the file name and type, and must select how the records to be imported should be handled. |
| Import Festo shopping basket | Allows importing of parts from the shopping basket of the Festo product catalog. |
| Export | Opens the Export records dialog, in which you must specify the file name, file type, and scope of the export. |
| Space requirement | Automatically calculates for all selected parts how much space they require, and enters the results in the field of the part of the same name (Mounting data tab). For this action to be executed, the corresponding part-specific values (e.g., "Width", "Height") must be entered in the Mounting data tab. |
| Prices | Opens the Calculate prices dialog, in which you can enter the purchase price EPLAN should calculate. The action applies to all marked parts. |
| Currencies | Opens the Convert currencies dialog, in which you must enter the data for the conversion of different currencies. The action applies to all marked parts. |
| Translation | Opens a flyout menu with options for automatic translation. |
| Sum up function templates | Sums up the function templates for the parts under an assembly / module (recursively) and enters them into the assembly / module. In the process [modules](Glossary_o_module.htm) with a template for a black box are supplemented. The black box is required as a grouping element and has the part number of the module assigned to it. |
| Assign function templates | Allows you to generate still missing function templates automatically from the stored macros for all records. Note that the Undo action is not available for this functionality! Therefore back up the parts data before major changes. |
| Update search index | Updates the search index for the full-text filter. |
| Configure properties | Opens the Configure properties dialog in which you create and configure [user-defined](Glossary_o_benutzerdefiniert.htm) properties for parts. |
| Settings | Opens the dialog Settings: Parts (user)   - for selecting an existing database or for generating a new database (Access or SQL) - for defining general [settings](Glossary_o_einstellungen.htm) relating to working with parts management. |

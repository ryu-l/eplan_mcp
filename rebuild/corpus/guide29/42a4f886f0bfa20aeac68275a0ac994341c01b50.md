# Page Scale

For graphics and mounting panel pages, the drawing area is enlarged or shrunken when the scale is changed. In addition, the plot frame and the [form](Glossary_o_verlauf.htm) are appropriately scaled. The graphics contained on the page are not changed, with the exception of the dimension style.

The page scale can be specified in the page [properties](Glossary_o_eigenschaften.htm).

| Object | Value |
| --- | --- |
| Graphical [objects](Glossary_o_objekte.htm) | No matter the scale. Size values for graphical objects are not changed. |
| Pattern length | No matter the scale. The value of the pattern length for graphical objects is not changed. |
| Texts | No matter the scale Font sizes are not changed. |
| Symbol labels | No matter the scale. |
| Dimension text | Depending on the scale. The font size (formatting of the dimension value) is changed. |
| Dimension line termination | Depending on the scale. |
| Dimension value | No matter the scale. The value of the dimension is not changed. |

If the value is independent of the scale, this means that the values of the elements (i.e. the sizes) will not change. Graphically, these elements become larger or smaller, but this is just relative to the page format selected.

If the value is dependent on the scale, this means that the values of the elements (i.e. the lengths) will change depending on the scale. The elements thus become larger or smaller. These elements remain visually identical relative to the page format selected.

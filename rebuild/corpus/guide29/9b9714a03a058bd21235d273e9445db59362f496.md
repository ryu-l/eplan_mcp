# Inserting Distributed Terminals

Preconditions:

- You have opened a schematic page in the graphical editor.
- You have set the function definition for the [distributed terminals](Glossary_o_teilklemmen.htm) in the project [settings](Glossary_o_einstellungen.htm) (Options > Settings > Projects > "Project name" > Devices > Terminals (distributed terminals)).

1. Select the Insert > Distributed terminal menu [items](Glossary_o_bauteile.htm).
2. Place the distributed terminal on the page.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The distributed terminal automatically receives the function definition that is set in the Settings: Terminals (distributed terminals) dialog.
3. Enter the device data for the terminal on the Terminal tab in the Properties <...> dialog. At least the DT must be entered; the connection point designation and description can be assigned automatically even after optimizing the distributed terminals.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you specified an existing DT, the terminal will be assigned to the corresponding terminal strip. If you specified a new DT that does not already exist, then EPLAN will [generate](Glossary_o_erzeugen.htm) a new terminal strip. However, this strip will have no terminal strip definition.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you specified an existing terminal designation, the distributed terminal will be assigned to the corresponding terminal.

![](../Pictures/Gui/ALL/note.png)Note:

In the Display tab of the [property dialog](Glossary_o_eigenschaftendialog.htm) the [connection point designations](Glossary_o_anschlussbezeichnungen.htm) of terminals are listed by default in the property arrangement. This takes place in the Connection points tab via the indexed property Symbol: Connection point designation ([ID](Glossary_o_id.htm) 20028). So that the connection point [designations](Glossary_o_bezeichnungen.htm) of the distributed terminals are visible in the schematic and can be printed, you have to activate the check boxes Visible and Print in the layer management for the layer EPLAN430, Property placement.Terminal connection point designations.

![](../Pictures/Gui/ALL/info.png)Tip:

You can modify the symbol during entry with the [Backspace] button.

### Inserting distributed terminals as device

A terminal can also be entered by inserting [devices](Glossary_o_betriebsmittel.htm) as distributed terminals in the project. They are numbered automatically.

The Placing from number of connection points project setting specifies from how many [connection points](Glossary_o_anschluesse.htm) with connection point designations (1, 2, 3, 4, 6, 8, never) a terminal is divided into distributed terminals when devices are inserted. Connection points without connection point designations are not counted here.

Preconditions:

- You have opened a schematic page in the graphical editor.
- In the project settings (Options > Settings > Projects > "Project name" > Devices > Terminals (distributed terminals)) you have used the Placing from number of connection points option to set the number of connection points from which terminals are entered as distributed terminals when devices are entered.
- You have defined terminal devices in parts management whereby the [function templates](Glossary_o_funktionsschablonen.htm) contain connection point designations.

1. Select the menu item Insert > Device.
2. Select the desired terminal in the Part selection dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the selected terminal has at least the same number of connection point designations as stated in the Placing from number of connection points project setting, the symbol for the first distributed terminal hangs on the cursor and the first connection point designation for the terminal is displayed.
3. If required, use the [Tab] key to change the direction of the connection point.
4. If necessary "scroll" through the available [functions](Glossary_o_funktionen.htm) using the [N] button until the desired function and its connection point designation hangs on the cursor. Or press the [Spacebar] to move to the next terminal device.
5. Place the distributed terminal on the page.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The first distributed terminal automatically becomes the main terminal.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The other distributed terminals are hung on to the cursor in succession with their connection point designations and the associated [connection point descriptions](Glossary_o_anschlussbeschreibungen.htm). Empty connection point designations are skipped and cannot be entered.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If a symbol or macro has been entered on a function template this is placed.
6. Then place other distributed terminals.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If all the connection point designations from the function template have been placed, the next function is offered for [placing](Glossary_o_auflegen.htm).

![](../Pictures/Gui/ALL/info.png)Tips:

- Use [symbols](Glossary_o_symbole.htm) for which the connection points used for the internal [connections](Glossary_o_verbindungen.htm) are not drawn. In this way the schematic stays clearer and the risk of entering connection point designations on the wrong connection points is reduced.
- When inserting distributed terminals as a device a separate distributed terminal is placed for each connection point designation. If you want to show several connection points of a terminal with a [component](Glossary_o_schaltzeichen.htm), you must then enter the other connection point designations manually on the relevant distributed terminal.

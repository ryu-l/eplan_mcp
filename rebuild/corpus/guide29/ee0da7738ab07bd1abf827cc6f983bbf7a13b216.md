# Dialog Generate functions

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened a navigator that displays device data. Select a device tag. Select the New functions popup menu item.

In this dialog you [generate](Glossary_o_erzeugen.htm) multiple [functions](Glossary_o_funktionen.htm) in the respective navigator for a new or existing DT according to a particular numbering pattern. This functionality is only available for particular functions (terminals, [pins](Glossary_o_steckerkontakte.htm), coil and relay contacts, device, and PLC [connections](Glossary_o_verbindungen.htm) and [busbars](Glossary_o_sammelschienen.htm)). Functions without [connection points](Glossary_o_anschluesse.htm) (for example [PLC connection points](Glossary_o_sps_anschluesse.htm) with the function definition "PLC connection point, internal, general") cannot be generated with this functionality. Depending on the selected function definition, the numbering pattern defines either terminal, contact, or [connection point designations](Glossary_o_anschlussbezeichnungen.htm).

Overview of the main dialog elements:

Full DT:

The full DT to which the function will be assigned is displayed in this field. The DT of the device you selected in the navigator is displayed. You can change the DT or enter a new DT.

Numbering pattern:

Enter the numbering pattern in this field. For terminals, [plugs](Glossary_o_stecker.htm), and coil contacts, the numbering pattern determines the terminal, plug, and coil contact [designations](Glossary_o_bezeichnungen.htm). For other functions, the numbering pattern defines the connection point designations.

Function definition:

This field contains the function definition used for the new functions. The [...] button opens the Function definitions dialog where you can select a different function definition.

Number of connection points:

The value in this field defines how many connection points every new function possesses. The number of connection points depends on the selected function definition.

Number of new functions:

The value in this field defines how many new functions are generated. The number of new functions depends on the numbering pattern and the number of connection points defined in the function definition.

Multi-level terminal:

If this check box is activated, multi-level terminals are formed from the generated terminals.

Number of levels:

The value in this field defines how many [levels](Glossary_o_etagen.htm) each generated multi-level terminal has.

Number by levels:

If the check box is selected, the terminals are numbered by level. If the check box is deselected, the terminals are numbered by terminal.

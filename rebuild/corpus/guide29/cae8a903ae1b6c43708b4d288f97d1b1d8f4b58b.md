# Using the List View

In addition to the tree view, which shows the data in a hierarchical structure, the List tab is available, with which you can display all parts, but not manufacturers, suppliers, or customers; only those [properties](Glossary_o_eigenschaften.htm) are displayed which all parts have (for instance, [part](Glossary_o_artikel.htm) numbers, product group, etc.).

List and tree update each other. This means that if a part is selected in the tree, it is also selected in the list (and vice versa). If a node (that is, a hierarchical level) is selected in the tree, then in the list, the first part is selected which is located below that level.

The field-based, full-text, and automatic [filters](Glossary_o_filter.htm) are also used in the list view; only parts data are, however, evaluated here..

### Configure list view

Precondition:

- You have opened the parts management: Utilities > Parts > Management.
- You have selected the List tab.

1. Select the Configure representation popup menu item.
2. In the Configure representation dialog, select the properties which should be displayed in the list, by selecting the corresponding check box.
3. Click [OK].

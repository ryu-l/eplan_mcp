# Dialog Settings: PLC

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Options > Settings > Projects > "Project name" > Devices > PLC.
- Project data > PLC > Addresses / assignment lists. In the dialog Addresses / assignment lists select [Extras] > Settings.

In this dialog, you define the [project-wide settings](Glossary_o_projektweiteeinstellungen.htm) for PLC data.

Overview of the main dialog elements:

Use address if search for symbolic address is unsuccessful:

If this check box is activated, the (real) address is copied into the symbolic address when the search for the symbolic address does not supply a result. This is the case when no sensor or actuator is found during [target tracking](Glossary_o_zielverfolgung.htm). Detailed information is available in the section "[Automatic Assignment of Symbolic Addresses](plcgui_k_symbolischeadressen.htm#I_AutomatischeVergabe)".

If the check box is deactivated, the symbolic address remains empty when the search for the symbolic address does not supply a result.

Treat sensors and actuators equally:

If this check box is checked, no differentiation is made between sensors and actuators when doing target tracking. The search for a target ends as soon as a sensor or actuator is found.

If the check box is not checked, only sensors are searched for from an input, and only actuators from an output.

Extended adoption of path function text:

If this check box is activated, a path function text is searched for in the existing [schematic paths](Glossary_o_schaltplanpfade.htm) at [PLC connection points](Glossary_o_sps_anschluesse.htm) that do not have a path function text and for which no entry was found in the Function text (automatic) field of the connected sensor or actuator. Depending on the connection point direction, a found function text is adopted from the left or from above.

If the check box is not activated, the search for a path function text for the connected sensors and actuators is canceled. The check box is deselected by default.

Assign identifier during import:

This check box is only relevant for the PLC data import in AutomationML format. This is used to specify how DTs for new [devices](Glossary_o_betriebsmittel.htm) (meaning devices for which a DT does not exist in the import file) are assigned during importing. DTs existing in the import file are always imported irrespective of this setting and overwrite the DT existing in the project. The devices are identified on the basis of the AutomationML GUID. If the DT is empty in the import file and the device already exists in EPLAN, this device retains its DT.

If this check box is activated, identifiers are automatically assigned for new devices during the import of PLC data. The identifier set specified in the [Settings for online numbering](numerationgui_d_einstellnummerierung.htm#AktKennbuchstabensatz) is used to this purpose. A question mark is also inserted as a tag before the identifier.

If the check box is deactivated, identifiers are not assigned to new devices during importing. The devices are numbered automatically and additionally marked by a question mark.

Interruption macro for rack layout:

Here you specify the macro used in the PLC schematic generation to graphically identify an interruption point on a [rack](Glossary_o_baugruppentraeger.htm) overview. The variant E in this macro file must contain the graphic for the interruption point and the variant F must contain the graphic for the continuation. Click [...] to open the Select macro dialog and select a file from any desired directory.

PLC-specific settings:

Here you define the PLC type-specific [settings](Glossary_o_einstellungen.htm). The scheme determined here is always used whenever a CPU has not been assigned a scheme. Select an existing scheme from the drop-down list. Click [...] to open the Settings: PLC-specific dialog which you can use to define or edit a scheme.

# Exchanging Symbols in Placeholder Objects via Value Sets

In [placeholder objects](Glossary_o_platzhalterobjekte.htm) it is now possible to exchange [symbols](Glossary_o_symbole.htm) via the selection of value sets. To this purpose the new property Symbol ([ID](Glossary_o_id.htm) 20575) is available to you in the Assignment tab for the property selection of [functions](Glossary_o_funktionen.htm). If a variable is entered for this property, you can - with a click - open the symbol selection in order to select a different symbol for a value set in the Values tab.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

Since you exchange the symbols by means of value sets, fewer macro [variants](Glossary_o_varianten.htm) are required.

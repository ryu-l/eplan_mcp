# Completing Projects / Defined Working Sections

In EPLAN, [projects](Glossary_o_projekte.htm) can be completed at any time. The project is then write-protected and can no longer be changed. A completed project is stored in the project directory with the file extension \*.elr.

Defined working sections can be completed at any time. In this case only those pages or layout spaces that belong to the selected defined working sections are write-protected.

Precondition:

You have opened a standard project (file extension \*.elk) or a revision project (file extension \*.ell).

1. Select the menu item Utilities > Revision control > Complete project / section.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you complete a standard project, the project will be write-protected and saved with the file extension \*.elr.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you complete a revision project, the Complete project dialog is opened.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you complete a defined working section, the Complete defined working sections dialog is opened.
2. Enter the revision data (revision index, description and reason for change) in the [Complete project](revisionlogmgtgui_d_projektabschliessen.htm) (or Complete defined working sections) dialog.
3. Select the Generate report when completing project check box if you also want all [report pages](Glossary_o_auswertungsseiten.htm) of the project to be updated when the project is completed.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) All pages of the project / defined working section are completed and the revision data are assigned to all modified pages of the revision project.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you complete a project, the project is write-protected and saved with the file extension \*.elr.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you complete a defined working section, the pages of the defined working section are write-protected.

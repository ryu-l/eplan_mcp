# Dialog Settings: Interruption points for Smart connect

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Options > Settings > Projects > "Project name" > Connections > Smart connect. Click [...] next to the Interruption point symbol field.

Use this dialog to manage and edit the [schemes](Glossary_o_schemata.htm) for the [interruption points](Glossary_o_abbruchstellen.htm) that are used for smart connect.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Symbol selection:

Use the table to edit the interruption point scheme. In such an interruption point scheme for smart connect, the information is provided individually for each connection point direction as well as the source and target pages.

The table contains the following columns:

- Connection point direction: Here, the possible [connection point directions](Glossary_o_anschlussrichtungen.htm) are displayed. You can make separate [settings](Glossary_o_einstellungen.htm) for the symbol for each connection point direction.
- Symbol: Click [...] to go to the Symbol selection dialog and select the desired interruption point symbol.
- Variant: Choose the required symbol variant from the drop-down list.
- Property arrangement: Select one of the possible property arrangements from the drop-down list.
- Distance: Enter the distance between the connection point and insertion point of the interruption point. The default value is 4 mm.

Insert break point for autoconnecting:

This setting is useful if you use interruption points with two [connection points](Glossary_o_anschluesse.htm) for smart connect. If this check box is activated, a break point is inserted automatically at the superfluous connection point of the interruption points. This break point ensures that no additional connection is created.

# Dialog Store image file

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a symbol. Insert > Graphic > Image file. In the Select image file dialog, select the desired image file and click [Open].

Image files in the GIF, JPG, BMP, ICO, PNG, or TIFF [formats](Glossary_o_formate.htm) can be inserted in EPLAN. In this dialog, you can specify whether the image file is to be stored in the symbol library or referenced from the source directory.

The following dialog elements are available:

Keep source directory:

A reference to the image file is inserted in the symbol. If the image file is changed, it is automatically updated as soon as you open the symbol. However, referenced files are not included in backups.

Transfer back:

The image file is stored as a copy in the symbol and thus becomes [part](Glossary_o_artikel.htm) of the symbol library. An image file transferred like this is retained after synchronization of the [master data](Glossary_o_stammdaten.htm), the forwarding of [symbol libraries](Glossary_o_symbolbibliotheken.htm), or a symbol import or export. When changing the image file it is, however, not automatically updated.

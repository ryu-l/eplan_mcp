# Checking Part Placements

When [part placements](Glossary_o_artikelplatzierungen.htm) are placed, the [part](Glossary_o_artikel.htm) placement assumes the [mounting location](Glossary_o_einbauort.htm) of the mounting panel. In the process, a check is performed to see if the part placement has been performed on the correct mounting panel, based on the structure [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) of the mounting panel and the placed device. In addition to this, you can compare the Mounting site (describing) property of the mounting panel with the main function.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

| Mounting panel | Device | Status |
| --- | --- | --- |
| =A1+O1-MP1 | =A1+O1-K1 | Correct |
| =A1+O1-MP1 | =A1+O2-K1 | Error |
| MP1 (Mounting location =O1) | K1 (Mounting location =O1) | Correct |
| MP1 (Mounting location =O1) | K1 (Mounting location =O2) | Error |

Preconditions:

- You have opened a project.
- You have selected Options > Settings > Projects > "Project name" > Management > Message management and in the Settings: Message management dialog, in the Check-related settings field you have clicked [...].

1. If necessary, in the Settings: Messages and checks dialog, select a Scheme for the [settings](Glossary_o_einstellungen.htm), or [create](Glossary_o_erstellen.htm) a new one.
2. Select the Class "Panel layout".
3. Define the individual errors and messages in the table on the right-hand side of the Category and Type of check dialogs by selecting an entry from the drop-down list for each one.
4. Click [OK].

Once you have performed this, when making part placements on the mounting panel, these are then checked according to the settings; if disagreement is found, then a suitable message is displayed.

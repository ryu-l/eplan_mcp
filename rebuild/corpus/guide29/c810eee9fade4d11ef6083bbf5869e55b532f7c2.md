# Dialog Selection list

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the [Settings: Connection numbering](wirenumberinggui_d_verbnumeinstellungen.htm) dialog (for example via the Options > Settings > Projects > "Project name" > Connections > Connection numbering menu [items](Glossary_o_bauteile.htm)). Select a [user-defined](Glossary_o_benutzerdefiniert.htm) scheme in the dialog Settings: Connection numbering and select the Designation tab. In the Format groups  field click ![](../Pictures/Gui/ALL/all_new_as.png) (New). Select "Devices..." or "Grouping..." in the Connection group drop-down list in the dialog Connection numbering: Formats.

In this dialog you select one of the [devices](Glossary_o_betriebsmittel.htm) or grouping values in the project. The connection group is then defined for all [connections](Glossary_o_verbindungen.htm) that are connected to the corresponding function or that have the specified value for the Grouping property.

Overview of the main dialog elements:

When opening the dialog from the "Devices..." entry, the devices in the project are shown in a list with their full and visible DTs.

When opening the dialog from the "Grouping..." entry, the values specified in the Grouping property will be shown in the list.

Value:

If you have selected an entry in the list, the DT is displayed here in its entirety or the value for the grouping is displayed.

# Dialog Settings: Rittal - Athex

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Automatic equipment > Rittal - Athex
- Utilities > Manufacturing data > Automatic equipment Rittal - Athex. Click [...] next to the Machine field.

Use this dialog to specify the [settings](Glossary_o_einstellungen.htm) for the export of data to control the automatic equipment system Rittal - Athex for terminal strips and alignable terminal [accessories](Glossary_o_zubehoer.htm).

Overview of the main dialog elements:

Machine:

The delivery scope includes the machine definition named "Default". If you have generated a different machine as a scheme, you can select and edit other machine definitions from the drop-down list.

You can [create](Glossary_o_erstellen.htm) new [schemes](Glossary_o_schemata.htm), save any changes to a scheme, and copy or delete schemes via the adjacent [Toolbar](schemeconfig_m_schemaschaltflaechen.htm). Schemes can also be imported or exported.

Description:

In this field is the description you entered for the machine in the Description field of the New scheme dialog.

Tabs:

You can use the following tabs to configure the export for the automatic equipment system Rittal - Athex:

- [Tab General (Automatic Equipment Rittal - Athex)](ncgui_r_allgemeinathas.htm)
- [Tab Machine (Automatic Equipment Rittal - Athex)](ncgui_r_maschineathas.htm)

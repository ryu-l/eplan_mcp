# Importing a Missing-word List

You can import a previously exported missing-word list, containing subsequently translated text, into the dictionary.

Precondition:

You have opened a project.

1. Utilities > Translation > Edit dictionary
2. Next to the Dictionary field click [...] and select the desired dictionary in the Open dictionary dialog.
3. Select [Extras] > Import.
4. In the Import dictionary dialog, in the File type field, select the format of the missing-word file.
5. Select the missing-word list and click [Open].
6. To define the source language of the translation, select the source language from the subsequent dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The translated target language text is imported into the dictionary.

# Automatic Generation of Views

It is possible to automatically [generate](Glossary_o_erzeugen.htm) pages with [model views](Glossary_o_modell_ansichten.htm), 2D [drilling views](Glossary_o_bohransichten.htm) and copper unfolds in [projects](Glossary_o_projekte.htm) with mechanical components in layout spaces. The basis for these automatic [reports](Glossary_o_auswertungen.htm) are report templates with specifications for the pages to be created. These templates are created and reported in the dialog Model views â <Project name> on the Templates tab.

How the views are displayed is specified by means of [macros](Glossary_o_makros.htm) that are created individually and assigned to the report templates. Filter [settings](Glossary_o_einstellungen.htm) in the templates are used to configure the basic [items](Glossary_o_bauteile.htm) (enclosures, [mounting panels](Glossary_o_montageplatten.htm), etc.) of which views are created in the layout spaces.

The automatic generation of pages with views on the basis of templates can be used for the standardized representation of views. Through this automated reporting the work required is reduced to a fraction of the time required for manual creation. For you this means a considerable reduction in time for the creation of documentation ready for manufacturing.

# Tab General (Copper Export NC)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Machining > Copper export NC. Select the General tab.
- Utilities > Manufacturing data > Machining > Copper NC. Click [...] next to the Machine field. Select the General tab.

Use this tab to specify the general [settings](Glossary_o_einstellungen.htm) for the NC export of copper [items](Glossary_o_bauteile.htm).

Overview of the main dialog elements:

Output directory:

The copper export NC is generated as an XML file. Enter the storage location in this field. You can specify any drive and subdirectory as the target for the export.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).

Generate file names:

Use this drop-down list to specify the manner in which file names are assigned by default during the copper export NC:

- From consecutive number: If you select this option, EPLAN assigns names to the XML files using the pattern Consecutive number.XML by default. If XML files already exist, EPLAN starts the numbering with the next available number.
- From item designation: If you select this option, EPLAN assigns names to the XML files using the pattern <Item designation>.XML by default.
- From properties: If you select this option, the file name is made up of the [project properties](Glossary_o_projekteigenschaften.htm) plus any freely-definable separators. Use the [...] button to open the Format: Property dialog to configure the file name.

Generate subdirectories:

Use this drop-down list to specify the manner in which subdirectories are generated by default during the copper export NC:

- None: If you select this option, no subdirectories are generated during the export.
- From project structure: If you select this option, subdirectories that reflect the [project structure](Glossary_o_projektstruktur.htm) are automatically generated during the export.
- From properties: If you select this option, the subdirectory name is made up of the project [properties](Glossary_o_eigenschaften.htm) plus any freely-definable separators. Use the [...] button to open the Format: Property dialog to configure the file name. Here you can, for instance, use the "Directory [separator](Glossary_o_trennzeichen.htm)" format element to [generate](Glossary_o_erzeugen.htm) a directory structure with several subdirectories arranged one below the other.

# Dialog Format: Parts data assignment

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have selected the desired elements or pages that are to be saved as a macro. Edit > Create window macro / symbol macro or Page > Page macro > Create. In the Save as dialog select [Extras] > Assign parts data. Click the [...] button in the Assignment column of the Parts data assignment dialog. Then, in the Available format elements list of the Format dialog, select a format element from "Parts data"; then click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right). Or select an existing format element in the Selected format elements list, and click ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit).
- You have inserted a macro box (Insert > Box / connection point / mounting panel > Macro box), or you have double-clicked an existing macro box. Select the Parts data assignment tab. Click the [...] button in the Assignment column of the Parts data assignment dialog. Then, in the Available format elements list of the Format dialog, select a format element from "Parts data"; then click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right). Or select an existing format element in the Selected format elements list, and click ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit).

In this dialog, select a specific property from a group of [properties](Glossary_o_eigenschaften.htm) and define the formatting for this.

Overview of the main dialog elements:

Category:

From the drop-down list select the properties that should be displayed in the list below. The list displays all properties of the selected type that have not yet been assigned a formatting.

Minimum number of digits:

Here you define the minimum number of characters to be used for the property value. Smaller values are prefixed with the Filler character defined in the following field. Longer values are displayed in their full length. Only positive numeric values are permitted. A value of zero means that the field width is variable.

Filler character:

The value is padded with this filler character if the entry in the Minimum number of digits field is larger than the width of the value.

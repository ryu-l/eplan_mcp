# P011001: Interruption point without device tag

### Cause

The [structure identifiers](Glossary_o_strukturkennzeichen.htm) in the full device tag are missing at an interruption point. (Only the preceding signs for the [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) selected are displayed.)

### Solution

Open the Property <...> dialog for the interruption point and click the [...] button next to the Full DT field. In the editable fields, enter the structure identifiers you want for the identifier structure specified in the project for [interruption points](Glossary_o_abbruchstellen.htm), or select them using [...]. In the Prefix to Subcounter fields, enter the identifier for the DT. Click [OK] to confirm the entries.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

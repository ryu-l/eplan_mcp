# Updating Symbols

A symbol library stored within a project can be modified outside the project at any time. In this case, the old symbol library stored in the project can be replaced with the modified one. Only the graphic is changed by this, the function remains unchanged.

Precondition:

You have opened a project.

1. Utilities > Master data > Synchronize current project
2. In the Synchronization of master data - <Project name> dialog, in the System master data field, select the symbol library / libraries that have changed outside the project. Multiple selection is possible here.
3. Click ![](../Pictures/Gui/ALL/all_arrowleft_as.png) (Move to the left).  
      
    ![](../Pictures/Gui/ALL/arrow.png) EPLAN compares the libraries with each other and displays a message with the results.
4. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The [project master data](Glossary_o_projektstammdaten.htm) is updated, i.e. overwritten by the [system master data](Glossary_o_systemstammdaten.htm).

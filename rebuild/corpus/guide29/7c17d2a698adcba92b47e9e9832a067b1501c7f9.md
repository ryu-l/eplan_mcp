# Tab Function templates

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have marked a [part](Glossary_o_artikel.htm) in the tree or list. Select the Function templates tab.

![](../Pictures/Gui/ALL/note.png)Note:

Since [function templates](Glossary_o_funktionsschablonen.htm) cannot be defined for [modules](Glossary_o_module.htm), the fields in this tab are grayed out when you are editing a module.

The function template is the most important element for the device comparison process to compare the selected [devices](Glossary_o_betriebsmittel.htm) (via the device selection function) with the devices actually designed in the schematic and to check their correctness. In addition to the function definition, the identifying [properties](Glossary_o_eigenschaften.htm) of the function are also stored in each function template (e.g., the connection point designation). Therefore, you specify here which fields are identifying for the comparison: The comparison is based on the user's predefinitions in the function template.

Enter only the exact [function definitions](Glossary_o_funktionsdefinitionen.htm) in the function templates. The [general function definitions](xfctdefbrowsergui_k_funktionsdefinitionen.htm#I_Grundfunktionsdefinition), for example "Terminal, general, 2 [connection points](Glossary_o_anschluesse.htm)", should not be used in the parts management.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

If the function definition remains empty, then an NO contact with the connection point designations 23Â¶24 is allowed.

In this tab, you use the function template to specify part of the technical properties of a variant; so the function template contains data for a function, where the function is something like a contact, a [cable](Glossary_o_kabel.htm) connection, a male pin, etc. This data can be specified multiple times for each part, that is, once per variant.

![](../Pictures/Gui/ALL/note.png)Note:

The connection point information of the first template is only taken into consideration if several variants exist for this part. During part placement the connection points from the function templates (if existing) are applied if these exist completely in the connection point pattern of the part or if no connection points are defined in the connection point pattern. This means, for example, that auxiliary [blocks](Glossary_o_bloecke.htm) can exist at contactors in different part [variants](Glossary_o_varianten.htm) in order to map differing connection point designations ("13;14" and "23;24" respectively). This is important when generating routing connections.  
  
If you want to work with connection point pattern in several parts variants, the following procedure applies:

1. All the connection points that are to be used in all the variants are defined in the connection point pattern.
2. No new connection points are generated in addition to the selected connection point pattern in the variants themselves.

Overview of the main dialog elements:

Device selection (function templates):

In the table, you define the data to be reported in the Device selection. The table contains one line for each function definition of a part variant. The order of the columns cannot be configured.

The fields which are displayed here next to the Function definition column depend on the selected function definition.

![](../Pictures/Gui/ALL/note.png)Note:

The Description column is of special importance here: A (multilingual) text entered in this column is not applied to the function during the selection of the part / the insertion of a device. For this, the description is displayed in the tree views of the [navigators](Glossary_o_navigatoren.htm). There, the description is displayed in square brackets and is directly behind the function definition.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

![](../Pictures/Gui/ALL/note.png)Note:

The table is switched to "write-protected" when multiple variants / parts are selected, and cannot be edited.

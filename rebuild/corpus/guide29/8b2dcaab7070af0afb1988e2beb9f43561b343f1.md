# Logic pages: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_logikseiten.htm)

### Logic pages

User interface / operation

On logic pages the device data is analyzed and reported, and autoconnecting lines are automatically generated. This does not occur with graphical pages. The page types "Schematic multi-line", "Schematic single-line", "Fluid power schematic" and "Overview" are all logic pages, all other page types are graphical pages.

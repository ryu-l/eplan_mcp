# P017011: Displayed DT contains structure identifiers that are not required

### Cause

One or more [structure identifiers](Glossary_o_strukturkennzeichen.htm) that already exist in the full DT were entered manually in the Displayed DT field in the dialog Properties <...> of a function, a structure box or a black box or an interruption point.

In the case of schematics with [devices](Glossary_o_betriebsmittel.htm) that are placed very closely, manually placed structure identifiers that are already contained in the full DT can rapidly impair the readability of schematics. This check run allows you to determine superfluous structure identifiers and thus keep order in the project.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

In your project you use a page structure with the [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) "Higher-level function" and "Mounting location". You have assigned the structure identifier "ANL" with the [preceding sign](Glossary_o_vorzeichen.htm) "=" to the "Higher-level function" identifier block, the "structure identifier "EBO" with the preceding sign "+" to the "Mounting location identifier block.

On the first page with the full page name "=ANL+EBO/1" you place, for example a signal lamp and open the dialog Properties <...> of the [component](Glossary_o_schaltzeichen.htm).. The "-H1" entry is displayed in the Displayed DT field. In addition to the displayed DT, the Full DT also contains the structure identifiers of the page because EPLAN always imports the page structure that you defined while creating the project for the devices. The page structure is placed in front of the displayed DT. Therefore the entry in the full DT of the signal lamp is "=ANL+EBO-H1".

You now add the string "+EBO" manually to the identifier "-H1" in the Displayed DT so that the displayed DT of the signal lamp is "+EBO-H1". This addition does not have any effect on the full DT since EPLAN recognizes the duplicate entry and reduces it automatically to one entry. So that the full DT remains unchanged. However, in the schematic a longer DT, namely "+EBO-H1", is displayed at the component.

### Solution

1. Locate the function in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Call the dialog Properties <...> of the component and compare the entries in the Displayed DT and Full DT property fields.
3. Delete all the superfluous structure identifiers in the Displayed DT, i.e. all the structure identifiers that are already contained in the Full DT field.
4. Then start a new check run.

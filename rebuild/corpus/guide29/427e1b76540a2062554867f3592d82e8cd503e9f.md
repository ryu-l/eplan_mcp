# Dialog Symbol library properties - <Library name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Utilities > Master data > Symbol library > New > [Save].
- You have opened a project and at least one symbol library. Utilities > Master data > Symbol library > Properties. If multiple [symbol libraries](Glossary_o_symbolbibliotheken.htm) are open, select the one you would like to edit in the Symbol library selection dialog.

In this dialog you specify the [properties](Glossary_o_eigenschaften.htm) for the newly created or the selected symbol library.

Overview of the main dialog elements:

Property name / Value list:

The available properties are displayed depending on the selected category. Some of them, for example "Creator", "Number of [symbols](Glossary_o_symbole.htm)," and "Creation date" have already been assigned values that cannot be changed. Others, such as "Symbol library description" and "Version", can be assigned values or their existing values can be changed.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

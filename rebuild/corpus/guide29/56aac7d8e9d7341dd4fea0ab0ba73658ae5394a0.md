# Dialog Open outline / Copy outline

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Utilities > Master data > Outline (...) > Open.
- Utilities > Master data > Outline (...) > Copy.

In this dialog, you can select an outline to edit.

Overview of the main dialog elements:

Search in:

From the drop-down list select the desired drive and directory location of the outline that you would like to open.

Preview:

Select this check box in order to display the graphical preview of the outline selected in the list on the left side of the dialog on the right side of the dialog.

![](../Pictures/Gui/ALL/note.png)Note:

You can't select multiple [outlines](Glossary_o_konturen.htm) here.

Info area:

Once an outline is selected in the list on the left side, the following [properties](Glossary_o_eigenschaften.htm) are displayed in the info area below the Preview check box if they have been created:

- Description ([form](Glossary_o_verlauf.htm), plot frame, outline, form (copper))
- Outline type
- Company code
- Creator
- Creation date
- Last editor
- Modification date

File name:

Enter the file name here, or select one from the drop-down list.

File type:

This field displays the currently selected outline type. It cannot be changed here.

Path:

The file path (including the drive) selected in the Look in field is displayed here. Via the Go to default popup menu item, you can automatically specify the default path <Program Drive>:\<Program Directory>\Macros\<Company code> or apply the [settings](Glossary_o_einstellungen.htm) specified under the Options > Settings > User > Management > Directories menu [items](Glossary_o_bauteile.htm).

If you change directories, then EPLAN stores the new setting and offers it the next time the dialog is called.

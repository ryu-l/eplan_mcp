# Import Design Space

EPLAN Design Space Exchange is used in 3 working steps:

- The import of design spaces as STEP files from 3D CAD programs
- The creation of a mounting layout in EPLAN Pro Panel
- The export of the design space with added mounting layout and NC data to a 3D CAD program.

The following section describes the first working step, the import of STEP files.

You can adjust the [settings](Glossary_o_einstellungen.htm) for the STEP import under Options > Settings > User > Interfaces > Design space import and export.

Precondition:

You have opened a project with a "Schematic project" project type. The [layout space](Glossary_o_bauraum.htm) navigator is open.

1. Select Layout space > Design space > Import.
2. In the Open open a STEP file that was generated by a 3D CAD program.
3. In the Design space import dialog select a scheme with settings for the import of the selected source file or use [...] to open the settings dialog and change the settings.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The 3D graphic data from the STEP file are imported into a separate layout space. The imported geometry is protected against changes.
5. Create the mounting layout in the imported design space using the functionality of EPLAN Pro Panel.

# Action: XEsSetProjectPropertyAction

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| PropertyId | Identifier of the property to be defined (= Property number) |
| PropertyIdentName | Identifier of the [user-defined](Glossary_o_benutzerdefiniert.htm) property as it was assigned by the user |
| PropertyIndex | Index of the property (usually 0) |
| PropertyValue | New value of the property |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
XEsSetProjectPropertyAction 
/PropertyId:? 
/PropertyIdentName:PEP.Project.PVW_1
/PropertyIndex:0 
/PropertyValue:"?"
```

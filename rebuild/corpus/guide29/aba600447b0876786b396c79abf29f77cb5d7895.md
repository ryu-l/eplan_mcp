# Dialog Dimensions

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open. Insert > Device.

Use this dialog to enter the values for width, height and depth of the [part](Glossary_o_artikel.htm) to be placed prior to the [placing](Glossary_o_auflegen.htm) of electrical engineering, Fluid power, and certain mechanical parts. The dialog is displayed automatically if no dimensions have been defined on the part selected for placement, and if no graphical macro has been assigned. Such parts can be used, for example, as variable prototypes for placement in small series or for a batch production in the parts management, without having to [create](Glossary_o_erstellen.htm) full [master data](Glossary_o_stammdaten.htm) in the [form](Glossary_o_verlauf.htm) of complete part definitions.

![](../Pictures/Gui/ALL/note.png)Note:

As for parts from the "Mechanics" generic product group, the manual input of dimensions is permitted if they belong to one of the following product subgroups and also have one of the following [function definitions](Glossary_o_funktionsdefinitionen.htm):

| Product group | Product subgroup | Function definition |
| Busbar | Adapter | Adapter  Connection adapter  Device adapter |
| System [accessories](Glossary_o_zubehoer.htm) | General | Cable gland  Enclosure [component](Glossary_o_schaltzeichen.htm) |

Manual input of part dimensions is not possible for all other mechanical parts from the "Mechanics" generic product group or parts from the "Process engineering" generic product group.

Overview of the main dialog elements:

Width, Height, Depth:

These fields are used to enter or modify the device-specific dimensions in the displayed measuring unit specified as the user setting. If some partial part dimensions are already entered at the associated part, the corresponding fields are filled with these values.

Write back dimensions to part:

If this check box is activated, the values entered in this dialog for the Width, Height, Depth are stored in the mounting data of the part to be placed. When this part is placed the next time, the dimensions are thus defined completely and the dialog Dimensions is no longer displayed.

# Generating Pages with Views Using "Generate project reports"

When a project is reported via the menu [items](Glossary_o_bauteile.htm) Utilities > Reports > Generate project reports, pages with views are now also generated (model view, 2D drilling view and / or copper [unfold](Glossary_o_abwicklung.htm)), if the respective report templates with [page macros](Glossary_o_seitenmakros.htm) are available in the dialogs for the management of the views. All views that have already been generated are also updated.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

Because the "Generate project [reports](Glossary_o_auswertungen.htm)" takes into consideration the templates for the views, you can [generate](Glossary_o_erzeugen.htm) the pages with the views more quickly. The separate reporting of the different views via different menu items is obsolete.

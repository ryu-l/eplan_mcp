# Multi-user Monitor: Principle

The monitor for [multi-user operation](Glossary_o_multiuser_betrieb.htm) was implemented as a client-server solution.

The server application is installed on the required computer by the EPLAN installation wizard. This may also be a "normal" EPLAN workstation. The server application is then available as a service in the server-computer's Control Panel. This EPLAN multi-user monitor service starts automatically.

For the other EPLAN workstations to be able to log onto this "monitor server" when the program is started, a further setting has to be made in EPLAN on the relevant client computers (Options > Settings > User > Management > Multi-user monitor).

When the service and the client-server connection have been set up, the monitor server receives the information about [actions](Glossary_o_aktionen.htm) that have been carried out, collates it, and redistributes it to the EPLAN workstations.

![](../Pictures/Gui/ALL/note.png)Note:

We recommend that a system administrator sets up the multi-user monitor and makes the necessary [settings](Glossary_o_einstellungen.htm) on the EPLAN workstations.

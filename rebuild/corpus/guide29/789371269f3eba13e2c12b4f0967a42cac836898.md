# Dialog Format: Separator (offline numbering)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Options > Settings > Projects > "Project name" > Devices > Numbering (offline).
- Page > Navigator. One or more pages are selected. Project data > Devices > Number > [Settings] > Numbering.
- Project data > Devices > Navigator. One or more [devices](Glossary_o_betriebsmittel.htm) are selected. Project data > Devices > Number > [Settings] > Numbering.

You have selected a [user-defined](Glossary_o_benutzerdefiniert.htm) scheme in the dialog Settings: Numbering (offline). In the Available format elements or Selected format elements field double-click the format element "Separator".

In this dialog, you define the "Separator" format element for device numbering.

Overview of the main dialog elements:

Blank:

If this option is activated, then a space is used as the [separator](Glossary_o_trennzeichen.htm). The number of spaces is entered in the field Number of characters.

Other characters:

If this option is activated, you can enter the required character combination to be used as the separator in the field below. Any digits, letters, and special characters can be used.

Number of characters:

This field is available if the option Blank is selected. The number in this field specifies the number of spaces to be displayed as separators in the numbering format. If you select Other characters, this field is grayed out and displays the specified number of characters.

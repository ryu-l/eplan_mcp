# P003028: Cable does not use all the cable connections of the part

### Cause

You have placed a [cable](Glossary_o_kabel.htm) in the schematic to which you have assigned a [part](Glossary_o_artikel.htm) with fixed [function templates](Glossary_o_funktionsschablonen.htm) (device). When [placing](Glossary_o_auflegen.htm) the cable you have however used less [functions](Glossary_o_funktionen.htm) ([cable connections](Glossary_o_kabelverbindungen.htm)) than the corresponding part has. For example, you have selected a part for the placed cable that contains 4 cable [connections](Glossary_o_verbindungen.htm) of which you only use 3 in the schematic.

### Solution

#### Possibility 1

Select a [cable part](Glossary_o_kabelartikel.htm) with a suitable function template assignment (number of cable connections).

#### Possibility 2

Reduce function template [settings](Glossary_o_einstellungen.htm) for the selected part in the parts management (number of cable connections). To do this, select Utilities > Parts > Management, and in the Parts management dialog, select the Function templates tab. In the table, highlight the function templates you want to remove and click ![](../Pictures/Gui/ALL/all_delete_as.png) (delete). Copy the changed setting into the parts management. Then place the cable as a device in the schematic once again.

Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

Whether this message is issued depends on the Minimize unused functions and Number of unused functions settings. You move to the settings by firstly opening the Properties dialog of the device, bringing the Part tab to the front and clicking the [Device selection] button. In the Device selection dialog then click on [Settings] and open here the Settings: device selection dialog with the setting options previously stated above. Using the Number of unused functions setting you set the number of functions not used in the device (reserve functions) that the part should provide. The number can only be set if you have selected the Minimize unused functions check box setting.   
If the Number of unused functions setting is set to "0", all unused templates will be identified as error(s) found.

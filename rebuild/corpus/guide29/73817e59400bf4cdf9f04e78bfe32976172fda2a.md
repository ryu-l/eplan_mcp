# Inserting Conduits, Piping and Hose Lines

Conduits, piping or [hose lines](Glossary_o_schlauchleitungen.htm) can be inserted as [devices](Glossary_o_betriebsmittel.htm) in the schematic.

Preconditions:

- You have opened a project.
- You have opened a fluid schematic page that contains fluid [connections](Glossary_o_verbindungen.htm) running parallel.

### Inserting a conduit

A conduit is inserted as a cable definition into a schematic.

1. Select the menu item Insert > Cable definition.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol for the [cable](Glossary_o_kabel.htm) definition hangs on the cursor.
2. Drag the line over the fluid connections to be included in the conduit. Click with the left mouse button to establish the start and end point of the line.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A connection definition point is placed automatically at each intersection of the drawn line with the autoconnect [lines](Glossary_o_leitungen.htm) of the fluid connections.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The [properties](Glossary_o_eigenschaften.htm) dialog of the conduit is opened. A device tag is entered automatically in the Displayed DT field in the Conduit / line tab. The DT is formed in accordance with the preset numbering format.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Since you have placed the definition line of a page of the "Fluid power schematic (I)" type, the line is displayed in the Symbol / function data tab as a conduit definition line. In addition, the Conduit definition value is automatically assigned to the function definition of the conduit.
3. In the Conduit / line tab enter the values for the empty fields Type, Function text, Number of connections / tubes, Length, Cross-section / diameter and Unit, and define further properties as required.
4. Click [OK].

#### Changing the symbol for the connection definition points

By default the symbol 311 / CDPNG is used when inserting the conduit definition line for the [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm). This symbol does not contain any graphics. Change the symbol in order to display a norm-compliant symbol to DIN ISO 1219 for the connection definition points with a hose graphic and to assign the correct function definition:

1. First mark all the connection definition points placed automatically on the conduit definition line and select the popup menu item Properties.
2. Bring the Symbol / function data tab to the front.
3. Click [...] next to the Number / name field in the Symbol (graphic) group box.
4. Select the list view in the symbol selection dialog and enter the value CDPCP2F5 into the Direct entry field.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The hose symbol is displayed in the preview.
5. Select the desired variant of the symbol in the preview.
6. Close the symbol selection and the [property dialog](Glossary_o_eigenschaftendialog.htm) by clicking [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) All the connection definition points in the conduit are now displayed as hoses.   
     
   ![](../Pictures/Gui/ALL/arrow.png) All the connection definition points and connections in the conduit furthermore have the "Hose" function definition assigned to them.

#### Hiding a conduit definition line

Since the conduit definition line still intersects the changed connection definition points with the hose [symbols](Glossary_o_symbole.htm), it has to be hidden.

1. Call the property dialog of the conduit definition line.
2. Bring the Format tab to the front.
3. Select the setting "Yes" for the property Invisible under the Format hierarchy level.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The conduit definition line is now no longer displayed.

### Inserting a piping and hose line

Piping and hose lines can also be inserted as devices in the schematic. Ready-to-use [symbol macros](Glossary_o_symbolmakros.htm) are available in EPLAN Fluid to this purpose. For [pipings](Glossary_o_rohrleitungen.htm) these are the symbol [macros](Glossary_o_makros.htm) Pipe1.ems to Pipe5.ems, for hose lines the symbol macro Hose.ems.

1. Select the Insert / Window macro / symbol macro menu item.
2. Select the desired symbol macro for piping or hose lines in the dialog Select macro and click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol macro is attached to the cursor.
3. Place the symbol on the desired connection between two fluid devices or [connection symbols](Glossary_o_verbindungssymbole.htm).
4. If preset, specify how you want to number the added device in the dialog Insertion mode and close the dialog with [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol macro is inserted. In the process the [autoconnecting](Glossary_o_autoconnecting.htm) line is interrupted and the connection is continued across the symbol.
5. Insert further symbol macros or interrupt the insertion process with [Esc].
6. Specify the device tag in the property dialog of the placed piping or hose lines, if it is not already assigned automatically and, if applicable, define further properties.

![](../Pictures/Gui/ALL/info.png)Tip:

For rapid and easy specification and completion of hydraulic hose lines use the [EPLAN Fluid Hose Configurator](fluidhoseconfiggui_k_start.htm). This software is already integrated as an add-on if you have installed EPLAN Fluid. In addition, the software is also available as a stand-alone variant.

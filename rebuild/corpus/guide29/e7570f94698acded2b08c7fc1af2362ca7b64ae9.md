# Using Existing Connections

During project design unplaced [connections](Glossary_o_verbindungen.htm) can be generated if, e.g., you delete function placements, or they can be created deliberately to predefine certain connections and their [properties](Glossary_o_eigenschaften.htm). These connections can be used on existing connection definition points.

1. Select a connection definition point in the graphical editor or a connection in the connections navigator.
2. Select the menu item Edit > Properties.
3. In the Properties <...> dialog, select the Connection definition point tab (for a selected connection definition point) or the Connection tab (for a selected connection).
4. Make sure that the connection property Connection: Association is not set to the "Cable" value.
5. Click [...] next to the Displayed DT field.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Use existing connections dialog displays all of the existing connections in a project (placed and unplaced) with the source and [target information](Glossary_o_zielinformationen.htm). Connections where both targets match the targets of the selected connections are at the top of the list. After that are the connections where one target is identical, then the unplaced connections without targets and finally all other placed and unplaced connections.
6. If you want other connection properties to be displayed, use the Configure representation popup menu item to open the dialog of the same name and select the desired properties there.
7. Select the desired connection.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection is used, i.e., its properties are transferred to the connection definition point or to the placed connection.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If a [cable](Glossary_o_kabel.htm) is assigned to the connection the corresponding DT is displayed in the Properties dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) An unplaced connection is always deleted after it has been used. It is also deleted if it previously had completely different targets and if a completely different connection is created by the combination of multiple [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm).

![](../Pictures/Gui/ALL/note.png)Note:

You can only [use existing](Glossary_o_abbuchen.htm) connections if the connection definition point is uniquely assigned to one individual connection. If this is not the case, then an appropriate message is displayed.

# P004055: More than one rack was found during importing. Ensure that you use the right hardware for connecting

### Cause

You use the PLC import interface Schneider Schneider Unity Pro: In the case of the M340 product line the [PLC boxes](Glossary_o_sps_kaesten.htm) for connecting the racks with each other are not contained in the import file.

### Solution

Ensure that existing [rack](Glossary_o_baugruppentraeger.htm) extensions are configured with the right hardware.

![](../Pictures/Gui/ALL/note.png)Note:

This module-specific message is generated by the importing of PLC data. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

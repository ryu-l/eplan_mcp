# Dimensions

You can enter as many project pages as you would like, for example for the [panel layout](Glossary_o_schaltschrankaufbau.htm) structure or dimension information.

EPLAN offers the following dimension types:

- Linear dimension
- Aligned dimension
- Continued dimension
- Incremental dimension
- Baseline dimension
- Angular dimension
- Radius dimension.

The dimensioning [functions](Glossary_o_funktionen.htm) via the object snap and is not [grid](Glossary_o_raster.htm)-dependent. Dimension results can be changed retroactively. A prefix and a suffix can be (pre)defined for dimensions.

Different views for arrows and dimension help [lines](Glossary_o_leitungen.htm) can be selected in order to customize the dimensions for specific countries and standards.

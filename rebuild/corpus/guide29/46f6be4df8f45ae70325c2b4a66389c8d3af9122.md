# Dialog Full DT

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have inserted a symbol in the graphical editor or generated a new function in a navigator.
- You have selected a general device in the graphical editor or in a navigator. Edit > Properties.

In the Properties <...> dialog, select the <Function category> tab. Click [...] in the Full DT field.

In this dialog, you can assign a different structure identifier to the [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) contained in the device tag, and edit the default [settings](Glossary_o_einstellungen.htm) for the display.

Overview of the main dialog elements:

Displayed DT:

This field shows the DT as it is displayed in the schematic according to the entries in the fields of this dialog. As soon as you edit this entry, the entries in the other fields will automatically be updated.

Full DT:

This field shows the full DT as it is defined according to the entries in the fields of this dialog. This field cannot be edited.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Lamp H1 is located in [higher-level function](Glossary_o_anlage.htm) A1 in the [mounting location](Glossary_o_einbauort.htm) O1. The displayed DT is -H1 and the full DT is =A1+O1-H1. If you now change the entry in the Displayed DT to +PT1-H1, then the entries in the Mounting location and Full DT are automatically adjusted.

---

Structure identifiers:

Depending on the [project structure](Glossary_o_projektstruktur.htm) the table displays the [structure identifiers](Glossary_o_strukturkennzeichen.htm) of the placed [component](Glossary_o_schaltzeichen.htm) which can be edited. EPLAN generally adopts the Device structure that you have defined in the [project properties](Glossary_o_projekteigenschaften.htm) of the project. If the device structure conforms to the page structure, the fields display the structure identifiers of the page on which the placed component is located.

- Structure: Lists the identifier [blocks](Glossary_o_bloecke.htm) which correspond to the device structure. The adjacent column displays the associated preceding signs.
- Value / Visible: Without extended reference identification, the Value column is displayed. If you are using extended reference identification, the Visible column is displayed. In this column, the structure identifiers can be edited. Enter a structure identifier in the proper field for this purpose, or click [...] to select a structure identifier already defined in the project using the [<Identifier block> (<Project name>)](pleditorgui_d_kennzeichnungsblock.htm) dialog.
- Complete: This column is displayed if you are using extended reference identification. It displays the structure identifier including all superior structure identifiers.

![](../Pictures/Gui/ALL/note.png)Note:

The preceding signs and separators between the individual structure identifiers can not be edited here. They originate from the settings of the Extended project structures dialog, which you open in the Structure tab of the project [properties](Glossary_o_eigenschaften.htm) by clicking [Other].

---

Editing fields for the DT

Depending on the settings for the project structure, different editing fields are displayed for the DT:

- Group boxes for the DT: If you are working without extended reference identification, the DT and Subordinate DT group boxes are shown. In these fields, you edit the identifier block for the device.
- Table DT: If you are using the extended reference identification, the editing fields for the DT are shown in a table. In this case, each [product aspect](Glossary_o_produktkennzeichen.htm) (the DT and each subordinate DT) is displayed in its own row.
- Table DT for fluid power functions: If, in the project settings, the Fluid power: Use trade identifier as identifier (media code) check box is activated, the edit fields for the DTs of [fluid power](Glossary_o_fluidtechnik.htm) [functions](Glossary_o_funktionen.htm) are shown in a table and the [designations](Glossary_o_bezeichnungen.htm) according to the standard DIN ISO 1219-2 used for column headers. For this, the prefix in the DT of fluid power functions must be empty.

![](../Pictures/Gui/ALL/note.png)Note:

To be able to use the extended reference identification, the Extended reference identification check box must be activated in the Structure tab of the project properties.

If you have additionally determined that the product aspect is to be used for structuring (by means of the corresponding check box in the [Display](prjmanagementgui_r_darstellungerwprjstrukturen.htm) tab of the Extended project structures dialog), the table for the DT is hidden and the product aspect shown in the Structure identifiers table.

The group boxes or the table allow for entries in the following fields:

Prefix:

These fields can be used to enter or change a prefix digit for the device and subordinate [devices](Glossary_o_betriebsmittel.htm).

Concerning fluid devices with an identifier structure according to DIN ISO 1219-2, this field must remain empty.

Identifier:

These fields can be used to enter or change the identifier for the item designation (according to DIN) of the device and subordinate devices.

Concerning fluid devices with an identifier structure according to DIN ISO 1219-2, this field is designated Media code. The trade identifier is used as media code and can be entered or changed here.

Counter:

These fields can be used to enter or change the counter for the device and subordinate devices.

Concerning fluid devices with an identifier structure according to DIN ISO 1219-2, this field is designated Circuit number. Here you can enter or change the circuit number.

Subcounter:

In these fields, the subcounter can be entered or changed for the device and subordinate devices. The [separator](Glossary_o_trennzeichen.htm) which separates the subcounter from the rest of the DT cannot be edited here.

Concerning fluid devices with an identifier structure according to DIN ISO 1219-2, this field is designated Item number. Here you can enter or change the item number.

# Inserting Devices

The functionality Insert device allows you to insert the first graphical representation (symbol or macro), the [part](Glossary_o_artikel.htm) and all the [functions](Glossary_o_funktionen.htm) or [function templates](Glossary_o_funktionsschablonen.htm) of a device into the project in a single action.

![](../Pictures/Gui/ALL/note.png)Note:

The New device popup menu item that is available in some [project data](Glossary_o_projektdaten.htm) [navigators](Glossary_o_navigatoren.htm) also allows the insertion of a device, however without placement.

![](../Pictures/Gui/ALL/info.png)Tips:

- When inserting [devices](Glossary_o_betriebsmittel.htm) or individual [objects](Glossary_o_objekte.htm), you have the option of using the [N] key to browse through the functions and select the one you want. The [connection point designations](Glossary_o_anschlussbezeichnungen.htm) of the selected function are displayed on the symbol. When inserting a macro, [Shift] + [Tab] is used to browse through the [representation types](Glossary_o_darstellungsarten.htm). Use [Tab] to browse through the macro [variants](Glossary_o_varianten.htm) of a representation type.
- It is also possible to place an auxiliary function first. The main function (and thus the device) is thus created as an unplaced function.
- In order to retain the variants selected via the [Tab] key for the inserting / [placing](Glossary_o_auflegen.htm) of devices, you can activate the setting [Retain symbol / macro variant when placing device](xessettingsgui_d_betriebsmittelallgemeinbenutzer.htm) (Menu path: Options > Settings > User > Device > General).

Preconditions:

- You have opened a project page in the graphical editor.
- You have entered a macro at the part in the parts management, or have defined function templates. A symbol or symbol macro can be entered additionally at the function templates, but does not have to be.
- If you have not defined function templates, but have stored [macros](Glossary_o_makros.htm) at the parts, the system reads the functions from the macro so that the device can be generated completely. To this purpose it is imperative that the setting Consider macro when generating devices (under Options > Settings > Projects > "Project name" > Devices > General) be activated.

### Insert devices in the graphical editor

1. Select the following menu [items](Glossary_o_bauteile.htm): Insert > Device
2. Select a part in the Part selection dialog and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The system selects the macro or symbol that best suits the opened page. The representation type is determined via the page type in the process.
3. If you want to use a different representation type or a different macro or symbol, press the [Backspace] key before the actual inserting.
4. Specify the insert options in the dialog [Insert device](egedgui_d_geraeteinfuegen.htm) and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Depending on the selected option a subsequent dialog is opened. If you have for example selected the option Macro selection, the Select macro dialog is opened.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The assigned or selected macro / symbol hangs on the cursor.
5. Insert the symbol or macro in the schematic.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts data are written to the main function.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the part has several functions, then the next symbol will subsequently hang on the cursor.
6. Insert the further functions of the device.  
     
   ![](../Pictures/Gui/ALL/arrow.png) When you sequentially insert all functions of the device, the [DT adoption](devicetaggui_k_bmkuebernahme.htm) is also taken into account.  
     
   ![](../Pictures/Gui/ALL/arrow.png) After all of the device functions have been inserted, the first device function is once again hanging on the cursor and you can insert it again if you wish.
7. When inserting [auxiliary functions](Glossary_o_nebenfunktionen.htm), hold down the [Spacebar] if you want to interrupt the insertion of the auxiliary functions and start again with the renewed insertion of the same device.
8. End the action via the Cancel action popup menu item or via the [Esc] button.

### Inserting Devices from the Device List

You can use the popup menu item Insert device to insert a device immediately with its associated parts data in the [device list](devicelistgui_d_geraeteliste.htm) as well as in the part [master data](Glossary_o_stammdaten.htm) navigator and in the bill of materials navigator. The procedure is the same as for inserting devices in the graphical editor.

![](../Pictures/Gui/ALL/info.png)Tip:

You can add parts to a device placed in the graphical editor using Drag&Drop. To do this, select the desired part in the device list, press the [Ctrl] + [Shift] key combination, and pull the part onto the [component](Glossary_o_schaltzeichen.htm). If the device already has one or more parts, then a query is displayed asking whether the existing parts should be enhanced or replaced.

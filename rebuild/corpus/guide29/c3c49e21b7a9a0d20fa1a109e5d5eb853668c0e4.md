# Dialog DXF / DWG import

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Page > Import > DXF / DWG. In the DXF / DWG file selection dialog, choose (at least) one file and click [Open].
- You are in a page within the graphical editor. Insert > Graphic > DXF / DWG. In the DXF / DWG file selection dialog, choose a file and click [Open].
- Utilities > Generate macros > From DXF / DWG files. In the DXF / DWG file selection dialog, choose (at least) one file and click [Open].

In this dialog you start the actual import process.

Overview of the main dialog elements:

Source:

The name of the file selected to import is displayed here.

Scheme:

Select a suitable scheme from the drop-down list or click [...] to call the dialog Settings: DXF / DWG export and import and to open or edit an existing scheme or [create](Glossary_o_erstellen.htm) a new scheme.

Target:

Only available when creating [macros](Glossary_o_makros.htm)! Specify the target directory here or click [...] to select it. You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).  
The selected files are saved in the specified macro directory as <Original\_Name>.ema [window macros](Glossary_o_fenstermakros.htm).

After clicking [OK] you may still have to define the Import formatting and, in another dialog (Assign pages) define how pages are handled when importing pages.

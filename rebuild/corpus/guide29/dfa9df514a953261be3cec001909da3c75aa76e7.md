# P004073: 'Function text (automatic)' has been assigned more than once (in the language '<x>') within a CPU

### Cause

The same entry was assigned several times in the language <x> at the Function text (automatic) property at the [PLC connection points](Glossary_o_sps_anschluesse.htm) of a CPU.

### Solution

1. Locate the PLC [connection points](Glossary_o_anschluesse.htm) in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Modify the function or path function text so that each entry is unique for the corresponding PLC connection points in the reported language.
3. Translate the modified function or [path function texts](Glossary_o_pfad_funktionstexte.htm) into all the further languages used by you.
4. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Notes:

- The comparison of the [function texts](Glossary_o_funktionstexte.htm) is effected for each language separately.
- Language-neutral (= untranslated) function texts are only compared with untranslated texts. The function texts must therefore be translated (or be translated again after a modification) so that the test [functions](Glossary_o_funktionen.htm).
- Empty function texts do not result in a message.

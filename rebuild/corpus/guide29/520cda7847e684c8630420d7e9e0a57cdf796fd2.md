# Dialog Terminal strips - <Project name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Project data > Terminal strips > Navigator.

This dialog lists all terminals and terminal strips from the open project. Every terminal is displayed with its function definition, structure identifier of the specified device structure, and position designation. You can select one or more terminals or terminal strips here. Use the popup menu to [create](Glossary_o_erstellen.htm) new terminals and terminal strips or call up the appropriate dialogs for editing them.

Overview of the main dialog elements:

Terminals are sorted and displayed according to the terminal strip in the tree view. Associated [terminal strip definitions](Glossary_o_klemmenleistendefinitionen.htm) and terminals are displayed below the DT of the terminal strip.

The function definition and the identifying name are displayed as the standard in the list view. Additional [properties](Glossary_o_eigenschaften.htm) can also be displayed (e.g., terminal / [pin designations](Glossary_o_steckerkontaktbezeichnungen.htm), saddle jumper options, etc.).

Filter:

This drop-down list displays all the available [filters](Glossary_o_filter.htm). A selected filter is automatically activated and is applied to both the tree and the list view. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the [Filter](modaldialogsdb_d_filternnach.htm) dialog. Here you can create, edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

- Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
- Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

Value: <Property>:

Use this field, via [Quick input](modaldialogsdb_k_filter.htm#I_Schnelleingabe), to adjust quickly the value of a filter criterion for a defined and activated filter.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| New | Opens the Function definitions dialog and allows the creation of a new function with pre-defined properties. Depending on the object selected, the Function definitions dialog will open the tree view for selecting a function definition. If, for example, you have opened the popup menu on a function, the associated function definition will be selected in the tree view. |
| New [functions](Glossary_o_funktionen.htm) | Opens the Generate functions dialog that allows you to [generate](Glossary_o_erzeugen.htm) multiple functions for a new or existing DT using a specific numbering pattern. |
| New terminals ([devices](Glossary_o_betriebsmittel.htm)) | Opens the Generate terminals (devices) dialog that allows you to generate multiple terminals for a new or existing DT using a specific numbering pattern. The first terminal generated becomes the main terminal per terminal device and receives the selected [part](Glossary_o_artikel.htm). |
| Generate terminal strip definition | Generates a terminal strip definition in as far as none exists yet for the device. |
| Generate terminal | Generates a terminal. |
| Delete | Following a prompt, this deletes all selected functions or - in the tree view - all functions below the selected tree structure level. (Multiple selection of functions or tree structure [levels](Glossary_o_etagen.htm) is possible here.) Both placed and [unplaced functions](Glossary_o_nicht_platziertefunktionen.htm) will be deleted. When a placed function is deleted, the [placing](Glossary_o_auflegen.htm) is also deleted at the same time in the graphical editor or [layout space](Glossary_o_bauraum.htm).  Note:  Please note that when deleting [placed functions](Glossary_o_platziertefunktionen.htm), the existing [connections](Glossary_o_verbindungen.htm) in the [projects](Glossary_o_projekte.htm) can also be modified. New connections can arise or connections can be deleted. |
| Place | Places the selected function in the schematic. Before the actual placing press [Shift] in order to start the placement action in the mode "Individual functions". Press [Backspace] to open the dialog Place device and, if required, for example open the macro selection or change the representation type. |
| Assign | This menu item is available if a project page is open and a DT / function / function template is selected in the navigator. It hangs the function description of the (first highlighted) function on the cursor and allows for this function to be moved to a [component](Glossary_o_schaltzeichen.htm) and to assign it with a single click. You can, for instance, assign an unplaced function to a component, or transfer the data of an already placed function to another component. An assigned function must have as many or more [connection points](Glossary_o_anschluesse.htm) than the component. If several functions or the DT have been selected, all selected functions can be assigned consecutively. This can be done either individually by mouse-click or blockwise by opening a frame around the required components. |
| Edit | Calls up the Edit terminal strip dialog for the selected terminal strip. |
| Number terminals | Opens the Number terminals dialog. There you can specify special formatting for [terminal designations](Glossary_o_klemmenbezeichnungen.htm). |
| Sort terminal strip | Allows you to automatically sort all terminals in a terminal strip according to certain criteria. Select the required criterion from the submenu. |
| Edit revision marker | This menu item allows you to edit the [revision marker texts](Glossary_o_revisionsmarkierungstexte.htm) and their format. This menu item is only available when a changed object in a revision is selected. |
| Delete revision marker | This menu item allows you to delete the revision marker texts. This menu item is only available when a changed object in a revision is selected. |
| Go to (cross-referenced) | Enters cross-referenced functions into the Go to list and opens it. |
| Go to (all [representation types](Glossary_o_darstellungsarten.htm)) | Enters all of the representation types of a function (e.g., on a schematic page, an overview page, and / or a report page) into the Go to list and opens it. |
| Go to (graphic) | Shows the selected object in the graphical editor. |
| Insert into list of search results | Enters all [objects](Glossary_o_objekte.htm) in a project that refer to the selected element in the search results list. |
| List with preselection (tree only) | Reduces the number of elements displayed in order to allow for a faster orientation in the list view. If this option is activated, the list view is called up with an automatic filter (preselection) containing the elements that are currently selected. |
| Select in tree (list only) | Displays the marked object in the Tree tab. |
| View | Switches the display in the tree view:   - DT-oriented: The terminals are structured by their device tags according to the [project structure](Glossary_o_projektstruktur.htm). - Device-oriented: The terminals are grouped according to their device position, meaning that terminals with the same device position are combined into a terminal device (for example a multi-level terminal). The device may have only one main terminal to ensure that all the terminals of a device are displayed below its node. |
| Edit in table | Opens tabular editing, with the possibility of editing the properties of the selected objects. |
| Properties | Opens the Properties (components): <...> dialog. Allows the editing of the function properties. |
| Properties (global) | Opens the Properties (global): <...> dialog. Allows the editing of the device properties. |

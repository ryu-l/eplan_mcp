# Dialog Settings: Operational sequence sheets

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Options > Settings > Projects > "Project name" > Devices > Operational sequence sheets.

In this dialog you specify the special symbol that is used for the placement of the [property texts](Glossary_o_eigenschaftstexte.htm) in [operational sequence sheets](Glossary_o_ablaufdiagramme.htm). Additionally, you can make [settings](Glossary_o_einstellungen.htm) for the symbol and macro graphics that are placed in symbol-based [functional diagrams](Glossary_o_funktionsdiagramme.htm).

Overview of the main dialog elements:

Group box Symbol for property placement

In this group box you edit the [properties](Glossary_o_eigenschaften.htm) of the symbol that is used for the placement of the property texts in operational sequence sheets.

- Library
- Number / name
- Variant
- Description.

---

Functional placing with symbol graphic:

If this check box is activated, then during the placement of a function with the "Functional" representation type, the symbol graphic of the function selected in the device navigator is inserted in the functional diagram in addition to the property texts.

If the check box is not enabled, only the property texts of the function selected in the device navigator will be inserted during the [placing](Glossary_o_auflegen.htm).

This check box does not affect the functional placing of macros. The macro graphic is always inserted as well.

---

Group box Target size for symbol / macro graphic

In symbol-based functional diagrams, device [symbols](Glossary_o_symbole.htm) or symbols of [part macros](Glossary_o_artikelmakros.htm) are placed in addition to the property texts. In this group box you specify the maximum size of the symbol or macro graphic. Enter the corresponding values in the fields Width and Height.

In the functional placing of a function or [part](Glossary_o_artikel.htm) macro, the associated graphic is appropriately reduced if necessary. Enlargement is not an option in this context.

Group box Position for symbol / macro graphic

In this group box you specify the position of the symbol or macro graphic in relation to the insertion point of the symbol for the property placement. Enter the corresponding values in the X and Y fields.

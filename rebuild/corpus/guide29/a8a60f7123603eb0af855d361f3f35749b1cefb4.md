# Higher-level function number: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_anlagennummer.htm)

### Higher-level function number

Electrical engineering

Identifier block. The higher-level function number is used to structure fluid devices. It is necessary if the project includes multiple higher-level functions. The "Higher-level function number" identifier block should not be confused with the "Higher-level function" identifier block.

### Function definitions

User interface / operation

The function definitions are pre-defined functions available to the system. It defines which functions may be used in the project as well as the standard behavior of these functions. In this way, the function definition defines how an object type is to be treated in reports (e.g., contacts in the contact image, terminals in the terminal diagram, etc.). Function definitions are managed in a function definitions library (see [Function definition libraries](Glossary_o_funktionsdefinitionsbibliotheken.htm)). Function definitions are allocated to symbols and are automatically entered into the component when the symbol is placed. The user can enter function definitions into parts and therefore enable the subsequent selection of devices.

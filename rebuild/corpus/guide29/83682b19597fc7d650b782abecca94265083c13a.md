# Main part: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_hauptartikel.htm)

### Main part

User interface / operation

In device selection items are divided into main parts and accessories (see [Accessories](Glossary_o_zubehoer.htm)). Main parts normally include function templates for specifying technical data, whereas accessories do not. In parts management, possible accessory parts are assigned to the main part via the Accessories tab.

# No Display of the Value "0" in the Automation Scheme

For the graphical display of automation [schemes](Glossary_o_schemata.htm) for the building automation, property arrangements are used to display the number of used or required PLC inputs / outputs per PCT loop by path or by column. The value "0" is not displayed in the case of a norm-compliant display. To do this, the new display property Zero as blank is available in the Display tab of the [property dialog](Glossary_o_eigenschaftendialog.htm).

![](../Pictures/Gui/ALL/benefit.png)Benefit:

When inserting [macros](Glossary_o_makros.htm) or copies into a [P&I diagram](Glossary_o_ri_fliessbild.htm) the [segments](Glossary_o_segmente.htm) already existing in a project can be assigned quicker, the tedious individual selection is superfluous.

This display property below the Value / unit hierarchy level can only be activated for [properties](Glossary_o_eigenschaften.htm) with numerical values. If this check box is activated, value "0" is replaced with a blank.

In addition, the display property is also available for texts such as [placeholder texts](Glossary_o_platzhaltertexte.htm) in the Format tab.

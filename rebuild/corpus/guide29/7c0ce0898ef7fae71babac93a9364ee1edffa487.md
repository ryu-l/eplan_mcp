# Connection point directions: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_anschlussrichtungen.htm)

### Connection point directions

User interface / operation

Symbols:  
Property on the connecting point of a symbol; is represented graphically by an arrow. The arrow shows the direction from which an automatic connection (Autoconnecting) is possible.   
  
Layout space:  
The connection point direction specifies the set direction via a vector in which the routing connection exits the connection point of the item.

# Macro projects: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_makroprojekte.htm)

### Macro projects

User interface / operation

Specific type of project used to manage and simplify the creation of macros. The project type is specified in the project properties. In comparison to schematic projects, macro projects have limited logic functions (for example no connections across multiple pages).

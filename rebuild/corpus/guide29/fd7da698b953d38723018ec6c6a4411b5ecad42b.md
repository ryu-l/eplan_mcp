# Completion of the PLC Data Moved Into Project Correction

Below the menu [items](Glossary_o_bauteile.htm) Project data > PLC > Complete data you previously had multiple [actions](Glossary_o_aktionen.htm) available to synchronize PLC data and prepare a project for the PLC [data exchange](Glossary_o_datenaustausch.htm). This menu item has been removed. Instead the actions are available to you in the project correction in the new version. Correspondingly the PLC data are now always completed for the entire project.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

The [settings](Glossary_o_einstellungen.htm) for completing the PLC data are now available for the project correction (analog to the correction settings for the terminals) and can be saved there in a scheme and be used repeatedly. Since the correction is performed project-wide by default, incomplete or contradictory data are avoided.

In the Settings: Correct dialog you specify which [project data](Glossary_o_projektdaten.htm) are to be corrected automatically by means of a correction run. A menu path for this dialog is: Options > Settings > Projects > "Project name" > Management > Correct. Here the new PLC hierarchy level with the following settings is available:

- Write back connection point designations
    
  It is no longer possible to select individual CPUs. The Write back connection point designations dialog has been removed.
- Writing back connection point designations and transferring to the connected pins / terminals
- Set data types
- Synchronize bus interface names
- Synchronize names of physical networks
- Delete superfluous configuration project at bus ports
    
  By means of this new action you can delete the configuration project entered at [bus ports](Glossary_o_sps_busanschluesse.htm) if it matches the configuration project of the associated PLC box. The configuration project of the bus port is then determined by the associated PLC box and automatically updated at changes.

The Write back configuration project to bus ports action is not required anymore since the configuration project at bus ports is now automatically determined by the associated PLC box. The corresponding menu item has been removed without replacement.

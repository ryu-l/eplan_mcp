# Entering Separator Suggestion

A [separator](Glossary_o_trennzeichen.htm) enables you to separate a keyword at a desired location. If you add a line break to a project text, the translated texts will have a line break at the location indicated by the separator suggestion.

Preconditions:

- You have access to a dictionary containing [keywords](Glossary_o_stichworte.htm).
- You have opened a dictionary.

1. Utilities > Translation > Edit dictionary
2. Select the Edit words tab.
3. In the Source language field, select the language that is used for the keyword in the dictionary.
4. In the Find field enter the existing keyword, and select it in the keyword list.
5. Place the mouse pointer in the Keyword field where it is that you would like to insert the separator suggestion in the translation text.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The mouse pointer changes into an insertion mark.
6. Press the [Alt Gr]+[|] (pipe character) shortcut key.  
     
   ![](../Pictures/Gui/ALL/arrow.png) EPLAN inserts a vertical line.

   ![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

   Tacho|meter
7. Click ![](../Pictures/Gui/ALL/all_save_as.png) (Save).

# Your Own Connection Point Designations and Identifiers

When editing [master data](Glossary_o_stammdaten.htm) you have the option of defining your own [connection point designations](Glossary_o_anschlussbezeichnungen.htm) and identifiers for [function definitions](Glossary_o_funktionsdefinitionen.htm).

- Using your own identifier sets you can take different standards, countries, and customers into consideration.
- For each function definition, ten sets of [connection designations](Glossary_o_verbindungsbezeichnungen.htm) and connection descriptions can be specified. These sets can then be selected later on from the function.
- Your self-defined identifier sets, connection point [designations](Glossary_o_bezeichnungen.htm), and [connection point descriptions](Glossary_o_anschlussbeschreibungen.htm) can be exported in XML files. This file can be used, for instance, as a backup for the exchange of data.
- You can import sets of identifiers, connection point designations, and connection point descriptions from an XML file and then use them for project planning in EPLAN.

# Using Connection Preview

The connection preview is useful when [placing](Glossary_o_auflegen.htm) [devices](Glossary_o_betriebsmittel.htm) on the 3D mounting layout navigator. A blue line shows which device, already placed, is electrically connected to the device that is about to be placed in the project plan. The connection preview makes it easier to group associated devices and helps avoid unnecessarily long [wiring](Glossary_o_verdrahtungen.htm).

Preconditions:

- You have opened a project.
- The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open.
- The layout space contains [part placements](Glossary_o_artikelplatzierungen.htm).
- The 3D mounting layout navigator is open.

1. Select a device in the 3D mounting layout navigator.
2. Select the Place popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The [part](Glossary_o_artikel.htm) that is to be placed hangs movably from the cursor as a preview.
3. Select the menu [items](Glossary_o_bauteile.htm) View > Connections > Preview.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A blue line appears between the part to be placed and the device with which it is electrically connected.
4. Place the part in a suitable location.

| **Selection** | Result | |
| --- | --- | --- |
| Device to be placed at the cursor, connected with two placed devices |  |
| Better placement location with shorter wiring to connected devices |  |

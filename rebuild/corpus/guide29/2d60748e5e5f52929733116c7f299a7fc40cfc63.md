# Creating Symbol Libraries

Precondition:

You have opened a project.

1. Select the following menu [items](Glossary_o_bauteile.htm): Utilities > Master data > Symbol library > New
2. In the Create symbol library dialog select a drive and a directory where you would like to save the new symbol library from the Save in drop-down list.
3. Overwrite the preset file name <New symbol library.slk> with a name of your choice.
4. Click [Save].  
     
   ![](../Pictures/Gui/ALL/arrow.png) If a symbol library with that name already exists in the selected drive and directory, reply to the prompt regarding overwriting the file.
5. In the Symbol library properties - <Library name> dialog you assign values to the desired [properties](Glossary_o_eigenschaften.htm).
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new symbol library is created, transferred to the list of opened [symbol libraries](Glossary_o_symbolbibliotheken.htm), and can be edited. EPLAN then extracts the company code, workstation number, and the short name of the employee from the system and user [settings](Glossary_o_einstellungen.htm) and stores this data in the symbol library.

![](../Pictures/Gui/ALL/note.png)Note:

A project configuration (Options > Settings > Projects > "Project name" > Management > Symbol libraries) can be used to assign an arbitrary number of symbol libraries to a project. The symbol libraries selected are then stored in the project.

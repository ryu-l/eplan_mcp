# Dialog Settings: Export Rittal - Perforex LC / Secarex

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Machining > Export Rittal - Perforex LC / Secarex
- Utilities > Manufacturing data > Machining > Rittal - Perforex LC / Secarex. Click [...] next to the Machine field.

In this dialog you configure the used Perforex LC / Secarex NC machine of the manufacturer Rittal.

Overview of the main dialog elements:

Machine:

The delivery scope includes the machine definition named "Default". If you have generated a different machine as a scheme, you can select and edit other machine definitions from the drop-down list.

You can [create](Glossary_o_erstellen.htm) new [schemes](Glossary_o_schemata.htm), save any changes to a scheme, and copy or delete schemes via the adjacent [Toolbar](schemeconfig_m_schemaschaltflaechen.htm). Schemes can also be imported or exported.

Description:

In this field is the description you entered for the machine in the Description field of the New scheme dialog.

Tabs:

The following tabs are available to configure the NC export in the format Rittal - Perforex LC / Secarex:

- [Tab General](ncgui_r_allgemeinexportkieslinglc.htm)
- [Tab Tools](ncgui_r_werkzeuge.htm)
- [Tab Tool selection](ncgui_r_werkzeugauswahl.htm)
- [Tab Fins](ncgui_r_stegparameterlc.htm)
- [Tab Field description](ncgui_r_feldbezeichner.htm)

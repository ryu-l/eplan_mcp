# Tab Connection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Project data > Connections > Navigator. Highlight a connection and select the Properties popup menu item. In the Properties <...> dialog, select the Connection tab.

On this tab you can edit the display [properties](Glossary_o_eigenschaften.htm) of a connection.

Overview of the main dialog elements:

Connection designation:

The [connection numbering](Glossary_o_verbindungsnummerierung.htm) process automatically enters the connection designation here. You can also manually enter a designation.

Use the Determine new designation popup menu item to automatically determine the next free connection designation. On the basis of the [settings](Glossary_o_einstellungen.htm) for the connection numbering, the next free connection designation is then determined and entered here.

Description:

Here you can enter an additional description of the connection; this property is not identifying and is only for information purposes.

---

Group box Cable / Conduit

Displayed DT:

If the connection is a [cable](Glossary_o_kabel.htm) connection or a cable, then the DT of the cable is displayed here. For tubes, the DT of the conduit is displayed.

Click [...] to open the DT selection dialog if the "Cable" value is set for the Connection: Association property (in the Properties group box of the table). Otherwise the Use existing [connections](Glossary_o_verbindungen.htm) dialog opens.

The displayed DT is displayed in the graphical editor on the [component](Glossary_o_schaltzeichen.htm). If you have defined in the project settings that [devices](Glossary_o_betriebsmittel.htm) are to be automatically numbered when [symbols](Glossary_o_symbole.htm) are inserted, then a DT is automatically suggested here. You can accept this DT or overwrite it manually.

In addition you can use the [popup menu or the [...] button](devicetaggui_r_feldsichtbaresbmk.htm) to [create](Glossary_o_erstellen.htm) or select a DT.

Full DT:

This field displays the full DT (i.e. structure identifier of the current environment + displayed DT) of the component / item. Use the [...] button to open the Full DT dialog. You can edit the [structure identifiers](Glossary_o_strukturkennzeichen.htm) there and select, e.g., another [mounting location](Glossary_o_einbauort.htm).

Color / number:

Here you enter the color or number of the connection; this property identifies the connection. This field is automatically filled by the connection numbering process. Click [...] to launch the Connection colors dialog and select a color from the list.

Pair index:

For paired [cable connections](Glossary_o_kabelverbindungen.htm) in a cable or paired tubes in a conduit, the pair index defines which cable connections or tubes are paired to each other. It thus identifies the cable connection pair or tube pair. This value can be manually entered or automatically filled on cable selection or [part](Glossary_o_artikel.htm) selection.

The pair index serves as an identifying property for automatically assigning the cable connections or tubes to the connections and can also be used as a selection criteria when selecting a cable or conduit via the device selection.

---

Cross-section / diameter:  
Cross-section / diameter unit:

The connection cross-section or diameter is adopted from the parts management and can be used as filter criteria when selecting devices. Click [...] to open the Cross-sections / diameters dialog and select a cross-section / diameter (with the associated unit) from the list.

If you selected a predefined cross-section / diameter from the Cross-section / Diameter field, the associated unit is automatically transferred to the Cross-section / diameter unit field. Use the drop-down list to select another unit. An overview of the possible units can be found in the section "[Connections: Units for Lengths and Cross-sections](connectionbrowsergui_k_einheitenverbindungen.htm)".

Representation type:

The representation type for connections is dependent on the display type of the connection targets. But it can be explicitly defined on a connection definition point or on the connection. This setting then overwrites the representation type determined from the connection targets.

Changing the representation type also changes the reporting behavior of the connection. For unplaced connections, only the [representation types](Glossary_o_darstellungsarten.htm) "Multi-line" and "Single-line" are available; the other representation types are only available placed connections. Connections can â like components â also be [graphical and external](devicetaggui_k_grafischeschaltzeichen.htm). Select the desired entry from the drop-down list:

- Not defined: This setting automatically determines the representation type from the connection targets.
- Multi-line: Defines the respective connection as multi-line. When reporting connections you can filter according to this criterion.
- Single-line: Defines the respective connection as single-line. When reporting connections you can filter according to this criterion.
- [P&I diagram](Glossary_o_ri_fliessbild.htm): Used for connections that you place in a P&I diagram. This includes, for example, connections between [process engineering](Glossary_o_verfahrenstechnik.htm) containers.
- Function overview ([fluid power](Glossary_o_fluidtechnik.htm)): Used for connections that you place in the function overviews of the fluid power. Such connections are not reported in the [reports](Glossary_o_auswertungen.htm).
- External: With this setting, the corresponding connection is not directly reported in reporting and [check runs](Glossary_o_prueflaeufe.htm). External connections are not directly reported, that is, they are included, for example, in terminal plans but not in connection lists. External connections are not designated when numbering connections.
- Graphic: With this setting, the corresponding connection is not reported in reporting and check runs. Graphical connections are not designated when numbering connections.

![](../Pictures/Gui/ALL/note.png)Note:

Targets are evaluated through external and logical connections. This means that whether a target is output in a report does not depend on the target itself but on the connection to that target. If the connection to the target is graphical, then the target will not be reported.

Function definition:

Click [...] to open the Function definitions dialog. The [function definitions](Glossary_o_funktionsdefinitionen.htm) are already filled in here, and only connection definitions are offered. Select the desired function definition.

This field is synchronized with the Definition field in the Symbol / function data tab.

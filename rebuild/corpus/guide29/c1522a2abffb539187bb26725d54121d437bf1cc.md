# Dialog Settings: Parts

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Options > Settings > Projects > "Project name" > Reports > Part.
- Utilities > Reports > Generate > [Settings] > Parts.
- Project data > Parts / Devices > Bill of materials navigator. In the tree or the list view of the Bill of materials - <Project name dialog, select Popup menu > Settings.

In this dialog, you define which project or parts data is output in the bill of materials from the bill of materials navigator and / or the "Parts list", "Summarized parts list", "Device tag list", and "Manufacturer / supplier list" [reports](Glossary_o_auswertungen.htm).

Overview of the main dialog elements:

Part assemblies:

The [settings](Glossary_o_einstellungen.htm) in this group box only have an effect on the parts list, the summarized parts list and the enclosure legend:

- Break up assemblies: Activate this check box if [assemblies](Glossary_o_baugruppen.htm) are to be broken down into their components, meaning their individual parts.
- Break up modules: Activate this check box if [modules](Glossary_o_module.htm) are to be broken down into their components, meaning their individual parts.
- Up to level: In this field enter the hierarchical level to which assemblies / modules are to be broken down. Values can only be entered if the Break up assemblies and / or Break up modules check box has been selected.
- Combine parts of a device: Activate this check box if the parts at terminals are to be combined into terminal strips and the parts at [cable connections](Glossary_o_kabelverbindungen.htm) are to be combined into cables in the parts list. If this check box is not selected then the parts are listed individually.

  ![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

  If the check box is selected, the parts list contains one item with 25 UK5 terminals and one item with 10 conductor sleeves; if the check box is not selected, the terminal UK5 is listed 25 times and the conductor sleeves are listed 5 times (conductor sleeves belong in pairs).

Include parts:

Activate the check box at those parts that are to be displayed in the bill of materials navigator and are to be included in the bill of materials. Most of the settings also apply to the "Parts list", "Summarized parts list", and "Manufacturer / supplier list" reports.

![](../Pictures/Gui/ALL/note.png)Notes:

- The Devices without part number setting is not reported for the Manufacturer / Supplier list.
- The settings Devices without part number, Terminal strip parts, Terminal parts, Cable parts, Plug parts, Pin parts, Busbar parts, Busbar connection point parts also apply for the Device tag list report.
- The Pre-planning part setting evaluates parts which have been entered solely at [planning objects](Glossary_o_planungsobjekte.htm) in pre-planning. If there already is a main function or a [part](Glossary_o_artikel.htm) placement for a planning object, this setting is not evaluated in the bill of materials and the parts reports.

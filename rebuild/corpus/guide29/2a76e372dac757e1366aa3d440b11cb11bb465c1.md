# P004006: PLC box without conn. point

### Cause

You have drawn a PLC box that does not contain [PLC connection points](Glossary_o_sps_anschluesse.htm).

### Solution

Insert at least one PLC connection point within the PLC box and start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

Missing PLC [connection points](Glossary_o_anschluesse.htm) are determined both on schematic pages as well as on overview pages.

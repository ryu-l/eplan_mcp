# Main placement: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_hauptplatzierung.htm)

### Main placement

User interface / operation

Defines the structure box to which cross-references refer as a main placement. This allows the display of cross-references between structure boxes. If the property is not switched on at any box, then the graphically first structure box is regarded as the main placement.

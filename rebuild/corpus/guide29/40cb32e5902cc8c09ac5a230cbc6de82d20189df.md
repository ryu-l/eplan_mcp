# Creating Macro Projects

You can use [macro projects](Glossary_o_makroprojekte.htm) to manage your [macros](Glossary_o_makros.htm) and automatically [create](Glossary_o_erstellen.htm) macros.

Precondition:

You have created a basic project \*.zw9 or a project template \*.ept.

1. Select the menu item Project > New.
2. In the Create project dialog create a new project as described in [Creating a Project](projects_h_projekteerstellen.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) EPLAN opens the Project [properties](Glossary_o_eigenschaften.htm): <Project name> dialog.
3. Select the "Settings" Category in the Properties tab.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Only the Type of project property is still displayed.
4. Click here in the Value column on the associated field and select the "Macro project" setting from the drop-down list.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new macro project is created and can be edited like a "normal" project.

![](../Pictures/Gui/ALL/info.png)Tip:

Creating a new project is not the only way to create macro [projects](Glossary_o_projekte.htm). You can also first create a schematic project, prepare corresponding schematics [cut-outs](Glossary_o_durchbrueche.htm) for the macros to be generated, and then convert to a macro project by changing the [project properties](Glossary_o_projekteigenschaften.htm). To do this you only have to change the project setting Type of project to "Macro project" as described in Step 3.

# P020017: <x> (value <y>) <z> -> <u>

### Description

You have run a project comparison, checking the [settings](Glossary_o_einstellungen.htm) of the test project (incoming project) against those of the comparison project and differences were found. In this message, <x> represents the path to the project setting where there are differences between the test project and the comparison project. <y> indicates the value number or value position of the setting in question. <z> indicates the value of the setting in the comparison project, and <u> the value in the test project.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

# Dialog Edit structures

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have selected one or more pages in the page navigator. Edit > Copy. In the page navigator, click the position where the copied pages are to be inserted. Edit > Paste. [Extras] > Edit structures.
- Page > Page macro > Insert. In the Select macro dialog, select a page macro and click [Open]. [Extras] > Edit structures.

In this dialog you can specify / edit the [main identifiers](Glossary_o_hauptkennzeichen.htm) and up to 9 [sub-identifiers](Glossary_o_unterkennzeichen.htm) each for the individual [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm).

Overview of the main dialog elements:

Table:

The table lists the identifier [blocks](Glossary_o_bloecke.htm) as well as the complete identifiers of the source [functions](Glossary_o_funktionen.htm) / pages. These cells cannot be edited. You can however use the cells Main identifier and Sub-identifier 1 to Sub-identifier 9 to specify / modify several identification structures in one pass.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Enter for example the desired characters into one cell and then use the Clipboard to copy this structure into other cells by using [Ctrl] + [C] and [Ctrl] + [V].

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# Dialog STEP export / VRML export

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have selected a [layout space](Glossary_o_bauraum.htm) in the layout space navigator. Select the Layout space > Export > STEP / VRML menu [items](Glossary_o_bauteile.htm).

In this dialog you specify the [settings](Glossary_o_einstellungen.htm) for the export of the 3D graphic data to the STEP or VRML format.

Overview of the main dialog elements:

Source:

This field displays the source of the export. For an entire project, this is the project name; for individual layout spaces the full layout space names are displayed (including the [structure identifiers](Glossary_o_strukturkennzeichen.htm) Functional assignment, Higher-level function, etc.). The entries in this field cannot be modified.

Scheme:

Select a scheme to define the settings for the STEP / VRML export from the drop-down list.

Click [...] to open the Settings: STEP export / VRML export dialog. In this dialog you define the settings for exporting STEP or VRML files and save them as a scheme.

---

Group box Export medium

Storage medium:

If this export medium is selected, the STEP / VRML file is output to a storage medium. Enter the storage location in the Output directory field. The directory is pre-selected that is defined for the STEP / VRML export in the user settings.

The [...] button opens the Select directory dialog in order to select any directory of your choice for the export.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).

E-mail:

If this export medium is selected, the STEP / VRML file is compressed and sent as an e-mail. From the Split size drop-down list select the maximum size for an individual e-mail file. You can choose values from 1 MB to 10 MB or the entry "Unlimited". EPLAN automatically creates the number of e-mail files required to send the whole project. All individual mails in the group will have this text in the subject line: "<File name> n/m". "n" is the number of the individual e-mail file and "m" is the overall quantity of the files.

---

File name:

When exporting a single layout space, you have the option of entering any random file name. You can use the [...] button to assign a file name or select the name of an existing file.

If no file name is specified, a name is assigned to the exported file on the basis of the [Generate file names](gededit3dgui_d_einstellungenstepexport.htm#Dateinamenerzeugen) setting.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available path variables.

When exporting multiple layout spaces, the file name cannot be freely chosen. STEP / VRML files are created as a consecutive number in the specified target directory, or from the layout space name, or from the [properties](Glossary_o_eigenschaften.htm); this depends on the settings of the selected scheme.

If a layout space is selected which contains several enclosures and, in the Settings: STEP export / VRML export dialog the Separate export per enclosure setting has been activated, then it is impossible to enter the file name. The File name field is deactivated in this case.

Apply to entire project:

If you activate this check box, the currently selected layout space is extended to all layout spaces of the project.

If this check box is deselected, then only the selected layout spaces are exported.

If you have already selected a single project (and not set any [filters](Glossary_o_filter.htm)), then this check box is grayed-out. You can then no longer change the relevant settings.

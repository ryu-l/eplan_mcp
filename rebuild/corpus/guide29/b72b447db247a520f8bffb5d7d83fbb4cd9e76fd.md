# P004100: The CPU is not assigned to a slot / module and / or a rack

### Cause

At a PLC card that was defined as a CPU the structure information specified in the message text is missing.

### Solution

1. Locate the PLC card in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Bring the PLC structure data tab to the front.
3. First check whether the structure information entered in the Configuration project and Station [ID](Glossary_o_id.htm) fields is complete.
4. Additionally enter a value in the Position (slot / module) field or fill the fields PLC card is placed on [rack](Glossary_o_baugruppentraeger.htm) ID and Rack with the corresponding values.
5. Click [OK].
6. Then start a new check run.

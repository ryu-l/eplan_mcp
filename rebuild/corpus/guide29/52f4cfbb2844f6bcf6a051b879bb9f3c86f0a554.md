# Fitting Text in Alignment Boxes

Texts or [placeholder texts](Glossary_o_platzhaltertexte.htm) can be fitted in the alignment box and thus adapted to the specific space available on a page in the [form](Glossary_o_verlauf.htm). Drawing in of the alignment box is not required. The display property Text fitting permitted is available in order to scale a text correspondingly in an alignment box without it being truncated. This check box allows the scaling of texts. Fitting itself is carried out by a subsequent action.

### Preparing texts for fitting

Precondition:

You have opened a page or a form.

1. Double-click a text / placeholder text.
2. In the Properties dialog, bring the [Format](gededitgui_r_format.htm) tab to the foreground.
3. Open the Alignment box hierarchy level and activate the check boxes for the [properties](Glossary_o_eigenschaften.htm) Activate alignment box, Text width fixed, Text height fixed and Text fitting permitted.
4. Click [OK].

![](../Pictures/Gui/ALL/info.png)Tip:

As for all other format and display [settings](Glossary_o_einstellungen.htm) you can also transfer these four settings to other texts / placeholder texts by using the [actions](Glossary_o_aktionen.htm) Copy format and Assign format.

### Adapting texts automatically

The output placeholder texts are adapted automatically during the generation of reports.

### Adapting texts manually

Precondition:

You have opened a page or a form or the page navigator.

1. Select one or more texts / placeholder texts. Or mark the selected pages or the project in the page navigator.
2. Select the menu [items](Glossary_o_bauteile.htm) Edit > Text > Fit texts in alignment boxes.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The font size of the corresponding texts is reduced so that the text fits into the alignment box. The calculated font size is entered automatically in the properties dialog in the Font size setting.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have marked [report pages](Glossary_o_auswertungsseiten.htm) in the page navigator, the output texts with a corresponding setting are also fitted manually.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have marked invisible texts in the graphical editor or in the page navigator during selection, fitting is also applied to these texts.

![](../Pictures/Gui/ALL/note.png) Notes:

- The font size is only reduced when fitting the text. At a subsequent enlargement of the alignment box the font size cannot be enlarged again by fitting it in the alignment frame.
- If you carry out the menu item Fit texts in alignment boxes for a [component](Glossary_o_schaltzeichen.htm) in the schematic, scaling is only carried out at those [property texts](Glossary_o_eigenschaftstexte.htm) at which the requirements (alignment box activated, etc.) are fulfilled for fitting.

# P027010: Topology - The routing track at the connection from <x> to <y> has an invalid routing path

### Cause

A routing path has been deleted within the routing path network through which the routing connection runs from <x> to <y>. Moreover, the connection has not been re-routed yet.

### Solution

1. Locate the source of the [topology](Glossary_o_topologie.htm) function in the routing path network using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Trace the routing track in the routing path network back to the gap that was created by the missing routing path.
3. Add the missing routing path to the routing path network using the Insert > Topology > Routing path menu [items](Glossary_o_bauteile.htm).
4. Position the new routing path between [routing path networks](Glossary_o_streckennetze.htm) [objects](Glossary_o_objekte.htm) that are no longer connected, so that the two ends of the routing path [dock](Glossary_o_andocken.htm) to the connection point of a topology function or to the insertion point of a routing point.
5. Re-[route](Glossary_o_verlegen.htm) the connection by selecting the total routing path network, and selecting Project data > Topology > Route.
6. Then start a new check run.

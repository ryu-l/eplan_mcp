# Placing Mounting Panels

When [mounting panels](Glossary_o_montageplatten.htm) are placed on "Panel layout" pages, a distinction is drawn between [placing](Glossary_o_auflegen.htm) a [part](Glossary_o_artikel.htm) from the parts management module, "free" placement using the [property dialog](Glossary_o_eigenschaftendialog.htm), and placing as a device.

### Place mounting panels from parts management

Preconditions:

- You have opened a project.
- You are in the graphical editor on a "Panel layout" page.

1. Insert > Device
2. In the Part selection dialog, in the generic product group Mechanics, open the hierarchy level Housing.
3. Select the desired housing part.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The mounting panel symbol is scaled to the specified size (only values larger than 0.0 are accepted!) and hangs on the cursor.
5. Place the symbol.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Properties <...>: Mounting panel dialog is opened.
6. Enter a device tag in the Displayed DT field on the Mounting panel tab.
7. If necessary, assign further [properties](Glossary_o_eigenschaften.htm) to the mounting panel.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The mounting panel is created.

### Placing free mounting panels

Preconditions:

- You have opened a project.
- You are in the graphical editor on a "Panel layout" page.

1. Select Insert > Box / connection point / mounting panel > Mounting panel.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The box symbol that displays the mounting panel is hanging on the cursor.
2. Place the rectangle representing the mounting panel.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Properties <...>: Mounting panel dialog is opened.
3. Enter a device tag in the Displayed DT field on the Mounting panel tab.
4. If necessary, assign further properties to the mounting panel.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The mounting panel is created.

### Place mounting panel as a device

Preconditions:

- You have opened a project.
- You are in the graphical editor on a "Panel layout" page.

1. Insert > Device
2. In the Part selection dialog, go to the generic product group Mechanics, select the hierarchy level Housing, and then search for parts that belong to the product subgroup Mounting panels.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If this property has been set for a part it will be recognized as a mounting panel. Parts for which this property is not specified will be treated as normal [devices](Glossary_o_betriebsmittel.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) If a suitable part is found, EPLAN checks whether a graphical macro (Mounting data tab), or a macro (Technical data tab) is stored in the parts data. If no graphical macro / macro is stored, a message is shown and you will be asked whether you wish to apply the dimensions of the part.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The mounting panel is created.

![](../Pictures/Gui/ALL/note.png)Note:

If neither graphical macro nor dimensions have been assigned to the part, the function is canceled.

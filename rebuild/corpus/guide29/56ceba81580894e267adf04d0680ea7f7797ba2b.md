# P030001: Original project contains changes in the defined working section of the subproject '<x>'

### Cause

In the original project, for example, pages, layout spaces or pre-[planning objects](Glossary_o_planungsobjekte.htm) were created in the working section in which you want to embed the subproject.

![](../Pictures/Gui/ALL/note.png)Note:

This message is only output in the original project.

### Solution

1. Delete the pages, layout spaces or pre-planning [objects](Glossary_o_objekte.htm) from the respective working section of the original project or move them to other defined working sections of the original project.
2. Start any check run in order to delete the message.
3. Then embed the subproject again into the desired working section of the original project.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

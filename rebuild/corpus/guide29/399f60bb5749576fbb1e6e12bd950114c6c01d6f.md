# Defining the Plot Frame and Path Numbering

The [settings](Glossary_o_einstellungen.htm) for the standard plot frame and the path, device and PLC numbering are adopted from the selected template (project template or basic project) when creating a project. If you do not want to use these settings, you can adjust them as desired.

Precondition:

You have opened a project.

### Define standard plot frame

1. Select the menu [items](Glossary_o_bauteile.htm) Options > Settings > Projects > "Project name" > Management > Pages.
2. In the dialog Settings: Pages select "Browse" from the Standard plot frame drop-down list.
3. In the Select plot frame dialog, switch to the directory PlotFrames\EPLAN.
4. Select a file.
5. Click [Open].

![](../Pictures/Gui/ALL/note.png)Note:

The selected plot frame has no effect on the path numbering.

### Define path numbering

1. Select the menu items Options > Settings > Projects > "Project name" > Management > Pages.
2. Select one of the options available in the Path numbering group box in the dialog Settings: Pages.
3. To use a changed setting for the path numbering in a project, you have to do this manually after closing the dialog this dialog by going to Utilities > Update path designations.

### Select format for device numbering

1. Select the Options > Settings > Projects > "Project name" > Devices > Numbering (online) menu items.
2. Select a format in the Numbering format field of the dialog Settings: Numbering (online).
3. To [create](Glossary_o_erstellen.htm) or customize a format, click [...].  
     
   ![](../Pictures/Gui/ALL/arrow.png) You can [Create a numbering format](numerationgui_h_onlineformat.htm) in the dialog Numbering formats.
4. Click [OK].

### Select format for PLC numbering

1. Select the menu items Options > Settings > Projects > "Project name" > Devices > PLC.
2. Select a scheme from the drop-down list in the PLC-specific settings field of the dialog Settings: PLC.
3. To create or customize a scheme, click [...].  
     
   ![](../Pictures/Gui/ALL/arrow.png) You can define the PLC-specific settings for the numbering in the dialog Settings: PLC-specific .
4. Click [OK].

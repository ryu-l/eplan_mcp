# Dialog Tree configuration

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Utilities > Parts > Management > [Extras] > Settings.
- Options > Settings > User > Management > Parts.

Click [...] in the Tree configuration field.

In this dialog you define the configuration of the parts management tree view.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Main nodes:

This list contains the possible main nodes for the configuration. Click [...] at the right edge of the line within a main node name to display the Tree configuration - main node dialog, where you define the detailed [settings](Glossary_o_einstellungen.htm) for the each configuration.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

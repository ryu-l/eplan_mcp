# Dialog Settings: Wire fabrication

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Wire fabrication > "Machine".
- Utilities > Manufacturing data > Wire fabrication > "Machine".

In this dialog define the [settings](Glossary_o_einstellungen.htm) for exporting wire data to [wire fabrication](Glossary_o_drahtkonfektionierung.htm) machines.

Overview of the main dialog elements:

Scheme:

The scope of delivery contains the machine definition with the name of the manufacturer. If you have generated a different machine as a scheme, you can select and edit other machine definitions from the drop-down list.

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Tabs:

To configure the wire fabrication, you can use the following tabs, depending on the respective machine:

[Tab General](productionwiringgui_r_allgemein.htm)

[Tab Wires](productionwiringgui_r_draehte.htm)

[Tab Conductor termination processing](productionwiringgui_r_aderendbehandlung.htm)

[Tab Machine command](productionwiringgui_r_maschinenbefehl.htm)

[Tab Labeling](productionwiringgui_r_beschriftung.htm)

[Tab Settings](productionwiringgui_r_einstellungen.htm)

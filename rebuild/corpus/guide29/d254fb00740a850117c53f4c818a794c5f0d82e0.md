# P003003: Mismatch between connection DT and cable DT

### Cause

A connection definition point, situated within reach of a [cable](Glossary_o_kabel.htm) definition line or a shielding conductor, uses its own device designation. The cable or shielding conductor DT and the connection definition point DT do not correspond.

### Solution

Double-click the connection definition point in the schematic, and delete the visible device designation of the connection definition point in the Properties<...> dialog.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

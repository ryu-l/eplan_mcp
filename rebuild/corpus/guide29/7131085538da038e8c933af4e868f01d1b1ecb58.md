# P501010: The part <x>, variant <y>, does not exist at the assembly / module

### Cause

In the parts database to be checked a [part](Glossary_o_artikel.htm) entered at an assembly or at a module was found that does not exist as a record in the parts database. EPLAN states the name of the part in the placeholder <x> and the part variant in the placeholder <y>.

### Solution

1. Open the parts management and first [create](Glossary_o_erstellen.htm) the required part in the parts management. Or import the part.
2. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective assembly / module is already marked in it.
3. Bring the Assembly or Module tab to the front.
4. Select the newly created part in the Part number field.
5. Close the parts management, save the modified data, and carry out a parts synchronization.
6. Then start a new check run.

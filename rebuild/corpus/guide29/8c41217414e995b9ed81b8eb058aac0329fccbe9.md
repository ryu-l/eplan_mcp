# Dialog Settings: Counter reset range

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the [Settings: Connection numbering](wirenumberinggui_d_verbnumeinstellungen.htm) dialog (for example via the Options > Settings > Projects > "Project name" > Connections > Connection numbering menu [items](Glossary_o_bauteile.htm)). You have selected a [user-defined](Glossary_o_benutzerdefiniert.htm) scheme in the dialog Settings: Connection numbering and have selected the Designation tab. You have selected an entry in the Format groups field and clicked ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit), or you have clicked ![](../Pictures/Gui/ALL/all_new_as.png) (New).

In the Connection numbering: Formats dialog, you have selected a "Counter" type of format element from the Available format elements list and moved it into the Selected format elements list using the arrow button, or you have selected an existing "Counter" type of format element and clicked ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit).

In the Format: Counter dialog you have selected the Reset per structure / page check box. Click [Settings].

In this dialog, you specify the range within which the counter will be incremented. When one of the specified criteria changes, the counter is reset to its start value.

When designating the [connections](Glossary_o_verbindungen.htm) you can, for example, specify that the [connection designations](Glossary_o_verbindungsbezeichnungen.htm) within a counter reset range of this type must be unique.

Overview of the main dialog elements:

Functional assignment ... User-defined:

If the check box in one of these fields is selected, the counter is reset to the start value as soon as the structure identifier for the identifier block in question changes.

Sub-identifiers:

If the check box in one of these fields is selected, the counter is reset to the start value as soon as the sub-identifier for the identifier block in question changes.

![](../Pictures/Gui/ALL/note.png)Note:

The preceding signs and separators between the individual [structure identifiers](Glossary_o_strukturkennzeichen.htm) can not be edited here. They originate from the [settings](Glossary_o_einstellungen.htm) of the Extended project structures dialog, which you open in the Structure tab of the [project properties](Glossary_o_projekteigenschaften.htm) by clicking [Other].

Page:

If this check box is selected, the counter is reset to the start value as soon as the page changes.

Subpage:

If this check box is selected, the counter is reset to the start value as soon as the subpage changes.

From source:

If this option is selected, the criteria specified above are applied to the source [functions](Glossary_o_funktionen.htm) of the connections, i.e. the range changes if the criterion at the source of the connection changes.

From target:

If this option is selected, the criteria specified above are applied to the target functions of the connections, i.e. the range changes if the criterion at the target of the connection changes.

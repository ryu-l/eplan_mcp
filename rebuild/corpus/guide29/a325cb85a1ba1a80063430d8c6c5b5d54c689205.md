# Dialog Settings: 2D (User, Graphical Editing)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > User > Graphical editing > 2D

In this dialog you can specify your personal [settings](Glossary_o_einstellungen.htm) for working with the graphical editor, like color settings, cursor [form](Glossary_o_verlauf.htm), or the display of invisible elements.

Overview of the main dialog elements:

Group box Color settings

Scheme:

Here, select the color scheme for the graphical editor. The names of the color [schemes](Glossary_o_schemata.htm) indicate the color of the screen background: You can select a white, black or gray background. The colors of the individual elements are adapted for each background.

Graphical symbol... Track potential:

You specify the colors for the representation of the following elements in the fields Graphical symbol to Track potential:

- Symbols to which a function with the representation type Graphic, External or Pair cross-reference is assigned
- Elements to which the Invisible property is assigned
- Highlighting of [connections](Glossary_o_verbindungen.htm) that have the same potential, signal or net.

Use [...] to open the dialog [Color selection](mf_d_farbauswahl.htm) at all the color settings. Select the desired color there.

---

Group box Cursor

Display:

From the drop-down list, select whether the cursor should be displayed as crosshairs or as a small cross.

Display crosshairs when placing symbols and macros:

If this check box is selected, the cursor will always take the form of crosshairs when you are [placing](Glossary_o_auflegen.htm) [symbols](Glossary_o_symbole.htm) or [macros](Glossary_o_makros.htm), regardless of any other cursor representation.

---

Scroll behavior:

Here, specify how the mouse wheel should act during scrolling:

- As for word processing: Scrolling moves the screen content up / down. [Ctrl] + scrolling enlarges / shrinks the image section.
- As in CAD: Scrolling enlarges / shrinks the image section. [Ctrl] + scrolling moves the screen content up / down.

Minimum font size:

Independently of the currently defined font size, you can define a minimum font size for text to be displayed on the screen. However, this setting has no effect on the printed image.

If this check box is activated, all texts whose actual font size is smaller than the minimum font size determined in the adjacent field are displayed with the minimum font size.

If the check box is deactivated, the texts are displayed in the actually set font size.

Show invisible elements:

If this check box is selected, elements marked as "Invisible" are shown on the project pages. Invisible elements are displayed in a different color.

Print / Export invisible elements:

If this check box is selected, elements marked as "invisible" are printed and exported (e.g. to PDF and [DXF](Glossary_o_dxf.htm)).

If the check box is deselected, only visible elements will be printed / exported.

Show tooltip:

If this check box is selected, a short information text is displayed in the graphical editor (2D and 3D) when you move the cursor over a [component](Glossary_o_schaltzeichen.htm).

Show property names:

If this check box is activated, then all property names are displayed for all placed [properties](Glossary_o_eigenschaften.htm) in all [projects](Glossary_o_projekte.htm) and the assigned values are hidden.

If the check box is deactivated, the values of placed properties are displayed. This is the default setting.

Default grid sizes:

In the Grid size A through Grid size E fields, you have the option of specifying five different [grid](Glossary_o_raster.htm) sizes. Choose the grid size in the graphical editor via the associated buttons ![](../Pictures/Gui/ALL/gededitgui_grida.png) to ![](../Pictures/Gui/ALL/gededitgui_gride.png) on the "View" toolbar.

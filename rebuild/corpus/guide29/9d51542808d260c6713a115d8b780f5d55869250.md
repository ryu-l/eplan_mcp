# P004035: Bus ID '<x>' within a logical network '<y>' assigned several times (bus port in the bus system: <z>')

### Cause

The same bus IDs were assigned at one or more [bus ports](Glossary_o_sps_busanschluesse.htm) within a logical network of the bus system. The check considers both the entered value of the Physical network: Bus [ID](Glossary_o_id.htm) / item number property and the value of the Physical network: Bus ID / item number 2 property in the Bus data tab.

The use of this check run makes sense if multiple bus IDs within the physical network are permitted and the uniqueness is only required within the logical network.

This check run only checks bus ports at which a configuration project is entered.

### Solution

1. Open the Properties <...> dialog for the corresponding bus port or bus ports. Enter differing values in the Bus data tab in the fields Physical network: Bus ID / item number and / or Physical network: Bus ID / item number 2.
2. Or change the entry in the Logical network: Name field at one of the bus ports to assign this bus port to another logical network.
3. Then start a new check run.

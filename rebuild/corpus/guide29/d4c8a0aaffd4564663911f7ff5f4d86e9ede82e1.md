# Defining Increment Sizes

The increment defines how far the cursor jumps in a particular direction when the arrow key is pressed. It is set and activated from the current cursor position.

For the Use logical coordinates setting, the step size is given in [grid](Glossary_o_raster.htm) increments. This depends on the grid increments used on the page. If the defined grid size is (e.g.) 4 mm, then an increment setting of 1 means that the cursor jumps by 4 mm, a setting of 2 by 8 mm, etc. An increment setting less than 1 is not permitted.

For the Use graphical coordinates setting, the increment is defined in terms of the drawing units (in mm or inches, depending on the [settings](Glossary_o_einstellungen.htm)).

![](../Pictures/Gui/ALL/note.png)Note:

The increment setting is only considered on the Graphical pages if there is no grid activated. If a grid is activated and set to 16 mm, for example, then the jump is 16 mm, irrespective of the increment setting for the graphical coordinates.

Precondition:

You have opened a page, [form](Glossary_o_verlauf.htm), plot frame or symbol.

1. Select the following menu [items](Glossary_o_bauteile.htm): Options > Increment
2. Select
   the Use graphical coordinates check box
   to display the increments for Graphical coordinates in the list fields.  
    Deactivate the check box to display the increments for
   Logic coordinates.
3. Enter the desired increment into the Increment field.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The cursor can now only be moved using the
   keyboard in the increment defined here.

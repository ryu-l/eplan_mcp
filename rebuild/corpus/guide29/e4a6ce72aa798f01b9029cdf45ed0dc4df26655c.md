# Creating and Editing Structure Segments

Structure [segments](Glossary_o_segmente.htm) are created and managed in the pre-planning navigator.

You edit the [properties](Glossary_o_eigenschaften.htm) of a structure segment in the tabs <Structure segment - displayed name> and Documents / Pages of the [property dialog](Glossary_o_eigenschaftendialog.htm).

![](../Pictures/Gui/ALL/note.png)Note:

Structure segments cannot be created below [planning objects](Glossary_o_planungsobjekte.htm), nor can they be moved there.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Pre-planning > Navigator
2. Highlight either the project or an existing structure segment, and select the New structure segment popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If there are several [segment definitions](Glossary_o_segmentdefinitionen.htm) in the project, the Select segment definition dialog opens.
3. Select the desired segment definition and click [OK].
4. Enter the desired data for the new structure segment in the <Structure segment - displayed name> tab in the Properties <...> dialog.
5. If necessary, assign to the structure segment [external documents](Glossary_o_fremddokumente.htm) and / or project pages on the Documents / Pages tab.
6. Click [OK].

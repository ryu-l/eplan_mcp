# Displaying Cable Connection Points

The View > Cable connections option makes it easier to find automatically generated cables and [connections](Glossary_o_verbindungen.htm) used during the automatic generation of cables. When this option is activated, [connection points](Glossary_o_anschluesse.htm) of [functions](Glossary_o_funktionen.htm) having an active Cable connection point property are marked with an arrow. (Automatic generation of cables only accounts for connections to functions with at least one [cable](Glossary_o_kabel.htm) connection point or which are defined as [cable connections](Glossary_o_kabelverbindungen.htm).)

You set the Cable connection point property in the [Connection point logic](xfctdefbrowsergui_d_anschlusslogik.htm) dialog, which you call up from the Symbol / function data tab, via the [Logic] button.

Precondition:

You have opened a project page in the graphical editor.

1. Select the menu [items](Glossary_o_bauteile.htm) View > Cable connections.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Connection points of functions with the Cable connection point property are marked with a small arrow.
2. Reselect the View > Cable connections menu items.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The arrows for displaying the cable connection points are hidden again.

# Dialog Settings: Hose line configurator

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have installed the hose line configurator as an add-on variant of EPLAN Fluid. You have started EPLAN Fluid and the hose line configurator.

- Select the menu [items](Glossary_o_bauteile.htm) Options > Settings > User > Add-ons > Hose line configurator.
- Or select the menu items Extras > Settings in the Configure hose lines dialog of the hose line configurator.

Or you have installed the hose line configurator as a stand-alone variant and started the program.

- Select the menu item Options > Settings in the menu of the hose line configurator.

In this dialog you define the [properties](Glossary_o_eigenschaften.htm) and values for the configuration of the [hose lines](Glossary_o_schlauchleitungen.htm) and save them as a scheme. The information stored here is offered for selection when the hose [lines](Glossary_o_leitungen.htm) are configured in the Edit <...> dialog.

![](../Pictures/Gui/ALL/note.png)Note:

The scheme DIN 20066\_2012-01 is preset by default. It allows you to configure hose lines conforming to the specifications of the standard DIN 20066.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Tabs:

In the tabs specify the [settings](Glossary_o_einstellungen.htm) for the configuration data:

- [Tab General](fluidhoseconfiggui_r_nummerierung.htm)
- [Tab Nominal diameter](fluidhoseconfiggui_r_nenndurchmesser.htm)
- [Tab Manufacturer](fluidhoseconfiggui_r_hersteller.htm)
- [Tab Fittings](fluidhoseconfiggui_r_armaturen.htm)
- [Tab Hose groups](fluidhoseconfiggui_r_schlauchgruppen.htm)
- [Tab Hose assignments](fluidhoseconfiggui_r_schlauchzuordnungen.htm)
- [Tab Further properties](fluidhoseconfiggui_r_weitereeigenschaften.htm).

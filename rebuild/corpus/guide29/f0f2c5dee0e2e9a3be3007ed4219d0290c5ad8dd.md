# Dialog Double junction

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project and are viewing a schematic in the graphical editor. Under the menu [items](Glossary_o_bauteile.htm) Options > Settings > User > Graphical editing > Connection symbols you selected the With target specification or as point option, or you selected the Connection symbols with prompt check box when you selected another option. Insert > Connection symbol > Double junction.

Connections flow in four directions at a double junction. Every double junction can also have four [variants](Glossary_o_varianten.htm).

Double junctions can also be displayed as points.

Overview of the main dialog elements:

[Specify targets:](egedgui_d_bruecke.htm#Ziele)

Vertical / Horizontal:

Every double junction has three connection directions. Here you specify the desired variant by selecting the corresponding option.

Draw as point:

Select this check box if you want the double junction to be drawn as a connection point.

If you selected the With target specification or as point option in the dialog Settings: Connection symbols, the last setting made will be saved, and will be used by default the next time you insert a connection symbol.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

First insert a double junction as a connection point. Then insert a jumper. The Draw as point check box is then selected in the Property dialog of the jumper. Deselect this to display the jumper with target specification. When you insert the next T-node, for example, the Specify targets setting will be used by default.

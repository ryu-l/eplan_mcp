# Dialog Settings: Column configuration

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have selected an object in the tree that belongs to the Connection point pattern hierarchy level. Select the Connection points tab and click [...] next to the Scheme field.

In this dialog, you can specify which columns will be displayed for connection point data.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

![](../Pictures/Gui/ALL/note.png)Note:

The [schemes](Glossary_o_schemata.htm) are saved by user. If, for instance, an electrical engineer and a fluid engineer are working together on a project, each of them can use specific [settings](Glossary_o_einstellungen.htm) for column configuration. To include a scheme together with the project, you must export the scheme and pass it on separately.

Column configuration:

In this field, you can specify which columns will be shown in the table in the Connection points tab. Check the corresponding check boxes. Use the arrow buttons to change the order of the columns.

The Connection point designation check box cannot be deactivated since the connection point designation is identifying here.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

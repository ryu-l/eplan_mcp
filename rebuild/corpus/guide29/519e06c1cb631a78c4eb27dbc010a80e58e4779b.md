# Synchronizing Connections Displayed in a Distributed Manner

A connection can occur in the schematic multiple times in a distributed manner in the [representation types](Glossary_o_darstellungsarten.htm) "Multi-line", "Single-line", "Topology" or "3D mounting layout". If you have not activated the Properties (global) processing mode, you can edit the [properties](Glossary_o_eigenschaften.htm) of the distributed [connections](Glossary_o_verbindungen.htm) independently of each other. This can [create](Glossary_o_erstellen.htm) differences between the properties of the connections. If you wish to fix the differences, synchronize the properties of the distributed connections throughout the project.

Preconditions:

- You have opened a project.
- You have further multi-line, single-line and / or [routing connections](Glossary_o_verlegeverbindungen.htm) of at least one identical connection.
- In the project [settings](Glossary_o_einstellungen.htm) you have determined the synchronization behavior, i.e. how the properties of one representation type are to be transferred to another representation type (via the menu [items](Glossary_o_bauteile.htm) Options > Settings > Projects > "Project name" > Devices > General, group box [Synchronization](xessettingsgui_d_betriebsmittelallgemein.htm)).

### Transfer multi-line connection properties

The following describes the synchronization of connections displayed in a distributed manner, with the values of the multi-line connections being transferred to the other representation types. Use the other submenu items, e.g. 3D mounting layout --> all representation types, to equally transfer the properties of the routing connections.

1. Select a project, page, or connection.
2. Select the Utilities > Synchronize > Connections > Multi-line --> all representation types menu items.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A query dialog opens.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The values of the selected multi-line connections are transferred to the corresponding connections of the other "multi-line", "single-line" and "3D mounting layout" representation types.

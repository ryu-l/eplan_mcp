# Regenerating Headings on Form Pages

You use the [form](Glossary_o_verlauf.htm) property Generate data headers for the first x sorting properties ([ID](Glossary_o_id.htm) 13060) to [create](Glossary_o_erstellen.htm) references to the sorting of the respective [reports](Glossary_o_auswertungen.htm). This means that the form defines whether the sorting [properties](Glossary_o_eigenschaften.htm) should be used for generating new headings.

The following values are possible for this property:

1. "0": No new headings are generated.
2. "1": The first sorting property is used for the new heading.
3. "2": The first and second sorting properties are used for the new heading.
4. "3": The first, second, and third sorting properties are used for the new heading.
5. etc.

Preconditions:

- You have opened a project.
- You have opened the form whose properties you would like to edit in the form editor (Utilities > Master data > Form > Open > [Open]).
- You have opened the Form properties - <Form name> dialog (Popup menu > Properties in the form in the navigator dialog Pages - <Project name>).

1. In the Form properties - <Form name> dialog, click ![](../Pictures/Gui/ALL/all_new_as.png) (New) above the Property name / Value list.
2. In the Property selection dialog, select the Generate headings for the first x sorting properties property.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property is loaded into the list.
4. Enter the number of sorting properties to be taken into account into the Value column.
5. Edit other form properties as required.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The defined properties are adopted for the form and the Form properties- <Form name> dialog closes.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

In the Sorting dialog, you have selected the "Higher-level function + Mounting location + DT" scheme for outputting the device list. In the form for the device list, the Generate headings for the first x sorting properties has been given the value "1".

If you now [generate](Glossary_o_erzeugen.htm) the [report pages](Glossary_o_auswertungsseiten.htm) for the device list, then a new heading is generated for every [higher-level function](Glossary_o_anlage.htm), containing (e.g.) the higher-level function name. The data between the headings is still sorted by [mounting location](Glossary_o_einbauort.htm) and DT.

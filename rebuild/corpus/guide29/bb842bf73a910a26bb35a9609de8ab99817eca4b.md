# Specifics of DT adoption

Basically, a function can adopt its DT from other [functions](Glossary_o_funktionen.htm) as follows:

| Function | General function | Terminal | Pin | Black box | Device connection point | Cable definition / shield |
| --- | --- | --- | --- | --- | --- | --- |
| General function | X | X | X | X | X |  |
| Terminal | X | X | X | X | X |  |
| Pin | X | X | X | X | X |  |
| Black box | X | X | X | X | X |  |
| Device connection point | X | X | X | X | X |  |
| Cable definition / shield |  |  |  |  |  |  |

The following functions are not taken into consideration for DT adoption or for adoption of [connection point designations](Glossary_o_anschlussbezeichnungen.htm):

- Structure boxes
- Terminal strip definitions
- Plug definitions
- Cable [connections](Glossary_o_verbindungen.htm)
- Connection definition points
- Interruption points
- Connection [symbols](Glossary_o_symbole.htm) (angles, T-nodes, etc.).

#### Black boxes

Functions in [black boxes](Glossary_o_geraetekaesten.htm) adopt their DT from the box, but not from functions outside the box. Functions outside the box can adopt the DT of functions within the box.

Terminals and [pins](Glossary_o_steckerkontakte.htm) can adopt their DT from black boxes and symbols in black boxes.

If symbols without their own DT are placed inside a black box, they adopt the DT of the box, even if no entry was actually made on the symbols. This means that an item without a DT, even in a black box, adopts the DT of the item lying in the search direction. If there is no item inside the box at the same height, then it inherits the DT from the box. If two black boxes with symbols lie at the same height, then the symbols in the second black box are not connected to the symbols placed in the first black box.

#### Structure boxes

Functions in [structure boxes](Glossary_o_strukturkaesten.htm) adopt their DT from the box, but not from functions outside the box. Functions outside the box can adopt the DT of functions within the box.

#### PLC connection points

For [PLC connection points](Glossary_o_sps_anschluesse.htm), the search direction is not only used to adopt the DT, but also to adopt the pin designation from another PLC connection point.

For overview pages, independent of the orientation of the plot frame, the search always proceeds upwards by default. Searching to the left can be forced by toggling the search direction directly on the PLC connection point.

# P026058: Number of connections at the connection point <x> is larger than specified in the connection point pattern

### Cause

For the connection point <x> of a [part](Glossary_o_artikel.htm) placement, the number of [routing connections](Glossary_o_verlegeverbindungen.htm) that can be wired to the connection point has been set in the connection point pattern, in the Max. number of [wires](Glossary_o_draehte.htm) column. However the actual number of routed wires connected to this connection point is higher than specified.

### Solution

#### Possibility 1

1. Check the target [wiring](Glossary_o_verdrahtungen.htm) in the multi-line schematic, meaning the use of the [connection symbols](Glossary_o_verbindungssymbole.htm) (T-nodes, angles, etc.), and correct it if necessary.
2. Then start a new check run.

#### Possibility 2

1. Increase for the connection point concerned in the connection point pattern the value in the Max. number of wires column. Specify at least the number of the actually routed wires connected to the connection point.
2. Then start a new check run.

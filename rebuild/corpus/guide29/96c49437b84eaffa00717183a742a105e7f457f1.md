# Backing up Projects

Projects can be backed up from the page navigator and from the project management.

### [ClosedBack up projects from the page navigator](javascript:void(0);)

Precondition:

You have selected a project in the page navigator.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project > Back up > Project
2. In the [Back up projects](bakbackupdlggui_d_projektesichern.htm) dialog, define the [settings](Glossary_o_einstellungen.htm) for the backup.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project is backed up to the specified directory or e-mailed, according to the entries you have made.

![](../Pictures/Gui/ALL/note.png) Note:

EPLAN notes these settings for each project and offers them again during later backups.

### [ClosedBack up projects from the project management](javascript:void(0);)

Preconditions:

- You have set up the project management.
- In the tree structure of project management there is an imported directory with at least one project.

1. Select the following menu items: Project > Management
2. Select the desired [projects](Glossary_o_projekte.htm) from the tree structure in the Project management dialog.
3. Select the Back up popup menu item.
4. In the [Back up projects](bakbackupdlggui_d_projektesichern.htm) dialog, define the settings for the backup.
5. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The projects are compressed one after another, and backed up to the specified directory (or e-mailed).

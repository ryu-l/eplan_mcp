# Grouping 3D Objects in the Layout Space

If you want to edit multiple 3D [objects](Glossary_o_objekte.htm) together in a [layout space](Glossary_o_bauraum.htm) (duplicate, copy, move, cut, delete) you can now, after marking, combine these 3D objects to a group with the menu [items](Glossary_o_bauteile.htm) Edit > Other > Group. You can subsequently undo the grouping again with Edit > Other > Ungroup.

# Tab File

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Utilities > Manufacturing data > Export / labeling. Click [...] next to the Settings field in the dialog Export manufacturing data / output labeling. In the dialog Settings: Manufacturing data export / labeling select the File tab.
- Options > Settings > User > Interfaces > Manufacturing data export / labeling. In the dialog Settings: Manufacturing data export / labeling select the File tab.

In this tab you can specify the [settings](Glossary_o_einstellungen.htm) for the file [formats](Glossary_o_formate.htm) in which the export / labeling file can be output.

Overview of the main dialog elements:

File type:

This field contains the file type in which the data are output.

- Text file (\*.txt): The data are output as a txt file.
- Excel file (\*.xls, \*.xlsx, \*.xlsm, \*.xlsb): The data are output as an MS Excel file in the following format:  
  \*.xls: Format for Microsoft Excel 97 - 2003   
  \*.xlsx: Format for Microsoft Excel 2007 / 2010 without [macros](Glossary_o_makros.htm)  
  \*.xlsm: Format for Microsoft Excel 2007 / 2010 with macros   
  \*.xlsb: Binary format for Microsoft Excel 2007 / 2010.   
  In the Template field, you can specify an Excel [form](Glossary_o_verlauf.htm).
- XML file (\*.xml): The data are output as an xml file.

Target file:

Enter the file path for the storage location and the file name of the export / labeling file.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).

Template:

If you have selected an Excel file as the export / labeling file in the File type field , enter an [Excel form as a template](labelgui_k_excelexportvorlagen.htm) in this field. The data are output in this form.

[Options]:

Depending on the file type selected, use this button to open the dialog Settings: Text export or the dialog Settings: Excel export.

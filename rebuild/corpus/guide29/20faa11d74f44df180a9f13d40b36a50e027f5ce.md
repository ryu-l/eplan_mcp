# Importing the PDF Comments into the EPLAN Project

An EPLAN project that you have issued as a PDF file and which has been commented in Acrobat Reader 8.0 can be imported into an EPLAN project in order to read the PDF [comments](Glossary_o_kommentare.htm) in EPLAN. When importing, the associated EPLAN project must be located in the same directory as when the PDF file was generated.

Preconditions:

- You are a [Project editor](redlining_k_projektkommentator.htm#Projektbearbeiter).
- [Output pages as PDF files](pdfexportgui_h_seitenexportieren.htm)
- [Send PDF file for checking](redlining_h_permailversenden.htm) or [Release PDF file for commenting](redlining_h_freigabe.htm)
- You have received a PDF file containing PDF comments from a project redliner.
- [Combine the PDF comments in the PDF files](redlining_h_zusammenfuehren.htm)

1. Project > Open
2. Select the EPLAN project that you issued for commenting as a PDF file and click [Open].
3. Select the menu item Page > Import > PDF comments.
4. In the subsequent dialog, select the directory containing the associated PDF file with the PDF comments and click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The PDF comments are imported into the EPLAN project.  
     
   ![](../Pictures/Gui/ALL/arrow.png) You can now [Read the imported PDF comments in EPLAN](redlining_h_projektkommentarebearbeiten.htm).

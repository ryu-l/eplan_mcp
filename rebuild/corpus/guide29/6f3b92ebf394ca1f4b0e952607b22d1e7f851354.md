# P004013: Rack '<x>': Ring connection

### Cause

The [rack](Glossary_o_baugruppentraeger.htm) name and the specification of the rack name for the PLC card slot reference one another for two different [PLC boxes](Glossary_o_sps_kaesten.htm).

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

For the first PLC box, the Rack field contains the designation BGT1 and the PLC card is placed on rack [ID](Glossary_o_id.htm) field contains the designation BGT2. For the second PLC box, the Rack field contains the designation BGT2 and the PLC card is placed on rack ID field contains the designation BGT1.

### Solution

1. Change the PLC structure data in the Properties <...> dialog for both PLC boxes so that the rack names do not link up.
2. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

This check run only checks PLC boxes at which a configuration project is entered.

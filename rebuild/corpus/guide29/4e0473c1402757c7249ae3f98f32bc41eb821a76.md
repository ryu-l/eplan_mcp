# Net-based Connections

The order in which components are connected in EPLAN is defined by default as soon as the [connections](Glossary_o_verbindungen.htm) are drawn. This is done through the choice of the appropriate connection symbol, in which the logic model for the target specification is stored.

Net-based connections enable a schematic to be created without having to define immediately how the connections are arranged. EPLAN notes the internal flow of the connections, irrespective of how they are graphically represented in the schematic.

The following is possible:

- Working methods employing both target specification and [net-based connections](Glossary_o_netzbasierteverbindungen.htm) can be mixed within a project.
- A mixture of connections with target specification and net-based connections can also occur within a net.
- In net-based connections, [connection symbols](Glossary_o_verbindungssymbole.htm) are always drawn as [connection points](Glossary_o_anschluesse.htm).
- Net-based connections are defined using a net definition point. Which connection points of the net are connected to each other is stored in the net definition point.
- The connections and their order can be retrospectively edited without having to modify the drawing.
- Net-based connections can be automatically designated in the same way as normal connections using [connection numbering](Glossary_o_verbindungsnummerierung.htm).
- Interruption points enable net-based connections to be continued on different pages.
- The connection [properties](Glossary_o_eigenschaften.htm) of net-based connections can also be modified using "external editing". The connection itself cannot be modified using "external editing".
- Cable definition [lines](Glossary_o_leitungen.htm) cannot be used for net-based connections. The connections under a [cable](Glossary_o_kabel.htm) definition line are not recognized as [cable connections](Glossary_o_kabelverbindungen.htm) in a net with net-based connections.

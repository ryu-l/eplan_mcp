# Deleting Stored Parts Properties

You can delete selected [properties](Glossary_o_eigenschaften.htm) from the parts stored in the project. For instance, before providing the project to an end customer, you can remove the price information.

Precondition:

You highlighted a project or individual pages in the page navigator, or you highlighted components in the graphical editor.

1. Select the following menu [items](Glossary_o_bauteile.htm): Utilities > Parts > Delete stored properties
2. Select a scheme from the Settings drop-down list in the dialog Delete stored part properties or click [...] to open the subsequent dialog of the same name in which you can manage and edit the [schemes](Glossary_o_schemata.htm).
3. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) and select the [part](Glossary_o_artikel.htm) properties to be deleted in the dialog Property selection. Multiple selection is possible.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected part properties are deleted from the project.

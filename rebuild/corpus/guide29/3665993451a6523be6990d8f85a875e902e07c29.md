# Moving Elements into the Foreground / Background

You can use the two commands Bring to front and Send to back to influence the order of elements on the screen and the order of access. For instance, if multiple elements are on top of one another, then normally the element added last is on top.

Precondition:

You have opened a page, [form](Glossary_o_verlauf.htm), plot frame or symbol.

1. Select an element and choose the menu item Edit > Other > Bring to front, or Edit > Other > Send to back.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The element will now be shown as the topmost or bottommost element of the stack.

If you edit one of the elements you have moved to the back, use the menu item View > Redraw to reactivate the defined front/back [properties](Glossary_o_eigenschaften.htm).

# Block Properties: Principle

For every block property there is an associated format property. The two [properties](Glossary_o_eigenschaften.htm) Block property [n] and Block property: Format [n] represent a single unit. The format property determines which properties are compiled in the block property. The associated block property shows the result in the graphical editor or in [reports](Glossary_o_auswertungen.htm).

The [block properties](Glossary_o_blockeigenschaften.htm) and the associated format properties are indexed. The common index represents associated block and format properties.

Block property: Format [1] determines the format.

Block property [1] displays the result.

Block properties are not multilingual. The result is always a simple character string. The language in which the individual nested properties are written in the result, can be individually specified for each property. If "all [display languages](Glossary_o_anzeigesprachen.htm)" are selected for a property, all specified display languages are written in the result one after another with a line break.

Block properties are automatically updated if they are displayed or queried. Nesting is possible at [indirect properties](Glossary_o_indirekteeigenschaften.htm): If a block property refers to another block property, the second is updated first, if the first is not up-to-date.

Block properties are placed on a separate layer. You can thus show block properties in a special color and - if you are only using the block properties for indirect properties - you can see from the color in the schematic that the information displayed cannot be edited on this object.

### Indirect properties

Indirect properties are used to access properties of [objects](Glossary_o_objekte.htm) that are connected to the object to be displayed. This is possible via the block properties.

The following other objects are connected to one object:

- The project in which the object is located
- The page on which the object is placed
- Objects connected to this object through other [connections](Glossary_o_verbindungen.htm)
- Connections and cables connected to the object
- Main function data
- Parts entered for the object.

Indirect properties can be selected in the format property by navigating using the ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level) and ![](../Pictures/Gui/ALL/all_stairdown_as.png) (Previous level) buttons.

### Determining automatic function texts via a block property

You have the possibility to [create](Glossary_o_erstellen.htm) an automatic function text with different properties and separators by using a block property at the [functions](Glossary_o_funktionen.htm) in the graphical editor. To this purpose the property Block property: Format (function text, automatic) ([ID](Glossary_o_id.htm) 20545) is available on the first tab in the [property dialog](Glossary_o_eigenschaftendialog.htm) for the properties table.

As usual with the format properties you use the subsequent dialog Format to specify the properties and separators that are summarized in the block property. The new format element "Path function text" is available in this dialog for the functions. By using the interface ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level) you can access the associated path function text and select it as the format element for the automatic function text.

The display of this function text defined by using the block property in the graphical editor is carried out via the placed property Function text (automatic). If a manual function text was entered at a function additionally, the Function text (automatic) property displays this text.

The new check run message 007033 is available in the message class 007 "Devices" in order to find such functions in a project, at which the function text was both entered manually and defined via the block property.

# Dialog Settings: DXF / DWG export and import

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Page > Export > DXF / DWG. Next to the Scheme field, click [...].
- Options > Settings > User > Interfaces > DXF / DWG export and import.

In this dialog specify the [settings](Glossary_o_einstellungen.htm) for [DXF](Glossary_o_dxf.htm) / [DWG](Glossary_o_dwg.htm) file imports and exports and save them as a scheme.

The settings in the Layers, Colors, Font and Line types tabs apply to exports and imports. Special settings such as the output or initial directory, which only affect import or export, can be specified in the Export and Import tabs. The data in the Block Definition and Block Attribute tabs is only evaluated on export.

The following dialog elements are available:

Scheme:

Select a scheme to define the settings from the drop-down list.

You can [create](Glossary_o_erstellen.htm) new [schemes](Glossary_o_schemata.htm), save any changes to a scheme, and copy or delete schemes via the adjacent [Toolbar](schemeconfig_m_schemaschaltflaechen.htm). Schemes can also be imported or exported.

Description:

This field displays the descriptive text that you entered into the Description field in the New scheme dialog when you created the scheme.

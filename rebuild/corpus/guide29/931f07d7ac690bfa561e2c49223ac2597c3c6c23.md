# Dialog Properties (special text): Form properties / Properties (special text): Plot frame properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Master data > Plot frame / Form > Open > [Open].

- Insert > Special text > Form properties (in open [forms](Glossary_o_formulare.htm)) or Insert > Special text > Plot frame properties (in open [plot frames](Glossary_o_normblaetter.htm)).
- You have double-clicked a [form](Glossary_o_verlauf.htm) / plot frame property (or selected the  Properties popup menu. In this case several [properties](Glossary_o_eigenschaften.htm) can be selected).

In this dialog, you can select the form / plot frame property that should be inserted into the form / plot frame, and specify its format, language, and frame properties.   
Only the properties permissible for the respective form / plot frame type are available for selection.

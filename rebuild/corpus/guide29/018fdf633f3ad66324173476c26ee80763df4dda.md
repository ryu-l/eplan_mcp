# Defining Cables and Cable Connections Manually

To manually define cables, draw [cable definition lines](Glossary_o_kabeldefinitionslinien.htm) and [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) and then specify the [cable properties](Glossary_o_kabeleigenschaften.htm). Only one [cable](Glossary_o_kabel.htm) definition line is required for each cable DT (more are possible). Any additional [connections](Glossary_o_verbindungen.htm) can be assigned to the cable using connection definition points.

You can display cables in a distributed [form](Glossary_o_verlauf.htm) by drawing multiple cable definition [lines](Glossary_o_leitungen.htm) and assigning them the same cable DT.

Cable connections can be defined either on the connection definition point or on the connection point of a function. The setting on the connection definition point has priority over the [settings](Glossary_o_einstellungen.htm) on the [connection points](Glossary_o_anschluesse.htm).

### Define cable connections on connection definition points

Individual connections can be assigned to a cable by [placing](Glossary_o_auflegen.htm) connection definition points and assigning the cable DT to them:

1. Select the Insert > Connection definition point menu [items](Glossary_o_bauteile.htm).
2. Place the connection definition point on a connection.
3. In the Displayed DT field of the Connection definition point tab in the Properties <...> dialog, specify the DT of the cable to which you want to assign the connection.
4. Mark the Connection: Association property in the table and select the "Cable" value from the drop-down list.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The cable connection is assigned to the cable.

### Define cable connections on connection points

1. Select a [component](Glossary_o_schaltzeichen.htm) in the graphical editor and then select the Edit > Properties menu items.
2. In the Properties <...> dialog, select the Symbol / function data tab and click [Logic].
3. In the Connection point logic dialog select the Cable connection point check box for the desired connection points.
4. You can also change the Connection point type, the Potential type, and other [properties](Glossary_o_eigenschaften.htm) of the connection point.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection point data is stored to the function.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connections attached to the function get the properties from the respective connection point and thus become [cable connections](Glossary_o_kabelverbindungen.htm).

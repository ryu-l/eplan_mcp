# Improvements When Sorting Into the Existing Structure

When inserting [macros](Glossary_o_makros.htm) or copies into a [P&I diagram](Glossary_o_ri_fliessbild.htm) you can use the Select structure dialog to integrate [PCT loops](Glossary_o_plt_stellen.htm), [PCT loop functions](Glossary_o_plt_stellenfunktionen.htm), [planning objects](Glossary_o_planungsobjekte.htm) etc. that are contained in the macro / copy into the existing structure of the pre-planning. In the current version the selection in this dialog has been simplified and improved at several points:

- Simplified assignment of segments:
    
  To assign identical [segments](Glossary_o_segmente.htm) in the source and project to each other during selection of the structure you previously had to assign the segments individually. In the new version you can now also assign structures with several existing segments. To do so mark the respective node of an existing structure segment in the fields Source and Project, and click the button ![](../Pictures/Gui/ALL/all_assign_as.png) (Assign).
- Improved user interface:
    
  New status [icons](Glossary_o_icons.htm) then indicate in the Project field whether a segment already existed in a project (icon ![](../Pictures/Gui/ALL/all_statusok_as.png)) or whether it is a new segment (icon ![](../Pictures/Gui/ALL/all_statusnew_as.png)).
- Uniform numbering setting:   
  The numbering setting in the dialog has been harmonized and now affects all segments in the source in the same way. As [part](Glossary_o_artikel.htm) of this extension the associated check box in Number segments has been renamed.   
  If this check box is activated, the device tags and [designations](Glossary_o_bezeichnungen.htm) of the segments are numbered in accordance with the numbering [settings](Glossary_o_einstellungen.htm) in the configuration of the [segment definitions](Glossary_o_segmentdefinitionen.htm).

![](../Pictures/Gui/ALL/benefit.png)Benefit:

When inserting macros or copies into a P&I diagram the segments already existing in a project can be assigned quicker, the tedious individual selection is superfluous.

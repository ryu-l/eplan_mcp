# Containers and Container Connection Points in the P&I Diagram

Containers and [container](Glossary_o_behaelter.htm) [connections](Glossary_o_verbindungen.htm) can be placed in a [P&I diagram](Glossary_o_ri_fliessbild.htm). To this purpose the program contains the menu [items](Glossary_o_bauteile.htm) Insert > Box / connection point / mounting panel > Container and ... > Container connection point.

### Containers

A container can be represented in a P&I diagram using a fixed, non-scalable symbol or a special box. Container [symbols](Glossary_o_symbole.htm) are located in the Special.slk symbol library.

You can rapidly select the symbol for drawing a container by selecting the respective menu Insert > Box / connection point / mounting panel > Container and subsequently pressing the [Backspace]. In the Symbol selection dialog the symbols are already filtered and only symbols with the same function category are displayed.

### Container connection points

Containers can be enhanced with container [connection points](Glossary_o_anschluesse.htm) (flanges). When container connection points are placed in a container box, they are regarded as belonging when their insertion point lies within the enclosing rectangle. The connection point type "Process engineering" is set by default in the connection point logic for container connection points.

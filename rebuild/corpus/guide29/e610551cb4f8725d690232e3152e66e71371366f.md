# Tab Connection graphic

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have selected a connection definition point, a potential definition point, a potential connection point or a net definition point in the graphical editor. Edit > Properties. In the Properties <...> dialog, select the Connection graphic tab.
- Project data > Connections > Navigator. Highlight a connection and select the Properties popup menu item. In the Properties <...> dialog, select the Connection graphic tab.

You can edit the graphical [properties](Glossary_o_eigenschaften.htm) of [connections](Glossary_o_verbindungen.htm) on this tab.

Overview of the main dialog elements:

Property / Assignment:

The hierarchy level Format is available in the table. This can be opened by clicking the ![](../Pictures/Gui/ALL/all_plussign_as.png) sign.

Layer:

The layer of the connection is automatically determined from the connection's function definition and the Pressure / Control port setting (in the [connection point logic](xfctdefbrowsergui_d_anschlusslogik.htm) of the [functions](Glossary_o_funktionen.htm) attached to the connection).

By default, no layer is entered for [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm), [potential definition points](Glossary_o_potenzialdefinitionspunkte.htm), [potential connection points](Glossary_o_potenzialanschluesse.htm) and [net definition points](Glossary_o_netzdefinitionspunkte.htm), i.e., the layer automatically determined for the connection is used.

If you need to, select another layer from the drop-down list. The layer defined here also defines the [settings](Glossary_o_einstellungen.htm) for line thickness, line type, etc.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The following properties in the connection point logic are defined for an electrical connection:  
Connection point type: Conductor / wire  
Pressure / control port: Undefined  
The connection then lies on the layer EPLAN311, Symbol graphic.Connection symbols.Autoconnecting.

The following properties in the connection point logic are defined for a [fluid power](Glossary_o_fluidtechnik.htm) connection:  
Connection point type: Fluid power  
Pressure / control port: Pressure line  
The connection then lies on the layer EPLAN507, Symbol graphic.Connection symbols.Autoconnecting.Pressure lines.

# P017010: Overlapping structure boxes contain contradictory structure identifiers

### Cause

In a project in which the [product aspect](Glossary_o_produktkennzeichen.htm) is used for structuring, there are two overlapping [structure boxes](Glossary_o_strukturkaesten.htm) containing different [structure identifiers](Glossary_o_strukturkennzeichen.htm) with regard to one or several [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm).

![](../Pictures/Visualisation/ALL/messages_017010_bsp1_av.png)

The structure box with identifier +O1 overlaps with the structure box which is characterized by =A1+E1. With regard to the device -F1, the structure identifiers are contradictory for the identifier block "[mounting location](Glossary_o_einbauort.htm)" (O1 and E1).

### Solution

#### Possibility 1

1. Locate the first overlapping structure box in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the Properties <...> dialog of the structure box, and bring to front the Identifier tab.
3. Adjust the structure identifier for the respective identifier block to the identifier structure of the second structure box and confirm with [OK].
4. Then start a new check run.

#### Possibility 2

1. Locate the second overlapping structure box in the schematic using the Go to 2nd coordinate function from the popup menu in the Message management dialog.
2. Open the Properties <...> dialog of the structure box, and bring to front the Identifier tab.
3. Adjust the structure identifier for the respective identifier block to the identifier structure of the first structure box and confirm with [OK].
4. Then start a new check run.

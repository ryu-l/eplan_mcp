# Dialog Messages

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have selected several [PLC connection points](Glossary_o_sps_anschluesse.htm) in the graphical editor, the PLC navigator, or in the device navigator. Or you have selected one or more pages or a project in the page navigator. Project data > PLC > Generate schematic. In the Generate PLC schematic dialog, you have selected the rows with the [devices](Glossary_o_betriebsmittel.htm) for which errors are to be displayed in the Status column. Select the Show messages popup menu item.

This dialog shows the errors that occurred when assigning [macros](Glossary_o_makros.htm) to the PLC [functions](Glossary_o_funktionen.htm).

Overview of the main dialog elements:

The following columns are displayed in the table:

- Object: This shows the DT of the PLC function that caused an error in the macro assignment.
- Representation type: This shows the representation type where an error occurred.
- Message text: This describes the error in more detail.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

If (e.g.) the multi-line representation macro variant for a PLC box is missing, then the following information is displayed in the table:

Object: =EB3+EB1-A1  
Representation type: Multi-line  
Message text: The "Multi-line" representation type does not exist in the macro.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

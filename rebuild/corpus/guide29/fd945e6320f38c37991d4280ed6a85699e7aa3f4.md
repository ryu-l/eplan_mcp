# Updating Data of Placeholder Objects at Segments

If you have changed the data of [placeholder objects](Glossary_o_platzhalterobjekte.htm) in [macros](Glossary_o_makros.htm) that are stored at [planning objects](Glossary_o_planungsobjekte.htm) or [PCT loops](Glossary_o_plt_stellen.htm) in the Macro tab, you previously had to individually open each segment with this assigned macro and update the data. The new popup menu item Update placeholder data is now available in the pre-planning navigator so that this update can also be performed simultaneously for several [segments](Glossary_o_segmente.htm).

In order to simultaneously update the placeholder data from the macros for several [segment templates](Glossary_o_segmentvorlagen.htm) as well, the segment template navigator has also been extended with the popup menu item Update placeholder data.

If a schematic page was already generated by means of a macro and the updated data is to be transferred from the segment to the detailed planning, you must then also update the detailed planning.

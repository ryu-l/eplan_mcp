# Functions and Numbering

During [online numbering](Glossary_o_onlinenummerieren.htm) [devices](Glossary_o_betriebsmittel.htm) are automatically numbered when they are inserted into the schematic.

| Function | Effects on the online numbering |
| --- | --- |
| Functions inserted into the schematic | These [functions](Glossary_o_funktionen.htm) are numbered online. |
| Placed functions | The numbering of these functions remains unchanged. |
| Functions unplaced in the schematic | These functions exist in the [projects](Glossary_o_projekte.htm) and are accounted for when numbering. |
| Connected functions | These functions remain connected. |
| Free functions (only exist through parts) | If the project contains free functions that previously only existed through parts, then when numbering, the numbering designator of these functions has the highest allocation priority. |

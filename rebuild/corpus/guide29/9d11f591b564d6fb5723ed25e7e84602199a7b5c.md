# Display Properties: Rectangle / Shield

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a page, [form](Glossary_o_verlauf.htm), plot frame, or symbol. You have marked a rectangle and selected the menu [items](Glossary_o_bauteile.htm) Edit > Properties, or you have double-clicked a rectangle. In the table of the Properties (Rectangle) dialog, expand the hierarchy level Rectangle.
- You have opened a project and are viewing a page in the graphical editor. You have inserted a rectangular structure, black, or PLC box, etc., or double-clicked a box. In the Properties <...> dialog select the Format tab and, in the table, expand the Rectangle hierarchy level.
- You have opened a project and are in the graphical editor on a "Panel layout" page. You have inserted a mounting panel or double-clicked on a mounting panel. In the Properties <...> dialog select the Format tab and, in the table, expand the Rectangle hierarchy level.
- You have opened a project and are viewing a page in the graphical editor. You have inserted a shield or double-clicked on a shield. In the Properties <...> dialog select the Format tab and, in the table, expand the Shield hierarchy level.

Below this hierarchy level, you can edit the specific [settings](Glossary_o_einstellungen.htm) of rectangles, [mounting panels](Glossary_o_montageplatten.htm), rectangular structure, black, or [PLC boxes](Glossary_o_sps_kaesten.htm), [shields](Glossary_o_abschirmungen.htm), etc.

Overview of the main dialog elements:

Starting point / End point:

In the fields below these hierarchy [levels](Glossary_o_etagen.htm), the coordinates of the starting and end points of the rectangle are displayed. The direction in which the rectangle was opened is considered here.

Angle:

Enter an angle in order to rotate the rectangle relative to the X axis. The field is only available for "free rectangles", that is, not for rectangles representing mounting panels or structure, black, PLC boxes, etc.

# Templates and Defining Rotation / Flipping (Changing Standards)

Use a template to adjust [designations](Glossary_o_bezeichnungen.htm) and names to the target standard. The setting for rotation / flipping specifies, in combination with the selected [symbol libraries](Glossary_o_symbolbibliotheken.htm), the location of the schematic elements in the schematic.

Preconditions:

- You have opened a project.
- In the case of several opened [projects](Glossary_o_projekte.htm): You have selected a project in the page navigator.
- You have a template containing country- or standards-specific [settings](Glossary_o_einstellungen.htm).
- You have set up a target project.

1. Utilities > Change of standard
2. To specify a template for the target project, use [...] on the Rotation / Flipping tab to select a project template \*.ept.
3. From the Rotation / flipping drop-down list, select the way in which you want to rotate and flip.
4. Click [Next].

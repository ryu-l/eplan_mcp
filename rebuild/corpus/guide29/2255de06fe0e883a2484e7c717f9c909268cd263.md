# Project Templates

Project templates are templates from which you can [create](Glossary_o_erstellen.htm) new [projects](Glossary_o_projekte.htm). When doing this, all data of the project template is adopted in the new project.

| File type | Meaning |
| --- | --- |
| EPLAN project template (\*.ept) | Project template / \*.ept file: You can create new projects from an \*.ept file and save EPLAN projects as \*.ept files. |
| EPLAN project template (\*.epb) | Project template / \*.epb file: You can still create new projects from an \*.epb file. However, it is no longer possible to create an \*.epb file from EPLAN projects. Use the \*.ept file or the \*.zw9 file for this. |

A project template can contain the following project [settings](Glossary_o_einstellungen.htm) and [project data](Glossary_o_projektdaten.htm).

- All project settings: Project settings are the settings under Options > Settings > Projects > "Project name". This includes the [schemes](Glossary_o_schemata.htm) for pages and device structure.
- All project data: Project data are for example unplaced [devices](Glossary_o_betriebsmittel.htm) and devices placed on pages.
- All pages: All pages in the project template are adopted in the new project.

![](../Pictures/Gui/ALL/info.png)Tip:

If you wish to create a project template with no pages from a project that contains pages, then first copy your project. Then delete the pages from the project copy and use this to create the project template.

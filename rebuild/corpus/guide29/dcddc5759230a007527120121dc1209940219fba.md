# Display Properties: Arc / Sector / Circle

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a page, [form](Glossary_o_verlauf.htm), plot frame, or symbol. You have marked a circle, an arc, or a sector and selected the menu item Edit > Properties. Or you have double-clicked on a circle, arc, or sector. In the table of the Properties (Arc / Sector / Circle) dialog, expand the hierarchy level Arc / Sector / Circle.

Below this hierarchy level you can edit the specific [settings](Glossary_o_einstellungen.htm) of circles, arcs, and sectors.

The following dialog elements are available:

Center:

In the fields below this hierarchy level, the coordinates of the circle's center are displayed and can be modified.

Sector:

This check box is selected if you have drawn a sector. Check it later to change an arc into a sector, or deactivate it in order to change a sector to an arc.

Starting angle:

The angle displayed here specifies the starting point of the arc or sector relative to the X axis, and it can be altered.

End angle:

The angle displayed here specifies the end point of the arc or sector relative to the X axis, and it can be altered.

Radius:

The circle's radius is displayed here and can be altered.

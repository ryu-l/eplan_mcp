# Extended Language Selection for One Language Variable Texts

In the project-specific translation [settings](Glossary_o_einstellungen.htm) you specify the displayed language for translated project texts to which you have assigned the property "One language (variable)" in the One language (variable) field. In the drop-down list of this field new entries are now available for the displayed language, such as "Displayed language 1", "Displayed language 2", etc. (The menu path for the corresponding settings dialog is Options > Settings > Projects > "Project name" > Translation > General.)

![](../Pictures/Gui/ALL/benefit.png)Benefit:

The new entries in the language selection ("Displayed language 1", "Displayed language 2", etc.) make it is possible to always display one language variable texts in the current displayed language even if it is changed in the translation settings.

During the selection of such an entry the texts of the property are displayed in the language that is specified as the first, second, etc. displayed language. Depending on the settings for the number of displayed languages up to five entries are possible here.

# Simpler Editing of Macro Directories in the Macro Navigator

The List view of the macro navigator has been extended to make it more easy to individually edit the macro names and directories of [macros](Glossary_o_makros.htm) in [macro projects](Glossary_o_makroprojekte.htm). In addition to the Macro: File name property, the property Macro: Directory ([ID](Glossary_o_id.htm) 23015) is now also available. So that you can change the macro name independently of the macro directory, the property Macro: Name (ID 23009) has also been made editable for the list view.

For direct editing in the added column Macro: Directory, press the [F2] key in the respective spreadsheet cell. With copying and pasting you can then transfer a changed directory to multiple marked directories.

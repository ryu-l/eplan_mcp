# Dialog Settings: API part selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Options > Settings > User > Management > Part selection. In the dialog Settings: Part selection dialog select a [user-defined](Glossary_o_benutzerdefiniert.htm) template from the drop-down list. Select the API option and click [...].
- You have selected a main function in the graphical editor or in a navigator. Edit > Properties. You clicked [...] in the Parts tab next to the Data source field. In the dialog Settings: Part selection (user) dialog, click on a user-defined template from the drop-down list. Select the API option and click [...].

In this dialog you determine which parts [properties](Glossary_o_eigenschaften.htm) to [load](Glossary_o_laden.htm) with the API interface.

Selecting parts via API is a purely functional interface. How the selection option is structured and how the selection dialog appears depends on the implementation of the corresponding API program.

Overview of the main dialog elements:

Name of the action:

Enter the action to be started when you select a [part](Glossary_o_artikel.htm) with the API interface. This action is prepared with an API program.

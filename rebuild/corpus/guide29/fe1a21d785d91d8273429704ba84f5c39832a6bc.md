# Automatically Numbering Devices in Macros / Copies

Macros are reusable schematic sections which can contain [devices](Glossary_o_betriebsmittel.htm) / [functions](Glossary_o_funktionen.htm). Copied or cut schematic elements can also contain devices / functions. Devices / functions that you insert into the schematic pages in this way can be automatically numbered on insertion. A DT is determined and automatically assigned online for every device / function that you insert. The counter for DT is incremented by one in the process.

![](../Pictures/Gui/ALL/note.png)Note:

Only the device groups that you have selected in the [online numbering](Glossary_o_onlinenummerieren.htm) format are numbered.

Preconditions:

- You have opened a project.
- You have opened a schematic page.
- You have access to a macro, or you have copied a schematic section containing devices / functions to the clipboard.

### Specify numbering behavior before insertion

1. Options > Settings > Projects > "Project name" > Devices > Numbering (online)
2. In the On insertion of macros and copies group box, select the Number option.
3. If you want to [create](Glossary_o_erstellen.htm) or edit an online numbering format, click [...] next to the Numbering format field.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The Numbering formats dialog opens. Here you can define an [Online numbering format](numerationgui_h_onlineformat.htm). Click [OK].
4. If you want to use an existing online numbering format, select an online numbering format from the Numbering format drop-down list in the On insertion of macros and copies group box.
5. Click [OK].
6. To insert your copy into the schematic page from the clipboard, select the menu [items](Glossary_o_bauteile.htm) Edit > Insert.
7. To insert a macro, select the menu items Insert > Window macro / symbol macro, select a macro from the dialog that opens, and click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The copy / macro hangs on the cursor.
8. Move the cursor to the desired location on the schematic page.
9. Click the page to place the copy / macro.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The device / function is automatically numbered.
10. Select the menu items Edit > Cancel action.

### Specify numbering behavior on insertion

If you activate the numbering behavior prompt in the global [settings](Glossary_o_einstellungen.htm), you can specify a different numbering behavior for devices in [macros](Glossary_o_makros.htm) or copies at each insertion.

1. Options > Settings > Projects > "Project name" > Devices > Numbering (online)
2. In the On insertion of macros and copies group box, select the With prompt option and click [OK].
3. To insert your copy into the schematic page from the clipboard, select the menu items Edit > Insert.
4. To insert a macro, select the menu items Insert > Window macro / symbol macro, select a macro from the dialog that opens, and click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The copy / macro hangs on the cursor.
5. Move the cursor to the desired location on the schematic page.
6. Click the page to place the copy / macro.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Insertion mode dialog opens.
7. Select the Number option.
8. If you want to create or edit an online numbering format, click [...] next to the Numbering format field.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The Numbering formats dialog opens. Here you can define an [Online numbering format](numerationgui_h_onlineformat.htm). Click [OK].
9. If you want to use an existing online numbering format, select an online numbering format from the Numbering format drop-down list in the Insertion mode dialog.
10. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The device / function is automatically numbered.
11. Select the menu items Edit > Cancel action.

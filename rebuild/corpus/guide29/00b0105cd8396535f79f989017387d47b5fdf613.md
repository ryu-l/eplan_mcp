# Dynamic forms: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_dynamischeformulare.htm)

### Dynamic forms

User interface / operation

Form in which the graphics are changeable (e.g. the number of rows: only those are displayed which contain data, no empty ones), i.e., the graphics are adapted to the actual number of rows. In this kind of form, headers, data, and footers can also be determined within one page.

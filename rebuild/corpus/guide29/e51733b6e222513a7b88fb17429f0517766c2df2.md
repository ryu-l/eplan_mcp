# P013051: A maximum of 50 parts can be assigned to a device

### Cause

When importing the bill of materials, an attempt was made to assign more than 50 parts to a device tag.

![](../Pictures/Gui/ALL/note.png)Note:

In EPLAN a maximum of 50 parts can be assigned to a device. The [part](Glossary_o_artikel.htm) index defines the order in which the parts are entered in the Property <...> dialog on the Parts tab.

### Solution

Open the import file with a text or XML editor and delete the surplus parts. Save the file, then import the bill of materials again.

![](../Pictures/Gui/ALL/note.png) Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

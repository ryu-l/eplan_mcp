# Copper Rail: Changing the Length

Each side of a placed copper item can be shortened or extended subsequently. If a delivery length is entered on the rail [part](Glossary_o_artikel.htm) used, this will be taken into account in case of an extension, and the length change is possible only up to this value.

Preconditions:

- You have opened a project. A [layout space](Glossary_o_bauraum.htm) is open.
- The layout space contains placed [busbars (bending)](Glossary_o_sammelschienegebogen.htm).

1. Edit > Graphic > Change length
2. To modify the length of a leg on a bent copper rail, move the cursor over the item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Positions where the length can be modified are marked with arrows.
3. Select the green arrow at the position you wish to extend / shorten.
4. Move the end point of the selected leg, or enter a positive or negative length value on the keyboard.

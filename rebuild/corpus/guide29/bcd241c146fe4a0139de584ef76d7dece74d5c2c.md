# Wire Harnesses

EPLAN supports you in planning and managing [wire harnesses](Glossary_o_kabelbaeume.htm) and wire harness components. By using an import functionality you can import wire harnesses designed in EPLAN Harness proD and the associated components into EPLAN [projects](Glossary_o_projekte.htm), edit and report them there. You can subsequently export the wire harnesses and their components for renewed editing in EPLAN Harness proD.

The following is possible:

- You can import the wire harnesses designed with EPLAN Harness proD into a project of the EPLAN platform.
- You can [create](Glossary_o_erstellen.htm) wire harnesses with pre-defined [properties](Glossary_o_eigenschaften.htm) or insert them as [symbols](Glossary_o_symbole.htm) in the schematic.
- You can assign father [functions](Glossary_o_funktionen.htm), [connections](Glossary_o_verbindungen.htm) or parts to a wire harness or remove existing harnesses again.
- The parts entered at the wire harness definitions and wire harness components can be output into [reports](Glossary_o_auswertungen.htm) or be used for the manufacturing data export / labeling.
- You can export the wire harnesses for further editing into EPLAN Harness proD.

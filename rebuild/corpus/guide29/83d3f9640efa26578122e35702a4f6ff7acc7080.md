# P501032: The channel designation entered in the function templates of the part is invalid

### Cause

In the parts database to be checked a PLC [part](Glossary_o_artikel.htm) was found where an incorrect channel designation is entered.

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective part is already marked in it.
2. Bring the Function templates tab to the front.
3. Change the value or values entered in the column Channel designation at the [function definitions](Glossary_o_funktionsdefinitionen.htm) that represent [connection points](Glossary_o_anschluesse.htm) for signal, network, bus and / or supply connection points into purely numerical values. Ensure that no blank space is entered before or after the value. Also there may not be any blank space between two numeric values.
4. Click [OK].
5. Close the parts management, save the modified data, and carry out a parts synchronization.
6. Then start a new check run.

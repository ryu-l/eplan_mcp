# Aligning Elements Horizontally / Vertically

The Align (horizontally) and Align (vertically) commands allow you to position several selected elements on a horizontal or vertical line. This only works with elements that have a single insertion point. The line is formed from the midpoint of the two elements with the greatest distance between them.

![](../Pictures/Gui/ALL/note.png)Note:

Note that you must run the Align on grid function after performing this action in order to reposition the insertion points on the [grid](Glossary_o_raster.htm).

Precondition:

You have opened a page, [form](Glossary_o_verlauf.htm), plot frame or symbol.

1. Select the respective elements and choose the Edit > Other > Align (horizontally) or Edit > Other > Align (vertically) menu [items](Glossary_o_bauteile.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) EPLAN determines the midpoint of the two elements with the greatest distance between them and aligns all elements to this line.

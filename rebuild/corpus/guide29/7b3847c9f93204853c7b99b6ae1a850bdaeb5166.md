# Changing the Target Order of Net-Based Connections

The target order of [net-based connections](Glossary_o_netzbasierteverbindungen.htm) can be retrospectively changed in the Property dialog of the associated net definition point.

Preconditions:

- You have opened a project and are in a schematic page.
- You have inserted a net definition point.

1. Select the net definition point in the graphical editor and then select the menu item Edit > Properties.
2. In the Properties <...> dialog, select the Net connections tab.
3. Select a connection point in the Connection points table.
4. Select Popup menu > Change target order.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Change target order dialog shows all the targets of the connection point that are connected through net-based [connections](Glossary_o_verbindungen.htm).
5. Use the arrow buttons to move the targets to the required positions.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The changed target order is saved.

# Tab Placement (layout space)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. In the tree or list, you have selected an object belonging to the Accessory placement hierarchy level.

In this tab, you specify the placement point of the [items](Glossary_o_bauteile.htm) in the [layout space](Glossary_o_bauraum.htm) in relation to different base points.

Overview of the main dialog elements:

Base point:

Base points are fixed defined [mounting points](Glossary_o_montagepunkte.htm) in a layout space. A distinction is made between automatically generated base points, such as those available for the "Enclosure" product group, "Component" and "Body" product subgroups, and [user-defined](Glossary_o_benutzerdefiniert.htm) base points that are placed by the user in a macro manually and that possess predefined [properties](Glossary_o_eigenschaften.htm).

Can be moved:

Activate this check box if the [part](Glossary_o_artikel.htm) placed via this installation variant can be moved in the enclosure; deactivate the check box if the part is to be a fixed part of the enclosure. Depending on the setting, the Item is fastened unmovably to the superior item property is set.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# Copying Symbol Libraries

Precondition:

You have opened a project.

1. Select the following menu [items](Glossary_o_bauteile.htm): Utilities > Master data > Symbol library > Copy
2. In the Copy symbol library dialog select the file to be copied. Multiple selection is not possible.
3. Click [Open].
4. In the Create symbol library dialog select a drive and a directory where you would like to save the copied symbol library from the Save to drop-down list.
5. If necessary, overwrite the preset file name of the original with a name you can recognize.
6. Click [Save].
7. In the Symbol library properties - <Library name> dialog you assign (new) values to the desired [properties](Glossary_o_eigenschaften.htm) of the copied symbol library.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The copy of the symbol library is created, transferred to the list of opened [symbol libraries](Glossary_o_symbolbibliotheken.htm), and can be edited.

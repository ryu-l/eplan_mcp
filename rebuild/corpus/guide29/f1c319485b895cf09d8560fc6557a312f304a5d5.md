# Dialog Change of the property

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have opened a dynamic [form](Glossary_o_verlauf.htm) (via the Utilities > Master data > Form > Open > [Open] menu [items](Glossary_o_bauteile.htm), for example). Insert > Dynamic area > Conditional area. You have drawn the conditional area as a rectangle. Double-click in the rectangle and select the Conditions tab in the [properties](Glossary_o_eigenschaften.htm) dialog. In the If property is changed field, click [...].
- Utilities > Master data > Form > Open > [Open]. You have opened the Form properties - <Form name> dialog (Popup menu > Properties on the form in the Pages - <Project name> navigator dialog) and have clicked [...] in the Value field of Regenerate header after change property.

In this dialog, you select the properties for which the conditional area / data header area is reported when they are changed.

Overview of the main dialog elements:

Property:

Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the toolbar above the list to open the Property selection dialog and select the properties for which the area/data header area is reported when they are changed. For example, for a device tag list, you can specify that a thick line is drawn before the next DT, or a new main header is generated, each time the DT (displayed) property is changed.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Select all | Selects all of the properties in the table. |
| Adjust column width | Adjusts the width of all table columns so that both the headings and column contents are fully legible. |

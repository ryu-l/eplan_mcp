# Creating Your Own Connection Point Designations and Descriptions

For each function definition, ten sets of [connection designations](Glossary_o_verbindungsbezeichnungen.htm) and connection descriptions can be specified. These sets can then be selected later on from the function.

### Create connection point designations

1. Utilities > Master data > Connection point designation / description
2. Select the Connection point designations tab.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Connection point designations tab lists the [function definitions](Glossary_o_funktionsdefinitionen.htm) with their [connection points](Glossary_o_anschluesse.htm). One line is shown for each connection point.
3. In the fields 1 - 10, enter up to 10 different [connection point designations](Glossary_o_anschlussbezeichnungen.htm) per connection point.
4. Click [OK].

### Create connection point descriptions

1. Utilities > Master data > Connection point designation / description
2. Select the Connection point descriptions tab.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Connection point descriptions tab lists the function definitions with their connection points. One line is shown for each connection point.
3. In the fields 1 - 10, enter up to 10 different [connection point descriptions](Glossary_o_anschlussbeschreibungen.htm) per connection point.
4. Click [OK].

![](../Pictures/Gui/ALL/note.png)Note:

After each change, the changed connection point [designations](Glossary_o_bezeichnungen.htm) / descriptions must be exported. If you receive a new function definition library in an update, you will need to import your exported connection point designations / descriptions into the new program version and add the new function definitions.

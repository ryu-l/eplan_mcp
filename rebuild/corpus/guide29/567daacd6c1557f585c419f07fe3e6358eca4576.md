# Duplicating Elements

Using the Duplicate command, you can insert multiple copies very easily at the same time. Duplication only works within a single page, not between pages.

Precondition:

You have opened a page, [form](Glossary_o_verlauf.htm), plot frame or symbol.

1. Select the element(s) to be duplicated, and select the menu item Edit > Duplicate.
2. Place the first copy.
3. In the Duplicate dialog, enter the total number of elements to be created.   
     
   ![](../Pictures/Gui/ALL/arrow.png) EPLAN automatically generates the specified number of copies and places them at the distance selected for the first copy.

# Extended Language Selection In The Block Properties

When formatting the [properties](Glossary_o_eigenschaften.htm) in the Format: Block property dialog you can specify the language in which the texts of the property are displayed by means of the Language drop-down list. In this list new entries are also available for the displayed language, such as "Displayed language 1", "Displayed language 2", etc.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

By means of the new entries in the language selection ("Displayed language 1", "Displayed language 2", etc.) it is possible that the texts of [block properties](Glossary_o_blockeigenschaften.htm) and [placeholder texts](Glossary_o_platzhaltertexte.htm) in the [master data](Glossary_o_stammdaten.htm) ([macros](Glossary_o_makros.htm), [forms](Glossary_o_formulare.htm), [plot frames](Glossary_o_normblaetter.htm), etc.) are always displayed in the current displayed language, even if this is changed in the translation [settings](Glossary_o_einstellungen.htm).

During the selection of such an entry the texts of the property are displayed in the language that is specified in the translation settings as the first, second, etc. displayed language. Depending on the number of displayed languages in the translation settings up to five entries are possible here.

# New Shortcut Keys

The following shortcut keys are now available in the user interface of the EPLAN platform by default:

| Command | Key combination |
| --- | --- |
| Generate [reports](Glossary_o_auswertungen.htm) | [Ctrl] + [E] |
| Generating [macros](Glossary_o_makros.htm) from a macro project | [Ctrl] + [K] |
| Use existing [PLC connection points](Glossary_o_sps_anschluesse.htm) blockwise | [Ctrl] + [L] |
| Address PLC | [Ctrl] + [O] |
| Search function: Synchronize selection | [Ctrl] + [S] |
| Update reports | [Ctrl] + [<] |
| Check project | [Ctrl] + [Shift] + [P] |
| Generate project reports | [Ctrl] + [Shift] + [<] |
| Edit workspace | [Ctrl] + [Alt] + [A] |

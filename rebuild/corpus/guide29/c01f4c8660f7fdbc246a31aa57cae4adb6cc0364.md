# Dialog Settings: 3D (User, Graphical Editing)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > User > Graphical editing > 3D.

Use this dialog to enter your own [settings](Glossary_o_einstellungen.htm) for graphical editing in the 3D view.

Overview of the main dialog elements:

Group box Color settings

Use [...] to open the dialog [Color selection](mf_d_farbauswahl.htm) at all the color settings. Select the desired color there.

Shading - background 1 / Shading - background 2:

Enter the background colors for the [shading](Glossary_o_shading.htm) in the 3D view.

Collision indication:

Enter the background colors for collisions between components during placement and when making changes in the 3D view.

Active mounting surface:

Enter the color for the active mounting surface in the 3D view.

Active copper bundle:

Enter the color for the active [copper bundle](Glossary_o_kupferstrang.htm) in the 3D view.

---

Default grid sizes group box

You can specify five different default [grid](Glossary_o_raster.htm) sizes in the Grid size A to Grid size E fields. Choose the grid size in the [layout space](Glossary_o_bauraum.htm) via the associated buttons ![](../Pictures/Gui/ALL/gededitgui_grida.png) to ![](../Pictures/Gui/ALL/gededitgui_gride.png) on the "View" toolbar.

---

Apply simplified representation to group box

Use this group box to specify which [items](Glossary_o_bauteile.htm) in the layout space are to be reduced in size in the detail in the graphic by the Simplified representation function.

- Terminal strips (block definition): If this check box is activated (default setting), the terminal strips will be displayed as a simplified block.
- 3D macros: If this check box is activated (default setting), the graphical [macros](Glossary_o_makros.htm), rails, and [wire ducts](Glossary_o_verdrahtungskanaele.htm) are simplified into a cuboid.

In the layout space you activate the display determined here by using the View > Simplified representation menu items of, in the layout space navigator, via Popup menu > Simplified representation.

---

Rotate when changing the viewpoints:

When switching the 3D viewpoint, the view becomes animated and is rotated into the new position. If this check box is deactivated, the view is switched without any movement.

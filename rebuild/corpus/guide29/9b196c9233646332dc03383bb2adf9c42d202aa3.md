# Updating the Column and Row Designations of Plot Frames

Both columns and rows can be predefined alphanumerically and numerically via the [numbering formats](Glossary_o_nummerierungsformate.htm) in the plot frame. Such a default can then be later updated.

### Specify column and row numbering

Precondition:

You have opened a project.

1. Select the menu [items](Glossary_o_bauteile.htm) Options > Settings > Projects > "Project name" > Management > Pages.
2. In the Path numbering group box, specify whether the numbering should be page- or project-related or by structure identifier by selecting the appropriate option.
3. Click [OK].

With the page-dependent counting method, counting of column areas starts from scratch for each page, i.e., EPLAN always starts with the configured starting value and increments it until the last column of the page is reached. For numbering by project, column numbers are counted through each page, so that counting starts with the starting value on page 1 and counted to x on the last page. (Please note that all pages are counted here, unless you activate the plot frame property Show column designation on non-logical pages.)

The following plot frame [properties](Glossary_o_eigenschaften.htm) ("Settings" Category) are taken as the basis for the report:

- Start value (column): The column numbers of the [grid](Glossary_o_raster.htm) are normally numbered from left to right (starting with 0). A different starting value can be provided here.
- Start value (row): The row numbers of the grid are normally numbered from top to bottom (starting with 0). A different starting value can be provided here.
- Column numbering format: Format of the column numbers. If no format is specified, the column number is hidden.
- Row numbering format: Format of the row numbers. If no format is specified, the row numbers are hidden.
- Page orientation / paper format: Specifies the way in which the schematic pages are divided into areas: Landscape or portrait format.

![](../Pictures/Gui/ALL/note.png)Note:

The properties Column numbering format ([ID](Glossary_o_id.htm) 12011) and Row numbering format (ID 12009) require at alphanumerical numbering that a number is entered in the property Start value (column) (ID 12025) / Start value (row) (ID 12026). This number is then converted by the system into the corresponding characters:  
The values "0" and "1" show the character "A",   
The value "2" shows the character "B",   
The value "3" shows the character "C", and so on.

### Update column and row numbering

Preconditions:

- You have opened a project.
- You have opened a schematic page to which a plot frame has been assigned.

1. Select the menu item Utilities > Update path [designations](Glossary_o_bezeichnungen.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) Path designations are updated in accordance with the selection made under Settings.

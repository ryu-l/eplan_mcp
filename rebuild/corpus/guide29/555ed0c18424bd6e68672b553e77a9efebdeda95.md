# P004025: Slot / module is missing

### Cause

In a PLC box, a [rack](Glossary_o_baugruppentraeger.htm) name was entered under PLC card is placed on rack [ID](Glossary_o_id.htm) but not the slot position.

### Solution

Open the Properties <...> dialog for the corresponding PLC box. In the PLC structure data tab, enter the missing slot position into the Position (slot / module) field.

Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

This check run only checks [PLC boxes](Glossary_o_sps_kaesten.htm) at which a configuration project is entered.

# Dialog Copy project

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened and selected a project in the Page navigator. Project > Copy.
- You have selected a project management database. You have loaded directories and [projects](Glossary_o_projekte.htm). Project > Management. Select a project. Select the Copy popup menu item.

In this dialog you can specify the scope of the project to be copied. After that, the copied project is automatically opened in the page navigator.

![](../Pictures/Gui/ALL/note.png) Note:

If you copy a filed-off project then the project copy is not filed-off.

Overview of the main dialog elements:

Entirely incl. report:

If you select this option then the entire project, with all [reports](Glossary_o_auswertungen.htm), is copied.

Entirely without report:

If you select this option then the entire project, without reports, is copied.

Only header data:

If you select this option, the project is copied without pages or reports but with the layer information.

Only interactive pages:

If you have selected this option then only interactive pages are copied. This includes (e.g.) schematic pages with page types of "External document", "Graphic", "[P&I diagram](Glossary_o_ri_fliessbild.htm)", "Schematic multi-line", "Schematic single-line", "Fluid power schematic", "Panel layout", and "Overview". Reports and [unplaced functions](Glossary_o_nicht_platziertefunktionen.htm) are not copied.

Source project:

This field contains the file path and name of the project you wish to copy.

Target project:

The file path to the target directory and the name of the project copy are entered into this field. [...] opens the Copy to dialog. Here you can select the target directory and a project name for the project copy.

Specify creation date:

If this check box is selected, then you can specify a creation date for the project copy in the field below.

Specify creator:

With this functionality a (different) creator can be specified for the project copy. If this check box is selected, your logon name or user code will automatically be entered in the field below, depending on the [settings](Glossary_o_einstellungen.htm) under User > Display > User code / address. If you do not wish to use your logon name or user code, you can enter a different name. If the check box is not selected, the creator of the original project is displayed. If nothing is entered in this field, this means that no creator was specified for the original project.

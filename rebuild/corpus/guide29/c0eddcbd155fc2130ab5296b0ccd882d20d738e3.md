# Changing Project Properties via Placeholder Objects

The [project properties](Glossary_o_projekteigenschaften.htm) of a project can now also be changed via the [placeholder objects](Glossary_o_platzhalterobjekte.htm). For this reason it is not only the page on which the placeholder object is located but also the project itself is an object that belongs to a placeholder object.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

In EPLAN Cogineer you can, for example, use the changing of project [properties](Glossary_o_eigenschaften.htm) by means of placeholder [objects](Glossary_o_objekte.htm) to overwrite the [project data](Glossary_o_projektdaten.htm) of the underlying basic project in the target project that is created (such as the commission number).

In the [property dialog](Glossary_o_eigenschaftendialog.htm) of the Assignment tab the project is therefore available as the top node in the property table. At the property selection for this object only the changeable properties of the project are displayed, and are displayed after the selection in the [form](Glossary_o_verlauf.htm) of a tree structure.

As [part](Glossary_o_artikel.htm) of this extension the setting for showing and assigning page properties in the Assign value set dialog has been renamed:

| Old designation | New designation |
| --- | --- |
| Show variables for page properties | Show variables for project and page properties |

# Defining Daisy Chains

The [connections](Glossary_o_verbindungen.htm) within a net can be defined on the net definition point. The net will not be complete until all [connection points](Glossary_o_anschluesse.htm) have been connected. If a net has more than one daisy chain, they must also be interconnected in order to [create](Glossary_o_erstellen.htm) a complete net.

Preconditions:

- You have opened a project and are in a schematic page.
- You have inserted a net definition point.

1. Select the net definition point in the graphical editor and then select the menu item Edit > Properties.
2. In the Properties <...> dialog, select the Net connections tab.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The Connection points table displays all the connection points in the net.
3. Select Popup menu > Create daisy chain.
4. Click the connection point where the daisy chain is to start.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection point is shown in the Connections table.
5. Click in sequence on the other connection points that are to be included in the daisy chain.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection points in the daisy chain are shown in the Connections table.
6. Select Popup menu > End daisy chain.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A horizontal line is added to the Connections table to indicate that the daisy chain is complete.
7. Select Popup menu > Create daisy chain again to define another daisy chain.
8. Click in sequence on the starting connection point and then the other connection points that are to be included in the daisy chain.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connections are displayed in the Connections table.
9. Select Popup menu > End daisy chain.
10. Click [Apply] to save the defined [daisy chains](Glossary_o_verbindungsketten.htm).

![](../Pictures/Gui/ALL/info.png)Tip:

You can create a new daisy chain by double-clicking a connection point in the Connection points table in the Net connections tab. This also ends an already started daisy chain.

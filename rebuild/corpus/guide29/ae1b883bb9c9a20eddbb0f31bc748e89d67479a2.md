# P003008: Cable connection without cable

### Cause

- Case 1: The connection definition point of a [cable](Glossary_o_kabel.htm) connection no longer exists on the interface with the cable definition line. This is preventing EPLAN from assigning the connection definition point to a cable.
- Case 2: The connection definition point of a shielding conductor in the area of influence has been changed. This is preventing EPLAN from assigning the connection definition point to a shielding conductor.

### Solution

#### Possibility 1

Move the connection definition point to the intersection of the cable definition line with the cable connection or to within reach of the shield.

#### Possibility 2

Draw the cable definition line or the shielding conductor again.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

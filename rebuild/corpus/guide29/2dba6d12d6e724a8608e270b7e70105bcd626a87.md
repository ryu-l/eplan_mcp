# Topology Routing Points

Routing points are characteristic positions in the routing path network, such as curves, wall [cut-outs](Glossary_o_durchbrueche.htm), an [offset](Glossary_o_offset.htm), an outlet in the path, enclosure openings, etc. The [routing points](Glossary_o_verlegepunkte.htm) can, but do not have to, consist of any material.

The routing point serves as a jump-in position for the connection to a target, as a position for a junction to other [routing paths](Glossary_o_strecken.htm) or for connecting routing paths. Routing paths always end at a routing point, i.e., the routing point interrupts the routing paths.

A routing point can have a maximum of one [topology](Glossary_o_topologie.htm) connection point; per default the insertion point is used as connection point.

### Structure routing points

Structure routing points are routing points with the function definition "Topology structure routing point". A structure routing point represents a specific identification structure and the connected topology functions. Topology functions can be generated manually as well as automatically at a structure routing point.

By means of [structure routing points](Glossary_o_strukturverlegepunkte.htm) it is possible to [route](Glossary_o_verlegen.htm) [connections](Glossary_o_verbindungen.htm) between different identification structures without the connected topology functions. You can, for example, route cables between different enclosures without knowing all the connected [devices](Glossary_o_betriebsmittel.htm) or [placing](Glossary_o_auflegen.htm) them individually.

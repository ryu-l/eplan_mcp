# Performing Settings for Cross-reference Display

The cross-reference is important in order to locate a [component](Glossary_o_schaltzeichen.htm) within a multitude of pages. For this reason, the cross-reference must uniquely designate the page that is being searched. An orientation within the page is also required, the column. Since a column can also be relatively large, the row provides a further orientation within the page.

Precondition:

You have opened a project.

1. Options > Settings > Projects > "Project name" > Cross-references / contact image
2. Select the Interruption points [settings](Glossary_o_einstellungen.htm) section.
3. In the Display group box, define how the [cross-references](Glossary_o_querverweise.htm) to [interruption points](Glossary_o_abbruchstellen.htm) are to be displayed.
4. Select the General settings section.
5. In the  Display group box, define how the cross-references at the item are to be displayed.
6. In the Separator group box, you define which characters are to be used as separators in front of the page, between page and column, and between row and column.
7. Select the Display settings section.
8. For each of the different page types, you define here which cross-references to other page types are to be displayed and in what order.
9. You also use the Display overview cross-references group box in the Display section to specify the treatment of [overview cross-references](Glossary_o_uebersichtsquerverweise.htm).
10. Click [OK].

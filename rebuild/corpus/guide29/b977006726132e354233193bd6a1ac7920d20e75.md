# P030002: Subproject '<x>' contains changes outside the defined working section

### Cause

In the subproject pages, layout spaces of pre-[planning objects](Glossary_o_planungsobjekte.htm), for example, were created or renamed that lie outside the defined working section.

![](../Pictures/Gui/ALL/note.png)Note:

This message is only output in the subproject.

### Solution

1. In the subproject delete the pages, layout spaces or pre-planning [objects](Glossary_o_objekte.htm) that lie outside the working section or move them into the defined working section.
2. Start any check run in order to delete the message.
3. Embed the subproject again into the original project.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

# Creating and Editing Project Options

Project options are stored in the project. For this reason, they must be created in the project where they will be later used.

Preconditions:

- You have opened a project.
- You have opened the [project options](Glossary_o_projektoptionen.htm) navigator: Project data > Project options > Navigator

### [ClosedCreate Project Options](javascript:void(0);)

1. Select the New > Project option popup menu item.
2. in the Project options dialog, select the project options group that the project option is to be assigned to from the Name drop-down list.
3. Alternatively, you can manually enter a new project options group.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Description field belonging to the project options group can now be edited.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you leave the Project options group field empty (or delete the entry) then the project option is not assigned to a project option group.
4. If desired, enter a description into the Description field of the project options group.
5. Enter a name for the project options in the Name field.
6. If desired, enter a description text into the Description field.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The description is a multi-language text and is displayed by default in the tree view next to the name, separated by a blank and within round brackets.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have entered a new name for the project options group, this is generated.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new project option is automatically activated. Existing project options in the same project options group are switched off.

### [ClosedEdit Project Options](javascript:void(0);)

1. Select a project option in the Project options - <Project name> dialog.
2. Select the menu item Edit > Properties.
3. in the Project option dialog, change the values in the Name and Description fields.
4. Click [OK].

### [ClosedDelete project options](javascript:void(0);)

1. Select a project option in the Project options - <Project name> dialog.
2. Select the menu item Edit > Delete.
3. Click [Yes] to confirm the safety prompt.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project option and all sections it contains are deleted. If the project option was switched on, the [objects](Glossary_o_objekte.htm) it contains remain in the project; if the project option was switched off, the objects it contains are deleted from the project.

# GRAFCET actions: Definition of term

### GRAFCET actions

User interface / operation

Component of GRAFCET diagrams (see [GRAFCET](Glossary_o_grafcet.htm)). A step can be allocated one or several actions. An action defines what is to be done to a variable. Actions are generally represented by rectangles.  
The variables can be combined in a variable table transparently. Via the additional placing of device tags in this variable table, a connection to the EPLAN devices is established.

# P005080: Connection (topology) does not have a multi-line / single-line counterpiece

### Cause

In the routing path network of your [topology](Glossary_o_topologie.htm) design there is one routing connection for which there is no multi-line counterpiece on a schematic page. Maybe one or several [functions](Glossary_o_funktionen.htm) which are targets of this multi-line connection were moved in the schematic or deleted or they have not been placed in the schematic yet. In all cases, no autoconnect line which, as a multi-line connection, represents the counterpiece to the topology routing connection can be generated between the multi-line targets.

### Solution

1. Locate the topology function which is the first target of the routing connection in the routing path network using the Go to (graphic) function from the popup menu in the Message management dialog.
2. From there, track the routing connection through the routing path network up to the topology function which represents the second target of the connection.
3. For both topology functions locate the corresponding multi-line functions in the schematic using the Go to (counterpiece) option from the popup menu.
4. If only one multi-line counterpiece can be determined or both multi-line counterpieces of the topology functions are missing, insert the missing function into the schematic correspondingly.
5. Position both multi-line functions in the schematic below of or next to each other so that their [connection points](Glossary_o_anschluesse.htm) can be connected by an autoconnect line. Or place [connection symbols](Glossary_o_verbindungssymbole.htm) in the schematic so that a connection per autoconnect line can be generated by means of these schematic [objects](Glossary_o_objekte.htm).
6. Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

# P004010: Rack '<x>' is unknown

### Cause

A non-existent [rack](Glossary_o_baugruppentraeger.htm) name was entered for a slot.

### Solution

#### Possibility 1

Create a new rack with a suitable designation.

#### Possibility 2

1. Enter an existing rack name.
2. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

This check run only checks [PLC boxes](Glossary_o_sps_kaesten.htm) at which a configuration project is entered.

# New Project Property for the Display of the Highest Revision Index

If you use the revision control with [change tracking](Glossary_o_aenderungsverfolgung.htm), you assign a revision index when completing pages or layout spaces. This revision index is saved at the respective page / [layout space](Glossary_o_bauraum.htm) in the property Revision index (change tracking) ([ID](Glossary_o_id.htm) 11071). You can now print the highest revision index in a project by using the new project property Highest revision index (change tracking) (ID 10098).

![](../Pictures/Gui/ALL/benefit.png)Benefit:

The new Highest revision index (change tracking) project property allows you to immediately see which highest revision index a project has.

The Highest revision index (change tracking) property supplies the highest revision index of all pages and layout spaces in the project. It can be placed as a special text on a project page and be printed this way. The property searches for the newest revision index. This must correspond to the format set in the [Settings: Change tracking (numbering of the revision index)](revisionlogmgtgui_d_einstellungenseitenindex.htm) dialog and must not be changed subsequently.

# Dialog Number cables

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have selected components in the graphical editor.
- Or you have selected cables or [cable connections](Glossary_o_kabelverbindungen.htm) in the navigator dialog Cables - <Project name>.
- Or you have selected [connections](Glossary_o_verbindungen.htm) in the navigator dialog Connections - <Project name>.
- Or you have selected pages or a project in the Pages - <Project name> navigator dialog.

Project data > Cables > Number.

In this dialog you specify the [settings](Glossary_o_einstellungen.htm) for numbering [cable](Glossary_o_kabel.htm) device tags and then you execute the numbering.

![](../Pictures/Gui/ALL/note.png)Note:

Ensure that nested DTs are excluded from numbering.

Overview of the main dialog elements:

Settings:

The scheme selected here specifies in which sequence cables are numbered, which [properties](Glossary_o_eigenschaften.htm) are to be displayed in the cable DT and how they and formatted. Use [...] to open the [Settings: Cable numbering](cablegui_d_einstellungenkabelnummerierung.htm) dialog where you manage and edit the [schemes](Glossary_o_schemata.htm).

Start value:

Enter the start value for the DT counter.

Increment:

Enter the value here to be used to increment the counter of the DT.

Keep existing cable DTs:

Select this check box if you would only like to renumber newly generated or copied cables. The DT of the already numbered cables is retained. The cables with "?" in the identifier will be numbered.

If the check box is deselected, all of the cable DTs are renumbered.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

In the following example, start value and increment are set to 1.

Prior to numbering: W2 W? W3 W5   
Activated check box: W2 W1 W3 W5  
Deactivated check box: W1 W2 W3 W4.

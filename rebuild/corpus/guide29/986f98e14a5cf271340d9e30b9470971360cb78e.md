# Tab Settings (placeholder object)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project page in the graphical editor. Or you have opened a [layout space](Glossary_o_bauraum.htm).

- Insert > Placeholder object. Select an area with [objects](Glossary_o_objekte.htm) that should belong to the placeholder object. In the Properties <...> dialog, select the Settings tab.
- Double-click the "anchor" symbol of an already created placeholder object. In the Properties <...> dialog, select the Settings tab.
- Project data > Project options > Placeholder objects. In the Placeholder objects - <Project name> dialog mark a placeholder object and select the Properties popup menu item. In the Properties <...> dialog, select the Settings tab.

In this tab you specify the [settings](Glossary_o_einstellungen.htm) for the usage of [placeholder objects](Glossary_o_platzhalterobjekte.htm) in EPLAN Cogineer. In EPLAN Cogineer placeholder objects in the [macros](Glossary_o_makros.htm) are used to vary the data during the generation of schematics or on the generated schematic pages.

Overview of the main dialog elements:

Use placeholder object in EPLAN Cogineer:

If this check box is activated, the placeholder object is available after adding the macro in EPLAN Cogineer and is considered during the schematic generation in EPLAN Cogineer. In this case values assigned in EPLAN Cogineer are displayed at the placeholder object on the generated schematic page.

If the check box is deactivated, the placeholder object in EPLAN Cogineer is not available. In this case the placeholder object is displayed unchanged on the generated schematic page. Subsequently a value set can be assigned on the schematic page.

Remove placeholder object after generation:

This check box is only available if the setting Use placeholder object in EPLAN Cogineer: has been activated.

If this check box is activated, the placeholder object is deleted from the schematic after the generation of the schematic with EPLAN Cogineer.

### Symbols

User interface / operation

A symbol is a graphic for representing functions (see [Functions](Glossary_o_funktionen.htm)). Logical data is normally stored in the function definitions. However, a symbol can include certain logic settings, e.g. for connection points. (In contrast to this, objects in the graphical user interface are represented by icons.)

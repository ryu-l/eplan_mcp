# P026021: The mounting surface and the main function / main terminal have differing mounting sites (describing)

### Cause

Differing data was entered in the property fields under Mounting site (describing) for the main function / main terminal of the [part](Glossary_o_artikel.htm) placement in the schematic and for the corresponding mounting surface in the [layout space](Glossary_o_bauraum.htm).

### Solution

1. Enter the same data for the main function / main terminal of the part placement in the schematic and for the corresponding mounting surface in the layout space, in both cases in the Mounting site (describing) property field.
2. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

The check run is also output if there are different translation states for the two property fields mentioned above, i.e. if the property was entered at the main function / main terminal in the current user interface language, but the property at the mounting surface exists in at least one other language translation.

# Tab Hose assignments

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have installed the hose line configurator as an add-on variant of EPLAN Fluid. You have started EPLAN Fluid and the hose line configurator.

- Select the menu [items](Glossary_o_bauteile.htm) Options > Settings > User > Add-ons > Hose line configurator in EPLAN Fluid and click in the Hose assignments tab in the subsequent dialog.
- Or select the menu items Extras > Settings in the Configure hose lines dialog of the hose line configurator and click in the Hose assignments tab in the subsequent dialog.

Or you have installed the hose line configurator as a stand-alone variant and started the program.

- Select the menu items Options > Settings > User > Add-ons > Hose line configurator in the hose line configurator and click in the Hose assignments tab in the subsequent dialog.

You define the default data for [hose assignments](Glossary_o_schlauchzuordnungen.htm) in this tab. In the process you assign different [hose groups](Glossary_o_schlauchgruppen.htm) to a specific [working pressure](Glossary_o_arbeitsdruck.htm) and furthermore store the desired maximum and minimum permissible hose diameters for the selected hose groups. The working pressures entered in the table are offered for selection when the [hose lines](Glossary_o_schlauchleitungen.htm) are configured in the Edit <...> dialog.

Use the buttons of the toolbar above the list to [create](Glossary_o_erstellen.htm) new entries, edit existing ones and / or delete entries no longer required.

Overview of the main dialog elements:

Working pressure (list):

Determine the maximum permissible dynamic working pressure of the hose [lines](Glossary_o_leitungen.htm) here. The values reference the unit "bar".

Use the buttons of the toolbar above the list to create new entries, edit existing ones and / or delete entries no longer required.

![](../Pictures/Gui/ALL/note.png)Note:

Different working pressures can be assigned in accordance with different hose groups.

Table:

In this table you assign the required hose groups as well as the minimum and maximum permissible nominal diameters of the hoses to the respective working pressure.

Use the buttons of the toolbar above the table to create new entries and / or delete entries no longer required.

![](../Pictures/Gui/ALL/note.png)Note:

If you select the default scheme DIN 20066\_2012-01 the [settings](Glossary_o_einstellungen.htm) in this tab and in the [Hose groups](fluidhoseconfiggui_r_schlauchgruppen.htm) tab have the effect that the hose types specified in accordance with the standard DIN 20066 are offered for selection in the Edit <...> dialog for each selected working pressure and for each selected nominal diameter of the hose.

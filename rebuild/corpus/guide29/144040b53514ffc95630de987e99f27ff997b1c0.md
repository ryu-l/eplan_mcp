# Tab Designation

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Options > Settings > Projects > "Project name" > Connections > Connection numbering. Select the Designation tab in the dialog Settings: Connection numbering.
- You have selected a connection in the graphical editor, or in the Connections - <Project name> navigator dialog. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog. Project data > Connections > Numbering > Place > [...]. Select the Designation tab in the dialog Settings: Connection numbering.

In this tab you specify a maximum of 20 format groups. You can compile different [function definitions](Glossary_o_funktionsdefinitionen.htm) in a format group and format them in the same way. In the process you can also use wildcards (\*). This allows groups of [functions](Glossary_o_funktionen.htm) to be combined for which a common format can be defined.

Overview of the main dialog elements:

Format groups:

This list shows the [connection groups](Glossary_o_verbindungsgruppen.htm) selected for numbering, their extent, as well as a preview of the specified format.

![](../Pictures/Gui/ALL/note.png) Note:

The [connections](Glossary_o_verbindungen.htm) are numbered according to the sequence of the connection groups. Thus the "General Connections" group should be at the last position.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

In the Format groups field, you have selected the following connection groups:

- Connections attached to [PLC connection points](Glossary_o_sps_anschluesse.htm)
- Connections attached to terminals
- General Connections.

In this case, the connections joined to PLC [connection points](Glossary_o_anschluesse.htm) are numbered first, whereby the numbering format defined for this group is used. After this, the connections joined to terminals are numbered (using the numbering format for the appropriate group). Finally, the remaining connections are numbered using the numbering format for the "General Connections" group.

If, however, the general connections are in the first position of the Format groups field, then all connections will be numbered using the "General Connections" numbering format. The [formats](Glossary_o_formate.htm) for connections joined to PLC connection points and terminals are not used since the appropriate connections are already numbered.

[Net extension]:

Opens the [Net extension](wirenumberinggui_d_netzerweiterung.htm) dialog. In this dialog you can extend the definition of a net. This setting affects the designation if the range is selected as "Net".

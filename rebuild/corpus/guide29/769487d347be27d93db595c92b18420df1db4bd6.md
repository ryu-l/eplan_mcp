# Inserting Connection Forks and Cable Lines into Connection Diagrams

Preconditions:

- You have opened a project.
- You have opened the Connection diagram [form](Glossary_o_verlauf.htm) whose [properties](Glossary_o_eigenschaften.htm) you would like to edit in the form editor (Utilities > Master data > Form > Open).

### Insert connection forks

To clarify the representation of [connections](Glossary_o_verbindungen.htm), the connections of [items](Glossary_o_bauteile.htm) located next to each other can be summarized and displayed graphically in the form of a double-ended "fork", where the number of "prongs" on the fork at each end is the same as the number of summarized individual connections. The Connection graphic ([ID](Glossary_o_id.htm) 13048) property exists for this purpose, which can be inserted into [forms](Glossary_o_formulare.htm) as a placeholder for internal and external cables. The index of the placeholders defines the connection diagram level. The extent of the fork is defined by the placeholder alignment box, and the height of the "prongs" is defined by the font size of the placeholder. The orientation of the fork is automatically defined by the form orientation.

1. Insert > Placeholder text
2. Select the Property option in the Placement tab of the Properties (placeholder text) dialog, and click [...].
3. Double-click one of the elements "Cable, internal 'Level (1-3)'" or "Cable, external 'Level (1-3)'" in the Element field in the Placeholder texts - <Form type> dialog.
4. Select an entry.
5. Select the Connection graphic property and click [OK].
6. Define the [settings](Glossary_o_einstellungen.htm) for displaying the placeholder text in the form on the Format tab of the Properties (placeholder text) dialog.
7. Click [OK].
8. Position the placeholder text using the mouse.

### Insert cable lines

The Cable graphic (ID 13107) property allows the graphical representation of [cable lines](Glossary_o_kabellinien.htm) in [connection diagrams](Glossary_o_anschlussplaene.htm), which can be used in forms as placeholders for internal and external cables, where the placeholder index defines the connection diagram level. The extent of the [cable](Glossary_o_kabel.htm) [lines](Glossary_o_leitungen.htm) is defined by the alignment box of the placeholder. In this case, the height should be defined as "0", so that the cable line is drawn perpendicular to the connection; if the height is other than "0", then the cable line will be drawn at an angle. Multiple connections lying next to each other are summarized if they belong to the same cable, whereby the length of the cable line is not altered.

1. Proceed as described above until Step 5.
2. Select the Cable graphic property and click [OK].
3. Define the settings for displaying the placeholder text in the form on the Format tab of the Properties (placeholder text) dialog.
4. Click [OK].
5. Position the placeholder text using the mouse.

![](../Pictures/Gui/ALL/note.png)Note:

In forms with several columns and rows at the same time, these properties cannot be used.

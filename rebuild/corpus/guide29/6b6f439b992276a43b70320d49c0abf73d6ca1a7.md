# Macros: Protected Groups

Window and [symbol macros](Glossary_o_symbolmakros.htm) can be generated as a so called "protected group" during insertion. Such a group is a similar grouping to an element or device group. Protected groups cannot be changed graphically or further broken down, however. The inserting of [macros](Glossary_o_makros.htm) as a protected group is, for example, of interest if you want to use [devices](Glossary_o_betriebsmittel.htm) or standardized prefabricated schematic sections and want to prevent other users from changing this standard.

You specify whether a protected group is generated for a macro during insertion when you prepare macros in the Macro project. To this purpose there is a check box Generate protected group during insertion in the Settings tab at the macro box. A [settings](Glossary_o_einstellungen.htm) possibility only exists in [macro projects](Glossary_o_makroprojekte.htm), if the type of usage "Defining" or "Not specified" was set for the macro box.

![](../Pictures/Gui/ALL/info.png)Tip:

If this grouping is to be removed for the inserted macros in a project, you can use the compression of [projects](Glossary_o_projekte.htm). To do so, activate the Remove protected groups check box in the Remove project data hierarchy level of the dialog Settings: Compression. This way the grouping is removed but the inserted macros and their components remain.

![](../Pictures/Gui/ALL/note.png)Note:

In contrast to the element and device groups, the grouping for protected groups cannot be deactivated temporarily by using the [Shift] key or canceling the option Consider groupings.

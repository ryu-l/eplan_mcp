# Drawing Potential Definition Points or Connection Points

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Select the menu [items](Glossary_o_bauteile.htm) Insert > Potential definition point or Insert > Potential connection point.
2. Place the potential definition point or connection point in the schematic.
3. In the [properties](Glossary_o_eigenschaften.htm) dialog, in the Potential definition tab, enter the potential properties (and other properties in the other tabs if required).
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The properties are assigned to the [connections](Glossary_o_verbindungen.htm) running through the potential definition point or the connection joined to the potential connection point.

![](../Pictures/Gui/ALL/info.png)Tip:

You can insert multiple [potential definition points](Glossary_o_potenzialdefinitionspunkte.htm) at the same time by holding the left mouse button down and pulling the cursor over multiple autoconnect [lines](Glossary_o_leitungen.htm). At each autoconnect line intersected, a potential definition point is then placed.

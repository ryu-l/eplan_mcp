# Dialog Settings: 2D panel layout

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Project data > Parts / Devices > 2D Panel layout navigator > Popup menu > Settings.
- Options > Settings > User > Graphical editing > 2D panel layout.

In this dialog, you define particular default [settings](Glossary_o_einstellungen.htm) for [part](Glossary_o_artikel.htm) placement on the mounting panel; these then affect how the project can be edited in the 2D panel layout - <Project name> dialog.

Overview of the main dialog elements:

Direction of equipment:

In this group box, you define whether the equipment on the mounting panel is to be mounted in a horizontal or vertical direction: Select the corresponding option. Note that the Vertical equipment direction for multiple placement occurs from above to below.

Part placement:

In this group box you can specify the following settings:

- Rotation angle: Select the desired angle from the drop-down list for rotation of the part on placement.
- Handle: From the drop-down list, select which position on the part is to be the handle for placement purposes.  
  If you have selected the View > Insertion points menu [items](Glossary_o_bauteile.htm) to display the insertion points for [symbols](Glossary_o_symbole.htm) and text, and the handle differs from the insertion point, then it is displayed as well.
- By preference from macro: If you have selected one of the Macro ... from parts master data options in the Apply group box, you can use this check box to control how the handle is used: If the check box is selected and a macro exists, then the handle from the macro is used.

Apply:

In this group box you can specify the following settings:

- Dimensions from parts master data: Select this option when the part dimensions should be taken from the part [master data](Glossary_o_stammdaten.htm).
- Macro and dimensions from parts master data: Select this option when the dimensions of [macros](Glossary_o_makros.htm) and parts should be taken from the part master data.
- Macro from parts master data: Select this option if the macro set for the part is to be placed using its original dimensions. The dimensions set for the part are then ignored.
- Manual input: Select this option when the dimensions should be manually entered on placement using the Extension and distance dialog.
- Manual input, macro from parts master data: Select this option when the dimensions should be manually entered using the Extension and distance dialog on placement but the default dimensional values should come from the parts master data.

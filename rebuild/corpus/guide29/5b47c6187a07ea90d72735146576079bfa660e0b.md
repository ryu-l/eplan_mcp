# Dialog Connecting point

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Utilities > Master data > Symbol > Open. You have opened the symbol library, selected the symbol to be edited and added a connecting point to the symbol in the [symbol editor](Glossary_o_symboleditor.htm): Insert > Connection point "Direction". Or you have double-clicked an existing connecting point.
- Utilities > Master data > Symbol > New. You have selected the symbol variant to be generated, specified the Symbol number and Symbol name [properties](Glossary_o_eigenschaften.htm), and added a connecting point in the symbol editor: Insert > Connection point "Direction".

In this dialog you specify or edit the properties of the new connecting point.

Overview of the main dialog elements:

Symbol: Connection point designation / Symbol: Connection point description:

From this list select one or more entries for the connection point property placements (multiple and block selection is possible):

- Non-rotated connection point designation / connection point description
- Rotated connection point designation / connection point description (relevant for the new DIN).

![](../Pictures/Gui/ALL/note.png)Note:

To display and toggle, use the menu [items](Glossary_o_bauteile.htm) View > Non-rotated connection point designations or View > Rotated connection point designations.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Property / Assignment:

If you have selected a property, you can edit its display properties in the table in the right-hand section of the dialog. The hierarchy [levels](Glossary_o_etagen.htm) Format, Text box, Alignment box, Value / Unit and Position are available for this purpose. These can be opened by clicking the ![](../Pictures/Gui/ALL/all_plussign_as.png) symbol. Concerning the display properties, the [settings](Glossary_o_einstellungen.htm) described in the following section are available:

- [Display Properties: Placed Property](devicetaggui_r_anzeigeeigenschaften.htm)

![](../Pictures/Gui/ALL/info.png)Tip:

The menu items View > Properties as numbers displays the [property texts](Glossary_o_eigenschaftstexte.htm) (device tags, function text, etc.) to be switched in order to make the display clearer. The property specified is also reported in the print-out and in the output as a PDF file.

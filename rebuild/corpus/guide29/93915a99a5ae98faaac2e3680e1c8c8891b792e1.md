# Creating an Identifier

Precondition:

You have opened a project in which [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) are used in the [project structure](Glossary_o_projektstruktur.htm), for instance "Higher-level function" and "Mounting location".

Project data > Structure identifier management

In the Structure identifier management - <Project name> dialog new [structure identifiers](Glossary_o_strukturkennzeichen.htm) can be created for the respective identifier [blocks](Glossary_o_bloecke.htm), whereby the positioning depends on the current marking: In the List tab new structure identifiers are sorted in above the currently marked identifier. In the Tree tab a sub-hierarchy level is generated below the current identifier.

![](../Pictures/Gui/ALL/note.png)Note:

The project setting Conversion to upper-case (under Options > Settings > Projects > "Project name" > Devices > General) is used here.

1. In the Structure identifier management - <Project name> dialog, select the identifier block (left-hand area of the dialog) that you want to edit.
2. In the List tab click ![](../Pictures/Gui/ALL/all_new_as.png) (New).  
     
   ![](../Pictures/Gui/ALL/arrow.png) A new line is created above the current cursor position in the table, which is empty except for the entry "No" in the Usage column. (If there is still another empty identifier in the table, then the Status column will show a yellow warning triangle and the Message description field will show the explanation of this symbol).
3. Change the desired [properties](Glossary_o_eigenschaften.htm) in the corresponding fields.
4. Click [OK] or [Apply].
5. Answer the confirmation prompt to update the project.

![](../Pictures/Gui/ALL/warning.png)Warning:

Updating of structure identifiers is a process which cannot be undone.

When updating the data, the device tags in the schematic and the page data is updated. A changed sort order for structure identifiers is also written back to the project and can have far-ranging effects on the order of pages and [connections](Glossary_o_verbindungen.htm).

Placeholders for device tags in automatically generated pages, such as the table of contents, terminal diagram, and so on, will be adjusted only after the corresponding update of [report pages](Glossary_o_auswertungsseiten.htm).

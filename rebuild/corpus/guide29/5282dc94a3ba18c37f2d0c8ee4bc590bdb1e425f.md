# Tab Net definition

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have selected a net definition point in the graphical editor. Edit > Properties. In the Properties <...> dialog, select the Net definition tab.
- Insert > Net definition point. In the Properties <...> dialog, select the Net definition tab.

In this tab you define the [properties](Glossary_o_eigenschaften.htm) of a net definition point. The properties are assigned to all the [connections](Glossary_o_verbindungen.htm) in the net. The net has a higher priority than the signal or the potential. This means that the properties stored in a net definition point take precedence over the properties stored in a potential definition point. Properties that are stored directly in the connection are not overwritten.

Overview of the main dialog elements:

Name of potential:  
Signal name:

Enter the name for the potential / signal here. Click [...] in order to open the Select potential / signal dialog. The potential names and the associated signal names existing in the project are presented here for selection.

![](../Pictures/Gui/ALL/note.png)Note:

No [potentials](Glossary_o_potenziale.htm) and [signals](Glossary_o_signale.htm) can be defined at [net definition points](Glossary_o_netzdefinitionspunkte.htm). The potentials and signals must be defined via a potential definition point or a potential connection point in the project.

Net name:

Enter the name of the net that was defined via the net definition point. Remember that the net name must be unique within a project.

Cross-section / diameter:  
Cross-section / diameter unit:

The connection cross-section or diameter is adopted from the parts management and can be used as filter criteria when selecting [devices](Glossary_o_betriebsmittel.htm). Click [...] to open the Cross-sections / diameters dialog and select a cross-section / diameter (with the associated unit) from the list.

If you selected a predefined cross-section / diameter from the Cross-section / Diameter field, the associated unit is automatically transferred to the Cross-section / diameter unit field. Use the drop-down list to select another unit. An overview of the possible units can be found in the section "[Connections: Units for Lengths and Cross-sections](connectionbrowsergui_k_einheitenverbindungen.htm)".

Color / number:

Here you enter the color or number of the connection; this property identifies the connection. Click [...] to launch the Connection colors dialog and select a color from the list.

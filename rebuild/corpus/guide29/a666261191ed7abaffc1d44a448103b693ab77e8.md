# Adoption of Connection Point Designations

Connection point [designations](Glossary_o_bezeichnungen.htm) can be assigned to a [component](Glossary_o_schaltzeichen.htm) in different ways:

- By default, the [connection point designations](Glossary_o_anschlussbezeichnungen.htm) are adopted from the function definition. The [function definitions](Glossary_o_funktionsdefinitionen.htm) contain a list of possible connection point designations; here, the first entry serves as the preset value. At the component, you can either select an entry from this list, or you can manually overwrite the connection point designations. Separators between the [connection points](Glossary_o_anschluesse.htm) can be typed using [Ctrl] + [Enter].
- If you have [defined devices](Glossary_o_geraete.htm) and given them connection point designations, these connection point designations are assigned when the function is placed.
- During device selection (or [part](Glossary_o_artikel.htm) selection), the connection point designations entered in the schematic are overwritten. If the Connection point designation check box is checked in the [settings](Glossary_o_einstellungen.htm) for device selection, connection point designations entered in the schematic are retained.
- The connection point designation can â just as during [DT adoption](devicetaggui_k_bmkuebernahme.htm) â be adopted from a function lying in the search direction. Prerequisite for this is that you have activated the Adopt connection point designation check box in the project settings (Options > Settings > Projects > "Project name" > Management > Compatibility).

### Adoption from search direction

You not only can enter connection point designations in a function, but also all the connection point designations of the "subsequent components" which adopt the DT from this function and lie to the right (or below) this function in the schematic. You can enter the connection point designations for an entire series of components into a single component in this way. The possible connection point designations can be selected from a list in the subsequent components. The possible combinations of connection point designations are derived from the connection point designations entered during symbol creation.

Only if more connection point designations are entered than needed by the current component are the following components influenced.

In the [properties](Glossary_o_eigenschaften.htm) dialog in the Connection point designation field, the current connection point designations are always listed as the first entries, after which the possible connection point designations of the following components are listed. For all empty connection point designations, there is a [separator](Glossary_o_trennzeichen.htm) displayed so that you can see how many connection point designations are expected.

For the following [functions](Glossary_o_funktionen.htm), connection point designation adoption is not available:

- Cables
- Cable [connections](Glossary_o_verbindungen.htm)
- Black boxes
- Terminals
- Pins.

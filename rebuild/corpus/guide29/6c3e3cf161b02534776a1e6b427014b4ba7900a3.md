# Dialog Generate parts

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have marked a [component](Glossary_o_schaltzeichen.htm) that represents a main function. At least one [part](Glossary_o_artikel.htm) reference is entered in the DT. Popup menu > Generate part.

In this dialog, you can sort the parts generated from the schematic into the parts management product group structure.

The following dialog elements are available:

Part number:

This field shows the first part number that you have entered as a part reference at the component in the Parts tab. If desired, you can also change the part number. If you close the dialog by clicking [OK] and the part already exists in the parts management, then you will receive an appropriate message.

Generic product group / Product group / Product subgroup:

The product group structure of the part to be created is displayed here. These fields are already partially filled with values, according to the function definition of the component. If you wish to sort the part into a different parts management group, then select a different entry in the respective drop-down list.

Open part in parts management:

If this check box is selected then, after the part has been transferred to the parts database and you have received a message informing you of this, the parts management opens. The part number of the new part is selected, and you can immediately edit the part data.

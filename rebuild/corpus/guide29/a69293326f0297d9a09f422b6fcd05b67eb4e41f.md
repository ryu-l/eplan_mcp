# Interrupting Connections

Autoconnecting can sometimes [create](Glossary_o_erstellen.htm) unwanted [connections](Glossary_o_verbindungen.htm) in the schematic (e.g., to motor overload switch auxiliary contacts). You can interrupt these connections by inserting a break point between the [connection points](Glossary_o_anschluesse.htm). A break point is an invisible symbol without connection points that prevents [autoconnecting](Glossary_o_autoconnecting.htm) or that interrupts an existing autoconnect line.

Preconditions:

- You have opened a project. You have opened a project page in the graphical editor.
- The page contains autoconnect [lines](Glossary_o_leitungen.htm).

1. Select the following menu [items](Glossary_o_bauteile.htm): Insert > Connection symbol > Break point
2. Click between the two connection points on the autoconnect line to be interrupted.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The autoconnect line is interrupted, i.e., the connection is deleted.
3. Proceed in a similar way for all additional autoconnect lines that are to be interrupted.
4. End the action via the Cancel action popup menu item or via the [Esc] button.

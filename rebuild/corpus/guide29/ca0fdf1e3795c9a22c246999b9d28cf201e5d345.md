# Generally Translating / Not Translating Texts and Properties

If you do not want to translate all of the texts and [properties](Glossary_o_eigenschaften.htm) in the project, you can generally exclude texts and properties from the translation. These [settings](Glossary_o_einstellungen.htm) are stored on a per project basis.

Precondition:

You have opened a project.

Options > Settings > Projects > "Project name" > Translation > Extent

### Text elements

Text elements are schematic elements that you insert in the schematic via the menu [items](Glossary_o_bauteile.htm) Insert > Graphic > Text. Text elements are not generated from [project data](Glossary_o_projektdaten.htm).

1. To select text elements for translation, select the Free texts check box.
2. To exclude text elements from translation, deselect the Free texts check box.

### Path function texts

1. To select [path function texts](Glossary_o_pfad_funktionstexte.htm) for translation, select the Path function texts check box.
2. To exclude path [function texts](Glossary_o_funktionstexte.htm) from translation, deselect the Path function texts check box.

### Properties

Texts whose contents are generated from properties and project data are placed in project pages. Texts whose contents are generated from descriptive properties can be translated. These properties are divided into the areas "Item", "Form and plot frame", "Project", "Page", "Symbol", and "Symbol library".

1. Select the desired file range from the Extent drop-down list.
2. To select a property for the translation, select the check box in front of the desired property.
3. To exclude a property from the translation, deselect the check box in front of the desired property.

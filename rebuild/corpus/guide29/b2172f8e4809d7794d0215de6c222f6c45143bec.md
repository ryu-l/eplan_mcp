# Inserting Model Views

Model views are standardized views and views of equipped [mounting surfaces](Glossary_o_montageflaechen.htm). They are used for display purposes and for creating drawings. Additional information such as dimensioning, texts, etc. for enclosure production (enclosure equipment) can be drawn in the [model views](Glossary_o_modell_ansichten.htm) using standard platform [functions](Glossary_o_funktionen.htm).

Precondition:

You have opened a project.You have opened a project page in the graphical editor.

1. Select the Insert > Graphic > Model view (<...>) menu [items](Glossary_o_bauteile.htm).
2. Press [Enter] to specify the first corner of the area for the model view.
3. Open a frame using the arrow keys. You can open the frame in any direction.
4. End area selection with [Enter].
5. Define the data specific to the model view on the View tab of the Model view dialog.
6. On the Display tab, define the display [settings](Glossary_o_einstellungen.htm) for describing the model view, such as font size, alignment and width / height of the alignment box.
7. On the Rectangle tab, define the graphical [properties](Glossary_o_eigenschaften.htm) of the model view border, such as starting point, end point, and width.
8. On the Format tab, define the format properties for the model view border.
9. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Model view dialog closes and the model view is placed on the page according to the settings.

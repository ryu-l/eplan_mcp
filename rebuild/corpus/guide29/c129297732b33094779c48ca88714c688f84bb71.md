# P004201: Siemens: Incorrect PLC station type assignment: <x>

### Cause

EPLAN has determined an incorrect assignment of a PLC card with regard to the used PLC station type. Which PLC card is affected and how the assignment has to be corrected is specified in the placeholder "<x>" of the message.

### Solution

1. Locate the PLC box representing the PLC card in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the PLC box.
3. Bring the first tab to the front.
4. Correct the value of the property specified in the message text for the PLC station type in accordance with the specification.
5. Click [OK].
6. Then start a new check run.

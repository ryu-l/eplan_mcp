# Tab View (Drilling View)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project that contains layout spaces. You have opened a project page in the graphical editor. You have inserted a 2D drilling view (Insert > Graphic > 2D drilling view) and placed it. In the 2D drilling view dialog, select the View tab.
- You have opened a project that contains layout spaces. You have opened a project page in the graphical editor. You have double-clicked a 2D drilling view. In the 2D drilling view dialog, select the View tab.

On this tab you can edit the display [properties](Glossary_o_eigenschaften.htm) of 2D [drilling views](Glossary_o_bohransichten.htm).

Overview of the main dialog elements:

View name:

Every view is identified by a unique name that is stored in the set language. You cannot have multiple views with the same name.

Description:

The description is any multilingual text that describes the view in detail.

Layout space:

A 2D drilling view can always be created for only one [layout space](Glossary_o_bauraum.htm). This drop-down list displays all the layout space created in the project. When you open the dialog for the first time, the name of the first main layout space in the project is displayed.

Basic items:

Here you can specify what is to be displayed in the 2D drilling view. You can also further restrict the content of the layout space that is displayed. Click [...] to open the [3D object selection](gededit3dgui_d_3dobjektauswahl.htm) dialog and select the [objects](Glossary_o_objekte.htm) to be displayed in the 2D drilling view.

In the case of 2D drilling views and [model views](Glossary_o_modell_ansichten.htm), the basic [items](Glossary_o_bauteile.htm) can also be components of lower item hierarchy [levels](Glossary_o_etagen.htm), e.g. [mounting surfaces](Glossary_o_montageflaechen.htm). In the case of copper unfolds, this is not possible.

If the selected basic items do not contain any NC-relevant surfaces, the hext-higher item with NC-relevant surfaces is automatically added.

Scale setting:

You can use the following methods to calculate the scale:

- Automatic: The scale is calculated so that the basic item fits in the highlighted area optimally. Only the scales recommended in DIN ISO 5455 are used.
- Fit: The scale is again calculated so that the basic item fits in the highlighted area optimally. Any possible scale may be used, however, e.g. "1:12", but only whole integers are permitted.
- Manually defined: If you select this setting, the Scale field is enabled and you can specify any scale.

Scale:

This field is active if you select the "'Manually defined" option from the Scale setting field. Enter the scale in the format "1:x".

[Properties group box](devicetaggui_r_gruppenfeldeigenschaften.htm)

The following properties are, among others, available for 2D drilling views:

- Item labeling: Here you can specify which scheme is to be applied for labeling the items in the 2D drilling view. Click [...], to open the [Settings: Labeling](gededit3dgui_d_einstellbeschriftung.htm) dialog and to select or [create](Glossary_o_erstellen.htm) a new scheme.
- Rotation: By selecting a value from this drop-down list, the content of the 2D drilling view is rotated by 90°, 180° or 270° counterclockwise. This can be useful in order to make optimum use of highly-formatted 2D drilling views on pages in landscape orientation. The border of the 2D drilling view is not rotated. Texts in a 2D drilling view that is rotated by 90° are rotated by the same angle. The exception are [property texts](Glossary_o_eigenschaftstexte.htm) to be read from the right. For them to remain legible, they are rotated by -90°.
- Automatic dimensioning: Here you can specify which scheme is to be applied for automatically dimensioning the items in the 2D drilling view. Click [...], to open the dialog [Settings: Automatic dimensioning](gededit3dgui_d_einstellautobemassung.htm) and to select or create a new scheme.
- Model view: Apply viewpoint to mounting surface: If the check box is activated for this property, the [display of an item in oblique position](gededit3dgui_k_start.htm#SchraegeFlaechen) is aligned at its mounting surface. This way, even an item with sloping alignment will be depicted in the 2D drilling view correctly and orthogonally. The dimensioning generated on it will then correspond to the real values.
- Display item silhouettes: If this check box is activated, the basic [outlines](Glossary_o_konturen.htm) of extruded items (e.g., [mounting rails](Glossary_o_tragschienen.htm) and [wire ducts](Glossary_o_verdrahtungskanaele.htm)) and the lateral boundary [lines](Glossary_o_leitungen.htm) of the 3D body generated from the basic outline will be displayed. Disabling this setting will accelerate the output of complex 2D drilling views, but will impair the quality of the illustration of the items.
- [Legend form](properties_o_main.htm#20440)
- [Suppress generation of the enclosure legend](properties_o_main.htm#20441)
- [Model view: Frozen](properties_o_main.htm#36502)

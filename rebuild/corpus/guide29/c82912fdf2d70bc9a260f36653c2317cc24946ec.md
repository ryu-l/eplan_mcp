# Automated Processing of Write-Protected Projects

Automated processing was previously not possible for a write-protected project. With the new version it is now possible to carry out the following [actions](Glossary_o_aktionen.htm) for write-protected [projects](Glossary_o_projekte.htm) during automated processing:

- Back up data
- Print
- Export [DXF](Glossary_o_dxf.htm) / [DWG](Glossary_o_dwg.htm)
- Export manufacturing data / Labeling
- Export PDF.

If you select another action in the Settings: Automated processing dialog, a message is displayed when the dialog is closed that you cannot perform this action. Accordingly, the Run: Automated processing dialog cannot be started.

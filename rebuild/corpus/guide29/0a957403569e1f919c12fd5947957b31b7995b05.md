# New Interface for the Manufacturing Data Export to "Rittal - Wire Terminal WT"

For the export of manufacturing data there is now an interface for the [wire fabrication](Glossary_o_drahtkonfektionierung.htm) fully automatic machine Rittal - Wire Terminal WT. To this purpose the menu item Rittal - Wire Terminal WT is now available below the menu path Utilities > Manufacturing data > Wire fabrication. After selecting the menu item you move into the export dialog where you can carry out [settings](Glossary_o_einstellungen.htm) for the export of the wire fabrication data and save them as a scheme.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

The new interface can now be used to also export manufacturing data for the wire fabrication fully automatic machine "Rittal - Wire Terminal WT".

![](../Pictures/Gui/ALL/note.png)Note:

This new interface is licensed with an optional fee-based extension module. You can find specifications on this in the current performance description for EPLAN Pro Panel.

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_zusammengelegtegrafiken.htm)

### Composite graphics

User interface / operation

Items are shown graphically in the connection diagram, where the specific graphic for each item is shown. If all items of a device lie next to one another, the graphic is summarized, i.e. only the graphic of the main function is shown.

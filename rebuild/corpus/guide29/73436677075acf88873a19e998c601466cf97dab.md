# Dialog Format for automatic page description

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Master data > Form > Open > [Open]. You have opened the Form properties - <Form name> dialog (Popup menu > Properties on the [form](Glossary_o_verlauf.htm) in the Pages - <Project name> navigator dialog) and have clicked [...] in the Value field of Format for automatic page description property.

In this dialog, you can specify which page information (page name, page description, [higher-level function](Glossary_o_anlage.htm), etc.) should be automatically assigned when generating [reports](Glossary_o_auswertungen.htm) for page description.

Overview of the main dialog elements:

Available format elements:

In this column, all possible [format elements](Glossary_o_formatelemente.htm) are listed. These include:

- Page type / form type: Automatically inserts the page or form type into the page description.
- Form properties: Allows particular form [properties](Glossary_o_eigenschaften.htm) from the Property selection dialog to be adopted in the page description.
- Name of header object: Automatically inserts the header object into the page description.
- Name of first data object: Automatically inserts the first data object into the page description. (In the terminal diagram, the first data object of report page 1 could be terminal number 1, for instance, and, if 30 terminals are displayed per page, terminal number 31 is the first data object on report page 2.)
- Name of last data object: Automatically inserts the last data object into the page description. (For the terminal diagram mentioned above, terminal number 30 would be on report page 1, and terminal number 60 on report page 2.)
- Separator between header objects: Opens the Format: Separator dialog, in which a single [separator](Glossary_o_trennzeichen.htm) character or a separator text can be specified. This separator can only be defined once and is automatically added to the end of the Selected format elements list; this position cannot be changed.

Selected format elements:

The elements copied from the Available format elements list are shown here. The display includes the following columns:

- Format element: Name of the format element as in the Available format elements list
- Symbol: The symbol for the format element used in the Preview field
- Setting: Number of characters / Length of entry / Property [ID](Glossary_o_id.htm).

Preview:

In this row, the preview of elements of the Selected format elements list are shown. The abbreviations from the Setting column are used. To distinguish the Separator format element from the Separator between header objects, the "<" and ">" characters are used for the latter item, for example <[SP]> (for "space" = blank space).

# Exchange of Hose Line Data

Hose line data can be exchanged between the hose line configurator as an add-on variant of EPLAN Fluid and the hose line configurator as a stand-alone variant.

The [data exchange](Glossary_o_datenaustausch.htm) is carried out by means of a tab-separated Unicode text file (\*.txt). This exchange file can also be opened in other applications such as MS Excel, if necessary revised, stored and read back into the hose line configurator.

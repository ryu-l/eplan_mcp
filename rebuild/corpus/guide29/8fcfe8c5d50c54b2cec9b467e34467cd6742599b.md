# Dialog Edit workspace

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have changed the user interface configuration for a workspace.

- View > Workspace. Click ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit) in the Workspace dialog.
- Options > Settings > User > Display > Workspace. Click ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit) in the Settings: Workspace dialog.

In this dialog you edit a workspace.

Overview of the main dialog elements:

Template for "<...>":

This list shows all of the existing [schemes](Glossary_o_schemata.htm) for [workspaces](Glossary_o_arbeitsbereiche.htm) and displays the Name and Description [properties](Glossary_o_eigenschaften.htm) for each scheme.

Select the Current configuration entry here if you changed the user interface of the current workspace and want to make a new scheme.

If a different scheme is to be used as the template for the scheme being edited, select the corresponding name here. In this case the [settings](Glossary_o_einstellungen.htm) of the scheme being edited are overwritten by the settings of the chosen template scheme.

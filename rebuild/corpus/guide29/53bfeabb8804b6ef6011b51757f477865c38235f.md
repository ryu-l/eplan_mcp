### Visible page area

User interface / operation

The visible page area is shown in the graphical editor and output when printing or when the page is output as PDF. It is determined depending on whether a plot frame is assigned to a page: If a page does not have a plot frame, then all elements located on the page form the visible page area. If a page has a plot frame, then only those graphical elements within the plot frame constitute the visible area. Elements outside the plot frame are ignored. Texts are also always ignored, since the special texts used may extend over the edges of the plot frame.

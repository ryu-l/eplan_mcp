# Dialog Manual page sorting

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened the page navigator and opened (at least) one project. In the List tab, select the popup menu item Manual [page sorting](Glossary_o_seitensortierung.htm).

In this dialog, you define the page sorting sequence for [actions](Glossary_o_aktionen.htm) such as paging, printing, outputting of [cross-references](Glossary_o_querverweise.htm), etc. The Manual page sorting check box in the project [settings](Glossary_o_einstellungen.htm) (Options > Settings > Projects > "Project name" > Management > Pages) must be selected for this sorting to take effect. Manual page sorting only affects list views, tree views remain unchanged.

If new pages are added to the project via creation, copying, importing, etc., these are always appended to the end of the list, which must then be resorted as required.

Overview of the main dialog elements:

The pages of the open project are displayed according to the [properties](Glossary_o_eigenschaften.htm) selected in the Configure representation dialog. Any page [filters](Glossary_o_filter.htm) set are also taken into account.

The arrow buttons can be used to change the order of pages within the list. The complete row is moved in each case.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Default sorting | Resets the manually changed sorting sequence to the default. |

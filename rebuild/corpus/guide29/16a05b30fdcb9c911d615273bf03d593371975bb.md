# Reorganizing Symbol Libraries

When you reorganize a symbol library, deleted data is irretrievably removed from the project database. The database is reduced in size.

Precondition:

You have opened a project.

1. Select the following menu [items](Glossary_o_bauteile.htm): Utilities > Master data > Symbol library > Reorganize
2. Select the library to be reorganized in the Reorganize symbol library dialog and click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol library is compressed and reorganized.

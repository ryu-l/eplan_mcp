# Using Zoom Functions

The zoom [functions](Glossary_o_funktionen.htm) can be controlled using the mouse or the keyboard. An optional mouse wheel is also supported.

Precondition:

You have opened a page, [form](Glossary_o_verlauf.htm), plot frame or symbol.

### Using Window Zoom

1. Select the following menu [items](Glossary_o_bauteile.htm): View > Zoom > Window
2. Draw a box over the desired area.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected area is displayed at maximum size.

If you would like to use the keyboard, then proceed as follows:

1. Move the cursor to the upper left corner of the desired window area and press [Enter].
2. Move the cursor to the lower right corner of the desired window area and press [Enter].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected area is displayed at maximum size.

### Zoom in / out

1. Select the following menu items: View > Zoom > In or View > Zoom > Out  
     
   ![](../Pictures/Gui/ALL/arrow.png) The image section is magnified or shrunk by 10% each time.
2. Select the following menu items: View > Zoom > 100%  
     
   ![](../Pictures/Gui/ALL/arrow.png) The drawing area within the plot form is fitted to the graphical editor window.

### Zoom with the mouse

The behavior when zooming with the mouse depends on the user [settings](Glossary_o_einstellungen.htm) (Options > Settings > User > Graphical editing > 2D). There you define whether the behavior reflects that of word processing or CAD programs.

1. Scroll up / down with the mouse wheel.  
     
   ![](../Pictures/Gui/ALL/arrow.png) With the As for word processing option the visible section is moved up / down.  
     
   ![](../Pictures/Gui/ALL/arrow.png) With the As in CAD option, the page is magnified / shrunk.
2. Hold down the [Ctrl] key and scroll up / down with the mouse wheel.  
     
   ![](../Pictures/Gui/ALL/arrow.png) With the As for word processing option, the page is magnified / shrunk.  
     
   ![](../Pictures/Gui/ALL/arrow.png) With the As in CAD option, the visible section is moved up / down.
3. Hold down the [Shift] key and scroll up / down with the mouse wheel.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The visible section is moved to the left / right.

### Using the PAN Function

1. Hold down the middle mouse button and move the cursor in the desired direction.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The contents of the page are moved in the same direction.

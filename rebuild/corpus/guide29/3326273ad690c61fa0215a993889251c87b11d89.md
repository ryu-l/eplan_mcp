# Moving Property Texts

The Move property texts command activates the insertion points of the property text and these are made visible by clicking on the individual components. The text can then be moved using Drag & Drop.

The contact image can also be manually moved in this way.

Preconditions:

- You have opened a page, [form](Glossary_o_verlauf.htm), plot frame or symbol.
- The [property texts](Glossary_o_eigenschaftstexte.htm) may not be docked. Undock the texts, if necessary (by using ![](../Pictures/Gui/ALL/all_undock_as.png) ([undock](Glossary_o_abdocken.htm)) in the Display tab of the [property dialog](Glossary_o_eigenschaftendialog.htm)).

1. Select the menu item Edit > Text > Move property text.
2. Select the [component](Glossary_o_schaltzeichen.htm) whose property text you wish to move.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The element points of the property text are shown as small square frames.
3. Select a property text and move it. Make sure that any leader line that may have been set is moved as well. (Leader [lines](Glossary_o_leitungen.htm) are defined in the Display tab under Border.)  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selection will stay active until you select another property text or cancel the action.

![](../Pictures/Gui/ALL/note.png) Note:

If you hold the [Shift] key down while moving, the current [grid](Glossary_o_raster.htm) snap is "divided by four". The insertion point can then be moved in steps of a one-fourth of the grid size.

### Reset moved property texts

You can use the Reset moved property text option to delete all moved (thus copied) property texts of selected [symbols](Glossary_o_symbole.htm). The property texts are shown again which are stored in the symbol. (Each symbol contains the information which property texts are displayed by default when inserting this symbol.)

1. Select the desired elements and choose the menu item Edit > Texts > Reset moved property text.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The copied property texts of all components will be deleted, and the default property text of the symbol will be displayed.

# Displaying Hyperlinks to the Festo Website

Hyperlinks in the parts data provide access to the Festo website, which contains current documentation and technical data of the parts.

Preconditions:

- You have opened a project.
- You have installed the Festo product catalog.
- In the festo.cfg configuration file, you have defined the desired [settings](Glossary_o_einstellungen.htm) for the import.
- You have placed a suitable window macro, symbol macro, or a suitable symbol in the graphical editor and assigned this to a Festo [part](Glossary_o_artikel.htm).

1. Select the [component](Glossary_o_schaltzeichen.htm) in the graphical editor, or the function in one of the [navigators](Glossary_o_navigatoren.htm), and select Edit > Properties.
2. In the Properties <...> dialog, select the Display tab.
3. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) on the toolbar above the property list.
4. In the Property selection dialog, select the dialog Part: External document 1 [n]. You define the particular assigned part for which the property is to be displayed via the index [n]. (Multiple selection is possible.)
5. Click [OK].
6. Click ![](../Pictures/Gui/ALL/all_save_as.png) (Save) in the toolbar above the Property arrangement drop-down list, and enter a descriptive name for the property arrangement in the Save property arrangement dialog.
7. If the newly created property arrangement is to be used as a default for all other usages of these [symbol variants](Glossary_o_symbolvarianten.htm), select the Use as default check box.
8. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The [properties](Glossary_o_eigenschaften.htm) display is updated, and the hyperlinks are displayed in the graphical editor. A text in the current user interface [dialog language](Glossary_o_dialogsprache.htm), and the section number are displayed. (If there is no text available for this language, the text display remains blank).
9. Hold down the [Ctrl] key and click the hyperlink.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Festo webpage for the corresponding part opens. The Festo webpage is shown in the language that was set as the display language at the time of import. If this language is not available, then the alternative language defined in the configuration file is used.

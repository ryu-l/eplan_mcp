# Dialog Settings: Translatable pages

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Options > Settings > Projects > "Project name" > Translation > Translatable pages.

In this dialog you specify via the page type which pages are to be translated. This [settings](Glossary_o_einstellungen.htm) are stored on a project-specific basis.

The following dialog elements are available:

Page types:

This field displays all of the available page types in EPLAN. If the check box in front of the page type is selected, all pages of this type are translated. If the check box in front of the page type is deselected, pages of this type are not translated.

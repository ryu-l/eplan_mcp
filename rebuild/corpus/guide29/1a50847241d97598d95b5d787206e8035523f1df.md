# Dialog Automatic cable selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Project data > Cables > Navigator. Select multiple entries and select the Automatic cable selection popup menu item.

In this dialog you define the [settings](Glossary_o_einstellungen.htm) for automatic [cable](Glossary_o_kabel.htm) selection. Cable selection can be defined for the entire project or just for the selected cables.

Overview of the main dialog elements:

Settings:

Select a scheme to determine the settings for automatic cable selection. Use [...] to open the [Settings: Automatic cable selection](cablegui_d_einstellungenautomatischekabelauswahl.htm) dialog where you manage and edit the [schemes](Glossary_o_schemata.htm).

Only automatically generated cables:

If this check box is selected, the cable selection is only performed for automatically generated or named cables. Otherwise, the automatic cable selection will also be made for manually generated or named cables.

# EPLAN Fluid Hose Configurator: Introduction

EPLAN Fluid Hose Configurator allows hydraulic [hose lines](Glossary_o_schlauchleitungen.htm) to be defined conforming to standards, rapidly, simply and comfortably and the generated data to be created and represented graphically.

EPLAN Fluid Hose Configurator, called the "hose line configurator" below, is available both as an add-on variant and as a separate program, called the stand-alone variant below. The add-on variant is [part](Glossary_o_artikel.htm) of the standard scope of delivery for all module packages of EPLAN Fluid.

In the basic version of the hose line configurator the standard DIN 20066, Issue January 2012, [forms](Glossary_o_formulare.htm) the pre-defined standard. The hose line configurator can be used to automatically [generate](Glossary_o_erzeugen.htm) a hose line identification and a type code for each hydraulic hose and to transfer it to EPLAN Fluid for reporting purposes in accordance with the specifications of this standard.

The hose line configurator offers the following possibilities and advantages:

- Thanks to the created [type code](Glossary_o_typencode.htm) conforming to standard, clear and defined ordering of a hose line from any manufacturer or supplier is ensured.
- The program simplifies the hose line planning and thus helps to avoid errors.
- Data from the manufacturing are included automatically in the schematic and ensure norm-compliant documentation of the hose [lines](Glossary_o_leitungen.htm) ([reports](Glossary_o_auswertungen.htm)).
- If required, hose line [configurations](Glossary_o_konfigurationen.htm) can be adapted completely individually to international standards and special type codes of manufacturers.

# Tab Data for reports

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have selected a [part](Glossary_o_artikel.htm) of the "Component", "Assembly", or "Module" part type from the tree or list.

You can assign an identifier for the [main part](Glossary_o_hauptartikel.htm) of a device on this tab. These identifiers may be assigned one or more "conditional [forms](Glossary_o_formulare.htm)", thus allowing the necessary [blocks](Glossary_o_bloecke.htm) to be combined in the report.

Overview of the main dialog elements:

Identifier for reports:

Select the appropriate identifier for the [reports](Glossary_o_auswertungen.htm) from the drop-down list, or enter a new identifier manually. Please note that these identifiers are always managed in a single language. The value of this identifier can determine the subform to be reported in the main [form](Glossary_o_verlauf.htm).

Symbols:

Click [...] in the Symbol  field to select a symbol from the drop-down list. (Multiple selection isn't possible here.)

The [lines](Glossary_o_leitungen.htm) are then displayed in the format  
<Symbol library>;<Symbol library assignment in the project>;<Symbol number>;<Variant>

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

IEC\_SYMBOL;1;50;0

![](../Pictures/Gui/ALL/note.png)Note:

Take care that only the [symbols](Glossary_o_symbole.htm) of the stored [symbol libraries](Glossary_o_symbolbibliotheken.htm) are displayed.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

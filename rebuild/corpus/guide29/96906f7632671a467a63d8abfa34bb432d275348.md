# Action: XSettingsRegisterAction

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| path | File path where add-on is located. |
| installFile | Instead of the "path" specification, the complete path to the "install.xml" file can be specified via this parameter. |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Registration of the add-ons through specification of the path where the add-on is located:

```
XSettingsRegisterAction /Path:c:\MyAddOn
```

Registration of the add-ons through specification of the complete path to the "install.xml" file:

```
XSettingsRegisterAction /InstallFile: c:\MyAddOn\CFG\Install.xml
```

# Distributing Elements Evenly

Using the Space evenly command, you can position multiple selected elements equal distances from one another in the horizontal or vertical direction. This only works for elements with insertion points (texts, [symbols](Glossary_o_symbole.htm), [placed functions](Glossary_o_platziertefunktionen.htm), etc.). Simple graphical elements such as rectangles and [lines](Glossary_o_leitungen.htm) are not taken into account as expected.

Precondition:

You have opened a page, [form](Glossary_o_verlauf.htm), plot frame or symbol.

1. Select
   the respective elements and choose the Edit >
   Other > Space evenly (horizontal) or
   Edit > Other > Space evenly (vertical) menu [items](Glossary_o_bauteile.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) EPLAN determines the distance between the first
   and last element and distributes all others evenly in between.

![](../Pictures/Gui/ALL/note.png)Note:

The [grid](Glossary_o_raster.htm) is not taken into account when distributing elements; if necessary, use the Align on grid command to place the elements back onto the grid.

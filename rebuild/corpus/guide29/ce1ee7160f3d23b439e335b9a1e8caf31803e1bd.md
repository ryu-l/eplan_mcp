### Component

Electrical engineering

A component is a graphical element for the representation of a function (see [Functions](Glossary_o_funktionen.htm)). It consists of the function and symbol. The function contains the logical data and the symbol contains the graphical data. A component has a device tag, connection point designations, and so on.

# Dialog Device structure

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Page > Navigator. Select a project. Select the Properties popup menu item. Select the Structure tab. Click [...] next to one of the fields for [devices](Glossary_o_betriebsmittel.htm).
- You have selected a project management database. You have loaded directories and [projects](Glossary_o_projekte.htm). Project > Management. Select a project. Select the Structure tab. Click [...] next to one of the fields for devices.

In this dialog you can [create](Glossary_o_erstellen.htm), edit, and manage [identifier schemes](Glossary_o_kennzeichnungsschemata.htm) for identifying and numbering devices.

The following dialog elements are available:

Scheme:

This field contains the name of the current identifier scheme. Using the neighboring [Toolbar](schemeconfig_m_schemaschaltflaechen.htm) you can create new [schemes](Glossary_o_schemata.htm), save any changes to a scheme, and copy or delete schemes. Schemes can also be imported or exported.

Description:

The description of the identifier scheme is displayed in this field. Enter the description in the Description field of the New scheme dialog.

Table:

In the table you specify which [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) are identifying, describing or not available for the device structure.

- Structure: Lists the identifier [blocks](Glossary_o_bloecke.htm) which correspond to the device structure. The adjacent column displays the associated preceding signs.
- Value: In this column you use the drop-down list to specify whether the identifier block is identifying, describing or not available.

# Dialog Change password

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Utilities > Rights management > Users. In the Rights management: Users dialog, select the Users folder in the field at the left and select a user name in the list at the right. Click [Change password].
- You are using the "Logon" operating mode. Start EPLAN. in the Log on to EPLAN dialog, click [Change password].

In this dialog, you can change the password that you use to log on to EPLAN. When calling up this dialog from the [rights management](Glossary_o_rechteverwaltung.htm), administrators can assign a new password to a user if (e.g.) they have forgotten their password.

The following dialog elements are available:

Name:

This field displays the user name.

Old password:

Enter your existing password here. To ensure protection of your input, the password is not displayed in plain text but rather as \* characters.

When you have called up this dialog from the rights management, this field is grayed out and cannot be edited.

New password:

Enter your new password here. To ensure protection of your input, the password is not displayed in plain text but rather as \* characters.

Confirm new password:

To avoid typing errors on entry, you must enter the new password a second time in this field. Only then will EPLAN accept the password.

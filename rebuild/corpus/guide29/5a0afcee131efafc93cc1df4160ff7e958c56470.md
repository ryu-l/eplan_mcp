# Numbering of Unplaced Main Functions

With [offline numbering](Glossary_o_offlinenummerieren.htm), you can use a numbering format which contains the [format elements](Glossary_o_formatelemente.htm) "Page" and / or "Column" or "Row". If the main function is placed, the placement [component](Glossary_o_schaltzeichen.htm) of the DT is formed by default from the placement information of the associated main function.

If the main function is unplaced, it contains no placement information, e.g. :

- Terminal strips: The main function "Terminal strip definition" is unplaced, the [auxiliary functions](Glossary_o_nebenfunktionen.htm) "Terminals" are placed.
- Plugs: The main function "Plug definition" is unplaced, the auxiliary [functions](Glossary_o_funktionen.htm) "Male and [female pins](Glossary_o_steckerbuchsen.htm)" are placed.

If in this case, you use a numbering format with the format elements "Page" and / or "Column" or "Row", the placement component of the DT is formed from the placement information of the terminal placed graphically first or the plug placed graphically first.

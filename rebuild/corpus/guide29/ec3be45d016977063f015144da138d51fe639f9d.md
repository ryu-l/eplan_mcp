# P026081: Error while placing a fitting: <x>

### Cause

A fitting <x> could not be placed while routing a hose line. This may have the following causes:

- The entry for the graphical macro of the fitting may be missing in the parts data.
- The entry is incorrect in the parts data.
- The required graphical macro of the fitting does not exist.

### Solution

1. Locate the source of the routing connection in the [layout space](Glossary_o_bauraum.htm) using the Go to (graphic) function provided by the popup menu in the Message management dialog.
2. Use the popup menu item Go to (counterpiece) to jump to the source in the schematic.
3. Determine the hose line connected to the source in the schematic.
4. Call the [property dialog](Glossary_o_eigenschaftendialog.htm) of the hose line and bring the Parts tab to the front.
5. Check whether a graphical macro is stored in the [part](Glossary_o_artikel.htm) selection (Mounting data tab) for the two fittings of the hose line and check whether this entry is correct. Also check whether the required graphical macro exists for both fittings.
6. If no graphical macro or an incorrect one is specified in the part selection, carry out the corresponding correction or addition in the parts management. If the graphical macro does not exist, add it in the corresponding macro directory.
7. Carry out a check run (any check run scheme set) to delete the module-specific message from the dialog of the message management.
8. Route the hose line again.

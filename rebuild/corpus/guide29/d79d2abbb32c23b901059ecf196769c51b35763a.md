# Changing a Curve Run

The [form](Glossary_o_verlauf.htm) of curves can be changed manually by moving control points.

1. Select the Edit > Graphic > Change curve run menu [items](Glossary_o_bauteile.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The status bar displays the prompt "Select freely routed connection or curve".
2. Select a curve in the [layout space](Glossary_o_bauraum.htm) or in the layout space navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The status bar shows the prompt "Select control point of the curve".  
     
   ![](../Pictures/Gui/ALL/arrow.png) The existing control points are displayed as blue cuboids on the curve run.
3. Move the cursor close to a control point.  
     
   ![](../Pictures/Gui/ALL/arrow.png) At the control point, a coordinate system with X, Y, and Z direction arrows is displayed.  
     
   ![](../Pictures/Visualisation/ALL/routing_modcurveform1_as.png)
4. Move the cursor on one of the three direction arrows.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The direction arrow touched by the cursor changes its color to green.  
     
   ![](../Pictures/Visualisation/ALL/routing_modcurveform2_as.png)
5. Click the green direction arrow, and use it to move the control point in the direction indicated by the arrow.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The curve run changes with the movement of the control point.  
     
   ![](../Pictures/Visualisation/ALL/routing_modcurveform3_as.png)
6. If you want to move the control point into another direction, select another direction arrow in the same coordinate system.
7. Place the control point by clicking on the desired position.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The curve run is displayed in the changed state.  
     
   ![](../Pictures/Gui/ALL/arrow.png) You can then change further control points.  
     
   ![](../Pictures/Visualisation/ALL/routing_modcurveform4_as.png)

# Synchronize stored parts with the parts database

Stored [part](Glossary_o_artikel.htm) [properties](Glossary_o_eigenschaften.htm) are a fixed [component](Glossary_o_schaltzeichen.htm) of the project, while non-stored properties must be accessed through parts management.

The configuration of commercial data for part selection also applies to device selection, i.e., there is only one common configuration.

### Update parts in project

Utilities > Parts > Update current project

  

![](../Pictures/Gui/ALL/arrow.png) The parts stored in the project are updated with data from the internal parts database. In addition the newer device data is transfered to the [main functions](Glossary_o_hauptfunktionen.htm) that are using these parts.  
  
![](../Pictures/Gui/ALL/arrow.png) Any messages are written to message management.

### Synchronizing parts

1. Select the following menu [items](Glossary_o_bauteile.htm): Utilities > Parts > Synchronize current project  
     
   ![](../Pictures/Gui/ALL/arrow.png) The [Synchronization of parts - <Project name>](partsextensiongui_d_artikelabgleich.htm) dialog is opened.
2. Select the required filter from the Filter drop-down list. You can either display the parts that are different in the project and / or [system master data](Glossary_o_systemstammdaten.htm) or only the older [project master data](Glossary_o_projektstammdaten.htm) or only the older system [master data](Glossary_o_stammdaten.htm).
3. In the Stored parts list highlight the parts that you want to carry over to the system master data and click the arrow button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts stored in the [projects](Glossary_o_projekte.htm) are carried over to the internal parts database. During this process, the [function templates](Glossary_o_funktionsschablonen.htm) of the [stored parts](Glossary_o_eingelagerteartikel.htm) are stored into the parts in the internal database.
4. In the System parts list highlight the parts that you want to store in the project and click the arrow button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected parts are stored in the project. In addition the newer device data is transfered to the main [functions](Glossary_o_funktionen.htm) that are using these parts.

![](../Pictures/Gui/ALL/warning.png)Warning:

When carrying over the stored parts to the system master data, only the parts not yet available in the parts database are synchronized. Already existing parts are not updated.

![](../Pictures/Gui/ALL/info.png)Tip:

You can replace all of the out-of-date stored parts with newer system parts via [Extras] > Update current project.  
You can complete all of the system master data stored in the project that are not yet available in the system via [Extras] > Complete current system.

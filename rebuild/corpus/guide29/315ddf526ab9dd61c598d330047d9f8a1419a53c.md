# Finding and Replacing Identifiers

The "find and replace" functionality in [structure identifier management](Glossary_o_strukturkennzeichen_verwaltung.htm) makes it possible to search through the table of [structure identifiers](Glossary_o_strukturkennzeichen.htm) in the List tab for existing data and then to replace it if needed. The search always takes place within a single (selected) column, and only downwards. If everything is selected, the search is limited to the Line column.

![](../Pictures/Gui/ALL/note.png)Note:

Please note that only the identifying and not the complete DT is taken into account when searching!

Precondition:

You have selected a project in which [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) are used in the [project structure](Glossary_o_projektstruktur.htm), for instance "Higher-level function" and "Mounting location".

1. Project data > Structure identifier management
2. Select the List tab in the dialog Structure identifier management - <Project name>.
3. Select the column to which the search is to apply by clicking the column header.
4. Click [Extras] > Find.
5. In the Replace dialog, enter the search terms and replacement text.
6. Select the Match case check box if upper and lower case should be taken into account during the find and replace.
7. Use the buttons to execute the find and replace.
8. If an illegal character is found (configuration under Options > Settings > Projects > "Project name" > Devices > DT syntax check), you decide in the DT syntax checking dialog how the corresponding structure identifier should be handled.
9. Click [Apply].
10. Answer the prompt.

![](../Pictures/Gui/ALL/note.png)Notes:

- Searching is always performed only in one column and always downwards, and replacement is limited to the Designation and Structure description columns.
- By default, the string in the currently-selected field is entered in the Find what field; in the case of a multiple selection, it is the content of the last-selected field.

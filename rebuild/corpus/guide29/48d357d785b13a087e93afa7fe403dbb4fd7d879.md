# Embedded Reports

An embedded report is a report you have manually placed in an existing project page (I). No [report pages](formgeneratorgui_k_auswertungsseiten.htm) are generated. Project data can be output as [embedded reports](Glossary_o_eingebetteteauswertungen.htm) when you have selected "Manual placement" as the output format when generating the [reports](Glossary_o_auswertungen.htm). You can place the report at any position in the project page. When updating reports, embedded reports are also updated.

![](../Pictures/Gui/ALL/note.png)Notes:

- When copying and pasting [devices](Glossary_o_betriebsmittel.htm) and the associated function-related embedded reports, the relationship is retained between the devices and a function-related embedded report that has also been copied. The same applies to creating relevant [macros](Glossary_o_makros.htm) with function-related, embedded reports. Pasting directly updates the embedded report. The device to which it applies is then immediately obvious.
- You can only select the "Manual placement" output type for the embedded report when the desired project page is open in the graphical editor.

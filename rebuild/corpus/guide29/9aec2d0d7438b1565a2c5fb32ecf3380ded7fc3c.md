# Project Correction

In the course of project planning, [project data](Glossary_o_projektdaten.htm) are often generated which have to be corrected when planning is finished. Therefore you can start correction runs that automatically correct specific errors at specific data (terminals, [plugs](Glossary_o_stecker.htm), etc.). Only multi-line [functions](Glossary_o_funktionen.htm) are taken into account here.

- You can decide what project data should be corrected.
- Project data are compressed for the entire project. You can define a filter to exclude project data from the correct or to correct only selected hierarchy [levels](Glossary_o_etagen.htm).
- The [settings](Glossary_o_einstellungen.htm) for the scope of correction are stored in [schemes](Glossary_o_schemata.htm). This allows you to save the settings you use most often for easy reuse.

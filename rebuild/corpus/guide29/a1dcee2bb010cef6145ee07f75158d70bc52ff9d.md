# Detection of Multilingual Fields

A multilingual input is possible for many [properties](Glossary_o_eigenschaften.htm) and entry fields in the project or parts management. Such multilingual texts can be translated automatically or manually. Fields for which a multilingual input is possible are now marked by default by a preceding icon in the user interface.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

With the new [icons](Glossary_o_icons.htm) it is instantly obvious in which fields a multilingual input is possible. In addition it is obvious whether a text is language-neutral or has already been translated.

| Icon | Meaning |
| --- | --- |
|  | The contents of the field are language-neutral (this means no language is assigned) or empty. |
|  | The contents of the field are language-dependent. In this case the Remove translation popup menu item is active. |

If you enter a text into a multilingual field it is initially language-neutral. This means the text is not assigned to a language and is displayed - as it was entered - independently of the selected source language. For a translation the text is assigned to the current source language and to a language-dependent text.

### Setting option for displaying the icons

In the user [settings](Glossary_o_einstellungen.htm) you can individually set the display of the icons for multilingual fields. To this purpose the new Identify multilingual input fields group box with the following options is available to you in the Settings: User interface dialog (menu path: Options > Settings > User > Display > User interface):

- Always show icons: All multilingual input fields are identified. The identification is made independent of whether input in the field is possible or the field only serves as a display.
- Only show icons for editable input fields: Only those multilingual fields are identified in which an entry is possible.
- Never show icons: Multilingual input fields are not identified.

As a default only the input fields to be edited are identified. If no icon is displayed for a field, even if the Always show icons option is activated, this is not a multilingual field.

# Dialog Insertion mode

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have selected the With prompt option under Options > Settings > Projects > "Project name" > Devices > Numbering (online).

- You have inserted schematic elements into the Clipboard using Edit > Copy or Edit > Cut. Edit > Paste.
- You have opened a page in the graphical editor and selected an element. Edit > Duplicate. Place the first copy of the element to be duplicated. Select the number of copies from the Duplicate dialog and click [OK].
- You have opened a page in the graphical editor. Insert > Symbol macro.

In this dialog you define the manner in which [devices](Glossary_o_betriebsmittel.htm) are to be numbered on insertion. The dialog is opened when you insert a copied or cut schematic element or macro into a schematic page. Which device types (e.g. plug, [cable](Glossary_o_kabel.htm), or general device) are numbered depends on the numbering formation you specified in the Numbering format field.

Overview of the main dialog elements:

Do not modify:

If this option is selected, then the displayed DT remains unchanged. The counter is not incremented. The full DT receives the structure identifier of the page if the original displayed DT did not contain a structure identifier.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

| Displayed DT of device source | New displayed DT for the copied device |
| --- | --- |
| -F1 | -F1 |
| -F2 | -F2 |
| -F3 | -F3 |

Components with the same names are displayed in the message management if the following applies:

- The components are [main functions](Glossary_o_hauptfunktionen.htm) and have the same DT.
- The components are [functions](Glossary_o_funktionen.htm) having the same DT and the same connection point designation.

Number:

If this option is selected, then the inserted devices are renumbered. The specified numbering format is taken into consideration here.

The starting value for the DT counter is the first free counter of the appropriate identifier.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

| Displayed DT of device source | New displayed DT for the copied device |
| --- | --- |
| -F1 | -F23 |
| -F2 | -F24 |
| -F3 | -F25 |

Number with flag "?":

If this option is selected, then the inserted devices are automatically renumbered on insertion and tagged with a question mark. The specified numbering format is taken into consideration here.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

| Displayed DT of device source | New displayed DT for the copied device |
| --- | --- |
| -F1 | -?F23 |
| -F2 | -?F24 |
| -F3 | -?F25 |

Numbering format:

Shows the [online numbering](Glossary_o_onlinenummerieren.htm) format that you selected in the global [settings](Glossary_o_einstellungen.htm) under Options > Settings > Projects > "Project name" > Device > Numbering (online) in the group box On insertion of macros and copies in the field Numbering format. From the drop-down list, you can select a different online numbering format or go to [...] and [create](Glossary_o_erstellen.htm) a new one. This setting will be adopted in the global settings. In [numbering formats](Glossary_o_nummerierungsformate.htm), you specify which [format elements](Glossary_o_formatelemente.htm) are to be used and which device types are to be taken into consideration during numbering.

Number prefix if existing:

This field is available if the Number option is selected.

This setting allows numbering of the prefix of the DTs of inserted device copies or inserted devices in [macros](Glossary_o_makros.htm). This functionality only affects device groups for which the Keep prefix numbering format setting in the DT format dialog is selected, that you can access via Options > Settings > Projects > "Project name" > Devices > Numbering (online).

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The Keep prefix setting is activated. You have copied the M1 device source and inserted the copy 5 times into the project page.

|  | "Number prefix if existing" is selected | "Number prefix if existing" is deselected |
| --- | --- | --- |
| Device source | M1 | M1 |
| New copied devices | 1M1, 2M1, 3M1, 4M1 | M1, M2, M3, M4 |

The Keep prefix setting is activated. You have copied the 3M1 device and inserted the copy 5 times into the project page.

|  | "Number prefix if existing" is selected | "Number prefix if existing" is deselected |
| --- | --- | --- |
| Device source | 3M1 | 3M1 |
| New copied devices | 4M1, 5M1, 6M1, 7M1 | 3M2, 3M3, 3M4, 3M5 |

Number circuit number if existing:

If the Fluid power: Use trade identifier as identifier (media code) check box has been activated in the project settings, the Number circuit number if existing field is displayed instead of the Number prefix if existing field for [fluid power](Glossary_o_fluidtechnik.htm) functions. This setting allows numbering of the circuit number (this corresponds to the counter) of the DTs of inserted device copies or inserted devices in macros.

Always use this insertion mode:

If this check box is selected, then the selected insertion mode is used for all subsequent insertion [actions](Glossary_o_aktionen.htm). The Insertion mode dialog is no longer displayed. You can reactivate the Insertion mode dialog by using Options > Settings > Projects > "Project name" > Devices > Numbering (online) to select the With prompt option.

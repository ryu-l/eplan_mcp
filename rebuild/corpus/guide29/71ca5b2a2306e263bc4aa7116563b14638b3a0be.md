# P020027: First project:<x> - Second project:<y>

### Description

You have run a project comparison, checking the [settings](Glossary_o_einstellungen.htm), [properties](Glossary_o_eigenschaften.htm) or [layers](Glossary_o_ebenen.htm) of the test project (incoming project) against those of the comparison project.

This message shows the path and name of the project to be compared. The first project <x> is the test project, the second project <y> is the comparison project.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

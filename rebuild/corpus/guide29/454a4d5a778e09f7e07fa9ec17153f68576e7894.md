# P005073: Different connection point cross-section / diameter of targets

### Cause

With the indexed property Connection point cross-section / diameter (all, depending on DT adoption) on a function, it is possible to specify a cross-section or diameter for each connection point.

In this case, the [connection points](Glossary_o_anschluesse.htm) of the targets (target [functions](Glossary_o_funktionen.htm)) connected to a function have different cross-sections or diameters.

### Solution

1. Enter the same value for the connection point cross-section or diameter on the targets (target functions).
2. Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

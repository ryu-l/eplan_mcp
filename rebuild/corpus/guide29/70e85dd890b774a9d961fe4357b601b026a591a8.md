# Action: XTranslateSourceLanguage

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| PROJECTNAME | Project name with complete file path (optional). If nothing is entered, the selected project will be used if the action is to be run over the user interface (e.g. via script or the toolbar). When executing from the Windows command line, PROJECTNAME must be specified or ProjectAction has to be used before that. |
| SOURCELANGUAGE | Specification of the source language, for example en\_US. |

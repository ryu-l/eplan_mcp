# Tab Drilling pattern frame

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have inserted a drilling pattern frame by using the menu item Insert > Box / connection point / mounting panel > Drilling pattern frame, or you have double-clicked an existing drilling pattern frame.

In this tab you define the drilling pattern frame [properties](Glossary_o_eigenschaften.htm). This is only possible in a macro project. In a schematics project most of the fields serve only to display data and cannot be changed.

Overview of the main dialog elements:

Group box General

Name:

This field can only be edited in the macro project! Enter the name of the drilling pattern frame and, if necessary, the path here. This name is then used for the file name of the drilling pattern to be generated. Without specifying a name you cannot [create](Glossary_o_erstellen.htm) a drilling pattern.

This field is automatically filled in a schematics project and cannot be edited.

Description:

This field can only be edited in the macro project! The text entered here becomes the description text of the drilling pattern automatically generated from the macro project and is displayed in a [comments](Glossary_o_kommentare.htm) field when the respective drilling pattern is inserted.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Subdirectory for outline (NC data):

Storage location for \*.fc1 files (outline NC data) that are created automatically during the creation of a drilling pattern. The default directory is the directory for [macros](Glossary_o_makros.htm) ($MD\_MACROS).

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).

Manual object assignment:

Normally, all [objects](Glossary_o_objekte.htm) located in a drilling pattern frame belong to one drilling pattern. In a macro project you can change this object assignment.

Select this check box if you would like to add an object outside of the box as well, for example. You then have to mark all the objects that are to belong to the drilling pattern and select the Assign objects to the drilling pattern frame function in the popup menu of the drilling pattern frame. If the check box is again deselected, the original object assignment in the drilling pattern is restored.

In a schematics project you cannot change the check box selection!

Group box Point of origin

X position / Y position:

If the Active check box is selected, the default values for the handle position are first displayed here. You cannot change these values.

Active:

The default position of the point of origin is at the bottom left of the drilling pattern frame.

If this check box is selected, the default point of origin is displayed and you can change it. The X-position and Y-position fields are enabled and you can overwrite the default values. After closing the dialog with [OK] the point of origin is indicated on the page with a special graphical symbol.

If the check box is deselected, no entries can be made in the X position and Y position fields and the point of origin is also no longer displayed. If you reselect the check box the point of origin is reset to its default position.

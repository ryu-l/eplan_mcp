# Formatting Settings for Actions in Toolbars

Using some [actions](Glossary_o_aktionen.htm) which you can store as buttons on [toolbars](Glossary_o_symbolleisten.htm), you have the option of setting the formatting [settings](Glossary_o_einstellungen.htm) of components, texts, graphical elements, or connection and [potential definition points](Glossary_o_potenzialdefinitionspunkte.htm) to exactly determined values. The available settings are the same as those that can be made in the individual property dialogs on the Display, Format and Connection graphic tabs.

For the formatting of [properties](Glossary_o_eigenschaften.htm), the following actions are available:

- Set [component](Glossary_o_schaltzeichen.htm) format (action name: XGedIaFormatSymbol)
- Set text format (action name: XGedIaFormatText)
- Set format of graphical elements (action name: XGedIaFormatGraphic)
- Set graphical format of [connections](Glossary_o_verbindungen.htm) (connection definition point, potential definition point) (action name: XGedIaFormatDefPoints).

In the following table, all possible parameters of these actions are listed. The exact syntax for each action can be seen in the example entry on the command line. This sample entry is shown in the Configure button dialog when you add a button with an action to a toolbar. If a property should not be changed, then leave the corresponding question mark "?" on the command line alone.

The following parameters are possible on the command line for the formatting settings:

| Command line parameters | Meaning | Values |
| --- | --- | --- |
| /height:? | Font size | Numeric values in "mm" or in "In" (Inch). With the value "-16002", the "From layer" setting will be applied. |
| /color:? | (Text or line) Color | The predefined values are:   - 0 = black - 1 = red - 2 = yellow - 3 = green - 4 = cyan - 5 = blue - 6 = magenta - 7 = black - 8 = white - 9 = light gray - 252 = dark gray - 253 = gray - -16002 = from layer.   However, other values can also be specified in the [Color selection](mf_d_farbauswahl.htm) dialog. Values from 0 to 256 are possible. The color values are displayed in the color selection [tooltips](Glossary_o_quickinfos.htm). |
| /justification:? | (Text) Alignment | The following values are possible:   - 1 = upper left - 2 = upper center - 3 = upper right - 4 = center left - 5 = middle centered - 6 = center right - 7 = bottom left - 8 = bottom centered - 9 = bottom right - 10 = basis left - 11 = basis center - 12 = basis right - 13 = special left  (special alignment type for [path function texts](Glossary_o_pfad_funktionstexte.htm) in DIN and USA [projects](Glossary_o_projekte.htm)) - 14 = special centered  (should not be used for new projects; needed only for reasons of compatibility with EPLAN 5) - 15 = special right - 16 = JIC special left  (special alignment types for path [function texts](Glossary_o_funktionstexte.htm) in JIC projects) - 17 = JIC special center   (should not be used for new projects; needed only for reasons of compatibility with EPLAN 5) - 18 = JIC special right. |
| /angle:? | Angle to the X-axis by which the text should be rotated in the counter-clockwise direction. | The following values are possible:   - 0 - 45 - 90 - 135 - 180 - -45 - -90 - -135.   Angle specifications are always in degrees. The "°" character need not be specified, but may be. |
| /font:? | Font | The values for fonts 1-10 can be determined under the Options > Settings > Company > Graphical editing > Fonts menu [items](Glossary_o_bauteile.htm). The following values are possible:   - 0 = Font 1 in the company settings - 1 = Font 2 in the company settings - 2 = Font 3 in the company settings - 3 = Font 4 in the company settings - 4 = Font 5 in the company settings - 5 = Font 6 in the company settings - 6 = Font 7 in the company settings - 7 = Font 8 in the company settings - 8 = Font 9 in the company settings - 9 = Font 10 in the company settings. |
| /visible:? | Invisible (text or line invisible / visible) | The following values are possible:   - 0 = invisible - 1 = visible. - 2 = from layer. |
| /bold:? | Font style / Bold | The following values are possible:   - 0 = normal - 1 = bold. |
| /italic:? | Font style / Italic | The following values are possible:   - 0 = normal - 1 = italic. |
| /underline:? | Font style / Underlined | The following values are possible:   - 0 = normal - 1 = underlined. |
| /showtextbox:? | Draw text box | The following values are possible:   - 0 = don't show text box - 1 = show text box as rectangle - 2 = show text box as ellipse - 3 = from layer. |
| /graphic:? | Graphic | The following values are possible:   - 0 = don't show graphic - 1 = show graphic as rectangle - 2 = show graphic as ellipse. |
| /setframeactive:? | Activate alignment box | The following values are possible:   - 0 = deactivate settings for alignment box - 1 = activate settings for alignment box. |
| /showframe:? | Draw alignment box | The following values are possible:   - 0 = don't show alignment box - 1 = show alignment box. |
| /framewidth:? | Width of the alignment box | Numeric values in "mm" or in "In" (Inch) |
| /frameheight:? | Height of the alignment box | Numeric values in "mm" or in "In" (Inch) |
| /adjustframe:? | Fit (alignment box) | The following values are possible:   - 1 = don't fit - 16 = Text: Fixed width, never hyphenate words - 32 = Text: Fixed height, never hyphenate words - 64 = Hyphenate words - 80 = Text: Fixed width, hyphenate words - 128 = Remove breaks - 144 = Text: Fixed width, never hyphenate words, remove breaks - 208 = Text: Fixed width, hyphenate words, remove breaks. |
| /width:? | Line thickness | Numeric values in "mm" or in "In" (Inch). With the value "-16002", the "From layer" setting will be applied. |
| /type:? | Line type | The following values are possible:   - 0 = solid - 1 = dashed - 2 = dotted - 3 = dash-dot - 4 = dash-dot-dot - 5 = dash-2 short dashes - 6 = long dash-dot - -16002 = from layer. |
| /patternlength:? | Pattern length | Numeric values in "mm" or in "In" (Inch). With the value "-16002", the "From layer" setting will be applied. |
| /sizefromsettings:? | Size from project setting | The following values are possible:   - 0 = switched off - 1 = switched on. |
| /leaderline:? | Activate leader line | The following values are possible:   - 0 = switched off - 1 = switched on. |
| /lineendstyle:? | Line end style | The following values are possible:   - 0 = round - 1 = rectangular - 2 = flat - 32 = from layer. |
| /filled:? | Fill surface | The following values are possible:   - 0 = graphical element is not filled - 1 = graphical element is filled. |
| /rounded:? | Rounded (only applies to rectangles) | The following values are possible:   - 0 = corners of the rectangle will not be rounded - 1 = corners of the rectangle will be rounded. |
| /radius:? | Arc Radius (only applies to rounded rectangles; fillet radius of the corners) | Numeric values in "mm" or in "In" (Inch) |
| /language:? | Language (as on the Display / Format tab in the Property dialog); only for the 'Set component format' and 'Set text format' actions | The following values are possible:   - AllLanguagesColumn = All displayed languages (arrange horizontally) - AllLanguagesRow = All displayed languages (arrange vertically) - OneLanguageVariable = One language (variable) - 'de\_DE', 'en\_US', ... = Specify the language |
| /propertyId:? | Identifier of a component property to be defined (= Property number)   - If this parameter is used, all format modifications are only performed for the [property texts](Glossary_o_eigenschaftstexte.htm) of the one specified property of the component. - If this parameter is not used, the format modifications are performed for the property texts of all placed properties. | 5-digit number |
| /propertyIndex:? | The index, if the property has indices; usually 0 |  |
| /linespacing:? | Row spacing | Numeric values. The value "1" corresponds, e.g., to single row spacing, value "2" is double spacing, etc. |
| /paragraphspacing:? | Paragraph spacing | Numeric values in "mm" or in "In" (Inch) |
| /layer:? | Layer | Layer name (e.g. "EPLAN501") |
| /donttranslate:? | Do not translate automatically (as in the Text tab in the Property dialog); only for the "Set text format" action | The following values are possible:   - 1 = Text is not automatically translated. - 0 = Text is translated. |

![](../Pictures/Gui/ALL/note.png)Note:

Size values such as those for the Font size or Line thickness fields may be entered in 'mm' or 'In' (inches). If no unit is specified for a value, the displayed measuring unit set in the properties (Options > Settings > User > Display > Displayed units of measure) will be used in the user interface settings.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The following values are to be set for certain texts: Font size: 10 mm, Color: Green, Angle: -90°. In addition an alignment box with the following values is to be shown: Width: 45 mm, Height: 20 mm. Then the entry in the command line looks as follows:

XGedStartInteractionAction /Name:XGedIaFormatText /height:10mm /color:3   
/angle:-90 /setframeactive:1 /showframe:1 /framewidth:45mm /frameheight:20mm

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

For certain graphical elements, the line thickness should be set to 5.5 mm and the graphic filled with cyan. The graphical elements should always be visible. Then the entry in the command line looks as follows:

XGedStartInteractionAction /Name:XGedIaFormatGraphic /width:5,5mm /color:4 /visible:1

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You want to change the function text and other placed property texts for specific components on a schematic page to French. Then the entry in the command line looks as follows:

XGedStartInteractionAction /Name:XGedIaFormatSymbol /language:fr\_FR

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

In the case of certain components on a schematic page, only the function text of all placed properties is to be assigned the color "Red". Then the entry in the command line looks as follows:

XGedStartInteractionAction /Name:XGedIaFormatSymbol /color:1 /propertyId:20011

If the parameter /propertyId is not specified in the command line, all property texts of the selected components receive the color "Red".

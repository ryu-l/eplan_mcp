# Combining the PDF Comments in the PDF Files

You merge PDF [comments](Glossary_o_kommentare.htm) when you have sent a PDF file for commenting and receive the commented PDF file back.

Preconditions:

- You are a [Project editor](redlining_k_projektkommentator.htm#Projektbearbeiter).
- You have Acrobat Professional 7.0 / Acrobat Standard 7.0 installed and open.
- [Output pages as PDF files](pdfexportgui_h_seitenexportieren.htm)
- [Send PDF file for checking](redlining_h_permailversenden.htm) or [Release PDF file for commenting](redlining_h_freigabe.htm)
- You have received a PDF file containing PDF comments from a project redliner.

1. File > Open
2. In the subsequent dialog, select the PDF file containing PDF comments and click [Open].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The dialog for merging comments opens.
3. Click [Yes].

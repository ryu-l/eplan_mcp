# Dialog Conditional forms

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project and a dynamic [form](Glossary_o_verlauf.htm) (via the Utilities > Master data > Form > Open > [Open] menu [items](Glossary_o_bauteile.htm), for example). Insert > Conditional forms. You have placed the conditional form. Double-click the form symbol.

The [forms](Glossary_o_formulare.htm) used for generating [reports](Glossary_o_auswertungen.htm) for certain filter criteria, are specified in this dialog. The forms are in a list, grouped according to the filter criteria. If several forms have the same filter criteria, they are combined in a section between two [lines](Glossary_o_leitungen.htm).

Overview of the main dialog elements:

Form name:

If forms have already been specified, their names will be shown in this list. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) to select a suitable form from the Select form dialog. Only forms with the same file type as the "main form" qualify as "suitable".

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You have opened the form for a terminal diagram in the form editor. The Select form dialog then only offers forms of the "terminal diagram" type.

If the list contains several forms with different conditions, these forms are displayed in groups and, if the condition changes, separated by a line.

---

Table

In this table, you specify filter criteria for the forms. The individual lines are AND-combined by default.

Value:

Here you enter the comparison value that is to be compared to the selected property. You can use [placeholders](searchandreplacegui_k_platzhalter.htm) (such as "\*" or "?"). Entry of several values within a cell (separated by semicolons) indicates an OR operation.

With some [properties](Glossary_o_eigenschaften.htm), you can use [...] to open a selection dialog. If, for example, you selected a structure identifier as the criterion, the selection dialog will contain the values of this structure identifier as they appear in the project.

In fields representing a directory, you can enter the "\*" wildcard; all subdirectories in the selection are then included.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

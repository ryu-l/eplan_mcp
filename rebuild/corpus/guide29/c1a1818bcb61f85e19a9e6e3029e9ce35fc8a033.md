# P501025: Part properties 'PLC type designation' or 'Device description: File name' are empty

### Cause

In the parts database to be checked a PLC [part](Glossary_o_artikel.htm) was determined where a value was stored neither for the PLC type designation property nor for the Device description: File name property.

The check run message is also output when the part is not a PLC device and disposes of a function template with the function definition "Network / bus [cable](Glossary_o_kabel.htm) connection point".

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective part is already marked in it.
2. Bring the Properties tab to the front.
3. Enter a value either in the PLC type designation field and / or the Device description: File name field.
4. Close the parts management, save the modified data, and carry out a parts synchronization.
5. Then start a new check run.

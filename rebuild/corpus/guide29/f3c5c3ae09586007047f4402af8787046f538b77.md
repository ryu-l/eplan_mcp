# P028015: Segment with a '<x>' segment definition that is not to be used anymore

### Cause

There is a segment definition <x> in the project that has been assigned the "Do not use anymore" setting. You have either made this setting as an authorized user, or the segment was inserted via a macro.

### Solution

1. Locate the segment definition in the pre-planning navigator using the Synchronize selection function offered by the popup menu in the Message management dialog.
2. As an authorized user, validate the segment definition to be used, or select another segment definition for the segment.
3. Then start a new check run.

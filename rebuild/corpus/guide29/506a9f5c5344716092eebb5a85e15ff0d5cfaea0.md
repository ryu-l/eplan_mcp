# Generating Forms

When generating a [form](Glossary_o_verlauf.htm), the Form properties - <Form name> dialog is opened, in which you specify the most important [properties](Glossary_o_eigenschaften.htm) of the new form. (This dialog can also be called up for an opened form after the event to allow you to change the properties at any time).

Precondition:

You have opened a project.

1. Utilities > Master data > Form > New
2. In the Create form dialog, select the drive and directory, in which the new form should be saved.
3. In the File name field, enter a descriptive name for the form.
4. From the Filetype drop-down list, select the form type (e.g. table of contents, [cable](Glossary_o_kabel.htm) diagram, etc.) that you want to [create](Glossary_o_erstellen.htm).
5. In the Path field, select the Go to default popup menu item if you would like to [return](Glossary_o_zurueckbuchen.htm) to the default [settings](Glossary_o_einstellungen.htm) for drive and directory. (The default directory is either the program-specific default setting <Program Drive>:\<Program Directory>\Forms\<Company Code> or the setting specified under the Options > Settings > User > Management > Directories menu [items](Glossary_o_bauteile.htm).)
6. Click [Save].
7. If necessary, select a different form type for the new form from the Form type drop-down list in the Form properties - <Form name> dialog.
8. Specify the values for the properties by either entering or overwriting an entry or selecting a template value from a drop-down list, or jump to a special dialog in which you can enter additional data.
9. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new form is stored according to your entries. The file extension depends on the form type selected and is displayed in the form editor.

If necessary, you can check the form during editing to quickly be made aware of and to immediately resolve incorrect entries.

![](../Pictures/Gui/ALL/info.png)Tip:

You can use Drag & Drop to insert existing [forms](Glossary_o_formulare.htm) by pulling a marked form from Windows Explorer into the Pages <Project name> navigator dialog of your project.

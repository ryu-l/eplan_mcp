# P022017: The project contains excessive field length values in the database: <x>

### Cause

A number of identifiers, numbers, and [designations](Glossary_o_bezeichnungen.htm) in EPLAN [projects](Glossary_o_projekte.htm), such as the device tag, are managed by different databases. In individual cases, the input of very long sequences of letters and / or numbers can result in a cap on information in one of the databases and thus produce incorrect results.

### Solution

Reorganize the project.

1. Select the menu [items](Glossary_o_bauteile.htm) Project > Organize > Reorganize.
2. In the Reorganize project dialog, activate the Advanced mode check box, click [Yes], and wait until the reorganization process is completed.
3. Then, start a new check run for the entire project.

![](../Pictures/Gui/ALL/note.png)Note:

The default field lengths of the identifying components of the device tag are often asked for.

Note that EPLAN supports the following number of characters:

- 16 characters for the prefix
- 16 characters for the identifier
- 64 characters for the counter
- 16 characters for the subcounter.

Keep the device tags as short as possible for the sake of an easy overview and to prevent errors.

# Showing Invisible Elements

The View > Invisible elements option allows elements defined as invisible to be made visible and subsequently editable: If this option is selected, invisible elements will be displayed in the graphical editor, [symbol editor](Glossary_o_symboleditor.htm), [form](Glossary_o_verlauf.htm) editor, and plot frame editor.

Precondition:

You have opened a page, form, plot frame or symbol.

1. Select the menu [items](Glossary_o_bauteile.htm) View > Invisible elements, or press the [U] key.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The invisible elements are displayed.
2. Select the menu items View > Invisible elements, or press the [U] key again.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The invisible elements are hidden again.

![](../Pictures/Gui/ALL/info.png)Tip:

The display of invisible elements can also be switched on and off via the user [settings](Glossary_o_einstellungen.htm) (Show invisible elements check box under Options > Settings > User > Graphical editing > General). There you can also use the Print / Export invisible elements check box to define whether invisible elements should be taken into account when printing and exporting.

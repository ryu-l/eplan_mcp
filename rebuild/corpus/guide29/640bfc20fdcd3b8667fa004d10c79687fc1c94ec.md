# Dialog Routing connection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Insert > Routing connection. You have selected the source and target of the routing connection to be inserted.

Use this dialog to specify whether the routing connection to be inserted is to be routed in the routing path network or freely.

The following dialog elements are available:

Route connection in the routing path network:

The existing routing path network is used for routing the connection. This is the default setting.

Route connection freely:

The connection is routed freely in the room outside the routing path network. The [form](Glossary_o_verlauf.htm) of the freely routed connection can be changed using the menu [items](Glossary_o_bauteile.htm) Edit > Graphic > New control point / Change curve run / Align curve run tangentially and adapted to the spatial conditions in the mounting layout.

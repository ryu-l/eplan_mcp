# P005045: Same connection designation on different signals or piping states

### Cause

In the schematic or in the [P&I diagram](Glossary_o_ri_fliessbild.htm) there are at least two [connection designations](Glossary_o_verbindungsbezeichnungen.htm) on [connections](Glossary_o_verbindungen.htm) that are assigned to different [signals](Glossary_o_signale.htm) or piping states.

This message may be output for the "Electrical engineering" and "Process engineering" [trades](Glossary_o_gewerke.htm) for several reasons. These are explained below with reference to the following examples:

#### Reason 1 (electrical engineering)

A connection section was separated from the original signal after potential-oriented [connection numbering](Glossary_o_verbindungsnummerierung.htm). The separated connection thus receives a different signal while retaining the same connection designation.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Two [device connection points](Glossary_o_geraeteanschluesse.htm) -U5:1 and -U6:2 are connected to one another via fused terminal -X2:1. There are two connection sections with the same designation 002 between the two device [connection points](Glossary_o_anschluesse.htm) and the fused terminal.

The With signal isolation check box is selected on the Symbol / function data tab of the [property dialog](Glossary_o_eigenschaftendialog.htm) for the fused terminal. This setting interrupts the signal transfer function. The lack of transfer causes the connection sections with the same designation to be assigned to different signals.

![](../Pictures/Visualisation/ALL/messages_005044_av.png)

#### Reason 2 (process engineering)

The signal transfer to a function within a piping is interrupted.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Two containers, -CM01 and -CM02, are connected with each other by a piping. This is identified with the piping definition point -WP01. The shut-off control valve -FL01 is installed in the piping. The substance H2O with the state A is passed through the pipe. Connection definition points that have the same designation 010 were placed on the piping between the connection points of the containers and the shut-off control valve.

The With signal isolation check box is selected on the Symbol / function data tab of the property dialog for the shut-off control valve. Through this setting the function interrupts the transfer of the pipe state. The lack of transfer causes the connections with the same designation to be assigned to different pipe states.

![](../Pictures/Visualisation/ALL/messages_005045_bsp2_av.png)

### Solution

#### Regarding options 1 and 2

1. Locate the connections with the same designation in the schematic or in the P&I diagram by using the Go to (graphic) and Go to 2nd coordinate functionalities from the popup menu of the Message management dialog.
2. Call the property dialog of the function placed between the connections of the same name and bring the Symbol / function data tab to the foreground.
3. Check the setting of the With signal isolation check box. Deactivate the With signal isolation check box if the signal transfer is interrupted at a function between the affected connections.
4. Refresh the connections, then start a new project check.

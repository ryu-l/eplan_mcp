# Displaying Connection Points Graphically

Connection points at 3D [part placements](Glossary_o_artikelplatzierungen.htm) can be rendered visible in the [layout space](Glossary_o_bauraum.htm). This allows you to better estimate whether their position and connection point direction are suitable for existing [routing paths](Glossary_o_strecken.htm) and [wire ducts](Glossary_o_verdrahtungskanaele.htm), so that [routing connections](Glossary_o_verlegeverbindungen.htm) can find the [connection points](Glossary_o_anschluesse.htm) reliably. If this is not the case, you must modify either the connection point direction or the course of the routing paths.

In the graphical display, connection points cannot be deleted, moved or duplicated. Connection point data is modified in the [property dialog](Glossary_o_eigenschaftendialog.htm) of the [part](Glossary_o_artikel.htm) placement.

### Display connection point designations

1. Select the menu item View > Connection point designations.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection points of the part placements are displayed as a red cuboid.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection point designation is visible with a suitable 3D viewpoint and substantial enlargement of the section on the front of the red cuboid.  
     
   ![](../Pictures/Visualisation/ALL/routing_connpointdesignation_av.png)  
     
   ![](../Pictures/Gui/ALL/arrow.png) The transparency of all part placements with connection points is set to 50%.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the cursor touches a connection point, a tooltip is displayed showing the plug designation and connection point designation.

### Display connection point directions

1. Select the menu item View > Connection point directions.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection point direction is indicated by a red arrow.

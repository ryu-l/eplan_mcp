# EPLAN Fluid: Definition of Conduits and Lines

Fluid [connections](Glossary_o_verbindungen.htm) can be defined as [devices](Glossary_o_betriebsmittel.htm) - either as a conduit in which several hoses are combined, or as a piping  or hose line. In this regard the following [functions](Glossary_o_funktionen.htm) definitions of the Conduit / line category are available:

- Conduit definition
- Piping definition
- Hose line definition.

Conduit definition for conduits

The "Conduit definition" function definition allows you to combine several hose connections running parallel into one hose package (conduit) and to treat this as one device. In this case the conduit definition is used like a [cable](Glossary_o_kabel.htm) definition and also placed by means of the same menu [items](Glossary_o_bauteile.htm) (Insert > Cable definition). EPLAN Fluid automatically recognizes that a conduit definition line is to be inserted on the basis of the used page type "Fluid power schematic (I)".

Graphical representation of the conduit definition in the schematic is carried out by means of the Conduit definition line (PDL symbol from the SPECIAL symbol library) that you drag over the desired [fluid power](Glossary_o_fluidtechnik.htm) connections that are to be [part](Glossary_o_artikel.htm) of the conduit during inserting.

After the conduit definition line has been inserted, [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) are placed automatically with an [autoconnecting](Glossary_o_autoconnecting.htm) line of a fluid connection at each interface of the conduit definition line. The [function definitions](Glossary_o_funktionsdefinitionen.htm) of the connection definition points are set to the "Hose" value in order to define a conduit.

The symbol and the variant of the connection definition points can be changed in the dialog Settings: Conduit by using the menu items Options > Settings > Projects > "Project name" > Devices > Conduit. For example you can use the CDPCP2F5 symbol for a tube. In this case the conduit definition line has to be made invisible correspondingly to obtain correct representation of the conduit.

The values in the Displayed DT, Length, Cross-section / diameter, and Unit fields of the conduit are transferred to all the connections contained in it, if the corresponding fields in the [properties](Glossary_o_eigenschaften.htm) dialog of the automatically placed connection definition point do not have an entry.

Pipe / hose line connection

Fluid connections can also be defined as [lines](Glossary_o_leitungen.htm) that are devices and at which device tags can be assigned. You have the possibility to define such a device as a piping or hose line by assigning the function definitions Piping definition or Hose line definition.

After the installation EPLAN Fluid provides corresponding [symbol macros](Glossary_o_symbolmakros.htm) so that piping or [hose lines](Glossary_o_schlauchleitungen.htm) can be placed as [symbols](Glossary_o_symbole.htm) in the fluid schematic. For pipings these are the symbol [macros](Glossary_o_makros.htm) Pipe1 to Pipe5, for hose lines the symbol macro Hose.ems (see following figure).

![](../Pictures/Visualisation/ALL/ftechnic_macro_hoselinesymbol_544_PD_1_av.png)

Simply insert the desired symbol macro into a fluid connection and assign a DT to the device placed by this means. The correct function definition is already preset after inserting.

### Display in the navigators

The conduit, piping and hose line definitions are displayed in the device navigator, but not in the cable navigator. Correspondingly the menu items of the menu path Project data > Devices > ... can also be executed for the conduit, piping and hose line definitions (e.g. Number).

The tree of the device navigator displays the relevant conduit or line definitions below the conduit / line DT. The [icons](Glossary_o_icons.htm) used for conduit, piping and hose line definitions (placed and unplaced) are the same as the icons for [cable definitions](Glossary_o_kabeldefinitionen.htm) (e.g. ![](../Pictures/Gui/ALL/navigatorgui_mainfunctionpart_as.png)![](../Pictures/Gui/ALL/navigatorgui_cable_as.png)).

To display only devices in the device navigator that are conduit, piping or hose line definitions, you can use the function definitions "Conduit definition", "Piping definition" and "Hose line definition" as a filter criterion. If you want to display only the connections generated by the conduit definition in the connection navigator, use the Connection: Association ([ID](Glossary_o_id.htm) 31142) property with the "Conduit" or "Line" value as the filter criterion.

### Reports

To output conduit, piping and hose line definitions, you can use [reports](Glossary_o_auswertungen.htm) of the types "Parts list", "Summarized parts list", "Device tag list", "Connection list" and "Conduit / line plan". Cable-specific reports cannot be created for these devices.

If you want to output only those connections in a connection list that were created by a conduit definition, you can use the Connection: Association (ID 31142) property with the value "Conduit" as a filter criterion.

If you want to output only those connections in a conduit / line plan that were created by a piping or hose line definition, you can use the Connection: Association (ID 31142) property with the value "Line" as a filter criterion to this purpose.

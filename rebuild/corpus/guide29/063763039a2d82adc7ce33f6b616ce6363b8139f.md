# P007027: The logic model of the function contains invalid connection point references via connection point designations: <x>

### Cause

At device and [PLC connection points](Glossary_o_sps_anschluesse.htm) a transfer of logic information to other [functions](Glossary_o_funktionen.htm) with the same DT is possible. This applies to the [properties](Glossary_o_eigenschaften.htm) Transfer potential to, Consumer / source to and Target tracking (PLC) to. In the concrete case a connection point designation that is not valid was assigned to a function connection point as a connection point reference in the logic model of the reported function.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

In a black box the potential is to be transferred from a device connection point with the connection point designation "1" to a device connection point with the connection point designation "4". In the logic model of the function the value "4" is entered for the function connection point "1" at the Transfer potential to property. However, a device connection point with this connection point designation does not exist in the schematic.

### Solution

1. Locate the device or PLC connection point in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Launch the [property dialog](Glossary_o_eigenschaftendialog.htm) of the function.
3. Bring the Symbol / function data tab to the front.
4. Click the [Logic] button.
5. Correct the connection point references for the properties Transfer potential to, Consumer / source to and / or Target tracking (PLC) to in the column for the corresponding function connection point in the Connection point logic dialog.
6. Click [OK].
7. Then start a new check run.

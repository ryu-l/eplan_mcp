# P033001: Function has an invalid wire harness name

### Cause

A function was found in the schematic to which a wire harness name has been assigned, but for which no wire harness definition with the same wire harness name exists. Possibly the function was copied from the schematic of a different project and inserted into the project currently opened, or wire harness names of wire harness definitions were renamed subsequently.

### Solution

If the function is not assigned to a wire harness definition, delete the wire harness name at the function. Or assign an existing wire harness name that is stored at a wire harness definition to the function.

1. Locate the function in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the function.
3. Delete the value of the Wire harness name in the [properties](Glossary_o_eigenschaften.htm) list of the first tab. Or use the [...] button in the value field of the property to select an existing wire harness name of a wire harness definition.
4. Click [OK].
5. Then start a new check run.

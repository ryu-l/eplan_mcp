# Tab Reports

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Reports > Generate. Select the Reports tab.

In this tab, you can specify the [settings](Glossary_o_einstellungen.htm) for all [reports](Glossary_o_auswertungen.htm), and manage reports that have already been generated.

Overview of the main dialog elements:

![](../Pictures/Gui/ALL/all_project_as.png) <Project name>:

In this tree structure, the names of the current [projects](Glossary_o_projekte.htm) are displayed as the top tree structure level. If a source project has been entered for a report, the report is listed under this project's name.   
All reports that have already been generated are shown under the project name, sorted by report type. Associated [report pages](Glossary_o_auswertungsseiten.htm) are summarized into [report blocks](Glossary_o_auswertungsbloecke.htm) by this.

| Icon | Tree structure layer | Meaning |
| --- | --- | --- |
|  | Source project (if stated) | Contains the project that is entered as the source project for the project or the reports / templates. |
|  | [(Report) pages](formgeneratorgui_k_auswertungsseiten.htm) | Contains all generated report pages. |
|  | [Function-related report types](formgeneratorgui_k_auswertungstypen.htm#I_Funktionsbezogene) | Contains all reports of a function-related report type. |
|  | [Report type for report overview](formgeneratorgui_k_auswertungstypen.htm#I_Auswertungsuebersicht) | Contains all reports of a report type for report overviews. |
|  | [Report blocks](formgeneratorgui_k_auswertungsbloecke.htm) (Function-related reports) | Contains all reports belonging to a report block (Function-related reports). |
|  | [Report blocks](formgeneratorgui_k_auswertungsbloecke.htm) (Report overviews) | Contains all reports belonging to a report block (Report overviews). |
|  | Report pages / placed reports | Represents a report page or the manual placement of an embedded report. |
|  | [Embedded reports](formgeneratorgui_k_ausgabeformen.htm) | Contains all generated [embedded reports](Glossary_o_eingebetteteauswertungen.htm). |

![](../Pictures/Gui/ALL/note.png)Note:

If a function has several [representation types](Glossary_o_darstellungsarten.htm), whose common [properties](Glossary_o_eigenschaften.htm) contain varying data, the representation type will determine which properties will be considered during reporting. EPLAN uses the specified [sequence of the representation types for its global editing and reporting](reverseengineering_k_reihenfolge.htm).

Popup menu:

| Menu item | Meaning |
| --- | --- |
| New | Opens the Select report dialog. Enables the generation of a report. |
| Update | Re-analyzes the [project data](Glossary_o_projektdaten.htm) of report [blocks](Glossary_o_bloecke.htm) selected in the tree structure. All data belonging to a report block is updated. |
| Delete report block | Deletes all report pages belonging to a report block. You must delete embedded reports directly from the project page. |
| [Freeze report pages](formgeneratorgui_h_auswerteinfrieren.htm) | Removes the selected report block. The associated report pages remain as they are and are no longer updated. This functionality is not available for embedded reports. |
| [Generate report template](formgeneratorgui_h_vorlageerstellen.htm) | Stores the selected report block as a report template. The stored report template is shown on the Templates tab. |
| Open page | Opens the currently highlighted page in the graphical editor. The Reports - <Project name> dialog closes automatically in the process. |

![](../Pictures/Gui/ALL/info.png)Tip:

Some functionalities of the popup menu are also available as buttons in the toolbar. This is located above the tree structure in this tab.

Property / Value:

In these columns, the properties and values of the selected reports are shown. Some [Properties](formgeneratorgui_d_vorlagen.htm#Ueberblick) are available in both the Reports tab and in the Templates tab.

[Settings]:

| Menu item | Meaning |
| --- | --- |
| Output to pages | Opens the dialog Settings: Output to pages. Enables settings to be specified for reports in pages and embedded reports. |
| Parts | Opens the dialog Settings: Part. Allows the definition of settings for parts in the bill of materials navigator and in the "Parts list", "Summarized parts list", "Device tag list" and "Enclosure legend" reports. |
| Display / output | Opens the dialog Settings: Display / Output. Enables the display and output of project data in reports to be limited. |

# Inserting DXF / DWG Files in the Graphical Editor

Precondition:

You are in a page within the graphical editor.

1. Insert > Graphic > DXF / DWG
2. In the DXF / DWG file selection dialog, select the desired file and click [Open]. (Multiple selection is not possible here.)  
      
    ![](../Pictures/Gui/ALL/arrow.png) The DXF / DWG import dialog is opened. The selected files are displayed in the Source field.
3. In the Scheme field, select an appropriate scheme from the drop-down list. Or click [...] to open the Settings: DXF / DWG export and import dialog. You can view the [settings](Glossary_o_einstellungen.htm) here for the standard scheme, and also [create](Glossary_o_erstellen.htm) and edit your own [schemes](Glossary_o_schemata.htm).
4. In the DXF / DWG import dialog, click [OK].
5. If under Options > Settings > User > Interfaces > DXF / DWG export and import in the Import tab you have selected the option Manual correction, then the Import formatting dialog will open, where you can then correct the automatically determined drawing limits.
6. Click [OK].
7. Use the mouse to position the graphic from the file on the current page.

![](../Pictures/Gui/ALL/note.png) Note:

You can also insert [DXF](Glossary_o_dxf.htm) / [DWG](Glossary_o_dwg.htm) files into pages in the [symbol editor](Glossary_o_symboleditor.htm) and in the [form](Glossary_o_verlauf.htm) and plot frame editor. The menu path here is also Insert > Graphic > DXF / DWG.

![](../Pictures/Gui/ALL/info.png) Tip:

You can import DXF / DWG files using Drag & Drop, by dragging the selected DXF / DWG files from Windows Explorer and dropping them into the graphical editor of your project.

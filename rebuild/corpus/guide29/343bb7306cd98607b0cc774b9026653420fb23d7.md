# Project Editor and Project Redliner

Redlining involves the exchange of a project PDF file between a project editor and a project redliner.

### Project editor

The project editor creates and / or edits a project. He issues the project pages as a PDF file. He then releases the PDF file for commenting and sends this to the project redliner.

Preconditions:

- EPLAN version
- Acrobat Professional 7.0 / Acrobat Standard 7.0

### Project redliner

The project redliner receives a PDF file from the project editor. The redliner draws and writes [comments](Glossary_o_kommentare.htm) in the PDF file and then sends this back to the project editor.

Precondition:

- Acrobat Reader 8.0

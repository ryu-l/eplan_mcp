# Properties (Global) Mode

The Properties (Global) Mode enables you to edit the shared [properties](Glossary_o_eigenschaften.htm) of distributed [functions](Glossary_o_funktionen.htm) in one action at the same time. To do this you can either edit the shared functions of all function representations of an auxiliary function or the shared properties of all function representations of a main function. It is also possible to globally change the DT for all function representations of a device.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Your project contains a device K1. The device consists of a multi-line main function Coil and multiple [auxiliary functions](Glossary_o_nebenfunktionen.htm) of the function categories NO contact and NC contact. In addition the multi-line main function exists in a single-line and an overview function representation. With the Properties (Global) Mode you can globally edit the function text for all function representations of the main function at the same time.

With very few exceptions, all properties can be globally edited that are available in the dialog Properties (global) <...> in the following tabs.

- [Tab <Function category>](devicetaggui_r_bmdaten.htm)
- [Tab <Function category> (device)](devicetaggui_r_bmdaten.htm)

The following table shows which properties in these tabs can not be globally edited in the Properties (Global) Mode.

| Property | Meaning |
| --- | --- |
| Cross-reference display: Display | Representation of the cross-reference display. |
| Cross-reference display: Number of rows / columns | Number of rows or columns for a row- or column-oriented cross-reference display. |
| Revision marker (from project comparison) | Marker of a revision change |
| Block property | Properties that have been specified in the relevant format property Block property: Format. |
| Block property: Format | Selects which properties are specified in the relevant block property. |
| Automatically generated | Shows if a function was generated by an automatic run (e.g., automatically generated cables). |
| Macro | Macro from which the function originates. |

You can also not change the properties in the Properties (Global) Mode in the following tabs in the Properties (Global) <...> dialog:

- Tab Display
- Tab Symbol / function data
- Tab Format

In these tabs you can only edit the selected function representation of the main and auxiliary function. All other associated function representations are not changed.

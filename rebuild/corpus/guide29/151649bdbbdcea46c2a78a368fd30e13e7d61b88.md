# Identifier Sets

In EPLAN you have the option of creating different sets of identifiers for different standards, countries, and customers. Identifiers can consist of multiple characters, for example KT or KTP. These can also be imported or exported. Identifiers are saved with references to [function definitions](Glossary_o_funktionsdefinitionen.htm) when exported and when they are imported the function definitions are assigned again.

In the project [settings](Glossary_o_einstellungen.htm) (Devices > Numbering (online)) you specify which set of identifiers you want to use for a project (for example DIN). Every function definition is then assigned a certain identifier. When creating a function the corresponding identifier is transferred from the function definition to the device tag. This can be manually changed. Identifiers are always entered in the function and are not referenced.

# Pre-planning: Procedure

The pre-planning and the detail planning based on it are created using the following steps:

- Configuring: This includes the creation and customization of [segment definitions](Glossary_o_segmentdefinitionen.htm) and [user-defined](Glossary_o_benutzerdefiniert.htm) [properties](Glossary_o_eigenschaften.htm). It also makes sense to [create](Glossary_o_erstellen.htm) suitable [macros](Glossary_o_makros.htm) with [placeholder objects](Glossary_o_platzhalterobjekte.htm) and value sets that, in the next step, you store at [segments](Glossary_o_segmente.htm) in the pre-planning and then place in the detail planning.
- Creating the pre-planning: To do so, in the pre-planning navigator, create [structure segments](Glossary_o_struktursegmente.htm) and [planning objects](Glossary_o_planungsobjekte.htm), then arrange them in a tree structure. Enter data for the individual segments, and assign macros, parts, templates, etc. to the planning [objects](Glossary_o_objekte.htm). In addition, the Project data > Pre-planning > Import menu [items](Glossary_o_bauteile.htm) offer the possibility to import lists with pre-planning data which have been generated in external applications.
- Creating the detailed planning: To do so, place macros or [functions](Glossary_o_funktionen.htm) from the pre-planning navigator on the schematic pages. Using the Pre-planning finished property, you can specify at a structure segment or planning object that this is finished and ready for the detail planning.
- Generate report: You can [generate](Glossary_o_erzeugen.htm) [reports](Glossary_o_auswertungen.htm) before and after creating the detail planning. Before you start with the detail planning, you can use the [report types](Glossary_o_auswertungstypen.htm) "Pre-planning: Structure segment overview", "Pre-planning: Structure segment plan", "Pre-planning: Planning object overview", and "Pre-planning: Planning object plan" to get an overview of the segments used. In addition, you can use [part](Glossary_o_artikel.htm)-specific reports ("Parts list", "Summarized parts list") to generate data sheets or order material.
- Check: You can conduct error checking before and after creating the detail planning. This includes specific project checks to check segments, segment definitions, and user-defined properties, while other project checks check references from the pre-planning to the detail planning. You can also define your own error checking for the pre-planning depth.   
  The segments with errors are identified in the pre-planning navigator with a red exclamation mark. In order to have only the segments with errors displayed in this navigator use the Messages in message management property as a filter criterion.

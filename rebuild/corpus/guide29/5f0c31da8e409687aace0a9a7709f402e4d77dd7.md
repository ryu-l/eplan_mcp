# P027017: Topology - No connection point pattern defined

### Cause

No connection point pattern has been defined at a [topology](Glossary_o_topologie.htm) function.

That is, there exists neither a local connection point pattern, nor a connection point pattern that has been stored on the [part](Glossary_o_artikel.htm) used.

### Solution

1. Locate the topology function in the project using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the Properties <...> dialog of the topology function.
3. Bring to front the Part tab, and check first whether a part has been stored for the topology function, and whether a connection point pattern has been entered for it. If this is not the case, and you want to use for the [route](Glossary_o_verlegen.htm) the connection point pattern defined on the part for the topology function, proceed as described below under "Possibility 1".
4. If no part has been stored on the topology function, check in the Connection point pattern tab whether [connection point designations](Glossary_o_anschlussbezeichnungen.htm) have been entered in the table that are derived either from the function [connection points](Glossary_o_anschluesse.htm) or are freely defined and not yet carried over to the local connection point pattern. If this is not the case, and you want to use for the route the local connection point pattern of the topology function, proceed as described below under "Possibility 2".

#### Possibility 1

For the route, the connection point pattern defined on the part is to be used for the topology function. To do so, select in parts management a part on which a connection point pattern has been stored. Proceed as follows:

1. Close, if still open, the [property dialog](Glossary_o_eigenschaftendialog.htm) of the topology function.
2. Select the Utilities > Parts > Management menu [items](Glossary_o_bauteile.htm), and navigate in the tree view of the Parts management dialog to the part that you want to assign to the topology function.
3. Bring the Technical data tab to the front, and next to the Connection point pattern field click [...].
4. Select in the Select connection point pattern dialog that opens the name of the required connection point pattern and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The name is carried over to the Connection point pattern field of the Technical data tab.
5. Close parts management, save the modified data, and update the parts database.
6. Open again the Properties <...> dialog of the topology function.
7. Bring to front the Part tab, and assign to the topology function the required part with the connection point pattern from parts management.
8. Switch to the Connection point pattern tab, and select from the popup menu the Update connection point pattern menu item   
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection point pattern is imported from the part.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the topology function comes with connection points, they will be listed in the table and identified by the ![](../Pictures/Gui/ALL/erroricon_error_systemmessages.png) icon.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the connection point [designations](Glossary_o_bezeichnungen.htm) of the imported connection point pattern stored on the part deviate from those of the topology function, they will be identified in the table by the ![](../Pictures/Gui/ALL/all_statusnotok_as.png) icon.
9. Delete in the connection point pattern of the topology function all connection points that do not belong to the connection point of the part, and click [OK].
10. Carry over the connection point designations to the local connection point pattern of the topology function by activating the Local connection point pattern check box.  
      
    ![](../Pictures/Gui/ALL/arrow.png) In the "Status" column, the connection point designations are identified by the ![](../Pictures/Gui/ALL/all_statusok_as.png) icon.
11. Click [OK] to close the Property dialog, then start a new project check.

![](../Pictures/Gui/ALL/note.png)Note:

If no connection point pattern has been stored in parts management, it will have to be created subsequently. Proceed as follows:

1. Select in the tree view of parts management the Connection point pattern hierarchy level, and select the New popup menu item.
2. Define the required connection point data on the tabs Connection point pattern, Connection points, and / or Attributes, enter a name for the connection point pattern, and click [Apply].
3. Select in the parts tree the part, and assign to it the connection point pattern - as described above.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The assignment is then also implemented for the part placement in the [layout space](Glossary_o_bauraum.htm).

#### Possibility 2

During the route, the connection point pattern entered locally on the topology function is to be used. Proceed as follows:

1. Bring to front the Connection point pattern tab.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the topology function comes with connection points, they will be listed in the table and identified by the ![](../Pictures/Gui/ALL/erroricon_error_systemmessages.png) icon.
2. Carry over the connection point designations to the local connection point pattern of the topology function by activating the Local connection point pattern check box.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the "Status" column, the connection point designations are identified by the ![](../Pictures/Gui/ALL/all_statusok_as.png) icon.
3. Click [OK] to close the property dialog, then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

You can also use freely defined connection point designations in the connection point pattern. Proceed as follows:

1. Add to the table new rows corresponding to the number of connection points.
2. Enter the required connection point designations.
3. Delete all connection point designations no longer needed, and carry over the data to the local connection point pattern via the check box.

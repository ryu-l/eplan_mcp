# P501005: The layer <u> assigned to the macro <x> (<y> / <z>) is user-defined

### Cause

In the parts database to be checked a [part](Glossary_o_artikel.htm) was found where a macro with a [user-defined](Glossary_o_benutzerdefiniert.htm) layer is entered.

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective part is already marked in it.
2. Bring the Technical data tab to the front.
3. Click [...] next to the Macro field and in the dialog then opened select a macro file with an assigned layer that is EPLAN-specific.  
     
   Or alternatively delete the entry in the Macro field.  
     
   Or [create](Glossary_o_erstellen.htm) a new macro with an EPLAN-specific layer, store it in the desired macro directory and select it in the Macro field.
4. Close the parts management, save the modified data, and carry out a parts synchronization.
5. Then start a new check run.

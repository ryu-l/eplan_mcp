# Dialog Format: Separator (Numbering with PLC Data)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the dialog [Settings: Number using PLC data](offlinenumerationplcgui_d_einstellungen.htm) (for example with Options > Settings > Projects > "Project name" > Devices > Number using PLC data). You have selected a [user-defined](Glossary_o_benutzerdefiniert.htm) scheme in the dialog Settings: Number using PLC data. You have selected an entry in the Format groups field and clicked ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit), or you have clicked ![](../Pictures/Gui/ALL/all_new_as.png) (New).

Select a format element of the type "Separator" in the Available format elements list of the dialog Number using PLC data: Format and move it to the Selected format elements list by using the arrow button.

In this dialog you specify the formatting for a [separator](Glossary_o_trennzeichen.htm) in the format group.

Overview of the main dialog elements:

You can specify the following characters as separators:

- Blank
- Other characters: After selecting this option, enter the desired character combination in the input field. Any digits, letters, and special characters can be used.

Number of characters:

If you have selected a space as a separator you can specify the number of characters here. If you select Other characters this field is grayed out and displays the specified number of characters.

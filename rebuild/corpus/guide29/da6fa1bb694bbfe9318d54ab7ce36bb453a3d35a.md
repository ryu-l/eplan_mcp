# Dialog Select revision index

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have generated a revision and have opened a revision project (file extension \*.ell). You have made changes to a page and opened the Description of page modification dialog. Click [...] next to the Revision index field.

In this dialog you select an existing revision index for the page description.

The following dialog elements are available:

The revision indexes already existing in the project are presented here in the table for selection.

Select a revision index and exit the dialog by clicking [OK]. The revision name and the associated description and reason for change entries are then entered into the Description of page modification dialog and you can edit these entries there.

# P007013: Part '<x>' is stored, but the variant '<y>' is not. There is the variant '<z>'

### Cause

You placed a device and manually selected a [part](Glossary_o_artikel.htm) variable that is not included in the part [master data](Glossary_o_stammdaten.htm). In this case the part variable is not loaded into the project.

### Solution

Create a new part variable for the selected device in the parts management. Place the device with this variable.

Then start a new check run.

# XML Export / Import: Overview of Tags and Attributes

Parts data import and export is done using an XML file, which must be structured as follows:

![](../Pictures/Visualisation/ALL/xmlexport_example_av.png)

![](../Pictures/Gui/ALL/note.png)Note:

The <partsmanagement> tag may only be defined once! All other tags can be defined several times and can also be omitted, for instance, if you have defined a variant without function template or a drilling pattern without data.  
Exception:  
At least one variant (<variant> tag) must always be defined for a [part](Glossary_o_artikel.htm) (<part> tag)!

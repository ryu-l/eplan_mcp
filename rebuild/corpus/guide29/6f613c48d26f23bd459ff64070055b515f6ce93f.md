# P021001: Placeholder object does not contain variables

### Cause

No variables were defined when assigning the value.

### Solution

Double-click the placeholder object. In the Placeholder object dialog, bring the Values tab to the front. Define at least one variable here. To do this, select Popup menu > New variable. In the Name new variable dialog enter a name and confirm the entry by clicking [OK].   
   
 ![](../Pictures/Gui/ALL/arrow.png) The variable is added as a new row under the column heading Variable.  
   
 Finally, select Popup menu > New value set.  
   
 ![](../Pictures/Gui/ALL/arrow.png) An empty column is added to the table.  
   
 Enter a name in the top cell of the column for the value set. Enter a value for the variable in the second row. Switch to the Assignment tab. In the column Variable, highlight the cell with the object property you want. Select Popup menu > Select variable. Assign the new variable to the object property you want in the next dialog.

Then start a new check run.

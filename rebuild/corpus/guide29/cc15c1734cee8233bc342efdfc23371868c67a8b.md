# P020048: <x> (x Pos <y> : y Pos <z>) : <u>

### Description

You have run a project comparison, checking the [properties](Glossary_o_eigenschaften.htm) of the test project (input project) against those of the comparison project and documented any differences.

This message displays when a difference concerning a text or path function text was detected by the project comparison. <x> outputs the text type (text or path function text) concerned, <y> the X position, and <z> the Y position of the text or path function text in the schematic. <u> [reports](Glossary_o_auswertungen.htm) if the text or path function text has been removed, added, or if one if its properties has been changed.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

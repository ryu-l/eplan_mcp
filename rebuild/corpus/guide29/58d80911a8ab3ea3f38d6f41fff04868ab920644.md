# Dialog Properties (placeholder text)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Master data > Form > Open > [Open].

- Insert > Placeholder text.
- You have double-clicked a placeholder text (or selected Properties popup menu item. In this case several [placeholder texts](Glossary_o_platzhaltertexte.htm) can also selected).

In this dialog, you can select the [form](Glossary_o_verlauf.htm) type specific placeholder text which should be inserted into the form, and specify its [properties](Glossary_o_eigenschaften.htm) for format, language, and frame. During the evaluation of the form, EPLAN automatically replaces these placeholders with the corresponding values of project [objects](Glossary_o_objekte.htm) on which the report is being run, such as [items](Glossary_o_bauteile.htm), pages, [symbols](Glossary_o_symbole.htm), etc.

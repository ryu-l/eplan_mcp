# Opening Cross-references in a New Window

In the graphical editor it is possible to jump from the displayed [cross-references](Glossary_o_querverweise.htm) to the cross referenced counterpieces ([interruption points](Glossary_o_abbruchstellen.htm), [main functions](Glossary_o_hauptfunktionen.htm) / [auxiliary functions](Glossary_o_nebenfunktionen.htm), etc.). During this action you can now also open a new window in the graphical editor provided that the respective cross referenced object is located on another project page. The new window opens by clicking the displayed cross-reference while simultaneously pressing the shortcut key [Ctrl] + [Shift].

![](../Pictures/Gui/ALL/benefit.png)Benefit:

When a cross-reference is opened in a new window, the project page with the first displayed cross-reference remains open. Tedious navigating to the original project page is superfluous.

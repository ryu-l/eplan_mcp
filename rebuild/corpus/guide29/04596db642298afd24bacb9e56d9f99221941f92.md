# Dialog Separator

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Manufacturing data > Export / labeling. Click [...] next to the Settings field in the dialog Export manufacturing data / output labeling. In the dialog Settings: Manufacturing data export / labeling select one of the Header, Footer or Label tabs, select the 'Separator' format element and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).

In this dialog you can specify the [separator](Glossary_o_trennzeichen.htm) to be placed between the texts of [properties](Glossary_o_eigenschaften.htm).

Overview of the main dialog elements:

Blank:

If this option is selected, a space will be printed after or before the text.

Tab:

If this option is selected, a tab character will be printed after or before the text.

Line break:

Inserts a line break. Enables output of a multi-line text.

Other characters:

In this field you can enter one or more characters to be output before or after the text. You enter spaces using the space bar. The number of characters you entered will automatically appear in the Number of characters field.

Number of characters:

In this field, the number of characters is shown which you entered in the Other characters field. This is particularly useful as a check if you have entered several spaces.

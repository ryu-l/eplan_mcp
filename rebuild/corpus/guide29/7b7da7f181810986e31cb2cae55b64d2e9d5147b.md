# Dialog Matching results

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The project contains a completely defined enclosure. The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open. The layout space contains imported 3D bodies which are to be saved as an enclosure. You have surrounded the 3D geometry with a rectangle and selected it.

Edit > Device logic > Automatic interpretation

This dialog displays the results of the similarity check. This check is activated when you have selected several template [objects](Glossary_o_objekte.htm) in the Select interpretation template selection dialog. A determination is made as to which templates have the most accurate similarity / highest hit ratio of specific characteristics with respect to the 3D object to be defined.

Overview of the main dialog elements:

List:

The list contains the following columns:

- Full item designation: Part number / item number dependent on the tab activated in the Select interpretation template dialog.
- Function definition
- Quota: Degree of similarity in percentage with respect to the item to be defined.

The entries in the list are sorted by the value shown in the Quota column. The template objects with the highest degree of similarity are at the top of the list. The list can contain a maximum of 10 entries.

Select an entry in the list whose [properties](Glossary_o_eigenschaften.htm) you want to carry over to the 3D object to be defined. Clicking [OK] selects the highlighted entry.

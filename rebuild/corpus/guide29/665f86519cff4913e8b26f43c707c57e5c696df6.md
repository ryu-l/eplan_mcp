# Tab Nominal diameter

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have installed the hose line configurator as an add-on variant of EPLAN Fluid. You have started EPLAN Fluid and the hose line configurator.

- Select the menu [items](Glossary_o_bauteile.htm) Options > Settings > User > Add-ons > Hose line configurator in EPLAN Fluid and click in the Nominal diameter tab in the subsequent dialog.
- Or select the menu items Extras > Settings in the Configure hose lines dialog of the hose line configurator and click in the Nominal diameter tab in the subsequent dialog.

Or you have installed the hose line configurator as a stand-alone variant and started the program.

- Select the menu items Options > Settings > User > Add-ons > Hose line configurator in the hose line configurator and click in the Nominal diameter tab in the subsequent dialog.

In this tab define the default values for the nominal diameter of the used hoses. The values entered in the table are offered for selection when the [hose lines](Glossary_o_schlauchleitungen.htm) are configured in the Edit <...> dialog.

Overview of the main dialog elements:

List:

The values of the nominal diameter always reference the unit "mm". They can therefore be entered without a unit.

Use the buttons of the toolbar above the list to [create](Glossary_o_erstellen.htm) new entries and / or delete entries no longer required and / or edit existing ones.

![](../Pictures/Gui/ALL/note.png)Note:

If you select the default scheme DIN 20066\_2012-01, the table is filled with preset values from the standard DIN 20066 that are assigned to the hose nominal diameter "d1".

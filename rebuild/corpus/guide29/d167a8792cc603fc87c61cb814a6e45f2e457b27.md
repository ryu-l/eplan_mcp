# Changing the 3D View of the Layout Space

Various functionalities can be used to change the view of an opened [layout space](Glossary_o_bauraum.htm).

Preconditions:

- You have opened a project.
- The layout space navigator is open and a layout space is open.

### [ClosedChanging zoom](javascript:void(0);)

You can use this functionality to zoom in or out, the layout space shown in the 3D view or a separately displayed [component](Glossary_o_schaltzeichen.htm) (mounting panel, mounting rail, etc.).

1. Select the menu [items](Glossary_o_bauteile.htm) View > Zoom > In/Out.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The view zooms in or out, step by step, starting from the position of the coordinate system.
2. Hold the cursor over the 3D view and turn the mouse wheel forward or backward.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The view zooms in or out, step by step, starting from the cursor position.

### [ClosedChanging viewpoint](javascript:void(0);)

This functionality generates different orthogonal (top, bottom, left, right, front, rear) or [isometric views](gededit3dgui_k_start.htm#IsometrischeAnsichten) (south-west, south-east, north-east, north-west) of your layout space. The [designations](Glossary_o_bezeichnungen.htm) of the four isometric viewpoints determine the orientation from which the model is viewed. Additionally, the viewpoint is rotated 60° downwards.

1. Select View > 3D viewpoint.
2. Select one of the available views from the submenu.

![](../Pictures/Gui/ALL/note.png)Note:

When switching the 3D viewpoint, the view becomes animated and is rotated into the new position. Using the user setting [Rotate when changing the viewpoints](gedviewer_d_einstellungenbenutzerallgemein3d.htm#DrehenBlickpunkte), this animation can be switched off, so that the viewpoint is changed without rotation.

![](../Pictures/Gui/ALL/info.png)Tip:

You can also use shortcut keys to change the 3D viewpoint. You can find the possible shortcut keys in the submenu of View> 3D viewpoint or in the help under [Overview of Shortcut Keys](gededitgui_k_tastaturbefehle.htm#3DBlickpunkt). You can also assign these shortcut keys to the function keys of a SpaceMouse.

### [ClosedRotate viewing angle](javascript:void(0);)

With this functionality, you can change the viewing angle of the graphic by moving the mouse.

1. Select the menu item View > Rotate viewpoint.
2. Click in the 3D view and keep the left mouse button pressed.
3. Holding the button down, move the mouse in the direction in which the viewing angle is to be changed.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The display in the layout space follows the movement of the mouse, and rotates in the corresponding direction.

### [ClosedSimplified representation](javascript:void(0);)

With this functionality, you can reduce the detail shown in the graphic of the parts placed in the layout space. You can set which items are to be shown in a simplified representation in the [Settings: 3D](gedviewer_d_einstellungenbenutzerallgemein3d.htm#VereinfachteDarstellung) dialog:

- Terminal strips (block definition)
- 3D [macros](Glossary_o_makros.htm).

These [settings](Glossary_o_einstellungen.htm) apply to all items already placed and to all subsequently placed items.

1. Select the Simplified representation popup menu item in the layout space navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) 3D macros are replaced by rectangular bodies in the dimensions of the items previously used. Terminal strips are combined into a block; the individual terminals are no longer displayed. The labeling of the terminal strip is displayed instead of the labeling for the individual terminals. The position of the components placed on the items does not change.

### [ClosedChanging the background colors for the 3D view](javascript:void(0);)

The default colors for the background to the 3D view can be set individually. You can specify a single color or two colors, between which a horizontal color gradient is generated.

1. Select Options > Settings > User > Graphical editing > 3D.
2. In the Color selection group box, use [...] in the Shading - Background 1 and Shading - Background 2 fields to open the [Color selection](mf_d_farbauswahl.htm) dialog.
3. Select the desired colors.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected two different colors, the background will be drawn with a color gradient. The first color defines the starting color in the upper window pane and the second color stands for the end color in the lower window pane.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected two identical colors, the background will be drawn with one single color.

### [ClosedDisplay and hide drilling view](javascript:void(0);)

Drilling view refers to the display of all mechanical working steps (designs). This does not concern manually placed [cut-outs](Glossary_o_durchbrueche.htm).

1. Select the menu items View > Drilling view.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The transparency of all [part placements](Glossary_o_artikelplatzierungen.htm) is set to 50%. All [drilling patterns](Glossary_o_bohrbilder.htm) stored on the parts are displayed on the [mounting surfaces](Glossary_o_montageflaechen.htm) where they have been placed. The visualized drilling patterns fully penetrate the components below to be drilled, which becomes clear in the side view.  
     
   ![](../Pictures/Visualisation/ALL/cabinetgui_drillview_as.png)
2. Again select the View > Drilling view menu items to hide the drilling view.

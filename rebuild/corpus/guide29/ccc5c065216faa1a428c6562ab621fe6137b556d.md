# Main functions: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_hauptfunktionen.htm)

### Main functions

User interface / operation

The main function represents a device in the devices represented in a distributed manner (e.g. the coil in a contactor). Only the main function carries (e.g.) the device definition of the device. Only one main function may exist per device.

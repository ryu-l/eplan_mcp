# P022027: Text is too small

### Cause

A text was found on a project page whose font size is smaller than the minimum font size defined in the [project-specific settings](Glossary_o_projektbezogeneeinstellungen.htm).

### Solution

1. Locate the text in the project using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the Properties <...> dialog of the text, and bring to front the Format tab and determine the value set in the Font size field.
3. Select the menu [items](Glossary_o_bauteile.htm) Settings > Options > "Project name" > Graphical editing > General and determine the value set in the Minimum font size (check for excessively small texts) field.
4. Either increase the value of the font size of the text so that the set minimum font size is exceeded. Or reduce the value for the project-specific setting in the field Minimum font size (check for excessively small texts) so that the font size currently used for the text becomes valid and an error is no longer reported.
5. Then start a new check run.

# Managing User Groups

The [rights management](Glossary_o_rechteverwaltung.htm) allows you to [create](Glossary_o_erstellen.htm) [user groups](Glossary_o_benutzergruppen.htm) and assign particular editing rights to them. You can also subsequently edit or delete user groups.

![](../Pictures/Gui/ALL/note.png)Note:

The user groups predefined by EPLAN - "Administrators" and "Guests" - cannot be edited or deleted.

### Create user groups

1. Select the following menu [items](Glossary_o_bauteile.htm): Utilities > Rights management
2. To the left of the Rights management dialog, select the Groups folder, and click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
3. In the Group dialog, enter a name and short description of the allowed editing rights of the new user group. In contrast to the user names, a distinction is made between upper and lower case in the group names, i.e., a group "QS" and a group "Qs" are different groups.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The group is created, but editing rights have not yet been assigned.
5. Assign editing rights to the group as described under "Assign rights to groups".

### Copy user group

1. Select the following menu items: Utilities > Rights management
2. To the left of the Rights management dialog, select the Groups folder.
3. Select a user group in the field on the right and click ![](../Pictures/Gui/ALL/all_copy_as.png) (Copy).
4. In the Group dialog, enter a name and short description of the allowed editing rights of the new user group. In contrast to the user names, a distinction is made between upper and lower case in the group names, i.e., a group "QS" and a group "Qs" are different groups.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The group is created and possesses the editing rights of the previously selected user group.
6. Modify, if required, the editing rights as described under "Assign rights to groups".

### Edit user groups

1. Select the following menu items: Utilities > Rights management
2. To the left of the Rights management dialog, select the Groups folder.
3. Select a (self-defined) user group in the right-hand field and click ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit).
4. In the Group dialog, change the name or description.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The dialog is closed and the changed data is displayed in the Rights management dialog.

### Delete user groups

1. Select the following menu items: Utilities > Rights management
2. To the left of the Rights management dialog, select the Groups folder.
3. Select a (self-defined) user group in the right-hand field and click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete).  
     
   ![](../Pictures/Gui/ALL/arrow.png) After confirmation of the warning message, the group name is deleted.

### Assign rights to groups

1. Select the following menu items: Utilities > Rights management
2. In the Rights management dialog, click the plus sign next to the Groups folder to open the folder and select a user group.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The available rights are displayed on the right and are grouped according to topic area.
3. Click the plus sign to open the subordinate rights in front of a topic area.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The rights are divided into editing rights for menu items, dialogs, and API [actions](Glossary_o_aktionen.htm). The rights for dialogs are also identified by "[Dialog]". The rights for API actions are also identified by "[Interface]".
4. Select the check boxes in front of the rights the user groups are to possess and deactivate those that are to be revoked.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The activated rights will be assigned to the user group.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If all subordinate rights are deselected for a topic area, then the check box for the topic area is displayed in gray.

![](../Pictures/Gui/ALL/info.png)Tip:

You can assign or revoke all of the rights for a particular topic area by selecting or deselecting the check box in front of the topic area.

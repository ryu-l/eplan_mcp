# Docking / Undocking Text

Texts can be docked together. This prevents texts from flowing together, for instance, if you change a one-line texts into a multiline text later. This is primarily useful for [property texts](Glossary_o_eigenschaftstexte.htm) on components, but "normal" texts can also be docked.

Docked text retains its original color, size, font, and style. Angle and orientation however, are adopted from the main text. This text also behaves as a block when moved.

The text "remembers" the position where it was located prior to docking, and then returns to this position when it is undocked.

![](../Pictures/Gui/ALL/note.png)Note:

Texts that are docked with each other may not be [part](Glossary_o_artikel.htm) of different element groups because otherwise problems can arise during the editing of these texts.

Precondition:

You have opened a page, [form](Glossary_o_verlauf.htm), plot frame or symbol.

### Dock text

1. Select the text you wish to [dock](Glossary_o_andocken.htm).
2. Select the menu item Edit > Text > Dock.
3. Select the main text to which the text is to be docked.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The text is oriented to the main text.

### Undock text

1. Select a [docked text](Glossary_o_angedocktetexte.htm).
2. Select the menu item Edit > Text > Undock.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The text is moved back to the position where it was before it was docked.

### Dock property text

Property texts are docked and undocked in the [property dialog](Glossary_o_eigenschaftendialog.htm) of the corresponding [component](Glossary_o_schaltzeichen.htm).

1. Mark a component and then select the menu item Edit > Properties.
2. In the Display tab, select a non-docked property from the list (a prefixed symbol indicates the configured docking direction) and select the popup menu Dock.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property text is correspondingly docked in direction specified in the Docking field.

### Undock property text

1. Mark a component and then select the menu item Edit > Properties.
2. In the Display tab select a docked property from the list (these do not have a prefixed symbol) and select the popup menu Undock.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property text is undocked and can now be moved separately.

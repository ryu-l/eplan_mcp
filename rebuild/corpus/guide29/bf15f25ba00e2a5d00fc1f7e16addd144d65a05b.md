# Dialog Trade / subtrade

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have marked a [part](Glossary_o_artikel.htm) in the tree or list. Select the General tab and click [...] in the Trade / Subtrade field.

This dialog is used to define the [trades](Glossary_o_gewerke.htm) to which a part is assigned.

Overview of the main dialog elements:

Toolbar:

For a [fluid power](Glossary_o_fluidtechnik.htm)-specific trade (for example electrical engineering, [hydraulics](Glossary_o_hydraulik.htm)) you can use the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button to open the Create subtrade dialog and [create](Glossary_o_erstellen.htm) a new subtrade. If a subtrade has been created, the additional ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit) button is available for renaming the subtrade.

Table:

The table lists all the existing trades and [subtrades](Glossary_o_untergewerke.htm). Activate the check boxes in the Use column to specify additional trades to which the parts are to be assigned.

![](../Pictures/Gui/ALL/note.png)Note:

If you assign more than one trade to a part here, the Select trade dialog is opened when the part is inserted as a device with fluid-power-specific [functions](Glossary_o_funktionen.htm) (in the assigned macro or as a function template) into the schematic. This dialog lists all the fluid-power-specific trades. In this case select the trade that suits the device.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# Overview of Toolbar Actions

The following actions can be inserted as buttons in [toolbars](Glossary_o_symbolleisten.htm):

| Action | Meaning |
| --- | --- |
| Open workspace | Sets the EPLAN user interface according to a particular workspace definition. |
| Define setting | Sets a user, station, or company setting to a certain value. |
| Import [settings](Glossary_o_einstellungen.htm) | Imports the property arrangement, dialog memory, tree and list configuration and external program settings. |
| Export manufacturing data / Output labeling | Outputs the manufacturing data / labeling for a project. |
| Set format of graphical elements | Sets one or more formatting settings of selected graphical elements to specific value(s). If you have not yet selected a graphical element then, after clicking the button, the cursor symbol changes and you can select a desired area containing the graphical elements. |
| Export [functions](Glossary_o_funktionen.htm) | Exports the function [properties](Glossary_o_eigenschaften.htm) of the current project for external editing. |
| Insert device | Allows [placing](Glossary_o_auflegen.htm) of a predefined device without calling up the Part selection dialog. |
| Insert macro | Allows insertion of a particular variant of a pre-defined macro without calling up a selection dialog. If the variant does not exist in the macro then a message is displayed. |
| Set project property | Sets a project property for a selected project to a specific value. |
| Define project setting | Sets a project setting to a certain value. |
| Set [component](Glossary_o_schaltzeichen.htm) property | Sets a component property for a selected component to a specific value. |
| Set component format | Sets one or more formatting properties for all [property texts](Glossary_o_eigenschaftstexte.htm) of selected components to specific value(s). If you have not yet selected a component then, after clicking the button, the cursor symbol changes and you can select a desired area containing the components. |
| Export pages | Exports the page properties of the current project for external editing. |
| Set page property | Sets a page property for a selected page to a specific value. |
| Insert symbol | Allows insertion of a pre-defined symbol without using the interactive Symbol selection dialog. If the "?" placeholders in the command line are not replaced with sensible values, then the Symbol selection dialog is opened. |
| Insert symbol with function definition | Allows insertion of [symbols](Glossary_o_symbole.htm) with the same function definition. |
| Copy toolbars | Copies the buttons of one toolbar to another. |
| Set text format | Sets one or more formatting settings of selected text elements to specific value(s). If you have not yet selected a text element then, after clicking the button, the cursor symbol changes and you can select a desired area containing the components. |
| Export [connections](Glossary_o_verbindungen.htm) | Exports the connection properties of the current project for external editing. |
| Set graphical format of connections (connection definition point, potential definition point) | Sets one or more formatting settings of selected connection and / or [potential definition points](Glossary_o_potenzialdefinitionspunkte.htm) to specific value(s). If you have not yet selected a definition point then, after clicking the button, the cursor symbol changes and you can select a desired area containing the definition points. |

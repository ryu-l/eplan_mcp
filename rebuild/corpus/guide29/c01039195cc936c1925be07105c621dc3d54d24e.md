# Data Transfer of EPLAN PPE Projects

EPLAN PPE [projects](Glossary_o_projekte.htm) from older EPLAN versions (Version 2.6 or older) are converted automatically into pre-planning projects during opening and the subsequent updating of the project databases. (In order for this to be possible, both the Microsoft operating system and the Microsoft Office applications (inter alia Microsoft Access) therefore have to be installed completely in the 64-bit version.)

In the process, [segments](Glossary_o_segmente.htm) are generated from the information contained in the PPE database. The old project is preserved under a modified name. If the EPLAN PPE project contains documents a message is displayed in which you can decide whether these documents are to be imported as [graphical pages](Glossary_o_grafikseiten.htm).

During this automatic data transfer the following PPE [objects](Glossary_o_objekte.htm) are converted into the corresponding segments or objects of pre-planning:

| PPE object | Segment / Object |
| Higher-level function  - PI system  - Designation | Structure segment  - Designation  - Description  The [structure identifiers](Glossary_o_strukturkennzeichen.htm) are determined on the basis of the configuration in EPLAN PPE. |
| PCT loop | PCT loop |
| PCT loop function | PCT loop function |
| PCT loop element  - Device type  - Device group | Planning object  - Description  - Segment definition |
| Specification | Segment template |
| Hook-up | Assembly |
| Orders | - Omitted - |
| Containers | Containers |
| Property | User-defined property. Property groups are displayed as [part](Glossary_o_artikel.htm) (additional node) of the identifying property name. |
| External document | Document (stored at the segment) |
| Document | Graphics page. During the opening and conversion of EPLAN PPE projects you can decide whether the documents from EPLAN PPE projects are to be converted into graphical pages or are to be ignored. |

![](../Pictures/Gui/ALL/note.png)Note:

After the data import of an EPLAN PPE project further predefined [planning objects](Glossary_o_planungsobjekte.htm) (such as "Sensor", "Actuator", "Pick-up", etc.) and [segment templates](Glossary_o_segmentvorlagen.htm) are available in the segment template navigator. These segment templates are based on the specifications from EPLAN PPE. During conversion the specification number in PPE becomes the identifying name of the segment template.

# Window macros: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_fenstermakros.htm)

### Window macros

User interface / operation

Macro that contains an area of a page or all of the objects located on a page, but without the page header data. Window macros are attached to the cursor when being inserted and can be positioned freely in X or Y direction.

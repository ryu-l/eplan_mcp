# Dialog Settings: Labeling

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have selected a model view. Edit > Properties. Click [...] in the "Value" field at the Model view: Item labeling property in the Model view dialog.

This dialog is used to define the [settings](Glossary_o_einstellungen.htm) for labeling the [items](Glossary_o_bauteile.htm) in the model view.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Table:

The table shows which items from the selected [layout space](Glossary_o_bauraum.htm) are labeled, which [properties](Glossary_o_eigenschaften.htm) are to be included in the labeling, and what the representation of the labeling is to look like.

- Function definition: The [...] button in a cell opens the Function definitions dialog. In this dialog, you can select a function definition for which the label should be generated.
- Property arrangement: The [...] button in a cell opens the Property arrangements dialog. In this dialog, you can modify the display settings of the labeling (format, unit / value, position) and thus set a [user-defined](Glossary_o_benutzerdefiniert.htm) representation of the labeling text for each function definition.
- From layout space: If the check box is activated in this column, the property arrangement set in the view for a function definition is overridden. Instead the property arrangement from the layout space is used for the representation of the labeling. This allows the optimal readability of the labeling established in the layout space to also be used in view derived from it.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

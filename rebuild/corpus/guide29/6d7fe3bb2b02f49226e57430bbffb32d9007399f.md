# Dialog Generate topology functions

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have marked a structure routing pointon a [topology](Glossary_o_topologie.htm) page or in the topology navigator. Project data > Topology > Generate topology functions > Manually.

The [main functions](Glossary_o_hauptfunktionen.htm) existing in the project that do not yet exist as topology [functions](Glossary_o_funktionen.htm) are listed in this dialog. Here you select the functions that are to be assigned to the structure routing point and created as topology functions. When the dialog is terminated with [OK], unplaced topology functions are generated and these are connected through unplaced [routing paths](Glossary_o_strecken.htm) with the structure routing point.

When the dialog is called up again, you can view the generated topology functions and, if required, change them subsequently.

The following dialog elements are available:

Area Main functions without topology

The main functions occurring in the project that do not yet exist as topology functions are displayed in accordance with the display in the device navigator in the Tree and List tabs.

The tree view is used to sort the [devices](Glossary_o_betriebsmittel.htm) on the basis of the [structure identifiers](Glossary_o_strukturkennzeichen.htm) of the device structure. Devices that have not been sorted into a defined [project structure](Glossary_o_projektstruktur.htm) by means of structure identifiers are sorted into the tree structure level Without structure identifier.

In the list view the view and sorting of the devices depends on the column configuration selected in the Configure representation dialog.

Filter:

This drop-down list displays all the available [filters](Glossary_o_filter.htm). A selected filter is automatically activated and is applied to both the tree and the list view. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the [Filter](modaldialogsdb_d_filternnach.htm) dialog. Here you can [create](Glossary_o_erstellen.htm), edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

- Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
- Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

Value: <Property>:

Use this field, via [Quick input](modaldialogsdb_k_filter.htm#I_Schnelleingabe), to adjust quickly the value of a filter criterion for a defined and activated filter.

---

Connected topology functions:

This list displays the functions that are to be generated as topology functions are to be connected to the structure routing point. This is done when the dialog is closed with [OK].

When the dialog is called up again, the topology functions already created and connected to the structure routing point are displayed here.

Arrow buttons:

Use the arrow buttons to select individual functions for the creation of topology functions or to undo this selection. Multiple selection is possible in both lists.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Select all | Selects all of the entries in the list. |
| Adjust column width | Adjusts the width of all table columns so that both the headings and column contents are fully legible. |
| Configure representation | Opens the Configure representation dialog in which you can define the [properties](Glossary_o_eigenschaften.htm) to be displayed in the list. |

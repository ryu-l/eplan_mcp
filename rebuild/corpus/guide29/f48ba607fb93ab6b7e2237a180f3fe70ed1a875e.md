# P028017: Identifying designation at PCT loops occurring multiple times

### Cause

A PCT loop or PCT loop function exists more than once with the same identifying designation according to the [settings](Glossary_o_einstellungen.htm) under Options > Settings > Projects > "Project name" > Pre-planning > Numbering / [PCT loops](Glossary_o_plt_stellen.htm) in the project.

### Solution

1. Locate the PCT loop or PCT loop function designated in identical fashion multiple times according to the settings in the pre-planning navigator using the Synchronize selection function offered by the popup menu in the Message management dialog.
2. Call the Properties <...> dialog of the PCT loop or PCT loop function, and depending on the selected basic segment definition, bring to the front the Loop, Measuring function, or Consumer function tab.
3. Modify the Number property on the PCT loop or PCT loop function, or modify the settings in the Identifying [properties](Glossary_o_eigenschaften.htm) in addition to the 'Number' group box below the menu [items](Glossary_o_bauteile.htm) Options > Settings > Projects > "Project name" > Pre-planning > Numbering / PCT [loops](Glossary_o_messstellen.htm).
4. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

In addition to the check run 028017, the check run 028002 "Planning object occurring multiple times" is also started, which checks the total full designation of the PCT loop or PCT loop function.

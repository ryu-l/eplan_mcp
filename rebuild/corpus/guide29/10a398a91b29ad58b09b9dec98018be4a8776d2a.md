# P005060: Connection point has a multi-line connection in both single-line and multi-line display

### Cause

A connection point that has been connected on the Interconnect [devices](Glossary_o_betriebsmittel.htm) tab already has a multi-line connection.

### Solution

1. Delete one of the two [connections](Glossary_o_verbindungen.htm).
2. Then start a new check run.

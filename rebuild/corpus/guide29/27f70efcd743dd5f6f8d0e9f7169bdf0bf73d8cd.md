# Examples of the Design of Structure Identifiers

All [objects](Glossary_o_objekte.htm) in a project (pages, [devices](Glossary_o_betriebsmittel.htm) and [functions](Glossary_o_funktionen.htm)) must be identified and placed in a hierarchical structure within the project.

![](../Pictures/Gui/ALL/example.png) [![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Structure identifier for a page: =AP+ST1/6.

| Identifier | Meaning |
| --- | --- |
| = | Prefix of the following structure identifier for the identifier block "Higher-level function" |
| AP | Structure identifier for the identifier block "Higher-level function" |
| + | Prefix of the following structure identifier for the identifier block "Mounting location" |
| ST1 | Structure identifier for the identifier block "Mounting location" |
| / | Separator before the page name |
| 6 | Page name |

![](../Pictures/Gui/ALL/example.png) [![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Structure identifier for a device: =AP+ST1-F6.

| Identifier | Meaning |
| --- | --- |
| = | Prefix of the following structure identifier for the identifier block "Higher-level function" |
| AP | Structure identifier for the identifier block "Higher-level function" |
| + | Prefix of the following structure identifier for the identifier block "Mounting location" |
| ST1 | Structure identifier for the identifier block "Mounting location" 1 |
| - | Preceding sign for the identifier block "Device" |
| F6 | Structure identifier for the identifier block "Device" |

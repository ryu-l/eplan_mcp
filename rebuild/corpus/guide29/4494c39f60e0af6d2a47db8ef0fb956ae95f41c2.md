# Network Structures: Definition of the Term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_netzwerkstrukturen.htm)

### Network structures

Electrical engineering

Representation of PLC configurations (see [PLC configurations](Glossary_o_sps_konfigurationen.htm)) on schematic pages that show which network components are connected with each other. The network structure is usually drawn on single-line schematic pages.

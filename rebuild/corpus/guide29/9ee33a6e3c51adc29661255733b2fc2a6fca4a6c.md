# Tab Placeholder texts

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the dynamic [form](Glossary_o_verlauf.htm) that you would like to edit in the form editor (Utilities > Master data > Form > Open > [Open]). Insert > Dynamic area> <...>. Use the mouse to draw the rectangle that represents the dynamic area and then double-click in the newly defined area.

In this tab all the [placeholder texts](Glossary_o_platzhaltertexte.htm) that are assigned to the respective area are listed in a table. In a newly inserted dynamic area you can then specify new placeholder texts and [settings](Glossary_o_einstellungen.htm) for the position of these placeholders for the report.

Overview of the main dialog elements:

Position:

In this drop-down list you specify how the placeholder texts are distributed in the dynamic area. Placeholder texts without activated alignment box always retain their position â irrespective of the selected setting. The following options are available:

- Retain position: The positions of all the placeholder texts are retained.
- Fit placeholder texts: The placeholder texts are fitted into the area. To this purpose the cell in the Width column is grayed out for the lowest placeholder text with activated alignment box. The width of the alignment box for this placeholder text is calculated from the width of the area minus the width of the alignment boxes of the other fitted placeholder texts.
- Space placeholder texts evenly: The placeholder texts are fitted evenly into the area. Thus the cells in the Width column for placeholder texts with activated alignment box are grayed out. The widths of the respective alignment boxes are calculated so that they fit the set [grid](Glossary_o_raster.htm) of the form.

Table:

In the table you can carry out settings for the most important display [properties](Glossary_o_eigenschaften.htm) of the placeholder texts (Activate alignment box, Draw alignment box, Width of the alignment box).

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

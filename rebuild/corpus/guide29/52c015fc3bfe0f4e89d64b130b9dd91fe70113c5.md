# User Interface

The EPLAN user interface offers you the following:

- You can use the mouse and the keyboard to call up all program [functions](Glossary_o_funktionen.htm).
- You can change the key assignments to suit your personal requirements.
- You can freely configure the [toolbars](Glossary_o_symbolleisten.htm).
- You can filter data sets.
- You can define, [create](Glossary_o_erstellen.htm), and edit [schemes](Glossary_o_schemata.htm) for [filters](Glossary_o_filter.htm) and different [settings](Glossary_o_einstellungen.htm).
- You can configure EPLAN for working with multiple screens.
- You can define the display and sorting order of data.

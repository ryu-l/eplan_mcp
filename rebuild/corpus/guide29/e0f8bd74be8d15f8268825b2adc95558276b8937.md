# Exporting the Address Space Assignment

In the Addresses / assignment lists dialog (menu item Project data > PLC > Addresses / assignment lists), all inputs and outputs for the PLC controllers in the project are managed. With the new menu item Export address space assignment below the [Extras] button you can now export the [address space assignment](Glossary_o_adressraumbelegung.htm) of a CPU as a list into a file. To do this the address range must be specified on the [PLC cards](Glossary_o_sps_karten.htm) by specifying a start address and the associated data length.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

With the export of the address space assignment, you obtain an overview of the address ranges of all PLC cards that are assigned to the same CPU.

You can export only one separate list each for each processor (CPU). Therefore set the filter in the dialog Addresses / assignment lists so that the [PLC addresses](Glossary_o_sps_adressen.htm) of only one CPU are displayed. With the menu [items](Glossary_o_bauteile.htm) [Extras] > Export address space assignment you open the export dialog of the same name. Here, enter the file name under which the address space assignment list is saved. You can save the list as a CSV file or as a TXT file.

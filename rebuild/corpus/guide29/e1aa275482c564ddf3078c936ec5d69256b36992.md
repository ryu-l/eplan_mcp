# Selecting Parts from the Festo Product Catalog

When selecting parts, you can use the API interface to directly access the Festo product catalog and select parts from this. In this case, the parts must not have been previously imported into the internal parts management.

Preconditions:

- You have opened a project.
- You have installed the Festo product catalog.
- In the festo.cfg configuration file, you have defined the desired [settings](Glossary_o_einstellungen.htm) for the import.
- You have placed a suitable window macro, symbol macro, or a suitable symbol in the graphical editor.

1. Select the [component](Glossary_o_schaltzeichen.htm) in the graphical editor, or the function in one of the [navigators](Glossary_o_navigatoren.htm), and select Edit > Properties.
2. In the Properties <â¦> dialog, select the Parts tab.
3. In the Data source field, select the "Festo product catalog" scheme from the drop-down list.
4. Click [...] in the Part number field.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Festo product catalog opens. The parts are filtered by the "SymbolId" Festo property, i.e., only parts with the "SymbolId" assigned to the corresponding macro or symbol in the configuration file are displayed.
5. Select the desired [part](Glossary_o_artikel.htm)(s) in the Festo product catalog and click [OK].
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts are stored in the project.

![](../Pictures/Gui/ALL/info.png)Tip:

If you wish to transfer the imported parts into the internal parts management then you must first change the scheme for the data source. Open the [properties](Glossary_o_eigenschaften.htm) dialog for a component or a function and select the Parts tab. In the Data source field select the "Default" scheme. After closing the properties dialog, use Utilities > Parts > Synchronize current project to transfer the Festo parts to the internal parts management.

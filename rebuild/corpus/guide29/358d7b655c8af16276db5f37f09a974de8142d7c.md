# Global Editing on Report Pages

The global editing feature allows you to edit the data of source [objects](Glossary_o_objekte.htm) from a report page. The linking between the [reports](Glossary_o_auswertungen.htm) and the source objects is done using placeholder text placed on the [report pages](Glossary_o_auswertungsseiten.htm).

In global editing, the respective object-specific dialog is opened, i.e for the "Function" source object the [properties](Glossary_o_eigenschaften.htm) dialog is opened, for a structure identifier the [structure identifier management](Glossary_o_strukturkennzeichen_verwaltung.htm) is opened. As soon as you confirm a change with [OK], the objects are updated on all [logic pages](Glossary_o_logikseiten.htm) in all views. On the report page itself, the line - or depending on the [form](Glossary_o_verlauf.htm) used - the column containing the changed object is updated. The data on the other report pages remains unchanged but the pages may have to be updated.

The following types of source objects on report pages can be edited using the specified dialog:

| Source object | Editing dialog | Report pages |
| --- | --- | --- |
| Page | Page properties | Table of contents |
| Function | Properties (global): <...> | E.g. device tag lists, device connection diagram, terminal diagram |
| Connection | Properties (global): <...> | E.g. connection list, [cable](Glossary_o_kabel.htm) diagram |
| Parts | Edit [part](Glossary_o_artikel.htm) | Parts list, summarized parts list |
| Project option | Option | Options overview |
| Placeholder object | Placeholder text | Placeholder object overview |
| Structure Identifiers | Structure Identifier Management | Structure identifier overview |

If different types of source object are selected on a report page (e.g. placeholder text and [general devices](Glossary_o_allgemeinebetriebsmittel.htm)) then you are asked which type of object is to be edited, in the same manner as with [block editing](Glossary_o_blockbearbeitung.htm). Then the editing dialog for the selected object type is opened.

If you are not "globally" editing report pages, then double-clicking an object always opens only the Properties - Placeholder text dialog. Changing the text does not have an immediate effect on the object data but is instead limited to the respective report page. The change is lost if the report page is later updated.

### Global editing in search results lists

Global editing of [project data](Glossary_o_projektdaten.htm) is also possible using Results lists. In the popup menu of the Search results dialog, the Properties (global) menu item is available for this. If this feature is used for a specified placeholder text, then the respective object-specific dialog is also displayed. Any changes made are updated at the source object on the report page and also on the logic pages in all views.

### Direct editing in reports

For direct editing of project data in reports, the Direct editing mode is also available. If this mode is switched on (Options > Direct editing), you can directly modify the data of some [function properties](inplaceeditinggui_k_eigenschaften.htm) directly on the report pages. To do this, an editing frame for direct input is displayed below the insertion point as soon as you position the cursor over each placeholder text. After editing, the changed data is written to the object and the placeholder text is updated.

# Dialog Number cables: Preview of result

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have opened the [Generate cables automatically](cablegui_d_kabelerzeugen.htm) dialog, e.g. via the Project data > Cables > Generate cables automatically menu [items](Glossary_o_bauteile.htm).
- You have opened the [Number cables](cablegui_d_kabelnummerierung.htm) dialog, for example via the Project data > Cables > Number menu items.

You have selected the Preview of result check box. Click [OK].

This dialog displays a preview of the DTs that are assigned to the [cable definition lines](Glossary_o_kabeldefinitionslinien.htm), [shields](Glossary_o_abschirmungen.htm), and [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) in the numbering process. You can accept the new device tags, modify the device tags, or keep the old ones.

Overview of the main dialog elements:

The table displays old device tags on the left and new ones on the right for newly generated or existing (but unnamed) [cable](Glossary_o_kabel.htm) definition [lines](Glossary_o_leitungen.htm), shields, and connection definition points.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Use original DT | Accepts the old DT for the selected rows in the right column of the table. |

The final device tags are generated in the subsequent numbering. The device tags that were previously identical are now renamed identically so that all assignments remain.

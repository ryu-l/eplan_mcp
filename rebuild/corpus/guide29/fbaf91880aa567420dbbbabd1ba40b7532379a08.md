# Tab Mounting panel (3D Part Placement)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- The project contains at least one [layout space](Glossary_o_bauraum.htm). The layout space contains [mounting panels](Glossary_o_montageplatten.htm) (3D). You have opened the layout space navigator. Select a mounting panel in the navigator. Select the Properties popup menu item. In the Properties <...> dialog, select the Mounting panel tab.
- You have selected a mounting panel in the 3D display area. Edit > Properties. In the Properties <...> dialog, select the Mounting panel tab.

In this dialog, you specify the [properties](Glossary_o_eigenschaften.htm) for the selected mounting panel.

Overview of the main dialog elements:

Displayed DT:

The displayed DT is displayed in the graphical editor on the [component](Glossary_o_schaltzeichen.htm). If you have defined in the project [settings](Glossary_o_einstellungen.htm) that [devices](Glossary_o_betriebsmittel.htm) are to be automatically numbered when [symbols](Glossary_o_symbole.htm) are inserted, then a DT is automatically suggested here. You can accept this DT or overwrite it manually.

In addition you can use the [popup menu or the [...] button](devicetaggui_r_feldsichtbaresbmk.htm) to [create](Glossary_o_erstellen.htm) or select a DT.

Full DT:

This field displays the full DT (i.e. structure identifier of the current environment + displayed DT) of the component / item. Use the [...] button to open the Full DT dialog. You can edit the [structure identifiers](Glossary_o_strukturkennzeichen.htm) there and select, e.g., another [mounting location](Glossary_o_einbauort.htm).

Item:

In this field, the item definition is displayed; it is imported from the selected function definition and used for the display in the layout space navigator.

Function definition:

The function definition of the mounting panel displayed here is automatically assigned, depending on the function definition of the associated item. Click [...] to open the Function definitions dialog and select a different function definition if required.

# Dialog Project options group

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Project data > Project options > Navigator.

- Select the New > Project options group popup menu [items](Glossary_o_bauteile.htm).
- You have selected a [project options](Glossary_o_projektoptionen.htm) group. Edit > Properties.

In this dialog you [create](Glossary_o_erstellen.htm) a new project options group or edit an existing one.

Overview of the main dialog elements:

Name:

Enter a name for the project options group here, or change the existing name.

Description:

Enter a description text for the project options group here. The description is a multi-language text and is displayed by default in the tree view next to the name, separated by a blank and within round brackets.

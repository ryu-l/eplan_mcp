# Editing Parts

![](../Pictures/Gui/ALL/note.png)Note:

You can also [create](Glossary_o_erstellen.htm) or edit parts in the part selection from the components' [property dialog](Glossary_o_eigenschaftendialog.htm). For this purpose the Modification allowed during selection check box must be activated in the [settings](Glossary_o_einstellungen.htm) (under Options > Settings > User > Management > Part selection). In this case open the [part](Glossary_o_artikel.htm) selection from the [properties](Glossary_o_eigenschaften.htm) dialog not as read-only but rather create and / or edit parts.

### [ClosedPaste a part](javascript:void(0);)

Preconditions:

- You have opened the parts management: Utilities > Parts > Management.
- You have copied or cut a part into the Clipboard.

1. Select the Insert popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) EPLAN generates the new part in the current hierarchical level with the part number original\_part\_number\_1.  

   ![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

   Copies of the part SIE.ABC are named SIE.ABC\_1, SIE.ABC\_2, etc.
2. Edit the copied data in the tabs on the right side of this dialog, or enter new data.  
     
   ![](../Pictures/Gui/ALL/arrow.png) During insertion, only the relevant data is used, i.e., copied data may not be inserted because the target part cannot store that data.

   ![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

   You copy the [cable](Glossary_o_kabel.htm) HELU.33 with order number ABC and a bending radius of 50 cm, and you insert this part as a general single [component](Glossary_o_schaltzeichen.htm). As a result, you have the single part HELU.33\_1 (in the "General" product group) with order number ABC. Since single components have no bending radius, the value of 50 cm is ignored.

![](../Pictures/Gui/ALL/note.png)Note:

The "Copy", "Paste", and "Cut" options are impossible for [variants](Glossary_o_varianten.htm), since they always apply to the entire part. Therefore, if you call up one of these options on the hierarchy level of a variant designation, then the part to which the variant belongs to is cut or copied, and then pasted, along with all of its current variants.

### [ClosedPaste technical data](javascript:void(0);)

After copying a part, its technical data can be carried over to another part.

Precondition:

You have copied the part whose technical data should be copied to the Clipboard using the popup menu Copy or Cut and have selected the parts or variants into which the technical data should be copied.

1. Select the Paste technical data popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The data is copied into the appropriate fields of the parts after any already existing data is first deleted. In the process variable data and the [function templates](Glossary_o_funktionsschablonen.htm) are also taken into consideration. It is here too that only the relevant data is inserted, i.e., copied data possibly might not be inserted because the target part can't store that data.

### [ClosedPaste function templates](javascript:void(0);)

After copying a part, its function templates / function definition can be carried over to another part.

Precondition:

You have copied the part whose function templates / [function definitions](Glossary_o_funktionsdefinitionen.htm) should be copied to the Clipboard using the popup menu Copy or Cut and have selected the parts or variants into which the function templates / function definition should be copied.

1. Select the Paste function templates popup menu item.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The data is copied into the corresponding fields of the parts. The data in the Function templates or Function definition tabs is taken into account. After a confirmation prompt, the existing function templates / function definitions are replaced by the templates / function definition being inserted.

### [ClosedEnter parts data](javascript:void(0);)

Precondition:

You have selected the desired part or variants.

1. Use the tabs on the right-hand side of the dialog to enter data for the selected parts.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If multiple parts are selected, then only data that is identical or undetermined (i.e., "empty") is displayed; this can be entered or changed globally for all selected parts. Compare the dialog-specific information with the fields in the individual tabs.

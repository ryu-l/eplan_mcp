# Dialog Format: PLC data

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the dialog [Settings: Number using PLC data](offlinenumerationplcgui_d_einstellungen.htm) (for example with Options > Settings > Projects > "Project name" > Devices > Number using PLC data). You have selected a [user-defined](Glossary_o_benutzerdefiniert.htm) scheme in the dialog Settings: Number using PLC data. You have selected an entry in the Format groups field and clicked ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit), or you have clicked ![](../Pictures/Gui/ALL/all_new_as.png) (New).

Select a format element of the type "Data" in the Available format elements list of the dialog Number using PLC data: Format and move it to the Selected format elements list by using the arrow button.

In this dialog you specify the formatting for a property in the format group.

The following dialog elements are available:

Category:

From the drop-down list select the [properties](Glossary_o_eigenschaften.htm) that should be displayed in the list below. All properties of the selected type that have not yet been assigned a formatting are then shown.

Minimum number of digits:

Here you define the minimum number of characters to be used for the property value. Longer values are displayed in their full length. Only positive numeric values are permitted. A value of zero means that the field width is variable.

Filler character:

The value is padded with this character if the Minimum number of digits is larger than the width of the value.

Suppress empty properties:

Select this check box so that properties that are not set will not be displayed. In addition to this, the Including preceding separator and Including following separator check boxes enable the suppression of the separators before and after the property.

Suppress properties equaling zero:

Select this check box so that numerical properties equal to zero will not be displayed. In addition to this, the Including preceding separator and Including following separator check boxes enable the suppression of the separators before and after the property.

Language:

For multilingual properties you can specify the output language using the drop-down list.

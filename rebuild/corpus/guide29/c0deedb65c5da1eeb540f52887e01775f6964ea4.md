# Defining a Handle

A handle is used to place a 3D macro. In addition to the handles, which are generated automatically for 3D bodies, there is a [user-defined](Glossary_o_benutzerdefiniert.htm) handle in the macro. When [placing](Glossary_o_auflegen.htm) an item in the project, select this handle in the placement options in the Handle field under the name "Graphical macro".

Preconditions:

- You have opened a project.
- The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open.
- The layout space contains imported 3D bodies which are to be saved as a macro.
- Object snap is switched on.

1. Select the Edit > Device logic > Handle menu [items](Glossary_o_bauteile.htm).
2. Move the cursor over the 3D geometry.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The 3D snap points of the object are displayed. These are the end or center points of an edge or the corner points of a cuboid surrounding the object.
3. Click the required point.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The handle is identified by an orange cuboid.
4. To move the handle to another location, execute the steps 1 to 3 again.

![](../Pictures/Gui/ALL/info.png)Tip:

In the Edit > Create window macro / symbol macro function, modify the handle in the Save as dialog, [Extras] button, using the Define handle menu item.

5. To define the extended handle logic, edit the [properties](Glossary_o_eigenschaften.htm) of the handle.

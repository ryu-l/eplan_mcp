# Tab Function definition

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have selected a [part](Glossary_o_artikel.htm) in the generic product group Mechanics in the tree or list. Select the Function definition tab.

Parts in the generic product group Mechanics have, instead of the Function templates tab, a Function definition tab. It is on this tab that the assignment of the function definition of mechanics [items](Glossary_o_bauteile.htm) to a product group in parts management is set.

Overview of the main dialog elements:

Function definition:

The function definition set here is also displayed in the Properties (components): Part placement (3D) dialog.

Item:

Product group within the generic product group Mechanics that is assigned to the function definition of the part.

The product group set here is also displayed in the Properties (components): Part placement (3D) dialog.

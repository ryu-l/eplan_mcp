# Tab General (Settings: External editing)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Utilities > Edit properties externally > Export data. Click [...] next to the Settings field in the Edit externally dialog. Select the General tab.

- Options > Settings > User > Interfaces > External editing. Select the General tab.

In this tab you specify the general [settings](Glossary_o_einstellungen.htm) for external editing.

The following dialog elements are available:

File type:

In this drop-down list, select the file type to be used when exporting. Depending on your selection, you can open the dialog for the corresponding settings using [Options].

Target file:

In this field, define the drive, directory, and name of the target file to be created, or click [...] to interactively select the drive and directory.

You can use the Insert path variable popup menu item to branch to the [Select path variable](modaldialogsdb_d_pfadvariablen.htm) dialog, where you can select one of the available EPLAN-specific [path variables](Glossary_o_pfadvariablen.htm).

Template:

If you have selected the "Excel file (\*.xls, \*.xlsx, \*.xlsm, \*.xlsb)" entry from the File type drop-down list, then you can enter the file path and name of a template file or select a file using [...] in this field; this template then defines the format of the exported data.

You can use the Insert path variable popup menu item to branch to the [Select path variable](modaldialogsdb_d_pfadvariablen.htm) dialog, where you can select one of the available EPLAN-specific path variables.

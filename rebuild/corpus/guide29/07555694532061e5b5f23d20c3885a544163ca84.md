### Locked editing functions

User interface / operation

Dialogs, menu items, and toolbars in the user interface can be locked using the rights management. The respective editing functions and dialogs are then either not displayed or their data cannot be changed. When a locked editing function is called up, an appropriate message describing the missing rights is displayed.

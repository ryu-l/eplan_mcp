# P028005: The value sets at the segment or at the segment template do not match the macro specified

### Cause

The value set of a placeholder object that is assigned to the macro stored by you at the segment or at the segment template was modified subsequently.

Or the macro stored at the segment or segment template does not exist anymore, because it was deleted subsequently.

Or the storage location of the macro stored at the segment or at the segment template was modified subsequently.

### Solution

1. Locate the respective segment or segment template in the project using the Go to (graphic) or Synchronize selection [functions](Glossary_o_funktionen.htm) offered by the popup menu of the Message management dialog.
2. Call up the Properties <...> dialog of the segment or segment template and bring the Macro tab to the front.
3. Update the data at the segment or segment template via the ![](../Pictures/Gui/ALL/all_update_as.png) button, if a schematic page has already been created by means of the macro. (If no schematic page has been generated yet, the data from the macro is automatically transferred to the segment or segment template when the [property dialog](Glossary_o_eigenschaftendialog.htm) is opened for the first time.)  
   For the case that the macro stored at the segment or at the segment template does not exist anymore or was changed subsequently, delete the macro name and reselect the macro. Or, if appropriate, [create](Glossary_o_erstellen.htm) a new macro (with the desired [placeholder objects](Glossary_o_platzhalterobjekte.htm) and value sets) and store it again at the planning object.
4. Then start a new check run.

# Dialog Edit block reference properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a page in the graphical editor. You have combined several elements to a block and selected this block. Edit > Properties (or Popup menu > Properties).

This dialog displays the [properties](Glossary_o_eigenschaften.htm) of a block reference.

The following dialog elements are available:

Number of objects:

This field shows the number of [objects](Glossary_o_objekte.htm) contained in the block.

Number of references:

This field shows how many references to this block are placed in the project. (At present only one reference is possible.)

Name of referenced block:

Provide a name for the block here. In a [DXF / DWG export](Glossary_o_dxf_dwg_export.htm), this name is stored in the exported file.

[Break up block]:

Breaks up the block into its individual elements. The individual objects can then be individually edited.

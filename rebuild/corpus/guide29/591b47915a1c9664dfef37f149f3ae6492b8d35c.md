# Dialog Settings: Project group (assignment)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Options > Settings > Projects > "Project name" > Display > Project group (assignment).

In this dialog, you assign a project group to a project. This activates the [settings](Glossary_o_einstellungen.htm) for the project (color in [project data](Glossary_o_projektdaten.htm) [navigators](Glossary_o_navigatoren.htm), provision of additional project data navigators), that you specified for the project group in the dialog Settings: Project groups (definition).

Overview of the main dialog elements:

Project group assignment:

Select the desired project group from the drop-down list.

![](../Pictures/Gui/ALL/note.png)Note:

Two of the possible five [project groups](Glossary_o_projektgruppen.htm) are predefined ("Project group 1: Schematic [projects](Glossary_o_projekte.htm)", "Project group 2: Macro projects"). The names of these project groups cannot be modified. If a name is also to be displayed for the project groups 3-5 behind the designation "Project group <3-5>:", you have to specify it in the [user-defined](Glossary_o_benutzerdefiniert.htm) settings during the definition.

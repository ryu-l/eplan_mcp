# New Markers for Jump Targets in the PDF

In an exported PDF document the jump targets after the jump are now marked by a red, blinking frame. Possible jump targets are for example [devices](Glossary_o_betriebsmittel.htm) on the schematic pages, generated device pages etc. If the Archiving format PDF/A check box is activated in the [settings](Glossary_o_einstellungen.htm) for the PDF export, no red markers are generated. In addition further improvements for the PDF Export were implemented, such as changed default settings.

[![](../Pictures/Visualisation/ALL/pdfexportgui_newmarks_av_thumb_0_60.png)](../Pictures/Visualisation/ALL/pdfexportgui_newmarks_av.png)

![](../Pictures/Gui/ALL/benefit.png)Benefit:

The new jump markers and modified default settings for the export make the orientations on the export pages easier for jumps in the PDF.

### Changed default settings for the PDF export

In the course of this extension the default settings for the PDF export were also changed:

- The [user-specific](Glossary_o_benutzerbezogen.htm) setting Use zoom is now deactivated by default.
- For the Zoom level setting the value was changed from "50.00 mm" / "1.9685 In" to "120.00 mm" / "4.7244 In".

(A possible menu path for the settings dialog is: Options > Settings > User > Interfaces > PDF export; General tab.)

### Jumps between main and auxiliary functions of 2D mounting panels

Jumps between 2D [mounting panels](Glossary_o_montageplatten.htm), that are placed as main and [auxiliary functions](Glossary_o_nebenfunktionen.htm) on pages of the type "Panel layout", are now also possible in the PDF documents.

### Display of property arrangements from the layout space in the 3D view

The property arrangements of the [items](Glossary_o_bauteile.htm) in the [layout space](Glossary_o_bauraum.htm) can now be recognized after the PDF export. The displayed [properties](Glossary_o_eigenschaften.htm) of a 3D model in a PDF file are identical with the display in the layout space.

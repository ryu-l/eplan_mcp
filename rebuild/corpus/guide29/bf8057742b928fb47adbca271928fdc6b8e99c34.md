# P026056: Connection cross-section is larger than specified in the connection point pattern

### Cause

The cross-section of the routed connection is larger than the cross-section set in the connection point pattern of the [part](Glossary_o_artikel.htm) placement in the Max. cross-section / diameter column.

### Solution

1. Reduce the value of the cross-section at the routing connection (or the corresponding multi-line connection in the schematic) so that it amounts to no more than the value entered in the connection point pattern in the Max. cross-section / diameter column. Or, alternatively, adjust in this column the cross-section value to the cross-section of the routing connection by increasing the value accordingly.
2. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

This check run considers the entered values in the Max. AWG field of the connection point pattern of the part placement as follows:

If a value that has the unit "AWG" is stored at the routing connection in the [layout space](Glossary_o_bauraum.htm) or in the multi-line connection in the schematic in the Cross-section / diameter field, the value entered in the connection point pattern of the part placement in the Max. AWG column is taken into consideration during the check, in as far an entry is available there. If no entry is available there, the cross-section specification entered in the connection point pattern in the column Max. cross-section / diameter is used for the check if the value is greater than 0.01 mm².

If no "AWG" value is stored at the routing connection in the layout space or in the multi-line connection in the schematic in the Cross-section / diameter field, the value entered in the connection point pattern of the part placement in the Max. cross-section / diameter column is considered during the check, in as far an entry is available there. If no entry is available there, the value entered in the connection point pattern in the column Max. AWG is used for the check.

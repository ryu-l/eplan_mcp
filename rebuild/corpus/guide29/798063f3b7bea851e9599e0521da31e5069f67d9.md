[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_projekte.htm)

### Projects

User interface / operation

In EPLAN, schematics and attached documents such as lists and overviews are created as pages within projects. A project is a database in which, besides the project pages, all master data used in the project (symbols, plot frames, forms, parts data, etc.) is stored. Projects are stored and organized in a second database - the so-called project management (see [Project management databases](Glossary_o_projektverwaltungsdatenbanken.htm)).

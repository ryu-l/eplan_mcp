# Working with Workspaces

An EPLAN workspace includes the size and position of the EPLAN [main window](Glossary_o_hauptfenster.htm) as well as the positions, sizes and [settings](Glossary_o_einstellungen.htm) of the "dockable" dialogs, menus, and [toolbars](Glossary_o_symbolleisten.htm). User-defined toolbars are also saved with a workspace.

This is handy, for example, for adjusting EPLAN to different project planning tasks. You can switch to PLC editing at the "push of a button", for example, and automatically open all of the dialogs you need for that whereby positions and settings are already specified. All unnecessary dialogs are automatically closed.

Work areas can be saved as schemes at any time and then selected or deleted at a later date. With EPLAN you can use several a predefined work areas in the Workspace dialog, which you can use as a template for future work areas, for example. Just as you usually can with the schemata, you can also [create](Glossary_o_erstellen.htm), copy, delete, import and export schematas for the work area by using a [toolbar](schemeconfig_m_schemaschaltflaechen.htm).

![](../Pictures/Gui/ALL/note.png)Note:

You cannot save the size, position or other Editor settings (graphical editor, [symbol editor](Glossary_o_symboleditor.htm), [form](Glossary_o_verlauf.htm) editor, etc.) for one work area.

### [ClosedDefine workspaces](javascript:void(0);)

Precondition:

You have adjusted the user interface of EPLAN for a certain project planning task.

1. View > Workspace
2. In the Workspace dialog, click ![](../Pictures/Gui/ALL/all_new_as.png) (New) on the toolbar beside the Scheme drop-down list.
3. In the New scheme dialog in the Name field enter the name of the new scheme, that is, overwrite the name of the one that is currently selected.
4. Enter a short descriptive text for the new scheme in the Description field.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The New scheme dialog is closed, iand the new scheme is set as the current one.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new workspace is created under the specified name. The current interface settings for open "dockable" dialogs, dialog positions, toolbars, etc, are saved.

If you want to, you can change the interface configuration of this work area (e.g. change the size and position of "dockable" dialogs, import customized toolbars, etc.) and save it again (see "Edit [workspaces](Glossary_o_arbeitsbereiche.htm)").

### [ClosedSelecting Workspaces](javascript:void(0);)

1. View > Workspace
2. Select the workspace you want to use from the Scheme drop-down list in the Workspace dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The information in the Description field is updated.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The settings made in the selected workspace for open "dockable" dialogs, dialog positions, toolbars, etc. are applied and the program's user interface is updated accordingly.

### [ClosedEdit workspaces](javascript:void(0);)

If necessary, the interface configuration of a workspace can be adjusted first and then saved again after any additional editing. When you edit a workspace you can also overwrite a selected workspace with the contents of another workspace. This could be useful if, for example, you want to use an existing scheme as a template for a new workspace.

1. View > Workspace
2. Click ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit) in the Workspace dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Edit workspace dialog opens.
3. Here you then select the Current configuration entry if the selected workspace should be saved again. If you want to use a different scheme as a template for the current workspace, select the name here. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Edit workspace dialog closes.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The changed settings will be saved in the current workspace.

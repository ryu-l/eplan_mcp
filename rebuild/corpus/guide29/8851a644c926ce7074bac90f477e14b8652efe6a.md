# Inserting and Changing Routing Ranges

Routing ranges are [part](Glossary_o_artikel.htm) of the routing path network. In [routing ranges](Glossary_o_verlegebereiche.htm), [connections](Glossary_o_verbindungen.htm) are not routed along a routing path, but always it is the shortest possible and direct connection that is routed. This way, for example, it possible to implement [wiring](Glossary_o_verdrahtungen.htm) on the back of a mounting panel.

- The placement of routing ranges is similar to that of locked areas.
- A cuboid with transparent representation is generated.
- No [items](Glossary_o_bauteile.htm) may be located in or protrude into routing ranges, because they are not taken into account during routing. This condition is checked by a check run ([P026036](messages_p_026036.htm)).
- Routing ranges placed next to each other are not connected with each other automatically. The connection must be established through manual [routing paths](Glossary_o_strecken.htm) that terminate at the edges.

### [ClosedInserting Routing Ranges](javascript:void(0);)

1. Select the menu items Insert > Routing range.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The status bar shows a prompt "Starting point of the routing range".  
     
   ![](../Pictures/Gui/ALL/arrow.png) When determining the starting and end point, you can use the Placement options popup menu item, and use the relative coordinate input.
2. Place the starting point of the routing range on an activated area.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The status bar shows a prompt "End point of the routing range".
3. Pull the routing range apart in the desired direction like a rectangle.
4. Place the end point freely, or capture another point.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The routing range is inserted as a transparent cuboid on the activated area.  
   ![](../Pictures/Visualisation/ALL/routing_routingrange_as.png)

### [ClosedChanging the size of routing ranges](javascript:void(0);)

To change the size of routing ranges, enter changed values for Width, Height and Depth in the [property dialog](Glossary_o_eigenschaftendialog.htm) on the Format tab. The change is made referenced to the bottom left-hand corner.

A graphical change in size is possible for routing ranges with the Edit > Graphic > Change length functionality. The graphical change is possible for one of the three dimensions respectively.

Preconditions:

- You have opened a project.
- The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open.
- The layout space contains at least one routing range.

1. Select the Edit > Graphic > Change length menu items.
2. Click the object to be changed.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A 3D coordinate system appears at the four corner points of the front surface when you touch them with the cursor.  
   ![](../Pictures/Visualisation/ALL/cabinetgui_modifydimension1_as.png)
3. Select the desired axis by clicking and with that the dimension to be changed.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The axis in whose direction a dimension can be changed is displayed in green.  
   ![](../Pictures/Visualisation/ALL/cabinetgui_modifydimension2_as.png)
4. After specifying the change of direction pull the 3D object in the selected direction. The following entry [forms](Glossary_o_formulare.htm) can be used:

- Free point entry by clicking

- Usage of a snap or a projection point at another object

- Usage of [grid](Glossary_o_raster.htm) points

- Entering a positive or negative value in the input box.  
    
  ![](../Pictures/Visualisation/ALL/cabinetgui_modifydimension3_as.png)

![](../Pictures/Gui/ALL/arrow.png) After the change the new dimensions are displayed in the property dialog on the Format tab.

# Inserting a Window Macro with P&I Diagram Data

If you want to reuse page sections that contain [P&I diagram](Glossary_o_ri_fliessbild.htm) data several times, you store these in a window macro. In addition to the usual [symbols](Glossary_o_symbole.htm) from [process engineering](Glossary_o_verfahrenstechnik.htm), such a window macro can also contain components that are linked with [segments](Glossary_o_segmente.htm) from the pre-planning ([PCT loops](Glossary_o_plt_stellen.htm), [PCT loop functions](Glossary_o_plt_stellenfunktionen.htm), containers, [planning objects](Glossary_o_planungsobjekte.htm), piping planning [objects](Glossary_o_objekte.htm), etc.). When inserting the window macro on a P&I diagram page of a different project, the contained segments are taken into consideration and can be transferred into a current project.

Preconditions:

- You have opened a project.
- You have opened a page of the "P&I diagram" type.

1. Select the following menu [items](Glossary_o_bauteile.htm): Insert > Window macro / symbol macro
2. In the Select macro dialog, select an \*.ema window macro with the representation type "P&I diagram".  
     
   ![](../Pictures/Gui/ALL/arrow.png) When the window macro is selected, then the representation type is displayed in the Representation type field.
3. Click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The macro is attached to the cursor and can be positioned wherever you want (single click).  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the window macro contains [devices](Glossary_o_betriebsmittel.htm) with [structure identifiers](Glossary_o_strukturkennzeichen.htm) that are not yet included in the project, they are inserted according to the user [settings](Glossary_o_einstellungen.htm) for identifiers (option Enter new identifiers in alphabetical order or Add new identifiers to the end) in the table of identifiers.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Select structure dialog is opened and allows for sorting all PCT [loops](Glossary_o_messstellen.htm) / PCT loop [functions](Glossary_o_funktionen.htm) / containers, etc. of the window macro into the existing structure.
4. Select a segment in the Source field.
5. In the Project field, select the segment below which the segment from the source is to be sorted in.
6. Move the segment using the arrow button or per Drag & Drop from the Source field into the Project field.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the window macro contains a DT and you have selected With prompt under Options > Settings > Projects > "Project name" > Devices > Numbering (online), the Insertion mode dialog is displayed.
8. To optionally number devices, select a numbering setting in the Insertion mode dialog.
9. Click [OK].

# Checking Device Tags

A device typically contains all of the identifying information (such as [higher-level function](Glossary_o_anlage.htm), [mounting location](Glossary_o_einbauort.htm), and identifier) in its device tag. An identifier check function is available for checking the length and validity of the characters in the specifications for the DT.

Precondition:

You have opened a project.

1. Options > Settings > Projects > "Project name" > Devices > DT syntax check
2. In the Settings: DT syntax check dialog on the Electrical engineering and / or Fluid tab, select the Enable check check box.
3. In the Device tag and Count numbers group boxes, specify the scope of the check for the device tag components of the full DT.
4. In the Identifier blocks group box on the Structure identifier tab, specify the scope of the check for the [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) within the full DT.
5. Click [OK].

After specifying the device data in the Properties <...> dialog, EPLAN checks whether the syntax for the specified device tag identifier is correct. The entire device tag string is always checked (i.e. the full DT). The [settings](Glossary_o_einstellungen.htm) on the Structure identifier tab are used for the identifier [blocks](Glossary_o_bloecke.htm), even if the check box is deselected on that tab.

![](../Pictures/Gui/ALL/note.png) Note:

The Enable check check box on the Structure identifier tab only has to be selected if you want to check other [structure identifiers](Glossary_o_strukturkennzeichen.htm), in addition to the electrical engineering or [fluid power](Glossary_o_fluidtechnik.htm) DTs (pages, for example).

If the syntax does not meet the defined criteria, EPLAN opens a message dialog in which the incorrect elements are displayed. Via [Settings], you can go from this message dialog to the setting for DT syntax checking. There you can check, and if necessary, correct your syntax settings. If the "error" is a an intentional deviation from the syntax, you can select [Ignore] to leave the dialog and accept your entry without having to change the settings.

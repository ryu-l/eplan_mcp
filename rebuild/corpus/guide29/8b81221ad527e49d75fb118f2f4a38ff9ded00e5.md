# Inserting and Editing Special Text

Preconditions:

- You have opened a project.
- You have opened the [form](Glossary_o_verlauf.htm) in which you want to define [special texts](Glossary_o_sondertexte.htm) in the form editor (Utilities > Master data > Form > Open > [Open]). You have opened the plot frame in which you want to define special texts in the plot frame editor (Utilities > Master data > Plot frame > Open > [Open]).

### Insert project and page properties in forms and plot frames

The special project and page [properties](Glossary_o_eigenschaften.htm) available for [forms](Glossary_o_formulare.htm) and [plot frames](Glossary_o_normblaetter.htm) are placeholders that are automatically replaced with the corresponding properties by EPLAN.

1. Insert > Special text
2. Select one of the options Page properties or Project properties.
3. Click [...] in the Property field of the Placement tab on the Special text <...> dialog.
4. In the Property selection dialog, select the page or project property that should be inserted in the plot frame / form.
5. If needed, limit the display of possible properties by selecting an entry from the Category drop-down list.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected property is adopted in the Property field.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The element hangs on the cursor.
8. Position the special text on the plot frame / form page.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The element hangs on the cursor.
9. Position the special text a second or third time.
10. Select the Cancel action popup menu item to exit the action.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The special text is inserted on the plot frame / form page and can be revised by double-clicking it.

![](../Pictures/Gui/ALL/note.png) Note:

EPLAN internally notes the last selected property and suggests it again when next inserting. All [settings](Glossary_o_einstellungen.htm) made during the placement are also used.

### Insert form and plot frame properties in forms and plot frames

The form and plot frame properties available for forms and plot frames are property placements that can be formatted as desired. Only the properties permissible for the respective form / plot frame type are available for selection.

The procedure for inserting these special texts is identical to that described above for page and [project properties](Glossary_o_projekteigenschaften.htm).

### Insert column and row texts in plot frames

There are also column and row texts available for plot frames in addition to the project and page properties.

1. Insert > Special text
2. Select one of the options Column text or Row text from the subsequent menu.
3. Specify the formatting settings for the row and column text in the Format tab of the Special text <... > dialog.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The element hangs on the cursor.
5. Position the special text on the plot frame page.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The element hangs on the cursor.
6. Position the special text a second or third time.
7. Select the Cancel action popup menu item to exit the action.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The special text is inserted on the plot frame page and can be revised by double-clicking it.

![](../Pictures/Gui/ALL/note.png) Note:

The Utilities > Place column and row text again option can be used to delete these special texts and automatically place them on the border areas of the defined columns and rows.

# P013054: Part with index '<x>': The property '<y>' cannot be changed when the bill of materials is imported

### Cause

When importing the bill of materials, an attempt was made to change the property of a [part](Glossary_o_artikel.htm) reference in the import file, e.g. the Order number property. However, this property cannot be changed.

### Solution

Undo the change, then import the bill of materials again.

![](../Pictures/Gui/ALL/note.png) Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

# Tab Settings (Rittal - Wire Terminal WT)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Wire fabrication > Rittal - Wire Terminal WT > Settings
- Utilities > Manufacturing data > Wire fabrication > Rittal - Wire Terminal WT. Click [...] next to the Scheme field. Select the Settings tab.

In this tab, information on the technical options of the machine to be used is stored. The individual [settings](Glossary_o_einstellungen.htm) are pre-set with appropriate values in a machine-specific manner, and can be modified here.

Overview of the main dialog elements:

Wire length minimum:

Minimum length the machine requires to handle the wire as defined (default value: 230 mm). Shorter [wires](Glossary_o_draehte.htm) are transferred to the machine with this minimum length.

Wire length maximum:

Wires that are longer than specified here cannot be processed by the machine (default value: 10,000 mm).

Conductor cross-section minimum:

Minimum cross-section of a wire that the machine can still process (default value: 0.5 mm²).

Conductor cross-section maximum:

Maximum cross-section of a wire that the machine can still process (default value: 2.5 mm²).

Routing direction up / down / left / right:

Texts that are to be printed on the wire to indicate individual [routing directions](Glossary_o_verlegerichtungen.htm).

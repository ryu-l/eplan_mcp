# P003025: Number of connections not specified

### Cause

The number of [connections](Glossary_o_verbindungen.htm) is not specified for the [cable](Glossary_o_kabel.htm)'s main function.

### Solution

Locate the cable's main function in the schematic from the Message management dialog using the Go to (graphic) functionality. Then double-click the selected cable definition line and call up the Properties <...> dialog for the cable. If not already set by default, switch to the Cable tab and enter a value in the Number of connections field. Alternatively you can carry out a [part](Glossary_o_artikel.htm) selection and assign a suitable type to the cable. To do this, click [...] beside the Type field and select the cable with the required [properties](Glossary_o_eigenschaften.htm) from the part selection dialog.

Click [OK] then start a new check run.

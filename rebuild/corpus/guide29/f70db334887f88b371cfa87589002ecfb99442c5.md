# P004005: Missing PLC connection point on overview

### Description

You cannot make a cross-reference between a PLC connection point in the schematic and a PLC connection point on the overview page.

### Cause

A PLC connection point in the schematic cannot be cross-referenced with the corresponding PLC connection point because of a missing device tag in the PLC box in the overview.

### Solution

Enter the same DT at the PLC connection point in the PLC box in the schematic and in the PLC box in the overview, and start a new check run.

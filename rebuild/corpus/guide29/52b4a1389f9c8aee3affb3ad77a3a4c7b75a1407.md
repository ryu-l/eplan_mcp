# Tabs <Function category> / <Function category> (Device)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call of <Function category> tab:](javascript:void(0);)

You have opened a project.

- You have inserted a symbol in the graphical editor or generated a new function in a navigator. In the Properties <...> dialog, select the <Function category> tab.
- You have selected the function of a general device in the graphical editor or in a navigator. Edit > Properties. Select the <Function category> tab.
- You have selected an auxiliary function of a general device in the graphical editor or in a navigator. Select the Properties (global) popup menu item.

In this dialog you specify the [properties](Glossary_o_eigenschaften.htm) for the selected function. The tab is labeled with the function category of the corresponding function definition, e.g., "Motor", "NO contact", "Safety fuse", etc.

In the Properties (global) editing mode, you can edit the properties for all function representations at once; otherwise, the [functions](Glossary_o_funktionen.htm) of distributed functions can be independently edited.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call of <Function category> (device) tab:](javascript:void(0);)

You have opened a project.

- You have selected a main function of a general device in the graphical editor or in a navigator. Select the Properties (global) popup menu item.
- You have selected an auxiliary function of a general device in the graphical editor or in a navigator. Select the Properties (global) popup menu item. Select the <Function category> (device) tab.

In this tab you edit the main function and all its representations in the Properties (global) editing mode, i.e., you define the properties of the device of the selected function. The tab is labeled with the function category of the corresponding function definition, e.g., "Motor", and the suffix "(Device)" for [devices](Glossary_o_betriebsmittel.htm). Not all properties that can be edited in the individual function representations are always available.

If you have opened the [property dialog](Glossary_o_eigenschaftendialog.htm) for an auxiliary function, then the <Function category> tab for the selected auxiliary function and an additional <Function category> (device) tab for the associated main function are displayed.

Overview of the main dialog elements:

Displayed DT:

The displayed DT is displayed in the graphical editor on the [component](Glossary_o_schaltzeichen.htm). If you have defined in the project [settings](Glossary_o_einstellungen.htm) that devices are to be automatically numbered when [symbols](Glossary_o_symbole.htm) are inserted, then a DT is automatically suggested here. You can accept this DT or overwrite it manually.

In addition you can use the [popup menu or the [...] button](devicetaggui_r_feldsichtbaresbmk.htm) to [create](Glossary_o_erstellen.htm) or select a DT.

Full DT:

This field displays the full DT (i.e. structure identifier of the current environment + displayed DT) of the component / item. Use the [...] button to open the Full DT dialog. You can edit the [structure identifiers](Glossary_o_strukturkennzeichen.htm) there and select, e.g., another [mounting location](Glossary_o_einbauort.htm).

Connection point designation:

This field displays the [connection point designations](Glossary_o_anschlussbezeichnungen.htm) of the current function.   
If the project setting Adopt connection point designation has been activated (Options > Settings > Projects > "Project name" > Management > Compatibility), the connection point [designations](Glossary_o_bezeichnungen.htm) of the functions adopting the DT from the current function are additionally displayed.

You can manually change the connection point designations for the function / device or select an entry from the drop-down list. Several connection point designations are separated by a paragraph mark. When manually editing multiple connection point designations keep the following in mind:

- You may change specific individual connection point designations by entering the value at the actual place between the paragraph marks.
- If you overwrite the entire entry with one single value, this value will be assigned to the first connection point. The connection point designations of the other [connection points](Glossary_o_anschluesse.htm) will remain unchanged.
- If you delete the entire entry, all connection point designations will be deleted.

![](../Pictures/Gui/ALL/note.png)Note:

The contents of this field is not stored in just one property. You can use the Connection point designations (all) ([ID](Glossary_o_id.htm) 20038) property to display the connection point designations at the component. This property displays all connection point designations of the current function. The connection point designations of other functions that are displayed in the field Connection point designation are not included in this property though.

Connection point description:

Enter the [connection point descriptions](Glossary_o_anschlussbeschreibungen.htm) for the function / device here, or select the data from the drop-down list.

Technical characteristics:

Here you enter the technical characteristics for the function / device.

Function text:

Here you enter the function text for the function / device.

Aside from the manually entered function text, there are other (automatically determined) [function texts](Glossary_o_funktionstexte.htm) that you will find in the table of properties:

- Function text (automatic): Displays the content of the manually entered function text or, if it is empty, the path function text. If you edit this function text in the Properties (global) processing mode, the content is returned to the function where the function text was entered originally. When this property is displayed on a project page, the line breaks are removed.
- Function text (common): Displays the function text (automatic) of the function or, if it is empty, the function text (automatic) of the associated main function.

Engraving text:

Here you enter the engraving text for the function / device, or select an entry from the drop-down list. The list shows all values that you have previously entered for the same type of function at other places in the project.

Mounting site (describing):

Enter the descriptive mounting site for the function / device here, or select an entry from the drop-down list. The list shows all values that you have previously entered for the same type of function at other places in the project.

Main function:

Since general functions are cross-reference-capable, they can display both main and [auxiliary functions](Glossary_o_nebenfunktionen.htm): Activate / deactivate this check box to modify the setting.

If the check box is checked, the function is a main function and can contain parts information.

If the check box is not checked, then the function is an auxiliary function. The Parts tab is hidden in this case, since auxiliary functions contain no parts information.

When using a DT for which there is already a main function, when using a placed main function, or when [placing](Glossary_o_auflegen.htm) an already placed main function, this property will automatically be switched off at the target function, that is, the check box is deactivated.

![](../Pictures/Gui/ALL/note.png)Note:

The setting is automatically compared to the check box of the same name in the Symbol / function data tab.

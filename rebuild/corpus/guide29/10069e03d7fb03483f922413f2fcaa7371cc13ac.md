# P020010: <x> has a different definition setting

### Description

When restoring a filed-off project, the [settings](Glossary_o_einstellungen.htm) of the filed-off project are compared with the settings of the source project. There is a difference in the definition settings.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

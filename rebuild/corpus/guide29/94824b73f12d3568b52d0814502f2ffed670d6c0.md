# Defining a Copper Part

Precondition:

You have opened a project.

1. Utilities > Parts > Management
2. In the Parts management dialog, navigate into the tree structure of the parts under "Mechanics" > "Component" > "Busbars" hierarchy level up to the "Rail" node.
3. Create a new entry using the New popup menu item.
4. Complete all relevant fields on the General tab, especially the fields Part number and Designation 1.
5. On the Mounting data tab, define the values for Width and Depth in order to set the dimensions of the rectangular basic outline of the rail.  
     
   ![](../Pictures/Gui/ALL/arrow.png) These entries are used for the placement to define the rectangular basic outline of the bent rail.
6. On the Function definition tab, select the "Busbar" function definition and the "Busbars - General" item designation.
7. Save the new [part](Glossary_o_artikel.htm) with [Apply] if you wish to define other parts, or save it using [Close] if you wish to define only this part and close parts management.

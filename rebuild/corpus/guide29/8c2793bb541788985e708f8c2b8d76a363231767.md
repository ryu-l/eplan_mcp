# Dialog Settings: External editing

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Utilities > Edit properties externally > Export data. Click [...] next to the Settings field in the Edit externally dialog.

- Options > Settings > User > Interfaces > External editing.

In this dialog, you can manage and edit [schemes](Glossary_o_schemata.htm) for external editing. A scheme specifies [settings](Glossary_o_einstellungen.htm) for external editing.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

![](../Pictures/Gui/ALL/note.png)Note:

To access old schemes, these must first be exported in the previous version. This can be done either for all schemes of an area via the ![](../Pictures/Gui/ALL/all_export_as.png) (Export) button in the left-hand area of the settings dialog (toolbar above the tree structure of the settings ranges) or for an individual scheme via the ![](../Pictures/Gui/ALL/all_export_as.png) (Export) button in the right-hand area of the settings dialog (toolbar next to the Scheme field).

After the import, the schemes will then be converted into the new format via the corresponding ![](../Pictures/Gui/ALL/all_import_as.png) (Import) button.

Object type:

A scheme for external editing is always generated in conjunction with an object type. In this field the object type is displayed that you have selected while creating the current scheme via the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button in the Object type dialog. Subsequent changes can then not be made to the object type!

The following [object types](Glossary_o_objekttypen.htm) are available for selection in the Object type dialog:

- Interruption points
- Shields
- All [functions](Glossary_o_funktionen.htm)
- General functions
- Part placement (3D) (license-dependent)
- Cables
- Terminals
- Terminal strips
- Path [function texts](Glossary_o_funktionstexte.htm)
- Potential definition
- Piping definition
- [PLC connection points](Glossary_o_sps_anschluesse.htm)
- [PLC boxes](Glossary_o_sps_kaesten.htm)
- Segment: Containers
- Segment: [PCT loops](Glossary_o_plt_stellen.htm)
- Segment: [PCT loop functions](Glossary_o_plt_stellenfunktionen.htm)
- Segment: Planning [objects](Glossary_o_objekte.htm)
- Segment: Structure [segments](Glossary_o_segmente.htm)
- Segment template: Containers
- Segment template: PCT [loops](Glossary_o_messstellen.htm)
- Segment template: PCT loop functions
- Segment template: Planning objects
- Segment template: Structure segments
- Pages
- Plugs
- Pins
- Structure boxes
- Connections
- Connection definition points with DT.

# Access to the EPLAN Data Portal

Our Internet portal for device data â the EPLAN Data Portal â supplies you with the [master data](Glossary_o_stammdaten.htm) of known manufacturers for the direct application to the EPLAN platform. In addition to alphanumeric parts data, among other information this master data also contains schematic [macros](Glossary_o_makros.htm), multilingual parts information, preview images, documents, etc. The data, supplied by the manufacturers, is directly integrated into the EPLAN platform when downloaded.

In the current version of the EPLAN platform, the EPLAN Data Portal is available in the following program [variants](Glossary_o_varianten.htm):

- EPLAN Electric P8
- EPLAN Fluid
- EPLAN Preplanning
- EPLAN Pro Panel Professional
- EPLAN Education for Classrooms.

In order to access the portal productively after installing a program variant, you will require a valid software service agreement for your EPLAN license. For a quick [part](Glossary_o_artikel.htm) search, you can also go directly to the website "https://www.eplandata.de/portal/".

After creating a user account (via the menu [items](Glossary_o_bauteile.htm) Options > Settings > User > Management > Data Portal), open the navigator of the EPLAN Data Portal by selecting the Data Portal menu item from the Utilities menu.

![](../Pictures/Gui/ALL/note.png)Notes:

- You must be connected to the Internet in order to use the EPLAN Data Portal, and you must make sure that access is not prevented by a firewall or any other security mechanism! If you have problems, you should first check your firewall, virus scanner, or proxy [settings](Glossary_o_einstellungen.htm).
- Note that the EPLAN Data Portal has been released for Microsoft Internet Explorer 11.

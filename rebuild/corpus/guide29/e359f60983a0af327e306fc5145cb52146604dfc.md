# Tab Project (Changing Standards)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. In the case of several opened [projects](Glossary_o_projekte.htm): You have selected a project in the page navigator. Utilities > Change of standard.

You configure a target project in this tab. A target project is created in order to adjust a project to a different standard.

Overview of the main dialog elements:

Source project name:

This field contains the project to be adjusted to a different standard. This source project is not changed during the next standard change.

Target project name:

In this field, you specify the project name for the target project without the file extension.

Storage location:

This field contains the directory where the new project is to be saved. EPLAN suggests using the directory specified under the menu [items](Glossary_o_bauteile.htm) Options > Settings > User > Master data > Directories in the Projects field as the save location.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).

Apply project properties from the source project:

If this check box is activated, the [properties](Glossary_o_eigenschaften.htm) are taken from the properties of the source project. If the check box is deactivated, they are taken from the template. User-defined properties are always taken from the source project.

# Tab Mounting rails

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have selected a [part](Glossary_o_artikel.htm) in the tree or list view, from the Generic product group "Mechanics", Product group "Busbars", Product subgroup "Adapter".

In this tab, you define the specific data for adapter [mounting rails](Glossary_o_tragschienen.htm), i.e. for parts from the Generic product group "Mechanics", Product group "Busbars", Product subgroup "Adapter". The data can be specified more than once per part, namely once per variant.

Overview of the main dialog elements:

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# Static forms: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_statischeformulare.htm)

### Static forms

User interface / operation

Appears only once in a project and contains no reports on schematic data (e.g. cover sheet). It is characteristic that the graphics of the form are fixed for a static form, so that it always has 30 rows, for instance, regardless of how many records are displayed (e.g. only 20).

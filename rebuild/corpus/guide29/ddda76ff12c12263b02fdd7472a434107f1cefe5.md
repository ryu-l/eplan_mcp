# P004054: Connection only in project! The connection to '<x>' only exists in the project

### Cause

A network connection was found in the project that was not contained during the last import of the PLC data.

### Solution

Remove the network connection at the bus port of the device <x> specified in the message.

![](../Pictures/Gui/ALL/note.png)Note:

This module-specific message is generated by the importing of PLC data. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

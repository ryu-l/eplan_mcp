# Assigning a Part to a Device

Parts can only be assigned to the main function of a device. EPLAN accesses the [master data](Glossary_o_stammdaten.htm) stored in parts management, making it possible to select the correct data for the current device with a parts selection dialog.

Preconditions:

- You have opened a project.
- You have opened the [property dialog](Glossary_o_eigenschaftendialog.htm) for a [component](Glossary_o_schaltzeichen.htm) / function (for example via the Edit > Properties menu [items](Glossary_o_bauteile.htm)).
- The Main function check box on the <Function category> tab (or the Symbol / function data tab) is selected.

1. In the Properties <â¦> dialog, select the Parts tab.
2. Click [...] in the Part number field.
3. In the Part selection dialog select the desired parts. Multiple selection is possible.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The data are adopted in the corresponding fields of the Parts tab, whereby the Number of units / quantity field is preset to "1".
5. If necessary, edit the [properties](Glossary_o_eigenschaften.htm) of the [part](Glossary_o_artikel.htm) in the right-hand side of the dialog.
6. Click [OK].

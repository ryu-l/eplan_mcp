# Defining a User-defined Project Structure

As well as the pre-defined [identifier schemes](Glossary_o_kennzeichnungsschemata.htm) for the [project structure](Glossary_o_projektstruktur.htm), you can also [create](Glossary_o_erstellen.htm) [user-defined](Glossary_o_benutzerdefiniert.htm) [schemes](Glossary_o_schemata.htm) and use them to define your own project structures. In addition to the "[functional assignment](Glossary_o_funktionalezuordnung.htm)", "[higher-level function](Glossary_o_anlage.htm)", "[installation site](Glossary_o_aufstellungsort.htm)", "[higher-level function number](Glossary_o_anlagennummer.htm)" and "[document type](Glossary_o_dokumentenart.htm)", the [user-defined identifier structure](Glossary_o_benutzerdefiniertekennzeichnungsstruktur.htm) also encompasses a user-defined identifier block for which you can freely define the [preceding sign](Glossary_o_vorzeichen.htm).

You can subsequently change a user-defined project structure, which consists of a user-defined page structure and a user-defined device structure, through the [project properties](Glossary_o_projekteigenschaften.htm) dialog. The page structure can however only be changed later under specific [conditions](projectstructure_k_hinterg.htm#Seitenstruktur) at a project with pages. The definition of all structures follows the same procedure.

Precondition:

You have created a project and selected it in the page navigator.

1. Select the Project > Properties menu [items](Glossary_o_bauteile.htm) and bring the Structure tab to the foreground.
2. Click [...] next to the page structure field or next to one of the device fields.
3. Use the drop-down lists to assign one of the three possible [properties](Glossary_o_eigenschaften.htm) "Identifying", "Describing" or "Not available" to each identifier block in the dialog Page structure / dialog Device structure.
4. If you want to change the identification order in the page structure, mark the identifier block in the Structure column of the dialog Page structure and move it to the desired position by using the arrow buttons.
5. Click [OK].

### Define user-defined preceding signs and separators

In a user-defined project structure, you can define selectable and / or user-defined prefixes and / or separators for [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm). However, this is not possible for all identifier [blocks](Glossary_o_bloecke.htm) since some identifiers are pre-defined. The relationships are described in the following table:

| Identifier block | Preceding sign | Separator for [sub-identifiers](Glossary_o_unterkennzeichen.htm) |

![](../Pictures/Gui/ALL/note.png)Note:

Prefixes and separators for identifier blocks can only be selected or entered by the user when the respective identifier block was specified with the "Identifying" or "Describing" property when the new identifier scheme was created.

Proceed as follows:

Precondition:

You have created a new scheme for the page or device structure.

1. Click [Other] in the Structure tab of the Project properties dialog.
2. In the Extended project structures dialog, select a preceding sign for the functional assignment, higher-level function number, document type, and user-defined identifier blocks, or enter a preceding sign of your own choice where this is permitted.
3. Proceed in the same manner for the [separator](Glossary_o_trennzeichen.htm) for the sub-identifier.
4. Click [OK].

![](../Pictures/Gui/ALL/note.png)Note:

The following preceding signs and separators may not be used for identifier blocks because they are already used for other purposes:

- / Separator before page name
- \ Directory structure
- ? Placeholder for [offline numbering](Glossary_o_offlinenummerieren.htm)
- : Separator for connection point designation.

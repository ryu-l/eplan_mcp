# P003018: Shield applied too often

### Cause

You have created the shield for a [cable](Glossary_o_kabel.htm) distributed over the schematic more than once or twice with the same name.

For example, the same shield is connected to two terminals with different names.

In the [cable properties](Glossary_o_kabeleigenschaften.htm) you have also defined that [placing](Glossary_o_auflegen.htm) [shields](Glossary_o_abschirmungen.htm) on both sides is not allowed.

### Solution

Double-click the cable definition line and select the check box Allow shields connected on both sides in the Properties <...> dialog.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

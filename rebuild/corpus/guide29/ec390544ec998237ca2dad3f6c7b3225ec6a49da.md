# Showing a Graphical View of the Placed Function

You can display the position of a placed function in the graphical preview. If a device is marked in the device navigator, the graphical preview shows all the components that belong to this device. If the [functions](Glossary_o_funktionen.htm) are placed in several pages, EPLAN displays all associated pages in nested [form](Glossary_o_verlauf.htm).

Precondition:

You have placed a function in the schematic.

### Activate graphical preview

1. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Devices > Navigator
2. Select a device.
3. Select the menu item View > Graphical preview.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the Graphical preview dialog, EPLAN displays the schematic page(s) on which the associated [devices](Glossary_o_betriebsmittel.htm) are placed.

### Jump to component

In the device navigator you can jump straight to the placed function in the schematic.

1. Select a device.
2. Select the Go to (graphic) popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) EPLAN opens the schematic page in the graphical editor and positions the cursor on the [component](Glossary_o_schaltzeichen.htm).

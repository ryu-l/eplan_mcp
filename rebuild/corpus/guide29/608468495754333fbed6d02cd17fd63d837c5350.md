# Routing Connections (Topology): Procedure

Routing is the generation of [routing connections](Glossary_o_verlegeverbindungen.htm) with the "Topology" representation type. The easiest way is to [generate](Glossary_o_erzeugen.htm) the routing [connections](Glossary_o_verbindungen.htm) on the basis of the multi-line planning. But it is also possible to generate routing connections on the basis of the [topology](Glossary_o_topologie.htm) planning. In addition, you can use the topology navigator to design [routing path networks](Glossary_o_streckennetze.htm) without graphical representation.

The [route](Glossary_o_verlegen.htm) affects highlighted [objects](Glossary_o_objekte.htm) to which connections are to be connected. You can select objects in the routing path network (in the graphical editor), or in the [project data](Glossary_o_projektdaten.htm) [navigators](Glossary_o_navigatoren.htm) (topology navigator, device navigator, etc.).   
In the connections navigator, you can also select one or several connections, and route the connections. Generally, multi-line connections and /or routing connections are routed for whose sources and targets topology [functions](Glossary_o_funktionen.htm) exist.

During routing, missing function [connection points](Glossary_o_anschluesse.htm) on topology functions are generated automatically.

### Route on the basis of multi-line planning

Starting with the multi-line planning, the connections are routed in several consecutive steps:

- Defining multi-line functions, cables, and connections via the planning in the schematic. If you want to route cables, the multi-line [cable connections](Glossary_o_kabelverbindungen.htm) will have to be designated clearly.
- Definition of a routing path network on the topology page ([placing](Glossary_o_auflegen.htm) of [routing paths](Glossary_o_strecken.htm) and [routing points](Glossary_o_verlegepunkte.htm))
- Placing of multi-line functions from the device navigator as topology functions
- Routing of connections  
  During the route, routing connections are generated and routed in the routing path network. The routing track and length of the connection are determined automatically for the routing connections.

### Route on the basis of planning in topology

During the planning in the topology, the route of connections is carried out in the following steps:

- Definition of a routing path network on the topology page (placing of routing paths and routing points)
- Placing of topology functions on the topology page  
  If the topology functions do not have a multi-line equivalent, you will also have to define additionally the [connection point patterns](Glossary_o_anschlussbilder.htm) of the functions.
- Definition of cables (as topology functions in the topology navigator or as multi-line functions in the device navigator, in each case via the New device popup menu item)
- Generation of routing connections in the Interconnect devices dialog, in the process, the previously defined cables can be selected.
- Routing of connections  
  During the route, existing routing connections are routed in the routing path network. The routing track and length of the connection are determined automatically for the routing connections.

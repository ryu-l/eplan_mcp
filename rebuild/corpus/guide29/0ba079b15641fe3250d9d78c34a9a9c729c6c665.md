# Placing Items on the Mounting Rail

The elements can be placed on a mounting rail as an alternative to placement on a mounting panel. An "Auxiliary function" for performing this is available, with which you must define the position of the [items](Glossary_o_bauteile.htm): A mounting rail can currently be represented on a "Line", a "Polyline", a "Polygon", a "Rectangle" or a "Spline". Not allowed are "Circle", "Ellipse", etc.  
The insertion point of the [part](Glossary_o_artikel.htm) placement is then placed on the selected object. The clearances defined in the parts management are also accounted for here when [placing](Glossary_o_auflegen.htm).

Preconditions:

- You have opened a project.
- You have opened the 2D panel layout - <Project name> dialog.
- You are in the graphical editor on a "Panel layout" page.
- You have added a mounting panel.
- The List display type contains parts with the "Unplaced" part status (Number of units / quantity (unplaced) property).
- If you have specified the dimensions and / or [macros](Glossary_o_makros.htm) in the parts management, specify one of the options <...> from parts master data in the dialog Settings: 2D panel layout (popup menu item Settings). Otherwise select Manual input <...>.

1. Select the items in the tree tab that have not yet been placed. (Multiple selection is possible.)
2. Select Popup menu > Place on mounting rail.
3. Select the object on which the part placement is to be positioned.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The first part placement hangs on the cursor.
4. Define the dimensions of the part placement using the Extension and distance dialog.
5. Click [OK].
6. Move the cursor along the object to move the part placement.
7. Confirm the position with a mouse click.
8. Proceed in this way for all additional [part placements](Glossary_o_artikelplatzierungen.htm) selected in the tree.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The newly-placed parts are removed from the "Unplaced" hierarchy level, and moved to the hierarchy level of the populated mounting rail. If parts have already been placed on the mounting rail, new placements can only occur in the free area.

![](../Pictures/Gui/ALL/note.png)Note:

Even if you do not move the cursor during placement, the [symbols](Glossary_o_symbole.htm) will be placed from left to right. If a symbol extends over the edge of the mounting panel, an error message will inform you of this.

# Cable Assignment Diagrams

When using standardized cables, they are often drawn only in the single-line representation. In the [cable](Glossary_o_kabel.htm) assignment diagram, it is then documented how a standard cable is constructed.

- The cable assignment diagram shows the structure of a cable, including any equipment on the ends (e.g., [plugs](Glossary_o_stecker.htm)) and information on the use of the cable in the project.
- The parts of the cables can be output in the cable assignment diagram.

### Report

For the report, only those cables are considered which are assigned a [form](Glossary_o_verlauf.htm) in the Cable assignment diagram form property. All other cables are ignored.

Using a manual filter, you can set additional limitations on any number of other [report blocks](Glossary_o_auswertungsbloecke.htm). For sorting and filtering, the Cable assignment diagram form property can be additionally used. Then for each form name, a report block with x pages will be created. For the form, the form specified at the cable is used.

For the report "Cable diagram", it is possible to use a filter to output only those cables for which the Cable assignment diagram form property is blank.

Cables for which there is a cable assignment diagram can be suppressed in device tag lists, [bills of materials](Glossary_o_stuecklisten.htm), etc. using a filter, but are output by default.

![](../Pictures/Gui/ALL/note.png)Note:

When generating cable assignment diagrams, all cables for which the same cable assignment diagram form has been entered, are output together in one report block. A possible sorting is only taken into consideration within a report block.

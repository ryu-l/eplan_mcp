# Dialog Insert device

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Select the menu item Insert > Device or, from a navigator, the popup menu item Insert device. Select a suitable [part](Glossary_o_artikel.htm) from the part selection and click [OK].

In this dialog, you specify the insertion options for the device.

Overview of the main dialog elements:

Part macro:

If a macro is assigned to the part in the parts management, you can select this option to insert this macro.   
Otherwise this option is grayed out.

Individual functions:

If [function templates](Glossary_o_funktionsschablonen.htm) are assigned to the part in the parts management, you can select this option to insert it.   
Press the [N] button in order to page through the [functions](Glossary_o_funktionen.htm) and select the desired one. Or use the [Spacebar] while [placing](Glossary_o_auflegen.htm) the [auxiliary functions](Glossary_o_nebenfunktionen.htm) if you want to interrupt the placement of the auxiliary functions and want to start again with the placement of the main function.

Macro selection:

Select this option if the Select macro dialog is to be opened after the confirmation with [OK] so that a (different) macro can be selected for the device. The [macros](Glossary_o_makros.htm) and [symbols](Glossary_o_symbole.htm) stored at the part are not taken into consideration.

Symbol selection:

Select this option if the Symbol selection dialog is to be opened after the confirmation with [OK] so that a (different) symbol can be selected for the device. The symbol selection is filtered in the process with regard to the representation type and with regard to all the symbols with the "Undefined" representation type.

Representation type:

If you have selected one of the options Part macro, Individual functions or Symbol symbol selection, you can use this drop-down list to assign a (different) representation type to the device.

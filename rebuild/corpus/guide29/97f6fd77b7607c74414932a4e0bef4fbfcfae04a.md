# Dialog Connections

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Master data > Form > Open > [Open] for a [form](Glossary_o_verlauf.htm) of type "Cable assignment diagram". You have opened the Form properties - <Form name> dialog (Popup menu > Properties on the form in the Pages - <Project name> navigator dialog) and have clicked [...] in the Value field of Connections property.

In this dialog, you control the assignment of [connections](Glossary_o_verbindungen.htm) to [connection points](Glossary_o_anschluesse.htm) in [cable](Glossary_o_kabel.htm) diagram [forms](Glossary_o_formulare.htm).

Overview of the main dialog elements:

Source (designation) / Target (designation):

The [designations](Glossary_o_bezeichnungen.htm) of the connection source and target are stored in this table.

Connection (color / number):

You can store the color or number of the connection here.

The assignment of a connection to two connection points is thus shown as a "three-tuple"; multiple connection assignments are each separated by a "pipe" character.  
("Tuple" is a mathematical term representing an ordered combination of [objects](Glossary_o_objekte.htm) whose elements have a fixed sequence.)

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

For a cable, the entry 1;2:red|2;3;|;3;4;blue means:   
The red conductor of the cable type connects connection point 1 with connection point 2. The second conductor of the cable type connects connection point 2 with connection point 3, and the blue conductor of the cable type connects connection point 3 with connection point 4.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# P026091: Incomplete project properties for the air-conditioning calculation

### Cause

No value was stored for at least one of the following project listed [properties](Glossary_o_eigenschaften.htm) that are required for the air-conditioning calculation at the enclosure:

- Thermal design: Simultaneity factor
- Thermal design: Voltage
- Thermal design: Frequency.

### Solution

1. Select the menu [items](Glossary_o_bauteile.htm) Project > Properties and check in the Properties tab for which of the above listed [projects](Glossary_o_projekte.htm) the value is not entered.
2. Add the missing value(s).
3. Click [OK] to close the dialog of the [project properties](Glossary_o_projekteigenschaften.htm), and then start a new check run.

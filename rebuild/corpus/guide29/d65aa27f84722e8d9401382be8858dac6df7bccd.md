# Creating Interruption Point Cross-references

Interruption points having the same full DT [form](Glossary_o_verlauf.htm) [cross-references](Glossary_o_querverweise.htm). Two [forms](Glossary_o_formulare.htm) of cross-references are distinguished:

- Star cross-reference: With a star cross-reference, one interruption point is defined as the starting point. All other [interruption points](Glossary_o_abbruchstellen.htm) of the same name refer to this starting point. At the starting point, a formattable list of the cross-references to the other interruption points is displayed. Here you can define how many cross-references are to be displayed alongside or between each other.
- Chain cross reference: With [chain cross-references](Glossary_o_kettenquerverweise.htm), the first interruption point refers to the second, the third to the fourth etc., meaning that the references follow from page to page.

### Create star cross-references

Preconditions:

- You have opened a project.
- You have inserted several interruption points with the same displayed DT.
- You have specified the [settings](Glossary_o_einstellungen.htm) for the display of cross-references of interruption points under Options > Settings > Projects > "Project name" > Cross-references / contact image > Interruption points.

1. Double-click one of the interruption points in the schematic.
2. In the Properties <...> dialog activate the Star source check box in the Interruption point tab.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The interruption point defined as the star source now points to all other interruption points with the same DT in the project. These interruption points in turn point to the star source.

![](../Pictures/Gui/ALL/note.png)Note:

You automatically receive a chain cross reference if you deactivate the Star source check box.

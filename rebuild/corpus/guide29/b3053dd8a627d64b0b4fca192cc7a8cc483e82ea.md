# Cable lines: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_kabellinien.htm)

### Cable lines

User interface / operation

Line graphics used to display cables in connection diagrams. The lines run perpendicular to the connection lines. Several cable lines next to each other are combined into a single line if all the lines belong to the same cable and all associated cable connections originate from the same device or the same terminal strip, or lead to the same device or the same terminal strip.

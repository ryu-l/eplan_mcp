# P027019: Connections of the cable are not defined uniquely

### Cause

The [connections](Glossary_o_verbindungen.htm) of the planned [cable](Glossary_o_kabel.htm) in the multi-line representation are not defined uniquely, because the [properties](Glossary_o_eigenschaften.htm) "Color / number" and / or "Pair index" have identical values for at least two [cable connections](Glossary_o_kabelverbindungen.htm). Thus, the cable could not be routed in the [topology](Glossary_o_topologie.htm).

### Solution

1. Locate the multi-line cable in the project using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Call up the Properties <..> dialog for all connections of the cable, and compare the values in the fields Color / number and / or Pair index.
3. If two or more connections have identical values with respect to the above properties, modify them. Make sure to assign to each connection a unique value for the respective property.
4. Re-[route](Glossary_o_verlegen.htm) the cable through the routing path network, and start a check run.

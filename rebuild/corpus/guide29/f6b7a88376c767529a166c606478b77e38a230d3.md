# Exporting Wire Fabrication

Representative for all [wire fabrication](Glossary_o_drahtkonfektionierung.htm) interfaces, here the export for the "General [wires](Glossary_o_draehte.htm) parts list" format is described. The export of the other interfaces is done in the same manner, but differs in terms of the values to be entered in the export dialog and the file [formats](Glossary_o_formate.htm) generated.

Preconditions:

- You have opened a project.
- A machine of the required type is defined in the company [settings](Glossary_o_einstellungen.htm).
- The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open.
- The [connections](Glossary_o_verbindungen.htm) navigator is open.
- You have created [routing connections](Glossary_o_verlegeverbindungen.htm).
- You have highlighted connections in the connections navigator, or you have selected the area to be exported in the layout space or layout space navigator.

1. Select the menu [items](Glossary_o_bauteile.htm) Utilities > Manufacturing data > Wire fabrication > General wires parts list.
2. In the dialog Wire fabrication: General wires parts list, select the scheme of the required machine, the language and the output directory, or import the default settings.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the set output directory, the wires parts list file is generated with the pre-selected name. In the export of machine-specific interfaces, depending on the manufacturer, several files are generated with set file names and file name extensions. This data is transferred to the software of the wire fabrication machine.

![](../Pictures/Gui/ALL/note.png)Note:

Please note that sorting of the wires parts list is carried out text-oriented by the [bundle](Glossary_o_buendel.htm) number, so that the output is "1, 10, 2, ...". To avoid this use leading zeros.

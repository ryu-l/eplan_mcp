# Dialog Edit legend item

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Project data > Parts / Devices > 2D panel layout navigator. In the tree view you have selected the mounting panel whose enclosure legend is to be updated. Popup menu > Edit legend item.
- You are in the graphical editor on a "Panel layout" page and have selected the mounting panel whose enclosure legend is to be updated. Project data > Parts / Devices > 2D Panel layout > Edit legend item.
- The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open. In the layout space navigator, select a layout space with legend [items](Glossary_o_bauteile.htm) to be edited. Select the Edit legend item popup menu item.

In this dialog you edit the positions of the [enclosure legends](Glossary_o_schaltschranklegenden.htm).

Overview of the main dialog elements:

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Table:

Depending on the selected columns in the Configure representation dialog, different information relating to the individual legend items is displayed. The Legend item column itself can't be masked out; it is the only column in this dialog that can be edited.

[Number]:

Click this button to open the Number dialog where you define the numbering [settings](Glossary_o_einstellungen.htm) for the legend items.

# Export wire harness data

Preconditions:

- You have opened a project.
- You have opened the wire harness navigator.

1. Select one or more wire harness definitions in the graphical editor or in the wire harness navigator.
2. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Connections > Export > Wire harness data  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Export wire harness data dialog is opened. The selected [wire harnesses](Glossary_o_kabelbaeume.htm) are displayed in the Source field.
3. Enter a name under which the export file is stored or select it interactively via [...] in the File name field.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A query is displayed when you export into an existing file. There decide whether you want to supplement or overwrite the file.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The file with the wire harness data (\*.hpdex) is generated.

![](../Pictures/Gui/ALL/note.png)Note:

If you activate the Apply to entire project check box when exporting wire harness data, not only all the predefined wire harnesses and their associated components are exported, but rather the entire project with all the [project data](Glossary_o_projektdaten.htm). In such a case the wire harness names of the entire project are not listed in the Source field. Instead the field remains empty.

# P026055: Connection point '<x>' exists more than once

### Cause

Several [part placements](Glossary_o_artikelplatzierungen.htm) have the same DT and an identical connection point designation <x> exists in the [connection point patterns](Glossary_o_anschlussbilder.htm) that are assigned to the parts. As a result the system does not know where it should [route](Glossary_o_verlegen.htm) the connection.

### Solution

1. Check the connection point patterns of the parts and ensure that there are no identical [connection point designations](Glossary_o_anschlussbezeichnungen.htm) in the connection point patterns.
2. Then start a new check run.

![](../Pictures/Gui/ALL/note.png) Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

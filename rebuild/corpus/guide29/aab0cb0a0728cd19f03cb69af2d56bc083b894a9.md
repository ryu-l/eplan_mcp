# Importing Parts Texts into the Dictionary

It is possible to import parts texts from parts management into the dictionary. All texts that can be translated and that exist in the selected language in parts management will be transferred as [keywords](Glossary_o_stichworte.htm) into the dictionary.

Precondition:

- You have selected a parts database via Options > Settings > User > Management > Parts management.
- Parts management contains parts texts in one or more languages.

1. Utilities > Translation > Edit dictionary
2. Select the Management tab.
3. Next to the Dictionary field click [...]; in the dialog that appears select the EPLAN dictionary into which you want to import, and click [Open].
4. Click [Close].
5. Select the menu [items](Glossary_o_bauteile.htm) Utilities > Parts > Management.
6. Select [Extras] > Translation > Settings.
7. In the Translate field next to the Languages field click ![](../Pictures/Gui/ALL/all_new_as.png) (New), select each of the [translation languages](Glossary_o_uebersetzungssprachen.htm) whose parts texts you wish to import into the dictionary and click [OK].
8. Select [Extras] > Translation > Import part text.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the Select languages dialog you will see all of the selected translation languages.
9. Select the languages you wish to import.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the selected languages are not selected as [dictionary languages](Glossary_o_woerterbuchsprachen.htm), the "Language not available" message will appear. Click [Yes].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts texts will be imported into the dictionary.
10. In the Parts management dialog, click [Close].
11. To check the import, select the menu items Utilities > Translation > Edit dictionary.
12. In the Source language field in the Edit words tab select one of the languages you imported.  
      
    ![](../Pictures/Gui/ALL/arrow.png) In the Find field you will see all of the imported parts texts of the selected language.

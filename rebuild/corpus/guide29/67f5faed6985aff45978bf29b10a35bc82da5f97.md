# The Help System

The EPLAN help system contains conceptual information, usage instructions, and dialog descriptions of most of the program [functions](Glossary_o_funktionen.htm). The help is opened online via an Internet connection. The help system is displayed in the Internet browser that is set as the default on your computer. The help system can be used context-sensitive via [F1] or context-independent.

Most chapters are split into the following subchapters:

![](../Pictures/Gui/ALL/helpsystem_info_as.png) Basics

![](../Pictures/Gui/ALL/helpsystem_action_as.png) Proceed as Follows

![](../Pictures/Gui/ALL/helpsystem_reference_as.png) Reference

In addition to the EPLAN Help, the help system also contains the ![](../Pictures/Gui/ALL/helpsystem_overview_as.png) "EPLAN Overviews". You can find further information on special topics (e.g. EPLAN [properties](Glossary_o_eigenschaften.htm) and placeholder elements) here. The ![](../Pictures/Gui/ALL/helpsystem_message_as.png) icon is used for help pages describing [check run messages](Glossary_o_prueflaufmeldungen.htm).

# Generating Pages with Views Automatically

It is possible to automatically [generate](Glossary_o_erzeugen.htm) pages with [model views](Glossary_o_modell_ansichten.htm), 2D [drilling views](Glossary_o_bohransichten.htm) and copper unfolds in [projects](Glossary_o_projekte.htm) with mechanical components in layout spaces.

Precondition:

You have opened a project. You have opened a project page in the graphical editor.

1. Create a model view, 2D drilling view or copper [unfold](Glossary_o_abwicklung.htm).
2. Save the view as a macro by using the menu [items](Glossary_o_bauteile.htm) Page > Page macro > Create.
3. Select the menu item Utilities > Reports > Model views.
4. In the Templates tab, click the button ![](../Pictures/Gui/ALL/all_new_as.png) (New) to [create](Glossary_o_erstellen.htm) a new template.
5. Enter suitable values in the [properties](Glossary_o_eigenschaften.htm) of the template as described under [Tab Templates (Dialog Model views, Copper unfolds, Drilling views)](gededit3dgui_r_vorlagen.htm#Eigenschaft).
6. Use the filter [settings](Glossary_o_einstellungen.htm) to specify the basic settings of which views are to be created and which hierarchically subordinate items are displayed in the view.
7. Enter the view saved as a macro in the Macro property.
8. Click the button ![](../Pictures/Gui/ALL/all_generate_as.png) (Generate report) or select the Generate report popup menu item in order to generate the automatic [reports](Glossary_o_auswertungen.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The pages with the reports are created on the basis of the settings in the template and with the selected macro.

![](../Pictures/Gui/ALL/note.png)Note:

When [Reporting projects](formgeneratorgui_h_projektauswerten.htm) by means of the menu items Utilities > Reports > Generate project reports, model views, 2D drilling views and copper unfolds are also automatically generated, if the appropriate templates are available in the dialogs for the views. If these views already exist in the project, they are updated.

# Highlighting Routing Path Networks

Routing path networks can be temporarily highlighted in color to verify if an unbroken routing path network is available for the laying of [connections](Glossary_o_verbindungen.htm) in the [layout space](Glossary_o_bauraum.htm).

Precondition:

You have opened a project. A layout space is open. The layout space contains one or more [routing path networks](Glossary_o_streckennetze.htm).

1. Select the following menu [items](Glossary_o_bauteile.htm): View > Connections > Routing path network tracking.
2. Click the object (wire duct, routing path, curve) with a partial routing path of the routing path network.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All paths of the routing path network that are connected with the routing path of the clicked object are highlighted in color.
3. Click another routing path.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The highlighting of the first routing path network is terminated and the routing path network belonging to this routing path is colored.

![](../Pictures/Gui/ALL/note.png)Note:

Connection [filters](Glossary_o_filter.htm) that were specified for [routing paths](Glossary_o_strecken.htm), [wire ducts](Glossary_o_verdrahtungskanaele.htm), etc. are taken into consideration when the routing path network is tracked.

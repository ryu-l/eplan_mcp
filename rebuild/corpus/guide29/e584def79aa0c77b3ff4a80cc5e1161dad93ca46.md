# Notes for the Reader

Important information:

- Before installing the version, please note the information on the software approvals in the EPLAN Information Portal:   
  <https://www.eplan.help/en-US/Infoportal/Content/htm/portal_software_approvals.htm>
- If you want to use old projects that were created with previous EPLAN versions in EPLAN Version 2.9, these [projects](Glossary_o_projekte.htm) have to be updated. For further information read the section ["Updating the Project Databases"](news_p_projekte_datenbankaktualisieren_256275.htm).
- If you want to use an "older" parts database, you will first have to update such a parts database. For further information read the section ["Updating the Parts Database"](news_p_artikelverwaltung_datenbankaktualisieren_2_9.htm).
- We used "EPLAN Electric P8" when creating the images for the news. If you use a different program of the EPLAN Platform, a different program icon will be displayed in the dialog of your program.

Before you begin reading, please note the following [symbols](Glossary_o_symbole.htm) and styles used in the news:

![](../Pictures/Gui/ALL/warning.png)Warning:

Text preceded by this symbol contains a warning; you should be absolutely sure to read this warning before proceeding!

![](../Pictures/Gui/ALL/note.png)Note:

Text preceded by this image contains extra notes.

![](../Pictures/Gui/ALL/info.png)Tip:

Useful tips to facilitate your interaction with the program are presented after this image.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Examples are highlighted by this symbol.

- User interface elements are marked in bold (and blue) so they can immediately be located in the text.
- bold text provides particularly important information that you should definitely pay attention to.
- Code examples, directory names, and direct input (among others) are displayed in a non-proportional font.
- Function keys, keyboard keys, and buttons within the program are shown in square brackets (e.g., [F1] for the "F1" function key).

- To improve the flow of the text, we often use "menu paths" in the news (for example, Help > Contents). In order to find a particular program function, the menus and options shown in a menu path must be selected in the sequence shown. For example, the menu path mentioned above calls up the EPLAN help system.
- In combination with [settings](Glossary_o_einstellungen.htm) or fields (e.g., check boxes) which can only be switched on or off, we often use the term "activate" (after which the setting is active ![](../Pictures/Gui/ALL/all_checkon_as.png)) and "deactivate" (after which the setting is inactive ![](../Pictures/Gui/ALL/all_checkoff_as.png)). in the news.

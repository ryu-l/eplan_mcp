# Dialog Settings: Parts pre-filtering

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > User > Management > Parts pre-filtering.

In this dialog you can pre-filter the parts management, the [part](Glossary_o_artikel.htm) [master data](Glossary_o_stammdaten.htm) navigator, the part selection and the device selection on the basis of specific [properties](Glossary_o_eigenschaften.htm).

Overview of the main dialog elements:

Filter:

This drop-down list contains all the filter [schemes](Glossary_o_schemata.htm) already defined. Through [...] you branch into the dialog [Filter](modaldialogsdb_d_filternnach.htm) in which you can for example [create](Glossary_o_erstellen.htm) a new scheme and assign filter criteria. To this purpose the dialog Criteria selection provides parts properties such as Discontinued part, ERP number etc.

![](../Pictures/Gui/ALL/note.png)Note:

If such a filter is active, a percentage sign "%" is displayed in the title bar of the dialogs listed above in front of the name of the parts database.

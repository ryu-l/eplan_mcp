# P005013: Targets have differing connection point types

### Cause

Targets of a connection have different connection types for their function [connections](Glossary_o_verbindungen.htm). For example, one target has the connection type "Conductor / wire", while another has the connection type "Optical fiber".

### Solution

Enter the same connection type for all function connections that are targets of the connection.

Refresh the connections and then start a new check run.

![](../Pictures/Gui/ALL/note.png) Note:

The connection type "undefined" can be used for all connections

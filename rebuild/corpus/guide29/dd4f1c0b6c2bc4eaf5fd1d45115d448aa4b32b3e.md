### terminal : Type (default)

| Internal value | Display value |
| --- | --- |
| 0 | Undefined |
| 1 | Cut |
| 2 | Strip |
| 3 | Crimp |
| 4 | Other |

Other values can be freely specified in the "tblLookup" table under the "TerminalType" key ("keyName" field).  
The internal value has to be set in the "nr" field and the display value in the "name" field.  
The display value is a multilingual text. Example:

| Key ("keyName" field) | Internal value ("nr" field) | Display value ("name" field) |
| --- | --- | --- |
| TerminalType | 5 | en\_US@Dualsleeve; |
| TerminalType | 6 | en\_US@Flcn. narrow; |
| TerminalType | 7 | en\_US@Flcn. wide; |
| TerminalType | 8 | en\_US@Cbllug M4:8; |
| TerminalType | 9 | en\_US@Cbllug M4:9; |
| TerminalType | 10 | en\_US@Cbllug M4:10; |
| TerminalType | 11 | en\_US@Cbllug M4:11; |

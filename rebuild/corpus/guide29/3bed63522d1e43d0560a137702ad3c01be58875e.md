# Dialog Graphical macro selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have activated the Use graphical macro selection check box in the user [settings](Glossary_o_einstellungen.htm) (Options > Settings > User > Graphical editing > Macros).

- Insert > Window macro / symbol macro
- Page > Page macro > Insert.

This dialog displays for a specific directory all subdirectories and, depending on the selection, the [macros](Glossary_o_makros.htm) contained in a specific subdirectory, together with information on the files as well as a graphical preview.

Overview of the main dialog elements:

File path:

This field displays the current file path for macros. By default, this is the path generated at the time of the installation: <Drive>:\<Program directory>\Macros\<Customer code>. Here, you can enter another directory manually, or select it by clicking the respective directory image.

Using the ![](../Pictures/Gui/ALL/all_nexthigherlevel_as.png) button (One level up), or via the corresponding image in the Directory area, you can move up by one directory level in the directory structure.

![](../Pictures/Gui/ALL/info.png)Tip:

In this input box, enter for the directory path behind the directory name a backward slash (\), followed by a letter (or number), and the first macro file with this letter (or number) in a directory of macros will be selected in the File selection area.

Directory:

In this area, all existing subdirectories are displayed as images for a selected directory. By default, an EPLAN logo is used, and the respective name of the subdirectory is displayed as text.

If you select on a specific directory entry the Set image popup menu item, a selection dialog opens in the set default directory for images that allows you to select another image file (\*.jpg, \*.png, etc.) for the directory.

If you select on a specific directory entry the Edit text popup menu item, the Input dialog opens. You can enter a multi-lingual text here for the directory selected.

The settings made here for a directory are stored in the company-specific settings, and can be modified at any time using the popup menu of the graphical macro selection or using the settings dialog (Options > Settings > Company > Display > Graphical macro selection).

File selection:

Here, the macros found in the selected directory are listed by name, type, date, and size in a table format. The preview is integrated in this area.

To find out about the representation type of the macro, and whether there are possibly several [variants](Glossary_o_varianten.htm), click the plus sign in front of a macro name, and in the hierarchy [levels](Glossary_o_etagen.htm) below, the existing [representation types](Glossary_o_darstellungsarten.htm) ("Multi-line", "Single-line", etc.).

To select a macro, click the required variant, followed by [OK]. By double-clicking a macro name, the first available macro variant is selected for insertion, and the selection dialog is closed.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Images | Allows for directory images to be displayed in the image sizes "Small", "Medium" or "Large". |
| Filter: <Macro file type> | Filters the display of the file selection according to the file type selected (\*.ema, \*.ems or \*emp, or \*.fc2). |
| Go to default | Restores the selected directory automatically to the default macro directory. |

![](../Pictures/Gui/ALL/info.png)Tip:

Besides the known macro file types, you can also filter the display of the file selection according to [outlines](Glossary_o_konturen.htm) of the "Outline extrusion" type (\*.fc2). This is relevant to the Technical data tab in parts management. There, you can also assign to a [part](Glossary_o_artikel.htm) an outline drawing via the Macro field. With the selection of such outline drawing, it is also possible to use the graphical macro selection as well.

When calling up the graphical macro selection again, the dialog with the macro most recently selected and the most recent settings is opened again.

![](../Pictures/Gui/ALL/note.png)Note:

In contrast to the usual macro selection, you cannot execute any [functions](Glossary_o_funktionen.htm) in the Graphical macro selection dialog that affect the directories or files. For example, you cannot [create](Glossary_o_erstellen.htm), rename or delete any directories or files in this dialog.

# 2D Drilling View: Principle

2D [drilling views](Glossary_o_bohransichten.htm) show the NC and drill hole-relevant data, [drilling patterns](Glossary_o_bohrbilder.htm), as well as [outlines](Glossary_o_konturen.htm) of basic [items](Glossary_o_bauteile.htm) and parts in a model view. 2D drilling views are project-internal documents which are permanently available during project processing in EPLAN. You can use the drilling views to synchronize the output manufacturing data (e.g., generated with the menu items Utilities > Manufacturing data > Machining > NC DXF / Drilling template) prior to the production start with the current editing status in the EPLAN project.

The items and [drill holes](Glossary_o_bohrungen.htm) can be assigned dimensioning in drilling views.

If the [part placements](Glossary_o_artikelplatzierungen.htm) in the project were changed, the 2D drilling views can be updated at any time with the menu items Utilities > Reports > Update.

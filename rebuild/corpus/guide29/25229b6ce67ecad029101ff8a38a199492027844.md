# Verifying Projects

In the project verification you compare the [settings](Glossary_o_einstellungen.htm) and [properties](Glossary_o_eigenschaften.htm) of the comparison and incoming [projects](Glossary_o_projekte.htm). Likewise, targeted [check runs](Glossary_o_prueflaeufe.htm) are carried out on the incoming project.

Preconditions:

- [Select a project management database](prjmanagementgui_h_projekteverwalten.htm)
- [Load directories and projects](prjmanagementgui_h_verzeichniseinlesen.htm).
- The loaded directory contains the returned incoming project.
- You have access to the original project that you wish to use as the comparison project.

1. Project > Management
2. In project management, select the project with the advanced project status.
3. Select [Extras] > Verify project.
4. Next to the Select comparison project field click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
5. In the dialog that appears, select the original project, which is the comparison project, and click [Open].
6. In order to compare project-related settings during the project verification, select the Compare settings check box and then select an existing comparison scheme from the Scheme drop-down list below it.  
      
    ![](../Pictures/Gui/ALL/arrow.png) Go to [...] in order to [create a new settings comparison scheme](processreceiptcontrol_h_vergleichsschema.htm).
7. In order to compare properties during the project verification, select the Compare properties check box and then select an existing comparison scheme from the Scheme drop-down list below it.  
      
    ![](../Pictures/Gui/ALL/arrow.png) Go to [...] in order to [create a new properties comparison scheme](processreceiptcontrol_h_eigenschaftenvergleich.htm).
8. In order to run checks during the project verification, select the Perform project checks check box and then select an existing check run scheme from the Scheme drop-down list below it.  
      
    ![](../Pictures/Gui/ALL/arrow.png) Go to [...] in order to [create a new check run scheme for the project verification](processreceiptcontrol_h_pruefschema.htm).
9. To compare the project structures of the two projects, select the Compare project structures check box.
10. To stop the comparison upon discovery of the first difference, select the Stop comparison when first difference is found check box.
11. Click [OK].  
       
     ![](../Pictures/Gui/ALL/arrow.png) The projects will be compared and the specified check runs will be carried out.  
       
     ![](../Pictures/Gui/ALL/arrow.png) In the Project verification: Results dialog EPLAN automatically shows you the overall results of the project verification.  
       
     ![](../Pictures/Gui/ALL/arrow.png) Under Project data > Messages > Management you will see a detailed list of results.

# P012004: The dimensions of the part placement do not correspond to the dimensions of the part

### Cause

The x- / y span of a placed [part](Glossary_o_artikel.htm) was changed and now differs from the property Width / Height of the part being used.

If the part property Width / Height of the part have been changed in the parts management and the x / y extension of the corresponding part placement is the same, this message also appears.

### Solution

Check the x and the y extension of the part placement. Also check the dimensions of the part under Width and Height in the parts management. The x extension and width as well as the y extension and height must match up! If the values do not match, adjust them.

Then start a new check run.

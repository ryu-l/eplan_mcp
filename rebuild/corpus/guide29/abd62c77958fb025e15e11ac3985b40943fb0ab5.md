# P026078: Bundle diameter too small; connections cannot be bundled with the selected part

### Cause

The total diameter of all [routing connections](Glossary_o_verlegeverbindungen.htm) that are to be bundled using the placed [cable / tubing protection](Glossary_o_kabel_schlauchschutz.htm) or [cable](Glossary_o_kabel.htm) / tubing tie is smaller than the minimum [bundle](Glossary_o_buendel.htm) diameter of the cable / tubing protection or cable / tubing tie used.

### Solution

1. Locate the cable / tubing protection or cable / tubing tie in the [layout space](Glossary_o_bauraum.htm) using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Call the [property dialog](Glossary_o_eigenschaftendialog.htm) of the cable / tubing protection or cable / tubing tie, and bring to front the Part tab.
3. Via the parts used, navigate to the [part](Glossary_o_artikel.htm) selection, and bring to front the Routing [accessories](Glossary_o_zubehoer.htm) data tab.
4. Check at the part used the value set in the Minimum bundle diameter field.
5. Select a cable / tubing protection or cable / tubing tie whose minimum bundle diameter is smaller than the total diameter of all routing [connections](Glossary_o_verbindungen.htm) in the bundle.
6. Close the part selection and property dialog by clicking [OK], and then start a new check run.

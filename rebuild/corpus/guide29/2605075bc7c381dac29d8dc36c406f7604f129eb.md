# Layer Management

In EPLAN, elements in the schematic are assigned to particular [layers](Glossary_o_ebenen.htm). Using layer management, the following is possible:

- Layers influence visibility when printing and in the graphical editor, as well as the [properties](Glossary_o_eigenschaften.htm) for representing the elements assigned to them, such as line thickness, line type, color, font size, etc.
- Certain information can be shown or hidden as needed for printing or for display on the screen.
- You can use layers to enter information into the schematic (e.g. [comments](Glossary_o_kommentare.htm) on the state of the system), that should not be displayed or printed.
- You can display and hide particular elements in the schematic, e.g. [cable definition lines](Glossary_o_kabeldefinitionslinien.htm), terminal strip text, auxiliary [lines](Glossary_o_leitungen.htm) for mechanical construction, etc. The layer management allows this hidden information to be made easily visible and edited.

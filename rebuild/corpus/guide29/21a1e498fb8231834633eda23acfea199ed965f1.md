# The EPLAN Message Management

While editing a project, there can be (intentional or unintentional) inconsistencies, electrical or logical errors. This sort of project error can result in incorrect or incomplete [reports](Glossary_o_auswertungen.htm). EPLAN offers you the option of performing logic checks on the schematic pages, which support you when creating electrical drawings. The problems discovered in the checks are displayed in message management. The checks help you work with the program quickly, surely, and effectively in all areas of schematic creation.

In addition, EPLAN allows you to check the quality of your [master data](Glossary_o_stammdaten.htm) that are stored in the parts database rapidly and without great effort.

Message management offers you the following options:

- All messages generated during [check runs](Glossary_o_prueflaeufe.htm) are displayed in an easily understood [form](Glossary_o_verlauf.htm) in the Message management - <Project name> dialog.
- You can determine which criteria should be selected and how the corresponding messages are categorized.
- You can allow every project step to be automatically checked (Online checking). Or you define a Check run according to particular criteria and start it at any desired time (Offline check run).
- Check runs can be carried out at an online check for the entire project, for any components of the [project structure](Glossary_o_projektstruktur.htm) or for any pages.
- In the case of the [part](Glossary_o_artikel.htm) master data check runs can be carried out for specific parts marked in the part master data navigator.
- Project data that were generated or modified by [actions](Glossary_o_aktionen.htm) of specific [modules](Glossary_o_module.htm), for example during the automatic [cable](Glossary_o_kabel.htm) selection, are also checked. These are so-called module-specific checks.
- You can specify for EPLAN that certain checks are not to be carried out by selecting the type of check "No".
- An intelligent jump function makes it possible to navigate to the "location" in the project or in the parts management where the message was generated.
- Extensive descriptions and correction suggestions are available in the help system for all [check run messages](Glossary_o_prueflaufmeldungen.htm).

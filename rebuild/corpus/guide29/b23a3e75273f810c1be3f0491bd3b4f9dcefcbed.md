# P026026: A measuring point is not in the same model view / unfold

### Cause

When dimensioning an item, one or more measuring points on the measuring line are not within the same model view / [unfold](Glossary_o_abwicklung.htm). For example, a measuring end point is set outside the model view / unfold and is found on the page on which the model view / unfold is inserted.

### Solution

1. Undo the incorrect dimensioning and measure the item again. Ensure that all of the measuring points are within the same model view / unfold.
2. Then start a new check run.

# Dialog Copy hyperlink

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a page in the graphical editor.Insert > Graphic > Hyperlink. In the Properties dialog, select the document to be linked on the Hyperlink tab and click [OK].

In this dialog, you can specify whether the document is to be copied into the project directory or referenced from the source directory.

Overview of the main dialog elements:

Keep source directory:

A reference to the document is inserted in the project and the document from the original directory is displayed. If the document is changed, it is automatically updated as soon as you open the page. During the data backup the documents that are stored in external directories and that are referenced are not considered.

Copy:

The document is copied to the project directory (this means into the external document directory of the project) and the copied document from the project directory is displayed. All files in the project subdirectories are also included in backups.

Overwrite with prompt:

Select this check box to have a confirmation displayed for the Copy option if the document is already present in the project directory. You can then decide whether it should be overwritten or not.

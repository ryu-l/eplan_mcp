# Filters and Parts Preselection

In order to use [filters](Glossary_o_filter.htm) properly, you must first have prepared the data in parts management properly. The filters only work on data entered in the fields in parts management, not the data from the function definition.

In [part](Glossary_o_artikel.htm) selection, you can provide different filters, which can be combined with one another:

- Field-based filter: The field-based filter performs the search only on particular record fields (e.g. for the field Type number). In this filter, the entire field contents are checked to ensure that they match the search text.
- Full-text filter: This filter allows the entry of an arbitrary search text that will be searched for in all of the fields of parts management.  
  Please note that the full-text filter in tree view also evaluates the main nodes "Accessory list", "Accessory placement", "Drilling pattern", and "Connection point pattern". In the List and Combination tabs, however, only parts data is considered.
- Automatic filter: Certain [properties](Glossary_o_eigenschaften.htm) of the marked device will be used as filter criteria.

Filter [settings](Glossary_o_einstellungen.htm) are stored for each user.

### Parts preselection

As well as the filters you can [create](Glossary_o_erstellen.htm) and use a parts selection, meaning a list of parts. Then, during item selection, only parts from this list will be offered. Different lists can be created and stored under a name, so you can use them again and again.

Parts preselection-lists are saved specifically for a project. However, export and import [functions](Glossary_o_funktionen.htm) allow them to be used in other [projects](Glossary_o_projekte.htm).

#### Cable selection

In [cable](Glossary_o_kabel.htm) selection, there is another filter for the conductor properties of the cable. You can also define a special preselection list for cable parts.

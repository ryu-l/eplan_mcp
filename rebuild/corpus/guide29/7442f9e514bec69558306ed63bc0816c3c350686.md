# P014004: No macro name defined

### Cause

At least one macro name has to be specified at the macro box for the automatic generation of [macros](Glossary_o_makros.htm) from a macro project. This has to be defined as a property both in the Macro box tab and in the Macro definition tab. In this case the entry is missing in both tabs.

### Solution

1. Locate the macro box in the macro project using the Go to (graphic) functionality from the popup menu in the Message management dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The macro box is marked in the project page.
2. Use the popup menu to open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the macro box.
3. Bring the Macro definition tab to the front.
4. Enter the desired macro name in the first line of the table in the Macro: Name column or select it interactively by using [...]. (Use the further [lines](Glossary_o_leitungen.htm) of the table to define further macro names.)
5. If required, store a description of the macro in the Macro: Description column.
6. Close the [properties](Glossary_o_eigenschaften.htm) dialog with [OK].
7. Then start a new check run.

![](../Pictures/Gui/ALL/note.png) Note:

If you have entered a macro name in the first line of the Macro definition tab, this is entered automatically in the Name field of the Macro box tab. Similarly a macro name defined in the Name field in the Macro box tab is entered automatically into the first line of the Macro definition tab and there displayed in the Macro: Name column.

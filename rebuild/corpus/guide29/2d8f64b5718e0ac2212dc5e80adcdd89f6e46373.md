# Synchronizing a Selection

If you have several [navigators](Glossary_o_navigatoren.htm) open, you can use the Synchronize selection command in these dialogs to display the same object. If an object is selected in a navigator or in the graphical editor, it will also be selected in the other navigators. This makes it easier to find [project data](Glossary_o_projektdaten.htm).

Precondition:

You have opened a project and have several navigators open.

1. Select an object in a navigator or in the graphical editor.
2. Select the menu [items](Glossary_o_bauteile.htm) Find > Synchronize selection.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The selected object will also be selected in all of the other open navigators that contain this object.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You have opened the graphical editor, the device navigator and the terminal strip navigator. Now, in the graphical editor, select a terminal, and then select the menu items Find > Synchronize selection. In the device navigator, and the terminal strip navigator, the selected terminal will also be marked. The tree can also be opened at the appropriate location.

# P007003: It was not possible to assign all parts. The maximum number of parts was reached

### Cause

While adding up [cable](Glossary_o_kabel.htm) lengths, the maximum permissible number of the project parts of "1000" was reached.

### Solution

Reduce the number of project parts. Delete, for example, superfluous project parts.

![](../Pictures/Gui/ALL/note.png)Note:

This module-specific message is generated by the automatic cable length summation. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

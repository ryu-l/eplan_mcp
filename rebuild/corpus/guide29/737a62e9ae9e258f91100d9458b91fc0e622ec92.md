# Importing Your Own Sets of Identifiers, Connection Point Designations, and Connection Point Descriptions

You can import sets of identifiers, [connection point designations](Glossary_o_anschlussbezeichnungen.htm), and [connection point descriptions](Glossary_o_anschlussbeschreibungen.htm) from an XML file and then use them for project planning in EPLAN.

### Import identifier sets

1. Utilities > Master data > Identifier
2. Select the Import popup menu item.
3. In the Import dialog, switch to the desired directory and enter a file name.
4. Click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The identifier sets are transferred from the XML file into the dialog.

### Import connection point designations and descriptions

1. Utilities > Master data > Connection point designation / description
2. Select the Import popup menu item.
3. In the Import dialog, switch to the desired directory and enter a file name.
4. Click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) All sets of connection point [designations](Glossary_o_bezeichnungen.htm) and descriptions are transferred [form](Glossary_o_verlauf.htm) the XML file into the dialog.

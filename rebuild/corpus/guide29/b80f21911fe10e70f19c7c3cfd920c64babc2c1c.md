# Dialog Property - <Property type>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Manufacturing data > Export / labeling. Click [...] next to the Settings field in the dialog Export manufacturing data / output labeling. In the dialog Settings: Manufacturing data export / labeling select one of the Header, Footer or Label tabs, select a format element for a property or for [project data](Glossary_o_projektdaten.htm) and click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).

In this dialog you can select a property for the manufacturing data export / labeling text and specify how the text is to be formatted.

Overview of the main dialog elements:

Category:

In this field, you select a category to limit the number of [properties](Glossary_o_eigenschaften.htm) displayed in the field below.

Filter:

Into this field enter the text for which the properties are to be filtered.

If you want to [return](Glossary_o_zurueckbuchen.htm) to the original view of the properties, remove the search term from the entry field. Click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) to do so.

Property / Assignment:

If you have highlighted a property under Category, you can edit its display properties in the table in the right-hand section of the dialog. To this purpose the hierarchy [levels](Glossary_o_etagen.htm) Format and Value / unit are available. These can be opened by clicking the ![](../Pictures/Gui/ALL/all_plussign_as.png) sign.

---

The following [settings](Glossary_o_einstellungen.htm) are available under the Format hierarchy level:

Length:

This drop-down list is used to specify the length of the respective property text:

- Infinitely variable: If this option is selected, the length of the text is unlimited.
- Limited variable: If this option is selected, the length of the text is limited. If the text of the selected property does not fit in the field, it is truncated to the length specified in the Number of characters field.
- Fixed: If this option is selected, the length of the field is fixed. This length is entered in the field Number of characters.

Number of characters:

This field is available if you have selected the Fixed or Limited variable options. The number in this field specifies the length of the text.

Output right-aligned:

This field is available if the option Fixed is selected. If this check box is selected, the text of the marked property is output right-aligned.

Apply line breaks:

Property texts may contain paragraph marks as placeholders for line breaks. If this check box is activated, a line break is inserted in the export / labeling file for each line break placeholder in the property text of the selected property.

Separator for index 0:

This functionality applies to [format elements](Glossary_o_formatelemente.htm) that are superior placeholder elements. The superior placeholder element is designated as index 0, e.g. "Terminal parts". It contains inferior placeholder elements from index [1] to index [10], e.g. "Terminal parts [1]" to "Terminal parts [10]". The superior placeholder element "Terminal parts" outputs the terminal parts of the entire terminal strip. This field shows the [separator](Glossary_o_trennzeichen.htm) that you defined via [...] in the dialog Format: Separator. This separator is inserted between the project data values.

Summation in one line:

This check box is only available for summarized parts list!  
Activate this check box so that the sum of the individual values of the respective property is output. Through this setting it is thus possible to output both the total amount (number of units) of individual parts and the total length, for example, of a [cable part](Glossary_o_kabelartikel.htm).

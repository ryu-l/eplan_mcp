# Dialog Extension and distance

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Project data > Parts / Devices > 2D panel layout navigator. In the 2D panel layout - <Project name> dialog, you used Popup menu > Settings to select one of the Manual input <...> options from the Apply group box. You are in the graphical editor on a "Panel layout" page. Select the Popup menu > Place on mounting panel on an unplaced [part](Glossary_o_artikel.htm).

This dialog allows you to manually define the dimensions of non-placed parts when [placing](Glossary_o_auflegen.htm) them on the mounting panel.

The following dialog elements are available:

Extension:

In this group box, enter the Width and Height values of the part to be inserted.

Spacing:

In this group box, enter the values for the horizontal and vertical clearance of the part to be inserted to any neighboring part.

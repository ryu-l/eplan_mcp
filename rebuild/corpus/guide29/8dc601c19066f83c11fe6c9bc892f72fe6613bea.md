# Dialog Change routing direction

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open. The layout space contains 3D [part placements](Glossary_o_artikelplatzierungen.htm) with defined [connection points](Glossary_o_anschluesse.htm). Select the menu [items](Glossary_o_bauteile.htm) Project data > Device > Change routing direction.

Use this dialog to change the routing direction for one or several highlighted [devices](Glossary_o_betriebsmittel.htm) in a layout space. This way, you specify a direction for the connection point in which the routing connection connected to it is to search for the entry into the routing path network if the connection point direction specified in the connection point pattern deviates from it.

The following dialog elements are available:

Routing direction:

This drop-down list contains the same direction [designations](Glossary_o_bezeichnungen.htm) that are also available for the creation of a connection point pattern:

- Automatic
- Left
- Move up
- Right
- Down.

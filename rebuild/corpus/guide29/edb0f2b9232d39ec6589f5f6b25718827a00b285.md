# Exporting Manufacturing Data for Automatic Equipment Systems

Another export format from EPLAN Pro Panel is the output of manufacturing data for automatic equipment systems. The Rittal - Athex interface is available to this purpose. This machine automatically equips [mounting rails](Glossary_o_tragschienen.htm) with terminal strips and alignable terminal [accessories](Glossary_o_zubehoer.htm) in accordance with the planning in the EPLAN project.

The exported files contain the [part](Glossary_o_artikel.htm) numbers, DTs, and lengths of the mounting rails to be equipped and the positioning data of the terminals to be placed there.

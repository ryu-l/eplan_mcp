### Form types

User interface / operation

Defines the form type, i.e., whether it is a form for a device tag list, terminal diagram, etc. Each form type is assigned a particular ID. This ID is used internally to generate the list of properties available (placeholder texts) that can be used during the editing of the form. Thus, each form has a specific list of available placeholder texts (see [Placeholder texts](Glossary_o_platzhaltertexte.htm)).

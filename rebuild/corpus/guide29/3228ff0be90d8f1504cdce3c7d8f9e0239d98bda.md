### Symbol macros

User interface / operation

Symbol macros are intended as an enhancement to the symbol libraries. This allows you to (e.g.) combine several single symbols or objects representing a single logical unit into a single object. Symbol macros are created in a similar manner to window macros (see [Window macros](Glossary_o_fenstermakros.htm)), but are stored in the same directory with a different file suffix.

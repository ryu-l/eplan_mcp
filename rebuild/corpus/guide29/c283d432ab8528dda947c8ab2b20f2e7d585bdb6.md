# P501007: The height, width and / or depth is not specified at the part: Height = <x>, Width = <y>, Depth = <z>

### Cause

In the parts database to be checked a [part](Glossary_o_artikel.htm) was found where the mounting information about the Height, Width and / or the Depth is missing.

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective part is already marked in it.
2. Bring the Mounting data tab to the front.
3. Insert the missing values in the Width, Height and / or Depth fields.
4. Close the parts management, save the modified data, and carry out a parts synchronization.
5. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

- So that the message is not output anymore at least two of the mounting data listed above need to have values at the part. The exception are parts at which a 3D macro is stored. In this case the values of all these mounting data have to be available.

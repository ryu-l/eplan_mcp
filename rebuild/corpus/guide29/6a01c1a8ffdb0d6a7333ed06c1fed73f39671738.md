# P501033: The identifying connection point information of the function templates does not match the connection point data at the connection point pattern

### Cause

In the parts database to be checked a [part](Glossary_o_artikel.htm) was determined at which the identifying connection point information of the [function templates](Glossary_o_funktionsschablonen.htm) do not match the connection point data at the connection point pattern.

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective part is already marked in it.
2. Bring the Function templates tab to the front.
3. Remember the values entered in the Connection point [designations](Glossary_o_bezeichnungen.htm) column.
4. Bring the Technical data tab to the front.
5. In the Connection point pattern group box, click [...] next to the Name field.
6. Change to the Connection points tab and compare the stored [connection point designations](Glossary_o_anschlussbezeichnungen.htm) with the connection point designations at the function templates of the part.
7. Correct the connection point designations in the connection point pattern. In the process ensure that - in contrast to the function templates - every single connection value has to be located in a separate row in the connection point pattern.
8. Save the modified data, and carry out a parts synchronization.
9. Then start a new check run.

# P024006: Media code does not suit the trade

### Cause

The media code used in the device tag of the fluid device does not suit the selected trade and thus does not conform to the current version of the standard DIN ISO 1219-2. For example, a control valve in a pneumatic circuit is designated with the media code "H" for "Hydraulics", but not with the correct media code "P" for "Pneumatics".

### Solution

1. Locate the fluid device in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Adapt the media code in the device tag of the fluid device standard-compliant to the trade by using the correct character.  
     
   The standard requires the following media code for the various [trades](Glossary_o_gewerke.htm):  
     
   - H for Hydraulics  
   - P for Pneumatics  
   - C for Cooling  
   - K for Cooling lubricant  
   - L for Lubrication  
   - G for Gas engineering.
3. Then start a new check run.

# P026024: The layout space name '<x>' exists more than once

### Cause

When you use data interfaces, several layout spaces with the same [layout space](Glossary_o_bauraum.htm) name can occur in the project.

The placeholder <x> in the message indicates the layout space name that is repeated.

### Solution

1. Rename the layout spaces in the layout space navigator.
2. Then start a new check run.

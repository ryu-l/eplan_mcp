# Dialog Field assignment / Protect fields (parts management)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call Field assignment dialog:](javascript:void(0);)

Utilities > Parts > Management. You have opened a parts database using [Extras] > Settings. [Extras] > Import. In the Import records dialog, click [...] in the Field assignment field.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call Protect fields dialog:](javascript:void(0);)

You have opened the EPLAN Data Portal and import a [part](Glossary_o_artikel.htm). Click [...] in the Protect fields field in the Import of parts dialog.

In this dialog you [create](Glossary_o_erstellen.htm) and edit the scheme that defines the fields in the database to which the exported data is to be written to, for the structure and the free [properties](Glossary_o_eigenschaften.htm). This simplifies the [data exchange](Glossary_o_datenaustausch.htm) between customers who use different structures. In addition you specify the fields or [user-defined](Glossary_o_benutzerdefiniert.htm) properties that are to be considered "protected".

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

---

Free properties / Attributes tabs:

![](../Pictures/Gui/ALL/note.png)Note:

When importing from the EPLAN Data Portal these two tabs are only available if the current scheme contains assignments for free properties / attributes.

Both of these tabs have an identical structure and contain the following dialog elements:

Table:

- Number - source: Enter the number of the appropriate field in the source database here.
- Number - target: Enter the number of the field into which the import is to occur here.

---

Protect fields tabs / Protect user-defined properties:

Use these tabs to define the fields and / or user-defined properties that should not be updated when the parts data is imported. To do so, click ![](../Pictures/Gui/ALL/all_new_as.png) (New), and select the property to be ignored when importing in the Criteria selection / Select property dialog.

Protect function templates:

This setting is only available to you in the Protect fields tab. Activate this check box, if the [function templates](Glossary_o_funktionsschablonen.htm) of the parts are to be protected against changes during the importing of parts data. This means that function templates are generally not imported.

---

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

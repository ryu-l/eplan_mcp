# Forms for Cable Assignment Diagrams

The [form](Glossary_o_verlauf.htm) for [cable](Glossary_o_kabel.htm) assignment diagrams contains a table with cable data. Within a form, it is possible to draw a detailed representation of a standard cable used, including the endpoint [connections](Glossary_o_verbindungen.htm) and [shields](Glossary_o_abschirmungen.htm). In addition, it is possible - via the insertion point of next form - to insert a summarized parts list; this list can be located either on the same page or on a subsequent page. A new form must be created and managed for every standard cable.

A cable assignment diagram can also be created with a dynamic form. A separate report is also created for each cable type.

![](../Pictures/Gui/ALL/note.png)Note:

When generating cable assignment diagrams, all cables for which the same cable assignment diagram form has been entered, are output together in one report block. A possible sorting is only taken into consideration within a report block.

### Data for the cable assignment form

The [properties](Glossary_o_eigenschaften.htm) of the graphically first cable are output as header data on the cable assignment page. The cables are sorted according to their sequence in the schematic. Non-placed cables are sorted according to DT and attached at the back. The following cable data of the individual cables can be output in table format:

- All data that is also output in a cable overview (e.g. cable DT, source, target, number of connections, etc.)
- Cable parts (product subgroup "Parts source")
- Cable parts (product subgroup "Parts target")
- Cable parts (all other product subgroups)

### Data for the summarized parts list

The summarized parts list is output as the next form. Here parts from all cables to be output to the cable assignment diagram are output with the corresponding total quantities. To do this, all placeholders from the "normal" summarized parts list are available.

In addition, there is another placeholder, the Total cable length. For one [cable part](Glossary_o_kabelartikel.htm), this adds up all lengths of the cables taken into consideration in the report block and for which this cable [part](Glossary_o_artikel.htm) is entered. Every cable is considered only once here.

The length is output in the default unit for cable lengths.

The system recognizes a cable part by the fact that the product group "Cables" and the product subgroup "Undefined" are specified on the part.

# P001037: Main terminals existing several times

### Cause

You use one and the same main terminal several times in different [representation types](Glossary_o_darstellungsarten.htm) of your schematic. For example the main terminal in the schematic exists in the representation type "Multi-line" and in the representation type "Overview".

### Solution

1. Locate the relevant main terminal in the schematic using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Launch the [property dialog](Glossary_o_eigenschaftendialog.htm) of the main terminal.
3. Change the main terminal into an auxiliary terminal by deactivating the Main terminal check box on the first tab or rename the main terminal.
4. Click [OK].
5. Then start a new check run.

# P015001: The report type of the report '<x>' on Page '<y>' is unknown. The report is not updated

### Cause

EPLAN has found a new report type in the project, which was created with a new version of EPLAN. The EPLAN version you are currently using cannot update this report type.

### Solution

This report can only be updated if you first update your software. Please save the data in your project first, and then install the latest EPLAN version.

![](../Pictures/Gui/ALL/note.png) Note:

If you want to remove the non-updatable report from the project, then select it in the page navigation and select Popup menu > Delete.

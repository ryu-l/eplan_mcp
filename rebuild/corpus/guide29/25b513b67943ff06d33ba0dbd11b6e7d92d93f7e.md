# P501006: The elements of the macro <x> (<y> / <z>) are not grouped

![](../Pictures/Gui/ALL/note.png)Notes:

- The check run does not consider 3D [macros](Glossary_o_makros.htm).
- This message is not output if [unplaced functions](Glossary_o_nicht_platziertefunktionen.htm) are located in the macro.

### Cause

In the parts database to be checked a [part](Glossary_o_artikel.htm) was found where a macro whose elements are not grouped is entered.

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective part is already marked in it.
2. Bring the Technical data tab to the front.
3. Click [...] next to the Macro field and in the dialog then opened select a macro file that contains a macro with grouped elements.  
     
   Or alternatively delete the entry in the Macro field.  
     
   Or [create](Glossary_o_erstellen.htm) a new macro with grouped elements, store it in the desired macro directory and select it in the Macro field.
4. Close the parts management, save the modified data, and carry out a parts synchronization.
5. Then start a new check run.

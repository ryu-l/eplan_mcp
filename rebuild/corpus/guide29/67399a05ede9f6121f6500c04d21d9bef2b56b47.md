# Dialog Connections - <Project name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Project data > Connections > Navigator.

In this dialog, all [connections](Glossary_o_verbindungen.htm) of the project are displayed in the tree or list view, as desired.

You can connect placed or [unplaced functions](Glossary_o_nicht_platziertefunktionen.htm) or [connection points](Glossary_o_anschluesse.htm). To do this, [generate](Glossary_o_erzeugen.htm) a new (unplaced) connection and specify the connection source and target in the connection [properties](Glossary_o_eigenschaften.htm). The source and target have to be existing [functions](Glossary_o_funktionen.htm) (placed or unplaced) in the project.

In addition, you can delete unplaced connections or repair incomplete connections. These connections can be identified by the blank "Source" and / or "Target" columns. Specify a source and target in the connection properties to link the connections.

Overview of the main dialog elements:

The tree view is used to sort the connections on the basis of the [structure identifiers](Glossary_o_strukturkennzeichen.htm) of the device structure. The connections are listed twice, once below the source DT, and a second time below the target DT.

In the List view function definition, source and target, connection color / number, connection cross-section / diameter, name of potential as well as the first [part](Glossary_o_artikel.htm) number of the connection are displayed.

![](../Pictures/Gui/ALL/note.png)Note:

If a multi-level terminal exists only as a 3D part placement (without a multi-line equivalent), the terminal designation cannot be determined. Instead, the level is displayed in square brackets in addition to the DT. In [reports](Glossary_o_auswertungen.htm), too, the DT is output together with the level.

Filter:

This drop-down list displays all the available [filters](Glossary_o_filter.htm). A selected filter is automatically activated and is applied to both the tree and the list view. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the [Filter](modaldialogsdb_d_filternnach.htm) dialog. Here you can [create](Glossary_o_erstellen.htm), edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

- Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
- Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

Value: <Property>:

Use this field, via [Quick input](modaldialogsdb_k_filter.htm#I_Schnelleingabe), to adjust quickly the value of a filter criterion for a defined and activated filter.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| New | Opens the Function definitions dialog and allows a new, unplaced connection to be created with pre-defined properties. A tree view for selecting a connection definition for the highlighted connection opens at the right place in the Function definitions dialog. |
| Delete | Deletes the selected unplaced connections. Placed connections can't be deleted. |
| Place | Places the selected function in the schematic. Before the actual [placing](Glossary_o_auflegen.htm) press [Shift] in order to start the placement action in the mode "Individual functions". Press [Backspace] to open the dialog Place device and, if required, for example open the macro selection or change the representation type. |
| Assign | This menu item is available if a project page is open and a DT / function / function template is selected in the navigator. It hangs the function description of the (first highlighted) function on the cursor and allows for this function to be moved to a [component](Glossary_o_schaltzeichen.htm) and to assign it with a single click. You can, for instance, assign an unplaced function to a component, or transfer the data of an already placed function to another component. An assigned function must have as many or more connection points than the component. If several functions or the DT have been selected, all selected functions can be assigned consecutively. This can be done either individually by mouse-click or blockwise by opening a frame around the required components. |
| Route ([topology](Glossary_o_topologie.htm)) | Allows for the selected connections to be routed in the routing path network. |
| Route ([layout space](Glossary_o_bauraum.htm)) | Allows for the highlighted connections to be routed manually in the layout space. |
| Free routing (layout space) | Offers the option to [route](Glossary_o_verlegen.htm) the marked connections in the layout space freely, i.e. to have a curve for the [form](Glossary_o_verlauf.htm) of the routing connection calculated. |
| Bundle | Opens the Bundle connections automatically dialog and thus allows for the connections to be bundled automatically according to specific criteria. |
| Show [routing connections](Glossary_o_verlegeverbindungen.htm) | Displays the selected routing connections or all existing routing connections in the layout space or in the topology. |
| Hide routing connections | Hides all routing connections displayed in the layout space or topology. |
| Edit revision marker | This menu item allows you to edit the [revision marker texts](Glossary_o_revisionsmarkierungstexte.htm) and their format. This menu item is only available when a changed object in a revision is selected. |
| Delete revision marker | This menu item allows you to delete the revision marker texts. This menu item is only available when a changed object in a revision is selected. |
| Edit display [settings](Glossary_o_einstellungen.htm) | This menu item is available if the highlighted connection runs via a connection definition point. Opens the [property dialog](Glossary_o_eigenschaftendialog.htm) with the Display tab and provides the option of changing the display settings for the properties in the connection definition point. |
| Go to (graphic) | Shows the selected object in the graphical editor. |
| Go to (graphic source) | This menu option is available when you have defined a starting point / source for the highlighted connection. It shows the starting point / source of the selected connection in the graphical editor. |
| Go to (graphic target) | This menu option is available when you have defined an end point / target for the highlighted connection. It shows the end point / target of the selected connection in the graphical editor. |
| List with preselection (tree only) | Reduces the number of elements displayed in order to allow for a faster orientation in the list view. If this option is activated, the list view is called up with an automatic filter (preselection) containing the elements that are currently selected. |
| Select in tree (list only) | Displays the marked object in the Tree tab. |
| Edit in table | Opens tabular editing, with the possibility of editing the properties of the connections. |
| Properties | Opens the Properties (components): <...> dialog. Allows the editing of the function properties. |
| Properties (global) | Opens the Properties (global): <...> dialog. Allows the editing of the device properties. |

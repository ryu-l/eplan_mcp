# Dialog Mounting point / Dialog Mounting line

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The project contains at least one [layout space](Glossary_o_bauraum.htm). The layout space contains 3D [objects](Glossary_o_objekte.htm). A mounting point or a mounting line has been defined at a 3D object. Select the mounting point or mounting line and then select the menu [items](Glossary_o_bauteile.htm) Popup menu > Properties. Or double-click the mounting point or the mounting line.

In this dialog you set the [properties](Glossary_o_eigenschaften.htm) of a mounting point / mounting line.

Overview of the main dialog elements:

Name:

Enter the name of the mounting point / mounting line here.

Description:

Enter a description text for the mounting point / mounting line here.

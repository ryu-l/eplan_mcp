# Changing the Page Description During the Copying of Pages

If you copy pages in a project or insert [page macros](Glossary_o_seitenmakros.htm) in a project, you can use the familiar dialog Adapt structure to modify the [structure identifiers](Glossary_o_strukturkennzeichen.htm) and page numbers before inserting the pages. Now you can also change the page description for these [actions](Glossary_o_aktionen.htm).

![](../Pictures/Gui/ALL/benefit.png)Benefit:

When inserting copied pages you can now directly adapt the page descriptions. Subsequent processing of the pages is not required anymore.

[![](../Pictures/Gui/Lang/pagebrowsergui_adjustingstructure_ls_thumb_0_60.png)](../Pictures/Gui/Lang/pagebrowsergui_adjustingstructure_ls.png)

To this purpose the Adapt structure dialog in the Pages tab was expanded by two columns Page description. In the Target table you can change the multilingual page descriptions of the inserted pages.

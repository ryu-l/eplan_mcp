# P020044: Image  <x> (x Pos <y> : y Pos <z>) : <u>

### Description

You have run a project comparison, checking the Properties of the test project (input project) against those of the comparison project and differences were found.

This message occurs when a difference concerning an inserted image file was found with the project comparison. <x> designates the name of the image file concerned, <y> the X position and <z> the Y position of the image in the schematic. <u> [reports](Glossary_o_auswertungen.htm) if the image file has been removed, added, or if one if its [properties](Glossary_o_eigenschaften.htm) has been changed.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

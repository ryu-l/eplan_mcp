# Inserting Fixed Graphics into Connection Diagrams

There are [connection diagrams](Glossary_o_anschlussplaene.htm) in which, for example, a fixed "screw graphic" is to be shown for each terminal (terminal connection diagram). Or, in the case of [cable](Glossary_o_kabel.htm) connection diagrams, a fixed graphic should be displayed for the [cable connections](Glossary_o_kabelverbindungen.htm) of a cable. In such cases, the terminal / cable connection / ...placeholder text "Assignment: Index to graphic" option is available. The index here is the index of the placeholder in graphic 1 to 100. In the [form](Glossary_o_verlauf.htm) [properties](Glossary_o_eigenschaften.htm), you can assign a symbol to every index. If you then place the "Assignment: Index to graphic [n]" property in a form, then the symbol assigned to index n is always placed.

Preconditions:

- You have opened a project.
- You have opened the form whose properties you would like to edit in the form editor (Utilities > Master data > Form > Open).
- You have inserted the "Assignment: Index to graphic" placeholder text for respective element (terminal, cable connection, ...).

1. Select the form in the page navigator.
2. Select the Properties popup menu item.
3. If the "Assignment: Index to graphic" property in the form has not yet been defined, in the Form properties dialog click ![](../Pictures/Gui/ALL/all_new_as.png) (New) on the toolbar above the property list, select the property from the Property selection dialog and click [OK].
4. In the Form properties dialog, click [...] in the Value column of the "Assignment: Index to graphic" property.
5. In the Assignment: Index to graphic dialog, click ![](../Pictures/Gui/ALL/all_new_as.png) (New), to [create](Glossary_o_erstellen.htm) a new line in the assignment table.
6. In the Symbol name field, click [...].
7. In the Symbol selection dialog, select the symbol to whose graphic you wish to assign an index and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The associated data is adopted in the Symbol library and Description fields.
8. In the Symbol variant field, select the desired symbol from the drop-down list of all the existing [variants](Glossary_o_varianten.htm) of the current symbol.
9. Perform all further assignments in a similar manner.
10. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The assignments are saved.

In the Form properties dialog, the assignments are displayed as follows in the Value column:

<Index number>;<Symbol library>;<Symbol number>;<Variant>|<Index number>;<Symbol library>;<Symbol number>;<Variant>|...

1;SPECIAL;321;0|2;IEC\_EPLAN\_D;176;1

![](../Pictures/Gui/ALL/note.png)Note:

Take care that only the [symbols](Glossary_o_symbole.htm) of the stored [symbol libraries](Glossary_o_symbolbibliotheken.htm) are displayed.

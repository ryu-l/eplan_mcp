# P005078: Connection with specification of substance without piping definition

### Cause

A substance was defined at a connection in the [P&I diagram](Glossary_o_ri_fliessbild.htm). However, there no piping definition (piping connection point or piping definition point) at the connection.

### Solution

1. Locate the connection in the P&I diagram using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the connection definition point.
3. Copy the value entered in the [properties](Glossary_o_eigenschaften.htm) table for the Substance property into the Clipboard and then delete the value.
4. Place a piping connection point or a piping definition point on the connection.
5. Paste the copied value in the Clipboard into the Substance field in the property dialog of the piping definition.
6. Specify the piping name and define its state.
7. Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

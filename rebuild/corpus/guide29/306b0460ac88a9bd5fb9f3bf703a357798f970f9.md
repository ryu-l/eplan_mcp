# P008001: The text '<x>' cannot be translated into the <y> language

### Cause

The necessary entries ([keywords](Glossary_o_stichworte.htm)) are missing in the dictionary language in question.

### Solution

Select the menu [items](Glossary_o_bauteile.htm) Utilities > Translation > Edit dictionary. In the Dictionary dialog check the [dictionary languages](Glossary_o_woerterbuchsprachen.htm) used. If the dictionary language you want is missing from the list in the Management tab, you can install it by using ![](../Pictures/Gui/ALL/all_new_as.png) (New). Then select the Edit words tab and select the desired language from the Source language drop-down list. In the Find field, enter the relevant keywords and check whether the right translated texts appear in the dictionary language you want. If not, [create](Glossary_o_erstellen.htm) or add the missing keywords in the source language and the corresponding translation texts in the dictionary language you want by using ![](../Pictures/Gui/ALL/all_new_as.png) (New). Close the Dictionary dialog and translate the texts.

Then start a new check run.

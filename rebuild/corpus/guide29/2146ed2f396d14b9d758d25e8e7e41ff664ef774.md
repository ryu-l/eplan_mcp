# P026018: The dimensions of the part placement do not correspond to the dimensions of the part

### Cause

#### Possibility 1

A new [part](Glossary_o_artikel.htm) has been selected for the part placement in the [layout space](Glossary_o_bauraum.htm) but the original part dimensions were retained.

#### Possibility 2

The part [properties](Glossary_o_eigenschaften.htm) Graphical macro, Texture and / or Width / Height / Depth of the part were changed retrospectively in parts management. However, the part placement used was not changed in line with these properties.

### Solution

1. Select the Update part placement menu item from the popup menu for the layout space navigator.
2. In parts management, check the entries in the Graphical macro and Texture fields and / or the dimensions in the Width, Height and / or Depth  fields for the part selected. The properties of the part in the parts management and the properties of the part placement in the layout space must match!
3. If the values do not match, adjust them.
4. Then start a new check run.

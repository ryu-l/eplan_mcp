# Dialog Design space export

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Layout space > Design space > Export

In this dialog you carry out the export of design spaces processed in EPLAN Pro Panel to external CAD programs.

Overview of the main dialog elements:

Source:

This field displays the source of the data export. In the case of a complete project this is the project name, in the case of individual layout spaces the complete [layout space](Glossary_o_bauraum.htm) names are displayed. The entries in this field cannot be modified.

Scheme:

Selection of a scheme or the possibility to edit or [create](Glossary_o_erstellen.htm) a scheme. The [...] button opens the [settings](Glossary_o_einstellungen.htm) dialog for the STEP export.

Output directory:

This field displays the storage location. The directory is pre-selected that is defined for the data export in the user settings.

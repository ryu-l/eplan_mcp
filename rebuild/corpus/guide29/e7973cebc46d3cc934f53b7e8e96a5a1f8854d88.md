# Dialog Settings: Representation in macro projects

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.Options > Settings > Projects > "Project name" > Graphical editing > Representation in macro projects.

In this dialog you specify the [settings](Glossary_o_einstellungen.htm) for the display of [block properties](Glossary_o_blockeigenschaften.htm) and [cross-references](Glossary_o_querverweise.htm) in macro projects.

In schematic projects you can not carry out settings in this dialog. The property values for block [properties](Glossary_o_eigenschaften.htm) and cross-references are always shown during graphical editing.

Overview of the main dialog elements:

Display mode for properties:

The table contains the following columns:

- Row: Contains a consecutive row number.
- Name: Shows the group of properties for which the respective display mode applies.
- Display mode: Select here whether the properties in the respective macro project are hidden or whether the name or value of the properties.

For the block properties the "Show property names" option corresponds to the behavior in previous EPLAN versions (before Version 2.8). For cross-references the "Hide property" option corresponds to the behavior in previous EPLAN versions (before Version 2.8).

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# Inserting and Editing Placeholder Texts

Placeholder texts are used in [forms](Glossary_o_formulare.htm) to define the position for the placement of fields in a record. During the evaluation of the [form](Glossary_o_verlauf.htm), EPLAN automatically replaces these placeholders with the corresponding values of project [objects](Glossary_o_objekte.htm) on which the report is being run, such as components, pages, [symbols](Glossary_o_symbole.htm), etc.

Preconditions:

- You have opened a project.
- You have opened the form in which you want to define [placeholder texts](Glossary_o_platzhaltertexte.htm) in the form editor (Utilities > Master data > Form > Open > [Open]).

1. Insert > Placeholder text
2. In the Properties (placeholder text) dialog, select the Property option of the Placement tab and click [...].
3. In the Placeholder texts - <Form type> dialog, select the element for which you want to define a placeholder text.
4. Select the property and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected property is adopted in the Property field.
5. Change to the Format tab and specify the formatting [settings](Glossary_o_einstellungen.htm) of the placeholder text.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The element hangs on the cursor.
7. Position the placeholder text on the form page.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The element hangs on the cursor.
8. Position the placeholder text a second, third ... time.
9. Select the Cancel action popup menu item to exit the action.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The placeholder text is inserted on the form page and can be revised by double-clicking it.

![](../Pictures/Gui/ALL/note.png)Note:

If the placeholder does not have an alignment box, or it has an alignment box and the Remove breaks check box is also selected (under the Border) property, line breaks are filtered out in the [reports](Glossary_o_auswertungen.htm).

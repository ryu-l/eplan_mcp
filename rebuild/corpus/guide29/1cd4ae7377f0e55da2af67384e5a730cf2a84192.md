# Synchronization of Project Data

Not only the project pages and [master data](Glossary_o_stammdaten.htm) belong to a project but also project [settings](Glossary_o_einstellungen.htm), report templates and other data such as [layers](Glossary_o_ebenen.htm), [user-defined](Glossary_o_benutzerdefiniert.htm) [properties](Glossary_o_eigenschaften.htm), property arrangements, etc. By means of a new synchronization dialog you can now specifically transfer the project settings and [project data](Glossary_o_projektdaten.htm) from a source project to another project. In the process these data are copied into the target project.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

By means of the new synchronization dialog you can rapidly and easily transfer the project settings and project data from another project (for example a basic project). The manual modification of [projects](Glossary_o_projekte.htm) as well as the exchange of project data via different exports and imports of XML files is obsolete.

To open the new dialog Synchronize project data select the menu path Project > Organize > Synchronize. The project data of the target project is displayed in the left-hand area of the dialog that is designed like the existing dialog for the master data synchronization.

You can select the source project whose data is displayed in the right-hand window section by using the [...] button next to the Source project field. The source project last selected is pre-selected when the synchronization dialog is opened the next time.

Please observe the following special aspects:

- You can use the drop-down list Type to set the dialog for synchronizing the project data so that only the data of a specific type is displayed.
- Not only project settings belong to the "Setting" data type, but also the associated [schemes](Glossary_o_schemata.htm) (for example check run schemes) and report templates.
- In contrast to the synchronization of master data, the data of some data types do not have a modification date. This applies for the data of the type "Layer", "Property arrangement", "Setting" and "Structure identifier". The associated data elements have states such as "Identical", "Differing" and "Only in project".
- To transfer individual project data into the target project, select these in the Source project list and click ![](../Pictures/Gui/ALL/all_arrowleft_as.png) (copy to the left).
- To update and complete the total project data of the target project, use the two menu [items](Glossary_o_bauteile.htm) below the button [Update].

![](../Pictures/Gui/ALL/note.png)Note:

If you select data of the "Setting" type during the synchronization and transfer them to the target project, the Undo action is not available subsequently. During the selection of other data types, however, an undoing of the synchronization is possible.

# P003027: Cable: 'Function text (automatic)' different (in language '<x>')

### Cause

For a [cable](Glossary_o_kabel.htm) placed in a distributed manner in the schematic, the Function text (automatic) property is different in the selected display language at one or several placements of the cable.

### Solution

1. Standardize the Function text (automatic) property in the selected display language for all placements of the cable.
2. Then start a new check run.

# Popup Menu in Tables Extended with Multilingual Input

To access the Multilingual input popup menu item in the property tables of the property dialogs for a value, you previously had to click into the respective table cell to edit. Now this popup menu item is also available for selected cells in the Value column. The popup menu item is also active and selectable if it is a non-editable property.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

Tanks to the extension of the popup menu you can now also view the translation texts in the Multilingual input dialog existing for non-edited [properties](Glossary_o_eigenschaften.htm).

For the tables of the new list views in the [navigators](Glossary_o_navigatoren.htm), the popup menu has not only been extended with the Multilingual input menu item but also with the following two popup menu [items](Glossary_o_bauteile.htm):

- Translating
- Remove translations

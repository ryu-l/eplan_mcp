# Inserting Drilling Pattern Frames

A [DXF](Glossary_o_dxf.htm) / [DWG](Glossary_o_dwg.htm) drawing can contain several [drilling patterns](Glossary_o_bohrbilder.htm). The graphical elements of a drawing that are to belong to a drilling pattern can be defined by the user by using [drilling pattern frames](Glossary_o_bohrbildkaesten.htm). A drilling pattern frame is analogous to a macro box. Prerequisite for the generation of drilling patterns is the assignment of the [objects](Glossary_o_objekte.htm) to specific EPLAN [layers](Glossary_o_ebenen.htm).

Drilling pattern frames can only be inserted in a macro project.

Preconditions:

- You have opened a macro project.
- You have imported DXF / DWG files as pages that were generated from NC data using an external machine software (for example Steinhauer eCAB).
- Any [blocks](Glossary_o_bloecke.htm) contained in the imported DXF / DWG files have been broken down using the menu [items](Glossary_o_bauteile.htm) Edit > Other > Break up block.

1. Select Insert > Box / connection point / mounting panel > Drilling pattern frame.
2. Encompass the selection area containing the [drill holes](Glossary_o_bohrungen.htm) specified for the drilling pattern with a rectangle or a polyline.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All the objects whose surrounding rectangle are located within the rectangular drilling pattern frame belong to the drilling pattern frame.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The point of origin of the drilling pattern to be generated lies at the bottom left.

![](../Pictures/Gui/ALL/info.png)Tip

During the generation of the drilling pattern all the calculations of positions and distances of the objects involved reference the point of origin of the drilling pattern frame. The position of the point of origin in the drilling pattern frame determines the position of the point of origin in the drilling pattern to be generated. Use the Move point of origin popup menu item to change the position f he point of origin and thus to set the desired spacing between the first and all following drill holes in the drilling pattern.

1. Enter the name of the drilling pattern to be generated and a description in the Drilling pattern frame tab.
2. Click [...] in the Subdirectory for outline (NC data) fields in which the \*.fc1 files automatically generated when generating the drilling pattern are to be stored.
3. Click [OK].
4. If applicable, change the position of the point of origin by using the Move point of origin popup menu item.
5. Assign further drill holes to the drilling pattern frame by using the Assign objects to the drilling pattern frame popup menu item.

![](../Pictures/Gui/ALL/info.png)Tip:

Drilling pattern frames can also be drawn as [polylines](Glossary_o_polylinien.htm) by using the BB2 symbol. To do so, select the symbol in the Symbol selection dialog and specify the starting point of the box by clicking the left mouse button inside the schematic. After you have specified all of the other points, complete the task via the Complete polyline popup menu item.

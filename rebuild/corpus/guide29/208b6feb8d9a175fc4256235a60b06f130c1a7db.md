# Generating Cables Automatically

When automatically generating cables, free [cable connections](Glossary_o_kabelverbindungen.htm) are assigned to a suitable existing [cable](Glossary_o_kabel.htm). If no suitable cable is found, EPLAN generates a new cable DT. A connection definition point is automatically set on the connection in question and the DT for the cable is entered there.

After generating the cable, they are automatically numbered and a cable selection is made. Whether or not the selection is made for newly generated cables or for all cables depends on the [settings](Glossary_o_einstellungen.htm). This results in completely designated cables with parts.

Preconditions:

- You have selected [connections](Glossary_o_verbindungen.htm), or [objects](Glossary_o_objekte.htm) that contain connections, in the graphical editor or in the navigator.
- The "Cable" value has been assigned to the connections for the Connection: Association property . (This can be set either in the [properties](Glossary_o_eigenschaften.htm) dialog for the connection or through a connection definition point.) Or at least the source connection point of the connected function has the Cable connection point property (can be specified in the connection point logic).
- The connections have been generated and are up-to-date (Project data > Connections > Update). Then update the view via View > Redraw.

1. Select the Project data > Cables > Generate cables automatically menu [items](Glossary_o_bauteile.htm).
2. In the [Generate cables automatically](cablegui_d_kabelerzeugen.htm) dialog, determine the settings according to which the cables are to be generated. In the Cable generation, Cable numbering, and Automatic cable selection group boxes, select the required [schemes](Glossary_o_schemata.htm).
3. Select the Only automatically generated cables check box in order to carry out the cable selection only for automatically generated cables. Otherwise manually generated cables will also be included.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Cable definition [lines](Glossary_o_leitungen.htm) and [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) are generated in the schematic. Only one cable definition line and one connection definition point will be placed on the first graphical connection of a cable. Connection definition points with the same DT will be placed on all other connections.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If an unnamed cable definition line receives a name in the course of the automatic run, it will be identified as "automatically set" (Name automatically assigned property). Automatically assigned names are deleted and newly assigned in the next automatic run and manually assigned names are retained.

![](../Pictures/Gui/ALL/note.png) Notes:

- When automatically generating cables, only connections are taken into consideration at which the "Cable" value is set for the Connection: Association property and that do not have a Full DT. This can also be cable connections that belong to an existing cable. In this case, connection definition points will be set that immediately have the right DT.
- Shields are not automatically generated.
- No cable is generated for connections with at least one target that is a graphical or external function.
- Cable definition lines are placed on a separate layer but not connection definition points.

### Change automatically generated cables into manually generated cables

The Automatically generated property is set for automatically identified [cable definition lines](Glossary_o_kabeldefinitionslinien.htm) and connection definition points. Objects identified in this way are first deleted each time the cable is newly generated. After that the connections in question are newly generated and new cable definition lines and connection definition points are drawn.

Automatically generated cables and connection definition points can be converted to manually generated ones.

1. Select cables in the graphical editor or select pages or a project in the page navigator.
2. Select the Project data > Cables > Automatic -> manual menu items.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Automatically generated property is reset for the selected cables. The cables are then treated as manually generated cables and remain unchanged in subsequent automatic processes.

![](../Pictures/Gui/ALL/info.png)Tip:

To change single cables into manually generated ones, open the Properites <...> dialog (e.g. by double-clicking the cable). Deselect the Automatically generated check box in the Cables tab.

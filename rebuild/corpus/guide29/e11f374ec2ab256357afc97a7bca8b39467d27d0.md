# Tab Data (outline definition point)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened an outline of the "outline extrusion" type.

- You have selected an outline definition point in the graphical editor. Edit > Properties. In the Outline definition point: <...> dialog, select the Data tab.
- Insert > Logic > Guide rail / Guide rail with alignment / Mounting surface / Mounting surface NC / Field size. Place the outline definition point and then double-click it. In the Outline definition point: <...> dialog, select the Data tab.

You define the [properties](Glossary_o_eigenschaften.htm) of an outline definition point in this tab.

Overview of the main dialog elements:

Counter:

The counter of the current logic element is shown here. The first counter is set to "1" by default, but you can change it to anything you want.

Subcounter:

The subcounter of the current logic element is shown here. If only one element of the selected type (guide rail, mounting surface, etc.,) is available, the field is grayed out and cannot be edited. If there are several elements of the same type on a page, the subcounter is incremented, starting with "1".

# P005018: Conflict between several connection definition points on a connection

### Cause

The connection [properties](Glossary_o_eigenschaften.htm) of several [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) on one connection have different properties. For example, they have contradictory colors or cross-sections for the same connection.

### Solution

Give the connection definition points the same properties.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

# Tab Wire termination processing

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Options > Settings > Projects > "Project name" > Routing connections > General. Select the Wire termination processing tab.

In this tab, you adjust [project-wide settings](Glossary_o_projektweiteeinstellungen.htm) for processing wire terminations of [routing connections](Glossary_o_verlegeverbindungen.htm) that are taken into account for the export of [connections](Glossary_o_verbindungen.htm).

Overview of the main dialog elements:

Table Connection category - Wire termination processing:

In parts management, the Connection category property is defined at the individual [connection points](Glossary_o_anschluesse.htm). In the transmission to the manufacturing machine, however, the information on [wire termination processing](Glossary_o_verbindungsende_behandlung.htm) is exported that is based on the Wire termination processing connection property. In this table, you assign each connection category a wire termination processing.

In the Connection category column, all entries are listed that have been defined in parts management. In the Wire termination processing column, you specify how the connection should be closed, e.g., with a conductor sleeve or a [cable](Glossary_o_kabel.htm) lug. The values entered here are carried over to the connection [properties](Glossary_o_eigenschaften.htm) during routing and used subsequently in the export of connections.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Wire termination processing (default):

The wire termination processing entered here is always used during routing if no connection category has been defined for the connection point in question.

Use of dual sleeves:

Here you specify the circumstances under which dual sleeves are to be used in the export of connections:

- Always use: In the export of connections, dual sleeves are always used if two connections lead to the same connection point.
- Use when prescribed: In the export of connections, dual sleeves are used if two connections lead to the same connection point and if the Dual sleeve prescribed property has been activated for the connection point in question in the connection point pattern (local connection point pattern or at the [part](Glossary_o_artikel.htm)).
- Never use: Generally, no dual sleeves are used.

The Use when prescribed option is set by default.

![](../Pictures/Gui/ALL/note.png)Note:

For routing connections in a [topology](Glossary_o_topologie.htm), the usage of dual sleeves is not considered.

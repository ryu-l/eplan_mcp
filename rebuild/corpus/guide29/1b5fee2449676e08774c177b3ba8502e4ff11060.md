### Routing tracks

User interface / operation

Layout space:  
Total number of routing paths, wiring cut-outs or routing ranges that run through a connection routed in the layout space.  
  
Topology:  
Total number of routing paths and routing points that a connection routed in the routing path network (topology) runs through.

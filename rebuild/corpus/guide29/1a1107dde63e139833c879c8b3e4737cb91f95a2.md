# Tab Items (NC Export DXF / Copper Export DXF)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Machining > NC export DXF. Select the Items tab.
- Utilities > Manufacturing data > Machining > NC DXF. Click [...] next to the Machine field. Select the Items tab.

In this tab, you specify the [settings](Glossary_o_einstellungen.htm) on visibility as well as [layers](Glossary_o_ebenen.htm) and colors of item silhouettes and the exported fields.

Overview of the main dialog elements:

Group box Format for field

Display field:

Fields on [mounting panels](Glossary_o_montageplatten.htm) and other [items](Glossary_o_bauteile.htm) are represented in the [DXF](Glossary_o_dxf.htm) file as geometric shapes and assigned to specific layers and colors. If the check box is activated, a defined field for NC machining on a mounting panel or another item is displayed as a rectangle in the DXF file.

If the check box is deactivated, the fields will not be identified in the DXF file. However, the content of the fields will still be exported.

Layer:

Default name of the layer where the field is stored in the DXF file.

Color:

Default color that is assigned to the field in the DXF file.

---

Group box Format for item silhouettes

Generate item silhouettes:

Silhouettes of 3D items display their spatial limitation in addition to the basic [outlines](Glossary_o_konturen.htm) and extrusion paths. If the check box is activated, item silhouettes will be generated in the DXF file. In the DXF file, they can be output on separate layers and be assigned colors.

If the check box is deselected, no item silhouettes are generated. This reduces the data volume.

Layer:

Default name of the layer where the item silhouettes are stored in the DXF file.

Color:

Default color that is assigned to the item silhouettes in the DXF file.

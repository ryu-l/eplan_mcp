# Assigning Function Data to a Component

When assigning, you can move a function or function template, from the device navigator, to a [component](Glossary_o_schaltzeichen.htm) and apply the function data by clicking the component. An assigned function must have as many or more [connection points](Glossary_o_anschluesse.htm) than the component. This process is also possible in other [navigators](Glossary_o_navigatoren.htm), e.g. in the terminal strip navigator or in the interruption point navigator. During the assignment a check is run whether the source function in the navigator has the same function group as the target function in the schematic. If this is not the case, then a message is displayed.

Preconditions:

- You have opened a project. You have opened a project page in the graphical editor.
- You have placed a component onto a project page.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Devices > Navigator
2. Select one or more [functions](Glossary_o_funktionen.htm) in the dialog Device - <Project name>.
3. Select the Assign popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The function description of the (first) selected function is attached to the cursor.
4. Move the cursor across the component to change the color of the component.
5. Select the component.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The function data are applied to the component. The associated function of the component is newly sorted into the device navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The function description of the next function hangs on the cursor.

![](../Pictures/Gui/ALL/info.png)Tips:

- Using the [Ctrl]+[Shift] shortcut keys, you can also assign a function during the drag & drop from the device navigator. When you let go of the left mouse button during the drag, the function description of the highlighted function will hang on the cursor. Move the cursor to a suitable component, and with one click you can apply the data of the function to the component.
- Simultaneous assigning of several functions / [function templates](Glossary_o_funktionsschablonen.htm) is possible via a multiple choice of target functions. To do this, after selecting the Assign popup menu item click in the schematic and draw a frame around the required components. The functions / function templates are assigned in the order in which they are displayed in the navigator. The appropriate target functions are sought in the schematic according to their graphic sequence.

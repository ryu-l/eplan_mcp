# Read Customer Data

You can [load](Glossary_o_laden.htm) customer data such as address, company name, or telephone number from parts management into the [project properties](Glossary_o_projekteigenschaften.htm) of the current project. This avoids having to enter the customer data twice. You can load address information for manufacturers / suppliers into the "Creator" property group and you can enter address information for customers into the "Customer" and "End customer" property groups. Existing property values are overwritten.

Preconditions:

- You have imported directories and [projects](Glossary_o_projekte.htm) into Project management.
- In the global [settings](Glossary_o_einstellungen.htm) you have defined a parts database that contains the appropriate customer, manufacturer, or supplier address data.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project > Management
2. Select a project.
3. Select [Extras] > Read customer data > Created by to load manufacturer / supplier data into the "Created by" property group.
4. Select [Extras] > Read customer data > Customer to read customer data into the "Customer" property group.
5. Select [Extras] > Read customer data > End customer to read customer data into the "End customer" property group.
6. Mark an entry in the Select address dialog.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The customer data is read into the project [properties](Glossary_o_eigenschaften.htm) and is displayed in the Properties tab.

# Dialog Property overview - <Project name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have selected one or more [objects](Glossary_o_objekte.htm) (texts, components, [segments](Glossary_o_segmente.htm), graphical elements) in the graphical editor, in the [layout space](Glossary_o_bauraum.htm) or in a navigator. Edit > Property overview.

In this dialog you can edit the [properties](Glossary_o_eigenschaften.htm) of one or more selected objects (texts, graphical elements, [functions](Glossary_o_funktionen.htm), segments).

In order for the desired properties to be displayed for the selected objects, you must select or [create](Glossary_o_erstellen.htm) a fitting scheme for a property configuration. You can, for example, use the included "Format graphic" scheme for graphical elements. Otherwise the "No data" entry is displayed for the properties in the Value column.

Overview of the main dialog elements:

Select a scheme from the drop-down list for the display and editing of the properties. Use [...] to open the dialog for the property configuration. There you can determine which properties are to be displayed and in which sequence for a scheme.

Toolbar:

| Button | Meaning |
| --- | --- |
| (Tree view) | Shows the properties of the property configuration grouped according to their source objects in a tree view. |
| (List view) | Shows the properties of the property configuration arranged one below the other in a list. |

Filter:

Into this field enter the text for which the properties are to be filtered. Both the names of the displayed properties as well as the values are searched.

If you want to [return](Glossary_o_zurueckbuchen.htm) to the original view of the properties, remove the search term from the entry field. Click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) to do so.

Property / Value:

Shows the values of specific properties for the marked object or marked objects. Which values you can edit depends on the selected scheme.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

![](../Pictures/Gui/ALL/note.png)Note:

Global editing of distributed functions in the Property overview dialog is not possible for the activated Properties (global) mode.

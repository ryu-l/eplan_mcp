# Dialog Generate drilling patterns / outlines

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a macro project. Select the menu [items](Glossary_o_bauteile.htm) Utilities > Generate drilling patterns / outlines > From Rittal - Perforex / Secarex NC files. In the file selection dialog select the Rittal - Perforex / Secarex NC files to be imported and click Open.

In this dialog set the directory in which the [user-defined](Glossary_o_benutzerdefiniert.htm) [outlines](Glossary_o_konturen.htm) that are created together with the drilling pattern are to be stored.

In addition select a scheme with a Rittal - Perforex / Secarex machine definition from which further information can be used for the drilling pattern to be created.

Overview of the main dialog elements:

Machine:

Selection option for a scheme with a Rittal - Perforex / Secarex machine definition as it is defined in the [settings](Glossary_o_einstellungen.htm) for the Rittal - Perforex / Secarex NC export. The drill type and diameter of the [drill holes](Glossary_o_bohrungen.htm) in the drilling pattern to be created are determined from the settings in this scheme.

Directory for outlines (NC data):

Storage location for \*.fc1 files (outline NC data) that are created automatically during the creation of a drilling pattern. The default directory is the directory for [macros](Glossary_o_makros.htm) ($MD\_MACROS).

# Deleting Placements and Returning Placed Functions

The Return mode allows the removal of a [component](Glossary_o_schaltzeichen.htm) for a placed function in the schematic while leaving the data contained in the then unplaced function in the database. The representation type of the function is retained when the function is returned.

The following placement types can be returned:

- Schematic (single-line and multi-line)
- Overview
- Pair cross-reference
- [P&I diagram](Glossary_o_ri_fliessbild.htm).

The following placement types cannot be returned:

- Graphical placements
- External placements
- Part placements
- All elements that are not [functions](Glossary_o_funktionen.htm) or that cannot exist "unplaced" (angle, T-node, [interruption points](Glossary_o_abbruchstellen.htm), ...).

Precondition:

- You are in a schematic project.
- You have opened a page in the graphical editor, or you have opened a [project data](Glossary_o_projektdaten.htm) navigator (e.g., the device navigator).

1. Select the components in the graphical editor or the [placed functions](Glossary_o_platziertefunktionen.htm) in the navigator that you want to [return](Glossary_o_zurueckbuchen.htm).
2. Select the menu item Edit > Delete placement.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected functions that can be returned are converted into [unplaced functions](Glossary_o_nicht_platziertefunktionen.htm) (and deleted from the page).

![](../Pictures/Gui/ALL/note.png)Notes:

- If a single object is selected that cannot be returned, then the menu item is grayed-out.

- If multiple [objects](Glossary_o_objekte.htm) are selected that cannot be returned, then the menu item is also grayed-out.

- Otherwise, if multiple objects are selected, then only the returnable functions are considered and all other functions in the selection remain unchanged.

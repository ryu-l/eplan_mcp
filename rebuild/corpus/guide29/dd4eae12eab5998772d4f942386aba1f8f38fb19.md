# Dialog Button representation

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Right-click on an area of the menu bar or a toolbar and select the Customize popup menu item. Right-click the button whose appearance you want to edit.

This popup menu allows you to adjust the representation of a button to your requirements.

Overview of the main dialog elements:

Image / Text / Image and text:

Use these popup menu [items](Glossary_o_bauteile.htm) to select whether only the image, the button text or both are to be displayed.

Edit:

The selection of this popup menu item opens the [Configure button](modaldialogs_d_einstellungenschaltflaeche.htm) dialog in which you can specify the [settings](Glossary_o_einstellungen.htm) for the button.

Delete:

This popup menu item is used to delete the assigned action / menu button deleted. The toolbar itself remains.

# Display of Links to Connection Planning Objects and Other Objects in the Pre-planning Navigator

The pre-planning dependencies between the different [segments](Glossary_o_segmente.htm) are made visible by means of links. In order to detect whether segments are entered as source and target segments for [cable](Glossary_o_kabel.htm) and piping [planning objects](Glossary_o_planungsobjekte.htm) in the pre-planning navigator, you can have the links to the connection planning [objects](Glossary_o_objekte.htm) displayed by means of the new Tree view dialog.

[![](../Pictures/Gui/Lang/planninggui_treesettingsdialog_ls_thumb_0_60.png)](../Pictures/Gui/Lang/planninggui_treesettingsdialog_ls.png)

To open this dialog select the popup menu item Tree view in the pre-planning navigator. Activate the check box Links to the cable and piping planning objects and close the dialog. Subsequently the links to the cable and piping planning objects are displayed in the tree view of the pre-planning navigator below the respective segments (icon: ![](../Pictures/Gui/ALL/planninggui_link_as.png)).

### Showing or hiding objects in the tree

The view of the tree view of the pre-planning navigator can possibly be unclear. For this reason you can use the respective check boxes to hide or display other objects displayed by default for the tree in the Tree view dialog, such as [PLC addresses](Glossary_o_sps_adressen.htm), [structure boxes](Glossary_o_strukturkaesten.htm), [functions](Glossary_o_funktionen.htm). etc.

In accordance with your specification in this dialog other objects (PLC addresses, structure boxes, functions, etc.) are displayed below the segments or not.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

Thanks to the new Tree view dialog you can individually specify which objects are to be displayed in the tree of the pre-planning navigator below the segments in the tree and in this way structure the tree in a manageable [form](Glossary_o_verlauf.htm). The new links show you where the segments are located that are entered as source and target segments at the connection planning objects.

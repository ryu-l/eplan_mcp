# Exporting Data for Automatic Equipment Systems

The export to automatic equipment systems generates XML files for the format "Rittal - Athex". This machine automatically equips [mounting rails](Glossary_o_tragschienen.htm) with terminal strips and alignable terminal [accessories](Glossary_o_zubehoer.htm).

Preconditions:

- You have opened a project.
- A machine of the required type is defined in the company [settings](Glossary_o_einstellungen.htm).
- The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open.
- You have selected a mounting panel and / or mounting rails in the navigator or the layout space.

1. Select the Utilities > Manufacturing data > Automatic equipment (Rittal - Athex) menu [items](Glossary_o_bauteile.htm).
2. In the Export Rittal - Athex dialog select the required machine. Configure further settings for the export on the tabs General and Machine.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the set output directory, several files are generated that contain the [part](Glossary_o_artikel.htm) number and DT of the mounting rail to be equipped and the item values of the terminals to be placed on them. These files are transferred to the software of the Rittal - Athex machine and control the manufacture.

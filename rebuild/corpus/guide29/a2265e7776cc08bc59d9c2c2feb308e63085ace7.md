# Tab Format (3D part placement)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- The project contains at least one [layout space](Glossary_o_bauraum.htm). The layout space contains [part placements](Glossary_o_artikelplatzierungen.htm) (3D). You have opened the layout space navigator. Select a [part](Glossary_o_artikel.htm) placement in the navigator. Select the Properties popup menu item. In the Properties dialog, select the Format tab.
- You have selected a device in the 3D display area. Edit > Properties. In the Properties dialog, select the Format tab.

In this tab you can edit the display [properties](Glossary_o_eigenschaften.htm) of the graphical display of 3D components such as enclosures, [mounting panels](Glossary_o_montageplatten.htm), [mounting rails](Glossary_o_tragschienen.htm), etc.

Overview of the main dialog elements:

Property / Assignment:

The hierarchy level Format is available in the table. This can be opened by clicking the ![](../Pictures/Gui/ALL/all_plussign_as.png) sign.

Transparency:

Select a transparency level from the drop-down list or enter a value manually. With a value of 100% the [component](Glossary_o_schaltzeichen.htm) is completely transparent.

![](../Pictures/Gui/ALL/note.png)Notes:

- The color of a 3D object cannot be changed if a surface color or body color already exists. The color of an individual surface cannot be changed if there is a corresponding layer for the entire body. That is the case with a 3D enclosure, for example.
- A surface or body color is created if a STEP file is imported in which the colors have been defined. If no surface colors or body colors have been defined, then they can be set with this dialog element.
- These restrictions also apply to the way in which the Edit > Copy format and Edit > Assign format [functions](Glossary_o_funktionen.htm) work in connection with 3D [objects](Glossary_o_objekte.htm).

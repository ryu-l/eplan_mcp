# Dialog Format

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call (Formats for block properties):](javascript:void(0);)

You have opened a project. You have opened the [properties](Glossary_o_eigenschaften.htm) dialog for a function, a page, a symbol, or a project. You have selected the Block property: Format [n] property in the Properties field / Property name field / Properties tab and have clicked [...] in the Value column.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call (block formats for the configuration of the tree view):](javascript:void(0);)

You have opened a project. You have selected the popup menu item Configure representation in the tree of a navigator or of a dialog for parts. Click [...] in the Block format column.

In this dialog you define the properties that are to be summarized in the block property or to be displayed in the automatic description text of the [change tracking](Glossary_o_aenderungsverfolgung.htm) or at a segment in the pre-planning navigator or at an object in the tree view of a navigator.

Overview of the main dialog elements:

Available format elements:

Available groups of properties are displayed in this field.

If a target is found for a format element, the identifying name of the target is displayed in brackets behind the format element (for example full DT, full page name, etc.). Note that targets can only be found if a block property is defined for a concrete object - meaning, for example, not at the predefinition of [block properties](Glossary_o_blockeigenschaften.htm) at the project or at a symbol.

When selecting a format element with a target that is located on a page, the position of this target on the respective page is displayed in the Graphical preview.

  

Depending on the object the properties are grouped differently:

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Functions](javascript:void(0);)

Formats for block properties: For [functions](Glossary_o_funktionen.htm) the properties are grouped as follows:

- Function: Direct properties of the current function. The current function can also be a function connected to the starting function, which was found during navigation using ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level).
- Functional assignment ... User-defined structure: Properties of the [structure identifiers](Glossary_o_strukturkennzeichen.htm).
- CDP: Properties of the connection definition point.
- Part reference: The [part](Glossary_o_artikel.htm) reference data copied to the device.
- Part: The parts data stored in the project from the parts project database, such as part number and type number, that is assigned to the current function.
- Main function: Allows access to the [indirect properties](Glossary_o_indirekteeigenschaften.htm) of the main function (via ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level)) in [auxiliary functions](Glossary_o_nebenfunktionen.htm).
- Main function of superior device: Where there are nested [devices](Glossary_o_betriebsmittel.htm), this allows the properties of the main function of the superior device to be accessed from the subordinate device (via ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level)). If no main function is found, the properties of the first auxiliary function are output. To reach the top superior device when there are multiple nested devices, you must repeatedly navigate via ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level).
- Other representation types of the function: If the current function exists more than once in the project (e.g. in single-line and multi-line displays), you can use this to access the properties of the other [representation types](Glossary_o_darstellungsarten.htm) of this function.
- Other functions of the device: In distributed devices, you can use this to access the properties of the main function (first entry) and all auxiliary functions (all further entries).
- Device group (further functions): Allows for access to properties of the further functions of the device group from the current function (via ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level)) in connection with device groups. Here, select directly the entry "Device group (further functions)" to output the properties of all functions of the device group, with the exception of the currently highlighted function. Select the entry "Function properties [n]" to output the properties of the respective function within the device group. If an auxiliary function has been selected, you can reach the multi-line main function via the index value "1", and the other possible functions using the further index values.
- Target via connection point and target number: Provides the properties of additional functions connected to the current function. If you directly select the "Target via connection point and target number" entry, all targets of all [connection points](Glossary_o_anschluesse.htm) of the current function are output, separated by semicolons. If you select the "Connection point [n]" entry, all targets for this connection point are output, separated by semicolons. Otherwise, select a target here and then use ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level) to select the properties of the target.
- Connection via connection point and target number: Provides the properties of additional functions connected to the current function. For [connections](Glossary_o_verbindungen.htm), connection point 1 is used as the source and connection point 2 as the target.
- Last function via connection point and target number (PLC): Searches for a connected PLC connection point via the PLC [target tracking](Glossary_o_zielverfolgung.htm). In the process, the first target is always followed (in the same way as with [symbolic addresses](Glossary_o_symbolischeadressen.htm)). If no PLC connection point is found, then the last function reached is output.
- Network / bus cable connection point (single-line) of the device: Allows for PLC devices and bus capable devices to access the data of the first five single-line [bus ports](Glossary_o_sps_busanschluesse.htm) of the device and display them at the PLC box of the device. The sequence of these bus ports corresponds to the sequence displayed in the PLC navigator. Free [function templates](Glossary_o_funktionsschablonen.htm) are included in counting so that the sequence of the bus ports is not changed during the overlaying of the function templates.
- Segment data: Properties of the planning object which is linked to the function.
- Superior 3D part placement: Enables accessing the properties of a 3D part placement superior in the [layout space](Glossary_o_bauraum.htm) navigator (via ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level)).
- Path function text: Enables accessing of the associated path function text (via ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level)).
- Page: Properties of the page containing the current function.
- Project: Properties of the current project.
- Separator: Opens the [Format: Separator dialog](eservicesgui_d_formattrennzeichen.htm) in which you define the formatting for a [separator](Glossary_o_trennzeichen.htm) in the format group.
- Comment: Opens the [Format: Comment dialog](eservicesgui_d_formatkommentar.htm) in which you can enter a comment within the format group to document your format [settings](Glossary_o_einstellungen.htm).

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Interruption points](javascript:void(0);)

Formats for block properties: For [interruption points](Glossary_o_abbruchstellen.htm) the properties are grouped as follows:

- Interruption point: Properties of the current interruption point.
- Interruption point (counterpiece): In star interruption points, this allows access to the indirect properties of the different counterpieces (via ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level)).
- Interruption point (source): This allows access to the properties of the interruption points source (via ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level)).
- Target: Properties of the targets connected to the interruption point.
- Connection: This allows access to the indirect properties of the connections, by which the targets are connected to the interruption point (via ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level)).
- Page: Properties of the page containing the current function.
- Project: Properties of the current project.
- Separator: Opens the [Format: Separator dialog](eservicesgui_d_formattrennzeichen.htm) in which you define the formatting for a separator in the format group.
- Comment: Opens the [Format: Comment dialog](eservicesgui_d_formatkommentar.htm) in which you can enter a comment within the format group to document your format settings.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Potential definitions](javascript:void(0);)

Formats for block properties: The properties are grouped as follows for [potential definition points](Glossary_o_potenzialdefinitionspunkte.htm), [potential connection points](Glossary_o_potenzialanschluesse.htm) and [net definition points](Glossary_o_netzdefinitionspunkte.htm):

- Potential definition point: Properties of the current potential definition point, potential connection point or net definition point.
- Page: Properties of the page containing the current definition point.
- Project: Properties of the current project.
- Separator: Opens the [Format: Separator dialog](eservicesgui_d_formattrennzeichen.htm) in which you define the formatting for a separator in the format group.
- Comment: Opens the [Format: Comment dialog](eservicesgui_d_formatkommentar.htm) in which you can enter a comment within the format group to document your format settings.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Piping definitions](javascript:void(0);)

Formats for block properties: For piping definition points the properties are grouped as follows:

- Piping definition: Properties of the current piping definition point.
- Segment data: Makes it possible to access the properties of the higher-level [segments](Glossary_o_segmente.htm) such as piping [planning objects](Glossary_o_planungsobjekte.htm) (via ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level)).
- Substance: Properties of the current substance.
- Pipe class: Properties of the current pipe class.
- Page: Properties of the page containing the current definition point.
- Project: Properties of the current project.
- Separator: Opens the [Format: Separator dialog](eservicesgui_d_formattrennzeichen.htm) in which you define the formatting for a separator in the format group.
- Comment: Opens the [Format: Comment dialog](eservicesgui_d_formatkommentar.htm) in which you can enter a comment within the format group to document your format settings.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Automatic description texts](javascript:void(0);)

Template for automatic marking: For automatic description texts the properties are grouped as follows at change tracking:

- Project: Properties of the current project.
- Separator: Opens the [Format: Separator dialog](eservicesgui_d_formattrennzeichen.htm) in which you define the formatting for a separator in the format group.
- Comment: Opens the [Format: Comment dialog](eservicesgui_d_formatkommentar.htm) in which you can enter a comment within the format group to document your format settings.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Segments](javascript:void(0);)

Formats for block properties / display format navigator: For segments in pre-planning the properties are grouped as follows:

- Segment data: Properties of the segment.
- Superior structure segment: Properties of the superior structure segment.
- Superior segment: Properties of the superior segment.
- Subordinate segment: Properties of the subordinate segment.
- Structure segment hierarchical: Enables accessing of the properties of the superior structure segment at a graphically placed segment or at a function linked with a planning object. This way the [structure segments](Glossary_o_struktursegmente.htm) can be processed by way of the index, beginning with the top node in the tree of the pre-planning navigator down to the last structure segment above the current segment.
- Linked with higher-level segments: Properties of the segments below which the original segment is stored as a link.
- Linked segments: Properties of the segments which are inserted as a link below the original segment.
- Part reference: The part reference data copied to the device.
- Part: The parts data stored in the project from the parts project database, such as part number and type number, that is assigned to the current function.
- Main function: Allows access to the indirect properties of the main function (via ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level)) in auxiliary functions.
- Page: Properties of the page where the segment is placed.
- Project: Properties of the current project.
- Placement: At placed segments enables accessing properties for the placement itself (page name, column number, etc.) and accessing properties of the page via ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level).
- Piping planning object: Properties of the superior piping planning object.
- PCT loop: Properties of the superior PCT loop.
- PCT loop function: Properties of the superior PCT loop function.
- Piping definition: Makes it possible to access properties of the subordinate piping definitions for piping planning [objects](Glossary_o_objekte.htm).
- Substance: Makes it possible to access properties of the current substance for piping planning objects.
- Pipe class: Makes it possible to access properties of the current pipe class for piping planning objects.
- Separator: Opens the [Format: Separator dialog](eservicesgui_d_formattrennzeichen.htm) in which you define the formatting for a separator in the format group.
- Comment: Opens the [Format: Comment dialog](eservicesgui_d_formatkommentar.htm) in which you can enter a comment within the format group to document your format settings.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Objects in the tree view](javascript:void(0);)

Block [formats](Glossary_o_formate.htm) for the configuration of the tree view: The properties are grouped as follows for an object that is displayed in the tree view of a navigator or dialog for parts:

- <Object>: Properties of the respective object (for example for the "Page" object: properties of the current page).
- Separator: Opens the [Format: Separator dialog](eservicesgui_d_formattrennzeichen.htm) in which you define the formatting for a separator in the format group.

The segment data property group (with properties of the segment) is furthermore available for objects such as "Page" and "Function: <...>".

A further property group is also available for the objects of the macro navigator such as "3D macro", "window macro" and "page macro". For the "Window macro" object this is, for example, the macro box property group (with properties of the associated macro box).

Click the plus sign to open the subordinate property groups. If you can access indirect properties of other objects from this object, the ![](../Pictures/Gui/ALL/all_stairup_as.png) (Next level) button will be active. If you click this, the original property grouping is displayed once more â but these are now the (indirect) properties of the subsequent object! If a format group can be selected, then the ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right) button is active. In the subsequent dialog, you then select a particular property and define the formatting for this.

Selected format elements:

If you have selected and formatted properties in the Available format elements field, they are displayed here. The selected [format elements](Glossary_o_formatelemente.htm) are shown in tabular [form](Glossary_o_verlauf.htm) with their designation, symbolic representation (for the preview) and specified value. The order in which the properties are listed determines the order in which the individual properties are displayed in the output of the block property. You can change the sequence using the arrow buttons on the toolbar.

Navigation:

(Only for block property formats!)

This field displays the path leading to the selected property. The function definition of the starting function is displayed in the first row. In the case of a formatted project, the corresponding name of the format group is displayed. The steps through the available format elements that led to selection of the current property are displayed in the subsequent [lines](Glossary_o_leitungen.htm), for the format elements highlighted in the Selected format elements field.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You have selected a terminal and wish to output the DT of the first target connected to the first terminal connection point.

To do so select the entries Target via connection point and target number > Connection point 1 > Target 1 in the Available format elements field. Now click ![](../Pictures/Gui/ALL/all_stairup_as.png). You can now select properties of the terminal target in the Available format elements field. Select the entries Function properties > Device properties and click ![](../Pictures/Gui/ALL/all_arrowright_as.png). The dialog Format: Block property is opened. There select the DT (full) property and click [OK].

If you now select the entry in the Selected format elements field, the following is displayed in the Navigation field:

Terminal, 2 connection points  
Target via connection point and target number, connection point 1, target 1  
Device properties

Toolbar:

By using the buttons above the Navigation field, you can follow the path to indirectly referenced objects and back again.

| Button | Meaning |
| --- | --- |
| (Next level) | Allows continuing from a starting object, going to objects connected to this object and examining the indirect properties there. |
| (Previous level) | Allows returning from an indirectly referenced object back to the starting object. |

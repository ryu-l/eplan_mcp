# Dialog Settings: Column configuration (plugs)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the dialog [Edit plug](connectormanagementgui_d_steckerbearbeiten.htm). Click [...] next to the Scheme field.

In this dialog you can specify which columns will be displayed for the plug data.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

![](../Pictures/Gui/ALL/note.png)Note:

The [schemes](Glossary_o_schemata.htm) are saved by user. To include a scheme together with the project, you must export the scheme and pass it on separately.

Column configuration:

In this field you can specify which columns will be shown in the table in the dialog Edit plug. Check the corresponding check boxes. Use the arrow buttons to change the order of the columns.

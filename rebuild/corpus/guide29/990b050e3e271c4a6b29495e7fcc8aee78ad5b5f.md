# Data from Unplaced Functions

It is possible to [create](Glossary_o_erstellen.htm) [functions](Glossary_o_funktionen.htm) without having to place them in the schematic or mounting plan. All data in these "unplaced" functions can be changed or adapted. The creation of [connections](Glossary_o_verbindungen.htm) between unplaced and [placed functions](Glossary_o_platziertefunktionen.htm), and between unplaced and [unplaced functions](Glossary_o_nicht_platziertefunktionen.htm) is also possible.

The creation of functions is realized using so-called [device definitions](Glossary_o_geraetedefinitionen.htm) (types). Device definitions contain [function templates](Glossary_o_funktionsschablonen.htm), where function templates contain the minimum identifying [properties](Glossary_o_eigenschaften.htm) which are used to create functions (placed or unplaced).

In unplaced functions, no data relating to the graphic can be stored, i.e., no [symbols](Glossary_o_symbole.htm), line data, position of property placements etc. This data is defined by the user during placement.

# P005063: Connection point is not contained in the multi-line connection definition

### Cause

A target has not been assigned to all the [connection points](Glossary_o_anschluesse.htm) displayed on the Interconnect [devices](Glossary_o_betriebsmittel.htm) tab of the [property dialog](Glossary_o_eigenschaftendialog.htm) for a connection definition point that is represented as a single line.

### Solution

1. On the Interconnect devices tab for the single-line connection definition point, either connect all the connection points or none of them.
2. Then start a new check run.

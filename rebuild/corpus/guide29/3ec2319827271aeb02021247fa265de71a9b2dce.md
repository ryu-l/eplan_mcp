# P004028: Conflict between PLC input / output and related supply connection point within the defined channel

### Cause

The [properties](Glossary_o_eigenschaften.htm) of the PLC connection point of the input or output and the associated supply connection point are different within the defined channel.

Even though both [connection points](Glossary_o_anschluesse.htm) have the same card DT, the same plug designation, and the same channel designation, the message always appears if at least one of the properties Function text, Remark, Technical characteristics, Supplementary field, Address, Data type, or Symbolic address contains different data.

![](../Pictures/Gui/ALL/note.png)Note:

The message only appears if a character string is entered differently in two of the same fields. If one of the fields is empty, there is no message.

### Solution

1. Check the entered data in the fields mentioned above in the Properties <...> dialog of the PLC connection point for the input or output and the supply connection point.
2. If necessary, change the entered data so that the properties of the connection points agree. Ensure that a channel designation is entered at the connection points.
3. Then start a new check run.

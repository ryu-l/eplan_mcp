# Overview of Entries in Drop-down Lists

In the festo.cfg configuration file, entries from drop-down lists are specified as numbers. In the EPLAN parts management, the values specified below are possible in the different drop-down lists.

### Record type

The [record types](Glossary_o_datensatztypen.htm) are displayed in the tree view of the Parts management dialog.

| Internal value | Display |
| --- | --- |
| 0 | Not defined |
| 1 | Component |
| 4 | Assembly |
| 5 | Module |
| 6 | Drilling pattern |
| 7 | Connection point pattern |
| 11 | Customer |
| 12 | Manufacturer / supplier |

### [Generic product group](xmlexport_o_sellists.htm#P_ARTICLE_PRODUCTTOPGROUP)

This drop-down list is displayed in the General tab of the parts management.

### [Product group](xmlexport_o_sellists.htm#P_ARTICLE_PRODUCTGROUP)

This drop-down list is displayed in the General tab of the parts management.

### [Product subgroup](xmlexport_o_sellists.htm#P_ARTICLE_PRODUCTSUBGROUP)

This drop-down list is displayed in the General tab of the parts management.

### [Mounting surface](xmlexport_o_sellists.htm#P_ARTICLE_MOUNTINGSITE)

This drop-down list is displayed in the Mounting data tab of the parts management.

# Dialog Cut-out <Type>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open. The layout space contains a mounting panel and / or construction [items](Glossary_o_bauteile.htm). Insert > Cut-out > <Type>.

In this dialog, you can enter or select values for all available cut-out types. The units are imported from the project [settings](Glossary_o_einstellungen.htm) or converted to mm in case of input in inches.

Overview of the main dialog elements:

Drill hole, Threaded hole

| Dialog element | Meaning |
| --- | --- |
| Diameter: Nominal diameter: | Value for the drill hole diameter. The drop-down list shows all drill hole diameters used in the project and the most recently used drill hole diameter. |

Rectangle

| Dialog element | Meaning |
| --- | --- |
| Type: | From the drop-down list, you can choose from the entries "Square", "Rounded", and "Chamfered". |
| Width: | Width of the rectangle |
| Height: | Height of the rectangle |
| Radius / Chamfer distance: | This input field is available only if in the Type field of one of the entries "Rounded" or "Chamfered" has been selected. Here, depending on the select type, you can enter or select the value for the radius of the rounded rectangle or for the [chamfer](Glossary_o_fasen.htm) distance of the chamfered rectangle. |

Slotted hole

| Dialog element | Meaning |
| --- | --- |
| Length: | Length of the slotted hole. The value for the length entered must exceed the value for the height. |
| Height: | Height of the slotted hole. |

Hexagon, Octagon

| Dialog element | Meaning |
| --- | --- |
| Edge length: | Edge length of the hexagon / octagon. |

User-defined outline

| Dialog element | Meaning |
| --- | --- |
| Outline: | File name of a [user-defined](Glossary_o_benutzerdefiniert.htm) outline file \*.fc1. Using the [...] button, you can select the file from the outline directory defined in the company settings. |

Select drilling pattern

| Dialog element | Meaning |
| --- | --- |
| List: | In this dialog, you can select a drilling pattern for the cut-out type "From drilling pattern" defined in the parts management. This way, you can insert all required [drill holes](Glossary_o_bohrungen.htm) for an item in a single work step.  This list contains the names and descriptions of the [drilling patterns](Glossary_o_bohrbilder.htm) defined in the parts management. By selecting an entry and clicking [OK], you can select the drilling pattern to insert it.  After the placement, the grouping of the individual [cut-outs](Glossary_o_durchbrueche.htm) is broken down to [form](Glossary_o_verlauf.htm) a drilling pattern. The components of the drilling pattern can then be handled as if they had been placed individually. |

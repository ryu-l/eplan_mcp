### Basic projects

User interface / operation

Basic projects are templates for new projects; they can contain project settings, project data, pages, and master data. Basic projects have the zw9 file extension. When creating a project based on a basic project, all project settings, project data, and project pages as well as all stored and originally referenced master data are copied from the basic project into the new project.

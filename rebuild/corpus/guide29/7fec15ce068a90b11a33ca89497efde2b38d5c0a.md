# Defining Device Numbering (Changing Standards)

User-defined and pre-defined [schemes](Glossary_o_schemata.htm) for device numbering are taken from the template that you specified when creating the target project.

Preconditions:

- You have opened a project.
- In the case of several opened [projects](Glossary_o_projekte.htm): You have selected a project in the page navigator.
- You have set up a target project.
- You have defined a template and the rotation / flipping.
- You have replaced the necessary plot frame, [forms](Glossary_o_formulare.htm), [symbol libraries](Glossary_o_symbolbibliotheken.htm), and [symbols](Glossary_o_symbole.htm).
- You have specified the [project structure](Glossary_o_projektstruktur.htm).

1. Utilities > Change of standard > Project tab > [Next] > Rotation / flipping tab > [Next] > Master data tab > [Next] > Structure tab > [Next]
2. In the Number tab select the Renumber devices check box.
3. Select a numbering format from the Device numbering drop-down list.
4. Click [Finish].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The target project is displayed in the page navigator.

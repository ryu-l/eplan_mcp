# Tab User-defined properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have marked a [part](Glossary_o_artikel.htm) in the tree or list.

In this tab you assign [user-defined](Glossary_o_benutzerdefiniert.htm) [properties](Glossary_o_eigenschaften.htm) that you previously created and configured for the parts management in the [Configuration dialog](eservicesgui_d_konfigeigenschaften.htm) to a part. These properties are identical for all [variants](Glossary_o_varianten.htm) of a part.

Overview of the main dialog elements:

Scheme:

Choose the scheme that you would like to use from the drop-down list. Or click [...] to edit an existing scheme or [create](Glossary_o_erstellen.htm) a scheme using the Configure properties dialog.

[Assign scheme]:

With this button the user-defined properties stored in the scheme are entered into the tab. If properties were already assigned, the user-defined properties from the scheme are attached. If a property was already selected and is available in the scheme, its values are not changed during assignment.

Table

The user-defined properties that are assigned to a part are displayed in the table.

You can freely select individual user-defined properties for a part via ![](../Pictures/Gui/ALL/all_new_as.png) (New) or assign a predefined set of user-defined properties via [Assign scheme].

During a later part or device selection these user-defined properties are transferred with the values to the respective main function.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# P004046: A conflict occurred during the adoption of the PLC data for '<x>'

### Cause

As of EPLAN Version 2.4 all the PLC structure data are only still located at the main function of the PLC box. During the project import or the placement of [macros](Glossary_o_makros.htm) from older versions the data (property values) of the [auxiliary functions](Glossary_o_nebenfunktionen.htm) are collected and transferred to the main function. If this is not successful, the message is output.

### Solution

1. check the data at the main function and at the auxiliary [functions](Glossary_o_funktionen.htm).
2. Mark the auxiliary function temporarily as the main function so that the PLC structure data tab is displayed.
3. Transfer the property values to the PLC box that is to serve as the main function in future.
4. Subsequently select the menu [items](Glossary_o_bauteile.htm) Project > Organize > Compress in order to clean the project.
5. Select the scheme "Remove unnecessary [project data](Glossary_o_projektdaten.htm)" in the Settings field of the Compress project dialog and branch via [...] to the [settings](Glossary_o_einstellungen.htm) for the data to be compressed.
6. Activate the check box Remove project data and additionally in the subordinate branch the check box Remove PLC structure data at PLC auxiliary functions.
7. Start the compression of the project by confirming all the [settings dialogs](Glossary_o_einstellungsdialoge.htm) with [OK].
8. Then start a new check run.

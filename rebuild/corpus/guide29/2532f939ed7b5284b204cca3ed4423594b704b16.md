# New Setting for New User-defined Properties from Macros

Previously new [user-defined](Glossary_o_benutzerdefiniert.htm) [properties](Glossary_o_eigenschaften.htm), that were for example inserted into the project by inserting and copying [macros](Glossary_o_makros.htm), automatically had the Do not use anymore setting assigned to them. These properties were then not visible at the assigned [objects](Glossary_o_objekte.htm) and were deleted when the project was compressed again. In the new version you can now decide whether the new user-defined properties are used in the current project or not.

To this purpose the new check box Do not use new property configurations from macros is now available in the [project-specific settings](Glossary_o_projektbezogeneeinstellungen.htm) for the graphical editing. (The menu path for this is Options > Settings > Projects > "Project name" > Graphical editing > General.)

This check box is deselected by default. In this case the new user-defined properties remain available in the project and are displayed at the assigned objects.

Activate the check box if the same behavior as before is desired for the new user-defined properties.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

By means of the Do not use new property configurations from macros setting you can specify whether new user-defined properties from macros or other [master data](Glossary_o_stammdaten.htm) are used or not. When using the standard setting the new user-defined properties are directly visible in the project and this way can be found more easily in the project.

![](../Pictures/Gui/ALL/note.png)Note:

New user-defined properties can also be inserted via other master data such as [forms](Glossary_o_formulare.htm), [plot frames](Glossary_o_normblaetter.htm), etc. These properties are also taken into consideration through the setting.

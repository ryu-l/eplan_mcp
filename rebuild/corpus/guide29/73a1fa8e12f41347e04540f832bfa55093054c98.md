# P005077: Piping connection or definition point without specification of the substance

### Cause

The [P&I diagram](Glossary_o_ri_fliessbild.htm) has a piping connection point or piping definition point without specification of the substance.

### Solution

1. Locate the piping connection point or piping definition in the P&I diagram using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the piping connection point or piping definition point and enter the desired value in the Substance field.
3. Click [OK].
4. Then start a new check run.

# Dialog Settings: Automated processing

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Utilities > Automated processing. Click [...] next to the Scheme field in the dialog Run: Automated processing.
- Project > Management. You have imported directories in the Project management dialog and selected at least one project. Popup menu > Automated processing. Click [...] next to the Scheme field in the dialog Run: Automated processing.

In this dialog, you define a sequence of [actions](Glossary_o_aktionen.htm) that are to be run in an automated manner. This sequence of actions is saved in a scheme in a [user-specific](Glossary_o_benutzerbezogen.htm) manner, and thus, for example, can be copied, exported, and imported.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Description:

This field displays the descriptive text that you entered into the Description field in the New scheme dialog when you created the scheme.

Toolbar:

In the toolbar to the right of the Scheme field, you will see the following button, which is in addition to the default buttons for [schemes](Glossary_o_schemata.htm):

| Button | Meaning |
| --- | --- |
| (Import script) | Opens the Import script from previous version dialog. Allows for a script file to be imported that was created using a previous EPLAN version (version 2.1 or older). In the process, a scheme is generated from this script file. You set the name and description of the scheme during the import in the New scheme dialog. |

Available actions:

This field contains all of the actions that can be selected for automated processing. In order for an action to be included in the scheme, you must use ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right) to carry it over to the Selected actions field.

Selected actions:

This field shows all the actions contained in the selected scheme.

# Tab Attributes

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have marked a [part](Glossary_o_artikel.htm) in the tree or list.

In this tab you can enter additional attributes independently of the part type. These attributes are then identical for all [variants](Glossary_o_varianten.htm) of a part.

Overview of the main dialog elements:

Value:

Enter the value of the attribute here. In contrast to the free [properties](Glossary_o_eigenschaften.htm), attributes are no longer multilingual. Entry is limited to 80 characters.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

![](../Pictures/Gui/ALL/note.png)Note:

Every attribute can be used for filtering with the field-based filter. For example, you can define part classes and classification characteristics as per [ETIM](Glossary_o_etim.htm) here and then display the part data filtered according to this model.

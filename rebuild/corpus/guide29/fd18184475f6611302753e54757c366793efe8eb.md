# Dialog Select identifier subclasses

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have inserted a symbol in the graphical editor or generated a new function in a navigator. You have selected the <Function category> tab In the Properties <...> dialog. In the Displayed DT field, select the popup menu item Identifier subclasses.
- You have selected a [component](Glossary_o_schaltzeichen.htm) in the graphical editor or a function in a navigator. Edit > Properties (or Popup menu > Properties). You have selected the <Function category> tab. In the Displayed DT field, select the popup menu item Identifier subclasses.
- You have marked a planning object in the graphical editor or in the pre-planning navigator. Edit > Properties (or Popup menu > Properties). You have selected the <Planning object display name> tab in the Properties <...> dialog. In the Product aspect field select the popup menu item Identifier subclasses.

In this dialog you select an identifier subclass, to be used for generating a new DT, from a selection list. The selected subclass is used at [planning objects](Glossary_o_planungsobjekte.htm) to [generate](Glossary_o_erzeugen.htm) a new [product aspect](Glossary_o_produktkennzeichen.htm). (The identifier subclasses are stored in the project [settings](Glossary_o_einstellungen.htm) under "Project name" > Devices > Numbering (online).)

Overview of the main dialog elements:

Direct entry:

Enter a string of characters into this field. As soon as you enter the first character, the cursor jumps to the first entry in the Subclass column that begins with that character and marks it. If this character / entry is not found in the Subclass column, a search is carried out in the Subclass task column and â if it exists â the first entry is marked there.

Subclass / Subclass task:

In the Subclass column, select the desired designation of the identifier subclass and click [OK]. These characters are then adopted in the Displayed DT field in the component [properties](Glossary_o_eigenschaften.htm) dialog. This generates a new DT and any existing identifiers are discarded.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Transfer subclass task to function text:

Not available for planning [objects](Glossary_o_objekte.htm)! If this check box is activated, the text from the Subclass task column is transferred to the function text, if the function is a main function. Existing [function texts](Glossary_o_funktionstexte.htm) are overwritten in the process. Multilingual texts are transferred into all languages. No text is transferred for [auxiliary functions](Glossary_o_nebenfunktionen.htm).

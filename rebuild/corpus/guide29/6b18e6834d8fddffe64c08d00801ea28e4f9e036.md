# Tab Documents

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management. You have marked a [part](Glossary_o_artikel.htm) in the tree or list.

You can store up to 20 [external documents](Glossary_o_fremddokumente.htm) for a part on this tab.

Overview of the main dialog elements:

File / hyperlink:

To store external documents for part and device data, click [...] in this column and select the document file from the file selection dialog that opens. Here, again, you can also use Copy and Paste from the Popup menu to enter an Internet or e-mail address.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Open document | Provides the possibility to open stored documents or Internet addresses in the File / Hyperlink column. |

# Dialog Clipboard

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Under Options > Settings > User > Display > General you have deactivated the Do not show description dialog check box. You have opened a project. In addition, you have selected at least one object on a project page or at least one page in the page navigator.

- Edit > Copy. The Clipboard dialog can also be called for selected [objects](Glossary_o_objekte.htm) via the menu [items](Glossary_o_bauteile.htm) Edit > Cut.
- Popup menu > Copy

In this dialog you enter a description for the element to be copied.

The following dialog elements are available:

Description:

In this field you enter a description for the object or page you want to save in the Clipboard. If you want to insert the object or page, this description is displayed in the Paste dialog in the Description column.

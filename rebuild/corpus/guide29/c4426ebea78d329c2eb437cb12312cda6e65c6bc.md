# Creating and Editing Plugs

Plugs are managed via the plug definition and can be created in the plug navigator, the device navigator, and when inserted into the schematic.

If you want to [create](Glossary_o_erstellen.htm) a predefined plug (with a fixed number of male and / or [female pins](Glossary_o_steckerbuchsen.htm)), you have to first set up a plug definition. When doing this, you define whether the plug contains only [male pins](Glossary_o_steckerstifte.htm), only female [pins](Glossary_o_steckerkontakte.htm), or both.

If you only want to create a new plug (without any other [properties](Glossary_o_eigenschaften.htm)), just enter the plug DT in the Properties <...> dialog when you insert a pin. This creates a non-predefined plug without a plug definition. Such a non-predefined plug is visible in [reports](Glossary_o_auswertungen.htm), but you can't assign it any properties (this can only be performed via a plug definition).

You can create non-predefined [plugs](Glossary_o_stecker.htm) first and then edit the properties at a later date. You can also determine the properties for plugs immediately as you create them. You can create a plug with predefined properties using the [function definitions](Glossary_o_funktionsdefinitionen.htm).

In the [Plug definition](devicetaggui_r_steckerdefinition.htm) tab of the [property dialog](Glossary_o_eigenschaftendialog.htm), you can edit the properties of a plug.

### Create plugs

1. Select the Project data > Plugs > Navigator menu [items](Glossary_o_bauteile.htm).
2. Select the Generate plug definition popup menu item.
3. Select one of the submenu items in order to determine whether the plug consists of female pins, male pins, or a combination of male and female pins. When managing the male and female pins together, select the entry Male and female pins; when managing them separately, select Female pins or Male pins in order to determine the female or male pin side of the plug.
4. In the Properties <...> dialog in the Plug definition tab, enter the data you want for the new plug.
5. Click [OK].

### Create plugs with predefined properties

1. Select the Project data > Plugs > Navigator menu items.
2. Select a DT and select the New popup menu item.
3. In the Function definitions dialog in the Selection field, mark a plug definition.
4. Click [OK].
5. In the Properties <...> dialog in the Plug definition tab, enter the data you want for the new plug.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Below the highlighted DT, a plug definition with the corresponding properties is created.

### Edit plug

1. Highlight a plug definition or a pin in the graphical editor or in the terminal strip navigator.
2. Select the Project data > Plugs > Edit menu items.
3. If desired, number the pins using the Edit plugs dialog or sort them according to particular criteria. Use the popup menu options for editing.
4. Click [OK].

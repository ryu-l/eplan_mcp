# Converting Components into Graphics

The Convert component into graphic action gives you the option to turn a [component](Glossary_o_schaltzeichen.htm) into a graphical object without logic information. This functionality can be used, for instance, to graphically represent internal circuits in [black boxes](Glossary_o_geraetekaesten.htm).

A component converted into a graphic is not included in the [reports](Glossary_o_auswertungen.htm) and cannot be converted back into a functional device. (This is in contrast to a graphical component, defined using the "Graphic" representation type.)

Precondition:

You have opened a page in the graphical editor. You have inserted a symbol.

![](../Pictures/Gui/ALL/note.png) Note:

When you insert [symbols](Glossary_o_symbole.htm) in the [symbol editor](Glossary_o_symboleditor.htm), the [form](Glossary_o_verlauf.htm) editor or the plot frame editor, they are automatically converted into graphical [objects](Glossary_o_objekte.htm).

1. Highlight the component.
2. Select the Edit > Other > Convert component into graphic menu [items](Glossary_o_bauteile.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The component is converted into a graphical object. All the logic information is lost.
3. Select the Edit > Other > Ungroup menu items, if you want to edit the individual graphical elements of the object.

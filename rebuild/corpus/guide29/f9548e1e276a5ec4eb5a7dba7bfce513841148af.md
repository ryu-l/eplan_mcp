# Defining Connection Point Pattern in Layout Space

Part placements receive information about their [connection points](Glossary_o_anschluesse.htm) mostly from the definition of the connection point pattern on the [part](Glossary_o_artikel.htm). If in the [properties](Glossary_o_eigenschaften.htm) of the part placement on the Connection point pattern tab the Local connection point pattern check box is activated, the connection points defined on the part will be copied to this part placement. Subsequently, the referencing to the parts data is canceled, and the connection points can be modified individually.

If the placed part does not have predefined connection points, it is possible to define the connection points on the part placement graphically. These graphical connection points are also local and apply to the edited part placement. Like all local connection points, the graphically defined connection points, too, can be modified individually (position, connection point direction). The modified connection point data of local connection points can then be used again in order to transfer them to [connection point patterns](Glossary_o_anschlussbilder.htm) in parts management.

![](../Pictures/Gui/ALL/note.png)Notes:

- If you work with several [variants](Glossary_o_varianten.htm) of a part that have a connection point pattern, you should customize these separately for routing in the Function templates tab. Further information on this topic is available [here](partsmanagementgui_r_funktionsschablone.htm#AnschlussRouting).
- When specifying the [connecting points](Glossary_o_anschlusspunkte.htm) you must make sure that they lie within the geometrical dimensions of the device. If the connecting points lie outside of the device, the [connections](Glossary_o_verbindungen.htm) cannot be routed.

Preconditions:

- You have opened a project.
- The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open.
- The layout space contains 3D [part placements](Glossary_o_artikelplatzierungen.htm).

### Define connection points graphically

1. Select the menu [items](Glossary_o_bauteile.htm) View > Connection point designations and View > Connection point directions.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The predefined connection points and those to be newly defined of the part placements are displayed as red cuboids.
2. Select the Edit > Device logic > Connection point pattern > Define connection point menu items.  
     
   ![](../Pictures/Gui/ALL/arrow.png) You are prompted to select a surface to define the connection point direction. This can be any surface of an item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Z orientation of the selected surface determines the connection point direction. The Z orientation of a surface is always perpendicular to the base.

   ![](../Pictures/Visualisation/ALL/cabinetgui_z_surface_av.png)
3. Move the cursor over the surface with which you want to define the connection point direction.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The surface is color-marked.
4. Click the desired surface.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection point is represented by a red cuboid and hangs on the cursor.  
     
   ![](../Pictures/Gui/ALL/arrow.png) You are prompted to define the connection point in the layout space. For this you select the point where the connection point is to be placed.
5. Move the cursor over the 3D geometry.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The 3D snap points of the object are displayed; the connection point can also be placed outside the snap points.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Press down the [Ctrl] key to click on two points and to determine the center between these points. This way, the connection point can also be placed in the center of rectangular openings.
6. Select the [Placement options](cabinetgui_d_platzieroptionen.htm) popup menu item to enter for the placement of the connection point an [offset](Glossary_o_offset.htm) in the X, Y and Z direction.
7. Click the required point.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the [property dialog](Glossary_o_eigenschaftendialog.htm), the Connection point pattern tab is extended by a new row containing the coordinates of the specified point in the X, Y and Z position columns.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The X, Y and Z vector columns define the connection point direction. The values describe the preference with which the vector points to the direction of the respective axis. When [placing](Glossary_o_auflegen.htm) the connecting point for the first time, the Z orientation of the selected surface alone determines the connection point direction, therefore, the values X=0, Y=0, Z=1 are entered here.
8. Modify the vector values if the connection point is to be directed into another direction. Examples for this can be found [here](devicetaggui_r_anschlussbild.htm#XYZVektor).
9. Enter a connection point designation in the Connection point designation field of the new connection point.
10. From the Routing direction field select the desired direction in which the routing connection is to preferably search for an entry into the routing path network after the exit from the connection point.
11. Enter other properties of the connection point, as needed, in the other fields.
12. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The new connection point is placed in the selected location at the part placement as a red cuboid.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The connection point designation is visible on the front of the cuboid.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The connection point direction is indicated by a red arrow.  
      
    ![](../Pictures/Visualisation/ALL/cabinetgui_connpointdirection_av.png)

### Changing connection point directions

1. Prior to the changing of [connection point directions](Glossary_o_anschlussrichtungen.htm), select the View > Connection point directions menu items.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All connection point vectors are displayed.
2. Mark the entire item to modify all connection point directions of this item, or select a single connection point to modify only its connection point direction (1).  
     
   ![](../Pictures/Visualisation/ALL/cabinetgui_modconnpointdirection1_av.png)
3. Select the Edit > Device logic > Connection point pattern > Change connection point direction menu items.
4. Select a surface at the part placement at the Z orientation of which the connection point directions are to be adjusted (2).  
     
   ![](../Pictures/Visualisation/ALL/cabinetgui_modconnpointdirection1b_av.png)  
     
   ![](../Pictures/Gui/ALL/arrow.png) The connection point direction of the connection point is adjusted to the Z orientation of the selected surface (3).  
     
   ![](../Pictures/Visualisation/ALL/cabinetgui_modconnpointdirection2_av.png)

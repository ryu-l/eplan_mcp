# Action: XSettingsExport

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| Node | 'Node' of the [settings](Glossary_o_einstellungen.htm) to be exported.  If only the 'PROJECT' node is specified, all the project settings are exported. If no node is specified, all the settings are exported.  [ClosedExample:](javascript:void(0);)  The following example shows the start of the User+Display+General.xml file; the information needed to specify the node is highlighted with a border. |
| XMLFile | Directory and name of the target file. You can also enter [path variables](Glossary_o_pfadvariablen.htm).  [ClosedExample:](javascript:void(0);) |
| prj | Name of the project (must be open). |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Export all the user settings:

```
XSettingsExport /node:USER /XMLFile:c:my_user.xml
```

Export all the settings from a specific project:

```
XSettingsExport /prj:DEMO_D /XMLFile:c:my_project.xml
```

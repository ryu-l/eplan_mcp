# Properties: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_eigenschaften.htm)

### Properties

User interface / operation

Characteristics with a value or a setting assigned to an object. A property can have different values and / or settings for different objects of the same type. Properties influence the object, but not the system behavior. They are identified by numbers and can be output in forms, etc. In the program, properties are separated into different categories (e.g., Data, Settings, Formats), which can be displayed independently from one another. Depending on the current user group, different properties are visible and can be edited.

# EPLAN Fluid: Connection Point Logic of Fluid Power Functions

The following [properties](Glossary_o_eigenschaften.htm) are important for [fluid power](Glossary_o_fluidtechnik.htm) [functions](Glossary_o_funktionen.htm) when establishing connection point logic:

- Connection point type
- Pressure / control port
- Type of signal.

These properties can be edited in the Connection point logic dialog. (To do so, click [Logic] on the Symbol / function data tab in the Properties <...> dialog.)

### Connection point type of fluid power functions

The "Fluid", "Internal" and "Direct connection point" [settings](Glossary_o_einstellungen.htm) are available to you for the [connection points](Glossary_o_anschluesse.htm) of fluid power functions. "Internal" and "Direct connection point" are intended specifically for distributors and [connection splicers](Glossary_o_leitungsverteiler.htm) if they are components of valve groups.

This connection point type is required when generating fluid [connections](Glossary_o_verbindungen.htm). Using the "Fluid" connection point type, which is the automatic default when creating or [placing](Glossary_o_auflegen.htm) a fluid power function, fluid-specific connection lists can be evaluated and output, e.g. piping and tubing lists. The program additionally checks the trade at the respective functions and the default function definition entered in the settings for the connection. If a connection also has a connection definition point, the function definition of this is copied for generation of the connection.

### Pressure / control ports of fluid power functions

Different values can be specified in the [form](Glossary_o_verlauf.htm) of line types for the ports of fluid functions using the Pressure / control port property.

The following options are available:

- Undefined
- Pressure line
- Control line
- Drain line
- Process medium
- Heating and [cooling](Glossary_o_kuehlung.htm) medium
- Reservoir line
- Working line.

The line type is forwarded automatically to the connection by the connection points once the Pressure / control port property has received the value "undefined" at the connection itself (via a connection definition point).

A check run ("Connections" class) can also be used to determine whether the line types assigned to the function connection points match each other. If there is contradictory data, e.g. if a drain line is connected to a control line, a message indicating this is displayed in message management.

If connection lists are to be output, the Pressure / control port property can be specified as a sorting criterion.

### Signal type of fluid power functions

For fluid power functions, the Type of signal property can be used to specify whether a connection point is a pressure or suction port or is undefined.

# Project options: Definition of term

[Open topic with navigation](../../EPLAN_Help.htm#htm/Glossary_o_projektoptionen.htm)

### Project options

User interface / operation

Project options are areas of a project that can be selectively switched on and off. A project option consists of one or more areas, i.e., schematic areas, pages, or unplaced functions and connections. All areas of a project option can only be switched on and off together.

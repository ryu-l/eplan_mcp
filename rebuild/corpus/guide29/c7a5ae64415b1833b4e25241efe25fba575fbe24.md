# Dialog Settings: Parts management

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a parts database. Utilities > Parts > Management > [Extras] > Settings.
- You have opened a project and selected a main function in the graphical editor or in a navigator. Edit > Properties. Select the Parts tab and click [...] next to the Data source field.
- Options > Settings > User > Management > Parts.

In the Settings: Parts (user) dialog, click [Other].

In this dialog, you can specify certain default [settings](Glossary_o_einstellungen.htm) for your work with parts management.

Overview of the main dialog elements:

Function definition library for template selection:

In this field enter the directory that contains the function definition library to be used to select the [function templates](Glossary_o_funktionsschablonen.htm): Click [...] and from the subsequent file selection dialog select the directory of your customer code, for example.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).

List / tree sorting:

From this drop-down list, select whether the sorting of records in the list and tree views should be alphabetical or alphanumerical.

Measuring unit - import / export:

In parts management, units are always saved in "mm" / "kg". If you import or export EPLAN data, you can use these options to decide which unit system should be used.

Currency 1 / Currency 2:

In these two fields you specify the two currency units and the conversion factor which should be used for the selected parts database.

# P004007: Rack '<x>' is mounted on itself

### Cause

Identical [designations](Glossary_o_bezeichnungen.htm) were entered for a PLC box containing bus data in the Rack [ID](Glossary_o_id.htm) and PLC card is placed on [rack](Glossary_o_baugruppentraeger.htm) ID fields, which means that the rack is mounted on itself.

### Solution

1. Open the Properties <...> dialog of the corresponding PLC box.
2. In the first tab, enter different data into the Rack ID and PLC card is placed on rack ID fields.
3. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

This check run only checks [PLC boxes](Glossary_o_sps_kaesten.htm) at which a configuration project is entered.

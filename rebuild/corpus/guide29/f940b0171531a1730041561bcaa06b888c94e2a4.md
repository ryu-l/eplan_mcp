# Defining Drilling Patterns Graphically

Drilling patterns can also be defined graphically in a macro project, without using data from imported NC or [DXF](Glossary_o_dxf.htm) / [DWG](Glossary_o_dwg.htm) files. The process encompasses four working steps:

- Drawing of the outline of the item and of the required [drill holes](Glossary_o_bohrungen.htm) on a graphics page
- Assigning the identifying [layers](Glossary_o_ebenen.htm) for the drilling pattern generation
- Inserting a drilling pattern frame
- Automatic generation of the drilling pattern.

Precondition:

You have opened a macro project.

1. Open a graphics page on a 1:1 scale.
2. Draw the outline of the item and the drill holes required in it true to scale.
3. Open the [properties](Glossary_o_eigenschaften.htm) dialog of the each element and bring the Format tab to the front. Change the layers of the elements specified for the drilling pattern as shown in the following table in the Layer property below the Format hierarchy level.

| Element | Name (layer), description | |
| --- | --- | --- |
| Outline item | EPLAN802, Graphic.Drilling pattern generation.Items | |
| Drill holes (all drill types) | EPLAN803, Graphic.Drilling pattern generation. Drill holes | |
| Threaded holes | EPLAN804, Graphic.Drilling pattern generation. Threaded holes | |
| User-defined [outlines](Glossary_o_konturen.htm) | EPLAN805, Graphic.Drilling pattern generation.Outlines | |

4. Insert a drilling pattern frame that encompasses the elements intended for the drilling pattern. Select Insert > Box / connection point / mounting panel > Drilling pattern frame.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A point of origin is set at the bottom left at the outline of the item.
5. Enter the name, a description and a directory for the [user-defined](Glossary_o_benutzerdefiniert.htm) outlines to be created in the properties dialog of the drilling pattern frame.
6. Create the [drilling patterns](Glossary_o_bohrbilder.htm). Select the menu [items](Glossary_o_bauteile.htm) Utilities > Generate drilling patterns / outlines > Automatically from macro project.
7. Select whether the process is to be applied to the complete project or only to the selected drilling pattern frame.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The drilling patterns are shown in a top view in the parts management from the drawn [objects](Glossary_o_objekte.htm) that are assigned to the [drilling pattern frames](Glossary_o_bohrbildkaesten.htm).

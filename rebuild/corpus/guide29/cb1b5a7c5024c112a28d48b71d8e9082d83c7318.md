# Dialog Address PLC connection points: Preview of results / Dialog Reassign PLC addresses: Preview of results

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have selected several [PLC connection points](Glossary_o_sps_anschluesse.htm) in the graphical editor, the PLC navigator, or in the device navigator. Or you have selected one or more pages or a project in the page navigator.

- Project data > PLC > Address. In the Readdress PLC connection points  dialog, select the Preview of result check box and click [OK].
- Project data > PLC > Addresses / assignment lists. You have selected [PLC addresses](Glossary_o_sps_adressen.htm) in the table. Select the Address popup menu item. In the Reassign PLC addresses dialog, select the Preview of result check box and click [OK].

This dialog displays a preview of the addressing. You can manually edit the new addresses before they are adopted by the project.

Overview of the main dialog elements:

Table:

The table lists the newly-addressed PLC [connection points](Glossary_o_anschluesse.htm) and their [properties](Glossary_o_eigenschaften.htm), such as DT (identifying), Connection point designation (with Plug designation (automatic)), Symbolic address, and Function text. The old and new address are displayed opposite each other; you can manually change the new address. All other fields are for information only and cannot be changed here.

If multiple assignment occurs at addressing, for example because an address is already used at a different point in the project, the corresponding cell id highlighted in red.

![](../Pictures/Gui/ALL/note.png)Note:

Please note that PLC connection points to which the Do not include in addressing property is assigned are not displayed here.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

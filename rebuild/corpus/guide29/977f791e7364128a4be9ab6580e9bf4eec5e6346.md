# Selecting Parts in the Navigators or the Device List

In the device navigator, the bill of materials navigator and the device list you can open the parts selection tool via the context menu.

### Create devices in the device navigator

You can [create](Glossary_o_erstellen.htm) [devices](Glossary_o_betriebsmittel.htm) in the device navigator with the parts selection tool.

1. Project data > Devices > Navigator
2. Mark an element and select the popup menu item New device.
3. In the Part selection dialog search through the tree structure and select one or more desired parts.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) A new device is created. The device is sorted into the [project structure](Glossary_o_projektstruktur.htm) according to the marked element.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts data are stored at the device. In this way, a new device is created through [part](Glossary_o_artikel.htm) selection.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Assume that you have marked an arbitrary device under the installation location PT1. Now open part selection through the New device function, and select a conctactor. Under PT1, the device K1 is created with all the [functions](Glossary_o_funktionen.htm) of a contactor.

### Select parts from the Bill of materials navigator

1. Project data > Parts / Devices > Bill of materials navigator
2. Mark an entry and select the popup menu item Add part or Exchange part.
3. In the Part selection dialog search through the tree structure and select one or more desired parts.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new part is assigned to the marked device. In Exchange part, the old part is replaced, while in Add part existing [part references](Glossary_o_artikelreferenzen.htm) are retained.

### Select parts from the device list

1. Project data > Parts / Devices > Device list
2. Select the Add part popup menu item.
3. In the Part selection dialog search through the tree structure and select one or more desired parts.
4. Click [OK].
5. You store the part-specific data in the dialog Properties.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts data are written into the Device list. A new entry is created for the part to be monitored.

# P005035: The connection definition point (<x>) on a multiple connection was re-arranged and re-formatted

### Description

This message appears if one of the [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) lies on a multiple connection when you are setting up and formatting these points.

![](../Pictures/Gui/ALL/note.png) Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

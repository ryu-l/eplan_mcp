# Updating a Report Automatically / Not Automatically

You can define whether or not already generated [reports](Glossary_o_auswertungen.htm) are automatically updated when opened.

Preconditions:

- You have created [report pages](Glossary_o_auswertungsseiten.htm).
- You have opened a project in the page navigator.

![](../Pictures/Gui/ALL/note.png) Note:

If you update report pages automatically, then opening pages takes somewhat longer than opening without automatic updating.

1. Select the menu [items](Glossary_o_bauteile.htm) Options > Settings > User > Display > General.
2. Activate the Update reports when opening pages check box in the dialog Settings: General and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you now open a report page, the report page is updated.
3. To deactivate the automatic updating again select the menu items specified above again and deactivate the Update reports when opening pages check box.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you now open a report page, the report page is not updated.

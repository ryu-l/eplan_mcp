# Dialog Mounting grid

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The project contains at least one [layout space](Glossary_o_bauraum.htm). The layout space contains 3D [objects](Glossary_o_objekte.htm). Edit > Device logic > Mounting grid.

In this dialog, you can set the [properties](Glossary_o_eigenschaften.htm) of a [mounting grid](Glossary_o_montageraster.htm). Mounting grids are assigned to individual areas of a 3D [part](Glossary_o_artikel.htm) placement, and during the placement of other components are displayed on these areas. Thus, placement is only possible on the intersections of the [grid](Glossary_o_raster.htm) [lines](Glossary_o_leitungen.htm). Using the mounting grid, it is possible to represent a manufacturer and type-specific hole pattern, for example, on enclosure profiles, within which screw [connections](Glossary_o_verbindungen.htm) are set during the mounting.

The grid points defined in the dialog always refer to the origin of the area, which is displayed by means of a coordinate system.

Overview of the main dialog elements:

Group box X direction

Grid increment:

Determines the distance between two grid lines in the X direction.

Number of grid lines:

Number of times the grid increment defined by the grid lines in the X direction is repeated.

The grid extends to the end of the mounting surface if you select the value "No limitation" in the drop-down list.

Number of grid lines in the X and Y direction may not be 1 simultaneously.

---

Group box Y direction

Grid increment:

Determines the distance between two grid lines in the Y direction.

Number of grid lines:

Number of times the grid increment defined by the grid lines in the Y direction is repeated.

The grid extends to the end of the mounting surface if you select the value "No limitation" in the drop-down list.

Number of grid lines in the X and Y direction may not be 1 simultaneously.

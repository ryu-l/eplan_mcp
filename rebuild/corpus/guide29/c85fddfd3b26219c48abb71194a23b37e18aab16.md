### Type code

Fluid power

The type code allows the defined ordering of a hose line from any manufacturer or supplier. The type code preset by default in EPLAN fulfils the specifications of the hose line standard DIN 20066 and is made up of the values of the following data:

- Hose designation (depending on the working pressure and the nominal diameter of the hose)
- Nominal diameter
- Form of the fitting, left
- Form of the fitting, right
- Hose length (without specification of the unit)
- Torsion angle (only relevant at elbow fittings, with specification of the degree)

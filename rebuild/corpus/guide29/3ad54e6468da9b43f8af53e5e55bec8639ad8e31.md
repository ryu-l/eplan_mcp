# Tab Display (Connection Numbering)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Options > Settings > Projects > "Project name" > Connections > Connection numbering. Select the Display tab in the dialog Settings: Connection numbering.
- You have selected a connection in the graphical editor, or in the Connections - <Project name> navigator dialog. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog. Project data > Connections > Numbering > Place > [...]. Select the Display tab in the dialog Settings: Connection numbering.

In this tab you specify the formatting for [connection designations](Glossary_o_verbindungsbezeichnungen.htm) generated on the connection definition point.

Overview of the main dialog elements:

Property / Assignment:

To this purpose the hierarchy [levels](Glossary_o_etagen.htm) Distance and Format are available. These can be opened by clicking the ![](../Pictures/Gui/ALL/all_plussign_as.png) sign.

---

Distance hierarchy level

Horizontal:

Specify the spacing of connection [designations](Glossary_o_bezeichnungen.htm) to vertical connection sections. The connection designation for vertical connection sections is fixed on the connection line. This setting allows you to move the position positively or negatively in a horizontal direction.

If the connection designation is docked to another property then the setting affects the entire block.

Vertical:

Specify the spacing of connection designations to horizontal connection sections.

---

Format hierarchy level

Alignment:

Select the desired text alignment from the drop-down list. The alignment defines where the insertion point relative to the text is located.

| 1: Upper left    2: Middle left    3: Basis left    4: Lower left |  | 9: Upper right    10: Middle right    11: Basis right    12: Lower right |
|  | 5: Upper center  6: Middle center  7: Basis center  8: Lower center |  |

- Special left

- JIC special centered.

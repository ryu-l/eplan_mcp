# Selecting Cables

Cables can be selected automatically or manually.

Using the Allow manual cable selection only property for each [cable](Glossary_o_kabel.htm) you can specify that the cable can only be manually selected. Those types of cables are then not considered for the automatic cable selection.

### Select the cables manually

Select a [part](Glossary_o_artikel.htm) from the parts database when making manual cable selections. The procedure is exactly like selecting any other part. You have the following options:

- [Selecting parts](partselectiongui_h_artikelauswahl.htm) in the Properties <...> dialog
- [Selecting parts in the navigators or the device list](partselectiongui_h_artikelauswahlnavigator.htm)

### Select cables automatically

The automatic cable selection only exchanges the [main part](Glossary_o_hauptartikel.htm) (this is the first part from the "Cable" product group) with a suitable part from the parts management.

In the project [settings](Glossary_o_einstellungen.htm) you can define a preselection list of [cable types](Glossary_o_kabeltypen.htm) (cable parts) for the automatic cable selection. Only the cables from this list will be used for automatic cable selection.

Preconditions:

- You have selected [cable definitions](Glossary_o_kabeldefinitionen.htm) in the graphical editor, or in the Cables - <Project name> navigator dialog.
- You have created a scheme with settings for the automatic cable selection ([Dialog Settings: Automatic cable selection](cablegui_d_einstellungenautomatischekabelauswahl.htm)).

1. Select the Project data > Cables > Automatic cable selection menu [items](Glossary_o_bauteile.htm).
2. In the [Automatic cable selection](cablegui_d_automatischekabelauswahl.htm) dialog, determine the settings for automatic cable selection.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) According to the settings specifying which [properties](Glossary_o_eigenschaften.htm) should be taken into consideration for the automatic cable selection, the suitable cable is searched for in parts management. The voltage entered for the cable, the voltage of the [cable connections](Glossary_o_kabelverbindungen.htm) (defined via the [potentials](Glossary_o_potenziale.htm)), the number of [connections](Glossary_o_verbindungen.htm) present, and the number of spare cable connections are compared. If there is no information on the manufacturer, the first one to be found will be taken.

![](../Pictures/Gui/ALL/note.png)Notes:

- The quantity of PE / PEN [conductors](Glossary_o_adern.htm) (0, 1, or 2) specified in the PE conductors field is taken into consideration when determining the quantity of connections. If the cable has no PE / PEN conductors and there is no cable in the corresponding voltage range without PE / PEN conductors in parts management, then a cable with PE / PEN conductors will be taken. The PE / PEN conductor is added to the number of connections needed.
- Arbitrary values can be predefined for the individual cables. This way, for example, a cable type can already be entered on a cable in the schematic that is not in the settings for the cable selection. A cable will then be selected which corresponds to the cable type entered and has a suitable number of connections. A missing cross-section / diameter is taken from the defaults depending on the voltage. The same values are used here as for manual cable selection.

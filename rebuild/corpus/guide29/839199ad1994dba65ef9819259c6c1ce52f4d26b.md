# Dialog Format: Property

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have installed the hose line configurator as an add-on variant of EPLAN Fluid. You have started EPLAN Fluid and the hose line configurator.

- Select the menu [items](Glossary_o_bauteile.htm) Options > Settings > User > Add-ons > Hose line configurator. Bring the General tab to the front and click [...] next to the Format type code field .
- Or select the menu items Extras > Settings in the Configure hose lines dialog of the hose line configurator. Bring the General tab to the front and click [...] next to the Format type code field .

Or you have installed the hose line configurator as a stand-alone variant and started the program.

- Select the menu item Options > Settings > User > Add-ons in the menu of the hose line configurator. Bring the General tab to the front and click [...] next to the Format type code field .

In this tab you define the display format for the [type code](Glossary_o_typencode.htm) of the [hose lines](Glossary_o_schlauchleitungen.htm).

Overview of the main dialog elements:

Available format elements (lists):

This list displays all the available [format elements](Glossary_o_formatelemente.htm) that can be [part](Glossary_o_artikel.htm) of the display format for the type code. In order for a format element to be used for the display format, you have to use the ![](../Pictures/Gui/ALL/all_arrowright_as.png) (move to right) command button to transfer it into the Selected format elements field. In the process the Property selection dialog opens in which you have to select the property.

The following format elements and [properties](Glossary_o_eigenschaften.htm) are available:

| Available format elements | Name of the selectable property | Meaning |
| Properties | Cable / Conduit: Cross-section / diameter | Outputs the selected nominal diameter of the hose (without unit). |
| Cable / Conduit: Type | Outputs the selected hose type. |
| Hose line length | Outputs the selected hose line length (without unit). |
| Part group [1]-[50]: Part group [1] and Part group [2] are available for fittings. | Part group [1] / Part group [2] outputs the selected type of construction of the fitting to be mounted on the left / right at the hose. |
| Torsion angle | Outputs the selected [torsion angle](Glossary_o_verdrehwinkel.htm) of the used fitting (without unit). |
| Separator | Separator | Separates format elements from one another. |

Selected format elements (table):

This table displays all the format elements comprising the current type code.

Use the command buttons of the toolbar above the table in order to edit the format elements, to change their order for the output in the type code and / or to delete format elements no longer needed.

![](../Pictures/Gui/ALL/note.png)Note:

If you select the default scheme DIN 20066\_2012-01, the format elements are already selected in this dialog so that a norm-compliant type code to DIN 20066 is created.

Preview:

This field indicates the order of the selected format elements in the type code. The individual format elements are shown through the placeholders of the properties.

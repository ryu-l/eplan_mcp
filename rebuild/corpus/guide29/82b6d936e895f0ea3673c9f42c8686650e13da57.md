# Dialog Configure property arrangements - <Project name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Project data > Configure property arrangements.

You [create](Glossary_o_erstellen.htm) [user-defined](Glossary_o_benutzerdefiniert.htm) property arrangements in this dialog. These arrangements are stored project-specifically and can be used at 3D [part placements](Glossary_o_artikelplatzierungen.htm) or components within a project.

Overview of the main dialog elements:

The user-defined property arrangements that exist in the current project are displayed on the left-hand side in the dialog in a tree and list view.

Property arrangements for 3D [part](Glossary_o_artikel.htm) placements in a new project already on the left-hand side in the dialog, via the used [project templates](Glossary_o_projektvorlagen.htm). The property arrangements are only displayed for the [component](Glossary_o_schaltzeichen.htm) if a user-defined property arrangement was saved under a name here in the dialog or at the component.

While the user-defined property arrangements of the 3D part placements in the [layout space](Glossary_o_bauraum.htm) are assigned to a function definition, the property arrangements for components are saved for a symbol variant.

Filter:

Enter the text for which the property arrangements are to be filtered into this field. To this purpose the property arrangements are searched for both the identifying name as well as the displayed name.

If you want to [return](Glossary_o_zurueckbuchen.htm) to the original view of the property arrangements, remove the text from the entry field. Click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) to do so.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Library-oriented (tree only) | Only available at the property arrangements for components. Shows the [symbol libraries](Glossary_o_symbolbibliotheken.htm) in the highest node below the "Component" folder. Under them are the [function definitions](Glossary_o_funktionsdefinitionen.htm). |
| Function-oriented (tree only) | Only available at the property arrangements for components. Shows the functional category (such as "Coils and contacts" and "Signal [devices](Glossary_o_betriebsmittel.htm)") in the upper node below the "Component" folder. |
| New | Allows creating a new user-defined property arrangement. Depending on the marker in the tree or list the Function definitions or Symbol selection dialog is first opened and after the selection of a function definition or a symbol the dialog New property arrangement. |
| Insert into list of search results | Checks the usage of the marked structure property arrangements in the project and enters the found [objects](Glossary_o_objekte.htm) into the search results list. This way you can search via the popup menu item Go to (graphic) in the graphic for the used property arrangements of objects such as components, part placements, etc. |

---

New property arrangement

The marked hierarchy level is used as a filter when creating new property arrangements.

If you have selected a symbol variant or the component arrangement of a symbol variant, the New property arrangement dialog for entry of an identifying name is opened and then a property arrangement is created for components. If you have selected a function definition or the property arrangement of a function definition, a property arrangement for a function definition is created.

If you have selected a higher hierarchy level in the tree, the marked position is used as a filter for the subsequently opened dialog Function definitions or Symbol selection. Then, enter a unique identifying name for the property arrangement in the New property arrangement dialog.

![](../Pictures/Gui/ALL/note.png)Note:

Within a project, the identifying name must be unique and cannot be subsequently changed any more.

Multiple selection of property arrangements

A multiple selection of property arrangements or list structure [levels](Glossary_o_etagen.htm) is possible here. The following points are to be considered:

- If you have selected the property arrangements of different [symbol variants](Glossary_o_symbolvarianten.htm) or function definitions, a shared displayed name can be assigned for these property arrangements.
- For the same configuration (same [properties](Glossary_o_eigenschaften.htm), order of the properties and docking [settings](Glossary_o_einstellungen.htm)) you can directly edit the property arrangements in the tabs 3D functions or Components etc.
- For a different configuration you are shown the ![](../Pictures/Gui/ALL/eservicesgui_multipleselection_as.png) entry in the tabs 3D functions or Components. To still be able to configure the property arrangements together, you must mark the entry and then remove all previously selected properties via the button ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete). This way all selected property arrangements receive a completely new configuration!

After the shared editing the selected property placements and changed display settings are available at all selected property arrangements.

---

Identifying name:

Here, the unique name is displayed that you specified when you created the property arrangement. The property arrangement is managed in EPLAN under this name.

Displayed name:

Here, enter the name under which the property arrangement is displayed in the project. Multi-lingual entry is possible.

Default:

Select this check box if the property arrangement is to be used as a default for all additional usages of the symbol 3D part placement / symbol variant.

---

Configuration of the properties and display settings

The actual configuration of the properties with the associated display settings is effected for 3D part placements in the 3D functions tab and for components in the Component tab as well as in the tabs Connection points and Contact image. To this purpose the same setting options are available as in the [Display](devicetaggui_r_anzeige.htm) tab of the [property dialog](Glossary_o_eigenschaftendialog.htm).

[Extras]:

| Menu item | Meaning |
| --- | --- |
| Check usage | Fills the Usage count column in the list view with the current numbers of how frequently the respective property arrangement is used in the project. Property arrangements not used receive the entry "0". |
| Remove unused property arrangements | Deletes user-defined property arrangements that are not used in the project. Fixed specified property arrangements (such as "Default value" or "Upper left, outside, 90°" at the boxes) are not removed. |

# Displaying / Filtering Frozen Report Pages

This functionality allows you to filter by [Frozen report pages](formgeneratorgui_k_eingefrorseiten.htm). You can also display the number of frozen [report pages](Glossary_o_auswertungsseiten.htm) from the project statistics.

Preconditions:

- You have opened a project.
- You have frozen report pages.

### Display the number of frozen report pages

1. Select the following menu [items](Glossary_o_bauteile.htm): Page > Navigator
2. Select a structure identifier layer.
3. Select the menu items Project > Properties.
4. In the Project properties - <Project name> dialog, select the Statistics tab.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The number of frozen report pages for each page type is displayed in the Frozen pages column.

### Filter frozen report pages

1. Select the following menu items: Page > Navigator
2. Click [...] next to the Filter field in the page navigator.
3. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) next to the Scheme field in the Filter dialog, and [create](Glossary_o_erstellen.htm) a new scheme in the subsequent dialog.
4. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the toolbar for the filter criteria.
5. Select the Frozen report page property in the Criteria selection dialog below the "Properties" hierarchical level.
6. Activate the associated check box for this criterion in the Value column of the Filter dialog.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The filter just created is entered automatically in the Filter field of the page navigator and activated.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All non-frozen report pages are hidden. Only the frozen report pages are displayed.

# Expanding All Trees in a Table At the Same Time

At various locations in the user interface several tree views are displayed under each other in a table column. You now have the new Expand all popup menu item available in the popup menu of the respective table cells, so that you can now expand all trees at the same time. The Collapse all popup menu item that is also new collapses all the trees in the table column at the same time so that only the respectively top hierarchy level is displayed.

This is, for example, the case in the following dialogs:

- In the Properties (components): Placeholder object dialog in the Assignment tab
- In the Generate PLC schematic dialog for PLC [devices](Glossary_o_betriebsmittel.htm)
- In the [property dialog](Glossary_o_eigenschaftendialog.htm) of the components on the Display tab in the Property / Assignment table.

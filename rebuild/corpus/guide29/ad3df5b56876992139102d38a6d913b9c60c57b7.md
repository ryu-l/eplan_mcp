# Deleting Connection Definition Points Without Connections

When compressing [projects](Glossary_o_projekte.htm) you can now delete [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) that have no [connections](Glossary_o_verbindungen.htm) assigned. Such connection definition points can for example occur while copying and pasting schematic sections.

A menu path to the compression [settings](Glossary_o_einstellungen.htm) is: Options > Settings > Projects > "Project name" > Management > Compress. The new Connection definition points without connections check box is availabe in the dialog Settings: Compression below the Remove project data hierarchy level

If this setting is activated, all connection definition points that have no connections assigned are deleted when compressing the project. Connection definition points on connections without target (this means the connection ends for example at an angle or T-node) are also deleted.

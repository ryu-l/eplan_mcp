# Adding PDF Comments to the PDF File

You can open an EPLAN project that you have issued as a PDF file in Acrobat Reader and add PDF [comments](Glossary_o_kommentare.htm) in the sense of redlining. The sender must either send the PDF file from Acrobat for checking or release it for commenting.

Preconditions:

- You are a [Project redliner](redlining_k_projektkommentator.htm#Projektkommentator).
- You have Acrobat Reader 8.0 installed.
- You have received a PDF file from a [Project editor](redlining_k_projektkommentator.htm#Projektbearbeiter).

1. File > Open
2. In the subsequent dialog, select the PDF file that you wish to comment and click [Open].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The PDF file opens in Acrobat Reader.
3. Select the menu item View > Toolbars > Comment & Markup.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The toolbar is displayed.
4. To draw a comment in a PDF page, select a graphical marking tool from the toolbar and (e.g.) draw a rectangle.
5. To enter comment text into the comment, double-click the drawn comment.
6. Enter the comment text into the comments field.  
      
    ![](../Pictures/Gui/ALL/arrow.png) After importing into the EPLAN project the comment text can be edited in EPLAN.
7. To add response text to the comment text, select the menu item Options > Reply in the comment field.
8. Enter text into the reply field.  
      
    ![](../Pictures/Gui/ALL/arrow.png) After importing into the EPLAN project, the response text can be displayed in EPLAN but not edited.
9. To define a status for the PDF comments, select the menu item Options > Set Status in the comments field, and select a status.
10. To close the comments and reply fields, click the symbol in the upper-right corner of the comments field.  
       
     ![](../Pictures/Gui/ALL/arrow.png) When you move the cursor over the drawn comments, then the comments text and the number of replies are shown in a tooltip.
11. Select the menu item File > Save.
12. To send back the commented PDF file via e-mail, click Send comments in the toolbar.
13. Enter the e-mail address in the subsequent dialog and then click [Send].

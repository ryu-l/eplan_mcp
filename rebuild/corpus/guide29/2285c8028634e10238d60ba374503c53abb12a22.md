# Dialog Property arrangements

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have selected a model view. Edit > Properties. In the Item labeling field of the Model view dialog, you have clicked [...]. In the Property arrangement column, click a cell and then [...].

In this dialog you can specify the display [settings](Glossary_o_einstellungen.htm) for the different [properties](Glossary_o_eigenschaften.htm) of the item placed in the [layout space](Glossary_o_bauraum.htm). Individually placed properties can be docked with each other and made into a single block; when moving, this allows all the (desired) text to be moved at once and avoids overlapping of multi-line text with other text.

Overview of the main dialog elements:

Property arrangement:

In the drop-down list, different predefined assignment [configurations](Glossary_o_konfigurationen.htm) are offered for selection.

Select the desired property arrangement from the drop-down list; the properties selected in this configuration for display will then be listed in the field below the drop-down list. The settings of property arrangements only affect the placement and display of properties.

If you have selected a property, you can edit its display properties in the right side of the dialog.

List of placed properties:

This list shows the already placed properties for the item. If you have selected a property, you can edit its display properties in the right side of the dialog.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Add | Opens the Property selection dialog, in which you can select further properties and add them to the properties table. (Properties inserted in this manner are added to the bottom of the table.) |
| Delete | Removes selected properties from the list. This does not cause the values of the properties to be deleted. Properties with assigned values are automatically displayed in the table again the next time the dialog is opened. |
| Move up / Move down | Move the selected property up or down, if possible. Multiple selection is not possible.. |
| Dock / Undock | Docks or undocks the selected property, if possible. Multiple selection is not possible. |

Property / Assignment:

If you have selected a property, you can edit its display properties in the table in the right-hand section of the dialog. The hierarchy [levels](Glossary_o_etagen.htm) Format, Text box, Alignment box, Value / Unit and Position are available for this purpose. These can be opened by clicking the ![](../Pictures/Gui/ALL/all_plussign_as.png) symbol. Concerning the display properties, the settings described in the following section are available:

# P027007: More than one topology function available in the device <x>

### Cause

In the routing path network, the <x> device has been assigned more than one [topology](Glossary_o_topologie.htm) function with the same device tag. But each topology function may exist in the routing path network only once with the "Topology" representation type.

![](../Pictures/Gui/ALL/note.png)Notes:

1. The message is also output if several [routing points](Glossary_o_verlegepunkte.htm) or [routing paths](Glossary_o_strecken.htm) have been placed with the same device tag.
2. Terminal strip definitions are an exception. They may occur several times, and are not checked in case of multiple placement!

### Solution

1. Locate the multiple topology [functions](Glossary_o_funktionen.htm) in your routing path network using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Rename the multiple topology functions of the device, or delete them, so that only one topology function with a unique device tag remains.
3. Then start a new check run.

# Action: MfRemoveToolbarAction

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| ToolbarName | Name of the toolbar. |
| Silent | When this value is set to 1, no message is displayed if the toolbar does not exist. |

![](../Pictures/Gui/ALL/note.png)Note:

This action requires a [main window](Glossary_o_hauptfenster.htm).

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
MfRemoveToolbarAction 
/ToolbarName:"?" 
/Silent:No
```

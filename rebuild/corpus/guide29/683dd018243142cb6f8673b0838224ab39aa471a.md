# Dialog Outline properties - <Outline name> / Dialog Form properties (copper) - <Form name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Utilities > Master data > Outline (...) > New > [Save].
- Utilities > Master data > Outline (...) > Open. Select the Properties popup menu item on the outline in the Pages -<Project name> navigator dialog.
- Utilities > Master data > Form (copper) > New > [Save]
- Utilities > Master data > Form (copper) > Open. Select the Properties popup menu item on the [form](Glossary_o_verlauf.htm) (copper) in the Pages -<Project name> navigator dialog.

In this dialog, you specify the [properties](Glossary_o_eigenschaften.htm) for a generated or opened outline or a form (copper).

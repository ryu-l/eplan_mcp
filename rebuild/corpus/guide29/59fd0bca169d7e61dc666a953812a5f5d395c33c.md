# Inserting Macros from Macro Navigator Using Drag & Drop

You can now insert the window and [symbol macros](Glossary_o_symbolmakros.htm) of a macro project from the macro navigator to the open project pages of a different macro or schematic project or the same macro project using Drag & Drop.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

Drag & Drop from the macro navigator allows you to insert your finished, standardized [macros](Glossary_o_makros.htm) faster and more easily into other [projects](Glossary_o_projekte.htm). The tedious selection via the macro selection in the macro directories is no longer required. Instead you can easily use a macro from the navigator.

This action is possible both for macros with the type of usage "Defining" as well as for macros with the type of usage "Not specified". You can drag 3D macros using Drag & Drop into an opened [layout space](Glossary_o_bauraum.htm) in the same way. The selection of a different macro variant is not possible when inserting via Drag & Drop. You also cannot select multiple macros.

Alternatively you can also execute the action in the macro navigator via the new Insert macro popup menu item.

![](../Pictures/Gui/ALL/note.png)Note:

Please also note that when inserting via Drag & Drop or via the Insert macro popup menu item, the status of the macro in the macro project and not the saved status of the macro in the macro file is used. If you update a macro that was inserted this way, the status that was saved in the macro file is used.

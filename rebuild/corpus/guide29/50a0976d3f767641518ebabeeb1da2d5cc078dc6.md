# P004024: Connection point description is missing

### Cause

The connection point description is missing at a PLC connection point.

[PLC connection points](Glossary_o_sps_anschluesse.htm) with the "PLC connection point, internal, general" function definition are not checked before this check run since they are only used for the display of free [symbolic addresses](Glossary_o_symbolischeadressen.htm).

### Solution

1. In the Properties <...> dialog of the PLC connection point, enter the missing connection point description in the field by the same name.
2. Then start a new check run.

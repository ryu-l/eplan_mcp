# P001033: The manual saddle jumper cannot be generated. <x>

### Causes

If manual saddle jumpers cannot be generated, the following causes are possible that are displayed in the placeholder <x>:

#### 1. The saddle jumper information <y> could not be reported.

The property defined at the terminal Manual saddle jumpers (internal) or Manual saddle jumpers (external) does not have a valid value <y>. Possibly a character that cannot be reported was inserted or supplemented.

#### 2. No terminal exists at the jumper end.

The property defined at the terminal Manual saddle jumpers (internal) or Manual saddle jumpers (external) has a value that leads to a saddle jumper that is too long. EPLAN therefore does not find a terminal at the jumper end. Possibly the value for the jumper start and the increment was extended manually, without making a corresponding terminal available at the end of the saddle jumper. Or a last terminal that was [part](Glossary_o_artikel.htm) of an existing saddle jumper has been deleted.

#### 3. The terminal <y> does not have an internal saddle jumper connection point.

The Manual saddle jumpers (internal) property is defined at the terminal. According to this property the specified terminal should be jumpered. The generation of the saddle jumper is. however, not possible because the terminal does not dispose of an internal saddle jumper connection point. This situation arises, for example, when you change the function definition at a participating terminal of an existing manually generated internal saddle jumper so that it does not have an internal saddle jumper connection point.

#### 4. The terminal <y> does not have an external saddle jumper connection point.

The Manual saddle jumpers (external) property is defined at the terminal. According to this property the specified terminal should be jumpered. The generation of the saddle jumper is. however, not possible because the terminal does not dispose of an external saddle jumper connection point. This situation arises, for example, when you change the function definition at a participating terminal of an existing manually generated external saddle jumper so that it does not have an external saddle jumper connection point.

### Solution

Locate firs for the respective cause the relevant terminal in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.

All other procedures are described below with respect to the different message options.

#### Re 1.: The saddle jumper information <y> could not be reported.

Precondition:

You have located and highlighted the respective terminal in the schematic.

1. Select the Properties popup menu item.
2. Bring the first tab to the front in the [property dialog](Glossary_o_eigenschaftendialog.htm) of the terminal .
3. Delete the property Manual saddle jumpers (internal) or Manual saddle jumpers (external) from the property table.
4. Click [OK].
5. Select the menu item Project data > Terminal strips > Edit.
6. Mark the terminals that you want to jumper manually in the dialog Edit terminal strips.
7. in the toolbar click the button ![](../Pictures/Gui/ALL/terminalgui_createsaddlejumpint_as.png) (Generate manual saddle jumper (internal)) or the button ![](../Pictures/Gui/ALL/terminalgui_createsaddlejumpext_as.png) (Generate manual saddle jumper (external)).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The desired saddle jumper is generated.
8. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property Manual saddle jumpers (internal) or Manual saddle jumpers (external) is redefined and filled with the correct information at the terminal.
9. Then start a new check run.

#### Re 2.: No terminal exists at the jumper end.

Proceed as described in the section Re 1.: The saddle jumper information <y> could not be reported.

#### Re 3.: The terminal <y> does not have an internal saddle jumper connection point.

Precondition:

You have located and highlighted the respective terminal in the schematic.

1. Select the Properties popup menu item.
2. In the property dialog of the terminal, bring the Symbol / function data tab to the front.
3. In the Function data (logic) group box, click [...] next to the Definition field.
4. In the subsequent dialog select a terminal that disposes of a saddle jumper connection point as the function definition.
5. Click [OK].
6. Click the [Logic] button in the property dialog.
7. Assign the value "Internal" to one of the saddle jumper [connection points](Glossary_o_anschluesse.htm) at the Internal / External property.
8. Accept all the changes with [OK].
9. Start a new check run.

#### Re 4.: The terminal <y> does not have an external saddle jumper connection point.

Proceed as described in the section Re 3.: The terminal <y> does not have an internal saddle jumper connection point. However, assign the value "External" to one of the saddle jumper connection points at the Internal / External property.

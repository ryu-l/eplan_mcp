# P001030: Used distributed terminal connection point without connection point designation

### Cause

A distributed terminal connection that is not a saddle jumper connection point and is connected to a function has no connection point designation.

### Solution

1. Locate the distributed terminal in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the distributed terminal's [property dialog](Glossary_o_eigenschaftendialog.htm) and in the Terminal tab insert the missing connection point designation in the field of the same name.
3. Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

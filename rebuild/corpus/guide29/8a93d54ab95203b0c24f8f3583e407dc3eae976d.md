# P501008: The connection point pattern <x> entered at the part does not exist

### Cause

In the parts database to be checked a [part](Glossary_o_artikel.htm) was found where a connection point pattern was entered which EPLAN cannot find.

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective part is already marked in it.
2. Bring the Technical data tab to the front.
3. Click [...] next to the Connection point pattern field.
4. Select the required connection point pattern from the selection dialog opened.
5. Close the parts management, save the modified data, and carry out a parts synchronization.
6. Then start a new check run.

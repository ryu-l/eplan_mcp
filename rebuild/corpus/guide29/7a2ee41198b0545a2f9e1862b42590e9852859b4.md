# Tab Properties

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Page > Navigator. Select a project. Select the Properties popup menu item. Select the Properties tab.
- You have selected a project management database. You have loaded directories and [projects](Glossary_o_projekte.htm). Project > Management. Select a project. Select the Properties tab.

The current [project properties](Glossary_o_projekteigenschaften.htm) of the selected project are displayed in this tab.

Overview of the main dialog elements:

Category:

The view of the [properties](Glossary_o_eigenschaften.htm) in the Property name column is filtered according to the category set in this drop-down list. The view of the properties is also filtered, which you can select using ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the Property selection dialog.

Toolbar:

| Button | Meaning |
| --- | --- |
| (New) | Opens the Property selection dialog. Allows a property to be selected. |
| (Delete) | Deletes one or more selected properties. |

Property name:

The project properties of the selected project are displayed in this column.

Value:

The values of these project properties are displayed and can be edited in this column. To do this you must first use the [Edit] button to activate the edit mode within the project management.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# Dialog Export manufacturing data / Output labeling

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Manufacturing data > Export / labeling.

In this dialog, you can specify the range and order in which manufacturing data and labeling data are output to a file.

Overview of the main dialog elements:

Settings:

This drop-drown list shows all the [user-defined](Glossary_o_benutzerdefiniert.htm) and pre-defined export / labeling [schemes](Glossary_o_schemata.htm). Click [...] to edit or [create](Glossary_o_erstellen.htm) a scheme.

Report type:

A scheme of the exported manufacturing data / labeling is always generated in conjunction with a report type. In this field, the report type is displayed that you selected for the current scheme.

Note that the [part](Glossary_o_artikel.htm) [assemblies](Glossary_o_baugruppen.htm) (for example the report type "Summarized parts list") depend on the current selection. This means:

- If terminals are selected, terminal parts are output.
- If terminal strips are selected, all the terminal and terminal strip parts are output.
- If terminal strips and individual terminals are selected, all the terminal and terminal strip parts are output. However, terminal parts are only evaluated once.

The same applies to cables and [connections](Glossary_o_verbindungen.htm).

All the parts are output when the corresponding setting is set (for example the [settings](Glossary_o_einstellungen.htm) Terminal parts, Cable conductor parts, etc.).

Language:

Select the language from the drop-down list in which the export / labeling file should be output. All languages are available which you have specified as [translation languages](Glossary_o_uebersetzungssprachen.htm) in the project-specific translation settings.

- All displayed languages: Allows you to output the EPLAN data in multilingual [form](Glossary_o_verlauf.htm). The data are output in all the languages you specified as displayed languages in the project-specific translation settings.
- Language: Allows you to output the EPLAN data in the selected language. If you wish to output the data to an external Excel file, you can control the sheet names in the Excel file here. The sheet name must be analogous to the language code. If the file does not contain any sheets with a suitable language code, then a search is done for a sheet matching the [dialog language](Glossary_o_dialogsprache.htm) or the alternative language. If a suitable sheet is still not found, then the first sheet from the template is used.

  ![](../Pictures/Gui/ALL/example.png) [![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

  As a template, you have selected an Excel file containing 5 sheets with the sheet names en\_US, de\_DE, fr\_FR, ru\_RU and zh\_CN.

  In the Language field you have selected the language en\_US.

  The EPLAN data is output to the en\_US Excel sheet.

Target file:

This field shows the file path to the export / labeling file.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).

Repetitions per label:

The number in this field specifies how many times each label is repeated in the export / labeling file.

Repetitions of total output:

The number in this field specifies how many times the entire output is repeated in the export / labeling file.

Output type:

In this group box, you can specify whether an application is started after the output.

- Export: If this option is selected, the data are output and an external application is not started.
- Export and start application: If this option is selected, the data are output and an external application, for example Notepad, is started.

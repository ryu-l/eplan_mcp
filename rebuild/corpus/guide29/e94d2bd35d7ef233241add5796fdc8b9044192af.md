# Model Views

Model views are standardized views and views of equipped [mounting surfaces](Glossary_o_montageflaechen.htm). They are used for display purposes and for creating drawings. Additional information such as dimensioning, texts, etc. for enclosure production (enclosure equipment) can be drawn in the [model views](Glossary_o_modell_ansichten.htm) using standard platform [functions](Glossary_o_funktionen.htm).

A model view is defined by specifying two points. When you [create](Glossary_o_erstellen.htm) a standard view, the entire content of the 3D view is displayed scaled to fit in the model view. In the model view of an equipped mounting surface, only the equipped mounting surface and the [items](Glossary_o_bauteile.htm) placed on it is scaled to fit.

A model view can be inserted in any page type.

### Copying and pasting model views

![](../Pictures/Gui/ALL/note.png)Note:

Copying a model view is possible, it is, however, only sensible within a project. When pasting into another project, the internal references between [layout space](Glossary_o_bauraum.htm) and model view will be lost; thus, only a copy of the graphics is generated. A reaction to changes in the layout space is then no more possible in the copy of the model view.

### Alignment options

A model view can be aligned orthogonally or isometrically in the [property dialog](Glossary_o_eigenschaftendialog.htm):

#### Orthogonal views

The orthogonal views provide the options Top (1), Bottom (2), Left (3), Right (4), Front (5) and Rear (6).  
![](../Pictures/Visualisation/ALL/gededit3dgui_orthographicviews.png)

#### Isometric views

The [isometric views](Glossary_o_isometrische_ansichten.htm), in which three-dimensional representations are displayed in two dimensions, contain the following options: SW isometric (1), SE isometric (2), NE isometric (3), and NW isometric (4).  
![](../Pictures/Visualisation/ALL/gededit3dgui_isometricviews.png)

The [designations](Glossary_o_bezeichnungen.htm) of the four isometric viewpoints (southeast, southwest, northeast, northwest) indicate the direction from which the model is viewed within a compass face projected onto the model's base area. The Y axis (green) is set to the north. Additionally, the viewpoint is rotated 60° downwards.

### Display of Sloping Surfaces in Model View

Viewpoints in model views are usually based on the coordinates of the layout space. A sloping surface, such as the front of a control panel, is not visible in its real dimensions in the model view since, by its position, it is displayed twisted from its orthogonal view and is thus shortened. Thus, dimensionings do not show their real lengths.

To be able to correctly dimension sloping surfaces in model views, the Model view: Apply viewpoint to mounting surface property is available. If this property is activated in the View tab of the Model view dialog, the view of an item in a sloping position is aligned at its mounting surface. This way, even an item with sloping alignment will be depicted in the model view correctly and orthogonally. The dimensioning generated on it will then correspond to the real values.

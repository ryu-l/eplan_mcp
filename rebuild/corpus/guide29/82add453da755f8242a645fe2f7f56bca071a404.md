# Exchanging the Settings

You can pass project-specific settings to other [projects](Glossary_o_projekte.htm). To do this, you must save the source project [settings](Glossary_o_einstellungen.htm), together with the project, as a template and then [create](Glossary_o_erstellen.htm) the new project from the template.

### Save the project as a template

Preconditions:

- You have opened the project management: Project > Management
- In the tree structure of project management, there is an imported directory with at least one project.

1. Select your source project in the Project management dialog.
2. Select [Extras] > Create project template.
3. Select the storage location and the name of the project template.
4. Click [Save].  
     
   ![](../Pictures/Gui/ALL/arrow.png) A project template is created.

### Create projects from templates

1. Select the menu item Project > New.
2. Assign a name to the new project in the Create project dialog.
3. Click [...] next to the Template field.
4. Select the desired template in the Select project template / basic project dialog and click [Open].
5. Select a storage location for the project.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) A project is created on the basis of the project template.

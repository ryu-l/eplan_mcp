# Configuring NC Machine

Representative for all NC interfaces, the configuration of a machine for the "Rittal - Perforex BC / Secarex" format is described here. The configuration of the machines of the other interfaces is done in the same manner, but differs in terms of the values to be entered in the [settings](Glossary_o_einstellungen.htm) dialog.

1. Select the menu [items](Glossary_o_bauteile.htm) Options > Settings > Company > Machining > Export Rittal - Perforex BC / Secarex.
2. In the dialog Settings: Export Rittal - Perforex BC / Secarex select the desired machine. Modify the settings on the tabs as needed, or [generate](Glossary_o_erzeugen.htm) a new machine definition with the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button.
3. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The set machine data is available at the time of the NC export in the export dialog under the associated machine name.

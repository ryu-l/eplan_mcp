# P020036: The project structure element '<x>' was changed from '<y>' to '<z>'.

### Description

You have run a project comparison, checking the structure of the test project (incoming project) against that of the comparison project and differences were found.

This message occurs when a difference in one of the extended [project structure](Glossary_o_projektstruktur.htm) elements was found in the test project. Extended project structure elements include all elements you have defined in the Extended project structures dialog, for example the separators. (Select the project in the page navigator, select Popup menu > Project > Properties, open the Structure tab and click [Other].) The extended project structure element (<x>), the previous setting (<y>) and the new setting (<z>) are output.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

# Modifying the Size of Locked Areas, Wiring Cut-outs and Routing Ranges

Previously size modifications for [restricted drilling areas](Glossary_o_bohrsperrflaechen.htm), restricted [placing](Glossary_o_auflegen.htm) areas, [wiring cut-outs](Glossary_o_verdrahtungsdurchbrueche.htm) and [routing ranges](Glossary_o_verlegebereiche.htm) were only possibly by deleting and re-placement. Now the size can be modified in at the placed [objects](Glossary_o_objekte.htm) as follows:

- Changing the format properties in the property dialog: Enter changed values for the Width and Height fields on the tab of the Format [property dialog](Glossary_o_eigenschaftendialog.htm). The change is made referenced to the bottom left-hand corner.
- Graphical change - for locked areas and wiring cut-outs: Mark the object. Similar to 2D rectangles, direction arrows appear at the corners and in the middle of the sideline, in whose displayed direction you can pull apart and pull together the object. While moving along the direction arrow, handles that you can use for exact positioning are displayed at neighboring 3D objects.
- Graphical change - only for routing ranges: Select the menu [items](Glossary_o_bauteile.htm) Edit > Graphic > Change length and click the object to be changed. A 3D coordinate system appears at the four corner points of the front surface when you touch them with the cursor. Select the dimension to be changed by clicking the desired axis. To this purpose the selected axis is displayed in green.   
  After specifying the change of direction pull the 3D object in the selected direction. There are different possibilities to specify the new size value, for example mouse click, use of snap points, projection points or [grid](Glossary_o_raster.htm) points.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

You can now directly perform size modifications for locked areas, [wiring](Glossary_o_verdrahtungen.htm) [cut-outs](Glossary_o_durchbrueche.htm) and routing ranges at the placed objects. The workaround through the deletion and re-placement is no longer required.

# EPLAN Fluid: PLC Functions

### PLC boxes and connection points

In [fluid power](Glossary_o_fluidtechnik.htm) it can be required to configure components with PLC functionalities. EPLAN Fluid supports this working method and makes [function definitions](Glossary_o_funktionsdefinitionen.htm) available with which you can realize the [PLC boxes](Glossary_o_sps_kaesten.htm) and [PLC connection points](Glossary_o_sps_anschluesse.htm) as fluid power [functions](Glossary_o_funktionen.htm).

If you insert a PLC box or connection point in the schematic, the program checks which page type this happens on. If it is a "Fluid power schematic"-type page, the corresponding function definition is automatically configured, and you insert a "PLC box (fluid)" or "PLC connection point (fluid)".

PLC functions for fluid power behave like the corresponding functions for electrical engineering.

- The fluid-power-specific PLC functions are displayed in the PLC dialogs and in the [reports](Glossary_o_auswertungen.htm) and are taken into consideration during the PLC [data exchange](Glossary_o_datenaustausch.htm).
- The corresponding [PLC addresses](Glossary_o_sps_adressen.htm) are displayed in the assignment list and can be edited there.
- The supplied [filters](Glossary_o_filter.htm) in the PLC navigator consider both the electrical- as well as the fluid-power-specific PLC functions.
- During the execution of [check runs](Glossary_o_prueflaeufe.htm) of the "PLC / bus" class the fluid-power-specific PLC functions are taken into consideration.

#### Numbering

The numbering of fluid-power-specific PLC functions is effected according to the [settings](Glossary_o_einstellungen.htm) for PLC [devices](Glossary_o_betriebsmittel.htm) and can therefore deviate from the numbering of the fluid devices. This ensures that PLC components are numbered uniformly in mixed [projects](Glossary_o_projekte.htm) that contain schematic pages of both fluid power and the electrical engineering.

#### Adoption of device tags

With regard to the DT adoption the fluid-power-specific PLC functions behave like all other fluid power devices. If no [DT adoption for fluid devices](prjmanagementgui_r_vererbung.htm#BMKUebernahmeFluid) is allowed, the fluid-power-specific PLC functions adopt neither a DT nor a plug designation. In this case you have to enter the DT and the plug designation individually at all the PLC [connection points](Glossary_o_anschluesse.htm). If required, use the editing in a table function to this purpose.

# P007006: Function without connection point designation

### Cause

There is at least one connection name missing from the function placed in the schematic.

### Solution

Double-click the [component](Glossary_o_schaltzeichen.htm) and enter the missing different connection point designation(s) in the Properties <...> dialog.

Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

Connection points without connection point designation are not reported if the connection point type "Internal", "Direct connection point" or "Saddle jumper" is assigned to them.

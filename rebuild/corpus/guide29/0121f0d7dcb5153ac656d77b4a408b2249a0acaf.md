# Structure Segments in the P&I Diagram

You can visualize the structures in the [P&I diagram](Glossary_o_ri_fliessbild.htm) by [placing](Glossary_o_auflegen.htm) [structure segments](Glossary_o_struktursegmente.htm) as [structure boxes](Glossary_o_strukturkaesten.htm). You then see immediately which apparatuses and machines drawn in the P&I diagram belong to which structures.

To this purpose you drag & drop a structure segment from the pre-planning navigator onto a P&I diagram. In the process a reference is generated to the structure segment and this reference is placed as a structure box on the P&I diagram. The [structure identifiers](Glossary_o_strukturkennzeichen.htm) of the structure segment are transferred to the structure box. The associated structure box is displayed in the pre-planning navigator below the referenced structure segment (icon ![](../Pictures/Gui/ALL/navigatorgui_structurebox_as.png)).

The following is possible:

- The [properties](Glossary_o_eigenschaften.htm) of the referenced structure segment (and of any superior structure [segments](Glossary_o_segmente.htm)) can be displayed at the structure box on the P&I diagram page. To this purpose the source [objects](Glossary_o_objekte.htm) "Segment" and "Structure segment hierarchical" are available in the dialog Property selection.
- A structure segment can be placed several times in the P&I diagram. Depending on the layout of the apparatuses and machines drawn in the P&I diagram that belong to the same structure you can either draw a structure box around all the objects or several structure boxes with the same DT around the individual objects. As usual a structure box can also be drawn as a polygon in the process.
- You can jump from the structure box displayed in the pre-planning navigator to its placement on the P&I diagram page via the popup menu Go to (graphic).
- Modified structure identifiers at the structure segments in the pre-planning navigator can also be transferred to the placed structure boxes via the popup menu item Update detailed planning . To this purpose you activate the check box Update device tags and symbolic addresses in the subsequent dialog.

### Displaying the visible designation at PCT loops

The property Designation (visible) ([ID](Glossary_o_id.htm) 44065) allows you to have a "reduced" designation displayed at the [PCT loops](Glossary_o_plt_stellen.htm) / [PCT loop functions](Glossary_o_plt_stellenfunktionen.htm) which are placed in a structure box. In this property the designation of the superior structure box is abbreviated, meaning that the partial structure in which the PCT loop / PCT loop function is located is displayed.

If a PCT loop / PCT loop function belongs to a different structure, a "reduced" designation is displayed. In this case a ">" is displayed before the designation.

The Designation (full) (ID 44009) property shows the complete designation of the PCT loop / PCT loop function including the structure identifiers of all the higher-level segments.

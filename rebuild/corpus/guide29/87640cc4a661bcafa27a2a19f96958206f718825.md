# Defined Working Sections

Projects can be divided into defined working sections. This creates more transparency in project editing, and facilitates the simultaneous editing of [projects](Glossary_o_projekte.htm) by several users. The criteria for the division are saved to filter [schemes](Glossary_o_schemata.htm).

For projects structured by [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm), the division is realized on the basis of [structure identifiers](Glossary_o_strukturkennzeichen.htm) that exist in the project for the identifier [blocks](Glossary_o_bloecke.htm). You can filter by any combinations of these structure identifiers. In addition you can filter pages, layout spaces, [functions](Glossary_o_funktionen.htm), and [connections](Glossary_o_verbindungen.htm) for certain [trades](Glossary_o_gewerke.htm).

Sequentially numbered projects can be divided only into trades.

The following is possible:

- Using the selection of a scheme, you can specify the defined working section to work in.
- When you use the [rights management](Glossary_o_rechteverwaltung.htm) of EPLAN, the defined working sections can be assigned centrally by a project administrator. Without usage of rights management each individual user can determine him-/herself in which defined working section he/she wants to work.
- The [project data](Glossary_o_projektdaten.htm) [navigators](Glossary_o_navigatoren.htm) will display only the pages, [devices](Glossary_o_betriebsmittel.htm), etc. corresponding to the criteria determined in the scheme. This makes the display of large projects more transparent and increases the editing speed.
- Editing can be extended temporarily to the entire project.

# Editing Page Properties

You can view and edit the [properties](Glossary_o_eigenschaften.htm) of pages in the Pages - <Project Name> navigator dialog.

Precondition:

You have opened a project.

1. Select the desired page in the tree or list view. Multiple selection is possible.
2. Select the menu item Edit > Properties.
3. Use the [Page properties](pagebrowsergui_d_seiteneigenschaften.htm) dialog to change the desired properties.
4. Click [OK].

![](../Pictures/Gui/ALL/note.png)Note:

Changing identifying page properties, such as the higher-level function, also renames all the DTs for the same [higher-level function](Glossary_o_anlage.htm) on the page.

![](../Pictures/Gui/ALL/info.png)Tip:

Some fields, such as the Page description and Drawing number field can be directly edited in the table in the page navigator list view.

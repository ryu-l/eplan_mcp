# Field Displayed DT

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened the Properties <...> dialog. The first tab is in the foreground.

You specify the displayed DT of a [component](Glossary_o_schaltzeichen.htm) in this field.

Overview of the main dialog elements:

Popup menu / Buttons:

| Menu item | Meaning |
| --- | --- |
| Find new DT | Generates a new DT with the next free counter. |
| Identifier subclasses | Opens the Select identifier subclasses dialog. You can select an identifier subclass there. (The identifier subclasses are stored in the project [settings](Glossary_o_einstellungen.htm) under "Project name" > Devices > Numbering (online).) Confirm your selection and a new DT will be generated. If required, any existing identifiers will be discarded. |
| Button | Meaning |
| [...] | Opens the DT selection dialog. Here, all of the device tags in the project that match the respective function are displayed. You can use an existing function, accept a DT, or use [Next] to [create](Glossary_o_erstellen.htm) a new DT. |
| (Delete) | Deletes the entry in the Displayed DT field. |

![](../Pictures/Gui/ALL/note.png)Note:

If you have activated the Properties (global) editing mode, then you cannot edit the displayed DT for the individual [functions](Glossary_o_funktionen.htm) of a device. In this case, the field is grayed out. However, in the <Function category> (Device) tab you can modify the Full DT field for the entire device. The displayed DT is automatically determined from this.

![](../Pictures/Gui/ALL/info.png)Tip:

You can switch to the editing mode by selecting Options > Properties (global). When you double-click a function, the [property dialog](Glossary_o_eigenschaftendialog.htm) is opened in the editing mode defined for this position.

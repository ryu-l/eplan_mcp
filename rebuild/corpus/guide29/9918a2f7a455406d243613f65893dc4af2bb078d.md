# Dialog Generate revision

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Revision control > Change tracking > Generate revision.

In this dialog, provide a name and description for a new revision.

Overview of the main dialog elements:

Revision name:

Provide a name for the revision here. EPLAN automatically suggests a revision name based on the existing project name and the number of [revisions](Glossary_o_revisionen.htm) already made.  
Use [...] to open the [Select revision](revisionlogmgtgui_d_revauswaehlen.htm) dialog. It is there that you can select a revision name that is already in use, and then change it.

Comment:

You can enter an optional comment text in this field.

User:

The user who created the revision is automatically entered in this field. The entry cannot be modified.

Defined working section:

This field displays the currently active defined working section. The entry cannot be modified.

Date:

The date on which the revision was generated is automatically entered in this field. The entry cannot be modified.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

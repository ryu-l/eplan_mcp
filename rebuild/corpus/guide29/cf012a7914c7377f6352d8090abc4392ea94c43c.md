# Specifying Settings for Connection Numbering

Settings for [connection numbering](Glossary_o_verbindungsnummerierung.htm) are saved in [schemes](Glossary_o_schemata.htm). This way you can access previously specified [settings](Glossary_o_einstellungen.htm) at any time and even change them, if necessary.

Precondition:

You have opened a project.

1. Options > Settings > Projects > "Project name" > Connections > Connection numbering
2. Select a [user-defined](Glossary_o_benutzerdefiniert.htm) scheme from the drop-down list, or [create](Glossary_o_erstellen.htm) a new scheme via ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the dialog Settings: Connection numbering.
3. In the [Filter](wirenumberinggui_r_filter.htm) tab select the check boxes for the [trades](Glossary_o_gewerke.htm) and the [function definitions](Glossary_o_funktionsdefinitionen.htm) you want to number.
4. In the [Placement](wirenumberinggui_r_platzierung.htm) tab select where and how often you want to place the [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) on the [connections](Glossary_o_verbindungen.htm).
5. In the [Designation](wirenumberinggui_r_bezeichnung.htm) tab, define the format groups that are to be formatted together.
6. In the [Display](wirenumberinggui_r_anzeige.htm) tab specify formatting for [connection designations](Glossary_o_verbindungsbezeichnungen.htm) generated on the connection definition point. Among these formatting options are, for example, horizontal and vertical increments of the connection designation from the connection line, as well as text color, size, etc.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The scheme is now set up and will be used when you are numbering connections.

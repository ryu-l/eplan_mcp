# Outputting Reports in Other Projects

The reporting of so-called "source [project data](Glossary_o_projektdaten.htm)" takes place in a project that is currently open, the "report project". In the Templates tab on the report project, you state the source project from where the data come.   
For any subsequent [reports](Glossary_o_auswertungen.htm), the source project is opened for reading in the background for the duration of the report, the data is read and the reports are generated in the report project.

![](../Pictures/Gui/ALL/note.png)Notes:

- When generating reports the [master data](Glossary_o_stammdaten.htm) ([forms](Glossary_o_formulare.htm), [symbol libraries](Glossary_o_symbolbibliotheken.htm) etc.) and [settings](Glossary_o_einstellungen.htm) for the project currently open - i.e. the report project - are always used in EPLAN.
- The [connections](Glossary_o_verbindungen.htm) are updated automatically before a connection list is generated in a "normal" project. When the connection list is output in the report project, the connections are not updated automatically! If the current connection list of a source project is to be output in a report project, the connections must first be updated in the relevant source project.

Preconditions:

- You have opened and selected a project.
- You have assigned a [form](Glossary_o_verlauf.htm) to the desired report type.
- You have specified all the desired settings in the dialog Settings: Output to pages.

### [ClosedCreate source project in new report template](javascript:void(0);)

1. Select the following menu [items](Glossary_o_bauteile.htm): Utilities > Reports > Generate
2. In the Reports - <Project name> dialog, click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
3. Select the output format "Page" from the Output format field of the Select report dialog.
4. Click [...] next to the Source project field.
5. So select another project as the source project, select the project and click on [Open].
6. Select a report type in the Select report dialog and click [OK].
7. Click [OK] in the Settings - <Report type> dialog.
8. Enter a start page in the subsequent dialog and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The report is generated.

### [ClosedCreate source project for individual templates in existing report template](javascript:void(0);)

1. In the Reports - <Project name> dialog, select the Templates tab.
2. In the hierarchical tree structure, branch to the templates to which you want to assign a source project.
3. In the right-hand dialog area, click [...] in the Value column of the Source project property,
4. Select the project that is to be assigned as the source project and click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project is written into the Value column of the Source project property and assigned to the templates.

### [ClosedCreate source project for entire project in existing report template](javascript:void(0);)

1. In the Reports - <Project name> dialog, select the Templates tab.
2. Select the project for which a source project is to be determined and select the Source project > Select source project popup menu items.
3. Select the project that is to be assigned as the source project and click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project is written into the Value column of the Source project property for all templates and assigned to them.

### [ClosedRemove entered source project](javascript:void(0);)

1. In the Reports - <Project name> dialog, select the Templates tab.
2. In the tree of the Templates tab, select a certain tree structure level (a project name, a report type such as "Parts list", etc.), and select the Source project > Remove entered source project popup menu items.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The project is removed from the Value column of the Source project property for all templates of the selected tree structure level.

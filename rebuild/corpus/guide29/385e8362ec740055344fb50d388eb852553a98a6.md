# P024018: Connection of the representation type 'Function overview (fluid power)' has no correspondence in the schematic

### Cause

There is a connection on the page of the "Function overview ([fluid power](Glossary_o_fluidtechnik.htm))" type that has the representation type "Function overview (fluid power)". This connection has no corresponding connection of the representation type "Multi-line" on the associated multi-line schematic page.

### Solution

1. Starting from the Message management dialog use the Go to (graphic) functionality to locate the connection point of the function that is the source of the connection on the page of the "Function overview (fluid power)" type.
2. Track the connection to the connection point of the function that is the target of the connection.
3. Switch to the associated multi-line fluid power schematic page and check whether a corresponding connection of the "Multi-line" representation type exists.
4. If this connection is missing on the multi-line fluid power schematic page, [create](Glossary_o_erstellen.htm) it. In the process ensure that the [connection point designations](Glossary_o_anschlussbezeichnungen.htm) at the [connections](Glossary_o_verbindungen.htm) of the source and / or the target agree both in the fluid power schematic as well as the function overview.   
   If the connection in the fluid power schematic exists, check and / or correct the connection point [designations](Glossary_o_bezeichnungen.htm) at the source and / or the target in the function overview.
5. Then start a new check run.

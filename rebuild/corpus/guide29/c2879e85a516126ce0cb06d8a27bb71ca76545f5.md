# Action: XPlaUpdateDetailAction

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| PROJECTNAME | Project name with complete file path. |
| UpdateMacros | 1: The placements of the [macros](Glossary_o_makros.htm) entered at the marked [planning objects](Glossary_o_planungsobjekte.htm) / [PCT loops](Glossary_o_plt_stellen.htm) are deleted and these macros are placed again. |
| UpdateIdentifier | 1: The [devices](Glossary_o_betriebsmittel.htm) tags of [functions](Glossary_o_funktionen.htm) placed in the detailed planning, the [structure identifiers](Glossary_o_strukturkennzeichen.htm) and the [symbolic addresses](Glossary_o_symbolischeadressen.htm) are updated. |
| UpdatePlaceholder | 1: The modified data from the pre-planning is transferred to the [placeholder objects](Glossary_o_platzhalterobjekte.htm) placed in the detailed planning. |
| UpdatePipedata | 1: The piping data is transferred from the piping planning [objects](Glossary_o_objekte.htm) to the associated [pipings](Glossary_o_rohrleitungen.htm) in the [P&I diagram](Glossary_o_ri_fliessbild.htm). In the process the pipe class, the associated [properties](Glossary_o_eigenschaften.htm) and the substance are transferred to the placed piping definition points and [connections](Glossary_o_verbindungen.htm). Only the pipe class and the associated properties are transferred at the functions in the pipings. |

# P001026: Unconnected distributed terminals with same designation

### Cause

The schematic contains [distributed terminals](Glossary_o_teilklemmen.htm) that are not connected with each other although they have the same designation. The Connect associated distributed terminals automatically project-specific setting may not be activated.

### Solution

1. Select Options > Settings, and in the tree view of the Settings dialog select Projects > "Project name" > Devices.
2. Click on the setting area Terminals (distributed terminals), and activate the Connect associated distributed terminals automatically check box.
3. Click [OK] in the dialog.
4. Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

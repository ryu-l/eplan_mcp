# Dialog Manual selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Reports > Generate. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New). In the Select report dialog, select a function-related [report type](formgeneratorgui_k_auswertungstypen.htm#I_Funktionsbezogene). Select the Manual selection check box. Click [OK].

In this dialog you select the [devices](Glossary_o_betriebsmittel.htm), parts, or [symbol libraries](Glossary_o_symbolbibliotheken.htm) for which a report is to be generated.

Overview of the main dialog elements:

Available:

This field shows all devices, parts, or symbol libraries for which the selected report type can [generate](Glossary_o_erzeugen.htm) a report. The entries displayed depend on the selected report type. To define which devices, parts, or symbol libraries are to be included in the report, select one or more entries and then click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).

Selected:

A report will be generated for all entries in this field.

Category:

Select a category from this list to reduce the [properties](Glossary_o_eigenschaften.htm) view in the Property name / Value field.

Property name / Value:

Shows the properties and values of the devices or symbol libraries selected in the Available field.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

[Sort]:

If you click this button, the devices in the Selected field will be sorted alphanumerically.

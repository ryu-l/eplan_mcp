# P001025: Connection point designation at a jumper connection

### Cause

A distributed terminal connection point, which is a saddle jumper connection point and to which a saddle jumper or an internal jumper is connected, bears a connection point designation.

### Solution

1. Locate the relevant terminals in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Delete the connection point designation on the relevant distributed terminal connection point.
3. Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

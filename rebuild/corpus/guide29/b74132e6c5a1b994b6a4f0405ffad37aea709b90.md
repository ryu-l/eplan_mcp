# Dialog Wire fabrication: < Machine>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Wire fabrication > "Machine"
- Utilities > Manufacturing data > Wire fabrication > "Machine"

In this dialog, you define the [settings](Glossary_o_einstellungen.htm) for the export of the [wire fabrication](Glossary_o_drahtkonfektionierung.htm) data.

Overview of the main dialog elements:

Scheme:

The scope of delivery contains the machine definition with the name of the manufacturer. If you have generated a different machine as a scheme, you can select and edit other machine definitions from the drop-down list. You can use [...] to open the Settings: Wire fabrication dialog, where you can modify an existing scheme or [create](Glossary_o_erstellen.htm) a new scheme.

Language:

If the user does not enter text for the routing direction, an internal text is output that depends on the [dialog language](Glossary_o_dialogsprache.htm). If several dialog languages are installed, you can use the drop-down list to select the output language.

File path:

Select the directory where the export files are to be saved.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).

File name:

Here, you can enter the name of the file to be generated or select it via [...] in the Save as dialog. The file name extension is derived from the machine format selected. If through the export several files are to be generated with different file name extensions, the name entered here will apply to all files.

Some file names and / or file name extensions are set by the manufacturer. In such a case, you can set only the file path.

Export manufactured wirings again:

With this check box you can choose whether only new [connections](Glossary_o_verbindungen.htm) are to be output or also connections already manufactured. Deleted connections are never exported via this dialog.

Apply to entire project:

If you activate this check box, all connections in the project are exported, and the settings of the Export manufactured wirings again check box will be taken into account.

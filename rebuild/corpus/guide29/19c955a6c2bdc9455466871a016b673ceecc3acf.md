# Routing Pipings Freely

Pipings that were designed as multi-line [connections](Glossary_o_verbindungen.htm) between [fluid power](Glossary_o_fluidtechnik.htm) [items](Glossary_o_bauteile.htm) or screw connections on a fluid power schematic page can be routed freely in the [layout space](Glossary_o_bauraum.htm).

Precondition:

You have opened a project. The project contains [pipings to be routed freely in the fluid planning](ftechnic_h_paketedefinieren.htm). A layout space is open.

1. Select the Project data > Connections > Free routing (layout space) menu items or the popup menu item Free routing (layout space) in the connections navigator.
2. Enter the two corner points of a rectangle that comprises the [part placements](Glossary_o_artikelplatzierungen.htm) and connections to be routed.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The curve for the [form](Glossary_o_verlauf.htm) of the routing connection is calculated.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The [routing connections](Glossary_o_verlegeverbindungen.htm) are generated and assigned the specific [properties](Glossary_o_eigenschaften.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The routing connections are displayed as pipes in the 3D representation.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The following figure shows a model with a freely routed piping.

![](../Pictures/Visualisation/ALL/piping_freeroutedpipes_as.png)

3. To modify the form of the freely routed connection, select the menu items Edit > Graphic > Change bending positions, Edit > Graphic > New bending position and Edit > Graphic > Delete bending position.

# Importing / Exporting Symbol Libraries

Precondition:

You have opened a project.

### [ClosedImport symbol libraries](javascript:void(0);)

1. Select the following menu [items](Glossary_o_bauteile.htm): Utilities > Master data > Symbol library > Import
2. In the Import symbol library dialog select the desired symbol library (\*.esl) from the list. Multiple selection is not possible.
3. Click [Open].
4. In the Create symbol library dialog select a drive and a directory where you would like to save the imported symbol library from the Save in drop-down list.
5. Overwrite the file name if you would like to.
6. Click [Save].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The symbol library is imported and can now be edited in the current project.

![](../Pictures/Gui/ALL/info.png)Tip:

You can import [symbol libraries](Glossary_o_symbolbibliotheken.htm) using Drag & Drop by dragging the selected symbol library from Windows Explorer and dropping it into the Pages - <Project name> navigator dialog of your project.

### [ClosedExport symbol libraries](javascript:void(0);)

1. Select the following menu items: Utilities > Master data > Symbol library > Export
2. In the Export symbol library dialog select the symbol library (\*.esl) to be exported from the list. Multiple selection is not possible.
3. Click [Open].
4. In the Create export file dialog select a drive and a directory where you would like to save the exported symbol library from the Save in drop-down list.
5. Overwrite the file name if you would like to.
6. Click [Save].  
     
   ![](../Pictures/Gui/ALL/arrow.png) An export file with the name specified is generated in the designated drive and directory.

# Action: UnregisterScript

|  |  |
| --- | --- |
| **Parameters** | **Description** |
| ScriptFile | File name of the script with complete file path. Two types of script can be used: C# (\*.cs) and VB.NET (\*.vb). |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

```
UnregisterScript 
/ScriptFile:"C:\myScript.vb"
```

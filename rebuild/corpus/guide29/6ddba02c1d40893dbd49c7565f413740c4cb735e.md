# AutoCAD Version for DXF Export

For the NC [DXF](Glossary_o_dxf.htm) and copper DXF export of manufacturing data for machining old AutoCAD versions that are no longer supported have been removed in the [settings](Glossary_o_einstellungen.htm). The following versions are now available in the drop-down list for the format selection in the AutoCAD version field:

- AutoCAD 2013/2014/2015/2016/2017
- AutoCAD 2018/2019.

![](../Pictures/Gui/ALL/note.png)Note:

The DXF export of manufacturing data is licensed via two optional fee-based [extension modules](Glossary_o_erweiterungsmodule.htm). You can find specifications on this in the current performance description for EPLAN Pro Panel.

# Editing in Table

Using table editing, different [objects](Glossary_o_objekte.htm) on different project pages can be edited together in a single dialog. The following is possible:

- The DT of the selected [devices](Glossary_o_betriebsmittel.htm) are shown in the convenient [form](Glossary_o_verlauf.htm) of a table and can be edited in [blocks](Glossary_o_bloecke.htm), e.g. renamed or numbered.
- Device tags can be subdivided into columns whose numbers and names you can determine yourself. In this way, for instance, structure fields can be edited in [fluid power](Glossary_o_fluidtechnik.htm) systems.
- The [properties](Glossary_o_eigenschaften.htm) of [functions](Glossary_o_funktionen.htm), [connections](Glossary_o_verbindungen.htm), [macros](Glossary_o_makros.htm), [interruption points](Glossary_o_abbruchstellen.htm), [potentials](Glossary_o_potenziale.htm), [pipings](Glossary_o_rohrleitungen.htm) and [segments](Glossary_o_segmente.htm) from the pre-planning are displayed in the form of a table and can be edited in a table. Separate tabs are only displayed for these different objects when the selection contains more than one object type.
- The data of the objects can be copied into Excel with copy and paste, edited there, and then written back into EPLAN.

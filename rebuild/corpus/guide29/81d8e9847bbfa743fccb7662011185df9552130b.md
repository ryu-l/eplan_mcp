# Configuring Wire Fabrication Machine

Representative for all [wire fabrication](Glossary_o_drahtkonfektionierung.htm) interfaces, here the configuration of a machine for the "General [wires](Glossary_o_draehte.htm) parts list" format is described. The configuration of the machines of the other interfaces is done in the same manner, but differs in terms of the values to be entered in the [settings](Glossary_o_einstellungen.htm) dialog.

1. Select the Options > Settings > Company > Wire fabrication > General wires parts list menu [items](Glossary_o_bauteile.htm).
2. In the Settings: General wires parts list dialog, select the scheme of the required machine.
3. Modify the settings on the tabs as needed, or [generate](Glossary_o_erzeugen.htm) a new machine definition with the ![](../Pictures/Gui/ALL/all_new_as.png) (New) button.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The set machine data is available at the time of the export in the export dialog under the associated machine name.

# Predefining Connection Properties

Connections are given [properties](Glossary_o_eigenschaften.htm) from the defaults in the project and the properties of the potential. All other properties are specified in the [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm).

You can specify certain properties for [connections](Glossary_o_verbindungen.htm) in the project [settings](Glossary_o_einstellungen.htm) that are then assigned to every connection generated.

The properties specified in the project are inherited by the potential. The [potentials](Glossary_o_potenziale.htm) then pass on their properties to the [signals](Glossary_o_signale.htm) and then the connections. You can manually change the data on the individual [levels](Glossary_o_etagen.htm) and define additional properties.

1. Select the Options > Settings > Projects > "Project name" > Connections > Properties menu [items](Glossary_o_bauteile.htm).
2. Select the desired tab, e.g. [Electrical engineering](connectionsettingsgui_r_projekteinstellungenelektrotechnik.htm), [Hydraulics](connectionsettingsgui_r_projekteinstellungenhydraulik.htm), or [Process engineering](connectionsettingsgui_r_projekteinstellungenhydraulik.htm).
3. In the individual fields specify the default values for the connection properties.
4. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The default values are saved. When generating a connection it is automatically assigned the corresponding default values.

![](../Pictures/Gui/ALL/info.png)Tip:

For large [projects](Glossary_o_projekte.htm), generating connections can take some time. If you don't have much time, select [No] when prompted. You have the option of generating the new connections at a later time by holding down the [Shift] + [Ctrl] keys when carrying out the action Project data > Connections > Update.

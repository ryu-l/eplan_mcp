# Creating Projects

Projects can be created via the project menu or the project management. In both methods the project is created based on a project template or a basic project. The following section describes how you [create](Glossary_o_erstellen.htm) a project via the project menu. If you have not yet created any [project templates](Glossary_o_projektvorlagen.htm) or [basic projects](Glossary_o_basisprojekte.htm) then you can use the EPLAN [Sample templates](projects_k_basisprojekt.htm#Beispielvorlagen).

Precondition:

You have access to [Project templates](projects_k_projektvorlagen.htm) or [Basic projects](projects_k_basisprojekteerweitert.htm).

1. Select the menu item Project > New.
2. Specify a project name without a file suffix in the Project name field of the dialog Create project.
3. Click [...] beside the Template field, then switch to the directory where the template is located in the Select project template / basic project dialog.
4. In the File type field, select the EPLAN project template (\*.ept) or EPLAN basic project (\*.zw9) entry.
5. Select the desired template and click [Open].
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new project \*.elk is created in the target directory.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you are working with project management, the new project is automatically loaded in the project management module.

![](../Pictures/Gui/ALL/info.png)Tip:

In the [project properties](Glossary_o_projekteigenschaften.htm), you can display the project template / basic project from which a project comes:   
Mark your project in the page navigator and select the popup menu Properties. In the Properties tab, add the project property Project template. The project template / basic project being used will be displayed.

# Specifying the Parts Preselection

The [parts preselection](Glossary_o_artikelvorauswahl.htm) is a list of parts that you [create](Glossary_o_erstellen.htm) yourself and save under a specific name. It can be used as a filter in parts selection and device selection. The parts preselection is saved specifically for a project.

Precondition:

You have double-clicked on a [component](Glossary_o_schaltzeichen.htm) and in the Properties <...> dialog you have moved the Parts tab to the foreground.

1. [Settings] > Device selection
2. In the Settings: Device selection dialog, next to the Selection list field, click [...].
3. From the expanded list, select a user defined scheme that you want to change or create a new [scheme](schemeconfig_h_schematabearbeiten.htm) by using ![](../Pictures/Gui/ALL/all_new_as.png) (New).   
     
   ![](../Pictures/Gui/ALL/arrow.png) If the parts preselection already contains parts, they will be displayed in the list.
4. Using ![](../Pictures/Gui/ALL/all_new_as.png) (New) above the parts list open the Part selection dialog.
5. Page through the tree structure, and mark the parts that you would like to place in the parts preselection.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts will be placed in the list.
7. In the Parts preselection dialog, click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The scheme for pre-selecting parts is saved and shown in the Settings dialog: Select devices in the drop-down selection list.
8. In the Settings dialog close: Device selection by clicking [OK].

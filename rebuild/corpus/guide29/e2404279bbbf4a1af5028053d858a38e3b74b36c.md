# Dialog Synchronize function texts

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project and are viewing a schematic in the graphical editor. You have selected a [component](Glossary_o_schaltzeichen.htm). Popup menu > Synchronize function texts or Project data > Devices > Synchronize function texts.

The synchronizing [function texts](Glossary_o_funktionstexte.htm) allows you to analyze various function texts of placed and [unplaced functions](Glossary_o_nicht_platziertefunktionen.htm) in a device tag and thus harmonize different writing styles used in those texts. The selected "new" function text is fully adopted, including formatting and foreign language translation, and existing function texts are overwritten.

Overview of the main dialog elements:

Function definition:

This column displays the [function definitions](Glossary_o_funktionsdefinitionen.htm) of all placed and unplaced [functions](Glossary_o_funktionen.htm) for the selected DT. (Function templates are not considered here.)

Representation type:

This column displays the [representation types](Glossary_o_darstellungsarten.htm) of the functions.

Connection point designation:

This column displays the [connection point designations](Glossary_o_anschlussbezeichnungen.htm) of the functions.

Position:

This column displays the positions of the [devices](Glossary_o_betriebsmittel.htm) ([higher-level function](Glossary_o_anlage.htm), [mounting location](Glossary_o_einbauort.htm), column, and row).

Function text:

The function texts assigned to the devices are displayed and can be edited in this column.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

In addition, the following dialog-specific popup menu items are available:

| Menu item | Meaning |
| --- | --- |
| Transfer function text | Carries the function text stored in the current Function text column over to all other placed and unplaced functions of the device. |

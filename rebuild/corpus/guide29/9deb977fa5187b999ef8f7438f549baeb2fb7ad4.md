# Symbol Editor: Functionality

The [symbol editor](Glossary_o_symboleditor.htm) is a robust tool that simplifies the process of working with [symbol libraries](Glossary_o_symbolbibliotheken.htm) and [symbols](Glossary_o_symbole.htm). Once you have opened a project, you can open the symbol editor via the menu [items](Glossary_o_bauteile.htm) Utilities > Master data > Symbol library or Utilities > Master data > Symbol and begin editing data.

It has to be taken into account that symbols and symbol libraries are [part](Glossary_o_artikel.htm) of the [master data](Glossary_o_stammdaten.htm) whose editing is controlled via the [rights management](Glossary_o_rechteverwaltung.htm) (Utilities > Rights management).

![](../Pictures/Gui/ALL/note.png)Note:

The reason a project must be opened before you can work with symbols is that several symbol and symbol library [properties](Glossary_o_eigenschaften.htm) come from project [settings](Glossary_o_einstellungen.htm).

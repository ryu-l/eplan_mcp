# Creating Project Templates

[Project templates](projects_k_projektvorlagen.htm) can be created via the project menu or the project management. You can use a project template to [create](Glossary_o_erstellen.htm) a project. When you create a project template from an existing project, all [project-specific settings](Glossary_o_projektbezogeneeinstellungen.htm) and pages are saved in the project template.

Precondition:

You have opened a project.

Project menu: Project > Organize > Create project template.

Project management: [Extras] > Create project template.

1. In the Create project template dialog, choose the storage location and enter the name for the project template.  
     
   ![](../Pictures/Gui/ALL/arrow.png) EPLAN suggests the template directory that you specified in the user [settings](Glossary_o_einstellungen.htm) for [master data](Glossary_o_stammdaten.htm) in the dialog Settings: Directories as the storage location.
2. Click [Save].  
     
   ![](../Pictures/Gui/ALL/arrow.png) An \*.ept project template is created.

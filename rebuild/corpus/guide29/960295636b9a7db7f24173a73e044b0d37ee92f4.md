# Placeholders in Forms and Plot Frames

The placeholders available are divided into the following different areas:

- Form type-dependent placeholders: These placeholders are available only in certain [form types](Glossary_o_formulartypen.htm). They are, for instance:  
  Terminal diagram placeholders like saddle jumpers, wire jumpers, etc.  
  Terminal connection diagram placeholders like [shields](Glossary_o_abschirmungen.htm), [cable definition lines](Glossary_o_kabeldefinitionslinien.htm), etc.  
  During the evaluation of the [form](Glossary_o_verlauf.htm), EPLAN automatically replaces these [placeholder texts](Glossary_o_platzhaltertexte.htm) with the corresponding values of project [objects](Glossary_o_objekte.htm) on which the report is being run, such as [devices](Glossary_o_betriebsmittel.htm), pages, [symbols](Glossary_o_symbole.htm), etc.

![](../Pictures/Gui/ALL/note.png) Note:

If the placeholder does not have an alignment box, or it has an alignment box and the Remove breaks check box is also selected (under the Border) property, line breaks are filtered out in the [reports](Glossary_o_auswertungen.htm).

- Special texts for forms and plot frames: A difference is made between project and page [properties](Glossary_o_eigenschaften.htm). These properties are filled with the appropriate data when inserted
- Row and column texts for plot frames: These [special texts](Glossary_o_sondertexte.htm) can be inserted in order to display the numbers of the plot frame [grid](Glossary_o_raster.htm) and thus arrange it more clearly.

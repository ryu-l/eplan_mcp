# Configure hose lines

The hose line data read into the Configure hose lines dialog as a rule only contain the complete DT of the [hose lines](Glossary_o_schlauchleitungen.htm). In order to [generate](Glossary_o_erzeugen.htm) norm-compliant Hose line identification and a norm-compliant Type code for each hose line, further [properties](Glossary_o_eigenschaften.htm) have to be added to the incomplete hose line information and values assigned to these, i.e. configured. The Edit <...> dialog is available to this purpose. During editing you access the properties and values set in the selected scheme. The Block editing function allows you to edit the data of several hose [lines](Glossary_o_leitungen.htm) simultaneously in this dialog.

Preconditions:

- You have installed the hose line configurator as an add-on variant of EPLAN Fluid or as a stand-alone variant.
- You have read in hose line data - either directly from the schematic page of an opened project (add-on variant) or by using an exchange file (stand-alone variant). The hose line data contain the complete device tags of the hose lines as the minimum information and are displayed in the table of the Configure hose lines dialog.

1. In the add-on variant select the menu [items](Glossary_o_bauteile.htm) Extras > Settings or in the stand-alone variant the menu items Options > Settings.
2. In the Settings: Hose line configurator dialog you select the desired scheme, for example the default preset scheme DIN 20066 with which you can generate the [hose line identification](Glossary_o_schlauchleitungskennzeichnung.htm) and the [type code](Glossary_o_typencode.htm) in accordance with the specifications of DIN 20066.
3. Click [OK].
4. Double-click a row with a complete DT in the Configure hose lines dialog.
5. Carry out the desired entries in the fields of the [Edit <...>](fluidhoseconfiggui_d_schlauchleitungenbearbeiten.htm) dialog.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The edited hose line data are entered in the table of the Configure hose lines dialog.
7. In the add-on variant of the hose line configurator close the Configure hose lines dialog with [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) After editing the hose line data are written back into the project and saved at the marked hose lines. (This is only possible if you have read in the hose line data from an opened schematic page of a project before editing and the respective hose lines are still marked in the schematic.)

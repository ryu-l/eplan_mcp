### PCT loop numbers

Pre-planning

The PCT loop number provides an abbreviated description via identifiers of the task of the PCT loop and consists of the four elements "Technical facility", "Measurand", "Processing function" and "Number". In EPLAN the PCT loop number is automatically combined from the inputs for the designation of the PCT loop.

# Dialog Multi-user monitor

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The prerequisites for [multi-user operation](Glossary_o_multiuser_betrieb.htm) have been met. EPLAN is connected to the monitor server. Project > Multi-user monitor.

This dialog has two tables listing the [projects](Glossary_o_projekte.htm) that are relevant for multi-user operation.

The following dialog elements are available:

Own opened projects in multi-user operation:

The table on the left provides detailed information about the multi-user operation. It shows the projects that you and other users have open at the same time. The following data is listed for these projects:

- Project
- Users
- Area
- Product version
- Project action
- Progress.

If a user has started an action with a corresponding run-time for a project that you also have open (checks, [reports](Glossary_o_auswertungen.htm), etc), this will be indicated by a progress bar in the Progress column.

If, in the User column, you click the User code set up as a hyperlink, the email application on your computer opens and you can email this user.

If you click the ![](../Pictures/Gui/ALL/all_plussign_as.png) icon to the left of a project name, other information about a user appears in both tables (name, phone, computer). For this to happen, the users working in multi-user operation must have their user information stored in the [settings](Glossary_o_einstellungen.htm) (Options > Settings > User > Display > User code / address).

![](../Pictures/Gui/ALL/note.png)Notes:

- Projects that only you have open do not appear in the multi-user monitor.
- To exchange e-mails, an e-mail editor must be installed and correctly set up on your computer.

Other open projects:

The table on the right of the dialog lists all the projects that have only been opened by other users. The following data is listed for these projects:

- Project
- User.

If more than one other user has a project open, the Users column displays more than one User code for the relevant project.

If you wish to email a user in this table, you first need to drop down the row of information below. Here, click the user name that has been set up as a hyperlink.

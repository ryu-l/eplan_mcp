# Drawing and Changing Restricted Placing Areas

Mounting surfaces on components in the [layout space](Glossary_o_bauraum.htm) ([mounting panels](Glossary_o_montageplatten.htm), enclosure profiles, walls, doors) can be locked for positioning so that [part placements](Glossary_o_artikelplatzierungen.htm) cannot occur on them. This may be necessary if holes are to be subsequently drilled at these points or if the space is needed for [devices](Glossary_o_betriebsmittel.htm) that are mounted from other sides. These can include top-mounted [cooling](Glossary_o_kuehlung.htm) units, which project from above into the enclosure, or monitors and control elements on a door which have a relatively large mounting depth. Locked areas are independent 3D [objects](Glossary_o_objekte.htm) drawn as rectangles.

Restricted [placing](Glossary_o_auflegen.htm) areas are displayed in the layout space navigator for each mounting surface under the Locked areas hierarchy level.

Precondition:

You have opened a project. A layout space is open. An enclosure or a mounting panel has been placed.

1. Select the Insert > Locked area > Restricted placing area menu [items](Glossary_o_bauteile.htm).
2. Move the cursor to the area to be locked to activate it automatically, or activate a mounting surface directly in the layout space navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The automatically or directly activated mounting surface is identified in color. Input is now only possible on this area.
3. Draw the rectangle that represents the restricted placing area.

![](../Pictures/Gui/ALL/note.png)Note:

As soon as a [part](Glossary_o_artikel.htm) placement is attempted in a locked area, the placement is prevented, and an [appropriate message](messages_p_026012.htm#kanchor590) is displayed. If the initiating check run P026012 has the setting "Prevent errors", then placement is prevented automatically on confirmation of the message.

### Modifying the size of restricted placing areas

The size of restricted placing areas can only be changed in two ways:

- Changing the format properties in the property dialog: Enter changed values for the Width and Height fields on the tab of the Format [property dialog](Glossary_o_eigenschaftendialog.htm). The change is made referenced to the bottom left-hand corner.
- Graphical change: Mark the object. Direction arrows appear at the corners and in the middle of the sideline, in whose displayed direction you can pull apart and pull together the object. While moving along the direction arrow, handles that you can use for exact positioning are displayed at neighboring 3D objects.

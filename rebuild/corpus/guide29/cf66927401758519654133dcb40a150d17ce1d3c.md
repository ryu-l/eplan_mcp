# P027016: Topology - No routing track to target found

### Cause

No routing track has been found for this connection. You have defined connection [filters](Glossary_o_filter.htm) for [routing connections](Glossary_o_verlegeverbindungen.htm) in the [settings](Glossary_o_einstellungen.htm). You can also assign these filter settings as a property to the [routing paths](Glossary_o_strecken.htm) within the routing path network. At least one of the routing paths has a different value for the selected connection filter than other routing paths in the routing path network.

For example, two of three routing paths between the source and target have the connection color "Blue", while one of them has the value "Red". In the attempt to [generate](Glossary_o_erzeugen.htm) a routing connection, the routing track, therefore, cannot be determined by the system, and only a not-routed routing connection between the source and target is displayed.

### Solution

Create a valid routing track from the source to the target.

1. Locate the target of the invalid routing connection using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Trace back the routing path network, and check for each routing path of the connection in the Properties <...> dialog the value of the property Topology: Connection filter.
3. Assign the same value to each routing path.
4. Then, re-[route](Glossary_o_verlegen.htm) the connection, and start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

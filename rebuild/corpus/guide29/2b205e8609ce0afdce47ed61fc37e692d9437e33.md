### Address space assignment

Electrical engineering

Overview of the address ranges of all PLC cards that are assigned to the same CPU. The address space describes the number of address bytes that are provided by a CPU. The address range that a PLC card occupies within an address space is specified in EPLAN on the PLC card by specifying a start address and the associated data length. PLC cards can have separated address ranges for inputs and outputs.

# Converting Auxiliary Functions into Main Functions

You can change an auxiliary function into a main function by assigning the "Main function" property to the auxiliary function. The auxiliary function is changed into a main function. The original main function is then converted to an auxiliary function.

Preconditions:

- You have opened a project.
- You have opened the graphical editor or a navigator.

1. Select an auxiliary function.
2. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Devices > Assign main function  
     
   ![](../Pictures/Gui/ALL/arrow.png) The function will be assigned the "Main function" property.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The parts data are copied to the new main function and deleted at the old one.

### Assign main terminal

If the same terminal occurs in different [representation types](Glossary_o_darstellungsarten.htm), you can use the menu items Project data > Terminal strips > Assign main terminal to change the main terminal. This functionality is analog to the assignment of [main functions](Glossary_o_hauptfunktionen.htm). The marked terminal becomes a main terminal, the [part](Glossary_o_artikel.htm) data are copied to the new main terminal and deleted at the original one.

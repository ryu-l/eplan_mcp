# Tab <Pipe class - displayed name> / Tab <Substance - displayed name>

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have generated a pipe class or substance in the segment template navigator. Select the tab <Pipe class - displayed name> or <Substance - displayed name> in the Properties <...> dialog.
- You have marked a pipe class or substance in the segment template navigator. Edit > Properties. Select the tab <Pipe class - displayed name> or <Substance - displayed name>.

Use this tab to define the [properties](Glossary_o_eigenschaften.htm) of the marked pipe class or substance.

Overview of the main dialog elements:

Identifying name:

Enter the name of the pipe class / substance here. The name entered here is displayed by default at the pipe class / substance in the segment template navigator.

Description:

Enter a description text for the pipe class / substance here. This text is displayed in the segment template navigator together with the designation at the pipe class / substance by default.

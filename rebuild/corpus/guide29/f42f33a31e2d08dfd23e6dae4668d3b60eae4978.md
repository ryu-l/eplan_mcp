# Inserting Image Files

Image files in the GIF, JPG, BMP, ICO, PNG, or TIFF [formats](Glossary_o_formate.htm) can be inserted in EPLAN.

Precondition:

You have opened a page, [form](Glossary_o_verlauf.htm), plot frame or symbol.

1. Select the following menu [items](Glossary_o_bauteile.htm): Insert > Graphic > Image file
2. In the Select image file dialog, select a file using the file selector.
3. In the [Copy image file](gededitgui_d_bildkopieren.htm) dialog, you decide whether the file should be copied into the project directory (that is, into the Images subdirectory of the project) or the source directory should be kept.
4. Click [OK].
5. Pull a frame open in which the image will be scaled.   
     
   ![](../Pictures/Gui/ALL/arrow.png) The original page ratios are kept when [placing](Glossary_o_auflegen.htm).
6. You can change the display [properties](Glossary_o_eigenschaften.htm) of the image file in the Properties (image file) dialog.
7. Click [OK].

![](../Pictures/Gui/ALL/note.png)Notes:

- Only image files located in the project directory are saved when backing up the project.
- When deleting a page, the image files copied into the project directory are not deleted.
- Image files that have not been inserted into the project directory can be copied into the project directory by using Edit > Other > Links, and the links may be updated that way.

If an image file has been deleted from its directory and can therefore no longer be displayed, a rectangle with the file path is displayed in its place.

![](../Pictures/Gui/ALL/info.png)Tip:

You can insert an image file using drag and drop, by dragging the selected image file from the Windows Explorer into the graphical editor of your project.

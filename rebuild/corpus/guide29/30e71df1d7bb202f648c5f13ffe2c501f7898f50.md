# P005034: An identified connection definition point is located on a multiple connection

### Description

This message appears if one of these points lies on a multiple connection when you are naming the [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm).

![](../Pictures/Gui/ALL/note.png)Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

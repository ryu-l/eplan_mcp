# Tab Segment template

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have created a segment template in the [segment templates](Glossary_o_segmentvorlagen.htm) navigator. In the Properties <...> dialog, select the Segment template tab.
- You have selected a segment template in the segment template navigator. Edit > Properties (or Popup menu > Properties). Select the Segment template tab.

In this tab you specify the identifying name and the description for the segment template.

Overview of the main dialog elements:

Identifying name:

Enter a unique name for the segment template here. The segment template is managed in EPLAN under this name.

Description:

Here, enter the name under which the segment template is displayed in the project. Multi-lingual entry is possible.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

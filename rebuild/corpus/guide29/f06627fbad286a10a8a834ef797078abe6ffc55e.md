# Tab Symbols (Changing Standards)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. If multiple [projects](Glossary_o_projekte.htm) are open: You have selected a project in the page navigator. Utilities > Change of standard. You have specified all of the [settings](Glossary_o_einstellungen.htm) in the Project tab. [Next]. You have specified all of the settings in the Rotation / flipping tab. [Next]. You selected the check box in the Master data tab in a symbol library row in the Individual assignment column. [Next].

In this tab, you can select assignment [schemes](Glossary_o_schemata.htm) for assigning [symbols](Glossary_o_symbole.htm) from the source symbol library to symbols from the target symbol library.

The following dialog elements are available:

Assign symbols:

A row contains an assignment of source library symbols to target library symbols. It displays only the assignment pairs from the [symbol libraries](Glossary_o_symbolbibliotheken.htm) for which the Individual assignment check box is selected in the Master data tab.

- Source: Symbol library: Displays the source project symbol library file name without a file extension.
- Target: Symbol library: Displays the target project symbol library file name without a file extension.
- Scheme: In this column you can select a scheme. This scheme contains information about which symbols can be assigned to one another. Click [Scheme] to [create](Glossary_o_erstellen.htm) or edit a scheme.
- Status: If a scheme is selected in the Scheme column, the assignment of the symbols is checked. This column displays the status of the check. The status is "OK" if the [function definitions](Glossary_o_funktionsdefinitionen.htm) for the symbols match and the number of source symbol [connection points](Glossary_o_anschluesse.htm) are less or equal to the number of target symbol connection points.

[Scheme]:

Opens the Settings: Symbol assignment dialog. Enables you to assign symbols from the source library to symbols from the target library.

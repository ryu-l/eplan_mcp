# P003006: Cable between same item

### Cause

The source and target function of the [cable](Glossary_o_kabel.htm) have identical device [designations](Glossary_o_bezeichnungen.htm) and are cross-referenced.

### Solution

Enter different device designations for the source function and target function of the connected cable.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

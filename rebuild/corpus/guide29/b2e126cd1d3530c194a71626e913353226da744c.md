# P005039: Representation types of targets differ

### Cause

The target [functions](Glossary_o_funktionen.htm) of a connection have a conflicting entry for the property "Display type". It may be that the first connection target was set to "Multi-line", but the second one was set to "Single-line".

### Solution

Give the targets the same display type.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

# Dialog Settings: Column configuration (terminals)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the [Edit terminal strip](stripmanagementgui_d_klemmenleistebearbeiten.htm) dialog. Click [...] next to the Scheme field.

In this dialog you can specify which columns will be displayed for the terminal data.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

![](../Pictures/Gui/ALL/note.png)Note:

The [schemes](Glossary_o_schemata.htm) are saved by user. To include a scheme together with the project, you must export the scheme and pass it on separately.

Column configuration:

In this field you can specify which columns will be shown in the table in the Edit terminal strip dialog. Check the corresponding check boxes. Use the arrow buttons to change the order of the columns.

![](../Pictures/Gui/ALL/info.png)Tip:

Activate the Preview check box in order to display a schematic preview of the terminals. This makes it easier, among other things, to recognize different terminal types, potential types and multi-level terminals.

# Dialog Properties to be combined

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Master data > Form > Open > [Open]. You have opened the Form properties - <Form name> dialog (Popup menu > Properties on the [form](Glossary_o_verlauf.htm) in the Pages - <Project name> navigator dialog) and have clicked [...] in the Value field of Combine in a line by property.

In this dialog, you define the [properties](Glossary_o_eigenschaften.htm) for which identical data should be combined in one line. For instance, you can combine the data for each page type in the table of contents. The default [separator](Glossary_o_trennzeichen.htm) is the semicolon and, for combined values, the character string "..."; but you can also use the Separator for multiple values and Separator for combined values properties to specify other separators.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You have selected page type as the property to be combined for [forms](Glossary_o_formulare.htm) of the "table of contents" type. The following text is then output as Page name (full) property, for example:

=EB3+EBS/1;=EB3+ET1/1...=EB3+ET1/3;=EB3+ET1/5...=EB3+ET1/8; =EB3+ET2/1...=EB3+ET2/3;=EB3+ET3/1...=EB3+ET3/3;=EB3+ET4/1...=EB3+ET4/3

If you set the property Generate data headers for the first x sorting properties, when the specified sorting properties are combined, they are automatically analyzed so that the combining is only done within a header.

![](../Pictures/Gui/ALL/note.png)Note:

If the Combine parts of a device setting has been set for parts lists (for example via the Options > Settings > Projects > "Project name" > Reports > Parts menu [items](Glossary_o_bauteile.htm)) and the combining is done based on the Part number property, the parts are output individually nonetheless. Note here that the combination is defined using the Combine in a line by ([ID](Glossary_o_id.htm) 13111) form property and the property can be set as you wish, i.e., it is not just limited to the [part](Glossary_o_artikel.htm) number.

Multilingual texts are also combined if they are totally identical. The figures in multilingual texts are not considered.

Overview of the main dialog elements:

List:

The list shows the properties selected for combining.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

# Using Connection Filters (Topology)

Routing paths have the property Topology: Connection filter. The connection filter is used for routing to control which [connections](Glossary_o_verbindungen.htm) may be routed through the routing track. The values of such criteria can be color assignments of [wires](Glossary_o_draehte.htm), cross-sections, or voltage values.

The assignment of values to the connections to be routed is purely textual. Free text is used to define the values, but it must also be added to the connections.

### Set project settings for connection filters

The values that can be activated or deactivated in the Connection filter dialog are set in the project [settings](Glossary_o_einstellungen.htm).

1. Select the menu [items](Glossary_o_bauteile.htm) Options > Settings > Projects > "Project name" > Routing connections.
2. Select the Connection filter tab in the Settings: Routing connections dialog.
3. Click the [...] button.
4. From the Criteria selection dialog select a connection property for which the values are to be displayed in the connection filter, e.g., Connection color / number, and click [OK].
5. In the table in the Value column, enter text that describes the filter criterion, e.g., "Blue", "Red", "Black", "Yellow". You can use 15 [lines](Glossary_o_leitungen.htm) for this.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The set values are stored and displayed there when opening the Connection filter dialog.

### Apply connection filter

The values defined in the connection filter are applied to [routing paths](Glossary_o_strecken.htm).

1. Select one or several routing paths on the [topology](Glossary_o_topologie.htm) page, and select the popup menu item Properties.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The dialog Properties (components): Routing path is displayed.
2. Select the Topology: Connection filter property, and in the Value column, click [...].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Connection filter dialog is displayed. The table displays the values that you defined in the project settings.
3. Activate the Active check box above the table in order to enable the connection filter generally.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Now the individual values in the table can be activated or deactivated.
4. Activate or deactivate the Active check box in the table in front of each value that is to be applied to this connection.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) All values that you activated in the connection filter are listed in the Value field of the Connection filter property in the Properties (components): Routing path dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) During routing, only the connections are still routed through the edited routing path that correspond to the set filter criteria.

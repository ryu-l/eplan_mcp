# Dialog Optimize nets automatically: Preview of result

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have created [routing connections](Glossary_o_verlegeverbindungen.htm). In the [layout space](Glossary_o_bauraum.htm) navigator or in the layout space a [component](Glossary_o_schaltzeichen.htm) has been highlighted that contains routing [connections](Glossary_o_verbindungen.htm). Project data > Connections > Optimize nets automatically. In the Optimize nets automatically dialog, click [OK].

In this dialog, the result of the analysis of [nets](Glossary_o_netze.htm) and routing connections is displayed. The data of the first connection is transferred to all connections of the net following optimization.

The following dialog elements are available:

The [properties](Glossary_o_eigenschaften.htm) of the connections are displayed in the table. The table contains the following columns:

- Row: Contains a consecutive line number.
- Status: Indicates whether the connection can be optimized.   
  "New" = connections that receive a new routing track through optimization.  
  "Cannot be optimized" = connections that are not complete or that were previously routed optimally.
- Source
- Target
- Connection designation
- DT (full)
- Connection color / number
- Connection: Cross-section / diameter with unit
- Part number [1]: Shows the [part](Glossary_o_artikel.htm) number of the first part entered at the connection.

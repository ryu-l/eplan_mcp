# Dialog Settings: Tree structure (...)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Options > Settings > Projects > "Project name" > Display > Tree structure (...)

These dialogs allow you to define the display and order of the information for the tree structure device- and page-specifically so that only the information relevant to you is displayed in the tree view of the [navigators](Glossary_o_navigatoren.htm).

![](../Pictures/Gui/ALL/note.png)Notes:

- These [settings](Glossary_o_einstellungen.htm) do not influence the list displays of the navigators. These still display the logical sequence of the pages and [project data](Glossary_o_projektdaten.htm).
- Please note that these settings are ignored when importing and exporting project settings!

Overview of the main dialog elements:

List:

All [properties](Glossary_o_eigenschaften.htm) that can be displayed are in the list with a check box. Select the check boxes for the properties that are to be displayed and deselect those that should not be.

![](../Pictures/Gui/ALL/note.png)Note:

Independent of the information to be displayed, certain columns are always displayed i.e., the check boxes cannot be deselected.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

Also show descriptive identifiers:

Select this check box when the identifying and describing [structure identifiers](Glossary_o_strukturkennzeichen.htm) should be displayed in the navigator tree views. If this check box is deselected then only the identifying project structures are displayed.

Detached representation of substructures:

If this check box is selected, then the substructures of structure identifiers are displayed as separate tree nodes in the navigator tree views.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

You have selected the check box and specified a structure identifier for the identifier block "Higher-level function", designating it New.2. The level New and the sublevel 2 below this are displayed in the tree structure. If the check box is deselected, then only one level New.2 is displayed.

Use representation sequence also for page outputs:

This check box is only available in the dialog Settings: Tree structure (pages).

If the check box is activated, the sequence for the tree structure of the page navigator specified in this dialog is also used for the following functionalities:

- Scroll through pages in the graphical editor
- Printing pages
- Exporting pages as a PDF file
- Exporting pages in [DXF](Glossary_o_dxf.htm) / [DWG](Glossary_o_dwg.htm) format
- Output pages in the properties Next page / Previous page.

If the check box is deactivated, the sequence f the pages in the list view is decisive for the page output.

![](../Pictures/Gui/ALL/note.png)Note:

The logical sequence of the pages in the list view of the page navigator is decisive by default at the page output (and at other functionalities).

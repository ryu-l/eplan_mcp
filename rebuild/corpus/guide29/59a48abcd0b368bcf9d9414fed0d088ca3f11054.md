# Updating Main Elements

All the [part references](Glossary_o_artikelreferenzen.htm) of all the associated [part placements](Glossary_o_artikelplatzierungen.htm) can be transferred to the main function in the 3D mounting layout as well. This replaces the [part](Glossary_o_artikel.htm) references in the main function with the part references contained in the part placements. As in the 2D [panel layout](Glossary_o_schaltschrankaufbau.htm), identification is by the complete device tag.

Preconditions:

- You have opened a project.
- There is a part placement on a mounting surface with a complete device tag in a [layout space](Glossary_o_bauraum.htm) of a project.
- One of the following [function definitions](Glossary_o_funktionsdefinitionen.htm) is assigned to the placement: Fluid device, Fluid connection splicer / line connector, black box, terminal, terminal strip, PLC card, busbar, plug, normal item.
- A symbol with the identical, complete device tag is placed on a page in the same project. The symbol has the property Main function.

1. Select one or more layout spaces in the layout space navigator.
2. Select the Update main elements popup menu item.
3. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The part references of all the associated part placements are transferred to the main function.

# Defining Defined Working Sections as Project Administrator

When you use the [rights management](Glossary_o_rechteverwaltung.htm) of EPLAN, the defined working sections can be assigned centrally by a project administrator.

![](../Pictures/Gui/ALL/note.png)Notes:

- The user names used for the assignment of defined working sections must have been created previously under rights management.
- The user name is managed in EPLAN internally always in upper-case letters. Accordingly, all user names entered in the Define working sections dialog are converted to and saved as upper-case letters.

Precondition:

You have opened a project.

1. Select the Project > Defined working sections > Define as project administrator menu [items](Glossary_o_bauteile.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the Define working sections as project administrator dialog, the [schemes](Glossary_o_schemata.htm) are displayed that were already created for the division in defined working sections.
2. If no scheme exists yet or if you want to edit a scheme, click on ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit) above the table.
3. In the [Filter](modaldialogsdb_d_filternnach.htm) dialog, [create](Glossary_o_erstellen.htm) a new scheme and determine the criteria for the division in defined working sections. Or edit the criteria of an existing scheme.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Your [settings](Glossary_o_einstellungen.htm) are saved in the scheme selected, and you are returned to the Define working sections as project administrator dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the All editors column, you can enter one or several [editors](Glossary_o_editoren.htm) for each defined working section.
5. To do so, in the row of the required defined working section click the All editors table cell, followed by the [...] button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Select editor dialog displays the users defined in rights management.
6. In the Assign column, activate the check boxes for the editors that are to be assigned the respective defined working section. Or deactivate the check boxes for the editors that are to be removed from the defined working section.
7. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected editors are displayed in the All editors column. If several editors have been entered for a defined working section, they will be separated by a comma.
8. Click [OK].

![](../Pictures/Gui/ALL/info.png)Tips:

- You can also enter user names manually in the All editors column. In this case, however, make sure that the user names entered also exist in rights management.
- In the All editors column, you can carry the content of a cell over to other cells using copy and paste.

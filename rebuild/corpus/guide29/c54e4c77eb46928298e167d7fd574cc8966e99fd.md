# Dialog Assign phase busbar

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

A [layout space](Glossary_o_bauraum.htm) is open. The [connections](Glossary_o_verbindungen.htm) navigator is open. Project data > Connections > Generate phase busbar connections. Select the Assign phase busbar popup menu item.

You can assign a [part](Glossary_o_artikel.htm) to a phase busbar connection in this dialog. In addition, you can enter or select the DT for the phase busbar connection.

The following dialog elements are available:

DT:

Enter the desired DT for the phase busbar. The [...] button opens the dialog [DT selection](modaldialogsdb_d_bmkauswahl.htm) in which you can select a DT existing in the project.

Parts:

Displays the part that is assigned to the phase busbar. The [...] button opens the part selection in which you can select the phase busbar part. A 3D macro that is used during the placement of the phase busbar can be entered at the assigned part.

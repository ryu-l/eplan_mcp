# Dialog Settings: Export of text files

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- You have opened a project. Utilities > Edit properties externally > Settings (<...>) Select the General tab. In the File type drop-down list, select one of the "Tab-delimited text", "Tab-delimited Unicode file (\*.txt)", or "XML file (\*.edc)" entries and click [Options].
- Options > Settings > User > Interfaces > External editing(<...>) Select the General tab. In the File type drop-down list, select one of the "Tab-delimited text", "Tab-delimited Unicode file (\*.txt)", or "XML file (\*.edc)" entries and click [Options].

In this dialog, you can specify the [settings](Glossary_o_einstellungen.htm) for external editing of pages, [functions](Glossary_o_funktionen.htm), or [connections](Glossary_o_verbindungen.htm) in a text editor.

Overview of the main dialog elements:

Application:

Enter the name (including the drive and directory) here for the format of the application to be used, or click [...] to select the program interactively.

Using Popup menu > Insert path variable you branch to the [Select path variable](modaldialogsdb_d_pfadvariablen.htm) dialog where you can select one of the available EPLAN-specific [path variables](Glossary_o_pfadvariablen.htm).

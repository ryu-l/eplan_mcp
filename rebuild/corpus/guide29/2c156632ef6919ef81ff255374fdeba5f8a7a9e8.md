# Displaying Fluid Device Tags in the Schematic

The [fluid power](Glossary_o_fluidtechnik.htm) standard DIN ISO 1219-2 stipulates that DT must have a rectangular frame in the schematic. EPLAN Fluid allows you to show and hide this text box. The Draw text box property is available to this purpose in the Display tab in the Properties <...> dialog. In addition to the rectangle, an ellipse or an oval can be used as the box frame. However, this is not norm-compliant.

![](../Pictures/Visualisation/ALL/ftechnic_bmk_mitrahmen_new_AV.png)

![](../Pictures/Gui/ALL/note.png)Note:

Please note that you can also use layer management to add borders to device tags (or to general text on a special layer). To do this, select the relevant setting for the Text box field for the desired [layers](Glossary_o_ebenen.htm) in the layer management (Options > Layer management menu item).

# P005061: More than one multi-line connection definition at a single-line connection

### Cause

A single-line connection has several [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) that contain multi-line connection definitions, i.e [connections](Glossary_o_verbindungen.htm) are defined on the Interconnect [devices](Glossary_o_betriebsmittel.htm) tab in the [property dialog](Glossary_o_eigenschaftendialog.htm) for both connection definition points.

### Solution

1. Only enter multi-line connection definitions for one connection definition point.
2. Delete the multi-line connection definitions for the other connection definition points.
3. Then start a new check run.

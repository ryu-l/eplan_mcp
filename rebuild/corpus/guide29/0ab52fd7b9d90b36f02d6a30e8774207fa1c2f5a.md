# Affecting Table Displays

In some tabular displays such as the Structure identifier management dialog and the Configure properties dialog for components, and when editing terminal strips and [plugs](Glossary_o_stecker.htm), etc., you can manually change and optimize the display options and sorting sequence of [objects](Glossary_o_objekte.htm).

In addition, you can optimize the column width for all tables.

![](../Pictures/Gui/ALL/note.png)Note:

Upon confirmation of a new ordering, EPLAN notes the positions of the table headers and automatically jumps to the last focused cell when the dialog is reopened. If the ordering within the table has changed, then a jump occurs to either the first or last cell to be edited.

Precondition:

You have opened a dialog containing a tabular display.

### [ClosedSort table objects](javascript:void(0);)

In some tabular displays such as the Message management or Layer management dialogs, in tabular editing in the Edit in table dialog, etc., you can sort the objects alphanumerically in ascending or descending order.

1. Double-click one of the column headers.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the displayed data is in the original order, then sorting first takes place in increasing alphanumeric order based on the column whose header you clicked. (An arrow symbol in the column header ![](../Pictures/Gui/ALL/all_triangleascending_as.png) shows the sorting direction.)
2. Double-click the same header once more.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The sorting now occurs in decreasing alphanumeric order, again based on the column whose header you clicked. (An arrow symbol in the column header ![](../Pictures/Gui/ALL/all_triangledescending_as.png) shows the sorting direction.)
3. Double-click the same header a third time.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The column data is now displayed in the original order.

### [ClosedOptimize the display of individual columns](javascript:void(0);)

To optimally display a column, i.e. at optimum width, proceed as follows:

1. Double-click the column [separator](Glossary_o_trennzeichen.htm) to the right of the heading of the column whose width you wish to optimize.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The width of the column is adjusted so that the header and the contents of the column are completely visible.

### [ClosedOptimize the display of all columns](javascript:void(0);)

Proceed as follows to optimize the width of all columns:

1. Select the Adjust column width popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All columns are adjusted so that both the header and the column contents are fully legible.

![](../Pictures/Gui/ALL/info.png)Tip:

To optimally adjust the width of all columns you can use the shortcut keys [Ctrl] + ["Plus"] on the numeric block of your keyboard.

If your keyboard does not have a numeric keypad, e.g., a laptop keyboard, you can also use the key combination [Fn] combined with the computer- and country-specific key for "Plus".

### [ClosedChange font size with mouse wheel](javascript:void(0);)

In many tabular displays like the Message management or Layer management dialogs, and in tabular editing in the Edit in table dialog, etc., you can change the displayed font size by pressing the [Ctrl] key while simultaneously scrolling the mouse wheel.

1. Click inside the table.
2. Hold down the [Ctrl] key and scroll up / down with the mouse wheel.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The font size in the table is enlarged or reduced.
3. Select the Font size 100% popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The texts in the table are re-displayed in their original font size.

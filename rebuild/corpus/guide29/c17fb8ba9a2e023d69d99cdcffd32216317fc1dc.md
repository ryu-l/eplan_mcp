# Dialog Select interpretation template

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The project contains a completely defined enclosure. The [layout space](Glossary_o_bauraum.htm) navigator is open and a layout space is open. The layout space contains imported 3D bodies which are to be saved as an enclosure. You have surrounded the 3D geometry with a rectangle and selected it.

Edit > Device logic > Automatic interpretation

In this dialog, you can select an enclosure from any layout space within the opened project or from the parts tree of parts management that will serve as a sample for importing the logical elements. The dialog contains the following tabs:

- Project-specific
- Part-specific.

Overview of the main dialog elements:

Tab Project-specific

On this tab, the project tree is represented with the layout spaces of all opened [projects](Glossary_o_projekte.htm). This way, it is also possible to use the logical elements of [items](Glossary_o_bauteile.htm) from a project other than the active project, e.g., from a macro project. The tree view of the projects takes into account possible filter [settings](Glossary_o_einstellungen.htm). In the tree, you can select one or several layout spaces as a template object.

Filter:

This drop-down list displays all the available [filters](Glossary_o_filter.htm). A selected filter is automatically activated and is applied to both the tree and the list view. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the [Filter](modaldialogsdb_d_filternnach.htm) dialog. Here you can [create](Glossary_o_erstellen.htm), edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

- Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
- Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

Value: <Property>:

Use this field, via [Quick input](modaldialogsdb_k_filter.htm#I_Schnelleingabe), to adjust quickly the value of a filter criterion for a defined and activated filter.

Tree:

Shows all the layout spaces, enclosures and [mounting panels](Glossary_o_montageplatten.htm) available in the opened projects. If you have selected an enclosure in the tree view, you can apply its logical elements to the previously selected 3D [objects](Glossary_o_objekte.htm) by clicking [OK].

---

Tab Part-specific

On this tab, the parts tree is represented appropriately in terms of parts management. Only parts are represented that contain a 3D macro. The tree view of the parts takes into account possible filter settings. In the tree, you can select one or several parts as a template object.

List:

In the list, the parts selected as template objects are displayed with the [part](Glossary_o_artikel.htm) number and associated graphical macro.

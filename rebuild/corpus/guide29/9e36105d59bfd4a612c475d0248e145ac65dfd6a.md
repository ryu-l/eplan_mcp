# P007011: The single-line function cannot be uniquely assigned to the multi-line function

### Cause

In the single level display, one device function is missing the data entry for a certain property. In the multi-level display this property is filled with data for the relevant device single function. For example, the name of each terminal is entered in the multi-level display for a terminal strip, but not for the terminal strip of the single-level display.

### Solution

If necessary, copy the missing data of the property from one of the [functions](Glossary_o_funktionen.htm) of the corresponding device into the multi-level display, and copy them into the function of the single-line display.

Then start a new check run.

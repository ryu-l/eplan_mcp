# Automatable Actions

You can automate the following [actions](Glossary_o_aktionen.htm) without programming knowledge:

| Action | Functionality |
| --- | --- |
| Update parts in project | Updates outdated parts data in the project. This will replace outdated [stored parts](Glossary_o_eingelagerteartikel.htm) in the project by newer system parts (i.e. newer parts in the parts database). |
| Complete parts in project | Searches in the project for missing parts; if they are found, they are automatically stored. Missing parts can occur if parts have first been entered at the main function in the project and only afterwards have been created in the parts database. |
| Complete parts in system | Supplements the system (i.e., the parts database) with parts that were present in the project, but not in the system. |
| Update [reports](Glossary_o_auswertungen.htm) | Updates all reports that are contained in the selection or in the entire project. |
| [DXF](Glossary_o_dxf.htm) / [DWG](Glossary_o_dwg.htm) | Outputs the entire project or selected project pages as a DXF / DWG file. |
| Back up data | Zips the entire project into a \*.zw1 file, and stores it in the selected directory. The source project remains unchanged. |
| Print | Prints the selected project pages or the entire project. |
| Delete stored [part](Glossary_o_artikel.htm) [properties](Glossary_o_eigenschaften.htm) | Deletes the properties of parts stored in the project. |
| Export / Label manufacturing data | Outputs [project data](Glossary_o_projektdaten.htm) for the manufacturing data / labeling. |
| Update [model views](Glossary_o_modell_ansichten.htm) | Updates all model views that are contained in the selection or in the entire project. |
| Export PDF | Outputs the entire project or selected project pages as a PDF file. |
| Compress project | Removes any unnecessary project data. |
| Optimize project database | Optimizes the project database. (This is necessary before "old" [projects](Glossary_o_projekte.htm) can be edited in the current version.) |
| Perform project checks | Performs the selected project checks. The messages generated are stored in the message management. |
| Generate [topology](Glossary_o_topologie.htm) [functions](Glossary_o_funktionen.htm) | Automatically generates topology functions and inserts them into the routing path network. |
| Update [connections](Glossary_o_verbindungen.htm) | Generates or updates connections. |
| Route (topology) | Routes connections in the topology. |
| Translate | Translates the project into the desired languages. |
| Remove translations | Removes translation text in one or more languages from the project. |

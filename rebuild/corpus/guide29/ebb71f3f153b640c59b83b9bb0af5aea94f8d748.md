# Dialog Customer-focused improvement program

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Help > Customer-focused improvement program.

Use this dialog to decide whether to participate in the [customer-focused improvement program](modaldialogs_k_benutzerfreundlichkeitdetails.htm).

Overview of the main dialog elements:

Tab Participation

Yes, participate in the customer-focused improvement program:

Activate this option to participate in the customer-focused improvement program. If you agree to the participation in the improvement program, statistical information, anonymized, will be collected about your use of EPLAN and how you configure your software and hardware. This information is sent to EPLAN Software & Service. EPLAN Software & Service will use insights gained from such information to further improve the user-friendliness and performance of the software in future versions.

The Customer-focused improvement program dialog will then not be displayed again the next time you launch the program. But you can access the dialog at any time via the menu [items](Glossary_o_bauteile.htm) Help > Customer-focused improvement program.

You can terminate your participation at any time by activating the No, don't participate option.

No, don't participate:

Activate this option if you do not wish to participate in the customer-focused improvement program (any longer).

The Customer-focused improvement program dialog will then not be displayed again the next time you launch the program. But you can access the dialog at any time via the menu items Help > Customer-focused improvement program.

Decide later:

Activate this option if you want to decide at a later time whether to participate in the customer-focused improvement program. The Customer-focused improvement program dialog is then displayed each time you start EPLAN.

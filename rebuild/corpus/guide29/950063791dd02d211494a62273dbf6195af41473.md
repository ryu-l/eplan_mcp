# P007008: The part '<x>,' which had been predefined in the device list, was used <y> times too often

### Cause

A [part](Glossary_o_artikel.htm) in the device list was used more often than allowed.

### Solution

#### Possibility 1

Delete the part in the schematic. Refer to the value entered in the parts column Number allowed.

#### Possibility 2

Increase the number of allowed pieces for the part in the device list. To do this, highlight the part in the device list. Select Popup menu > Properties. Increase the value under Number allowed in the Properties <...> dialog.

Then start a new check run.

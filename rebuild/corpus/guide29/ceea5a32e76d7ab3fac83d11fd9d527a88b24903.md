# Settings

You can perform a number of different [settings](Glossary_o_einstellungen.htm) to configure the program to suit your personal requirements and needs:

- You can define the [properties](Glossary_o_eigenschaften.htm) of a project, e.g. the graphical representation of electronic [functions](Glossary_o_funktionen.htm) or the default format for device tags.
- You can set the working environment on a [user-specific](Glossary_o_benutzerbezogen.htm) basis and thus adapt the program functionality to match the working methods of each user.
- You can define workstation-specific settings, such as the file path for the management of [system messages](Glossary_o_systemmeldungen.htm).
- You can define company-specific settings, in order to define defaults and company conventions for all workstations used.

# P004053: Too many differences were found between the network structure in the import file and in the project! Please check all network structures

### Cause

During the last import of PLC data a connection was found that contradicts the connection currently existing in the project. The faulty connection could not be determined due to the complex contradiction.

### Solution

Check all the [bus ports](Glossary_o_sps_busanschluesse.htm) whether they are connected with the correct physical network.

![](../Pictures/Gui/ALL/note.png)Note:

This module-specific message is generated by the importing of PLC data. Using a new check run (any desired scheme) it can be deleted from the message management dialog.

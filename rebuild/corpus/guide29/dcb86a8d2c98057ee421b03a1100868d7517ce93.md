# Dialog Drill hole

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened an outline of the type "Outline NC record generation" in the Outline editor (for example via the Utilities > Master data > Outline (NC data) > Open menu [items](Glossary_o_bauteile.htm)) and have created an NC record for this outline. Utilities > Master data > Outline (NC data) > Edit record > Generate drill hole.

In this dialog you specify the [properties](Glossary_o_eigenschaften.htm) of the drill hole.

Overview of the main dialog elements:

Diameter:

Select one of the drill hole diameters defined for the machine from the drop-down list next to the field. Manual input is not possible here.

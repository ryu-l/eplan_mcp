# Connection Symbols: Representation of the Connection Direction

Note the following special features relating to the representation of the connection direction for [connection symbols](Glossary_o_verbindungssymbole.htm):

### [ClosedT-nodes](javascript:void(0);)

T-nodes are used to branch automatically generated connection [lines](Glossary_o_leitungen.htm). There are T-nodes for four different directions. For each direction, there are then four [variants](Glossary_o_varianten.htm). These variants determine the flow of the [connections](Glossary_o_verbindungen.htm).

Every T-node had three [connecting points](Glossary_o_anschlusspunkte.htm). The point without a designation shows where the connection comes from. The points designated by "1" and "2" define the sequence of the lines.

In the T-node <Direction> dialog, the first target is indicated by the straight line and the second target by the diagonal line.

|  |  |
| --- | --- |
|  | T-node down |
|  | T-node up |
|  | T-node right |
|  | T-node left |

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

For the setting T-node right, third variant, that means:

![](../Pictures/Visualisation/ALL/egedgui_trightvar3.png)
  
If you come from above (1) or from below (2), the target is on the right.  
If you come from the right, the first target is above (1) and the second is below (2 / diagonal line).

### [ClosedDouble junctions](javascript:void(0);)

Double junctions can be regarded as two permanently joined T-nodes. There are two basic types of double junctions in EPLAN, which are distinguished by the search directions "Vertical" and "Horizontal". Depending on the different targets, there are two variants for each search direction. These variants clearly define the paths for [target tracking](Glossary_o_zielverfolgung.htm) in [reports](Glossary_o_auswertungen.htm).

Every double junction has three connection directions. Two opposite ends are directly connected to each other (straight line) and these lead to the first target. The other two ends (diagonal lines) each lead to the second target.

![](../Pictures/Visualisation/ALL/egedgui_crossing.png)

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

For the second variant, Vertical, this means:  
From above, the first target is below and the second is on the left (diagonal line).  
From the right, the target is below. (In the illustration, the coil is the first target in both cases.)  
From below the first target is above and the second is on the right (diagonal line).  
From the left the target is above. (In the illustration, the NO contact is the first target in both cases.)

![](../Pictures/Visualisation/ALL/egedgui_crossingexample.png)

### [ClosedJumpers](javascript:void(0);)

Jumpers are used to [create](Glossary_o_erstellen.htm) an electrical connection between a terminal and neighboring terminals (potential distribution). In electrical engineering this is done using metal jumpers or cross-connectors.

Every jumper has three connection directions. For this purpose, every jumper is equipped with four connecting points. The points designated by "1" , "2", and "3" define the sequence of the targets. The fourth point (without a designation) represents the shared connection point of the jumper. The first target is always opposite. The second target is always at a right angle to the left or right. The third target is always at a right angle to the right or at a right angle toward the bottom.

![](../Pictures/Visualisation/ALL/egedgui_bridge.png)

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

For the third variant, Above, this means:  
From above, the first target is below, the second is on the left, and the third is on the right.  
From left, from right, and from below the first target is always toward the top.

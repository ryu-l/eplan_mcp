# P004030: Missing symbolic address (automatic)

### Cause

There is no symbolic address specified at a PLC connection point. Furthermore, the connection point does not possess a connected target that could automatically [generate](Glossary_o_erzeugen.htm) a symbolic address from its DT.

### Solution

#### Possibility 1

Open the Properties <...> dialog for the PLC connection point in question. Enter a symbolic address in the PLC connection point tab, in the Symbolic address, field.

Then start a new check run.

#### Possibility 2

Connect the PLC connection point with a sensor or actuator that possesses a device tag.

EPLAN will then automatically locate the connected DT with its [target tracking](Glossary_o_zielverfolgung.htm) function and generate a symbolic address from it.

Then start a new check run.

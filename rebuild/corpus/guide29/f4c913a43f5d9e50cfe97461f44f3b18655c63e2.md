# Dialog Select format elements

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > Company > Wire fabrication > Komax or Options > Settings > Company > Wire fabrication > Schleuniger. In the Settings: <Manufacturer of wire fabrication machine> dialog, select the Labeling tab and click the [...] button in the Value column.

In this dialog you can configure the labeling text of the [wire fabrication](Glossary_o_drahtkonfektionierung.htm) machines by means of [format elements](Glossary_o_formatelemente.htm).

Overview of the main dialog elements:

Available format elements:

This field shows all format elements that can be [part](Glossary_o_artikel.htm) of a labeling text. To [load](Glossary_o_laden.htm) a format element for the labeling into the Selected format elements field, select it and then click ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right).

Selected format elements:

This field contains the format elements comprising the format of the labeling text.

Preview:

This field displays a preview of the format you created.

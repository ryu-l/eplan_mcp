# P005083: Conduit connection without color / number

### Cause

You have not assigned a color or a number at a conduit connection.

### Solution

1. Locate the connection definition point of the conduit in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Call up the dialog Properties <...> of the connection definition point and enter a value in the Color / Number field.
3. Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

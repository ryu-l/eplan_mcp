# P022015: The pages combined with ''Number of pages / Page name per property' are not consecutive. Property value: '<x>' Pages: '<y>'

### Cause

Non-consecutive pages were identified when calculating identical values for page [properties](Glossary_o_eigenschaften.htm) Number of pages per property and Page names per property.

### Solution

1. In the Message management dialog, look at the list of page ranges in this message.
2. Open the page navigator and expand all the pages in the tree view.
3. In the tree view, select the entire range for all the non-consecutive pages reported.
4. Select Popup menu > Number and number the pages with a start number and increment value of "1". (When using a page structure on the basis of "[higher-level function](Glossary_o_anlage.htm)" and "[mounting location](Glossary_o_einbauort.htm)", also add structure-oriented numbering.)
5. After numbering, select Page > Number of pages / page name per property.
6. Then start a new check run.

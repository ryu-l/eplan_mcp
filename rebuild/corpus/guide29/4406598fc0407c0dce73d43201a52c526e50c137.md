# Tab Edit words / Select words

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call (Edit words):](javascript:void(0);)

Utilities > Translation > Edit dictionary. Select the Edit words tab.

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call (Select words):](javascript:void(0);)

You have opened the [property dialog](Glossary_o_eigenschaftendialog.htm) for a [component](Glossary_o_schaltzeichen.htm), a text, a project page, etc. In a multilingual field select the popup menu item Multilingual input. Click the [Dictionary] button in the dialog Multilingual input.

In this tab you can add new [keywords](Glossary_o_stichworte.htm) with translation texts to the dictionary as well as edit existing keywords and their translation texts. Dictionary keywords are case-sensitive.

Overview of the main dialog elements:

Full-text filter:

Enter the text to be found in this box, and click ![](../Pictures/Gui/ALL/all_search_as.png) (Find). This way only entries that include the text searched for are displayed in the keyword list.  
Click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) to delete the search term and [return](Glossary_o_zurueckbuchen.htm) to the full keywords display.

![](../Pictures/Gui/ALL/note.png)Note:

Do not use placeholder characters (such as "\*", "?" or "\_") for the full-text search as these will not be returned by the search. These restrictions are caused by the search mechanisms of the databases used. In addition no differentiation is made between upper- and lower-case letters and no AND / OR links are supported.

Source language:

Select one of the [dictionary languages](Glossary_o_woerterbuchsprachen.htm) as the source language for the keyword that you would like to edit. The source language is the language in which the keyword is stored in the dictionary.

Find:

Use this field to search for all keywords already in the dictionary. When also using the full-text filter you can search for keywords within the filtered list.  
To search for a keyword, enter it in the input field. To show all translation texts for a keyword, click on the desired keyword in the keyword list.

Keyword:

This field shows all of the translation texts for the selected keyword. One line is shown for each dictionary language. The keyword must have a translation text in the selected source language because the keyword is stored under this entry in the dictionary. You can enter a comment in the last line. A comment can be helpful if the keyword was stored twice but with different meanings. The comment is shown with the word suggestion in the Found words dialog.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The word Connector is stored twice in the en\_US source language in the dictionary. It is translated differently in the fr\_FR target language in each case.

| en\_US | fr\_FR | Comment |
| --- | --- | --- |
| Connector | Connecteur | Function definition |
| Connector | Symbole de connexion | Symbol |

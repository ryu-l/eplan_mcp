# Block Properties

Block [properties](Glossary_o_eigenschaften.htm) allow you to jointly format and display direct or [indirect properties](Glossary_o_indirekteeigenschaften.htm). The following is possible when using [block properties](Glossary_o_blockeigenschaften.htm):

- You can access indirect properties of an object using block properties.
- You can enter block properties for any components and display the property values in the schematic.
- Block properties can be output in [reports](Glossary_o_auswertungen.htm).
- Block properties can be predefined for [symbols](Glossary_o_symbole.htm) and [projects](Glossary_o_projekte.htm).

# P028020: Macro at the planning object is not placed in the representation type 'multi-line'

### Cause

A window macro that is not placed in the "multi-line " representation type was entered in the [property dialog](Glossary_o_eigenschaftendialog.htm) of a planning object in the Macro tab. Or a page macro was entered at the planning object that contains a multi-line schematic page that is unplaced.

### Solution

1. Open the project page on which the window macro is to be placed.
2. Open the pre-planning navigator (menu [items](Glossary_o_bauteile.htm) Project data > Pre-planning > Navigator).
3. Mark the message in the Message management dialog and select the popup menu item Synchronize selection.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The respective planning object is marked in the pre-planning navigator.
4. Select the Place macro > Multi-line popup menu item in the pre-planning navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The macro assigned to the planning object hangs on the cursor.
5. Place the macro on the project page by clicking there.
6. In the subsequent dialog select the desired insertion mode.
7. Click [OK] to close the dialog, then start a new project check.

![](../Pictures/Gui/ALL/note.png)Note:

If a page macro with a page of the "Schematic multi-line" type was entered at the planning object, drag & drop the planning object from the pre-planning navigator into the page navigator. The page macro is then added to the project as a multi-line page.

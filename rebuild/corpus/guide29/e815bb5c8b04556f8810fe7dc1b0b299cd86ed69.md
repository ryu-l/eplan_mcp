# Dialog Number connecting points

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Utilities > Master data > Symbol > Open. You have opened a symbol library, selected the symbol to be edited, and added [connecting points](Glossary_o_anschlusspunkte.htm) to the symbol. Utilities > Number connecting points.
- Utilities > Master data > Symbol > New. You have selected the symbol variant to be generated, specified the Symbol number and Symbol name [properties](Glossary_o_eigenschaften.htm), and added connecting points in the [symbol editor](Glossary_o_symboleditor.htm). Utilities > Number connecting points.

In this dialog you specify how the connecting points should be numbered.

Overview of the main dialog elements:

Sequence:

Use these options to specify whether the [connection points](Glossary_o_anschluesse.htm) should be numbered according to the "from top to bottom and left to right " method or the "from left to right and top to bottom" method.

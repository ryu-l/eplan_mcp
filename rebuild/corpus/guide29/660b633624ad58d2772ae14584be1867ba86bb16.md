# Defining Translation Fonts

If you wish to translate a project into a language whose characters are not contained in the standard fonts on your computer, then you must install an appropriate font containing these characters on your computer. You must select this font in the EPLAN [settings](Glossary_o_einstellungen.htm).

Precondition:

You have installed a font containing the desired characters.

### Determine a dictionary font

1. Select the menu item Control Panel from the start menu.
2. Select the Display entry.
3. Select the Appearance and Personalization entry, and then click on Personalization.
4. Select the Window Color entry.
5. In the Window Color and Appearance dialog, click on the display of the dialog field.
6. In the Font field, select the font containing the desired characters. The "Segoe UI" font in size "9" and black color is defaulted.
7. Click [OK].

### Defining graphical editor fonts

1. In EPLAN: Options > Settings > Company > Graphical editing > Fonts
2. In the Font drop-down list, select the font containing the desired characters.

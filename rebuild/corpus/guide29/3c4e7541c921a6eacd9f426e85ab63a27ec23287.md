# External Reports

The "Export / labeling" functionality also allows the generation of external [reports](Glossary_o_auswertungen.htm). In the same manner as with export / labeling, the [project data](Glossary_o_projektdaten.htm) is reported and output to an external report file.

![](../Pictures/Gui/ALL/note.png)Note:

Prerequisite for the generation of Microsoft Office file [formats](Glossary_o_formate.htm) from EPLAN is an executable installation of an Office version cleared by EPLAN.

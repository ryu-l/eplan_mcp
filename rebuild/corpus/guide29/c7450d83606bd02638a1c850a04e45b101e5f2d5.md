# Dialog Number using PLC data

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have selected [devices](Glossary_o_betriebsmittel.htm) in the graphical editor or a navigator, or you have selected one or more pages in the Pages - <Project name> navigator dialog. Project data > Devices > Number using PLC data.

In this dialog, you can specify the [settings](Glossary_o_einstellungen.htm) for the numbering of devices with PLC data and then execute the numbering.

Overview of the main dialog elements:

Settings:

Select a scheme defining the settings for the numbering from the drop-down list. Or click [...], to edit an existing scheme or [create](Glossary_o_erstellen.htm) a new scheme using the Settings: Number using PLC data dialog.

Format groups used:

In this field, the groups of devices are shown which were specified in the scheme as the range of numbering.

Overwrite:

Here you can specify which DT / [designations](Glossary_o_bezeichnungen.htm) should be overwritten during the numbering:

- All: The device tags / designations of all devices in the numbering range will be renumbered.
- Only those "Numbered by using PLC data": Only those [functions](Glossary_o_funktionen.htm) will be renumbered which are flagged as "Numbered by using PLC data".
- Only number marked ones: Only the functions identified by a question mark "?" in the DT or designation will be renumbered.

Mark as "Numbered using PLC data":

If this check box is selected, the functions affected by the numbering will have the "Numbered with PLC data" property set. During later numbering runs (DT numbering, terminal numbering, etc.) you can then choose to number these functions or exclude them from numbering.

If the check box is deselected, the functions are not flagged and can't be differentiated from other functions in later numbering runs.

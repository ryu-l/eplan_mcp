# Tab Busbar

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- The project contains at least one [layout space](Glossary_o_bauraum.htm). The layout space contains [busbars (bending)](Glossary_o_sammelschienegebogen.htm). You have opened the layout space navigator. Select a busbar in the navigator. Select the Properties popup menu item. In the Properties (components): Part placement (3D) dialog, select the Busbar tab.
- While keeping the [Shift] key pressed, you have highlighted a busbar in the 3D display area. Edit > Properties. In the Properties <...> dialog, select the Busbar tab.

On this tab, you specify the [properties](Glossary_o_eigenschaften.htm) for the highlighted busbar.

Overview of the main dialog elements:

Displayed DT:

The displayed DT is displayed in the graphical editor on the [component](Glossary_o_schaltzeichen.htm). If you have defined in the project [settings](Glossary_o_einstellungen.htm) that [devices](Glossary_o_betriebsmittel.htm) are to be automatically numbered when [symbols](Glossary_o_symbole.htm) are inserted, then a DT is automatically suggested here. You can accept this DT or overwrite it manually.

In addition you can use the [popup menu or the [...] button](devicetaggui_r_feldsichtbaresbmk.htm) to [create](Glossary_o_erstellen.htm) or select a DT.

Full DT:

This field displays the full DT (i.e. structure identifier of the current environment + displayed DT) of the component / item. Use the [...] button to open the Full DT dialog. You can edit the [structure identifiers](Glossary_o_strukturkennzeichen.htm) there and select, e.g., another [mounting location](Glossary_o_einbauort.htm).

Item:

In this field, the item definition is displayed; it is imported from the selected function definition and used for the display in the layout space navigator.

Function definition:

The function definition of the busbar displayed here is automatically assigned, depending on the function definition of the associated item. Click [...] to open the Function definitions dialog and select a different function definition if required.

Copper bundle:

This field specifies that a copper item belongs to a [copper bundle](Glossary_o_kupferstrang.htm). This relationship can be changed. Using the [...] button, you can display the 3D object selection dialog. All the copper [bundles](Glossary_o_straenge.htm) in the layout space are listed here. By moving the selection to another copper [bundle](Glossary_o_buendel.htm), the copper item is assigned to this bundle. The selection is carried over to the property field via [OK].

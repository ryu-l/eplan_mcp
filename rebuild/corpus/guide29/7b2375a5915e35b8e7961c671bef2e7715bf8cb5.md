# Rotated Pages / Non-rotated Pages

Rotation of pages is a standard procedure when adjusting a project from one standard to another. It is not necessary to rotate some pages. The following table shows which pages are not rotated.

| Pages that are not rotated | Page type |
| --- | --- |
| Graphical pages | Page type "Graphic (I)" |
| Mounting panel pages | Page type "Panel layout (I)" |
| Fluid pages | Page type "Fluid power schematic (I)" |
| P&I pages | Page type "[P&I diagram](Glossary_o_ri_fliessbild.htm) (I)" |
| Model views | Page type "Model view (I)" |
| All [report pages](Glossary_o_auswertungsseiten.htm) |  |

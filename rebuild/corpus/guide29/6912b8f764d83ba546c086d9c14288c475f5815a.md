# P021002: Placeholder object does not contain object references

### Cause

When expanding a placeholder object the earlier object references were accidentally deleted. This means the placeholder object has variables and value sets, but no object reference in the table of the Assignment tab.

### Solution

To expand [placeholder objects](Glossary_o_platzhalterobjekte.htm), proceed as follows: Press and hold the [Ctrl] key. Then click all the [objects](Glossary_o_objekte.htm) that you want to add to the placeholder object one after the other in the schematic. Then release the [Ctrl] key and click the right mouse button quickly on the placeholder object. From the popup menu that appears, select the menu item Assign objects to placeholder object,and double-click the placeholder object.

![](../Pictures/Gui/ALL/arrow.png) In the Assignment tab of the Placeholder Object dialog, all selected objects are shown in the table.

Assign a placeholder to the object property you want; one that contains a variable with a corresponding value.

Then start a new check run.

# Adjusting Toolbars

EPLAN has pre-defined [toolbars](Glossary_o_symbolleisten.htm) that you can activate or deactivate. You can also change the display type of the buttons. You can also [create](Glossary_o_erstellen.htm) your own toolbars and equip them with the desired commands. These [user-defined](Glossary_o_benutzerdefiniert.htm) toolbars can be edited and deleted. You can also edit the EPLAN pre-defined toolbars. Buttons can be added or deleted. The pre-defined toolbars cannot however be deleted.

![](../Pictures/Gui/ALL/note.png)Note:

Once you have created user-defined toolbars, you must save the current user interface configuration as a new workspace or as a selected workspace (edit), so that the user-defined toolbars are permanently available for use (in the current workspace). This also applies for the extension of pre-defined toolbars and the removal of buttons.

### Extend pre-defined toolbars

1. Right-click on an area of the menu bar or a toolbar and select the Customize popup menu item.
2. In the Customize dialog, select the Toolbars tab.
3. Select the check box of the toolbar to which you wish to add extra commands.
4. Select the Commands tab.
5. From the Categories list, select the desired category whose buttons are to be displayed.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the Buttons area, the button [symbols](Glossary_o_symbole.htm), menu [items](Glossary_o_bauteile.htm) or [actions](Glossary_o_aktionen.htm) belonging to the selected category are displayed.
6. Click the desired button and use "Drag & Drop" to pull it onto the previously activated toolbar.   
     
   ![](../Pictures/Gui/ALL/arrow.png) If you select an action or a menu without pre-defined image file, you must specify further [settings](Glossary_o_einstellungen.htm) for the button in a subsequent dialog.

### Delete buttons from toolbars

1. Right-click on an area of the menu bar or a toolbar and select the Customize popup menu item.
2. Click the desired button and use "Drag & Drop" to pull it off your toolbar.

# Dialog Part selection: Select data source

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Parts > Management > [Extras] > Settings. Select the Part selection with scheme selection check box and click [OK].

- You have selected a main function in the graphical editor or in a navigator. Edit > Properties. Select the Parts tab and click [...] in the Part number field.
- Project data > Devices > Navigator. Select an entry. Popup menu > New device.
- Project data > Parts / Devices > Bill of materials navigator. Select an entry. Popup menu > Add part or Popup menu > Exchange part.
- Project data > Parts / Devices > Device list. Select an entry. Popup menu > Add part.

In this dialog, select a scheme for the data source for the [part](Glossary_o_artikel.htm) selection. This is used to determine which data source is used for the part selection.

Overview of the main dialog elements:

Data source:

Select a scheme from the drop-down list which determines the [user-specific](Glossary_o_benutzerbezogen.htm) default [settings](Glossary_o_einstellungen.htm) for part selection. Click [...] to open the [Settings: Parts (user)](partselectiongui_d_datenauswahlbenutzer.htm), which you can use to change these default settings.

Always use this data source:

If this check box is selected, the selected data source will be used for all further [actions](Glossary_o_aktionen.htm) which open the part selection. The Part selection: Select data source dialog is not displayed any more. You can reactivate the Part selection: Select data source dialog by activating the Part selection with scheme selection check box again (via Utilities > Parts > Management > [Extras] > Settings).

# Dialog Settings: Number using PLC data

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Options > Settings > Projects > "Project name" > Devices > Number using PLC data
- You have selected [devices](Glossary_o_betriebsmittel.htm) in the graphical editor or a navigator, or you have selected one or more pages in the Pages - <Project name> navigator dialog. Project data > Devices > Number using PLC data. In the Number using PLC data dialog, click [...] next to the Settings field.

In this dialog, you can specify the [settings](Glossary_o_einstellungen.htm) for the numbering of devices with PLC data.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Format groups:

The groups of devices for which you have set a format are shown here. You can use the buttons above the list to [generate](Glossary_o_erzeugen.htm) format groups, change them later, or delete them. The order of groups has no influence on the numbering (in contrast to [connection numbering](Glossary_o_verbindungsnummerierung.htm)).

[Net extension]:

Opens the [Net extension](offlinenumerationplcgui_d_netzerweiterung.htm) dialog. In this dialog you can extend the definition of a net. This setting affects the designation if the range is selected as "Net".

# Dialog DT syntax check

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. The check is activated in the DT syntax check [settings](Glossary_o_einstellungen.htm). In the Properties <...> dialog, specify an invalid character as the identifier element and click [OK].

After specifying the device tag [properties](Glossary_o_eigenschaften.htm), EPLAN then checks whether the syntax for the specified device tag identifier is correct. If this is not the case, this dialog appears.

![](../Pictures/Gui/ALL/note.png)Notes:

- You specify which characters are permitted in the settings for the DT syntax check.
- A syntax check also takes place when entering the identifier in Structure identifier management.

The following dialog elements are available:

Message:

This unchangeable field displays the identifier and highlights the incorrect elements.

Description:

Text describing the error that occurred is displayed here.

[Settings]:

Opens the Settings: DT syntax check. There you can check, and if necessary, correct your syntax settings.

[<<] / [>>]:

Click one of these buttons to highlight the next (or previous) incorrect element of the identifier. If only one character is invalid, these buttons are grayed out.

[Ignore]:

Ignores all errors, closes the message dialog, and inserts the rejected identifier.

[Cancel]:

Closes a dialog. You [return](Glossary_o_zurueckbuchen.htm) to the properties dialog and can correct your entry there.

# Dialog Settings: General (project, connections)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Options > Settings > Projects > "Project name" > Connections > General.

In this dialog you specify the general [settings](Glossary_o_einstellungen.htm) for [connections](Glossary_o_verbindungen.htm).

Overview of the main dialog elements:

Determine the source and target of connections from the placement:

If this check box is selected, the connection sources and targets are determined using the graphical position of the connected [functions](Glossary_o_funktionen.htm). This setting is the same as the behavior in EPLAN before Version 1.9 SP 1. In the [reports](Glossary_o_auswertungen.htm), the source and target of connections are then sorted based on their placement in the schematic.

If the check box is deselected, the device tags of the connected functions are compared, to determine the connection sources and targets. The sorting of the [structure identifiers](Glossary_o_strukturkennzeichen.htm) in the [structure identifier management](Glossary_o_strukturkennzeichen_verwaltung.htm) will be used for these comparisons; the "smaller" device tag will become the source.

![](../Pictures/Gui/ALL/note.png)Note:

Cable connections are not affected by this setting.

Manage saddle jumper connection points in the net definition point:

If this check box is selected, the Net connections tab in a net definition point's [properties](Glossary_o_eigenschaften.htm) dialog also displays symbol connection points with the connection point type "saddle jumper". However, additional function connection points for saddle jumpers are not displayed.

If the check box is deselected, saddle jumpers are not displayed in the Net connections tab.

![](../Pictures/Gui/ALL/note.png)Note:

Net based connections cannot be used together with distributed terminal jumper optimization. The two functionalities [generate](Glossary_o_erzeugen.htm) different connections that are incompatible with one another.

Manage all the net connections in the net definition point:

If this check box is checked, the targets are not automatically specified for net-connecting functions that are directly connected to one another (i.e. the Net-connecting property is activated for the function). In this case the connections are not automatically generated and have to be specified manually. I.e., all the connections in a net (both connections via [connection symbols](Glossary_o_verbindungssymbole.htm) with no specified target and [direct connections](Glossary_o_direktverbindungen.htm) between net-connecting functions) are specified and stored in the net definition point.

If the check box is deselected, the targets are automatically specified for net-connecting functions that are directly connected to one another, and connections are generated automatically. This is the default setting. These connections are displayed in the Other connections dialog, but cannot be deleted or changed.

![](../Pictures/Gui/ALL/note.png)Notes:

- If there is a connection symbol with target specification between the net-connecting functions (e.g. a [T-node](egedgui_d_tstueck.htm)), the connections are specified automatically in all cases.
- If the net definition point is deleted, the net connections will no longer be defined.

If both check boxes are selected (Manage saddle jumper connection points in the net definition point and Manage all the net connections in the net definition point), all of the net's symbol [connection points](Glossary_o_anschluesse.htm) can be defined and rewired via the net definition point.

Suppress unplaced topology routing paths in the routing track:

Unplaced [topology](Glossary_o_topologie.htm) [routing paths](Glossary_o_strecken.htm) arise, for example, during the [Generation of topology functions](cablinggui_h_strukturenverbinden.htm) at [structure routing points](Glossary_o_strukturverlegepunkte.htm).

If this check box is activated, unplaced topology [routing tracks](Glossary_o_verlegewege.htm) in the property Topology: Routing track ([ID](Glossary_o_id.htm) 20237) are hidden and are not output in the reports.

Output topology routing points with length in the routing track:

If this check box is activated, the topology [routing points](Glossary_o_verlegepunkte.htm) and structure routing points at which a length is entered are output in the Topology: Routing track (ID 20237) property.

If in addition the setting Suppress unplaced topology routing paths in the routing track is activated, only the placed topology routing points and structure routing points in the routing track are included in the output.

If the check box is not checked, only the topology routing paths are be output in the routing track.

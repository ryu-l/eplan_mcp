# Path Function Texts

Path [function texts](Glossary_o_funktionstexte.htm) ease documentation because you don't have to enter a function text for each [component](Glossary_o_schaltzeichen.htm). These texts can be positioned arbitrarily within a path and are reported when generating [PLC cross-references](Glossary_o_sps_querverweise.htm), in terminal diagrams, and in [bills of materials](Glossary_o_stuecklisten.htm).

If no other function text is entered for a component, the function text from the schematic path will be used for [reports](Glossary_o_auswertungen.htm).

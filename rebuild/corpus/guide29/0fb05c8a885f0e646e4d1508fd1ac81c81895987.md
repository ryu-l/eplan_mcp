# P003012: Color / number assigned twice (for same shields / indexes)

### Cause

#### Possibility 1

You have assigned the same color or number to two [cable connections](Glossary_o_kabelverbindungen.htm) when entering connection colors or numbers.

#### Possibility 2

In the [cable](Glossary_o_kabel.htm) you are using shielded connection pairs with identical connection colors, the [shields](Glossary_o_abschirmungen.htm) of which have the same name.

#### Possibility 3

The cable contains paired [connections](Glossary_o_verbindungen.htm), at least two pairs of which are assigned the same color or number and the same index.

### Solution

#### Regarding option 1

Change the duplicated connection colors or numbers. Make sure each cable connection has a clear value assigned to it.

#### Regarding option 2

If you are using shielded connection pairs with identical connection colors in the cable, then assign a unique name for every shield.

#### Regarding option 3

If you are using paired connections in the cable, and you have allocated the same color or number and the same index to at least two connection pairs, then assign unique colors or numbers to every connection pair in the cable, or assign a unique index to every connection pair.

Refresh the connections and then start a new check run.

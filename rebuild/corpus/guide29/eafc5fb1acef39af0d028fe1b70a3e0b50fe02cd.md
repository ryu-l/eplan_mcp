# Dialog New identifier set

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. Utilities > Master data > Identifier. Select the New popup menu item.

In this dialog you can define your own identifier set.

Overview of the main dialog elements:

Designation:

In this field you specify the name of the new identifier set. After confirming with [OK] the Suggested identifiers dialog displays a new column. There you can specify an identifier set for each function definition.

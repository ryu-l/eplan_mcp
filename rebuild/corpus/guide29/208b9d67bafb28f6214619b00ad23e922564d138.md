# Building Automation

In building automation in accordance with the standards VDI 3814 and DIN EN ISO 16484-3 it is usual to output the information required for the planning and implementation of building automation systems and instrumentation and control systems in function lists. Special [project templates](Glossary_o_projektvorlagen.htm), [forms](Glossary_o_formulare.htm) as well as [properties](Glossary_o_eigenschaften.htm) for pre-planning are available in EPLAN to support these function lists.

### Function lists

The [form](Glossary_o_verlauf.htm) for the function lists is divided into sections and columns. The properties displayed in the form are sorted by sections. In EPLAN the properties specified by the standard are mapped in [part](Glossary_o_artikel.htm) by fixed defined EPLAN properties and in part by [user-defined](Glossary_o_benutzerdefiniert.htm) properties. Section 1 contains fixed defined EPLAN properties for the display of PLC inputs and outputs. Sections 2 to 8 contain user-defined properties. These properties are already predefined in the project template for building automation and are available for immediate use if you use this template.

The EPLAN properties listed below are used in Section 1 of the form for function lists. These properties are determined from the entries in the PLC tab (in the properties dialog of [planning objects](Glossary_o_planungsobjekte.htm)). The combination of the entries in the columns Direction, Data type and Counter specify which type of PLC input or output this is.

| Section | Column | Input / output [functions](Glossary_o_funktionen.htm) | EPLAN property |
| 1 | 1 | Binary output: switching / actuating | Total number of digital PLC outputs ([ID](Glossary_o_id.htm) 44029) |
| 1 | 2 | Analog output: actuating | Total number of analog PLC outputs (ID 44031) |
| 1 | 3 | Binary input: signaling | Total number of digital PLC inputs (ID 44028) |
| 1 | 4 | Binary input: counting | Total number of PLC counter inputs (ID 44059) |
| 1 | 5 | Analog input: measuring | Total number of analog PLC inputs (ID 44030) |

In order to output function lists for building automation in accordance with the standard VDI 3814, use the report type "Pre-planning: Planning object overview" and assign the form F40\_VDI3814.f40 or F40\_VDI3814\_A.f40 to it.

### Function lists in BACnet-compliant representation

The function lists for the building automation can also be output in BACnet-compliant representation in accordance with the standards VDI 3814 and EN ISO 16484-5. In this form of representation the [PCT loop functions](Glossary_o_plt_stellenfunktionen.htm) not only describe the measuring and user functions but also the software functions of [PCT loops](Glossary_o_plt_stellen.htm).

For a BACnet-compliant representation a PCT loop function must be created for each software function (each PLC input and output) in the pre-planning navigator and the PCT loop functions must be located below the PCT [loops](Glossary_o_messstellen.htm). By default these PCT loop functions have a row in the PLC tab. The assignment of a PLC address is not necessarily required in this case.

For the output of function lists in BACnet-compliant representation some forms are now also have available in the [master data](Glossary_o_stammdaten.htm) (for example F40\_VDI3814\_1.f40, F40\_VDI3814\_1\_en\_US.f40. etc.).

### Graphical display of automation schemes

You can draw a schematic overview (automation scheme) of the planned part area in the EPLAN project on a page of the type "[P&I diagram](Glossary_o_ri_fliessbild.htm)". In this overview the amount of used or required inputs / outputs per planning object can be displayed. To do so use a property arrangement at the functions placed in the automation scheme in which the properties for the total number of the PLC inputs and outputs (for example Total number of digital PLC outputs (ID 44029)) are selected for display. This information is usually displayed path-wise below the drawing. In the property arrangement for properties that output the total number of the PLC inputs and outputs, activate the display property Zero as blank if zero values are not to be shown anymore in the listing of the overall numbers.

To implement such a path-wise display you have to change the display [settings](Glossary_o_einstellungen.htm) and select an automatic Y coordinate. To do so activate the display property Y-coordinate automatic (path) in the property arrangement. The value of the Y coordinate (in relation to the point of origin of the page) is determined in the Property arrangement: Y coordinate automatic (path) (ID 12062) property. This property is available for [plot frames](Glossary_o_normblaetter.htm) and pages.

A line-by-line display (for example for [projects](Glossary_o_projekte.htm) to the [NFPA standard](Glossary_o_nfpa_norm.htm)) is also possible. To do so activate the display property X coordinate automatic (path) in the property arrangement. The value of the X coordinate (in relation to the point of origin of the page) is determined in the Property arrangement: X coordinate automatic (path) (ID 12063) property. This property is available for plot frames and pages.

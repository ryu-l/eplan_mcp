# Exporting Parts Data

When exporting [part](Glossary_o_artikel.htm) data, there is a difference noted between:

- The export of subsets of the database
- The export of selected records.

Precondition:

You have opened a parts database using [Extras] > Settings in the Parts management dialog.

### Export subsets of the database

1. Utilities > Parts > Management > [Extras] > Export
2. Select the desired file type from the File type drop-down list of the Export records dialog.
3. Click [...] to specify the path for the configuration file for the text format and the CSV format; in the same way you can specify for the EPLAN Data Portal exchange format (EDZ) how the data is to be exported: Activate the Export referenced data completely check box if, in the case of [assemblies](Glossary_o_baugruppen.htm), [modules](Glossary_o_module.htm), etc., subassemblies, submodules, etc. are also to be included in the export.

   ![](../Pictures/Gui/ALL/note.png)Note:

   When you export data in the "Text" file type, note that the textimportexport.cfg configuration file in the \Parts\<Customer code> directory of the current program version may have to be modified so that certain fields (such as those in the Connection point pattern and Drilling pattern groups) are included in the export.   
   Details on this can be found in the [Parts Management: Control Files for Importing and Exporting Data](partsmanagementgui_k_steuerdateiimportexport.htm) topic.
4. Select if export is to be made to one file (Entire file option) or to an individual file for each record (Individual files option); depending on your selection you must either enter the file name for the export file (File name field) or specify the export directory.
5. In the Record type group box, select the check boxes of the data that you would like to export.
6. In the Trade group box, select the check boxes of the [trades](Glossary_o_gewerke.htm) that you would like to export.
7. Change the scope of the fluid data to be exported by selecting / deselecting the check box.
8. Click [OK].

### Export selected records

Precondition:

You have selected the records to be exported in the tree or in the list.

1. Utilities > Parts > Management > Popup menu > Export
2. Continue as described above.

![](../Pictures/Gui/ALL/note.png)Note:

If the current selection contains nodes (in the tree view) then all the records under those nodes will be exported.

# Changing Route (Topology)

The routing track, determined by the routing, of a routing connection can be influenced by modifying the routing.

- Routed [connections](Glossary_o_verbindungen.htm) can be routed from a routing path to another routing path.
- Non-routed connections can be placed on a routing path, so that [routing connections](Glossary_o_verlegeverbindungen.htm) are created from them.

When modifying the [route](Glossary_o_verlegen.htm) manually, the Topology: Routing track specification connection property is filled. Subsequently, the connection [filters](Glossary_o_filter.htm) set for the routing path are no longer taken into account for the routing of this connection.

For modifying a route use the center points of the [routing paths](Glossary_o_strecken.htm) or the graphics of the unrouted routing connections (thin orange line). By dragging such a center point / such a line to another routing path, the routing track of the connections can be modified. If several connections run through the routing path, a selection dialog is displayed that you can use to decide which of these connections are to be moved into the new routing path. At the selected connections, the routing path is then entered into the Topology: Routing track specification property.

1. Click a routing path.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The snap points become visible on the routing path.
2. Drag the center point of the routing path to another routing path.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Connections dialog is displayed, which lists all the connections routed through the source routing path. Displayed connections are already highlighted in the dialog.
3. Activate the check box in the Change route column for the connections that are to be re-routed in the selected target routing path.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected connections are re-routed.

![](../Pictures/Gui/ALL/info.png)Tip:

If you want to consider the connection filters for routing again, you can manually delete the value of the Topology: Routing track specification property for the respective connections. Or pull the connection away from the routing path entered here, and the routing path will be removed from the property.

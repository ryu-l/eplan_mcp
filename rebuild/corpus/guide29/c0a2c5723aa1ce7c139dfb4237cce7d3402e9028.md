# Restoring Master Data

When restoring archives that contain only [system master data](Glossary_o_systemstammdaten.htm), EPLAN checks if the data has changed. If a file has changed, a message is displayed with the information as to which file is newer. You must the decide whether you wish to overwrite the existing file. Restoring to a different (new / empty) [master data](Glossary_o_stammdaten.htm) directory is also possible.

1. Select the menu item Project > Restore > "Master data".
2. Use the [...] button in the Backup directory field in the dialog Restore <Master data> to select the directory in which the backed up [projects](Glossary_o_projekte.htm) are located.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The backed up master data contained in the selected directory are displayed in the Master data: <Master data> list.
3. Select the files you wish to restore.
4. Use the [...] button in the Target directory dialog to select the target directory to where the data backup should be restored.
5. Confirm your entries.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The data from the swap file is copied to the specified target directory. If several files were selected, then these are sequentially restored.

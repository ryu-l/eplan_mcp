# Generating Drilling Patterns from DXF / DWG Files

Importing of drilling information from Steinhauer NC files with the file extension \*.CNC is not possible directly, since a CNC file always contains all drilling information for all the components of a mounting panel. In order to make this information available for the creation of [drilling patterns](Glossary_o_bohrbilder.htm), the CNC file in the Steinhauer machine software has to be exported into the format [DXF](Glossary_o_dxf.htm) / [DWG](Glossary_o_dwg.htm). The exported DXF / DWG files can then be imported into EPLAN and used for the creation of drilling patterns by means of [drilling pattern frames](Glossary_o_bohrbildkaesten.htm).

In addition to DXF / DWG files from the Steinhauer machine software, this functionality can also be used to import other drilling data that were exported from other DXF files (for example CAD systems).

![](../Pictures/Gui/ALL/note.png)Note:

A special import scheme is required for the identification of the [objects](Glossary_o_objekte.htm) as [items](Glossary_o_bauteile.htm), [cut-outs](Glossary_o_durchbrueche.htm) or [outlines](Glossary_o_konturen.htm) during importing. Select the menu items Options > Settings > User > Interfaces > DXF / DWG export and import and [create](Glossary_o_erstellen.htm) a new scheme.

Prerequisite for the generation of drilling patterns is the assignment of the objects to specific EPLAN [layers](Glossary_o_ebenen.htm). Assign the four new EPLAN layers for the drilling pattern creation (802 - 805) to the respective CAD-specific layer names for items, [drill holes](Glossary_o_bohrungen.htm), threads and outlines on the [Layers](xdxfgui_r_ebenen.htm) tab. These layer names are defined under the menu items Options > Settings > Company > Machining > NC export DXF.

Example:

| Name (layer) | Description | CAD name |
| --- | --- | --- |
| EPLAN802 | Graphic.Drilling pattern generation.Items | Component |
| EPLAN803 | Graphic.Drilling pattern generation.Drill holes | Drilling |
| EPLAN804 | Graphic.Drilling pattern generation.Threaded holes | Thread |
| EPLAN805 | Graphic.Drilling pattern generation.Outlines | Contour |

To ensure that the DXF / DWG elements are imported in a scale of 1:1, set the Scaling factor setting on the Export tab to "1".

Precondition:

You have opened a macro project.

1. Import a DXF / DWG file: Select the menu items Page > Import > DXF / DWG, or select the menu items Insert > Graphic > DXF / DWG in order to insert the DXF / DWG graphic into a page that is already opened. In the process use the import scheme created beforehand with the assignment of the CAD layer names to the EPLAN layers for the drilling pattern creation.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The DXF / DWG graphic is inserted on a new page or one already opened.
2. Break up any [blocks](Glossary_o_bloecke.htm) that may be contained in the DXF / DWG graphic: Select the menu items Edit > Other > Break up block.
3. Check whether the outlines contained in the DXF / DWG graphic are closed.
4. Insert a drilling pattern frame that encompasses the objects intended for the drilling pattern: Select Insert > Box / connection point / mounting panel > Drilling pattern frame.

![](../Pictures/Gui/ALL/info.png)Tip

During the generation of the drilling pattern all the calculations of positions and distances of the objects involved reference the point of origin of the drilling pattern frame. The position of the point of origin in the drilling pattern frame determines the position of the point of origin in the drilling pattern to be generated. Use the Move point of origin popup menu item to change the position f he point of origin and thus to set the desired spacing between the first and all following drill holes in the drilling pattern.

1. Enter the name, a description and a directory for the [user-defined](Glossary_o_benutzerdefiniert.htm) outlines to be created in the [properties](Glossary_o_eigenschaften.htm) dialog of the drilling pattern frame.
2. Create the drilling patterns: Select the menu items Utilities > Generate drilling patterns / outlines > Automatically from macro project.
3. Select whether the process is to be applied to the complete project or only to the selected drilling pattern frame.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The drilling patterns are shown in a top view in the parts management from the imported DXF / DWG objects that are assigned to the drilling pattern frames.

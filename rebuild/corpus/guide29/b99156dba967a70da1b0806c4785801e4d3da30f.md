# P007028: The DT ID '<x>' is missing at the auxiliary function

### Cause

The specification of the DT [ID](Glossary_o_id.htm) is missing at an auxiliary function that is a [component](Glossary_o_schaltzeichen.htm) of a macro for a module. However, this information is entered at the associated main function in the macro.

### Solution

1. Locate the auxiliary function in the schematic by using the Go to (graphic) functionality from the popup menu in the Message management dialog.
2. Launch the [property dialog](Glossary_o_eigenschaftendialog.htm) of the auxiliary function.
3. Enter the DT ID <x> of the main function that is displayed in the message into the DT ID property of the auxiliary function.
4. Click [OK].
5. Then start a new check run.

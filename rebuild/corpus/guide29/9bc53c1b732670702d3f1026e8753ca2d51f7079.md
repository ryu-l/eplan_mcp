# P005033: Designation process of format group no. <x>: First assigned connection designation '<y>', last assigned connection designation '<z>' within the format group

### Description

This message appears as confirmation after each designation operation of the [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm). You receive information on the number (position) of the format group in the table of the Settings: Connection numbering dialog and also on the first and last assigned [connection designations](Glossary_o_verbindungsbezeichnungen.htm) or first and last assigned names within the format group.

![](../Pictures/Gui/ALL/note.png) Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

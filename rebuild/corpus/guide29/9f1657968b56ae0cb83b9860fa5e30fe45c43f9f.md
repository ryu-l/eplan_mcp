# P026098: The part placement collides with the airflow-specific reserved area

### Cause

A [part](Glossary_o_artikel.htm) placement [projects](Glossary_o_projekte.htm) into the airflow-specific reserved area of a climate control [component](Glossary_o_schaltzeichen.htm). As a result the air circulation in the enclosure is impaired.

### Solution

1. Locate the respective part placement in the [layout space](Glossary_o_bauraum.htm) using the Go to (graphic) function from the popup menu in the Message management dialog. You can jump to the part placement of the climate control component by using the popup menu item Go to 2nd coordinate.
2. Move the part placement so that it no longer collides with the reserved area of the climate control component.
3. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Note:

A collision does not yet exist if the airflow-specific reserved area and the part placement touch each other.

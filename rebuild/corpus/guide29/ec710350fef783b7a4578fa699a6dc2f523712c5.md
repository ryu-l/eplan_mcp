# Form for Bent Copper Rails: Principle

The form is the path along which a rectangular basic outline is moved in order to shape the bent copper rail. Generally, only rectangular [outlines](Glossary_o_konturen.htm) are shaped along a [form](Glossary_o_verlauf.htm); other cross-section [forms](Glossary_o_formulare.htm) cannot be assigned.

A form is created in the outline editor and saved under the file type Form copper (\*.fp1); only [lines](Glossary_o_leitungen.htm) and [polylines](Glossary_o_polylinien.htm) are permitted here. The form drawing must [create](Glossary_o_erstellen.htm) a continuous set of lines; it must not contain any branch or double junction. The form can be checked for this purpose. This check is also run prior to closing the form drawing.

When [placing](Glossary_o_auflegen.htm) a bent rail, a form drawing must be selected that is assigned to the rectangular cross-section of the rail [part](Glossary_o_artikel.htm).

### Position of the origin in the form drawing

The position of the origin is of special significance, which is marked by a red circle. The handle of the rail is at the origin of the form drawing when placing on a mounting surface.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

The position of the origin in the form drawing determines the handle of the copper rail.

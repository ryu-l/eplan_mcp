# Tab Image file

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a page, [form](Glossary_o_verlauf.htm), plot frame, or symbol. You have selected a file and chosen the menu item Edit > Properties, or you have double-clicked on an image file. In the Properties dialog, select the Image file tab.

On this tab you can edit the display [properties](Glossary_o_eigenschaften.htm) of an image file.

Overview of the main dialog elements:

File:

When an image file is inserted, the file name is automatically written to this field. Whether or not the path is also entered here depends on the setting you selected in the Copy image file dialog when inserting the image file:

- Keep source directory: If this option is selected, the image is a referenced image, i.e. only a reference to the image is inserted. It is not copied into the project directory and the path is also specified here.
- Copy: If this option is selected, the image is copied into the image directory specified in the [settings](Glossary_o_einstellungen.htm) and is displayed without a path.

Display size:

Here you can specify the size at which the image will be displayed. Entry can optionally be either in coordinate values or in percentages of the original size.

Keep aspect ratio:

Select this check box, so that the original ratio between height and width will be preserved on changes to the display size of the image.

Angle:

Enter an angle in order to rotate the image relative to the X axis.

# P017004: Error in DT: <x>

### Cause

You used one or more characters in the device identifier which are not permitted characters.

### Solution

#### Possibility 1

Remove the incorrect character(s) and replace them with permitted characters.

#### Possibility 2

Select the menu item Options > Settings. In the Settings <...> dialog navigate through Projects > "Project" > Devices to the DT syntax check [settings](Glossary_o_einstellungen.htm) area. Under Device tag, select the Valid special characters check box if you want to use the characters + - \_ \* ?. Select the Special text characters check box as well, if you want to allow special characters, such as umlauts, in the device identifier. Copy the characters defined as allowed into the neighboring field without adding any dividers.

Then start a new check run.

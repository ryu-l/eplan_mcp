# Aligning a Curve Run Tangentially

Using this function, both ends of a curve can be aligned tangentially to an edge. Depending on the edge selected, you can achieve different results in this way:

- A curve end is not to run toward an area vertically, but is to be aligned with the area tangentially. This [route](Glossary_o_verlegen.htm) corresponds to the mounting method in practice, that is, the routed connection is to run tangentially along the mounting surface and is attached to it by means of [cable](Glossary_o_kabel.htm) / tubing clamps.
- A curve end should enter a connection point vertically to avoid the bending of [connections](Glossary_o_verbindungen.htm) with large cross-sections.

In the following example, a curve run is to be aligned tangentially with a vertical edge in order to enter into a connection point vertically. The viewpoint is "Top".  
  
![](../Pictures/Visualisation/ALL/routing_modcurvetang1_as.png)

1. Select the Edit > Graphic > Align curve run tangentially menu [items](Glossary_o_bauteile.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The status bar shows the prompt "Select end of the curve".  
     
   ![](../Pictures/Gui/ALL/arrow.png) A red snap square is displayed on the cursor; the curve is highlighted upon touching the cursor.
2. Select the bottom end of the curve to be changed.  
     
   ![](../Pictures/Visualisation/ALL/routing_modcurvetang2_as.png)  
     
   ![](../Pictures/Gui/ALL/arrow.png) The status bar shows the prompt "Select edge for tangential alignment".
3. Select a vertical edge of an object.  
     
   ![](../Pictures/Visualisation/ALL/routing_modcurvetang3_as.png)  
     
   ![](../Pictures/Gui/ALL/arrow.png) The [form](Glossary_o_verlauf.htm) of the curve is rounded in the area of the bottom curve end, and aligned tangentially with the vertical edge.  
     
   ![](../Pictures/Visualisation/ALL/routing_modcurvetang4_as.png)  
     
   ![](../Pictures/Gui/ALL/arrow.png) You can then change further curve runs.

![](../Pictures/Gui/ALL/info.png)Tip:

If you press the [Shift] key when selecting the edge, the tangential alignment is rotated by 180°.

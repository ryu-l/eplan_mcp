# Improvements for Distributed Terminals

The following improvements for [distributed terminals](Glossary_o_teilklemmen.htm) have been realized for this version:  
- Specific logic transfer for distributed terminals  
- Error checks 007020 and 007023 take distributed terminals into consideration  
- Displaying the placement of [connection points](Glossary_o_anschluesse.htm).

### Specific logic transfer for distributed terminals

The transfer of logic information (potential, PLC [target tracking](Glossary_o_zielverfolgung.htm)) is effected automatically at the distributed terminals of the same terminal function. To this purpose the project setting Connect associated distributed terminals automatically is activated, and you do not have to carry out further [settings](Glossary_o_einstellungen.htm) for the potential transfer within the terminal. As at the device and [PLC connection points](Glossary_o_sps_anschluesse.htm) a specific transfer to designated distributed terminal connection points is now also possible at the distributed terminals.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

Distributed terminals now act like [device connection points](Glossary_o_geraeteanschluesse.htm) with regard to the logic setting. The terminal connection points can specifically transfer their potential and the PLC target tracking to specified terminal connection points within the same terminal function.

### Error checks 007020 and 007023 consider distributed terminals

By means of the error checks [007020](messages_p_007020.htm) and [007023](messages_p_007023.htm) you can determine whether the data entered at a main terminal corresponds with the data of the [part](Glossary_o_artikel.htm) stored there. These error checks have been extended and now also consider the distributed terminals. The complete terminal function is checked for a distributed displayed main terminal. In the process data that was entered at the individual terminals of the same terminal function is summarized.

This extension [reports](Glossary_o_auswertungen.htm) configuration errors that were not found by previous EPLAN versions.

### Displaying the placement of connection points

In the Edit terminal strip dialog you can show the two new columns Placement (external) and Placement (internal) in the table. In these columns the placement of the connection point in the schematic for an external / internal target to which this target is connected is displayed. This way the placements of the connected connection points of distributed terminals can.also be found. In the connection-point-oriented view the placements of the non-connected connection points are additionally output.

# Overview of EPLAN Part Properties

You can define the assignment of Festo [part](Glossary_o_artikel.htm) [properties](Glossary_o_eigenschaften.htm) to EPLAN part properties in the festo.cfg configuration file. These properties can be entered in the tabs of the EPLAN parts management.

The Help text [Parts Management: CSV Import and Export for Parts](partsmanagementgui_k_konfigurationcsvartikel.htm) contains the part properties sorted by the tab [designations](Glossary_o_bezeichnungen.htm). And in the Help text "EPLAN Properties" (under the overviews) you can have the EPLAN-internal properties for the "Part (stored)" object class sorted alphabetically.

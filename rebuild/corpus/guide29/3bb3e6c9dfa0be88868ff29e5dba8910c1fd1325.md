# Dialog Property placement

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project and either opened or created a symbol in the [symbol editor](Glossary_o_symboleditor.htm) (Utilities > Master data > Symbol > ...). Edit > Placed properties.

In this dialog you select a property placement (for example for connection point designation, connection point description, DT, function text, etc.) and specify its position, direction and format.

Overview of the main dialog elements:

Property arrangement:

In the drop-down list, different predefined assignment [configurations](Glossary_o_konfigurationen.htm) are offered for selection. These configurations are stored on the symbol with their names. Edit > Property arrangements allows you to [create](Glossary_o_erstellen.htm) own property arrangements.

---

Tab Components

In the Components tab, specify which [properties](Glossary_o_eigenschaften.htm) are placed and displayed together with the symbol. If you have selected a property, you can edit its display properties in the right side of the dialog.

---

Contact image tab

In the Contact image tab you specify whether a [contact image](Glossary_o_kontaktspiegel.htm) is displayed for the symbol. To this purpose you select the alignment of the contact image via ![](../Pictures/Gui/ALL/all_new_as.png) (New) in the dialog Generate contact image:

- In path: The contact image â depending on the selected plot frame â is displayed below or right on the page in the schematic path of the [component](Glossary_o_schaltzeichen.htm).
- On component: The contact image is displayed next to the component.

---

Property / Assignment:

If you have selected a property, you can edit its display properties in the table in the right-hand section of the dialog. The hierarchy [levels](Glossary_o_etagen.htm) Format, Text box, Alignment box, Value / unit, and Position are available for this purpose. These can be opened by clicking the ![](../Pictures/Gui/ALL/all_plussign_as.png) symbol.

To be able to edit the [settings](Glossary_o_einstellungen.htm) for the contact image in the Contact tab you must select one of the contact image alignments ("In path", "On component"). To this purpose only the hierarchy level Position is available in the symbol editor.

The settings described in the following sections are available for the display properties:

- [Display Properties: Placed Property](../../../DeviceTagGUI/Content/htm/devicetaggui_r_anzeigeeigenschaften.htm)
- [Display Properties: Contact Image](../../../DeviceTagGUI/Content/htm/devicetaggui_r_anzeigekontaktspiegel.htm)

Popup menu:

The popup menu provides - depending on the field type (date, integer, multilingual, etc.) - the following menu [items](Glossary_o_bauteile.htm):

- Popup menu items for the display of tables

![](../Pictures/Gui/ALL/note.png)Note:

Properties cannot be placed on [connection symbols](Glossary_o_verbindungssymbole.htm) (angles, T-nodes, double junctions) and existing property placements will be removed when you save / close the symbol editor. This applies especially to [connecting points](Glossary_o_anschlusspunkte.htm) that automatically possess a property placement (namely, the connection point description / designation).

# Dialog Delete revision (Change tracking)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have generated a revision and have opened a revision project (file extension \*.ell). There are [revision markers](Glossary_o_revisionsmarkierungen.htm) in the project. Utilities > Revision control > Change tracking > Delete revision.

In this dialog you can delete revision data and markers produced during [change tracking](Glossary_o_aenderungsverfolgung.htm). Depending on the selection (pages, layout spaces or project) all revision information existing there is deleted.

Overview of the main dialog elements:

Revision markers:

If this check box is selected, then all of the revision markers that were generated by change tracking are deleted. Both the marker text and the graphical marker on the page are deleted.

Revision data from change tracking:

If this check box is selected, then the revision data that was generated by change tracking is deleted. This is the information that you entered when completing pages and generating [revisions](Glossary_o_revisionen.htm) as well as revision change [formats](Glossary_o_formate.htm) that you stored on the symbol.

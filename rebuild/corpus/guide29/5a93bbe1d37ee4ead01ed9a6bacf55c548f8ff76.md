# P028026: The source and / or target segment is missing at the piping or cable planning object

### Cause

No source and/or target segment was defined in the [properties](Glossary_o_eigenschaften.htm) of a piping or [cable](Glossary_o_kabel.htm) planning object.

### Solution

1. Locate the piping or cable planning object in the pre-planning navigator using the Synchronize selection function offered by the popup menu in the Message management dialog.
2. Call up the [property dialog](Glossary_o_eigenschaftendialog.htm) of the piping or cable planning object.
3. Select a segment existing in the pre-planning in the fields Source segment and / or Target segment.
4. Click [OK].
5. Then start a new check run.

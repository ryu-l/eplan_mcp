# Displaying Links to Connection Planning Objects

The pre-planning dependencies between the different [segments](Glossary_o_segmente.htm) are made visible by means of links. In order to detect whether segments are entered as source and target segments for [cable](Glossary_o_kabel.htm) and piping [planning objects](Glossary_o_planungsobjekte.htm) in the pre-planning navigator, you can have the links to the connection planning [objects](Glossary_o_objekte.htm) displayed by means of the Tree view dialog.

The view of the tree view of the pre-planning navigator can possibly be unclear. For this reason you have the possibility to hide or display other objects displayed by default for the tree in the Tree view dialog such as [PLC addresses](Glossary_o_sps_adressen.htm), [structure boxes](Glossary_o_strukturkaesten.htm), [functions](Glossary_o_funktionen.htm), etc.

Precondition:

- You have opened a project with existing [structure segments](Glossary_o_struktursegmente.htm) and planning objects.
- You have specified source and target segments for piping and / or cable planning objects.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Pre-planning > Navigator
2. In the tree of the pre-planning navigator select the menu items Popup menu > Tree view.
3. In the Tree view dialog select the check box Links to the cable and piping planning objects.
4. If necessary, activate or deactivate other check boxes to show or hide the corresponding objects in the tree below the segments.
5. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the tree view of the pre-planning navigator, the links to the cable and piping planning objects that are entered as source and target segments for connection planning objects are displayed below the source (icon: ![](../Pictures/Gui/ALL/planninggui_link_as.png)).  
     
   ![](../Pictures/Gui/ALL/arrow.png) In accordance with your specification in the Tree view dialog, other objects (PLC addresses, structure boxes, functions, etc.) are displayed below the segments.

# Dialog Place existing interruption point

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You are in a schematic page within the graphical editor. Insert > Connection symbol > Interruption point. You have placed the interruption point, and you have clicked [...] in the Displayed DT field of the Interruption point tab in the Properties <...> dialog.
- Project data > Connections > Interruption point navigator. In the Interruption points - <Project name> dialog you have double-clicked an interruption point or selected the interruption point and then selected the popup menu  Properties. Click [...] in the Displayed DT field in the Interruption point tab in the Properties <...> dialog.

The visible name of an interruption point identifies which [interruption points](Glossary_o_abbruchstellen.htm) belong to each other: All interruption points with the same name belong together. This name can be composed of the potential names (e.g., "L1", "L+", "PE", "PEN", "N" etc.), or descriptions of the type of operation (e.g., "Not", "+15V", the signal name), or simply a combination of alphanumeric characters.

Interruption points are defined on a per-project basis by their name, e.g., every project has its own list of interruption points. When inserting interruption points into the schematic, you can thus assign an existing name to the new interruption point.

The following dialog elements are available:

List:

In the list view, the [identifier blocks](Glossary_o_kennzeichnungsbloecke.htm) used in the project (e.g., "[higher-level function](Glossary_o_anlage.htm)", "[mounting location](Glossary_o_einbauort.htm)", etc.), the device tag, and if present, the description of the source of the interruption point are displayed.

Tree:

In the tree view, the "Identifier block" and "Interruption point name" are displayed in a hierarchical structure and, among other data, information about the source and target is also displayed.

![](../Pictures/Gui/ALL/note.png) Note:

When you use an existing interruption point, and the name of the interruption point is selected, only this will be used; all other data will be ignored.  
On the other hand, if an individual function is selected, the data on the Symbol / function data and Display tabs are not changed; all existing editable [properties](Glossary_o_eigenschaften.htm) of the selected function are used, apart from the representation-specific properties from the "Settings" category and the Sort code and Star source fields.

# Tab Thread (NC Export DXF / Copper Export DXF)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

- Options > Settings > Company > Machining > NC export DXF. Select the Thread tab.
- Utilities > Manufacturing data > Machining > NC DXF. Click [...] next to the Machine field. Select the Thread tab.

In this tab, you specify the [settings](Glossary_o_einstellungen.htm) on visibility as well as [layers](Glossary_o_ebenen.htm) and colors of threads.

Overview of the main dialog elements:

Group box Format for thread

Export as circle:

During the [DXF](Glossary_o_dxf.htm) export, threads are represented as geometric shapes and assigned to specific layers and colors. If the check box is activated, the thread will be generated as the DXF element "circle with center".

Layer:

Default name of the layer where the thread is stored in the DXF file.

Color:

Default color that is assigned to the thread in the DXF file.

Export as text:

Alternatively, or in addition to the representation of a thread as a circle, you can specify text with a prefix to output the thread. If the check box is activated, the thread is characterized with the diameter. In addition, the text can be preceded by a prefix.

Layer:

Default name of the layer where the text is stored in the DXF file.

Color:

Default color that is assigned to the text in the DXF file.

Prefix:

Here you enter the string that precedes the text at the thread.

# Freezing Report Pages

You can freeze [report pages](Glossary_o_auswertungsseiten.htm) to exclude them from the update. Project data in [placeholder texts](Glossary_o_platzhaltertexte.htm) on [frozen report pages](formgeneratorgui_k_eingefrorseiten.htm) is then no longer updated. Frozen report pages and non-frozen report pages have different [icons](Glossary_o_icons.htm) in the page navigator.

Preconditions:

- You have opened a project.
- You have created report pages.

1. Utilities > Reports > Generate
2. Select the Reports tab.
3. Select a report block.
4. Select the Freeze report pages popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The report block is deleted. The report pages remain intact.

![](../Pictures/Gui/ALL/info.png)Tip:

To regenerate frozen report pages, you must first manually delete the existing report pages and then [generate](Glossary_o_erzeugen.htm) them as new pages. If you do not delete the report pages then additional report pages are generated.

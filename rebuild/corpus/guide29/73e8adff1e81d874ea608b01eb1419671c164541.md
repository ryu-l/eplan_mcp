# Export Design Space

The following section describes the third working step when using EPLAN Design Space Exchange:

- The export of the design space with added mounting layout and NC data to a 3D CAD program.

You can adjust the [settings](Glossary_o_einstellungen.htm) for the export of design spaces under Options > Settings > User > Interfaces > Design space import and export.

Precondition:

You have opened a project. The [layout space](Glossary_o_bauraum.htm) navigator is open. You have created a mounting layout in the previously imported design space.

1. In the layout space navigator, select the design space that is to be exported.
2. Select Layout space > Design space > Export.
3. In the Design space export dialog select a scheme with settings for the export of the selected design space or use [...] to open the settings dialog and change the settings.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) One STEP file each is exported for each [part](Glossary_o_artikel.htm) placed with EPLAN Pro Panel during the data export.  
     
   ![](../Pictures/Gui/ALL/arrow.png) During data export one XML file with the data of all the [objects](Glossary_o_objekte.htm) in the layout space (the objects imported from the CAD system, the objects added using EPLAN Pro Panel, the [cut-outs](Glossary_o_durchbrueche.htm) generated automatically through a part placement and manually inserted cut-outs) is created for each layout space.
5. Use the [CAD Add-ins](xdesignspaceimportgui_k_prinzip.htm#CADAddIn) to import the generated STEP files back into the 3D model in the 3D CAD program.

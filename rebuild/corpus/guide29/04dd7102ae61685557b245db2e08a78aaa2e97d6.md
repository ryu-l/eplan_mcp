# Defining the Header, Label, and Footer

You use [format elements](Glossary_o_formatelemente.htm) to specify which data is to be output in the header, labels, and footer of the export / labeling page, and how these texts are to be formatted.

Precondition:

You have opened a project.

1. Utilities > Manufacturing data > Export / labeling
2. Click [...] next to the Settings field in the dialog Export manufacturing data / output labeling.
3. Select a [user-defined](Glossary_o_benutzerdefiniert.htm) scheme or [create](Glossary_o_erstellen.htm) one in the Scheme field of the dialog Settings: Manufacturing data export / labeling.

### Selecting format elements

You select the format elements for the header, labels, and footer in the same way. Which format elements are available depends on the report type selected. The format elements "Page break" and "Page break when change of DT" are only available for the footer.

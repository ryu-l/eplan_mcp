# Improvements when Translating with Manual Selection for Terms with Multiple Meanings

If the Manual selection for terms with multiple meanings setting is activated in the project [settings](Glossary_o_einstellungen.htm) or in the user settings for the translation, a selection dialog is displayed for words that are stored multiple times with different meanings in the dictionary. With the [Cancel] button in this dialog you could previously only cancel the translation of the current text. Now the complete translation process is canceled when this button is used. To only cancel the translation of the current text, the new [Skip] button is available in the dialog.

# Manually Placing a Report in a Page

Manual placement of [reports](Glossary_o_auswertungen.htm) allows the placement of [project data](Glossary_o_projektdaten.htm) into existing pages as [Embedded reports](formgeneratorgui_k_ausgabeformen.htm).

![](../Pictures/Gui/ALL/note.png)Note:

You can only select the "Manual placement" output type for the embedded report when the desired project page is open in the graphical editor.

Preconditions:

- You have opened a project.
- You have assigned a [form](Glossary_o_verlauf.htm) to the desired report type.
- You have opened the page in the graphical editor in which you want to place the report.

1. Utilities > Reports > Generate
2. In the Reports - <Project name> dialog, select the Reports tab and click ![](../Pictures/Gui/ALL/all_new_as.png) (New).
3. Select the "Manual placement" output format from the Output format drop-down list of the Select report dialog.
4. In the Report type field, mark the report type and click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) When the Settings - Report type dialog opens, define any optional filtering and sorting and then click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The report hangs on the mouse pointer.
5. Position the mouse pointer at the location on the page where the report should be placed.
6. Click the left mouse button.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The report is inserted in the page.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The report is listed under the Utilities > Reports > Generate menu [items](Glossary_o_bauteile.htm) in the report overview as an "embedded report".

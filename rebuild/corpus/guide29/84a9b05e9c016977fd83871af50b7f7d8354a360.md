# Project Verification: Procedure

The project verification consists of the following steps:

- [Generate reference project](revisionmgtgui_h_vergleichsprojekterzeugen.htm): Using your unchanged original project, you [generate](Glossary_o_erzeugen.htm) a completed EPLAN project (\*.elr) as a reference project. You can also use standard EPLAN [projects](Glossary_o_projekte.htm) (\*.elk) as [reference projects](Glossary_o_referenzprojekte.htm).
- You send your original project to other project participants to be edited and receive it from them again in an advanced state as an incoming project. You can use the project verification to check whether your own project fulfills the specified standards.
- [Create settings comparison scheme](processreceiptcontrol_h_vergleichsschema.htm): You specify which project-related [settings](Glossary_o_einstellungen.htm) from both projects should be compared by EPLAN and save these requirements in a scheme.
- [Create properties comparison scheme](processreceiptcontrol_h_eigenschaftenvergleich.htm): You specify which [properties](Glossary_o_eigenschaften.htm) from both projects should be compared by EPLAN and save these requirements in a scheme.
- [Create check run scheme for project verification](processreceiptcontrol_h_pruefschema.htm): You specify which [check runs](Glossary_o_prueflaeufe.htm) EPLAN should perform during the project verification and save these requirements in a scheme.
- [Verify project](processreceiptcontrol_h_eingangskontrolvorber.htm): You check whether the incoming project fulfills your specified requirements.
- Show results: After checking the project, EPLAN displays the results automatically in the Project verification: Results dialog and in message management. The results are then in the incoming project. You can copy the results from message management into another application using copy & paste.

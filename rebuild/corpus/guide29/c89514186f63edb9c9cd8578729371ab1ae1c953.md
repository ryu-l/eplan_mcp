# Routing Paths (Topology): Principle

Generally, a routing path network can be drawn on any page type. But using the "Topology" page type has the advantage that the [symbols](Glossary_o_symbole.htm) placed there are assigned the "Topology" representation type automatically. There is no [autoconnecting](Glossary_o_autoconnecting.htm) on [topology](Glossary_o_topologie.htm) pages.

A routing path network is structured via the identifier structure (for pages, [devices](Glossary_o_betriebsmittel.htm), etc.). For example, you can assign each routing path network a separate [mounting location](Glossary_o_einbauort.htm) by dividing the project pages accordingly and, if necessary, using [structure boxes](Glossary_o_strukturkaesten.htm).

![](../Pictures/Gui/ALL/info.png)Tip:

It is possible for you to insert image files (e.g., an imported [DXF](Glossary_o_dxf.htm) / [DWG](Glossary_o_dwg.htm) file) as a background image. For this purpose, the layer management comes with the Background setting. Elements on such a layer are always right at the bottom, i.e. also behind the autoconnect [lines](Glossary_o_leitungen.htm). An imported DXF / DWG drawing placed in the background can thus be used as a basis for the routing path network in the topology.

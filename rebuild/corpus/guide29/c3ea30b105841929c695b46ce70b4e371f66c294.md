# Dialog Select

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. In the Addresses / assignment lists dialog, you have imported or created an assignment list.

- You have selected multiple [PLC connection points](Glossary_o_sps_anschluesse.htm) in the graphical editor or in the navigator dialog PLC - <Project name> or in the navigator dialog Devices - <Project name>. Or you have selected one or more pages or a project in the Pages - <Project name> navigator dialog. Project data > PLC > Use existing addresses blockwise.
- You have opened the Use existing PLC addresses blockwise dialog. Click [...] on the toolbar.
- You have opened the Properties <...> dialog for one or more PLC [connection points](Glossary_o_anschluesse.htm). In the PLC connection point dialog, next to the Address field, click [...].

In this dialog, the [PLC addresses](Glossary_o_sps_adressen.htm) of the current assignment list are displayed and can be selected for re-use. Both free addresses and those already in use can be reused.

Overview of the main dialog elements:

Filter:

This drop-down list displays all the available [filters](Glossary_o_filter.htm). A chosen filter is activated automatically. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the [Filter](modaldialogsdb_d_filternnach.htm) dialog. Here you can [create](Glossary_o_erstellen.htm), edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

- Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
- Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

The filter with which you can limit the display of the PLC addresses to a specific range, for example to all addresses of a specific CPU.

Table:

The free addresses of the assignment list are displayed, ordered by CPU, symbolic address, and function text. You can select multiple addresses.

If an address is already used, the DT (identifying) column shows the DT and the Connection point designation (with plug designation (automatic)) column shows the plug designation (if existing) and the connection point designation of the PLC connection point.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

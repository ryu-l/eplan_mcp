# Dialog Format: Separator (numbering of the revision index)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Options > Settings > Company > Management > Change tracking (numbering of the revision index). In the dialog Settings: Change tracking (numbering of the revision index), in the Available format elements list, select a format element of type 'Separator' and click on ![](../Pictures/Gui/ALL/all_arrowright_as.png) (Move to the right) (or double-click an already defined [separator](Glossary_o_trennzeichen.htm) in the Selected format elements list).

In this dialog you specify the formatting for a separator in the format group.

Overview of the main dialog elements:

You can specify the following characters as separators:

- Blank
- Other characters: After selecting this option, enter the desired character combination in the input field. Any digits, letters, and special characters can be used, with the exception of #, < and >. However, these can be entered with a preceding slash (\).

Number of characters:

If you have selected a space as a separator you can specify the number of characters here. If you select Other characters this field is grayed out and displays the specified number of characters.

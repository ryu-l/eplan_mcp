# P026096: The additional length of the fitting is equal to 0

### Cause

You have placed a 3D macro of a fitting in the [layout space](Glossary_o_bauraum.htm). The [additional length](Glossary_o_zusatzlaenge.htm) has the value "0" in the connection point pattern of the graphical macro.

### Solution

1. Locate the 3D macro in the layout space using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Enter a value that is greater than 0 in the connection point pattern of the 3D macro.
3. Then start a new check run.

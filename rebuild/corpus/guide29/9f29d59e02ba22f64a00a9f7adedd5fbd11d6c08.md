# Checking Outlines

A geometric test is available to check at any time during outline editing whether your outline is correct or there are errors. Depending on the file type (outline type) used, this check performs the following routines:

Geometric check for the Outline extrusion type:

- Use of illegal elements
- Existence of at least one closed outline
- All existing [outlines](Glossary_o_konturen.htm) are closed and do not contain any duplicate elements
- No nested inner outlines.

Geometric check for the Outline NC record generation type:

- Use of illegal elements
- Existence of exactly one closed outline which does not contain duplicate elements
- No nested inner outlines.

Preconditions:

- You have opened a project.
- You have opened the outline that you want to edit in the outline editor (Utilities > Master data > Outline (...) > Open > [Open]).

1. Utilities > Check outline
2. Confirm the message in the Check outline dialog by clicking [OK].
3. Select the Utilities > System messages menu [items](Glossary_o_bauteile.htm).
4. Click [Save] in the System messages dialog.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The [system messages](Glossary_o_systemmeldungen.htm) applicable to the current outline are saved to the system messages file, and can be printed as required.

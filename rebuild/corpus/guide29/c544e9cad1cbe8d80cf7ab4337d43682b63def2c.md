# Tab Piping definition

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- You have selected a piping definition point or a piping connection point in the graphical editor. Edit > Properties. In the Properties <...> dialog, select the Piping definition tab.
- Insert > Piping definition point or Insert > Piping connection point. In the Properties <...> dialog, select the Piping definition tab.

In this tab you can set the [properties](Glossary_o_eigenschaften.htm) of a piping definition point or piping connection point.

Overview of the main dialog elements:

Piping name:

Enter the name for the piping here.

Pipe class:  
Substance:

Enter the name for the pipe class / substance here. Use [...] to open a selection dialog in which the pipe classes or substances managed in the dialog Segment templates - <Project name> are offered for selection.

State (substance):

Here you enter the state for the selected substance or select an entry from the drop-down list. The list shows all values that you have previously entered for the substance at other places in the project.

Cross-section / diameter:  
Cross-section / diameter unit:

The connection cross-section or diameter is adopted from the parts management and can be used as filter criteria when selecting [devices](Glossary_o_betriebsmittel.htm). Click [...] to launch the Cross-sections / diameters dialog and select a cross-section / diameter from the list.

If you selected a predefined cross-section / diameter from the Cross-section / Diameter field, the associated unit is automatically transferred to the Cross-section / diameter unit field. Use the drop-down list to select another unit. An overview of the possible units can be found in the section "[Connections: Units for Lengths and Cross-sections](connectionbrowsergui_k_einheitenverbindungen.htm)".

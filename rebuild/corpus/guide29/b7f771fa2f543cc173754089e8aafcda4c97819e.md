# P008003: The dictionary language '<x>' does not exist in the dictionary

### Cause

The dictionary language was removed from the dictionary.

### Solution

Add the missing language to the dictionary. Select Utilities > Translation > Edit dictionary. In the Dictionary click ![](../Pictures/Gui/ALL/all_new_as.png) in the Management tab. Highlight the dictionary language you want, close the dialog and translated the texts you want.

Then start a new check run.

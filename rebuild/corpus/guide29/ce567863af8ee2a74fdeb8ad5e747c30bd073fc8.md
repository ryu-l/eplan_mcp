# Master Data

Managing [master data](Glossary_o_stammdaten.htm) is especially important for supplier relationships and data exchanges. It is therefore possible to group all of the master data by way of the end customer in turn making it easier to sort through the information.

The term "Master data" here includes all "auxiliary data" generated outside of the project for use within the project.

In EPLAN the following data belong to the master data:

- Symbols
- Plot frames
- Reporting [forms](Glossary_o_formulare.htm)
- Macros
- Project templates and [basic projects](Glossary_o_basisprojekte.htm)
- Foreign language database
- Parts data, including [device definitions](Glossary_o_geraetedefinitionen.htm) etc.
- Function definitions
- Image files
- [DXF](Glossary_o_dxf.htm) / [DWG](Glossary_o_dwg.htm) files
- EPLAN-specific rights database.

This data is managed in specific directories that you can initialize under Options > Settings > User > Management > Directories.

# Form Functions

In addition to the text, there are two types of graphics in the report lists:

- Generated graphics
- Symbol graphics

### Generated graphics

Generated graphics only occur as jumper graphics in the following [reports](Glossary_o_auswertungen.htm):

- Terminal diagram
- Terminal bill of materials
- Terminal connection diagram

The graphics in the connection diagram are generated in the following manner: In the [form](Glossary_o_verlauf.htm), particular placeholder [properties](Glossary_o_eigenschaften.htm) (Graphic for ... jumpers properties) are placed at the positions where the base of the "jumper legs" should be located. During the report run, special terminal properties are placed at these points, which contain the jumper information among other values. In a subsequent run, exactly this text is replaced by the suitable jumper graphic. The exact representation of the graphic is determined by the placeholder properties and some form properties.

### Symbol graphics

Symbol graphics can be used in any diagram, whereby particular placeholders are not replaced with text during the report run, but rather with symbol graphics in the form of graphical [symbols](Glossary_o_symbole.htm) or item references (Symbol graphic property, <13049>). The symbol graphic is always obtained from the indirectly referenced object, i.e. exactly the same graphic as in the item is used.

# Exporting 3D Graphic Data in STEP Format

The STEP export writes the faceted geometry of a [layout space](Glossary_o_bauraum.htm)'s 3D bodies into a file in the STEP format. Information on analytic surfaces or volumes is not transferred. The exported data can be imported into external CAD systems and be visualized there. The models are used as 3D [macros](Glossary_o_makros.htm) or [items](Glossary_o_bauteile.htm) for placement in Pro Panel [projects](Glossary_o_projekte.htm) on the basis of the STEP import of edited 3D bodies.

You can adjust the [settings](Glossary_o_einstellungen.htm) for the STEP export under the menu item Options > Settings > User > Interfaces > STEP export.

Precondition:

You have opened a project. The layout space navigator is open.

1. In the layout space navigator, select the layout space whose content is to be exported.
2. Select the following menu items: Layout space > Export > STEP
3. In the STEP export dialog enter a name for the STEP file to be generated, or use the [...] button to define a directory and file name.
4. Click [OK].

# Macros

Working with [macros](Glossary_o_makros.htm) provides you with the following advantages:

- You repeatedly want to use [cut-outs](Glossary_o_durchbrueche.htm) of your schematic, including the graphics, but not always the same data and parts.
- You want to save partial schematics under specific names in order to use them later.
- You want to store records ([variants](Glossary_o_varianten.htm) i.e., value tables for technical data and parts) in the macros in order to avoid having to revise macros after inserting them in the schematic. To do this, [placeholder objects](Glossary_o_platzhalterobjekte.htm) can be defined for all kinds of data in a macro.
- You can [create](Glossary_o_erstellen.htm) [macro projects](Glossary_o_makroprojekte.htm) and define [macro boxes](Glossary_o_makrokaesten.htm). The latter enable you to automatically [generate](Glossary_o_erzeugen.htm) [window macros](Glossary_o_fenstermakros.htm), for example.

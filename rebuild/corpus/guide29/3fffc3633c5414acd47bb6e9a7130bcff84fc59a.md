# Dialog Settings: Device selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.

- Options > Settings > Projects > "Project name" > Management > Device selection.
- You have selected a main function in the graphical editor or in a navigator. Edit > Properties. Select the Parts tab. [Settings] > Device selection (or [Device selection] > [Settings]).

In this dialog, you determine the [settings](Glossary_o_einstellungen.htm) for device selection.

Device selection normally offers only parts which have an "appropriate" or a "larger" set of [function templates](Glossary_o_funktionsschablonen.htm) than needed. The check for matching [functions](Glossary_o_funktionen.htm) can be turned off by turning off all selection criteria. In this case, all available parts are displayed.

Overview of the main dialog elements:

Selection list:

Select an existing scheme (a list of parts) from the drop-down list. Then only those parts are offered during [part](Glossary_o_artikel.htm) selection that are contained in the selected list.

With [...] the Parts preselection dialog opens and you can [create](Glossary_o_erstellen.htm) a new list of parts to save it as a scheme or change an existing list.

Automatic device selection:

If this check box is selected, during the device selection the data of the part entered for the function is compared against the criteria set for the device selection. The Device selection dialog is only opened if a new device selection is required (because an error such as over-allocation has been found) or if no part has been entered at the function yet. If on the other hand the part meets the criteria set for device selection, the Device selection dialog is not opened. If you are carrying out a device selection for multiple [devices](Glossary_o_betriebsmittel.htm), then the devices to which an appropriate part has already been assigned are skipped.

If an appropriate part has already been entered at a function but the technical data for the part is missing (e.g. because the part number was entered manually or via external editing), then this part data is automatically added during device selection. The data for the function templates stored at the parts is also transferred.

If the check box is not selected, the Device selection dialog is opened for all selected devices, regardless of whether an appropriate part has already been assigned. The automatic addition of technical data for an existing part is not possible in this case.

Only consider main function:

Select this check box to have all parts offered that match the selected main function, regardless of which [auxiliary functions](Glossary_o_nebenfunktionen.htm) are available. This setting can be useful for devices with a modular structure, for example.

If the check box is deactivated, only those devices are offered that cover all the functions, meaning both the main function as well as all the auxiliary functions. This means that the device selection only offers such parts with which all the functions of the device, whether with or without [accessories](Glossary_o_zubehoer.htm), can be covered through function templates. No parts are offered with which the functions of the device cannot be realized. It is irrelevant whether one or more accessory parts are required or not.

Minimize unused functions:

Select this check box to have only devices offered that have at most the given number of free functions (e.g. functions unused in the device). This number is entered in the Number of unused functions field.

Display even if only one part matches:

Select this check box to have the Device selection dialog displayed in all cases.  
If the check box is deselected, then the part is immediately accepted if only one part number (i.e. a device type) matches the device.

Overwrite old parts with current selection:

If this check box is selected, a [main part](Glossary_o_hauptartikel.htm) can be selected in the Device selection dialog with a single click. A part existing in the list Selected parts: Functions / templates is deleted and is replaced by the main part. The same applies when selecting an accessory. As soon as a part number is entered for an accessory, you can also select the accessory with just a single click. When you apply the selection, the parts at the [component](Glossary_o_schaltzeichen.htm) are replaced.  
If the check box is deselected, new parts are attached to those already selected.

Change symbol if function differs:

If this check box is selected then when a device is selected the symbol is swapped if the part has a different function definition. The symbol used is the same as that used when [placing](Glossary_o_auflegen.htm) the corresponding function. If a symbol is entered for the part in a function template, then this symbol is used.

Selection criteria

Use available function data:

Select this check box in order to [use existing](Glossary_o_abbuchen.htm) data from the functions as selection criteria. On the following tabs you can define the criteria for individual [product groups](Glossary_o_produktgruppen.htm) in more detail by selecting the relevant check box.  
If the check box is deselected, existing data from the functions is ignored in the selection. The check boxes in the subsequent tabs are then grayed out.

In the individual tabs, select the desired check boxes for each of the product groups, so that the relevant property data is used as the selection criteria. Then, only devices will be offered that match the values of these [properties](Glossary_o_eigenschaften.htm). Once you have selected a device, suitable function templates will be assigned to the individual functions based on the selection criteria determined here. Note that only the values of the activated properties will be retained at the functions. Values of deactivated properties will be overwritten with the values from the function templates.

![](../Pictures/Gui/ALL/note.png)Notes:

- If you activate the Potential type check box here in the Cable / Conduit tab, only the [potentials](Glossary_o_potenziale.htm) "N", "PE" / "PEN" and "SH" are taken into consideration in the device selection.
- If you activate the check box Pipe class here in the Process engineering tab and have selected a pipe class for a device in the [P&I diagram](Glossary_o_ri_fliessbild.htm), only those parts that are stored at the pipe class are taken into consideration during the device selection. The same applies in the device selection for [connections](Glossary_o_verbindungen.htm) if the Pipe class check box that is available in the Connection tab is activated.

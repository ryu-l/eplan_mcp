# Connection Numbering

Connection numbering allows you to automatically assign [connection designations](Glossary_o_verbindungsbezeichnungen.htm). It is also possible to manually enter the connection [designations](Glossary_o_bezeichnungen.htm).

The main types of numbering are the potential-oriented allocations and the connection-oriented allocations of designations.

Connection numbering offers you the following options:

- Manually preallocated and automatically assigned connection designations can be used together in a project.
- You can exclude individual [connections](Glossary_o_verbindungen.htm) from the numbering and freely position the connection designation on the connection (subsequently).
- Connection designation formatting is flexible. The designation is not limited to only numbers, but may also contain letters and special characters.
- In addition to being displayed in the schematic, connection designations can also be output as lists and in [forms](Glossary_o_formulare.htm). These output options can be used in label printing machines or for tags as well as for connection lists used in assembly operations.

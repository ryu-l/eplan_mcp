# Dialog Print preview

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Project > Print > [Print preview].

In this dialog you see a print preview of the selected pages. The display corresponds to the output on the printer, including the position on the paper. For color printing, all of the elements are displayed using the "Colored on white" color scheme; for black and white printing, all of the elements (except image files) are shown in black, on a white background.

The following dialog elements are available:

The name of the currently displayed page is shown in the title bar of the dialog.

Is included in print job:

This check box indicates whether the page will be printed. If in the Print dialog you have selected the Changed pages only option, then the selection may contain pages that have not changed since the last printout and these will therefore not be printed. The check box is deselected for these pages.

[Back] / [Next]:

You can use these buttons to sort through the pages that are selected for printing.

[Print]:

Starts the print process immediately.

[Close]:

Exits the print preview and returns to the Print dialog.

# P024014: Conduit length not specified

### Cause

The conduit length value is not specified at the main function of the conduit.

### Solution

1. Locate the main function of the conduit in the schematic from the Message management dialog using the Go to (graphic) functionality.
2. Then double-click the selected [cable](Glossary_o_kabel.htm) definition line and call up the Properties <...> dialog for the conduit.
3. If not already set by default, switch to the Conduit / line tab and enter a value in the Length field.
4. Click [OK].
5. Then start a new check run.

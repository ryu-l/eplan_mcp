# Editing Terminal Data

You can edit terminal and terminal strip [properties](Glossary_o_eigenschaften.htm) at a variety of locations:

- In the Properties <...> dialog you edit data for the selected terminal strip or the selected terminals.
- The terminal strip navigator (Terminal strips - <Project name> dialog) shows you an overview of all the terminal strips and terminals in the open project. You can select one or more terminals or terminal strips here. Use the popup menu to [generate](Glossary_o_erzeugen.htm) terminals and terminal strips or call up the appropriate dialog for editing them. In the device-oriented view you can recognize immediately which terminals belong to a terminal device (for example to a multi-level terminal).
- The Edit terminal strip dialog displays all the terminals in a terminal strip with all the targets and jumpers. Use the popup menu to call up the various editing [functions](Glossary_o_funktionen.htm) for numbering or moving terminals. There is also a button for sorting terminals.

![](../Pictures/Gui/ALL/info.png)Tip:

When you have opened the graphical preview, the placements of the terminals marked in the dialog Edit terminal strip are displayed there. This allows you, for example to rapidly recognize the terminals that are jumpered with each other. If a terminal occurs in several [representation types](Glossary_o_darstellungsarten.htm), all the pages / layout spaces in which this terminal is placed are displayed in the preview.

### Numbering

Terminals can be numbered using a special terminal numbering which offers extra [settings](Glossary_o_einstellungen.htm) for assignment of the [terminal designations](Glossary_o_klemmenbezeichnungen.htm). Only the DT of the terminal strip can be numbered using the "normal" DT numbering.

When copying and pasting terminals, these are automatically numbered according to the settings for [online numbering](Glossary_o_onlinenummerieren.htm).

# P005074: Different connection point cross-section / diameter of connection and connecting point

### Cause

One or several [connection points](Glossary_o_anschluesse.htm) of [functions](Glossary_o_funktionen.htm) are connected to a connection. The connection point, or at least one of several connection points, has a different value than the connected connection in terms of the connection point cross-section or diameter.

### Solution

1. Enter both on the connection points of all functions and on the connected connection the same value for the connection point cross-section or diameter.
2. Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

# Find and Replace

When planning a project and comparing [revisions](Glossary_o_revisionen.htm) it is often necessary to find specific information within a project in order to make further changes. The following is possible:

- You can search for text, device tags, [symbols](Glossary_o_symbole.htm), cables, [cable connections](Glossary_o_kabelverbindungen.htm), [potentials](Glossary_o_potenziale.htm), [macros](Glossary_o_makros.htm), [master data](Glossary_o_stammdaten.htm), page header data, project header data, [properties](Glossary_o_eigenschaften.htm) (format data), etc. in the entire project or on specific pages.
- Placeholders can be used within searches.
- Structure identifiers are also included within searches.
- Invisible [objects](Glossary_o_objekte.htm) and [layers](Glossary_o_ebenen.htm) are also taken into consideration within searches.
- The results of a search are written to [lists of results](Glossary_o_ergebnislisten.htm). The following [actions](Glossary_o_aktionen.htm) are possible based on these lists: As a result, for example, the Properties dialog for a selected object can be open and its properties edited.
- You can synchronize the displays of open [navigators](Glossary_o_navigatoren.htm).

# Offline Numbering of Fluid DTs (DIN ISO 1219-2)

For fluid [devices](Glossary_o_betriebsmittel.htm), use a standardized identifier structure according to DIN ISO 1219-2; this allows the [offline numbering](Glossary_o_offlinenummerieren.htm) to increment the item number in the DT.

Preconditions:

- You have opened a project.

- The project was created by using the project template `FL_1219-2_tpl001` . This project template has the effect that fluid device tags are structured to DIN ISO 1219-2 with a trade-specific Media code, a Circuit number and an Item number.
- The project contains one or more schematic pages of the type "Fluid power schematic" with fluid devices that are identified in accordance with the standard.

1. Select several fluid devices on a schematic page, or select several schematic pages from the page navigator, or select the project.
2. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Devices > Number.
3. Define with which value the item number of the respective fluid DTs is to start during offline numbering as well as the increment (difference between two consecutive numbers) in the Start value and Increment columns of the dialog [Numbering (offline)](offlinenumerationgui_d_nummerieren.htm).
4. Click [OK].

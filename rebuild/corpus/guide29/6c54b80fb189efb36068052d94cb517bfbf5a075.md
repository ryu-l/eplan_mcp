# P001023: Main terminal is not assigned to the first function template

### Cause

A main terminal is assigned to one of the following [function templates](Glossary_o_funktionsschablonen.htm) of the selected [part](Glossary_o_artikel.htm), rather than to the first function template.

### Solution

#### Possibility 1

Make another terminal the main terminal if there is already an assignment to the first function template.

#### Possibility 2

Select another terminal part for which it is guaranteed that the main terminal can be allocated to the first function template.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

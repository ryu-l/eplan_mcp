# Using User-Defined Property Arrangements

The property arrangement specifies the arrangement of the placed [property texts](Glossary_o_eigenschaftstexte.htm) and their display [settings](Glossary_o_einstellungen.htm) at a function. The settings for the [contact image](Glossary_o_kontaktspiegel.htm) are also stored at the property arrangement.

The [user-defined](Glossary_o_benutzerdefiniert.htm) property arrangements are saved project-specifically and are assigned to the symbol variant for which it was created. Therefore such a property arrangement is only available for [functions](Glossary_o_funktionen.htm) with the same symbol variant. For [part placements](Glossary_o_artikelplatzierungen.htm) in the [layout space](Glossary_o_bauraum.htm) the property arrangements are assigned to the function definition and are correspondingly available for [part](Glossary_o_artikel.htm) placements with the same function definition respectively.

You can [create](Glossary_o_erstellen.htm) user-defined property arrangements both at the components or at the 3D part placement itself or at the configuration in the configuration dialog.

The configuration dialog [Configure property arrangements](eservicesgui_d_konfigeigenschaftsanordnungen.htm) provides an overview of all the property arrangements available in the project. This dialog allows you to export the property arrangements of several selected part placements or components and to import them into another project. In addition you have the possibility to verify the usage of the user-defined property arrangements and to remove property arrangements not used.

### [ClosedCreating property arrangements at components](javascript:void(0);)

Precondition:

You have opened a project.

1. Select a [component](Glossary_o_schaltzeichen.htm) in the graphical editor or a function in a [project data](Glossary_o_projektdaten.htm) navigator. Or select a part placement in a layout space.
2. Select the menu item Edit > Properties.
3. In the Properties <...> dialog, select the Display tab.
4. Select the "User defined" entry from the Property arrangement drop-down list and edit the property arrangement.
5. Use the ![](../Pictures/Gui/ALL/all_new_as.png) (New) and ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) buttons to add further [properties](Glossary_o_eigenschaften.htm) to the list or remove unnecessary ones.
6. Use the buttons ![](../Pictures/Gui/ALL/all_cut_as.png) (Cut) or ![](../Pictures/Gui/ALL/all_copy_as.png) (Copy) to cut or copy the properties selected in the list together with their set display properties. At a different component these properties can be inserted below the selected property into the list of the other property arrangement by using the button ![](../Pictures/Gui/ALL/all_paste_as.png) (Paste). Properties that cannot be used at a component are not taken into consideration during pasting. (Through such an action the property arrangement is set to "user-defined" at the target component.)
7. In the list of properties, select the property for which you would like to define the display settings. The default values for the individual fields are taken from the "Default setting".
8. Edit the display properties in the [Property / Assignment](devicetaggui_r_anzeigeeigenschaften.htm) table.
9. Click ![](../Pictures/Gui/ALL/all_save_as.png) (Save).
10. Enter the name for the property arrangement in the [Save property arrangement](devicetaggui_d_eigschanordnungspeichern.htm) dialog or select an existing name from the drop-down list.
11. Activate the Use as default check box if you want to specify the property arrangement as the default for all further usages of this symbol variant (at functions) / function definition (at part placements).
12. Confirm your entries.  
      
    ![](../Pictures/Gui/ALL/arrow.png) The property arrangement is stored and is assigned to the symbol variant. At part placements the property arrangement is assigned to the function definition.  
      
    ![](../Pictures/Gui/ALL/arrow.png) If you have defined the property arrangement as the default, this is used by default for the corresponding symbol variant, for example when inserting a symbol. At part placements the property arrangement is used by default for the corresponding function definition.

![](../Pictures/Gui/ALL/info.png)Tip:

You can use the ![](../Pictures/Gui/ALL/all_export_as.png) (Export) and ![](../Pictures/Gui/ALL/all_import_as.png) (Import) buttons to export the stored user-defined property arrangements of a symbol variant and to import them into a different project.

### [ClosedCreating property arrangements in the configuration dialog](javascript:void(0);)

Precondition:

You have opened a project.

1. Select the menu [items](Glossary_o_bauteile.htm) Project data > Configure property arrangements.
2. In the tree mark an existing hierarchy level or an existing property arrangement.
3. In the dialog Configure property arrangements - <Project name> click the button ![](../Pictures/Gui/ALL/all_new_as.png) (New).  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected a function definition, a symbol variant or the property arrangement of a function definition or symbol variant, the dialog New property arrangement is opened.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have selected a higher hierarchy level in the tree, the marked position is used as a filter for the subsequently opened dialog Function definitions or Symbol selection. After the selection of a function definition or of a symbol the dialog New property arrangement is also opened.
4. Enter a unique identifying name in the dialog New property arrangement.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The identifying name cannot be changed later on.
5. In the Displayed name field enter the name under which the property arrangement is displayed in the project. Multi-lingual entry is possible.
6. Activate the Default check box if the property arrangement is to be used as the default at all further usages of the 3D part placement / symbol variant.
7. To select the properties in the respective tab 3D functions or Component, etc. click the button ![](../Pictures/Gui/ALL/all_new_as.png) (New).
8. Specify the display settings for the selected properties in the table Property / Assignment.
9. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property arrangement is stored and is assigned to the symbol variant. At part placements the property arrangement is assigned to the function definition.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If you have defined the property arrangement as the default, this is used by default for the corresponding symbol variant, for example when inserting a symbol. At part placements the property arrangement is used by default for the corresponding function definition.

![](../Pictures/Gui/ALL/info.png)Tip:

You can use the popup menu items Copy / Cut and Paste to transfer the property arrangements from a symbol variant or function definition into a different symbol variant or function definition. Properties that cannot be used at a component or a function definition are not taken into consideration during pasting. A transfer of property arrangements between the areas "Part placement (3D)" and "Component" is not possible.

### [ClosedAlternative possibilities for the assignment of property arrangements](javascript:void(0);)

You can specify a property arrangement for a component or a part placement in the Display tab in the [property dialog](Glossary_o_eigenschaftendialog.htm) by using the drop-down list Property arrangement. Alternatively you have the following options:

- When editing functions in tables you can display the Property arrangement column and select a property arrangement from the drop-down list. The list contains all the property arrangements that are available for the respective symbol variant.
- When creating [schemes](Glossary_o_schemata.htm) for external editing, you can select the property arrangement in the Settings: External editing dialog as format element, thereby considering the respective data during export and import.
- In the property dialog of [placeholder objects](Glossary_o_platzhalterobjekte.htm) you can use the property Property arrangement ([ID](Glossary_o_id.htm) 19307) and assign the user-defined property arrangements as value sets via a variable. The corresponding property arrangements have to exist in the project to this purpose.
- You can also assign existing property arrangements through a user-defined button in the toolbar. To do so use the Customize dialog to select the action XEsSetPropertyAction and use the ID 19307 of the Property arrangement property as the value for the PropertyId parameter.

### [ClosedReset property arrangements](javascript:void(0);)

Preconditions:

- You have opened a project page in the graphical editor.
- You have created at least one user-defined property arrangement.

1. Select one or more functions that use a user-defined property arrangement in the graphical editor or in a project data navigator. Or select a part placement in a layout space.
2. Select the menu item Edit > Text > Reset property arrangement.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The property arrangement is reset to the default setting for the selected functions / part placements. This is either the setting "Default setting" or the property arrangement that you have specified as the default.

![](../Pictures/Gui/ALL/info.png)Tip:

You can also restore the default settings directly in the property dialog. In the Display tab, select the "Default setting" entry from the Property arrangement drop-down list; all your settings will then be replaced by the defaults.

![](../Pictures/Gui/ALL/note.png)Notes:

- When you overwrite a user-defined property arrangement, the modified display settings are transferred automatically to all the functions / part placements that use this property arrangement. This behavior also applies to the importing of property arrangements. If you overwrite one or more property arrangements during importing, the modified display settings are also automatically transferred to all the functions / part placements that use the property arrangements.
- During the copying and pasting of pages, layout spaces, functions or part placements into a different project or when inserting [macros](Glossary_o_makros.htm), the user-defined property arrangements are compared. The name of the property arrangement at the function / part placement is retained if the property arrangements are identical or if the property arrangement does not yet exist in the project. If a property arrangement with the same name already exists in the project and is not identical with the property arrangement at the function / part placement, the project setting [Apply property arrangements from the project](gedviewer_d_einstellungenprojektallgemein.htm#EigenschaftsanordnungenAusProjekt) decides which property arrangement is to be used.
- The property selection is opened through the ![](../Pictures/Gui/ALL/all_edit_as.png) (Edit) button. This makes it possible to replace a property in the property arrangement by another one (for example the property DT (displayed) by the property DT (full)).

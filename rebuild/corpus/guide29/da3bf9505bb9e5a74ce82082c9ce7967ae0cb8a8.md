# Tab BMEcat Data Field Assignment

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

Utilities > Parts > Management > [Extras] > Import. You have selected the entry for an [eCl@ss](Glossary_o_eclass.htm) version in the File type field and select an XML file with the parts records in the File name field and clicked [OK]. In the eCl@ss import dialog click the [...] button next to the Settings field and select the BMEcat data field assignment tab.

Here you can assign some fixed [BMEcat](Glossary_o_bmecat.htm) fields for which an eCl@ss property does not exist or that are normally saved separately in a BMEcat field to the [part](Glossary_o_artikel.htm) [properties](Glossary_o_eigenschaften.htm) of the parts management. User-defined properties and free properties are not available for selection because no (multilingual) eCl@ss property name exists. To allow the importing of such data a special treatment for some fixed BMEcat fields is available here.

Overview of the main dialog elements:

BMEcat field:

The contents of these fields are taken from the BMEcat file and cannot be changed.

Part property:

Click the [...] button in these fields and select the property that you want to assign to the BMEcat field in the Property selection dialog.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu [items](Glossary_o_bauteile.htm) that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section [Popup menu items](userinterface_m_kontextmenu.htm).

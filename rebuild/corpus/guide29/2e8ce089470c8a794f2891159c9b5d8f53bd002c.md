# P004202: Siemens: Incorrect bus port: <x>

### Cause

EPLAN has determined a faulty bus port. Which PLC card is affected and which [properties](Glossary_o_eigenschaften.htm) of the bus port may have to be corrected is specified in the placeholder "<x>" of the message.

### Solution

1. Locate bus port in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the bus port.
3. Bring the PLC connection point tab to the front.
4. Check the value of the Plug designation property and correct it if necessary.
5. Bring the Bus data tab to the front if errors in further properties apart from the plug designation are reported.
6. Check the values of the properties specified in the message text and correct these (for example for the property Bus system or Bus interface: Name) if necessary.
7. Click [OK].
8. Then start a new check run.

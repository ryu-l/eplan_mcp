# Dialog XML project

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

There is (at least) one project with the \*.epj file name extension present, that was previously exported.

- Project > Organize > Import. In the Import project dialog, select a file and click [Open].
- You have opened the project management. [Organize] > Import. In the Import project dialog, select a file and click [Open].

In this dialog you define the [settings](Glossary_o_einstellungen.htm) for the XML import of a project.

The following dialog elements are available:

XML file:

Enter the drive, directory, and name here for the XML file to be imported, or click [...] to select the file interactively.

Using Popup menu > Insert path variable you branch to the [Select path variable](modaldialogsdb_d_pfadvariablen.htm) dialog, where you can select one of the available EPLAN-specific [path variables](Glossary_o_pfadvariablen.htm).

Synchronize parts:

Select this check box if automatic parts synchronization should be performed during the import. In this case, a progress bar shows the progress of the synchronization.

Target project:

Here, enter the drive, directory, and name of the project where the data is to be imported, or click [...] to interactively select the file.

Using Popup menu > Insert path variable you branch to the [Select path variable](modaldialogsdb_d_pfadvariablen.htm) dialog, where you can select one of the available EPLAN-specific path variables.

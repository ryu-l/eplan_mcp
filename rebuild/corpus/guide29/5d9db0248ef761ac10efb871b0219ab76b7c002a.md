# Dialog Export pipe bending

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. In the [layout space](Glossary_o_bauraum.htm) or in the [connections](Glossary_o_verbindungen.htm) navigator, you have marked freely routed pipes for which you want to carry out an export to the pipe bending software. Utilities > Manufacturing data > Machining > Pipe bending.

Use this dialog to specify the [settings](Glossary_o_einstellungen.htm) for the export of data for the control software for controlling pipe bending machines.

Overview of the main dialog elements:

Machine:

The delivery scope includes the machine definition named "Standard". If you have defined other [schemes](Glossary_o_schemata.htm) in the company settings, you can select other machine definitions from the drop-down list.

The [...] button opens the Settings: Export pipe bending dialog where you can modify the settings for the scheme or define a new scheme.

Output directory:

This field displays the storage location. The directory is pre-selected that is defined for the pipe bending export in the user settings.

You can use the Insert path variable popup menu item to branch to the dialog [Select path variable](modaldialogsdb_d_pfadvariablen.htm) where you can select one of the available [path variables](Glossary_o_pfadvariablen.htm).

Target file:

Several files result from a pipe bending export. The field is deactivated, and the conditions apply that are defined in the scheme for generating the file name and the subdirectories.

# P005091: Connection and function have differing pipe classes

### Cause

The value for the Pipe class property entered at a connection in the [P&I diagram](Glossary_o_ri_fliessbild.htm) does not agree with the value that is entered at the property having the same name of the function that is the source or target of this connection.

### Solution

1. Locate the function using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Jump to the connection definition point of the connection by using the Go to 2nd coordinate functionality of the popup menu.
3. Determine the value entered in the Pipe class field in the respective [property dialog](Glossary_o_eigenschaftendialog.htm).
4. Standardize the two values.
5. Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

# Dialog Settings: Item selection

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project.You have opened a project page in the graphical editor. You have inserted a model view (Insert > Graphic > Model view) and placed it. In the Model view dialog, select the View tab and click [...] in the "Value" field of the property Model view: Selection scheme.

You use this dialog to [create](Glossary_o_erstellen.htm) and manage [schemes](Glossary_o_schemata.htm) for displaying item types in the model view.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

Table:

This [part](Glossary_o_artikel.htm) of the dialog is used to specify the criteria for automatic item selection.

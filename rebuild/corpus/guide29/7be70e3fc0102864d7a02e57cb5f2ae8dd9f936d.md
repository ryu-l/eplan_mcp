# Automatically Assigning Addresses to PLC Connection Points

[PLC connection points](Glossary_o_sps_anschluesse.htm) can be automatically addressed on insertion into a schematic or overview page. To do this, you must specify in the Online numbering [settings](Glossary_o_einstellungen.htm) that [PLC addresses](Glossary_o_sps_adressen.htm) are also to be taken into account. During automatic addressing, increment and format are taken from the scheme for the PLC-specific settings which is assigned to the CPU. If no scheme is assigned to the CPU, the scheme specified in the project settings is used.

Precondition:

You have opened a project with a schematic or overview page on which you have drawn one or more [PLC cards](Glossary_o_sps_karten.htm). You have selected a scheme for the PLC-specific settings and used this to define the address format for digital or analog inputs and outputs.

1. Select the following menu [items](Glossary_o_bauteile.htm): Options > Settings > Projects > "Project name" > Devices > Numbering (online)
2. Next to the Numbering format drop-down list, click [...].
3. In the Numbering formats dialog, bring the Designations tab to the foreground and select the PLC addresses check box.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) This setting causes PLC [connection points](Glossary_o_anschluesse.htm) to be automatically addressed, using the selected PLC-specific settings, on insertion (also via [macros](Glossary_o_makros.htm)) or copying of PLC connection points.

![](../Pictures/Gui/ALL/note.png)Note:

After installing EPLAN, automatic addressing of PLC connection points is already activated.

### Disable automatic addressing of PLC connection points

1. Deselect the PLC addresses check box in the Designations tab of the Numbering formats dialog.
2. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Through this setting the PLC address field in the Settings <...> dialog remains empty when PLC connection points are inserted or copied. You must then manually address the PLC connection points.

# P004037: Missing bus ID (bus port '<x>' in the bus system: '<y>')

### Cause

The bus [ID](Glossary_o_id.htm) is missing at the bus port <x> that is assigned to the bus system <y>.

### Solution

1. Locate bus port in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the bus port.
3. Bring the Bus data tab to the front.
4. Enter the missing bus ID in the Physical network: Bus ID / item number field.
5. Or activate the property Ignore missing bus ID, if the bus port does not require a bus ID.
6. Then start a new check run.

![](../Pictures/Gui/ALL/note.png)Notes:

- This check run only [reports](Glossary_o_auswertungen.htm) a missing bus ID if one of the following [function definitions](Glossary_o_funktionsdefinitionen.htm) is set at the bus port:  
    
  - Network / bus [cable](Glossary_o_kabel.htm) connection point, general  
    
  Only main [bus ports](Glossary_o_sps_busanschluesse.htm) are checked. Bus ports where a value is entered at the Bus interface: Name property and where the check box of the property Bus interface: Main bus port is deactivated are not reported.
- Please also note the following:  
  In the case of bus ports the Plug designation and the Bus interface name are used for identification in addition to the connection point designation. A check is carried out whether this combination (Connection point designation + Plug designation + Bus interface name) is identical. If at least one of these partial [designations](Glossary_o_bezeichnungen.htm) shows a difference, the message is not output.

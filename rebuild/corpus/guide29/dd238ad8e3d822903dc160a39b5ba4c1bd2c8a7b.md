# Adding Project Parts

Project parts are parts that are not assigned to any special device, i.e., the parts to be included with delivery.

Precondition:

You have opened a project.

1. Select the following menu [items](Glossary_o_bauteile.htm): Project data > Parts / Devices > Bill of materials navigator
2. In the Bill of materials - <Project name> dialog, select the Add project part popup menu item.
3. In the Part selection dialog, select the [part](Glossary_o_artikel.htm) or parts to be added. Multiple selection is possible.
4. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The new project parts are inserted into the tree in alphabetical order.

![](../Pictures/Gui/ALL/note.png)Note:

All [functions](Glossary_o_funktionen.htm) of the Part selection dialog can be used, and the parts-specific presettings are taken into account.

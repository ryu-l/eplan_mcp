# P005047: Net definition point contains incomplete connections

### Cause

One or more [connections](Glossary_o_verbindungen.htm) were deleted within a net in the schematic. This creates a gap in the daisy chain. A connection gap is identified in the Property dialog for a net definition point (Connections table on the Net connections tab) by a small warning triangle in the Connection points column. Message [P005046: Incomplete net](messages_p_005046.htm) is also output.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

A net N1 in the schematic connects 5 fuses (-F1 to -F5) with the potential L1. The [connection points](Glossary_o_anschluesse.htm) [form](Glossary_o_verlauf.htm) the following daisy chain:

| Connection point | Source | Target |
| --- | --- | --- |
| L1 | L1 | -F1:1 |
| -F1:1 | -F1:1 | -F2:1 |
| -F2:1 | -F2:1 | -F3:1 |
| -F3:1 | -F3:1 | -F4:1 |
| -F4:1 | -F4:1 | -F5:1 |
| -F5:1 |  |  |

The fuse -F4 and the associated T-node are deleted from the schematic.

![](../Pictures/Visualisation/ALL/messages_005046_bsp1.3_av.png)

When -F4 and the T-node are deleted, a gap is created in the daisy chain:

| Connection point | Source | Target |
| --- | --- | --- |
| L1 | L1 | -F1:1 |
| -F1:1 | -F1:1 | -F2:1 |
| -F2:1 | -F2:1 | -F3:1 |
| -F3:1 | -F3:1 |  |
|  |  | -F5:1 |
| -F5:1 |  |  |

### Solution

Complete the net by integrating the deleted connection back into the net and closing the gap in the daisy chain.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

For the above example, the steps are as follows:

1. Locate the relevant net definition point in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the Properties <...> dialog for the net definition point.
3. Bring the Net connections tab to the front.
4. In the Connections table, the missing connection point is identified by a warning triangle - in the example the fuse -F4:1 is missing.
5. Close the Property dialog and insert a new fuse with the DT -F4.
6. Use a T-node to connect the connection point for fuse -F4:1 to the net.
7. Open the Properties <...> dialog again for net definition point N1 and bring the Net connections tab to the foreground.
8. Click ![](../Pictures/Gui/ALL/all_startdaisy_as.png) (Create daisy chain).
9. In the Connection points table, select connection point -F4:1 with number of targets "0".  
     
   ![](../Pictures/Gui/ALL/arrow.png) Connection point -F4:1 is copied to the Connections table and entered beneath the horizontal line of the daisy chain. This creates a new daisy chain.
10. Click ![](../Pictures/Gui/ALL/all_enddaisy_as.png) (End daisy chain) to complete the daisy chain.  
      
    ![](../Pictures/Gui/ALL/arrow.png) A horizontal line is created beneath connection point -F4:1 in the Connections table.
11. Select connection point -F4:1 in the new daisy chain, then click the ![](../Pictures/Gui/ALL/all_arrowup_as.png) (Move up) button to move it to the first daisy chain.  
      
    ![](../Pictures/Gui/ALL/arrow.png) This breaks up the second daisy chain.
12. Position the connection point -F5:1 immediately beneath the warning triangle.
13. Select the entry with the warning triangle and click ![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) to delete it.
14. Click OK to close the Properties <...> dialog for the net definition point, then start a new project check.

# P003024: The cable and its cable connections do not have the same intrinsic safety state.

### Cause

At the [cable](Glossary_o_kabel.htm) as main function, the Intrinsically safe property is selected (Symbol / function data tab). At least one cable connection of the cable does not possess this property. In reverse, it is also possible that all [cable connections](Glossary_o_kabelverbindungen.htm) have the Intrinsically safe property but the cable as the main function does not.

### Solution

#### Possibility 1

Select the intersections of the cable definition line with the cable [connections](Glossary_o_verbindungen.htm), by clicking them one after another. For every cable connection, check in the Properties (components): Connection definition point dialog that the Intrinsically safe check box in the Symbol / function data tab is selected. If not, then select it.

#### Possibility 2

If the cable and associated cable connections are not intrinsically safe, then deselect the Intrinsically safe check box for the cable and all cable connections.

Refresh the connections and then start a new check run.

# Projects: Principle

In EPLAN, schematics and [attached documents](Glossary_o_begleitdokumente.htm) such as lists and overviews are created as pages within [projects](Glossary_o_projekte.htm). A project is a database in which, besides the project pages, all [master data](Glossary_o_stammdaten.htm) used in the project ([symbols](Glossary_o_symbole.htm), [plot frames](Glossary_o_normblaetter.htm), [forms](Glossary_o_formulare.htm), parts data, etc.) is stored.

Thus the [project file](Glossary_o_projektdatei.htm) (\*.elk) belongs to a project, as well as the directory where the database and the project-related master data are stored. The project file represents the project; using this file you select (e.g.) a project to open or unzip. It contains the reference to the associated directory containing the [project data](Glossary_o_projektdaten.htm).

Project files can have different file suffixes, e.g.:

\*.elk: Standard project

\*.elp: Zipped project

\*.elr: Completed project / reference project.

In the ..\Projects\EPLAN directory is the ESS\_Sample\_Project.elk project file. This contains the reference to the ESS\_Sample\_Project.edb directory. In the ..\Projects\EPLAN\ESS\_Sample\_Project.edb subdirectory is the associated project data. If you wish to open a project using Project > Open, the file ESS\_Sample\_Project.elk is offered in the file selection dialog.

# Configuring List and Tree Views

As a default, a lot of information about the various [objects](Glossary_o_objekte.htm) is displayed in the list views. In order to only display the information that is relevant to you about the [devices](Glossary_o_betriebsmittel.htm), parts, [connections](Glossary_o_verbindungen.htm), etc., every list can be individually configured. In the process you use a property selection to specify the columns that are to be displayed in a list view.

Additional information for the rapid identification of objects and parts can be displayed in the tree views of most of the [navigators](Glossary_o_navigatoren.htm) and dialogs for parts. The representation of this additional information can be configured.

A configuration with the information ([properties](Glossary_o_eigenschaften.htm)) to be displayed is stored as a scheme for both the list and tree views and can be used repeatedly or revised at any time.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Examples:](javascript:void(0);)

The following is possible through the configuration of the tree view:

- Page navigator: The display of additional information that is not required (such as the page description) can be suppressed.
- Project data navigators: Additional information such as the function text or the technical characteristics can be displayed for the tree structure [levels](Glossary_o_etagen.htm) of the devices (icon ![](../Pictures/Gui/ALL/navigatorgui_device_as.png)) and the functions (icon for example ![](../Pictures/Gui/ALL/navigatorgui_function_as.png)).   
  It is possible, for example, to display the [designations](Glossary_o_bezeichnungen.htm) of these pre-planning [segments](Glossary_o_segmente.htm) at functions to which a planning object or a PCT loop has been assigned. Further information, such as the descriptions of the parts from the parts management, can be displayed behind the [part](Glossary_o_artikel.htm) numbers.
- Macro navigator: The macro type and the representation type of the prepared [macros](Glossary_o_makros.htm) can, for example, be displayed in the tree view of the macro navigator. The page description can be displayed behind the [page macros](Glossary_o_seitenmakros.htm) to be generated.
- "DT selection" dialog: The tree view can be extended for each object by the display of further information such as the function text.
- Parts management, part selection and part master data navigator: In the tree views other properties can be displayed in addition to the part designation (for example ERP Number, type number, etc.) for the part number. The representation cannot be configured for [variants](Glossary_o_varianten.htm) and other tree structure levels such as accessory lists, [drilling patterns](Glossary_o_bohrbilder.htm), etc.

### Configuring list views

Precondition:

You have opened a project and are now in the list view of a navigator, in the list view of the Symbol selection dialog, in the data table of the Synchronize devices dialog, etc.

1. Select the Configure representation popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) All the properties that are currently being used in the list view are displayed in the Configuration field of the Configure representation dialog.
2. In the Scheme field select an existing scheme or [create](Glossary_o_erstellen.htm) a new scheme.
3. Click ![](../Pictures/Gui/ALL/all_new_as.png) (New) at the Configuration field to add a property for the configuration to the selected scheme.
4. Select the desired property in the subsequent Property selection dialog. Multiple selection is possible.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The inserted properties are added to the end of the list.
5. Use the arrow buttons to specify the order in which the properties are to be displayed.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Configure representation dialog is closed and the representation is updated.
7. If necessary, adjust the width of the individual columns.

The adjusted column widths of the list views in the navigators are stored automatically both when a navigator dialog is closed and when the Configure representation popup menu item is selected. This means that column widths that have been set once are retained and are restored when a scheme for the configuration of the representation is selected again.

![](../Pictures/Gui/ALL/note.png)Notes:

- The set column widths of list views are stored on a per-user basis in the dialog memory. This means that even at a [data exchange](Glossary_o_datenaustausch.htm) of a configuration scheme for the list view each user can optimize the column width for themselves.
- Certain properties are always displayed. Such properties can not be deleted from the list in the Configuration field. For example the Project name property is always displayed in the list view as a column, in as far as more than one project or no project is opened.

### Configuring tree views for navigators

Precondition:

You have opened a project and are in the tree view of specific navigators.

1. Select the Configure representation popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Configuration table of the Configure representation dialog lists those objects ([projects](Glossary_o_projekte.htm), pages, devices, [functions](Glossary_o_funktionen.htm), [structure identifiers](Glossary_o_strukturkennzeichen.htm), etc.) that can be displayed in the respective tree.
2. In the Scheme field select an existing scheme or create a new scheme.
3. Click in the Block format column for an object and use [...] to branch to the Format dialog in order to change the formatting of a property already selected or to add further properties for the respective object.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Formatting of properties for the objects of a tree view is carried out in the same way as for [Defining Block Properties](blockproperties_h_blockeigenschaftendefinieren.htm).
4. After you have added [format elements](Glossary_o_formatelemente.htm) (properties, separators) in the Format dialog, specified your sequence or edited the format of selected format elements, click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) Configuration of the tree view for this object is now completed. In the Configure representation dialog the associated cell of the Block format column is filled with the preview of the set format.
5. Repeat the steps above in order to configure the tree view for further objects, if required.
6. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Configure representation dialog is closed and the representation is updated.

![](../Pictures/Gui/ALL/note.png)Note:

Certain properties are always displayed. For example, the Project name property is displayed in the tree view even if no format is specified for the Block format column.

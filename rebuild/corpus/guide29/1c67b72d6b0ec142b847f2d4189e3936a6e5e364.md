# Defining the Search Direction for DT Adoption

By default, device tags are adopted corresponding to the plot frame orientation. However, you can change the search direction for any function in which DT adoption is possible.

Preconditions:

- You have opened a project.
- In the project [settings](Glossary_o_einstellungen.htm), you have defined that [devices](Glossary_o_betriebsmittel.htm) and [macros](Glossary_o_makros.htm) are to be numbered online on insertion (Options > Settings > Projects > "Project name" > Devices > Numbering (online)).

1. Select a function in the graphical editor or in one of the [navigators](Glossary_o_navigatoren.htm) and select the Edit > Properties menu [items](Glossary_o_bauteile.htm).
2. In the Properties <...> dialog, select the <Function category> tab.
3. In the Properties table, select the DT adoption: Search direction property, and select one of the possible settings from the drop-down list in the Value column.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the search direction is "According to orientation of plot frame", then the DT is taken from the left in [projects](Glossary_o_projekte.htm) using the IEC standard, from above in projects using the [NFPA standard](Glossary_o_nfpa_norm.htm), and from the right in projects using the [GOST standard](Glossary_o_gost_norm.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the search direction is "An alternative to orientation of plot frame", then the DT is taken from above in projects using the IEC standard, from the left in projects using the NFPA standard, and from below in projects using the GOST standard.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the search direction is "Only from boxes", then the DT is taken only from the box surrounding the function (Black box, PLC box). If the function is not located in a box, no DT can be adopted.
4. Click [OK].

![](../Pictures/Gui/ALL/note.png) Notes:

- To prevent DT adoption in general, deselect [online numbering](Glossary_o_onlinenummerieren.htm).
- To prevent the DT adoption for individual pages, activate the DT adoption: Only from boxes property at the selected [plot frames](Glossary_o_normblaetter.htm) for the pages.
- To prevent DT adoption for individual [functions](Glossary_o_funktionen.htm), set the search direction "Only from boxes" for those functions.

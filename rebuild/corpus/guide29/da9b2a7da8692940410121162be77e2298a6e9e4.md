# P024002: Connection between different trades

### Cause

The target [functions](Glossary_o_funktionen.htm) of a connection have a conflicting entry for the property Trade. This can occur when, for example, a connection exists between functions belonging to the [trades](Glossary_o_gewerke.htm) "Pneumatics " and "Hydraulics".

### Solution

Assign data to the connection targets that agrees with the Trade property. The trade can be set for each function in the Properties <...> dialog, on the  first tab.

Refresh the [connections](Glossary_o_verbindungen.htm) and then start a new check run.

# P005031: A connection designation is added to the connection definition point (<y>) located on a section of the connection (<x>)

### Description

A connection definition point having the No connection designation property (Valid data drop-down list in the Properties <...> dialog), is centered on an individual section of a connection. When further [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm) are placed, the previously-inserted centered connection definition point is prepared for the connection designation. This automatically changes the value of the property in the Valid data drop-down list to "All data".

![](../Pictures/Gui/ALL/note.png) Note:

Using a new check run (any desired scheme) this module-specific message can be deleted from the message management dialog.

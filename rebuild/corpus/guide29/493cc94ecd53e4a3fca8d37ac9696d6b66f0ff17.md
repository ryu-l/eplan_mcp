# P501003: The document <x> entered at the part does not exist

### Cause

In the parts database to be checked a [part](Glossary_o_artikel.htm) was found where a document was entered which EPLAN cannot find.

### Solution

1. In the message management dialog mark the line with the message and select the Properties popup menu item.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The Parts management dialog is opened, the respective part is already marked in it.
2. Bring the Documents tab to the front.
3. In the File / Hyperlink column click the entry that contains the path to the document not found and click [...].
4. Select the required document from the selection dialog opened.  
     
   Or alternatively the table entry with the path specification of the non-existent document.  
     
   Or store a new document in the document directory and select it in the File / hyperlink column.
5. Close the parts management, save the modified data, and carry out a parts synchronization.
6. Then start a new check run.

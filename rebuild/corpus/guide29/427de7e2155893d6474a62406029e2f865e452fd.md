# EPLAN Actions: Overview

The following EPLAN Actions are available:

| Action name | Description |
| --- | --- |
| [backup](availableactions_o_backup.htm) | Backs a project or [master data](Glossary_o_stammdaten.htm) up. |
| [changelayer](availableactions_o_changelayer.htm) | Changes the graphical [properties](Glossary_o_eigenschaften.htm) of [layers](Glossary_o_ebenen.htm). |
| [check](availableactions_o_check.htm) | Checks pages or the entire project. |
| [compress](availableactions_o_compress.htm) | Compresses a project. |
| [CopyToolBarAction](availableactions_o_copytoolbaraction.htm) | Copies the buttons of one toolbar to another. |
| [devicelist](availableactions_o_devicelist.htm) | Imports, exports, or deletes a device list. |
| [edit](availableactions_o_edit.htm) | Opens a page or a project. |
| [EplApiModuleAction](availableactions_o_eplapimoduleaction.htm) | Loads and registers an API module. |
| [EsCorrectConnections](availableactions_o_escorrectconnections.htm) | Combines identical [connection definition points](Glossary_o_verbindungsdefinitionspunkte.htm). |
| [ExecuteScript](availableactions_o_executescript.htm) | Runs a script. |
| [export](availableactions_o_export.htm) | Exports pages or [projects](Glossary_o_projekte.htm) in different [formats](Glossary_o_formate.htm). |
| [export3D](availableactions_o_export3d.htm) | Exports layout spaces into the STEP format. |
| [exportNCData](availableactions_o_exportncdata.htm) | Exports NC data for different machine formats. |
| [exportProductionWiring](availableactions_o_exportProductionWiring.htm) | Exports [wire fabrication](Glossary_o_drahtkonfektionierung.htm) data into different formats. |
| [ExportSegmentsTemplate](availableactions_o_exportsegmentstemplate.htm) | Exports [segment templates](Glossary_o_segmentvorlagen.htm) into a file. |
| [exportToGraphics](availableactions_o_exporttographics.htm) | Exports pages or projects in graphic format (TIF, GIF, PNG, JPG). |
| gedRedraw | Builds the image of the graphical editor anew. |
| [generate](availableactions_o_generate.htm) | Generates [connections](Glossary_o_verbindungen.htm) or cables. |
| [GenerateMacros](availableactions_o_generatemacros.htm) | Generates [macros](Glossary_o_makros.htm) from a project. |
| [GraphicalLayerTable](availableactions_o_GraphicalLayerTable.htm) | Imports / exports layers. |
| [import](availableactions_o_import.htm) | Imports projects, macros, or drawings. |
| [ImportPrePlanningData](availableactions_o_importpreplanningdata.htm) | Imports pre-planning data. |
| [ImportSegmentsTemplate](availableactions_o_importsegmentstemplate.htm) | Imports segment templates from a file into a project. |
| [InsertModelViewAction](availableactions_o_InsertModelViewAction.htm) | Inserts [model views](Glossary_o_modell_ansichten.htm) into a project. |
| [label](availableactions_o_label.htm) | Generates the export of the manufacturing data / the labeling for a project. |
| [masterdata](availableactions_o_masterdata.htm) | Updates the master data of the current project. |
| [MfExportToolbarAction](availableactions_o_mfexporttoolbaraction.htm) | Exports one or more [user-defined](Glossary_o_benutzerdefiniert.htm) [toolbars](Glossary_o_symbolleisten.htm). |
| [MfImportToolbarAction](availableactions_o_mfimporttoolbaraction.htm) | Imports a toolbar from a file. |
| [MfRemoveToolbarAction](availableactions_o_mfremovetoolbaraction.htm) | Deletes a user-defined toolbar. |
| [OpenWorkspaceAction](availableactions_o_xsvopenworkspaceaction.htm) | Opens an existing workspace. |
| [partslist](availableactions_o_partslist.htm) | Imports or exports a bill of materials. |
| [plcservice](availableactions_o_plcservice.htm) | Imports or exports PLC data by means of the specified configuration program. |
| [print](availableactions_o_print.htm) | Prints a page or the whole project. |
| [ProjectAction](availableactions_o_xesprojectaction.htm) | Runs an action for a project and closes the project after this. |
| [projectmanagement](availableactions_o_projectmanagement.htm) | Loads a file with project information into the project management. |
| [ProjectOpen](availableactions_o_projectopen.htm) | Opens a project. |
| [RegisterScript](availableactions_o_registerscript.htm) | Registers a script. |
| [Renumber](availableactions_o_renumber.htm) | Carries out renumbering. |
| [reports](availableactions_o_reports.htm) | Generates project [reports](Glossary_o_auswertungen.htm). |
| [restore](availableactions_o_restore.htm) | Restores a project or master data from backup. |
| [SaveWorkspaceAction](availableactions_o_xsvsaveworkspaceaction.htm) | Saves the current user interface [settings](Glossary_o_einstellungen.htm) as workspace. |
| [search](availableactions_o_search.htm) | Searches for [objects](Glossary_o_objekte.htm) ([devices](Glossary_o_betriebsmittel.htm), properties, texts, etc.) in a project. |
| [selectionset](availableactions_o_selectionset.htm) | Retrieves values (name, file path, file name extension) from selected pages or a selected project. |
| [SetProjectLanguage](availableactions_o_xessetprojectlanguageaction.htm) | Determines [display languages](Glossary_o_anzeigesprachen.htm) for editable and read-only projects. |
| [SpExportSubProject](availableactions_o_SpExportSubProject.htm) | Files off a project that has to be opened in the "Exclusive" editing mode. |
| [SpImportSubProject](availableactions_o_SpImportSubProject.htm) | Imports a project that has to be opened exclusively. |
| [SwitchProjectType](availableactions_o_switchprojecttype.htm) | Switches the "Type of project" property. |
| [synchronize](availableactions_o_synchronize.htm) | Synchronizes [project data](Glossary_o_projektdaten.htm). |
| [Topology](availableactions_o_Topology.htm) | Routes [topology](Glossary_o_topologie.htm) connections or creates topology [functions](Glossary_o_funktionen.htm). |
| [translate](availableactions_o_translate.htm) | Translates a project, deletes the translation from the project, or exports a missing word list. |
| [UnregisterScript](availableactions_o_unregisterscript.htm) | Unregisters a script. |
| [UpdateSegmentsFilling](availableactions_o_UpdateSegmentsFilling.htm) | Calculates the value of the property "Topology: Fill capacity" ([ID](Glossary_o_id.htm) 20332) of the manual [routing paths](Glossary_o_strecken.htm) project-wide and enters it at the respective routing paths, i.e. supplies a feedback about the space reserves in manual routing paths. |
| [XAfActionSetting](availableactions_o_xafactionsetting.htm) | Sets a user, station, or company setting to a certain value. |
| [XAfActionSettingProject](availableactions_o_xafactionsettingproject.htm) | Sets a project setting to a certain value. |
| [XCMRemoveUnnecessaryNDPsAction](availableactions_o_XCMRemoveUnnecessaryNDPsAction.htm) | Removes superfluous [net definition points](Glossary_o_netzdefinitionspunkte.htm) from the current project. If necessary, connection definition points are placed on the connections of the net so that no properties are lost. |
| XCMUniteNetDefinitionPointsAction | Unites net definition points that are placed in the same net of the current project. If more than one net definition point is placed in the same net, these net definition points (i.e. their connections) are combined into a net definition point. After the execution of this action a maximum of one net definition point exists per net that contains all the [net-based connections](Glossary_o_netzbasierteverbindungen.htm) of the net. |
| [XDLInsertDeviceAction](availableactions_o_xdlinsertdeviceaction.htm) | Inserts a device. |
| [XEGActionInsertSymRef](availableactions_o_xegactioninsertsymref.htm) | Inserts a symbol. |
| [XEsSetPagePropertyAction](availableactions_o_xessetpagepropertyaction.htm) | Sets a page property for the currently selected page to a specific value. |
| [XEsSetProjectPropertyAction](availableactions_o_xessetprojectpropertyaction.htm) | Sets a project property for the currently selected project to a specific value. |
| [XEsSetPropertyAction](availableactions_o_xessetpropertyaction.htm) | Sets a [component](Glossary_o_schaltzeichen.htm) property for the currently selected component to a specific value. |
| [XEsUserPropertiesExportAction](availableactions_o_xesuserpropertiesexportaction.htm) | Exports user-defined properties into a file. |
| [XEsUserPropertiesImportAction](availableactions_o_xesuserpropertiesimportaction.htm) | Imports user-defined properties from a file. |
| XGedClosePage | Closes all selected pages. This action has no parameters. |
| [XGedStartInteractionAction](availableactions_o_xgedstartinteractionaction.htm) | Starts an interaction in the graphical editor. Possible interactions are (e.g.) insertion of a macro or definition of the format settings for components, text, or similar elements. |
| [XGedUpdateMacroAction](availableactions_o_xgedupdatemacroaction.htm) | Updates macros. |
| [XMActionDCCommonExport](availableactions_o_XMActionDCCommonExport.htm) | Starts the export for the external editing. |
| [XMActionDCImport](availableactions_o_xmactiondcimport.htm) | Imports a data configuration file of external editing into an existing EPLAN project. |
| [XMDeleteReprTypeAction](availableactions_o_xmdeletereprtypeaction.htm) | Removes from selected macros a representation type and saves these macros in a directory. |
| [XMExportConnectionsAction](availableactions_o_xmexportconnectionsaction.htm) | Exports the connection properties of a project for external editing. |
| [XMExportFunctionAction](availableactions_o_xmexportfunctionaction.htm) | Exports the function properties of a project for external editing. |
| [XMExportPagesAction](availableactions_o_xmexportpagesaction.htm) | Exports the page properties of a project for external editing. |
| [XPamsDeviceSelectionAction](availableactions_o_xpamsdeviceselectionaction.htm) | Carries our a device selection or updates device data. |
| [XPamSelectPart](availableactions_o_XPamSelectPart.htm) | Starts the [part](Glossary_o_artikel.htm) selection. |
| [XPlaUpdateDetailAction](availableactions_o_xpamsdeviceselectionaction.htm) | Updates the detailed planning in the pre-planning navigator. |
| [XPrjActionUpgradeProjects](availableactions_o_XPrjActionUpgradeProjects.htm) | Updates one or more projects to the current database scheme. |
| [XSDPreviewAction](availableactions_o_xsdpreviewaction.htm) | Opens or closes a page or macro preview window. |
| [XSettingsExport](availableactions_o_xsettingsexport.htm) | Exports user, workstation and company settings. |
| [XSettingsImport](availableactions_o_xsettingsimport.htm) | Imports user, workstation and company settings. |
| [XSettingsRegisterAction](availableactions_o_XSettingsRegisterAction.htm) | Allows registering of [add-ons](Glossary_o_add_ons.htm). |
| [XSettingsUnregisterAction](availableactions_o_XSettingsUnregisterAction.htm) | Allows unregistering of add-ons. |
| [XTranslateSourceLanguage](availableactions_o_XTranslateSourceLanguage.htm) | Allows translating of texts in a specific source language. |

![](../Pictures/Gui/ALL/warning.png)Warning:

Please note that the examples given for the individual [actions](Glossary_o_aktionen.htm) in the help topics are separated by line breaks to make them easier to read. If you want to use the examples in the [form](Glossary_o_verlauf.htm) illustrated, you MUST delete these line breaks. Please also make sure that, during input, action and parameter as well as the individual parameters are separated from each other by a blank space.

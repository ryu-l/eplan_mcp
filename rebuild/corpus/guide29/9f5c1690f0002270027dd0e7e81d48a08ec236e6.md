# P005086: Different connection dimension '<x>' / '<y>'

### Cause

The [connection dimension](Glossary_o_anschlussmass.htm) at the target or source connection point of a connection / hose line does not match the connection dimension of the connected function. The source- or target-specific connection dimension of the connection / hose line is displayed in the placeholder <x>, while the connection dimension of the function that is the source or the target of the connection / hose line is output in the placeholder <y>.

### Solution

1. Locate the connection / hose line in the schematic by using the Go to (graphic) functionality from the popup menu in the Message management dialog. Jump to the connected function by using the Go to 2nd coordinate popup menu item.
2. Consecutively open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the connection definition point / hose line and of the function that is the source or target of the connection.
3. Unitize the values of the connection dimensions at the source or target connection point of the connection / hose line and / or at the function. To this purpose the Connection dimension source / Connection dimension target [properties](Glossary_o_eigenschaften.htm) are available at the connection / hose line, the Connection dimension (all) property at the function. Ensure that the upper-case / lower-case spelling is the same for all the values.
4. If you have transferred the connection dimensions via a device or [part](Glossary_o_artikel.htm) selection to the connection / hose line and/or function, select corresponding parts with suitable values.
5. Then start a new check run.

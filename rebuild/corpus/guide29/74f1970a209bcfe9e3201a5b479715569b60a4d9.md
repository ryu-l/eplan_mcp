# Releasing the PDF File for Comments

In order to comment an EPLAN project that you have issued as a PDF file in Acrobat Reader, it must be released for commenting via Acrobat.

Preconditions:

- You are a [Project editor](redlining_k_projektkommentator.htm#Projektbearbeiter).
- You have Acrobat Professional 7.0 / Acrobat Standard 7.0 installed and open.
- [Output pages as PDF files](pdfexportgui_h_seitenexportieren.htm)

1. File > Open
2. In the subsequent dialog, select the PDF file containing the EPLAN pages and click [Open].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The PDF file opens in Acrobat.
3. Select the Comments menu item.
4. Select the menu item that activates reading the file in Adobe Reader for commenting
5. Select a target directory in the subsequent dialog and click [Save].  
      
    ![](../Pictures/Gui/ALL/arrow.png) In Acrobat Reader you can now [Create PDF comments in the PDF file](redlining_h_pdfkommentare.htm).

# Placing Connected Functions

Connected [functions](Glossary_o_funktionen.htm) are all functions that are directly connected to a device via [connections](Glossary_o_verbindungen.htm). When you place a device, you can use the "Connected functions" feature to automatically place all connections and functions that are directly connected to an already placed function.

Preconditions:

- You have created at least 2 unplaced [devices](Glossary_o_betriebsmittel.htm) that have [connection points](Glossary_o_anschluesse.htm).
- You have [generated unplaced connections](planningconnections_h_createconnections.htm) between the devices.
- You opened a symbol library.

1. Project data > Devices > Navigator
2. Select a device that has connections for connected functions.
3. Use Drag & Drop to pull the device onto the page.
4. Select the placed device.
5. Select the menu [items](Glossary_o_bauteile.htm) Insert > Connected functions.  
      
    ![](../Pictures/Gui/ALL/arrow.png) All directly connected, unplaced connections and functions are placed.
6. Press [F5] to update.

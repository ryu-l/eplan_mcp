# Copying, Cutting, and Pasting Schematic Elements

Preconditions:

- You have opened a project.
- The project contains pages in which [functions](Glossary_o_funktionen.htm) have been placed.
- You have opened the page navigator: Page > Navigator

### Copy or cut

1. Double-click a schematic page in the Pages - <Project name> dialog.
2. Select the menu item Edit > Select > Area.
3. With the left mouse button pressed, pull a rectangle around all the schematic elements that you wish to copy or cut.
4. Select the menu item Edit > Copy or Edit > Cut.

### Insert at a position

1. In the Pages <Project name> dialog, double-click the schematic page where you wish to insert the schematic elements.
2. Select the menu [items](Glossary_o_bauteile.htm) Edit > Paste.
3. Click the position in the schematic where the schematic elements from the EPLAN Clipboard are to be inserted.  
     
   ![](../Pictures/Gui/ALL/arrow.png) If the With prompt option is selected in the Settings: Numbering (online) dialog, the Insertion mode dialog opens.
4. Define the manner in which the schematic elements are to be numbered and click [OK].

### Insert at multiple places

1. If you wish to insert schematic elements at further positions, click again in the schematic.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The selected insertion mode does not change.
2. To change the selected insertion mode, press [Esc].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The action will be canceled.
3. Select the menu item Edit > Paste and insert the schematic elements in the same manner.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In this procedure, you can again specify the manner in which the schematic elements are to be numbered, using the Insertion mode dialog.

# Tab Result (Project Verification)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have selected a project management database. You have loaded directories and [projects](Glossary_o_projekte.htm). Project > Management. Select the input project with the advanced project status. Select [Extras] > Verify project. Select a comparison project. Select the Compare settings check box. Click [OK]. Select the Result tab.

This tab displays a short overview of results from the project verification.

The following dialog elements are available:

Description:

This column displays which comparisons and [check runs](Glossary_o_prueflaeufe.htm) were carried out during the project verification process and which were not. The overall result of the project verification are also displayed. If you select a line, the Message description field (below the table) will show a text description. Detailed results of the project verification can be found under Project data > Messages > Management.

- Comparison of settings: This line displays the results of the [settings](Glossary_o_einstellungen.htm) comparison.
- Comparison of properties: This line displays the results of the [properties](Glossary_o_eigenschaften.htm) comparison.
- Comparison of project structures: This line displays the results of the [project structure](Glossary_o_projektstruktur.htm) comparison.
- Comparison of layers: This line displays the results of the layer comparison.
- Project checks: Displays the results of the check run. The [Status tab](prjmanagementgui_r_status.htm) also shows additional statistics of the check runs, for example the number of errors and the check run scheme used.

Status:

Shows the overall results of the project verification.

- ![](../Pictures/Gui/ALL/all_statusok_as.png): Everything correct! There are no setting / property differences between the comparison and incoming project. The check run generated no [check run messages](Glossary_o_prueflaufmeldungen.htm).
- ![](../Pictures/Gui/ALL/erroricon_error_systemmessages.png): Warning! Setting / property differences were found between the comparison and incoming project. The check run generated check run messages.
- ![](../Pictures/Gui/ALL/all_statusnotok_as.png): Warning! The comparison / check was not completed. Possible causes: You did not select the comparison / check run for the project verification. You selected the setting Stop comparison when first difference is found and EPLAN discovered a difference that stopped the comparison / check run.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Freeze panes | Fixes all the rows of the table above the selected row, or all of the columns to the left of the selected column. The rows below, or the columns to the right of the selection, can still be moved by using the scroll bar. |
| Unfreeze panes | Removes the freezing so that all of the rows and columns can again be moved using the scroll bar. |
| Adjust column width | Adjusts the width of all table columns so that both the headings and column contents are fully legible. |
| Font size 100% | This menu item is only available if the font size has been changed in the table (via [Ctrl] + scrolling with the mouse wheel). Re-displays the text in the table in its original font size. |

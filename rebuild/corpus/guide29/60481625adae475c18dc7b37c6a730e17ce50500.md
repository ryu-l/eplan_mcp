# Overview of the Transferred Part Data

By means of [part](Glossary_o_artikel.htm) selection, you assign one or more parts to a device. In the process the data listed below of the first part contained in the selection are assigned to the function / [component](Glossary_o_schaltzeichen.htm).

In addition, the following values are transferred:

- All [properties](Glossary_o_eigenschaften.htm) of the "main template". The main template is the first function template in the Function templates tab of the parts management whose function definition is set to "Main function".
- Part assignments set in the macro box (If a macro is entered at the part and part assignments are configured there).
- The value from the Technical characteristics field in the Technical data tab is only transferred during the part selection if no value is entered for this property at the "main template" or if there are no [function templates](Glossary_o_funktionsschablonen.htm).

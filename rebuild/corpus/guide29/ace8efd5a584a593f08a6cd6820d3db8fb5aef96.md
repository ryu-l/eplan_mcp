# P004089: PLC card name '<x>' assigned several times within a rack

### Cause

At least two [PLC boxes](Glossary_o_sps_kaesten.htm) that are [PLC cards](Glossary_o_sps_karten.htm) of the same [rack](Glossary_o_baugruppentraeger.htm) within a configuration project have the same PLC card name.

This check run only checks PLC boxes at which a configuration project is entered.

### Solution

1. Locate the PLC boxes in the schematic using the Go to (graphic) and Go to 2nd coordinate functionalities from the popup menu of the Message management dialog.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) of each PLC box of the rack.
3. Bring the first tab to the front.
4. Modify the value of the PLC card name property in the property table. In the process ensure that each PLC box has a unique PLC card name.
5. Click [OK].
6. Then start a new check run.

![](../Pictures/Gui/ALL/info.png)Tip:

The [Edit in table](functiondatagridgui_k_start.htm) function can also be used for comfortable searching for errors in the project. Simply [create](Glossary_o_erstellen.htm) a scheme that displays the PLC card name and the required PLC structure data in a clearly structured [form](Glossary_o_verlauf.htm).

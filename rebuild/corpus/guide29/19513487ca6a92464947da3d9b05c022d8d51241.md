# Scheme Toolbar

In the toolbar to the right of the Scheme field, the following buttons can be available:

| Button | Meaning |
| --- | --- |
| (Edit) | Opens a dialog allowing editing of the selected scheme. |
| (New) | Opens the New scheme dialog. This enables you to [create](Glossary_o_erstellen.htm) a scheme. |
| (Save) | Saves a scheme. |
| (Copy) | Opens the Copy scheme dialog. This enables you to copy an existing scheme. |
| (Delete) | Deletes a scheme. |
| (Export) | Opens the Select export file dialog. This enables you to export a scheme. Multiple selection is not possible. |
| (Import) | Opens the Select import file dialog. This enables you to import one or more [schemes](Glossary_o_schemata.htm). Multiple selection is possible. |

![](../Pictures/Gui/ALL/note.png) Note:

For both imports and exports, unique file names following the pattern "Action.Schema name.xml" are suggested, for example "CBcr.Standard.xml" for exporting the "Default" scheme for [cable](Glossary_o_kabel.htm) generation ("CBcr" = CABLE create). This makes it easier to keep an overview of existing schemes.

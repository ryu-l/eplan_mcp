# P004092: Missing bus interface name

### Cause

No bus interface name is assigned at an Ethernet-based bus port.

This check run only checks [bus ports](Glossary_o_sps_busanschluesse.htm) at which a configuration project is entered.

### Solution

1. Locate bus port in the schematic using the Go to (graphic) functionality that is provided by the popup menu of the Message management dialog.
2. Open the [property dialog](Glossary_o_eigenschaftendialog.htm) of the bus port.
3. Bring the Bus data tab to the front.
4. Enter the missing value in the Bus interface: Name field in the [properties](Glossary_o_eigenschaften.htm) list.
5. Click [OK].
6. Then start a new check run.

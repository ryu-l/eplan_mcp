# Importing 3D Graphic Data

You can import 3D graphic data from external CAD systems to [create](Glossary_o_erstellen.htm) your own [items](Glossary_o_bauteile.htm) and 3D [macros](Glossary_o_makros.htm). The item data must be available in the common international STEP format (STandard for the Exchange of Product model data).

![](../Pictures/Gui/ALL/note.png)Note:

EPLAN supports solely the import of STEP files that have been generated with the application protocol AP 203 or AP 214.

A new [layout space](Glossary_o_bauraum.htm) is generated for each import, and is given the name of the imported STEP file. Once imported, the item data can be edited and given functional logic.

Precondition:

You have opened a project. The layout space navigator is open.

1. Select the following menu items: Layout space > Import (3D graphic).
2. In the Open dialog select the desired STEP file.
3. Click [Open].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The 3D graphic data will be imported to a new layout space with the description from the name of the STEP file. Function definitions are automatically generated for the individual 3D [objects](Glossary_o_objekte.htm).
4. You can now edit the imported graphic and add functional logic, so that it can be used as an enclosure item, a device or a 3D macro. Use the menu items Edit > Graphic > Rotate around axis, Edit > Graphic > Unite, and Edit > Device logic > Mounting surface / Handle / Mounting point / Placement area > Define to do this.

![](../Pictures/Gui/ALL/note.png)Note:

As well as the [part](Glossary_o_artikel.htm) [properties](Glossary_o_eigenschaften.htm) Width, Height, and Depth, EPLAN Pro Panel also provides the option of displaying [devices](Glossary_o_betriebsmittel.htm) and items using qualified 3D graphical macros.

In order to create own devices, items and 3D graphics macros, 3D model data in STEP format can be imported into EPLAN Pro Panel. This data, normally provided by [component](Glossary_o_schaltzeichen.htm) manufacturers, is usually based on the component manufacturer's CAD design data, and is often complex and detailed.

Using complex, detailed 3D models as the basis for EPLAN 3D graphical macros is correspondingly RAM-intensive and can have a negative impact on the program's performance when editing [projects](Glossary_o_projekte.htm) in EPLAN.

To obtain further information about this topic as well recommendations please contact the EPLAN Support.

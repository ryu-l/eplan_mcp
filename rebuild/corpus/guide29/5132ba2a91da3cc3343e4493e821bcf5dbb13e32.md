# Editing Sequence of Grouped Objects

If the Consider groupings option is selected, then all [actions](Glossary_o_aktionen.htm) such as deleting, copying, moving etc., are performed for the entire group. Editing actions relating to the [properties](Glossary_o_eigenschaften.htm) of the [objects](Glossary_o_objekte.htm) (e.g. particular options in the popup menu or calling up the [property dialog](Glossary_o_eigenschaftendialog.htm)), are however only performed on one object in the group. Different objects within a group have a particular sequence. This sequence defines which object in the group is edited. Logical objects ([functions](Glossary_o_funktionen.htm)) will receive preference to graphical objects.

If the group contains several functions, then the representation type defines which function "takes priority" for the editing:

- Multi-line
- Overview
- Pair cross-reference
- Single-line
- [P&I diagram](Glossary_o_ri_fliessbild.htm)
- External.

This allows easy editing of mounting panel objects or [symbol macros](Glossary_o_symbolmakros.htm) containing only one function. Symbol [macros](Glossary_o_makros.htm) containing (e.g.) functions with "Multi-line" and "Pair cross-reference" [representation types](Glossary_o_darstellungsarten.htm) (such as valves, cylinders with end switches, etc.), can be edited.

### Manual selection of the function to be edited

In groups with several functions, you can also manually define which function is to be edited by selecting it. Graphical components are ignored in this.

When selecting a [component](Glossary_o_schaltzeichen.htm) with any representation type other than "graphical", the jump functions and properties relate only to the selected function. The specific popup menu for this function is thus displayed and (e.g.) the property dialog for this function is opened. Moving, deleting, and copying still relate to the entire group.

When selecting a graphical element or component with the "graphical" representation type, the component with the highest representation type is searched for and the relevant popup menu or property dialog for this is opened. If no element of highest value can be found in the group (i.e., the group only contains graphics, text, and components of representation type "graphical"), then the objects are edited as a block.

![](../Pictures/Gui/ALL/info.png)Tip:

You can select individual element points within a group using the keyboard ([Ctrl] / [Alt] + arrow keys or [Tab]).

### Block editing of graphical elements

The graphical elements of a group can be edited as a block by (briefly) deselecting the Consider groupings option and selecting the affected elements.

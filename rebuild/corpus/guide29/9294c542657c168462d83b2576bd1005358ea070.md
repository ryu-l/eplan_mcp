# Considering Connection Properties when Exchanging Source and Target

By activating the Exchange source and target ([ID](Glossary_o_id.htm) 31013) property you could previously only reverse the direction of the connection for individual [connections](Glossary_o_verbindungen.htm) (meaning exchange the source and target). You can now exchange source and target including source- and target-dependent connection properties at selected connections.

To this purpose mark the desired connections In the graphical editor or the connections navigator. Alternatively you can mark a page / [layout space](Glossary_o_bauraum.htm) or a project in the page or layout space navigator. Subsequently select the new menu item Exchange source and target in the menu Project data > Connections.

![](../Pictures/Gui/ALL/benefit.png)Benefit:

When exchanging source and target via the new menu item Exchange source and target, connection [properties](Glossary_o_eigenschaften.htm) such as, for example, the [wire termination processing](Glossary_o_verbindungsende_behandlung.htm), the [connection dimension](Glossary_o_anschlussmass.htm) or the routing track information are exchanged as well. These properties are amongst others required during the manufacturing data export or when [routing connections](Glossary_o_verlegeverbindungen.htm). Repeating of routing is not required anymore after exchanging source and target.

If a connection exists in several [representation types](Glossary_o_darstellungsarten.htm) in a project, source and target are exchanged globally. The direction of the connection is then the same at all representation types.

In addition, the sequence of the [routing paths](Glossary_o_strecken.htm) passed through is revered in the properties Layout space: Routing track (ID 31095) and Topology: Routing track (ID 20237). You can find a list of properties that are exchanged in the help system in the section "[Connections: Principle](connectionbrowsergui_k_prinzipverbindungen.htm#I_QuelleZielTauschen)".

When exchanging source and target via the new Exchange source and target menu item, the Exchange source and target property is changed at the same time. This property, however, now serves only for display purposes and cannot be changed manually. For unplaced connections and routing connections in the layout space or in the [topology](Glossary_o_topologie.htm) this property is not reported and not updated.

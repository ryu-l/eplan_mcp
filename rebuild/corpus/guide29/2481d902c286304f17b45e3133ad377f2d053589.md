# Managing Master Data

Master data files to be edited or stored in the project can be opened in the standard dialog, which is in a default directory. You can specify [settings](Glossary_o_einstellungen.htm) for this via Options > Settings > User > Management > Directories.

Actual storage and management depends on the type of [master data](Glossary_o_stammdaten.htm) in question, in which the program distinguishes between the management of:

- [Parts data](xmasterdatasettingsgui_h_artikeldatenverwalten.htm)
- Forms
- Plot frames
- [Macros](xmasterdatasettingsgui_h_makrosverwalten.htm)
- Symbol libraries.

If the specified [form](Glossary_o_verlauf.htm) / plot frame is not in the master data pool, it can be found using the Complete project function and can even be automatically stored. If missing master data can't be found in the master data pool, a message is displayed.

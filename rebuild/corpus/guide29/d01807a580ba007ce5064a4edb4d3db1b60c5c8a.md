# Inserting Text

Precondition:

You have opened a page, [form](Glossary_o_verlauf.htm), plot frame or symbol.

1. Insert > Graphic > Text
2. Enter the desired text in the [Text](gededitgui_r_text.htm) tab of the [property dialog](Glossary_o_eigenschaftendialog.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) As soon as you have opened the dialog for entering and editing texts, the status bar shows the current data entry language.

![](../Pictures/Gui/ALL/info.png)Tip:

The popup menu provides you with the possibility to further edit the text. You can, for example, enter special characters and line breaks. Line breaks can be entered using [Ctrl]+[Enter].

3. In the Format tab, specify the format [properties](Glossary_o_eigenschaften.htm), such as size, color and alignment, as well as the border properties, such as whether the text is placed within an alignment box and how it is adapted into the alignment box.
4. Click [OK].
5. Place the text on the page.

![](../Pictures/Gui/ALL/info.png)Tip:

To convert text into path function text, select the Path function text check box.

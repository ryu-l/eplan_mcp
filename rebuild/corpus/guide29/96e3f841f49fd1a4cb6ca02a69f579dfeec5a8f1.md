# Defining graphics depending on property values in forms and plot frames

The Assignment: Property / value to graphic [form](Glossary_o_verlauf.htm) / plot frame property is required to display a specific graphic in the data area for a property that has a specific value.

Preconditions:

- You have opened a project.
- You have opened the form whose [properties](Glossary_o_eigenschaften.htm) you would like to edit in the form editor (Utilities > Master data > Form > Open > [Open]). Or you have opened the plot frame, whose properties you would like to edit in the plot frame editor (Utilities > Master data > Plot frame > Open > [Open]).
- You have opened the Form properties - <Form name dialog ( Popup menu > Properties in the form in the navigator dialog Pages - <Project name>). You have opened the Plot frame properties - <Plot frame name dialog ( Popup menu > Properties in the plot frame in the navigator dialog Pages - <Project name>).

1. Click [...] in the Value column of the Assignment: Property / value to graphic property in the Form properties - <Form name> / Plot frame properties - <Plot frame name> dialog.
2. In the Assignment: Property / value to graphic dialog, click ![](../Pictures/Gui/ALL/all_new_as.png) (New), to [create](Glossary_o_erstellen.htm) a new line in the assignment table.
3. In the Category / property field, click [...].
4. In the Property selection dialog, select the property to which you want to assign a graphic.
5. Click [OK].
6. In the Value field, enter the value that the property should have.
7. In the Symbol name field, click [...].
8. In the Symbol selection dialog, select the symbol whose graphic you want to assign to the property.
9. Click [OK].  
     
   ![](../Pictures/Gui/ALL/arrow.png) The associated data is adopted in the Symbol library and Description fields.
10. In the Symbol variant field, select the desired symbol from the drop-down list of all the existing [variants](Glossary_o_varianten.htm) of the current symbol.
11. Perform all further assignments in a similar manner.
12. Click [OK].  
      
    ![](../Pictures/Gui/ALL/arrow.png) The assignments are saved and can be inserted in the form / plot frame using placeholders.

The assignments are displayed in the Value column of the Form properties - <Form name> / Plot frame properties - <Plot frame name> dialog as follows:

<Property number>;<Category>;<Value>; <Symbol library>;<Symbol number>;<Variant>|  
<Property number>;<Category>;<Value>; <Symbol library>;<Symbol number>;<Variant>|...

20400;0;SIE;SPECIAL;310;0|1120;0;A\*;IEC\_EPLAN\_D;7;1

![](../Pictures/Gui/ALL/note.png) Note:

Take care that only the [symbols](Glossary_o_symbole.htm) of the stored [symbol libraries](Glossary_o_symbolbibliotheken.htm) are displayed.

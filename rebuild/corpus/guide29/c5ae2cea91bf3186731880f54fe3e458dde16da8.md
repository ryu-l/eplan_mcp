### Routing points

User interface / operation

Routing points are characteristic points in the routing path network, such as curves, wall cut-outs, an offset, an outlet in the path, enclosure openings, etc. The routing point is used as a jump-in point for the connection to a target, as a junction to another routing path or as a connection of routing paths.

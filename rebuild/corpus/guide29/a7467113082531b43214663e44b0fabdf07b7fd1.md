# Routing Connections Freely

The free routing of [connections](Glossary_o_verbindungen.htm) generates curved electrical engineering or Fluid power [routing connections](Glossary_o_verlegeverbindungen.htm) outside of a routing path network. Such connections are needed when the use of [wire ducts](Glossary_o_verdrahtungskanaele.htm) is impossible or not customary:

- For routing [wires](Glossary_o_draehte.htm) with large cross-sections
- When routing, e.g., Ethernet cables
- For the definition of [routing tracks](Glossary_o_verlegewege.htm) in complex housing situations
- For the flexible direct connection of electrical [devices](Glossary_o_betriebsmittel.htm), e.g., devices mounted on a swivelable door
- For the connection of Fluid power devices to [hose lines](Glossary_o_schlauchleitungen.htm) outside of a routing path network.

Freely routed connections are often mounted or bundled with routing [accessories](Glossary_o_zubehoer.htm) ([cable](Glossary_o_kabel.htm) / tubing clamp, cable / tubing tie, [cable / tubing protection](Glossary_o_kabel_schlauchschutz.htm)).

A freely routed connection is generated along a defined spatial curve between the source and target devices. No routing path network is expected or needed. Following the exit from the connection point, the connection is first aligned at the curve run tangentially to the connection point direction, and runs again tangentially at the target in the direction of the target connection point.

The curve run of a freely routed connection can be modified subsequently. As such, the position of control points can be changed, or new control points can be inserted. After modifying the curve run, the connection is re-routed.

Precondition:

You have opened a project. A [layout space](Glossary_o_bauraum.htm) is open that contains connections to be routed freely.

![](../Pictures/Gui/ALL/note.png)Note:

You can select the connections to be routed freely before or after the function call. The possibilities for the selection of connections to be routed freely are the same as those for routing in a routing path network.

Use the Free routing (layout space) popup menu item in the connections navigator to specifically [route](Glossary_o_verlegen.htm) multi-line connections outside of the routing path network.

1. Select the Project data > Connections > Free routing (layout space) menu [items](Glossary_o_bauteile.htm) or the popup menu item Free routing (layout space) in the connections navigator.  
     
   ![](../Pictures/Gui/ALL/arrow.png) In the status bar, you are prompted to select the connections to be routed.
2. Enter the two corner points of a rectangle that comprises the [part placements](Glossary_o_artikelplatzierungen.htm) and connections to be routed.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The curve for the [form](Glossary_o_verlauf.htm) of the routing connection is calculated.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The routing connections are generated and assigned the specific [properties](Glossary_o_eigenschaften.htm).  
     
   ![](../Pictures/Gui/ALL/arrow.png) The routing connections are displayed in 3D representation.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

Freely routed spatial routing connections outside of the routing path network

![](../Pictures/Visualisation/ALL/routing_freerouting_as.png)

3. To modify the form of the freely routed connection, select the menu items Edit > Graphic > Change curve run and Edit > Graphic > New control point.

# Dialog Net extension (Numbering with PLC Data)

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a project. You have opened the dialog [Settings: Number using PLC data](offlinenumerationplcgui_d_einstellungen.htm) (for example with Options > Settings > Projects > "Project name" > Devices > Number using PLC data). Select a [user-defined](Glossary_o_benutzerdefiniert.htm) scheme in the dialog Settings: Number using PLC data and click [Net extension].

In this dialog you extend the definition of the net. This setting affects the designation if the range is selected as "Net". The net extension for numbering with PLC data is independent of the Net-connecting property of the function concerned.

Overview of the main dialog elements:

Selection:

All [functions](Glossary_o_funktionen.htm) are displayed in a tree view. Use the arrow button to move a selected entry from the list on the left to the list on the right. It is also possible to select a category and move all of the functions within the category.

Net extended with following objects:

The list displays all of the functions that you have moved from the selection list. The net will then no longer end at the selected functions, but rather it will be extended by them.

![](../Pictures/Gui/ALL/all_delete_as.png) (Delete) allows you to remove a selected function from the list.

Popup menu:

| Menu item | Meaning |
| --- | --- |
| Select all (list only) | Selects all of the entries in the list. |

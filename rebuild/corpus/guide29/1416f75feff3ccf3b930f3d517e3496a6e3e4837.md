# Dialog Filter

[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Dialog call:](javascript:void(0);)

You have opened a dialog for which you can specify a filter. Click [...] next to the Filter drop-down list.

In this dialog you specify the filter criteria for a field-based filter. This filter then executes the search in certain record fields (e.g. for the "Type number" field) and it is verified whether the entire field contents match the search text. In doing so, the filter criteria can be saved as [schemes](Glossary_o_schemata.htm) so they can be used again at any time.

Overview of the main dialog elements:

Scheme:

Select the scheme that you wish to use or edit from the drop-down list. You can also use the adjacent [toolbar](schemeconfig_m_schemaschaltflaechen.htm) for this purpose.

---

Table

In this table you specify filter criteria for the object [properties](Glossary_o_eigenschaften.htm). The individual [lines](Glossary_o_leitungen.htm) are AND-combined by default.

Criterion:

In this field you select the property for which you wish to define filter criteria. Use [...] to open a selection dialog displaying the properties in a tree structure.

The OR entry allows you to [create](Glossary_o_erstellen.htm) a line for an OR selection.

Operator:

In this column you choose a comparison operator that binds the property comparison to a value.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

To filter by all [unplaced functions](Glossary_o_nicht_platziertefunktionen.htm), for example, link the Main function criterion using the "=" operator and the value ![](../Pictures/Gui/ALL/all_checkon_as.png), and the Placement criterion using the "=" operator and a blank entry in the Value field.

![](../Pictures/Gui/ALL/note.png)Notes:

- Note that operators in text boxes, such as the "Voltage" field, cannot be evaluated correctly as text boxes can only be used to compare text, and not values.
- The sequence of the entered criteria is normally irrelevant. However, if they have a high degree of nesting, errors may easily arise (such as a closing bracket) and thus cause incorrect filter results.

Value:

Here you enter the comparison value that is to be compared to the selected property. You can use [placeholders](searchandreplacegui_k_platzhalter.htm) (such as "\*" or "?"). Entry of several values within a cell (separated by semicolons) means an OR relationship.

In fields representing a directory, you can enter the "\*" wildcard; all subdirectories in the selection are then included.

Language:

Select the language in which the search is to be carried out from this drop-down list. The default setting is "All languages". If a specific language is selected, the search is carried out only in this language. If no specific language is entered, the search is carried out in all languages.

Quick input:

This field is available if you have opened the Filter dialog, for example, from within a [project data](Glossary_o_projektdaten.htm) navigator.

If the check box is activated, the Value: <Property> field is activated for the relevant navigator as soon as the check filter scheme is selected.

To enter a new value in the Value: <Property> field, click in the field, type in the value, and press [Enter]. The display in the navigator changes accordingly. The value entered here is then accepted as the value of the filter criterion in the filter scheme.

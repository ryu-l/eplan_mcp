# P005050: Duplicate ID for net-based connections within a net (<x>)

### Cause

An additional connection that has not yet been assigned to a daisy chain was placed within a net in the schematic. The additional connection contains a copy of a [component](Glossary_o_schaltzeichen.htm) that is [part](Glossary_o_artikel.htm) of the net. The copying process duplicates the [ID](Glossary_o_id.htm) for [net-based connections](Glossary_o_netzbasierteverbindungen.htm).

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

A net N1 in the schematic connects 5 fuses (-F1 to -F5) with the potential L1. The [connection points](Glossary_o_anschluesse.htm) [form](Glossary_o_verlauf.htm) the following daisy chain:

| Connection point | Source | Target |
| --- | --- | --- |
| L1 | L1 | -F1:1 |
| -F1:1 | -F1:1 | -F2:1 |
| -F2:1 | -F2:1 | -F3:1 |
| -F3:1 | -F3:1 | -F4:1 |
| -F4:1 | -F4:1 | -F5:1 |
| -F5:1 |  |  |

Another fuse -F6 is placed within the net in the schematic with a T-node by copying and renaming fuse -F5.

![](../Pictures/Visualisation/ALL/messages_005046_bsp1.4_av.png)

When the connection is inserted, the daisy chain remains unchanged as the connection point -F6:1 has not yet been assigned to the daisy chain.

| Connection point | Source | Target |
| --- | --- | --- |
| L1 | L1 | -F1:1 |
| -F1:1 | -F1:1 | -F2:1 |
| -F2:1 | -F2:1 | -F3:1 |
| -F3:1 | -F3:1 | -F4:1 |
| -F4:1 | -F4:1 | -F5:1 |
| -F5:1 |  |  |

When the fuse -F4 was copied, the ID (identification number) for the net-based connection was copied as well, so there are now two identical identification numbers "8" in the net.

### Solution

Integrate the copied connection into a daisy chain.

![](../Pictures/Gui/ALL/example.png)[![Closed](../../Skins/Default/Stylesheets/Images/transparent.gif)Example:](javascript:void(0);)

For the above example, the steps are as follows:

1. Locate the relevant net definition point in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
2. Open the Properties <...> dialog for the net definition point.
3. Bring the Net [connections](Glossary_o_verbindungen.htm) tab to the front.
4. Identify the added connection point in the Connection points table.  

   ![](../Pictures/Gui/ALL/note.png) Note:

   When you open the Property dialog, duplicate IDs for net-based connections are no longer displayed in the Connection points table - only unique IDs. In our example, fuse -F6 is automatically assigned ID 9. In fact, the IDs are still duplicated (ID 8).

   The fact that -F6 was added can be seen from the value 0 under Number of targets in the Connection points table.

5. Add the connection point to the daisy chain by clicking ![](../Pictures/Gui/ALL/all_startdaisy_as.png) (Create daisy chain) and highlighting -F6:1 in the Connection points table.  
     
   ![](../Pictures/Gui/ALL/arrow.png) Connection point -F6:1 is copied to the Connections table and entered beneath the horizontal line of the daisy chain. This creates a new daisy chain.
6. Click ![](../Pictures/Gui/ALL/all_enddaisy_as.png) (End daisy chain) to complete the daisy chain.  
     
   ![](../Pictures/Gui/ALL/arrow.png) A horizontal line is created beneath connection point -F6:1 in the Connections table.
7. Select connection point -F6:1 in the new daisy chain, then click the ![](../Pictures/Gui/ALL/all_arrowup_as.png) (Move up) button to move it to the first daisy chain under connection point -F5:1.  
     
   ![](../Pictures/Gui/ALL/arrow.png) This breaks up the second daisy chain.
8. Click [OK] to close the Properties <...> dialog for the net definition point.  
     
   ![](../Pictures/Gui/ALL/arrow.png) The duplicated IDs are automatically removed and the new connection is integrated into the daisy chain for the net.
9. Then start a new check run.

# Drawing Boxes as Polylines

Structure boxes, [black boxes](Glossary_o_geraetekaesten.htm), [PLC boxes](Glossary_o_sps_kaesten.htm), [macro boxes](Glossary_o_makrokaesten.htm) and [drilling pattern frames](Glossary_o_bohrbildkaesten.htm) can also be drawn as [polygons](Glossary_o_geschlossenepolylinien.htm). The SPECIAL symbol library contains the following [symbols](Glossary_o_symbole.htm) for this purpose:

- DC2: Black box as a polyline
- DCF2: Fluid black box as a polyline
- PLCC3: PLC box as a polyline
- SC2: Structure box as polyline
- MC2: Macro box as polyline
- BB2: Drilling pattern frame as polyline.

Precondition:

You have opened a project and are viewing a schematic in the graphical editor.

1. Select the menu item Insert > Symbol.
2. Select the symbol for a box as polyline from the tree or list view of the SPECIAL symbol library, such as DC2 for a black box.
3. Specify the starting point of the polyline and click the left mouse button.
4. Specify the next points of the polyline, and click with the left mouse button each of the points to place.
5. Select the Complete polyline popup menu item to finish drawing the box.
6. Enter the box-specific device data in the Properties <...> dialog.
7. Click [OK].

![](../Pictures/Gui/ALL/info.png)Tip:

You can rapidly select the symbol for drawing a box as a polyline by selecting the respective menu [items](Glossary_o_bauteile.htm) for inserting a box (for example Insert > Box / connection point / mounting panel > Black box) and subsequently pressing the [Backspace]. In the Symbol selection dialog the symbols are already filtered and only symbols with the same function category are displayed.

![](../Pictures/Gui/ALL/note.png)Notes:

- If [grid](Glossary_o_raster.htm)-snap is activated (Options > Snap to grid) a newly created box is exactly on the grid on which it is placed. If grid-snap is not active, the black box can be drawn at any desired position next to the grid.
- In contrast to rectangular boxes, boxes as [polylines](Glossary_o_polylinien.htm) have only one property arrangement which relates to the insertion point. The corner point furthest to the left is selected as the insertion point when positioning the polyline. If multiple points are overlaid, the topmost point is used as the insertion point.
- The drawing of macro boxes and drilling pattern frames is only possible in [macro projects](Glossary_o_makroprojekte.htm).

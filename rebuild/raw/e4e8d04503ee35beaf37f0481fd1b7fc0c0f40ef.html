Dialog Page sorting <Report type>

Dialog call:

You have opened a project.

  • File > Settings > Projects > "Project name" > Reports > Output to pages. Click the [...] in the column Page sorting, e.g. in the summarized parts list line.
  • Tab Tools > Command group Reports > Generate. Button [Settings] > Output to pages. Click the [...] in the column Page sorting, e.g. in the summarized parts list line.
  • Tab Tools > Command group Reports > Generate. Select the Templates tab. Select a report template, click next to the Page sorting field in the Value column and select [...].

You define the Page sorting for reporting in this dialog. The page sorting specifies for which structure identifier levels of the page structure report blocks are to be generated. It is also possible to generate report blocks dependent on the Output group component property.

Note:

Which types of page sorting are available depends on the report type. Total page sorting is the only option available for the "Forms documentation" report type, for example.

Overview of the main dialog elements:

Sort by / into:

Use the drop-down list to define the type of page sorting.

  • From settings: (Not available in the Settings dialog.) If this option is activated, the settings specified in the project settings are used.
  • Structure identifier: If this option is active, then use the check boxes in the lower part of the dialog to determine which identifier blocks are to be evaluated in the report. At least one check box must be activated. If you have selected several identifier blocks, a report block is generated for each combination of structure identifiers. The report blocks are sorted into the page structure according to their structure identifiers.
  • Total: The Total page sorting generates a comprehensive report for the entire project. If this option is selected, all structure identifier levels will be allocated a reporting block. Depending on the amount of project data, this report block may contain one or several report pages.
    If you have selected additional identifier blocks, separate report blocks are generated for each combination of structure identifiers in addition to the total evaluation and sorted into the page structure at the corresponding locations. The settings for the identifier blocks are not available for function-related reports.
  • Output group: If this option is selected, a report block is generated every time the Output group component property changes. This setting cannot be combined with the other settings in the current dialog.
  • Object identifier: If this option is activated, only the Document type check box is activated. When this is activated, the pages can be structured in accordance with the standard DIN EN 61355-1. In doing so, the object identifier assigns a document (i.e. a project page) to a certain object (e.g. a function, a location, or a product).

Example:

You have exclusively selected the Total option for the report type "Table of contents". Eplan generates a table of contents and thus a report block for the entire project. In this example, the report block contains 9 report pages.

If you have activated the Structure identifier option and additionally the Function designation and Location designation check boxes, a separate table of contents is generated for each combination of function designation and location designation, for example for =GB1+A1, =GD1+A2, =GL1+B2.Y1, etc. The tables of contents are sorted into the page structure, meaning that the table of contents for =GB1+A1 is sorted below A1, the table of contents for =GL1+B2.Y1 is sorted below Y1, etc.

Structure / value table:

If the check box is activated in one of the fields "Functional assignment", "Function designation", etc., an individual report block is generated for each structure identifier level of the respective identifier block (for example the functional assignment). In this case the structure depth can be specified by using the drop-down list of the Value column: Here the entries "Full" and, if they exist, "Main identifier" and "Sub-identifier" are available. This setting cannot be combined with the Output group setting. Additionally, the Total setting will not be available for function related reports.

Example:

You have solely activated the Function designation check box for the report type "Table of contents" and set the structure depth "Complete". Eplan generates a table of contents for every structure identifier level of the "Function designation" identifier block, for example =GB1, =GD1, =GD2 etc. This generates the report in several report blocks. The tables of contents are sorted into the page structure below the respective function designation.

Use source / target:

This check box can only be activated for cable diagrams, cable overviews, cable-connection diagrams and connection lists.
If the check box is selected, it is not the device tags of the cables that are used for page sorting, but those of the sources and targets. Cables with different structure identifiers for their source and target (such as location designation, for example), are output in multiple structure identifiers.

Use placement:

If this check box is selected, when reporting devices into different project structures, it is not the structure identifiers of the devices that are considered, but the structure identifiers of the page on which they are placed.

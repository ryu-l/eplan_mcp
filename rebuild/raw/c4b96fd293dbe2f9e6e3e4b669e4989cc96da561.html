Inheriting Drilling Pattern Automatically or Manually

Precondition:

You have opened a project that contains copper items.

Inherit drilling pattern automatically

When equipping copper items, cut-outs can be referenced automatically from one copper item to another. If a copper item is placed on the mounting surface of another copper item, and in the area of the overlap, there is a cut-out, such a cut-out will be referenced automatically to the newly placed copper item. This referencing will be taken into account for the drilling view and exports. After separating the two copper items by deleting or moving, the referenced drilling pattern will not be preserved.

Precondition:

The Automatic multiple cut-out setting is activated (command path: File > Settings > User > Graphical editing > Copper bending > Check box Automatic multiple cut-out).

  1. Place cut-outs, such as drill holes, on the mounting surface of a copper item.
  2. Place a second copper item on the mounting surface of the first item that contains the drill holes.

    Note:

    Make sure that you place the second item parallel to the first item so that the drill holes of the first item are completely covered by the mounting surface of the second copper item.




    The drill holes are carried over to the second copper item and represented there.

Inherit drilling pattern manually

Apart from the automatic inheriting of cut-outs, it is also possible to carry over cut-outs subsequently from one to another, already-placed, copper item.

Precondition:

The items have to be placed parallel to each other so that the drill holes of the source item are completely covered by the mounting surface of the target item.

  1. Select the following commands: Tab Edit > Command group Graphic > Drop-down button Inherit drilling pattern > Update multiple cut-outs.
  2. Click and select the source item whose drilling pattern you wish to carry over. In this context, you can only select copper items.
  3. Select the mounting surface of the item to which you wish to carry over the drilling pattern.

    The mounting surfaces of the target item are highlighted in color upon touching the cursor. Snap points and a coordinate system are displayed on them.
  4. Click to select the required mounting surface.

    The drilling pattern of the source item (1) is carried over to the target item (2).

    Note:

    If further items are located in a copper bundle between the source item and the target item, the drilling pattern is also transferred to these items. Prerequisite for this is that all the items are placed parallel to each other so that a cut-out is possible through the mounting surfaces of all the items.


    The selection of the target item remains active, and you can click other mounting surfaces to which to carry over the drilling pattern.

Update inheritance

The inheritance of the cut-outs can be affected by miscellaneous actions that modify copper items. A modification of the copper items may result in the inherited cut-outs no longer being displayed correctly. If the Automatically update multiple cut-outs setting is activated, the update is executed automatically after each modification of the copper items (command path: File > Settings > User > Graphical editing > Copper bending > Check box Automatically update multiple cut-outs).

But it is also possible to update the inheritance in the total layout space manually.

  1. Select the following commands: Tab Edit > Command group Graphic > Drop-down button Inherit drilling pattern > Update multiple cut-outs.

    In the current layout space, all inheritances of the cut-outs are re-calculated. The display is updated.

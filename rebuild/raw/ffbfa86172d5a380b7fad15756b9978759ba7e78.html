Using User-Defined Property Arrangements

The property arrangement specifies the arrangement of the placed property texts and their display settings at a function. The settings for the contact image are also stored at the property arrangement.

The user-defined property arrangements are saved project-specifically and are assigned to the symbol variant for which it was created. Therefore such a property arrangement is only available for functions with the same symbol variant. For 3D part placements in the layout space the property arrangements are assigned to the function definition and are correspondingly available for 3D part placements with the same function definition respectively.

You can create user-defined property arrangements both at the components or at the 3D part placements themselves or at the configuration in the configuration dialog.

The configuration dialog Configure property arrangements provides an overview of all the property arrangements available in the project. This dialog allows you to export the property arrangements of several selected 3D part placements or components and to import them into another project. In addition you have the possibility to verify the usage of the user-defined property arrangements and to remove property arrangements not used.

Creating property arrangements at components

Precondition:

You have opened a project.

  1. Select a component in the graphical editor or a function in a project data navigator. Or select a 3D part placement in a layout space.
  2. Select the Properties popup menu item.
  3. In the Properties <...> dialog, select the Display tab.
  4. Select the "User defined" entry from the Property arrangement drop-down list and edit the property arrangement.
  5. Use the (New) and (Delete) buttons to add further properties to the list or remove unnecessary ones.
  6. Use the buttons (Cut) or (Copy) to cut or copy the properties selected in the list together with their set display properties. At a different component these properties can be inserted below the selected property into the list of the other property arrangement by using the button (Paste). Properties that cannot be used at a component are not taken into consideration during pasting. (Through such an action the property arrangement is set to "user-defined" at the target component.)
  7. In the list of properties, select the property for which you would like to define the display settings. The default values for the individual fields are taken from the "Default setting".
  8. Edit the display properties in the Property / Assignment table.
  9. Click (Save).
  10. Enter the name for the property arrangement in the Save property arrangement dialog or select an existing name from the drop-down list.
  11. Activate the Use as default check box if you want to specify the property arrangement as the default for all further usages of this symbol variant (at functions) / function definition (at 3D part placements).
  12. Confirm your entries.

    The property arrangement is stored and is assigned to the symbol variant. At 3D part placements the property arrangement is assigned to the function definition.

    If you have defined the property arrangement as the default, this is used by default for the corresponding symbol variant, for example when inserting a symbol. At 3D part placements the property arrangement is used by default for the corresponding function definition.

Tip:

You can use the (Export) and (Import) buttons to export the stored user-defined property arrangements of a symbol variant and to import them into a different project.

Creating property arrangements in the configuration dialog

Precondition:

You have opened a project.

  1. Select the following commands: Tab Tools > Command group Management > Property arrangements.
  2. In the tree mark an existing hierarchy level or an existing property arrangement.
  3. In the dialog Configure property arrangements - <Project name> click the button (New).

    If you have selected a 3D part placement, a symbol variant or the property arrangement of a 3D part placement or symbol variant, the dialog New property arrangement is opened.

    If you have selected a higher hierarchy level in the tree, the marked position is used as a filter for the subsequently opened dialog Function definitions or Symbol selection. The dialog New property arrangement is also opened after the selection of a 3D part placement or of a symbol.
  4. Enter a unique identifying name in the dialog New property arrangement.

    The identifying name cannot be changed later on.
  5. In the Displayed name field enter the name under which the property arrangement is displayed in the project. Multi-lingual entry is possible.
  6. Activate the Default check box if the property arrangement is to be used as the default at all further usages of the 3D part placement / symbol variant.
  7. To select the properties in the respective tab 3D functions or Component, etc. click the button (New).
  8. Specify the display settings for the selected properties in the table Property / Assignment.
  9. Click [OK].

    The property arrangement is stored and is assigned to the symbol variant. At 3D part placements the property arrangement is assigned to the function definition.

    If you have defined the property arrangement as the default, this is used by default for the corresponding symbol variant, for example when inserting a symbol. At 3D part placements the property arrangement is used by default for the corresponding function definition.

Tip:

You can use the popup menu items Copy / Cut and Paste to transfer the property arrangements from a symbol variant or 3D part placement into a different symbol variant or 3D part placement. Properties that cannot be used at a component or a 3D part placement are not taken into consideration during pasting.
It is also possible to insert copied property arrangements within a symbol variant or a 3D part placement. To this purpose the identifying name of the copy is incremented with a counter beginning with "1". You can edit this identifying name until you apply the new data.
A transfer of property arrangements between the areas "Part placement (3D)" and "Component" is not possible.

Alternative possibilities for the assignment of property arrangements

You can specify a property arrangement for a component or a 3D part placement in the Display tab in the property dialog by using the drop-down list Property arrangement. Alternatively you have the following options:

  • When editing functions in tables you can display the Property arrangement column and select a property arrangement from the drop-down list. The list contains all the property arrangements that are available for the respective symbol variant.
  • When creating schemes for external editing, you can select the property arrangement in the Settings: External editing dialog as format element, thereby considering the respective data during export and import.
  • In the property dialog of placeholder objects you can use the property Property arrangement (ID 19307) and assign the user-defined property arrangements as value sets via a variable. The corresponding property arrangements have to exist in the project to this purpose.
  • You can also assign existing property arrangements through a user-defined button in the toolbar. To do so use the Customize dialog to select the action XEsSetPropertyAction and use the ID 19307 of the Property arrangement property as the value for the PropertyId parameter.

Reset property arrangements

Preconditions:

  • You have opened a project page in the graphical editor.
  • You have created at least one user-defined property arrangement.
  1. Select one or more functions that use a user-defined property arrangement in the graphical editor or in a project data navigator. Or select a 3D part placement in a layout space.
  2. Select the following commands: Tab Home > Command group Text > Drop-down button Move > Reset property arrangement.

    The property arrangement is reset to the default setting for the marked functions / 3D part placements. This is either the setting "Default setting" or the property arrangement that you have specified as the default.

Tip:

You can also restore the default settings directly in the property dialog. In the Display tab, select the "Default setting" entry from the Property arrangement drop-down list; all your settings will then be replaced by the defaults.

Notes:

  • When you overwrite a user-defined property arrangement, the modified display settings are transferred automatically to all the functions / 3D part placements that use this property arrangement. This behavior also applies to the importing of property arrangements. If you overwrite one or more property arrangements during importing, the modified display settings are also automatically transferred to all the functions / 3D part placements that use the property arrangements.
  • During the copying and pasting of pages, layout spaces, functions or 3D part placements into a different project or when inserting macros, the user-defined property arrangements are compared. The name of the property arrangement at the function / 3D part placement is retained if the property arrangements are identical or if the property arrangement does not yet exist in the project. If a property arrangement with the same name already exists in the project and is not identical with the property arrangement at the function / 3D part placement, the project setting Apply property arrangements from the project decides which property arrangement is to be used.
  • The property selection is opened through the (Edit) button. This makes it possible to replace a property in the property arrangement by another one (for example the property DT (displayed) by the property DT (full)).

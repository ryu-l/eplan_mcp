Report Types

Report types specify which group of related information should be reported. Report types are predefined and cannot be user-created. In order to output report pages and embedded reports in a formatted and structured manner, you must assign a form to the report type before generating the report. In Eplan, a distinction is made between report types for function-related reports, report types for report overviews, and graphical reports.

Function-related report types

The following report types generate function-related reports:

  • Cut-out legend
  • Device-connection diagram
  • Cable-connection diagram
  • Cable diagram
  • Terminal-connection diagram
  • Terminal line-up diagram
  • Terminal diagram
  • Enclosure legend
  • PLC diagram
  • Pin-connection diagram
  • Plug diagram
  • Symbol overview
  • Topology: Routing path diagram
  • Pre-planning: Planning object plan
  • Pre-planning: Segment template plan
  • Pre-planning: Structure segment plan.

Report types for report overviews

The following report types generate Report overviews:

  • Assembly / module overview
  • Parts list
  • Summarized parts list
  • Device tag list
  • Forms documentation
  • Manufacturer / supplier list
  • Table of contents
  • Cable assignment diagram
  • Cable overview
  • Terminal-strip overview
  • Mounting list
  • Plot frame documentation
  • Placeholder object overview
  • Potential overview
  • Project options overview
  • Revision overview
  • P&I diagram: Piping overview
  • PLC address overview
  • PLC card overview
  • Plug overview
  • Structure identifier overview
  • Title page / cover sheet
  • Topology: Routing path list
  • Topology: Routed cables / connections
  • Connection list
  • Pre-planning: Structure segment overview
  • Pre-planning: Planning object overview
  • Pre-planning: Segment template overview
  • Pre-planning: Pipe class overviews
  • Pre-planning: Substance overviews.

Report types for graphical reports

The following report type generates graphical reports:

  • Operational sequence sheet

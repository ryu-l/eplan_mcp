Dialog Use existing PLC connection points blockwise

Dialog call:

You have opened a project. You have selected one or more PLC boxes and/or PLC connection points in the graphical editor, PLC navigator or device navigator. Or you have selected one or more pages or a project in the page navigator. Tab Devices > Command group PLC > Connection points. In the Select unplaced PLC connection points to place them blockwise dialog, open the tree view or list view, select the desired PLC boxes and connection points and click [OK].

In this dialog you can use other PLC connection points at several multiple selected and placed PLC connection points and as a result transfer their properties to the selected PLC connection points. As a rule placing is used to transfer the properties of non-placed PLC connection points or function templates to the selected PLC connection points.

Note:

If you have selected placed PLC connection points that are located in a PLC box, these will have the DT of the PLC connection points selected for use assigned when you use the 'use existing' function. This does not change the DT of the PLC box and, as a result, the assignment of the PLC connection points to the PLC box is lost. If you want to retain the assignment of the PLC connection points to the PLC box, you should again use the existing PLC box.

Overview of the main dialog elements:

To:

The selected, placed PLC boxes and connection points are displayed in this table. Other objects and unplaced PLC functions are not displayed. The connection points are sorted in their graphical order in the schematic. It does not matter whether the connection points were selected in the graphical editor or in a navigator.

If placements of the same PLC connection point using different representation types (multi-line, single-line, etc.) are selected, then only one entry will appear in the table for this. If the addresses of these placements using different representation types are different, then the <<...>> character string is displayed in the table.

If PLC connection points occur multiple times in the project with the same representation type (with the same DT and connection point designation) then they are also listed multiple times in the table.

From:

The PLC boxes and connection points that you selected for re-use are displayed in this table. The table is empty when the dialog is first called up.

Status:

This column shows whether the PLC box or connection point selected for reuse can be assigned to the PLC box or connection point available in the project in the left-hand table. The icons have the following meaning:

Button

Meaning

Category and group of the PLC function definitions match. It can be used.

Warning: The category of the PLC function definitions match, but the group does not. It can be used, but this could lead to incorrect results.

Error: The category of the PLC function definitions do not match. It cannot be used.

Toolbar:

Use the arrow keys to assign the PLC boxes and connection points selected for use to the existing PLC boxes and connection points available in the project. Only the entries in the right table change their order during this. The assignment of the PLC functions cannot be transferred until the Status column contains no more red error icons.

Button

Meaning

(Delete)

Deletes the contents of the selected lines. No lines are moved.

Opens the Select unplaced PLC connection points to place them blockwise dialog for selection of unplaced PLC connection points. This displays all the functions that are also displayed in the PLC - <Project name> navigator dialog. Multiple functions can be selected here. When you close the dialog, the selected PLC functions are transferred to the right-hand table of the Select unplaced PLC connection points to place them blockwise dialog. The connection points are sorted in the order in which they appear in the Select unplaced PLC connection points to place them blockwise dialog.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

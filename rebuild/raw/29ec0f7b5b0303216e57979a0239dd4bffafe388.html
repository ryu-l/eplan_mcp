Global Editing of Properties on Report Pages

The global editing feature allows you to make changes on report pages that are immediately adopted on all logic pages in all views.

Notes:

  • If you change the data of an object on a report page, then the row or column containing the object on the page is updated. Note that other report pages that may also contain this object data remain unchanged. You may need to also update these reports.
  • On report pages of page types Forms documentation, Plot frame documentation, Revision overview, and Symbol overview, global editing is not possible.
  • Reports generated in a different project lose their reference to the original objects. Global editing on such pages is therefore not possible.
  • Some entries on report pages have no reference to an object. No editing dialog can be opened for such entries - a double-click then always opens the Properties - Placeholder text dialog.

Precondition:

You have opened a report page.

  1. Select the desired placeholder text on the report page.
  2. Select the Properties (global) popup menu item.

    The editing dialog linked to the source object opens.
  3. Make the desired changes in the respective dialog.
  4. Click [OK].

    The changes are immediately adopted on the report page. The data of the source object is also automatically updated on all logic pages in all views.

Example:

While examining an opened device tag list, you discover that a safety fuse has the incorrect DT -F25. Place the cursor over the device tag of this function and select the popup menu Properties (global).

The Properties (global): General device dialog opens. In the Safety fuse (Device) tab, click the Full DT and change (e.g.) the device tag counter to 3. After you close the dialog by clicking [OK] the new DT will be immediately displayed in the device tag list. The device tag is also updated on all logic pages liked to this function (e.g. Schematic multi-line).

The wrong DT for the safety fuse is also shown in the project parts list. Update this page , for example manually. To this purpose mark the parts list in the page navigator and select the following commands: Tab Tools > Command group Reports > Update. The parts list now shows the correct DT.

If you have activated the Properties (Global) Mode (command path: Tab Edit > Command group Options > Global) you can also open the respective editing dialog of the source object with a double-click on a placeholder text. If this mode is not selected, double-clicking a placeholder text opens the Properties - Placeholder text dialog.

Example:

You have opened the table of contents of a project and wish to change the page description of the Feed-in schematic page. To do this activate the Global button in the command group Options of the Edit tab. Then double-click the text to be changed in the report page. The Page properties dialog opens. After changing the text in the Page description field to Feed-in station 1 click [OK]. The new page text is displayed in the table of contents and the changes are immediately adopted in the page navigator and the plot frame of the schematic page.

Tip:

You can set up Eplan so that existing report pages are automatically updated when opened. To this purpose, select the user setting Update reports when opening pages (command path: File > Settings > User > Display > General).

Tab Connected structures

Dialog call:

You have opened a project.

  • You have inserted a structure routing point in the graphical editor or generated one in the topology navigator. In the Properties <...> dialog, select the Connected structures tab.
  • You have marked a structure routing point in the graphical editor or in the topology navigator. Popup menu item Properties. Select the Connected structures tab.

In this tab you specify a filter that is used during the automatic generation of topology functions. The filter acts on the current structure routing points as well as on those connected to it. For the generation of the topology functions a search is carried out in the multi-line or single-line schematic for those functions that correspond to the identification structure of the marked structure routing point or of the structure routing points connected to it and that additionally fulfill the specified filter criteria.

Overview of the main dialog elements:

Selection criteria:

In this table you specify filter criteria. The individual lines are AND-combined by default.

Example:

You have inserted three structure routing points on a topology page and have assigned the device tags =A1+O1-U1, =A1+O2-U2 and =A1+O3-U3 to them. The corresponding structure boxes with the same name, which contain different devices, exist in the multi-line schematic for these DTs. The three structure routing points are interconnected by means of routing paths.

Now you wish to route connections only between the identification structures =A1+O1-U1 and =A1+O2-U2. To do so, open the property dialog for the structure routing point =A1+O1-U1 and specify a filter for the topology functions to be generated automatically. In this example select the criterion Location designation with the operator "=" and the value O2.

When you subsequently generate the topology functions via the command Generate functions automatically (Tab Connections > Command group Topology > Drop-down button Generate > Generate functions automatically) and then route the connections, routing connections only arise between the identification structures =A1+O1-U1 and =A1+O2-U2. Without the filter routing connections would also be generated between the identification structures =A1+O1-U1 and =A1+O3-U3 and between =A1+O2-U2 and =A1+O3-U3.

Reporting and Outputting Piping and Tubing Lists

Piping lists and / or tubing lists can be reported and output using the default settings for connection properties or the connection definition points set for the function definition. The section below describes how you can evaluate such a list using the default settings and output it as a project page. All pipe and tube connections of a fluid power project are shown together in this list.

Preconditions:

  • You have opened a project.
  • The project contains one or more fluid schematic pages with devices of the trades "Hydraulics" and "Pneumatics".
  • Connections exist between the devices of the respective trade.
  • You have access to connection list forms. (Command path: Tab Tools > Command group Reports > Generate > Drop-down button [Settings] > Output to pages. A form entry for the report type "Connection list" must be present, e.g. F27_FT004.)
  • The connection point type "Fluid" is set at the function connection points of all fluid power components. (This connection point type is automatically assigned during insertion of fluid power functions. To check this, call up the Properties <...> dialog for the respective function, bring the Symbol / function data tab to the foreground, and click [Logic].)
  • For all connections in the "Hydraulics" trade you have set the function definition "Pipe" as the default setting, and for all connections in the "Pneumatics" trade, you have set the function definition "Tube" as the default setting. (Command path: File > Settings > Projects > "Project name" > Connections > Properties > Tabs Hydraulics and Pneumatics.)
  • You have defined a cross-section or diameter as the default settings for all fluid connections in the "Hydraulics" and "Pneumatics" trades. In addition, you have defined lengths for all hydraulic and pneumatic connections. (Command path: File > Settings > Projects > "Project name" > Connections > Properties > Tabs Hydraulics and Pneumatics.)
  1. Select the project in the page navigator.
  2. Select the following commands: Tab Tools > Command group Reports > Generate.
  3. Bring the Reports tab in the Reports <Project name> dialog to the front.
  4. Select the [New] popup menu item in the tree view.
  5. In the Select report dialog, select your project in the Source project field (if not already defined) and select the "Connection list" type from the Select report type list.
  6. Click [OK].
  7. In the Settings - Connection list dialog, next to the Filter drop-down list, click [...] to create a new filter scheme.
  8. In the Filter dialog, click (New).
  9. Enter a scheme name in the dialog New scheme, for example "Pipes + tubes", and a meaningful description.
  10. In the Filter dialog, click (New) to the right above the table to define the first filter criterion.
  11. Mark the "Connection: Function definition" entry in the Criteria selection dialog.
  12. Click [...] in the first table cell of the filter dialog below the Value column to select a value for the "Function definition" criterion.
  13. Follow the branch "General > General special functions > Connection > Connection definition" in the tree view of the Function definitions dialog and select the connection definition "Pipe".
  14. Specify a second filter criterion in the second table row in the dialog Filter. Select the "OR" entry.
  15. Create a final filter criterion "Function definition" with the value "Tube" in the third table row.
  16. Click [OK].
  17. Select the "Trade" entry as the sorting criterion in the dialog Settings - connection list.
  18. Click [OK].
  19. In this dialog, you specify how the connection list is to be sorted into the existing page structure of your project. Enter the desired values into the Higher-level function number, Page name, and Suppl. field: Sheet no. fields.
  20. Click [OK].

    The report begins. When this is finished, the pages are output to the project. The generated connection list contains all tubing and piping connections of your project, with the connections being listed sorted by tubes and pipes .

Note:

The following preconditions have to be fulfilled if you wish to report and output a pipe / tube list using the connection definition points placed via the function definition:

  • Connection definition points have to be placed on the fluid power connections.
  • The following properties have to be defined for each of the connection definition points:

    - Cross-section / diameter
    - Connection designation
    - Function definition "Pipe" for the "Hydraulics" trade, and "Hose" for the "Pneumatics" trade
    - Connection: Length with unit.

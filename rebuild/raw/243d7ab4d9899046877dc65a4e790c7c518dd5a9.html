Inserting Devices

By inserting devices you insert the first graphical representation (symbol or macro), the part and all the functions or function templates of a device into the project in a single action.

Tips:

  • When inserting devices or individual objects, you have the option of using the [N] key to browse through the functions and select the one you want. The connection point designations of the selected function are displayed on the symbol. When inserting a macro, [Shift] + [Tab] is used to browse through the representation types. Use [Tab] to browse through the macro variants of a representation type.
  • It is also possible to place an auxiliary function first. The main function (and thus the device) is thus created as an unplaced function.
  • In order to retain the variants selected via the [Tab] key for the inserting / placing of devices, you can activate the setting Retain symbol / macro variant when placing device (command path: File > Settings > User > Devices > General).

Preconditions:

  • You have opened a project page in the graphical editor.
  • You have entered a macro at the part in the parts management, or have defined function templates. A symbol or symbol macro can be entered additionally at the function templates, but does not have to be.
  • If you have not defined function templates, but have stored macros at the parts, the system reads the functions from the macro so that the device can be generated completely. To this purpose it is imperative that the setting Consider macro when generating devices is activated (command path: File > Settings > Projects > "Project name" > Devices > General).

Insert devices in the graphical editor

  1. Select the following commands: Insert center > Breadcrumb trail Home > Devices.
  2. Branch to the desired device in the Insert center via the folder structure or the breadcrumb trail and select it by clicking the preview tile.
  3. Use drag & drop to place the device in the schematic.

    The system selects the macro or symbol that best suits the opened page. The representation type is determined via the page type in the process.
  4. If you want to use a different representation type or a different macro or symbol, press the [Backspace] key before the actual inserting.
  5. Specify the insert options in the dialog Insert device and click [OK].

    Depending on the selected option a subsequent dialog is opened. If you have for example selected the option Macro selection, the Select macro dialog is opened.

    The assigned or selected macro / symbol hangs on the cursor.
  6. Insert the symbol or macro in the schematic.

    The parts data are written to the main function.

    If the part has several functions, then the next symbol will subsequently hang on the cursor.
  7. Insert the further functions of the device.

    When you sequentially insert all functions of the device, the DT adoption is also taken into account.

    After all of the device functions have been inserted, the first device function is once again hanging on the cursor and you can insert it again if you wish.
  8. When inserting auxiliary functions, hold down the [Spacebar] if you want to interrupt the insertion of the auxiliary functions and start again with the renewed insertion of the same device.
  9. End the action via the Cancel action popup menu item or via the [Esc] button.

Inserting devices in the device navigator

With the New device popup menu item that is available in some navigators, the insertion of a device is possible without placement. The following example describes the insertion of a device in the device navigator.

  1. Select the following menu items: Tab Devices > Command group Devices > Navigator.
  2. Select the New device popup menu item.
  3. Select a part in the Part selection dialog and click [OK].

    The system selects the macro or symbol that best suits the opened page. The representation type is determined via the page type in the process.
  4. Insert the symbol or macro in the schematic. The procedure is the same as for inserting devices in the graphical editor.
  5. End the action via the Cancel action popup menu item or via the [Esc] button.

Inserting devices from the device list

You can use the popup menu item Insert device to insert a device immediately with its associated parts data in the device list and in the bill of materials navigator. The procedure is the same as for inserting devices in the graphical editor.

Tip:

You can add parts to a device placed in the graphical editor using drag & drop. To do this select the desired part in the device list, drag the part on the component and press the [Ctrl] + [Shift] shortcut key while dragging. After pressing the shortcut key, first release the mouse button and then the keys. If the device already has one or more parts, then a query is displayed asking whether the existing parts should be enhanced or replaced.

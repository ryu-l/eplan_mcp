New Wiring Manager for Managing Routing Connections

The new Wiring manager dialog allows you to manage routing connections. In this dialog, only the connections relevant for routing and wiring are displayed. For the sake of clarity, saddle jumpers and other connection types that are not relevant for routing in the layout space are deliberately not displayed. In addition, no distinction is made between the representation types of the connections for better clarity.

Benefit:

The new Wiring manager dialog is the central point for retaining an overview of the connections within a layout space and for routing these connections and exporting them for wire fabrication.
The dialog can also be used to display the connection properties and the current status of the connections. Every change to the connection outside the dialog is displayed directly in the dialog. In addition, the status of the connections during routing and export is updated and displayed in the dialog.

A new command is available in the ribbon to open the Wiring manager dialog. If you have opened a project and a layout space, open the dialog via the following command path: Tab Edit > Command group Routing connections > Manager.

Display in dialog

The dialog reacts to the selection in the layout space navigator, in the 3D mounting layout navigator, in the connections navigator, etc. For example, if you select a layout space and start the Wiring manager dialog, all connections running within the layout space are displayed. Only those connections are displayed whose function definitions are taken into consideration during routing and whose source and target are located as part placements in the same layout space. Connections across layout spaces are not displayed.

  • Title bar: During selection in the layout space navigator or in the 3D mounting layout navigator, the name of the first object contained in the selection is displayed in the title bar of the dialog.
  • Toolbar: The number of connections listed in the table is displayed in the toolbar above the table. In addition several buttons are available here with which you can filter the displayed connections according to the routing- and wiring-relevant status. For example, only the connections already routed are displayed with the (Routed connections) button, and the non-routable connections with the (Non-routable connections) button. The quantity of the respective connections is displayed next to each button.
  • Table: The properties of the connection, such as the function definition, source and target of the connection and specific connection properties, are displayed in a row in the table. If required, further columns, for example with information about the routing track or the potential type, can be displayed via the Configure representation popup menu item.
    The connection data is displayed in accordance with the Properties (global) processing mode, meaning that the properties of the associated 2D connection and 3D connection are combined in one row. The properties cannot be changed in the table.

The list of connections can be filtered by layout space and enclosure via the selection in the layout space navigator. This way you can edit each enclosure individually and already enter the wiring data into the manufacturing process while you are editing the next enclosures. You can carry out this procedure consecutively for all layout spaces located in the project.

The connections marked in the dialog can be exported for the wire fabrication (command path: File > Export > Command group Manufacturing data > Wire fabrication). After the export the status for the connections is updated and displayed in the dialog.

Editing via the popup menu

Through the popup menu you have the possibility to jump to the 2D and 3D representation types of the connection for the selected connections or to open the property dialog of the connection in the Properties (global) editing mode.

The Source and Target columns allow editing of the devices connected to the connection and therefore have a deviating behavior. If you have selected a cell in one of these columns, menu items are displayed in the popup menu with which you can jump to the source or target of the connection. In addition you open the property dialog of the respective device in the Properties (global) processing mode with a double-click.

The popup menu also contains commands to route the connections marked in the dialog directly from the dialog or to delete the route (meaning the marked 3D connections).

Display of check run messages

If messages have occurred during routing or during exporting, the status, the check run number and the message text of the first message occurring for the connection are displayed in the Check run: Status, Check run: Number and Check run: Message text columns.

New check run for failed routing

A new check run is available in the message class 026 "3D mounting layout". The check run 026114 "Routing failed: <x>" checks for all connections managed in the Wiring manager dialog whether and why they could not be routed. In the process the check run determines causes that in the past were only output as project messages for source or target (in different layout spaces), as well as causes that in the past were not reported yet (protected cables and connections). The message text with information about the cause is displayed both in the Message management dialog and in the new Wiring manager dialog.

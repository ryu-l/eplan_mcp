Dialog Device list

Dialog call:

You have opened a project.

  • Tab Devices > Command group Devices > Drop-down button Navigator > Device list
  • You have opened an editor such as the graphical editor, the plot frame editor, etc. Tab View > Command group Navigators > Drop-down button Open > Device list

In this dialog you edit the device list. The device list monitors all of the parts used in the project. The dialog is automatically updated when opened, a manual update can be performed at any time using [F5].

The device list is sorted by system part and device description as the standard. The list can be sorted using the column headers.

Overview of the main dialog elements:

Filter:

This drop-down list displays all the available filters. A chosen filter is activated automatically. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the Filter dialog. Here you can create, edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

  • Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
  • Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

Value: <Property>:

Use this field, via Quick input, to adjust quickly the value of a filter criterion for a defined and activated filter.

List:

The device list can display the following properties (configurable via the popup menu Configure representation):

Property

Contents

Project name

The project name is only displayed when several projects are open.

Spare quantity

Contains the difference between the Total number allowed and Used unit quantity properties. Parts with a spare quantity of < 0 are marked by a symbol at the beginning of the line.

Part number

Identifies the part and can be manually entered or adopted from the parts management (or also from an imported list).

System part

Name of the system part in which the device is to be built (e.g. "Conveyor element 15"). Does not come from parts management, but rather has to be separately entered.

Device description

Functionality description. Does not come from parts management, but rather has to be separately entered.

Number allowed

Defined how many times a part may be used in a project.

Total number allowed

Contains the sum of all permitted unit quantities for all respective parts in the device list.

Used unit quantity

Indicates how often a part was actually used in the project. Deviations from the allowed quantity are permitted and will be reported in the test run.

Type number

Taken from parts management based on the part number.

Order number

Taken from parts management based on the part number.

Variant

Taken from parts management based on the part number.

Designation 1 - 3

Taken from parts management based on the part number.

Manufacturer

Taken from parts management based on the part number.

Macro

Shows the macro name when a macro is assigned to the part.

Trade

Shows the first setting for the trade, when trades are assigned to the part.

Subtrade

Shows the text entered for the subtrade, when a subtrade is assigned to the part in the properties dialog.

Popup Menu

Menu item

Meaning

Select all

Selects all parts in the list.

Adjust column width

Adjusts the width of all table columns so that both the headings and column contents are fully legible.

New

Creates a part (using the Properties dialog). The new part is sorted into the list according to the part number.

Add part

Opens the Part selection dialog. You can insert one or more parts into the list; they are appended to the end. Parts may appear multiple times.

Delete

Deletes the selected part. The relevant part is then no longer monitored.

Insert device

Places the selected part as a device. First opens the dialog Insert device in which you can specify the insertion options.

Export

Exports all parts to a file, regardless of the selection. The export type is determined based on the file extension of the file type (XML, text, CSV, etc.).

Import

Imports parts from a file. The import type is determined based on the file extension of the file type (XML, text, CSV, etc.). From this file, the fields Part number, Number allowed and Device description are loaded. The entries are appended to the end of the existing device list.

Go to (graphic)

Displays the first placed object containing a reference to the selected part in the Graphical editor.

Insert into list of search results

Enters all objects in a project referring to the marked parts into the search results list.

Configure representation

Opens the Configure representation dialog in which you can define the properties to be displayed in the list.

Properties

Opens the Properties dialog for the selected list elements. All selected parts are displayed and can be edited (block editing). In the Part number field, [...] starts the part selection. Within the part selection, in this case only a single part may be selected. The properties are automatically updated when the part number changes, as soon as you shift to another field.

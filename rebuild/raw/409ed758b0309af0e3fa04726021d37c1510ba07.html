You are here:

Dialog Drilling views - <Project name>

Dialog call:

You have opened a project. Tab Tools > Command group Reports > Drop-down button Model views > 2D drilling views.

Use this dialog to manage all 2D drilling views in the opened project via the Reports tab.

Overview of the main dialog elements:

Drilling views:

In this tree structure, the top tree-structure level displayed is the "Drilling views" report type to be managed. The second structure level shows the layout spaces contained in the project. Below each layout space node, the 2D drilling views assigned to this layout space are displayed, and below that, the pages on which the report is placed.

Popup menu:

Menu item

Meaning

Update

Modifications to the objects in the layout space are not represented in the report automatically. The Update function harmonizes the 2D drilling view with the current project data in the layout space and corrects the display if objects are changed.

Delete drilling view

Deletes all 2D drilling views below the highlighted node.

Open page (only drilling view node)

Opens the currently highlighted page with the 2D drilling view in the graphical editor. The Reports - <Project name> dialog closes automatically in the process.

Property name / Value:

In these columns, the properties and values of the highlighted 2D drilling views / copper unfolds are shown.

Model view: Frozen:

If the check box of this property is activated, the associated 2D drilling view will be locked for updates. The display remains unchanged even if the objects in the layout space have been modified. With this setting, you can document different edited versions in the 2D drilling views.

Model view: Edge width:

With this property you can set the width of the edge lines in a model view, 2D drilling view and copper unfold to a fixed value, for example 0.5 mm. During zooming and at scale changes the line width is adapted correspondingly. During PDF export the edge lines are output with the specified width.

[Update]:

Modifications to the objects in the layout space are not represented in the report automatically. The Update button harmonizes the 2D drilling view with the current project data in the layout space and corrects the display if objects were changed.

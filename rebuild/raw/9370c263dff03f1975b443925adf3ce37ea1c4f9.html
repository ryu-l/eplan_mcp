Dialog Settings: PLC

Dialog call:

You have opened a project.

  • File > Settings > Projects > "Project name" > Devices > PLC
  • Tab Devices > Command group PLC > Assignment list. In the dialog Addresses / assignment lists select [Extras] > Settings.

In this dialog, you define the project-wide, general settings for PLC data.

Overview of the main dialog elements:

Use address if search for symbolic address is unsuccessful:

If this check box is activated, the (real) address is copied into the determined symbolic address if the search for the symbolic address does not supply a result. This is the case when no sensor or actuator is found during target tracking. Detailed information is available in the section "Automatic Assignment of Symbolic Addresses".

If the check box is deactivated, the determined symbolic address remains empty if the search for the symbolic address does not supply a result.

This setting has no effect on I/O connection points with the representation type "Overview" since no target tracking is possible there. These PLC connection points apply the determined symbolic address from the associated multi-line or single-line PLC connection point.

Treat sensors and actuators equally:

If this check box is checked, no differentiation is made between sensors and actuators when doing target tracking. The search for a target ends as soon as a sensor or actuator is found.

If the check box is not checked, only sensors are searched for from an input, and only actuators from an output.

Extended adoption of path function text:

If this check box is activated, a path function text is searched for in the existing schematic paths at PLC connection points that do not have a path function text and for which no entry was found in the Function text (automatic) field of the connected sensor or actuator. Depending on the connection point direction, a found function text is adopted from the left or from above.

If the check box is not activated, the search for a path function text for the connected sensors and actuators is canceled. The check box is deselected by default.

Assign identifier during import:

This check box is only relevant for the PLC data import in AutomationML AR APC format. This is used to specify how DTs for new devices (meaning devices for which a DT does not exist in the import file) are assigned during importing. DTs existing in the import file are always imported irrespective of this setting and overwrite the DT existing in the project. The devices are identified on the basis of the AutomationML GUID. If the DT is empty in the import file and the device already exists in Eplan, this device retains its DT.

If this check box is activated, identifiers are automatically assigned for new devices during the import of PLC data. The identifier set specified in the Settings for online numbering is used to this purpose. A question mark is also inserted as a tag before the identifier.

If the check box is deactivated, identifiers are not assigned to new devices during importing. The devices are numbered automatically and additionally marked by a question mark.

Interruption macro for rack layout:

Here you specify the macro used in the PLC schematic generation to graphically identify an interruption point on a rack overview. The variant E in this macro file must contain the graphic for the interruption point and the variant F must contain the graphic for the continuation. Click [...] to open the Select macro dialog and select a file from any desired directory.

PLC-specific settings:

Here you define the PLC type-specific settings. The scheme determined here is always used whenever a CPU has not been assigned a scheme. Select an existing scheme from the drop-down list. Click [...] to open the Settings: PLC-specific dialog which you can use to define or edit a scheme.

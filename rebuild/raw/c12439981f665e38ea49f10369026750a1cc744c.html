Import Eplan Electric P8 macros

In the T_Mechatronic_ModularSystem library create the ECAD unit, and in it, the Schematic subunit:

See Creating units.

The unit structure should look like this:

In the Schematic unit, insert a schematic component:

  1. Select the Schematic unit.
  2. Select New > ECAD > Schematic.
  3. Enter Schematic in the Name field.
  4. In the Resource location panel, click [Assign].
  5. Highlight the Template_Project.zw1 file.
  6. Confirm with [Open].
  7. In this process, the Parameter unit was created in addition. This includes the following parameters:
  • FunctionDesignation
  • LocationDesignation
  • ProjectSupplementaryFields
  • Report
  • Script
  • ScriptArguments

The names of the parameters can be set under Model > Model Variables. This way it is possible to define the structure identifiers in P8 in EEC.

Launch the mass import of macros:

  1. Select the ECAD unit.
  2. Select Create Model from Resources from the popup menu.
  3. The Create Model from Resources wizard opens.
  4. Enter the path for the sources in the Source field:

<EEC installation folder>\resources\Tutorial\P8
  1. Confirm via [Next >].
  2. In the next wizard window, the macro files are listed, among other things:

  3. Deactivate all objects that do not reference macros.
  4. For the /Page/page.ema macro, select the Page class.
  5. Apply the new class with [Set].
  6. Confirm with [Finish].
  7. Due to the mass import, the units Page and PLC_Inputs have been created, and they contain the macros. The parameters have been adopted from the macros, and inserted in the Parameters unit:

A parameter is still missing for the page numbering. In the ECAD.Parameter unit create the parameter PageNumber with the type String.

Note

In unit a point '.' is applied like a backslash '\' is applied in data directories.

Specify an abstract page as super class.

  1. Select the Page unit.
  2. Select New > ECAD > Page.
  3. Enter abstractPage in the Name field.
  4. Select the Abstract check box.

  1. Open the Parameters editor page.
  2. Insert the parameters FunctionDesignation, LocationDesignation, PageDescription and PageNumber.

The parameters can be inserted easily in the editor via Drag & Drop. To do so, highlight the parameters and drag them to the editor. The parameters are then sorted exclusively in alphabetical order in the editor. The sequence can be changed via the arrows Move up and Move down.

The Page page is to inherit the properties of the abstract page abstractPage (see Creating discipline components).

Assign the abstractPage super class to the Page page:

  1. Open the Page page.

  2. In the Super class field, select the abstractPage class.

Check the number of parameters. The structure parameters of the abstractPage super class must be included as well as the parameters for the function texts and sockets of the macro file.

Generating Drilling Patterns from DXF / DWG Files

Importing of drilling information from Steinhauer NC files with the file extension *.CNC is not possible directly, since a CNC file always contains all drilling information for all the components of a mounting panel. In order to make this information available for the creation of drilling patterns, the CNC file in the Steinhauer machine software has to be exported into the format DXF / DWG. The exported DXF / DWG files can then be imported into Eplan and used for the creation of drilling patterns by means of drilling pattern frames.

In addition to DXF / DWG files from the Steinhauer machine software, this functionality can also be used to import other drilling data that were exported from other DXF / DWG sources (for example CAD systems).

Note:

A special import scheme is required for the identification of the objects as items, cut-outs or outlines during importing. Select the commands File > Settings > User > Interfaces > DXF / DWG export and import, and create a new scheme.

Prerequisite for the generation of drilling patterns is the assignment of the objects to specific Eplan layers. Assign the four new Eplan layers for the drilling pattern creation (802 - 805) to the respective CAD-specific layer names for items, drill holes, threads and outlines on the Layers tab. These layer names in the company settings are defined (command path: File > Settings > Company > Machining > Export NC - DXF).

To ensure that the DXF / DWG elements are imported in a scale of 1:1, set the Scaling factor setting in the user settings on the Export tab to "1".

Precondition:

You have opened a macro project.

  1. Import a DXF / DWG file. Select the following commands: File > Import > Command group Project data > Project data > Command group Page > DXF / DWG.
    Or insert the DXF / DWG graphic into an opened page. Select the following commands: Tab Insert > Command path External > DXF / DWG. In the process use the import scheme created beforehand with the assignment of the CAD layer names to the Eplan layers for the drilling pattern creation.

    The DXF / DWG graphic is inserted on a new page or one already opened.
  2. Break up any blocks that may be contained in the DXF / DWG graphic. Select the following commands: Tab Edit > Command group Block > Break up.
  3. Check whether the outlines contained in the DXF / DWG graphic are closed.
  4. Insert a drilling pattern frame that encompasses the objects intended for the drilling pattern. Select the following commands: Tab Master data > Command group Insert > Drilling pattern frame.

    5. Tip

    During the generation of the drilling pattern all the calculations of positions and distances of the objects involved reference the point of origin of the drilling pattern frame. The position of the point of origin in the drilling pattern frame determines the position of the point of origin in the drilling pattern to be generated. Use the Move point of origin popup menu item to change the position f he point of origin and thus to set the desired spacing between the first and all following drill holes in the drilling pattern.

  1. Enter the name, a description and a directory for the user-defined outlines to be created in the properties dialog of the drilling pattern frame.
  2. Create the drilling patterns. Select the following commands: Tab Master data > Command group Drilling pattern / outline > Drop-down button Generate > From macro project (automatically).
  3. Select whether the process is to be applied to the complete project or only to the selected drilling pattern frame.

    The drilling patterns are shown in a top view in the parts management from the imported DXF / DWG objects that are assigned to the drilling pattern frames.

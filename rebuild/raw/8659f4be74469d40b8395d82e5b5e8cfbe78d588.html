Influencing Table Displays

In some tabular displays such as the Structure identifier management dialog and the Configure properties dialog for components, and when editing terminal strips and plugs, etc., you can manually change and optimize the display options and sorting sequence of objects.

In addition, you can optimize the column width for all tables.

Notes:

  • Upon confirmation of a new ordering, Eplan notes the positions of the table headers and automatically jumps to the last focused cell when the dialog is reopened. If the ordering within the table has changed, then a jump occurs to either the first or last cell to be edited.
  • The settings for the row height and the "Bold" font are saved like the column width in the dialog memory and can be exchanged with other users via the export and import of the user-specific settings.

Precondition:

You have opened a dialog containing a tabular display.

Sort table objects

In some tabular displays such as the Message management or Layer management dialogs, in tabular editing in the Edit in table dialog, etc., you can sort the objects alphanumerically in ascending or descending order.

  1. Double-click one of the column headers.

    If the displayed data is in the original order, then sorting first takes place in increasing alphanumeric order based on the column whose header you clicked. (An arrow symbol in the column header shows the sorting direction.)
  2. Double-click the same header once more.

    The sorting now occurs in decreasing alphanumeric order, again based on the column whose header you clicked. (An arrow symbol in the column header shows the sorting direction.)
  3. Double-click the same header a third time.

    The column data is now displayed in the original order.

Optimize the display of individual columns

To optimally display a column, i.e. at optimum width, proceed as follows:

  1. Double-click the column separator to the right of the heading of the column whose width you wish to optimize.

    The width of the column is adjusted so that the header and the contents of the column are completely visible.

    If the option Column width automatic was switched on, it is activated.

Optimize the display of all columns

Proceed as follows to optimize the width of all columns:

  1. Select the Adjust column width popup menu item.

    All columns are adjusted so that both the header and the column contents are fully legible.

    If the option Column width automatic was switched on, it is activated.
  2. Or select the Column width automatic popup menu item.

    The columns are customized in such a way that the table is displayed within the overall available area.

    The check box before the popup menu item Column width automatic shows you that the automatic column width is activated. A repeated selection deactivates this option again.

Tip:

You can assign own shortcut keys to the commands Adjust column width and Column width automatic. In order for these commands to be displayed in the Customize shortcut keys dialog in the Commands field, you have to select the "All commands" entry in the Tabs field. The shortcut keys specified in this way can be used in dialogs that can remain open while the project is being edited, for example in message management, in editing in tables or in the list views of the navigators.

Adjusting width of multiple columns simultaneously
  1. In the table select the columns whose width you want to adjust.
  2. For one of these columns click the column separators on the right edge, keep the left mouse button clicked and drag the column to the desired width.

    The width of all selected columns is adjusted accordingly.

Optimizing the display of individual rows

In some dialogs that have a table (e.g. first tab of the property dialog, Properties tab of the parts management), you can customize the row height individually.

  1. In the desired row select the popup menu item Customize row.
  2. Determine the desired row height of the marked row in the Customize row dialog in the Row height field.
  3. If required, activate the Bold check box to emphasize the text of the marked row in bold.
  4. Click [OK].

    The settings made are saved for the marked row.

Note:

In the Edit terminal strip, Edit plug and Multilingual input dialogs the setting for the row height has an effect on all rows of the table. The possibility to emphasize the text in bold is not available here.
In the Dictionary dialog the row height is set fixed to three lines.

Change font size with mouse wheel

In many tabular displays like the Message management or Layer management dialogs, and in tabular editing in the Edit in table dialog, etc., you can change the displayed font size by pressing the [Ctrl] key while simultaneously scrolling the mouse wheel.

  1. Click inside the table.
  2. Hold down the [Ctrl] key and scroll up / down with the mouse wheel.

    The font size in the table is enlarged or reduced.
  3. Select the Font size 100% popup menu item.

    The texts in the table are re-displayed in their original font size.

Dialog Settings: Interruption points

Dialog call:

You have opened a project. File > Settings > Projects > "Project name" > Cross-references / contact image > Interruption points.

Special settings affecting each current project can be made for cross-references at interruption points.

Overview of the main dialog elements:

Display:

In this group box you can specify the following settings:

  • By row / By column: Select the desired option for the display of interruption point cross-references.

  • Number per row / column: Define how many cross-references are to be displayed per row or column. If the quantity is greater than the default value of "1", then the interruption point cross-references are displayed in a matrix.

Example:

If the display is By row and the Number per row / column is set to 3:
0 1 2
3 4 5
6
If the display is changed to By column, the cross-reference display appears as follows:
0 3 6
1 4
2 5

Display cross-reference:

If this check box is activated, the cross-reference will be displayed on interruption points.

Only display page names in cross-reference:

In Eplan, an overview of all interruption points of the same name in the schematic project can be displayed at a specified source interruption point. You can use this setting to suppress the display of the column and line information in the overview: If this check box is selected, the cross-reference is only displayed with the page names (without column and row information).

Example:

The normal cross-reference is 7.8/L-; if the Only display page names in cross-reference check box is selected, then it is displayed as 7/L-.

Note:

Activating or deactivating this check box is only possible if the check box of the Display cross-reference setting is activated.

Display full structure identifier in cross-reference:

If this check box is activated, the full identifier structure of the cross-referenced interruption point is displayed in the cross-reference in addition to page and / or schematic path information (row / column).

Example:

In a project, the identifier blocks "Function designation" and "Location designation" are used. The structure identifier for the identifier block "Function designation" is AA1, the structure identifier for the identifier block "Location designation" is BC1.

An interruption point -L1 is located in the project on the schematic page in column 8 with full page name =AA1+BC1/1. The interruption point's counterpiece of the same name is in column 5 of the schematic page with full page name =AA1+BC1/2. Cross-references are created between both interruption points:

If the Display full structure identifier in cross-reference check box is activated, the entry =AA1+BC1/2.5 is displayed in the cross-reference at the interruption point on page =AA1+BC1/1. At the counterpiece on the project page =AA1+BC1/2, the cross-reference correspondingly reads =AA1+BC1/1.8. If you deactivate the check box, both cross-references will only display the page and / or schematic path information without structure identifiers.

Note:

Activating or deactivating this check box is only possible if the check box of the Display cross-reference setting is activated.

Display target at pair cross-references:

If this check box is selected, then the target is displayed at pair cross-references, where the (first) target and then the cross-reference is displayed (for example, L1/ X1:1 /7.04).

Display target at star cross-references:

If this check box is selected, then the target is displayed at star cross-references.

Example:

Interruption point as a star source with star cross-references (the cross-reference follows the information for the respective target connection point)

Display target under the cross-reference:

If this check box is selected, then the target is displayed below the cross-reference.

Separator between name and cross-reference:

At interruption points, the page and column of a target arrow can be displayed. Here you enter the characters to be used to separate the interruption point designation from the page and column designations in the cross-reference.

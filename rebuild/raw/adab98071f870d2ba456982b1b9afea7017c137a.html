Tab Bundle (Komax - Zeta)

Dialog call:
  • File > Settings > Company > Wire fabrication > Komax - Zeta > Tab Bundle
  • File > Export > Command group Manufacturing data > Wire fabrication > Komax - Zeta. Click [...] next to the Scheme field. Select the Bundle tab.

In this tab you specify in which way the single conductors produced with the Komax - Zeta wire fabrication machine are bundled and how these bundles are to be provided with information.

Overview of the main dialog elements:

Bundle single conductors:

Use this check box to specify whether the single conductors produced are to be bundled.

Bundle type:

If you have activated the bundling of single conductors, use this drop-down list to select the type of bundling. The following bundle types are available to you:

Bundle type

Meaning

Example

Round bundle, one-sided

Single conductors are combined into a round bundle at the connection start or connection end with an adhesive strip.

Round bundle, both sides

 Single conductors are combined into a round bundle at the connection start and connection end with an adhesive strip.

Sequence bundle, one-sided

 Single conductors are fixed on an adhesive strip in a specific sequence at the connection start or connection end.

Sequence bundle, both sides

 Single conductors are fixed on an adhesive strip in a specific sequence at the connection start and connection end.

Loop bundle

Single conductors are bent in a U-shape, so that the connection start and the connection end meet at the same height. Both ends of the connections are then fixed on an adhesive strip.

Chain bundle

The connection end of a single conductor and the connection start of a further single conductor are fixed continuously on an adhesive strip, so that bundling in the form of a chain is produced.

"Info wire" hierarchy level:

In this hierarchy level settings for labeling and length of an "info wire" are available. This info wire is an additionally produced single conductor that the engineer can optionally add to the bundle used. The info wire is only used for information purposes or for additional identification of the bundle and can be printed with property values specially selected for this purpose. No wire termination processing is applied to the info wire.

Attach info wire:

Use this check box to specify whether an info wire is to be added to the bundle.

WireKey:

Enter the "WireKey" for the info wire here. This is a text that is defined as a parameter set in the software settings of the Komax machine and has to be taken from there. The "WireKey" contains information about the part, the connection color and the connection cross-section of the info wire.

FontKey:

Enter the "FontKey" for the info wire here. The "FontKey" is required for printing the info wire. This is a text that is defined as a parameter set in the software settings of the Komax machine and has to be taken from there. The "FontKey" contains information about the text formatting such as font, font size and font color. The maximum text length of this parameter set is 25 characters.

Length:

Enter the length of the info wire here. Values of 42 - 300 mm can be entered.

Note:

If you do not enter a measuring unit, "mm" is assumed. If you want to specify the length in "Inch", enter the measuring unit explicitly. During the export the conversion into "mm" required for the machine is then carried out.

Labeling:

Use the [...] button in the value field to configure the labeling text for the info wire and branch to the dialog Select format elements. Use this dialog to specify the desired properties and formats for the text.

Text spacing:

The text used for labeling is printed as continuous text on the info wire. Use this field to define the distance between the individual text blocks.

Note:

If you do not enter a measuring unit, "mm" is assumed. If you want to specify the distance in "inch", enter the measuring unit explicitly. During the export the conversion into "mm" required for the machine is then carried out.

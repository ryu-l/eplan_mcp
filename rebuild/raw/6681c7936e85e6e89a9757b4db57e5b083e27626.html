Display Properties: Contact Image

Dialog call:

You have opened a project. You have opened a dialog for editing the display properties of placed properties such as, e.g., the properties dialog for a component. You have selected the Contact image tab for the property arrangement. A contact image alignment is already displayed or you select an alignment for the contact image via (New).

  • Tab Display (device)
  • Dialog Property placement

First the (preset) contact image settings are displayed for a contact image with selected alignment in the table Property / Assignment. The contact image settings are specified project-specifically with the exception of the position (File > Settings > Projects > "Project name" > Cross-references / contact image), but they can also be set individually for each device. The component settings have priority over the project setting. To this purpose the hierarchy levels Position and Setting are available. These can be opened by clicking the sign.

Overview of the main dialog elements:

Position hierarchy level

Align automatically:

Deactivate this check box if you want to specify the position of the contact image by entering the corresponding value.

X coordinate / Y coordinate:

Enter the values for the position of the contact image in these fields. The base point is the insertion point for which you have specified the contact image.

Hierarchy level setting

User-defined:

Select this check box if you don't want to adopt the settings from the project settings; deselect the check box if the project-specific default settings should be used (again). (In this case, the input options on this hierarchy level are deactivated, that is, grayed out.)

Display own cross-reference:

Check this check box if the cross-reference of the device should also be displayed in the contact image.

Display as symbol image:

Check this check box if a symbol contact image should be displayed on the device. In this representation type, all of the components are displayed, only the main function is suppressed by default.

Default:

Activate this check box if you want to define the defaults for displaying contact images on the component or for displaying contact images in the schematic path of the component. All the settings between this check box and the Embedded form setting are then activated for selection / activation.

Arrange vertically:

Check this check box if the text for the contact image should be vertical.

Display cross-references vertically:

Check this check box if the cross-reference texts should be displayed vertical.

Underline cross-references of NC and change-over contacts:

Check this check box if the cross-references of NC contacts and change-over contacts should be highlighted with underlining.

Decrease cross-references and connection point designations:

Check this check box if the cross-reference texts and connection point designations should be shrunk; this makes the display easier to read.

Show symbols:

Check this check box if, in addition to the cross-reference texts, the symbols of the contacts should also be displayed in the contact image. The following check boxes offer additional options for influencing the display of symbols in the contact image.

Show cross-references on the left:

Check this check box if the cross-reference should be displayed to the left of the symbol.

Hide left-hand / right-hand connection point designation:

Check this check box if the left / right connection point designation should not be displayed; this can also improve the readability of the display.

Show in tabular form:

Activate this check box if the page number and path areas of the cross references should be displayed in tabular form, where the layout is affected by the Arrange vertically setting; the table headings for NO and NC contacts are then taken from the setting Contact image table: Labeling (command path: File > Settings > Projects > "Project name" > Cross-references / contact image > General).

Table cross with variable length:

Activate this check box if the table cross should automatically be adjusted to the maximum size of the contact image entries. In this case the setting Contact image table: Width / height is not taken into consideration (command path: File > Settings > Projects > "Project name" > Cross-references / contact image > General).

Rotation:

The contact image of a device is normally located in the same path in which the corresponding device is located. If this is not desired, select the angle by which the contact image should be rotated from the drop-down list.

Display of 1st / 2nd part:

Select from this drop-down list whether, and if so where, each part number in the main function / auxiliary block should be displayed. (The setting always follows the alignment of the contact image, and the part numbers are displayed centered in multi-line format.)

Display of 1st / 2nd part type:

Select from this drop-down list whether, and if so where, each part type should be displayed. (The setting always follows the alignment of the contact image, and the part types are displayed centered in multi-line format.)

Embedded form:

Activate this check box if you want to create contact images with the use of embedded forms. All the settings between this check box and the Default setting are grayed out and can no longer be activated.

Form:

From this drop-down list select the embedded form for creating form-based contact images.

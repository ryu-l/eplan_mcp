Overview Reports

In contrast to function-related reports, report overviews provide an overview of several devices as standard, e.g., all terminal strips used in the project.

Report overviews may occur multiple times in the project.

Example:

You have generated two parts lists in the same project. In the first parts list, the item is output with the Manufacturer A filter setting. In the second parts list, the identical item is output with the Manufacturer B filter setting.

Parts lists belong to part assemblies.

Report type

Parts list

Reporting behavior

Report overview

Form

Parts list (*.f01)

Description

All parts used in the project, all parts at part definition points and all part placements without associated parts. All parts are listed individually. Please note that parts with quantity = 0 are usually also output! To avoid this, use a filter.

(See also: Outputting Cable Parts in Reports)

Report overview

Summarized parts list (*.f02)

Description

All parts used in the project, all parts at part definition points and all part placements without associated parts. Identical parts are consolidated and listed in summary. Please note that parts with quantity = 0 are usually also output! To avoid this, use a filter.

Overview of the General Eplan Command Line Parameters

The following general command line parameters are evaluated by Eplan:

Parameters

Description

/NoLoadWorkspace

No workspace is loaded or recreated.

/NoSplash

No splash screen is displayed when the system starts up.

/Language:<Value>

Opens Eplan with the specified dialog language (e.g., /Language:en_US in English). The dialog language specified in the settings dialog remains unchanged.

Eplan can only be opened in the specified language if this language has also been installed and licensed on your system.

/Auto 

Quits Eplan after the command line is executed.

/Quiet

No dialogs are displayed while a command is being executed.

/Frame:<Value>

Determines the main window of Eplan, for example:

  • /Frame:0 => The Eplan main window will not be displayed.
  • /Frame:1 => The Eplan main window will be displayed in the original size and position.
  • /Frame:2 => The Eplan main window will be minimized.
  • /Frame:3 => The Eplan main window will be maximized.

/Setup:<Value>

All settings are set to the default installation values:

  • /Setup:0 => The user, workstation and company settings are reset to the default values of the installation and the databases are backed up.
  • /Setup:USER => The user settings are reset to the default values of the installation and the databases are backed up.
  • /Setup:STATION => The workstation settings are reset to the default values of the installation and the databases are backed up.
  • /Setup:COMPANY => The company settings are reset to the default values of the installation and the databases are backed up.

/PathsScheme

Sets the directory settings to a predefined scheme (e.g., /PathsScheme:MyDirectories). If the stated scheme does not exist, the default scheme will be used.

/Variant

Only specify when Eplan is started via the Eplan.exe file of the "Eplan Platform" component! Specifies the used licensed program variant (values for example "Electric P8", "Fluid", "ProPanel", etc.).

/User:<Value>

<Value> specifies which user settings are to be used during the start. If the rights management is used, this parameter also specifies the corresponding user names.

/Password:<Value>

If the rights management is used, this parameter specifies the password specified for "/User".

/Station:<Value>

<Value> specifies which station settings are to be used during the start.

/Company:<Value>

<Value> specifies which company settings are to be used during the start.

/SystemConfiguration:<Value>

<Value> specifies the scheme name of the system configuration.

/NoRemoting:<Value>

If <Value> = "1", no remote server is started. The default setting is "0", meaning that the remote server is started.

/License:<Value>

<Value> specifies the license predefinition file *.lis (including path specification and file extension) that is to be used.

/UseLastOpenedProjects:<Value>

Specifies whether recently opened projects are to be opened during the start:

  • /UseLastOpenedProjects:0 => No projects are opened.
  • /UseLastOpenedProjects:1 => The most recently used projects are opened.
  • /UseLastOpenedProjects:2 => The most recently used projects are opened if no action is transferred. No projects are opened when a command line is called with specification of an action.

If you start Eplan from the command line with an action, no previously opened projects are opened by default.

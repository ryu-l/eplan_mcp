Use formulas for plugs, sockets, and PLC inputs

Before using the formula for calculating the plug parameter values, the fixed values have to be deleted first.

  1. In the Project Catalog open the Feeder component.
  2. Set the Option_Inspect_available parameter to true.
  3. Open the Mechatronic structure.
  4. For each sensor, delete the value of the IP parameter.

An abstract sensor is required so that the formula for the plug parameter has to be defined only in one location. The concrete sensors are then derived from the abstract sensor and inherit amongst other its parameters.

In the ECAD.PLC_Inputs unit create the abstract sensor with the name abstract_Sensor with the Fragment superclass.

See Creating discipline components.

Assign the abstract_Sensor class as the super class to the three sensors:

  1. Open Sensor_Pressure.
  2. In the Super class field, select abstract_Sensor.
  3. Repeat Steps 1 to 2 for the sensors Sensor_optical and Sensor_Inductive.

The abstract sensor requires a parameter that stores a list of sensors as well as a parameter for the function text.

In the ECAD.Parameter unit create a parameter with the name Sensors and the type Collection, as well as a parameter with the name Functiontext and the type String.

See Create parameter.

Assign the parameters IP, DT, Sensors and Functiontext to the abstract sensor:

  1. Open the abstract_Sensor class.
  2. Open the Parameters editor page.
  3. Add the parameters IP, DT and Sensors.
  4. In the Value field enter the following formula for the IP parameter:

    5. ='I' + ($Sensors.indexOf(origin.ifNull(this)) /8) + '.' + $Sensors.indexOf(origin.ifNull(this)).mod(8)

  7. This formula is used to determine a list of all subordinate components of the abstract_Sensor type.

At a later point you enter a formula for the DT parameter.

The calculation of the socket parameters on the pages requires a parameter that contains the page number.

Create the Page parameter of the String type in the ECAD.Parameter unit, and assign this parameter to the abstract_Page page. The parameter is inherited to the Page subclass.

Formulas have to be entered in the abstract page for the values of the Page and PageDescription parameters. The formulas for the socket parameters Input1 to Input8 are entered directly in the Page page:

  1. Open the abstract page abstractPage.
  2. Open the Parameters editor page.
  3. Enter the following formula in the Value field of the Page parameter:

    4. =mroot.rmos('T_Mechatronic_ModularSystem.ECAD.Page.Page').indexOf(origin.ifNull(this))

  5. Enter the following formula for the PageDescription parameter:

  6. This formula determines the name of the page.
  7. On the Page page enter the following formulas for the parameters Input1 to Input8:

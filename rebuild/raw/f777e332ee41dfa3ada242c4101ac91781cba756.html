Dialog Select paper format

Dialog call:
  • You have selected a project or at least one project page. File > Export > Command group Project data > Project data > Command group Page > PDF. Click the [Settings] button and select the menu item Output size. In the following dialog select the option Scale to page and click the [...] button next to the Width field.
  • File > Settings > Workstation > Graphical editing > PDF output size. You have selected the Scale to page option. Next to the Width field, click the [...] button.

In this dialog, you can select a paper format that will be used for the PDF output.

Overview of the main dialog elements:

Format:

Choose the paper format that you would like to use from the drop-down list. The following formats are available:

Note:

Note that the project pages are not rotated during the PDF output. For example, if you have selected for the output size the A4 portrait paper format, but the project page has the A4 landscape paper format, the project page will be scaled to A5 and output on the PDF page.

Width / height:

In these fields, the dimensions of the selected paper format is displayed in the set displayed unit of length. The dimensions are carried over to the Settings: PDF output size dialog.

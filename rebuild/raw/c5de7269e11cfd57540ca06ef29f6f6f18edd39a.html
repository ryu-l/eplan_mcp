Generating objects

A project component is generated in the following steps:

  1. Determine or directly name the library component to be instantiated.
  2. Determine or directly name the placeholder or extension point on which the instance is to be installed.
  3. Creating and installing the project component into the mechatronic structure by means of the instantiation API.

Example code in Groovy

Requirements:

  • The model data of install\scripting\scripting.eox have been imported.
  • A valid integer value is set for the instances parameter of the Feeder.Move project component.

The following script example ( ScriptingExamples.instantiateAxes) is to be executed on the Move project component. The script generates instances of the Axis library component and mounts them on the Axes placeholder below Move. The arguments instantiationTarget, (row 25), classToInstantiate (row 30), instanceName (row 35), instantiateExtensions (row 40) and context (row 44) are required to this purpose.

The library component to be instantiated determines the method TypeClass.findType() (see rows 20 and 30).

The instantiate(instantiationTarget, classToInstantiate, instanceName, instantiateExtensions, context); method creates an instance and mounts it on the placeholder. (see row 67).

The method is repeated as many times as the value of the instances parameter in the Move project component specifies (see rows 49, 53, and 65).

The uow.saveChanges() method (see row 73) is used to make the change effective in the Unit-Of-Work in the project.

The output of information and possible errors is carried out in the message log (see rows 9, 17, 22, 27, 32, 42, 46, 55, 62, 70, 78, 83 and 88).

import org.foederal.util.ui.messages.UserMessageCollector;
import com.mind8.mechatronic.skill.api.IMechatronicInstantiationAPI;
import com.mind8.mechatronic.skill.api.NoMatchingPlaceholderException;
import com.mind8.mechatronic.skill.eos.TypeClass;
import java.util.ArrayList;

String scriptName = "instantiateAxes";
String info = "### Start of script '" + scriptName + "' ###";
UserMessageCollector.addInfo(PROJECT,'self',null,"Scripting",info);

// determine the UnitOfWork
uow = self.getUnitOfWork();

// determine the absolute name of the marked object
String absoluteName = obj.getAbsoluteName();
info = "absoluteName: " + absoluteName;
UserMessageCollector.addInfo(PROJECT,'self',null,'Scripting',info);

// Component to instantiate
String absLibComp = "T_Mechatronic_ModularSystem.Mechatronic.Functionunits.Axis"; 
info = "absLibComp: " + absLibComp;
UserMessageCollector.addInfo(LIBRARY,'self',null,'Scripting',info);

// Component containing a placeholder or extension point
instantiationTarget = obj;
info = "instantiationTarget: " + instantiationTarget;
UserMessageCollector.addInfo(PROJECT,'self',null,'Scripting',info);

// Library component to instantiate
classToInstantiate = TypeClass.findType(uow, absLibComp);
info = "classToInstantiate: " + classToInstantiate;
UserMessageCollector.addInfo(PROJECT,'self',null,'Scripting',info);

// an instance name set to 'null' forces the instantiation API to create a unique name
String instanceName;

aList = new ArrayList();

// compute inner extension points
Boolean instantiateExtensions = false;
info = "instantiateExtensions: " + instantiateExtensions;
UserMessageCollector.addInfo(PROJECT,'self',null,'Scripting',info);

context = IMechatronicInstantiationAPI.DEFAULT.createInstantiationContext(instantiationTarget);
info = "context: " + context;
UserMessageCollector.addInfo(PROJECT,'self',null,'Scripting',info);

// initialize variable for number of instances
Integer numberOfInstances;

// determine if parameter is existing
if(obj.getParameter('instances') === null){
	numberOfInstances = 0;
	warning = "The parameter 'instances' is not existing.";
	UserMessageCollector.addWarning(PROJECT,'self',null,'Scripting',warning);

}
else{
	numberOfInstances = obj.getParameter('instances').getCalculatedValue().toInteger();
}

info = "numberOfInstances: " + numberOfInstances;
UserMessageCollector.addInfo(PROJECT,'self',null,'Scripting',info);

try{
	for(Integer i = 1; i <= numberOfInstances; i++){
		// instantiate component	
		instance = IMechatronicInstantiationAPI.DEFAULT.instantiate(instantiationTarget, classToInstantiate, instanceName, instantiateExtensions, context);
		aList.add(instance);
		info = "instance: " + instance;
		UserMessageCollector.addInfo(PROJECT,'self',null,'Scripting',info);
	}
		// save the change
		uow.saveChanges();
}
catch (NoMatchingPlaceholderException nmpe){
	// error handling
	err = ("Error: " + nmpe);
	UserMessageCollector.addError(PROJECT,'self',null,'Scripting',err);
}
finally{
	context.deleteUnusedInstances();
	info = "### End of script '" + scriptName + "' ###";
	UserMessageCollector.addInfo(PROJECT,'self',null,'Scripting',info);
}

return aList;

UserMessageCollector.addInfo(PROJECT,'self',null,"End method",methodName);

The instantiation API offers different methods to control the instantiation process more exactly. Concrete placeholders can be specified or the calculation of extension points can be suppressed.

For several instantiations in a sequence, the performance is optimized by reuse of the instantiation context. The instantiate method of the IMechatronicInstantiationAPI.DEFAULT API is implemented with different signatures:

  • instantiate(ITopInstantiationTarget instantiationTarget, MechatronicObjectClass classToInstantiate, String instanceName, boolean instantiateExtensions)
  • instantiate(instantiationTarget, MechatronicObjectClass classToInstantiate, String instanceName, boolean instantiateExtensions, String placeholderName)
  • instantiate(instantiationTarget, MechatronicObjectClass classToInstantiate, String instanceName, boolean instantiateExtensions, Placeholder placeholder)
  • instantiate(instantiationTarget, MechatronicObjectClass classToInstantiate, String instanceName, boolean instantiateExtensions, String placeholderName, IMechatronicInstantiationContext context)
  • instantiate(instantiationTarget, MechatronicObjectClass classToInstantiate, String instanceName, boolean instantiateExtensions, IMechatronicInstantiationContext context)

Eplan Fluid: Definition of Conduits and Lines

Fluid connections can be defined as devices - either as a conduit in which several hoses are combined, or as a piping or hose line. In this regard the following functions definitions of the Conduit / line category are available:

  • Conduit definition
  • Piping definition
  • Hose line definition.

Conduit definition for conduits

The "Conduit definition" function definition allows you to combine several hose connections running parallel into one hose package (conduit) and to treat this as one device. In this case the conduit definition is used like a cable definition and also placed by means of the same commands (Tab Insert > Command group Cables / connections > Cable) . Eplan Fluid automatically recognizes that a conduit definition line is to be inserted on the basis of the used page type "Fluid power schematic (I)".

Graphical representation of the conduit definition in the schematic is carried out by means of the Conduit definition line (PDL symbol from the SPECIAL symbol library) that you drag over the desired fluid power connections that are to be part of the conduit during inserting.

After the conduit definition line has been inserted, connection definition points are placed automatically with an autoconnecting line of a fluid connection at each interface of the conduit definition line. The function definitions of the connection definition points are set to the "Hose" value in order to define a conduit.

The symbol and the variant of the connection definition points can be changed in the dialog Settings: Conduit by using the command path File > Settings > Projects > "Project name" > Device > Bundle. For example you can use the CDPCP2F5 symbol for a tube. In this case the conduit definition line has to be made invisible correspondingly to obtain correct representation of the conduit.

The values in the Displayed DT, Length, Cross-section / diameter, and Unit fields of the conduit are transferred to all the connections contained in it, if the corresponding fields in the properties dialog of the automatically placed connection definition point do not have an entry.

Pipe / hose line connection

Fluid connections can also be defined as lines that are devices and at which device tags can be assigned. You have the possibility to define such a device as a piping or hose line by assigning the function definitions Piping definition or Hose line definition.

After the installation Eplan Fluid provides corresponding symbol macros so that piping or hose lines can be placed as symbols in the fluid schematic. For pipings these are the symbol macros Pipe1 to Pipe5, for hose lines the symbol macro Hose.ems (see following figure).

Simply insert the desired symbol macro into a fluid connection and assign a DT to the device placed by this means. The correct function definition is already preset after inserting.

Display in the navigators

The conduit, piping and hose line definitions are displayed in the device navigator, but not in the cable navigator. Accordingly the commands of the tab Devices, for example the command Number from the command group Devices, can also be executed for conduit, piping and hose definitions.

The tree of the device navigator displays the relevant conduit or line definitions below the conduit / line DT. The icons used for conduit, piping and hose line definitions (placed and unplaced) are the same as the icons for cable definitions (e.g. ).

To display only devices in the device navigator that are conduit, piping or hose line definitions, you can use the function definitions "Conduit definition", "Piping definition" and "Hose line definition" as a filter criterion. If you want to display only the connections generated by the conduit definition in the connection navigator, use the Connection: Association (ID 31142) property with the "Conduit" or "Line" value as the filter criterion.

Reports

To output conduit, piping and hose line definitions, you can use reports of the types "Parts list", "Summarized parts list", "Device tag list", "Connection list" and "Conduit / line plan". Cable-specific reports cannot be created for these devices.

If you want to output only those connections in a connection list that were created by a conduit definition, you can use the Connection: Association (ID 31142) property with the value "Conduit" as a filter criterion.

If you want to output only those connections in a conduit / line plan that were created by a piping or hose line definition, you can use the Connection: Association (ID 31142) property with the value "Line" as a filter criterion to this purpose.

Dialog Settings: Counter reset range

Dialog call:

You have opened a project. You have opened the Settings: Connection numbering dialog (for example by using File > Settings > Projects > "Project name" > Connections > Connection numbering). You have selected a user-defined scheme in the dialog Settings: Connection numbering and have selected the Designation tab. You have selected an entry in the Format groups field and clicked (Edit), or you have clicked (New).

In the Connection numbering: Formats dialog, you have selected a "Counter" type of format element from the Available format elements list and moved it into the Selected format elements list using the arrow button, or you have selected an existing "Counter" type of format element and clicked (Edit).

In the Format: Counter dialog you have selected the Reset per structure / page check box. Click [Settings].

In this dialog, you specify the range within which the counter will be incremented. When one of the specified criteria changes, the counter is reset to its start value.

When designating the connections you can, for example, specify that the connection designations within a counter reset range of this type must be unique.

Overview of the main dialog elements:

Functional assignment ... User-defined:

If the check box in one of these fields is selected, the counter is reset to the start value as soon as the structure identifier for the identifier block in question changes.

Sub-identifiers:

If the check box in one of these fields is selected, the counter is reset to the start value as soon as the sub-identifier for the identifier block in question changes.

Note:

The preceding signs and separators between the individual structure identifiers can not be edited here. They originate from the settings of the Extended project structures dialog, which you open in the Structure tab of the project properties by clicking [Other].

Page:

If this check box is selected, the counter is reset to the start value as soon as the page changes.

Subpage:

If this check box is selected, the counter is reset to the start value as soon as the subpage changes.

Schematic path:

If this check box is selected, the counter is reset to the start value as soon as the schematic path changes. Depending on the plot frame used, the counter is reset per column or per row.

From source:

If this option is selected, the criteria specified above are applied to the source functions of the connections, i.e. the range changes if the criterion at the source of the connection changes.

From target:

If this option is selected, the criteria specified above are applied to the target functions of the connections, i.e. the range changes if the criterion at the target of the connection changes.

Project-specific Check Run Messages for Part Master Data

The check runs of the message class 502 "Part master data" are available in the parts management to verify the part master data. The project-specific check runs of the outdated message class 501 "Part master data" can no longer be executed.

Project-specific check run messages of the old message class 501 "Part master data" can still be stored in projects from older versions (2025 and older). When opening such a project you can remove these messages from the project by means of a prompt. If this has not been done, these messages continue to be displayed in the message management.

For a check run message displayed in the message management from the message class 501 you can branch via the [Properties] popup menu item into the parts management and there eliminate the error at the part. For processed messages, you can select the Completed check box and filter on this property in order to hide them.

In order to obtain a solution suggestion for the respective problem for an old check run message from the message class 501, please refer to the help for the check runs of the message class 502 "Part master data" with the same last three digits (for the check run message 501002 for example in the help for the check run message 502002).

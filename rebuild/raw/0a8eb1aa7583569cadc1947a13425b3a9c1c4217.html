Generating a Report Template

You can specify settings for reports in report templates. These settings can always be reused when generating new reports. Report templates can be generated completely from scratch or based on an existing report.

Precondition:

You have opened a project.

Generate report templates from scratch
  1. Select the following commands: Tab Tools > Command group Reports > Generate.
  2. In the Reports - <Project name> dialog, select the Templates tab.
  3. Click (New).
  4. Select a report type in the Select report dialog and click [OK].
  5. In the Settings - <Report type> dialog, select schemes for the filtering, sorting, and page breaks, and click [OK].
  6. In the <Report type> dialog, specify a structure identifier and a page name for the start page of the report.
  7. Click [OK].

    Eplan creates a report template and automatically allocates the name 0001 for it. If you have already generated a template of this report type, a prompt opens, asking whether or not the old template should be overwritten. If you select [No] here, two templates will be generated with the same name, which you should then change.

Generate report templates from existing reports

Precondition:

You have created a report.

  1. In the Reports - <Project name> dialog, select the Reports tab.
  2. Select a report and select the Create report template popup menu item.

    The report template is created and entered into the Templates tab.
  3. To check or adapt the settings of the report template, select the Templates tab.
  4. Select the template and change the settings in the right-hand area in the Value column.

Create a report template for conditional reports

This method facilitates the creation of conditional reports.

Precondition:

You have created a report template.

  1. In the Reports - <Project name> dialog, select the Templates tab.
  2. Select a report template.
  3. Click the Value column, then the Project filter line, and then [...].
  4. Define a project filter with filter criteria in the subsequent dialog and click [OK].

    If all filter criteria are met in the current project, the check box in the Template active field will automatically be selected. Using the following "Report" and "Generate project reports" method will generate a report from the template.

    If not all filter criteria are met in the current project, the check box in the Template active field will automatically be deselected. In that case, using the following "Report" and "Generate project reports" method will not generate a report from the template.

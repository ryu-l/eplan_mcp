Form-UI elements: Overview

Form-UI element Area Description
uis Structure The Form-UI element <uis> is the top-level element.
form Structure Each Form-UI element <form> appears as a separate editor page of the instance editor.
tabbedPane Structure Multiple Form-UIs can be displayed in a single editor as tabs by using the <tabbedPane> element.
tab Structure A <tab> element corresponds to a tab in which a Form-UI is displayed.
messageForm Structure A <messageForm> is a message window that is displayed as a pop-up.
fileSelectionForm Structure A <fileSelectionForm> is used for file selection.
messageIcon Structure The <messageIcon> element defines the type of message window by assigning a specific icon.
messageText Structure The <messageText> element defines the text displayed in the message window, which is either a normal text or the result of a formula.
pathLocation Structure The element <pathLocation> encompasses the definition of the file extensions permissible for the file selection.
fileFilters Structure The element <fileFilters> encompasses the definition of the file extensions permissible for the file selection.
ext Structure The element <ext> defines with the attribute name a permissible file extension for the file selection window.
fileButtonArea Structure The element <fileButtonArea> encloses the definition of the buttons for a file selection window.
formContentArea Structure The <formContentArea> element encloses the definition of a Form-UI which is displayed in a popup window.
cancelButton Structure Displays the [Cancel] button in the title bar of a messageForm.
noButton Structure Displays the [No] button in the title bar of a messageForm.
okButton Structure Displays the [OK] button in the title bar of a messageForm.
yesButton Structure Displays the [Yes] button in the title bar of a messageForm.
group Placement and grouping By means of the Form-UI element <group>, the elements nested by this tag are grouped.
line Placement and grouping The Form-UI element <line> arranges sub-elements in one line of the Form-UI.
gap Placement and grouping The Form-UI element <gap> creates a defined distance with the pixel unit between two Form-UI elements, which are located in one line (element <line>).
label Field types The element <label> inserts a text.
input Field types The <input> element inserts a simple input field, a drop-down list box, a radio button, a check box or a button with toggle function, which serves for either entering a value or selecting one.
progressBar Field types The <progressBar> element inserts a progress bar.
table Tables The element <table> inserts a table into the Form-UI.
colGroup Tables The element <colGroup> groups columns, which are superordinate set to the same properties.
col Tables The <col> element determines the properties for one or more table columns.
rowGroup Tables The element <rowGroup> groups rows, which are superordinate set to the same properties.
row Tables The <row> element determines the properties for one or more table rows.
td Tables The element <td> inserts a table cell.
pureTable Tables The element <pureTable> is used to display large amounts of data in a table.
column Tables The <column> element is exclusively used for the configuration of columns within <pureTable>.
filters Tables The <filters> element activates the filters for displaying the determined values of the created <pureTable> table.
columnFilter Tables The <columnFilter> element configures one filter per table column within <pureTable>.
img Images The element <img> inserts a picture.
tree Tree structure

The <tree> element is used to display project components in a tree structure.
treeNode Tree structure The <treeNode> element defines subordinate project components to be displayed in the tree structure.
treeNotifications Tree structure The <treeNotifications> element is only implemented in a tree structure when a trigger event occurs that is supposed to execute an action, e.g. when a user clicks a project component.
action Actions Clicking the <action> element initiates a defined action or a component method.
tabNotifications Actions Serves as a container for any number of elements declared by trigger events for actions to be executed.
onEnter Actions Declares the trigger event for an action to be performed when opening.
onClickEvent Actions Declares the trigger event for an action to be performed when a mouse click occurs.
performEvent Actions Defines the action to be performed.
loop Loops and conditions To iterate consecutively multiple times over Form-UI elements, they are enclosed by the loop element <loop>.
switch Loops and conditions The element <switch> with at least one sub-element <case> and one sub-element <default> formulates one or more conditions for displaying either input fields or labels in a column of the pureTable.
case Loops and conditions A condition is formulated with every <case> sub-element.
default Loops and conditions With the sub-element <default>, a sub-element (<input> or <label>) must be specified, which is displayed in the column of the pureTable if the previous conditions are not satisfied.
instantiation Placeholders The <instantiation> element is used to instantiate objects on placeholders.
include Nesting The element <include> inserts the content of a Form-UI at the place where the element tag <include> is positioned.
open

Navigation

 The element <open> opens a Form-UI page or an Internet page.
link Navigation The <link> element opens a Form-UI page.
dialog Navigation The <dialog> element configures a modal dialog window to display a Form-UI page.
command Navigation By means of the <command> element enclosed by the <dialog> element before opening and after closing as well as by clicking the buttons [OK], [Cancel], [Yes] and [No] actions, resp. commands are executed.
browser Web pages The <browser> element shows the content of a web site in a browser within a form-UI.
mailto E-mail The element <mailto> creates a new e-mail by means of the locally installed mail client.
tooltip Tooltips The element <tooltip> creates a tooltip, that appears as a pop-up window.
inputValidators Validation The element <inputValidators> encompasses the specific elements <numberRangeValidator>, <contentValidator>, or <keyValidator> for validation of the input in a text box or a drop-down box.
numberRangeValidator Validation In this type of validation, the content that has been input is converted into a number and compared with the specifications for the lower limit (attribute start) and upper limit (attribute end).
contentValidator Validation In this type of validation, the input content is compared with the given specifications by means of a regular expression.
keyValidator Validation This type of validation compares each letter while entering with the specification of a regular expression.

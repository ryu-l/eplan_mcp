Customizing the Ribbon

You can customize the ribbon to your requirements by adapting the commands of a user-defined command group. These can be commands from the main tabs, rarely used commands of a tab ("Further commands") as well as actions. Furthermore, you can create your own tabs, rename available tabs as well as change the sequence in the ribbon.

Note:

The tab for access to the Eplan Cloud products cannot be adjusted since it is generated dynamically.

Minimize the ribbon
  1. Right-click the ribbon.
  2. Select the Minimize the ribbon popup menu item.

    Only the tabs of the ribbon are still displayed.
  3. Select the Minimize the ribbon popup menu item to enlarge the ribbon again.

Tips:

  • You can also minimize the ribbon by pressing the shortcut key [Ctrl] + [F1]. Enlarge the ribbon by pressing this shortcut key again.
  • To also select a command in the minimized state click in the ribbon on the desired tab.

Creating new command groups

You can assign commands only to a user-defined command group.

  1. Right-click the ribbon.
  2. Select the Customize ribbon popup menu item.
  3. In the Customize dialog, switch to the Customize ribbon tab.
  4. In the Main tab field select the location to which the user-defined command group is to be added.
  5. Click the [New command group] button.

    Below the currently selected tab / command group a new user-defined command group with the name "New command group (user-defined)" is created.
  6. Click the [Edit] button.
  7. Enter the desired name for the command group in the subsequent dialog.

    User-defined command groups are identified by the supplement "(User-defined)" that is attached to the name.

You can use the buttons and to change both the sequence of the command groups and the tabs in the ribbon. The [New tab] button can be used to create a new tab below the selected tab. A new user-defined command group is created at the same time below this tab.

Assigning commands to a user-defined command group
  1. Right-click the ribbon.
  2. Select the Customize ribbon popup menu item.
  3. In the Customize dialog, switch to the Customize ribbon tab.
  4. In the drop-down list Select commands, select the category from which you want to select a command for the ribbon.
  5. Select the desired command in the list located below.
  6. In the Main tab field select the user-defined command group that is to be extended.
  7. Click the button to assign the selected command of the user-defined command group.
  8. Repeat the process to assign further commands.
  9. Click [OK].

    The selected commands are displayed in the respective tab in the ribbon.

Assigning actions of a user-defined command group as commands

Numerous program functionalities in Eplan are realized via so called "Actions". You can select a part of these actions explicitly when customizing the ribbon and this way, for example, store regularly used symbols, macros or other important program actions as quickly accessible commands in the ribbon. These actions are controlled here via a command line.

  1. Right-click the ribbon.
  2. Select the Customize ribbon popup menu item.
  3. In the Customize dialog, switch to the Customize ribbon tab.
  4. In the drop-down list Select commands select the "Actions" category.
  5. Select the desired action in the list located below.
  6. In the Main tab field select the user-defined command group that is to be extended.
  7. Click the button to assign the action to the user-defined command group.
  8. In the subsequent dialog Edit in the Image field select the image which is to be displayed for the command in the ribbon.
  9. For selected action enter the text that is to be displayed for the command in the ribbon in the Displayed name field.
  10. Modify the example entry according to your wishes in the Command line field for the selected action.
  11. In the fields Tooltip and Description enter the texts which are to be displayed as the header and second line in the Tooltip.
  12. Click [OK].

    The selected action is displayed as a command in the respective tab in the ribbon. If you have not selected any image in the Edit dialog, a standard image is shown for the command.

Note:

You can also subsequently edit the settings for such a command. Right-click the ribbon and select the popup menu item Customize ribbon. Then select the corresponding command in the Customize dialog in the Main tabs field, click the [Edit] button and carry out your modifications in the subsequent dialog Edit.

Example:

You can, for example, integrate a text editor in Eplan via the action "Run external program" (XCMUserToolAction). To this purpose specify the file path and the file name in the command line:
XCMUserToolAction /command:"c:\Windows\notepad.exe"

Resetting the ribbon
  1. Right-click the ribbon.
  2. Select the Customize ribbon popup menu item.
  3. In the Customize dialog, switch to the Customize ribbon tab.
  4. Click the [Reset] button.

    After confirming a prompt, the ribbon is reset to the default state again.

Exporting a ribbon
  1. Right-click the ribbon.
  2. Select the Export ribbon popup menu item.
  3. In the subsequent dialog specify the directory and the file name for the export file.
  4. Click [Save].

    The export file is saved in the XML format. The entire ribbon is exported.

Importing a ribbon
  1. Right-click the ribbon.
  2. Select the Import ribbon popup menu item.
  3. In the subsequent dialog select the desired file in XML format.
  4. Click [Open].

    The Customize dialog opens. The commands contained in the import file are displayed in a tree structure in the list below the Select commands field.
  5. Mark the commands that you wish to import. You can select individual commands as well as command groups and tabs.
  6. In the Main tab field select the location to which the user-defined commands are to be added. Individual commands can only be inserted into a user-defined command group.
  7. Click the button to assign the selected commands.
  8. Repeat the process to assign further commands.
  9. Click [OK].

    The selected commands are imported and then displayed in the respective tab in the ribbon.

Tip:

The MfImportRibbonBarAction action allows you to import a ribbon completely. Existing customizations of the ribbon are overwritten in the process.

Note:

Ribbons which were exported with a newer Eplan version than the one currently used cannot be imported. In the case of ribbons that were exported with an older Eplan version, only the user-defined tabs are imported.

    Eplan.EplApi.DataModel

    The namespace for electrotechnical data model includes all the classes/objects belonging to an EPLAN project, like the project itself, pages, functions, placements, etc. Every class is derived from the base class StorableObject and has its specific properties.

    Eplan.EplApi.DataModel.E3DThis sub-namespace of DataModel provides access to 3D placements in a layout space
    Eplan.EplApi.DataModel.EObjectsThis sub-namespace of the electrotechnical data model, contains all classes for special electrotechnical items like cables, terminal strips, or plugs.
    Eplan.EplApi.DataModel.FiltersThis sub-namespace of the electrotechnical data model, contains all classes to filter items like functions or pages.
    Eplan.EplApi.DataModel.GraphicsThis sub-namespace of the electrotechnical data model, contains all classes for graphical items like lines, circles, images, or texts.
    Eplan.EplApi.DataModel.HelpersThis sub-namespace of the electrotechnical data model, contains all helper classes.
    Eplan.EplApi.DataModel.MasterDataThis sub-namespace of the electrotechnical data model, contains all classes for accessing master data stored in the project. The classes SymbolLibrary, Symbol, etc. access the symbols included in the project. The class FunctionDefinitionLibrary lists the available function definitions, which can be assigned to a Function object. The macro classes, like WindowMacro provide the possibility to get information from macro files before inserting them into the project.
    Eplan.EplApi.DataModel.PlanningThis sub-namespace of the electrotechnical data model, contains all classes of the Preplanning module.
    Eplan.EplApi.DataModel.RevisionsThe sub-namespace of DataModel contains objects created by revisions
    Eplan.EplApi.DataModel.TopologyThis sub-namespace provides access to the topology routing paths functionality..

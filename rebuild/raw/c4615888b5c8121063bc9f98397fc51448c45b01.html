Dialog Master data synchronization - system master data

Dialog call:
  • You have installed a new Eplan version in addition to an existing version, and are starting the program for the first time.
  • You have subsequently installed an add-on with master data, and are starting the program for the first time.
  • Tab Master data > Command group Synchronization > Synchronize system master data

In this dialog you specify whether and how the master data in your customer code directories should be updated. When you start a newly-installed update or add-on for the first time, the data is copied automatically if it does not already exist in the target. If there is existing data that would be overwritten, a prompt appears asking you to decide whether the synchronization should take place directly:

  • If you select [User-defined], the master data is loaded, and the Master data synchronization - system master data dialog opens. You can then use this dialog to transfer specific Eplan original master data to specific targets.
  • If you select [Yes], the system master data will be synchronized automatically. Old system master data will be overwritten and non-existent system master data added.
  • If you select [No], you can resume your work without synchronizing.

Overview of the main dialog elements:

Directories:

You can select various directories for master data synchronization from this drop-down list. To be able to do this, you must first have saved these directory settings as a scheme. This may be useful if you are using different master data directories for different companies / customers. Click [...], to open the Settings: Directories dialog and create a new scheme for the directories.

Source:

Select the source for the synchronization from this drop-down list. The list contains the data of all the installed program variants, such as the entries "Eplan Electric P8 Data" or "Eplan Fluid Data".

System master data:

The list of system master data in the company-specific directories contains the following entries:

  • Status: Status information such as "Newer" or "Identical"
  • Name: File name of the master data object, without file extension
  • Type: Master data type (symbol library, form for title page, plot frame, etc.)
  • Modification date: Date of last change to the master data object.

The entries are alphanumerically sorted by columns, with standard sorting being by the Name entry; if you click the Type column header, then all entries are displayed sorted by master data type.

Eplan master data:

The list of Eplan original master data contains the following entries:

  • Status: Status information such as "Not stored" or "Identical"
  • Name: File name of the master data object, without file extension
  • Type: Master data type (symbol library, form for title page, plot frame, etc.)
  • Modification date: Date of last change to the master data object.

These entries are also alphanumerically sorted by columns, with standard sorting being by the Name entry; if you click the Type column header, then all entries are displayed sorted by master data type.

Arrow button:

Use the arrow button to transfer specific Eplan master data to the system master data. Multiple selection is possible.

Filter:

Use this drop-down list to set the dialog for synchronizing the master data so that only specific data is displayed. A chosen filter is activated automatically. The entry "- Not activated -" deactivates the filter and causes an unfiltered display of the data.

  • Show differences: Select this filter to display only the master data that exists both in the Eplan master data for the selected source and in the system master data in the set directories, and has the status "Older" or "Newer".
  • System master data (older): Select this filter so that the System master data list shows only the system master data that is older than the corresponding Eplan master data.
  • Eplan master data (older): Select this filter so that the Eplan master data list shows only the Eplan master data that is older than the corresponding system master data.
  • Extensions: Select this filter so that the Eplan master data list shows only the master data that does not yet exist in the system master data (status: "Only in Eplan master data").
  • System master data (older) and extensions: Select this filter to show both system master data that is older than the corresponding Eplan master data, and the Eplan master data that does not yet exist in the system master data ("Only in Eplan master data" status).

[Update]:

Use the menu options beneath this button to update the master data globally.

Menu item

Meaning

System master data (older)

Replaces all outdated system master data with newer Eplan master data.

Extensions

Adds data that was previously only available in the Eplan master data to the system master data.

System master data (older) and extensions

Replaces all outdated system master data with newer Eplan master data and adds the data that does not yet exist in the system master data.

Notes:

  • If the update would result in a newer version of the master data being replaced with an older one (identified by the entry in the Modification date column), then a message is generated and you can still cancel the update.
  • The master data comparison is not case-sensitive with regard to file names. The file name ABC.XYZ is identical to abc.xyz.
  • To be able to use the updated system master data in a specific project, you must then synchronize the project master data for this project with the system master data.

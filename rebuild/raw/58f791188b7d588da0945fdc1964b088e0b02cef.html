Tab Reports

Dialog call:

You have opened a project. Tab Tools > Command group Reports > Generate. Select the Reports tab.

In this tab, you can specify the settings for all reports, and manage reports that have already been generated.

Overview of the main dialog elements:

<Project name>:

In this tree structure, the names of the current projects are displayed as the top tree structure level. If a source project has been entered for a report, the report is listed under this project's name.
All reports that have already been generated are shown under the project name, sorted by report type. Associated report pages are summarized into report blocks by this.

Icon

Tree structure layer

Meaning

Source project (if stated)

Contains the project that is entered as the source project for the project or the reports / templates.

(Report) pages

Contains all generated report pages.

Function-related report types

Contains all reports of a function-related report type.

Report type for report overview

Contains all reports of a report type for report overviews.

Report blocks (Function-related reports)

Contains all reports belonging to a report block (Function-related reports).

Report blocks (Report overviews)

Contains all reports belonging to a report block (Report overviews).

Report pages / placed reports

Represents a report page or the manual placement of an embedded report.

Embedded reports

Contains all generated embedded reports.

Note:

If a function has several representation types, whose common properties contain varying data, the representation type will determine which properties will be considered during reporting. Eplan uses the specified sequence of the representation types for its global editing and reporting.

Popup menu:

Menu item

Meaning

New

Opens the Select report dialog. Enables the generation of a report.

Update

Re-analyzes the project data of report blocks selected in the tree structure. All data belonging to a report block is updated.

Delete report block

Deletes all report pages belonging to a report block. You must delete embedded reports directly from the project page.

Freeze report pages

Removes the selected report block. The associated report pages remain as they are and are no longer updated. This functionality is not available for embedded reports.

Generate report template

Stores the selected report block as a report template. The stored report template is shown on the Templates tab.

Open page

Opens the currently highlighted page in the graphical editor. The Reports - <Project name> dialog closes automatically in the process.

Tip:

Some functionalities of the popup menu are also available as buttons in the toolbar. This is located above the tree structure in this tab.

Property / Value:

In these columns, the properties and values of the selected reports are shown. Some Properties are available in both the Reports tab and in the Templates tab.

[Settings]:

Menu item

Meaning

Output to pages

Opens the dialog Settings: Output to pages. Enables settings to be specified for reports in pages and embedded reports.

Parts

Opens the dialog Settings: Part. Allows the definition of settings for parts in the bill of materials navigator and in the "Parts list", "Summarized parts list", "Device tag list" and "Enclosure legend" reports.

Display / output

Opens the dialog Settings: Display / Output. Enables the display and output of project data in reports to be limited.

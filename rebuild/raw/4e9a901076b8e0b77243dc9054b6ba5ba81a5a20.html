Unit Groups for Properties of the Field Type "Value with unit"

All property definitions of the field type "Value with unit" now dispose of additional information for the definition of the concrete unit group (such as "Length" or "Pressure"). If a unit group is defined for a property of the field type "Value with unit" and a value without unit is entered for this property, the corresponding default SI unit is used for the value (for example during a conversion).

The unit group can now be specified during the configuration of user-defined properties in the dialog Configure properties. To this purpose the dialog has been extended with the new drop-down list Unit group. In addition the dialog now has a customized layout due to size restrictions and has been divided into the two tabs General and Display. This applies for both the user-defined properties for the project as well as for the user-defined properties in parts management.

The General tab contains mainly the settings that cannot be changed after a user-defined property has been created. The new Unit group drop-down list is also available on this tab. The setting in this field can, however, be changed.

In order to check the properties of the field type "Value with unit" in the project and the part master data, the message classes 022 "Other" and 502 "Part master data" each contain two new check runs:

  • The check runs 022063 and 502040 check whether a unit is missing in the property value if this is defined in the configuration.
  • The check runs 022064 and 502041 determine that the property value has a wrong unit if a unit group is defined in the configuration.

Dialog Edit <...>

Dialog call:

You have opened the Configure hose lines dialog.

  • Double-click the desired row with hose line data in the table.
  • Or mark several rows with hose data in the table and select the Edit popup menu item.

In this dialog you configure the hose lines marked in the table of the Configure hose lines dialog by completing their properties and assigning values. The values offered for selection in the drop-down list are taken from the settings of the selected scheme. As a result of the configuration a hose line identification and a type code are generated.

The dialog offers the possibility of block editing This means that you can edit the selected configuration data of several hose lines simultaneously by using this functionality. If the hose lines to be edited have different values with regard to the properties, this is identified by the entry "<<...>>".

Overview of the main dialog elements:

Hose group box

Working pressure:

The values offered for selection are the maximum permissible dynamic working pressure of the hose line in "bar".

Nominal diameter:

The values offered for selection are displayed together with the unit selected in the settings. If no unit is specified, the entries automatically reference the unit "mm".

Hose type standard:

Since hoses are standardized items, a standard designation is additionally displayed at the hose type. The hose type depends on the selected maximum permissible dynamic work pressure and on the nominal diameter of the hose.

Hose line length:

This information is required for the output of the type code. You have the option of entering the value with or without unit. All entries are converted automatically into the unit stored in the Measuring unit for hose line length field of the General tab.

The hose line length always refers to the measure between the sealing heads or - in the case of curved fittings- to the measure between the middle points of the fitting.

Further specifications group box

Manufacturer:

Click [...] and select the desired hose line manufacturer in the subsequent dialog. This information is required for the output of the hose line identification.

Manufacturing date:

Use the arrow buttons and / or the calendar to specify when the hose line was manufactured. The date is displayed in the field in the format <MM / YYYY>. The manufacturing date is part of the hose line identification (see explanations for the Identification field).

Pressure indication unit:

The selected unit for the working pressure is output in the hose line identification. Here select between the display unit bar or MPa.

Since the unit "bar" is used as the basis in the settings when the working pressure is entered, the hose line configurator converts the value of the working pressure correspondingly for the display if "MPa" is used.

Identification:

This field displays the hose line identification.

The order of the components of the hose line identification fulfils the specifications of the standard DIN 20066. Viewed from left to right the components consist of the values of the following properties:

  • Manufacturer (only short name)
  • Working pressure (with information about the unit)
  • Manufacturing date (The display is effected in the format <YYMM> without slash. For example, the date specification "1608" means that the hose line was manufactured in August 2016.)

The values are separated from each other respectively by a slash with preceding and succeeding blank.

Fitting left / Fitting right:

Click [...] next to the field respectively and from the dialog that opens Select fitting select the desired Series and Type of construction of the fitting that is to be mounted on the left or correspondingly right on the hose. If you have stored a path to an image file in the settings for the selected fitting, an image of the fitting is displayed in the preview window below the respective field.

Torsion angle:

In this field enter the torsion angle for the fittings to be mounted at the hose ends without a unit. A graphic below the field explains how the angle is defined.

Type code:

This field displays the configured hose line that has to be specified to ensure correct ordering of the hose line.

The components of the type code and their output order can be specified in the settings.

If you use the scheme DIN 20066_2012-01 preset by default in the settings, a type code is generated that fulfils the specifications of the standard DIN 20066. In this case the type code consists of the values of the following properties that are displayed from left to right as follows:

  • Hose type (depending on the working pressure and the nominal diameter of the hose)
  • Nominal diameter (without specification of the unit)*
  • Type of construction of the fitting left*
  • Type of construction fitting right*
  • Hose length (without specification of the unit)
  • Torsion angle (only relevant at elbow fittings, without specification of the degree).

The values of the properties marked with an "*" are output in the type code without separators. All the other values are separated from each other by a slash.

[Other]:

Some hose manufacturers offer extended order options for hose lines. For example, hose lines with a tubing protection can be ordered. In order to allow the manufacturer-specific order specifications, this button allow you to add free properties to the type code in the hose line configurator.

Click the button and in the dialog Properties (type code) enter the name and the value of the free property.

Note:

This button is only enabled if the following requirements are fulfilled in the settings of the hose line configurator:

  • One or more free properties are defined and have a respective value assigned in the Further properties tab.
  • Corresponding format elements (free properties and separators) have been added to the type code format in the General tab.

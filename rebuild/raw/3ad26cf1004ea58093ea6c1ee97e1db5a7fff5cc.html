P005047: Net definition point contains incomplete connections

Cause

One or more connections were deleted within a net in the schematic. This creates a gap in the daisy chain. A connection gap is indicated in the property dialog of a net definition point (tab Net connections, Connections table) by a small warning triangle in the Connection points column. In this case the P005046: Incomplete net message is output as well.

Example:

Solution

Complete the net by reintegrating the deleted connection into the net and closing the gap in the daisy chain.

Example:

Proceed as follows with regard to the example listed above:

  1. Locate the relevant net definition point in the schematic using the Go to (graphic) function from the popup menu in the Message management dialog.
  2. Open the Properties <...> dialog of the net definition point.
  3. Bring the Net connections tab to the front.
  4. In the Connections table determine the missing connection point that is indicated by a warning triangle - in this case the -F4:1 fuse is missing.
  5. Close the property dialog and insert a fuse again with the DT -F4.
  6. Use a T-node to connect the connection point of the fuse -F4:1 to the net.
  7. Call up the Properties <...> dialog of the net definition point N1 again and bring the Net connections tab to the front.
  8. Click (Create daisy chain).
  9. In the Connection points table select the connection point -F4:1 with the target number "0".

    Connection point -F4:1 is copied to the Connections table and entered beneath the horizontal line of the daisy chain. This creates a new daisy chain.
  10. Click (End daisy chain) to complete the daisy chain.

    A horizontal line is created beneath connection point -F4:1 in the Connections table.
  11. Select the connection point -F4:1 in the new daisy chain, then click the (Move up) button to move it to the second daisy chain.

    The second daisy chain is deleted in the process.
  12. Position the -F5:1 connection point directly under the warning triangle.
  13. Select the entry with the warning triangle and delete it with (Delete).
  14. Close the Properties <...> dialog of the net definition point by clicking [OK].
  15. If required, start a new check run.

EPLAN Electric P8

The executable file (W3u.exe) of the desired version is to be specified in the EPLAN Electric P8 executable field for the EPLAN Electric P8 discipline. After a normal installation this is located in the directory C:\Program Files\EPLAN\Electric P8\<Version Number>\Bin\. Use [Browse...] to navigate to the file.

Note:

The versions of EEC and EPLAN Electric P8 have to have the same version!

The specification of a base project template (*.zw1 or *.zw9 file) is required in the Macro project template field in order to generate a schematic or a Pro Panel schematic. Use [Browse...] to navigate to the file.

Mark one of the following options to activate its function:

  • Start API automatically in background: When EEC is started, an instance of EPLAN Electric P8 is started in the background. This instance occupies a license.

    • Note:

    This option cannot be executed if the Remote Server > Start a second EC process in background option is activated!

  • Keep plug / socket text objects: When the schematics are generated, the plug and socket text objects are not removed.
  • Keep macro boxes in window macros: When the schematics are generated, the macro boxes of window macros are not removed.
  • Keep macro boxes in symbol macros: When the schematics are generated, the macro boxes of symbol macros are not removed.
  • Keep using projects at generation: The creating and deleting of P8 projects using API takes considerable time. Schematic generation has therefore been optimized so that a project already generated is kept during repeated generating. If the project already exists when a new schematic is to be generated, EEC checks whether the project template for the project has remained the same. If yes, EEC deleted only existing pages and leaves the project. As a secondary effect an error message is no longer generated if the project is still opened in a P8. This is particularly useful, if only individual pages are to be checked in a schematic.
  • Group macros during schematic generation: During the generation of the schematics all the objects belonging to a macro are grouped so that their coherence is not lost.

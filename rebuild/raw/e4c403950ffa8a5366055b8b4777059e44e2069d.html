connection

GRAPH2D

Describes a connection between two nodes of the diagram.

Further elements, which are required for specifying of connections:

  • router
  • backward
  • forward
  • reference

Example code

This example shows the configuration of connections in the Planning_Diagram of the BodyshellWork model. The representation of the connections is specified by the <connection> element and the reference attribute defines, for what connection this representation applies.

<reference id="OrderReference" type="connectable" src="=isInstanceEO() and
	isInstanceOf('BodyShellWork_Architecture.LevelComponents.Function')"
	target="=isInstanceEO() and
	isInstanceOf('BodyShellWork_Architecture.LevelComponents.Function')">
	<forward multiplicity="*" connector="=getParameter('Successor')"/>
	<backward multiplicity="*" connector="=getParameter('Predecessor')"/>
</reference>
	<connection id="Order"
		reference="OrderReference"
		width="3"
		color="17,240,70"
		sourceDeco="empty"
		targetDeco="filled-arrow"/>

Example code

This example code shows a connection with a tooltip, which indicates the names of the start and destination nodes.

<connection id="Order"
	reference="OrderReference"
	width="3"
	color="17,240,70"
	sourceDeco="empty"
	targetDeco="filled-arrow"
	tooltip= "='Predecessor: ' + src.getName() + '|' + 'Successor: ' + target.getName()" />

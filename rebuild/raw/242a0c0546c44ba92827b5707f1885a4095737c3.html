Creating Planning Objects, PCT Loops, PCT Loop Functions, Containers and Connection Planning Objects

Planning objects are created and managed in the pre-planning navigator. PCT loops, PCT loop functions, containers, connection planning objects (piping planning objects, cable planning objects) are created in the same way as general planning objects and are managed parallel to these. You specify the type of planning object that you create through the segment definition.

Note:

PCT loop functions can only be created below PCT loops.

When PCT loops and PCT loop functions are created, the settings for PCT loops specified in the project settings are followed in the pre-planning (command path: File > Settings > Projects > "Project name" > Pre-planning > PCT loops). In this dialog you specify, for example, the properties that are to be identifying in addition to the "Number" and the hierarchical levels that allow for identical PCT loops.

  1. Select the following commands: Tab Pre-planning > Command group General > Navigator.
  2. Highlight the project, a structure segment or an existing planning object, and select the popup menu item New planning object.
  3. Select the desired segment definition in the dialog Select segment definition.

    Depending on the selected hierarchy level, segment definitions for planning objects, PCT loops, containers, piping planning objects or cable planning objects are displayed for selection. If you have selected a PCT loop, only segment definitions for PCT loop functions are displayed.
  4. Click [OK].
  5. Enter the desired data for the new planning object in the Properties <...> dialog. To do so, bring the first tab to the front in the property dialog.

    At PCT loops and PCT loop functions the PCT loop number is combined automatically from the entries in the Designation group box.
  6. Enter the designations of the segments that are to represent the source and target of the connection planning object for a connection planning object. To this purpose the fields Source segment and Target segment are available for piping planning objects, and the properties of the same name are available for cable planning objects. In both cases you can also select source and target segments by using the [â¦] button.
  7. Click [OK].

    A planning object is created with the corresponding properties.

Tip:

When creating connection planning objects you can initially leave the Source segment and Target segment fields empty. The source and target of a connection planning object are then determined automatically later on during placement on a pre-planning page.

Filters and Parts Preselection

In order to use filters and search properly, you must first have prepared the data in parts management properly. These functionalities only work on data entered for the properties in parts management, not the data from the function definitions.

During the part selection these two possibilities can also be combined with each other:

  • Filter: The filter performs the search only on particular record fields (e.g. for the property Type number). The entire field contents are checked to ensure that they match the search text.
  • Find: Any search text can be entered by means of the search. The search in the parts management behaves exactly like the Search in the Insert center. You can use the same operators and placeholder characters. By default only the most important part properties are taken into consideration during the search (such as Part number, Type number, Manufacturer, etc.). To perform the search for all properties, enter a "p" before the search term (for example p:Motor).

Filter settings are stored for each user.

Parts preselection

In addition to the filter you can create and use a parts preselection, meaning a list of parts. Then, during item selection, only parts from this list will be offered. Different lists can be created and stored under a name, so you can use them again and again.

Parts preselection-lists are saved specifically for a project. However, export and import functions allow them to be used in other projects.

Cable selection

In cable selection, there is another filter for the conductor properties of the cable. You can also define a special preselection list for cable parts.

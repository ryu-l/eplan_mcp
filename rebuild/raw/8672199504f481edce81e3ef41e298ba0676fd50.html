Dialog Settings: General (projects, management)

Dialog call:

You have opened a project. File > Settings > Projects > "Project name" > Management > General.

In this dialog you specify general, project-specific master data-specific default settings.

Overview of the main dialog elements:

Synchronize project master data when opening:

Select this check box if the master data used in the project should be synchronized with the master data pool as soon as the project is opened, saved, or restored.

Symbol libraries and forms, however, are only synchronized when the Synchronize check box is also selected for the individual symbol libraries and forms. You define the symbol libraries and forms to be synchronized in the following areas:

  • Symbol libraries: Dialog Settings: Symbol libraries (File > Settings > Projects > "Project name" > Management > Symbol libraries)
  • Forms: Dialog Settings: Output to pages (File > Settings > Projects > "Project name" > Reports > Output to pages)

If the check box is deactivated, the master data is not synchronized when the project is opened, even if the Synchronize check box is selected for the individual symbol libraries and forms.

Synchronize plot frames:

If this check box is selected, the plot frames used in the project are synchronized with the master data pool as soon as the respective project is opened, saved, or restored. A precondition is that the Synchronize project master data when opening check box is selected.

Synchronize stored parts when opening:

If this check box is selected, the parts used in the project are synchronized with the parts in the parts database when the project is opened. If the project parts are obsolete, a prompt opens.

Preferred standards for inserting schematic macros:

In this group box you specify which company standard or which standard is to be used for the insertion of macros. If a schematic macro is stored in the Properties tab of the Parts management at a part for the respective company standard or the respective standard then this macro is used. This applies for nearly all actions where macros are inserted or devices are inserted or placed. You can find further information in the section "Schematic macros: Consideration of company standards and standards".

Company standard:

Here you can enter the name of a company standard. If this name is also entered in the parts management in the Property: Schematic macros for company standard dialog and a schematic macro is stored there for this name, this schematic macro is used when inserting macros.

Standard:

With the drop-down list you specify which standard is to be used when inserting macros. If you select, for example, the "IEC" entry here, the macro which is stored at the part in the Schematic macro: IEC property is inserted.

Notes:

  • If both a company standard is entered and a standard is selected in the group box Preferred standards for inserting schematic macros and if the corresponding schematic macros in the parts management are available at the part, the schematic macro for company standards is used with preference for insertion.
  • If no schematic macro is stored in the parts management for the respective company standard or for the standard, the "default" schematic macro is used. This is the macro which has been selected for the property Schematic macro (ID 22145).

Standard for generating schematic macros:

These settings can only be edited in a macro project! In this group box you specify which company standard or which standard is to be saved during the automatic generation of macros at the respective schematic macro.

To this purpose either enter the desired designation in the Company standard field or select the desired standard in the Standard field. Both fields cannot be filled at the same time.

The setting for the company standard or for the standard is saved at the macro boxes of all generated schematic macros when generating schematic macros. The corresponding value is transferred into the properties Macro: Company standard or Macro: Standard.

On the basis of the setting specified here the automatically generated schematic macros can be filtered when inserting via the Insert center into another project.

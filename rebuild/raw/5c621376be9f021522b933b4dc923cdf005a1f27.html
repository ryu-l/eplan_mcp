Tab Property assignment

Dialog call:

Tab Master data > Command group Parts > Management. Button [Extras] > Import. You have selected the entry ECLASS version in the File type field. Click the [...] button next to the File type field and select the Property assignment tab.

The ECLASS properties can be assigned to the part properties of the parts management in this tab.

Note:

The ECLASS classes must have been selected beforehand on the Class structure assignment tab.

Overview of the main dialog elements:

Toolbar:

Button

Meaning

(New)

Opens the Property selection dialog. Allows you to select one or more ECLASS properties. In this case you can select from the ECLASS properties drop-down list whether you want to use ECLASS properties of the "Advanced" type (default setting) or the "Basic" type. "Advanced" designates a structured properties tree, whereas "Basic" represents a flat properties list.

With the filter you can limit the number of displayed properties. In the Filter field enter the text to be found and click (Find). Both the names of the properties as well their description are searched.

(Delete)

Allows one or more property assignments to be deleted from the scheme.

Table

To assign a part property or a user-defined property to a selected ECLASS property, click the [...] button in the Part property or User-defined property column. This opens the Property selection dialog in which you can select the desired property from the list of available properties. If a part property is already assigned, no user-defined property can be assigned and vice versa.

Whether you assign one or more part properties or user-defined properties depends on the cardinality of the ECLASS property. For further information refer to the topic Parts management: Assignment of ECLASS Properties to Eplan Part Properties.

In the Condition column you can specify filter criteria by clicking the [...] button in a field and selecting the criteria in the subsequent dialog Filter. In the process (New) is used to open the Property selection dialog. Select the ECLASS property for which the filter is to be defined and specify the condition (meaning operator and value) in the Filter dialog.

Example:

Let us assume that you always want to import the file paths from documents of the type "2D graphic" at the same point, for example in the part property External document: File / hyperlink 1, irrespective of the sequence of the properties in the import file. Then you specify the part property External document: File / hyperlink 1 for the property "Source as path specification" and create the condition "Document type = 2D graphics". (The two properties "Source as path specification" and "Document type" can be accessed in the Property selection dialog below the folders Supplementary documentation > Supplementary documentation.)

Notes:

  • The ECLASS properties cannot be assigned to different Eplan properties depending on the class. This is also not necessary since the ECLASS properties are described uniquely through the ID and definition.
  • It is possible to assign several ECLASS properties to one Eplan part property. In this case conflicts can occur during importing if a part has both ECLASS properties. A system message is output and the first imported property "wins".
  • Values and ECLASS properties that are imported in multi-language fields are imported in the languages of the BMEcat catalog, in as far as they exist.
  • The unit of the values is appended, except when importing is carried out into the free properties. In this case it is transferred to the Unit field of the Free properties dialog. If applicable, conversion has to be carried out for fields of the parts database with a fixed unit.
  • The Part number property always has to be filled so that a part can be imported.

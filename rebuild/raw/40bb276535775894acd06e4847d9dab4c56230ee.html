Dialog Property selection (for display)

Dialog call (for the display):

You have opened a project.

  • You have selected one or more components or connection definition points in the graphical editor, or one or more functions in a navigator. Popup menu item Properties. In the Display tab click (New).
  • You have selected one or more segments, which are graphically placed on a pre-planning page or P&I diagram page, in the pre-planning navigator or the graphical editor. Or you have selected a template of a planning object in the pre-planning navigator. Popup menu item Properties. In the Display tab click (New).
  • You have either opened or created a symbol in the symbol editor (Tab Master data > Command group Symbols > Drop-down button Symbol > Open or New). Tab Edit > Command group Symbol > Drop-down button Other > Placed properties. In the Property placement dialog, click (New).

Dialog call (for special texts):

You have opened a project. You have opened a project page in the graphical editor.

  • Tab Insert > Command group Text > Drop-down button Text > Project properties or Page properties. In the Placement tab, click [...].
  • Tab Home > Command group Text > Drop-down button Insert > Project properties or Page properties. In the Placement tab, click [...].

Dialog call (for the property overview):

You have opened a project. You have selected one or more objects (texts, components, segments, graphical elements) in the graphical editor, in the layout space or in a navigator. Tab Home > Command group Edit > Property overview. You have used the button (from scheme). In the property overview click next to the drop-down list on [...]. In the dialog Configure properties click (Edit) or (New) for a row of the Main nodes table. Click (New) in the dialog Configure properties - main node for the Properties list.

Dialog call (for property tables in the parts management):

You have opened parts management. You have opened a parts database using [Extras] > Settings.

  • You have selected a part in the tree or list and selected the Overview tab. Or you have selected a part in the tree or list and selected the Properties tab. Next to the drop-down list, click [...]. In the dialog Configure properties click (Edit) or (New) for a row of the Main nodes table. Click (New) in the dialog Configure properties - main node for the Properties list.
  • You have marked an accessory list, an accessory placement, etc. in the tree and have selected the Properties tab. Next to the drop-down list, click [...]. In the dialog Property configuration click (New) for the Configuration list.

Dialog call (for the configuration of the search):

You are in the parts management, in the part selection, in the part master data navigator or in the Insert center. Click [...] next to the Find field. In the dialog Configure search click (New) for the Configuration list.

In this dialog you select the properties that are displayed at the respective object (function, pre-planning placement, connection definition point, etc.) or in tabs or that are used in a scheme for the property configuration of the property overview or in which the search for the search term takes place.

Overview of the main dialog elements:

Source object:

This field is only available if multiple sources are possible for the properties.

This field lists the possible sources for a property. If you select a source object, the right part of the dialog displays a tab of the same name with the available properties of this source object.

Source objects (for the display):

Source object

Available properties

Function

Properties of the selected function. Available if an auxiliary function or a function template have been selected.

Main function

Properties of the associated main function. Available if an auxiliary function has been selected or a connection definition point whose connections belong to a cable / conduit.

Segment

Properties of the segment (structure segment, planning object, or PCT loop in pre-planning). Available if a graphically placed segment or a function or function template linked to a planning object has been selected. The index passes through the hierarchy levels in accordance with the tree structure in the pre-planning navigator. This is done starting from the current segment of the tree from the bottom upward.

Structure segment hierarchical

Properties of the superior structure segment. Available if a graphically placed segment or a function or function template linked to a planning object has been selected. The index passes through the hierarchy levels in accordance with the tree structure in the pre-planning navigator. This is done starting from the highest node in the tree to the last structure segment above the current segment.

PCT loop

Properties of the superior PCT loop. Available if a graphically placed segment or a function or function template linked to a planning object has been selected.

PCT loop function

Properties of the superior PCT loop function. Available if a graphically placed segment or a function or function template linked to a planning object has been selected.

Part reference

Properties of the part that can be changed at the device, and calculated properties. Available when a main function is marked and parts are assigned to it. The index passes through the parts in accordance with their sequence in the Parts tab of the property dialog.

Parts

Properties of the part. Available when a main function is marked and parts are assigned to it. The index passes through the parts in accordance with their sequence in the Parts tab of the property dialog.

Segment: Part reference

Properties of the part that is assigned to the planning object and that can be edited at the planning object. Available when a function of a pre-planning placement is marked to which a planning object is assigned and parts are entered at the planning object. The index passes through the parts in accordance with their sequence in the Parts tab of the property dialog.

Segment: Part

Properties of the part that is assigned to the planning object. Available when a function of a pre-planning placement is marked to which a planning object is assigned and parts are entered at the planning object. The index passes through the parts in accordance with their sequence in the Parts tab of the property dialog.

Placement

Properties of the graphical placement of the segment. Available if a graphically placed segment has been selected.

Connection definition point

Properties of the connection definition point. Available if a connection definition point has been selected.

Connection

Properties which are available for the connections that run under the connection definition point. Available if a connection definition point has been selected.

Piping definition

Properties of the piping definition point. Available if a piping definition point has been selected.

Pipe class

Properties of the pipe class. Available if a segment, function, piping or connection definition point for which a pipe class is selected has been marked.

Piping planning object

Properties of the piping planning object. Available if a connection definition point or a function is selected on a defined piping and the associated piping definition point is linked to a piping planning object. At functions that are the source / target of several defined pipings, the index passes through the linked piping planning objects in accordance with the graphical order of the defined pipings.

Page

Page properties. Available if page properties are inserted as special texts.

<Identifier block>

Properties of the identifier block. Available if page properties are inserted as special texts and the project is structured by identifier blocks.

Source object

Available properties

Part

Properties of the parts.

Manufacturer / supplier / customer

Properties of the manufacturers / suppliers or customers.

Drilling pattern

Properties of the drilling patterns.

Connection point patterns

Properties of the connection point patterns.

Accessory list

Properties of the accessory lists.

Accessory placements

Properties of the accessory placements.

Category:

The category allows you to limit the display of the properties possible for the marked source object to a subset.

This field is irrelevant for the property configuration of the property overview and for the property configuration in the parts management at the record types such as accessory list, drilling pattern, etc.

Example (categories for the display):

In the "Devices" category device properties are available, for example components of the DT; elements of the DT, structure identifiers.

The "Data" category makes properties available for which the entry of data values is possible, e.g., function texts, technical characteristics, user supplementary fields, block properties.

In the "Settings" category properties are available that are set using check boxes or drop-down lists, e.g., "Suppress in device tag list", "Cross-reference display: Display".

Find:

Into this field enter the text for which the properties are to be filtered. Both property names and set values are found when the properties are filtered. Logic operators (AND / OR operation) and placeholders (such as * or ?) are not supported for filtering.

If you want to return to the original view of the properties, remove the search term from the entry field. Click (Delete) to do so.

Tip:

Enter multiple letters one immediately after the other to search for a string and jump directly to the first entry that starts with the letters you entered. If you enter "sup", for example, the cursor will jump in the list of properties directly to the first entry that starts with "sup", for example "supplementary field".
If you pause too long between entering "s" and "u", the cursor will jump to the first entry that starts with "s", and then to the first entry that starts with "u".

Table:

All properties available for the relevant object are displayed sorted by name in the Property name column of the table. The associated property values (where available) are displayed in the Value column. Double-click a column header to sort the properties by the respective column.

New Features for Eplan API

Area Description
Methods (API)

Summarize function templates of an assembly or module

The class MDPart represents a part in the parts database. The class MDPart includes the new method SumUpFunctionTemplates in order to summarize the function templates of this part. This only functions if the part is an assembly or a module. By means of the new property SummedUp from the class MDFunctionTemplatePosition you can determine whether a function template has already been summarized.
Methods (API)

New method for calculating the total weight of enclosures

The class Placement3DService now includes the new method CalculateCabinetWeight to calculate the enclosure weight. In the user interface this corresponds to the command Calculate total enclosure weight.
Events (API)

New event "Eplan.EplApi.OnLoadWorkspace"

The new event Eplan.EplApi.OnLoadWorkspace is now available in the Eplan API. This event is triggered when a user changes the workspace. The event can be used in the Eplan API to supplement any missing entries in the ribbon in the newly loaded workspace.
Methods (API)

New method for project-specific path variables

To resolve project-specific path variables for a specific project, the class PathMap now contains a new overload of the method SubstitutePath.
Methods (API)

New method for routing connections

The new method RouteConnection from the class ConnectionService3D makes it possible to route a routing connection via a specific routing track. This new feature is available as of Version 2025 Update1.
Properties (API)

Renaming mounting points

The new property Name from the class Mate can now be used to rename user-defined mounting points as in the user interface.
Methods (API)

Consideration of the export scheme during the STEP export

The new methods Placements3DToStep and ProjectToStep from the class Edit3D can be used to export 3D objects into the STEP format under consideration of the export scheme.
Properties (API)

New property for the property arrangements of model views

You can now access the property arrangements of model views by means of the new property PropertyPlacementsSchemas from the class ViewPlacement.
Properties (API)

Determine displayed tooltips

The new property Tooltip from the class Placement now makes it possible to query the tooltip for a placement in the graphical editor as it is displayed in the user interface (for example the full DT for a function).
User-defined properties

Create user-defined properties with the field type "Value with unit"

The method Create from the classes UserDefinedPropertyDefinition and MDUserdefinedPropertyDefinition makes it possible to create user-defined properties with the field type "Value with unit" and to assign a unit group to these properties.

Unit Groups for Properties of the Field Type "Value with unit"

Properties (API)

Determining the availability of tabs in the ribbon

In the past it was already possible to switch the availability of a tab in the configuration of the ribbon with the property IsSetAsVisible from the class RibbonTab. Now you can also use the IsSetAsVisible property to specify the value for a tab in the ribbon (activated or deactivated).
Methods (API)

New method for determining user-defined mounting aids

The new GetCustomMateEntries method is now available in the DMObjectsFinder class. You can use this method to determine user-defined mounting aids in the tree of the layout space navigator via Eplan API.
Properties (API)

Determine all words not to be translated

The new property NotTranslatedWords from the class MDTranslationDatabase makes it possible to determine all the words "not to be translated" from the dictionary.
Methods (API)

New method for the export in IFC format

The new InstallationSpacesToIFC method is now available in the Export3D class. This method can be used to export 3D graphic data in the IFC format. This new feature is available as of Version 2025 Update1.
Methods (API)

New methods for exporting and importing in JT format

In the Export3D class the new method InstallationSpacesToJT is now available, and in the Import3D class the new method JT. These methods can be used to import and export 3D graphic data in the JT format.

The import3D action is now also available for importing 3D graphic data in the JT format (and also in the STEP format). For the export in the JT format the TYPE parameter of the export3D action has been extended with the JT value for the JT format, and the STEPINSTALLATIONSPACES value of the TYPE parameter has been renamed to STEP.

This new feature is available as of Version 2025 Update1.
Methods (API)

Outdated methods for the ribbon removed

You could have a menu bar with the "old" menus from Version 2.9 shown as a transition help for the ribbon. This possibility was removed from the user interface in Version 2024. Now the outdated methods, classes and actions for the menu bar have also been removed in the Eplan API.
Methods (API)

Specifying the format of the export file and further options for the export of PLC data

In the user interface the Export PLC data dialog provides the Format of export file field and the [Options] button. In order to carry out the corresponding settings via Eplan API, the class PLCService now contains a new revision of the method ExportData (with the parameters strFormat, bExportPortSpecificInterconnection, bExportAccessories, bExportDrives, bExportDeviceSpecificConfValues). Analog to this, the action plcservice has been extended with the new parameters FORMAT, EXPORTPORTSPECIFICINTERCONNECTION, EXPORTACCESSORIES, EXPORTDRIVES and EXPORTDEVICESPECIFICCONFIGURATIONVALUES.
Properties (API)

Consideration of additional saddle jumper slots

Additional saddle jumper slots are now considered in the BridgeSegments property from the Terminal.Bridge class. To this purpose the Terminal.Bridge.Kinds list returned by the Kind property from the BridgeInfo class has been extended by corresponding entries for the additional slots.
Methods (API)

Generating multi-level terminals as devices

The new CreateTerminalDevice method is now available in the DeviceService class. This method can be used to generate multi-level terminals in accordance with the Generate terminals (devices) dialog.
Methods (API)

Creating Links in Pre-Planning

The new CreateLink method is now available in the PlanningSegment class. You can use this method to create links in the pre-planning.
Class (API)

New classes for the check runs in the parts management

The check runs for the part master data are now executed in the parts management. Therefore check runs of the previous message class 501 "Part master data" have been renamed and moved into the new message class 502 "Part master data". As a result of this new feature the Eplan API has been extended with several new classes (for example, MDPartsDatabaseMessages, MDPartsMessage etc.). The VerifyMDPartsDatabaseItems method, with which the check runs for the part master data are started, now no longer requires a parameter for the specification of a project. In the Check class, the VerifyMDPartsDatabaseItems method has been revised for this reason.

Improved check runs for part master data

Methods (API)

Specify scheme for the design space import

In the user interface you can select a scheme with settings for the import in the Design space import dialog when importing a design space. This possibility has now also been taken into consideration in the Eplan API. To this purpose there is a new overload in the method DesignSpace in the Import3D class with the parameter strSchemeName. And the action import3d has been extended analog to this with the new parameter SCHEME.
Parts management

New import option "Replace existing records and add new ones"

For the import of parts data, the user interface includes the new option Replace existing records and add new ones. This option can now also be used in the Eplan API. To this purpose the enumeration ImportMode from the class MDPartsManagement has had the option ReplaceAndAppend added to it (Value 3).
Parts management

Using supplemental parts in the Eplan API

The new record type "Supplemental part" is now available in the parts management. To be able to use this record type in the Eplan API as well, the enumeration MDPartsDatabaseItem.Enums.Type has been extended with the option SupplementalPart (value 16).

Management of Supplemental Parts

Actions (API)

Outdated action "XPamArticlesSyncAction" removed

The possibility to write back the parts data of a new parts database (Version 202x) into an old, updated parts database (Version 2.9 SP1 or older) has been removed. Since these old Eplan versions are no longer supported, the XPamArticlesSyncAction action is no longer available.

Generating Connection Diagrams

In a wiring diagram, the devices are placed in the sequence in which they occur on the mounting panel; the precise coordinates and dimensions are unimportant here. Rather, wiring diagrams serve to provide information about the connected cable connections and targets. This is implemented as follows:

  • A line is generated for every target. If a connection point has multiple targets, the distance to the next connection point can be increased.
  • You can output a symbol for every function. The symbols do not have to fit the connection points.

Preconditions:

  • You have opened a project.
  • You have created a mounting panel and inserted part placements.
  • You have placed a black box and assigned the DT of the mounting panel to it. You have selected "Overview" as the Representation type. The black box may be placed either immediately beside the mounting panel or on an overview page, but never on a report page.
  1. Select the following commands: Tab Tools > Command group Reports > Generate.
  2. In the Reports - <Project name> dialog, click (New).
  3. Select the "Manual placement" output format from the Output format drop-down list of the Select report dialog.
  4. In the Select report type field, select the "Device connection diagram (for wiring diagram)", "Terminal connection diagram (for wiring diagram)" or "Pin connection diagram (for wiring diagram)" report.
  5. Select the Manual selection check box.
  6. Click [OK].
  7. In the Select mounting panel dialog, select the mounting panel for which the wiring diagram is to be generated.
  8. Set the Hide devices already reported check box to define whether devices for which this report has already been run should be hidden.
  9. Click [OK].
  10. In the Manual selection dialog, select the devices for which the report is to be generated. Multiple selection is possible.

    If you selected the "Terminal connection diagram" report type, only terminal strips are displayed. If you selected "Pin connection diagram", only plugs are displayed.
  11. Click [OK].

    The report is generated and hangs on the cursor.
  12. Place the report on the appropriate positions in the black box.

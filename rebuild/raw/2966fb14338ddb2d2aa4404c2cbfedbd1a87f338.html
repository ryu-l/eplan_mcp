Pre-planning: Reports

The following report types exist for the pre-planning:

  • Pre-planning: Structure segment overview: Overview of all structure segments and necessary expenditure (time, energy, and costs) from the subordinate planning objects.
  • Pre-planning: Structure segment plan: Per structure segment, a report is generated: different properties of the structure segment can be output (Technical description, Power consumption, etc.). In addition, the directly subordinate segments are output in the data area.
  • Pre-planning: Planning object overview: Overview of all planning objects and necessary expenditure (time, energy, and costs), as well as the documents, parts, and PLC addresses stored there. Function lists for the building automation as well as reports for piping planning objects including the associated properties (substance, pipe class, source and target segment, etc.) can be output by means of the planning object overview - if suitable forms are used.
  • Pre-planning: Planning object plan: Corresponds to a data sheet. For each planning object, a list of parts, PLC addresses, etc. entered at the planning object is output. In addition, the directly subordinate segments are output in the data area. Reports for piping planning objects including the associated properties (substance, pipe class, source and target segment, etc.) can also be output by means of this report - if a suitable form is used.
  • Pre-planning: Segment template overview: Overview of all the segment templates.
  • Pre-planning: Segment template plan: One report is created per segment template. Various properties of the segment template can be output in the process, for example those parts that are entered at the segment template. In addition, the properties of the segments can be output that use the segment template.
  • Pre-planning: Pipe class overview: Overview of all the pipe classes of a project that are managed in the segment template navigator. Reports per pipe class can also be generated by means of the pipe class overview - when a suitable form is used. In this context a list of properties that are entered at the pipe class is output for each pipe class.
  • Pre-planning: Substance overview: Overview of all the substances of a project that are managed in the segment template navigator. Reports per substance can also be generated by means of the substance overview - when a suitable form is used. In this context a list of properties that are entered at the substance is output for each substance.
  • Assembly/Module overview: Overview of all assemblies and modules used in the project. You can use the Record type property to differentiate between assemblies and modules. By means of this report you can output hook-ups for planning objects.

Parts, which have only been entered at planning objects in pre-planning, can also be evaluated in part assemblies (parts list, summarized parts list, etc.) as well as the bill of materials. To this purpose the Pre-planning part check box has to be activated in the dialog Settings: Parts.

In the other reports (device tag list, terminal diagram, PLC diagram, etc.), planning objects which are linked to main functions can be included. For this output, placeholder elements for planning objects are available in the respective forms.

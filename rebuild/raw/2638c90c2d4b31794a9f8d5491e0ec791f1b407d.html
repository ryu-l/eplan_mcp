Dialog Settings: Image file export

Dialog call:
  • File > Export > Command group Project data > Project data > Command group Page > Image file. Next to the Scheme field, click [...].
  • File > Settings > Company > Interfaces > Image file export

In this dialog you define the settings for exporting image files and save this as a scheme. The schemes for image file export are saved on a per-company basis. You can copy and edit an existing scheme or create a new scheme.

Overview of the main dialog elements:

Scheme:

Select a scheme to define the settings from the drop-down list.

You can create new schemes, save any changes to a scheme, and copy or delete schemes via the adjacent Toolbar. Schemes can also be imported or exported.

Description:

This field displays the descriptive text that you entered into the Description field in the New scheme dialog when you created the scheme.

Target directory:

Enter the directory where the image files are to be saved. Every page is saved as a separate image file. Use to open the dialog for choosing a directory.

You can use the Insert path variable popup menu item to branch to the dialog Select path variable where you can select one of the available path variables.

File type:

Use this drop-down list to select the desired image format. BMP, GIF, JPG, PNG, and TIFF are possible formats.

Compression:

Depending on the chosen file type, this drop-down list offers various levels of compression. Select the desired level of compression.

You will find detailed information on the level of compression for the TIFF file type online at "http://partners.adobe.com/public/developer/en/tiff/TIFF6.pdf".

Color depth:

Depending on the chosen file type, this drop-down list offers a range of different color depths. The color depth allows you to define how many colors can be represented in the exported image file. The color depth is defined as the "number of bits used per pixel" (e.g.: 1 bit per pixel means 2 colors, 4 bits per pixel 16 colors, 8 bits per pixel 256 colors, etc.).

Width:

This field allows you to define the desired width of the image file in pixels. The appropriate height is calculated by Eplan based on the aspect ratio of the page. This setting has the effect of making all exported pages the same width, regardless of their format (e.g. DIN A4 or DIN A0).

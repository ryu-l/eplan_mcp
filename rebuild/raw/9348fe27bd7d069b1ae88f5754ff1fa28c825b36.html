Using the Help System

Dialog call:

File > Help > Command group Support > Contents > Help system

If you have opened a dialog, you can also activate the context help ([F1]).

You can directly select a help topic from the contents menu. However, a comfortable full-text search which automatically supplements the search terms during the input and thus displays new proposals is also available in the help system. You can also use a search filter to limit the search specifically to specific categories. The syntax which is used for searching orients itself towards the syntax of well-known Internet search machines.

Glossary entries are available for the definitions of terms. Glossary entries are shown underlined in the text and highlighted in color as soon as you move the cursor over them. If you click such an entry, the glossary entry is displayed in a separate window.

Note:

Text search allows for the search for synonyms: A suitable search result is shown in many cases even when you enter similar or incorrect search terms or ones no longer used.

Using a search filter

The text search in the help can be restricted by means of a search filter to specific categories. Possible categories are Eplan product variants (such as "Eplan Electric P8") and the page types of the help system (for example "operating information", "check run messages"). The search filter can be set before the search is started or be activated in the search result.

  1. Click the [Search in] button on the right next to the input field of the text search.
  2. Select a category from the drop-down list.
  3. Enter a search term and start the search with the button.

    Only the find locations from the selected category are displayed in the search result.
  4. Select a different category from the drop-down list.

    Only the find locations from the new category are displayed in the search result.

AutoComplete for search terms

Search terms are completed automatically while being entered in the input field of the text search. The suggested terms are contained in the help system index.

Automatic search suggestions can also be combined with search filters.

Switching the help language

It is possible to switch between all available languages within the help system.

  1. Click the button in which the current help language is displayed in the toolbar of the help.
  2. Select the language to which you want to switch from this drop-down list.

    The help system shows the current page in the selected language.

Copying the URL of a help page into the Clipboard

You can use the button (Copy URL to Clipboard) in the toolbar of the help system to copy the URL of the currently opened help page into the Clipboard and to then insert the address as required in other applications. This helps, for example, if you have questions for the Support.

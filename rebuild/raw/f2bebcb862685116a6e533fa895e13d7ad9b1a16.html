Dialog Full DT

Dialog call:

You have opened a project.

  • You have inserted a symbol in the graphical editor or generated a new function in a navigator.
  • You have selected a general device in the graphical editor or in a navigator. Popup menu item Properties.

In the Properties <...> dialog, select the <Function category> tab. Click [...] in the Full DT field.

In this dialog, you can assign a different structure identifier to the identifier blocks contained in the device tag, and edit the default settings for the display.

Overview of the main dialog elements:

Displayed DT:

This field shows the DT as it is displayed in the schematic according to the entries in the fields of this dialog. As soon as you edit this entry, the entries in the other fields will automatically be updated.

Full DT:

This field shows the full DT as it is defined according to the entries in the fields of this dialog. This field cannot be edited.

Example:

The lamp H1 is assigned to the function designation A1 and the location designation O1. The displayed DT is -H1 and the full DT is =A1+O1-H1. If you now change the entry in the Displayed DT field to +PT1-H1, the entries in the Location designation and Full DT fields are automatically modified.

Structure identifiers:

Depending on the project structure the table displays the structure identifiers of the placed component which can be edited. Eplan generally adopts the Device structure that you have defined in the project properties of the project. If the device structure conforms to the page structure, the fields display the structure identifiers of the page on which the placed component is located.

  • Structure: Lists the identifier blocks which correspond to the device structure. The adjacent column displays the associated preceding signs.
  • Value / Visible: Without extended reference identification, the Value column is displayed. If you are using extended reference identification, the Visible column is displayed. In this column, the structure identifiers can be edited. Enter a structure identifier in the proper field for this purpose, or click [...] to select a structure identifier already defined in the project using the <Identifier block> (<Project name>) dialog.
  • Complete: This column is displayed if you are using extended reference identification. It displays the structure identifier including all superior structure identifiers.

Note:

The preceding signs and separators between the individual structure identifiers can not be edited here. They originate from the settings of the Extended project structures dialog, which you open in the Structure tab of the project properties by clicking [Other].

Editing fields for the DT

Depending on the settings for the project structure, different editing fields are displayed for the DT:

  • Group boxes for the DT: If you are working without extended reference identification, the DT and Subordinate DT group boxes are shown. In these fields, you edit the identifier block for the device.
  • Table DT: If you are using the extended reference identification, the editing fields for the DT are shown in a table. In this case, each product aspect (the DT and each subordinate DT) is displayed in its own row.
  • Table DT for fluid power functions: If the Fluid power: Use trade identifier as identifier (media code) check box is activated in the project settings, the edit fields for the DT in a table are shown for fluid power functions and the designations according to the standard ISO 1219-2 are used as column headers. For this, the prefix in the DT of fluid power functions must be empty.

Note:

To be able to use the extended reference identification, the Extended reference identification check box must be activated in the Structure tab of the project properties.

If you have additionally determined that the product aspect is to be used for structuring (by means of the corresponding check box in the Display tab of the Extended project structures dialog), the table for the DT is hidden and the product aspect shown in the Structure identifiers table.

The group boxes or the table allow for entries in the following fields:

Prefix:

These fields can be used to enter or change a prefix digit for the device and subordinate devices.

For fluid devices with an identifier structure according to ISO 1219-2 this field must remain empty.

Identifier:

These fields can be used to enter or change the identifier for the item designation (according to DIN) of the device and subordinate devices.

For fluid devices with an identifier structure according to ISO 1219-2 this field is designated the Media code. The trade identifier is used as media code and can be entered or changed here.

Counter:

These fields can be used to enter or change the counter for the device and subordinate devices.

For fluid devices with an identifier structure according to ISO 1219-2, this field is designated the Circuit number. Here you can enter or change the circuit number.

Subcounter:

In these fields, the subcounter can be entered or changed for the device and subordinate devices. The separator which separates the subcounter from the rest of the DT cannot be edited here.

For fluid devices with an identifier structure according to ISO 1219-2, this field is designated the Item number. Here you can enter or change the item number.

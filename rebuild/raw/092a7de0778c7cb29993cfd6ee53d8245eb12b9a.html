Exporting and Importing 3D Graphic Data

Eplan Pro Panel allows the export and import of 3D graphic data in different file formats.

Export of 3D graphic data

The export of 3D graphic data is possible in the file formats listed below. For all exports you can carry out user-specific Settings under File > Settings > User > Interfaces > STEP export / VRML export / IFC export / JT export.

STEP

The STEP export writes the faceted geometry of a layout space's 3D objects into a file in the STEP (STandard for the Exchange of Product model data) format. Information on analytic surfaces or volumes is not transferred. The exported data can be imported into external CAD systems and be visualized there. The models are used as 3D macros or items for placement in Pro Panel projects on the basis of the STEP import of edited 3D objects.

VRML

The VRML export writes the geometry of a layout space's 3D objects into a file in the VRML (Virtual Reality Modeling Language) format. The exported data is displayed as 3D models in browsers, and there can be rotated all around and zoomed.
With each VRML export, in parallel to the generated VRML file, a file is generated with the file name extension *.wri. In there, all items that have a part number or DT are attached with a number in the form "ID000001". The number is incremented from 1 to n.

IFC

The IFC export writes geometric data of three-dimensionally constructed enclosures of a layout space into a file of the open data standard IFC (Industry Foundation Classes) . IFC is a worldwide standard for data exchange in civil engineering for planning with digital 3D building data models. This digital planning method is also called BIM (Building Information Modeling).

Among other things, the data of the following properties of enclosures are exported:

  • Height, width and depth of the cuboid that encases the enclosed enclosure including base and other elements projecting outwards.
  • Largest extension with opened enclosure door (only graphical)
  • Weight (full) (ID 22233)

Notes:

  • All versions of the IFC specification supported by Eplan Pro Panel are listed in the IFC version drop-down list of the Settings: IFC export dialog.
  • One export file with the file extension *.ifc is generated in the output directory per layout space.
  • Entire layout spaces are always exported, with multiple selection of layout spaces being permitted. The export of an individual enclosure in a layout space or the export of individual items in an enclosure is not possible.
  • Only part placements with the "Enclosure" function definition are exported.

JT

The JT export writes geometric data of 3D objects of a layout space into a file in the JT (Jupiter Tesselation) format. Through the JT export it is possible to make a 3D model of an enclosure available for further usage in another CAD program. JT files can contain faceted data, product and manufacturer information as well as metadata.

Note:

Note that the 3D graphic data for the JT export must contain "BREP" information (BREP = Boundary Representation). If this information is missing, a corresponding message is output during the export and the item for which the BREP information is missing is excluded from the export. In this case we recommend that you either update your 3D macros via Eplan Data Portal or generate the 3D macros again. You then have to insert all the parts used in Eplan Pro Panel again.

Import of 3D graphic data

To create own items and 3D macros, 3D graphic data can be imported from external CAD systems. The graphical data must be available in the internationally common STEP format or in the JT format. Project-specific settings for both formats are available for the import of data.

Note:

Note that during the import of 3D graphic data in the JT format "BREP" information (BREP = Boundary Representation) must be contained in the data in order to ensure correct representation of the 3D graphics in Eplan Pro Panel. If this information is missing, a corresponding message is output during the import, and the import is not possible.

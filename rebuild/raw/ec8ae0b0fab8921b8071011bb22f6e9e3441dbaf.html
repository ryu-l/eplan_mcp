Master Data: Symbols

This section provides information about the new and corrected symbols that are available to you in the master data as of the current version.

Notes:

  • The following pages show a number of illustrations of new symbols from different symbol libraries. The illustrations show the variant "A" of the respective symbols in multi-line or single-line representation (at a deactivated project setting Display rotated connection point designation). The name and number of the symbol are shown underneath the symbol.
  • Several symbols dispose of the same symbol graphic. These symbols do, however, differ with regard to usage in the trades, the function definitions, the symbol properties and their positions. New symbols that have the same symbol graphic are displayed together.

The following extensions and corrections have been carried out in the symbol libraries:

  • The following new symbol has been added to the "IEC_single_symbol", "GOST_single_symbol" and "GB_single_symbol" symbol libraries:

QLTR2_1 // 1590

  • In the symbol libraries "IEC_single_symbol", "GOST_single_symbol" and "GB_single_symbol" the symbol representation type was corrected from multi-line to single-line for the symbols SSTO // 1264 and SOTS // 1273.
  • In the "IEC_single_symbol", "GOST_single_symbol" and "GB_single_symbol" symbol libraries, numerous symbols for terminals / plugs with more than two connection points have been blocked (for example XTR3_1 // 1230, X3_1 // 1353, etc.).

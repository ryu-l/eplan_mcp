Overview of Shortcut Keys

Key combinations can be used to call up commands particularly quickly in Eplan. In the Customize shortcut keys dialog, you can customize the shortcut keys and create your own, as well as reset the key combinations back to the default settings if required.

Note:

Please note that there are key combinations which are internally used by Eplan or Windows. If you try to assign such an internal key combination to a menu command, a corresponding message is displayed.

In Eplan, for example, the Input box functionality uses the keys [+], [-] as well as numeric values. For this reason these keys cannot be used as exclusive key combinations any more.
Windows, for example, uses the key combination [Ctrl] + [F6] to switch to the next document window or the key combination [Shift] + arrow key [Right] to mark a character to the right of the cursor.
In addition, combinations of the keys [F1], [F4], [F6] with [Ctrl], [Shift], [Alt] cannot be assigned.

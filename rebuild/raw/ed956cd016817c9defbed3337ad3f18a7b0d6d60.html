    API Framework
    In This Topic

    The API Framework provides all necessary functionality to integrate API add-ins into Eplan, to process scripts, and to use base technology of the Eplan system, like e.g. creating Actions, writing system messages and managing Eplan settings. The framework encloses the namespaces  Eplan.EplApi.ApplicationFramework,  Eplan.EplApi.Base,  Eplan.EplApi.EServices,  Eplan.EplApi.Gui, Eplan.EplApi.Scripting,  and  Eplan.EplApi.System. 

     

    No electrotechnical functions are made available by the framework.

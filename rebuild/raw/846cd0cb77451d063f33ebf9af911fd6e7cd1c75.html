Dialog Bundle routing connections

Dialog call:

You have created routing connections. Routing connections are highlighted in the connections navigator. Tab Edit > Command group Routing connections > Bundle.

In this dialog you select a scheme with settings for the automatic bundling of routing connections. Each bundling scheme can contain further schemes for filtering, sorting, and bundling criteria. You can create new schemes and edit existing ones. In addition you determine general settings for bundling in this dialog which are not part of a scheme.

Through the automatic bundling, bundle numbers are written into the properties Bundle and Bundle group of the routing connections.

Overview of the main dialog elements:

Settings:

  • Bundling scheme: Select the scheme to be edited in the left-hand column of the table.

    The [...] button is used to open the dialog Settings: Bundle in which you can set the filters and criteria for bundling with this scheme.

    You can create or delete entries in the list by using the toolbar above the fields. In addition, the order of the schemes can be changed. According to the sequence determined here, bundles are created successively with a consecutive bundle number per scheme.
  • Description: In this field you enter a short descriptive text for the scheme.

The bundling schemes in the table are successively processed in the sequence from top to bottom. The wires recognized by the scheme are bundled correspondingly. Bundle numbers that were assigned by a higher-hierarchy scheme are not overridden if the same wire is to be bundled again by a subsequent scheme.

Example:

Bundle scheme arrangement:

  • Topmost scheme:
    Filter criterion: Connection color / number = RD (red)
  • Second scheme:
    Filter criterion: Connection color / number = BK (black)
  • Third scheme:
    Filter criterion = No filter.

In this arrangement with three bundling schemes the criteria for sorting (connection cross-section / diameter) and for a new bundle (connection cross-section / diameter) are the same for all schemes.

Result:

  • First, all red wires are individually bundled by cross-section (Bundle number e.g. 1).
  • Then, all black wires are also individually bundled by cross-section (Bundle number e.g. 2,3).
  • Finally, all other colors except red and black are bundled by cross-section (Bundle number e.g. 4,5,6).

Start value:

Beginning with the start value, the generation of bundle numbers is incremented with the specified increment. The default value is "1". Only bundle numbers are assigned that do not yet exist in the project. Gaps are filled.

Increment:

Determines the distance by which the respective next bundle number is incremented. The default value is "1".

Number of wires per bundle maximum:

The maximum number of wires per bundle is the number of wires that the wire fabrication machine can combine into one bundle. If the determined number is exceeded, a new bundle is automatically created. If the setting remains empty, a bundle can contain an unlimited number of wires.

Total conductor cross-section maximum:

The maximum total of conductor cross-sections is the machine-specific limit value for the sum of the cross-sections of all wires. If the determined sum is exceeded, a new bundle is automatically created. If the setting remains empty, the sum of the conductor cross-sections remains unlimited.

Bundle daisy chains with priority:

If this check box is activated, routing connections in a net which contains more than one connection are combined in one bundle prior to all other routing connections. In this case the field lying below, Beginning at number of wires is enabled and you can specify the number of wires as of which the chains are to be bundled.

Beginning at number of wires:

As soon as the Bundle daisy chains with priority check box is activated, you can specify in this field the number of wires as of which the chains are to be bundled. If the value 0 (default) is used, there is no limitation. If a conductor chain does not have the required number of wires, the connections are bundled in accordance with the set bundling criteria.

If the Bundle daisy chains with priority setting is not activated, the number of wires is ignored by the program.

Apply to entire project:

Using this check box, the selection for bundling is extended to the entire project depending on the selection of the connections to be bundled.

  • If no connection is selected, the checkbox is activated and cannot be deactivated.
  • If one or more connections are selected, the checkbox is not activated and can be activated.

Preview of result:

If this check box is activated, the Bundle connections: Preview of result dialog is displayed before the new bundle numbers are accepted. This dialog lists the connections to be modified. You can confirm the new bundle numbers with [OK] or modify them manually.

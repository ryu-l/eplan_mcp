Specifying Online Numbering Format

You use the online numbering format to specify the automatic numbering behavior for new devices / functions. This applies, for example, to devices / functions that you place in the schematic using Insert > Symbol or create in the device navigator.

You also use an online numbering format to specify the automatic numbering behavior for devices / functions that you insert into the schematic via macros and / or by copying from the clipboard.

A DT is determined and automatically assigned online for every device that you insert, according to the online numbering format. You can specify the same or different online numbering formats for the two procedures.

Precondition:

You have opened a project.

  1. Select the following commands: File > Settings > Projects > "Project name" > Devices > Numbering (online).
  2. In the On symbol insertion or On insertion of macros and copies group box, click [...] next to the Numbering format field.
  3. To create a numbering format, in the Numbering formats dialog click next to the Scheme field on (New).
  4. Enter a recognizable name in the Name field and, if you wish, enter a short descriptive text in the Description field, then click [OK].
  5. Select the DT tab.

    This tab displays all the device groups for which online numbering can be activated and for which you can specify the DT formats independently of one another. These include: "General devices", "Terminal strips", "Plugs", "Black boxes", "PLC", "Cables", "Fluid devices", "Fluid connection splicers / line connectors".
  6. For example, to select all the devices in the "General devices" device group for online numbering, activate the General devices check box.
  7. To specify the DT format for all devices in the "General devices" device group, click [...] next to the General devices field.

    The DT format dialog opens. By default, the DT format already contains the format elements "Identifier" and "Counter". These format elements are displayed in the Selected format elements field.
  8. To select additional format elements for the DT format, select a format element in the Available format elements field and then click (Move to the right).
  9. In the Format dialog, under Minimum number of digits, enter the number of digits that will be used to display the value in the DT, and if you wish, in the Filler character field enter a character that will be used to replace missing digits in the DT, then click [OK].

    The format element is entered into the Selected format elements field.
  10. To edit previously selected format elements, select an entry in the Available format elements field and click (Edit), enter the settings you require in the Format dialog, then click [OK].
  11. To specify the order of the format elements in the DT, select a format element and click the (Move up) or (Move down) button.

    The result is shown in the Preview field.
  12. Select and edit all the format elements you wish to edit in turn. Pay attention to the rules for the Online numbering format.
  13. Click [OK].
  14. To specify the DT format for connection point designations, select the Designations tab.

    This tab displays all the device groups for connection points for which online numbering can be activated and / or for which you can specify the DT formats for the connection point designations independently of one another. These include: "Terminals", "Pins", "Device connection points", "PLC connection points".
  15. For example, to select all the terminals for online numbering, activate the Terminals check box.
  16. For example, to specify the DT format for the connection point designation of terminals, click [...] next to the Terminals field, specify the format elements in the DT format dialog, and click [OK].
  17. Click (Save) and then click [OK].

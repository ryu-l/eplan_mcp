Working with Workspaces

An Eplan workspace encompasses the sizes and the positions of the Eplan main window, the editors (graphical editor, symbol editor, form editor, etc.), the Insert center and the "dockable" dialogs (navigators, message management, etc.). For the dockable dialogs and the Insert center the settings for the window position (for example dock, flyout, etc.) belong to a workspace. The customizations of the ribbon with, for example, user-defined tabs and command groups are also saved to a workspace.

This is handy, for example, for adjusting Eplan to different project planning tasks. You can switch over to PLC processing with a click, for example, and automatically open all of the required dialogs, whereby positions and settings are already specified. All unnecessary dialogs are automatically closed.

Work areas can be saved as schemes at any time and then selected or deleted at a later date. With Eplan you can use several a predefined work areas in the Workspace dialog, which you can use as a template for future work areas, for example. Just as you usually can with the schemata, you can also create, copy, delete, import and export schematas for the work area by using a toolbar.

Note:

The workspaces from previous Eplan versions (Version 2.9 or earlier) cannot be used.

Define workspaces

Precondition:

You have adjusted the user interface of Eplan for a certain project planning task.

  1. Click in the top right in the ribbon on the button (Workspace) and in the opened list select the command Edit workspace.
  2. In the Workspace dialog, click (New) on the toolbar beside the Scheme drop-down list.
  3. In the New scheme dialog, enter the name for the new scheme in the Name field.
  4. Enter a short descriptive text for the new scheme in the Description field.
  5. Click [OK].

    The New scheme dialog is closed, iand the new scheme is set as the current one.
  6. Click [OK].

    The new workspace is created under the specified name. The current interface settings for open "dockable" dialogs, dialog positions, etc, are saved.

If you want to, you can change the interface configuration of this workspace (for example change the size and position of "dockable" dialogs, etc.) and save it again (see "Edit workspaces").

Selecting Workspaces
  1. Click in the top right in the ribbon on the button (Workspace) and select the name of the desired workspace in the opened list.

    The currently selected workspace is identified in the drop-down list by a preceding check mark.

    The settings made in the selected workspace for open "dockable" dialogs, dialog positions, etc. are applied and the program's user interface is updated accordingly.

Edit workspaces

To save the changed user interface configuration of a currently selected workspace, click the button in the dialog Workspace.

When you edit a workspace you can also overwrite a selected workspace with the contents of another workspace. This could be useful if, for example, you want to use an existing scheme as a template for a new workspace.

  1. Click in the top right in the ribbon on the button (Workspace) and in the opened list select the command Edit workspace.
  2. Click (Edit) in the Workspace dialog.
  3. In the Edit workspace dialog select the workspace which is to serve as the template for the current workspace.
  4. Click [OK].
  5. In the Workspace dialog modify the description for the current workspace, if necessary.
  6. Click [OK].

    The changed settings will be saved in the current workspace.

Dialog Bill of materials - <Project name>

Dialog call:

You have opened a project.

  • Tab Devices > Command group Devices > Bill of materials
  • You have opened an editor such as the graphical editor, the plot frame editor, etc. Tab View > Command group Navigators > Drop-down button Open > Bill of materials.

This dialog allows the display and editing of all parts data in the open project.

Overview of the main dialog elements:

List:

The bill of materials list view is device-oriented. Please note that you can select via the Configure representation popup menu item at any time in order to specify which information should be displayed in the list (for example, part number, DT, number of units, etc.).

Tree:

In contrast to the list view, the tree view is parts-oriented, i.e. only those device tags that already have a part are shown. You can select the various views for display via the View popup menu item.

If the Graphical preview dialog is open, and a product photo has been assigned to the part, it is displayed.

Filter:

This drop-down list displays all the available filters. A selected filter is automatically activated and is applied to both the tree and the list view. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the Filter dialog. Here you can create, edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

  • Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
  • Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

Value: <Property>:

Use this field, via Quick input, to adjust quickly the value of a filter criterion for a defined and activated filter.

Popup menu:

The popup menu provides - depending on the field type (e.g. date, integer, multilingual) - the following menu items that are, depending on the situation, available for influencing the table or editing the values in the fields. You can find an overview of these popup menu items in the section Popup menu items.

In addition, the following dialog-specific popup menu items are available:

Menu item

Meaning

Add project part

Adds parts to the current project which are not assigned to any special DT, such as parts included in the delivery. To this purpose Eplan opens the Part selection dialog in which you can select the desired parts. New project parts are always sorted alphabetically into the tree. Multiple selection is possible.

Add part

Assigns one (or more) additional part(s) to the current device. The new parts are added to the device data with the already existing parts. To this purpose Eplan opens the Part selection dialog where you select the parts.

Delete

Deletes the selected parts after a confirmation warning. Parts for which a part placement exists cannot be deleted.

Insert device

Inserts the marked device. Before the actual placing press the [Backspace] in order to open the dialog Insert device and, if required, for example open the macro selection or change the representation type.

Exchange part

Allows exchanging the assigned parts against a new part for selected devices. Multiple selection is not possible in the Part selection dialog opened to this purpose. During the part exchange the number of parts remains, in contrast to the part selection. Assemblies are not broken up in the process.

Edit part

Opens the Edit part dialog, in which you can edit the selected parts, i.e., assign the part number, quantity, and properties, or overwrite any already existing data.

Device selection

Opens the Device selection dialog for the marked parts. Here, all parts of the device are always taken into account, even if they aren't marked.
Multiple selection of parts is possible, but this menu item is not available for part definition points and project parts.

Update device data

Transfers the device data of the selected parts to the functions in the project that use these parts. In addition to template data, part properties are also transferred during a device selection. This is of interest for you in case you have selected a part during a part or device selection that has an older status in the project than in the parts database. For further information on this topic please refer to the section "Updating part and device data".

Add item numbers

Opens the Number items dialog, in which you can assign the values for a new numbering of the currently selected items, or for all of the items of the project.

Synchronize parts data

Performs a synchronization of the master data part with project parts. In the process parts that are used in the project and that do not exist in the parts database are generated in the parts database.

Edit revision marker

This menu item allows you to edit the revision marker texts and their format. This menu item is only available when a changed object in a revision is selected.

Delete revision marker

This menu item allows you to delete the revision marker texts. This menu item is only available when a changed object in a revision is selected.

Export

Export and import can only be carried out within the same project. Opens the Export bill of materials dialog, which enables you to define the file name and format for the export.

Import

Export and import can only be carried out within the same project. Opens the Import bill of materials dialog, where you can define the file to be imported.

Go to (graphic)

Opens the graphical preview of the page and shows the current DT highlighted; double-clicking in this preview opens the Part placement dialog or the item-specific properties dialog.

Insert into list of search results

Enters all objects in a project that refer to the selected element in the search results list.

Settings

Opens the Settings: Parts dialog, where you can perform some configurations regarding the handling of certain part types. These settings furthermore affect the data displayed in the bill of materials navigator, and to a certain extent the "Device tag list", "Parts list", "Summarized parts list", and "Manufacturer / supplier list" reports.

List with preselection (tree only)

Reduces the number of elements displayed in order to allow for a faster orientation in the list view. If this option is activated, the list view is called up with an automatic filter (preselection) containing the elements that are currently selected.

View (tree only)

Switches the display to the tree view and thus specifies the order in the hierarchical levels:

  • Part number: The display includes the part number, identifier, and full DT.
  • Part number / structure identifier: The display includes the part number, structure identifier, and DT short designation.
  • Manufacturer: The display includes the manufacturer, part number, identifier, and full DT.
  • Supplier: The display includes the supplier, part number, identifier, and full DT.
  • Bill of materials grouping: The display includes the part number, structure identifier, and DT short designation.

Select in tree (list only)

Displays the marked object in the Tree tab.

Properties

Opens either the item-specific properties dialog of the device data, where you can edit the properties of the elements selected, or - for placed items to which parts have been assigned - the Part placement dialog.

Properties (global)

Opens the Properties (global): <...> dialog. Allows the editing of the device properties.

Dialog Part master data

Dialog call:

You have opened an editor such as the graphical editor, the plot frame editor, etc. Part master data command. (To this purpose you first have to Customize the ribbon and then assign the desired command to a user-defined command group.)

This dialog provides you with an overview of the existing parts master data. Parts / devices can be placed in a schematic page from here using drag & drop, and then subsequently edited.

Overview of the main dialog elements:

Toolbar:

You can specify the display of the data by means of the following buttons:

Button

Meaning

(Tree view)

Shows the data in a hierarchical tree structure. Individual part numbers or, if available, the designation of the part variants is displayed as the last hierarchy level.

(List view)

Shows the parts arranged one below the other in a list.

(Combination)

Shows the parts in a combined view of tree and list. The parts of the node selected in the tree are displayed in the list.

Toggles between the last selected filter scheme and the unfiltered view.

You can influence the nodes / hierarchy levels which are shown for a specific record type in the tree view in the tree configuration under [Extras] > Settings.

Filter:

This drop-down list displays all the available filters. A selected filter is automatically activated and is applied to both the tree and the list view. The "- Not activated -" entry deactivates the filter and causes an unfiltered display of the data. Click [...] to open the Filter dialog. Here you can create, edit, delete, copy, export, import, and manage filters.

The popup menu of the Filter drop-down list contains the following entries:

  • Deactivate: This popup menu item is available if a filter has been set: Resets the filter setting to the "- Not activated -" entry.
  • Activate <filter name>: This popup menu item is available if the filter setting is "- Not activated -": Reactivates the last active filter.

This allows you to toggle rapidly between the unfiltered representation and a representation filtered in accordance with your requirements.

By means of the filter criteria Function template in the part it is now possible to filter the parts according to function definitions and other data of the function templates (e.g. technical characteristics). As the result of such a filter only those parts are then displayed at which the property values or the function definitions of the function templates stored there match the set criteria.

Find:

Enter the text that is to be found into this field and confirm with [Enter].

By default only the most important properties (such as Part number, Type number, Manufacturer, etc.) are taken into consideration during the search. If the search is to be carried out via other properties, use the [...] button to branch to the dialog Configure search. There you can use a scheme to specify the properties and the order in which the search is to be carried out.

Otherwise the search behaves exactly like the Search in the Insert center. You can use the same operators and placeholder characters.

Popup menu:

Menu item

Meaning

List with preselection (tree only)

Reduces the number of elements displayed in order to allow for a faster orientation in the list view. If this option is activated, the list view is called up with an automatic filter (preselection) containing the elements that are currently selected.

Configure representation

Opens the Configure representation dialog, where you define which properties are to be displayed in the list and tree view.

Open hyperlink

Allows opening of external documents or an image file, as long as this is assigned to the part in the parts management.

Insert device

Inserts the marked device. Before the actual placing press the [Backspace] in order to open the dialog Insert device and, if required, for example open the macro selection or change the representation type.

Assign

This menu option is used to assign a part previously selected in the navigator to a certain function on the schematic. When you select this option, the part hangs on the cursor. Position the cursor on the required component in the graphical editor, and left-click to assign the part. The part can be assigned several times; it remains on the cursor until you cancel the action.

Tip:

You can add parts to a device placed in the graphical editor using drag & drop. To do this select the desired part in the parts master data navigator, drag the part onto the component and press the [Ctrl] + [Shift] shortcut key while dragging. After pressing the shortcut key, first release the mouse button and then the keys. If the device already has one or more parts, then a query is displayed asking whether the existing parts should be enhanced or replaced.

Further Optimizations for the Eplan Platform and Its Products

Product Area Functionality
Eplan Platform User interface

Reduced number of displayed objects in the property overview

Previously the data of all objects that were selected in the graphical editor, in a navigator, etc. and that corresponded to the scheme used for the property overview were displayed in the property overview. If no scheme was used in the property overview, the display was limited to 1000 objects. In both cases it could take a certain amount of time until all the objects were displayed in the property overview.

Now the display in the property overview is limited to the data of 100 objects. This way the data of selected objects is displayed faster in the property overview. If there are more than 100 objects in the selection, the "Not all selected objects are displayed" text is displayed in the information area of the dialog. If more than these objects are to be displayed in the property overview, you can click the [Load all objects] button below them. Depending on the number of objects this process can take some time.
Eplan Platform User interface

New notification for updates

If an update is available for your installed Eplan version, this is displayed by means of a download icon in the status bar. Often users are not aware of these system messages, in particular when the icon was already visible. For this reason - when a new update is available - a notification is now shown in the lower right-hand corner of the screen for a few seconds. In addition to the information that a new update is available, a hyperlink is displayed here with which you can call up the Eplan Download Manager.
Eplan Platform User interface

Input aid for Japanese keyboard with [F10]

The [F10] key is used by the operating system in a Japanese keyboard under Windows to convert characters by means of an input aid. In Eplan, however, the [F10] key has been used since Version 2022 to jump in a tab with the cursor into the first field of the tab. This means that the input aid did not function at Japanese keyboards. This has been corrected. In order to allow this standard Windows functionality for Japanese users, the assignment of [F10] by Eplan has been removed.
Eplan Platform User interface

Hotkeys removed in dialogs and in the popup menu

When you pressed the [Alt] key, underlined letters, so-called "Hotkeys", were previously displayed in dialogs and popup menus. As part of a cross-product standardization these elements have now been removed in the dialogs and popup menus. The hotkeys continue to be displayed in the ribbon.
Eplan Platform User interface

Customizing the ribbon extended with eStock commands

The following commands for Eplan eStock are now available to you when customizing the ribbon in the Customize dialog under Further commands (master data):

  • Upload all parts in eStock
  • Check for changes in eStock
  • Delete local eStock data
  • Update with data from eStock
Eplan Platform User interface

Improved support of the Windows setting for high contrast

The "High contrast" setting is available in the Windows operating system. This setting was previously supported by the Eplan platform beforehand, but was not taken into consideration correctly at some points during the color display in the user interface (for example coloring of icons in comparison to the background, the color of selected elements, etc.). This has been corrected. Eplan now offers an improved support for this setting.
Eplan Platform User interface

Copying the project name and storage location from the project properties

The project name of the current project and the associated storage location below it are displayed in the project properties (command path: File > Information > Command group Project properties > Properties). Here you now have the possibility to copy the project name or the file path of the storage location into the clipboard. The new (Copy) button is now available to this purpose next to the project name and next to the storage location. With the new (Open) button next to the storage location, you can also open the file path of the storage location in Windows Explorer.
Eplan Platform User interface

Same sequence for projects in the navigators and settings

If previously several projects were open in the Eplan platform, it was possible that the projects were displayed in a different sequence in the tree and list views of the navigators and in the tree of the settings dialog. This was because the projects in the navigators were sorted by an internal database ID and in the tree of the settings dialog by name. This has been corrected. The projects are now sorted by name in the tree and list of navigators as in the settings dialog. This means that the last opened project in the tree of a navigator is no longer displayed at the bottom of the list of projects, but sorted according to the name.

This search field behaves analogously to the search for properties in the parts management. During the search both the names of the displayed properties as well as the values of the properties are searched.

Eplan Platform User interface

Improvements in the assignment of tags in the Insert Center

If you assign a tag to a symbol, device or macro in the Insert center, the Manage tags: <Object name> dialog is opened to this purpose. Improvements have been made in this dialog so that tags can be created more easily and comfortably. If you click in the New tag field after opening the dialog, the list of existing tags is now displayed immediately and not as in the past only when a letter is entered. (This list contains all the existing tags, but without the tags already assigned to this object.)

In the Multilingual input dialog the row height was previously set fixed to three rows. Eplan Platform Graphical editor

Configurable coding for the QR code

In the past only the "UTF-8" coding was used for the coding of texts in QR codes. However, the "Shift JIS" coding is required for Japanese characters.

The new QR code coding project setting is now available to modify the coding of inserted QR codes in a project (command path: File > Settings > Projects > "Project name" > Graphical editing > General). With the drop-down list of this setting you can switch between the two codings "UTF-8" and "Shift JIS".
Eplan Platform Find

Also list the model views from the schematic via "Cross-referenced function -> List"

If the Cross-referenced function > List popup menu items are executed for a function on a schematic page, the cross-referenced model views are now also listed in the Search results dialog - if they exist. If you then jump from the Go to list by means of the Go to (graphic) popup menu item into the model view, the cross-referenced representation of the function is highlighted in the model view. If the function itself is not visible in the model view (for example in a drilling view) or if a style with "shading" is set for the model view, this is not possible and the entire model view is highlighted.

Thanks to this new feature it is now no longer necessary to navigate to the model view via the layout space. You can now also access the model views from the schematic via the "Go to" list.

If two or more projects are open, the project name is displayed in the tree view of a navigator as the top hierarchy level. Now you can also branch in these navigators via the Properties popup menu item into the Properties tab of the respective project.
Eplan Platform Device selection

Improvements for the device selection

In the Selected parts: Functions / templates list of the device selection the associated function templates of several parts were previously highlighted in alternating colors. Since the yellow color is used at other points in the program for the display of changed properties, this has been changed. Instead of the list, the functions / templates are now displayed in a table.

The associated function templates are now identified by having the same part number and the part number being grouped in a field. The grouped rows form a block that stands for a part. This makes it easier to differentiate the parts. In addition the part number is now displayed as the first column by default.

In the project settings for connections you now have the possibility to specify a user-defined sorting for the connection colors and for the cross-sections / diameters. Eplan Platform Reports

Output parts data of source and target of connections directly in the connection list

In the past if you wanted to output the parts data of connected items (source and target) in a connection list for a connection, this was only indirectly possible via the definition of block properties. Now these data can be output directly in a connection list, just as it is possible when outputting the parts data of source and target of cables in the cable diagram. To this purpose the placeholder texts for the forms of the connection list (*.f27) have been extended. The Part (source), Part (target), Part reference (source), and Part reference (target) elements are now additionally available in the Placeholder texts - Connection list dialog for the placement of corresponding placeholder texts in the forms.
Eplan Platform Reports

Displaying the data source of placeholder text

In a form for a function-related report (for example terminal diagram), both data for the header object to be reported (for example devices such as a terminal strip in the terminal diagram) and data for the associated data objects (for example functions such as the terminals of the terminal strip in the terminal diagram) can be output. When inserting placeholder texts into such a form it was previously not clear whether the property for the header object to be evaluated or for the associated data objects was selected and inserted into the form.

The source of the placeholder text is now displayed in the property dialog of the placeholder texts and during the selection in the Placeholder texts - <Form type> dialog. To this purpose the Placement tab in the property dialog of the placeholder texts below the field with the selected placeholder text has been extended by the new Data source field. This field shows you whether the data comes from the header object or from the data object.

In addition, the available elements in the Element field are now divided into the two lists "Header object" and "Data object" in the Placeholder texts - <Form type> selection dialog. However, these two lists are only available to you in the forms for function-related reports.

Placeholder texts for the header object can be placed in the header or footer of a form, placeholder texts for the data object can be placed meaningfully in the data area of a form.
Eplan Platform Form editor

Displaying properties of placeholder texts as images

In the Eplan platform it is now possible for reports to display properties as images by means of placeholder texts. To this purpose the technology familiar to you for the display of images or QR codes at a device has been extended for the placeholder texts. In the form editor the Display drop-down list with the three options "Text", "QR code" and "Image file" is now available in the Property (placeholder text) dialog on the Format tab below the "Alignment box" hierarchy level.

If a desired representation (for example "Image file") is not possible for a placeholder text, nothing is displayed.

Since the setting for outputting a QR code has now been moved to the Format tab, the Show as QR code check box on the Placement tab has been removed.

Eplan Platform Messages

New check run for stored parts that do not exist in the parts database

The new check run 013056 "The part with part number '<x>' and variant '<y>' does not exist in the database" is now available in the message class 013 "Parts data". This check run determines parts that are stored in the project but for which no part or no part variant with the same part number exists in the parts database. This could be the case, for example, if a part number in the parts database has changed or the part or the part variant has been deleted in the parts database.

A message is output for each device to which this part or part variant is assigned. You can use the Go to (graphic) popup menu item - as usual - to jump from the displayed message in message management to the placement on the respective schematic page and there exchange the part or the part variant. This way you can ensure that only those parts are used in a project that are currently stored in the parts database and are thus "permitted" and released.
Eplan Platform Block properties

New IF Conditions for calculation properties

IF conditions are now also possible when defining calculation properties in the calculation formulas. To this purpose a new "Conditions" section has been added to the Available format elements field in the Format: Properties dialog. Here the three new conditions "if_true", "if_false" and "if_else" are available. In addition the existing condition "if_error" has been moved from the "Basic arithmetic operations" section into this new "Conditions" section.

When using the IF conditions in calculation properties, the sequence and the grouping by brackets must be observed correctly:

  • The calculation formula that is to be evaluated (for example a comparison or a mathematical operation) must be specified first. This calculation formula must be grouped by brackets (format elements "(" and ")"). Several IF conditions are also possible in a calculation formula. These then also have to be grouped by brackets.
  • This is followed by the IF condition, which checks the result of the calculation and returns values or texts accordingly.

Conditions (dialog "Format: Calculation")

Eplan Platform Parts management

Summarize function templates automatically

Previously the function templates of the subparts in the parts management had to be combined manually during the creation or extension of assemblies or modules. Such manual editing is error-prone and it was possible that the function templates of assemblies and modules were not up-to-date. In order to prevent this in the future the new Summarize function templates automatically setting is available in the Dialog Settings: Parts (user).

By means of this setting which is activated by default, the function templates located at the subparts are combined automatically after each change in the Parts management dialog for assemblies and modules. This also takes place after a parts data import or in the case of modifications via the Eplan API. (A possible command path to the Settings: Parts (user) dialog is: Tab Master data > Command group Parts > Drop-down button Management > Settings.)
Eplan Platform Parts management

Delete local eStock data and unlink from an eStock collection

In the parts management of the Eplan platform you now have the possibility to remove the connection to an eStock collection. To this purpose - if an eStock collection is set as the data source - the Delete local eStock data menu item is available below the [Extras] button. This function deletes the downloaded parts data from eStock and rescinds the connection to an eStock collection.

This may be necessary, for example, if an eStock collection no longer exists online and the local data is to be cleaned up. Or if, for example, you have created separate directories for the master data for an eStock collection and want to change these. This is not possible as long as you are connected to the eStock collection.

When deleting the local eStock data, the files (macros, images, etc.) associated with the parts from eStock are not deleted. The settings for the directories and the settings for the database source are reset by disconnecting the connection to an eStock collection. In the process a suitable scheme (for example a scheme for another eStock collection) is set in the settings for the database source. If no suitable scheme is found, these settings are reset to the default settings of the installation ($(MD_PARTS)\EPLAN_parts.alk).
Eplan Platform Parts management

Enlarging images in the preview of the parts management

In the parts management, the Overview tab now provides the possibility to magnify the images of the preview. If you keep the [Ctrl] key pressed and double-click a preview image, this image is opened in an enlarged view in a separate dialog.

This Preview dialog can be moved, enlarged to any size, or maximized by using the corresponding button in the title bar. To close the dialog you can, for example, click the [Close] button.

This extension has also been implemented for other preview dialogs such as the graphical preview, the preview in the Symbol selection dialog, etc.
Eplan Platform Parts management

Assignment of DT IDs of an assembly to the components of a macro

The DT ID column, among others, is available to you in the Assembly tab. This DT ID can be used to carry out an assignment between the subparts of an assembly and the elements of a macro. Prerequisite for this is that the Distributed placement of assembly check box must be deselected for the assembly.

The macro can be a 3D macro (graphical macro) or a schematic macro that is assigned to the assembly. If the assembly is then inserted as a device into a layout space or onto a schematic page (for example from the Insert center), the subparts of the assembly are assigned to the components in the macro (device in the schematic macro, 3D part placement in the 3D macro) via the matching DT ID. A DT ID can be assigned more than once in the macro, but each DT ID must be unique in an assembly.

The assignment of subparts by means of a DT ID allows you to use macros flexibly. This allows you to use macros without assigned parts for different assemblies with different subparts.

The display must be configured accordingly to this purpose. These columns show you information about nested assemblies or modules. If an assembly or a module contains further assemblies and/or modules, the information whether these components contain further supplemental parts, assemblies or modules is displayed here.

The [Connection test] button has been added to the SQL server settings dialog so that you can identify a possible cause more quickly in the case of problems when using SQL databases.

Eplan Electric P8 Cables

New check run 005094 for cable connections

The check run 003029 of the message class 003 "Cables" determines prefabricated cables whose cable connections are not connected to the correct pins. However, only the first faulty cable connection is reported when this check run is executed. The new check run 005094 "For cable connection '<x>' the connected pin '<y>' of the prefabricated cable is not specified as conductor start or conductor end" is now available in the message class 005 "Connections" to report all faulty cable connections of a prefabricated cable. This check run reports all cable connections that are not connected to the correct pins. Here you jump from the popup menu of the message management to the connection definition point of the connection in the schematic by using the Go to (graphic) command and to the associated cable by using the Go to (2nd coordinate) command.
Eplan Electric P8 Terminals

New check run 001039 for saddle jumpers

The check run 001012 "Incorrect saddle jumper formation" reports an error for a connection if a connected terminal does not have a saddle jumper connection point or the terminals connected via a saddle jumper have different levels. However, cross-level jumpers can be permitted in certain cases. The new check run 001039 "Saddle jumper at terminal without saddle jumper connection point" is now available to check only the saddle jumper connection points. This check run reports an error for a connection defined as a saddle jumper if no value or the value 0 was entered at at least one of the connected terminals in the Connection point logic dialog for the Number of saddle jumpers property.

The following grouped properties are now additionally available in the property selection:

Eplan Electric P8 Terminals

"Optimize distributed terminals" extended by selection of the part variant

When optimizing distributed terminals you specify in the Optimize distributed terminals dialog which part is assigned to the different terminal types. In the past you could select a specific part variant during the selection of the part, but only the part variant "1" was used during optimization. Now the Optimize distributed terminals command takes the selected part variant into consideration. To this purpose the Optimize distributed terminals dialog has been redesigned and the selection of the part variant has been added. The previous Part number group box has been broken up and changed into group boxes for the different terminal types (Terminal, PE terminal, N terminal and SH terminal). For each terminal type the new Part variant field is now available in addition to the Part number field for each terminal type. This field displays the part variant of the selected part. If the part has several variants, you can select a different part variant by using the drop-down list. If the field is empty, part variant "1" is used.

Eplan Pro Panel Messages

New check run for determining wire lengths that are too short for routing connections

The message class 026 "3D mounting layout" now contains the new check run 026113 "Wire length is too short. The bending radius of the routing connection is possibly too large." This check run determines routing connections at which wire lengths were found that are shorter than the direct linear distance between the source and target of a routing connection. The cause is often an incorrect value of a bending radius for the connection part that is stored in the parts management. A corresponding correction avoids unnecessary queries arising during the wire manufacturing process.
Eplan Preplanning Segment templates

"Reset to segment template" only takes selected segments into consideration

In the pre-planning navigator the changed, user-defined values of segments can be reset to the values predefined in the segment template by using the Reset to segment template popup menu item. Previously this functionality affected not only the selected segments, but also the subordinate segments. If segment templates were also assigned to the subordinate segments, these segments were also reset. This behavior has now been changed. Only those segments are now reset that were also selected in the pre-planning navigator. This new feature is available as of Version 2025 Update1.
Eplan Preplanning Importing pre-planning data

Generating nested segments directly during the import

Nested segments can be generated in the pre-planning navigator on the basis of segment templates with subordinate segment templates. If such segment templates are predefined in the segment template navigator, nested segments can now also be generated directly during the import of corresponding pre-planning data. The Update segments from segment templates after the import check box is available in the Import pre-planning data dialog to this purpose.

If this check box is activated, the segments to which a segment template is assigned are updated after the import. In the process the data from the segment templates - also subordinate segment templates - are transferred to the segments. If subordinate segment templates exist, possible nested segments are generated directly in the pre-planning navigator.

The segments with assigned segment templates can also be updated at a later time. To do so, select the Update segments popup menu item in the segment template navigator.
